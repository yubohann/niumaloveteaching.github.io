第 060 章：早停与ASHA调度器

把预算花在幸存者身上：逐次减半（Successive Halving）用"小预算广撒网、大预算重点养"的层级结构压缩评估成本，异步版本 ASHA 去掉同步屏障后让试验随到随比，理论性质与实践参数（宽限期、降级因子、档位）逐一讲透。

  • 主题：Ray Tune 调优（早停调度器）
  • 关键机制：逐次减半、档位晋升、异步剪枝
  • 预计学时：60 分钟
  • 前置章节：第 059 章

学习目标

  • 理解逐次减半的资源分配逻辑：几何级数档位、每档保留固定比例、总预算的指数级节省。
  • 掌握 ASHA 的异步化改造：去掉档位屏障后，试验随到随比、达到标准立即晋升或终止。
  • 会计算档位表与总预算：由宽限期、降级因子与训练上限推导各级预算与初始试验数。
  • 会配置 ASHA 调度器并说明检查点频率与档位对齐的必要性，避免恢复回退浪费。
  • 能对比 ASHA 与中位数停止（Median Stopping）的适用差异，并为噪声任务设计宽限期。

背景与动机

大量试验里，多数配置在训练早期就能被判定为劣质：学习率量级错误的配置往往在十分之一的预算内就露出差距。平均分配预算会把这些注定失败的试验"养到终点"，浪费的算力本可以分给更有希望的候选。早停调度器的任务是把预算从劣质试验手中收回，重新分配给幸存者。

逐次减半给出了层级化的分配结构，但同步版本要求所有试验在同一档位等齐才能淘汰，慢试验会拖住整档。ASHA（Asynchronous Successive Halving Algorithm）去掉等待：试验完成一档即可与同档对手比较，胜者立即加预算进入下一档。强化学习训练时长长、单试验代价高，ASHA 的异步剪枝是 Tune 搜索的默认推荐调度器。

核心原理

本节按"逐次减半、ASHA 异步化、档位计算、噪声适配"四步展开。

1. 逐次减半：几何档位与固定保留比例

设最小评估预算为 r（宽限期），降级因子为 η，则档位预算构成几何级数：r, r·η, r·η², …, 直到训练上限。每档结束后按指标排序，保留前 1/η 进入下一档，其余终止。初始试验数 n 与档位数 k 的关系由几何结构决定：从 n 个试验起步，每档规模除以 η，最后一档恰剩 1 个（或少数几个），所需的档位数 k 满足 n ≈ ηk。

档位预算：rj = r · ηj ，j = 0, 1, …, k ； 每档保留比例 1/η r=10 轮、η=3、上限 810 轮时档位为 10、30、90、270、810 共 5 档；起步试验数约 34=81 个

预算节省来自结构：大多数试验只在最小档位消耗 r，少数进入高档。设总档位数 k，全部试验跑满的总成本是 n·r·ηk，逐次减半的实际成本约为其 1/η 至数分之一的量级（随档数与比例变化）。节省的本质是把"广撒网"的探索与"重投入"的利用放进同一预算曲线：早期样本多而浅，后期样本少而深。

节省倍数可以写成闭式：实际总成本等于 档位数 × 起步数 × 宽限期，全量成本等于 起步数 × 最末档预算，两者相除得 比值 = ηk−1/k（k 为档位数）。前文例子的 34/5=16.2 与 24/5=3.2 都与此式吻合。因子越大、档位越多，节省越显著，但每档保留比例 1/η 也越小，误杀概率同步上升；这条曲线把"省预算"与"保质量"的取舍写成一个式子，调参时两者一起看。

2. ASHA：去掉屏障的异步剪枝

同步逐次减半在每一档设置屏障：等齐、排序、淘汰、放行。ASHA 把排序改为"随到随比"：试验完成当前档位后，与同一档位已完成的试验比较，若排进前 1/η 立即晋升下一档，否则终止。异步化消除了等待，代价是晋升判定只基于"部分对手"：决策带有局部性，理论保证从精确排序退化为高概率保留优质配置。在评估噪声可控、试验数量充足时，这个代价可以接受。

ASHA 还支持多括号（Brackets）：用不同的宽限期同时运行多个独立的减半结构，例如一组从 10 轮起步、一组从 30 轮起步。括号是对"最小可信预算"不确定性的对冲：宽限期过小的括号负责快速筛除劣质配置，宽限期较大的括号保护"起步慢、后程强"的配置不被误杀。

3. 档位与预算的计算流程

配置 ASHA 的三个输入是宽限期、降级因子与训练上限，其余量可推导：

  1. 由上限除以宽限期得到档位跨度比值 R/r；
  2. 档位数 k = ⌊ logη(R/r) ⌋，档位预算为几何级数；
  3. 每档保留比例 1/η，初始试验数按"最终每档幸存数乘以 η档位数"估算；
  4. 总评估成本按"各档试验数乘档位预算"逐档累加。

检查点频率必须与档位对齐：试验被终止或晋升时，调度器读取最近检查点决定状态；若检查点频率低于档位间隔，恢复或晋升会回退到旧状态，重复消耗的预算抵消剪枝节省。对强化学习任务，检查点频率取档位间隔的 1/2 至 1 倍。

指标口径的实施同样在配置阶段定死：上报字段必须与调度器声明的 metric 逐字一致，评估前缀写错时调度器把试验视为没有指标、从不淘汰，表现为全部试验跑满上限、算力被明显劣质的配置白白消耗。核对方法沿用 056 章的口径：先跑单试验打印报表键，再写调度器配置；评估间隔不大于宽限期，保证第一档结束时每个试验至少有一次评估读数可用。

成本核算的落点：把"档位数 × 起步数 × 宽限期"记入实验记录的预算栏，与资源池换算出的并发数配对，估算搜索墙钟 = 总轮数 ÷（并发数 × 单轮平均耗时）。三个量中任何一个调整后重算一次，整批搜索的资源申请单直接引用该栏数字；评审时无需回翻配置，预算变化时也只改这一处。

3.1 数值算例：档位表与总预算的逐步计算

例一：宽限期 10 轮、降级因子 3、上限 810 轮。档位按几何级数生成：10、30、90、270、810，共 5 档；由"最后一级剩 1 个试验"反推起步规模约 34=81 个。逐档成本：第 0 档 81×10=810 轮，第 1 档 27×30=810 轮，第 2 档 9×90=810 轮，第 3 档 3×270=810 轮，第 4 档 1×810=810 轮，总成本 4050 轮。全量评估需要 81×810=65610 轮，剪枝压到约 1/16.2。观察到的不变量：每档成本恰好等于 起步数 × 宽限期，原因是幸存数每档除以 η、档位预算每档乘以 η，两者乘积恒定，于是总成本等于 档位数 × 起步数 × 宽限期。

例二：宽限期 15、因子 2、上限 240。档位 15、30、60、120、240 共 5 档，起步 16 个，每档成本 240 轮，总成本 1200 轮；全量 16×240=3840 轮，比值 3.2。两例对比说明两个参数的角色差异：因子决定每档保留比例与档位步进，宽限期决定最小可信预算；总成本由三者乘积控制。调参数前先把这个乘式算一遍，"剪枝后预算反而超支"的配置就不会出现。

3.2 宽限期的估计与误杀防护

宽限期估计实验：用一组固定配置跑 10 粒种子，记录回报首次超过随机水平 1.5 倍的轮数，取该分布的中位数再乘 1.5 至 2 作为宽限期。样本中位数为 12 轮时宽限期取 18 至 24 轮；起步慢的配置占比高时取上界。误杀的定量直觉：两个配置真实水平相差 δ、单次评估噪声标准差 σ 时，正确排序的概率约为 Φ(δ/(σ√2))，δ=σ 时约 0.76，δ=2σ 时约 0.92。宽限期的作用是让 δ 从早期的小值长大到 σ 的量级以上再开始排名，否则"谁先被淘汰"接近抛硬币。

3.3 多括号的资源口径

括号数 b 的运行口径：括号共享同一试验预算池，每个括号获得 num_samples/b 个试验；宽限期不同的括号各自独立推进档位，彼此的淘汰互不影响。括号数的代价不在资源，而在每个括号的规模被摊薄：120 个试验分两括号时各 60 个，链长缩短、竞争变弱。启用多括号时建议把总试验数按括号数同比例上调；资源紧张时回到单括号加保守宽限期，比拆分一个小池子更稳。

4. 噪声适配：宽限期与指标口径

强化学习评估噪声是早停的最大威胁：宽限期太小时，排名由起步波动决定，优质配置可能被提前淘汰。适配手段有三：（1）宽限期覆盖"回报脱离随机水平"的典型时长，用单变量实验估计；（2）指标用评估回报或滚动均值，压低单点噪声；（3）降级因子取温和值（2 至 3），保留比例 1/2 或 1/3，给幸存者更多证明机会。中位数停止是另一类早停：把试验与"同进度全部试验的中位数"比较，低于中位数若干轮即终止；它无需分档结构，实现更简单，但缺少几何预算的层级放大效应。试验数量多、预算紧张时选 ASHA；试验数量少、想温和过滤时选中位数停止。

噪声大时还有一条降误杀手段：把降级因子降到 2（每档保留一半），同时把试验总数放大到原来的两倍以上，用规模换统计余量。等价地，把同样预算从"少试验、激进淘汰"改成"多试验、温和淘汰"，在噪声主导的任务里结论更可靠。

实现思路与设计

ASHA 接入按五步执行。

  1. 估计宽限期：用单变量扫描估计回报脱离随机水平的轮数，取其 1.5 至 2 倍。
  2. 定降级因子：2 至 3；噪声大时取小值（保留比例大）。
  3. 定训练上限与试验数：上限按正式训练预算；试验数按档位公式反推，量级 50 至 200。
  4. 配置检查点：频率与档位间隔对齐，保证晋升与恢复状态完整。
  5. 指标与括号：评估指标进调度器；对宽限期不确定时启用多括号。

宽限期、因子与上限的选择顺序固定下来：先由脱离随机水平的实验定宽限期，再由噪声水平定因子（噪声大取 2），最后由正式训练预算定上限；三个量固定后，用核算函数重算档位表与总预算，与资源池换算的并发数一并写入实验记录再启动。顺序颠倒时最常见的返工是把因子调大以求多省预算，结果宽限期不足、误杀率飙升，搜索结论比省下的算力更贵。

与上一章的差异：059 章淘汰的是"落后个体"且资源留在种群内继续进化，本章淘汰的试验直接终止、资源回收给新试验或幸存者；PBT 依赖状态复制，ASHA 依赖状态检查点，两者对检查点的依赖形式不同。

关键代码与解读

片段 1：档位表计算

import math

def rung_schedule(grace=10, factor=3, max_t=810):
    """由宽限期、降级因子与上限推导档位预算表。"""
    rungs = []
    r = grace
    while r <= max_t:
        rungs.append(r)
        r *= factor
    # 每档保留 1/factor：最后一级剩 1 个试验时，初始试验数约为
    # factor 的(档位数-1)次方；此处按最后档位反推起步规模
    n_start = factor ** (len(rungs) - 1)
    total_budget = sum(n_start // (factor ** j) * rungs[j]
                       for j in range(len(rungs)))
    print("档位：", rungs, " 起步试验数：", n_start,
          " 近似总预算：", total_budget, "轮")
    return rungs, n_start, total_budget

# 输出：档位 [10, 30, 90, 270, 810]，起步 81 个，总预算约 4050 轮
# 每档成本恒为 810 轮（幸存数减半、预算翻三倍，乘积不变）；
# 对照：81 个试验全部跑满 810 轮需要 65610 轮，节省约 16 倍

解读：逐块说明。（1）档位按几何级数生成，循环条件用上限截断；档位数由宽限期与因子共同决定。（2）总预算按"每档幸存数乘档位预算"逐档累加：第 j 档的幸存数为 n/ηj，两者相乘后求和，得到剪枝后的实际消耗。（3）对照数字是理解剪枝收益的最短路径：同一探索宽度下，逐次减半的预算约为全量评估的十六分之一；节省倍数随档数与因子变化，可用该函数直接核算后再拍板参数。

片段 2：ASHA 调度器配置

from ray import tune
from ray.tune.schedulers import ASHAScheduler

asha = ASHAScheduler(
    time_attr="training_iteration",           # 档位按训练迭代计
    max_t=300,                                # 单试验上限：正式训练预算
    grace_period=20,                          # 宽限期：回报脱离随机水平的估计值
    reduction_factor=3,                       # 每档保留 1/3
    brackets=2,                               # 两个括号对冲宽限期不确定性
    metric="evaluation/episode_reward_mean",  # 评估指标：抗训练噪声
    mode="max",
)

analysis = tune.run(
    "PPO",
    scheduler=asha,
    config={
        "env": "LunarLander-v2",
        "lr": tune.loguniform(1e-5, 1e-2),
        "gamma": tune.uniform(0.95, 0.999),
        "train_batch_size": tune.choice([4096, 8192, 16384]),
        "evaluation_interval": 5,
        "num_env_runners": 4,
    },
    num_samples=120,                          # 宽探索：多配置配浅预算
    resources_per_trial={"cpu": 6, "gpu": 0.25},
    max_concurrent_trials=8,
    stop={"training_iteration": 300},
    checkpoint_config=tune.CheckpointConfig(
        checkpoint_frequency=10,              # 不大于档位间隔：恢复不回退
        checkpoint_at_end=True,
    ),
)

解读：这段配置把档位计算的结论逐项落地。（1）宽限期 20、因子 3、上限 300 对应的档位为 20、60、180（下一档 540 超过上限），起步规模约 9 个幸存链再乘 120 个试验的探索宽度，剪枝在早期即开始工作。（2）括号数 2：两个减半结构并行，一个从宽限期起步、一个从更大预算起步，降低"起步慢但后程强"的配置被误杀的风险。（3）检查点频率 10 与档位间隔（20 轮）对齐：晋升与终止决策都能取到较新状态；评估间隔 5 保证调度器看到的指标取自评估回报，与训练噪声隔离。

片段 3：剪枝效果核算

import pandas as pd

def pruning_report(analysis):
    """统计被剪枝与跑满的试验，核算实际节省。"""
    rows = []
    for trial in analysis.trials:
        df = trial.metrics_dataframe
        if df is None or df.empty:
            continue
        last_iter = int(df["training_iteration"].max())
        # 未到上限即结束的试验，即被 ASHA 剪枝的个体
        rows.append({"trial": trial.trial_id, "iters": last_iter,
                     "pruned": last_iter < 300,
                     "best": df["evaluation/episode_reward_mean"].max()})
    table = pd.DataFrame(rows)
    pruned = table[table["pruned"]]
    saved = int((300 - pruned["iters"]).sum())
    print(f"剪枝试验 {len(pruned)}/{len(table)} 个，节省约 {saved} 轮训练")
    # 验收口径：剪枝试验的最高指标不应超过幸存者头名太多，
    # 否则说明宽限期或因子过激进，优质配置被误杀
    head_pruned = pruned["best"].max() if len(pruned) else 0.0
    print(f"被剪枝个体的最高指标：{head_pruned:.1f}")
    return table

# 若被剪枝个体最高指标显著高于幸存者，优先调大宽限期或因子，
# 继续加试验数收益有限：误杀的成本高于多评估的成本

解读：逐块说明。（1）以"是否跑满上限"区分剪枝与完整试验，节省量按未消耗的轮数累加，是剪枝收益的直接度量。（2）误杀检查给出调度参数的调优方向：被剪枝个体的最高指标接近甚至超过幸存者时，剪枝标准过激，先调宽限期与降级因子再考虑扩容。（3）该函数与 056 章的选优流程衔接：剪枝报告用于体检调度器，最优检查点仍按评估指标从幸存者中提取。

读取口径再补两点：被剪枝个体在低预算处的高指标不构成误杀证据，只有它们在更高预算上仍具竞争力的旁证（例如同配置在其他括号中的表现）才说明宽限期偏小。报告中同时记录每个试验的结束预算分布：分布集中在低档说明剪枝激进而有效；长尾延伸到高档说明多数试验跑完了大半预算，剪枝收益有限，应检查因子是否过小或指标噪声是否过大。

常见坑

  • 宽限期过小：起步噪声决定排名，优质但起步慢的配置被提前剪枝，搜索结论偏差大。修复：宽限期覆盖回报脱离随机水平的时长，并启用多括号对冲。
  • 检查点与档位不对齐：晋升时只能恢复到很旧的状态，重复训练抵消节省。修复：检查点频率取档位间隔的 1/2 至 1 倍。
  • 降级因子过激进：η 取 4 以上时每档只留 1/4，噪声下幸存者选择几乎随机。修复：η 取 2 至 3，保留比例 1/2 或 1/3。
  • 用训练指标驱动剪枝：训练回报噪声大，剪枝频繁误判。修复：评估指标进调度器，评估间隔不大于档位间隔。
  • 试验数不足：20 个试验配 3 档剪枝，幸存者链条太短，搜索宽度与深度都受限。修复：按档位公式反推起步规模，量级 50 至 200。

练习与思考

  1. 计算：宽限期 15、因子 2、上限 240 的档位表、起步试验数与近似总预算；与全部试验跑满的成本比较节省倍数。★
    提示
    档位为 15、30、60、120、240 共 5 档；起步 16 个，按每档保留 1/2 逐档累加总预算，再与 16×240 对比。
  2. 推导：设每档保留比例 1/η、档位数 k，写出剪枝后总预算与全量预算的比值表达式，并说明 η 增大时比值如何变化。★★
    提示
    总预算为 Σ n·rj/ηj，全量为 n·r·ηk；η 越大保留越少、比值越小，但噪声下误杀概率上升，收益与风险同向。
  3. 设计宽限期估计实验：用固定配置跑 10 个种子，记录回报首次超过随机水平 1.5 倍的轮数分布，给出宽限期取值与验证方式。★★
    提示
    取分布的中位数乘 1.5 至 2 作为宽限期；验证方式是观察剪枝报告中误杀个体与幸存者的指标差距。
  4. 比较 ASHA 与中位数停止在"20 个试验、评估噪声大"场景下的表现差异，给出选择与参数建议。★★★
    提示
    20 个试验规模小，ASHA 的档位链条短、晋升竞争不足；中位数停止按同进度比较更平滑。建议该场景用中位数停止加宽松阈值，或扩试验数后再启用 ASHA。
  5. 解释多括号为什么能对冲宽限期的不确定性：从"起步慢、后程强"配置的命运角度分析，并说明括号数与资源开销的关系。★★
    提示
    大宽限期的括号让慢热配置获得证明机会；每个括号独立消耗预算，括号数增加意味着同等试验数下每括号的规模变小，需要整体扩容配合。

小结

  • 逐次减半用几何档位与固定保留比例分配预算：早期样本多而浅，后期样本少而深，总成本降至全量评估的若干分之一。
  • ASHA 去掉档位屏障，试验随到随比、即时晋升或终止；理论保证退化为高概率保留，换取无等待的吞吐。
  • 档位、初始试验数与总预算由宽限期、降级因子与训练上限推导，可用核算函数在配置前拍板。
  • 检查点频率与档位对齐，评估指标进调度器，宽限期覆盖回报脱离随机水平的时长。
  • 多括号对冲宽限期不确定性，误杀检查（被剪枝个体的最高指标）是调度参数调优的第一依据。
