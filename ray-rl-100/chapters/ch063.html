第 063 章：多目标优化与约束优化

回报、吞吐、时延、显存常被同时要求，单一标量目标无法表达这种取舍。本章讲透多目标优化（Multi-Objective Optimization, MOO）的支配关系与帕累托前沿（Pareto Frontier），给出权重和、ε-约束、惩罚三种表达方式各自的边界，以及训练期约束的可行性处理路径。

  • 主题：Ray Tune 调优 / 多目标与约束
  • 关键机制：帕累托支配、超体积、ε-约束、惩罚项、可行域
  • 预计学时：55 分钟
  • 前置章节：第 062 章

学习目标

  • 掌握帕累托支配与帕累托前沿的定义，会从结果表手工判定支配关系。
  • 理解权重和标量化的局限：非凸前沿段不可达，从而理解为什么需要 ε-约束与多目标搜索。
  • 会用 Tune 的多目标搜索接口（以 OptunaSearch 为代表）同时优化两个指标，并提取前沿集合。
  • 掌握约束的三种处理路径：空间层消除、惩罚项软约束、训练期检测硬终止，知道各自的代价。
  • 会判读多目标实验：用前沿点数量与超体积（Hypervolume）评估搜索进展。

背景与动机

强化学习调优的实际问题常带多个要求：回合回报要尽量高，每迭代耗时不能失控，显存占用要在预算内，策略熵不能塌缩。把多要求压成一个加权求和是常见做法，但它有两个硬伤：权重难以事先确定，且权重和只能找到前沿的凸起部分。非凸的取舍关系（例如“略微牺牲回报换取大幅吞吐”）在权重和框架下永远采不到。

约束优化处理另一类要求：某些指标不参与竞争，只要求不越界。显存超限、动作越界、可行性违例都属于此类。约束与目标的区别在于语义，一个要求“尽量好”，一个要求“不许坏”。混用两种语义会把搜索引向违规边界。本章把多目标表达与约束处理分开讲清，再合流到统一的实验设计。

归属判定的口径可以写成一句话：某项指标"多一点少一点都要尽量好"就归目标；"越过某条线才需要处置"就归约束。按这条口径逐项过一遍指标清单，每个量都有归属，后续搜索接口与惩罚项的配置就不再依赖临时判断。

核心原理

1. 支配关系与帕累托前沿

多目标问题写作 min f(θ) = (f1(θ), …, fm(θ))。配置 A 支配（Dominate）配置 B，当且仅当 A 在所有目标上不劣于 B，且至少在一个目标上严格更优。被任何配置都不支配的配置集合构成帕累托前沿。前沿上的点互相不可比较，取舍由下游偏好决定。多目标优化的输出是一个集合，不存在单一最优点，这一点决定了实验报告的形式：给出的应是前沿表，单行最优配置无法表达取舍。

A ≺ B  ⟺  ∀i: fi(A) ≤ fi(B)  且  ∃i: fi(A) < fi(B) “≺”表示支配；前沿 = 不被任何点支配的子集；两目标问题可在一张散点图上直接圈出

2. 权重和标量化的局限

权重和把目标合成 S(θ) = w1f1 + w2f2，形式上把问题还原为单目标。它的可达集合是前沿与某条等值线的切点，几何上只覆盖前沿的凸包（Convex Hull）部分。前沿若向原点凹陷，凹陷段上任意一点都不是任何正权重组合的最小值，无论怎么调权重都取不到。ε-约束法解决这个缺陷：保留一个主目标，把其余目标改为上限约束 f2(θ) ≤ ε2，扫描若干 ε 值即可贴着一整段前沿采样，包括非凸段。

不可达的凹部可以用一组手算读数确认：取三个可行配置的目标值（两个目标都取最小化），P1=(0,4)、P2=(1.5,2.7)、P3=(4,0)。P1 与 P3 互不支配（一个第一目标更好、一个第二目标更好）；P2 虽在每个单目标上都不占优，却也没有被任何点支配，属于帕累托前沿成员。把权重和 S=w·f1+(1−w)·f2 在 w 从 0.05 扫到 0.95 上逐一求最小，结果只会落在 P1 或 P3，P2 从不取胜；几何上 P2 位于 P1P3 连线的上方，任何权重的等值线都切不到它。换成 ε-约束即可达：令第一目标不超过 2，在可行集内最小化第二目标，P2 以 2.7 胜出。

3. 前沿质量的度量：超体积

比较两轮搜索得到的前沿需要单标量指标。超体积（Hypervolume, HV）以一个参考点 r 为基准，计算被前沿支配区域的 Lebesgue 测度：

HV(A) = Volume( ∪p∈A [r, p] ) 参考点取各目标的最差值再加余量；前沿越接近理想角、点越密，超体积越大

超体积对“前沿向理想方向推进”与“前沿覆盖变宽”都敏感，适合作为多目标搜索的进展曲线：随试验数绘出 HV 曲线，若长期平坦说明边际收益耗尽，应转入局部加密或更换空间。

数值算例：第一轮前沿为 (175,39)、(180,39)、(185,44)（回报越大越好、耗时越小越好），参考点取 (170,50)。按回报升序扫描被支配区域：到 175 贡献 5×11=55；到 180 新增宽度 5、高度 11，贡献 55；到 185 新增宽度 5、高度 6，贡献 30，合计 HV=140。第二轮前沿推进为 (175,39)、(185,38)、(190,42)：按耗时最小值分段计算，三段贡献 5×12=60、10×12=120、5×8=40，HV=220，相比第一轮的 140 提升约 57%。推进距离与覆盖宽度都被同一根曲线吸收，这正是用 HV 做进展曲线的理由。参考点的位置影响 HV 的绝对数值，跨轮比较必须固定同一参考点，并在各目标最差值之外留约 5% 余量；参考点移动过的两轮结果不可直接相减。

4. 调度器与多目标的适配

早停调度器的比较池基于单指标，与多目标存在口味差：一个在目标一上出色、目标二上平庸的试验，在单指标调度器眼里可能被判弱。常用方案是给调度器指定一个主指标（例如回报），多目标搜索机制在存活试验之间维护前沿；主指标承担筛选，前沿承担输出。把两个角色分开后，逻辑清晰且与现有调度器兼容。若希望调度器也感知取舍，可用超体积贡献作为调度指标，但这会增加实现复杂度，适合在基础流程稳定后再引入。

5. 约束的三种处理路径

约束按“可判定时机”分三层处理：

  • 空间层消除：整除、互斥这类采样时即可判定的结构约束，用第 061 章的 sample_from 联动，代价为零。
  • 惩罚项软约束：把违反量加进目标，S(θ) = 归一化目标 − λ·Violation(θ)。λ 是代价旋钮：过小时约束被无视，过大时梯度被惩罚主导、目标优化停滞。惩罚量必须与目标同量纲，先各自归一化再线性组合。
  • 训练期检测硬终止：当约束只能在训练中判定（显存溢出、数值爆炸），在训练函数内检测并抛出终止信号，试验立即回收资源。它保住剩余预算，但已消耗的部分不可追回，因此检查频率要高、判定要留安全余量。

可行率高时，硬终止近似于采样拒绝，效率可观；可行率很低（多数配置都违规）时，应回到空间层收缩范围，把采样概率质量移回可行区。

5.1 惩罚系数的对照实验口径

惩罚系数 λ 的对照实验按倍率展开：以"违反量达到整个经验量程时惩罚等价于一份主目标"为基准口径，分别测试 0.5、2、8 三档。预期读数：0.5 时可行率偏低，约束被部分无视；2 时可行率与主目标的联合曲线进入拐点区间；8 时几乎全部试验挤在可行域内侧，主目标推进停滞。判读口径看两条曲线的交叉区：可行率随 λ 上升趋近 1，主目标随 λ 上升而下降，取两者乘积开始回落的点作为 λ 的起点。实验记录里同时保存未归一化的原始量，后续改量纲时可以直接回算，不必重跑。

实现思路与设计

多目标与约束实验的设计从一张清单开始：把每个指标明确归类为“目标”或“约束”，目标给出方向，约束给出阈值与判定时机。与上一章的差异在于，第 062 章调度试验的生死，本章重新定义试验被评价的坐标系。

方法适用情形表达方式主要风险
权重和只有两个目标且前沿近凸单指标 S = Σwifi非凸段不可达；权重需反复试
ε-约束可指定可接受阈值主目标 + 其余指标上限阈值过紧时可行域为空
多目标搜索要求输出完整前沿指标列表 + 方向列表调度器需指定单指标适配
惩罚项约束可量化且时时可测目标 − λ·违反量λ 选择困难，量纲敏感
训练期硬终止约束只在运行中暴露检测后抛出终止信号已消耗预算不可追回

执行流程分五步：

  1. 归一化口径：为每个指标确定参考范围（历史结果或首轮粗搜），后续所有组合运算都在归一化后进行。
  2. 目标与约束分离：目标进搜索接口的指标列表，约束进惩罚项或检测点。
  3. 调度主指标选择：从目标中挑一个与最终诉求最贴近的作为调度器比较轴，写进实验说明。
  4. 预算分配：多目标搜索的试验数取 60 至 120，比单目标更宽，因为前沿覆盖率随点数增长。
  5. 判读输出：导出前沿表与超体积曲线，前沿点逐个检查是否贴合物理直觉，异常点回查配置。

判读的三条阈值规则写进分析脚本：前沿点数占总试验数的比例反映搜索集中度，比例低于 5% 说明大多数试验被支配、空间可能过宽；前沿中相邻点的目标间距突然变大处是覆盖空洞，下一轮对该区段加密；目标值几乎相同的重复点在提取时按试验标识去重，避免同一配置占用多个前沿名额。实验报告只呈现清洗后的前沿表与 HV 曲线，异常点回查配置后再归档。

设计决策：为什么多目标搜索仍要指定调度主指标？

调度器在每个上报点上只接受一个标量比较值，这是接口层面的现实约束。指定主指标意味着“筛选标准”与“输出标准”分离：筛选过程保持单轴可解释，输出阶段再展示完整取舍。主指标建议选择与任务目标直接相关的量（回报），把资源类指标（时延、显存）留给前沿展示与约束判定。

片段 2：从结果表提取帕累托前沿

import pandas as pd

def pareto_front(df, objs, modes):
    """非支配筛选：objs 为指标列，modes 为每列方向（max/min）。"""
    df = df.dropna(subset=objs).reset_index(drop=True)
    sign = [1.0 if m == "max" else -1.0 for m in modes]
    # 统一方向后一律按“越大越好”比较，支配判定只写一遍
    pts = [tuple(df[c].iloc[i] * s for c, s in zip(objs, sign))
           for i in range(len(df))]
    keep = []
    for i, p in enumerate(pts):
        dominated = False
        for j, q in enumerate(pts):
            # 不允许自我支配；其余点需在所有目标上不劣且至少一维严格更优
            if i != j and all(qk >= pk for qk, pk in zip(q, p)) \
                    and any(qk > pk for qk, pk in zip(q, p)):
                dominated = True
                break
        if not dominated:
            keep.append(i)
    # 返回时保留原始量纲与列结构，便于直接生成报告表
    return df.iloc[keep].sort_values(objs[0], ascending=(modes[0] == "min"))

解读：提取函数只有两层循环，代价 O(n²)，本课程的试验量级下完全可接受。（1）先按方向把各列乘以符号，之后所有比较都按“越大越好”，避免在判据里反复分支，减少方向写反的机会。（2）支配判定要求“所有维度不劣”与“至少一维严格更优”同时成立，缺一不可；只有全等时互不支配，两个重复点会同时保留，此时可按试验标识去重。（3）输出保留原始量纲并沿主目标排序，直接可作报告表；前沿点数与总试验数的比值反映搜索是否集中，比值过小说明大量试验被支配、空间可能过宽。接口随版本演进，若所用版本自带前沿工具函数，可用它替换本实现并核对结果一致。

片段 3：惩罚项与训练期硬终止

from ray import tune

# 归一化参考：由首轮粗搜得到的目标量程与违反量量程
RET_SCALE = 200.0     # 回合回报的经验量程
VIOL_SCALE = 0.4      # 显存违反比例的经验量程

def train_fn(config):
    for it in range(max_iters):
        m = run_one_iteration(config, it)
        # 违反量：超出显存预算的比例，0 表示完全满足约束
        viol = max(0.0, m["mem_used_gb"] / m["mem_budget_gb"] - 1.0)
        # 惩罚项与目标各自归一化后相减：量纲对齐是 λ 有效的前提
        penalized = m["episode_return_mean"] / RET_SCALE \
            - 2.0 * (viol / VIOL_SCALE)
        if viol > VIOL_SCALE:
            # 严重不可行：尽早终止，回收剩余预算（异常类型以版本文档为准）
            raise tune.TuneError("显存约束严重违反，终止该试验")
        tune.report(episode_return_mean=m["episode_return_mean"],
                    penalized_return=penalized,
                    mem_violation=viol)

解读：这段训练函数展示约束处理的双层结构。（1）轻微违反交给惩罚项，搜索机制仍能沿着“可行边缘”寻找平衡点；（2）严重违反交给硬终止，避免为一个已注定不可行的配置继续消耗数十分钟的采样预算，两个阈值分开设置给了一个缓冲区。（3）惩罚系数 2.0 的含义是“违反量达到整个经验量程时，惩罚相当于两份归一化目标”，即约束权重约为主目标的两倍；系数的最终取值靠对照实验确定，先跑 2 至 3 个系数值观察可行率与回报的曲线。（4）上报三个指标：主指标供调度器使用，惩罚目标供分析对比，违反量供可行性审计。具体异常类型与终止语义以对应版本的官方文档为准。

常见坑

  • 方向写反：mode 与指标含义不匹配（耗时按 max 处理），前沿整体取反，挑出的“最优”恰是最差。症状是前沿点明显违背直觉。修复：前沿提取前先做方向断言，检查主指标与人工抽查点一致。
  • 量纲未归一化就做支配判定：回报量程两百、耗时量程个位数时，耗时差异对支配关系几乎无影响，第二目标形同虚设。修复：比较前统一归一化，或先标准化再进前沿提取。
  • 用权重和代表全部取舍：非凸前沿段不可达，搜索跑到“凸角”就停滞。修复：改 ε-约束或直接使用多目标搜索接口。
  • 惩罚系数失控：λ 过小时约束被无视，试验批量违规；λ 过大时全部试验挤向可行边界内侧，目标优化停滞。修复：在归一化基础上做 λ 的小范围对照，观察可行率与目标的联合变化。
  • 硬终止判定阈值过紧：把“接近上限但仍有优化价值”的配置提前杀掉，可行率虚高但前沿缩水。修复：设缓冲带，把终止阈值放在预算上限之外再留余量。

    提示
    回报按 max、耗时按 min 比较：(180, 39) 支配 (175, 39)（回报更高、耗时相同）；(185, 44) 与 (180, 39) 互不支配（一个回报更高，一个耗时更短）。前沿为 {(185, 44), (180, 39)}。
  2. 预测题：双目标搜索中把调度主指标从回报改为耗时，早期被 ASHA 淘汰的试验群体结构会怎样变化？对最终前沿的覆盖有什么影响？★★
    提示
    以耗时为主指标会保留“快而弱”的试验，回报高但慢的配置在第 0 档就被淘汰，最终前沿在高回报区域出现空洞。主指标应与最终诉求对齐，牺牲的恰好是另一侧的覆盖。
  3. 设计题：用 ε-约束法设计一次两阶段搜索：第一阶段用宽 ε 找出可行域边界，第二阶段收窄 ε 并加密主目标搜索。给出两阶段的试验数、ε 取值与判读标准。★★★
    提示
    阶段一 40 个试验扫描 3 个 ε 档位，找出可行与不可行的分界；阶段二在分界内侧 1 至 2 档选 40 个试验密集搜索。判读标准：阶段一的违规率必须随 ε 单调下降；阶段二主目标的分布不应向 ε 边界塌缩。
  4. 推导题：写一个两目标专用的前沿提取算法，利用“按第一目标排序后扫描”把复杂度降到 O(n log n)，并说明为什么它不能直接推广到三维。★★★
    提示
    按第一维降序排序，维护当前第二维的最大值，新点第二维若不超过该最大值则被支配。三维需要维护二维前缀结构（如分层树），简单扫描失效。
  5. 实践题：仿照片段 3 为你的任务定义一条训练期约束（如梯度范数上限），选择惩罚系数起点，并写出判定硬终止的阈值与理由。★★
    提示
    先统计无约束训练中该量的分布，取 95 分位作为违反从零起算的基准；硬终止阈值放在 99 分位之外并留 20% 余量，惩罚系数从“违反量满量程等价于一份主目标”开始对照。

小结

  • 多目标优化的输出是帕累托前沿集合；支配判定要求全维不劣且至少一维严格更优。
  • 权重和只能覆盖凸前沿段；ε-约束与非支配搜索是更完整的表达方式。
  • 超体积把前沿质量压成单标量，适合作为搜索进展曲线与两轮搜索的对比指标。
  • 调度器保持单主指标，多目标搜索维护前沿，“筛选与输出分离”是兼容现有组件的关键设计。
  • 约束按判定时机分三层处理：空间层消除、惩罚项软约束、训练期硬终止；惩罚必须建立在归一化之上。
