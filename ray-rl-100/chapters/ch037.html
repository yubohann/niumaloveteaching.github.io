第 037 章：RLlib实现SAC算法

SAC（Soft Actor-Critic）以最大熵目标把探索写进优化对象，用双 Q 网络与软更新稳定价值估计。本章讲清熵增强回报、软贝尔曼方程、重参数化采样与温度自动调节，以及连续控制场景的配置要点。

  • 主题：RLlib 算法 / 离策略演员评论家
  • 关键机制：最大熵目标、软 Q 更新、双 Q、重参数化、温度自动调节
  • 预计学时：55 分钟
  • 前置章节：第 036 章

学习目标

  • 理解最大熵目标的结构，说明熵项与温度系数在探索中的角色。
  • 掌握软贝尔曼方程与双 Q 目标的构造，理解最小化取值对高估的抑制。
  • 理解重参数化采样与有界压缩，会处理对数概率的修正项。
  • 掌握温度自动调节的机制与目标熵取值依据。
  • 会配置 SAC 的关键参数：软更新系数、回放容量、学习启动步数与批次规模。

背景与动机

连续控制任务的动作为实数向量，价值型算法对连续动作取最大值的操作不可直接枚举，标准做法是再训练一个策略网络逼近最大动作，流程与稳定性都更复杂。SAC 从另一条路解决同一问题：把策略的随机性纳入优化目标，最大化回报与熵的加权和，策略网络直接输出动作分布，价值网络评估软 Q 值。

收益有两层：熵增项让策略在回报相近的动作间保持分散，探索持续存在；离策略结构支持回放复用，样本效率高于同策略方法。SAC 因此成为连续控制的常见默认选择，前提是奖励尺度与温度机制对齐。上一章数据用完即弃，本章重新引入回放并改造目标函数。

核心原理

SAC 的四块拼图：最大熵目标、软 Q 更新、重参数化采样与温度调节。

1. 最大熵目标

标准目标是最大化期望回报；SAC 在每个时间步的回报上追加熵奖励，得到熵增强回报：

J(π) = Σt E[ rt + α · H(π(·|st)) ] H 为策略熵，α 为温度系数，控制"每单位回报换取多少随机性"；α 越大策略越分散，α 越小越接近确定性策略

熵项把探索提升为优化对象的一部分：策略在多个高回报动作间保持概率质量，面对噪声与估计误差更稳健。温度系数是熵与回报的兑换率，取值与奖励尺度耦合，这是 SAC 对奖励量纲敏感的根本原因。

2. 软 Q 更新与双 Q

软贝尔曼方程在目标中吸收熵项：下一状态的价值由下一个动作的 Q 值减去该动作的对数概率乘温度构成。SAC 同时维护两个 Q 网络，目标取两者最小值：

y = r + γ ( mini=1,2 Qi,target(s′, a′) − α · log π(a′|s′) ) 取最小值缓解 Q 值高估；a′ 由当前策略采样，不再对动作取最大，两条设计共同替代了离散场景的 max 操作

双 Q 与"采样代替最大化"的组合是连续场景爆掉高估问题的主要手段。目标网络的更新采用软更新：每次梯度步把目标参数向在线参数移动一个小比例，取代周期性整体复制。软更新的等效平滑窗口约为 1/τ 次更新，τ 取 0.005 时窗口约两百步，与 DQN 的硬同步周期是同类节奏参数。

3. 重参数化与有界压缩

策略网络输出高斯分布的均值与标准差，动作经重参数化采样：先采标准正态噪声再线性变换，梯度可穿过采样回传，方差低于得分函数估计。动作再经双曲正切压缩到有界区间，对数概率需加雅可比修正项：压缩改变概率密度，不做修正时熵估计错误，温度调节随之失准。修正后的对数概率同时出现在策略损失与软 Q 目标中，两处使用同一份数值。

4. 温度自动调节

固定温度需要按任务逐个调参；自动调节把温度当作对偶变量：当策略熵低于目标熵时增大温度（加强探索激励），高于目标熵时减小温度。目标熵通常取动作维度的相反数，例如六维动作对应目标熵负六。自动调节让温度在训练过程中自适应：早期策略分散、温度下降，后期策略收敛、温度回升以维持目标熵。温度曲线本身是诊断指标：长期贴近零说明目标熵过小，长期高企说明回报信号不足。

5. 软目标与温度项的数值示例

取 r = 1、γ = 0.99、Q₁ = 2.0、Q₂ = 1.8、α = 0.2。下一动作的对数概率为 −0.7 时：软价值 = min(2.0, 1.8) − 0.2×(−0.7) = 1.8 + 0.14 = 1.94，目标 y = 1 + 0.99×1.94 ≈ 2.92。若策略更分散、下一动作对数概率降到 −2.0：软价值升到 1.8 + 0.4 = 2.2，目标升到约 3.18。同一奖励与 Q 值下，策略越随机软目标越高，训练持续奖励在相似回报下保留随机性的行为。

y = r + γ ( min(Q₁, Q₂) − α · log π(a′|s′) ) 对数概率为负值，熵惩罚项 −α·logπ 为正；α = 0.2、logπ = −0.7 时惩罚贡献 0.14，策略分散程度直接影响目标水平

DDPG外部动作噪声无专门机制软更新支持对超参敏感，易发散

9. 数值算例：熵水平、双 Q 偏差与回放周转

对角高斯的每维熵为 H = ln σ + 0.5 ln(2πe) ≈ ln σ + 1.419。σ = 1 时每维熵约 1.42，σ = 0.5 时约 0.73，σ = 0.1 时约 −0.88；目标熵按"维度相反数"取每维 −1 时，自动调节会把标准差推向 σ ≈ 0.089 的水平。这组数字说明两件事：目标熵是启发式基线，取值按经验设定，高维动作空间里它偏保守，需要按探索需求上调；温度机制直接控制分布宽度，σ 从 1 收缩到 0.1 意味着动作抖动幅度下降一个数量级。

标准差 σ每维熵 H行为含义
1.0约 1.42宽分布，强探索
0.5约 0.73中等分散
0.1约 −0.88接近确定性
0.089约 −1.00目标熵对应的宽度

双 Q 的偏差可以估算：设两条网络的估计误差近似独立、标准差为 σq，取最小值的期望偏差约为 −0.564 σq（两个标准正态取最大值的期望是 1 ÷ √π ≈ 0.564）。单网络取最大时的正向高估同量为 0.564 σq，双 Q 把高估换成轻微低估，σq = 1 时偏差约 0.56 个价值单位。方向选择有讲究：高估沿自举链放大并诱发过度乐观的策略，低估只让策略偏保守，后者安全。

回放周转同样可算：容量 10 万、每轮写入 256 条时，池的整体换血需要约 391 轮。目标网络等效平滑窗口（τ = 0.005 时约 200 次更新）短于周转周期，学习信号里始终夹着旧策略数据的痕迹；容量缩到 1 万时周转缩短到 39 轮，数据新鲜度提高而样本效率下滑。容量选择是在新鲜度与复用深度之间取舍，判据是池内数据年龄分布与价值损失的波动。

10. 边界与失效模式

压缩函数的饱和边界：预压缩值 |x| 超过 3 后，修正项 log(1 − tanh2x) 的绝对值升到 −6 以下并快速走低，梯度接近消失，落在边界附近的动作难以被有效修正。表现是策略把部分动作长期顶在边界上；修复动作是核对动作范围与任务需求的匹配，必要时放宽动作界声明。

熵目标的坏情形要会识别：目标熵过高时策略长期保持高随机性，回报停滞而熵曲线贴着目标；过低时早期就收缩到确定性，探索不足导致次优收敛。稀疏奖励任务适合下调目标熵，密集奖励任务可保持默认。温度自动调节是慢回路，奖励尺度突变后要给足调节时间，或直接重设初值。

并行度也有边界：离策略算法不依赖大批量新鲜数据，采样器从二到四个继续增加，边际收益迅速衰减；回放池的读写是单点服务时，过多采样器还会在池的写入队列上排队。规模验证的办法是扫描采样器数并观察单位墙钟时间的更新数据比，比值不再上升即为该加别的资源。

实现思路与设计

配置顺序：核对奖励尺度与动作范围，设置回放与批次，再校准温度机制与软更新节奏。

train_batch_size256每步更新批次离策略小批次高频更新
设计决策：为什么 SAC 对奖励尺度格外敏感？

温度系数是熵与回报的兑换率：奖励整体放大十倍时，同样的温度下熵的相对吸引力下降，策略迅速确定化，探索激励形同消失。自动调节能部分吸收尺度差异，目标熵与初始温度仍需与量纲匹配。奖励函数修改后，温度参数重新校准，两者写入同一份实验记录。

温度初值与奖励量纲同比例缩放：奖励整体放大十倍时，初始温度从 0.2 量级抬到 2.0 量级，熵与回报的兑换率才保持不变；自动调节能吸收部分差异，初值偏离过大时调节过程需要更长时间，早期策略可能已经确定化。目标熵的手工设定用于两类场景：高维动作空间按维度取相反数往往偏保守，可适度上调；稀疏奖励任务中回报信号弱，可下调目标熵避免策略长期松散。双 Q 的两条网络应使用不同的初始化，共模初始化会削弱取最小值对高估的抑制作用。梯度裁剪阈值与学习率配套检查，SAC 的更新同时涉及策略、双 Q 与温度多个目标，梯度尺度失衡时优先怀疑学习率。回放池容量与观测体积的关系：状态 8 维、单转移约 70 字节时，10 万容量仅占约 7 MB，容量可取大；图像观测按单帧字节数重算后再定容量。评估阶段关闭动作随机化，取分布均值或低温采样，保持与部署行为一致；评估回报与训练回报的差值进入监控，差值扩大时先排查探索强度与过拟合。双 Q 与自动温度同时开启时，价值估计的收敛速度通常慢于单 Q 配置，学习率的校准要以最终组合为准。回放池采用单写入多读取结构时，索引由写入端更新、读取端只取完整转移，采样进程的数量不改变写入顺序。

与上一章差异：第 036 章的策略批次来自并行采样、用完即弃；本章把回放池带回训练循环，且目标函数多了熵项、价值侧多了一个网络与软更新。数据组织回到离策略模式，稳定性机制则从"批次新鲜度"转移到"目标平滑与双 Q"。下一章讨论 PPO：用裁剪目标限制更新幅度，是目前使用最广的同策略方法。

片段 2：软更新与双 Q 目标

import numpy as np


def soft_update(online_params, target_params, tau=0.005):
    """目标参数向在线参数移动：目标参数 = tau 乘在线参数 + (1 − tau) 乘目标参数。"""
    for name in online_params:
        target_params[name] = (
            tau * online_params[name] + (1.0 - tau) * target_params[name])
    return target_params


def sac_target(rewards, q1_next, q2_next, log_prob_next, dones,
               alpha=0.2, gamma=0.99):
    """软贝尔曼目标：双 Q 取最小，减去温度的熵惩罚项。"""
    entropy_term = alpha * log_prob_next           # 下一动作的熵贡献
    soft_value = np.minimum(q1_next, q2_next) - entropy_term
    soft_value = np.where(dones, 0.0, soft_value)  # 终止样本屏蔽自举
    return rewards + gamma * soft_value

解读：软更新把"复制参数"变成"参数插值"，实现是逐参数的加权平均，等效于在线参数的指数移动平均。目标中的熵项是 SAC 与 DQN 目标的结构性差别：价值评估的对象变成"回报减熵成本"的软价值；终止掩码在熵项计算之后应用，吸收态不引入任何后续项。双 Q 取最小值的对象是两条独立网络的前向结果，两条网络的初始化与训练数据相同但梯度路径独立，减小估计的共模误差。

片段 3：有界压缩与对数概率修正

def squashed_log_prob(mean, log_std, noise):
    """重参数化加 tanh 压缩，返回动作与其修正后的对数概率。"""
    std = np.exp(np.clip(log_std, -20, 2))          # 标准差截断，防数值发散
    pre_tanh = mean + std * noise                    # 重参数化：噪声独立采样
    action = np.tanh(pre_tanh)                       # 压缩到 [-1, 1]
    # 高斯对数概率按每个维度计算（对角协方差）
    gaussian_logp = -0.5 * (
        ((pre_tanh - mean) / std) ** 2 + 2 * log_std + np.log(2 * np.pi))
    # 雅可比修正：log(1 - tanh(x)^2)，防止熵估计被压缩扭曲
    correction = np.log(1 - action ** 2 + 1e-6)
    return action, gaussian_logp - correction.sum(axis=-1)


# 策略损失 = (alpha * log_prob - Q(s, a)).mean()：
# 提高 Q 的同时奖励高熵动作，两项的相对权重由 alpha 给出

解读：重参数化的价值在于梯度路径贯穿采样：噪声是外生输入，梯度可以穿过均值与标准差回传。tanh 压缩改变密度，雅可比修正项把概率换算回动作空间的密度；修正遗漏时 log_prob 的尺度错误，策略损失与温度调节同时失准，症状是熵曲线与回报曲线同时异常。标准差截断是数值稳定手段，防止早期网络输出过大导致高斯尾部采样溢出。

常见坑

  • 奖励尺度与温度不匹配：奖励放大后熵吸引力下降，策略迅速确定化。症状是熵跌落而回报不涨。修复：随奖励量纲校准初始温度与目标熵。
  • 回放容量或批次过小：离策略复用不足，训练退化为近似同策略。症状是样本效率优势消失。修复：放大容量与批次，或提高采样环境数。
  • 对数概率修正遗漏：压缩后未加雅可比项。症状是熵曲线异常、温度震荡。修复：在策略损失与软 Q 目标两处使用同一修正实现。
  • 评估使用随机动作：评估未取分布均值，评估回报被随机性压低。症状是评估曲线明显低于部署表现。修复：评估模式取动作分布均值，与部署行为对齐。
  • 软更新系数过小或过大：τ 过小目标几乎不动、学习滞后；过大目标跟随过快、稳定性下降。症状是价值损失长期高位或高频震荡。修复：从 0.005 量级起步，按价值曲线的平滑程度微调。

练习与思考

  1. 奖励整体放大五倍后，预测熵曲线与温度曲线的变化方向，给出两种补偿手段。★
    提示
    熵的吸引力相对下降，熵曲线下移；补偿手段是放大初始温度或提高目标熵，两者都恢复熵与回报的兑换率。
  2. 把 tau 从 0.005 改到 0.05，预测目标网络平滑窗口与训练稳定性的变化。★
    提示
    等效窗口从约两百次更新缩短到约二十次，目标跟随更快、稳定性下降，价值损失震荡概率上升。
  3. 推导：说明 tanh 压缩的雅可比修正项来源，以及遗漏它时熵估计的偏差方向。★★
    提示
    密度变换需乘以压缩函数的导数绝对值，取对数即 log(1−tanh(x)²)；遗漏时边界附近动作的概率密度被高估，熵与温度调节失准。
  4. 设计消融实验：twin_q 开关与固定温度、自动温度两组对照，说明观察指标与判定标准。★★
    提示
    观察 Q 值的高估幅度（与回报核对）、熵曲线与评估回报；双 Q 关闭且奖励尺度大时高估明显，自动温度在任务切换时更省调参。
  5. 设计诊断流程：价值损失高企时，按目标网络节奏、回放新鲜度、熵项三方向排查并给出判据。★★★
    提示
    先核对 tau 与更新频率的匹配、再看池内数据年龄分布、最后检查熵项尺度是否压过回报；三个方向分别对应目标滞后、分布偏移与目标函数失衡。

小结

  • 最大熵目标把熵奖励并入回报，温度系数 α 是熵与回报的兑换率。
  • 软贝尔曼目标用双 Q 最小值与下一动作熵惩罚替代离散场景的 max 操作。
  • 重参数化采样让梯度穿过随机采样；tanh 压缩需雅可比修正，修正贯穿两处损失。
  • 温度自动调节按目标熵自适应，目标熵默认取动作维度相反数。
  • 离策略回放复用样本，并行采样器只需少量；奖励量纲变化时必须重新校准温度。
