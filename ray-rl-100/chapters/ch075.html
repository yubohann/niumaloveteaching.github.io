第四篇 · Ray Tune 超参搜索

第 075 章：阶段实践：一次完整的超参搜索

把搜索空间、调度器、资源、种子、分析、归档六组部件串成一次端到端搜索：预热验证链路、粗搜定位区域、精搜确认峰形、复验核验差异、归档固化口径。每个阶段有明确的进入条件与退出判据。

  • 主题：Ray Tune 调优 / 全流程实践
  • 关键机制：阶段门控、预算分配、边界判读、复验判决、口径固化
  • 预计学时：60 分钟
  • 前置章节：第 074 章

学习目标

  • 会为一次完整搜索划分阶段并分配预算：预热、粗搜、精搜、复验、归档五段的试验数与资源。
  • 会为每个阶段定义可执行的退出判据，把“感觉可以了”替换为数值门限。
  • 会从粗搜结果做边界判读，据此决定精搜空间的中心与半径。
  • 会把种子策略、检查点配置、日志配置固定为全程不变量，识别阶段间的口径漂移。
  • 会产出交付组合：结果表、复验表、报告与归档清单，并通过一致性校验。

背景与动机

前十四章各自解决了搜索流程的一个环节，组合使用时新的问题出现在阶段衔接处：粗搜的结论以什么标准判定“可以进入精搜”；精搜的范围从哪里来；复验用哪些种子；哪些配置参数在阶段之间必须保持不变。阶段实践的目标是把这些衔接问题固化为可复制的流程，使搜索从“一次性事件”变成可重复执行的工序。

本章用一个具体场景贯穿：在连续控制任务上为 PPO 做一次学习率与批量的搜索，粗搜 48 个试验、精搜 20 个试验、复验 3 个配置各 5 个种子。所有机制都来自前文各章，本章不引入新部件，重点在阶段门控与口径纪律。

核心原理

1. 五阶段结构与预算分配

一次完整搜索分为五段：预热段（2 至 3 个试验，验证链路与资源声明）；粗搜段（40 至 60 个试验，宽范围、中等预算、ASHA 早停）；精搜段（20 至 30 个试验，窄范围、高预算、复用粗搜结论）；复验段（top-3 各 3 至 5 个种子，配对比较）；归档段（导出、报告、清单校验）。

总试验量 ≈ 3 + 48 + 20 + 15 = 86 个试验单元（复验按种子计入） 粗搜占总量的约 56%，是最贵的一块；精搜与复验合计约 41%，预热约占 3%

预算分配的比例不是固定值，它随任务性质移动：搜索空间维数高、主效应未知时，粗搜占比上升；已有历史结论可复用时，精搜与复验占比上升。无论比例如何移动，两条纪律不变：预热必做，复验必做。

2. 阶段门控

每段的退出判据必须是可执行的数值门限：

  • 预热门控：一个试验完整跑通，指标非空、检查点可生成、恢复路径可读、吞吐与预期同量级。
  • 粗搜门控：完成试验数达到计划的八成以上；top-K 配置在主效应参数上的分布给出明确信号（贴边、居中或分散）；若某参数持续贴边，精搜范围向外扩一档后再进下一段。
  • 精搜门控：top-1 与 top-3 的尾段均值差小于种子噪声的可分辨门限，或边际增益低于预期阈值；两者满足其一即认为峰形已确认。
  • 复验门控：入围配置两两配对的差值区间给出判决；区间跨 0 的组合列为“未分胜负”，不强行排序。

3. 粗搜到精搜的边界判读

精搜空间的两个参数都由粗搜结果决定：中心取 top-K 的中位值，半径按“覆盖中心上下各半个数量级”起步。取中位值是防选择偏差的细节：top-1 的点值带有单点噪声，中位数更接近高分区的位置。半径过大时精搜退化为重复粗搜，过小时最优值贴在新空间边界，贴边信号再次出现时执行一次外扩。精搜只加密粗搜显示敏感的参数，其余参数回落到粗搜最优区域的代表值。

4. 全程不变量与口径纪律

五段之间有四类参数必须保持不变，任何改动都构成口径漂移：评估口径（评估回合数、评估种子集、评估频率）；预算轴定义（迭代计数含义、换算到环境步数的规则）；种子派生规则（偏移常量与 worker 派生）；结果落盘结构（指标字段名、检查点命名）。需要改动的实验应另起实验名，并在报告中并列两套口径，禁止在同一实验名内悄悄更换。

5. 交付物与验收

搜索结束时交付四件套：结果表（全部试验的迭代记录与清单）、复验表（入围配置的均值、区间、判决）、报告（口径卡、摘要、证据链、复跑信息）、归档清单（校验和与验证结论）。验收标准是三条一致性检查：报告摘要数字与结果表重算值一致；复验表引用的试验在结果表中存在；归档清单校验通过。三条检查同时通过，搜索才算完成；任一条失败，按失败项回到对应阶段补数据。

实现思路与设计

全流程的执行按阶段推进，每段结束先跑门控再进入下一段。与前几章的差异在于，各章解决单点机制，本章解决机制之间的衔接与验收。

  1. 预热：2 至 3 个试验跑全链路，核对资源声明与实际占用。
  2. 粗搜：48 个试验、宽空间、ASHA 早停、单种子；并发按第 065 章的预算取 6。
  3. 判读：生成分位带与参数散点，执行边界判读，确定精搜中心与半径。
  4. 精搜：20 个试验、窄空间、提高预算上限；沿用同一批评估与种子规则。
  5. 复验：top-3 配置各配 5 个新种子，配对运行，输出区间与判决。
  6. 归档：导出四件套，执行三条一致性验收。
阶段试验数预算上限退出判据产物
预热2 至 3低（3 迭代）链路五项检查通过资源核对记录
粗搜48中（60 迭代）完成率八成、边界信号明确分位带、散点
精搜20高（90 迭代）峰形确认或边际增益收敛局部曲线
复验15（3×5）高配对区间判决完成复验表
归档不新增不适用三条一致性检查通过四件套
设计决策：为什么预热段不能省略？

预热段的价值与故障面成正比：分布式链路的路径、权限、版本、资源声明问题会在并发放大时同时爆发，排障成本随并发线性上升。预热用两三个试验把链路走通，等于把故障暴露成本压到最低点。省略预热的搜索常在启动后二十分钟内发现配置错误，此时已消耗的集群时间远超预热段的全部成本。

关键代码与解读

片段 1：粗搜配置与全程不变量

from ray import tune
from ray.tune.schedulers import ASHAScheduler

# 全程不变量：评估口径、种子规则、预算轴在五段之间保持一致
INVARIANTS = {"eval_episodes": 20, "eval_seeds": list(range(0, 20))}

search_space = {
    "lr": tune.loguniform(1e-5, 1e-2),
    "train_batch_size": tune.choice([2048, 4096, 8192]),
    # 整除约束在采样期联动：避免不可行组合消耗预算
    "sgd_minibatch_size": tune.sample_from(
        lambda s: s["train_batch_size"] // 4),
    "entropy_coeff": tune.loguniform(1e-4, 1e-2),
    # 搜索阶段固定单种子：宽度优先，复验阶段再引入新种子
    "seed": 1234,
    # 评估口径随配置进入训练函数，确保所有试验同口径
    "eval_seeds": INVARIANTS["eval_seeds"],
}

asha = ASHAScheduler(
    time_attr="training_iteration",
    metric="episode_return_mean",
    mode="max",
    max_t=60,
    reduction_factor=3,
    grace_period=5,
)

tune.run(
    train_fn,
    config=search_space,
    num_samples=48,
    scheduler=asha,
    max_concurrent_trials=6,       # 第 065 章的并发预算结果
    name="ppo_lr_batch_stage1",
    storage_path="/shared/tune_results",
)

解读：粗搜段配置集中体现三条纪律。（1）不变量单独成字典并注入配置，评估种子集在全部试验间共享，防止评估噪声进入配置差异。（2）整除联动与第 061 章一致，熵系数等次要参数只给一个宽范围而不加密，把粗搜预算集中在学习率与批量两个主效应候选上。（3）种子固定为单值：搜索阶段宽度优先，这条设定直接对应第 074 章的三层种子策略。粗搜的试验数与并发由容器上限与集群容量共同确定，取 48 与 6 是本场景的平衡点。

片段 2：粗搜门控与边界判读

def coarse_gate(df, params, metric, top_k=8, edge_frac=0.15):
    """粗搜退出判据：完成率检查 + top-K 边界聚集检测。"""
    done = df["trial_id"].nunique()
    if done < 0.8 * 48:
        return {"status": "blocked", "reason": f"完成 {done}/48，不足八成"}
    final = df.sort_values("epoch").groupby("trial_id").last()
    top = final.nlargest(top_k, metric)
    report = {"status": "ok", "params": {}}
    for p in params:
        if final[p].dtype == object:
            continue                       # 分类参数按分组均值判读，另出图
        lo, hi = float(final[p].min()), float(final[p].max())
        span = max(hi - lo, 1e-12)
        # 贴边比例：top-K 落在全域两端 15% 区间的比例
        edge = max((top[p] <= lo + edge_frac * span).mean(),
                   (top[p] >= hi - edge_frac * span).mean())
        report["params"][p] = round(float(edge), 2)
        if edge >= 0.5:
            # 贴边超过一半：下一段向外扩一档，并把中心改为中位值
            report["status"] = "expand"
    return report

gate = coarse_gate(final_df, ["lr", "train_batch_size"],
                   "episode_return_mean")
print(gate)

解读：门控函数把“感觉”替换成两个可计算的量。（1）完成率检查排在第一位：样本不足时任何边界判读都不可靠，函数直接输出阻塞状态。（2）贴边比例用 top-K 落在全域两端 15% 区间的占比度量，超过一半判定“外扩”；函数不直接给出“上扩还是下扩”的动作，方向由端点侧决定，实现时可返回贴边的具体一侧。（3）分类参数跳过数值判读，由分组均值视图另行处理；这保持了函数对参数类型的显式分支，避免对分类列做无意义的数值比较。

片段 3：复验汇总表

import numpy as np
import pandas as pd

def verify_table(rev_df, metric="episode_return_mean", tail=10):
    """复验汇总：每配置的均值、经验区间与种子数。"""
    rows = []
    for key, g in rev_df.sort_values("epoch").groupby("config_key"):
        per_seed = (g.groupby("seed").tail(tail)
                      .groupby("seed")[metric].mean())
        # 分位区间代替正态区间：样本 5 时对分布形状不做假设
        rows.append({
            "config": key,
            "n_seeds": len(per_seed),
            "mean": float(per_seed.mean()),
            "p10": float(np.percentile(per_seed, 10)),
            "p90": float(np.percentile(per_seed, 90)),
        })
    table = pd.DataFrame(rows).sort_values("mean", ascending=False)
    print(table.to_string(index=False))
    return table

table = verify_table(verify_df)
# 判决门限：两配置均值差超过区间半宽之和的一半才列为分出胜负

解读：复验表是最终交付的核心证据。（1）每个配置先按种子聚合尾段均值，再算跨种子的均值与 10/90 分位区间；5 个种子的区间较宽，按第 071 章的原则如实呈现，不缩窄措辞。（2）表格按均值排序但拒绝“只看第一名”：判决同时参考区间重叠程度，重叠严重的相邻名次列为未分胜负。（3）种子数列入表内，读者可核对复验操作的完整性；缺少种子的条目按缺失处理并在备注中说明原因，不静默丢弃。本章示例中的配置字段与调度接口以对应版本的官方文档为准。

常见坑

  • 跳过预热直接开粗搜：链路问题在 48 个试验并发时集中爆发，排查期间集群空转。修复：预热段固定为流程第一步，两三个试验的成本可以忽略。
  • 粗搜结果直接当结论：单种子、中等预算的结果带有选择偏差，复验时常无法重现。修复：粗搜只承担“定位区域”，结论由精搜加复验产出。
  • 精搜半径凭感觉：半径过大退化为重复粗搜，过小造成最优贴边。修复：中心取 top-K 中位值，半径按半个数量级起步，用贴边信号迭代调整。
  • 阶段间口径漂移：精搜改了评估频率或预算轴定义，两段结果无法合并。修复：四类不变量写进配置并在门控中校验，改动含义等同于新实验。
  • 归档缺验收：报告数字与数据表不一致、清单未校验，交付物在传播中失真。修复：三条一致性检查作为流程的最后一步，自动化执行。

练习与思考

  1. 为一次 100 试验单元的预算设计阶段分配，给出各段试验数与理由，并说明哪一段可以压缩、哪一段不能。★
    提示
    参考 3＋50＋25＋20（复验）的形态；粗搜与复验不可压缩，预热虽小但不可省；精搜规模可按粗搜边界信号的强弱伸缩。
  2. 预测题：粗搜试验数从 48 减到 24，边界判读的可靠性、精搜半径的选择与总完成时间各会如何变化？★★
    提示
    top-K 样本减半，贴边比例估计的抖动增大，容易误判“外扩”；半径选错的风险上升；完成时间缩短但错误决策的代价可能更大，属于用确定性换时间。
  3. 设计题：为粗搜门控补充“分类参数”判读：给出分组均值的读法、组间样本量要求与一个判决规则，并说明它与数值参数贴边判读的差异。★★★
    提示
    分组均值需附加组内样本数；组间样本量差异大时均值比较不可靠，可要求每组至少占 top-K 的一定比例；与贴边判读的差异在于比较发生在组间，贴边判读则看全域端点。
  4. 推导题：为“峰形确认”门控设计一个可计算判据：用 top-1 与 top-3 的尾段均值差与复验噪声水平比较，推导判据的统计含义与误判方向。★★★
    提示
    判据形如 |Δ| 小于噪声标准误的某个倍数时认为未分出胜负；误判方向两侧不对称：门限过松会把噪声当增益进入复验，过紧会漏掉真实小增益，按“复验能补测”的原则可略偏松。
  5. 实践题：为一个已有任务写出完整五段执行清单：每段的输入、动作、门控与产物，并把四类不变量列在清单最前。★★
    提示
    清单可以直接转化为流程检查表；不变量先行防止中途改口径，门控列写数值门限，不用描述性词句。

小结

  • 完整搜索分五段：预热、粗搜、精搜、复验、归档；预热与复验不可省略。
  • 阶段门控全部使用数值门限：完成率、贴边比例、均值差与噪声比较、区间判决。
  • 精搜中心取 top-K 中位值，半径从半个数量级起步，按贴边信号迭代。
  • 四类不变量贯穿全程：评估口径、预算轴定义、种子规则、落盘结构；改动视为新实验。
  • 交付四件套通过三条一致性验收，搜索才算完成。
  • 第五篇进入单参数族实战：从学习率与批量开始，逐类给出搜索范围设计逻辑与判读方法。
