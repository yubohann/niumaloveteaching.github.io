第 097 章：训练平台化：结果对比与报告生成

一句话：本章给出结果对比的统计口径与报告生成管线：公平比较协议、多种子聚合、曲线对齐与平滑、以及可复现的报告数据流。

  • 主题：平台化 / 结果对比（Result Comparison）与报告生成
  • 关键机制：等预算协议、IQM 与自助置信区间、曲线重采样、报告数据流
  • 预计学时：65 分钟
  • 前置章节：第 096 章

学习目标

  • 掌握公平比较协议的要素：预算口径、回报口径、种子数量与比较时点，理解协议不统一时结论如何失效。
  • 会计算与解释多种子聚合统计量：均值与标准差、中位数、四分位均值（Interquartile Mean, IQM）与自助置信区间（Bootstrap Confidence Interval）。
  • 会做曲线对齐与重采样：统一横轴、插值到公共网格、平滑窗口的选择与代价。
  • 理解曲线下面积（Area Under Curve, AUC）作为学习速度指标的用法与适用边界。
  • 会搭建从检索、聚合到报告组装的生成管线，并保证报告可复现。

背景与动机

第 096 章把实验数据组织成可检索的数据集，本章回答下一个问题：两组配置的试验数据放在一起，凭什么说 A 优于 B。强化学习实验的噪声结构让"看曲线"这一直觉动作经常给出错误答案：单次运行的曲线形状由种子、环境随机性与评估抽样共同决定，两条曲线的高低差可能完全落在噪声范围内。比较方法的价值在于把"差异是否可信"从主观判断变成可复核的统计流程。

报告生成则是比较结论的固化与传播：把检索出的数据、聚合统计与图形按固定模板组装成文档，并携带数据版本戳使任何人可以按同一输入重建同一报告。报告一旦脱离数据版本，就在传播过程中变成了不可追溯的断言。本章的管线设计把"输入确定、变换确定、输出确定"三个条件全部落实。

核心原理

对比方法的核心是控制变量与量化不确定性：协议固定输入域，聚合统计给出差异的量级，置信区间给出差异的可信程度。本节按协议、聚合、曲线与报告依次展开。

1. 公平比较协议

协议的四个要素必须在比较开始前写定：预算口径，按环境步数还是墙钟时间对齐。按步数对齐回答"同样的数据量下谁学得更好"，按时间对齐回答"同样的等待下谁更好"；两者结论可以不同，报告必须写明所用口径。回报口径，训练回报与确定性评估回报分列，混用会让曲线剧烈跳动。种子数量，每个配置至少 3 个独立种子，5 个以上时聚合统计才具有区分度；种子集在两个配置间保持一致，减少配对差异。比较时点，在预算末端比较，或按"达到阈值所需步数"比较，二者回答不同问题，同样需要预先声明。

2. 多种子聚合统计

均值与标准差是最常用也最脆弱的统计量：少数失败种子会把均值拉低，双峰分布下均值不落在任何真实行为附近。稳健的做法是多统计量并列：

IQM = 去掉最小与最大各 25% 种子后的均值；CI = 对种子集自助重采样 B 次统计量的分位数区间 IQM 抑制离群种子；自助置信区间只依赖观测样本，无需分布假设

自助置信区间的构造：从 n 个种子回报中有放回抽取 n 个组成新样本，计算其统计量（均值或 IQM），重复 1000 次以上得到统计量的经验分布，取 2.5% 与 97.5% 分位数作为 95% 区间。区间重叠不代表无差异，区间分离代表差异稳健；在 n 很小（3 至 5）时区间宽度大，结论应写成"未观察到稳定差异"。报告建议同时给出每个种子的原始曲线（细线）与聚合曲线（粗线加区间带），让读者同时看到个体与总体。

3. 曲线对齐与平滑

比较曲线前需要统一横轴：不同运行按步数记录时步点不重合，按时间记录时更不均匀。标准流程是重采样到公共网格（如在 0 到预算之间取 100 个等距点），每点用前值填充或线性插值；插值只在前向范围内定义，超出记录范围的网格点应留空，外推会在曲线末端制造虚假趋势。

平滑用于压制采样噪声，常用滑动窗口均值或指数滑动平均。平滑的代价是遮掩不稳定：震荡剧烈的运行被平滑后与稳定运行的曲线形状趋同。约定做法是平滑仅用于主图，同时报告未平滑曲线的局部方差指标（如窗口内标准差的中位数），把"稳定性"作为独立维度呈现。窗口长度按评估间隔的整数倍选取，在报告中列出，保证图形可解释。

4. 学习速度指标：曲线下面积

曲线下面积把整条学习曲线压成一个标量，适合比较"学习速度"：面积越大说明在预算内越早达到高回报。使用边界有三条：其一，面积对未能学会的运行很敏感，若比较对象中有接近零回报的运行，面积会进一步放大差异，应配原始曲线核对；其二，横轴按步数与按时间算出的面积含义不同，不可交叉比较；其三，面积与末端回报回答不同问题，报告建议并列。归一化处理（按最大可能面积缩放）可让不同任务间的面积具有相对含义，归一化方式需写明。

5. 报告生成管线

管线分四段：检索，按第 096 章的查询接口取回目标试验集合及其指标序列；聚合，按比较协议将原始序列折叠为每配置的统计对象（种子数、各统计量、置信区间、曲线网格）；渲染，把统计对象转换为表格与图形规格（坐标轴、平滑窗口、图例、色序固定）；组装，按模板把表格、图形与文字说明写为文档，同时记录数据版本戳（索引构建时间、试验标识列表）与参数记录（协议四要素）。管线的每次运行由输入与参数完全决定输出，同一输入重跑得到字节级一致的报告。

6. 常见误用与防线

报告级别的误用集中在三处：挑种子（只展示最优种子），防线是聚合必须覆盖全部通过校验的种子并在页脚列明种子清单；不等预算对比，防线是查询时强制携带预算字段并校验一致；口径漂移，同一张图里混入不同评估口径或不同环境版本的数据，防线是检索条件中固化口径字段并在图注中显示。

实现思路与设计

对比报告系统的实现分六步，产物是一个聚合库与一套报告模板。

  1. 冻结协议：预算口径、回报口径、种子要求与比较时点写成常量，随报告存档。
  2. 实现聚合库：多种子统计、置信区间、重采样与平滑，全部为纯函数。
  3. 定义图形规格：坐标轴、色序、平滑窗口、区间带样式，固定为模板常量。
  4. 实现数据戳：报告页脚记录索引时间、试验标识清单与协议常量。
  5. 组装模板：表格加图形加结论区，结论区只引用聚合统计，不引入手工数字。
  6. 回归测试：固定输入跑管线，比对输出摘要，防止渲染层无意变更。

报告字段对照表

与上一章的差异

第 096 章保证"数据找得到、取得对"，本章保证"比较做得对、报告可重放"。前者是存储与检索问题，后者是统计与呈现问题；数据版本戳是两章之间的接口，它把报告的每个数字绑回到可复查的数据来源。

关键代码与解读

以下片段基于 Ray 2.x 时期的通用写法，接口随版本演进，以对应版本的官方文档为准。

片段 1：IQM 与自助置信区间

import numpy as np

def iqm(values):
    """四分位均值：去掉最大与最小各 25% 后的均值。
    抑制离群种子：少数失败运行不会把整体结论拖偏。"""
    xs = np.sort(np.asarray(values, dtype=np.float64))
    n = len(xs)
    lo, hi = int(n * 0.25), n - int(n * 0.25)
    if hi <= lo:                     # 种子太少时退化为中位数
        return float(np.median(xs))
    return float(xs[lo:hi].mean())

def bootstrap_ci(values, stat=iqm, samples=2000, alpha=0.05, seed=0):
    """自助置信区间：有放回重采样，统计量的经验分位数区间。
    不依赖分布假设；区间宽度随种子数减少而增大。"""
    rng = np.random.default_rng(seed)         # 固定种子使区间可复现
    xs = np.asarray(values, dtype=np.float64)
    stats = [stat(rng.choice(xs, size=len(xs), replace=True))
             for _ in range(samples)]
    lo = float(np.quantile(stats, alpha / 2))
    hi = float(np.quantile(stats, 1 - alpha / 2))
    return lo, hi

解读：两个统计量都体现了"抗离群、可复现"的取向。（1）IQM 在种子数不足时退化为中位数：n 小于 4 时四分位截断无意义，退化分支保证函数在边缘输入下仍然有定义。（2）自助重采样不假设正态分布，对偏态与双峰的种子分布同样适用；重采样器固定种子，区间数值在重复运行间一致。（3）区间宽度是种子数的函数：报告中同时给出 n，读者才能判断"未观察到差异"来自真实接近还是样本太少。

片段 2：曲线重采样与平滑

def resample_curve(steps, values, grid):
    """把不规则采样点重采样到公共网格：只在记录范围内插值。
    超出记录范围的网格点置 NaN：外推会在末端制造虚假趋势。"""
    xs = np.asarray(steps, dtype=np.float64)
    ys = np.asarray(values, dtype=np.float64)
    out = np.interp(grid, xs, ys, left=np.nan, right=np.nan)
    return out

def moving_average(values, window=5):
    """滑动窗口均值：窗口取评估间隔的整数倍，平滑参数随报告记录。
    平滑遮掩震荡：稳定性指标用未平滑数据单独计算。"""
    xs = np.asarray(values, dtype=np.float64)
    kernel = np.ones(window) / window
    # 边缘用同长度窗口对齐，首尾点不做零填充以免压低曲线
    valid = np.convolve(np.nan_to_num(xs), kernel, mode="valid")
    pad = window // 2
    return np.concatenate([xs[:pad], valid, xs[-pad:]])

def instability(values, window=5):
    """局部波动指标：窗口内标准差的中位数，作为稳定性附注。
    与平滑曲线并列呈现：主图看趋势，该指标看幅度。"""
    xs = np.asarray(values, dtype=np.float64)
    stds = [xs[i:i + window].std() for i in range(0, len(xs) - window + 1)]
    return float(np.median(stds)) if stds else 0.0

解读：三个函数对应曲线处理的三条约定。（1）重采样用"范围外置 NaN"避免外推；NaN 在图形层表现为空缺，比虚假延续诚实地多。（2）滑动平均的边缘处理保留原始首尾点，避免零填充人为压低曲线两端的表现。（3）稳定性指标基于未平滑数据：平滑只服务主图可读性，判断震荡要回到原始序列，两个视图分列呈现。

片段 3：报告组装与数据戳

import json
import hashlib

def build_report(records, protocol):
    """报告组装：输入为检索结果与协议常量，输出为结构化报告对象。
    每个数字都来自聚合结果，结论区不引入手工数字。"""
    table = []
    for name, group in records.items():
        finals = [r["final_return"] for r in group]          # 每种子末端回报
        lo, hi = bootstrap_ci(finals)
        table.append({
            "config": name,
            "n_seeds": len(group),
            "return_mean": float(np.mean(finals)),
            "iqm": iqm(finals),
            "ci95": [lo, hi],
            "auc_norm": normalized_auc(group),               # 归一化面积
        })
    # 数据戳：把报告绑回数据来源，任何人可按同一输入重放
    stamp = {
        "trial_ids": sorted(r["trial_id"] for g in records.values() for r in g),
        "protocol": protocol,                                # 协议四要素
        "digest": hashlib.sha256(
            json.dumps(table, sort_keys=True).encode()).hexdigest()[:16],
    }
    return {"table": table, "stamp": stamp}

# 页脚渲染 stamp：试验标识列表、协议常量与摘要标识随报告发布，
# 标识变化即说明输入或聚合逻辑发生了变更，需人工核对报告之间可比性

解读：组装函数把可复现性做成结构性质。（1）表格的每个字段直接来自聚合函数调用，没有任何手填数字；结论文字若生成，也应按表格字段拼装。（2）数据戳包含试验标识清单与协议常量：重放报告只需这两个输入加聚合库版本。（3）摘要标识覆盖聚合结果：任何输入数据或逻辑的变化都会改变该标识，报告之间的可比性由标识相等保证，避免了"同一文件名下数字悄悄变化"的传播风险。

常见坑

  • 单种子下结论：一条曲线的高低被当成配置优劣。修复：至少 3 个种子，报告列明种子清单；无置信区间的图表标注"单次运行"。
  • 不等预算对比：某一配置多跑了预算，末端回报自然更高。修复：检索条件含预算字段并强制一致，横轴截断到公共预算。
  • 平滑掩盖震荡：主图平滑后两类配置看似相同。修复：稳定性指标与原始曲线附注并列，平滑窗口写入图注。
  • 横轴口径混用：步数与时间混在一张图或一次排序中。修复：协议冻结横轴口径，检索与排序字段绑定该口径。
  • 报告不可重放：图中数字与数据集脱节，无法追溯来源。修复：数据戳与摘要标识随报告发布，重放脚本纳入回归测试。

练习与思考

  1. 计算题：五个种子的末端回报为 [420, 350, 480, 40, 460]。求均值、中位数与 IQM，并说明三者中哪个最适合代表"典型表现"及理由。★
    提示
    均值 350，中位数 420，IQM（截掉 40 与 480 后）≈ 410；IQM 抑制了失败种子又不忽略信息。
  2. 预测题：把比较横轴从步数改为墙钟时间、其余不变。预测两条原本接近的曲线可能的走向差异及原因。★
    提示
    吞吐低的配置按时间对齐会出现更陡的下降或更晚起升；差异来自采样效率与吞吐的权衡，非学习质量本身。
  3. 设计题：为"3 个配置 × 5 种子"的比较设计完整协议与报表：预算与回报口径、聚合统计、图形规范、稳定性呈现与数据戳字段。★★
    提示
    按步预算 10 万步、确定性评估回报；IQM 加自助区间；主图加区间带加细线；稳定性附注；戳含试验清单与协议。
  4. 分析题：讨论"置信区间重叠"与"差异不显著"的关系，并说明为什么在小种子数下更应使用保守表述。★★★
    提示
    区间重叠时差异缺乏证据但可能真实存在；小样本下区间宽，误判方向的风险高，保守表述避免过强结论。

小结

  • 比较协议四要素：预算口径、回报口径、种子数量与比较时点，必须先于实验冻结。
  • 聚合统计以 IQM 与自助置信区间为主：抗离群、无分布假设、区间宽度反映样本量。
  • 曲线重采样只在记录范围内插值；平滑主图与稳定性指标分列，避免震荡被掩盖。
  • 面积指标与末端回报并列，各自回答学习速度与最终水平的问题。
  • 报告由数据、聚合与模板完全决定；数据戳与摘要标识保证可重放。下一章处理复现性的更深层：种子、环境与版本的三层控制。
