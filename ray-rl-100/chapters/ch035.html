第 035 章：RLlib实现DQN算法

DQN（Deep Q-Network）用深度网络逼近动作价值函数，靠回放池与目标网络稳定训练。本章讲清时间差分目标的自举结构、回放与目标网络的稳定机制，以及 Double Q、Dueling 与 n-step 三个常用改进项。

  • 主题：RLlib 算法 / 值函数类
  • 关键机制：时间差分目标、回放池、目标网络、探索调度、双重估计
  • 预计学时：55 分钟
  • 前置章节：第 034 章

学习目标

  • 理解动作价值函数的自举更新结构，说明目标网络为何必要。
  • 掌握回放池与探索调度在训练稳定性和覆盖性上的分工。
  • 理解 Double Q、Dueling 与 n-step 各自修正的问题与代价。
  • 会配置 DQN 的关键参数并解释取值依据：回放容量、启动步数、目标同步周期。
  • 能诊断值函数类算法的常见异常：价值高估、目标震荡与探索停滞。

背景与动机

值函数类算法把"该做什么"转化为"每个动作价值多少"：网络学习动作价值函数（Action-Value Function, Q 函数），策略从价值中导出。DQN 用两条机制解决两个根本问题：样本的时间相关性让逐轨迹训练近似于反复看同一段数据，回放池把样本打散；自举目标随参数移动，目标网络把目标暂时固定，给学习一个稳定参照。

DQN 属于离策略（Off-Policy）家族，样本可复用，数据效率高于同策略方法；代价是价值估计的正确性依赖探索覆盖与目标计算的细节。知道每个部件在稳定什么，才能知道训练发散时先检查哪里。上一章完成了输入模态的讨论，本章开始逐个剖析算法实现。

核心原理

DQN 的核心是一条自举更新式与两条稳定机制，改进项是在其上的偏差修正。

1. 时间差分目标与自举

动作价值满足贝尔曼最优方程：Q*(s, a) 等于即时奖励加上折扣后的下一状态最优价值。训练用采样近似该方程，构造时间差分目标（Temporal Difference Target）：

y = r + γ · maxa′ Qtarget(s′, a′) 目标中的下一状态价值来自目标网络；终止状态的下一状态价值置零，掩码由回合边界标志提供

直接用同一个网络同时构造目标与预测，等价于追一个随自己移动的靶子，误差可能持续震荡。目标网络的参数定期从在线网络复制，两次复制之间目标保持固定，自举过程获得短暂的稳定参照。同步周期是稳定性上的一对矛盾：周期太短稳定性不足，太长则目标陈旧、学习滞后。

2. 回放池与样本分布

回放池（Replay Buffer）保存历史转移，训练批次从池中均匀采样。均匀采样把数据分布从"最近轨迹的分布"拉向"历史访问过的状态分布"，削弱时间相关性；容量决定记忆长度，容量过小时早期数据被迅速覆盖，容量过大时陈旧数据长期参与训练、与当前策略偏离加剧。均匀采样对稀有但关键的状态（例如高风险边界）覆盖不足，优先采样（Prioritized Sampling）按误差大小为样本加权，属于第 052 章的主题。

3. 探索调度

价值型策略的探索常由 ε-贪心实现：以概率 ε 取随机动作，其余取当前最优动作。ε 从较大值（例如 1.0）随环境步数衰减到小值（例如 0.02 到 0.1），早期保证覆盖、后期保证利用。衰减节奏与回放池配合决定可复用的数据质量：衰减过快时池中高质量数据不足，衰减过慢时策略长期带噪，价值目标被随机动作的后果稀释。以环境步数为自变量，不用迭代数，才能与并行采样规模解耦。

4. 三个常用改进项

  • Double Q：最大化操作会让含噪的估计被系统性放大（高估偏差）。双重估计把动作选择交给在线网络、动作评估交给目标网络，切断选择与评估的同源噪声，缓解高估。
  • Dueling：把价值分解为状态价值与动作优势两个分支之和。多数状态下动作之间差异不大时，优势分支接近零，网络把容量集中到状态价值；对动作敏感的状态，优势分支承担区分任务。
  • n-step：目标从单步奖励扩展为 n 步回报加尾端自举，偏差减小、方差上升。n 取 3 到 5 是常见折中，需与回放池的回合边界处理配合。

5. 回放池内存的数值核算

回放池占用随容量与单转移字节数线性增长，不同观测类型的对比如下：

观测类型单转移字节数容量 5 万容量 100 万
低维状态 8 维 float32约 70 字节约 3.5 MB约 70 MB
84×84 灰度四帧 uint8约 28 KB约 1.4 GB约 28 GB
96×96 彩色四帧 uint8约 108 KB约 5.4 GB约 108 GB

读表可得规划原则：低维任务的回放池可以取百万级容量而不构成压力；图像任务在同样容量下内存需求上升三个数量级，必须与单样本体积联立核算。图像场景的容量决策顺序是先定观测分辨率与栈深，再反推可负担的容量；先定容量会压缩观测规格的选择空间。

6. 最大化高估的数值示例

设动作估计含独立噪声，噪声服从半宽为 a 的均匀分布 [−a, a]。对 n 个动作取最大时，期望高估量为 a(n−1)/(n+1)：n = 2、a = 0.5 时约 0.167；n = 4 时升到 0.3。动作数越多、噪声越大，高估越严重。双重估计把动作选择与价值评估分离，噪声不再同时作用于同一取值，高估幅度被显著削弱。

E[最大操作高估] = a · (n − 1) / (n + 1)，a 为噪声半宽，n 为动作数 n = 2、a = 0.5 时约 0.167；n = 4 时约 0.3；动作空间越大，未修正的高估越明显，价值曲线与真实回报的偏离越持久

7. 三个改进项的定量对照

改进项修正对象附加开销配置开关收益显现条件
Double Q最大化操作的高估偏差每批一次额外前向double_q=True动作数多或奖励尺度大的任务
Dueling状态价值的学习效率结构参数量中等增加dueling=True多数状态下动作间差异小的任务
n-step单步目标的偏差批次组装复杂度上升n_step=3 至 5奖励传播路径长的任务

选择依据：三项互不冲突，可以叠加；叠加前逐项消融，确认每项的净收益与开销。动作价值曲线的绝对水平与评估回报持续对不上时，优先核对 Double Q 是否生效。

8. 更新数据比与目标同步的核算

稳定性还取决于更新与数据的比例。数值示例：每轮采集 1024 个环境步，执行 4 次梯度更新、每次批次 256，合计消耗 1024 条回放样本，更新数据比为 1.0；把更新次数提到 8 次而环境数据不变，比值升到 2.0，同一批数据被反复训练，过拟合与价值震荡的风险上升。目标同步周期按梯度步计，与更新次数联动：每轮 4 次更新、周期 500 步时约每 125 轮同步一次；更新次数翻倍而未调整周期时，等效同步频率随之翻倍，稳定性基础改变。两处核算使用同一计数单位（梯度步），任何一项变更都要同步复核另一项。

9. 目标计算与稳定账户的数值演算

取一次具体的自举更新：某转移的当前估计 Q(s, a) = 2.0，即时奖励 r = 1.0，折扣 γ = 0.99，目标网络在下一状态上的最大输出为 3.0。时间差分目标 y = 1.0 + 0.99 × 3.0 = 3.97，平方误差 (2.0 − 3.97)² ≈ 3.88；对线性输出头的单样本梯度为 2 × (2.0 − 3.97) = −3.94，学习率 5e-4 对应一次更新把估计推向约 2.002。单次更新只移动目标差距的千分之一量级，价值曲线从初始估计爬到目标水平需要数千次更新，这就是启动步数、更新频率与目标同步周期要一起核算的原因。

yn = Σk=0n−1 γk rt+k + γn · max Qtarget(s′, ·) 奖励均为 1、末端自举 2 时：n = 1 的目标 2.98，n = 3 的目标 4.91，目标规模随 n 抬高约 65%；偏差被真实奖励逐步替换，方差同时上升

回放池的老化账可以用同一组数算清。容量 50000、每次更新消耗 1024 条样本时，池整体翻新需要约 49 次更新；按采样吞吐 4000 步每秒计，一次更新间隔约 0.256 秒，池中最旧数据的年龄约 12.5 秒。目标同步周期 500 梯度步约等于 10 个池翻新周期，目标每同步一次，池整体已换过约十轮。目标寿命偏长偏向稳定但陈旧，偏短偏向新鲜但抖动；起步配置让该比例落在 1 到 10 之间，用价值曲线的抖动幅度与评估回报共同校准。

账户算式代入示例用途
单步更新幅度2 × 学习率 ×（目标 − 估计）2 × 5e-4 × 1.97 ≈ 0.002估算收敛速度的下界
池翻新所需更新次数容量 / 每次更新样本数50000 / 1024 ≈ 49 次推算数据平均年龄
目标寿命的翻新数同步周期 / 池翻新周期（同以梯度步计）500 / 49 ≈ 10衡量目标的陈旧程度

读表可得调参的联动关系：更新次数翻倍（更新数据比从 1.0 升到 2.0）时池翻新周期减半，目标寿命的翻新数随之翻倍，稳定边界改变；放大回放容量而不动同步周期，目标相对数据变得更陈旧。三格账户来自同一条时间轴，任何一格改动都要在另外两格上复核，这是 DQN 调参区别于有监督训练的地方。高估修正也在同一时间轴上起作用：Double Q 降低目标中的乐观偏差，使 y 的期望更接近真实回报，收敛速度的下界随之改善，但每批要多一次前向，训练时间上浮一成量级。

实现思路与设计

配置顺序：先定回放与探索，再定目标同步节奏，最后叠加改进项做消融。

参数示例值作用取值依据
replay_buffer_capacity50000回放池容量按任务长度与内存预算取值，约为训练批次数十倍
learning_starts1000开始学习前的填充步数先积累去相关样本再更新，取池容量的百分之二量级
target_network_update_freq500目标同步周期以梯度步计，与更新数据比联立检查
ε 衰减1.0 到 0.05探索概率范围按环境步线性或指数衰减，尺度约十万步量级
train_batch_size1024每次更新批次离策略算法可小批次高频更新，与回放容量匹配
改进项开关double_q、dueling、n_step 3偏差修正逐项消融，确认每项的净收益
设计决策：为什么 DQN 需要回放池而 PPO 不需要？

PPO 是近似同策略方法：批次数据在使用前由当前策略采集，采样与更新的时距很短，近似的同分布假设基本成立。DQN 想要样本复用，就必须接受数据来自历史策略这一事实，回放池把跨时间的数据混合成一个近似平稳的分布，代价是引入内部状态（池内容）与新鲜度管理。选择算法家族的同时也在选择数据管理方式，两者的复杂度是绑定的。

回放池的均匀性需要审计：统计池内转移按回合编号与动作类别的分布，明显偏斜说明写入端不均衡或探索策略偏窄。n-step 回报不能跨越回合边界，组装时按边界标志切段并标记片段端点，片段内的自举与终止语义保持与目标网络一致。目标网络与在线网络的结构必须完全一致，软更新或硬同步只搬运参数，不改变结构；结构不一致会在目标前向时直接报形状错误。奖励量纲变化会同时改变价值尺度与梯度幅度，奖励归一化后学习率的搜索区间才可跨任务复用。回放写入与采样并行执行时，写入端受容量约束淘汰最旧转移，读取端只见到两类操作完成后的状态；学习启动步数之前的采样进程持续写入回放，填充速度由样本吞吐决定。收敛后期出现性能回退时，可短时提高探索概率重新加热，或在评估确认后退回最近的检查点。

与上一章差异：第 034 章的训练批次由策略自身采样后直接使用；本章引入回放池，训练批次来自历史数据与当前采样的混合，训练循环时序随之改变。下一章讨论 A3C 的并行采样结构。

片段 1：DQN 配置骨架

from ray.rllib.algorithms.dqn import DQNConfig

config = (
    DQNConfig()
    .environment(env=LineGoalEnv)
    .training(
        train_batch_size=1024,              # 每次梯度更新的批次
        lr=5e-4,
        n_step=3,                           # 三回报加自举：偏差与方差的折中
        double_q=True,                      # 缓解最大化操作的高估
        dueling=True,                       # 价值与优势分解，加速状态价值学习
        replay_buffer_capacity=50000,       # 回放容量：记忆长度与内存的平衡
        learning_starts=1000,               # 先填充样本，再开始更新参数
        target_network_update_freq=500,     # 目标同步周期（按梯度步计）
        epsilon=1.0,                        # 探索初值
    )
    .env_runners(num_env_runners=4, num_envs_per_env_runner=2)
)
algo = config.build_algo()
result = algo.train()

解读：配置项按"稳定机制"分组阅读：回放组（容量、启动步数）、目标组（同步周期、双重估计）、探索组（初值与衰减）、结构组（Dueling、n-step）。启动步数决定池中初始样本的多样性，取值过小时初期更新在高度相关的数据上重复，价值曲线陡起陡落。探索衰减配置在部分版本中以独立的调度项表达（例如 epsilon_timesteps），键名随版本演进，以对应版本文档为准。

片段 2：时间差分目标的计算

import numpy as np


def td_target(rewards, next_q_batch, dones, gamma=0.99, n_steps=3):
    """构造 n-step 时间差分目标，含终止掩码与双重估计。"""
    # next_q_batch 形状为（批次, 动作数），已由前向计算得到
    # 双重估计：动作选择用在线网络的排名（此处以传入的最大值示意），
    # 评估用目标网络取值，两者分离削弱同源噪声
    bootstrap = next_q_batch.max(axis=1)
    # 终止状态屏蔽自举：吸收态之后不存在后继回报
    bootstrap = np.where(dones, 0.0, bootstrap)
    # 折扣因子按 n 步累乘；实现中 n-step 回报在批次组装阶段完成，
    # 这里用单步结构演示掩码与折扣的写法
    return rewards + (gamma ** n_steps) * bootstrap


# 损失只用目标与预测之差的平方，目标一侧需要停止梯度
# loss = ((q_pred - target) ** 2).mean()

解读：目标计算的三个要点：最大化取值给出自举量、终止掩码把吸收态之后的价值置零、折扣因子按步数累乘。掩码遗漏会让终止状态的价值把"虚拟后续"混入目标，表现为回合结束附近的误差系统偏大；双重估计的完整实现中，动作选择来自在线网络的前向结果，评估用目标网络对所选动作取值，两处前向不可混用。n-step 回报的实际组装发生在采样与批次处理阶段，函数注释说明这一分工，避免与训练循环代码重复。

片段 3：探索调度

def epsilon_by_step(step, start=1.0, end=0.05, decay_steps=100000):
    """按环境步线性衰减探索概率：与并行规模解耦。"""
    fraction = min(1.0, step / decay_steps)
    return start + fraction * (end - start)


for step in (0, 25000, 50000, 100000):
    # 早期接近全随机保证覆盖，后期保留少量探索防局部最优
    print(step, round(epsilon_by_step(step), 3))

解读：衰减函数以环境步作自变量，不用训练迭代，回到第 022 章的结论：迭代对应的样本量随并行配置变化，只有样本量是可移植的坐标系。衰减末值保留小量探索（例如 0.05），让策略在收敛后仍能响应环境变化与估计误差；归零则丧失这一响应能力。衰减长度与回放容量应匹配：容量足够容纳高 ε 阶段的数据时，衰减可以更从容。探索曲线本身值得作为诊断指标记录，与评估回报曲线对照检查停滞。

常见坑

  • 启动步数过小：更新开始得过早，池中样本相关性强。症状是价值损失剧烈震荡。修复：按池容量的百分之二量级设置启动步数。
  • 目标同步周期不匹配更新频率：周期按迭代配置而更新频率随批次变化。症状是目标陈旧或同步过频。修复：按梯度步计数，与更新数据比联立核算。
  • 回放池内存超预算：图像观测下单样本体积大，池容量按样本数计会使占用迅速放大。症状是内存溢出。修复：容量与单样本字节数联立计算，必要时缩容。
  • 终止掩码遗漏：目标穿越回合边界。症状是回合末尾附近价值系统性偏差。修复：由回合边界标志构造掩码，单测覆盖终止与非终止两类样本。
  • 高估偏差长期累积：未启用双重估计且奖励尺度大。症状是动作价值远超实际回报。修复：启用 Double Q，并用评估回报核对价值曲线的绝对值。

  2. 把 n_step 从 1 改到 5，预测偏差、方差与收敛速度的变化方向。★
    提示
    偏差下降、方差上升；在奖励稀疏任务上通常加快信号传播，在噪声大的任务上可能拖慢稳定。
  3. 推导最大操作对含噪估计的放大效应，以及双重估计削弱它的机制。★★
    提示
    对含噪声的多个值取最大，期望高于真实最大；选择与评估分离后，噪声不再同时作用于同一取值，高估幅度显著下降。
  4. 设计消融实验：double_q、dueling、n_step 三项逐项开关，说明指标选择与对照条件。★★
    提示
    固定种子与采样预算，指标用评估回报与价值曲线偏差；每项单独开关形成对照，结论以配对差异表达。
  5. 设计诊断流程：价值曲线持续上升而评估回报不涨时，按探索、回放、目标三个方向逐一排查并给出判据。★★★
    提示
    先看探索曲线是否已衰减到底、再核对池内数据新鲜度、最后检查目标同步周期与高估幅度；三个方向分别对应覆盖率、数据分布与估计偏差。

小结

  • DQN 用时间差分目标自举更新动作价值，目标网络把目标暂时固定以保证稳定。
  • 回放池打散时间相关性并提供样本复用；容量在记忆长度与内存之间折中。
  • ε-贪心探索按环境步衰减，与并行规模解耦；末值保留小量探索防停滞。
  • Double Q 缓解高估、Dueling 分解价值与优势、n-step 折中偏差与方差，逐项消融验证。
  • 终止掩码与目标同步周期是稳定性的两个细节，配置时与更新频率联立核算。
