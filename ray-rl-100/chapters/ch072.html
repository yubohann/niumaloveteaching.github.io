第 072 章：实验对比方法

对比两位候选、两种算法或两套配置，结论的可信度来自对照设计。本章讲清单变量原则、对齐轴的选择、同实验内与跨实验两种形态的差异，以及配对自助检验与对比表的产出方法。

  • 主题：Ray Tune 调优 / 对照实验设计
  • 关键机制：单变量对照、对齐轴、变体网格、样本效率口径、配对检验
  • 预计学时：55 分钟
  • 前置章节：第 071 章

学习目标

  • 掌握对照实验的基本原则：单变量变更、同等调参预算、同等评估口径，并会写出对照条件清单。
  • 会区分并对齐三种横轴：迭代数、环境步数、墙上时间，说明每种轴对应的结论诉求。
  • 会用“变体网格”在同一个实验内构造配对对比，理解它与跨实验对比在控制力上的差异。
  • 会计算样本效率口径（达到阈值的步数）并处理平滑与缺失两个技术点。
  • 会输出结构化对比表：逐种子差值、自助区间、判决与备注，四条要素缺一不可。

背景与动机

“配置 A 比配置 B 好”是调优工作最常见的结论形式，也是最容易出错的结论。对比结论的外部效度由对照设计决定：改动点之外的差异都会污染归因。常见的污染源有四个：改动不止一处、双方调参预算不对等、比较横轴口径不同、样本量不足以覆盖噪声。

上一章在搜索内部做排序，回答“哪个试验好”；本章做方法之间的对照，回答“哪个方案值得推广”。后者的判据更严格：内部排序允许选择偏差存在，对外结论要求差异在独立复验下稳定重现。本章把对照设计、对齐轴、检验方法组装成可复用的对比流程。

核心原理

1. 单变量对照与对等条件

对照实验的最小形式是 A 与 B 只差一个因素，其余全部对齐：环境与版本、评估频率与评估种子、总预算、硬件资源、调度器配置。“同等调参预算”容易被忽略：若方案 A 经过了完整搜索而方案 B 使用默认超参，比较的其实是“A 加上一轮搜索”与“B”，结论无法归因到方案差异。对等做法是给双方同量级的搜索预算，各取自身的最优区域再比较；计算总量可以在报告中如实列出。

2. 对齐轴：迭代、环境步数、墙上时间

三种横轴对应三种结论诉求：环境步数轴衡量样本效率，回答“同样多的交互数据谁学得更好”，适合数据获取代价高的场景；墙上时间轴衡量计算效率，回答“同样等多久谁更强”，适合算力受约束的场景；迭代数轴是各算法自身的记账单位，不同实现的迭代粒度不同，跨方案比较时容易失真，仅适合同实现内部的配置比较。

结论口径 = (对齐轴, 统计量)：样本效率 → (环境步数, 达阈值步数)；计算效率 → (墙上时间, 时间点均值) 报告必须同时写明两要素；“A 在 1e6 步达到 200 分、B 在 1e5 步”是无效对比，缺横轴与统计量

3. 同实验内对比与跨实验对比

同实验内对比把“方案变体”做成搜索维度（如网格轴），全部试验在同一时段、同一资源池、同一调度器下运行。它的控制力最强：时间漂移、硬件差异、集群负载三个外部因素在变体之间自然抵消，配对设计的条件天然成立。跨实验对比把各自独立完成的实验合并分析，灵活性高（不同时段、不同集群都能用），代价是要在报告中说明时段与硬件差异，并承担无法消除的外部漂移。关键结论建议放回同实验内验证一次。

4. 统计量：最终性能与学习速度

最终性能用尾段均值度量（第 071 章的口径）；学习速度用“达到阈值所需的环境步数”度量。阈值判定有两个技术点：一是先平滑再判定，否则单帧越线会被记成提前达标；二是未达阈值的试验记为空值并单独统计，缺失比例本身是结论的一部分（达标率）。另一种综合口径是曲线下面积，它同时包含速度与高度，代价是解释力不如“阈值加最终值”直观，适合作为辅助指标。

5. 配对检验与范围边界

同实验内的变体共享种子列表时，逐种子的差值序列构成配对样本，用自助法给出均值的区间。样本量 5 的配对设计能可靠识别的只有大效应：区间半宽约为 1.6 倍标准差除以样本量的平方根，弱差异需要更多种子，而更多种子意味着线性增加的预算。这是对比工作的现实约束：结论强度与投入成正比，报告应写明“在 5 个种子与给定预算下能分辨的最小差异”；笼统宣称“无差异”会夸大证据强度。

实现思路与设计

对比流程按六步执行：定问题、选轴、设对照、配种子、跑实验、出表格。与上一章的差异在于，第 071 章在单个实验内部排序，本章面向方案之间的外部结论。

  1. 定问题：写明要回答的一句话问题，例如“折扣因子 0.999 是否在主指标上优于 0.99”。
  2. 选轴与统计量：按结论诉求选环境步数或墙上时间，选定阈值与尾段长度的口径。
  3. 设对照：构造变体网格，明确除变体外的全部参数取值，形成对照条件清单。
  4. 配种子：变体之间共享同一组种子，配对结构在数据层就位。
  5. 跑实验：同一实验提交；若必须跨实验，记录时段与资源池信息。
  6. 出表格：逐种子差值、自助区间、判决、备注四要素齐全；备注写明可分辨的最小差异。
对比类型控制力适用报告要求
同实验变体网格强（配对天然成立）关键结论、消融实验写明种子列表与对照条件
跨实验合并中（存在外部漂移）补充验证、历史对比写明时段、硬件与版本
与文献数值对比弱（口径不可控）量级参考注明口径差异，不作强结论
设计决策：为什么消融实验优先用网格轴？

消融的目的是“关掉一个因素看影响”，结论依赖严格的单变量控制。网格轴把变体绑定在同一实验内，调度器、资源池、时段全部共享，任何外部扰动都以相同方式作用于两个变体。代价是网格轴占用试验名额度：变体数乘种子数即试验数，两个变体各 5 个种子就是 10 个试验，预算必须提前计入。

关键代码与解读

片段 1：同实验内的变体网格

from ray import tune

# 消融网格：折扣因子两档 × 种子五个，其余参数固定
compare_space = {
    # 变体维度：只改这一个参数，差异才能归因到它
    "gamma": tune.grid_search([0.99, 0.999]),
    # 固定参数：两档共享同一套值，形成对照条件
    "lr": 3e-4,
    "train_batch_size": 4096,
    "entropy_coeff": 0.01,
    # 种子维度：两个变体共享同一组种子，配对结构在采样期就位
    "seed": tune.grid_search([11, 12, 13, 14, 15]),
}

tune.run(
    train_fn,
    config=compare_space,
    # 网格轴已覆盖全部组合，num_samples 保持 1
    num_samples=1,
    metric="episode_return_mean",
    mode="max",
    name="gamma_ablation",
    storage_path="/shared/tune_results",
)

解读：网格配置把“对照条件清单”直接写在了空间里。（1）网格轴承担变体维度，固定键承担对照条件；读者看空间即知除 gamma 外没有任何差异。（2）种子维度用网格展开：配对检验要求变体之间的种子一一对应，随机采样模式下两组种子集合可能错位。（3）试验总数等于 2×5=10，预算提前可见；相比随机搜索的 40 个试验，消融用更少试验换取更强的归因力，这正是对照设计的价值。

片段 2：样本效率口径的提取

def steps_to_threshold(df, metric, threshold, smooth_window=5):
    """样本效率：每试验首次达标的环境步数；未达标记空值并统计比例。"""
    out, missing = {}, 0
    for tid, g in df.sort_values("env_steps").groupby("trial_id"):
        # 先平滑再判定：单帧越线可能是评估噪声造成的假达标
        smooth = g[metric].rolling(smooth_window, min_periods=1).mean()
        hit = g[smooth >= threshold]
        if len(hit) == 0:
            out[tid] = float("nan")
            missing += 1
        else:
            out[tid] = int(hit["env_steps"].iloc[0])
    rate = 1.0 - missing / max(len(out), 1)
    # 达标率是结论的一部分：达标率低时“平均达标步数”只覆盖子集
    print(f"达标率 {rate:.0%}，未达标 {missing} 个")
    return out, rate

解读：提取函数处理了学习速度口径的两个技术点。（1）平滑窗口先于阈值判定生效，滚动均值把评估噪声压平，达标的“首次”位置不再由单帧波动决定；窗口大小与评估频率相关，报告中应写明。（2）未达标试验显式记为空值，不参与平均值计算，但计入达标率；达标率 60% 与 100% 的两组数据，即使平均步数相同，含义完全不同。（3）输出按试验标识索引，后续按变体分组时直接可用；环境步数列的来源是训练上报，若任务按迭代记账，需要先在训练函数中换算为步数（第 073 章讨论上报口径与日志细节）。

片段 3：配对对比表

import numpy as np

def variant_means(df, metric="episode_return_mean", tail=10):
    """每（变体, 种子）一个尾段均值：对比统计的最小单元。"""
    return (df.sort_values("epoch")
              .groupby(["gamma", "seed"]).tail(tail)
              .groupby(["gamma", "seed"])[metric].mean()
              .unstack("gamma"))   # 行=种子，列=变体

def ab_table(means, va, vb, n_boot=2000):
    """配对差值：自助 90% 区间与判决；区间跨 0 时不宣称差异。"""
    diffs = (means[va] - means[vb]).dropna().to_numpy()
    rng = np.random.default_rng(0)
    boot = [rng.choice(diffs, size=len(diffs), replace=True).mean()
            for _ in range(n_boot)]
    lo, hi = np.percentile(boot, [5, 95])
    verdict = ("A 优于 B" if lo > 0
               else "B 优于 A" if hi < 0 else "差异未超噪声")
    # 输出四要素：差值、区间、判决、样本量
    print(f"{va} - {vb}: 差值 {diffs.mean():.1f} "
          f"[{lo:.1f}, {hi:.1f}]（{len(diffs)} 对）：{verdict}")
    return {"diff": float(diffs.mean()), "ci": (float(lo), float(hi)),
            "verdict": verdict, "n_pairs": len(diffs)}

means = variant_means(results_df)
ab_table(means, va=0.999, vb=0.99)

解读：对比表函数的三个要点。（1）最小统计单元是“变体 × 种子”的尾段均值，配对差值在单元之间逐行相减；unstack 之后行是种子、列是变体，配对关系一目了然，缺失种子用 dropna 对齐。（2）判决三分支：A 优、B 优、未超噪声；措辞把“证据不足”与“无差异”区分开，为后续增加种子留出空间。（3）输出包含样本量，读者可以据此评估结论强度；5 对样本下的可分辨差异较大，报告中应写明这一点，避免把“未超噪声”解读为“等价”。Tune 的网格与结果接口在 2.x 内多次调整，字段与行为以对应版本的官方文档为准。

常见坑

  • 调参预算不对等：一方经过搜索、另一方使用默认值，差异无法归因。症状是两个方案的结论在补充搜索后反转。修复：给双方同量级的搜索预算，或明确声明这是“默认对默认”的比较。
  • 用迭代数轴跨实现比较：不同实现的迭代粒度不同，曲线形状被记账方式扭曲。修复：换算到环境步数或墙上时间轴再比较，并在报告写明换算方式。
  • 跨实验对比忽略时段与硬件：两次实验在不同负载的集群上运行，吞吐差异混入性能差异。修复：关键结论放回同实验内验证；跨实验结论注明外部条件。
  • best-of-both 式比较：拿 A 的最佳种子与 B 的平均水平对比，优势被夸大。修复：配对同种子比较，或统一用尾段均值加区间。
  • 阈值判定不平滑：单帧噪声越线被记为达标，学习速度被系统性高估。修复：先滚动平滑再判定，平滑参数写入报告。

练习与思考

  1. 为四个对比问题各选对齐轴与统计量：样本效率、计算效率、最终水平、稳定性。★
    提示
    样本效率用环境步数轴加达标步数；计算效率用墙上时间轴加时间点均值；最终水平用环境步数轴加尾段均值；稳定性用末端分位区间宽度。
  2. 预测题：把对比轴从环境步数换成迭代数（两算法每迭代消耗的步数相差一倍），配对差值的均值与判决会如何变化？★★
    提示
    每迭代步数多的算法在迭代轴上进度显得更快；样本效率占优的一方若每迭代消耗的步数更少，换成迭代轴后优势会缩小甚至反转；这正是跨实现比较不能用迭代轴的原因。
  3. 设计题：为一个“新损失项是否有效”的问题设计消融实验：写出对照条件清单、变体网格、种子列表与判决标准，并说明试算预算。★★★
    提示
    变体网格两档（开/关损失项），固定其余全部参数，种子 5 个共享，共 10 个试验；判决用配对自助区间与达标率双口径，若性能与稳定性结论冲突，以预注册的主指标为准。
  4. 推导题：证明配对差值的方差随种子间相关性增大而下降，并解释同实验变体网格为何天然提高该相关性。★★★
    提示
    Var(a−b)=σa2+σb2−2ρσaσb；同实验内两变体共享时段、资源池与种子，外部扰动同向作用，ρ 接近 1，差值方差被大幅压缩。
  5. 实践题：对片段 3 的输出补充“可分辨最小差异”的计算：用差值序列的标准差估计 5 对样本下区间宽度，并说明需要多少种子才能分辨 10 分的差异。★★
    提示
    区间半宽约 1.6×σd/√n；要分辨 10 分需半宽小于 5，反推所需 n。计算时用复验种子的差值标准差作 σd 估计。

小结

  • 对照设计三原则：单变量变更、同等调参预算、同等评估口径；缺一结论都无法归因。
  • 对齐轴按诉求选择：样本效率用环境步数，计算效率用墙上时间，迭代轴仅限同实现内部。
  • 关键对比放同实验变体网格：配对结构天然成立；跨实验对比须注明时段与硬件。
  • 学习速度口径先平滑后判阈值，未达标记空值且统计达标率。
  • 对比表四要素：逐种子差值、自助区间、判决、样本量与可分辨最小差异。
