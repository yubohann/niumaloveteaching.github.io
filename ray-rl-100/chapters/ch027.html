第二篇 · RLlib 核心接口与训练

第 027 章：RLlib离线数据与行为克隆

离线训练脱离环境交互，直接从记录数据中学习策略。本章讲清行为克隆（Behavior Cloning, BC）的监督目标、离线数据的组织格式、RLlib 的离线训练接入方式，以及数据覆盖度对策略上限的约束。

  • 主题：RLlib 训练 / 离线数据与监督式学习
  • 关键机制：交叉熵监督目标、离线数据格式、无环境训练、分布偏移
  • 预计学时：55 分钟
  • 前置章节：第 026 章

学习目标

  • 理解行为克隆的监督目标，说明它与策略梯度在数据来源上的差异。
  • 掌握离线数据的组织格式：列式批次、回合分段与字段约定。
  • 会配置离线训练入口，把数据集接入训练循环完成监督更新。
  • 理解分布偏移与复合误差的成因，会判断覆盖度对策略上限的影响。
  • 能设计离线训练的前置检查与评估协议。

背景与动机

很多场景无法提供可交互环境：真实系统试错代价过高，仿真器算力受限，而历史日志与人工操作记录已积累大量状态动作对。离线训练从记录中直接拟合策略，无需环境交互，适合冷启动与安全敏感场合。

行为克隆把策略学习化简为监督学习：给定状态，预测数据中的动作。后果有两点：训练目标从最大化回报退化为模仿似然，策略上限由数据质量与覆盖度决定；数据分布之外缺乏监督信号，误差沿轨迹复合放大。理解这两点，才能正确设定离线训练的预期与评估协议。上一章完成了在线训练的评估视角，本章转向完全离线的训练路径。

核心原理

行为克隆的数学形式简洁，工程要点集中在数据组织与分布覆盖上。

1. 监督目标与数据来源

设数据集 D 由状态动作对 (si, ai) 构成，行为克隆最小化负对数似然（等价于交叉熵）：

L(θ) = − E(s,a)∼D [ log πθ(a | s) ] 连续动作用高斯分布的负对数似然，离散动作用分类交叉熵；监督信号来自数据中的动作标签，回报不参与目标函数

与在线策略梯度对照：策略梯度用期望回报的梯度更新，数据由当前策略产生；行为克隆用监督标签的梯度更新，数据由行为策略（人工或旧系统）产生。前者优化任务目标，后者优化模仿精度，数据分布约束不同。回报仍有用处：加权形式（MARWIL 风格）用回报对样本加权，让高回报样本占更大权重，兼顾模仿与偏好。

2. 分布偏移与复合误差

训练分布是行为策略访问到的状态集合，部署时的状态由学到的策略驱动。轻微偏差把系统带到数据未覆盖区域，模仿误差上升并沿轨迹累积，形成复合误差。覆盖度决定安全边界：覆盖越广，部署外推越少。缓解手段包括增加数据多样性、统计轨迹偏离度、必要时用在线微调收尾。

3. 数据组织格式

离线数据以列式批次存储，字段与在线采样批次一致：观测、动作，可选奖励与回合边界。轨迹按回合分段，段内保持时间顺序；含回报加权的算法依赖正确边界。文件层面分片存放便于并行读取与断点恢复，读取时跨片打乱避免同源轨迹成批出现。动作编码必须与动作空间严格对应：连续动作为浮点数组，离散动作为整数编号，错位会让训练数值收敛而行为无效。

4. RLlib 的离线接入

RLlib 提供行为克隆入口，训练循环不创建环境进程组，直接从数据流取批次监督更新；读取接口历经演进（早期 InputReader 与 IOContext，新版本围绕离线数据 API，以官方文档为准）。评估单独组织：离线训练不产生交互，如需回报曲线应挂接独立评估进程组，或用离线评估集度量模仿精度。

5. 复合误差的量化

设单步模仿误差率为 ε，回合长度为 T。轨迹全程保持在数据覆盖区内的概率按 (1 − ε)T 衰减：ε = 0.02、T = 120 时，仅约 8.8% 的轨迹始终不偏离；首次偏离的期望步数约为 1/ε = 50 步。偏离一旦发生，策略进入没有监督信号的区域，误差率进一步上升，形成正反馈循环。

P(全程在覆盖区内) = (1 − ε)T，ε 为单步模仿误差率，T 为回合长度 ε = 0.02、T = 120 时约 8.8%；首次偏离期望步数约 50；提高覆盖度等效于延缓 ε 的上升速度

由此得到评估协议的要求：单步似然指标不能作为部署性能的充分证据，评估必须覆盖偏离之后的行为，例如从扰动起点出发测量恢复能力，或统计长回合下的动作匹配率衰减曲线。

6. 三类离线方法的对比

方法优化目标数据要求是否使用回报主要风险
行为克隆（BC）负对数似然状态动作对否分布偏移与复合误差
回报加权模仿（MARWIL 风格）回报加权的负对数似然状态动作对与回报是（权重）权重设计不当使少数样本主导
离线策略优化（CQL 类）策略目标加保守约束回报与动作分布是（目标）保守系数难调，实现复杂

选择依据：目标是复现既有行为时用行为克隆；数据带可靠回报且希望超越平均水平时用加权模仿；确有必要在离线数据上直接优化回报、且能承担保守约束调参成本时再考虑离线策略优化。三类方法对数据质量的要求依次上升，方法选择应先看数据供给能力。

7. 覆盖度核算示例

把状态空间离散为 10×10 网格做粗粒度覆盖审计：每格目标 50 次访问时，需要 5000 次状态访问；按回合长度 120 折算，约合 42 条轨迹。若数据显示访问集中在前 20% 的网格，其余区域接近空白，策略在这些区域只能外推，部署表现无法由训练指标预测。审计报告同时给出每格的主要动作占比与动作熵：占比过高说明该区域的动作多样性不足，模仿目标会退化为常量输出。覆盖度审计回答的核心问题是：部署分布与数据分布的差距落在哪些区域。

8. 交叉熵的数值示例与覆盖度精度账

先看监督目标的一次具体计算。某三动作离散任务的预测 logits 为 [2.0, 0.5, −1.0]，数据标签为第 0 类：对 logits 取指数得 [7.39, 1.65, 0.37]，按总和 9.41 归一后分布为 [0.786, 0.175, 0.039]；正确类的负对数似然为 −ln 0.786 ≈ 0.241。作为对照，三分类均匀分布的单样本损失为 ln 3 ≈ 1.099，该预测把损失压到均匀基线的约 22%。

∂L/∂zi = pi − 1{i = a*}，即"预测概率减去目标指示" 同一组 logits 的梯度为 [−0.214, 0.175, 0.039]：正确类被向上推、错误类被向下压，推压幅度等于预测偏离程度；预测越自信且错误，单样本梯度越大

这个梯度形式解释了本讲最容易踩的坑：标签编码错位时，模型会把错误的映射当作目标学习，损失曲线照常下降，数值上完全看不出异常，问题只在评估与部署行为中暴露。损失下降速度与映射正确性无关，这是离线训练必须做编码审计的根本原因。

再看覆盖度审计的精度账。10 × 10 网格、每格 50 次访问时全网格需要 5000 次状态访问，按回合长度 120 折算约 42 条轨迹；此时单格的动作均值（以二值动作为例，真实占比 0.5）标准误为 0.5/√50 ≈ 0.071，95% 置信区间半宽约 0.14，只能区分较大的动作偏好差异。每格访问提到 100 次，标准误降到 0.05，全网格访问量与轨迹数同步翻倍。

实现思路与设计

离线训练的实施顺序：先审计数据，再配置训练，最后设计评估。

检查项要求失败后果
动作编码与动作空间逐一对应数值收敛但行为错乱
观测特征与部署端同一归一化口径训练评估两头都失真
回合分段边界标志正确，段内有序加权算法估计偏差
数据规模覆盖主要状态区域，样本量足够过拟合与覆盖盲区

参数示例值作用取值依据
train_batch_size4096每轮监督样本数与在线批次同量级起步，按评估集似然的稳定性调整
lr3e-4监督更新学习率监督目标比策略梯度平稳，可沿用常见量级
weight_beta0 至 1.0回报加权强度0 为纯模仿；加权从 0.5 起步，用独立评估集判断收益
评估集占比10% 至 20%独立评估数据比例按来源或时间切分，保证与训练集不同源
设计决策：为什么离线训练更需要独立评估集？

在线训练中环境提供新鲜数据，过拟合表现为评估回报停滞。离线训练的监督损失可持续下降而策略不改善，模型可能记住个案而失去泛化。按时间或来源切分训练与评估集，用评估集似然与动作匹配率做模型选择，是离线流程的基本纪律。监督损失只用于优化，模型选择以独立评估为准。

数据量与分片的核算示例：每条约 50 字节（8 维 float32 观测 32 字节，加上动作、奖励与边界标记），一千万条约 500 MB；按 100 MB 一片切成 5 片，每片约 200 万条。并行读取度取片数与读取核心数的较小值，跨片打乱由读取层完成，片内保持时间顺序。分片粒度兼顾两件事：足够的片数支撑并行读取，单片又足以摊薄打开文件的固定开销；分片文件命名携带生成批次标识，便于溯源。

数据审计的常用做法：按观测维度分桶统计直方图，与预期物理范围对照，越界值提示采集端编码问题；统计动作的边缘分布，严重偏斜提示操作者偏好或标签错误；统计回合长度分布，长尾条目需要单独核查是否存在截断处理缺失。审计输出与训练任务一起存档，后续问题定位以此为基线。评估集划分优先按时间切分，其次按来源切分；同源数据泄漏会让评估指标虚高，切分逻辑应写入数据说明文件。离线评估还可使用环境回放：固定策略重放历史轨迹，对照数据中的动作计算匹配率与似然，回放不引入新交互，成本低于在线评估。动作熵按每格主要动作占比与分布熵两项计算，先按窗口平滑再跨格比较。

与上一章差异：第 026 章的评估围绕在线管线组织；本章的数据不经过环境，训练循环省略采样阶段。离线产出常作为在线微调的起点。下一章讨论 GPU 训练与数据搬运。

关键代码与解读

片段 1：离线数据的组织与落盘

import json
import numpy as np


def dump_episode(path, obs_list, act_list, rew_list):
    """把一条轨迹写成 JSON 行：每行一条转移，回合内保持时间顺序。"""
    with open(path, "a", encoding="utf-8") as f:
        for i, (obs, act, rew) in enumerate(zip(obs_list, act_list, rew_list)):
            last = i == len(obs_list) - 1      # 段尾标记：回合计数的依据
            record = {
                "obs": np.asarray(obs, dtype=np.float32).tolist(),
                "actions": int(act),           # 离散动作存整数编号，与空间对应
                "rewards": float(rew),         # 回报供加权算法使用，模仿本身不用
                "dones": bool(last),
            }
            f.write(json.dumps(record) + "\n")


# 写入时按来源分片：不同批次的数据落在不同文件，
# 训练时交叉读取，降低同一来源轨迹整批出现的相关性
dump_episode("demo_part_01.jsonl", [[0.1, 0.0], [0.2, 0.3]], [1, 2], [0.0, 1.0])

解读：三个工程要点：回合分段用段尾标记表达，段内保持时间顺序，打乱只发生在片段之间；离散动作存整数、连续动作存浮点数组，编码与空间严格对应；按来源分片存放，原始文件保留完整轨迹便于审计。奖励字段一并写入是低成本决定：未来切换加权算法或离线评估无需重采。

片段 3：行为克隆损失的计算与权重

import numpy as np


def bc_loss(action_logits, actions):
    """离散动作的交叉熵：等价于负对数似然。"""
    # 数值稳定写法：先减去每行的最大值再取指数归一化
    shifted = action_logits - action_logits.max(axis=1, keepdims=True)
    log_probs = shifted - np.log(np.exp(shifted).sum(axis=1, keepdims=True))
    picked = log_probs[np.arange(len(actions)), actions]
    return -picked.mean()                    # 批次平均负对数似然


def weighted_bc_loss(action_logits, actions, sample_rewards):
    """按样本回报加权：高回报样本在模仿目标中占更大权重。"""
    base = -np.array([bc_loss(action_logits, actions)])
    weights = np.exp(sample_rewards - sample_rewards.max())   # 稳定化归一
    return float(base * weights.mean())

解读：两个函数构成从纯模仿到偏好加权的连续谱：标准交叉熵只在数据分布上优化匹配；加权版本让高回报轨迹影响更大，靠近策略优化又保持监督学习的稳定形式。权重指数化需处理量纲：回报跨度大时指数溢出，减去最大值是常见稳定化手段；权重过强会让少数样本主导更新。起步先用无权重版本，确认模仿基线后再引入加权。

常见坑

  • 动作编码错位：数据中的动作编号与动作空间枚举顺序不一致。症状是监督损失正常下降，部署行为完全错误。修复：核对编码表，在数据生成端固定枚举顺序。
  • 观测归一化不一致：采集端与训练端的特征缩放不同。症状是评估集似然正常但真实环境表现差。修复：归一化参数随数据存档，训练与部署读取同一份。
  • 回合边界缺失：分段信息在数据整理中被抹掉。症状是加权算法回报估计偏差。修复：保留段尾标记，或从时间戳重建回合边界后再训练。
  • 训练损失持续下降而策略不改善：模型记忆训练集个案，评估集似然停滞。修复：扩大数据多样性，加入权重衰减或早停。
  • 把离线数据当作在线训练数据：希望用离线数据驱动需要环境交互的算法。症状是算法启动后等待环境或批次构造失败。修复：区分监督目标与策略梯度目标，离线路径使用支持无环境训练的算法入口。

    提示
    样本总量大但集中在少数轨迹时，未覆盖区域没有监督信号；按状态网格统计轨迹访问次数比只看行数更有意义。
  3. 推导交叉熵目标的梯度与"预测分布同数据分布距离"的关系，说明加权形式的假设。★★
    提示
    梯度为预测概率减去目标指示的期望；加权形式假设高回报样本的动作更值得模仿，相当于对目标分布做重要性倾斜。
  4. 设计数据审计脚本：检查动作分布、观测维度、边界比例，说明每项异常的典型案例。★★
    提示
    动作分布严重倾斜提示操作者偏好或编码错误；观测维度不一致多为多版本数据混装；边界比例异常提示拼接错误。
  5. 设计实验：行为克隆预训练后接在线微调，说明两阶段的评估指标与切换判据。★★★
    提示
    离线阶段用评估集似然与动作匹配率；切换判据可设为评估集指标进入平台期，随后在线阶段观察回报曲线相对纯在线训练的起点的提升。

小结

  • 行为克隆以负对数似然为目标，把策略学习化为监督学习；回报不进入基础目标，可用于加权。
  • 数据覆盖度决定策略上限，分布偏移与复合误差是部署阶段的主要风险源。
  • 离线数据保持列式批次与回合分段，动作编码、归一化口径、边界标志三项必须审计。
  • 离线入口无需环境交互；评估独立组织，监督损失只用于优化，模型选择依据独立评估集。
  • 离线训练的产出常作为在线微调的起点，两阶段衔接可以兼顾冷启动与持续改进。
