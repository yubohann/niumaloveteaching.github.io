第 077 章：超参搜索实战：GAE与折扣因子

折扣因子决定信用分配的跨度，GAE 参数决定偏差与方差的配比。本章讲清有效视野与 λ 衰减长度的推导、两者的耦合与等价带、预算依赖的排名陷阱，以及离散候选加分组矩阵的判读方法。

  • 主题：超参搜索实战 / 信用分配参数族
  • 关键机制：有效视野、GAE 递推、偏差方差权衡、预算依赖排名
  • 预计学时：55 分钟
  • 前置章节：第 076 章

学习目标

  • 会用有效视野公式推导折扣因子对应的信用分配跨度，并判断它与任务时域的匹配关系。
  • 理解 GAE 的偏差方差权衡：端点取值（单步 TD 与蒙特卡洛）的行为差异与中间值的平滑过渡。
  • 识别折扣因子与 λ 的耦合结构：等价带的存在原因与联合搜索的预算浪费。
  • 会用预算依赖判读区分“真实劣势”与“预算不足造成的低估”，避免系统性误判大折扣因子。
  • 会用回报水平与价值学习质量（解释方差）的对照表判读 λ 与折扣因子对评论家的压力。

背景与动机

折扣因子与 GAE 参数共同定义“多大的时间跨度上的回报被纳入更新”。它们与学习率的职责不同：学习率直接决定步长，这两个参数决定优化目标的形状。改小折扣因子等于把目标的视野缩短，策略学会的可能是短视的局部行为；改大折扣因子把远处的回报纳入信用分配，代价是估计方差上升、价值函数更难学。

上一章的参数对（学习率、批量）作用于优化过程；本章的参数对作用于问题定义。搜索设计因此多了一层纪律：改折扣因子会改变目标的语义，跨折扣因子的比较必须保证预算充足且评估口径一致，否则结论只回答“谁在短预算下更快”，回答不了“谁能学到更好的策略”。预算依赖的排名陷阱是本章的核心判读对象。

核心原理

1. 有效视野与任务时域的匹配

折扣回报对步数 t 之后的奖励施加 γt 的权重，权重衰减到 1/e 所需的步数约为 1/(1−γ)，称为有效视野（Effective Horizon）。

H ≈ 1/(1−γ)：γ=0.99 → 100 步；0.995 → 200 步；0.999 → 1000 步；0.9999 → 10000 步 经验判据：视野应覆盖任务关键因果链的数倍；走过短的策略无法建立长程信用，走过长地放大方差与价值学习负担

时域匹配是范围设计的起点：视野判据给出候选档位的筛选线，最终档位由搜索与复验决定。任务环境有最大步数截断时，视野接近或超过截断长度会带来边界效应：截断处的回报计算需要自举处理，否则大折扣因子的估计偏置被放大（第 053 章的目标值机制在此与本参数族交汇）。

2. GAE 的递推与两端行为

广义优势估计（Generalized Advantage Estimation, GAE）把多步时序差分残差按几何权重叠加：At = δt + (γλ)δt+1 + (γλ)2δt+2 + …，其中 δ 是单步 TD 残差。λ=0 退化为单步自举：偏差最大、方差最小；λ=1 退化为蒙特卡洛回报减去基线：无偏、方差最大。中间值的偏差与方差在两端之间平滑过渡，衰减长度由乘积 γλ 控制，约 1/(1−γλ)。

At = Σk≥0 (γλ)k δt+k，  优势估计的衰减长度 ≈ 1/(1−γλ) γ=0.99、λ=0.95 时衰减长度约 17 步；λ=1 时等于折扣视野本身

3. 耦合结构与等价带

两个参数都通过乘积进入优势估计：γ 增大与 λ 减小可以在一定范围内互相补偿，形成“等价带”：低折扣因子配高 λ 与高折扣因子配中 λ 往往表现出相近的学习曲线，优势矩阵上呈现沿对角方向延伸的等值区。联合大范围搜索时，等价带大量采样点携带冗余信息，预算利用率下降。两种应对：其一，先固定 λ 的中值（如 0.95）搜索折扣因子，再在最优折扣因子上搜索 λ；其二，使用小规模全因子网格（3 档 × 4 档共 12 个组合）直接观察等价带形态，为后续范围收窄提供地图。第一种省预算，第二种提供结构信息，按阶段选择。

4. 预算依赖的排名陷阱

折扣因子越大，策略需要更多交互才能把长程信用的收益显现出来：在短预算下截断比较时，小折扣因子因“学习快”占据优势；预算拉长后，大折扣因子的上限更高，排名可能反转。这是本章最重要的判读陷阱：搜索预算不足时，机制会系统性地淘汰大的折扣因子，把“预算不足”写成“参数不佳”。判读方法是在多个预算检查点上分别聚合（如预算的 1/3、2/3、全程），若排名随预算变化，结论标注为“预算依赖”，并给出更长预算的复验建议；直接把小折扣因子写成最优会固化预算不足造成的结果。

5. 价值学习质量的压力观测

折扣因子与 λ 的变化同时给评论家加压：视野变长、λ 增大都会拓宽价值函数的估计范围。解释方差（Explained Variance）度量价值预测解释回报波动的能力，是观察该压力的直接指标：回报上升但解释方差持续偏低时，策略改进可能建立在不稳定的价值估计上，后续训练易回落。判读表按参数档位聚合回报与解释方差两列，两者同向时结论可信；回报高而解释方差低的档位标记为“需复验”，用更长预算与更多种子确认。

实现思路与设计

搜索设计按“筛档位、定顺序、控预算、双指标、防反转”五步执行。与上一章的差异在于，第 076 章调优化过程参数，本章调目标定义参数，判读时必须附带预算条件。

  1. 筛档位：用视野判据过滤折扣因子候选，剔除与任务时域明显不匹配的档位。
  2. 定顺序：先固定 λ 中值搜折扣因子，收敛后再搜 λ；需要结构信息时改用小全因子网格。
  3. 控预算：折扣因子档位的搜索预算不低于视野覆盖关键因果链所需的最短预算，并在设计表中写明该下限。
  4. 双指标：聚合表并列回报与解释方差，主指标用于排序，解释方差用于标注可信度。
  5. 防反转：在 1/3、2/3、全程三个预算点做排名快照，排名不稳定即判预算依赖。

设计决策：离散候选与对数分布如何取舍？

折扣因子在 0.99 与 0.995 之间的行为差异很显著（视野 100 对 200 步），从 0.990 到 0.991 的差异几乎不可观测。连续分布会把大量预算花在“行为等价”的邻近值上，尤其在 0.99 附近密度集中。离散候选把预算直接放在行为差异明显的档位上，邻档之间的比较信息量最大；档位间距在视野意义上大致等倍，兼顾了粗调与细调的连续性。

关键代码与解读

片段 1：候选档位与视野合理性检查

from ray import tune

def horizon(gamma):
    """有效视野：折扣权重衰减到约 1/e 的步数。"""
    return 1.0 / (1.0 - gamma)

def horizon_ok(gamma, episode_len=60, factor=3.0):
    """合理性判据：视野应覆盖环境回合长度的数倍。"""
    h = horizon(gamma)
    return h >= factor * episode_len, h

# 先做范围审查：不合适的档位在进入空间前被剔除
for g in (0.99, 0.995, 0.999):
    ok, h = horizon_ok(g)
    print(f"gamma={g}: 视野约 {h:.0f} 步，{'保留' if ok else '剔除'}")

search_space = {
    # 通过审查的档位才有资格进入搜索：离散候选对应行为差异明显的点
    "gamma": tune.choice([0.995, 0.999]),
    # lambda 在 0.9 至 1.0 区间行为平滑，用均匀分布
    "lambda": tune.uniform(0.9, 1.0),
    # 配套参数沿用优化参数族的结论，避免同时改两类参数
    "lr": 2e-4,
    "train_batch_size": 4096,
}

解读：这段代码把“先审查后搜索”写进了流程。（1）视野函数是可复算的判据，任何候选档位进空间之前都过一遍审查，剔除环境时域明显不匹配的值；元组返回让判据与数值同时可见，便于写入口径卡。（2）审查通过后空间只保留 0.995 与 0.999 两档，预算集中在有行为差异的位置。（3）λ 用均匀分布：0.93 与 0.95 的差异在本任务的衰减长度意义上连续变化，无需预设档位；若后续判读发现优势集中在小范围，下一轮再改离散。（4）优化参数固定为上一章结果，保证本轮的差异只来自信用分配参数。

片段 2：预算依赖的排名快照

import pandas as pd

def budget_dependence(df, metric="episode_return_mean",
                      checkpoints=(30, 60, 90), tail=5):
    """三个预算切点上的分组均值：排名随预算变化即判预算依赖。"""
    g_of = df.groupby("trial_id")["gamma"].first()
    out = {}
    for c in checkpoints:
        snap = (df[df["epoch"] <= c].sort_values("epoch")
                  .groupby("trial_id").tail(tail)
                  .groupby("trial_id")[metric].mean())
        out[f"epoch<={c}"] = snap.groupby(g_of).mean().sort_index()
    table = pd.DataFrame(out).round(1)
    # 首末两列的排名差是非零向量时，结论必须标注预算依赖
    delta = (table.iloc[:, -1].rank(ascending=False)
             - table.iloc[:, 0].rank(ascending=False))
    print(table)
    print(f"首末排名差：{delta.to_dict()}")
    return table

snapshot = budget_dependence(coarse_df)

解读：快照函数把预算依赖变成可检查的输出。（1）三个切点取计划的 1/3、2/3 与全程，既覆盖成长段也覆盖平台段；每档用尾段均值（最后 5 条）抵抗单点噪声，口径与第 071 章一致。（2）分组均值按折扣因子档位聚合，读者可直接比较排名在各列的移动方向。（3）首末排名差提供自动判据：非零即标注“预算依赖”；差值方向指向“大折扣因子在长预算下上移”时，说明短预算结论不可用于淘汰该档位。（4）快照结果应写入报告的证据链，与最终复验结论并列。

片段 3：λ 与价值学习质量的对照表

import pandas as pd

def lambda_effect(df, metric="episode_return_mean",
                  ev="explained_variance", tail=10):
    """按 λ 分桶：回报水平与解释方差并列，观察评论家压力。"""
    final = (df.sort_values("epoch").groupby("trial_id").tail(tail)
               .groupby("trial_id").agg(
                   lam=("lambda", "first"),
                   ret=(metric, "mean"),
                   ev=(ev, "mean")))
    # 分桶边界覆盖 0.9 至 1.0 的常用区间
    bins = pd.cut(final["lam"], bins=[0.89, 0.93, 0.96, 0.99, 1.01])
    summary = (final.groupby(bins, observed=True)
                    .agg(ret=("ret", "mean"),
                         ev=("ev", "mean"),
                         n=("ret", "size")))
    print(summary.round(3))
    return summary

summary = lambda_effect(coarse_df)

解读：对照表把两个视角装进一张表。（1）回报列回答“λ 档位与最终水平的关系”，解释方差列回答“价值网络在该档位是否学得动”；两者同向时才给出强结论。（2）分桶样本数（n 列）必须一并阅读：极端桶（接近 1.0 或 0.9）如果样本稀疏，桶均值波动大，应改看散点或加密采样。（3）典型形态是 λ 升高时回报略升、解释方差略降；若某档位回报高但解释方差显著塌陷，标记为“需复验”并检查优势估计的噪声水平。（4）解释方差字段名以 RLlib 训练结果为准，不同版本可能给出均值或末值形态，使用前先确认口径；相关的配置与结果字段名以对应版本的官方文档为准。

常见坑

  • 折扣因子用连续分布搜索：0.990 与 0.991 的行为差异不可观测，预算被消耗在等价点之间。修复：使用行为差异明显的离散档位，间距按视野等倍设计。
  • 短预算淘汰大折扣因子：预算不足时大折扣因子的长程收益尚未显现，排名系统性偏低。修复：多预算快照判读，排名随预算变化时标注预算依赖，不做淘汰结论。
  • γ 与 λ 全因子大范围搜索：等价带内的组合互相冗余，优势矩阵大片等值。修复：分层搜索或小规模网格先取结构信息，再收窄范围。
  • 忽略时间截断与折扣的交互：回合被最大步数截断时，大折扣因子的回报估计偏置被放大，误判为参数不佳。修复：确认截断处的自举处理生效，或把视野控制在截断长度的合理倍数内。
  • 不看解释方差就下结论：回报高但价值估计不稳的配置被选为最优，复验时回落。修复：对照表双指标判读，解释方差低的档位进入复验清单。

练习与思考

  1. 算一算：折扣因子 0.98 与 0.998 的有效视野各是多少步？若任务关键因果链跨越 300 步，两档的匹配判断分别是什么？★
    提示
    0.98 视野约 50 步，覆盖不住 300 步的因果链；0.998 约 500 步，覆盖有余。前者可能学出短视策略，后者需要更长预算与更强的价值学习。
  2. 预测题：固定 λ=0.95，把折扣因子从 0.995 提到 0.999，前 1/3 预算的排名与全程排名各会怎样变化？解释方差曲线有什么形态差异？★★
    提示
    前段小折扣因子领先（学得快），全程可能被大折扣因子反超（上限高）；大折扣因子的解释方差在前段偏低并缓慢爬升，这是“价值学习跟不上”的典型形态。
  3. 设计题：为一次 24 个试验的预算设计信用分配参数搜索：给出分层或网格的选择、每档折扣因子的试验数分配、预算下限与复验安排。★★★
    提示
    方案示例：12 个试验做 γ 两档 × λ 均匀采样；12 个试验在优胜档位做 λ 加密。预算下限按视野覆盖关键因果链的步数换算迭代数；复验给前两档各 5 个种子。
  4. 推导题：从 GAE 递推定义出发，推导衰减长度 1/(1−γλ) 的形式，并说明 γλ 接近 1 时对优势估计方差的影响。★★★
    提示
    几何权重和 Σ(γλ)k 的衰减尺度为 −1/ln(γλ)≈1/(1−γλ)；乘积接近 1 时有效叠加项数剧增，优势估计接近蒙特卡洛，方差随叠加项数增长。
  5. 实践题：用片段 2 的输出写一段结论草稿，要求正确使用“预算依赖”措辞，并给出下一步实验的两个选项。★★
    提示
    草稿应区分“当前预算下更优”与“长期更优”；两个选项为延长预算复验大折扣因子档位，或在当前预算下接受小折扣因子并在报告中限定适用范围。

小结

  • 有效视野 1/(1−γ) 是折扣因子的第一判据；视野应覆盖任务关键因果链的数倍。
  • GAE 的两端行为清晰：λ=0 单步自举低方差高偏差，λ=1 蒙特卡洛无偏但方差最大；衰减长度约 1/(1−γλ)。
  • γ 与 λ 通过乘积耦合，存在等价带；联合搜索优先分层，小网格用于取结构信息。
  • 预算依赖排名是本参数族的核心陷阱；多预算快照与首末排名差是标准判读手段。
  • 解释方差与回报并列判读，解释方差低的档位进入复验清单，暂不直接采纳。
