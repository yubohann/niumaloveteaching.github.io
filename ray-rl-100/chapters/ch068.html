第四篇 · Ray Tune 超参搜索

第 068 章：实验可视化与结果分析

可视化是判读工具：曲线回答收敛问题，散点回答主效应问题，平行坐标回答组合问题。本章讲清结果数据的三层组织、跨试验聚合的对齐口径与幸存者偏差，以及四类图各自能回答与不能回答的问题。

  • 主题：Ray Tune 调优 / 结果分析与可视化
  • 关键机制：长表聚合、分位带、参数效应散点、秩序相关、幸存者偏差
  • 预计学时：50 分钟
  • 前置章节：第 067 章

学习目标

  • 理解结果数据的三层视图：试验清单、迭代级曲线、跨试验聚合表，以及各层的读取接口。
  • 掌握跨试验聚合的对齐口径：公共预算网格、分位带、存活数标注，会解释幸存者偏差如何影响后期曲线。
  • 会用参数效应视图判读主效应：数值参数的秩序相关、分类参数的分组均值、边界聚集的信号。
  • 会组合使用四类视图（曲线、散点、平行坐标、相关表）回答不同问题，并说明每类视图的边界。
  • 会用 TensorBoard 做运行期监控、用结果表做离线聚合，理解两者职责划分。

背景与动机

搜索跑完后，结果以“每试验每迭代一条记录”的形式存储，动辄数万行。直接把全部曲线画在一张图上会得到一团线，看不出任何结构；只挑最漂亮的一条展示又会引入选择偏差。结果分析的核心是把原始记录加工成能回答具体问题的视图：这个参数是否有主效应、搜索是否覆盖了最优区域、性能差异是否超过噪声。

上一章保证了结果在分布式环境下完整落盘，本章处理“读得懂”。判读方法与前几章的设计决策一一对应：空间设计决定散点图的形状，调度器决定曲线的长度分布，约束处理决定可行率视图。分析不是事后点缀，它检验的是前述每一层设计是否按预期工作。

核心原理

1. 结果数据的三层视图

第一层是试验清单：每个试验一行，包含配置、最终状态、检查点索引，用于回答“有哪些试验、各自结局如何”。第二层是迭代级曲线：每个试验一条时间序列，横轴是预算量（迭代数或环境步数），用于回答“训练过程是否健康”。第三层是跨试验聚合表：把全部曲线对齐到公共预算网格后聚合，用于回答“总体趋势与离散程度”。三层之间的转换要点只有一条：所有跨试验比较都发生在同一预算刻度上，第 062 章的同预算可比性原则在这里从调度侧延伸到分析侧。

agg(g) = { mean, q25, q75, nalive }( { fi(g) | 试验 i 在预算 g 有记录 } ) fi(g) 取“不超过 g 的最后一条记录”；nalive 随 g 变化的形态暴露幸存者偏差

2. 幸存者偏差与截尾

早停调度器会把弱试验提前终止，后期的聚合池里只剩下强者。分位带在后期收窄有两个来源：真实方差下降，或弱样本被淘汰。两者的含义完全不同，必须用存活数曲线区分：存活数稳定说明收窄来自真实收敛；存活数下降说明收窄来自截尾，此时的均值应标注“仅统计存活者”。报告口径建议固定三种写法：全体均值（含截尾警告）、存活者均值、固定试验集合（只统计跑满预算的试验），三者对照使用。

3. 平滑与原始曲线

训练曲线叠加环境与评估噪声，直接观察趋势困难。指数滑动平均（Exponential Moving Average, EMA）是常用平滑手段，窗口参数决定趋势可见性与延迟的取舍：窗口大时趋势清晰但拐点被推迟显示；窗口小时噪声残留，容易把波动误读为趋势。规范做法是双图并看：平滑曲线用于判读趋势，原始曲线用于检测崩溃与异常尖峰。任何报告都应注明平滑参数，否则同一份数据的“趋势”会随窗口选择而变。

4. 四类视图与各自边界

学习曲线回答收敛速度与稳定性问题；单参数分辨率有限，需要配合分位带。参数散点图（横轴参数值、纵轴预算末端的指标）回答主效应问题：单调趋势提示方向，贴边聚集提示边界需要外扩（回到第 061 章的判读规则），散布无结构提示该参数在当前范围内不敏感。平行坐标图把 top-K 试验与全体试验画在同一张多维图上，回答组合模式问题：哪些参数的取值在 top-K 中高度一致，哪些参数保持分散。秩序相关表把参数按与指标的秩相关排序，回答“先调哪个”的问题；它的边界是只见关联、不见因果，参数之间的相关性会让排序互相污染。

5. 运行期与离线分析的分工

运行期可视化（以 TensorBoard 为代表）的价值在“及时发现异常”：曲线长时间平坦、损失发散、吞吐骤降，都需要在实验进行中暴露，以便中断或修正。离线分析（结果表加工）的价值在“口径可控”：聚合方式、过滤条件、对齐网格都由分析者显式定义。两者使用同一份底层记录，职责区分是时间点：运行期回答“要不要继续”，离线回答“结论是什么”。报告只引用离线口径的数据，运行期曲线作为过程证据。

实现思路与设计

结果分析按固定管道执行：清洗、聚合、出图、落结论。与上一章的差异在于，第 067 章保证数据完整送达，本章把数据加工成决策依据。

  1. 清洗：按试验状态过滤（剔除错误试验），按预算轴去重（第 064 章的审计），确认配置列可用。
  2. 聚合：选定公共预算网格（建议 15 至 20 个点），生成均值与分位带，同时输出存活数序列。
  3. 出图：曲线看趋势、散点看主效应、平行坐标看组合；每个视图配一句“它回答什么、不回答什么”的图注。
  4. 落结论：把观察写入实验记录：参数方向、边界信号、性能离散度、下一步动作，一条观察对应一条证据。
视图回答的问题读数口径常见误读
分位带曲线收敛速度与稳定性同预算聚合、标注存活数把截尾收窄读成收敛
参数散点主效应与边界信号预算末端每试验一个点用单点极值代替分布
平行坐标top-K 的组合模式top-K 与全体对照颜色映射暗含因果暗示
秩序相关表参数重要性排序统一预算点、秩相关关联被当作因果
设计决策：为什么聚合网格取 15 至 20 个点？

网格过密时，相邻点之间的数据几乎相同，噪声被放大成锯齿；网格过疏时，拐点与平台被抹平。15 至 20 个点对应一条曲线 3 至 5 个可辨识的阶段，足以判读趋势且不制造伪波动。网格密度选择与平滑窗口配合：网格疏时无需平滑，网格密时配小窗口 EMA。

关键代码与解读

片段 1：跨试验的分位带聚合

import pandas as pd

def curve_bands(df, step="epoch", metric="episode_return_mean",
                grid=None):
    """按公共预算网格聚合：输出均值、四分位带与存活数。"""
    if grid is None:
        grid = list(range(0, 81, 5))   # 15 至 20 个点覆盖整段预算
    out = []
    for g in grid:
        # 取每个试验“不超过 g 的最后一条记录”，实现前向对齐
        sub = (df[df[step] <= g]
               .sort_values(step)
               .groupby("trial_id").last())
        out.append({
            "step": g,
            "mean": sub[metric].mean(),
            "q25": sub[metric].quantile(0.25),
            "q75": sub[metric].quantile(0.75),
            # 存活数序列：区分真实收敛与截尾收窄的关键列
            "alive": len(sub),
        })
    return pd.DataFrame(out)

bands = curve_bands(results_df)
print(bands.tail(3))   # 检查后期存活数是否下降

解读：聚合函数的四个设计点各有出处。（1）前向对齐（取不超过网格点的最后一条记录）保证每个试验在每个网格点至多贡献一个值，避免同一试验的重复计数。（2）四分位带比标准差稳健：回报分布右偏时，标准差被极端值抬高，分位带忠实呈现主体范围。（3）存活数列与均值列同等重要：后期存活数骤降时，均值列必须标注“仅存活者”。（4）网格作为参数可调，便于与第 072 章的对比实验复用同一口径。结果表列名在不同版本间略有差异，以对应版本的官方文档为准。

片段 2：参数效应视图

def param_effects(df, params, metric, cutoff=80):
    """主效应判读：数值参数算秩相关，分类参数算分组均值。"""
    # 每试验取预算末端的一条记录：比较发生在同一预算刻度上
    final = (df[df["epoch"] <= cutoff]
             .sort_values("epoch")
             .groupby("trial_id").last())
    report = []
    for p in params:
        col = final[p]
        if col.dtype == object:   # 分类参数（如激活函数）
            means = final.groupby(p)[metric].mean().sort_values()
            report.append((p, "categorical", means.to_dict()))
        else:                     # 数值参数：秩序相关对单调性无假设
            rho = final[[p, metric]].corr(method="spearman").iloc[0, 1]
            report.append((p, "spearman", round(float(rho), 3)))
    # 按相关强度排序：给出“先调哪个参数”的行动顺序
    report.sort(key=lambda r: -abs(r[2]) if r[1] == "spearman" else 0)
    for row in report:
        print(row)
    return report

param_effects(results_df,
              ["lr", "train_batch_size", "entropy_coeff"],
              "episode_return_mean")

解读：主效应视图的两个分支对应两类参数。（1）数值参数用 Spearman 秩序相关：它只依赖排序，对非线性的单调关系同样敏感，比 Pearson 更贴合“参数越大越好还是越差”的判读提问。（2）分类参数直接输出分组均值，激活函数、优化器这类参数没有秩序，分组是唯一有意义的比较方式。（3）相关性排序只是线索：参数之间的相关（例如学习率与批量在空间设计里联动）会污染单个参数的排序，行动前应回到散点图确认趋势形态。（4）截断点 80 与聚合网格的末端一致，保证散点与曲线引用同一批记录。

解读：这段配置明确两种可视化的分工。（1）TensorBoard 回调把逐迭代指标写成事件文件，供运行中打开查看；它的目录跟随实验目录，天然按试验分子目录组织。（2）log_to_file 让结果同时以文本与结构化形式落盘，离线聚合用的是同一份记录的另一种视图，两个口径不会打架。（3）verbose 控制的是什么进终端：并发 40 个试验时逐条打印会淹没关键信息，阶段汇总才是运行期该看的。回调类与日志接口在 2.x 演进中调整过命名，以对应版本的官方文档为准。

常见坑

  • 不同长度的曲线直接同图叠加：后期只剩少数长试验，视觉上“整体还在上升”，实际是样本结构变化。症状是总图与分位带图的形状矛盾。修复：统一用公共网格聚合，并附存活数曲线。
  • 平滑窗口过大掩盖崩溃：训练中途发散后短暂恢复，大窗口 EMA 把它抹成小凹陷，判读为“稳定”。修复：双图并看，原始曲线单独保留，报告中注明窗口参数。
  • 只展示 best 一条曲线：最优曲线来自数十个试验的挑选，包含选择偏差，无法代表方法的稳定水平。修复：展示 top-K 均值带与全体分位带对照。
  • 用末端单点极值代替分布：挑选指标最高的一帧截图作结论，忽略评估噪声与相邻帧的波动。修复：末端指标取最后 K 次迭代的均值，并给出分位区间。
  • 未完成的试验混入聚合：错误试验或预算中等的试验把短序列混进后期网格，均值被拉低或抬高。修复：清洗阶段按状态过滤，聚合阶段只做前向对齐、不做外插。

练习与思考

  1. 算一算：给出 5 个试验在预算 60 处的指标值 [120, 140, 150, 160, 180]，计算均值与四分位带，并说明 5 个样本下四分位数的稳健性局限。★
    提示
    均值 150；四分位数近似为 140 与 160。样本量 5 时分位估计的抖动很大，报告里应同时给出样本数，避免读者误读为精确区间。
  2. 预测题：把平滑窗口从 5 个点增大到 20 个点，曲线上的三类事件（上升趋势、崩溃后恢复、平台期）各会发生什么变化？★★
    提示
    趋势更平滑但拐点推迟；崩溃后恢复被压缩成浅坑甚至消失，这是最危险的变化；平台期的波动被抹平，变得更容易判读。
  3. 设计题：为一次 60 试验的搜索设计三视图分析计划：每个视图给出数据准备方式、观察目标与一条判读规则，并写明三个视图之间的交叉验证关系。★★★
    提示
    曲线找异常试验、散点定主效应方向、平行坐标看 top-K 组合；交叉验证关系示例：散点提示学习率有强主效应，平行坐标中 top-K 的学习率应集中在该方向对应的区间，两个视图结论一致才立案。
  4. 推导题：若早停淘汰比例为 50%，解释后期网格点的存活均值与全体真实均值之间的偏差方向，并构造一个使其无偏的统计口径。★★★
    提示
    被淘汰者按调度规则系统性地偏弱，存活均值系统性高估；无偏口径需要回到同预算点比较全部试验（被淘汰者在淘汰前的记录仍有效），或在固定试验集合上比较。
  5. 实践题：对片段 2 的输出做混杂检查：若学习率与批量在空间中是联动采样的，解释它会如何影响两者的秩序相关排序，并给出一种消解方式。★★
    提示
    联动使两个参数的变化同步，各自与指标的秩相关混合了对方的贡献，排序失真。消解方式：在联动的一个参数上分层（固定其取值区间），分层内重算秩序相关。

小结

  • 结果数据有三层视图：试验清单、迭代级曲线、跨试验聚合表；跨层比较以同预算刻度为准。
  • 分位带配存活数曲线使用；存活数下降时，后期收窄来自截尾效应，与真实收敛无关，报告必须标注口径。
  • 平滑用于趋势、原始曲线用于异常检测；两者并看并注明平滑参数。
  • 四类视图各司其职：曲线看收敛、散点看主效应、平行坐标看组合、相关表看重要性；关联判读要防混杂。
  • 运行期可视化回答“要不要继续”，离线聚合回答“结论是什么”，报告引用离线口径。
