第 078 章：超参搜索实战：熵系数与KL约束

熵系数管理策略的随机性，KL 约束管理每次更新的距离。本章讲清熵正则的作用与熵塌缩的机理、KL 惩罚与目标值的自适应逻辑、两个开关与学习率的共线性，以及熵轨迹分类与 KL 达成度的判读方法。

  • 主题：超参搜索实战 / 探索与信任域参数族
  • 关键机制：熵正则、熵塌缩、KL 信任域、自适应惩罚、共线性
  • 预计学时：55 分钟
  • 前置章节：第 077 章

学习目标

  • 理解熵正则项的作用机理：维持策略分布的可塑性，防止过早确定化。
  • 掌握熵轨迹的三种典型形态（缓降、早期塌缩、高熵停滞）与对应的参数方向判断。
  • 理解 KL 约束的两层结构：目标值定义更新距离的上限，惩罚系数由自适应机制调节。
  • 会识别熵系数、KL 参数与学习率的共线性，并用分层搜索避免三者同时大范围变动。
  • 会判读 KL 达成度：实际 KL 与目标值的比值分布，比值异常时给出调整方向。

背景与动机

策略梯度的两个失败模式都与本章的参数族相关：其一是过早确定化，策略在探索不足时锁定到次优行为，分布方差塌缩后再也无法纠正；其二是更新越界，一次过大的策略更新离开旧数据的有效范围，后面的优化建立在失真的优势估计上。熵系数与 KL 约束分别针对这两个失败模式，它们是策略优化稳定性控制的两只手。

这对参数与前面两组的关系是递进的：优化参数族决定步长，信用分配参数族决定目标视野，本章参数族决定“分布形状与更新幅度”。三组参数存在跨族交互（熵系数与学习率的梯度项叠加、KL 上限与学习率互相替代），搜索安排上必须错开，本章给出的分层顺序就是为此设计的。

核心原理

1. 熵正则与可塑性

熵度量策略分布的随机程度。在损失中加入熵奖励项后，目标变为策略损失减去 β·H(π)：β 越大，策略被推向更高熵的分布，探索更广；β 越小，利用（Exploitation）越强，收敛更快但风险是过早确定化，即熵塌缩（Entropy Collapse）。离散动作空间的熵上界是 ln|A|（动作数 2 时约 0.69，动作数 6 时约 1.79），熵指标读数必须对照该上界；连续动作空间的熵由各维分布参数决定，读数含义不同。

L = Lpolicy − β·H(π),   H(π) ≤ ln|A|（离散动作） β 的作用是推迟确定化；塌缩发生在分布方差趋零时，一旦发生不可逆，早期轨迹是唯一判据窗口

2. KL 约束的两层结构

信任域（Trust Region）限制每次更新后新旧策略的 KL 距离，保证优势估计所依赖的旧数据仍然有效。PPO 的实现把约束做成罚项：目标减去 c·KL，其中目标距离由 kl_target 定义，惩罚系数 c（kl_coeff）由自适应机制根据实际 KL 调整。典型自适应逻辑是：实际 KL 超过目标 1.5 倍时系数加倍，低于目标 2/3 时系数减半，使实际 KL 稳定在目标附近；目标值太小时更新过慢，训练停滞；太大时信任域失去意义，更新退化为无约束的大步。

L = Lpolicy − c·KL(πold, π),   c 自适应：KL > 1.5·目标 → c×2；KL < 目标/1.5 → c÷2 目标值决定“允许走多远”，系数决定“当前罚多重”；两者分工不同，搜索时分开看待

3. 与学习率的共线性

学习率、KL 惩罚、熵系数都会影响“单次更新改变策略的幅度”，在效应上存在替代关系：学习率调小与 KL 惩罚调大都减慢策略变化；熵系数偏大时策略更随机，KL 通常也更大，自适应机制随即抬高系数。三者的共线性意味着“同时大范围搜索”的方案下，交互表难以归因。推荐的搜索安排是分层：固定学习率（沿用第 076 章结论）搜索熵系数与 KL 目标；收敛后再联合微调学习率，观察 KL 达成度是否随之移动。

4. 熵轨迹的三种形态

熵的演化轨迹是判读熵系数最直接的窗口：缓降（从接近上界逐步下降并稳定在中间水平）是健康形态，探索逐步让位于利用；早期塌缩（前少量迭代内跌到接近零）说明熵系数过小或学习率过大，策略已难以恢复随机性；高熵停滞（全程贴近上界不降）说明熵系数过大，策略拒绝确定化，回报水平通常偏低。

判读的时间窗必须在早期：塌缩不可逆，后期曲线只能是塌缩之后的景象。搜索中的早停调度器对这种参数族特别合适：塌缩与停滞在前 20% 预算内即可分辨，淘汰决策的误伤成本低。

5. KL 达成度与调整方向

实际 KL 与目标值的比值是第二判读窗口：比值稳定在 0.5 至 1.5 之间说明自适应机制正常工作；比值长期远小于 1 说明更新没有被 KL 约束卡住，停滞的原因在别处（学习率过小、数据复用不足）；比值剧烈超调并震荡说明系数自适应跟不上学习率或批量变化，需要先调低学习率或抬高目标值。比值指标应与回报水平对照：KL 达标但回报不涨，说明瓶颈不在信任域，不要继续在 KL 参数上花费搜索预算。

实现思路与设计

搜索设计按“定层次、设范围、错交互、早判读、终复验”五步执行。与上一章的差异在于，第 077 章调目标视野，本章调分布形状与更新幅度，且本族参数与学习率的交互最重。

  1. 定层次：先搜熵系数（影响探索），再搜 KL 目标（影响更新距离），最后联合微调；不把三个开关同时铺开。
  2. 设范围：熵系数用低端对数均匀（1e−4 至 1e−2），KL 目标用离散档位，惩罚系数给自适应机制一个中值起点。
  3. 错交互：学习率在熵与 KL 的搜索阶段保持固定值，避免共线性污染归因。
  4. 早判读：前 20% 预算内做熵轨迹分类，塌缩与停滞的配置尽早淘汰，把预算让给健康轨迹。
  5. 终复验：入围配置检查 KL 达成度与回报是否同向，同向才进入交付。

设计决策：为什么熵轨迹要在前 20% 预算内判读？

熵塌缩由分布方差趋零触发，一旦发生，策略的采样范围不再覆盖被放弃的行为，后续梯度无法把它拉回；健康形态与异常形态的差异在塌缩发生的时刻就固定下来。把判读窗口放在前 20%，能在预算尚未大规模消耗时识别两类异常，剩下的 80% 预算留给健康配置的深度训练。这一安排与 ASHA 的分档结构天然配合：低预算档位就能完成形态分类。

关键代码与解读

片段 1：本族参数的搜索空间

from ray import tune

search_space = {
    # 熵系数：有效值集中在低端，对数均匀在低端给出更高采样密度
    "entropy_coeff": tune.loguniform(1e-4, 1e-2),
    # KL 目标：定义单次更新的距离上限，离散档位覆盖一个数量级
    "kl_target": tune.choice([0.01, 0.02, 0.05]),
    # 惩罚系数初值：自适应机制会接管，初值只影响启动期的节奏
    "kl_coeff": tune.choice([0.2, 0.5, 1.0]),
    # 学习率固定：与 KL 惩罚存在替代效应，本阶段不参与搜索
    "lr": 2e-4,
    "train_batch_size": 4096,
    "gamma": 0.995,        # 信用分配参数沿用上一章结论
    "lambda": 0.95,
}

# PPO 配置中的对应开关（字段名以对应版本的 RLlib 文档为准）：
#   use_kl_loss=True 启用 KL 罚项；kl_target 与 kl_coeff 如上
#   训练结果中读取 kl 与 entropy 两条曲线用于判读

解读：空间设计把三层分工写得很直白。（1）熵系数的范围取两个数量级；再往上的值会在高熵停滞区浪费预算，再往下的值在大多数任务上等价于关闭探索。（2）KL 目标与惩罚系数分开采样：目标决定约束位置，系数初值只影响启动期的收敛速度；自适应机制接管后，系数的长期行为由实际 KL 与目标的比值驱动。（3）学习率与信用分配参数全部固定：本阶段只允许探索与信任域相关的变量变化，差异才能干净归因。RLlib 的开关命名与默认值随版本演进，以对应版本的官方文档为准。

片段 2：熵轨迹三分类

def classify_entropy(series, high_frac=0.9, collapse=0.05):
    """按熵轨迹分类：缓降 / 早期塌缩 / 高熵停滞。"""
    upper = max(series[0], 1e-9)     # 以起点为参照的“接近上界”判据
    start = sum(series[:5]) / 5
    mid = sum(series[len(series) // 2 - 2: len(series) // 2 + 3]) / 5
    end = sum(series[-5:]) / 5
    if start >= upper * high_frac and end >= start * 0.9:
        kind = "高熵停滞"    # 全程贴近起点（上界）：熵系数过大
    elif end <= collapse:
        kind = "早期塌缩"    # 跌至接近零：熵系数过小或步长过大
    else:
        kind = "缓降"        # 逐步下降：健康形态
    print(f"熵 {start:.2f} -> {mid:.2f} -> {end:.2f}：{kind}")
    return kind

# 使用：从每条试验曲线提取 entropy 序列后逐条分类
# kinds = [classify_entropy(curve) for curve in entropy_curves]

解读：分类器的阈值设计围绕“可判读性”。（1）“高熵停滞”用起点与末值的相对关系判定：末值不低于起点的九成且起点本身接近上界，说明策略几乎没有确定化。（2）“早期塌缩”用末值阈值判定，塌缩后的末值稳定在极小值附近，异常足够醒目；实现中若需要更精确的“早期”判据，可扫描首次跌破阈值的位置。（3）分类结果用于分派动作，不充当终局结论：塌缩配置关闭熵系数维度的低位候选，停滞配置抬高范围下界，缓降配置进入性能排序。（4）离散动作空间的熵上界是 ln|A|，判读时把上界一并打印，避免对不同动作数任务误用固定阈值。

片段 3：KL 达成度分组表

def kl_report(df, tail=10):
    """KL 达成度：实际 KL 与目标的比值，按目标档位聚合。"""
    agg = (df.sort_values("epoch").groupby("trial_id").tail(tail)
             .groupby("trial_id").agg(
                 target=("kl_target", "first"),
                 kl=("kl", "mean"),
                 ret=("episode_return_mean", "mean")))
    # 比值接近 1 表示自适应机制把 KL 稳定在目标附近
    agg["ratio"] = agg["kl"] / agg["target"]
    summary = agg.groupby("target").agg(
        kl=("kl", "mean"), ratio=("ratio", "mean"),
        ret=("ret", "mean"), n=("ret", "size"))
    print(summary.round(4))
    return summary

summary = kl_report(reg_df)
# 比值长期低于 0.5：约束未起作用，瓶颈不在此处，改查学习率与数据复用

解读：分组表把 KL 判读做成一次聚合。（1）聚合单元与前述章节一致：尾段均值、按试验、按配置档位分组；n 列提示每档样本量。（2）比值列是核心输出：三档目标的比值各自接近 1 时，自适应工作正常，继续比较回报列；某档比值显著偏离时，先查该档的学习率与批量是否与本组不一致。（3）“比值远小于 1”的解释要克制：它只说明 KL 没被顶到目标，不足以证明参数组合有问题，下一步应检查更新幅度是否由其它因素限制。（4）训练结果中的 KL 字段命名随 RLlib 版本变化（有时嵌套在学习器统计中），使用前确认提取路径。

常见坑

  • 熵系数范围整体偏高：1e−1 以上的取值几乎全部落入高熵停滞区，回报低且预算被浪费。修复：范围从 1e−4 至 1e−2 起步，依据熵轨迹分类结果决定下界是否再降。
  • 学习率、KL 惩罚、熵系数同时大范围搜索：三者共线性导致优势组合无法归因，交互表呈现杂乱的大片区域。修复：分层搜索，每个阶段只放飞一个开关，学习率作为不变量。
  • 只看熵的末值：塌缩发生在早期，末值已无法区分“一直低”与“早期骤降”；两类问题的修复方向不同。修复：判读窗口放在前 20% 预算，用轨迹三分类替代单点读数。
  • KL 目标设得过小：更新被压得过慢，训练曲线平缓，误判为“参数稳定”。修复：对照达成度比值与回报斜率，比值常年远小于 1 说明约束过紧或未起作用，抬高目标值观察。
  • 把 SAC 的自动熵目标与 PPO 的熵系数混用经验值：两者的机制不同（自动温度调节对固定系数），互相套用范围会造成系统性偏差。修复：按算法族分别维护参数范围表。

练习与思考

  1. 算一算：动作数分别为 2 与 6 的离散任务，策略熵的上界各是多少？若某配置的熵稳定在 0.3，在两任务中分别意味着什么？★
    提示
    上界为 ln2≈0.69 与 ln6≈1.79。0.3 在任务一中是中等偏低（部分确定化），在任务二中已是明显塌缩方向；同一读数在不同动作数下的含义不同。
  2. 预测题：把熵系数从 1e−3 提到 1e−1，熵轨迹、KL 比值与最终回报各会如何变化？三者的因果链条如何排列？★★
    提示
    熵上移接近上界（停滞），策略更随机使 KL 上升，自适应抬高惩罚系数，更新幅度被压缩，回报通常下降；链条是“熵系数 → 分布随机性 → KL → 自适应系数 → 实际更新幅度”。
  3. 设计题：为一次三阶段搜索设计本族参数的计划：熵系数阶段、KL 阶段、联合微调阶段的试验数、范围与判据，并说明学习率在各阶段的角色。★★★
    提示
    阶段一 20 个试验扫熵系数；阶段二固定熵系数最优档，扫 KL 目标与系数初值；阶段三在两者最优邻域内联合微调，学习率在阶段一、二固定，阶段三允许 ±1 档。
  4. 推导题：写出离散策略熵 H=−Σ pa log pa 在“均匀分布”与“确定性分布”两个端点的取值，并解释熵系数梯度在两端的行为差异。★★★
    提示
    均匀分布 H=ln|A|，确定性分布 H=0。熵奖励梯度在均匀处最小（接近平坦），在确定性附近最大（把概率质量从极大项拉回），这正是熵系数在低熵区“拖回”能力强、在高熵区“推不动”的原因。
  5. 实践题：对一次已完成搜索提取熵曲线并三分类，统计各类占比与对应的回报分布，给出下一轮范围的两处修改。★★
    提示
    塌缩占比高时抬高熵系数的下界；停滞占比高时降低上界；两处修改都用占比数据支撑，不凭单条曲线的印象。

小结

  • 熵系数维持策略分布的可塑性；塌缩不可逆，判读窗口必须在早期。
  • 熵轨迹三分类（缓降、早期塌缩、高熵停滞）直接对应范围调整方向；读数要对照 ln|A| 上界。
  • KL 约束两层结构：目标定义允许距离，惩罚系数自适应调节；比值 0.5 至 1.5 为健康区。
  • 学习率、KL 惩罚、熵系数存在共线性；搜索分层进行，每阶段只放飞一个开关。
  • KL 达成度与回报同向才进入交付；比值异常时先查别处，不要在 KL 参数上过度消耗预算。
