第四篇 · 开放词汇与大模型

第 069 讲｜SG-Nav I：3D 场景图 + 分层 CoT

第 067 与 068 讲的 VLFM 用二维价值图给前沿做语义打分，语义信息以数值场的形式存在，不含物体之间的关系。本讲进入 SG-Nav（Yin 等 2024，Online 3D Scene Graph Prompting for LLM-based Zero-shot Object Navigation，arXiv:2410.08189，NeurIPS 2024）：把观测时的场景表示为在线增量维护的分层 3D 场景图，节点分物体、组、房间三层，边分属籍与同层关系两类；用分层链式推理（hierarchical chain-of-thought）让 LLM 遍历子图，先预测子图中心物体与目标的距离，再把子图概率按反距离插值到前沿，得到每个前沿的探索分数；场景图的增量构建用一次合并提示把 m(m+n) 对节点的关系预测压缩为单次调用，并配合长、短两条剪枝规则。结果面：SG-Nav 在 MP3D、HM3D、RoboTHOR 三个验证集上取得 40.1 / 16.0、53.9 / 24.8、47.3 / 23.7（SR / SPL，LLaMA-7B 版），相对 L3MVN 的 SR 增量为 5.2、5.2、6.1 个百分点，相对 ESC 为 11.4、14.7、9.2 个百分点，MP3D 上超过有监督的 SemEXP 与 PONI。本讲讲清图结构、增量构建与复杂度、四步 CoT 提示、前沿插值与传统意义上的结果与消融；重感知纠错机制留到第 070 讲。

  • 主题：分层 3D 场景图 / 在线增量构建 / 分层 CoT / 前沿概率插值
  • 关键公式：Pifro = Σj=1..M Pjsub / Dij；Tour / Tnaive = (1 + m(m+n)α)r / [m(m+n)(1+α)r]
  • 预计学时：80 分钟
  • 前置章节：第 068 讲（VLFM II：Spot 真机零样本）

学习目标

  • 会描述：分层场景图的三类节点（物体、组、房间）与两类边（跨层属籍、同层关系），并说明组字典的生成方式与作用。
  • 会推导与复算：一次合并提示把 m(m+n) 对关系预测压成单次调用的复杂度对比；子图概率到前沿分数的反距离插值。
  • 会实现：节点注册与跨帧合并、短边与长边两种剪枝、四步分层 CoT 提示协议、前沿评分的数据结构与数值防护。
  • 会读：与 L3MVN、ESC、VLFM、OpenFMNav 的增量，与有监督 SemEXP、PONI、ProcTHOR 的交叉，三个数据集的差异来源。
  • 会判断：组节点、房间节点、长边、短边、CoT 各自的消融增量；场景图表示的失效条件与跨论文引用数字的版本差异。

背景与动机

零样本 ObjectNav 的 LLM 路线此前有两种典型做法。L3MVN 与 ESC 把每个前沿附近物体的类别转成文本，让 LLM 直接输出每个前沿的可能性。SG-Nav 的引言指出这类做法有两个缺陷：提示中只有物体类别文本，缺少空间关系等场景上下文；要求 LLM 直接产出抽象的前沿概率，没有充分利用推理能力，决策过程也缺少解释性（Yin 等 2024，第 1 节）。VLFM 用视觉语言模型给出空间接地的语义值，但值仍是逐格数值，不含物体与物体、物体与房间的关系。SG-Nav 的思路是把观测整理成结构化表示：点云与 RGB-D 在线构建分层 3D 场景图，图结构同时保留空间关系与功能关系；决策时把图切成子图，用链式提问让 LLM 逐步推理“目标可能在哪个子图附近”，再把子图概率投影到前沿上。

本讲解决三个问题。第一，图怎么在线建：每个新检测到的物体如何注册、合并、连边、剪枝，且保持可实时运行的调用预算。第二，LLM 怎么被问：如何把图结构放进提示，如何让每步推理可解释，如何把语言输出的距离转成可比较的概率。第三，这套表示是否有效：三个数据集上相对前代方法的增量、各组件消融，以及与场景图表示自带的边界。第 070 讲再展开同一场景图支持的重感知纠错机制。

核心原理

1. 任务与总体流水线

任务设定沿用零样本 ObjectNav：智能体在未知环境中搜索类别由文本指定的目标物体；输入为带位姿的 RGB-D 观测，动作集合为前进、左转、右转、停止；在不超过 T 步内停在目标 ds 米以内则成功（Yin 等 2024，3.1 节）。实验参数为：最大步数 500，感知距离范围 1.5 至 10 m，每步前进 0.25 m，每次旋转 30°，相机高度 0.90 m，RGB-D 分辨率 640 × 480；占据图为 800 × 800 的二维栅格，分辨率 0.05 m，可表示 40 m × 40 m 的场景（本讲实算：800 × 0.05 = 40 m，共 640,000 格）（Yin 等 2024，4.1 节）。

流水线分四步。第一步，随探索在线构建分层 3D 场景图与占据图。第二步，每一步把场景图切成若干子图，每个子图由一个物体节点、它的父节点与直接相连的物体节点组成；用分层 CoT 让 LLM 输出该子图与目标同现的可能性 Psub。第三步，把子图概率按到前沿中心的反距离插值，得到前沿分数，选择分数最高的前沿。第四步，用快速行进法（Fast Marching Method）等局部规划器把运动指令落到动作空间（Yin 等 2024，3.3 节）。LLM 只负责“去哪一片区域”，几何可达性交给局部规划器，这一分工与 FBE 系列方法一致。

2. 分层 3D 场景图：节点、边与组字典

场景图定义三类节点。物体节点来自在线开放词汇 3D 实例分割：每帧检测并分割物体，同步重建点云，新实例与历史实例做匹配，匹配成功则合并，失败则注册为新节点；每个物体节点带语义类别与置信度。组节点把相关物体聚成整体，例如餐桌与周围椅子、电视与电视柜；注册规则是：两个物体节点间已有边且类别相关时建立组，迭代吸收直到没有新节点可加入。房间节点把房间当作实例处理，提示开放词汇分割模型以房间类型做分割（Yin 等 2024，3.2 节）。类别相关性查询预先生成字典，论文附录给出 26 组示例，包括（餐桌，椅子）（书柜，椅子）（冰箱，冰柜）（烤箱，微波炉）（沙发，桌子）（书桌，办公椅）（壁炉，壁炉架）（窗，窗帘）等（Yin 等 2024，6.2 节）。

边分两类。跨层边表示属籍：房间与物体之间，若物体的实例掩膜包含于房间掩膜，则物体属于该房间；房间与组之间，若组的全部物体属于该房间，则建立连接；组与物体之间不再另建边，因为组由物体定义。同层边表示物体之间的关系，可以是近邻物体间的空间关系，例如“在…上方”，也可以是远距离物体间的功能关系，例如电视与对面的沙发。同层边只存在于物体节点之间，组与房间之间不建同层边。

3. 在线增量构建、剪枝与复杂度

图的重建成本来自连边：t 时刻新增 m 个物体节点，与已有点集（n 个）之间的候选对数量为 m(m+n)。朴素做法对每对节点调用一次 LLM 推断关系，调用与成本都随对数线性增长。论文的压缩方式是“一次合并提示”：把所有候选对写成结构化列表交给 LLM，一次性输出全部关系。设提示与单条回答的 token 数分别为 Lpro 与 Lres，按 LLM 处理 L 个 token 的复杂度 O(Lr)（1 < r ≤ 2），两种做法的成本之比为：

Tour / Tnaive = (1 + m(m+n)α)r / [ m(m+n)(1 + α)r ] α = Lres / Lpro ≤ 0.01，1 ≤ m ≤ 5，1 ≤ n ≤ 100；论文目标是证明比值小于 c / (m+n)，即复杂度从 O(m(m+n)) 降到 O(m)

取典型参数 m = 5、n = 100、Lpro = 1,000、Lres = 10（α = 0.01）做实算。候选对为 525 对；朴素版本的 token 吞吐为 525 × (1,000 + 10) = 530,250，合并提示为 1,000 + 525 × (10 + 2) = 7,300，吞吐比约 1.38%。按 O(Lr) 计，r = 1 时时间比约 1.18%，r = 2 时约 7.29%（本讲实算）。论文附录给出上界 c / (m+n)，并写 c = 5.49，即 525 对情形下比值上界约 5.23%。这里有一处需要记录的推导细节：论文附录式 (8) 在化简系数时把带有前导 1 的 (1 + (m² + mn − 1)α)2 记成了以 (0.01m² + m − 0.01)² 为上界；代入 m = 5 时，保留前导 1 的系数为 7.79，论文形式为 5.49（本讲实算）。两个取值都落在 10% 以内的小百分数区间，结论“单次调用取代数百次调用、每新增节点的调用数从 m+n 次量级降到常数次”不受影响。复现时建议直接按上式代入自己的 m、n、α、r 计算，并把 c 的取值与推导口径一并写入实验记录。

稠密连边后做剪枝，规则按“是否存在同时包含两个物体的 RGB-D 帧”分两类。短边：存在这样的帧，用视觉语言模型（论文使用 LLaVA-1.6，Mistral-7B 底座）检查该关系是否成立，不成立则删除。长边：不存在共同帧，要求同时满足两条标准才保留，即两物体连线无遮挡且平行于房间墙体，且两物体属于同一房间节点（Yin 等 2024，3.2 与 4.1 节）。剪枝的作用在实验部分有消融证据。

4. 分层链式推理与子图概率

子图的构造规则是：以一个物体节点为中心，取它的父节点与直接相连的物体节点，构成一个小图。对每个子图，分层 CoT 用四步提示得到 Psub（Yin 等 2024，3.3 与 6.4 节）：第一步，预测该子图中心物体与目标物体之间最可能的距离，要求同时给出理由；第二步，让 LLM 针对“中心物体与目标”提出有助于预测距离的问题；第三步，把子图的节点与边、以及上一步的问题一起交给 LLM 回答；第四步，综合对话内容给出子图到目标的距离估计，取该距离的倒数作为 Psub。四步的作用分别是：先建立距离这一可量化目标，再让模型主动索取缺失信息，然后用图结构作答，最后汇总。相比直接问“该前沿有多大可能”，这条链路把抽象概率判断拆成可检查的距离推理，决策解释由距离最近的前三个子图的分析摘要给出。

得到子图概率后，第 i 个前沿的分数为：

Pifro = Σj=1..M Pjsub / Dij，  i ∈ {1, 2, …, N} M 为子图总数，N 为前沿数；Dij 为第 i 个前沿中心与第 j 个子图中心物体之间的距离

这个插值的性质可以先用一个小例子看清。设三个子图的概率为 0.5、0.3、0.2，距某前沿的距离为 2 m、4 m、8 m，则三项贡献为 0.25、0.075、0.025，前沿分数为 0.35；若把概率与距离的配对反过来（0.5 在 8 m、0.2 在 2 m），分数降到 0.2375（本讲实算）。距离作为分母使近处子图的话语权远高于远处，这与探索决策的直觉一致：目标更可能出现在语义相关且距离近的区域。需要注意 Pjsub 是 1 / 距离，量纲为 1/m，本身不构成校准概率，只有排序与相对大小有意义；前沿分数同样只有相对比较的意义。

6. 消融：组、房间、边与 CoT

四组消融都在 MP3D 上进行。第一组是场景图与重感知的联合消融，用来给两个组件分账：去掉场景图与重感知（退化为随机前沿探索）时 SR / SPL / SoftSPL 为 25.7 / 12.9 / 22.6；只去掉重感知为 36.5 / 15.0 / 23.9；完整版为 40.1 / 16.0 / 24.9。场景图单独贡献 SR +10.8，重感知在场景图之上再贡献 +3.6，两者合计 +14.4（本讲实算）。

第三组是边消融：只保留节点时 SR / SPL 为 38.0 / 15.2；去掉短边为 39.0 / 15.5；去掉长边为 39.5 / 15.7；完整图为 40.1 / 16.0。边际贡献为：短边 −1.1 SR、长边 −0.6 SR；两类边同时缺失时损失 2.1，大于单项损失之和 1.7，差值 0.4 个百分点（本讲实算），说明两类边对 CoT 推理有互补作用。第四组是 CoT 消融：把图直接转成文本提示为 36.5 / 14.9；把节点与边分别转文本为 37.0 / 15.0；去掉跨层边后再加 CoT 为 38.2 / 15.5；完整 CoT 为 40.2 / 16.0。完整 CoT 相对直接文本提示的 SR 增量为 +3.7，跨层边相对完整 CoT 的贡献为 +2.0（本讲实算）。这里出现一个 0.1 的口径差：CoT 消融的完整版报 40.2 / 16.0，主表 SG-Nav-LLaMA 为 40.1 / 16.0，属于评测波动，引用时以主表为准并注明两处数字。

7. 边界与失效条件

第一，图的质量上限由在线 3D 实例分割决定。论文自述当前实现用二维视觉语言模型与视觉基础模型逐帧分割再跨帧合并掩膜，尚未做到端到端与三维一致；分割错误会以节点错误的形式进入图，进而污染 CoT 的输入（Yin 等 2024，第 5 节）。第二，失败案例分三类：把货架误判为柜子并走向它；目标漏检；LLM 先验导致错误的位置预期，例如附近有沙发与电视时模型高估椅子出现的可能性，使智能体在有限步数内更难找到目标（Yin 等 2024，图 10）。第三，方法目前只处理物体目标导航，图像目标与视觉语言导航被列为未来工作。第四，跨论文引用要核对版本：本论文表 1 引用 VLFM 的 MP3D 行为 36.2 / 15.9，而 VLFM 原文表 I 为 36.4 / 17.5；HM3D 行为 52.4 / 30.3 对 52.5 / 30.4。SPL 在 MP3D 上差 1.6，这不是小量；交叉对比时以被引论文原表为准，并注明引用链。第五，LLM 推理与图更新都有调用成本，移动平台部署时需要把调用频率与步进节拍对齐；论文的全部实验在仿真内完成，真机证据留给后续工作。

实现思路与设计

SG-Nav 的工程结构可以拆成四个模块与三条协议。四个模块是：场景图构建、占据图与前沿、子图推理、局部规划。三条协议是：边关系合并提示、剪枝规则、分层 CoT 提示。下面用表格固定接口与设计判据。

两条实现约定需要写进代码仓库。其一，所有 LLM 输出都要经过类型与数值校验再进入计算，LLM 返回的距离必须为正数并做下界夹取，非法值回退到中性概率，避免单次解析失败放大成全局错误。其二，图的增量合并要以实例掩膜的空间重叠为主要依据，类别只做辅助判定；跨帧合并错误比漏合并的代价更高，漏合并产生冗余节点，错误合并会制造假关系。

关键代码与解读

三段代码对应图结构与增量合并、边关系合并提示、子图概率到前沿分数的插值。

片段 1：节点注册与跨帧合并

def register_objects(graph, detections, frame_id):
    """把当前帧检测到的 3D 实例注册或合并进场景图。"""
    for det in detections:
        merged = False
        for node in graph.objects:
            iou = mask_iou_3d(det.mask, node.mask)      # 掩膜空间重叠
            if iou >= 0.5 or (iou >= 0.3 and det.label == node.label):
                node.mask = fuse_masks(node.mask, det.mask)   # 合并点云掩膜
                node.conf = max(node.conf, det.score)         # 置信度取高值
                node.frames.append(frame_id)
                merged = True
                break
        if not merged:
            graph.add_object(ObjectNode(
                label=det.label, conf=det.score,
                mask=det.mask, center=det.center, frames=[frame_id]))
    graph.update_groups()          # 按关系字典迭代吸收新物体进组
    graph.update_rooms()           # 房间当实例处理，按掩膜包含关系归籍
    return graph

解读：（1）合并用两级判据：高重叠直接合并，中等重叠要求类别一致；类别仅作辅助，避免把两个不同物体按标签错误合并。（2）置信度取历史高值，不用最新值，与 VLFM 的多视角融合思路一致：单帧低置信度不应抹掉此前的高置信度证据。（3）组与房间的更新放在函数末尾批量执行，保证一轮注册结束后图结构自洽，组吸收是迭代过程，需要收敛判定。

片段 2：一次合并提示与解析

def connect_new_nodes(llm, new_nodes, prev_nodes):
    """对 m 个新节点稠密连边：写一次提示，拿回全部关系。"""
    pairs = []
    for a in new_nodes:
        for b in new_nodes + prev_nodes:
            if a is b:
                continue
            pairs.append({"object1": a.label, "object2": b.label})
    prompt = (
        "Predict the most likely relationships between these pairs of objects: "
        + json.dumps(pairs, ensure_ascii=False))        # 论文记 m(m+n) 对
    raw = llm.generate(prompt, response_format="json")
    relations = json.loads(raw)
    if len(relations) != len(pairs):                    # 数量校验
        relations = pad_missing(relations, len(pairs))  # 缺失回退为无关系
    edges = []
    for pair, rel in zip(pairs, relations):
        if rel.get("relationships"):
            edges.append((pair["object1"], pair["object2"],
                          rel["relationships"]))
    return edges

解读：（1）候选对数量的正确性是复杂度的关键：论文按 m(m+n) 记对数（允许自环），实现中通常跳过自环，实际对数 m(m+n−1)，数量级与论文一致。（2）返回条数必须校验，LLM 漏项或多项都会错位；回退策略是把缺失项按“无关系”处理，宁可少边，不可错边。（3）提示中对象名进入 JSON 前要转义，真机输入来自检测器，含引号或特殊字符的类别名会破坏结构化解析；这是工程实现中最常见的解析崩溃来源。

片段 3：子图概率插值到前沿

def frontier_scores(frontiers, subgraph_probs, subgraph_centers, eps=1e-3):
    """按 P_fro(i) = sum_j P_sub(j) / D_ij 计算每个前沿的探索分数。"""
    scores = {}
    for f in frontiers:
        total = 0.0
        for p_sub, center in zip(subgraph_probs, subgraph_centers):
            dist = euclidean(f.center, center)          # 单位：米
            total += p_sub / max(dist, eps)             # 距离下界防除零
        scores[f.id] = total
    return max(scores, key=scores.get) if scores else None

解读：（1）距离下界 eps 防止子图中心与前沿重合时的除零；物理上两者重合意味着语义证据就在前沿上，用大权重是合理极限。（2）子图概率来自 LLM 输出距离的倒数，进入该函数前必须已完成数值校验与夹取，本函数只负责插值。（3）对每个前沿遍历全部子图是 O(N·M)，论文实验中 N 与 M 均为几十量级；若要扩展到大场景，可按空间邻近裁剪子图集合，但需要重新验证与全量计算的排序一致性。

常见误区

  • LLM 输出的距离不做数值校验：症状是偶发崩溃或某前沿分数突然极大。根因是取倒数前未检查 0、负数与非数值输出。修复：解析后做正数检查与下界夹取，非法值回退中性概率，并记录一次失败日志用于统计 LLM 输出质量。
  • 把子图概率当作校准概率：症状是用固定阈值筛选子图时在不同场景表现漂移。根因是 Psub 为距离倒数，量纲 1/m，数值范围随场景尺度变化，只有排序意义。修复：只用相对排序或归一化后的分数，不做概率解释。
  • 边剪枝口径混用：症状是图规模与论文不符、消融方向异常。根因是短边与长边判定条件不同，短边依赖共同帧与 VLM 验证，长边依赖无遮挡平行墙体与同房间两条标准。修复：两条路径分别实现、分别统计剪除率，禁止一套阈值通用。
  • 跨论文直接比较引用数字：症状是复现表里 SG-Nav 对 VLFM 的增量与两篇原文都对不上。根因是 SG-Nav 表 1 引用的 VLFM 数字与 VLFM 原表不同（MP3D SPL 15.9 对 17.5）。修复：以被引论文原表为准，注明引用链与评测版本。
  • 组字典覆盖不足或过度合并：症状是图碎片化或出现错误的组节点。根因是类别关系字典是预生成的，覆盖范围有限；掩膜合并阈值过松也会制造跨物体组。修复：统计组节点规模分布，对超大规模组做人工抽查；字典按场景类别体系扩展并保留版本号。

小结

  • 表示：SG-Nav 用在线分层 3D 场景图替代纯文本提示，节点分物体、组、房间三层，边分跨层属籍与同层空间、功能关系；组类别字典由 LLM 预生成，论文附录给出 26 组示例。
  • 构建与复杂度：新节点与全部节点稠密连边，候选对 m(m+n)；一次合并提示把调用压缩为单次，m = 5、n = 100 时 token 吞吐比约 1.38%，按 O(Lr) 的时间比约 1.18%（r = 1）与 7.29%（r = 2）；论文附录系数推导存在一处前导项差异（5.49 对 7.79），量级结论不变，复现按原式代入。
  • 推理：子图由中心物体、父节点与相连物体组成；四步分层 CoT 依次预测距离、提问、据图作答、汇总；Psub 取距离倒数，前沿分数 Pifro = Σ Pjsub / Dij 按反距离插值。
  • 结果：SG-Nav-LLaMA 在 MP3D、HM3D、RoboTHOR 上为 40.1 / 16.0、53.9 / 24.8、47.3 / 23.7（SR / SPL），相对 L3MVN 的 SR +5.2、+5.2、+6.1；MP3D 上超过有监督 SemEXP 与 PONI，HM3D 与 RoboTHOR 上仍低于 ProcTHOR；与 VLFM 相比成功率领先而 HM3D 路径效率落后 5.5。
  • 消融：场景图贡献 SR +10.8，重感知再贡献 +3.6（MP3D）；组节点 +1.1 大于房间节点 +0.7；短边与长边边际损失 1.1 与 0.6，同时缺失损失 2.1；完整 CoT 相对文本提示 +3.7 SR。
  • 下一讲展开重感知纠错：当检测器报出假阳性目标时，如何用图概率与检测置信度累积可信度，在有限步数内决定接受或放弃；同时给出三个数据集上的纠错增量与效率代价。
