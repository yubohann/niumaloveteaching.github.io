第四篇 · 开放词汇与大模型

第 079 讲｜2026 快照 IV：空中与多机

前三讲都在单机地面场景内展开；本讲换平台，读三篇 2026 年的工作。（Xiao 等，2026，AeroBelief，arXiv:2609.08164）把开放词汇目标导航搬到无人机上：VLM 的帧级判断噪声大且空间上瞬时，方案用直觉层与证据层分离上下文合理性与目标证据，在 UAV-ON 测试集上取得 21.61% 成功率、35.57% 邻近率（Oracle Success Rate, OSR）与 10.62 SPL。（James 等，2026，GoalVLM，arXiv:2603.18210）用两台机器人协作在 GOAT-Bench 上做零样本开放词汇链式导航，5–7 个目标的子任务成功率 55.8%。（Yu 等，2026，SurveilNav，arXiv:2606.25119）让机器人与 206 台监控相机协同，跨 74 个楼层评测多视角信息利用。本讲的重点是三张协作接口：信念如何在图层间传递、前沿如何分配给多机、巡检视角如何并入机器人的价值图。

  • 主题：空中 ObjectNav / 双层信念地图 / 多机协作 / 机器人-监控协同 / 协作接口
  • 关键公式：Ft = clip(clip(It,0,ĪF) + λt(gt)·clip(Et,0,ĒF), 0, 1)；U(f) = (1−w)·svlm + w·v̂；UCB(f) = μ(f) + β√σ2(f)
  • 预计学时：80 分钟
  • 前置章节：第 078 讲（2026 快照 III：记忆与终身）

学习目标

  • 理解：说清空中 ObjectNav 与地面 ObjectNav 在观测几何、成功判据与预算上的差异，以及为什么 VLM 帧级输出需要持久化。
  • 会推导：写出双层信念的更新式与门控融合式，分析各层取值边界、衰减与不衰减的设计动机。
  • 会算：复算三篇论文的主结果增量、逐尺寸族与消融差额，并用终止构成验证成功率内部一致性。
  • 会设计：为多机或机器人-监控系统画出协作接口表，包括共享信息、频率、缺失后果与验证方式。
  • 会判断：识别 20 m、1 m 两类成功半径与不同动作预算，避免跨平台横向排序。

背景与动机

平台一变，问题结构就变。空中智能体面对大范围室外环境：目标可能长时间不在视场内，观测随水平位移与高度共同变化，成功判据以 20 m 半径计；第 077 讲讨论的检测瓶颈在这里被放大，因为候选目标往往只有几十像素。多机协作把覆盖问题拆分给多台智能体，收益来自并行探索，但引入前沿分配与地图融合的一致性代价。机器人-监控协同则利用基础设施的静态全局视角，把「搜索」的一部分从机器人本体转给环境，代价是对相机位姿与时间同步的依赖。三条路线共同回答第 080 讲回顾要收束的问题：开放词汇能力向新平台扩散时，哪些模块可以直接迁移、哪些必须重写。

本讲按「信念、分工、视角」三个关键词组织：AeroBelief 处理单机信念的持久化与选择性；GoalVLM 处理多机之间的前沿分工与语义地图共享；SurveilNav 处理机器人-基础设施的跨视角融合。每篇都给出可复算的结果表与消融，末节把它们放进同一张协作接口表。

核心原理

1. 空中 ObjectNav：任务与三条挑战

任务定义沿用目标规格 g = (ng, sg, dg)：目标名称、尺寸类别与自然语言描述。无人机在未知室外环境用机载视觉探索，终止时显式发出停止动作且距目标不超过成功半径 δ 才算成功：

S = 1[aT = stop ∧ dist(xT, xg) ≤ δ]

UAV-ON 基准设置每幕至多 150 个动作、搜索半径 50 m、成功半径 δ = 20 m；碰撞终止计为失败（Xiao 等，2026，AeroBelief）。论文指出三条核心挑战。第一，VLM 输出是帧级判断：一次正例可能随位移或高度变化从后续观测中消失，若不写入持久空间表示就丢失。第二，上下文合理性与目标证据被混淆：建筑立面可能是空调外机的合理背景，但背景本身不构成目标可见。第三，逐步骤独立决策的时序一致性差：没有稳定的覆盖导向，无人机容易反复访问已探区、在相近方向间震荡。

2. 物体条件视觉推理与保守资格审查

每幕开始时，用目标规格与初始前、左、右三视角构造一次目标条件线索 q，内容包括判别性属性、部件-整体结构、距离相关外观、支持性与抑制性场景上下文、易混物与目标级验证标准。q 作为解释先验复用整幕，不作为动作策略。每个语义更新步，对每个视角 v 输出结构化判断：

rtv = (mtv, κtv, btv, ρtv, ζtv)

其中 m 为匹配类型（exact、strong semantic、weak contextual、none 四级），κ 为置信度，b 为距离档，ρ 为语义角色（规范目标、目标部件、邻近物体、模糊匹配），ζ 为停止就绪度。同时从场景类别与可见物体推导场景支持度 ηtv ∈ [0,1]。η 与 b 进入直觉层作为上下文搜索支持，不构成目标存在的直接证据。

资格审查（Evidence Qualification）在写入空间前对其中的 exact 与 strong semantic 声明做三项检查：场景上下文冲突识别被抑制性上下文主导的声明；核心验证不足识别不满足判别性要求的观测；部件-整体不匹配识别由孤立部件或邻近物体触发的响应。支持不足时把匹配类型降级为 weak contextual，并保守修正语义角色与停止就绪度，该观测仍可进入直觉层，但被证据层拒收。资格审查不把弱观测强化为目标证据，这是单向的保守操作。

3. 双层信念与证据门控融合

两层共享同一世界坐标搜索栅格。直觉层存 It(c)，证据层存 Et(c)。单视角贡献先做截断：

ΔL,tv(c) = clip(αL(m̂tv) · κtv · ΦLv(c; btv, pt), 0, Δ̄L)，L ∈ {I, E}

αL 为层与匹配类型相关的语义贡献，Δ̄L 限制单次观测的上限，Φ 含距离档调制与按位姿的空间衰减。多视角聚合用逐格最大值：ΔL,t(c) = maxv ΔL,tv(c)。取最大值避免同一格被重叠观测反复累加，这是把「多次看到」与「看到一次但可信」区分开的关键。

直觉层接纳集合 MI = {exact, strong semantic, weak contextual}，更新为局部最大后再做全局时间遗忘：

Itloc(c) = min{Ī, max(It−1(c), ΔI,t(c))}；It(c) = γItloc(c) 若 γItloc(c) ≥ τclear，否则取 0

γ 为衰减因子，τclear 清除长期低置信格，Ī 为上限。证据层更严格：只接纳 ME = {exact, strong semantic} 且 κ > τE 的观测，更新为：

Et(c) = min{Ē, max(Et−1(c), ΔE,t(c))}

证据层在幕内不衰减：位移、遮挡或视角变化导致暂时看不见目标时，此前的合格证据必须保留，供后续接近与确认使用。两层经证据门控融合：

Ft(c) = clip(clip(It(c), 0, ĪF) + λt(gt) · clip(Et(c), 0, ĒF), 0, 1)

门控状态 gt ∈ {missing, sparse, sufficient}，由合格目标证据的可用量与可靠性决定；证据缺失或稀疏时融合图主要受上下文直觉支配，证据充足后 λt 增大。融合图再经方向分箱的非极大值抑制与已探区惩罚，抽出 top-K 信念热点 Ht = {h1, …, hK}，每个热点给出方向扇区、相对方位、距离与融合分数，供规划器做细粒度目标导向决策。

并行的覆盖导向来自四叉树（Quadtree）覆盖建模：把覆盖节点变换到当前机体坐标，分入 5×5 的航向相对箱 Rt = {Rijt}，中央箱为机体自身。每个箱的分数为 St(R) = Stopp(R) + Streach(R) − Stpen(R)，分别度量剩余探索机会、方向可达性与空间低效（含访问历史）。区域打分与语义信念值完全独立，维持探索压力，避免局部语义热点过早支配规划。瞬时候选箱 Rtcand = argmax St(R) 经时间承诺（Temporal Commitment）在步间保持：KEEP 保持上一承诺、UPDATE 切换到更优候选，并设最短承诺时长与切换迟滞以抑制方向震荡。

5. 多机开放词汇：GoalVLM

GoalVLM 把多机 ObjectNav 形式化为去中心化部分可观测马尔可夫决策过程（Dec-POMDP）：N 台智能体在未知环境 E 中寻找自由文本类别的实例，类别集合为 379 以上的开放词表。单机观测为 ot = (Itrgb, Itdepth, pt)，动作为停止、前进 0.25 m、左转与右转 ±30°、微转 ±10° 六项；GOAT-Bench 协议下每幕包含 5–7 个目标的链式序列，子任务成功判据为停止位置距目标实例不超过 1.0 m，每子任务预算 500 步。

感知管线两条并行：SAM3 做文本提示的检测与分割，输出框与掩码；GoalProjector 把掩码经标定深度反投影到 BEV 语义图，得到与 VLM 无关的目标定位信号；多视角确认要求连续 2 次以上检测超过阈值 τdet = 0.30 才触发接近。空间推理由 SpaceOM 承担，输出前沿排序概率：P(g|fi, Ht) = VLM(Itrgb, g, {frontieri})，提示链依次包含场景描述、房间类型分类、感知门控与多前沿排序。最终前沿效用把 VLM 分数与贝叶斯价值图混合：

U(fi) = (1 − w) · sivlm + w · v̂i，w = 0.35；UCB(fi) = μ(fi) + β√σ2(fi)，β = 1.7

价值图初始均值 0.5、初始方差 0.5，按深度可见锥做贝叶斯更新，兼顾高信念与高不确定性区域。导航用快速行进法（FMM）解程函方程 |∇T(x)| = 1/v(x) 得到测地距离场，再由梯度下降抽取短期目标 xstg = xt − λ∇T(xt)，并裁剪到 25 格（1.25 m）以支持反应式避碰。多机协作保持轻量：各机维护局部语义图，用逐元素最大池化融合为全局图 Mglobal(x,y,c) = maxi Mti(x,y,c)；前沿分配用序列贪心，第一台选定后从候选集移除，第二台在剩余前沿中选择，避免重复探索。

6. 机器人-监控协同：SurveilNav

任务把第一人称观测与建筑内固定监控的第三人称观测结合：场景集合 S、类别集合 C，场景 si 部署监控集合 Hi = {h1, …, hni}；每幕机器人随机初始化，需定位目标类别实例，动作集为前进 0.25 m、左右转 30°、抬头/低头 30° 与停止，预算 500 步，成功判据沿用测地距离口径。

数据集构造分三步。楼层识别：把机器人置于场景并记录可行点，用 DBSCAN 对高度聚类分层。相机采样：按楼层面积每 100 m² 布置一台相机、安装高度 1.8 m，跳过黑像素比例过高的候选位（扫描伪影），用最远点采样优化覆盖。观测生成：每台相机记录 13 个视角（12 个方位间隔 30°、下倾 30° 的环视加 1 个下视 90°），每视角 1280×1280 RGB-D。最终规模为 36 个场景、74 个楼层、206 台相机、1000 条 episode、6 个目标类别；平均每层 2.78 台相机、每场景 27.8 条 episode，全库共 206 × 13 = 2678 个监控视点。论文另提供相机密度（200 m²/台）与视场（全景对半幅）变体，并用 Habitat 真值深度作为经验上界，把方法与深度估计噪声隔离。

主动调用（Active Camera Invocation）按楼层对齐过滤无关相机：αj,t = 1[|ẑta − ẑjc| ≤ τz]，其中 ẑ 为推理出的楼层绝对高度，τz 取 0.4 m。该步剔除跨楼层观测，是多楼层可扩展性的前提。融合分三层。几何层：机器人点云与相机点云各自变换到全局系后合并，构建联合 3D 点云，再投影出障碍图与探索图，膨胀障碍边界后相减得到前沿。语义层：对监控与机器人图像统一用 CLIP 计算与文本提示「seems like there is a [object name]」的余弦相似度，投影到俯视栅格后平均融合：

sjoint(i,j) ← [ssurveil(i,j) + srobot(i,j)] / 2

物体层：GroundingDINO 检测、MobileSAM 分割、CLIP 提特征，构建带置信度、类别与特征的语义点云；新检测与已有物体按 s(i,j) = w1Svis(i,j) + w2Sgeo(i,j) 关联，几何相似度为点云 IoU，低于阈值 τ = 1.35 时新建实例，否则并入最相似节点；类别由机器人局部与监控全局置信度的较大者决定，移动中持续更新，若某物体预测类别发生变化则判为假阳性。这个「置信演化」机制让静态全局视角与动态局部视角互相补位。导航用 FMM 局部规划：目标已确认时直接取其位置为航点，否则选择高潜力候选物体或价值最高的前沿。

关键代码与解读

三段代码对应三篇的最小核心：双层信念更新、多机前沿分配、监控主动调用与价值图融合。

片段 1：双层信念更新与证据门控融合

import numpy as np

def update_beliefs(I_prev, E_prev, delta_I, delta_E,
                   gamma=0.9, tau_clear=0.05, I_bar=1.0, E_bar=1.0):
    """I/E：直觉层与证据层栅格；delta_*：本步逐格最大贡献。"""
    I_loc = np.minimum(I_bar, np.maximum(I_prev, delta_I))   # 局部最大
    I_new = np.where(gamma * I_loc >= tau_clear,
                     gamma * I_loc, 0.0)                      # 全局遗忘
    E_new = np.minimum(E_bar, np.maximum(E_prev, delta_E))   # 证据不衰减
    return I_new, E_new

def gated_fusion(I_t, E_t, evidence_state, I_f=0.6, E_f=1.0):
    """evidence_state ∈ {missing, sparse, sufficient} 决定证据权重。"""
    lam = {"missing": 0.0, "sparse": 0.5, "sufficient": 1.0}[evidence_state]
    fused = np.clip(I_t, 0, I_f) + lam * np.clip(E_t, 0, E_f)
    return np.clip(fused, 0, 1.0)                            # 供热点抽取

解读：（1）两次 max 聚合的含义不同：层内 max 融合多视角贡献，避免重叠累加；时间维 max 保留历史信念，直觉层再乘 γ 做遗忘，证据层保持原值。（2）τclear 在乘 γ 之后比较，防止低置信格无限期残留；证据层没有清除步，因为「暂时看不见」不等于「证据作废」。（3）门控权重按三态离散取值，对应论文的 missing/sparse/sufficient；离散化降低了调参面，适合复现，代价是状态切换附近可能抖动，工程上可加迟滞。

片段 2：UCB 前沿打分与序列贪心分配

def frontier_utility(frontier, s_vlm, w=0.35, beta=1.7):
    """融合 VLM 语义分与贝叶斯价值图的 UCB 分。"""
    mu = frontier["value_mean"]                     # 价值图信念均值
    var = frontier["value_var"]                     # 价值图方差
    v_hat = (mu + beta * var ** 0.5)                # UCB 探索项
    v_hat = (v_hat - v_hat.min()) / (v_hat.ptp() + 1e-9)  # 归一到 [0, 1]
    return (1 - w) * s_vlm + w * v_hat

def allocate_frontiers(frontiers, agents, w=0.35, beta=1.7):
    """序列贪心：每台智能体选当前最高分前沿，选后移出候选集。"""
    remaining = list(frontiers)
    assignment = {}
    for agent in agents:
        scored = [(f, frontier_utility(f, f["s_vlm"], w, beta))
                  for f in remaining]
        best = max(scored, key=lambda x: x[1])[0]
        assignment[agent] = best
        remaining.remove(best)                      # 防止双机撞目标
    return assignment

解读：（1）UCB 的 β 控制探索权重，β 越大越偏向高方差（未探明）区域；论文取 1.7，改动会影响前期探索与后期收敛的平衡。（2）v̂ 做 min-max 归一是为了让价值图分数与 VLM 概率可比；若两者量纲不一致，w 的物理含义会被破坏。（3）序列贪心是 O(N·K) 的轻量协议，没有市场机制或协商；论文用它换取低通信开销，代价是分配结果依赖智能体处理顺序，规模增大后需要更公平的协议。

片段 3：监控主动调用与联合价值图

import numpy as np

def activate_cameras(agent_floor_z, cameras, tau_z=0.4):
    """只保留与机器人同层的相机；floor_z 为推理出的楼层高度。"""
    active = [c for c in cameras
              if abs(c["floor_z"] - agent_floor_z) <= tau_z]
    return active                                   # 跨层观测被剔除

def fuse_value_maps(map_robot, map_surveil):
    """两源语义价值图按平均法融合，尺寸须一致。"""
    return 0.5 * (map_robot + map_surveil)          # 论文式 (2)

def associate_object(det, nodes, w1=1.0, w2=1.0, tau=1.35):
    """几何 IoU 与语义特征相似度求和；低于阈值新建实例。"""
    best, best_score = None, -1.0
    for node in nodes:
        s_vis = cosine(det["feature"], node["feature"])
        s_geo = iou(det["points"], node["points"])
        s = w1 * s_vis + w2 * s_geo
        if s > best_score:
            best, best_score = node, s
    if best is None or best_score < tau:
        return {"action": "create"}
    return {"action": "merge", "node": best}        # 类别变化时判假阳性

解读：（1）楼层阈值把「空间上接近但不同层」的相机挡在融合之外，这是多楼层可扩展的核心保护；阈值过大会漏掉同层相机，过小会引入跨层噪声。（2）平均融合对两源等权，实现简单；两源质量差异大时应改成置信度加权，但论文选择等权以保持可复现性。（3）关联分数把外观与几何并列，阈值 1.35 是标定值；误合并会污染置信演化，漏合并会重复计数，两者在调阈值时方向相反，需在验证集上配对评估。

常见误区

  • 把 20 m 成功半径与室内 1 m 口径混排：症状是拿 AeroBelief 的 21.61% 与室内方法的 SR 直接比较。根因是 UAV-ON 的成功判据、搜索半径与动作预算都不同（150 动作、50 m 半径）。修复：按平台分表；跨平台只比较机制，不做数值排序。
  • 把 OSR 与 SR 的差当随机噪声：症状是只报成功率，忽略 13.96 个百分点的总体差值。根因是邻近率与成功停止是两件事，停止精度仅 42.36%。修复：同时报告 OSR、SR 与停止精度；按目标尺寸分层检查差值（小型 18.44、大型 5.89）。
  • 外推多机加速比：症状是引用「双机 1.8 倍」并预测更多机器人线性增长。根因是同一论文的消融表为 38.6 → 56.2（1.456 倍），讨论段为 32.0 → 56.2（1.756 倍），口径不一致；且 SPL 提升有限。修复：引用回到具体表格；扩展数量前先做 N = 3、4 的实测。
  • 混淆零样本与训练型方法：症状是把 GoalVLM 55.8% 与 AstraNav-Memory 62.7% 当作能力差距。根因是后者在导航轨迹上微调了 3B 参数模型。修复：按「免训练 / 训练型」分组；比较时同时看 SPL（18.3 对 56.9，差距主要在路径效率）。
  • 忽略基础设施依赖：症状是把监控协同当作即插即用。根因是方案依赖精确相机位姿、静态场景与真值深度上界，且真机部署存在通信带宽约束。修复：部署前逐项核验位姿来源、场景动态性与深度获取方式，并把缺失条件下的降级策略写进设计。

    最先失效的是联合点云对齐与物体关联（几何 IoU 下降导致重复实例），其次才是价值图的空间错位。检测：在静态场景中比对监控点云与机器人点云的配准残差；缓解：放宽关联阈值并加入位姿不确定性权重，或改用视觉重定位在线修正外参。

小结

  • 空中（AeroBelief）：UAV-ON 协议为 150 动作、50 m 搜索半径、20 m 成功半径；双层信念把直觉层（上下文，含时间遗忘）与证据层（合格目标证据，幕内不衰减）分离并门控融合；测试集 SR 21.61%、OSR 35.57%、SPL 10.62，相对历史最好分别 +2.11、+6.27、+0.48。
  • 消融与失败：完整模型相对 Vanilla 成功率 +14.00 个百分点、碰撞率 −11.50；显式停止占 51.03%、停止精度 42.36%，OSR-SR 总差 13.96（小型 18.44、大型 5.89），小型目标与停止校准是主要失分点。
  • 多机（GoalVLM）：Dec-POMDP 下用共享语义图最大融合与序列贪心前沿分配，SAM3 检测、深度反投影定位、VLM 提示链排序、UCB 探索；GOAT-Bench val_unseen 子任务 SR 55.8%、SPL 18.3%，双机相对单机在消融集为 1.456 倍；总体路径效率与训练型方法仍有明显差距。
  • 机器人-监控（SurveilNav）：36 场景、74 楼层、206 相机、1000 条 episode、2678 个监控视点；楼层对齐筛选 + 联合价值图平均融合 + 置信演化确认；HM3D v0.2 最短路规划下 SPL 36.4、SR 71.1，监控输入带来 SPL +8.4、SR +2.4 至 +4.7 个百分点，区域级价值图优于物体级。
  • 协作接口纪律：地图、前沿、证据、监控观测、价值图与物体置信度各有明确的共享方式与缺失后果；20 m 与 1 m 判据、150 与 500 步预算不可混排。
