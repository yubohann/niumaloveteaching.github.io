第 058 讲｜Sim 与真机落差量化

第 056 讲量化了噪声，第 057 讲量化了数据配比，两者都在仿真内完成。一个配方在仿真里排名靠前，部署到家庭环境还剩下多少成功率？HomeRobot OVMM 基准（Yenamandra 等 2023，Open-Vocabulary Mobile Manipulation）提供仿真与真机两套同接口评测：真机基线成功率 15% 与 20%，而仿真里把感知从真值分割换成开放词汇检测器后，同一技能组合的整体成功率从 14.8% 掉到 0.4%。NeurIPS 2023 竞赛总结（Yenamandra 等 2024）又报告同一策略在两个仿真 split 上从 10.8% 变到 6.0%。本讲用阶段乘积模型与对数分解把落差拆到感知、决策集成、执行与评测规模四个来源，并给出可信度核算方法。

  • 主题：Sim2Real 落差 / 阶段分解 / 感知误差 / 评测样本量
  • 关键公式：P(成功) = P(找物) × P(抓取 | 找物) × P(找容器 | 抓取) × P(放置 | 找容器)
  • 预计学时：85 分钟
  • 前置章节：第 057 讲（混合任务训练）

学习目标

  • 会算：把 OVMM 的四阶段累计成功率还原为条件成功率，并用链式乘积复核整体成功率；能对仿真与真机两组数表各算一遍。
  • 会分解：把「真值感知到检测器感知」的成功率变化放到对数空间，量化各阶段对总降幅的贡献；本讲的算例给出 31.1%、18.5%、8.7%、41.7% 的分解。
  • 会判断：样本量对结论的影响。真机 1/3 与 2/3 的 95% 区间分别为 [6.15%, 79.23%] 与 [20.77%, 93.85%]，区间大幅重叠，不能据此给方法排序。
  • 会设计：同一策略在真值仿真、检测器仿真与真机三条件下的对比协议，含阶段日志、配对策略与样本量计划。
  • 会读：竞赛复盘的定性结论与定量结果如何互相印证，尤其是错误检测与恢复对成功率的贡献。

背景与动机

仿真评测的可信度是前几讲所有结论的地基。第 056 讲在 HM3D-OVON 内比较噪声鲁棒性，第 057 讲在 HM3D-v0.2 与 HM3D-OVON 内比较配方，这些结论都绑定在 Habitat 渲染器、离散动作与 500 步口径上。真机部署面对的是另一套误差源：开放词汇检测器在真实图像上的误检与漏检、机械臂运动学误差、抓取成功与否的判定、放置时物体滚落。要把这些误差量化，需要一个同时在仿真与真机提供同接口评测的基准。

HomeRobot OVMM（Yenamandra 等 2023）正是为此设计：任务是把指定物体从起始容器搬到目标容器，阶段包括找到物体、抓取、找到目标容器、放置；仿真侧用 HSSD 场景（Habitat Synthetic Scenes Dataset，60 个场景）与 2,535 个物体，真机侧用一台 Stretch 在受控公寓里执行同一套技能调用。论文给出两组基线（启发式与强化学习）在两个世界的成绩，成为少见的可对照数据。

随后举办的 NeurIPS 2023 竞赛（Yenamandra 等 2024）把仿真榜单与真机评测连接起来：仿真提交 250 条 episode，前三名到真机公寓各跑 3 次。竞赛结果显示，仿真里 0.8% 的基线成绩被参赛队做到 10.8%，而真机只有 1/3 与 2/3 量级的样本。这些数字合在一起，正好可以把「落差来自哪里」与「我们用多少样本在测量」两个问题分开讨论。本讲先建阶段模型，再逐块量化。

核心原理

1. 任务与阶段指标

OVMM 的指令形式为「把物体从起始容器搬到目标容器」：物体是可操作的小件（杯子、毛绒玩具、药瓶等），起始与目标容器是家具表面（桌子、椅子、沙发等）。一次试验成功的判据是物体最终位于正确类别的目标容器表面上；论文同时报告部分成功（partial success），定义为四个阶段累计成功率的算术平均，并给出平均步数。四个阶段为：

阶段英文判定
找物FindObj在起始容器上定位目标物体
抓取Pick机械臂抓取成功，物体离开支撑面
找容器FindRec定位正确类别的目标容器
放置Place物体稳定落在目标容器表面，整体成功

论文报告的四个累计率都以前一阶段成功为前提，最后一项即整体成功率；部分成功指标把四项累计率平均，用作并列时的次级排序量。读表时最易犯的错误是把它当作四个独立概率相乘，那会系统性低估整体成功率。

2. 阶段乘积模型与复核

设累计率为 c1 ≥ c2 ≥ c3 ≥ c4，则条件成功率与整体成功率满足：

P(成功) = c1 × (c2/c1) × (c3/c2) × (c4/c3) = c4 括号内依次为抓取、找容器、放置的条件成功率；恒等式用于核对表内的自洽性

用 HomeRobot 论文的仿真表逐行复核（真值分割感知，技能组合按导航与放置两列标注；表中凝视技能与放置列同步，放置取启发式时凝视项为空，放置取强化学习时为强化学习）：

3. 感知是最大单因子：对数分解

以效果最好的组合（强化学习导航加强化学习放置）为例，感知从真值切到 DETIC 后整体成功率从 14.8% 降到 0.4%，保留率 2.7%。把总变化写到对数空间，各阶段条件增量相加恰好等于总变化：

Δ = ln(0.004 / 0.148) = −3.611；各阶段贡献按 ln(条件比) / Δ 计算 对数分解使乘性链条变成加性贡献，适合定位落差来源
阶段真值条件率 → 检测器条件率对数贡献占总体降幅
找物66.6% → 21.7%−1.12131.1%
抓取 | 找物91.7% → 47.0%−0.66918.5%
找容器 | 抓取83.3% → 60.8%−0.3158.7%
放置 | 找容器29.1% → 6.5%−1.50641.7%
合计14.8% → 0.4%−3.611100%

读法有三层。第一，感知误差不只影响「找物」这一处，它污染所有需要识别物体的阶段，因此四个条件率一起下降，最终放置阶段的条件率从 29.1% 跌到 6.5%，是占比最大的贡献项（41.7%）。第二，找物阶段的绝对降幅最大（66.6% 到 21.7%，降 44.9 个百分点），说明检测器一旦漏检，后续阶段根本无从开始；论文也把感知列为所有参赛队的共同瓶颈。第三，链条后端本来就不强：即使在真值感知下，放置条件率只有 29.1%，这是操作技能的固有限制，与感知无关。把两者混为一谈，会把本该投向操作技能的努力投到检测器上。

4. 真机与仿真的对照，以及方向性问题

HomeRobot 论文在受控三室公寓里各做 20 次试验，启发式 15%、强化学习 20%；仿真里同组合在真值感知下是 5.1% 与 14.8%。也就是说，真机数字高于仿真真值数字，而仿真检测器数字（0.4%）又低于两者。这一组方向不一致的对比揭示了三个混杂：其一，真机试验的物体与初始摆放经过筛选，保证机器人可达、可抓，仿真 episode 的难度分布更宽；其二，DETIC 在真实照片上的表现好于在仿真渲染图上的表现，论文观察到换用检测器后仿真里的性能损失远超真机；其三，真机样本只有 20 次，区间很宽（15% 的 95% Wilson 区间为 [5.24%, 36.04%]，20% 为 [8.07%, 41.60%]）。因此仿真与真机之间没有单向的固定偏差：本组数据中真机成绩高于两种仿真条件，同时仿真检测器条件最低。可迁移的量化结论有两个：其一，仿真内部的感知替换造成约 14 个百分点的落差，方向与量级都稳定；其二，真机点估计的区间宽达 30 个百分点量级，任何单向的「高估」「低估」说法都超出数据支持范围，必须与样本量和场景筛选条件一起报告。

NeurIPS 2023 竞赛的数据补充了另一面。仿真 test-challenge 上，主办方基线（启发式）为 0.8%，最好参赛队 UniTeam 为 10.8%（提高约 13.5 倍），第二名 Rulai 3.2%；真机侧前三名各跑 3 次，UniTeam 1/3 成功、Rulai 0/3、KuzHum 0/3；同场对比的强化学习基线真机 2/3 成功。以 3 次试验计，1/3 的 95% 区间是 [6.15%, 79.23%]，2/3 是 [20.77%, 93.85%]，完全重叠。竞赛的定量结论只能是「仿真成绩对真机成功有参考价值」（UniTeam 是仿真第一，真机也拿到成功），不足以对基线排序。

split 差异同样要算进评测噪声：UniTeam 在 test-challenge 为 10.8%，在 test-standard 为 6.0%，后者只有前者的 55.6%；主办方启发式基线在两个 split 上是 0.8% 与 0.0%。同一份代码、同一预算，仅换 episode 集合就有约 4.8 个百分点的波动；按后文样本量公式，分辨这一差值需要每组约 521 条 episode，而两个 split 各只有 250 条，落在评测噪声的量级内。

5. 错误检测与恢复：同一检测器下的增益

竞赛复盘给出两条共同经验：做得好的队伍都强化了错误检测与恢复，并改进了感知与决策的集成。UniTeam 的案例最有说服力：它用的是与主办方基线相同的 DETIC 检测器，改动集中在任务模型：在抓取后校验抓取是否成功，失败则回退到导航阶段重新找；抓取尝试前左右旋转扩大视野；放置分多步小幅靠近，避免过远或过近；目标容器未检出时改为放在面前的平面；大件物体从更高处投放。这些改动把仿真 test-challenge 成绩从 0.8% 提到 10.8%，部分成功从 17.7% 提到 32.8%，平均步数从 962.2 微增到 993.2（增 3.2%）。以约 3% 的步数代价换取 13.5 倍成功率，说明在感知固定的前提下，任务层的校验与重试是最划算的改进方向之一。

6. 评测的可信度：样本量与区间

比较两个方法的成功率，需要的最小样本量由目标分辨率和基线方差决定。对两组比例差检验，每组样本量近似为：

n ≈ (zα/2 + zβ)2 × [p1(1−p1) + p2(1−p2)] / Δ2 双侧 α = 0.05 与 80% 功效下：zα/2 = 1.96，zβ = 0.842；Δ 为要分辨的成功率差

代入常用场景：分辨 10 个百分点（10% 对 20%）每组约 197 条；5 个百分点（15% 对 20%）约 903 条；竞赛里基线 0.8% 与最好成绩 10.8% 的差距每组约 82 条即可分辨；而同一策略两个 split 的 6.0% 与 10.8% 需要每组约 521 条；仿真榜单上 73.7% 对 77.0% 的 3.3 个百分点差需要每组约 2,674 条。真机一次只能跑几十条，这解释了为什么真机结论必须依赖区间与多次会话累积。报告真机结果时同时给点估计、样本量与 Wilson 区间，是比单点数字更负责的做法。

7. 边界与失效模式

三条边界必须写进实验报告。第一，任务口径不同：OVMM 是四阶段移动操作，存在触及场景即失败（真机约 3 次碰撞停试）等规则，与 ObjectNav 的 1 m 停止判据不可互换；引用数字要绑定任务与规则。第二，感知切换在仿真里引入的分布差与真机方向不同：渲染图与真实照片的纹理、光照差异会放大检测器误差，两个方向的偏差会叠加到同一份部署预测里，应分别报告而不能互相替代。第三，受控公寓的单一环境限制了外推：论文明确把单一真机环境列为挑战赛的组织限制，多环境分布式评测是其后续建议。

关键代码与解读

三段代码覆盖阶段分解复核、统计可信度核算与对数落差分解，输入数据与论文表一致，运行即可核对正文数字。

片段 1：阶段分解与链式复核

def stage_rates(name, find_obj, pick, find_rec, place):
    """累计率（%）转条件率并复核乘积；四列按论文表口径给累计值。"""
    cond_pick = pick / find_obj
    cond_rec = find_rec / pick
    cond_place = place / find_rec
    product = find_obj * cond_pick * cond_rec * cond_place
    assert abs(product - place) < 1e-9, (name, product, place)
    print("%-10s cond: pick=%.1f%% rec=%.1f%% place=%.1f%% -> overall=%.2f%%"
          % (name, cond_pick * 100, cond_rec * 100, cond_place * 100, product))
    return cond_pick, cond_rec, cond_place

stage_rates("GT RL/RL", 66.6, 61.1, 50.9, 14.8)
stage_rates("DETIC RL/RL", 21.7, 10.2, 6.2, 0.4)
stage_rates("Real RL", 70.0, 45.0, 30.0, 20.0)
# GT:    cond pick=91.7% rec=83.3% place=29.1% -> overall=14.80%
# DETIC: cond pick=47.0% rec=60.8% place=6.5%  -> overall=0.40%
# Real:  cond pick=64.3% rec=66.7% place=66.7% -> overall=20.00%

解读：（1）恒等式 c₄ = c₁ × (c₂/c₁) × (c₃/c₂) × (c₄/c₃) 对每行成立，断言可在数据录入错误时立即报警。（2）条件率把「阶段能力」与「前面阶段是否送达」分开：真机放置条件率 66.7% 远高于仿真真值的 29.1%，说明仿真里的操作技能本身还有欠训练成分。（3）累计率四列的差值不能当独立概率使用，报告时应以本函数输出的条件率为准做归因。

片段 2：Wilson 区间与样本量

import math

def wilson(k, n, z=1.959964):
    """二项比例的 Wilson 95% 区间（%）。"""
    p = k / n
    d = 1 + z * z / n
    center = (p + z * z / (2 * n)) / d
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return max(0.0, center - half) * 100, min(1.0, center + half) * 100

def n_per_group(p1, p2, alpha=0.05, power=0.8):
    """两组比例差检验的最小样本量（每组）。"""
    z_a = abs(_z(1 - alpha / 2))
    z_b = abs(_z(power))
    return math.ceil((z_a + z_b) ** 2 * (p1 * (1 - p1) + p2 * (1 - p2)) / (p2 - p1) ** 2)

def _z(q):                       # 反标准正态，精度到 1e-5 足够
    lo, hi = -10.0, 10.0
    for _ in range(80):
        mid = (lo + hi) / 2
        if _phi(mid) < q:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2

def _phi(x):
    return 0.5 * (1 + math.erf(x / math.sqrt(2)))

print("real 1/3:", ["%.2f" % v for v in wilson(1, 3)])       # [6.15, 79.23]
print("real 2/3:", ["%.2f" % v for v in wilson(2, 3)])       # [20.77, 93.85]
print("n(10% vs 20%):", n_per_group(0.10, 0.20))             # 197
print("n(73.7% vs 77.0%):", n_per_group(0.737, 0.770))       # 2674

解读：（1）Wilson 区间在小样本下仍覆盖良好，明显优于正态近似（1/3 的正态近似会给出负下界）。（2）两组比例差检验的样本量随目标差值的平方增长：把分辨率从 10 个百分点收紧到 3.3 个百分点，样本量从约 197 涨到约 2,674，涨了 13.6 倍。（3）功效计算假设两组独立；若同一批 episode 上配对比较，实际所需样本更少，但真机通常做不到配对，按独立口径保守规划。

片段 3：对数空间落差分解

import math

def log_decomposition(clean, worse):
    """输入两组四阶段累计率（%），输出各阶段对数贡献与占比。"""
    c1, c2, c3, c4 = [v / 100 for v in clean]
    w1, w2, w3, w4 = [v / 100 for v in worse]
    total = math.log(w4 / c4)
    seg = {
        "FindObj": math.log(w1 / c1),
        "Pick|FindObj": math.log((w2 / w1) / (c2 / c1)),
        "FindRec|Pick": math.log((w3 / w2) / (c3 / c2)),
        "Place|FindRec": math.log((w4 / w3) / (c4 / c3)),
    }
    print("total log change: %+.3f (%.1f%% -> %.1f%%)" % (total, c4 * 100, w4 * 100))
    for k, v in seg.items():
        print("  %-14s %+.3f  share=%5.1f%%" % (k, v, v / total * 100))
    assert abs(sum(seg.values()) - total) < 1e-9

log_decomposition([66.6, 61.1, 50.9, 14.8], [21.7, 10.2, 6.2, 0.4])
# FindObj 31.1% / Pick|FindObj 18.5% / FindRec|Pick 8.7% / Place|FindRec 41.7%

解读：（1）分解要求选择可比的两次评测（同 episode 列表、同技能组合），否则对数贡献里混入 episode 构成差异。（2）若某阶段条件率不降反升，贡献为正值，会在总量里被其他阶段的降幅抵消，读表时要检查符号，不能只看绝对值。（3）分解结果直接对应改进排序：本例中放置阶段贡献最大，但其中相当部分由前端感知误差递延而来，改进前先用真值感知条件率确定操作技能自身的上限。

常见坑

  • 用真值感知的仿真成绩预测真机：症状是部署后成功率差一个数量级。根因是真值分割把感知误差置零，而部署时感知是最大瓶颈。修复：仿真评测至少跑两个感知条件（真值、检测器），部署预测以检测器条件为准，并用真机小样本校准。
  • 用 n=3 或 n=20 的真机结果给方法排序：症状是结论在下一轮试验中翻转。根因是区间过宽。修复：先按目标分辨率算样本量（分辨 10 个百分点约 197 条），分批累积；报告时附 Wilson 区间，区间重叠时不排序。
  • 把部分成功当独立概率相乘：症状是复核出的整体成功率与论文表不符。根因是把四个累计率当成四个独立阶段概率。修复：先转条件率再用链式乘积；用片段 1 的断言自动核对。
  • 跨 split 或跨版本推理：症状是同一方法在两篇文章里数字差几个点，被误认为复现失败。根因是 episode 集合不同（如 test-challenge 与 test-standard 的 10.8% 与 6.0%）。修复：所有数字绑定 split 名称与版本；论证时在同一 split 内比较。
  • 真机规则差异未声明：症状是不同来源的成功率不可比。根因是碰撞停试、超时上限、物体可达性筛选等规则不同。修复：在方法节列出规则清单；跨来源比较前逐条核对，不能对齐的数值不做差。

练习与思考

  1. 用片段 1 复核启发式组合（真值 54.1 / 48.5 / 31.5 / 5.1）与强化学习组合（检测器 21.7 / 10.2 / 6.2 / 0.4）的条件率，并指出两组中放置条件率更低的是哪一组。★
    提示
    启发式真值：抓取 89.6%、找容器 64.9%、放置 16.2%；强化学习检测器：47.0%、60.8%、6.5%。检测器组合的放置条件率更低，说明感知误差会递延到链条末端。
  2. 把检测器感知的条件率全部替换为「真值条件率的 80%」做敏感性分析，重算四阶段累计率与整体成功率，观察整体成功率对哪一阶段最敏感，并解释原因。★★
    提示
    整体成功率等于四个条件率的连乘乘以首阶段累计率，乘积对每个条件率等弹性（各 1% 相对变化引起 1% 相对变化，用对数看即等权）。看起来相同，但实际改进空间不同：条件率越低的阶段，绝对提升 1 个百分点带来的乘法增益越大，优先修最低的条件率。
  3. 用片段 2 计算：若要在真机上分辨「15% 对 25%」与「50% 对 55%」两种差距，各需每组多少条 episode？并说明为什么同样的 5 至 10 个百分点差在高成功率区更难分辨。★★
    提示
    15% 对 25% 约需每组 248 条；50% 对 55% 约需每组 1,562 条。原因在公式里的 p(1−p) 项：接近 50% 时方差最大，需要更多样本才能稳定分辨同样幅度的差异。
  4. 为「同一 Docker 策略在三条件下评测」写一份完整计划：列出每个条件的 episode 来源、配对方式、主指标、样本量与判定标准，并给出一个模拟的决策场景，说明当仿真检测器条件与真机结果方向相反时结论怎么写。★★★
    提示
    计划要点：仿真两条件共用同一 episode 列表与检查点并配对；真机按受控摆放重复会话；主指标为整体成功率与四阶段条件率，附 Wilson 区间；样本量按目标分辨率反推，真机分批累积。若真机点估计高于两个仿真条件（与本讲数据同型），结论写成「真机高于仿真，但区间宽且摆放经过筛选，三个混杂无法拆开；可保留的稳定结论是仿真内部感知替换的约 14 个百分点落差」，不能把真机数字外推为方法的普适水平，也不能据此给真机上的方法排序。
  5. 竞赛复盘指出两支获胜队伍的共同点是错误检测与恢复。请设计一个对照实验量化其贡献：控制检测器与低层技能不变，只加入抓取校验与重试逻辑，说明如何归属成功率增益与步数代价。★★
    提示
    两组同检查点、同 episode、同检测器，唯一变量是校验与重试状态机；指标用整体成功率、部分成功与平均步数三元组；增益归因用抓取条件率的变化，步数代价看平均步数增幅；参照量级为 UniTeam 案例的 0.8% 到 10.8% 与步数增 3.2%。

小结

  • OVMM 的成功率可写成四阶段条件率的连乘：找物、抓取、找容器、放置。累计率转条件率后逐行复核，仿真与真机数表均自洽；条件率是归因的正确读法。
  • 感知是最大单因子。HomeRobot 论文里强化学习组合把感知从真值换成 DETIC 后，整体成功率 14.8% 降到 0.4%（保留 2.7%）；对数分解的贡献为找物 31.1%、抓取 18.5%、找容器 8.7%、放置 41.7%。
  • 真机与仿真的偏差方向不一致：真机 15% 与 20%（n=20）高于仿真真值的 5.1% 与 14.8%，而仿真检测器的 0.4% 最低。原因是 episode 难度、渲染图与真实照片的检测差异、样本量三方面混杂，不能得出简单的「高估」或「低估」。
  • 任务层校验与重试性价比高：UniTeam 用同一 DETIC，把仿真 test-challenge 从 0.8% 提到 10.8%，步数仅增 3.2%（962.2 到 993.2）。
  • 评测可信度要算：分辨 10 个百分点每组约 197 条，分辨 3.3 个百分点约 2,674 条；真机 1/3 与 2/3 的 Wilson 区间重叠，不足以排序；同一策略在两个 split 上 10.8% 与 6.0%，split 噪声约 4.8 个百分点。
  • 下一讲进入训练工程：仿真步速、并行环境数与墙钟时间的换算，把本讲的三条件评测与前一讲的混合训练放到同一张算力账上。
