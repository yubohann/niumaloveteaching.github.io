第二篇 · 模块化：地图·探索·常识

第 040 讲｜第二篇复盘

第二篇从 1997 年的前沿探索走到 2024 年的信息路径规划，共 20 讲。本讲不再引入新方法，把 021 至 039 收进同一张范式总表，用同协议数据实算模块化与端到端的数字账，回答两个问题：模块化在哪些条件下保持优势，端到端在哪些条件下反超。产出物是一张总表、一套协议卡、一份阶段自测与通往第三篇的接口清单。

  • 主题：篇末复盘 / 模块化范式总表 / 模块化与端到端决策
  • 关键公式：Psucc ≈ p检测 · p建图 · p探索 · p导航
  • 预计学时：80 分钟
  • 前置章节：第 039 讲 反直觉：uniform 探索为何最强

学习目标

  • 能在一张表里横向复述 021 至 039 的代表方法：记忆载体、探索与决策、学习成分、代表数字（带协议）、主要边界。
  • 会算同协议数字账：2022 验证集上模块化与端到端的 SR、SPL 差值，以及训练成本、跨数据集迁移的倍数量级。
  • 能按约束选择路线：给定词汇范围、算力预算、数据条件与失败归因需求，判断选模块化、端到端或混合，并写出判据。
  • 能执行一次课程级复盘：为每行结果标注协议卡，拒绝跨协议排序，把失败优先级与误差链纳入结论。
  • 能完成阶段自测，定位自己在第二篇的薄弱环节，并说清第三篇需要补齐的能力（样本效率与端到端配方）。

背景与动机

第二篇的主线是「把长程语义导航拆成模块」。第 021 至 026 讲建立四段式流水线、语义先验与 PointGoal 复用；第 027 至 032 讲处理学习式决策、训练成本、噪声与常识；第 033 至 036 讲进入失败分析、跨楼层、多机协作与信息论规划；第 037 至 039 讲收束评测口径、记忆表示与探索策略。二十讲之后，读者手里有一批方法，但它们的数字来自不同年份、不同数据集、不同判据，直接并排会得出错误结论。

复盘的任务是把可比性重新建立起来。做法分三层：第一层，把方法放回统一维度（记忆、探索、学习、评测），看清设计空间；第二层，只在同协议内做数字比较，跨协议只比能力与成本；第三层，把误差链与失败优先级纳入结论，回答「改哪里收益最大」。本讲按这三层组织，并在末尾给出阶段自测与第三篇接口。

口径提醒：本讲引用的所有成绩都带来源与协议标注；第 037 讲建立的口径卡是每张表的必备件。任何缺少数据划分、成功判据、检测来源与步数上限的数字，只能作为线索，不能参与排名。

核心原理

1. 模块化范式的四个维度

把 021 至 039 的方法放在四个维度上观察，设计空间就清晰了。

  • 记忆载体：占据栅格（FBE 与前沿系列）、2D 语义图（SemExp、MOPA、L3MVN、MFNP）、部分语义图（PONI）、导航图与房间结构（ESC）、三维概率图（IPPON）、3D 场景图（第 038 讲与第四篇）。载体决定查询能力与维护成本。
  • 探索与决策：最近前沿（几何）、学习式覆盖（ANS）、目标导向语义策略（SemExp）、均匀采样（MOPA）、势函数（PONI）、语言模型前沿打分（L3MVN）、常识谓词约束（ESC）、信息增益路径（IPPON）、多楼层因子决策（MFNP）。第 039 讲证明这一维度的强弱依赖任务分布。
  • 学习成分：无学习（FBE、Stubborn、MOPA 探索）、强化学习（ANS、SemExp）、监督学习（PONI）、零训练加基础模型（ESC、L3MVN、MFNP、IPPON）、复用预训练策略（MOPA 导航）。训练成本由此拉开数量级。
  • 评测口径：成功率、SPL、SoftSPL、DTG、进度与 PPL；成功判据随年份与平台变化（2020 与 2021 用 1 m 加 oracle 可见；部分 2024 年论文自述 0.1 m 停止距离）。协议不同，数字不可直接排序。

四个维度共享一条误差链：Psucc ≈ p检测 · p建图 · p探索 · p导航。取 (0.90, 0.95, 0.90, 0.90) 的示意参数，合成成功概率 0.6925，与模块化系统在挑战验证集上的量级一致。该式为乘法链，任何一环的短板决定整体上限；第 029 讲已给出检测误差在建图与探索中的传播公式。

第二组协议来自 2023 至 2024 年的零样本模块化工作，采用 MFNP 论文内部设定（HM3D 全集、停止判据为论文自述的 0.1 m，与挑战口径不同）：ESC 39.2 / 22.3，L3MVN 50.4 / 23.1，VLFM 52.5 / 30.4，TriHelper 56.5 / 25.3，MFNP 58.3 / 26.7。相对变化：MFNP 对 VLFM 成功率 +5.8 个百分点（相对 +11.05%），对 ESC +19.1 个百分点（相对 +48.72%）；VLFM 对 ESC +13.3 个百分点（相对 +33.93%）。零样本模块化在不到两年的公开结果里进步幅度超过 19 个百分点，说明「被端到端反超」的结论有年份边界；引用时先看论文的检测来源与判据，再看数字。

4. 成本与迁移：模块化的两张底牌

第一张底牌是训练成本。PONI 用 40 万条离线俯视样例、3 个 epoch 完成监督，约 120 万次监督通过；论文报告的 GPU 小时比中，SemExp 约为其 7 倍（Gibson 口径，对手不同），端到端 RL 约为其 1600 倍（MP3D 口径）。MOPA 完全不训练新模块，复用公开 PointNav 权重与零样本检测器；整轮评测耗时 12 小时，分析式规划器基线为 48 小时（同为 MultiON 2.0 评测规模）。成本对比必须标注对手，第 028 讲已给出换算注意事项。

第二张底牌是跨域迁移。MOPA 的 PointNav 在 MP3D 训练后直接用于 HM3D 的 MultiON 2.0，PredSem 保持成功率 38%；同场竞技的三个端到端模型从 MP3D 换到 HM3D 后成功率落在 0.3% 至 0.5%。按 0.4% 折算，模块化复用是端到端迁移成绩的约 95 倍（38 / 0.4）；按 0.3% 与 0.5% 折算区间为 76 至 126.7 倍。第 020 讲的开放词汇证据给出另一面：端到端 DAgRL 在词汇扩档时成功率从 41.3% 降到 18.3%（落差 23.0 个百分点），模块化 VLFM 三档极差 2.8 个百分点；噪声注入下 VLFM 的 SR 最多降 6.1 个百分点，DAgRL 加开放检测器最多降 0.3 个百分点。迁移与稳健性的证据按方法组合而不同，不能按「模块化对端到端」一刀切。

数字账结论

同协议下，模块化的天花板由检测质量决定：真值检测时与训练充分的端到端同档，零样本检测时落后 32 至 35 个百分点。模块化的稳定优势在训练成本（低至 1/1600 量级）与跨域迁移（约 95 倍量级）。选择路线时先问感知条件与数据预算，再看范式标签。

5. 失败与误差链：复盘的第二条主轴

只比较成绩会漏掉「改哪里」。第 033 讲把 PIRLNav 在 HM3D 语义 v0.1 的 592 条失败分成八类：标注缺失 27%、跨楼层 21%、识别失败 20%、最后一公里 12%、导航网格失败 9%、语义混淆 5%、绕圈 4%、探索失败 2%；按层级归并为数据 36%、跨层 21%、感知 25%、执行 12%、记忆 6%。修复上界按增量排序后，依次是数据审计 +7.99、跨楼层 +6.22、识别与再感知 +5.92、最后一公里 +3.55 个百分点。排序直接给出工程优先级：先修数据与跨层结构，再修感知，最后处理记忆与探索病理。

把这条主轴与四个维度对齐：记忆载体决定绕圈与探索失败的可观测性（第 038 讲的对齐键与访问计数）；探索策略决定覆盖不足的占比（第 039 讲的换点日志）；检测来源决定识别与语义混淆（第 029 讲的噪声公式）；执行与局部规划决定最后一公里（第 026 讲的复用策略）。复盘表若只列 SR 与 SPL，就无法回答「失败集中在哪一层」。

8. 未解问题与第三篇接口

  • 感知瓶颈：同协议下检测来源造成 34 个百分点的落差，超过任何单模块改进。开放词汇检测与再感知是第四篇主题。
  • 评测协议：成功视点采样稀疏会让「已到 1 m 内且目标可见」的轨迹被判失败（MOPA 作者的建议）；跨论文比较前先统一判据。
  • 语义结构依赖：探索与常识方法的收益取决于任务分布是否保留语义结构；随机放置与真实布局两个极端之间需要统一的评测集。
  • 成本口径：训练成本倍率依赖对手与数据集，跨论文不可换算；复现实验必须报告基准自身的算力。
  • 第三篇接口：端到端路线要用配方解决样本低效（DD-PPO 的 2.5B 步、表征预训练、辅助任务、模仿学习两阶段），第 041 讲从 CNN + RNN 的过拟合与样本效率讲起，第 060 讲与本篇总表会再做一次同协议对照。

关键代码与解读

两段代码把复盘规则工具化：按协议分组的比较与协议卡完整性检查。

片段 1：按协议分组的比较

def compare(rows):
    """只在同协议组内计算差值；跨协议只输出警告。"""
    groups = {}
    for r in rows:
        groups.setdefault(r["protocol"], []).append(r)   # protocol 为协议卡键
    for proto, group in groups.items():
        print("协议:", proto, "共", len(group), "行")
        group = sorted(group, key=lambda x: x["sr"], reverse=True)
        for i in range(1, len(group)):
            base, cur = group[i - 1], group[i]
            print("  %s - %s: dSR=%+.1f dSPL=%+.3f" % (
                base["name"], cur["name"],
                base["sr"] - cur["sr"], base["spl"] - cur["spl"]))
    if len(groups) > 1:
        print("警告：存在多协议，禁止跨组排名")

解读：（1）协议键是分组依据，缺省或拼写不一的键会让本应同组的数字分散；（2）组内排序与差值自动完成，避免手工并排造成跨协议污染；（3）多协议警告让复盘表在生成阶段就暴露可比性问题；（4）输出只含 SR 与 SPL，扩展到 SoftSPL、DTG 只需加字段。

片段 2：协议卡完整性检查

REQUIRED = ("dataset", "split", "success", "detection",
            "action_space", "horizon", "metrics", "source")

def check_card(row):
    """缺字段的行不得进入总表；返回缺失清单供修正。"""
    missing = [k for k in REQUIRED if not row.get(k)]
    if missing:
        return {"ok": False, "missing": missing,
                "hint": "补齐后再参与排名"}
    if row["success"] == "custom" and row["metrics"] == "sr_only":
        return {"ok": False, "missing": ["spl_def"],
                "hint": "自定义判据必须同时给 SPL 定义"}
    return {"ok": True, "missing": []}

解读：（1）八个必需字段覆盖数据、判据、动作、指标与来源，任何一项缺失即退回；（2）自定义判据与单指标组合被显式拦截，对应「跨协议 SR 虚高」这一常见问题；（3）返回缺失清单取代布尔值，便于批量修复；（4）该检查可与上一段比较函数串联，先过卡再分组。

常见坑

  • 跨协议并排数字：症状是把 2020 挑战、2022 验证集与 2024 论文自述的结果放进同一张排名表，得出模块化退步或进度的错误结论。根因是成功判据、数据集与检测来源不同。修复：先写协议卡，再按协议分组；跨组只对照能力与成本。
  • 单指标排名：症状是只按 SR 排序，把高 SR 低 SPL 的方案放在最优。根因是忽略 SPL 的子集分解（第 004 讲）与 SoftSPL 的失败路径惩罚（第 005 讲）。修复：SR、SPL 成对报告，必要时加 SoftSPL 与 DTG。
  • 检测口径混淆导致归因错位：症状是把 PredSem 30 / 14 与 OracleSem 64 / 32 的差距归因到探索或建图。根因是两行只换了检测来源。修复：总表增设检测列，任何单模块对照都必须共享其余模块。
  • 零样本与训练方法混榜：症状是用 PredSem 与 PIRLNav 的排名证明范式优劣。根因是训练数据与算力不在同一档。修复：榜单分「零训练 / 轻量监督 / 大规模训练」三区，或并列报告训练成本。
  • 成本倍率不标对手：症状是引用「1600 倍」作为通用结论。根因是该比值来自 PONI 与特定端到端基线的对比，换对手与数据集即失效（SemExp 口径为 7 倍）。修复：成本对比附基准名与数据集口径，缺一不可引用。

小结

  • 第二篇四个维度：记忆载体、探索与决策、学习成分、评测口径；误差链 Psucc ≈ p检测 · p建图 · p探索 · p导航，示意参数下合成 0.6925。
  • 范式总表收录 FBE、ANS、SemExp、Stubborn、MOPA、PONI、ESC、L3MVN、Co-NavGPT、MFNP、IPPON；每行数字带协议，跨行不可排名。
  • 同协议数字账：真值检测时模块化 64 / 32 与 PIRLNav 62 / 28 同档；零样本检测时 PredSem 30 / 14 落后 OVRL2 35 个百分点；检测来源造成 34 个百分点落差，超过任何单模块改进。
  • 模块化的两张底牌：训练成本低至 1/1600 量级（对手相关）、跨域迁移约 95 倍（0.3% 至 0.5% 对 38%）；零样本模块化 2023 至 2024 年仍在快速进步（ESC 39.2 到 MFNP 58.3）。
