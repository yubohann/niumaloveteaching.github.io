第 084 讲｜噪声建模与本体参数：LoCoBot 与 PyRobot

第 083 讲列出了现实化改造清单，本讲把其中「注入噪声」与「按 LoCoBot 设本体」两项落到具体参数。2020 挑战的本地配置给出：智能体半径 0.18 m、身高 0.88 m，相机位于 0.88 m；PointNav 的 RGB 与深度为 640×360、水平视场 70°，深度范围 0.1 至 10 m；动作配置为 pyrobotnoisy，噪声模型机器人为 LoCoBot、控制器为 Proportional、噪声倍率 0.5；RGB 使用高斯强度噪声（强度常数 0.1），深度使用 Redwood 噪声模型。致动噪声的底层参数来自 habitat-sim 的 PyRobot 噪声实现：LoCoBot 的 Proportional 控制器在直线运动中的前向位移噪声均值 0.017 m、方差 0.007，转向上叠加的标准差约 9.24°；转向动作的转角噪声标准差约 7.47°。所有采样都做 3σ 截断并保持指令方向的符号。本讲复算这些参数在半倍噪声下的有效值，用蒙特卡洛给出开环漂移量级，并说明该模型只是可标定的现实化旋钮：论文在受控环境中发现噪声倍率取 0.0 时仿真预测性反而最高。

  • 主题：LoCoBot 本体 / PyRobot 致动噪声 / RGB 与深度噪声 / 噪声注入接口
  • 关键公式：xt+1 = xt + D(at) + m·εlin；θt+1 = θt + at + m·εrot；Inoisy = clip(I/255 + ε·c, 0, 1)·255
  • 预计学时：85 分钟
  • 前置章节：第 083 讲（现实化改造：去 GPS、噪声与禁滑动）

学习目标

  • 理解：说清 LoCoBot 本体、相机与动作参数在 2020 挑战配置中的取值，以及它们与早期默认本体的差异。
  • 会推导：写出截断多元高斯致动噪声的采样语义，包括 3σ 截断、指令方向 5% 下限与符号保持三条规定。
  • 会算：复算半倍噪声下的前向位移分布、转角分布、百步开环漂移与深度误差随距离的增长。
  • 会实现：按官方语义实现致动噪声采样器与 RGB、Redwood 两种传感噪声注入，并接入回放与评测流程。
  • 会判断：区分「可标定的现实化参数」与「真机实测常数」，按实验目的选择噪声倍率并设计敏感性分析。

背景与动机

第 083 讲回答了「为什么要现实化」，本讲回答「现实化的数值从哪来、怎么实现」。噪声参数是 Sim2Real 研究里最容易误用的对象：报出一个倍率或标准差很容易，说清它的控制器条件、采样语义与适用边界很难。2020 挑战的设计有一个可复现的优点：致动噪声有明确的实测来源，即 PyRobot 团队用动捕设备对 LoCoBot 做动作基准测试后发布的参数表，habitat-sim 以开源代码固定了采样语义；传感噪声同样是两个具名模型。读懂这份参数表，才能回答后续问题：奖励曲线为什么抖动、真机迁移为什么在开环段失效、评测该开哪一档噪声。

本讲同时为第 085 讲铺路。SemExp 的真机结论是「完美的位姿与深度不构成迁移成功的必要条件」，这个判断要在噪声量级已知的前提下才有意义；第 085 讲会把模块化结构与这份噪声参数对照，解释哪些模块天然抗噪。

2. 致动噪声的模型结构

PyRobot 噪声模型按「机器人、控制器、运动类型」三层组织。机器人有 LoCoBot 与 LoCoBot-Lite；控制器有 ILQR、Proportional、Movebase 三种；运动类型分直线运动与转向运动。每种运动又被分解为平移与转角两个通道，每通道是一个截断多元高斯：

ε = (εtrans, εrot)，εtrans ~ N(μ2, Σ2)，εrot ~ N(μ, σ2)

采样语义有三条规定。第一，逐维 3σ 截断：每个分量限制在均值加减三倍标准差之内。第二，指令方向下限：直线运动时平移的前向分量下界取 −0.95 倍指令位移，转向运动时转角分量下界取 −0.95 倍指令弧度，保证智能体始终朝指令方向至少移动或转动约 5%。第三，符号保持：平移噪声乘以指令位移的符号，转角噪声乘以指令转角的符号，避免前进系统性过冲、后退系统性不足这类偏置。施加方式为：

xt+1 = xt + (at + m·εtrans,∥)·f + m·εtrans,⊥·l，θt+1 = θt + at·s + m·εrot

其中 f 与 l 为机体的前向与左向单位向量，s 为转角符号，m 为噪声倍率。注意倍率在采样之后、截断之后相乘，因此倍率变小会让「至少保留 5% 位移」的相对下限变松，实际最小位移比例上升。挑战配置取 m = 0.5，控制器取 Proportional，此为下表参数。

4. 单步分布与开环漂移实算

按官方采样语义做两组实算。先看单步：前向指令 0.25 m、半倍噪声下，3σ 截断与 5% 规则的联合下界为原始均值减三倍标准差（−0.234 m）与 −0.95×0.25 m（−0.2375 m）中的较大者，即 −0.234 m；半倍后最小位移为 0.25 − 0.117 = 0.133 m，占指令的 53.2%。对 20 万次采样统计，前向位移均值 0.258 m、1% 分位 0.163 m、99% 分位 0.353 m。转向指令 30°、半倍噪声下，最小转角 20.03°（66.8%），转角均值 31.23°、1% 分位 22.72°、99% 分位 39.74°。

5. 传感噪声：RGB 与 Redwood 深度

彩色图采用加性高斯强度噪声，语义为：先把像素归一化到 [0, 1]，加上均值 0、标准差为 1 再乘以强度常数的噪声，裁剪回 [0, 1] 后还原到 [0, 255]：

Inoisy = clip(I/255 + (N(0, 1)·σ0 + μ0)·c, 0, 1) · 255

模型默认强度常数 c = 0.2、均值 0、标准差 1；挑战配置把 c 调到 0.1，对应归一化尺度上 0.1 的标准差，即灰度级上 25.5 级；默认值对应 51 级。噪声超过 0.5（约 5 倍标准差）的概率为 5.7×10⁻⁷，裁剪几乎不触发。强度常数乘在标准差上，因此 c 与噪声标准差线性相关，c = 0.1 比默认值噪声减半。

深度图采用 Redwood 噪声模型，源于 Redwood 室内数据集的立体深度噪声研究。其链路为：像素坐标按 0.25 倍噪声倍率的抖动进行重采样；深度值做 2×2 下采样；超过 10 m 的深度直接返回 0，表示无效；其余深度经查表得到的畸变系数还原，最后通过一个量化公式写入输出：

denom = round((35.130/d + N(0, 1)·0.027778·md) · 8)，dout = 281.04 / denom

其中 md 为深度噪声倍率，挑战配置使用默认值 1.0。用单位畸变表隔离量化链路后，对平面深度做 30 帧模拟，得到误差随距离平方增长的结果：1 m 处标准差 0.6 mm、2 m 处 7.1 mm、3 m 处 13.1 mm、5 m 处 25.8 mm、9 m 处 88.7 mm；10 m 处全部标记无效。解析上，随机项贡献约 0.00079·d²，量化项贡献约 0.0010·d²，两者量级相当。深度误差在 5 m 处仍是厘米级，在近场可忽略；失效模式集中在远场与无效值处理，精度本身尚可。真实模型还叠加了数据拟合的畸变表，上述数值应视为误差下界。

6. 参数标定的边界

三条规定必须写进使用说明。第一，致动噪声来自特定控制器、地面与维护状态的基准测试，控制器不同参数表不同，跨平台引用先核对控制器名称。第二，噪声倍率是最常用的标定自由度，官方网格搜索范围为 0 到 1、步长 0.1，倍率与预测性的关系取决于任务与环境，需要重新标定。第三，传感噪声在官方文档中有明确工程提示：开启会降低仿真速度，建议训练初期关闭、微调阶段再开，评测时与提交配置保持一致。此外，ObjectNav 赛道不注入传感噪声，其本地配置也没有 pyrobotnoisy 动作空间；不要把本讲的噪声参数套到该赛道。

关键代码与解读

三段代码分别实现致动噪声采样、带噪声的动作步进、传感噪声注入，语义与 habitat-sim 的 PyRobot 实现一致。

片段 1：截断多元高斯采样（对齐官方语义）

import numpy as np

def trunc_normal(mean, var, lo, hi, n, rng):
    """逐维 3σ 截断加显式边界；用拒绝采样实现，多维独立。"""
    sd = np.sqrt(var)
    lo = np.maximum(lo, mean - 3.0 * sd)          # 3σ 下界
    hi = np.minimum(hi, mean + 3.0 * sd)          # 3σ 上界
    out = np.empty(n)
    filled = 0
    while filled < n:
        z = rng.standard_normal(n - filled) * sd + mean
        ok = (z >= lo) & (z <= hi)
        out[filled:filled + ok.sum()] = z[ok]
        filled += int(ok.sum())
    return out

# LoCoBot / Proportional 直线运动：平移 [前向, 侧向]，转角
LOCOBOT_PROP_LIN = dict(t_mean=[0.017, 0.042], t_var=[0.007, 0.023],
                        r_mean=0.031, r_var=0.026)
print(LOCOBOT_PROP_LIN)

解读：（1）方差的平方根是标准差，代码把「三倍标准差」写成 ±3σ 的显式边界，避免把方差当标准差错用。（2）拒绝采样对独立维度逐维处理，与官方实现对每个维度单独截断的语义一致。（3）边界参数 lo、hi 与 3σ 取交集，后续动作层只需传入 −0.95 倍指令量的下限即可复现「至少保留 5% 位移」的规则。

片段 2：带噪声的动作步进

import numpy as np

def noisy_step(pose, action, rng, mult=0.5, step=0.25, turn=np.deg2rad(30.0)):
    """pose=(x, y, theta)；action 取 'forward' 或 'turn_left'。"""
    x, y, th = pose
    if action == "forward":
        lo = -0.95 * step                                  # 指令方向下限
        d = step + trunc_normal(0.017, 0.007, lo, np.inf, 1, rng)[0] * mult
        lat = trunc_normal(0.042, 0.023, -np.inf, np.inf, 1, rng)[0] * mult
        rot = trunc_normal(0.031, 0.026, -np.inf, np.inf, 1, rng)[0] * mult
    else:
        lo = -0.95 * turn
        d = trunc_normal(0.001, 0.001, -np.inf, np.inf, 1, rng)[0] * mult
        lat = trunc_normal(0.005, 0.004, -np.inf, np.inf, 1, rng)[0] * mult
        rot = turn + trunc_normal(0.043, 0.017, lo, np.inf, 1, rng)[0] * mult
    f = np.array([np.cos(th), np.sin(th)])                 # 机体系前向
    l = np.array([-np.sin(th), np.cos(th)])                # 机体系左向
    p = np.array([x, y]) + f * d + l * lat
    return (p[0], p[1], (th + rot + np.pi) % (2 * np.pi) - np.pi)

解读：（1）倍率乘在采样之后，与官方实现顺序一致；若乘在均值与方差上会改变截断边界的相对位置，产生系统性差异。（2）直线运动同时注入平移与转角噪声，转角噪声的标准差 4.62° 是长轨迹漂移的主导项；转向运动同样带平移噪声，对应实体机器人旋转时的轮地滑移。（3）航向归一化到 (−π, π] 便于后续策略网络读取，不影响物理量。

片段 3：RGB 高斯与 Redwood 深度注入

import numpy as np

def gaussian_rgb(image_u8, rng, intensity_constant=0.1):
    """image_u8: H×W×3，单位 0 至 255；返回同形状无符号字节图。"""
    noise = rng.standard_normal(image_u8.shape) * intensity_constant
    noisy = np.clip(image_u8 / 255.0 + noise, 0.0, 1.0) * 255.0
    return noisy.astype(np.uint8)

def redwood_depth(depth_m, rng, multiplier=1.0):
    """按官方公式复刻量化链；depth_m 为浮点深度图，单位米。"""
    h, w = depth_m.shape
    rn = rng.standard_normal((h, w, 3))
    ys = np.clip(np.arange(h)[:, None] + rn[:, :, 0] * 0.25 * multiplier, 0, h - 1)
    xs = np.clip(np.arange(w)[None, :] + rn[:, :, 1] * 0.25 * multiplier, 0, w - 1)
    yi, xi = ys.astype(int), xs.astype(int)
    d = depth_m[yi - yi % 2, xi - xi % 2]                  # 2×2 下采样
    invalid = d >= 10.0                                    # 远场直接无效
    denom = np.round((35.130 / np.where(invalid, 1.0, d)
                      + rn[:, :, 2] * 0.027778 * multiplier) * 8.0)
    out = 281.04 / np.where(denom <= 0, 1.0, denom)
    return np.where(invalid, 0.0, out)

解读：（1）RGB 噪声在归一化尺度上采样，强度常数直接是标准差；官方默认 0.2，挑战配置 0.1，改动前先确认指标是按原始图像还是归一化图像统计。（2）深度链的误差有两项：0.027778 倍的随机项与 round 引入的量化项，两者都随距离的平方增长；10 m 以上返回 0，不采用裁剪到 10 的处理，下游必须把 0 当作无效值剔除，直接参与点云会污染地图。（3）两段代码都只依赖随机数发生器，接口简单；代价是循环版本较慢，工程上应向量化或启用 GPU 实现，同时用固定种子保证回放可复现。

常见误区

  • 把方差当标准差：症状是写出「转角噪声 0.026 弧度」这类数字。根因是参数表存的是方差，官方代码中显式取平方根。修复：读取后先开方再解释；半倍倍率下直线转角标准差为 4.62°，由 √0.026 × 0.5 得到。
  • 截断与倍率的顺序写反：症状是复现出的最小前向位移与官方对不上。根因是官方在原始尺度做 3σ 截断与 5% 下限，再把样本乘以倍率；顺序颠倒会改变下限与截断边界的相对位置。修复：按官方顺序实现；半倍时前向最小位移为 0.133 m（53.2%），转向最小转角为 20.03°（66.8%）。
  • 控制器与机器人配置不匹配：症状是照抄参数后漂移量级对不上。根因是 ILQR、Proportional、Movebase 三套参数差异明显，LoCoBot 与 LoCoBot-Lite 也不同表。修复：先核对配置里的 ROBOT 与 CONTROLLER 字段；挑战配置为 LoCoBot 加 Proportional。
  • 把深度 0 当作 0 米：症状是点云出现贴脸噪点、占据栅格被填满。根因是 Redwood 模型对 10 m 以上返回 0 表示无效。修复：滤波时先剔除 0 与超出量程的值，再投影；同时注意 ObjectNav 配置的深度量程是 0.5 至 5 m，与 PointNav 的 0.1 至 10 m 不同。
  • 只在训练时开噪声、评测时关掉：症状是提交分数与本地验证差距大。根因是评测口径与训练分布不一致，策略在验证集上「过度干净」。修复：验证与提交必须使用同一份噪声配置；敏感性分析另开实验臂，不混入正式验证。

练习与思考

  1. 复算：LoCoBot Proportional 直线运动的转角噪声方差为 0.026，在倍率 0.5 下标准差是多少度？该值在 100 步随机游走下的朝向标准差约为多少度？★
    提示
    标准差为 √0.026 × 0.5 = 0.0806 rad = 4.62°；100 步独立随机游走按 √100 放大，约 46.2°，与蒙特卡洛实测 45.37° 一致。
  2. 推导：设前向指令位移为 a，平移前向噪声服从均值 μ、标准差 σ 的截断正态，求实际位移的期望下界与 3σ 上界表达式，并代入 a = 0.25、μ = 0.017、σ = 0.0837、倍率 0.5 计算。★★
    提示
    下界由 max(μ−3σ, −0.95a) 与倍率共同决定：0.017 − 3×0.0837 = −0.234，大于 −0.2375，故原始下界 −0.234，半倍后位移下界 0.25 − 0.117 = 0.133 m；上界为 (μ + 3σ)×0.5 + a = (0.017 + 0.251)×0.5 + 0.25 = 0.384 m。注意先截断后乘倍率。
  3. 设计一个噪声倍率标定实验：在固定回合集与策略检查点上，扫描倍率 0、0.25、0.5、1.0，给出要记录的指标、判断最优倍率的口径，以及如何避免过拟合到单个环境。★★★
    提示
    指标至少包含 SR、SPL、SoftSPL、碰撞计数与平均航向漂移；若目标是预测性，用多个小模型（或同一模型多个检查点）构成「模型集合」，分别计算仿真与真机（或高保真参照）指标的相关系数，选择相关系数最高的倍率。避免过拟合：至少两个环境族、每档多个种子，并报告相关系数的置信区间；同时固定回合集与动作序列。
  4. 用片段 3 推导：Redwood 深度链中随机项导致的深度标准差为什么近似与真实距离平方成正比？给出量级估计式并解释量化项在近场为何可能占主导。★★
    提示
    输出深度对分母的灵敏度为 −281.04/denom²，denom 约等于 281.04/d，故随机项标准差约为 0.00079·d²。量化项来自 round 的 ±0.5 格，贡献约 0.0010·d²，在 1 至 3 m 处与随机项同量级或更大，因此在近场不可忽略。
  5. 若把动作噪声从训练到评测全程关闭，但保留禁用滑动与去 GPS 两项改造，预测 SR、SPL 与碰撞次数的变化方向，并说明哪些结论可以从 083 讲的 CODA 网格搜索结果外推、哪些不能。★★
    提示
    关闭噪声后位移更可控，SR 与 SPL 通常上升、碰撞次数下降；但 CODA 的最优噪声倍率 0.0 来自特定受控环境与预测性目标，外推到「所有任务都该关闭噪声」没有依据。可以外推的是「噪声倍率需要按环境标定」这一方法论；不能外推的是具体的最优值。

小结

  • 本体与相机参数：挑战配置为半径 0.18 m、身高 0.88 m、相机位于 0.88 m；PointNav 用 640×360、水平视场 70°、深度 0.1 至 10 m，成功半径 0.36 m；ObjectNav 用 640×480、水平视场 79°、深度 0.5 至 5 m。
  • 致动噪声结构：按机器人、控制器、运动类型分层，平移与转角通道各自服从截断多元高斯，逐维 3σ 截断、指令方向 5% 下限、符号保持三条语义固定。
  • LoCoBot Proportional 半倍有效值：直线运动前向位移标准差 4.18 cm、转角标准差 4.62°；转向动作转角标准差 3.74°；控制器换档会显著改变量级。
  • 漂移量级：百步开环在倍率 0.5 下终点误差均值约 19.0 m、朝向标准差 45.4°；32 步方形闭环（回路 5 m）误差均值约 0.68 m；论文在 CODA 中发现倍率 0.0 预测性最优，说明该模型属于可标定旋钮，不能当作真机常数。
  • 传感噪声：RGB 强度常数 0.1 对应 25.5 灰度级标准差；Redwood 深度误差随距离平方增长，5 m 处约 2.6 cm，10 m 以上返回 0 表示无效。
  • 下一讲进入 SemExp 真机迁移：模块化结构如何绕开精确位姿与深度的依赖，20 次真机试验的 65% 成功率能支持什么结论、不能支持什么结论。
