第四篇 · 开放词汇与大模型

第 072 讲｜GOAT I：多模态终身导航

第 071 讲的 ConceptGraphs 证明了对象化、开放词汇的 3D 图可行；本讲读 GOAT（Chang 等 2023，arXiv:2311.06430），把对象图推进为实例感知的终身记忆，并搬上真机。GOAT 统一处理类别、图像、语言三类目标，按类别过滤后用 SuperGlue 做图图匹配、用 CLIP 做语言匹配，探索阶段用阈值、探索结束后取最高分。系统在 9 个真实家庭、90 小时、675 个目标、200+ 个对象实例上报告平均成功率 83.0%（类别 94.3、图像 86.4、语言 68.2），相对 CLIP on Wheels 提升 32.3 个百分点；同一家庭内随经验从首个目标 60% 提升到探索后的 90%。本讲拆解记忆结构与失败面，为第 073 讲的 GOAT-Bench 协议打底。

  • 主题：实例感知记忆 / 多模态目标匹配 / 真机终身导航
  • 关键公式：Ci ← Ci ∪ Cd，Mi ← Mi ∪ {Id}；arg minA,b Σ‖Di − A·Xi − b‖²
  • 预计学时：75 分钟
  • 前置章节：第 071 讲（ConceptGraphs：开放词汇 3D 图）

学习目标

  • 会拆：GOAT 的两层记忆（语义地图与对象实例记忆）的字段、更新时机与查询路径，解释“实例感知”与“类别感知”的区别。
  • 会算：三类目标的成功率与 SPL、与 CoW 及两组消融的差值、经验提升曲线，以及深度补洞最小二乘的闭式解。
  • 会实现：实例匹配的三个关键动作（类别过滤、CLIP 或 SuperGlue 打分、跨视图取最大），以及实例记忆的增量更新。
  • 会判断：探索阶段阈值与探索后最高分两种决策模式的区别，阈值口径在论文不同章节的差异，以及语言目标为何比图像目标难。
  • 会设计：把 90 小时真机实验读成可复现协议（目标序列、预算、判据、方差），并给出记忆消融的判读标准。

背景与动机

第 062 讲的 CLIP on Wheels（CoW）用 CLIP 特征匹配“记忆里所有看过的图像”，能处理多模态目标，但分不清同类实例，阈值也难以调稳：整帧特征既包含目标也包含背景，误匹配与漏匹配同时存在。第 071 讲的 ConceptGraphs 给出了对象化表示，但它的下游实验以查询与演示为主，没有回答在真实家庭里“连续找 5 至 10 个目标、越找越快”的长期运行问题。GOAT（GO to Any Thing）把问题形式化为多模态终身导航：智能体在一个未见环境中依次接收类别、图像或语言描述的目标，允许维护并使用过去经验，考察的不只是单次成功率，还有同一环境内效率随时间的提升。

与第 071 讲的对象图相比，本讲有三点推进：记忆从“建好供查询”变为“持续增长的实例集合”，每个实例保留多视角外观；匹配从“语言标签加 LLM 推理”变为可实时执行的 CLIP 与 SuperGlue 打分；验证从数据集实验变为 9 个真实家庭、200 多个实例的部署级实验。这三点也是第四篇从方法走向系统的标志，第 073 讲将把它们搬进可复现的仿真基准。

核心原理

1. 任务定义与评测协议

GOAT 任务是目标序列导航：机器人随机出生在未见室内环境，接收 5 至 10 个目标 g1, …, gK，每个目标可以是类别名（如 SINK）、唯一标识对象的图像，或唯一标识对象的语言描述（如“沙发旁的盆栽”）。到达当前目标或耗尽时间预算后，立即接收下一个目标，场景不重置。每个时刻机器人可获取 RGB 图像 It、深度图 Dt 与位姿读数 xt，并可维护由观测计算出的记忆。

真机实验协议（Chang 等 2023，方法节）：每目标成功判据是调用停止动作时距正确实例小于 1 m，且在该目标上不超过 200 步；SPL 的参考路径按测地距离，从上一个目标的实例位置算到当前目标实例（第一个目标从出生点算）。这个“参考起点随子任务滑动”的细节很关键，第 073 讲的仿真协议沿用同一思想但预算不同，两套协议的数字不可直接互比。9 个家庭、10 条轨迹每家庭、5 至 10 个目标每轨迹，合计 90 条轨迹、675 个目标、200+ 个实例，总时长 90 小时，平均每家庭 10 小时、每目标 8.0 分钟、每轨迹 7.5 个目标。

2. 系统架构：两层记忆加两级策略

GOAT 是无训练模块化系统，感知、建图、匹配、规划各自独立：

3. 深度补洞：最小二乘对齐

玻璃、镜面等反射物体的深度读数会缺失。GOAT 用单目深度估计得到相对深度 Xt,i，再用有读数的像素 Dt,i 拟合线性对齐参数：

arg minA,b Σi ‖ Dt,i − A·Xt,i − b ‖²

这是一个一元线性回归，两个正规方程解出闭式：

A = (n·Σ XiDi − Σ Xi · Σ Di) / (n·Σ Xi² − (Σ Xi)²)；b = (Σ Di − A·Σ Xi) / n

数值算例：取三个有读数的像素 X = (1.0, 2.0, 3.0)、D = (1.1, 2.0, 2.9)，n = 3，ΣX = 6.0，ΣD = 6.0，ΣXD = 13.8，ΣX² = 14.0，得 A = (3 × 13.8 − 6.0 × 6.0) / (3 × 14.0 − 36.0) = 5.4 / 6.0 = 0.900，b = (6.0 − 0.900 × 6.0) / 3 = 0.200，即 D ≈ 0.900·X + 0.200，残差在数值精度内为 0。实际使用中只对无读数的像素填 A·X + b，有读数像素保持原值，避免把估计噪声引入几何。

4. 对象实例记忆：结构与更新

实例记忆 ot 是检测随时间的聚类。每个实例 i 由三部分构成：地图中的细胞集 Ci、外观视图集 Mi（带背景的包围盒图像）、语义类别 Si。对每个新检测 d（框 Id、类别 Sd、投影细胞 Cd），先把 Cd 膨胀 p 个格子得到 Dd，再与已有实例逐一比对：

匹配条件：Sd = Si 且 Dd ∩ Ci ≠ ∅

命中则更新 Ci ← Ci ∪ Cd，Mi ← Mi ∪ {Id}；否则新建实例。膨胀的作用是容忍投影误差与视角差异，避免同一物体因几厘米的配准漂移被拆成两个实例。与第 071 讲的节点融合相比，这里视图以原始图像保存，特征不预先合并，匹配时对每个视图单独打分再聚合。这样做让图像目标可以直接用几何关键点匹配，语言目标用 CLIP 在视图集上取最大分，两种匹配器共用同一份记忆，不需要为不同模态各存一套特征。

记忆规模随时间单调增长，但室内场景的实例数有限。以 9 个家庭平均 200 / 9 ≈ 22.2 个实例每家庭、675 / 200 ≈ 3.4 个目标每实例计，单个家庭的目标远多于实例数，这正是终身记忆能带来收益的结构性原因：同一实例被反复作为目标出现，记忆命中就能跳过探索。评价记忆时既要看成功率，也要看 SPL，前者反映“找不找得到”，后者反映“找得省不省”。

5. 目标匹配：类别过滤加双匹配器

给定新目标，全局策略先在记忆里定位实例，方法按模态分流。类别目标：直接查询语义地图是否出现过该类，若有则选距离最近的实例。语言目标：先用 Mistral 7B 从描述中抽类别（如从“沙发旁的盆栽”抽出类别），再对记忆里该类别实例的所有视图与描述做 CLIP 余弦匹配。图像目标：先用 Mask R-CNN 从目标图中抽类别，再对该类别实例的所有视图做 SuperGlue 关键点匹配。三条路径都遵守同一条原则：先在目标类别内做匹配，再跨视图聚合。论文补充材料报告，类别过滤使匹配准确率提升 23%，扩大包围盒保留背景上下文使另一组实验提升最多 22%，图像目标匹配比语言目标匹配成功率高 23%。

探索进行中的匹配与探索结束后的匹配使用不同决策规则。探索中记忆不完整，必须设阈值：方法节给出语言匹配 0.28、图像匹配 6.0 两个阈值；补充材料给出的离线实验用的是 0.75 与 3.0。两组数字的分数归一化口径不同，跨章节引用会互相矛盾，复现时以公开代码的分数计算方式为准。探索充分后，记忆覆盖了大部分区域，改用“取最高分实例、不设阈值”，论文报告这一转变带来 6% 的成功率提升。阈值模式的本质是“现在赌不赌”，最高分模式的本质是“选最像的”，前者避免误报、后者避免漏报，适用阶段不同。

记忆命中失败时，全局策略输出探索目标，采用前沿法选择最近的未探索区域；到达后再重新查询记忆。局部策略用 FMM 在障碍与已探索栅格上规划路径。整条回路没有可训练参数：机器人换本体时，只要提供 RGB-D、位姿与低层移动指令，系统即可迁移，论文在 Spot 与 Stretch 两个平台上验证了这一点。

经验曲线给出终身性的直接证据：首个目标成功率约 60%、SPL 约 0.20；到第 5 至 10 个目标时升到约 90%、SPL 约 0.80，SPL 提升 4 倍。曲线来自同一环境的连续目标，说明记忆随探索增厚并被复用。三个下游应用进一步展示通用性：抓放任务 30 条查询、3 个家庭，找物体成功 79%、找承载面 87%；社交导航中把行人当 PERSON 类别实例、动态更新位置，5 条轨迹下避开行人成功率 81%，搜索并跟随行人 83%，接近静态图像目标的 86.4%。

7. 讨论与失效边界

论文自述的边界有五条。第一，实验选 15 个类别、9 个家庭、200+ 实例，每类平均样本有限，按类别的结论要谨慎外推。第二，语言目标明显弱于图像（68.2 对 86.4）：CLIP 语义特征难以区分实例级细节，而 SuperGlue 能利用几何对应；语言描述还引入用户表述方差。第三，开放词汇检测器在真机上的可靠性不如 2017 年的 Mask R-CNN，论文明确把这一现象列为开放问题，理由是开放词汇模型以通用性换稳健性、训练数据与具身场景分布不同。第四，匹配阈值与归一化口径在两个章节数值不同，工程复现必须核对代码。第五，任务假设单层平面移动与稳定位姿传感器，楼梯与剧烈光照变化不在验证范围内。

把本讲数字与第 073 讲的仿真结果放在一起时还存在协议差：真机每目标预算 200 步、目标类别来自 15 类预选；仿真基准的预算、判据与类别体系不同。两套数字分别回答“真机可行性”与“可复现对照”，混排会得出错误结论。引用时至少标注实验环境（9 家庭真机）、目标数与本体（Spot）。

关键代码与解读

三段代码对应记忆更新、目标匹配与深度对齐，均为按论文口径的示意实现。

片段 1：实例记忆的增量更新

def update_instance_memory(det, map_cells, memory, dilate=2):
    """把一帧检测并入实例记忆：按类别与膨胀细胞集匹配，命中则融合。"""
    inflated = dilate_cells(det.cells, dilate)        # 容忍投影误差
    for inst in memory:
        if inst.category != det.category:
            continue                                  # 类别不同不可能是同一实例
        if inflated & inst.cells:                     # 细胞集有交集即命中
            inst.cells |= det.cells
            inst.views.append(crop_with_context(det)) # 保留带背景的原始视图
            return inst
    new_inst = Instance(cells=set(det.cells), views=[crop_with_context(det)],
                        category=det.category, instance_id=next_id(memory))
    memory.append(new_inst)
    return new_inst

解读：（1）类别与空间重叠是并列条件，缺一不可；只按类别合并会把同类不同实例并成一个，只按空间合并会把相邻异类实例并成一个；（2）视图保存原始裁剪，不预先压缩为特征，使 CLIP 与 SuperGlue 两种匹配器能共用记忆，这是多模态能力的结构基础；（3）新建实例时分配唯一编号并写入语义地图通道，后续类别查询走地图、实例查询走记忆；（4）更新时间是常数级（类别过滤后通常只比较少数实例），支持在线逐帧执行。

片段 2：目标匹配的分流与聚合

def match_goal(goal, memory, mode, threshold=None):
    """mode 取 category、language 或 image；返回最佳实例与得分。"""
    if mode == "category":
        hits = [inst for inst in memory if inst.category == goal.category]
        return pick_nearest(hits, goal.pose)
    if mode == "language":
        goal_category = parse_category(goal.text)     # Mistral 7B 抽取类别
        goal_feat = clip_text(goal.text)
        scored = [(inst, max(cosine(goal_feat, clip_img(v))
                             for v in inst.views))
                  for inst in memory if inst.category == goal_category]
    else:
        goal_category = detect_category(goal.image)   # Mask R-CNN 抽取类别
        scored = [(inst, max(superglue_score(goal.image, v)
                             for v in inst.views))
                  for inst in memory if inst.category == goal_category]
    if not scored:
        return None                                   # 交给前沿探索
    best_inst, best_score = max(scored, key=lambda x: x[1])
    if threshold is not None and best_score < threshold:
        return None                                   # 探索阶段宁可漏报
    return best_inst

解读：（1）先抽类别再匹配，把搜索空间从全记忆缩到单类别实例集，论文报告该过滤提升匹配准确率 23%；（2）跨视图取 max，不用均值，避免一个低质量视图拉低整个实例的分数；（3）同一份视图集支撑两种打分器，图像走几何关键点、语言走语义相似度，各自发挥；（4）阈值参数可选：探索中传入（0.28 或 6.0 口径），探索完成后传 None 取最高分，对应论文的两阶段策略。

片段 3：深度补洞的最小二乘对齐

import numpy as np

def align_depth(raw_depth, est_depth, eps=1e-9):
    """用有读数的像素拟合 D = A * X + b，填回缺失像素。"""
    valid = raw_depth > 0.0
    x = est_depth[valid].astype(np.float64)
    d = raw_depth[valid].astype(np.float64)
    n = x.size
    if n < 2:
        return est_depth                                 # 样本不足，放弃对齐
    sx, sd = x.sum(), d.sum()
    sxd, sxx = float(x @ d), float(x @ x)
    denom = n * sxx - sx * sx
    if abs(denom) < eps:
        return est_depth                                 # 深度无变化，尺度不可辨识
    A = (n * sxd - sx * sd) / denom
    b = (sd - A * sx) / n
    filled = A * est_depth + b
    out = raw_depth.copy()
    out[~valid] = filled[~valid]                         # 只替换缺失像素
    return out

解读：（1）只在有读数像素上拟合，保证几何基准来自真实传感器；（2）闭式解避免迭代，适合逐帧执行；（3）分母接近零意味着深度估计几乎为常数、尺度不可辨识，此时返回原始估计比输出错误尺度安全；（4）只回填缺失像素，已读数像素保持原值，避免把单目估计的系统偏差灌进建图；（5）示例算例 X = (1.0, 2.0, 3.0)、D = (1.1, 2.0, 2.9) 得 A = 0.900、b = 0.200，可直接作为单元测试。

常见误区

  • SPL 参考起点用错：症状是自评 SPL 明显偏离论文且目标序号越靠后偏差越大。根因是把参考路径从 episode 出生点算，而协议规定从上一个目标的实例位置算。修复：实现时把子任务起点随目标滑动，首个子任务才用出生点；报告时写明该口径。
  • 阈值口径张冠李戴：症状是复现时阈值 0.28 与 0.75 互相矛盾。根因是方法节与补充材料使用不同分数归一化。修复：以代码中的打分函数为准，记录分数范围，必要时把两组数字都换算到同一口径再比较。
  • 跳过类别过滤直接全记忆匹配：症状是真实物体识别率低、目标偶尔匹配到外观相似的异类实例上。根因是少了类别键这道闸门，论文报告该过滤带来 23% 的匹配准确率提升。修复：保持“先抽类别、后匹配”的顺序；类别抽取失败时退回探索，不做全库匹配。
  • 把不含记忆的消融读成“只差探索”：症状是认为 60.3% 与 83.0% 只差探索时间。根因是该消融同时重置语义地图与实例记忆，匹配质量与效率耦合下降，SPL 仅 0.188。修复：把成功率与 SPL 并列读，并注意消融同时移除了两类资源。
  • 用开放词汇检测器直接替换 Mask R-CNN 期待更好：症状是真机漏检与误检增多。根因是论文实测开放词汇模型在真机上不如 2017 年的 Mask R-CNN，通用性与稳健性存在张力。修复：先复现 Mask R-CNN 基线；替换检测器时在同一目标集上对照，别只比对训练指标。
  • 忽略超时与判据细节：症状是成功率虚高或虚低。根因是失败样本被算成未完成、或“停止位置小于 1 m”与“可见”等附加条件混用。修复：明确 200 步预算、1 m 距离与正确实例三项条件，统计超时比例，报告时附判据说明。

练习与思考

  1. 由主表计算 GOAT 相对 CoW 的平均成功率差、SPL 差与相对提升率，并用三类模态的算术平均验证 83.0 这一数字。★
    提示
    成功率 +32.3 个百分点，相对 +63.7%；SPL +0.224，相对 +53.6%；(86.4 + 68.2 + 94.3) / 3 = 82.97，四舍五入为 83.0。注意误差线为两倍标准差，差值应显著大于误差范围才有意义。
  2. 推导深度对齐的闭式解：写出两个正规方程并解出 A 与 b，再用 X = (1.0, 2.0, 3.0)、D = (1.1, 2.0, 2.9) 验证 A = 0.900、b = 0.200。★★
    提示
    方程一：Σ(D − AX − b)·(−X) = 0，即 ΣXD = AΣX² + bΣX；方程二：Σ(D − AX − b)·(−1) = 0，即 ΣD = AΣX + nb。联立消元得 A = (nΣXD − ΣX·ΣD) / (nΣX² − (ΣX)²)、b = (ΣD − AΣX)/n。
  3. 解释“不含实例区分”消融在类别目标上只掉 0.2 个百分点（94.3 对 94.1），在图像目标上却掉约 58 个百分点。设计一个实验在仿真里复现这一模式并控制检测质量变量。★★
    提示
    类别目标不要求区分实例，找到任意同类即成功；图像与语言目标要求唯一定位，缺少实例记忆时只能靠类别与外观偶然命中。实验设计：同一场景同一目标序列，只切换匹配模块（含实例视图与不含实例视图），固定检测器与探索策略，比较三模态成功率与首达时间。
  4. 为一个两层住宅设计多楼层实例记忆扩展：给出楼层标识、跨层目标处理、记忆检索顺序与预算分配，并估算相对单层的额外存储与查询开销。★★★
    提示
    在实例与地图中加入楼层键（如楼号加坐标），目标匹配先判断目标可能楼层再检索；楼梯通行作为局部策略的额外动作与原语，需单列成功率。开销估算：实例数按楼层分别计数，地图每个楼层一张，检索复杂度不变；风险点是跨层 SPL 参考路径与预算分配，需要按论文口径明确失败处理。
  5. 论文报告语言目标比图像目标低约 18 个百分点。提出两种改进方案（改善描述、改善匹配），分别给出验证协议与预期读数。★★
    提示
    改善描述：收集同一实例的多种表述做训练或提示增强，测试同义与复述下的成功率；改善匹配：用区域级对齐或图文多视图融合替代单视图 CLIP 最大分，测试实例级检索 R@1 与端到端导航成功率。两组实验都要固定其他模块，报告基线 68.2% 与误差线口径。

小结

  • 任务与协议：5 至 10 个类别、图像或语言目标顺序执行；每目标 200 步预算、距正确实例小于 1 m 判成功；SPL 参考路径从上一目标实例起算。
  • 系统：Mask R-CNN 感知、MiDaS 加深度的最小二乘补洞、K = C + 4 通道语义地图（格子 25 cm²）、对象实例记忆（细胞集加视图集加类别）、FMM 局部规划；全程无可训练参数。
  • 记忆与匹配：同类别且膨胀细胞集相交则并入；图像目标用 SuperGlue、语言目标用 CLIP，跨视图取最大；类别过滤提升匹配准确率 23%，探索后改用最高分再提升 6%。
  • 真机结果：平均成功率 83.0%、SPL 0.642；类别 94.3、图像 86.4、语言 68.2；相对 CoW 成功率 +32.3 个百分点；不含实例区分掉到 49.4，不含记忆 SPL 仅 0.188。
  • 终身证据：同一环境内从首个目标约 60% / SPL 0.20 升到第 5 至 10 个目标约 90% / SPL 0.80，效率提升 4 倍。
  • 衔接：下一讲把 GOAT 的任务与记忆分析搬进可复现仿真基准 GOAT-Bench，看统一协议如何给出跨方法的对照读数与稳健性分析。
