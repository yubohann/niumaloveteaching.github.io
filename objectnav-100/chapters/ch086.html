第五篇 · 真机、Sim2Real 与系统集成

第 086 讲｜L3MVN 真机

第 032 讲指出 L3MVN（Yu 等，2023，L3MVN，arXiv:2304.05501 v2，IROS 2023）的真机实验为演示级证据。本讲把这组证据放进真机方法学的框架里复核：平台为 ROS 上的 Jackal 移动机器人，传感为 RealSense D455 相机与 Ouster 激光雷达，作者把相机高度与深度量程对齐仿真，用激光雷达实时建图改善定位，场景为客厅寻沙发的一次完整演示，推进到第 58 步，论文未报告成功率、路径长度与失败统计。本讲要回答三个问题：这次真机实验验证了什么、没有验证什么；从演示到可检验结论需要多少样本；语言模块的响应延迟如何约束重规划频率。核心结论先行：演示证明流程可运行，样本量算术说明它不构成泛化结论；模块化的地图层接口能吸收单帧噪声，定位误差会整体进入地图几何。

  • 主题：LLM 前沿排序真机 / Jackal 平台 / 传感器对齐 / 证据强度 / 真机评测设计
  • 关键公式：n = (z1−α/2 + z1−β)2[p1(1−p1) + p2(1−p2)] / (p1−p2)2；Wilson 区间
  • 预计学时：80 分钟
  • 前置章节：第 085 讲（SemExp 真机迁移）

学习目标

  • 理解：逐项复述 L3MVN 真机实验的平台、传感器、对齐措施与演示范围，区分「流程可运行」与「泛化结论」两类主张。
  • 会推导：写出两组比例检验的样本量公式与 Wilson 区间公式，解释单次演示的区间下界为什么只有约 0.21。
  • 会算：复算 LLM 模块与探索模块的消融差额、真机演示步数占仿真预算的比例，以及语言调用次数对重规划频率的预算约束。
  • 会设计：为一个真机 A/B 实验给定最小可检测差异，反推所需幕数与运行时长，并列出证据登记的字段。
  • 会判断：识别相机高度与量程未公布、分割域差、激光雷达替代无噪声位姿、单场景外推四类风险。

背景与动机

第 081 至 085 讲把真机问题拆成三条线：081 讲给出 Sim2Real 的历史与量化落差，082 至 084 讲用 RoboTHOR 与噪声建模固定评测口径，085 讲复盘 SemExp 的真机迁移。本讲处理同一条线上的另一类证据：把一个模块化语言导航方案搬到移动平台之后，作者实际测了什么、报告到什么颗粒度。第 031 与 032 讲已经从机制与仿真结果两侧讲透 L3MVN，032 讲在结尾留下一个承诺，把真机证据放到第五篇的方法学框架里再评一次，本讲兑现这个承诺。

真机章节最容易出现两类误读。一类把演示视频当作性能证据，忽略样本量与场景多样性；另一类反向否定一切演示，忽略演示在接口打通、噪声暴露与失败模式发现上的价值。本讲用同一套框架同时容纳两种判断：先把实验的每一项设置还原，再用证据强度评分与样本量算术给出可检验的边界，最后落到一张可直接照抄的真机实验设计表。下一讲转入本体与动作空间，Hello Robot Stretch 如何改变仿真侧的接口假设。

核心原理

1. 真机实验逐项还原

论文的真机部分只有一段正文加一组过程图，信息量有限，需要与仿真设置并排阅读才能看清替换了哪些部件。作者在真实环境中用 ROS 与 Jackal 机器人实现并测试策略，传感配置为 RealSense D455 相机加 Ouster 激光雷达。为压缩仿真与现实的落差，作者做了两项对齐：把机器人 RGB-D 相机的高度与深度量程设置成与仿真环境一致；用激光雷达构建实时几何地图，改善机器人定位精度。RGB-D 图像、位置与目标类别送入模型，模型输出动作，长期目标（前沿）引导探索直到找到沙发，过程图推进到第 58 步。

2. 地图层为什么是迁移接口

论文对迁移成本给出的解释值得逐句拆开：模块化框架的优势在于策略输入是场景地图，不直接使用带噪声的原始图像，多帧融合吸收了单帧噪声，因此可以用极少的微调把模型部署到机器人平台。把接口定在地图层，意味着相机替换不会直接改变策略输入分布，代价是定位误差会通过地图几何整体进入系统。把地图更新写成更新式，这一点更清楚：

Mt = f(Mt−1, proj(It, Dt, Tt))

其中 It 为 RGB 观测，Dt 为深度图，Tt 为位姿，proj 为按相机内外参把像素反投影到世界坐标的操作，f 为占据栅格与语义通道的累积更新。对误差做一阶展开，地图误差可近似分解为位姿项与深度项：

δM ≈ (∂f/∂T)·δT + (∂f/∂D)·δD

深度项 δD 在逐帧投影中近似零均值，多帧累积后被平均，这正是论文观察到「深度噪声影响被削弱」的来源；位姿项 δT 具有强相关性，激光雷达或里程计的漂移会把同一面墙反复写入相邻位置，形成点云拖影，改变前沿的连通关系与可达区域。两类误差的统计性质不同，处置方式也应不同：深度用多帧平均，位姿用回环与配准修正。第 084 讲的噪声注入表给出仿真侧的标定口径，真机侧的对齐声明必须落实到同样的可量化字段上，否则「对齐了高度与量程」这句话无法复现。

3. 证据强度：六项评分与区间算术

评价一组真机证据，先把主张拆成可检验命题，再检查证据是否覆盖命题。本讲给出一张六项评分表，每项 0 至 2 分：样本量（幕数是否足以支撑区间收窄）、场景覆盖（是否跨越房间布局与目标类别）、指标完整性（是否报告 SR、SPL、DTG 与失败构成）、对照设置（是否有同口径基线或消融）、失败分析（是否分解失败模式）、可复现性（是否公布硬件参数、速度上限、种子与代码版本）。

样本量问题可以用区间算术精确表达。对 n 次独立试验中的 k 次成功，比例 p 的 95% Wilson 区间为：

[p̂ + z2/(2n) ± z·√(p̂(1−p̂)/n + z2/(4n2))] / (1 + z2/n)，z = 1.96

把单次演示按「1 次尝试」记账：1/1 的区间为 [0.207, 1.000]，下界约 0.21。也就是说，即使演示成功，也只能排除「成功率低于两成」这一极端情况，无法区分 30% 与 90%。要让区间有用，幕数必须上去。

4. 从区间到实验设计：样本量公式

若目标是检验「新方法比基线高若干点」，使用两组比例检验的样本量公式，每组所需幕数为：

n = (z1−α/2 + z1−β)2 · [p1(1−p1) + p2(1−p2)] / (p1 − p2)2

取 α = 0.05（双侧）、power = 0.8，z1−α/2 = 1.96、z1−β = 0.84。以 L3MVN 前馈范式在 HM3D 上的 0.542 为参照臂，对不同的可检测差异（Minimum Detectable Effect, MDE）实算：

0.4509.2 个百分点460精细比较，仍超常规真机预算
0.40014.2 个百分点191中等差异，多家庭多轮可行

这张表把「真机实验要跑多少次」从经验问题变成算术问题。第 085 讲 SemExp 真机与第 088 讲 OVMM 真机基准的样本量都远小于 143，所以它们只能支持粗粒度结论。引用真机数字前先做两件事：对齐成功判据口径，检查样本量对应的最小可检测差异。

5. 语言模块的延迟预算

把语言打分搬到真机后，计算延迟直接进入控制回路。零样本范式对每条前沿、每个目标类别各构造一条查询句；前馈范式对每条前沿只编码一条描述句，再接一次分类头。按每轮重规划可见 10 条前沿、6 个目标类别计算，零样本每轮 60 次前向，前馈每轮 10 次嵌入加 1 次分类头前向，共 11 次，两者之比为 5.45 倍。

重规划频率零样本单次前向预算前馈单次前向预算含义

1.0 Hz16.7 ms90.9 ms零样本需批处理或缩短句子

表中预算为「把一轮全部语言调用压进一个重规划周期」的上限，按调用次数与周期长度实算，与具体硬件无关。工程上有三个常规减压手段：把前沿签名变化作为触发条件，未变化时复用上次分数；对句子模板做前缀缓存，共享目标词之前的激活；把打分与规划解耦成异步进程，最新分数到达前沿旧目标执行。真机部署时还应记录两类日志：语言调用的实际耗时分布，以及回退到几何探索的触发比例，后者反映语言先验在真实场景中的实际参与率。

6. 失效模式与证据边界

把风险按下游影响排序，可以形成一张对照表。深度域差影响分割与点云质量，属于可以量化、可以缓解的一类；定位漂移影响地图几何，属于需要外部传感补偿的一类；场景与类别单一影响结论外推，属于设计层面无法靠后处理修复的一类；平台差异影响可迁移性，Jackal 为差速轮式平台，2023 挑战本体已改为 Stretch，第 087 讲展开两者在身高、相机高度与动作空间上的差异。

关键代码与解读

三段代码覆盖本讲三个核心动作：把仿真侧的相机几何对齐检查写成函数、把语言打分调度器写成带缓存与预算的循环、把证据登记写成含 Wilson 区间的统计工具。接口按论文描述做教学化命名。

片段 1：相机几何对齐检查

import numpy as np

def align_depth(depth_raw, sim_range=(0.5, 5.0),
                real_height=1.31, sim_height=1.31):
    """模板函数：量程与高度为占位值，须换取实验版本的实际参数。"""
    lo, hi = sim_range
    depth = np.clip(depth_raw, lo, hi)          # 量程外像素失去意义，先裁剪
    depth[~np.isfinite(depth)] = hi             # 无效值不参与反投影
    height_err = abs(real_height - sim_height)  # 高度差直接平移点云平面
    if height_err > 0.02:                       # 2 cm 以上必须重新标定外参
        raise ValueError("camera height mismatch: %.3f m" % height_err)
    return depth, height_err

解读：（1）裁剪让真机深度与仿真分布可比，量程外像素在仿真中不存在，保留会在地图上形成虚假障碍。（2）相机高度差按点云平面的整体平移进入地图，超过阈值时任何语义结论都失真；阈值 0.02 m 为工程建议值，可取地图栅格边长（5 cm）的四成。（3）函数只做几何对齐，分割域差不在这一步处理，后者要用逐类召回统计单独验收。

片段 2：带缓存与预算的语言打分调度

def score_frontiers(frontiers, target_idx, budget_ms, forward_fn,
                    cache={}):
    """按前沿签名缓存分数；预算内算不完的部分沿用旧分数。"""
    out, used = {}, 0.0
    for f in frontiers:
        key = (f["signature"], target_idx)      # 前沿物体清单的稳定标识
        if key in cache:
            out[f["id"]] = cache[key]           # 命中缓存，零调用成本
            continue
        t0 = time_ms()
        if used + est_ms(forward_fn) > budget_ms:
            out[f["id"]] = cache.get((f["prev"], target_idx), 0.0)
            continue                            # 预算不足时退回探索分数
        out[f["id"]] = forward_fn(f, target_idx)
        used += time_ms() - t0
        cache[key] = out[f["id"]]
    return out, used

解读：（1）前沿签名由邻域物体清单构成，物体集合未变时句子未变，分数可复用，这是把 60 次调用压下来的关键。（2）预算参数来自前文的重规划预算表；超预算分支返回保守分数，规划层随后回退到几何探索，保证控制回路不被语言调用阻塞。（3）缓存键包含目标类别，换目标时必须整体失效；真机日志应记录命中率与平均耗时，两者共同决定重规划频率能否维持。

片段 3：证据登记与区间估计

import math

def wilson_ci(k, n, z=1.959964):
    """k/n 的 95% Wilson 区间，适合小样本。"""
    if n == 0:
        return (0.0, 1.0)
    p = k / n
    denom = 1.0 + z * z / n
    center = (p + z * z / (2 * n)) / denom
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / denom
    return (max(0.0, center - half), min(1.0, center + half))

def required_n(p1, p2, alpha=0.05, power=0.8):
    """每组幕数：两组比例检验的常规近似。"""
    za, zb = 1.959964, 0.841621
    return math.ceil((za + zb) ** 2 *
                     (p1 * (1 - p1) + p2 * (1 - p2)) / (p1 - p2) ** 2)

if __name__ == "__main__":
    print(wilson_ci(1, 1))            # 单次演示的下界
    print(required_n(0.542, 0.379))   # 复现 16.3 个百分点的差异

解读：（1）Wilson 区间在小样本与极端比例下比正态近似稳定，1/1 与 0/n 都能给出有限区间，适合作为真机预注册的分析口径。（2）required_n 使用未合并方差的标准近似，与多数统计软件的常规公式一致；若使用合并方差，结果在小差异档会略有不同，报告时注明公式版本。（3）两个函数应在实验开始前写好并冻结，避免看到结果后调整判据；证据登记表另存硬件参数、判据版本与种子。

常见坑

  • 把演示当成功率证据：症状是引用视频截图称「真机可行，成功率可期」。根因是单次成功不提供区间信息，1/1 的 Wilson 下界只有 0.207。修复：按证据等级表登记，演示只支持流程命题；需要性能命题时按 MDE 反推幕数。
  • 「对齐」不留数字：症状是复现时无法判断相机高度、量程与畸变校正是否一致。根因是论文用定性语句描述对齐，正文未给数值。修复：把高度、近远裁剪面、分辨率、外参残差写入实验记录；缺失即按证据评分表扣分。
  • 语言调用拖垮控制回路：症状是真机上目标切换后动作迟滞、重规划周期抖动。根因是零样本每轮 60 次前向超出周期预算（1 Hz 下每次仅 16.7 ms）。修复：改用前馈头、缓存句子分数、把打分异步化，并记录回退比例。
  • 忽略分割域差：症状是仿真消融（GT 分割 +12.2 个百分点）被误读为真机也有同等提升空间，或真机效果差被归因于策略。根因是 RedNet 训练域与真机实拍分布不同。修复：先做逐类召回验收，再谈策略改进；域差过大时优先域内微调。
  • 单平台单场景外推：症状是用 Jackal 的演示推断 Stretch 等新本体的可迁移性。根因是两者身高、相机高度、动作空间与动力学都不同。修复：平台差异单独列为一个实验维度；换本体时至少重复关键臂并报告差异来源。

练习与思考

  1. 用 500 步与 0.25 m 两个设定，复算仿真单幕的纯前进路径上界，并计算第 58 步演示所占比例。★
    提示
    500 × 0.25 = 125 m；58 / 500 = 11.6%；若第 58 步全部为前进动作，对应 14.5 m。演示未覆盖步数耗尽、长时漂移与重复探索三类失效。
  2. 推导 Wilson 区间在 n = 1、k = 1 时的取值，并解释直觉上的 0.5 为何不成立。★★
    提示
    代入后下界化简为 1/(1+z²) = 1/4.84 ≈ 0.207，与查表值一致。点估计 1 不代表真实比例接近 1，单次成功无法排除低成功率。
  3. 设定目标为检测 15 个百分点的成功率差异，α = 0.05 双侧、power = 0.8，估算每组所需幕数，并给出单机每天 8 幕时的最短运行天数。★★
    提示
    按公式 n ≈ 170 至 200 档（取决于对照臂基线），取 191 幕（对照臂 0.40）；两组共 382 幕，除以每天 8 幕后向上取整，约 48 天；若用双臂并行或减少指标维度可压缩，但需写清取舍。
  4. 为一个「前馈头对零样本」的真机 A/B 实验写完整设计：判据、场景与类别分层、幕数、随机化、预注册分析口径、失败登记字段，并说明为什么不能让两臂共享同一批前沿缓存。★★★
    提示
    判据固定为 1 m 加可见性口径并在两臂完全一致；按房间类型与目标类别分层采样；幕数由 MDE 公式反推；起点与目标实例随机化、种子预注册；分析用 Wilson 区间与两组比例检验。缓存会跨臂泄漏分数信息，破坏独立性，两臂必须使用独立缓存或在每幕后清空。
  5. 把相机高度差从 0.01 m 增大到 0.05 m，按 5 cm 栅格估计点云平面的相对错位，并预测语义地图与前程连通性的变化方向。★★
    提示
    0.05 m 等于一个栅格，投影点会整体落入相邻格；语义通道与障碍通道错位使前沿边界抖动，连通的走廊可能被误判为障碍或反之。修复是重新标定外参，并把高度残差作为地图更新的先验修正项。

小结

  • 真机设置：ROS + Jackal、RealSense D455、Ouster 激光雷达；相机高度与深度量程对齐仿真，激光雷达建图改善定位；输入为 RGB-D、位置与目标类别，演示为客厅寻沙发、推进到第 58 步，占仿真步数预算的 11.6%。
  • 证据强度：按六项评分得 2/12，属于演示级；单次成功 1/1 的 95% Wilson 区间为 [0.207, 1.000]，不构成成功率结论。
  • 样本量算术：以 0.542 为参照臂、α = 0.05 双侧、power = 0.8，检测 24.2、16.3、14.2、9.2 与 4.2 个百分点的差异分别需要约 62、143、191、460 与 2,217 幕每组。
  • 延迟预算：10 条前沿与 6 类目标下，零样本每轮 60 次前向、前馈 11 次；1 Hz 重规划给零样本的单次预算仅 16.7 ms，缓存与异步是落地前提。
  • 误差分解：地图接口吸收零均值深度噪声，位姿误差按几何整体进入地图；定性「对齐」声明必须补充高度、量程与外参残差等可验收字段。
