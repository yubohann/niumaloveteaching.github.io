第二篇 · 模块化：地图·探索·常识

第 031 讲｜L3MVN I：LLM 给 frontier 打分

L3MVN（Yu 等，2023，IROS 2023）把前沿选择的常识来源压缩成一句话：把每个前沿邻域的物体清单写成自然语言描述，让语言模型判断「这个前沿有多像目标所在的位置」。零样本范式直接用掩码语言模型给句子打概率，前馈范式把句子嵌入送进三层分类头；再用物体与目标的共现熵筛出高信息量词表，并用分数门限把语言模型分数与经典 cost-utility 融合。HM3D 上成功率 0.542，比同口径的 SemExp 高 16.3 个点。

  • 主题：语义地图 / 前沿打分 / 语言模型常识
  • 关键公式：SLLMf = log p(W)；SLLMf = [ fθ(Emb(W)) ]tj
  • 预计学时：60 分钟
  • 前置章节：第 030 讲

学习目标

  • 能描述语义地图与前沿图的构建流程，说明候选前沿如何从连通域中提取并按 cost-utility 打分。
  • 能写出零样本与前馈两种前沿打分公式，说明各自的模型、输入输出与训练需求。
  • 能计算物体与目标类别的共现熵，构建信息量词表，并解释为什么门、窗这类高频物体应被过滤。
  • 能实现分数门限 B = [0.15, 0.3] 的三段融合策略，说明每段的动机与失效场景。
  • 能解读 Gibson 与 HM3D 上的 SR、SPL、DTG 三联数字，说清 DTG 与 SR 方向不一致的原因。

背景与动机

第 030 讲的 ESC 把常识组织成带权重的软规则库，表达力强，代价是规则模板与权重需要设计，原子取值、阈值、权重互相耦合。L3MVN 走更轻的路线：不写规则，直接把「前沿周围有什么物体」描述成一句英文，让语言模型给出「目标物体出现在这句话描述的位置」的可能性。常识从谓词演化成句子的语言合理性打分，规则库设计工作被提示词模板取代。

L3MVN（Yu 等，2023，Leveraging Large Language Models for Visual Target Navigation）给出两种打分范式：零样本范式用预训练掩码语言模型给查询句打分，不做任何任务训练；前馈范式把查询句嵌入后接一个三层分类头，用房间级物体共现自动生成监督信号。两者共享同一套语义地图、前沿提取与局部规划，差额即「任务训练」的净贡献，这与第 029 讲 OracleSem 与 PredSem 的对照思路相同，方向相反。

本讲解决三个问题：前沿的内容如何变成语言模型的输入；两种打分范式在成本与泛化上如何取舍；语言模型分数与经典探索效用如何融合，避免在语义稀疏区域被高熵词语淹没。第 032 讲将展开该框架的真机实验与零样本泛化分析。

核心原理

1. 任务与框架总览

任务沿用 ObjectNav：环境集合 S、目标类别集合 C，episode 记为 Ti = {si, ci, pi}，智能体从随机位姿出发，寻找类别 ci 的任一实例。观察为 480 × 640 的 RGB-D、本体里程计与目标类别编号；动作空间为前向 25 cm、左右转 30°、抬头低头 30°与 STOP；episode 上限 500 步。实验在 Gibson tiny 划分（25 训练 / 5 验证场景）与 HM3D（75 训练 / 20 验证场景）上进行，目标类别固定为 chair、couch、potted plant、bed、toilet、TV 六类。

框架分四层：语义地图层把 RGB-D 观测转成俯视栅格；前沿层从已探索与障碍信息中提取候选探索点；全局策略用语言模型给前沿排序，产生长期目标；局部策略用快速行进法（Fast Marching Method, FMM）规划到长期目标的路径并输出动作。前两层与第 022、023 讲的建图模块同源，后两层的分工与 PONI（第 027 讲）相同，本讲的增量集中在全局策略的前沿打分。

2. 语义地图与前沿提取

语义地图表示为 K × M × M 的张量：M × M 为俯视地图尺寸，K = Cn + 2 个通道，其中两个通道记录障碍与已探索区域，其余通道按语义类别存放投影结果。episode 开始时全图清零，智能体置于地图中心；视觉输入经几何方法生成点云，结合深度与位姿投到俯视平面。语义分割（论文使用微调的 RedNet）给出每个像素的类别掩码，与点云对齐后逐通道落图。

前沿从前两层地图提取，步骤为：对已探索图取最大轮廓得到探索边缘；对障碍图做膨胀；两者求差得到前沿带；用连通邻域把前沿格聚成链状簇；删除过小的簇；剩余簇的中心格组成候选目的地集合 F。每个候选按 cost-utility 打分（Juliá 等，2012）：

SCU(a) = U(a) − λCU · C(a) U 为效用（如信息增益或邻近度），C 为代价（如路径长度），λCU 调节两者相对重要度

cost-utility 是纯几何的经典探索指标，不含语义。它的角色在下一节与语言模型分数融合时体现：当语言证据不可靠，系统回退到它。

3. 信息量词表与共现熵

前沿描述由「邻域内的物体类别列表」构成，词表选择直接决定句子质量。若把门、窗、墙这类到处都有的物体写进句子，任何前沿的描述都相似，语言模型无从区分；若词表过窄，又可能漏掉真正有信息量的物体。L3MVN 用条件熵做筛选：在公开语义标注场景（论文统计 1000 个高分辨率扫描）上统计物体 oi 与目标 tj 的共现条件概率 p(tj | oi)，归一后计算

Hoi = − Σtj ∈ LT p(tj | oi) log p(tj | oi) LT 为目标类别集合；分布越集中熵越低，该物体对目标的指示性越强

熵在分布均匀时最大，在一热分布时最小。取熵最低的 15 个物体组成输入词表，其余物体不进句子。用一组构造计数说明筛选方向（6 个目标类别，计数为教学构造）：

4. 零样本打分：句子概率

零样本范式为每个前沿 fi 与每个目标类别 tj 构造一条查询句，把前沿邻域内的词表物体 o1..k 与目标一起列入：

Wfitj = “A frontier area containing o1, o2, …, ok, tj.”，  SLLMfi = log p( Wfitj ) p 为预训练语言模型（论文使用 RoBERTa-large）对整句的概率；对每个目标类别各算一次，取使该前沿得分最高的目标

机理是「合理化测试」：目标物体出现在对应房间的语境更常见，语言模型给这类句子的概率更高，反之更低。论文举的例子是，句子「This frontier area contains sink, bathtubs, and toilet.」的得分高于把 toilet 换成 tv 的版本。零样本范式不需要任何任务数据，新目标类别只需替换词表里的目标名；代价是每个前沿要对 |LT| = 6 个目标各做一次前向，计算量随目标数线性增长。

5. 前馈打分：嵌入加分类头

前馈范式把查询压缩成一条固定形式的句子，不再拼接目标名：

Wfi = “This frontier contains o1, …, and ok.”，  SLLMfi = [ fθ( Emb( Wfi ) ) ]tj Emb 为语言模型句嵌入；fθ 为三层网络，输出 |LT| 维对数向量，取目标类别对应分量

训练数据自动生成：遍历 HM3D 场景的每个房间，记录房间内的物体集合与是否包含某目标类别；含目标的房间样本把目标作为标签、其余物体作为输入，不含目标的房间样本给出负例。三层头以 RoBERTa-large 的句嵌入为输入。参数账：RoBERTa-large 公开规模约 3.55 亿参数，三层头按 1024 → 256 → 256 → 6 计算为 329,734 个参数，约 0.33 M，占骨干的 0.093%。推理成本差异体现在查询次数：15 个候选前沿下，零样本要做 15 × 6 = 90 次语言模型前向，前馈只需 15 次嵌入加 15 次头前向，语言模型前向减少 6 倍。前馈范式把 |LT| 从查询复杂度里移除，代价是需要目标类别的标注共现数据，跨到全新目标集合时不如零样本直接。

6. 门限融合：B = [0.15, 0.3]

室内场景的语义信息稀疏，前沿附近可能没有任何词表物体，也可能出现与场景不符的物体（论文举的例子是卫生间里的沙发）。L3MVN 的做法是给语言模型分数设一个容差带 B = [0.15, 0.3]，把是否信任语言证据分成三段：语言分数高于带的上界时采用语言模型排序；落在带内时与 cost-utility 组合排序；低于带的下界时完全回退到 cost-utility。用一组构造分数演示三段判定：

F40.31高于 0.3纯语言模型分数
F60.29带内语言分数与 cost-utility 组合

带内的组合排序按加权和实现，权值 λ 是工程自由度；以 λ = 0.5、语言分数按最大值 0.62 归一为例：F2 的组合分为 0.5 × 0.355 + 0.5 × 0.85 = 0.602，F6 为 0.5 × 0.468 + 0.5 × 0.70 = 0.584；F1 与 F4 处于纯语言段，按归一化语言分数 1.000 与 0.500 直接排序，F1 仍居首。为了让组合可解释，cost-utility 需要先归一到与语言分数同量纲的 [0, 1]，这一步若省略，融合会退化成单一来源主导，是复现时最常见的口径错误。三段策略的直接收益有两个：语义稀疏区域不因语言分数噪声而乱选；语义明确区域完全交给语言模型，保持常识的主导权。

7. 数值算例：句子长度偏差与词表收益

零样本打分依赖整句对数概率，句长会成为混淆变量：假设每 token 的平均对数概率相同（示例取 −0.50 nat），4 token 的句子总分为 −2.00，8 token 为 −4.00，16 token 为 −8.00。若不控制长度，模型会系统性偏向物体更少的前沿，而物体少的区域往往恰是语义稀疏区域，判断被反向诱导。对策有三种：模板补齐到固定物体数、按 token 数取平均、或在带内段用组合分数抵消。论文的模板写法固定了句子结构，但 o1..k 的数量仍随检测结果变化，复现时应在日志里同时记录句子长度与分数，检查两者是否相关。

词表收益可以用消融侧写。HM3D 上以完整版 0.542 为基准：把 cost-utility 探索换成「最近前沿」而保留语言模型，降到 0.490，对应探索模块贡献 5.2 个点；去掉语言模型、保留 cost-utility，降到 0.518，对应语言模型分数贡献 2.4 个点。两组消融共同说明前沿排序的收益来自探索效用与语言常识的正确配合。把分割换成真值（GT Seg）后达 0.664，比完整版高 12.2 个点，增量来自更干净的语义地图，这与第 029 讲的结论一致：感知入口仍是最大变量。

9. 边界与失效模式

第一，零样本范式的收益依赖语言模型对句式的先验，换语言、换模板或把物体名改成同义词都会移动分数分布，需要重新校准门限 B；论文只在英文与固定模板下验证。第二，共现熵表在公开语义标注数据上统计，与部署场景的物体分布存在偏移，词表应在目标场景数据上重算或至少抽检。第三，前馈头的训练数据由房间级共现自动生成，标签噪声来自「房间包含目标」这一弱监督的近似，跨到新建筑风格时需要增量数据。第四，三段策略的门限是硬切分，带边界附近的排序在相邻帧之间可能振荡，工程上应加选择迟滞或按 mission 级平滑。第五，任务定义里的成功距离在论文中写作 0.1 m，与第 001 讲挑战页的 1 m 口径不同，复现时应以所用数据集的评测脚本为准，不可跨口径比较 SR。

零样本与前馈的差异封装在 score 模块内部，上游只传物体清单与目标类别，下游只读浮点分数。这样做的收益是消融实验不需要改动地图与前沿代码，三种配置（换用最近前沿、去掉语言模块、完整版）可以在同一批 episode 上直接对比，论文的消融表才能干净地解释各组件贡献。

设计决策：先归一化再融合

语言模型分数与 cost-utility 来自不同分布，直接加权会让某一项主导。实现时把 SCU 在候选集合内做 min-max 归一，或按论文的分数界做法把语言分数按段处理。融合前打印两项的分布直方图，是排查「融合退化为单源」最快的检查手段。

词表是分布相关的资产

共现熵表在公开扫描数据上统计，部署到办公楼、医院等非住宅场景时，先验词表可能整体失效。工程上把词表当作带版本号的资产：进入新场景先做一批人工或半自动抽检，确认位列前茅的物体确实有指示性，再冻结使用。

关键代码与解读

片段 1 实现前沿提取与 cost-utility 打分，片段 2 实现两种打分范式的统一接口，片段 3 实现三段融合。

片段 1：前沿提取与 cost-utility

import numpy as np
from scipy import ndimage

def extract_frontiers(explored, obstacle, min_cluster=8):
    """explored/obstacle 为布尔栅格；返回候选前沿格与 cost-utility。"""
    edge = explored ^ ndimage.binary_erosion(explored)      # 已探索区轮廓
    frontier = edge & ~ndimage.binary_dilation(obstacle, iterations=1)
    labels, n = ndimage.label(frontier)                     # 连通域聚类
    candidates = []
    for i in range(1, n + 1):
        cells = np.argwhere(labels == i)
        if len(cells) < min_cluster:                        # 去小簇，抑制噪声前沿
            continue
        center = cells.mean(axis=0)                         # 簇中心作为候选目的地
        utility = len(cells) / frontier.size                # 教学用效用：簇规模占比
        candidates.append((center, utility))
    return candidates

def cost_utility(candidates, agent_xy, lam=0.5):
    ranked = []
    for center, u in candidates:
        cost = np.linalg.norm(center - agent_xy)            # 到候选的欧氏距离
        ranked.append((u - lam * cost, center))
    return sorted(ranked, key=lambda x: -x[0])              # 分数从高到低

解读：（1）轮廓、膨胀、差集三步与论文的提取顺序一致；min_cluster 是去小簇阈值，语义地图噪声大时应调大，代价是窄通道前沿可能被误删。（2）效用函数与代价函数在设计上是可替换的，这里用簇规模与欧氏距离做教学简化；论文使用更完整的 cost-utility 形式，接口保持不变。（3）λCU 越大越保守，智能体倾向就近探索；越小越激进，愿意走远换取信息，两侧都会改变 SR 与 SPL 的组合，调参时以验证集为准。（4）返回的候选集合就是后续语言打分的输入，打分器只消费候选与物体清单，不关心其来源。

片段 2：两种打分范式的统一接口

def describe_frontier(frontier_xy, semantic_map, vocab, radius_cells=3):
    """收集前沿邻域内词表物体，返回去重后的类别清单。"""
    hits = set()
    for (r, c) in neighborhood(frontier_xy, radius_cells):
        name = semantic_map.category_at(r, c)
        if name in vocab:                      # 词表之外的物体不进入句子
            hits.add(name)
    return sorted(hits)

def zero_shot_score(objects, target, lm):
    sentence = "A frontier area containing " + ", ".join(objects + [target]) + "."
    return lm.sentence_logprob(sentence)       # log p(W)，对每个目标算一次

def feed_forward_score(objects, head, lm):
    sentence = "This frontier contains " + ", ".join(objects) + "."
    emb = lm.embed(sentence)                   # 句嵌入，与目标类别无关
    return head(emb)                           # |L_T| 维对数，取目标分量

解读：（1）describe_frontier 用集合去重，避免同一物体重复出现放大句式权重；radius_cells 控制搜索窗，论文按前沿提出时一并给出，窗口过大会把远处物体错记为邻域证据。（2）zero_shot_score 与 feed_forward_score 的签名不同，但返回值同为浮点分数；上层通过配对的适配函数统一成 score(objects, target) 形态，替换范式时只改一处。（3）前馈范式里句子不含目标名，嵌入可缓存复用，这是语言模型前向从 |LT| 次降到 1 次的关键；零样本则天然支持新目标类别，两者是算力与灵活性的取舍。（4）实现时必须在日志中记录句子与实际词表，否则换词表后的分数漂移无法回溯。

片段 3：三段门限融合

def fuse_frontiers(llm_scores, cu_scores, B=(0.15, 0.3), lam=0.5):
    """llm_scores/cu_scores 已按前沿对齐并归一到 [0, 1]。"""
    lo, hi = B
    best = max(llm_scores)
    final = {}
    for i in range(len(llm_scores)):
        if best > hi:                          # 语言证据强，语义空间可信
            final[i] = llm_scores[i]
        elif best < lo:                        # 语义稀疏，回退几何效用
            final[i] = cu_scores[i]
        else:                                  # 带内：两项组合，稳健过渡
            final[i] = lam * llm_scores[i] + (1 - lam) * cu_scores[i]
    return max(final, key=final.get)           # 返回被选前沿的下标

解读：（1）判定用全体前沿中的最大语言分数统一决定信任级别，不逐个前沿分别判定：这是论文三段策略的原意，整批候选共享同一种模式，避免同一帧内两种打分并存造成的排序矛盾。（2）两段硬切换在边界处可能抖动，实现里可加迟滞：上一帧采用纯语言模式且本帧进入带内时，保留组合模式若干帧再切换。（3）lam 只在带内生效，调参影响面小，适合先标定 B 再调 lam。（4）返回下标后由局部规划执行，若目标不可达，应在重采样时记录门限段，便于统计「语义稀疏区域是否更常发生不可达」。

常见误区

  • 忽略句子长度偏差：症状是语言模型总是偏好物体少的前沿，探索退化为游走。根因是整句对数概率随 token 数下降。修复：模板补齐到固定物体数，或改用按 token 平均的对数概率，并在日志中检查句子长度与得分的相关性。
  • 词表直接使用全部检测类别：症状是所有前沿的句子高度相似，区分度消失。根因是门、窗等高熵物体对目标没有指示性。修复：按共现熵截取低熵词表，并在目标场景数据上验证排名稳定性。
  • 熵表与部署分布错配：症状是住宅数据上有效的词表在办公楼场景失效。根因是条件分布 p(t | o) 随场景类型变化。修复：把词表作为带版本号的资产，进入新场景先抽检再冻结，必要时重统计。
  • 融合前未归一化：症状是组合分流于语言分数或 cost-utility 其一，调 lam 几乎不改变结果。根因是两项量纲不同。修复：先做 min-max 或分位归一，打印两项分布，确认带内组合确实在混合两个来源。
  • 用 DTG 单指标下结论：症状是依据 DTG 判定 L3MVN 不如 SemExp，与 SR、SPL 的排序相反。根因是 DTG 把失败轨迹的末端距离一并平均，探索面积大的策略会吃亏。修复：主指标用 SR 与 SPL，DTG 用于失败分析，三联一起报告并注明口径。

    提示

小结

  • L3MVN 把前沿选择交给语言模型：语义地图与前沿提取沿用经典管线，增量在「描述前沿、给描述打分」这一步。
  • 零样本范式用掩码语言模型给「前沿包含物体清单与目标」的句子打分，无需任务训练；前馈范式把句子嵌入送进三层头，语言模型前向减少 |LT| 倍，代价是需要共现监督数据。
  • 词表按物体-目标共现熵截取低熵的 15 个物体，过滤门、窗等高熵项；熵的均匀上界为 ln 6 = 1.7918 nats（六类目标示例）。
  • 分数门限 B = [0.15, 0.3] 把选择分成纯语言、组合、纯 cost-utility 三段，避免语义稀疏区域被噪声主导；组合前必须归一化。
  • 结果：HM3D 前馈 SR 0.542、SPL 0.255，比零样本高 3.8 / 2.4 个点，比 SemExp 高 16.3 / 6.7 个点；Gibson 前馈 SR 0.769。DTG 与 SR 方向不一致时以 SR、SPL 为主指标。
