第二篇 · 模块化：地图·探索·常识

第 024 讲｜SemExp II：常识先验与真机

Chaplot 等（2020，arXiv:2007.00643）的目标导向策略并未被显式教过「床在卧室」这类常识。本讲讨论语义先验的三种形态与贝叶斯形式，实算一张共现先验表与前沿打分，设计辨别「先验」与「未探索偏好」的反事实实验，并复算 SemExp 真机迁移证据（LoCoBot 加 PyRobot，20 次成功 13 次）的置信区间与移植风险清单。

  • 主题：语义先验 / 物体共现 / 前沿打分 / 真机迁移与证据强度
  • 关键公式：P(r | c) = P(c | r) · P(r) / Σr′ P(c | r′) · P(r′)；score(f) = P(hit | f) · exp(−λ · d(f))
  • 预计学时：60 分钟
  • 上一讲：第 023 讲 SemExp I：语义地图+目标导向探索

学习目标

  • 能定义语义先验的三种形态：房间条件分布、物体共现分布、空间关系分布，并写出由计数到条件概率的贝叶斯形式。
  • 会从一张共现计数表实算拉普拉斯平滑后的条件概率、熵与相对均匀分布的 KL 散度，并用它给前沿或长期目标打分。
  • 能设计对照实验，区分策略使用「类别先验」与「优先访问未探索区域」两类机制，并写出预期签名与替代解释。
  • 能复算真机成功率的小样本置信区间，判断「65%」与仿真数字的比较边界，并估算把结论收紧到指定精度所需的试验量。
  • 能按域相关程度对模块分类，列出一份可执行的真机移植风险清单。

背景与动机

第 023 讲的系统有两个显式部件与两个默认假设。显式部件是语义地图与目标导向策略：地图把「哪里有椅子、哪里有盆栽」写成栅格通道，策略每 25 步在图上选一个长期目标。默认假设是策略能学会「物体通常出现在哪里」的统计规律，并且在训练场景上学到的规律换到新场景仍然有用。论文的表述是「模型学到了物体与区域相对布局的语义先验」，证据来自消融与一组定性轨迹。

工程上，这个说法需要被拆成可检验的问题。第一，先验到底是什么量：它在数学上是房间与类别的联合分布，还是物体之间的共现关系，还是「目标物离墙多远」之类的空间关系。第二，隐式学到的先验能不能被直接观察到：如果不能，怎么用反事实输入证明策略在使用它。第三，先验在真机上是否仍然成立：训练场景的统计规律来自数据集，真实住宅的布局可能不同；同时真机的深度与位姿带噪声，第 023 讲算过 1° 朝向误差在 5 m 处偏移 1.75 格，先验依赖的地图本身可能先被噪声污染。

本讲回答这三个问题。先给出先验的形式化与显式建模方法，用一张构造的计数表把条件概率、平滑、熵、前沿打分算一遍；再给出检验隐式先验的实验设计；最后拆解 SemExp 的真机迁移证据与边界。第 025 讲转向另一条路线：端到端智能体如何用辅助任务与探索奖励重新回到竞争位置。

核心原理

1. 语义先验的三种形态与贝叶斯形式

先验描述「在目标类别已知时，物体可能位于何处」的概率结构，常用三种形态。第一种是房间条件分布：给定房间类型 r 与类别 c，写出 P(物体类别 c 出现 | 房间类型 r)，或反过来写 P(房间 r | 目标类别 c)。第二种是物体共现：给定一个物体类别，另一个类别出现的条件概率，例如「有烤箱的场景更可能有冰箱」。第三种是空间关系：目标相对墙面的距离、高度、所在家具表面等几何统计。第 023 讲的策略把三者都压进网络权重，本讲把第一种形态显式化，因为它最容易从标注数据统计得到，也最容易在探索排序中使用。

设 Ec,r 为训练集中「类别 c 的实例出现在房间类型 r 中」的场景计数，按最大似然估计（Maximum Likelihood Estimation, MLE）：

PMLE(r | c) = Ec,r / Σr′ Ec,r′ 行归一化；每个类别一行，行和为 1；并未使用房间先验的形状假设

MLE 的缺陷是零计数。设某类别在训练集里从未出现在卫生间，MLE 给出 P(卫生间 | 该类别) = 0；若测试场景里目标恰好藏在卫生间，任何按乘积打分的探索策略都会把该房间的权重压成零。加性平滑（拉普拉斯平滑的推广）在每个计数上加常数 α：

Pα(r | c) = (Ec,r + α) / (Σr′ Ec,r′ + α · |R|) |R| 为房间类型数；α 越大越接近均匀，越小越接近 MLE；下文取 α = 1

需要房间条件概率时用贝叶斯公式换算。若记 P(r) 为房间出现频率、P(c | r) 为房间内出现该类别的概率，则

P(r | c) = P(c | r) · P(r) / Σr′ P(c | r′) · P(r′) 先验模式选择要与使用方式一致：按「目标在哪个房间」搜索时用 P(r | c)；按「该房间像不像装有目标」判断时用 P(c | r)

先验的尖锐程度可以直接度量。以 6 个房间类型为例，均匀分布的熵为 log2 6 = 2.585 比特；某个类别的房间分布熵越低，说明「去哪里找」的指向越明确；相对均匀分布的 KL 散度则衡量先验带来的信息量：

H(c) = −Σr P(r | c) · log2 P(r | c)，  KL(c) = Σr P(r | c) · log2 [P(r | c) / (1/|R|)] KL 以比特为单位；P(r|c) 与均匀分布差异越大，探索排序能从先验获得的信息越多

3. 前沿打分：概率与距离的折中

先验表要进入探索决策，还需与「走过去要多久」结合。设前沿 f 位于房间 r(f)、从当前位置到前沿的路径长度估计为 d(f)，给它一个实用打分：

score(f) = P(r(f) | c) · exp(−λ · d(f)) P 为先验命中概率；λ 为距离折减系数（单位 1/米）；λ = 0 表示只看先验，λ 很大表示只看近处

用一个实算例看转折。目标为盆栽，两个候选前沿：客厅前沿 P = 0.3919、路径 8 m；办公室前沿 P = 0.1486、路径 3 m。取三档 λ 计算：

λ（1/米）客厅前沿得分办公室前沿得分排序
0.100.17610.1101客厅优先
0.1940.08300.0831近似并列
0.250.05300.0702办公室优先

两式相等解出转折点：λ* = ln(P1 / P2) / (d1 − d2) = ln(0.3919 / 0.1486) / 5 = 0.1939 / 米。λ 高于该值时就近搜索更划算，低于该值时远赴高概率房间更划算。λ 的物理含义是每米路程愿意用多少概率换取；它可以按机器人的移动速度与场景尺度设定，也可以从数据里学习。注意 λ 为零时策略退化为「纯先验排序」，λ 很大时退化为「最近前沿优先」，两个极端都是已知的失败模式。

打分公式还可以看出先验的适用条件：当两个候选前沿的先验概率接近时（例如盆栽在客厅与办公室的 0.3919 对 0.1486 之比只有 2.64），距离项容易主导排序；当先验尖锐时（床 0.8679 对 0.0566，比值 15.3），即使卧室远一些，先验仍可能胜出。这与第 023 讲的定性图一致：目标越专门（马桶、床），目标导向探索的优势越明显。

4. 隐式先验的检验实验

论文的定性图与消融支持「策略学到先验」，但要从证据走到结论，需要排除替代解释。最主要的替代解释是：策略学到的只是「优先去未探索区域」的一般偏好，与类别无关。三组反事实输入可以区分两者。

实验输入扰动观测指标先验假设的预期覆盖偏好的预期
A 类别替换同一张地图，目标类别在 6 类之间替换长期目标落点分布、到达步数落点随类别显著变化，且与先验表排序相关落点分布基本不变
B 语义通道清零保留障碍与已探索通道，其余语义通道清零（目标已见格保留）幕级 SR、DTS退化到约 0.488（论文消融值）退化幅度与 A、C 无差异
C 目标通道打乱地图通道不变，把目标类别标签随机置换落点与置换标签的吻合度落点跟随被置换的目标，说明策略读目标通道落点不变

三条对照的逻辑环环相扣。A 检验「策略输出是否条件于类别」，C 检验「条件作用是否真的通过目标通道发生」，B 度量「失去其他物体语义线索的整体代价」。配合第 023 讲的消融数字：目标导向策略存在与否造成 −9.4 点，语义通道存在与否造成 −5.6 点，两者共同说明目标导向与语义信息各自独立贡献。检验时还要报告一条量化相关：长期目标所在房间的先验概率排序与策略实际排序的一致性（例如 Spearman 秩相关），以及同一场景换类别后的落点距离。

需要提前说明一个混淆：训练场景与测试场景不重叠时，先验表本身也有估计误差。若先验从只有几十个场景的训练集统计而来，改换目标类别后优先房间的估计会波动；实验中应把先验估计的不确定性一并报告。删除「先验表」这个环节、只比较端到端策略的落点分布，能部分绕开该问题，代价是无法把结论归因到具体概率量。

5. 真机迁移：证据与算账

论文的真机实验用 LoCoBot 平台与 PyRobot 接口，把训练好的系统直接部署，目标涵盖盆栽等类别（论文展示了盆栽目标的完整轨迹）。报告结果是：20 次真机试验中成功 13 次，成功率 65%。作者给出两条成功原因的定性解释：其一，第一视角分割用的 Mask R-CNN 在真实图像（MS-COCO）上训练，视觉域差小；其二，去噪网络与目标导向策略在俯视地图上运作，地图空间的语义结构与视觉纹理无关，属于域无关模块。论文还指出，端到端学习策略在真机上持续失败，归因于仿真与真实之间的视觉域差；而真机试验表明完美位姿与深度不构成成功的必要条件，属于定性表述，论文未给出对应消融数字。

小样本证据要用区间核算。20 次试验 13 次成功，点估计 0.65，按 Wilson 区间计算 95% 置信区间为 [0.4329, 0.8188]，半宽约 19.3 个百分点。把区间与仿真数字比较：Gibson 测试集 SR 0.544 落在区间内，MP3D 的 0.360 落在区间外（低于下界）。由于真机试验的场景、类别与判定协议与仿真评测不同，这组比较只能说明「真机成绩与 Gibson 量级相容」，不足以支持「真机优于 MP3D」这类方向性结论。若要把真机成功率的 95% 区间半宽压到约 10 个百分点，需要把试验量提高到约 85 次（按 p = 0.65 估算）。

真机噪声如何进入地图，可以用第 023 讲的公式量化。朝向误差 Δθ 在距离 d 处的横向偏移为 d · tan(Δθ)：0.1° 在 5 m 处为 0.0087 m，即 0.175 格；0.5° 为 0.873 格；1° 为 1.746 格。深度相对误差 δd 造成 δd · d 的径向偏移：1% 误差在 3 m 处为 0.030 m（0.600 格），2% 在 6 m 处为 0.120 m（2.400 格）。真实里程计的漂移通常高于深度误差，这也是地图在真机上先模糊、后错位的原因。论文的地图模块含多帧池化与去噪网络，能在一定程度上平滑这些误差；移植时需要监控位姿质量，并准备重定位或减速策略。

先验本身的适用边界也要写明。数据集统计的先验带地域与户型偏置：同一类别在不同地区的典型房间可能不同；训练集覆盖不到的类别没有可靠先验；多层住宅里房间与楼层的联合分布更复杂；场景内的动态变化（家具移动、房间改用途）会让历史统计过期。工程上可行的缓解手段有三条：用在线观测覆盖或修正离线先验（观测证据优先）；给先验一个不确定度权重，证据稀疏时降低其影响力；把先验按楼层或户型分组维护，避免全局平均抹掉结构。

实现思路与设计

本讲的设计任务是把「先验」从网络权重里搬到一个可检查、可替换的部件，并用它改造长期目标打分。四件事：先验表的生成与存储、前沿或长期目标打分、反事实检验的接口、真机移植的检查清单。

把房间条件分布显式化后，同一套探索框架可以在「学到的先验」与「统计的先验」之间切换：前者作为对照，后者作为可审计的默认值。代价是多维护一张表与一条一致性校验，收益是任何排序都能追溯到具体的概率数字，反事实检验也才有落点。

真机移植的三条硬检查

第一，深度量程：停止判定需要 1 m 内的可靠测距，量程下限不足会造成盲区。第二，位姿连续性：地图错位的首要来源是朝向漂移，部署前先做一段走廊往返测试，量化回环误差。第三，类别映射：真机检测器的类别集合与地图通道必须逐类核对，任何漏映射都会让先验指向错误通道。

关键代码与解读

三段代码分别实现先验表、前沿打分与 Wilson 区间。

片段 1：平滑条件概率与诊断量

import numpy as np

def room_prior(counts, alpha=1.0):
    """counts[c][r] 为类别 c 出现在房间类型 r 的场次数；返回 (概率表, 熵, KL)。"""
    counts = np.asarray(counts, dtype=np.float64)
    smoothed = counts + alpha                       # 加性平滑：零计数不再致命
    probs = smoothed / smoothed.sum(axis=1, keepdims=True)
    uniform = 1.0 / probs.shape[1]
    ent = -(probs * np.log2(np.clip(probs, 1e-12, None))).sum(axis=1)
    kl = (probs * np.log2(probs / uniform)).sum(axis=1)
    return probs, ent, kl

解读：（1）输入按类别分行、房间分列，输出逐行归一化的条件概率表；α 在归一化前加入，与非平滑版只差一个常数。（2）log 前做下截断，避免零概率产生负无穷；平滑后理论上无零元，截断只防御数值误差。（3）熵与 KL 以比特为单位，用来筛选「值得先验探索」的类别：盆栽的 0.252 说明先验接近均匀，探索应退回覆盖式策略。（4）函数不负责数据划分，统计方必须保证 counts 来自训练集，否则先验泄漏会让离线评估虚高。

片段 2：前沿打分与排序

def rank_frontiers(frontiers, prior_row, lam=0.2):
    """frontiers: [(cell, room_id, path_len_m)]；prior_row: 当前目标类别的 P(房间|c)。"""
    scored = []
    for cell, room_id, dist in frontiers:
        p_hit = prior_row[room_id]                  # 先验命中概率
        score = p_hit * np.exp(-lam * dist)         # 概率乘以距离折减
        scored.append((score, cell, p_hit, dist))
    scored.sort(key=lambda x: x[0], reverse=True)
    return scored                                    # 首位即下一段探索的前沿

def crossover_lambda(p_far, p_near, d_far, d_near):
    """两个候选前沿得分相等的 λ：先验优势与路程劣势相抵的位置。"""
    return np.log(p_far / p_near) / (d_far - d_near)

解读：（1）打分同时保留概率、距离与总分，失败分析时能判断是「先验把流程带偏」还是「路程估计失准」。（2）exp(−λd) 是连续折减，λ 的量纲为 1/米；与「概率除以距离」相比，它在 d 很大时才显著压制，行为更平滑。（3）crossover_lambda 把设计选择显式化：p_far = 0.3919、p_near = 0.1486、d 差 5 m 时转折点为 0.1939，λ 落点决定策略性格。（4）排序只对当前已提取的前沿生效；前沿集合的完整性仍由建图模块决定，打分无法找回没被观测到的区域。

片段 3：小样本置信区间

import math

def wilson_ci(x, n, z=1.959964):
    """二项比例的 Wilson 区间：小样本与极端比例下比正态近似稳定。"""
    p = x / n
    den = 1.0 + z * z / n
    center = (p + z * z / (2.0 * n)) / den
    half = z * math.sqrt(p * (1.0 - p) / n + z * z / (4.0 * n * n)) / den
    return center - half, center + half

lo, hi = wilson_ci(13, 20)          # SemExp 真机：20 次成功 13 次
print("point=%.4f  95%% CI=[%.4f, %.4f]" % (13 / 20, lo, hi))
# point=0.6500  95% CI=[0.4329, 0.8188]

解读：（1）Wilson 区间把点估计向 0.5 方向收缩，样本越小区间越宽，避免正态近似在 n = 20 时给出越界区间。（2）实算结果 [0.4329, 0.8188]，半宽 19.3 个百分点；把它写进报告比只写「65%」诚实得多。（3）区间是随机试验的兼容范围，不能用它做精确的功效推断；要比较两个方案，按目标差异另做样本量估算。（4）试验协议（场景数、类别、成功判据、是否配对）必须与区间一起报告，否则区间再精确也无法解释。

常见坑

  • 把隐式先验当成显式常识过度宣称：症状是论文结论被外推为「模型理解了房间功能」，而证据只支持「某组消融与定性轨迹」。根因是混淆「行为与先验一致」与「行为由先验驱动」。修复：补做本讲第 4 节的三组反事实实验，把结论限定在被扰动能改变的量上。
  • 先验统计与评测场景重叠：症状是离线评估指标好得异常，换测试集后回落。根因是 counts 统计用了测试场景，先验泄漏。修复：按场景划分统计与评测，先验表带版本与场景清单；用留出场景做一次干净复核。
  • 平滑常数与距离折减凭经验设定：症状是探索顺序在同一场景里随超参剧烈变化。根因是 α 与 λ 未做敏感性分析：α 过大抹平结构（盆栽与床趋同），λ 过大退化为最近前沿优先。修复：扫描 α ∈ {0.1, 1, 5} 与 λ ∈ {0.1, 0.2, 0.5}，报告排序稳定性与幕级指标。
  • 真机试验量不足就下结论：症状是用 20 次试验的 65% 宣称真机性能超过某仿真数字。根因是忽略了区间半宽 19.3 个百分点。修复：报告 Wilson 区间与协议；需要更窄区间时按约 85 次的量级扩试验。
  • 位姿漂移未监控导致地图错位：症状是运行一段时间后长期目标指向墙外或已探索区，策略无谓折返。根因是里程计漂移使地图与真实几何错位，1° 偏差在 5 m 处即 1.75 格的实算给出了量级。修复：加入位姿质量监控与重定位触发；降低移动速度；必要时切换回不依赖长程地图的覆盖策略。

小结

  • 语义先验有三种形态：房间条件分布、物体共现与空间关系；房间条件分布最易统计、最适合做探索排序。
  • 条件概率由计数经平滑得到，α = 1 时床集中在卧室（0.8679、熵 0.844 比特），盆栽最分散（熵 2.333）；KL 相对均匀分布给出一致结论。
  • 前沿打分 score = P(命中) · exp(−λd) 把概率与路程折中；本讲实算的转折点为 λ* = 0.1939 /米，λ 决定「先验优先」与「就近优先」的性格。
  • 隐式先验要靠反事实实验检验：类别替换、目标通道打乱、语义通道清零三组对照，配合落点分布与步数指标，并报告先验估计自身的不确定性。
  • 真机证据：LoCoBot 加 PyRobot，20 次成功 13 次，Wilson 95% 区间 [0.4329, 0.8188]；域无关模块（几何反投影、俯视地图、地图空间策略）是迁移可行的结构原因，位姿漂移是首要风险。
  • 下一讲换一条路线：端到端 CNN+RNN 曾经只有 6.2% 成功率，Ye 等（2021）用辅助任务、探索奖励与系留策略把它推到 24.5% 成功率与 8.1% SPL，第 025 讲将拆解这套配方的每个部件与量级。
