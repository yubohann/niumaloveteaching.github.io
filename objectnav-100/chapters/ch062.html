第四篇 · 开放词汇与大模型

第 062 讲｜CoW / Pasture：CLIP 基线

第 061 讲把开放词汇目标导航（Open-Vocabulary ObjectNav, OVON）定义为自由文本目标、379 类与 15k+ 实例的设定。本讲回到语言驱动零样本导航（Language-driven Zero-Shot Object Navigation, L-ZSON）的早期脉络，拆解 Gadre 等（2022，CoWs on Pasture）的 CLIP on Wheels（CoW）基线与 Pasture 基准：不做任何导航训练，用开放词汇定位、经典前沿探索与深度建图拼成流水线，在 Habitat、RoboTHOR 与 Pasture 上评测 21 种配置。Pasture 把语言目标细分为罕见物体、外观属性、空间关系、隐藏物体及各自的干扰项版本共七个能力档，合计 2,520 个任务。学完能判断零训练启发式基线的能力边界，并为第 063 与第 064 讲的学习型零样本方案建立对照。

  • 主题：开放词汇 / 零样本 / 启发式基线 / 基准设计
  • 关键公式：Rmap(c) ← max(Rmap(c), ρt(u))；触发条件：maxc Rmap(c) ≥ θ
  • 预计学时：75 分钟
  • 前置章节：第 061 讲（OVON 问题定义与 HM3D-OVON）

学习目标

  • 会形式化：写出 L-ZSON 的 episode 元组与成功判据，说明它与闭集 ObjectNav、ZSON 的关系，以及语言描述粒度带来的评测差异。
  • 会拆解：CoW 流水线的四段结构（深度建图、前沿探索、开放词汇定位、阈值触发规划与停止），并说明每段的接口与默认参数。
  • 会算：七个能力档成功率的算术均值与后处理增益，罕见物体相对 RoboTHOR 的差值，以及相对 ZSON 的成功率与 SPL 取舍。
  • 会判断：五类定位器与两种视觉骨干的取舍，干扰项与隐藏目标下的失效结构，经典前沿探索与学习型探索的对照结论。
  • 会读：验证集评测口径、RoboTHOR 与 Habitat 的可见性判据差异、v1 与 v2 表格数字的版本差异，以及三类失败模式。

背景与动机

第 061 讲把开放词汇目标导航的目标从固定类别名扩展为自由文本，并给出 HM3D-OVON 的 379 类、15k+ 实例口径。围绕这一设定存在两种技术路线。第一种把开放词汇模型当作感知模块，配上手工设计的探索与停止规则，不训练任何导航策略；第二种训练一个策略，把语言目标编码后直接作为策略输入。本讲处理第一种路线的代表：Gadre 等（2022，CoWs on Pasture）提出的 CLIP on Wheels（CoW）基线，以及为它设计的 Pasture 基准。

这条路线要回答的问题很直接：只靠开放词汇模型与经典规划，零样本导航能走多远？此前的评测多集中在常见类别（椅子、电视、沙发），语言目标退化为类别名，属性与空间关系没有进入评测。Pasture 把评测面铺开：罕见物体（如“木质玩具飞机”）、外观描述（如“小红苹果”）、空间描述（如“梳妆台上的盆栽”）、隐藏物体（如“床下的杯子”），以及在外观、空间、隐藏三类设定中加入视觉干扰项后的加压版本。七档任务共享同一套场景与成功判据，便于横向比较。

结论有两面。一面是能力证据：最好的 CoW 在 RoboTHOR 子集上取得 32.5% 成功率与 20.8% SPL，超过当时训练了 60M 步的 EmbCLIP-ZSON 对照；另一面是能力缺口：属性与空间描述没有带来稳定增益，干扰项使成功率进一步下降，隐藏目标最好也只有 19.2%。本讲拆解这套基线的结构与数字，第 063 讲转入学习型路线。

核心原理

1. L-ZSON 任务形式化

设 M 为自然语言目标描述集合，元素可以是一个类别名（“plant”），可以带属性（“snake plant”），也可以带空间或隐藏关系（“plant under the bed”）。设 S 为场景集合，p0 为智能体初始位姿。一个导航 episode 写为二元组 (m, p0)，其中 m ∈ M。训练阶段不出现任何该形式的样本，评测阶段的目标描述也未在训练中出现，零样本的含义由此确定。智能体在时刻 t 收到观测 ot（RGB-D 与位姿估计），执行动作 at，动作集合为离散四元组 {MoveForward, RotateRight, RotateLeft, Stop}：前进 0.25 m，左右转各 30°。

成功判据为：执行 Stop 时，智能体到目标实例的距离不超过 1.0 m；RoboTHOR 与 Pasture 另外要求目标在停止时刻可见，Habitat 2021 挑战口径不要求可见。两个指标为成功率（Success Rate, SR）与成功加权路径长度（Success weighted by Path Length, SPL）：

SR = (1/N) Σi=1..N Si，SPL = (1/N) Σi=1..N Si · ℓi* / max(ℓi, ℓi*) Si ∈ {0, 1} 为第 i 个 episode 是否成功；ℓi* 为 oracle 最短路径长度；ℓi 为实际路径长度；失败轨迹的 SPL 计 0

与传统 ObjectNav 相比，L-ZSON 的目标空间从闭集类别扩到自由文本；与 ZSON 相比，L-ZSON 明确允许属性与关系描述，ZSON 是只给类别名时的特例。这层包含关系决定了两类评测的读法：CoW 在 ZSON 基准上可以和 ZSON 方法直接比较，在 Pasture 上则考察额外的语言理解能力。

2. CoW 流水线：建图、探索、定位、停止

CoW 的输入是单目 RGB-D 与位姿估计，输出是动作序列。流水线分四段。第一段是深度建图：用相机内参与首帧深度初始化一张俯视占据栅格，分辨率 0.125 m；每步按动作的预期位移增量更新位姿，把深度点投到地面；已知相机高度 0.9 m，靠近地面的格子判为自由空间，其余判为占据。为抑制动作执行失败与深度噪声，地图比较相邻两帧深度以检测卡住的动作。位姿漂移会让窄通道在地图上闭合，当所有前沿都不可达时，地图整体重建。

第二段是探索。默认策略为前沿探索（Frontier-Based Exploration, FBE）：前沿定义为自由格与未知格相邻的边界，智能体贪心地走向最近的前沿，持续扩张已探索区域。第三段是开放词汇定位：每步用定位模块对当前 RGB 帧与目标文本计算相关性图 ρt(u)，其中 u 为像素坐标；相关性经深度反投影到地图，逐格做单调取大更新：

Rmap(c) ← max(Rmap(c), ρt(u))，c = Π(u, d(u), Tt) Π 为“像素 + 深度 + 位姿”到栅格单元的投影；单调取大让单帧高响应可以保留，同时抑制低响应帧的稀释

第四段是停止与规划：当地图上的最大相关性超过阈值 θ，取最大值所在格为目标，规划过去并停止。阈值的作用是平衡误触发与漏检：偏低会让智能体提前停在错误位置，偏高会让目标进入视野后仍继续探索。

3. 五类定位器与两种视觉骨干

论文比较五类开放词汇定位模块。CLIP-Ref. 把当前图像与 N 个指代性文本（如“图像左上角的盆栽”）做相似度匹配，得到按区域划分的相关性。CLIP-Patch 把图像切成若干小块，逐块过 CLIP 视觉编码器，再与目标文本嵌入做卷积式相似度，块级响应高者即目标所在。CLIP-Grad. 借用视觉 Transformer 的梯度相关性方法，用目标文本嵌入与视觉骨干的梯度构造像素级相关性图；论文去掉了该方法常见的归一化步骤，使目标不在视野时响应保持低值，从而提供真假两端的信号。MDETR 在 PhraseCut 上微调过，直接输出文本条件的分割。OWL-ViT 把 CLIP 类模型微调成开放词汇检测器，直接输出目标框。

骨干方面比较 ViT-B/32、ViT-B/16 与 EfficientNet B3。B/16 的块更小、算力更高，直觉上定位更细，但论文的结论相反：B/16 常常与 B/32 持平或更差。后处理提供两种取用方式：整块掩码，或只取掩码中心像素。中心像素策略基于一个任务事实：只要目标的一部分被登记到地图，就足以支持成功导航，稀疏目标能减少地图污染。

4. Pasture 七个能力档与数据统计

Pasture 建在 RoboTHOR 验证场景上，后者有对应的真实房间版本，便于后续真机评测。七个能力档为：罕见物体（每房间加入 12 个新物体，标识含图像文字与外观属性，如“写着 CVPR 的白板”）、外观描述（模板为“{尺寸}，{颜色}，{材质}{物体}”）、空间描述（“{物体}在{[某物]}上，靠近{[某物]}”）、外观描述加干扰项、空间描述加干扰项、隐藏物体描述（“{物体}在{x}里/下”，并从房间移除该物体的可见实例）、隐藏描述加干扰项（重新放回可见实例作干扰）。

规模上，每个能力档使用 12 个物体实例、15 个房间、2 个起始位置，得到 12 × 15 × 2 × 7 = 2,520 个任务，与 RoboTHOR 的 1,800 与 Habitat MP3D 的 2,195 同量级（分别为其 1.40 倍与 1.15 倍）。统计细节：47% 的物体属于“小”档；每个物体平均配 1.2 个颜色描述（颜色候选 22 个）与 0.6 个材质描述（材质候选 5 个）；空间描述里每个物体配一个“在上/在内”关系，平均 1.9 个“靠近”关系。描述均经人工检查。

探索策略对照固定定位器（OWL-ViT B/32 中心像素）后比较三种选择：FBE 在 Pasture 均值上为 12.6 SPL / 21.1 SR，RoboTHOR 上为 16.9 / 26.7；在 RoboTHOR 训练的学习型探索为 10.2 / 17.3 与 13.1 / 20.9；在 Habitat 训练的学习型探索为 8.6 / 19.4 与 9.8 / 20.4。FBE 在全部指标上领先，且不需要任何训练步。论文的解释有两点：学习型探索虽能学到有效行为，但在跨域推理时受训练域约束，Habitat 训练的模型迁到 RoboTHOR 与 Pasture 时下降最明显；FBE 没有域依赖。

7. 失败结构与边界

论文对最优配置做失败分析，归为三类：探索失败（目标从未进入视野）、定位失败（目标进入视野但定位器未触发）、规划失败（已触发但地图误差导致到不了目标格）。探索与定位的占比接近，加入干扰项后定位失败比例上升，与“属性文本利用不足”的判断一致。边界条件有四条。第一，评测使用各数据集的验证集，因为官方测试集真值未公开，跨论文比较要确认 split 口径。第二，域噪声设置不同：RoboTHOR 与 Pasture 有动作噪声、无深度噪声，Habitat 有显著深度噪声与重建伪影、无动作噪声，数字不可跨域直接比较。第三，成功判据的可见性要求不同，RoboTHOR 与 Pasture 要求目标可见，Habitat 2021 口径不要求。第四，CoW 使用 RGB-D，而 ZSON 与多数学习型对照只用单目 RGB，深度这一项在公平性比较中需要单独说明。

数据流

每步的数据流为：观测 (RGB, 深度, 位姿) → 地图更新 → 若置信不足，选前沿并规划；若置信超过阈值，选最大相关格并规划；到达目标格后执行停止。定位模块与探索模块共享同一张地图：探索消费地图的自由与未知边界，定位向地图写入相关性。这种共享让“看过的区域”同时携带几何与语义两类信息，也是 CoW 不需要训练的原因：语义来自预训练模型，几何来自深度与位姿，二者都不依赖导航数据。

评测设计

评测矩阵由三套环境与七个能力档组成，共评估 21 种 CoW 配置：表 1 的 18 种（5 类定位器 × 骨干与后处理组合）加表 2 的 3 种探索变体。按“配置 ×（Pasture 2,520 + RoboTHOR 1,800）”可复算的最小评测规模为 (18 + 3) × 4,320 = 90,720 条 episode，与论文“超过 9 万条”的口径一致。RoboTHOR 子集为四个留出类别，用于与 EmbCLIP-ZSON 对照；Habitat MP3D 用于与 SemanticNav-ZSON 对照。跨论文引用时必须同时标注：数据集、split（验证集）、本体配置、成功判据与是否使用深度。

片段 1：前沿选择与地图重建触发

import numpy as np

FREE, OCCUPIED, UNKNOWN = 0, 1, -1

def frontiers(grid):
    """前沿：与未知格相邻的自由格，代表可继续扩张的边界。"""
    free = grid == FREE
    unknown = grid == UNKNOWN
    adj_unknown = np.zeros_like(free)
    for dy, dx in ((1, 0), (-1, 0), (0, 1), (0, -1)):
        adj_unknown |= np.roll(np.roll(unknown, dy, 0), dx, 1)
    return np.argwhere(free & adj_unknown)

def pick_frontier(grid, agent_xy, geodist):
    """贪心选择最近前沿；返回 None 表示需要重建地图。"""
    fs = frontiers(grid)
    if len(fs) == 0:
        return None, True                     # 无前沿：可能被位姿漂移困死
    d = [geodist(agent_xy, (int(f[0]), int(f[1]))) for f in fs]
    return tuple(int(x) for x in fs[int(np.argmin(d))]), False

解读：（1）前沿判定只依赖栅格状态，不需要语义，因此与定位模块解耦，任何定位器都能复用。（2）“无前沿触发重建”处理的是位姿漂移导致窄通道闭合的情形：地图上的自由空间被割裂后，智能体可能困在局部区域，重建把地图恢复到未知状态，重新开始探索。（3）贪心最近前沿牺牲了全局覆盖效率，换来实现简单与零训练；表 2 显示这一取舍在 Pasture 与 RoboTHOR 上优于两种学习型探索。

片段 2：相关性反投影与逐格取大

def project_relevance(depth, K, pose, relevance, grid, res=0.125, height=0.9):
    """把像素级相关性反投影到地面栅格，逐格取历史最大值。"""
    h, w = depth.shape
    us, vs = np.meshgrid(np.arange(w), np.arange(h))
    # 相机坐标：x 向右，y 向下，z 向前；再旋转平移到世界系
    xyz_cam = np.stack([(us - K[0, 2]) * depth / K[0, 0],
                        (vs - K[1, 2]) * depth / K[1, 1],
                        depth], axis=-1).reshape(-1, 3)
    R, t = pose[:3, :3], pose[:3, 3]
    xyz_world = xyz_cam @ R.T + t
    floor = xyz_world[:, 1] < height - 0.2        # 只保留接近地面的点
    rel = relevance.reshape(-1)[floor]
    xy = xyz_world[floor][:, [0, 2]]
    ij = np.floor(xy / res).astype(int)
    for (i, j), r in zip(ij, rel):
        grid[i, j] = max(grid[i, j], r)           # 单调更新，抗单帧噪声
    return grid

解读：（1）取大更新的动机在时序噪声：单帧相关性抖动大，若用平均或衰减，目标短暂高响应会被后续低响应稀释；取大保证一次可靠检测长期留在图上。（2）只保留接近地面的点，避免把墙面与上限上的高响应投到错误栅格；0.2 m 的余量对应相机高度 0.9 m 的容差。（3）分辨率 0.125 m 与动作步长 0.25 m 成整数比，栅格索引不会因半步移动反复落到边界格上。

片段 3：主循环：探索与置信触发的切换

def cow_episode(env, localizer, goal_text, threshold=0.6, center_pixel=True):
    """探索直到置信超阈值，再规划到高相关区域并停止。"""
    grid = np.full(env.map_shape, UNKNOWN, dtype=float)
    while not env.episode_over():
        rgb, depth, pose = env.observe()
        rel = localizer(rgb, goal_text)           # 与 RGB 对齐的相关性图
        if center_pixel:
            rel = keep_center_pixel(rel)          # 只留连通域中心，抑制误触发
        grid = project_relevance(depth, env.K, pose, rel, grid)
        if grid.max() >= threshold:
            target = np.unravel_index(np.argmax(grid), grid.shape)
            env.plan_and_move_to(target)          # 目标驱动规划
            if env.at(target):
                env.stop()                        # 停在高相关格
                break
        else:
            f, reset = pick_frontier(grid, env.agent_xy, env.geodist)
            if reset:
                grid.fill(UNKNOWN)                # 漂移导致无路可走时重建
            env.plan_and_move_to(f)
    return env.success()

解读：（1）主循环只有两种模式：置信不足时探索，置信足够时奔赴目标，状态机简单且无训练参数。（2）阈值 θ 是唯一把感知转成决策的门限，按定位器分布分别调参；OWL-ViT 与 CLIP 类模型的响应尺度不同，跨模型照搬阈值会同时改变误触发与漏检率。（3）停止前用“到达目标格”确认，避免在高响应格附近提前停止；RoboTHOR 与 Pasture 还要求停止时目标可见，可见性由环境判定，策略端无法绕过。

常见误区

  • 跨版本混用数字：症状是用 CoW 的 MP3D 成功率 11.1% 与 v2 表 3 的 9.2% 或 7.4% 相互矛盾。根因是不同 CoW 配置与论文版本（v1 2022-03、v2 2022-12）报告的行不同。修复：每张表标注定位器、骨干、后处理与版本；引用 11.1% 时注明来自 ZSON 论文引用的早期口径。
  • 把可见性判据混谈：症状是用 RoboTHOR 的成功率与 Habitat 的成功率直接排序。根因是 RoboTHOR 与 Pasture 要求停止时目标可见，Habitat 2021 口径不要求。修复：对照表分列判据；跨环境比较只做趋势判断。
  • 把七档均值当作任务加权成功率：症状是复算 21.1% 时对不上。根因是均值 SR 为七档算术平均，隐含各档任务数相同（每档 360 条）。修复：复算时确认 12 × 15 × 2 的每档规模；若要加权，需按真实任务数重算。
  • 照搬定位阈值：症状是换一个定位器后成功率骤降。根因是各模型的响应分布与归一化方式不同，CLIP-Grad. 还特意去掉了归一化。修复：按模型重调阈值，报告调参协议；不要把 OWL-ViT 的阈值移植到 CLIP 类定位器。
  • 忽略域噪声设置：症状是在 Habitat 上复现 CoW 时 SPL 低于论文。根因是 Habitat 有显著深度噪声与重建伪影，地图质量下降更快。修复：复现实验先确认噪声配置；地图重建触发逻辑在噪声域要更频繁。
  • 把中心像素后处理当成纯损失：症状是担心稀疏目标丢失定位信息。根因是未理解成功判据只需目标部分可见。修复：先做整块掩码与中心像素的对照；表 1 显示中心像素在 OWL 配置上均值 SR 提升 3.9 个百分点。

  2. 写出像素 (u, v) 与深度 d 到世界坐标的完整变换，说明反投影时逐格取大的理由，并给出一个单帧误检后地图长期保留的修复方案。★★
    提示

  3. 从表 1 计算外观、空间、隐藏三档加入干扰项后的成功率损失（26.4→19.4、19.4→16.1、19.2→14.4），并设计一个只改变干扰项数量的对照实验来定位损失来源。★★

    提示

小结

  • L-ZSON 把目标扩到自由文本，允许属性与关系描述；ZSON 是其特例。成功判据为停止距离 ≤ 1.0 m，RoboTHOR 与 Pasture 另加可见性要求。
  • CoW 是不训练的四段流水线：0.125 m 俯视栅格建图、FBE 探索、开放词汇定位、阈值触发的规划与停止；21 种配置合计评测超过 9 万条 episode（Pasture 与 RoboTHOR 上的可复算口径为 90,720 条，另有 MP3D 与子集评测）。
  • Pasture 七档 × 12 物体 × 15 房间 × 2 起点 = 2,520 个任务；最优配置 OWL-ViT B/32 中心像素均值 SR 21.1%、均值 SPL 12.6，RoboTHOR 16.9 / 26.7。
  • 罕见物体成功率高于常见物体（32.8% 对 26.7%，+6.1 点）；属性与空间描述未带来稳定增益；干扰项使外观档下降 7.0 点，隐藏档下降 4.8 点；B/16 骨干未优于 B/32。
  • 零训练 CoW 在 MP3D 的 SPL 4.9 略高于训练 500M 步的 SemanticNav-ZSON（4.8），成功率低 6.1 点；在 RoboTHOR 子集上成功率大幅领先 EmbCLIP-ZSON，说明“感知换训练”在部分指标上可行。
