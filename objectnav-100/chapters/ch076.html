第四篇 · 开放词汇与大模型

第 076 讲｜2026 快照 I：技能与状态

第 074 与 075 讲把「VLM 即策略」的两条路走完：零样本提示与视频 VLM 微调。本讲进入 2026 快照章，用三篇论文回答同一条主线的三个问题。SkillNav（Sang 等 2026，arXiv:2607.15758）问「跨步行为意识放在哪里」：把好奇心价值图当作可写基底，用软缩放、抬底、硬覆盖三层技能在分数级写入行为记忆，零 token 成本，在 MP3D 与 HM3D 两个版本上刷新 SPL（25.5 / 39.3 / 43.2）。LANav（Zhang 等 2026，arXiv:2607.18794）问「策略状态怎么更新」：受控实验显示 Transformer 策略不随上下文变长受益，改用线性注意力并设计加权状态扩展（WSLA），HM3D-OVON 平均成功率 36.4%，比 Transformer 基线高 6.3 个百分点。快慢 ReAct（Lan 等 2026，arXiv:2608.09816）问「何时思考、用什么证据、失败怎么办」：反应式价值图控制器常开，坐标锚定记忆（语义栅格 + 位姿关键帧）支撑一个事件触发、预算受限、失败可回退的推理循环，HM3D v1 验证集 68.75% SR，贪心选择远前沿相对深思少 3.40 个百分点。

  • 主题：技能干预 / 状态更新 / 有界深思 / 2026 前沿对照

学习目标

  • 会定位：说清三篇论文各自回答的问题（行为记忆放哪、状态如何更新、深思如何受限），以及三种「状态」载体（地图、策略网络、外部记忆）的分工。
  • 会推导：SkillNav 三层算子的公式与固定组合顺序，并验证三条稳定性性质；WSLA 的门控增量更新与加权读出；ReAct 的关键帧打分与事件触发条件。
  • 会算：三篇的主结果差值与消融差值，包括 SPL 的绝对与相对增益、调用次数与成功率的联合读法、距离分层增益。
  • 会判断：三套机制各自的成本结构与失效边界，能按场景（免训练约束、长程探索、算力预算）选择或组合。
  • 会设计：把「地图级技能 + 策略级状态 + 有界深思」组合成一套系统，给出接口、预算、降级路径与评测口径。

背景与动机

第 074 讲暴露了提示词路线的上限：跨步行为无法靠拼接文本获得，且 token 成本随 episode 线性上升。第 075 讲用视频 token 与训练数据补上了历史利用，但代价是训练成本与固定 token 预算。2026 年的三篇工作从三个不同位置切入同一问题：行为记忆应该存放在哪里，策略的内部状态应该如何更新，以及大模型调用应该何时发生、何时停止、失败后去哪里。三篇的共同底色是「把无界的东西变成有界」：SkillNav 把行为记忆写进已有的价值图（零 token），LANav 把历史压缩进固定大小的递归状态（零上下文增长），ReAct 把深思限制在结构事件上并给出调用预算与回退路径。

读这一讲需要先建立一张坐标系：状态放在地图（SkillNav）、放在策略网络（LANav）、放在外部记忆与调用预算（ReAct）。三者可以共存，也各自独立成立。本讲先分别拆机制与结果，再做横向对照与组合设计。三篇的评测口径不同（SkillNav 在 ObjectNav 的 HM3D 与 MP3D，LANav 在 HM3D-OVON，ReAct 在 ObjectNav 的 HM3D v1 与 MP3D），跨表数字不可直接排序，这一点会在每张表后单独标注。

2. SkillNav：分数级技能干预

管线基础是四模块 VLM 导航器：Predict VLM 给每个朝向打好奇心分，Plan VLM 生成子目标，Goal VLM 验证目标检测，Action VLM 选局部动作。智能体每步原地环视，得到 K = 6 个朝向视图，Predict VLM 给出每方向分数 α(θk) ∈ [0, αmax]，其中 αmax = 10。分数经射线投射累积到好奇心价值图 Mt，随后进入精炼层（Refinement Layer）。精炼层把行为记忆写成对分数的结构化修正，分三层算子。

第一层软缩放（soft scaling）按比例重加权：

S(αk) = min(γk · αk, αsoft)，γk ∈ (0, +∞)，αsoft = 7.0

γk 大于 1 放大，小于 1 抑制但不置零。软上限 αsoft = 7.0 刻意低于全局最大值 αmax = 10，把分数区间的顶部留给更高层。典型实例是「房间耗尽」：当可见方向平均好奇心低于阈值 τexh 且体素覆盖超过 τcov，已探索方向取 γk < 1，朝向未探索前沿或房间出口的方向取 γk > 1。

第二层抬底（lower-bound boost）保证确认过的目标位置不会被瞬时分数波动遗忘。当 Goal VLM 在连续两步、两个邻近像素确认目标，取两像素坐标均值、用深度反投影得到全局锚点 p⋆，存入历史缓冲。此后每一步，以 p⋆ 为圆心、半径 r 的圆形区域 B(p⋆, r) 投影到地图，区域内单元格取值抬到 αmax：

m̂i,j = αmax，若 (i,j) ∈ B(p⋆, r)；否则 m̂i,j = mi,j

第三层硬覆盖（hard override）在行为指标越过阈值时无条件改写动作。典型实例是防卡死：监测滑动窗口 W = 2 步内的 L2 位移，低于 τmove 时启动逃脱子程序，选出与已失败方向集 Ft 不相交的最开阔方向 θ†，构造覆盖集 𝒪 = {k†} ∪ Ft，替换值为 ck = cesc（k†）或 0（Ft）。若 θ† 仍不产生位移，把 k† 追加进 Ft，逐一排除死角。另有一个 ABAB 振荡检测器检查最近四步是否在两个位置间往返，触发时把重复航点方向加入 Ft 并覆盖为 0。

三层按固定顺序组合：

ℛ(α, Mt, ht) = 硬覆盖 ∘ 抬底 ∘ 软缩放 (α)

论文证明这个顺序（在活动支撑集不相交的算子间可交换的意义下）是唯一同时满足三条性质的顺序。P1 抬底保持：若方向 k 的下界为 βk > 0 且未被覆盖，最终分数 α̂k ≥ βk。P2 覆盖优先：被覆盖方向最终值等于替换值 ck。P3 缩放中性：γk = 1、βk = 0 且未覆盖时，最终值等于原值。直观检查：若先抬底后缩放，γk < 1 会把抬过底的方向压回下界之下，违反 P1；若先覆盖后抬底，非零下界会把刚覆盖为 0 的方向重新抬起，违反 P2。这三条性质把「新技能如何注册」变成了声明式问题：新技能只需声明属于哪一层，冲突消解由固定顺序保证。

分数级修正之外，SkillNav 保留一条受限提示词通道：回合开始时从离线库加载最多 Lmax 条类别级提示（例如「椅子必须有靠背」「只在镜子里可见的物体不是有效检测」），追加到 Predict 与 Plan 的系统提示中，整回合固定，token 成本 O(1)。空间记忆全部走地图，语义消歧全部走短提示，论文把这一分工称为双表征设计。

结果（Sang 等 2026，表 1；Habitat，40 步预算，成功阈值 1.0 m）：MP3D 48.3% SR / 25.5 SPL；HM3D v0.1 69.7% / 39.3；HM3D v0.2 75.9% / 43.2。相对此前最强方法 MerNav：SPL 分别提高 6.0、2.4、5.6（相对 +30.8%、+6.5%、+14.9%），SR 在 HM3D 上高 1.7 与 1.1，在 MP3D 上低 2.5。论文把 MP3D 的取舍解释为：行为记忆在锚定目标后截断冗余探索，牺牲少量晚成功换取路径效率。消融在 HM3D v0.2 上进行（表 2）：基线 69.9% / 28.3；只加提示通道 70.5% / 28.1（SR +0.6，误检率从 10.1% 降到 8.9%）；再加精炼层 71.6% / 31.9（SR +1.1，SPL +3.8，超步率从 20.4% 降到 18.7%）；换更强骨干（Gemini-3-Flash）到 75.9% / 43.2（超步率再降到 13.4%，误检率回升到 10.7%）。分工清晰：提示通道治语义混淆（误检），精炼层治空间低效（超步）。类别分析给出残余瓶颈：床、沙发、椅子、马桶等显著类别在两种骨干间基本饱和（沙发 81.8% 持平，马桶 75.3% 持平），而电视屏幕 +16.3、床 +10.3、植物 +7.9，差距集中在易混淆类别，瓶颈定位在感知侧。

3. LANav：策略状态更新与线性注意力

LANav 的问题起点是一个受控发现：在开放词汇目标导航（Open-Vocabulary Object Goal Navigation, OVON）里，Transformer 策略的性能不随上下文窗口变长而提升，训练上下文取 500 时甚至退化；换句话说，把更多历史塞进注意力窗口并不等于更好地利用历史。论文把变量锁定在策略骨干上：视觉编码器、语言编码器、数据与训练流程全部固定，只换时序结构。

任务沿用 DAgRL 设置：每步输入 xt = (It, G, at−1)，即 RGB 观测、语言目标、上一动作，不提供位姿。RGB 与文本各经冻结的 SigLIP 编码器得到 768 维向量，上一动作经可学习嵌入得到 32 维，三者拼接后投影到骨干维度 d = 512。动作空间为 6 个离散动作：前进、左转、右转、抬头、低头、停止。四层解码器骨干在上下文窗口 l 上运行。

Transformer 骨干每步对窗口内所有 key 做 softmax 注意力，复杂度随 l 二次增长；线性注意力骨干为每个头维护一个与上下文长度无关的状态矩阵 St ∈ ℝdk×dv，用当前 key-value 对增量更新，当前 query 从状态读出：

St = Update(St−1, kt, vt)；ot = qtT St

不同线性注意力变体的差别在更新规则：Linear Transformer 直接累加 key-value 关联；DeltaNet 按现有记忆的预测误差更新，写系数控制修正强度；Gated DeltaNet 再引入数据依赖的保留门。论文的结论是「更新规则越结构化、越受调节，导航性能越好」，这组递进在结果表里逐级可见。

WSLA（Weighted State-Expansion Linear Attention）在此基础上做两件事。第一，状态扩展：把每个头展开为 E 个独立子状态，query 与 key 经线性投影扩到 E 组，value 在各子头间共享以省参数。第二，加权读出：用一组可学习 logit λ ∈ ℝE（跨头跨时间共享）对子状态输出做 softmax 加权。每个子头 (h,e) 的门控增量更新为：

S̃t−1 = γt St−1；Δvt = vt − S̃t−1T kt；St = S̃t−1 + βt kt ΔvtT

其中 γt 为衰减门（保留多少旧状态），βt 为写入门（修正多强），两者按 Gated DeltaNet 的参数化逐子头预测。读出为 ot(h,e) = qt(h,e)T St(h,e)，再经 λ 加权、RMSNorm 与 SiLU 门控后进入下一层。实现取 H = 4 个头、E = 4 个子状态，参数量与计算量与其它骨干相当。

结果（Zhang 等 2026，表 1；HM3D-OVON，三个验证划分，三次种子均值）：GRU 26.7%、Transformer 30.1%、DAgRL 29.7%、Linear Transformer 31.3%、DeltaNet 33.9%、Gated DeltaNet 34.6%、WSLA 36.4%（划分分别为 47.8 / 39.8 / 21.6）。WSLA 相对 Transformer 平均 +6.3 个百分点（相对 +20.9%），相对 GRU +9.7；同族内从 Gated DeltaNet 到 WSLA 再 +1.8。消融（表 3）：34.6 → 35.2（加状态扩展）→ 36.4（加加权读出），两级各有贡献。距离分层（表 2）显示增益随距离变大：0 至 8 m 的 SR 差 +6.71、SPL 差 +1.36；8 至 15 m 为 +6.92 与 +3.38；15 m 以上为 +7.68 与 +4.21。效率对照（图 4）：Transformer 每动作 FLOPs 从 l = 100 的 3.52G 升到 l = 1000 的 42.53G（12.08 倍），WSLA 稳定在约 0.048G，为前者的约 1/886。迁移与部署：HSSD 零样本 19.55 → 29.17 SR（+9.62），60M 步微调后 56.17 → 64.50（+8.33），SPL 增益 10.17；Unitree Go2 真机 5 类目标、2 个起点、每个组合 5 次共 50 次试验，成功 41 次，82%。

训练配方（复现必读）：两阶段，DAgger 预训练 150M 步，PPO 微调 100M 步，合计 250M 步；8 张 A100 80GB，每卡 32 个并行环境，16 个小批量每次更新，Adam，学习率 2.5 × 10−4，梯度裁剪 0.2。

4. 快慢 ReAct：坐标锚定记忆与有界深思

系统的底座是常开的反应式控制器（论文基于 ASCENT，属 VLFM 价值图一族）：每层楼维护四张 2D 地图，占据图管运动与前沿，价值图在每个自由格 c 存放目标条件分数

V(c) = sim( φimg(Ic), φtxt(g) )

其中 Ic 是格子关联的视角，g 是目标类别。目标候选由检测集成与轻量分割器给出，每个候选在融合进「可授权停止」的物体图之前，必须通过一次在线验证门：把当前帧按候选框裁剪后连同类别名交给 VLM，接受才融合，拒绝则丢弃、后续帧可再次提出。论文给出的数字是门控在融合前否决 16.7% 的候选检测。融合不可逆，所以验证必须在融合前完成，这是设计要点，需要在系统结构层面落实。

慢层与快层共享坐标化记忆。语义栅格把占据像素按 8 × 8 块聚合，每格约 0.4 m，存三样东西：房间类型投票直方图（累加不覆盖，让瞬时误分类被平均掉）、覆盖过该格的关键帧索引环、以及目标之外的已确认物体实例表（类别、反投影世界坐标、观测次数、支撑关键帧）。实例被观测至少两次才算确认并可检索，用于压制单帧误检。关键帧库保存低分辨率缩略图，按平移与旋转阈值采样，带位姿、楼层、步号标签，逐层容量限制保证新楼层不会挤掉旧楼层记忆。检索接口按查询位置返回四项：房间估计与置信度、附近确认实例、覆盖统计、排序后的候选关键帧。候选打分同时约束视角与距离：

s(k) = cos(Δβk) − λ dk，约束 |Δβk| ≤ ½ HFOV

Δβk 是关键帧相对查询方向的方位偏差，dk 是距离。图像召回按固定降级阶梯：精确足迹命中、放宽足迹搜索、前沿发现帧、最后返回空并要求纯文本继续。

深思由四类结构事件唤醒，全部由反应层已有量计算。第一，接触卡死：滑动窗口 W 内碰撞计数增量之和达到 κ，配合上升沿锁存与冷却期保证一次物理卡死只触发一次事件；恢复分两级，第一级抑制当前前沿目标并强制重规划（零模型调用，解决大多数卡死），只有位移窗口内仍未脱困才升级为一次 VLM 逃脱方向查询。第二，远前沿：当最近候选前沿距离超过 dfar，唤醒深思；第一轮纯文本比较（房间估计、附近物体、类别与房间的固定亲和知识），文本分不开时最多请求两个候选的首视角图，第二轮带图，把固定图像预算变成按需支出。第三，前沿耗尽：前沿集为空时，把当前楼层关键帧均匀抽样成一张带索引的拼图，单次带图调用询问是否有被忽略的通道（楼梯、门、开口）；识别出的视图把锚定位姿变成带有效期的持久目标，并重新启用该处被抑制的探索目标。论文报告重扫在 6.1% 的回合触发，其中 41.4% 从记忆视图中找到新目标。第四，跨楼层：把纯文本的逐层摘要交给 VLM 决定是否换层。

预算与仲裁是这套设计的另一半。单次调用最多 M = 3 轮推理、每轮最多 2 张图，另有墙钟上限；整回合上限 20 次模型调用，其中带图调用不超过 10 次；单步看门狗 180 秒，连续失败触发熔断。仲裁器按固定优先级协调：恢复宏动作最高，楼梯状态机在跨层时持有控制权，其余情况驶向已检测目标或深思目标；深思目标为持久目标，带有效期，避免反复横跳。所有失败路径（记忆为空、服务中断、回复不可解析、预算耗尽）都回退到反应层，保证系统始终有控制器。

结果（Lan 等 2026，表 1；Habitat，成功阈值 1.0 m 且目标可见，500 步上限）：HM3D v1 验证集 68.75% SR / 33.97 SPL，MP3D 验证集 47.29% / 18.01。对照：ASCENT 65.4 / 33.5 与 44.5 / 15.5；VLFM 52.5 / 30.4 与 36.4 / 17.5。平均每回合 5.00 次深思调用、205 个环境步，即约每 41 步一次调用。消融（表 2，同一 2000 条 HM3D episode 配对比较）：贪心前沿（远前沿用 argmax 不深思）65.35% / 32.78，比完整系统低 3.40 个百分点（配对自助法 95% 置信区间 [1.70, 5.05]，McNemar χ² = 15.06，p < 0.001）；每步都深思（Always-Deliberate）64.80% / 31.36，比完整系统低 3.95 且低于贪心，调用反而更多（8.87 次，其中带图 4.88 次）；单轮给全图（One-Shot）65.05% / 31.80，低 3.70，调用更少但全部带图；去掉语义栅格 65.40% / 32.49，低 3.35，调用与带图次数与完整系统几乎相同（4.99 / 3.02 对 5.00 / 3.04）；去掉重扫 68.50% / 33.92，低 0.25。失败类别归因：深思的 3.60 个百分点分别来自误检 1.35、无前沿停止 1.25、漏检 1.00；语义栅格 3.35 中的 2.55 集中在无前沿停止；深思重定向的 3.60 个百分点中 3.40 最终转化为成功（94.4%）。这组消融的核心信息是：增益来自「何时深思、读什么记忆」，调用更多并不自动更好。

关键代码与解读

四段代码对应技能组合、状态更新、记忆检索与预算仲裁。代码为教学重写。

片段 1：SkillNav 精炼层的固定组合

import numpy as np

ALPHA_MAX, ALPHA_SOFT = 10.0, 7.0

def soft_scaling(alpha, gamma):
    """按比例重加权，钳在软上限之下，顶部留给更高层。"""
    return np.minimum(gamma * alpha, ALPHA_SOFT)

def lower_bound_boost(scores, anchors, grid):
    """把确认锚点邻域抬到全局上限，保证目标不被遗忘。"""
    out = scores.copy()
    for p_star, radius in anchors:
        out[grid.within_radius(p_star, radius)] = ALPHA_MAX
    return out

def hard_override(scores, forced):
    """阈值触发的无条件改写：逃脱方向与已失败方向。"""
    out = scores.copy()
    for k, value in forced.items():
        out[k] = value
    return out

def refine(alpha, gamma, anchors, forced, grid):
    scores = soft_scaling(alpha, gamma)          # 第一步：缩放
    scores = lower_bound_boost(scores, anchors, grid)  # 第二步：抬底
    return hard_override(scores, forced)         # 第三步：覆盖

解读：（1）顺序不可交换：先缩放后抬底才能满足抬底保持；先抬底后覆盖才能满足覆盖优先。（2）软上限 7.0 小于 10，保证缩放过的方向不会冒充抬底结果。（3）覆盖值直接替换，不参与排序竞争，对应「无条件动作」。（4）新技能按所属层级注册，冲突由顺序统一裁决，无需逐对检查。

片段 2：WSLA 的子状态更新与加权读出

import torch

def wsla_step(S, q, k, v, beta, gamma, lam):
    """S: (E, dk, dv) 子状态；q,k: (E, dk)；v: (dv,)；
    beta,gamma: (E,) 逐子头门；lam: (E,) 读出 logit。"""
    S = gamma[:, None, None] * S                       # 衰减旧状态
    pred = torch.einsum("edk,edv->ekv", k, S)          # 旧状态对 v 的预测
    delta_v = v[None, :] - pred                        # 预测误差
    S = S + beta[:, None, None] * torch.einsum("ek,ev->ekv", k, delta_v)
    o = torch.einsum("edk,edv->edv", q, S)             # 子头读出
    w = torch.softmax(lam, dim=0)                      # 可学习加权
    return S, torch.einsum("e,edv->dv", w, o)

解读：（1）状态矩阵大小与上下文长度无关，这是长程算力优势的来源（WSLA 约 0.048G FLOPs/动作）。（2）γ 控制旧状态保留、β 控制新信息写入，两个门逐子头预测，让不同子状态承担不同时间尺度。（3）预测误差形式（delta 规则）让状态在「与预测不符」时修正更多，优于纯累加。（4）λ 跨头跨时间共享，参数极少，消融显示加权读出贡献 +1.2 个百分点（35.2 到 36.4）。

片段 3：ReAct 坐标锚定记忆的检索打分

import math

def retrieve(memory, query_xy, hfov, lam=0.5, top_n=4):
    """按世界坐标检索：房间估计、确认实例、覆盖度、候选关键帧。"""
    cell = memory.grid.cell_at(query_xy, cell_size=0.4)   # 8x8 像素块聚合
    room, confidence = cell.room_votes.argmax_with_conf()
    instances = cell.instances.filter(min_observations=2)  # 至少两次观测
    coverage = cell.seen_fraction()
    scored = []
    for kf in memory.keyframes.near(query_xy):
        d = math.dist(kf.pose[:2], query_xy)
        d_bearing = abs(angle_diff(kf.yaw, bearing_to(kf.pose, query_xy)))
        if d_bearing <= hfov / 2.0:                       # 视场门
            scored.append((kf, math.cos(d_bearing) - lam * d))
    scored.sort(key=lambda item: -item[1])
    return room, confidence, instances, coverage, [k for k, _ in scored[:top_n]]

解读：（1）一切按世界坐标索引，位姿抖动被 0.4 m 粗粒度容差吸收；楼层号随格子与关键帧存储，可检索已离开的楼层。（2）实例至少两次观测才可检索，与验证门一起构成两级证据准入。（3）打分同时惩罚方位偏差与距离，视场门保证召回的视图确实覆盖查询方向。（4）检索失败返回空并由调用方转纯文本，对应降级阶梯的最后一格。

片段 4：深思预算与失败回退

class Deliberation:
    def __init__(self, per_run=20, image_calls=10, rounds=3):
        self.calls, self.image_calls = 0, 0
        self.per_run, self.image_calls_max, self.rounds = per_run, image_calls, rounds

    def request(self, with_image=False):
        if self.calls >= self.per_run:
            return False
        if with_image and self.image_calls >= self.image_calls_max:
            return False
        self.calls += 1
        self.image_calls += int(with_image)
        return True

def step(controller, deliberator, obs, budget):
    if controller.stall_detected():                    # 结构事件
        if controller.suppress_and_replan():           # 第一层：零调用
            return controller.act(obs)
        if budget.request(with_image=True):            # 第二层：一次调用
            plan = deliberator.escape(obs)             # 失败返回 None
            if plan is not None:
                return controller.execute(plan)
    return controller.act(obs)                         # 单一回退路径

解读：（1）预算分两层：单次规模（轮数与图像数）与整回合总量，先便宜后昂贵的层级顺序把调用花在刀刃上。（2）第一层零调用恢复解决多数卡死，论文的 Always-Deliberate 反例说明无差别调用会同时抬高成本、压低成功率。（3）所有失败（解析失败、超时、预算耗尽）都走同一条回退到反应控制器的路径，系统永远有控制器。（4）看门狗与熔断属于同一原则：深思是可选增强，不是主控制回路。

常见误区

  • SkillNav 过滤口径混用：症状是复现的 HM3D v0.1 数字与论文对不上。根因是论文过滤了标注或导航图异常的部分 episode。修复：报告时注明过滤规则；与未过滤结果比较时先重算同一子集。
  • 忽略软上限的层级语义：症状是技能互相压制、行为不稳定。根因是把 αsoft 设成 αmax，缩放结果与抬底结果同分。修复：保持 αsoft = 7.0 低于 αmax = 10，让三层各占区间。
  • 把上下文长度结论外推：症状是换更大的注意力窗口却看不到收益。根因是受控实验显示 Transformer 策略不随上下文受益，且该结论来自浅骨干与特定训练配方。修复：先做上下文扫描；若走线性注意力，训练与测试上下文都要扫描（LA 受益于更长训练上下文）。
  • 把 3.40 个百分点当普遍增益：症状是在别的数据集或系统上复现不出深思收益。根因是该数字来自 HM3D v1 的 2000 条配对比较，且触发条件与记忆质量强相关。修复：先用贪心对照测自己的触发率与结构僵局占比，再决定是否引入深思层。
  • 深思无预算或失败无回退：症状是延迟飙升、偶发停摆。根因是每步调用或缺少降级路径。修复：采用事件触发、双层预算与单一回退路径；用调用次数与 SR 的联合曲线评估，避免 Always-Deliberate 式反例。

小结

  • 三条问题线：行为记忆放哪（SkillNav 写地图）、策略状态怎么更新（LANav 用线性注意力递归状态）、深思如何受限（ReAct 事件触发 + 预算 + 回退）。
  • SkillNav：三层算子软缩放（αsoft = 7.0）、抬底（锚点邻域到 10）、硬覆盖（阈值触发），固定组合满足三条稳定性性质；SPL 25.5 / 39.3 / 43.2，相对 MerNav 提高 6.0 / 2.4 / 5.6；提示通道治误检、精炼层治超步，分工在消融中解耦。
  • LANav：Transformer 策略不随上下文受益；WSLA 用 H = 4、E = 4 的子状态扩展与可学习加权读出，HM3D-OVON 平均 SR 36.4%，比 Transformer 高 6.3 个百分点，距离越远增益越大（15 m 以上 +7.68）；每动作约 0.048G FLOPs；真机 50 次试验成功率 82%。
  • 快慢 ReAct：反应式价值图常开，坐标锚定记忆（0.4 m 语义栅格、两次确认实例、逐层关键帧）支撑四类结构事件上的有界深思；HM3D v1 68.75% SR，贪心少 3.40 个百分点（95% 置信区间 [1.70, 5.05]），平均 5.00 次调用；每步深思的反例说明「何时深思」比「调用多少」更重要。
  • 共同设计原则：状态有界、证据准入（融合前验证、两次确认）、成本显式（token 或调用预算）、失败可回退（单一降级路径）。
