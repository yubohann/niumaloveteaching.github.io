第二篇 · 模块化：地图·探索·常识

第 032 讲｜L3MVN II：真机与零样本泛化

上一讲把 LLM 打分引入前沿选择，本讲检验这条路线能否离开训练分布：对照零样本与轻量前馈两条范式在 Gibson 与 HM3D 上的数字，追踪跨数据集迁移能力，解剖消融中每个模块的贡献，并把 Jackal 真机迁移的输入替代、风险与边界写成可执行的清单。语言先验的强度与感知质量的约束同时被量化。

  • 主题：零样本泛化 / 轻量前馈 / 消融读法 / Sim2Real 落差
  • 关键公式：SLLMfi = log p(Wfitj)（零样本句子打分）
  • 预计学时：65 分钟
  • 前置章节：第 031 讲 L3MVN I：LLM 给 frontier 打分

学习目标

  • 能复述 L3MVN 的两条范式与接口差异：零样本对每条前沿按目标类别构造查询句打分，前馈范式把句子嵌入送入轻量分类头。
  • 会读表：从 Gibson tiny 与 HM3D val 的 SR、SPL、DTG 计算条件效率，解释前馈相对零样本的增益来源与量级。
  • 会判断零样本泛化的边界：跨数据集迁移、分割质量依赖、先验失配与查询成本四类证据各自说明什么。
  • 会设计真机迁移清单：逐项列出仿真输入的替代方案、噪声来源与对策，并说明哪些结论还不能从单次演示外推。
  • 能识别两类口径风险：自建停止判据与挑战共识判据的差异，以及 Gibson 与 HM3D 数字并排的不可比性。

背景与动机

第 031 讲把 L3MVN 的机制拆开：语义地图给出前沿候选，LLM 用句子打分为每个前沿估计「附近出现目标类别的可能性」，代价效用分数负责兜底，局部策略用快速行进法把智能体带到选中的前沿。机制讲清了，性能证据还没有摆上桌。本讲接着回答三个问题：语言先验在未见场景里到底带来多少成功率与效率；不训练目标策略的前提下，两条范式各自付出什么代价；把同一套流程搬到真机上，哪些差距会消失、哪些会放大。

L3MVN（Yu 等，2023，IROS）给出的证据结构值得顺序阅读。其一，零样本范式不采集任何 ObjectNav 训练数据，只调用预训练语言模型对句子打分；前馈范式只在 HM3D 的房间物体共现数据上微调嵌入器与三层分类头，训练成本仍在轻量级。其二，两套结果分别在 Gibson 与 HM3D 上报告，前馈范式没有在 Gibson 上训练，因此 Gibson 一列同时包含跨数据集的迁移证据。其三，消融实验把语言模块、代价效用探索与分割质量各自的贡献分开；其四，真机实验用 ROS 与 Jackal 平台把系统跑通，讨论仿真与现实的差距。

本讲与第 031 讲的分工是：031 讲清 prompt 与打分机制，本讲读结果、算账、划边界。第二篇此后转向失败分析（第 033 讲）与多楼层推广（第 034 讲），失败解剖使用的正是本讲暴露出的感知瓶颈与先验失配。第五篇第 086 讲会把 L3MVN 真机证据放进更大的真机方法学语境里复核，本讲只做到迁移清单与证据强度评估。

核心原理

1. 两条范式与接口

先固定符号。设当前语义地图中提取的候选前沿集合为 F = {f1, …, fK}，目标类别集合为 LT（训练与评测共 6 类），每个前沿视野内识别到的物体词表记为 o1, …, ok。两条范式都先把每个前沿的内容压缩成句子，再用语言模型估计「该句子对目标类别的支持程度」。

零样本范式。对每个前沿 fi 与每个目标类别 tj 构造一条查询句：

Wfitj = "A frontier area containing o1, o2, …, ok, tj." 句子由前沿周围的检测物体与候选目标类别拼接；论文用 RoBERTa-large 的掩码语言模型打分

脚本用预训练语言模型给出句子的对数概率，作为该前沿对该目标类别的支持分数：

SLLMfi = log p(Wfitj) 给定目标类别时，对每个候选前沿计算一次；取分数最高的前沿作为长期目标

前馈范式。每个前沿只构造一条不含目标类别的描述句 Wfi = "This frontier contains o1, …, and ok."，语言模型输出句子嵌入 Emb(Wfi)，再送入一个三层网络 fθ，得到 6 维目标类别 logits，取目标类别那一维作为分数：

SLLMfi = [ fθ( Emb(Wfi) ) ]tj fθ 为三层映射；论文在 HM3D 上微调句子嵌入器并训练分类头

两种范式都依赖同一套预处理。论文先按物体与目标类别的条件分布 p(tj | oi) 计算条件熵，挑出熵最低、信息量最高的 15 类物体，限制句子词表只用这 15 类，以减少门窗这类到处出现的无信息词对打分的干扰；共现统计来自公开语义标注数据集中的 1000 个高分辨率三维扫描。最后，语言分数 SLLM 与第 031 讲的代价效用分数 SCU 按分数上界 B = [0.15, 0.3] 融合，语言分数明显高时直接采纳，落入区间时加权合成，明显低时退回几何探索。

3. 结果读法二：零样本泛化的证据结构

论文宣称的两条泛化能力需要拆开核对。第一条是不训练目标策略的零样本能力：零样本范式不接触任何 ObjectNav 训练 episode，在 HM3D 上仍拿到 0.504 的成功率，高于已训练的 SemExp（0.379）与地图随机采样（0.300）。第二条是跨数据集迁移：前馈范式的嵌入器与分类头只用 HM3D 的房间共现数据训练，评测却同时覆盖 Gibson；它在 Gibson 上得到 0.769，与零样本的 0.761 只差 0.8 个百分点。语言侧的表征在两个数据集之间基本保持稳定，迁移时不需要为 Gibson 重新训练打分模块。

两条证据都有附带条件。条件一，语言先验是类别级的统计常识，句子词表的构成直接决定它能看到什么：词表被限制在信息量最高的 15 类物体，目标是这 15 类之外的小众物体时，分数退化为噪声。条件二，语言分数要与代价效用分数融合使用，分数上界 B = [0.15, 0.3] 之外的两个区间分别对应直接采纳与完全回退，回退比例是场景相关的未公开量。条件三，分割质量是整条流水线的输入上限，消融给出量化证据。

消融在 HM3D 上进行，四行结果如下表。完整模型为 0.542 / 0.255 / 3.934；去掉语言模块、保留代价效用探索后为 0.518 / 0.244（成功率 −2.4 个百分点，SPL −0.011）；把代价效用探索替换为「选最近前沿」、保留语言模块后为 0.490 / 0.231（相对完整模型成功率 −5.2 个百分点）；把语义分割换成真值（GT Seg）后升到 0.664 / 0.364。

4. 结果读法三：真机实验的设置与观察

真机平台为 ROS 上的 Jackal 移动机器人，传感配置为 RealSense D455 相机加 Ouster 激光雷达。为压缩仿真与现实的距离，作者把相机高度与深度量程对齐仿真设置，并用激光雷达构建实时几何地图、改善定位精度；RGB-D、位置与目标类别送入模型后输出动作。论文报告客厅寻沙发的一次完整演示，展示长期目标如何引导探索，图 6 的快照推进到第 58 步。

作者对落差的讨论集中在三处。其一，深度图受光照与相机硬件质量影响，与仿真渲染存在系统性偏差。其二，激光雷达与里程计的测量精度低于仿真给出的无噪声位姿，物体与墙面周围出现噪声点。其三，模块化结构把策略输入放在场景地图层，不直接使用原始图像，多帧融合吸收了单帧噪声，因此迁移只需极少微调。这三条与第 024 讲 SemExp 真机经验同源：显式地图是天然的噪声缓冲器，代价是地图误差会累积为决策输入。

证据强度要如实标注。论文没有公布真机成功率、路径长度或失败统计，实验覆盖单一平台与展示性场景，激光雷达承担了仿真中由 GPS+Compass 免费提供的定位功能。该实验证明流程可运行，不能作为真机泛化能力的量化结论；第五篇第 086 讲会把这条证据放在真机方法学框架里再评一次。

5. 数值算例（Python 实算）

算例一，范式差异与条件效率。把上表数字代入，前馈与零样本在 HM3D 的成功率差为 0.038、SPL 差为 0.024、DTG 差为 −0.493 m；条件效率按 SPL / SR 折算，前馈为 0.255 / 0.542 = 0.4705，零样本为 0.231 / 0.504 = 0.4583。同一组量在 Gibson 上为 0.5046（前馈）与 0.4954（零样本）。前馈在两个维度同时提高，说明增益来自更准的前沿排序，排除了牺牲效率换成功率的解释。

算例二，查询成本。零样本范式对每条前沿、每个目标类别各构造一条查询句，假设每轮重规划可见 10 条前沿、目标 6 类，则每轮需要 60 次语言模型前向；前馈范式每条前沿只编码一条描述句，共 10 次嵌入加一次分类头前向。按最坏情况计，前馈的语言侧调用次数为零样本的 1/6。在真机上，这直接决定重规划频率能否跟上机器人移动速度；工程实现可以把句子打分离线批处理，并依靠前沿集合的变化频率触发重算。

算例三，口径折算。论文任务定义处把停止成功写作「目标距离小于 0.1 m」，而 Habitat ObjectNav 共识口径为 1 m 加 oracle 可见性（第 001 讲）。两个判据对应的距离壳面积比为 (1.0 / 0.1)² = 100。同一段轨迹在两套判据下的成败可以完全不同，任何把 L3MVN 数字与挑战榜数字并排的行为都需要先统一这一项；本讲所有表格只做论文内部比较。

6. 适用边界与失效模式

  • 超出 15 类信息词的物体：语言分数失去区分度，前沿选择退化为几何探索。修复路线是扩充词表或改用开放词汇嵌入，第 061 讲之后的方法处理这一问题。
  • 分割漏检：目标附近物体未被识别时，句子里没有相关词，分数无法反映真实情况；真值分割消融显示上限抬高 12.2 个百分点。修复路线是提高分割召回、增加多帧融合或引入贝叶斯更新（第 036 讲 IPPON 的滤波方案）。
  • 房间功能错配：语言先验来自共现统计，把物体放在非常规房间（浴室里的沙发）会持续压低对应前沿的分数。第 030 讲 ESC 的软常识约束与第 069 讲场景图方法从另一侧处理这类冲突。
  • 大规模开放布局：HM3D 上 DTG 4.427 m 明显高于 Gibson 的 1.101 m，说明搜索范围扩大后，语言先验的覆盖有限，前馈分类头也只缩小了 0.493 m。
  • 真机定位替代：仿真位姿无噪声，真机由激光雷达与里程计提供，误差分布不同；定位漂移会把语义地图的几何结构扭曲，进而改变前沿的连通关系。
  • 证据外推边界：单平台、单场景演示不支持「任意住宅可迁移」的结论；迁移能力需要多样本真机统计（第 096 讲方法学）。

实现思路与设计

本讲的设计产出是两张工程表：一张把仿真输入逐项映射到真机替代，另一张固定可复现的参数与口径。任何真机迁移报告都应以第一张表为骨架，逐项标注「对齐、替代、放弃」三种处置。

设计决策：以地图作为迁移接口

3. 与第 031 讲的差异点

031 讲解决「怎么用 LLM 打分」，本讲解决「打分系统的证据强度」：引入前馈训练头作为对照臂，把零样本泛化拆成不训练策略与跨数据集迁移两条，增加消融与真机清单。评审实验时，031 的检查表关注 prompt 与分数融合，本讲的检查表追加四项：是否在同一判据下比较、是否报告条件效率、是否给出分割质量、是否披露真机证据的样本量。

关键代码与解读

三段代码对应两条范式与一次融合：零样本打分、前馈分类头、三段式前沿选择。接口按论文描述做教学化命名，模型调用以伪函数表示。

片段 1：零样本句子打分与前沿选择

def zero_shot_select(frontier_objects, target_words, informative15, t_idx, mlm_logprob):
    """零样本：每条前沿对每个目标类别各构造一条查询句并打分。"""
    best_frontier, best_score = -1, float("-inf")
    for fi, objs in enumerate(frontier_objects):
        kept = [o for o in objs if o in informative15]   # 只用信息量高的词，抑制门窗干扰
        kept = kept[:8]                                  # 句子过长会稀释打分信号的稳定性
        sent = "A frontier area containing " + ", ".join(kept) + ", " + target_words[t_idx] + "."
        score = mlm_logprob(sent)                        # RoBERTa-large 给出句子对数概率
        if score > best_score:                           # 只在目标类别上比较分数
            best_frontier, best_score = fi, score
    return best_frontier

解读：（1）每个前沿对目标类别各构造一句话，目标词出现在句尾，句子概率衡量「该物体组合与原目标共现的合理性」；（2）信息词表把无信息物体挡在句外，否则「door、window」这类词会在所有前沿出现，分数被压平；（3）句子长度截断到 8 个词是工程折中，论文未给出固定上限，复现时应扫描该参数；（4）返回的是前沿下标，调用方再把它交给局部规划器。

片段 2：前馈分类头

import torch

class FrontierHead(torch.nn.Module):
    """三层映射：句子嵌入到 6 个目标类别的 logits。"""
    def __init__(self, d_model=1024, d_hidden=512, n_targets=6):
        super().__init__()
        self.net = torch.nn.Sequential(
            torch.nn.Linear(d_model, d_hidden), torch.nn.ReLU(),
            torch.nn.Linear(d_hidden, d_hidden), torch.nn.ReLU(),
            torch.nn.Linear(d_hidden, n_targets))

    def forward(self, emb):
        return self.net(emb)                             # |F| x n_targets

def feed_forward_select(embedder, head, frontier_objects, t_idx):
    """前馈：每条前沿一条描述句，目标类别那一列取最大。"""
    sents = ["This frontier contains " + ", ".join(objs) + "." for objs in frontier_objects]
    with torch.no_grad():                               # 推理不更新参数；训练时按论文设定微调嵌入器
        emb = embedder(sents)
        logits = head(emb)
    return int(logits[:, t_idx].argmax())

解读：（1）嵌入器与分类头构成轻量训练路径，训练数据由房间共现自动构造，成本远低于目标策略学习；（2）每条前沿只编码一次，6 个类别共享同一嵌入，查询成本为零样本的 1/6；（3）训练与评测都在 HM3D 侧进行，Gibson 评测因此构成跨数据集迁移测试；（4）argmax 在实际系统中应加分数上界判断，低置信时退回几何探索。

片段 3：三段式前沿选择

B_LO, B_HI = 0.15, 0.30            # 论文给出的语言分数上界区间

def choose_frontier(s_llm, s_cu, blend=0.5):
    """高置信用语言分数，中置信与探索分数合成，低置信完全回退。"""
    hi = max(s_llm)
    if hi > B_HI:                                        # 语言分数显著高：直接采纳
        return int(max(range(len(s_llm)), key=lambda i: s_llm[i]))
    if hi >= B_LO:                                       # 落入区间：与代价效用分数合成
        fused = [blend * a + (1.0 - blend) * b for a, b in zip(s_llm, s_cu)]
        return int(max(range(len(fused)), key=lambda i: fused[i]))
    return int(max(range(len(s_cu)), key=lambda i: s_cu[i]))  # 低置信：退回几何探索

解读：（1）三段式把「语言先验失效」编码成显式分支，避免在低置信场景硬用语言分数；（2）论文未公布合成公式的具体权重，blend 取 0.5 是教学示例，复现时应做权重扫描并报告回退比例；（3）「最近前沿」也能作为分支的极端版本，消融显示这一替换会让 SR 从 0.542 降到 0.490；（4）三个分支都应写入日志，便于失败分析统计语言模块的实际参与率。

常见误区

  • 把 0.1 m 判据与 1 m 判据混用：症状是同一轨迹在两套判据下成败翻转，复现数字与论文差距明显。根因是两套停止判据的距离壳面积相差 100 倍。修复：复现前先读任务定义与判定函数，报告注明来源口径，跨论文比较前统一判据。
  • Gibson 与 HM3D 数字并排：症状是得出「方法在 A 上强于 B 上」的错误排序。根因是两套数据集的场景来源、划分与规模不同（25/5 对 75/20），任务类别相同不构成可比条件。修复：同数据集同划分比较，表格逐列标注数据集与划分。
  • 忽视分割质量：症状是语义地图里目标类别通道破碎，前沿打分抖变。根因是分割漏检沿流水线上传，真值分割消融把 SR 抬高 12.2 个百分点。修复：先量化分割召回，再决定是否加多帧融合或更换模型；把分割质量写进结果报告。
  • 低置信时硬用语言分数：症状是机器人在没有语义线索的区域反复选择同一条前沿。根因是缺少 B 区间回退逻辑，随机性来自打分噪声。修复：实现三段式选择，记录回退触发的 episode 比例，并检查回退时探索分数是否正常。
  • 真机照搬仿真深度与位姿：症状是点云噪声导致障碍通道膨胀、路径变窄。根因是光照、硬件与定位误差未对齐。修复：对齐相机高度与量程，用激光雷达构建几何地图并改善定位，把地图质量检查放在策略评审之前。

小结

  • L3MVN 有两条范式：零样本按「前沿物体加目标类别」构造查询句打分，前馈把句子嵌入送入三层分类头；后者在 HM3D 上成功率 0.542 对 0.504（+3.8 个百分点），SPL +10.39%，语言调用次数约为前者的 1/6。
  • 跨数据集迁移证据：只在 HM3D 训练的前馈模块在 Gibson 上得到 0.769，与零样本 0.761 基本持平，说明语言侧表征可迁移，目标数据集无需承担训练开销。
  • 消融结论：语言模块贡献 2.4 个百分点，代价效用探索贡献 5.2 个百分点（两项为独立单模块消融，不可相加），真值分割把成功率抬高 12.2 个百分点，感知质量是整条流水线的上限。
  • 真机证据：Jackal 加 D455 与激光雷达的演示证明流程可运行，模块化结构以地图吸收传感器噪声；论文未公布真机统计，迁移能力尚不能量化外推。
  • 口径纪律：论文自述停止判据为 0.1 m，与挑战共识的 1 m 加可见性不同，距离壳面积差 100 倍；所有跨论文数字必须先统一判据与数据集划分。
  • 下一讲进入失败模式解剖：用 PIRLNav 对 592 条失败 episode 的人工标注与 IPPON 的消融证据，建立卡滞、绕圈、误停的分类学与修复优先序。
