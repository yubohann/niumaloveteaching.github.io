第二篇 · 模块化：地图·探索·常识

第 027 讲｜PONI I：势函数

PONI（Ramakrishnan 等，CVPR 2022）把「去哪找物体」当作纯感知问题，在语义地图的地图前沿上定义面积与物体两类势函数，用被动收集的语义地图做监督学习，全程不做环境交互。本讲推导两类势函数的定义与监督构造，拆解势函数网络与损失，并给出全部数值算例。

  • 主题：势函数 / 地图前沿 / 监督学习 / 语义地图
  • 关键公式：Ut = αUat + (1 − α)Uot
  • 预计学时：65 分钟
  • 上一讲：第 026 讲 PointGoal 智能体复用

学习目标

  • 能把「去哪找未见物体」写成在语义地图前沿集合上的目标位置选择问题，并复述「只在边缘打分不损失可达性」的论证。
  • 能推导面积势函数与物体势函数的定义、取值范围与归一化口径，解释两类信号各自补上的能力缺口。
  • 能构造训练三元组（部分语义图、面积势函数、物体势函数）：随机最短路、方形掩码、连通分量关联、测地距离场。
  • 能描述势函数网络（UNet 编码器加双解码器）与前沿像素上的均方误差损失，说明 α、dmax、采样频率、类别通道数的取值依据。
  • 会算：势函数衰减、组合平局、连通分量归一化、掩码覆盖面积与监督数据量。

背景与动机

第 023 讲的 SemExp 用强化学习训练「目标导向探索」：智能体每次与仿真交互，产生轨迹，用奖励塑形引导它把长期目标点选向目标可能所在区域。这套范式有效，代价是交互量：论文记录 SemExp 依靠 8 块 GPU 量级、多天训练才能收敛。第 026 讲的 MOPA 把「怎么去」交给复用的 PointNav 策略，但「去哪找」仍然由启发式探索承担，效果的上限受探索策略限制。

PONI（Potential functions for ObjectGoal Navigation with Interaction-free learning，Ramakrishnan 等，CVPR 2022；arXiv:2201.10029v2）提出一个尖锐的观察：对未见物体问「去哪找」，本质上是感知问题。在物体还不可见时，判断「哪个方向的未探索区域更可能藏着洗手间」，依据的是地图上已有的几何布局与语义线索：走廊通向哪里、已见到的水槽与马桶在哪个房间。这些线索都写在语义地图里，可以用带标注的三维场景离线生成监督信号，不需要智能体迈出一步。

本讲解决四个问题：势函数怎么定义；监督标签从哪里来；网络预测量是什么；怎么组合与采样。第 028 讲评估这条路线省下多少算力、在什么条件下失效。术语从本讲冻结：地图前沿、面积势函数、物体势函数、部分语义图、采样频率。

核心原理

1. 问题定义：在前沿上选「去哪找」

智能体在时刻 t 维护一张自顶向下的部分语义图（partial semantic map）mt，形状为 (N + 2) × M × M：两个通道记录障碍与已探索自由空间，其余 N 个通道记录各类物体的位置（第 023 讲的建图流程）。未探索区域的信息在图中为空。地图前沿（frontier）定义为已探索自由空间与未探索区域之间的边界像素集合 Ft，这套定义与 Yamauchi（1997）的经典前沿探索一致。

「去哪找」被写成一个打分与取最大的问题：给每个前沿位置 x ∈ Ft 打一个分数 Ut(x) ∈ [0, 1]，然后

gt = argmax Ut(x)，x ∈ Ft gt 为长期目标点，交给局部导航策略或规划器；分数只在时刻 t 的地图上前沿处计算

只在前沿打分有两个依据。第一是可达性论证：通往任何未探索区域的路径必然穿过前沿，因为前沿按定义隔开已探索与未探索区域，路径从已探索一侧出发，第一次进入未知区域的位置必在前沿上；因此只在边缘打分不会丢掉任何可探索方向。第二是经验依据：消融实验显示，只在边缘预测略优于在所有地图位置上预测（成功率 73.6% 对 72.7%），边缘处的预测也让推理更聚焦。注意这里的「前沿」与「研究前沿」无关，全部指地图几何边界。

2. 面积势函数：往哪里探索

面积势函数（area potential function）回答「哪个边缘背后有更多的未知自由空间」。定义从完整地图上的解析计算开始。设完整语义图中，部分地图里尚未探索、而完整图中属于自由空间的像素集合为 Ufree，用图像连通算法把它分成连通分量（connected component）C = {c1, …, cn}。对每个前沿 f，定义其关联分量集合：

A(f) = { c ∈ C : ∃ q ∈ c, ∃ p ∈ f 使 q 与 p 八邻接 } 八邻接指上下左右与四个对角方向相邻；即分量与前沿在像素层面接触

面积势函数为该前沿关联分量的面积之和，按完整图自由空间总面积归一：

Uat(f) = ( Σc ∈ A(f) |c| ) / |Ffree| |c| 为分量像素数；|Ffree| 为完整图自由空间总像素数；MP3D 地图很大，论文改用固定常数归一

取值落在 [0, 1]，通往大未探索区域的边缘分值高。它的作用在 episode 早期最关键：语义图几乎为空时，目标物体势函数没有可用线索，智能体靠面积势函数尽快扩大覆盖范围、收集信息。这对应强化学习里的探索偏置，区别是这里不依赖奖励，靠离线标签直接给出。

3. 物体势函数：朝哪边靠近目标

物体势函数（object potential function）回答「哪个边缘离目标类实例更近」。对目标类别 o 与前沿位置 x：

Uot(o, x) = max( 1 − dg(o, x) / dmax, 0 ) dg(o, x) 为 x 到最近 o 类实例 1 m 成功区边界的测地距离；dmax 为衰减尺度，验证集选定；超过 dmax 归零

测地距离（geodesic distance）在完整地图的自由空间上，用最短路径规划求得：从目标侧 1 m 成功区出发做反向传播，得到每个位置的距离场。这与 A* 搜索里的启发式函数同源：越靠近目标，潜在值越高。关键区别在于目标实例未知：训练标签用完整地图解析计算，推理时网络只能看到部分地图，必须从几何与语义线索中预测距离场，无法直接测量。dmax 控制衰减速度：取值太小，远处边缘一律为零，信号失去区分度；取值太大，近处与远处的差异被压平。论文在主文说明该常数由验证集选择。

物体势函数与面积势函数的互补性构成 PONI 的核心机制。第 023 讲的常识先验（物体共现统计）是显式的条件概率表；这里把先验压进一个卷积网络的预测里，输入是当前地图的几何布局与已见物体，输出是「哪条边缘更值得走」。两类信号都归一到 [0, 1]，尺度一致后可以线性组合。

把两类势函数线性组合，得到总势函数与目标采样规则：

Ut = α Uat + (1 − α) Uot，  α = 0.5 α 由验证集选定；组合前把非前沿位置置零；保留未探索格的网络预测为零散边界留出柔性

采样时取 argmax。论文还实验了加入行动代价的扩展形式 Ut = αUa + βUo + γUd（Ud 为随距离线性衰减的代价势），网格搜索后结果略降（MP3D 验证集成功率 31.8% 降到 30.3%）。解释是智能体倾向把一条边缘探索充分再换方向，优先选最优边缘、忽略远近的做法在实践中可行。

4. 势函数网络：结构、输入与输出

网络是一个编码器加双解码器的卷积结构：

  • 地图编码器 E：UNet 风格，4 个下采样卷积块，输入 (N + 2) × M × M 的部分语义图，输出空间特征 et = E(mt)。
  • 面积解码器 Da：4 个上采样卷积块，末端 sigmoid，输出 1 通道的 Ûat。
  • 物体解码器 Do：同样结构，输出 N 通道，第 n 个通道对应第 n 类物体的势函数；使用目标类别 o 时取对应通道。

两个解码器共享编码器特征。物体解码器输出整张类别表，覆盖所有类别，原因是分类头表达力更强、训练信号更密集：同一张地图同时监督「椅子在哪一片」「床边在哪一片」，共享的几何编码因此学到更通用的空间布局表征。推理时按目标类别取通道，没有额外计算。

损失是两类势函数在前沿像素上的像素级均方误差之和：

La = (1 / |F|) Σx ∈ F ‖ Ûa(x) − Ua(x) ‖2 只在前沿像素集 F 上求平均，非前沿位置的预测不参与损失
Lc = (1 / (|F| N)) Σx ∈ F Σn = 1N ‖ Ûo(x, n) − Uo(x, n) ‖2，  L = La + Lc 物体项在 N 个类别上取平均，避免类别数变化改变总损失量级

把损失限制在前沿上使训练目标与推理用法完全一致：网络只需要在前沿处预测准，其他位置由掩码规则置零。若改成全图回归，绝大部分像素的标签为零或背景，梯度被无效位置稀释。

5. 监督数据构造：从三维标注到训练三元组

训练集是一条条 (mp, Ua, Uo) 三元组，其中 mp 为部分语义图，两个势函数为解析标签。构造流程分五步：

  1. 完整图：把三维语义点云按正交投影压成每层楼一张二维语义图（沿用 Semantic MapNet 的流程）；用 DBScan 沿竖直方向聚类可通行点，自动发现楼层数与范围，逐层建图。Gibson 图最多 15 类，其中 6 类为导航目标；MP3D 图 21 类，全部是导航目标。
  2. 数据增强：对完整图施加随机平移与旋转，等价于在场景中换起点与朝向。
  3. 采样部分图：在完整图自由空间里随机取两个位置，计算它们的最短路径；沿路径每个位置把 3 m × 3 m 的方形窗口标记为已探索；把完整图的信息拷贝到已探索区域，其余位置留空，得到部分图 mp。备选方案是在路径上揭示半径 3 m、视场 90° 的锥形区域，效果与方形相当（MP3D 验证集 31.9% 对 31.8%）。
  4. 解析标签：在完整图上计算面积与物体势函数。距离场由目标侧的测地传播得到，面积由连通分量关联得到。
  5. 规模固定：每个数据集预计算 40 万条训练样例与 1 千条验证样例，训练 3 个 epoch，Adam 优化器，学习率 0.001，2 个 epoch 后乘 0.1 衰减到 0.0001。

「预计算样例」是这条路线省算力的关键：同一张完整图可以生成大量不同起点与朝向的部分图，代价只是磁盘空间。第 028 讲会看到，监督通过量约 120 万次，与交互式强化学习的 25 亿帧量级相差三个数量级。

7. 数值算例 II：归一化、掩码与数据量

面积势函数的归一化影响 α 的实际效果。设完整图自由空间 100 m²，两个未探索分量面积 30 m² 与 15 m²，分别关联两条前沿：Ua 为 0.30 与 0.15。若场景较小、自由空间只有 60 m²，同样两个分量得到 0.50 与 0.25，整体抬高，α = 0.5 时面积项的绝对影响放大。论文对 MP3D 用固定常数归一，就是因为场景面积大、逐图归一后数值过小，区分度不足；这种「按数据集切换归一化口径」的做法必须记录在实验配置里，否则跨数据集数字不可比。

3 m × 3 m 方形掩码沿最短路径揭示的覆盖面积可解析估算：长度 L 的路径，方形窗扫过的区域等于线段的 3 m 膨胀，面积约为 3(L + 3) = 3L + 9（单位 m²）。L = 5、10、20 m 分别得到 24、39、69 m²；在 100 m² 的楼层上对应 24%、39%、69%。对比锥形区域：半径 3 m、90° 视场的单帧面积 π × 3² × 90 / 360 = 7.07 m²，沿路径叠起来与方形窗量级相当，这解释了两种掩码效果接近的实验结果。

最后估算监督数据量。以 5 cm 一格的语义图口径（第 023 讲 SemExp 系列的常用分辨率）与 100 m² 自由空间为例：单张地图 100 / 0.05² = 40000 个格点，23 个通道（21 类加障碍与已探索）用 float32 存储约 3.68 MB；40 万条训练样例约合 1.5 TB。这个量级说明预计算样例是有意用磁盘换训练效率，把仿真交互从训练循环里彻底移除；若改用 0.1 m 一格，单元数降为四分之一，存储约 0.4 TB，但测地距离场的空间精度同步下降。

实现思路与设计

PONI 的在线系统由四个组件串成，接口如下表。前三个组件每步更新，长期目标按采样频率 T 更新：

设计上与 SemExp（第 023 讲）的差异点有三处：训练信号从奖励换成解析标签，不再需要环境交互；长期目标采样频率从固定 25 步改为每步，论文发现 T = 1 对 PONI 最优，而直接回归式基线（Predict-θ 与 Predict-xy）更适合 T = 25；局部策略沿用快速行进法（FMM）加确定性动作，与 MOPA 复用 PointNav 的路线形成对照。与非交互基线相比，PONI 的优势落在「去哪找」这一环，导航本身沿用既有方案：与直接回归目标方向或位置的基线同训练数据、同编码器，PONI 在 Gibson 验证集上一项高 3.7 个百分点（成功率 73.6% 对 69.9%）。

设计决策：标签解析算，预测学起来

训练标签用完整地图解析计算（特权信息），推理只允许使用部分地图。两条信息通路必须严格分开：输入侧混入完整图就是信息泄漏，训练损失下降但部署失效。工程上把「完整图只在离线数据生成启用」写成硬约束，推理管线里不应出现完整图变量。

设计决策：双势函数分离探索与利用

面积项负责启动探索，物体项负责语义搜索，消融显示两项都有贡献：只用物体项，Gibson 成功率 58.8%；补上边缘限制与面积项后升到 73.6%（第 028 讲展开）。把探索与利用显式拆成两项、再用验证集选权重，比让单一网络端到端地把两件事纠缠起来更可控。

离线数据的两个前提

其一，必须有带语义标注的三维场景，标签质量直接决定监督上限；其二，掩码生成假设「路径附近的方形窗口即已探索」，与真实视锥存在差异，论文验证两种掩码效果相当，但换到视场更窄或建图更慢的平台时需要重新评估。

import numpy as np

def object_potential(free_mask, goal_zone, d_max_m, cell_m):
    """从目标成功区反向 BFS 得到测地距离场，再截断成 [0, 1] 势函数。"""
    dist = np.full(free_mask.shape, np.inf)
    queue = deque()
    for cx, cy in goal_zone:              # goal_zone：1 m 成功区内的自由格
        dist[cx, cy] = 0.0
        queue.append((cx, cy))
    h, w = free_mask.shape
    while len(queue) > 0:
        x, y = queue.popleft()
        for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nx, ny = x + dx, y + dy
            if nx < 0 or nx >= h or ny < 0 or ny >= w:
                continue                   # 越界格跳过
            if not free_mask[nx, ny] or np.isfinite(dist[nx, ny]):
                continue                   # 障碍格与已访问格跳过
            dist[nx, ny] = dist[x, y] + cell_m
            queue.append((nx, ny))
    return np.maximum(1.0 - dist / d_max_m, 0.0)

解读：（1）从目标向全图传播，避免为每个前沿单独搜索，一次 BFS 得到所有位置的标签，与 A* 反向距离场同构。（2）队列初始化为整个 1 m 成功区，不取单个点，与 001 讲的成功判据衔接：只要落在成功区内，势函数都达到峰值 1。（3）np.inf 表示不可达，最终被 max 截断为 0，障碍物内部没有标签像素也无影响。（4）真实实现可用快速行进法得到更平滑的距离场；论文的局部策略同样使用快速行进法，训练标签用最短路传播即可。

片段 2：部分图与训练三元组

def build_training_tuple(complete, free_mask, rng, patch_m=3.0, cell_m=0.05):
    """由完整语义图生成 (partial, Ua, Uo)：模拟一次随机探索的可见范围。"""
    start, end = sample_free_pair(free_mask, rng)       # 随机两个自由格
    path = shortest_path_on(free_mask, start, end)      # 经典最短路
    half = int(round(patch_m / (2.0 * cell_m)))         # 3 m 方窗的半边长
    seen = np.zeros_like(free_mask)
    for x, y in path:
        x0, x1 = max(0, x - half), min(seen.shape[0], x + half + 1)
        y0, y1 = max(0, y - half), min(seen.shape[1], y + half + 1)
        seen[x0:x1, y0:y1] = 1                          # 方窗内记为已探索
    partial = complete * seen[:, :, None]               # 未探索位置整通道清零
    frontier = find_frontier(seen, free_mask)           # 已探索与未知的边界
    ua = area_potential(complete, seen, frontier)       # 面积势函数标签
    uo = object_channels(complete, frontier)            # 每类一份物体势函数标签
    return partial, ua, uo, frontier

解读：（1）随机起终点加最短路径模拟智能体实际走过的走廊与房间，比随机撒点更接近测试分布；论文对完整图另加随机平移旋转做增强。（2）方形窗口按格数取整，窗口参数在数据生成阶段固定，训练与部署的建图分辨率必须一致。（3）partial 用乘法清零，语义图三个部分（障碍、已探索、物体）同步被屏蔽，网络无法从输入侧推断未知区域内容。（4）标签只在完整图上计算，frontier 同时作为损失掩码返回；生产实现要把四个张量一起序列化，避免训练时重新计算。

片段 3：前沿掩码损失

def pf_loss(pred_area, pred_obj, ua, uo, frontier_mask):
    """前沿像素上的均方误差；面积项单通道，物体项在 N 个类别上取平均。"""
    m = frontier_mask.astype(np.float32)
    n = float(m.sum()) + 1e-6                            # 前沿像素计数，防零除
    err_a = ((pred_area - ua) ** 2) * m
    la = float(err_a.sum()) / n
    err_o = ((pred_obj - uo) ** 2) * m[:, :, None]
    lc = float(err_o.sum()) / (n * pred_obj.shape[2])    # 对 N 类取平均
    return la + lc, la, lc

解读：（1）掩码乘在平方误差上，非前沿像素梯度为零；实现时也可用索引收集前沿像素，内存更省。（2）物体项除以类别数 N，使损失量级不随类别数变化；MP3D 的 N = 21，Gibson 的标签最多 15 类、6 类为导航目标。（3）返回分项损失便于诊断：面积项不下降通常说明归一化或边缘定义有问题，物体项不下降指向类别通道或距离场标签错误。（4）论文使用 PyTorch 训练 3 个 epoch；损失之外没有奖励、没有折扣因子，监督式训练循环与常规分割任务相同。

常见误区

  • 信息泄漏：症状是训练损失极低、部署后智能体朝未探索区域乱走。根因是输入侧混入了完整图或由完整图计算的通道。修复：数据生成与推理分两条管线，推理时断言输入只含已探索区域；用「把完整图与部分图差异区域涂随机值」的扰动测试检查泄漏。
  • 前沿定义不一致：症状是同一模型在不同代码路径上表现差异大。根因是训练与推理的边界提取参数不同（障碍膨胀、已探索阈值、是否含对角格）。修复：把 find_frontier 抽成共享函数，训练与推理调用同一实现，并对边界样例写单元测试。
  • 归一化口径混用：症状是跨数据集迁移时面积项权重明显失衡（小场景里面积项压过物体项）。根因是 Gibson 用逐图自由空间归一、MP3D 用固定常数，两套口径没有随模型一起记录。修复：把归一化方式写入数据卡与配置，跨数据集比较时先做尺度校准。
  • dmax 失配：症状是物体势函数在整张图上近似全零或近似全同。根因是衰减尺度与场景尺寸量级不匹配：小于最短典型距离时远处无信号，大于场景尺度时区分度消失。修复：统计验证集中前沿到目标距离的分位数，把 dmax 设在六成到九成分位之间，用成功率与 DTS 联合确认。
  • argmax 平局与零势兜底：症状是智能体在两条同样差的边缘之间来回切换，或停在地图中央不动；特定类别成功率异常低也可能是类别通道索引在数据生成与推理之间错位。根因是组合分数并列或全部接近零，argmax 不稳定；修复：加入确定性的平局规则与最小探索分数，低于阈值时退回最大面积边缘，并把类别表序列化进权重文件、逐类跑固定验证 episode。

    U = 0.75、0.50、0.25、0.00、0.00。dmax 越大，斜率 1 / dmax 越小，相邻距离的分数差按比例缩小。
  2. 实现面积势函数的连通分量关联：给定已探索掩码与自由空间掩码，用八邻接把未探索自由格分组，说明如何判断某个分量与某条前沿接触；讨论两个分量只在对角处相接时是否应合并。★
    提示
    八邻接接触即关联；对角相接的两个分量在连通性上属于八连通，合并与否取决于障碍表示约定，必须与 find_frontier 使用同一约定。
  3. 复算训练配置：40 万条样例、3 个 epoch 对应多少次监督通过；保持样例数不变，把地图分辨率从 0.05 m 改成 0.10 m，估算单条样例的存储与计算量变化，并预测 Uo 的精度变化方向。★★

    提示
    ① 预测排序：全组合 73.6 大于「物体加面积」72.7 大于「物体加边缘」65.1 大于「仅物体」58.8；面积项负责探索启动，边缘限制聚焦预测位置，两项贡献可加。② 逐层图里没有楼梯的连通表示，前沿可达性判断失效；需要楼层编号、跨层导航图与专门的楼梯策略，这部分在 034 讲的 MFNP 展开。

小结

  • PONI 把「去哪找」写成在语义地图前沿上取势函数最大的问题；通往未知区域的路径必然穿过前沿，边缘打分不损失可达性。
  • 面积势函数按关联未探索分量的面积归一，负责启动探索；物体势函数按到目标成功区的测地距离线性衰减，负责语义搜索；两者归一到 [0, 1] 后以 α = 0.5 线性组合。
  • 监督标签离线解析计算：随机最短路加 3 m 方形掩码生成部分图，连通分量给面积标签，反向测地传播给物体标签；每个数据集 40 万条样例，训练 3 个 epoch。
  • 网络为共享 UNet 编码器加两个解码器，物体解码器输出 N 个类别通道；损失为前沿像素上的均方误差，训练目标与推理用法一致。
  • 验证集上 PONI 成功率 73.6%（Gibson）、31.8%（MP3D），优于同建图与同局部策略的 SemExp，也优于直接回归方向或位置的监督基线。
