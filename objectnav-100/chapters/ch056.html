第三篇 · 端到端与配方

第 056 讲｜定位/执行噪声鲁棒性

第 055 讲把无地图端到端策略的适用边界落在「训练分布内的高效探索」上，真机部署还有一个绕不开的问题：里程计会漂移，执行器会失准。HM3D-OVON 基准（Yokoyama 等 2024，Open-Vocabulary ObjectNav）在评测中注入两类噪声，给出了一组少见的受控对比：依赖地图的 VLFM 在噪声下成功率最多降 6.4 个百分点（论文正文概括为 6.1），而只用 RGB 历史的 DAgRL+OD 成功率保留在 99.2% 以上。本讲推导累积误差的随机游走律，复算退化与保留率，并给出可复现的噪声注入与配对评测协议。

  • 主题：噪声注入 / 里程计漂移 / 鲁棒性评测 / 配对比较
  • 关键公式：σN = a√(N/3)，a 为每步均匀噪声半宽
  • 预计学时：80 分钟
  • 前置章节：第 055 讲（无地图无模块的适用边界）

学习目标

  • 会算：给定每步均匀噪声半宽 a，推导 N 步后位置与航向误差的标准差，说明随机游走按 √N 增长；能算出 N 取 100、250、500 时的数值并与蒙特卡洛结果对照。
  • 会实现：分别实现执行噪声（作用于真实位姿）与里程计噪声（作用于策略输入）两类注入封装，用固定种子与配对 episode 列表评测。
  • 会读：HM3D-OVON 表 VI 的退化与保留率，区分成功率保留与路径效率损失，解释为何 DAgRL+OD 的成功率几乎不变而 SPL 仍降约 2.5 至 3.0 个百分点。
  • 会判断：方法结构与噪声敏感性的关系。地图类方案把观测按里程计投影到全局坐标，噪声直接污染地图；只用视觉历史的策略隐式做相对定位，对相同噪声更稳。
  • 会设计：以执行噪声与传感器噪声为两因子的 2×2 解耦实验，写明样本量、主指标与判定标准。

背景与动机

第 055 讲分析了纯反应式策略的边界，其中一条是感知与运动都在训练分布内时性能才可复现。真机把这个前提打破：轮式底盘靠编码器推位置，打滑、地面材质与负载变化都会积累误差；云台转角与前进距离也有标定偏差。训练时这些误差近似为零，部署时却持续存在，评测若只在无噪声仿真里做，排名可能给出误导性结论。

HM3D-OVON（Yokoyama 等 2024）的设计把噪声当作一等评测条件：同一批检查点，分别在干净条件与噪声条件下跑同一批 episode，噪声条件包含执行扰动（每次动作后对机器人位置与朝向加高斯扰动）与里程计传感器扰动（每步对策略收到的位姿加均匀噪声，位置半宽 7 mm，航向半宽 2°）。两条基线恰好代表两种结构：VLFM 是模块化地图方案，靠里程计把深度观测投影到俯视占据图；DAgRL+OD 是端到端方案，探索阶段只吃连续 RGB 历史，检测到目标后交给 PointGoal 策略走最后一程。

结果是结构性的：噪声下 VLFM 成功率平均降 5.47 个百分点，SPL 平均降 4.47 个百分点；DAgRL+OD 成功率平均只降 0.20 个百分点，SPL 降 2.70 个百分点。本讲的作用是把这组数字拆开：噪声如何在时间上累积、如何进入两条流水线的不同环节、如何用最小实验把两个噪声源分开。完成本讲后，第 057 讲转向训练数据配比，第 058 讲再把仿真与真机的落差做系统分解。

核心原理

1. 任务与两条基线的信息通路

评测沿用 HM3D-OVON 的 ObjectNav 口径：智能体匹配 Stretch 构型（身高 1.41 m，底盘半径 17 cm，RGB-D 相机高 1.31 m，分辨率 360×640），动作为前进 0.25 m、左转与右转各 30°、抬头与低头各 30°、停止，500 步内停止位置距目标实例不超过 1 m 判成功。目标类别由自由文本给出，验证集分三档：已见类别（Val Seen，79 类）、同义类别（Val Seen Synonyms，50 类，与训练类别的句向量余弦相似度落在 [0.68, 0.96]）、未见类别（Val Unseen，49 类，相似度落在 [0.45, 0.68]）。

两条基线的信息通路不同，这决定了噪声进入系统的位置。VLFM 用深度与里程计逐步构建占据图，用视觉语言模型给前沿打分，检测到目标后切到 PointGoal 策略；里程计误差会同时污染占据图与自身定位。DAgRL+OD 的探索策略只接收 RGB 序列（4 层解码器结构 Transformer，8 头，隐层 512，上下文长度 100 帧），不显式维护全局地图，位置感来自视觉序列本身；检测到目标后同样切换到 PointGoal 策略。

基线探索策略输入是否建图噪声进入点
VLFM（Yokoyama 等 2024，模块化）RGB-D、里程计、目标文本占据图与语义前沿图地图投影、前沿坐标、PointGoal 输入
DAgRL+OD（Yokoyama 等 2024，端到端）连续 RGB 历史、目标文本不建图视觉相对定位与动作执行

2. 两类噪声模型

执行噪声（actuation noise）作用在动作效果上：每次动作后，对机器人的真实位置与朝向叠加高斯扰动。论文采用基于动捕标定的扰动模型，标定对象是动力学与传感器配置接近 Stretch 的机器人。执行噪声会改变真实轨迹，把智能体推离训练时见过的状态分布。里程计传感器噪声（odometry sensor noise）作用在观测通道上：每步对策略收到的相对位姿 Pt = (Δx, Δy, Δθ) 叠加均匀噪声，位置幅度在 ±7 mm 内，航向幅度在 ±2° 内，参数取自相关不确定性研究。传感器噪声不改变真实轨迹，只让智能体对自己的位置判断出错。

两者的差别在评测中很关键：执行噪声惩罚的是策略对偏差的纠正能力，传感器噪声惩罚的是依赖精确自定位的模块。地图类方案对后者格外敏感，因为地图的每一帧投影都用了被污染的位姿。

3. 累积误差推导

设每步位置读数的噪声为独立同分布均匀变量 ui ~ U(−a, a)，a = 7 mm。单步方差为

Var(ui) = a2 / 3，E[ui] = 0 均匀分布半宽 a 时方差为 a2/3，单步标准差约为 4.04 mm

N 步累积误差 SN = Σi=1..N ui 的方差按独立性相加：

Var(SN) = N · a2 / 3，σN = a · √(N/3) 随机游走律：误差标准差按 √N 增长，与步数线性增长无关

航向同理，a = 2°，单步标准差 1.155°。代入三档步数得到累积误差账：

步数 N位置标准差（mm）航向标准差（°）含义
10040.4111.55短程探索，误差与目标判定半径同阶
25063.9018.26接近 1 m 判据的一半
50090.3725.82满步数上限，仅传感器噪声就有可观漂移

用蒙特卡洛复核（每步位置在 ±7 mm、航向在 ±2° 内均匀采样，20,000 条轨迹，NumPy 2.2.3，种子 0）：N = 500 时位置误差均值 113.26 mm，中位数 106.73 mm，P90 为 193.78 mm，P99 为 274.48 mm；航向误差均值 20.72°，P90 为 42.59°，P99 为 66.68°。随机流的消费顺序（逐条生成与批量生成）会让 P99 相差 0.8% 以内（位置 P99 分别为 274.48 与 276.66 mm），不影响上述结论；引用时固定写法与 NumPy 版本。解析标准差 90.37 mm 与分布尺度一致，均值高于标准差是瑞利分布的固有比例（均值约为标准差的 1.253 倍）。

E[|SN|] = σN · √(π/2) ≈ 1.2533 · σN 二维随机游走模长的期望；不必记忆，知道均值大于标准差即可

500 步满程时，仅里程计噪声就会让位置读数平均偏出 11.3 cm；均值不代表上界，P99 达到 27.4 cm。对 1 m 成功半径来说，单次误差尚可控，但地图会把每帧误差固化下来，误差进入地图后再被后续规划反复引用，形成与步数的正向反馈。

4. 为什么地图方案更敏感

地图构建是一个投影过程：深度观测按当帧位姿投到全局坐标系，xmap = R(θt) · xlocal + pt。位姿误差 δp 与 δθ 不经过平均就被写入地图，错误占据格与错误前沿会被后续探索反复选择。深度越远，角度误差带来的投影偏差越大，近似为 r · δθ：r = 3 m、单帧 δθ = 2° 时横向偏差约 10.5 cm；若闭环失效、航向误差累积到 500 步的标准差 25.8°，r = 5 m 处的投影偏差达 2.25 m，足以把整面前沿推到错误一侧。而只用 RGB 历史的策略把位置感隐含在序列特征里，视觉内容自身提供闭环约束，单步位姿噪声不会固化成持久结构；代价是噪声让实际走过的路变长，路径效率下降，成功率却基本保住。

6. 适用条件与失效边界

四条边界要写清。第一，噪声模型是为特定平台标定的：换机器人、换轮系、换相机云台，半宽参数都要重新标定，直接套用 7 mm 与 2° 会高估或低估真实敏感性。第二，这里的噪声只在评测时注入，训练未见噪声；若训练时也做噪声增强，结论可能改变，属于另一个实验条件。第三，噪声与场景构成耦合：长走廊与开阔客厅的漂移后果不同，报告应绑定场景集合；同时，主动回环的 SLAM 系统不在本对比范围内，其闭环机制能部分抵消里程计漂移，不能把 VLFM 的退化幅度外推到所有地图方案。第四，DAgRL+OD 在噪声下的稳定性来自策略只用 RGB 的设定，若在端到端策略里加入里程计输入并让网络依赖它，结论需要重新验证。

实现思路与设计

实现目标是把两类噪声做成可开关、可复现的封装，并把评测组织成配对实验：干净与噪声两条件用同一 episode 列表、同一随机种子、同一检查点，减少与噪声无关的方差。

关键代码与解读

三段代码分别覆盖噪声注入、配对保留率统计与累积误差的解析加蒙特卡洛复核。全部按本讲协议书写，输出与前面的数表对应。

片段 1：两类噪声注入封装

import numpy as np

class ActuationNoise:
    """执行噪声：动作后扰动真实位姿（高斯）。切换开关用于 2×2 解耦。"""
    def __init__(self, pos_sigma, rot_sigma_deg, seed, enabled=True):
        self.rng = np.random.default_rng(seed)
        self.pos_sigma = pos_sigma
        self.rot_sigma = np.deg2rad(rot_sigma_deg)
        self.enabled = enabled

    def apply(self, true_x, true_y, true_yaw):
        if not self.enabled:
            return true_x, true_y, true_yaw
        dx, dy = self.rng.normal(0.0, self.pos_sigma, size=2)
        dyaw = self.rng.normal(0.0, self.rot_sigma)
        return true_x + dx, true_y + dy, true_yaw + dyaw

class OdometryNoise:
    """里程计噪声：污染策略输入 P_t（均匀）；不改变真实轨迹。"""
    def __init__(self, pos_halfwidth=0.007, rot_halfwidth_deg=2.0, seed=0, enabled=True):
        self.rng = np.random.default_rng(seed)
        self.a = pos_halfwidth
        self.b = np.deg2rad(rot_halfwidth_deg)
        self.enabled = enabled

    def apply(self, delta_x, delta_y, delta_yaw):
        if not self.enabled:
            return delta_x, delta_y, delta_yaw
        dx = self.rng.uniform(-self.a, self.a)
        dy = self.rng.uniform(-self.a, self.a)
        dyaw = self.rng.uniform(-self.b, self.b)
        return delta_x + dx, delta_y + dy, delta_yaw + dyaw

解读：（1）两类噪声放在两个类里，开关独立，2×2 实验只需组合 enabled 标志，避免把两个效应混在一个函数里。（2）种子在构造时固定，干净条件与噪声条件用同一种子序列，配对差值的方差更小。（3）执行噪声用高斯，与动捕标定的口径一致；里程计噪声用均匀，与不确定性研究给出的「±7 mm、±2°」边界口径一致。（4）传感器噪声只加在返回值上，真实位姿保持不变，这保证了两类噪声的因果作用点不同。

片段 2：配对保留率与置信区间

import numpy as np
from math import sqrt

def paired_summary(clean_sr, noisy_sr, clean_spl, noisy_spl):
    """输入同一 episode 列表上的两条件结果（0/1 序列），输出差值与保留率。"""
    clean_sr, noisy_sr = np.asarray(clean_sr), np.asarray(noisy_sr)
    delta = clean_sr - noisy_sr
    n = len(delta)
    mean_delta = float(delta.mean())
    se = float(delta.std(ddof=1) / sqrt(n)) if n > 1 else float("nan")
    lo, hi = mean_delta - 1.96 * se, mean_delta + 1.96 * se
    retention = float(noisy_sr.mean() / clean_sr.mean()) if clean_sr.mean() > 0 else float("nan")
    return {"delta_sr": mean_delta, "ci95": (lo, hi), "retention": retention,
            "delta_spl": clean_spl - noisy_spl}

# 示例（与表 VI 的汇总口径一致，此处为示意序列长度）
clean = np.array([1, 0, 1, 1, 0, 1, 0, 1, 1, 1])
noisy = np.array([1, 0, 0, 1, 0, 1, 0, 1, 1, 1])
print(paired_summary(clean, noisy, 0.211, 0.181))
# 输出：delta_sr=0.1，配对差值均值的 95% 区间；retention=0.9

解读：（1）配对统计落在逐条 episode 的成功指示上；若先聚合成功率再相减，配对结构丢失，方差通常更大。（2）区间用差值均值的标准误构造，样本量 30 以下时建议改用 Bootstrap 分位区间，第 058 讲会给出 Wilson 区间与样本量核算的完整版本。（3）保留率与差值同时输出：差值回答「退化多少」，保留率回答「还剩多少」，两者分别对应工程上不同的容忍口径。

片段 3：累积漂移的解析式与蒙特卡洛复核

import numpy as np
from math import sqrt

def drift_std(n_steps, halfwidth):
    """均匀噪声随机游走：单步方差 a^2/3，N 步后标准差 a*sqrt(N/3)。"""
    return halfwidth * sqrt(n_steps / 3.0)

a_pos, a_rot_deg = 0.007, 2.0          # ±7 mm，±2°
for n in (100, 250, 500):
    print(n, "%.2f mm" % (drift_std(n, a_pos) * 1000),
          "%.2f deg" % drift_std(n, a_rot_deg))

rng = np.random.default_rng(0)          # 与写作核算同一协议
n, trials = 500, 20000
pos = rng.uniform(-a_pos, a_pos, size=(trials, n, 2)).sum(axis=1)
rot = rng.uniform(-a_rot_deg, a_rot_deg, size=(trials, n)).sum(axis=1)
dist_mm = np.hypot(pos[:, 0], pos[:, 1]) * 1000
print("mean=%.2f p50=%.2f p90=%.2f p99=%.2f mm" % (
    dist_mm.mean(), np.percentile(dist_mm, 50),
    np.percentile(dist_mm, 90), np.percentile(dist_mm, 99)))
print("heading mean=%.2f p90=%.2f p99=%.2f deg" % (
    np.abs(rot).mean(), np.percentile(np.abs(rot), 90),
    np.percentile(np.abs(rot), 99)))

解读：（1）解析式与蒙特卡洛使用同一参数，解析给数量级，蒙特卡洛给尾部：500 步时 P99 位置误差 274.48 mm，远大于 90.37 mm 的标准差，说明只报均值会低估风险。（2）这里模拟的是读数累积，不包含闭环修正；真实系统若有 SLAM 回环，量级会低于此值，报告时应注明是否含闭环。（3）随机游走的 √N 律意味着把 500 步缩短到 125 步，位置误差标准差减半（约 45.2 mm），控制 episode 时长本身就是降噪手段。

常见误区

  • 只做一个噪声源就下结论：症状是报告「噪声下鲁棒」或「噪声下崩溃」，但无法归因。根因是执行噪声与传感器噪声作用点不同。修复：按 2×2 组合分别评测，先报告单因子效应，再报告交互项；若预算只够一个条件，明确写出选定的是哪一个。
  • 干净与噪声条件使用不同 episode 列表：症状是差值噪声大，结论随种子漂移。根因是没有配对。修复：先冻结 episode 列表与初始化种子，再开两个条件；差值统计落在逐条 episode 上。
  • 只看成功率保留，忽略 SPL 退化：症状是宣称「成功率几乎不变」，部署后发现耗能与耗时明显上升。根因是 SPL 对路径成本敏感。修复：双指标并列报告；成功集内的效率损失用 SPL 降幅除以干净 SPL 估算，本讲示例为 14.2%。
  • 单位与角度处理错误：症状是漂移量级差几个数量级，或航向噪声表现为整圈跳变。根因是 mm 与 m 混用、度与弧度混用、角度未取模。修复：内部统一用米与弧度，只在打印时换算；航向误差按 (−180°, 180°] 归一化后再统计。
  • 把 500 步上限当成平均轨迹长度：症状是漂移预估偏大，与实测不符。根因是失败轨迹才接近上限，成功轨迹通常更短。修复：从日志统计每题实际步数分布，按分布加权预估，并在报告中给出分位数。

练习与思考

  1. 设每步里程计位置噪声半宽 a = 5 mm、航向半宽 b = 1.5°，分别计算 250 步与 500 步的累积标准差；把噪声减半后重算，验证误差按 √N 与线性于 a 的比例关系。★
    提示
    σ = a√(N/3)：250 步约 45.6 mm 与 13.7°；500 步约 64.5 mm 与 19.4°。半宽减半则各标准差减半，步数增 4 倍标准差增 2 倍。
  2. 把片段 2 的配对区间换成 Bootstrap：对 episode 配对差值做 10,000 次重采样，给出 95% 分位区间，并说明它与正态近似的适用边界。★★
    提示
    重采样对象是配对差值序列；Bootstrap 不依赖正态假设，适合小样本与偏态分布；比较两者区间宽度，若差异大则说明样本不足或分布偏斜。
  3. 设计执行噪声与传感器噪声的 2×2 解耦实验：写出四个条件的注入开关、主指标、样本量与判定标准，并预测哪个条件对 VLFM 最不利、对 DAgRL+OD 代价最小。★★
    提示
    VLFM 最不利的条件是传感器噪声开启（地图投影被污染），执行噪声主要影响动作闭环；DAgRL+OD 在四个条件间 SR 差异应很小，SPL 随两类噪声都下降。判定标准：单因子效应与交互项的配对区间是否含 0。
  4. 基于表 VI 的 SR 保留与 SPL 退化，构造一个「效率损失估计量」：把 SPL 降幅分解为成功率下降贡献与成功集内效率下降贡献，对 DAgRL+OD Val Seen 与 VLFM Val Seen 各算一次，并讨论分解的混杂因素。★★★
    提示
    近似分解：失败集贡献 ≈ SPL_clean × ΔSR / SR_clean，剩余为效率项。DAgRL+OD Seen：ΔSR = 0.3，SPL_clean = 21.1，SR_clean = 38.5，失败项约 0.16，剩余约 2.84 归效率；VLFM Seen：ΔSR = 6.4，失败项约 3.38，剩余约 1.22。混杂：成功集本身在噪声条件下发生构成变化，两项并不严格正交，应同时报告成功集效率的逐条配对均值。
  5. 若要在自研平台上复现本讲的鲁棒性对比，写出标定清单：需要测量哪些量、每项至少多少个样本、如何判定标定收敛，以及为什么不能直接沿用 7 mm 与 2°。★★
    提示
    清单覆盖轮距与编码器比例、直行 10 m 的横向偏差、原地转 360° 的角度误差、地面材质分层；每项按均值与标准差报告并给出分位数；收敛判据为重复测量的标准差低于目标分辨率的三分之一；不同底盘与轮系的误差谱不同，参数必须实测。

小结

  • 噪声分两类：执行噪声扰动真实位姿，传感器噪声污染策略收到的里程计读数（均匀 ±7 mm、±2° 每步），作用点不同，需分开评测。
  • 累积误差服从随机游走：σN = a√(N/3)。500 步时位置标准差 90.37 mm、航向 25.82°；蒙特卡洛（20,000 条、种子 0）给出位置误差均值 113.26 mm、P99 274.48 mm，航向均值 20.72°。
  • HM3D-OVON 表 VI（Yokoyama 等 2024）：噪声下 VLFM 成功率平均降 5.47 个百分点、SPL 降 4.47；DAgRL+OD 只降 0.20 与 2.70，SR 保留 99.2% 以上。
  • 机制解释：地图方案把被污染的位姿固化成地图结构，误差被反复引用；只用 RGB 历史的策略以视觉做相对定位，成功率稳定，代价是路径效率损失约 14.2%（Val Seen，成功集内）。
  • 评测要配对抗：同 episode、同种子、双指标、区间判定；噪声模型与平台绑定，跨平台需要重新标定，结论不外推。
