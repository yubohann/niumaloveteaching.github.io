第 078 讲｜2026 快照 III：记忆与终身

第 077 讲处理单次请求内的长尾查询；本讲把时间轴拉长，读三篇 2026 年的工作。（Xu 等，2026，VTM-Nav，arXiv:2607.14514v2）研究跨 episode 记忆：每幕独立初始化，只允许自采的场景记忆跨幕持久，在受控 40 步对比中把 HM3D v0.1 的成功率从无记忆对照的 55.0% 提到 59.6%。（Pei 等，2026，OVAL，arXiv:2604.12872）研究终身开放词汇：价值记忆以视觉描述符与置信度管理实例，概率式前沿评分兼顾距离、语义与足迹，终身协议下 HM3D 成功率 68.1%。（Kim 等，2026，CLUE，arXiv:2605.19206）处理上下文取舍：用目标-房间关联熵在房间线索与物体线索之间自适应加权，HM3D 成功率 61.7%。三篇合起来回答同一个问题：把经验存下来、把上下文用起来，收益有多大、代价在哪里。

  • 主题：跨 episode 记忆 / 终身导航 / 记忆描述符 / 房间-物体线索 / 评测协议
  • 关键公式：Sloc = Ssem + Stopo + Ssp；H(O) = −Σk P(Rk|O) log P(Rk|O) / log n；vsem = vtarget + ωroom·vroom + ωobject·vobject

学习目标

  • 理解：区分跨 episode 复用、终身多目标导航与单幕上下文加权三类问题，说清各自的持久状态边界。
  • 会算：复算三篇论文的核心增量与消融差额，包括成功率、SPL、置信区间与场景级胜出计数。
  • 会推导：从房间定位打分、记忆描述符置信度到熵加权价值图，逐步写出公式并解释每项的物理含义与取值范围。
  • 会设计：为「同一场景反复执行多目标请求」的部署场景设计记忆写入与检索协议，并给出评估矩阵。
  • 会判断：识别三篇评测中 40 步、500 步与 0.2 m 阈值三个口径差异，避免跨表排序。

背景与动机

本课第 072 与 073 讲过 GOAT 与 GOAT-Bench：在一条持续的目标链上，子任务继承上一子任务的终止状态，从而复用地图与记忆。这类协议假设物理状态连续，和真实部署仍有距离，服务机器人更常见的工作形态是「同一场景、多次独立请求」：每次请求从随机位姿开始、只有一个目标，请求之间场地不变。若智能体每次都从零建图，此前发现的房间连通、目标视点与成功接近路径全部浪费。VTM-Nav 把这类场景形式化为跨 episode 导航（Cross-Episode ObjectNav），并回答一个更严格的问题：模型参数与导航组件完全冻结、每次独立初始化，仅凭自采的场景记忆能提升多少？

另外两条线处理长期运行的另两个侧面。OVAL 把「终身」定义为同一场景内按序完成一串开放词汇目标，记忆需要跨目标保持可用，且不能依赖预定义类别表；它的难点是自动化开放词汇标注本身无序且含噪，直接存文本标签会造成重复与同义堆积。CLUE 则处理单幕内的上下文取舍：房间线索与物体线索都有效，但相对重要性随目标变化，固定权重不是最优。三篇共同给出 2026 年「记忆与终身」工具箱的一个截面，也是第 080 讲回顾里记忆议题的原料。

核心原理

1. 跨 episode 形式化与分层视觉拓扑记忆

设场景为 E，跨 episode 序列 Es = (es,1, …, es,J)，每幕有独立的起点与单目标 g；幕内观测与动作空间、成功判据、目标词表、模型参数、导航组件全部固定，物理状态与短期执行历史在幕界重置。唯一允许持久的对象是场景记忆 Ms，写入算子为：

Ms(j) = Φwrite(Ms(j−1), τs,j)，Ms(0) = ∅

其中 τs,j 汇总本幕的自我中心观测、位姿估计、语义预测、动作序列与结果。记忆被严格限制为导航期自采信息：不含真值物体位置、oracle 语义地图与房间标签、最短路径，且按场景隔离，不可跨场景查询（Xu 等，2026，VTM-Nav）。

VTM 的结构是「粗拓扑 + 细视觉」两层。粗层是房间拓扑 Ts = (Vsroom, Esroom)：节点存房间规范名、别名、定位置信度、访问统计与近期视觉摘要，边表示已观测到的房间过渡。每个房间节点拥有一份局部物体记忆 Os,v = (Os,vin, Os,vrem)，分别存室内直接观测与透过开口看到的远处线索；对象节点记录类别、置信度、观测计数、视点、视觉摘要、导航提示与成功接近方向。整幕记忆为 Ms = (Ts, Os, Hs)，Hs 存幕级搜索结局与导航历史。

每步的语义证据为 zt = (r̂t, Q̂t, ut, Pt, Rt, at−1, g)：感知房间类别、归一化可见物体集合、文本视觉摘要、估计位置与朝向、上一动作、目标类别。写入前先做清洗：剔除被误当物体的房间名、丢弃否定表述、开口外的物体标记为远程可见。房间定位打分把三类一致性相加：

Sloc(v, zt) = Ssem(v, zt) + Stopo(v, zt) + Ssp(v, zt) ∈ [0, 3]
Ssem = (1/3)[Sname + Sovl + Sdesc]；Stopo = 1[v = vt−1★ 或 (vt−1★, v) ∈ Esroom]；Ssp = maxPi∈Pv 1/(1 + ‖Pt − Pi‖2)

语义项中 Sname 为房间名指示函数、Sovl 为可见物体集合与房间已存物体集合的 Jaccard 系数、Sdesc 为文本摘要关键词的 Jaccard 最大值。拓扑项刻画与上一步房间的连通一致性，空间项用当前位置与房间历史位置的距离开根倒数。三项各归一化到 [0,1] 后无权求和，跨数据集使用同一套规则。最高分房间 vt★ = argmaxv Sloc；证据不足时不强行归属，重复的试探性支持或一次高置信观测才提升为新房间，避免瞬时误述污染拓扑。

记忆写入对物体节点做置信度累积：直接室内观测增量 Δo0，成功幕结束时最终目标条目获得额外增量 Δo+，且 Δo+ > Δo0，更新式为 γo ← min(1, γo + Δ)：

γo ← min(1, γo + Δo0)；成功幕：γo ← min(1, γo + Δo+)，Δo+ > Δo0 > 0

检索阶段按房间对目标 g 的关联度排序：Rin(v, g) = γv,g + η1 nv,g + η2 nv,gsucc，即置信度、观测计数与成功回溯次数的线性组合；没有室内确认时回退到远程可见线索，且其置信度上限更低，防止「透过门缝瞥见」压过室内确认。若当前房间 vt 与目标房间 vg 在拓扑中连通，用 BFS 得到最短房间跳数路径 πt；检索先验 ρt 作为软上下文进入 VLM 提示，并可对「由当前观测导出的候选」重排：kt† = argmaxk B(dt,k, ρt)，B 衡量候选描述与记忆线索的词汇一致性，仅当分数超过阈值 τbias 才替换原选择。保守执行守卫处理阻塞、无进展、重复访问、震荡与过早停止，默认不激活，并在目标可见时保留停止动作。

统计与进展分析另有三个读数。场景级计数：在 HM3D v0.2 的 36 个场景中，VTM-Nav 的成功率在 21 个场景高于文本记忆、6 个打平，SPL 在 26 个场景高于无记忆对照。场景聚类自助法（10,000 次重采样，保留场景内全部 episode 与配对）给出 95% 置信区间：对无记忆对照 SR 为 [−0.60, 3.87]、SPL 为 [0.34, 2.65]；对文本记忆 SR 为 [0.50, 7.65]、SPL 为 [−1.82, 2.24]。区间解读要克制：SPL 对无记忆的区间不含 0，SR 对无记忆的区间含 0；SR 对文本记忆的区间不含 0，SPL 对文本记忆的区间含 0。跨幕进展按场景前后半段平均：VTM-Nav 成功率先 70.8 后 73.4（+2.7），无记忆对照 +0.7，文本记忆 +0.3；论文自述该分析未控制 episode 顺序与目标构成，只能作描述性证据。

3. 终身开放词汇与记忆描述符

OVAL 把任务扩展为同一未知环境的开放词汇目标序列：先前目标完成后再给下一个目标，智能体需在 500 步内以停止动作落在目标 1 m 内，动作集合为停止、前进、左转、右转、抬头、低头六项。核心是两个模块。

开放语义记忆模型为每个观测类维护描述符 C = {Si, Ii, Xi, Hi, Ci}：Si 为标签（经关键词过滤与同义词处理）、Ii 为对齐的图像缓冲（上限 N 张）、Xi 为像素中心反投影到 3D 平面的位置描述符、Hi ∈ RH×S×V 为基于 HSV 颜色直方图的场景描述符、Ci 为置信度概率。置信度用于判定「观测质量是否足够支撑停止」：

Ci = exp(−σ · ‖p̄c − pc‖ · Dt,p̄c / Ab)

其中 p̄c 为检测框像素中心、pc 为图像中心、D 为中心处深度、Ab 为框面积、σ 控制空间调节范围。结构上该式对「偏离视野中心越远、越远距离、框越小」的观测给低置信度，与检测器在边缘与远距处更易出错的统计规律一致；指数形式保证置信度落在 (0, 1]。

实例匹配先做轻量筛除再升级：Sm = λH Sim(Hi, Hj) − λX Sigmoid(k‖Xi − Xj‖)，Sim 取 HSV 各通道逐元素最小值，位置项做距离惩罚。相似度落在模糊区间 [τl, τu] 时调用 SuperGlue 做局部特征匹配，匹配点数超过 τM 判定为同实例，参数更新按置信度比较覆盖（Ci ≤ Cj 时以新观测覆盖），匹配失败则新建实例。查询端用 KMP 子串搜索处理跨粒度词法差异（记忆存「green desk」、查询「desk」仍可命中），到达候选后做 360° 全景验证，停止得分为 S = ω φ({Vk}) + (1 − ω) Ci，φ 为 LLM 对目标出现概率的估计，低于阈值则从记忆中删除该实例。

概率式前沿探索把前沿得分分解为三项之和：P(F) ∝ od(F) + os(F) + of(F)。距离因子 od 用当前位置为中心的高斯核乘可通行指示，偏向近处前沿；语义因子 os 用记忆描述符位置的核与「目标-共现组」概率之积，偏向语义相关房间；足迹因子 of 用历史位置的核求和取负，抑制重复走访。若无预定义共现表可用，后两项仍能完成探索。

4. 房间与物体线索的熵加权

CLUE 的出发点是：房间线索与物体线索都携带信息，但相对权重随目标变化。厕所与浴室强关联，房间线索主导；椅子可能出现在多种房间，与桌子等物体的共现线索更可靠。形式化过程分三步。第一步，用离线 LLM 查询得到目标出现在各房间类的概率分布 P(Rk|O)，并计算归一化信息熵：

H(O) = −Σk=1n P(Rk|O) log P(Rk|O) / log n

除以 log n 把熵归一到 [0,1]，n 为房间类别数。第二步，熵直接映射为权重：ωroom = 1 − H(O)，ωobject = H(O)。低熵意味着目标与特定房间强绑定，房间权重升高；高熵意味着房间分布分散，物体线索权重升高。第三步，把三类分数合成统一价值图：

vsem = vtarget + ωroom · vroom + ωobject · vobject

目标分数 vtarget 与房间分数 vroom 都用 BLIP2 计算当前视图与文本提示的余弦相似度并投影到 2D 栅格，像素置信度 c = cos2(θ/(θFoV/2) · π/2)，中心高、边缘低；重访像素按置信度加权平均更新。物体分数以检测到的共现物体为中心建高斯核：

vobject(x, y) = A · exp[−((x − x̄)2 + (y − ȳ)2) / (2σ2)]，A = A0 · cor(Otarget, OC)，σ = σ0 + cor(Otarget, OC)

相关度 cor 由离线 LLM 预计算并归一化（目标自相关为 1）。相关度同时进入幅度与展宽：语义相关度越高，物体附近的场越强、影响范围越宽，与「共现强的物体应引导更大范围搜索」的直觉一致。探索阶段先用几何驱动（TSP 式）快速铺开，当价值图任一处分数超过阈值后切换到语义驱动选前沿；找到候选后做多视角验证，按一致检测数与类别一致性判定真伪。全部 LLM 查询都在执行前离线完成，避免在线推理延迟。

HM3D 验证集结果（SR / SPL）：CLUE 61.7 / 34.3；ApexNav 59.6 / 33.0；VLFM 52.5 / 30.4；OpenFMNav 54.9 / 24.4；SG-Nav 54.0 / 24.9；TriHelper 56.5 / 25.3。复算：相对同属离线查询路线的 ApexNav，SR +2.1 个百分点（相对 +3.52%）、SPL +1.3；相对 VLFM，SR +9.2（相对 +17.52%）、SPL +3.9。消融从基线 59.6 / 33.0 出发：加房间线索 59.8 / 33.2；加物体线索 60.2 / 31.8（SPL 较基线降 1.2）；两者同加 61.2 / 33.8；改为熵自适应 61.7 / 34.3。逐目标对照更直观：厕所（H = 0.043）房间权重为 1 时 72.9、物体权重为 1 时 63.8，自适应 72.4；椅子（H = 0.883）房间权重为 1 时 69.0、物体权重为 1 时 72.7，自适应 73.3；盆栽（H = 0.915）房间权重为 1 时 38.1、物体权重为 1 时 42.9，自适应 42.9。总行上固定权重最优档为物体权重 1 时的 61.2，自适应把其提到 61.7。自适应的收益来自「大部分目标落在合适的一侧」，个别目标上单一固定权重可能略高，总体优势是分布层面的。

6. 边界与失效模式

VTM-Nav 的结论限定在「交互预算 40 步、闭源 VLM 固定、单场景记忆」三个条件内；500 步长预算的 65.3% 只是诊断，未做跨幕对照。记忆写入依赖 VLM 的房间与物体判断质量，房间误分类会通过拓扑传播；论文的守卫只处理局部执行失败，不修复系统性语义偏差。OVAL 的限制是只支持 ObjectNav 单一模态输入、识别精度在动态快速场景下降，且依赖 Grounded-SAM2 自动标注与 GPT-4o 系列模型；终身协议中同组内传送继承的假设要求场景静态。CLUE 的主要风险在离线知识：房间分布、共现物体与相关度全部来自预查询，若目标在评测场景中的真实分布与 LLM 先验偏离，权重会在错误一侧；物体检测器与分割模型的噪声会直接进入高斯场；真机部署中把全向图像限制到 90° 象限，也引入视场近似。

关键代码与解读

三段代码分别对应三篇论文的最小核心：VTM 的房间定位与目标房间检索、OVAL 的实例匹配与置信度、CLUE 的熵加权融合。

片段 1：VTM 式房间定位与目标房间检索

def jaccard(a, b):
    return len(a & b) / len(a | b) if (a | b) else 0.0

def locate_room(z_t, rooms, prev_room, edges):
    """按语义、拓扑、空间三项给每个房间打分，返回最高分房间。"""
    best, best_score = None, -1.0
    for v in rooms:
        s_name = 1.0 if z_t["room_label"] in v["aliases"] else 0.0
        s_ovl = jaccard(z_t["objects"], v["object_set"])
        s_desc = max((jaccard(z_t["keywords"], u) for u in v["summaries"]),
                     default=0.0)
        s_sem = (s_name + s_ovl + s_desc) / 3.0            # 语义三项等权
        s_topo = 1.0 if (prev_room is None or v["id"] == prev_room
                         or (prev_room, v["id"]) in edges) else 0.0
        s_sp = max((1.0 / (1.0 + dist(z_t["pose"], p)) for p in v["poses"]),
                   default=0.0)
        score = s_sem + s_topo + s_sp                      # 取值 [0, 3]
        if score > best_score:
            best, best_score = v, score
    return best, best_score                                # 阈值判定归入 λ_t

def retrieve_target_room(target, rooms, top_k=1):
    """按置信度 + 观测数 + 成功回溯数排序候选房间。"""
    scored = [(v, v["conf"].get(target, 0.0)
                  + 0.3 * v["count"].get(target, 0)
                  + 0.5 * v["succ"].get(target, 0)) for v in rooms]
    scored.sort(key=lambda x: x[1], reverse=True)
    return [v for v, _ in scored[:top_k]]                  # 供 BFS 路径规划

解读：（1）三项等权求和不做学习，跨数据集共用一个固定规则，这是「可复现优先」的设计取舍；若要调权，必须报告调参集与评测集的划分。（2）空间项用 1/(1+d) 的开根倒数形式，避开高斯核 σ 的跨尺度重标定问题；无历史位置时该项为 0，不制造虚假置信。（3）检索排序里成功回溯权重 0.5 大于观测计数 0.3，体现「成功接近过一次」比「见过多次」信息量更高，与论文的 Δo+ > Δo0 一致（示例权重为教学值）。

片段 2：OVAL 式实例匹配与置信度

import math

def memory_confidence(bbox_center, image_center, depth_at_center,
                      bbox_area, sigma=1.0):
    """论文式 (3)：偏离中心越远、越远、框越小，置信度越低。"""
    offset = math.dist(bbox_center, image_center)
    return math.exp(-sigma * offset * depth_at_center / bbox_area)

def instance_similarity(scene_i, scene_j, pos_i, pos_j,
                        lam_h=0.5, lam_x=0.5, k=8.0):
    """论文式 (4)：场景描述符相似度减位置距离惩罚。"""
    sim = min(scene_i[c][0] for c in range(3))        # HSV 逐通道取最小
    penalty = 1.0 / (1.0 + math.exp(-k * dist(pos_i, pos_j)))
    return lam_h * sim - lam_x * penalty

def match_or_create(new_obs, memory, tau_l=0.2, tau_u=0.8):
    """低相似度直接新建；高相似度判同实例；模糊区间交给 SuperGlue。"""
    best, best_s = None, -1e9
    for node in memory:
        s = instance_similarity(new_obs["scene"], node["scene"],
                                new_obs["pos"], node["pos"])
        if s > best_s:
            best, best_s = node, s
    if best is None or best_s < tau_l:
        return {"action": "create"}                    # 新实例
    if best_s > tau_u:
        return {"action": "merge", "node": best}       # 高置信合并
    return {"action": "superglue", "node": best}       # 特征点复核

解读：（1）置信度公式的指数项把三个质量因素（居中、距离、面积）合成一个 (0,1] 分数，直接用于停止判定；面积在分母，等价于要求检测框足够大才可信。（2）Sm 用场景色与位置先做粗筛，避免对所有节点跑昂贵的特征匹配；模糊区间才升级到 SuperGlue，这是延迟与准确率的折中。（3）合并时按置信度比较覆盖，保证记忆收敛到更高质量观测；τl、τu、τM 的默认值见超参表，改动会直接影响实例数（漏合并导致冗余，误合并导致跨实例污染）。

片段 3：CLUE 式熵加权价值图融合

import torch

def normalized_entropy(probs):
    """probs: 目标出现在各房间类的概率 [n]；返回归一化熵 H ∈ [0, 1]。"""
    p = probs.clamp_min(1e-12)
    return float(-(p * p.log()).sum() / torch.log(torch.tensor(p.numel())))

def entropy_weights(target):
    """低熵目标偏房间线索，高熵目标偏物体线索。"""
    h = normalized_entropy(target["room_probs"])
    return 1.0 - h, h                                  # ω_room, ω_object

def unified_value_map(v_target, v_room, v_object, target):
    w_room, w_object = entropy_weights(target)
    return v_target + w_room * v_room + w_object * v_object

def object_field(center, corr, grid, a0=1.0, sigma0=0.5):
    """高斯共现场：相关度同时放大峰值与展宽。"""
    x = torch.arange(grid).view(-1, 1)
    y = torch.arange(grid).view(1, -1)
    amp = a0 * corr
    sigma = sigma0 + corr
    d2 = (x - center[0]) ** 2 + (y - center[1]) ** 2
    return amp * torch.exp(-d2 / (2.0 * sigma ** 2))

解读：（1）熵归一化除以 log n，使权重可直接解释为比例；概率输入先做 clamp 防止 log(0)。（2）融合式中 vtarget 不带权，保证目标自身的直接相似信号在任何目标上都不被上下文压掉；房间与物体两项按熵此消彼长。（3）object_field 让相关度同时控制峰值与展宽，等价于「越可能共现，引导范围越大」；若只控峰值，弱相关物体仍会在近距离竞争，若只控展宽，强相关物体引导范围受限。

常见误区

  • 把 40 步受控表与 500 步诊断值混排：症状是用 VTM-Nav 的 65.3% 与其他方法的 500 步数字比较。根因是 65.3 / 32.1 的长预算结果没有跨幕对照，只作诊断。修复：主结论只用 40 步受控块；引用长预算时注明「无配对对照」。
  • 把跨 episode 与 GOAT 连续子任务混为一谈：症状是认为本讲与第 072 讲研究同一问题。根因是状态边界不同：跨 episode 每幕物理状态重置、只留场景记忆；GOAT 子任务继承上一子任务终止状态。修复：写清状态边界再比较方法；两者的 SR 不进入同一张表。
  • 用表值复算相对变化并据此质疑论文：症状是由 0.80 / 0.78 算出 +2.56%，与论文的 +1.7% 不符。根因是论文用未舍入的内部值计算。修复：表值复算只用于量级核对，相对变化的权威值引论文，或在复现时导出全精度数据。
  • 忽略 CLUE 的 0.2 m 成功阈值：症状是把 61.7% 与 1 m 口径的表直接排序。根因是成功距离、动作步长（0.2 m / 30°）与 Habitat 默认动作集不同。修复：表格单列阈值与动作口径；跨方法比较前先对齐判据。
  • 把逐目标自适应当每类必胜：症状是用厕所或电视的单项数字否定自适应。根因是熵映射是分布在总体最优，个别目标上单侧权重可能略高（厕所自适应 72.4 对房间权重 1 的 72.9；电视自适应 38.4 对物体权重 1 的 40.2）。修复：看总行与机制证据，单项差异归因到熵估计或检测噪声。

小结

  • 跨 episode（VTM-Nav）：每幕独立初始化、只留场景记忆；分层视觉拓扑记忆用房间拓扑索引局部视觉证据；受控 40 步下 HM3D v0.1 / v0.2 与 MP3D 成功率分别比无记忆对照高 4.6 / 2.0 / 0.8 个百分点，比文本记忆高 3.1 / 5.5 个百分点。
  • 统计读法：HM3D v0.2 场景级 21/36 胜、6 平；自助置信区间对无记忆 SR 含 0、SPL 不含 0；跨幕前后半段成功率 +2.7（描述性，未控制顺序）。
  • 终身开放词汇（OVAL）：记忆描述符把标签、图像、位置、场景色与置信度结构化；终身协议 HM3D 68.1 / 33.8、MP3D 44.1 / 18.6，相对 VLFM 成功率 +14.4 / +9.0 个百分点；消融显示记忆模型贡献最大（−12.0），概率图里足迹项贡献最大。
  • 上下文权衡（CLUE）：用目标-房间关联熵在房间与物体线索间自适应加权，HM3D 61.7 / 34.3，相对 ApexNav +2.1 个百分点；逐目标证据显示低熵目标偏房间、高熵目标偏物体，总体优于任一固定权重。
  • 口径纪律：40 步受控、500 步终身序列与 0.2 m 阈值三套协议不可互推；跨幕与连续子任务的状态边界不同，数字分表使用。
