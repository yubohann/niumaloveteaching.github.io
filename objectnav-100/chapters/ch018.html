第一篇 · 任务、仿真与评测地基

第 018 讲｜挑战赛史 I：2020–2021

2020 与 2021 两届 Habitat ObjectNav 挑战赛在 Matterport3D 的 21 类目标上完成了第一次路线交替：Chaplot 等（2020）的 SemExp 以语义地图加目标导向探索夺冠，Ye 等（2021）的 Red Rabbit 以辅助任务、探索奖励与双策略把端到端 RL 推回第一。本讲拆解两套配方、复算榜单三元组、标注论文数字与榜单数字的口径差异。

  • 主题：挑战赛史 / 冠军配方拆解 / 榜单解读与口径
  • 关键公式：SPL = (1/N) · Σ Si · li / max(pi, li)；条件效率 = SPL / SR
  • 预计学时：70 分钟
  • 前置章节：第 017 讲（训练规模常识）

学习目标

  • 会复述两届赛道的固定口径：MP3D 90 个场景、21 类目标、1 m 距离加 oracle 可见性、六离散动作（含抬头与低头）、500 步上限、无噪声 GPS+Compass，以及 test-std 与 test-ch 两套评测集的分工。
  • 会拆解 SemExp 的模块化流水线（语义建图加目标导向探索加确定性局部规划）与 Red Rabbit 的学习信号（六个辅助任务、探索奖励、双策略），说清各自的增益来源。
  • 会算：从榜单的 SR、SPL、DTG 三元组计算条件效率与相对提升，识别 0.003 的 SPL 差距为何不足以支撑强排序结论。
  • 会判断：论文数字与最终榜单数字、验证集与测试集、test-std 与 test-ch 之间的口径差别，说明跨届比较为什么不成立。
  • 能识别两套冠军方案暴露的瓶颈：感知质量、终止行为、探索覆盖，以及这些瓶颈如何指向第 2、3 篇的方法选型。

背景与动机

第 017 讲建立了规模预算：25 亿步、64 卡、2.75 天。规模本身不是目的，它要在任务上兑换成绩单。2020 与 2021 两届 Habitat ObjectNav 挑战提供了课程内少见的可控对比窗口：两届使用同一数据集（MP3D 90 个场景）、同一目标类别集合（21 类）、同一成功判据（1 m 加 oracle 可见性）、同一动作空间（六离散动作，含抬头与低头），任务规格没有变化，变的只有参赛方法与训练规模。

两届的冠军路线几乎相反。2020 年，Chaplot 等（2020）的 SemExp 用 1000 万帧训练一个模块化系统：显式语义地图、学习到的目标导向探索策略、确定性的局部规划器，测试集成功率 25.3%。2021 年，Ye 等（2021）的 Red Rabbit 用 8 个 GPU-天（192 GPU-时）、约 1.25 亿帧训练一个端到端 CNN+RNN 智能体，靠六个辅助任务、一个探索奖励与双策略结构，在测试集上把成功率推到 24.5%、把 SPL 推到 8.1%，两项成绩分别由两个配置取得（论文口径）。两套方案各有明确的失败分析，恰好覆盖了本课程第 2 篇与第 3 篇的两条主线。

本讲回答四个问题：两届榜单怎么读；两套配方各自在做什么；论文数字与榜单数字为何不同；哪些结论可以直接进入实验设计。SemExp 的模块细节留到第 023、024 讲，辅助任务与模仿学习配方留到第 046 至 050 讲，本讲先给出全貌与可复算的数字。

核心原理

1. 两届赛道口径

先把任务规格冻结成一张表。2021 届的任务规格与 2020 届保持一致，挑战页明确说明「除 PointNav 的相机俯仰外规格未变」，变更都落在参赛方法一侧。

三处口径要点在后续反复用到。第一，test-ch 是决名次的隐藏集，每年更换，论文里报告的数字常来自 test-std 或验证集，二者不可互换。第二，榜单按 SPL 排序，但成功与效率是两个轴，排序结论必须回看 SR 与 DTG。第三，SOFT_SPL 对失败轨迹按比例给分，数值系统性高于 SPL，引用时必须同名同列。

2. SemExp：语义地图加目标导向探索

Chaplot 等（2020）的 SemExp（Goal-Oriented Semantic Exploration，目标导向语义探索）把导航拆成三个模块。语义建图模块先在第一视角上做实例分割（Mask R-CNN，ResNet50 骨干），再用可微的几何投影把分割结果投到俯视栅格，经去噪网络输出语义地图。地图为 K × M × M 的张量，单元格精度 5 cm × 5 cm，通道数 K = C + 2，前两通道为障碍与已探索区域，其余通道对应 C 个语义类别，实验用 15 类。

目标导向策略是系统的大脑。若目标类别对应通道已经出现非零格，长期目标直接取这些格子；尚未看到目标时，由一个 5 层卷积加 3 层全连接的网络根据语义地图、智能体历史位置与目标类别给出长期目标。策略以 PPO 训练，奖励为「到最近目标物体的距离减少量」，长期目标每 25 步重采一次，把强化学习的时域压缩到原来的 1/25。局部执行交给 Fast Marching Method 在障碍通道上规划路径并逐步走完，确定性执行。

关键数字如下（Chaplot 等，2020）：训练 10M 帧；Gibson 测试集 SR 54.4%、SPL 0.199；MP3D 测试集 SR 36.0%、SPL 0.144；挑战赛 test-ch 以 SR 25.3%、SPL 0.102、DTG 6.328 m 夺冠。消融实验给出两条独立的增益来源：去掉语义地图，Gibson SR 从 54.4% 掉到 48.8%；去掉目标导向策略换成覆盖优先的探索，掉到 45.0%；把预测分割换成真值分割，升到 73.1%。最后一组说明感知质量是当时的上限瓶颈：分割改进最多能收回 18.7 个百分点，剩下的 26.9 个百分点属于「始终没找到目标」的情形，要靠探索改进。真机迁移用 LoCoBot 与 PyRobot，20 次试验成功 13 次，点估计 65%，Wilson 95% 区间约 [0.433, 0.819]。

3. Red Rabbit：辅助任务、探索奖励与双策略

Ye 等（2021）的 Red Rabbit 走相反路线：不建显式地图，用 CNN+RNN 的通用架构，把工程重点放在学习信号上。输入侧增加两项语义特征：语义分割通道（训练用 MP3D 真值标注，评测用 RedNet 预测）与 SGE（Semantic Goal Exists，目标类别占画面比例）。SGE 把一个先验直接喂给网络：目标一旦出现就该转向它。

学习信号分三块。其一是奖励，总奖励为成功奖励（成功 +2.5）、每步松弛惩罚（−10−4）与探索奖励之和，探索奖励用 2.5 m 边长的体素计数，形式为 rexplore = 0.25 × dt / v，其中 d = 0.995 按时间步衰减，v 为当前体素的访问次数。其二是六个辅助任务：两个时间跨度的对比预测任务 CPC|A（k = 4 与 16）、一个 PBL（k = 8）、动作分布预测 ADP（k = 6）、广义逆动力学 GID（k = 4）与覆盖预测 CP（k = 16）。其三是双策略（tethered policy）结构：主策略带探索奖励学习如何探索，副策略只接稀疏成功奖励，用重要性加权的 VTrace 做离策略更新，用来在后期把「找到了却继续游荡」的行为压下去。

训练规模为 8 个 GPU-天（192 GPU-时）约 125M 帧，最后 25M 帧切换到稀疏副策略。效果与代价都清晰：论文表 1 的测试集口径下，六动作加 RedNet 微调的成功率 24.5%、SPL 6.4%；换成双策略后成功率降到 21.1%、SPL 升到 8.1%。验证集上同样存在交换：六动作 30.8% / 7.60 对双策略 26.6% / 9.79，成功率让出 4.2 个百分点，SPL 相对提高 28.8%。消融实验显示 SGE 的作用最大：去掉 SGE，验证集成功率从 34.4% 掉到 20.3%，落差 14.1 个百分点。

6. 验证集到测试集的落差

两套方案都出现明显落差。Red Rabbit 的六动作加 RedNet 配置在验证集 34.6%，到 test-std 为 24.5%，落差 10.1 个百分点；四动作配置落差 14.5 个百分点。SemExp 的测试场景同样很少：Gibson 5 个、MP3D 11 个。场景数量少时随机抽样会放大分布偏移，Ye 等（2021）在分析自己作品的验证考核落差时专门讨论了这一点，25.3% 的 test-ch 成绩与验证集表现之间的缺口由此变得可理解。实验纪律：验证集用于选型与早停，结论必须用测试集数字；报告时把两个集合同时给出，并注明集别。

7. 附加指标的口径

榜单除 SPL 外还有三列，各有归属。SOFT_SPL 把失败轨迹的接近程度折算成部分分数，数值系统性高于 SPL：2021 届榜首 Red Rabbit 的 SOFT_SPL 0.22 对 SPL 0.13，高出 69.2%。2020 届尤其能说明列间差别：冠亚军的 SPL 是 0.102 对 0.099，SOFT_SPL 却是 0.18 对 0.22，第二名 SRCB 在软化口径下换到领先位置。差距的机制相同：失败 episode 在软化判据下仍有分数，分数越高说明失败时离目标越近。DTG 记录停止点到目标的距离，越小越好，用来区分「差一点」与「差很远」；它也不是 SPL 的镜像，2020 届 Black Sheep 的 DTG 7.033 m 优于 Active Exploration 的 7.336 m，SPL 却更低，两列分别刻画失败距离与成功时的路径质量。SUCCESS 列即 SR，与 SPL 构成两个主轴。SOFT_SPL 的定义与计算留到第 005 讲，本讲只需记住一条纪律：引用榜单时写清列名，跨列纵向比较数值不成立。

8. 跨届比较的边界

2020 与 2021 的任务规格相同，跨届读数依然有限制：test-ch 的 episode 集合按届更换，参赛者无法看到，因此两届冠军数字的差（SR 0.253 到 0.30，相对提高 18.6%；SPL 0.102 到 0.13，相对提高 27.5%）只能当作量级信号，不能解释为「同一批题目上提高多少」。DTG 从 6.328 m 变为 6.48 m，方向甚至与 SR、SPL 相反，说明集合难度构成发生了变化。可比较的是同一届、同一 split、逐条配对的结果；跨届只能做口径说明与量级描述。

9. 失败模式与结论

Red Rabbit 把验证集 300 条 episode 的失败人工编码成七类：探索失败（explore）、被杂物卡死（plateau）、绕圈或重复走（loop）、看见了却没认准（detection）、距目标一步之遥卡住（last mile）、看到目标却不停止（commitment）、在空旷区游荡（open）。这份分类学在第 033 讲会再次出现。三条方法学结论由此浮现：语义先验与探索是两个独立增益来源（SemExp 消融与 Red Rabbit 消融互相印证）；成功与效率可以互相交换（双策略用 4.2 个成功率点换 28.8% 的 SPL 相对提升）；感知质量与终止行为是当时最贵的两块短板。

设计决策：三元组一起报

只报 SPL 会把「覆盖率高的队伍」与「路径直的队伍」混在一起。榜单三元组的读法固定为：先看 SR 判断找得多少，再看条件效率判断成功时的路径质量，最后用 DTG 校准失败距离。三列同报，排序争议可以当场解释。

设计决策：split 写进数字的名称里

Red Rabbit 同一支队伍存在 24.5%（test-std）与 30%（test-ch 榜单）两个成功率。工程上要求所有实验记录以「方法 + split + 协议版本」命名结果文件，正文数字跟随文件名生成，从源头消除混用。

复现红线：动作空间与本体先核对

2020 与 2021 官方赛道是六动作（含抬头与低头）、LoCoBot 本体。Red Rabbit 论文另外报告了去掉俯仰的四动作限定设置，两套动作空间的数字只在论文内部对照有效，复现时若采用四动作，所有对比必须在同一动作空间内重跑，禁止直接与官方榜单相减。

关键代码与解读

三段代码对应本讲的三个分析动作：榜单三元组分解、目标导向探索的目标选择、学习信号复算。数据全部来自公开页面与论文表格。

片段 1：榜单三元组分解

def board_row(name, sr, spl, dtg):
    """榜单三元组分解：条件效率 = SPL / SR，越低说明成功时越绕路。"""
    cond_eff = spl / sr if sr > 0 else float("nan")
    return {"name": name, "SR": sr, "SPL": spl,
            "cond_eff": round(cond_eff, 4), "DTG": dtg}

# 2020 届 test-ch 前二（Chaplot 等 2020 表 3）
rows = [board_row("SemExp", 0.253, 0.102, 6.328),
        board_row("SRCB",   0.188, 0.099, 6.908)]
for r in rows:
    print(r)
# SemExp: cond_eff 0.4032, DTG 6.328
# SRCB:   cond_eff 0.5266, DTG 6.908
# 冠亚军 SPL 差 0.003，SR 差 0.065：强排序结论需要附加指标

解读：（1）条件效率把「成功率」与「成功时的效率」拆开，两队的短板立刻可读：SemExp 覆盖更多，SRCB 路径更直。（2）SR 为 0 或 SPL 显示 0.00 的行不做除法，返回未定义，与榜单上 BEyond-VRI-UFPR 一行一致。（3）四舍五入要注意：榜单显示 0.10 对 0.10，原始值 0.102 对 0.099，差值 0.003 在显示精度之外，结论必须回到原始值。

片段 2：SemExp 的长期目标选择

def select_long_term_goal(sem_map, goal_channel, policy, t, interval=25):
    """SemExp 长期目标：已见目标就直奔，未见目标按粗时间尺度交给语义策略。
    sem_map: K×M×M 语义地图；goal_channel: 目标类别通道索引。
    返回长期目标格集合，或 None 表示沿用上一目标。"""
    seen = sem_map[goal_channel] > 0
    if seen.any():
        return seen                # 见到目标后所有非零格都是候选终点
    if t % interval == 0:          # 每 25 步重采一次长期目标
        return policy(sem_map, t)  # 语义先验给出下一个探索点
    return None                    # 其余步沿用当前目标

# 局部执行由 FMM 在障碍通道上规划，本片段只覆盖长期目标接口

解读：（1）「已见即直奔」把感知结果直接变成行为，避免找到目标后继续按探索策略游荡。（2）25 步的重采间隔是关键超参：它把探索决策的时域从 500 步压到 20 次决策，直接降低 PPO 的样本复杂度，代价是局部绕行增加。（3）返回 None 的约定让地图更新与长期目标解耦，每个时间步都可以重规划路径，符合论文「每步更新地图并重规划」的描述。

片段 3：Red Rabbit 奖励复算

def red_rabbit_reward(success, t, visit_count, d=0.995):
    """三项奖励：稀疏成功、每步松弛惩罚、访问计数与时间双衰减的探索项。"""
    r_success = 2.5 if success else 0.0
    r_slack = -1e-4
    r_explore = 0.25 * (d ** t) / max(visit_count, 1)
    return r_success + r_slack + r_explore

print(round(red_rabbit_reward(False, 0, 1), 4))     # 0.2499
print(round(red_rabbit_reward(False, 500, 1), 4))   # 0.0203
print(round(red_rabbit_reward(True, 200, 4), 4))    # 2.5228
# 同一体素反复访问时 v 上升，探索奖励按 1/v 递减

解读：（1）探索奖励在开局（t = 0、首次访问）为 0.25，到 500 步时衰减到 0.0204 加负松弛项，量级降了一个数量级，终止行为在后期不再被探索项淹没。（2）除以访问次数 v 使同一区域重复经过时奖励递减，抑制绕圈。（3）成功步合成值 2.5228 中成功项占绝对主导，稀疏信号与稠密信号的尺度差是这一配方能维持长期探索的原因。

常见坑

  • 论文数字与榜单数字混用：症状是同一支队伍在不同材料里出现 24.5% 与 30% 两个成功率。根因是 Red Rabbit 论文报告 test-std，决赛名次来自 test-ch，两套 episode 集不同。修复：数字与 split 强绑定，引用时写全「来源 + 集别」。
  • 验证集数字当结论：症状是把 Red Rabbit 验证集 34.6% 或 SemExp 的 Gibson 54.4% 当作挑战成绩。根因是验证集与测试集分布不同，验证集用于选型，测试集用于结论。修复：报告模板固定两列，val 与 test 同时出现。
  • 跨届直接相减：症状是把 2020 冠军的 0.253 与 2021 冠军的 0.30 做配对比较并宣布进步 18.6%。根因是两届 test-ch 的 episode 集合不同，且软件版本演进。修复：跨届只做口径说明与量级描述，配对结论限定在同一届同 split 内。
  • 用 0.003 的 SPL 差下强结论：症状是引用 2020 榜单宣称冠军在效率上明显领先。根因是把两位小数显示值当成精确排序依据，SR 差距是 SPL 差距的 21.7 倍。修复：同时报告 SR、SPL、DTG 与区间，SPL 接近时参考附加指标与统计检验。
  • 动作空间自选后对标旧榜单：症状是复现代理用四动作（去掉俯仰），却直接引用官方六动作赛道的榜单数字。根因是俯仰动作改变观察空间与任务难度，两套动作空间不可直接对比。修复：在复现记录里显式固定动作空间与本体参数，跨动作空间的结论一律自建对照重跑。

练习与思考

  1. 用 2020 届 test-ch 表复算前两名的条件效率与相对差；解释为什么 SRCB 的条件效率更高却排在第二，并写出你会向读者推荐的三列读数顺序。★
    提示
    条件效率 SemExp 0.4032、SRCB 0.5266；榜单按 SPL 排序，SRCB 的 SPL 0.099 低于 0.102：成功率覆盖不足，成功时的路径优势不足以弥补。读序建议 SR → 条件效率 → DTG。
  2. 复算 Red Rabbit 论文宣称的成功率 +37% 与 SPL +8%，写出各自的基线与方法变体；说明为什么两个提升没有出现在同一个配置上。★
    提示
    +37% 对应 24.5% 对 SemExp 17.9%（六动作加 RedNet 微调）；+8% 对应 8.1% 对 SRCB 7.5%（双策略变体）。成功与效率的交换关系让单一配置难以同时登顶。
  3. 设计 SGE 的替代实验：把 SGE 从输入特征改为辅助预测任务，或换成检测框面积占画面比例，预测两个方案对成功率的影响方向，并给出评估协议与消融表结构。★★
    提示
    参考 Red Rabbit 论文的旁证：SGE 作为输入特征有效，作为辅助任务收益有限。替换特征要注意信息量变化（比例与存在性不同），评估协议固定同一 seed 与 val split。
  4. SemExp 真机实验 20 次成功 13 次。计算 Wilson 95% 区间，讨论 20 次试验能够支持与不能支持的结论；若要检验「真机成功率不低于 50%」需要多少样本量（给出估算公式与代入过程）。★★
    提示
    区间 [0.433, 0.819]，宽度约 38.6 个百分点，不能支持 5 个百分点级别的比较。非劣检验样本量按 n ≈ (zα + zβ)² p(1−p) / δ² 估算：δ = 0.15、p = 0.65 时约 63 次；δ = 0.05 时约 560 次，20 次试验远不够。
  5. 参赛设计：预算 8 个 GPU-天，目标是在 MP3D 21 类的 test-std 上进入前二。在模块化与端到端之间选择一条路线，写出数据与监督来源、奖励或辅助任务清单、训练规模分配、评测协议与两条风险预案，并用本讲至少四组数字支撑每一处判断。★★★
    提示
    把问题拆成探索、感知、终止三段：模块化用 10M 帧量级加语义先验，端到端需要 1 亿帧量级与多任务信号。风险预案覆盖感知误差（分割质量上限 73.1%）、终止行为（双策略的 SR/SPL 交换）、评测集偏置（val 到 test 落差 10 个百分点量级）。

小结

  • 2020 与 2021 两届赛道同规格：MP3D 90 场景、21 类、1 m 加 oracle、六离散动作（含抬头与低头）、500 步、理想化定位；变化集中在方法侧。
  • SemExp（Chaplot 等，2020）以语义地图、目标导向探索与确定性局部规划夺冠，test-ch SR 25.3% / SPL 0.102；消融显示语义先验与目标导向探索各自独立增益。
  • Red Rabbit（Ye 等，2021）以六个辅助任务、探索奖励与双策略把端到端 RL 推回第一：test-std 上 24.5% 的成功率与 8.1% 的 SPL 分别由六动作加 RedNet 微调与双策略两个配置登顶；训练规模约 125M 帧、8 个 GPU-天。
  • 榜单三元组的读法：SR 看覆盖，条件效率看路径，DTG 校准失败距离；2020 冠亚军 SPL 差 0.003 而 SR 差 0.065，单指标排序不稳健。
  • 口径红线：test-std、test-ch、验证集三者不可混用；跨届 test-ch 不是同一批 episode，只做量级描述。
