第三篇 · 端到端与配方

第 052 讲｜失败模式工具箱

第 051 讲把规模收益算到边际，本讲处理另一半：失败在哪里。Ramrakhya 等（2023，PIRLNav，ObjectNav）对最强策略在 HM3D-Semantics v0.1 验证集上的 592 条失败 episode 做了人工标注，归为 8 类：缺失标注 27%、跨楼层导航 21%、识别失败 20%、最后一米 12%、导航网格失败 9%、语义混淆 5%、绕圈 4%、探索失败 2%。本讲把这些占比变成可执行的工具箱：计数校准、Wilson 区间、修复收益预算、自动探针与改进决策树，并为跨楼层、识别、最后一米三类失败给出干预设计与验收指标。

  • 主题：失败标注 / 改进优先级 / 决策树 / 统计校准
  • 关键公式：修复上界 = 失败率 × 类别占比
  • 预计学时：70 分钟
  • 前置章节：第 051 讲（演示规模与收益递减）

学习目标

  • 会算：由 592 条与各类占比反推条数（取整合计 592）、验证集规模、分组占比、修复收益上界与 Wilson 置信区间。
  • 会建：失败标注协议（全量标注、单一归类、双标一致性、schema 版本化）与自动探针（最终到目标距离、回访率、楼层切换、近失判定）。
  • 会判断：按修复上界与可行性排出改进优先序，识别算法无法回收的数据类份额。
  • 会设计：跨楼层、识别、最后一米三类干预实验，含数据构造、对照、验收指标与终止条件。
  • 会读：把失败构成与相邻讲衔接（第 033 讲的工程统计、第 034 讲的跨楼层、第 070 讲的重感知、第 078 讲的记忆），并说明数据噪声对评测的污染。

背景与动机

第 050 与 051 讲把来源和规模都定了，剩余问题是「接下来修什么」。总成功率只说明差多少，失败构成才给方向。把 70.4% 的验证成功率拆开：剩余 29.6% 的 episode 失败，按标注占比折算到类别，就得到每类改进的收益上界；同时也能分辨哪些失败无法通过算法回收。

数据侧的数字最容易被忽略：约 36% 的失败来自缺失标注与导航网格问题，与策略行为无关；另有 25% 属于识别类（识别失败加语义混淆），指向感知层。两类合计超过失败总量的六成。若不做这层拆解，研究者容易把数据问题计入算法差距，把预算错配到探索或记忆模块上。

本讲与第 033 讲分工不同：第 033 讲从运行信号给出工程口径的失败分类，本讲以人工标注为基准，给标注协议、统计校准与改进指南。产出是一套工具：分类学表、计数与区间、修复预算表、探针与决策树。第 053 讲起进入新的架构路线（OVRL-v2），本讲的审计方法可以直接迁移到新基线的对比实验里。

核心原理

1. 标注对象与口径

标注对象是最强 BC→RL 策略在 HM3D-Semantics v0.1 验证集上的失败 episode，共 592 条。该策略验证成功率为 70.4%，失败率 29.6%。若 592 条覆盖了该 split 的全部失败，则验证集规模约为 592 / 0.296 = 2,000 条；这是本讲的推算，用于解释百分比与条数的换算关系，论文未直接给验证集条数。标注采用单一归类，一条失败记入一个类别，类别表占比合计 100%。论文正文有一处将最后一米写作 11%，与其分类表的 12% 相差 1 个百分点；表值合计为 100，本讲以表值为准，引用时注明该出入。

2. 分类学与计数校准

把 592 条按占比反推，取整后各分类条数如下表，取整合计恰好为 592，说明百分比来自整数计数的四舍五入，换算自洽。

3. 修复收益预算

定义修复上界：假设某类失败被完全修复、全部转为成功，且各类别互不影响，则成功率上界为

SR上界 = 70.4% + 29.6% × p类别 p类别 为该类占失败总量的比例；上界为乐观值，实际收益低于此值

代入各类占比得到排序：数据类 +10.66 点到 81.06%；识别类 +7.40 点到 77.80%；导航类 +6.22 点到 76.62%；执行类 +3.55 点到 73.95%；探索记忆类 +1.78 点到 72.18%。若数据类与导航类同时修复且独立，上界为 87.27%。

改进项覆盖失败期望增益（上界）可行性风险

优先级要叠加可行性读：按上界排序是数据、识别、跨楼层、最后一米、探索；论文叙述的顺序是数据、跨楼层、识别，因为它同时考虑「跨楼层可以靠构造训练数据直接干预」。两条排序并不冲突：预算表回答收益上限，干预表回答哪个先动手。数据修复成本与全量标注挂钩，识别类依赖外部模型进展，跨楼层则可以立刻用数据构造做 A/B 实验，因此执行顺序常见为：先修数据里最便宜的部分，同时启动跨楼层干预，识别升级排在骨干替换窗口。

4. 统计校准：592 条样本能支撑多细的结论

百分比之间的比较需要不确定度。对二项比例用 Wilson 区间，在 592 条样本下：缺失标注 160 条，95% 区间约 [23.61%, 30.74%]；语义混淆 30 条，约 [3.57%, 7.14%]；绕圈 24 条，约 [2.74%, 5.96%]；探索失败 12 条，约 [1.16%, 3.51%]。

读法：27% 这一档的区间宽度约 7 个百分点，用于「数据类占约三分之一」的判断足够；2% 到 5% 的小类区间彼此重叠，不能据此对绕圈、语义混淆、探索失败做精细排序。若要把 4% 类别的估计精度做到半宽 2 个百分点，需要约 369 条标注失败；2% 类别需要约 188 条。当前 592 条对大类充足、对小类不足，决策时应先把小类合并成分组再排序。

5. 自动探针与人工标注的映射

人工标注准确但慢，训练循环内需要自动探针做快速迭代。探针从 episode 元数据计算信号，与人工类别有一对多的映射，需抽样复核校准。

失败类别探针信号判据示例误差来源
最后一米最终到目标距离（Distance To Goal，DTG）落在 1 至 2 m 且已停止1.0 < final_dtg ≤ 2.0目标实例半径与可见性判据的口径差
绕圈导航网格单元重复访问率回访率 > 0.30门口、走廊等必要重复被误计
跨楼层楼层切换次数为零且目标在另一层floor_changes = 0依赖场景元数据的楼层标注质量
识别失败目标可见帧数大于零但从未接近可见帧 > 0 且 min_dtg > 2 m可见性计算与检测器能力耦合
数据类到达目标类别附近但无实例标注难以自动判定需要重标注或人工回放确认

探针的定位是筛选器：把 episode 分桶后送人工复核，不直接充当标注。典型的校准流程是随机抽 10% 到 20% 的桶内样本，人工标注后计算一致率，一致率低于阈值就调整判据。

6. 改进指南：每类失败的干预设计

数据类（213 条）：修复缺失标注与导航网格，评测时把该类失败单列，并给出修正口径下的敏感性分析。这部分上限最高，也最容易被忽略。

识别类（148 条）：升级视觉骨干、引入显式语义分割模块；第 023 讲的语义地图路线用过分割检测，第 070 讲的重感知（re-perception）提供在线回看纠错思路。验收指标选「目标可见后的接近率」，它比总成功率更直接反映感知到行动的转化。

跨楼层（124 条）：训练时过采样跨楼层 episode，并加入楼层检测与跨层规划，可参考第 034 讲的 MFNP。验收指标选楼层切换成功率与跨楼层子集成功率，单看总成功率会被稀释（该类只占失败 21%）。

最后一米（71 条）：改进目标距离估计与停止策略（Wasserman 等 2022，Last Mile 导航）。验收指标选近失率（最终距离落在 1 至 2 m 的比例）与停止距离分布。

探索记忆类（36 条）：重访惩罚或记忆机制（第 078 讲）可作参考，但上界只有 1.78 点，投入产出比低，放在最后。

7. 边界与失效条件

第一，失败构成是策略、数据集与评测协议的联合属性，换策略或换到 v0.2 后需要重新标注，历史占比不能直接复用。第二，修复上界假设类别独立且可完全修复，实际干预之间存在重叠，例如修复标注后部分识别失败也可能转为成功，此时两类增益不可相加，87.27% 的组合上界只在独立假设下成立。第三，人工单一归类掩盖多因一果，一条失败可能同时含跨楼层与识别问题，标注规则会影响占比。第四，592 条对小类统计不足，区间宽，排序结论只对分组可靠。第五，探针判据依赖参数（如回访率 0.30），换环境后需重新校准。

实现思路与设计

工具链分三层：标注层定义分类与一致性，统计层做计数、区间与预算，执行层用探针与决策树驱动实验。三层共用同一张 episode 元数据表。

标注协议

环节设计依据
样本标注全部失败 episode（592 条全量）避免二次抽样偏差；百分比直接可比

数据结构与探针

episode 表建议字段：episode_id、scene、goal_category、floors、final_dtg、min_dtg、goal_visible_frames、revisit_ratio、floor_changes、collisions_near_goal、success、label。前段字段由评测管线自动写入，label 由人工或一致性校准后的探针写入。探针函数只读轨迹，不侵入训练循环，保证评测与训练解耦。

干预实验设计

每个干预做成 A/B：基线组保持原配方，干预组只改一个因素（数据构造或模型模块），其余变量固定，种子不少于 3 个。主指标是总成功率，辅以专项目标子集成功率与该类的过程指标（楼层切换率、可见后接近率、近失率）。验收前先跑一轮探针统计，确认目标类在失败中的占比没有漂移，再对比干预前后。

与相邻讲的差异

第 033 讲用工程信号给出失败分类，服务于模块化流水线的调参；本讲以人工标注为基准，服务端到端配方的改进排序；第 070 讲的重感知与第 078 讲的记忆分别对应识别类与探索记忆类的具体机制。三处口径不同，引用时注明数据来源与统计方式。

关键代码与解读

三段代码覆盖统计校准、修复预算与探针计算，输出与正文数字逐项对应。

片段 1：分类计数与 Wilson 区间

from math import sqrt

LABELS = {"missing_annot": 27, "inter_floor": 21, "recognition": 20,
          "last_mile": 12, "navmesh": 9, "semantic_confusion": 5,
          "looping": 4, "exploration": 2}
N = 592
counts = {k: round(N * p / 100) for k, p in LABELS.items()}
print(sum(counts.values()))                     # 592，百分比来自整数计数的四舍五入

def wilson(c, n, z=1.96):
    """二项比例的 Wilson 置信区间。"""
    p, d = c / n, 1 + z * z / n
    ctr = (p + z * z / (2 * n)) / d
    half = z * sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return ctr - half, ctr + half

lo, hi = wilson(counts["missing_annot"], N)
print(f"缺失标注 {counts['missing_annot']} 条，95% 区间 [{lo:.4f}, {hi:.4f}]")
# 缺失标注 160 条，95% 区间 [0.2361, 0.3074]

lo, hi = wilson(counts["exploration"], N)
print(f"探索失败 {counts['exploration']} 条，95% 区间 [{lo:.4f}, {hi:.4f}]")
# 探索失败 12 条，95% 区间 [0.0116, 0.0351]

解读：（1）取整后合计仍为 592，说明四舍五入口径自洽；报告百分比时同时给出条数，读者可以自行复核。（2）Wilson 区间在小比例与中等样本下比正态近似稳健，适合 2% 到 27% 的跨度。（3）区间用于决策，不用于装饰：大类可排序，小类先合并；若两类区间大幅重叠，优先级应交给可行性与成本判断。

片段 2：修复收益预算

FAIL_RATE = 1 - 0.704                 # val 失败率 29.6%
BASE_SR = 70.4

def ceiling(p):
    """假设该类失败全部修复且类别独立时的成功率上界（百分比）。"""
    return BASE_SR + 100 * FAIL_RATE * p

groups = {"数据类": 0.36, "识别类": 0.25, "导航类": 0.21,
          "执行类": 0.12, "探索记忆类": 0.06}
for name, p in groups.items():
    gain = 100 * FAIL_RATE * p
    print(f"{name}: +{gain:.2f} 点 -> {ceiling(p):.2f}%")
# 数据类 +10.66 -> 81.06；识别类 +7.40 -> 77.80；导航类 +6.22 -> 76.62
# 执行类 +3.55 -> 73.95；探索记忆类 +1.78 -> 72.18

print(f"数据加导航组合上界: {ceiling(0.36 + 0.21):.2f}%")   # 87.27，独立假设

解读：（1）上界公式把「失败率」与「类别占比」相乘，得到修复该类后成功率的天花板，量纲是百分点。（2）组合行只在独立假设下成立，实际干预重叠时收益低于相加值，代码注释与论文口径都要写明。（3）输出用于排序，不用于承诺；实验验收仍以 A/B 实测为准。

片段 3：轨迹探针

def probe_episode(traj):
    """从轨迹计算失败探针：近失、回访率、楼层切换。"""
    dtg = [s["dtg"] for s in traj]            # 到目标的测地距离序列
    cells = [s["cell"] for s in traj]         # 离散化导航网格单元
    floors = [s["floor"] for s in traj]
    revisits = 1 - len(set(cells)) / max(1, len(cells))
    return {
        "final_dtg": dtg[-1],
        "min_dtg": min(dtg),
        "near_miss": 1.0 < dtg[-1] <= 2.0,     # 最后一米候选
        "revisit_ratio": revisits,             # 大于 0.30 记为绕圈候选
        "floor_changes": sum(a != b for a, b in zip(floors, floors[1:])),
    }

# 探针只做分桶筛选：近失候选还要回放确认停止动作与目标可见性；
# 回访率高的 episode 可能只是反复经过门口，需要人工复核后再标为绕圈。

解读：（1）三个信号分别对应执行类、绕圈与导航类失败，覆盖占比合计 37%（12% + 4% + 21%），是自动分桶里性价比最高的组合。（2）阈值（2 m、0.30）为教学建议，换环境后要用人工标注校准；阈值写进配置并在报告中固定。（3）探针不替代标注：数据类与识别类仍以人工为主，探针只负责缩小复核范围。

常见坑

  • 把数据口径与修复上界当成算法结论：症状有两个，把 27% 的缺失标注失败写进「导航能力不足」，或把组合上界 87% 直接写成修复承诺。根因是评测口径未拆分，且类别独立与完全修复两个假设被忽略。修复：数据类单列并报告修正口径的敏感性分析，上界标注为乐观值，以 A/B 实测校准；重叠干预只报单类增益。
  • 对小类做精细排序：症状是根据 2% 与 4% 的占比差决定先修绕圈再修语义混淆。根因是 592 条样本下小类区间重叠。修复：合并成分组再排序，给出 Wilson 区间，把可行性纳入判据。
  • 干预实验只看总成功率：症状是跨楼层过采样后总成功率不动就宣布失败。根因是目标类只占失败 21%，总指标被稀释。修复：增设专项目标子集与过程指标（楼层切换成功率、可见后接近率、近失率）。
  • 把探针当标注使用：症状是绕圈占比虚高、近失误判。根因是探针判据与人工定义不一致。修复：抽样 10% 到 20% 人工复核并计算一致率，调整阈值后再全量分桶。
  • 失败构成跨版本搬运：症状是把 v0.1 的 592 条占比用到 v0.2 或模块化方法上。根因是失败构成与策略、场景、判据耦合。修复：换基线或换数据集后重新标注；引用时标注数据来源与样本量。

  2. 计算语义混淆（5%）与探索失败（2%）的 Wilson 区间；若要让 4% 类别的估计半宽达到 2 个百分点，需要多少条标注失败；说明「先合并后排序」的统计理由。★★

  3. 按修复上界给改进项排序，再与论文叙述顺序（数据、跨楼层、识别）对照，解释两条排序的差异并给出你的执行顺序。★★

小结

  • 失败标注对象为最强 BC→RL 策略在 HM3D-Semantics v0.1 val 上的 592 条失败；按 70.4% 成功率反推验证集约 2,000 条。分类表占比合计 100%，正文一处最后一米 11% 与表值 12% 差 1 点，采用表值并注明。
  • 分类与计数：缺失标注 160、跨楼层 124、识别失败 118、最后一米 71、导航网格 53、语义混淆 30、绕圈 24、探索失败 12；分组为数据类 36%、识别类 25%、导航类 21%、执行类 12%、探索记忆类 6%。
  • 修复上界（失败率 29.6%）：数据类 81.06%、识别类 77.80%、导航类 76.62%、执行类 73.95%、探索记忆类 72.18%；数据加导航组合在独立假设下 87.27%，属乐观值。
  • 统计校准：27% 档的 95% Wilson 区间约 [23.61%, 30.74%]，小类区间重叠；4% 类别要达到半宽 2 点需约 369 条标注失败。小类先合并再排序。
  • 探针与决策树：近失、回访率、楼层切换三信号覆盖执行、探索记忆与导航类，用于分桶而不替代标注；决策树按数据、识别、跨楼层、最后一米、探索的触发条件给出动作与验收指标。
