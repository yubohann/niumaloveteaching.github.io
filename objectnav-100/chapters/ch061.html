第四篇 · 开放词汇与大模型

第 061 讲｜OVON 问题定义与 HM3D-OVON

第 060 讲把开放词汇列为端到端的边界条件：类别语义距离一拉大，成功率从 41.3% 掉到 18.3%。第四篇从本讲开始处理开放词汇目标导航（Open-Vocabulary ObjectNav, OVON）。以 Yokoyama 等（2024，arXiv:2409.14296）的 HM3D-OVON 为主线，本讲给出任务形式化、数据集构成、三档评估协议、首轮基线结果与失败结构，为 062 至 064 讲的方法拆解立好口径。

  • 主题：开放词汇任务定义 / 基准构建 / 评估协议
  • 关键公式：成功判据 = 500 步内停止且距目标实例 ≤ 1 m
  • 预计学时：80 分钟
  • 前置章节：第 060 讲 第三篇回顾：端到端 vs 模块化

学习目标

  • 会形式化：写出 OVON 的观测、动作、目标与成功判据，列出它与闭集 ObjectNav 的差异项，说明开放词汇把泛化轴从场景扩到类别。
  • 会读数据：解释 181 个场景、379 类目标、15,661 个实例、280 与 178 的类别划分，以及 145 / 36 场景划分与 HM3DSem v0.2 训练验证划分的对应关系。
  • 会解释协议：用 SentenceBERT 余弦相似度说明 Val Seen、Val Seen Synonyms、Val Unseen 三档的构造逻辑与 79 / 50 / 49 的类别数，指出三档共享场景、类别互斥。
  • 会算落差：由基线表计算 DAgRL 跨档衰减、DAgRL+OD 的检测器增益与 VLFM 的三档极差，并解释两类方案泛化差异的来源。
  • 能设计一轮 OVON 评测：给出协议卡、控制变量（检测器、导航权重、场景）、三档加噪声的评测矩阵与失败分类字段。

背景与动机

闭集 ObjectNav 的目标类别数量有限：Habitat 挑战在 HM3D 上只测 6 类，MP3D 上 21 类。第 033 与 049 讲的失败分析已经显示，策略的大部分失败集中在少数类别与场景结构上；6 类目标无法暴露模型在长尾物体上的行为。真实家庭中的目标由人用语言临时指定，例如「把沙发上的钥匙找回来」，类别集合在测试时未知。第 060 讲给出直接证据：端到端策略在训练类别上成功率 41.3%，换到语义距离最远的一档只剩 18.3%；模块化方案靠开放词汇检测器把三档成绩稳定在 32.4% 至 35.2%。开放词汇把「找什么」的自由度交给测试时的语言，这既扩大了任务范围，也把泛化评测从场景维度扩到类别维度。

HM3D-OVON 解决的正是「用什么数据与协议衡量这种能力」。它建立在 HM3DSem 的密集标注之上（第 013 讲），把目标粒度从挑战赛的 6 类扩到 379 类，并用语义相似度把评估集切成三档，分别度量同词、同义与远距离类别的表现。本讲先定义任务与基准，062 至 064 讲再拆解方法：062 讲 CoW 与 Pasture 的 CLIP 基线，063 与 064 讲 ZSON 的多模态嵌入与跨数据集零样本。

边界说明：本讲的数字全部来自仿真基准（HM3DSem 场景、Stretch 规格的智能体、500 步预算），不涉及真机；真机评测协议留到第 087 至 096 讲。

核心原理

1. 任务形式化

OVON 把 ObjectNav 的目标条件从「固定类别集中的一个标签」换成「测试时给定的自由文本」。在每个时刻 t，智能体接收观测四元组：RGB 图像 It、深度图 Dt、相对起点的里程计 Pt = (Δx, Δy, Δθ) 与目标描述 G。动作空间为离散六动作：前进 0.25 m、左转与右转各 30°、抬头与低头各 30°、停止。一个 episode 的预算为 500 步，成功判据是智能体调用停止时距目标物体任一实例不超过 1 m；与挑战协议不同，本基准的判据不附加 oracle 可见性校验，引用时按各自协议卡区分。

要素闭集 ObjectNavOVON
目标集合训练与测试同一固定集（HM3D 6 类 / MP3D 21 类）测试时自由文本，可为训练未见类别
泛化轴仅新场景新场景加新类别，且类别可分同义与远距
观测与动作RGB-D、里程计、六离散动作相同，另加语言目标编码
成功判据1 m 加 oracle 可见性（2020 至 2023 挑战口径）500 步内停止且距目标 ≤ 1 m（本基准口径，无可见性校验）
主要失败模式探索不足、误停、最后一米另加类别不识别与同义词混淆

基准把智能体配置对齐 HelloRobot Stretch：身高 1.41 m、底盘半径 17 cm、360×640 RGB-D 相机安装高度 1.31 m。选择该本体是为了让仿真设定靠近真机部署形态，与第 087 讲的连续动作章节衔接。

场景与实例统计：181 个真实扫描场景，15,661 个目标物体实例，379 个目标类别；平均每个类别约 41.3 个实例，每个场景约 86.5 个实例。训练与评估划分完全不重叠：训练 145 个场景，评估 36 个场景；训练出现 280 个类别，评估涉及 178 个类别。第 013 讲已经说明 HM3DSem v0.2 的场景划分为 145 / 36 / 35（训练 / 验证 / 测试），HM3D-OVON 的 145 与 36 与之逐位相同，评估沿用 v0.2 验证场景，测试场景未进入论文报告；引用跨版本数字时要写清这一层对应。

类别口径需要特别注意。HM3DSem 的挑战标注把原始标签映射到 40 个规范类（第 013 讲），本基准在目标粒度上使用 379 类。两者服务于不同问题：40 类服务于闭集挑战，379 类服务于开放词汇评估。379 与 6、21 不可并用，280 与 178 也不可直接相加：280 加 178 等于 458，超出 379 的原因在于 Val Seen 一档按定义复用训练类别，训练与评估类别集在「已见」部分刻意重叠。

episode 生成遵循三条约束。第一，目标实例与起点在同一楼层，任务不要求上下楼；第二，起点到最近目标实例的测地距离落在 1 m 至 30 m；第三，目标物体在至少一个距其 1 m 以内的视点中占相机视图的 5% 以上，保证任务可行且目标可辨认。按此协议，训练场景每个生成 5 万条 episode，145 个场景共 725 万条；评估场景每个生成 3 千条，36 个场景共 10.8 万条。实例数（15,661）与 episode 数（约 736 万）是两个量级的概念，前者是物体标注，后者是起点与目标的采样组合。

3. 三档评估协议

评估集的 178 个类别按语义距离切成三档，切分工具是 SentenceBERT（Reimers 与 Gurevych，2019）的句嵌入余弦相似度。流程为：先均匀采样约 25% 的类别，计算每个类别与训练集全部类别的最大余弦相似度；最大相似度高于阈值的进入 Val Seen Synonyms，其余进入 Val Unseen；Val Seen 直接使用训练类别。

分档类别数是否新类别与训练类别的最大相似度考查能力
Val Seen79否1.00同词推断，分布内上限
Val Seen Synonyms50是[0.68, 0.96]同义词与近邻词迁移
Val Unseen49是[0.45, 0.68]远距离类别的开放词汇泛化

三档共享同一批 36 个评估场景，任何一档都没有训练场景与训练实例。这样设计的目的是把「场景难度」固定住，让差异只来自类别语义距离；练习中的对照实验也应保持这一控制。分档还有一个细节：Val Seen Synonyms 的目标词与训练词同义但不同拼写，例如训练见 couch、评估问 sofa；验收时应把「同义替换是否掉点」与「未见类别是否掉点」分开报告。

4. 基线方法与训练协议

论文比较三类范式。端到端策略的观察编码为：冻结的 SigLIP 视觉与文本编码器各输出 768 维向量，上一步动作经嵌入层得到 32 维，拼接后送入 4 层解码器式变换器（8 个注意力头、隐藏维 512、上下文长度 100）输出动作分布；对照 RNN 时把变换器换成参数量相近的 4 层 LSTM。模仿学习分行为克隆与 DAgger 两种，DAgger 的在线专家由前沿探索加 3.5 m 内直线奔向目标（bee-line）组成；该专家实现把单步建议耗时压到约 1 毫秒，此前的前沿探索实现在线运行需约 250 毫秒，延迟差 250 倍，这是 DAgger 能在本基准上跑通的前提。模仿轨迹有三种来源：前沿探索、最短路径，以及两者的对比实验（每个 episode 每类各生成一条轨迹，约 725 万条）。

训练预算：BC 与 DAgger 各训练 1.5 亿步，RL 基线训练 3 亿步；BCRL 与 DAgRL 在模仿预训练后追加 1.5 亿步 RL 微调。RL 使用 PPO 与 PointNav 式塑形奖励：成功给 2.5，其余步为负的测地距离变化减 0.01。全部策略在 8 张 TITAN Xp 上训练，每卡 16 个环境，使用变经验回放（VER）。模块化对照为 VLFM：占据地图、视觉语言价值图、OWLv2 开放词汇检测器与点目标策略；DAgRL+OD 把同一 OWLv2 检测器与点目标策略接到 DAgRL 探索策略之后。

噪声实验补充了稳健性维度：测试时注入执行噪声与里程计噪声（位置与旋转高斯噪声、里程计 ±7 毫米与 ±2°），训练过程不注入。VLFM 的 SR 最多下降 6.4 个百分点（表 VI 差值；论文正文概括为 6.1）、SPL 最多下降 5.4 点；DAgRL+OD 的 SR 最多下降 0.3 点、SPL 最多下降 3.0 点。只用 RGB 序列的策略不依赖精确建图，对定位漂移天然不敏感，代价是路径效率在噪声下变差。

6. 失败结构

论文对 DAgRL 逐档统计失败原因。随着类别语义距离拉大，超时（未调用停止）从 19.5% 升到 25.5% 再升到 37.3%，其中「看到目标却忽略」从 2.6% 升到 8.6% 再升到 16.8%，「在目标附近进出后停错位置」从 2.2% 升到 11.4% 再升到 17.8%；探索不足造成的漏看稳定在 16.8% 至 20.5%。全程占比最高的两类是停在错误物体与从未看到目标，均为 16.8% 至 20.5%。这份失败结构把改进顺序写得很清楚：先降低误检与漏检（检测器与再感知），再提高探索覆盖（前沿策略与预算管理），类别不识别的问题会随检测器接入自然缓解。

7. 适用边界

第一，场景域：全部评估在 HM3DSem 真实扫描的 36 个场景内进行，跨到其他数据集需要新的类别对齐与 episode 生成。第二，本体域：智能体按 Stretch 几何建模，不含机械臂、连续动作与接触动力学。第三，成功判据：本基准只查停止位置距目标 ≤ 1 m，不附加 oracle 可见性校验；挑战协议两者兼查，跨协议比较前先读协议卡。第四，语言域：目标为短类别词或简单短语，「L 形沙发」一类组合描述可以出现，但长指令与指代关系超出本基准。第五，评估成本：三档各含数万条 episode，完整评测的仿真步数在千万级，评测预算要与第 059 讲的吞吐账一起核算。

选型初步建议

按第 060 讲的四轴框架，开放词汇目标与无演示预算指向「学习导航 + 开放检测器」的混合结构：DAgRL+OD 的三档极差 1.9 点、噪声下 SR 仅降 0.3 点，是当前证据下最稳的起点；若坚持纯端到端，需要接受同义与远距档的衰减，并把检测器接入列为第一优先改进。

关键代码与解读

三段代码覆盖基准的三个关键环节：类别分档、episode 可行性过滤与分档指标聚合。输入都写成显式结构，便于替换为自己的数据管线。

片段 1：按相似度做类别分档

import numpy as np

def split_categories(cats, train_cats, emb, threshold=0.68):
    """emb: 类别到句嵌入的映射；对每个新类别取与训练类别的最大余弦相似度。"""
    def cos(a, b):
        return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))
    seen, synonyms, unseen = [], [], []
    train_set = set(train_cats)
    for c in cats:
        if c in train_set:
            seen.append(c)                          # 与训练同名，归 Val Seen
            continue
        sim = max(cos(emb[c], emb[t]) for t in train_cats)
        (synonyms if sim > threshold else unseen).append((c, round(sim, 2)))
    return seen, synonyms, unseen

# 论文口径参考值：Seen 79 类（相似度 1.00），Synonyms 50 类（0.68 至 0.96），
# Unseen 49 类（0.45 至 0.68）；阈值在 0.68 附近，切分后需人工抽查边界类别。

解读：（1）相似度按「与训练集的最大值」计算，平均值口径不采用，只要存在一个近义训练类就算同义档，符合「能借力已有类别」的定义；（2）阈值 0.68 是分档的敏感参数，边界类别（0.65 至 0.71）建议人工复核并保持分档冻结；（3）同名类别直接进 Val Seen，不参与相似度计算；（4）两档返回相似度便于审计，论文给出的区间可以用来对比自建分档是否偏移。

片段 2：episode 可行性过滤

def feasible(start, goal_instances, geo_dist, same_floor, view_ratio,
             min_d=1.0, max_d=30.0, min_view=0.05):
    """三条约束：同层、测地距离区间、至少一个 1 m 内视点可见度达标。"""
    if not same_floor(start, goal_instances):
        return False                                # 不要求上下楼
    d = min(geo_dist(start, inst) for inst in goal_instances)
    if d < min_d or d > max_d:
        return False                                # 过近无探索价值，过远超预算
    best_view = max(view_ratio(inst) for inst in goal_instances)
    return best_view >= min_view                    # 目标需占视图 5% 以上

# 生成侧：训练场景每场景 5 万条、评估场景每场景 3 千条；
# 过滤失败的目标组合要重采样，禁止放宽阈值换数量。

解读：（1）测地距离用可通行路径计算，欧氏距离会在隔墙情形下高估可达性；（2）可见度检查在距目标 1 m 以内的视点上做，取最大值，保证任务可完成；（3）失败组合重采样并在日志中记录拒绝原因，便于审计生成分布；（4）三个阈值与论文一致（1 m、30 m、5%），修改任何一项都要在协议卡里声明为新基准。

片段 3：三档指标聚合与落差核算

def eval_table(rows):
    """rows: [{'name','split','sr','spl'}...]；输出每方法三档与跨档落差。"""
    by_name = {}
    for r in rows:
        by_name.setdefault(r["name"], {})[r["split"]] = (r["sr"], r["spl"])
    out = []
    for name, d in by_name.items():
        seen = d.get("seen", (0.0, 0.0))[0]
        syn = d.get("synonyms", (0.0, 0.0))[0]
        uns = d.get("unseen", (0.0, 0.0))[0]
        out.append({"name": name, "sr": (seen, syn, uns),
                    "drop_syn": round(seen - syn, 1),
                    "drop_uns": round(seen - uns, 1),
                    "span": round(max(seen, syn, uns) - min(seen, syn, uns), 1)})
    return out

rows = [{"name": "DAgRL", "split": "seen", "sr": 41.3, "spl": 21.2},
        {"name": "DAgRL", "split": "synonyms", "sr": 29.4, "spl": 14.4},
        {"name": "DAgRL", "split": "unseen", "sr": 18.3, "spl": 7.9},
        {"name": "DAgRL+OD", "split": "seen", "sr": 38.5, "spl": 21.1},
        {"name": "DAgRL+OD", "split": "synonyms", "sr": 39.0, "spl": 21.4},
        {"name": "DAgRL+OD", "split": "unseen", "sr": 37.1, "spl": 19.9}]
print(eval_table(rows))
# DAgRL 落差：11.9 与 23.0，极差 23.0；DAgRL+OD 落差：−0.5 与 1.4，极差 1.9

解读：（1）聚合按方法名分组、按档取值，跨档落差与极差自动生成，避免手工计算口径不一；（2）DAgRL+OD 的 drop_syn 为 −0.5 表示同义档甚至略高于 Seen 档，说明检测器把同义迁移问题基本抹平；（3）极差 span 是三档稳定性的单一数字，与第 060 讲回顾表兼容；（4）扩展 SPL 与噪声两档时在行结构里加字段即可，聚合逻辑不变。

常见误区

  • 把三档当成三个独立数据集：症状是在实验里为每档重新划分场景，导致场景难度与类别难度混在一起。根因是忽略「共享 36 个场景、类别互斥」的设计。修复：分档只动类别列表；脚本里冻结场景清单并断言三档场景集合相同。
  • 类别计数口径混谈：症状是声称基准有 458 个类别（280 加 178），或把 178 当训练类别数。根因是 Val Seen 复用训练类别造成集合重叠。修复：引用时写「全集 379、训练涉及 280、评估涉及 178、三档 79 / 50 / 49」，并说明重叠关系。
  • 把实例数当 episode 数：症状是估算评测步数时用 15,661 乘 500。根因是混淆物体标注与起点目标的采样组合。修复：训练约 725 万条、评估约 10.8 万条；数据集论文的数字与 episode 生成协议分开记录。
  • 检测器来源不标就横向比较：症状是直接用 DAgRL 的 18.3 与 VLFM 的 35.2 得出「模块化泛化更强」的结论。根因是两行感知配置不同（前者无检测器，后者用 OWLv2）。修复：对照表增设检测来源列；把 DAgRL+OD 放进比较，结论改为「检测器是泛化主因」。
  • 把 Seen Synonyms 当未见类：症状是只报告 Unseen 或只报告 Synonyms，或用 Synonyms 成绩宣称零样本能力。根因是两档的语义距离与考查目标不同。修复：三档并列报告；同义档掉点归因于同义词迁移，远距档掉点归因于开放词汇识别，两者分开讨论。
  • 噪声结论外推：症状是引用「端到端噪声下只降 0.3 点」时不说明训练无噪声、噪声在测试时注入。根因是省略协议条件。修复：引用时补齐「训练不注入、测试注入、里程计 ±7 毫米与 ±2°」三个条件，并注意 SPL 在噪声下仍降 3.0 点。

练习与思考

  1. 用数据集统计计算：实例数的类别均值（15,661 / 379）与场景均值（15,661 / 181）；由 5 万与 3 千的每场景生成量计算训练与评估 episode 总量；并解释为什么 episode 数远大于实例数。★
    提示
    每类约 41.3 个实例，每场景约 86.5 个；训练 145 × 50,000 = 725 万条，评估 36 × 3,000 = 10.8 万条。每类实例可在不同起点被重复采样，episode 是（场景、起点、目标类）三元组。
  2. 说明 79 / 50 / 49 与 379、280、178 三组数字的关系，并写出至少两条引用规则，保证不同论文之间不串口径。★
    提示
    79 加 50 加 49 等于 178，是评估涉及类别数；280 是训练涉及类别数；379 是全集。引用规则：写清「涉及」与「全集」两个词；提到 Seen 档时声明该档类别也属于训练集。
  3. 设计一组阈值消融：把分档阈值从 0.60 到 0.80 取值，预测 Synonyms 与 Unseen 的类别数与平均语义距离如何变化；给出判定「阈值合适」的标准与要冻结的审计字段。★★
    提示
    阈值升高，Synonyms 档变小且更近义，Unseen 档变大且更难；判定标准是分档后两档的平均相似度差距稳定、边界类别人工复核通过、三个种子的评测结论方向一致。冻结字段：阈值、每类最大相似度、边界类别清单。
  4. 从结果表解释：为什么 VLFM 在 Seen 档输给 DAgRL 6.1 点，却在 Unseen 档反超 16.9 点；设计一个只改检测器、不动探索策略的消融来验证你的解释。★★
    提示
    VLFM 的伪影在开放词汇检测器上，它见过远多于训练类的类别；DAgRL 只能识别训练分布内视觉模式。消融：同一 DAgRL 策略加挂 OWLv2 与点目标策略，即 DAgRL+OD 行；若其 Unseen 档跃升约 18.8 点，检测器归因成立。
  5. 完整评测设计：为自研的 OVON 智能体写一份评测协议，覆盖三档类别与两档噪声，要求写出协议卡、控制变量、统计方案、失败分类字段与验收标准；并说明当资源只够评测一档时该选哪档、依据是什么。★★★
    提示
    协议卡按本讲表格填写，控制变量锁定场景清单、检测器权重、导航权重与随机种子；统计按 3 种子报告均值与区间；失败字段含超时、忽略目标、停错物体、从未看到四类。资源受限时优先 Val Unseen，它对开放词汇能力区分度最高，且 VLFM 与 DAgRL+OD 的差距在此档最大；但最终发表仍需三档齐全。

小结

  • OVON 把目标条件换成测试时自由文本，观测为 RGB-D、里程计与目标描述，动作为六离散动作，500 步内停止且距目标 ≤ 1 m 为成功；与闭集任务的差别集中在目标集合与泛化轴。
  • HM3D-OVON 规模：181 个真实扫描场景（训练 145 / 评估 36，无重叠）、379 个目标类别、15,661 个实例；训练涉及 280 类、评估涉及 178 类；训练与评估 episode 总量约 725 万与 10.8 万。
  • 三档协议：Val Seen 79 类（相似度 1.00）、Val Seen Synonyms 50 类（[0.68, 0.96]）、Val Unseen 49 类（[0.45, 0.68]），由 SentenceBERT 余弦相似度切分；三档共享场景、类别互斥。
  • 首轮结果：DAgRL 41.3 / 21.2 起步，跨档降到 18.3 / 7.9（−23.0 点）；VLFM 三档 32.4 至 35.2 接近平坦；DAgRL+OD 三档 37.1 至 39.0（极差 1.9 点），全面超过 VLFM 1.9 至 6.6 点。检测器是泛化的关键变量。
  • 稳健性与失败结构：测试时噪声下 DAgRL+OD 的 SR 最多降 0.3 点、VLFM 最多降 6.4 点（表 VI 差值）；失败中超时随类别距离从 19.5% 升到 37.3%，误停与漏看全程各占 16.8% 至 20.5%。
