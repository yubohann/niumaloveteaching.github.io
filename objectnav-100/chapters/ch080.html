第四篇 · 开放词汇与大模型

第 080 讲｜第四篇复盘：开放词汇横评与未解问题

第四篇从 OVON 的问题定义走到 2026 年的多平台快照，19 讲留下了分散在多套协议上的结果。本讲先给出一条统一坐标：目标接口、信念表示、选项空间与策略训练四个轴；再把三个 2026 年的对照点放进坐标。（Zemskova 等，2025/2026，OVSegDT，arXiv:2508.11479v3）用 1.3 亿参数的纯 RGB 端到端策略，在 HM3D-OVON 的 val unseen 划分取得 44.7% 成功率与 20.6 SPL，未见类别与可见类别几乎持平。（Sun 等，2026，Graph-MambaNav，arXiv:2608.13723）用 LLM 常识关系给物体图排序，在 AI2-THOR 上达到 83.22% 成功率。（Xiao 等，2026，REST，arXiv:2603.18624v2）把选项空间从孤立路点改成路径树，在 HSSD 上取得 56.7% 成功率与 29.1 SPL。三条读数收束到本讲的三个未解问题：长尾、验证与记忆。

  • 主题：开放词汇横评 / 四轴方法坐标 / 长尾·验证·记忆 / 阶段自测
  • 关键公式：LEALM = pPPO·LPPO + pBC·LBC；hi = A[i, i*]；r(θ|M) = |{v ∈ M ∩ F(θ) : Ivis(v,θ)·Iunk(v) = 1}|
  • 预计学时：90 分钟
  • 前置章节：第 079 讲（2026 快照 IV：空中与多机）

学习目标

  • 理解：说清四轴坐标每个维度的判据，并把第 061 至 079 讲的代表方法放进同一张横评表。
  • 会算：复算 OVSegDT、Graph-MambaNav 与 REST 的主表增量、消融差额、失败构成与复杂度比值，核对版本之间的数字差异。
  • 会判断：分辨四套评测协议（HM3D-OVON 三档、GOAT-Bench、HSSD-rare、标准 ObjectNav 主表），说明哪些数字可以并排、哪些只能分组阅读。
  • 会设计：把长尾、验证、记忆三个开放问题改写为可检验假设与最小实验矩阵，给出对应的指标与失败分析口径。
  • 会自测：用十问清单定位第四篇的薄弱环节，为第五篇的真机与系统集成准备接口问题。

背景与动机

第四篇的 19 讲覆盖了四条线索：零样本基线（CoW、ZSON）、价值图与场景图（VLFM、SG-Nav、ConceptGraphs）、多模态与终身任务（GOAT、VLMnav、NaVid）、以及 2026 年的五组快照。线索各自完整，读数却分散：HM3D-OVON 报成功率与 SPL，GOAT-Bench 报子任务成功率，HSSD-rare 报长尾增益，Gibson 与 HM3D v1 主表又是另一套起点。缺少统一坐标时，最容易被跨协议的数字并排误导。

本讲承担三件事。第一，给出四轴坐标（目标接口、信念表示、选项空间、策略训练），用一张表把 19 讲的方法压缩到可比较的位置。第二，读三个 2026 年的对照工作：它们分别重写了感知接口、结构化先验与选项空间，恰好对应第 077 讲的检测瓶颈、第 065 讲的语言排序与第 031 讲的前沿排序。第三，把长尾、验证、记忆三个问题写成假设清单，作为第五篇的接口准备：真机部署会把这里的每一个假设放大成工程约束。

核心原理

1. 四轴坐标与口径四元组

方法对比先固定比较框架。第一篇复盘给出的口径四元组仍然有效：P = (任务, 数据, 指标, 平台)，四项逐项对齐才允许直接比较。在开放词汇这一篇内部，再叠加四个方法轴，得到本讲的横评坐标：

轴取值判据
目标接口类别文本 / 自由文本 / 网络图像 / 目标掩码目标在策略输入中如何表示，词表内外是否同路
信念表示语义价值图 / 3D 场景图 / 对象实例记忆 / 无显式地图空间信息是否持久化，误差是否可分离
选项空间前沿 / 路点 / 子图 / 路径树决策候选的粒度与结构，是否暴露在途收益
策略训练零样本拆解 / 模仿+RL / 端到端 / LLM 推理训练数据量、是否需要特权信息、推理成本

按四轴把代表方法摊开，可见三条趋势。目标接口从文本走向掩码与图像：ZSON（Majumdar 等，2022，ImageNav 训练的零样本 ObjectNav）用 CLIP 嵌入做接口替换；OVSegDT 进一步把目标二值掩码编码进观测，把「找什么」与「在哪里」分开。第 077 讲的图像条件查询与第 078 讲的 OVAL 记忆描述符都在同一方向上扩展。信念表示从栅格走向结构：VLFM 的价值图、SG-Nav 的分层场景图、GOAT 的实例记忆，各自用不同方式对抗感知噪声。选项空间大部分方法仍停留在一组独立候选：前沿或路点逐个打分，直到 REST 把路径树作为设计对象。四个轴的组合决定方法的能力边界，单看某一个指标会丢信息。

2. 四套评测协议不可互排

开放词汇篇内部至少存在四套协议，数字必须分组。HM3D-OVON（Yokoyama 等，2024）用 181 个真实扫描场景（训练 145、评估 36，无场景重叠）、379 个目标类别与 15,661 个实例，评测分三档：Val Seen 79 类、Val Seen Synonyms 50 类、Val Unseen 49 类，类别按 SentenceBERT 余弦相似度切分且三档互斥。GOAT-Bench（Khanna 等，2024）在同一场景上串联 5 至 10 个目标，SUBTASK 成功判据为停止在目标实例 1 m 内，SPL 从上一子任务结束时智能体的位置起算。HSSD-rare（第 077 讲）用 17 个场景、1000 条 episode、559 个子类考察长尾，子类词表外比例 41.68%。标准主表（Gibson、HM3D v1/v0.2、MP3D）仍是 500 步、1 m 与 oracle 可见性的挑战口径，且 MP3D 的 21 类与 HM3D 的 6 类不可混谈。

一个具体的混排示例：REST 在 HSSD 上报告 56.7 SR，VLFM 在 HM3D v1 上报告 52.5 SR，两者数值接近，场景集合、动作预算与停止判据却都不同，不能据此判断方法强弱。可并排的只有同一表格内的行，跨表只能比较机制与方向。

3. 对照点一：OVSegDT 的感知接口与熵门控训练

OVSegDT 解决的是第 077 讲的检测瓶颈在端到端路线中的版本：策略不再依赖语义地图，观测直接包含目标掩码。六离散动作（停止、前进 0.25 m、左右转 30°、抬头/低头 30°），500 步预算，判据为停止在目标 1 m 内。观测 ot = (It, g, at−1, Mt)：RGB 帧经冻结 SigLIP 编码为 768 维，目标文本同维；上一动作是可学习 32 维嵌入；二值掩码经 ResNet9 编码为 128 维。拼接后的观测向量序列取最近 100 步送 4 层、8 头、隐藏 512 的因果 Transformer，动作头、价值头与分割头共享主干，整模型约 1.3 亿参数，推理只用 RGB。

训练把模仿与强化统一到单阶段。经典做法是先 DAgger 再硬切换 PPO，切换点靠手工设定；EALM 用策略熵连续调制两路损失。动作空间 |A| = 6 时最大熵 Hmax = ln 6 ≈ 1.79 nats，论文取上界 Hhigh = 0.42·Hmax ≈ 0.75、下界 Hlow = 0.20·Hmax ≈ 0.35，用指数滑动平均 Ĥt = αĤt−1 + (1−α)Ht（α = 0.95）平滑后计算

λt = clip((Hhigh − Ĥt) / (Hhigh − Hlow), 0, 1)，LEALM = λt·LPPO + (1−λt)·LBC

低熵（策略确信）时 λt 接近 1，以强化为主；高熵时以模仿为主。论文报告该调度把样本复杂度降低 33%，碰撞次数相对基线减少约 10%。训练分两段：先用真值分割训练 2 亿步，再用预测分割微调 1500 万步；分割来自现成的 YOLOE 模型。辅助分割损失为 Dice 与二元交叉熵之和，语义奖励为

Rsemt = λsem·(clip(dt−1 − dt) + clip(bt − bt−1))，λsem = 0.5

两项分别奖励测地距离下降与目标掩码像素面积增加。结果（HM3D-OVON，v3 全文表 1，SR / SPL 单位 %）：val unseen 44.7 / 20.6，val seen 43.6 / 20.1，val seen synonyms 40.1 / 17.9；未见划分反而比可见划分高 1.1 个百分点。对照同基准下的 DagRL 基线 18.3 / 7.9，增量 +26.4 与 +12.7；与带深度与里程计的 DAgRL+OD（37.1 / 19.9，OVSegDT 表 1 转引作 19.8）相比，SR 仍高 7.6。掩码接口把「目标类别泛化」的压力从策略权重转移到分割模型上，这是未见类别不掉的机制解释。分割源对照给出代价：真值掩码 69.3 / 39.1，直接用 YOLOE 28.8 / 14.0，按类别校准置信度后 35.6 / 16.2，再经预测掩码微调回到 44.7 / 20.6；推理时间从 107 ms 升到 132 ms（NVIDIA Jetson Orin，+23%）。失败构成（unseen，完整配置）总计 55.3%：探索失败 8.9%、目标识别失败 28.2%、忽略目标 15.8%、错停 12.5%、接近失败 18.2%（其中停得过远 12.0%）。识别仍是最大单项失分，与第 069 讲、第 077 讲的结论一致。

4. 对照点二：Graph-MambaNav 的结构化先验

第 065 讲的语言排序停留在「给候选打分」。Graph-MambaNav 把常识关系推进到图的计算顺序：节点按与目标的相关度排序，相关度由 LLM 给出的亲和矩阵初始化。设亲和矩阵 A，目标索引 i*，排序键为

hi = A[i, i*]，hi* = +∞，ρ = argsort(h)，xglo = Mamba(x[ρ])[ρ−1]

相关度低的节点排在前面，目标自身放在序列末尾，因果扫描让目标在更新时聚合到最丰富的上下文；ρ−1 把结果还原到原始节点顺序。空间模块把 GINE 局部消息传递与上述全局扫描相加，时间模块对每个物体的轨迹序列再做一次 Mamba 扫描（记忆长度 T = 35），目标条件的注意力从记忆里取出与目标相关的上下文，最后与 ResNet-18 全局特征、动作嵌入拼接送 LSTM 与 A3C。检测用 COCO 预训练 DETR，词表固定为 22 类，文本嵌入为 GloVe 300 维。

结果（AI2-THOR 与 RoboTHOR，SR / SPL 单位 %）：AI2-THOR 全轨迹 83.22 / 46.52，长轨迹子集（最短路径不小于 5）76.09 / 46.20；相对 TSOG（80.04 / 41.44）为 +3.18 与 +5.08；相对 CGI+GAIL（77.59 / 46.25）为 +5.63 与 +0.27；相对 M-MambaNav（81.24 / 46.60）为 +1.98 与 −0.08，路径效率基本持平。RoboTHOR 上 49.82 / 28.67，相对 CGI+GAIL（48.30 / 28.77）为 +1.52 与 −0.10。消融逐项：无扫描基线 63.83 / 33.75，加局部扫描到 66.15，加全局有序扫描升至 78.34 / 43.39（+12.19），再加时间扫描到 83.22 / 46.52（+4.88）；全局扫描换成随机顺序降到 73.67，说明收益来自排序而不只是 Mamba 结构。鲁棒性：把亲和矩阵 10%、20%、30% 的对称非对角项替换为随机值后，成功率从 83.22 降到 82.31、80.46、77.92；排序节点从 top-5 扩到全 22 类收益递减（77.05 → 83.22）。复杂度：12.58M 参数、23.47 GFLOPs、2.53 GB 显存、22.12 FPS，对照同配 Transformer 变体的 62.13M、82.39 GFLOPs、6.72 GB、11.32 FPS，参数量比 4.94、显存比 2.66、帧率比 1.95。结构化先验的收益取决于先验质量，先验被污染时收益会单调衰减，这条结论直接对应第 031 讲 L3MVN 与第 030 讲 ESC 的边界讨论。

5. 对照点三：REST 的选项空间重构

REST 把第三篇反复出现的「前沿打分」改写为「路径树选择」。信念层用 UFOMap 维护占用体素（体素 5 cm），语义层用「小 VLM 打标签 → 开放词汇检测器出框 → SAM2 类分割模型出掩码」的级联，按多视角置信加权投票写回体素；路图层用 RT-RRT* 维护以机器人为根的可行路径树；选项层先按泊松盘采样（半径 1.25 m）稀疏化视图点，再用信息增益阈值 τIG = 10 过滤，其中

r(θ|M) = |{v ∈ M ∩ F(θ) : Ivis(v,θ)·Iunk(v) = 1}|

统计相机位姿 θ 视锥 F(θ) 内可见且未知的体素数。保留的视图点作为终端，用欧氏斯坦纳树优化把独立路径压缩成共享主干：论文示例把树总长从 85 m 压到 47 m（−44.71%），压缩过程同时把决策点暴露在走廊分岔与房间入口。每段边被文本化为「已知实体与距离」加「未知区域体积与位置」，再由摘要模型生成子树描述，交给 LLM 以链式推理打分；为避免每步调用，系统只在两类事件触发 LLM：到达分支节点，或已承诺子树发生结构变化；无可信语义时回退到最近的视图点。策略层在 500 步预算内执行，仿真按 Habitat 2023 挑战设置（640×480、水平视场 79°、深度 0.5 至 5.0 m、六个离散动作，前进 0.25 m、转向 30°），全部组件免训练。

结果（SR / SPL 单位 %）：Gibson 85.1 / 53.5，HM3D v1 57.3 / 33.4，HSSD 56.7 / 29.1。HM3D v1 上相对 VLFM（52.5 / 30.4）为 +4.8 与 +3.0，相对 ApexNAV（59.6 / 33.0）为 −2.3 与 +0.4；HSSD 上相对 VoroNav（41.0 / 23.2）为 +15.7 与 +5.9。消融（HSSD）：去掉 LLM 推理只剩 29.1 / 18.7（SR −27.6），去掉斯坦纳压缩降到 53.1 / 25.3（SR −3.6、SPL −3.8）。失效边界写得直接：HM3D 扫描中的镜面与玻璃形成几何空洞，抬高信息增益，把智能体反复引向无进展的位姿，这是成功率低于 ApexNAV 的主因；HSSD 语义稀疏时逐点相似度易陷入局部最优，树结构按方向推理反而更稳。

6. 三个未解问题

长尾。第 077 讲给出长尾的量化起点：HSSD-rare 的子类词表外比例 41.68%，图像条件查询在静态评测里带来 +10.54 与 +6.37 个百分点，检测增强把在线成功率抬到 18.17 与 11.75，失败中超时占 55.3% 且其中只有 4% 进入过 2 m 邻域。本讲的 OVSegDT 把长尾压力转移给分割器：同一策略在真值掩码与预测掩码之间相差 24.6 个百分点（69.3 对 44.7），从开箱 YOLOE（28.8）到最终配置（44.7）由类别校准与预测掩码微调分两段补回（SR 约 +6.8 与 +9.1）。开放问题：子类级长尾的评测协议与分割器的类别校准能否标准化，即用一套与策略解耦的感知诊断，预测端到端系统的长尾上限。

验证。第 070 讲的 re-perception 用 +3.6、+4.3、+5.4（MP3D、HM3D、RoboTHOR）证明「回头看」的价值；第 076 讲的证据准入要求两次确认并限制深思次数。OVSegDT 的失败结构补上另一面：目标识别失败占 28.2%，忽略目标 15.8%，错停 12.5%，校准置信度与掩码微调主要降低的是错停与漏看。开放问题：验证机制的开销与收益何时平衡，需要一个把假阳性率、验证步数与最终成功率放进同一张曲线的协议。

记忆。第 073 讲显示模块化方法移除记忆后 SPL 从 17.6 掉到 9.4；第 078 讲的 VTM-Nav 跨幕记忆带来 4.6、2.0、0.8 个百分点（HM3D v0.1、v0.2、MP3D），OVAL 的终身协议达到 68.1 / 33.8。本讲三个对照点里，REST 的滚动时域树在单幕内重用路径结构，Graph-MambaNav 的时间记忆上限 35 步，跨幕持久化仍是空白。开放问题：终身评测的协议与遗忘代价，需要在受控步数、场景顺序与统计口径三处同时固定。

三个问题共享一条接口纪律：感知接口决定长尾上限，验证策略决定错停下限，记忆结构决定探索效率的复利。第五篇的真机章节会把这些量变成工程约束，第 081 讲先处理最基本的信任问题：仿真里的排序能否预测真机。

关键代码与解读

三段代码对应复盘章的三件工具：跨协议读数核对、EALM 熵门控、目标感知的节点排序。

片段 1：协议台账与 Wilson 区间

import math

def wilson(k, n, z=1.96):
    """成功率 k/n 的 Wilson 区间；比较前先看区间是否重叠。"""
    p = k / n
    d = 1.0 + z * z / n
    c = (p + z * z / (2.0 * n)) / d
    h = z * math.sqrt(p * (1.0 - p) / n + z * z / (4.0 * n * n)) / d
    return c - h, c + h

def comparable(a, b):
    """两项读数能否排序：差值区间不含 0 才给结论。"""
    la, ha = wilson(a["k"], a["n"])
    lb, hb = wilson(b["k"], b["n"])
    lo, hi = la - hb, ha - lb
    return lo, hi, (lo > 0.0 or hi < 0.0)

解读：（1）Wilson 区间在样本量小时比正态近似稳，长尾子类往往只有几百条 episode，这个选择影响结论。（2）差值区间由两个区间端点之差构成，这是保守的分布无关写法，结论比直接比较点估计少，但不会把小样本波动读成方法差距。（3）台账里每行必须带协议键：数据集、划分、步数与成功判据；缺键的行不进入排序，这是第 020 讲口径四元组的程序化版本。

片段 2：EALM 熵门控

import torch

def ealm_weights(logits, ema=None, alpha=0.95, h_low=0.35, h_high=0.75):
    """按策略熵在 PPO 与 BC 之间连续混合；低熵偏 PPO，高熵偏 BC。"""
    p = torch.softmax(logits, dim=-1)
    ent = -(p * torch.log(p + 1e-8)).sum(dim=-1).mean()
    ema = ent.detach() if ema is None else alpha * ema + (1 - alpha) * ent
    lam = ((h_high - ema) / (h_high - h_low)).clamp(0.0, 1.0)
    return lam, 1.0 - lam, ema

def ealm_loss(ppo_loss, bc_loss, lam):
    """两路损失的加权和；权重由熵连续给出，无需手工相位开关。"""
    return lam * ppo_loss + (1.0 - lam) * bc_loss

解读：（1）熵用批量均值再进 EMA，单样本熵抖动大，直接当权重会让损失在批次间震荡。（2）阈值以 nats 为单位：|A| = 6 时 Hmax ≈ 1.79，0.75 与 0.35 分别对应约 80% 与 95% 的头部动作概率，这是论文给出的解释，也是换动作空间时重新标定阈值的依据。（3）EMA 与梯度脱钩（detach），否则熵正则项的梯度会污染权重计算。（4）两路权重和为 1，等价于对总损失做凸组合；若改为两路独立系数，实际学习率会随熵漂移，复现时不可混用。

片段 3：目标感知的节点排序扫描

import numpy as np

def target_aware_order(affinity, target_idx):
    """h_i = A[i, i*]；目标置 +inf，相关度低的先扫描。"""
    h = affinity[:, target_idx].astype(np.float64).copy()
    h[target_idx] = np.inf
    order = np.argsort(h)
    inv = np.empty_like(order)
    inv[order] = np.arange(order.shape[0])
    return order, inv

def ordered_scan(x, order, inv, scan_fn):
    """重排、扫描、还原：排序决定信息沿哪条链路传播。"""
    return scan_fn(x[order])[inv]

def corrupt_affinity(affinity, ratio, rng):
    """按比例替换对称非对角项，用于先验鲁棒性消融。"""
    a = affinity.copy()
    n = a.shape[0]
    iu = np.triu_indices(n, k=1)
    pick = rng.choice(iu[0].shape[0], int(ratio * iu[0].shape[0]), replace=False)
    vals = rng.uniform(0.0, 1.0, size=pick.shape[0])
    a[iu[0][pick], iu[1][pick]] = vals
    a[iu[1][pick], iu[0][pick]] = vals
    return a

解读：（1）目标自身排到序列末尾，因果扫描下它聚合全部上下文；（2）还原步骤保证下游模块看到原始节点顺序，排序只是计算路径，不改变图结构；（3）污染函数与论文消融对齐：比例取 10%、20%、30%，对应成功率 82.31、80.46、77.92，这组读数是判断先验质量要求的最小证据。

常见坑

  • 跨协议并排数字：症状是把 REST 的 HSSD 56.7 SR 与 VLFM 的 HM3D 52.5 SR 放在一句话里比较。根因是数据集、预算与判据三处都不同。修复：横评表只保留机制列，数值列标注协议键；跨协议讨论限定方向与量级。
  • 可见与未见类别的方向误读：症状是假设所有方法在未见划分必然下降。根因是 OVSegDT 的掩码接口把泛化压力转移给分割器，unseen 44.7 高于 seen 43.6；而 DAgRL 的纯文本接口从 41.3 掉到 18.3。修复：读任何开放词汇结果先看目标接口，再解释两档差值的方向。
  • 版本与元数据混用：症状是引用 OVSegDT 时同时使用 arXiv 摘要页的 40.1 / 20.9 与 v3 全文表的 44.7 / 20.6。根因是摘要页元数据与全文版本更新不同步；同类的还有碰撞下降比例，摘要写 10%，按表 45.4 对 50.2 复算为 9.56%。修复：数字一律带版本号与表号，正文与元数据不一致时以全文表格为准并注明差异。
  • 把感知差距当方法差距：症状是用 OVSegDT 的 44.7 与真值掩码 69.3 比较并宣称策略不足。根因是两行使用不同分割源。修复：按分割源分列（真值、现成预测、校准、微调），报告时给出差值 24.6，并把校准与微调两段的 SR 增益（约 +6.8 与 +9.1）分开。
  • 小样本消融过度解读：症状是用 50 条 episode 的消融差值给方法排序。根因是成功率区间宽，十个百分点以内的差常不显著。修复：所有消融记录 episode 数与分层结构，用片段 1 的区间判据决定是否下结论；Graph-MambaNav 的三次重复与标准差是正面示例。

    提示
    压缩牺牲的是各路径独立最优，换来共享主干与更清晰的决策结构；LLM 在分支级别的推理粒度更粗，正好匹配「选区域」的决策。反例条件：目标位于某终端子树的深处且期间出现更优分支时，承诺到共享主干会延迟重新规划；若分支事件触发不敏感，滚动时域的重规划收益被削弱。

小结

  • 四轴坐标（目标接口、信念表示、选项空间、策略训练）与口径四元组一起使用：先对齐任务、数据、指标、平台，再谈方法差异。
  • 2026 对照点一（OVSegDT）：1.3 亿参数纯 RGB，掩码接口加 EALM 单阶段训练，HM3D-OVON v3 表 1 的 val unseen 为 44.7 / 20.6（SR / SPL），未见高于可见 1.1 点；与真值掩码相差 24.6 点，感知是上限。
  • 对照点二（Graph-MambaNav）：LLM 亲和先验同时定义边权与扫描顺序，AI2-THOR 83.22 / 46.52；全局有序扫描贡献最大（+12.19）；先验污染 10% 至 30% 使成功率降 0.91 至 5.30 点。
  • 对照点三（REST）：选项空间改为路径树，斯坦纳压缩 85 m 至 47 m；Gibson 85.1 / 53.5、HM3D v1 57.3 / 33.4、HSSD 56.7 / 29.1；去掉 LLM 推理损失 27.6 点。
