第一篇 · 仿真环境与训练框架

第 021 章：使用域随机化增强泛化能力

让策略不再"死记"某一种物理世界：把质量、摩擦、增益、光照与传感器噪声都变成每回合变化的分布，用"训练分布的宽度"换来真实世界里的鲁棒性。

  • 主题：强化学习 / 域随机化与迁移
  • 相关组件：Isaac Sim（物理材质、驱动增益、相机与灯光）
  • 预计学时：60 分钟
  • 前置章节：第 020 章

学习目标

  • 理解仿真到现实差距（sim2real gap）的主要来源：动力学、感知、时序与接触建模。
  • 掌握域随机化（Domain Randomization, DR）的核心思想：在 MDP 分布上训练，让现实成为分布的一个采样。
  • 会选取并采样值得随机化的参数：质量、摩擦、驱动增益、传感器噪声与外观；理解"覆盖条件"。
  • 会实现"每回合采样一次"的随机化流程，并说清它与每步采样在语义上的差别。
  • 会设计三协议评估（标称/训练分布/偏移分布），用鲁棒性曲线衡量泛化。

背景与动机

前二十章的策略都在"一个确定的世界"里学会技能：固定的质量、固定的摩擦、固定的灯光。但真实世界与仿真永远存在差距：连杆比 CAD 重 5%、地面摩擦比参数低 20%、相机会有噪声与过曝、通信还有一个控制周期的延迟。把策略直接搬到真机，这些"没训练过的小差别"会系统性地破坏性能。

域随机化的回应很务实：既然无法把仿真对得绝对准，就把所有"不确定的量"变成训练时的随机分布，让真机成为分布中的一个采样。它不依赖精确系统辨识（067 章），是 sim2real 的默认武器（065 章展开）。

核心原理

1. 差距从哪来，随机化就覆盖哪

sim2real gap 分四类，域随机化对前三类最有效：

来源典型误差量级随机化项目
动力学参数质量 ±5–15%、摩擦 ±20–50%、增益 ±10–30%刚体质量/惯量、材质摩擦与弹性、驱动刚度阻尼
感知参数相机噪声 σ≈2–10 mm、光照 ±50%、延迟 10–50 ms传感器噪声、灯光强度/颜色、纹理与背景
时序控制延迟 1–3 个周期动作延迟缓冲、观测延迟
未建模效应弹性、回差、多路径，无法参数化随机化覆盖不到：需要系统辨识或鲁棒算法（067/070 章）

范围选择第一原则是覆盖条件：真机参数必须落在训练分布内；摩擦真值 0.35 时应覆盖 0.2–0.6，0.05–0.15 这样的窄区间根本够不到真机。第二原则：只随机化真正不确定的量（重力 9.81 是准的，±20% 只是白加难度）。

2. 分布上的训练：目标函数变了

域随机化把单一 MDP 变成 MDP 的分布 p(M)：

JDR(π) = EM∼p(M) [ J(π, M) ] M 包含动力学参数、外观与传感器配置；每个回合采样一个 M，整个回合内保持不变

两条推论。第一，策略的性能曲线随训练分布宽度呈"先升后降"：分布太窄，覆盖不到真机（脆弱）；太宽，策略被迫在所有参数下都"保守求稳"，平均性能下降（可能保守到完不成任务）。合适的宽度是"刚好覆盖真机不确定性 + 一点余量"。第二，每回合采样一次、回合内固定：MDP 假设奖励与转移只依赖状态动作，回合内改变参数会破坏这个假设（策略观察到"物理变了"却看不到原因）；每回合固定则每个回合仍是一个合法 MDP，只是从不同 MDP 里抽的。每步随机化只在特定场景使用（如研究在线自适应），并要在观测里给足信息。

4. 随机化项的优先级量化

不是所有随机化项对任务的影响都一样。把各项折算成"占任务容差的比例"，优先级自然浮现（以到达/推挤类任务、成功阈值 5 cm 为例）：

项目量级折算对任务的影响优先级
深度噪声 5 mm占 5 cm 阈值的 10%接近判定边界时的抖动中（感知类任务高）
质量 ±20%重力力矩需求同步变化约 ±20%推挤与抓取时接触力变化高（接触任务）
摩擦 0.2–0.6可达驱动力变化约 3 倍推不动、打滑高（接触任务）
增益 ±30%跟踪误差按比例放大到位时间与稳态偏差变化中
动作延迟 2 步占回合 200 步的 1%闭环相位滞后，快速任务明显中高（高速任务高）

折算方法：把参数波动翻译成"任务成功条件的直接量"（距离、接触力、时间）。某几项合起来把不确定性推过容差的一半时，它们值得优先随机化；折算后远小于容差的项（如关节噪声 2 × 10⁻³ rad 对 5 cm 判定）可以放到第二批。这张表同时给出范围记录口径：每项写成"名义值 × 倍数"或绝对区间，连同评估结果一起归档。

5. 性能-宽度权衡的量化

DR 的收益与代价可以写成一条可测量的曲线。训练分布取摩擦区间 [μ_min, μ_max]，评估用鲁棒性曲线扫过更大的范围：

覆盖条件：μ真机 ∈ [μmin, μmax]；越界距离 dshift = |μtest − 边界| 示意量级：分布内性能比标称低 5–10 个百分点；越界后的退化大致随 d_shift 线性，每超界 0.1 单位掉约 10 个百分点

两条读数方法：先看覆盖（曲线在训练区间内是否平坦，平坦说明该区间内策略稳定）；再看斜率（边界外每 0.1 单位的性能损失，斜率越缓说明外推能力越强）。宽度选择据此制定：把区间端点扩到"真机值加 20% 余量"；若扩宽导致分布内性能明显下降，说明策略对参数仍然敏感，先检查范围是否过宽、策略是否被迫保守，再决定收窄还是继续训练。

6. 每回合采样与每步采样的形式差别

每回合采样一次不只是工程习惯，它对应另一套数学结构。回合内固定的参数 M 让回报、转移与最优策略都属于同一个 MDP：

回合内固定：JDR(π) = EM[ J(π, M) ]，每个回合是标准 MDP 每步变化：P(s′ | s, a, M_t) 的 M_t 隐藏且不可预测，问题退化为部分可观测

形式差别带来结果差别：回合内固定时，策略可以通过前几步交互把当前参数"隐式估计"出来，表现得像自适应控制器；每步变化时，同一个动作的效果每 33.3 ms 就换一个分布，值函数的目标本身带噪，学习信号被稀释。若确实需要每步变化（研究在线适应、对抗扰动），正确做法是把参数信息放进观测或让历史帧隐含它，把问题重新变成可观测 MDP，这条准则在 052 章的部分可观测理论里会再次出现。

7. 完整算例：摩擦不确定下的推挤任务

取一个能手算的任务：推动 0.2 kg 的方块，水平推力 1.0 N，持续 0.5 s 后松开；重力加速度 9.81 m/s²。方块启动后受滑动摩擦 μmg，净加速度 a = (F − μmg)/m，位移 = ½aT²。把不同摩擦下的结果列表。

0.20.393.040.38
0.30.592.060.26
0.4（标称）0.781.080.13
0.50.980.100.01
0.51 及以上≥1.000（推不动）0.00

这张表把"摩擦是最优先随机化项"的断言量化了：同一个动作，在不同摩擦下的位移相差 30 倍以上（0.38 m 对 0.01 m），而且存在硬边界 μ = F/(mg) = 1.0/1.962 ≈ 0.51，越过这条线方块纹丝不动。只在标称 μ=0.4 下训练的策略（目标推 0.13 m）遇到真机 μ=0.5 时，同样推力只能得到 0.012 m 的位移，任务失败；要让策略在 [0.2, 0.6] 全域都能完成任务，输出力必须覆盖 0.39–1.18 N 的范围，跨度 3.0 倍，这正是训练分布 [0.2, 0.6] 存在的意义。反过来，如果真机摩擦已经测得很准（比如系统辨识给出 0.35±0.03），随机化范围收窄到 [0.3, 0.45] 即可，宽范围只会浪费策略容量。

算例还给出一个自检方法：用"力跨度"核算分布宽度是否够用。计算范围两端所需的最小推力（μmax·mg = 1.18 N 与 μmin·mg = 0.39 N），若策略实际输出力的可达范围覆盖不了这个跨度，随机化范围再宽也学不出可用策略，应该先检查动作空间与控制器增益。

8. 边界与失效模式

  • 时序延迟的相位预算：控制频率 30 Hz 时，2 个 RL 步的延迟等于 66.7 ms。延迟对闭环的破坏按相位计算：2πfτ，频率 1 Hz 的任务损失约 24° 相位余量，2 Hz 损失约 48°，经典 45° 余量线对应约 1.9 Hz。若任务的闭环带宽高于这条线，只随机化延迟而不训练"提前量"，策略在仿真里就会振荡；判据是把任务带宽与 1/(2πτ) 比较，量级接近时延迟随机化必须与动作历史一起进观测。
  • 极端参数组合导致物理不收敛：质量下限 0.16 kg（0.2×0.8）配上刚度上限（名义 ×1.3）的接触，冲量峰值可能超出物理步的稳定处理范围，症状是物体抖动、穿模甚至 NaN。修复：采样后做可行域过滤（同时约束质量与增益的组合），或提高物理子步数；过滤规则要写进随机化器，不要隐式依赖默认参数。
  • 独立采样与真机联合分布的错位：真机的质量与摩擦往往相关（同一种材料既重又滑），独立均匀采样会在真实中不可能出现的角落（轻且极滑、重且极涩）上浪费策略容量。若已有多台真机或辨识数据，用联合分布替代独立分布；没有数据时至少把"物理上不可能"的组合裁掉。
  • 随机化修不了模型偏差：参数化随机化只能表达"参数不确定"，弹性变形、齿轮回差、相机卷帘这类未建模效应不在参数空间里。症状：仿真里的偏移评估很好看，上真机仍出现同样的系统性失败。判据：若把随机化范围扩大到真机误差量级后，仿真里仍复现不出真机的失败模式，问题在模型结构，需要系统辨识（067 章）；继续加宽分布解决不了这类系统性失败。

实现思路与设计

为已有环境添加域随机化的步骤：

  1. 先建基线（无随机化策略在标称环境上的成功率，后面所有比较的参照）。
  2. 列清单定范围（照抄上表起点，按任务裁剪；范围写进配置文件）。
  3. 实现每回合采样（reset 里采样一个参数向量；写入引擎属性的同时缓存一份供日志）。
  4. 覆盖传感器与外观（噪声进观测流水线、灯光/纹理改动场景；注意与 020 章的评估隔离）。
  5. 训练与记录（随机化参数进入 info 与 TensorBoard，训练曲线要能按"参数轴"切片分析）。
  6. 三协议评估（标称 / 训练分布 / 偏移分布；固定种子；报告成功率与最差参数区间）。
设计思维：为什么"偏移评估"比"分布内评估"更能说明问题？

在训练分布内评估告诉你"策略学会了分布"；把摩擦、质量推到训练范围之外评估，才告诉你"策略是否有真正的适应力"。两类结果的差值就是 DR 的鲁棒性红利。真机部署前，你希望看到的是"分布内 95%、偏移 20% 仍有 70%"这样的曲线；它比单点数字承载更多信息，是 065 章 sim2real 决策的核心依据。

关键代码与解读

片段 1：每回合一次的物理参数随机化（属性写入接口随版本变化，以官方文档为准）

import numpy as np

class DomainRandomizer:
    """域随机化器：每个回合采样一次物理参数，回合内保持不变。"""
    def __init__(self, seed):
        self.rng = np.random.default_rng(seed)   # 独立随机流：与 012 章的采样器分开
        self.params = {}                          # 当前回合的参数：供日志与评估切片

    def sample(self, task_object, robot):
        p = self.params
        p["object_mass"] = 0.2 * self.rng.uniform(0.8, 1.2)      # 质量 ±20%
        p["table_friction"] = self.rng.uniform(0.2, 0.6)          # 摩擦：覆盖真机不确定性
        p["gain_scale"] = self.rng.uniform(0.7, 1.3)              # 驱动刚度缩放 ±30%
        p["act_delay_steps"] = int(self.rng.integers(0, 3))       # 动作延迟 0-2 个 RL 步
        # 写入物理：刚体质量、材质摩擦、驱动器增益（具体 API 随版本变化）
        task_object.set_mass(p["object_mass"])
        set_material_friction(task_object, p["table_friction"])   # 示意封装
        robot.apply_gain_scale(p["gain_scale"])                   # 示意封装：控制器增益缩放
        return p

解读：三个设计点。第一，随机流独立：域随机化器拥有自己的 Generator（012 章纪律），与初始状态采样器分开，调试时你能单独锁定"物理参数"或"初始状态"的随机性，定位问题快得多。第二，参数先存字典再写引擎：self.params 是"这一回合的物理世界身份证"，进 info、进日志、进评估切片都靠它；如果只写进引擎不保存，事后分析"成功率是不是随摩擦下降"就无从谈起。第三，延迟用整数步数：连续延迟（如 1.7 个周期）在实现上通常量化为 1–2 步的缓冲更简单（动作历史队列实现），量化误差本身也是合理的随机化对象。

片段 2：动作延迟缓冲与传感器噪声

import numpy as np
from collections import deque

class DelayBuffer:
    """动作延迟：把策略动作放进队列，滞后 k 步输出，模拟真机通信延迟。"""
    def __init__(self, max_delay=2, num_joints=7):
        self.queue = deque(maxlen=max_delay + 1)
        self.action = np.zeros(num_joints)  # 初始动作：全零（稳定起点）

    def push(self, action, delay_steps):
        self.queue.append(np.asarray(action, dtype=np.float32).copy())
        # queue 里第 (len-1-delay) 个元素才是"应该执行"的动作
        idx = len(self.queue) - 1 - delay_steps
        self.action = self.queue[max(idx, 0)]  # 早期队列不满时退化为最新动作
        return self.action

def add_sensor_noise(obs, rng, depth_sigma=0.005, joint_sigma=0.002):
    """观测噪声：深度（米）与关节量（弧度）分别按传感器手册量级加高斯噪声。"""
    noisy = np.asarray(obs, dtype=np.float32).copy()
    noisy[-6:] += rng.normal(0.0, joint_sigma, size=6)   # 假设末 6 维是关节类量
    # 深度通道单独处理（此处示意）：真实管线里深度图加噪在像素级进行
    return noisy

解读：这两个小工具代表 DR 的"非物理"部分。DelayBuffer 用最小实现演示了延迟的本质，策略看到的世界永远慢 k 步：动作要经过队列滞后发出，如果只延迟动作而观测是即时的，任务会变得"可控但别扭"；真实系统里观测与动作都有延迟，严谨的实现会双向加延迟。max 保护的退化逻辑处理了"队列还没填满"的前几步。add_sensor_noise 的默认 σ 取 5 mm（深度）与 2e-3 rad（关节），量级依据是真实传感器手册（ToF 深度噪声、编码器分辨率与差分噪声），噪声量级永远要有真实来源，随手写 0.1 会把任务变成噪声识别游戏。

片段 3：三协议评估与鲁棒性曲线

import numpy as np

def eval_protocols(model, make_eval_env, seeds=range(50)):
    """三协议评估：标称 / 训练分布 / 偏移分布，全部用固定种子。"""
    protocols = {
        "nominal": {"mass_scale": 1.0, "friction": 0.4, "gain_scale": 1.0},
        "in_distribution": None,        # None = 用随机化器采样（训练分布）
        "shifted_friction": {"mass_scale": 1.0, "friction": 0.8, "gain_scale": 1.0},
    }
    results = {}
    for name, fixed in protocols.items():
        scores = []
        for seed in seeds:
            env = make_eval_env(seed=seed, fixed_params=fixed)  # 固定参数注入评估环境
            sr = rollout_success(model, env)                    # 单回合成功判定
            scores.append(sr)
        results[name] = float(np.mean(scores))
    print({k: f"{v:.0%}" for k, v in results.items()})
    return results

解读：这套评估把"泛化"从形容词变成数字。三个协议的分工：标称回答"最理想情况下多强"；训练分布回答"学会这个分布了吗"（对比标称的下降幅度=随机化的代价）；偏移分布（摩擦 0.8，超出训练上限 0.6）回答"分布之外还有多少适应力"（普遍会掉分，但掉多少决定能不能上真机）。所有协议共享同一批评估种子，且评估环境用 fixed_params 完全接管随机化，这是 4 节纪律的实现：只要真实参数能映射到某个 fixed_params，你就能在仿真里"彩排"真机表现。写完这套评估，本书第一篇的能力（环境、接口、奖励、随机化）就全部闭环了。

常见坑

  • 范围过宽或过窄：过宽导致策略"处处保守"、任务学不会；过窄覆盖不到真机。修复：从窄起步、按覆盖率与评估曲线逐步放宽（ADR 思想）。
  • 随机化不含覆盖条件的量：把重力随机化 ±20% 只是白加难度；只随机化真正不确定的参数。
  • 每步随机化：回合内物理不断变化，MDP 假设破裂、策略行为混乱。修复：每回合采样一次、回合内固定（除非研究在线自适应并给足观测）。
  • 评估分布与训练分布混用同一随机化器：评估结果不可复现、与训练数字不可比。修复：评估用固定参数集（片段 3），训练随机化器只服务训练。
  • 只报单点数字：只报"分布内 95%"隐藏了偏移风险。修复：三协议 + 鲁棒性曲线（摩擦/质量扫描）一起报，参数范围与结果同档存档。
  • 极端参数组合不收敛：质量下限配刚度上限时接触冲量过大，物体抖动、穿模或出现 NaN。修复：采样后过滤不可行组合（把约束写进随机化器）、必要时提高物理子步；把"物理异常计数"接入训练日志。
  • 范围写死在代码里：采样区间散落在 reset 的各个角落，实验记录只剩一句"当时放宽了摩擦"。修复：全部范围进配置文件，参数向量进 info 与 TensorBoard，评估时可按参数轴切片。

练习与思考

  1. 为你的任务写一张随机化清单：项目、分布、范围、以及"真机该项可能的真值"估计（覆盖条件检查）。★
    提示
    每个范围都要能回答"真机的值会落在里面吗"；答不上来的先别随机化，或把范围放宽一档。
  2. 实现摩擦扫描：固定种子集，在 μ = 0.1–1.0 中取 7 个点评估同一模型，画出鲁棒性曲线并标出训练分布边界。★★
    提示
    曲线在分布内应平坦、边界外开始下降；下降的斜率即"外推能力"，对比无 DR 基线的曲线体会差异。
  3. 对照实验：无 DR 与有 DR 两个模型，在三协议下评估。预测哪一列差距最大，并解释"DR 用分布内性能换偏移性能"的权衡。★★
    提示
    无 DR 在标称常更强、偏移骤降；DR 标称略低但偏移稳健。差值是迁移决策的依据。
  4. 实现 ADR 雏形：以最近 N 个回合的成功率作为信号，成功率高于 80% 时把摩擦范围上限扩大 10%，低于 50% 时收回，观察范围如何自动收敛。★★★
    提示
    ADR 的核心是"随能力成长扩范围"；注意用固定评估集判断能力，别让训练随机性干扰扩张决策。
  5. 实验设计：把动作延迟从 0 步增加到 2 步，预测任务成功率与策略行为（提前量、振荡）的变化，并说明为什么"延迟"是最容易被忽略又最伤迁移的随机化项。★★
    提示
    延迟下策略必须学会"预判"；真机的通信与控制周期延迟常被低估，导致仿真里"反应灵敏"的策略上机后频出过冲。
  6. 按 7 节的模型复算：0.2 kg 方块、推力 1.0 N、持续 0.5 s，用 a = (F − μmg)/m 算出 μ = 0.2、0.4、0.5 三档的位移，并求出"推不动"的临界摩擦；解释为什么临界值随推力线性移动。★★★
    提示
    临界条件 F = μmg，解出 μ* = F/(mg) = 1.0/1.962 ≈ 0.51；推力加倍则临界值加倍，这条线决定动作空间需要多大的力上限。
  7. 计算时序预算：控制周期 1/30 s、延迟 2 步时，闭环带宽 2 Hz 的任务损失多少相位余量；若要保留 45° 余量，延迟最多允许几个 RL 步？★★
    提示
    相位损失 = 2πfτ，τ = 2/30 s；45° 对应 0.785 rad，反解 τ 再换算成步数，会得到 1 步左右的结论。

小结

  • 域随机化在 MDP 分布上训练（JDR = EM∼p(M)[J(π,M)]），让真机成为分布中的一个采样；它处理参数不确定性，不修复模型偏差。
  • 随机化清单：质量、摩擦、增益、延迟、传感器噪声、光照外观；只随机化不确定的量，范围必须满足覆盖条件。
  • 每回合采样一次、回合内固定；独立随机流、参数存档（进 info 与日志）。
  • 评估三协议（标称/训练分布/偏移分布）+ 鲁棒性曲线；DR 是用分布内性能换偏移性能的取舍。
