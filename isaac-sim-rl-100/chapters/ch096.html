第 096 章：实现无人机飞行控制

换一个平台：四旋翼只有一个推力方向，却要管六个自由度。本章讲透"倾斜才能飞"的欠驱动本质、级联控制与 RL 的分工，以及飞行仿真到现实的落差清单。

  • 主题：系统集成 / 欠驱动飞行平台与 RL
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：60 分钟
  • 前置章节：第 095 章

学习目标

  • 理解四旋翼的欠驱动本质：4 个输入、6 个自由度，以及"倾斜产生水平力"的因果链。
  • 掌握经典级联控制（位置→姿态→角速度→电机）的分工与频率分层，知道 RL 适合接在哪一层。
  • 会用四元数表达并控制姿态，避免欧拉角在大俯仰角下的万向锁。
  • 会搭建四旋翼 RL 环境：观测、奖励、推力预算、域随机化与延迟建模。
  • 能列出一份"仿真到现实"的差距清单：电机时间常数、阻力、地效、传感器延迟。

背景与动机

前十四章的手法都长在"轮子与关节"上，本章开始转向特殊平台。四旋翼（quadrotor）最反直觉：它只有 4 个电机，却要控制 6 个自由度（3 位置 + 3 姿态）。飞手说"想往前就往前压杆"，物理上真正的因果是：先低头倾斜，推力方向随之向前，水平分力把你带着走，这意味着"控制位置"和"控制姿态"永远纠缠在一起。

这个欠驱动结构让无人机成为飞行控制与 RL 研究最经典的平台：题目足够难（非线性、耦合、安全边界敏感），又足够干净（动力学可简化建模）。本章讲两条技术路线，经典级联控制与学习端到端，的分工，以及飞行系统特有的仿真到现实落差清单。

核心原理

1. 四个输入、六个自由度：欠驱动的数学

四旋翼的合推力沿机体 z 轴（机身法向），四个电机转速决定合推力大小与三轴力矩。简化动力学（忽略气动，质量为 m、惯量矩阵 J）：

m·ẍ = R(q)·(0, 0, T) − (0, 0, mg)，  J·ω̇ = τ − ω × (Jω) R(q) 是机体姿态旋转矩阵；T = Σ 四电机推力；τ 由推力差产生（横滚/俯仰）+ 反扭矩差（偏航）

数自由度：控制输入 4（T 与 τ 三维），状态 12（位置、速度、姿态、角速度），可独立指令的只有 4 个"加速度方向"，姿态的三个自由度不能任意指定：你无法同时"朝北、朝东、朝上"。这就是欠驱动：位置的实现必须经由姿态的倾斜。

2. 悬停与推力预算：飞得起来只是起点

悬停时 T = mg。设推力冗余比（推力重量比 T/W）为 k，则最大水平加速度大致为

ah,max ≈ g·√(k² − 1) k=1.4（总推力余量 40%）⇒ a_h ≈ 9.6 m/s²；k=1.1 ⇒ 仅 4.5 m/s²

再含爬升需求：需要竖直加速度 az 时可用水平加速度进一步压缩。这块"推力预算"决定了机动的物理上限，也是训练中必须准确建模的部分，训练时给足推力（k=2.0）、部署时只有 k=1.3，策略会在真机上"动作做不出来"直接摔机。按真机的连续推力设定 k，并用域随机化抖动 ±10%。

3. 姿态动力学：小角度与大角度的分水岭

小角度下，横滚角 φ、俯仰角 θ 与水平加速度近似线性（ax ≈ g·θ）；超过约 30° 后非线性显著，欧拉角也不再安全，俯仰到 ±90° 时万向锁出现（第 086 章）。所以飞行控制器一律用四元数/旋转矩阵表达姿态：

姿态误差 eq = 2·vec(qcur−1 ⊗ qdes)（小角度近似） 角速度环的期望力矩 τ = Kp·eq − Kd·ω + ω×Jω（前馈补偿陀螺项）

注意最后一项 ω×Jω 是姿态动力学里的科氏/陀螺耦合项：高转速翻滚时它显著，不补偿会持续振荡。这也是"仿真训练的端到端策略在剧烈翻滚时表现差"的原因之一，网络得从数据里重新发现这一项。

4. 级联控制与频率分层

环输入→输出典型频率带宽量级
位置环（外）位置误差 → 期望加速度/姿态20–50 Hz1–3 rad/s
姿态环（中）姿态误差 → 期望角速度200–500 Hz10–20 rad/s
角速度环（内）角速度误差 → 力矩 → 电机指令500–1000 Hz50+ rad/s

外环的期望姿态由"要达到的加速度"反推（称为姿态解算或推力方向映射），这也是 RL 的天然接入点：让 RL 学 20–50 Hz 的位置层（输出期望加速度/速度），底层 500 Hz 的姿态角速度环用经典控制器保证飞行。这比端到端（观测→电机 PWM）样本效率高一个量级，稳定性也有保证，与第 087/092 章"学习高层、经典底层"是同一分工哲学。

5. 仿真到现实的落差清单

  • 电机动态：真实无刷电机+桨的转速响应时间常数 20–50 ms；仿真里常是瞬时或 5 ms。造成相位滞后、闭环带宽被高估。
  • 气动效应：平飞阻力（与速度平方成正比）、桨叶挥舞、地效（贴近地面时升力增加 10%–20%）、涡环（垂直下降时的气动失稳）。仿真若无这些，策略学会的"猛降"手法真机会失控。
  • 传感器延迟：IMU 1–5 ms（内环可用），但位置/速度来自视觉或动捕，延迟 10–40 ms，位置环在仿真里若零延迟，真机上振荡。
  • 质量与惯量：电池位置、载荷安装都改变惯量矩阵（可达 ±20%），直接影响姿态环增益。
  • 通信与指令量化：遥控/上位机链路 10–50 ms 抖动；电机指令 16 位量化。

实现思路与设计

  1. 任务：从起点起飞到目标点悬停（位置误差 <0.1 m、速度 <0.2 m/s），保持 5 秒后判定成功；目标点在工作空间内随机。
  2. 观测：位置误差（3）+ 线速度（3）+ 旋转误差向量（3，第 086 章工具直接复用）+ 角速度（3）+ 上一动作（4）= 16 维。全部归一化：位置 ÷5 m、速度 ÷5 m/s、角速度 ÷10 rad/s。
  3. 动作：期望加速度（3 维，限幅 ±8 m/s²）+ 偏航角速度指令（1 维），交给底层级联控制器转成电机指令。比直接输出 4 个电机转速收敛快 5–10 倍。
  4. 奖励：r = −‖ep‖ − 0.5·max(0, 倾斜角−30°)² − 0.05·‖ω‖² − 0.02·‖Δa‖² − 0.01（时间税）+ 1.0（悬停成功）。倾斜惩罚防止"倒飞"式激进机动。
  5. 课程：悬停（目标=起点）→ 1 m 内点到点 → 5 m 内 → 加入风扰（侧向 0–2 N）与目标随机速度。
  6. 域随机化：质量 ±10%、惯量 ±20%、电机时间常数 20–50 ms、阻力系数 ±30%、位置观测延迟 10–40 ms、重力 ±1%。
  7. 评估：位置误差收敛时间、悬停 5 秒内的位置 RMS（抖动指标）、抗风扰恢复时间、以及"倾斜角 P95"（安全性）。
设计思维：为什么高空悬停任务还要练"低速点到点"？

从"原地悬停"到"飞到 5 m 外的目标"，难度跳变发生在"需要大角度倾斜 + 精确减速刹停"的组合上，这正是欠驱动系统最难的机动（减速必须反向倾斜，而反向倾斜的瞬间会有掉高趋势）。课程中间必须有"短距离点到点"这一档，它让策略先学会"倾斜、平移、反向倾斜刹车"的基本节奏，再扩展距离。跳过这一档，训练会卡在"能悬停但一到点就冲过头"。

关键代码与解读

片段 1：四旋翼动力学步进（简化模型）

import torch

def quadrotor_step(pos, vel, quat, omega, thrust, torque, dt,
                   mass=1.2, inertia=(0.01, 0.01, 0.02), k_drag=0.15):
    """简化四旋翼动力学：欧拉积分。thrust 沿机体 z 轴，torque 三轴。
    真机建模还要加电机一阶滞后与气动项；这里是 RL 训练的最小集。"""
    g = 9.81
    # 1) 机体 z 轴在世界系的方向：旋转矩阵的第三列（四元数直接算）
    w, x, y, z = quat.unbind(-1)
    R_z = torch.stack([2 * (x * z + w * y),
                       2 * (y * z - w * x),
                       1 - 2 * (x * x + y * y)], dim=-1)   # (B,3)
    # 2) 平动：推力沿机体 z + 重力 + 线性阻力（简化）
    acc = (thrust.unsqueeze(-1) * R_z - torch.tensor([0., 0., g])) \
          - k_drag * vel
    vel = vel + acc * dt
    pos = pos + vel * dt
    # 3) 转动：角加速度 = J^{-1}(τ − ω×Jω)；陀螺耦合项在大角速度时不可忽略
    J = torch.tensor(inertia)
    gyro = torch.cross(omega, omega * J, dim=-1)             # ω×(Jω)
    alpha = (torque - gyro) / J
    omega = omega + alpha * dt
    # 4) 四元数积分：q_dot = 0.5·q⊗(0,ω)；再归一化防漂移
    dq = 0.5 * quat_mul(quat, torch.cat([torch.zeros_like(w), omega], dim=-1))
    quat = quat + dq * dt
    quat = quat / quat.norm(dim=-1, keepdim=True)
    return pos, vel, quat, omega

解读：（1）机体 z 轴方向的解析式避免了完整旋转矩阵乘法，是四旋翼仿真的优化小技巧；（2）gyro = ω×(Jω) 这行是大角度机动的关键：横滚/俯仰/偏航三轴惯量不等（Jz=0.02 是 Jx 的两倍）时，快速旋转会互相"踢"，不建模就学不会剧烈机动；（3）四元数积分后强制归一化：数值漂移会让"姿态"慢慢变成非单位四元数，进而污染旋转矩阵，这是长期训练中静默积累的 bug；（4）k_drag=0.15 是低速近似的线性阻力，高速时真机阻力与 v² 相关，在域随机化里覆盖这个参数并在高速课程阶段换成平方阻力。

片段 2：RL 观测、动作与"倾斜约束"奖励

class HoverEnv:
    """指点悬停任务：RL 输出期望加速度 + 偏航角速度指令，底层级联控制执行。"""

    def __init__(self, num_envs, a_xy_max=8.0, yaw_rate_max=2.0, tilt_max=0.52):
        self.a_xy_max = a_xy_max          # 期望水平加速度限幅 8 m/s²
        self.yaw_rate_max = yaw_rate_max  # 偏航角速度限幅 2 rad/s
        self.tilt_max = tilt_max          # 安全倾斜角 30° = 0.52 rad

    def obs(self, pos_err, vel, quat, omega, prev_action):
        # 全部归一化：不同量纲的输入尺度一致，PPO 才稳（第 020 章的通用原则）
        return torch.cat([pos_err / 5.0, vel / 5.0,
                          orientation_error_vector(quat, self.quat_des),  # 第 086 章工具
                          omega / 10.0, prev_action], dim=-1)

    def reward(self, pos_err_norm, quat, omega, action, prev_action, hovering):
        # 倾斜角：机体 z 轴与世界 z 轴夹角 = arccos(R33)
        w, x, y, z = quat.unbind(-1)
        cos_tilt = 1 - 2 * (x * x + y * y)
        tilt = torch.acos(cos_tilt.clamp(-1.0, 1.0))
        r_pos = -pos_err_norm                                # 主任务（已归一化）
        r_tilt = -0.5 * (tilt - self.tilt_max).clamp(min=0.0) ** 2   # 只在超 30° 时罚
        r_rate = -0.05 * (omega ** 2).sum(dim=-1)            # 抑制旋转抖动
        r_smooth = -0.02 * ((action - prev_action) ** 2).sum(dim=-1)
        return r_pos + r_tilt + r_rate + r_smooth - 0.01 + 1.0 * hovering.float()

解读：（1）tilt 由四元数直接算（cos_tilt = R33），不经过欧拉角，这是飞行代码的规范做法；（2）倾斜惩罚取"阈值型"（超 30° 才罚）：若换作线性项，"该倾斜 25° 的正常机动"也会被罚掉，导致策略畏手畏脚不敢飞远，与第 084/085 章"惩罚只在临界区激活"的原则一致；（3）动作平滑项 r_smooth 在无人机上格外重要：上层 50 Hz 输出抖动会被姿态环放大成电机指令振荡，真机表现为电机啸叫与过热；（4）成功奖励与 hovering（需保持 5 秒）一次性给，防"掠过目标点"。

片段 3：电机混合器，从"总推力 + 三轴力矩"到四电机

import torch

def mixer(T, tau, arm=0.17, c_tau=0.016):
    """混合器（十字形布局示例）：把总推力 T 与三轴力矩 τ 映射为四个电机推力。
    arm 是电机到中心距离 0.17 m；c_tau 是反扭矩系数（力矩/推力比）。"""
    # 横滚力矩由左右推力差产生；俯仰由前后推力差；偏航由反扭矩差
    # 下面矩阵的行：[T, tau_x, tau_y, tau_z] = M @ [f1, f2, f3, f4]
    M = torch.tensor([
        [1.0, 1.0, 1.0, 1.0],                      # 总和
        [0.0, -arm, 0.0, arm],                     # 横滚（右减左）
        [-arm, 0.0, arm, 0.0],                     # 俯仰（前减后）
        [-c_tau, c_tau, -c_tau, c_tau],            # 偏航（正反桨反扭矩）
    ])
    f = torch.linalg.solve(M, torch.stack([T, tau[:, 0], tau[:, 1], tau[:, 2]],
                                          dim=-1).unsqueeze(-1)).squeeze(-1)
    # 物理约束：推力不能为负（电机只能正转），超出即饱和
    f = f.clamp(min=0.0)
    # 饱和后总推力会变；真机的"控制分配失效"就发生在这里，仿真必须复现
    return f

解读：（1）混合器矩阵是四旋翼的"传动机构"：理解它才能理解"为什么横滚力矩要牺牲总推力"，该布局下任意三轴力矩都对应各电机推力的增减组合，合推力随之波动；（2）clamp(min=0) 之后必须接受"实际总推力 ≠ 请求值"：这个差异在需求超过预算时（如同时要求大爬升率与大力矩）直接变成控制失效，仿真里如果不做这个饱和，策略会学到物理上做不到的机动；（3）混合器是"上层输出力矩、底层输出电机"这条分界线上的必经环节，端到端策略则把混合器隐含进网络里，那正是它样本效率低的来源之一。

常见坑

  • 用欧拉角做姿态表达：俯仰 ±90° 处万向锁；激进机动时误差符号跳变。修复：全程四元数，观测用旋转误差向量（第 086 章）。
  • 推力预算建模失真：仿真 k=2.0、真机 k=1.3，策略"要什么给什么"的动作真机根本做不到。修复：按真机连续推力设定并随机化 ±10%。
  • 电机动态忽略：零延迟电机让内环"完美"，真机 30 ms 滞后导致振荡。修复：一阶滞后模型（时间常数 20–50 ms）+ 域随机化。
  • 位置观测零延迟：位置环带宽被高估 2–3 倍。修复：位置/速度观测加 10–40 ms 延迟；训练期间随机采样。
  • 没有倾斜约束：策略学会"横着飞"（接近 90° 倾斜的极限机动），真机气动模型不符且极易失速。修复：阈值型倾斜惩罚 + 倾斜角 P95 评估门槛。
  • 奖励里的"悬停陷阱"：目标随机但策略学会"慢慢飘过去"，悬停抖动大。修复：成功判据要求速度 <0.2 m/s 并保持 5 s；用悬停 RMS 作为主评估指标。

练习与思考

  1. 用动力学公式计算：1.2 kg 四旋翼悬停所需总推力，以及 k=1.5 时的最大水平加速度。★
    提示
    T=11.8 N；a_h = 9.81×√(1.5²−1) ≈ 11.0 m/s²。注意这些是理想上限，实际还要分给爬升与姿态控制。
  2. 把倾斜约束从 30° 放宽到 45°，观察点到点任务的时间与"倾斜 P95"的变化。★★
    提示
    放宽会更快但更"野"；这是速度与安全裕度的直接权衡，用（完成时间，倾斜 P95）二维散点记录不同阈值的点。
  3. 用片段 3 的 mixer 计算：要求 T=12 N、τ=(0.2, 0, 0) 时四个电机的推力，并判断是否饱和。★★
    提示
    先解方程再检查负值；出现负推力就意味着该指令物理不可行，记录"饱和发生率"作为保护性指标。
  4. 设计实验：给位置观测量注入 0/20/40 ms 延迟，比较悬停位置 RMS 与带宽拐点。★★★
    提示
    延迟越大，闭环带宽必须越低；用位置误差的频谱峰值频率判断振荡频率，与 1/(2πτ) 的量级对照（第 088 章的经验在这里复用）。
  5. 在环境里加入地效（高度 <1 m 时推力 +15%）再训练降落任务，对比"无地效训练、有地效评估"的失败模式。★★★
    提示
    无地效训练的下降策略在 0.3–1 m 高度会"飘"（实际推力过大），表现为软着陆变悬停；有地效训练的策略会用更小的下降推力。

小结

  • 四旋翼是欠驱动系统：4 输入、6 自由度，"控制位置"必须先"倾斜姿态"；推力冗余比 k 决定机动上限（ah≈g√(k²−1)）。
  • 姿态全程用四元数；动力学里不能漏 ω×(Jω) 陀螺项；推力不能为负，混合器的饱和正是控制分配失效点。
  • 经典级联（位置 20–50 Hz / 姿态 200–500 Hz / 角速度 500–1000 Hz）与 RL 的最佳分工：RL 学期望加速度与偏航指令，底层经典环保飞行。
  • 域随机化清单要覆盖：质量/惯量、电机时间常数 20–50 ms、阻力、地效、位置观测延迟 10–40 ms；课程从悬停到短距点到点再到风扰。
