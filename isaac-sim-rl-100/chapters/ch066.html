第 066 章：实现域随机化迁移

与其把仿真调到最准，不如让策略见过足够宽的动力学分布，本章讲清域随机化的数学直觉、随机化什么、宽度如何权衡，以及自动域随机化（ADR）的渐进扩边机制。

  • 主题：Sim2Real / 训练期鲁棒化
  • 相关组件：Isaac Sim / Isaac Lab / PPO 训练环
  • 预计学时：60 分钟
  • 前置章节：第 065 章

学习目标

  • 会用数学形式描述域随机化：在动力学参数分布上优化期望回报，并说清它与鲁棒优化的联系与区别。
  • 会判断"哪些参数值得随机化"：高敏感度 × 高不确定性，以及必须保持的物理一致性。
  • 理解随机化宽度的权衡曲线：过窄覆盖不足、过宽策略保守，找出中间的最优区间。
  • 会实现逐回合随机化采样、参数日志与覆盖率检查。
  • 会实现 ADR（自动域随机化）的渐进扩边：用性能阈值驱动分布边界的扩张与回收。
  • 会设计域随机化的评估协议：参数网格扫描 + 鲁棒性能曲线。

背景与动机

第 065 章讲了部署机制，但还有一半问题在训练侧：仿真里的质量、摩擦、电机强度、延迟都只是估计值，真机参数可能偏差 10–30%。一种思路是把参数辨识得尽可能准（第 067 章），另一种思路是承认"不知道"并把这个不确定性显式地放进训练分布，让策略在训练时见过质量 ±25%、摩擦 0.3–1.2、延迟 0–2 步的成千上万种"平行世界"，任何落在该范围内的真机参数都不再是"分布外数据"。这就是域随机化（Domain Randomization, DR）。

它最早在视觉领域成名（随机纹理、光照让视觉策略直接迁移），后来在足式与操作任务中成为动力学迁移的主力：多项开源四足工作报告的零样本真机步态，几乎都把 DR 列为核心组件。本章讲清楚它的数学、参数选择、宽度权衡与自动化扩展：DR 的强度是一条需要测量的鲁棒-性能前沿。

核心原理

1. 数学表述：从单一点到一族世界

把动力学参数记作 θ（质量、摩擦、电机增益、延迟等），仿真环境是 Mθ。常规训练优化 J(π; Mθnom)，即名义点上的回报；域随机化把目标换成分布上的期望：

maxπ　Eθ~p(θ) [ J(π; Mθ) ] p(θ) 是你为参数选择的分布（常用均匀分布或 ±% 的均匀分布）

它与最坏情况鲁棒优化 maxπ minθ∈Θ J 有两点区别：采样期望保留了"平均表现"，不为了最坏点牺牲全部；但覆盖足够宽时，期望目标会自然压低最坏点的损失，DR 是"以采样换鲁棒"的近似，代价是每个具体点上都比专化策略略差。这正是下一节权衡曲线的来源，也是第 070 章鲁棒 RL 要处理的同一族问题的另一种解法。

2. 为什么它能保证真机性能？覆盖假设与敏感度

设真实参数 θreal，回报对参数的敏感度上界为 L（即 |J(θ₁)−J(θ₂)| ≤ L·‖θ₁−θ₂‖）。那么在分布覆盖区域内的任何 θreal：

J(π; θreal) ≥ Eθ[J(π; θ)] − L · Eθ[‖θ − θreal‖] 右端第二项是"到分布的期望距离"乘以敏感度：分布越宽越亏这一项，但 θ_real 越可能被覆盖

这条不等式给出两个工程启示：其一，随机化必须覆盖真实参数，如果真机摩擦 1.5 而训练分布是 [0.4, 1.0]，理论保证失效，策略可能在真机上从未见过的区域崩溃；其二，随机化参数要挑"高敏感 × 高不确定"的：敏感度 L 大意味着参数错一点回报掉很多，必须随机化；敏感性低或估计很准的参数随机化是浪费容量。敏感度可以在仿真里用"单参数扰动扫描"测出来：把质量 ±30% 扫一遍，看回报变化多少，变化大者优先进随机化清单。

3. 随机化什么：三类参数与一致性约束

类别典型参数与范围一致性要求
动力学连杆质量 ±20%、质心偏移 ±2 cm、转动惯量 ±30%、地面与关节摩擦 [0.3, 1.2]质量变化时惯量按比例联动，否则出现"1 kg 却有 10 kg 惯量"的非物理个体
执行器电机力矩增益 80–120%、时间常数 5–20 ms、力矩噪声 σ=2%增益与饱和一起缩放；不要把增益与延迟独立乱采
环境/传感器延迟 0–2 控制步、关节噪声 σ=0.02 rad、深度图 dropout 5%、地面纹理与光照视觉随机化覆盖纹理与光照的分布，避免纯随机像素

刻意不随机化的东西同样重要：重力（9.81 是硬事实）、机器人拓扑、关节限位（错了就是硬件风险）。随机化的本质是"对未知建模"，避免把所有数字都搅浑。

4. 宽度的权衡：一条有最优点的曲线

设随机化半宽为 δ（例如质量 ±δ%）。δ 太小的后果是覆盖率不足，真机稍有偏差即分布外；δ 太大的后果有三：训练更难（策略要同时在极端轻和极端重上工作，梯度冲突）、最优行为趋向保守（慢、稳，但慢）、以及"用错误范围随机化"时把容量浪费在与真机无关的区域。实践中成功率对 δ 的曲线是单峰或平顶：先升后降或到达平台。找到它的方法是实验：训练 3–4 组 δ 的策略，各自在真机（或高保真验证环境）上测 20 次。经验起点：质量 ±15–25%、摩擦 [0.4, 1.2]、电机增益 90–110%。

5. ADR：自动域随机化

手动调 δ 费时，ADR（Automatic Domain Randomization，常见于 OpenAI 灵巧手工作）把它自动化：对每个参数维护一个边界，定期用策略在当前分布上的表现决定扩边或收边。直觉是"能轻松通过当前难度的参数范围，就把它扩宽一点；在边缘上表现差的参数，就把该方向的边界收回来"。这让训练自动落在鲁棒-性能前沿附近，比手工扫描省 3–5 倍实验量。

若 J̄ > Jtarget（如目标回报的 70%）：δ ← δ · (1 + Δ)；若 J̄ 低于目标回报的 50%：δ ← δ · (1 − Δ)；其余维持 Δ 常取 0.1–0.3；只对超过性能阈值的参数维度扩边，防止一次性全放太宽

实现思路与设计

以四足机器人的地形负重行走为例，完整落地分五步：

  1. 建立参数清单：先做敏感度扫描（单参数 ±30%，每档 50 回合），把回报变化超过 5% 的参数列为随机化对象：质量、躯干质心、关节摩擦、电机增益、延迟、地形摩擦。回报变化不足 1% 的参数（如连杆颜色）移出清单。
  2. 定义分布与一致性：质量 m ~ Uniform(0.85, 1.15)·mnom，惯量按 m 比例联动；摩擦 μ ~ Uniform(0.4, 1.2)；增益 ~ Uniform(0.9, 1.1)；延迟 ~ Uniform{0, 1, 2} 步。所有采样用固定种子的独立随机流，保证可复现。
  3. 随机化时机：物理参数每回合开始时采样一次（回合内不变），回合内抖动物理参数会让策略学到"读心术"（同状态不同动力学），破坏马尔可夫性；传感器噪声与延迟则每步独立采样。
  4. 训练与日志：每个回合把采样到的参数写进信息字典，训练结束导出参数-回报散点图；检查"低回报是否集中在边缘参数"，据此收窄对应维度或先降后升。
  5. ADR 扩边：每 500 个回合评估一次当前分布下的平均回报，超过阈值就把质量/摩擦边界各扩 10%，并把新边界记录进日志；连续两轮无提升则停止扩边。
设计思维：为什么物理参数要"逐回合"随机化？

真实世界的一次任务里，机器人质量不会突然从 10 kg 变 12 kg。逐步骤随机化看似让策略更鲁棒，实际会教会策略"同一状态有不同未来"，它必须对每个动作的输出分布做更保守的估计，等价于额外噪声，损害学习效率。逐回合采样既覆盖了世界的不确定性，又保留了单回合内的物理自洽。这条规则仅对"真实中确实每步变化"的量（噪声、延迟）开例外。

关键代码与解读

片段 1：逐回合域随机化采样器（含物理一致性）

import numpy as np

class DomainRandomizer:
    """每个回合 reset 时调用一次：返回一组物理上自洽的参数。"""
    def __init__(self, nominal_mass, nominal_inertia, seed=0):
        self.m0, self.i0 = nominal_mass, nominal_inertia
        self.rng = np.random.default_rng(seed)   # 独立随机流：不与其他模块共享全局随机状态

    def sample(self):
        m_scale = self.rng.uniform(0.85, 1.15)          # 质量 ±15%，先采缩放比
        theta = {
            "mass_scale": m_scale,
            # 惯量按质量比例联动：否则会出现"质量 8.5kg、惯量却是 12kg 级"的非物理个体
            "inertia_scale": m_scale * self.rng.uniform(0.95, 1.05),
            "friction": self.rng.uniform(0.4, 1.2),      # 关节/地面摩擦
            "motor_gain": self.rng.uniform(0.9, 1.1),    # 电机力矩增益
            "latency_steps": int(self.rng.integers(0, 3)),  # 0/1/2 步延迟，覆盖抖动范围
            "com_offset": self.rng.uniform(-0.02, 0.02, size=3),  # 质心偏移 ±2 cm
        }
        return theta

    def apply(self, sim_handles, theta):
        # 把参数写进仿真：质量/惯量/摩擦/增益/时延分别对应资产、材质、驱动与通信配置
        sim_handles.set_mass_scale(theta["mass_scale"], theta["inertia_scale"])
        sim_handles.set_friction(theta["friction"])
        sim_handles.set_motor_gain(theta["motor_gain"])
        sim_handles.set_latency(theta["latency_steps"])     # 训练侧的真实延迟注入
        return theta

解读：default_rng(seed) 独立随机流（不用 np.random 全局流），是为了让"哪个环境采到什么参数"可复现，出问题时你能精确重放某个坏样本。质量与惯量的联动缩放是新手最容易忽略的物理一致性：惯量随质量按比例缩放是个一阶近似（真实机器人载荷分布会同时改变质心位置），比"独立乱采"安全得多，比"固定不动"更接近真实。latency_steps 用整数离散：控制周期的延迟天然是步数量化；连续延迟可以等效为"分数步 + 插值"，实现成本高、收益小。参数写入后必须作用于本轮所有并行环境，Isaac Sim 中常用张量广播一次写全部环境，避免逐环境 Python 循环。

片段 2：ADR 渐进扩边

class ADRBoundaries:
    """自动域随机化：用性能阈值驱动质量/摩擦边界的扩与收。"""
    def __init__(self, mass_half=0.05, friction_half=0.1, step=0.1, target_ratio=0.7):
        self.mass_half = mass_half           # 初始只随机化 ±5%：先学会走路，再学走"任何世界"
        self.friction_half = friction_half
        self.step = step                     # 每次扩边 10%
        self.target_ratio = target_ratio     # 达到"近期名义回报的 70%"才允许继续扩

    def update(self, recent_return, nominal_return):
        if nominal_return <= 0:
            return                                # 名义回报无效时冻结边界
        ratio = recent_return / nominal_return
        if ratio > self.target_ratio:
            self.mass_half *= (1 + self.step)     # 表现富余：扩宽分布
            self.friction_half *= (1 + self.step)
        elif ratio < 0.5:
            self.mass_half *= (1 - self.step)     # 表现崩塌：收窄，避免发散后无法学习
        # 上限护栏：扩到 ±40% 质量、±0.6 摩擦仍无提升即停，防止无限扩宽
        self.mass_half = min(self.mass_half, 0.4)
        self.friction_half = min(self.friction_half, 0.6)
        return self.mass_half, self.friction_half

解读：ADR 的三条纪律全在这段里。初始窄（±5%）：一上来就 ±30% 会让早期策略在极端个体上持续失败、梯度被噪声主导，学不出基本步态；只在表现富余时扩：阈值 0.7 是经验值，低于它说明当前分布还没"学会"，扩边只会加深失败；双向调节 + 护栏：表现崩塌时收窄（学习安全性），边界有上限（防止参数扫出物理合理区）。扩边周期（本类外部调用）常用 500 回合，太频繁会让分布长期停在高难度边缘。若你想复现经典 ADR 论文里的"边界只有在所有参数都达标时才整体扩张"，把 update 改成"全部维度共享一个缩放系数"即可。

片段 3：鲁棒性评估，参数网格扫描

import numpy as np

def robustness_sweep(env, policy, param_grid, episodes=20):
    """固定策略在参数网格上逐点评估：得到一条"鲁棒性能曲线"。"""
    results = []
    for value in param_grid:
        returns, success = [], 0
        for ep in range(episodes):
            obs = env.reset(params={OBS_KEY: value})   # 只在指定参数点上重置环境
            done, ep_ret = False, 0.0
            while not done:
                act = policy.act(obs)                 # 评测：确定性动作，关闭探索噪声
                obs, r, done, info = env.step(act)
                ep_ret += r
            returns.append(ep_ret)
            success += int(info["success"])
        # 同时记录均值与最差 20% 分位：最差分位才是"部署风险"的代理指标
        results.append({"param": value, "mean": np.mean(returns),
                        "q20": np.quantile(returns, 0.2),
                        "success": success / episodes})
    return results


OBS_KEY = "friction"   # 扫描的物理参数名（评估时只改它，其余保持在名义值）

解读：评估与训练必须解耦，用确定性策略（关闭探索噪声）在单一参数点上重复 20 次，不用训练期带随机化的回合。报告里同时给出均值和 20% 分位：均值告诉你"平均表现"，分位告诉你"最差情况风险"，部署决策往往由后者决定（例如成功率 90% 但 q20 掉到 40% 说明任务在边缘不可靠）。把扫描参数设为摩擦、质量、延迟逐一做单轴扫描，再做一两组双轴组合，真实世界不会只违反一个参数，单轴全过而组合崩塌是常见陷阱。曲线画出来后的判读规则：平台区越宽越好；平台边缘的陡降点应落在真机参数估计的置信区间之外。

常见坑

  • 随机化范围与真机参数错位：训练用摩擦 [0.8, 1.2]，真机实际 0.5。症状是仿真里明明鲁棒、真机却持续打滑。修复：先用手头数据（第 067 章系统辨识、器件手册）确认真机参数的合理区间，把分布覆盖它，宁宽勿窄。
  • 逐步骤随机化物理参数：同一回合内质量来回变，破坏马尔可夫结构，策略学到"保守到不动"。症状是训练回报长期卡在低位且动作幅度小。修复：物理参数逐回合采样；仅噪声/延迟逐步骤。
  • 参数不联动：质量、惯量、电机增益独立乱采。症状是策略学会"用极小惯量表对抗大质量个体"这种物理上不存在的技巧。修复：建立参数间的联动关系（质量↔惯量、增益↔饱和），在采样器内统一处理。
  • 没有参数日志：训练完不知道哪个参数维度在拖后腿。症状是只能看到总回报曲线，调参靠猜。修复：每回合记录采样参数与回报，训练后画"参数-回报"散点图，找出低回报集中的维度。
  • 评测复用带探索的策略：用训练中带高斯噪声的策略做鲁棒性评估，曲线噪声大到读不出趋势。症状是相邻参数点结果跳变。修复：评估固定关掉动作噪声，每点重复 20 次以上取分位数。

练习与思考

  1. 做一次单参数敏感度扫描：质量、摩擦、增益各 ±30%，找出回报变化最大的前两个参数，并解释为什么它们值得随机化。★
    提示
    固定同一策略、同一初始状态集，每档跑 50 回合；用回报变化率排序；绝对值会掩盖敏感度差异。
  2. 训练三组不同质量半宽（±5%、±15%、±35%）的策略，在同一参数网格上评估，画出"宽度 vs 各点性能"曲线，找出你的任务上的最优区间。★★
    提示
    预期中间半宽的综合分最高：±5% 在网格两端崩，±35% 在中心区略差。用 20% 分位做综合分。
  3. 把 ADR 的扩边阈值从 0.7 改成 0.9 与 0.5，观察边界扩张速度与最终鲁棒性能的变化。★★
    提示
    0.9 更保守但更慢；0.5 激进、可能早早把分布推到学不动的区域，表现为曲线掉坑再爬不出来。
  4. 设计一个"组合鲁棒性"评测：质量与摩擦各自取低/中/高三档组成 3×3 网格，报告成功率矩阵，并标出训练分布覆盖的区域。★★★
    提示
    矩阵四角是压力测试点；检查"覆盖内全绿、覆盖外可控"是否成立，覆盖外崩得越快说明敏感度越高。
  5. 把延迟随机化从整数 {0,1,2} 步改成 {0,1,2,3,4} 步并重训，预测部署端 P95 延迟 3 步时的表现是否改善，并用实验验证。★★
    提示
    关注训练回报下降幅度与部署 P95 点性能的交换：分布上界决定部署上界，但训练难度上升。

小结

  • 域随机化 = 在动力学参数分布上最大化期望回报：以采样近似鲁棒优化，保留平均性能、换取覆盖。
  • 理论保证依赖两个条件：真机参数落在分布支持集内、参数维度选在"高敏感 × 高不确定"处。
  • 宽度是一把双刃剑：太窄覆盖不足，太宽策略保守；成功率对半宽的曲线存在最优点，靠实验找。
  • 工程纪律：物理参数逐回合随机化、参数间保持联动一致性、采样参数全程日志、评估用确定性策略。
  • ADR 用性能阈值自动扩边/收边，把分布推向前沿；护栏与初始窄边是防止训练发散的关键。
  • 下一章转向另一条路线：用数据把仿真参数调到更准，系统辨识，它决定你的随机化分布应该以谁为中心。
