第一篇 · 仿真环境与训练框架

第 016 章：实现Franka机器人操作环境

把环境接口扩展到 7 自由度机械臂：定义"到达目标"任务，讲清末端执行器的位姿从哪来、观测怎么组装、稠密奖励如何引导策略，以及为什么基座坐标系是隐藏的关键决定。

  • 主题：强化学习任务 / 机械臂到达（Reach）
  • 相关组件：Isaac Sim（Franka、正向运动学、TCP）
  • 预计学时：60 分钟
  • 前置章节：第 015 章

学习目标

  • 理解机械臂到达任务的完整定义：工作空间、目标采样、成功判定与终止条件。
  • 掌握末端执行器位姿的获取方式，理解工具中心点（TCP）为什么比连杆原点更重要。
  • 会在基座坐标系下组装观测与计算距离，解释坐标系选择对任务语义的影响。
  • 会设计一阶稠密奖励（负距离）+ 成功奖励的组合，并预测它对探索的引导作用。
  • 能用固定种子评估集测量成功率，为 018 章的训练建立基线指标。

背景与动机

Cartpole 只有一个执行器和一个被控对象；机械臂有 7 个关节、几十厘米的工作空间、丰富的冗余构型，同一末端位置可以由多组关节角实现。到达任务（Reach）是机械臂所有操作任务的"第一课"：先学会把末端移动到任意指定位置，才谈得上抓取与装配。它也是 037 章抓取、046 章轨迹跟踪的前置能力。

本章的新问题是：末端位姿从哪读（TCP 概念）、目标在哪采样（难度设计）、基座系与世界系的区别。

核心原理

1. 任务定义：把"到达"翻译成数学

到达任务的目标是让末端执行器（end-effector）的位置 pee 尽可能接近目标点 pt。直观的度量是欧氏距离：

d = ‖ pee − pt ‖2，到达成功 ⇔ d ≤ d成功 d_成功 是成功阈值，如 5 cm；它同时定义了"任务精度"与"学习难度"

两个任务设计决策随之而来。第一，是否需要姿态对齐：只约束位置（3 个自由度）是 6 自由度机械臂的欠约束问题，末端可以以任意朝向到达同一个点，策略解空间大、容易学。抓取类任务还需要末端朝向（夹爪要对准物体），那就是 6 维约束；本章从位置开始。第二，目标采样点要落在前向可达扇区：撒满全空间时大量点不可达，早期训练几乎不可能成功（012 章的课程思想）。

2. 末端位姿与 TCP：距离算的到底是谁

机械臂的链末端连杆（如 panda_hand）有一个坐标系原点，但真正干活的是工具中心点（Tool Center Point, TCP），两指指尖的中点，通常在手掌前方 10 cm 左右。距离必须用 TCP：按"掌心"判定成功时夹爪还差半截没碰到物体，抓取判定会系统性偏 10 cm。

TCP 的位置由连杆位姿与固定偏移叠加得到：

pTCP = plink + Rlink · oTCP o_TCP 是 TCP 在连杆坐标系中的位置偏移（恒定），R_link 是连杆的当前朝向

两个途径：库的运动学接口（名称随版本变化）或从 USD 读连杆 prim 的世界变换（注意物理同步时机）。无论哪种，先做一次目视标定：让机械臂摆一个姿势，把一个标记物放在 TCP 目测位置，比较两者距离，这一步能把"偏移量抄错、轴搞反"这类错误一次消灭。

3. 坐标系：基座系是任务的"正确"参照系

观测与距离应该在哪个坐标系里表达？直觉答案是世界系，但结论是：固定基座机械臂的任务，用基座系。原因有二。第一，不变性：基座系下的相对几何与机械臂摆在场景何处无关；用世界系时，同一任务在不同摆位会得到完全不同的观测，策略要学的映射跟着漂移。第二，纪律：凡涉及任务几何的量统一在基座系，后面加入相机与多物体时保持清晰。基座恰好在世界原点是巧合，别依赖它。

4. 观测与奖励的设计

观测沿用 014 章骨架并补充任务量（共 20 维，全部 float32）：

分量维度归一化方式作用
关节位置7除以关节限位本体构型
关节速度7除以 2.2 rad/s运动趋势（纯位置观测是部分可观测，007 章）
TCP 位置3除以工作区半径 0.8 m当前末端位置（基座系）
目标位置3除以 0.8 m任务目标（基座系）

奖励用"稠密距离引导 + 稀疏成功奖励"：每个 RL 步给 −d（单位米，约 −0.5 到 0 之间），成功时额外给 +5 并终止。负距离就是"越近越好"的连续信号，是 020 章势函数塑形的最简单实例。量级要对：−d 每步约 −0.5、回合约 −100 量级；成功奖励 +5 要显著但不主导，018 章用训练曲线验证。

5. 冗余与解空间：7 个关节对 3 维目标

Franka 的 7 个手臂关节张成 7 维关节空间，位置到达只约束 3 维，二者之差就是冗余度：

冗余度 = nDOF − mtask = 7 − 3 = 4 同一目标点对应一个 4 维构型流形，到达同一位置的方式有无穷多组

冗余带来两个好处与一个难点。好处：避碰与避限位有回旋余地，某个关节接近限位时可以换构型；难点：稠密距离奖励只关心末端位置，策略可能学到"拧着关节够到"的怪异构型，进入抓取阶段后姿态不可用。缓解手段是让任务延续到 6 维位姿约束，或加入姿态正则项。量化对照：3 维任务的每点解流形是 4 维，6 维任务把它压缩到 1 维，探索难度随之上一个台阶。

6. 成功奖励的量级校验：两个选择的算术对比

成功奖励 +5 是否足够大？在"成功时刻"做一次边际比较即可。设策略在第 50 步到达 d ≈ 0.05，两个选择：

终止：获得 +5，之后无回报  对比  继续徘徊：剩余 150 步每步约 −0.05，折扣累计 ≈ −0.05 × Σγt ≈ −2.3 γ = 0.99 时 Σt=51..199 γ^t ≈ 46.5；+5 明显优于 −2.3，策略会及时抓住成功

结论：+5 的量级在 200 步回合、γ = 0.99 的口径下足以压过徘徊收益。把回合缩短到 100 步，徘徊累计降到约 −1.2，+5 更加占优；把成功奖励降到 +1，某些状态下"多磨蹭几秒再成功"变得同样诱人，训练曲线会出现"到了阈值边缘却不完成"的形态。校准奖励量级都可以用这种在关键决策点做算术的方法，019–020 章会反复使用。

课程在到达阶段先用 3 维约束把"移动到位"学会，进入抓取章节再叠加姿态约束。这张表也是判断"任务需要几维约束"的检查表：凡是要用夹爪做工的任务，姿态都在成功条件里。

补充一条与阈值配套的量化：TCP 偏移的目视标定误差约 1 cm，成功阈值取 5 cm 时它只占 20%，判定仍然可信；把阈值收紧到 2 cm 时，标定误差与判定精度进入同一量级，评估出的成功率上限会被标定误差本身压住。任务精度指标要和测量精度一起设计，这一条对后面所有操作任务都成立。评估 6 维任务时同时报告"位置达标率"与"姿态达标率"，两个数字分开看，才能判断失败模式是到不了位置，还是对着方向不对。两项指标的差值还能反映学习顺序：位置先达标、姿态后达标是常见的收敛形态，反方向的形态通常意味着奖励里的姿态项写得过重。姿态阈值可从 ±20° 起步，随成功率提升收紧到 ±5°，与位置阈值的收紧同步进行；训练初期直接使用 ±5° 会明显拉长预算。

8. 采样盒与可达域的边界核对

工作区采样盒的八个角点要逐个与可达半径核对，方法是一次开方运算：把角点坐标的模长与 Franka 约 0.855 m 的标称可达半径相减。八个角点里 y 取 ±0.25 对称，只需看四个：

角点（x, y, z）距原点相对 0.855 m 的余量
(0.35, 0.25, 0.20)0.474 m+0.381 m
(0.35, 0.25, 0.60)0.738 m+0.117 m
(0.65, 0.25, 0.20)0.725 m+0.130 m
(0.65, 0.25, 0.60)0.919 m−0.064 m

核对结果有两面。好的一面是近端与低处的角点余量充足，最小正余量约 0.117 m，采样点绝大多数可达；问题的一面是远上方的两个角点超出标称半径约 6.4 cm，这一带的采样会混入不可达目标，把成功率的理论上限压住，训练曲线表现为"接近却总差最后几厘米"。修正方案是把 x 上限收到 0.5 m（最远角点约 0.820 m，余量约 0.035 m），或保留原盒并在采样后加一次参考 IK 可达性预筛，把不可达样本比例纳入监控。两种做法都能把"采样区与可达域"的边界对齐。预筛的监控口径是拒绝率：把"参考 IK 解不出或碰撞检查不过"的样本比例记为拒绝率，稳定在 1%–5% 属于正常余量，超过 5% 说明采样盒与可达域脱节，先收 x 上限再考虑其它改动；拒绝率曲线也可以在训练日志里画出，它与成功率曲线的背离往往先于训练异常出现。

两条几何补充。第一，TCP 在连杆前方约 10.5 cm，工具线段伸出的方向上可达距离实际更大，但该加成只沿工具方向有效，盒角方向不能按它计算，保守设计仍用连杆标称半径。第二，采样盒体积约 0.06 m³，而半径 0.3 到 0.65 m 的球壳体积约 1.04 m³：盒子只覆盖工作空间的一个小扇区，随机策略的初始平均距离约 0.4 m、成功率接近零，都是这个小扇区的几何背景决定的，评估数字要随它一起解释。

动作幅度与任务尺度之间还有一条核对线：到达任务的动作分辨率要覆盖"接近目标后微调几厘米"的需求。末端位移与关节幅度按 Δx ≈ L·Δq 换算（L 取 0.8 m）：Δq = 0.2 rad 对应单步 16 cm，对 5 cm 成功阈值来说步子偏大，接近目标后容易来回跨越；Δq = 0.05 rad 对应 4 cm，与阈值同量级，微调能力刚好够用；Δq = 0.02 rad 对应约 1.6 cm，精度富余但探索效率下降。推荐档位是 0.05–0.1 rad：单步位移略小于成功阈值，策略在目标邻域里有至少两三步的调整空间，探索速度也不至于被压死。

奖励分辨率的口径一起给出：距离每变化 1 cm，奖励 −d 变化 0.01，占单步奖励量级（约 0.4–0.5）的约 2%；在 200 步回合里，1 cm 的持续优势累计约 2 个奖励单位，与成功奖励 5 同量级。这说明精度信号在回报里本来就可感知，无需专门放大 −d 的系数；反过来，如果任务需要更精细的收敛，把成功阈值收紧比放大奖励系数更有效，因为阈值同时收紧的是终止条件与密度信号的作用范围。阈值、动作幅度、归一化分母、奖励系数四者构成一组互相咬合的参数，改动任何一项都要按这张清单逐项复核。

实现思路与设计

实现到达环境的步骤：

  1. 摆放与标定（机械臂基座固定在工作台近端；测量并记录 TCP 偏移 oTCP）。
  2. 定义工作区（基座系下的采样盒或球扇区，如 x ∈ [0.35, 0.65]、y ∈ [−0.25, 0.25]、z ∈ [0.2, 0.6]）。
  3. 实现 reset（关节初态 + 目标采样 + 稳定期；目标位置存进环境状态供观测与奖励使用）。
  4. 实现观测与奖励（基座系 TCP、目标；r = −d，附加成功奖励与终止）。
  5. 超时设置（如 200 个 RL 步；给足探索时间又控制回合成本）。
  6. 评估基线（固定 50 个目标种子：随机策略成功率、初始距离分布，这两个数字是训练前的"地平线"）。
参数取值理由

设计思维：为什么先做"随机策略基线"？

训练前先用随机策略跑 50 个固定种子回合，记录成功率（大概率是 0）与初始平均距离（比如 0.4 m）。它们是所有进步的参照：训练后 30% 成功率意味着"从 0 到 30%"；没有基线就说不清进步。评估集用 012 章的固定种子纪律，让每次比较面对完全相同的目标序列。

关键代码与解读

片段 1：读取连杆位姿并计算 TCP（运动学接口名称随版本变化，以官方文档为准）

import numpy as np

O_TCP = np.array([0.0, 0.0, 0.105])   # TCP 在手掌坐标系中的偏移：约 10.5 cm（目视标定过）

def tcp_position(robot, hand_link_path):
    """返回 TCP 在基座坐标系中的位置（米）。"""
    p_link, q_link = get_link_world_pose(robot, hand_link_path)  # 库接口：连杆世界位姿
    # get_link_world_pose 是示意封装：不同版本提供不同的连杆位姿查询接口，以文档为准；
    # 也可以从 USD 场景读取该 prim 的世界变换（注意物理同步时机）。
    R = quat_to_matrix(q_link)            # 朝向四元数 → 3×3 旋转矩阵（常用工具函数）
    p_tcp = np.asarray(p_link) + R @ O_TCP  # 偏移在连杆坐标系里，故要先旋转到世界方向
    return p_tcp, np.asarray(q_link)

解读：p_tcp = p_link + R @ O_TCP 这一行是第 2 节公式的直接实现，也是整章最容易出错的一行。三个常见错误：偏移轴写错、忘乘旋转矩阵（手腕一转 TCP 就"瞬移"）、偏移量抄自别的资产。防呆方案是目视标定：手腕水平时 TCP 应在指尖，亚厘米级一致即可。函数同时返回朝向四元数，为将来升级到"位置+姿态"的 6 维到达任务预留。

片段 2：目标采样与初始观测组装

import numpy as np

WORKSPACE = {"x": (0.35, 0.65), "y": (-0.25, 0.25), "z": (0.20, 0.60)}
WORKSPACE_RADIUS = 0.8    # 归一化分母：工作区对角线量级

class ReachEnvState:
    """任务层状态：目标位置等跨步信息集中管理（011 章习惯）。"""
    def __init__(self):
        self.target = np.zeros(3)          # 基座系下的目标位置（米）

    def sample_target(self, rng):
        """在前向扇区盒子里均匀采样一个可达目标。"""
        self.target = np.array([
            rng.uniform(*WORKSPACE["x"]),  # * 展开元组：把 (min, max) 变成两个参数
            rng.uniform(*WORKSPACE["y"]),
            rng.uniform(*WORKSPACE["z"]),
        ])

def build_observation(robot, state, joint_limits, qd_scale=2.2):
    """20 维观测：关节(14) + TCP(3) + 目标(3)，全部归一化。"""
    q = robot.get_joint_positions()[:7]                 # 只取手臂 7 轴（夹爪不参与到达）
    qd = robot.get_joint_velocities()[:7]
    p_tcp, _ = tcp_position(robot, robot.HAND_LINK_PATH)  # 基座系 TCP 位置
    obs = np.concatenate([
        np.clip(q / joint_limits[:7], -1.0, 1.0),       # 关节位置按限位归一
        np.clip(qd / qd_scale, -2.0, 2.0) / 2.0,        # 速度允许 2 倍典型值
        p_tcp / WORKSPACE_RADIUS,                        # 任务几何按工作区量级归一
        state.target / WORKSPACE_RADIUS,
    ])
    return obs.astype(np.float32)

解读：观测里两项任务几何（TCP 与目标）都用同一个分母 WORKSPACE_RADIUS，这是刻意的：让"TCP 与目标的差"在归一化后保持比例，网络更容易学到两个向量的差。state.target 平时静止，只有 reset 时被采样器改写，所以它作为"任务上下文"存在于观测中，让同一个策略网络能泛化到任意目标位置。joint_limits[:7] 的切片呼应了 002 章"只取手臂"的决定：夹爪关节对到达任务无意义，放进观测只会增加噪声（夹爪位置只影响抓取类任务）。

片段 3：奖励、成功判定与一步的完整组装

import numpy as np

SUCCESS_D = 0.05          # 成功阈值（米）
SUCCESS_BONUS = 5.0       # 成功奖励：与 -d 的量级对比见 4 节
MAX_RL_STEPS = 200        # 超时（200 × 2/60 s ≈ 6.7 s）

def reach_reward_and_done(robot, state, step_count):
    """稠密距离奖励 + 成功终止 + 超时截断。"""
    p_tcp, _ = tcp_position(robot, robot.HAND_LINK_PATH)
    d = float(np.linalg.norm(p_tcp - state.target))     # 基座系欧氏距离
    success = d < SUCCESS_D
    reward = -d                                          # 稠密引导：越近越好
    if success:
        reward += SUCCESS_BONUS                           # 成功额外奖励
    terminated = bool(success)                            # 成功即终态
    truncated = bool(step_count >= MAX_RL_STEPS)          # 超时是截断
    info = {"distance": d, "is_success": success}
    return reward, terminated, truncated, info

# step() 内组装（与 014 章骨架一致）：
#   action → 位置控制下发（004 章）→ decimation 次物理步
#   → build_observation() → reach_reward_and_done() → 返回五元组
# 注意：距离与成功判定必须在物理推进"之后"计算，与观测同一时刻

解读：三个设计点在代码里各占一行。距离基于最新 TCP 独立计算：任务判定不依赖观测流水线，观测将来加噪后判定仍然干净。成功立即终止：终止的价值是防止策略学会"到达后继续乱动刷步数奖励"；由于本任务没有存活奖励，终止更多是效率考虑（省去无意义步数）。info 里保留原始距离：018 章训练时，把"每回合最小距离"的分布画出来，能直观区分"没学会（最小距离≈初始距离）"与"学会了但不够精（最小距离 6–8 cm）"两种失败模式，这比只看成功率信息量大得多。

常见坑

  • 用连杆原点、未换算到 TCP 就计算距离：表面误差恒定 10 cm，成功率永远卡在阈值之外。修复：目视标定 TCP 偏移；把偏移量写进配置并做一次几何自检。
  • 坐标系混用：目标在基座系、TCP 读成世界系，机械臂摆位一变任务就"失灵"。修复：任务几何统一在基座系；世界系的量只用于可视化。
  • 工作区超出可达范围：采样点中混入不可达区域，成功率的理论上限被压低。修复：采样后做一次可达性粗筛（用参考 IK 或前向检查），或从示教可达点云里采样。
  • 奖励量级失衡：成功奖励取 100 时策略赌"冲一次"；取 1 时策略对成功无所谓。修复：参考"成功奖励 ≈ 10–20 倍的单步 |d| 典型值"，018 章用曲线验证。
  • 观测不含目标：策略看不到"去哪"，只能碰运气。修复：目标位置必须进观测；这是"任务条件化"的最小要求（031 章的目标条件 RL 是它的推广）。

练习与思考

  1. 测量 TCP 偏移：把机械臂摆到手腕竖直向下、TCP 指向桌面的姿势，用桌面上标记点验证偏移量，写出你的标定流程。★
    提示
    让 TCP 恰好触碰桌面已知点，比较该点与 p_link 的距离向量；多摆两个朝向来交叉验证旋转部分。
  2. 把成功阈值依次取 0.02、0.05、0.10 m，预测并（在 018 章训练框架就绪后）验证三者对学习速度与最终精度的差别。★★
    提示
    阈值越小，稠密奖励的有效梯度区越窄、越难；越大则学会容易但"精度"名不副实。
  3. 把奖励从"每步 −d"改成"每步 −d 乘以 decimation"（按仿真时间归一），推导两种回报口径下策略行为是否改变，并说明何时该用哪种。★★
    提示
    如果 decimation 固定，两者只差常数因子，策略最优解不变；但换 decimation 的对照实验之间回报不可比，按时间归一让不同决策频率的实验可比。
  4. 把观测里的关节速度去掉（20 维 → 13 维），解释为什么这会让任务变成"部分可观测"，并预测成功率变化方向。★★★
    提示
    策略无法判断机械臂"正在往哪动"，会在目标附近来回过冲；对照 052 章的部分可观测理论。
  5. 设计一个"位置+姿态"的 6 维到达判定（提示：位置距离 + 四元数夹角），说明新增的难度来自哪里，并预测需要多少额外训练样本。★★
    提示
    姿态夹角可用 2·arccos(|⟨q1, q2⟩|) 计算；腕部还要同时满足位置与姿态，有效解空间变小、探索更难。

小结

  • 到达任务 = 最小化 TCP 与目标的距离；成功阈值 d成功（如 5 cm）同时定义任务精度与学习难度。
  • 距离必须用 TCP 算：pTCP = plink + R·oTCP；偏移量与旋转一个都不能少，目视标定兜底。
  • 任务几何统一在基座坐标系表达：获得摆放无关的不变性，观测分布更稳定。
  • 观测 20 维（关节 14 + TCP 3 + 目标 3）；奖励 = 每步 −d + 成功 +5 并终止；超时截断。
