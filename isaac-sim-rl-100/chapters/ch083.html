第四篇 · 控制与优化

第 083 章：实现平滑控制

上一章的 bang-bang 又快又"硬"，会激励机械结构的柔性模态。本章从 jerk 受限轨迹讲起，把"平滑"变成可训练的目标：动作变化率惩罚、输出低通滤波与频谱评估。

  • 主题：控制与优化 / jerk 受限与动作平滑
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：50 分钟
  • 前置章节：第 082 章

学习目标

  • 理解振动从哪里来：加速度阶跃（jerk 冲击）如何激励机械结构的柔性模态。
  • 掌握 jerk（加加速度）受限的 S 曲线速度剖面，以及它与梯形剖面的频谱差别。
  • 掌握 RL 中实现平滑的三条路径：奖励惩罚、输出低通滤波、动作参数化，并会说清各自代价。
  • 会正确设置平滑惩罚的权重：量纲归一化、与任务奖励的比例、训练课程。
  • 会用频谱分析评估策略的平滑度，并诊断"滤波对抗""动作冻结"等典型病态。

背景与动机

第 082 章的时间最优解把力矩在 ±τmax 之间阶跃切换，这相当于对机械臂结构施加了近似冲击的激励。真实的机械臂不是刚体：谐波减速器有弹性、铝制连杆有柔性、末端挂着的负载会晃。这些柔性模态的固有频率通常在 10–30 Hz，阻尼比只有 0.02–0.1，一旦被阶跃激励就会持续振动数百毫秒，导致末端定位抖动、装配失败、零件磨损。

更麻烦的是仿真与现实的落差：仿真里把机器人建成纯刚体时，bang-bang 策略"看着完美"，上真机却抖成一团。因此平滑控制的目标是让策略输出在时间上连续、频谱上"干净"：消除无谓的高频激励，速度本身不必牺牲。

核心原理

1. 振动的来源：jerk 就是冲击

定义 jerk（加加速度）为加速度的变化率：

j(t) = da/dt = d³q/dt³ 位置、速度、加速度、jerk 是运动学"四阶"；jerk 越大，力变化越陡

把结构近似为单自由度二阶模态（固有频率 fn、阻尼比 ζ）：

ẍ + 2ζωnẋ + ωn²x = (1/m)·F(t) ωn = 2πfn；F 变化越快，模态被激励得越狠

时域的"快"与频域的"高频"是同一件事：加速度阶跃的频谱按 1/f 衰减，而 jerk 受限的平滑加速度按 1/f² 或更快衰减。以 20 Hz 模态为例，把 jerk 上限降到 1000 rad/s³，该频率附近的激励能量可下降一个数量级以上，这就是"平滑"的物理本质：它关乎的是能量注入。

2. S 曲线：把 jerk 当约束

第 082 章的速度剖面是梯形（加速度恒定的两段）。若把 jerk 限制为 J，梯形剖面会变成七段式 S 曲线：

jerk 分段常数 → 加速段三分：J⁺ → 0 → J⁻ → 匀速 → 减速段对称 每段的 jerk 停留时间 tj = amax/J；这就是"S"名字的来源

峰值加速度不变（仍为 amax），但加速度从"跳变"变成"斜坡"，频谱能量被搬到更低的频段。多花的时间约为 2tj：amax = 20 rad/s²、J = 200 rad/s³ 时 tj = 0.1 s，一段运动多花约 0.2 s，这是用时间换平稳的明确价格，也是它与第 082 章目标的折中点。

3. 滤波等价性：平滑 = 低通

还有一种更工程化的理解：对原始加速度做一阶低通（时间常数 τ）再积分，得到的运动正是"jerk 近似受限"的轨迹，且约束近似为 J ≈ amax/τ。滤波器是线性系统：时域里"软化了拐角"，频域里"砍掉了截止频率 1/(2πτ) 以上的能量"。它同时带来两个副作用，必须心里有数：

时间常数 τ等效截止频率对节拍的影响平滑收益
20 ms≈ 8 Hz几乎无感去除采样毛刺
80 ms≈ 2 Hz每段延迟约 80 ms显著压制 10–30 Hz 模态
200 ms≈ 0.8 Hz明显变慢接近"温柔"极限，跟踪误差增大

4. RL 中实现平滑的三条路径

策略网络天然倾向输出高频抖动（尤其是用动作噪声探索之后），需要主动治理：

  1. 奖励惩罚：奖励中减去 β·‖Δτ‖² 或 β·‖τk − 2τk−1 + τk−2‖²。前者罚一阶变化率、后者真正罚 jerk（二阶差分）。优点是不干扰动作可达域；缺点是 β 需调参，且奖励产生历史依赖。
  2. 输出低通滤波：策略输出先过一阶惯性环节 u ← u + α(unew − u)，再乘力矩上限。优点是"硬保证"，无论策略输出什么，执行侧都不可能高频跳变；缺点是引入固定延迟，且策略会"学会对抗滤波器"（见常见坑）。
  3. 动作参数化：不直接输出力矩，改为输出低维轨迹参数（样条控制点、速度指令的幅值与方向），由底层控制器生成平滑轨迹。平滑性由结构保证，但牺牲策略的高频补偿能力。
一阶滤波离散实现：uk = uk−1 + α·(utarget − uk−1)，α = dt / (τ + dt) dt=1/60 s、τ=80 ms 时 α≈0.17：每次只走目标差的 17%，天然限速

实现思路与设计

  1. 先度量再优化：记录策略的力矩序列，算 jerk RMS 与 10–30 Hz 频段能量占比。没有基线数字，"更平滑"无从谈起。
  2. 惩罚项的量纲要归一化：动作先除以 τmax 再求差分平方，否则 β 的合理范围随力矩单位漂移；差分再除以 dt 化为"每秒"量纲，与时间税比例更易调。
  3. β 从"损失占比"反推：训练早期让平滑惩罚约占总损失的 5%–15%；占比超过 50% 会"动作冻结"。
  4. 推荐组合：弱滤波 + 奖励惩罚。只用滤波，策略会输出反向高频信号去抵消滤波延迟；只用惩罚，末端仍可能残留几百毫秒的抖动。两者结合并让滤波时间常数取小（20–40 ms），效果最稳。
  5. 观测要补历史：若奖励依赖 τk−1，严格来说状态不再是马尔可夫的。把上一步动作拼进观测最省事；或用循环网络（第 061 章）保留记忆。
  6. 训练课程：任务成功率 <80% 时先别加平滑项，否则既学不会任务也抓不住平滑；成功稳定后再线性提升 β（0 → 0.1 → 0.3），每档重训。评估用三件套：任务指标（到点时间/成功率）、平滑指标（jerk RMS、频谱峰值）、执行器指标（力矩变化率 P99）。
设计思维：平滑与时间最优的折中曲线

把 β 从 0 扫到较大值，会得到一条"抖动—时间"折中曲线：横轴 jerk RMS，纵轴到点时间。曲线通常前段很陡（去掉毛刺几乎不花时间）、后段很平（再平滑只是白白变慢），工程上选在拐点附近。本课程推荐 τ=40 ms 滤波 + 惩罚占 10%，多数搬运任务能在时间增加 <10% 的前提下把末端振动砍掉一半以上。

关键代码与解读

片段 1：梯形剖面 → 低通平滑 → S 曲线（理解"平滑就是低通"）

import numpy as np

def trap_then_smooth(d, v_max, a_max, dt=1.0 / 60.0, tau=0.08):
    """生成点到点运动：先算理想梯形速度剖面，再对加速度做一阶低通。
    tau 是低通时间常数：越大越平滑、总时长越长（近似 jerk 上限 a_max/tau）。"""
    n = int(4.0 / dt)                     # 预分配 4 秒的序列，够一般短行程用
    a_ideal = np.zeros(n)
    v = 0.0
    x = 0.0
    for k in range(n):                    # 第一遍：按"剩余距离"开关加速度，得梯形剖面
        remain = d - x
        # 能停下的条件：remain 还大于刹车距离 v^2/(2a) 才继续加速，否则减速
        if v < v_max and remain > v * v / (2.0 * a_max) + v * dt:
            a_ideal[k] = a_max
        elif remain > 1e-6:
            a_ideal[k] = -a_max
        else:
            a_ideal[k] = 0.0
        v = max(v, 0.0) + a_ideal[k] * dt
        x += v * dt
    # 第二遍：一阶低通加速度，把"阶跃"变成"斜坡"，这正是 jerk 受限的近似
    alpha = dt / (tau + dt)               # dt=1/60、tau=0.08 时 alpha≈0.17
    a_smooth = np.zeros(n)
    for k in range(1, n):
        a_smooth[k] = a_smooth[k - 1] + alpha * (a_ideal[k] - a_smooth[k - 1])
    v_smooth = np.cumsum(a_smooth) * dt   # 平滑加速度积分回速度与位置
    x_smooth = np.cumsum(v_smooth) * dt
    return a_ideal, a_smooth, v_smooth, x_smooth

解读：这个片段把本章两个核心概念连了起来，"S 曲线"与"低通滤波"其实是一回事的两种说法。第一遍按最朴素的"到点刹车"逻辑生成梯形加速度（与第 082 章 bang-bang 同源）；第二遍的 alpha 决定平滑强度：τ=80 ms 时每次只吸收目标差的 17%，加速度拐角被拉成斜坡。低通会带来总时长增加，这正是"平滑的代价"在代码里的体现。把 tau 改成 0.02 与 0.2 各跑一次，观察拐角与总时长变化。

片段 2：在 RL 环境里加入动作变化率惩罚与输出滤波

class SmoothReachEnv:
    """在普通到点任务上叠加平滑机制：输出低通 + 动作变化率惩罚。"""

    def __init__(self, num_envs, dt=1.0 / 60.0, tau_max=30.0,
                 filt_tau=0.04, beta=0.1):
        self.dt = dt
        self.tau_max = tau_max            # 力矩上限：归一化动作时用
        self.alpha = dt / (filt_tau + dt) # 40 ms 低通：只削高频，不造成明显延迟
        self.beta = beta                  # 平滑权重：占任务损失 5%-15% 之间为宜
        self.filtered = torch.zeros(num_envs, 7)      # 滤波后的动作（7 个关节）
        self.prev_action = torch.zeros(num_envs, 7)   # 上一步动作，供差分用

    def step(self, raw_action):
        raw_action = torch.clamp(raw_action, -1.0, 1.0)   # 先截断，防策略输出越界
        # 一阶低通：执行侧拿到的是"以 alpha 速度逼近目标"的平滑指令
        self.filtered = self.filtered + self.alpha * (raw_action - self.filtered)
        tau = self.filtered * self.tau_max                # 再映射到物理力矩
        # 动作变化率（离散 jerk 代理）：除以 dt 化为"每秒"量纲，与时间税可比
        rate = (raw_action - self.prev_action) / self.dt
        self.prev_action = raw_action.clone()
        obs, task_reward, done = self._physics_step(tau)
        # 惩罚只作用在变化率上，不动任务奖励的量纲；beta 从小往大升
        penalty = self.beta * torch.sum(rate ** 2, dim=-1)
        return obs, task_reward - penalty, done

解读：这是本章的"最小可运行改造"。（1）alpha 由 filt_tau 反推，不硬编码，让时间常数成为可解释参数：改平滑强度只改 τ；（2）惩罚取 raw_action，滤波已削掉高频，再惩罚滤波序列会低估策略的"抖动意图"；（3）除以 dt 是量纲细节：不除的话训练步长一变，β 的等效强度就变了；（4）prev_action 用 .clone() 防张量别名污染，这是批量环境的常见坑。把 β 从 0.1 提到 1.0，你会看到动作变"肉"、到点变慢。

片段 3：用 FFT 评估平滑度（找柔性模态的激励峰）

import numpy as np

def jerk_spectrum(tau_series, dt=1.0 / 60.0, band=(10.0, 30.0)):
    """对力矩序列做频谱分析：检查 10-30 Hz 柔性模态频段的能量占比。
    tau_series: shape=(T, n_joints)，一次到点运动的力矩记录。"""
    rate = np.diff(tau_series, axis=0) / dt            # 一阶差分 = 力矩变化率
    x = rate - rate.mean(axis=0, keepdims=True)        # 去直流：只关心动态分量
    window = np.hanning(x.shape[0])[:, None]           # 加汉宁窗：抑制频谱泄漏
    spec = np.fft.rfft(x * window, axis=0)             # 沿时间轴做实数 FFT
    freqs = np.fft.rfftfreq(x.shape[0], d=dt)
    power = np.abs(spec) ** 2                          # 功率谱
    lo, hi = band
    mask = (freqs >= lo) & (freqs <= hi)
    ratio = power[mask].sum() / max(power.sum(), 1e-12)  # 模态频段的能量占比
    peak = freqs[power.sum(axis=1).argmax()]           # 能量最大的频率
    return ratio, peak

# 用法：分别记录 beta=0 与 beta=0.3 的策略轨迹，比较 ratio 与 peak
# 预期：beta=0 时 10-30 Hz 占比可达 20%-40%，beta=0.3 后降到 5% 以下

解读：评估平滑度不能只看"最大力矩"（那衡量的是幅值，变化率才决定冲击），要对力矩变化率做频谱。加汉宁窗是必须的：一次到点运动只有 2–4 秒（120–240 个采样点），不加窗会因截断产生假频峰。判据 ratio 直接回答"策略有没有踩到结构模态"；peak 给出主频，帮助区分是策略低频摆动还是采样混叠（接近 25 Hz 的假峰）。预期：不惩罚时频段占比常在 20%–40%，加合理 β 后降到 5% 以下，到点时间只增加 5%–10%。

常见坑

  • 只滤波不惩罚：策略发现输出被滤波器"吃掉"后会主动输出反向高频来预补偿，噪声反而更大。修复：惩罚入口固定在滤波前（如片段 2），或滤波 + 惩罚双管齐下。
  • 惩罚项没归一化：直接用原始力矩（30 N·m 量级）平方差，β 稍微一调就天翻地覆。修复：动作先除以 τmax 再差分，β 在 0.01–0.5 间就有清晰效果。
  • β 过大导致"动作冻结"：策略发现"不动最平滑"，拒绝大动作，到点时间暴涨甚至学不会任务。修复：课程学习，从 β=0 逐步上升。
  • 把奖励历史当马尔可夫状态用：奖励里出现 τk−1 后，策略需要历史信息才能最优；观测不补上会训练不稳（表现为回报震荡）。修复：观测拼接上一步动作，或换循环策略。
  • 用未滤波的差分估 jerk：编码器量化噪声（如 0.001 rad 分辨率）在 60 Hz 下差分出的"jerk"全是噪声。修复：对信号做与物理带宽匹配的滤波后再差分。
  • 把平滑当万能药：与结构模态频率接近的强制往复运动（如 15 Hz）靠惩罚压不住，需要陷波滤波器（notch filter）或改机构；平滑只对宽带冲击有效。

练习与思考

  1. 用片段 1 生成 τ=0.02 s 与 τ=0.2 s 的速度剖面，画出两条曲线，标出总运动时间与峰值加速度的差别。★
    提示
    低通不改变低频（匀速段）只磨圆拐角，所以峰值加速度几乎不变；总时间差主要来自加速/减速两端的"圆角"。
  2. 在到点任务上扫 β = 0、0.05、0.1、0.3、1.0，记录（jerk RMS，到点时间），画出折中曲线并找到拐点。★★
    提示
    前几个 β 会大幅降 jerk 而时间几乎不变；β≥0.3 后时间开始明显上升。这就是选参数的依据。
  3. 把低通时间常数 τ 分别设为 0、20、80、200 ms 训练，预测并验证跟踪误差与相位延迟的关系。★★
    提示
    一阶低通对正弦的相位滞后约 arctan(2πfτ)：1 Hz 下 τ=80 ms 约滞后 27°，跟踪误差随滞后增大。
  4. 设计实验：把上一步动作加入观测（维度 +7），对比加与不加时的回报曲线与到点时间方差。★★★
    提示
    平滑奖励依赖历史，补齐观测后状态近似马尔可夫，训练应更稳；用多次随机种子的标准差衡量。
  5. 在仿真里给机械臂加一个 20 Hz 的柔性模态（如末端加弹簧-阻尼负载），对比 β=0 与 β=0.3 策略的末端振动包络，并用片段 3 验证频段能量变化。★★★
    提示
    柔性负载可用小质量块 + 弹簧阻尼关节近似；振动包络用末端位置滑动标准差量化。

小结

  • 振动的根源是 jerk（力变化率）：bang-bang 的加速度阶跃在 10–30 Hz 频段注入大量能量，激励柔性模态。
  • S 曲线 = jerk 受限的轨迹；一阶低通滤波与 jerk 受限近似等价（J ≈ amax/τ），代价是响应变慢。
  • RL 平滑三路径：奖励惩罚 Δτ²（推荐二阶差分）、输出低通滤波、动作参数化；推荐"弱滤波（40 ms）+ 惩罚（占损失 10%）"组合。
  • 平滑惩罚必须量纲归一化，β 过大导致动作冻结；观测应包含上一步动作以保证马尔可夫性；用 FFT 检查模态频段能量。
  • 验收三件套一起报：任务指标（到点时间/成功率）、平滑指标（jerk RMS、频段能量占比）、执行器指标（力矩变化率 P99）。
  • 下一章转向空间侧约束：机械臂在奇异位形附近雅可比退化，末端"想动却动不了"，需要用可操作度来度量并规避，见第 084 章。
