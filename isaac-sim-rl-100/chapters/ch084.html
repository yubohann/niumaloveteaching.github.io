第 084 章：实现避奇异位形

机械臂走到某些位形时"想动却动不了"：雅可比退化让某些方向彻底失控。本章用可操作度、条件数与阻尼最小二乘把这些禁区变成可度量、可绕开、也可安全穿越的对象。

  • 主题：控制与优化 / 雅可比与奇异性
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：50 分钟
  • 前置章节：第 083 章

学习目标

  • 理解奇异位形（singularity）的物理与数学含义：雅可比矩阵降秩、末端丢失自由度。
  • 掌握可操作度（manipulability）与条件数，理解它们与奇异值椭球的几何关系。
  • 会说清"避开"与"穿越"两条路线：可操作度奖励塑形 vs 阻尼最小二乘（DLS）。
  • 会在 RL 环境里设计可操作度观测与阈值型奖励，把"越远离越好"替换为只在临界带收费。
  • 能诊断奇异附近的关节速度爆炸、腕部奇异漏检、目标恰好落在奇异点时训练失败等问题。

背景与动机

机械臂的运动学关系是 ẋ = J(q)·q̇：雅可比矩阵 J 把"关节速度"翻译成"末端速度"。这个翻译在大多数位形下是良态的，但在奇异位形处会退化，某些末端方向再也无法产生，控制器为了完成一条本来做不到的指令，会要求关节以极高速度"硬凑"。真机上这表现为剧烈抖动、力矩饱和甚至保护性急停；仿真里你会看到一个"抽搐的机器人"却不知道为什么。

奇异位形并不罕见：肘部完全伸直的搬运姿态、手腕两个关节轴对齐的"钻孔"方向，都是日常会遇到的工作点。第 034 章的逆运动学与第 046 章的轨迹跟踪都默认雅可比可逆，本章把这块地基补上：让策略学会感知自己"离危险有多近"，从而绕开、减速通过或用阻尼软着陆。

核心原理

1. 奇异性：翻译失灵的地方

对 n 关节机械臂，末端位姿 x ∈ Rm（m=3 位置，或 m=6 位姿），速度映射为：

ẋ = J(q) · q̇，  J(q) ∈ Rm×n q̇ 是关节速度；J 的每一列是"该关节单独运动时的末端速度方向"

若 rank(J) < m，则末端某些运动方向不在 J 的列空间里，无论关节怎么动都产生不了。对方阵（m=n=6）判据是 det(J)=0；更通用的是看奇异值：把 J 做奇异值分解（SVD），奇异值 σ1 ≥ σ2 ≥ … ≥ σm，当最小奇异值 σmin → 0 时接近奇异。条件数 κ = σmax/σmin 则描述"各方向能力有多不均匀"。

2. 可操作度椭球：把 Jacobian 画出来

考察所有满足 ‖q̇‖ = 1 的关节速度，它们映射出的末端速度集合是一个椭球（可操作度椭球）：

椭球半轴方向 = J 的左奇异向量，长度 = 对应奇异值 σi σ 越小的方向，末端越"推不动"；σ_min=0 时该方向彻底失效

为把整只椭球的"体积"压成一个标量，Yoshikawa 定义可操作度：

w(q) = √det(J·JT) = σ1·σ2·…·σm w 与椭球体积成正比；w=0 即奇异，w 越大各方向越均衡

几何直觉：w 是椭球体积，σmin 是椭球最扁的那根半轴。关心"会不会失控"要看 σmin（最扁方向），关心"整体灵活度"才看 w，这是两个常用但容易混淆的指标。

3. 奇异附近的灾难：速度爆炸

用伪逆做逆运动学 q̇ = J+ẋ 时，J+ 含 1/σi 因子。当 σmin = 0.01 而期望末端速度 0.1 m/s 时，沿该方向的关节速度需求高达 10 rad/s，远超关节限速。关节速度被打到上限后，实际末端运动又达不到期望，误差积分放大，形成"指令—饱和—误差"的恶性循环。

4. 两条路线：避开与穿越

路线做法适用
避开（回避）把 w 或 σmin 写进奖励/约束，让轨迹绕开奇异区有冗余空间可绕；任务不要求穿越奇异
穿越（软化）阻尼最小二乘：q̇ = JT(JJT + λ²I)−1ẋ必须经过奇异附近；用精度换稳定

阻尼最小二乘（DLS，也叫 Levenberg–Marquardt 法）的核心思想：给小奇异值方向"注水"。λ 很小（0.001）时几乎等于伪逆；λ 增大时，该方向的等效增益从 1/σ 变成 σ/(σ²+λ²)，在 σ→0 时趋于 0，不会发散到无穷，接受"这个方向暂时动不了"，换取速度不发散。实践中 λ 随可操作度自适应：λ = λ0(1 − w/w0)²，远离奇异时自动关闭。

5. 数值算例：伪逆与 DLS 的速度—精度交易

设末端在弱方向上的期望速度 0.1 m/s，该方向对应 σ = 0.01。两种解法：

伪逆：q̇ = ẋ/σ = 0.1/0.01 = 10 rad/s DLS 在 λ = 0.02 时约 2.0 rad/s（末端实际速度 0.02 m/s）；λ = 0.05 时约 0.38 rad/s（约完成期望的 3.9%）

数字读法：DLS 把"不可完成的期望"转化为"可执行的小速度"，用精度换稳定。λ = 0.02 时关节速度约是伪逆的 1/5，末端完成期望的 20%；λ = 0.05 时速度约 1/26，完成不足 4%。穿越策略的实质是承认"弱方向做不满"，把剩余需求交给时间与冗余姿态去消化。选 λ 时先定两条界：关节速度上限（本例 2 rad/s）决定 λ 下限，任务允许的末端短差决定 λ 上限。

6. 阈值标定与速度放大倍数

σsafe 与 σref 应从数据里定。标定流程：跑一条覆盖工作空间的名义轨迹，记录 σmin 分布，取分位数：

统计量示例值用途
中位数0.15σ_ref：观测归一化的参考刻度
第 10 百分位0.03σ_safe：进入惩罚带的门限
最小值0.005危险区实际下限，检查观测分辨率是否够

把 σ 阈值换算成速度放大倍数（1/σ）便于直觉判断：σ = 0.15 时约 6.7 倍，0.03 时约 33 倍，0.01 时 100 倍，0.005 时 200 倍。放大倍数就是"弱方向需要多夸张的关节速度"：33 倍以上普遍超过关节限速，所以 0.03 在 Franka 量级上作为门限合理；换机器人要重新标定这张表。

7. 三种逆解做法的对照

做法关节速度精度连续性
伪逆σ→0 时无界理论上完全跟踪奇异处不连续，控制器易振荡
DLS（阻尼）有界（由 λ 控制）弱方向按比例折损平滑连续
截断 SVD有界（直接丢弃弱方向）弱方向完全放弃阈值处有跳变

三种做法里，DLS 是"平滑 + 有界"的组合，代价是弱方向精度按 λ 折损；截断 SVD 更激进，适合"宁可不动、绝不抽搐"的场景；伪逆只在远离奇异时使用。工程实现通常给出"伪逆 + 自适应 DLS"的混合：σmin 高于门限走伪逆（精度满血），跌破门限自动切 DLS（安全优先），两条曲线在切换点处连续，行为不会跳变。

8. 三个指标的数值对照

σmin、可操作度 w、条件数 κ 从不同侧面描述同一个雅可比。设某位形的奇异值为 1.0、0.8、0.6、0.4、0.2、0.01，三个指标的读数如下：

指标计算读数主要用途
σ_min最小值0.01（放大倍数 100）安全判据：最弱方向会不会失控
w = ∏σ_i六值连乘约 3.8 × 10⁻⁴整体灵活度：椭球体积
κ = σ_max/σ_min最大除以最小100数值病态程度：求解器灵敏度

对照要点：这组奇异值里 σmin = 0.01 已经危险，但 w 的数值看起来只是一个很小的数、没有直观阈值；κ = 100 提示数值上接近病态但仍可解。三个指标里，σmin 最适合做安全门限（量纲干净、物理含义直接），w 适合做全局的能力地图（扫描工作空间时画等值线），κ 适合做数值诊断（判断线性求解会不会放大误差）。选定指标后，把阈值与标定流程写进实验记录，与随机化范围一样随结果存档。三个指标在工作空间内的分布（热图）是设计课程与采样范围的省事工具：先扫一遍 σ_min 热图，把目标采样区间限定在"大部分区域 σ_min 高于门限、局部允许穿越"的范围内，再进入训练。

实现思路与设计

  1. 先选指标：以任务需要穿越的姿态自由度为准，6 维任务就取 σmin(J6×n)，只关心位置可先用 3×n 位置雅可比，但要小心漏检腕部奇异（下节详述）。
  2. 观测加"安全裕度"：把归一化后的 σmin/σref（σref 取典型工作位形的数值，如 0.15）拼进观测。策略看不到自己离奇异多远，就学不会提前规避。
  3. 奖励用阈值型：当 σmin < σsafe（如 0.03）时施加惩罚 β·(σsafe−σmin)²；不要写成"σmin 越大越好"的线性项，否则策略会为了可操作度牺牲任务精度（例如总往工作空间中体积最大的位置跑）。
  4. 穿越场景加阻尼惩罚：直接惩罚关节速度的峰值 ‖q̇‖∞，等价于对"硬凑"行为收费；或把底层控制器从伪逆换成 DLS（λ=0.01–0.05），让安全由结构保证。
  5. 目标采样覆盖危险区：课程里主动把一部分目标放在奇异附近（肘伸直方向 ±0.1 rad），否则策略没见过危险场景，评估时的成功率是幻觉。
  6. 评估指标：任务成功率、轨迹上 σmin 的最小值、关节速度峰值的 P99、以及"接近奇异的时长占比"。
设计思维：避奇异不是"越远越好"

可操作度最大的位形（肘弯 90°）往往离目标最远，单纯最大化 w 会把任务做慢做偏。正确姿势是"任务奖励为主，奇异惩罚只在临界区激活"：远离奇异时惩罚为零（策略完全自由），进入 σmin < σsafe 的临界带才开始收费。这条"惩罚只在需要时出现"的原则也适用于第 085 章的关节限位。

关键代码与解读

片段 1：读取雅可比并计算可操作度与条件数

import torch

def manipulability_metrics(jacobian, sigma_safe=0.03):
    """通用工具：输入雅可比张量 J（batch, m, n），返回可操作度与安全裕度。
    不同 Isaac Sim 版本获取雅可比的方法名有差异（如 get_jacobian 系列），
    注意确认返回坐标系是"基座系"还是"世界系"，以及是否已含末端帧偏移。"""
    # SVD：σ 是奇异值，V 是右奇异向量（关节侧方向），U 是末端侧方向
    U, S, Vh = torch.linalg.svd(jacobian)          # S: (batch, min(m, n))
    sigma_min = S[:, -1]                           # 最小奇异值：最"扁"方向的能力
    sigma_max = S[:, 0]
    kappa = sigma_max / sigma_min.clamp(min=1e-6)  # 条件数：放大"不均匀程度"
    # 可操作度 = 全部奇异值之积（对 6x7 等非方阵同样成立，因 S 只有 min(m,n) 个）
    w = S.prod(dim=-1)
    # 安全裕度：只在临界带内为正，供阈值型奖励使用
    margin = (sigma_safe - sigma_min).clamp(min=0.0)
    return {"w": w, "sigma_min": sigma_min, "kappa": kappa, "margin": margin}

解读：这段代码把"离奇异多远"从抽象概念变成三个可训练的数字。选择 SVD 作为指标有三个理由：非方阵（7-DoF 对 6 维任务）根本没有 det；det 的量纲随长度单位变化（米制改毫米相差 10⁹ 倍）；det 的绝对值不区分"一个方向很弱"和"多个方向都弱"，SVD 分得清。clamp(min=1e-6) 防条件数在精确奇异处除零；margin 只在 σmin 跌破 0.03 后才为正，直接对应片段 3 的阈值惩罚。注意注释里的坐标系提醒：雅可比随参考系不同数值不同，但奇异值（可操作度、条件数）对基座系/世界系的刚体变换是不变的，这是选择 SVD 指标、放弃原始元素的又一层理由。

片段 2：阻尼最小二乘逆运动学（穿越奇异的安全通道）

import torch

def dls_ik_step(jacobian, twist_err, qdot_max=2.0, lam0=0.05,
                w_ref=0.05, dt=1.0 / 60.0):
    """阻尼最小二乘逆解一步：q_dot = J^T (J J^T + λ²I)^{-1} * twist_err。
    当可操作度低时自动增大 λ：用精度换稳定，避免关节速度爆炸。"""
    m = jacobian.shape[1]
    eye = torch.eye(m, device=jacobian.device).expand(jacobian.shape[0], m, m)
    # 自适应阻尼：w 越小 λ 越大。这里用 σ_min 近似代替 w（量纲更干净）
    _, S, _ = torch.linalg.svd(jacobian)
    sigma_min = S[:, -1]
    scale = ((w_ref - sigma_min) / w_ref).clamp(min=0.0, max=1.0)  # 0=远离, 1=奇异
    lam = lam0 * scale ** 2                        # 平方使阻尼只在临近奇异时显著
    JJt = jacobian @ jacobian.transpose(-1, -2)    # (batch, m, m)
    damped = JJt + (lam ** 2).view(-1, 1, 1) * eye  # 对角加 λ²：给小 σ 方向"注水"
    y = torch.linalg.solve(damped, twist_err.unsqueeze(-1))   # 解 (JJt+λ²I) y = ẋ
    q_dot = (jacobian.transpose(-1, -2) @ y).squeeze(-1)      # J^T y
    # 关节速度限幅：即便 DLS 也保留硬上限，双保险
    q_dot = torch.clamp(q_dot, -qdot_max, qdot_max)
    return q_dot, lam

解读：DLS 是本章"穿越"路线的核心公式，逐项看：JJt + λ²I 把原方程的病态对角"垫高"，从而保证可逆且条件数有界；solve 是数值惯例（稳定、快），显式求逆会放大误差。自适应 λ 用平方映射是个工程技巧：σmin=0.049（离阈值 0.05 很近）时 scale=0.02，λ≈0.05·0.0004=2e-5，几乎无感；σmin=0.005 时 scale=0.9，λ≈0.04，精度显著下降但速度安全。把 DLS 放在底层控制器里，RL 策略只需输出笛卡尔速度指令，这是混合架构（学习高层 + 经典底层）在奇异问题上的典型分工。最后一句关节速度限幅是"双保险"：DLS 已经防止发散，但仿真里参数异常时硬限幅能避免崩坏。

片段 3：把安全裕度接入观测与奖励

class SingularityAwareEnv:
    """在末端跟踪任务上叠加奇异感知：观测给裕度，奖励在临界带内收费。"""

    def __init__(self, num_envs, sigma_safe=0.03, beta_sing=0.5):
        self.sigma_safe = sigma_safe      # 安全阈值：按机器人典型工作位形标定
        self.beta_sing = beta_sing        # 惩罚权重：先小后大的课程里逐步提升
        self.sigma_ref = 0.15             # 归一化参考值：典型位形下的 σ_min

    def compute_obs(self, joint_pos, joint_vel, ee_err, jacobian):
        metrics = manipulability_metrics(jacobian, self.sigma_safe)
        # 观测里给归一化裕度：0 表示远离奇异，1 表示已进入危险带
        risk = 1.0 - (metrics["sigma_min"] / self.sigma_ref).clamp(0.0, 1.0)
        return torch.cat([joint_pos, joint_vel, ee_err, risk.unsqueeze(-1)], dim=-1)

    def compute_reward(self, ee_err, metrics):
        # 任务项：跟踪误差；奇异项：只在临界带内为正（阈值型，不干扰任务）
        task = -torch.linalg.norm(ee_err, dim=-1)
        risk_penalty = self.beta_sing * metrics["margin"] ** 2
        return task - risk_penalty

解读：三个设计点。（1）观测用 risk 取代原始 σmin：归一化到 [0,1] 后与其它观测分量尺度一致，网络不必学一个"0.15 是好、0.01 是危险"的隐式标尺；（2）奖励的 margin² 是阈值型的：σmin > 0.03 时恒为 0，策略在这片广阔区域里完全自由，这避免了第 083 章那种"惩罚无处不在导致行为扭曲"的毛病；（3）惩罚取平方，让惩罚在刚进入临界带时很轻（σmin=0.025 → margin=0.005 → 惩罚 0.5·2.5e-5≈1e-5），逼近奇异时急剧变重，形成"软墙"。sigma_safe 和 sigma_ref 怎么定：先跑一条经过全部工作空间的名义轨迹，记录 σmin 的分布，取 10% 分位数为 σsafe、中位数为 σref，用数据标定，不要拍脑袋。

常见坑

  • 用 det(J) 当奇异指标：7-DoF 等非方阵根本没有定义；即使是 6×6，det 的量纲是 (m/rad)⁶，换单位就变，且不反映"哪个方向弱"。修复：统一用 σmin 或可操作度。
  • 只算位置雅可比导致腕部奇异漏检：3×n 位置雅可比对"关节 4、6 轴共线"完全不敏感，策略会在姿态失控时毫无预警。修复：姿势自由度相关的任务一律用 6×n 雅可比。
  • 伪逆不设阻尼：直接用 pinv 在 σ=0.002 的位形上会输出几十 rad/s 的关节速度指令。症状是仿真中机械臂突然抽搐/穿模。修复：DLS 或至少一份关节速度硬限幅。
  • 可操作度写成线性奖励：σmin 越大越好会诱导策略放弃任务精度、永远躲在工作空间中央。修复：阈值型惩罚，临界带外零代价。
  • 训练目标从不经过危险区：评估时把目标放在肘伸直方向，成功率骤降，训练分布没有覆盖，泛化无从谈起。修复：目标采样与课程主动覆盖近奇异点。

    平面 2R 的可操作度正比于 |sin(q2)|·l1·l2；q2=90° 体积最大，q2=0° 或 180°（手臂伸直/对折）为零。
  2. 固定一个恰好落在奇异点附近的笛卡尔目标，对比伪逆与 DLS 的关节速度轨迹，记录峰值速度与末端收敛时间。★★
    提示
    伪逆会出现速度尖峰甚至发散；DLS 速度平滑但末端留有稳态误差，把轨迹画在一起最能说明"用精度换稳定"。
  3. 把 σsafe 分别设为 0.01、0.03、0.08 训练奇异感知策略，记录最小 σmin、成功率与到点时间。★★
    提示
    σsafe 越大越保守：轨迹离奇异越远、但绕路变多。目标是找到"成功率高且时间代价小"的拐点。
  4. 用 7-DoF 机械臂设计：在零空间里优化可操作度（关节裕度允许时），画出任务误差与 σmin 的联合变化。★★★
    提示
    零空间投影 q̇ = J⁺ẋ + (I−J⁺J)z，z 取可操作度梯度方向；有冗余时任务不受影响，只是"顺手"把姿态调得更安全。
  5. 实验设计：把训练目标 20% 采样在肘伸直方向 ±0.1 rad 范围内，对比有无奇异惩罚时的失败模式（速度爆炸 vs 提前绕行）。★★★
    提示
    无惩罚的策略常用"高速甩过去"通过危险区，记录关节速度 P99；有惩罚的策略会减速并微调姿态。

小结

  • 奇异位形 = 雅可比降秩：末端丢失某些方向的能力，伪逆求出的关节速度趋于爆炸。
  • 用 SVD 度量：可操作度 w = ∏σi（椭球体积）描述整体灵活度，σmin 描述最弱方向；两者对参考系变换不变。
  • 两条路线：避开（阈值型可操作度奖励 + 观测裕度）与穿越（自适应阻尼最小二乘 λ = λ0(1−w/w0)²）。
  • 奖励原则：惩罚只在临界带内激活，绝不做"可操作度越大越好"的线性塑形；DLS 的关节速度硬限幅是最后一道保险。
  • 下一章处理另一类"禁区"：关节自身的物理限位。数学结构相似（都是约束），但约束作用在关节空间这一侧，任务空间是上一章的对象，见第 085 章。
