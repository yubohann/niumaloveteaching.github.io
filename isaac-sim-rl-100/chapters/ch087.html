第 087 章：实现力位混合控制

擦桌子要控制压力、插孔要控制侧向位置：同一个任务里，有的方向该管位置、有的方向该管力。本章讲透选择矩阵与接触坐标系，把"哪些方向管什么"变成代码。

  • 主题：控制与优化 / 接触任务与力控
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：55 分钟
  • 前置章节：第 086 章

学习目标

  • 理解纯位置控制在刚性接触下为什么会"力爆炸"，以及环境约束与自由度互补的本质。
  • 掌握选择矩阵（selection matrix）与接触坐标系（C-frame）的推导直觉与构造方法。
  • 会说清混合控制与阻抗控制的适用边界，以及为什么工业装配两者都用。
  • 会在 RL 环境里接入力/力矩观测（含滤波与延迟建模），设计位置与力分离的奖励。
  • 能诊断力信号噪声、选择矩阵坐标系错配、接触瞬间的冲击等常见问题。

背景与动机

前五章都在"自由空间"里练功：机械臂不与环境接触，位置与姿态就是全部目标。但真实任务的一半以上发生在接触中，擦桌面、拧螺丝、插连接器、装配轴承。这类任务的物理是位置与力通过环境刚度耦合的：刚性桌面上，位置指令多给 1 mm，接触力可能暴涨几十牛。

纯位置控制在这里必然失败：要么力太小滑脱，要么力太大压坏工件。工程师的答案是把六个方向"分权"：沿能被环境约束的方向控位置，沿力可改变的方向控力。这就是力位混合控制（hybrid force/position control），也为第 089/090 章的高动态操作打基础。

核心原理

1. 接触让位置控制失效的定量原因

接触可以用弹簧模型近似：环境刚度 kenv。机器人力控（或位置伺服）本质上输出的是位置指令 xcmd，与真实接触位置 xc 的差被环境刚度放大成力：

f = kenv · (xcmd − xc) k_env 对钢件可达 10⁵–10⁶ N/m：0.1 mm 的位置误差 = 10–100 N 的力

数字很直观：钢对钢 10⁵ N/m，插入多走 0.5 mm 就是 50 N，足以压弯薄壁件。而环境的真实位置 xc 你并不精确知道（工件有公差、标定有误差）。在接触方向继续"管位置"，等于把力交给运气。

2. 自由度互补：环境管什么，机器人管什么

一个深刻的观察：在刚性接触下，每个方向要么被环境约束（位置由环境决定、力由机器人决定），要么自由（位置由机器人决定、力恒为零）。环境的约束面（C-surface）把六个方向分成两类：

方向类型环境侧机器人侧例子（平面接触）
受约束方向（法向）位置被挡住可以施加力竖直方向的压力
自由方向（切向）位置不受限不能"施加切向力"而不产生运动水平面的滑动位置

所以强行在受限方向控位置、或在自由方向控力，都只会得到无意义的结果。混合控制的本质是分工。

3. 选择矩阵：把"分工"写成数学

用一个对角矩阵 S（对角元为 0 或 1）标记每个方向的控制模式，混合控制律为：

fcmd = S · fpos + (I − S) · fforce S 的对角元 1 = 该方向执行位置控制律；0 = 执行力控制律

两种控制律各自可以很简单：位置律是笛卡尔 PD（fpos = Kpex + Kdẋ），力律是 PI（fforce = Kf(fd − f) + Ki∫…）。合成后的笛卡尔指令再经雅可比转成关节力矩：

τ = JT · fcmd J^T 是"笛卡尔力 → 关节力矩"的对偶映射；加零空间项可同时做姿态优化

S 必须定义在接触坐标系（C-frame）里：以接触面法向为一个轴（法向控力），切向两轴控位置/速度。同一组关节在桌面与墙面任务里 S 的数值不同，因为 C-frame 转了，这也是踩坑重灾区：S 与坐标系错配，控制器行为立刻自相矛盾。

4. 与阻抗控制的对照

另一大流派是阻抗控制（第 048 章）：不显式分工，改为把末端塑造成一个"弹簧-阻尼系统"，与环境交互力自然平衡：

M·ẍ + D·ẋ + K·(x − xd) = −fext 刚度 K 小 = 柔和（力控制倾向）；K 大 = 刚硬（位置控制倾向）
维度混合控制阻抗控制
前提需要知道接触几何（S 与 C-frame）不需要方向先验
力跟踪精度高（独立积分器）中（取决于环境刚度匹配）
几何不确定时S 错方向则失效鲁棒但精度下降
典型场景已知表面的抛光/擦除/插入未知环境的接触交互

实践中常见"混合 + 阻抗"的组合：法向用阻抗（远距离安全接近，接触时柔和），切向用位置/速度控制。RL 的定位是把选择矩阵与 C-frame 交给传统控制层，让策略去学力/位置的参考值与切换时机。

实现思路与设计

  1. 先定 C-frame：从接触面法向构造正交基（如桌面法向 +z，切向由任务方向决定）。所有 S、力误差、位置误差都在这个系里计算；每步根据当前接触几何更新。
  2. 选择矩阵按任务写死还是学习：几何已知的任务写死最稳（法向 0、切向 1）；几何不确定时可以让策略输出"软选择"（连续门控），但训练难度显著上升。本课建议先用写死的 S。
  3. 动作空间的两层设计：策略输出 (a) 期望法向力 fd（限幅 0–30 N）与 (b) 切向速度/位置参考；底层混合控制器负责力与位置的跟踪。这比"直接输出力矩"学得快，也比"只输出位置"安全。
  4. 观测设计：末端六维力/力矩（经低通滤波与 1–2 步延迟模拟）、位置误差（C-frame 下）、切向速度、接触状态标志。滤波与延迟是必须的，真实力传感器都有。
  5. 奖励分离：r = −wf·|fn − fd| − wv·|vt − vd| − wc·(接触冲击惩罚)。法向力权重与切向速度权重按任务优先级给（如抛光：力精度优先）。
  6. 课程：先在自由空间学接近（纯位置），接触后亮出力的目标；冲击惩罚从松到紧。
  7. 评估：力跟踪误差（均值与波动 RMS）、切向速度跟踪、接触瞬间力峰值的 P95、任务完成时间。
设计思维：为什么不让 RL 直接学全部？

理论上 RL 可以从观测到力矩端到端学出混合控制，但不推荐把"哪个方向控力"也交给它：这个先验非常廉价（看一眼接触几何就得到），交给传统层是零样本成本；留给 RL 的"力的参考值与接触时机"才是真正需要数据学习的不确定部分。能用几何/物理写清楚的部分用经典控制，剩下不确定的交给学习。

关键代码与解读

片段 1：选择矩阵与混合控制律的合成

import torch

def hybrid_force_control(ee_pos, ee_vel, f_ext, x_des, v_des,
                         f_des, R_c, S_diag, Kp, Kd, Kf, Ki, i_err,
                         dt=1.0 / 60.0):
    """笛卡尔混合力位控制：C-frame 下按 S 分流，返回关节力矩。
    R_c: (B,3,3) 接触坐标系旋转矩阵（世界←C）；S_diag: (6,) 0/1 选择对角。"""
    # 1) 把位置/速度/力都转到 C-frame：S 只有在 C-frame 才有物理意义
    S = torch.diag(S_diag).expand(R_c.shape[0], 6, 6)     # (B,6,6) 选择矩阵
    e_p_c = R_c.transpose(-1, -2) @ (x_des - ee_pos).unsqueeze(-1)   # 位置误差→C
    v_c = R_c.transpose(-1, -2) @ ee_vel.unsqueeze(-1)               # 速度→C
    f_c = R_c.transpose(-1, -2) @ f_ext.unsqueeze(-1)                # 接触力→C
    # 2) 位置律：PD（只对 S=1 的方向生效，其它方向被 S 置零）
    f_pos = Kp * e_p_c - Kd * v_c + Kd * v_des.unsqueeze(-1)
    # 3) 力律：PI（只对 S=0 的方向生效）
    f_err = f_des.unsqueeze(-1) - f_c
    i_err = i_err + f_err * dt                # 积分项由调用方保存并重置
    f_force = Kf * f_err + Ki * i_err
    # 4) 合成：S 与 (I−S) 互补，绝不重叠、绝不漏项
    f_cmd_c = S @ f_pos + (torch.eye(6) - S) @ f_force
    f_cmd_w = R_c @ f_cmd_c                   # 转回世界系，才能过雅可比
    return f_cmd_w.squeeze(-1), i_err

解读：（1）先做坐标变换再分流，S 与 C-frame 绑定，若在世界系直接套用，桌面水平与倾斜放置会得到完全错误的分工；（2）S @ f_pos + (I−S) @ f_force 是互补投影：任何方向要么吃位置律、要么吃力律，不重叠不漏项；若 S 取连续值（软选择），两项和仍是完备分解，这就是"学习门控"的入口；（3）积分项由外部持有：脱离接触时力恒为零会使积分器饱和（windup），需要清零，这个细节决定"第二次接触会不会猛冲"。量纲参考：Kp=2000 N/m、Kf=0.5、Ki=2.0/s。

片段 2：力观测的滤波与接触状态机

class ForceObserver:
    """力信号预处理：低通滤波 + 接触检测 + 冲击标记。
    真实力传感器噪声 0.1-0.5 N、带宽约 100 Hz，仿真里也应加入噪声与滤波。"""

    def __init__(self, num_envs, dt=1.0 / 60.0, cutoff=20.0, f_on=2.0, f_off=0.5):
        self.alpha = dt / (1.0 / (2 * 3.14159 * cutoff) + dt)  # 一阶低通系数
        self.f_filt = torch.zeros(num_envs, 6)      # 滤波后的六维力
        self.in_contact = torch.zeros(num_envs, dtype=torch.bool)
        self.f_on, self.f_off = f_on, f_off          # 施密特触发双阈值：防抖
        self.prev_contact = self.in_contact.clone()

    def update(self, f_raw):
        # 低通滤波：力信号比位置信号噪声大，20 Hz 截止去掉大部分毛刺
        self.f_filt = self.f_filt + self.alpha * (f_raw - self.f_filt)
        fn = self.f_filt[:, 2].abs()                 # 假设 z 为法向：只看法向幅值
        # 双阈值：进入用高阈值、退出用低阈值，避免在临界点反复翻转
        enter = (~self.in_contact) & (fn > self.f_on)
        exit_ = self.in_contact & (fn < self.f_off)
        prev = self.in_contact.clone()
        self.in_contact = (self.in_contact | enter) & (~exit_)
        # 冲击事件：本步刚进入接触，用于惩罚/统计接触瞬间的力峰值
        impact = self.in_contact & (~prev)
        return self.f_filt, self.in_contact, impact

解读：传感器数据不能直接使用。（1）一阶低通 20 Hz 截止：策略要知道的是准静态接触力，噪声进观测只会让网络对噪声反应、动作抖振；（2）施密特触发双阈值（进入 2 N、退出 0.5 N）是接触检测标准做法：单阈值在 1 N 附近随噪声反复翻转，观测与奖励剧烈震荡；（3）impact 标记"刚进入接触"，供奖励对冲击惩罚，否则策略学会"砸上去"（快进入接触在位置指标上反而好看）。滤波引入约 8 ms 延迟，加传感器自身延迟共 20–30 ms，是接触控制不可消除的物理事实；可再拼接历史值帮助策略推断趋势。

片段 3：分离式奖励与训练统计

def hybrid_reward(force_c, v_t_c, f_des, v_des, impact, time_scale=0.01,
                  w_f=1.0, w_v=2.0, w_impact=1.0):
    """力位混合任务的奖励：法向力跟踪 + 切向速度跟踪 + 冲击惩罚。
    force_c/v_t_c 均在 C-frame 下；法向取 z 分量，切向取 x,y。"""
    f_n = force_c[..., 2]
    v_t = torch.linalg.norm(v_t_c[..., :2], dim=-1)
    r_force = -w_f * (f_n - f_des).abs()          # 力跟踪误差（N）
    r_speed = -w_v * (v_t - v_des).abs()          # 切向速度误差（m/s）
    r_impact = -w_impact * impact.float() * 0.5   # 冲击一次性惩罚（等效 -0.5）
    return r_force + r_speed + r_impact - time_scale

# 训练循环中记录三个指标，分开判读：
# 力跟踪 RMS < 1.5 N（目标力 10 N 时约 15%）视为可用
# 切向速度 P50 误差 < 0.02 m/s；冲击峰值力的 P95 应随训练下降

解读：加权方式是本章"分离"思想在奖励层的体现：w_v=2.0 比 w_f=1.0 大，因为速度误差 0.1 m/s 与力误差 0.5 N 在数量级上"等重"（1 N 的力差对整体行为的影响小于 0.2 m/s 的速度差），权重的依据是量纲换算，无关审美偏好。冲击惩罚取一次性 −0.5（叠加时间税）：冲击属于瞬时事件，不宜按状态逐步累积，一次性惩罚与"避免砸上去"的行为模式对齐。判读经验：训练后期力跟踪 RMS 通常卡在 1–2 N（传感器噪声 + 环境刚度估计误差的下限）；如果切向速度误差大而力误差小，说明权重偏了或底层速度环带宽不够。

常见坑

  • S 与坐标系错配：在错误系里应用选择矩阵，接触方向"管位置"、自由方向"管力"，力暴涨与乱窜同时出现。修复：误差先转 C-frame，单测验证（法向手动位移 → 只该有力变化）。
  • 力噪声直接进观测：未滤波的 0.3 N 噪声让策略产出 10 Hz 抖动。修复：低通（20 Hz）+ 拼接历史值；训练时也把噪声加进仿真。
  • 积分器 windup 未处理：脱离接触期间力误差持续累积到饱和，再次接触时"猛推"。修复：无接触时清零积分项或限幅（±10 N 等效）。
  • 位置/力权重失衡：力权重太大策略"不敢碰"、磨蹭到超时；太小则撞击频繁。修复：从等效量级 1:1 起步，看指标二分调整。
  • 用位置控制模式做接触：大刚度位置伺服在接触瞬间产生冲击力尖峰。修复：接触方向用阻抗/力控模式，或在仿真中合理设置接触刚度与阻尼。

练习与思考

  1. 构造桌面擦除任务：法向保持 10 N、切向速度 0.1 m/s。写出 S 与 C-frame 的具体数值。★
    提示
    桌面法向竖直向上，C-frame 即世界系；S 的法向位取 0（力控）、其余取 1（位置速度控制）。
  2. 把低通截止频率从 20 Hz 改到 50 Hz 与 5 Hz，观察力跟踪误差与动作抖动的变化。★★
    提示
    截止越高延迟越小但噪声越大；越低越平滑但相位滞后拖慢力环。用（力 RMS，动作频谱高频能量）两指标对比。
  3. 实验：把积分项在脱离接触时的清零去掉，观察第二次接触的力峰值与恢复时间。★★
    提示
    无接触时力误差恒不为零，积分器持续累积到饱和；再次接触时一次性释放，形成"猛推"。对比两次接触的峰值力。
  4. 设计对比实验：混合控制（写死 S）vs 纯 RL 直接出力矩，在工件位置 ±3 mm 扰动下比较成功率与样本效率。★★★
    提示
    写死 S 对 3 mm 级扰动通常仍鲁棒；端到端 RL 需更多样本覆盖扰动。比较达到 80% 成功率所需的环境步数。
  5. 把法向改为阻抗控制（刚度 500→5000 N/m 扫），与纯力控对比"接触几何未知 ±5 mm"情形下的表现。★★★
    提示
    画（力跟踪误差 P50）vs（几何误差）两条曲线：阻抗随几何误差增长平缓，积分力控在单向几何偏差下有稳态误差。

小结

  • 刚性接触下位置误差被环境刚度 kenv 放大成力（10⁵ N/m × 0.1 mm = 10 N），接触方向必须改管力。
  • 自由度互补：环境约束的方向控力、自由方向控位置/速度；选择矩阵 S 把分工写成 fcmd = S·fpos + (I−S)·fforce，且必须在接触坐标系 C-frame 里定义。
  • 混合控制精度高但依赖接触几何先验；阻抗控制鲁棒但力跟踪精度中等；真实系统常组合使用。
  • RL 接口推荐"策略输出力参考 + 速度参考，底层混合控制器执行"；力观测必须滤波、用双阈值做接触检测、对冲击单独惩罚。
