第三篇 · 高级强化学习专题

第 067 章：实现系统辨识

用激励轨迹把真机的质量、惯量、摩擦"问"出来：本章讲清刚体动力学对参数线性的性质、最小二乘辨识、可辨识性与激励设计，并把辨识结果写回 Isaac Sim。

  • 主题：Sim2Real / 参数估计
  • 相关组件：Isaac Sim / Isaac Lab / NumPy / SciPy
  • 预计学时：60 分钟
  • 前置章节：第 066 章

学习目标

  • 理解刚体动力学方程对惯性参数是线性的：τ = Y(q, q̇, q̈)·β 的来历与结构。
  • 会用最小二乘（含正则化）估计参数，并解释加权、正则与条件数的作用。
  • 理解可辨识性：为什么只有基础参数集（base parameters）能被辨识，如何处理秩亏。
  • 会设计傅里叶级数激励轨迹，让数据"信息量"足够（持续激励）。
  • 会做交叉验证：用留出轨迹的力矩预测误差判断辨识质量，不只依赖拟合残差。
  • 会把辨识结果写回 Isaac Sim，并与域随机化的中心/宽度联动。

背景与动机

第 066 章说"随机化分布要覆盖真机参数"，但真机那条腿的质心到底在哪、关节摩擦系数是 0.4 还是 0.9？这些数字不能靠猜。系统辨识（System Identification, SI）就是用实验数据反推模型参数：让机器人做一组精心设计的运动，记录关节位置、速度、电机力矩，然后解一个最小二乘问题，得到质量、惯量、质心、摩擦系数。

辨识在 Sim2Real 管线中扮演"锚点"角色：辨识值给出动力学参数的中心估计，域随机化围绕它展开；第 068 章的差距分析有了它才能判断"仿真里剩下的误差是参数错还是模型结构缺失"。它的边界也要说清楚：辨识只能修正模型结构内的参数，无法弥补模型结构本身的缺失（比如没有建模的柔性、齿隙）。

核心原理

1. 为什么动力学对参数是线性的

机械臂的刚体动力学方程形如 M(q)q̈ + C(q, q̇)q̇ + g(q) = τ。看起来对参数密密麻麻非线性，但关键性质是：惯性参数（连杆质量、一阶质心矩、惯量张量）进入方程的方式是线性的。把每条连杆的 10 个惯性参数排成一个向量 β（或把 n 自由度系统排成 10n 维向量），有：

τ = Y(q, q̇, q̈) · β + τf(q̇; βf) Y 称为回归矩阵（regressor），只依赖运动学量 q、q̇、q̈，不含参数

直觉来源：动能是 ½q̇TM(q)q̇，而 M(q) 的每一项都是惯性参数乘以运动学函数的和，质量以一次方出现。于是参数估计变成线性回归问题，可以用最小二乘一次解出，不需要非线性优化。这是机器人辨识教科书（如 Khalil、Siciliano 的经典处理）的基石。

2. 最小二乘解与它的三个工程变体

在一次激励运动中共采样 N 个时刻（1 kHz 采集 10 秒 = 10000 个数据点），堆叠回归矩阵与力矩向量，得到超定方程组 Y·β ≈ τ，最小二乘解：

β̂ = (YTY + λI)−1 YT τ λ>0 即岭回归：对付病态矩阵（条件数大）时防止解爆炸；λ=0 是标准最小二乘

三个工程变体：加权最小二乘，不同速度段噪声不同（低速段摩擦辨识方差大），按信噪比加权；物理一致性约束，质量必须为正、惯量矩阵必须正定，解出后要检查，必要时加约束或截断；分步辨识，先静态（重力+静摩擦）后动态，降低联合辨识难度。摩擦项 τf = Fc·sign(q̇) + Fv·q̇ 对 Fc、Fv 也是线性的，把 sign(q̇) 与 q̇ 作为两列追加进 Y 即可一起估计。

3. 可辨识性：你只能看到参数的和

不是所有参数都能被"单独"看到。举例：一条只做单轴旋转的连杆，其绕旋转轴的惯量与电机转子惯量在方程里以"和"的形式出现（Ilink + Imotor），任何数据都分不开这两项。数学上这表现为回归矩阵 Y 秩亏：只有落在 Y 行空间内的参数组合可辨识，这些组合叫基础参数（base parameters）。处理方式有两种：一是符号推导/数值 QR 分解，找出一组基础参数并重新组织回归矩阵；二是"正则化 + 看协方差"，用岭回归稳住数值，用 (YTY)−1σ² 的对角元报告每个参数的不确定度，不确定度爆炸的参数就是不可辨识方向的组合。工程上更省事的近似：每个连杆只估 4–6 个"够用"的参数（质量、质心两三个方向、主轴惯量），维数低、条件数好。

4. 激励轨迹：数据的信息量上限

辨识精度由"轨迹能激活多少动力学模式"决定。慢速平移运动几乎"看不到"惯量（加速度小，惯性力矩被重力淹没）；不动、缓慢的运动看不到速度阻尼。持续激励条件要求轨迹在感兴趣频带上都有能量。工程标准做法是有限傅里叶级数轨迹：

qi(t) = qi0 + Σk=1..H [ aik/ωk·sin(ωkt) + bik/ωk·cos(ωkt) ] 基频 ω 取 0.1–0.5 Hz，谐波 H=5 左右；周期性保证 q̇、q̈ 解析可得且首尾平滑

用傅里叶级数还有一个大好处：位置、速度、加速度全部是解析式，不需要从含噪位置信号里数值微分，微分会把噪声放大几十倍（噪声幅度乘 2πf）。系数的选择目标是最大化回归矩阵的"信息"，常见做法是优化 D-最优准则（最大化 det(YTY)）或直接手工给一组覆盖常用关节范围、幅值 60–80% 限位的多频运动。

5. 验证：拟合残留 ≠ 预测能力

辨识完成后必须在另一条没有用于拟合的轨迹上做前向预测：用它预测的 τ̂ = Yβ̂ 与实测 τ 比较，计算 RMSE 与决定系数 R²。典型合格线：力矩预测 RMSE 小于额定力矩的 5–10%，或者在总力矩量级上 R² > 0.9。如果训练轨迹上残差很低、验证轨迹上残差很大，说明参数在过拟合数据（激励不足或参数太多），需要加正则或减少参数。

实现思路与设计

完整流程"设计激励 → 采集 → 预处理 → 拟合 → 验证 → 回写仿真"：

  1. 设计激励轨迹：5 谐波傅里叶级数，基频 0.2 Hz，各关节幅值取限位的 60%，关节间系数与相位独立采样（避免共线激励），总时长 20 秒；开头和结尾各加 1 秒零运动段用于偏置校正。
  2. 采集：力矩控制模式（或位置控制 + 读估计力矩），1 kHz 采样 q、q̇、τ；同时在 Isaac Sim 里用同一轨迹跑一遍得到"仿真数据"，先验证辨识管线本身正确（用仿真数据能恢复出已知参数），再去碰真机。
  3. 预处理：0.5–2 Hz 低通滤波（Butterworth，2 阶）去高频噪声；重采样到 200 Hz 降低自相关；剔除非激励段。
  4. 拟合：构造回归矩阵（重力列 + 惯量列 + 摩擦列），岭回归 λ 从 1e-6 到 1e-2 扫一遍，用验证集选 λ；输出参数的 95% 置信区间。
  5. 验证与回写：留出轨迹预测误差达标后，把质量/质心/摩擦/电机增益写回 Isaac Sim 的资产配置；辨识不确定度大的参数用"中心 ± 2σ"作为域随机化的范围，不确定度小的参数可以收窄甚至固定。
设计思维：为什么先在仿真里辨识一遍？

辨识管线本身可能有 bug（回归矩阵符号错、单位错、滤波相位没补偿）。仿真里参数真值已知，管线跑通意味着"能从数据恢复已知参数"；这个自检通过之后，真机数据上的结果才可信。把仿真当辨识算法的单元测试环境，是 Sim2Real 工程的通用套路。

关键代码与解读

片段 1：傅里叶级数激励轨迹（位置/速度/加速度解析式）

import numpy as np

class FourierExcitation:
    """5 次谐波傅里叶激励：q、q̇、q̈ 全部解析，避免数值微分放大噪声。"""
    def __init__(self, n_joints=6, harmonics=5, f0=0.2, dt=0.001, duration=20.0):
        rng = np.random.default_rng(7)               # 固定种子，轨迹可复现、可对比
        self.w0 = 2 * np.pi * f0
        self.H = harmonics
        self.a = rng.uniform(-0.3, 0.3, (n_joints, harmonics))  # 正弦项系数
        self.b = rng.uniform(-0.3, 0.3, (n_joints, harmonics))  # 余弦项系数
        self.q0 = np.zeros(n_joints)                 # 轨迹中心（可改为各关节中位）
        self.t = np.arange(0.0, duration, dt)

    def eval(self):
        q = np.zeros((len(self.t), len(self.q0)))
        qd = np.zeros_like(q)
        qdd = np.zeros_like(q)
        for k in range(1, self.H + 1):
            wk = k * self.w0
            s, c = np.sin(wk * self.t), np.cos(wk * self.t)
            # 链式求导直接给出速度/加速度，噪声零放大
            q += (self.a[:, k-1, None].T * s + self.b[:, k-1, None].T * c) / wk
            qd += (self.a[:, k-1, None].T * c - self.b[:, k-1, None].T * s)
            qdd += (-self.a[:, k-1, None].T * wk * s - self.b[:, k-1, None].T * wk * c)
        return self.q0 + q, qd, qdd

解读：周期性与解析性是这段代码的全部要点，q(t) 由正弦叠加生成，q̇、q̈ 逐项求导直接写出，避免了"从位置差分估计加速度"这个辨识里最大的噪声源（1 kHz 采样下二阶差分的噪声增益约 (2π·50)²，能把 0.01 度的编码器噪声放大成几十 rad/s²）。系数取 ±0.3、除以 ω 后幅值约 ±0.24 rad（约 14°），5 个谐波叠加后总幅值更大，练习里你会调幅值到限位 60%。基频 0.2 Hz 意味着最大谐波 1 Hz：这覆盖了机械臂动力学的主要频带（刚体模态通常在 1–10 Hz 以下），同时避开减速器与结构的柔性共振区。所有关节共用同一组频率但相位/系数不同，保证回归矩阵各列线性无关（互质频率是更强的版本，简单任务里随机系数已够用）。

片段 2：回归矩阵构造与岭回归辨识

import numpy as np

def identify_parameters(q, qd, qdd, tau, lam=1e-4, gravity=9.81):
    """单连杆演示版辨识：Y 的列 = [重力项, 惯量项, 库仑摩擦, 粘性摩擦]。"""
    q, qd, qdd, tau = map(np.asarray, (q, qd, qdd, tau))
    N = len(q)
    Y = np.zeros((N, 4))
    Y[:, 0] = -gravity * np.sin(q)     # 重力力矩对"质量×质心距离"线性
    Y[:, 1] = qdd                      # 惯量项：τ += I·q̈
    Y[:, 2] = np.sign(qd)              # 库仑摩擦：Fc·sign(q̇)，对 Fc 线性
    Y[:, 3] = qd                       # 粘性摩擦：Fv·q̇，对 Fv 线性
    # 岭回归：病态设计（激励不足）时普通最小二乘会解出巨大参数，λ 把它拉回
    A = Y.T @ Y + lam * np.eye(4)
    beta = np.linalg.solve(A, Y.T @ tau)         # 解 4×4 线性方程，避免显式求逆
    resid = tau - Y @ beta
    r2 = 1.0 - resid.var() / tau.var()           # 拟合优度（只在训练轨迹上，仅作参考）
    # 参数协方差 → 置信区间：诊断哪些参数"看不清"
    sigma2 = resid.var(ddof=4)
    cov = sigma2 * np.linalg.inv(A)
    ci95 = 1.96 * np.sqrt(np.diag(cov))
    return beta, r2, ci95


# 返回: [m·lc, I, Fc, Fv]，ci95 是每个参数的 95% 置信半宽
# 若 ci95 相对估计值很大（例如 Fc 的 ci95 大于 |Fc|），说明激励不充分或该项不可辨识

解读：这段代码是辨识心脏，四列对应四类物理量，每一列都"只含运动学、含参数为一次方"。A = Y.T Y + λI 的 np.linalg.solve 比显式求逆数值稳（条件数平方问题）；λ 从 1e-6 起试，用留出轨迹的预测误差选：λ 太大参数被压向零（欠拟合），太小病态方向爆炸（过拟合）。ddof=4 是自由度校正，先扣掉已估的 4 个参数再算残差方差，否则小样本下置信区间会偏乐观。最实用的产出其实是 ci95：它以数值方式告诉你"哪些参数组合不能被这组数据分开"，与第 3 节的秩亏理论一一对应。把 ci95 当作辨识报告的必填项，比只给点估计负责得多，域随机化的范围就该由它来定。

片段 3：交叉验证与写回仿真

import numpy as np

def validate_on_holdout(beta, q_hold, qd_hold, qdd_hold, tau_meas):
    """在未参与拟合的轨迹上做前向预测：这才是辨识质量的真话。"""
    Y = regressor(q_hold, qd_hold, qdd_hold)     # 与训练同一套回归矩阵构造函数
    tau_pred = Y @ beta
    rmse = np.sqrt(np.mean((tau_pred - tau_meas) ** 2))
    ratio = rmse / np.abs(tau_meas).max()        # 相对额定力矩的误差比
    return {"rmse": float(rmse), "ratio": float(ratio)}

def write_back_to_sim(beta, ci95, sim_asset):
    """把辨识结果写回 Isaac Sim：点估计做名义值，置信区间做随机化范围。"""
    mass_lc, inertia, fc, fv = beta
    sim_asset.set_inertial(mass_lc, inertia)         # 资产层：质量/惯量
    sim_asset.set_joint_friction(fc, fv)             # 关节层：库仑+粘性摩擦
    for name, val, half in zip(["m_lc", "I", "Fc", "Fv"], beta, ci95):
        # ci95 是 95% 置信半宽（约 ±2σ），直接作为域随机化区间：不确定度翻译成训练分布宽度
        sim_asset.set_randomization_range(name, low=val - half, high=val + half)
    return sim_asset


def regressor(q, qd, qdd, gravity=9.81):
    Y = np.zeros((len(q), 4))
    Y[:, 0], Y[:, 1] = -gravity * np.sin(q), qdd
    Y[:, 2], Y[:, 3] = np.sign(qd), qd
    return Y

解读：验证函数故意用独立的 regressor()，不复用训练代码里的 Y：同一份代码在训练与验证阶段各写一遍虽然啰嗦，能避免"把训练数据的预处理偷偷带进验证"的隐性泄漏。判读标准：ratio（RMSE 占最大力矩的比例）低于 10% 算合格；超过 20% 就不要相信这组参数，先回去查激励与滤波。write_back_to_sim 展示了辨识与域随机化的接口设计：点估计进资产、置信区间进随机化范围，两条信息都不浪费。注意 set_inertial 这类接口在不同 Isaac Sim 版本命名不同（有的在 USD 层直接写 physics:mass 属性），写回时以你所用版本的官方 API 为准；理念是"仿真资产的参数来自辨识报告，不能靠手工估计"。

常见坑

  • 从位置差分算加速度：未滤波的二阶差分把编码器噪声放大成剧烈抖动的 q̈，辨识出的惯量完全漂移。症状是不同激励轨迹得到差异巨大的惯量值。修复：用傅里叶解析导数；若必须差分，先 2 Hz 低通再差分，且报告滤波引入的相位延迟（离线处理可双向滤波消相位）。
  • 激励不足导致病态：慢速小幅度运动下回归矩阵条件数 104 以上，参数解对噪声极其敏感。症状是参数置信区间比估计值还大。修复：加大幅度与频段覆盖，或改用 D-最优设计；识别并剔除不可辨识方向（基础参数化）。
  • 摩擦符号跳变：sign(q̇) 在零速附近抖动，库仑摩擦列在低速数据上贡献噪声。症状是 Fc 估计不稳定、重复实验之间差 30%。修复：低速段加权降低或剔除 |q̇| 小于 0.01 rad/s 的样本；需要更精细时用 Stribeck 模型或在零速附近做线性过渡。
  • 闭环采集的偏置：用位置控制器采集、把指令力矩当实测力矩用，辨识到的是"控制器+机器人"的复合模型。症状是辨识参数与手册值系统性偏离。修复：力矩模式直接记录电流×扭矩常数；或采用闭环辨识方法明确承认反馈路径。
  • 只用拟合残差判断质量：训练轨迹残差低不代表泛化好，参数多、数据少时必然过拟合。症状是验证轨迹预测糟糕。修复：强制留出轨迹；先仿真后真机；报 R² 与 RMSE 两个指标。

练习与思考

  1. 在 Isaac Sim 里给单摆设置已知参数（m=0.5 kg、l=0.3 m、Fv=0.05），用傅里叶激励辨识，检查能否恢复真值，误差量级多少。★
    提示
    用解析的 q、q̇、q̈ 直接生成数据先跑一遍（无噪声），确认管线正确后再加噪声考核鲁棒性。
  2. 把激励改为"单频 0.2 Hz、幅值 5°"的慢速小运动，观察条件数与参数置信区间如何恶化，并解释原因。★★
    提示
    计算 cond(Y)，比较单频与 5 谐波的差异；慢速运动里加速度项的量级相对噪声几乎不可见。
  3. 在辨识里加入一组不可辨识的冗余参数（例如电机转子惯量与连杆惯量分开），观察协方差矩阵与置信区间，解释"为什么数据分不开它们"。★★
    提示
    看 (YTY) 的特征值谱：接近零的小特征值方向就是不可辨识组合，协方差在该方向爆炸。
  4. 设计实验：比较 λ = 1e-6、1e-4、1e-2 三档岭回归在验证轨迹上的预测误差，画出误差-λ 曲线并选参。★★
    提示
    预期 U 形：λ 太小病态解噪声大，太大参数被压向零欠拟合；最低点在 1e-4 附近是常见经验。
  5. 把辨识出的参数与置信区间联动到域随机化配置，设计一个"辨识精度 vs 迁移成功率"的对比实验，说明为什么辨识不确定度大的参数更应该随机化。★★★
    提示
    用两组配置训练：窄随机化（±10% 固定）与按 2σ 自适应宽度；在真机或高保真验证集上各测 20 次成功率。

小结

  • 刚体动力学对惯性参数线性：τ = Y(q, q̇, q̈)·β，使辨识变成最小二乘问题；摩擦也可线性化并入 Y。
  • 岭回归 + 协方差分析：λ 控病态，ci95 揭示哪些参数不可辨识；基础参数是理论上的解药。
  • 激励轨迹决定信息量：傅里叶级数给出解析的 q̇、q̈，避开数值微分的噪声放大，多谐波覆盖动力学频带。
  • 验证必须在留出轨迹上做前向预测（RMSE/R²），拟合残差不是预测能力。
  • 辨识输出双通道：点估计做仿真名义值，置信区间做域随机化范围；先在仿真自检管线再上真机。
