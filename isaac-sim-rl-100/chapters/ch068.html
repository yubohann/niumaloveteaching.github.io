第 068 章：实现仿真与真实差距分析

把"仿真和真机到底差在哪"从感觉变成报告：本章给出轨迹对齐、频域对比、回放消融三套测量方法，把差距量化并归因到手头的具体修改项。

  • 主题：Sim2Real / 测量与诊断
  • 相关组件：Isaac Sim / Isaac Lab / NumPy / SciPy
  • 预计学时：55 分钟
  • 前置章节：第 067 章

学习目标

  • 说清差距分析的目标：把差距归因到可修改的项上，不止于得到一个"差 20%"的数字。
  • 掌握时域对比三步：时间对齐、同激励对比、指标计算（RMSE、时间常数、稳态增益）。
  • 会用频域方法（多正弦/扫频 + FFT）对比幅频与相频，从中读出摩擦、共振与延迟的特征标识。
  • 会用"真机观测回放"技巧把感知差距与动力学差距分离。
  • 能写一份差距预算表：每类差距的贡献与证据、优先级排序。
  • 理解开环轨迹发散与闭环性能的辩证关系：为什么闭环能"掩盖"模型误差。

背景与动机

经过第 065–067 章，你手上有了部署管线、域随机化和辨识参数。但下一个问题更硬：当你真机效果不理想时，怎么知道是哪一项没做好？是视觉延迟？是摩擦模型？是标定？还是策略本身在真机状态分布上根本没见过？没有测量，改进就是碰运气，改一个猜一个，实验成本吞噬整个项目。

差距分析（gap analysis）就是把"感觉"变成"报告"的工程方法：用同一激励、同一策略、同一动作序列分别跑仿真与真机，对齐时间轴，从时域、频域、回放消融三个角度量化差异，最后产出一张差距预算表，每一行是一个可修改项、它的量化贡献、测量证据与修复优先级。它也是 Sim2Real 四连的收口：辨识给参数，随机化给鲁棒，而本章回答"接下来该修哪里"。

核心原理

1. 差距有三层，先决定你要测哪一层

层级定义测量方式
观测层同一物理状态下，仿真观测与真机观测的差异真机回放：把真机观测喂给仿真策略，比较动作
执行层同一动作指令下，产生的力矩/加速度差异开环动作序列对比：τ→q̈ 的响应差距
任务层同一策略的最终成功率、跟踪误差闭环对照试验（20 次以上）

三层要按顺序测：任务层差距大不告诉你原因，观测层与执行层才是可归因的。常见陷阱是拿任务层数字当结论，"成功率低 30%"无法指导任何修改。

2. 时域对比：先对齐，再比较

仿真与真机的时间轴不同源：真机的 t=0 由启动脚本决定，仿真从零开始。直接算 RMSE 会把"纯延迟"误算成"轨迹形状差异"，得出错误结论。正确的流程：

Δt* = argmaxΔt Σt qsim(t) · qreal(t − Δt)　（互相关对齐） 对齐后残差才是真实形状差异；同时记录 Δt* 本身，它往往是"仿真没建模的延迟"的直接证据

对齐后计算三类指标：跟踪误差 RMS（与指令的偏差）、响应时间（阶跃指令的 63% 上升时间）、稳态增益（长时间平均的位置/力矩比）。三个指标对应三种差距：RMS 大指向噪声与摩擦，上升时间差指向惯量与带宽，稳态增益差指向重力补偿与标定。

3. 频域对比：差距的"特征图谱"

时域指标告诉你"差多少"，频域告诉你"差在哪"。方法：给系统一条多正弦（multi-sine）或扫频（chirp）指令，同步记录指令与响应，估计频率响应函数（FRF）：

Ĝ(f) = Suy(f) / Suu(f)　（输入输出互谱 ÷ 输入自谱） 分别对仿真数据与真机数据估计 Ĝ，比较幅值与相位两条曲线

读图经验：幅值整体偏低 → 有未建模的摩擦/阻尼（能量被吃掉）；相位在高频急坠 → 存在未建模的纯延迟（相位斜率 ≈ −2πf·τ，可直接反推 τ）；某频点幅值凸起 → 共振（结构或传动柔性），这在时域里只是"抖动"，在频域里一眼可见。这是控制工程用了几十年的标准手法，套在 Sim2Real 上依然是最快的差距定位工具。

4. 回放消融：把感知与动力学分开

最有力的一招是把真机日志回放进仿真：取真机的一段轨迹，把记录的观测序列逐帧喂给仿真里的同一策略网络，同时让仿真以相同的状态继续演化。对比两组仿真回放：

  • 仿真状态 + 仿真观测 → 仿真动作（策略在仿真分布上的行为）；
  • 仿真状态 + 真机观测 → 仿真动作（策略在真机观测上的行为）。

两组的动作差异就是纯观测差距的贡献（状态相同，只有"看到的东西"不同）；而"真机观测 + 真机动力学"与"真机观测 + 仿真动力学"的响应差异是纯动力学差距的贡献。逐层叠加（先对齐接口 → 再换辨识参数 → 再加执行器/延迟模型 → 剩下的是结构缺失），差距被拆成阶梯，每一级的高度就是你下一件要修的事的收益上限。

5. 开环发散 vs 闭环掩盖

模型再准，长期开环预测也会发散：状态误差按 e(t) ≈ e(0)·eλt 增长（λ 为局部最大 Lyapunov 指数）。抓取、行走这类任务本身不稳定（λ>0），1% 的初始误差在 1–2 秒后就能放大到 10%；因此不要用"开环预测 5 秒后轨迹对不上"直接判定模型不行，要看闭环下的表现，因为反馈控制器每秒都在纠正偏差。反过来，闭环性能好也不能证明模型准：高增益控制器把扰动压下去，但代价是能量、抖振与对延迟的敏感性。差距分析的结论必须同时给出两层：开环模型误差（诊断用）与闭环任务性能（验收用）。

实现思路与设计

一次完整差距分析的执行清单：

  1. 选三条测试激励：慢速正弦（0.2 Hz、限位 30%）测准静态与摩擦；扫频 chirp（0.1–10 Hz）测频响与延迟；任务型轨迹（抓取/行走片段）测综合表现。三条各自独立分析，避免一条轨迹的偶然性。
  2. 同步采集：仿真与真机都以 1 kHz 记录 q、q̇、τ、观测向量与墙钟时间戳；真机日志用同一格式（列顺序、单位）导出，方便复用分析脚本。
  3. 预处理：统一重采样到 200 Hz；0.5 Hz 高通去偏置、50 Hz 低通去噪（避免混叠误判）；互相关对齐并记录 Δt*。
  4. 三层指标计算：时域 RMSE/上升时间/稳态比；频域 FRF 幅相；回放消融的动作差异。
  5. 归因与预算表：按"辨识参数、执行器模型、延迟、观测噪声、结构缺失"归因，每项给出量化贡献（如"质量修正贡献 12% 的稳态误差"）与优先级。修复最高项后复测，验证预算表是否闭环（修了它，差距应降相应幅度）。
设计思维：为什么强调"修复后复测"？

差距归因本质是一次"测量-假设-干预"的科学循环。没有复测，你的归因只是又一个猜测。复测还顺带检验测量方法本身：如果修了最高项差距纹丝不动，要么预算表排错了，要么测量被时间对齐之类的系统误差污染。差距分析报告的价值在于闭环验证，表格只是载体。

关键代码与解读

片段 1：时间对齐与时域指标

import numpy as np
from scipy.signal import resample, correlate

def align_and_metrics(q_sim, q_real, fs_sim=1000, fs_real=1000, fs_out=200):
    """先重采样再互相关对齐，最后算时域三指标。返回对齐后的两段与 Δt。"""
    if fs_sim != fs_out:                                   # 统一采样率，否则互相关无意义
        q_sim = resample(q_sim, int(len(q_sim) * fs_out / fs_sim))
    if fs_real != fs_out:
        q_real = resample(q_real, int(len(q_real) * fs_out / fs_real))
    # 去均值再互相关：否则直流分量把峰值固定在零延迟处，掩盖真实时移
    a, b = q_sim - q_sim.mean(), q_real - q_real.mean()
    lag = int(np.argmax(np.abs(correlate(b, a, mode="full")))) - (len(a) - 1)
    dt_star = lag / fs_out                                  # 正值表示真机滞后于仿真
    if lag >= 0:                                           # 按 lag 截齐重叠段
        xs, xr = a[lag:], b[:len(b) - lag]
    else:
        xs, xr = a[:len(a) + lag], b[-lag:]
    n = min(len(xs), len(xr))
    xs, xr = xs[:n], xr[:n]
    rmse = float(np.sqrt(np.mean((xs - xr) ** 2)))
    return {"dt": dt_star, "rmse": rmse, "n": n, "sim": xs, "real": xr}

解读：三个动作按顺序都很关键。先重采样：互相关比较的是"形状对齐程度"，采样率不同时每样本对应的物理时间不同，延迟估计直接错。用 resample（频域）替代线性插值，避免插值低通让高频差异失真。去均值：机器人的绝对位置常有常数偏置（例如标定零点差），不去均值时互相关峰值恒在 0 延迟。记录 dt_star 本身：它常常就是最有价值的输出，例如算出真机滞后 22 ms，而你的延迟预算里只建模了 16 ms，差值 6 ms 就是下一步要补的建模或补偿项。RMSE 要拿对齐后的段计算，用"原始未对齐数据"直接算会把延迟误计成形状误差（可能虚增 3–5 倍）。

片段 2：频响对比，从相位斜率反推等效延迟

import numpy as np

def frf_estimate(u, y, fs=1000, nperseg=2048):
    """估计输入 u → 输出 y 的频率响应：互谱 ÷ 自谱，Welch 平均降方差。"""
    f, Suu = welch_psd(u, fs, nperseg)          # 输入自谱
    _, Suy = welch_csd(u, y, fs, nperseg)       # 输入输出互谱
    G = Suy / np.maximum(Suu, 1e-12)            # 逐频点相除，1e-12 防零除
    return f, G                                  # G 是复数：幅值=|G|，相位=angle(G)

def equivalent_delay(f, phase_sim, phase_real, band=(2.0, 10.0)):
    """在高频带用相位斜率差反推未建模延迟：τ ≈ −d(Δφ)/dω。"""
    mask = (f >= band[0]) & (f <= band[1])
    dphi = np.unwrap(phase_real - phase_sim)[mask]   # 解缠绕先于斜率，否则跳跃点毁掉拟合
    omega = 2 * np.pi * f[mask]
    slope = np.polyfit(omega, dphi, 1)[0]            # 线性拟合相位差 vs 角频率
    return -slope                                    # 单位：秒

解读：频响估计的本质是"在每个频点上，看输出里有多少成分与输入同频、相位差多少"。用 Welch 分段平均替代一次 FFT，是为了压低单次估计的方差（噪声随分段的 1/√K 下降）。equivalent_delay 是这段代码的精华：纯延迟的相位是 −ωτ 的线性函数，两条曲线在高频带的相位差斜率就是延迟差，哪怕时域里看不出"22 ms"这个数，频域相位一眼定位。选 2–10 Hz 频带是因为低频相位常被摩擦/重力补偿误差污染，高频又被噪声淹没；np.unwrap 必须先于拟合，否则 ±π 的跳变会让斜率毫无意义。welch_psd/welch_csd 指 scipy.signal 里对应实现，工程脚本中建议封装成团队共用的分析库。

片段 3：回放消融，分离观测差距与动力学差距

import numpy as np

def replay_ablation(sim_env, policy, real_log, n_steps=3000):
    """real_log：真机记录的观测序列 obs_real[t] 与动作 a_real[t]。
    两组回放对比，拆出观测差距与动力学差距的动作贡献。"""
    act_sim_state = []      # 仿真状态 + 仿真观测 → 动作
    act_real_obs = []       # 仿真状态 + 真机观测 → 动作
    obs = sim_env.reset()   # 从与真机相同的初始状态开始
    for t in range(n_steps):
        a_pure = policy.act(obs)                       # 基准：完全仿真链路
        a_mixed = policy.act(real_log.obs[t])          # 只把观测换成真机的
        act_sim_state.append(a_pure)
        act_real_obs.append(a_mixed)
        obs, _, _, _ = sim_env.step(a_pure)            # 用基准动作推进，保持两条链可比
    d_obs = np.abs(np.array(act_sim_state) - np.array(act_real_obs)).mean()
    # 观测差距贡献：同一状态、不同观测下的平均动作偏差（单位与动作同）
    # 动力学差距贡献：把仿真步进换成"真机下一状态"继续回放，同样统计动作偏差
    return {"obs_gap_action": float(d_obs)}

解读：这段代码体现的是差距分析的受控变量法，两次回放只有"观测来源"一个变量不同：a_pure 用仿真观测、a_mixed 用真机观测，两者之差就是观测差距的纯贡献（不用管策略有多好）。动力学差距同法：把 sim_env.step 换成"从真机日志取下一状态"，观察在相同观测下动作如何被真实轨迹带偏。两个贡献值都不要看绝对值，看相对占比：观测贡献 0.15、动力学贡献 0.45（动作量纲归一化后）说明先修动力学（辨识/执行器模型）收益更大。回放要用确定性策略、关闭探索噪声；n_steps=3000 对应 50 秒数据，足够覆盖几条轨迹的统计。若真机日志没有同步的初始状态，用"真机状态叠加到仿真"的方式从轨迹中段切入。

常见坑

  • 未对齐就报指标：直接算仿真与真机的轨迹 RMSE，把几毫秒的时钟差放大成"30% 形状误差"。症状是所有指标都大、无从下手。修复：先互相关对齐并报告 Δt*；若 Δt* 随测试变化，说明有速率抖动，先修采集链路。
  • 采样率与滤波不一致：仿真 200 Hz、真机 1 kHz，滤波截止不同，对比的其实是两套系统。症状是高频段误差巨大但低频一致。修复：重采样到统一频率、统一滤波器参数，分析脚本两端共用。
  • 只比较闭环性能：高增益控制器压住了模型误差，闭环曲线看起来"差不多"，但能量与抖振已明显恶化。症状是发热、噪声大、寿命短。修复：开环对比（拟合度、频响）与闭环性能并列报告，两层结论缺一不可。
  • 用开环发散长度判定模型好坏：不稳定任务的轨迹本来就会指数发散，在天真的指标下"模型永远不行"。症状是每次分析都判"动力学差距大"。修复：报告发散率（Lyapunov 指数）并与理论值比较，发散绝对量不作判据。
  • 归因不做干预验证：写了预算表就收工，修的项对不对没有复测。症状是差距常年不变、团队对分析失去信任。修复：每修一项复测一次，量化差距下降幅度，预算表与修复闭环。

练习与思考

  1. 对一段慢速正弦轨迹做互相关对齐，比较对齐前后的 RMSE。若对齐后 RMSE 下降 70%，你的结论是什么？★
    提示
    说明原指标主要由纯延迟贡献；下一步是查延迟来源（采集、通信、控制器），不要先去调"动力学参数"。
  2. 给同一条 chirp 指令、真机与仿真各做一次频响估计，画出幅值与相位对比图，指出摩擦与延迟的特征标识。★★
    提示
    幅值整体低 10–20% 通常是未建模摩擦；相位在高频额外下垂即延迟差 = −斜率。
  3. 用回放消融估计你手上系统的"观测差距/动力学差距"占比，并设计一次修复实验验证你的排序是否正确。★★★
    提示
    先修占比大的那项（例如重训执行器模型），复测两个占比应同时变化，动力学修好了，观测差距的相对占比会上升。
  4. 把低速段（|q̇| 小于 0.05 rad/s）从频响分析中剔除，观察低频相位图变化，解释库仑摩擦的符号非线性对测量的干扰。★★
    提示
    符号函数在小速度下等效于高增益非线性，会在低频产生"伪阻尼/伪刚度"，污染 FRF。
  5. 写一份差距预算表模板（列：差距项、测量方法、量化贡献、修复动作、复测结果），把本章三个实验的结论填进去。★★
    提示
    表格按贡献排序；"复测结果"列留空，直到干预实验完成后填写，这张表是活的文档。

小结

  • 差距分析的目标是归因：把任务层落差分解到观测层、执行层等可修改项上，并给出优先级。
  • 时域三步：重采样统一、互相关对齐、三指标（RMSE/上升时间/稳态比）；Δt* 本身常是最重要的输出。
  • 频域看特征：幅值差→摩擦阻尼，相位斜率→未建模延迟，凸起→共振；Welch 平均降方差，unwrap 后再拟合。
  • 回放消融分离变量：同一状态下换观测来源测观测差距，换动力学来源测动力学差距，用相对占比排序修复项。
  • 开环诊断、闭环验收；报告发散率（发散量不作判据）；每次修复后复测，让预算表闭环。
