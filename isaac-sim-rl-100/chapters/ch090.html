第 090 章：实现灵巧手操作

从"抓住"到"玩转"：多指手在掌内旋转、重定向物体，动作维度高、接触模式多变。本章讲清多指协调、摩擦锥与力闭合，并给出让 RL 学得动的工程配方。

  • 主题：控制与优化 / 多指操作与接触丰富任务
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：60 分钟
  • 前置章节：第 089 章

学习目标

  • 理解灵巧手与两指夹爪的本质差异：多指协调、掌内操作与接触模式切换。
  • 掌握摩擦锥与力闭合的概念，会用简化判据评价"抓得稳不稳"。
  • 会说清灵巧手任务的三大训练难点：高维动作、稀疏成功、接触仿真敏感，并掌握对症手段。
  • 会搭建"先握稳、再旋转"的课程、设计含上一动作的观测与平滑奖励。
  • 能诊断物体被弹飞、手指抽搐、训练停滞等常见问题。

背景与动机

上一章的抓取是"一次性事件"：在正确时刻闭合，任务完成。灵巧手操作（dexterous manipulation）是持续过程：物体留在手里，手指不断调整接触点，让它旋转、翻面、沿轴滑动，这正是人手最日常的能力。硬件上，五指手已有成熟产品（20+ 个自由度）；软件上，它至今是机器人学习最难的基准之一。

难在哪？三个叠加：动作维度高（15–24 维连续控制）、接触模式离散跳变（指-物接触的出现/消失/滚动/滑动）、物理敏感（摩擦系数差 10%，策略就完全不工作）。这三点让经典建模几乎走不通，而 RL 的大规模并行训练正好对症。本章沿用第 089 章的高动态线索，转向"高精度持续接触"的另一极。

核心原理

1. 摩擦锥：抓稳的第一原理

单点接触处，手指能给物体的力必须落在一锥体内：法向压力 fn ≥ 0，切向力 ft 满足

‖ft‖ ≤ μ · fn μ 为静摩擦系数：橡胶-橡胶约 1.0，钢-钢约 0.15；锥张角 2·arctan(μ)

翻译成工程语言：想让物体抗住切向的外力（含重力分量），就得压得更紧。μ=0.3 时，要抗住 3 N 的切向力至少需要 10 N 法向压力。但压得越紧，指关节力矩越大、越容易扰动物体，"抓稳"与"扰动小"之间的平衡贯穿本章。

2. 力闭合：多指为什么能"锁住"物体

单点接触只能产生锥内一个方向的力；多点接触时，把各指的接触力合起来看：抓取矩阵 G（把手指接触力映射到物体受到的净力旋量）满足

G · fcontact = −wext，  fcontact ∈ 各指摩擦锥 给定任意外力旋量 w_ext（受物体重量与惯性限制），总能找到一组锥内的指力抵消它 → 力闭合

力闭合（force closure）是"抓稳"的严格定义：不管外力往哪个方向推，都存在一组合法指力扛住它。它有两个工程推论：（1）接触点要"包围"物体（三点非共线是常态下限，实际建议 3 点以上且法向尽量对置）；（2）抓取矩阵 G 的秩与奇异值决定抗扰方向，对 6 维外力，至少需要 3 个硬指接触才能有一般性的力闭合。（本课用简化判据：三点接触时检查 G 的最小奇异值 > 阈值。）

3. 掌内操作：物体也是"被控对象"

掌内旋转的动力学直觉：手指"搓"物体，靠的是接触点的切向力（摩擦锥内部）与重力、惯性的配合。物体绕掌心的角加速度由各接触力的力矩决定：

I · α = Σi (ri × fi) + τgravity r_i 是接触点相对物体质心的位置，手指"够得越远"越容易搓动

这解释了两个现象：（1）物体越大越难旋转（ri 大但 I 增长更快，赶不上）；（2）手指必须周期性"松开、重触"（re-grasping），因为接触点一旦滑到不合适的区域，力矩臂就失效了。学习型策略要自发学会这种"换手"节奏，这是灵巧手任务最令人着迷也最难的部分。

4. 接触模式切换与可微性

接触状态是离散的：接触/分离、滚动/滑动。接触状态一跳变，动力学方程整体切换（混合动力学），梯度是"分段"的。这也是为什么端到端模仿/解析优化困难，而 RL 的随机采样恰恰擅长处理这类依赖大量"接触时序"的任务。数字感：一个 20-DoF 手 + 3 个接触点的任务，单个回合的接触模式序列可能有数十种；训练需要的样本量常达到 10⁸–10¹⁰ 环境步（这正是需要 GPU 并行物理的原因）。

实现思路与设计

  1. 任务降维起步：从"三指手、每指 2 关节、掌心朝上旋转方块"开始，总动作 6–9 维。先能把方块绕竖直轴转 ±45° 不停下，再升级五指 20 自由度。
  2. 观测设计：物体相对掌心位姿（四元数→旋转误差向量，见第 086 章）+ 物体线/角速度 + 手指关节位置/速度 + 上一动作 + 接触标志位（或每个指尖的接触力，仿真里可直接取）。
  3. 动作设计：手指 PD 位置目标（关节刚度 5–20 N·m/rad）比直接力矩更稳，尤其在接触力学敏感时；动作率惩罚与输出滤波防止指关节抽搐（第 083 章）。
  4. 奖励结构：主项 = − 角度误差（旋转任务）+ 稳定性辅助项（−指尖接触力超过 30 N 的越界惩罚）− 动作率惩罚 − 时间税；成功（误差 <10°）给 +1 并冻结目标角若干毫秒确认"稳住"。
  5. 课程：阶段 1 只要求"不掉"（目标角 = 初始角的 ±2°）；阶段 2 目标角随指抓稳定后加入 ±20°；阶段 3 逐步放大到 ±90°，并随机化初角。
  6. 域随机化：摩擦系数 μ ∈ [0.5, 1.2]、质量 ±20%、尺寸 ±5%、指关节阻尼 ±30%，灵巧手对摩擦最敏感，这项要比第 089 章更激进。
  7. 评估：角度误差的分布、掉落率（每百回合）、重抓次数、接触力峰值 P95、以及"无扰成功率 vs 随机化成功率"的落差（泛化指标）。
设计思维：为什么灵巧手的观测必须包含"上一动作"？

接触动力学对速度敏感，而速度信息在离散观测里最直接的代理就是"上一动作"。没有它，策略每步都在"重新决策"，行为会退化为无节奏的高频抖动（手指飞快开合），这在接触任务里几乎必然导致物品滑落。第 083 章讲了平滑机制；本章把它上升为观测完整性问题：对接触丰富任务，观测里不放动作历史，等于坐在没有后视镜的车上倒车。

关键代码与解读

片段 1：三指灵巧手环境，观测与稳定奖励

import torch

class TriFingerRotateEnv:
    """三指手掌内旋转：观测含物体位姿/速度、手指关节、上一步动作与接触力。"""
    def __init__(self, num_envs, n_fingers=3, n_joints_per=3, f_contact_max=30.0):
        self.n_joints_per = n_joints_per
        self.f_max = f_contact_max          # 指尖接触力的安全上限 30 N
        self.prev_action = torch.zeros(num_envs, n_fingers * n_joints_per)

    def compute_obs(self, obj_quat, obj_angvel, fingertips, joint_pos, joint_vel,
                    contact_forces, target_yaw_err):
        # 物体姿态用旋转误差向量（3 维），不用四元数原值，见第 086 章
        rot_err = rotation_error_vector(obj_quat, self.target_quat)   # (B,3)
        contact = contact_forces.flatten(1)          # 每指尖的接触力范数 (B,3)
        return torch.cat([
            rot_err,                                 # 姿态误差（对任务的充分统计）
            obj_angvel,                              # 物体角速度（判断旋转趋势）
            joint_pos, joint_vel,                    # 手本体状态
            contact,                                 # 接触力：盲抓 vs 有感知的分水岭
            self.prev_action,                        # 动作历史：给接触动力学"速度感"
        ], dim=-1)

    def reward(self, rot_err_norm, contact_forces, action_prev, action, time_scale=0.01):
        r_task = -rot_err_norm                      # 主任务：角度误差越小越好
        # 稳定项：接触力超过 f_max 的部分平方罚，保护手也保护物体
        over = torch.clamp(contact_forces.norm(dim=-1) - self.f_max, min=0.0)
        r_safe = -0.02 * over ** 2
        # 动作率惩罚：手指运动要顺，不能高频开合（灵巧手版第 083 章）
        r_smooth = -0.05 * torch.sum((action - action_prev) ** 2, dim=-1)
        return r_task + r_safe + r_smooth - time_scale

解读：（1）观测中的 rot_err 用了第 086 章的旋转误差向量，多指操作里姿态控制是核心，欧拉角/四元数原值都会引入跳变；（2）contact 是仿真里的"作弊"真值（真实系统需要指尖触觉传感器或力矩估计），但即使仿真里也建议加 ±5% 噪声，避免策略依赖完美触觉；（3）prev_action 既进观测又参与奖励：观测给"速度感"，奖励压制高频开合，两者配合是灵巧手任务收敛的必要条件之一；（4）系数 0.02 与 0.05 的量纲换算：接触力冲到 35 N（越界 5 N）时 r_safe = −0.02×5² = −0.5，相对主项 −0.1 量级是"硬警告"；单个关节单步变化 0.3 rad 时 r_smooth = −0.05×0.3² = −0.0045（提醒级），安全项要重、平滑项要轻，否则任务学不完。

片段 2：力闭合的简化检查与接触模式统计

import torch

def grasp_quality(contact_points, contact_normals, mu=0.8, wrench_dim=6):
    """简化力闭合指标：由接触点/法向构造抓取矩阵 G，返回最小奇异值。
    force closure ⇔ 正则化后的 G 的最小奇异值 > 0（越大越稳）。"""
    B, k, _ = contact_points.shape            # k 个接触点（这里 k=3）
    cols = []
    for i in range(k):
        r = contact_points[:, i, :]           # 接触点相对质心的位置 (B,3)
        n = contact_normals[:, i, :]          # 接触法向（单位向量）
        # 每个接触点贡献"力"与"力矩"两行块：力沿 n，力矩 r × n
        torque = torch.cross(r, n, dim=-1)    # (B,3)
        cols.append(torch.cat([n, torque], dim=-1))      # (B,6)
    G = torch.stack(cols, dim=-1)             # (B, 6, k)：6 维旋量 = G @ 指力
    # 最小奇异值：为 0 ⇒ 某方向外力无法被抵消 ⇒ 非力闭合
    s = torch.linalg.svdvals(G)
    return s[:, -1]                           # 教具用法：监控 > 0.05 视为"抓稳"

# 用法：训练中每步记录 grasp_quality；掉落前该值通常先跌到 0.02 以下
# 把它作为辅助观测/奖励信号，可显著加快"先抓稳"阶段的课程进度

解读：这是把力闭合从"定理"变成"可监控数字"的最小版本。构造上只考虑 3 个接触点的纯法向力（教学简化；完整版要枚举摩擦锥的基向量），G 是一个 6×3 矩阵，询问"3 个指力能否覆盖 6 维外力空间"，答案显然是"不能全覆盖"，但最小奇异值仍能反映"最薄弱方向多弱"。它的工程价值：作为课程触发器，当 grasp_quality 连续多步 >0.05，再进入下一阶段（加旋转目标），成功率能翻倍；同时它也是"掉落预警"，可以在物体真的滑脱前几帧就被观测到，让策略有机会补救。

片段 3：课程与域随机化配置

class DexterousCurriculum:
    """三阶段课程 + 域随机化：先握稳、再小角度、后大角度。"""

    def __init__(self):
        self.stage = 0
        self.cfg = {
            # 阶段 0：目标角扰动 ±2°（≈只要求不掉）
            0: {"yaw_range": 0.035, "mu": (0.7, 1.0), "mass_std": 0.10},
            # 阶段 1：±20°，摩擦范围放宽（开始考验"抓得多稳"）
            1: {"yaw_range": 0.35, "mu": (0.6, 1.1), "mass_std": 0.15},
            # 阶段 2：±90°，全随机化 + 随机初角（最接近真实部署）
            2: {"yaw_range": 1.57, "mu": (0.5, 1.2), "mass_std": 0.20},
        }
        self.success_hist = []

    def update(self, success_rate):
        self.success_hist.append(success_rate)
        # 滑动窗口平均成功率 > 0.7 才升级，防止"偶尔侥幸"被当成掌握
        if len(self.success_hist) >= 20:
            avg = sum(self.success_hist[-20:]) / 20
            if avg > 0.7 and self.stage < 2:
                self.stage += 1
                self.success_hist.clear()

    def sample_domain(self, num_envs):
        import torch
        c = self.cfg[self.stage]
        yaw = (torch.rand(num_envs) * 2 - 1) * c["yaw_range"]
        mu = c["mu"][0] + torch.rand(num_envs) * (c["mu"][1] - c["mu"][0])
        mass = 1.0 + torch.randn(num_envs) * c["mass_std"]   # 相对标称质量的抖动
        return yaw, mu, mass

解读：课程的两个细节决定成败。（1）阶段 0 的 yaw_range 只有 0.035 rad（2°），它本质上是"保持抓取"任务，让随机初始化的策略先学会"手指不乱动、物体不掉"，这是把稀疏的成功变成密集的成功的关键跳板；（2）升级判据用滑动窗口平均成功率 >0.7，不用瞬时值，且窗口 20 次评估：灵巧手任务的偶然成功很常见（接触抖两下恰好达标），窗口平均能过滤掉。域随机化在设计上是"跟阶段同步放宽"的：阶段 0 的 μ 范围窄，是为了让"握稳"容易学；阶段 2 才收紧到真实范围。注意 sample_domain 返回的 mass 是相对系数，环境侧乘到物体质量参数上，这正是第 021 章域随机化思想在接触任务里的用法。

常见坑

  • 动作维度一开始就取满：20+ 维动作 + 随机初始化策略，探索在指数空间里迷路。修复：先做低维加法结构（手指耦合映射到 3–6 维潜在动作），或按课程逐步放开"自由度预算"。
  • 观测缺接触信息：没有接触力/接触标志的"盲抓"策略只能在失败后学习，样本量翻几倍。修复：仿真取接触力真值（加噪声），真机用指尖触觉或关节力矩估计。
  • 接触参数设置不当：接触刚度太大（物体被弹飞）或阻尼太小（抖动不收敛）。修复：参考物理量级，指垫刚度 10³–10⁴ N/m、阻尼 10–100 N·s/m，先用单指推盒子调稳再上全手。
  • 奖励里"旋转"与"防掉"打架：旋转项权重过大，策略用暴力搓转把物体甩出去；过小则从不旋转。修复：课程分离两阶段；掉落惩罚设为旋转成功的 2–3 倍，并监控掉落率随权重变化的曲线。
  • 并行环境数不足：灵巧手任务的样本效率低是物理特性，单环境训练接近不可行。修复：起步 512–4096 个并行环境；这也让"动作历史观测"的实现要自洽（每个环境独立维护 prev_action）。

练习与思考

  1. 用手指压力 10 N、摩擦系数 μ=0.3 计算：单点接触能抗住的最大切向力是多少？μ 升到 0.8 呢？★
    提示
    直接用摩擦锥不等式 f_t ≤ μ·f_n：3 N 与 8 N。结论是摩擦系数对"抓得住多重"的影响是线性的，这就是域随机化难点。
  2. 用片段 2 的 grasp_quality 生成三种接触配置（正三角、共线、两点对置），对比最小奇异值。★★
    提示
    共线配置的 G 必定降秩（奇异值≈0），这实验能让你直观理解"三点非共线是力闭合的底线"。
  3. 把观测里的 prev_action 去掉再训练，观察掉落率与手指动作的频谱变化。★★
    提示
    预期手指动作高频分量增大、掉落率上升；用第 083 章的 FFT 工具量化"抽搐"。
  4. 把域随机化的 μ 范围从 [0.5, 1.2] 收窄到 [0.75, 0.85]，对比训练成功率与"评估时换 μ=0.5"的落差。★★★
    提示
    这是经典的泛化-性能折中实验：窄范围训练更快但抗扰差；用（训练成功率，跨 μ 评估成功率）两张表对比。
  5. 设计一个"重抓（re-grasping）"评估实验：统计一次旋转任务中手指松开并重新接触的次数，以及它和目标角度的关系。★★★
    提示
    检测方法：接触力低于阈值超过 50 ms 记为一次松开。大角度旋转（>60°）时预期出现重抓，这正是"策略是否学会换手节奏"的证据。

小结

  • 灵巧手的三重难点：动作维度（15–24 维）、接触模式离散切换、物理参数（尤其摩擦）敏感；它比第 089 章的抓取更侧重"持续接触的精细控制"。
  • 摩擦锥 ‖ft‖ ≤ μ·fn 是第一原理；力闭合（G 的最小奇异值 >0）是"抓稳"的判据，也可当课程触发器与掉落预警。
  • 观测必备三件套：物体姿态误差向量、接触力、上一动作；动作率惩罚配合 PD 底层驱动抑制手指抽搐。
  • 课程"先握稳（±2°）、再小角度、后大角度"，域随机化随课程放宽；升级判据用滑动窗口成功率，样本量需要 10⁸ 步量级与数千并行环境。
  • 第四篇到此收束：从时间最优到灵巧手，你已掌握"怎样让单个机器人做得又快又稳又安全"。下一章开始第五篇，进入系统集成，首先把两条手臂合成一个"团队"，见第 091 章。
