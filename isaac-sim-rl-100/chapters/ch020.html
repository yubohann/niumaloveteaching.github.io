第 020 章：实现稀疏奖励与奖励塑形

当成功信号稀少到几乎摸不着：理解稀疏奖励为什么难、势函数塑形（PBRS）为什么"改了奖励却不改最优策略"，并掌握引导退火与"真目标评估"的完整用法。

  • 主题：强化学习 / 稀疏奖励与奖励塑形
  • 相关组件：Isaac Sim 环境、SB3 训练循环
  • 预计学时：60 分钟
  • 前置章节：第 019 章

学习目标

  • 理解稀疏奖励任务的核心困难：成功事件的概率极低与信用分配的"长尾"。
  • 掌握势函数奖励塑形定理：F = γΦ(s′)−Φ(s) 保证所有策略的回报只差一个常数，最优策略不变。
  • 会为到达类任务设计势函数（如 Φ = −d），并解释它为什么在数学上"安全"。
  • 会使用引导退火（annealing）在"早期易学"与"最终忠于真目标"之间取舍。
  • 会设计对照实验：真目标（稀疏成功率）评估所有变体，识别塑形带来的代理目标偏差。

背景与动机

019 章的奖励是"稠密"的：每步的 −d 都在给反馈。但很多真实任务的成功是二值的：插头插进插座、杯子放到架子上、螺丝拧到位，过程没有有意义的中间刻度，只有"成了/没成"。这就是稀疏奖励（sparse reward）：整条轨迹里几乎全是 0，一个回合也许只有最后一个状态给出 +1。

稀疏奖励下随机探索几乎撞不上成功事件；撞上了也难归因。本章给出标准工具箱：势函数塑形、引导退火与诚实评估纪律（036/037/041 章都会复用）。

核心原理

1. 稀疏奖励难在哪里：概率与信用

用 016 章的到达任务算一笔账。工作区半径 0.4 m、成功体积半径 0.05 m，随机策略下"终点恰好落在成功球内"的概率约为 (0.05/0.4)³ ≈ 0.002；再乘以"动作随机时机械臂确实走到终点"的条件概率（远小于 1），每回合成功的概率可以低到 10⁻⁵ 以下，等于平均十万个回合才有一次正样本。更糟的是信用分配：+1 落在 200 步轨迹上，谁知道哪个动作是功臣？突破口是给智能体额外的、可撤掉的引导信号，难在引导不能改变任务本质，否则训出的只是"擅长刷引导分"的代理。

2. 势函数塑形定理：安全引导的数学保证

设原奖励为 r，塑形后的奖励 r′ = r + F(s, s′)。一般形式的 F 会改变最优策略（第六章的剧本二"振荡刷分"就是例子）。Ng 等人 1999 年的定理给出了一类安全的塑形：只要存在一个状态函数 Φ（势函数），使得

F(s, s′) = γ·Φ(s′) − Φ(s) γ 是训练用的折扣因子；Φ 可以是任意函数（离目标的负距离、高度、势能……）

那么对任何策略 π，塑形后的期望回报与原回报只相差一个与 π 无关的常数：

Eπ[ Σ γt·Ft ] = −Φ(s0) + γT+1·Φ(sT+1) ≈ −Φ(s0) 级数望远镜相消：中间所有项的 Φ 相互抵消，只剩首尾两项

推导直觉就是"望远镜相消"：Σ[γΦ(s′)−Φ(s)] 里每一步的 γΦ(s′) 与下一步的 Φ(s) 抵消。所有策略的回报都平移同一常数，最优策略不变。于是 Φ = −d 给出的 F ≈ "靠近目标的进度分"，与 019 章警告的朴素进度奖励有本质区别：前者有定理背书。

三个工程细节：终点势值设 Φ(终止) = 0（防死亡套利）；γ 与训练折扣一致（否则残留漂移项）；Φ 是注入先验的位置，这就是塑形的艺术。

3. 引导退火：从"扶着走"到"放开走"

即使 PBRS 保证最优策略不变，它改变的是学习动力学：引导项提供了最初的学习坡度。实践中的常见做法是再进一步，把塑形权重 w(t) 随训练从 1 退火到 0：

r′t = rsparse + w(t)·Ft，  w(t): 1 → 0（如 30 万步内线性衰减） 早期解码"往哪走"，后期只优化真目标；避免策略过度适配引导项的残差

退火是工程保险：Φ 常含近似（如用 TCP 近似工具位姿），归零保证收敛后完全由真奖励塑造。代价是回报曲线出现一次"台阶"，那是预期现象。

4. 评估纪律：训练可以作弊，评估必须诚实

用塑形训练、用稀疏指标评估，是本主题不可动摇的纪律。原因：塑形项是你发明的"代理分数"，它随着 Φ 与权重变化；只有真目标（成功率、最小距离、完成时间）才是任务的事实。对照实验的模板：

变体训练奖励预期曲线风险
纯稀疏成功 +1长期 0，随后陡升（若预算足够）可能永远不触发；预算浪费
PBRS 塑形稀疏 + w·F平稳爬升，成功率单调改善Φ 设计不当导致引导指向错误
PBRS + 退火w(t) 衰减到 0台阶后继续改善退火过早：引导撤走太快
朴素进度奖励稀疏 + 进度分可能爬升更快无保证：可能钻空子（019 章剧本二）

评估要报"成功率 ± 标准差、最差种子、完成时间"，稀疏任务方差大，均值讲不清；022 章并行化后低成本跑到 3 个种子。

5. 稀疏探索的量化：多少回合才能遇见一次成功

仍用第 1 节的估计 p = 10⁻⁵ 每回合。期望"遇见第一次成功"需要的回合数与环境步数：

期望回合数 = 1/p = 10⁵；按 200 RL 步/回合折合约 2 × 10⁷ 环境步 单环境按 2400 RL 步/秒计约 2.3 小时；4096 个并行环境按合计 10⁶ 步/秒计约 20 秒

这组数字说明稀疏任务的出路：探索概率低本身拦不住大规模并行采集，真正难的是"遇见之后如何利用"。这也是 022 章并行环境的价值所在：把"幸运事件"的出现频率从按小时计压缩到按秒计。任何声称"稀疏任务学不动"的结论，都要先算这条乘法，确认不是采集规模不够导致的正样本荒。乘法两端都可调：p 靠课程学习或初始状态课程（032 章）提高，采集靠并行规模扩大；两者都不动用时，纯稀疏就是和概率硬碰硬。课程学习与引导可以并用：先用简单任务把状态分布铺开，再切换完整任务（032 章）。

6. PBRS 的数值示例与量级上限

把 Φ = −d/0.8、γ = 0.98 代入一次典型转移：d 从 0.50 m 降到 0.45 m。

F = γ·Φ(s′) − Φ(s) = 0.98 × (−0.5625) − (−0.6250) = 0.074 Φ(s) = −0.50/0.8 = −0.625，Φ(s′) = −0.45/0.8 = −0.5625

一次 5 cm 的接近得到 +0.074 的塑形回报，约合稀疏 +1 的 7%。更重要的是总量上界：整条回合的塑形累计由望远镜相消决定，ΣF = γT+1·Φ(终止) − Φ(s₀)，终点势值归零时上限就是 −Φ(s₀) = 0.625。塑形总分被 Φ 的尺度锁死，绕路、振荡都无法突破这个上界，这正是它区别于朴素进度分的安全之处。把 Φ 的尺度乘 2，塑形总量最多也乘 2，预算是可控的。

7. 势函数形态的对照

Φ 设计形态行为倾向风险
Φ = −d / s（负距离）近处与远处梯度均匀全距离段都有稳定引导接近终点时引导不衰减，需要成功奖励收口
Φ = −(d / s)²远处梯度大、近处梯度小先快速拉近，接近后依赖真目标细化早期动作幅度大，接触冲击风险高
Φ 取 0/1 指示（d 小于 r）台阶状只在跨过阈值时给信号平坦区域无梯度，接近新的稀疏问题

三种形态对应三种引导风格：均匀引导覆盖从远到近的全过程，二次引导强调快速接近，指示函数几乎不提供稠密信息。选择依据是任务失败的主要阶段：总是远远地迷路，用均匀版；总是接近后不敢深入，检查成功奖励的量级与二次形态的搭配。若要把引导的影响放大，正确做法是加乘退火权重 w：尺度放大写在 w 里，势函数的形态与安全性质讨论仍按上面的对照表进行。Φ 的形态、尺度与 w 的时间表都属于实验配置，与随机化范围一样要随结果存档；存档粒度到"每一次对照实验一行"，片段 3 的对照骨架正好批量产出这类记录。若训练后发现撤掉引导性能掉档，回看三个数：退火窗口、w 曲线、成功率台阶幅度，基本能区分"撤得太快"与"势函数有偏"。

8. 数值验证：望远镜相消的逐项核算

定理说塑形总分只取决于首末势值，下面用两条轨迹实测。配置：Φ = −d/0.8、γ = 0.98、起点 d0=0.5，终止时 Φ=0。轨迹一"直线"用 10 步到达，每步缩短 5 cm；轨迹二"之字"用 9 步，途中三次后退（0.5→0.6、0.4→0.45、0.3→0.35）再折返。逐项代入 Ft = γΦ(st+1) − Φ(st) 并乘以 γt 求和，结果两条轨迹的塑形总分都等于 0.625，恰好是 −Φ(s0)。

Σt γt·Ft = γT+1·Φ(sT+1) − Φ(s0)；终止时 Φ=0 ⇒ 总分 = −Φ(s0) = 0.625 两条轨迹的中间项全部相消：之字路径每步后退的负分量（如 0.5→0.6 后退一步为 −0.11）都由后续折返步的正分量精确补齐

单步分量也能算清楚：沿直线走一步 5 cm 的 F = (dt − γdt+1)/s = (0.5 − 0.98×0.45)/0.8 = 0.074，其中约 0.05/0.8 = 0.0625 来自"距离真的变短"，另有 (1−γ)dt+1/s ≈ 0.011 来自折扣的账务效应。两点结论。第一，塑形对"怎么到达"完全中性：直线与绕路的总分相同，塑形只改变沿途每步信号分布，给早期学习提供坡度；速度激励必须来自成功奖励的折现或单独设计的项。第二，安全性质可以被手算复核：任何绕路、振荡都无法让总分超过 0.625，019 章担心的"振荡刷分"在 PBRS 下从数学上被排除。

9. 尺度取值依据与截断边界

势函数尺度 s 决定引导信号的量级，取值有可查的依据。以 d ≈ 0.5 m 处一次 5 cm 接近为例，单步塑形分量随 s 的变化：s=0.1 时为 0.59、s=0.8 时为 0.074、s=4.0 时为 0.015。据此给两条设计线：单步分量落在 0.01–0.1（相对稀疏 +1 是可感的坡度，又不至于喧宾夺主），总上界 −Φ(s0)=d0/s 落在 0.5–2（引导总量与成功奖励同量级）。d0=0.5 m 时对应 s 的推荐区间是 0.25–1.0，课件实现取 0.8，正好同时满足两线。s 取小了引导总量失控，退火前策略几乎只学"靠近"；s 取大了单步信号掉到 0.01 以下，早期学习速度与纯稀疏无异。

再看一条容易踩的边界：超时截断不得复用"终止势值归零"。若把时间上限触发的截断也交给 Φ=0 处理，则超时步出现 +|Φ(sT)| 的跳变：在 d=0.5 处停留 200 步后超时，末步跳变高达 +0.625，与整条轨迹的正常累计相当，且停在越远处跳变越大。学习信号因此被污染：拖到超时在塑形账面不吃亏，"一路接近"的相对优势只剩稀疏项。修复：势函数接口区分 terminated 与 truncated，只有成功或失败终止时才归零；截断保留当前势值，让价值引导处理尾部。

实现思路与设计

从稀疏任务出发的完整路线：

  1. 先建立稀疏基线（纯稀疏跑一个小预算，记录成功率，大概率是 0；这个数字是后面所有引导的对照点）。
  2. 设计势函数（到达类：Φ = −d/dscale；抓取类可叠加"靠近 + 夹爪张开度"等物理先验）。
  3. 实现 PBRS 项（F = γΦ(s′)−Φ(s)，终点势值归零；γ 从训练配置读取，不写死）。
  4. 接入并分项日志（稀疏项与塑形项分开记录，贡献占比要能看到，019 章的工具直接复用）。
  5. 可选退火（w(t) 线性衰减；记录 w 的时间曲线以便解释回报台阶）。
  6. 诚实评估（固定种子集，只报稀疏指标；塑形回报仅作训练诊断）。
设计思维：为什么势函数是"注入先验"的最佳位置？

Φ 可以编码任何"好状态"直觉（离目标近、物体抬离桌面……）：定理保证它只影响学习过程、不污染任务定义。很多看似"奖励设计"的问题，其实该被表述成"势函数设计"。

关键代码与解读

片段 1：稀疏奖励 + PBRS 塑形的实现

import numpy as np

class SparseShapedReward:
    """稀疏成功奖励 + 势函数塑形：F = gamma*Phi(s') - Phi(s)。"""
    def __init__(self, gamma, dist_scale=0.8, shaping_weight=1.0):
        self.gamma = float(gamma)        # 必须与算法配置一致：不一致会破坏不变性保证
        self.dist_scale = dist_scale     # 势函数尺度：把距离压到 O(1)
        self.w = shaping_weight          # 塑形权重：支持后续退火，外层可修改
        self.prev_phi = None             # 上一步的势值；reset 时置 None 重新初始化

    def potential(self, p_ee, p_goal, terminated):
        """势函数：负距离。终止状态势值强制为 0（防死亡套利）。"""
        if terminated:
            return 0.0                   # 见 2 节"终点势值"细节
        d = float(np.linalg.norm(np.asarray(p_ee) - np.asarray(p_goal)))
        return -d / self.dist_scale      # 离目标越近，势值越高（越接近 0）

    def compute(self, p_ee, p_goal, success, terminated):
        r_sparse = 1.0 if success else 0.0             # 真目标：只有成功给 1
        phi = self.potential(p_ee, p_goal, terminated) # 当前状态的势值
        if self.prev_phi is None:
            F = 0.0                                    # 回合第一步没有 s'，不产生塑形项
        else:
            F = self.gamma * phi - self.prev_phi       # PBRS 差分项：望远镜相消的核心
        self.prev_phi = phi
        terms = {"sparse": r_sparse, "shaping": self.w * F}
        return r_sparse + self.w * F, terms            # 总数 + 分项（019 章日志规范）

解读：这段代码的三个"对定理的精确翻译"值得逐一确认。第一步 F=0：PBRS 定义在状态转移 (s, s′) 上，回合第一步没有前缀状态，处理成 0 最安全。gamma 从环境配置注入：如果训练用 γ=0.98 而塑形用 1.0 版差分，那么望远镜相消后残留的量将随轨迹变化，理论上会轻微改变最优策略，实践中影响小但没必要引入；直接对齐参数是零成本的正确做法。终止势值归零：这是最容易被忘的一步。失败终止时若势值取"重置初值"，"快速失败"就比"坚持接近"更划算，智能体学会主动放弃；归零切断这条路。分项字典把 sparse 与 shaping 分开记录，才能在任何时刻回答"策略现在是在追真目标还是刷引导"。

片段 2：引导退火与训练循环接入

import numpy as np

class ShapeAnneal:
    """线性退火器：把塑形权重从 1 衰减到 0，让后期完全由真目标塑造。"""
    def __init__(self, start_step, end_step, w_max=1.0):
        self.start, self.end, self.w_max = start_step, end_step, w_max

    def weight(self, total_steps):
        if total_steps <= self.start:
            return self.w_max                          # 早期满权重：快速学到"往哪走"
        if total_steps >= self.end:
            return 0.0                                 # 后期归零：只优化真目标
        frac = (total_steps - self.start) / (self.end - self.start)
        return self.w_max * (1.0 - frac)               # 线性衰减

# total_steps = model.num_timesteps                         # SB3 累计步数
# reward_fn.w = anneal.weight(total_steps)                  # 每步更新退火权重
# 注意：eval 时不使用训练奖励函数；评估用纯稀疏指标（4 节纪律）

解读：退火器的接口设计成"查询式"（给步数、返回权重）这种无状态形式，这样它可以被训练循环、日志系统、甚至事后曲线重建共享，不会因调用顺序不同出现权重错位。参数选择上：start_step 不宜为 0（最初几步连策略都没热起来，退火无意义）；end_step 建议落在总预算的 50%–70%，太早撤引导会让策略"回退"，太晚则失去退火的意义（残差适配风险留存到最后）。代码注释里"eval 不用训练奖励函数"是本章反复强调的纪律在代码里的体现：评估脚本调用的是稀疏判定，SparseShapedReward 只出现在训练侧。

片段 3：三种奖励变体的对照实验骨架

import numpy as np

def run_variant(make_env, train_fn, evaluate_fn, variant, budget, seeds=(0, 1, 2)):
    """对一种奖励变体训练多个种子并评估：所有变体共用预算与评估集。"""
    success_rates, times = [], []
    for seed in seeds:
        env = make_env(variant=variant, seed=seed)   # 变体配置注入环境（奖励函数在此切换）
        model = train_fn(env, total_timesteps=budget, seed=seed)   # 相同训练预算
        sr, t = evaluate_fn(model, eval_seed=9000)   # 固定评估集 → 只取稀疏指标
        success_rates.append(sr)
        times.append(t)
    return {
        "variant": variant,
        "success": f"{np.mean(success_rates):.0%} ± {np.std(success_rates):.0%}",
        "avg_time": f"{np.mean(times):.2f} s",
    }

# 三个变体共用一切条件，只改训练奖励（评估一律用稀疏成功率）：
# for v in ["sparse", "sparse+pbrs", "sparse+pbrs+anneal"]:
#     print(run_variant(make_env, train_fn, evaluate_fn, v, budget=300_000))

解读：这段骨架把 4 节的纪律固化成代码形态，注意四个"相同"：相同预算（30 万步，比较的是"同样钱买到什么"）、相同种子集（训练 0/1/2 三个种子，评估统一从 9000 开始）、相同评估函数（只取稀疏成功率与完成时间，塑形回报进不了报告）、只变奖励（variant 是唯一自变量）。函数签名把 make_env、train_fn、evaluate_fn 作为参数注入，是因为训练脚本的这三块会随实验演进（并行化、算法升级），骨架保持稳定。跑完对照你会得到一张表：纯稀疏能否学会、PBRS 是否加速、退火是否让终态更干净，它就是引导策略的决策依据。

常见坑

  • 用塑形回报评估策略：塑形项是训练工具，不是任务事实。修复：所有对外报告只用稀疏指标（成功率、完成时间）。
  • γ 不一致：塑形的 γ 与算法配置不同，望远镜相消残留漂移项。修复：从训练配置读取 γ 并写进塑形类构造参数。
  • 终止势值未归零：失败终止被套利，"主动放弃"成为策略。修复：终止状态 Φ=0，并用"失败率随训练上升"作为检测信号。
  • Φ 指向错误：符号写反会引导策略冲向障碍。修复：用一句话说清"哪个方向好"，并可视化 Φ 的等值面抽查。
  • 退火过猛：权重在很短的窗口里归零，策略"刚学会走就被撤掉扶手"。修复：退火窗口覆盖预算的 30%–50%，并监控成功率曲线的"台阶"幅度。
  • 超时截断也被势值归零：截断步出现 +|Φ(s)| 的跳变（d=0.5 时约 +0.625），拖到超时的账面与一路接近相当，学习信号被污染。修复：接口区分 terminated 与 truncated，只有真终止归零；用"截断回合的塑形末步贡献"作为检测指标。
  • 势函数尺度失控：s 取 0.1 时单步塑形分量达 0.59，引导项比稀疏 +1 还重，策略只学"靠近"不学"到达"。修复：按 9 节两线取值（单步 0.01–0.1、总量 0.5–2），并用分项贡献占比监控引导项是否长期过半。

练习与思考

  1. 推导望远镜相消：写出 Σt=0T γt(γΦ(st+1) − Φ(st)) 的展开式，确认中间项如何抵消、剩下什么。★
    提示
    逐项写开：γΦ(s₁) − Φ(s₀) + γ²Φ(s₂) − γΦ(s₁) + …；每步 γΦ(s_{t+1}) 与下一项相消。
  2. 在到达任务上跑三种变体（纯稀疏、PBRS、PBRS+退火），用固定种子集报告成功率与平均完成时间，并解释曲线"台阶"出现在哪里。★★
    提示
    台阶出现在退火完成、引导奖励归零的时刻；台阶幅度反映策略对引导的依赖程度。
  3. 把 Φ 从"负距离"改成"负距离 + 0.1×姿态对齐度"，预测并验证学习速度的变化，说明为什么这类先验只应放进 Φ。★★
    提示
    Φ 编码先验不改变最优策略（定理保证）；放进奖励项则有策略偏移风险，对比两种实现。
  4. 构造一个"死亡套利"实验：故意不把终止势值归零，令 Φ(终止) = Φ(s₀)，观察失败率与"快速放弃"行为，并解释观测结果。★★★
    提示
    若失败终止后势值被重置到初值，远离目标时"弃局"能白赚势差；训练日志中失败回合的平均长度会明显变短。
  5. 实验设计：把退火窗口从"50%–70%"改成"0%–20%"，预测训练曲线的形态变化（早期成功率、终态性能、方差），并给出验证指标。★★
    提示
    过早撤引导 → 策略没学好就失去坡度，成功率可能停滞或回退；用成功率±标准差与最小距离双指标验证。
  6. 用 10 行 Python 复算 8 节的验证：分别对直线路径与含三次后退的之字路径逐项计算 ΣγtFt，确认两者都等于 0.625，并算出每次后退步的负分量；据此说明塑形项为什么不包含"速度激励"。★★★
    提示
    用 F = (dt − γdt+1)/s 逐步算；总分 = γT+1Φ(sT+1) − Φ(s0)，终止时只剩 −Φ(s0)，与路径和步数无关。

小结

  • 稀疏奖励的困难是双重的：成功概率极低（可能 10⁻⁵ 每回合）与信用分配长尾；引导信号是标准解法。
  • PBRS 定理：F = γΦ(s′)−Φ(s) 使回报整体平移常数，最优策略不变；Φ = −d 是到达类任务的安全引导。
  • 工程三件套：终止势值归零、γ 与训练一致、引导退火（w: 1→0）；回报曲线的台阶是预期现象。
  • 评估只用真目标（稀疏成功率等），塑形回报仅作训练诊断；对照实验多种子、固定评估集。
