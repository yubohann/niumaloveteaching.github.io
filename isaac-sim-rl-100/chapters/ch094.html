第 094 章：实现群体机器人编队

让一群机器人保持几何队形整体移动：从图的邻接矩阵到拉普拉斯矩阵，从一致性协议到学习式编队，本章把"队形"翻译成连通的代数条件。

  • 主题：系统集成 / 群体编队与图论基础
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：60 分钟
  • 前置章节：第 093 章

学习目标

  • 掌握编队控制所需的图论工具：邻接矩阵、度矩阵、拉普拉斯矩阵及其零特征向量的意义。
  • 理解代数连通度（Fiedler 值）与"通信半径决定编队能不能维持"之间的定量关系。
  • 会说清位移型与距离型编队的差别，以及势场法与一致性协议的原理。
  • 会设计群体编队的 RL 配方：邻居相对观测、局部编队奖励、连通保持、数量泛化。
  • 能诊断"全员静止也是完美队形"、编队尺寸超过通信半径、数量泛化失败等问题。

背景与动机

上一章多台机器人共同"抬一个东西"，物理连接让协调有天然的抓手。编队（formation）更难也更有趣：没有共同的负载，机器人之间只靠"与邻居保持某种几何关系"的约定，就能整体呈现蜂群般的秩序。无人机灯光秀的整齐方阵、农耕机器人的平行作业、搜索与救援的扇形展开，都是编队问题。

它同时是"局部规则产生全局结构"的最佳教科书：每台机器人只看得到通信半径内的邻居，却要形成并维持全局队形。这里图论给出的稳定性条件（连通性、代数连通度）决定了任务在物理上是否可行，很多看似"算法调不好"的问题，实际是通信半径与队形尺寸的几何矛盾。学完本章，你就会用矩阵定量回答"这个队形能不能维持"。

核心原理

1. 把群体写成一张图

N 台机器人构成图 G = (V, E)：顶点是机器人，边表示"两台能通信/感知"（通常在通信半径 r 内）。三个核心矩阵：

邻接矩阵 A：aij = 1（有边）、0（无边）；度矩阵 D = diag(Σjaij)；拉普拉斯矩阵 L = D − A L 的行和恒为 0；对称且半正定，特征值排序 0 = λ1 ≤ λ2 ≤ … ≤ λN

L 的两个事实是整章的骨架：（1）L·1 = 0：向量 1（所有机器人"同意"同一位置）是零特征向量，零特征值的重数等于图的连通分量数；（2）第二小特征值 λ2（Fiedler 值/代数连通度）大于零当且仅当图连通，且 λ2 越大，信息在图上传得越快、一致性收敛越快。λ2 = 0 意味着图断开，分成的两拨机器人"永远无法达成共识"。

2. 一致性协议：为什么"向邻居平均"能收敛

最基础的分布式规则：每台机器人按"与邻居的差值"调整自己：

ẋi = Σj∈N(i) (xj − xi)  ⇔  ẋ = −(L ⊗ I)·x 线性系统；由图论，收敛到全体平均值，速率由 λ₂ 决定（最慢模态 e^{−λ₂t}）

直觉：把差值当成"弹簧"，全系统就是一张弹簧网，能量单调下降直到所有弹簧松弛（共识）。数字感：λ2=0.5/s 时最慢模态衰减时间常数约 2 s，如果你希望编队误差在 3 秒内收进 5%，图的设计（通信半径、连接密度）必须先把 λ2 抬上去。

3. 位移型 vs 距离型编队

类型控制目标坐标系典型问题
位移型pi − pj → dij（向量）需要共同参考系/地标坐标系对齐误差会整体扭曲队形
距离型‖pi − pj‖ → dij（标量）不需要绝对坐标可能镜像翻转（刚性不足时形状不唯一）

距离型在硬件上友好（相对测距即可），但需要研究刚性（rigidity）：一组距离约束要能唯一确定形状（除平移旋转镜像外）。直观结论：平面上正 N 边形需要足够的对角连线（N=4 的正方形至少一条对角线）才能锁住形状；纯外圈连线会"铰链式"翻折。RL 侧对应着：观测里只给邻居距离时，环境必须通过奖励隐含地处理镜像自由度。

4. 势场法与编队误差

工程最常用的编队控制器是势场：为每条期望边定义一个势函数，机器人在总势能下降方向运动：

V = Σ(i,j)∈E* ½·k·(‖pi − pj‖ − d*ij)²，  ẋi = −∂V/∂pi 期望图 E* 的边长 d*_ij 决定几何；k 是"弹簧刚度"，过大会振荡

把这个 V 直接搬进 RL 的奖励（作为编队误差项）就是本章的局部纪律：策略不需要显式学"弹簧力"，但 V 给它的梯度与一致性协议同构，能让训练轻松得多。实践中还要叠加两项：避碰短程斥力（否则"弹簧"会把机器人拉到同一处）与连通保持项。

5. 通信半径 vs 编队尺寸：一个残酷的几何约束

图的边由"距离 ≤ rcomm"决定。若期望队形的某些边长 d*ij 接近或超过 rcomm，对应的边会时断时续，λ2 剧烈波动，甚至整个图分成两半。经验设计准则：

期望边长的最大值 ≤ 0.6 · rcomm 留有 40% 余量，让队形在机动中短暂拉伸时边不中断；通信半径 2 m ⇒ 间距不超过 1.2 m

对 RL 的对应物：观测只聚合"当前在通信半径内"的邻居；若训练时的队形尺寸太接近半径，策略学到的其实是"随机断连下凑合"，泛化很差。把间距、半径都做域随机化，并监控"每步平均邻居数"这个指标。

实现思路与设计

  1. 任务：N=6 台机器人维持正六边形编队（间距 0.8 m），整体沿一个移动的队形中心（领航参考）运动；目标：编队误差收敛并跟上参考速度、无碰撞、不断连。
  2. 观测（每台）：在通信半径内的邻居相对位置（可变数量，聚合为"均值 + 最小值 + 计数"三个特征）；队形中心相对自己的方向与距离；自己的速度。邻居列表长度可变，所以绝不能按编号固定拼观测，要聚合。
  3. 动作：底盘速度 (v, ω)（2 维）。
  4. 奖励：局部编队势场项 −Σ(‖pij‖−d*)²（只对期望边算）+ 避碰斥力项（距离 < 0.3 m 时剧增）+ 连通保持项（邻居数低于 2 时惩罚）+ 全局引导项 −‖中心 − 参考‖ + 平滑项。
  5. 防"静止队形"：参考中心持续运动，并通过"跟随误差"项给方向，没有这一项，"所有机器人原地不动"恰好是编队误差的全局最优（对称的空集陷阱）。
  6. 课程：N=3（三角形，邻居少）→ N=6（六边形）；间距 0.6 → 1.0 m；参考速度 0 → 0.3 m/s。
  7. 评估：编队误差的收敛时间与稳态值、每步平均邻居数（连通性代理）、最小成对距离（碰撞）、以及扩展到 N=8 的成功率（数量泛化）。
设计思维：λ₂ 也可以进观测

把当前通信拓扑的代数连通度 λ2（或它的简化代理"最小邻居数"）作为观测的一部分，策略就能"知道自己快断连了"并主动靠近。对 N≤8 的小队，λ2 由 L 的特征值直接算出（矩阵只有 8×8）；大队伍可用最小度或"最远邻居距离"作代理。这与第 084 章用 σ_min 感知奇异、第 092 章用可达性布尔量是同一思路：把关键安全指标显式喂给策略。

关键代码与解读

片段 1：拉普拉斯矩阵与代数连通度的计算

import torch

def graph_metrics(positions, comm_radius=2.0):
    """由位置计算通信图：邻接矩阵、拉普拉斯矩阵、代数连通度 λ2、平均度。
    positions: (B, N, 2) 或 (B, N, 3)。返回 dict。"""
    B, N, _ = positions.shape
    # 成对距离矩阵：用广播计算 (B, N, N)
    diff = positions.unsqueeze(2) - positions.unsqueeze(1)      # (B,N,N,d)
    dist = diff.norm(dim=-1)
    # 邻接：距离在半径内且非自身；理想化用硬阈值（真实系统是概率性连接）
    A = ((dist < comm_radius) & (dist > 1e-6)).float()          # (B,N,N)
    deg = A.sum(dim=-1)                                         # (B,N) 各顶点度
    L = torch.diag_embed(deg) - A                               # L = D - A
    # 特征值分解：实对称矩阵，用 eigh 保证升序特征值
    evals = torch.linalg.eigvalsh(L)                            # (B,N) 升序
    lambda2 = evals[:, 1] if N > 1 else torch.zeros(B)          # 第二小
    # 图是否连通：λ2 > 阈值（数值上 λ2 约等于 0 也算连通，取 1e-4 更稳）
    connected = lambda2 > 1e-4
    return {"A": A, "L": L, "lambda2": lambda2,
            "mean_degree": deg.mean(dim=-1), "connected": connected}

解读：（1）这个函数每步为整个群体算一次拓扑，N≤16 时开销可忽略（16³ 的特征分解），N 很大时应改成稀疏方法或只监控采样；（2）选用 eigvalsh：L 实对称，用专门的 eigh 家族切保特征值升序且数值精确，也省算力；（3）阈值取 1e-4，不直接和 0 比较：浮点误差下"理论连通"的图 λ2 可能是 1e-6 量级，用 0 判断会误报断开；（4）lambda2 有两个用途，训练中作为观测/奖励（连通性奖励），评估中作为"编队可维持性"的诊断量。

片段 2：编队奖励，势场 + 避碰 + 连通

class SwarmFormationReward:
    """编队局部奖励：势场编队误差 + 短程斥力 + 连通保持 + 全局引导。"""

    def __init__(self, d_des=0.8, r_avoid=0.3, w_form=1.0, w_avoid=2.0,
                 w_conn=0.5, w_guide=1.0):
        self.d_des = d_des                 # 期望边长（六边形边 0.8 m）
        self.r_avoid = r_avoid             # 避碰半径：0.3 m 内开始强斥力
        self.w_form, self.w_avoid = w_form, w_avoid
        self.w_conn, self.w_guide = w_conn, w_guide

    def compute(self, positions, center_err, neighbor_count, edge_pairs):
        import torch
        B, N, _ = positions.shape
        diff = positions.unsqueeze(2) - positions.unsqueeze(1)
        dist = diff.norm(dim=-1)                        # (B,N,N)
        iu = torch.triu_indices(N, N, offset=1)         # 上三角：无向边只算一次
        # 1) 编队势场：只对"期望图中的边"计算 (dist - d*)^2
        d_ij = dist[:, iu[0], iu[1]]                    # (B, E)
        r_form = -self.w_form * ((d_ij - self.d_des) ** 2).mean(dim=-1)
        # 2) 避碰：所有对的距离小于 r_avoid 时按越界深度平方惩罚
        d_all = dist[:, iu[0], iu[1]]
        r_avoid = -self.w_avoid * ((self.r_avoid - d_all).clamp(min=0.0) ** 2).mean(dim=-1)
        # 3) 连通保持：邻居数为 0/1 时惩罚（图即将断开的前兆）
        r_conn = -self.w_conn * (neighbor_count < 2).float()
        # 4) 全局引导：队形中心跟随参考点；没有它，全体静止是最优
        r_guide = -self.w_guide * center_err.norm(dim=-1)
        return r_form + r_avoid + r_conn + r_guide

解读：（1）triu_indices 取上三角避免"同一条边算两次"，所有基于成对量的奖励都该这样处理；（2）编队项取 mean：不同 N 的规模下奖励幅度量级一致，这对数量泛化（N=6 训练、N=8 测试）是必要的；（3）避碰项的权重是编队的 2 倍（w_avoid=2.0）：安全优先原则，且此处的斥力是"软"的，真正防撞还要靠底层速度限幅与几何检查；（4）连通项用 neighbor_count < 2 的脉冲式惩罚，不写成连续函数：它表达的是"低于最低连通要求"这一事件，跟第 087 章冲击惩罚的"事件式惩罚"一个套路。

片段 3：可变数量邻居的观测聚合

def aggregate_neighbor_obs(positions, self_idx, comm_radius=2.0):
    """把"数量可变的邻居列表"聚合成定长特征：均值/最小值/计数。
    这是实现数量泛化（N 可变）的关键；固定编号拼接的方案不可迁移。"""
    import torch
    B, N, _ = positions.shape
    me = positions[:, self_idx:self_idx + 1, :]              # (B,1,d)
    diff = positions - me                                    # (B,N,d)
    dist = diff.norm(dim=-1)                                 # (B,N)
    mask = (dist < comm_radius) & (dist > 1e-6)              # 排除自己与超距
    out = []
    for b in range(B):                                       # 小批量循环（教学清晰版）
        d = dist[b][mask[b]]                                 # 该个体的邻居距离集合
        if d.numel() == 0:
            out.append(torch.zeros(4))
            continue
        # 均值 = "整体远近"；最小 = "最近邻居"；计数 = "拓扑丰富度"
        out.append(torch.stack([d.mean(), d.min(), d.max(),
                                torch.tensor(float(d.numel()))]))
    feat = torch.stack(out)                                  # (B,4) 定长！
    return feat

解读：这是全章最实用的一段工程代码。编队任务里每台机器人看到的邻居数量随队形与通信实时变化，而神经网络输入必须是定长的，聚合函数（mean/min/max/count）就是"可变长度 → 定长"的标准桥，并且天然满足集合的置换不变性（邻居顺序无意义）。教学版用 Python 循环（B 小时可接受），生产版可用 masked mean：(d*mask).sum()/mask.sum() 的向量化形式。三个特征的语义各有分工：mean 感知队形整体尺度、min 感知碰撞风险、count 感知拓扑健康度，后者与片段 1 的 λ2 高度相关。

常见坑

  • 全局静止是"最优队形"：只写编队误差不加引导项，所有机器人停在原地即可完美收敛。修复：移动参考 + 跟随项（片段 2 的 r_guide），并检查"队形中心速度"指标。
  • 编队尺寸超过通信半径：间距 1.5 m 而通信半径 1.5 m，边时断时续、λ2 抖成噪声。修复：设计准则 d* ≤ 0.6·rcomm；或放大半径、加密队形。
  • 固定编号拼邻居观测：训练 N=6 时按 5 个槽位拼接，测试 N=8 直接崩。修复：聚合函数（片段 3）。
  • 只有吸引没有排斥：势场把机器人拉到期望距离，但若少数个体位置接近，会互相"穿越"，仿真的无碰撞穿模让策略学会犯规。修复：避碰斥力 + 物理碰撞体，双保险。
  • 距离型编队的镜像翻转：只约束距离时，整个队形翻个面还是同一组距离。修复：至少一条对角约束（提高刚性），或观测中加入"侧向"性的邻居向量。
  • 要"一点点通信"却给"每分钟一次"：训练时假设即时、无损通信，部署时 10 Hz 且丢包。修复：观测更新加延迟与随机丢包，训练一次到位。

练习与思考

  1. 构造 3 台、4 台机器人在一条直线上的位置，手算邻接矩阵 A 与 L，验证 λ2 与连通性的关系（直线间距超过通信半径时 λ2=0）。★★
    提示
    3 台等距且都连通时 L 是一个"路径图"的拉普拉斯；断开成一个 2+1 时零特征值重数变为 2，用 eigvalsh 验证。
  2. 实验：把期望间距从 0.6 m 调到 1.2 m（通信半径 2 m 不变），记录 λ2 的时间序列与编队误差。★★
    提示
    间距接近 0.6–1.2 m 仍安全（≤ 0.6·r_comm）；把间距拉到 1.8 m 以上会看到断连与 λ2 抖动，这就是几何约束的临界证据。
  3. 把观测从"聚合特征"改为"按编号拼接最近 3 个邻居"，对比 N=8 上的泛化成功率。★★★
    提示
    拼接方案在训练数量上可能表现相近，但换数量后断崖下跌，这是"置换/数量泛化"的经典对照实验。
  4. 设计：把 λ2 加入观测（N=6 可算），比较训练收敛速度与"断连时长占比"。★★★
    提示
    λ2 给了策略"拓扑健康度"的直接信号；预期断连时长显著下降，但注意把它归一化（除以 N）再进观测。
  5. 用一致性协议（ẋ = −Lx）作为"编队移动"的底层控制器基线，与端到端 RL 对比稳态编队误差与能耗。★★
    提示
    经典协议在无扰、无避碰下几乎零误差，但遇到障碍或个体失效就崩；RL 的对比优势体现在鲁棒场景，设计四种场景做对比表。

小结

  • 编队的图论骨架：邻接矩阵 A、度矩阵 D、拉普拉斯矩阵 L = D − A；L·1 = 0、零特征值重数 = 连通分量数。
  • 代数连通度 λ2 > 0 ⇔ 图连通；它同时决定一致性收敛速度，是"队形能不能维持"的定量判据。
  • 位移型编队需要共同坐标系、距离型只需测距但有镜像自由度；势场 V = ½Σ(‖pij‖−d*)² 是奖励里最直接的局部纪律。
  • RL 配方：邻居观测用聚合（mean/min/max/count）保证数量泛化；奖励含势场 + 避碰 + 连通 + 全局引导，缺了引导项会退化成"全体静止"。
  • 设计准则 d* ≤ 0.6·rcomm；通信延迟与丢包要在训练时建模。下一章把编队升级成对抗赛，对手的存在让奖励结构彻底换血：分层策略与自我对弈，见第 095 章。
