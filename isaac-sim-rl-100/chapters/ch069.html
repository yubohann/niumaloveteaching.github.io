第 069 章：实现安全强化学习

把"不许撞坏、不许超限"从愿望变成公式：本章用约束马尔可夫决策过程（CMDP）与拉格朗日方法训练带预算约束的策略，再叠加一层控制屏障函数安全滤波兜底。

  • 主题：安全 RL / 约束优化与安全滤波
  • 相关组件：Isaac Sim / Isaac Lab / PPO（自定义代价回路）
  • 预计学时：65 分钟
  • 前置章节：第 068 章

学习目标

  • 会用 CMDP 表述安全任务：在最大化回报的同时满足累积代价约束 Jc ≤ d。
  • 理解拉格朗日松弛的直觉："λ 是安全的价格"，并用对偶上升让 λ 自动适应预算。
  • 说清它与"固定惩罚项"的本质差异，以及为什么惩罚系数拍脑袋定不出想要的违约率。
  • 会在 Isaac Sim 里定义代价函数（碰撞力、限位余量、速度超标）并接入 PPO 双回路训练。
  • 会用控制屏障函数（CBF）构造最小干预安全滤波器，在动作下发前做最后一道防护。
  • 会以"违约率-回报"帕累托前沿评估安全策略，违约率与回报一并读取。

背景与动机

普通 RL 只优化期望回报，它"愿意"用偶尔的剧烈碰撞换取长期高回报，在仿真里这没关系，在真机上意味着烧电机、撞坏工件。安全强化学习（Safe RL）要解决的问题是：在尽可能高的任务回报下，把违规（碰撞、超限、失稳）的累积量压到给定预算之内。

这不是"给碰撞加个惩罚"那么简单：惩罚是软性的，系数调小则约束失效，调大则策略畏手畏脚、任务表现崩盘。本章的正规做法分两层。训练层用约束马尔可夫决策过程（Constrained MDP, CMDP）+ 拉格朗日对偶：让算法自己找到"恰好满足预算"的惩罚价格；运行层再叠加一道控制屏障函数（Control Barrier Function, CBF）安全滤波器，把任何策略（包括训练不充分的）输出投影到安全动作集上。两层互补，训练层考虑长期权衡，滤波层保证单步硬安全。

核心原理

1. CMDP：给 MDP 加一条"代价预算线"

在标准 MDP (S, A, P, R, γ) 上增加代价函数 C: S×A → R≥0，得到 CMDP (S, A, P, R, C, γ)。策略 π 的回报与代价回报分别为：

Jr(π) = Eπ[ Σt γt rt ]　　Jc(π) = Eπ[ Σt γt ct ]

安全 RL 的目标是求解：

maxπ Jr(π)　s.t.　Jc(π) ≤ d d 是代价预算：可由真机容忍度换算，例如"每 1000 步碰撞力超标事件 ≤ 2 次"

预算 d 的物理含义要亲手算一遍：若定义为"每回合平均碰撞力冲量 ≤ 5 N·s"，那 d 就是每回合允许的累积冲量上限。它必须来自硬件/工艺的真实容忍度；拍脑袋定的预算在安全 RL 落地时最容易被糊弄、也最致命。

2. 拉格朗日松弛：把约束变成"价格"

构造拉格朗日函数（λ ≥ 0）：

L(π, λ) = Jr(π) − λ · ( Jc(π) − d ) λ 是"单位违规的价格"：违反预算时 λ 上升，惩罚加重；有富余时 λ 下降

对 λ 求 min、对 π 求 max，鞍点就是原约束问题的解（凸性条件下严格成立；深度 RL 里是局部近似，实践效果良好）。训练用原对偶交替：固定 λ，用 PPO 最大化 L（即回报减去 λ 加权的代价）；然后更新 λ：

λ ← max( 0, λ + ηλ · ( Jc(π) − d ) ) 违反预算（Jc > d）→ λ 增大 → 策略更重视安全；低于预算 → λ 减小 → 策略可以更激进

与固定惩罚的本质区别：固定惩罚 w·c 的最优策略只依赖 w，你无法预先知道它对应多少违约率，只能试错扫参；而拉格朗日方法的解在鞍点上必然满足 Jc ≈ d（活跃约束），你设定想容忍的违约水平，算法去找实现它的价格。λ 的收敛轨迹本身也是诊断信号：震荡说明 ηλ 太大或两个目标冲突太强，发散说明代价定义或预算不合理。

3. 代价函数怎么定义：把"物理危险"翻译成可累积的量

危险源代价 ct 设计预算量级示例
碰撞/冲击max(0, Fcontact − Fsafe) · Δt，Fsafe=20 N每回合 ≤ 5 N·s
关节接近限位max(0, marginsafe − margin)，margin 为到限位的角距离每回合 ≤ 0.3 rad（累积）
速度超标max(0, |q̇| − q̇max) · Δt每回合 ≤ 0.1 rad（累积）
失稳（倾角/姿态）指示式：躯干角超阈值持续步数每回合 ≤ 5 步

设计原则：代价必须"越危险越大、可加、有界"。0/1 指示的碰撞代价信息量太少（撞得轻和撞得重一样），连续的力超额给梯度；但也不能无上界，否则单次大碰撞主导整个期望，训练难以收敛。用"超额量×时长"这类形式兼顾两者：小违规有密度、大违规有上界（限幅）。

4. 安全滤波：CBF 的最小干预投影

训练层管长期，单步硬安全靠控制屏障函数。设安全集由函数 h(x) ≥ 0 定义（例如 h = 到障碍距离 − 0.05 m），只要保证

ḣ(x, u) + α · h(x) ≥ 0　对某个 α > 0 h 大时可以自由行动，h 逼近 0 时该项迫使状态"回头"，指数屏障的松弛形式

则在 h(x0) ≥ 0 时不变量成立：轨迹永远不会进入 h < 0。滤波器求解"离策略动作最近、且满足 CBF 条件"的动作（一个小的二次规划）：

u* = argminu ‖u − uπ‖²　s.t.　ḣ(x, u) + α·h(x) ≥ 0，u ∈ U "最小干预"意味着：策略安全时它什么都不做；策略要越界时它只修正最小必要的分量

工程上更常用的是它的简化版：对速度/力矩直接做上界投影（例如按 CBF 推导的最大允许接近速度截断）。在 Isaac Sim 里可以用解析式先验证逻辑，再上正式 QP 求解器。

实现思路与设计

以"导轨上高速接近挡板的 Franka 推块任务"为例（挡板是危险物，推块是目标物）：

  1. 定义代价与预算：接触力超额项（Fsafe=15 N）+ 关节速度超标项；预算 d 换算为"每回合累积超限量 ≤ 3 N·s"。预算的验证方法：先跑 5 回合人操数据统计自然水平，再取一个更紧的目标作为训练指标。
  2. 训练回路：PPO 主回路（回报）+ 独立的价值网络与 GAE 计算代价优势；损失 = 策略损失 + λ·代价损失。λ 初始取 0，每 20 个训练迭代做一次对偶上升，学习率 ηλ=0.05，并限幅 λ ≤ 5.0 防止一次大违规把价格打飞。
  3. 代价的折扣与回报一致：代价也用 γ 折扣（γ=0.99），保证 Jc 数值尺度与 Jr 可比、λ 的调节平滑；若用无折扣代价，λ 的更新会随着回合长度漂移。
  4. 安全滤波：对"末端与挡板距离"定义 h(d)=d−0.03；用微分关系把 CBF 条件转成"最大允许末端接近速度"，对策略输出的笛卡尔速度指令做最小投影；滤波器修改量与触发频率都记录，供复盘。
  5. 评估协议：训练结束后扫 λ∈{0, 1, 3}（或扫预算 d）得到违约率-回报曲线，报告帕累托前沿；安全策略的验收标准是"违约率达标且回报损失相对无约束基线小于 15%"（阈值按任务定）。
设计思维：安全滤波为什么放在"动作下发前"？

放环境里（对危险状态直接罚/终止）是训练手段，不是运行保障，策略没训好时真机依然会撞。放在动作下发前，滤波器对任何策略（包括训练早期的随机策略、推理异常的输出）都提供单步保障，且它只依赖当前状态估计与安全集定义，不依赖策略质量。两层职责清晰：训练层学会"根本不打算违规"（省得滤波器频繁干预），滤波层保证"想违规也执行不了"。

关键代码与解读

片段 1：Isaac Sim 环境里的代价计算与台账

import torch

class SafetyCost:
    """把物理危险翻译成可累积标量代价；逐环境独立记账。"""
    def __init__(self, n_envs, f_safe=15.0, qd_max=3.0, dt=1.0 / 60.0,
                 force_scale=0.01, speed_scale=0.05):
        self.n, self.dt = n_envs, dt
        self.f_safe, self.qd_max = f_safe, qd_max
        # 两项代价先各自量纲归一，再相加：否则 N·s 与 rad 无法可比
        self.force_scale, self.speed_scale = force_scale, speed_scale

    def compute(self, contact_force, joint_vel):
        # 力超额：max(0, F − F_safe)，小违规给梯度、大违规有上界（力本身有物理上限）
        c_force = torch.clamp(contact_force - self.f_safe, min=0.0) * self.dt
        # 速度超标同理；取范数覆盖任意方向高速，单轴会漏检斜向超标
        qd_norm = joint_vel.norm(dim=-1)
        c_speed = torch.clamp(qd_norm - self.qd_max, min=0.0) * self.dt
        cost = self.force_scale * c_force + self.speed_scale * c_speed
        return cost                           # [n_envs]，由训练框架累加成回合成本

# 环境 step 返回：坏境 index 0 是回报，info 里额外携带 cost，供双回路算法使用
# obs, reward, terminated, truncated, info = env.step(action)
# info["cost"] = safety_cost.compute(contact_force, joint_vel)

解读：设计要点有三。逐环境张量化：安全训练在大规模并行下进行（4096 环境），代价必须是向量；Python 标量循环会让吞吐崩溃。超额量 × dt：乘时长把它变成"累积量"（单位 N·s、rad），与预算 d 的量纲一致；不乘 dt 的话，同一事件在高频环境里会被多计倍率。两项分开缩放再相加：力的典型超额是几十 N（乘 0.01 后 0.1–1 量级），速度超额是 0.1–1 rad/s（乘 0.05），让两项在同一个数量级上谈判，这不是数学必需，是工程调参的润滑剂。代价计算刻意放在环境侧：不同的观测表示、不同的传感器都能复用同一套记账，`info["cost"]` 成为标准接口，与第 080 章容错、第 081 章能量优化共用一条通道。

片段 2：PPO-Lagrangian 的对偶更新

class LagrangeMultiplier:
    """λ 的对偶上升：违反预算就涨价，低于预算就降价；带阻尼与限幅。"""
    def __init__(self, lr=0.05, lam=0.0, lam_max=5.0, ema=0.9):
        self.lr, self.lam, self.lam_max, self.ema = lr, lam, lam_max, ema
        self.cost_ema = None                 # 代价回报的滑动平均：单次迭代噪声大

    def update(self, mean_cost_return, budget):
        if self.cost_ema is None:
            self.cost_ema = mean_cost_return
        else:
            self.cost_ema = self.ema * self.cost_ema + (1 - self.ema) * mean_cost_return
        # 对偶梯度：dL/dλ = −(J_c − d)；上升步 = +η(J_c − d)
        self.lam = max(0.0, self.lam + self.lr * (self.cost_ema - budget))
        self.lam = min(self.lam, self.lam_max)     # 限幅：防止极早期的大违规把价格打飞
        return self.lam

# 训练循环（每 20 个迭代更新一次 λ，比策略更新慢一档，近似"原问题先动、对偶后动"）
# lam = dual.update(mean_cost_return=episode_cost_mean, budget=cost_budget)  # 对偶慢回路
# policy_loss = pg_loss + vf_coef * value_loss - ent_coef * entropy
# cost_adv = compute_gae(cost_values, costs)      # 代价独立的 GAE 与价值网络
# actor_loss = policy_loss + lam * (cost_adv * logp).mean()

解读：对偶上升的核心一行是 lam += lr * (cost_ema - budget)，注意方向：代价超预算时 λ 增大（惩罚变贵），低于预算时 λ 减小（松绑）。三点工程细节：EMA 平滑是必须的，单次迭代的代价回报方差大，直接把原始值喂给 λ 会引起"价格跳动→策略抽搐→价格反向跳动"的恶性振荡；λ 更新频率更慢（每 20 迭代 vs 策略每迭代）是原对偶算法的时间尺度分离，经典做法；限幅 λmax 是安全阀，早期还有大量违规时若不打上限，λ 可能冲到 100+，梯度被完全压制，策略再也没机会学任务。理论上完整算法里代价也有自己的价值网络与广义优势估计（GAE），实践中"代价优势用代价价值网络算、策略损失用 λ 加权"已经能拿到大部分收益。

片段 3：CBF 速度投影安全滤波（简化解析版）

import numpy as np

def cbf_speed_filter(v_cmd, distance, alpha=2.0, d_stop=0.05):
    """朝障碍方向限制接近速度：ḣ + αh ≥ 0 的解析投影。
    h = distance − d_stop ≥ 0 是安全集；v_cmd 为策略给出的末端速度指令。"""
    if distance <= d_stop:
        return np.zeros_like(v_cmd)          # 已在安全集边界：只允许远离，禁止继续接近
    # 需要知道障碍方向：这里用单位向量 e（实际系统中来自距离场/射线/势场梯度）
    e = normalize_obstacle_direction()       # 指向障碍的单位向量
    v_approach = float(np.dot(v_cmd, e))     # 当前接近速度分量（正值表示在接近）
    v_max = alpha * (distance - d_stop)      # CBF 给出的最大允许接近速度
    if v_approach <= v_max:
        return v_cmd                         # 本来就安全：最小干预 = 不干预
    # 只砍掉超出的接近分量，保留切向运动：这是"最小干预"的字面含义
    return v_cmd - (v_approach - v_max) * e

解读：CBF 条件 ḣ + αh ≥ 0 在这里展开为"接近速度 ≤ α·(距离−d_stop)"：离障碍越近，允许的接近速度按比例越小，逼近 d_stop 时归零，这正是"指数屏障"的物理图像。滤波器的行为符合最小干预三段律：安全时原样放行（v_approach ≤ v_max 直接返回）、临界时按需削减接近分量（只动径向、保留切向）、贴边时只许远离（返回零接近）。“只砍径向”这个设计让机器人贴着障碍滑过去，避免被推停，能显著减少滤波器对任务的干扰；滤波器开销是 O(1) 的向量运算，1 kHz 下也无压力。真机实现里 e 的方向估计常来自距离场或势场梯度；多约束时单一解析式不再够用，写成一个带多个线性约束的小 QP 交给求解器（哪怕 4 个约束、10 行的求解器也远快于控制周期预算）。

常见坑

  • 用固定惩罚代替 λ 自适应：扫了 5 个惩罚系数找到"差不多能忍"的一个，换任务/换速度就得重扫，而且永远无法精确命中违约率。症状是实验记录里一堆"惩罚=0.1 撞 3 次、0.5 撞 1 次、2.0 不撞但慢"的试错。修复：拉格朗日对偶，让算法自己定价。
  • λ 更新太快或太大：价格振荡导致策略在"激进行为"和"畏缩行为"之间横跳。症状是回报与违约率曲线同步剧烈振荡。修复：EMA 平滑代价、降低 ηλ、拉开策略/对偶更新频率、加 λ 限幅。
  • 代价量纲混乱：力、角度、时间直接相加，某一项把 λ 的调节带偏。症状是只有某一类违规被压制，另一类被忽视。修复：逐项归一化后加权，定期检查各项在总代价中的占比。
  • 只在训练后期记录违约：训练早期的大量违规把 Jc 的统计带偏，验收时才第一次看违约率的真面目。症状是"训练日志一片祥和，验收一塌糊涂"。修复：从第一个迭代开始逐回合记录违约次数与峰值，训练中途画违约率-回报散点。
  • 奖励套利（reward hacking）：策略学会"用极慢速度蹭过去"或"撞在传感器死区里"来规避代价。症状是违约率达标但任务时间翻倍/任务成功率跳水。修复：代价定义要覆盖规避路径（时长计入约束或奖励），质检阶段做行为录屏抽查，不能只看数字。

练习与思考

  1. 把速度超标阈值从 3.0 rad/s 改到 1.5 rad/s，固定其余配置重训，观察 λ 的收敛值与任务回报变化。★
    提示
    更紧的约束 → λ 收敛到更高价位 → 回报下降；记录"回报损失 vs 约束收紧"曲线，这就是安全的价格。
  2. 对比实验：固定惩罚系数 w∈{0.1, 1.0, 10} 与拉格朗日自适应各训一次，画出违约率-回报散点，说明哪一个更容易命中目标违约率。★★
    提示
    固定 w 三个点散落在曲线上不同位置；拉格朗日法在鞍点附近自适应，通常落在预算线邻近处。
  3. 把 CBF 滤波的 α 从 2.0 调到 0.5 与 5.0，观察滤波触发频率与任务完成时间，解释 α 的物理含义。★★
    提示
    α 是"安全集边界的收敛速率"：太小刹车太晚、触发频繁；太大则过早减速、任务变慢。
  4. 设计一个代价-奖励冲突场景（例如"快速穿过狭窄通道"），记录训练中 500 个迭代的 λ 曲线，标注每次碰撞事件，解释对偶变量如何"记住"了危险区域。★★
    提示
    λ 在发生碰撞的迭代附近上冲，随后缓慢回落；它以全局价格的形式概括了"此时此地危险"的信息。
  5. 设计验收协议：给一个安全策略定义 4 项验收指标（违约率、峰值违规、任务回报、任务时长），并给出你任务上的数值阈值与理由。★★★
    提示
    阈值从硬件与工艺来：峰值力不超过工件屈服强度的百分数、时长不超过人工基准的 1.3 倍等。

小结

  • 安全 RL 的形式化是 CMDP：max Jr s.t. Jc ≤ d；预算 d 必须来自硬件容忍度的真实换算。
  • 拉格朗日松弛把约束变成价格：L = Jr − λ(Jc − d)，对偶上升 λ ← max(0, λ + η(Jc − d)) 自动定价。
  • 与固定惩罚的本质区别：惩罚系数定不出违约率，对偶变量让解落在预算线上（活跃约束）。
  • 代价设计三原则：越大越危险的连续梯度、可累积、有上界；分项归一化后再合并。
  • CBF 安全滤波提供单步硬安全：ḣ + αh ≥ 0，最小干预只砍危险分量；与训练层互补，是部署前最后一道闸。
  • 下一章回答"扰动下的性能保持"：不设定预算，改为假设环境参数在一个不确定集内变动，鲁棒强化学习，和本章的约束视角正好构成一对。
