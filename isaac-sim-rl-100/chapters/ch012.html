第一篇 · 仿真环境与训练框架

第 012 章：实现随机化初始状态

把"每次从同一个姿势开始"变成"每次从分布里的一个采样开始"：设计采样范围、保证可复现、拒绝非法开局，并理解随机化对泛化的价值与代价。

  • 主题：仿真环境 / 初始状态分布采样
  • 相关组件：Isaac Sim（状态写入）、NumPy 随机数生成器
  • 预计学时：50 分钟
  • 前置章节：第 011 章

学习目标

  • 理解初始状态分布 ρ0 在 RL 中的地位：策略的期望性能是对 ρ0 求平均，分布越多样、泛化压力越大。
  • 会设计采样清单与范围：机器人位姿、关节构型、目标物位姿各自的合理区间。
  • 掌握可复现采样的正确做法：带种子的 Generator，避免全局随机状态。
  • 会处理非法初始状态：避让采样区、拒绝采样与稳定期配合。
  • 能评估随机化带来的训练变难（方差上升、样本需求增加）并设计对照实验。

背景与动机

011 章的确定性重置让每个回合都从同一个姿势开始。这会带来一个典型的学习捷径：策略可以记住"这一条固定轨迹"，而不需要真正理解任务。一旦评估时初始条件稍有变化，性能立刻跳水。解决办法是让每个回合从初始状态分布 ρ0 中采样不同的开局，策略被迫学习"从任意位置都能完成任务"的通用策略。

这也是"训练时见过的多样性 = 部署时的鲁棒性"这一原则的最基础版本。021 章会把随机化扩展到动力学与外观（域随机化），而本章只动初始状态，是整套随机化方法里最安全、收益最先显现的一步。

核心原理

1. 从单点到分布：ρ0 的语义

回顾 011 章的目标函数：轨迹从 s0 ∼ ρ0 出发。确定性重置相当于 ρ0 是单点分布（概率全在一个状态上）；随机化重置把它变成真正的分布。训练目标随之变成"对分布的平均性能"：

J(θ) = Es0∼ρ0, τ∼πθ [ Σ γt rt ] ρ_0 越宽，J(θ) 衡量的是越"通用"的策略；训练难度也随分布宽度上升

实用推论：ρ0 的宽度就是难度旋钮，范围小收敛快，范围大更泛化；常见做法是"先窄后宽"的课程（032 章）。

2. 采样什么：三组量，三种纪律

组典型范围（抓取示例）纪律
机器人基座位姿x, y ±0.1 m；偏航角 ±0.3 rad小范围扰动即可；大幅移动往往更适合用固定基座 + 随机目标物实现
关节构型默认姿态附近 ±0.1–0.2 rad（截断到限位内）只采"合理邻域"：远离默认位姿的构型可能自碰撞或不可达
目标物位姿工作区内 ±0.15 m；绕 z 轴 ±180°最大的一组随机性通常在这里；要留在机械臂可达域内
初始速度通常全零；需要时 ±0.05 rad/s 量级速度随机化要非常保守：大速度会让物理开局就"飞"

为什么目标物占随机化的大头？因为操作任务的定义就是"从任意目标位置完成操作"；基座位姿扰动只起"防记忆"作用。先问"评估时自由度在哪里变"，答案决定清单权重。

3. 分布形态与可复现性

最常用的是均匀分布（区间内等概率）：简单、无中心偏好。希望"多数靠近基准、少数偏远"时用截断高斯（截断到 ±2–3σ）：均匀分布有一半回合比平均更偏，早期训练偏难；截断高斯压低极端概率，训练更平滑。

可复现性是随机化最容易做错的一点：永远用带种子、独立实例的生成器（如 np.random.default_rng(seed)）；全局 np.random.* 的状态被任何库代码共享，别处多调一次就改变采样序列，崩溃时连"重放开局"都做不到。独立 Generator 还天然支持并行环境各持种子流（022 章用）。

4. 非法开局：重叠、穿越、不可达

随机采样可能产生物理上荒谬的开局：目标物与桌面半重叠、落在机械臂正下方、或者超出可达域。三种处理策略：

  • 避让设计：把范围定义在"安全区"（桌子边缘留 2 cm、避开基座半径）：最简单、零开销，覆盖 90% 情况。
  • 拒绝采样：采样后做合法性检查（碰撞查询、可达性判断），不合法就重采，最多重试 K 次（如 20 次），仍失败则回退到默认状态。开销可控。
  • 软处理：接受轻微重叠，靠稳定期让物理"弹开"。只适合毫米级的小重叠，且会引入初始状态不确定性，不推荐作为主策略。

5. 分布形态的量化对比：均匀与截断高斯

两种分布可以定义在同一区间上，差别在样本密度的分布。以范围 ±0.1 m 为例，截断高斯取 σ = 0.05 m、截断到 ±2σ：

指标均匀分布截断高斯（σ = 0.05 m，±2σ）
中心 60% 之外的样本占比40%约 24%
极端样本（|x| 超过 0.08 m）占比20%约 11%
训练表现早期难度方差大多数样本靠近中心，训练平滑
实现成本一行 uniform需要 raw-normal + 截断重采

第二行的口径：均匀分布在 |x| 超过 0.08 m 的部分占比为 (0.1 − 0.08) / 0.1 = 20%；截断高斯中该部分约占 11%（按 1.6σ 之外的双侧概率除以截断区间质量估算）。样本密度的差异直接转化为"早期训练遇到极难开局的频率"：高斯配置大约把极端开局的频率压低一半。

6. 拒绝采样的定量：接受率与重试上限

设单次采样通过合法性检查的概率为 p，最多重试 K 次，整轮重置失败的概率为：

Pfail = (1 − p)K，期望尝试次数 E ≈ 1 / p（p 不太小时） K = 20、p = 0.3 时 P_fail ≈ 0.7²⁰ ≈ 0.08%；p = 0.1 时 P_fail ≈ 0.9²⁰ ≈ 12%

这组数字给出两条准则：重试 20 次对接受率 30% 以上的采样区足够可靠，失败概率可以忽略；接受率降到 10% 时失败率升至 12%，此时更该收缩采样范围或修整合法区，继续加大 K 收效有限。监控指标用"每千次重置的拒绝次数"：它从 5 升到 200，说明采样区已经与可达域脱节。

7. 范围扩展的课程化数值示例

把范围宽度当作可调度的训练量：令缩放因子 s 从 0.2 线性升到 1.0，最终范围 ±0.15 m 时，开局范围随训练推进从 ±0.03 m 扩到 ±0.15 m。若扩展在总训练步数的前 30% 内完成，剩余 70% 的步数用于在全范围精调。这种安排的量化依据来自前面的权衡：窄范围早期成功率高、梯度信号密集；宽范围后期提供泛化压力。扩展过快（例如 5% 步数内完成）相当于从窄分布直接跳到大分布，评估曲线会出现明显回撤；扩展过慢则总训练量被拖长。

8. 评估的统计口径：50 个回合能分辨多大的差异

成功率是伯努利量的均值，n 个评估回合下的标准误为：

SE = √(p(1 − p) / n) p = 0.7、n = 50 时 SE ≈ 6.5%；要压到 2% 需要约 525 个回合，压到 1% 需要约 2100 个回合

这条公式补全了"固定种子集"的另一半含义：固定种子解决"同一批开局公平比较"，样本量解决"随机波动有多大"。用 50 个回合评估时，两个模型 3% 的差异完全落在噪声范围内；报告口径写成"n ≥ 200 的固定种子评估，附标准误"，结论才站得住。评估样本量和训练样本量同样需要预算，早期用小样本快速迭代，正式对比时再扩大。一个可操作的流程：先用 50 回合筛掉明显较差的候选，进入对比环节的模型统一用 300–500 回合复核；两档结论方向相反时，以样本量更大的一方为准。报告对外结论时把样本量与标准误一起给出，避免把噪声当作进步。评估样本量的预算写进实验配置，与随机化范围成对管理。

9. 评估口径的置信区间核算

把标准误公式做成一张可查的置信区间表（95% 置信水平下取 ±1.96 倍标准误）：

真实成功率评估回合数标准误95% 置信半宽
0.85505.1%±9.9%
0.852002.5%±4.9%
0.60506.9%±13.6%
0.602003.5%±6.8%

读表得到三条纪律。第一，50 个回合的评估只能把真实能力钉在约 ±10–14 个百分点的带子里，两个模型相差 5 个百分点时，这个差异完全淹没在抽样噪声里。第二，要把可比差异压缩到 5 个百分点以内，需要把双方标准误压到约 1.3%，对应约 800 个回合的量级（真实成功率 0.85 附近）。第三，置信半宽与回合数的平方根成反比：回合数翻四倍，精度才翻一倍，加大样本量的收益是递减的。评估协议因此定成两档：迭代期用 50 回合快速筛查，正式对比用 300–500 回合复核，报告同时给出回合数与置信半宽。

负采样与拒绝采样的预算也顺手结清。截断高斯在 ±2σ 处截断时，区间外的概率约 4.5%，接受率 95.5%；截断放到 ±1.5σ 时接受率约 86.6%。拒绝采样的平均尝试次数约为 1 / p：合法率 30% 时平均 3.3 次，若单次合法性检查约 0.05 ms，单个重置的采样成本约 0.17 ms；并行 1024 个环境、1% 重置率下，每步约 10.2 次重置合计约 1.7 ms，已经接近步进预算的六成，这正是合法性检查必须做成廉价、可向量化判据的原因。合法率降到 10% 时平均尝试 10 次、成本再翻三倍，同时兜底回退率升到 12%，此时正确的动作是收缩采样范围，继续加大重试上限会掩盖问题。

课程式扩展可以落成一张具体的调度表。设总训练 60 万步、扩展安排在前 30%（18 万步）内完成：把 18 万步分成 10 档、每档 1.8 万步，缩放因子从 0.2 线性升到 1.0，每档增加约 (1.0 − 0.2) / 9 ≈ 0.089。若最终范围是 ±0.15 m，开局范围从 ±0.03 m 起步，每档向外扩约 ±0.013 m。这样安排的量化理由在第 7 节已经给出：窄范围早期成功率高、梯度信号密集，宽范围后期提供泛化压力；把扩展压进前 30% 的步数，是让"较难的开局"尽早进入训练分布、又不在最早期就把成功率压到零的折中。扩展表与评估种子集一起写进实验配置，跨实验对比时两边的调度保持一致。

随机性的三层结构也在这里一并讲清：环境采样种子决定初始状态序列，算法种子决定网络初始化与动作采样，评估种子决定检验用的开局集合。三层各自独立、各自记录，才能回答"这次结果差异来自算法、来自采样，还是只是评估抽签"。三层混用一个全局随机源时，任何一次"多调了一次随机数"的改动都会让旧结果无法复现，这是随机化工程里最常见的返工来源。核对方法也很直接：同一训练种子连跑两次，评估曲线应逐点一致；若第二次结果不同，说明有随机源没有受控。不同训练种子之间的评估差异则给出"种子方差"的估计，它可与第 9 节的抽样置信区间相加，构成实验结论的不确定性总账。

实现思路与设计

实现随机化重置的步骤：

  1. 写采样清单（按 2 节的表格，为每个量写下分布类型与范围，先全部取小值跑通）。
  2. 建采样器对象（持有 rng 与参数；提供 sample() 返回一个"重置字典"）。
  3. 接入 reset_state（011 章的流程不变，只把写死的初值换成字典里的采样值）。
  4. 合法性过滤（拒绝采样或范围避让；把失败次数记入日志）。
  5. 稳定期（保留 011 章的 settle 步；随机化会带来更大的瞬态，稳定期可以适当加长）。
  6. 评估协议（评估用固定种子集合，让不同版本的模型面对同一批开局；报告"固定种子得分 + 随机种子得分"两个数字）。
设计思维：评估为什么要固定种子？

随机化训练让每次评估的样本不同，"这版模型比上版好 3%"可能只是这次抽到的开局更简单。用同一批评估种子（例如 50 个固定开局），不同模型面对完全相同的考验，比较才有意义；再补一组随机种子的评估衡量"运气之外的稳健性"。这项纪律从今天开始建立，后面 017 章接入 Stable-Baselines3 后会一直用到。

关键代码与解读

片段 1：带种子的采样器

import numpy as np

class ResetSampler:
    """初始状态采样器：独立随机数流 + 参数化范围，可复现。"""
    def __init__(self, seed):
        self.rng = np.random.default_rng(seed)  # 独立 Generator：不碰全局 np.random 状态
        # 关节扰动：每个关节在默认姿态附近 ±0.1 rad 内采样（示意：9 个 DOF）
        self.joint_noise_max = 0.1

    def sample(self, default_joints, workspace_box):
        """返回一组初始状态：关节（截断到限位）+ 目标物位姿。"""
        noise = self.rng.uniform(-1.0, 1.0, size=len(default_joints)) * self.joint_noise_max
        joints = default_joints + noise        # 均匀分布：避免对某个方向有偏好
        # 目标物：在工作区盒子里均匀采样 x/y，绕 z 轴均匀采样朝向
        x = self.rng.uniform(workspace_box["x_min"], workspace_box["x_max"])
        y = self.rng.uniform(workspace_box["y_min"], workspace_box["y_max"])
        yaw = self.rng.uniform(-np.pi, np.pi)  # ±180°：方形物体四个朝向等价，圆形无差别
        return {"joints": joints, "object_pose": (x, y, yaw)}

解读：default_rng(seed) 返回的是独立的 PCG64 生成器实例，它的状态只被自己的 uniform / normal 调用推进，这正是可复现性的关键：无论库里其它代码怎么调随机数，只要种子相同、调用序列相同，sample() 的输出就逐位相同。yaw = rng.uniform(-π, π) 的注释点出了一个任务层面的推理：如果目标物是方形的，绕 z 旋转 90° 后外观与物理都对任务无差别，采样范围可以缩小到 [−π/2, π/2] 以降低难度；如果物体是不对称的（比如带把手的水杯），就必须全角度采样。采样范围的选择始终服务于"任务的不变量是什么"。

片段 2：接入重置流程并记录采样

import numpy as np

class RandomResetEnv:
    """环境侧：把采样器接进 011 章的重置流程。"""
    def __init__(self, robot, world, task_object, seed=0):
        self.robot, self.world, self.task_object = robot, world, task_object
        self.sampler = ResetSampler(seed)          # 采样器：种子进入构造函数，方便复现
        self.reject_count = 0                      # 拒绝采样计数器：监控采样范围是否过激

    def reset_state(self):
        for attempt in range(20):                  # 拒绝采样：最多重试 20 次
            s = self.sampler.sample(self.DEFAULT_JOINTS, self.WORKSPACE_BOX)
            if self.is_valid(s):                   # 合法性检查：不碰撞、在可达域内
                break
            self.reject_count += 1
        else:
            s = self.default_state()               # 兜底：全部失败时回退到默认开局
        self.robot.set_joint_positions(np.clip(s["joints"], self.Q_LOW, self.Q_HIGH))
        self.robot.set_joint_velocities(np.zeros(self.robot.num_dofs))
        self.task_object.set_world_pose(position=s["object_pose"][:2] + (self.TABLE_Z,))
        self.world.step(render=False)              # 稳定期前先步进一帧，让写入生效
        for _ in range(15):                        # 随机化后的稳定期：比 011 章略长
            self.world.step(render=False)
        return self.build_observation()

解读：三个结构点。第一，拒绝采样用 for + break + else：else 只在未 break 时执行，恰好表达"全部失败就兜底"；重试上限防止病态输入下死循环。reject_count 快速增长说明范围与合法区冲突严重，是最早的告警信号。第二，关节采样同样 clip 到限位：采样的"截断"应该发生在写入之前，机制上是"分布本来就该定义在限位内"的体现。第三，稳定期从 15 步起步：随机化后物体与机器人姿态更五花八门，接触解算需要的收敛时间比固定开局更长，用尝试式数值换取初始状态的一致。

片段 3：采样分布的统计校验

import numpy as np

def validate_sampler(sampler, default_joints, box, n=2000):
    """抽 n 组样本，检查分布覆盖与合法性：随机化上线前的'质检'。"""
    xs, ys, yaws = [], [], []
    for _ in range(n):
        s = sampler.sample(default_joints, box)
        xs.append(s["object_pose"][0]); ys.append(s["object_pose"][1])
        yaws.append(s["object_pose"][2])
    xs, ys = np.array(xs), np.array(ys)

    print(f"x 范围: [{xs.min():.3f}, {xs.max():.3f}]  均值 {xs.mean():.3f}")  # 应为 [x_min, x_max]
    print(f"y 范围: [{ys.min():.3f}, {ys.max():.3f}]  均值 {ys.mean():.3f}")  # 均值应接近区间中点
    # 边缘覆盖率检查：每个边带 (各 10% 宽度) 的样本比例应在 10% 上下浮动
    edge_ratio = ((xs < box["x_min"] + 0.1*(box["x_max"]-box["x_min"]))).mean()
    print(f"x 左边缘 10% 带覆盖率: {edge_ratio:.3f}（均匀分布下应约 0.10）")

解读：随机化的错误常常是"静默的"：范围写错、轴搞反、分布退化成常量都不报错，只让效果莫名变差。这段质检用一个简单的事实来兜底：均匀分布的样本应该覆盖整个区间、均值接近中点、任何等宽的边带比例都约等于其宽度占比。edge_ratio 检查的是最容易被忽视的一类问题：如果采样代码里把某个边界写错（比如 x_min 与 x_max 交换导致 uniform 报错之前先退化），范围统计会立刻暴露。把这段校验作为"环境验收"的一部分跑一次，比训练 10 万步后才发现采样从没有出过某个区域要划算得多。

常见坑

  • 使用全局 np.random：采样序列被库代码干扰，无法复现某次崩溃时的开局。修复：独立 Generator + 显式种子，种子存进实验配置。
  • 随机化范围一开始就取满量程：开局大量难样本，早期训练成功率长期为零、价值学不出来。修复：从小范围起步（±几厘米、±0.1 rad），用课程式扩展。
  • 采样出重叠/越界状态：目标物嵌进桌面或机械臂，稳定期"炸开"。修复：拒绝采样 + 安全边距 + 监控失败率；稳定期适当加长。
  • 训练与评估分布不一致：训练随机、评估却用了别的范围（或忘了固定种子），指标不可比。修复：评估固定种子集 + 明确的评估协议写进代码。
  • 速度随机化过猛：开局速度几 rad/s，物理第一步就大幅运动。修复：速度随机化默认全零，需要时量级压到 0.05 rad/s 以内。

练习与思考

  1. 为你的任务写一张采样清单：每个量的分布类型与范围，并说明每个范围与"评估时会变化的自由度"的对应关系。★
    提示
    从"部署时目标物会出现在哪"出发反推范围；机器人自身扰动只用于防记忆，取值可以小。
  2. 用片段 3 校验你的采样器，把目标物 x 范围的 x_min 与 x_max 对调（并做防御），观察质检输出如何暴露问题。★★
    提示
    直接对调会让 uniform 报错；更隐蔽的写法是先把范围当作常量写死再改一处，范围统计会显示覆盖不对。
  3. 对照实验：随机化范围取"±0.02 m"与"±0.2 m"两档训练同一任务，比较评估得分与收敛步数，画出"范围-性能"的权衡曲线。★★
    提示
    小范围收敛快但评估到宽分布时掉分；大范围训练慢但评估稳健。用固定评估种子集保证两档可比。
  4. 实现拒绝采样并统计 1000 次重置的失败率；再故意把采样区移向机械臂，观察失败率与稳定期后的状态偏差如何变化。★★★
    提示
    失败率的量级变化（比如 0.5% → 30%）会直接告诉你采样区与可达域的关系是否合理。
  5. 实验设计：让"训练随机、评估固定"与"训练随机、评估也随机"两种协议评估同一模型，预测并解释两组数字的差异及其适用场景。★★
    提示
    固定评估可复现、可比版本；随机评估反映期望性能但有波动。正式报告建议两个都给。

小结

  • 随机化初始状态把 ρ0 从单点变成分布：策略性能按分布求平均，泛化压力随宽度上升，宽度是可调的课程旋钮。
  • 采样清单按任务自由度加权：机器人与关节取小扰动，目标物位姿是随机化的主战场，速度保持保守。
  • 可复现性靠独立种子的 Generator；评估用固定种子集，训练与评估的协议写进代码。
  • 非法开局用"避让设计 + 拒绝采样"处理；失败率是监控指标，稳定期可适当加长。
