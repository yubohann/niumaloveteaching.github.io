第 025 章：实现动作空间离散化

把连续的关节控制翻译成"分档按钮"：什么任务适合离散动作、分几档、档位怎么映射，以及维度爆炸这条红线在哪里。

  • 主题：动作空间设计 / 离散化
  • 相关组件：Isaac Sim、Stable-Baselines3（DQN）、Gymnasium
  • 预计学时：45 分钟
  • 前置章节：第 024 章

学习目标

  • 理解离散动作空间的形式定义与适用边界：哪些机器人任务该离散、哪些必须连续。
  • 掌握动作分档（action binning）的映射公式与档位设计：中点采样、边界差异与档数的取舍。
  • 会用 MultiDiscrete 表达"每个关节各自分档"的因子化动作空间，并说清它与联合离散（|A|=mn）的差别。
  • 能写出一个包装器，把连续关节环境改造为 DQN 可训的离散接口，并保证映射可逆、可解释。
  • 会估算维度爆炸的规模，判断"分档方案是否可行"。

背景与动机

前面章节你都默认动作是连续的：策略输出 7 个实数，直接映射成关节目标。但强化学习算法家族里有一半成员（DQN、Double DQN 及其各种变体）天生只会处理离散动作，它们为每个动作输出一个价值估计，取最大值。你不可能对连续区间取 max。

与其换算法，不如换动作空间。把"关节动到任意角度"改成"关节拾取 M 个档位之一"，DQN 就可用；而且离散动作还带来两个真金白银的好处：探索变得可控（ε-greedy 在有限选项上指数收敛可分析），动作执行变得稳定（不会有 0.0001 rad 级别的抖动，因为根本表达不出来）。很多经典任务，抓取的"开/合"、导航的方向选择、粗定位的"往八个方向挪"，天生就是离散的。本章的任务就是把这套翻译做成可复用的工程组件。

核心原理

1. 形式定义：从连续区间到有限集合

连续动作空间是 A = ℝn 的一个盒约束（每个关节各自量程）；离散化把它替换为有限集合：

Adiscrete = { a1, a2, …, aK }， K 为档数 协议上就是一个整数索引 i ∈ {0,1,…,K−1}，"第 i 档"到真实量的映射由你定义

最常用的映射是等宽分档 + 中点采样：

qi = qmin + (i + 0.5) / K × (qmax − qmin)， i = 0…K−1 取中点作代表值：它离本档两个边界都最远，量化误差上限为半档宽

为什么中点优于边界？量化的本质是"用离散代表值近似整个连续区间"，近似误差应与到代表值的距离成正比。把代表值放在中点，最大误差是半档宽 (qmax−qmin)/(2K)；放在边界则误差可接近一整档宽。K=5、量程 ±2.9 rad 的关节，档宽约 1.16 rad，中点采样把最坏量化误差压到 0.58 rad，这就是"分 5 档"的物理含意。

2. 维度爆炸：|A| = mn 的红线

如果对 n 个关节做联合离散（所有关节的组合是一个动作），动作数随自由度指数增长：

|A| = Kn， 7 关节 × 5 档 = 57 = 78125 个动作 DQN 的网络输出层要 78125 个 logits；每个动作的 Q 值都靠采样估计，数据被稀释到学不动

这就是离散化的红线：联合离散只适合 1–2 维动作（如 Cartpole 左/右、夹爪开/合）。对多关节机械臂，正确方案是因子化离散（factorized / MultiDiscrete）：每个关节各自独立分档，动作表示为一个 n 维整数向量 (i1,…,in)。经典 DQN 不直接支持这种结构，但工程上有两条路：查表式近似（对每个关节分别用独立价值头采样，如 multi-head DQN 变体），或者干脆换支持因子化动作的算法（如第 026 章的连续策略、或离散 PPO 配 MultiDiscrete）。本章先讲清映射与可行性分析，两条路线都会给出。

3. 绝对分档 vs 增量分档

离散化的对象有两种选择：

  • 绝对分档：档位值就是关节角目标，i 直接映射到 qi。优点：动作含义明确、可解释；缺点：策略在关节限位附近需要"记得"当前档位，信用分配距离变长。
  • 增量分档：档位表示"在当前目标上加多少"。典型三档方案：{−Δ, 0, +Δ}，Δ 取 0.05 rad。优点：增量接近零中心分布，探索效率高；轨迹由档位序列积分而成，类似速度控制；缺点：单步幅度固定，精调能力受 Δ 限制，且需要处理累计目标的限位截断。

经验判断：回合短、定位粗的任务用绝对分档（导航选方向、选抓取点）；伺服类精细操作优先增量分档（±Δ/0 的三档就是最经典的"离散速度控制"）。两者可以混合：机械臂用增量三档调位置，夹爪用绝对两档。

4. 探索与算法匹配

离散动作下 ε-greedy 是最常用的探索：以概率 ε 均匀随机挑一个动作，以 1−ε 挑 Q 值最大的。工程上 ε 从 1.0 线性衰减到 0.05，衰减长度取总训练步数的 10%–20%。为什么不是 100%？因为机器人任务里后期环境仍有随机化，保留 5% 的随机动作能让策略对扰动更鲁棒；而衰减太快（如 1% 长度）会让早期探索不足，Q 值在大范围状态上没数据支撑。另一个要点是动作重复（action repeat）：离散档位粒度粗，若每档只执行 1/60 s，策略要连续选很多步同一档才能产生可见位移，直接把同一个离散动作重复执行 k 个物理控制步（如 k=4，等效控制 15 Hz）通常学得更快，也让"档 = 一段动作"的语义更自然。

5. 完整算例：三档增量的速度与时间账

增量离散的核心参数是 Δ 与 action repeat，它们共同决定"离散控制能达到多快"。取 Δ=0.05 rad、repeat=4、物理步 1/60 s，动作速率是 15 Hz，等效关节角速度 = 0.05 × 15 = 0.75 rad/s。以常见协作臂关节速度上限约 2.6 rad/s 为参照，余量约 3.5 倍，安全。把参数拉到边界就能看到约束：

Δ（rad）repeat等效角速度（rad/s）相对 2.6 rad/s 判定
0.0240.30安全但偏慢
0.0540.75安全区（推荐起点）
0.0513.00超过速度上限，控制器持续饱和
0.2043.00同上；这正是"抽风"来源

覆盖能力也能一次算清：单动作步的末端位移 = Δ × 等效臂长 = 0.05 × 0.5 = 0.025 m；1.67 s 的回合里有 100/4 = 25 个动作步，总覆盖 25 × 0.025 = 0.625 m，刚好覆盖 0.6 m 量级的任务范围。若把 repeat 加到 8，等效速度减半到 0.375 rad/s，回合覆盖收缩到约 0.31 m，任务做不完；若把 Δ 降到 0.02 又保持 repeat=4，覆盖只有 0.25 m。Δ、repeat 与回合长度构成一个三角形约束：三者必须同时满足"速度不超限"与"覆盖够用"，改任何一个都要重算另外两个。可复用的判据有两条：Δ/(repeat/60) ≤ 速度上限；Δ×臂长×回合步数/repeat ≥ 任务最大距离。

6. 表示与样本效率：两种离散的规模对比

先澄清一个常见误解：MultiDiscrete 与联合离散描述的是同一个动作集合，7 关节 × 3 档在两种表示下都是 37 = 2187 种组合，组合数本身不会因为换表示而缩小。真正的差别在网络接口与学习信号密度：

维度联合离散MultiDiscrete 因子化
网络输出2187 个 logits，一次对全部组合取 max7×3 + 2 = 23 个 logits，按维独立决策
样本需求让每个组合获得 100 次访问需约 21.9 万条 transition让每维每档获得 100 次访问只需约 300 条
函数逼近假设每个组合的 Q 互相独立各维近似条件独立（协调性被牺牲）
最大偏差对 2187 个含噪估计取 max，系统性高估约 3.5σ每维 3 个估计取 max，高估约 0.85σ

最后一行的数字来自一个可复算的小实验：对 K 个独立标准正态的含噪 Q 值取最大值，期望随 K 增长，K=5 时约 1.16σ，K=9 时约 1.49σ，K=100 时约 2.51σ，K=2187 时约 3.46σ（增长规律近似 σ√(2 ln K)）。这就是"D3QN 输出层越大、高估越重"的量化表达，Double DQN 用另一套参数挑动作来缓解它。结论：因子化的收益在参数规模与样本分摊上是线性的，在协调性上是损失；需要多关节协同动作（如双手协作）时，考虑自回归式策略或直接回到连续动作空间。

7. 边界与失效模式

  • 量化精度的硬边界：5 档绝对分档在 ±2.9 rad 量程下档宽 1.16 rad，最坏误差 0.58 rad（约 33°），远不足以做插孔这类任务。边界结论：绝对分档只做粗定位，精调阶段交给连续控制器或更小量程的分档（粗/细分离，见 035/041 章）。
  • repeat 是隐藏的延迟源：repeat=4 意味着命令最多滞后 3 个物理步（50 ms）才被新的离散决策更新。按 021 章的相位预算，50 ms 延迟在 2 Hz 闭环任务上损失约 36° 相位余量，接触类任务会明显变钝。重复次数每翻倍，延迟同步翻倍，别把它当免费参数。
  • 限位处的积分器饱和：目标被 clamp 在限位、策略仍连续输出 +Δ 时，控制实质失效；等到需要回退时，策略必须学会连续选 −Δ，而这期间的观测（关节不动）与信用分配距离很长。缓解手段：把"距限位距离"放进观测、对持续饱和加小惩罚、在日志里监控饱和步数占比。
  • 档位边界与观测分辨率的错位：若任务成功判据（如 5 cm）小于单动作步位移（0.025 m 的两倍量级），策略可能无法在同档位下停在判据内，会出现"总是在成功边界来回跳"的训练噪声。判据：成功半径 ≥ 2 × 单动作步位移，否则增大档数或缩短 repeat。

实现思路与设计

实现闭环是"定义档位 → 建立双向映射 → 包装动作空间 → 选算法与探索策略 → 验证映射无损"。每一步的设计取舍如下：

  1. 定维度：先问"哪些自由度真的需要连续"。机械臂 7 个关节 + 夹爪：夹爪天然二值（开/合），取 2 档；7 个关节若用增量方案，每关节 3 档（±Δ/0）。动作向量的维度是 8，但每维只有 2–3 个取值，Actions 的组合数虽为用户可控，MultiDiscrete 表示下每维独立采样。
  2. 定档位表：等宽中点公式生成；夹爪这类二值量直接手写。档位表固化成张量，映射时用索引查表；现场乘除在 GPU 上更费且会累积误差。
  3. 双向映射：index_to_action 与 action_to_index（最近档）。回放时要能解释"策略在第 30 步选了什么物理量"，评估日志也用得到。
  4. 包装环境：观测不变、动作接口从 Box 换成 MultiDiscrete；每步把离散索引先转成关节目标，再交给你第 004 章写的位置控制逻辑。
  5. 选算法：单离散维度（Cartpole、夹爪）用 DQN 全家桶；多维因子化用"离散化 + PPO"或进化为第 026 章的连续策略。DQN 需要回放缓冲区，4096 环境并行时先取子集或改用每环境小缓冲。
设计点取值例理由
关节档数 K3（增量）/ 5–9（绝对）增量 3 档覆盖"加/减/停"，档数再多语义重复；绝对档数 ≥5 才有定位价值
增量步长 Δ0.05 rad关节行程的 1%–2%；Δ 太大来回振荡，太小到不了目标
夹爪档数2开/合二值；中间态没有语义
action repeat4 个物理步等效 15 Hz 动作频率：档位粒度与执行时长匹配
ε 衰减1.0 → 0.05，总步数 15%保证早期覆盖、后期保底鲁棒
设计思维：离散化的收益必须大于量化损失

离散化丢掉的是"精细连续调节"能力，换取的是"算法可选项 + 探索可控性"。判断准则：任务的成功判据对动作分辨率有多敏感？导航方向、抓取开合对分辨率不敏感，放心离散；插轴入孔对亚毫米分辨率敏感，离散 3 档可以（它只做"粗接近"），但要配精调阶段。这个"粗/细分离"的思想会在第 035 章（规划 + RL）和第 041 章（插拔）里再次出现。

关键代码与解读

片段 1：增量档位表与双向映射

import torch

def make_delta_bins(delta: float, device: str = "cuda"):
    """增量三档：{-Δ, 0, +Δ}。索引 0/1/2 直接查表，避免现场浮点乘除累积误差。"""
    table = torch.tensor([-delta, 0.0, delta], device=device)   # 形状 (3,)
    return table

def index_to_delta(idx: torch.Tensor, table: torch.Tensor):
    """(N, n_joints) 的整数索引 → (N, n_joints) 的实际增量张量"""
    return table[idx.long()]              # 高级索引：GPU 上并行完成 N×7 次查表

def delta_to_index(delta_val: torch.Tensor, table: torch.Tensor):
    """反向映射：找最近档。仅用于回放/日志解析，训练路径用不到"""
    dist = (delta_val.unsqueeze(-1) - table).abs()   # (N, n_joints, 3) 到三个档位的距离
    return dist.argmin(dim=-1)                        # 最近邻：把连续量归档位便于解释

# 用法：机械臂 7 关节增量离散 + 夹爪 2 档绝对
ARM_JOINTS, GRIPPER_BINS = 7, 2
action_bins = make_delta_bins(delta=0.05)             # 每关节三档：覆盖加减停
# 动作向量语义：[a0..a6] 各三档（0/1/2），[a7] 二档（0=合 1=开）

解读：这段代码的三个工程决策值得展开。为什么用查表、不用公式计算？GPU 上 table[idx] 是纯内存访问，没有浮点除法；更重要的是映射完全无歧义，评估时想精确回答"策略这一步选了哪个物理增量"，查表直接给出；而公式计算在边界取整上容易出歧义。为什么要写反向映射？它不是训练必需，但它是可解释性工具：分析坏回合时，把日志里的物理量换算回档位序列，能一眼看出"它在目标附近一直选 −Δ 档，说明过冲了"。为什么夹爪单独用绝对分档？开/合是状态型动作，不存在"增量"语义，学会了这个区分，你设计任何混合动作空间都不会别扭。

片段 2：把连续环境包装成 MultiDiscrete 接口

import gymnasium as gym
from gymnasium import spaces

class DiscretizedJointEnv(gym.ActionWrapper):
    """不碰观测与物理，只替换动作接口：Box(7) → MultiDiscrete([3]*7 + [2])"""
    def __init__(self, env, delta=0.05):
        super().__init__(env)
        self.num_arm = 7                      # 与底层机器人的手臂自由度一致
        self.table = make_delta_bins(delta)   # 增量档位表，只建一次
        self.action_space = spaces.MultiDiscrete([3] * self.num_arm + [2])
        # 每维独立取值数：[3,3,3,3,3,3,3,2]，因子化动作空间的标准表达
        self.q_target = None                  # 累计关节目标：增量语义的"积分器"

    def reset(self, **kwargs):
        obs, info = self.env.reset(**kwargs)
        self.q_target = self._current_joint_positions().clone()   # 回合起点对齐当前位姿
        return obs, info

    def action(self, act):                    # ActionWrapper 协议：返回底层可执行动作
        arm_idx = torch.as_tensor(act[: self.num_arm], device=self.device)
        delta = self.table[arm_idx]           # 查表得到 7 个增量
        self.q_target = self.q_target + delta # 积分：增量动作 → 目标轨迹
        low, high = self.joint_limits          # 限位截断：缺了它，目标会漂出可行范围
        self.q_target = torch.clamp(self.q_target, low, high)

        gripper = float(act[self.num_arm])    # 0=合 1=开，直接二值
        return torch.cat([self.q_target, torch.tensor([gripper], device=self.device)])

解读：这个包装器演示了"增量离散化"的完整链路。核心是那个积分器 q_target：离散策略给的是"加/减/停"，把它累加成目标轨迹，再由底层位置控制器去跟踪，这正是教科书里"速度型离散控制"的现代版实现。限位截断这行不能省：策略还没学会"到头了别再推"时，累计目标会一路漂出量程，位置控制器会把关节顶在硬限位上抖动，观测量纲全部失真。截断提供了一个"软墙"，把扰动限制在可控范围。回合重置要对齐当前位姿：如果 reset 时把 q_target 清零，第一动作就会让关节从随机初始位姿猛跳到零位附近，这是"训练刚开始机器人抽风"的最常见原因。

片段 3：训练入口与探索安排

from stable_baselines3 import DQN
from torch import nn

model = DQN(
    "MlpPolicy", env,
    learning_rate=1e-4,        # DQN 对 lr 敏感：比 PPO 惯用的 3e-4 再低一档更稳
    buffer_size=200_000,       # 7 维动作的组合远少于联合离散，回放缓冲压力可控
    learning_starts=5_000,     # 先灌满 5000 条随机数据再开网络，避免早期过拟合
    batch_size=256,
    gamma=0.99,                # 60 Hz 控制下有效视野约 1.7 s
    train_freq=4,              # 每 4 个环境步更新一次网络：让数据积累与梯度更新匹配
    target_update_interval=1_000,  # 目标网络更新频率：太频繁退化成在线 Q 学习
    exploration_fraction=0.15,     # ε 衰减占总训练步数的 15%
    exploration_final_eps=0.05,    # 保底 5% 随机：对随机化环境的鲁棒性来源
    policy_kwargs=dict(net_arch=[256, 256, 128], activation_fn=nn.ELU),
    device="cuda",             # 网络在 GPU；底层环境若是 Isaac 张量，注意两端设备一致
)
model.learn(total_timesteps=2_000_000, log_interval=10)
# 注意：DQN 是 off-policy 单环境语义，改 4096 并行需要自己改写采样，
# 常见折中是 64-256 个子环境各采一步凑 batch（K 个环境 = K 条并行经验）

解读：DQN 超参里有两个"为什么"必须理解。learning_starts=5000：随机初始化网络的 Q 值近乎噪声，早期用它做 TD 自举会自我强化错误；先用随机策略灌够数据，等于给网络一个"地面真值"再起飞。target_update_interval：DQN 的经典不稳定源是"用自己估计的目标更新自己"，目标网络把它变成慢速移动的靶子，1000 步是 60 Hz 控制下的常用量级。最后那段注释是本章最重要的工程提醒：SB3 的 DQN 假设单环境、同步回放，而你要吃第 022 章的并行红利，就要在"并行环境数"与"回放缓冲压力"之间做折中，64 环境并行、每步各出一帧凑成 64 条 transition 是工业界常见做法，介于纯单环境与全量 4096 之间。

常见坑

  • 对 7 关节做联合离散：|A| = 37 = 2187（还只是三档），DQN 输出层巨大、每个动作的样本量被稀释成 1/2187。症状：Q 值发散或策略永远只挑几个动作。修复：改用 MultiDiscrete 因子化，或换连续策略。
  • 增量积分器不截断：目标值漂出关节限位，物理上表现为顶死、抖动、接触力异常。症状：训练几百步后所有环境同步抽风。修复：每次积分后 clamp 到限位，reset 时重置积分器。
  • 档位映射用边界值：代表值取在档位边界，量化误差上限翻倍；若边界与控制输入的"死区"重合，还会出现"小动作无效"的伪梯度。修复：中点采样公式，并用查表实现。
  • 忘记动作重复：每物理步都让策略重新选档，档位粒度（0.05 rad）相对物理步（1/60 s）过粗，等效角速度高达 3 rad/s，机器人全程"抽搐"。修复：action repeat=4，或把 Δ 降到 0.01。
  • ε 衰减太快：exploration_fraction 设 0.01，早期只探索了 1% 的轨迹分布，Q 网络对大片状态没有数据。症状：回报曲线快速上升后卡死。修复：衰减长度 ≥ 总步数 15%，并保留 0.05 的末端探索率。
  • 把 MultiDiscrete 当成"更小的动作集合"：两种表示的组合数完全相同（3⁷ 仍是 2187），缩小的是网络输出与每维样本需求。症状：以为换表示就消除了组合爆炸，协调类任务上仍学不动。修复：理解"参数化变线性、条件独立变假设"，需要协同动作时改用自回归策略或连续空间。
  • Δ 与 repeat 各自为政：单独调其中一个而不同步重算另一个，等效角速度与回合覆盖会悄悄越界。症状：要么控制器饱和抽搐，要么回合结束时离目标还差一大截。修复：按 5 节的两条判据每次重算。

练习与思考

  1. 给一个 1 关节旋转任务（如倒立摆的力矩控制）设计两种离散方案：5 档力矩、3 档增量。各训练到收敛，比较所需步数与最终控制平滑度。★
    提示
    平滑度用相邻控制步动作差的均方值量化。5 档绝对方案的抖动通常更小，但探索更慢，想想为什么。
  2. 把 delta 从 0.05 调到 0.2 再训练，观察关节目标的过冲现象。解释 Δ 与控制器带宽、动作频率的关系。★★
    提示
    Δ 决定了"每步最大指令速度"（Δ / 控制周期）。它若超过关节速度限位对应的可达速度，位置控制器就会持续饱和，表现为过冲与振荡。
  3. 计算题：6 关节机械臂、每关节 5 档。联合离散的动作数是多少？若用 MultiDiscrete，一个动作向量有几种可能的组合？两者相差几个数量级？★
    提示
    5⁶ = 15625 vs 组合数同样是 15625，但 MultiDiscrete 的差别在于：网络按维独立输出分布，每维只有 5 个 logits，参数与样本开销随维度线性增长。
  4. 实验设计题：在 Reach 任务上，把"手腕 3 个关节保持连续、手臂 4 个关节离散化"的混合方案实现出来（提示：用 Dict 动作空间或两层包装），预测它与全离散、全连续方案的性能排序并验证。★★★
    提示
    混合动作空间要注意接口解析顺序；性能排序的直觉是：全连续 > 混合 > 全离散（定位精度维度），但训练稳定性排序可能相反。
  5. 思考题：为什么离散化会"提升探索可控性"？从样本效率角度解释 ε-greedy 在有限动作集与连续高斯策略下的差别。★★★
    提示
    连续高斯策略的探索方差本身也是被学习的参数，早期方差过大等于在无限大的空间里乱撞；有限集合上的均匀探索是"无死角但有界的"。
  6. 用 5 节的两条判据做参数设计：给一个最大距离 0.5 m 的 Reach 任务、关节速度上限 2.6 rad/s、等效臂长 0.45 m、回合 90 步（1.5 s），找出满足约束的 (Δ, repeat) 至少两组，并说出各自的行为风格差异。★★★
    提示
    覆盖判据要求 Δ×0.45×(90/repeat) ≥ 0.5，速度判据要求 Δ/(repeat/60) ≤ 2.6；先取 repeat=4 解出 Δ 区间，再换 repeat=8 看区间如何移动。

小结

  • 离散化用有限档位集合替换连续区间：中点采样 + 索引查表是最稳妥的工程实现，量化误差上限为半档宽。
  • 联合离散有指数红线：|A|=Kn 只适合 1–2 维；多关节一律用 MultiDiscrete 因子化表达。
  • 增量分档（±Δ/0）适合伺服类任务，绝对分档适合方向/开合类任务；两者可以混合。
  • DQN 三件套：learning_starts 预热、目标网络、ε 衰减 15% 到 0.05；并行采样时注意 off-policy 缓冲的规模折中。
  • 下一章回到另一极：连续动作空间，高斯策略、tanh 压缩、动作缩放与平滑滤波，看看连续控制的完整工具箱。
