第 041 章：实现插拔任务

毫米级的接触之舞：对孔、下压、搜索、插入，力觉观测、防卡死奖励与柔顺策略，任务篇的集大成之作。

  • 主题：任务实现 / 精密装配
  • 相关组件：Isaac Sim（接触力 + 关节控制）、Stable-Baselines3
  • 预计学时：60 分钟
  • 前置章节：第 040 章

学习目标

  • 掌握插拔任务的完整规格与四阶段结构：接近对孔、压面接触、搜索入孔、插入到底。
  • 理解"插入深度"作为核心进度信号的作用，以及为什么它必须配"力约束"一起使用。
  • 会设计防卡死（jam）判据与搜索鼓励：接触力超限且无进度 = 卡住；策略要学会"退一点、换个角度再试"。
  • 会把第 029 章的力观测、第 030 章的接触状态、第 032 章的课程与第 033 章的示教全部接入一个任务。
  • 能按"间隙等级"设计插拔评估矩阵，把成功率、力峰值、卡死率、耗时拆开报告。

背景与动机

插拔（peg-in-hole）是机器人操作里的"珠穆朗玛脚下的大本营"：它是装配一切的前置技能，也是接触动力学最密集的任务。难在两处：几何上，插头与孔的间隙可能只有 0.5–2 mm，远小于视觉与控制误差之和；力学上，一旦姿势略有偏差，下压会把接触力迅速推至上限、插头卡在孔沿上，硬碰硬只会越卡越死。人类操作这类任务的秘诀是"柔顺"：手腕放松、力反馈引导、轻微晃动找孔，这正是 RL 可以学、而传统位置控制学不会的东西。

本章也是本课程"任务篇"的收官：第 029 章的力观测是它的眼睛（触觉），第 030 章的接触状态机是它的判据，第 032 章的课程是它的台阶，第 033/034 章的示教是它的加速器。做完这个任务，你已经拥有了仿真装配任务的全部零件；第 042 章的装配任务将在它之上叠加多物体与顺序约束。

核心原理

1. 接触几何：为什么 1 mm 误差会变成 50 N 的力

插头与孔的间隙 c=1 mm 时，允许的最大姿态偏差近似为 c/(2L)（L 为插入深度，接触两点决定角度）。L=2 cm 时姿态容差约 1.4°，超过它，插头下压时先接触孔沿，求解器为了"纠正穿透"施加的接触力随穿透深度线性上升：

F ≈ kc · δ， kc 为接触刚度（典型 10⁴–10⁵ N/m） 1 mm 的姿态误差在 1/60 s 的控制步里可积累 1.7 cm/s 的下压速度 → 单步穿透 0.28 mm → F ≈ 3–30 N；继续下压则线性放大

这个关系解释了插拔任务的两条铁律：(1) 下压必须慢且柔，任何硬性位置指令在下压方向上的误差都会被刚度放大成暴力；(2) 力信号是最早的预警，力在 1 ms 内变化，而位置误差要等到几何穿透才可见。策略要学会的行为是"力的反馈环"：力上升 → 停止下压 → 微调姿态/横向搜索 → 力回落 → 继续下压。这种"以力定进退"的策略正是人类装插头时的动作，也是 RL 在本任务里最值得学的部分。

2. 四阶段结构与它们的信号

阶段几何状态主导信号判据
接近对孔插头在孔上方 3–10 cm，自由空间xy 对齐差分xy 误差 > 5 mm
压面接触插头贴住表面（z 到位），xy 仍可能偏接触标志 + xy 差分（系数减小）接触 && 深度 = 0
搜索入孔孔沿接触，小幅横向搜索搜索奖励（接触 + 位移）+ 深度出现0 < 深度 < 30% 孔深
插入到底对中后压入深度差分（每步）深度 ≥ 30% 孔深

阶段不是硬编码的开关（策略看到的只有状态与奖励），但奖励的每一项都对应一个阶段的可测量事件："深度首次大于 0"是最关键的事件，它意味着"插头咬进孔里"了。对这个事件给一次性奖励（+3）比深度差分更重要：它把整个任务从"99% 的失败姿势"里挑出成功轨迹的起点，是信用分配的分水岭。搜索阶段的奖励设计有个微妙之处：接触但未深入时，奖励要"鼓励继续接触+尝试移动"（接触保持 + 位移探索）；若惩罚接触，策略学会"悬停在孔上方不敢碰"，而不敢碰是插不进去的。

3. 防卡死：卡与不卡的一线之间

卡死（jam）的物理定义：接触力高于阈值且插入深度停止增长超过若干步。两个条件缺一不可，只测力大，会把"正常对中压入"误判（插入到底时接触力也大）；只测无进度，会把"还没对准的搜索期"误判。判据：

jam = ( Ffilt > Fjam = 15 N ) ∧ ( 深度变化 < 0.1 mm/步 ) 持续 20 步 Ffilt 用滤波力（第 029 章）：卡死是持续状态不是冲击事件；20 步 ≈ 0.33 s 的观察窗

对卡死时段施加惩罚（如 −0.1/步，不终止，给策略留出"退出来重试"的机会）。为什么用惩罚，终止有什么代价？卡死是可恢复状态（人拔一下重插就行），终止会砍掉"从卡死中恢复"的宝贵样本，而 RL 恰恰要从这些样本里学会"退一点、换个角度再试"的恢复行为。终止只留给真正的硬失败（力超过硬上限 50 N，代表机械损伤风险）。"软失败给惩罚、硬失败给终止"的分级，是接触类任务里安全与学习容错的平衡术。

4. 间隙与课程：容差是插拔任务的头号难度轴

插拔任务的所有难度都浓缩在一个参数上：间隙 c。任务允许的姿态容差近似与 c 成正比：以插入深度 2 cm 计，c=1 mm 时姿态容差约 1.4°，c=5 mm 时放宽到约 7°，c=0.5 mm 时只剩约 0.7°。课程设计：

c: 5 mm → 2 mm → 1 mm →（可选）0.5 mm；每个间隙等级的 xy 初始误差从 ±2 cm 收敛到 ±3 mm。

间隙从大变小有两个好处：(1) 早期正样本密度高，大间隙下"随便晃晃"就能进去，策略先学会"插"的基本动作；（2）策略能迁移，从"宽间隙下的成功插入"里学到的接触反馈逻辑（力上升→减速→搜索）在小间隙下依然有效，只是需要更精细的执行。这与第 032 章"目标距离课程"同构，只是难度轴换成了间隙。注意把间隙也放进域随机化（每个环境一个间隙值）：单一间隙训练的策略会对间隙过拟合，大间隙下动作太慢、小间隙下动作太糙。

实现思路与设计

任务规格：桌面上固定一个带方孔的基座（孔深 2 cm、间隙可配）；Franka 握住插头（细柱体），从孔上方随机位置出发，完成对孔与插入，使插入深度 ≥ 80% 孔深且横向力不超过安全阈值。

规格设计理由
观测（30 维）本体(14) + 插头—孔相对位姿(6) + 插入深度(1) + 滤波力/力矩(6，第 029 章管线) + 接触标志(1) + 力历史(2 帧)力是接触阶段的"眼睛"；深度是进度刻度；力历史看出"正在恶化还是在缓解"
动作（7 维）关节增量 ×0.02 rad（比抓取任务更细）+ 夹爪保持握紧精密任务探索半径减半：0.05 rad 的步长会直接撞孔沿
奖励xy 对齐差分 1.0（仅未接触时）→ 接触后降为 0.3；深度差分 3.0/米；首次入孔 +3；卡死 −0.1/步；硬力终止 −5；成功 +20四阶段信号；深度是最核心的进度量
成功判据深度 ≥ 80% 孔深 且 Flat < 10 N，持续 10 步深度达标 + 力安全双条件；持续 10 步防"冲过去"的假成功
终止成功｜硬力 > 50 N（−5）｜超时 200 步硬力是真危险；卡死不终止只惩罚（可恢复）
随机化间隙 2–5 mm、孔位置 ±3 cm、插头质量与摩擦、表面接触刚度 ±20%、力噪声（029 章模型）间隙是头号难度轴；接触刚度模拟实物差异
课程间隙 5 → 2 mm；初始 xy 误差 ±2 cm → ±3 mm；插头初始高度 3 cm 起先宽后窄（原理 4）

四条权重推理：(1) 深度差分 3.0/米：全程插入 1.6 cm（80%×2 cm）累计 0.048，听起来小，但它是"每步都在增长"的连续信号；配合首次入孔 +3 的事件锚，深度段的总收益被抬到 3 以上。（2）首次入孔事件 +3 高于抓握事件 +0.5 的量级：因为"深度从 0 到正"是比抓握更稀有的事件（抓握是"以正确姿势碰对了位置"，入孔是"在接触约束下找到孔"），更稀有的事件需要更大的奖励保证信用传播。（3）xy 差分在接触后从 1.0 降到 0.3：接触后横向移动的代价里多了摩擦与卡孔风险，权重降档防止策略"用横向硬拖找孔"。（4）成功 +20 比前面所有任务都高：插拔是最难的任务，成功后能"全身而退"（不带隐患）的轨迹稀少，用大奖励补偿稀疏性；同时硬力 −5 的威慑量级也最高，安全与成功大致 1:4。

设计思维：让"恢复行为"有数据，卡死不终止

高级任务与初级任务的差距全在"出了错怎么办"：插入碰到孔沿卡住后，退出来重试的策略不是天生的，它必须从"卡死—退出—再进"的样本里学。若卡死即终止，这类样本的占比会被压到极低，策略只会学到"卡住=回合结束"，而学不到"卡住=调整信号"。工程做法：卡死时给持续惩罚 + 保持回合运行，并在观测里给出"卡死计时"特征（连续多少步无进度）；策略会逐渐学会"计时变大时切换动作模式"。这个"把失败过程编码成可学习的阶段信号"的思路，是第 038 章阶段标志与本章四阶段结构的思想终点。

关键代码与解读

片段 1：插拔观测，相对位姿、深度与力的组合

def insertion_observation(peg_pose, hole_pose, force_filt, contact,
                          force_hist, jam_timer):
    """30 维观测：几何(7) + 深度(1) + 力(6) + 历史(2) + 状态(3) + 本体"""
    rel_pos = hole_pose["pos"] - peg_pose["pos"]          # (N,3)：孔相对插头
    rel_quat = quat_multiply(hole_pose["quat"], quat_inverse(peg_pose["quat"]))
    rel_rot = quat_to_rotvec(rel_quat)                    # 姿态差转旋转向量(3)
    depth = (peg_pose["pos"][:, 2] - hole_pose["pos"][:, 2]).clamp(min=0.0)
    # 深度 = 插头尖端低于孔口面的量：钳位到 0，悬空阶段不产生虚假负值
    obs = torch.cat([
        rel_pos, rel_rot,                                 # 几何：孔在哪、朝哪
        depth.unsqueeze(-1) * 50.0,                       # 深度(m)放大到可见量级
        force_filt / 20.0,                                # 滤波力归一：量程 20 N
        (force_filt - force_hist[:, 0]) / 20.0,           # 力的变化趋势：看出"恶化/缓解"
        contact.float().unsqueeze(-1),                    # 接触标志（去抖后）
        jam_timer.unsqueeze(-1) / 20.0,                   # 卡死计时：连续无进度步数
        peg_pose["vel"],                                  # 插头速度：下压速度很重要
    ], dim=-1)
    return obs                                            # 交给策略网络（MLP）

解读：观测组装里三处"信息设计"值得展开。(1) 力给"当前 + 变化趋势"两组：单帧力只能说明"现在压着多大力"，而力的变化方向决定正确反应，力在上升说明还在恶化（应停止下压），力在下降说明调整有效。第 029 章的力历史在这里落地为差分特征。(2) jam_timer 作为显式特征：计数器本身没有物理单位，但"卡了 20 步"比"卡了 2 步"需要完全不同的行为（微调 vs 强行对抗）。把计时归一化后放进观测，就是第 038 章"阶段标志进观测"的连续版。(3) 深度放大 50 倍：孔深 2 cm 的深度值在 0–0.02 范围，直接归一化后会淹没在参数精度里；放大到 O(1) 让这个"任务最重要的标量"在网络输入里占据应有的尺度，标量观测的缩放系数不是形式主义，它决定这一维能否在梯度里"说话"。

片段 2：四阶段奖励与卡死检测

class InsertionReward:
    """四阶段奖励：对齐 → 触面 → 搜索 → 插入；卡死惩罚 + 硬力终止"""
    def __init__(self, num_envs, F_jam=15.0, F_hard=50.0, stall_steps=20, device="cuda"):
        self.F_jam, self.F_hard = F_jam, F_hard       # 卡死阈值 / 硬力上限
        self.stall_steps = stall_steps                # 无进度的观察窗：20 步 ≈ 0.33 s
        self.depth_prev = torch.zeros(num_envs, device=device)
        self.stall = torch.zeros(num_envs, dtype=torch.long, device=device)
        self.entered = torch.zeros(num_envs, dtype=torch.bool, device=device)  # 入孔事件锁存

    def update(self, depth, xy_err_prev, xy_err, force_filt, contact):
        r_align = (1.0 - 0.7 * contact.float()) * (xy_err_prev - xy_err)
        # 接触后 xy 权重降到 0.3：防"横向硬拖找孔"（权重取舍 4-3）
        r_depth = 3.0 * (depth - self.depth_prev).clamp(min=0.0)   # 只奖插入方向
        newly = (depth > 0.001) & (~self.entered)                 # 深度首次越过 1 mm
        r_enter = 3.0 * newly.float()
        self.entered = self.entered | (depth > 0.001)
        # 卡死：力大 且 深度停滞，持续 20 步；两条同时成立才是"卡"
        stalled_now = (force_filt.norm(dim=-1) > self.F_jam) & \
                      ((depth - self.depth_prev).abs() < 1e-4)
        self.stall = torch.where(stalled_now, self.stall + 1,
                                 torch.zeros_like(self.stall))
        jammed = self.stall >= self.stall_steps
        r_jam = -0.1 * jammed.float()                  # 软失败：惩罚不终止，留恢复样本
        over_hard = force_filt.norm(dim=-1) > self.F_hard
        self.depth_prev = depth.detach().clone()       # 状态快照：detach 防计算图泄漏
        return r_align + r_depth + r_enter + r_jam, jammed, over_hard

解读：这段集中了本章全部核心设计。(1) 对齐权重随接触降档：1.0 − 0.7·contact 一行实现"自由空间重对齐、接触后重深度"的注意力切换，与第 037 章"抓握后接近项退场"是同一个手法的连续版。(2) 深度差分的 clamp(min=0)：同第 040 章角度差分，只奖励深入、不惩罚拔出（拔出可能是必要的搜索动作），真正的失败由成功判据的"未达标"自然承担。(3) 卡死判据的双条件与持续窗：力大但仍在深入 = 正常压入（接触力本来就大）；无进度但不费力 = 悬空或没接触，都不是卡死。20 步的窗口防单帧误判。(4) detach 的纪律：depth_prev 是状态快照，忘了 detach 会让训练图在时间维度上无限增长，这个坑在第 037 章提醒过一次，本章再犯就是真踩坑了。(5) 返回值三件套（奖励/软失败/硬失败）让调用方分别处理：软失败只影响奖励，硬失败进终止，日志分开统计卡死率与硬力率。

片段 3：柔顺下压与课程，把"慢"写进动作语义

class CompliantInsertion:
    """下压方向的柔顺控制：位置指令 + 速度上限 + 力触发的回退"""
    def __init__(self, max_down_speed=0.01, force_backoff=12.0):
        self.max_down_speed = max_down_speed    # 下压速度上限 1 cm/s：硬位置指令的刹车
        self.force_backoff = force_backoff      # 力超过 12 N 时自动回退（安全层）

    def apply(self, policy_delta, force_filt):
        delta = policy_delta.clone()
        # 1) 下压速度限制：z 方向的指令按最大速度裁剪（其余方向不限制）
        if delta[:, 2].mean() < -self.max_down_speed:
            delta[:, 2] = -self.max_down_speed
        # 2) 力触发的回退：检查后不管策略怎么想，抬升指令直接注入
        too_much = force_filt.norm(dim=-1) > self.force_backoff
        delta[too_much, 2] = torch.abs(delta[too_much, 2]) + 0.002
        # 抬升 2 mm 的"逃生脉冲"：给接触一个脱离窗口，防穿孔与卡死升级
        return delta
    # 这个安全层对训练与部署都生效：策略在"力过大"时收到的反馈是"动作被改写"，
    # 但奖励与观测如实记录；它会学到"主动减速比被动回退更划算"（时间罚更少）

解读：这个柔顺层是"安全约束"与"策略学习"的接口，三个设计原则。(1) 速度裁剪只作用于下压方向：横向与旋转的精细动作不受影响，安全约束的作用域要最小化，否则会把正常操作也刹死。(2) 力触发回退是"硬接管"：无论策略输出什么，力超过 12 N 就注入抬升脉冲（还在硬力 50 N 之下留出 38 N 的缓冲带）。这种约束在控制理论里叫"人工势场式的安全层"，在 RL 里它保证策略永远有时间调整。(3) 为什么还让策略学"主动减速"？因为被动回退会触发时间罚（来回抬升浪费时间），两种行为的收益差在回报里清晰可见，安全层的职责是"兜住最坏情况"，给学习留出空间。工程提醒：这个安全层必须在训练、评估、部署三处都启用，参数写进同一份配置，训练时有、评估时无的行为差异，是评估成绩"好看但真机崩"的经典来源。

片段 4：课程与评估矩阵，间隙是头号难度轴

# 课程配置（第 032 章状态机）：间隙与初始误差两个轴交替收紧
curriculum = dict(
    promote=0.7, demote=0.25, beta=0.01, cooldown=3000,
    clearance_mm=[5.0, 2.0, 1.0],          # 三个等级：清楚感受每个档的精度跃迁
    init_xy_err=[0.02, 0.008, 0.003],      # 初始对孔误差：与间隙等级同步收紧
    # 逐环境采样：4096 个环境分布在相邻等级上，"熟练工带新手"的梯度混合
)

# 评估矩阵：间隙 × 初始误差，各 3 档 = 9 组，每组 100 episode
# 报告四列指标：成功率 / 力峰值中位数 / 卡死率 / 平均插入耗时
def evaluate(model, env, clearances=(0.001, 0.002, 0.005),
             errs=(0.003, 0.008, 0.02), episodes=100):
    rows = []
    for c in clearances:
        for e in errs:
            env.set_eval(clearance=c, init_xy_err=e)   # 评估固定条件（第 023 章纪律）
            sr, fmax, jam, t_insert = run_episodes(model, env, episodes, deterministic=True)
            rows.append((c, e, sr, fmax, jam, t_insert))
    return rows
# 合格线：目标间隙档（1 mm）成功率 ≥ 80%，力峰值 < 25 N，卡死率 < 10%

解读：这份配置与评估把本章收束到工程闭环。(1) 两个课程轴为什么同步收紧？间隙与初始误差的作用是"相乘"的：1 mm 间隙配 2 cm 初始误差的难度大于 5 mm 间隙配 2 cm，同步收紧让每个等级的难度跃迁保持"可学习"（成功率从 0.7 掉到 0.3–0.5 区间再爬升），而分步收紧会让某一轴单独变得过陡。(2) cooldown 3000 步比前几章更长：插拔的插入动作学习慢，策略适应新间隙需要更多数据，冷却期参数要随任务的时间尺度成比例放大。(3) 评估用 deterministic=True + 每条件 100 回合：精密任务的成功率有采样噪声（±5%），100 回合是最低可信量；重测时用固定种子。"合格线"三列（成功率/力峰值/卡死率）体现了插拔的双重标准：不仅要能插进去，还要"干净地"插进去，力峰值与卡死率是过程质量，成功率是结果。三者一起达标，这个策略才配得上第 047 章力控任务的进阶与第 065 章 sim-to-real 的检验。

常见坑

  • 下压用硬位置指令：位置误差在 z 方向被接触刚度放大成 30 N 冲击。症状：训练初期频繁硬力终止。修复：柔顺层（速度裁剪 1 cm/s + 12 N 力触发回退），动作增量缩到 0.02 rad。
  • 卡死就终止：丢失"卡住—退出—重试"的恢复样本，策略永远学不会搜索。症状：卡死率与超时率双高。修复：卡死给持续惩罚不终止；只对硬力终止。
  • 卡死判据只看力：正常对中压入时力本来就大，误判成卡死持续罚分，策略被吓得不敢下压。症状：插到一半停住。修复：力大 + 深度停滞双条件 + 20 步窗口。
  • 深度不留余量：成功深度设成 100% 孔深，策略顶着孔底无法完成（物理上插不到底）。症状：成功率卡在低位。修复：80% 孔深，预留接触与公差余量。
  • 只在大间隙上训练：策略对间隙过拟合，目标间隙（1 mm）成功率崩盘。症状：评估矩阵里大间隙全绿、小间隙全红。修复：间隙进域随机化（逐环境采样 2–5 mm）+ 课程收紧。

练习与思考

  1. 计算题：间隙 1 mm、插入深度 2 cm。允许的最大姿态偏差约多少度？下压速度 1 cm/s 时，每控制步（1/60 s）的最大穿透增量是多少？★
    提示
    姿态容差 ≈ c/(2L) = 0.001/0.04 rad ≈ 1.4°；每步穿透 ≈ 0.17 mm，接触刚度 10⁴ N/m 时对应约 1.7 N 的单步力增量，可控。
  2. 消融实验：把卡死判定从"双条件"改成"只看力 > 15 N"，观察策略行为（下压频率、成功率、卡死率）的退化。★★
    提示
    策略会学得"不敢压"：正常接触即被罚，最优策略变成悬停，成功率崩盘、超时率飙升。
  3. 设计实验：对比"无安全层（直接执行策略动作）"与"柔顺层启用"两组训练，记录硬力终止事件数与训练稳定性。安全层是否拖慢了学习？★★
    提示
    无安全层组早期存活率低、有效样本少；安全层组学习更稳但策略略"依赖"回退，看最终成功率与力峰值。
  4. 进阶题：用第 033 章的框架，让脚本策略（IK 对中 + 正弦搜索）生成 200 条示教，做 BC 预热 + RL 微调，统计达到 80% 成功率所需步数与纯 RL 的差距。★★★
    提示
    示教的价值集中在"搜索入孔"阶段；把示教数据按阶段切片统计覆盖，能解释加速主要来自哪里。
  5. 思考题：为什么插拔任务的"成功"要同时绑定深度与力（Flat < 10 N），而堆叠任务的成功只看位置与稳定？从"任务质量的定义"角度给出你的分析。★★★
    提示
    堆叠的失败模式是"掉下来"（几何不稳定），插拔的失败模式是"插进去但伤了自己/工件"（力超标、卡伤孔壁），成功定义必须覆盖各自最贵的失败模式。

小结

  • 插拔是接触密集任务之最：1 mm 间隙对应约 1.4° 姿态容差，位置误差被接触刚度放大成暴力，柔顺下压是唯一正解。
  • 四阶段结构：对齐（差分）→ 触面（接触标志 + 降档对齐）→ 搜索（入孔事件 +3）→ 插入（深度差分 3.0/米）；深度放 50 倍进观测，力给"当前 + 趋势"两组。
  • 卡死 = 力 > 15 N 且深度停滞 20 步；软失败给惩罚保样本，硬力 50 N 才终止；恢复行为的学习靠"卡死不结束"。
  • 柔顺层三件套：下压速度 ≤ 1 cm/s、12 N 力触发 2 mm 回退脉冲、训练/评估/部署三处同参启用。
  • 课程双轴（间隙 5→1 mm、初始误差 2 cm→3 mm）同步收紧；评估矩阵按间隙×误差 9 组报告成功率/力峰值/卡死率/耗时。本任务零件齐备后，第 042 章将在它之上叠加装配的多物体顺序约束。
