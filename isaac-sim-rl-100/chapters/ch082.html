第 082 章：实现时间最优控制

让机械臂以最短时间完成点到点运动：从 bang-bang 原理与相平面切换曲线出发，把"省时间"翻译成可训练的奖励，并解释为什么最优解总把力打在饱和边界上。

  • 主题：控制与优化 / 时间最优轨迹
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：50 分钟
  • 前置章节：第 081 章

学习目标

  • 理解时间最优控制的数学本质：为什么力矩永远打在饱和边界上，即 bang-bang（开关）原理。
  • 掌握双积分系统在相平面（phase plane）中的轨迹形状，会推导切换曲线与临界距离。
  • 会把"最短时间"写成奖励：每步时间惩罚 + 到达判据 + 终端奖励，并解释为什么不直接用误差范数。
  • 会为时间最优任务设计饱和动作与归一化观测，让策略自发学会"先加速、后刹车"。
  • 能诊断末端抖振（chattering）、过冲与到点时间统计异常等常见问题。

背景与动机

工业现场按节拍算钱：搬运机器人每次循环节省 50 ms，一天 3 万次循环就是 25 分钟。把"完成动作"提升为"最快完成动作"，是高速产线的核心诉求，这就是时间最优控制要解决的问题。

上一章的能量优化关心"用最小的力做完"，本章关心"用最短的时间做完"，两者是一对相互拉扯的目标。传统时间最优解依赖精确模型与离线规划；存在摩擦、柔性、带宽限制时，模型与实际必然偏离。RL 的价值在于直接在含约束的真实动力学上用试错逼近时间最优。本章也为第 083 章平滑控制埋下伏笔：bang-bang 的力跳变会激励结构振动，届时你会明白"最快"为什么常需被"最平滑"约束。

核心原理

1. 最小时间问题

先看最干净的形式：质量为 m 的滑块在一维轨道上运动，控制量推力 u 幅值受限，这就是双积分系统（double integrator）：

q̇ = v，  v̇ = u / m，  |u| ≤ umax 位置 q、速度 v 是两个状态；加速度只能取有限范围内的值

时间最优问题：寻找控制律，使从 (q0, v0) 到目标 (qf, 0) 的时间 T 最小：

minu(·) T = ∫0T dt  s.t. q(0)=q0, q(T)=qf, v(T)=0, |u| ≤ umax

注意目标里没有误差平方、没有力的平方，只有时间，这与常规最优控制的直觉相反。

2. bang-bang 原理：为什么力矩永远打满

庞特里亚金最小值原理（Pontryagin's Minimum Principle）给出答案。构造哈密顿函数（λ 为协态变量）：

H = 1 + λ1 · v + λ2 · (u / m) 积分项 1 对应"每一步都计时间成本"

关键：H 对 u 是线性的（只出现一次 u，没有 u²）。线性函数在闭区间上的最小值必在端点，于是最优控制只能是：

u*(t) = −umax · sign(λ2(t)) 要么全力加速、要么全力减速，中间值永远不会最优

这就是 bang-bang 原理。反过来，若目标是力的平方（能量最优，第 081 章），H 中出现 u²，最优解变为连续反馈 u = −K·v，两章结果的本质差别就在于此。

3. 相平面与切换曲线

把状态画在 (q, v) 平面（相平面）。设最大加速度 a = umax/m，利用 v·dv = a·dq 积分得加速段与减速段的抛物线：

加速：v² = v0² + 2a(q − q0)  |  减速：v² = 2a(qf − q)

把"刚好能以最大减速度停在目标点"的状态连起来，得到切换曲线（switching curve）：v = −√(2a·(qf − q))。最优策略因此极简洁：状态在曲线上方就全力减速，在下方就全力加速，全程最多切换一次。

4. 临界距离与采样量化

使速度剖面恰好"加速到顶再刹车"的距离称临界距离 dcrit = v0²/(2a)。以关节角速度 1 rad/s、最大角加速度 20 rad/s² 计，dcrit 仅 0.025 rad（约 1.4°），除起停外的大部分行程都处于"打满加速→打满减速"状态，饱和是常态，附着中间的力矩值极少出现。

以上是连续时间结论。60 Hz 采样下切换时刻被量化到最近的采样点（误差 ≤16.7 ms），结果是几毫米量级的过冲与末段小幅往返：RL 学出的时间最优策略末段抖振是离散控制下的物理必然。

5. 与能量最优的对偶关系

真实控制器常在"时间—能量"的帕累托前沿（Pareto front）上选点，例如奖励写成 −∫(1 + β·u²) dt，β 越大越省电、越慢。

6. 一个完整数值算例：1.0 rad 转动的全流程

取单关节 amax = 20 rad/s²、目标 1.0 rad、静止起步。解析最速时间与峰值速度：

T* = 2√(d/a) = 2√(1.0/20) ≈ 0.447 s，峰值速度 vpeak = a·T*/2 ≈ 4.47 rad/s 60 Hz 采样下 T* 约 27 步；切换时刻落在第 13–14 步之间

7. 采样延迟导致的过冲量化

切换时刻被量化到最近的采样点后，最坏情况下延迟一个控制周期 Δt。过冲包括延迟期间继续前进的位移与残余加速度项：

过冲 ≈ vswitch · Δt + ½·a·Δt² v_switch = 0.5 rad/s、Δt = 16.7 ms 时过冲约 8.4 mrad（约 0.5°）；速度翻倍则主项翻倍

减速段接近目标时，力矩反解误差还会叠加到过冲上。这就是"末段抖振属于离散控制物理必然"的来源：过冲与切换时的速度成正比，也与采样周期近似成正比。把控制频率从 60 Hz 提到 120 Hz，延迟项减半；或让末段在更低速度下切换，过冲同步减小。

8. 折扣因子与时间成本视野

时间税金与 γ 的配合决定"拖时间有没有代价"。第 N 步时间成本的折扣权重为 γN：

工作点通常在 0.995–0.999：回合长度 30–80 步（0.5–1.3 s）时要让整段"时间税"被有效计入，γ = 0.99 已覆盖视野 100 步，若回合更长（多关节协同、含等待）则应提高。γ 过大（0.999 以上）会让值函数尺度变大、学习变慢，先用 0.995 跑基线，再按"到点时间是否贴住下界"决定是否上调。

9. 多关节协同的评估口径

把单关节结论搬到 7 自由度时，时间不再由单个关节决定：路径上每个位形都有一组关节力矩约束，轨迹的速度上限由力矩余量最少的关节决定。协同时间最优的基本事实：总时间的下界是各关节单独最速时间的最大值，实际时间介于"最大值"与"各时间之和"之间，取决于是否把慢关节安排在力矩余量充裕的轨迹分段上。RL 不需要显式求解这条分配，但评估时要知道：用 max(Ti*) 作下界、用 sum(Ti*) 作悲观参照，收敛结果落在两者之间就是正常表现。

实现思路与设计

总思路：先用解析解建立基线，再让 RL 在同样系统上逼近它，最后迁移到完整机械臂。

  1. 先解析后学习：写一个 20 行的 bang-bang 控制器作为标准答案，先验证环境动力学与时间尺度，没有基线的 RL 实验无法判断好坏。
  2. 从单关节起步：单 DoF 关节力矩模式对应双积分模型，状态只有 (q, q̇)，先把奖励与终止逻辑调对，再上升到 6–7 自由度协作臂。
  3. 动作做成饱和形式：策略输出经 tanh 后乘以力矩上限（如 30 N·m），"打满"对应输出 ±1，网络不必学幅值先验，也天然满足 |τ| ≤ τmax。
  4. 奖励 = 时间成本 + 到达奖励：每步 r = −0.01，按住到达判据给 +1 并终止。绝不用 −‖q−qf‖ 作主项，否则诱导策略"慢慢靠近不敢冲"。
  5. 到达判据宽严得当：位置误差 < 5 mm 且末端速度 < 0.05 m/s。太松会"擦边冲过去"，太紧则离散抖振使其永远达不到。
  6. 随机化目标与初速：目标角均匀采样、初速 ±0.5 rad/s，逼策略学反馈律，背固定轨迹行不通；再按距离做课程学习（先 0.3 rad 短程，后 1.5 rad 以上）。
  7. 评估用相对下界的时间比：到点步数 ÷ 解析下界 T* = 2√(d/a)，统计 P50/P90，优秀策略应在 1.1–1.2 倍以内。
设计思维：为什么时间税用"每步 −1"量级？

两者在回报总量上等价，但 −1 与折扣因子配合更好：γ=0.99 时时间成本有效权重为 1/(1−γ)=100，值函数保持在个位数到两位数，训练更稳。真正要小心的是 γ 本身：时间最优任务建议 γ=0.995–0.999，否则远期时间成本被折扣吃掉，策略会觉得"拖时间无所谓"。

关键代码与解读

片段 1：解析 bang-bang 控制器（基线与直觉验证）

import math

def bang_bang(q, v, q_goal, a_max, v_eps=1e-3):
    """双积分系统的时间最优控制：返回 +a_max / -a_max / 0。
    a_max 是最大加速度 = tau_max / inertia（单位 rad/s^2）。"""
    d = q_goal - q                       # 到目标还有多远（带符号）
    if abs(d) < v_eps and abs(v) < v_eps:
        return 0.0                       # 已到目标附近且几乎静止：不再施加力矩
    dir_ = 1.0 if d >= 0 else -1.0       # 朝目标的方向
    dist = abs(d)                        # 剩余距离（恒为正）
    speed = v * dir_                     # 朝目标方向的速度：负表示正在远离
    brake_dist = speed * speed / (2.0 * a_max)   # 以当前速度刹车所需距离
    # 切换判据：速度朝目标且刹车距离已超过剩余距离 → 必须立刻全力减速
    if speed > 0 and brake_dist >= dist:
        return -dir_ * a_max
    return dir_ * a_max                  # 否则全力加速（含静止起步的方向判断）

解读：这就是切换曲线的在线版本。教科书用 v = −√(2a·剩余距离) 判定，这里改用"刹车距离 vs 剩余距离"比较，数值上更稳（v 很小时不会出现 0/0 形式的放大误差）。speed > 0 把两侧方向折叠处理：向目标运动为正、远离为负。这不是最精简的写法，但"为什么这样切"一目了然。它是检验环境正确性的黄金基线：如果仿真里它停不到目标附近，问题一定在力矩映射或摩擦参数上，与学习算法无关。

片段 2：把"最短时间"写成奖励与终止逻辑

import torch  # 向量化环境：所有计算在 GPU 上整批进行

class TimeOptimalReachEnv:
    """时间最优到点任务：奖励 = 每步时间成本 + 到达奖励。
    以 Isaac Lab 风格说明，自研 World 循环可套用同样逻辑。"""

    def __init__(self, num_envs, dt=1.0 / 60.0, tau_max=30.0):
        self.dt = dt                    # 控制周期 1/60 s：时间成本按步计就与它绑定
        self.tau_max = tau_max          # 关节力矩上限：真实物理约束，必须显式建模
        self.pos_tol = 0.005            # 到达判据：位置误差 5 mm
        self.vel_tol = 0.05             # 且速度 0.05 m/s 以下，避免"高速掠过"
        self.time_scale = 0.01          # 每步 -0.01；与到达 +1 的比例决定"多快算快"

    def _get_rewards(self, joint_pos, joint_vel, target):
        err = torch.linalg.norm(target - joint_pos, dim=-1)   # 位置误差
        speed = torch.linalg.norm(joint_vel, dim=-1)          # 速度幅值
        # 联合判据：位置与速度同时满足，避免"擦边冲过去也算成功"
        reached = (err < self.pos_tol) & (speed < self.vel_tol)
        # 时间成本占主导：只有到达才给终端奖励，杜绝"慢慢蹭到"的模仿空间
        reward = -self.time_scale * torch.ones_like(err)
        reward = torch.where(reached, torch.full_like(err, 1.0), reward)
        return reward, reached

    def _reset_targets(self):
        # 目标角在 ±1.5 rad 均匀采样；随机初速 ±0.5 rad/s 逼策略学反馈律
        self.target = (torch.rand(self.num_envs) * 2 - 1) * 1.5
        self.joint_vel[:, 0] = (torch.rand(self.num_envs) * 2 - 1) * 0.5

解读：（1）-time_scale 是每步都交的时间税，让策略在"多走一步"与"更早到达"之间真实权衡；（2）到达奖励 +1 一次性发放，与时间税共同隐含"最少步数到达"，不依赖手工距离梯度；（3）联合判据是关键，只判位置会催生"高速掠过再折返"，真实产线上这是事故；（4）随机初速是泛化关键：永远静止出发的策略可能背下固定时序而不学切换曲线。参数依据：5 mm 来自常见定位精度；0.05 m/s 使判据时间 0.1 s 远大于 16.7 ms 采样周期，保证判据不会被跳过。

片段 3：记录到点时间，与解析下界对比

obs, _ = env.reset()
for it in range(2000):                # 2000 次迭代 × 并行环境，量级参考
    action = policy(obs)              # 网络输出经 tanh，范围 (-1, 1)
    tau = action * env.tau_max        # 饱和动作：网络不必学幅值上限
    obs, reward, done, info = env.step(tau)
    # 用 info["reached"] 统计到点步数；done 可能因超时触发，必须区分
    t_used = info["elapsed_steps"][info["reached"]]
    if t_used.numel() > 0:
        # 解析下界 T* = 2*sqrt(d/a)：静止起步、先加速后对称减速的理论最短
        d = info["initial_dist"][info["reached"]]
        t_star = 2.0 * torch.sqrt(d / env.a_max)
        ratio = t_used * env.dt / t_star
        p90 = torch.quantile(ratio, 0.9)
        print(f"iter {it}  相对下界均值 {ratio.mean():.2f}  P90 {p90:.2f}")
    obs = env.reset_done(obs, done, info["timeout"])   # 超时与成功分别重置

解读：看点在评价体系。时间最优的"好坏"不能看累计回报（不同初始距离尺度不同），必须换算成"到点步数 ÷ 解析下界"再看分布。T* = 2√(d/a) 忽略切换与采样损失，故 RL 达到 1.1–1.2 倍即优秀。done 与 reached 必须分开：超时回合若计入统计，会掩盖"摆烂等超时"的病态行为；超时给 −1、成功给 +1 形成清晰正负对照，是这类任务的标准做法。

常见坑

  • 用距离塑形当主奖励：−‖误差‖ 会让策略"贴着目标慢慢挪"。症状是成功率高但到点时间远逊基线。修复：时间税占主导，距离项系数压到 0.001–0.01 或去掉。
  • γ 太小：γ=0.95 时 50 步后的时间成本权重只剩 8%，策略觉得拖时间无代价。修复：γ ≥ 0.995。
  • 到达判据过松或过严：只判位置 → 高速掠过也算成功；要求误差 < 0.1 mm → 60 Hz 下永远达不到，训练信号消失。修复：位置 + 速度联合判据，并核对"判据 ÷ 速度 > 采样周期"。
  • 力矩上限与实物不符：仿真给 30 N·m、电机连续只有 10 N·m，学到的饱和策略真机跑不动。修复：取连续力矩（非峰值），域随机化再抖动 10%–20%。
  • 把末段抖振当训练失败：离散切换延迟导致的几毫米过冲是物理必然。修复：降低到达速度阈值、提高控制频率，或末段交给小阻尼控制器接管。

练习与思考

  1. 用初始速度 −0.5、0、+0.5 rad/s 测试片段 1 的控制器，验证"最多切换一次"，并记录切换时刻。★
    提示
    观察 sign(u) 的变化次数；把 (q, v) 轨迹画在相平面上，你会看到它先沿抛物线族逼近切换曲线，再沿曲线滑向原点。
  2. 把时间税系数从 0.01 改成 0.001 与 0.1 各训一次，预测并验证到点时间与到达精度的变化。★★
    提示
    系数越大越激进（快但粗糙），越小越保守。用 P50/P90 到点步数与成功率两个维度做表对比。
  3. 把到达速度阈值从 0.05 m/s 放宽到 0.5 m/s，观察成功率与"到点后仍在运动的平均速度"，解释"高速掠过算成功"的机制。★
    提示
    放宽阈值相当于允许"擦着目标飞过"，统计上命中判据但实际没有停下，真实产线要避免的行为。
  4. 设计时间—能量折中奖励 −(1 + β·τ²)，在 β=0、0.1、1 三档训练，把各档的（到点时间，平均力矩平方）画在平面上，观察帕累托前沿。★★★
    提示
    β=0 是本章的时间最优（全程饱和）；β 增大策略变平滑、时间变长。把第 081 章能量目标放在同一张图上可直观看前沿形状。
  5. 把控制周期从 60 Hz 降到 20 Hz（力矩上限不变），预测末段过冲幅度的变化并验证。★★
    提示
    切换量化误差从 ±16.7 ms 变为 ±50 ms，过冲随延迟平方量级增长；用峰值位置误差对比两组数据。

小结

  • 时间最优的目标是 min T；哈密顿函数对控制线性，最优解必然是 bang-bang（全力加速或减速）。
  • 双积分相平面轨迹为抛物线族，最优切换发生在切换曲线 v = −√(2a·剩余距离) 上，全程最多一次。
  • RL 表述：每步时间税（−0.01 量级）+ 到达终端奖励（+1）；到达判据必须"位置 + 速度"联合，不要用距离范数当主奖励。
  • 离散采样的切换延迟带来几毫米过冲，是物理必然；用更高控制频率或末段接管缓解。
  • 时间最优与能量最优是一对目标。下一章在此基础上加入平滑约束，把"最快"变成"又快又不激励振动"，见第 083 章。
