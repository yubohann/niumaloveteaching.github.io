第 050 章：实现人机交互

当环境中多了一个"不听话"的智能体，人：本章搭建人在环的仿真环境（人类运动回放 + 意图特征），用速度-间距监控实现硬安全约束，并设计让机器人"有礼貌"的奖励。

  • 主题：任务实现 / 人在环协作与安全
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：55 分钟
  • 前置章节：第 049 章

学习目标

  • 理解"人作为环境一部分"带来的三重挑战：行为不可控、状态不可全测、安全不可妥协。
  • 会搭建第一近似人类模型：运动回放 + 简单反应式策略，并说清各自的适用边界。
  • 掌握速度-间距监控（SSM）的思想：把"最大允许速度"写成与安全距离相关的函数。
  • 会给安全约束做"动作屏蔽"（shield）：为什么硬约束比奖励罚项更可靠。
  • 会从人的位置/速度序列中提取意图特征（运动方向、目标接近度），并解释它为什么让机器人"提前让路"。
  • 能用最小间距、干预次数、交接时间、舒适度代理指标评估人机交互质量。

背景与动机

049 章里两个智能体是"队友"，它们共享同一套算法、同一份奖励，也同样的理性。本章的另一方是人：行为不可控（可能突然转身）、状态不可全测（意图藏在脑子里）、安全不可妥协（碰撞的代价是事故，不能按负奖励处理）。工厂里机器人和工人在同一空间作业（协作机器人）、仓库里 AMR 与拣货员共享通道、医院里配送机器人穿过人群，这些场景要求机器人既能干活，又知道"什么时候该让"。

本章的目标是工程上可行的三步：把人放进仿真（回放/脚本模型）、用硬约束保证安全底线、用观测量做粗略的意图预测。安全这部分你会接触到速度-间距监控与动作屏蔽，它们是第 069 章（安全强化学习）在交互场景中的前置知识；舒适与礼貌的量化则是第 074 章（偏好学习）的伏笔。

核心原理

1. 人在环的三个建模选项

人类模型做法优点局限
轨迹回放播放预录/脚本化轨迹（mocap 数据）真实、可复现、零成本不响应机器人，无法测"相互适应"
反应式模型人按规则响应（如避让、让出通道）能测双向交互规则写死，行为单一
学习/数据驱动模型从人类数据学人类策略行为多样工程量大、分布外不可靠

工程上的标准路径是"回放打底 + 少量反应式变体 + 域随机化"：用回放保证行为真实，用 10–20 条反应规则（比如"人朝机器人方向走来时在 1.2 m 处减速"）制造多样性，再随机化人的速度、路径与时延，让策略见多识广。特例是"训练时人的策略固定、评估时换一批人"，这就是 051 章要讲的非平稳环境问题的具体形态，本章先从回放版入手。

2. 安全：速度-间距监控与硬约束

协作机器人安全的经典框架是速度-间距监控（speed and separation monitoring, SSM，概念与 ISO/TS 15066 一致）：机器人必须始终与人保持"能够在人进入危险区之前停下来"的距离。保护距离由人的接近速度与双方的反应时间决定：

dprotect = vhuman·(Tr + Ts) + dstop + msafety 典型：v 人 1.2 m/s、（反应+停止）0.5 s、停止距离 0.3 m、余量 0.2 m 得 1.1 m

把它变成机器人侧的执行约束：机器人的最大允许速度随距离单调上升，直到额定值：

vmax(d) = clip( k·(d − dstop), 0, vnom ) d 为与人的最短距离；d < dstop 时速度上限为 0（急停区）

关键是这个约束不以奖励的形式实现。奖励罚项只改变"期望行为"：训练收敛后的策略在绝大多数状态下远离人，但永远存在小概率的探索与分布外状态，那里碰撞就会发生。工业安全要求的是"任何时刻都不越界"，所以正确做法是动作屏蔽（shield）：策略输出动作后，先按当前 d 投影到允许的速度集合，再执行。策略照样学习（它通过屏蔽试出新边界），但物理上不可能执行危险动作。这就是"奖励软约束 + 执行硬约束"的分工。

2.1 数值算例：保护距离、限速曲线与制动余量

把 SSM 公式代入具体数字：人类接近速度 1.2 m/s、反应与停止时间合计 0.5 s、停止距离 0.3 m、安全余量 0.2 m 时，保护距离 dprotect = 1.2×0.5 + 0.3 + 0.2 = 1.1 m。设计里分段限速取 k = 0.3：距离 1.0 m 时速度上限 0.195 m/s，0.8 m 时 0.135 m/s，0.5 m 时 0.045 m/s，0.35 m 以内为 0。把 0.3 m/s 代回制动核算：0.5 m/s² 减速度下纯制动距离 0.3²/(2×0.5) = 0.09 m，加上 0.1 s 反应期走过的 0.03 m，总需求 0.12 m，相比 dstop = 0.35 m 仍有 0.23 m 余量；这条"限速曲线乘制动能力"的核算就是安全评审需要出示的材料，它把"保守"从感觉变成算术。

意图特征的触发点也可以算。人距机器人 3 m、接近速度 1.3 m/s（人 1.0 m/s、机器人 0.3 m/s 相向）时，TTC = 3/1.3 ≈ 2.3 s；按"TTC 低于 2 s 开始让路"的约定，减速触发点位于 2×1.3 = 2.6 m，比按 dslow = 2.0 m 触发的纯距离限速早 0.6 m。这正是把 TTC 放进观测的收益：它用相对速度做出提前量，人走得越快，机器人越早开始反应；观测里若没有人体速度，策略只能用距离，同样的人流密度下急停次数上升。延迟的账也顺手核一下：真机感知到决策链路延迟 50–150 ms，人走 1.2 m/s 时对应 6–18 cm 的"位置盲区"，比 0.35 m 的急停线小一个量级，属于可以被安全余量覆盖的范围，但训练时不随机化延迟，策略就会把这份余量当作不存在。

侵入罚的量级再核一遍：权重 4.0、平方形式下，距离 0.5 m 时单步罚 4×0.09 = 0.36，0.4 m 时 0.64，0.3 m 时 1.0。与任务进度项（势函数，典型单步 0.1–0.2 量级）对比：进入 0.4 m 以内后，"远离人"的梯度压过"往前走"的收益，策略的优先级自动切换；这也是侵入罚不需要设得更大的原因，屏蔽已经兜住物理底线，奖励只在舒适半径内做引导。jerk 罚同理：上限 1.5 m/s³ 时，0.1 s 决策周期内加速度变化 0.15 m/s² 以内不罚；一次"从 0.5 m/s 急停到 0"的鲁莽动作（加速度阶跃约 5 m/s²、jerk 约 50 m/s³）被罚 0.01×48.5 ≈ 0.49，与任务进度的单步量级相当，鲁莽急停的直觉代价与一步正常前进的收益可比，策略有动力选择平滑减速。

评估口径再补一条：最小间距的 P5 分位与均值要同时报告。均值会被多数空旷时段拉高，P5 才反映"最接近人"的那几次交互；把 P5 与急停次数并排看，可以区分"一贯保守"与"偶尔冒险"两类策略：前者 P5 大、急停多，后者 P5 小、急停少。安全验收的常见做法是给 P5 设下限（如大于 0.5 m）、给急停次数设上限（如每局不超过 3 次），两个约束同时满足才算通过，这比"平均距离"一个数字更能约束住尾部风险。

3. 意图特征：把"碰撞后响应"升级为"预判"

只把人当动态障碍物，机器人会等人到了跟前才让，行为上表现为频繁急停，效率低，人也不舒服。改进方法是把人的"运动趋势"做成特征：

意图特征 = [ vhuman（世界系速度）, 到机器人工作区的接近率 −di/dt, 最小预计相遇时间 TTC ]

最小预计相遇时间（time to collision, TTC）是最有用的一项：把人与机器人的相对位置与相对速度投影到"相对距离为零"的最小时间，TTC 小说明即将相遇，机器人应提前减速或绕行。加进观测后，策略学会"TTC 低于 2 s 就开始让路"；等到 0.5 m 才急停的滞后反应会被淘汰。注意我们在仿真里提取这些特征很轻松，但真机上需要可靠的人体跟踪（视觉/激光），训练时必须把特征的噪声尺度（±3 cm、±0.1 m/s）随机化进观测，否则策略依赖"完美追踪"会过度自信。

4. 奖励：任务、安全、舒适三层

奖励分三层：任务奖励（完成搬运/交接）、安全项（对侵入距离的连续罚，作为屏蔽之外的"软化梯度"）、舒适项（降低人的不适感）：

  • 侵入罚：d < 0.8 m 时按 (0.8 − d)2 罚，量级适中，它是给策略"远离人"的密集梯度，安全底线仍由屏蔽确保。
  • 速度平滑：jerk 罚 + 减速提前量。人坐在机器人旁边时，退让急停比缓慢停下吓人得多；平滑性本身就是舒适的一部分。
  • 可预测性：动作方向变化率过大时罚。人喜欢"能看懂下一秒去哪"的机器人。

实现思路与设计

一个"走廊避让 + 货架交接"场景的完整搭建：

  1. 场景：AMR（移动机器人）+ 一名虚拟人（胶囊体，高 1.7 m）。人按脚本轨迹在走廊往返，脚本从 20 条预录轨迹里随机选；轨迹在人造的中转货架处停留 1.5 s 取放货物。
  2. 控制：AMR 策略 10 Hz（0.5 m/s 额定速度，共享空间降为 0.3 m/s）；物理 60 Hz。
  3. 观测（约 40 维）：激光扫描（36）、自身速度、目标点（本体系）、人的相对位置与速度（4）、TTC（1）、屏蔽修正量（2，见片段 2）、上一步动作。
  4. 安全屏蔽：按"与人最短距离 + 人接近速度"计算 v_max，对策略输出的速度指令做投影；投影量也记录进观测（告诉策略"你被限制了多少"）。
  5. 奖励：任务进度（势函数）+ 到达奖励 + 侵入罚 + jerk 罚 + 交接奖励（在货架区人与机器人同时停留时给）。
  6. 终止：与人的距离小于 0.35 m（视为碰撞事件，重罚并终止）；超时 40 s。
  7. 评估：最小间距的分布（P5 分位）、急停次数（速度跳变事件）、任务完成时间、交接成功时的间距。人机交互的"好"是一组分布，无法用单一数字概括。

设计思维：为什么"屏蔽"不会让策略学坏？

常见担心是"动作被屏蔽后策略学到的是被扭曲的行为"。实际上策略通过屏蔽的边界持续获得反馈：当它想快但被限制时，"屏蔽修正量"进了观测，任务奖励照常按真实结果计算，它学到的是"在允许速度内做事最优"。这类似经典控制里的饱和限幅：执行器限幅决定了控制器必须工作的工作域，控制器并不会因此失能。经验上再加一条保险：评估时用"距离分布 + 任务时间"的组合与屏蔽前的基线对比，避免只看"平均性能"。

关键代码与解读

片段 1：人类运动回放与意图特征提取

class HumanPlayer:
    # 第一近似：从预录轨迹库中采样回放。轨迹为 (t, pos, vel) 采样序列
    def __init__(self, motion_library, noise_pos=0.03, noise_vel=0.1):
        self.library = motion_library          # 20 条走廊轨迹（含停留段）
        self.noise = (noise_pos, noise_vel)    # 模拟真机视觉跟踪的噪声尺度

    def reset(self, rng):
        self.traj = self.library[rng.randint(len(self.library))]
        self.t0 = rng.uniform(0.0, 0.3)        # 相位随机：人可以从轨迹任意点进入
        self.t = 0.0

    def update(self, dt, rng):
        self.t += self.t0 + dt
        pos, vel = self.traj.sample(self.t)    # 插值出当前位置/速度
        # 训练时给追踪噪声：真机的人体跟踪不可能完美，策略必须适应不精确输入
        pos = pos + rng.normal(0.0, self.noise[0], size=pos.shape)
        vel = vel + rng.normal(0.0, self.noise[1], size=vel.shape)
        return pos, vel

def intent_features(human_pos, human_vel, robot_pos, robot_vel):
    # 相对量都在世界系里算，最终由调用方旋到机器人本体系再进观测
    rel_p = human_pos[:2] - robot_pos[:2]      # 人相对机器人的位置
    rel_v = human_vel[:2] - robot_vel[:2]      # 相对速度
    d = float(np.linalg.norm(rel_p))
    # 接近率：距离的负导数。为负表示"正在靠近"，正表示远离
    closing = -float(np.dot(rel_p, rel_v)) / max(d, 1e-6)
    # 最小预计相遇时间 TTC：把相对运动投影到相遇时刻，近似为 d / 接近率
    ttc = d / max(closing, 1e-3) if closing > 0.05 else 9.9   # 没在靠近时给"安全大值"
    return np.array([d, closing, min(ttc, 9.9)], dtype=np.float32)

解读：这段代码的两个部分各负责一件事。HumanPlayer 的关键设计是"噪声注入"：仿真里人可以拿到毫米级的真值位置，但真机部署时人体位姿来自视觉/激光追踪，误差 2–5 cm、速度噪声 0.1 m/s，而且偶尔丢帧。训练时就把这份噪声加进去，策略才会学"对输入保持适度怀疑"，这是第 065 章 sim-to-real 迁移在人机交互上的具体体现。intent_features 的 TTC 计算里，条件 closing > 0.05 是必要的保护：人静止或远离时接近率接近零，直接做除法会产生巨大的 TTC 值（甚至除零），把观测数值撑爆；这里统一给 9.9 s 的"安全值"，让策略在"不会相遇"的情况下看到稳定的数字。TTC 上限截断（min(..., 9.9)）也是同理，异常值一旦进入神经网络，归一化层会被拉偏。

片段 2：速度-间距监控与动作屏蔽（shield）

class SafetyShield:
    # 把人机最短距离映射成速度上限，再对策略输出做投影：硬约束，不靠奖励
    def __init__(self, v_nom=0.5, d_stop=0.35, d_slow=2.0, k=0.3):
        self.v_nom, self.d_stop, self.d_slow, self.k = v_nom, d_stop, d_slow, k

    def allowed_speed(self, d_human):
        # 分段线性：2 m 以外全速；0.35 m 以内为 0；中间线性过渡
        # k = 0.3 (1/s)：距离 1 m 时上限约 0.2 m/s，对应约 5 s 的制动余量
        if d_human <= self.d_stop:
            return 0.0
        if d_human >= self.d_slow:
            return self.v_nom
        return self.k * (d_human - self.d_stop)

    def project(self, v_cmd, omega_cmd, d_human):
        v_max = self.allowed_speed(d_human)
        v_allow = float(np.clip(np.linalg.norm(v_cmd), 0.0, v_max))
        if np.linalg.norm(v_cmd) > 1e-6:
            v_allow_vec = v_cmd / np.linalg.norm(v_cmd) * v_allow
        else:
            v_allow_vec = v_cmd
        # 角速度同样限幅：原地高速旋转在人旁边同样危险（撞到人/惊吓）
        w_max = 1.0 if d_human < self.d_slow else 1.8
        w_allow = float(np.clip(omega_cmd, -w_max, w_max))
        # 返回屏蔽后的动作 + 修正量（修正量进观测，让策略知道"被限了多少"）
        correction = np.array([np.linalg.norm(v_cmd) - v_allow, omega_cmd - w_allow])
        return v_allow_vec, w_allow, correction

解读：这段代码是本章"安全优先"思想的实体。第一个设计点是分段线性的 allowed_speed：它是可解释、可验证的工程曲线（不追求精确的物理制动模型），你在验收时可以说"距离 1 m 时速度不超过 0.2 m/s"，这对安全评审至关重要。第二个设计点是投影方向不变、长度截断：只缩放速度大小（保持运动方向），因为改变方向可能在走廊窄处把机器人推向另一侧的人。第三，角速度也被限制，很多实现只限线速度，但机器人贴人原地快速旋转同样会甩动末端或引起恐慌；协作场景建议 w_max 取 1.0 rad/s。第四，correction 返回给环境进观测：策略需要知道"我的意图被打了多少折"，否则它在被限制时仍按原意图做后续决策，会导致动作链错乱。最后要强调：屏蔽函数与 047/048 章的"无接触安全层"一样，是不依赖策略正确性的最后一道防线，策略越差，它越重要。

片段 3：安全+舒适奖励（阈值外罚 + 平滑项）

def hri_reward(state, cmd, prev_cmd, dt, cfg):
    r = 0.0
    # 1) 任务项：势函数前进（第 043 章的同款写法，这里略去系数细节）
    r += 2.0 * (state["prev_goal_dist"] - 0.99 * state["goal_dist"])

    # 2) 侵入罚：0.8 m 以内按平方增长。给策略"远离"的密集梯度；
    #    真正的安全底线由 SafetyShield 保证，这里只负责"越早让越好"
    if state["d_human"] < cfg["d_comfort"]:      # d_comfort = 0.8 m
        r -= 4.0 * (cfg["d_comfort"] - state["d_human"]) ** 2

    # 3) 舒适项：加速度与 jerk 平滑。人判断机器人"鲁不鲁莽"主要看动作突变
    jerk = np.linalg.norm(cmd - prev_cmd) / dt
    r -= 0.01 * max(0.0, jerk - cfg["jerk_safe"])      # jerk_safe = 1.5 m/s^3 量级入口

    # 4) 交接奖励：在货架区、人与机器人都停下时给一次性奖励（简化：按停留计时）
    if state["in_handover_zone"] and state["my_speed"] < 0.05:
        r += 0.5

    return r

解读：三项奖励的设计逻辑与 048 章一致，"阈值外才罚、量级让位于任务"。侵入罚用平方形式：线性罚下"从 0.8 m 蹭到 0.7 m"和"从 0.4 m 蹭到 0.3 m"付出的代价一样，策略没有"越近越危险"的直觉；平方罚在 0.4 m 附近的单步梯度是 0.7 m 处的 4 倍，把"离人远一点"的紧迫性编码进了曲率。jerk 罚的阈值 1.5 是经验值：低于它的动作人几乎无感，超过后不适感快速增长；写死一次性的"安全 jerk 上限"比全程罚 jerk 更聪明，因为全程罚会鼓励机器人"慢吞吞"，而慢本身也让人不耐烦。交接奖励先用"区域 + 静止"的简化条件，真实系统里应该用"人手接近货物 → 机器人松手 → 人取走"的事件序列，这类"时序事件奖励"可以借助第 013 章的 OmniGraph 事件机制实现，不必在每步内轮询。

常见坑

  • 把人当静态障碍物：观测里只有人的当前位置，没有速度/意图。症状是机器人反复急停（人一动它就失效），任务时间翻倍。修复：加人类速度与 TTC 特征，训练时对人体追踪加噪声。
  • 只用奖励做安全：训练后统计里"平均距离"很漂亮，但尾部仍有少量 0.1 m 级的贴人事件。修复：安全必须是执行层的硬约束（shield/projection），奖励只辅助塑形。
  • 安全约束太保守：d_stop 设成 1 m，机器人见人就停，任务永远做不完，测试者很快失去耐心。修复：按 SSM 公式算 d_stop（速度 × 时间 + 余量），让保守程度由计算给出，不凭感觉。
  • 人类模型太单一：只用一条回放轨迹训练，策略把那条路径背下来，换个人/换条路线就撞。修复：轨迹库 + 相位随机 + 速度随机 + 反应式变体，训练分布要覆盖"快的人、慢的人、突然停的人"。
  • 忽略通信/感知延迟：真机上人的位置到机器人决策有 50–150 ms 延迟，仿真里没有。修复：训练时对观测的人体状态做 0–150 ms 随机延迟，评估时对比延迟前后的安全裕度。

练习与思考

  1. 把 SafetyShield 的 d_slow 从 2.0 m 调到 1.2 m 与 3.0 m，记录任务完成时间与最小间距的 P5 分位，画出两者的权衡曲线。★
    提示
    d_slow 越大，机器人越早减速，最小间距越安全但时间越长。找"P5 间距达标（比如大于 0.5 m）前提下时间最短"的点，这就是在安全要求下的最优工作点。
  2. 删掉观测里的 TTC 特征（其余不变），统计"急停次数"（速度从大于 0.3 降到 0 的事件）的变化。★
    提示
    没有 TTC，策略只能在距离已经很近时才反应，急停次数应显著增加；同时观察急停是否集中在人的运动方向变化之后。
  3. 给人类回放加"突然停留"事件（随机在轨迹中段停 2 s），训练策略并在含该事件的评估集上对比有/无事件训练的两个版本。★★
    提示
    未见过"突然停"的策略会在人停下后继续逼近然后急停；加事件训练的策略学会"人停了我也停"。这是训练分布覆盖度问题的直接演示。
  4. 设计一个实验区分"安全"与"礼貌"：写出两组机器人参数（比如 jerk 阈值 1.5 与 3.0），并给出除时间、间距之外的第三个量化的舒适指标。★★★
    提示
    可用的指标：机器人动作方向反转率（转身次数）、人机最小间距的方差、或"人被迫侧移"的比例（人的路径偏离其标称轨迹的幅度积分）。
  5. 把屏蔽后的"修正量"从观测里删掉，训练后观察贴着屏蔽边界的徘徊行为，解释原因。★★
    提示
    策略不知道自己被限速，会持续输出大动作期望，形成"想快，被限，再想快"的循环，表现为贴着安全边界抖动。观测里给出修正量等于给它"当前约束"的显式信息。

小结

  • 人作为环境的一部分有三个特殊点：不可控、不可全测、安全不可妥协；人类模型从"回放 + 噪声 + 反应式变体"起步最稳。
  • SSM 思想把安全变成几何：dprotect = v·(Tr+Ts) + dstop + 余量；机器人侧用 vmax(d) 曲线执行。
  • 安全必须实现为动作屏蔽（硬约束），奖励罚项只做塑形；屏蔽修正量要回填进观测，避免策略活在幻觉里。
  • 意图特征（人类速度、接近率、TTC）让机器人提前让路；训练时对人体追踪加噪声与延迟，才可能迁移到真机。
  • 奖励三层：任务、侵入罚（平方、阈值外）、舒适（jerk 阈值外 + 可预测性）；评估用"间距分布 + 急停次数 + 完成时间"的组合。
  • 下一章换一个视角看"人"：当环境的规则随时间变化（人的行为、传送带、载荷），就是动态环境适应问题，你会看到在线估计与快速适应的机制。
