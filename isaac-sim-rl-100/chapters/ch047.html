第 047 章：实现力控任务

接触一旦发生，"控位置"和"控力"就不能同时自由：本章讲清这个二元性，给出混合力/位置控制的选择矩阵、力观测的滤波与死区处理，以及适配工业臂的导纳外环。

  • 主题：任务实现 / 接触力控制
  • 相关组件：Isaac Sim（力/接触传感器）/ Isaac Lab / Stable-Baselines3
  • 预计学时：55 分钟
  • 前置章节：第 046 章

学习目标

  • 理解接触中"运动-力"的二元性：受约束方向上位置与力不可能同时独立给定。
  • 会推导接触刚度模型 F = Ke(x − xenv)，并用它解释"硬位置控制为什么必然爆力"。
  • 能写出混合力/位置控制律与选择矩阵 S，说清 S 为什么必须在工具/接触坐标系下定义。
  • 掌握力传感器数据的工程处理：重力补偿、低通滤波、死区，理解为什么原始力信号不能直接进观测。
  • 会实现一个导纳外环（力误差 → 位置修正），并解释它为什么天然适配"位置控制型"机械臂。
  • 能在 RL 任务里正确使用力信号：进观测、进奖励、进安全终止，各要什么处理。

背景与动机

第 046 章的轨迹跟踪回避了一个现实：真实任务里末端经常"贴着东西"走，打磨要压着工件、插装要感受孔壁、装配要拧到规定的预紧力。一旦接触发生，纯粹的位姿控制在物理上就失效了：你把位置命令往前推进 1 mm，接触力可能涨 50 N，也可能因为零件让位而几乎不涨；你能决定的只是"位置和力这两个量里，哪个由你控制、哪个由环境决定"。这就是力控要解决的问题。

本章先讲清接触中的运动-力二元性（核心理论），再给两类工程结构：直接力控/混合力位控制（面向有转矩接口的机器人）与导纳控制（面向内置位置环的工业臂）。最后把它接回 RL：力信号怎么进观测才不被噪声淹没、力误差怎么写奖励、力上限怎么做安全约束。第 048 章的柔顺控制会在此基础上把"刚度"本身变成可学习参数。

核心原理

1. 运动-力二元性：接触里的"控制自由度"减少

自由空间里，机械臂末端有 6 个自由度，位姿是 6 个可独立指定的量。接触发生后情况变了：以"末端压在刚性工作台上"为例，竖直方向（法向）的运动被环境约束死了，你不能既规定末端停在 z = 0.300 m，又规定法向力恰好 10 N。这两个量由环境连接在一起：

F = Ke·(x − xenv) Ke 为环境等效刚度（钢 106、橡胶 104 N/m 量级），xenv 为接触面自然位置

把数字代进去：Ke = 106 N/m 时，10 N 的力对应的位置差只有 10 μm，比大多数机械臂的重复定位精度还小。这意味着在刚性接触中"控力"实际上就是"控一个 10 μm 级的微位移"；反过来，位置控制的 1 mm 误差会变成 1000 N 的力（现实中会被结构变形、关节柔度限制在几十牛，但足以报警）。

结论就是本章第一条原理：每个接触方向上，只能选一个被控量（力或者运动），另一个由环境方程决定。混合控制的任务就是给 6 个方向分别做出这个选择。

2. 选择矩阵：逐方向决定"控力还是控位"

选择矩阵 S 是一个 6×6 对角矩阵，对角元取 0 或 1（1 = 该方向控力，0 = 该方向控位），控制律为：

vcmd = S·vforce + (I − S)·vposition 力回路输出（PI）+ 位置回路输出（PD），在 6 个方向上互斥合成

打磨是典型例子：法向（压入）控力，切向（进给）控位置/速度。插孔则是轴向控位置（直到深度达标）、侧向控力（感受孔壁）。S 决定了任务结构，写错 S 等于换了任务。

S 必须定义在工具/接触坐标系下：因为"哪个方向是法向"由工件的局部几何决定，随末端姿态变化。世界系里固定 S 只对"接触面恰好水平、末端姿态恰好不变"的特例成立，一旦机器人转身，控力的方向就飘了。这也是新手最常见的力控 bug。

3. 力回路为什么需要积分：未知的接触刚度

力回路的被控对象是"力误差 → 力变化"，其增益直接由 Ke 决定，而 Ke 事先未知（钢、铝、塑料差两个数量级）。纯比例控制下，达到稳态时残余误差 Fd − Fmeas = (1/(1 + kpKe))·Fd，增益越不确定、静差越不可控；引入积分项后，稳态误差被压到零：

u(t) = kp(Fd − F) + ki∫(Fd − F)dτ

积分带来稳定性的代价，必须配抗积分饱和（anti-windup）：当接触断开（力突然为 0）时，积分器若持续累积，重新接触瞬间会冲出巨大指令。典型工程做法是积分限幅 + 接触检测置零。

4. 导纳与阻抗：一条分界线"谁在控制运动"

工业机械臂的控制接口几乎都是位置环（关节伺服封闭），你无法直接指令关节扭矩。对这类机器人，力控只能用导纳控制（admittance）：测量力误差，把它"翻译"成位置修正，再交给位置环执行：

Bd·ẋcorr = Fmeas − Fd,   xcmd = xnominal + ∫ẋcorrdt 导纳 = 力 → 运动；Bd 为虚拟阻尼，N·s/m

反过来，如果机器人能直接输出关节扭矩，就更适合阻抗控制：把末端虚拟成一个弹簧-质量-阻尼系统，让"位置偏差"推出"力"。两者是同一物理关系的两种因果朝向（力→运动 vs 运动→力），第 048 章会展开他们的适用条件。本章先记住结论：位置控制型机器人用导纳，扭矩控制型机器人用阻抗。

5. 力信号进 RL 之前必须做的三件事

力传感器给的是"原始"数据，直接进观测有三个问题。第一，工具重力：传感器测的是它感受到的合外力，末端夹具的重力（可能 5–20 N）会以恒定偏置混进信号，必须先做重力补偿（按姿态旋转重力向量并从测量中减去）。第二，噪声：商用六维力传感器噪声 0.1–0.5 N RMS、采样率 1 kHz，直接进 50 Hz 的策略会让它"看着噪声抖动"，典型滤波是一阶低通、截止约 20 Hz。第三，零点漂移与死区：标定后的零点随温度缓慢漂移，设置 0.3–0.5 N 的死区把"无接触"稳定映射为 0，策略才能干净地区分"碰到/没碰到"。

6. 数值算例：导纳修正量、滤波与积分的尺度

把设计里的参数代进物理量算一遍。导纳环 Bd = 150 N·s/m，力误差 20 N（目标 15 N、实测出现反向 5 N 的极端瞬态）产生的"退让速度"是 20/150 ≈ 0.133 m/s，每个 2 ms 外环周期（500 Hz）产生 0.27 mm 的位置修正；若误差持续 0.1 s，累积修正 13.3 mm，接近 ±20 mm 限幅的一半。两点结论：导纳环的退让速度量级与接触瞬态匹配（0.1 m/s 级）；±2 cm 的修正限幅给了约 0.15 s 的持续误差余量，超过它说明名义轨迹或力指令出了系统性问题，限幅触底是异常信号，应视为待排查的问题。

滤波与积分的尺度同样可以精确核对。一阶低通系数 α = 0.1、1 kHz 采样时，等效截止频率 fc = α/(2π·dt) ≈ 15.9 Hz，对应相位滞后约 1/(2πfc) = 10 ms；对 10 Hz 的外环决策完全够用，对 500 Hz 的内环意味着 5 个周期的滞后，所以原始通道必须留给内环使用。积分通道的量级：积分限幅 ±5、积分增益 ki = 0.02 时，积分项能贡献的最大速度修正为 0.1 m/s，而比例项在 20 N 误差时的贡献是 0.001×20 = 0.02 m/s，积分项是比例项的 5 倍，力跟踪的精度主要由积分项承担，比例项接近"底噪"，因此抗积分饱和（接触丢失清零）比调比例增益更重要。最后是分辨率的核算：接触刚度 5×10⁵ N/m 时，1 N 的力差只对应 2 μm 的位置差，远低于机械臂的重复定位精度，刚性接触里"用力闭环做精确定位"在数值上没有意义，力的精度只能来自柔顺结构，与位置分辨率无关。

安全阈值的刻度也核对：目标力 15 N、过载终止 40 N，终止线是目标值的约 2.7 倍，这条比例保证"正常跟踪的波动不误触发终止，而真正的碰撞（力瞬间突破数十牛）一定触发"；接触丢失判定（力降到 1 N 以下）是目标值的 1/15，与 0.4 N 的死区拉开约 2.5 倍差距，避免死区边缘的噪声把"轻接触"误判成丢失。三项阈值构成一条 1 : 15 : 40 的刻度尺，评估时报告"力落在各区间的时间占比"，能同时看到跟踪质量与安全事件的频率；只看平均力会把两端的分布全部掩盖。

重力补偿的量级也核一遍：工具质量 1.5 kg 时重力 14.7 N，若漏做补偿，竖直朝下姿态观测里混入 14.7 N 偏置、水平姿态混入 0，偏置随姿态在 0–14.7 N 之间漂移，策略无法从这样的信号里学会区分"碰到物体"与"举着工具"；补偿后的残余误差应在悬空状态下保持 0.5 N 以内，这条验收线可以直接写成单元测试，超过它说明质心参数或姿态标定有误，应先重做标定，再谈训练参数的调整。

实现思路与设计

把上面的原理落成一个可训练的"压紧并沿面滑动"任务（打磨的简化版）：

  1. 任务定义：末端工具压住工件表面，法向维持 Fd = 15 N（±2 N），同时沿水平方向以 0.05 m/s 进给滑动 20 cm。工件表面随机高度 ±3 mm、摩擦 0.2–0.6。
  2. 控制架构：内外双环。内环 500 Hz：力 PI（法向）+ 位置伺服（切向）；外环 RL 10 Hz：输出法向力指令 Fd 的偏置（±5 N）与切向速度指令（±0.03 m/s 相对标称值）。为什么让 RL 管指令偏置，直接输出力指令有什么问题？因为内环已经把"接触"这件快变量处理掉了，RL 面对的是慢变量（工件高度变化、摩擦变化），学习难度直线下降。
  3. 方向划分：工具坐标系的 z 轴为法向（控力，S 对应位为 1）；x、y 为切向（控位/速，S 为 0）。工具扭转方向的扭矩在打磨中不重要，锁定为 0。
  4. 观测（约 24 维）：滤波后力/力矩（6）、力误差（3）、工具位置（3）、切向速度（3）、工件高度估计（1，可选特权信息）、相位/进度（2）、关节位置速度（选 7 维）。
  5. 奖励：力跟踪 −|F − Fd| 的软核、进给进度、力变化率平滑、接触保持（力 > 3 N 的时长占比）。
  6. 安全：力超过 40 N 立即终止并给重罚；接触丢失（力降到 1 N 以下）也终止，防止策略"回避接触"消极刷时间。
  7. 随机化：表面高度 ±3 mm、局部坡度 ±2°、摩擦 0.2–0.6、工具质量 ±10%（别忘同步改重力补偿）。
结构接口要求优点局限
直接力控（关节转矩）关节力矩接口 + 动力学模型带宽高（可达数百 Hz）需精确动力学/重力补偿，工程量大
混合力/位置（选择矩阵）任务空间速度/位置接口结构清晰，逐方向选择需要精确的任务坐标系定义
导纳外环仅需位置接口（工业臂常见）落地成本最低，兼容封闭伺服带宽受位置环限制（典型 < 30 Hz）
设计思维：为什么把力控拆成"内环经典控制 + 外环 RL"？

接触力环的稳定需要 500 Hz–1 kHz 的采样与严格整定，这个频段 RL 既学不了（样本量爆炸）也没必要学。把力环交给 PI，RL 只在 10 Hz 上做"慢决策"：加压多少、滑多快。这就是反馈控制里的分层原则：内环解决带宽与稳定，外环解决目标与适应。你在 047/048 两章都会反复看到这个结构。

关键代码与解读

片段 1：混合力/位置控制（选择矩阵版）

import numpy as np

class HybridForcePositionController:
    # 选择矩阵 S：对角元 1 = 该方向控力，0 = 该方向控位。工具坐标系下定义！
    def __init__(self, S_diag, kp_pos=10.0, kd_pos=0.2, kp_f=0.001, ki_f=0.02):
        self.S = np.diag(S_diag)                 # 6x6 对角选择矩阵
        self.kp_pos, self.kd_pos = kp_pos, kd_pos # 位置环 PD（输出速度指令）
        self.kp_f, self.ki_f = kp_f, ki_f         # 力环 PI（输出速度修正）
        self.i_err = np.zeros(6)                  # 力环积分状态

    def compute(self, x_err, xd_err, wrench_meas, wrench_des, dt):
        # 力环：PI 跟踪期望力。积分项负责吃掉"接触刚度未知"带来的静差
        self.i_err += (wrench_des - wrench_meas) * dt
        self.i_err = np.clip(self.i_err, -5.0, 5.0)      # 抗积分饱和：断开接触时不炸
        v_force = self.kp_f * (wrench_des - wrench_meas) + self.ki_f * self.i_err

        # 位置环：PD 产生速度指令（自由方向用）
        v_pos = self.kp_pos * x_err + self.kd_pos * xd_err

        # 选择矩阵合成：每个方向严格二选一，绝不把两套律叠加
        v_cmd = self.S @ v_force + (np.eye(6) - self.S) @ v_pos
        return v_cmd

解读：这段代码里值得反复看的是三个地方。第一，v_cmd 的合成式是"互斥选择"：选择矩阵的哲学是"每个方向只能有一个被控量"，如果写成 0.5 力 + 0.5 位，两个回路会在接触点互相抢控制权，表现是高频振荡。第二，力环的 PI 输出被解释成"速度修正"：这是因为最外层的执行接口是速度/位置（导纳思想），力误差大就"退得快一点"，等效于降低接触刚度。第三，积分限幅 ±5.0 对应"最多让速度修正偏 5 个指令单位"：没有这个限幅，接触断开 0.5 s（策略常干的事）后积分器可能累积到几十，重新接触的瞬间就是一次冲击。

片段 2：力信号的重力补偿、滤波与死区

class ForceConditioner:
    # 原始力信号 -> 可进观测的净接触力。三步：去重力、低通、死区
    def __init__(self, tool_mass, tool_com_in_sensor, alpha=0.1, deadband=0.4):
        self.m = tool_mass                       # 工具质量 kg（装配后重新标定）
        self.com = np.asarray(tool_com_in_sensor)  # 工质心（传感器系），产生重力力矩
        self.alpha = alpha                       # 一阶低通系数（1 kHz 采样时约 20 Hz 截止）
        self.deadband = deadband                 # 0.4 N：把"没接触"和噪声分开
        self.f_filt = np.zeros(6)

    def update(self, raw_wrench, R_sensor_in_world):
        # 1) 重力补偿：把工具重力旋转到传感器系后从测量中扣掉（含力臂产生的力矩）
        g_s = R_sensor_in_world.T @ np.array([0.0, 0.0, -9.81 * self.m])
        tau_g = np.cross(self.com, g_s)
        net = np.asarray(raw_wrench) - np.concatenate([g_s, tau_g])

        # 2) 一阶低通：y <- (1-a)y + a*x。alpha 越小越平滑，但相位滞后越大
        self.f_filt = (1.0 - self.alpha) * self.f_filt + self.alpha * net

        # 3) 死区：绝对值小于 0.4 N 的分量直接置零，避免策略把零点漂移当接触
        out = self.f_filt.copy()
        out[np.abs(out) < self.deadband] = 0.0
        return out

解读：三步里最容易出事的是第一步。工具重力补偿需要两个量：质量 m 与质心位置 com（相对传感器的力臂）。它们必须在"工具装好之后"重新标定，换夹具不重新标，观测里就多一个 5–20 N 的恒定偏置，策略会把这个偏置误当成"已经接触"，于是永远学不会主动压下去，或者相反，用错误的基线去"追"一个不存在的力。第二步的低通滤波要理解时间常数：alpha = 0.1 时等效截止频率约 20 Hz，滞后约 8 ms，对 10 Hz 的外环完全够用，对 500 Hz 的内环就太慢了，所以内外环要各用一份滤波后/原始数据。第三步死区 0.4 N 的量级来自传感器噪声（0.1–0.5 N RMS）：设太小噪声照进；设太大（如 2 N）则 2 N 以内的真实接触被当成"没碰"，任务里的轻触检测直接失效。

片段 3：导纳外环，力误差到位置修正

class AdmittanceLoop:
    # 适配"位置控制型"机械臂：测力 -> 生成位置修正 -> 叠加在名义轨迹上
    def __init__(self, B_d=150.0, dt=2.0e-3):
        self.B_d = B_d                  # 虚拟阻尼 N·s/m：越大越迟钝越稳，越小越灵敏越易振
        self.dt = dt                    # 外环周期 2 ms（500 Hz），需与外环滤波匹配
        self.x_corr = np.zeros(6)       # 位置修正累积量

    def update(self, wrench_meas, wrench_des):
        # 力误差限幅：碰撞瞬间的尖峰不应直接进积分器（等价于输入饱和+抗饱和）
        err = np.clip(wrench_des - wrench_meas, -20.0, 20.0)
        # 一阶导纳：力误差驱动"退让速度"，再积分成位置修正
        # 物理直觉：B 越小，机器人越"软"，同样的力退得越快
        v_corr = err / self.B_d
        self.x_corr += v_corr * self.dt
        # 修正量限幅 ±2 cm：允许让位，但不允许偏离名义轨迹太远（工艺要求）
        self.x_corr = np.clip(self.x_corr, -0.02, 0.02)
        return self.x_corr

解读：导纳环的整条链路可以概括为"力误差 → 速度 → 位移"，其中 Bd 是唯一的核心参数，它决定接触刚度上限：稳态下修正速度为零，力的残差要靠名义轨迹的前进自然建立，所以严格说一阶导纳是"速度型"的，稳态力由进给速度与 Bd 共同决定。这带来一个实用推论：要调节接触力，可以调 Bd，也可以调名义轨迹的压入量，后者正是本章任务里 RL 外环在做的事（输出 Fd 偏置）。另外两个限幅分别防两类事故：误差限幅防碰撞尖峰灌进积分器（重新接触时不会猛退），位置限幅 ±2 cm 防"让位过头"把工具带离工件，打磨工艺要求工具始终跟住表面，让位超过 2 cm 本身就该触发异常处理。

常见坑

  • 选择矩阵在世界系下定义：机器人一转姿态，原本"法向控力"的方向变成切向，力环和位置环开始互相打架。症状是力跟踪在某些姿态下正常、换个姿态就振荡。修复：S 只在工具系下定义，每步按当前工具姿态解释。
  • 没做工具重力补偿：空载观测里就有 5–20 N 偏置，策略学出"永远在接触"的错误判断，任务成功率莫名很低。修复：换工具后重新标定质量与质心，并写一个"悬空 10 s 平均力应小于 0.5 N"的单元测试。
  • 积分饱和打冲击：接触断开时 PI 的积分继续累积，重新接触瞬间力尖峰可达目标值的 2–3 倍。修复：积分限幅 + 接触丢失（力低）时把积分项乘 0。日志里检查"断开-重接触"事件附近的力峰值。
  • 力环带宽超过接触共振：外环频率定得过高（如 200 Hz），与接触刚度+机械臂惯量构成的共振耦合，出现持续啸叫或极限环。修复：外环带宽不超过系统最低结构共振频率的 1/5，且用滤波后的力。
  • 用未滤波的原始力进观测：0.1–0.5 N 的噪声被策略当成信号，动作高频抖动、真机上听到"嗡嗡"。修复：观测通道用 20 Hz 低通 + 死区；需要高带宽信号时（如阻抗内环）单独用原始通道。

练习与思考

  1. 把 S 里法向的对角元从 1 改成 0（法向改为控位），预测并验证接触力随位置指令的变化，用 F = KeΔx 定量解释你的观察。★
    提示
    控位时力的变化完全由"位置指令 − 实际表面高度"决定，把位置指令阶梯增加 0.5 mm，记录力响应：斜率就是 Ke 的估计。
  2. 把 ForceConditioner 的 deadband 从 0.4 N 调到 2.0 N，观察"接触检测"的滞后与任务成功率的变化。★
    提示
    死区过大时，小于 2 N 的真实接触被视为"无接触"，策略的接触保持奖励统计偏低，行为变得犹豫（不敢轻触）。
  3. 设计实验测量你手上系统的"接触共振频率"：写出激励方法、观测信号与分析方式。★★
    提示
    让机器人以小幅正弦位置指令压向工件，扫频 1–200 Hz，记录力响应幅值曲线；峰值对应的频率即接触共振，外环带宽应低于它的 1/5。
  4. 把外环 RL 的策略频率从 10 Hz 提高到 100 Hz（其余不变），预测样本效率与抖动指标的变化并验证。★★
    提示
    内环已处理高频，外环提高频率主要是把噪声带给了策略；观察动作的高频能量与训练步数，通常得不偿失。
  5. 为"插孔 + 压紧"任务写一份 S 矩阵设计：逐方向说明选力还是选位、依据是什么、什么时候需要方向切换。★★★
    提示
    轴向在接近段控位（位置趋近）、接触后控力（限力压入）；侧向全程控力（跟随孔壁）；绕轴旋转控扭，状态机与 S 的组合才是完整答案。

小结

  • 接触的"运动-力二元性"：F = Ke(x − xenv)，每个接触方向只能独立指定一个被控量，另一个由环境方程决定。
  • 混合力/位置控制用选择矩阵 S（工具系下定义）逐方向分配：法向控力、切向控位是打磨/插装的通用划分。
  • 力环需要积分消除"未知接触刚度"的静差，但必须配抗积分饱和与接触丢失处理。
  • 位置控制型机器人用导纳（力 → 位置修正），扭矩控制型机器人用阻抗；Bd 是导纳环的核心参数。
  • 力信号进 RL 前必须去重力、低通（约 20 Hz）、设死区（0.3–0.5 N）；内环用原始信号、外环用处理后信号。
  • 下一章柔顺控制把这里的思想推进一层：不再只控"一个方向的力"，改为把机器人整体调成可编程的弹簧-阻尼系统，并让 RL 学习刚度参数本身。
