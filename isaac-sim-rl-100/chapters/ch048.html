第 048 章：实现柔顺控制

把机器人末端调成一只"可编程的手"：用阻抗方程 Mdẍ + Bdẋ + Kd(x−xr) = Fext 定义刚度与阻尼，让 RL 在外环学习"什么时候该软、软哪个方向"。

  • 主题：任务实现 / 柔顺与变阻抗控制
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3
  • 预计学时：55 分钟
  • 前置章节：第 047 章

学习目标

  • 写出笛卡尔阻抗控制方程，解释"质量-弹簧-阻尼"三个参数各自控制什么行为。
  • 说清阻抗控制与导纳控制的因果方向差异，以及"位置环机器人用导纳、力矩机器人用阻抗"的工程依据。
  • 会推导临界阻尼条件 B = 2√(M·K) 的直觉，并能解释阻尼比 ζ 偏离 1 时会发生什么。
  • 能实现"策略输出刚度参数"的变阻抗结构：sigmoid 有界映射、逐轴各向异性、刚度变化率限幅。
  • 理解各向异性柔顺为什么是插装任务的关键：轴向软（吸收误差）、横向硬（保持精度）。
  • 会设计柔顺相关的奖励：力尖峰、力方差、jerk，并说明它们与任务奖励的分工。

背景与动机

第 047 章的力控解决了"方向选择"的问题，但真正的装配现场还需要更细腻的能力：零件有 0.2 mm 的错位，你要让机械臂"软一下"让它滑进去；拧螺丝时你要"顺着螺距走"，硬顶会滑牙；和人握手时你的手臂要"让力"，硬刚会顶回去。这些场景的共同点是：机器人不应该是一条硬邦邦的钢管，而应该表现得像一只弹簧-阻尼可调的手。这就是柔顺控制（compliant control）的思想，其数学核心是阻抗控制。

本章的路线是"经典骨架 + RL 调参"：内环用固定的阻抗方程保证接触稳定，外环让策略根据任务上下文在线调整刚度 Kd 与阻尼 Bd，接近孔口时调软吸收误差，插入后调硬保证跟随，遇到卡滞时再放松。你会发现它与 042 章的装配任务是同一问题的两面：042 设计奖励与观测，本章设计"执行器"。

核心原理

1. 阻抗方程：把末端变成"可编程的弹簧-质量-阻尼"

阻抗控制的理想目标是控制位置与力之间的动态关系：

Md·ẍ + Bd·ẋ + Kd·(x − xr) = Fext Md 虚拟质量，Bd 虚拟阻尼，Kd 虚拟刚度，xr 参考轨迹，Fext 外力

直观读法：末端像一个质量为 Md、阻尼为 Bd、弹簧原长为 xr 的机械系统。外力 Fext 推它，它按这套参数"退让"。三个参数的物理分工：

参数物理含义典型值调大/调小的效果
Kd虚拟刚度200–5000 N/m（逐轴）大 = 硬、精度高、接触力大；小 = 软、顺应强、易漂
Bd虚拟阻尼由临界阻尼公式给出小 = 弹跳振荡；大 = 迟钝、响应慢
Md虚拟质量常取 0.1–1.0 kg大 = 冲击惯量大；小 = 轻快但易被噪声驱动

关键数字对比：环境刚度 106 N/m（钢对钢）时，若机器人等效刚度取 500 N/m，同样的 0.2 mm 错位只产生 0.1 N 的力，误差被"弹性吸收"了。这就是柔顺能让装配误差不变力的原因：接触力由两者中较小的刚度主导，只要机器人比环境"软"一到两个数量级，微小错位就不会造成力爆炸。

2. 阻抗 vs 导纳：谁指谁

同一组参数可以有两种实现因果：

阻抗：运动（x 偏差）→ 力（τ = JT[Kd(xr−x) + Bd(ẋr−ẋ)]）  |   导纳：力（F 测量）→ 运动（xcorr）

选择依据在硬件闭环的"里层"是什么：机械臂能接收关节扭矩指令、且你知道它的动力学（做重力/科氏补偿），就适合直接实现阻抗，运动偏差即时算出应发的扭矩，带宽最高。如果机械臂的关节伺服封闭，只接受位置/速度指令（大多数工业臂），就无法"施加指定的力"，只能反过来：先测接触力，按阻抗/导纳方程算出"应该退让多少"，把退让量加到位置指令上。稳定性上两者要防的隐患也不同：阻抗回路里机器人的物理惯量与虚拟 Md 相互作用，Md 不能远大于真实惯量；导纳回路里位置环带宽与虚拟参数相互作用，参数在接触刚度突变时容易失稳。

3. 临界阻尼：为什么要让 B 与 K 联动

把阻抗方程看成一个二阶系统，其阻尼比为：

ζ = Bd / (2·√(Md·Kd)) ζ = 1 临界阻尼：最快无超调；ζ < 1 欠阻尼振荡；ζ > 1 过阻尼迟钝

代入数字：Md = 0.5 kg、Kd = 500 N/m 时临界阻尼 Bd = 2√(0.5×500) ≈ 31.6 N·s/m。如果策略偷偷把 Kd 变成 125 N/m 而 Bd 不变，ζ 涨到 2.0，系统变得迟钝，接触力建立得很慢；反之 Kd 升到 5000 时 ζ 降到 0.32，末端变成"弹性球"，接触后抖动几拍才能稳定。因此工程实现上 Bd 从不独立设定，永远由 Bd = 2·√(Md·Kd) 随 Kd 一起算，这就是"刚度-阻尼联动"。训练里如果让 RL 自由输出 Bd，它往往会为了"省力"把阻尼调小，然后在接触里振荡，把联动固化是更好的选择。

4. 各向异性柔顺：插装任务的黄金配置

柔顺不必是各向同性的。孔轴插入的最优刚度分布是"轴向软、横向硬"：

Kd = diag(Kxy, Kxy, Kz),   Kz ≈ 200–500 N/m（轴向）,   Kxy ≈ 2000–5000 N/m（横向）

轴向软：一旦对准偏差让轴撞上孔肩，轴向的顺从性让零件"让一让"，配合倒角把接触力转化为横向自对准力；横向硬：插装过程中保持横向刚性，不让零件随意漂移损失定位精度。同样的思路用在拧螺丝上：沿螺距方向软（顺从螺纹），绕轴方向需要扭矩控制（避免过拧）。刚度的方向性是工艺知识的直接编码，策略学什么？学"在什么阶段、遇到什么接触状态时，把哪个方向的刚度调到什么挡位"。

5. RL 的学习信号：任务奖励 + 平滑惩罚

变阻抗不需要"教策略什么是柔顺"，只需要给它正确的评价函数。任务层面沿用装配的奖励（深度、误差、完成），补充三个过程惩罚：

  • 力尖峰：max(0, ‖F‖ − Fsafe)²，Fsafe 取工艺许用值（如 25 N）。它直接惩罚"用蛮力"，逼策略用柔顺通过卡滞点。
  • 力变化率（jerk 代理）：‖Ft − Ft−1‖²。接触力突变意味着碰撞；平滑的力曲线是柔顺的直接体现。
  • 刚度变化率：‖Kt − Kt−1‖²。刚度突变会向系统注入能量（等效于瞬间改变弹簧长度），是变阻抗特有的不稳定源，用惩罚 + 限幅双保险压住。

6. 数值算例：阻尼比、超调与响应时间

取 Md = 0.5 kg、临界阻尼基准 Bd = 2√(0.5×500) ≈ 31.6 N·s/m（对应 Kd = 500 N/m、ζ = 1）。保持 Bd 不变扫 Kd：Kd = 125 N/m 时 ζ = 31.6/(2√62.5) = 2.0（过阻尼，力建立慢）；Kd = 5000 时 ζ = 31.6/(2×50) = 0.32（欠阻尼）。超调量按二阶系统解析式 e−πζ/√(1−ζ²) 核算：ζ = 0.32 时约 35%，ζ = 0.3 时约 37%；到达 ±5% 带的整定时间按 4/(ζωn) 估算，Kd = 5000 时 ωn = √(5000/0.5) = 100 rad/s，约 0.13 s；Kd = 100 时方程的两个实极点为 −3.3 与 −59.9 rad/s，慢极点决定响应时间常数约 0.30 s。这张表解释了"刚度-阻尼联动"的必要性：只调 Kd 不动 Bd，高刚度端进入 35% 超调区（接触振荡），低刚度端进入整定 0.3 s 以上的迟钝区，两种行为都不该留给策略去"学会绕开"，参数化直接排除更干净。

刚度对环境误差的放大倍数再核：0.2 mm 的错位在 Kd = 5000 时产生 1.0 N 接触力，Kd = 200 时 0.04 N，Kd = 100 时 0.02 N；同样错位在环境刚度 10⁶ N/m 下是 200 N。机器人刚度比环境低两个数量级时，接触力被同比例地折算下来，这就是柔顺的定量含义；反过来说，Kd 的调节范围 100–5000（50 倍）给了策略从"几乎无感"到"能分辨 1 N"的完整空间，变阻抗的输出尺度与任务需求对齐，不需要在外层再乘额外增益。

各向异性配置的数值效果同样可以分解：轴向取 Kz ≈ 300 N/m 时，轴端撞上孔肩 0.2 mm 的错位只产生 0.06 N 的力，接触几乎"无感"地让位；横向取 Kxy = 2000 N/m 时，同样的 0.2 mm 保持 0.4 N 的回正力，定位精度不丢。横向与轴向的刚度比约 7:1，正对应"让错位进得来、不让精度跑出去"的插装需求。刚度变化率再细化：每步限幅 10% 量程即 490 N/m，从最低 100 N/m 升到最高 5000 N/m 需要约 10 个控制步（20 Hz 下 0.5 s），"软硬切换"存在固有过渡时间；阶段切换的时序设计必须把这 0.5 s 算进去，否则会出现"该软的瞬间还没软下来"的错拍。

实现思路与设计

把变阻抗柔顺接到装配任务（042 章）上的完整设计：

  1. 分层结构：内环 500 Hz 阻抗控制（力矩接口）或导纳外环（位置接口）；外环 RL 20 Hz 输出刚度调整量。为什么 20 Hz？刚度是"慢变量"，接触动力学决定它不需要快更新；更新太快会与力环耦合出振荡。
  2. 参数量化：策略输出 4 维，整体刚度比例（1 维）+ 三个方向的各向异性系数（3 维），经 sigmoid 映射到 [Kmin, Kmax] 区间：平移刚度 100–5000 N/m，旋转刚度 5–200 N·m/rad。Md 固定 0.5 kg，Bd 由临界阻尼公式联动。
  3. 观测：力/力矩（滤波后 6 维）、当前刚度参数（4 维）、相对位姿（6 维）、接触状态指示（1 维）、阶段指示（2 维）、上一步动作（4 维）。把当前刚度放进观测很关键，策略需要知道"自己现在有多软"才能决策。
  4. 动作限速：刚度每步（50 ms）最多变化 10% 量程。理由：刚度突变 10 倍时，同样的位置偏差对应的力矩瞬间变化 10 倍，是冲击的来源。
  5. 奖励：装配任务奖励（深度、对齐、完成）+ 力尖峰惩罚 + 力变化率惩罚 + 刚度变化率惩罚；时间罚保持 −0.001。
  6. 课程：第一阶段固定刚度（只学任务，刚度参数锁死在中档 1000 N/m）→ 第二阶段解锁刚度（学变阻抗）→ 第三阶段缩小间隙随机化范围。先学"任务会做"，再学"做得好"，最后"做得精"。
  7. 安全护栏：Kd 上下限硬约束（sigmoid 天然满足）+ 力超过 40 N 时强制把刚度调到最低档 0.5 s（"自动软下来"），这是不依赖策略的最后一层保护。
阶段策略输出刚度设定学习目标
阶段 1只输出位姿锁定 1000 N/m任务流程
阶段 2位姿 + 刚度100–5000 N/m 自适应柔顺策略
阶段 3同上同上小间隙鲁棒性
设计思维：为什么让 RL 调"刚度"，直接输出力矩有什么问题？

直接输出力矩意味着策略要吃掉整个接触动力学（毫秒级、非线性、状态跳变），样本需求上亿；而刚度是低频决策变量，改动它以后由内环的阻抗方程自动兑现"接触瞬间该如何反应"。这就是把快反馈交给物理（弹簧-阻尼），慢决策交给学习的分工。判断标准很简单：如果一个量在 100 ms 内就变化剧烈，它就不该是 RL 直接输出的对象。

关键代码与解读

片段 1：笛卡尔阻抗控制律（力矩接口版）

import numpy as np

def cartesian_impedance(x, xd, x_r, xd_r, wrench_ext, params, J, J_dot_qd):
    # params: M_d, B_d, K_d 均为 6x6 对角矩阵（平移+旋转）
    M_d, B_d, K_d = params["M_d"], params["B_d"], params["K_d"]
    # 阻抗项：参考轨迹与实际之间的"虚拟弹簧-阻尼-质量"产生的期望力
    # 只依赖运动偏差，不依赖力测量；这是阻抗控制与力控的本质区别
    a_cmd = np.linalg.solve(M_d, K_d @ (x_r - x) + B_d @ (xd_r - xd) - wrench_ext)
    # 期望加速度 -> 期望关节扭矩：用 J^T 把任务空间力映射回关节空间
    # 实际工程中这里还会加动力学补偿（重力/科氏项），否则静态时末端会"软塌"
    F_cmd = M_d @ a_cmd + wrench_ext        # 由阻抗方程解出的等效任务力
    tau = J.T @ F_cmd + gravity_compensation(q) - J_dot_qd  # J_dot_qd 为科氏/离心补偿项
    return tau

解读：这段代码的抽象层级要仔细看。第一行解出 a_cmd 是把阻抗方程"反解成加速度"：给定期望的 M/B/K 和测量到的外力，算出机器人此刻应该以多大加速度运动才能"表现得像一个虚拟弹簧"。注意它只用了运动偏差与外力的组合，没有力闭环，这正是阻抗控制之美：不需要力传感器也能实现"接触时变柔顺"（力传感器只在需要显式感受外力的场景才用）。第二，τ = JTF 是任务空间到关节空间的映射（虚功原理），对冗余机械臂还要加零空间投影以免奇异位形。第三，初学者最常忘的是 gravity_compensation：没有它，机械臂自己的重力就会把末端"压软"，表现为刚度参数怎么调都偏软、静态位置总是偏低，这是 047 与 048 共用的高频坑。最后，这段代码里 J_dot_qd 只作概念性说明：真实的实现要按机器人动力学库（比如 Pinocchio 或 Isaac 自带接口）取这些量，不同 Isaac Sim 版本 API 名称不同，以官方文档为准。

片段 2：策略输出刚度，有界映射 + 阻尼联动 + 变化率限制

import numpy as np

class VariableImpedance:
    # 平移刚度范围 N/m；旋转刚度范围 N·m/rad。上下限来自系统辨识与稳定性试验
    K_TRANS_MIN, K_TRANS_MAX = 100.0, 5000.0
    K_ROT_MIN, K_ROT_MAX = 5.0, 200.0

    def __init__(self, M_d=0.5, max_rate=0.10):
        self.M_d = M_d                   # 虚拟质量固定，不让策略碰（最容易失稳的参数）
        self.max_rate = max_rate         # 每步最多变化 10% 量程
        self.K_prev = np.full(6, 1000.0) # 上一步刚度（平移 3 + 旋转 3）

    def map_stiffness(self, raw_action):
        # sigmoid 有界映射：raw 任意实数 -> (0,1) -> [K_min, K_max]
        # 好处：无论策略输出多大，刚度永远在安全范围内，天然满足稳定约束
        s = 1.0 / (1.0 + np.exp(-np.asarray(raw_action, dtype=np.float64)))
        K = np.empty(6)
        K[:3] = self.K_TRANS_MIN + s[:3] * (self.K_TRANS_MAX - self.K_TRANS_MIN)
        K[3:] = self.K_ROT_MIN + s[3:] * (self.K_ROT_MAX - self.K_ROT_MIN)

        # 变化率限制：单步限幅，防止刚度突变向系统注入能量
        step = self.max_rate * (self.K_TRANS_MAX - self.K_TRANS_MIN)
        K[:3] = self.K_prev[:3] + np.clip(K[:3] - self.K_prev[:3], -step, step)
        self.K_prev = K.copy()

        # 阻尼联动：B = 2*sqrt(M*K)，保持阻尼比约 1（临界阻尼），永不让 RL 单独调 B
        B = 2.0 * np.sqrt(self.M_d * K)
        return np.diag(K), np.diag(B)

解读：三处设计各防一类问题。sigmoid 映射把"网络输出无界"和"刚度必须落在安全区间"这两个矛盾的世界调和了：无论策略输出 ±100 还是 0.001，刚度永远在 [100, 5000] 内，训练过程本身就受约束。限速逻辑里 step 的计算值得注意，限速用"量程的 10%"作为固定绝对步长，这样无论刚度在 100 还是 5000 附近，绝对速度限制一致，避免在低刚度区变得太慢（低刚度基本身只差 50 倍，按比例限速会在最小值附近几乎不动）。最后的阻尼联动是防振荡的总闸：只要阻尼比恒定，无论刚度怎么被策略折腾，接触响应不会出现"越来越弹"的情况；如果让策略自由输出 B，它会在某些状态下学出极低阻尼的"震荡换分"行为，这是变阻抗训练中最常见的不稳定来源。参数从哪来：K 的范围由稳定性试验定（从 2000 N/m 开始，逐步加压找到不失稳的上下界），Md 选 0.5 kg 是因为它接近实测末端等效惯量。

片段 3：柔顺过程的奖励项（力尖峰、力变化率、刚度变化率）

def compliance_rewards(force_norm, force_prev, K_curr, K_prev_step, cfg):
    # 1) 力尖峰：只在超过安全阈值时罚，阈内完全不罚；避免"不敢接触"的保守策略
    #    平方罚让"超标一点点"和"超标很多"区别对待，梯度随超标量增长
    excess = max(0.0, force_norm - cfg["force_safe"])       # force_safe = 25 N
    r_peak = -2.0 * excess ** 2

    # 2) 力变化率（jerk 代理）：接触力突变 = 碰撞。65 N/s 是打磨工艺的常见平滑要求
    d_force = abs(force_norm - force_prev) / cfg["dt"]
    r_jerk = -0.01 * max(0.0, d_force - 65.0)

    # 3) 刚度变化率：变阻抗特有的不稳定性来源，超过限速再补一刀惩罚
    d_K = float(np.linalg.norm(K_curr - K_prev_step))
    r_dK = -0.001 * max(0.0, d_K - cfg["K_step_limit"])

    # 三项都是"过程惩罚"：只修行为不决定任务成败，所以量级远小于任务奖励（深度+完成）
    return r_peak + r_jerk + r_dK

解读：三个惩罚的共同特征是"阈值外才罚"，这是过程惩罚的标准形态。如果改成无阈值惩罚（比如直接罚 ‖F‖ 或罚 |ΔK|），最优策略会退化：力罚逼出"永远轻触"，刚度罚逼出"永远不变刚度"，柔顺行为无从学起。阈值设多少有依据：力安全阈值 25 N 来自工艺许用（与 042 章一致），力变化率 65 N/s 来自打磨工艺的表面质量要求，刚度限速与片段 2 的 max_rate 共用同一个数，奖励与硬约束同源，策略受到的信号才不会自相矛盾。量级上这三项每次最多贡献零点几分，远小于装配任务奖励（完成 +50），目的是"微调姿态"，任务目标仍由装配奖励主导：在完成装配的前提下，选择更柔顺的通过方式。

常见坑

  • 忘了重力补偿：阻抗控制的静态精度依赖力矩模型的正确性。没补偿时末端在自由空间也"软塌"（比如竖直方向总偏低 1–3 cm），策略会把这种系统性偏差当成任务误差去补，最后学到畸形的姿态。修复：先把重力/科氏补偿对接好，再做"悬空手推刚度测试"验证。
  • 刚度范围和位置环带宽冲突：高刚度（5000 N/m 以上）配低带宽位置环，会产生持续的低频振荡（听起来像"嗡嗡"），因为指令的刚度超过了执行器能实现的闭环刚度。修复：先测执行器能达到的最大稳定刚度，Kmax 取它的 0.5–0.7 倍。
  • 阻尼独立于刚度设定：为了让"退让更快"把 B 调小，结果接触后振荡多拍，力曲线出现振铃。修复：B 永远用临界阻尼公式联动，想加快响应就同时调大 K。
  • 刚度突变：策略每步把刚度从 100 跳到 5000，位置偏差 1 mm 时力瞬间增加 4.5 N，等效于"敲击"。修复：变化率限幅 + 处罚（片段 2、3），并在观测里给出当前刚度让策略意识到自己的状态。
  • 把阻抗当力控用：想看力跟踪效果却只调 Kd，结果静差大。阻抗控制不保证任何指定力，要精确力控制必须闭环（047 章）；阻抗的卖点是"接触行为可控"，不是"力精确"。修复：明确任务需求，力精度要求高的方向用混合力控，其余用阻抗。

练习与思考

  1. 固定 Kd = 500 N/m，把 Bd 分别取临界阻尼的 0.3、1.0、3.0 倍，记录接触-退出过程的力曲线形状，解释阻尼比的影响。★
    提示
    0.3 倍（ζ≈0.3）会振荡（欠阻尼），3 倍（ζ≈3）迟钝（过阻尼），1 倍最快无超调。用"接触时刻起，力进入 ±5% 带的时间"作为量化指标。
  2. 把各向异性系数设为"轴向 K=200、横向 K=5000"，对比各向同性 K=2000 时插装的力峰值与成功率。★★
    提示
    各向异性应显著降低力峰值（轴向吸收错位），同时保持横向定位精度（成功率不降）。注意检查横向误差的统计分布是否比各向同性版更窄。
  3. 让策略输出刚度但不做阻尼联动（B 固定 20 N·s/m），训练后观察力信号的频谱与训练稳定性。★★
    提示
    高刚度时阻尼比会掉到 0.2 以下，力曲线出现 10–30 Hz 的振铃；观察策略是否学会"回避高刚度"（刚度输出长期贴在最小值）。
  4. 设计一个"刚度课程"：写出每一阶段的刚度范围、切换判据与评估指标，并预测三个阶段各自的学习难点。★★★
    提示
    阶段 1 锁死中档学任务流程；阶段 2 解锁范围学柔顺；阶段 3 缩小间隙。切换判据建议用"成功率 + 力峰值分位数"双指标，避免策略靠硬碰硬冲高成功率。

小结

  • 阻抗控制的目标是"控制位置与力之间的动态关系"：Mdẍ + Bdẋ + Kd(x−xr) = Fext，三参数分别管惯性、振动、硬度。
  • 接触力由"机器人刚度与环境刚度中较小者"主导：Kd 比 Ke 低一到两个数量级，1 mm 错位才不会变成上百牛。
  • 因果方向决定选型：力矩接口用阻抗（运动→力），封闭位置环用导纳（力→运动）；D 与 K 用临界阻尼公式联动。
  • 变阻抗的正确接口是"sigmoid 有界映射 + 变化率限幅 + 阻尼联动"；刚度是 20 Hz 的慢变量，让 RL 只学"何时软、哪个方向软"。
  • 各向异性柔顺（轴向软、横向硬）是插装类任务的黄金配置；平滑性用阈值外罚（力尖峰、力 jerk、刚度变化率）表达，量级远小于任务奖励。
