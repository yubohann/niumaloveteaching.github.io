第 042 章：实现装配任务

把第 041 章的单次插拔扩展成"多零件、多阶段"的完整装配流程：用分阶段奖励、socket 系相对位姿观测与间隙课程学习，让策略走完对齐—插入—旋紧的整条动作链。

  • 主题：任务实现 / 接触丰富的装配
  • 相关组件：Isaac Sim / Isaac Lab / Stable-Baselines3（PPO）
  • 预计学时：55 分钟
  • 前置章节：第 041 章

学习目标

  • 理解装配任务的阶段结构（接近 / 对齐 / 插入 / 紧固），说清每个阶段的物理难点与可观测信号。
  • 掌握"势函数奖励塑形"（potential-based shaping）：知道它为什么能在不改变最优策略的前提下提供密集梯度。
  • 会设计 socket 局部坐标系下的相对位姿观测，并解释它比世界坐标观测更易泛化的原因。
  • 能根据配合间隙（clearance）设计课程学习与随机化范围，并预估难度变化量级。
  • 能定义可量化的装配成功判据（插入深度 + 横向误差 + 力峰值 + 保持时间），并做统计评估。
  • 理解为什么刚性位置控制在装配中会"爆力"，为第 047、048 章的力控与柔顺控制建立动机。

背景与动机

工业装配是机器人强化学习价值最高、也最难啃的场景之一：孔轴配合间隙通常只有 0.1–1 mm，接触刚度高达 105–106 N/m，轻微的对齐误差就会产生几十牛的接触力，失败模式还很多，卡死、刮伤、弹飞、斜插。第 041 章的插拔任务只做了"一次插入"；真实的装配是一条动作链：接近零件、找正姿态、插入、旋紧或卡扣，每一步的观测、奖励与终止条件都不同。

本章把装配从"一个动作"升级为"一条流水线"：你会学到分阶段奖励的设计方法、接触信息怎么进观测、间隙难度如何课程化。它同时是第 047 章（力控）与第 048 章（柔顺控制）的任务载体，那两章将解释本章刻意回避的问题：怎么让机器人在接触中"软"下来。

核心原理

1. 接触的多模态：为什么装配不是"精确定位"就够了

装配过程中零件对的接触状态在四个模式间跳变：自由（free）、碰撞（impact）、滑动（sliding）、卡阻（jamming）。四者之间的切换几乎是瞬时的：以 60 Hz 控制周期计，一个 16.7 ms 的步长里零件就能从"差 0.3 mm"变成"力超限"。这就是装配难的本质：接触状态的离散跳变与力反馈的强非线性。

把接触近似成弹簧，偏差 δ 与接触力 F 的关系为：

F ≈ kc · δ kc 为接触刚度，典型 105–106 N/m

代入数字：δ = 0.1 mm、kc = 5×105 N/m 时 F ≈ 50 N，已经超过小型机械臂的安全力上限。反过来看，如果末端表现为一个等效刚度 Kd = 2000 N/m 的弹簧（第 048 章的阻抗控制思想），同样的 0.1 mm 误差只产生 0.2 N 的力。这个对比解释了本章的第一个工程结论：装配任务里，位置控制的"硬"与力的不可控是同义词；观测里必须给策略力/力矩信息，否则它看不见接触。

2. 对齐误差分解与接触力方向信息

孔轴配合的几何误差可以分解成三个量：横向偏移 Δxy（目标 0.1 mm 级）、角向偏差 Δθ（目标 0.5° 级）、以及沿轴深度 d。当轴倾斜插入时，接触点偏离轴心，产生的不只是力还有力矩：

τ ≈ F × lc lc 为接触点相对末端参考点的力臂

力矩的符号与大小携带了"往哪修正"的信息：倒角（chamfer）把横向力转化成自动定心的滑入趋势，这也是人类插螺丝时"晃一晃"就进去的原因。策略要利用这份信息，观测里就必须同时有三个量的历史，力、力矩、以及上一时刻动作。经验上加入前一步动作能让接触策略的成功率提升 10–30 个百分点，因为它让策略"记得"自己是怎么把力做出来的。

3. 势函数奖励塑形：密集奖励为什么不改变最优策略

装配的稀疏奖励（成功 +1，其余 0）几乎不可训练；但随手加密集项容易把策略带偏。势函数塑形（Ng 等 1999 的经典结论）给出了安全的加稠方式：选一个状态势函数 Φ(s)，用差分塑形

r′(s, a, s′) = r(s, a, s′) + γ · Φ(s′) − Φ(s)

则任何有限 MDP 中，最优策略集合不变。直觉：差分项在一条完整轨迹上求和会望远镜式抵消，只剩 γTΦ(sT) − Φ(s0)，与路径无关；所以它只改变"走哪条路更受奖励"，不改变"终点在哪"。本章的 Φ 按阶段选取：接近阶段用距离的负值，对齐阶段用横向与角度误差的加权负值，插入阶段用深度减去误差惩罚。

4. 阶段门控：一种朴素但有效的奖励防作弊手段

多个密集项同时打开时，策略会找"套利路径"，例如侧向蹭着力传感器刷接触奖励、却从不真正对孔。解决方法是给每项奖励乘一个随阶段切换的 0/1 门控 gi(s)：

r = Σi gi(s) · wi · ri(s),   阶段机：接近 → 对齐 → 插入 → 紧固一次单向推进

门控让每个阶段只考核一个几何量，配合单向推进防止策略在两个阶段间来回横跳刷奖励。这本质上是一种人工"分层"，与第 055 章学出来的分级策略形成对照。

5. 间隙课程：难度不是线性的

配合间隙 c 不是线性地影响难度：孔轴的最小可插入条件近似要求横向误差 < c/2 且角度误差 < arctan(c/L)（L 为插入长度）。c 从 1 mm 降到 0.1 mm 意味着容差缩小 10 倍，而策略需要把误差控制在同一个绝对量级上，这个精度跃迁比"距离缩短 10 倍"难得多。因此课程设计往往按对数尺度推进间隙：5 mm → 2 mm → 1 mm → 0.5 mm → 0.2 mm，并在每个档位取得约 70% 成功率后再进入下一档。

6. 数值算例：倒角自定心力与插入速度预算

先算倒角"以力换容错"的机制。30° 倒角面上，轴向压入力 Fz 在倒角面产生法向力，其横向（定心）分量与轴向分量的比值约为 tan 30° = 0.577。也就是说 10 N 的压入在倒角上换来约 5.8 N 的定心推力；这份推力要与接触摩擦竞争，自定心能够发生的近似条件是 tan α > μ（α 为倒角半角）。摩擦随机化区间 0.1–0.4 全部落在 0.577 之下，最不利的 μ = 0.4 仍留有 0.577/0.4 ≈ 1.44 倍的余量。"倒角不是装饰"由此有了定量含义：它把"横向偏差必须小于 c/2"的几何门槛，放松成"自定心力能克服摩擦"的力学条件。如果倒角减到 15°，tan 15° = 0.268，在 μ = 0.4 时自定心失效，插入成功率会随摩擦档位明显分层，这正是评估要按摩擦分组报告的原因之一。

再算位移预算。间隙随机化下限 c = 0.2 mm 时，横向容差约 c/2 = 0.1 mm。控制 10 Hz、平移动作限幅 2 mm/步（设计规格）时，单个控制步最多横向移动 2 mm，是容差的 20 倍；把接触前 3 cm 的接近压到每步 0.5 mm（等效 5 mm/s），仍是容差的 5 倍。这组数字说明两件事：其一，亚毫米间隙下"一次对准再插"在开环意义上不现实，必须借助倒角与柔顺把误差滑进去；其二，末段减速梯度属于任务可学性的前提，无法省略。它同时解释了阶段划分的必要性：接近末段与对齐段的误差量级相差一个数量级以上，用同一套势函数同时考核两级尺度，等于对两级都没有有效考核，只有分开设势、按轴向距离门控，梯度才各自落在正确的尺度上。

把阶段势函数的权重代进量级核对。对齐阶段 Φ = −(100·‖Δxy‖ + 0.5·‖Δθ‖)：横向误差 1 mm 时位置项 0.1，角度误差 0.01 rad（约 0.6°）时角度项 0.005，位置项是角度项的 20 倍。"先对上位置再摆正"的排序不存在于奖励的文字里，它存在于这两个系数的比例里；如果希望"先正角度再对位置"，把两个系数反过来即可，全部改动只有一行配置。插入阶段 Φ = 50·d − 200·‖Δxy‖：深度 15 mm 时深度项 0.75，1 mm 的横向残差罚 0.2；深度推进 4 mm 的收益（0.2）恰好抵得上 1 mm 的横向偏离，这个"4 mm 深度换 1 mm 横向"的兑换率就是"宁慢勿歪"的权重表达。检查势函数还有一条纪律：相邻阶段在切换点的势函数值要连续可控，跳变会给出一笔与行为无关的"横财"或"横罚"，训练中表现为切换线附近的来回振荡。把时间轴也接上核对：15 mm 的插入行程按每步 0.5 mm 推进需要 30 个控制步、约 3 s，8 s 的超时上限留给接近与对齐约 5 s，与"接近 3 cm、对齐压到 1 mm/0.5°"的自然耗时相符；若发现训练后期策略"卡着超时边缘"完成插入，优先检查末段位移限幅是否反而拖慢了流程。

实现思路与设计

装配环境的搭建顺序如下，每一步都给出理由：

  1. 场景与资产：带孔的底座（socket）固定在桌面，轴（peg）由机械臂夹持。孔口加 30° 倒角，倒角不是装饰，它把小的横向误差转化为自定心力，让任务在 0.2 mm 间隙下仍然可学。
  2. 控制模式：机械臂用关节 PD 的位置控制（第 003、004 章），但末端动作用"位姿增量 + 小增益"表达，本质上已是很弱的阻抗，避免刚性碰撞直接爆力。完整方案在 048 章展开。
  3. 动作空间：10 Hz 策略输出 6 维位姿增量（前 3 维平移、后 3 维旋转向量），每维限幅 ±2 mm / ±1°。为什么慢？接触过程需要"观察-反应"的余量，10 Hz 给反馈留出 6 个物理步。
  4. 观测：socket 系下的相对位置（3）、相对旋转向量（3）、力/力矩各 3 维、夹持状态、上一步动作（6），共约 19 维。为什么不给世界坐标？世界坐标要求策略把"孔在哪"记成绝对位置，随机化桌面位置后就失效；相对坐标让策略学"怎么对准"，与位置无关。
  5. 奖励：分阶段的势函数差分 + 每步时间罚 −0.001 + 完成奖励（仅在低力深插时发放 50）。三项分工：势函数给方向，时间罚逼速度，完成奖励给终点。
  6. 终止：深度达标且稳定判定成功；力峰值超过 60 N 视为过载终止；超时 8 s 终止。过载终止是安全约束的雏形（第 069 章安全 RL 展开）。
  7. 随机化：间隙 0.2–1 mm、摩擦系数 0.1–0.4、孔位 ±5 mm 位置 / ±3° 姿态、轴的初始位姿。间隙与摩擦直接决定接触的行为，是必随机化的两项。

设计思维：为什么"成功"必须多个条件同时成立？

只看插入深度会把"斜插进去一半"也算成功，只看力不超限会把"悬在空中没碰到"算成功。工业上判定装配成功至少要满足：深度达标 + 横向/角向误差达标 + 力在许用范围内 + 连续保持若干控制周期。四个条件各堵一个失败模式，最后一条（保持时间）用于去抖，防止碰撞瞬间的"假成功"污染训练数据。

关键代码与解读

片段 1：socket 系相对位姿观测（含力/力矩对齐）

import numpy as np

def assembly_obs(socket_pos, socket_quat, peg_pos, peg_quat, ft_wrench, prev_action):
    # 把 peg 位姿转换到 socket 坐标系：策略只关心"零件之间"的关系，不关心桌子放在哪
    R_s = quat_to_matrix(socket_quat)      # socket 姿态 → 3x3 旋转矩阵（本课程约定的辅助函数）
    R_p = quat_to_matrix(peg_quat)
    rel_pos = R_s.T @ (np.array(peg_pos) - np.array(socket_pos))  # 平移差投影到 socket 系
    rel_R = R_s.T @ R_p                    # 相对姿态：消掉 socket 的绝对朝向
    rel_rotvec = matrix_to_rotvec(rel_R)   # 旋转向量 3 维，比四元数更适合直接送进 MLP
    # 力/力矩必须用同一个坐标系表达，否则同一份物理量在不同朝向下"方向"完全不同
    ft_local = np.concatenate([R_s.T @ ft_wrench[:3], R_s.T @ ft_wrench[3:]])
    # 上一步动作作为观测的一部分：接触任务里策略需要"记得自己刚做了什么"（延迟反馈）
    return np.concatenate([rel_pos, rel_rotvec, ft_local, prev_action])

解读：这段代码的核心是三次消元，用 RsT 消掉 socket 的绝对位置和朝向，让观测只保留相对几何量。做与不做的差别很大：如果直接喂世界坐标，随机化桌面位置后策略等价于一个需要重新学习的任务；相对坐标下，同一策略在所有桌面位置上通用。第二个细节是旋转向量替换四元数：四元数 q 与 −q 表示同一姿态，网络会把它们当成两个不同的输入，旋转向量没有这个二义性。第三点：力/力矩被旋转到 socket 系，接触力的方向才具有"物理含义"（例如 +z 是压入方向），策略才能学到"力大就往反方向修正"这样的一般规律。

片段 2：分阶段势函数奖励

def assembly_reward(state, prev_potential, stage):
    # 每个阶段只考核一个几何量：避免多项奖励同时打开时的"套利"行为
    if stage == "approach":                       # 阶段 1：15 cm 尺度，速度优先
        potential = -2.0 * np.linalg.norm(state["xy_error"])
    elif stage == "align":                        # 阶段 2：把误差压到 1 mm / 0.5 度以内
        potential = -(100.0 * np.linalg.norm(state["xy_error"])
                      + 0.5 * np.linalg.norm(state["rot_error"]))
    else:                                         # 阶段 3：插入，深度越大越好，误差仍有惩罚
        potential = 50.0 * state["depth"] - 200.0 * np.linalg.norm(state["xy_error"])

    # 势函数差分：r_shape = gamma * Phi(s') - Phi(s)，保证最优策略集合不变
    r = 0.99 * potential - prev_potential
    r -= 0.001                                    # 每步时间罚：逼策略尽快完成，防止原地徘徊

    if state["inserted"] and state["force_norm"] < 30.0:
        r += 50.0                                 # 完成奖励只在"低力深插"时发放，堵死硬砸路线
    return r, potential                           # 返回新势能存下来给下一步用

解读：注意 r = 0.99 * potential - prev_potential 这一行，它就是 γΦ(s′)−Φ(s) 的直译，系数必须与训练所用折扣因子一致（这里是 0.99），否则理论上的策略不变性会被破坏。第二个设计是完成奖励附加了 force_norm < 30 N 的条件：如果只发"成功"奖励，策略发现"用力砸进去"也算成功，而真机上这会把零件砸变形；把力条件写进奖励，等于把工艺约束前移到了学习问题里。第三个细节是时间罚 −0.001 的尺度：它必须远小于势函数的单步变化量（对准阶段一步约 0.05–0.5），否则策略会"抢时间"而放弃精细对齐。

片段 3：装配成功判据（多条件 + 去抖）

class AssemblySuccessMonitor:
    # 装配成功不能只看深度：深度 + 横向误差 + 力上限 + 连续保持，四条件缺一不可
    def __init__(self, depth_tol=0.015, xy_tol=0.001, force_limit=25.0, hold_steps=15):
        self.depth_tol = depth_tol        # 15 mm：插入深度下限，按图纸公差取
        self.xy_tol = xy_tol              # 1 mm：接触区允许的横向残差
        self.force_limit = force_limit    # 25 N：工艺许用力，超过视为损伤件
        self.hold_steps = hold_steps      # 15 步（控制周期 10 Hz 即 1.5 s）保持稳定
        self.hold = 0                     # 连续满足条件的计数器

    def update(self, depth, xy_err, force_norm):
        ok = (depth > self.depth_tol and xy_err < self.xy_tol
              and force_norm < self.force_limit)
        # 去抖：碰撞瞬间可能恰好"深、正、轻"各满足一帧，连续保持才判定成功
        self.hold = self.hold + 1 if ok else 0
        return self.hold >= self.hold_steps

解读：这个监视器同时充当训练终止条件与评估指标。四个阈值都有物理来源：深度 15 mm 来自配合长度，横向 1 mm 来自公差带，力 25 N 来自工艺规范，保持 1.5 s 是为了滤掉碰撞瞬态的误判。注意判定用的是接触区残差（对孔后的横向误差），不是接近时的距离，两者数值量级差一个数量级，混用会让成功率统计完全失真。工程上建议把 hold 计数也记进日志：成功前的平均保持时间能反映策略的"稳"度，是比成功率更细的指标。

常见坑

  • 位置控制直插、力瞬间爆表：症状是仿真里零件弹飞、真机上过载报警。原因是刚性位置环把毫米级误差变成几何约束冲突，求解器用巨大接触力"修正"。修复：降低末端等效刚度（增益调小、或改用 048 章的阻抗/导纳外环），并在奖励里加力上限约束。
  • 参考系混用：观测用世界系、奖励用相对系、成功判据又用 socket 系，三者数值对不上，策略学到一半"精神分裂"。症状是训练曲线高方差、成功率卡住。修复：全链路统一在 socket 系下计算，写一个 to_socket_frame() 工具函数集中管理。
  • 奖励套利：接触奖励在未对孔时也能被"蹭"出来，策略学会侧向摩擦刷分。症状是深度指标停滞、接触奖励却持续为正。修复：奖励加门控（阶段 + 距离条件），主评测指标改用成功率。
  • 间隙忘了随机化：训练只用固定 0.5 mm 间隙，换到 0.2 mm 直接全败。修复：随机化间隙与倒角尺寸，并用对数尺度课程；评估时按间隙分档报告成功率。
  • 成功判据太松：只看深度不看横向误差，斜插也算成功，统计出的 90% 成功率在真机上会变成 30%。修复：用片段 3 的四条件判据，并且在评测时同时记录峰值力分布。

练习与思考

  1. 把间隙从 0.2 mm 调到 2 mm 各训练一遍，记录"达到 70% 成功率所需的训练步数"。画出间隙—步数曲线，并解释为什么前段近似对数、后段近似平坦。★★
    提示
    换算一下最小可插入条件：横向误差容限约为间隙的一半。容限每缩小一半，策略需要提升的绝对精度也翻倍，但训练步数增长往往快于线性。
  2. 删掉观测里的力/力矩（其余不变），预测并验证配对成功率与峰值力的变化。★
    提示
    没有力信息的策略只能靠位姿盲插，接触瞬间无法反应。重点观察峰值力分布：它应当显著变宽、右尾变长。
  3. 把势函数中的 Φ 换成"只奖励成功"的稀疏版本，训练 10 万步后对比。解释势函数塑形在早期探索中的关键作用。★★
    提示
    稀疏奖励下随机探索命中 0.5 mm 公差带的概率极低，PPO 的梯度几乎为零。可先用小间隙环境验证"稀疏奖励同样可学"，再回到原间隙。
  4. 给完成奖励改成"力越小、奖励越高"的连续形式（例如 50·exp(−F/10)），预测策略行为的变化，并讨论它与固定阈值版的优劣。★★★
    提示
    连续版给策略一条"轻放"的梯度路径，但会削弱"尽快完成"的压力，需要配合时间罚重新调权重。
  5. 设计一个两阶段装配（插轴 → 旋 90° 卡扣）的阶段机与门控表，写出每阶段的切换判据和奖励项。★★★
    提示
    紧固阶段需要同时约束扭矩上限并提供旋转进度奖励；切换判据要用"深度稳定 + 横向达标"，避免在晃动中提前进入旋紧。

小结

  • 装配难在接触状态的多模态跳变：F ≈ kc·δ，105 N/m 的刚度让 0.1 mm 误差变成 50 N 的力，力的可测、可控是任务成立的前提。
  • 观测统一用 socket 系相对位姿 + 力/力矩 + 上一步动作：消掉绝对位置、避免四元数二义性、给策略反应接触的窗口。
  • 势函数差分塑形 γΦ(s′)−Φ(s) 提供密集梯度且不改变最优策略；阶段门控防止多项奖励互相套利。
  • 间隙课程按对数尺度推进，每档 70% 成功率再晋级；间隙与摩擦是必随机化的两个参数。
  • 成功判据 = 深度 + 误差 + 力限 + 保持时间，四条件各堵一个失败模式，保持时间负责去抖。
