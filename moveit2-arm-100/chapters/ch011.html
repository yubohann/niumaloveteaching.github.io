第 011 章：笛卡尔空间运动实现

本章让末端沿指定轨迹运动：位姿目标的表达、直线段的离散化与逐点逆解，以及分数、步长、跳变阈值三个决定成败的参量。

  • 主题：运动实现 / 笛卡尔空间规划
  • 关键机制：位姿目标与逆解、笛卡尔路径离散化、跳变阈值保护
  • 预计学时：60 分钟
  • 前置章节：第 010 章

学习目标

  • 掌握末端位姿目标的表达：位置、姿态四元数与参考坐标系。
  • 理解笛卡尔路径的求解机制：直线离散化、逐点逆解、中途失败的分数回报。
  • 掌握步长（eef_step）与跳变阈值（jump_threshold）的作用，能按任务选择取值。
  • 会处理分数小于 1 的结果，能区分"拒绝执行"与"截断使用"两种策略的前提。
  • 能把关节空间转移与笛卡尔空间工序组合成完整任务，并对每一段给出选择依据。

背景与动机

有一类任务对末端的运动形状有硬性要求：沿桌面直线下降抓取、沿焊缝匀速推进、轴向插入装配。这类运动的共同特征是"路径形状即工艺要求"，关节空间的自由连线无法满足，必须在笛卡尔空间里把轨迹显式指定出来。

笛卡尔空间运动比关节空间多一层逆运动学转换，随之引入新的失败模式：目标位姿不可达、逆解在途中断裂、多解之间发生跳变。本章的核心是理解这些失败模式的表现形式并建立处理策略。由于路径逐点由逆解拼成，它的可靠性与目标的位姿设计直接相关；先看穿机制，再谈调参，顺序不能颠倒。

核心原理

本节解释笛卡尔路径的求解机制、三个关键量（步长、跳变阈值、分数）的数学含义，以及它与关节空间运动的分工。

1. 位姿目标与逆运动学

笛卡尔目标是一组末端位姿：三维位置加三维姿态，姿态通常用四元数表达以避免欧拉角的万向节问题。求解时，逆运动学在关节空间里寻找满足位姿约束的关节向量。数值求解器从种子状态出发迭代逼近，因此同一目标在不同种子下可能收敛到不同解，呈现肘部上下的构型差异。

qgoal = IK(Ttarget, qseed)，目标可达且数值收敛时得到解 位置可达、姿态可达、连同限位约束共同构成解存在的条件

工作空间边界附近与奇异位形附近是求解的两个困难区：前者可能无解，后者附近关节角变化剧烈且对微小位姿扰动敏感。工程上把期望目标设在工况需要的位置上，同时借助种子状态引导到希望的构型分支，是位姿目标设计的基本思路。种子状态的选择会在第 052 章的求解器对比中进一步展开。

2. 笛卡尔路径：直线离散化加逐点求解

让末端沿直线运动并没有解析的关节表达式可用，标准实现是数值离散：在起点位姿与目标位姿之间按固定步长插入中间位姿，对每个中间位姿求逆解，把得到的关节向量串成关节空间路径。

  1. 计算起点与目标的位姿差，按步长切分为若干采样位姿。
  2. 对每个采样位姿调用逆解，得到对应的关节向量。
  3. 检查相邻关节向量之间的距离，超过跳变阈值则判定为解跳变，中止。
  4. 返回已完成的采样比例，记为分数（Fraction）。

分数是这套机制做出的核心承诺：分数为 1 表示整条路径全部求解成功；小于 1 表示在某个位置断裂，已完成部分保持连续。分数既是质量指标也是安全指标：默认策略是分数不足时拒绝执行，除非任务经过分析后确认部分路径本身可用。

3. 步长与跳变阈值

步长决定离散密度。0.2 m 的直线在 0.01 m 步长下产生约 21 个采样点，在 0.05 m 步长下只有 5 个。步长偏大时，相邻采样点之间的直线近似误差变大，中间区段的碰撞检查粒度变粗；步长偏小时，逆解调用次数成比例上升，单条路径的求解耗时增加。

跳变阈值保护的是关节空间的连续性。逆解的多解分支之间可能存在突变：相邻两个采样位姿位置差异极小，求解结果却跳到另一分支，关节向量距离很大。若不设防，串出来的路径会出现瞬时的姿态跳变，执行侧表现为剧烈动作。阈值按相邻解在关节空间中的距离度量：

d(qk, qk+1) = 各关节角差的加权范数；段距超过 jump_threshold × 平均段距时判为跳变 阈值取 0 表示禁用保护；启用时典型量级在 5 附近，以对应版本约定为准

阈值的取向是"宁可误停、不可放行"：误停的代价是分数略降、调整种子重试；放行的代价是执行时的关节跳变，可能危及设备与工件。在确认目标位姿干净、求解稳定的工序中，把阈值禁用可以避免误停，但应在仿真中充分验证后再上真机。

4. 与关节空间运动的分工

两类空间构成互补分工，各司其职。典型任务结构是"转移加工序"：工位之间的移动用关节空间，速度快、成功率高；进入工序段后切换笛卡尔空间，只在需要形状约束的区间使用直线路径。

维度关节空间笛卡尔空间
目标形式关节角向量末端位姿或位姿序列
路径形状末端轨迹不可预测末端沿指定直线运动
求解方式构型空间搜索离散加逐点逆解
主要失败源限位与碰撞逆解不存在、分支跳变、中途碰撞
典型任务大范围转移、回零下降抓取、焊接、插装

组合原则可以浓缩为一句：自由移动用关节空间，受约束段用笛卡尔空间，两段之间用关节空间路径衔接。衔接处若要求速度连续，需要在轨迹层做处理，第 015 章给出工具。

实现思路与设计

笛卡尔运动的实现按"定位姿、设精度、算路径、查分数、再执行"五步推进。

  1. 确定参考坐标系：位姿在哪个坐标系下表达，决定"下降"等方向语义的正确性。
  2. 构造目标位姿：位置与姿态分别设定；姿态优先用工具坐标系语义描述（如工具朝下）。
  3. 选择精度参数：步长 0.01 m 起步；跳变阈值按工序稳定性启用或禁用。
  4. 计算路径：调用笛卡尔路径接口，读取分数与错误信息。
  5. 判定与执行：分数达标才执行；低于阈值时分析断裂原因后再调整。

设计决策：为什么分数不足默认拒绝执行？

分数小于 1 的轨迹终点停在断裂前的采样位姿，它是一个"半程位置"：对抓取工序而言，半程下降可能落在工件正上方也可能停在干涉区内，语义上不可控。默认拒绝把不确定性挡在执行之前；确需使用部分路径时，应同时满足两个条件：断裂点之后无工序义务，且部分路径终点对后续动作安全。两个条件都写进任务逻辑并复验后，截断使用才成立。

关键代码与解读

本节给出三段片段：位姿目标设置、笛卡尔路径调用与分数处理、直线采样点的生成。

片段 1：位姿目标的表达

// 位姿的语义由参考坐标系决定：先声明参考系，再给位置与姿态
group.setPoseReferenceFrame("base_link");

geometry_msgs::msg::Pose target;
// 位置取当前末端位姿再沿 Z 下移 0.10 m：下降抓取的典型目标
geometry_msgs::msg::PoseStamped current = group.getCurrentPose("flange");
target.position.x = current.pose.position.x;
target.position.y = current.pose.position.y;
target.position.z = current.pose.position.z - 0.10;

// 姿态用四元数表达：工具轴朝下为常见工序姿态，避免欧拉角歧义
tf2::Quaternion q;
// 绕 X 轴翻转 180 度：工具轴（法兰 +Z 约定）指向 base_link 的 -Z，即朝下
q.setRPY(3.1416, 0.0, 0.0);   // 工具轴定义与法兰不一致时按实际模型换算
target.orientation.x = q.x();
target.orientation.y = q.y();
target.orientation.z = q.z();
target.orientation.w = q.w();

// 位姿目标走逆解：容差分开设置，姿态容差过紧是常见失败源
group.setGoalPositionTolerance(0.005);      // 5 mm
group.setGoalOrientationTolerance(0.01);    // 约 0.6 度
group.setPoseTarget(target, "flange");

解读：位姿目标的三段信息缺一不可。（1）参考坐标系决定数值语义：同样的坐标分量在不同参考系下指向完全不同的方向，跨坐标系复用目标前必须换算。（2）从当前位姿派生目标（当前点向下偏移）是工序编程的稳健写法：无须绝对定位，工件或桌面轻微变更时目标自动跟随。（3）位置容差与姿态容差分开设置：姿态容差对逆解收敛的影响通常更大，数值上比位置容差更敏感，需要单独评估。

片段 2：笛卡尔路径调用与分数处理

// 路点列表：单点列表表示"到该位姿的一条直线"，多点表示折线工序
std::vector<geometry_msgs::msg::Pose> waypoints{target};

const double eef_step = 0.01;          // 步长 1 cm：精度与逆解次数的平衡
const double jump_threshold = 5.0;     // 启用分支跳变保护
moveit_msgs::msg::RobotTrajectory trajectory;
// 返回值是分数：1.0 表示整条路径求解成功
double fraction = group.computeCartesianPath(
    waypoints, eef_step, jump_threshold, trajectory, true);

RCLCPP_INFO(node->get_logger(), "笛卡尔路径分数 %.3f", fraction);
if (fraction >= 0.95) {
  // 分数达标：把轨迹包装进 Plan 后执行，接口与关节空间一致
  moveit::planning_interface::MoveGroupInterface::Plan plan;
  plan.trajectory_ = trajectory;
  group.execute(plan);
} else {
  // 分数不足：不执行半程轨迹；先诊断断裂位置
  RCLCPP_WARN(node->get_logger(),
              "路径在约 %.0f%% 处断裂：检查可达性与跳变阈值", fraction * 100.0);
}

解读：这段代码体现"先算路、后判定、再执行"的工序纪律。（1）步长与阈值是求解参数，在调用时传入，与执行参数、规划参数分离。（2）第五个布尔参数开启碰撞检测：笛卡尔路径同样要经过场景校验，投产时不应关闭。（3）分数分支的输出给出断裂比例，把它与几何直觉对照（例如断裂恰在工作空间边缘）是定位问题的最快路径；同时注意笛卡尔路径返回的轨迹可能需要再经过时间参数化才能满足控制器的速度约束，第 015 章展开这一环节。

片段 3：直线采样点生成

import numpy as np

def line_waypoints(p_start, p_end, step=0.01):
    """沿直线按步长离散位置点，返回包含两端点的列表。

    step 控制离散密度：0.2 m 直线在 0.01 m 步长下约 21 个点；
    点列将作为笛卡尔路径的输入，逐点需要逆解求关节向量。
    """
    p_start = np.array(p_start, dtype=float)
    p_end = np.array(p_end, dtype=float)
    length = float(np.linalg.norm(p_end - p_start))
    # 段数向上取整：确保最后一段不超过步长，端点严格落在目标上
    n = max(int(np.ceil(length / step)), 1)
    return [p_start + (p_end - p_start) * (i / n) for i in range(n + 1)]

# 自检：直线长度与采样密度是否符合工序预期
pts = line_waypoints([0.30, 0.0, 0.35], [0.30, 0.0, 0.15], step=0.01)
print(f"采样点数 {len(pts)}，首点 {pts[0]}，末点 {pts[-1]}")

解读：采样点的生成逻辑与笛卡尔路径接口内部的离散步骤一致，先用脚本演练有助于建立参数直觉。（1）段数向上取整保证"每段不超过步长、端点严格命中"两个性质，与图元拼接的端点纪律一致。（2）生成的只是位置序列，完整路点还需要姿态序列；姿态的插值方式（球面插值）影响末端转角路径，在第 015 章与轨迹插值一并讨论。（3）把采样逻辑独立成函数，便于在任务层预估逆解调用次数，进而预估单条路径的求解耗时量级。

常见坑

  • 忽略分数直接执行：半程轨迹终点落在不确定位置，后续工序全部失准。修复：分数低于阈值即拒绝执行并诊断断裂点。
  • 跳变阈值设置过小：正常的大步长解被误判为跳变，分数骤降到一半以下。修复：先禁用阈值排除误判，确认无误后恢复并逐步收紧。
  • 步长过粗：直线近似误差明显，工序精度不达标。修复：按工序精度要求选步长，0.01 m 步长适配毫米级工序。
  • 目标姿态超出可达姿态空间：位置可达但姿态无解，分数停在早期采样点。修复：把姿态向工具工作范围中心回退，或接入冗余构型重新选解。
  • 坐标系语义混淆：在世界坐标系下计算目标却按末端坐标系理解，位移方向偏离。修复：位姿构造的第一行显式声明参考系，与坐标系检查表对照。

练习与思考

  1. 计算：0.30 m 的直线在 0.01 m 与 0.03 m 两种步长下各产生多少采样点？对照说明逆解调用次数与路径精度的变化。★
    提示
    段数分别为 30 与 10，采样点为段数加一；调用次数按比例变化，精度误差在采样点之间达到峰值。
  2. 比较位姿目标与关节目标实现的两次规划，记录失败时的错误信息差异，并解释错误信息与求解方式的关系。★★
    提示
    位姿目标的失败信息可能来自逆解环节或规划环节，两类共存；关节目标只有规划环节的失败信息，定位更直接。
  3. 预测实验：同一直线路径，分别在跳变阈值 0 与 5.0 下计算，比较两次的分数与轨迹路点数。若某次分数明显更低，指出断裂位置的几何特征。★★
    提示
    阈值启用时，靠近奇异位形的采样点附近更容易触发中止；禁用时同一路径往往分数更高，但需要仿真确认真实连续性。
  4. 设计题：为一个"接近桌面、直线下降、抓取、直线提升"的工序设计运动方案：标出每个阶段使用的空间类型、关键参数与验收指标（分数、容差、速度缩放）。★★★
    提示
    接近段用关节空间省时；下降与提升段用笛卡尔空间并设分数阈值 0.95、步长 0.01 m；抓取段涉及末端执行器，属于第四篇内容，此处留出接口即可。

小结

  • 位姿目标由位置与四元数姿态构成，参考坐标系决定数值语义；逆解存在性与种子状态相关。
  • 笛卡尔路径按步长离散、逐点逆解，分数记录完成比例，是质量与安全双重指标。
  • 跳变阈值保护关节空间连续性，宁可误停不可放行；步长在精度与求解代价之间平衡。
  • 组合原则：自由移动用关节空间，受约束工序段用笛卡尔空间，衔接由关节空间路径承担。
