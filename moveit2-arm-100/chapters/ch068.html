第四篇 · 抓取与操作任务

第 068 章：动态抓取策略

目标在运动时的抓取问题：把抓取从静态位姿扩展为时间维上的一次拦截，用恒速方程与卡尔曼预测求拦截点，用相对速度匹配与触发判据保证会合质量。

  • 主题：抓取任务 / 动态抓取（Dynamic Grasping）
  • 关键机制：拦截点求解 / 卡尔曼预测 / 触发时序与速度匹配
  • 预计学时：55 分钟
  • 前置章节：第 067 章

学习目标

  • 理解动态抓取与静态抓取的结构差异：时间成为显式变量，抓取窗口由目标运动速度与机械臂动作时长共同决定。
  • 掌握恒速模型下的拦截点求解：二次方程的建立、判别式的物理含义与最早可行根的选择。
  • 掌握卡尔曼滤波（Kalman Filter）在抓取预测中的应用：状态模型、观测修正与超前量设计。
  • 会设计触发判据与相对速度匹配条件，能说明接近段与目标的速度差为什么要控制在 0.05 m/s 以内。
  • 能诊断追不上、抓早、抓晚、多次触发四类动态抓取故障。

背景与动机

前几章的抓取目标静止在桌面上，规划可以先用足规划时间再执行。当目标由传送带、移动平台或人手携带时，目标位姿成为时间的函数，抓取问题从"寻找位姿"变为"在正确时刻到达正确位置"。时间预算开始起作用：感知延迟、规划时间、执行时间共同构成机械臂的动作时长，超过预算就会错过拦截点。

动态抓取在 MoveIt2 生态中的实现位置与静态抓取相同：规划与执行仍由 move_group 提供，动态部分由任务层承担，包括状态估计、拦截点计算、触发判定与接近段速度规划。本章聚焦任务层的算法与参数，不引入额外规划器。

本章与第 069 章的衔接关系：动态抓取的候选位姿由拦截点之后的运动学评估决定，姿态优化需要考虑目标速度方向与接近方向的夹角，评分函数中将增加时间项。

核心原理

1. 动态抓取的问题结构

静态抓取的时间预算只需覆盖规划与执行；动态抓取还要把"目标在这段时间内的位移"纳入计算：

时间项典型量级说明
感知延迟30–100 ms从采样到状态估计输出
规划时间50–500 ms任务层的拦截计算与运动规划
执行时间0.3–1.5 s从当前位置到拦截点的运动
抓取窗口0.1–1 s可抓区域长度除以目标速度

三种策略按目标速度选择：等待式要求目标存在停点，机械臂在停点作业；跟踪式适合 0–0.1 m/s 的慢速目标，末端跟随目标并伺机闭合；拦截式适合 0.1–1 m/s，预测目标未来位置并提前启动。策略选择的依据是抓取窗口与动作时长的比值：窗口小于动作时长的两倍时，跟踪式的可用时间已经不足，必须采用拦截。

2. 恒速模型下的拦截点求解

设目标当前位姿 p0、速度 v（恒速假设），机械臂末端当前位置 pe、可达最大速度 vmax。要求存在时刻 T 使末端恰好抵达目标位置，即距离等于 vmax·T：

|d + vT| = vmax T，d = p0 − pe 展开为关于 T 的二次方程：(|v|2 − vmax2) T2 + 2 (d·v) T + |d|2 = 0

解的结构给出物理判断：当 |v| ≥ vmax 时二次项系数非负，方程可能无正根，无正根表示目标比机械臂末端更快且正沿背离方向远离，同向追赶不可行；目标迎向运动时仍可能相遇；判别式为负同样无解。两个正根中取较小者作为最早拦截时刻，对应"先去最近的相遇点"。得到的拦截位置为 p0 + vT，送入可达性与碰撞检查后作为抓取位姿候选。

计算代价低是该模型的工程价值：一次二次方程求根只需数十次浮点运算，可以在每个控制周期重算，作为跟踪回路的实时外环。

3. 预测、滤波与超前量

真实测量含噪声且存在延迟，直接用差分速度会放大噪声。卡尔曼滤波用状态向量 [位置, 速度] 与匀速过程模型做最优估计：

x̂k|k−1 = F x̂k−1，F = [[1, Δt], [0, 1]] 位置更新为"上一位置加估计速度乘时间步"，速度由位置观测序列渐进修正；预测协方差随过程噪声 q 增长

预测拦截点时使用总超前量：感知延迟加规划执行时间再乘以估计速度，把状态估计外推到抓取瞬间。过程噪声 q 与观测噪声 r 的比值决定滤波特性：q 小、r 大时估计平滑但滞后，适合匀速目标；q 大、r 小时响应快但抖动大，适合机动目标。模型失配的监控指标是新息（Innovation）序列：目标突然转向或加速时新息超出正常范围，此时应暂停抓取并重新等待合适的窗口。

4. 触发时序与相对速度匹配

触发判据需同时成立：拦截点在工作空间内且无碰撞、剩余时间不小于动作时长、姿态可满足接近方向要求。三个条件都满足才启动抓取序列。

Δt剩余 ≥ κ · tarm，κ 取 1.2–1.5 tarm 为任务层统计的实际动作时长；κ 为安全余量系数，覆盖规划时间波动

抓取瞬间末端速度与目标速度之差称为相对速度。相对速度过大时，夹爪与目标之间产生冲击与滑移：冲击力约等于相对动量除以接触时间，滑移则由摩擦锥被瞬时打破引起。把相对速度控制在 0.05 m/s 以内，可使冲击与滑移都落在夹持力余量内；匹配方式是让接近段末速度跟随目标速度的方向与大小，或选择目标速度较低的窗口（例如传送带降速段）。

实现思路与设计

动态抓取任务层的实现步骤：

  1. 状态估计：目标位姿进入卡尔曼滤波，输出位置与速度估计；传感器帧统一变换到规划坐标系，时间戳对齐。
  2. 拦截计算：解二次方程得到最早拦截时刻与位置，必要时对多目标逐个求解。
  3. 可行性检查：拦截点可达性、碰撞、接近方向与目标表面法向的夹角。
  4. 触发判定：按剩余时间与安全系数决定启动时刻，触发后锁定并进入冷却期。
  5. 接近段规划：末速度匹配目标速度，直线段沿接近方向进入，相对速度阈值 0.05 m/s。
  6. 抓取确认：复用第 066 章的双信号确认；失败时回到状态估计进行下一次尝试。

设计决策：为什么采用固定最大速度的保守估计？

拦截方程假设末端以最大速度直线趋向拦截点，这是保守估计：真实轨迹受关节速度与加速度约束，实际到达时间不短于该估计。用保守估计决定触发时刻，触发后仍有余量吸收规划波动；若换用乐观估计，触发时刻会推迟到没有回旋裕度的位置，感知或规划的轻微波动都会导致错过窗口。

关键代码与解读

片段 1：恒速目标的最早拦截时间

import math

def intercept_time(p_e, p_0, v, v_max):
    """解 |d + vT| = v_max·T 的最小正根；无解返回 None。"""
    dx, dy, dz = p_0[0] - p_e[0], p_0[1] - p_e[1], p_0[2] - p_e[2]
    a = v[0] * v[0] + v[1] * v[1] + v[2] * v[2] - v_max * v_max
    b = 2.0 * (dx * v[0] + dy * v[1] + dz * v[2])
    c = dx * dx + dy * dy + dz * dz
    if abs(a) < 1e-9:                  # 目标速度接近上限：退化为一次方程
        return -c / b if b < 0.0 else None
    disc = b * b - 4.0 * a * c
    if disc < 0.0:
        return None                     # 判别式为负：运动学上无法相遇
    r1 = (-b - math.sqrt(disc)) / (2.0 * a)
    r2 = (-b + math.sqrt(disc)) / (2.0 * a)
    cands = [t for t in (r1, r2) if t > 1e-6]   # 只保留未来时刻的根
    return min(cands) if cands else None

def intercept_point(p_0, v, T):
    """由恒速模型外推拦截位置。"""
    return (p_0[0] + v[0] * T, p_0[1] + v[1] * T, p_0[2] + v[2] * T)

解读：（1）二次项系数 a 的符号包含物理判断：目标速度模长超过末端速度上限时，方程的正根可能消失，代码由"候选根为空"自然表达"追不上"。（2）退化分支处理目标速度恰好等于上限的情形，此时方程降为一次，仅当目标朝向末端运动（b 为负）才有正解。（3）取最小正根对应最早相遇点，物理含义是尽快会合、缩短目标暴露时间；若应用偏好更平稳的会合点，可改用较大正根并同步调整触发策略。

片段 2：一维匀速卡尔曼滤波

class KF1D:
    """一维匀速卡尔曼滤波：状态 [位置, 速度]，观测为位置。"""
    def __init__(self, pos, p_vel=1.0, r=1e-4):
        self.x = [pos, 0.0]              # 初始速度未知，置零并由观测修正
        self.P = [[r, 0.0], [0.0, p_vel]]  # 初始协方差：速度不确定性大

    def predict(self, dt, q=1e-4):
        p00, p01, p10, p11 = self.P[0][0], self.P[0][1], self.P[1][0], self.P[1][1]
        self.x = [self.x[0] + self.x[1] * dt, self.x[1]]   # 匀速状态推进
        self.P = [[p00 + dt * (p01 + p10) + dt * dt * p11 + q,
                   p01 + dt * p11],
                  [p10 + dt * p11, p11 + q]]               # 协方差传播加过程噪声

    def update(self, z, r=1e-4):
        s = self.P[0][0] + r             # 新息协方差：位置不确定性加观测噪声
        k0 = self.P[0][0] / s            # 位置增益
        k1 = self.P[1][0] / s            # 速度增益：靠位置序列间接收正
        y = z - self.x[0]                # 新息：观测与预测之差，可作失配监控
        self.x = [self.x[0] + k0 * y, self.x[1] + k1 * y]
        p00, p01, p10, p11 = self.P[0][0], self.P[0][1], self.P[1][0], self.P[1][1]
        self.P = [[(1.0 - k0) * p00, (1.0 - k0) * p01],
                  [p10 - k1 * p00, p11 - k1 * p01]]

    def ahead(self, lead):
        """超前 lead 秒的预测位置：拦截点计算的输入。"""
        return self.x[0] + self.x[1] * lead

解读：（1）两个矩阵运算手写展开，避免引入线性代数依赖，便于移植到对计算资源敏感的执行环境。（2）速度没有直接观测，靠位置序列的时序信息渐进修正，因此初始阶段的速度估计需要若干次更新才收敛，对应"起步阶段不触发抓取"的保护策略。（3）新息 y 同时是失配监控量：目标匀速假设被破坏（转向、加速）时新息幅值超常，任务层据此暂停触发。（4）三个坐标轴各维护一个独立滤波器，目标做曲线运动时也可用联合模型替换。

片段 3：触发判据

def trigger_ready(pred_point, reachable, t_intercept, t_arm,
                  kappa=1.3, alignment_limit=0.15):
    """三重判据：可达、时间充足、接近方向可用；任一不满足则继续等待。"""
    if not reachable(pred_point):
        return "WAIT"                    # 拦截点超出工作空间或存在碰撞
    if t_intercept < kappa * t_arm:
        return "WAIT"                    # 剩余时间不足以在余量内完成动作
    if alignment_limit is not None and alignment_limit < 0.0:
        return "WAIT"                    # 保留分支：方向判据由外部预计算
    return "TRIGGER"                     # 条件齐备：启动抓取序列并锁定冷却

解读：（1）判据按代价从低到高排列：可达性检查最便宜且过滤最强，时间判据次之，方向判据最贵（涉及姿态搜索），实现顺序与排列一致。（2）kappa 放大动作时长形成时间余量，取值 1.2–1.5，覆盖规划时间的波动。（3）返回值用枚举表达等待原因：布尔值只能区分等或不等，枚举让上层日志能区分"等位置"与"等时间"两种原因，便于调参时定位瓶颈。触发成功后任务层进入冷却期，避免同一窗口被重复触发。

常见坑

  • 未补偿感知与执行延迟：拦截点按当前观测外推，启动与到达之间目标又走了几厘米，抓在目标身后。修复：超前量取感知延迟加规划执行时间的总和，并按实测校准。
  • 相对速度超标：末端以静止策略接近运动目标，接触瞬间产生冲击与滑移。修复：接近段末速度匹配目标速度，阈值 0.05 m/s；无法匹配时选择目标降速段作业。
  • 触发抖动导致重复启动：判据在边界反复满足与失效，任务层反复启动抓取。修复：触发后进入冷却期，并对判据加入迟滞（hysteresis），进入与退出的阈值分离。
  • 滤波参数过平滑：过程噪声过小导致估计滞后于真实运动，拦截点系统性偏后。修复：按目标机动性标定过程噪声，并用新息幅值验证跟随性。
  • 坐标系与时间戳未对齐：传感器数据与机械臂状态的时间戳差异在运动场景中被放大为位置误差。修复：统一时间基准，数据融合前做时间同步，坐标变换使用与数据时间戳一致的位姿。

小结

  • 动态抓取把时间作为显式变量：感知、规划、执行的时间总和必须小于抓取窗口，策略按目标速度分为等待式、跟踪式与拦截式。
  • 恒速模型下的拦截点由二次方程求解，判别式与二次项系数给出可行性判断，最早正根对应最快的会合方案。
  • 卡尔曼滤波提供带噪声与延迟条件下的位置速度估计，超前量把估计外推到抓取瞬间，新息可作机动失配的监控量。
  • 触发判据按可达、时间余量、方向可用三重条件判定，余量系数 1.2–1.5；触发后进入冷却期防止抖动重触发。
  • 会合质量由相对速度刻画，阈值 0.05 m/s，下一章讨论在候选集合上做姿态优化与评分，把动态约束纳入统一排序。
