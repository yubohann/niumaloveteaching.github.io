第 015 章：轨迹重放与轨迹插值

本章处理轨迹的质量工序：用重定时重排时间轴、用重采样对齐控制周期、用样条插值获得连续的速度与加速度，并解决连续关节的绕行问题。

  • 主题：轨迹处理 / 重放、重定时与插值
  • 关键机制：时间参数化算法、重采样、五次多项式插值
  • 预计学时：55 分钟
  • 前置章节：第 014 章

学习目标

  • 区分轨迹重放的三类通道：控制器执行、显示回放、离线数据驱动，明确各自能验证什么。
  • 理解重定时与重采样的差别，能在任务中组合使用两类工序。
  • 掌握线性、三次、五次插值的连续性阶梯，能按平滑度要求选择插值次数。
  • 会实现五次多项式插值并检查端点速度、加速度边界条件。
  • 能识别并处理连续关节角度绕行与多段轨迹时间戳拼接两类问题。

背景与动机

规划器输出的轨迹在几何上可行，在时间上未必理想：速度缩放调低后轨迹可能过慢；换用控制器后可能要求更密集的路点；多段轨迹拼接时接缝处的速度可能中断。这些问题不需要重新规划，只需要对既有轨迹做后处理。重定时、重采样与插值就是这套后处理工具箱。

另一个必须掌握插值的原因在显示与重放：把存储的轨迹重新播放时，观察者对轨迹质量的判断依赖于插值实现。线性插值下速度阶跃、五次插值下加速度连续，同一个几何路径在两种插值下的运动观感完全不同。理解连续性阶梯，才能解释"轨迹看着一样，运行表现却不同"的现象。

核心原理

本节依次解释重放通道、重定时算法、重采样与插值数学，最后给出两类角度问题的处理。

1. 重放的三类通道与各自能验证的内容

通道实现方式能验证的内容
控制器执行把存储的轨迹再次发送给控制器完整执行链路与真实运动表现
显示回放发布到显示轨迹话题，可视化环境播放几何路径、关节运动形状，不涉及物理
状态流驱动按时间戳发布关节状态，驱动模型显示与其它组件的时间同步关系

三类通道的验证能力自上而下减弱。常见的误用是把显示回放的结果当作执行验证：显示通道只要消息格式正确就会播放，控制器拒绝的轨迹在显示通道里照常"运动"。重放验证的结论要标注通道，避免把可视化的通过当成执行的通过。

2. 重定时：重新分配时间轴

重定时保持几何路点序列不变，重新计算每个路点的时间戳与速度，使轨迹满足给定的速度与加速度上限。常用算法按输出特性分为几类：

算法类别连续性特点
迭代抛物线型速度连续按梯形速度剖面分配时间，计算快，加速度阶跃
迭代样条型速度、加速度连续用样条拟合时间轴，平滑度好，计算量中等
时间最优型速度连续，加速度分段常值给定上限下用时最短，加加速度不受限
加加速度限幅型位置、速度、加速度、加加速度连续运动最柔和，计算量最大，部分实现可选

连续性阶梯的物理意义：速度不连续对应动量突变，加速度不连续对应力突变，加加速度不连续对应冲击。设备越贵重、末端工件越脆，需要的连续性等级越高。选择原则是够用即止：大范围转移用抛物线型足够，精密工序段再用样条或限幅型，把计算代价花在真正需要的段上。

3. 重采样与插值数学

重采样在时间轴上按固定周期取点：给定重采样周期 T（对应控制频率），在每段轨迹上按时间插值出若干个新路点。用途有三类：控制器期望固定周期的路点流、重放显示需要与状态流节奏对齐、轨迹段拼接处需要统一密度。

插值多项式的选择决定连续性。设单段归一化时间为 τ ∈ [0, 1]，段时长与端点速度决定曲线：

线性：q(τ) = q0 + τ (q1 − q0)；位置连续，速度阶跃
三次 Hermite：位置与速度连续，加速度阶跃；五次：位置、速度、加速度均连续 五次边界条件为两端的位置、速度、加速度六项，据此解出六个系数

三次 Hermite 用端点位置与速度构造，是"给定端点速度"场景的默认选择；五次多项式多出加速度边界条件，适合要求加速度从零开始、到零结束的工序，能消除启停时的加速度阶跃。插值次数存在代价上限：高次曲线可能出现过冲，且计算量上升；工程上五次已是"平滑启停"的常用选择。

4. 连续关节的绕行问题

连续旋转关节的角度可以跨过 ±π 表示同一构型。若两个路点的原始角度差超过 π，线性插值会沿"长边"绕行，执行时间无故增加，还可能扫过危险区域。处理方式是在插值前对相邻路点做最短方向归一：把角差折叠到 (−π, π] 区间再叠加。

Δq = q1 − q0；若 |Δq| > π，则取 Δq ← Δq − 2π·sign(Δq) 对连续关节与接近 ±π 的转动关节都适用；处理时机必须在重定时与重采样之前

绕行问题的典型症状：一条短距离目标的轨迹耗时异常高、路点数异常多，且末点角度与目标"相差 2π"。检查轨迹首末点的角度差值即可确认。

实现思路与设计

轨迹后处理按固定管线组织：检查、归一、重定时、重采样、复核。

  1. 检查：时间戳单调性、首末点角度差、目标位置与限位的关系（第 010 章三项速检）。
  2. 归一：对连续关节与超过 π 的角差做最短方向折叠。
  3. 重定时：按精度需求选择算法，用速度缩放与加速度缩放约束输出。
  4. 重采样：按目标周期（如 100 Hz 对应 0.01 s）生成统一密度的路点流。
  5. 复核：再次执行速检，确认速度、加速度在限值内且时间戳严格单调。

参数表

参数建议值作用取值依据
重采样周期0.01 s路点密度对应 100 Hz 控制频率
速度缩放0.2 至 1.0重定时速度约束与规划阶段保持一致口径
加速度缩放0.1 至 1.0重定时加速度约束首次调试取低值
插值次数三次或五次平滑度等级常规用三次，启停工况用五次
角差折叠阈值π绕行判定数学上最短路径的半周界
设计决策：为什么把归一化放在重定时之前？

时间轴由路段长度决定：归一化会改变相邻路点的角差，从而改变每段的时长与速度分布。若顺序颠倒，重定时基于绕行的角度差分配了多余的时间，归一化之后轨迹变得远低于速度上限，节奏松散且需要二次重定时。后处理管线一旦确定顺序就应固定：先几何后时间，先归一后计时，任何顺序交换都要重新评估整管线。

关键代码与解读

片段 1：重定时工具调用

#include <moveit/trajectory_processing/time_optimal_trajectory_generation.h>
#include <moveit/trajectory_processing/iterative_spline_parameterization.h>

using moveit::planning_interface::MoveGroupInterface;

// 轨迹来自规划结果：robot_trajectory 是包含起始状态的完整轨迹对象
robot_trajectory::RobotTrajectory trajectory(group.getRobotModel(), "arm");
trajectory.setRobotTrajectoryMsg(*(group.getCurrentState()), plan.trajectory_);

// 时间最优重定时：速度与加速度上限之内用时最短
trajectory_processing::TimeOptimalTrajectoryGeneration totg;
// 参数为速度与加速度缩放：与规划阶段口径一致，便于对照
bool ok = totg.computeTimeStamps(trajectory, 0.2, 0.1);

if (!ok) {
  // 重定时失败的常见原因是路径点不满足连续性前提（如重复点）
  RCLCPP_ERROR(node->get_logger(), "重定时失败：检查轨迹路点结构");
} else {
  // 把重定时后的轨迹写回消息，供执行或存储
  moveit_msgs::msg::RobotTrajectory msg;
  trajectory.getRobotTrajectoryMsg(msg);
}
// 备选：迭代样条重定时，平滑度更高、计算量更大
trajectory_processing::IterativeSplineParameterization spline(true);
spline.computeTimeStamps(trajectory, 0.2, 0.1);

解读：重定时工具以轨迹对象为操作单位，输入输出都是完整轨迹。（1）轨迹对象需要先由模型与组名构造，再装入规划结果；模型与组名决定限位与自由度的解释方式。（2）缩放参数与规划阶段一致，重定时前后速度分布可对照；不一致时轨迹速度与预期出现系统性偏差。（3）两种算法通过同一接口调用，切换成本低；选择依据是连续性需求，与算法新旧无关。重定时失败的报错信息应结合路径结构排查（重复路点、孤点）。

片段 2：五次多项式插值

import numpy as np

def quintic_segment(q0, q1, T, n=20):
    """两路点间五次多项式插值：位置、速度、加速度均连续。

    q0/q1: 端点位置（标量），T: 段时长，n: 采样段数
    边界条件：起点与终点速度、加速度均为零（平滑启停）
    五次多项式共有六个系数，恰好由六项边界条件确定。
    """
    # 归一化时间采样：tau 从 0 到 1
    tau = np.linspace(0.0, 1.0, n + 1)
    # 六项边界条件解出的系数形式（零端点速度与加速度）
    s = 10 * tau**3 - 15 * tau**4 + 6 * tau**5     # 位置剖面
    ds = (30 * tau**2 - 60 * tau**3 + 30 * tau**4) / T   # 速度剖面
    dds = (60 * tau - 180 * tau**2 + 120 * tau**3) / T**2  # 加速度剖面
    q = q0 + (q1 - q0) * s
    # 自检：端点速度与加速度应为零（误差在数值精度内）
    assert abs(ds[0]) < 1e-12 and abs(ds[-1]) < 1e-12
    return tau * T, q, ds, dds

t, q, v, a = quintic_segment(q0=0.0, q1=0.9, T=1.5)
print(f"末点位置 {q[-1]:.3f} rad，峰值速度 {np.max(np.abs(v)):.3f} rad/s")

解读：五次插值用系数形式直接表达端到端的平滑。（1）位置剖面多项式 10τ³ − 15τ⁴ + 6τ⁵ 是"平滑阶跃"的标准形状：在两端一阶与二阶导数均为零，对应静止起步与平稳停止。（2）速度剖面峰值出现在中段，数值上约为平均速度的 1.88 倍，这个系数可用于快速核对：峰值速度要在关节上限内。（3）内置断言把边界条件变成自检，插值函数被复用时不会因手误破坏端点条件。

片段 3：连续关节角差归一

import math

def wrap_delta(delta):
    """把角差折叠到 (-π, π]：连续关节与贴边转动关节的最短方向。"""
    # 两处加减 2π：一步处理越过半周界的情况，另一步保证落在开区间
    if delta > math.pi:
        delta -= 2.0 * math.pi
    elif delta < -math.pi:
        delta += 2.0 * math.pi
    return delta

def unwrap_path(q_prev, q_next):
    """在插值前逐关节归一相邻路点：返回延续最短方向的绝对角度。"""
    return [p + wrap_delta(n - p) for p, n in zip(q_prev, q_next)]

# 示例：joint_1 从 3.0 rad 到 -3.0 rad（原始角差 -6.0，绕行约 6 rad）
path = unwrap_path([3.0], [-3.0])
# 归一后目标约为 3.283 rad，绕行距离约 0.283 rad，运动量减少一个数量级
print(f"归一后目标 {path[0]:.3f} rad，实际角差 {abs(path[0] - 3.0):.3f} rad")

解读：绕行处理是替换绝对值而不改变物理构型。（1）归一后的角度可能超出原限位表示范围（例如超过 π），但物理构型不变；限位检查应在归一之前用原始构型完成，避免误报。（2）折叠函数只处理一次加减 2π 的情形，对 |Δq| ≤ 3π 的常规路点足够；异常大角差的输入应在上游拦截。（3）示例中归一把约 6 rad 的绕行压缩到 0.283 rad，直接决定轨迹的耗时与路点数，这就是绕行问题的量化影响。

常见坑

  • 重定时后未复核限值：缩放口径与规划阶段不一致，轨迹速度潜超限。修复：复核流程固定为"重定时后重跑速检"。
  • 顺序错误：先重定时再归一，时间轴与实际角差脱节。修复：管线顺序固定为"先几何后时间"。
  • 重采样周期过粗：控制器插值曲线随之改变，验证过的轨迹与实际执行不一致。修复：周期与控制频率匹配，密度不足时补插值。
  • 显示回放当作执行验证：控制器会拒绝的轨迹在显示通道里正常播放。修复：验证结论标注通道，执行验证必须过控制器。
  • 多段轨迹直接拼接：第二段的时间戳从零重新开始，接缝时间语义混乱。修复：拼接前对齐时间原点与端点速度，再统一重定时。

练习与思考

  1. 取一条现有轨迹，计算各路段时长与路点数量，再用 100 Hz 重采样，核对重采样后的点密度与时间刻度。★
    提示
    重采样点数约等于段时长乘以频率；两处应一致，偏差来自端点取整约定。
  2. 对同一条轨迹分别用时间最优与迭代样条两种算法重定时，比较总时长与末点速度，解释差异来源。★★
    提示
    时间最优追求最短时长，速度剖面更激进；样条受平滑度约束，时长略长、末端收敛更柔和。
  3. 预测实验：构造 joint_1 从 3.0 rad 到 -3.0 rad 的两点轨迹，分别在归一与不归一两条件下计算时长与路点数，先预测比值再验证。★★
    提示
    绕行路径约为最短路径的 21 倍（6.0 / 0.283），时长与路点数近似同比例放大；数值对照可直观展示归一化的收益。
  4. 设计题：为一条"规划产生、后处理、存储、重放"的流水线编写校验规程，标明每道工序的输入输出检查点与失败时的回退动作。★★★
    提示
    检查点参考各章速检：几何检查在前，时间检查在后，执行前再过一遍起点一致性；回退动作区分"重处理"与"重新规划"两类。

小结

  • 重放分三类通道，验证能力递减；显示通过不等于执行通过。
  • 重定时重排时间轴，算法按连续性分级选择；重采样对齐控制周期。
  • 插值连续性阶梯：线性保证位置连续，三次补上速度连续，五次补上加速度连续。
  • 连续关节绕行在归一后消除，处理时机必须在重定时之前。
