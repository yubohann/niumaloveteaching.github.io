第二篇 · 规划场景与碰撞管理

第 032 章：深度相机接入

点云从哪里来：本章讲深度成像的三种原理与噪声特性、针孔模型与反投影计算、光学参考系的旋转约定与 TF 链搭建、深度图转点云的实用代码，以及标称距离下的精度回归方法。

  • 主题：传感器接入 / 深度成像
  • 关键机制：针孔投影与反投影、光学参考系约定、深度噪声随距离的增长规律
  • 预计学时：50 分钟
  • 前置章节：第 031 章

学习目标

  • 理解深度成像的三类原理（立体视觉、结构光、飞行时间）与各自的误差特征，能按工作距离与材质选型。
  • 掌握针孔模型的投影与反投影公式，能手工把深度像素换算为相机坐标系下的三维点。
  • 记住相机机身参考系与光学参考系的轴向约定及两者间的固定旋转，能正确搭建静态 TF 链。
  • 会用深度噪声公式估算给定距离下的测距标准差，并据此设定观测范围与安全裕量。
  • 能设计相机接入的验证流程：标称距离回归、坐标系核对、与规划场景的联调。

背景与动机

第 031 章把点云写入地图，本章回到点云的源头设备。深度相机是机械臂感知的主力：它以毫秒级节拍输出场景的稠密距离信息，让规划场景在缺少 CAD 模型的情况下获得障碍几何。相机接入看似只是"接一条话题"，实际上有三个工程层面的问题需要答清楚：深度数据有多准（误差随距离与材质如何变化）、它在哪个坐标系里（参考系约定错一步，障碍位置整体镜像或旋转）、它如何与规划场景对齐（TF 链与消息时间戳，第 031 章已提出要求）。

深度相机的接入质量直接决定感知驱动规划的安全边界。把噪声特性弄错，安全裕量就是拍脑袋；把坐标系弄错，障碍会出现在空间中错误的位置，规划器围绕幻影避障而真实障碍敞开。本章从原理到标定逐层展开，第 033 章在此基础上讲感知接口的扩展方式，第 034 章讲多路数据融合。

核心原理

1. 三种深度成像原理与误差特征

主流的深度测量方式有三类，原理与误差结构各不相同：

方式原理误差特征适用条件
立体视觉两幅视图的视差换算深度误差随距离平方增长，纹理依赖强纹理丰富、中等距离
结构光投影编码图案，按形变换算深度近距离精度高，受强环境光与反光面影响室内、近距离精细作业
飞行时间发射并接收调制光，按飞行时间测距中远距离稳定，多路径反射引入偏差中等精度、较大范围

立体视觉的深度由三角关系给出，这一式子同时给出误差传播规律：

Z = f · B / d；σZ ≈ Z2 · σd / (f · B) f 为等效焦距（像素），B 为基线（米），d 为视差（像素）；σd 为视差估计标准差

平方增长意味着立体视觉的可用距离区间有限：距离翻倍，噪声扩大四倍。结构光在近距离（典型 0.3 至 1.5 m）精度优秀，却怕反光与强光；飞行时间在米级距离上稳定，但镜面与玻璃会产生多路径误差。选型的第一步从来是"工作距离加目标材质"，分辨率与帧率属于后续优化项。对规划场景而言，深度噪声是安全裕量设计的输入参数：裕量必须覆盖最大工作距离处的测距标准差，典型距离处的数值不能作为依据。

2. 针孔模型：投影与反投影

相机内参把三维点与像素坐标联系起来。以光学参考系为基准（z 轴沿光轴向前），投影关系为：

u = fx · X / Z + cx，v = fy · Y / Z + cy
反投影：X = (u - cx) · Z / fx，Y = (v - cy) · Z / fy (fx, fy) 为像素表示的焦距，(cx, cy) 为主点，Z 为该像素的深度读数

反投影是"深度图转点云"的全部数学：每个有效像素一个 3D 点，逐像素计算即得点云。两个工程细节：主点偏差对横向定位的影响随距离放大，例如主点错 20 像素、焦距 600 像素时，1 m 处的横向偏差约 33 mm，属于不可忽略的量级；镜头畸变在标定后由校正环节处理，点云话题输出的数据通常已是校正后的结果，核对驱动配置可以避免"校正两次"或"一次都没做"两类错误。

3. 光学参考系：轴向约定与固定旋转

ROS 生态沿用一条明确的约定：相机机身参考系（如 camera_link）采用右手系下 x 前、y 左、z 上的轴向；深度图与点云所在的光学参考系（optical frame）采用 z 前、x 右、y 下的轴向。两者只差一个固定旋转：

Rlink→optical：xoptical = -ylink，yoptical = -zlink，zoptical = xlink URDF 中对应的固定旋转常用 rpy = (-π/2, 0, -π/2)

深度相机驱动输出的点云、深度图等数据都挂在光学参考系上，而机械装配、遮挡分析、外参估计都在机身参考系上进行。漏建光学参考系这一级的直接后果是点云整体旋转 90 度级错位：地面出现在"右侧"，障碍出现在"上方"，规划器围绕错误几何避障。两类参考系在 TF 树中的固定关系由静态变换发布，必须在接入阶段一次性核对（用可视化查看轴向箭头是最快的验证手段）。

4. 接入链路：从驱动到规划场景

深度相机接入规划场景的完整链路包含五个环节：驱动节点输出深度流与内参信息；驱动或后处理环节把深度反投影为点云并按光学参考系标注；静态 TF 链把光学参考系依次接到机身、安装法兰、机器人基座与世界；占据地图监视器的传感器插件订阅点云并执行第 031 章的写入管线；规划场景对外提供带感知内容的世界。链路上任何一环的时间戳或参考系出错，都会以"地图不更新"或"障碍错位"的形式暴露，验证时从链路的源头逐段核对最为高效。

5. 安装位置与遮挡

安装位置决定遮挡结构。安装在末端（腕部）的方案随臂运动，工作时指向目标，近距精度好，但自身臂身会进入视场（依赖第 031 章的自过滤），且相机随臂振动需要充分的静态标定；固定安装的方案视野稳定、外参一次标定可长期使用，但工件与工装会遮挡后向区域，贴近工件时视场中心可能被自身夹爪占据。工程折中是两种方案并存：固定相机负责工位大范围与安全区域，腕部相机负责操作近景。无论哪种方案，验证流程都要包含"目标在标称工作距离处的定位误差"与"遮挡边界处的可见性"两项。

实现思路与设计

相机接入的工程步骤：

  1. 选型：按工作距离区间、目标材质与所需精度确定测量原理与型号参数，明确最大可用距离处的测距标准差。
  2. 安装与刚性固定：确定安装位置与视角，保证关键工作量区域在视场内且受遮挡最小。
  3. 搭建 TF 链：在机器人描述中加入相机安装连杆、机身参考系与光学参考系的固定关节，核对旋转约定。
  4. 配置驱动输出：设定深度流分辨率与帧率、深度距离范围；确认点云话题的参考系标注为光学参考系。
  5. 精度回归：用标准平面板在若干标称距离测量偏差与噪声，形成设备档案，作为安全裕量的依据。
  6. 接入场景并联调：按第 031 章配置传感器插件，验证标准障碍在地图中的位置、尺寸与清除行为。

接入参数与验收要点

项目常用取值说明
深度流分辨率640 × 480 或 848 × 480兼顾精度与链路负荷；更高分辨率配合抽稀使用

关键代码与解读

片段 1：Python 深度图反投影为点云

import numpy as np

def depth_to_points(depth_mm, fx, fy, cx, cy, min_range=0.2, max_range=3.0):
    """深度图反投影：像素 + 内参 + 深度读数 -> 光学参考系下的点云。

    输入 depth_mm 为以毫米为单位的深度数组（无效像素为 0）。
    输出为 N x 3 的浮点数组，单位米。
    """
    h, w = depth_mm.shape
    # 像素网格：u 沿列向右、v 沿行向下，与光学参考系约定一致
    u, v = np.meshgrid(np.arange(w), np.arange(h))
    z = depth_mm.astype(np.float32) / 1000.0   # 毫米转米，单位错误是常见事故源
    valid = (z > min_range) & (z < max_range)   # 去掉无效与超程像素
    x = (u[valid] - cx) * z[valid] / fx         # 反投影公式的逐分量实现
    y = (v[valid] - cy) * z[valid] / fy
    pts = np.stack([x, y, z[valid]], axis=1)    # 光学参考系：z 前、x 右、y 下
    print(f"有效点 {pts.shape[0]} / {h * w}，占比 {pts.shape[0] / (h * w):.0%}")
    return pts

解读：（1）单位换算显式写出：深度驱动常以毫米发布，直接按米使用会让场景放大一千倍，这类错误在可视化中表现为"障碍贴满脸"，排查时先核对单位与数值量级。（2）有效区间同时给出下限与上限：过近的点受遮挡与标定误差影响，过远的点噪声超预算，两者都应剔除，最小距离参数通常对应相机最近成像距离。（3）输出点按光学参考系组织，与该参考系进入 TF 链后的变换方向一致；自实现点云时保持这一约定，可以与驱动输出无缝互换。

片段 3：Python 用标准平板做测距精度回归

def depth_accuracy_check(depth_mm, roi, truth_m):
    """在标称距离的平面板上测量：偏差与噪声是安全裕量的输入。"""
    u0, v0, du, dv = roi                      # 平板在图像中的采样区域
    region = depth_mm[v0:v0 + dv, u0:u0 + du].astype(np.float32) / 1000.0
    valid = region[region > 0]
    if valid.size == 0:
        print("该区域无有效深度：检查平板是否在视场与量程内")
        return None
    mean = float(valid.mean())
    std = float(valid.std())
    print(f"标称 {truth_m:.2f} m：均值 {mean:.3f} m，"
          f"偏差 {(mean - truth_m) * 100:+.1f} cm，"
          f"噪声标准差 {std * 1000:.1f} mm")
    return mean, std

# 分别在 0.5 / 1.0 / 2.0 m 处重复，观察偏差与噪声随距离的增长
# 噪声在最大工作距离处的数值决定观测上限与安全裕量下限

解读：（1）偏差（均值减真值）反映系统误差，可能来自标定或温度漂移；噪声（标准差）反映随机误差，两者分开记录，处置手段不同。（2）回归在多档距离上重复，才能观察到平方增长规律并外推可用范围；只测中点距离会让最大距离处的裕量失去依据。（3）结果进入设备档案：更换相机或调整安装后重测，把"设备是谁、测得多准"固化成可追溯数据，避免停留在口头经验。

常见坑

  • 光学参考系漏建或旋转错误：点云挂在机身参考系下发布，或旋转写成其它角度，障碍整体旋转错位。修复是按轴向对应关系核对固定旋转，并在可视化中沿三个轴确认方向。
  • 深度单位误解：驱动以毫米发布，消费侧按米使用，地图中出现放大千倍的障碍。修复是在解析入口统一做单位换算并打印数值量级检查。
  • 静态 TF 未发布：点云到地图参考系的链缺环，第 031 章管线的变换阶段失败，地图静默不更新。修复是核对 TF 树中相机相关链路完整，含光学参考系与安装关节。
  • 把标称量程当作可用量程：在噪声超预算的远距离上使用深度数据，安全裕量形同虚设。修复是按噪声公式与回归数据设定观测上限，超过上限的点在预过滤阶段剔除。
  • 忽略材质影响：反光、透明、黑色表面造成深度空洞或跳变，地图在目标工件处出现缺口。修复是调整安装角度避开镜面反射方向，或补充第二视角传感器覆盖（第 034 章）。

练习与思考

  1. 误差计算：立体相机等效焦距 f = 600 像素、基线 B = 0.05 m，视差估计标准差 σd = 0.1 像素。计算 1 m 与 3 m 处的测距标准差，并说明该相机把观测上限设在 3 m 是否合理。★
    提示
    1 m 处：σZ ≈ 1 × 0.1 / (600 × 0.05) ≈ 3.3 mm；3 m 处约 30 mm。若安全裕量按厘米级设计，3 m 处 30 mm 的噪声已接近裕量下限，应当作为观测上限或收紧裕量。
  2. 参数影响预测：主点横向偏差 20 像素、焦距 600 像素。分别计算 0.5 m、1 m、2 m 处由主点误差引起的横向位置偏差，说明为什么标定不良的相机不适合远距离精细定位。★
    提示
    横向偏差 = Z × Δc / f：0.5 m 约 17 mm，1 m 约 33 mm，2 m 约 67 mm。偏差随距离线性增长，精细定位要求毫米级时应重新标定或缩短工作距离。
  3. 设计题：为"固定相机监视料箱区域、机械臂取件"的场景设计相机接入方案：安装位置、TF 链、验证用例与安全裕量取值依据。★★
    提示
    相机固定于料箱上方斜俯视；TF 从世界经安装支架到机身与光学参考系；验证用例覆盖料箱内标准件的定位误差与遮挡（机械臂伸入时）。裕量取料箱最远点处的测距标准差加抓取公差。
  4. 诊断题：RViz 中相机点云整体绕 z 轴旋转约 90 度，而距离数值看起来正常。列出两种可能原因与验证方法。★★
    提示
    候选原因：光学参考系固定旋转写错（核对 URDF 的 rpy 值与轴向可视化）；安装关节的 rpy 与真实装配不符（用棋盘格或标准板核对机身朝向）。距离正常说明内参与深度链路本身无问题。
  5. 分析题：比较腕部安装与固定安装两种方案在遮挡结构、标定稳定性、自过滤依赖三个方面的差异，给出一个"两种并存"系统的分工设计与切换策略。★★★
    提示
    腕部方案近距精度好但依赖自过滤与振动标定；固定方案视野稳定但遮挡多。分工：固定相机负责工位大范围与安全监控，腕部相机负责操作近景；切换策略按任务阶段（接近前用固定、操作中切腕部）并统一地图参考系。

小结

  • 深度成像三类原理的误差结构不同：立体视觉随距离平方增长，结构光近距离强但怕反光，飞行时间稳定但有多路径问题。
  • 反投影公式把深度像素变为光学参考系下的三维点，主点与焦距误差对定位的影响随距离放大。
  • 机身参考系与光学参考系相差标准固定旋转，漏建或写错会让点云整体错位，这是接入阶段的第一验证项。
  • 接入链路从驱动到规划场景包含五段，任何一段的时间戳或参考系问题都以"地图不更新"或"障碍错位"暴露。
