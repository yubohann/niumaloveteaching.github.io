第 064 章：Place Action 接口

放置侧接口与抓取侧对称，目标却不同：Place 的阶段组织、PlaceLocation 多候选语义、放置精度的误差分层与接触检测驱动的轻放策略。

  • 主题：任务接口 / Place Action（Place Action）
  • 关键机制：多放置位姿候选 / 误差合成 / 接触检测与轻放
  • 预计学时：50 分钟
  • 前置章节：第 063 章

学习目标

  • 掌握 PlaceGoal 与 PlaceLocation 的字段组成，理解多放置位姿候选（Place Location Candidates）的顺序尝试语义。
  • 能画出 Pick 与 Place 的阶段对称映射，并说明两阶段在"释放控制"与"接触检测"上的本质差异。
  • 掌握放置精度的误差分层方法，能用平方和开方（RSS）与代数和两种方式做误差预算。
  • 会实现接触检测驱动的减速下降与轻放逻辑，并设计释放扰动的抑制策略。
  • 能诊断偏移放置、压靠过载、场景未还原三类常见放置故障。

背景与动机

抓取控制的是"夹紧"，放置控制的是"松开"。看似对称的两个动作，工程难点分布完全不同：抓取时物体被手爪约束，误差由夹持力与摩擦吸收；放置时物体与支撑面接触，误差直接表现为放置位置偏差，且释放瞬间的反力可能推倒或滚动物体。放置是整条流水线中精度要求最高、接触状态变化最多的一段，因此需要独立的接口语义与专门的轻放策略。

Place action 在消息层与 Pickup 对称：目标携带放置位置候选列表、支撑面信息与可接触连杆列表，反馈报告阶段推进，结果返回错误码。二者的区别集中在 PlaceLocation 的字段设计与执行层策略上，本章按"接口语义 → 误差理论 → 轻放实现"展开。

本章是第 063 章的对称补充，并为第 070 章的装配对位、第 071 章的力控柔顺做概念铺垫：放置中的接触检测与力阈值控制正是力控思想的起步形态。

核心原理

1. 阶段对称性与释放控制差异

Pick 阶段Place 对应阶段共同点差异点
预抓取（Pre-Grasp）预放置（Pre-Place）沿接近方向退距的中间位姿预放置位姿还需容纳手爪与物体的总高度
接近（Approach）下降（Descend）直线段进入最终位姿下降段末端存在接触，需减速与检测
夹紧（Close）释放（Release）一次手爪动作张开产生反力，可能扰动已就位物体
回退（Retreat）撤离（Retreat）直线退出撤离时物体已脱离手爪，需避开物体边界

释放控制的关键差异在于力的方向性：夹紧时反力由物体承担，释放时反力传给支撑面，方向不利时表现为物体翻转或滚动。因此释放阶段保留轻微下压、降低张开速度、张开完成后先抬升再侧向移动，是最小化放置扰动的通行策略。

2. PlaceLocation 与多候选语义

PlaceGoal 携带一个放置位置候选数组（PlaceLocation[]），每个候选包含：放置位姿（place_pose，含 frame）、放置前手爪姿态（pre_place_posture）、接近参数（approach）与撤离参数（retreat），以及可选的标识（id）。

多候选服务于两类场景：同一物体的多个可放置位置（料框的不同格位、传送带的不同区段），以及同一位置的多组接近方向（从上方、从侧向摆放）。服务器按顺序或按优先级尝试，直到某个候选完成或全部失败，语义与第 063 章抓取候选列表一致。

设计决策：多候选选择顺序由谁决定？

服务器逐候选尝试的默认顺序是数组顺序，因此把"最希望放置的位置"排在前面是客户端的职责。若希望按空间可行性排序，可由客户端先做可放置性初筛（格位空间余量、与相邻物体的间隙），把通过初筛且余量大的候选排在前面。接口层不承担排序逻辑，保持目标语义的纯粹性。

3. 放置精度的误差分层

放置偏差由若干独立来源叠加，误差预算按来源分层：

误差来源典型量级性质抑制手段
机械臂绝对定位误差0.2–1 mm（标定后）系统性，可标定运动学标定、TCP 标定
抓取瞬间物体相对手爪偏移1–3 mm随机，接触决定抓取后视觉复检、夹紧定心
搬运过程中的滑移0–1 mm随机，与加速度相关限制搬运加速度、提高夹持力
支撑面倾斜与不平0.2–1 mm 等效系统性，可测量标定支撑面平面度，补偿高度
释放扰动0.5–2 mm随机，方向相关轻压下释放、慢速张开

独立误差按平方和开方（Root Sum Square, RSS）合成，最坏情形按代数和估计：

eRSS = √(Σ ei2)，eworst = Σ ei 0.5 mm、1.5 mm、0.5 mm 三项合成：RSS ≈ 1.66 mm，最坏 2.5 mm

误差预算的作用是定位主导项：RSS 与代数和相差越远，说明各来源量级接近且相互独立；若某一项明显主导，投入应集中在该项的抑制手段上。上式示例中抓取抓偏项（1.5 mm）主导，优先方案是抓取后的视觉复检或定心机构；继续提高机械臂标定精度对抓偏项的收益有限。

4. 接触检测与轻放

下降段末端需要感知"何时接触"，可用手段按获得难度递增排列：

  • 位置偏差检测：位置控制下观察实际关节位置与指令位置的偏差累积，接触产生等效刚度突变。无需额外传感器，灵敏度低。
  • 关节电流突变：接触使关节负载增大，电流上升超过阈值判定接触。常用阈值对应 5–15 N 的等效接触力，无需力传感器。
  • 腕部力/力矩传感：直接测量六维力，可分辨接触方向与大小，适合第 071 章的力控闭环。

轻放策略分为五步：快速下降到名义高度上方 5–10 mm，低速下降到接触检测触发，触发后停止下降，保持轻压并慢速张开手爪，张开完成后直线抬升。下压余量（0.5–2 mm）是为支撑面不平与位置误差预留的行程，太小会出现"未接触就释放"导致物体坠落，太大则压靠力过大。

实现思路与设计

放置流水线的实现步骤：

  1. 目标解析：读取候选数组，校验 place_pose 的 frame、手爪姿态与接近参数完整性。
  2. 预放置位姿派生：由放置位姿沿接近方向后退，退距需容纳物体与手爪总高。
  3. 阶段推进：预放置（关节或笛卡尔）→ 下降（分快速与低速两段）→ 接触检测 → 释放 → 撤离。
  4. 场景还原：释放完成后分离物体并按当前位姿放回场景，确保后续目标看到的世界模型正确。
  5. 失败处理：接触未触发时按到达名义高度处理并告警；候选失败切换下一个放置位置。

放置参数表

参数典型值作用取值依据
预放置高度0.05–0.10 m下降段起点高度容纳物体加手爪总高并留余量
快速下降速度0.05–0.1 m/s接近段主速度空旷段提速，缩短周期
低速下降速度0.01–0.03 m/s接触前速度降低冲击与超调
接触力阈值5–15 N判定接触的等效力大于空载摩擦、小于物体承压上限
下压余量0.5–2 mm接触检测的行程预算覆盖位置误差与支撑面不平
释放保持时间0.3–0.5 s张开完成后的稳定等待让物体落稳后再抬升
放置位置容差1–2 mm验收判据由第 3 节误差预算反推

与上一章的差异：Pick 的失败判据集中在"是否夹住"，Place 的失败判据分散在"是否接触、是否放正、是否扰动"，因此 Place 的执行层需要更细的分段与检测点。

关键代码与解读

片段 1：PlaceGoal 与 PlaceLocation 构造

from moveit_msgs.action import Place
from moveit_msgs.msg import PlaceLocation

def make_place_goal(target_name, locations, d_approach, d_retreat, group="arm"):
    """封装放置目标：候选顺序即尝试顺序，接近与撤离参数逐个候选携带。"""
    goal = Place.Goal()
    goal.group_name = group            # 规划组名：与抓取侧保持同一执行链
    goal.target_name = target_name     # 已附着物体名：放置完成后转回场景物体
    built = []
    for i, pose in enumerate(locations):
        loc = PlaceLocation()
        loc.id = f"slot_{i}"           # 标识用于反馈中报告使用了哪个候选
        loc.place_pose = pose          # 含 frame 的放置位姿：须与支撑面标定一致
        # 接近与撤离方向按位姿法向给出：竖直放置时方向取支撑面法向
        loc.approach.direction.header.frame_id = pose.header.frame_id
        loc.approach.direction.vector.z = -1.0
        loc.approach.desired_distance = d_approach
        loc.approach.min_distance = 0.01
        loc.retreat.direction = loc.approach.direction
        loc.retreat.desired_distance = d_retreat
        built.append(loc)
    goal.place_locations = built       # 数组顺序即尝试顺序：期望位置排前面
    goal.support_surface_name = "table"
    return goal

解读：（1）loc.id 设计为格位标识，配合反馈可以知道实际落在哪个候选上，便于对多格位料框做统计。（2）接近方向在候选内部单独携带，不同放置位姿可拥有不同的接近方向（侧向码垛与竖直摆放并存），这是把方向字段放在 PlaceLocation 层携带、目标层不携带方向的直接原因。（3）数组顺序即尝试顺序，把期望位置排在前面属于客户端的排序职责。（4）放置位姿的 frame 必须与支撑面的标定参考一致，否则高度方向的系统偏差会整体平移。

片段 2：接触检测驱动的减速下降

import time

def descend_until_contact(servo, force_reader, z_target, force_limit,
                          step=0.0005, poll=0.02):
    """按固定步长下降并在接触时立即停止；接触力超限前终止下降。"""
    z = servo.current_z()                      # 当前末端高度（笛卡尔伺服接口）
    while z > z_target:
        if force_reader.contact_force() > force_limit:
            servo.stop()
            return "CONTACT"                   # 触发了接触检测：进入释放流程
        z -= step                              # 步长 0.5 mm：决定检测粒度
        servo.move_to_z(z)
        time.sleep(poll)                       # 轮询 20 ms：决定最大运动超调
    servo.stop()
    return "REACHED"                           # 到达名义高度仍无接触：按到位处理并告警

解读：（1）步长与轮询间隔共同决定接触时刻的过冲量：过冲 ≈ 下降速度 × 轮询间隔，0.02 m/s 与 20 ms 组合的过冲约 0.4 mm，与下压余量同量级。（2）两个返回值的语义不同：CONTACT 表示检测成功，REACHED 表示未接触但到达名义高度，后者可能源于位置误差或空抓，需要上层判别。（3）该函数用位置步进加力检查的组合实现轻放，替代方案是把下降段交给力控或柔顺控制，把接触力作为闭环目标（第 071 章展开）。

片段 3：放置误差预算

import math

def error_budget(terms):
    """误差预算：独立来源按 RSS 合成，给出最坏界用于容差校核。"""
    rss = math.sqrt(sum(e * e for e in terms))
    worst = sum(abs(e) for e in terms)
    return rss, worst

# 典型分解：定位 0.5 mm、抓取抓偏 1.5 mm、支撑面倾斜等效 0.5 mm
rss, worst = error_budget([0.5e-3, 1.5e-3, 0.5e-3])
print(f"合成误差 {rss * 1000:.2f} mm，最坏 {worst * 1000:.2f} mm")
print("对照容差 1.0 mm：主导项为抓取抓偏，优先加装抓后复检")

解读：（1）RSS 用于常规情形评估，最坏界用于安全相关的下压余量设计：下压余量需大于最坏界，否则存在未接触即释放的风险。（2）输出同时给出主导项提示，把误差预算从"算术练习"变成"改进方向的选择依据"。（3）该估算应在系统设计阶段完成，并以实测数据（重复放置测试的分布）迭代更新各分项。

常见坑

  • 放置位姿 frame 与支撑面不一致：place_pose 表达在物体坐标系或手爪坐标系，直接按规划坐标系使用导致高度与水平方向系统性偏差。修复：目标构造时统一变换到规划坐标系，并在接口文档中固定约定。
  • 预放置高度不足：下降段起点离支撑面过近，直线段在起始处已接近碰撞，姿态调整余地小。修复：预放置高度按物体与手爪总高加 5–10 mm 余量设定。
  • 下压余量过大或过小：过大时接触后仍继续下压，压靠力上升甚至触发碰撞停止；过小时未接触就释放，物体坠落。修复：按下压余量大于误差最坏界、小于物体允许压缩量的区间取值，典型 0.5–2 mm。
  • 释放扰动未抑制：手爪张开速度过快，物体被推偏或被带倒。修复：张开前保留轻压下压，张开速度取行程的 20%–30%，张开完成后等待 0.3–0.5 s 再抬升。
  • 放置完成未还原场景：物体仍以附着状态存在，后续规划把物体当作手爪的一部分，出现"物体悬空跟随"。修复：分离后按当前实际位姿重新加入场景，完成场景一致性检查。

练习与思考

  1. 给定误差分项：定位 0.6 mm、抓取抓偏 2.0 mm、释放扰动 1.0 mm。分别计算 RSS 合成值与最坏界，并指出优先改进项。★
    提示
    RSS = √(0.36 + 4.0 + 1.0) ≈ 2.32 mm；最坏界 3.6 mm。抓取抓偏为主导项，优先加装抓取后复检或定心结构。
  2. 把接触检测的轮询间隔从 20 ms 缩短到 5 ms，预测过冲量与对关节电流采样率、通信周期的新要求。★★
    提示
    过冲按比例降至约 0.1 mm，但要求电流或力信号的采样与传输周期同步缩短；若驱动器状态上报周期大于轮询间隔，缩短轮询没有实际收益。
  3. 为"把圆柱杯放入直径大 6 mm 的杯托"设计放置阶段表，标出每个阶段的速度、检测点与失败回退动作，并估算允许的位置误差上限。★★
    提示
    间隙 3 mm 意味着位置误差需小于 3 mm 才能落座，倒角过渡可放宽到接近 5 mm；下降末端速度取 0.01 m/s，接触检测后轻压释放。
  4. 设计对比实验：同一放置任务分别在"位置控制固定下压 1 mm"与"接触检测触发停止"两种策略下重复 30 次，给出评价指标与预期差异。★★★
    提示
    指标包括落座位置分布、接触力峰值、失败次数、动作时长；固定下压策略的位置一致性依赖标定精度，接触检测策略的力峰值更低，但引入轮询延迟带来的过冲。

小结

  • Place 与 Pick 在阶段结构上对称，差异集中在下降末端的接触检测与释放扰动抑制。
  • PlaceLocation 数组承载多放置位置与方向候选，数组顺序即尝试顺序，排序职责在客户端。
  • 放置精度按来源分层，独立误差用 RSS 合成、下压余量按最坏界设计，主导项的判别决定改进方向。
  • 轻放策略为"快速下降、低速接触、检测停止、轻压释放、稳定抬升"五步，接触力阈值典型 5–15 N。
  • 接口语义与执行策略分离：消息定义候选与支撑面，具体检测与速度策略在执行层配置，下一章逐字段剖析 Grasp 与 PlaceLocation 消息。
