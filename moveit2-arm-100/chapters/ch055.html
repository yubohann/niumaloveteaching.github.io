第三篇 · 规划算法与求解器

第 055 章：正运动学与雅可比矩阵

正运动学（Forward Kinematics, FK）回答"关节角给定时末端在哪"，雅可比矩阵（Jacobian）回答"关节动一点，末端动多少"。两者是 IK、奇异分析、力控与执行监控的共同基础，本章给出从链式变换推导到 MoveIt 接口使用的完整链条。

  • 主题：运动学基础 / 变换链与速度映射
  • 关键机制：齐次变换链、几何雅可比、速度与力的对偶、数值校验
  • 预计学时：55 分钟
  • 前置章节：第 054 章

学习目标

  • 掌握链式齐次变换形式：由关节变量、关节轴与连杆偏置组合出末端位姿。
  • 能推导转动关节的雅可比列向量 Ji = [zi × (pe − pi); zi]，并解释每一项的几何含义。
  • 理解速度映射 v = J(q)q̇ 与静力对偶 τ = JTF，能用虚功原理解释对偶关系。
  • 会用有限差分计算数值雅可比并与解析结果对照，掌握步长选择与误差量级。
  • 会在 MoveIt 中读取末端变换与雅可比，并说清坐标参考系约定对结果的影响。

背景与动机

IK 求解（第 050 到 054 章）、奇异分析（第 056 章）、力控与柔顺操作（第 071 章）、执行期轨迹监控，都建立在这两个基础量上。把 FK 与雅可比理解成"可以直接拿来算的公式"，是从调用 API 走向自主分析的转折点。

工程现场的两个高频任务尤其依赖它们：其一，用 FK 校验标定与模型一致性（末端实测位姿与模型计算值对照）；其二，用雅可比检测轨迹上的速度放大与奇异接近程度。本章为这两类任务准备工具。

核心原理

1. 链式齐次变换

刚体位姿用 4 × 4 齐次变换矩阵描述，旋转部分 R ∈ SO(3)，平移部分 p ∈ R³。单关节变换由"固定偏置 + 关节运动"组成：

转动关节：Ti(qi) = origini · Rot(zi, qi) origin 为连杆偏置（URDF 中 origin 的 xyz 与 rpy），zi 为关节轴方向

整条链的 FK 是各关节变换的顺序乘积：

T0n(q) = T1(q1) · T2(q2) · 依次至 Tn(qn) 从基座到末端的顺序不可交换；矩阵乘法次序错误是最常见的手工实现错误

FK 是"一步到位"的计算：没有迭代、没有歧义，给定关节值就有唯一末端位姿。IK 的所有困难恰好来自它的逆问题不唯一。工程上把 FK 当作"真值生成器"：由随机关节角生成可达位姿样本，用于 IK 验收（第 054 章片段 3）与标定校验。

2. 几何雅可比：逐关节的贡献叠加

对末端位姿微分可得速度关系。对第 i 个转动关节，其单位角速度对末端速度的贡献为：

Jv,i = zi × (pe − pi)，Jω,i = zi zi：关节轴单位向量（基座系表达）；pi：关节原点；pe：末端位置

把 n 个关节的列向量并排得到 6 × n 的几何雅可比，末端速度 twist 与之线性相关：

[v; ω] = J(q) · q̇ v 为末端线速度，ω 为角速度；平移关节的列改为 [zi; 0]

几何直觉：转动关节在末端产生"绕轴旋转 + 切向平移"的复合运动，叉乘项 z × (pe − pi) 正是"臂长乘以角速度"的向量形式。同一公式解释了为什么手臂完全伸直时（pe 与轴方向关系退化）速度出现异常，这正是第 056 章奇异分析的数学起点。

3. 速度与力的对偶

由虚功原理，关节力矩与末端力通过雅可比转置互映：

τ = JT F F 为末端六维力旋量（力与力矩）；维度 n × 6 乘 6 × 1 得到关节力矩 n 维

对偶关系的用途：已知末端期望接触力，可以直接估算各关节所需力矩，用于负载能力评估与力控分配（第 071 章）。与速度映射共用同一个雅可比，是"速度与力在能量意义上互为对偶"的直接体现。

4. 数值雅可比与校验

解析公式之外，用有限差分可以独立计算雅可比：对每个关节施加小扰动 δ，观察末端位姿变化：

Jcol,i ≈ ( FK(q + δei) − FK(q) ) / δ δ 取 10−6 到 10−4：过小被浮点噪声淹没，过大引入截断误差

数值雅可比的意义在于交叉校验：解析实现有行列错误或参考系混用时，两种方法的结果会明显不一致。把"解析与数值对照"做成单元测试，可以在模型或代码变更时第一时间暴露问题。注意旋转部分的差分要用旋转向量表达，直接对矩阵元素做差没有几何意义。

实现思路与设计

在项目中引入 FK 与雅可比的步骤：

  1. 明确参考系约定：确定雅可比的表达坐标系（基座系或工具系）与末端参考点，写入接口注释。
  2. 解析实现并测试：按几何公式实现或直接使用库函数，用数值差分做逐列对照。
  3. 接入校验工具：把"FK 对照标定测量"与"雅可比对照差分"固化为回归测试。
  4. 面向用途封装：奇异检测（σ 相关，第 056 章）、力估算（τ = JTF）、速度限幅三条路径分别封装。

使用场景与指标

场景用到的量典型阈值或量级
标定校验FK 位置偏差超过 1 到 3 mm 触发复查
轨迹速度监控J(q) 与关节速度末端速度超工艺上限即降速

关键代码与解读

片段 1：平面三连杆的 FK 与解析雅可比（numpy 原理实现）

import numpy as np

L = np.array([0.4, 0.3, 0.25])          # 三段连杆长度（米）

def fk_planar(q):
    """平面三连杆正运动学：累加各段方向向量，返回末端位置与各关节位置。"""
    pts = [np.zeros(2)]
    ang = 0.0
    for qi, li in zip(q, L):
        ang += qi                       # 绝对角：各关节角沿链累加
        pts.append(pts[-1] + li * np.array([np.cos(ang), np.sin(ang)]))
    return np.array(pts)                # (4, 2)：基座到末端四个点

def jacobian_planar(q):
    """解析雅可比：第 i 列 = 关节轴叉乘(末端 - 关节原点)，平面情形化为垂直向量。"""
    pts = fk_planar(q)
    pe = pts[-1]                        # 末端位置
    J = np.zeros((2, 3))
    for i in range(3):
        d = pe - pts[i]                 # 关节 i 原点指向末端的向量
        J[:, i] = np.array([-d[1], d[0]])   # 平面叉乘 z × d
    return J

def numeric_jacobian(q, delta=1e-6):
    """数值雅可比：逐关节差分，用于交叉校验解析实现。"""
    J = np.zeros((2, 3))
    for i in range(3):
        qp = q.copy(); qp[i] += delta
        J[:, i] = (fk_planar(qp)[-1] - fk_planar(q)[-1]) / delta
    return J

q = np.array([0.3, -0.5, 0.8])
print("解析与数值之差的最大绝对值：",
      np.abs(jacobian_planar(q) - numeric_jacobian(q)).max())

解读：平面情形把三维叉乘降为二维，结构更清晰。关键对照点是"绝对角累加"：关节空间的 q 与平面角度之间隔一层运动学耦合，这正是雅可比逐列计算要取"末端减关节原点"的原因，简单臂长相加无法给出正确列。解析与数值结果之差应在 10−7 量级（前向差分 δ = 10−6 时的截断误差水平；把差分改为中心形式可再降约四个数量级，至 10−11 量级）；若差异出现且有结构（如某一列系统性偏大），优先怀疑公式里的点位置用错。把这段扩到三维即可得到与通用公式一致的形式。

片段 2：MoveIt 中的 FK 与雅可比读取（C++）

#include <moveit/robot_state/robot_state.h>

// 读取末端变换与雅可比：用途是校验、监控与力估算的共同入口
void inspect_kinematics(moveit::core::RobotState& state,
                        const moveit::core::JointModelGroup* group,
                        const std::string& tip_link)
{
  state.setToDefaultValues();
  state.setVariablePositions(std::vector<double>{0.3, -0.5, 0.8, 0.0, 0.5, -0.5, 0.0});
  state.update();                                     // 更新所有缓存的变换

  const Eigen::Isometry3d& T = state.getGlobalLinkTransform(tip_link);
  // 末端位置：T.translation()；姿态：T.linear()。参考系为模型根坐标系（通常是基座）

  const Eigen::MatrixXd& J = state.getJacobian(group);
  // J 的维度：6 x 自由度；参考系与参考点约定以实现为准，使用前需实验确认

  // 速度映射示例：给定关节速度向量 qd，估算末端 twist（在前三行取线速度）
  Eigen::VectorXd qd = Eigen::VectorXd::Zero(J.cols());
  qd << 0.1, -0.2, 0.15, 0.0, 0.1, -0.1, 0.05;
  Eigen::VectorXd twist = J * qd;
  const double v_norm = twist.head<3>().norm();        // 末端线速度范数
  (void)v_norm;                                      // 监控示例：与工艺速度上限比较
}

解读：三点值得注意。第一，更新顺序：设置关节值后必须调用 update() 刷新缓存变换，否则读到上一状态的结果。第二，参考系纪律：末端变换在模型根坐标系表达，雅可比的表达坐标系依实现约定（常见为基座系表达、参考点为组内末端），跨版本或跨库比较前先做数值实验确认。第三，速度映射是最轻量的验证用途：给定单位关节速度观察末端 twist 的构成，可以直观感受各关节的贡献比例，为奇异接近判断（第 056 章）建立手感。

常见坑

  • 变换乘法次序错误：手工实现时按"末端到基座"相乘顺序，结果发散。修复：固定"从基座出发依次右乘"的书写习惯，用已知单关节情形做单元测试。
  • 雅可比参考系混用：把工具系表达的雅可比与基座系期望混用，速度映射结果方向错乱。修复：在接口处显式声明参考系与参考点，并用数值差分对照。
  • 数值差分步长随意：δ 取 0.1 量级时截断误差主导，对照结果失真。修复：取 10−6 到 10−4，并观察误差随步长的 U 形曲线选取。
  • 旋转部分直接对矩阵元素做差：元素差没有旋转向量语义，无法得到几何雅可比。修复：用旋转向量（轴角）表达姿态差再求导。
  • 忽略关节轴归一化：URDF 中轴向量若未归一化，叉乘结果量纲错误。修复：实现时显式归一化，或使用经过验证的库函数。

练习与思考

  1. 写出两连杆平面机械臂的雅可比矩阵显式表达式，并求手臂完全伸直（q2 = 0）时的行列式。★
    提示
    J 的第二列与第一列在 q2 = 0 时线性相关，det(J) = L1L2sin(q2) = 0。行列式为零即速度映射降秩，这份直觉在三维情形就是奇异位的判定。
  2. 用虚功原理推导 τ = JTF：从末端做功等于关节做功出发写出等式并整理。★
    提示
    q̇Tτ = vTF，代入 v = Jq̇ 得 q̇T(τ − JTF) = 0；对任意 q̇ 成立，故 τ = JTF。
  3. 设计实验：固定 q̇ 为单位向量，扫描 q 的一个关节从 0 到 π/2，记录末端速度范数与 J 的最小奇异值变化，预测两者关系并用片段 1 的代码验证。★★
    提示
    末端速度范数上限由 σmax 决定，最小奇异值趋零时该方向上的速度映射放大；两者曲线应呈现"σmin 下降对应速度放大率上升"的镜像关系。
  4. 推导与设计：某关节轴方向 z 在世界系中表达为 z(q)，说明为什么雅可比的列向量会随构型变化，并给出"哪一类关节的列不随构型变化"的例子。★★★
    提示
    z 与臂向量 pe − pi 都随上游关节角变化，故列向量随 q 变。第一关节（绕固定基座轴）的列方向恒定，'不随构型变化'的典型即基座转动关节的角速度方向。

小结

  • FK 由链式齐次变换顺序乘积给出，无迭代、无歧义，是位姿样本生成与标定校验的真值源。
  • 几何雅可比逐列构建：转动关节列为 [z × (pe − pi); z]，体现"绕轴旋转加切向平移"。
  • 速度映射 v = Jq̇ 与静力对偶 τ = JTF 共用同一矩阵，由虚功原理联结。
  • 数值差分是解析实现的交叉校验工具，步长取 10−6 到 10−4，旋转差用轴角表达。
  • 参考系与参考点是使用雅可比时的第一纪律，接口必须显式声明并做数值对照。
