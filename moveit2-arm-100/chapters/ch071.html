第 071 章：力控与柔顺操作

接触任务的控制理论：环境刚度为什么不许位置伺服硬碰硬，阻抗与导纳的建模差异、力位混合的轴选择矩阵，以及采样率与噪声对稳定性的约束。

  • 主题：控制 / 力控与柔顺操作（Force Control and Compliance）
  • 关键机制：二阶阻抗与导纳模型 / 力位混合选择矩阵 / 离散稳定性校验
  • 预计学时：60 分钟
  • 前置章节：第 070 章

学习目标

  • 理解位置控制在接触任务中的根本限制，能用 F = Kenv·Δx 说明环境刚度对位置误差的放大作用。
  • 掌握阻抗控制与导纳控制的对偶关系，能写出二阶模型并解释刚度、阻尼、惯量三个参数的物理意义。
  • 掌握力位混合控制的选择矩阵方法，能按接触几何分解任务空间方向。
  • 会做离散稳定性校验：采样率、闭环带宽与安全倍数之间的约束。
  • 了解力控在 MoveIt2 生态中的实现落点与版本差异，能说明规划层与伺服层的频率分工。

背景与动机

第 070 章的装配把机械臂推进到持续接触的状态。接触环境中，位置伺服会把位置误差转换为接触力：力的大小等于环境刚度乘以压入量，金属件的等效刚度可达 106 N/m 量级，几十微米的位置误差就能产生数十牛顿的接触力。位置控制的误差容忍度与接触任务所需的力控制精度之间存在量级差距，这就是需要独立力控框架的原因。

力控在实现层面位于 MoveIt2 规划层之下：规划层以 1–10 Hz 生成任务级目标，力控环以 100–1000 Hz 在伺服层修正笛卡尔指令。MoveIt2 生态提供笛卡尔伺服（MoveIt Servo）与关节级力矩接口作为落点；较新发行版在控制器集合中提供导纳控制器，Humble 时期通常需要自实现外环或采用外部包，具体接口以对应发行版的官方文档为准。

本章与上一章的衔接：装配中的"柔顺"是本章理论的一个特例；与第 070 章的虚拟弹簧相比，本章给出完整的二阶形式与稳定性条件。

核心原理

1. 环境刚度：位置控制失效的根源

接触环境中，机械臂末端位置与环境表面位置之差决定接触力：

F = Kenv · (xcmd − xenv) 金属件接触刚度约 105–107 N/m；0.1 mm 压入量在 106 N/m 环境下产生 100 N 的力

位置控制的目标是让 x 精确等于 xcmd，压入量由位置误差决定，与力需求无关，力的可控性完全丧失。力控的目标从"控制位置"改成"控制接触力与位置修正量的关系"，即控制机械臂在接触方向上的等效动力学，这一关系就是阻抗（Impedance）。

2. 阻抗与导纳：对偶的两种实现

二阶阻抗模型把机械臂在接触方向上的行为描述为质量、阻尼、弹簧的组合，外力与位置偏移的关系为：

Md ẍ + Bd ẋ + Kd (x − xd) = −Fext 阻抗形式：位置是输入、力是输出；导纳形式把方程右端改写为 Fext，力是输入、位置修正是输出
参数物理意义典型取值调整效果
刚度 Kd抵抗位置偏移的能力（N/m）装配 500–2000，抛光 2000–5000越大越"硬"，稳态偏移 F/Kd 越小
阻尼 Bd速度相关阻力（N·s/m）由阻尼比反推越大振荡越少，响应越慢
惯量 Md等效质量（kg）0.5–5越大对力噪声越不敏感，迟滞越明显

两个派生指标决定动态品质：自然频率 ωn = √(Kd/Md)，阻尼比 ζ = Bd / (2√(KdMd))。ζ 取 0.7–1.0 获得无超调的快速响应。稳态偏移是最直观的整定依据：Kd = 500 N/m、F = 10 N 时稳态偏移 20 mm，该偏移量必须小于任务允许的位置误差。

两种形式的适用边界由环境刚度决定：阻抗控制直接输出力或力矩，与高刚度环境耦合时容易形成非最小相位式的失稳；导纳控制输出位置修正，对高刚度环境天然稳定（因为压入量由环境吸收），因此装配、插拔、抛光这类硬接触任务常用导纳形式，而与人交互、软体操作等软环境多用途阻抗形式。

3. 力位混合控制：按方向分解任务

多数任务在部分方向要求力、在其余方向要求位置。平面插孔在竖直方向需要稳定接触力，在水平方向需要精确对位；擦拭任务在表面法向恒力、切向恒速。力位混合控制用选择矩阵把两个目标分配到正交子空间：

τ = JT [ S · Fd + (I − S) · Kp (xd − x) ] S 为对角选择矩阵，对角元 1 的方向做力控、0 的方向做位置控；(x_d − x) 为位置误差，K_p 为位置增益

选择矩阵的确定依赖接触几何：表面法向是天然的力控方向，切平面内是位置控制方向。几何先验错误（把受约束方向设成位置控制）会让两个目标在同一方向对抗，表现为力发散或位置停滞。S 的设置过程本质上是把接触几何写成矩阵。

4. 稳定性、采样率与噪声

力控环是数字闭环，离散化引入相位滞后，闭环带宽与采样率之间需要足够余量：

fs ≥ 10–20 × ωn / (2π) Kd = 800 N/m、Md = 1 kg 时 ωn ≈ 28.3 rad/s（约 4.5 Hz），1 kHz 采样率有百倍以上余量

放宽刚度或减小惯量会提高带宽，采样率需求同步上升。力传感器噪声经导纳环放大为位置抖动：惯量下限（Md ≥ 0.5 kg）与低通滤波（20–50 Hz）是抑制噪声的两道手段，代价分别是响应迟滞与相位滞后，两者都需要在整定时逐项验证。噪声量级参考：六维力传感噪声 0.05–0.5 N，滤波后用于导纳环的可用信号带宽通常限制在 50 Hz 以内。

实现思路与设计

力控系统的分层设计：

  1. 规划层（1–10 Hz）：MoveIt2 生成任务级轨迹与阶段切换，给出接触方向与期望力。
  2. 轨迹执行层（100–500 Hz）：轨迹控制器按时间参数化输出关节位置指令。
  3. 力控环（100–1000 Hz）：读取力信号，经滤波与导纳计算得到位置修正量，叠加到伺服指令。
  4. 安全层：力上限、速度上限与位置边界在每一层独立校验，任何一层超限即触发降级。

MoveIt2 生态中的落点：（a）笛卡尔伺服（MoveIt Servo）提供关节速度级接口，导纳外环的输出可映射为伺服速度指令；（b）关节力矩接口直接给出力矩前馈，适合阻抗形式；（c）导纳控制器在较新发行版随控制器集合提供，使用前确认版本与配置格式，以官方文档为准。

设计决策：为什么装配任务采用导纳形式？

装配环境的等效刚度高，阻抗控制直接把计算力施加到硬环境上，力指令的微小延迟就会转化为力尖峰与振荡；导纳控制把力信号转换为位置修正，位置修正被环境的柔顺与间隙自然吸收，闭环回路中不含"给硬环境施力"的环节。稳定性的来源不同，这是选型的主要依据。

关键代码与解读

片段 1：一维导纳控制器的离散实现

class Admittance1D:
    """一维导纳：输入接触力，输出位置修正量，二阶离散更新。"""
    def __init__(self, m=1.0, b=60.0, k=800.0):
        self.m, self.b, self.k = m, b, k   # 惯量、阻尼、刚度：决定柔顺手感
        self.x = 0.0                       # 位置修正量
        self.v = 0.0                       # 修正速度

    def step(self, f_ext, dt):
        # 二阶动力学：m·a + b·v + k·x = f_ext（导纳形式，力为输入）
        a = (f_ext - self.b * self.v - self.k * self.x) / self.m
        self.v += a * dt                   # 显式欧拉积分：dt 过大即失稳
        self.x += self.v * dt
        return self.x                      # 叠加到伺服指令位置

# k=800 N/m 时，10 N 接触力的稳态修正量约 12.5 mm

解读：（1）三个参数直接映射物理直觉：刚度决定"压多深"，阻尼决定"晃不晃"，惯量决定"对力信号的敏感度"。（2）离散更新用显式欧拉积分，稳定性依赖步长与带宽的比值，这正是下一片段校验的内容。（3）稳态行为可手算验证：k = 800、f = 10 N 时修正量 12.5 mm，整定时以这个量对照任务允许的位置偏差。

片段 2：力位混合指令生成

def hybrid_command(x_d, x_meas, f_d, f_meas, gain, S):
    """力位混合：S=1 的轴做力控，S=0 的轴做位置控制。"""
    x_cmd = list(x_d)
    for i in range(3):
        if S[i] == 1:
            # 力误差乘柔顺增益得到位置微调：等效刚度 = 1/gain
            x_cmd[i] = x_meas[i] + gain * (f_d[i] - f_meas[i])
    return x_cmd

S = (0, 0, 1)      # 平面装配：x、y 位置控，z 方向力控
gain = 0.002       # 0.002 m/N 等效刚度 500 N/m
# 力超目标时 (f_d - f_meas) 为负，指令位置向后退让，降低压靠

解读：（1）选择矩阵以元组表达，轴与几何方向对应，接触方向由标定得到后写入配置。（2）力控轴的位置微调以实测位置为基准（x_meas[i]），使修正量相对当前状态累加计算，避免绝对位置记忆带来的漂移。（3）增益 0.002 m/N 即等效刚度 500 N/m，与导纳参数的取值区间一致；该形式是导纳环的稳态简化，动态修正由片段 1 的完整模型承担。

片段 3：离散稳定性校验

import math

def check_stability(k, m, dt, safety=10.0):
    """校验采样率相对闭环带宽的比例余量。"""
    wn = math.sqrt(k / m)             # 自然频率 rad/s
    f_close = wn / (2.0 * math.pi)    # 闭环带宽 Hz
    f_s = 1.0 / dt                    # 采样率 Hz
    return f_s >= safety * f_close, f_close, f_s

ok, fc, fs = check_stability(k=800.0, m=1.0, dt=0.001)
print(f"闭环带宽 {fc:.1f} Hz，采样率 {fs:.0f} Hz，余量校验"
      + ("通过" if ok else "不足"))

解读：（1）判断依据是采样率与带宽的固定倍数关系（10–20 倍），倍数越低相位滞后越显著，闭环越接近失稳边界。（2）该校验在参数整定阶段执行一次即可：刚度提高或惯量减小时带宽上升，需要重新校验；采样率由硬件决定，只能作为固定约束参与校验。（3）输出同时给出带宽与采样率，便于记录整定过程；示例中 4.5 Hz 带宽与 1 kHz 采样率余量充足，为后续提高刚度留出空间。

常见坑

  • 硬接触环境使用阻抗形式：力指令与高刚度环境直接对抗，出现高频振荡与力尖峰。修复：改用导纳形式（力输入、位置输出），或显著降低刚度并提高滤波强度。
  • 采样率不足：闭环带宽接近采样率的一成以内，相位滞后导致振荡。修复：提高力环频率至 200 Hz 以上，或降低刚度与惯量的带宽需求，两者取其一。
  • 力噪声直接进入导纳环：末端持续抖动，位置修正高频振荡。修复：低通滤波截止 20–50 Hz，设置惯量下限 0.5 kg，并为小信号设置死区。
  • 选择矩阵方向设置错误：受约束方向被设成位置控制，力发散；自由方向被设成力控，位置失控漂移。修复：由接触几何标定 S，加入方向正确性校验（例如接触力方向与力控轴的一致性检查）。
  • 规划层与力控层指令互相覆盖：轨迹执行以低频覆盖伺服层的力修正，力控效果时有时无。修复：分层明确，力修正只在伺服层叠加，规划层输出接触方向与期望力而不直接修改伺服指令。

练习与思考

  1. 刚度 Kd = 500 N/m、期望接触力 10 N，求稳态位置偏移；若任务允许的位置误差为 5 mm，判断该刚度能否满足要求。★
    提示
    偏移 = 10 / 500 = 20 mm，超过 5 mm 的允许值；需要把刚度提高到 2000 N/m（偏移 5 mm）以上，或降低期望接触力。
  2. Md = 1 kg、Kd = 800 N/m，求自然频率与临界阻尼系数；若整定取阻尼比 0.8，求 Bd。★★
    提示
    ωn = √800 ≈ 28.3 rad/s；临界阻尼 B = 2√(KM) ≈ 56.6 N·s/m；ζ = 0.8 时 B ≈ 45.3 N·s/m，响应略快于临界阻尼且无显著超调。
  3. 把力环采样率从 1 kHz 降到 100 Hz，保持刚度 800 N/m 不变，分析稳定性余量的变化；若必须使用 100 Hz 采样，提出两种可行的参数调整方案。★★
    提示
    带宽 4.5 Hz 时 100 Hz 采样仍有约 22 倍余量，仍在可接受范围；若进一步提高刚度导致余量不足，可降低刚度或增大惯量以降低带宽，或提高滤波截止与闭环带宽的比值。
  4. 为"曲面抛光恒力 20 N"设计力控方案：确定控制形式、选择矩阵方向、刚度与滤波参数，并说明曲面法向变化时选择矩阵如何更新。★★★
    提示
    法向恒力、切向恒速，S 随曲面法向变化在线更新，法向采用导纳形式（K 取 2000–5000 N/m），切向位置控制并跟踪路径；法向估计由工件模型或力信号的梯度方向给出，更新频率与轨迹插值同步。

小结

  • 接触环境中位置误差经环境刚度放大为接触力，位置控制无法管理接触力，力控从"控制位置"转为"控制接触动力学"。
  • 阻抗与导纳是同一二阶模型的对偶形式，刚度、阻尼、惯量分别对应"压多深、晃不晃、敏感度"，稳态偏移 F/K 是整定的直观依据。
  • 硬接触任务采用导纳形式以规避与高刚度环境的失稳耦合，软环境与交互任务多用阻抗形式。
  • 力位混合控制用选择矩阵把任务空间分解为力控与位置控两个正交子空间，S 的设置等价于把接触几何写成矩阵。
  • 稳定性由采样率与闭环带宽的倍数关系保证，力噪声靠惯量下限与低通滤波抑制，下一章进入双臂协作的闭链约束问题。
