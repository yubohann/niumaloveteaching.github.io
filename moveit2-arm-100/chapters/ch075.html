第 075 章：柔性臂与软体机械臂

当刚体假设失效：柔性关节的二质量模型、软体臂的常曲率运动学、输入整形的抑振参数，以及 MoveIt2 在柔性平台上的近似方案与适用边界。

  • 主题：平台形态 / 柔性臂与软体机械臂（Flexible and Soft Manipulators）
  • 关键机制：弹簧阻尼关节模型 / 常曲率（PCC）运动学 / 输入整形（Input Shaping）
  • 预计学时：55 分钟
  • 前置章节：第 074 章

学习目标

  • 能区分柔性的三个来源（关节柔性、连杆柔性、材料柔性）与各自的建模方法及振动频率量级。
  • 掌握柔性关节的弹簧阻尼模型，能计算自然频率与阻尼比，解释到位后残余振动的成因。
  • 掌握软体臂的常曲率（Piecewise Constant Curvature, PCC）运动学，能写出平面单段的正运动学公式。
  • 掌握输入整形（Input Shaping）的零振动（ZV）整形参数计算，理解其与速度限制的分工。
  • 能说明 MoveIt2 刚体假设在柔性平台上的适用边界，并设计"限速加等待加闭环补偿"的近似方案。

背景与动机

前三章的机械臂都被视为刚体与刚性关节的组合：关节角确定位形，位形确定末端位姿。柔性关节、长连杆与软体材料打破这一假设：关节存在弹性变形，指令角与负载角不同步；长臂在运动中弯曲，末端轨迹与刚体模型预测不符；软体臂的形变是连续体的行为，无法用有限个关节角精确描述。

柔性的价值与代价并存：柔性关节保护减速器并提高能效，软体臂能安全交互、适应不规则物体；代价是动力学进入中低频段（0.5–30 Hz），恰好与常见的控制与轨迹频段重叠，产生振动、残余振荡与定位误差。MoveIt2 的规划与碰撞模型都建立在刚体假设上，柔性平台需要一个"近似表达加外部补偿"的组合方案。

本章与第 071 章的衔接：力控处理接触，柔性处理结构本身的弹性；与第 076 章的衔接：柔性在仿真中难以建模，仿真与真机的差异（Sim-to-Real Gap）很大一部分来自结构柔性。

核心原理

1. 柔性的三个来源与建模选择

来源物理机制建模方法振动频率量级
关节柔性谐波减速器与同步带的弹性集中参数弹簧阻尼模型5–30 Hz
连杆柔性长臂梁的弯曲与扭转分布参数离散化（有限元或模态截断）3–20 Hz
材料柔性硅胶与气囊结构的连续变形常曲率模型或 Cosserat 杆0.5–5 Hz

建模选择的原则是"主导模态优先"：柔性集中在关节时用集中参数模型即可，长臂的弯曲需要至少两个模态才能描述端部位移，软体臂则整体采用连续体模型。三类柔性的共同后果是把系统从单频率的伺服控制对象变成多频率的弹性系统，控制与规划的频段必须与之错开。

2. 柔性关节：弹簧阻尼模型与残余振动

把关节两侧（电机侧与负载侧）之间的扭矩传递简化为弹簧与阻尼并联，负载角的运动方程为：

I ẍ + b ẋ + k (x − θcmd) = 0 I 为负载等效惯量，k 为关节刚度，b 为阻尼系数；自然频率 ω = √(k/I)，阻尼比 ζ = b / (2√(k I))

取 k = 500 N·m/rad、I = 0.5 kg·m2、b = 8 N·m·s/rad：ω ≈ 31.6 rad/s（约 5 Hz），ζ ≈ 0.25。欠阻尼系统的阶跃响应带超调与振荡，进入 ±1% 误差带的整定时间约为 4 / (ζω) ≈ 0.5 s，这段时间就是到位后的"残余振动"窗口，抓取与放置若在其间开始，接触位置与力都会抖动。

关节柔性的另一后果是动态耦合：负载惯量越大有效频率越低，同一控制器在不同姿态下的表现不同，这就是柔性臂高速运动时振铃现象随姿态变化的原因。

3. 软体臂：常曲率模型

软体与连续体臂的分段常曲率模型假设每一段弯曲为圆弧，由曲率 κ 与弧长 l 描述平面内的弯曲形状，末端位姿有解析表达式：

x = sin(κ l) / κ，y = (1 − cos(κ l)) / κ，θ = κ l κ = 20 1/m、l = 0.1 m 时弯曲角 κl = 2 rad（约 114.6°），末端位于约 (0.045, 0.071) m；κ 趋近零时退化为直线

多段串联即多段弧参数拼接，自由度等于段数乘每段参数数（弯曲平面内 2 个、空间内 3 个）。PCC 的价值是给出可解析、可求导的运动学表达；局限是"等曲率"假设在大变形、外部载荷与多腔非对称驱动下失配，此时需要 Cosserat 杆模型或有限元，代价是计算量上升数个量级。工程上常采用"分段 PCC 加在线校正"：把长段切成 3 至 5 个子段，用视觉或姿态传感数据修正段参数。

4. 振动抑制：输入整形与限速

输入整形（Input Shaping）把阶跃指令替换为两个脉冲，第二脉冲在半个振动周期后到达，用反相激励抵消第一脉冲激起的振荡。零振动（Zero Vibration, ZV）整形器的参数由频率与阻尼比决定：

K = exp(−ζπ / √(1 − ζ2))，A1 = 1/(1+K)，A2 = K/(1+K)，Δt = π / (ω√(1 − ζ2)) 5 Hz、ζ = 0.05 时：A1 ≈ 0.539、A2 ≈ 0.461、Δt ≈ 100 ms；代价是响应延迟约一个脉冲间隔

与输入整形互补的手段是限速：关节速度上限从 0.5 rad/s 降到 0.2 rad/s 会显著降低激励强度，同时把加速度约束在 0.5 rad/s2 以内。两者分工：限速降低振动的"输入能量"，整形消除"振荡模式"，到位等待（3 至 5 个振动周期，约 0.6 至 1 s）让残余振动衰减到误差带内再开始接触动作。

MoveIt2 的适配策略组合四项：其一，规划层对柔性臂使用降低的速度与加速度约束；其二，把驱动量分段（例如气动软体臂的腔压档位）映射为虚拟关节并离散化表达；其三，末端位姿用视觉或力传感闭环补偿模型误差；其四，验收指标以"残余振动幅值小于 1 mm"这类可观测量定义，与关节角精度的定义方式区分开。

实现思路与设计

柔性平台的工程实现步骤：

  1. 柔性辨识：用阶跃响应或频率扫描测量主导振动频率与阻尼比，确定建模形式。
  2. 模型选择：关节柔性用集中参数，连杆与软体用 PCC 分段或模态模型，记录模型误差范围。
  3. MoveIt2 近似：把柔性段表达为 3 至 5 个虚拟关节并配置关节限位，或直接降低规划速度与加速度约束。
  4. 控制叠加：在轨迹控制器输入端叠加输入整形，或使用低通滤波替代（滞后更大）。
  5. 到位判定：以残余振动幅值或视觉位姿稳定为条件，等待时间取 3 至 5 个振动周期。
  6. 闭环补偿：接触动作前用视觉或力信号确认实际位姿，补偿模型误差。

设计决策：为什么限速优先于整形？

整形器需要准确的频率与阻尼比参数，辨识误差会削弱甚至放大振动；限速不依赖模型参数，效果稳定但以节拍为代价。工程顺序是先限速把振动压到可接受范围，再对剩余振动叠加整形，最后用闭环确认收尾。参数依赖性从无到有，风险逐级递增，这一顺序让每一步的收益都可以独立验证。

关键代码与解读

片段 1：柔性关节的响应仿真与整定时间

def simulate_flexible_joint(k=500.0, b=8.0, I=0.5, theta_cmd=0.1,
                            dt=0.001, T=0.8):
    """简化模型：电机理想跟随指令，负载按弹簧阻尼响应。"""
    x, xd = 0.0, 0.0                    # 负载角与角速度
    ts, xs = [], []
    for i in range(int(T / dt)):
        acc = (-k * (x - theta_cmd) - b * xd) / I   # 弹簧回复减阻尼
        xd += acc * dt
        x += xd * dt                    # 显式积分：dt 需远小于振动周期
        ts.append(i * dt)
        xs.append(x)
    return ts, xs

def settling_time(ts, xs, band=0.001):
    """从末尾回扫，找最后一次超出误差带的时刻：即整定时间。"""
    target = xs[-1]
    for i in range(len(xs) - 1, -1, -1):
        if abs(xs[i] - target) > band:
            return ts[i + 1]
    return ts[0]

解读：（1）模型把电机侧简化为理想跟随，负载侧保留弹簧与阻尼：这抓住了柔性关节的核心行为（谐振与衰减），同时把仿真规模控制在几十行，适合在参数整定阶段快速试验。（2）整定时间从响应末尾回扫，找最后一次越出误差带的时刻，直接回答"到位后要等多久才能动作"这一工程问题。（3）积分步长 1 ms 对应 5 Hz 振动周期（200 ms）的两百分之一，数值精度充分；步长过大时弹簧系统会数值失稳，这是显式积分的固有限制。

片段 2：ZV 输入整形器参数计算

import math

def zv_shaper(freq_hz, zeta):
    """计算 ZV 整形器的两个脉冲幅值与间隔。"""
    wn = 2.0 * math.pi * freq_hz                 # 自然频率 rad/s
    wd = wn * math.sqrt(1.0 - zeta * zeta)       # 阻尼振动频率
    K = math.exp(-zeta * math.pi / math.sqrt(1.0 - zeta * zeta))
    a1 = 1.0 / (1.0 + K)                         # 第一脉冲幅值（先发）
    a2 = K / (1.0 + K)                           # 第二脉冲幅值（延迟发出）
    return a1, a2, math.pi / wd                  # 间隔为半个阻尼周期

a1, a2, dt = zv_shaper(5.0, 0.05)
print(f"脉冲幅值 {a1:.3f} 与 {a2:.3f}，间隔 {dt * 1000:.1f} ms")
# 输出：脉冲幅值 0.539 与 0.461，间隔约 100.1 ms；响应延迟即为此间隔

解读：（1）两脉冲幅值之和为 1，表示稳态增益不变；整形只改变时间分布，不改变最终到达的幅值。（2）间隔取半个阻尼周期，第二脉冲到达时第一脉冲引起的振动恰好处于反相位置，两段响应叠加后相消。（3）对阻尼比低的系统（ζ 小于 0.1）K 接近 1，两脉冲幅值接近相等；阻尼比增大时 K 减小，第二脉冲变弱，抑振收益同步下降，这也说明整形对高阻尼系统的必要性较低。

片段 3：软体段的平面常曲率正运动学

import math

def pcc_planar_forward(kappa, length):
    """平面常曲率段的正运动学：曲率与弧长到末端位姿。"""
    if abs(kappa) < 1e-9:
        return length, 0.0, 0.0          # 曲率为零：退化为直线
    x = math.sin(kappa * length) / kappa
    y = (1.0 - math.cos(kappa * length)) / kappa
    theta = kappa * length               # 末端切向相对起点切向的转角
    return x, y, theta

x, y, th = pcc_planar_forward(kappa=20.0, length=0.1)
# κ=20 1/m、l=0.1 m：弯曲角 2 rad，末端约 (0.045, 0.071) m

解读：（1）三段公式把连续弯曲解析化：位置由正弦与余弦项给出，切向角等于曲率乘弧长，全部分量可在微秒量级计算，适合在线使用。（2）零曲率分支不可省略：气动软体臂的直立状态就是零曲率，除零会直接产生无穷大。（3）多段串联时逐段复合位姿即可；与刚体链不同，这里的"关节"参数是曲率与弧长，把驱动量（腔压或拉线长度）映射到这些参数需要标定或数据拟合，映射误差是 PCC 模型精度的主要来源。

常见坑

  • 按刚体模型高速规划柔性臂：轨迹执行后到位残余振动持续数百毫秒，接触动作在其间开始导致位置与力抖动。修复：降低速度与加速度上限，到位后等待 3 至 5 个振动周期再进入接触阶段。
  • 轨迹频段与振动频率重叠：规划轨迹的加加速度时间尺度接近振动周期，持续激励主导模态。修复：加大轨迹的平滑时间常数（加加速度限制），或叠加输入整形。
  • PCC 模型用于大变形工况：弯曲角超过约 120° 后等曲率假设失配，末端位置误差快速增大。修复：采用分段 PCC 并对段参数在线校正，或降低单段弯曲角上限。
  • 缺省到位判定条件：以关节指令到达作为到位标志，未考虑负载侧的滞后。修复：用关节实际位置或末端视觉位姿判断稳定，稳定判据与残余振幅验收指标一致。
  • 虚拟关节离散化方向错误：把软体段离散为串联关节却未限制各关节的协调关系，规划结果产生物理上不可能的位形。修复：为虚拟关节配置耦合约束或限位，并把离散化误差纳入模型误差预算。

小结

  • 柔性来源分关节、连杆与材料三类，振动频率量级依次下移，建模按主导模态选择集中参数或连续体模型。
  • 柔性关节的弹簧阻尼模型给出自然频率与阻尼比，欠阻尼系统的整定时间约 4/(ζω)，是到位等待时间的依据。
  • 软体臂的常曲率模型提供解析正运动学，零曲率退化分支必须处理，大变形工况需要分段与在线校正。
  • 振动抑制先用限速降低激励能量，再用 ZV 整形消除振荡模式，最后以到位等待与闭环确认收尾。
  • MoveIt2 的刚体假设通过虚拟关节离散化、保守速度约束与视觉闭环补偿适配柔性平台，下一章进入仿真环境中的操作任务验证。
