第四篇 · 抓取与操作任务

第 061 章：抓取生成 Grasp Generation 基础

抓取任务的第一问是"抓哪里"：本章从接触力学与摩擦锥（Friction Cone）出发，推导对跖抓取（Antipodal Grasp）条件与力闭合（Force Closure）判据，并给出可自实现的采样式抓取生成流程。

  • 主题：抓取任务 / 抓取生成（Grasp Generation）
  • 关键机制：摩擦锥判据 / 力闭合 / 对跖采样 / 抓取质量度量
  • 预计学时：50 分钟
  • 前置章节：第 060 章

学习目标

  • 理解三类接触模型（点接触、线接触、软指接触）与摩擦锥（Friction Cone）的几何含义，能写出摩擦角关系 tan α = μ。
  • 掌握对跖抓取（Antipodal Grasp）条件与力闭合（Force Closure）判据的区别，能说明二指平行夹爪在三维空间中的挺抗能力边界。
  • 掌握采样式抓取生成（Sampling-Based Grasp Generation）的四步流程：表面采样、配对检查、几何过滤、执行性过滤。
  • 会为给定物体设计抓取生成参数表（采样数、张开行程、摩擦系数、候选保留数），并说明每项取值依据。
  • 能解释 MoveIt2 在抓取生成环节的架构位置：为什么抓取候选由外部节点产生，moveit_msgs 只提供 GraspPlanning 服务定义。

背景与动机

第一至第三篇解决的是"给定目标位姿后如何运动"：规划管线（Planning Pipeline）把关节空间或笛卡尔空间的目标变成可执行轨迹。抓取任务则多出前置一问：目标位姿本身要从物体的几何与物理条件中推导出来。这一推导过程称为抓取生成，其输出是若干抓取候选（Grasp Candidate），每个候选包含夹爪在抓取瞬间的六维位姿、张开量与质量评估。

在 MoveIt2 架构中，抓取生成不属于 move_group 的默认能力：move_group 负责运动规划与轨迹执行，moveit_msgs 仅保留抓取规划服务（GraspPlanning）的接口定义，用于把抓取生成委托给外部生成器节点。因此掌握生成算法本身是构建抓取系统的必要前提。

本章讲"如何从几何生成候选"，第 069 章讲"如何结合具体机械臂的运动学评分与细化候选"，第 062 章开始讲拿到候选之后如何组织 Pick and Place 管线。

核心原理

1. 接触模型与摩擦锥

抓取分析的第一步是选定接触模型。接触模型决定能传递哪些力与力矩，也决定抓取稳定性分析的精度上限。

接触模型可传递量典型适用对象约束形式
无摩擦点接触（Frictionless Point Contact）沿法向的推力理想化分析、形闭合推导切向力恒为零
有摩擦点接触（Point Contact with Friction）法向力与两维切向力硬质指尖、金属爪库仑锥约束
软指接触（Soft Finger Contact）再加绕法向的力矩橡胶指尖、大面积贴合库仑锥加力矩上限

有摩擦点接触遵守库仑摩擦定律（Coulomb Friction Law）：切向力大小不超过法向力的 μ 倍，等价于说接触力向量必须落在以法向为中心、半角为 α 的圆锥内，这个圆锥称为摩擦锥。

|ft| ≤ μ fn，α = arctan μ μ = 0.2 → α ≈ 11.3°；μ = 0.5 → α ≈ 26.6°；μ = 0.8 → α ≈ 38.7°

摩擦锥把"能出多大的力"变成一个纯几何问题：判断某个方向的力是否可传递，只需判断该方向是否落在锥内。后续所有判据都建立在这个几何视角上。

2. 对跖条件与力闭合

二指平行夹爪的经典稳定条件是对跖抓取：两个接触点的连线（接触法线方向）必须同时落在两个接触处的摩擦锥内。直观理解：夹紧时两指沿连线方向推压，切向分量由摩擦承担；若连线偏出摩擦锥，所需切向力超过 μ fn，接触点会滑移。

更严格的概念是力闭合（Force Closure）：一组接触所能产生的力旋量（Wrench，力与力矩合称）通过正系数线性组合，能够平衡任意方向的单位外部旋量。用公式表达为，对任意外部旋量 wext，存在非负组合系数 λi ≥ 0，使得

Σ λi wi = −wext，且每个接触力满足摩擦锥约束 力旋量空间为 6 维（3 力 + 3 力矩），正张成需要足够多且方向分散的接触

三维空间中无摩擦点接触实现形闭合（Form Closure）至少需要 7 个接触点（按正张成维数计数：6 维旋量空间至少需 7 个非负射线；平面情形对应 4 个）；有摩擦的二指点接触提供 2 个仅含 3 个独立分量的锥，无法正张成完整的 6 维空间，因此在"任意外力均可抵抗"的严格意义下并不构成力闭合。工程上二指平行夹爪依赖指尖接触面尺寸、材料摩擦与重力方向的准静态条件，用"摩擦锥余量 + 抗扰度量"代替严格证明。

刚度结论：为什么对跖条件仍然实用？

在桌面抓取这类准静态任务中，外部扰动主要来自重力与惯量，方向集中在竖直轴及其邻域。对跖抓取配合足够大的夹紧力，可在这类扰动方向上建立余量充足的支持。因此生成算法以对跖条件为硬过滤，以摩擦锥余量为主要排序依据，把"任意方向鲁棒"的严格目标降级为"可量化余量"的工程目标。

3. 抓取质量度量

候选之间需要可比较的分数。常用度量来自 Ferrari-Canny：把每个接触处能满足摩擦锥约束的单位力旋量收集成一个凸集合 W，W 的最大内接球半径即最坏方向上仍可抵抗的单位外力大小，归一化后记作 ε ∈ [0, 1]，ε 越大抓取越稳健。

另一个常用指标是抗滑余量：对两指竖直抓取质量为 m 的物体，设两接触处摩擦系数均为 μ，安全系数 s ≥ 2，则单指法向力需满足

N ≥ s · m g / (2 μ) m = 1 kg、μ = 0.4、s = 2 时 N ≥ 24.5 N，落在常见夹爪 5–50 N 的出力区间内

这一估算直接指导夹持力参数：摩擦系数越保守（取 0.3–0.5 而不用标称 0.8）、安全系数越大，所需夹持力越高；夹持力上限又受物体强度与夹爪行程驱动能力限制，两侧共同夹住可行区间。

4. 采样式生成流程与计算代价

采样式生成把连续问题离散化为四步：

  1. 表面采样：在物体表面按面积或曲率均匀采样接触点与该点法向，采样数 N 取 500–2000。
  2. 配对检查：两两配对，检查对跖条件与张开量范围，复杂度为 O(N²)。
  3. 几何过滤：剔除退化点对、落在棱边与尖角附近的点对，保留几何上干净的候选。
  4. 执行性过滤：对幸存候选做逆运动学（Inverse Kinematics, IK）、碰撞与接近路径可达性检查，昂贵检查必须放最后。

代价结构决定了实现顺序：N = 500 时配对约 1.25 × 105 次，每次几何检查是常数级运算；而一次 IK 求解与碰撞查询的开销高出数个量级。把 IK 检查放在几何过滤之后，可把昂贵查询次数从十万量级压到百量级，这就是"廉价判据先做、昂贵判据后做"的过滤链设计依据。

实现思路与设计

抓取生成节点的标准实现分七步，每步都有明确的输入输出与失败处置：

  1. 输入装配：物体碰撞几何（Collision Geometry）、夹爪模型（张开行程、指尖几何）、摩擦系数估计、场景坐标系。
  2. 法向预处理：统一网格法向方向，检查外法向与质心连线一致，剔除自交与退化三角形。
  3. 接触采样：按面积加权采样，输出点与法向数组。
  4. 配对与对跖过滤：对每对点做张开量检查与摩擦锥检查，记录余量。
  5. 候选构造：由接触点、连线方向与接近方向构造夹爪位姿，形成抓取候选结构。
  6. 排序与截断：按摩擦锥余量与张开量适配度加权排序，保留前 K 个（K 取 20–50）。
  7. 输出：填充 moveit_msgs/Grasp 数组，或发布到自定义话题供 Pick 管线消费。

关键代码与解读

片段 1：摩擦锥与对跖条件检查

import math

def friction_angle(mu):
    # 摩擦锥半角 α = arctan(μ)：μ 越大锥越宽，可抓方向越多
    return math.atan(mu)

def antipodal_ok(p1, p2, n1, n2, alpha):
    """判断两接触点连线是否同时落在两个摩擦锥内。
    p1、p2 为接触点，n1、n2 为物体表面内法向（指向物体内部）。"""
    d = (p2[0] - p1[0], p2[1] - p1[1], p2[2] - p1[2])
    L = math.sqrt(d[0] ** 2 + d[1] ** 2 + d[2] ** 2)  # 点间距，供张开量检查复用
    if L < 1e-6:
        return False, L, math.pi  # 退化点对：直接淘汰，余量记为最差
    u = (d[0] / L, d[1] / L, d[2] / L)  # 连线方向的单位向量
    # 连线方向与内法向夹角必须小于摩擦角，否则所需切向力超出摩擦上限
    c1 = u[0] * n1[0] + u[1] * n1[1] + u[2] * n1[2]
    c2 = -(u[0] * n2[0] + u[1] * n2[1] + u[2] * n2[2])
    t1 = math.acos(max(-1.0, min(1.0, c1)))  # clamp 防止浮点误差越界
    t2 = math.acos(max(-1.0, min(1.0, c2)))
    worst = max(t1, t2)  # 取较大夹角作为该点对的最差余量
    return (t1 <= alpha and t2 <= alpha), L, worst

解读：三个设计点。（1）函数返回 (是否满足, 点间距, 最差夹角) 三元组，让调用方一次拿到过滤与排序所需的全部信息，避免重复计算角度；点间距 L 同时服务于张开量检查，属于典型的"一次计算、多处复用"。（2）内法向方向的定义（指向物体内部）决定了第二个点处连线方向的符号，代码中用负号处理，这是抓取代码中最容易出错的方向约定。（3）max/ min 截断保证反余弦在数值误差下不产生 NaN。

片段 2：按面积加权的表面采样

import random

def sample_box_surface(half, n=500):
    """在长方体表面近似均匀采样接触点与内法向。
    half 为三个半轴长；按面积配额分配采样数，避免小面覆盖不足。"""
    areas = (4 * half[1] * half[2], 4 * half[0] * half[2], 4 * half[0] * half[1])
    total = sum(areas)
    pts, nrms = [], []
    for axis in range(3):
        cnt = max(1, int(n * areas[axis] / total))  # 面积配额：大面多采样
        for _ in range(cnt):
            sgn = random.choice((-1.0, 1.0))  # 法向轴上的两个面
            a, b = [k for k in range(3) if k != axis]  # 面上两个自由坐标
            p = [0.0, 0.0, 0.0]
            p[axis] = sgn * half[axis]  # 面到中心的距离等于对应半轴长
            p[a] = random.uniform(-half[a], half[a])
            p[b] = random.uniform(-half[b], half[b])
            nrm = [0.0, 0.0, 0.0]
            nrm[axis] = sgn  # 外法向与面朝向一致
            pts.append(tuple(p))
            nrms.append(tuple(-v for v in nrm))  # 统一转为内法向供判据使用
    return pts, nrms

解读：采样策略直接决定候选质量。（1）按面积配额分配采样数，等价于在平面上做面积均匀采样；若对每个面平均分配，小面会获得过多采样，大面覆盖稀疏。（2）面片采样只用了两个自由坐标，第三个坐标由面位置确定，这种参数化避免了对曲面求逆的复杂性，适用于盒类物体的快速实现；对任意网格则应改用三角形面积累积分布的采样。（3）采样阶段就统一转向内法向，把方向约定收敛在一处，后续判据代码无需再关心朝向。

片段 3：配对过滤与排序

import math

def generate_candidates(pts, nrms, w_min, w_max, alpha, top_k=30):
    """两两配对做对跖与张开量过滤，按摩擦锥余量排序输出前 top_k 个候选。"""
    cands = []
    n = len(pts)
    for i in range(n):
        for j in range(i + 1, n):
            dx = pts[j][0] - pts[i][0]
            dy = pts[j][1] - pts[i][1]
            dz = pts[j][2] - pts[i][2]
            L = math.sqrt(dx * dx + dy * dy + dz * dz)
            if L < w_min or L > w_max:
                continue  # 超出夹爪行程的点对先淘汰，省下角度计算
            ok, _, worst = antipodal_ok(pts[i], pts[j], nrms[i], nrms[j], alpha)
            if not ok:
                continue  # 连线不在双摩擦锥内，夹紧时会滑移
            cands.append((alpha - worst, pts[i], pts[j], L))
    cands.sort(key=lambda c: -c[0])  # 余量越大抗扰越强，降序排列
    return cands[:top_k]

解读：这段代码体现过滤链的顺序原则。（1）先算距离并做行程检查，再算夹角；距离计算只涉及乘法与开方，比反余弦便宜，把拒绝成本最低的判据放最前。（2）排序键取摩擦角减最差夹角，即"允许的扰动角范围"，物理含义直观且与其他候选可比。（3）只返回前 K 个候选，把后续 IK 与碰撞检查的调用次数控制在百量级。替代方案是用力闭合度量做更精确的打分，代价是需要构造力旋量集合，适合离线分析而不适合在线逐点配对。

常见坑

  • 网格法向朝向混乱：STL 类网格不保证法向朝向一致。症状是对跖检查几乎全部失败，或抓取方向指向物体内部。修复：做一致性重定向（相邻三角形法向夹角与公共边方向共同判据），并检查外法向与"点减质心"方向的内积为正。
  • 跳过执行性过滤就输出候选：生成上百候选全部发给规划层，规划成功率低且规划时间被耗尽。修复：在生成节点内执行过滤链，先做运动学可达性粗筛，再做碰撞检查，最后按质量排序截断。
  • 把对跖条件当作任意外力下的稳定性证明：二指点接触在严格意义下不构成三维力闭合。症状是理论"稳定"的抓取在加减速阶段打滑。修复：以摩擦锥余量排序，配合夹持力估算 N ≥ s·mg/(2μ) 设夹紧力，加速度大的任务再降速。
  • 摩擦系数取乐观值：按标称 0.8 计算，实际表面有油污或灰尘时迅速滑移。修复：取 0.3–0.5 的保守值，并将真机滑移试验结果回写参数表。
  • 张开量与坐标系约定不一致：最小张开用毫米而行程用米，过滤失效；抓取位姿表达在物体局部坐标系却直接当作规划坐标系使用。修复：生成节点内统一 SI 单位，位姿一律附带 frame_id，消费端用 tf2 变换后再规划。

练习与思考

  1. 取 μ = 0.4，计算摩擦角 α。若某对接触点的连线与两处内法向夹角分别为 20° 与 25°，该点对是否满足对跖条件？请给出余量。★
    提示
    α = arctan 0.4 ≈ 21.8°。第二处夹角 25° 超过 α，不满足；该点对最差余量为 21.8° − 25° = −3.2°，排序时应被淘汰。
  2. 把表面采样数从 500 提到 2000，配对检查次数变为原来的多少倍？候选数量是否也按同样比例增长？说明原因。★★
    提示
    配对次数按 N² 增长，为 16 倍。候选数增长远小于 16 倍：邻近点对会产生大量近似重复的候选，且几何过滤对密集采样最不敏感，收益递减。
  3. 推导两指竖直抓取的最少夹持力公式 N ≥ s·mg/(2μ)：写出竖直方向力平衡方程，代入 m = 1 kg、μ = 0.4、s = 2 求 N。★★
    提示
    两接触处摩擦力之和需平衡重力：2μN ≥ mg，乘安全系数得 N ≥ s·mg/(2μ) = 2 × 9.8 / (2 × 0.4) = 24.5 N，注意与夹爪出力上限对照。
  4. 为三类物体设计抓取生成参数表：金属圆柱罐（高 0.12 m、直径 0.06 m、重 0.4 kg）、薄板（厚 0.004 m）、软包装袋（可变形）。说明摩擦系数、开口方向、最小张开的取值差异与理由。★★★
    提示
    圆柱罐取侧面两个对跖点，张开量按直径加间隙；薄板只能沿厚度方向对跖，需要指尖有足够平面贴合面积，并检查板面弯曲风险；软包装的接触几何随夹紧变形，需降低夹持力上限并留泄压策略。

小结

  • 接触模型决定抓取分析能力上限；有摩擦点接触的库仑约束几何化为摩擦锥，半角 α = arctan μ。
  • 对跖条件是二指平行夹爪的硬过滤：两接触点连线必须同时落在两个摩擦锥内。
  • 力闭合要求接触旋量正张成六维空间，二指点接触不满足严格定义，工程上以摩擦锥余量与抗扰度量替代。
  • 采样式生成按"表面采样 → 配对过滤 → 几何过滤 → 执行性过滤"顺序执行，廉价判据先做，昂贵判据后做。
  • 夹持力估算 N ≥ s·mg/(2μ) 把物体质量与摩擦条件连接到夹爪出力参数，典型值落在 5–50 N。
