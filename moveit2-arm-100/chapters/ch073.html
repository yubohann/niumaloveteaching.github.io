第 073 章：移动机械臂操作

把底盘并入操作链条：九自由度系统的冗余利用、分层与统一规划的权衡、停靠位姿的采样求解，以及底盘定位误差的感知闭环补偿。

  • 主题：平台形态 / 移动机械臂（Mobile Manipulator）
  • 关键机制：冗余自由度分配 / 停靠位姿选择 / 感知闭环补偿
  • 预计学时：55 分钟
  • 前置章节：第 072 章

学习目标

  • 掌握移动机械臂的自由度构成（底盘平面运动 3 加机械臂 n），理解冗余自由度在任务中的分配方式。
  • 理解分层规划（导航、停靠、操作）与统一规划（Whole-Body）的权衡，能按任务规模选择方案。
  • 会求解底盘停靠位姿：以采样加逆运动学过滤加评分的方式选择使臂处于优选的位姿。
  • 掌握底盘定位误差（1–5 cm）对抓取精度的影响，能说明感知闭环补偿链条的每一步。
  • 会在 URDF 与 SRDF 中表达运动底盘（平面关节或虚拟关节）并配置底盘、臂与整体的规划组。

背景与动机

机械臂固定安装时，可达范围由臂长决定；把臂装到移动底盘上，作业范围扩展到整个环境，代价是引入一个新的误差与控制层级：底盘能带来米级的定位能力，也能带来厘米级的定位误差。移动机械臂的操作问题由此分裂为两级：底盘负责把目标带入臂的有利工作空间，臂负责毫米级的抓取精度。

在 MoveIt2 中，移动底盘的表达方式是关键工程决策：URDF 可以用平面关节（Planar Joint）描述底盘的平面运动，由此构造包含底盘与臂的规划组做统一规划；也可以保持底盘在规划体系之外，由导航栈负责停靠，MoveIt2 只规划臂。两种路径在规划维度、精度保证与实现复杂度上各有取舍。

本章与上一章的衔接：第 072 章的闭链约束讨论"两臂如何耦合"，本章讨论"底盘与臂如何分工"；与第一、二篇的衔接：底盘带来的场景变化需要规划场景同步（第 034 章）与坐标对齐（第 098 章的回溯）。

核心原理

1. 自由度构成与冗余

移动机械臂由平面移动底盘与机械臂串联组成：

总自由度 = 3（底盘 x、y、θ）+ n（臂关节）；冗余度 = 3 + n − 6 底盘 3 加六轴臂 6 共 9 自由度，任务空间 6 维，冗余 3 维；底盘的位置自由度可替换臂的部分伸展，形成"移动换位形"能力

冗余的三个用途：其一把目标带入臂的优选工作空间中心，远离边界与奇异位形；其二为臂规避关节限位与自碰撞提供额外位形；其三让底盘承担大范围移动，臂只做局部精调，降低对臂长与臂展的要求。冗余也带来代价：规划维度上升，采样规划的搜索难度随维数指数增长，这是分层方案存在的原因。

2. 分层规划与统一规划的权衡

方案结构优点代价
分层规划导航层到停靠点，操作层规划臂各层成熟独立，规划时间可控，诊断清晰停靠点误差需补偿，底盘在操作中不可动
统一规划底盘与臂同一规划组联合规划可边移动边调整，工作空间利用充分维度高、规划时间长，底盘模型需要近似

统一规划中底盘通常以平面关节建模，关节的位移范围对应可达区域。需要注意差速底盘的实际运动受非完整约束限制（不能横向平移），而平面关节模型是完整的：规划出的横向位移无法被底盘精确执行，只能由底盘控制器通过"旋转加前进"的路径跟踪近似。因此统一规划更适用于全向底盘或左右轮独立转向的平台，差速平台宜采用分层方案并把底盘运动限制为小幅调整。

3. 停靠位姿选择

停靠位姿的质量由三个因素决定：目标在臂工作空间中的裕度、底盘位姿的可行性与到作业区的路径代价。求解方式是离散采样加过滤加评分：

  1. 采样：以目标为圆心，距离取若干档（0.4 m 至 0.8 m），朝向以 15° 间隔一圈采样。
  2. 过滤：对每个候选底盘位姿求臂的逆运动学，失败或碰撞的候选淘汰。
  3. 评分：以相对可操作度（第 069 章）为主要指标，叠加关节裕量与底盘路径长度惩罚。

朝向安排的经验规则是让底盘正对目标：此时臂在自然姿态下向前伸展，肩部与腕部关节远离限位。距离档位的取舍：过近时臂处于折叠位形，接近奇异；过远时臂接近完全伸展，同样接近奇异，0.4–0.8 m 的区间对应目标位于臂展的中段。

4. 底盘定位误差与感知闭环

底盘导航到停靠点后的重复定位误差：激光导航 1–5 cm，反光标记或二维码辅助可到 0.2–1 cm。抓取容差通常在 2 mm 量级，底盘误差比抓取容差大一个数量级，任何"用标称停靠位姿计算抓取位姿"的做法都会把厘米级误差带入抓取闭环。

补偿链条有三层，工程上组合使用：

  • 二次对准：到达停靠点后用视觉标记微调底盘位姿，把误差压缩到 5 mm 量级。
  • 感知闭环：目标位姿由安装在臂上或车体上的相机实时测量，直接输出臂基座坐标系下的位姿，测量结果天然包含底盘的实际位置，标称停靠位姿不参与抓取计算。
  • 臂内冗余补偿：目标仍在臂工作空间内时，臂按实测目标位姿规划，底盘误差由臂的姿态调整吸收。

核心结论：移动机械臂的抓取精度由感知闭环保证，底盘定位精度只决定"目标是否落在臂的工作空间内"。

实现思路与设计

移动抓取的实现步骤：

  1. 目标感知：获取目标在导航坐标系下的位姿，评估置信度与遮挡情况。
  2. 停靠求解：采样底盘位姿、求臂逆解、评分排序，输出停靠点与朝向。
  3. 导航与二次对准：导航到停靠点，视觉标记微调，记录实测底盘位姿。
  4. 目标复测：以实测位姿与相机数据重新计算目标在臂基座坐标系中的位姿。
  5. 抓取执行：复用第 062 章的管线，含夹持力与确认逻辑。
  6. 失败恢复：抓取失败时依次尝试重新复测、切换候选抓取、重新停靠（最多两次）。

设计决策：为什么不让底盘直接承担抓取精度？

底盘定位依赖轮式运动与外部定位源，误差来源多且随环境变化；臂的运动学精度在标定后稳定在亚毫米量级。让底盘负责"到达"、臂与感知负责"精确"，各层的误差预算与职责边界清晰，也使得升级路径明确：需要更高精度时改进感知与臂标定，更换底盘定位系统的收益有限。

关键代码与解读

片段 1：停靠位姿采样

import math

def dock_candidates(target_xy, dists=(0.4, 0.6, 0.8), n_ang=24):
    """围绕目标采样停靠位姿：距离分档、朝向一圈均匀采样。"""
    out = []
    for k in range(n_ang):
        ang = 2.0 * math.pi * k / n_ang      # 底盘相对目标的方位角
        for d in dists:
            # 底盘放在目标的 ang 方向 d 距离处，朝向面对目标
            x = target_xy[0] - d * math.cos(ang)
            y = target_xy[1] - d * math.sin(ang)
            out.append((x, y, ang))          # (x, y, θ) 平面位姿
    return out

# 24 个方位 × 3 档距离 = 72 个候选：够覆盖可行域，逆解调用量可控

解读：（1）朝向取"面对目标"（θ 等于方位角），对应臂自然前伸的姿态；如果需要侧向作业（例如贴墙），可把朝向偏移作为参数扩展该函数。（2）距离分档 0.4、0.6、0.8 m 覆盖臂展中段：候选越靠近目标越容易碰撞车体与工装，越远越接近伸展奇异。（3）候选总数 72 是采样量与逆解代价的折中：每次候选评估含一次臂逆解，总调用量在百次量级，可在任务层实时完成。

片段 2：停靠候选过滤与评分

def select_dock(candidates, ik_feasible, score):
    """对候选底盘位姿逐一评估：逆解可行者按评分取最优。"""
    best, best_s = None, -1e9
    for (x, y, th) in candidates:
        sol = ik_feasible(x, y, th)     # 内部把底盘位姿折算到臂基座坐标系
        if sol is None:
            continue                    # 逆解失败、超出限位或碰撞：淘汰
        s = score(sol)                  # 评分：相对可操作度、关节裕量、路径代价
        if s > best_s:
            best, best_s = (x, y, th), s
    return best, best_s

解读：（1）接口把"底盘位姿是否可行"封装为逆解可行性函数，实现层负责坐标折算（底盘位姿到臂基座变换）与碰撞检查，任务层只消费结果，职责边界清晰。（2）评分以相对可操作度为主、关节裕量与路径代价为辅，与第 069 章的评分结构保持一致，参数可复用。（3）返回最优位姿与分数：分数同时用于判断是否需要重停靠（分数过低说明没有好的作业位姿，应上报处理，不得硬执行）。

片段 3：目标位姿的感知闭环变换

import math

def map_to_base(target_map, base_measured):
    """把目标在导航坐标系中的位姿变换到臂基座坐标系。"""
    dx = target_map[0] - base_measured[0]
    dy = target_map[1] - base_measured[1]
    th = base_measured[2]                     # 底盘实测朝向（非标称值）
    # 逆变换 R(−th)：得到目标在底盘/臂基座坐标系中的表达
    x = math.cos(th) * dx + math.sin(th) * dy
    y = -math.sin(th) * dx + math.cos(th) * dy
    return x, y

# 底盘定位误差 3 cm：该误差会原样出现在输出中；
# 抓取前用臂上相机直接测量目标可跳过这一误差源

解读：（1）变换使用实测底盘位姿，导航栈下发的标称位姿不进入该计算，这是补偿链条中成本最低的一步：同样的测量数据，换一个参考点即可让臂的规划吸收底盘定位误差。（2）误差的传播是透明的：底盘位置误差直接叠加到输出，朝向误差则随目标距离放大（0.6 m 处的 1° 朝向误差对应约 10 mm 位移），因此朝向的二次对准优先级高于位置。（3）若目标位姿由臂载相机经手眼标定直接给出，该变换整体被跳过，这也是"感知闭环优于绝对定位"的直接体现。

常见坑

  • 用标称停靠位姿计算抓取位姿：厘米级底盘误差全部进入抓取，规划成功但抓不到。修复：以实测位姿做坐标变换，抓取前用臂载相机复测目标。
  • 统一规划维度失控：底盘与臂联合规划时间过长，任务节拍无法满足。修复：分层处理，底盘负责大范围移动，联合规划只在小范围内使用。
  • 忽略非完整约束：按平面关节规划出横向位移，差速底盘无法执行导致路径偏差。修复：统一规划限于全向底盘或小幅调整；差速平台由底盘控制器跟踪并接受位置误差。
  • 停靠距离不当：过近使臂折叠接近奇异，过远使臂完全伸展且误差放大。修复：距离分档取臂展中段（0.4–0.8 m），用相对可操作度评分过滤。
  • 底盘与臂的碰撞矩阵未配置：车体与臂的自碰撞漏检，或在装载工装后频繁误报。修复：在 SRDF 中配置底盘、臂、工装之间的碰撞矩阵，并随工装变更同步更新。

小结

  • 移动机械臂的自由度为底盘 3 加臂 n，冗余用于选择有利位形、规避限位与扩大作业范围。
  • 分层规划与统一规划的取舍由平台类型与节拍决定：差速平台宜分层，全向平台可用小幅统一规划。
  • 停靠位姿由采样加逆解过滤加可操作度评分求解，距离取臂展中段、朝向面对目标。
  • 底盘定位误差比抓取容差大一个数量级，抓取精度由二次对准与感知闭环保证，标称停靠位姿不进入抓取计算。
  • 底盘在 URDF 中以平面关节或虚拟关节表达，碰撞矩阵需覆盖车体、臂与工装，下一章讨论多机械臂共享工作空间的协调问题。
