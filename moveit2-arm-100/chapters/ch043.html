第三篇 · 规划算法与求解器

第 043 章：轨迹优化基础

采样规划器负责"找到一条可行路径"，轨迹优化（trajectory optimization）负责"把它变得平滑、远离障碍、满足时限"。本章建立代价泛函、梯度更新与时间参数化的完整认知框架，为 CHOMP 与后续优化型规划器铺路。

  • 主题：轨迹优化 / 代价泛函与数值求解
  • 关键机制：平滑度代价、障碍代价、协变梯度、时间参数化
  • 预计学时：55 分钟
  • 前置章节：第 042 章

学习目标

  • 理解"可行解"与"最优解"的区别，能说清轨迹优化在规划系统中的定位与输入输出。
  • 掌握轨迹代价泛函的分解：平滑度项、障碍项、动力学项，以及各项的数学形式与几何直觉。
  • 理解离散化轨迹上的梯度下降与协变梯度（covariant gradient）的差异，认识局部极小问题的来源。
  • 能区分两类任务：几何优化（改变路径形状）与时间参数化（只改时间轴），知道它们在 MoveIt2 中的实现组件。
  • 会为优化型规划器准备合格初值，并会用路径长度、最小间隙、平滑度指标对结果做量化校验。

背景与动机

RRT、PRM 一类采样规划器的目标是概率完备：只要有解，给足时间就能找到。它们对解的质量不做保证，输出的折线轨迹常常带着冗余拐点、贴着障碍边缘、速度剖面粗糙。对于接近操作、视觉扫查、节拍敏感的任务，"存在解"远不够，"好解"才是交付标准。

轨迹优化把整条轨迹当作可变形对象，通过最小化代价泛函同时改善平滑度与间隙。它也是理解 CHOMP、STOMP、TrajOpt 等规划器的公共基础，本章先建立这套语汇，第 044 章再落到具体实现。

核心原理

1. 轨迹的离散表示与优化变量

连续轨迹是关节空间中的曲线 q(s)，s ∈ [0, 1]。数值方法将其离散为 n+1 个路径点（waypoint）：

ξ = (q0, q1, 依次至 qn)，端点 q0、qn 固定 内部点 q1 至 qn−1 是优化变量；分辨率用路径点间距度量，常见 0.01 到 0.1 rad 量级

端点由起点与目标决定，内部点自由，优化问题等价于"在端点之间拉伸一条曲线，直到代价最小"。分辨率决定规模：点越密越能刻画细节，单次迭代代价越高。分辨率的选择是精度与计算量的第一权衡。

2. 代价泛函：三项分解

目标函数是若干代价项的加权和：

J[ξ] = wsmooth · Jsmooth + wobs · Jobs + wdyn · Jdyn 权重决定"更平滑"与"更远离障碍"的取舍，量纲不同需要归一化

平滑度项惩罚曲线的曲率或速度突变。加速度形式为：

Jsmooth = ½ Σi ‖qi+1 − 2qi + qi−1‖² 几何直觉：像绷紧的橡皮筋，把轨迹拉直，抑制锯齿与急转

障碍项基于有符号距离 d(x)（signed distance）构造铰链函数，仅在距离小于安全阈值 ε 时生效：

c(d) = −d + ε，当 d < ε；c(d) = 0，当 d ≥ ε d 由规划场景的距离场查询得到；c 对 q 的梯度经雅可比链式传播：∇qc = J(q)T ∇xc

工作空间中的代价沿弧长积分得到轨迹总障碍代价，其中弧长加权因子 ‖x′(s)‖ 让这一积分与运行速度无关：同一路径无论快慢，总障碍代价相同。障碍项以软惩罚（penalty）的形式参与优化：优化结束后仍须做碰撞校验，这是优化型规划器与采样规划器在工程流程上的关键差别。

动力学项惩罚关节力矩（含惯量矩阵 M(q)），多数操作场景可以缺省，由后处理阶段的限定代替。

3. 梯度下降与协变更新

对离散轨迹，梯度的最简更新为沿负梯度方向移动：

ξ ← ξ − η ∇J[ξ] η 为步长；步长过大震荡，过小收敛慢

该更新对参数化敏感：离散步长变化时梯度势能失衡，轨迹可能越优化越僵硬。协变梯度方法引入平滑度矩阵 A（平滑项的海森矩阵）作为度量，更新变为：

ξ ← ξ − η A−1 ∇J[ξ] A−1 的作用是把更新"抹匀"到整条曲线上，等价于在函数空间中下降

协变更新是 CHOMP 类方法的数学基石，它保证优化结果与离散化细节解耦。代价函数非凸，优化只能收敛到局部极小：初值轨迹穿过障碍带或贴着窄通道壁时，容易停在"绕不出去"的形状。随机化手段（随机下降、哈密顿蒙特卡洛扰动）用于帮助逃逸，代价是引入随机性与额外迭代。

4. 几何优化与时间参数化的分工

一条可执行轨迹携带两层信息：几何路径（形状）与时间剖面（什么时候到哪个点）。两类处理分别针对它们：

层对象方法示例是否改变几何形状
几何优化路径点序列梯度型（CHOMP）、随机型（STOMP）、序列凸型（TrajOpt）是
时间参数化速度、加速度、时间戳时间最优参数化、基于滤波器或采样平滑的实现否（以所用实现为准，重采样后需复核）

采样规划器与优化型规划器输出的都是几何轨迹，都需要时间参数化这一关。把两层分开治理是调参时定位问题范围的抓手：几何问题看间隙与形状，时间问题看速度剖面与时长。

实现思路与设计

引入轨迹优化的典型流程：

  1. 准备初值：来源可以是直线插值、采样规划器解或人工示教轨迹。初值的可行性决定优化起点质量。
  2. 选择分辨率：以最小间隙尺度为准取点距，常见 0.01 到 0.05 rad；先用粗分辨率快速循环，再逐步加密。
  3. 设定权重：先单独调平滑项，再加障碍项；两项量纲不同，建议以"安全阈值 ε 下的代价量级"对齐。
  4. 迭代求解：以迭代上限与代价变化阈值双重终止；记录每轮代价，用于判断是否收敛或震荡。
  5. 时间参数化：对优化后的几何轨迹补时间剖面，随后做碰撞与限位复核。

参数总览

参数典型取值作用取值依据
路径点间距0.01 到 0.05 rad离散分辨率小于最小障碍尺度的一半即可，过细付出线性代价
平滑权重 wsmooth1.0（基准）平滑项强度作为其余权重的归一基准
障碍权重 wobs0.5 到 2.0（相对值）避障裕度安全阈值附近要显著影响形状
迭代上限100 到 500 次求解预算观察代价曲线进入平台段的位置
设计决策：为什么优化前必须先有可行初值

梯度方法沿代价下降方向移动，不具备"穿透"障碍重新寻路的能力。初值穿越障碍时，障碍代价把路径点推向障碍两侧，形成来回折叠的畸形结果。先用采样规划器求可行解，再交给优化层做美容（smoothing），这一"两段式"流程在复杂环境中最为稳妥。

关键代码与解读

片段 1：离散轨迹的平滑度代价与其梯度（numpy 原理演示）

import numpy as np

def smoothness_cost(xi):
    """xi: (n+1, d) 路径点序列。返回加速度平方和形式的平滑代价。"""
    acc = xi[2:] - 2 * xi[1:-1] + xi[:-2]   # 二阶差分：离散加速度
    return 0.5 * np.sum(acc ** 2)

def smoothness_grad(xi):
    """代价对内部路径点的梯度：a[j-1] - 2*a[j] + a[j+1]，等价于 A @ xi。"""
    acc = xi[2:] - 2 * xi[1:-1] + xi[:-2]   # a_1 到 a_{n-1}，共 n-1 项
    a_pad = np.pad(acc, ((1, 1), (0, 0)))   # 边界补零：a_0 = a_n = 0
    grad = np.zeros_like(xi)                # 端点固定，梯度在端点处保持 0
    grad[1:-1] = a_pad[:-2] - 2 * a_pad[1:-1] + a_pad[2:]
    return grad

xi = np.zeros((40, 2))
xi[:, 0] = np.linspace(0.0, 1.5, 40)        # 起点 0 到目标 1.5（弧度）
xi[1:-1, 1] = 0.3 * np.sin(np.pi * np.linspace(0.0, 1.0, 38))  # 人工制造波动

eta = 0.05                                  # 步长：与分辨率匹配，过大导致震荡
for it in range(200):
    xi[1:-1] -= eta * smoothness_grad(xi)[1:-1]
    if it % 50 == 0:
        print(f"迭代 {it:3d}，平滑代价 {smoothness_cost(xi):.5f}")

解读：这段代码复现"橡皮筋绷直"的过程。二阶差分的平方正比于曲率，最小化它等价于让轨迹接近直线；端点梯度为零保证起止位置不被破坏。梯度公式 a[j-1] - 2*a[j] + a[j+1] 是四阶差分的离散形式，边界补零自然降阶，正对应平滑度矩阵 A 的稀疏结构（练习 1 推导）。把 eta 从 0.05 调到 0.3，代价出现震荡甚至发散，这是参数化敏感性的迷你演示。

片段 2：时间参数化与平滑（MoveIt2 C++ 接口）

#include <moveit/trajectory_processing/time_optimal_trajectory_generation.h>
#include <moveit/trajectory_processing/ruckig_traj_smoothing.h>

// 给几何轨迹补时间剖面：速度缩放 0.5、加速度缩放 0.3（平台常见保守取值）
bool add_timing(moveit::planning_interface::MoveGroupInterface::Plan& plan,
                double velocity_scaling, double acceleration_scaling)
{
  // 时间最优参数化：在关节速度/加速度上限内求出最短执行时间
  trajectory_processing::TimeOptimalTrajectoryGeneration totg;
  if (totg.computeTimeStamps(plan.trajectory, velocity_scaling, acceleration_scaling))
    return true;

  // 备选：基于平滑滤波的实现，对加速度不连续的折线轨迹更友好
  // RuckigSmoothing::applySmoothing(plan.trajectory, velocity_scaling, acceleration_scaling);
  return false;
}

解读：时间参数化接收"形状已定"的轨迹，输出带时间戳的可执行轨迹。缩放因子的含义是"占模型上限的比例"：0.5 表示只用一半速度能力，给控制留裕量。两个实现的选择依据：时间最优参数化追求节拍；平滑实现对 jerk 敏感的场景更友好。注意 computeTimeStamps 返回布尔值，失败要回退处理。

片段 3：轨迹质量指标计算（用于优化前后对照）

import numpy as np

def path_quality(points, velocities=None):
    """points: (n+1, d) 关节路径点。返回长度、平滑度与最大关节步长。"""
    pts = np.asarray(points)
    steps = np.linalg.norm(np.diff(pts, axis=0), axis=1)
    length = float(steps.sum())                  # 关节空间欧氏长度
    acc = np.diff(pts, n=2, axis=0)
    smooth = float(0.5 * np.sum(acc ** 2))       # 与片段 1 同一口径
    max_step = float(steps.max())                # 单步最大跳变，反映采样均匀性
    return {"length": length, "smooth": smooth, "max_step": max_step}

# 用法：对同一起止的两条轨迹分别计算指标，量化"优化带来了多少改善"
before = path_quality(rrt_output_points)
after = path_quality(chomp_output_points)
print("长度变化", after["length"] - before["length"])
print("平滑度变化", after["smooth"] - before["smooth"])

解读：优化结论要能被验证。三个指标从不同角度描述质量：长度反映绕行程度，平滑度反映可控性，单步最大跳变反映离散均匀性。用同一函数处理优化前后两条轨迹，差值即改善量。第 047 章的基准测试会把这一思路扩展为多样本统计比较。

常见坑

  • 把软惩罚当硬保证：障碍项权重再大也只是代价，"优化后无碰撞"仍要独立校验。症状是优化轨迹的某些路径点进入安全阈值内部。修复：优化后沿轨迹重新做碰撞检测，必要时追加一轮细分辨率优化。
  • 初值穿越障碍直接开优化：梯度方法无法重新选路，结果在障碍两侧折叠。修复：先用采样规划器或人工路径给出可行初值。
  • 权重与量纲失配：位置误差按米、关节角按弧度衡量，直接照抄权重会偏向一侧。修复：先用单位化或按任务尺度归一，再调相对大小。
  • 分辨率与步长不匹配：点距 0.05 rad 时用 0.3 量级的步长，迭代震荡；点距 0.01 rad 时步长过小，收敛缓慢。修复：步长取点距的同一量级起步，观察代价曲线微调。
  • 时间参数化后不再复核：重采样或平滑实现可能微调路径点，产生新的近障点。修复：时间参数化完成后执行一次全轨迹校验，作为交付前的固定工序。

练习与思考

  1. 推导一维情形下 Jsmooth = ½ Σ (qi+1 − 2qi + qi−1)² 对内部点 qi 的偏导，并说明它由哪些邻项组成。★
    提示
    ∂J/∂qi = qi+2 − 4qi+1 + 6qi − 4qi−1 + qi−2，即四阶差分形式，只涉及相邻五个点。这正是协变更新中矩阵 A 的稀疏结构来源。
  2. 把障碍权重 wobs 从 0.5 提到 5.0，预测路径长度、最小间隙与迭代收敛速度的变化。★
    提示
    间隙增大、长度增加（绕行更保守）；障碍代价比重大导致收敛更慢、更易震荡。可在同一初值上比较两条曲线验证。
  3. 设计一个两段式规划流程：采样规划器出可行解，优化层美容，再做时间参数化。画出数据流，并写出每一步的失败回退策略。★★
    提示
    采样失败则报无解并压缩工作空间；优化失败则退回采样原解（仍可执行）；时间参数化失败则降缩放因子重试。回退策略的价值在于保证"最差也有可交付结果"。
  4. 测量某任务上优化前后轨迹的路径长度、平滑度与执行时长，分析三者的相关性。若平滑度显著改善而执行时长不变，说明哪种代价项起了主导作用？★★★
    提示
    执行时长由时间参数化在速度上限内决定，几何平滑改善不必然缩短时长。平滑度主导时，形状更顺但速度剖面受关节上限约束，时长可能持平。

小结

  • 轨迹优化把离散化路径点作为优化变量，在固定端点之间最小化代价泛函，改善平滑度与间隙。
  • 代价泛函由平滑项、障碍项与动力学项加权组成；障碍项是软惩罚，优化后必须独立校验碰撞。
  • 协变梯度用平滑度矩阵的逆抹匀更新，使结果与离散化细节解耦，是 CHOMP 类方法的基石。
  • 代价非凸，初值质量决定结果质量；复杂场景采用"采样出可行解、优化做美容、时间参数化收尾"的两段式流程。
  • 几何优化与时间参数化分属两层，调参时先定位问题层级，再动对应参数。
