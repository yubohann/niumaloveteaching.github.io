第 036 章：方向约束与位置约束

两类几何约束逐字段展开：方向约束的锥形容差与四元数距离、位置约束的区域并集与偏置语义、两者组合时的误差预算公式，以及环形路径约束的构造代码。

  • 主题：运动学约束构造 / 几何语义
  • 关键机制：轴向容差与球面帽、区域并集的点包含判定、旋转误差到线位移的换算
  • 预计学时：55 分钟
  • 前置章节：第 035 章

学习目标

  • 掌握方向约束（OrientationConstraint）的字段结构与几何含义：目标四元数、三根轴的角容差、权重的语义。
  • 掌握位置约束（PositionConstraint）的字段结构：受约束点、偏置、区域并集与位姿描述，理解点包含判定规则。
  • 会用四元数角距离公式核对姿态偏差，能按工艺公差把角度换算为末端线位移误差。
  • 能程序化构造复合区域（如环形路径约束），并解释分区数量与重叠量对可行集的影响。
  • 能执行位置与方向约束的联合误差预算：确定各自容差的分配比例。

背景与动机

第 035 章把约束的机制与流程讲完，本章回答"字段怎么填、数值怎么定"。方向与位置是任务语义中最常见的两类要求：贴装要求端面平行度与位置精度，焊接要求工具指向沿缝，搬运要求工件姿态稳定。它们分别由方向约束与位置约束表达，而两者的容差取值互相耦合：姿态的角偏差在末端会转化为线位移，线位移预算与位置容差共享同一个额度。

字段语义的细节直接决定成败。角容差的单位是弧度，误写成度数会把容差放大几十倍；区域并集是"点在任意一个区域内即通过"，构造时的空隙与重叠决定约束边界的连续性；偏置点的参考系理解错误，会让约束施加在错误的位置上。本章把这些字段逐一落到几何与公式上，给出可直接使用的误差预算方法。关节约束与可见性约束留给下一章。

核心原理

1. 方向约束：目标姿态加轴向容差

方向约束描述"某个连杆的姿态应当接近给定姿态"：字段给出参考系、连杆名、目标姿态四元数、三根轴的绝对角容差（单位弧度）与权重。几何上，每根轴的容差把该轴的运动限制在一个圆锥内：实际姿态的对应轴与目标轴夹角不得超过容差。三根轴联合起来，可行姿态集是三个锥体的交：

可行姿态 = { R | angle(R ei, Rtarget ei) ≤ τi，i ∈ {x, y, z} } ei 为目标姿态的三根轴；τx、τy、τz 为对应容差（弧度）

三根轴容差不等时，可行姿态集是一个被拉长的"椭球"；三根容差相等时近似一个以目标姿态为中心的球面帽，半径约等于容差角。两个数量级直觉：角度制与弧度制的换算必须显式（1° ≈ 0.0175 rad，0.5° ≈ 0.0087 rad）；要实现"接近朝向"的宽松约束，容差通常在 0.05–0.3 rad（约 3°–17°），而"苛刻对齐"在 0.005–0.02 rad（约 0.3°–1.1°）之间。

2. 姿态偏差的度量：四元数角距离

核对姿态偏差需要一把统一的尺子。两个单位四元数之间的角距离为：

θ = 2 · arccos( |q1 · q2| ) 点积取绝对值处理四元数的双符号（q 与 -q 表示同一姿态）；θ 为旋转最小角度

绝对值的使用是一条必须记住的规则：四元数在数学上双覆盖旋转空间，同一姿态有两个符号相反的表示，忘记取绝对值会把"几乎相同的姿态"算成大角度偏差。数值实现时还要把点积钳制到 [-1, 1] 再取反余弦，避免浮点误差导致的无效输入。把这把尺子写进验证工具（见代码片段 2），规划结果与执行记录的姿态偏差就有一个与约束容差同口径的度量。

3. 位置约束：受约束点与区域并集

位置约束描述"某个点应当落在给定区域内"。受约束点由连杆原点加偏置（target_point_offset，在连杆坐标系下表达）确定，实际使用时通常把偏置设为工具点相对连杆原点的平移。区域由包围体（BoundingVolume）给出：一组解析形状或网格，各带自己的位姿（在约束参考系下解释）。判定规则是点包含的并集语义：

满足 ⇔ ∃ k：p ∈ Regionk p 为受约束点；只要落入任意一个区域内即通过，多区域联合表达复杂形状

并集语义支持"拼出"任意复杂区域：一条直线用细长盒体表达；一个圆环用围绕圆周排布的多个小区域表达（片段 3）；一个平面窗口用薄板盒体表达。构造质量由两个量决定：相邻区域的间隙决定约束边界是否连续（有间隙时点可能落在"允许范围之外"的缝隙里，规划路径在此处中断）；重叠量决定数值稳定性（重叠越小边界越敏感）。工程上重叠量取分段尺寸的 10% 到 30% 之间，兼顾连续性与区域总量。

4. 旋转误差到线位移的换算：联合预算

方向容差与位置容差通过"末端偏离量"耦合。设受约束点距姿态旋转中心的臂长为 r，姿态角偏差为 θ，则角偏差在受约束点处产生的线位移近似为：

Δtip ≈ r · θ；预算要求 Δtip + Δpos ≤ Δtotal Δpos 为位置约束容差；总偏差预算 Δtotal 由工艺公差给出

举一个工况：工具长 r = 0.15 m，方向容差 1°（0.0175 rad）产生的位移约 2.6 mm；若工艺总预算 5 mm，留给位置约束的额度只有 2.4 mm。这条公式说明容差分配不能独立取值：放宽方向容差会吃掉位置预算，收紧方向容差会增加约束流形的厚度压力，两者要在总预算下统一分配。分配的经验序是：先按工艺固定位置精度（通常更直接决定成品质量），剩余预算反推方向容差，再核对方向容差是否在流形可行区间内。

5. 权重与软约束的边界

两个约束消息都带权重字段。权重表达约束的"软硬程度"：接近 1 表示刚性要求，取较小的值表示可让位于其它约束。需要明确两点边界：（1）权重是否被消费取决于规划器实现，约束采样器在投影与修正时使用权重做折中，部分规划器忽略权重按硬约束处理，跨规划器迁移任务时要重新验证；（2）软约束改变的是搜索中的取舍，不改变任务验收标准，复核环节仍按硬容差判定。把权重当作"运行时可放宽的安全阀门"使用，是约束系统常见的误用。

实现思路与设计

两类几何约束的构造流程：

  1. 定受约束对象：确定连杆名与受约束点（偏置换算到连杆坐标系），核对连杆在 URDF 中的实际位置。
  2. 定区域与目标姿态：在稳定参考系中描述区域；目标姿态取自工装或标定结果，避免手工拼四元数。
  3. 做联合预算：按公式分配位置与方向容差，留出标定与建模误差的余量。
  4. 构造消息：填写字段，复核对：参考系、连杆名、单位（弧度）、区域位姿与形状的一致性。
  5. 数值核对：用角距离工具与点包含自检核对一个已知好姿态，把工具与消息口径对齐。
  6. 回归任务：施加约束规划并复核（第 035 章流程），记录成功率与轨迹裕量作为基线。

字段与取值要点

字段取值示例语义易错点
orientation标定得到的单位四元数期望姿态（在参考系中）忘记单位化；与参考系轴向约定不符

关键代码与解读

片段 1：C++ 构造方向约束并与位置约束组合（接口以对应 ROS2 发行版与 MoveIt2 版本的官方文档为准）

// 方向约束：姿态接近目标，三根轴容差各 0.01 rad（约 0.57 度）
moveit_msgs::msg::OrientationConstraint oc;
oc.header.frame_id = "world";          // 目标姿态与容差在该参考系中解释
oc.link_name = "tool0";
oc.orientation = target_orientation;   // 单位四元数，来自标定或工装定义
oc.absolute_x_axis_tolerance = 0.01;   // 弧度制；按度数填写会放大数十倍
oc.absolute_y_axis_tolerance = 0.01;
oc.absolute_z_axis_tolerance = 0.01;
oc.weight = 1.0;                       // 权重是否生效取决于规划器实现

// 与位置约束组合进同一个约束集合：先给受约束点定义允许区域
moveit_msgs::msg::PositionConstraint pc;
pc.header.frame_id = "world";
pc.link_name = "tool0";
pc.target_point_offset.z = 0.15;       // 工具点相对连杆原点的偏置（连杆系下）
pc.constraint_region.primitives.resize(1);
pc.constraint_region.primitives[0].type =
    shape_msgs::msg::SolidPrimitive::BOX;
pc.constraint_region.primitives[0].dimensions = { 0.05, 0.05, 0.02 };
pc.constraint_region.primitive_poses.resize(1);
pc.constraint_region.primitive_poses[0].position.z = 0.4;
pc.constraint_region.primitive_poses[0].orientation.w = 1.0;
pc.weight = 1.0;

moveit_msgs::msg::Constraints pose_window;
pose_window.orientation_constraints.push_back(oc);
pose_window.position_constraints.push_back(pc);   // 两者构成"姿态窗口"

解读：（1）方向容差按弧度填写，0.01 rad 约 0.57 度；示例中位置与方向组合后，可行集是"位置窗口与姿态锥体的乘积"，任务形如"贴装到平面上的小窗口并保持平行"。（2）target_point_offset 的偏置在连杆坐标系下解释：工具点位于连杆原点沿 z 轴 15 cm 处，约束实际作用于该点；把偏置方向理解反了，区域位置会整体错位。（3）区域盒体尺寸 5 cm × 5 cm × 2 cm 给出位置自由度：平面内允许移动，法向仅留 2 cm 的容差带；该分配应当来自第 4 小节的联合预算，避免凭经验拍定。

片段 2：Python 四元数角距离核对工具

import numpy as np

def quat_angle(q1, q2):
    """两个单位四元数之间的最小旋转角（弧度）。"""
    q1 = np.asarray(q1, dtype=float)
    q2 = np.asarray(q2, dtype=float)
    dot = float(np.clip(np.dot(q1, q2), -1.0, 1.0))
    # 双符号处理：q 与 -q 表示同一姿态，取绝对值后再求角
    return 2.0 * np.arccos(abs(dot))

ref = [0.0, 0.0, 0.0, 1.0]                 # 单位姿态
# 绕 z 轴旋转 0.5 度（约 0.0087 rad）对应的四元数
half = 0.5 * np.deg2rad(0.5)
tilted = [0.0, 0.0, np.sin(half), np.cos(half)]
print("角距离(rad):", round(quat_angle(ref, tilted), 5))
print("角距离(deg):", round(np.rad2deg(quat_angle(ref, tilted)), 3))
# 与约束容差同口径比较：0.0087 rad 的容差恰好覆盖 0.5 度的偏差

解读：（1）点积先钳制再取反余弦，两个数值细节对应两类真实误差：浮点误差越界与四元数双符号误判。（2）把角距离换算成角度后与工艺公差直接可比，验证工具的意义在于建立"约束容差、规划结果、执行记录"三方的公共度量。（3）该工具适合放进核对脚本：给定一个已知好姿态与规划输出姿态，打印角距离连同各轴分量偏差，替代"看起来差不多"的主观判断。

片段 3：Python 程序化构造环形路径约束

import math
from moveit_msgs.msg import Constraints, PositionConstraint
from shape_msgs.msg import SolidPrimitive
from geometry_msgs.msg import Pose

def circular_path_constraint(center, radius, n=24, tube=0.01,
                             frame="world", link="tool0"):
    """构造"受约束点沿圆运动"的位置约束：环形排布的小区域并集。"""
    cs = Constraints()
    cs.name = "circular_path"
    pc = PositionConstraint()
    pc.header.frame_id = frame
    pc.link_name = link
    pc.weight = 1.0
    seg = 2.0 * math.pi * radius / n            # 单段弧长
    for k in range(n):
        ang = 2.0 * math.pi * k / n
        prim = SolidPrimitive()
        prim.type = SolidPrimitive.BOX
        # 弧长方向重叠 20% 保证边界连续；径向与高度方向取管道粗细 tube
        prim.dimensions = [seg * 1.2, tube, tube]
        pose = Pose()
        pose.position.x = center[0] + radius * math.cos(ang)
        pose.position.y = center[1] + radius * math.sin(ang)
        pose.position.z = center[2]
        # 盒体 x 轴沿切线：绕 z 轴旋转 ang + 90 度（四元数半角写法）
        yaw = ang + math.pi / 2.0
        pose.orientation.z = math.sin(yaw / 2.0)
        pose.orientation.w = math.cos(yaw / 2.0)
        pc.constraint_region.primitives.append(prim)
        pc.constraint_region.primitive_poses.append(pose)
    cs.position_constraints.append(pc)
    return cs

解读：（1）环形约束由 n 个切向小盒体的并集近似；tube 同时控制径向与高度方向的允许偏差，是把"跟着圆走"的精度要求翻译为几何的旋钮。（2）分段弧长乘 1.2 的重叠系数保证相邻区域无缝衔接：没有重叠时，圆周上会留下窄缝，规划路径在缝处被判违规而中断，症状是"少数方位可以规划、其它方位失败"。（3）离散近似的精度由内接弦误差决定，弦高约为 r × (1 - cos(π/n))；半径 0.2 m、n = 24 时约 1.7 mm，与 tube 配合决定实际可用容差，必要时增大 n 或 tube 缩小近似误差占比。

常见坑

  • 角度制与弧度制混用：把 0.5 度写成 tolerance = 0.5（误以度数填弧度位），容差放大近 57 倍，约束形同虚设。修复是全部按弧度填写并做一次量级检查（苛刻对齐应在 0.01 rad 量级）。
  • 四元数未归一化或双符号误解：目标姿态从数据源直接抄录未归一化，或验证工具忘记绝对值处理，角距离虚高。修复是消息构造后统一归一化，验证工具按片段 2 实现。
  • 偏置点的坐标系理解错误：把 target_point_offset 当作世界系偏移填写，受约束点落在错误位置，约束区域与真实动作脱节。修复是核对消息定义的坐标系语义，并在仿真中用可视化标志点验证受约束点的实际位置。
  • 环形或分段区域留缝：区域无重叠时圆周边界不连续，部分方位无法通过约束。修复是按片段 3 加入重叠系数，把缝隙检查纳入约束构造的单元测试。
  • 容差分配超预算：位置与方向容差各自按上限取值，叠加后超过工艺公差，成品在边界上超差。修复是按联合预算公式统一分配，把 r · θ 一项显式计入。

练习与思考

  1. 换算练习：把 2° 与 0.5° 换算为弧度；工具长 r = 0.10 m 时，2° 的姿态偏差在工具点产生多少线位移？★
    提示
    2° ≈ 0.0349 rad，0.5° ≈ 0.0087 rad；线位移 ≈ 0.10 × 0.0349 ≈ 3.5 mm。若工艺总预算 5 mm，位置容差只剩 1.5 mm。
  2. 预算设计：工艺要求工具点总偏差不超过 4 mm，工具长 0.15 m。给出位置容差与方向容差的一种分配（方向取整角度值），并说明分配依据。★
    提示
    例如方向容差 0.5°（0.0087 rad）产生约 1.3 mm，位置容差取 2.5 mm，合计 3.8 mm 留 0.2 mm 余量。若工艺对位置更敏感，可把方向收紧至 0.3°，把更多额度留给位置。
  3. 设计题：为"把轴类零件插入垂直孔"设计姿态窗口约束：目标姿态如何取得（标定还是手工）、区域形状与尺寸、方向容差量级、联合预算，并给出失败排查顺序。★★
    提示
    目标姿态由孔轴线标定得到；区域取孔口上方的小盒体（直径级）；方向容差按间隙与插入深度估算（间隙越大越宽容）；预算按 r · θ 分配；排查顺序为参考系、单位、可行集、流形厚度。
  4. 诊断题：环形约束任务在四个象限都能规划，唯独在圆周的某个方位持续失败。给出最可能原因与构造层面的修复，并解释为什么该现象指向"区域缝隙"这类构造问题。★★
    提示
    最可能是相邻区域未重叠或重叠不足，失败方位恰在缝附近；相邻方位正常说明运动学可达，问题在约束可行性判定上。修复是增大重叠系数并复测该方位。
  5. 分析题：讨论软约束权重在"装配对位"与"扫描路径"两类任务中的不同用法：哪类任务适合让权重发挥折中作用、哪类任务必须按硬约束处理，并说明复核环节如何对待权重。★★★
    提示
    扫描路径的"贴近但不必卡死"适合软权重换取成功率；装配对位直接决定装配质量，应按硬约束设置并在复核中按硬容差判定。复核环节永远按硬标准执行，权重只影响搜索过程。

小结

  • 方向约束用三根轴的角容差（弧度）圈出姿态锥体集合，容差相等时近似球面帽。
  • 位置约束由受约束点（连杆原点加偏置）与区域并集组成，点落入任一区域即通过；重叠量决定边界连续性。
  • 四元数角距离是姿态偏差的统一度量，双符号处理与点积钳制是两个必做的数值细节。
  • 方向与位置容差通过末端线位移耦合，按 Δtip ≈ r · θ 做联合预算分配。
