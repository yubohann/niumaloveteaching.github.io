第 070 章：装配任务：插孔与对位

装配的难点在接触状态：孔轴配合的几何条件、卡阻与楔紧的成因、倒角的引导作用，以及螺旋搜索与柔顺对位两类误差吸收策略。

  • 主题：操作任务 / 装配（Assembly：Peg-in-Hole）
  • 关键机制：接触状态分析 / 卡阻判据 / 螺旋搜索与主动柔顺
  • 预计学时：55 分钟
  • 前置章节：第 069 章

学习目标

  • 掌握孔轴装配的几何参数（间隙、倒角、插入深度）与误差分解（位置误差、姿态误差及其耦合）。
  • 理解二维接触状态的分类（无接触、单点接触、两点接触、就位）与摩擦在状态转化中的作用。
  • 掌握卡阻（Jamming）与楔紧（Wedging）的形成条件，能解释倒角为什么能扩大容错范围并产生自定心分力。
  • 会设计螺旋搜索（Spiral Search）轨迹：螺距、半径上限、速度与力阈值的取值依据。
  • 理解主动柔顺的虚拟刚度模型，能说明其与第 071 章力控的衔接关系。

背景与动机

抓取与放置过程中，接触是瞬时的、单侧的；装配过程中，接触是持续的、双侧的：轴与孔之间存在多个接触点，接触力方向随状态变化，纯位置控制的机械臂在两点接触下会自锁在孔口，继续施加插入力只会让侧向力上升。装配任务的本质从"走到位"变成"通过接触力的调节进入下一个接触状态"。

本章讨论的插孔与对位是装配操作的原子过程：轴类零件插入孔类特征，包含粗对位、接触探测、搜索、插入与就位确认五个环节。它向下衔接第 069 章的姿态精度（对位误差来源），向上引出第 071 章的力控与柔顺控制（连续接触下的闭环方法）。

工程背景：精密配合的间隙常在 0.05–0.5 mm 量级，而机械臂的绝对定位误差在标定后仍有 0.2–1 mm，误差量级超过间隙是常态，装配必须依靠几何引导（倒角）与误差吸收（搜索或柔顺）完成，这也解释了为什么装配对控制策略的要求高于普通搬运。

核心原理

1. 装配几何与误差分解

参数典型值作用
配合间隙 c0.05–0.5 mm（精密）、0.5–2 mm（常规）决定可插入的姿态误差上限
倒角长度 lc0.5–2 mm，角度 30°–45°扩大孔口引导范围，产生自定心分力
插入深度 h5–30 mm决定接触状态演化长度
横向位置误差0.1–2 mm粗对位残差
姿态角误差 θ0.1°–2°与横向误差耦合，放大卡阻风险

对位误差由横向偏移与姿态倾角共同构成。轴端要落进孔口，其位置需落在倒角环带内，引导范围的近似表达为：

rguide ≈ c / 2 + lc · tan α α 为倒角半角；c = 0.2 mm、lc = 1 mm、α = 45° 时 rguide ≈ 1.1 mm；姿态误差通过轴长放大为端部位移，θ = 1° 在 0.1 m 轴上产生约 1.7 mm 端部偏移

上式给出两个设计结论：倒角是性价比最高的容错来源；姿态误差经轴长放大后极易超过引导范围，因此对位顺序应为"先姿态对正、后位置搜索"。

2. 接触状态与卡阻成因

以二维截面观察，轴插入孔的过程经历四种状态：

  1. 无接触：轴端在孔口上方，仅受重力与夹持约束。
  2. 单点接触：轴侧壁或端部棱边与孔口棱边接触，接触力集中在一点，轴可绕该点转动。
  3. 两点接触：轴同时接触孔口的两个对角棱边，几何上形成跨距。
  4. 就位：轴进入孔内，接触转为面接触，插入完成。

两点接触是稳定性分叉点。设插入力沿轴方向，两个接触点提供的法向力与摩擦力需同时满足力平衡与力矩平衡；无摩擦极限下，两个法向反力的作用线无法与插入力构成平衡，轴被几何锁定，此状态即楔紧（Wedging）。引入摩擦后，摩擦锥扩大可行力集合，存在一组平衡力的条件取决于摩擦系数与几何比例，一旦姿态角超过由二者共同决定的阈值，插入力无法推动轴前进，侧向力却持续上升，此状态即卡阻（Jamming）。

设计决策：卡阻的工程含义

卡阻判定与摩擦系数、姿态角、间隙比同时相关：摩擦越小插入越顺畅（摩擦锥窄，接触点容易滑动让位），摩擦越大越容易被卡住；间隙越大姿态容许范围越宽。现场处置逻辑与之对应：检测到力上升且无位移时，先回退并减小姿态角，再以更小的横向步长重试；加大插入力在卡阻状态下只会把侧向力推向工件损伤方向。

倒角改变接触几何：轴端首先与斜面接触，斜面的法向力具有指向孔心的分量，形成自定心效应；斜面还把小横向误差转换为轴向力的分力，使轴端沿斜面滑入孔内。这一效应就是引导范围公式中 lc·tan α 项的来源。

3. 螺旋搜索：用运动替代精度

当粗对位残差接近或超过引导范围时，用确定性搜索覆盖误差区域。阿基米德螺旋是最常用的搜索轨迹：半径随转角线性增长，每圈半径增量即螺距。

r(φ) = b φ，b = p / (2π) p 为螺距；螺旋全程保持轴向恒定下压，轴端一旦落到引导范围即被倒角滑入，搜索自动结束

参数设计的核心约束是覆盖性：螺距需要小于引导范围的两倍，保证相邻两圈之间有重叠带，不存在漏过孔口的空隙。半径上限覆盖粗对位的最大残差（取 1.5–3 mm），速度取 2–10 mm/s 以保持接触力可控。搜索期间监控轴向力与侧向力矩：力单调上升说明卡在孔口边缘，力骤降说明轴端落入孔口，两种信号分别触发"继续搜索"与"转入插入"。

4. 主动柔顺与被动柔顺

柔顺（Compliance）让机械臂在受约束方向上表现出弹性让位能力，把位置误差转换为接触力，避免硬抵抗。两类实现：

方式实现特点适用范围
被动柔顺（RCC）远心柔顺装置，机械弹性解耦响应快、无需传感固定姿态的专用装配工位
主动柔顺力反馈闭环加虚拟刚度参数可调、可编程多任务通用机械臂

主动柔顺的一维形式即"虚拟弹簧"：接触力除以虚拟刚度得到位置修正量，修正方向与受力方向相反。虚拟刚度取 3000–10000 N/m 时，15 N 接触力对应 1.5–5 mm 的让位量，与引导范围同量级，能有效吸收残余对位误差。柔顺处理小误差与接触过渡，搜索处理大误差，二者的分工与参数区间由此确定。

实现思路与设计

插入装配的实现步骤：

  1. 接近孔口：轴端下降到孔面上方 2–5 mm，速度 0.02–0.05 m/s。
  2. 姿态对正：将轴轴线与孔轴线夹角收敛到 0.5° 以内，姿态误差优先处理。
  3. 接触探测：低速下压直到轴向力上升，确认轴端与孔面接触。
  4. 螺旋搜索：按螺距 0.3 mm、半径上限 2 mm 搜索，保持下压 5–20 N。
  5. 落入检测：轴向力回落或深度增量出现，判定轴端进入倒角。
  6. 低速插入：速度 1–5 mm/s，插入力上限 15 N，柔顺闭环吸收剩余误差。
  7. 就位确认：深度达到设定值且力回落，判定装配完成。

装配参数表

参数典型值作用取值依据
螺旋半径上限1.5–3 mm覆盖粗对位残差取对位误差分布的 95% 分位

与第 064 章放置任务的差异：放置允许位置误差由误差预算决定，装配的允许误差由间隙与倒角决定且量级更小；放置的接触是单次事件，装配的接触是状态机，需要在多个接触状态间转换。

关键代码与解读

片段 1：阿基米德螺旋搜索轨迹

import math

def spiral_path(r_max=0.002, pitch=0.0003, v=0.005, dt=0.01):
    """生成螺旋搜索的横向偏移序列：弧长速度近似恒定。"""
    b = pitch / (2.0 * math.pi)     # 阿基米德螺旋系数：r = b·φ
    pts = []
    phi, r = 0.0, b                 # 从极小半径起步，避免除零
    while r <= r_max:
        pts.append((r * math.cos(phi), r * math.sin(phi)))
        phi += (v * dt) / r         # 弧长增量换算角度增量：半径越小转得越快
        r = b * phi                 # 每转一圈半径增加一个螺距
    return pts

# 半径上限 2 mm、螺距 0.3 mm、速度 5 mm/s、周期 10 ms：约生成数百个搜索点

解读：（1）螺旋的角速度随半径减小而增大，保证弧长速度恒定：近中心处转得快、外圈转得慢，接触力的动态特性一致。（2）螺距 0.3 mm 的选择依据是覆盖性约束（小于引导范围 1.1 mm 的两倍），保证任意方向的误差都会在某一圈内被覆盖。（3）周期 10 ms 对应 100 Hz 的横向步进，与力信号的采样周期匹配；若力信号频率更低，步进周期应同步放宽。

片段 2：搜索与插入的两阶段状态机

def search_then_insert(force_z, depth, descend, spiral, insert, opts):
    """先螺旋搜索孔口，落入后在力上限内低速插入。"""
    for (x, y) in spiral:
        if force_z() > opts["search_force_limit"]:
            return "ABORT"                # 搜索期力超限：姿态异常或孔口毛刺
        descend(x, y, opts["press"])      # 保持恒定下压，横向移动到搜索点
        if force_z() < opts["entry_force"]:
            break                         # 轴向力回落：轴端滑入倒角
    else:
        return "NOT_FOUND"                # 搜索走完未落入：扩大半径或重新对位
    insert(opts["speed"], opts["insert_force_limit"])
    if depth() >= opts["seat_depth"]:
        return "SEATED"                   # 深度到位：装配完成
    return "PARTIAL"                      # 未到位：可能是浅孔或异物

解读：（1）循环结构依赖 for-else：正常落入用 break 跳出并进入插入，搜索穷尽则走 else 分支上报未找到，两种出口互斥且显式。（2）三个力阈值承担不同职责：搜索上限保护零件，落入阈值检测状态转换，插入上限保护孔壁；阈值全部来自标定，不写死在代码中。（3）PARTIAL 与 SEATED 的区分让上层可以继续尝试或转为人工处理，避免把浅插误判为完成。

片段 3：主动柔顺的一维虚拟刚度模型

def compliant_axis(x_cmd, x_meas, f_meas, k_virtual=5000.0, f_limit=15.0):
    """虚拟弹簧：把接触力折算为位置让位量，方向与受力相反。"""
    f = max(-f_limit, min(f_limit, f_meas))   # 力限幅：限制柔顺作用范围
    x_correction = f / k_virtual              # 15 N 对应 3 mm 让位（k 取 5000）
    x_next = x_cmd - x_correction             # 受力方向让位，降低压靠与侧向力
    # 收敛判据：修正量小于 0.01 mm 且残余力小于 1 N 时视为稳定接触
    settled = abs(x_meas - x_next) < 1e-5 and abs(f) < 1.0
    return x_next, ("CONTACT_STABLE" if settled else "ADJUST")

解读：（1）虚拟刚度 kv = 5000 N/m 使 15 N 接触力对应 3 mm 让位，与引导范围同量级，既能吸收残余误差又不会让姿态失控。（2）力限幅是稳定性保护：力信号异常尖峰若不限幅会产生过大的位置修正，激发振荡。（3）返回状态区分"稳定接触"与"调整中"，上层据此决定是否推进到下一阶段，这一接口形态与第 071 章的阻抗控制一致，只是把导纳环简化为单轴比例关系。

常见坑

  • 无倒角孔口配纯位置控制：轴端轻微偏移即进入两点接触楔紧，插入力持续上升而位移为零。修复：加工或选用带倒角的孔口特征，并引入搜索或柔顺策略。
  • 姿态误差未先收敛就做位置搜索：倾角经轴长放大后远超引导范围，搜索覆盖不到。修复：把姿态对正放在搜索之前，目标夹角 0.5° 以内。
  • 螺距超过引导范围的两倍：螺旋相邻圈之间出现未覆盖空隙，搜索可能整体错过孔口。修复：螺距取引导范围的两倍以下，并留出覆盖余量，用可视化轨迹验证覆盖。
  • 卡阻时加大插入力：力上升被误读为"差一点就进去了"，继续加力导致孔口倒角剥落或轴弯曲。修复：检测到力上升无位移时按回退、减小倾角、缩小步长的顺序处置。
  • 落入检测只依赖单信号：仅看轴向力下降在斜面摩擦波动下可能误判。修复：联合判定轴向力回落与深度增量，必要时加入力矩不平衡信号，三点中至少两点满足才确认。

练习与思考

  1. 孔轴配合间隙 0.2 mm，孔口倒角 1 mm × 45°。计算引导范围；若横向对位残差为 0.8 mm、姿态误差 0.3°，判断能否直接插入（轴长 0.08 m）。★
    提示
    引导范围约 1.1 mm；姿态误差等效端部偏移约 0.3° × π/180 × 80 mm ≈ 0.42 mm，与横向残差叠加约 1.22 mm，略超引导范围，建议先做搜索或柔顺过渡。
  2. 引导范围 1.1 mm，若螺距取 2.5 mm，说明搜索可能出现的行为；给出满足覆盖性的螺距上限。★★
    提示
    相邻圈间距 2.5 mm 大于两倍引导范围，环带间存在空隙，孔口可能落在空隙中不被触发；螺距上限建议 0.5 mm 以下。
  3. 设计落入检测的多信号判据：列出可用的三路信号、各自的误判情形与组合逻辑，说明为什么两点确认优于单点。★★
    提示
    轴向力回落会被斜面摩擦波动干扰；深度增量会被下压力导致的压缩量影响；力矩不平衡在接近对中时最不敏感。三路信号中两路同时满足的判定在误报与漏报之间取得平衡。
  4. 为"电机轴插入减速器内孔（间隙 0.08 mm，长配合 40 mm）"设计完整装配流程与参数表，说明与常规间隙装配的差异及原因。★★★
    提示
    小间隙要求姿态误差小于 0.2°、粗对位残差小于 0.3 mm，搜索半径可缩小到 0.8 mm；长配合段摩擦累积，插入力上限与柔顺刚度需要按深度增加而放宽，插入速度取 1–2 mm/s。

小结

  • 装配的对位误差由横向偏移与姿态倾角构成，姿态误差经轴长放大，引导范围由间隙与倒角长度共同决定。
  • 两点接触是稳定性分叉点：无摩擦极限下楔紧不可避免，有摩擦时卡阻边界由摩擦系数与几何比例决定。
  • 倒角提供自定心分力并扩大容错范围，是性价比最高的几何引导手段。
  • 螺旋搜索以运动覆盖误差，螺距小于引导范围的两倍保证无空隙；搜索处理大误差，柔顺处理小误差与接触过渡。
  • 主动柔顺的虚拟刚度模型与第 071 章的阻抗与导纳控制同源，下一章展开力控与柔顺操作的一般理论。
