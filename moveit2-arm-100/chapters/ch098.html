第 098 章：机械臂标定与坐标系对齐

从手眼方程 AX=XB 出发，讲清相机与末端关系、工具中心点与基座对齐三类标定的原理与最小二乘求解，以及标定结果如何进入变换树并用残差验证。

  • 主题：空间精度 / 标定与对齐
  • 关键机制：手眼方程、四元数线性化求解、残差验证、静态变换发布
  • 预计学时：60 分钟
  • 前置章节：第 097 章

学习目标

  • 理解三类标定对象：手眼关系、工具中心点（TCP）与基座对齐，及各误差项对末端精度的影响。
  • 掌握手眼方程 A X = X B 的推导含义，能区分眼在手与眼在外两种布置下的量。
  • 会用四元数线性化把手眼方程化为最小二乘问题并写出求解步骤。
  • 会设计标定数据采集方案：位姿数量、姿态多样性与数据质量检查。
  • 会把标定结果发布为静态变换，并用残差与端到端核对验证标定质量。

背景与动机

视觉给出的目标位姿要经过多段坐标系变换才能进入规划，其中相机与机器人之间的变换无法从模型推导，只能通过标定获得。标定误差直接进入每次抓取的位置误差，且随目标距离放大。

三类标定各自解决一段链路：手眼标定解决"相机与机器人"的固定关系；工具中心点标定解决"法兰与工具作用点"的偏差；基座对齐解决"机器人基座与世界"的位姿。任一段缺失或过时，系统都会表现出"看起来对不上"的固定偏差或随机偏差。

第 096 章的视觉链与第 097 章的任务链都建立在同一套坐标系之上，本章为这套坐标系提供精度基础。

核心原理

1. 三类标定与误差传播

末端定位精度由多段变换的误差叠加而成。角度类误差按目标距离放大，位置类误差按常数叠加，两类都必须在预算内分配。

σ末端 ≈ σ模型 + σ基座 + σTCP + r · σ手眼,角 + σ手眼,位 + σ估计 r 为相机到目标距离；手眼角度误差 0.5° 在 1 m 处引入约 8.7 mm 位置误差，是多数场景中的主导项
标定对象未知量采集方式典型残差目标
手眼关系相机与末端的固定变换多组位姿下观测同一标定板重投影误差亚像素级
工具中心点法兰到工具作用点的变换多姿态接触同一固定点接触点散布毫米级
基座对齐基座与世界的位姿已知点或平面接触测量按现场测量精度

2. 手眼方程 A X = X B

让机器人携带相机（或相机观察装有标定板的末端）做两次位姿，得到一对相对运动：机器人侧相对运动 A 与相机侧相对运动 B。同一物理运动在两侧坐标系中的表达相差一个固定变换 X，即手眼变换：A X = X B。

运动对：Ai X = X Bi（i = 1…N−1，N 组位姿产生 N−1 个独立方程对） 眼在手布置中 A 为末端相对运动、B 为相机观测反推的相对运动；眼在外布置中角色互换并附加基座常量，方程形式不变

求解分两步：旋转部分用四元数线性化，平移部分在旋转已知后化为线性最小二乘。旋转解的正确性依赖姿态多样性：若所有采集位姿的旋转轴接近平行，旋转部分退化，解不可信。

旋转：qA ⊗ qX = qX ⊗ qB ⟺ ( L(qA) − R(qB) ) qX = 0
平移：( RA − I ) tX = RX tB − tA L 与 R 为四元数左右乘矩阵；对全部方程对堆叠后取最小奇异向量（旋转）与最小二乘解（平移）

3. 工具中心点与基座对齐

工具中心点标定用"变姿态同一点"原理：工具以不同姿态接触同一固定点，法兰读数随姿态变化而接触点不变，由此反解工具偏移。姿态变化范围决定解的稳定性，变化越小，偏移解对噪声越敏感。

基座对齐给出基座在世界中的位姿：用已知世界坐标的接触点或平面测量，解出平移与旋转。现场中最容易被忽略的是基座对齐的时效性：设备搬动、地脚调整后必须重新对齐，误差会整体平移工作空间。

4. 残差与验证

标定结果必须附残差：把解出的 X 代回全部方程对，统计 A X 与 X B 的差异。残差大说明采集质量差或存在外点；残差小也不能完全代表可用，需要独立验证。独立验证用标定结果预测一个未参与求解的目标位姿，与实测对比，差值才是可信的端到端精度。

姿态残差 εR,i = 角度( RA,i RX, RX RB,i )；平移残差 εt,i = ‖A X − X B‖ 的平移分量 按中位数与最大残差双口径报告；最大残差超过阈值时先剔除外点再求解

实现思路与设计

标定工程按"准备、采集、求解、验证、固化"五步执行。采集质量决定上限，求解算法决定逼近上限的程度，验证给出可信区间，固化保证结果被系统正确消费。

1. 采集方案表

项要求依据
位姿数量20–30 组覆盖姿态多样性与冗余，冗余用于外点剔除
旋转轴多样性至少三个显著不同的旋转轴方向避免旋转解退化
平移幅度覆盖工作空间内多段区域约束平移解并暴露非线性误差
静止条件采集时机械臂完全静止，时间戳对齐运动中的读数与图像错配
观测质量标定板完整可见、居中、光照稳定降低位姿估计噪声

2. 求解与检查流程

  1. 把机器人位姿与标定板观测统一到各自相对运动形式。
  2. 四元数矩阵堆叠求解旋转，检查最小奇异值比例。
  3. 回代求解平移，检查条件数。
  4. 计算双口径残差，剔除最大外点后复解。
  5. 独立验证：选未参与求解的位姿做预测与实测对比。

3. 结果固化

标定结果写入配置文件并存档采集数据摘要（数量、残差、日期），启动时由静态变换发布者发布到变换树。固化遵循"单一来源"原则：变换只由标定文件产生，禁止在多个启动文件中各写一份数值，否则版本漂移不可避免。

与上一章的差异点：第 097 章的组织对象是决策结构，本章的对象是空间精度；标定误差预算约束着任务层对抓取容差的设定。

关键代码与解读

片段 1：四元数最小二乘求解手眼旋转

import numpy as np


def quat_left(q):
    w, x, y, z = q
    return np.array([[w, -x, -y, -z], [x, w, -z, y],
                     [y, z, w, -x], [z, -y, x, w]])


def quat_right(q):
    w, x, y, z = q
    return np.array([[w, -x, -y, -z], [x, w, z, -y],
                     [y, -z, w, x], [z, y, -x, w]])


def solve_hand_eye_rotation(pairs):
    """pairs: [(q_A, q_B), ...] 相对运动的四元数表示。

    A X = X B 的旋转部分线性化为 (L(q_A) - R(q_B)) q_X = 0；
    对所有方程对堆叠后，q_X 取最小奇异向量。
    """
    M = np.zeros((4, 4))
    for q_a, q_b in pairs:
        d = quat_left(q_a) - quat_right(q_b)
        # 累加 d^T d：等价于对全部方程做最小二乘
        M += d.T @ d
    eigvals, eigvecs = np.linalg.eigh(M)
    # 第二小奇异值用于退化检查：与最小值接近说明姿态多样性不足
    degenerate = eigvals[1] - eigvals[0] < 1e-3 * max(1.0, eigvals[-1])
    q_x = eigvecs[:, 0]
    return q_x / np.linalg.norm(q_x), degenerate

解读：求解器的核心是线性化与退化检查。设计要点：（1）四元数乘法的左右乘矩阵把非线性方程变为线性方程，逐个方程对累加得到 4×4 矩阵；（2）最小特征值对应的特征向量即旋转解，符号歧义由归一化消除；（3）退化检查比较前两个特征值：比值过小说明旋转解不稳定，必须补充姿态多样的采集数据；（4）返回布尔标志让调用方在求解阶段就能发现问题，不等验证阶段才发现。平移部分的求解在旋转已知后进行，公式见正文。

片段 2：标定结果发布为静态变换

import yaml
import rclpy
from rclpy.node import Node
from tf2_ros import StaticTransformBroadcaster
from geometry_msgs.msg import TransformStamped


class CalibrationPublisher(Node):
    """把标定文件发布为静态变换：变换树的单一来源。"""

    def __init__(self, calib_path, parent="tool0", child="camera_link"):
        super().__init__("calibration_publisher")
        with open(calib_path, encoding="utf-8") as f:
            calib = yaml.safe_load(f)
        tf = TransformStamped()
        # 时间戳取零值：静态变换不随时间变化，零值表示对全历史有效
        tf.header.stamp = rclpy.time.Time().to_msg()
        tf.header.frame_id = parent
        tf.child_frame_id = child
        tf.transform.translation.x = calib["x"]
        tf.transform.translation.y = calib["y"]
        tf.transform.translation.z = calib["z"]
        tf.transform.rotation.x = calib["qx"]
        tf.transform.rotation.y = calib["qy"]
        tf.transform.rotation.z = calib["qz"]
        tf.transform.rotation.w = calib["qw"]
        self._broadcaster = StaticTransformBroadcaster(self)
        self._broadcaster.sendTransform(tf)
        # 打印残差摘要：固化时同步核对标定质量指标
        self.get_logger().info(
            f"标定加载完成: 残差(中位)={calib.get('residual_median', 'NA')}")

解读：静态发布把文件中的标定值变成变换树中的边。设计要点：（1）静态变换时间戳取零值（对全历史有效），保证按戳查询在任何历史时刻都能查到；（2）父帧与子帧的顺序对应"父到子"的变换方向，写反是最常见的方向性错误；（3）残差摘要随加载打印，运行日志即可回溯标定质量；（4）单一来源原则体现在只从此处发布，任何其他节点不得重复发布同一对角色的变换。

片段 3：独立验证脚本

import numpy as np


def validate(calib_T, samples, threshold_pos=0.005, threshold_rot=0.01):
    """用未参与求解的样本做端到端预测核对。

    samples: [(T_base_tool, observed_T_base_target, T_camera_target), ...]
    预测链：T_base_target = T_base_tool 手眼变换 相机到目标的观测
    """
    errors = []
    for t_base_tool, t_base_target_obs, t_camera_target in samples:
        predicted = t_base_tool @ calib_T @ t_camera_target
        # 位置误差取平移差范数；姿态误差取旋转角（小角度用轴角近似）
        e_pos = np.linalg.norm(predicted[:3, 3] - t_base_target_obs[:3, 3])
        r_delta = predicted[:3, :3].T @ t_base_target_obs[:3, :3]
        e_rot = np.arccos(np.clip((np.trace(r_delta) - 1) / 2, -1, 1))
        errors.append((e_pos, e_rot))
    pos_max = max(e[0] for e in errors)
    rot_max = max(e[1] for e in errors)
    # 双阈值判定：位置与姿态任一超限即视为标定不通过
    ok = pos_max <= threshold_pos and rot_max <= threshold_rot
    return ok, pos_max, rot_max

解读：独立验证回答"标定结果在真实链路里可用吗"。设计要点：（1）验证样本不参与求解，避免自证；（2）误差按位置与姿态分别度量，姿态误差取旋转矩阵夹角的迹公式，小角度下与轴角近似一致；（3）双阈值判定：任一维度超限即整体不通过，阈值按任务容差与误差预算分配（见公式）。阈值 5 mm 与 0.01 rad 属示例量级，实际按抓取容差扣除感知估计误差后设定。

常见坑

  • 姿态多样性不足：采集位姿都绕近似平行轴旋转，旋转解退化，验证阶段才发现。修复：采集前规划位姿清单，覆盖至少三个显著不同的旋转轴方向，并在求解阶段做退化检查。
  • 采集时机械臂未静止：图像与位姿读数时刻错配，标定解吸进运动误差。修复：每个采集点等待状态稳定后再记录，全链路保持同一时间戳。
  • 父帧子帧方向写反：变换发布方向与预期相反，表现为目标绕参考系翻转。修复：发布前用已知点核对方向，把父子关系写入标定文件，散落在代码里会随版本漂移。
  • 标定结果多处维护：启动文件与代码中各写一份数值，更新后版本漂移。修复：单一来源原则，全部消费者从同一文件读取。
  • 忽略基座对齐的时效性：设备搬动后未重新对齐，误差整体平移工作空间。修复：把基座对齐纳入设备变动检查表，重新对齐后重跑端到端验证。

练习与思考

  1. 推导：说明 A X = X B 中两侧相对运动为何满足该方程，并指出眼在手与眼在外两种布置下 A 与 B 的具体含义。★
    提示
    同一物理运动在机器人侧与相机侧的表达相差固定变换 X；眼在手时 X 为末端到相机的变换，眼在外时相机固定，X 表达相机与世界的关系并附加常量。
  2. 计算误差传播：手眼角度误差 0.3°，相机到目标距离 0.8 m，求该误差项引入的位置偏差；若角度误差降到 0.1°，偏差降为多少？★★
    提示
    0.8 × 0.3 × π/180 ≈ 4.2 mm；0.1° 时约 1.4 mm，说明角度标定精度是抓取容差的主导项。
  3. 设计采集方案：为六轴臂与固定相机（眼在外）设计 20 组采集位姿的分配原则，说明如何同时满足平移幅度与旋转轴多样性。★★
    提示
    按工作空间划分若干区域，每区域分配位姿且姿态绕不同主轴变化；位姿清单先验证标定板可见性再执行。
  4. 改参数并预测：把独立验证的位置阈值从 5 mm 放宽到 15 mm，标定通过率与抓取任务的实际成功率如何变化？给出取舍依据。★★
    提示
    通过率上升，但标定残差大的解进入系统后抓取成功率下降；取舍依据是任务容差与重新标定成本的对比。
  5. 说明为什么"残差小"不能替代独立验证，给出一个残差小但端到端误差大的构造性例子，并说明其机理。★★★
    提示
    采集数据集中在工作空间一角时方程对内部一致（残差小），但解在其余区域外推误差大；机理是数据分布不覆盖实际使用区域。

小结

  • 三类标定各管一段链路：手眼关系、工具中心点、基座对齐；角度误差按距离放大，是精度预算的主导项。
  • 手眼方程 A X = X B 把固定变换的求解化为对相对运动方程组的最小二乘。
  • 四元数线性化求解旋转，最小奇异向量即解；退化检查依赖姿态多样性。
  • 残差双口径报告，独立验证用未参与求解的样本做端到端核对。
  • 标定结果以静态变换发布，遵循单一来源原则，随设备变动重新对齐与验证。
  • 下一章面向时间维度：长时运行稳定性与数值漂移分析，把精度与状态维护放到持续运行的尺度上考察。
