第 072 章：双臂协作

两臂组成闭链后的运动学变化：相对位姿约束如何减少自由度、内力从何而来，以及 MoveIt2 中单规划组与双规划组两类实现方案的取舍。

  • 主题：平台形态 / 双臂协作（Bimanual Manipulation）
  • 关键机制：闭链约束（Closed-Chain Constraint）/ 自由度缩减 / 相对位姿监控
  • 预计学时：55 分钟
  • 前置章节：第 071 章

学习目标

  • 掌握双臂协同的模式分类（松协调、半紧协调、紧协调），能按任务给出模式选择。
  • 理解闭链约束的运动学本质：相对位姿固定的两臂组合后自由度减少，能计算常见构型的自由度。
  • 能解释内力的来源：位置误差经工件刚度放大，理解柔顺与力控在其中的作用。
  • 掌握 MoveIt2 中双臂任务的两种表达方案（单规划组与双规划组加约束）与各自的限制。
  • 会设计双臂协作的同步执行、相对位姿监控与物体表示策略。

背景与动机

单臂操作受工作空间、负载与姿态能力的限制，双臂系统通过两条臂的配合扩展能力：共同搬运大件、一臂扶持一臂操作、双手协同装配。代价是两臂从独立开链变成耦合闭链：一条臂的运动约束另一条臂，位置误差转化为工件内力，规划与控制的复杂度显著上升。

在 MoveIt2 中，双臂系统的表达有多种路径：把两臂关节放进同一规划组由采样规划器同时求解，或保留两个规划组并用约束与同步逻辑在任务层耦合。两种方案对约束表达、规划时间与诊断粒度的影响不同，是本章的设计重点。历史背景上，MoveIt1 曾提供双机架与闭链约束求解器，MoveIt2 的能力集合不同，实践方案以任务层自建为主，具体能力以官方文档为准。

本章与第 071 章的衔接：闭链产生内力，柔顺与力控是吸收内力的手段；与第 074 章的区别：本章处理"同一工件的紧耦合协作"，第 074 章处理"共享工作空间的独立多臂协调"。

核心原理

1. 协同模式分类

模式耦合方式典型任务约束强度
松协调（Loose）各自独立运动，仅共享工作空间两臂分别取放不同物体仅碰撞约束
半紧协调（Semi-Tight）目标由同一工件关联，各自抓取工件不同部位一臂扶持、一臂拧螺丝工件位姿关联
紧协调（Tight）共同夹持同一刚体，末端相对位姿固定双端搬运长料、折叠装配完整闭链约束

模式决定约束的表达方式：松协调只需碰撞检查，紧协调必须显式维护相对位姿约束并监控误差。工程中多数省力的设计是把任务组织成"半紧协调"：把刚性闭链拆成"一臂定位、一臂柔顺"的形态，用柔顺吸收不可避免的相对误差。

2. 闭链约束与自由度缩减

两臂共同持有一个刚体时，末端之间的相对位姿为常量。设主臂位姿 T1、副臂位姿 T2，约束写作：

T1−1 T2 = Trel（常量），自由度 = Σ ni − 6 两臂各 6 关节时，组合自由度 12 − 6 = 6，恰好对应工件在空间中的位姿；若工件还与支撑面接触，再减去接触方向约束维数

自由度计算给出规划问题的规模判断：6 自由度的组合系统与单臂同维，但状态空间是两臂关节的笛卡尔积，采样规划的有效维度上升，规划时间显著变长。冗余臂（7 关节）组合后自由度大于 6，多余自由度构成零空间，可用于避障与关节限位优化。

约束的第二个后果是误差传递：两臂位置误差之和经工件刚度放大为内力。设相对位姿误差 1 mm、工件等效刚度 105 N/m，内力可达 100 N，远超合理操作力。因此紧协调必须至少让一臂工作在柔顺模式：若柔顺等效刚度取 5000 N/m，同样的 1 mm 误差仅产生 5 N 内力，落在安全区间。

3. MoveIt2 中的两种表达方案

方案实现优点限制
单规划组两臂关节放入同一规划组，一次规划求解约束在规划内满足，无事后同步问题采样维度高，规划时间长；组内自碰撞检查需配置
双规划组主臂规划，副臂按相对约束求解逆运动学，任务层同步规划时间可控，诊断粒度细，易于复现约束由任务层维护，需监控与补偿误差

相对位姿约束在 MoveIt2 的标准约束接口中以世界坐标系下的位置与方向约束表达；"两臂之间的相对约束"通常由任务层转写：先规划主臂轨迹，再对轨迹上每个路点用 Trel 计算副臂目标位姿并求逆运动学，得到副臂轨迹后做时间轴对齐。这一"主从式"结构把闭链约束转化为两次开链求解，是工程中最常用的落地方式。

4. 同步执行、物体表示与标定

  • 时间同步：两臂轨迹在同一时间轴上参数化，速度缩放取两臂各自允许值的最小者；路点时间戳对齐误差控制在 10 ms 量级以内。
  • 物体表示：工件附加到主臂，副臂对工件的碰撞检查通过放行名单处理；或工件保持为场景物体并随相对位姿更新。
  • 基座标定：两臂基座的相对位姿（外参）误差直接进入相对位姿精度，标定残差需控制在 1 mm 以内；工具中心点标定同理。
  • 运行监控：用实际关节状态计算两臂末端相对位姿，与期望约束比较，超限即停止并降速回退。

三者构成紧协调的必要条件：没有同步则工件受撕扯，没有物体表示则碰撞误报，没有标定则相对位姿从起点就带着系统偏差。

实现思路与设计

双臂协作的实现步骤（以双规划组方案为例）：

  1. 标定与准备：标定两臂基座外参与工具中心点，验证残差在允许范围内。
  2. 模式与约束定义：确定协同模式；紧协调时计算 Trel 并写入任务配置。
  3. 抓取就位：两臂分别抓取工件（可复用第 061 至 066 章的流程），确认夹持成功。
  4. 主臂规划：按工件目标位姿规划主臂轨迹。
  5. 副臂求解：逐路点计算副臂目标并求逆运动学，拼接为副臂轨迹。
  6. 时间对齐执行：两轨迹时间轴对齐，速度缩放取小值，同步下发执行。
  7. 在线监控：相对位姿偏差与内力监控，超限停止并柔顺回退。

设计决策：为什么采用"主臂定位、从臂柔顺"的分工？

两条刚性位置控制臂共同持物时，任何相对偏差都变成硬碰硬。把从臂刚度降低到 3000–8000 N/m 后，偏差被转化为可控的内力；主臂保持位置精度负责工件位姿，从臂的柔顺起"误差吸收器"作用。分工让系统既保持了工件的位姿精度，又把闭链误差限制在安全区间，代价是工件实际位姿略偏向从臂受力方向，偏差量由力除以刚度给出。

关键代码与解读

片段 1：由主臂位姿与相对约束计算副臂目标

def quat_mul(q1, q2):
    """四元数乘法，顺序为 (x, y, z, w)。"""
    x1, y1, z1, w1 = q1
    x2, y2, z2, w2 = q2
    return (w1 * x2 + x1 * w2 + y1 * z2 - z1 * y2,
            w1 * y2 - x1 * z2 + y1 * w2 + z1 * x2,
            w1 * z2 + x1 * y2 - y1 * x2 + z1 * w2,
            w1 * w2 - x1 * x2 - y1 * y2 - z1 * z2)

def quat_rotate(q, v):
    """用四元数旋转向量 v。"""
    x, y, z, w = q
    vx, vy, vz = v
    t = (2.0 * (y * vz - z * vy),
         2.0 * (z * vx - x * vz),
         2.0 * (x * vy - y * vx))
    return (vx + w * t[0] + y * t[2] - z * t[1],
            vy + w * t[1] + z * t[0] - x * t[2],
            vz + w * t[2] + x * t[1] - y * t[0])

def secondary_target(p1, q1, p_rel, q_rel):
    """副臂目标位姿 = 主臂位姿复合相对约束位姿。"""
    q = quat_mul(q1, q_rel)                  # 姿态复合
    dp = quat_rotate(q1, p_rel)              # 相对平移旋转到世界系
    return (p1[0] + dp[0], p1[1] + dp[1], p1[2] + dp[2]), q

解读：（1）位姿复合 T1·Trel 拆成姿态的四元数乘法与平移的旋转相加两步，公式明确且无外部依赖。（2）相对约束 (p_rel, q_rel) 是常量，由抓取工件时的两臂位姿确定；工件一旦被两臂夹持，该常量在任务期间保持不变。（3）复合结果直接送入副臂的逆运动学求解，逐路点执行即得到从臂轨迹；这种"主从复合"把闭链约束转换成了两次开链计算，代价是主臂轨迹的任何执行偏差都会原样传给从臂目标，因此需要第 7 步的相对位姿在线监控兜底。

片段 2：相对位姿偏差监控

import math

def rel_error(p_a, p_b, q_a, q_b, rel_p, rel_ang, tol_pos=0.002, tol_ang=0.01):
    """监控两臂末端实际相对位姿与期望约束的偏差。"""
    dx = p_b[0] - p_a[0] - rel_p[0]
    dy = p_b[1] - p_a[1] - rel_p[1]
    dz = p_b[2] - p_a[2] - rel_p[2]
    e_pos = math.sqrt(dx * dx + dy * dy + dz * dz)   # 位置偏差模长
    dot = abs(q_a[0] * q_b[0] + q_a[1] * q_b[1]
              + q_a[2] * q_b[2] + q_a[3] * q_b[3])
    angle = 2.0 * math.acos(min(1.0, dot))           # 两姿态夹角
    e_ang = abs(angle - rel_ang)                     # 姿态偏差
    ok = e_pos <= tol_pos and e_ang <= tol_ang
    return ok, e_pos, e_ang

解读：（1）两臂末端实际位姿由关节状态与正运动学计算，偏差与期望约束比较；位置与姿态分开监控，两类偏差的处置不同（位置偏差降速、姿态偏差停止）。（2）四元数点积取绝对值后乘二倍反余弦得到夹角，避免了开方与除法，是姿态距离计算的标准做法。（3）容差 2 mm 与 0.01 rad 来自误差预算：外参标定残差、关节跟踪误差与柔顺偏移的共同上界；阈值越紧，系统越早停止但可用工作区间越小。

片段 3：闭链自由度检查

def dof_check(n1, n2, rigid=6, contact=0):
    """闭链自由度：独立关节总数减去约束维数。"""
    dof = n1 + n2 - rigid - contact
    state = "可动" if dof > 0 else "过约束（需柔顺或调整任务）"
    return dof, state

print(dof_check(6, 6))              # 两臂各 6 关节刚性闭链：自由度 6
print(dof_check(7, 7))              # 冗余臂组合：自由度 8，含 2 维零空间
print(dof_check(6, 6, contact=3))   # 工件另与支撑面接触 3 维：自由度 3

解读：（1）自由度检查在任务设计阶段执行：结果为零或负说明约束过强，刚性编程无法满足，必须引入柔顺或修改任务结构。（2）冗余臂组合的多余自由度是零空间资源，可用于避障与关节限位优化；自由度恰好为零的组合没有零空间，任何扰动都无法通过姿态调整吸收。（3）接触约束维数按接触类型估算（点接触 1 维、面接触 3 维），保守估计可取上限，优先保证系统的可行性判断不出错。

常见坑

  • 忽略两臂基座外参标定：相对位姿从起点就带有 2–5 mm 系统偏差，工件装配偏斜。修复：执行外参标定并验证残差小于 1 mm，标定结果随系统版本固定保存。
  • 两臂独立规划且时间轴不对齐：执行时一臂超前，工件被撕扯或夹持失效。修复：轨迹时间参数化到同一时间轴，速度缩放取两臂最小值，路点时间戳对齐误差小于 10 ms。
  • 共享工件只附加到一臂：另一臂对工件的碰撞检查缺失或误报穿透。修复：明确物体表示策略，副臂对工件的接触通过放行名单管理，并保持工件位姿随主臂更新。
  • 全刚性双臂无柔顺：相对误差全部转为内力，工件受压或传感器超量程。修复：从臂切换柔顺模式，刚度取 3000–8000 N/m，并设置内力上限监控。
  • 相对约束在运行中被静默破坏：单臂轨迹跟踪偏差逐路点累积，系统直到工件损伤才暴露问题。修复：在线监控相对位姿偏差，超限即停止并回退，监控频率与轨迹执行频率一致。

练习与思考

  1. 两臂各 6 关节共同夹持一个刚性工件，工件的另一侧还与导轨发生面接触（约束 3 维）。计算组合系统自由度，并说明结果对任务可行性的含义。★
    提示
    自由度 = 12 − 6 − 3 = 3，仍有 3 个可动方向；若结果小于等于零，说明任务在刚性假设下不可实现，需要引入柔顺或修改工装。
  2. 相对位姿误差 1 mm，工件等效刚度 105 N/m，求内力；若从臂柔顺刚度为 5000 N/m，重新求内力并说明降低幅度。★★
    提示
    刚性情形 100 N，超出常见操作力区间；柔顺情形 5 N，说明从臂的柔顺承担了误差吸收，工件受力水平由柔顺刚度决定。
  3. 对比单规划组与双规划组两种方案：从规划时间、约束满足方式、诊断粒度、实现复杂度四个维度列表比较，并给出适用场景判断。★★
    提示
    单规划组在规划内满足约束但维度高、诊断困难；双规划组把约束移到任务层，逐路点求解可控且便于监控，适合大多数工程实现，单规划组适合自由度较低的专用构型。
  4. 设计"双端搬运 1.5 m 长料"的完整方案：给出模式选择、约束定义、执行同步、监控阈值与失败回退，并估算允许的把持点误差。★★★
    提示
    紧协调模式；Trel 由两端夹持位姿确定；长料对姿态误差敏感，0.2° 的相对姿态误差在 1.5 m 上产生约 5 mm 端部位移，需要提高姿态容差要求或增加中间支撑；失败回退为先降速、再停止，最后由从臂柔顺缓释内力。

小结

  • 双臂协同按耦合强度分松协调、半紧协调与紧协调，紧协调对应完整闭链约束，工程上常拆解为"一臂定位、一臂柔顺"。
  • 闭链约束使组合系统自由度减少 6 维，冗余臂保留零空间用于优化，自由度检查应在任务设计阶段完成。
  • 相对位姿误差经工件刚度放大为内力，柔顺刚度决定实际内力水平，从臂柔顺是紧协调的必要条件。
  • MoveIt2 中常用主从式实现：主臂规划、副臂按相对约束复合求解并时间轴对齐，运行中以相对位姿偏差在线监控。
  • 工程三件套为外参标定、时间同步与相对位姿监控，下一章把平台从固定基座扩展到移动底盘。
