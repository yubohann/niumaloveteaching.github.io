第四篇 · 抓取与操作任务

第 069 章：抓取姿态优化

候选有了，选哪个由评分决定：抓取质量、可操作度、奇异距离、碰撞间隙与运动代价的多目标加权评分，以及硬约束过滤与局部细化。

  • 主题：抓取任务 / 抓取姿态优化（Grasp Pose Optimization）
  • 关键机制：多目标加权评分 / 可操作度与奇异度量 / 局部邻域细化
  • 预计学时：55 分钟
  • 前置章节：第 068 章

学习目标

  • 掌握抓取姿态评分函数的构成：抓取质量、运动学可操作度、最小奇异值、碰撞间隙、运动代价与方向偏好。
  • 理解可操作度 w = √(det(J JT)) 的几何意义（速度椭球体积），能说明相对可操作度的定义与阈值用法。
  • 会设计"硬约束过滤加软指标加权"的层次化优化流程，并解释两类判据为什么不能混合。
  • 掌握候选姿态的局部细化方法：邻域参数、接受准则与计算量控制。
  • 能诊断权重失配、邻域越界、评分与执行结果不一致三类优化失效问题。

背景与动机

第 061 章从物体几何出发生成候选，保证"能夹住"；但能夹住不等于"这台机械臂能完成"：候选可能位于工作空间边缘、接近路径经过奇异位形、与周围障碍间隙过小、或者需要大幅关节运动才能到达。抓取姿态优化回答的问题是把物体侧的质量与机械臂侧的可执行性合并为一个可排序的分数，从候选中选出综合最优者。

优化问题的结构是"少量硬约束加多个软目标"：硬约束（逆运动学可解、无碰撞、张开量匹配）违反即无效；软目标（质量、可操作度、间隙、代价）之间可以折中。两类判据的处理方式不同，这一区分是本章的核心设计原则。

本章与上一章动态场景衔接：运动代价项在动态场景中扩展为时间项；本章也是第 061 至 068 章中所有评分线索的收束点，输出直接进入第 062 章的管线执行。

核心原理

1. 评分函数的组成与量纲问题

分项物理含义方向典型权重
抓取质量摩擦锥余量或力闭合度量越大越好0.30
可操作度末端速度椭球体积的相对大小越大越好0.20
最小奇异值离奇异位形的距离越大越好0.15
碰撞间隙与障碍物的最小距离越大越好，截断0.15
方向偏好接近方向与重力、表面法向的夹角按任务取向0.10
运动代价关节空间距离或路径长度估计越小越好0.10

各分项量纲差异巨大：质量为无量纲比值，间隙以米计，代价以弧度计。直接加权求和会让量纲大的分项主导排序，因此每项先经归一化映射到 [0, 1]，再加权：

S = Σ wi · ŝi，Σ wi = 1 ŝi 为归一化分项；归一化区间取任务相关的经验边界，越界截断

2. 可操作度与奇异度量的几何意义

雅可比矩阵（Jacobian）J 把关节速度映射为末端速度。J JT 的特征值给出末速度椭球的半轴平方，其行列式的平方根即椭球体积，称为可操作度：

w = √(det(J JT))，wrel = w / wmax wmax 取该臂在参考位形下的最大值；工程阈值：wrel 小于 0.1 的位形视为接近奇异，不宜作为抓取位姿

对二连杆平面臂，可操作度有解析式 w = l1l2|sin q2|：两连杆共线时 sin q2 = 0，椭球退化为线段，末端只能沿单一方向运动，对应完全伸展或完全折叠的奇异位形。几何直觉：可操作度小的方向正是施力能力弱的方向（力椭球与速度椭球对偶），抓取位姿接近奇异时，抵抗外力的能力与位置保持精度同步恶化。

3. 层次化优化：硬约束与软指标的分离

优化流程分三层执行：

  1. 硬约束过滤：逆运动学可解、碰撞自由、张开量匹配、可达工作空间。违反任一条件直接淘汰，不进入评分。
  2. 加权评分排序：幸存候选按归一化加权和排序，保留前 K 个（K 取 3–8）。
  3. 局部细化：对前 K 个候选在姿态邻域内搜索评分更高的位姿，输出最终排序。

两类判据不能混合的原因：硬约束是可行性的边界，软指标是可行域内的偏好；把碰撞这类硬约束放进加权和，会在"其他分项很高"时被折中通过，产生实际不可执行的输出。过滤保证正确性，评分保证质量，细化保证局部最优。

4. 局部细化与计算量控制

抓取质量随位姿变化的曲面在其有效域内是分段平滑的，局部细化只需在候选周围小邻域搜索：平移 ±2 mm、旋转 ±5°（约 0.087 rad）的采样范围可覆盖接触点微调的效果。接受准则采用"只接受改进"的爬山策略，避免在评分噪声下退回较差位姿。

计算量控制的关键是评估次数预算：每次评估包含一次逆运动学与碰撞查询，是整条优化管线的开销主导项；细化迭代数取 20–50 次，配合前 K 个候选，把总评估次数约束在百次量级。动态场景中还需叠加时间项（第 068 章的剩余时间），使评分随窗口临近而衰减，保证选出的姿态在时间上可行。

实现思路与设计

优化的实现步骤：

  1. 候选输入：来自第 061 章的候选列表，含位姿、张开量、摩擦锥余量与接近方向。
  2. 过滤执行：逐候选做逆运动学求解与碰撞查询，记录可行解与解的多重性（冗余臂存在多解）。
  3. 分项计算：对每个可行解计算可操作度、最小奇异值、间隙与运动代价。
  4. 评分排序：归一化加权，输出前 K。
  5. 局部细化：对前 K 做邻域搜索，输出最终位姿与评分明细。
  6. 输出与解释：返回排序结果与各分项分数，供调试与权重回归使用。

设计决策：为什么在总分之外返回分项明细？

总分用于排序，明细用于解释。当执行结果与预期不符时（选出的抓取仍失败），明细可以定位是哪个分项的估计失真：间隙估计未覆盖动态障碍、可操作度计算用了错误的工作空间参考、或者质量分高但接近方向不合适。没有明细，权重调整只能靠盲试。

关键代码与解读

片段 1：归一化加权评分

def normalized(value, best, worst):
    """线性归一化：best 得 1 分、worst 得 0 分，越界截断。"""
    if best == worst:
        return 1.0
    t = (value - worst) / (best - worst)
    return max(0.0, min(1.0, t))

def score_grasp(g, kin, clearance, path_cost, weights):
    """加权评分：各分项先归一化，避免量纲不同直接相加。"""
    s = {}
    s["quality"] = normalized(g["margin"], 0.6, 0.0)      # 摩擦锥余量（弧度）
    s["manip"] = normalized(kin["rel_manip"], 1.0, 0.1)   # 相对可操作度
    s["sigma"] = normalized(kin["sigma_min"], 0.1, 0.0)   # 最小奇异值
    s["clear"] = normalized(min(clearance, 0.05), 0.05, 0.0)  # 间隙截断在 5 cm
    s["path"] = 1.0 - normalized(path_cost, 3.0, 0.5)     # 代价越小得分越高
    total = sum(weights[k] * s[k] for k in weights)
    return total, s

解读：（1）归一化区间的两端取自工程经验边界（余量 0.6 rad、可操作度 0.1–1.0 等），区间越界时截断，保证异常值不会主导排序。（2）方向相反的分项（运动代价）用 1 减归一化值表达，使所有分项方向一致，权重全为正数，便于回归调参与解释。（3）返回总分与分项字典，总分供排序使用，分项供解释与权重校准使用，这一结构在权重回归时不可替代。

片段 2：二连杆可操作度与最小奇异值

import math

def manipulability_2link(l1, l2, q2):
    """二连杆平面臂可操作度解析式：w = l1·l2·|sin q2|。"""
    return abs(l1 * l2 * math.sin(q2))

def sigma_min_2link(l1, l2, q2):
    """最小奇异值：由 J Jᵀ 的迹与行列式解特征值后开方。"""
    a = l1 * l1 + l2 * l2 + 2.0 * l1 * l2 * math.cos(q2)
    b = l2 * l2
    det_jjt = (l1 * l2 * math.sin(q2)) ** 2   # det(J Jᵀ) 的解析值
    tr = a + b
    disc = math.sqrt(max(0.0, tr * tr - 4.0 * det_jjt))
    return math.sqrt(max(1e-12, (tr - disc) / 2.0))  # 较小特征值开方

def rel_manip(l1, l2, q2):
    """相对可操作度：除以该臂最大可操作度 l1·l2。"""
    return manipulability_2link(l1, l2, q2) / (l1 * l2)

解读：（1）解析式让原理可见：w 与两连杆长度和夹角正弦成正比，q2 为 0 或 π 时退化为零，对应两个奇异位形（完全伸直与完全折叠）。（2）最小奇异值由 J JT 的较小特征值开方得到，衡量"最难方向"的运动能力，比可操作度对接近奇异的位形更敏感，两者互补。（3）相对可操作度除以理论上限 l1l2，得到与臂长无关的指标，可直接跨机型比较并用于阈值过滤；多关节臂的实际实现由雅可比矩阵经奇异值分解获得同样两个量。

片段 3：局部邻域细化

import random

def perturb(pose, dpos, drot):
    """位姿邻域采样：[x, y, z, rx, ry, rz] 六维各加小扰动。"""
    p = list(pose)
    for i in range(3):
        p[i] += random.uniform(-dpos, dpos)    # 平移扰动：毫米量级
    for i in range(3, 6):
        p[i] += random.uniform(-drot, drot)    # 姿态扰动：小角近似
    return tuple(p)

def refine(grasp_pose, evaluate, iters=30, dpos=0.002, drot=0.087):
    """爬山式细化：在邻域内接受改进，评估次数受 iters 约束。"""
    best, best_s = grasp_pose, evaluate(grasp_pose)
    for _ in range(iters):
        cand = perturb(grasp_pose, dpos, drot)
        s = evaluate(cand)          # 一次评估包含 IK 与碰撞查询：管线开销主导项
        if s > best_s:
            best, best_s, grasp_pose = cand, s, cand   # 改进才接受
    return best, best_s

解读：（1）扰动幅度取 2 mm 与 5°（0.087 rad）是有依据的：小于指尖尺寸的平移改变接触点位置但保持抓取语义，姿态微调改变接近方向但不脱离表面。（2）爬山策略只接受改进，评估次数固定为迭代数加一次初始评估，时间可预测，适合嵌入有实时约束的任务层。（3）如果评分地形存在多个局部峰，可在 K 个候选上并行细化再比较，用候选多样性替代全局搜索。

常见坑

  • 分项未归一化直接加权：间隙以米计的数值远小于以弧度计的余量，排序实际由单一分项决定。修复：所有分项映射到 [0, 1] 后加权，权重之和归一为 1。
  • 把硬约束放进加权和：碰撞候选因其他分项得分高而入选。修复：碰撞、逆运动学、张开量作为过滤条件前置，评分只作用于可行域内部。
  • 细化邻域过大：扰动幅度超过指尖尺度，优化结果脱离原抓取语义，接触点滑出物体表面。修复：平移步长不超过指尖尺寸的四分之一，旋转步长不超过 10°。
  • 权重长期不更新：任务从装配换成分拣后权重未调整，选出的抓取偏向已过时的目标。修复：按任务类型保存权重组，用执行结果（成功率、力峰值）回归校准。
  • 动态场景忽略时间项：评分只含静态指标，选出的位姿在时间上来不及到达。修复：加入剩余时间约束或在评分中乘时间衰减因子，与第 068 章的触发判据联动。

练习与思考

  1. 二连杆臂 l1 = l2 = 0.3 m，q2 = 60°。求可操作度与相对可操作度；指出 q2 取何值时该臂进入奇异。★
    提示
    w = 0.3 × 0.3 × sin 60° ≈ 0.0779，相对可操作度 = sin 60° ≈ 0.866；q2 = 0 或 π 时 sin 为零，臂完全伸直或完全折叠，进入奇异。
  2. 为"精密装配上料"与"高速分拣"两个任务各设计一组权重，说明抓取质量、可操作度、运动代价三项权重的差异与理由。★★
    提示
    装配任务提高抓取质量与间隙权重（放置精度敏感、接触复杂）；分拣任务提高运动代价与可操作度权重（周期时间敏感）。权重组按任务切换，全局共用一套权重会让两类任务互相牵制。
  3. 列出抓取优化的硬约束清单与软指标清单，各至少四项，并说明一条你曾认为属于软指标但实际应为硬约束的判据。★★
    提示
    硬约束：IK 可解、无碰撞、张开量在行程内、接近路径可达；软指标：质量、可操作度、奇异距离、间隙、代价、方向偏好。典型易错项是"接近路径可达"，它常被当作可折中的软指标，实际违反时执行必然失败。
  4. 设计细化实验：固定候选与评分函数，把迭代数从 0 增至 60，记录评分与评估次数的曲线，确定收益饱和点并解释成因。★★★
    提示
    评分随迭代数先升后平，饱和点通常在 20–40 次之间；成因是邻域为有限范围且爬山只接受改进，接近局部最优后改进概率下降，继续迭代只增加 IK 调用开销。

小结

  • 抓取姿态优化把物体侧质量与机械臂侧可执行性合并为可排序分数，分项含质量、可操作度、奇异距离、间隙、方向与代价。
  • 可操作度 w = √(det(J JT)) 是速度椭球体积，相对可操作度用于跨机型阈值过滤，最小奇异值补充对奇异位形的敏感性。
  • 优化流程为"硬约束过滤、软指标加权、局部细化"三层，硬约束保证可行性，评分保证质量，细化保证局部最优。
  • 局部细化的扰动幅度限制在指尖尺度以内，评估次数由迭代数控制，评估成本由 IK 与碰撞查询主导。
  • 评分明细是权重回归与故障定位的依据，下一章进入装配任务：插孔过程中的接触状态与对位理论。
