第三篇 · 规划算法与求解器

第 046 章：使用 Pilz Industrial Motion Planner

Pilz Industrial Motion Planner 用工艺语言组织运动：PTP 关节同步运动、LIN 笛卡尔直线、CIRC 圆弧路径，外加序列混合（blend）。本章讲清三种运动指令的生成机制、插件结构、以及"不做绕障搜索"这一关键定位。

  • 主题：工业运动规划器 / 指令式轨迹生成
  • 关键机制：关节同步插值、笛卡尔直线与圆弧插值、轨迹混合、内置时间参数化
  • 预计学时：55 分钟
  • 前置章节：第 045 章

学习目标

  • 理解指令式运动规划与自由度搜索的差异：运动形态由任务指定，规划器负责可行性校验与时间规划。
  • 掌握 PTP、LIN、CIRC 三种指令的数学构造与失败条件，能按工艺需求选择指令类型。
  • 理解轨迹混合（trajectory blending）的用途与半径参数，能组织多段序列并设置混合区。
  • 会在 MoveIt2 中配置 Pilz 管线、通过规划器标识选择指令，并正确表达关节目标与位姿目标。
  • 能设计"OMPL 粗定位 + Pilz 精段"的混合流水线，并说清为什么 Pilz 不做绕障搜索。

背景与动机

工业现场的多数运动可以归纳为三类：从 A 点快速移动到 B 点（点到点）、沿直线接近工件（直线）、沿圆弧完成工艺路径（圆弧）。这些任务的路径形态由工艺决定，自由发挥属于缺陷。采样式规划器追求"找到任意一条路"，优化型规划器追求"更平滑的路"，而 Pilz 规划器提供的是确定形态、可预测、可重复的指令式轨迹。

Pilz 规划器同时承担"这指令能不能执行"的校验职责：沿生成轨迹检查关节限位、速度加速度上限与碰撞，任一失败即报告失败，不尝试绕行。理解这一边界，才能把它放在正确的任务位置上。

核心原理

1. PTP：关节空间的同步运动

PTP（Point to Point）在关节空间生成轨迹：每个关节按带限位的多项式速度剖面运动，所有关节被缩放到同一总时长，实现"同时出发、同时到达"。

t关节 = maxi ti(Δqi, vmax,i, amax,i)，各轴按 t关节 时间缩放 总时长由"最慢关节"决定；末端路径形状不可预期，只保证起点与终点

PTP 的末端轨迹随关节配置不同而不同，绝不能在 PTP 段做"末端走直线"的假设。它的优势是速度快、关节运动充分、对奇异不敏感，适合空载的快速转场。

2. LIN：笛卡尔直线与姿态插值

LIN 在任务空间生成一条直线段：位置从起点线性插值到终点，姿态沿最短旋转路径插值（四元数插值），路径上的每个采样点通过逆运动学（Inverse Kinematics, IK）映射回关节空间：

p(s) = p0 + s · (p1 − p0)，R(s) = slerp(R0, R1, s)，s ∈ [0, 1] 采样间距随速度剖面变化；每个采样点求解 IK 并检查限位、速度与碰撞

LIN 的失败条件集中而明确：路径穿越奇异位形邻域、关节限位中途截断、IK 在某段无解、或轨迹与场景碰撞。由于逐点求 IK，LIN 对起点位姿有严格要求：起点与目标位姿应处于同一参考系下且姿态容差配置合理，否则直线名义方向与实际起点不匹配，首段出现位置偏差或直接判不可行。

3. CIRC：三点定圆的圆弧插值

CIRC 由起点、辅助中间点与终点确定一段圆弧：三点不共线时唯一确定圆平面与圆心，姿态沿圆弧同步插值。圆弧的适用场景是工艺圆弧（圆弧焊、圆弧涂胶）与绕行障碍的几何避让。

  • 辅助点与起终点共线时圆退化，规划器报错。
  • 圆弧曲率过大时，末端速度与关节速度的映射可能触发上限，规划器降低可行速度或报不可行。
  • 与 LIN 相同的逐点 IK 校验适用于整条圆弧。

较新版本还提供 POLYLINE 折线与轨迹混合指令，把多段直线在拐角处用多项式过渡，形成连续路径。混合区的存在让"多段直角路径"可以一次执行，避免每段起停造成的节拍损失。

4. 插件结构与执行校验

Pilz 以单一管线插件（pilz_industrial_motion_planner/CommandPlanner）注册，内部为每种指令提供规划上下文（planning context），规划器标识即指令名：PTP、LIN、CIRC，较新版本增加 POLYLINE。多段序列通过序列接口承载，每段携带指令类型的运动请求与混合半径。

Pilz 的时间参数化内置在指令生成过程中：速度与加速度缩放因子直接进入速度剖面计算，输出轨迹自带时间戳，不需要额外的时间参数化适配器。这与 OMPL、CHOMP 输出几何轨迹再补时间的流程不同，迁移配置时容易忽略。

实现思路与设计

接入流程：

  1. 加载管线：在 move_group 配置中加入 Pilz 管线条目与规划器标识清单。
  2. 按工艺选指令：转场用 PTP，接近与工艺直线用 LIN，圆弧路径用 CIRC，多段连续路径用混合序列。
  3. 表达目标：PTP 用关节目标或位姿目标；LIN、CIRC 必须用位姿目标，并通过容差参数控制名义路径的紧度。
  4. 设置缩放：速度、加速度缩放因子按工艺要求设置（接近段常用低值）。
  5. 校验失败路径：对奇异、限位与碰撞失败设计回退：退回到高位姿（PTP）后重试，或改用 OMPL 求替代路径。

参数总览（字段以所发行版为准）

项典型值作用取值依据
规划器标识PTP / LIN / CIRC（另有 POLYLINE）选择指令类型由工艺路径形态决定
速度缩放0.1 到 1.0进入速度剖面计算接近段取低值，转场可提高
加速度缩放0.1 到 1.0进入加速度剖面计算与节拍和冲击振动权衡
姿态容差0.01 到 0.1 rad位姿约束的允许偏差容差越大名义直线越松弛
混合半径0.01 到 0.05 m序列拐角的过渡区按节拍与路径贴合要求选择
设计决策：为什么 Pilz 不绕障

指令式运动的路径由工艺规定，规划器的职责是把指令变成满足物理约束的轨迹并回答"能否执行"。如果允许规划器自由改变路径形态，工艺定义就失去意义。绕障属于"自由段"的职责：先用 OMPL 或 CHOMP 把机器人带到接近点，再用 Pilz 完成最后一段确定形态的工艺路径。这一分工是工业流水线里最常见的混合规划结构。

关键代码与解读

片段 1：Pilz 管线配置

# pilz_planning.yaml（结构示意；字段名与可用指令随发行版演进）
planning_plugins:
  - pilz_industrial_motion_planner/CommandPlanner   # 统一入口插件
planner_ids:                     # 指令清单：规划器标识即指令名
  - PTP                          # 关节空间同步点对点
  - LIN                          # 笛卡尔直线
  - CIRC                         # 三点圆弧
  - POLYLINE                     # 折线与混合（较新版本提供）
arm_group:
  default_planner_config: PTP    # 缺省指令：按现场习惯选择

解读：与 OMPL 管线的多插件配置不同，Pilz 用单插件加指令清单的组织方式，简化了"选择运动类型"这件事的配置面。把指令清单理解为能力声明：现场工艺用到哪几种就声明哪几种，缺省指令选现场最常用的类型。注意清单条目必须与插件实际提供的规划上下文一一对应，多写或错写会在启动时报插件解析失败。

片段 2：LIN 直线运动的请求构造（Python）

from moveit_commander import MoveGroupCommander   # 接口以发行版为准
from geometry_msgs.msg import PoseStamped

arm = MoveGroupCommander("arm_group")

# 选择指令：LIN 表示末端沿直线运动，本段作为工艺接近段
arm.set_planner_id("LIN")
arm.set_max_velocity_scaling_factor(0.2)        # 接近段低速：降低接触冲击
arm.set_max_acceleration_scaling_factor(0.2)

goal = PoseStamped()
goal.header.frame_id = "base_link"               # 与规划组基座坐标系一致
goal.pose.position.x = 0.45
goal.pose.position.y = -0.05
goal.pose.position.z = 0.30
goal.pose.orientation.w = 1.0                    # 姿态需显式给出，容差按工艺收缩

arm.set_pose_target(goal.pose)                   # 位姿目标是 LIN 的必需输入
plan = arm.plan()                                # 先规划：确认可行再执行
if plan[0]:
    arm.execute()                                # 输出自带时间戳，可直接执行
else:
    # LIN 失败的三类常见原因：奇异邻域、限位、碰撞；回退策略见练习 3
    print("LIN 不可行，错误码：", plan[3].val)

解读：请求的语义由三件事共同定义：规划器标识给出运动形态，位姿目标给出终点，缩放因子给出速度预算。姿态必须显式设置：只给位置时 LIN 无法确定名义姿态，规划器要么拒绝要么使用当前姿态造成朝向意外偏转。plan() 与 execute() 分离是为了先把"可行性"与"执行"两件事解耦，失败时错误码可进入第 049 章的诊断流程。

片段 3：多段序列与混合半径（结构示意）

# 序列结构示意：每个条目携带一段运动请求与一个混合半径。
# pilz_msgs 中序列消息的字段名以所用版本为准。
sequence = [
    {"type": "PTP",  "goal": joint_home,    "blend": 0.0},    # 首段不混合：确保起点精确
    {"type": "LIN",  "goal": approach_pose, "blend": 0.02},   # 接近段终止于混合区内
    {"type": "LIN",  "goal": contact_pose,  "blend": 0.01},   # 工艺段：拐角小半径过渡
    {"type": "PTP",  "goal": joint_home,    "blend": 0.0},    # 收尾段：回到确定性终点
]

def execute_sequence(arm, sequence):
    """顺序组织指令式运动：前段混合点作为后段起点，减少起停次数。"""
    for item in sequence:
        arm.set_planner_id(item["type"])            # 切换指令类型
        arm.set_joint_value_target(item["goal"]) if item["type"] == "PTP" \
            else arm.set_pose_target(item["goal"])
        # blend 大于 0 表示该段终点允许进入混合区，由序列执行器决定过渡几何
        arm.execute()

解读：序列的关键参数是每段的混合半径：设为 0 表示该段终点必须精确到达并完全停止；大于 0 表示终点附近允许与下一段做多项式过渡，实现连续运动。起点与终点段保持零混合，保证任务的确定性；中间段用小半径混合换取节拍。生产系统中序列通常经序列接口整体下发；此处采用逐段调用，用于说明混合半径对每段边界的控制语义。

常见坑

  • 在 PTP 段假定末端走直线：PTP 只保证起终点，中间末端轨迹随关节同步策略变化，可能扫过工装上方的意外区域。修复：对末端轨迹有要求的段改用 LIN，并对 PTP 段做全轨迹扫掠校验。
  • LIN 起点与目标不在同一参考系：请求位姿的坐标系与规划组基座不一致，名义直线方向错误。修复：统一把目标变换到基座坐标系，或明确使用同一工作坐标系并校验 TF 可用性。
  • 姿态容差过松：容差放宽到 0.2 rad 以上后，名义直线在执行中允许明显姿态偏摆，工艺贴合度下降。修复：按工艺要求收紧容差并实测执行偏差。
  • 期望 Pilz 绕过障碍：目标位姿与起点之间横着工装时，规划器稳定报不可行。修复：引入 OMPL 自由段把机器人带到接近点，再进入 Pilz 精段。
  • 双重时间参数化：Pilz 输出已含时间戳，若管线中再挂时间参数化适配器，重复处理可能覆盖速度剖面。修复：核对 Pilz 管线的适配器配置，移除多余条目。

练习与思考

  1. 某任务从待机位到工件上方 10 cm 处，再从上方进入接触点。为两段各选择指令并说明理由。★
    提示
    第一段 PTP（快速转场，末端路径不敏感）；第二段 LIN（沿接近向量直线进入，接触方向可控）。若接近方向存在奇异风险，考虑把姿态分两段缓冲。
  2. 把 LIN 的速度缩放从 0.2 提到 0.8，预测轨迹时长、关节速度峰值与失败率的变化。★
    提示
    时长缩短到约四分之一量级；关节速度峰值提高，接近奇异时更易触发上限报不可行；失败率在工件附近位形紧张时上升。用同一位姿重复 20 次观察分布。
  3. 设计 LIN 失败的三级回退：奇异邻域、关节限位、轨迹碰撞。为每种失败给出一个具体动作并说明依据。★★
    提示
    奇异：抬高起点姿态角或改用带姿态缓冲的两段 LIN；限位：调整目标位姿的旋转（绕工具轴旋转寻找可行解）；碰撞：回退到接近点后请求 OMPL 重新找路。
  4. 设计一个混合流水线实验：OMPL 粗定位加 Pilz 精段与全程 LIN 两组方案完成同一插孔任务，各 20 次，比较成功率、暴露的失败类型与节拍。★★★
    提示
    记录每类失败计数（奇异、限位、碰撞、超时）；平均节拍用执行轨迹的时长求和。预期混合方案成功率显著更高，纯 LIN 方案的失败集中在位形与碰撞两类。

小结

  • Pilz 提供指令式运动：PTP 关节同步、LIN 笛卡尔直线、CIRC 三点圆弧，较新版本增加折线与混合指令。
  • 每种指令的路径形态由任务规定，规划器负责逐点 IK、限位与碰撞校验，不进行绕障搜索。
  • LIN 与 CIRC 必须提供位姿目标与合理容差；逐点 IK 使奇异、限位、碰撞成为三类主要失败来源。
  • 序列与混合半径支撑多段连续运动，首尾段保持零混合保证确定性，中间段以小半径换取节拍。
  • Pilz 内置时间参数化，输出可直接执行；配置时避免叠加额外的参数化适配器。
