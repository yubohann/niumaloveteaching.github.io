第 093 章：安全机制：速度与力矩限制

从模型限值到硬件保护，梳理速度与力矩限制的四层防御体系；讲清限值来源、组合规则与安全速度上限的推导，并给出力控模式下的边界条件。

  • 主题：安全设计 / 限制与保护
  • 关键机制：限值分层、缩放系数组合规则、停止距离约束、力矩监测与限幅
  • 预计学时：55 分钟
  • 前置章节：第 092 章

学习目标

  • 理解安全限制的四层结构：模型限值、规划约束、控制器限制、硬件保护，及各层职责。
  • 掌握关节限值配置的语义：速度、加速度与力矩限值分别在哪一环节生效。
  • 会用最小组合规则计算生效限值，解释缩放系数与限值的叠加关系。
  • 会由间隙与减速度推导安全速度上限，并把结论落实到配置。
  • 理解力矩限制的实现途径与力控模式下的边界条件。

背景与动机

限制值是把规划算法与物理安全之间的差距弥合起来的工具。限制设计不完整的表现通常落在现场现象上：偶发过冲、急停后仍滑行一段、受冲击时关节闷响，程序日志里未必有对应记录。这些现象都可以追溯到某一层限制缺失或取值松懈。

限制值分散在多个配置位置：模型的关节定义、关节限值配置、控制器参数与硬件安全链。它们各自独立生效，最终的允许值取全体中最严格者。不理解组合规则时，开发者容易以为改了规划侧缩放就足够，而忽略控制器与硬件层的独立钳制。

上一章用停止距离约束了时序参数，本章把速度与力矩限制系统地落实到四层结构中，两者共同构成系统安全边界。

核心原理

1. 四层防御体系

安全限制按生效位置分为四层，逐层兜底。上层失守时下层仍能阻止危险动作，这是"防御深度"的含义。

层内容典型故障失效后果
模型层关节位置、速度、力矩限值限值留空或过于宽松规划与仿真越过真实能力
规划层速度与加速度缩放、工作空间边界、路径约束缩放未设置或误设轨迹过快、贴边运行
控制器层命令限幅、跟随误差监控、控制器级限值限幅未使能异常命令直接驱动电机
硬件层安全板、驱动器保护、急停回路、机械限位急停未接线或未测试无物理止损手段

2. 限值的来源与语义

模型层限值写在关节定义中，包含位置上下限、速度上限与力矩上限；关节限值配置可以对速度与加速度补充分级限制并覆盖模型值。加速度限值尤其重要：时间参数化在没有加速度限值时只能按速度与梯形速度曲线近似，轨迹的加速度曲线可能不连续。

生效限值 = min( 模型限值, 关节限值配置, 控制器级限值, 硬件保护阈值 )
准静态允许速度 = 缩放系数 · 生效速度限值 缩放系数在 (0, 1] 区间，乘在生效限值之上；任一层设了更小值，缩放后仍以更小值为准

3. 由间隙推导安全速度上限

安全速度不是常数，它随环境间隙变化：间隙充足时允许全速，接近障碍时按减速距离衰减。该规则是伺服碰撞缩放与安全区间分区的共同依据。

v安全(d) = min( v限值, √( 2 · a减速 · max(0, d − d0) ) ) d 为最小间隙、d0 为保留余量（停止后仍需维持的距离）、a减速 取生效减速度；间隙等于余量时速度上限为零

举例：减速度 3 m/s²、保留余量 0.02 m，间隙 0.10 m 时平方根项约 0.69 m/s，若限值为 1.0 m/s 则按 0.69 m/s 运行。把该公式离散成若干档位写入配置（例如间隙小于 0.05 m 时限速 0.3 m/s），实现成本低于在线求解。

4. 力矩限制与力控边界

力矩限制有两条实现途径：命令侧限幅（对力矩命令按上限截断）与监测侧保护（对比命令力矩与模型预测力矩，偏差超限判为异常负载或碰撞）。无外力传感器时，监测侧的灵敏度受摩擦与动力学误差限制，阈值取保守值以避免误触发。

τ允许 = min( τ驱动上限, τ额定 · k温度降额 )
碰撞判据：|τ实测 − τ模型预测| > τ阈值（持续超过过滤窗口时长） 降低温度降额系数覆盖连续负载发热；判据加持续时长条件抑制瞬时尖峰误报

力控模式（柔顺控制）下，位置环被外力偏置软化，位置限位对末端位置不再构成硬约束，安全依赖力矩上限与速度上限。进入力控模式前必须确认这两类限值已生效，并在退出时平滑复位位置环。

实现思路与设计

安全参数设计按"定职责、填限值、验证组合、标定阈值"四步执行。每一层只做自己职责内的钳制，验证阶段通过超限注入证明每层都独立有效。

1. 分层参数表

层参数示例取值依据
模型层关节速度上限1.5 rad/s厂家标称值乘安全系数
模型层关节力矩上限按额定值降额连续负载温升与冲击余量
规划层速度缩放0.3（调试）任务验证阶段保守，稳定后提升
规划层工作空间边界操作区加余量 0.1 m围栏与感知盲区之外
控制器层速度与力矩限幅取模型限值的 0.9控制器侧先于硬件触发
硬件层急停与安全区按现场标定物理止损，独立于软件

2. 安全速度档位设计

把间隙到速度的连续映射离散为档位：间隙大于 0.2 m 用全速，0.1–0.2 m 用 70%，0.05–0.1 m 用 40%，小于 0.05 m 用 0.2 m/s 以下或暂停。档位边界取整数便于评审与实测对照；每档速度都要满足该档最小间隙下的停止距离约束。

3. 验证方法与注入项

  1. 超速注入：发送超过缩放后限值的轨迹，确认控制器层截断。
  2. 超限位注入：目标越过软限位，确认规划层拒绝且给出错误码。
  3. 力矩异常注入：人为施加负载或阻挡，确认监测侧在标定窗口内触发。
  4. 急停链路测试：软件与硬件两级分别触发，测量停止距离并记录。

与上一章的差异点：第 092 章确定"什么时刻必须完成"，本章确定"什么数值必须不超过"；时序预算与限值设计共同决定可行速度区间。

关键代码与解读

片段 1：关节限值配置（YAML）

# joint_limits.yaml：模型限值的补充与覆盖，供时间参数化消费
joint_limits:
  shoulder_pan_joint:
    has_velocity_limits: true
    max_velocity: 1.5            # 与模型标称一致，留作现场降额入口
    has_acceleration_limits: true
    max_acceleration: 2.0        # 缺少加速度限值时轨迹加速度可能不连续
  elbow_joint:
    has_velocity_limits: true
    max_velocity: 1.2
    has_acceleration_limits: true
    max_acceleration: 1.5
  wrist_3_joint:
    has_velocity_limits: true
    max_velocity: 2.0            # 腕部惯量小，允许更高速度但受振动约束
    has_acceleration_limits: true
    max_acceleration: 2.5

解读：这份配置决定时间参数化的输入边界。设计要点：（1）显式声明 has_* 标志，缺省时该维度不参与参数化，轨迹质量退化；（2）限值取值区分关节特性：大惯量关节速度与加速度都更保守，腕部可略高但受振动与末端精度约束；（3）max_velocity 写作标称值的现场降额入口，同一份配置在调试与生产环境可切换。加速度限值必须与速度限值同时给出，否则梯形曲线的拐点加速度无限大，实际执行端无法复现。

片段 2：安全速度档位计算

import math


def safe_speed(clearance_m, a_decel=3.0, reserve_m=0.02, v_limit=1.0):
    """由间隙推导安全速度上限：停止距离公式的逆用。"""
    reachable = max(0.0, clearance_m - reserve_m)
    # 平方根项是"在该距离内能够停下的最大速度"
    v_stop = math.sqrt(2.0 * a_decel * reachable)
    return min(v_limit, v_stop)


def speed_ladder(clearances, bands=(0.2, 0.1, 0.05)):
    """把连续映射离散为档位，便于写入伺服速度缩放配置。"""
    ladder = []
    for d in clearances:
        if d >= bands[0]:
            scale = 1.0
        elif d >= bands[1]:
            scale = 0.7
        elif d >= bands[2]:
            scale = 0.4
        else:
            scale = 0.0               # 进入保留区：暂停运动并等待避让
        # 档位只是初值；每一档还要通过停止距离复核后才可使用
        ladder.append((d, scale))
    return ladder


# 示例：三档间隙下的缩放系数，供配置评审对照
for d, s in speed_ladder([0.30, 0.15, 0.08, 0.03]):
    print(f"间隙 {d:.2f} m -> 缩放 {s:.1f}，安全速度上限 {safe_speed(d)*s:.2f} m/s")

解读：这段代码把连续的安全速度映射落地为可配置的档位表。设计要点：（1）停止距离公式取逆用，间隙减余量后开方得到可停速度；（2）档位是离散近似，边界取整数便于评审与现场实测对照；（3）最紧档位取零缩放表示暂停，交由上层避让或等待；（4）打印对照表把两个函数联动起来，检查每档速度确实不高于该档最小间隙下的可停速度。替代方案是伺服节点内在线计算，精度更高但验证路径更长。

片段 3：控制器层的命令限幅与监测（C++ 示意）

#include <algorithm>
#include <cmath>

// 控制器更新周期内的命令处理：先限幅再监测，两道处理彼此独立
double clamp_and_check(double cmd, double limit, double measured,
                       double predicted, double torque_threshold) {
  // 第一道：命令限幅保证任何上游异常都不会直接驱动电机
  const double limited = std::clamp(cmd, -limit, limit);

  // 第二道：力矩残差监测；残差为实测与模型预测之差
  const double residual = std::fabs(measured - predicted);
  if (residual > torque_threshold) {
    // 持续时间条件由上层过滤器承担，此处只发出异常样本
    reportTorqueAnomaly(residual);
  }
  return limited;
}

解读：控制器层的两个动作对应"防输入"与"防状态"。设计要点：（1）限幅放在命令出口，位置与速度命令同点位截断，保证最坏情况下输出有界；（2）力矩残差监测独立于限幅，覆盖"命令合法但环境异常"的情形（碰撞、缠绕、负载突变）；（3）残差判据需要持续时长过滤，瞬时尖峰由上层窗口计数器处理，避免单周期噪声触发停机。阈值标定方法：正常负载下采集残差分布的 P99，阈值取其上再乘安全系数。

常见坑

  • 只改规划侧缩放：以为缩放系数就是最终速度，忽略控制器与硬件层的独立阈值配置。修复：每层限值单独核对，验证实验逐层注入超限命令。
  • 未启用加速度限值：时间参数化只约束速度，轨迹拐点处加速度突变，执行端产生冲击。修复：在关节限值配置启用加速度限值并给出合理数值。
  • 软限位贴边设置：软限位与硬限位间距过小，控制误差叠加标定误差后仍有触碰硬限位的风险。修复：软限位留出与控制误差匹配的余量并纳入验收项。
  • 力矩监测阈值过紧：正常加速段被误判为碰撞，频繁触发停机。修复：阈值按残差分布标定并加载持续时长条件，标定数据覆盖最大加速度工况。
  • 力控模式沿用位置模式假设：进入柔顺控制后仍以位置限位作为主要保护。修复：力控模式下以力矩与速度上限为主保护，退出时平滑恢复位置环。

练习与思考

  1. 计算安全速度：间隙 0.15 m、保留余量 0.02 m、减速度 3 m/s²、限值 1.2 m/s，求安全速度上限；若减速度提高到 5 m/s²，结果如何变化？★
    提示
    √(2×3×0.13) ≈ 0.88 m/s；减速度提高到 5 时为 √(2×5×0.13) ≈ 1.14 m/s，接近限值 1.2；若继续提高减速度，限值将取代距离项成为主约束。
  2. 解释四种限值来源的生效关系，并构造一个"规划层最严"与一个"控制器层最严"的具体配置组合。★★
    提示
    生效值取各层最小值；规划层最严：缩放 0.3 乘 1.5 得 0.45 小于控制器 0.9 档；控制器层最严：缩放 1.0 而控制器按模型限值 0.9 截断。
  3. 改配置并预测：把肘关节 max_acceleration 从 1.5 提高到 3.0（其余不变），同一条点到点轨迹的执行时间与关节峰值力矩分别如何变化？★★
    提示
    加速段更短、执行时间下降；峰值力矩近似与加速度成正比上升，需复核力矩上限与残差监测阈值。
  4. 设计力矩残差监测的标定流程：数据采集工况、分布统计、阈值选择与验证，说明每个环节的判据。★★★
    提示
    覆盖最低到最高加速度与满载工况采集残差，取 P99 乘 1.5–2 倍安全系数做初值；用阻挡实验验证灵敏度，用全速空载运行验证误报率。
  5. 说明为什么"急停之后仍需减速距离预算"，并给出停止距离与安全围栏尺寸的关系式。★★
    提示
    急停切断动力后机械系统仍按减速度滑行；围栏尺寸至少覆盖停止距离加余量，公式见第 092 章停止距离式。

小结

  • 四层防御：模型限值、规划约束、控制器限制、硬件保护，逐层独立兜底。
  • 生效限值取各层最小值，缩放系数乘在生效值之上；设置前先确认每层的实际配置。
  • 安全速度随间隙变化，由停止距离公式逆用得到，可离散为便于验证的档位。
  • 力矩限制包含命令限幅与残差监测两条途径，阈值按数据分布标定并加载持续时长条件。
  • 力控模式以力矩与速度上限为主保护，位置限位不再构成硬约束。
  • 下一章处理失败与异常本身：规划失败的恢复策略，把安全边界内的失败转化为可恢复的状态转移。
