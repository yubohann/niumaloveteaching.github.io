第 067 章：真空吸盘建模与控制

真空吸附的物理链条：抽速与漏率决定稳态真空度，真空度与面积决定法向吸力；从平面检测生成吸附位姿，到泄漏检测确认吸附的三段式控制。

  • 主题：末端执行器 / 真空吸盘（Vacuum Gripper）
  • 关键机制：稳态真空度 Δp ≈ Q/S / 吸力估算 F = η·Δp·A / 平面检测与法向对齐
  • 预计学时：50 分钟
  • 前置章节：第 066 章

学习目标

  • 理解真空系统三要素：抽速（Suction Flow）、漏率（Leak Rate）与稳态真空度（Vacuum Level）的关系 Δp ≈ Q/S，能解释密封条件对漏率的影响。
  • 掌握吸力估算 F = η·Δp·A 与安全系数设计，能按负载与加速度反推吸盘直径。
  • 掌握平型、波纹管型、椭圆型吸盘与粗糙度、曲率、透气性等表面特征的匹配原则。
  • 会在 URDF 与 SRDF 中建立吸盘工具坐标系，并实现由平面检测结果生成吸附位姿的法向对齐计算。
  • 会设计基于真空度阈值与抽吸时间上限的吸附确认与泄漏检测逻辑。

背景与动机

夹持式夹爪依靠两侧指面施加法向力，真空吸盘依靠负压把工件吸在接触面上。吸盘的物理链条比夹爪更长：真空源能力、管路损失、唇边密封、工件表面特性共同决定实际吸力，任何一环劣化都会以"吸附失败"或"搬运中途脱落"的形式暴露。因此吸盘控制需要把物理估算、位姿对齐与在线检测连成闭环。

在规划与操作层面，吸盘任务的几何特征也不同：吸附面通常由感知（点云平面检测）给出，位姿生成需要法向对齐；吸附确认依赖真空传感器，位置与电流反馈在吸盘任务里不构成判据。这些差异决定了吸盘虽然复用第 062 章的阶段结构，但确认逻辑与位姿来源需要独立设计。

本章承接第 066 章的"接触后确认"视角，把确认信号从电流换成真空度；同时为第 069 章的抓取姿态优化提供"吸附面法向约束"这一特殊情形。

核心原理

1. 真空系统物理：抽速、漏率与稳态真空度

真空源的抽速 S 表示单位时间内能抽走的气体体积流量，漏率 Q 表示密封界面单位时间漏入的气量。二者动态平衡时，系统稳定在一个真空度上：

Δp ≈ Q / S Δp 为相对大气压的压差（真空度）；Q 与 S 使用一致的单位制（如 Pa·m³/s 与 m³/s）。文丘里真空发生器在供气压力 0.4–0.6 MPa 下典型可达 Δp = 60–80 kPa

该式解释了两个工程事实：抽速不足时再怎么等待也无法提升真空度；漏率超标（表面粗糙、褶皱、透气材料）会把稳态真空度整体拉低。密封的物理条件是唇边与表面形成连续接触带：表面粗糙度小于唇边压缩变形量、接触带内无贯穿沟槽、工件无贯穿气孔。多孔材料（纸板、织物、木材）漏率极大，吸盘方案在其上往往不可行。

2. 吸力估算与安全系数

法向吸力由压差与有效吸附面积相乘，并乘上有效系数：

F = η · Δp · A，A = π d2 / 4 d 为唇边内径；η 取 0.6–0.8，涵盖边缘泄漏与压力分布不均；安全系数 s 取 2–3 后再校核惯性载荷

直径 30 mm 吸盘、Δp = 60 kPa、η = 0.7 时吸力约 29.7 N；按安全系数 2 计算，允许静负载约 15 N，对应质量约 1.5 kg。安全系数需要覆盖两类动态载荷：竖直方向的搬运加速度产生的惯性力，以及加速度方向作用于长条形工件时产生的剥离力矩。剥离力矩约束常比法向载荷更苛刻：细长工件应布置多点吸附并要求力矩平衡。

s · m (g + a) ≤ n · F n 为并联吸盘数量；单吸盘方案需再校验剥离力矩：m(g+a)·L ≤ n·F·r，L 为重心到吸附点距离，r 为吸盘半径

3. 吸盘类型与表面匹配

类型结构特点适用表面注意点
平型（Flat）唇边薄、行程小平整硬质表面抗侧向力好，曲面泄漏大
波纹管型（Bellow）有轴向行程补偿轻微曲面、装配高度差侧向刚度低，需控制惯性
椭圆与长条型长宽比大板材、窄条工件覆盖面积大，仍要校核剥离

表面特征按影响排序：透气性最致命（漏率量级失控），其次为粗糙度与褶皱（泄漏路径），再次为油膜与污染（唇边附着力变化）。选型结论：透气或高粗糙表面选用大流量发生器与波纹管型，平整表面选用平型以获得抗侧向能力。

4. 吸附位姿生成与泄漏检测

吸附面由点云处理给出：平面分割（如随机采样一致性方法）输出平面法向与平面内点集合。吸附位姿由三项要素构成：

  • 位置：平面内点集合的中心点沿内法向偏移，偏移量为吸盘唇边压缩行程。
  • 姿态：吸盘轴线与平面法向对齐，等价于把工具坐标系 z 轴转到指定方向，用最小旋转构造四元数。
  • 可用性：平面内点覆盖范围需大于吸盘唇边投影面积，且法向与重力夹角小于阈值（例如 45°），保证法向吸力承担主要载荷。

吸附确认由两个条件同时约束：真空度在时间上限内达到阈值（确认密封），以及搬运过程中真空度跌落不超过允许值（确认保持）。第一条件检测初始密封，第二条件检测过程稳定；只做前者会在唇边逐渐移位后失去预警能力。

实现思路与设计

吸盘抓取流水线的实现步骤：

  1. 感知输入：点云预处理（降采样、离群点剔除），平面分割输出候选平面的法向、中心与内点集合。
  2. 候选筛优：按面积覆盖、法向倾角、高度可迭性筛选，输出吸附位姿候选。
  3. 位姿生成：法向对齐与唇边偏移生成吸附位姿，接近方向取法向反方向。
  4. 接近与贴合：低速垂直下降直到唇边压缩行程用尽，速度 0.01–0.03 m/s。
  5. 抽吸与确认：开阀抽吸，按真空度阈值与时间上限判定，成功后进入附着流程。
  6. 搬运监控：周期读取真空度，跌落超限则中止并就地放置。
  7. 释放：破真空或吹气，等待时间让工件与唇边分离后再抬升。

设计决策：为什么真空度按相对大气压表达？

吸力的物理来源是吸盘内外压差，工程中一致使用相对大气压的真空度（如 −60 kPa 或 60 kPa 真空度）表达，避免绝对压力与表压混用造成的计算错误。传感器读数的符号约定需在驱动层统一，消息接口只传递一个约定方向的量。

关键代码与解读

片段 1：吸力估算与吸盘直径反推

import math

def suction_force(d_cup_mm, dp_kpa, eta=0.7):
    """吸力估算 F = η·Δp·A：面积按唇边内径圆计算。"""
    r = d_cup_mm / 2000.0                 # 毫米转米并取半径
    area = math.pi * r * r                # 有效吸附面积
    return eta * (dp_kpa * 1000.0) * area  # 真空度千帕转帕后参与计算

def min_cup_diameter(load_n, dp_kpa=60.0, eta=0.7, safety=2.0):
    """按负载反推最小直径：需求吸力除以单位面积吸力。"""
    need = safety * load_n                      # 负载上叠加安全系数
    area = need / (eta * dp_kpa * 1000.0)       # 由 F = η·Δp·A 解出面积
    return 2.0 * math.sqrt(area / math.pi) * 1000.0  # 米转毫米输出

m = 1.5                                          # 工件质量 1.5 kg
print(f"直径 30 mm 吸盘吸力 {suction_force(30, 60):.1f} N")
print(f"安全系数 2 下所需最小直径 {min_cup_diameter(m * 9.81):.0f} mm")

解读：（1）两个函数互为逆运算：正算给出"现有吸盘能提多重"，反推给出"要多大的吸盘"，选型阶段用后者、改造阶段用前者。（2）单位换算集中在函数内部（毫米到米、千帕到帕），调用方只按工程习惯输入，减少量纲错误。（3）示例结果：30 mm 吸盘吸力约 29.7 N，1.5 kg 工件在安全系数 2 下需要约 30 mm 直径，恰好处于边界，实际选型应上取到 40 mm。

片段 2：由平面法向生成吸附位姿

import math
from geometry_msgs.msg import Pose, Quaternion

def unit(v):
    L = math.sqrt(v[0] * v[0] + v[1] * v[1] + v[2] * v[2])
    return (v[0] / L, v[1] / L, v[2] / L)   # 调用方负责检查零长度

def quat_from_z_axis(t):
    """最小旋转：把工具 z 轴转到目标方向 t（单位向量）。"""
    tx, ty, tz = t
    dot = tz                                # 与 z=(0,0,1) 的点积
    if dot > 0.9999:
        return Quaternion(x=0.0, y=0.0, z=0.0, w=1.0)   # 已对齐
    if dot < -0.9999:
        return Quaternion(x=1.0, y=0.0, z=0.0, w=0.0)   # 反向：绕 x 转 π
    s = math.sqrt(2.0 * (1.0 + dot))        # 四元数归一化因子
    return Quaternion(x=-ty / s, y=tx / s, z=0.0, w=(1.0 + dot) / s)

def cup_pose_on_plane(center, normal, compress=0.002):
    """吸附位姿：位置沿内法向偏移压缩行程，姿态使工具 z 对齐内法向。"""
    n = unit(normal)
    pose = Pose()
    pose.position.x = center[0] - n[0] * compress  # 压向表面：负向偏移
    pose.position.y = center[1] - n[1] * compress
    pose.position.z = center[2] - n[2] * compress
    pose.orientation = quat_from_z_axis(n)  # 接触面朝外，与接近方向相反
    return pose

解读：（1）四元数由"把 z 轴转到法向"的最小旋转直接构造，包含两个退化分支：法向与 z 轴同向时返回单位四元数，反向时绕 x 轴转 π，避免叉乘为零向量。（2）归一化因子 s 的推导来自四元数模长恒等式，代码长度比引入完整旋转库更短，适合嵌入式与实时路径使用。（3）压缩行程沿内法向负向偏移，让唇边在接触后得到设计压缩量，偏移量取吸盘手册给出的许用值（典型 1–3 mm）。

片段 3：抽吸与吸附确认

import time

def attach_by_vacuum(vacuum_reader, valve, threshold_kpa=45.0, timeout_s=1.0):
    """抽吸并确认：真空度达标才算吸附成功，超时判定泄漏。"""
    valve.open()                                # 打开抽吸阀，启动真空发生器
    t0 = time.monotonic()
    while time.monotonic() - t0 < timeout_s:
        if vacuum_reader.kpa() >= threshold_kpa:
            return "ATTACHED"                   # 密封良好：进入附着与搬运
        time.sleep(0.02)                        # 20 ms 轮询：判定延迟可接受
    valve.close()                               # 超时先关阀：避免持续耗气
    return "LEAK"                               # 未达标：表面漏气或未贴合

def monitor_vacuum(vacuum_reader, drop_kpa=10.0, baseline_kpa=None):
    """搬运中的保持性监控：真空度相较基线跌落超限即报警。"""
    base = baseline_kpa if baseline_kpa is not None else vacuum_reader.kpa()
    return "HOLD" if base - vacuum_reader.kpa() < drop_kpa else "SLIP"

解读：（1）确认条件采用"阈值加时间上限"双判据：只设阈值会无限等待泄漏状态，只设时间会在真空度不足时误判成功。（2）超时分支先关阀再返回，避免故障状态下持续消耗压缩空气；返回值 LEAK 交由任务层决定换吸附位姿或放弃该工件。（3）搬运监控以起始真空度为基线比较跌落量，适应不同发生器与管路的绝对差异，阈值 10 kPa 高于传感器噪声与正常波动。两段代码共同构成"进入吸附"与"保持吸附"两个时间尺度的防护。

常见坑

  • 只算法向载荷不校剥离力矩：细长工件在加速时绕吸附点旋转脱落，法向吸力完全满足也无效。修复：按 m(g+a)·L ≤ n·F·r 校核矩，必要时增加吸盘数量或缩小重心偏心。
  • 曲面与褶皱表面沿用平型吸盘：唇边无法形成连续接触带，抽吸时间上限内真空度不达标。修复：改用波纹管型并提高发生器流量，或改选机械夹持方案。
  • 接近速度过快：唇边撞击工件后弹跳或过度压缩，密封面瞬时破坏。修复：贴合段速度取 0.01–0.03 m/s，下降分为快速接近与低速贴合两段。
  • 真空度阈值设定脱离实际：按发生器标称值设阈值，未扣除管路长度与接头损失，正常密封也判为泄漏。修复：以实测稳态真空度为基准设阈值，并在系统中记录管路布置。
  • 释放时不破真空或等待不足：工件仍被吸附，抬升时被拖动或撕拉表面。修复：释放走"破真空加吹气再等待 0.2–0.5 s"的固定序列，确认真空度回落到大气附近再抬升。

练习与思考

  1. 直径 40 mm 吸盘、真空度 60 kPa、有效系数 0.7，求吸力；若工件质量 3 kg、安全系数 2，判断是否可用单只吸盘竖直提升。★
    提示
    F = 0.7 × 60000 × π × 0.02² ≈ 52.8 N；需求 2 × 29.4 = 58.8 N 大于吸力，单只不足，需要更大直径或多点吸附。
  2. 把安全系数从 2 提高到 3，最小所需吸盘直径如何变化？推导直径与安全系数的比例关系。★★
    提示
    由 d ∝ √s 得放大 factor √(3/2) ≈ 1.22，30 mm 需上取到 37 mm 以上的标准规格，通常直接选 40 mm。
  3. 设计泄漏判据：给定阈值 50 kPa、时间上限 1.0 s，列举三种会触发泄漏判定的物理情形，并为每种情形给出后续处置。★★
    提示
    未贴合（下降深度不足）、表面有贯穿沟槽或褶皱（漏率过高）、管路或接头泄漏（抽速有效值下降）。处置分别为增加压缩行程、更换吸附位姿、检修管路。
  4. 为 0.6 m × 0.4 m 板材设计吸附布局：给出吸盘数量、布置位置、抽吸顺序与剥离力矩校核过程。★★★
    提示
    四点对称布置使重心居中，力矩校核取臂长最小的一个吸盘；抽吸顺序建议对角交替以避免单侧先吸附导致板面挠曲，释放顺序与抽吸相反。

小结

  • 真空系统的稳态真空度由漏率与抽速之比决定，密封条件即"唇边连续接触加无贯穿泄漏路径"。
  • 吸力按 F = η·Δp·A 估算，选型需同时校核法向载荷与剥离力矩，安全系数取 2–3。
  • 吸盘类型按表面透气性、粗糙度与曲率匹配，波纹管型提供行程补偿，平型提供侧向刚度。
  • 吸附位姿由平面检测的法向与中心生成，法向对齐可用最小旋转四元数直接构造，含同向与反向两个退化分支。
  • 确认逻辑采用"阈值加时间上限"检测密封，并以基线跌落监控搬运过程中的保持性，下一章讨论动态抓取中的时间预算与预测拦截。
