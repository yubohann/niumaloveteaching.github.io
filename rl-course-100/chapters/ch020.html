第一篇 · 策略梯度与 PPO

第 020 章：PPO的稀疏奖励处理

在 MountainCar 上对比原始奖励与势能塑形（PBRS）：每步 −1 的稀疏信号下策略几乎学不动，加上 γΦ(s′)−Φ(s) 的势能差后，成功率从"长期趴窝"变成"十几万步内稳定上山"。

  • 主题：稀疏奖励 / 奖励塑形
  • 关键公式：r̃ = r + η·[γΦ(s′) − Φ(s)]；ΣγtΔΦ 望远镜式抵消
  • 预计学时：65 分钟
  • 前置章节：第 019 章

学习目标

  • 理解稀疏奖励任务为什么难：回报对"过程中的进步"不敏感，优势信号被常数淹没。
  • 掌握势能塑形（Potential-Based Reward Shaping, PBRS）的形式与"最优策略不变"定理。
  • 实现位置势能与高度势能两种 Φ，理解"塑形只加速、不改变解"的含义。
  • 在 MountainCar-v0 上对比 baseline 与 shaping，评价指标采用成功率（回报数值受回合长度混杂，不能直接横比）。
  • 了解稀疏奖励的其他解法（计数奖励、RND 好奇奖励、课程），能按任务选择组合。

背景与动机

MountainCar 的规则简单到残酷：每步奖励 −1，只有把车开到右边山坡（位置 ≥ 0.5）才算成功；停着不动、来回晃、冲坡失败，回报都是 −1/步。这意味着在策略偶然成功之前，所有轨迹的回报几乎一样，"靠近坡顶"和"在原地打转"得到的学习信号毫无区别。策略要学的偏偏是反直觉的动作：先向左倒车积累动能，再猛冲右坡。

这就是稀疏奖励（sparse reward）问题：核心困难在于奖励对"进步"的梯度是零，与奖励的数量多少无关。解决办法分两类：一是改变奖励（塑形、好奇心），二是改变探索（计数、噪声、课程）。本章用最经典、最有理论保障的一种，势能塑形：给每个状态定义一个"潜在价值" Φ(s)，用它的折扣差作为额外奖励。Ng 等人的定理保证，只要形如 γΦ(s′)−Φ(s)，无论 Φ 怎么选，最优策略都不变；Φ 的好坏只影响学习速度。这条定理让塑形从"玄学调参"变成"有原则的设计"。

核心原理

1. 稀疏奖励的困境：常数奖励等于没有奖励

MountainCar 每步 −1，直到成功。不成功时回合回报恒为 −200（200 步上限），回报对策略改进完全不敏感。优势 Ât = 回报 − 基线，在失败轨迹上近似 0，策略梯度只能在极少数成功轨迹上获得信号。结果就是：要么长时间学不动，要么靠运气找到成功轨迹后慢慢强化。

用 GAE 的折扣核把这个困难量化：优势估计里，距离 t 步远的事件权重按 (γλ)k 衰减，代入 γ=0.99、λ=0.95，(γλ)=0.9405。成功与失败的唯一差别出现在回合尾部（早停 110 步对跑满 200 步，差 90 分），这个信号在回合起点处的权重只有 0.9405110 ≈ 0.0012，也就是被衰减了约 850 倍；GAE 的"平均信用跨度"是 (γλ)/(1−γλ) ≈ 15.8 步，超过约二十步的信息基本传不回早期状态。MountainCar 的一次成功需要几十步的动量积累，远离尾部的位置几乎收不到这次成功带来的分差，这正是"整段回报无差别"背后的机制级解释，也是塑形奖励为何能改变学习速度：它把"哪一步在进步"直接写进了每步的奖励里，信用不再依赖尾部事件向后传播。

2. 势能塑形与不变性定理

给定势能函数 Φ: S → ℝ，塑形奖励定义为：

r̃(s, a, s′) = r(s, a, s′) + η · [ γ Φ(s′) − Φ(s) ] η > 0 是塑形强度；Φ 可以是任意状态标量函数

把整条轨迹的塑形项按折扣求和，会发现它"望远镜式"抵消：

Σt γt[γΦ(st+1) − Φ(st)] = −Φ(s0) + γTΦ(sT) s0：回合起点；sT：回合终点；每回合总塑造量只与首尾状态有关

这条抵消不是近似，逐项展开就能看见：t=0 项是 γΦ(s1) − Φ(s0)，t=1 项是 γ²Φ(s2) − γΦ(s1)，t=2 项是 γ³Φ(s3) − γ²Φ(s2)。每一项的负半边恰好抵消上一项的正半边，首尾各剩一项，即上式。任何两个策略的排序都不因塑形而改变，最优策略集合不变（Ng, Harada & Russell, 1999）。Φ 的作用纯粹是把"整段回报"里的稀疏信息重排成"每步都有信号"。

不变性还有一条等价的证明，值得记住：设原问题在策略 π 下的价值为 Vπ(s)，可以验证塑形问题的价值恰好是 Ṽπ(s) = Vπ(s) − Φ(s)。推导只用一个恒等式：把塑形奖励沿轨迹求和，塑形部分等于 −Φ(s0) + γTΦ(sT)，当 Φ 有界且 γ<1 时尾项随回合推进趋近 0，于是每一步的期望回报都被"减去当前势能"这一个只依赖于状态、与动作无关的平移改写。动作排序在同一个状态内比较时，−Φ(s) 对每个动作一视同仁，argmax 不变；再把"状态分布里也含 Φ 平移"这件事逐层代入 Q 的递推，得到 Q̃π(s,a) = Qπ(s,a) − Φ(s)，同样只在两策略的价值之间加了与动作无关的平移。塑形改变的是价值曲线的形状，不改动它的峰谷结构。

这条推导顺带说明不变性依赖的两个前提：Φ 有界、γ<1，尾项 γTΦ(sT) 才会随回合推进自动消退。若把 γ 取到 1，尾项退化成 Φ(sT)，塑形总量等于"终点势能减去起点势能"；此时若智能体对"何时结束回合"有选择权，它会学会把回合结束在高势能处，不变性被打破。工程上沿用 γ<1 与有界 Φ，这两条都不需要额外实现成本。

把塑形项再拆一层，可以看清它同时携带两种信息：

γΦ(s′) − Φ(s) = −(1−γ)·Φ(s) + γ·[Φ(s′) − Φ(s)] 第一项是"当前位置的贴现租金"，只与 s 有关；第二项才是"本步前进量"

第一项是折扣造成的"停留成本"等价物：势能高（离目标近）的状态每步要缴 (1−γ)Φ(s) 的租金，势能低的状态则有补贴。第二项是真正的方向信号，正比于一步之内的势能增量，与速度成比例。这个分解说明：Φ 选好后，η 缩放的是两部分之和，哪里都不能"只缩放一半"；也解释了为什么单纯坐着不动也会拿到小额塑形奖励（租金项），而向目标移动能把租金项补回来并反超。

3. Φ 的工程选择

MountainCar 两个自然的势能：位置 Φ=position（越靠右越好，直接指向目标）；高度 Φ=sin(3·position)（山坡的势能，鼓励爬升，与"物理能量"同构）。位置势能对本任务通常更直接有效；高度势能更"物理"，在更复杂的控制任务里常被采用。强度 η 决定塑形的尺度：本节里位置范围约 1.8，单步势能差约 0.001～0.01 量级，乘 η=100 后与每步 −1 同量级，恰好让"向目标移动"成为有意义的选择。

把 MountainCar 的真实动力学代入分解式，各量级可以逐个核对（环境里 position += velocity，速度本身就是每步位移）。设速度 v=0.02（攀爬期的典型值），单步势能差 γΦ(s′) − Φ(s) = −0.01p + 0.99v：p=−1.2 时约 +0.032，p=−0.5 时约 +0.025，p=0 时约 +0.020，p=+0.5 时约 +0.015；静止（v=0）时只剩租金项 −0.01p，量级为 0.001～0.012。乘 η=100 之后，移动中每步的塑形奖励在 +1.5～+3.2 之间，静止在 ~0.5 到 −0.5 之间。η=100 把"动起来的半步位移"放大到与每步 −1 同量级，这是上段"量级匹配"的具体账目。

数值例子：同一起点的"驻足"与"登顶"各自拿到多少塑形量

取起点 s0 的位置 −0.5、速度 0。按望远镜求和，塑形折扣总量 = −Φ(s0) + γTΦ(sT)，与中途路线无关。

驻足 200 步：sT=s0，总量 = 0.5 − 0.99200×0.5 ≈ 0.5 − 0.067 = 0.433，乘 η=100 约 +43.3；原始回报 −200，塑形回报约 −156.7。

100 步登顶：sT 位置 0.5，总量 = 0.5 + 0.99100×0.5 ≈ 0.5 + 0.183 = 0.683，乘 η=100 约 +68.3；原始回报 −100，塑形回报约 −31.7。

解读：两段轨迹的原始回报相差 100 分，塑形后相差约 125 分，塑形把"登顶"的优势放大了约四分之一；更重要的是信噪结构，驻足时每步塑形奖励约 +0.5 且毫无区分度，移动时每步 +2 上下且方向正确，优势估计终于有东西可估。注意两个回合的塑形总量都不大（与原始回报同量级），这正是 η=100 选得合适的信号：太大时塑形总量会盖过 −1 的步成本，价值目标被整体抬高一个量级，拟合更吃力。

4. 塑形不解决探索，只解决信号

注意：位置塑形不会让策略"知道"要先向左倒车，它只知道"位置变大是好事"。正确的动量积累仍然要通过探索发现。所以塑形常与探索机制组合使用；第 021 章的参数空间噪声、以及练习 4 的计数探索，都是可以叠加的互补手段。另一类流行方案是世界模型/内在奖励（RND、ICM），用预测误差当"新鲜度"信号，不需要领域知识但计算更重。

三类"改变奖励"的手段各有边界，对照着选比较稳妥：

手段是否保持最优策略需要的先验每步额外开销典型失效模式
势能塑形（PBRS）保持（定理保证）一个方向正确的 Φ可忽略（一次标量计算）Φ 方向写错则主动躲目标；η 过大时价值尺度失衡
计数奖励 β/√N不保持状态离散化方案按格子编号的查找表高维连续状态几乎不给奖励；网格太粗时奖励变成"绕圈"
RND / ICM 内在奖励不保持无（自动学新鲜度）一次预测网络前向与反向随机环境里的"噪声陷阱"：不可约的随机被视为新鲜，探索被拖住

另一条边界值得单独记住：PBRS 的望远镜性质意味着"同一对首末状态之间，任何路径的塑形折扣总和相同"。所以"来回振荡攒塑形分"在目标函数层面不成立，若训练中真的观察到周期性抖动，根因多半在优势估计或价值尺度（η 太大导致拟合困难），排查方向不要放在 Φ 的方向上。

塑形奖励与原始奖励的分工

这一章的核心纪律是"两个口径各管一段"：训练目标用塑形奖励（让每步都有梯度信号），日志与评估用原始奖励/成功率（让数字可解释、可跨臂比较）。把两者混用会出现"塑形回报很好看但车没上去"的假象，练习与坑里都会反复强调。

关键代码与解读

片段 1：势能函数，一行公式，两种设计

# 势能函数：把“状态离目标多远”编码成一个标量
def potential(obs, kind: str) -> float:
    """Φ(s)：position 用位置；height 用 sin(3·position)（坡的高度）。"""
    if kind == "position":
        return float(obs[0])                  # 越靠右势能越高
    if kind == "height":
        return float(np.sin(3.0 * obs[0]))    # 与物理高度同构
    raise ValueError(f"未知的势能类型: {kind}")

解读：（1）Φ 只需要"一个状态标量"：本章用最朴素的两种设计展示"塑形只影响速度、不影响解"。位置势能直接编码"离目标多远"；高度势能编码"爬了多高"，后者在物理系统里更常用。（2）函数接收的是环境原始观测（ndarray），不是网络的归一化输入：塑形是任务层的事，与网络无关。（3）非法 kind 直接 raise ValueError：配置错误要立刻暴露，绝不静默返回 0，静默失败会让"没塑形"伪装成"塑形无效"。（4）如果要加第三种势能（练习 3），只需在这里加分支：这也是"Φ 可任意选择"定理的直接体现，接口只要保持"状态 → 标量"。

解读：（1）塑形只改写 rew_buf 里的数：r_used 进 GAE、进价值目标；其余管线（obs/act/logp/term）一字不动。这是"最小侵入"的改造方式。（2）prev_obs 的维护是塑形的账本：每步需要 Φ(s) 与 Φ(s′)，所以要记住上一步观测；回合 reset 时 prev_obs 同步换成新回合的首观测（见下一片段），否则跨回合会算出一个虚假的势能差。（3）注意 ep_ret += r 用的是原始奖励、success_flag 用的是 terminated：日志口径与评估口径一致，都与塑形无关。（4）success_flag 用 or 累积：本任务只有到坡顶才 terminated，一步成功即整个回合成功；200 步上限是 truncated，不计成功。（5）换种写法：把塑形写进环境的 step（包装器）也可以，但那样"原始奖励"就拿不到了，保留原始 r 的可见性，是评估纪律的代码基础。

片段 4：评估，回到原始环境

@torch.no_grad()
def evaluate(env, net, episodes: int, device):
    returns, success = [], []
    for _ in range(episodes):
        obs, _ = env.reset()
        done = False
        ep_ret = 0.0
        ok = False
        while not done:
            logits, _ = net(to_tensor(obs, device))
            action = int(torch.argmax(logits, dim=-1).item())
            obs, r, terminated, truncated, _ = env.step(action)
            ep_ret += r
            ok = ok or bool(terminated)      # 到坡顶即成功
            done = terminated or truncated
        returns.append(ep_ret)
        success.append(1.0 if ok else 0.0)
    return float(np.mean(returns)), float(np.mean(success))

解读：（1）评估函数不接收 eta、不调用 potential：它跑的是原始环境与原始奖励，这是本章最重要的工程纪律，塑形只存在于训练侧。（2）同时返回成功率与平均回报：成功率是主指标，回报用于交叉验证（比如成功率 0.9 时回报应在 −110 附近，约等于平均 110 步内到达）。（3）贪婪策略 + 默认 20 回合：MountainCar 单回合成功与否二元且方差大，5 个回合看不准，20 个回合把标准误压到可接受范围。（4）env 由调用方传入（每次 gym.make 新实例）：不复用训练环境，评估的随机状态与训练互不污染。

完整可运行脚本（附录）：code/ch020.py

python code/ch020.py             # baseline 与 shaping 各 20 万步，CPU 约 4–8 分钟
python code/ch020.py --quick     # 两臂各 2 万步，约 30–60 秒
python code/ch020.py --phi height   # 换高度势能
python code/ch020.py --eta 200      # 加强塑形

预期结论（以实跑为准）：baseline 在 20 万步内成功率通常停在 0.2～0.5，很难稳定（偶尔撞出成功轨迹又回落）；shaping 通常在 8 万～15 万步内把近 100 回合成功率推过 0.9，评估成功率 0.9 以上、评估回报约 −110。两臂的可比指标只有成功率：塑形臂的训练回报数值受 η 影响，绝不能与 baseline 的 −200 量级直接比。MountainCar 成功率方差大，评估回合数不足时结论会飘，默认 20 回合是有意的。

常见坑

  • 用塑形后的回报做跨臂比较：塑形回报的绝对数值由 η 和 Φ 决定，与原始回报没有可比性。统一用成功率或原始回报评估。
  • Φ 的方向设计错误：如果 Φ 鼓励远离目标（例如把位置取负），策略会主动"躲避成功"。先人工检查 Φ 在几个状态上的取值方向。
  • η 过大导致"刷分"行为：塑形项主导后，策略可能学会在势能梯度上振荡来攒奖励。观察原始回报（或成功率）是否同步改善，是识别这类行为的最好方法。
  • 把塑形当探索用：PBRS 不改变最优策略，如果探索本身不足（找不到上山轨迹），塑形也救不了"从未见过成功"的问题，那时要叠加计数奖励或参数噪声（第 021 章）。
  • 跨回合势能账本没重置：回合 reset 时忘了同步更新 prev_obs，下一步会用"上回合终点"与"新回合起点"做差，凭空产生一个大的势能奖励，污染优势估计。

练习与思考

  1. 把 --eta 设为 10 / 100 / 500，比较首达 90% 成功率的步数，解释为什么太小与太大都会变差。★
    提示
    η 太小时塑形信号淹没在 −1 里；η 太大时"刷势能"（来回移动保持势能差）可能比"上山"更划算，但 PBRS 定理保证最优策略不变，恶化的只是学习过程。
  2. 把 --phi 换成 height，对比两条学习曲线，说明两种势能的差异。★
    提示
    高度势能在"下坡"时给出负奖励，更符合能量守恒直觉；位置势能对"到达目标"更直接。多跑几个种子再下结论。
  3. 设计第三种势能：Φ = 位置 + 0.5·速度（或别的组合），验证它同样不改变最优策略、但可能学得更快或更慢。★★
    提示
    在 potential 里加一个分支即可。速度量纲与位置不同，先做缩放再组合；观察是否有加速。
  4. 实现计数探索奖励：把 (位置, 速度) 离散成 20×20 格子，奖励加 β/√N(cell)，与塑形叠加，比较成功率爬升速度。★★★
    提示
    在 collect_rollout 里维护格子计数字典，bonus 同样加进 r_used。注意这个 bonus 取非势能形式、会改变最优策略，属于"探索"类手段，评价仍要用成功率。

小结

  • 稀疏奖励的困难在于回报对过程中的进步不敏感，优势信号被常数淹没；MountainCar 是标准测试场。
  • 势能塑形 r̃ = r + η(γΦ(s′)−Φ(s)) 把稀疏回报重排成每步信号；Ng 等人的定理保证最优策略不变，Φ 只影响速度。
  • 实验结论：baseline 20 万步内很难稳定成功；位置塑形通常在 8～15 万步把成功率推过 90%，评估成功率 0.9+。
  • 评估纪律：训练可以用塑形奖励，评估必须回到原始环境与成功率。
  • 下一章处理探索本身：参数空间噪声，直接给策略权重加扰动并自适应调节幅度，对照动作空间采样的探索方式。
