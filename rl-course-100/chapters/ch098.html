第五篇 · 多智能体环境与实践

第 098 章：多智能体环境：电网调度

三个区域电网各自决策机组出力与储能充放，通过有限的联络线互济：用共享网络的离散 PPO 训练，考察"日均成本、缺电惩罚、可再生利用率"之间的取舍（实测：缺电几乎清零、成本与规则基线持平，利用率反而被牺牲）。

  • 主题：环境设计 / 经济调度与跨时段储能
  • 关键公式：cost = Σ(0.4g + 0.05g²) + 0.02·#充放 + 4.0·缺电电量
  • 预计学时：60 分钟
  • 前置章节：第 097 章

学习目标

  • 把经济调度形式化成多智能体 MDP：状态（负荷、可再生、储能）、动作（机组档位 × 储能模式）、成本函数。
  • 掌握"日负荷曲线 + 光伏型可再生 + 储能效率 + 联络线互济"的最小电力系统模型。
  • 用共享奖励的离散 PPO（参数共享 + 共享 GAE）训练 3 个区域，理解强共享奖励下的协作学习。
  • 构建规则调度基线：本区域贪心补缺口，它不做跨时段套利，也不跨区域协调。
  • 用"日均成本 / 未满足电量 / 可再生利用率 / 储能循环"四指标评价调度策略，解释它们之间的权衡。

背景与动机

电网调度是"工程 + 经济"双重约束的经典多智能体问题：每个区域每小时都要决定发多少电、电池充电还是放电，既要供上电（否则付出高额缺电惩罚），又要省钱（机组有成本曲线），还要尽量消纳波动性可再生。区域之间用联络线互济，你富余、我缺电，能互相拉一把，但这条线的容量有限。

把它写成能在几万步内训完的环境需要抓住三个建模要点：需求是时间的函数（早晚双峰）、可再生是天气的函数（中午高、云量抖）、储能是跨时段资产（今天的充电是明天的放电）。三者叠加后，"规则调度"（有缺口就开机、有富余就充电）不做跨时段套利、也不跨区域协调，看似留有改进空间；但实测里学习策略先学会的是"简单可靠"（机组恒出力、几乎不用电池），跨时段套利并没有被学出来。这提醒你：折扣因子与奖励定价只是必要条件，想优化什么，就必须把什么写进成本。本章与前两章的"空间协调"也由此区分：这里的耦合发生在时间轴与功率平衡上。

核心原理

1. 单区域功率平衡

区域 i 在第 t 小时的净功率：

neti = ri,t + gi,t + bi,t − di,t

其中 r 是可再生出力、g 是机组出力（0～3 档）、b 是储能（放电 +0.9、充电 −1.0，效率 90%）、d 是负荷。net < 0 表示缺电、net > 0 表示富余。注意充电的物理约束：只有本小时自身供大于求时才允许充电，不能靠联络线送来的电充电，也不能"赊账"。

2. 成本函数与缺电惩罚

cost = Σi (0.4·gi + 0.05·gi2) + 0.02·#充放 + 4.0·缺电电量

机组成本随出力超线性上升（二次项），所以"多开机组"并不划算；缺电惩罚 4.0/单位远高于任何机组成本（g=3 时单台机组成本 1.65），因此供电可靠性是第一优先级。储能充放有 0.02 的磨损费，抑制无意义的来回充放。

3. 联络线互济

区域内富余与缺口先各自汇总，再按联络线容量传输：

transfer = min( 全系统富余, 全系统缺口, line_capacity=1.5 )
unmet = max(0, 缺口 − transfer)，curtailed = max(0, 富余 − transfer)

这个"先内部结算、再总量调拨"的简化把空间结构压缩成一个容量约束，但保留了最关键的耦合：一个区域多发电可以救另一个区域的急。因此奖励取全系统总成本的负值，三个区域在数学上构成纯合作博弈，这也是全课程里"共享奖励"最自然的一次应用。

4. 跨时段套利为什么难学

储能的收益不在当下：低谷充电（付 0.02 磨损 + 承担充电时的功率平衡）换来高峰放电，价值延迟 7～10 步，而单步成本信号只回答"现在省了没有"。折扣因子 0.97 让十步之外的收益保留约 0.74 的权重，为学习这一模式提供了条件；但实测（种子 0）策略停在"不用电池"的简单解上（循环次数 0），跨时段套利没有被学出来。这是本章最值得追踪的行为：储能循环次数与日成本的联动。

5. 共享奖励下的 GAE

奖励是标量（全系统成本），价值函数是每区域一份：

δt,i = rt + γ·Vi(ot+1) − Vi(ot)

每个区域的观测不同（本地负荷/可再生/储能各异），所以价值估计不同、优势也不同，共享奖励不等于共享信息，信用仍然通过各自的局部价值函数体现。这是第 083 章 (T,N) 共享奖励 GAE 的又一次复用。

与前一章的差异

第 097 章是"需求侧争夺"的市场博弈（独立奖励），本章是"供电侧协同"的纯合作博弈（共享奖励）；前者的难点在偏好漂移与不完全信息，后者的难点在时间耦合，储能的收益延迟与可再生的波动共同要求"前瞻"。两章合起来覆盖了多智能体环境的两大奖励范式：独立奖励的竞争 vs 共享奖励的合作。

为什么充电必须"先有富余"

物理上电池只能吸收本区域已经发出、且没被负荷消耗掉的电。若把充电写成"无条件加电量"，模型会凭空获得能量：成本虚低、缺电量虚降，策略学到的跨时段权衡全是假的。环境里 supply − demand ≥ 1.0 的判定就是这道物理闸门，所有能量流动都必须可追溯到电源，这比任何奖励项都重要。

关键代码与解读

片段 1：需求与可再生的时间模型

def _demand(self, t: float) -> np.ndarray:
    """日负荷曲线：早晚双峰 + 区域差异 + 噪声。"""
    base = np.array([1.5, 1.7, 1.4], dtype=np.float32)   # 三个区域的基础负荷
    amp = np.array([0.8, 0.9, 0.7], dtype=np.float32)    # 各自的峰谷幅度
    shape = 0.5 * (1.0 - np.cos(2.0 * np.pi * (t / 24.0)))   # 0→1→0 的日内包络
    d = base + amp * shape * (1.0 + 0.6 * np.sin(2.0 * np.pi * (t - 6.0) / 24.0))
    return (d + self.rng.uniform(-0.1, 0.1, size=3)).astype(np.float32)

def _renewable(self) -> np.ndarray:
    """可再生出力：中午高、夜间低，叠加云量噪声。"""
    t = float(self.steps)
    solar = np.maximum(0.0, np.sin(np.pi * (t % 24.0 - 6.0) / 12.0))  # 6~18 点的日照窗
    base = np.array([1.8, 1.4, 2.0], dtype=np.float32) * solar        # 三区装机不同
    noise = self.rng.uniform(0.0, 0.6, size=3).astype(np.float32)
    return (base + noise * solar).astype(np.float32)   # 云量噪声按日照强度缩放

解读：供给与需求两个时间序列定义了整场调度的节奏。（1）需求曲线用"余弦包络 × 修正项"：shape 从 0（午夜）爬到 1（正午）再回落，乘一个 6 点相位的正弦修正后形成早晚双峰的日常节奏；base/amp 按区域微调，让三个区域不完全同步（这是互济有意义的前提）。（2）噪声 ±0.1 让每天不同，评估必须多天取均值。（3）光伏模型 sin(π(t−6)/12) 截断在 6～18 点：日出到日落的正弦；np.maximum(0, ...) 保证夜间为零。（4）云量噪声 U(0,0.6)·solar 乘了日照强度，夜里没有云也没有电，噪声不该在夜间"凭空发电"，这是物理一致性最简单的一条检查。

片段 2：8 维观测，每区一台"仪表盘"

def _obs(self) -> np.ndarray:
    demand = self.demand
    renew = self.renewable
    t = float(self.steps)
    obs = []
    for i in range(self.n_agents):
        others = [float(demand[j]) for j in range(3) if j != i]
        o = np.concatenate([
            [demand[i] / 3.0, renew[i] / 3.0, self.battery[i] / self.battery_cap],
            [np.sin(2 * np.pi * t / 24.0), np.cos(2 * np.pi * t / 24.0)],  # 时间编码
            np.asarray(others) / 3.0,          # 另两区的负荷：互济的线索
            [self.last_g[i] / 3.0],            # 自己上步机组出力
        ])
        obs.append(o.astype(np.float32))
    return np.stack(obs)

解读：观测把"调度员面前的仪表盘"精确翻译成 8 个数字。（1）本区三件套：负荷、可再生、储能余量（除以容量 3 归一化），这是决策的直接输入。（2）时间用 sin/cos 双编码：相位角的连续表示让策略能区分"23 点"与"0 点"的相邻关系（直接给单值 t/24 时，0.96 与 0.0 会被网络当成远亲）。这是周期性任务编码时间的主流做法。（3）另外两区的负荷进观测：本区缺电时能否指望邻居，取决于邻居是否也在高峰，互济的判断依据必须可见。（4）自己上步机组出力：让策略感知"我的机组刚开了多大"，避免阶跃式调整造成成本抖动。注意没有把邻区储能放进来：跨区 SOS 的信息粒度不必那么细，这也是控制观测维度的取舍。维度账：3+2+2+1 = 8。

片段 3：逐区结算，储能与净功率

for i in range(3):
    gen_cost += 0.4 * g[i] + 0.05 * g[i] ** 2      # 机组成本的二次曲线
    supply = float(self.renewable[i]) + float(g[i])
    if batt_mode[i] == 0 and self.battery[i] >= 1.0:      # 放电：需要至少 1.0 存量
        self.battery[i] -= 1.0
        supply += self.battery_eff                          # 放出 0.9（效率 90%）
        wear_cost += self.wear
        self.battery_cycles += 1
    elif batt_mode[i] == 2 and self.battery[i] <= self.battery_cap - 0.9:
        # 充电：需要 1.0 的富余电量，实际存 0.9
        if supply - float(self.demand[i]) >= 1.0:
            supply -= 1.0
            self.battery[i] += self.battery_eff
            wear_cost += self.wear
            self.battery_cycles += 1
    net[i] = supply - float(self.demand[i])         # 本区净功率：正=富余，负=缺额

解读：这段是电力系统的"每一度电都要对上账"。（1）机组成本二次项 0.4g+0.05g²：g=1 时 0.45、g=3 时 1.65，边际成本随出力上升，"需要 2 就开 2，别开 3"是成本最优，这条曲线就是"经济调度"里的经济二字。（2）放电条件 battery ≥ 1.0：电池以"单位电量"为粒度管理，存量不足 1.0 就不能放；充电条件 ≤ cap−0.9：留出装下 0.9 的空间。（3）充放 不是对称的：放电放出 0.9、充电消耗 1.0 存 0.9，效率损失 10% 体现在两条路径上（充的时候吃 1.0 吐 0.9，放的时候扣 1.0 吐 0.9），这种写法让功率平衡守恒到每一步。（4）充电的物理闸门 supply − demand ≥ 1.0：必须本小时先有 1.0 的富余才能充，电池不能透支未来、也不能吸联络线的电。被拒绝的充电动作"静默失效"（不扣磨损），策略得从观测里学会预判。

片段 4：互济结算与共享奖励

# 区域互济：富余区支援缺额区（容量受限的"总调拨"简化）
surplus = float(np.sum(np.maximum(net, 0.0)))     # 全系统富余
deficit = float(np.sum(np.maximum(-net, 0.0)))    # 全系统缺口
transfer = min(surplus, deficit, self.line_capacity)
unmet = max(0.0, deficit - transfer)              # 传不过去的缺口：缺电惩罚
curtailed = max(0.0, surplus - transfer)          # 送不出去的富余：弃风弃光

self.tot_gen += float(g.sum())
self.tot_unmet += unmet
self.tot_curtail += curtailed
self.steps += 1
self.last_g = g.copy()

# 共享奖励：全系统总成本的负值，三个区域是纯合作博弈
cost = gen_cost + wear_cost + 4.0 * unmet
reward = -cost
truncated = self.steps >= self.max_steps

解读：四行公式定义了"互联电网"的价值与局限。（1）min(surplus, deficit, line_capacity) 三重取小：调拨量受限于富余、缺口与线路容量，任何一方成为瓶颈都会造成浪费或缺口。（2）缺口减不掉的记 unmet（×4.0 惩罚）、富余送不出的记 curtailed（弃风弃光，无直接罚款但体现在利用率指标里）：两类"没用好"分开统计，让问题可诊断。（3）奖励是全系统标量的负成本，复制给三个区域：这是全书共享奖励链条的又一次出现（083/087/095→098），协作动机完全内生。提醒：奖励是对称的、但观测不对称，各区域的价值函数会学到"我这一份责任"。（4）成本三项的量级决定行为优先级：缺电 4.0 ≫ 机组满开 1.65 ≫ 磨损 0.02，策略先保证不缺电、再省钱、最后省电池寿命，这个排序直接写在一串系数里。

常见坑

  • reset 时没有初始化 demand/renewable：观测要读当前小时的需求与可再生；若它们只在 step 里生成，reset 后第一次观测直接 AttributeError。本实现让 reset 显式调用一次生成函数。
  • 把充电写成"无条件加电量"：不给充电加"先有富余"的约束，模型会凭空获得能量，成本虚低、策略学不到跨时段权衡。功率平衡必须守恒到每一步。
  • 可再生利用率算法越界：浪费的富余里既有弃风弃光也有机组过发，直接用 curtail/renew 会算出负利用率；本实现把浪费量截断到可再生总量内，指标才落在 [0,1]。
  • 用单日成本比较不同随机种子：每天的需求/可再生噪声不同，单日成本波动可达 ±15%。评估必须多天取均值，且学习策略与基线用完全相同的种子序列。
  • 把 γ 设回 0.95：储能收益延迟 7～10 步，0.95 时十步外只剩 0.6 的权重、且策略更短视，"囤电"行为会明显变弱。本章 γ=0.97 是为跨时段任务专门选的。

    提示
    容量越大缺电越少、成本越低，但边际收益递减，拐点之后继续扩容几乎不省钱，这解释了实际电网里"新建一条线值不值"的评估逻辑。
  2. 把储能磨损费从 0.02 提到 0.1，先预测储能循环次数的变化方向，再观察成本的联合变化。★
    提示
    磨损费是"使用电池的价格"。观察模型是否把循环次数压到精细化后的水平；如果直接归零，说明训练退化成"机组直供"。
  3. 把可再生噪声幅度从 0.6 加到 1.2，先论证"谁的劣势更大"（规则还是学习），再实测两者差距的变化。★★
    提示
    波动越大，规则调度越难应对、学习策略的潜在优势越大；但训练也更难，可能需要把预算加到 10 万步。
  4. 把储能效率从 0.9 降到 0.7，先推导最优调度哲学的变化，再观察循环次数与成本。★★
    提示
    效率越低、往返损失越大，最优策略应"只做高价值套利"；循环次数随效率下降而减少是可检验的预测。
  5. 把 3 区"总调拨"改成 6 区只有两条联络线的拓扑，先分析哪些区会失去互济、协作难度如何变，再实现一个简单的逐边迭代结算。★★★
    提示
    把"全系统统一调拨"替换成按边传输的迭代结算。拓扑连通性越差，各区越接近独立，学习收益主要来自储能管理，互济贡献有限，正好用来验证"耦合强度决定协作价值"。

小结

  • 电网经济调度 = 逐小时功率平衡 + 成本最小化：机组成本递增、缺电惩罚极高、储能是跨时段资产。
  • 联络线互济让区域间形成纯合作博弈，共享奖励 + 逐区域价值函数是自然的学习配置。
  • 可再生的波动与储能的延迟收益让"前瞻"成为学习策略超越规则基线的关键能力，但实测种子 0 下学习器尚未用起储能，超越只体现在未满足电量上（≈0 对 5.09）；充电必须先有富余是物理底线。
  • 四指标里"未满足电量"是硬约束、"成本"是效率、"可再生利用率"是外部性的代理，三者要一起报告。
