第二篇 · 离策略方法与 SAC

第 047 章：SAC的批量归一化层

把 SAC 网络的隐藏层从裸 MLP 换成 BatchNorm 或 LayerNorm，对照 Pendulum-v1 上的评估回报与梯度范数变异，并用"训练/评估输出差"指标，亲眼看到 BatchNorm 的滑动统计在非独立同分布数据上如何与策略脱节。

  • 主题：网络结构 / 归一化层与 RL 数据的兼容性
  • 关键公式：BN: ĥj=(hj−μbatch)/√(σ2batch+ε)；LN: 每条样本自归一化
  • 预计学时：50 分钟
  • 前置章节：第 046 章

学习目标

  • 理解归一化层在神经网络中的作用：稳定每层输入分布、缓解梯度尺度问题。
  • 区分 BatchNorm1d 与 LayerNorm 在 RL 场景下的关键差异：前者依赖 batch 统计与滑动统计，后者只依赖单样本。
  • 实现可切换的 none / layer / batch 三种网络结构，保持算法其余部分完全一致。
  • 用"训练模式与评估模式的策略输出差"这个诊断量，量化 BatchNorm 在非独立同分布（non-i.i.d.）回放数据上的行为偏移。
  • 会给出结论：要处理观测尺度问题，优先在环境接口层做归一化，不要在往网络里塞 BatchNorm 的方向上花力气。

背景与动机

深度网络的传统经验是"加归一化能加速训练"，但 RL 不是监督学习：回放池样本来自不同时期的策略，batch 内部相关性强、分布持续漂移。BatchNorm 的 batch 统计与滑动统计在这种数据上会打架，训练与评估对"正常输入"的定义可能完全不同，于是出现"训练时像一个策略、部署时是另一个策略"的隐性偏移。

本章做一次受控结构实验：算法、超参数、种子全部不变，只换隐藏层的归一化方式，并加一把专门量这种偏移的尺子，训练/评估输出差。看完你会理解为什么社区在 RL 里更偏好 LayerNorm，甚至宁可直接归一化观测。需要提前说明的是，LayerNorm 也不是万灵药：它对单样本做统计，不依赖 batch，但在窄层上会压缩特征动态范围；把它与 none 并列对照、不预设"默认更好"，才是正确的实验姿态。

核心原理

1. 两种归一化的定义

设某层输出向量为 h ∈ ℝd，一个 batch 有 B 条样本。BatchNorm 对每个维度 j 用整个 batch 的统计量归一化；LayerNorm 对每条样本的所有维度做归一化：

BatchNorm:   ĥi,j = (hi,j − μj) / √(σj2 + ε)，μj、σj 来自 batch
LayerNorm:   ĥi = (hi − μi) / √(σi2 + ε)，μi、σi 来自样本 i 自身 两者都会附加可学习的仿射参数 γ、β（PyTorch 默认开启）

符号说明：hi,j 是第 i 条样本第 j 维的取值，μ、σ 是归一化用的均值与标准差，ε≈1e-5 防止除零；γ、β 让网络可以学回任意尺度与偏移。关键差别在统计量的来源，BatchNorm 训练模式用 batch 统计并更新滑动平均（momentum 默认 0.1），eval() 模式改用滑动统计；LayerNorm 没有这两种模式的差别。这决定了它们在 RL 里的命运。

1.1 数值算例：batch 统计的抽样噪声与滑动窗口

BatchNorm 的麻烦不止于"漂移"，batch 统计本身还带抽样噪声。设某维的真实标准差约 1，batch 大小 B=256 时，batch 均值的标准误差约 1/√256=0.0625；B=64 时升到 0.125。这意味着训练模式下归一化结果逐维带着约 0.06～0.13 的随机抖动，抖动还会经反传进入梯度。评估模式用全历史的滑动统计，单批抖动被平均掉，于是"训练时的输入口径"与"评估时的输入口径"天然相差一个噪声量级，这正是输出差为正的第二个来源。把批量从小调大时，这批噪声按 1/√B 收缩，BatchNorm 的缺点会随之"隐身"，这也是本章刻意用 256 而不用更大批量的原因。

滑动统计的跟随速度同样可以量化。PyTorch 的 momentum 默认 0.1，滑动值每步按 (1−m) 保留旧值、m 吸收新 batch，记忆窗口约 1/m=10 个 batch，半衰期 ln2/(−ln 0.9)≈6.6 个 batch。相对 1.6 万步预算，这个窗口相当短，跟踪速度不是瓶颈；把 momentum 调到 0.001，半衰期变成约 693 个 batch，统计量明显迟钝，输出差的预测见练习第 2 题。两个极端都不好：窗口长则跟不上分布漂移，窗口短则统计抖动大，BatchNorm 的两难在数值上有清晰的下界。

2. 为什么 RL 数据让 BatchNorm 难受

梯度下降假设 batch 是独立同分布采样。SAC 的 mini-batch 虽然从回放池随机抽，但池子本身只覆盖历史访问过的状态；训练早期数据集中在摆角正下方附近，后期集中在直立附近，数据分布随训练持续漂移。BatchNorm 的滑动平均有"时滞"，评估时的归一化参数与当前数据统计差一个档位，策略输出随之偏掉。这个偏差可以用一个简单指标直接测量：

输出差 = mean | tanh(μtrain(s)) − tanh(μeval(s)) | 对同一批固定探针状态前向两次：一次 train 模式、一次 eval 模式

对无归一化（none）和 LayerNorm，两种模式的结果逐位相同，输出差恒为 0（都是确定性逐样本运算）；对 BatchNorm，只要滑动统计与探针数据的统计不一致，输出差就为正。它是"结构性代价"的直接读数，与回报高低无关。

数值例子：同一批数据在两种模式下的归一化结果

设某隐藏层某一维的输出为 h = [2, 4, 6, 8]。训练模式下用 batch 统计：μ=5，σ2 = (9+1+1+9)/4 = 5，σ ≈ 2.236，归一化结果 ĥ ≈ [−1.342, −0.447, 0.447, 1.342]（γ=1、β=0 时输出不变）。

评估模式改用历史滑动统计，设当前滑动值为 μ̄=4.0、σ̄=1.5，同一条数据被归一化成 [−1.333, 0.0, 1.333, 2.667]。

逐条对比：第 1 条 −1.342 对 −1.333（接近），第 3 条 0.447 对 1.333（差出近 1 个单位）。解读：滑动统计与当前数据统计的偏移会被归一化层"放大"成特征差异，再经过后续层与 tanh 传到动作上，这就是输出差 0.05 量级的来源。若 batch 只有 1 条样本，训练模式下 σ=0，归一化公式直接失效，这是 BatchNorm 在 RL 里对 batch 组成的另一重依赖。

2.1 三种结构的对照预期

维度nonelayerbatch
统计量来源无每条样本自身整个 batch（训练）/ 滑动统计（评估）
训练/评估一致性完全一致完全一致依赖滑动统计，可能不一致
输出差（探针）恒为 0恒为 0可达 0.05 量级
对 batch 组成的依赖无无强：batch 大小与内容都影响输出
梯度范数变异基准与基准接近通常更大
典型评估表现稳定与 none 接近，个别任务略慢后期波动更大，回报常落后

对照的判据是"一致性优先"：先看输出差是否恒为 0（结构是否与 batch 解耦），再看梯度范数变异，最后才比较回报。即便某个种子下 batch 的回报追平了 none，前两项结构性代价依然存在，这也是本章结论优先推荐 none/layer 的原因。

2.2 LayerNorm 的代价：范数恒定的两面性

LayerNorm 消除 batch 依赖的同时引入了一条硬约束：归一化后每条样本的向量范数恒为 √d（d=256 时约 16），输入有多"强"这一信息只能靠逐维仿射参数 γ 的缩放保留。对特征方向（哪些维度活跃）的编码不受影响，对特征幅度的编码被整体压缩了。窄层上这个代价更容易显形：两层 256→256 的网络里，样本间本可以靠激活幅度区分"置信"与"犹豫"，归一化后所有样本被拉到同一范数，区分度只能由后续层重新学出来，个别任务因此收敛更慢。这与 1.1 小节的抽样噪声是两个不同性质的代价：BatchNorm 的问题是与数据分布和 batch 组成耦合，LayerNorm 的问题是无条件的信息压缩，前者可能随配置起伏，后者在任何数据上都存在。

与观测归一化对照，还能看清统计量窗口的差别：第 039 章的做法把统计量挂在数据管道上，权重是全历史均等的（随样本数累积），训练与评估显式共享同一个对象；LayerNorm 的统计窗口是"当前样本本身"，没有任何跨样本状态，所以既无法跟踪分布也无法记忆分布。三者摆放的是一根连续的谱：全历史统计（观测归一化）、近期窗口统计（BatchNorm 滑动值）、无跨样本统计（LayerNorm）。选哪种，取决于你希望统计量对"分布变化"做出多快的反应，以及你能否接受评估行为随之改变。

3. 处理观测尺度的正确姿势

如果目的是"让网络少受观测尺度影响"，标准做法是在环境接口层做观测归一化（第 039 章）：维护固定的运行统计量，训练与评估用同一套参数。前者不改变网络的数学结构，评估行为可复现；后者把训练动力学与数据分布耦合在一起。两者的差别还可以从"统计量的所有者"理解：观测归一化的统计量属于数据管道，训练与评估显式共享同一个对象；BatchNorm 的滑动统计属于网络内部状态，随模式切换而换源，行为不由调用方完全掌控。当出现问题时，前者只需检查一个对象，后者的排查面覆盖整张网络。

实现思路与设计

数据流

与第 046 章相同的训练闭环，只在两处不同：构造网络时由 norm 参数决定隐藏层堆叠；每次更新开头显式 .train()、每次评估开头显式 .eval()，并在梯度反传后记录裁剪前的梯度总范数。评估点同时计算三项诊断：梯度范数变异、Q 损失变异、训练/评估输出差。三种配置同种子、同步数、同批量（256）。

模块划分

组件职责关键点
make_hidden(in, hidden, out, norm)按配置生成隐藏层堆叠结构统一为 Linear → [Norm] → ReLU，Norm 在激活之前
QNet / GaussianPolicy接受 norm 参数，其余不变策略的均值头与 log_std 头接在归一化躯干之后

梯度范数统计记录裁剪前 Q 网络梯度总范数用变异系数横向比较三种结构

关键超参数

参数默认值作用与取值理由
--normsnone,layer,batch三组对照依次训练，唯一变量是归一化方式
--max-steps16000每组预算；三组共约 4.8 万步
--batch-size256刻意用中小批量：BN 的统计噪声更明显
--eval-every2000每个评估点同时算输出差，形成完整曲线
--tau / --lr0.005 / 3e-4回到默认值，避免与结构变量混淆

批量刻意保持 256（中等偏小），原因与诊断的灵敏度有关：BatchNorm 的 batch 统计噪声随批量缩小而增大，滑动统计与 batch 统计的差距更容易显形，输出差与梯度范数变异这两个指标的量级都更可观；若把批量开到 4096，统计噪声被平均掉，BN 的缺点会"藏起来"，实验的对照强度反而下降。这也是复现文献结论时的常见陷阱：小批量下观察到的现象，换到大批量配置未必复现，报告结论时必须带上批量这一条件。

与前一章的差异点

  • 第 046 章改目标网络的跟随速度 τ；本章改网络内部结构，τ 固定回 0.005。
  • 新增 make_hidden() 结构与 norm 配置参数，Q 网络与策略网络同步换层。
  • 新增训练/评估模式切换与"输出差"诊断，这是纯结构改动才需要的测量。
  • update() 额外返回梯度范数，用于对比三种结构的梯度稳定性。

关键代码与解读

片段 1：一行配置切换网络结构

def make_hidden(in_dim: int, hidden: int, out_dim: int, norm: str) -> nn.Sequential:
    """构造 'Linear -> [Norm] -> ReLU' 的隐藏层堆叠，尾部接输出层。"""
    layers = []
    last = in_dim
    for _ in range(2):                       # 两层隐藏层，宽度一致便于对照
        layers.append(nn.Linear(last, hidden))
        if norm == "batch":
            layers.append(nn.BatchNorm1d(hidden))    # 依赖 batch 统计
        elif norm == "layer":
            layers.append(nn.LayerNorm(hidden))      # 只依赖样本自身
        layers.append(nn.ReLU())             # 激活放在归一化之后
        last = hidden
    layers.append(nn.Linear(last, out_dim))
    return nn.Sequential(*layers)


class QNet(nn.Module):
    """Q(s,a) 网络，隐藏层归一化方式由 norm 参数决定。"""

    def __init__(self, obs_dim: int, act_dim: int, hidden: int = 256,
                 norm: str = "none"):
        super().__init__()
        self.net = make_hidden(obs_dim + act_dim, hidden, 1, norm)

    def forward(self, obs: torch.Tensor, act: torch.Tensor) -> torch.Tensor:
        return self.net(torch.cat([obs, act], dim=-1)).squeeze(-1)

解读：（1）make_hidden 是"配置即结构"的典范：三种网络共享同一段构造逻辑，norm 决定插入哪种层，这样对照实验里除归一化方式之外没有第二个变量。（2）顺序是 Linear → Norm → ReLU：归一化作用于线性层的原始输出，统计量更规整；ReLU 放在后面，避免大量零输出把均值方差算歪。这是社区常用写法，你会在练习里把它颠倒过来看代价。（3）Q 网络把 (s,a) 拼接后进入同一个堆叠，策略网络只处理观测，两者的归一化必须同步加，只加一边会让价值回归与策略提升的特征分布不一致。

片段 2：训练/评估输出差，结构代价的直读器

    @torch.no_grad()
    def train_eval_output_gap(self, probe: dict) -> float:
        """训练模式与评估模式下策略均值动作的差：BatchNorm 会露出马脚。"""
        obs = probe["obs"]
        self.policy.train()
        mean_train, _ = self.policy.forward(obs)
        a_train = torch.tanh(mean_train)
        self.policy.eval()
        mean_eval, _ = self.policy.forward(obs)
        a_eval = torch.tanh(mean_eval)
        return float((a_train - a_eval).abs().mean().item())

解读：（1）探针批次来自回放池的前 256 条（ReplayBuffer.probe），内容固定，前后两次前向的唯一差别就是 train()/eval() 模式。（2）比较对象选 tanh 后的均值动作，logp 不作为比较对象：动作空间有界，输出差的量级直观（0.05 意味着平均动作偏了满量程的 2.5%）。（3）对 none/layer 两次前向逐位相同，差恒为 0；对 batch，train 用探针 batch 自己的统计、eval 用历史滑动统计，二者只要漂离，差就为正。（4）整段 no_grad 且用后随即切回，注意它把策略留在 eval() 状态，所以训练循环里的 update() 必须在开头再显式 .train()。

片段 3：模式切换与梯度范数记录

    def update(self, batch: dict, args) -> dict:
        obs, act = batch["obs"], batch["act"]
        rew, next_obs, done = batch["rew"], batch["next_obs"], batch["done"]
        # 训练时确保网络处于 train 模式（BatchNorm 使用 batch 统计）
        self.policy.train()
        self.q1.train()
        self.q2.train()

        with torch.no_grad():
            next_act, next_logp = self.policy.sample(next_obs)
            q_next = torch.minimum(self.q1_target(next_obs, next_act),
                                   self.q2_target(next_obs, next_act))
            backup = rew + args.gamma * (1.0 - done) * (q_next - self.alpha.detach() * next_logp)

        q1 = self.q1(obs, act)
        q2 = self.q2(obs, act)
        q_loss = F.mse_loss(q1, backup) + F.mse_loss(q2, backup)
        self.opt_q.zero_grad()
        q_loss.backward()
        # 记录裁剪前的梯度范数（不做裁剪，仅诊断）
        grad_norm = float(torch.sqrt(sum(
            float((p.grad ** 2).sum()) for p in self.q1.parameters() if p.grad is not None
        ) + sum(
            float((p.grad ** 2).sum()) for p in self.q2.parameters() if p.grad is not None
        )))
        self.opt_q.step()

解读：（1）开头三行 .train() 是正确性关键：评估函数会把网络切到 eval，如果这里不切回来，BatchNorm 会一直用滑动统计训练，统计量冻结，网络退化成"带噪声的固定归一化"，曲线会莫名变平。（2）梯度范数在 backward() 之后、step() 之前统计：把 q1、q2 全部参数的 p.grad 平方和累加再开根。（3）外层 float(...) 会断开与计算图的联系，纯记数值、不干扰反传。（4）注意只统计 Q 网络梯度：本章关心自举回归的稳定性，这是结构差异最容易显形的地方；跨配置比较用变异系数（std/mean），直接比较绝对值的可比性差。

常见坑

  • 评估时不切 eval 模式：BatchNorm 会用评估 batch 的统计做归一化，动作输出甚至评估回报随 batch 内容变化。评估协议必须固定探针数据、固定模式。
  • 训练时不切回 train 模式：一次评估后再训练忘了恢复，BN 的滑动统计冻结，训练动力学与设计不符，曲线会莫名其妙地变平。
  • 只在 Q 网络加 BN、策略网络不加：策略与 Q 对同一状态的特征分布不一致，价值回归与策略提升不同步，训练震荡加剧。要加就对称地加。
  • 把 LayerNorm 当成"没有代价的 BatchNorm"：LayerNorm 在宽度较窄的层（256→256）会压缩特征动态范围，个别任务上收敛更慢。对照实验里它和 none 接近，谈不上稳赢。
  • batch=1（或评估单样本）时直接前向 BN：BatchNorm1d 在训练模式下遇到 batch 大小为 1 会报错或产生无意义统计（方差为 0）。评估永远走 eval 模式，逐样本诊断也要避开 train 模式的单样本前向。

练习与思考

  1. 把 --batch-size 改成 64 再跑三种配置。预测 BatchNorm 的输出差变大还是变小，然后验证。★
    提示
    小 batch 的统计量噪声更大、滑动平均与 batch 统计的差距更明显。对比 64 与 256 下 batch 配置的梯度变异和输出差两项指标。
  2. 把 BatchNorm 的 momentum 从默认 0.1 改成 0.001（在 make_hidden 里传参）。滑动统计更新变慢后，输出差与评估回报怎么变？★★
    提示
    momentum 越小滑动统计越"迟钝"，跟踪分布漂移的速度越慢，预计输出差反而更大。这个实验正好说明 BN 的两难：快则统计噪声大，慢则跟不上分布。
  3. 给 none 配置加一层观测归一化（对观测减均值除标准差，统计量随训练缓慢更新），与 batch 对比输出差与评估回报。谁更接近"在线数据"？★★
    提示
    在 train_norm 里维护 obs_mean/obs_var 滑动统计，agent.act 与 update 前先归一化 obs（评估与探针用同一套统计）。这是第 039 章的做法。
  4. 把 BatchNorm 放到激活之后（Linear → ReLU → BatchNorm），重复实验。输出差与回报有什么变化？★★
    提示
    改一下 make_hidden 里 append 的顺序即可。ReLU 后的特征含大量零，统计量偏置更明显，输出差可能更大，这就是社区普遍用"先归一化后激活"的原因之一。
  5. 在 MountainCarContinuous-v0 上重复三组对照（观测尺度差异大：位置 ±1.2、速度 ±0.07）。先预测哪个配置最可能受益，再跑实验验证。★★★
    提示
    --env MountainCarContinuous-v0 --max-steps 30000。尺度差异越大，归一化的理论收益越明显；但别忘了 BN 的分布漂移问题同样存在，用输出差与评估回报两条曲线一起判断。

小结

  • BatchNorm 与 LayerNorm 的关键差别在统计量来源：batch 内 vs 样本内；后者与 batch 组成无关，训练/评估行为一致，前者则依赖滑动统计的跟踪质量。
  • SAC 的回放数据来自不断漂移的策略分布，BN 的滑动统计会与当前数据脱节，表现为"训练/评估输出差"持续为正且随训练增大。
  • 实验上 none 与 layer 的输出差恒为 0；batch 的输出差可达 0.05 量级，且后期评估波动更大，两个信号互为佐证。
  • 想让网络对观测尺度更鲁棒，优先在环境接口做观测归一化（第 039 章）；在网络里塞 BatchNorm 的方案排查难度高出一个量级。
  • 数值对照：h=[2,4,6,8] 在 batch 统计（μ=5、σ≈2.24）与滑动统计（μ̄=4、σ̄=1.5）下归一化结果逐条偏移，第三条第 3 项从 0.447 变成 1.333，偏移经后续层放大后就是输出差的来源。
  • 三种结构的判据顺序：先一致性（输出差是否为 0），再梯度稳定性（范数变异），最后才是回报，避免被单种子成绩误导。
  • 下一章换一个"稳定器"：梯度裁剪，当梯度范数偶尔爆炸时，裁剪能救回一次更新；但阈值怎么选、会不会伤到正常梯度，都要用实验数据说话。
