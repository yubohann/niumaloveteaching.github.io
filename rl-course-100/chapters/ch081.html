第 081 章：多智能体SAC：信用分配

团队奖励的大锅饭问题，在 SAC 里换个吃法：用集中式联合双 Q 做评审团，演员按"逐动作的反事实优势"更新，这次把功劳准确记到每个智能体头上。

  • 主题：信用分配 / SAC 版反事实基线
  • 关键公式：Lactor = −Σaπi(a)·Âi(a) − α·H(πi)，Â 带 detach
  • 预计学时：60 分钟
  • 前置章节：第 080 章

学习目标

  • 把第 073 章（PPO 版）的信用分配思想迁移到 SAC：反事实基线与共享基线两种优势。
  • 看懂集中式联合双 Q（SARSA 目标 + 目标网络）如何为"假设动作"提供查询能力。
  • 掌握 SAC 的分类分布演员目标：最大化 Σaπ(a)·Â(a) 加熵正则，并解释与普通 SAC 演员目标的联系。
  • 用"智能体间优势标准差"诊断信用信号是否真的被分摊到个人。
  • 理解 off-policy 带来的实验便利：两种信用方案共用同一个评审团与同一批数据，比较是受控的。

背景与动机

第 073 章在 PPO 上做过信用分配的对照：反事实基线（只替换自己的动作）比共享基线（全队一个数字）更能区分"谁的贡献"。SAC 的处境相同，但演员更新机制不同：PPO 用比率裁剪目标乘优势，SAC 用"软 Q 减熵"的策略梯度。要引入信用分配，舞台从"损失函数乘什么优势"变成"演员最大化什么量"，本章把第 073 章的优势定义搬进 SAC 的演员目标里，在离散动作（方便枚举反事实）的合作导航任务上做对照。

选离散动作还有一个现实理由：反事实基线要求"查询替换一个动作后的 Q"，连续动作无法穷举，只能近似采样。离散化让实验归因干净：两种信用方案共用同一个联合双 Q、同一批回放数据、同一个温度机制，唯一的变量是演员收到的信用信号。这就是控制变量实验该有的样子，也是本篇收尾阶段最有含金量的一课。

核心原理

1. 集中式联合双 Q 与 SARSA 目标

Qk(s, a1:N)，  y = rteam + γ(1−d)·mink Qktgt(s′, a′1:N) a′ 是数据里真实发生的下一联合动作（SARSA）；双 Q 取最小抑制过估计；s 是全局状态

网络输入是全局状态与联合动作 one-hot（19+15 维），输出两个 Q 头，目标网络软更新，这些与第 073 章一致，只是多了第二个 Q 头。注意这里没有"软 Bellman 的熵项"：团队价值用普通 SARSA 目标训练，熵只作用在演员与温度上，保持实现简单、优势信号干净。

2. 两种信用信号

对智能体 i，先枚举它替换成每个动作 a 后的反事实 Q：

qcfi(a) = mink Qk(s, (a, a−i))，  a = 0…|A|−1 a−i 是队友的真实动作（固定）；每个智能体有 |A| 个反事实 Q

然后减去各自的基线，得到逐动作优势 Âi(a)：

COMA：Âi(a) = qcfi(a) − Σa′ πi(a′)·qcfi(a′)
shared：Âi(a) = qcfi(a) − b(s)，  b(s) = meank≤K Q(s, arandk) COMA 各人有各人的基线（对智能体 i 自己的策略求期望）；shared 的 b(s) 对全队是同一个数（随机联合动作的 Q 均值，K=16）

两者的区别只有基线：COMA 的基线把"我的平均表现"扣掉，优势告诉你"这个动作比我自己平时好多少"；shared 的基线是全队平均水位，扣掉后剩下"这一步比全队随机发挥好多少"。前者是逐人信用，后者是全队信用；日志里的智能体间标准差 adv_std 记录同一状态内各智能体优势的离散程度。

3. SAC 的演员目标

演员最大化"信用信号 + 熵"：

Lactor = −Σa πi(a)·Âi(a) − α·H(πi)，  Â 视为常数（detach） 用优势替代 Q 相当于"以平均表现为零点"的标准化：策略只被推向高出自己平均水平的动作，不改变最优解，却让梯度尺度与基线对齐

这与标准离散 SAC 的演员目标（最大化 Σπ(a)Q(a) + αH）形式一致，只是把 Q 换成了优势。熵项与自动温度不变：目标熵按 −0.5·|A| 设定（|A|=5 时为 −2.5，量纲与 log π 一致）。优势在进入损失前已 detach，只作为固定的靶子；熵项则照常参与求导，这是熵正则发挥作用的方式。

4. off-policy 的记账方式：next_act 回填

SARSA 目标需要"下一联合动作"，而 off-policy 数据的时间顺序在采样时是连续的。本章在采样阶段把每条转移的 next_act 用下一步实际发生的动作补齐（最后一条丢弃或用窗口外动作占位），记住这个细节，它是"离线数据如何表达 SARSA"的标准答案：动作来自数据历史，不来自当前策略。

关键代码与解读

片段 1：联合双 Q 与反事实张量

class JointTwinQ(nn.Module):
    def __init__(self, state_dim, n_agents, n_actions, hidden=128):
        super().__init__()
        in_dim = state_dim + n_agents * n_actions
        self.in_dim = in_dim

        def make():
            return nn.Sequential(nn.Linear(in_dim, hidden), nn.ReLU(),
                                 nn.Linear(hidden, hidden), nn.ReLU(),
                                 nn.Linear(hidden, 1))
        self.q1, self.q2 = make(), make()

    def forward(self, state, joint_onehot):
        x = torch.cat([state, joint_onehot], dim=-1)
        return self.q1(x).squeeze(-1), self.q2(x).squeeze(-1)


def counterfactual_alternatives(actions: torch.Tensor, n_agents: int,
                                n_actions: int) -> torch.Tensor:
    """(T, N) -> (T, N, A, N·A)：只替换第 i 个智能体的动作块。"""
    T = actions.shape[0]
    device = actions.device
    base = joint_onehot(actions, n_agents, n_actions)
    alts = base.unsqueeze(1).unsqueeze(2).repeat(1, n_agents, n_actions, 1)
    eye = torch.eye(n_actions, device=device)
    for i in range(n_agents):
        block = alts[:, i, :, i * n_actions:(i + 1) * n_actions]
        block.copy_(eye.unsqueeze(0).expand(T, -1, -1))
    return alts

解读：评审团与前缀机制与第 073 章同构，双 Q 是本章新增。（1）JointTwinQ 的 make() 调用两次产生两个独立初始化的 Q 头；forward 一次前向同时返回两个值，训练/反事实查询都用 torch.min(q1, q2) 的悲观估计。（2）counterfactual_alternatives：先复制 base 出 (T,N,A,N·A) 的备份，再对每个智能体 i 用单位矩阵覆盖它自己的动作块，第 (i, a) 行就是"智能体 i 做动作 a、队友照旧"的联合动作 one-hot。copy_ 原地覆写是零拷贝外存的关键。（3）这个张量让"每个问题一次前向"成为可能：B·N·A 行一起送入 Q，reshape 回 (B,N,A) 即可查询任意智能体的任意替换动作。（4）隐藏层 128 比策略宽（64）：Q 要区分的联合动作组合更多，容量压力更大，这与第 073 章的取舍一致。

片段 2：联合双 Q 的 SARSA 回归

        # ---- 联合双 Q：SARSA 目标，软更新目标网络 ----
        with torch.no_grad():
            q1t, q2t = self.q_target(next_state, next_joint)
            target = team_rew + self.gamma * (1.0 - done) * torch.min(q1t, q2t)
        q1, q2 = self.q(state, joint)
        q_loss = F.mse_loss(q1, target) + F.mse_loss(q2, target)
        self.q_opt.zero_grad()
        q_loss.backward()
        self.q_opt.step()
        with torch.no_grad():
            for p, p_t in zip(self.q.parameters(), self.q_target.parameters()):
                p_t.data.mul_(1.0 - self.tau).add_(self.tau * p.data)

解读：与第 073 章的目标几乎相同，一处关键差别是，这里没有熵项。SAC 的正统软 Bellman 会减 α·log π，而本章的信用分配框架把熵完全交给演员与温度处理，团队价值回到"纯回报"的 SARSA 目标。这样做的好处有二：① 优势 Â = qcf − 基线里两个项的口径一致，不会被熵项扭曲；② 反事实查询Q(s,·) 不必再为"假设动作"计算 log π。评估时也不会因为熵项而低估团队价值。作为交换，探索完全由策略侧的熵正则承担，在本任务里这个分工工作得很好。

片段 3：反事实 Q 与两种基线

        # ---- 反事实 Q：对每个智能体枚举其全部动作 ----
        with torch.no_grad():
            alts = counterfactual_alternatives(act, N, A)          # (B,N,A,N·A)
            state_rep = state.repeat_interleave(N * A, dim=0)
            q1a, q2a = self.q(state_rep, alts.reshape(B * N * A, N * A))
            q_cf = torch.min(q1a, q2a).reshape(B, N, A)            # 反事实 Q
            if self.credit == "coma":
                logits = self.policy(obs.reshape(B * N, -1))
                probs = torch.softmax(logits, dim=-1).reshape(B, N, A)
                baseline = (probs * q_cf).sum(dim=-1, keepdim=True)  # (B,N,1)
                adv = q_cf - baseline                                # 逐智能体信用
            else:
                k = args.baseline_samples
                rand_acts = torch.randint(0, A, (B, k, N), device=device)
                rand_joint = torch.zeros(B, k, N * A, device=device)
                idx = (torch.arange(N, device=device)[None, None, :] * A + rand_acts)
                rand_joint.scatter_(2, idx, 1.0)
                q1r, q2r = self.q(state.repeat_interleave(k, dim=0),
                                  rand_joint.reshape(B * k, N * A))
                q_rand = torch.min(q1r, q2r).reshape(B, k)
                baseline = q_rand.mean(dim=1, keepdim=True)          # (B,1)
                adv = q_cf - baseline.unsqueeze(1)                   # 全队共享基线
            adv_std = float(adv.std(dim=1).mean().item())

解读：全章最重的计算段，两个分支只在"基线怎么算"处不同。（1）反事实前向把每个 (状态, 替换动作) 展成 B·N·A 行一起算：128×3×5=1920 行一次算完，之后 reshape 回 (B,N,A)。这是"反事实把指数成本压回线性"的具体形态。（2）coma 分支：probs 是策略对每个智能体动作的分布，baseline = Σ probs·q_cf 逐人求期望，注意基线随智能体不同（(B,N,1)），这就是"逐人信用"的代码形态。（3）shared 分支：随机采 K=16 组联合动作（整组采，不是逐人），Q 均值作为全队共享基线（(B,1)），广播给所有智能体。（4）adv_std：同一状态内 N 个智能体优势的标准差再对 batch 平均。shared 的基线对全队相同，但减去后逐动作优势仍随各智能体自己的 q_cf 变化，adv_std 不会归零；coma 的基线逐人扣平均。它是本章"信用是否分化"的体检指标。

片段 4：演员目标与温度

        # ---- 演员：最大化 Σ_a π(a)·Â(a) + α·H(π) ----
        obs_flat = obs.reshape(B * N, -1)
        adv_flat = adv.reshape(B * N, A)                             # (B·N, A)，已 detach
        logits = self.policy(obs_flat)
        probs = torch.softmax(logits, dim=-1)
        entropy = -(probs * torch.log(probs + 1e-8)).sum(dim=-1).mean()
        actor_loss = -(probs * adv_flat).sum(dim=-1).mean() \
            - self.log_alpha.exp().detach() * entropy
        self.policy_opt.zero_grad()
        actor_loss.backward()
        self.policy_opt.step()

        # ---- 温度：把平均熵拉向目标熵 ----
        with torch.no_grad():
            sampled = Categorical(probs=probs).sample()
            logp = torch.log(probs.gather(1, sampled.unsqueeze(-1)).squeeze(-1) + 1e-8)
        alpha_loss = -(self.log_alpha * (logp.detach() + self.target_entropy)).mean()
        self.alpha_opt.zero_grad()
        alpha_loss.backward()
        self.alpha_opt.step()

解读：演员与温度两段合起来完成"按信用更新策略"的闭环。（1）adv_flat 是从反事实段来的 (B·N, A)，在 no_grad 里算好、天然不带梯度，优势是"靶子"，不参与求导。（2）演员损失 = −Σπ(a)Â(a) − α·H(π)：前一项把概率质量推向正优势动作，后一项用熵奖励防止塌缩。log_alpha.exp().detach() 让温度不接收演员梯度。（3）温度损失用采样动作的 log 概率（Categorical 采样）与目标熵对齐：target_entropy = -0.5×A（|A|=5 时为 −2.5）按动作数缩放目标熵，与连续版的 −dim(A) 约定同构。（4）顺序是"批评家/反事实 → 演员 → 温度"，每一步都吃上一步的新鲜产物；反事实 Q 在演员更新前就是最终稿，不会被演员梯度污染。

常见坑

  • 优势忘了 detach：Â 来自 critic 的反事实前向，必须整体在 no_grad 里算好；若让梯度穿回 critic，演员更新会污染价值网络。
  • next_act 用当前策略重新生成：SARSA 的下一动作必须来自数据历史（回填），不是更新时的策略重采样。写成后者会把方法变成"Q-learning 的近似"，目标不稳。
  • 反事实张量内存挤爆：B·N·A 行是 B 的 15 倍；batch 调大前先估算显存（128×15=1920 行，已经不小）。
  • shared 与 coma 用了不同的 Q 或数据：两者必须共用同一个联合双 Q 与同一批回放数据，否则实验就混入了别的变量，比较将失去意义。
  • 把 adv_std 当性能指标：它只说明信用是否分化；分化更"真"不等于回报更高，要结合回报与协调指标一起读。

练习与思考

  1. 跑两种方案，对比 adv_std：shared 的 adv_std 为什么不会归零？从"基线完全相同"这一事实出发推导逐人优势的差异来源。★
    提示
    再看代码：shared 的基线是 (B,1)，q_cf 是 (B,N,A)，相减后差异全部来自 q_cf；它不会自动归零，只有当队友动作对 Q 的边际影响很小时，各智能体的 q_cf 才趋于同值。
  2. 把 --baseline-samples 从 16 改到 4 与 64，观察 shared 的性能与 adv_std。基线噪声与信用质量是什么关系？★
    提示
    K 小 → 基线方差大 → 优势信号更抖；K 大成本高、收益递减。基线估计的稳定性直接影响"公平"本身。
  3. 把 SARSA 目标改成 Q-learning 式（对下一联合动作枚举取 max），预测并观察训练稳定性。为什么本章坚持 SARSA？★★
    提示
    枚举 max 要再构造一次 A^N 组合（或张量化近似），成本高；max 还会引入乐观偏差与非策略数据外推的双重风险。
  4. 把目标熵从 −0.5A 调到 −0.1A 与 −0.9A，观察探索行为与最终回报。分类分布与连续高斯在"熵的直觉"上有什么不同？★★
    提示
    目标熵越负，α 受到的下压越强，具体行为以实跑日志为准。分类熵的量纲与 log π 一致（纳特），上限随动作数增长。
  5. 把本章的信用信号与第 080 章的对称编码器叠加：用集合编码器替换策略输入网络，观察 adv_std 与回报是否同时受益。讨论：哪些机制可以叠加，哪些会互相抵消？★★★
    提示
    对称性作用于表征层，信用分配作用于信号层，理论上可叠加。真正容易互相干扰的是信号层内部的组合（如共享基线 + 独立批评家），动手验证。

小结

  • SAC 版信用分配 = 集中式联合双 Q（SARSA 目标）提供反事实查询 + 演员按逐动作优势更新。
  • 两种基线：COMA 逐智能体求期望（逐人信用）；shared 用随机联合动作的 Q 均值（全队一个数）。
  • 演员目标 = −Σπ(a)Â(a) − α·H(π)；优势 detach、熵奖励保留；与标准离散 SAC 演员目标同形。
