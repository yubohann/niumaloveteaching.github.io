第五篇 · 多智能体环境与实践

第 097 章：多智能体环境：推荐系统

把推荐系统改造成一场注意力市场：3 家内容平台各守一个类别，每步选择质量投入去争夺 3 组有习惯偏好的用户，用共享的双重 DQN 训练，看投入竞争会不会演变成"广告军备竞赛"（默认参数下的答案：不会，近似零投入接近最优），以及用户偏好在竞争中如何被锁定。

  • 主题：环境设计 / 注意力市场与习惯锁定
  • 关键公式：U(s,i) = ps[ci]·(1+0.5qi) + ε；ps ← 0.9ps + 0.1·onehot(winner)
  • 预计学时：60 分钟
  • 前置章节：第 096 章

学习目标

  • 把推荐竞争建模成多智能体市场：平台选择质量投入、用户按效用选择、偏好随消费漂移。
  • 掌握"习惯锁定"机制：偏好更新是一个惯性系统，早期抢到的用户会持续更容易被留住。
  • 用共享网络的双重 DQN 训练 3 家平台（类别独热进观测，异质角色共享网络），观察投入策略的差异化。
  • 用五个指标评估市场：消费者效用、总投入成本、平台利润、集中度 HHI、消费类别熵。
  • 理解"策略性投入"与"军备竞赛"的区别：前者该花才花，后者被对手逼着一起烧钱。

背景与动机

推荐系统看似是"平台给用户推什么"的工程问题，一旦有多个平台竞争同一批用户，它立刻变成多智能体博弈：你提升内容质量，用户多看两眼；对手也提升，注意力又被拉回去。平台之间的投入策略互相影响、收益取决于彼此的选择，这正是多智能体 RL 的标准结构。本章把它压缩成一个 3×3 的注意力市场。

环境把"用户"建模成会漂移的偏好系统：每次消费都让偏好往被消费的类别移动一点（习惯锁定）。这个机制让市场出现阶段性现象：用户会在平台间摇摆，偏好被消费逐步拉走；训练中段曾出现集中度上升（HHI 一度到 0.556），但默认参数下没有形成稳定的"赢家通吃"，最终评估 HHI 约 0.47。学习策略要做的是判断何时值得投入、何时收手，避免无脑砸钱；评估输出的"总成本"与"消费者效用"对比零投入/满投入基线，两个数字的差距就是本章的答案。

核心原理

1. 用户选择模型

平台 i 属于类别 ci（0/1/2），用户组 s 对类别有偏好向量 ps（三维且归一化）。用户选择效用最高的平台：

U(s, i) = ps[ci] · (1 + 0.5·qi) + ε，ε ∼ U(0, 0.15)

符号：qi ∈ {0,1,2,3} 是平台的投入档，乘 0.5 后把吸引力放大到最多 2.5 倍；ε 是"口味抖动"，避免三组用户机械地钉在同一平台，也迫使策略考虑期望份额，确定性份额在这里没有意义。注意平台只能提升自己类别的吸引力，不能跨界，这是一个差异化市场，投入竞争发生在"抢对口味用户"的维度上。

2. 习惯锁定动力学

每组用户消费后，偏好以 0.9 的惯性向被消费类别漂移：

ps ← 0.9·ps + 0.1·onehot(cwinner) + 噪声，随后归一化

把它看成"指数衰减的记忆"：今天的选择以 0.9k 的权重影响第 k 步后的偏好（半衰期约 6.6 步）。于是"先抢用户"有复利效应，这就是平台愿意早期投入的根本原因，也是集中度 HHI 上升的引擎。0.01 的均匀噪声保证"完全锁死"不会出现，市场始终保留一点流动性。

3. 平台收益与投入成本

ri = sharei − 0.15·qi

份额 share 是"本步选择该平台的用户组比例"（0、1/3、2/3 或 1），量级 0～1；投入成本每档 0.15，q=1 相当于花 0.15 的利润换 1.5 倍吸引力。动态判断的关键在于：用户已锁定在自己类别时（偏好集中、基础效用 0.8+），对手满投入也抢不走，继续投入是纯浪费；三分天下的胶着局面里，一次 q=1 就可能多拉一组用户，同一平台在不同局势下的最优动作完全不同，这正是策略必须"条件化"的原因。

4. 为什么必须用"一组指标"评估市场

只看平台利润，策略可能学会"永远零投入"；只看效用又分不清"高效用来自投入"还是"用户本就专一"。五个指标一起看才能判断市场健康度：高利润 + 高效用 + 低成本是理想组合；高成本 + 高效益（军备竞赛）次优但常见；HHI 上升说明向某家集中，类别熵下降说明用户偏好被锁进少数类别，两个扭曲必须分开监测。

5. 共享网络与异质角色

三家平台类别不同，但观测里含类别独热（最后 3 维），因此一个网络可以服务三个角色，它学的是"给定我的类别和当前格局，投入多少合适"的条件策略。这与第 091 章用"偏移向量"区分无人机角色同构：把角色身份写进观测，是共享网络处理异质个体的标准做法。

实现思路与设计

模块划分

组件职责关键点
AttentionMarket注意力市场环境（纯 numpy）用户选择 + 偏好漂移 + 份额统计
QNet / DoubleDQNAgent共享网络双重 DQN类别独热区分平台角色；逐平台 ε-贪婪

关键超参数

参数默认值作用与取值理由

数据流

每步：3 家平台读各自的 14 维观测 → ε-贪婪选投入档 → 环境让 3 组用户各自选效用最高的平台、更新偏好、按份额与成本结算奖励 → 三条转移进共享回放池 → 每 2 步抽 64 条做双重 DQN 更新 → 每 1 万步用贪婪策略评估五指标，并对照零/满/随机三条基线。

与前一章的差异

第 096 章里"耦合"来自空间约束（前车挡路），本章的耦合来自需求侧的争夺：平台的动作不改变物理位置，只改变用户的选择概率，而用户选择又反过来改变偏好分布，这是一条"动作 → 份额 → 偏好 → 未来收益"的反馈环。两章都用共享策略网络，但角色异质性的处理方式不同：096 靠观测结构自然同质，本章靠类别独热显式区分角色。

不完全信息：为什么观测里没有"对手投入"

真实市场里你看不到对手的预算表，只能看到结果（份额变化）。本环境的观测因此只含各平台的"上步份额"，对手的投入需要从份额的波动里推断，这是一个不完全信息博弈。把对手投入塞进观测会让策略依赖部署时拿不到的信息，实验结论也会失真：观测必须只含执行时可获得的信息。

关键代码与解读

片段 1：初始偏好，归一化的随机市场

def reset(self, rng: np.random.Generator):
    self.rng = rng
    # 每组用户的类别偏好：随机但归一化，三组用户的口味开局各不相同
    self.prefs = rng.uniform(0.2, 1.0, size=(self.n_segments, 3)).astype(np.float32)
    self.prefs /= self.prefs.sum(axis=1, keepdims=True)   # 每行和为 1
    self.last_q = np.zeros(self.n_firms, dtype=np.int64)
    self.last_share = np.full(self.n_firms, 1.0 / 3.0, dtype=np.float32)
    self.steps = 0
    self.share_history = []
    return self._obs()

解读：开局设定决定了整局博弈的初始条件。（1）偏好从 U[0.2,1.0] 采样再按行归一化：保证每组用户对三个类别都有一定基础兴趣（下限 0.2 避免"完全不看某类"），归一行和恒为 1 让"偏好"读起来就是概率权重。（2）三组用户独立采样：市场开局就有差异化口味，某些组天然靠近某些平台，这给"各守一方"与"互相争夺"都留出了空间。（3）last_share 初始化为 1/3：起始观测告诉平台"现在是三分天下"，策略从均匀格局出发学习。（4）share_history 留痕：评估端的类别熵要靠整个回合的份额序列计算，环境只负责记录、评估负责解释，职责分离。

片段 2：14 维观测，竞争态势的压缩

def _obs(self) -> np.ndarray:
    obs = []
    for i in range(self.n_firms):
        q_onehot = np.zeros(self.n_quality, dtype=np.float32)
        q_onehot[self.last_q[i]] = 1.0                 # 自己上步投入了什么
        others = [float(self.last_share[j])
                  for j in range(self.n_firms) if j != i]   # 另两家的上步份额
        cat_onehot = np.zeros(3, dtype=np.float32)
        cat_onehot[self.categories[i]] = 1.0           # 自己的类别：角色身份证
        o = np.concatenate([
            q_onehot,
            [float(self.last_share[i])],               # 自己的份额
            self.prefs[:, self.categories[i]],         # 三组用户对我类别的偏好
            np.asarray(others),
            [self.steps / self.max_steps],             # 时间进度
            cat_onehot,
        ])
        obs.append(o.astype(np.float32))
    return np.stack(obs)

解读：观测把"竞争态势"拆成四类信号。（1）自己的上步投入（独热）+ 份额：让策略知道"我刚刚花了多少、换回了什么"，这是它做因果推断的原料。（2）prefs[:, categories[i]] 是最有信息量的三维：三组用户当前对我类别的偏好，它同时暗示了"我还能守住谁、还能抢谁"。（3）对手只给份额不给投入：结果可见、预算不可见，对应上一节说的不完全信息。（4）时间进度 + 类别独热：进度支持"临到期改变节奏"，类别独热是共享网络的角色身份证，同构于第 091 章的偏移向量。维度账：4+1+3+2+1+3 = 14，与 obs_dim 一致。

片段 3：用户选择，带噪声的离散抉择

# 1) 每组用户选择效用最高的平台（效用 = 偏好 × 吸引力 + 噪声）
for s in range(self.n_segments):
    utilities = np.zeros(self.n_firms, dtype=np.float64)
    for i in range(self.n_firms):
        attractiveness = 1.0 + 0.5 * float(q[i])       # 投入把吸引力放大到最多 2.5 倍
        utilities[i] = (float(self.prefs[s, self.categories[i]])
                        * attractiveness
                        + self.rng.uniform(0.0, 0.15)) # 口味抖动：避免机械锁定
    winner = int(np.argmax(utilities))
    shares[winner] += 1.0                              # 计数，最后再除以组数
    consumer_util += float(self.prefs[s, self.categories[winner]]) \
        * (1.0 + 0.5 * float(q[winner]))               # 消费者效用 = 获胜组合的体验

解读：需求侧建模的全部内容都在这里。（1）效用公式与原理一节一一对应：偏好 × 吸引力 + 噪声；吸引力的斜率 0.5 决定了"投一档提升 50%"的边际效果。（2）噪声 U(0,0.15) 是正噪声（不居中）：它让效用整体轻微上浮，触发更多"逆偏好选择"，三组用户不会永远钉在最喜欢的平台上，市场因此保持流动。没有噪声，策略会学到"永远零投入"。（3）argmax 是"赢家通吃"的选择规则：一组用户整份注意力归一个平台，所以份额只能是 0、1/3、2/3、1 四个值。这个离散化让奖励信号清晰，代价是失去用户规模的连续性，练习五会让你改成 softmax 连续份额。（4）consumer_util 用"获胜组的实际体验"累加：它衡量的是用户福利，平台收入另走奖励通道，它是五指标里唯一站在需求侧的（同一次选择，两者读出不同视角）。

片段 4：习惯锁定与奖励结算

# 2) 习惯锁定：偏好向被消费的类别漂移（惯性 0.9）
target = np.zeros(3, dtype=np.float32)
target[self.categories[winner]] = 1.0
self.prefs[s] = (self.pref_inertia * self.prefs[s]
                 + (1.0 - self.pref_inertia) * target)
self.prefs[s] += self.rng.uniform(0.0, 0.01, size=3).astype(np.float32)
self.prefs[s] /= self.prefs[s].sum()      # 归一化：偏好恒为概率权重，防数值漂移

shares /= self.n_segments                  # 计数还原成比例：量级与成本 0.15 对齐
rewards = shares - self.invest_cost * q.astype(np.float32)
self.last_q = q.copy()
self.last_share = shares.copy()
self.share_history.append(shares.copy())
self.steps += 1

truncated = self.steps >= self.max_steps
hhi = float(np.sum(shares ** 2))           # 集中度：全归一家=1，三家均分≈0.33
info = {"shares": shares.copy(), "hhi": hhi,
        "consumer_util": consumer_util / self.n_segments,
        "total_cost": float(self.invest_cost * q.sum())}

解读：漂移与结算两段共同构成"市场的记忆与账本"。（1）漂移公式 0.9·prefs + 0.1·onehot：被消费的类别偏好权重每次涨 10%，其余按比例衰减，连续消费同一类别会让偏好几何式收敛到它。这就是"锁定"的数学形状。（2）漂移后必归一到 1：不归一化会让偏好总和随步数漂移（有的行涨到 3、有的跌到 0.2），观测与效用的尺度全乱，这是本章第一号坑。（3）加噪 U(0,0.01) 给偏好留出"松动"：完全锁死（偏好 = onehot）的市场上投入竞争彻底消失，博弈的后期就没了观察价值。（4）份额先除以组数再进奖励：0.15 的成本是"比例量级"，如果直接用计数（0～3），成本相对变得微不足道，策略会疯狂投入。（5）HHI = Σshare² 与消费者效用、总成本都从同一步读出：五指标的原始数据全在 info 里，评估端做二次加工（如类别熵），环境不预设解释。

常见坑

  • 偏好向量忘了归一化：漂移更新后不重新除以总和，偏好会随步数漂出 [0,1]，效用尺度失衡、观测数值爆炸，这是本章最隐蔽的数值事故。
  • 用户选择写成无噪声 argmax：没有 0.15 的随机项，三组用户永远停在最喜欢/最便宜的平台，策略学会"永远不需要投入"，博弈味道全失。
  • 份额忘记除以组数：用计数当份额会让奖励被放大成 0～3 的量级，与成本 0.15 彻底错位，策略疯狂投入；份额必须先除以组数。
  • 观测里给"对手上步投入"：对手投入是私有信息；放进观测会让策略依赖部署时拿不到的信息，实验结论失真。只给结果（份额）。
  • 把 0.15 的正噪声写成对称噪声：U(−0.075, 0.075) 的中位数在 0，选择更接近纯偏好；正噪声让"逆偏好选择"更多、市场更活。噪声的区间写错会悄悄改变博弈性质。

练习与思考

  1. 比较学习策略与零投入/满投入基线的"效用—成本"组合，说明学习策略的性价比优势体现在哪个指标上。★
    提示
    把三个组合画在"成本为横轴、效用为纵轴"的平面上：零投入在左上（低成本低效用）、满投入在右下（高成本高效用），学习策略落在右上就是帕累托改进。注意利润是三者的综合评价。
  2. 把偏好惯性 pref_inertia 从 0.9 调到 0.5，先预测 HHI 与投入成本的走向，再对比实验。★
    提示
    惯性弱意味着用户随时可以走，平台必须持续投入才能守住份额，成本上升、集中度下降。这解释了很多行业"用户忠诚度低 ⇒ 营销费用高"的现象。
  3. 把投入档位加到 6 档（n_quality=6 并同步调整吸引力系数），先预测动作空间变大对训练难度的影响，再观察策略是否学出更精细的投入节奏。★★
    提示
    可以先把 --max-steps 加到 10 万。观察投入档位的时间序列是否出现"低—高—低"的脉冲式结构，这正是"该花才花"的行为特征。
  4. 给市场加第四家平台（与某家同类别），先论证"同类别竞争"与"跨类别竞争"的区别，再改 n_firms 与 categories 验证。★★
    提示
    同类别的两家会直接抢同一批用户，投入竞争显著加剧；跨类别竞争更像差异化定位。注意观测维度会变（别人数+1 需要调整份额列表），网络输入自动适配。
  5. 把"每组用户只选一个平台"改成 softmax 分配注意力（份额连续），先分析奖励信号的变化，再改代码并试几个温度参数。★★★
    提示
    把 argmax 换成 softmax(U/T)：份额连续、奖励更平滑但单步差异更小，可能需要更大的学习率或更长的训练。温度 T 决定"接近确定性"还是"接近均分"。

小结

  • 推荐竞争 = 平台投入策略 + 用户选择模型 + 偏好漂移：三件套缺一不可，习惯锁定是市场集中化的引擎。
  • 共享网络靠"类别独热"服务三个异质角色，学到的是一族条件策略，参数在三个角色间共享。
  • 学习策略的定位要用三条基线来量：效用高于零投入、成本低于满投入、利润领先两者才算合格。
  • 五个指标的组合揭示市场健康度；HHI 与类别熵一起看，能区分"集中"与"同质化"两种不同的扭曲。
