第五篇 · 多智能体环境与实践

第 099 章：多智能体环境：金融交易

在一条会随机游走的基本面曲线上放 4 个交易者：2 个握有清醒的私有信号、2 个信号含噪，用共享网络的离散 PPO 学习下单，观察知情者盈利、噪声者被收割，以及学会交易后市场价格对基本面的跟踪是否更快更准。

  • 主题：环境设计 / 带私有信号的噪声市场与价格发现
  • 关键公式：ri,t = ai,t·(Ft+1 − pt) − 0.01·|ai,t|
  • 预计学时：60 分钟
  • 前置章节：第 098 章

学习目标

  • 理解"带私有信号的做市市场"的核心部件：基本面过程、价格冲击、私有信号与交易成本。
  • 掌握一个无做市商、用订单流与均值回复共同定价的最小市场模型。
  • 用共享网络的离散 PPO 训练知情/噪声两类交易者，观察类型差异如何演化为盈亏差异。
  • 把"价格发现"变成可量化指标：|基本面 − 价格| 的时间平均误差与价格波动率。
  • 用三种脚本交易者（零订单、追信号、追动量）给学习策略定位，理解哪些直觉策略在冲击成本下必亏。

背景与动机

金融市场是多智能体强化学习最有商业吸引力、也最容易被过度包装的领域。撇开"用 RL 炒股"的噱头，它作为学习环境有三个干净的教学价值：其一，奖励按"基本面 vs 成交价"结算，个体盈亏可清晰分解，费用是恒定的负项（注意：本模型的合计盈亏并不自动守恒，实测中学习策略甚至让全员转正，后文对账会看到）；其二，市场是内生的，你自己的订单会推动价格，这是与静态数据集监督学习最根本的差别；其三，"价格发现"这个市场质量指标可以直接测量，让你看到个体逐利如何改变市场质量（实测里学习策略反而把发现误差推高，方向与直觉相反）。

本章的设定接近经典做市模型：基本面以 AR(1) 波动，知情交易者收到低噪声信号，噪声交易者只看高噪声版本；两者共享同一个网络，靠类型独热区分角色。学习目标在于观察两类交易者的盈亏与行为如何演化（实测：类型分化没有出现，两类都转为激进同向交易）、价格发现误差如何被交易影响；评估口径里没有"稳赚"这一项。

核心原理

1. 基本面与价格的动力学

基本面 F 服从均值回复的 AR(1) 过程，市场价格同时受三股力量影响：

Ft+1 = 0.98·Ft + ηt，η ∼ N(0, 0.06²)
pt+1 = pt + 0.08·净订单流 + 0.2·(Ft − pt) + ε，ε ∼ N(0, 0.02²)

符号：0.98 的近单位根让基本面缓慢回归零（长期锚）；冲击系数 0.08 意味着"净买 1 手平均把价格推高 0.08"；回归系数 0.2 意味着价格每期向基本面收敛 20%；ε 是成交噪声。知情交易者提前知道 η 的方向，因此能预判"价格接下来往哪走"，选择正确方向的订单。

2. 信号与两类交易者

每期开始时抽出 η，生成下一期的基本面增量 ΔF，两类交易者收到不同噪声的信号：

si = ΔF + νi，ν知情 ∼ N(0, 0.02²)，ν噪声 ∼ N(0, 0.12²)

知情者的信号几乎是真实的 ΔF（噪声只有增量的 1/3），噪声者的信号大半是干扰。观测里同时给出"F−p"（公开的错价信息）与信号：知情者可以用信号方向下注，噪声者若偏信信号会吃亏；但实测里共享网络把两类行为拉向同一套激进策略，噪声者没有被收割，类型分化没有出现，这是共享网络在异质任务上的风险实例。

3. 收益分解：为什么必须按基本面结算

ri,t = ai,t·(Ft+1 − pt) − 0.01·|ai,t|

仓位 a ∈ {−2,…,2} 在现价 pt 建立、按下一期基本面结算，再扣 0.01/手的交易费。注意不是按 pt+1 结算：在含冲击定价的市场里，按下一期价格结算会让"自己买入推高的那部分"变成收益（a·Δp 中含 λa² 的正项），凭空创造利润。用基本面结算堵住自我交易漏洞，是本章最重要的建模细节。

4. 价格发现度量

每期记录 |Ft − pt|（错价幅度）并取时间平均。零订单基线里价格只靠 0.2 的回归项爬向基本面；本章本意是知情交易者通过买卖把价格"推"向基本面、让误差下降，但实测里高频交易把价格推来推去，发现误差反而上升（0.36 对零订单 0.07）：因为信号预测的是下一期基本面，交易让价格"抢跑"，而度量看的是与当期基本面的距离。价格变化的标准差作为"波动率"（0.71 对零订单 0.028），用来检验市场是否被搅得过度动荡，发现误差与波动率两个指标要一起看，且要理解度量口径。

5. 为什么用共享网络训练两类交易者

观测里含类型独热，一个网络可以同时表达两类角色的条件策略，与第 091、097 章的角色条件化技巧一致。两类角色的梯度互相影响，平衡得好时网络会学到"知情者重仓、噪声者轻仓"的差异化行为；平衡得不好时两类样本会互相拉扯，这也是共享网络在异质任务上的固有风险。

数据流

每期（1 步）：环境先滚出下一期基本面增量与四个私有信号 → 4 个交易者读 6 维观测（错价、动量、信号、上期仓位、类型）→ 策略输出 5 档订单 → 价格按"订单冲击 + 回归 + 噪声"更新 → 按基本面结算盈亏、扣费 → 推进基本面、生成下一期信号。每 10 局做一次 PPO 更新（4000 样本），每 1 万步评估四指标，并对照三种脚本策略。

与前一章的差异

第 098 章是纯合作的共享奖励（全系统成本），本章是零和/负和的独立奖励；098 的耦合在时间轴上（储能跨期），099 的耦合在价格里（我的订单改变你的盈亏环境）。两章合起来展示了"共享奖励"与"竞争奖励"在实现上的全部差异：前者看全队成本、价值函数逐区分解，后者每人一份盈亏、优势和优化完全独立。

信号的时序：领先一步才叫"信息"

每步的顺序固定为"先推进基本面并生成信号 → 再拼观测"：知情者看到的 si 是对尚未启动的下一期的预测，据此决定本期仓位；到下一期结算时信息才兑现。如果把信号生成放在 step 末尾、观测却延后一期读取，知情者就变成"用上一期信息打这一期"，盈亏全部失真。多智能体经济环境里，信息时序与结算时序的先后关系就是"公平"本身。

关键代码与解读

片段 1：信号生成，把未来增量分给不同噪声

def _roll(self):
    """抽出下一期基本面增量并生成各交易者的私有信号。"""
    eta = float(self.rng.normal(0.0, self.eta_std))      # 未来的创新项 η
    self.F_next = 0.98 * self.F + eta                    # 下一期基本面（AR(1)）
    dF = self.F_next - self.F                            # 真正值得交易的增量
    self.signals = np.array(
        [dF + float(self.rng.normal(0.0, s)) for s in self.signal_noise],
        dtype=np.float32)                                # 知情者噪声 0.02、噪声者 0.12

解读：八行代码定义了"信息不对称"这一市场最基本的燃料。（1）生成分两步：先抽 η、再算 F_next，所有交易者面对的是同一个未来基本面，区别只在信号的清晰度。（2）信号预测的是"ΔF"（基本面的下一步变化），与价格无关：买方向正确与否以基本面结算衡量，避免了把价格噪声混进信号。（3）四个信号的噪声按 signal_noise 元组分配：前两人 0.02（信噪比高）、后两人 0.12（信噪比低），一个元组就编码了"谁是天选之子"。（4）_roll 在 reset 和 step 的各一处调用：观测构造之前必须先滚动出信号，否则交易者看到的永远是上一期的旧信息，时序正确性全在这个调用点上。

片段 2：6 维观测，公开信息 + 私有信息的配方

def _obs(self) -> np.ndarray:
    obs = []
    dp = self.p - self.prev_p                        # 上一期价格变化（动量特征）
    for i in range(self.n_agents):
        type_onehot = np.array([1.0, 0.0]) if i < 2 else np.array([0.0, 1.0])
        o = np.concatenate([
            [self.F - self.p],                       # 公开信息：当前错价（所有人可见）
            [dp],                                    # 公开信息：价格动量
            [float(self.signals[i])],                # 私有信息：各人的信号不同
            [self.last_order[i] / 2.0],              # 自己上期仓位（归一化到 [-1,1]）
            type_onehot,                             # 角色身份证：共享网络的关键输入
        ])
        obs.append(o.astype(np.float32))
    return np.stack(obs)

解读：每条观测都是"公共广播 + 私人短信"的组合。（1）F − p 是错价（mispricing）：正数表示价格低于基本面、做多有利，公开信息、人人可用，但它的兑现速度取决于流动性，单靠它无法稳定盈利。（2）动量项 dp 对应"追涨杀跌"策略的信息来源；配合 0.2 的均值回复，动量策略在模型里会被反向力量压制（基线实验会看到）。（3）signals[i] 是各人的私有信号：同样位置的一维，数值分布因角色而异，这是市场里唯一"只看得到自己的那一份"。（4）类型独热最后两维：让共享网络知道"把这条观测当知情者还是噪声者处理"；没有它，网络无法同时拟合两类行为，梯度会互相拉扯。

片段 3：价格更新与盈亏结算，一步之内的因果链

orders = (actions.astype(np.float32) - 2.0)       # 动作 0..4 → 仓档 -2..+2
net = float(orders.sum())
self.steps += 1

# 1) 价格更新：订单冲击 + 向基本面回归 + 噪声
self.prev_p = self.p
self.p = (self.p + self.lambda_impact * net
          + self.kappa_revert * (self.F - self.p)
          + float(self.rng.normal(0.0, self.price_noise)))
self.price_changes.append(self.p - self.prev_p)

# 2) 实现盈亏：以"上期价格"建仓，按"下期基本面"结算（教学简化）
rewards = orders * (self.F_next - self.prev_p) - self.fee * np.abs(orders)
self.tot_pnl += rewards
self.last_order = orders.copy()
self.mispricing.append(abs(self.F - self.p))

# 3) 基本面推进一期，并滚动出新的场景（新信号在这里生成）
self.F = self.F_next
self._roll()

解读：这二十行是市场模型的"心脏"，每一行的时序都值钱。（1）价格更新三项：订单净流 × 0.08（冲击）、(F−p) × 0.2（回归）、N(0,0.02)（噪声）。注意冲击项用的是净订单：四个人的仓位先汇总再作用于价格，"合力"才决定市场移动，这正是多交易者市场区别于单体交易的关键。（2）盈亏用 orders * (F_next − prev_p)：仓位以建立时刻的价格 prev_p 记账，以下一期基本面 F_next 兑现，中间隔着一个价格更新步，这正是"信息提前、价格跟进"的时序。若改成用 self.p 结算，orders 自己推动的冲击会变成自融资利润（练习四）。（3）费用 0.01·|orders| 阻止"无限刷单"，是恒定的负项；但注意本模型的合计盈亏并不守恒（结算基准是 prev_p 与 F_next，没有显式的对手盘），实测里学习策略甚至让全员录得正盈亏（各约 +69），这提醒你教学模型与严谨零和市场的差距。（4）末尾两行推进基本面并 _roll：此时 F_next 已兑现、旧信号已消费，新的信号对应新的未来，时序闭环。读懂这三步的先后，就读懂了"为什么信息有价值"。

片段 4：四种交易者在同一评测循环里对账

if mode == "learned":
    a = net.act_deterministic(obs, device)
elif mode == "zero":
    a = np.full(env.n_agents, 2, dtype=np.int64)      # 动作 2 = 空仓
elif mode == "signal":     # 追信号：信号正就买 1 手，负就卖 1 手
    a = np.zeros(env.n_agents, dtype=np.int64)
    for i in range(env.n_agents):
        s = float(env.signals[i])
        a[i] = 3 if s > 0.005 else (1 if s < -0.005 else 2)
else:                      # 追动量：价格在涨就买
    a = np.zeros(env.n_agents, dtype=np.int64)
    dp = env.p - env.prev_p
    for i in range(env.n_agents):
        a[i] = 3 if dp > 0 else (1 if dp < 0 else 2)

解读：三种脚本不是陪跑，它们定义了"直觉策略"的坐标系。（1）zero 全空仓：盈亏恒为零，但它的价格发现误差是"纯回归"的基准，学习策略的误差必须比它低才证明"交易确实帮市场发现了价格"。（2）追信号：信号超过 0.005 阈值才买 1 手（买 3、空 2、卖 1），是"弱一点但谨慎"的知情策略，学习策略要以它为目标下限。（3）追动量：价格涨就买，在含均值回复（0.2）与冲击成本（0.08）的市场里它通常两头挨打：追的往往是将要回归的噪声。（4）四种模式共用同一段 rollout 循环与同一批随机种子（seed+111），数字才能直接比；知情/噪声盈亏在评估末尾按前两人/后两人分开统计，类型维度的拆分统计是本章所有结论的载体，合并成总数会把信号全部抹掉。

常见坑

  • 用市场价格结算盈亏：含冲击定价的市场里按收盘价结算会凭空创造利润（订单自己推高价格）。教学模型必须用基本面结算，或显式建模做市商赚差价，二者必居其一。
  • 信号的时序错误：信号必须在动作之前生成并出现在观测里；顺序写反会让知情者"用上一期信息打这一期"，盈亏全部失真。本实现每步先推进基本面再拼观测，顺序不能换。
  • 把总盈亏当训练指标：本模型的合计盈亏并不守恒（结算基准没有对手盘），可以全体为正；总量高低只反映交易频率。要按类型分开统计，并关注"知情者 − 噪声者"的差距。
  • 学习率与奖励尺度不匹配：单期盈亏量级约 0.1，大 lr 会把优势估计推向噪声；3e-4 配优势标准化已够用。
  • 把发现误差与波动率只看一个：光看误差下降可能掩盖"市场被搅得过度动荡"；光看波动平稳可能掩盖"价格懒得动"。两个指标是市场质量的两面。

    提示

  4. 把结算价从"下一期基本面"改成"下一期市场价格"，先分析会出现什么病态现象，再改 F_next → self.p 验证冲击项自融资的机制。★★★
    提示
    p 的更新式含 0.08·net，自己的仓位会通过 net 推动价格，a·Δp 里因此混入 λa² 的正项，"买入即赚钱"的假象。专业模型为什么重视执行价格假设，这一课最直接。
  5. 给市场加第 5 个"做市商"智能体：每期同时挂买卖两边、赚价差但承担库存风险，先设计它与价格更新的接口，再观察做市商与知情者的博弈如何改变市场质量。★★★
    提示
    把价格更新拆成"中间价 + 半价差"，做市动作决定价差大小；建模量显著增加，建议立为开放式项目，不必压在单次练习里。

小结

  • 金融市场环境的三要件：基本面过程、冲击定价、信息不对称；本模型用 AR(1) + 线性冲击 + 两类信号实现最小闭环。
  • 盈亏必须按"基本面结算 vs 成交价建仓"拆分建模，否则会产生自我交易的假利润；费用制造了负和结构。
  • 共享网络配合类型独热，本可让知情者与噪声者学到分化策略（一个择时重仓、一个保持轻仓）；实测里两类行为趋同、分化没有出现，这是共享网络在异质任务上的风险实例。
  • 价格发现误差与波动率把"个体逐利如何改变市场质量"变成可测量的数字（实测里交易让误差变大，度量口径与冲击模型的组合要谨慎解读）；信号时序与结算时序的先后就是公平本身。
