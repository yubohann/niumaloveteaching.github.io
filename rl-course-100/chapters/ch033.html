第二篇 · 离策略方法与 SAC

第 033 章：SAC的双Q网络与目标网络

把 SAC 的两根稳定器分别拆掉：只用单 Q、或者干脆不要目标网络。在 Pendulum-v1 上用同种子消融对比，你会亲眼看到"Q 值幅度爆掉"这件事长什么样。

  • 主题：过估计抑制 / 自举稳定性
  • 关键公式：𝔼[max(Q1,Q2)] ≥ Q*（取 min 则方向相反）；θ̄ ← (1−τ)θ̄ + τθ
  • 预计学时：50 分钟
  • 前置章节：第 032 章

学习目标

  • 理解双 Q 网络（clipped double-Q）抑制过估计的机制，以及目标网络阻断"自举发散"的原理。
  • 实现一个通过 --configs 切换的消融框架：双 Q / 单 Q、有 / 无目标网络共用同一套训练代码。
  • 在 Pendulum-v1 上对比三组配置的评估回报、|Q| 幅度与 Q 损失曲线。
  • 学会用"Q 值幅度"判断训练是否发散：回报下降不一定是学不会，可能是价值估计炸了。
  • 说清 SAC 选择 min 的理由：保守偏差可控，乐观偏差会被策略主动利用。

背景与动机

Q 学习的更新目标里藏着一次"取最好动作"的操作。当 Q 网络带估计误差时，取 max 会系统性地挑中"被噪声抬高的那个动作"，下一轮又用这个偏高的目标去训网络，误差自我放大，这就是过估计。更危险的是在 actor-critic 里，策略会主动往 Q 大的方向走，等于拿着放大镜去利用这些虚假的高价值，过估计会直接推动策略跑偏。

另一个隐患来自自举（bootstrap）：用网络自己算出的 Q(s′,a′) 去监督 Q(s,a)。如果两边是同一份参数，更新就成了"追自己的尾巴"，目标随参数一起动，训练可能震荡甚至发散。目标网络把"目标"冻结成一个移动慢得多的副本，把这两件事解耦。

第 032 章我们只动了温度系数，把这两根柱子当成默认配置。本章反过来：固定自动温度机制不动，只做消融，看看拆掉哪一根柱子会先塌。

核心原理

1. 过估计的数学来源

设真实价值 Q*(s,a)，两个独立网络给出 Q1 = Q* + ε1、Q2 = Q* + ε2，误差近似零均值且相互独立。取最大值的期望满足：

𝔼[max(Q1, Q2)] ≥ max(𝔼[Q1], 𝔼[Q2]) = Q* max 是凸函数，Jensen 不等式给出正向偏置

取最小则方向相反，给出负向偏置。SAC 选择"绑定在双 Q 较小值上"，宁可比真实价值保守一点，也不给策略虚假的希望。代价是偏差为负（Q 网络不追求无偏），收益是切断了"乐观误差 → 策略追高 → 目标更高"的正反馈环。

2. 数值算例：max 会偏多少，min 会歪多少

设两个网络的误差是独立同分布的高斯：ε1, ε2 ~ N(0, σ2)，取 σ=0.5。两个独立高斯取大的期望有解析结果 𝔼[max(ε1, ε2)] = σ/√π：代入得 0.5/1.7725 ≈ 0.2821，即每次自举目标被系统性抬高约 0.28；取小得到 −0.2821，方向相反。用 200 万对样本做模拟，取大均值 0.2819、取小均值 −0.2821，与公式吻合，感兴趣的读者用不到 10 行 numpy 代码就能复现这组数字。

0.28 的单次偏置不大，问题在于它会进入下一轮的目标。设每步目标被抬高约 b，而学习率足以跟上目标，则价值函数整体比真实值多出约 b，再经 γ 折扣进入后续目标，稳态偏差放大约 b/(1−γ)。取 γ=0.99，放大倍数为 100，b=0.28 对应 Q 平台整体偏高约 28 分；对单步奖励量级为 1 的 Pendulum，这是 30 倍量级的失真，策略会优先追逐这些被抬高的动作。取 min 的偏差方向相反，同样会被放大，但保守方向更安全：略微低估时错过的只是少量潜在收益，而过高估计会把策略主动拖出最优动作区域。作为对照，把两项取平均的 mean 版本没有这一项偏置，同时也失去了纠偏功能，练习第 3 题会用实验验证这个此消彼长。

3. 自举与目标网络

不加目标网络时，TD 目标的梯度会经由 Q(s′,a′) 回到同一组参数：

θ ← θ − α∇θ ( Qθ(s,a) − [ r + γ·(minjQθ,j(s′,a′) − α′·log π) ] )² 目标里出现 θ 自己，参数一更新目标就跟着动

参数副本 Qθ̄ 以 τ = 0.005 的软更新滞后跟随：θ̄ ← (1−τ)θ̄ + τθ。每一步目标只移动千分之五，让回归问题近似"追一个静止靶子"。τ 太大失去意义，太小则价值学得慢，这是第 046 章要专门调的系数。

4. 三组消融各验证什么

  • double_target：完整 SAC。预期最稳。
  • single_target：砍掉 Q2，仍有目标网络。检验"少一个纠偏尺子"的代价，通常学得会，但 Q 幅度更高、回报波动更大。
  • double_notarget：保留双 Q，但自举直接用在线网络。检验目标网络是否必要，预期 Q 幅度失控、回报崩坏。

三组共享同一随机种子、同一批超参数、同一份网络结构，因此差异可以干净地归因到被拆掉的那根柱子。三组的预期画像可以并成一张对照表，训练时按"判定信号"一列逐项核对：

配置被拆掉的柱子预期 |Q| 形态预期回报判定信号
double_target无（完整 SAC）收敛到与回报量级匹配的平台−300 ~ −150Q 损失平稳下降，target_gap 稳定在小值
single_targetQ2（保留目标网络）平台更高，约高出 30% 以上能学会，波动更大|Q| 的斜率长期为正但增速缓慢
double_notarget目标网络（保留双 Q）指数式上涨，可到上万跌回随机水平Q 损失冲到 1e+07 量级

5. 无目标网络为什么会爆：一个可算的放大模型

目标网络的作用可以用一个极简误差递归模型说清。设当前 Q 与真实值之差为 ek，每步更新后误差被 γ 折扣保留一部分（自举），还有一小部分 δ 因为"目标跟着参数动"而同步放大。则 ek+1 ≈ γ(1+δ)ek。只要放大因子 γ(1+δ) 大于 1，误差就按几何级数增长：δ=0.03 时因子为 1.0197，1000 步放大到 3×108；δ=0.05 时因子为 1.0395，1000 步放大到 6.7×1016，3000 步到 1050 量级。实验里"|Q| 涨到上万、Q 损失 1e+07"正处在这条指数曲线的中段，继续训练只会更夸张。

反过来，γ 离 1 越远越安全：γ=0.9 且 (1+δ)=1.05 时因子为 0.945，小于 1，误差自身衰减，发散很难发生。这解释了为什么无目标网络的失控几乎总出现在 γ≥0.99 的长时域任务里。还有一个实践上的边界要注意：该模型假设误差与状态无关，实际训练早期数据分布较窄，网络可能先拟合出一个"假平台"，评估回报暂时正常，随后才进入指数段；因此消融实验必须跑足预算，在 15000 步里用 |Q| 与 Q 损失两条曲线交叉验证，才能对"发散"下结论。

最后给出 Q 幅度的预期量级，便于看日志时判断"平台"是否正常：Pendulum 每步奖励在 −16～0 之间，合格策略的平均单步回报约 −1.5～−0.75，按 r̄/(1−γ)、γ=0.99 折算，健康的 Q 平台大致落在 −150～−75 之间（随机策略约 −6/步，对应 −600 量级）。若 |Q| 平台远高于几百，先怀疑过估计或自举实现有误；若 |Q| 缓慢单调上涨而回报不动，优先检查目标网络的软更新是否真的执行了。

每组配置：set_seed 后建智能体（按 config 决定 Q2 / 目标网络是否创建）→ 随机探索垫池 → 每步一次更新（评论家自举 → 演员 → 温度 → 条件软更新）→ 每 3000 步评估并记录 |Q| 幅度、Q 损失、目标滞后 → 保存模型并进消融汇总表。三组的日志列完全一致，差异只在被拆掉的那根柱子上。

target_gap 的定量读法

target_gap 是"目标网络滞后"的仪表读数，其大小可以反推 Q 值移动的速度。软更新本质上是指数滑动平均：若在线 Q 每步均匀变化 v，稳态滞后约为 v(1−τ)/τ，τ=0.005 时放大倍数约 200。观测到 gap=1.0，意味着在线 Q 平均每步移动约 0.005；gap=0.3 对应每步 0.0015。把这把尺子用在消融表上：double_target 的 gap 通常先变大再收敛，对应"价值先快速移动、后进入平台"；double_notarget 的 gap 恒为 0，因为它没有目标网络，这一列在日志里就是配置的特征标识。gap 与 |Q| 曲线配合读，可以把"健康滞后"与"跟随失效"分开。

与前一章的差异点

  • 第 032 章对比 alpha 的处理方式；本章固定自动温度机制，把问题换成双 Q 与目标网络的存废。
  • SACAgent 增加 config 分支：Q2 与目标网络按需创建，软更新按需执行。
  • 新增 mean_abs_q 与 target_gap 两个诊断量：前者是评价发散的核心指标，后者衡量目标滞后。
  • 实验组织从"两种 alpha 模式"换成"三组消融配置"。

双 Q 有效的前提与失效边界

取 min 的纠偏能力建立在一个前提上：两个网络的误差不能高度相关。有三件事会破坏这个前提。（1）共享网络主体、只分两个输出头：特征提取被共享，误差同源，min 与单 Q 几乎没有区别，消融表里的 |Q| 差距会消失。（2）批量太小且奖励噪声很高时，两个 Q 的差异主要来自随机批次的抖动，扰动幅度压不过共同的系统性误差，取 min 的收益随之变小。（3）τ 取太小导致目标严重滞后时，min 里的两个数都不是当下估计，纠偏仍在但价值爬升很慢，表现为 |Q| 平台正常而回报迟迟不动。训练最初几百步两个 Q 是同步初始化的，几乎完全相同，min 的偏差与单 Q 一致；过估计抑制要等两个网络真正分家之后才生效，这是评估早期差距时容易误判的地方。误差相关系数 ρ 的影响可以量化：独立高斯下 𝔼[max] ≈ σ√((1−ρ)/π)，σ=0.5 时 ρ=0 对应偏置 0.2821，ρ=0.5 降到 0.1995，ρ=0.9 只剩 0.0892（用 σ=1 的 200 万样本模拟，三种 ρ 的均值与公式偏差都在 0.001 以内）。共享主体就是把 ρ 推向 1 的极端操作，min 的纠偏量随之趋近于零。

消融实验的唯一变量原则

三组配置跑的是同一段更新代码，行为差异完全由构造时固化的两个布尔开关决定，训练循环里不出现任何配置字符串的分支。再加上每组开头 set_seed(args.seed)（初始权重、探索轨迹、回放池填充完全一致），"谁塌了"这件事才能干净地归因到被拆的柱子上。

关键代码与解读

片段 1：两个布尔开关，消融的构造时固化

        assert config in ALL_CONFIGS, f"未知配置: {config}"
        self.config = config
        self.use_double = config != "single_target"    # 是否有第二个 Q
        self.use_target = config != "double_notarget"  # 是否使用目标网络
        self.alpha = float(alpha)
        self.target_entropy = float(target_entropy)

        self.q1 = QNet(obs_dim, act_dim, hidden)
        self.q2 = QNet(obs_dim, act_dim, hidden) if self.use_double else None
        if self.use_target:
            self.q1_target = QNet(obs_dim, act_dim, hidden)
            self.q1_target.load_state_dict(self.q1.state_dict())   # 初始完全一致
            for p in self.q1_target.parameters():
                p.requires_grad_(False)                # 目标网络永远不训练
            if self.use_double:
                self.q2_target = QNet(obs_dim, act_dim, hidden)
                self.q2_target.load_state_dict(self.q2.state_dict())
                for p in self.q2_target.parameters():
                    p.requires_grad_(False)

解读：消融框架的全部机关都在构造函数里。（1）两个布尔开关把"三组配置"翻译成"建不建额外的网络"：single_target 不建 Q2，double_notarget 不建目标网络，不存在"建了但不使用"的浪费，也不存在训练中改行为的不确定性。（2）目标网络创建后立刻 load_state_dict 同步在线权重的初始值：这样"目标网络的问题"不会混入"初始值不同"的噪声。（3）requires_grad_(False) 明确冻结：目标网络只被软更新公式拖动，绝不进入任何优化器。少了这行虽然 forward 在 no_grad 里不会报错，但一旦有人误加进参数列表，消融实验的语义就被破坏了。

片段 2：自举的四种组合，写显式分支，不藏逻辑

        # ---------------- 1) 评论家 ----------------
        with torch.no_grad():
            next_act, next_logp = self.policy.sample(next_obs)
            if self.use_target:
                if self.use_double:
                    q_next = torch.min(self.q1_target(next_obs, next_act),
                                       self.q2_target(next_obs, next_act))
                else:
                    q_next = self.q1_target(next_obs, next_act)
            else:
                # 消融：直接用在线网络做自举（注意也在 no_grad 下，只借数值）
                if self.use_double:
                    q_next = torch.min(self.q1(next_obs, next_act),
                                       self.q2(next_obs, next_act))
                else:
                    q_next = self.q1(next_obs, next_act)
            target = rew + self.gamma * (1.0 - done) * (
                q_next - self.current_alpha * next_logp)

        q1_pred = self.q1(obs, act)
        if self.use_double:
            q2_pred = self.q2(obs, act)
            q_loss = F.mse_loss(q1_pred, target) + F.mse_loss(q2_pred, target)
            q_abs_mean = 0.5 * (q1_pred.abs().mean() + q2_pred.abs().mean())
        else:
            q_loss = F.mse_loss(q1_pred, target)
            q_abs_mean = q1_pred.abs().mean()

解读：自举分支的四种组合一次写全，这是消融实验里最重要的可读性投资。（1）use_target × use_double 的四个分支互斥且完整：双 Q 有目标（min of targets）、单 Q 有目标、双 Q 无目标（min of online）、单 Q 无目标。读者一眼能定位"这一组到底改了哪一项"。（2）整段包在 no_grad 里：无论是目标网络还是在线网络，自举只借数值、不借梯度，尤其 "double_notarget" 分支用的是在线网络，如果漏了 no_grad，梯度会从目标路径反向流回 q1/q2，实验就变成了另一种算法。（3）Q 损失对双 Q 是两份 MSE 之和（两个网络各自向同一目标回归），q_abs_mean 取两者平均作为统一的"Q 幅度"读数，三种配置的 |Q| 列因此口径一致、可以直接叠在同一张图上。

片段 3：策略损失的统一入口，min 口径必须一致

    def _q_values_online(self, obs: torch.Tensor, act: torch.Tensor):
        """返回 (min 或唯一) 在线 Q 值，用于策略损失。"""
        q1 = self.q1(obs, act)
        if self.use_double:
            q2 = self.q2(obs, act)
            return torch.min(q1, q2), q1, q2
        return q1, q1, None

    # ... 在 update() 的演员段：
        new_act, logp = self.policy.sample(obs)
        q_new, _, _ = self._q_values_online(obs, new_act)   # 与评论家同口径
        policy_loss = (self.current_alpha * logp - q_new).mean()

解读：_q_values_online 是个很小的封装，但它防住了一个经典的隐性 bug。（1）策略损失里的 Q 必须和评论家目标里的 Q 用同一种取法（双 Q 就都取 min）。如果评论家取 min、策略却拿 q1 单独求导，策略会朝"两个 Q 里更乐观的那个"走，过估计被从后门放了进来。（2）封装成函数后，"单 Q / 双 Q"的差异只在这一个地方处理：调用方不需要知道自己跑的是哪组配置。（3）返回值第二个、第三个是 q1、q2 原值，只是为调试与扩展留的门；主路径只依赖第一个元素。

片段 4：软更新与 target_gap 诊断

        # ---------------- 4) 目标网络软更新 ----------------
        if self.use_target:
            with torch.no_grad():
                for p, tp in zip(self.q1.parameters(), self.q1_target.parameters()):
                    tp.mul_(1.0 - self.tau).add_(self.tau * p)     # 原地混合
                if self.use_double:
                    for p, tp in zip(self.q2.parameters(), self.q2_target.parameters()):
                        tp.mul_(1.0 - self.tau).add_(self.tau * p)

        # 诊断：目标滞后量 = 在线 Q 与目标 Q 的平均绝对差（无目标网络时为 0）
        target_gap = 0.0
        if self.use_target:
            with torch.no_grad():
                gap = (self.q1(obs, act) - self.q1_target(obs, act)).abs().mean()
                target_gap = float(gap.item())

解读：两个小段，一个是机制、一个是仪表。（1）软更新必须原地操作：tp.mul_(1.0 - self.tau).add_(self.tau * p) 先乘再加，等价于 θ̄ ← (1−τ)θ̄ + τθ。如果写成 tp = (1-tau)*tp + tau*p，只是让 Python 名字重新绑定到一个新张量，模型里的参数根本没变，这是初学 SAC 最常踩的写法坑。（2）target_gap 用同一批 (s,a) 比较在线与目标网络的输出差：它衡量"目标滞后有多少"。新鲜训练时目标网络刚同步、gap≈0；训练中 gap 稳定在一个小值（如 0.3～1.0）说明跟随健康；无目标网络的配置里 gap 恒为 0，日志上这一列直接暴露"没有目标网络"。（3）诊断代码同样放在 no_grad 下，仪表盘不该干扰发动机。

完整可运行脚本（附录）：code/ch033.py

python code/ch033.py           # 三组消融依次训练：CPU 约 6–10 分钟
python code/ch033.py --quick   # 快速跑通：约 1 分钟
python code/ch033.py --configs double_notarget --max-steps 15000   # 单看发散

以实跑为准：double_target 稳定收敛到 −300 ~ −150；single_target 能学会但波动更大、|Q| 高出 30% 以上；double_notarget 的 |Q| 与 Q 损失很快指数式爆掉（|Q| 可到上万，Q 损失 1e+07 量级），评估回报跌回随机策略水平。三者排序通常在 15000 步内稳定复现。

常见坑

  • 两个 Q 网络共享主体只留两个头：那只是"一个网络两个输出"，误差高度相关，min 起不到纠偏作用。修复：两套 Q 必须从初始化就没有共享参数。
  • 目标网络忘了 requires_grad_(False)：参数若允许梯度、又误入优化器参数列表，会破坏软更新语义并浪费资源。修复：构造时明确冻结。
  • 软更新写成 tp = (1−tau)·tp + tau·p：这行是 Python 重新绑定，不会改到原地参数。修复：必须用 tp.mul_().add_() 或 tp.data.copy_()。
  • 消融实验忘记重置种子：若三组配置接着上一组的状态继续随机，差异里混入"运气"成分。修复：每组开头 set_seed，并把初始网络、探索策略都重置。
  • 自举分支漏写 no_grad：尤其"无目标网络"分支用在线网络时，梯度会从目标路径回流，算法语义改变。这是隐蔽的实现事故，训练仍会动、但测的不再是你要测的东西。

练习与思考

  1. 把 --configs 只留 single_target 与 double_target，并加大到 --max-steps 30000，对比两者 |Q| 轨迹的差距是否随训练扩大。★
    提示
    不用改代码。重点看两列 |Q| 的斜率，终值信息量小：单 Q 的偏离是"持续拉大"还是"稳定收敛到更高平台"。
  2. 把 --tau 改成 0.05，重跑 double_target 与 double_notarget。目标网络"更快跟随"是缓解还是加重了发散？★★
    提示
    τ 越大目标网络越接近在线网络，无目标网络的极端情况相当于 τ=1。观察 |Q| 与 target_gap 列的联动。
  3. 在 update() 的目标值里，把 torch.min(q1_target, q2_target) 换成 0.5 * (q1_target + q2_target) 组成 mean 版本，新加一个配置跑一次。★★
    提示
    仿照 double_notarget 的写法加一个 double_mean 配置：构造上仍是双 Q，只是目标组合换成均值。对比它与 single / min 的 |Q| 均可说明偏差方向。
  4. 写一个小脚本加载 double_target 的训练产物（runs/ch033/sac_double_target.pt），在固定一批 (s,a) 上输出 Q1、Q2 的差值分布，直观感受"从同一个初始权重出发的两个网络在训练后会分家到多大"。★★★
    提示
    用保存的 state_dict 重建 QNet，随机采样观测与动作喂进去，统计 |Q1−Q2| 的均值与分位数。差得太小说明两网络的训练样本重叠导致了同质化；差距太大则 min 的保守性过强。
  5. 把 --gamma 改成 0.9 重跑 double_notarget，检验"放大因子小于 1 就不发散"的预测；再把 double_target 的 γ 改成 0.995，观察 target_gap 与回报稳定性的变化。★★
    提示
    γ=0.9 时自举项权重只有 0.9，误差递归因子 γ(1+δ) 大概率低于 1，|Q| 应停止指数上涨；γ=0.995 时折扣更接近 1，目标滞后更容易被放大，target_gap 列的抬升是先兆信号。

小结

  • 双 Q 取 min 把"最大化带来的乐观误差"换成"保守误差"，切断策略钻空子的正反馈；它是有意为之的负偏差，不是缺陷。
  • 目标网络用滞后参数计算自举目标，把"追自己的尾巴"变成"追一个慢速靶子"；缺少它时 Q 值会指数级膨胀。
  • 消融的关键是控制变量：同一份实现 + 同一种子 + 同一超参数，只切换一个开关。
  • 判断发散的两个硬指标：|Q| 幅度指数式上涨、Q 损失同步爆炸；正常训练的 |Q| 会收敛到一个与回报量级匹配的平台。
