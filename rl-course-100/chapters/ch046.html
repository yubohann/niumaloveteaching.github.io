第二篇 · 离策略方法与 SAC

第 046 章：SAC的软更新系数τ调优

在 Pendulum-v1 上扫描四个软更新系数 τ（0.001 / 0.005 / 0.01 / 0.05），用达标步数衡量"学得多快"、用后期评估波动与 Q 损失变异衡量"学得多稳"，找出这条"速度-稳定性"曲线上的甜点。

  • 主题：目标网络 / 软更新（Polyak averaging）
  • 关键公式：θ̄ ← (1 − τ)·θ̄ + τ·θ，有效记忆窗口 ≈ 1/τ
  • 预计学时：50 分钟
  • 前置章节：第 045 章

学习目标

  • 理解目标网络与软更新（Polyak averaging）为什么是 off-policy 深度 RL 的标配稳定器。
  • 掌握 τ 的物理含义：它决定目标值的有效记忆窗口约为 1/τ 次更新。
  • 实现 τ 的可扫描训练流程，并引入两个稳定性指标：后期评估回报标准差、Q 损失变异系数。
  • 在 Pendulum-v1 上给出 τ 的推荐区间，能解释"τ 太大为什么会抖、太小为什么会慢"。
  • 会判断"稳定但学不动"与"学得快但抖"各自的症状，并给出下一步调参方向。

背景与动机

DDPG 用硬更新（每 N 步全量拷贝一次），SAC 用软更新（每一步只挪一小步）。软更新只有一个参数 τ，却同时控制两件事：目标值跟得多快（影响价值信息的传播速度）和目标值有多吵（影响回归目标的方差）。

本章把 τ 从 0.001 扫到 0.05，跨两个数量级，你会看到"太小则慢、太大则抖"的完整曲线。更重要的是学会用指标取代直觉来选它：达标步数回答"快不快"，后期评估波动与 Q 损失变异回答"稳不稳"，两者交叉处就是甜点区。这个过程也是后面章节的方法论模板：任何"看起来只是个小系数"的超参数，都可以通过一次受控扫描 + 两个互补指标，变成一张可以复用的决策表。

核心原理

1. 软更新公式

记在线网络参数为 θ，目标网络参数为 θ̄。每完成一次梯度更新后执行：

θ̄ ← (1 − τ)·θ̄ + τ·θ τ=0.005 意味着每一步目标网络只朝在线网络挪 0.5%

符号说明：τ 是软更新系数（本章扫描 0.001～0.05），θ 每一步都被梯度更新，θ̄ 只做"追踪"。把它展开看：目标参数是历史在线参数的指数加权平均，权重按 (1−τ)k 衰减。等效记忆窗口约为 1/τ 次更新，τ=0.005 对应约 200 次更新，τ=0.05 只有 20 次。窗口越长目标越平滑，但新的价值信息要过约 1/τ 步才能完全传入目标值，学得自然慢；窗口越短信息传播越快，但目标值本身带着每一步的噪声。

展开的推导只有两行：递推 θ̄t = (1−τ)θ̄t−1 + τθt 反复代入，得到

θ̄t = τ · Σk≥0 (1−τ)k · θt−k 所有历史权重的和恰好为 1（等比级数 τ/(1−(1−τ)) = 1），因此目标网络是"权重归一的历史平均"
数值例子：四个 τ 的记忆半衰期

记忆窗口 1/τ 是"平均寿命"，换成"半衰期"更直观：解 (1−τ)k = 0.5，得 k = ln2 / (−ln(1−τ))，即某次在线参数更新对目标的影响衰减一半所需的步数：

τ记忆窗口 1/τ半衰期（步）含义
0.0011000约 693极长记忆：目标几乎不动，信息传播最慢
0.005200约 138长记忆：平滑但有明显滞后
0.01100约 69中等记忆：常用区间
0.0520约 13.5短记忆：紧跟在线网络，噪声直接进入目标

解读：τ 从 0.005 提到 0.05，半衰期从 138 步缩到 13.5 步，缩短约 10 倍。这解释了实验里 τ=0.05 的"抖"：目标值只反映最近十几个梯度步的网络状态，而在线网络本身每步都在被批噪声推动，目标因此持续跳变；τ=0.001 的另一端，新信息要几百步才在半数权重上体现，达标自然慢。

1.1 数值算例：噪声压制倍数与稳态滞后

软更新的"平滑"可以精确量化。设在线网络每步的更新噪声独立、方差为 σ2，则目标网络参数在稳态下的方差为 σ2·τ/(2−τ)，噪声标准差被压到 √(τ/(2−τ)) 倍。代入四档 τ：0.001 压制约 44.7 倍，0.005 约 20 倍，0.01 约 14.1 倍，0.05 约 6.2 倍。作为对照，硬更新（每 N 步拷贝一次）的噪声压制倍数恒为 1，它只提供"陈旧"而不提供"平滑"；单看噪声这一项，τ=0.005 的软更新比硬更新安静约 20 倍。

平滑的代价是滞后，同样可以算。若在线参数以恒定速度 v 漂移，目标网络的稳态滞后约为 v(1−τ)/τ≈v/τ。取 v=0.01（每步移动 0.01），τ=0.005 的滞后约 1.99，τ=0.05 只落后 0.19；而每 200 步硬拷贝的平均滞后为 100×v=1.0 的参数落后量。这解释了两端实验画像为何如此不同：τ=0.001 把噪声压到约 2%，但新信息要几百步才进入目标，达标最慢；τ=0.05 滞后很小而噪声很大，"抖"的根源不在跟随慢，而在目标本身带着在线网络的即时波动。

用滤波器的语言小结一下：软更新本质上是一阶低通，单位步长下的截止频率约等于 τ，周期短于约 2π/τ 步的波动被明显衰减。τ=0.005 时截止周期约 1257 步，目标只保留慢趋势；τ=0.05 时约 126 步，几十步尺度的波动都能穿透进目标值。频率视角与半衰期视角给出同一张排序，只是度量单位不同。

2. 为什么不能没有目标网络

SAC 的目标值可以写成：

y = r + γ · 𝔼a′~π[ minj∈{1,2} Q̄j(s′, a′) − α·log π(a′|s′) ]

如果 Q̄ 与 Q 完全同步（τ=1，即没有目标网络），y 会随每一步更新剧烈变化，Q 回归的"标签"永远在动；更糟的是，策略又朝着 Q 大的方向更新，Q 影响 y、y 反过来影响 Q，形成正反馈，很容易发散。目标网络提供了一条"低通滤波"，切断高频的自激震荡：标签以 1/τ 的窗口缓慢演化，回归问题在局部近似平稳。

用信号的角度再讲一遍：把每步更新的噪声看成高频成分，软更新相当于一个一阶低通滤波器，截止频率与 τ 成正比。τ=0.005 时，单个梯度步的噪声只有 0.5% 权重进入目标，需要约 200 步累积才能改变目标值；τ=0.05 时，单个步的权重升到 5%，目标网络几乎跟随在线网络的即时波动。低通滤波的代价是相位滞后：τ 越小，目标落后在线网络越多，价值信息的传播延迟约 1/τ 步。稳定性与速度这对矛盾在同一个参数上，无法同时取到两端，这正是本章实验要量化的权衡。

3. 两个稳定性指标

本章用两个量把"稳不稳"写下来：

评估波动 = std( 最后 4 次评估回报 )   ·   Q 损失变异 = std(q_loss) ÷ mean(q_loss) 评估波动反映"策略是否在后期来回跳"；Q 损失变异反映"回归目标有多吵"

注意评估波动也受环境随机性影响（5 个回合的采样噪声），所以判断 τ 的走向要看变异系数的趋势：τ 增大时 Q 损失变异通常单调上升；τ 过小时达标步数明显变大。两个信号交叉的位置就是甜点区。Q 损失取最后 2000 次更新的统计，早期数值大、波动剧烈，混进来会掩盖后期的真实差別。

变异系数的读法可以举个例子：q_loss 均值约 10 时，std 为 1 对应变异系数 0.1，std 为 3 对应 0.3。τ=0.001 组的典型值在 0.1 附近，τ=0.05 组常在 0.3 以上，差距足以跨过种子噪声。需要注意它只度量"回归目标有多吵"，不直接等于"策略水平有多好"，必须与达标步数、评估回报联合解读。

4. 四档 τ 的预期画像

τ达标速度后期评估 stdQ 损失变异典型风险
0.001最慢，达标步数最大最低约 0.1价值信息滞后，回报长期偏低
0.005中等低约 0.12～0.15几乎没有明显风险，综合均衡
0.01最快或接近最快中等约 0.15～0.2偶发小幅震荡
0.05不稳定，常无法稳定达标最高0.3 以上自举震荡，评估回报断崖

读表顺序：先用"Q 损失变异随 τ 单调上升"确认机制方向，再看达标步数选速度，最后用后期评估 std 检查稳定性。若某个 τ 的三列读数互相矛盾（例如变异很高但 std 很低），先怀疑评估样本太少，把评估回合数提高再复跑。评估 std 的噪声底也可以估算：每个评估点只跑 5 个回合，若单回合回报的标准差约 40，点均值的标准误差约 40/√5≈18；后 4 个评估点的 std 要超过约 25，才值得当作"真实波动"来解读，否则更像采样噪声。

5. 与其他超参数的交互

τ 不是孤立的旋钮，它与三个量存在可预测的交互。其一，学习率：在线网络每步移动越大（lr 越大或批量越小），目标值需要吸收的噪声越大，最优 τ 通常变小；练习第 3 题把 lr 提到 1e-3，预期甜点从 0.01 向左移动。其二，数据新鲜度：回放池越小或更新频率越高，目标要跟上的分布变化越快，τ 的需求变大；第 043 章的 noreplay 配置本质上要求更快的跟随。其三，双 Q 的差异度：τ 过小会让两个目标网络长时间停在各自的旧值上，min 的诊断读数滞后；τ 过大则两个目标几乎同步，双 Q 分散偏差的效果被压缩。三者指向同一个原则：τ 应与"目标需要跟随的分布变化速度"匹配，照抄论文默认值不如照这个原则估一遍。经验上，lr 每提高约三倍，把 τ 减半通常能找回相近的稳定性，这条来自低通近似的粗规则可以当作扫描 τ 时的第一个猜测。

实现思路与设计

数据流

每个 τ 跑一遍完整训练：采样 → 均匀回放池 → 每步一次 update(batch, args, tau)（τ 由参数传入）→ 每 2000 步评估、记录评估回报与 Q 损失变异 → 16000 步结束。四个 τ 用同一随机种子串行训练，每次重新初始化网络、优化器与回放池，保证对照组只差 τ 一个变量。结束维度：达标步数（速度）、后期评估 std 与 Q 损失变异（稳定性）。

一个小的工程细节值得单独说明：τ 由函数参数传入（不经全局配置），这是"同一进程扫多组参数"的标准写法。若 τ 写在 args 里、训练循环又复用同一个 agent，扫描时必须反复修改全局配置，既容易漏改也容易被缓存值欺骗；参数化之后，train_tau(tau) 的每次调用都是自包含的，扫描循环只是外层的一个 for。

模块划分

组件职责关键点

--max-steps16000每个 τ 的预算；比单实验章节略短以控制总时长

与前一章的差异点

  • 第 045 章改温度系数（策略侧探索）；本章只改目标网络的跟随速度 τ，探索配置恢复为标准自动 α。
  • update() 的 τ 从 args.tau 变成显式参数，服务"一个进程扫多个 τ"的需求。
  • 新增两个稳定性指标（后期评估 std、Q 损失变异），前面章节没有这类训练健康度统计。
  • 汇总口径从"覆盖熵"换成"速度-稳定性"权衡表。

关键代码与解读

片段 1：唯一自变量的那一行

def soft_update(net: nn.Module, target: nn.Module, tau: float) -> None:
    for tp, p in zip(target.parameters(), net.parameters()):
        tp.data.mul_(1.0 - tau).add_(tau * p.data)
        # 就地运算：目标网络不接收梯度，.data 避免建计算图、也避免新建张量

    # 在 SAC.update 的末尾：
        # 本章的关键一行：tau 由外部传入，其余算法与第 045 章一致
        with torch.no_grad():
            soft_update(self.q1, self.q1_target, tau)
            soft_update(self.q2, self.q2_target, tau)

解读：（1）tp.data.mul_(1.0 - tau).add_(tau * p.data) 是本章实验的全部"自变量"。用 .data 就地写有两个理由：目标网络不参与反向传播（requires_grad_(False)），且就地操作避免每步新建上百个张量。（2）千万不要写成 tp = (1-tau)*tp + tau*p，那只是重新绑定循环里的局部变量，目标网络根本不会改变，训练会"看起来稳定"但完全学不动。（3）τ 作为参数传入，不读 args，让同一进程里的扫描循环可以复用全部代码路径；两个 Q 的目标网络必须用同一个 τ同步更新，避免双 Q 的记忆窗口错位。

片段 2：train_tau 的记录与诊断

def train_tau(tau: float, args):
    set_seed(args.seed)  # 每个 tau 同种子，控制变量
    env = make_env(args.env, args.seed)
    eval_env = make_env(args.env, args.seed + 100)
    obs_dim = env.observation_space.shape[0]
    act_dim = env.action_space.shape[0]
    action_scale = float(env.action_space.high[0])
    agent = SAC(obs_dim, act_dim, action_scale, args)
    buffer = ReplayBuffer(args.buffer_size, obs_dim, act_dim)

    obs, _ = env.reset(seed=args.seed)
    ep_ret = 0.0
    ep_returns = []
    eval_returns = []      # 按评估顺序保存的评估回报
    q_loss_hist = []       # 每次更新的 q_loss，用于算变异系数
    solved_at = None
    t_start = time.time()
    print(f"\n===== tau = {tau}：开始训练（有效记忆窗口 ≈ {1.0 / tau:.0f} 次更新） =====")

    for step in range(1, args.max_steps + 1):
        if step <= args.start_steps:
            action = env.action_space.sample()
        else:
            action = agent.act(obs, deterministic=False)
        next_obs, rew, terminated, truncated, _ = env.step(action)
        buffer.add(obs, action, rew, next_obs, float(terminated))
        obs = next_obs
        ep_ret += rew

        if terminated or truncated:
            ep_returns.append(ep_ret)
            ep_ret = 0.0
            obs, _ = env.reset()

        if step % args.update_every == 0 and buffer.size >= args.start_steps:
            stats = agent.update(buffer.sample(args.batch_size), args, tau)
            q_loss_hist.append(stats["q_loss"])

解读：（1）函数开头 set_seed + 重建网络/回放池：每个 τ 都是一次"干净的重复实验"，计算图与优化器状态全部重置，这正是控制变量要求。（2）q_loss_hist 每次更新都追加，评估点用它算滑动窗口的变异系数；不存这个序列就只能看瞬时值，噪声太大。（3）日志第一行把记忆窗口 1/tau 直接打出来，把参数翻译成物理含义，τ=0.005 的那行会显示"≈ 200 次更新"。

片段 3：把稳定性折算成两个数字

        if step % args.eval_every == 0:
            eval_ret = evaluate(agent, eval_env, args.eval_episodes)
            eval_returns.append(eval_ret)
            recent20 = np.mean(ep_returns[-20:]) if ep_returns else float("nan")
            q_cv = float(np.std(q_loss_hist[-1000:]) / (np.mean(q_loss_hist[-1000:]) + 1e-9))
            print(f"[tau={tau}] 步数 {step:6d} | 近20回合回报 {recent20:8.1f} | "
                  f"评估 {eval_ret:8.1f} | Q损失变异 {q_cv:5.3f} | alpha {stats['alpha']:.3f}")
            if solved_at is None and eval_ret >= args.target_return:
                solved_at = step
                print(f"[tau={tau}] 首次达到评估回报 {args.target_return}（步数 {step}）")

    elapsed = time.time() - t_start
    final_eval = evaluate(agent, eval_env, args.eval_episodes)
    all_evals = eval_returns + [final_eval]
    best_eval = max(all_evals)
    tail = all_evals[-4:]                 # 最后 4 个评估点衡量后期稳定性
    eval_std = float(np.std(tail))
    q_cv = float(np.std(q_loss_hist[-2000:]) / (np.mean(q_loss_hist[-2000:]) + 1e-9))

解读：（1）q_cv = std ÷ mean 是变异系数：它做无量纲化，让不同量级的 q_loss 能横向比较，否则 τ=0.05 与 τ=0.001 的绝对损失差异会干扰判断。（2）评估时打印最近 1000 次更新的变异（跟随训练进程），结束时打印最近 2000 次（更平滑），两个窗口分别服务"过程监控"与"最终对比"。（3）tail = all_evals[-4:] 取最后 4 个评估点（含最终评估）算 std：这正是"后期还抖不抖"的操作化定义。（4）solved_at 用"首次不低于 −400"判定，注意单点波动可能带来 ±2000 步的时间抖动，结论应看四个 τ 的相对次序与量级差。

预期：τ=0.001 学得最慢（达标步数最大）但后期最稳；τ=0.05 后期明显抖动，Q 损失变异比其他配置高 50% 以上，常常无法稳定达标；τ=0.005 与 0.01 在速度与稳定性之间最均衡。不同种子下具体数值有波动，但"Q 损失变异随 τ 单调上升"基本稳定复现；τ=0.05 的评估回报若出现断崖下跌再缓慢回升，就是自举震荡的典型画像。以实跑为准。

常见坑

  • 把 τ 当作"越小越稳、永远更好"：τ 太小会让价值信息滞后，表现为达标步数翻倍、Q 值长期偏保守。它是速度与稳定性的折中参数，不是单调指标。
  • 软更新写成了重新绑定：tp = (1-tau)*tp + tau*p 只改局部变量，目标网络永远停在初始权重，训练退化成固定目标回归，看起来"很稳"但学不动。
  • 忘了目标网络不接收梯度：漏掉 requires_grad_(False) 时反传会经过目标网络回传到在线网络，把慢速副本也拖进梯度链，τ 的实验结论被污染。
  • 用单次评估的尖峰判断性能：Pendulum 评估方差大，τ 之间的差距常被种子噪声淹没。至少在两个种子下重复，或把 --eval-episodes 提高到 10。
  • 只更新一个目标网络：q1_target 动了、q2_target 忘了动（或传了不同 τ），min 双 Q 的两个分支记忆窗口不一致，诊断量会给出自相矛盾的"稳定"读数。修复：两次 soft_update 用同一 τ、同一处调用。

练习与思考

  1. 把 --taus 改成 0.1 单跑一次，观察是否出现发散或评估回报断崖，记录 Q 损失变异的量级。★
    提示
    重点看 q_loss 是否出现数量级跳变，这是自举目标噪声过大的直接证据；再看评估回报是否"不降反升"。
  2. 先预测再验证：把软更新改成"每 200 步硬拷贝一次"，与 τ=0.005 对比达标步数与稳定性，两种记忆窗口的本质差别是什么？★★
    提示
    硬更新等价于锯齿形的 0～200 步记忆窗口。实现：agent.update(..., 0.0) 并在 step % 200 == 0 时 q1_target.load_state_dict(q1.state_dict())（两个目标网络都要拷）。
  3. 同时把 --lr 改成 1e-3，重复四个 τ 的扫描。学习率变大后，最优 τ 往哪边移动？先写预测再跑。★★
    提示
    学习率越大，在线网络每步变化越大，目标网络跟得快就更吵。猜想：最优 τ 变小（更依赖平滑）。用两组汇总表对比验证。
  4. 给训练加一个"目标漂移速率"监控：每次评估对固定 128 个 (s,a) 探针求目标 Q 的 L2 变化量，除以间隔步数。用它替代 Q 损失变异，结论是否一致？★★★
    提示
    探针批次在训练开始时抽一次存下；每次评估前 no_grad 前向目标 Q 并缓存。这个指标直接度量"目标漂移速度"，比 q_loss 更贴近 τ 的物理含义。
  5. 把本章代码与第 045 章的 explore 配置组合（固定 α=0.5），重扫 τ。强探索下目标网络的跟随速度需求会变大还是变小？★★★
    提示
    探索越强，回放池数据分布变化越快，目标网络需要更快跟上。把 ch045 的 MODE_CONFIG 逻辑搬过来固定 α=0.5，再跑 0.001/0.01/0.05 三档对比。

小结

  • 目标网络是打断"自举目标自激"的稳定器；软更新用 θ̄ ← (1−τ)θ̄ + τθ 把目标变成历史参数的指数平均，权重之和恰为 1。
  • τ 的记忆窗口约为 1/τ 次更新、半衰期约为 0.69/τ 步：τ 小则稳但慢，τ 大则快但吵，0.005～0.01 是连续控制任务的常用甜点。
  • 稳定性可以用后期评估 std 与 Q 损失变异两个指标量化；后者对 τ 变化更敏感、更早报警，读法要与达标步数联合使用。
  • 本章把 τ 从常量改成扫描变量，验证了"速度-稳定性"权衡曲线的存在；扫描时每次都要重置网络、种子与回放池。
  • 四个 τ 的半衰期分别约为 693、138、69、13.5 步：τ 越大记忆越短、目标越吵，实验里 Q 损失变异随 τ 单调上升与这个换算一致。
  • 低通滤波的代价是相位滞后：稳定性与信息传播速度共用同一个参数，选 τ 就是在两者之间取折中，没有单方向的"更优"。
  • 下一章深入网络结构内部：批量归一化层会怎样影响 Q 网络的训练，注意它和回放池的非独立同分布数据并不天然兼容，实验里会出现"训练指标好、评估崩"的特殊现象。
