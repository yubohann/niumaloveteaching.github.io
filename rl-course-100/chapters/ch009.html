第一篇 · 策略梯度与 PPO

第 009 章：PPO的时序差分与蒙特卡洛混合

把 TD(0)、n-step、GAE(0.95)、蒙特卡洛四个优势估计器放到同一批固定轨迹上量方差、算相关，再分别训练 CartPole 对照，优势估计的偏差-方差权衡第一次被完整量化。

  • 主题：优势估计谱系 / 偏差-方差权衡
  • 关键公式：Â(n)t = Σl<nγlrt+l + γnV(st+n) − V(st)
  • 预计学时：55 分钟
  • 前置章节：第 008 章

学习目标

  • 理解 TD(0) 与蒙特卡洛是优势估计谱系的两个端点，n-step 与 GAE 是它们之间的两种插值方式。
  • 实现固定 n 步优势估计，正确处理"n 步内终止"与"数据不够 n 步"两类边界。
  • 设计不训练的估计器诊断：同一批轨迹上比较优势标准差、与 MC 优势的相关系数与平均绝对偏差。
  • 分别用四种估计器训练 PPO，比较首达 400 步数、优势尺度与最终成绩。
  • 能根据任务特征选择估计器：短回合任务怎么选、长回合任务为什么要避开纯 MC。

背景与动机

第 002 章扫描了 GAE 的 λ，看到的是"连续调节旋钮"；但优势估计还有另一种更贴近工程实现的形态，固定 n 步回报。它不玩指数加权，直接把未来 n 步的奖励加起来、再接一个价值函数 bootstrap。n=1 就是 TD(0)，n 等于回合长度就是蒙特卡洛，中间是离散的台阶。很多实现（包括分布式 PPO）选用 n-step，因为它的语义更好写进回放/异步管线。

问题也随之而来：n 该取多少？"偏差大一点但方差小"和"无偏但噪声大"到底差多少？只靠训练曲线比较既贵又慢。本章先把估计器从训练里拆出来，在同一批数据上直接量：优势的标准差、与无偏参照（MC）的相关系数、平均绝对偏差。度量完再做训练对照，两段证据互相印证。

核心原理

1. n 步回报与优势

从 t 出发向前看 n 步，得到 n 步回报，再接价值函数近似剩下的一切：

Rt(n) = Σl=0n−1 γl rt+l + γn V(st+n)　（若中途终止则去掉 bootstrap）
Ât(n) = Rt(n) − V(st)

n=1 时 Ât = δt（单步 TD）；n→∞ 时退化为 Gt − V(st)（蒙特卡洛）。GAE 与 n-step 的关系是"指数加权平均"：

ÂGAE(λ)t = (1 − λ) Σn=1∞ λn−1 Ât(n) 所以 GAE 是"所有 n 步优势的 λ 加权和"，它把 n 的选择变成了一条平滑曲线

2. 偏差从哪里来：自举误差

用 V(st+n) 近似"剩余回报"会引入价值函数的误差。若价值函数误差为 ε，n 步优势的偏差约为 γn·ε（被自举的部分按折扣衰减），所以 n 越大偏差越小；n=∞（MC）没有自举，偏差为零（在折扣回报的定义下）。代价是方差：

Var[Ât(n)] ≈ σ2 · Σl=0n−1 γ2l = σ2 · (1 − γ2n) / (1 − γ2) 奖励噪声 σ2 被逐层累加；n 越大方差越接近 MC 的上限 σ2/(1−γ2)

这两个公式合起来就是一句工程经验：价值函数靠谱时用小 n（低方差），价值函数不靠谱或奖励有强长程结构时用大 n（低偏差）。方差公式的推导同样直接：假设奖励噪声独立、方差同为 σ2，则 Var[Σl<n γl rt+l] = σ2Σl<n γ2l，几何级数求和即得上式；n→∞ 时上限为 σ2/(1−γ2)，γ=0.99 时约等于 50.25σ2，即单条轨迹的 MC 优势噪声可放大 50 倍，这就是"无偏的代价"。

偏差还可以推得更细。把 Bellman 等式向前迭代 n 次得到恒等式 Vπ(st) = E[Σl<n γl rt+l + γn Vπ(st+n)]，它说明若价值函数完全准确，n 步估计对任何 n 都无偏；把 V = Vπ + ε 代入并取期望，偏差等于 γnE[ε(st+n) | st] − ε(st)。当 ε 在各状态上同号（例如整体高估同一个常数 c），偏差就是 (γn−1)c，按 γn 收缩：γ=0.99 时 γ4≈0.961、γ20≈0.818、γ40≈0.669。这条推导同时标出边界：折扣是偏差稀释的机制，γ 越接近 1 稀释越慢；γ=1 时 γn≡1，增大 n 完全不降偏差，只剩方差账单。

GAE(0.95) 在同一模型下的方差是 8.66σ2（标准差 2.94σ），落在 n=4 与 n=8 之间；把 λ 调大会连续移动这个位置（λ=0.999 时 45.7σ2，逼近 MC 的 50.25σ2）。算它要多一步：GAE 是各阶 n 步优势的线性组合，方差由两两协方差求和，Cov(Â(m), Â(n)) = σ2(1−γ2min(m,n))/(1−γ2)，两条序列共享前 min(m,n) 步奖励，共享越多相关越强。用它读表：想把优势噪声压到 MC 的三分之一以下，等效回看长度要控制在 20 步以内。

数值例子：同一状态上四种优势逐一算出

设 γ=0.99，一段轨迹的奖励 r0=r1=r2=1，第 3 个奖励后回合终止；价值估计 V(s0)=10、V(s1)=10.5、V(s2)=11。四种估计器给出的 Â0：

TD(0)：δ0 = 1 + 0.99×10.5 − 10 = 1.40。

n-step(2)：[1 + 0.99×1 + 0.992×11] − 10 = 12.77 − 10 = 2.77。

n-step(≥3) 与 MC：走到终止为止，[1 + 0.99 + 0.992] − 10 = 2.98 − 10 = −7.02。

GAE(0.95)：按 (1−λ)λn−1 权重合成：n=1 权重 0.05、n=2 权重 0.0475，n≥3 的剩余权重 0.9025 全部对应 MC 的 −7.02。合成结果 ≈ 0.05×1.40 + 0.0475×2.77 + 0.9025×(−7.02) ≈ −6.13。

解读：真实回报只有 2.98，而三条价值预测都在 10 以上，说明价值函数高估严重。TD(0) 只看到 1.40 的"好消息"，完全没察觉高估；n=2 部分察觉；MC 与 GAE 把 −7 级别的信号完整暴露出来。这个例子一次性演示了偏差随 n 衰减、以及"回合在窗口内终止时 GAE 迅速向 MC 靠拢"两件事。

拓展算例：λ 扫描，观察优势如何滑向 MC

仍用上面的轨迹（精确值 Â(1)=1.395、Â(2)=2.7711、n≥3 与 MC=−7.0299）。由于回合已终止，所有 n≥3 的项都等于 MC，GAE 只剩三个互不相同的数在加权：c1=1−λ、c2=(1−λ)λ、剩余权重 λ2 全给 −7.03。于是 ÂGAE(λ) = −7.03 + (1−λ)×8.42 + (1−λ)λ×9.80。代入几档：λ=0 得 1.40（与 TD(0) 一致）；λ=0.5 得 −0.37；λ=0.95 得 −6.14；λ→1 时前两项权重趋于 0，极限是 −7.03。λ 只用两个加权系数就把估计值从 1.40 带到了 MC 附近。

这条曲线并不严格单调：在 λ≈0.07 处它比 λ=0 高约 0.05，因为 Â(2)=2.77 比 Â(1)=1.40 更大，少量掺入先抬升再压低。幅度小到可以忽略，但机制值得记住：GAE 曲线的形状由各阶数值的相对大小与权重曲线共同决定，换一段轨迹，这点非单调可能换位置、换方向。

3. 用相关系数当"偏差探测器"

MC 优势不是真值（它是单样本估计），但它对"整条轨迹的回报"无偏。因此把 MC 当作参照系：一个估计器与 MC 的相关性越高，说明它捕捉的长期方向越准确；标准差越大，说明它的噪声越大。两个数字的相对关系（TD(0) 低相关低方差、MC 高相关高方差）就是本章诊断表要展示的核心现象。

4. 两个边界的定量判据

边界一：n 超过回合平均长度时的退化。若 n ≥ 平均回合长度 L̄，多数样本在窗口内就终止了，"n 步 bootstrap"在它们身上根本不发生，估计器实际退化成 MC：方差接近上限，而 n 带来的那点低偏差收益并不存在（终止样本本来就无自举偏差）。定量判据是看 "n 步内未终止的比例"：CartPole 随机策略平均每回合约 22 步，n=4 时大多数窗口未终止，bootstrap 生效；n=32 时绝大多数窗口内终止，与 MC 已经没有区别。工程取值的经验区间是 n 取 L̄ 的 1/10 到 1/2：任务越长、越大；短回合任务上大 n 只有成本没有收益。

边界二：诊断结论的统计噪声。诊断表只用 4096 步的数据，相关系数本身带标准误，量级约 (1−r2)/√T：T=4096 时，r=0.3 附近的标准误约 0.014，r=0.9 附近约 0.003。也就是说表里 0.31 与 0.68、0.68 与 0.92 这些差距远超采样噪声，"次序"结论可信；反过来，若两个估计器的相关系数只差 0.02，不要据此下结论，应把诊断步数加倍再比。这条判据同样适用于训练日志里的优势 std 对比。

把理论倍数（1.00 / 1.97 / 2.94 / 7.09）与诊断表实测（约 1.4 / 3.1 / 5.9 / 8.7）对照：次序完全一致，比例并不相等。理论表假设奖励噪声独立同分布、价值误差固定；CartPole 单条轨迹的奖励高度相关（杆角每步延续），价值网络误差也随状态起伏，这两点都会让长窗口估计器的实测方差比简化模型更大。分工是清楚的：理论表解释"为什么排序如此"，实测表回答"这台任务上选谁"。

读诊断表可以归纳成三条规则：其一，std 与 corr 同步上升时，说明估计器是在"用噪声换信息"，属于正常的偏差-方差移动；其二，若某估计器 corr 高但std 异常大（超过 MC 的量级），大概率是尾部边界处理有问题，应回到 compute_nstep 检查终止与 bootstrap 分支；其三，若 corr 接近 MC 但训练反而更慢，问题通常出在优势尺度过大导致裁剪比例飙升，应先标准化再对照训练曲线，急着换估计器解决不了尺度问题。

为什么要把采样和优势计算拆开

collect_raw 返回的是 raw 字典（obs/act/logp/rew/val/term/last_value），raw_to_batch 才做优势计算。这样拆开有两个好处：诊断阶段可以对同一份数据依次调用四个估计器，保证"数据完全相同、只有估计器不同"；训练阶段可以把"采样"和"损失准备"分开测试。这是实验脚本值得养成的结构。放在全书视角看，它还有第三个回报：解析优势的代码从采样循环里剥离后，每个估计器的实现都可以单独写单元测试，例如构造一段已知终止位置的假数据，断言尾部样本的优势等于手算值。

关键代码与解读

片段 1：固定 n 步优势的两个边界

def compute_nstep(rewards, values, terminateds, last_value, n: int, gamma: float):
    """固定 n 步优势：Â_t = Σ_{l<n} γ^l r_{t+l} + γ^k V(s_{t+k}) − V(s_t)。"""
    T = len(rewards)
    adv = np.zeros(T, dtype=np.float32)
    for t in range(T):
        g = 0.0
        discount = 1.0        # γ^l：逐项递乘；bootstrap 折扣取 γ^k（实际步数）
        k = 0
        bootstrap = True
        while k < n and t + k < T:
            g += discount * rewards[t + k]
            discount *= gamma
            k += 1
            if terminateds[t + k - 1]:     # 命中真实终止：不 bootstrap，直接停
                bootstrap = False
                break
        if bootstrap:
            next_v = values[t + k] if t + k < T else last_value
            g += discount * next_v         # 数据不足 n 步时，用 last_value 收尾
        adv[t] = g - values[t]
    return adv

解读：前向展开比 GAE 的后向递推更"直译"，但边界更多，是本章最容易出 bug 的地方。（1）while 的两个条件对应两种"走不满 n 步"：k < n 是正常上限，t + k < T 是数据尾部。（2）终止检查放在累加奖励之后、继续累加之前：terminateds[t + k - 1] 表示"第 k 个被累加的奖励来自终止转移"，此时序列到此为止，bootstrap = False。若忘了这个分支继续加 V，就会在终止边界凭空引入一个与当前回合无关的价值。（3）bootstrap 用 discount（即 γk，按实际步数）：k 是实际走了几步，尾部数据只有 k 步时折扣必须按实际步数算，写成固定的 γn 会系统性放大尾部样本的优势。（4）values 与 last_value 的三目选择：序列内部用快照 V(st+k)，出界用采样结束后的 bootstrap 值。

片段 2：统一入口，四个估计器，一个接口

def compute_advantages(mode, rewards, values, terminateds, last_value,
                       gamma: float, lam: float, nstep: int):
    """按模式计算优势。mc 等价于 GAE(λ=1)。"""
    if mode == "td":
        return compute_nstep(rewards, values, terminateds, last_value, 1, gamma)
    if mode == "nstep":
        return compute_nstep(rewards, values, terminateds, last_value, nstep, gamma)
    if mode == "gae":
        return compute_gae(rewards, values, terminateds, last_value, gamma, lam)
    if mode == "mc":
        return compute_gae(rewards, values, terminateds, last_value, gamma, 1.0)
    raise ValueError(f"未知优势估计模式: {mode}")

解读：（1）四个分支里有两个值得注意的等价关系：td 就是 nstep(n=1)，不需要再写一份单步实现；mc 就是 GAE(λ=1)，第 002 章验证过的端点恒等式在这里被直接复用为一种"实现选择"。（2）为什么 mc 不单独写"手工折扣累加"：GAE(λ=1) 的递推在无终止处与折扣累加完全等价，且终止掩码、尾段 bootstrap 的处理已经被验证过；复用它比再写一遍更不容易错。（3）raise ValueError：模式名打错要立刻失败；若默默返回 None，训练会在 adv.mean() 处才报一个难懂的错。（4）统一接口让"切换估计器"变成字符串参数，诊断、训练两条路径都用它。

        # 相关系数衡量“方向一致性”；std 接近 0 时返回 nan 避免除零
        corr = float(np.corrcoef(adv, mc)[0, 1]) if np.std(adv) > 1e-8 else float("nan")
        mad = float(np.mean(np.abs(adv - mc)))     # 与 MC 的平均绝对差
        big = float(np.mean(np.abs(adv) > 5.0))    # 大优势占比：噪声的另一种度量
        print(f"{name:>10} | {np.mean(adv):>10.3f} | {np.std(adv):>10.3f} | {corr:>10.3f} | "
              f"{mad:>14.3f} | {big:>10.3f}")

解读：（1）raw 只采集一次：这是"同批量对比"的关键，否则不同估计器面对不同的数据，"差异"里混进了采样噪声。（2）四个统计量各自回答一个问题：std 量噪声规模；corr 量方向一致性（偏差的代理）；mad（与 MC 的平均绝对差）量"整体差异"，它对尺度敏感；big（|Â|>5 占比）量尾部厚度，直接对应"会不会有超大梯度样本"。（3）np.std(adv) > 1e-8 的保护：估计器完全退化时相关系数无定义，返回 nan 比抛异常更适合表格场景。（4）注意诊断用的策略是随机初始化的网络（不是训练好的），这是故意的：随机策略下优势的差异最明显，而且完全可复现。

片段 4：训练循环，raw 到 batch 的唯一接口

    while total_steps < args.max_steps:
        raw, ep_returns, obs_t = collect_raw(env, net, args.steps_per_update, obs_t, device)
        total_steps += args.steps_per_update
        n_updates += 1
        all_returns.extend(ep_returns)

        batch = raw_to_batch(raw, mode, device, args.gamma, args.lam, args.nstep)
        stats = ppo_update(net, optimizer, batch, args)
        adv_stds.append(batch["adv_raw_std"])   # 原始优势尺度：估计器差异的直接读数
        kls.append(stats["approx_kl"])

        if reached_at is None and len(all_returns) >= 100 and np.mean(all_returns[-100:]) >= args.stage_reward:
            reached_at = total_steps

        if n_updates % 5 == 0 and len(all_returns) >= 20:
            print(f"  [{mode:5}] 步数 {total_steps:7d} | 近20均 {np.mean(all_returns[-20:]):7.1f} | "
                  f"优势std {batch['adv_raw_std']:6.2f} | KL {stats['approx_kl']:.4f}")

解读：（1）采样与优势计算通过 raw → raw_to_batch 解耦：训练循环里只有一行"按模式转换"，加一个新估计器不用动循环。（2）adv_raw_std 在 raw_to_batch 里算出（标准化之前），训练循环只做汇总，与第 002 章的设计一致，保证"优势尺度"这个指标在全书里口径统一。（3）日志每 5 次更新打印一次优势 std：td 组通常 2～6、gae 组 5～12、mc 组 8～20，这个排序在训练过程中肉眼可见，与诊断表的结论互相印证。（4）仍然只记录不提前停：四个估计器要跑满同一预算，末段成绩才有可比性。

常见坑

  • n-step 的终止处理写错：在 t+k−1 终止时应当只累加前 k 步奖励、不做 bootstrap；若仍加上 V(st+k)，会在终止边界引入一个凭空的价值。这类 bug 在训练曲线上表现为"回报高原"，很难察觉。
  • 尾段 bootstrap 把折扣写成固定 γn：rollout 尾部不足 n 步时，折扣必须按实际步数 k 计算，否则尾部样本的优势被系统性放大或缩小。
  • 用优势 std 直接比较不同任务/不同标准化设置：本章的 adv_std 是标准化之前的原始尺度，任务奖励尺度一变就没有可比性。跨任务比较请用"std / |mean|"或直接看训练指标。
  • 把 MC 当成优势真值：MC 优势本身也是单样本估计，方差很大；诊断表里的相关系数说明的是"方向一致性"，不是"正确性"。真正的无偏参照需要多条轨迹平均。
  • 诊断时忘了单独播种：诊断用的网络与数据必须固定种子，否则每次运行表格都变，"对照"无从谈起；本章用 seed + 777 与训练阶段隔离。

小结

  • TD(0) 与蒙特卡洛是优势估计谱系的两个端点；n-step 是离散插值，GAE 是 n-step 的指数加权平均，二者都能在两端之间滑动。
  • 偏差来自价值自举，随 γn 衰减；方差来自奖励噪声累加，随 n 增长趋于 σ2/(1−γ2)。这就是"小 n 稳、大 n 准"的定量版本。
  • 同一批数据上的诊断显示：优势 std 与"和 MC 的相关系数"随 n/λ 增大而同向上升，表格化后比任何直觉都清楚。
  • CartPole 训练上 GAE 综合最优；TD(0) 最稳但学得慢；MC 噪声最大。任务越长、越稀疏，差距越明显。
  • GAE(λ) 的等效回看长度约为 1/(1−γλ) 步：它把"用几步未来信息"变成可调的设计量，这是它作为默认估计器的重要原因。
  • 诊断表解释原因（偏差与噪声），训练表给出结果（速度与成绩），两段证据要对照着读，只信其中一边都容易误判。
