第五篇 · 多智能体环境与实践

第 094 章：多智能体环境：社交博弈

四个玩家在 300 轮的重复公共品博弈里选择贡献水平：搭便车占便宜、集体贡献社会最优，用最朴素的表格 Q 学习看合作能否自发涌现；默认配置会给出一个欠乐观但在文献里常见的答案。

  • 主题：环境设计 / 公共品博弈与条件合作（表格 Q 学习）
  • 关键公式：ui = 1.6·Σc/4 − ci（边际个人回报 0.4 < 1，搭便车占优）
  • 预计学时：55 分钟
  • 前置章节：第 093 章

学习目标

  • 理解公共品博弈的收益结构：边际个人回报 0.4 小于成本 1 时"贡献 0"是占优策略，而社会最优是全员贡献最大。
  • 设计记忆 1 轮的观测（自己上轮贡献 + 他人均值/最小值 + 回合进度），让策略具备条件合作的可能。
  • 实现纯表格 Q 学习（状态离散化 + 在线更新），理解它和深度网络的适用边界。
  • 用四个脚本基线（纳什、社会最优、条件合作、随机）给学习结果定位。
  • 理解"终局崩塌"的理论预言（有限次重复从末轮倒推、合作逐轮瓦解），以及它与"合作根本没建立、全程塌向 0"两种塌缩的区别。

背景与动机

社交博弈回答一个几乎所有多智能体系统都关心的问题：没有中心权威时，合作能否靠学习自发维持？公共品博弈是这个问题的标准模型：每个人的贡献让所有人受益（乘数 1.6、四人平分，边际个人回报 0.4），但贡献成本 1 全由自己承担，别人贡献时你搭便车最赚。一次性博弈里理性选择是 0 贡献；重复博弈里却可能出现"我用贡献回应你的贡献"的互惠均衡。

本章特意把算法"退化"到表格 Q 学习：状态空间只有 640 个，值得展示"把观测离散化后直接查表"的完整流程。这样注意力全在博弈结构上（记忆、终局、互惠），网络训练技巧退居最简。本章的实验会给出一个在文献里相当常见的答案：只靠记忆 1 轮的独立 Q 学习，合作通常维持不住，策略会塌向搭便车（实测平均贡献 0.03～0.11）；把这套学习器放进更有利于互惠的机制（更长记忆、惩罚选项、共享 Q 表）会发生什么，正是练习要探索的方向。这也是本章与第 093 章的联系：两章都是"经济体模拟"，只是本章的均衡无法闭式求解，只能靠基线定位。

核心原理

1. 收益结构与占优策略

当 4 人贡献 c1..4 ∈ {0,1,2,3} 时：

ui = 1.6 · (Σj cj) / 4 − ci = 0.4·Σj cj − ci

从个体看：多贡献 1 单位让四人均分 1.6/4 = 0.4，自己却付出 1，净亏 0.6。因此无论别人怎么做，贡献 0 严格占优。从集体看：每人多贡献 1 让总福利增加 1.6 − 1 = 0.6；全员贡献 3 时每轮总福利 7.2，远高于全员 0 的 0。个体理性与集体理性直接冲突，这就是"社会困境"的数学形状。

2. 记忆 1 轮的观测为什么能支撑合作

如果观测只有"我在第几轮"，无状态差异，学习只能收敛到一个固定动作（0 或 3）。本环境的观测包含：

oi = [ onehot(cilast) ⊕ mean(c−ilast) ⊕ min(c−ilast) ⊕ t/T ]

有了他人上轮的贡献，策略就有条件化空间："别人上轮贡献高，我这轮也高"这种条件合作（conditional cooperation）可以被直接表达。选均值与最小值两个聚合量各有担当：均值刻画"群体的平均善意"，最小值刻画"最吝啬那个人的行为"，现实中的条件合作者对两者都敏感（均值低就少贡献、有人摆烂就跟着摆烂）。

3. 有限次重复的终局崩塌

博弈论经典结论：有限次重复的公共品/囚徒困境从最后一轮倒推（backward induction），合作会逐轮瓦解。RL 玩家未必做严格倒推，但它们会把"回合进度 t/T"当成特征学出经验规律：越接近结束，报复未来的机会越少，搭便车越划算。这个预言有一个先决条件：合作必须先建立起来，才谈得上"在终局前崩塌"。实测（多种子）：默认配置下合作从始至终都没有建立，策略直接塌向贡献≈0，日志里的首尾对比因此看不到"先高后低"的崩塌形状，这是本章最重要的负面结果，也是练习三、四要去改的方向。

4. 表格 Q 学习的状态离散化

把 7 维观测压成一个整数状态：

s = ((cilast·4 + bucket(mean))·4 + bucket(min))·10 + bucket(t/T)

共 4×4×4×10 = 640 个状态、4 个动作。每个玩家一张 Q 表，在线更新 Q(s,a) ← Q(s,a) + α[r + γ·maxa′ Q(s′,a′) − Q(s,a)]，α=0.1 够快、不需要回放池与目标网络；γ=0.95 意味玩家看到约 20 轮的未来，远小于一局的 300 轮，这个"短视"本身就是终局崩塌能被学出来的原因之一。

实现思路与设计

模块划分

组件职责关键点
PublicGoodsGame4 人重复公共品博弈同时出价、收益均分、记忆 1 轮观测

数据流

每轮：4 个玩家各自把 7 维观测映射成整数状态 → ε-贪婪选贡献 → 环境同时结算收益并记录贡献 → 只要不是本局最后一轮，四个玩家各自在线更新 Q 表 → 回合推进。每 3 万轮用贪婪策略、独立随机流评估 20 局（平均贡献/合作率/福利/首尾 50 轮），并同时打印四条脚本基线。

与前一章的差异

第 093 章是单步博弈 + 解析均衡对账，算法用 REINFORCE；本章是有限步重复博弈 + 无解析解，算法退化到表格 Q 学习，对账对象是四条脚本基线。两章的"环境"都与物理无关，它们示范了多智能体 RL 的另一个重要分支：用智能体模拟社会与经济行为。

终局处理：与 GAE 一脉相承的一条原则

每局最后一轮之后环境会 reset，此时 不执行 Q 更新（if not done）。若照常执行 Q ← Q + α(r + γ·max Q(s′))，等于把"下一局的开局状态"当成"本局终局"来学习，两个独立场景被缝在一起，终局崩塌现象会被抹掉。这与第 001 章 GAE 里"真终止不 bootstrap"是同一条时间边界原则，只是表现形式不同。

关键代码与解读

片段 1：博弈结算，一行公式定义社会困境

def step(self, actions: np.ndarray):
    contrib = np.clip(actions.astype(np.int64), 0, self.n_actions - 1)
    total = float(contrib.sum())
    # 收益公式：u_i = 1.6·总贡献/4 − c_i，贡献成本独担、收益均分
    payoff = self.multiplier * total / self.n_agents - contrib
    self.last = contrib.copy()          # 记忆：本轮贡献成为下一轮观测的输入
    self.round += 1
    self.contrib_history.append(contrib.copy())   # 全程留痕，评估端统计合作率
    truncated = self.round >= self.max_rounds
    info = {"contrib": contrib.copy(), "total": total,
            "welfare": float(payoff.sum())}
    return self._obs(), payoff.astype(np.float32), False, truncated, info

解读：环境只有十几行，但三件事都在这了。（1）payoff = multiplier·total/4 − contrib 是 numpy 向量化写法：对每个人同时算"摊到的公共收益减去自己的付出"。1.6/4 = 0.4 < 1 是困境的全部来源；把 1.6 改成 4.0，占优策略立刻反转（练习一）。（2）self.last = contrib 是"记忆 1 轮"的落点：它轮回进 _obs，让下轮的决策看到本轮的集体行为。没有它，重复博弈退化成每轮独立的单次博弈。（3）terminated=False 恒成立：博弈没有"失败终止"，只有 300 轮的时间截断，但注意主循环的更新仍然用 done 隔离最后一轮（截断也不 bootstrap），这是有限局任务的特殊处理，与"截断要 bootstrap"的连续任务相反，差别在于本局之后再无本局收益。（4）welfare 是四人收益之和，不是个人收益，日志里要分清这两个数。

片段 2：记忆观测的构造

def _obs(self) -> np.ndarray:
    obs = []
    for i in range(self.n_agents):
        others = np.delete(self.last, i)          # 排除自己：只看"别人上轮做了什么"
        onehot = np.zeros(self.n_actions, dtype=np.float32)
        onehot[self.last[i]] = 1.0                # 自己的上轮贡献（独热）
        o = np.concatenate([
            onehot,
            [float(others.mean()), float(others.min())],  # 群体善意 + 最吝啬者
            [self.round / self.max_rounds],               # 回合进度：终局算计的原料
        ])
        obs.append(o.astype(np.float32))
    return np.stack(obs)

解读：七维观测，每一维都在支撑一种行为模式。（1）自己的上轮贡献用独热：策略需要知道自己"刚做了什么"才能形成前后一致的行为（报复或延续）。（2）others.mean() 与 others.min() 两个聚合：均值支持"你贡献我也贡献"的平均互惠；最小值支持"有人摆烂我止损"的自保逻辑。它们是条件合作文献里最经典的两种对齐目标。（3）round/max_rounds 是终局崩塌的原料：策略能从进度感知"还剩多久"，从而在接近结束时降低贡献。（4）观测对每个人独立构造（np.delete 排除自己），四个玩家看到的世界不同，这正是各自 Q 表能拉开差异的基础。

片段 3：状态离散化与在线更新

def state_index(obs_row: np.ndarray) -> int:
    """把观测压成一个离散状态：贡献独热→4 档，均值/最小值→4 档，进度→10 档。"""
    own = int(np.argmax(obs_row[0:N_OWN]))
    mean_b = min(int(obs_row[N_OWN]), N_MEAN - 1)          # 均值可以是 3.0，截到 3
    min_b = min(int(obs_row[N_OWN + 1]), N_MIN - 1)
    round_b = min(int(obs_row[N_OWN + 2] * N_ROUND), N_ROUND - 1)  # 进度 1.0→10，必须截到 9
    return ((own * N_MEAN + mean_b) * N_MIN + min_b) * N_ROUND + round_b

class TabularQLearner:
    def update(self, s: int, a: int, r: float, s2: int, done: bool) -> None:
        # 终局不更新：下一局的开局状态不属于本局轨迹（done 时 target 只有 r）
        target = r if done else r + self.args.gamma * float(self.q[s2].max())
        self.q[s, a] += self.args.lr * (target - self.q[s, a])

解读：离散化与更新是表格方法的全部"算法"。（1）索引公式是一个混合进制编码：设所有权重为 4、4、4、10，状态总数正好 640；这种"低位到高位累乘"的写法比字典键更省内存、更快。（2）三处 min(x, 档位−1) 是防越界的保险丝：均值最大 3.0、int(3.0)=3 幸好没越界，但进度在最后一轮恰好是 1.0，int(10)=10 一定越界，不截断就是一次真实的数组越界事故。（3）int() 截断（向下取整）：档位边界干净且单调，实现最简单；粗粒度损失（比如均值 2.4 与 2.6 同档）由 640 的状态数兜住。（4）更新式是标准的表格 Q 学习：done 时 target 只剩 r，与前面"终局隔离"呼应。α=0.1 的大步长配合在线更新（不存储不重放），让 15 万轮的总预算足够完成 640 个状态的覆盖。

片段 4：主循环的终局隔离与评估节奏

for rnd in range(1, args.max_rounds + 1):
    frac = min(1.0, rnd / max(args.eps_decay, 1))
    epsilon = args.eps_start + frac * (args.eps_end - args.eps_start)
    states = [state_index(obs[i]) for i in range(env.n_agents)]
    actions = np.array([learners[i].act(states[i], epsilon, rng)
                        for i in range(env.n_agents)])

    next_obs, rew, terminated, truncated, info = env.step(actions)
    done = terminated or truncated
    next_states = [state_index(next_obs[i]) for i in range(env.n_agents)]
    if not done:                       # 终局隔离：最后一轮不更新，防止跨局污染
        for i in range(env.n_agents):
            learners[i].update(states[i], int(actions[i]), float(rew[i]),
                               next_states[i], done)

    if done:
        ep_count += 1
        obs = env.reset(rng)           # 新的一局：记忆清空（last 归零、round 归零）
    else:
        obs = next_obs

解读：主循环把一个"连续 15 万轮"看成一局又一局 300 轮的重复博弈。（1）ε 的线性衰减跨局连续（按总轮数计算，不因 reset 重置），探索调度服务于整体训练进程，与"局"的边界无关。（2）if not done 的位置在环境步进之后、reset 之前：skip 的正是"用下一局开局状态当本局终局"的那次更新。若打印学到的策略里末段贡献不掉，先怀疑这里写漏了。（3）注意 reset 会清空记忆（last 归零、round 归零）：新局的观测从"全员上轮贡献 0、进度 0"开始，策略必须重新启动合作关系，这给"启动期"增加了成本，也是短局（30 轮）实验里合作难以建立的原因。（4）评估与训练解耦：评估走独立随机流（seed+777、seed+999）且用贪婪动作，产出的是"策略本身"的行为画像，不被训练探索流污染。

常见坑

  • 状态索引越界：均值可以是 3.0 恰好合法，但进度在最后一轮是 1.0，int(10)=10 越界。所有分档都要 min(x, 档位−1)。
  • 终局更新污染：最后一轮仍执行 Q ← Q + α(r + γ·max Q(s′))，等于把下一局开局当本局终局学习，终局崩塌会被抹掉。用 if not done 隔离。
  • 评估时还带 ε：带 0.05 探索的随机贡献会把合作率压低约 5 个百分点，让你误判学习效果。评估必须贪婪。
  • 把福利当个人收益：日志里"社会福利"是四人收益之和（全员 3 时 7.2/轮）；搭便车者个人收益可以高达 3.6 而福利很低，这正是困境所在，两个数不能混读。
  • 忘记 reset 清空记忆：新的一局若不把 last 与 round 归零，上一局的终局贡献会被当成新局势的"上轮行为"，策略会带着错误的互惠预期开局。

  1. 把乘数从 1.6 调到 4.0（占优策略反转），先论证博弈结构变成了什么，再观察学习到的贡献水平。★
    提示
    乘数 4.0 时边际回报 1.0，贡献不再亏本，"全员贡献 3"成为弱占优，困境消失，学习的目标结构也完全不同了。对比两种乘数下尾段行为。
  2. 把观测里的"回合进度"去掉（obs 变 6 维、状态数变 64），先预测终局崩塌会不会消失，再训练验证。★
    提示
    _obs 去掉最后一维、state_index 去掉回合分档，注意重算状态总数。没有进度信息，"最后几轮"在策略眼里与中间轮无法区分。
  3. 把四个玩家改成共享一张 Q 表（所有更新写同一张表），先说明这等价于什么假设，再比较合作水平是否更稳定。★★
    提示
    把 learners 指向同一实例即可。共享表假设"所有人完全同质、互信对方的更新"，学术上是研究对称均衡的简化，现实中很少有这种条件。
  4. 实现"有惩罚"版本：每轮贡献后可以花 0.3 让某玩家扣 1.0（动作空间扩成贡献×惩罚目标），先预测合作水平的变化，再实现并观察惩罚会不会变成报复螺旋。★★★

  5. 把每局轮数从 300 改成 30，先论证"合作是否来得及建立"，再重跑观察平均贡献与首尾对比的变化。★★
    提示
    短局的每局都要从"记忆全 0"重新启动合作，启动成本占比大幅上升；训练总量不变时，策略获得更少的"建立信誉"机会。

小结

  • 公共品博弈把"个体理性 vs 集体理性"的冲突写进一个公式：边际回报 0.4 小于成本 1 时搭便车占优，但全员贡献让福利最大。
  • 记忆 1 轮的观测（他人均值/最小值 + 回合进度）足以让策略表达条件合作与终局算计。
  • 640 状态的表格 Q 学习在本配置下重现的是社会困境的"悲观结局"：策略塌向搭便车、福利远低于随机基线；要看到"合作高于纳什"或"终局崩塌"这些现象，得先解决合作如何建立的问题（更长记忆、惩罚、共享 Q 表）。
  • 脚本基线（纳什/社会最优/条件合作/随机）为无闭式解的社会困境提供坐标系；注意条件合作在同质群体里会退化为 0，基线本身也要先验证行为；终局不更新的隔离原则与 GAE 一脉相承。
