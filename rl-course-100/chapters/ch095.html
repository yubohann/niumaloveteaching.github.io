第五篇 · 多智能体环境与实践

第 095 章：多智能体环境：资源收集

把公地悲剧搬进空间里：4 个采集者在 4 块会再生的资源场上作业，同一套算法分别用"各算各的"与"全队共享"两种奖励制度训练，考察制度差异能否改变采集行为的可持续性。

  • 主题：环境设计 / 可再生资源与制度对照实验
  • 关键公式：St+1 = St + r·St·(1 − St/K)，r=0.08、K=10
  • 预计学时：60 分钟
  • 前置章节：第 094 章

学习目标

  • 掌握把可再生资源的动力学写进环境：逻辑斯蒂（logistic）再生曲线、采集速率、耗尽阈值。
  • 理解奖励制度本身就是环境设计的一部分：同一物理世界，individual 与 shared 两种奖励归属会引出完全不同的行为。
  • 用共享网络的独立 PPO 训练 4 个采集者；观测只含最近两块资源的信息，迫使策略学会巡逻与错峰。
  • 构建"总采集量 / 后半程采集量 / 末态存量 / 耗尽步比例"四指标，刻画可持续性而不只是产量。
  • 与"就近采集"脚本基线对比：实测贪心基线在四项指标上都不落下风，理解"基线为什么强"（一人守一块接近自然解）比急着超过它更重要。

背景与动机

第 094 章的公共品博弈是抽象经济学模型：一轮一结算，没有空间。本章把它落到地理上：资源长在四个角落，采集者要跑过去才能拿，于是"搭便车"变成"抢资源"，"可持续"变成"给块地留出再生时间"。这层空间结构让个体短视有了更具体的表现：谁跑得勤，谁先把最近的资源采空，然后被迫长途跋涉。

更重要的是，本章让你亲手做一个制度对照实验：环境的物理规则完全不变，只改奖励归属。个体制度下每个人只关心"我今天采了多少"；共享制度下每个人都会感受到"把资源采垮，明天大家都没饭吃"。按设计期望，同一套 PPO、同一个世界，两种制度应学出不同的策略风格；但实测（默认参数、种子 0）两者收敛到几乎相同的巡逻策略，四项指标相差不到 0.1，这提醒你：制度效应不是无条件显形的，需要合适的参数与回合长度把它逼出来（练习二、三正是去改变这些条件）。这也是多智能体环境设计里最有教育意义的观察之一，也把第 094 章"合作能否涌现"的问题推进到"制度在什么条件下塑造合作"。

核心原理

1. 可再生资源的逻辑斯蒂动力学

每块资源的存量 S 按逻辑斯蒂规律增长：

St+1 = St + r·St·(1 − St/K)，r = 0.08，K = 10

这是生态学里最常见的单种群增长模型：存量低时增长近似指数（恢复慢），接近容量 K 时增长趋缓。它天然定义了一个可持续采集上限，每步总采集量不能持续超过当期总再生量，否则存量单调下滑。零存量时增长为 0（S + rS(1−S/K) = 0），所以"采空"是不可逆的硬惩罚：这块地在本局内几乎再也缓不过来。

2. 采集与耗尽的临界

采集者在 0.25 半径内每步取 0.12。一块资源被两人同时采时每步流失 0.24，而 S=5 时的再生速度约 0.08·5·0.5 = 0.2，人数一多就会跌破再生线。这正是环境里注定的冲突点：个体最优是"我多拿"，集体最优是"总采集 ≤ 再生"。注意这个冲突完全来自参数设定（0.12 与 0.08 的对比），不是随机性，环境设计者用数字"调"出了困境。

3. 两种奖励制度

individual：ri = harvesti
shared    ：ri = Σj harvestj（所有人相同）

shared 制度下，一个人的采集会同时抬高全队回报，"少采一块地"的机会成本从"只有我少赚"变成"全队都亏"，对"保住整片资源场存量"的激励就内生了。这是制度设计，算法本身没有任何改动：代码里唯一的区别就是 collect_rollout 里那几行 if args.regime == "shared"。对账时请记住：制度改变的是"谁拿到信号"，不改变物理，也不改变网络结构。

4. 观测与局部性

每个采集者只能看到最近两块资源的存量与位置，以及三名队友的相对位置。局部性迫使策略在"继续采眼前的"与"跑去查看另一块"之间做勘探-利用权衡；归一化存量（除以 K=10）告诉它"这块地还能撑多久"。如果观测给全部四块地，任务会明显变简单，信息量本身就是难度旋钮。

5. 指标体系：只报产量会被骗

  • 总采集量：一局 200 步的总产出；
  • 后半程采集量：后 100 步产出，直接反映"资源还活着吗"；
  • 末态总存量：回合结束时四块地的存量之和；
  • 耗尽步比例：后半程中"存量低于 0.5 的资源"的平均数量。

掠夺式采集在 200 步的短回合里产量并不低（采完存量本身就计分），只看总采集量会把"前期掠夺、后期饿死"与"细水长流"混为一谈。四个指标必须一起看，这是本章评测协议的核心。

与前一章的差异

第 094 章是抽象博弈（无空间、表格 Q、单轮结算）；本章是空间环境（连续控制、PPO、状态随时间演化），但保留了同一个灵魂：奖励归属决定行为。把两章并排读，你会看到"社会困境"从离屏模型走进物理世界后，多了"空间错峰"与"资源再生"两个新机制。

评估四指标的读法（按顺序）

1) 先看后半程采集：它掉一半说明资源崩了；2) 再看末态存量：接近 0 说明是掠夺式；3) 耗尽比例越高说明过采越严重；4) 最后才看总采集，它是被前三个指标解释的结果，不是结论本身。只看第 4 个指标是被本章明确警告过的误读。

关键代码与解读

片段 1：再生 + 采集，环境的"生态经济学"

# 1) 资源按逻辑斯蒂规律再生：先增长、后采集，顺序固定
self.stock = np.clip(
    self.stock + self.growth * self.stock * (1.0 - self.stock / self.K),
    0.0, self.K)          # 上限 K：接近容量时增长自然趋缓；S=0 时增长也为 0

# 2) 采集：靠近资源的采集者按顺序各取一份
harvest = np.zeros(self.n_agents, dtype=np.float32)
for i in range(self.n_agents):
    for j in range(len(self.patch_pos)):
        if np.linalg.norm(self.pos[i] - self.patch_pos[j]) < self.harvest_radius:
            take = min(float(self.stock[j]), self.harvest_rate)   # 存量不够就采了多少算多少
            self.stock[j] -= take
            harvest[i] += take
self.total_harvest += harvest

解读：两段逻辑定义了"资源还能撑多久"的全部答案。（1）逻辑斯蒂再生的三个性质：低存量时增长慢（近似指数但系数小）、高存量趋缓（1−S/K 趋零）、S=0 时零增长，第一和第三个性质合起来构成"采空不可逆"。若图省事把再生写成常数增量 S+r，资源永不枯竭，公地悲剧实验直接失效。（2）再生与采集的顺序是刻意的：先长后采相当于"这一轮的收成从先长出来的开始算"，若是采后再长，采空的地当步还能"回一点血"，锐度下降。（3）take = min(stock, rate)：不能凭空采集超过存量，否则会出现负存量；最后按 clip(..., 0, K) 双保险。（4）采集按智能体顺序逐个结算：物理上总采集一样，但"谁先到谁多拿"的微妙不对称会被策略学到，这正是"错峰"动机的一部分。

片段 2：局部观测，最近两块资源

def _obs(self) -> np.ndarray:
    obs = []
    for i in range(self.n_agents):
        d = np.linalg.norm(self.patch_pos - self.pos[i], axis=1)
        order = np.argsort(d)                     # 按距离排序，只取最近两块
        patch_feats = []
        for k in order[:2]:
            patch_feats.append(self.patch_pos[k] - self.pos[i])   # 相对坐标(2)
            patch_feats.append(np.asarray([self.stock[k] / self.K], dtype=np.float32))  # 归一化存量(1)
        others = [self.pos[j] - self.pos[i]
                  for j in range(self.n_agents) if j != i]
        o = np.concatenate([self.pos[i], self.vel[i],
                            np.concatenate(patch_feats),
                            np.concatenate(others)])
        obs.append(o.astype(np.float32))
    return np.stack(obs)

解读：观测的裁剪方式就是任务的难度设定。（1）只给最近两块资源：采集者无法"一眼看全四角"，必须学会探索与轮换，如果给全部四块，策略可以离线规划最优路线，勘探-利用的张力消失，任务会变得平淡。（2）每块资源带"相对坐标 + 归一化存量"两个信息：坐标回答"去哪"，存量回答"值不值得去"；只给位置不给存量，策略无法区分"还富余"与"已采空"，只能瞎跑，这是本章最重要的观测分量。（3）存量除以 K=10，让量级与坐标（±1 上下）可比：否则存量 0～10 的数值会主导输入尺度，网络对位置信息不敏感。（4）队友相对位置 6 维用于避让与错峰；注意这里没给队友的"目标资源"，错峰必须靠观察队友位置自己推断，这正是协调难度所在。

片段 3：制度分支，三行代码的实验变量

for _ in range(steps):
    a, logp, v = net.act_batch(obs, device)
    next_obs, harvest, terminated, truncated, info = env.step(a)
    # 奖励制度：individual 各算各的；shared 所有人拿到全队总采集
    if args.regime == "shared":
        rew = np.full(env.n_agents, float(harvest.sum()), dtype=np.float32)
    else:
        rew = harvest.copy()
    obs_buf.append(obs); act_buf.append(a)
    logp_buf.append(logp); val_buf.append(v)
    rew_buf.append(rew)
    done_buf.append(np.zeros(env.n_agents, dtype=np.float32))  # 只有截断，恒为 0
    ep_ret += float(rew.mean())
    ep_harvest += harvest            # 指标始终用"各自采集量"统计，与奖励制度无关

解读：这是全书最短也最深刻的"制度代码"。（1）individual 直接把各自的采集量当奖励；shared 把全队总和复制给每个人，两种制度共用同一套环境与网络，对照实验没有任何其他变量。（2）奖励制度只影响 rew_buf（进 GAE 的信号），不影响统计口径：ep_harvest、评估里的四指标永远按"各自实际采集"计算，这样两种制度的日志可以直接对比。（3）shared 模式下每个人的回报包含队友的行动效果，GAE 的优势计算自动"团队化"，学习信号自然要求协调，这就是"制度内生激励"在代码里的样子。（4）注意 done_buf 恒为 0：环境只有 200 步时间截断，价值在回合边界继续 bootstrap。

片段 4：就近采集基线，短视策略的锚点

else:   # 就近采集：选"最近且存量 > 1"的资源，直接朝其方向走
    a = np.zeros((env.n_agents, env.act_dim), dtype=np.float32)
    for i in range(env.n_agents):
        d = np.linalg.norm(env.patch_pos - env.pos[i], axis=1)
        cand = [j for j in range(4) if env.stock[j] > 1.0]     # 只考虑"还没采空"的地
        j = int(np.argmin(d[cand])) if cand else int(np.argmin(d))
        vec = env.patch_pos[j] - env.pos[i]
        a[i] = vec / (np.linalg.norm(vec) + 1e-8)              # 单位向量朝目标直走

解读：基线策略体现了"看一眼库存、去最近的、不回头"的朴素理性。（1）cand 过滤掉存量 ≤1 的资源：这是基线唯一的一点"智能"，不然它会守着一块空地采到天荒地老；阈值 1.0 与耗尽判定 0.5 呼应，留了一点缓冲。（2）没有候选时退化为"去最近的地"（argmin(d) 的兜底分支）：死也要死在路上，这个笨拙的兜底恰好说明贪心策略在资源崩盘后完全无从应对。（3）动作是单位方向向量直接作为加速度：简单但也暴露性质，它不会减速（没有惯性补偿），到点上会来回震荡，采集效率天然打折。这正是"强基线不需要完美"的例子：它的作用是给学习策略一个可读的下限锚点。（4）评估时四指标与学习策略完全同口径：后半程采集、末态存量、耗尽比例都按后半 100 步/回合末统计，保证两种制度、三类策略可以放进同一张表。

常见坑

  • 把再生写成常数增量：S+r 与存量无关时资源永不枯竭，公地悲剧实验直接失效。必须用逻辑斯蒂形式，确保 S=0 时再生也为 0。
  • 观测不含存量：只给位置不给存量，策略无法判断"还富余"还是"已采空"，只能瞎跑。归一化存量是本章最重要的观测分量。
  • 奖励尺度失衡：采集奖励每步 0～0.5，与更新幅度匹配的是相对差异；把它乘 10"放大信号"会改变优势尺度，等于放大有效学习率，通常要同步调小 lr。
  • 用总采集量单指标下结论：短回合里掠夺策略产量不低，只看总采集会误判"没有公地悲剧"；必须带末态存量与后半程产量。
  • shared 模式下连统计口径也改成总和：评估四指标必须始终按各自采集统计；若把统计也改成全队总和，你就无法分辨"产量高"与"某个体搭便车"，且与 individual 的数字不可比。

练习与思考

  1. 把 --regime 两种设置各跑一遍，比较四个指标，并说明哪个指标最能代表"可持续性"。★
    提示
    总采集比不出差别就看末态存量与后半程采集；评估输出里四个数都列好了。结论记得配种子稳定性。
  2. 把回合长度改成 400 步（ResourceEnv(max_steps=400)），先预测制度差距会怎么变，再看两种制度的新结果。★
    提示
    逻辑斯蒂再生在存量被压到 2 以下时恢复极慢，"回本周期"超过回合剩余时间，掠夺的成本才充分暴露，长回合放大制度效应。
  3. 把再生速率 growth 从 0.08 调到 0.18，先判断掠夺行为会不会自然缓解，再实测"制度与资源丰度"谁更重要。★★
    提示
    资源越充裕，可持续上限越高，individual 与 shared 的分化越小声，"制度与丰度互补"的实证。注意同样要修改评估环境的参数。
  4. 给采集者加"运输成本"：采集量要在回到中心站时才结算（携带 50% 到达生效），先设计状态与奖励的改法，再观察"多采"与"多跑"的权衡如何演化。★★★
    提示
    状态加携带量维度，奖励改成"抵达中心结算"。路径规划与分配问题同时出现，训练难度明显上升，这正是真实物流的味道。
  5. 实现"税收-再分配"：individual 下每人把采集的 30% 汇入公共池、期末按人头均返；先预测它介于两种制度之间的位置，再实现对比。（提示：奖励可写成 0.7·own + 0.3·mean(all) 的形式。★★★
    提示
    真实政策往往介于两个极端之间。观察"部分共享"的效果曲线：共享比例提高多少才能压住掠夺，是本题最有意思的数字。

小结

  • 可再生资源用逻辑斯蒂增长建模：低存量时恢复慢、采空不可逆，天然定义了可持续采集上限。
  • 采集速率与再生速度的对比决定冲突强度：多人同采必然超过再生线，这是制度问题，不是随机性。
  • 奖励归属就是制度：individual 与 shared 只差三行代码；本默认参数下两者收敛到相近策略，制度效应要靠回合长度与再生参数放大，统计口径必须与奖励制度解耦。
  • 可持续性要看四指标组合：总采集、后半程采集、末态存量、耗尽比例；只报产量会被短视策略骗过。
