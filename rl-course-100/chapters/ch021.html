第一篇 · 策略梯度与 PPO

第 021 章：PPO的探索策略：参数空间噪声

对照两种探索机制的"性格"：动作空间噪声每步独立掷骰子，参数空间噪声给整批采样换一套权重。后者让探索在时间上连贯，σ 还会自适应到目标 KL，两条轨迹用覆盖度与样本效率说话。

  • 主题：探索机制 / 参数空间噪声
  • 关键公式：θ̃ = θ + σ·ε；δ̂ = 𝔼[KL(πθ̃‖πθ)] → 自适应 σ
  • 预计学时：60 分钟
  • 前置章节：第 020 章

学习目标

  • 理解动作空间噪声（每步独立采样）与参数空间噪声（整批共享一套扰动权重）的机制差异。
  • 实现参数噪声的完整流程：扰动 → 采样 → 恢复 → 重算 logp_old → 更新。
  • 实现基于"扰动策略与原始策略的 KL"的 σ 自适应调节，把探索强度稳定在目标附近。
  • 实现状态覆盖度指标（观测离散桶访问数），用它观察两种机制的探索分布差异。
  • 理解为什么参数噪声必须在更新前恢复权重、并用原始策略重算对数概率。

背景与动机

第 005 章的熵正则在鼓励"每步都随机一点"，第 020 章的塑形在解决"奖励太稀疏"。这一章处理探索的另一个维度：随机性在时间上的结构。动作空间噪声每一步独立采样，策略可能这步向左、下一步向右，行为是高频抖动的布朗运动；参数空间噪声给整批数据共用一套扰动权重，于是策略在整段轨迹里"性格一致"（比如一贯喜欢加速或一贯保守），探索是连贯的行为变异。

为什么连贯性有价值？在稀疏或结构化任务中，"一直往一个方向试"比"平均而言试遍所有方向"更容易撞进狭小的成功区域；Plappert 等人的实验也显示参数噪声在部分任务上显著优于此前的探索方案。代价是参数噪声的强度更难控制，扰动太小没效果、太大行为崩溃，所以工程上用一个反馈回路把 σ 自动稳定在"扰动后策略与原策略的平均 KL ≈ δ"的水平。本章把这条回路完整实现，并用覆盖度指标观察两种机制的差异。

核心原理

1. 两种噪声的作用位置

动作噪声在输出端加随机性：

at ~ πθ(· | st)，　各步独立

参数噪声在参数端加随机性，每个采样批次换一套参数：

θ̃ = θ + σ · ε，ε ~ N(0, I)，　整批数据都用 θ̃ 采集；更新前恢复 θ σ 是全局噪声尺度；也可以按参数范数逐层缩放（练习 3）

动作噪声的探索在 (s, a) 空间里是"处处加噪"；参数噪声的探索是"换一个策略"，同一状态下的动作偏好被整体改变，且这一改变在整段轨迹中保持一致。两者互为补充：参数噪声改变的是"策略族内的取样"，动作噪声改变的是"策略内分布的取样"。

2. σ 自适应：把探索强度锁定在目标 KL 上

扰动多大算合适？直接量"扰动策略行为变了多少"最稳：

δ̂ = 𝔼s[ KL( πθ̃(·|s) ‖ πθ(·|s) ) ]
δ̂ > 1.5·δ ⇒ σ ← σ/1.01　；　δ̂ < δ/1.5 ⇒ σ ← σ·1.01

目标 δ 一般取 0.01 量级。这条规则的效果是：训练早期策略平坦，需要更大的 σ 才能达到 δ（σ 上升）；后期策略尖锐，同样的 σ 会造成巨大行为差异（σ 下降）。自适应让"探索强度"以行为变化为单位恒定：参数扰动的幅度随策略尖锐程度自动缩放，这是参数噪声工程化的关键思想。带宽与步长分工不同：1.5 倍带宽决定"什么时候动手"，1% 步长决定"动手多快"，本章刻意选择"宽触发 + 慢响应"，宁可让稳态附近保留小的估计噪声，也不让 σ 在目标两侧来回过冲。

3. 数值算例：σ 要多大才能命中目标 KL

回路平衡时的 σ 到底多大？在噪声直接加于 logits 的情形（第 022 章的机制），小扰动下的期望 KL 有闭式近似：𝔼[KL(πθ̃‖πθ)] ≈ ½·σ²·(1 − Σa pa2)。推导只用两步：KL 关于 logits 扰动的二阶展开系数是类别分布的费舍尔信息矩阵 F = diag(p) − pp⊤；对称噪声下期望 KL ≈ ½σ²·tr(F)，而 tr(F) = 1 − Σp²。数值核对：p=(0.953,0.047) 时，小扰动区间（σ≤0.2）蒙特卡洛给出 𝔼[KL] ≈ (0.045±0.001)σ²，与 ½×0.0896σ² 的 0.0448 一致；σ 增大后高阶项占比上升，σ=0.47 时系数升到约 0.055、σ=1 时约 0.079，因此这张工作点地图在目标 KL 远小于 0.1 时最可靠。

令 𝔼[KL] = δ = 0.01，反解 σ* = √( 2δ / (1−Σp²) )，得到"工作点地图"：均匀策略 p=(0.5,0.5) 需 σ*≈0.20；p=(0.65,0.35) 需 ≈0.21；p=(0.8,0.2) 需 ≈0.25；p=(0.953,0.047) 需 ≈0.47。策略越尖锐，维持同一行为强度所需的 σ 越大；这就是"以行为变化为单位恒定"的定量含义，也解释了固定 σ 为什么在不同训练阶段的效果天差地别。

两个 σ 不在同一把尺子上：上面的计算针对"直接扰动 logits"的 σ；本章的回路扰动的是网络参数，噪声经过线性层与激活才到达 logits，传递过程按权重尺度压缩。因此参数空间的 σ 稳态落在 1e-2 量级与 logits 空间的 0.2～0.5 并不矛盾，跨机制直接比较两个 σ 的数值没有意义。

回路还有一个容易忽略的物理限制：调节步长固定为每次更新 ×1.01 或 ÷1.01，等价于每 69.7 次更新翻一倍。本章预算 8 万步、每次更新 2048 步，全场约 39 次更新，σ 在一次运行内最多移动 1.0139 ≈ 1.47 倍。实用规则由此而来：自适应适合在初值附近 ±50% 内做精调；σ_init 与稳态相差一个数量级以上时，回路在固定预算内拉不回来，应先用两三次短程试验把初值粗调到同一数量级，或把步长改成 ×1.05（每 14.2 次更新翻倍）再跑长程。

4. 三个必须做对的实现细节

  • 采样后立即恢复 θ：更新必须发生在原策略上；忘记恢复会让扰动累积成随机游走，训练发散。
  • 用原始策略重算 logp_old：收集到的动作是"扰动策略"产生的，但 PPO 的比率要以更新起点（原始 θ）为基准；用扰动 logp 当基准会让比率系统性偏离 1。Plappert 论文的标准做法就是在更新前用 θ 重新计算全部对数概率。
  • bootstrap 价值用原始 θ 估计：GAE 尾部的 V(sT) 必须来自未扰动网络，否则价值目标带上噪声。

两个失效极端也要有预案：σ 顶在 0.1 上界时，每个权重被扰动超过其典型幅值的 10%，回合内行为大幅跑偏，扰动 KL 长期高于目标，策略更新被噪声拖后腿；σ 顶在 1e-4 下界时扰动 KL 大约在 1e-8 量级，探索增强实际为零。看到 σ 长期贴住任何一侧边界，先改 --sigma-init，再考虑调整目标 δ。

5. 覆盖度：探索多样性的直接度量

CartPole 的状态是 4 维连续量，本章把它切成 6×6×6×6 的桶，统计每批数据访问过的唯一桶数。动作噪声的批次往往覆盖更均匀的"轨道周围区域"；参数噪声批次由于行为连贯，可能覆盖更少但更深的路径。没有哪种覆盖"一定更好"，要看任务需要的是广撒网还是深挖路径；这个指标的作用是把"探索风格"变成可观察的数。

估算量本身的噪声也值得核一遍：在目标 KL=0.01、批量 2048 的配置下，用 30 万样本蒙特卡洛测得单样本对数值的标准差约 0.143，批均值的标准误约 0.003，约为 KL 目标值的 29%；1.5 倍带宽的半宽约 0.005，折合约 1.7 个标准误。结论：平衡点附近偶尔的 ±1% 调整有一部分来自抽样噪声，回路退化成慢速随机游走，不会造成系统性漂移；若希望回路更"安静"，可以把带宽放宽到 2 倍，或对最近几次更新的 KL 估计做滑动平均再判方向。

6. 三种探索增强的横向对照

三列的共同点：都把"探索"变成一个可以被度量、被调度的量；不同点在前两列属于"数据从哪来"的工程，第三列属于"目标函数长什么样"的设计。本章的自适应 σ 正好介于两者之间：它调整的是数据来源，但依据的是策略层面的行为变化（KL）。

数据流

每个 arm 一条完整训练。param 臂的单轮流程：perturb_parameters（备份 + 加噪）→ 用扰动权重采样 2048 步 → 立刻 restore_parameters → 用原始网络算 last_value 与 logp_old（重算）→ 10 epochs 更新 → 在同一批观测上重新扰动估计 δ̂ 并调整 σ → 记录覆盖度、σ 轨迹。action 臂跳过扰动相关步骤，其余一致。汇总里的 σ 初值/终值都取 5 次均值（前 5 次与后 5 次），单点读数会把一次随机微调误读成趋势。健康判据也直接写在日志里：kl_pert_mean 终值落在 δ 的 [1/1.5, 1.5] 带内说明回路锁得住；若长期低于 δ/1.5 而 σ 已贴上界，说明 --sigma-max 卡住了回路，需要放宽上界或抬高 δ。

为什么参数噪声必须"重算 logp_old"

PPO 的比率是 πnew(a|s) / πold(a|s)，其中 πold 的定义是"更新开始前那个参数的策略"。param 臂的数据虽然由 θ̃ 采集，但更新是在恢复后的 θ 上进行的，因此 logp_old 必须用 θ 重新算，否则分母来自另一个分布，比率整体偏移，裁剪阈值形同虚设。这一步不做，训练还能跑，但更新会系统性偏保守、样本效率悄悄变差。

关键代码与解读

片段 1：扰动与恢复，一步备份、一步回填

def perturb_parameters(net, sigma: float):
    """给所有权重加 σ·N(0,1) 噪声，返回原始参数的克隆。"""
    originals = []
    with torch.no_grad():
        for p in net.parameters():
            originals.append(p.data.clone())          # 先备份，再扰动
            p.data.add_(sigma * torch.randn_like(p))
    return originals

def restore_parameters(net, originals):
    with torch.no_grad():
        for p, o in zip(net.parameters(), originals):
            p.data.copy_(o)                           # 原地恢复，覆盖扰动

解读：（1）备份用 p.data.clone()（不用 state_dict()）：后者返回的字典在某些实现里仍指向共享存储，clone 是明确的深拷贝；直接操作 p.data 绕过 autograd，语义干净。（2）torch.randn_like(p) 逐参数张量采样：每个权重独立 N(0,1)，这就是 θ̃ = θ + σ·ε 的实现。（3）add_ 是原地操作：扰动只改数值、不换对象，网络的引用（优化器里的参数列表）保持一致。（4）restore_parameters 按 zip 的同一个顺序回填，两函数的遍历顺序都由 net.parameters() 决定，天然对齐。（5）整个操作只用两次浮点向量运算，成本极低：参数噪声的成本大头从来不在加噪这一步，真正费心的是把探索的语义管理正确。

片段 2：采样后的恢复与 logp 重算，顺序即正确性

    if originals is not None:
        # 用扰动权重评估价值 bootstrap 会引入偏差：先恢复再算
        restore_parameters(net, originals)

    last_value = net.value(obs_after)
    advantages, returns = compute_gae(rew_buf, val_buf, term_buf, last_value, gamma, lam)

    obs_tensor = torch.as_tensor(np.asarray(obs_buf), dtype=torch.float32, device=device)
    act_tensor = torch.as_tensor(np.asarray(act_buf), dtype=torch.long, device=device)

    if originals is not None:
        # 关键：用恢复后的策略重算 logp_old（Plappert 等 2018 的标准做法）
        with torch.no_grad():
            logits = net.logits_of(obs_tensor)
            dist = Categorical(logits=logits)
            logp_old = dist.log_prob(act_tensor).cpu().numpy()
    else:
        logp_old = np.asarray(logp_buf, dtype=np.float32)

解读：（1）采样循环一结束就是 restore_parameters：之后所有计算（bootstrap 价值、GAE、重算 logp、更新）都发生在原始 θ 上，扰动只存在于"数据从哪来"这一件事里。（2）logits_of 是新加的只读接口：批量算 logits 而不需要 value；配合 Categorical 得到 logp_old。（3）注意重算用的是整批向量化（一次前向），不是逐步重复，2048 步的数据一次算完，开销可忽略。（4）action 臂走 else 分支：直接用采样时的 logp_buf（每步独立采样，采样策略与更新起点都是 θ，无需重算）。两条分支的存在让"重算"的必要性在代码里一目了然。（5）如果顺序反了（先算 last_value 再恢复、或用扰动 logp 当基准），训练仍能进行，但价值目标带噪、比率偏移，这是本章最隐蔽的两类 bug。

片段 3：σ 自适应，行为层面的反馈回路

        if use_param:
            # 在同一批观测上重新扰动一次，估计 KL(π_perturbed ‖ π_base)
            originals = perturb_parameters(net, sigma)
            with torch.no_grad():

            with torch.no_grad():

            kls_pert.append(kl_pert_now)
            if kl_pert_now < args.delta / 1.5:
                sigma = min(sigma * 1.01, args.sigma_max)   # 行为变化太小：加大扰动
            elif kl_pert_now > args.delta * 1.5:
                sigma = max(sigma / 1.01, args.sigma_min)   # 变化太大：收缩
            sigmas.append(sigma)

解读：（1）自适应用的扰动是更新之后、另抽的一次：在同一批观测上先加噪算 logits_pert、再恢复算 logits_base，两者之 KL 就是"当前参数下的探索强度"。（2）为什么不在采样时复用扰动：那时没保存扰动权重，且采样与更新之间参数已经变了；用"当前参数 + 新扰动"估计的 δ̂ 更贴近下一批数据的实际探索。（3）规则是 1.5 倍带 + 1.01 步长：KL 超出目标 1.5 倍就缩 σ、低于 1/1.5 就放大 σ，每次只动 1%，慢速调节避免振荡，和 KL 惩罚的自适应 β（第 003 章）是同一种反馈思想，只是作用在探索强度上。（4）min/max 的上下界是保险丝；sigmas 列表记录轨迹，报告里的"σ 初/终"就是这条回路的健康证明。（5）categorical_kl 的实现是 𝔼[logp_a − logp_b]（a 的分布下取期望），数值稳定，不需要先算概率。

片段 4：覆盖度，把"探索风格"变成数字

STATE_BINS = [(-2.4, 2.4), (-3.0, 3.0), (-0.21, 0.21), (-3.0, 3.0)]

def state_coverage(obs_array: np.ndarray, n_bins: int = 6) -> int:
    keys = set()
    for obs in obs_array:
        key = []
        for x, (lo, hi) in zip(obs, STATE_BINS):
            b = int(np.clip((x - lo) / (hi - lo) * n_bins, 0, n_bins - 1))
            key.append(b)
        keys.add(tuple(key))
    return len(keys)

解读：（1）STATE_BINS 是 CartPole 四个维度的物理范围（位置、速度、角度、角速度），每维切 6 格：一条观测被映射成 4 元组键，进 set 去重。（2）np.clip(..., 0, n_bins-1) 保证越界观测也被归入边界桶，不会产生非法索引。（3）返回的是"唯一桶数"，衡量覆盖的广度；参数噪声的批次行为连贯，往往覆盖桶数更少但路径更深（练习里可结合回报曲线看）。（4）粒度 6⁴=1296 是一个折中：太粗没有区分度、太细几乎每步都是新桶。这个工具会在第 022、023 章的探索对比里继续复用。

python code/ch021.py             # action 与 param 各 8 万步，CPU 约 3–6 分钟
python code/ch021.py --quick     # 两臂各 8000 步，约 30–60 秒
python code/ch021.py --delta 0.03   # 更强的目标 KL（更激进的行为变异）
python code/ch021.py --arms param   # 只跑参数噪声臂

预期结论（以实跑为准）：两臂通常都能在 4～7 万步内越过 400，最终评估都接近 480～500，CartPole 太简单，两种探索的样本效率差异不明显，不要用一次运行定胜负。可观察的稳定差异在另外三列：param 臂的 σ 会从初值自适应到 0.01～0.03 区间且扰动 KL 稳定在目标 δ 附近（这条回路是本章的核心工程）；param 臂的覆盖桶均值通常比 action 臂低 15%～30%，说明探索更"成片"，动作噪声则更接近"撒胡椒面"；KL 与裁剪比例两臂相当。想看参数噪声的样本效率优势，应换到稀疏奖励任务（把第 020 章的 MountainCar 与本机制组合）或把 δ 调得更激进。

常见坑

  • 采完忘记恢复参数：扰动会被下一次扰动叠加，参数变成随机游走。恢复要在采样循环结束后的第一时间执行。
  • 用扰动策略的 logp 当比率基准：PPO 的比率必须相对"更新起点"的参数；用扰动 logp 会让 rt 偏离 1，更新被系统性削弱。恢复后重算 logp_old 是必需步骤。
  • bootstrap 用扰动价值：GAE 的尾端价值与 sT 的 V 估计必须来自未扰动策略，否则价值目标带噪、优势估计被污染。
  • 把 σ 直接当超参数硬调：不同训练阶段的合适 σ 差一个数量级，手调必然顾此失彼。请使用 KL 目标的自适应回路，只调 δ。
  • 评估时忘了回到原始权重：评估应在未扰动的策略上进行；若在扰动状态评估，成绩里混进噪声，跨臂比较失真。评估函数本身不扰动，但要确认调用时参数已恢复。

练习与思考

  1. 把 --delta 设为 0.003 / 0.01 / 0.05，观察 σ 的稳态水平与学习曲线，解释"目标 KL 决定探索强度"的含义。★
    提示
    δ 越大 → 稳态 σ 越大 → 覆盖面更宽但行为更乱。看日志里 σ 与扰动 KL 是否互相锁定，以及首达 400 的步数变化。
  2. 只给 actor 参数加噪声（critic 保持原样），对比全参数扰动，判断价值函数带噪是否拖慢训练。★
    提示
    把 perturb_parameters 改为只遍历 actor 与 body（或只 actor）。价值网络带噪会让 GAE 的 bootstrap 与优势估计更脏，预期纯 actor 扰动更稳。
  3. 实现"按层缩放"的参数噪声：每层噪声乘以该层参数的平均绝对值（或范数），使各层扰动幅度可比，对比统一 σ 的效果。★★
    提示
    Plappert 论文讨论过多种缩放；按范数缩放能让输出层（本身权重小）不被过量扰动。观察扰动 KL 的波动是否变小。
  4. 把参数噪声与第 020 章的 MountainCar 组合：不做塑形，仅用参数噪声（δ=0.02）训练 20 万步，与 baseline 比较成功率。★★★
    提示
    需要把环境换成 MountainCar-v0 并保留本章的扰动/恢复逻辑（注意成功判定用 terminated）。参数噪声的连贯探索在稀疏奖励上最有机会展现实力，也最可能暴露"σ 太大会崩、太小没用"的调参边界。

小结

  • 动作噪声每步独立、参数噪声整批共享：前者探索"广"、后者探索"深"（行为连贯）。
  • 参数噪声的实现闭环：扰动 → 采样 → 恢复 → 重算 logp_old → 更新；任何一步顺序错误都会污染训练信号。
  • σ 自适应把行为层面的 KL 稳定在目标 δ 附近，使探索强度在训练全程保持一致，避免手调 σ 的困境。
  • CartPole 上两种探索都能达标；稳定的差异在覆盖度（param 更集中）与 σ 自适应轨迹，而不一定在样本效率。
  • 下一章把探索方向反过来：动作空间噪声的显式方案，动作噪声注入、动作重复统计与探索调度，并与本章的参数噪声做直接对照。
