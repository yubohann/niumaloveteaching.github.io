第二篇 · 离策略方法与 SAC

第 037 章：SAC的离散动作扩展

把 SAC 从连续搬到离散：策略换成 softmax、Q 网络变成"每个动作一个分数"，评论家目标对全部动作求期望。在 CartPole-v1 上对比期望目标与采样目标两种写法。

  • 主题：离散 SAC / 全期望软贝尔曼目标
  • 关键公式：V(s′) = Σa π(a|s′)·(minjQj(s′,a) − α·log π(a|s′))
  • 预计学时：55 分钟
  • 前置章节：第 036 章

学习目标

  • 理解离散 SAC 与连续 SAC 的三处结构差异：策略分布、Q 网络输入、Bellman 目标。
  • 掌握离散版的目标熵设定 0.98·log|A| 的来历与数值含义（CartPole 上约 0.679）。
  • 实现"期望目标"与"采样目标"两种评论家更新，并在同种子下对比。
  • 在 CartPole-v1 上把随机策略训练到接近满分，读通熵与 |Q| 的轨迹。

背景与动机

上一章我们看到连续 SAC 的灵魂是重参数化，它对高斯的 μ、σ 光滑可导。换成离散动作，动作空间天然是"几个类别"，分类分布采样不可导，重参数化在这里要么用代价高昂的 Gumbel 松弛，要么放弃。于是问题来了：SAC 的最大熵思想能不能直接搬到离散动作上？答案是可以，而且改动很干净。

更大的变化在评论家。连续 SAC 的 Bellman 目标里只有"下一个动作"一个点：Q(s′,a′)。离散动作数少，我们可以对全部动作做精确期望，得到一个方差更小的软价值目标。这一步不是必须的，很多从连续移植过来的实现会顺手写成"采一个动作"，两者的训练差异正是本章要量化的对象。

为什么用 CartPole？它是验证离散 SAC 正确性的最小环境：2 个动作、4 维状态、回报就是存活步数。学习曲线对了、Q 值量级对了，说明离散扩展的实现是对的。它还有一个隐性好处：每回合上限 500 步、几乎不会触发数值极端值，熵与 |Q| 的轨迹可以直接肉眼判读，出现异常时容易定位到具体那一处形状或符号改动。

核心原理

1. 离散策略与温度系数

策略输出 logits z(s)，动作概率是 softmax：

π(a|s) = exp(za) / Σa′ exp(za′)   ·   log π(a|s) = za − logsumexp(z)

策略目标是最大化 Q 与熵的加权组合：J(π) = Σa π(a|s)·(Q(s,a) − α·log π(a|s))。因为动作数只有几个，这个求和可以精确计算，无需采样估计，这是离散版比连续版简单的地方。取负号直接作为最小化的损失。离散版不需要重参数化：动作是类别编号，从 softmax 分布里"取出一个类别"这一操作本就不可导，而精确期望把"对动作求平均"变成了对所有类别的加权求和，梯度可以直接穿过 π(a|s) 与 log π(a|s) 回传，采样不可导的问题被绕开。

2. 评论家目标的两种写法

连续 SAC 的软 Bellman 目标是 r + γ·(Q(s′,a′) − α·log π(a′|s′))，其中 a′∼π 采样一次。离散版可以做全期望：

V(s′) = Σa π(a|s′)·( minjQj(s′,a) − α·log π(a|s′) )
期望目标：target = r + γ·V(s′)   |   采样目标：a′∼π，target = r + γ·(Qmin(s′,a′) − α·log π(a′|s′))

期望目标对下一个状态的价值做了无偏的"策略平均"，把采样噪声从目标里消掉，代价是每个 batch 多算一次全动作 Q（本来就要算，因为 Q 网络直接输出全部动作的分数）。采样目标更贴近连续版直觉，但目标值的方差明显更大，它和你实际执行的动作无关，只贡献噪声。

数值例子：同一下一状态的两种目标值

设某下一状态有两个动作，双 Q 取 min 后得到 Q = [10, 5]，策略概率 π = [0.8, 0.2]，温度 α = 0.2。先算对数概率：log π = [−0.223, −1.609]。

期望目标：V = 0.8×(10 − 0.2×(−0.223)) + 0.2×(5 − 0.2×(−1.609)) = 0.8×10.045 + 0.2×5.322 ≈ 9.10。

采样目标：以 0.8 的概率抽到动作 0，目标为 10.045；以 0.2 的概率抽到动作 1，目标为 5.322。

两者的均值相同（都是 9.10，所以都无偏），但采样目标的方差 = 0.8×(10.045−9.10)2 + 0.2×(5.322−9.10)2 ≈ 3.57，标准差约 1.89。也就是说，单看一个样本，采样目标平均要偏离真值近 1.9；期望目标在我们把 π 算准的前提下不产生这层抽样噪声。

解读：这 1.89 的波动会原样叠加进 TD 目标，再经回归传给 Q 网络与策略。动作分布越均匀、动作之间 Q 差距越大，这层噪声越明显；本项目里动作只有 2 个、策略后期偏向确定，噪声相对可控，但训练早期的波动主要就来自这里。按 batch=256 折算，批平均后的目标扰动约为 1.89/√256≈0.12；对 |Q| 平台 20～80 的 CartPole，这是千分之几的相对扰动，属于可接受但非零的噪声底。一般地，采样目标的方差为 Σaπ(a)·(ya−V)2，即"各动作的目标值离期望有多远"的概率加权平方和，可以直接拿来预估任何 π、Q 组合下的噪声。

3. 目标熵 0.98·log|A|

连续版的目标熵用 −dim(A)。离散版没有"维度"的概念，一个自然的选择是把接近均匀分布但不完全均匀的熵作为目标。均匀分布的熵是 log|A|（CartPole 上约 0.693），乘 0.98 得到 0.679，意思是"保留九成以上的随机性，同时留有一点确定性的余地"。这样 alpha 会在策略接近均匀时收敛，探索强度保持有界。

公式里的 logsumexp(z) 值得单独记一笔：它是数值稳定版的 log Σ ez。直接先算 exp 再求和，logits 稍大就会溢出成 inf；logsumexp 先减去最大 logit 再计算，同价但永远安全。这也解释了代码里统一使用 F.log_softmax 的原因：前者内部就是 logsumexp 的实现，既稳又快，且是后面所有比率、权重计算的数值底座。

4. Q 网络为什么不再吃动作

连续版 Q(s,a) 必须把动作当输入才能对动作求梯度。离散版也可以这么写（one-hot 拼接），但更省参数的写法是让网络一次输出所有动作的 Q 值向量。它带来的直接好处：期望目标用一次前向就能拿到全部动作的价值；代价是每个状态的动作之间不再共享"动作嵌入"，动作极少时无所谓，动作成千上万时要把动作输入拼回去。

5. 数值算例：熵缺口、初始 α 的走向与溢出阈值

CartPole 的均匀分布熵是 log 2 ≈ 0.6931，目标熵 0.98×0.6931 ≈ 0.6793，两者只差 0.0138。训练最初 logits 接近零、分布接近均匀，熵 0.693 高于目标 0.679，温度损失对 log α 的梯度等于熵缺口 H−Htarget≈+0.014；梯度下降把 log α 每步压低 lr×0.014≈4.2e-6，方向向下、幅度极小。策略开始变确定后，熵降到 0.2 量级，缺口变成 0.679−0.2≈0.48，log α 每步上移约 1.4e-4，比初始阶段快约 35 倍。这解释了两段式的 α 轨迹：先安静、后上抬，最终停在"熵≈0.679"的平衡点。把这两个数字与连续版第 032 章的每步 1e-4 量级对照：离散版的温度缺口被 0.98 系数压得很小，α 的移动节奏天然比连续版慢一档。

另一个可以量化的边界是 logsumexp 的防溢出阈值。float32 的最大值约 3.4×1038，指数在 88.7 附近就会溢出；若某个 logit 涨到 500 这样的常见数量级，直接 exp 求和会得到 inf，后续除法变成 NaN。logsumexp 先减去最大值再计算，等价变形后结果不变，却把最大的指数项压回 0，这就是 F.log_softmax 在实现里被反复使用的理由：它不仅是方便，还是数值上的必需品。可以顺手检验：对 logits=[1000, 1001] 直接 exp 必溢出，而 logsumexp 的结果稳定在 1001.313 附近，与手算 log(e0+e1)+1000 一致。

每种目标模式：set_seed → 随机探索垫池 → 每步一次更新：评论家（双 Q 目标 + 期望或采样构造 V(s′)）→ 演员（对全动作求期望的精确损失）→ 温度（离散熵公式）→ 软更新 → 每 5000 步评估并记录熵、|Q|、alpha 轨迹。两种模式共用其余全部代码，唯一变量在 v_next 的构造方式。

补充两条取值说明：隐藏层宽度沿用 256 是为了让离散版与连续版的代码差异最小化，CartPole 的观测只有 4 维，64 宽其实已经足够，容量过剩下的性能差异在评估噪声之内；评估回合数取 5 是因为 CartPole 单回合上限 500 步、回报就是步数，5 个回合的均值已经能反映策略水平，评估频率 5000 步则保证两种目标都在同一批评估点上对比。再补两个评估协议的数字：3 万步预算共产生 6 个评估点，确定性策略的回报集中在 450～500，评估点之间 50 分以内的差距通常不算"明显差异"，判定优劣仍要落到多 seed 的均值上。

与前一章的差异点

  • 环境从 Pendulum-v1 换成 CartPole-v1，动作空间从 1 维连续变成 2 个离散动作。
  • GaussianPolicy 换成 CategoricalPolicy；没有 tanh、没有 log_std、没有重参数化。
  • Q 网络输入去掉动作维度，输出从标量变成向量；评论家目标新增"全动作期望"分支。
  • 目标熵公式从 −dim(A) 换成 0.98·log|A|。
  • 策略损失与温度损失都改为"对全动作求和"的精确期望，不再使用单样本估计。

关键代码与解读

片段 1：离散网络两件套

class QNetDiscrete(nn.Module):
    """Q(s, ·)：输入状态，输出向量 (B, n_actions)。"""

    def __init__(self, obs_dim, n_actions, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.ReLU(),      # 只吃状态：动作不再是输入
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, n_actions),               # 每个动作一个分数
        )

    def forward(self, obs):
        return self.net(obs)

class CategoricalPolicy(nn.Module):
    """离散策略：输出 logits，采样/确定性动作都在类别分布上完成。"""

    def __init__(self, obs_dim, n_actions, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, n_actions),               # 输出 logits：softmax 分布的参数
        )

    def forward(self, obs):
        return self.net(obs)

解读：两个网络的改动加起来只有"输入输出形状"四行，但它们是离散化的地基。（1）QNetDiscrete 的输入只有 obs_dim，动作与状态的拼接结构被省去：输出层直接给出 n_actions 个分数，一次前向就拿到全部动作的价值。期望目标之所以"几乎免费"，就是因为这份输出本来就在。（2）动作之间不再共享"动作嵌入"：动作只有 2 个时这是纯收益（参数更少、计算更快）；动作成千上万时（比如推荐系统）就要权衡是否改回 (s,a) 拼接结构。（3）CategoricalPolicy 与 Q 网络结构相同但语义不同：它的输出是 logits，配合 log_softmax 得到 log 概率；torch.distributions.Categorical 也可以直接吃 logits，两种用法在本章都会出现。

片段 2：评论家目标，两条路径的唯一分岔

        with torch.no_grad():
            next_logits = self.policy(next_obs)
            next_log_probs = F.log_softmax(next_logits, dim=-1)
            next_probs = next_log_probs.exp()
            q_next_min = torch.min(self.q1_target(next_obs),
                                   self.q2_target(next_obs))     # (B, A)
            if self.target_mode == "expectation":
                # 期望目标：V(s') = sum_a pi(a|s') * (Q_min - alpha * log pi)
                v_next = (next_probs * (q_next_min -
                                        self.current_alpha * next_log_probs)).sum(dim=-1)
            else:
                # 采样目标：从下一个策略里抽一个动作，用它的 Q 值
                dist = torch.distributions.Categorical(probs=next_probs)
                a_next = dist.sample()
                q_next_a = q_next_min.gather(1, a_next.unsqueeze(1)).squeeze(1)
                logp_next_a = next_log_probs.gather(
                    1, a_next.unsqueeze(1)).squeeze(1)
                v_next = q_next_a - self.current_alpha * logp_next_a
            target = rew + self.gamma * (1.0 - done) * v_next

解读：本章的实验开关就在这个 if/else 里，两种路径共享前面四行、只在 v_next 处分开。（1）q_next_min 的形状是 (B, A)：双 Q 取 min 先把"每个动作的保守价值"合成一个向量，之后两条路径都在这个向量上工作。（2）期望路径是"概率加权求和"：Σ π·(Q_min − α·log π)，一次算完全部动作；它天然平滑，没有"这一批恰好抽到差动作"的噪声。（3）采样路径用 Categorical(probs).sample() 抽一个动作，再用 gather 取出对应的 Q 与 log π，非常像连续版，但目标值的方差明显更大。（4）两条路径的期望在数学上相同，差异全在方差上：这就是本章要量化的"平滑性"。no_grad 包住整段：目标只是回归的靶子。

片段 3：演员与温度，全期望的两处应用

        # ---------------- 2) 演员：对全部动作求期望的策略损失 ----------------
        logits = self.policy(obs)
        log_probs = F.log_softmax(logits, dim=-1)
        probs = log_probs.exp()
        with torch.no_grad():
            q_min = torch.min(self.q1(obs), self.q2(obs))          # (B, A)
        # E_{a~pi}[ alpha * log pi(a|s) - Q(s,a) ]
        policy_loss = (probs * (self.current_alpha * log_probs - q_min)).sum(dim=-1).mean()

        self.policy_optimizer.zero_grad()
        policy_loss.backward()
        self.policy_optimizer.step()

        # ---------------- 3) 温度系数：熵目标为 0.98*log(|A|) ----------------
        with torch.no_grad():
            log_probs_new = F.log_softmax(self.policy(obs), dim=-1)
            probs_new = log_probs_new.exp()
            entropy = -(probs_new * log_probs_new).sum(dim=-1)      # (B,)
        alpha_loss = (self.log_alpha * (entropy - self.target_entropy)).mean()

解读：离散版的最大优势在这一段兑现，所有期望都是精确计算。（1）演员损失 Σ π·(α·log π − Q_min)：对每个状态的所有动作按概率加权求和，不再"抽一个动作估梯度"。注意 probs 与 log_probs 都带梯度（策略参数要对"概率分布本身"求导），q_min 则来自 no_grad，演员不反向影响评论家。（2）温度损失这里的写法与连续版有一处符号差异：连续版是 −(log_alpha·(logp + target))，这里写成 log_alpha·(entropy − target)。因为离散的 entropy = −Σπ log π 是正数、目标也是正数，写成"熵缺口"（entropy − target）更直观：熵低于目标 → 缺口为负 → 梯度下降抬升 log_alpha → 加大探索。（3）entropy 在 no_grad 下算：它是温度损失的"观测量"，只喂给 log_alpha，不应把梯度引回策略。

片段 4：目标熵公式与动作选择

        # 离散版目标熵：0.98 * log(动作数)，传负值表示"用默认公式"
        if target_entropy < 0:
            self.target_entropy = 0.98 * math.log(n_actions)
        else:
            self.target_entropy = float(target_entropy)

    @torch.no_grad()
    def act(self, obs, deterministic=False):
        obs_t = torch.as_tensor(obs, dtype=torch.float32).unsqueeze(0)
        logits = self.policy(obs_t)
        if deterministic:
            return int(torch.argmax(logits, dim=-1).item())     # 评估：argmax
        probs = torch.softmax(logits, dim=-1)
        return int(torch.multinomial(probs, num_samples=1).item())  # 训练：采样

解读：两个小段，一个是超参数换算，一个是行为接口。（1）目标熵公式 0.98·log|A| 里，math.log(n_actions) 是均匀分布的熵；0.98 的系数保留"一点点确定性的余地"。CartPole 上它约等于 0.679，比连续版的 −1 更有物理意义（熵不可能为负）。"传负值用默认公式"的设计让命令行参数保持简单：想覆盖就传正数。（2）act() 的两条路径对应两种场合：评估用 argmax（确定性极限），训练用 multinomial 采样（探索来源）。（3）注意采样前先 softmax 再 multinomial，与直接对 logits 采样等价，但显式的概率张量便于阅读与调试。这个接口与前几章的 act() 语义完全一致，评估框架因此不需要任何改动。

python code/ch037.py           # expectation vs sample：CPU 约 5–8 分钟
python code/ch037.py --quick   # 快速跑通：约 1–2 分钟
python code/ch037.py --targets sample --max-steps 40000   # 只跑采样目标

以实跑为准：两种目标都能把 CartPole 训练到 450～500 的评估回报；期望目标通常 1 万步左右就有明显回报、|Q| 曲线更平滑；采样目标 |Q| 抖动更大、达标步数可能更多。健康轨迹：熵从 0.693 降到 0.1～0.3，|Q| 稳定在 20～80 之间。

常见坑

  • gather 维度写错：gather(1, act) 要求索引形状与输出形状一致，未 unsqueeze(1) 会直接报维度错误，或者广播出 (B,B) 的假损失。修复：先打印形状再跑训练。
  • 策略损失里采样单个动作估梯度：离散动作的"采样 + log π"虽然可跑，但方差大。动作数是个位数时，全期望几乎免费，没有理由不用。
  • 目标熵照搬连续版 −1：0.98·log2 = 0.679 与 −1 相差甚远；用 −1 会让 alpha 长期压在低位、策略过早确定，CartPole 上表现为回报曲线抖且上不去 300。
  • 评估时用 Q 的 argmax 作为动作：策略的 argmax 才是训练目标的产物，Q 的 argmax 只是它的近似。混用会使评估与训练的策略不一致，回报对不上训练日志。修复：评估统一走 policy 的 argmax。
  • done 把 CartPole 的 500 步截断也算进去：到达步数上限是时间截断，必须继续 bootstrap；写错会让价值函数系统性低估长回合。

练习与思考

  1. 把 --target-entropy 设成 0.3 和 0.9 各跑一次 expectation 模式，观察熵轨迹与评估回报的变化。★
    提示
    0.3 太确定、0.9 强迫探索（均匀熵才 0.693，0.9 追不到，alpha 会一直涨）。重点看 alpha 是否稳定收敛。
  2. 把采样目标里的 a_next 换成"argmax Q 的动作"（离散 DQN 风格），再跑一次。它与两种现有目标的关系是什么？★★
    提示
    argmax Q 给出最贪心的目标，是"软 Bellman"去掉熵项的极限，Q 值幅度通常最高。对比 |Q| 轨迹与回报。
  3. 给评论家目标里的 q_next_min 换成 0.5*(q1_target+q2_target)，观察 CartPole 这种正奖励、多步任务上平均组合与 min 组合的差异。★★
    提示
    CartPole 回报恒为正，过估计导致 Q 虚高、策略变化慢。比较两种组合下 |Q| 的终值差距。
  4. 把离散策略换成"连续 SAC 的 tanh 高斯 + 动作取整"，去拟合 CartPole：图省事的连续化移植会踩哪些坑？★★★
    提示
    取整是不可导操作，策略梯度收不到正确方向；边界动作（±1）对应两个类别，采样密度在端点堆积。跑 5000 步感受一下回报是否明显低于分类策略。
  5. 取 π = [0.5, 0.5]、Q = [10, 5]，重算采样目标的方差并与框中的 3.57 对比，解释为什么动作分布越均匀、Q 差距越大，噪声越明显。★
    提示
    两种动作各 0.5 时，目标在 10.045 与 5.322 之间等概率跳变，方差 = (10.045−5.322)²/4 ≈ 5.58。对照框中 3.57 的读法，理解"概率分布越平、方差越大"。

小结

  • 离散 SAC 的三处改动：Categorical 策略、Q 输出动作向量、Bellman 目标对全动作求期望；策略与温度损失同样改为精确求和。
  • 期望目标把下一个动作的采样噪声从目标中消掉，通常比采样目标更早起飞、曲线更平滑。
  • 离散目标熵用 0.98·log|A|：接近均匀分布但保留一点确定性余地。CartPole 上约 0.679，介于 0 与均匀熵 0.693 之间。
  • CartPole 上两种目标都能到 450～500，差别主要体现在收敛速度与 |Q| 稳定性上。动作数很大时，期望目标的全动作求和成本上升，才需要退回采样目标。
  • 离散版的精确期望是"用计算换方差"的典型：动作数是个位数时，几十次浮点乘加就能消掉一层抽样噪声，性价比极高。
