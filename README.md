# niumaloveteaching · 机器人学习课程库

10 门课程、1000 讲，全部为独立 HTML 页面。

| # | 课程 | 主题 |
|---|------|------|
| 01 | 深度强化学习课程 | PPO、SAC 与多智能体系统 |
| 02 | 多智能体强化学习课程 | CTDE 框架与协同算法 |
| 03 | 分布式强化学习课程 | Ray RLlib 训练与调优 |
| 04 | 多机器人协同学习课程 | ROS2 通信与系统集成 |
| 05 | 机械臂规划学习课程 | ROS2 MoveIt2 运动规划与操作 |
| 06 | 柔顺控制学习课程 | 阻抗/导纳、力控与稳定性 |
| 07 | 机器人仿真学习课程 | Isaac Sim 强化学习训练 |
| 08 | 具身智能学习课程 | VLA 与世界模型联合训练 |
| 09 | 视觉语言导航课程 | VLN · 指令 grounding 与长程导航 |
| 10 | 目标物体导航课程 | ObjectNav · 从探索到开放词汇 |

## 最近更新

## 使用

- 从首页进入课程；每门课程的 index.html 为 100 讲目录。
- 第 01 门课附运行脚本：pip install -r rl-course-100/requirements.txt；python rl-course-100/code/ch001.py --quick。
