第四篇 · 规模、记忆与泛化方法论

第 067 讲｜局部度量地图与预训练

第 037 讲把 BEVBert（An 等 2023，ICCV 2023，arXiv:2212.04385v2）放进混合地图对照，本讲只做一件事：把局部度量地图推到能写公式、能算误差、能设计消融的深度。21 × 21 单元、0.5 米边长的地图把 14 × 14 网格特征投影到以智能体为中心的 10.5 米空间，三层预训练目标把从零训练 60.24 SR 推到 74.88；误差算例显示，5 米处 2 度朝向噪声配 10% 深度误差、30 步历史下投影偏差约 2.18 个单元，这是默认只整合一阶历史的原因。

  • 主题：局部度量地图 / 网格投影 / 地图预训练 / 误差传播
  • 关键公式：σ总2 ≈ (c/√12)2 + (r·σψ·√t)2 + (r·ε)2；可靠距离上界 r < c/(2·δψ)
  • 预计学时：70 分钟
  • 前置讲：第 066 讲（记忆范式总览（承 039））

学习目标

  • 会算：投影量化误差（0.289 个单元）、单点方位与深度误差、随机游走累积误差与可靠距离上界；核对 κ 与地图尺寸消融。
  • 会解释：局部度量图如何聚合不完整观察、消除重复与处理碰撞；极坐标位置编码与可导航嵌入各自的作用。
  • 会实现：网格特征投影与平均池化、κ 阶历史整合与 node 到 cell 映射、HSAP 动态融合与 MSI 多标签损失三段代码。
  • 会判断：地图尺寸、单元边长、历史阶数与深度来源四个设计变量的取舍，并说明各自的证据。
  • 会设计：为新平台写地图预训练目标与误差预算表，明确可靠半径与降级路径。

背景与动机

离散全景输入有两个结构性缺陷：单视角观察不完整，跨视角存在重复观察。BEVBert 论文的引例是「书柜对面的第二间卧室」：卧室与书柜在不同视角里各出现一次，模型无法判断眼前的两张图描述同一个物体还是两个实例。地图路线把观察投影到统一的俯视平面，重复在投影中自然合并，不完整被邻域补全；代价是引入位姿与深度两类噪声，误差还会随历史整合累积。

第 066 讲把度量图列为固定尺寸载体：21 × 21 单元、1.29 MiB 每样本、2 GiB 门槛下轻松通过；但固定尺寸不等于低成本，短期 transformer 计算量随地图边长近似平方增长（11 / 21 / 31 对应 4.5 / 15.2 / 32.7 GFLOPs）。第 037 讲讲了混合地图的结构与结果，本讲补三块：投影的几何推导、三层预训练目标的具体形式、以及误差如何决定可靠半径与历史阶数。这三块决定地图方案在真机与估计深度条件下的可用性。

本讲的产出是一张地图误差预算表、一张预训练目标消融表与一段投影代码，直接服务第 068 讲的全局拓扑与跨尺度推理：局部地图管短程推理，全局拓扑管长程规划，两者的分工边界由误差半径决定。训练与评测的协议细节（R2R-CE 低层 500 步、规划 15 步、val 集已知 8 条标注错误）在第 048 讲已建立，本讲引用时沿用。

核心原理

本讲按「问题、地图构建、混合结构、预训练目标、误差传播、尺寸与计算、训练配置、失效模式」八步展开；数字以 arXiv:2212.04385v2 的表 1 至表 8 为准，误差算例由 Python 实算，属本讲推导口径。

1. 地图构建：从 14 × 14 网格特征到 21 × 21 单元

输入侧用 ViT-B/16-CLIP 提取两类特征：每个视角的图像级向量与 MLP 头之前的 14 × 14 网格特征；深度图下采样到同一尺度（14 × 14），位姿由仿真器提供（离散环境由导航图推导）。局部度量图以当前节点为中心，把 κ 阶以内已访问节点的网格特征按深度与位姿投影到地面，落在同一单元的多个特征做逐元素平均。

规模实算：单个全景 12 个视角、每视角 196 个网格特征，合计 2,352 个特征；κ = 1 时最多整合两个节点的 4,704 个特征，摊到 441 个单元平均 10.67 个特征每单元（上界口径，实际受遮挡与视场限制更少）。极坐标编码让同一几何位置在不同步获得相近表示，可导航嵌入把「单元属于局部动作空间」这一先验显式注入；两者共同承担跨步的几何一致性。

2. 混合结构：局部推理与全局规划的分工

地图只覆盖局部视野，全局依赖由拓扑图承担：节点分已访问、当前与 ghost（可导航未探索）三类；ghost 节点由多个位置的观察累积表示；全局动作空间包含所有已观测节点，长距离动作选完后用 Dijkstra 在图上规划最短路径。把两侧单独使用与合用做对照（R2R val unseen，论文表 5），分工的必要性直接体现在数字上。

3. 地图预训练：三层目标

预训练在离线的专家轨迹上构建混合地图，用三个目标学习地图表示，再在仿真器里在线微调。三层目标的分工是：语言建模学通用对齐，动作预测学决策相关表示，语义想象学补全未观察区域。

  • MLM（掩码语言建模，masked language modeling）：指令按 15% 概率掩码，拓扑与度量两路输出的词表示相加后预测被掩词，负对数似然损失。它提供跨模态基础对齐。
  • HSAP（混合单步动作预测，hybrid single action prediction）：把局部动作单元经 cell 到 node 反变换对齐到全局动作空间，节点分数与单元分数按智能体状态动态融合。
  • MSI（掩码语义想象，masked semantic imagination）：地图单元按 15% 概率掩码，用多标签分类预测 40 类语义（标签来自 Matterport3D），二值交叉熵损失；目标是补全未观察区域、降低决策不确定性。
si = δt·siG + (1 − δt)·siM（i ∈ AG ∩ AG′），否则 si = siG；δt = σ(FFN([ñ0; m̃c,c])) sG 为节点分数，sM 为转回全局空间的单元分数；ñ0 为 stop 节点表示，m̃c,c 为中心单元表示，两者共同决定门控系数

消融账（R2R val unseen，论文表 6）：从零训练 60.24 SR / 48.29 SPL；加 MLM 到 73.52 / 60.13；再加 HSAP 到 74.03 / 63.03（SPL +2.90，轨迹效率显著改善）；再加 MSI 到 74.88 / 63.60（SR +0.85、SPL +0.57）。增量最大的两项是 MLM 与 HSAP：前者说明地图表示需要大规模语言监督，后者说明表示要按决策目标塑形；MSI 提供的是对未观察区域的补全先验。

4. 误差传播：投影误差如何累积

投影误差有四个来源：单元量化、方位角误差、深度相对误差与位姿漂移。量化误差在单元内均匀分布，均方根为 c/√12；方位角误差 δψ 把距离 r 处的落点沿切向平移 r·δψ；深度相对误差 ε 造成径向平移 r·ε；位姿漂移按随机游走近似，t 步后角度标准差约为每步标准差的 √t 倍。四者近似独立，合成误差取平方和：

σ总2 ≈ (c/√12)2 + (r·σψ·√t)2 + (r·ε)2；可靠距离上界 r < c / (2·δψ) c = 0.5 米；σψ 为每步朝向噪声标准差；ε 为深度相对误差；要求单步切向误差不超过半个单元时取右式

数值算例（Python 实算，取 r = 5 米）：量化项 0.1443 米，折 0.289 个单元；方位误差 1 度 / 2 度 / 5 度分别给出 0.087 / 0.175 / 0.436 米，折 0.17 / 0.35 / 0.87 个单元；深度误差 5% / 10% / 20% 分别给出 0.25 / 0.50 / 1.00 米，折 0.50 / 1.00 / 2.00 个单元。可靠距离上界：朝向噪声 1 度时 14.32 米，2 度时 7.16 米，5 度时 2.86 米。累积漂移：每步 2 度、30 步后角度漂移 10.95 度，切向误差 0.956 米，折 1.91 个单元；与 10% 深度误差和量化项合成后总均方根 1.088 米，折 2.18 个单元。

这张表解释了三个设计。第一，可靠半径由朝向噪声决定：2 度噪声下超过 7.16 米的投影不再可靠，10.5 米窗口内只有内圈可信，外圈主要提供背景与房间轮廓。第二，历史整合的阶数要小：κ 从 1 增到 2 时（论文表 8），SR 从 74.88 升到 75.18（+0.30），SPL 从 63.60 降到 62.71（−0.89）；更久历史带来更多已漂移的投影，污染近场判断。第三，深度噪声影响有限：真值与估计深度在混合设置下只差 0.21 SR，因为投影发生在特征空间，深度分辨率为 14 × 14，粗糙深度已足够决定大致的落点区域。

6. 训练与评测配置

预训练在离线专家轨迹上以批 64 训练 10 万次迭代（4 张 A100，约 10 小时，共 640 万样本）；微调在仿真器里交替使用 teacher-forcing 与 student-forcing，批 16、4 万次迭代（约 20 小时，共 64 万样本）。两个编码器各 4 层、文本编码器 9 层、隐藏维度 768，用 LXMERT 预训练权重初始化（RxR 用 RoBERTa）。推理时在线构建混合地图，贪心选择分数最高的节点或 stop；选中非相邻节点时用 Dijkstra 规划最短路径；触发 stop 或达到步数上限时结束（R2R-CE 低层 500 步、规划 15 步，沿用第 048 讲口径）。

7. 适用边界与失效模式

  • 没有高度维度：地图为平面俯视，多楼层需要楼层标识与楼梯节点显式建模，论文把多楼层列为未解问题。
  • 可靠半径受限：2 度朝向噪声下可靠半径约 7.16 米，小于 10.5 米窗口；外圈单元用于背景推断，不可用于精确落点判断。
  • 历史整合受漂移约束：κ 增大带来的收益被污染抵消，默认取 1。
  • 位姿依赖：投影直接使用位姿；真机的位姿漂移若超过每步 2 度，误差预算需重算，可靠半径收缩。
  • 特征空间投影的对偶性：对深度噪声鲁棒，但地图单元停留在特征空间，无法直接用于精细避障，低层控制仍由独立控制器承担（第 042 讲）。

设计决策：先定覆盖半径，再定分辨率

预算有限时的顺序是：先按朝向噪声算可靠半径，据此确定覆盖边长（使半边长不超过可靠半径，2 度噪声下 5.25 米小于 7.16 米）；在覆盖边长固定后，单元边长取 0.5 米与 1.0 米两档做对照，用近距离指代类指令的成功率判断分辨率是否需要提高；最后调节历史阶数，判据是 SPL 不下降。判据来自表 7 与表 8 的两组证据：覆盖半径的收益远大于分辨率，历史只在近场有正贡献。

与相邻讲的分工：第 037 讲给出混合地图的结构与主结果；本讲补投影几何、预训练目标形式与误差传播；第 066 讲提供内存预算口径（1.29 MiB 每样本、批 64 时 82.69 MiB）；第 068 讲接过全局一侧，讨论拓扑抽象与跨尺度推理。三讲合起来构成「局部度量加全局拓扑」的完整方法学。

关键代码与解读

三段代码：网格投影与平均池化、κ 阶历史整合与单元嵌入、HSAP 融合与 MSI 多标签损失。

片段 1：网格特征投影与碰撞池化

import torch

def project_view(grid, depth, pose, c=0.5, n=21):
    """把单视角 14x14 网格特征投影到以智能体为中心的俯视网格。
    grid: (14, 14, D)；depth: (14, 14)；pose: (x, y, psi)；返回 (n, n, D) 与计数。
    """
    h, w, d = grid.shape
    _, cols = torch.meshgrid(torch.arange(h), torch.arange(w), indexing="ij")
    # 以视场中心为参考的方位与俯仰近似；实际实现按相机内参展开
    phi = (cols - (w - 1) / 2) / w * torch.pi / 2 + pose[2]
    rng = depth  # 简化口径：水平距离取深度值
    qx = pose[0] + rng * torch.cos(phi)
    qy = pose[1] + rng * torch.sin(phi)
    u = torch.floor((qx - pose[0]) / c + n / 2).long().clamp(0, n - 1)
    v = torch.floor((qy - pose[1]) / c + n / 2).long().clamp(0, n - 1)
    acc = torch.zeros(n * n, d)
    cnt = torch.zeros(n * n, 1)
    flat = (u * n + v).reshape(-1)
    acc.index_add_(0, flat, grid.reshape(-1, d))     # 落点相同的特征累加
    cnt.index_add_(0, flat, torch.ones(h * w, 1))
    return acc / cnt.clamp(min=1), cnt                # 逐元素平均处理碰撞

解读：（1）投影以当前节点为原点，u、v 由世界坐标相对位移除以单元边长得到，clamp 把视野外落点并到边界；（2）index_add_ 把落在同一单元的特征累加，再除以计数实现平均池化，计数向量可用于掩码空单元；（3）示例把水平距离简化为深度值，真实实现要按相机内参与俯仰角分解；无论是简化还是完整版本，误差预算都按本讲的四个来源逐项核算。

片段 2：κ 阶历史整合与单元嵌入

def build_local_map(topology, current, kappa, project_fn):
    """整合 κ 阶内已访问节点的投影，生成局部度量图。"""
    nodes = topology.visited_within(current, kappa)   # 含当前节点，按阶数排序
    maps, counts = [], []
    for node in nodes:
        g, c = project_fn(node.grid, node.depth, node.pose)
        maps.append(g)
        counts.append(c)
    stack = torch.stack(maps)                          # (K, n, n, D)
    cnt = torch.stack(counts).sum(0)
    merged = stack.sum(0) / cnt.clamp(min=1)           # 跨节点再次平均
    cnt_embed = (cnt > 0).float()                      # 空单元掩码
    return merged, cnt_embed

def cell_embedding(merged, cnt_embed):
    """叠加极坐标位置编码与可导航嵌入。"""
    n = merged.shape[0]
    idx = torch.arange(n) - (n - 1) / 2
    yy, xx = torch.meshgrid(idx, idx, indexing="ij")
    theta = torch.atan2(yy, xx)
    dis = torch.sqrt(xx ** 2 + yy ** 2) / (n / 2)      # 归一化距离
    pos = torch.stack([torch.cos(theta), torch.sin(theta), dis], -1)
    return torch.cat([merged, pos, cnt_embed], -1)     # 拼接后送入短期 transformer

解读：（1）历史节点按阶数 Q 查询，κ = 1 只整合当前与前一节点，与误差预算的结论一致；（2）跨节点平均与单元内平均共用同一套计数逻辑，落到同一单元的历史观察被稀释；（3）极坐标编码取相对中心的角度与归一化距离，可导航嵌入以「单元是否有投影」近似表达通行先验，真实实现中由局部动作空间显式标注。

片段 3：HSAP 融合与 MSI 多标签损失

import torch.nn.functional as F

def hsap_loss(node_score, cell_score, delta, target, global_ids):
    """混合单步动作预测：两路分数按门控系数融合后做交叉熵。"""
    fused = node_score.clone()
    inter = global_ids                                  # 单元转回全局后的下标
    fused[:, inter] = delta * node_score[:, inter] + (1 - delta) * cell_score
    return F.cross_entropy(fused, target)               # 已访问节点在外部掩码

def msi_loss(pred_logits, labels, mask_ratio=0.15):
    """掩码语义想象：对被掩单元做 40 类多标签二值交叉熵。"""
    b, n2, c = pred_logits.shape
    keep = (torch.rand(b, n2, device=pred_logits.device) < mask_ratio)
    logits = pred_logits[keep]                          # 只监督被掩码的位置
    target = labels[keep].float()                       # 每单元可含多个类别
    bce = F.binary_cross_entropy_with_logits(logits, target, reduction="none")
    return bce.sum(-1).mean()                           # 先按类求和，再按单元平均

解读：（1）门控系数 δ 由 stop 节点与中心单元表示共同生成，融合只发生在两路都覆盖的全局动作上，其余动作保留节点分数；（2）MSI 的掩码比例与 MLM 一致取 15%，监督只作用于被掩单元，未掩单元不产生梯度；（3）多标签设定下先对 40 类求和再按单元平均，避免类别数放大损失尺度；标签来自 Matterport3D 语义层，跨数据集迁移时要核对类别映射。

常见坑

  • 把单元边长当覆盖范围：0.5 米与 21 两个数放在一起，误以为地图覆盖 21 米。根因是漏乘单元边长。修复：配置表同时写 N、c 与 N·c 三个值；扩尺寸前先按表 7 算计算量倍数。
  • 训练与评测的深度来源不一致且未标注：训练用真值、评测用估计，或反之。根因是协议脚注缺失。修复：统一来源并标注；若要混用，按论文口径做真值与估计的对照（混合设置差 0.21 SR），把差值写进误差预算。
  • 地图尺度取偶数：智能体落在四个单元的交界，极坐标编码失去唯一中心。根因是未遵守奇数尺度约定。修复：N 取 11 / 21 / 31 这类奇数，中心单元即智能体位置。
  • 历史阶数一味加大：以为历史越多越稳，SPL 却下降。根因是漂移投影混入近场（κ = 2 时 SPL −0.89）。修复：κ 默认取 1，增大前先跑 SPL 对照，必要时对历史投影做衰减加权。
  • 把预训练收益记到地图结构名下：从零训练 60.24 到 74.88 的增量主体来自三层预训练目标，地图结构本身的边际贡献要用「同预训练配方下只改载体」的对照来测。修复：结构消融与配方消融分表，报告时说明预训练数据与轮数。

小结

  • 局部度量地图把 14 × 14 网格特征投影到 21 × 21 单元、0.5 米边长的俯视平面（覆盖 10.5 米），用平均池化处理碰撞，用极坐标位置编码与可导航嵌入保持几何一致性。
  • 混合结构的分工有消融支撑：只用拓扑 70.25 / 61.29，只用度量 60.64 / 52.17，混合 74.67 / 63.63（均为 R2R val unseen、估计深度口径）。
  • 预训练三层目标：MLM 把从零训练 60.24 SR 推到 73.52，HSAP 再补 2.90 SPL，MSI 再补 0.85 SR；增量主体属于预训练配方，不属于地图结构。
  • 误差算例：量化 0.289 个单元；5 米处 2 度朝向误差折 0.35 个单元、10% 深度误差折 1.00 个单元；30 步随机游走漂移折 1.91 个单元，合成 2.18 个单元。可靠距离上界 r < c/(2δψ)，2 度噪声下为 7.16 米。
  • κ 默认取 1：κ = 2 时 SR +0.30 但 SPL −0.89；覆盖半径比分辨率更关键，11 × 11 配 1.0 米与 21 × 21 配 0.5 米只差 0.30 SR，计算量降到 4.5 GFLOPs。
