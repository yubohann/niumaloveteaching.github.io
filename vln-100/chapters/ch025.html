第二篇 · 离散方法谱系：从模块到预训练

第 025 讲｜RCM：强化跨模态匹配

匹配评论器把「从轨迹重建指令」的概率变成密集的内在奖励，与距离缩减和成功信号的外部奖励混合，用 REINFORCE 训练导航器。本讲推导回环式打分、长度归一化、折扣回报与混合权重，讲清样本构造与评论器冻结的工程理由，并交代跨方法比较的动作空间与数据口径。

  • 主题：跨模态匹配 / 内在奖励 / REINFORCE / 评论器冻结
  • 关键公式：Rintr = (1/n) log pβ(X | τ)；At = Rextr + δRintr；∇θL = −At∇θlog πθ(at | st)
  • 关键数字：γ = 0.95、δ = 2、步数上限 10；SPL 28 → 35、成功率 +8.1 个百分点（测试集，R2R）
  • 预计学时：60 分钟
  • 前置讲：第 024 讲

学习目标

  • 会推导：回环式匹配分数（从轨迹重建指令的概率）如何定义、为何要按指令长度归一化，以及归一化缺失时奖励尺度如何漂移。
  • 会实现：轨迹采样、折扣外部回报、内在奖励混合与 REINFORCE 更新四步构成的训练循环，并正确放置终点成功信号。
  • 会算：γ = 0.95 下的折扣因子表与累计回报，δ 对优势符号的影响，以及使两条路线排序翻转的 δ 阈值。
  • 会判断：评论器冻结与参数共享的取舍，说明冻结为什么让奖励保持平稳，代价是什么。
  • 会复核：RCM 相对 Speaker-Follower 的 SPL、SR 增益（35 对 28、43.1% 对 35.0%），并核对两者共享的动作空间与数据增广口径。

背景与动机

第 024 讲的进度监控用最短路径距离生成监督信号：模型知道「离目标还有多远」，却不知道「当前轨迹在语言上是否讲得通」。这在成功判定里暴露得很清楚：R2R 只看终点是否落在目标 3 m 以内，一条完全无视指令、绕远后碰巧到达目标的轨迹会拿到成功标记；一条忠实执行指令、只差一步停止的轨迹会被判失败（Wang 等，2019，CVPR，第 1 节，图 1 的路线 B 与路线 C）。奖励与任务意图之间的这种错位，原文称为不适宜反馈（ill-posed feedback）。

RCM（Reinforced Cross-Modal Matching，强化跨模态匹配）的思路是给策略补上一个「指令保真」通道：训练一个匹配评论器（matching critic），从轨迹反推指令，重建概率越高说明轨迹与指令越吻合；这个概率作为内在奖励（intrinsic reward）加进优势函数，与外部奖励（距离缩减与成功信号）一起驱动 REINFORCE。导航器一侧则用跨模态推理结构做局部定位：轨迹历史、文本上下文、视觉上下文依次条件化，动作在 [历史; 文本; 视觉] 的联合表示上打分。原文报告：在相同动作空间与增广数据下，测试集 SPL 从 28 提升到 35，成功率从 35.0% 提升到 43.1%（Wang 等，2019，表 1）。

本讲解决四个问题：第一，回环式打分怎样定义与归一化；第二，外部奖励、内在奖励与折扣回报怎样组合；第三，采样轨迹与更新策略的训练循环怎样构造，评论器为什么先预训练后冻结；第四，结果数字的动作空间、数据与评测口径是什么，如何与第 022、024 讲的方法公平对比。第 026 讲的自监督模仿学习（SIL）会把同一个评论器当作「回放筛选器」，让代理在无标注环境中模仿自己过去的好轨迹。

核心原理

1. 从「到达」到「讲得通」：内在奖励的动机

把 VLN 写成序贯决策：状态 st 来自环境观测，动作为候选方向上的选择，外部奖励由环境给出。R2R 的外部信号只有两类：每步到目标距离的变化，以及终止时刻是否进入 3 m 阈值。两类信号合起来回答「到没到」，回答不了「怎么到的」。RCM 引入评论器 Vβ，对指令 X 与轨迹 τ 打分，并要求这个分数衡量二者的一致程度：

Rintr = Vβ(X, τ) = Vβ(X, πθ(X)) = pβ(X | τ) πθ 为导航器策略，τ = πθ(X) 为它按指令 X 执行出的轨迹；Vβ 取「在给定轨迹条件下重建出原指令」的概率，这一形式称为回环式重建（cycle-reconstruction）

实现上 pβ(X | τ) 由一个注意力序列到序列模型给出：轨迹编码器把轨迹编码成特征序列，语言解码器逐词输出指令，逐步概率相乘得到整句概率。整句概率随指令长度指数衰减，直接用会把「长指令重建得不错」的轨迹压得过低，因此原文按指令长度 n 归一化（Wang 等，2019，3.2.2 节）。工程上取对数后按词平均：

Rintr = (1/n) Σi=1..n log pβ( xi | x<i, τ ) x<i 为指令已经生成的前缀；n 为指令词数。这是长度归一化对数概率，量与「每词平均负对数似然」相反号。论文正文写概率形式并说明按长度归一化，对数域实现是本讲的换算口径，复现时需在实验记录中写明

实算一组对照：指令长度 n = 12，轨迹 A 的整句对数概率为 −8.4，轨迹 B 为 −6.0。按词平均后 A 为 −0.700、B 为 −0.500，B 好 0.2 nats/词；对应困惑度 exp(0.700) = 2.0138 与 exp(0.500) = 1.6487。整句概率之比为 exp(2.4) ≈ 11.02 倍，按词平均后差距被压缩到 0.2 nats，这才是适合作为奖励的尺度。若省略归一化，同一条好轨迹在长指令上的分数会系统性偏低，策略会偏好针对短指令的改进。

2. 导航器：跨模态推理结构

RCM 的导航器建立在前两讲的动作接口上：全景视图切成 m 个图像块，特征为 {vt,j}，动作在可通行方向上选择。与第 024 讲「文本与视觉各做一次定位、动作依赖 [ht; x̂t]」不同，本讲的上下文链是顺序条件化的（Wang 等，2019，3.2.1 节）：

ht = LSTM( [ vt ; at−1 ], ht−1 )，vt = attention( ht−1, {vt,j} ) 先由历史状态对全景特征做注意力，得到加权视图 vt，再与上一步动作一起更新轨迹历史 ht
ctextt = attention( ht, {wi} )，cvisualt = attention( ctextt, {vt,j} ) 文本上下文以轨迹历史为查询；视觉上下文以文本上下文为查询，形成「历史 → 文本 → 视觉」的条件链
pk = softmax( [ ht ; ctextt ; cvisualt ] Wc ( uk Wu )T ) uk 为第 k 个可通行方向的嵌入；论文附录给出的配置：语言编码 LSTM 隐藏 512、词嵌入 300，三段注意力的内部维度依次为 256、512、256，动作嵌入为 2048 维外观特征加 128 维方向特征（4 维朝向平铺 32 次），Wc 与 Wu 投影维度均为 256

导航器先做监督学习热身：用演示动作做最大似然，损失 Lsl = −E[log πθ(a*t | st)]，学习率 1e-4。这一步保证已见环境上的可用性，也让策略分布落到演示轨迹附近，之后再切换强化学习（学习率 1e-5）。参数维度是复现时的硬约束：动作嵌入 2176 维 = 外观 2048 + 方向 128，与第 023 讲的方向编码口径一致；评论器的轨迹编码器与导航器同构，但使用自己的词嵌入层（Wang 等，2019，附录 B）。

3. 奖励设计：外部项、折扣与混合

外部奖励直接对准评测目标。逐步奖励取到目标距离的缩减量，终止步取成功指示函数：

r(st, at) = Dtarget(st) − Dtarget(st+1)，t < T；r(sT, aT) = 1 [ Dtarget(sT) ≤ 3 m ] Dtarget(s) 为状态 s 到目标的距离；阈值 3 m 与 R2R 成功判定一致（Anderson 等，2018，4.4 节）

折扣累计回报把即时项与未来项相加，折扣因子 γ = 0.95（Wang 等，2019，3.3 节）：

Rextr(st, at) = r(st, at) + Σt′ = t+1..T γt′−t r(st′, at′) 注意指数为 t′ − t，从 1 开始；最后一步的成功信号按同样的折扣进入之前各步的回报

取一组距离缩减 [1.2, 0.9, 0.6, 1.4] 与末步成功 1.0，实算从 t = 0 出发的累计回报：γ 的幂依次为 1.000000、0.950000、0.902500、0.857375、0.814506，累计回报为 1.2 + 0.855 + 0.5415 + 1.200325 + 0.814506 = 4.611331，未折扣和为 5.1。折扣把远期成功信号从 1.0 压到 0.8145，这是「尽早成功」偏好与「稳定收敛」之间的折中；γ 调到 0.99 时末项变为 0.960596，远期信号更强，训练方差也随之上升。

混合优势把两条信号相加：

At = Rextr + δ Rintr，Lrl = −Ea∼π[At]，∇θLrl = −At∇θlog πθ(at | st) δ 为内在奖励权重。原文正文记作 δ，附录同一权重记作 σ，取值 2（Wang 等，2019，3.3 节与附录 A）

δ 的尺度分析可以用两组数字说明。长度归一化之后，评论器的每词对数概率大致落在 −0.5 到 −2 nats 区间，δ = 2 时内在项贡献约 −1 到 −4，与外部回报的量级（单条 10 m 路径的距离缩减总和约 8，折扣后约 4 到 5）可比但不过分。若省略归一化，整句对数概率可低到 −58 量级（29 词 × 每词 2 nats），要让 δRintr 与外部回报同量级，δ 必须降到 8.5 ÷ 58 ≈ 0.147 附近；反之若按词平均后想等价，δ 需到 8.5 ÷ 2 = 4.25。原报告取 δ = 2，与长度归一化的口径配套。

δ 还会影响「成功但偏离指令」与「失败但忠于指令」两类样本的排序。设路线 A 成功但偏离指令：Rextr = 4.611，Rintr = −1.2；路线 B 失败但忠于指令：Rextr = 1.0，Rintr = −0.2。两者优势之差为 AB − AA = (1.0 − 4.611) + δ(1.2 − 0.2) = −3.611 + δ。δ < 3.611 时 A 仍然领先，δ > 3.611 时排序翻转。这个阈值给出调 δ 的直觉：提高 δ 会让策略更愿意为指令保真牺牲到达率，实践中需要按 SPL 与 SR 的联合目标标定。

4. 样本构造：轨迹从哪来

强化学习的样本来自策略自身的交互，构造流程分四步。第一步，采样。每条指令让当前策略在环境中执行，动作按类别分布采样，不采用取最大的方式，步数上限为 10（Wang 等，2019，附录 A），轨迹上与动作一起保存逐步对数概率、距离缩减以及终止成功标记。第二步，折扣回报。按上一小节的公式从后向前累计 Rextr，指数取 t′ − t。第三步，内在打分。把整条轨迹送入评论器，得到长度归一化的回环分数 Rintr；论文以轨迹级分数加到该轨迹各步的优势上，不区分步级贡献。第四步，更新。用 At 加权对数概率的负值做一次 REINFORCE 更新。评论器本身在策略学习前用人工演示对 (X*, τ*) 预训练，学习率 1e-4，随后冻结：训练集 14,025 条指令-轨迹对，批大小 64 时每轮约 220 个更新步。

监督热身与强化训练的衔接也有数字可核：R2R 训练 split 为 14,025 条指令（第 004 讲口径），先以 1e-4 做最大似然，再以 1e-5 做策略梯度；批大小与轮数未在正文公开，复现时按显存与收敛曲线自行搜索。原文附录 E 记录了几条试错经验：稠密自底向上特征在未见环境上表现变差（稀疏视觉表示更适合导航）；位置编码对结果影响不大；ELMo 嵌入不做微调会掉分；只用内在奖励训练不稳定，混合奖励效果最好。最后一条直接支撑了本讲的混合设计。

读表有三个要点。第一，SPL 提升 7 个点、SR 提升 8.1 个点，代价是 PL 比 Speaker-Follower 略长（15.22 对 14.82），说明内在奖励把策略推向「讲得通但稍绕」的轨迹，随后由 SIL 把路径长度压回 11.97 m（第 026 讲展开）。第二，在验证集未见环境上移除内在奖励，成功率从 42.5% 降到 40.6%（−1.9 个百分点），而已见环境几乎不变（67.4% 对 67.6%）；原文的解释是内在奖励在缺少探索的未见环境里提供额外监督（Wang 等，2019，5.3 节）。第三，换成纯监督学习（去掉外部强化信号）时未见环境降到 37.7%，去掉跨模态推理结构时降到 35.7%，两条消融分别验证强化目标与推理结构的作用。

口径提醒同样重要。RCM 与 Speaker-Follower 的对比建立在三项共同设置上：全景动作空间（第 023 讲）、相同的增广数据、无束搜索的执行轨迹（原文注 4 明确说明为公平比较而共享动作空间与增广数据）。RCM 原文明说束搜索在现实中不实用，因为它要求先执行很长的搜索轨迹再决定终点，SPL 会被严重惩罚；这也是本课程反复强调的「动作空间、解码方式、轨迹记录规则三者绑定」的又一例证。跨方法引用数字时，至少核对这三项，再核对指令语言、split 与目标隐藏规则。

与相邻讲的差异

与第 022 讲的 Speaker 相比：两者的序列模型结构相近，但 Speaker 只在训练期生成增广指令、在测试期对候选路线重打分，不进入策略梯度；RCM 的评论器把「轨迹解释指令的程度」变成逐步优势里的奖励项，直接塑造策略。与第 024 讲的进度监控相比：进度由距离监督、与策略共同训练、作用于束搜索排序与回退；本讲的匹配分数由指令重建监督、冻结使用、作用于强化目标。两条路径都在给稀疏任务奖励补充密集信号，监督来源不同，工程性质不同。

关键代码与解读

三段代码覆盖评论器打分、混合优势的强化更新、评论器预训练与冻结；数值与正文算例一致。

片段 1：回环式匹配评论器

import torch
import torch.nn as nn

class MatchingCritic(nn.Module):
    """从轨迹重建指令：长度归一化对数概率作为内在奖励。"""
    def __init__(self, traj_dim=2176, emb=300, hidden=512, vocab=3100):
        super().__init__()
        self.traj_lstm = nn.LSTM(traj_dim, hidden, batch_first=True)
        self.embed = nn.Embedding(vocab, emb)
        self.dec_lstm = nn.LSTM(emb + hidden, hidden, batch_first=True)
        self.attn = nn.Linear(hidden, hidden, bias=False)
        self.out = nn.Sequential(nn.Linear(hidden, hidden), nn.Tanh(),
                                 nn.Linear(hidden, vocab))

    def forward(self, traj, tokens):
        # traj: (B, T, 2176)；tokens: (B, n) 指令词编号，首位为起始符
        enc, _ = self.traj_lstm(traj)                 # (B, T, H)
        h = torch.zeros(1, traj.size(0), self.dec_lstm.hidden_size, device=traj.device)
        c = torch.zeros_like(h)
        logps = []
        for i in range(tokens.size(1) - 1):
            q = self.attn(h[-1])                       # 解码状态作查询
            att = torch.softmax(torch.matmul(q, enc.transpose(1, 2)) / q.size(-1) ** 0.5,
                                dim=-1)
            ctx = torch.matmul(att.unsqueeze(1), enc).squeeze(1)
            out, (h, c) = self.dec_lstm(
                torch.cat([self.embed(tokens[:, i]), ctx], -1).unsqueeze(1), (h, c))
            logps.append(torch.log_softmax(self.out(out.squeeze(1)), dim=-1))
        logp = torch.stack(logps, dim=1)               # (B, n-1, V)
        target = tokens[:, 1:]
        nll = -logp.gather(2, target.unsqueeze(-1)).squeeze(-1)
        return -(nll.sum(dim=1) / nll.size(1))         # 按词平均的整句对数概率

解读：（1）返回值是长度归一化的对数概率（负值），整句概率随长度衰减的问题在除以词数后被压平；若直接返回整句对数概率，奖励尺度会与指令长度强相关。（2）解码逐步读取轨迹编码：注意力用解码状态查询轨迹特征，拼接词嵌入后进入解码 LSTM，输出层用「线性、Tanh、线性」结构映射到词表，与原文附录 B 的描述一致。（3）评论器与导航器各有一套词嵌入与编码器；共享方案见设计一节的取舍表。预训练完成后要把 requires_grad 关掉并切换到评估模式，避免策略更新时被意外改动。

片段 2：混合优势与 REINFORCE 更新

import torch

def discounted_extrinsic(rewards, gamma=0.95):
    """外部回报：逐步折扣累计，末步成功信号已包含在 rewards 中。"""
    out = []
    for t in range(len(rewards)):
        g = 0.0
        for k in range(t, len(rewards)):
            g += (gamma ** (k - t)) * rewards[k]
        out.append(g)
    return out

def collect_and_update(policy, env, instr, critic, optimizer,
                       gamma=0.95, delta=2.0, horizon=10):
    """采样一条轨迹，混合优势，做一次策略梯度更新。"""
    log_probs, rewards, traj = [], [], []
    state = env.reset(instr)
    for _ in range(horizon):                          # 步数上限 10（原文附录 A）
        probs = policy(state)
        action = torch.distributions.Categorical(probs).sample()
        log_probs.append(torch.log(probs[action]))
        state, reward, done = env.step(action)
        rewards.append(reward)
        traj.append(state.feature)
        if done:
            break
    r_extr = discounted_extrinsic(rewards, gamma)
    r_intr = critic.score(instr, torch.stack(traj))   # 轨迹级回环分数
    adv = torch.tensor([x + delta * float(r_intr) for x in r_extr])
    loss = -(torch.stack(log_probs) * adv).sum()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item()

解读：（1）折扣指数取 k − t，与公式一致；最后一步的成功标记参与所有前序状态的回报，这就是 γ 表里 0.814506 的来源。（2）内在奖励是轨迹级分数，论文把它加到该轨迹各步优势上；若要做步级归因，需要额外设计（例如按步遮蔽重建的增量），属于开放实现选择。（3）跨 episode 批处理时优势要做标准化，否则 δ 的绝对尺度会随评论器漂移；示例保留单轨迹形式便于对照公式。

片段 3：评论器预训练与冻结

def pretrain_critic(critic, loader, epochs=5, lr=1e-4):
    """用演示对预训练评论器：最大化指令的按词平均对数概率。"""
    opt = torch.optim.Adam(critic.parameters(), lr=lr)
    for epoch in range(epochs):
        for traj, tokens in loader:                   # 14,025 条演示对
            loss = -critic(traj, tokens).mean()
            opt.zero_grad()
            loss.backward()
            opt.step()
        print("epoch", epoch, "nll/word", round(loss.item(), 4))

def freeze(critic):
    """冻结评论器：关闭梯度并切换评估模式。"""
    for p in critic.parameters():
        p.requires_grad_(False)
    critic.eval()
    return critic

# 混合优势的尺度校准（正文算例）
for delta in (0.1466, 2.0, 4.25):
    good = 8.5 + delta * (-2.0)       # 每词 -2 nats 的归一化口径
    raw = 8.5 + delta * (-58.0)       # 未归一化的整句口径
    print(round(delta, 4), "归一化", round(good, 3), "未归一化", round(raw, 3))

解读：（1）预训练损失取负的平均对数概率，与片段 1 的返回值配套；批大小 64 时每轮约 220 步（14,025 ÷ 64 向上取整）。（2）冻结在强化主循环开始前执行一次；若中途需要继续训练评论器，应重新校准 δ，因为奖励尺度已经改变。（3）最后一段打印尺度对照：δ = 0.1466 在未归一化口径下与外部回报平衡，δ = 2.0 在每词归一化口径下的内在项贡献 −4，量级与外部回报相当。这组数字解释了为什么「δ = 2」只在长度归一化口径下成立。

常见误区

  • 省略长度归一化：模型对短指令的保真度远高于长指令，内在奖励被长度支配。根因：整句对数概率随词数线性下降，29 词的指令整句概率可比 12 词低十几个 nats。修复：按词平均后再进优势；在训练日志中同时记录每词与整句两种口径，核对 δ 的取值与口径配套。
  • 评论器未冻结：训练早期指标正常，后期奖励上升而成功率下降。根因：策略梯度同时改变评分函数，评论器向「给当前策略高分」的方向漂移，形成自证循环。修复：预训练后冻结并切到评估模式；若要周期性更新，使用目标网络或滞后副本，并在更新后重新校准 δ。
  • 只用内在奖励：策略学会输出「容易重建指令」的保守轨迹，到达率下降；训练本身也不稳定。根因：重建分数与到达目标只是相关，优化前者不等于优化后者；原文附录 E 明确记录纯内在奖励训练不稳定。修复：保持外部奖励主导，内在项按 δ 加权；用消融实验确认 ΔSR 与 ΔSPL 的净收益。
  • 终点奖励错位：折扣累计出现方向错误，或成功标记被放在 T+1 步。根因：公式中 r(sT, aT) 是终止步的即时奖励，指数从 t′ − t 起算；实现时容易把成功项再乘一次 γ 或漏掉逐步项。修复：用正文算例做单元测试，断言 [1.2, 0.9, 0.6, 1.4, 1.0] 的 t = 0 回报为 4.611331。
  • 跨方法口径混用：把 RCM 的 35 SPL 与未共享动作空间或增广数据的旧方法直接比较。根因：RCM 的增益是在共享全景动作空间与增广数据的前提下测得的（原文注 4）；束搜索、轨迹记录规则、split 版本都会改变数字。修复：报告时列出动作空间、增广数据、解码方式、split 与步数上限；本地复现先对齐这五项再谈方法增益。

小结

  • RCM 用匹配评论器把「轨迹重建指令」的概率变成内在奖励：Rintr = (1/n) log pβ(X | τ)，按词平均后尺度稳定；实算两轨迹每词差 0.2 nats，困惑度 2.0138 对 1.6487。
  • 导航器用「历史 → 文本 → 视觉」顺序条件化的跨模态推理链，动作在 [ht; ctext; cvisual] 上打分；公开配置为隐藏 512、词嵌入 300、动作嵌入 2176（外观 2048 加方向 128）。
  • 外部奖励为距离缩减加 3 m 成功信号，折扣回报 γ = 0.95；实算 [1.2, 0.9, 0.6, 1.4, 1.0] 的 t = 0 回报为 4.611331。混合优势 At = Rextr + δRintr，δ = 2（附录记作 σ）。
  • 样本来自策略自采样，步数上限 10；评论器用 14,025 条演示对预训练后冻结，学习率 1e-4；策略先监督热身 1e-4，再强化 1e-5；纯内在奖励不稳定，混合奖励是原报告的稳定方案。
  • 结果与消融：测试集 SPL 28 → 35、SR 35.0% → 43.1%；未见环境上移除内在奖励使 SR 下降 1.9 个百分点，纯监督降至 37.7%，去掉跨模态推理降至 35.7%。比较口径为共享的全景动作空间与增广数据、无束搜索。
  • 下一讲把同一个评论器变成「回放筛选器」：在无标注的未见环境中采样多条轨迹，用匹配分数选出最可信的一条存入回放池，再以自监督模仿更新策略（第 026 讲）。
