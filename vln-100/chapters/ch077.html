第四篇 · 规模、记忆与泛化方法论

第 077 讲｜跨语言/跨环境表征

本讲以 CLEAR（Li、Tan、Bansal 2022，NAACL 2022 Findings，arXiv:2207.02185v1）为主样本，拆解跨语言与跨环境两条表示学习线：用 RxR 中同一路径的三语指令做对比学习，把语言方差压进共享表示；用指令相似度挖出跨环境的语义对齐路径，再用物体匹配过滤假正对，得到对低层外观不敏感的环境不变视觉表示。学完能独立设计一张跨语言乘跨环境的迁移实验矩阵，并分清零样本、表示迁移与目标域训练三种口径下的数字含义。

  • 主题：跨语言迁移 / 环境不变表征 / 对比学习 / 迁移评测
  • 关键数字：RxR 三语、每路径 9 条标注、指令对 36 种、物体类 27 选 10、RxR val-unseen 平均 SR 35.1 到 40.4
  • 预计学时：60 分钟
  • 前置讲：第 076 讲（因果去偏：BACL / FACL）

学习目标

  • 会算：同一路径 9 条标注可构成的指令对数、跨语言对占比、InfoNCE 负样本数与随机命中率、物体类抽样空间。
  • 会解释：跨语言对比损失与语义对齐路径对比损失各自压掉哪一种方差，为什么两者合用的增益大于单项之和的直觉预期。
  • 会实现：跨语言成对对比损失、语义路径对挖掘加物体匹配过滤、带协议字段的迁移矩阵运行器三段示意代码。
  • 会判断：一组迁移结论属于零样本、表示迁移还是目标域训练口径，哪些数字可以并排比较，哪些只能单独陈述。
  • 会设计：给定新语言或新任务，写出跨语言乘跨环境的消融矩阵，配控制变量、预算匹配与验收指标。

背景与动机

第 011 讲把 seen-unseen 落差定位到低层视觉外观：同一动作在不同房间里对应不同的纹理、颜色与家具风格，智能体把训练环境的表观属性误当成指令语义的一部分。第 075 与 076 讲在目标域内部做诊断与因果去偏，例如重加权与反事实增广。第 012 讲则展示了数据的另一条线：RxR 为同一批路径同时提供英语、印地语与泰卢固语三种母语指令，语言成为天然的对齐信号。这两条线在 2022 年被 CLEAR 合成一个统一问题：多语言平行数据能否反过来改进指令表征，跨环境的语义相似路径能否反过来改进视觉表征，两者叠加后能否同时降低未见环境上的误差。

CLEAR 的做法分两阶段。第一阶段只做表示学习，不碰导航策略：语言侧把同一路径的两条指令（可跨语言）拉近，视觉侧把不同环境下语义相近的两条路径拉近，并用物体匹配剔除名不副实的图像对。第二阶段在学到的表示上训练导航智能体，训练配方沿用 EnvDrop 一类的模仿学习与强化学习混合方式。收益的参照点很清楚：在 RxR val-unseen 的三语平均上，ResNet 特征基线 SR 为 35.1，加上双表示后到 40.4；换成更强的 CLIP 特征，基线 41.7，到 44.4（arXiv:2207.02185v1 表 2，单跑协议）。

本讲的重心不在导航策略，而在表示层与迁移评测：学到什么、用什么信号学、迁移到什么任务时报什么口径。第 076 讲在目标域内去偏，本讲在表示层跨域对齐，第 078 讲再讨论少样本与 unseen 泛化的完整协议，三讲连成「去偏、迁移、泛化」的递进。

核心原理

本节按「数据基础、语言表示、视觉表示、训练流程、结果证据、边界失效」六步展开。所有 RxR 数字沿用第 012 讲口径（Ku、Anderson、Patel、Ie、Baldridge 2020，EMNLP 2020，arXiv:2010.07954），CLEAR 数字标注 arXiv:2207.02185v1 的协议。

1. 数据基础：9 条标注与 36 种指令对

RxR 共 16,522 条路径、126,069 条指令，其中约 12.8K 条公共路径每种语言各标 3 条、共 9 条，其余约 1.2K 条独有路径各标 3 条。CLEAR 的表示学习以公共路径为主：对每条路径，从 9 条指令中随机抽 2 条构成一个视觉对齐指令对（visually-aligned instruction pair），两条指令可以跨语言。实算抽样空间：C(9,2) = 36 种无序对，其中同语言对为 3 种语言乘 C(3,2) = 9 种，占 25.00%；跨语言对 27 种，占 75.00%。均匀抽样下每条训练样本有四分之三的概率携带跨语言监督，这正是后续「只用同语言对训练会丢点」的算术根源。

路径侧沿用 RxR 的二层采样先验：44.5% 的路径不沿最短路，平均比最短路长 27.4%，平均 8 条边、14.9 米（对照 R2R 的 5 条边、9.4 米）。路径更长、绕行更多，意味着跨环境语义对齐时不能依赖「起点终点相同」这类结构性线索，语言成为唯一的桥。

两条表示线的复现预算也能先算清。物体匹配要对训练路径的每个时间步做检测：RxR 训练集 11,089 条路径、平均 8 条边（节点数约 9），每个节点的全景离散为 36 个视角，检测规模约为 11,089 × 9 × 36 = 3,592,836 帧视角；语言侧每个训练轮次为每条路径抽 1 对指令，共 11,089 对，批大小 64 时约 174 步。把这两个数字放进实验计划，比只写「用 Mask R-CNN 检测物体」更能约束复现成本。

2. 跨语言语言表示：把同一路径的两条指令拉近

语言侧以多语言 BERT 为基础（m-BERT-base，cased 版本）。对指令 w1…wm，取 [CLS] 位置输出作为句表示：

w̃ = m-BERT(w1, …, wm)[CLS] w̃ 为整句表示；[CLS] 是预训练阶段固定引入的句级槽位

一个批里有 N 个正对 (w̃j, ũj)，每个锚点的候选集是批内 2N 个表示，排除自身后共 2N−1 个负例。对比损失用余弦相似度与温度 τ 控制分布锐度：

αi,j = w̃iTũj / (‖w̃i‖·‖ũj‖)，Llang = −Σi log exp(αi,i/τ) / Σk≠i exp(αi,k/τ) α 为余弦相似度；τ 为温度超参。N = 64 时每个锚点见 127 个负例，随机命中率 1/127 ≈ 0.787%

这个目标把「同一路径」声明为等价关系，等价类内部的语言差异（词汇、语序、描写重点）被压成不变量，等价类之间的差异被保留。等价关系的定义权在路径，语言只是观测通道，因此同一语义的跨语言句子在表示空间里天然靠近，m-BERT 预训练中语言特定的残差会被下游目标冲刷掉一部分。

3. 环境不变视觉表示：指令相似度搭桥，物体匹配过滤

视觉侧的难点在于没有现成的「跨环境等价路径」标注。CLEAR 用语言搭桥：对训练集中每条指令路径对 (I, P)，在其余指令里检索余弦相似度最高、且路径长度相同的一条 Î，并把 P 与 P̂ 组成语义对齐路径对。相似度高意味着两条指令提到相同的物体与动作，等长约束是控制变量，避免长短悬殊的路径被强行对齐。随后用物体匹配过滤图像对：对每一帧全景的 36 个离散视角用 Mask R-CNN（在 LVIS 上训练，detectron2 实现）检测物体，先剔除出现频率低于 1% 的类，保留 27 类常见室内物体；每轮迭代从 27 类中随机抽 10 类，只保留两侧都含被抽中物体的图像对。实算：C(27,10) = 8,436,285 种子集组合，单轮覆盖类占比 10/27 ≈ 37.04%。

视觉编码器在预训练视觉骨干之上加两层全连接与残差、层归一化：

v̂t,i = LayerNorm(Wv1·ReLU(Wv2·ôt,i) + ôt,i)，pk,t = (1/36)·Σi=136 v̂p,k,t,i ô 为骨干输出；单帧全景表示取 36 视角表示的均值

对比目标与语言侧同构，正对为跨环境的语义对齐全景对，负例为批内其他路径的全景：

βk,t = pk,tTqk,t / (‖pk,t‖·‖qk,t‖)，Lvisual = −ΣkΣt log Softmaxk(βk,t/τ) Softmax 沿批内候选路径维度计算；下标 t 遍历该路径的全部时间步

这一步压掉的是环境特定的低层外观：同一语义路径（例如「进门后左转停在水槽边」）在不同房屋的纹理、光照与家具样式差异被当成噪声。训练后语义相同、外观不同的两个位置靠近，语义不同、外观相似（同款沙发、同色墙面）的两个位置被拉开。

4. 训练流程：先学表示，再学导航

两阶段流程里，表示学习阶段只优化 Llang 与 Lvisual，不改动导航目标；导航训练阶段把学到的语言编码器与视觉编码器接进导航模型，用模仿学习与强化学习的混合方式训练动作策略，评测采用单跑（single-run）协议，即智能体在测试环境里只导航一次、不做预先探索。这个流程的顺序很关键：若两阶段联合优化，导航损失会淹没表示目标的等价类结构，跨语言与跨环境的对齐信号被稀释。

seen-unseen 落差方面（表 5），基线 SR / SPL / nDTW / sDTW 的绝对差依次为 3.3 / 2.5 / 1.6 / 2.5 个百分点，加入环境不变视觉表示后收窄到 1.5 / 1.4 / 1.0 / 1.7。需要如实说明的是，该行的已见集数字低于未见集（34.1 对 35.6），差值取绝对值后为 1.5；这提示单次划分下的已见数字波动不小，落差的证据要结合多指标看。

榜单与迁移（表 1 与 6.5 节）：RxR test 单跑上，RxR 原基线 nDTW 36.81、CLIP 单语 51.10、CLEAR 53.69，相对 CLIP 单语高 2.59、相对原基线高 16.88，SR 从 22.8 到 40.29（1.767 倍）。把学到的表示搬到 R2R 与 CVDN：R2R 上经目标域训练后 SR 提升 1.4、nDTW 提升 1.8；完全不训练目标域时零样本 SR 提升 4.5、SPL 提升 2.2。CVDN 上训练后目标进度 4.05 对基线 3.31（+0.74），零样本 0.92 对 0.50（+0.42）。

6. 边界与失效模式

  • 语言子集训练会掉点：只用两种语言对齐时，被漏掉语言的对齐误差会挤占共享空间（hi+te 27.8 是全部配置里最低）。三语全开是前提条件。
  • 同语言对丢弃四分之三监督：均匀抽样下跨语言对占 75%，只算同语言对等于把大部分等价约束删掉，结果低于不做表示学习的基线。
  • 等长约束只是启发式：同长度路径在不同环境里仍可能语义不同，不配物体匹配会引入假正对；物体匹配自身也有代价，10/27 的抽样覆盖让每轮只看部分类，需要多轮累积。
  • 迁移增益量级有限：跨任务迁移的稳态增益在 1 到 2 个百分点量级（R2R +1.4 SR），零样本数字（+4.5 SR）是相对其自身基线，不能与经目标域训练的数字混排。
  • 评测口径敏感：单跑、beam search、模型集成的 RxR / R2R 数字不可直接比较（第 040 讲与第 079 讲讨论），引用时必须带 split、协议与特征主干。

实现思路与设计

把本讲落成可执行工作，需要三份材料：迁移实验矩阵、三种迁移模式的判据表、参数与协议登记表。所有条目的数字口径以 arXiv:2207.02185v1 为准，建议值单独标注。

迁移实验矩阵

矩阵的四个维度是：语言覆盖（源语言到目标语言，含同语言与跨语言对照）、环境划分（源环境训练、未见环境评测，必要时再加跨数据集行）、视觉主干（ResNet-152 与 CLIP ViT-B/32 两档，用于确认表示增益不依赖单一特征）、迁移模式（零样本、表示迁移加目标域训练、全量联合训练）。每一格记录协议字段：任务与 split、单跑或 beam、步数上限、是否加载源表示、目标域训练轮数。矩阵的行是语言，列是环境与模式，格子里放数字与协议；缺任一协议字段的格子视为无效。

迁移模式源表示的使用方式典型增益量级适用判据

选择判据是「目标域监督量」：监督为零选零样本并报告与基线的差；监督少选表示迁移；监督充分且多任务并存时才考虑联合训练。零样本数字只回答「先验是否可用」，表示迁移数字才回答「先验值多少」，两类数字分表报告。

设计决策：先把等价关系写对，再谈模型容量

本讲两条线的共同结构是「声明等价关系＋对比学习」。等价关系错了，容量越大错得越整齐：路径标签写错会把跨环境语义不同的样本强行拉近，语言对不覆盖三语会让共享空间被单语主导。工程顺序是先核对等价关系的定义与覆盖率（36 种对、27 类物体、等长约束），再上编码器与损失；核对的产物是带协议的实验矩阵，一次性跑分脚本不算交付物。

与相邻讲的分工：第 011 讲换掉低层外观特征，属特征层面的修复；第 076 讲在目标域内做因果去偏，属训练分布层面的修复；本讲在表示层做跨语言与跨环境对齐，属迁移层面的修复；第 078 讲把少样本与 unseen 协议讲全，其预训练数据（BnB）与本讲的表示学习方法可以叠加使用。

关键代码与解读

三段代码分别给出跨语言对比损失、语义路径对挖掘与物体匹配、迁移矩阵运行器。均为方法示意，接口以各开源实现的公开设计为参照，随版本演进。

片段 1：跨语言成对对比损失（2N 候选）

import torch
import torch.nn.functional as F

def info_nce_2n(w, u, temperature=0.07):
    """w、u 形状 [N, d]，第 i 行互为正对；候选集 2N，负例 2N-1。"""
    z = F.normalize(torch.cat([w, u], dim=0), dim=-1)   # [2N, d] 单位化
    logits = z @ z.t() / temperature                    # [2N, 2N] 余弦相似度
    n = w.size(0)
    eye = torch.eye(2 * n, dtype=torch.bool, device=z.device)
    logits = logits.masked_fill(eye, float("-inf"))     # 自身位置置负极大
    labels = torch.cat([torch.arange(n, 2 * n),          # w_i 的正对在 u_i
                        torch.arange(0, n)]).to(z.device)  # u_i 的正对在 w_i
    return F.cross_entropy(logits, labels)

# 采样：每条公共路径从 9 条三语标注中抽 2 条，跨语言对占多数
pair_a, pair_b = sample_two_of_nine(batch_paths)         # 各 [N, d] 句表示
loss = info_nce_2n(pair_a, pair_b)

解读：（1）把两路表示拼成 2N 候选，锚点看到 2N−1 个负例，与论文的批内候选口径一致；N=64 时随机命中率 1/127。（2）对角线掩码去掉自身，标签是循环移位后的配对索引，实现正对「i 对 i+N」与「i+N 对 i」的双向监督。（3）温度 τ 是唯一锐度旋钮，建议在 0.05 至 0.1 区间扫描，本文未在正文给出数值，脚本默认值仅作示意。

片段 2：语义对齐路径对挖掘与物体匹配过滤

def mine_semantic_pairs(instructions, paths, encode, object_cls):
    """为每条指令路径检索同长度、最相似的跨环境伙伴。"""
    embeddings = F.normalize(encode(instructions), dim=-1)   # 句表示
    sim = embeddings @ embeddings.t()                        # [P, P] 相似度
    sim.fill_diagonal_(float("-inf"))                       # 排除自身
    pairs = []
    for i in range(len(paths)):
        for j in sim[i].argsort(descending=True)[:20]:      # 取相似度前列
            j = int(j)
            if len(paths[i]) == len(paths[j]):              # 等长约束
                pairs.append((i, j))
                break                                       # 每条路径取一个伙伴
    kept = []
    for i, j in pairs:                                      # 物体匹配过滤
        sampled = random.sample(range(27), 10)              # 27 类中抽 10 类
        shared = set(sampled) & set(object_cls[i]) & set(object_cls[j])
        if shared:
            kept.append((i, j))
    return kept

# object_cls[k]：第 k 条路径的物体类集合（Mask R-CNN 于 LVIS 检测后过滤低频类）
# 实算：C(27,10) = 8,436,285 种子集，单轮覆盖类占比 10/27 ≈ 37.04%

解读：（1）相似度检索加同长度约束是控制变量，避免把长短悬殊的路径硬配对；取 top-20 再过滤，比只取 top-1 有更多通过等长约束的机会。（2）物体匹配用「双方都含被抽中的类」作为条件，剔除只看语言相似度时混入的假正对；10/27 的抽样让每轮成本可控，多轮累积覆盖全部类。（3）等长与物体匹配都可能把正对筛得过严，脚本把命中列表返回，不直接丢弃样本，便于统计保留率并调阈值。

片段 3：带协议字段的迁移矩阵运行器

PROTOCOL = ("task", "split", "decode", "max_steps",
            "source_rep", "target_train_epochs", "feature_backbone")

def run_transfer_cell(cell, agent, loader, source_rep=None):
    """cell 描述语言与环境组合；返回值必须携带全部协议字段。"""
    assert all(k in cell for k in PROTOCOL), "协议字段缺失，结果无效"
    zero_shot = cell["target_train_epochs"] == 0
    if not zero_shot:
        for _ in range(cell["target_train_epochs"]):
            train_one_epoch(agent, loader.target_train)
    assert zero_shot == (source_rep is not None)  # 零样本必须有源表示可加载
    metrics = evaluate(agent, loader.target_eval,
                       decode=cell["decode"], max_steps=cell["max_steps"])
    return {"language": cell["language"], "env": cell["env"],
            "protocol": {k: cell[k] for k in PROTOCOL}, **metrics}

# 分表报告：零样本与目标域训练结果不并入同一排名

解读：（1）协议字段作为硬约束写在断言里，缺字段的实验不生成记录，从源头杜绝「数字有了、口径没了」。（2）零样本分支不允许目标域训练轮数非零，同时要求加载源表示，杜绝把普通基线结果伪装成零样本迁移。（3）返回结构把语言、环境与协议一起落盘，后续汇总时按模式分表，避免不同口径的数字混排。

常见坑

  • 语言覆盖不全：只用同语言对训练时 SR 32.9，低于不做表示学习的 m-BERT 基线 35.1；只对齐英-印或印-泰（32.0 与 27.8）同样低于三语 36.0。根因是均匀抽样下跨语言对占 75%，语言子集让被漏语言在共享空间里缺少对齐压力。修复：始终三语全开，把语言组合消融作为必报实验（multi / mono / 两两子集四档），并把「删一种语言」作为敏感性检查。
  • 跳过物体匹配：跨环境正对里混入语义不符的图像对，visual 项的 nDTW 增益缩水且波动变大。根因是等长与高相似度都不保证物体一致。修复：按论文口径保留 27 类、每轮抽 10 类做匹配过滤，并记录每轮保留率与类覆盖。
  • 用单一表示距离替代导航指标：en+te 子集的英-印距离 0.43 优于三语的 0.61，但导航 SR 只有 30.0 对 36.0。根因是距离指标只测一对语言的局部几何，不测等价结构整体。修复：以导航指标为验收标准，距离指标只作诊断辅助。
  • 迁移口径混排：把零样本（R2R SR +4.5）与目标域训练（SR +1.4）写进同一张排名表。根因是两类实验的监督量与目的不同。修复：按迁移模式分表，每张表标注 split、单跑或 beam、步数上限与特征主干（第 079 讲给出完整清单）。
  • 把已见集当作稳定参照：+visual 行的已见 SR 低于未见 SR，单次划分的落差方向可能翻转。根因是 seen 数字受划分内环境构成影响。修复：同时报四个指标的绝对值差与多指标方向，避免只挑一个指标讲趋势。

练习与思考

  1. 抽样空间核算：某公共路径有 9 条三语标注（每语言 3 条）。计算：(a) 两两无序对总数；(b) 同语言对与跨语言对的数量及占比；(c) 批大小 N=64 时 InfoNCE 的候选数与每个锚点的负例数，以及随机命中率。 ★
    提示
    (a) C(9,2) = 36。(b) 同语言 3×C(3,2) = 9，占 25.00%；跨语言 27，占 75.00%。(c) 候选 2N = 128，每锚点负例 2N−1 = 127，随机命中率 1/127 ≈ 0.787%。
  2. 把语义对齐的等长约束从「严格等长」放宽为「长度差不超过 1 步」。预测三件事的变化方向：可用正对数量、假正对比例、visual 项的 nDTW；写出预测依据与一个可证伪的观测。 ★
    提示
    正对数量上升，假正对比例也上升（长度接近不保证语义一致），nDTW 的方向取决于假正对的占比与多样性：若假正对集中打击少数类别，均值可能持平而方差上升。可证伪观测：统计保留对的长度差分布与人工抽检的语义一致率，再看 nDTW 的分环境方差。
  3. 从表 5 数据推导绝对差：基线已见 38.4 / 未见 35.1，+visual 已见 34.1 / 未见 35.6。要求 (a) 计算两行的 SR 绝对差；(b) 解释为什么 +visual 行的差值是负值而论文按绝对值报告；(c) 说明报告这类差值时应同时给出哪些信息。 ★★
    提示
    (a) 基线 |38.4−35.1| = 3.3；+visual |34.1−35.6| = 1.5。(b) 表示学习改变了已见集上的拟合程度，已见数字回落而未见数字上升，差值符号翻转；论文关心的是落差的量级，方向次之。(c) 至少给出已见与未见两个原值、划分版本、特征主干与运行次数。
  4. 设计一个 en 到 hi 的表征迁移矩阵（源域 en、目标域 hi），含三档模式：零样本、表示迁移加目标域训练、全量联合训练。列出每一档需要控制的变量（语言覆盖、路径采样、特征主干、解码方式、步数上限）与要报告的指标。 ★★
    提示
    三档共用同一验证集与同一视觉主干，唯一变化量是监督来源与目标域训练轮数；零样本档不训练、报告与基线差；迁移档固定目标域轮数；联合档同时训练源与目标任务。指标取 SR / SPL / nDTW / sDTW 四项并标 split 与单跑协议。
  5. 综合实验设计：在 RxR 上验证「物体匹配过滤是否必要」。要求 (a) 给出三组对照（无过滤、语言相似度过滤、物体匹配过滤）；(b) 控制变量与预算匹配方式；(c) 预期结果与失败判据（什么结果说明物体匹配无效）；(d) 如果物体匹配有效但增益很小，给出两个可能的替代解释。 ★★★
    提示
    (a) 三组都使用同一信号、同一语言覆盖、同一训练轮数，唯一变化是正对过滤规则。(b) 固定随机种子与批大小，N 一致以对齐负例数。(c) 若物体匹配组与无过滤组在 nDTW 上的差小于跨种子标准差，视为无效；有效判据是差大于两倍标准差。(d) 替代解释：增益来自正对数量减少带来的正则效应；或来自保留对与测试环境的重叠分布，需用分环境消融排除。

小结

  • CLEAR 的两条表示线分别是跨语言对比与环境不变视觉对比：语言侧把同一路径的三语指令拉近，视觉侧把不同环境下语义对齐的路径拉近，物体匹配过滤假正对。
  • 抽样实算：每路径 9 条标注构成 36 种指令对，跨语言对 27 种占 75.00%；N=64 时每锚点 127 个负例；物体类保留 27、每轮抽 10，子集组合 C(27,10) = 8,436,285。
  • 收益证据（RxR val-unseen 三语平均，单跑）：ResNet 基线 35.1 到双表示 40.4（SR +5.3）；CLIP 基线 41.7 到 44.4（+2.7）；语言组合三语 36.0 高于同语言 32.9 与两两子集 32.0 / 30.0 / 27.8。
  • seen-unseen 绝对差从 3.3 / 2.5 / 1.6 / 2.5 收窄到 1.5 / 1.4 / 1.0 / 1.7；已见数字存在波动，落差的证据要结合多指标与划分版本。
  • 迁移口径三档：R2R 目标域训练 +1.4 SR / +1.8 nDTW，零样本 +4.5 SR / +2.2 SPL，CVDN 目标进度 +0.74 与零样本 +0.42；三类数字分表报告。
