第 096 讲｜2026 快照 IV：记忆与闭环纠错

第 095 讲结算了效率三本账，本讲处理长程导航的另一半问题：错误一旦发生，系统靠什么发现并纠正。四篇 2026 年论文分别给出四种机制（arXiv 版本已逐一核实，检索日 2026-10-01）。Liu、Liu、Ding、Jiang、Chen、Tang、Leng、Zhang、Cheng 2026（arXiv:2607.29600v1）的 HAM-VLN 用决策耦合的分层智能体记忆：同一次模型调用既选动作也写入房间、物体、进度与失败笔记，工作窗口只保留最近 K 个路点，旧历史经相关性、时近性、显著性检索回到上下文；R2R-CE 61.0 SR、RxR-CE 52.7 SR，上下文比全历史少 69.0% / 67.2%。Huang、Wang、Lin、Xu、Huang、Jiang、Dong、Lin 2026（arXiv:2608.03143v1）的 Route2Step 把语义进度与局部执行拆成两个模块，E-SPA 从路线级示范里自动对齐子指令与轨迹片段；R2R-CE 从 48.1 / 43.3 升到 55.3 / 48.2 SR / SPL，190K 状态级校正样本只配 11.5K 直接动作监督。Yao、Zhu、Gao、Wang、Xu 2026（arXiv:2608.07548v1，ICML 2026）的 SC²-WM 用世界模型前瞻构造内部反馈，单目 R2R-CE Val-Unseen 从 43.77 升到 50.90 SR，轨迹长度缩短 32.5%。Li、Lin、Shao、Zhang、Shi、Li、Wu 2026（arXiv:2609.28296v1，IROS 2026）的 Talk2Escape 在运动学异常时触发对话求助，GTA 基座 SR 从 48.8 升到 72.0。交付物是纠错机制分类表：纠错对象、触发信号、监督来源与失效条件。

  • 主题：智能体记忆 / 世界图检索 / 失败笔记 / 进度-执行解耦 / 子指令对齐 / 世界模型内部反馈 / 测试时自适应 / 对话触发与求助
  • 关键公式：st(p)=α·rel+β·rec+γ·sal；Δt=s̃t+1−st；κt=KL(p̃t‖pt)；Caway(t)=1[d̄t,k>d̄t−k,k]
  • 预计学时：80 分钟
  • 前置讲：第 095 讲（2026 快照 III：全景、蒸馏与效率）

学习目标

  • 会解释：上下文记忆与结构化记忆的取舍；进度错误与执行错误的区分为什么决定监督分配；内部反馈与外部监督在闭环中的分工。
  • 会算：记忆检索分数与衰减；状态级/动作级监督配比；世界模型反馈触发的 KL 量与分位阈值；对话触发率与成功率的关系。
  • 会实现：世界图检索切片、分层监督标注、内部反馈状态校正、运动学触发四段示意代码。
  • 会判断：四种纠错机制各自的纠错对象与前提，什么条件下触发式纠错会伤害系统（干预疲劳、无节制自适应、上下文稀释）。
  • 会设计：为一台长程服务机器人组合记忆、进度监控、闭环反馈与求助通道，写清触发条件、监督来源与回退路径。

背景与动机

前几讲反复出现同一类失败结构：错误发生在个别步上，随后被历史污染。第 094 讲用不确定性发现「哪一步不可信」，但发现之后的动作由谁负责，当时只给出三类用法的框架。长程场景里还有第二个瓶颈：历史本身在膨胀。原始视觉历史随轨迹线性增长，稠密语义地图随面积增长，两者都把「记住什么」的决策交给固定规则，大量无关信息在关键时刻稀释了模型注意力。HAM-VLN 的统计把这一点量化：窗口从 K=3 扩到全历史，API 令牌增加 98.7%，SR 与 SPL 同步下降 4.7 与 6.6 个百分点。上下文长度与导航能力之间没有单调关系。

另一条线是纠错的责任划分。Route2Step 指出，扩散式动作监督会把两种错误混在一起：选错了子指令（语义进度错误），与执行正确子指令时的动作失误（局部执行错误）；两者需要不同时间范围的证据与不同粒度的监督。SC²-WM 则给出不依赖外部奖励的闭环信号：世界模型对候选动作的前瞻，与当前隐状态的差异本身就是可计算的反馈。Talk2Escape 把纠错推到系统外部：当运动学检测到局部绕圈或持续偏离，主动生成问题向人求助。四种机制覆盖了从内部记忆到外部对话的整条纠错链。

核心原理

本节按「记忆表示、HAM 检索与回退、进度-执行接口、世界模型闭环、对话纠错、结果与分类表、边界」七步展开；派生数字先经 Python 实算，论文数字标注协议。

1. 记忆的两种旧表示与分层智能体记忆

原始视觉历史保留直接证据，代价随轨迹增长，且没有按地点、进度或失败分支建立的索引；稠密语义地图提供持久度量结构，代价随地图面积增长，内容与决策过程分离。HAM-VLN 选择第三条路：类型化地点-物体图 Gt=(VP, VO, EPP, EPO)，地点状态由增量式单链聚类形成，聚合空间锚点、智能体书写的语义上下文、访问统计与失败证据；物体状态关联深度定位的类别观测与开放词汇描述。图随发现的地点与物体增长，不随面积增长。

决策耦合的关键是：同一次 System 2 调用输出结构化记录 Jt=(at, wt, rt)，at 为动作、wt 含地点语义与进度更新、rt 为理由；记忆维护不需要额外模型调用。上下文由三部分组成：Mt=Wt ⊕ Lt ⊕ R(Gt, qt)，其中 Wt 是最近 K 个路点的逐字帧窗口，Lt 是有序指令进度记录，R 是按当前子目标检索出的子图。默认 K=1，论文枚举的四种功能视图为工作记忆（窗口内逐字）、情节记忆（访问轨迹与时近性）、语义记忆（地点-物体内容与拓扑）、反思记忆（失败笔记，随地点检索返回）。实现配置：System 2 为 Gemini-3.1-Pro，System 1 为 Qwen3.6-35B，检索编码器为本地 bge-large-en-v1.5，检索不产生 API 调用。

2. 子目标条件检索与失败回退

当前子目标 qt 取指令进度记录中的第一个未完成项。地点 p 的检索分数为三项加权和

st(p) = α·rel(qt, p) + β·rect(p) + γ·sal(p)，rect(p) = ρt−τ(p) rel 为查询与地点摘要的余弦相似度；τ(p) 为上次访问时间；sal 综合地标一致性与物体丰富度；实验取 (α, β, γ)=(1.0, 0.3, 0.3)，ρ=0.85

实算示例：rel=0.8、距上次访问 3 步、sal=0.5 的地点得 0.8+0.3×0.6141+0.15=1.1342；rel=0.6、距上次访问 10 步、sal=0.9 的地点得 0.6+0.3×0.1969+0.27=0.9291。旧但显著的地点仍能进入候选，时近性与相关性各起作用。读出算子在分数最高的 Ks=3 个地点上做一跳拓扑扩展，连同当前位置邻域，最终保留至多 Kp=5 个地点，序列化后进入上下文。

回退被建模为控制与记忆的联合转移：当 System 2 返回已访问路点 bt，被放弃的轨迹后缀映射到地点状态，理由 rt 作为带定位的失败证据存放；证据只在地点被检索时回到上下文，不修改检索分数、不封锁地点。回退同时改变位姿与记忆状态，这是闭环从动作、失败到条件召回再到修正动作的完整路径。论文在 100 个 R2R-CE 回合中统计到 175 次回退、1,288 个决策点，回退占比 13.6%，平均每回合 1.75 次。

3. Route2Step：进度与执行的显式接口

Route2Step 把策略拆成两个独立训练的模块：指令分析模块 MIA 读全局指令与完整视觉历史，输出当前活动子指令 st 与执行状态 mt∈{Normal, Recovering}；动作生成模块 MAG 只读近期观测窗口与接口，输出动作块 at:t+h。两个模块的时间上下文、优化目标与监督来源全部分离，梯度不跨接口传播。监督构造的核心是 E-SPA：把路线级指令改写为有序子指令序列，在轨迹上寻找使综合代价最小的连续分段，代价由语义对齐、动作一致性、时长正则与楼梯锚定四项加权组成，语义项用冻结 CLIP 特征在温度 τ=0.05 下的负对数概率求和；分段端点的位姿构成语义路点，作为物理空间的完成判据。

训练分两段。专家路径初始化之后，固定一个子指令采样多条随机 rollout，只有同时满足位置与朝向容差才算完成；整组失败时追加干预式 rollout，由专家把偏离过大的轨迹带回参考线附近，再交还策略。所有 rollout 历史按几何完成情况标注活动子指令，给 MIA 提供 190K 状态级校正样本；只有反复失败的 Recovering 区间才配专家动作，给 MAG 提供 11.5K 直接动作监督，占比 6.05%。消融把这条分配纪律讲得很清楚：仅状态校正是 50.6 / 44.7，仅选择动作是 49.4 / 44.8，常规 DAgger 用 200K 动作标签也只到 49.8 / 44.4，而状态加选择性动作达到 55.3 / 48.2。动作监督解决局部恢复，语义进度必须由状态级监督从长期历史中学习，两者可以分辨且必须分辨。

4. SC²-WM：世界模型内部反馈闭环

SC²-WM 在连续环境里维护隐状态 st：后验转移 q(st|st−1(Δ), at−1, vt, l) 融入上一状态、已执行动作与当前视觉语言特征；前瞻策略 π̃ 在 st 上给临时动作 ãt；先验转移 fp 预测 s̃t+1。反馈信号取前瞻与当前状态的差 Δt=s̃t+1−st，再经可学习函数 ψ 得到校正状态 st(Δ)=ψ(st, Δt)，最终动作由 π(·|st(Δ)) 给出。Δ 不是损失目标，它是描述「临时动作会把隐状态带向何处」的引导量；把它最小化会抹掉反馈本身。

视觉校准模块（VCM）为反馈质量兜底：维护最近 L 步的视觉表征记忆，用带可学习时间衰减的交叉注意力检索上下文，再以门控权重与当前表征融合，抑制视角变化与感知噪声造成的伪漂移。预训练目标三项：动作监督同时作用在校正前后两个状态上（Lac），先验与后验的 KL 对齐（Lwm），以及用轻量解码器从前瞻状态重建下一步视觉特征（Lrec）。模型级纠错由条件自适应完成：监控校正前后行动分布的分歧 κt=KL(p̃t‖pt)，用滚动缓冲的分位阈值 τ 触发，并要求校正后的分布熵低于阈值，触发时只用自监督重建损失更新世界模型参数。

结果（单目模式，R2R-CE Val-Unseen）：SR 从基线的 43.77 升到 50.90、SPL 从 29.39 升到 37.17、轨迹长度从 26.16 米降到 17.65 米（−32.5%）；测试未见 SR 43.8 升到 47.0。RxR-CE 单目 SR 从 26.7 升到 35.8、SPL 从 20.1 升到 27.2、SDTW 从 20.4 升到 26.5。消融的增量清晰：状态校正到 48.34、加 VCM 到 49.86、固定间隔自适应 50.30、反馈触发自适应 50.90、去掉重建损失 48.89。全景设置下叠到 ETPNav 上，SR 与 SPL 从 55 / 45 到 57 / 47，NE 从 5.96 米降到 5.57 米。整套训练单卡 RTX 3090、不到 40 小时。

5. Talk2Escape：运动学触发的外部纠错

Talk2Escape 把导航重写为闭环交互过程。触发条件基于运动学，不依赖模型内部量：重复触发 Crep 统计当前半径 r=0.5 米区域内是否已访问至少 n=3 次；偏离触发 Caway 比较两段长度为 k=2 的滑动窗口平均目标距离，若近期更大则判定正在远离；混合触发取两者或；另有周期触发（每 5 步）与人工触发作对照。触发后，视觉语言翻译模块把当前四视角观测改写成简短、有依据的问题，问题只允许引用可观测地标与相对方向；应答方给出相对方位与距离，包含转角 |θt| 的目标提示被注入提示词，作为独立的导航辅助块。

触发消融（R2R-CE 100 集、GTA 基座、Gemini-3.1-Pro）给出关键取舍：无干预 48.8 SR / 41.8 SPL；周期触发 63.0 / 46.5（询问率 10.2%）；偏离触发 66.0 / 49.4（15.0%）；重复触发 57.0 / 45.1（4.74%）；混合触发 54.0 / 44.5（23.1%）；人工对照 74.5 / 61.2（9.8%）。询问率存在最优点：混合触发把两类异常都算上，询问率 23.1% 的成绩低于两个单触发，说明过密请教打乱了模型自身的上下文与反事实推理。主表中完整系统在 GTA 上达到 72.0 SR，在 NavGPT 上达到 64.0 SR（论文摘要引用的 66.0 对应偏离触发的默认配置）。RxR-CE 上 SR 从 46.2 升到 62.9，SPL 从 39.3 降到 34.2：把原本失败的回合救回来需要回退与绕行，路径效率指标必然让位给任务完成。VLNVerse 细粒度任务上，NavGPT 从 19.30 升到 84.60 SR，MapGPT 从 25.53 升到 67.02。真机 Unitree Go2 上，GTA 从 40.0 SR 升到 62.0，NE 从 3.66 米降到 3.31 米。

7. 边界与失效模式

  • 记忆检索的评测子集有限：HAM-VLN 主结果基于 val-unseen 的 100 集子集、三次运行，子集与全 split 的偏差论文引用来源报告不超过 1.1 个百分点；引用数字需带子集口径。
  • 失败笔记可能固化错误：HAM-VLN 的反思记忆只在关联地点被检索时返回，笔记由模型自身书写；若一次错误回退被写成「此路不通」，后续可能回避正确分支。论文未给出笔记的自动校验机制。
  • E-SPA 依赖离线的语义分割质量：对齐由冻结 CLIP 与动态规划完成，楼梯锚定等规则针对结构化场景设计；更开放的环境需要重新定义锚定代价。
  • 测试时自适应有分布代价：SC²-WM 只在分歧超过滚动分位阈值且分布足够自信时更新世界模型；无节制更新会把当前环境的偏差写进参数，离开该区域后性能下降。
  • 对话纠错依赖外部主体：Talk2Escape 的增益在算法预言机与人工监督下成立；论文明确报告人工监督的提示质量受离散渲染与局部视角限制，真实部署需要应答方协议。

实现思路与设计

四种机制可以按「内部到外部」排成一条链：记忆保存证据，接口分离责任，反馈校正状态，对话兜底失败。接入时先决定每一环的触发与预算，再决定数据来源。

HAM-VLN 接入流程

  1. 把规划调用改为结构化输出：动作、地点语义、进度更新、理由与失败笔记同一次返回；工作窗口取 K=1 至 3。
  2. 维护地点-物体图：地点单链聚类，物体经开放集检测与深度投影合并；每步按 st(p) 检索，种子 3 个、一跳扩展、最终至多 5 个地点。
  3. 回退时把被放弃后缀映射到地点并写入失败证据；证据只参与检索返回，不改分数、不封锁地点。

Route2Step 接入流程

  1. 离线用 E-SPA 生成子指令-轨迹对齐，标出每段的语义路点位姿；无人工时间标注的基准也可生成监督。
  2. 先训 MIA 与 MAG 的专家初始化版本；再固定子指令采样 rollout，按几何完成情况标活动子指令与执行状态。
  3. 只把反复失败组的 Recovering 区间配专家动作；状态样本进入 MIA，动作样本进入 MAG，梯度不跨接口。

SC²-WM 接入流程

  1. 预训练联合三项损失：双状态动作监督、先验后验 KL、前瞻状态到下一步视觉特征的重建。
  2. 推理时先算校正状态再出动作；同时缓存 κ 值，超滚动分位阈值且熵足够低时用重建损失做一次测试时更新。
  3. 把 Δ 与 κ 作为监控量记录，用于诊断「反馈是否在起作用」与「自适应是否过于频繁」。

Talk2Escape 接入流程

  1. 接入运动学监控：重复半径 0.5 米、次数 3；偏离窗口 2 步；阈值与本体控制频率一起标定。
  2. 触发后暂停运动，生成有依据的问题（只引用可观测地标与相对方向），等待应答并注入提示块。
  3. 记录每次询问的触发原因、应答与后续轨迹，用询问率-成功率曲线选工作点，禁止按固定周期强制询问。

与相邻讲的分工

关键代码与解读

四段代码分别给出世界图检索、分层监督标注、内部反馈校正与运动学触发。示意实现，接口按四篇论文的公开公式重写。

片段 1：世界图检索与子图序列化

def retrieve_slice(graph, subgoal, alpha=1.0, beta=0.3,
                   gamma=0.3, rho=0.85, n_seed=3, n_keep=5):
    """按子目标地点排序，种子一跳扩展，输出紧凑子图。"""
    scored = []
    for place in graph.places.values():
        rel = cosine(subgoal_emb(subgoal), place.summary_emb)
        rec = rho ** (graph.step - place.last_visit)
        sal = 0.5 * place.landmark_score + 0.5 * place.object_richness
        scored.append((alpha * rel + beta * rec + gamma * sal, place))
    scored.sort(key=lambda x: x[0], reverse=True)   # 分数降序
    seeds = [p for _, p in scored[:n_seed]]
    expanded = set(seeds)
    for p in seeds:
        expanded.update(graph.one_hop(p))           # 拓扑扩展
    expanded.update(graph.current_neighborhood())
    keep = sorted(expanded, key=lambda p: -place_score(p, scored))
    return serialize(keep[:n_keep])                 # 含语义、拓扑与失败笔记

解读：（1）分数三项分别对应任务相关性、时间连续性与感知显著性，权重与衰减在全部实验统一，检索无需额外模型调用。（2）种子加一跳扩展保证被检索地点携带邻居上下文，避免孤点语义缺失。（3）序列化带失败笔记；笔记只在关联地点进入切片时出现，不参与打分。

片段 2：分层监督标注（固定子指令 rollout）

def label_rollout(traj, active_step, waypoint, expert_path, dev_thresh):
    """固定活动子指令，按几何完成情况标注状态级与动作级监督。"""
    labels = []
    for t, state in enumerate(traj):
        reached = within(state.pose, waypoint, pos_tol=0.25, yaw_tol=15)
        dev = distance_to_reference(state.pose, expert_path)
        if reached:
            labels.append((active_step, "Normal", None))   # 完成，进入下一子指令
            continue
        if dev < dev_thresh:
            labels.append((active_step, "Normal", None))   # 专家状态样本
        else:
            labels.append((active_step, "Recovering",
                           expert_action_chunk(active_step)))  # 仅此处给动作标签
    return labels

# 统计：190K 状态级样本中只有 11.5K 进入直接动作监督（6.05%）

解读：（1）完成判据在物理空间（位置与朝向容差），轨迹偏离时不改变活动子指令，语义边界保持稳定。（2）只有反复失败组的 Recovering 状态携带专家动作块，动作监督集中在局部执行失败上。（3）状态标签进 MIA、动作标签进 MAG，梯度不跨接口，避免动作更新覆盖进度估计器。

片段 3：内部反馈校正与条件自适应

def self_correct_step(world_model, policy, foresight, state, obs, history):
    """前瞻一步，用隐状态差修正当前状态；分歧超分位阈值时更新世界模型。"""
    v_hat = world_model.calibrate(obs, history)      # 视觉校准模块
    s = world_model.posterior(state, v_hat)          # 后验状态
    a_tilde = foresight.propose(s)                   # 临时动作
    s_next_pred = world_model.prior(s, a_tilde)      # 前瞻状态
    delta = s_next_pred - s                          # 内部反馈信号
    s_refined = world_model.refine(s, delta)         # 校正状态
    kappa = kl_divergence(softmax(foresight.logits(s)),
                          softmax(policy.logits(s_refined)))
    if kappa > world_model.kappa_percentile(0.5) and \
       entropy(softmax(policy.logits(s_refined))) < 0.5:
        world_model.update_on_reconstruction(obs)    # 自监督单步更新
    return policy.act(s_refined), kappa

解读：（1）Δ 是引导量，直接参与状态校正；把它当损失最小化会使反馈失效，这是与世界模型预训练目标的边界。（2）触发条件同时要求分歧大与分布自信，避免在随机探索期反复更新参数。（3）更新只使用重建目标，不需要奖励或动作标签，因此可以在推理期执行。

片段 4：运动学触发与求助查询

def need_help(pose_log, radius=0.5, repeat_n=3, window=2):
    """重复触发与偏离触发取或；返回触发类型与触发点。"""
    p_t = pose_log[-1]
    visits = sum(1 for p in pose_log
                 if dist_xz(p, p_t) < radius)          # 近期同区域访问数
    if visits >= repeat_n:
        return "repeat"
    d_now = mean(dist_xz(pose_log[-i], goal) for i in range(1, window + 1))
    d_prev = mean(dist_xz(pose_log[-window - i], goal)
                  for i in range(1, window + 1))
    if d_now > d_prev:                                     # 平均距离在变大
        return "deviation"
    return None

常见误区

  • 用扩大历史窗口换记忆：K 从 3 加到全历史，API 令牌增加 98.7%，SR 与 SPL 同步下降 4.7 与 6.6 个百分点。根因是上下文稀释，关键线索被无关全景淹没。修复：改为结构化检索，窗口保持小值，让旧信息按需返回。
  • 把进度错误当动作错误修：偏离后只补动作标签，模型从错误进度继续决策。根因是两类错误的时间范围不同。修复：状态级监督进进度模块，动作监督只留给反复失败的恢复区间；对照常规 DAgger 验证分配收益。
  • 把内部反馈 Δ 当损失最小化：反馈信号被训练抹平，闭环退化回开环。根因是忽略 Δ 的引导语义。修复：Δ 只进入状态校正函数，训练目标保持动作监督、KL 对齐与重建三项。
  • 触发过密造成干预疲劳：把重复与偏离两个触发简单叠加，询问率 23.1% 时 SR 掉到 54.0，低于任一单触发。根因是频繁打断破坏模型自身推理上下文。修复：优先偏离触发，询问率控制在 10% 至 15%，用成功率-询问率曲线选工作点。
  • 测试时自适应无节制：每步都更新世界模型会把当前区域的偏差写入参数，离开后性能反弹。根因是缺少触发条件与更新边界。修复：滚动分位阈值加分布熵双条件，更新只走自监督重建损失，并监控触发频率。

练习与思考

  1. 检索分数复算：rel=0.8、上次访问距当前 3 步、sal=0.5 与 rel=0.6、距当前 10 步、sal=0.9 两个地点，按 (1.0, 0.3, 0.3)、ρ=0.85 求分数；说明时近性衰减对排序的影响在什么场景下会超过相关性。 ★
    提示
    分数为 1.1342 与 0.9291。当两个地点相关性接近时，久未访问的高显著地点可能反超；若新增地点与旧地点 rel 差距超过 0.2，衰减通常不足以翻转排序。
  2. 监督配比：Route2Step 的 190K 状态级样本只配 11.5K 动作标签，比例为多少？若把常规 DAgger 的 200K 动作标签直接混入，论文对照结果如何变化？这说明监督分配的关键在哪里？ ★
    提示
    比例 6.05%；常规 DAgger 200K 只到 49.8 / 44.4，状态加常规动作 54.4 / 46.7，仍低于选择性动作的 55.3 / 48.2。关键是动作监督集中在持续失败的恢复区间，不做均匀铺开。
  3. 记忆令牌账：HAM-VLN 每决策 17.9k 令牌、每回合 244.9k API 令牌，对照全历史 57.7k 与 746.1k，求降幅；对照 K=3 的 32.6k 与 375.5k 再求降幅。为什么论文用「全历史」作为主要对照？ ★★
    提示
    相对全历史降 69.0% 与 67.2%；相对 K=3 降 45.1% 与 34.8%。全历史代表「不选记忆」的上限开销与下限性能（SR 53.3 / SPL 38.1），用来证明结构化记忆同时省钱且更准。
  4. 触发策略比较：Talk2Escape 消融中偏离触发 66.0 SR / 15.0% 询问率，混合触发 54.0 SR / 23.1%。求两者 SR 差与询问率差；再结合 VLNVerse 上 +T2E 的 NavGPT 84.60 与 MapGPT 67.02，解释为什么「密集几何坐标历史」在对话纠错下表现更差。 ★★
    提示
    SR 差 12.0 点，询问率差 8.1 点。应答提示是相对方位语义，MapGPT 的绝对坐标历史与之存在模态错配，模型要在两套空间表述之间换算，恢复效率下降。
  5. 设计题：为一台医院配送机器人设计闭环纠错系统，运行 8 小时班次、有人流、需要与护士站通信。要求 (a) 选择记忆结构与窗口参数；(b) 设计进度监控与动作恢复的监督方案（标注成本受限）；(c) 给出内部反馈与外部求助的优先级、触发条件与回退路径；(d) 定义三项监控指标并给出报警阈值；(e) 列出两项会被现场推翻的假设与对应的降级方案。 ★★★
    提示
    (a) 地点-物体图加 K=1 至 3 工作窗口，失败证据挂地点。(b) 用示范轨迹自动对齐（E-SPA 思路），状态级样本为主、动作级只补持续失败区间。(c) 先内部反馈校正；绕圈或持续偏离且内部反馈无效时求助，询问率控制在 10% 至 15%，人工应答协议先于触发上线。(d) 监控回退率（参考 13.6%）、询问率、校正触发频率；报警阈值按班次滑动统计。(e) 可被推翻的假设示例：护士站随时可应答、行人不会持续遮挡关键通道；降级方案含延迟求助、保守停靠。

小结

  • HAM-VLN 把导航历史放进深度定位的地点-物体世界图：同一次调用写动作与记忆，工作窗口 K=1，检索按相关性、时近性、显著性加权；R2R-CE 61.0 SR，上下文比全历史少 69.0% / 67.2%，K 增大令牌上涨而性能不涨。
  • Route2Step 把语义进度与局部执行拆成显式接口：E-SPA 自动生成子指令-轨迹对齐，190K 状态级监督只配 11.5K 选择性动作标签；R2R-CE 48.1→55.3 SR、43.3→48.2 SPL，偏离历史下进度准确率提升 10.51 点。
  • SC²-WM 用世界模型前瞻构造内部反馈 Δ，校正隐状态并按分歧分位阈值触发测试时自适应；单目 R2R-CE 43.77→50.90 SR，轨迹长度缩短 32.5%；Δ 是引导量，不能当损失最小化。
  • Talk2Escape 用重复与偏离触发对话求助：GTA 基座 48.8→72.0 SR；询问率存在最优点，混合触发 23.1% 询问率掉到 54.0，偏离触发 15.0% 达 66.0。
  • 纠错机制分类表按纠错对象、触发信号、监督来源与失效条件组织；四类机制的共同纪律是触发条件与监督粒度必须匹配错误类型，触发式系统必须报告触发率与反事实对照。下一讲进入快照第五篇：多智能体与社交动态（第 097 讲）。
