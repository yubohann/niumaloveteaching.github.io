第五篇 · 基础模型与 2026 前沿

第 097 讲｜2026 快照 V：多智能体与社交动态

此前所有讲次默认一个智能体执行一条指令。本讲把设定扩到两种真实约束：任务需要多个智能体分工完成，环境里还有会移动的人。三篇 2026 年论文各占一端（arXiv 版本已核实，检索日 2026-10-01）。Xu 与 Liu 2026（arXiv:2609.35965v1）提出多智能体 VLN 的系统形式化，把任务建模为带依赖与资源约束的协调问题（在场锁 presence lock 与持有链 holding chain），并发布 MAVLN 基准：11,724 个回合、145 个场景、团队上限 4 个智能体、三种指令制度，配套 TRISS 基线（LLM 子任务调度、共享拓扑记忆、冲突感知执行）。该论文的 HTML 全文在检索时未开放（仅 PDF，39 页、18 图、16 表），本讲对它按摘要级信息写作，涉及具体指标名处标注为本讲整理口径。Dai、Wang、Wang、Sheng、He、Liu、Ye、Chen 2026（arXiv:2609.21504v1）的 DPed-VLN 基于 Habitat 3.0 建成动态行人基准：33,093 个回合、66,186 条配对指令、ORCA 控制的仿真行人、社交约束专家轨迹，并把 SR、SPL、STL 与碰撞率、个人空间合规率同表报告；DPet-RL 在 level-2 指令下取得 38.55 SR，而零样本 StreamVLN 的碰撞率经 LoRA 微调从 41.59 降到 26.06。Zhang、Li、Wang、Wang、Kang、Xu 2026（arXiv:2609.03483v3）的 AGC-VLN 用共享俯瞰地图把无人机与地面车接成训练免调团队：CARLA-Air Town10HD 上 100 个闭环回合取得 77.0% 联合成功率，协作增益 +27.0 个百分点。交付物是多智能体约束表。

  • 主题：多智能体形式化 / 在场锁与持有链 / 子任务调度 / 共享拓扑记忆 / 社交合规导航 / 碰撞率与个人空间 / 空地协同 / 共享俯瞰地图
  • 关键公式：CG=SRjoint−min(SRUAV,SRUGV)；θtgt=θA*+αt·wrap(θavoid−θA*)；HCR=至少一次碰撞的回合占比；PSC=个人空间合规时步占比
  • 预计学时：80 分钟
  • 前置讲：第 096 讲（2026 快照 IV：记忆与闭环纠错）

学习目标

  • 会解释：多智能体 VLN 与单智能体任务在状态、约束、指标三处的差别；社交合规为什么必须与成功率同表报告；空地协同为何选择俯瞰视图作为通信接口。
  • 会算：带依赖与在场锁的队级调度时长；联合成功率与单机成功率的并集分解；碰撞率与个人空间合规率的统计口径与变化量。
  • 会实现：约束感知的调度校验、ORCA 式避让航向融合、俯瞰地图注释与闭环跟踪三段示意代码。
  • 会判断：社交基准中「到达即成功」的误用风险；行人先验指令与普通路线指令的对照价值；训练免调协同的适用边界。
  • 会设计：为一个多机器人服务场景定义子任务约束、共享记忆接口与队级验收协议，并写清失效条件。

背景与动机

第 093 至 096 讲的所有方法都默认单智能体：一条指令、一个观测流、一份记忆、一套纠错机制。真实部署很快越过这个假设。仓库拣货需要多个机器人在不同楼层接力，医院配送需要一部电梯在多个机器人之间分时复用，园区任务需要空中平台提供地面视角看不到的全局信息。多智能体带来三类新问题：任务层面的依赖与资源竞争（谁先做、谁能同时在场、哪个资源被谁占用）、信息层面的共享表示（每个智能体的探索如何成为团队知识）、执行层面的冲突消解（同时刻的意图如何变成无碰撞路径）。MAVLN 论文把这三类问题整理成带约束的协调问题，这是本讲的第一条线。

第二条线是环境里的人。静态室内基准把行人物体化或直接忽略，部署到人流场景后，同一策略的行为差异很大：DPed-VLN 的对照实验显示，把静止行人改为动态行人，零样本 NaVILA 的碰撞率从 2.11% 升到 40.17%，StreamVLN 从 4.22% 升到 37.24%。语言指令还叠加了社交语义，例如「避开绿色行人」，此时语言 grounding 与反应式控制必须共同工作。第三条线是异质团队：无人机有全局俯瞰但无法沿道路行驶，地面车能沿路执行但只有局部第一人称视野，AGC-VLN 证明把两者的视图互补性做成一张共享地图，可以取得单机无法达到的联合成功率。三条线合起来构成多智能体与社交动态的完整图景。

核心原理

本节按「问题形式化、MAVLN 基准、社交动态基准、DPet 与适配结果、空地协同、约束表与结果对照、边界」七步展开；派生数字先经 Python 实算，论文数字标注协议。

1. 多智能体 VLN 的协调形式化

按 MAVLN 摘要给出的约束类型，本讲用如下口径整理。一个任务 M 由共享环境图 G、子任务集合 S={s1,…,sn}、依赖偏序 ≺、在场锁 Lock(·)、持有链 Hold(·) 与时限 Tmax 构成。每个子任务 sk 指定执行区域 Rk 与预估时长 dk。在场锁 Lock(sk)⊆A 要求集合内所有智能体在 sk 执行期间同时位于 Rk，典型场景是双人搬运或交接；持有链描述资源占用：资源 r 被某智能体持有，直到释放条件对应的子任务完成。可行调度要给每个子任务分配智能体与起止时间，并同时满足：依赖顺序 tend(si)≤tstart(sj)（当 si≺sj）、在场锁、持有链互斥与时限。队级成功定义为全部子任务完成，协调代价按「团队总路程除以各智能体独立最短路之和再减一」的口径度量。

实算一个调度示例：三个子任务时长 [40, 25, 35] 秒，s1≺s2，s3 独立。单智能体串行需 100 秒；两个智能体让 s3 与 s1、s2 并行，最短完成 65 秒，加速 1.54 倍；若 s1 的在场锁要求两名智能体同时在场（s3 无法与 s1 并行），两个智能体下 s3 要等 s1 结束后再与 s2 并行，完成时间变为 75 秒。在场锁把「可以并行」变成「必须同步」，是队级指标与单机指标分道扬镳的直接来源。

2. MAVLN 基准与 TRISS 基线

MAVLN 含 11,724 个回合、145 个场景，平均每场景 80.9 个回合；团队规模上限 4，指令覆盖三种制度。论文称自己是多智能体 VLN 的首个系统形式化，并给出四阶段任务构造管线与验证流程，配套约束感知指标。TRISS 基线由三部分构成：基于 LLM 的子任务调度器、把每个智能体的探索转为团队知识的共享拓扑记忆、以及把同时刻意图实现为无碰撞路线的冲突感知执行机制。论文的实验结论是，在调度、规划与执行三个环节都存在显著改进空间。需要说明的是，本讲检索时该论文没有 HTML 全文，以上内容为摘要与元信息级；子任务划分、指标具体名称与数值以日后放出的 PDF 为准。

3. DPed-VLN：动态行人下的社交合规基准

DPed-VLN 建在 Habitat 3.0 上，机器人状态 xt=(pt, θt)，行人集合 Ht={(hi,t, vi,t)}，动作空间为 {Stop, Forward, TurnLeft, TurnRight}，任务成功要求停在目标 3 米内；超过时域或触发终止碰撞条件都判失败。行人由 ORCA 局部策略在路点间运动，仿真提供网格级碰撞检查；专家轨迹由全局最短路意图与局部避让合成：先算朝下一路点的全局航向 θA*=atan2(−(wz−pz), wx−px)，再按最近行人的相对位置与速度算避让速度 vavoid（行人半径 r=0.3 米、时间常数 τorca=4.0 秒），最后按接近度自适应权重 αt 融合两个航向：距离小于 1.0 / 1.5 / 2.5 米时 αt 取 0.95 / 0.85 / 0.70，否则 0.50，角度差经 wrap 处理。航向差超过 7.5° 触发转向动作，局部净空低于 0.8 米时确定性抑制前进，死锁时执行恢复机动。专家质量另用 1.0 米终点容差过滤，评测成功半径仍是 3.0 米。

指令分两级：level-1 只用静态场景线索描述目标与路线，接近普通路线指令；level-2 在相同回合上暴露动态行人线索，例如行人朝向或风险提示，供对照实验使用。两级均禁止逐步动作脚本、精确未来状态与特权标签。数据集 32,172 个训练回合加 921 个验证未见回合，共 33,093 个回合、66,186 条指令-轨迹对；动态行人出现在 13,478 个训练回合中，占比 41.9%，平均每回合 3.21 人；场景行人密度 1 至 6 人。

4. DPet 与 VLM 适配结果

DPet 用 CLIP 视觉编码器与语言编码器，融合起点相对的极坐标位移 [ρt, φt, Δθt]，经交叉注意力与 LSTM 递推后接策略与价值头，并用行人计数、相对位置、短时运动三个辅助头提供监督，辅助权重各 0.1。RL 版本用 PPO，奖励为任务奖励加社交认知惩罚（碰撞与个人空间违规）；IL 版本为行为克隆，动作切换帧权重 c=3.0。评测指标里有两个社交量：碰撞率 HCR 统计至少发生一次碰撞的回合占比；个人空间合规率 PSC 统计个人空间阈值 τ=0.5 米之外的时步占比。主结果（level-2、val-unseen）：DPet-RL 为 38.55 SR / 36.35 SPL / 37.97 STL / 92.88 PSC / 36.70 HCR，DPet-IL 为 22.37 / 18.45 / 20.42 / 94.08 / 30.62，社交合规与到达效率由不同训练范式各占一头：RL 到达最好，IL 碰撞更少。

VLM 适配用 3,000 个样本、覆盖 561 个训练场景、5 轮 LoRA 微调（NaVILA 约 1,875 步、StreamVLN 约 3,750 步，全量训练约为其 10.7 倍）。结果按指标分化：NaVILA 的 level-1 SR 从 21.61 升到 22.37、HCR 从 40.17 降到 39.52；StreamVLN 的改动集中在安全侧，level-1 HCR 从 37.24 降到 27.14、level-2 从 41.59 降到 26.06，SR 小幅上升。行人动态消融给出最直接的对照：静止设置下 NaVILA 的 HCR 只有 2.11%，动态设置升到 40.17%；DPet-RL 从 1.02% 升到 42.45%。只用静止场景训练的策略迁移到动态设置后，SR 从 34.53 降到 27.69、HCR 从 12.27 升到 31.92，补上 level-2 指令也不能恢复。社交语言必须配合动态场景的具身经验才能生效，这是本基准最值得记住的负结果。

5. AGC-VLN：共享俯瞰地图的空地协同

任务给双机器人团队一个用提示描述的目标（例如卡车）。无人机悬停在高空、相机垂直向下，地面车相机朝前，回合时限 180 秒、成功判据为任一成员进入目标 5 米内且无碰撞。共享地图的构造是协同的核心：无人机读取地面车上报位姿与目标坐标，投影到当前俯视图像，渲染蓝色 CAR 标记、红色 GOAL 标记、绿色自机十字与黄色参考线，并标注无人机到目标、地面车到目标两个距离标签；整张注释图连同标注时刻的无人机位姿通过共享内存传给地面车，供其做像素到世界的逆投影。无人机自身并行运行 3D-SPF：冻结 VLM 在俯视图上输出目标像素 (u, v) 与高度指令 hc∈{−1, 0, 1}（下降、保持、上升），像素经平面地面射线投射转世界坐标，水平按比例速度飞行，稳定后按 10 米步长调整高度。地面车侧用冻结 VLM 在注释图上规划 10 个像素路点的道路路径，首点约束为自身位置、末点约束为目标位置，逆投影后用闭环控制器跟踪：航向误差分段量化为六个驾驶原语，油门按剩余距离缩放并裁剪到 [0.3, 1]，卡死时倒车脱困。

结果（CARLA-Air Town10HD，100 个闭环回合、50 个出生点各两次、无人机初始高度 60 米）：联合成功率 77.0%，其中地面车 75.0%、无人机 50.0%，协作增益 CG=SRjoint−min(SRUAV, SRUGV)=+27.0 个百分点；并集分解显示两个体同时成功的回合占 75.0+50.0−77.0=48.0%。对照单机：地面车单独 12.0%、无人机 SPF 20.0%、升级 3D-SPF 后 60.0%（三倍），最强已发表单机 Travel UAV 53.0%，被团队高出 24.0 个百分点。高度消融很能说明问题：30 米时视场变窄，联合掉到 28.0%；90 与 120 米时卡车只有几个像素，无人机定位失败（0.0%），77.0% 与 72.0% 完全由地面车贡献。注释消融同样有信息量：原始俯视图 65.0%、只标 GOAL 60.0%、CAR+GOAL 70.0%、再加参考线 75.0%、完整注释 77.0%：只给目标不给队友锚点时，地图比不注释时更低（60.0 对 65.0），队友位置是把全局视图转成可执行路径的必要条件。

7. 边界与失效模式

  • MAVLN 的全文未开放：本讲对其形式化与基线的描述来自摘要与元信息（39 页、18 图、16 表），指标名称与数值未经全文核对；引用时以正式版本为准。
  • 联合成功率是并集指标：AGC-VLN 的成功判据为任一成员到达，77.0 的联合数高于两个单机各自水平；评估团队时必须同时列出单机成功率与交集，否则会高估协同价值。
  • 社交指标主要覆盖室内动态行人：DPed-VLN 的行人由 ORCA 与路点驱动，不含人群逃避、群体对流等复杂社会动力学；从该基准得出的合规结论不能外推到任意人群。
  • LoRA 适配的收益是分项的：提升集中在碰撞率与部分成功率，SPL 与 STL 有轻微下降；论文明确说并不均匀改善全部效率指标。
  • AGC-VLN 依赖同步位姿与准静态假设：仿真内共享同一物理时钟，真机部署需要 LiDAR 里程计；3 秒决策间隔使快速移动目标不可用，论文将这三项列为有意的简化。

实现思路与设计

三类系统可以拼成一条多智能体设计流程：先定义子任务与约束，再定义共享表示，最后定义冲突消解与验收协议。每一层都需要在部署前确定回退路径。

多智能体任务定义流程（MAVLN 口径）

  1. 枚举子任务与依赖，划分执行区域；标注在场锁与资源持有链，检查可行调度的存在性。
  2. 确定共享记忆接口：每个智能体的探索写入共享拓扑图，调度器读图更新子任务状态。
  3. 定义冲突消解：同时刻意图先转路径再检测互碰，冲突时按优先级重排或改派。
  4. 验收用队级指标：全体完成率、协调代价、单机与联合指标分开列。

社交合规导航流程（DPed-VLN 口径）

  1. 仿真侧固定行人策略与专家生成参数（避让权重分档、动作阈值 7.5°、净空抑制 0.8 米），保证回合可复现。
  2. 指令分层：普通路线指令与行人先验指令成对生成，分别用于训练与诊断。
  3. 训练侧把碰撞与个人空间违规写进奖励或辅助损失；评测侧同表报告 SR、SPL、STL、HCR、PSC。
  4. 部署前做静止到动态的迁移测试，若 HCR 升幅超过训练时水平，先补动态数据再上线。

空地与异质团队流程（AGC-VLN 口径）

  1. 选视图互补性最强的物理量作通信接口：俯瞰视图携带队友与目标的全局相对位置，文本、特征与控制信号均无正增益。
  2. 注释必须包含队友锚点与目标锚点；缺队友锚点时规划器会被孤立目标误导（60.0 低于不注释的 65.0）。
  3. 确定性投影与逆投影把两个平台的误差隔开，一侧的模型错误不传播到另一侧。
  4. 低层执行与高层决策分频：决策 3 秒一次，跟踪按控制周期执行，卡死走倒车脱困。

关键代码与解读

三段代码分别给出约束感知的调度校验、ORCA 式避让航向融合、俯瞰地图注释与闭环跟踪。示意实现，约束校验按 MAVLN 摘要给出的约束类型整理，后两段按 DPed-VLN 与 AGC-VLN 的公开公式重写。

片段 1：在场锁与持有链的调度校验

def schedule_feasible(tasks, assign, start, end, agents, locks, holds):
    """校验一份队级调度：依赖顺序、在场锁、资源持有链。"""
    for sid, predecessors in tasks.deps.items():
        for pre in predecessors:
            if end[pre] > start[sid]:                # 依赖必须在开始前完成
                return False, f"dependency violated: {pre}->{sid}"
    for sid, need in locks.items():                  # 在场锁：全体同时在场
        if set(need) - set(assign[sid]):
            return False, f"lock agents missing: {sid}"
        for a in need:
            if not (start[sid] <= start[(sid, a)] and end[(sid, a)] <= end[sid]):
                return False, f"presence window mismatch: {sid}/{a}"
    holder = {}
    for (sid, a), r in holds.items():                # 持有链：资源单占
        if r in holder and overlap(holder[r], (start[sid], end[sid])):
            return False, f"resource conflict: {r}"
        holder[r] = (start[sid], end[sid])
    return True, "ok"

# 示例时长 [40, 25, 35] 秒、s1->s2 依赖：单机 100 秒；
# 两机并行 65 秒；s1 需两名智能体同时在场时变 75 秒

解读：（1）三类约束分开校验，报错信息给出具体类型与位置，便于调度器局部修复。（2）在场锁不仅要求成员在分配集合里，还要求其执行窗口被包含在子任务窗口内，二者缺一不可。（3）持有链按资源记录占用区间，只有区间重叠才算冲突；同一资源串行复用在多机器人电梯场景里是常态。

片段 2：ORCA 式避让航向融合

def blended_heading(pose, next_wp, pedestrians,
                    r=0.3, tau_orca=4.0):
    """全局意图与局部避让按距离分档融合，输出目标航向。"""
    theta_goal = math.atan2(-(next_wp[1] - pose[1]),
                            next_wp[0] - pose[0])          # θ_A*
    v_cur = current_velocity(pose)
    near = [p for p in pedestrians
            if dist_xz(p.pos, pose) < 2 * r]               # 交互集
    if not near:
        return theta_goal
    v_rep = 0.0
    for p in near:
        rel = sub(p.pos, pose)
        unit = normalize(rel)
        gap = 2 * r - norm(rel)
        v_rep += (v_cur - p.vel) + unit * (gap / tau_orca) # 排斥项
    v_avoid = v_cur + v_rep / len(near)
    theta_avoid = math.atan2(-v_avoid[1], v_avoid[0])
    d_min = min(dist_xz(p.pos, pose) for p in near)
    alpha = 0.95 if d_min < 1.0 else \
            0.85 if d_min < 1.5 else \
            0.70 if d_min < 2.5 else 0.50                 # 接近度分档
    return theta_goal + alpha * wrap(theta_avoid - theta_goal)

# 航向差超过 7.5° 触发转向；净空 < 0.8 m 抑制前进

解读：（1）避让只在行人进入 2r 交互集时生效，远处行人不会干扰路线意图。（2）融合权重随最近距离分档，距离越近越偏向避让，避免在最后一刻来不及转向。（3）输出仍要经过动作量化与安全规则，确定性抑制前进是碰撞前的最后一道保护。

片段 3：俯瞰注释与闭环跟踪

def annotate_bev(image, uav_pose, ugv_pos, goal_pos, K):
    """在无人机俯视图上渲染 CAR/GOAL 标记与距离标签。"""
    car_uv = project_to_pixel(ugv_pos, uav_pose, K)
    goal_uv = project_to_pixel(goal_pos, uav_pose, K)
    draw_marker(image, car_uv, "CAR", color="blue")
    draw_marker(image, goal_uv, "GOAL", color="red")
    draw_line(image, car_uv, goal_uv, color="yellow")      # 仅参考
    draw_text(image, car_uv, f"{dist(ugv_pos, goal_pos):.1f} m")
    return image, uav_pose                                 # 位姿用于逆投影

def track_path(ugv_pose, waypoint):
    """闭环跟踪：航向误差错位为驾驶原语，油门随距离缩放。"""
    d = dist_xz(ugv_pose, waypoint)
    psi_wp = math.atan2(-(waypoint[1] - ugv_pose[1]),
                        waypoint[0] - ugv_pose[0])
    e = wrap(psi_wp - ugv_pose[2])
    throttle = min(max(d / 10.0, 0.3), 1.0)
    if e > math.radians(30):
        action = "left"
    elif e < -math.radians(30):
        action = "right"
    else:
        action = "forward"
    return action, throttle

# 消融：只标 GOAL 时联合 60.0，低于不注释的 65.0

解读：（1）注释包含队友锚点、目标锚点、参考线与距离标签；消融显示缺队友锚点时，规划器会把孤立目标连成不可行路径。（2）逆投影依赖注释时刻的无人机位姿，两个平台之间用确定性几何换算，模型误差不跨平台传播。（3）跟踪控制按角度阈值量化六个原语，油门下限 0.3 保证低速通过，卡死检测另接倒车恢复。

常见坑

  • 把单机指标直接当成队级指标：用一名成员的成功率代表团队，忽略联合成功率是并集。根因是队级事件与个体事件不同。修复：同时报告单机、联合与交集三项（本例联合 77.0 由 75.0 与 50.0 并集而来，交集 48.0）。
  • 只报成功率不报碰撞：社交场景里「到达即成功」会掩盖危险行为。根因是效率与安全是两个维度。修复：HCR 与 PSC 同表报告；DPet-RL 的高 SR（38.55）伴随高 HCR（36.70），需与 IL 的低 HCR（30.62）对照解读。
  • 用静止场景训练后直接上动态环境：静止训练的 RL 迁移后 SR 从 34.53 掉到 27.69，HCR 从 12.27 升到 31.92，补文字先验也无法恢复。根因是社交行为需要具身动态经验。修复：动态数据先入训练分布，再做迁移评测。
  • 通信接口选在语义文本层：队友状态用自然语言转述会引入歧义与延迟，相关研究报告多数模型在文本耦合下退化。根因是缺少伙伴状态锚定。修复：选物理量接口（本例为俯瞰视图加队友与目标标记），并做注释消融验证必要性。
  • 忽略准静态与同步假设：AGC-VLN 的 3 秒决策与仿真同步位姿是其工作前提，直接外推到快速目标或异步真机会失效。根因是把实验简化当成能力边界。修复：先量化目标速度与通信延迟上限，超界场景在接口层加预测或提高决策频率。

  1. 调度核算：三个子任务时长 [40, 25, 35] 秒，s1≺s2，s3 独立。求单机串行时长、两机最短时长与加速比；若 s3 与 s1 需要同窗执行，两机时长变为多少？ ★

    串行 100 秒，两机并行 65 秒，加速 1.54 倍；在场锁下 s3 等 s1 完成后与 s2 并行，时长 75 秒。
  2. 社交指标解码：DPed-VLN 中动态相对静止设置，NaVILA 的 HCR 从 2.11% 升到 40.17%、StreamVLN 从 4.22% 升到 37.24%，各求变化量；DPet-RL 的 SR 38.55 与 HCR 36.70 同时高于 DPet-IL 的 22.37 与 30.62，说明部署时应在什么条件下选 RL 版本？ ★
    提示
    升幅 38.06 与 33.02 个百分点。RL 版本适合到达优先级高、可接受较高碰撞风险且速度受控的场景；人流密集或安全审计严格的场景应选 IL 或对 RL 加安全约束。
  3. 协同增益核算：AGC-VLN 联合成功率 77.0%、地面车 75.0%、无人机 50.0%，求协作增益 CG 与两名成员同时成功的回合占比；再求相对最强单机基线 Travel UAV（53.0%）的差。为什么联合指标必须与交集一起报告？ ★★
    提示
    CG=+27.0 个百分点；交集=75.0+50.0−77.0=48.0%；较 Travel UAV 高 24.0 个百分点。没有交集就无法判断团队是稳定双保险还是互相补位，后者对单点故障更敏感。
  4. 改参数预测：把 AGC-VLN 的无人机初始高度从 60 米升到 90 米，预测 (a) 无人机定位成功率；(b) 联合成功率；(c) 协作增益；(d) 这种「联合不变、增益变高」的指标形态会带来什么误读风险？ ★★
    提示
    (a) 0.0%（目标只剩几个像素）；(b) 77.0% 不变；(c) CG 从 +27.0 升到 +77.0。风险是把「无人机失效、地面车独撑」误读成协作变强；增益指标必须与单机指标同表阅读。

    提示
    (a) 例：取货、乘梯、搬运、投递四类子任务；电梯为持有链资源，双机搬运为在场锁。(b) 共享拓扑图存楼层连通与占用，调度器按依赖与资源状态派单。(c) 全员完成率、协调代价、碰撞率、个人空间合规率、平均完成时间。(d) 用激光与视觉检测同事位置与速度，通道拥堵时让行或改道，协议先于部署上线。(e) 可被推翻的假设示例：电梯时刻表稳定、无线覆盖无死角、行人遵守固定路线；降级方案含手动接管与单机模式。

小结

  • 多智能体 VLN 把任务建模为带依赖、在场锁与持有链的协调问题；MAVLN 含 11,724 回合、145 场景、团队上限 4，TRISS 以 LLM 调度加共享拓扑记忆加冲突感知执行作基线（本讲为摘要级，全文未开放）。
  • 调度实算：时长 [40, 25, 35] 秒且 s1≺s2 时，单机 100 秒、两机 65 秒；加入在场锁变 75 秒，说明同步约束把并行收益直接抹掉一部分。
  • DPed-VLN 用 ORCA 行人与两层指令提供可控社交评测：33,093 回合、动态行人占训练集 41.9%；动态相对静止使 NaVILA 碰撞率从 2.11% 升到 40.17%；DPet-RL 在 level-2 取得 38.55 SR（HCR 36.70），安全与效率分属不同训练范式。
  • AGC-VLN 用共享俯瞰地图完成空地互补：联合 77.0%、CG +27.0、交集 48.0%；只标目标不标队友时联合掉到 60.0，低于原始俯视图的 65.0。
