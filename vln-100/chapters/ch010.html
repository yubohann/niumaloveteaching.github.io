第一篇 · 任务、数据、仿真与评测地基

第 010 讲｜捷径与模态偏差

本讲复现一个反直觉实验：把视觉特征整体置零后，某些 VLN 模型在未见场景上的成功率不降、部分设置下更高（Hu 等，2019，ACL）。顺着这条线索讲清三件事：语言接地可以绕过路线结构这条捷径、像素级视觉特征在 61 个训练场景上容易过拟合、把接地拆成对象与路线两类专家再集成能把视觉信息重新变成增益。

  • 主题：模态偏差 / 捷径诊断 / 视觉消融 / 对象表征 / 混合专家
  • 关键数字：unseen SR 31.7 对 29.0（无视觉对 ResNet）；集成后 51.9
  • 预计学时：60 分钟
  • 前置讲：第 009 讲（val-seen / val-unseen：泛化协议）

学习目标

  • 会算：由视觉消融表的四组数字计算 seen 与 unseen 的分差变化，构造「记忆增益指数」并解释其符号。
  • 会判断：区分三类接地通道（视觉外观、路线结构、对象检测），说明为什么离散导航图放大了路线结构这条捷径。
  • 会实现：视觉特征置零 / 打乱两种消融钩子，以及跨模型动作空间对齐的 logits 集成。
  • 会设计：一套包含单模态基线、seen-unseen 成对报告与互补性分析的偏差诊断实验。
  • 会评估：解释对象表征与混合专家在 unseen 上的收益来源，并指出其协议边界（贪心解码、无数据增广、快照选择在 val-seen）。

背景与动机

第 009 讲把评测协议立住了：val-seen 与 val-unseen 的落差包含环境记忆与选择效应，读数字之前先看口径。本讲用一台精心设计的对照实验把「记忆」的具体形态挖出来。Hu 等 2019 在 R2R 上把两个当时的最优模型（Speaker-Follower 的 follower 与 Self-Monitoring）分别训练两个版本：完整版使用 ResNet 视觉特征，消融版把所有视觉特征置零。按常识，盲版本应该更差；实测在未见场景上，盲版本的成绩与视觉版本持平甚至更好（Hu 等，2019，表 1）。

这条结果推翻了一个隐含假设：模型在 R2R 上变强，未必来自视觉接地的增强。论文把接地拆成三条通道：视觉外观、路线几何结构、物体检测（Hu 等，2019，图 1）。指令「向右转」可以由路线结构直接满足，指令「在门边停下」才需要视觉或物体信息。当离散导航图的每个节点只有少量可行动作时，很多指令可以用「转弯模式匹配」蒙对，视觉特征于是成为可被忽略的通道。

本讲解决三件事：第一，把消融实验的结果算成可解释的分量表，理解「视觉在不同 split 上的作用方向为何相反」；第二，讲清对象表征与混合专家的修复路径；第三，把这套诊断方法整理成自己课题可用的实验模板，衔接下一讲的环境偏差诊断。

核心原理

1. 接地通道与捷径：语言可以接到什么上

VLN 的接地（grounding）指指令词与环境中可感知实体建立对应。论文把对应渠道分为三类：视觉外观（像素级 CNN 特征）、路线几何结构（导航图的边、可行动作、转弯序列）、物体检测（门、桌子等符号化实体）（Hu 等，2019，图 1）。三条通道都存在时，模型会优先利用统计上最容易拟合的那条。离散导航图恰好把路线结构的拟合难度压得很低：每个节点的候选动作通常只有数个，语言里的「左转、直行、上楼梯」与图中的边序列几乎一一对应。

论文给出一个直观解释：如果指令说「在沙发处左转」，而路线结构显示全程只有一个位置允许左转，模型不识别沙发也能完成任务；「直行 5 米后停」这类指令同样不需要视觉（Hu 等，2019，6 节）。这构成一种捷径（shortcut）：利用数据集与动作空间的统计规律达到高 SR，把语言理解与视觉接地的需要绕开。捷径本身不是错误，但它让评测分数与能力声明脱节，需要诊断实验来识别。

诊断原则：单独报告每个通道的能力，再看集成是否真的互补

把「完整模型」与「单通道模型」放在同一评测协议下对比，可以回答两类问题：完整模型的增益来自哪条通道；去掉某条通道后分数损失多大。若「去掉视觉」几乎没有损失，说明视觉通道未被有效利用，后续工作应优先改表征与训练目标，继续堆叠视觉模块收效有限。

2. 消融实验设计：把视觉特征置零

论文的实验协议干净且可复现：取两个语言跟随主干（SF：Speaker-Follower 的 follower 模型，Fried 等 2018；SM：Self-Monitoring 模型，Ma 等 2019），各自训练完整版与消融版。消融版在训练与测试时都把视觉特征向量置零。为排除干扰，模型不使用数据增广，推理使用贪心搜索（不使用 beam search、pragmatic 推理或进度监控），快照按 val-seen 上的成功率选择（Hu 等，2019，3 节）。两种训练方案各做一遍：teacher-forcing（按参考路径逐步监督）与 student-forcing（按模型自身分布采样并接受最短路 oracle 监督）。

这组数字还排除了几个替代解释。其一，「盲模型只是训练得更久」：两种模型共享迭代数与选择流程。其二，「差异来自随机波动」：落差在两种主干、两种训练方案上重复出现，方向一致。其三，「视觉特征本身无用」：同表显示视觉在 seen 上有大幅增益，说明特征携带信息，问题出在泛化。论文的解释是：训练集只有 61 个建筑，CNN 像素特征让模型有能力记忆训练场景的具体外观，学生强制采样会进一步鼓励这种记忆；换到新建筑，记忆失效，视觉通道从助力变成噪声源（Hu 等，2019，4 节）。

盲模型的绝对水平同样值得核对：以 SF 为例，盲模型在 unseen 上达到 31.7 到 35.2，比第 009 讲给出的随机基线 16.3 高约 15 到 19 个百分点，这部分来自语言与路线结构的组合，说明「循着转弯模式走」是一条真实可解、容量可观的捷径通道。把盲模型只当作健全性检查会低估问题：它测量的是捷径在没有任何视觉输入时的完整容量，任何新的视觉方法都应当先越过这条基线再谈增益。

3. 对象表征：把外观换成符号化实体

修复思路与第 009 讲的诊断一致：问题的载体是像素级特征的可记忆性，那就换一种更难记住、更容易迁移的表征。论文用在大规模视觉基因组（Visual Genome）上预训练的 Faster R-CNN 检测器，在每个位置取置信度最高的 150 个检测框；每个物体向量由三部分拼接：物体类别词的 GloVe 向量、属性词的 GloVe 向量之和、检测框坐标组成的空间向量；再用与基线一致的注意力机制在这个物体集合上做加权（Hu 等，2019，4 节）。检测结果是符号化的类别与属性，跨场景共享词表，记忆压力从「这个房间的纹理」转移到「这里有没有桌子、门是什么颜色」。

SF 上的改善最完整：物体表征把 unseen SR 从 29.0 抬到 33.5（+4.5），与像素特征拼接后到 39.8（+10.8），高于盲模型的 35.2。SM 上物体单独使用达到 41.6（+1.1），拼接后略降至 39.5（−1.0）。同一组对照在不同主干上给出不同排序，提示两点：其一，对象通道确实携带可迁移信息，两个主干上都没有出现「换表征后 unseen 下降」的灾难；其二，单一模型内混合两种视觉表征并不自动带来互补，容量与优化路径会决定收益归属，这直接引出下一小节的模块化方案。

4. 混合专家：把通道交给不同专家再集成

视觉与非视觉模型的错误并不重合：视觉模型擅长需要外观判断的指令，盲模型擅长路线结构即可解决的指令。论文由此把接地过程分解为若干专家，每个专家只接触一种输入，预测时在动作层集成（Hu 等，2019，5 节）。集成方式为每个时间步对动作 logits 取平均；早期实验显示平均 logits 略优于平均概率。先分别训练再集成的结果：SF 上最佳两路组合为（ResNet，无视觉）39.5，高于同类组合的最佳值 35.4（物体对物体）；SM 上最佳两路组合为（ResNet，无视觉）46.9，高于同类最佳 45.2（物体对物体）。跨模态集成优于同模态集成，说明通道之间的互补是真实存在的，两个同类模型只共享同一类错误。

三路集成（ResNet、物体、无视觉）在 SM 上达到 49.5，比最佳两路高 2.6；把两路与三路组合改为共享指令编码器联合训练后分别升到 48.3 与 51.9（相对分训集成 +1.4 与 +2.4）。最终 51.9 的意义可以用两把尺子量：相对 SF 的 ResNet 单模型 29.0 高 22.9 个百分点（+79.0%），相对 SM 的 ResNet 单模型 40.5 高 11.4 个百分点（+28.1%）。更有说服力的是同信息量对照：单模型（ResNet + 物体）拥有与三路联合模型完全相同的输入，unseen SR 只有 39.5，比 51.9 低 12.4。同样的信息，拆成多个各看一种模态的专家再集成，比塞进一个模型效果更好；模块化本身提供了一种归纳偏置，迫使每个专家依赖各自的通道。

协议边界

以上数字的成立条件：模型不使用数据增广、推理为贪心搜索、快照按 val-seen SR 选择、评测采用 R2R 离散协议 3 m 成功阈值（Hu 等，2019，3 节与附录）。换成 beam search、进度监控或增广训练后，消融与集成的数值会变化；跨论文引用时必须连同这些条件一起说明。

5. 从「视觉无用」到「视觉未被学会」：解释的边界

盲模型在 unseen 上不降甚至更高的现象，最常见的错误解读是「视觉对 VLN 没有价值」。论文的数据不支持这一结论：视觉在 seen 场景上有 +23.6 与 +26.7 量级的增益，说明模型能学会利用视觉；对象表征在两个主干上都能提升 unseen；跨模态集成稳定优于同模态集成。综合起来，正确表述是「像素级视觉表征在训练场景有限的条件下未被学到可迁移的接地方式，且与路线结构捷径竞争时经常落败」。这与第 008 讲的 R4R 证据相互印证：当参考路径变得曲折、终点与走法解耦，语言与视觉通道的价值才会在指标上显形。第 011 讲会把这类分析推广到环境与骨干网络的更换实验，形成完整的偏差诊断方法学。

实现思路与设计

把本讲的实验整理成可复用模板，需要三张设计表：消融矩阵、消融算子、集成方案。

1. 消融实验矩阵

通道配置训练方案报告 split回答的问题
完整视觉（ResNet）teacher / studentval-seen 与 val-unseen 成对视觉的基准贡献与记忆分量
无视觉（置零）teacher / student成对路线结构通道单独能走多远
仅物体与完整版对齐成对符号化视觉通道的迁移性
ResNet + 物体与完整版对齐成对单模型内多表征是否互补
跨模态集成分训 + 联合两档成对模块化归纳偏置的净收益
同模态集成（对照）分训成对区分「集成涨点」与「通道互补涨点」

矩阵的关键在于两类对照必须同时存在：同模态集成回答「涨点是否只是集成效应」，跨模态集成回答「不同通道是否互补」。缺任何一类，结论都无法闭合。缺省设置建议：迭代数、批大小、学习率、快照选择规则在全部行保持逐字一致。

2. 消融算子：置零、打乱、随机特征各自测什么

算子操作检验对象预期症状
置零视觉特征向量全置 0通道整体移除后的下限unseen 不降或小降，说明视觉未被依赖
打乱在同一 episode 内把各方向特征按随机顺序重排空间对应关系是否被使用若分数与完整版接近，说明模型未使用方向对齐
随机特征替换为同维随机噪声（训练与测试一致）特征分布本身是否被利用下降幅度反映模型对特征统计的依赖强度

三种算子回答的问题不同，混用会导致结论错位：置零测「有没有用」，打乱测「用没用对」，随机特征测「依赖的是分布还是内容」。执行时还要写清消融的边界，例如朝向编码（sin/cos 朝向特征）是否属于被消融的视觉输入。第 008 讲曾提示动作与朝向的耦合，这里是同一问题的另一面：置零范围定义不清，消融结论就无法归因。

决策选项选择判据

与第 009 讲的衔接：本讲全部数字都遵守上一讲的选择协议（快照按 val-seen 选、val-unseen 只报告），因此「盲模型在 unseen 上更强」这一结论不携带快照选择偏差。把它与第 008 讲的 CLS 视角合读，可以得到第一篇的评测结论：只看终点与标称路径的指标体系会同时漏掉两条捷径，一条来自路径保真，一条来自模态利用。

关键代码与解读

三段代码分别实现消融钩子、动作对齐集成与互补性统计，均按本讲的实验口径设计。

片段 1：视觉特征消融钩子

import torch

def ablate_visual(feats, mode="zero", rng=None):
    """对形状为 (B, M, D) 的全景特征做消融。

    B: 批大小；M: 视角数（12 朝向 x 3 俯仰 = 36）；D: 特征维度。
    mode="zero": 全零；"shuffle": 批内视角顺序逐样本重排；
    "random": 用标准正态噪声替换（训练与测试使用同一分布）。
    """
    if mode == "zero":
        return torch.zeros_like(feats)
    if mode == "random":
        return torch.randn_like(feats)
    if mode == "shuffle":
        out = feats.clone()
        for b in range(feats.shape[0]):
            perm = torch.randperm(feats.shape[1])   # 视角维重排，保持内容不变
            out[b] = feats[b, perm]
        return out
    raise ValueError(mode)

# 训练循环中的接入点：只包住图像特征，朝向编码另行控制
# feats = encoder(observations)                 # (B, M, D)
# feats = ablate_visual(feats, mode=cfG.mode)   # 实验组统一从这里切换
# logits = policy(feats, instruction_tokens)

解读：（1）三个模式对应三种检验对象，实验脚本用同一个开关切换，保证除算子以外的一切逐字一致。（2）打乱在视角维内进行，保留「此刻存在 M 个观测」的结构，只破坏方向对应关系，这样能区分「模型用没用到方向对齐」与「模型用没用到特征存在性」。（3）接入点刻意放在图像特征之后、策略网络之前，朝向编码等非图像输入是否消融由实验配置显式决定并在论文中说明，避免归因含混。（4）消融版在训练与测试使用同一算子，防止训练-评测分布不一致引入新的混淆。

片段 2：跨模型动作 logits 集成

def fuse_logits(logit_list, action_maps, eps=1e-6):
    """把多个专家的动作 logits 融合到统一动作空间。

    参数：
      logit_list: 各专家的动作 logit 张量组成的列表；
      action_maps: 各专家的语义动作名列表组成的列表。

    返回：(n_union,) 的统一动作 logits，未提供该动作的专家不参与平均。
    """
    union = sorted({a for m in action_maps for a in m})
    idx = {a: i for i, a in enumerate(union)}
    total = {a: 0.0 for a in union}
    count = {a: 0 for a in union}
    for logits, amap in zip(logit_list, action_maps):
        for j, name in enumerate(amap):
            total[name] += float(logits[j])
            count[name] += 1
    return [total[a] / max(count[a], 1) for a in union]

解读：（1）不同主干的动作编号体系独立，先映射到语义动作名（左转、右转、前进、停止等）再融合；按编号直接平均会在「编号 2 的含义不同」时产生错误。（2）某专家在某位置不可用的动作不参与该项平均，等价于只在可行动作集合上做均值，避免把「不可达」当成低分。（3）返回统一顺序的列表，供解码器与停止判定共用；真实实现应保留 tensor 形式并放在设备上，本片段用 Python 浮点便于逐行核对语义。（4）若需要学权，把 count 替换为可学习权重的归一化即可，但须按上一讲纪律在独立 dev 集上学习，val-unseen 不参与。

片段 3：模态互补性统计

def complementarity(records_visual, records_blind):
    """统计视觉专家与盲专家的互补结构，输入为逐指令成功布尔列表。

    返回：单模态 SR、两者并集上界、互补对占比与不一致方向计数。
    """
    assert len(records_visual) == len(records_blind)
    n = len(records_visual)
    v = sum(records_visual)
    b = sum(records_blind)
    both = sum(x and y for x, y in zip(records_visual, records_blind))
    union = sum(x or y for x, y in zip(records_visual, records_blind))
    only_v = sum(x and not y for x, y in zip(records_visual, records_blind))
    only_b = sum(y and not x for x, y in zip(records_visual, records_blind))
    return {
        "sr_visual": v / n,          # 视觉专家成功率
        "sr_blind": b / n,           # 盲专家成功率
        "sr_union": union / n,       # 两专家并集上界（集成潜力上限）
        "only_visual": only_v,       # 视觉独对、盲错的指令数
        "only_blind": only_b,        # 盲对、视觉错的指令数
        "complement_ratio": (only_v + only_b) / max(union, 1),
    }

解读：（1）并集成功率 sr_union 是集成的理论上限：只有当两个专家至少一个成功时，集成才有机会答对，它与单模态 SR 的差即互补空间。（2）only_visual 与 only_blind 的计数直接对应论文「错误不重合」的直觉；若两个数字都接近 0，说明两个专家犯同样的错，跨模态集成不会有效。（3）complement_ratio 用并集成功作分母做归一化，便于跨模型比较；它的对称性也能暴露「互补只存在于一个方向」的情形。（4）统计按评估集分别运行（val-seen 与 val-unseen 各一份），两套数字的差异就是第 2 小节记忆增益指数的逐指令版本。

常见误区

  • 消融只报一个 split。症状：看到「无视觉模型更强」就写「视觉有害」。根因：视觉在 seen 与 unseen 上的作用方向不同，只报 unseen 会丢掉「视觉确实被使用」的另一半证据。修复：seen 与 unseen 成对报告，并给记忆增益指数；memo 一下公式：seen 增益减 unseen 增益。
  • 消融范围定义含混。症状：复现者把朝向编码与图像特征一起置零，或反过来只置零图像特征的部分通道，结论互不可比。根因：视觉输入往往包含图像特征与朝向编码两类张量。修复：在实验文档中逐项列出被消融的输入；朝向等非图像输入单独做一组对照。
  • 集成时按动作编号直接对齐。症状：集成后的分数低于最强单模型，且在天真的平均概率下同样如此。根因：不同主干的动作索引语义不同，且各专家可行动作集合的形状数不一致。修复：先做语义动作名到统一编号的映射，缺项动作只按提供的专家平均，见片段 2。
  • 把「盲模型强」解读为「视觉无用」。症状：论文结论写成「VLN 不需要视觉」。根因：忽略了 seen 上的大幅视觉增益、对象表征的 unseen 提升与跨模态集成的稳定优势。修复：结论改写为「当前像素表征在有限训练场景下未学到可迁移的接地，模块化分解能释放视觉价值」。
  • 对照实验的训练方案不齐。症状：消融版与完整版使用不同的迭代数或快照选择规则，差距被训练预算混淆。根因：消融实验常复用旧检查点或旧配方。修复：全部组共用同一份训练预算与选择规则；两种训练方案（teacher / student）都要覆盖，因为论文实测两者结论一致才可信。

练习与思考

  1. 由表 1 的 SF student-forcing 行计算：视觉在 val-seen 与 val-unseen 上的分差（53.3 − 29.7 与 29.0 − 31.7），以及记忆增益指数；再用 SM teacher-forcing 行验证同一算法。★
    提示
    SF：seen +23.6，unseen −2.7，指数 = 23.6 − (−2.7) = 26.3。SM teacher-forcing：seen +9.7，unseen +0.6，指数 = 9.1。指数为正且量级可观，说明视觉收益集中在训练场景。
  2. 为「置零 / 打乱 / 随机特征」三种算子各设计一个可证伪的预测：在什么结果下，可以判定模型「使用了方向对齐的视觉信息」？★★
    提示
    打乱算子保持特征内容与数量、只破坏方向对应：若打乱后 unseen SR 明显低于完整版而接近置零版，说明模型依赖方向对齐；随机特征下降则反映对特征统计的依赖；三者需要有完整版作共同参照系。
  3. 实现片段 1 的消融钩子，在一份小批量特征上验证三种模式：输出形状与输入一致、置零模式全零、打乱模式每行是同一集合的重排（可用排序后求和验证）。★★
    提示
    打乱不变性是关键断言：对每个样本，打乱前后沿视角维求和应逐元素相等；随机模式则检验均值接近 0、方差接近 1（大样本下）。
  4. 设计一套完整诊断协议，回答「模型有没有使用视觉」与「视觉是否伤害泛化」两个问题。协议要包含：消融算子选择、split 报告方式、互补性统计、对象通道对照，以及至少两个能推翻结论的反例情形。★★★
    提示
    两个问题对应两组判据：使用与否看置零/打乱的分差与互补性计数；伤害与否看 seen 与 unseen 成对分差与记忆增益指数。反例情形可设计为「置零后 seen 大涨、unseen 不变」（使用的证据）与「对象通道置零后 unseen 大跌」（视觉可迁移的证据）。两套结果同时出现时，结论应表述为「像素通道未被有效使用、符号通道可迁移」。
  5. 取片段 3 的统计接口，构造一组假数据：视觉与盲模型各 20 条指令，视觉独对 4 条、盲独对 6 条、共同对 8 条。计算两个单模态 SR、并集上界与互补比，并讨论 logits 集成能否达到并集上界、受哪些因素限制。★★★
    提示
    视觉 SR = 12/20 = 60%，盲 SR = 14/20 = 70%，并集 = 18/20 = 90%，互补比 = 10/18 ≈ 55.6%。集成低于并集上界，因为动作级平均会在两人分歧的步骤上折中；上限只有当某专家的正确动作同时被另一专家给出高分时才可能触及，停止判定与误差累积进一步拉低实测值。

小结

  • 视觉消融实验：把视觉特征置零后，SF 在 unseen 上从 29.0 升到 31.7（student-forcing）与从 29.0 升到 35.2（teacher-forcing）；SM 两方案接近持平（40.5 对 39.7，32.8 对 32.2）；而在 seen 上视觉带来 +23.6 量级的增益，记忆增益指数为 9.1 到 26.3。
  • 解释：语言接地存在三条通道，离散导航图让路线结构捷径极易拟合；61 个训练场景下像素特征可被记忆，换场景后收益消失。正确表述是「像素表征未学到可迁移接地」，与「视觉无用」有本质区别。
  • 对象表征：在 Visual Genome 上预训练的检测器取 top-150 物体，用类别与属性词向量加检测框坐标；SF 的 unseen SR 从 29.0 升到 33.5，与像素特征拼接后到 39.8。
  • 混合专家：跨模态集成优于同模态（SM 46.9 对 45.2；SF 39.5 对 35.4），三路 49.5，联合训练终值 51.9，比同信息量单模型 39.5 高 12.4，比 SM 单模型高 11.4。
  • 协议边界：贪心解码、无数据增广、快照按 val-seen 选择；以上数字均为 R2R 离散协议 3 m 口径（Hu 等，2019）。
