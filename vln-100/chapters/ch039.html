第二篇 · 离散方法谱系：从模块到预训练

第 039 讲｜记忆与地图范式横评

本讲把第 032 至 038 讲出现过的四类记忆载体（递归与显式历史、在线拓扑图、局部度量加全局拓扑、动态网格）收进同一张对比表：用内存、延迟、精度三笔账量化差异，给出以任务、传感器与算力为输入的选择决策树，并实践一套与具体载体解耦的记忆接口。

  • 主题：记忆范式对比 / 三笔账 / 决策树 / 统一接口
  • 关键对比：R2R val unseen 从 RecBERT 63 / 57 到 BEVBert 与 GridMM 75 / 64 的路径拆解
  • 预计学时：60 分钟
  • 前置讲：第 038 讲（GridMM：动态网格记忆）

学习目标

  • 会写：四类记忆载体的统一表述 mt = U(mt−1, ot)，并写出各自的载体、更新算子与读取方式。
  • 会算：给定历史长度 t，实算四类范式的内存占用；会用 token 数与注意力公式估算延迟量级；会标注精度数字的出处与协议。
  • 会实现：与载体解耦的记忆接口，能替换后端而不改动作头。
  • 会判断：按任务类型、传感器条件、显存预算与延迟上限，用决策树选出记忆范式并说明理由。
  • 会诊断：跨协议比较、seen 与 unseen 混报、token 数代替延迟、记忆收益与预训练收益混淆四类系统性错误。

背景与动机

第 032 至 038 讲按时间顺序展开了一条方法线：循环状态（RecBERT，Hong 等 2021，CVPR 2021）、显式全景历史（HAMT，Chen 等 2021，NeurIPS 2021，arXiv:2110.13309）、在线拓扑图（DUET，Chen 等 2022，CVPR 2022，arXiv:2202.11742）、局部度量加全局拓扑（BEVBert，An 等 2023，ICCV 2023，arXiv:2212.04385）、动态网格（GridMM，Wang 等 2023，ICCV 2023，arXiv:2307.12907）。每一步都在回答同一个问题：把“走过的环境”记成什么。

这条线上的数字不能直接连成排行榜。各方法的评测协议不同：特征来源从 ResNet 特征到 ViT 到 CLIP 网格特征，位置信息从无到有，R2R-CE 数字还依赖航点预测器与迁移管线。更隐蔽的问题是收益归属：同一篇论文里，记忆载体的改进、代理任务的改进与增广数据的改进混在同一张表里，读者容易把预训练收益记到记忆结构名下。

本讲的三个交付物：一张四范式统一对比表，回答“差异在哪里”；一套三笔账（内存、延迟、精度），回答“代价是什么”；一棵决策树，回答“新任务选哪个”。这三件东西也是第四篇 066 讲记忆范式总览、067 至 069 讲深化三篇的接口。读完本讲，你应能对一个新任务在四类载体中做出有据可依的选择，并能设计实验把“载体收益”从“训练配方收益”里分离出来。

核心原理

先给统一表述，再逐个范式展开，最后做三笔账与决策树。数字全部标注论文来源、表号与 split；本讲实算在代码片段 3 中给出。

1. 统一表述：载体、更新与读取

把第 t 步之前的全部历史抽象为记忆 mt，四类范式都可写成：

mt = U(mt−1, ot)，at ~ π(· | Q(mt, ℓ), ot) ot 为当前观测（全景特征与可达候选），ℓ 为指令；U 为更新算子，Q 为读取算子。四类范式的差异全部落在 U 与 Q 上，动作头可以在不同载体间复用
范式载体 mt更新算子 U读取算子 Q
P1 递归与显式历史（RecBERT / HAMT）1 个状态 token 或 t 个全景摘要 token门控递推（递归）或追加（显式）对历史序列做时序注意力
P2 在线拓扑图（DUET）节点特征集合与邻接关系加入当前节点与邻居，更新节点特征图上跨模态注意力与全局打分
P3 局部度量加全局拓扑（BEVBert）U×V×D 度量图与全局节点图历史邻节点网格投影与节点维护单元级与节点级双编码后动态融合
P4 动态网格（GridMM）不断增大的特征与坐标集合、N×N 地图投影新特征并按相对坐标重建地图指令相关性聚合后与观测和轨迹融合

2. P1 递归与显式历史

RecBERT 用一个循环更新的 [CLS] token 承载历史，显存为常数（768 维 float32 约 3 KiB），代价是早期信息随步数指数衰减。HAMT 改为保留每步全景摘要：单视图经 ViT 编码、全景内空间注意力聚合、历史时序注意力建模，把复杂度从全铺开的 O(t²K²) 降到 O(tK²+t²)，t = 15 时历史仅 (t+1)×768×4 B ≈ 48 KiB，而把 15 步、每步 36 视角的全部 token 缓存需要约 0.304 GiB。

P1 的优势与预训练最兼容：历史是标准序列，可直接套 BERT 式代理任务与大规模指令轨迹预训练，这也是 HAMT 能把代理任务收益做到 +9.1 个百分点 SR（val unseen 54.4 到 63.5）的结构基础。边界有三条：动作空间仍为局部（12 视角加 stop），长程回退要靠逐步执行；历史长度在显存里线性增长；空间关系只在步内建模，跨步的几何一致性依赖模型自行推断。

3. P2 在线拓扑图

DUET 把环境维护为在线增长的图，节点分三类：已访问节点、可导航但未探索的节点、当前节点。每步把当前节点与邻居加入图，更新节点视觉表示：已访问节点用全景平均特征，可导航节点用从多个位置累积的部分视图特征。读取时分两路：粗尺度对全图节点做图感知跨模态注意力（GASA，在注意力分数上叠加节点间距离矩阵的可学习偏置），预测全局动作；细尺度对当前位置的 12 视角与物体特征做局部预测；两路分数经门控系数融合，长距离目标用 Floyd 最短路执行。

实验数据说明两路缺一不可（REVERIE val unseen，DUET 论文表 1）：只用细尺度 28.86 SR / 23.57 SPL；只用粗尺度 36.52 / 25.98；平均融合 45.81 / 31.94；动态融合 46.98 / 33.73。GASA 的边际收益体现在 SPL：动态融合下从 32.88 升到 33.73。代价是节点表示粗糙（每个节点一个向量），以及全局搜索与回溯让轨迹变长：R2R val unseen 上 DUET 72 SR / 60 SPL，相对 HAMT-e2e 的 66 / 61，SR 加 6 而 SPL 减 1，论文明确解释为回溯带来的路径变长。

4. P3 局部度量加全局拓扑

BEVBert 的出发点是全景输入的两类空间缺陷：单视角观察不完整，跨视角存在重复观察，模型难以判断“同一个书架”与“两个书架”。它把视角的 14×14 网格特征按深度与位姿投影到以智能体为中心的局部度量图（21×21 单元、单元边长 0.5 m、全图 10.5 m×10.5 m），历史投影取图上 κ 阶以内的已访问节点；全局依赖仍由拓扑图承担。细胞嵌入使用极坐标位置编码（cos θ, sin θ, 归一化距离），并对局部动作空间中的单元加可导航嵌入。

预训练目标有三项：MLM、混合单步动作预测（HSAP，把局部单元分数转换到全局动作空间后与节点分数门控融合）、掩码语义想象（MSI，15% 单元掩码后预测 40 类语义标签）。消融（R2R val unseen，论文表 5 至表 7）给出三段证据：从零训练 60.24 SR，仅加 MLM 升到 73.52，再加 HSAP 到 74.03（SPL +2.90），再加 MSI 到 74.88（SR +0.85）；深度用真值或估计值差异很小（60.90 对 60.64、74.88 对 74.67），说明特征空间投影对深度噪声不敏感；度量图从 11×11 升到 21×21，短期推理 transformer 的 FLOPs 从 4.5 G 升到 15.2 G，再升到 31×31 时 32.7 G 而收益有限，论文因此取 21×21。

5. P4 动态网格

GridMM 进一步放弃固定局部窗口，把全部已访问特征投影进随环境扩张的自中心网格；单元内容用指令相关性聚合，末段单元内特征数可超过 600（t = 15 时平均约 45），平均池化会让关键线索被背景稀释。相对 P3，它多两项成本：记忆库按步线性增长（本讲实算每步约 1.72 MiB，t = 15 约 25.84 MiB），以及每步重建地图的坐标变换；换来的收益集中在目标导向任务（REVERIE val unseen 51.37 SR / 36.47 SPL，对 DUET 加 4.39 / 2.74）与连续环境（R2R-CE val unseen 49 / 41，同一航点预测器下对 DUET 加 2 / 2），在 R2R 上与 BEVBert 持平。论文结论同时承认多楼层仍是未解问题。

延迟账没有单一数字，按三个可测代理量比较：键值序列长度、注意力 FLOPs、执行侧代价。P1 的读取代价随 t 平方增长但常数小；P2 的动作空间随图扩张，且长距离目标需要最短路规划；P3 的短期 transformer FLOPs 随度量图边长平方增长（4.5 / 15.2 / 32.7 G 对应 11 / 21 / 31）；P4 把地图压到 196 个 token 且只作键值，论文按同一公式估算其交叉注意力成本约为 BEVBert 度量图的二分之一（本讲实算：查询长度 37，键值 196 对 441 的单层成本约 0.57 对 1.18 GFLOPs），但每步的投影与相关性计算需要缓存机制支撑，t = 30 时缓存把相关性行数从 273,420 压到 17,640。整机延迟还取决于实现与硬件：HAMT 论文在单张 P100、R2R val unseen 全集上实测 RecBERT 69 秒、HAMT 104 秒（1.51 倍），可作为“显式历史相对递归状态的推理代价”参照。

8. 选择决策树

  • 第一步看任务：逐步指令、短路径、单卡小显存，选 P1；目标导向或对话式长程探索，进入第二步。
  • 第二步看传感器与携带条件：只有 RGB、无可靠深度与位姿，回到 P1 或 P2 的轻量拓扑；有位姿且深度可用，进入第三步。
  • 第三步看空间证据需求：指令以房间与地标为主，选 P3 的局部度量加全局拓扑；指令频繁引用属性、背景与细粒度关系，选 P4 网格。
  • 第四步看预算：显存与延迟紧，把分辨率压到下限（P3 取 11×11，P4 取 8×8）并配合缓存；预算充足再回到论文默认（P3 的 21×21、P4 的 14×14）。
  • 边界提醒：多楼层、室外、动态环境不在四范式的舒适区，需要高度维度、语义压缩或时效标记等扩展，第 5 篇的地图记忆智能体会再次回到这一话题。

9. 适用边界与失效模式

  • 协议不可比：R2R-CE 数字受航点预测器、迁移数据与训练管线影响，跨论文比较必须先对齐这三项。
  • 收益归属混淆：BEVBert 从零到 MLM 的 +13.28 SR 属于预训练配方收益，不属于记忆载体本身；给记忆结构记账时要单列。
  • seen 与 unseen 分工：val seen 高分包含环境记忆贡献，泛化结论只看 val unseen；成对报告是底线。
  • 统计显著与单次运行：多数论文单次运行、无方差报告，1 个百分点内的差异不足以支撑选型结论。
  • 动态环境未覆盖：四类载体都假设观察过的环境不再改变，物体移动与人群活动需要时效机制。

实现思路与设计

本讲的工程交付物是一套与载体解耦的记忆接口，让研究者能在同一动作头下切换四类后端做对照实验。

接口定义

方法输入输出语义
observe(ot)当前全景特征、位姿、深度、可达候选无把新观测并入记忆，即更新算子 U
tokens()无键值 token 集合供跨模态注意力读取，含类型标记
action_scores(ℓ, ot)指令与当前观测局部与全局候选分数各后端自行决定动作空间，返回统一字段
backtrack(target)目标节点标识最短动作序列无图后端返回空列表并回退到逐步执行
memory_bytes()无字节数三笔账中的内存项，训练日志直接记录

接口设计的关键取舍是“动作空间由后端声明”。P1 只返回 13 个局部候选，P2 至 P4 可以返回全局候选；评测器与执行器按声明的空间解释分数，避免把全局节点分数误当局部视角分数。另一处取舍是 token 类型标记：拓扑节点、度量单元、网格单元与历史摘要共用一套注意力，需要类型嵌入区分，否则模型无法区分“一个位置”与“一个时刻”。

四范式的对照实验若同时更换记忆、预训练数据与动作头，任何差值都无法归因。本课程建议的受控设置是：动作头固定为“局部加全局门控融合”（036 讲起已统一的接口），训练配方固定为“同一预训练数据加同一微调流程”，只替换 observe 与 tokens 两个方法。判据来自 DUET 与 BEVBert 的消融教训：增广数据在预训练阶段有正收益、在策略阶段消失；预训练任务的收益又大于记忆结构本身的收益。只有先剥夺这两项变量，载体差异才可读。

与前后讲的衔接：本讲收束第二篇的记忆主线；040 讲复盘两条泛化路线时会再次使用本讲的三笔账。第四篇 066 至 069 讲把内存、延迟、精度扩展成完整的记忆预算方法论。

    def action_scores(self, instruction, obs):
        raise NotImplementedError
    def memory_bytes(self):
        raise NotImplementedError

class RecurrentMemory(EpisodeMemory):
    """P1 递归：一个状态 token，常数内存。"""
    def __init__(self, dim=768):
        self.state = torch.zeros(1, dim)
        self.cell = None
    def observe(self, obs):
        z = self.cell(obs["pano"]) if self.cell else obs["pano"].mean(0, keepdim=True)
        self.state = z                                    # 门控更新略
    def tokens(self):
        return {"history": self.state.unsqueeze(0), "type": 1}
    def memory_bytes(self):
        return self.state.numel() * 4

class GridMemoryAdapter(EpisodeMemory):
    """P4 网格：观察入记忆库，查询时重建地图并聚合。"""
    def __init__(self, bank, n_cells=14):
        self.bank = bank
        self.n = n_cells
    def observe(self, obs):
        self.bank.add_step(obs["grid"], obs["depth"], obs["angles"], obs["pose"])
    def tokens(self):
        f, cell, side = self.bank.egocentric_map(self.pose, self.n)
        return {"map": aggregate(f, cell, self.n), "type": 2, "side": side}
    def memory_bytes(self):
        return sum(t.numel() * t.element_size() for t in self.bank.feats)

解读：（1）动作头只消费 tokens() 的类型标记与内容，四个后端可以互换而不改动作头，这是做受控对照的前提。（2）P1 在后端内部声明局部动作空间，P4 生成地图 token，动作空间差异对上层透明。（3）memory_bytes() 把三笔账里的内存项变成可记录指标，训练时按 episode 均值写日志，便于跨范式比较；真实实现还需处理批内长度不齐与无效填充。

片段 2：拓扑图更新与图感知注意力

import torch

def update_topo_map(nodes, edges, cur, nbrs, view_feat):
    # nodes: dict 节点标识 -> 特征；edges: 邻接表；cur 当前节点；nbrs 可达邻居
    nodes[cur] = view_feat["pano"].mean(0)          # 已访问节点：全景平均
    for v, emb in zip(nbrs, view_feat["dir"]):
        if v in nodes:                              # 可导航节点：累计部分观察
            nodes[v] = 0.5 * (nodes[v] + emb)
        else:
            nodes[v] = emb
    for v in nbrs:
        edges.setdefault(cur, set()).add(v)         # 记录无向连接
        edges.setdefault(v, set()).add(cur)
    return nodes, edges

def gasa(node_tokens, dist_matrix, w_e, b_e, attn):
    """DUET 的图感知注意力：在注意力分数上叠加距离偏置。"""
    bias = dist_matrix @ w_e + b_e                  # (K, K)
    return attn(node_tokens, bias=bias)

解读：（1）可导航节点可能被多个位置部分观察，用滑动平均累积，避免后见的观察完全覆盖先见观察。（2）GASA 把节点间距离写成可学习偏置加到注意力分数上，让近邻在没有视觉相似性时也有连接先验；消融显示它对 SPL 的贡献大于对 SR。（3）真实实现中节点标识由仿真器位姿生成，位姿噪声会导致同一节点分裂为多个标识，需要按距离阈值合并，这也是 P2 在真机场景的脆弱点。

片段 3：三笔账核算

D, B4, B2 = 768, 4, 2

state = D * B4                                   # P1 递归
print("P1 state", state, "B")                    # 3072 B
for t in (6, 15, 30):
    print("P1 HAMT hist t=%2d: %.1f KiB" % (t, (t + 1) * D * B4 / 1024))

for n in (20, 50, 100):                          # P2 拓扑
    print("P2 nodes=%3d: %.1f KiB" % (n, n * D * B4 / 1024))

for N in (11, 21, 31):                           # P3 度量图
    print("P3 map %2dx%2d: %.3f MiB" % (N, N, N * N * D * B4 / 2**20))

I = 12 * 7 * 7                                   # P4 网格：588 特征/步
for t in (10, 15, 30):
    print("P4 bank t=%2d: %.2f MiB" % (t, t * I * D * B4 / 2**20))

def cross(s, t, h=D):                            # 延迟代理：交叉注意力
    return 4 * s * h * h + 4 * t * h * h + 4 * s * t * h
print("P4/P3 map key cost", round(cross(37, 196) / 1e9, 2),
      round(cross(37, 441) / 1e9, 2))            # 0.57 / 1.18 GFLOPs

解读：（1）四类载体的内存量级从 KiB 跨到几十 MiB，选型前先算这一行，能直接排除不可行的方案。（2）延迟代理量只反映注意力内核，真实排序还会被地图重建、图规划与最短路查询改写；P4 的缓存机制（t = 30 时把相关性计算压到 1/15.5）属于实现层延迟，不体现在公式里。（3）把核算脚本与训练日志绑定，能让“记忆收益”与“记忆成本”在同一张表里呈现，这正是三笔账的用途。

常见坑

  • 跨协议直接相减：把 BEVBert 的 R2R-CE 59 / 50 与 GridMM 的 49 / 41 相减得出“网格落后 10 个点”的结论。根因：忽视航点预测器、迁移数据与训练管线差异。修复：只比较共用航点预测器的行，跨管线数字只做量级参照并写明差异来源。
  • seen 与 unseen 混报：P1 的 val seen 优势来自环境记忆，与泛化能力无关。根因：报告时只取最好看的 split。修复：所有主表成对给出 val seen 与 val unseen，跨 split 差值单列一栏。
  • 用 token 数代替延迟：P4 地图 token 只有 196 个，就推断它比 P3 快。根因：忽略每步投影、聚合与记忆库维护的开销。修复：延迟按“注意力加地图维护加执行”三段分别测量，缓存开关作为消融变量。
  • 把预训练收益记到记忆载体名下：BEVBert 从零到预训练有 +13.28 SR，这个增量来自 MLM 等目标与数据。根因：消融表把预训练与结构改动混排。修复：所有比较固定训练配方，或单列“从零训练”行作为基线。
  • 无深度平台照搬度量与网格：直接套用 P3、P4，坐标投影失效导致地图退化。根因：忽略载体对位姿与深度的依赖。修复：先做传感器可用性评估，无深度时退回 P2 并只使用视觉位姿图；若必须用度量图，改用单目深度估计并按 BEVBert 的估计深度口径验证鲁棒性。

练习与思考

  1. 按 t = 15、float32 实算四类范式的记忆占用：RecBERT 状态、HAMT 历史、DUET 50 节点、BEVBert 21×21、GridMM 记忆库，并把结果从小到大排序。 ★
    提示
    3 KiB、48 KiB、150 KiB、1.292 MiB、25.84 MiB。量级跨四个数量级，选型时先看这一列是否满足显存预算。
  2. BEVBert 论文给出 11×11、21×21、31×31 三种度量图的短期 transformer FLOPs 为 4.5 / 15.2 / 32.7 G。解释它近似随边长平方增长的原因，并说明为什么论文仍选 21×21。 ★
    提示
    自注意力序列长度为单元数 N²，评分次数随 N⁴，但单元嵌入维度固定且注意力之外的开销线性，综合近似平方。31×31 相对 21×21 FLOPs 翻倍而 SR 从 74.88 变 74.84，收益消失。
  3. 实现片段 1 的接口，把 P1 与 P4 两个后端接到同一动作头，在一条合成 episode 上分别输出动作分布，比较两者的候选数量、得分范围与停止概率，并解释差异来源。 ★★
    提示
    P1 候选 13 个、分数定义在视角上；P4 候选含全局节点、分数还含地图证据。比较前先确认两后端的动作空间声明，再对齐温度与掩码，否则分布不可比。
  4. 设计 R2R-CE 上的受控对照实验，比较 P2 与 P4 的记忆载体收益。要求：(a) 固定航点预测器、训练数据与微调流程；(b) 写出训练与评测配置；(c) 预测 SR、SPL、NE 的变化方向；(d) 说明如何分离缓存带来的延迟收益与载体本身的精度收益。 ★★
    提示
    (a) 两后端共享所有非记忆模块。(b) 同预训练权重、同步数上限、同贪心解码。(c) 预期 P4 在目标导向子集 SR 更高，SPL 因轨迹变长可能持平。(d) 缓存开关作为延迟维度单独消融，精度表在缓存固定为开时比较。
  5. 新任务设定：多层别墅、RGB-D 可用但深度噪声大、显存预算 2 GiB、要求全局回退与细粒度指代。用本讲的决策树给出载体选择与混合方案，写清每层地图或记忆的分工，估算 t = 30 时的内存并与预算对照；再设计一个消融实验，验证混合方案相对单一载体的收益。 ★★★
    提示
    建议分层：全局用 P2 拓扑保回退，楼内局部用 P3 度量图保短程推理，多楼层用楼层标识切分并维护楼间连接；GridMM 的记忆库在 2 GiB 预算下需 float16 并限制窗口。消融固定动作头与训练配方，比较“单拓扑”“拓扑加度量”“拓扑加度量加楼层切分”三档的 SR/SPL 与内存。

小结

  • 四类记忆载体可用统一式 mt = U(mt−1, ot) 与读取算子 Q 描述，差异集中在载体形态、更新方式与动作空间。
  • 三笔账：内存从 P1 的 3 KiB 到 P4 的 25.84 MiB（t = 15）跨四个数量级；延迟要用键值长度、注意力 FLOPs 与执行侧代价三段评估；精度必须带 split 与协议。
  • 目标导向任务的收益最陡：REVERIE val unseen 从 RecBERT 的 30.67 / 24.90 升到 BEVBert 的 51.78 / 36.37；R2R 在 036 至 038 间趋平；R2R-CE 跨管线数字不可直接相减。
  • 决策树顺序：任务类型、传感器条件、空间证据需求、预算；多楼层与无深度场景需要扩展，不能直接照搬。
  • 受控对照的原则：固定动作头与训练配方，只替换记忆后端；预训练与增广的收益单列，D 类与结构类收益分开记账。
  • 下一讲复盘第二篇：把增广线与地图预训练线两笔收益拆开，给出 seen→unseen 落差台账与实验设计模板（第 040 讲）。
