第四篇 · 规模、记忆与泛化方法论

第 068 讲｜全局拓扑与跨尺度推理

本讲把 DUET（Chen 等 2022，CVPR 2022，arXiv:2202.11742v1，任务：R2R / REVERIE / SOON）的在线拓扑方案当作一份“抽象层级与复杂度”的样本：36 个视角与 15 个物体先压缩为节点、再由节点构成全局动作空间，跨尺度注意力分别承担全局规划与当前全景接地。实算给出节点增长、注意力评分量、回退代价与规划开销的完整账目，并回答一个可判定的问题：地图增长到多大时，全局动作空间仍然划算。

  • 主题：拓扑抽象层级 / 跨尺度注意力 / 大场景效率 / 复杂度核算
  • 关键公式：Kt ≈ 1 + d·t；M = E We + be
  • 预计学时：60 分钟
  • 前置讲：第 067 讲（局部度量地图与预训练）

学习目标

  • 会算：节点规模 Kt、粗尺度与细尺度单步注意力评分量、回退 R 步相对全局一步的代价比、距离矩阵与最短路规划开销。
  • 会写：三类节点与坐标去重、GASA 距离偏置、局部分数升维与门控融合三段核心代码。
  • 会判断：全局动作空间的引入时机、地图规模预算、按 episode 步数与回退需求选择方案。
  • 会诊断：距离偏置取向错误、节点重复入图、已访问节点掩码遗漏、离线图与在线图漂移四类实现问题。

背景与动机

第 066 讲把记忆载体分成递归状态、显式历史、拓扑图与网格四类，其中拓扑图以稀疏结构和全局可达见长；第 067 讲把短程空间推理交给局部度量地图，并把它写进预训练。长程部分由谁承担？第 036 讲已经给出答案：DUET 在线构建拓扑图，把动作空间从当前节点的邻居扩展到图上全部已观测节点。那一讲以机制介绍与结果为主。本讲换一个视角，把同一方法拆成三个足以决定成败的设计量：信息从全景压缩到节点损失了什么、两路注意力的成本函数各自怎样增长、地图规模增长到什么程度时全局动作空间开始亏本。

这些问题在第四篇的方法论尺度下变得具体。规模上，地图类方法的能力随节点数上升，代价随节点数平方或立方上升；工程上，室内 episode 的步数上限把节点数限制在一个可核算的区间内。判断“值不值得全局化”需要三份账：信息账、注意力账与规划账。本讲的产出是一张跨尺度复杂度对比表与一套预算判据，并给第 069 讲的网格记忆留出接口。

本讲全部方法数字来自 DUET（Chen 等 2022，CVPR 2022，arXiv:2202.11742v1）与课程 036 讲口径；规模与代价数字先经 Python 实算，脚本逻辑见第 5 节片段 3。

核心原理

本讲按“抽象层级、规模增长、跨尺度注意力、全局动作空间、复杂度对比、边界”六步展开，所有数字标注来源与协议。

1. 三层抽象：视角、节点、图

导航观测在 DUET 中被组织成三层抽象，层与层之间的信息密度与作用范围逐级对调。

层级内容规模（课程口径）服务对象损失
视角层当前全景的视图特征与物体特征36 视图 + 15 物体 + 1 停止 token细尺度编码与物体接地无压缩，只覆盖当前节点
节点层压缩特征 + 位置嵌入 + 步序嵌入每节点 768 维（已访问、当前、边界三类）图推理的输入 token视图级细节被池化
图层节点、边、stop 节点、成对距离Kt 个节点，Kt(Kt−1)/2 个距离条目全局动作空间与 GASA节点内部空间关系不可见

节点表示分两档：已访问节点与当前节点持有完整全景，取全景自注意力输出的平均向量；边界节点（navigable，从已访问位置观察到但未探索）只被部分观测，把多次观测的视图嵌入取平均累积。同一物理位置可能被多次观测，必须按坐标匹配阈值合并为一个节点。图另加零向量 stop 节点，与所有节点相连，停止动作由此进入同一打分空间。抽象层级的判据是“这一层要回答什么问题”：视角层回答“指令里的物体在哪里”，图层回答“下一步去哪个已观测位置”。

2. 规模增长：节点数的估计式

设导航图平均度为 d，课程 001 与 036 讲采用 MP3D 单场景口径 d = 4.1。第 t 步后已访问节点与当前节点合计 t + 1 个，每步新观察到最多 d − 1 个边界节点，于是节点数上界为

Kt ≤ (t + 1) + (d − 1)·t = 1 + d·t d 为导航图平均度（课程口径 4.1）；Kt 为第 t 步可观测子图节点数上界；真实值受去重效果与重复观测影响

实算扫描 t = 6 至 40：Kt 依次为 25.6、42.0、62.5、83.0、124.0、165.0；对应节点特征内存 76.8、126.0、187.5、249.0、372.0、495.0 KiB（768 维 float32）；GASA 使用的距离矩阵内存 2.6、6.9、15.3、26.9、60.1、106.3 KiB。节点层与图层的内存都在百 KiB 量级，真正随规模失控的是注意力与规划的计算量，下一节和第 4 节分别核算。

3. 跨尺度注意力：两种成本函数

细尺度编码器只处理当前节点：把停止 token、36 个视图特征与 15 个物体特征拼成 52 个 token 的视觉序列，与长度 L = 80 的指令做交叉注意力并保留一层自注意力。按“自注意力平方项加两倍交叉注意力项”的课程口径，单步评分量为

Cfine = (36 + 15 + 1)2 + 2 × 52 × 80 = 2,704 + 8,320 = 11,024 36 为全景视图数，15 为物体特征数，1 为停止 token，80 为指令长度；评分量指注意力权重元素个数，用于跨方案比较

粗尺度编码器把地图节点当作 token，与指令做跨模态融合，其自注意力改为图感知自注意力（Graph-Aware Self-Attention, GASA）：在注意力 logits 上加入由图上成对距离生成的偏置，使注意力同时考虑内容相似度与空间邻近性。

GASA(X) = Softmax( X Wq (X Wk)T / √d + M ) X Wv，M = E We + be X 为节点表示序列；E 为从在线图边集得到的成对距离矩阵；We 与 be 为可学习参数；偏置在 Softmax 之前与内容相似度相加

用三个节点的数值例说明方向（实算）：内容相似度 logits 为 [0.1, 0.3, 0.6]，对应图上距离 [0, 1, 4]。不加偏置时 softmax 为 [0.2584, 0.3156, 0.4260]，内容相似度最高的远端节点胜出；取 We = −0.2 时权重变为 [0.3649, 0.3649, 0.2703]，远端节点退到末位；取 We = −0.8 时进一步变为 [0.6188, 0.3396, 0.0416]，注意力几乎锁定最近节点。We 的实际取值由训练学习：绝对值越小，内容信号占比越高；绝对值越大，空间邻近性的影响越强。这条尺度由损失自动校准，但训练初期给过大的初值会让内容梯度难以进入注意力。

粗尺度单步评分量为 Ccoarse = (Kt + 1)2 + 2(Kt + 1) × 80，实算 t = 6、10、15、20、30、40 依次为 4,963.6、8,729、14,192.2、20,496、35,625、54,116。两个尺度在 t = 10 附近量级相当，此后粗尺度按节点数平方增长，超过细尺度的固定值。

4. 全局动作空间：把回退从多步压成一步

局部动作空间在迷路后回退 R 步需要运行 R 次模型，每次都要重走细尺度编码，代价 R × 11,024 评分量；全局动作空间把“去哪个已观测节点”变成一次选择，选完由最短路展开逐边执行。按 R = 5 实算，两者比值随 t 变化：

按 d = 4.1、R = 5 的口径解不等式 5 × 11,024 ≤ (K + 1)2 + 160(K + 1)，得到 K ≈ 167，对应 t ≈ 40.5 步，即约 40 步附近两者持平。结论一：回退需求的相对收益随地图增长递减，地图变大后的单步推理成本单调上升；在室内 episode 的常见步数范围内，全局方案仍处在单步成本可接受的一侧。

再看整段 episode 的累计账（每步一次全局选择，对照每步一次细尺度前向）：T = 10 时累计粗尺度为 46,694，比值 0.424；T = 20 时为 195,929，比值 0.889；T = 22 时比值 0.994，T = 23 时 1.048，T = 30 时 1.455。结论二：以约 22 步为界，更短的 episode 里全局方案在纯注意力开销上也不亏；更长的 episode 依靠“一次选择省下的多次回退”回本。

三点读法。第一，全局方案的候选数从 5.1 涨到 166，增长来源是地图展开；局部方案的候选数固定，代价转移到回退次数上。第二，距离矩阵与成对距离条目随 K2 增长（t = 10、20、30 时为 861、3,403、7,626 对），GASA 每层都要用到它。第三，Floyd 全源最短路为 O(K3)：t = 20 的 57.2 万次运算仍低于注意力主项，t = 40 的 449 万次已经与注意力主项可比，工程上应换成增量式或单源 Dijkstra。结论三：地图规模的中段（数十节点）三类开销都处于同一量级；规模上探时先变得难以承受的是规划项与距离矩阵内存。

6. 结果证据与适用边界

DUET 的结果回放（来源：Chen 等 2022，表与附录；与 036 讲口径一致）：R2R test unseen 69 SR / 59 SPL；REVERIE test unseen 52.51 SR / 22.06 RGSPL，相对 HAMT 提升 22.11 与 8.98；SOON test unseen 33.44 SR / 21.42 SPL。回溯比例（附录 C.2）：REVERIE val seen 13.7%、val unseen 48.6%、R2R val unseen 23.2%，说明全局动作空间主要服务于未见环境中的纠错。GASA 消融（REVERIE val unseen）：去掉图结构偏置从 46.98 / 33.73 降到 45.24 / 32.88，SR 的下降幅度大于 SPL（1.74 对 0.85）。

边界与失效模式：

  • 离散协议限定：节点与连通关系来自仿真器导航图；连续环境需要先有路点与连通修正，第三章的方案才能衔接。
  • 节点表示密度有限：粗尺度节点的池化特征丢失视图细节，需要细尺度分支补偿；关掉细尺度后停止判定与物体接地同步变差。
  • 去重误差会同时污染两处：重复节点让动作空间与 GASA 距离矩阵一起失真，长 episode 下错误累积。
  • 规划开销的低估：每步重算 Floyd 的账在 t = 40 时已与注意力可比，真机或城市级场景需要分层抽象或增量规划。
  • 指标口径：R2R 上 DUET 的 SR 高于 HAMT，SPL 略低，地图鼓励回退使轨迹变长；跨数据集不可拼表，报告需标注 split 与步数上限。

设计决策：全局化的两条判据

引入全局动作空间之前先回答两个问题。第一，回退需求有多强：REVERIE 一类目标导向任务在未见环境的回溯比例达 48.6%，全局纠错的价值高；R2R 的逐步指令回溯比例 23.2%，收益相对小。第二，地图规模在预算内吗：按第三节的评分量与第四节的拐点，数十节点规模内注意力、距离矩阵、规划三项都处于同一量级，可以同时开启；上百节点后应引入增量规划与分层抽象，或把全局分支改为按需激活。两条判据都通过时，全局方案以“可调用的纠错能力”换取可核对的额外开销；任一不通过时，回到局部动作空间并接受回退的多步代价。

与相邻讲的分工：第 036 讲介绍 DUET 的机制与结果，本讲把同一方法展开为抽象层级与复杂度账；第 067 讲的局部度量地图补足节点内部的短程空间关系；第 069 讲的网格记忆用固定 token 数的地图控制全局证据的代价，本讲的三角账（注意力、距离矩阵、规划）在那里换成另一组三角账（内存、延迟、精度）。

关键代码与解读

三段代码分别给出拓扑图去重与状态维护、GASA 与评分量核算、规模扫描实算。数字与本讲正文一致，可直接作为验收断言的实现骨架。

片段 1：图更新与节点数估计

import math

class TopoGraph:
    """DUET 风格在线拓扑图：坐标去重、三类节点与规模统计。"""
    def __init__(self, pos_tol=0.5):
        self.nodes = {}          # 键 -> {"pos": (x, y), "type": 类型}
        self.pos_tol = pos_tol   # 匹配阈值：过小重复建点，过大误合并

    def key_of(self, xy):
        for k, nd in self.nodes.items():
            if math.dist(xy, nd["pos"]) < self.pos_tol:
                return k                     # 命中已有节点，复用键
        return "n%d" % len(self.nodes)       # 新位置分配新键

    def observe(self, xy, navigable_xy):
        cur = self.key_of(xy)
        self.nodes[cur] = {"pos": xy, "type": "cur"}
        for nxy in navigable_xy:
            nb = self.key_of(nxy)
            if nb not in self.nodes:                       # 首次观测登记为边界节点
                self.nodes[nb] = {"pos": nxy, "type": "nav"}
        return cur

    @staticmethod
    def scale_estimate(step, degree=4.1):
        k = 1 + degree * step            # 已访问 + 边界节点上界
        return k, k * (k - 1) / 2        # 节点数与成对距离条目

# 实算：t = 20 时 k = 83.0，成对距离 3,403 条

解读：（1）去重阈值是全流程最敏感的参数，它同时决定动作空间规模与距离矩阵质量；工程上应记录每步“命中已有节点”与“新建节点”的比例，比例异常意味着阈值失配。（2）三类节点用类型字段区分，当前节点在下一步自动转为已访问，边界节点支持多次观测累积。（3）scale_estimate 给出的是上界，用于预算与告警；真实节点数从图的长度直接读取，二者持续对照可以尽早发现去重失效。

片段 2：GASA 偏置与评分量核算

import math

def softmax(xs):
    m = max(xs)
    es = [math.exp(x - m) for x in xs]
    s = sum(es)
    return [e / s for e in es]

def gasa_demo(logits, dist, we, be=0.0):
    """把成对距离偏置加到内容相似度 logits 上，返回归一化权重。"""
    biased = [l + we * d + be for l, d in zip(logits, dist)]
    return biased, softmax(biased)

def step_scores(k_nodes, n_views=36, m_obj=15, ins_len=80):
    """粗尺度（地图节点）与细尺度（当前全景）的单步评分量。"""
    vis = n_views + m_obj + 1                 # 停止 token 计入视觉序列
    fine = vis ** 2 + 2 * vis * ins_len
    coarse = (k_nodes + 1) ** 2 + 2 * (k_nodes + 1) * ins_len
    return coarse, fine

print(gasa_demo([0.1, 0.3, 0.6], [0, 1, 4], -0.2))
# 偏置 [0.1, 0.1, -0.2]，权重 [0.3649, 0.3649, 0.2703]
print(gasa_demo([0.1, 0.3, 0.6], [0, 1, 4], -0.8))
# 偏置 [0.1, -0.5, -2.6]，权重 [0.6188, 0.3396, 0.0416]
print(step_scores(42.0), step_scores(83.0))   # (8729.0, 11024) 与 (20496.0, 11024)

解读：（1）偏置在 Softmax 之前加入，与多头注意力兼容：每个头可学习各自的 We，得到不同强度的空间先验。（2）示例刻意取“远端节点内容相似度最高”的输入，用来观察偏置如何反转选择；真实训练中 We 学到的是连续取值，示例中的两个档位只用于展示方向。（3）step_scores 把两路成本函数放在同一单位下，任一实现改动（视图数、指令长度、节点数）都能即时重算预算。

片段 3：规模扫描与拐点实算

DEG, L, FINE = 4.1, 80, 11024

for t in (6, 10, 15, 20, 30, 40):
    k = 1 + DEG * t
    coarse = (k + 1) ** 2 + 2 * (k + 1) * L
    dist_kib = k * k * 4 / 1024            # 距离矩阵，float32
    floyd = k ** 3                          # 每次重算最短路的基本运算次数
    print(t, round(k, 1), round(coarse), round(5 * FINE / coarse, 2),
          round(dist_kib, 1), round(floyd))

# 累计账：每步一次全局选择，对照每步一次细尺度前向
for T in (10, 20, 22, 23, 30):
    total = sum((1 + DEG * t + 1) ** 2 + 2 * (1 + DEG * t + 1) * L
                for t in range(1, T + 1))
    print(T, round(total), round(total / (T * FINE), 3))
# 拐点：T = 22 比值 0.994，T = 23 比值 1.048

解读：（1）回退 5 步的比值从 t = 6 的 11.10 降到 t = 40 的 1.02，说明全局化的相对优势在短 episode 上最明显。（2）距离矩阵内存增长温和，Floyd 项增长最快，t = 40 的 449 万次已经与注意力主项可比，应改用增量或单源方案。（3）累计比值在 T = 22 附近越过 1，这条曲线与数据集的平均 episode 长度对照，就能判断全局分支的开销是否处在预算之内。

常见坑

  • 距离偏置取向或量级错误：注意力被空间项完全主导，指标接近“只走最近点”的贪心策略。根因：We 初值过大或符号写反，且训练集偏短时损失无法纠正。修复：初始化为小负值，训练日志中记录偏置项与内容项的方差比；用合成样例单测“远端高相似度节点应被抑制但不消失”。
  • 节点重复或者分裂：动作空间出现多个近邻候选，距离矩阵条目虚增，指标随 episode 变长下降。根因：坐标匹配阈值失配，或里程计与真值坐标混用。修复：统一坐标来源，扫描阈值并报告节点数与真值图的偏差，每步记录新建节点数。
  • 已访问节点未掩码：智能体在图上反复横跳，TL 明显高于对照。根因：全局分数保留了历史节点。修复：按任务口径掩掉已访问节点，只保留 stop 与边界节点；需要重访的任务单独配置并在报告中注明。
  • 规划每步全量重算：地图不大时无感，t 超过 30 后单步延迟跳升。根因：Floyd 的 O(K3) 每次从头计算。修复：改用单源 Dijkstra 只求目标节点路径，或增量维护距离矩阵；把规划项列入部署预算监控。
  • 离线图与在线图分布漂移：预训练指标正常，在线微调偏低。根因：预训练按完整专家轨迹构图，在线按实际前缀构图，节点类型与步序分布不同。修复：预训练也从轨迹前缀随机截断构图，两处共用同一份建图代码。

练习与思考

  1. 按 d = 4.1 的口径计算 t = 25 时的节点数估计、粗尺度单步评分量与“回退 5 步 / 全局一步”的比值，并判断此时全局方案在单步推理上是否仍然划算。 ★
    提示
    K = 1 + 4.1 × 25 = 103.5；粗尺度为 (104.5)2 + 2 × 104.5 × 80 = 10,920.25 + 16,720 = 27,640.25；比值为 55,120 / 27,640.25 ≈ 1.99。按单步推理仍划算，距离约 40 步的持平点还有约 15 步余量。
  2. 复算 GASA 数值例：logits 取 [0.2, 0.4, 0.9]，距离取 [0, 1, 4]，We = −0.5。写出偏置后的 logits 与 softmax 权重，并解释三节点权重的相对次序与 We = −0.8 时不同的原因。 ★
    提示
    偏置后 logits 为 [0.2, −0.1, −1.1]，softmax 为 [0.4967, 0.3680, 0.1354]。中等强度的偏置压住了远端节点但未压死：距离 0 与 1 的两个节点权重接近，内容相似度的差异仍可见；We = −0.8 时距离项更强，权重会进一步向最近节点集中。
  3. 用本讲的成本模型推导两个拐点：(a) 固定 R = 5，求单步比值降到 1 的节点数 K 与步数 t；(b) 固定每步一次全局选择，求累计比值越过 1 的 episode 长度 T。写出不等式并说明两个拐点分别对应什么工程决策。 ★★
    提示
    (a) 解 (K + 1)2 + 160(K + 1) ≤ 55,120，得 K + 1 ≈ 168，K ≈ 167，t ≈ (167 − 1) / 4.1 ≈ 40.5 步。(b) 累计实算在 T = 22 时比值 0.994、T = 23 时 1.048，越过点在 22 与 23 之间。拐点 (a) 指导“是否开启全局分支”，拐点 (b) 指导“按数据集平均长度选择方案并预留回退预算”。
  4. 设计 GASA 的等参数对照实验：构造一个不含距离输入的替代分支，使其参数量与 GASA 相同，用于区分“图结构收益”与“参数量收益”。要求写出替代分支的结构、固定变量、评价指标与判定标准。 ★★
    提示
    替代分支可在注意力 logits 上加同形状的 token 对偏置（K × K 可学习矩阵），输入不含图距离。固定骨干、数据、训练预算与随机种子，只替换偏置来源；若 GASA 仍显著提升 SPL（论文口径 32.88 到 33.73），收益可归因于图结构，否则主要来自额外参数。
  5. 预算设计：设单层注意力算力按 8nh2 + 4n2h 估算（n 为节点数、h = 768），四层编码器每步预算上限取 2 GFLOPs。求可支持的最大节点数 K 与对应步数 t；再说明超过该规模时两种降本路径（分层抽象与按需激活）各自改变哪一项复杂度，以及验证降本有效性的实验设计。 ★★★
    提示
    单层预算 0.5 GFLOPs，解 4n2h + 8nh2 ≤ 5 × 108，得 n ≈ 99.5，K ≈ 98，t ≈ 23.8；实算参考：n = 84 时四层约 1.67 GFLOPs，n = 166 时约 3.47 GFLOPs。分层抽象把 n 降到区域节点数，直接压低平方项；按需激活把全局分支的调用频率降低，单次成本不变。验证实验固定成功率目标，报告每步延迟、峰值显存与 SPL，比较两种路径在同一预算下的达成情况。

小结

  • 抽象分三层：视角层（36 视图 + 15 物体）、节点层（768 维压缩表示，三类状态）、图层（节点、边、stop 与成对距离）；层间交换的是信息密度与作用范围。
  • 规模估计式 Kt ≈ 1 + d·t（d = 4.1）；t = 20 时约 83 个节点、3,403 条成对距离；节点与距离矩阵内存处于百 KiB 量级。
  • 跨尺度成本：细尺度单步固定 11,024 评分量；粗尺度 (K+1)2 + 160(K+1)，t = 20 为 20,496，t = 40 为 54,116。
  • 回退 5 步相对全局一步的比值从 t = 6 的 11.10 降到 t = 40 的 1.02；累计比值在约 T = 22 步越过 1，工程上以平均 episode 长度对照该拐点。
  • GASA 数值例显示距离偏置可以在 Softmax 前反转选择（远端节点权重从 0.4260 降到 0.0416），强度由 We 控制，属可学习尺度。
  • 结果（来源：DUET 论文与 036 讲口径）：R2R test unseen 69 / 59；REVERIE test unseen 52.51 / 22.06；回退需求集中出现在未见环境。下一讲进入网格记忆，讨论动态更新、指令相关性聚合与分辨率选择（第 069 讲）。
