第二篇 · 离散方法谱系：从模块到预训练

第 026 讲｜SIL：自监督模仿学习

在没有演示轨迹、没有目标位置的未见环境里，智能体用匹配评论家（matching critic）给自己的多条候选轨迹打分，挑出最好的一条当作伪标签（pseudo-label）再模仿更新。本讲拆解 SIL（Self-Supervised Imitation Learning，自监督模仿学习）的目标函数、伪轨迹生成流程与选择偏差，并核对 R2R 上的收益与协议边界。

  • 主题：离散方法 / 自监督模仿 / 伪标签 / 探索
  • 关键公式：Lsil = −Rintr log πθ(at|st)，τ̂ = argmaxτ Vβ(X, τ)
  • 预计学时：60 分钟
  • 前置讲：第 025 讲（RCM：强化跨模态匹配）

学习目标

  • 说清 SIL 的问题定位：在无标注、无目标位置的未见环境里，用评论家分数从自身多条 rollout 中选出伪轨迹；复述论文报告的 seen-unseen 成功率差距收窄结果（30.7% 到 11.7%，Wang 等，2019，R2R 验证集）。
  • 推导 SIL 目标函数：从「回报加权的策略梯度」写到「伪标签交叉熵」，说清两种写法等价的条件与差别。
  • 会算：指令长度归一化对跨指令可比性的影响；取 K 条候选最大值的期望选择偏差；一轮 SIL 的采样步数预算。
  • 会实现：采样多条轨迹、评论家打分、回放缓冲、模仿更新四步闭环，并正确处理停止动作与步数上限。
  • 会判断：SIL 与 beam search、自模仿学习的异同，以及标准评测协议与预探索协议的数字为何不能混用。

背景与动机

第 025 讲把 RCM 的全局与局部跨模态匹配讲完了：回环重建奖励充当内在奖励，引导策略让整条轨迹与指令对齐。这套方法在已见环境训练，然后零样本迁移到未见环境。Wang 等（2019）的原文报告了一个持续存在的现象：未见环境的成功率明显低于已见环境，泛化仍是主要矛盾。

难点在于监督缺口。未见环境既没有人类演示轨迹，也没有目标位置，行为克隆（behavior cloning）无从下手；纯强化学习又只能拿到稀疏的成功信号，长轨迹上的信用分配效率低。论文提出的场景是「测试前允许探索」：智能体抵达新环境后先自行探索，把过去的好决策沉淀为监督，再执行指令。家用机器人在新居先熟悉环境、再按指令取物，正是这个场景的现实动机。

SIL 的思路是把「探索数据」和「伪监督」接起来：策略采样多条候选轨迹，评论家给每条轨迹与指令的匹配度打分，分数最高的一条进入回放缓冲（replay buffer），下一轮更新时被当作演示来模仿。整个过程中没有外部目标位置参与，监督信号完全来自自监督打分器，这也是方法名中 self-supervised 的含义。

本讲要解决四件事：第一，写清 SIL 目标的两种等价形式与适用条件；第二，算清长度归一化与最大选择偏差带来的影响；第三，给出可实现的伪轨迹生成流程；第四，界定它的协议边界，避免把预探索数字与标准零样本榜单直接对比。

核心原理

1. 设定与监督缺口

沿用第 025 讲的记号：指令 X = <x1, x2, …, xn>，n 为词数；策略 πθ(at|st) 在状态 st 输出可导航方向的分布；一条轨迹 τ = <(s1, a1), (s2, a2), …, (sT, aT)>。RCM 阶段已经训练出一个可用的策略与一个匹配评论家 Vβ，评论家把轨迹编码后自回归地重建指令，输出 pβ(X|τ)。

SIL 阶段的输入只有 (X, 起点) 与一个没有标注的探索环境。目标位置 s* 不可见，演示动作 at* 不存在，成功与否也无法在探索时判定。整个监督缺口由评论家填补：它给候选轨迹排序，排序靠前的轨迹携带「与指令语义一致」的信号。

关键约定：评论家预训练后冻结

论文用人类演示对评论家做监督预训练，在策略学习与 SIL 阶段保持参数冻结。冻结的意义在下一节展开：它保证伪标签的评判标准不随策略漂移，也让 SIL 损失中的回报项与策略参数解耦。

2. 评论家打分与长度归一化

评论家输出的是指令在给定轨迹下的似然。把逐词概率连乘写成对数域求和：

log pβ(X|τ) = Σi=1n log pβ(xi | x<i, τ) x<i 表示第 i 个词之前的词序列；轨迹 τ 经轨迹编码器压缩为条件向量

论文报告内在回报 Rintr 时按指令长度 n 做归一化。归一化的作用需要精确表述：对同一条指令的 K 条候选轨迹，n 完全相同，排序不受影响；跨指令比较时，长指令的词数多，未归一化的对数似然天然更低，批次内不同指令的回报尺度因此不可比。归一化让不同长度的指令进入同一个尺度，这对批次内混合计算的 RL 与 SIL 目标都必要。

一个典型量级：29 词指令、每词平均对数概率 −0.9 时，总和对数似然为 −26.1，几何平均约 0.4066。评论家分数既不接近 0 也不接近 1，说明它在训练分布上给出的匹配概率是中间值，伪标签之间靠相对排序区分。

3. 伪轨迹生成与选择偏差

SIL 的每一次伪标签生成分三步。第一步，对同一条指令从当前策略采样 K 条轨迹；第二步，用冻结的评论家给每条轨迹计算 Rintr；第三步，取分数最高的轨迹写入回放缓冲：

τ̂ = argmaxτ ∈ {τ(1), …, τ(K)} Vβ(X, τ) K 为候选条数；论文只说明「多次 rollout」，未给出公开的 K 默认值，工程上按算力预算取 3 到 10

这里存在一个必须量化的问题：取 K 条候选的最大值，会系统性高估策略的真实水平。把每条候选的评论家分数看成「真实匹配度 + 独立噪声」，当噪声近似标准正态时，K 条最大值的期望如下（蒙特卡洛实算，200 万样本）：

K1351020
E[max]（单位：噪声标准差）0.000.851.161.541.87

读法：K 从 1 增到 5，伪标签分数平均抬高约 1.16 个噪声标准差；K 增到 10 抬高约 1.54 个标准差。K 的作用是「用算力换监督质量」，代价是噪声也被放大。三条缓解手段在论文设计中都能找到对应：评论家冻结防止评判标准漂移；SIL 与已有监督数据配合使用，让伪标签只占更新的一部分；探索范围限定在无标注的未见环境，不覆盖评测指令的目标位置。

采样必须保证多样性。若 rollout 用贪心解码，K 条候选完全相同，argmax 失去区分度，伪标签退化为当前策略的复制。论文在训练期使用类别采样（categorical sampling），本讲代码沿用这一约定，并允许在需要时调整采样温度。

4. SIL 目标与等价推导

选出 τ̂ 后，论文给出两种写法。第一种把评论家分数当作回报，对整条轨迹加权：

Lsil(θ) = − Rintr log πθ(at|st) Rintr = Vβ(X, τ̂)，与 θ 无关（评论家冻结）；乘在同一轨迹所有步的梯度上

第二种把 τ̂ 的动作当作标签，做交叉熵：

Lsil(θ) = − E[ log πθ(ât|st) ]，ât 为回放缓冲中 τ̂ 的第 t 步动作 期望对回放缓冲中的 (st, ât) 样本取

等价条件：Rintr 不依赖 θ 且为正常数时，第一式对每条轨迹是第二式的常数倍；常数不改变梯度方向，只改变步长尺度。回报为负时结论反转，这也是上一节强调回报取正数的原因。

从策略梯度看，第一式正是 REINFORCE 形式：∇θ L = −Rintr ∇θ log πθ(at|st)。与标准在策略（on-policy）算法相比，这里的轨迹由旧策略采样、存在回放缓冲里，更新时属于离策略（off-policy）蒙特卡洛回报。论文没有引入重要性权重修正，把选出的轨迹直接当演示，属于自模仿式的简化。当两轮之间策略变化过大时，旧伪标签与当前策略的分布偏离增大，更新偏差随之上升，这是该方法的一条边界。

自模仿学习（self-imitation learning）的一般结论在此适用：当采样回报高于当前策略的期望水平时，提高这些动作的概率可在局部改进策略。SIL 用评论家替代环境回报完成筛选，把该思想迁移到没有目标信号的导航任务。

5. 有效性证据与协议边界

论文在 R2R 上报告了两组结果。验证集上，去掉跨模态推理的消融行 seen / unseen 成功率为 66.4% / 35.7%，差距 30.7 个百分点；加入 SIL 在未见环境探索后为 73.0% / 61.3%，差距 11.7 个百分点。差距收窄 19.0 个百分点，相对降幅 61.9%（实算）。

读法有三点。第一，训练集上的 SIL 主要买效率：路径长度从 15.22 米降到 11.97 米（−3.25 米，−21.4%），SPL 从 35 升到 38，成功率持平。它把「走对」改造成「更短地走对」，这正是 SPL 关注的性质。第二，未见环境探索把收益放大：相对训练集 SIL，路径再降 2.49 米（−20.8%），成功率升 17.5 个百分点，SPL 升 21 点；相对 RCM 基线，路径降 5.74 米（−37.7%）。第三，两类收益的性质不同：训练集 SIL 定义在标准协议内，可以直接与榜单比较；未见环境 SIL 属于终身学习场景，只能与同协议数字对比。

停止行为的监督缺口值得单独指出。评论家只评价指令与轨迹的语义匹配，不判断是否到达目标。论文的定性例子给出了反例：某条轨迹的回环奖励很高，大部分动作与指令一致，但智能体最终没有认出洗衣房，没能停到正确位置。这解释了为什么 SIL 在预探索协议下成功率仍明显低于已见环境：到达目标与对齐指令是两件事，后者可以用自监督逼近，前者在无目标位置时缺少监督信号。

6. 与 beam search 的机制差异

同为「多轨迹、选最优」，SIL 与 beam search 的落点不同。beam search 在测试时执行多条轨迹，按累计概率重排，选出得分最高的整条路径作为预测；它不更新参数，改进是一次性的，且执行多条轨迹导致路径长度剧增，SPL 被重罚。SIL 在训练时用最优伪轨迹更新参数，收益固化到权重里，测试时按更新后的策略执行单条轨迹，路径更短。论文的对照给出了数量级：Speaker-Follower 加 beam search 在测试集上 SR 53.5%，路径长度 1257.38 米，SPL 0.01；Regretful Agent 用贪心加回溯达到 SR 48%、SPL 0.40（Ma 等，2019，表 1 与表 5；该对照在 027 讲展开）。这说明「测试时搜索」与「训练时改进策略」是两条不同的性能曲线。

关键代码与解读

以下片段以论文方法与公开实现的接口习惯为参照，接口命名随版本演进，重点是机制，具体 API 只作示意。三个片段依次覆盖采样、选择与更新。

片段 1：K 条候选轨迹采样

def sample_trajectories(policy, env, instr, K=5, max_steps=20, greedy=False):
    # max_steps 取 R2R 离散协议上限 20（第 005、006 讲已核对仓库 max_episode_len 口径）
    trajs = []
    for _ in range(K):
        env.reset(instr["scan"], instr["path"][0], instr["heading"])
        actions, feats, done = [], [], False
        while not done and len(actions) < max_steps:
            p = policy(instr["tokens"], feats, actions)      # 当前步可导航方向的概率
            if greedy:
                a = int(p.argmax())                          # 诊断用：会退化候选多样性
            else:
                a = int(torch.multinomial(p, 1))             # 类别采样，保证 K 条轨迹互不相同
            feats_new, _, done = env.step(a)
            actions.append(a)
            feats.append(feats_new)
        trajs.append({"instr_id": instr["instr_id"], "actions": actions, "feats": feats})
    return trajs

解读：（1）环境复位到同一条指令的起点，保证 K 条候选可比；若起点随机化，评论家分数混入位置差异。（2）训练期采用类别采样，这是候选多样性的来源；贪心分支仅用于对照实验，执行时会出现 K 条完全相同的序列。（3）「到停止或步数上限」两个终止条件都要保留，否则与评测口径不一致，统计出的伪标签长度分布也会失真。（4）缓存每步全景特征，为片段 3 的特征重放做准备；若改用重跑环境，可只保留动作序列。

def select_pseudo_trajectory(critic, instr, trajs, topk=1):
    # 评论家冻结，只做前向；输出逐词对数概率之和
    scored = []
    for t in trajs:
        logp = critic.log_prob(instr["tokens"], t["actions"])       # 轨迹条件似然，log 域
        n = max(len(instr["tokens"]), 1)
        score = float(torch.exp(logp / n))                          # 几何平均，落在 (0, 1]
        scored.append((score, t))
    scored.sort(key=lambda x: x[0], reverse=True)
    picked = [t for _, t in scored[:topk]]                          # 默认取最优一条
    best = scored[0][0]
    mean = sum(s for s, _ in scored) / len(scored)
    return picked, {"best": best, "mean": mean, "gap": best - mean}

解读：（1）按词数归一化用几何平均实现，分数落在 (0, 1]，可直接作为正回报；它与词均对数概率排序等价，数值上更适合乘进损失。（2）返回最优分与候选均值的差，作为选择偏差的在线监控量；差值长期偏大说明候选噪声大或 K 过大。（3）topk 参数为扩展设计（多选伪轨迹按分数加权），论文默认取最优一条，扩展时需处理重复轨迹。（4）评论家冻结在训练脚本层面由 requires_grad 关闭与优化器不注册双重保证，防止误更新。

片段 3：伪标签模仿更新

def sil_update(policy, optimizer, pseudo, critic_score, max_grad=5.0):
    # 把伪轨迹动作当标签；critic_score 与策略参数无关，作为整条轨迹的正权重
    loss = torch.zeros((), device=next(policy.parameters()).device)
    for t, a_hat in enumerate(pseudo["actions"]):
        p = policy(pseudo["tokens"], pseudo["feats"][t], pseudo["actions"][:t])
        loss = loss - critic_score * torch.log(p[a_hat] + 1e-8)     # 回报加权的伪标签交叉熵
    optimizer.zero_grad()
    loss.backward()
    torch.nn.utils.clip_grad_norm_(policy.parameters(), max_grad)   # 防止单条伪标签把参数带偏
    optimizer.step()
    return float(loss.detach())

解读：（1）损失是片段 2 的几何平均分数乘以负对数似然；常数权重只缩放梯度，不改变方向，与纯交叉熵写法在固定评论家下等价。（2）每步的状态特征与历史动作从回放缓冲读取，保证标签与输入对齐；若重跑环境，此处的 feats 改为在线重新编码。（3）梯度裁剪是工程护栏：K 较大时最优候选的分数可能显著高于均值，单条伪轨迹的梯度尺度相应偏大。（4）学习率保持 1e-5，与 RL 阶段一致；伪标签更新属于离策略数据，步长过大会让旧标签迅速失效。

常见坑

  • 把 SIL 当作普通行为克隆再训练：伪标签未经筛选直接使用，指标先升后降。根因：自身轨迹的错误动作被当成标签，误差在轮次间累积。修复：按评论家归一化分数取 argmax（或分位数筛选），限制轮数并配合早停。
  • 评论家与策略联合更新：训练中期伪标签质量突然波动，成功率曲线出现台阶。根因：评判标准随策略一起漂移，评论家输出不再对应演示分布。修复：SIL 阶段冻结评论家；若要更新，采用低频快照并保留历史版本做一致性检查。
  • rollout 使用贪心解码：K 条候选几乎相同，argmax 选择退化为复制当前策略，SIL 贡献接近 0。根因：缺少采样噪声，候选集合没有覆盖策略分布的尾部。修复：训练期使用类别采样或带温度采样，并监控候选两两之间的动作序列差异率。
  • 回报不按长度归一化：长指令的伪标签被系统性压低，批次内短指令垄断更新。根因：对数似然随词数单调下降，跨指令尺度不可比。修复：统一使用词均对数概率或几何平均；同一条指令内部无需归一化，排序本来就不变。
  • 把预探索数字与标准榜单混用：用 60.5% 的成功率宣称超过零样本方法。根因：SIL 在未见环境探索属于不同评测协议，论文脚注已声明不可直接比较。修复：表格分栏标注标准协议与预探索协议，引用数字时写明环境是否在测试前被探索。

练习与思考

  1. 指令 A 为 12 词、逐词平均概率 0.35，指令 B 为 30 词、逐词平均概率 0.45。分别计算不归一化与词均归一化下的分数，并说明归一化在「同一条指令内部排序」与「跨指令比较」两种场景中的作用差别。★
    提示
    不归一化：A 为 12 × ln 0.35 ≈ −12.60，B 为 30 × ln 0.45 ≈ −23.96，A 占优；词均归一化后 A 为 −1.0498，B 为 −0.7985，B 占优。同一条指令的候选词数相同，归一化不改变排序；跨指令时它消除词数带来的尺度差。
  2. 写出 SIL 的回报加权形式与伪标签交叉熵形式，证明二者在评论家冻结时只差一个正常数因子，并说明回报为负时会发生什么。★
    提示
    Rintr 与 θ 无关时，L = −Rintr log π 的梯度方向与 L = −log π 相同，尺度相差 Rintr；若 Rintr 为负，梯度方向翻转，更新会降低所选动作的概率。因此回报必须取正值，几何平均概率天然满足。
  3. 实现本讲片段 1、2、3 的最小闭环，在验证集上统计两个量：评论家分数最高的候选轨迹中未在 3 米内停止的比例；候选最优分与均值的平均差。用这两个量解释选择偏差。★★
    提示
    第一个量用验证集的目标位置做诊断（仅用于分析，不进入训练）；第二个量直接由片段 2 返回。若最优分与均值差随 K 增大而上升，同时未达目标比例保持高位，说明评论家排序捕捉指令对齐，停止判断仍是缺口。
  4. 把 K 从 5 改为 1 与 10，把 SIL 学习率放大 10 倍，再把训练期采样改为贪心。分别预测成功率、路径长度与训练稳定性的变化方向，并说明理由。★★
    提示
    K=1 无选择效应，伪标签质量下降；K=10 质量上升但偏差与算力上升。学习率放大使旧伪标签快速失效，指标可能先升后崩。贪心采样使候选退化，SIL 接近无效。三项都属于选择偏差与分布漂移的相互作用。
  5. 设计一套「停止动作自监督」方案：在不知道目标位置的条件下，为停止动作构造伪监督信号。要求给出伪标签构造规则、损失形式、至少一个反例场景、评价协议与与主流程的消融对照。★★★
    提示
    可选信号包括：轨迹回环奖励随步数的饱和点、相邻候选轨迹的停止位一致性、评论家对「短轨迹加停止」与「长轨迹」的分数差。损失可写成停止动作的二分类加权交叉熵，伪标签取多数票。反例：地标外观相似导致多轮探索都在同一房间停止。评价时把「到达目标」与「指令对齐」分开统计，避免把停止正确率混入匹配分数。

小结

  • SIL 面向无标注、无目标位置的未见环境：评论家给 K 条自采样轨迹打分，取最优者写入回放缓冲，作为伪标签做模仿更新，监督信号完全来自自监督打分。
  • 目标函数有两种等价写法：回报加权策略梯度与伪标签交叉熵；等价条件是评论家冻结、回报取正常数。回报为负会翻转更新方向。
  • 数字要点：seen-unseen 成功率差距从 30.7 收窄到 11.7 个百分点（相对降幅 61.9%）；测试集上 SIL（训练集）把路径从 15.22 米降到 11.97 米、SPL 从 35 升到 38；SIL（未见环境）达到 SR 60.5、SPL 59，但属于预探索协议。
  • 统计要点：长度归一化消除跨指令尺度差；取 K 条最大值平均抬高伪标签分数（K=5 约 1.16 个噪声标准差，K=10 约 1.54 个），K 的收益与偏差同步增长；一轮 SIL（K=5、平均 12 步、14,025 条指令）约 841,500 个环境步。
  • 边界：停止行为没有目标监督，高匹配分不保证到达目标；离策略更新缺少重要性修正，轮数过多会引入偏差；预探索协议数字不能与标准零样本榜单混用。
  • 下一讲把「探索」换成「搜索」：Regretful Agent 用学习到的进度估计做启发式，让智能体自己决定何时回溯，以贪心解码逼近搜索的效果。
