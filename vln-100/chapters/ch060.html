第三篇 · 连续环境、跨域与真实平台

第 060 讲｜第三篇复盘：仿真到现场的差距地图

本讲把 041 至 059 讲的证据收成一张四层差距地图：感知、地图、决策、执行，另加贯穿四层的协议与数据账；用 Anderson 等 2020 的差距分解（9.1 = 3.9 + 5.2 个百分点）、ETPNav 的试错消融（SDTW 18.64 到 45.33）、指令错误注入（组合错误相对降幅 30.64%）、标注审计（val 集确认 8 条与 10 条错误）等数字给每层定量；给出部署预算算例、对策优先级表与按层诊断模板，并把接口移交给第四篇。

  • 主题：阶段复盘 / 仿真到现实差距 / 失败归因 / 部署预算
  • 关键公式：G总 = G感知 + G地图 + G决策 + G执行（加性记账）；P部署 ≈ P仿真 × Π(1 − δ层)（乘法敏感性演示）
  • 预计学时：60 分钟
  • 前置讲：第 059 讲（连续环境结果横评）

学习目标

  • 会写：复述四层差距地图的每层来源、代表证据与对策，并说明协议与数据账为何贯穿四层。
  • 会算：完成一次差距账，把相对降幅换算为绝对百分点，并用加性与乘法两种口径做部署预算的敏感性分析。
  • 会实现：把评测日志编码为按层归因的记录流，统计各层失败占比与预算敏感性。
  • 会判断：区分仿真内排行榜数字与部署预期；判断一次失败应归入感知、地图、决策还是执行层。
  • 会诊断：为每层设计一个最小诊断实验，识别单层归因、数据泄漏与协议混用三类误判。

背景与动机

第三篇从第 041 讲拆开 VLN-CE 的三条假设开始，经过控制器、路点、桥接、拓扑规划、避障、评测协议、真机迁移、空中与城市、鲁棒性与系统集成，最后在第 059 讲收成一张横评表。仿真内的最好水平已经到 R2R-CE val-unseen 57.21 SR / 49.15 SPL（An 等 2023 表 III），RxR-CE 到 54.79 SR / 45.33 SDTW（同表 IV）。但第 049 讲的真机实验给出另一组数字：同一类智能体在 Coda 环境中，有图部署成功率 46.8%，无图冷启动 22.5%，仿真内为 55.9%（Anderson 等 2020）。仿真与现场之间的落差由多层机制叠加而成，本讲的任务就是把叠加结构画清楚。

归因框架借用 Zhang 等 2024 的 VLN 综述（arXiv:2407.07035v2）。该综述用世界模型（world model）、人类模型（human model）、智能体模型（agent model）组织挑战与解法，并在部署一节明确指出：仿真环境缺少真实世界的复杂性与可变性，渲染图像质量放大了这一问题；感知差距导致性能与精度下降，实体差距（embodiment gap）与数据稀缺是另外两个瓶颈；语义地图与三维特征场被列为缓解单目机器人全景感知的起点（Wang 等 2024 的工作）。这些判断与本课程第三篇的实验证据可以逐条对齐。

本讲的产出是差距地图 v1、部署准备清单 v1 与一套诊断模板。它们同时是第四篇的入口：数据规模化（第 061 讲起）、记忆与地图范式（第 066 讲起）、偏差诊断方法学（第 075 讲）、评测公平性（第 079 讲）都会回到这张地图上认领各自的层。

核心原理

本讲按「证据链复盘、四层地图、差距账、逐层展开、对策优先级、诊断模板、边界」展开；所有引用数字标注来源、协议与 split，换算由 Python 实算。

2. 四层差距地图：定义与证据

把部署差距按「信息在哪一层被改变」分成四层，另加一层跨层的协议与数据账。四层的定义如下。感知层（perception）处理从环境到观测的变换：相机型号、动态范围、曝光、光照、视角与高度。地图层（map）处理从观测到位姿与空间结构的变换：定位来源、建图误差、回环与漂移。决策层（decision）处理从指令与状态到动作选择：指令质量、语义接地、泛化、停止判定。执行层（execution）处理从动作选择到物理位移：底盘约束、碰撞、滑动规则、控制时延。协议与数据账不属于任何单层，它同时改变四层的评测输入与结果记录。

层差距来源量化证据（来源 + 协议）对策残差风险
感知相机与渲染域、视角高度、光照与动态Theta V 替换后 55.9 到 49.5，域随机化回到 52.0，残差 3.9；视角项 5.2（Anderson 等 2020，Coda 111 条指令）；渲染域 2.68 SR / 2.88 SPL（An 等 2023 表 IX，R2R-CE val-unseen）域随机化、渲染域对齐、图像修复、鲁棒性测试集颜色抖动无法覆盖曝光与运动模糊；视角停位误差与地图层耦合

结论一：四层之间不是独立同分布的加性项。感知误差改变地图输入，地图误差改变决策状态，决策变化改变执行轨迹，任何一层的对策都会通过闭环反馈影响其余层。下表与算例使用加性记账作为一阶近似，加性形式便于沟通与敏感性分析，不能当作精确预测。

3. 差距账：从 55.9 到 46.8 的分解与部署预算

Anderson 等 2020 的分解是当前唯一一组在同一环境、同一批指令、同一智能体上完成的端到端差距账。其结构为：仿真内基准 55.9%，真机有图 46.8%，总差距 9.1 个百分点；其中视觉项 3.9（换相机图像 49.5 加域随机化 52.0 后相对基准的残差），视角项 5.2（仿真加域随机化 52.0 与真机 46.8 之差）。相对降幅 9.1 / 55.9 = 16.28%。无图设定再降 24.3 个百分点（相对有图降幅 51.92%），对应定位、建图与候选生成全部在线完成。

G总 = G感知 + G地图 + G决策 + G执行；P部署 ≈ P仿真 − G总（加性一阶近似） Anderson 2020 口径：G总 = 55.9% − 46.8% = 9.1 = 3.9（视觉）+ 5.2（视角）；视角项含停位误差与光照等混合因素。G层 用百分点作单位

把这一分解的量级迁移到第 059 讲的仿真水平上，做一个量级推演：以 ETPNav 的 R2R-CE val-unseen 57.21 SR 为起点，若感知与视角两项的量级与 Coda 实验相同，则预期落在 57.21 − 9.1 = 48.11 SR 附近；用相对降幅 16.28% 计算得 47.90，两者一致到 0.2 个百分点以内。作为参照，Anderson 实验中有图设定为 46.8，仿真加域随机化为 52.0，推演值落在两者之间。结论二：跨环境外推只能在量级上使用；迁移的前提是两个场景的感知条件、底盘与指令分布没有数量级差异。

乘法口径给出更保守的下界，用于敏感性分析：把各层差距写成对成功率的相对损耗 δ层 = G层 / P仿真，则 P部署 ≈ P仿真 × Π(1 − δ层)。取视觉与视角的相对损耗（3.9 / 57.21 与 5.2 / 57.21），再叠加一次指令方向错误的相对降幅 18.64%，与三处错误组合的 30.64%，四项连乘后从 57.21 落到 27.35。该数字对应「感知残差、视角停位、方向错误、多处错误同时命中」的叠加场景，与无图真机的 22.5 同量级。乘法口径的用途是给出保守下界与识别主导项，两项 Anderson 损耗单独连乘得 48.46，与加性的 48.11 相差 0.35 个百分点，说明在损耗较小时两种口径接近。

4. 逐层展开：机制、证据与对策

感知层。差距有三个来源：相机响应（动态范围与色彩）、观测几何（视角与高度）、环境动态（光照、行人、移动物体）。Anderson 等 2020 用颜色抖动把视觉残差从 6.4 压到 3.9 个百分点，说明训练侧外观扰动可以消掉约四成；剩余部分与曝光、运动模糊和视角混合，无法用同一手段处理。An 等 2023 的渲染域对照给出同类证据：预训练图像用 Habitat 渲染比用 MP3D 渲染高 2.68 SR 与 2.88 SPL，微调无法完全消除。Wang 等 2023 的图像修复管线（第 061 讲展开）把 HM3D 与 Gibson 的破损渲染图恢复到接近相机质量，Gibson 部分带来 1.75 SR 的提升。Zhang 等 2024 综述把感知差距列为部署瓶颈的第一项，并指出三维特征场与语义地图是给单目机器人提供全景感知的候选路线。

地图层。连续环境论文普遍假设可读取仿真器真值位姿。An 等 2023 明确声明该工作不处理基于噪声传感器的定位，把视觉里程计列为可替换方向；这一假设同时服务于建图（位姿用于图更新）与控制（位姿用于朝向与距离换算）。撤掉先验后，Anderson 等 2020 的无图设定需要在线完成定位、建图与候选生成，成功率从 46.8 掉到 22.5。地图误差还以两种可测形式进入系统：子目标预测误差（1.5 米内占 74%，超过 1.5 米占 26%）决定动作候选的质量上限；幽灵节点位置误差让规划器可能选择不可达目标，删除保护消融显示关闭该项会损失 4.80 SR。对策按成本排序为：接入视觉里程计并报告漂移量、把位姿不确定性写入接口、保留并校验删除保护、在评测中使用独立定位栈记录位姿真值（第 049 讲的做法）。

决策层。三类风险已在前文量化。第一类是指令与标注质量：方向词错误相对降幅 18.64% 为单类最大，三处错误组合达 30.64%；val 集内已确认的标注错误虽只占 0.44% 与 0.27%，但会破坏同一 split 的可复现前提。第二类是泛化：ScaleVLN 把 seen 与 unseen 的成功率缺口从约 8 个百分点压到 0.92，说明环境多样性是决策层最强的杠杆之一；该结果依赖 1,291 个合成场景与 4.94M 条指令轨迹对（第 061 讲）。第三类是停止：OSR 与 SR 的缺口在 R2R-CE 上为 7.50 至 8 个百分点，ScaleVLN 距人类的 6 个百分点与缺口同量级，综述把人类模型层的对话能力（澄清歧义、主动提问）列为下一步（第 081 讲起展开基础模型接入）。

执行层。禁止滑动协议下的数据最有说服力：同一规划器下开启试错后 SR 从 22.61 升到 54.79、SDTW 从 18.64 升到 45.33，把执行缺口压到接近上界（Teleportation 为 46.04 SDTW）。经典快速行进法加碰撞图的组合从 21.73 恢复到 41.09 SDTW，说明显式的碰撞记忆可以部分替代试错，但依赖先撞一次获得信息。控制器的动作效率同样可测：旋转后前进平均 60.63 个动作，PointGoal 为 146.81，FMM 为 188.79，效率差约 2.4 至 3.1 倍，直接影响 SPL。对策是执行层优先于规划层的升级顺序：在禁止滑动、窄通道或大门槛场景里，先修执行，再谈规划。

决策注入方向或物体错误，或替换评测 split冻结策略与解码相对降幅（方向 18.64%）与 seen-unseen 缺口
执行开关试错、换控制器、缩放底盘半径规划器与观测SR/SDTW（试错 +32.18 SR）与碰撞次数

诊断的通用纪律有三条。第一，一次只动一层，其余层固定并记录版本；第二，相对降幅与绝对百分点成对报告，注明分母；第三，任何「修复」上线前在冻结轨迹集上重放，确认口径未漂移。第 075 讲会把这三条扩展为完整的偏差诊断方法学。

7. 边界与失效模式

  • 单环境与单平台证据：Anderson 的实验在一处 325 平方米空间完成，底盘为 TurtleBot2；把 9.1 的分解外推到其它环境需要重新标定，本讲的 48.11 推演只是一阶近似。
  • 加性记账的适用条件：损耗较小时加性与乘法接近（48.11 对 48.46）；损耗较大时乘法更保守（四项叠加 27.35）。两层以上同时出现超过 30% 的相对损耗时，不应再使用加性口径。
  • 静态与受控实验：现有证据大多来自静态环境与受控光照；动态行人、天气与移动障碍属于综述列出的开放项，需要专门基准（综述提到的动态环境方向）。
  • 协议层未闭环：val 集的标注错误只清理了检测器筛出并人工复核的子集，真实错误数与分布仍未知；清理前后的数字必须同时报告。
  • 综述框架的时间性：Zhang 等 2024 的框架覆盖基础模型兴起后的方法，2025 至 2026 年的新平台与新基准需要增量核对；第 093 至 099 讲会给出更新指引。
  • 真机章节的定位：本课程把真机内容写到「方案加复现指南」级，不承诺替读者完成真机实验；差距地图是对证据的组织方式，不构成部署合格证明。

关键代码与解读

三段代码分别给出差距账两种口径、按层归因与部署清单放行检查。数字对应本讲算例。

片段 1：加性与乘法差距账

SIM = 57.21          # ETPNav R2R-CE val-unseen SR（An 等 2023 表 III）
VISUAL, VIEWPOINT = 3.9, 5.2    # Anderson 等 2020 的百分点口径
INSTR_DIR, INSTR_ALL = 0.1864, 0.3064   # 指令错误相对降幅

def additive(sim, items):
    """加性一阶近似：逐项减去绝对百分点。"""
    p = sim
    for name, delta in items:
        p -= delta
    return round(p, 2)

def multiplicative(sim, ratios):
    """乘法敏感性：逐项乘以 (1 - 相对损耗)。"""
    p = sim
    for name, r in ratios:
        p *= (1.0 - r)
    return round(p, 2)

print(additive(SIM, [("visual", VISUAL), ("viewpoint", VIEWPOINT)]))
# 48.11：量级推演，与相对口径 57.21 * (1 - 0.1628) = 47.90 一致
print(multiplicative(SIM, [("visual", VISUAL / SIM), ("viewpoint", VIEWPOINT / SIM),
                           ("instr_dir", INSTR_DIR), ("instr_all", INSTR_ALL)]))
# 27.35：四项同时命中的保守下界，与无图 22.5 同量级

解读：（1）加性口径把每项当作独立可减量，适合沟通与预算；乘法口径把小损耗折算为相对比例，累乘后给出保守下界。（2）指令错误的相对降幅来自冻结策略注入实验（第 048 讲），换算成绝对百分点为 9.9 与 15.9，不能与视觉项直接混用不加说明。（3）两种口径在损耗小时接近（48.11 对 48.46），是选择记账户径的依据。

片段 2：按层归因的日志分类器

def attribute(event):
    """把一次失败归到感知、地图、决策或执行层，返回 (层, 依据)。"""
    if event["pose_source"] == "slam" and event["pose_drift_m"] >= 3.0:
        return "map", "位姿漂移超过成功阈值"
    if event["collision"] and event["sliding"] == "forbidden" and event["stuck"]:
        return "execution", "禁止滑动下发生死锁"
    if event["instruction_error_detected"]:
        return "decision", "指令与轨迹兼容性低于阈值"
    if event["renderer_train"] != event["renderer_eval"]:
        return "perception", "训练与评测渲染域不一致"
    if event["closest_geodesic_m"] < 3.0 and event["stopped"] is False:
        return "decision", "到达阈值内但未停止"
    return "unclassified", "无显著单层标记，保留人工复核"

# 一条真实轨迹记录示例
row = dict(pose_source="slam", pose_drift_m=3.4, collision=True,
           sliding="allowed", stuck=False, instruction_error_detected=False,
           renderer_train="habitat", renderer_eval="habitat",
           closest_geodesic_m=6.2, stopped=True)
print(attribute(row))   # ('map', '位姿漂移超过成功阈值')

解读：（1）分类器只做第一层筛查，一条记录命中多条时按可验证性排序（位姿、死锁、指令、渲染域、停止）。（2）未分类记录必须保留，统计各类占比本身就是诊断输出。（3）字段名与第 048 讲的可比键对齐，避免日志与评测配置各用一套命名。

片段 3：部署清单放行检查

CHECKLIST = [
    ("perception_camera_gap", 4.0, "小于 4 个百分点"),
    ("map_pose_drift_m", 0.3, "小于成功阈值一个数量级（3 m 的十分之一）"),
    ("decision_seen_unseen_gap", 2.0, "小于 2 个百分点"),
    ("execution_sdtw_loss", 2.0, "禁止滑动场景下小于 2 个百分点"),
]

def gate(measured):
    """返回未通过项清单；空清单表示可以进入下一阶段。"""
    bad = []
    for name, limit, desc in CHECKLIST:
        if measured.get(name, float("inf")) > limit:
            bad.append((name, measured.get(name), desc))
    return bad

measured = {"perception_camera_gap": 3.9, "map_pose_drift_m": 0.25,
            "decision_seen_unseen_gap": 0.92, "execution_sdtw_loss": 4.5}
print(gate(measured))   # 执行项 4.5 超过 2.0，其余通过

解读：（1）四项阈值都来自本讲引用证据的保守缩放：感知 4 对应 Anderson 的 3.9 残差，地图 0.3 米对应评测栈量级，决策 2 对应 ScaleVLN 的 0.92 留出余量，执行 2 对应试错恢复后的残差。（2）阈值是工程判据，不是论文结论；部署前应结合场景重新标定并记录版本。（3）清单函数保持纯函数式，便于在 CI 中对每次评测的配置与日志自动运行。

常见坑

  • 把仿真 SOTA 当部署预期：直接引用 57.21 SR 作为上线指标。根因是忽略完整链条的差距账。修复：按四层填账，至少给出感知与执行两项的量级区间；用加性与乘法两种口径交叉验证。
  • 单层归因：把所有失败都归到决策层，忽略定位漂移与碰撞。根因是日志字段缺失。修复：按片段 2 的分类器补齐四层标记字段；未分类记录单独统计。
  • 忽略协议与数据账：在同一实验里混用清理前后数据或两个渲染域。根因是数据版本未随结果入库。修复：把八项可比键写入配置；清理与渲染域切换时重放固定轨迹集。
  • 用评测栈的定位精度代替机器人能力：评测定位误差 0.3 米来自独立带图栈，机器人自身仍需 SLAM。根因是两类定位混用。修复：分开记录「评测位姿」与「机器人位姿」，无图设定报告自身漂移。
  • 在微调集上诊断泛化：用与微调同源的轨迹做失败归因，缺口被人为压小。根因是数据泄漏。修复：诊断集固定为未见场景，且与训练数据的场景、指令模板交叉检查（第 074 讲展开）。
  • 把对策当独立增益相加：把试错的 +32.18 与数据规模的 +11 直接相加。根因是忽略协议差异与交互项。修复：每个对策标明所属层与协议；跨层增益只给区间，必要时用四格实验分离主效应。

练习与思考

  1. 把 Anderson 等 2020 的分解搬到另一组数字：若某系统仿真成功率 62.0%，换相机图像后掉到 56.0%，加域随机化回到 58.5%，真机有图 52.0%。计算视觉项、视角项、总差距与相对降幅。 ★
    提示
    视觉项 = 62.0 − 58.5 = 3.5；视角项 = 58.5 − 52.0 = 6.5；总差距 = 10.0；相对降幅 = 10.0 / 62.0 = 16.13%。视觉项的原始落幅（62.0 到 56.0）为 6.0，域随机化回收 2.5 个百分点，与 Anderson 的 6.4 回收 2.5 的案例同量级。
  2. 某次部署评测：位姿来自 SLAM，漂移 0.25 米；发生 2 次碰撞，滑动允许且未卡死；指令检测分数正常；最近点距目标 2.6 米但未调用停止。按片段 2 的分类器应归入哪层？如果要区分「停止太晚」与「策略保守」，还需要哪两个字段？ ★
    提示
    归入决策层（到达阈值内但未停止）。补充字段：首次进入 3 米时的步号与停止动作步号（区分太晚），以及停止动作的对数概率或分位数（区分策略保守）。
  3. 取损失项为：视觉残差 3.9、视角 5.2、方向错误 18.64%、组合错误 30.64%，仿真 57.21。分别计算加性总损耗（把相对项先乘以 0.53 规格的基线再换算）与乘法下界，并说明为什么两个结果相差很大。 ★★
    提示
    相对项换算：方向 0.53 × 18.64% = 9.88 个百分点；组合 0.52 × 30.64% = 15.93 个百分点（第 048 讲口径）。加性总损耗 = 3.9 + 5.2 + 9.88 + 15.93 = 34.91，结果为 57.21 − 34.91 = 22.30。乘法下界（每项相对仿真）为 27.35。两者相差大的原因是损耗超大时乘法对小项也重复折扣，且加性把不同基线的相对量直接搬到 57.21 的基线上。
  4. 为地图层设计一个最小诊断实验：在同一个在线拓扑规划器上，把位姿来源从仿真真值换成语义视觉里程计，要求写出 (a) 固定项与变量；(b) 三个观测量与各自判据；(c) 预期失效模式与修复方向。 ★★
    提示
    (a) 固定规划器、控制器、评测 split 与最大规划次数，只改位姿源。(b) 观测量：位姿漂移（均方根误差）、图节点位置误差（与真值图对齐后的平均距离）、SR/SDTW 变化；判据：漂移小于阈值一个数量级，节点误差随步数不持续增长，SR 下降可归因。(c) 预期失效：回环缺失导致幽灵节点重复创建、删除保护误删可达目标；修复：加入回环检测与位姿不确定性阈值，并对删除操作做可逆日志。
  5. 综合设计一份「从仿真模型到真实部署」的例行报告模板：要求 (a) 包含四层与协议账各至少两条量化项；(b) 给出加性与乘法两种预算结果及主导项识别方法；(c) 规定哪些数字必须双报（清理前后、val 与 test）；(d) 列出三个会让结论失效的场景变化并给出对应敏感性实验。 ★★★
    提示
    (a) 感知：换相机残差、渲染域一致性；地图：位姿漂移、节点误差；决策：seen-unseen 缺口、停止缺口；执行：禁用滑动 SDTW 损失、碰撞次数；协议：可比键、两个上限。(b) 加性给出量级，乘法给出下界；主导项按「单项损耗占总体损耗的比例」排序，占比超过四成的项优先。(c) val 与 test 的成功率、标注清理前后的指标、渲染域切换前后的指标。(d) 场景变化示例：光照剧变、动态行人、底盘半径变化；对应实验：昼夜对照、带行人评测集、底盘半径扫描（ETPNav 论文的半径曲线给出参考方法）。

小结

  • 四层差距地图：感知（相机与渲染域、视角、动态）、地图（位姿、节点误差、回环）、决策（指令质量、泛化、停止）、执行（碰撞、滑动、死锁、时延），另设跨层的协议与数据账。
  • Anderson 等 2020 的差距账：总 9.1 个百分点 = 视觉 3.9 + 视角 5.2，相对降幅 16.28%；有图 46.8，无图 22.5。把该量级迁到 57.21 的仿真水平，推演值为 48.11（加性）与 47.90（相对口径）。
  • 每层的代表证据：感知的渲染域差 2.68 SR；地图的真值位姿假设与无图 22.5；决策的方向错误相对降幅 18.64% 与组合 30.64%、缺口 8 到 0.92；执行的试错 +32.18 SR 与 +26.69 SDTW。
  • 部署预算两种口径：加性用于沟通与一阶近似（48.11 对 48.46，差 0.35）；乘法用于保守下界与主导项识别（四项叠加落到 27.35）。
  • 对策优先级：执行与感知的代价低、收益立即可测，排在前；数据规模化收益最大但需要上千场景的生成成本；视觉里程计是解除真值位姿假设的关键前置。
