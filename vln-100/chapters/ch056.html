第 056 讲｜指令错误与数据讹误鲁棒性

本讲拆解 Taioli 等 2024（IROS 2024，arXiv:2403.10700v2）的 R2RIE-CE：在 R2R-CE Val Unseen 上注入方向、房间、物体等五类指令错误，冻结的 BEVBert 策略相对降幅从 6.66% 到 30.64%（摘要口径最多约 25%）；论文定义指令错误检测与定位任务，IEDL 模型平均 AUC 0.79、平均绝对 token 距离 7.71；并把方法反过来用于数据质检，在 R2R-CE 与 RxR-CE 的验证集中确认 8 条与 10 条错误或含混标注。

  • 主题：鲁棒性评测 / 错误注入 / 检测与定位 / 数据讹误
  • 关键公式：ΔSR = (SR(EC) − SR(EP)) / SR(EC)；ATD = (1/N) Σi (1/Ji) Σj |ℓji − ℓ̂ji|
  • 预计学时：60 分钟
  • 前置讲：第 055 讲（室外泛化：图特征 vs 图像）

学习目标

  • 会写：复述五类指令错误的定义与注入规则（方向、房间、物体、房间与物体、全部），以及检测与定位任务的形式化目标。
  • 会算：按论文表 II 的相对降幅换算出扰动集上的绝对成功率，区分相对降幅与百分点；核对平均降幅 15.17 的计算口径。
  • 会实现：写一个可复现的错误注入脚本（替换表加种子加元数据），并实现 AUC 与 ATD 两个度量的最小版本。
  • 会判断：给定一批候选错误标注，判断能否直接删除，识别检测阈值与人工复核的分工。
  • 会诊断：指令错误评测中五类常见问题的成因与修复，包括子集口径混用与相对量误读。

背景与动机

第 055 讲把泛化问题推到室外场景的模态选择上，本讲转向输入侧的第二类失配：指令与标注本身含错。所有 VLN-CE 方法在训练与评测时都默认语言指令精确描述了目标路径，而真人给出指令时会记错房间、混淆物体、说反方向。论文的动机例子很直接：把「go left」改成「go right」，智能体会在错误位置停止，即使指令后半段仍包含可用于发现矛盾的细节。

这类问题的研究价值有两层。第一层是鲁棒性：策略在含错指令下的性能下界决定了它能否进入真实交互。第二层是数据质量：同一个检测模型可以反向用于发现基准数据集里的错误标注。论文报告的两组数字分别对应这两层：五类注入错误下成功率的最大相对降幅达到 30.64%（表 II 的 All 项，带常识）；在标准 R2R-CE 与 RxR-CE 验证集上，模型标记的候选经人工复核确认了 8 条与 10 条应当修正的 episode。

本讲先建立错误分类与注入基准，再讲鲁棒性实验的配对协议，随后给出检测与定位任务的定义、IEDL 模型与结果，最后讨论数据讹误发现与引用纪律。第 057 讲处理观测侧的同类问题（视角与高度变化），两讲合起来构成部署前的输入压力测试；评测协议本身沿用第 048 讲的两层截断与停止判定口径。

核心原理

本讲按「错误分类、基准构建、鲁棒性协议、检测与定位定义、IEDL 方法、结果、数据讹误、边界」展开；论文数字标注表格与协议，换算结果先算后写。

1. 五类指令错误与注入规则

论文把室内导航指令中最可能出现的错误分成三类基本型与两种组合型，注入规则都带人类错误的先验，模拟记忆不准与方向混淆：

  • 方向错误（Direction）：把真值方向词换成反义词。论文使用的方向词对包括 left/right、go down/go up、into/out of、forward/backward、inside/outside、go around/go back、leftmost/rightmost。
  • 物体错误（Object）：把真值物体类换成常在同类空间共现的物体类，例如 sofa 与 chair 混淆比 sofa 与 toilet 混淆更符合常识。
  • 房间错误（Room）：把真值房间换成几何上常相邻的房间，邻接表由 ConceptNet 关系加人工整理得到；论文使用的房间集合为 kitchen、archway、bathroom、bedroom、gym、lounge、hallway、living room、office、dining room、laundry、restroom。
  • 房间与物体错误（Room&Object）：同一句指令中同时注入房间错误与物体错误，共 2 处扰动。
  • 全部错误（All）：方向错误与房间和物体错误同时出现，共 3 处扰动。

每条扰动句保留扰动词的位置元数据，供定位任务评测使用；这是后续 ATD 度量能够计算的前提。

2. 基准构建与统计

R2RIE-CE 基准以 R2R-CE 的 Val Unseen 为底，原始规模 1839 条 episode。构建分两步。第一步过滤：剔除词数低于阈值 τ 的 episode，并剔除缺少对应错误类型所需词类的 episode，得到各类型的正确集 EC。第二步成对注入：对 EC 中每条 episode 按规则生成一条扰动 episode，构成 EP，两者除指令外完全对齐，从而把性能差归因到指令扰动上。

3. 鲁棒性协议与结果

评测协议体现配对思想：冻结策略在 EC 与 EP 上各跑一次，其余条件完全一致，报告相对降幅

4. 检测与定位任务的形式化

给定指令 I = {w1, …, wF} 与策略 π 在导航过程中产生的一串观测 O = {O1, …, OT}，检测任务学习函数 dπ: I × O → {True, False}，判断指令是否含错；定位任务学习 lπ: I × O → P({0, 1, …, len(I) − 1})，输出错误词的位置集合。注意两点：策略 π 在训练检测器时冻结；观测序列来自策略按该指令实际走出的轨迹，因此检测器看到的是「策略会犯的错」作用后的行为证据。

检测用 ROC 曲线下面积（AUC）评测，指令含至少一处错误即为正样本。定位用论文提出绝对 token 距离（Absolute Token Distance, ATD）：

ATD = (1 / N) Σi=1..N (1 / Ji) Σj=1..Ji |ℓji − ℓ̂ji| N 为扰动 episode 数，Ji 为第 i 条的错误数，ℓ 与 ℓ̂ 为真值与预测位置；单位是 token 距离，越低越好

ATD 的直觉是「预测位置离真值位置几个词」。论文报告 IEDL 平均 ATD 7.71，接近一条典型子句的长度，说明定位粒度处在子句级；完整句子级精确定位仍是开放问题。

5. IEDL：结构与训练

IEDL（Instruction Error Detector & Localizer）是模型无关的跨模态检测器，论文把它装在 BEVBert 之上，但输入只依赖指令与冻结策略产生的轨迹，可以换成其它策略。结构分四段：文本侧把指令截断或补齐到 W = 80 个 token，取 BERT 词嵌入 Υ ∈ ℝW×D；视觉侧把策略每一步所在视点的全景特征（ViT-B/16-CLIP 提取，再经全景编码器）组成轨迹集合 Γ ∈ ℝT×D，加正弦位置编码；两侧拼接上可学习的 [CLS] 后送入 k = 4 层跨模态 Transformer（轨迹作查询、指令作键值，再做自注意力与前馈）；[CLS] 的输出分两路，检测头给出对齐分数 σ(a) ∈ [0, 1]，定位头给出 W 维 token 打分。

训练用两个损失的加权和：检测头用二元交叉熵 Ld，定位头用交叉熵 Ll，并按错误数 E 归一化：

L = λ1 Ld + (λ2 / E) Σi=1..E Ll，论文取 λ1 = λ2 = 1 D = 768；AdamW；最多 9k 次迭代；训练集为 R2R-CE 训练集上「无常识版本」的 All 错误基准，验证集为「带常识版本」的 All，按 AUC 选模型

结论二：训练时去掉常识先验（不约束物体共现与房间邻接），可以避免把注入规则本身的统计规律当作捷径学走，测试时再用带常识的扰动集检验泛化。这一设计是该方法能迁移到 RxR-CE 的前提。

三条读法。第一，检测与定位是两个难度不同的任务：Direction 的 AUC 只有 0.58，但 ATD 8.13 仍优于随机基线 10.54，说明模型难以确认「方向被说反」这件事，却能在需要定位时缩小搜索范围。第二，CLIP 对齐基线在物体定位上优于 IEDL（ATD 8.76 对 9.21），因为物体词与图像区域的对应关系更直接；但它的检测 AUC 只有 0.59，说明它给出的证据覆盖不全。第三，ATD 相对随机的降幅为 31.53%，相对 CLIP 为 16.38%，换来的是 AUC 从 0.59 到 0.79 的检测能力提升，两个头联合使用才有完整价值。

7. 数据讹误发现

把 IEDL 的检测头用到标准数据集上，可以得到一份候选错误清单。在 R2R-CE Val Unseen 的 1839 条中，对齐分数高于阈值 τa = 0.99 的候选有 25 条，人工逐条查看后确认 8 条真为错误标注（占候选的 32.0%，占全集的 0.44%）。在 RxR-CE 的 3669 条（英语 en-IN 与 en-US 子集）上标记 118 条，人工复核确认 10 条（占候选的 8.47%，占全集的 0.27%），错误涉及方向、物体、目标位置与网格问题，论文建议把这些 episode 从验证集中移除。

结论三：自动检测的价值在候选筛查，最终判定必须经过人工复核；但即使按保守的确认率折算，标准基准里也存在千分之几量级的错误标注，足以让胜负差距在 1 个百分点量级的方法对比失去意义。RxR-CE 指令平均 110 个 token（R2R-CE 约 30 个，比值 3.667），更长的指令给了检测器更多证据，候选率也更高（3.22% 对 1.36%）。

8. 适用边界与失效模式

  • 合成错误的分布偏移：注入错误由替换表生成，同一位置一词替换；真人错误可能出现删词、语序混乱与前后矛盾，难度分布不同，报告结论时要标明「注入错误」。
  • 子集口径不同：各错误类型在过滤后的子集上评测，正确集基线 SR 在 0.52 至 0.58 之间浮动，不能与标准 R2R-CE 数字并排。
  • 冻结策略限制：鲁棒性数字描述的是「给定策略如何被错误指令带偏」，不能推广到重训后的策略；错误感知训练属于论文未来的工作。
  • 阈值敏感性：τa = 0.99 时 R2R-CE 候选 25 条、确认率 32%；阈值降低会增加召回，也会抬高复核成本，论文没有给出完整的查全与查准曲线。
  • 语言覆盖：RxR-CE 实验只覆盖 en-IN 与 en-US；其它语言的检测性能未测。
  • 停止判定细节：论文文字把成功描述为「终点距离小于 3 米」，省略了停止条件；按第 048 讲口径，官方评测器要求显式停止与距离阈值同时成立，跨实现比较时需要核对。

关键代码与解读

三段代码分别给出错误注入、AUC 与 ATD 计算、IEDL 结构示意。接口按论文与公开实现的设计为参照，版本演进时以仓库为准。

片段 1：错误注入脚本

import random

DIRECTION_ANTONYMS = {"left": "right", "right": "left", "up": "down", "down": "up"}
ROOM_ADJACENT = {"kitchen": ["dining room"], "bathroom": ["bedroom", "hallway"]}
OBJECT_COLOCATED = {"sofa": ["chair", "table"], "toilet": ["sink", "bathtub"]}

TABLES = {"direction": DIRECTION_ANTONYMS, "room": ROOM_ADJACENT,
          "object": OBJECT_COLOCATED}
PLANS = {"direction": ["direction"], "room": ["room"], "object": ["object"],
         "room_object": ["room", "object"], "all": ["direction", "room", "object"]}

def inject_errors(tokens, error_type, rng):
    """按类型在词序列上替换，返回扰动序列与 (类型, 位置) 元数据。"""
    out = list(tokens)
    meta = []
    for kind in PLANS[error_type]:
        cand = [i for i, w in enumerate(out) if w in TABLES[kind]]
        if not cand:
            continue                      # 过滤阶段保证候选存在，这里兜底
        pos = rng.choice(cand)            # 位置随机采样
        out[pos] = rng.choice(TABLES[kind][out[pos]])   # 替换词按常识表采样
        meta.append((kind, pos))
    return out, meta

rng = random.Random(2024)                 # 固定种子，E_P 可重建
perturbed, meta = inject_errors(["walk", "left", "into", "the", "kitchen"], "all", rng)
print(perturbed, meta)                    # 例如 right / bedroom 方向与房间各一处

解读：（1）替换表分三类，组合型按 PLANS 的顺序注入多处，与论文的五类口径一致；方向表用反义词，房间与物体表用常识集合。（2）固定随机种子是复现的关键：同一批 episode 生成同一批扰动，实验对比才可重复。（3）元数据记录被扰动位置，ATD 评测直接消费它；漏记位置等于丢失定位任务的标签。

片段 2：AUC 与 ATD 的最小实现

import numpy as np

def absolute_token_distance(pred, gold):
    """pred/gold: 每条 episode 的预测位置列表与真值位置列表。"""
    per_episode = [float(np.mean([abs(p - g) for p, g in zip(pl, gl)]))
                   for pl, gl in zip(pred, gold)]
    return float(np.mean(per_episode))     # 先按 episode 内求平均，再跨集平均

def auc(scores, labels):
    """按正负样本对的秩和计算 ROC 曲线下面积。"""
    scores = np.asarray(scores, dtype=float)
    labels = np.asarray(labels, dtype=int)
    order = np.argsort(scores)
    ranks = np.empty(len(scores))
    ranks[order] = np.arange(1, len(scores) + 1)
    n_pos = int(labels.sum())
    n_neg = len(labels) - n_pos
    pos_rank_sum = ranks[labels == 1].sum()
    return (pos_rank_sum - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)

解读：（1）ATD 按论文公式先算每条 episode 内部的平均绝对位置差，再对所有 episode 取平均；顺序反了会让错误数多的 episode 权重漂移。（2）AUC 用秩和实现，等价于「随机取一对正负样本、正样本得分更高的概率」；比较方法时应报告同一批样本上的曲线，避免只报一个工作点。（3）定位评测只在扰动集上进行，检测评测则需要正负混合，两套样本组织方式要分开管理。

片段 3：IEDL 结构与双头损失

import torch
import torch.nn as nn
import torch.nn.functional as F

class IEDL(nn.Module):
    """指令与轨迹的跨模态检测与定位模型（Taioli 等 2024 的结构示意）。"""
    def __init__(self, dim=768, layers=4, max_words=80):
        super().__init__()
        self.cls = nn.Parameter(torch.zeros(1, 1, dim))       # 可学习 [CLS]
        self.text_proj = nn.Linear(768, dim)                   # BERT 词嵌入投影
        self.traj_proj = nn.Linear(2048, dim)                  # 全景特征投影
        layer = nn.TransformerEncoderLayer(dim, 8, dim * 4, batch_first=True)
        self.fuse = nn.TransformerEncoder(layer, layers)       # k = 4 层
        self.det_head = nn.Sequential(nn.Linear(dim, 1))       # 对齐分数
        self.loc_head = nn.Sequential(nn.Linear(dim, dim), nn.ReLU(),
                                      nn.LayerNorm(dim), nn.Linear(dim, max_words))

    def forward(self, traj_feats, text_feats):
        t = self.traj_proj(traj_feats)                         # (B, T, D)
        w = self.text_proj(text_feats)                         # (B, W, D)
        cls = self.cls.expand(t.shape[0], -1, -1)
        h = self.fuse(torch.cat([cls, t, w], dim=1))[:, 0]     # 取融合后的 [CLS]
        return self.det_head(h).sigmoid(), self.loc_head(h)    # 检测分数与位置打分

det_logits, loc_logits = model(traj, text)
loss_det = F.binary_cross_entropy(det_logits.squeeze(-1), det_labels)
loss_loc = sum(F.cross_entropy(loc_logits, gold_positions[:, j])
               for j in range(gold_positions.shape[1]))
loss = 1.0 * loss_det + (1.0 / n_errors) * loss_loc           # λ1 = λ2 = 1

解读：（1）[CLS] 聚合轨迹与指令的跨模态信息，两个头共享它，对应论文的共享融合层设计。（2）定位头输出 W 维打分，按位置做交叉熵；多处错误时对每处求损失再除以错误数 E。（3）检测分数经 sigmoid 后用于筛查：阈值 τa 越低召回越高，0.99 是论文在质检实验中的高置信工作点。两个头都是「MLP 加 ReLU 加 LayerNorm 加输出层」的结构，检测头输出 1 维分数，定位头输出 W 维打分。

常见坑

  • 把合成注入当作自然错误分布：用替换表生成的错误，难度与真人错误不同，结论被外推到人机交互场景。根因是把「注入错误」等同于「真实错误」。修复：所有结论标注「注入错误」；补充真人在环的错误采集，至少报告一套自然错误子集。
  • 在过滤子集上与标准数字并排：各错误类型的正确集 SR 在 0.52 至 0.58 之间浮动，直接拿 0.55 与标准 R2R-CE 的 SR 比较会引入非扰动差异。根因是忽略过滤规则。修复：配对报告 EC 与 EP，只用两者之差说事；需要与文献比较时写明子集口径。
  • 相对降幅与百分点混用：Direction 的 −18.64% 是相对量，对应 9.88 个百分点；把两个数放进同一张对比表会误导。根因是口径标签缺失。修复：每个数字带「相对」或「百分点」标签，换算过程写进脚注。
  • 只看检测 AUC 不看定位 ATD：某个方法 AUC 高但 ATD 接近随机，高召回靠的是对整句打高分，不能用于高亮错误词。根因是把两个任务当成一个。修复：两个指标一起报告；在线高亮场景以 ATD 为准，离线筛查以 AUC 为准。
  • 把标记候选当确认错误：R2R-CE 上 25 条候选只有 8 条确认，直接按候选删除会砍掉正确样本。根因是省略人工复核。修复：建立两级流程，先按高置信阈值筛候选，再由人工逐条判定；记录确认率，供阈值调参使用。

小结

  • R2RIE-CE 在 R2R-CE Val Unseen 上注入五类指令错误，配对协议为 ΔSR = (SR(EC) − SR(EP)) / SR(EC)，冻结策略的摘要口径为最多约 25%（预实验），表 II 的最大项 All（带常识）为 30.64%（两个口径的来源见第 3 小节）。
  • 类型差异有结构性：方向错误 18.64% 远大于物体错误 8.47%；Room&Object 的 11.47% 低于两者之和 15.13%；All 的 30.64% 是方向错误的 1.644 倍。
  • 检测与定位是两个任务：IEDL 平均 AUC 0.79、平均 ATD 7.71；CLIP 基线平均 AUC 0.59、ATD 9.22，且在物体定位上局部更优。
  • 同一方法可用于数据质检：R2R-CE 标记 25 条、确认 8 条；RxR-CE 标记 118 条、确认 10 条；自动筛查必须配合人工复核与阈值记录。
  • 引用纪律：表 I 的 episode 数与 Val Unseen 不同口径；相对降幅与百分点要分别标注；成功判定按第 048 讲协议核对停止条件。
