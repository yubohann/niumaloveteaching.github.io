第五篇 · 基础模型与 2026 前沿

第 086 讲｜NavCoT：可学习导航思维链

本讲把思维链从提示技巧改造成训练目标：Lin 等 2024 的 NavCoT（arXiv:2403.07376v2，TPAMI 2025）用「未来想象、信息过滤、动作预测」三段式标签，指导语言模型在域内数据上做参数高效微调。R2R val-unseen 上，7B 开源模型加 1.6M 可训练参数取得 SR 36.40、SPL 33.17，补入 12k 增广样本后升到 SR 40.23、SPL 36.64，单步推理 0.5 秒。学完能构造导航思维链监督数据、写出三段式训练目标，并判断这类方法何时值得使用。

  • 主题：语言模型导航 / 可训练思维链 / 参数高效微调
  • 关键数字：可训练参数 1.2M 与 1.6M；R2R val-unseen SR 36.40→40.23、SPL 33.17→36.64；单步 0.5 秒对 9.8 秒
  • 预计学时：60 分钟
  • 前置讲：第 085 讲（DiscussNav：多专家讨论）

学习目标

  • 会算：三段式思维链的训练目标、候选观察描述在上下文中的占比、域内微调相对零样本提示的成功率与路径效率增量。
  • 会解释：世界模型视角下「未来想象、信息过滤、动作预测」的先后关系，以及为什么把想象约束在指令地标集合内。
  • 会实现：思维链监督标签构造、受限格式提示组装与动作解析、参数高效微调与两阶段损失三段示意代码。
  • 会判断：一组语言模型导航结果里，哪些增量来自思维链训练、哪些来自增广数据或主干规模，并给出成组报告方式。
  • 会设计：针对新指令集构造思维链标签的流程，以及把三段推理拆开做消融实验的方案。

背景与动机

第五篇前几讲把语言模型引入导航的方式以提示为主。NavGPT（Zhou 等 2023，arXiv:2305.16986）把全景观察写成文本让 GPT-4 逐步推理；DiscussNav（Long 等 2023，arXiv:2309.11382）让多个专家角色讨论后再决策；MapGPT（Chen 等 2024，arXiv:2401.07314）把地图写进提示词。它们的共同短板在训练分布：模型在网页语料上长大，导航任务的语言与决策格式都不在其原生分布内，于是推理链格式漂移、噪声过滤缺位、单步成本高。第 085 讲结尾留下的问题正是：多专家讨论提高了决策质量，代价是每步多次调用，能否把「怎么推理」直接教给模型。

NavCoT 给出一个直接的回答。它把人类导航时的心理模型翻译成三段可监督的推理：先根据指令想象下一个可能看到的物体或场景，再从候选观察中选出与想象最吻合的一个，最后依据前两步给出动作。论文（arXiv:2403.07376v2）的关键设计是让思维链拥有统一格式与真值标签，从而可以在域内数据上做参数高效微调，把域差从「提示弥补」改为「训练消除」。

本讲的定位是承上启下。第 085 讲处理「调用什么模型来讨论」，本讲处理「把推理写成可训练目标」；第 087 讲的 InstructNav 会把这套链式思想搬到连续环境，并用价值图把语言规划落到几何轨迹上。

核心原理

本节按「任务口径、思维链定义、标签构造、训练目标、参数高效机制、证据、边界」七步展开。所有评测数字来自 Lin 等 2024（arXiv:2403.07376v2），协议为 R2R val-unseen（成功判定为停止点距目标 3 米内），另有标注时除外。

1. 任务口径与两阶段决策

沿用第 005 讲的离散设定：时刻 t 的全景观察 Ot = {Ot,k}k=1..K 含 K 个单视角，其中 N 个可通行视角连同一个停止标记构成动作空间，智能体从中选 at。历史 Ht = {a0, …, at−1}。训练目标分两段：先在拆分后的子任务上做预训练，再在完整思维链上做模仿学习微调。这种「先分后合」的安排让每个推理环节的准确率先被单独抬高，再学习多步串联。

2. 三段式导航思维链

把每个时刻的推理写成三段有序输出，格式固定：

CoTt =（想象 Ut；过滤 Vt；动作 at） Ut 为未来想象（Future Imagination, FI），Vt 为视觉信息过滤（Visual Information Filter, VIF），at 为动作预测（Action Prediction, AP）

输出模板为三行：Imagination: U、Filtered observation: V matches the imagination、Action: a。FI 要求模型预测「下一步可能看到的物体或场景」，其作用是让后续过滤有可对齐的目标；VIF 显式在候选观察里指出与想象吻合的一项；AP 汇总前两步给出选项。论文用世界模型理论解释这一顺序：先建立对环境的心理预测，再据此筛选感官输入，最后行动。三段之间的依赖方向是单向的，想象质量决定过滤质量，过滤质量决定动作质量，这为消融实验提供了天然的断点。

一个训练目标的直观量级：设可通行视角 12 个，加停止标记共 13 个选项。若模型对所有选项无差别，交叉熵为 ln 13 = 2.565 奈特，换算 3.700 比特；三段式标签把「选哪个」拆成「想象什么、哪个最像、选哪个」，每一步的候选集合都被收窄，梯度信号更集中。

3. 监督标签构造：指令地标加视觉相似度

零样本输出有两个典型失败：过滤行写成与选项无关的描述；想象出指令并未提及的物体，把动作引向错误分支（论文图 3 给出两类案例）。修复办法是把标签约束成可计算的真值。对 FI，先用语言模型从指令 I 中抽出被提及的物体或场景，得到地标词表 Ula = {Ulak}k=1..M；再取真实执行动作对应的下一观测图像 B*t，在 CLIP 文本编码器与图像编码器之间做相似度最大化：

U*t = argmaxUlak Sim( FtCLIP(Ulak), FvCLIP(B*t) ) FtCLIP 与 FvCLIP 分别为 CLIP 文本、图像编码器；相似度取余弦

地标词表来自指令，想象因此被限制在任务相关集合内，这一约束同时缩小了标签空间、提高了跨模态对齐质量。VIF 与 AP 的真值直接取真实动作选项：过滤行要求写出「a*t 与想象吻合」，动作行要求写出 a*t。三段标签拼合后即为该时刻的完整思维链监督 CoT*t。

4. 训练目标：多任务预训练与模仿学习微调

预训练把三个推理环节视为三个独立任务，各自计算负对数似然再加和：

Lp = LFI + LVIF + LAP，其中每项形如 L = −y* log pLLM(y | I, H, D) D 为单步的文本化观察；y 为对应环节输出；三个任务共享同一主干与提示模板

微调阶段换成对完整思维链的序列损失，训练模型按「想象、过滤、动作」的顺序自回归地逐步决策：

Lf = − Σt CoT*t · log pLLM(CoTt | I, Ht, Dt) 求和遍历轨迹内所有决策时刻；监督信号覆盖三段完整输出，学习多步串联

论文的消融给出了分工证据（R2R val-unseen 子集，90 条指令-轨迹对、来自 8 个场景）：仅预训练时，三任务组合的 SR 11.11、SPL 4.01；预训练加微调后升到 SR 30.00、SPL 28.23；只保留动作预测的变体在微调后 SR 21.11、SPL 14.82。两阶段分工不同：预训练已把各推理环节的可达信号抬到较高水平（OSR 32.22），微调对成功与效率的贡献更大（SR 11.11→30.00、SPL 4.01→28.23，OSR 基本持平），报告时应分开。

5. 参数高效微调：两套轻量方案

把 7B 语言模型全参微调在单机环境代价过高，论文采用两种轻量方案。LLaMA-Adapter 在 LLaMA 1 上引入可学习适配提示与零初始化门控注意力，可训练参数 1.2M，占 7B 的 0.017%；LLaMA 2 7B 采用偏置微调，可训练参数 1.6M，占 0.023%，两者比值 1.33。导航域适配只动了模型参数量的万分之二量级，说明域差不总是需要重训主干来消除。训练配置为 4 张 V100、批大小 8、学习率 0.001、权重衰减 0.02，整程约 10 小时；推理在单张 V100 上完成。

6. 证据：三档配置的读数

先看与纯提示方法的对照（R2R val-unseen，语言模型主干）：NavGPT（GPT-4）SR 34.00、SPL 29.00、OSR 42.00、NE 6.46 米。NavCoT 接 LLaMA 2 7B、不加增广数据：SR 36.40（加 2.40 个点，相对 7.06%）、SPL 33.17（加 4.17 个点，相对 14.38%）、OSR 43.98、NE 6.67 米。补入 12k 增广样本后：SR 40.23（相对 +18.32%）、SPL 36.64（相对 +26.35%）、OSR 48.11、NE 6.26 米。单步推理时延，GPT-4 约 9.8 秒，NavCoT 约 0.5 秒，相差 19.6 倍。

第二个对照是子集上的提示设计（90 条指令-轨迹对）：GPT-4 配原始思维链提示 SPL 12.33；LLaMA 2 零样本 SPL 1.85；NavCoT 微调后 SPL 48.69，比原始思维链提示高 36.36 个点，比同主干零样本高 46.84 个点。另有「语言模型生成想象加 CLIP 匹配」的变体 SPL 29.14，低于完整微调，说明动作决策还需要历史与方向等综合信息。

跨数据集结果同样成立。RxR 英文子集（val-unseen，CLS 与 nDTW 为指令保真指标）：NavCoT 对直接动作预测，SR 24.52 对 20.46（相对 +19.84%）、SPL 22.58 对 18.68（相对 +20.88%）、CLS 45.06 对 37.19、nDTW 38.94 对 33.64。REVERIE 远程物体任务：SR 9.20 对 3.12、OSR 14.20 对 7.36、SPL 7.18 对 1.74。需要同时看到上限：同表里跨模态专用模型 HAMT 复现的 RxR SR 38.26、SPL 36.23，语言模型路线仍有明显距离。

7. 边界与失效模式

  • 监督标签依赖真值观测。想象标签用「真实执行动作对应的下一观测」与地标做匹配，训练期可得，评测期不可得。部署时模型自行生成想象，错误想象会沿链条传下去，这是误差累积的来源。
  • 文本化观察的信息瓶颈。视觉经描述器压成文本，细节与空间关系受损；描述器换域（仿真到真实、白天到夜间）后分布漂移，需要重测。
  • 域内训练的数据规模决定上限。不加增广的增益有限（SR +2.40），补 12k 样本后增益扩大（SR +6.23），说明此路线对标注与近邻数据供给敏感。
  • 离散动作空间的预设。方法以选项字母为单位，天然面向图上的离散决策；连续环境需要额外接口（第 087 讲正是这条线的推进）。
  • 子集数字不能与全量混比。子集 90 条、8 场景的 SR 可达 53.33，全量为 36.40 至 40.23，协议不同、方差更大，引用时必须标注。

实现思路与设计

把方法落成系统需要四样东西：视觉到文本的描述器、思维链标签构造器、两阶段训练循环、受限格式的推理与解析。目标是让推理格式稳定、标签可复算、训练代价可控。

数据流

  1. 观察描述：对每个候选视角用图像描述模型生成一句话，与方向标签（六个基本方向）拼接成选项文本，并附选项字母。
  2. 标签构造：从指令抽地标，按上节公式选想象真值；过滤与动作真值取自行走的真实动作。
  3. 预训练：三任务分别成样本，共享主干与提示模板。
  4. 微调：以完整思维链为序列目标，学习逐步串联。
  5. 推理：固定示例加当前输入组成提示；解析动作行；解析失败回退停止，避免无效动作卡死。

方案取舍

方案监督形式代价选择判据
零样本提示（NavGPT 类）无，靠提示与模型先验每步高成本调用，格式不稳定快速原型、无可训练数据时
直接动作预测微调只监督动作选项训练便宜，可解释性弱只关心成功率、不排查推理错误的场景
三任务预训练加微调（NavCoT）三段完整标签需构造标签，训练约 10 小时（4×V100）需要可解释中间推理、希望域内适配时
跨模态专用模型图到图或图到动作的大规模预训练数据与算力最高追求绝对指标、评测域与训练域接近时
设计决策：让思维链可验证，再谈可学习

三段式之所以能训练，前提是每一步都有可计算真值：想象来自地标集合与图像相似度，过滤与动作来自真实动作。缺少可验证标签的思维链只能停留在提示工程。先定义可验证的中间变量，再投入训练预算，是本讲最可迁移的工程原则。

关键代码与解读

三段代码分别给出思维链标签构造、提示组装与解析、参数高效训练目标。示意实现，接口按论文与公开实现的设计抽象。

片段 1：思维链监督标签构造

import torch
import torch.nn.functional as F

def build_cot_label(landmarks, gt_img_feat, gt_action, clip):
    """landmarks 为 LLM 从指令中抽出的地标词表；gt_img_feat 为真实下一观测特征。"""
    text_feat = clip.encode_text(clip.tokenize(landmarks))   # (M, C)
    img_feat = F.normalize(gt_img_feat, dim=-1)              # (1, C)
    sims = F.normalize(text_feat, dim=-1) @ img_feat.T       # (M, 1)
    u_star = landmarks[int(sims.argmax())]                   # 与真值观测最接近的地标
    return (f"Imagination: {u_star}. "                       # 第一段：受指令约束的想象
            f"Filtered observation: {gt_action} matches the imagination. "  # 第二段
            f"Action: {gt_action}")                          # 第三段：动作真值

解读：（1）想象真值被限制在指令地标词表内，标签空间缩小且与任务对齐。（2）相似度在归一化特征上做内积，等价于余弦相似度，避免幅值影响。（3）三行拼接的字符串即微调阶段序列损失的目标，格式统一便于批量构造。（4）地标抽取失败时应对该时刻打标记并跳过，避免把空词表喂进 argmax。

片段 2：提示组装与动作解析

import re

def build_nav_prompt(instruction, obs_options, history, cot_example):
    """obs_options 为 (选项字母, 描述) 列表；cot_example 为固定三行示例。"""
    options = " ".join(f"{c}. {d}" for c, d in obs_options)
    query = (f"Input: Instruction: {instruction} "
             f"Observation: [{options}] History: {history} Output:")
    return cot_example + " " + query

def parse_action(generation, valid_letters):
    """只接受模板内的动作行；解析失败时回退停止动作，保证闭环可继续。"""
    m = re.search(r"Action:\\s*([A-Z]|stop)", generation)
    if m and m.group(1) in valid_letters:
        return m.group(1)
    return "stop"

解读：（1）示例与查询拼接的顺序固定，训练与推理共用同一模板，减少分布错位。（2）正则只认动作行，模型在想象或过滤行写错内容时不会误解析。（3）回退到停止是一种保守策略；若任务不允许提前停止，应改为回退到最高似然的可通行选项并记录异常率。

片段 3：参数高效微调与两阶段损失

def freeze_except_peft(model):
    """只训练适配提示或偏置项，主干保持冻结。"""
    for name, param in model.named_parameters():
        param.requires_grad = ("adapter" in name) or name.endswith("bias")
    n_train = sum(p.numel() for p in model.parameters() if p.requires_grad)
    return n_train                              # 实测 1.2M 或 1.6M

def navcot_pretrain_loss(step_losses):
    """三任务分别计算负对数似然后求和，先抬高各环节准确率。"""
    return step_losses["imagination"] + step_losses["filter"] + step_losses["action"]

def navcot_finetune_loss(step_losses):
    """微调阶段对完整思维链序列计算损失，学习多步串联决策。"""
    return step_losses["full_cot"]

解读：（1）冻结主干后，可训练参数只占 7B 的万分之二量级，单机多卡即可完成。（2）预训练与微调的损失形状不同：前者是三项和，后者是单序列项，切换时需重建数据加载器。（3）判断是否需要切换的实用信号是验证集上的 OSR 与 SR 走势：OSR 先动、SR 后动，说明预训练已把「可达」学会，可以进入串联阶段。

常见误区

  • 零样本输出格式漂移。症状：模型输出环境描述，动作行缺失，闭环中断。根因：提示未约束输出结构，且主干语料缺少导航格式。修复：用三行模板做域内训练，推理端加正则解析与回退策略（论文图 3 即为该失败的两类样例）。
  • 想象标签超出指令范围。症状：模型学会想象指令未提及的物体，动作被引向无关分支。根因：标签构造未受约束。修复：先抽指令地标，再用 CLIP 从地标集合中选真值，把想象空间锁在任务相关集合内。
  • 子集数字与全量数字混用。症状：引用 53.33% 的 SR 与 36.40% 的 SR 做对比。根因：子集只有 90 条指令-轨迹对、来自 8 个场景，方差远大于全量。修复：报告标注子集规模与来源场景数，跨协议数字只做趋势判断。
  • 把增益全部归因给思维链。症状：宣称思维链带来十几个点提升。根因：把增广数据与主干升级的贡献合并计入。修复：按四档报告：零样本、直接动作预测、三任务微调、加增广；无增广与加增广的 SR 增量分别为 2.40 与 6.23，归因必须分列。
  • 训练与部署的描述器不一致。症状：仿真里推理稳定，换真实图像后错误率上升。根因：文本化观察依赖描述器，域漂移直接改变输入分布。修复：固定描述器版本，部署前用目标域图像重测描述质量，必要时替换并全量重训思维链标签。

练习与思考

  1. 增量核算：以 NavGPT 的 R2R val-unseen 为基线（SR 34.00、SPL 29.00、OSR 42.00），计算 NavCoT 无增广与加增广两档的绝对差与相对差，并说明哪部分增量应归因于数据增广。 ★
    提示
    无增广：SR +2.40（+7.06%）、SPL +4.17（+14.38%）；加增广：SR +6.23（+18.32%）、SPL +7.64（+26.35%）。两档之差（SR 3.83、SPL 3.47）来自 12k 增广样本与训练配置，归因时须与三任务微调分开报告。
  2. 上下文预算：设指令 30 token、13 个选项每项 16 token、三段思维链输出约 15 token、直接动作输出 2 token。(a) 计算两种输出的上下文总量；(b) 思维链相对直接决策的上下文增幅；(c) 说明为什么 19.6 倍的时延差不能归因于 token 数。 ★
    提示
    (a) 直接决策 30+13×16+2 = 240；思维链 30+13×16+15 = 253。(b) 增幅约 5.42%。(c) 选项描述占上下文约 86.67%，思维链新增 token 很少；时延差主要来自模型规模与调用服务，说明成本核算要区分 token 与调用。
  3. 损失设计：预训练损失为三段负对数似然之和，微调损失为完整序列损失。(a) 说明两种损失对参数更新的作用差异；(b) 若只保留动作预测一项做预训练，按消融表预测哪项指标掉得最多；(c) 给出一次「预训练轮数加倍」的对照实验设计，并说明观察哪条曲线判断收益是否饱和。 ★★
    提示
    (a) 三项和分别抬高想象、过滤、动作三个环节，序列损失学习跨环节串联。(b) 只留动作预测时 SR 从 30.00 降到 21.11、SPL 从 28.23 降到 14.82，效率指标跌幅最大。(c) 固定微调配置不变，只改预训练轮数；观察验证集 OSR 先饱和还是 SR 先饱和，OSR 饱和后再加轮数收益有限。
  4. 标签审计：给定一条指令「走过玻璃门后在露台停下」，地标词表含「glass door」与「patio」。真值下一观测画面里玻璃门占画面左半、露台仅露出角落。(a) 讨论 CLIP 相似度选择可能出现的结果；(b) 给出两种降低错标的手段；(c) 说明错标沿链式推理传播的后果。 ★★
    提示
    (a) 单一整图相似度可能被大面积区域主导，露台地标可能被漏选。(b) 可对图像分块后取最大相似度，或对地标做同义扩展并结合历史动作过滤。(c) 想象错则过滤行指向错误选项，动作错误率上升；三段监督的断点允许只回改想象标签后重训定位问题。
  5. 系统设计：为新采集的 5 千条指令-轨迹对（含 20 个新场景、连续控制执行）设计一条迁移路线。要求 (a) 说明离散选项接口如何从连续控制轨迹导出；(b) 设计标签构造流水线与质检规则；(c) 给出预训练与微调的数据划分及三段消融；(d) 预测哪项指标最可能先受益，并给出验收阈值。 ★★★
    提示
    (a) 在每个决策点把可通行方向离散为若干候选视角，动作表示为候选字母加停止。(b) 地标抽取加 CLIP 匹配，质检抽 5% 人工核对想象标签与动作一致性。(c) 预训练用全部样本的三任务拆分，微调用完整序列；消融去掉 FI 或 VIF 各跑一组。(d) OSR 最可能先动（可达性先改善），验收看 SR 与 SPL 是否同步超过直接动作预测基线，幅度若低于 2 个点则检查标签质量。

小结

  • NavCoT 把导航推理定义为三段可监督的思维链：未来想象、信息过滤、动作预测；格式统一，标签可计算，因而可训练。
  • 标签构造的关键约束是把想象限制在指令地标集合内，用 CLIP 图像与文本相似度选真值；过滤与动作真值取真实执行动作。
  • 训练采用参数高效两阶段：三任务预训练把 SR 从 11.11 抬到 30.00（子集口径），完整思维链微调把 SPL 从 4.01 抬到 28.23；主干只动 1.2M 至 1.6M 参数，占 7B 的万分之二量级。
  • R2R val-unseen 上相对 GPT-4 提示基线：无增广 SR +2.40、SPL +4.17；加 12k 增广后 SR +6.23、SPL +7.64；单步 0.5 秒对 9.8 秒，相差 19.6 倍。
  • 边界清晰：标签依赖真值观测、文本化观察有信息瓶颈、增益对增广规模敏感、面向离散动作空间。
