第二篇 · 离散方法谱系：从模块到预训练

第 034 讲｜HAMT：层级 ViT 与长程历史

本讲把历史从“压成一个状态向量”改为“保留每一步的全景摘要 token”：视图经共享 ViT 编码、全景内经空间 Transformer 聚合、历史上经时序 Transformer 建模，复杂度从全铺开的 O(t²K²) 降到 O(tK²+t²)；配合代理任务与强化学习微调，R2R test unseen 达到 65% SR / 60% SPL，回程任务 R2R-Back 相对循环基线提升 16.1 个百分点。

  • 主题：层级 ViT / 长程历史 / 代理任务 / 端到端视觉编码
  • 关键公式：复杂度 O(tK²+t²) 对比 O(t²K²)；K = 36、NL = 9、Nh = 2、Nx = 4
  • 预计学时：60 分钟
  • 前置讲：第 033 讲（Airbert / BnB：域内数据工程）

学习目标

  • 会写：HAMT 三段编码（单视图 ViT、全景空间聚合、历史时序建模）的输入输出与张量形状，能写出跨模态融合的 token 构成。
  • 会算：层级、全铺开、仅时序三种历史编码的复杂度与序列长度，能按 K、t、层数实算评分次数与显存量级。
  • 会实现：层级历史编码的前向传播，以及单步动作预测与空间关系预测两个代理任务的损失。
  • 会判断：两阶段端到端训练与强化加模仿微调的配合方式，说明冻结 ViT、解冻 ViT、RL+IL 各自的收益与代价。
  • 会诊断：历史长度、全景视图数、停止 token、掩码与特征版本五类实现问题，能给出检查清单。

背景与动机

第 032 讲把历史压进一个状态 token，换来常数级显存，代价是早期记忆随步数衰减；论文以“把勺子带回来”这类需要记住起点的指令说明瓶颈所在。第 033 讲补齐了域内预训练数据，但历史建模方式没有变化。本讲处理显式历史路线：把每一步的全景摘要都保留下来，用层级结构控制计算量，相关工作为 HAMT（Chen 等 2021，NeurIPS 2021，arXiv:2110.13309v2）。

显式历史的第一版方案是“全铺开”：把每步的 36 张视图全部 token 化后拼成一个长序列。该方案能建模任意两张视图之间的关系，代价是序列长度随步数倍数增长，注意力评分次数按步数平方乘视图数平方增长。第二版方案是“仅时序”：每步只取智能体正朝向的那张视图参与历史，序列短，却丢掉侧后方的视觉证据；论文举的例子里，指令提到“左侧的窗户”时，窗户可能从未出现在朝向视图中，仅时序历史无法判断智能体是否已经走过它。

HAMT 选择折中：先在每步内部用 ViT 加全景 Transformer 把 36 张视图聚合为少量全景 token，再在历史上用时序 Transformer 建模。复杂度从 O(t²K²) 降到 O(tK²+t²)，保留全部视角信息。论文把该结构描述为第一个全 Transformer 的 VLN 架构并经端到端训练，同时用代理任务赋予视觉编码器任务相关的表示。结果上，R2R test unseen 达到 65% SR / 60% SPL；在长程任务上收益更大：R2R-Back 的 val unseen SR 相对循环基线提升 16.1 个百分点，R4R 的路径保真指标 CLS 提升 6.3。

本讲的产出是一张张量维度全链路推演表：从一个 224×224 视图到一个候选动作分数，中间每个张量的形状与含义都要能写出来。这是读懂后续 DUET、BEVBert、GridMM 等地图与记忆方法的基础。

核心原理

本讲按“输入表示、三段历史编码、跨模态融合、代理任务、训练流程、结果与边界”展开；核心数字先实算后写入，论文结果标注 HAMT（Chen 等 2021，NeurIPS 2021）与协议。

1. 输入表示：角度嵌入、类型嵌入与停止 token

文本、历史与当前观测先各自经过单模态 Transformer。文本编码沿用 BERT 结构：词嵌入、位置嵌入与类型嵌入相加，经 NL = 9 层自注意力得到上下文表示 xi。观测编码对每张视图 [voi; aoi] 计算：

oi = LN(Wov voi) + LN(Woa EAaoi) + ENoi + ET1 EA = (sin θi, cos θi, sin φi, cos φi)，θ 与 φ 为相对智能体朝向的水平角与俯仰角；EN 为可导航类型嵌入（0 不可导航、1 可导航、2 停止）；ET1 为观测类型嵌入；两个 LN 用于平衡视觉与角度的量纲

停止动作的实现是在观测序列末尾追加一个 stop token，并给它类型嵌入 EN2；动作预测时 stop 与可导航视图在同一候选集中比较。K = 36 由 12 个水平朝向（间隔 30°）与 3 个俯仰角（±30°）构成，与第 032 讲循环模型的特征口径一致，都是全 36 视图；区别在本模型把每张视图当作图像 token，用 ViT 编码，走向与预抽取网格特征不同的技术路线。

2. 层级历史编码：从视图到全景再到时间

第 i 步的历史摘要由两次聚合得到。第一层，ViT 独立编码每张视图；第二层，全景 Transformer（Nh = 2 层）编码 36 张视图之间的空间关系，平均池化得到全景嵌入，并与智能体朝向视图的特征做残差相加；第三层，各步的全景嵌入按时序进入历史编码。时序 token hi 的构造与观测 token 同构：

hi = LN(Whv vhi) + LN(Wha EAahi) + ESi + ET2 vhi 为第 i 步全景嵌入；ahi 为该步执行动作的转镜角度；ESi 为步序嵌入，ET2 为历史类型嵌入；历史序列首部另加一个可学习的 [cls] token（零向量初始化）

ViT 与全景 Transformer 的参数在所有步之间共享，因此历史长度的增加不会带来参数增长，只带来注意力的计算增长。复杂度对比（单层评分数近似）：

3. 跨模态融合：双流结构与 token 构成

历史 token 与观测 token 拼接成视觉模态，文本单独为另一模态，经 Nx = 4 层跨模态 Transformer 融合。每层先做视觉与文本的互相交叉注意力，再做各自的自注意力与前馈网络。论文解释了采用双流结构、不用单流的原因：两种模态的长度高度不平衡（文本约 80 个 token，视觉约 40 至 140 个），双流结构可以通过设计分别平衡模态内与模态间的关系强度。

最终融合序列的 token 构成可以写成：文本 L + 1 个（含 [cls]）、历史 t + 1 个（含历史 [cls]）、观测 K + 1 个（含 stop）。为与前面的复杂度表口径一致，下面的评分实算不计两个 [cls]：L = 80、K = 36 时，t = 10 共 127 个 token，评分 16,129 次；t = 20 共 137 个 token，评分 18,769 次（若计入两个 [cls] 则为 129 与 139 个）。若把历史全铺开，t = 20 时该项会变为 801 个 token、641,601 次评分，与层级的比值为 34.18。结论二：层级设计不仅服务历史编码器，也让最终跨模态融合的序列长度与步数近似线性。

4. 代理任务：五个目标与它们教给模型的东西

训练前两阶段使用代理任务（proxy tasks），让单模态与跨模态表示先获得任务相关结构，再交给强化学习。五个目标的作用不同：

任务监督信号教什么
掩码语言建模（MLM）被掩码词元的预测指令内部的语言上下文
掩码区域建模（MRM）以 ImageNet 千类分类为目标，最小化两个分布之间的 KL 散度被掩码视图的视觉连续性与指令相关性
指令-轨迹匹配（ITM）1 正 4 负的对比损失，负样本 2 个批内错配、2 个时序打乱跨模态对齐与时序敏感
单步动作预测与回归（SAP/SAR）分类：在可导航视图中选教师动作；回归：预测动作的朝向与俯仰角直接塑造策略
空间关系预测（SPREL）随机把视觉特征或角度特征以 0.3 概率置零，预测两张视图之间的相对角自监督的空间关系推理

单步动作预测的写法与全景动作空间一致：对每个可导航视图 oi，用文本 [cls] 与视图特征的逐元素乘积分类：

pt(oi) = exp( fSAP(oi ⊙ xcls) ) / Σj exp( fSAP(oj ⊙ xcls) )，LSAP = − log pt(o*) fSAP 为两层全连接；⊙ 为逐元素相乘；oj 遍历可导航视图与 stop token；o* 为教师动作

空间关系预测则取同一全景内的两张视图，预测它们的相对水平角与俯仰角，损失为两项平方误差之和：LSPREL = (θ̂ij − θij)² + (φ̂ij − φij)²。该任务不需要任何人工标注，属于自监督信号，训练数据是观测本身。消融显示，在冻结 ViT 的设置下，动作预测把 val unseen SR 从 62.8 提到 63.6，加入空间关系预测再提到 64.4。

5. 训练流程：两阶段端到端加混合微调

训练分三步。第一步用代理任务训练整套模型但冻结 ViT，避免随机初始化的其余模块反向破坏 ImageNet 预训练权重；配置为 200,000 次迭代、批 64、学习率 5×10−5，4 张 P100 约 1 天。第二步解冻 ViT 端到端训练，学习率对 ViT 用 5×10−5、其余模块用 1×10−5（论文解释：ViT 学习率更高是为了避免梯度消失并加速收敛），20,000 次迭代，20 张 V100 约 20 小时。第三步用 RL+IL 微调策略：A3C，批 8，学习率 1×10−5，100,000 次迭代，单卡；模仿权重 λ = 0.2，折扣 γ = 0.9；单模态编码器默认冻结。奖励沿用 EnvDrop 系设计：非停止动作按到目标的距离增减给回报，停止动作为到达 3 米内 +2、否则 −2，另叠加与专家路径的对齐分数。

微调目标的消融说明了配合关系（val unseen SR/SPL）：只用代理任务不微调为 51.8 / 48.9；仅模仿为 57.2 / 54.7；仅强化为 63.5 / 57.5；强化加模仿为 65.7 / 60.9。结论三：代理任务先稳住表示，强化负责探索，模仿负责稳定，三项缺一不可。

训练数据用 R2R 训练集与 PREVALENT 的增广对（延续第 030、033 讲的增广线）；RxR 任务改用多语言 BERT 初始化语言编码器，并使用编码器-解码器变体降低长指令的融合开销。推理用贪心解码、单次运行，不集成、不预探索。

6. 结果：全面指标与消融

R2R 单次运行结果（HAMT 对 RecBERT）：val seen 为 76 / 72 对 72 / 68；val unseen 为 66 / 61 对 63 / 57；test unseen 为 65 / 60 对 63 / 57，NE 3.93 米对 4.09 米，TL 12.27 米对 12.35 米。论文报告相对 RecBERT 在 val seen 与 val unseen 的 SPL 上分别有 5.9% 与 7.0% 的相对提升。

7. 计算账与推理时间

推理在 R2R val unseen 的 2,349 条指令上实测（单张 P100，两次平均）：RecBERT 69 秒，HAMT 104 秒，去掉文本到视觉注意力的 HAMT noT2V 为 76 秒。折合每条指令 29.4、44.3、32.4 毫秒，HAMT 与 noT2V 分别是 RecBERT 的 1.5 倍与 1.1 倍。noT2V 在更省时的同时仍保持 val unseen SR 65 / SPL 60，高于 RecBERT 的 63 / 57。论文据此说明，保留全部历史并不必然带来推理时间的大幅膨胀，因为历史 token 数远小于全铺开方案。

维度链路实算（以 ViT-B/16、224×224 输入为例）：每张视图 14×14 个 patch 加 1 个 cls，共 197 个 token；一个全景 36 张视图为 7,092 个 token；若把 t = 20 的历史按视图全铺开缓存，张量规模为 20 × 7,092 × 768 × 4 字节 ≈ 0.41 GiB。层级方案只在历史中保留每步 1 个全景 token，t = 20 的历史矩阵（含 [cls]）为 21 × 768 × 4 字节 ≈ 63.0 KiB。结论四：层级设计同时压缩了计算量与中间张量的存储量，代价是多一次全景内的局部注意力。

8. 适用边界与失效模式

  • 历史长度仍然受限：模型理论上保留全部历史，实际训练中步数上限与显存决定有效窗口；步数极长时，时序注意力的成本与全景编码的重复计算都会显现。
  • 36 视图口径与课程 12 视角特征不可混用：本模型输入的是图像块，课程其他方法常用 12 视角乘 2048 维预抽取特征；两者 token 数、角度编码与类型嵌入都不同，替换时需整体重建。
  • 端到端 ViT 的跨任务代价：R2R 上优化的视觉表示在 REVERIE 接地任务上不如检测数据预训练的物体特征，跨任务迁移要重新评估。
  • 协议特定的设定：R2R-Last 与 R2R-Back 是论文提出的新设定，指令与专家路径都经改动，不能与标准 R2R 数字同表比较。
  • 不涉及连续环境：全部实验在离散导航图上完成；移植到 R2R-CE 需要重新设计动作头与控制接口，见第三篇。

设计决策：历史 token 化，但把空间关系留在步内

层级设计的关键分工是：步内的视图组合交给全景 Transformer 一次算完，跨步的时序关系只在全景摘要之间建模。这样做的判据是“空间关系的时效性”：同一时刻的视图关系在后续步骤里很少需要重新解析，而不同时刻的关系才是长程任务的核心。若把两者混在一个平面上（全铺开），计算量按视图数的平方放大；若只留朝向视图，空间证据丢失。三档消融的 SR 差距（52.2、53.2、54.4）说明两层信息都有价值，层级方案在成本与收益之间取到了最优点。

与前后讲的衔接：第 032 讲提供循环状态基线与预训练接口；第 033 讲提供域内预训练数据与增广；本讲验证显式历史的收益边界。下一讲 HOP 引入历史与顺序的预训练目标，把“历史该记住什么”从结构问题推进到监督信号问题。

关键代码与解读

三段代码分别给出层级历史编码的前向传播、动作与空间关系的代理损失、复杂度与张量的核算脚本。接口以公开实现的设计为参照，版本演进时以仓库为准。

片段 1：层级历史编码

import torch
import torch.nn as nn

class HierarchicalHistory(nn.Module):
    """视图 ViT 与全景 Transformer 参数跨步共享；历史只保留全景摘要 token。"""
    def __init__(self, vit, hidden=768, n_pano=2):
        super().__init__()
        self.vit = vit
        self.pano = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(hidden, nhead=12, batch_first=True), n_pano)
        self.pool = nn.AdaptiveAvgPool1d(1)      # 36 个视图 token 池化为 1 个
        self.hist_proj = nn.Linear(2 * hidden, hidden)
        self.pano_cls = nn.Parameter(torch.zeros(1, 1, hidden))   # 历史 [cls]，零向量初始化

    def encode_step(self, views, act_angle):
        b, k = views.shape[:2]
        tok = self.vit(views.flatten(0, 1))      # (B*K, 197, hidden)
        tok = tok[:, 0]                          # 取每张视图的 cls 特征
        tok = tok.view(b, k, -1)
        pano = self.pano(tok).mean(dim=1)        # 步内空间关系聚合
        pano = pano + tok[:, 0]                  # 朝向视图残差（此处以第 0 张示意）
        return self.hist_proj(torch.cat([pano, act_angle], dim=-1))

    def forward(self, views_seq, angles):
        # views_seq: (B, t, K, 3, 224, 224)；输出 (B, t, hidden) 后再加步序与类型嵌入
        steps = [self.encode_step(views_seq[:, i], angles[:, i])
                 for i in range(views_seq.size(1))]
        hist = torch.stack(steps, dim=1)
        cls = self.pano_cls.expand(hist.size(0), 1, -1)   # 零向量初始化的历史 [cls]
        return torch.cat([cls, hist], dim=1)

解读：（1）ViT 在全景维度展平后一次性前向，36 张视图共享权重；历史循环只遍历步数 t，不重复遍历视图。（2）池化加朝向视图残差对应论文的“平均池化全景嵌入 + 朝向视图残差”设计。（3）真实实现需为不同步数与不同候选数的样本加时间掩码与视图掩码，并把无效位置排除出池化；pano_cls 为可学习参数，论文以零向量初始化。

片段 2：单步动作与空间关系损失

import torch
import torch.nn as nn
import torch.nn.functional as F

hidden = 768
action_head = nn.Sequential(nn.Linear(hidden, hidden), nn.GELU(), nn.Linear(hidden, 1))
rel_head = nn.Sequential(nn.Linear(2 * hidden, hidden), nn.GELU(), nn.Linear(hidden, 2))

def sap_loss(obs_emb, text_cls, expert_idx, navigable_mask):
    """单步动作预测：文本 [cls] 与候选视点逐元素相乘后分类。"""
    fused = obs_emb * text_cls.unsqueeze(1)          # (B, n+1, hidden)
    logits = action_head(fused).squeeze(-1)          # 两层 MLP 打分
    logits = logits.masked_fill(~navigable_mask, float("-inf"))
    return F.cross_entropy(logits, expert_idx)       # stop token 也在候选集中

def sprel_loss(view_emb, angles_ij, drop_prob=0.3):
    """空间关系预测：以 drop_prob 置零视觉或角度，回归相对角。"""
    vis, ang = view_emb["vis"], view_emb["ang"]
    vis = F.dropout(vis, p=drop_prob, training=True)
    ang = F.dropout(ang, p=drop_prob, training=True)
    pred = rel_head(torch.cat([vis, ang], dim=-1))   # (B, 2) 预测水平角与俯仰角
    return ((pred - angles_ij) ** 2).sum(dim=-1).mean()

# 组合损失：L = L_SAP + L_SPREL + L_MLM + L_MRM + L_ITM

解读：（1）动作预测用逐元素相乘，避免直接拼接，迫使文本向量与视图向量在同一坐标上对齐后再打分，与 032 讲的状态精炼同源。（2）masked_fill 把不可导航候选排除，但保留 stop token 参与比较，这是停止判定的实现要点。（3）空间关系预测的置零概率 0.3 迫使模型在缺少视觉或角度任一时仍能推断关系，属于自监督正则；回归目标是相对角的正余弦编码更稳，示例用原始角简化。

常见坑

  • 每步重跑 ViT 编码历史视图：训练时间随步数平方增长，显存也随历史累积。根因：把“保留历史 token”误实现为“重算历史特征”。修复：每步只编码当前全景，历史保存全景摘要 token；或使用梯度检查点，并保证 ViT 与全景 Transformer 的共享权重只训练一份。
  • 36 视图口径与 12 视角特征混用：角度编码、可导航类型嵌入与 stop token 全部错位，损失下降但指标不升。根因：换了输入表示却没有重建观测编码器。修复：统一 token 数与角度约定，特征来源写入实验记录；跨表示迁移时只迁移语言与融合部分，视觉编码重训。
  • 停止 token 遗漏或类型嵌入错位：模型永不停止或首步停止。根因：观测序列末尾没有追加 stop，或 EN 的三类取值用错。修复：写单测检查候选集包含 stop、掩码不覆盖 stop、停止后轨迹正确终止。
  • 历史掩码与步序嵌入处理错误：短 episode 被填充污染，长 episode 的步序编码溢出。根因：不同样本的历史长度不等，注意力掩码与步序索引没有按有效长度生成。修复：按有效步数构造掩码，步序嵌入只对真实步编号；评测时确认填充不参与池化与注意力。
  • 特征版本漂移：训练用端到端 ViT，评测误用冻结特征，或反之。根因：特征提取版本没有写进配置。修复：把视觉骨干的冻结状态、权重版本与输入分辨率写入实验记录；比较方法时先对齐此项再比指标。

练习与思考

  1. 维度链路推演：取 ViT-B/16、224×224 输入、K = 36、L = 80、t = 20，写出视图 token 数、全景编码输出、历史序列长度与跨模态融合的总 token 数，并计算层级与全铺开两种融合的评分次数比。 ★
    提示
    每视图 197 个 token，36 视图池化为每步 1 个历史 token；历史含 [cls] 为 21 个，观测 37 个，文本 81 个，合计 139。按正文不计两个 [cls] 的口径为 80 + 20 + 37 = 137；全铺开约 801 个，评分次数比约 34 倍。
  2. 用复杂度公式计算 t = 40 时层级与全铺开的比值，并解释为什么论文观察到“轨迹越长，HAMT 相对收益越大”。 ★
    提示
    t = 40 时比值 38.80，说明全铺开方案随步数超线性变贵，层级方案让模型能在同等算力下利用更长历史；长程任务（R4R、R2R-Back）因此放大优势，R2R-Back SR +16.1 是直接证据。
  3. 把全景 Transformer 的层数从 2 改为 0（直接平均池化），预测 R2R 与 R2R-Back 两个任务上指标的变化方向，并设计消融验证；同时说明该改动对推理时间的影响。 ★★
    提示
    去掉空间关系建模后，侧后方线索的整合能力下降，长程任务跌幅应大于标准 R2R；推理时间下降有限（全景层只作用于 36 个 token）。消融固定其余结构，只改 Nh，报告 SR/SPL 与 nDTW。
  4. 实现 SPREL 的 0.3 置零机制，说明它为什么属于自监督任务，并分析置零视觉与置零角度两种情形分别逼模型学习什么能力。 ★★
    提示
    监督信号由数据自身几何关系提供，无需人工标注。置零视觉时模型必须依靠角度编码推断关系；置零角度时必须从视觉内容推断方位，两类能力分别对应对照描述与自我中心描述的理解。
  5. 设计一组长程历史消融实验：在 R2R-Back 设定下比较循环状态、仅时序与层级三种历史编码，要求 (a) 写出训练与评测配置（固定初始化、数据、迭代数）；(b) 预测 SR、SPL、nDTW、SDTW 四个指标的方向与相对幅度；(c) 核算三种方案的显存与推理时间差异；(d) 指出端到端 ViT 给结论带来的混淆因素并给出隔离办法。 ★★★
    提示
    (a) 三者共享预训练权重与数据，只换历史编码模块。(b) 层级在长程任务上 SR 与 SDTW 领先最多（论文附录：层级 56.5 对循环 41.1），仅时序居中。(c) 循环 O(t) 显存最低，层级居中，全铺开最高；推理时间按论文 69/76/104 秒量级排序。(d) 端到端 ViT 改善视觉表示本身，可用冻结 ViT 与端到端两组对照分离“历史结构收益”与“特征收益”。

小结

  • HAMT 用三段编码处理长程历史：单视图 ViT（参数跨步共享）、全景 Transformer（Nh = 2）、历史时序编码；停止动作由观测序列末尾的 stop token 承载。
  • 层级历史把复杂度从全铺开的 O(t²K²) 降到 O(tK²+t²)：K = 36 时，t = 20 的评分次数比 19.70，t = 40 为 38.80；跨模态融合的 token 数约为 137 对 801。
  • 代理任务（MLM、MRM、ITM、SAP/SAR、SPREL）先塑造表示，再解冻 ViT 端到端训练，最后用 A3C 强化加模仿（λ = 0.2，γ = 0.9）微调；三步消融显示 54.4 到 63.5 到 65.7 的逐级提升。
  • R2R test unseen 达到 65% SR / 60% SPL、NE 3.93 米；长程任务收益更大：R2R-Back val unseen SR 57.2（对照 41.1），R4R CLS 57.7（对照 51.4），RxR test SR 53.12。
  • 推理时间可控：val unseen 全集 104 秒对 RecBERT 69 秒（1.5 倍），去掉文本到视觉注意力后 76 秒（1.1 倍）且指标仍更高；历史缓存从全铺开的 0.41 GiB 降到约 63.0 KiB。
