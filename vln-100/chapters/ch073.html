第四篇 · 规模、记忆与泛化方法论

第 073 讲｜训练策略：IL / RL / DAgger

第 029 讲讲过一条混合训练配方，本讲把三种训练范式的适用面摊开：模仿学习在 EnvDrop 的从零骨干上成功率 43.6%，纯强化学习跌到 24.0%（平均路径 73.8 米），而在预训练过的 HAMT 上强化学习反而比模仿高 6.3 个百分点。本讲用误差累积的简化推导、DAgger（Ross 等 2011）的数据聚合与无遗憾归约解释这两组结果，并给出预算核算与范式决策树。

  • 主题：模仿学习 / 强化学习 / DAgger / 曝光偏差 / 混合权重 / 奖励设计
  • 关键数字：误差累积界 εT(T+1)/2；β = 0.75n；每轮 5,000 条轨迹；λ = 0.2、γ = 0.9；EnvDrop IL 43.6 对 RL 24.0 对 IL+RL 46.5；HAMT IL 57.2 对 RL 63.5 对 IL+RL 65.7
  • 预计学时：60 分钟
  • 前置讲：第 072 讲（顺序建模深化）与第 029 讲（混合训练：IL + RL 两阶段）

学习目标

  • 会算：单步失误率 ε 在时程 T 上的误差累积上界与按步成功的概率，能说明为什么长轨迹对模仿学习更苛刻。
  • 会写：DAgger（Dataset Aggregation，数据集聚合）的轮次结构、混合系数 β 的作用与聚合数据的规模账。
  • 会实现：按 β 采样的 DAgger 轮次循环、模仿与强化混合损失的更新步骤、训练预算核算函数。
  • 会判断：在专家是否可得、奖励是否稠密、骨干是否预训练三个条件下选择 IL、RL 或 DAgger，并给出权重取值依据。
  • 会诊断：教师次优、奖励投机、停止动作坍塌、β 调度错误、离线数据陈旧五类问题。

背景与动机

第 021 讲确立了序列到序列基线与教师强制、学生强制的差别；第 029 讲以 EnvDrop 为例讲过模仿学习与强化学习的两阶段混合。本讲回答策略选择层面的问题：三种范式各自的成功条件是什么，为什么同一种强化学习在一个骨干上崩塌、在另一个骨干上反超模仿学习，以及 DAgger 的专家查询在仿真与真机上分别意味着什么。

两组数字给出问题轮廓。Tan 等 2019 的 EnvDrop（NAACL 2019，arXiv:1904.04195v1）在 R2R 验证未见集上：行为克隆 43.6% 成功率、平均路径 9.15 米；纯 A2C 强化学习 24.0%、平均路径 73.8 米，路径长度加权成功率 0.03；两者混合 46.5%、加权 0.43。路径长度 73.8 米说明纯强化学习在没有稠密引导时会长时间游走，成功率因此低于模仿学习近 20 个百分点。另一侧，Chen 等 2021 的 HAMT（NeurIPS 2021，arXiv:2110.13309v2）在预训练后微调，验证未见集上模仿 57.2%、纯强化 63.5%、两者混合 65.7%。同样的两类优化器，次序完全相反。

本讲的解释框架由三部分组成：曝光偏差（exposure bias）与误差累积解释了模仿学习何时失效；DAgger 的归约与数据集聚合解释了专家可查询时的修补方式；奖励稠密度、骨干质量与探索成本解释了强化学习的翻转条件。产出是一张范式决策树与一份预算核算表。

核心原理

本讲按「数据假设、误差累积、DAgger、VLN 实践、强化学习设计、证据对照、决策树、边界」展开。论文数字标注 EnvDrop（Tan 等 2019，NAACL 2019）与 HAMT（Chen 等 2021，NeurIPS 2021）；推导为本讲简化分析，界为最坏情形上界，精确常数不进入结论。

1. 三种范式的数据假设

把导航记为有限时程 T 的序贯决策，策略 π 的期望代价记为 J(π)，专家策略记为 π*。三个范式的差别集中在训练数据的分布与来源。

离散 VLN 的一个特殊条件让 DAgger 几乎零成本：导航图已知且确定，任意节点到目标的最短路可由仿真器随时计算，专家动作随处可得。这一条件在真机上不成立，第 021 讲已点明它是仿真内可用的强监督。

2. 误差累积：模仿学习的时程惩罚

行为克隆只保证在专家分布上每步失误率约 ε。推理时状态来自策略自身，一旦偏离，错误分布随之改变。做最坏情形估算：设每步失误概率 ε，一次失误后智能体离开专家走廊，额外代价至多等于剩余步数。期望额外代价为

J(π̂) − J(π*) ≤ ε·Σt=1T(T − t + 1) = ε·T(T + 1) / 2 = O(εT²) 最坏情形简化上界：每次失误对应剩余时程的额外代价，失误次数期望为 εT；该二次依赖是动机性分析，精确界与假设见 Ross 与 Bagnell 2010、Ross 等 2011

实算（单位取单步代价）：ε = 0.05、T = 10 时上界 2.75，T = 20 时 10.50，T = 55.88（R2R-CE 平均步数，Krantz 等 2020）时 79.46；ε = 0.10 时分别为 5.50、21.00、158.92。换成成功率口径，假设各步独立，全程无失误概率 (1 − ε)T：ε = 0.05 时 T = 10 为 0.5987、T = 20 为 0.3585、T = 55.88 为 0.0569；ε = 0.10 时降到 0.3487、0.1216、0.0028。同一单步失误率在短轨迹上可控，在连续环境的长轨迹上几乎必然出现。结论一：模仿学习的短板随时程放大，VLN-CE 一类平均 50 步以上的任务必须对训练分布做补丁，学生强制、DAgger 或强化学习都在补同一件事。

3. DAgger：把专家标注搬到学徒分布上

Ross、Gordon 与 Bagnell 2011 在 AISTATS 提出的 DAgger（PMLR 15:627–635）把模仿学习归约为无遗憾在线学习。论文指出的核心矛盾是：序贯预测中未来观测依赖过去的预测动作，独立同分布假设不成立；此前的 Forward Training 与随机混合迭代学习要么训练非稳态策略、要么训练随机策略，且迭代次数需求大。DAgger 的迭代结构如下。

步骤操作目的
初始化数据集 D 置空，初始策略 π̂1 可用行为克隆热身保证第一轮轨迹不离谱
第 i 轮采样用 πi = βiπ* + (1−βi)π̂i 采样 T 步轨迹覆盖学徒会到达的状态，β 控制专家介入比例
第 i 轮标注对访问到的每个状态查询专家动作 a* 并入 D把监督补到学徒分布上
第 i 轮训练在聚合数据集 D 上训练 π̂i+1早期数据不淘汰，防止灾难性遗忘
输出验证集上最优的策略选择验证集最优快照，不用最后一轮结果

理论侧，论文的归约结论为：在损失强凸、梯度有界、专家与学习器诱导分布的偏移有界的条件下，N 轮迭代后学习器的期望代价与专家代价之差以在线学习平均遗憾 RN/N 为上界，且策略保持确定与稳态（Ross 等 2011，第 4 节；常数依赖代价敏感度与分布偏移，完整形式见原文）。直观含义是：只要在线学习器每轮的遗憾增长慢于线性，聚合数据的策略就会收敛到专家水平。实践含义有两条。第一，βi 应按轮次递减，让学徒逐步接管动作、使训练分布向推理分布漂移；第二，专家必须在学徒自己诱导的状态上给出可靠动作，否则聚合数据会被系统性错误污染。

4. VLN 实践：学生强制、β 调度与伪专家

离散 VLN 的第一代做法是学生强制（student forcing）：上一步采用模型采样动作，标签对偏离后的位姿重新规划最短路径首动作。它在效果上等价于在线 DAgger，区别是每步都能免费取得标注（第 021 讲）。Krantz 等 2020 的 VLN-CE（ECCV 2020，arXiv:2004.02857v2）把 DAgger 写进连续环境配方：第 n 轮以 β = 0.75n 的概率执行专家动作、否则执行策略动作，每轮采集 5,000 条轨迹，随后在全部历史轨迹上做 4 轮模仿学习，重复 6 至 10 轮。实算 β 序列（n 从 1 计）：0.7500、0.5625、0.4219、0.3164、0.2373，前十轮均值 0.2831；每轮标注量 5,000 × 55.88 ≈ 279,400 步，6 轮约 167.6 万步、10 轮约 279.4 万步，分别是原始数据（约 4,475 条 × 55.88 ≈ 25.0 万步）的 6.70 倍与 11.17 倍。图形与网格方法则用伪交互演示者（Pseudo Interactive Demonstrator, PID）：演示者读真值图，在每个状态选“经该邻居到终点总距离最小”的动作，仿照 DAgger 在策略访问状态上继续监督（第 036、038、046 讲）。

三类实践的共同点是把“专家查询”抽象成可插拔接口：仿真内用重规划或真值图，真机上退化为人类确认或安全规则。DAgger 的成与败都取决于这个接口的可靠性。

5. 强化学习设计：奖励塑形与混合权重

EnvDrop 的强化分支使用优势演员-评论家（Advantage Actor-Critic, A2C）：智能体按策略采样动作，停止位置距目标 3 米以内给 +3、否则给 −3，非停止步给到目标距离的变化量作为稠密塑形。HAMT 用同类算法但把停止奖励改为成功 +2、失败 −2，并叠加“接近专家的对齐分数”塑形。两套设计都把稀疏的成败信号拆成逐步信号，差别在塑形项是否参考专家轨迹。

混合训练把模仿损失当作正则项压制强化分支的漂移。EnvDrop 的混合损失为 L = LRL + λILLIL，模仿与强化各走独立轨迹、共享权重；HAMT 在参数更新中写作“强化梯度 + λ × 模仿梯度”，取 λ = 0.2、折扣 γ = 0.9，在单卡上以批 8、学习率 1e-5 微调 10 万次迭代。λ 的作用是双刃：过小则强化分支在长时程上漂移，过大则退化为模仿、失去探索带来的成功率增益。HAMT 的消融显示纯强化相对纯模仿成功率 +6.3、路径加权 +2.8，说明奖励里的距离项更偏向“到达”，对“按指令走”的约束较弱；混合再补 +2.2 与 +3.4，其中路径加权的补幅大于成功率，指向模仿项对路径保真的约束作用。

7. 范式决策树

  • 专家可查询且标注便宜（仿真最短路、真值图）：行为克隆热身，随后 DAgger 聚合，β 从 0.75 起按轮衰减；这是离散仿真里最稳的起步顺序。
  • 专家只在部分状态可得（人类稀疏确认、安全规则）：用 DAgger 的近似变体，只对安全关键状态查询；其余状态靠模仿与强化混合补。
  • 无专家、仅有奖励：先做大规模自监督预训练或轨迹增广，再上强化；直接对随机策略做长时程强化在本课程的 EnvDrop 对照中已被否定。
  • 骨干为大型 Transformer：先代理任务预训练，再模仿微调，最后轻量强化并保持 λ 在 0.1 至 0.3；纯强化在论文中被描述为波动大于模仿（HAMT 第 4.2 节），不适合作为唯一目标。
  • 指标以路径保真为先（RxR、R4R 类协议）：提高模仿权重或引入轨迹级奖励，纯距离奖励会偏向更短路径而牺牲保真（第 025、027 讲的讨论同样适用）。

8. 边界与失效模式

  • 专家次优或众包噪声：DAgger 把专家错误按访问分布加权放大，聚合越多越难修正；需要专家质量抽检与异常状态回退。
  • 查询接口成本被低估：仿真内重规划是常数开销，真机上每次确认可能耗秒级时间，轮数与每轮轨迹数必须按接口延迟重算。
  • β 调度与回合数错配：β 衰减慢则策略依赖专家、推理时分布不一致；衰减快则聚合数据里缺少学徒状态；第 041 讲已强调 β 的轮次起点必须写进日志。
  • 奖励投机：距离塑形可被原地转圈刷分（EnvDrop 纯强化路径 73.8 米、加权 0.03），需要路径长度惩罚或成功终止约束。
  • 停止动作坍塌：成功奖励集中在停止步，策略可能提前停止或永不停止；监控平均路径与停止率是必要检查项。
  • 离线数据陈旧：用旧策略轨迹做行为克隆会再次引入分布错位；聚合数据集必须记录每条轨迹的产生策略版本。

三种范式的组合顺序有判据支撑：行为克隆把策略推进到专家分布的邻域，DAgger 把监督铺到学徒会到达的状态，强化学习在稠密奖励下探索出超出最短路的成功路径。反向顺序（先强化、后模仿）在无预训练骨干上会把大量预算耗在游走上。唯一的例外是骨干已经过大规模预训练，此时强化可以直接微调（HAMT 的 RL 对 IL 领先 6.3 个百分点），但仍建议保留 0.2 量级的模仿项以稳定训练。

        state = env.reset()
        states, expert_actions = [], []
        done = False
        while not done:
            # 以 beta 的概率走专家，否则走策略；采样分布逐步向学徒漂移
            action = expert(state) if torch.rand(1).item() < beta else policy.act(state)
            states.append(state)
            expert_actions.append(expert(state))   # 访问状态一律补专家标注
            state, _, done = env.step(action)
        new_episodes.append((states, expert_actions))
    dataset.extend(new_episodes)           # 聚合旧数据，早期轨迹不淘汰
    for _ in range(4):                     # 聚合数据上的模仿轮数
        policy.imitation_update(dataset)
    return {"round": round_id, "beta": beta, "episodes": len(dataset)}

解读：（1）β 的幂次起点必须与日志一致，0.75n 与 0.75n+1 会整体错位一轮；（2）动作由专家或策略二选一，标注则对每个访问状态都查询专家，这两件事在 DAgger 里是分开的；（3）数据集用 extend 聚合，早期轨迹保留在训练集中；（4）每轮结束返回数据集规模，便于与原始数据量核算倍数。

片段 2：模仿与强化的混合更新

def mixed_update(policy, critic, batch_il, batch_rl, lam=0.2, gamma=0.9):
    """强化梯度加 lambda 倍模仿梯度，两批数据共享权重。"""
    logp_rl, values, rewards, dones = policy.evaluate(batch_rl)
    returns = compute_returns(rewards, dones, gamma)          # 逐步回报
    advantage = returns - values.detach()
    loss_rl = -(logp_rl * advantage).mean()                   # 优势加权策略梯度
    loss_value = torch.nn.functional.mse_loss(values, returns)
    logp_il = policy.log_prob(batch_il.states, batch_il.actions)
    loss_il = -logp_il.mean()                                 # 专家动作交叉熵
    loss = loss_rl + loss_value + lam * loss_il               # 模仿项充当正则
    loss.backward()
    policy.optimizer.step()
    # lam 过小则长时程漂移，过大则退化为纯模仿；以路径加权指标调参
    return {"rl": loss_rl.item(), "il": loss_il.item(), "lam": lam}

解读：（1）两条损失来自两批数据、共享同一策略网络，对应“各走独立轨迹、共享权重”的公开设计；（2）优势用采样回报减价值估计，评论家同步回归回报，避免策略梯度方差过大；（3）λ 是唯一调节两种信息的旋钮，取值范围以 0.1 至 0.3 为起始，按验证集路径加权指标增减；（4）返回值分项记录，防止混合损失均值掩盖某一项失效（例如模仿损失正常而强化项爆炸）。

片段 3：训练预算核算

def dagger_budget(rounds=6, traj_per_round=5000, avg_steps=55.88,
                  base_traj=4475, beta_p=0.75):
    """核算 DAgger 的标注量、聚合规模与相对原始数据的倍数。"""
    labels_per_round = traj_per_round * avg_steps
    total_steps = labels_per_round * rounds
    base_steps = base_traj * avg_steps
    betas = [beta_p ** n for n in range(1, rounds + 1)]
    return {
        "labels_per_round": labels_per_round,          # 约 27.94 万步
        "total_steps": total_steps,                    # 6 轮约 167.6 万步
        "ratio_vs_base": total_steps / base_steps,     # 6 轮 6.70，10 轮 11.17
        "beta_first": betas[0], "beta_mean": sum(betas) / len(betas),
    }

# 判据：聚合规模低于原始数据 3 倍时，先加轮数；高于 12 倍时先查专家质量，
# 因为聚合的边际收益会先被专家噪声吞掉，再加数据不再改善验证集

解读：（1）标注量按时程折算，比较对象必须是同一平均步数口径，避免把轨迹数倍数与步数倍数混用；（2）β 的均值与首值同时返回，供复现实验核对调度；（3）注释中的 3 倍与 12 倍为经验门限，只用于排期，不进入结论；（4）聚合数据要额外记录每条轨迹的产生策略版本，片段只算规模，版本管理在数据侧完成。

常见坑

  • 把纯强化当默认起点：从零骨干上纯 A2C 的成功率 24.0%、平均路径 73.8 米，路径加权 0.03，预算被游走吞掉。根因是稀疏成败信号遇到随机初始化策略。修复：先行为克隆热身，再按 DAgger 聚合，最后以 λ 约 0.2 的比例加入强化；骨干已预训练时才允许强化占主导。
  • β 调度与轮次起点不一致：复现结果整体偏移，前几轮专家介入比例与论文差一轮。根因是 0.75n 的 n 从 0 还是 1 计未写进配置。修复：把轮次起点、β 值、每轮轨迹数写入训练日志与配置标识；第 041 讲给出的 0.75n+1 微调变体要与主配方分开记录。
  • 专家标注被当作真值：真值图或重规划在动态障碍、指令歧义下会给出次优动作，聚合数据把错误放大。根因是缺少专家质量检查。修复：按状态分层抽检专家动作，统计次优率；对高歧义状态回退到人类确认或直接掩码。
  • 混合损失用均值监控：只看总损失，模仿项正常而强化项发散的情况被掩盖。根因是日志粒度不足。修复：分项记录策略梯度损失、价值损失与模仿损失；同时监控平均路径长度与停止率，识别奖励投机与停止坍塌。
  • 陈旧数据反复使用：用旧版本策略的轨迹继续做行为克隆，曝光偏差没有缓解反而固化。根因是数据未标记产生策略版本。修复：每条轨迹记录策略版本与生成时间；模仿更新只读取与当前策略差距在阈值内的数据，超出者重新采样。

练习与思考

  1. 实算误差累积的简化上界 ε·T(T+1)/2：ε = 0.05、T 分别取 10、20、55.88，并与按步成功概率 (1 − ε)T 的读数对照，说明两个口径各自回答什么问题。 ★
    提示
    上界为 2.75、10.50、79.46；成功概率为 0.5987、0.3585、0.0569。前者是代价口径的最坏情形增量，后者是按步独立假设下全程零失误的概率；两者都随 T 放大，前者二次、后者指数，说明长轨迹对模仿学习尤其苛刻。
  2. 预测：把 HAMT 的 λ 从 0.2 调到 0 与调到 1.0，分别预测验证集成功率与路径长度加权成功率的变化方向，并给出可证伪的观测指标。 ★
    提示
    λ = 0 时强化项失去正则，成功率可能短期上升而波动加大、路径加权下降（论文提到纯强化波动大于模仿）；λ 过大时模仿项占主导，两项指标向 IL 行（57.2/54.7）回落。可证伪指标：多次运行的指标方差与平均路径长度，若 λ = 0 时方差显著上升则支持漂移解释。
  3. 推导与设计：在 DAgger 中，β 按几何衰减 βn = pn 时，推导前十轮 β 的均值表达式并计算 p = 0.75 的数值；说明 β 均值与“专家标注占比”这两个量的区别。 ★★
    提示
    Σ pn（n = 1 至 10）= p(1 − p10)/(1 − p)，均值 = 该值除以 10；p = 0.75 时约 0.2831。β 均值为专家动作介入概率，用于控制轨迹来源；专家标注占比始终为 100%，因为每个访问状态都会查询专家，两者不能混用。
  4. 对照分析：EnvDrop 的纯强化平均路径 73.8 米、路径加权成功率 0.03，而混合训练加权 0.43。请从奖励结构与状态分布两个角度解释这幅对照，并设计一个能区分“游走”与“绕路执行指令”的测量。 ★★
    提示
    奖励只有距离变化与成败项时，策略可沿远离目标的短循环反复获得局部回报，评论家估计被塑形项主导；混合训练的模仿项把动作分布锚回专家邻域，路径长度随之回落。测量：按与最短路的偏离度分层统计轨迹，若 73.8 米集中在低偏离度但长绕行层则为执行型绕路，若集中在高偏离度且终点错层则为游走。
  5. 系统设计：为一个真机部署项目选择训练范式。条件：专家仅能在约 5% 的关键状态获得人工确认，奖励为稀疏成败信号加距离塑形，骨干为预训练的 Transformer。给出完整配方（范式顺序、λ、β、轮数与采样量）、两个风险与对应的监控指标，并写出预算核算表。 ★★★
    提示
    范式顺序：代理任务预训练、行为克隆热身、专家确认状态的近似 DAgger、最后 λ 约 0.2 的强化微调。风险一：人工确认延迟导致轮次预算被压缩，监控每轮实际标注量与排队时长；风险二：稀疏成功信号下的游走，监控平均路径与停止率，设置长度惩罚。预算表按 avg_steps、确认覆盖率（5%）与每轮标注上限计算，明确哪些状态退化为模仿标签。

小结

  • 三种范式的差别在训练状态分布：行为克隆用专家轨迹、强化学习用策略轨迹、DAgger 用两者的混合并逐步并入学徒分布。
  • 模仿学习的误差按时程放大：简化上界 ε·T(T+1)/2，ε = 0.05 时 T = 55.88 的上界约 79.46；按步成功概率 (1 − ε)T 在长轨迹上降到 0.0569。
  • DAgger（Ross 等 2011，AISTATS，PMLR 15:627–635）把顺序预测归约为无遗憾在线学习：每轮以 βi 混合专家与策略采样，对访问状态补专家标注并聚合。归约结论在强凸损失与有界偏移条件下依赖平均遗憾 RN/N 收敛。
  • VLN 实践：学生强制等价于在线 DAgger；VLN-CE 用 β = 0.75n、每轮 5,000 条、6 至 10 轮，标注量约为原始数据的 6.70 至 11.17 倍；图形方法用伪交互演示者替代真值图专家。
  • 强化学习的翻转条件：从零 LSTM 上纯 A2C 成功率 24.0%（路径 73.8 米），预训练 Transformer 上纯强化比模仿高 6.3 个百分点；混合以 λ 约 0.2 保留探索收益并补路径保真（HAMT 混合加权 60.9）。
  • 决策顺序：专家便宜先克隆后 DAgger，专家稀疏用近似变体，无专家先预训练再强化，路径保真优先时提高模仿权重。
