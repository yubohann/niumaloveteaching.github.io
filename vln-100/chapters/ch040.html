第二篇 · 离散方法谱系：从模块到预训练

第 040 讲｜第二篇回顾：seen→unseen 的两条路线

本讲把 021 至 039 的十九讲收束成两条回答泛化问题的路线：增广与数据路线、结构与地图预训练路线。R2R val unseen 成功率从 Seq2Seq 的 22% 走到 75%，每一步的增益按路线与训练阶段拆账；最后给出落差台账、谱系时间线 v1 与一套可复用的受控实验模板，并说明第三篇从何处接续。

  • 主题：阶段回顾 / 泛化落差 / 收益拆解 / 谱系时间线
  • 关键台账：R2R 基线落差 16.8 个百分点（相对 43.52%）到 2021 年降至 10 个百分点（相对 13.16%）
  • 预计学时：60 分钟
  • 前置讲：第 039 讲（记忆与地图范式横评）

学习目标

  • 会算：按绝对差与相对降幅两种口径计算 seen 与 unseen 的落差，并说明两种口径在报告中的不同用途。
  • 会拆：把一条方法线的总增益拆成增广数据、预训练目标、记忆结构、动作空间四类来源，指出各自的证据位置。
  • 会判：识别跨协议拼接、val seen 混报、收益重复归属三类系统性误读，给出纠正写法。
  • 会设计：用受控变量法设计“分离两条路线”的消融实验，写出固定项、变化项与预期结论方向。
  • 会定位：把第二篇的任意方法放进“模块时代、预训练时代、结构与地图时代”的时间线，说明它与两篇综述的分类如何对应。

背景与动机

第二篇从 Seq2Seq 基线（021 讲）出发，经历合成指令增广（022 讲）、全景动作空间设计（023 讲）、共定位与进度监控（024 讲）、强化跨模态匹配与自监督模仿（025、026 讲）、回溯智能体（027 讲）、环境丢弃与回译（028 讲）、混合训练（029 讲），随后进入预训练与数据工程时代：PREVALENT（030 讲）、VLN-BERT（031 讲）、循环 VLN-BERT（032 讲）、Airbert 与租赁图库（033 讲）；再到结构与地图时代：HAMT（034 讲）、HOP（035 讲）、DUET（036 讲）、BEVBert（037 讲）、GridMM（038 讲）；039 讲完成记忆范式的横评。

这条线上反复出现同一个目标：缩小在训练建筑上测得的成绩与在未见建筑上测得的成绩之间的落差。第一篇 009 讲定义了这个协议，010 与 011 讲提醒过捷径与环境偏差的存在，但直到第二篇才出现系统的应对手段。手段分两族。一族从数据入手，制造更多指令、更多环境、更难的环境；另一族从表示与结构入手，用预训练目标与显式空间记忆把“见过什么”与“该去哪里”解耦。

回顾的难点在于两族手段经常出现在同一篇论文的同一张表里：增广数据进入预训练，预训练改变表示，表示又服务于新的记忆结构，循环归因会把收益重复记账。本讲的交付物正是拆账工具：一张落差台账、一张增益来源表、一套受控实验模板。它们也是 061 讲规模路线与 080 讲数据-表征-泛化闭环的前置约定。

核心原理

1. 落差的两个口径

设同一配置在 val seen 上的成功率为 S，在 val unseen 上为 U。绝对落差为 S − U，相对降幅为 (S − U) / S。两个口径回答不同问题：绝对落差用于判断“还差多少个百分点可以追”，相对降幅用于判断“泛化损耗占已获得能力的比例”。R2R 原始基线（Anderson 等 2018，CVPR 2018，student-forcing）为 38.6% 与 21.8%，绝对落差 16.8 个百分点，相对降幅 43.52%，超过四成，泛化问题在任务诞生之初就占据中心位置。

报告纪律有两条：第一，两个 split 必须成对出现，只报 unseen 会隐藏训练拟合程度；第二，跨方法比较落差时，split 定义、步数上限与解码设置必须一致，否则落差里混入协议差。第一篇 009 讲给出过实验记录表模板，本讲的时间线表格沿用同一字段。

3. 路线 A：增广与数据

路线 A 的核心判断是“泛化差源于见过的世界太少”。代表手段四类：指令增广（Speaker 模型为无标注路径生成指令，022 讲）、环境增广（视角级特征丢弃、房间混合、风格迁移，028 讲与第四篇 065 讲）、域内数据工程（Airbert 用租赁图片构建百万级路径-指令对，033 讲）、跨任务数据（HOP 在预训练中混合多任务数据，035 讲）。基础模型时代综述（Zhang 等 2024）把这条线概括为两类：预训练视觉表示（ResNet 到 CLIP 到视频编码器）与环境增广（EnvEdit、EnvMix、Pathdreamer 等），并给出一个重要结论：域内预训练的多模态 transformer 比用 Oscar、LXMERT 初始化的模型更有效。

路线 A 的收益证据有三处。第一，宏观台阶：Speaker-Follower 到 EnvDrop 的 val unseen SR 从 35 升到 52，增加 17 个百分点，是时间线上最大的单步增量；EnvDrop 到 PREVALENT 再增 6。第二，同篇消融：DUET 论文表 4 显示，合成指令加入预训练使 SPL 升 1.63、RGSPL 升 1.76；但进入策略学习阶段后，同样的增广数据使 SR 从 46.98 微降到 46.58。论文的解释是：代理任务能利用带噪合成数据，策略学习需要更干净的数据。第三，规模路线预告：更大规模的环境与轨迹合成将在 061 讲展开，属于路线 A 的极端形态。

路线 A 的边界也要写清：增广数据的质量分布与评测分布未必一致，合成指令携带生成器的偏差；环境增广若改变语义（例如把厨房混淆成卧室），收益会转为噪声；评测集不接受任何来自评测场景的增广，否则构成泄漏（074 讲）。

4. 路线 B：结构与地图预训练

路线 B 的核心判断是“泛化差源于表示没有抓住可迁移的空间结构”。代表手段：循环状态与再预训练（RecBERT）、层级全景历史（HAMT）、顺序感知目标（HOP）、在线拓扑与双尺度图注意力（DUET）、局部度量加全局拓扑与地图预训练（BEVBert）、动态网格与指令相关性聚合（GridMM）。这条线的每一步都同时改动结构、代理任务与训练配方，回顾时把三类收益分开记账：

证据（来源）对照增量归因

三行证据的说服力不同。HAMT 与 BEVBert 的两行主要是“预训练目标收益”，说明即使是同一结构，换监督信号也能带来数个百分点；GridMM 一行才是真正的“载体收益”，因为无地图与各有地图对照组共享网络其余部分。这解释了 039 讲“先固定动作头与训练配方，再比较载体”的原则：不先剥夺预训练与数据变量，载体差异读不出来。

路线 B 的代价在 039 讲已量化：显式历史与地图把内存从 KiB 级推到 MiB 级，全局动作空间让轨迹变长（DUET 相对 HAMT 在 R2R 上 SR 加 6 而 SPL 减 1），度量图与网格的注意力成本随分辨率增长。选型时收益与代价必须同表。

5. 两条路线的交互与归属

两线互相耦合。增广数据只有经过预训练目标才能转化为可迁移表示（DUET 证据）；预训练表示又决定记忆结构能提取多少空间信息（BEVBert 的 MSI 依赖地图特征空间）。归属拆账的可行方法是三组对照：固定数据与结构、只换监督目标；固定数据与目标、只换记忆载体；固定结构、把增广开关作为变量并分阶段记录（预训练阶段与策略阶段分别评测）。三组对照分别回答“目标值多少、载体值多少、数据值多少”。任何两项同时变化的表格，只能报告联合增益。

规模维度是第二篇没有覆盖的缺口：R2R 训练集只有 14,025 条指令（Anderson 等 2018），在深度模型时代属于小数据。数据规模、记忆结构与预训练目标三者在更大规模下的相对权重可能重排，这是第三篇之后第四篇要回答的问题（061 至 065 讲）。

7. 未解问题与第三篇接口

盘点第二篇结束时留下的问题：其一，离散导航图的三条不真实假设（完美定位、节点跳转、已知拓扑）在 R2R-CE 中放松，但方法迁移后指标系统性下降（041 至 048 讲）；其二，评测集含错事实与指令噪声，注入实验显示最多 25% 的成功率损失（056 讲）；其三，真机部署的观察、光照与碰撞问题尚无系统结论（049 至 051、099 讲）；其四，预训练数据与评测集的交叉泄漏缺少统一审计（074 讲）；其五，地图范式的多楼层、室外与动态环境缺口（039 讲边界，098 讲空中与室外）。

第三篇（041 至 060）把动作空间从“选节点”换成“连续速度与转向”，把平台从仿真扩到真机与空中。第二篇建立的两条路线在连续环境下需要重估：增广数据能否覆盖控制误差？记忆结构在连续定位噪声下是否稳定？这些问题的答案从 041 讲的三假设放松开始展开。

8. 常见误读与纠正

  • 误读一：把时间线当排行榜。纠正：表格中的数字来自不同论文的各自评测，特征、数据、解码与步数上限不同，只用于观察趋势。
  • 误读二：把 val seen 的高分解释为泛化。纠正：val seen 与训练共享建筑，其分数包含环境记忆，泛化结论只看 val unseen，并成对报告。
  • 误读三：把预训练收益记入记忆结构。纠正：先看消融表是否有“从零训练”基线；BEVBert 的 +13.28 属于目标与数据，不属于地图。
  • 误读四：忽略解码与集成的抬升。纠正：beam search 与多模型集成会系统性抬高 SR，比较前统一解码设置（079 讲）。
  • 误读五：把两线收益直接相加预测新模型。纠正：两条线共享表示，增益高度耦合；只报告受控实验测得的联合增益。

设计决策：以“从零训练”为锚，不以最强配置为锚

    print("%-24s | %6.2f pp | %6.2f%%" % (tag, d, d / seen * 100))

rows = [
    (38.6, 21.8, "R2R Seq2Seq 2018"),
    (72, 63, "R2R RecBERT 2021"),
    (76, 66, "R2R HAMT 2021"),
    (71.75, 46.98, "REVERIE DUET 2022"),
    (37, 32, "R2R-CE VLN-CE 基线"),
    (59, 49, "R2R-CE GridMM 2023"),
    (86.4, 73, "R2R test 人类对模型"),
]
for s, u, tag in rows:
    gap(s, u, tag)
# Seq2Seq 16.80 pp / 43.52%; RecBERT 9.00 / 12.50%; HAMT 10.00 / 13.16%
# REVERIE 24.77 / 34.52%; VLN-CE 5.00 / 13.51%; GridMM 10.00 / 16.95%

解读：（1）录入 raw 值后统一计算，避免手抄第二位小数造成台账内部矛盾。（2）最后一行是“人类对模型”，含义与前面不同：86.4 为人类 test 成功率，73 为最优模型 test unseen 成功率，两个数字都来自 R2R 协议，但一侧是上界一侧是模型成绩。（3）真实台账还应记录步数上限与解码设置，本片段为可读性省略，扩展时把字段写成字典逐行输出 CSV。

片段 2：增益拆解

# 各来源的边际增益均来自对应论文消融，单位：R2R 系列 SR（百分点）
hamt = {"从零": 54.4, "加代理任务": 63.5, "端到端 ViT": 65.7}
bevbert = {"从零": 60.24, "加 MLM": 73.52, "加 HSAP": 74.03, "加 MSI": 74.88}
gridmm = {"无地图": 45.19, "拓扑": 47.02, "语义": 46.36, "物体": 47.61, "网格": 49.05}

def marginal(d):
    ks = list(d)
    return [(ks[i], round(d[ks[i]] - d[ks[i - 1]], 2)) for i in range(1, len(ks))]

print("HAMT", marginal(hamt))       # [('加代理任务', 9.1), ('端到端 ViT', 2.2)]
print("BEVBert", marginal(bevbert)) # [('加 MLM', 13.28), ('加 HSAP', 0.51), ('加 MSI', 0.85)]
print("GridMM", [(k, round(gridmm[k] - gridmm["无地图"], 2)) for k in ("拓扑", "语义", "物体", "网格")])
# 各载体相对无地图的增益：+1.83 / +1.17 / +2.42 / +3.86
# 拆账原则：同一字典内的差分才可解释为边际增益；跨字典相减会混入协议差。

解读：（1）三组数字对应三类变量：HAMT 与 BEVBert 的同组差分测量预训练目标收益，GridMM 的同组差分测量记忆载体收益。（2）GridMM 组内“语义”的增益（+1.17）低于“拓扑”（+1.83），说明预定义标签表限制了俯视语义图的表达，这类不占优的结果应原样记录。（3）跨组相减（例如把 HAMT 的 +9.1 与 GridMM 的 +3.86 相加）没有实验依据，属于常见的错误记账。

片段 3：受控实验配置骨架

BASE = {
    "benchmark": "R2R",              # 协议固定：离散图、官方 split、步数上限随仓库版本记录
    "features": {"view": "ViT-B/16", "grid": None, "dim": 768},
    "memory": "recurrent",
    "pretrain": {"data": "original", "tasks": []},
    "finetune": {"mode": "dagger", "lr": 1e-5, "epochs": 30},
    "decode": "greedy",
    "seed": [0, 1, 2],               # 至少三次运行，报告均值与标准差
}

def variant(**kw):
    cfg = {k: (dict(v) if isinstance(v, dict) else v) for k, v in BASE.items()}
    cfg.update(kw)
    return cfg

groups = {
    "baseline": variant(),
    "data": variant(pretrain={"data": "original+synthetic", "tasks": []}),
    "objective": variant(pretrain={"data": "original", "tasks": ["MLM", "SAP"]}),
    "memory": variant(memory="grid", features={"view": "ViT-B/16", "grid": "CLIP-B/32", "dim": 768}),
    "joint": variant(memory="grid", features={"view": "ViT-B/16", "grid": "CLIP-B/32", "dim": 768},
                     pretrain={"data": "original+synthetic", "tasks": ["MLM", "SAP"]}),
}
# 判读：joint - baseline 为联合增益；(data + objective + memory 各自减 baseline) 之和 与联合增益的差为交互项。

解读：（1）配置对象固定了协议面（benchmark、特征、解码、微调），只允许数据、目标、载体三个旋钮变化；把旋钮写成显式字段，避免实验漂移。（2）种子列表要求至少三次运行并报告标准差，1 个百分点内的差异不应作为结论。（3）交互项的写法给出了两线耦合的量化方式：若各项边际之和显著大于联合增益，两线存在冗余；若小于，两线互补。这正是本讲“先拆账、再归因”的工程化身。

常见误区

  • 跨协议拼接曲线：把不同论文、不同特征与解码设置的数字连成一条“方法演进曲线”。根因：只看数值不看表注。修复：时间线表格增设协议列（特征、微调、解码、步数），跨论文数字只做趋势示意，做结论前用同一仓库复现关键点。
  • 用 val seen 讲泛化：val seen 与训练共享建筑，高分包含环境记忆。根因：报告时未成对给出 split。修复：所有主表强制 seen 与 unseen 成对，落差单列一栏，相对降幅用 Python 计算避免手抄。
  • 收益重复归属：增广数据进入预训练、预训练改变表示、表示又服务新结构，三步只做一次消融就宣称结构收益。根因：缺少从零训练锚点与单项变量组。修复：按受控实验模板分组，逐项计算边际增益并报告交互项。
  • 泄漏混入泛化结论：预训练语料或增广数据与 val unseen 场景交叉，落差被人为压低。根因：数据来源审计缺失。修复：建立语料与评测场景的交叉检查清单，审计方法与案例在 074、075 讲展开。
  • 忽略解码与集成的抬升：beam search、后验重排序与多模型集成会抬高 SR，跨方法直接比较。根因：不同论文的解码预算不同。修复：统一解码设置，或单列“解码增益”并从结构收益中扣除。

练习与思考

  1. 给定两组数字：(a) seen 72、unseen 63；(b) seen 76、unseen 66。分别计算绝对落差与相对降幅，并说明为什么 (b) 的绝对落差更大却可能意味着泛化更好。 ★
    提示
    (a) 9.0 pp / 12.50%；(b) 10.0 pp / 13.16%。两组相对降幅接近，(b) 的整体能力更高；绝对落差会随基线能力上升而扩大，跨方法比较优先看相对降幅并注明口径。
  2. 从本讲时间线中选出两个增量最大的相邻台阶，指出各自的主要收益来源属于路线 A 还是路线 B，并写出支持该判断的消融证据或论文段落。 ★
    提示
    SF 到 EnvDrop 加 17 属于路线 A，证据是环境丢弃与回译的增广消融；HAMT 到 DUET 加 6 属于路线 B，证据是 DUET 的细/粗/融合三档消融与 GASA 消融。
  3. 解释 DUET 论文中“合成指令使预训练 SPL 加 1.63，却使策略学习 SR 从 46.98 降到 46.58”的原因，并据此说明增广数据应加在训练流程的哪个阶段、如何验证。 ★★
    提示
    带噪合成数据可被掩码与匹配类代理任务消化，策略学习直接拟合带噪动作监督会引入偏差。验证方法：分别冻结预训练与策略阶段的数据开关，两阶段单独评测；策略阶段只用干净演示数据或对合成数据做置信度过滤。
  4. 用片段 3 的配置骨架为一个“记忆载体对照”实验补全字段，要求固定预训练数据与代理任务，只更换记忆载体，并写出评测指标、运行次数与判定阈值。再说明当载体变化需要不同特征输入（例如网格需要深度）时，如何改写配置以保持其余变量不变。 ★★
    提示
    固定 pretrain 与 finetune 字段，只改 memory；深度作为载体内部依赖，向所有组提供同一传感器流，避免只有新载体获得额外输入。判定阈值可用三次运行的标准差与 1 个百分点余量共同设定。
  5. 设计一个诊断实验，把某一方法的 seen 与 unseen 落差分解为三个可测分量：指令理解误差、环境泛化误差、执行与停止误差。要求 (a) 说明每个分量用什么对照或扰动来测量；(b) 给出指标与预期方向；(c) 指出该分解对第三篇连续环境迁移的预判价值。 ★★★
    提示
    指令理解可用指令打乱与截断（010 与 056 讲）；环境泛化可用 val-seen 到 val-unseen 的差值加上 backbone 更换实验（011 讲）；执行与停止误差可用 OSR 与 SR 的差、以及 oracle 停止下的成功来测。预期：执行误差在 R2R-CE 迁移后占比上升，因为它对应控制与碰撞，预判第三篇需要优先处理低层控制与停止判定。

小结

  • 第二篇围绕 seen→unseen 落差组织：R2R 基线的相对降幅 43.52%，到 2021 至 2023 年方法降至 12% 至 13% 量级，剩余差距部分来自任务执行误差，不再是纯粹的环境泛化。
  • 两条路线：增广与数据路线（合成指令、环境增广、域内数据、规模合成），结构与地图预训练路线（循环状态、层级历史、顺序目标、拓扑、混合度量、网格）。
  • 收益拆解用受控实验：HAMT 代理任务 +9.1、BEVBert 的 MLM +13.28 属于目标与数据；GridMM 建图总和 +3.86 属于记忆载体；跨组相减没有实验依据。
  • 落差台账：REVERIE 相对降幅 34.52% 仍是重灾区；R2R-CE 为 16.95%，高于离散 R2R；人类对最优模型的 test 差距 13.4 个百分点。
  • 回顾资产：谱系大表（021 至 039）、落差台账脚本、受控实验模板（基线、数据组、目标组、载体组、联合组）与“以从零训练为锚”的记账原则。
