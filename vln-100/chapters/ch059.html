第三篇 · 连续环境、跨域与真实平台

第 059 讲｜连续环境结果横评

本讲把连续环境的两条主线（R2R-CE 与 RxR-CE）上的主流方法放进同一张协议核对表：每行标注来源、split、路点预测器、控制器、预训练数据与成功判定口径；用同口径差分拆出五类变量的收益（数据规模、路点输入、规划空间、预训练任务、执行控制）；给出可比键检查流程与横评大表 v1。所有数字先在 Python 中核算，论文值标注表号与版本。

  • 主题：评测横评 / 协议对齐 / 收益归因
  • 关键公式：ΔSR = SR方法 − SR对照；停止缺口 = OSR − SR；可比性 = 八键一致
  • 预计学时：60 分钟
  • 前置讲：第 048 讲（连续环境评测协议与坑）、第 046 讲与第 047 讲（ETPNav 两讲）

学习目标

  • 会写：复述 R2R-CE 与 RxR-CE 主表中各方法的协议标签，写出八项可比键（comparable keys）并说明每一项不一致时的后果。
  • 会算：计算同族方法之间的 SR、SPL、NDTW、SDTW 绝对差与相对差；计算停止缺口 OSR − SR，并解释它与截断的关系。
  • 会实现：把论文结果表编码为结构化记录，用可比性检查函数自动输出差异清单与差分报告。
  • 会判断：给定两张结果表，判断能否并排；在数据规模化、架构改进、执行控制三类方案之间按部署场景取舍。
  • 会诊断：识别混口径、混 split、用取整值算差分三类误读，并给出修正步骤。

背景与动机

第 046 至 048 讲把 ETPNav 的建图、规划、控制与评测协议讲完，属于单方法内部的完整链条；第 057、058 讲又把视角鲁棒性与真机集成方案收尾。留下的问题是跨方法的：同一张 R2R-CE val-unseen，端到端基线 Seq2Seq 的成功率为 32，局部规划版本 Reborn 为 50，全局拓扑版本 ETPNav 为 57.21，使用大规模合成数据的 HAMT+ScaleVLN 为 55（均为各论文表值，口径见后文）。从 32 到 57 的跨度里，哪些部分来自方法，哪些部分来自评测口径与配套组件，需要逐项拆开。

这个问题的严重性在第 048 讲已经铺垫：同一批轨迹在三种停止判定下可以给出 0.400、0.600、0.800 三个成功率，口径差异达到 2 倍。跨论文横评甚至更复杂，因为每条结果还绑定了自己的路点预测器、控制器与预训练数据。横评的第一原则是把「方法差异」与「配套差异」分开，第二原则是只在同一套可比键下做差分。违反任一条，得到的收益归因都会系统性偏移。

本讲的产出是一张横评大表 v1、一套可比键与一个差分报告流程。它同时服务两个下游：第 060 讲把第三篇的结论收成仿真到现场的差距地图，需要横评提供「仿真内最好水平的量级」；第 079 讲的评测公平性讨论，则需要本讲的可比键清单作为输入。

核心原理

本讲按「横评纪律、R2R-CE 主表、RxR-CE 主表、收益归因、停止缺口、可比性流程、边界」展开；论文数字标注来源、表号与 split，差分值由 Python 实算。

1. 横评的三条纪律与八项可比键

把两份结果放进同一张表之前，先明确三条纪律。第一，键不一致的记录只能定性并列，不能做数值差分。第二，差分只在协议键一致的记录之间进行；跨族差分要逐项标注配套变化，并优先引用原论文的受控对照。第三，凡引用数值必须带四个标签：数据集版本、split、动作与成功判定口径、配套组件版本。这三条纪律的工程化形式就是可比键检查：八项键全部一致时差分可信，任意一项不一致时必须标注。

再看跨族对照。HAMT+ScaleVLN 的 val-unseen 为 55 SR / 51 SPL，与 ETPNav 的 57.21 / 49.15 形成交叉：ScaleVLN 的 SPL 更高，SR 更低。结论二：这两个数字不能按单一排名解读，前者在数据规模上占优，后者在决策结构上占优；交叉说明「成功数」与「路径效率」可以沿不同方向优化。ScaleVLN 论文自述在 R2R-CE 上把 SR 提高 5 个百分点，其对照是没有额外数据的 HAMT 基线；表 11 内与 HAMT+InternVideo 的 53 SR / 48 SPL 相比为 +2 SR 与 +3 SPL。引用时写明对照行，两个增量都能成立。

5. 停止缺口与指标读法

停止缺口定义为 OSR 与 SR 的差，度量「曾走到目标 3 米内但没有在正确时机停止」这一失败模式的规模。R2R-CE val-unseen 上，ETPNav 的缺口为 64.71 − 57.21 = 7.50 个百分点；test-unseen 为 63 − 55 = 8；Reborn 的 val-unseen 为 57 − 50 = 7；HPN 为 40 − 36 = 4。缺口越小，说明策略的停止判定越准，或者轨迹越短、进入阈值的路径越少。ScaleVLN 论文给出一个呼应：其模型距人类成功率（86）还差 6 个百分点，与 OSR 减 SR 的 6 至 7 个百分点同量级，据此把停止策略列为数据规模化之后的下一个瓶颈。

Δstop = OSR − SR；ΔSR = SR方法 − SR对照；相对提升 = ΔSR / SR对照 Δstop 越大表示「到达过但未停对」的比例越高；相对提升只在同一可比键下计算。ETPNav 对 CWP-RecBERT 的相对提升为 57.21 / 44 = 1.3002，即 30.02%

其余指标的读法遵循第 048 讲的主次分工：R2R-CE 主报 SR 与 SPL，RxR-CE 主报 NDTW 与 SDTW；NE 是终点距离均值，TL 是轨迹长度均值，两者都不单独作为方法优劣的依据。一次可用的报告至少包含四个数：SR、SPL、NE、TL，加上 OSR 用于诊断停止缺口，RxR-CE 再加 NDTW 与 SDTW。

还需要一把统计尺子。把单条 episode 的成功与否看作二项变量，在成功率约 50% 时标准误为 √(0.25 / N)（实算）：R2R-CE val-unseen 的 1,839 条对应 1.17 个百分点，test-unseen 的 3,408 条对应 0.86，RxR-CE val-unseen 的 11,006 条对应 0.48；对应的近似 95% 置信半宽为 2.29、1.68 与 0.93 个百分点。结论五：R2R-CE 上 1 个百分点以内的单次运行差落在噪声区间内；RxR-CE 的统计分辨率更高，能分辨 0.5 个百分点量级的差。配对比较（同一批 episode 上比较两种方法）的方差小于该未配对估计，报告时需注明用的是哪一种。

6. 可比性判定的操作流程

把过程写成四步，可直接落成脚本。第一步，为每条记录补齐八项键；第二步，按「数据版本与 split」分组，跨组只做定性并列；第三步，在组内按方法族分层，计算同族差分；第四步，输出差分报告，注明哪些差分受配套差异污染。第五步是可选的敏感性检查：把取整口径换成精确口径（例如用 57.21 代替 57），观察结论是否翻转。结论六：横评报告的质量由每个差分旁边的键一致性标记决定，表格长度不构成质量指标。

7. 适用边界与失效模式

  • val-unseen 兼作模型选择集：上表的大多数方法以 val-unseen 早停与选权重，该 split 的排序不构成纯泛化结论；跨论文比较时优先补 test-unseen 列。
  • 取整值与精确值混用：论文表格常取整（如 55、49、57），正文或消融表给出小数（57.21、49.15）。用取整表算差分会引入至多 0.5 的偏差，跨行差分可能达到 1 个百分点。
  • 来源内部不一致：ETPNav 表 X 的 Teleportation 上界 NDTW 为 64.33，正文写作 64.43；Reborn 的 test-unseen SDTW 表值为 38.42，正文为 38.43。引用以表值为准，并在脚注记录差异。
  • 样本量不对称：R2R-CE val-unseen 1,839 条，RxR-CE val-unseen 11,006 条（6.0 倍），后者在指标上的统计波动更小；把一个数据集上的小差值（1 个百分点以内）当作方法结论需要谨慎。
  • 配套版本漂移：CWP 预测器、CLIP 主干版本（ViT-B/32 与 B/16）、Habitat 渲染域都会改变结果；复现某一行时必须对齐该行声明的配套，不能只对齐方法名。
  • 覆盖范围有限：表 v1 只覆盖室内、英语与三种语言子集，不含空中与城市数据（第 052 至 055 讲）与 2022 年之后的竞赛版本；新方法入表前需要重新核对键。

同族内部（如 CWP-CMA 与 CWP-RecBERT）共享预测器与大部分训练配置，差分接近方法差异；跨族差分（如 CWP-RecBERT 与 ETPNav，或 ETPNav 与 HAMT+ScaleVLN）同时包含架构、训练范式与配套的多重变化，引用时须逐项列出变化并优先采用原论文的受控消融。判据是「混淆变量的数量」：一个差分涉及的配套差异超过两项，报告只能写「区间参考」，不能写「提升多少」。

与相邻讲的分工：第 047 讲决定执行怎么做得稳，第 048 讲决定结果怎么记得准，本讲决定结果怎么横向比较；第 060 讲把本表的仿真量级带进部署差距地图，第 079 讲把可比键扩展为评测公平性规范。

关键代码与解读

三段代码分别给出可比性检查、差分报告与停止缺口分析。数据结构与数字对应本讲表格，可直接复用到自己的结果库。

片段 1：可比键检查

KEYS = ("dataset", "split", "version", "action_space", "max_actions",
        "max_plans", "success_rule", "renderer")

def record(paper, table, dataset, split, version, action_space,
           max_actions, max_plans, success_rule, renderer,
           sr, spl, ne, tl, osr, n_dtw=None, s_dtw=None, family=""):
    """一条横评记录：先挂协议键，再挂指标与方法族。"""
    row = dict(paper=paper, table=table, dataset=dataset, split=split,
               version=version, action_space=action_space, max_actions=max_actions,
               max_plans=max_plans, success_rule=success_rule, renderer=renderer,
               sr=sr, spl=spl, ne=ne, tl=tl, osr=osr, n_dtw=n_dtw,
               s_dtw=s_dtw, family=family)
    return row

def comparable(a, b):
    """返回不一致键清单；清单为空才允许做数值差分。"""
    diff = [k for k in KEYS if a[k] != b[k]]
    return diff

etp = record("An 2023", "III", "R2R-CE", "val-unseen", "v3",
             "FWD 0.25m/ROT 15/STOP", 500, 15, "stop+geodesic<3m",
             "Habitat", 57.21, 49.15, 4.71, 11.99, 64.71,
             family="global-topo")
cwp = record("An 2023", "II", "R2R-CE", "val-unseen", "v3",
             "FWD 0.25m/ROT 15/STOP", 500, 15, "stop+geodesic<3m",
             "Habitat", 44.0, 39.0, None, None, None,
             family="local-waypoint")
print(comparable(etp, cwp))   # 空清单：同协议，可做差分

解读：（1）键与指标分离，键不一致的记录进入并列展示区，指标差分函数拒绝执行。（2）「未声明」应显式写入字符串，例如 renderer="unknown"，避免默认一致。（3）方法族字段供差分时筛选同族记录；跨族比较必须走另一条只输出区间的函数。

片段 2：差分与相对提升

def delta(method, control, metric="sr"):
    """同一可比键下的绝对差与相对差；分母为对照值。"""
    d = round(method[metric] - control[metric], 2)
    r = round(d / control[metric], 4)
    return d, r

# ETPNav 对 CWP-RecBERT（R2R-CE val-unseen，表 II 与表 III）
for metric in ("sr", "spl"):
    print(metric, delta(etp, cwp, metric))
# sr (13.21, 0.3002)；spl (10.15, 0.2603)

# ETPNav 对 Reborn（RxR-CE test-unseen，表 IV）
reborn = record("An 2023", "IV", "RxR-CE", "test-unseen", "v3",
                "FWD 0.25m/ROT 15/STOP", 500, 25, "stop+geodesic<3m",
                "Habitat", 45.82, 38.82, 7.10, None, None,
                n_dtw=55.43, s_dtw=38.42, family="local-waypoint")
rxr = record("An 2023", "IV", "RxR-CE", "test-unseen", "v3",
             "FWD 0.25m/ROT 15/STOP", 500, 25, "stop+geodesic<3m",
             "Habitat", 51.21, 39.86, 6.99, None, None,
             n_dtw=54.11, s_dtw=41.30, family="global-topo")
print(delta(rxr, reborn, "sr"), delta(rxr, reborn, "n_dtw"),
      delta(rxr, reborn, "s_dtw"))   # (5.39, 0.1176) (-1.32, -0.0238) (2.88, 0.0750)

解读：（1）相对差的分母固定为对照值，报告时写上分母口径，例如「相对 CWP-RecBERT 提升 30.02%」。（2）同一对方法的差分在不同指标上可能反号（NDTW 为负、SDTW 为正），报告必须给全指标表。（3）Reborn 的 SDTW 采用表值 38.42；若采用正文 38.43，差分变为 2.87，差别在报告精度之外。

片段 3：停止缺口与收益归因汇总

def stop_gap(row):
    """停止缺口：OSR 减 SR，单位百分点。"""
    return round(row["osr"] - row["sr"], 2)

print(stop_gap(etp))                     # 64.71 - 57.21 = 7.5
print(stop_gap(dict(osr=63, sr=55)))     # test-unseen 整数口径：8

    ("waypoint-depth-vs-rgbd", 57.21, 56.44, "SR"),
    ("planning-global-vs-local", 57.21, 53.15, "SR"),
    ("pretrain-vs-scratch", 57.21, 37.41, "SR"),

解读：（1）停止缺口只用两列指标即可监控，适合作为评测流水线的固定输出。（2）归因表用统一的「方法值、对照值、协议标签」三元组表达；每项都标注协议，跨协议的行不参与同表排序。（3）执行项的量级随协议剧变：R2R-CE 上旋转后前进与 Teleportation 上界仅差 0.76 SR（57.21 对 57.97），RxR-CE 上试错开关差 32.18 SR；归因报告必须按协议分栏输出。

常见坑

  • 混协议并列：把 ETPNav 与 HAMT+ScaleVLN 直接排名，忽略后者使用不同预测器与视觉主干。根因是只看方法名不看配套。修复：每行补八项可比键；配套不同的行放入「区间参考」区，只写交叉结论。
  • 混 split 做差分：用某方法的 val-unseen 减另一方法的 test-unseen，得到虚高增益。根因是论文表格排版相近。修复：分组字段先于指标字段检查；差分函数入口强制校验 split 一致。
  • 用取整值算差分：用 57 减 44 得到 13，再用 55.92 减 53.24 得到 2.68，两种精度混用后报表小数位失真。根因是来源表精度不同。修复：记录原始精度与取整规则；差分统一保留两位并注明来源精度上限。
  • OSR 冒充 SR：引用 ETPNav 的 64.71 作为成功率，而 64.71 是 oracle 停止值。根因是两列相邻且都叫成功率类指标。修复：报告模板把 SR 与 OSR 成对列出，OSR 只用于停止缺口诊断。
  • 忽略来源内部不一致：直接引用 64.43 或 38.43，与自己表格中的 64.33 或 38.42 对不上。根因是正文与表格版本未核对。修复：引用以表值为准，在脚注记录正文差异，避免两处数字在同一文档中并存而不解释。
  • 把相对提升当绝对提升：把「30.02% 相对提升」写成「提升 30 个百分点」。根因是相对与绝对分母混淆。修复：报表字段名带单位类型（pp 或 %），CLI 输出模板强制定型。

小结

  • 横评三纪律：键不一致只定性并列；差分只在协议键一致的记录间做，跨族差分标注配套污染；数值引用带数据集版本、split、动作与成功判定、配套组件四类标签。
  • R2R-CE val-unseen 从 Seq2Seq 的 32 / 30 到 ETPNav 的 57.21 / 49.15；test-unseen 从 28 / 25 到 55 / 48。HAMT+ScaleVLN 的 55 / 51（val）与 ETPNav 形成 SR 与 SPL 的交叉。
  • RxR-CE 上 ETPNav 相对 CWP-RecBERT 的差分一致为正（val-unseen +27.71 SR、+22.24 SPL、+15.19 NDTW）；相对 Reborn 的 NDTW 低 1.32、SDTW 高 2.88，主指标选择决定排名。
  • 收益归因五类变量：连续数据规模 +2 SR、离散 +11；深度单模态 +0.77（对 RGBD）；全局规划 +4.06（对局部）；MLM+SAP 相对从头训练 +19.80；试错控制在 RxR-CE 上 +32.18 SR、+26.69 SDTW。
  • 停止缺口 OSR − SR：ETPNav val-unseen 7.50、test-unseen 8；Reborn val-unseen 7；ScaleVLN 距人类 6 个百分点与缺口同量级，停止策略是下一瓶颈。
