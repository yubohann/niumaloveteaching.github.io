第二篇 · 离散方法谱系：从模块到预训练

第 029 讲｜混合训练：IL + RL 两阶段

本讲把模仿学习与强化学习装进同一套两阶段配方：第一阶段用行为克隆提供稳定预热，并用在线采样修正教师路径与指令之间的偏差；第二阶段在环境丢弃与回译合成的新三元组上继续混合训练。本讲把奖励设计、折扣回报、混合权重与训练稳定性逐项推导，并用 EnvDrop（Tan 等，NAACL 2019）与 Regretful（Ma 等，CVPR 2019）的原文数字做算例。

  • 主题：混合训练 / 行为克隆预热 / A2C 微调 / 奖励设计 / 训练稳定性
  • 关键公式：LMIX = LRL + λIL·LIL；rt = dt−1 − dt
  • 预计学时：60 分钟
  • 前置讲：第 028 讲（EnvDrop：环境丢弃与回译）

学习目标

  • 会写：写出模仿学习（Imitation Learning, IL）的负对数似然目标与 A2C 的回报、优势定义，说明离线（off-policy）与在线（on-policy）两类样本的来源差异。
  • 会算：由 EnvDrop 消融表实算 IL-only、RL-only、IL+RL 与两阶段微调四个阶段的成功率增量，并核算环境丢弃相对仅回译的增益倍数。
  • 会设计：把终端奖励 ±3、距离势能塑形与折扣因子 0.9 组合成可复现的 RL 配置，说明进度信号在进入回溯模块前分离梯度的原因。
  • 会判断：依据路径长度与停止行为判断 RL 是否失控，依据验证曲线决定何时进入第二阶段、何时提高 IL 权重。
  • 会诊断：对合成指令质量下降与深度学习框架版本差异两类复现问题给出修复路径，并设计多随机种子的报告口径。

背景与动机

第 028 讲解决了「数据不够」：环境丢弃（environmental dropout）制造新环境，speaker 在丢弃后的环境里回译（back translation）出新的路径-指令三元组。数据有了，训练配方是另一个独立问题：这些旧三元组与合成三元组应该按什么目标、什么顺序、什么权重喂给策略网络。本讲专门回答这个问题，主线是 Tan、Yu 与 Bansal 在 NAACL 2019 提出的两阶段方案（arXiv:1904.04195），辅线是 Ma 等人在 CVPR 2019 给出的进度监督与回溯机制（arXiv:1903.01602）。

第 021 讲的序列到序列基线只做行为克隆（Behavioral Cloning, BC），在 EnvDrop 的同一套消融口径下，val-unseen 成功率 43.6%；改用纯 A2C（Advantage Actor-Critic，优势演员-评论家）训练，成功率只有 24.0%，平均路径长度 73.8 米。两个数字揭示两类不同的困难：模仿学习只看教师动作，训练时状态来自教师轨迹，推理时状态来自自身轨迹，两类分布不一致，这一错位称为暴露偏差（exposure bias，Ross 等 2011 在 DAgger 工作中系统讨论）；强化学习（Reinforcement Learning, RL）的奖励只在终点给出，早期随机探索几乎收不到正信号，样本效率低，策略容易在长轨迹里迷失。

混合训练的思路是把两者拼成一个互补结构：IL 提供稠密、稳定的监督，约束策略不要偏离可读的指令结构；RL 用采样轨迹直接优化任务回报，修正教师路径与指令语义不一致的地方。数字上的结果是：IL+RL 把 val-unseen 成功率从 43.6% 提到 46.5%，再做第二阶段的环境丢弃微调，升到 52.2%，相对纯 IL 基线提升 19.7%（均为 EnvDrop 表 2 口径）。Regretful 还给出另一条稠密信号路线：把进度监控器（progress monitor）做成可学习启发式，测试集上贪心解码的成功率提高 5 个百分点、SPL 提高 8 个百分点。本讲解开这些数字背后的训练机制。

核心原理

1. 两阶段骨架：监督混合在前，半监督微调在后

EnvDrop 的训练分两个阶段，两阶段共用同一个混合目标，区别在数据来源与 IL 权重。第一阶段在 R2R 训练集（14,025 条指令，61 个训练场景）上做监督学习；论文把 IL 与 RL 都归入监督学习，因为两者都有外部信号，前者来自教师动作，后者来自环境奖励。第二阶段是半监督学习：先用环境丢弃生成新环境 E′ = envdropp(E)，再在 E′ 里采样未标注路径 R′，用 speaker 生成指令 I′，组成新三元组 (E′, R′, I′)，然后继续用同一套 IL+RL 目标微调。

E′ = envdropp(E)，I′ = speaker(E′, R′)，三元组 (E′, R′, I′) p 为环境丢弃率，论文取 0.4；E 取自 60 个训练环境，评测环境不参与任何阶段的生成

这个骨架有一个容易忽略的设计点：第二阶段没有另起一套算法。微调阶段可以看作把「回译产物」当作新的标注数据继续跑第一阶段，于是超参数、损失函数、早停口径全部复用，工程实现只需增加数据生成管线。第 028 讲已给出环境丢弃与回译的数据细节，本讲聚焦损失与优化。

2. 模仿学习：教师动作与负对数似然

IL 的目标是让策略模仿教师。设时刻 t 的策略输出为动作分布 pt(at,k)，覆盖当前视点的可达视点；教师动作 a*t 取「从当前视点出发到目标的最短路上」的下一个可达视点。IL 用负对数似然作为损失：

LIL = Σt LtIL = Σt −log pt(a*t) a*t 为教师动作；训练时智能体按教师动作前进以收集状态，这种不使用自身动作的体制即离策略，动作执行方式为行为克隆

教师的定义决定 IL 的边界。论文的教师动作按「到目标的最短路」计算，在 R2R 里标注路径本身就是最短路，因此教师动作与数据一致；但最短路只保证到达终点，不保证每一步都符合指令的语义要求，例如指令要求「经过厨房」，最短路可能直接穿过客厅。这一偏差正是 RL 需要修正的对象，也是两阶段方案把 RL 放在同一目标里的动机。

3. 强化学习：A2C、终端奖励与距离塑形

RL 部分采用在线策略的 A2C：智能体从动作分布中采样动作，沿自身轨迹收集奖励。奖励设计有两项。第一项是终端奖励：停止时若位于目标 3 米以内，停止步奖励 +3，否则 −3。第二项是距离塑形：每个非停止步的直接奖励 rt 取到目标视点距离的变化量 dt−1 − dt；靠近目标为正，远离为负。折扣因子 γ = 0.9，折扣回报与优势写为：

Gt = Σk=0T−t γk rt+k，At = Gt − V(st) V(st) 为评论家网络的价值估计，作为策略梯度的基线；策略项按 −log pt(at)·At 计算，价值项用回归损失训练

用一组自设距离序列验算回报。设起点到目标的距离依次为 d = [8.0, 6.5, 8.5, 5.0, 1.5] 米，停止步成功。塑形奖励为 [1.5, −2.0, 3.5, 3.0]，其中最后一项是终端奖励 +3（停止步按论文口径只给终端项，该步的距离变化不另计）。按 γ = 0.9 反向累积：G3 = 3.0，G2 = 3.5 + 0.9 × 3.0 = 6.2，G1 = −2.0 + 0.9 × 6.2 = 3.58，G0 = 1.5 + 0.9 × 3.58 = 4.722。这组数字由本讲 Python 脚本实算，与正文四舍五入一致。

塑形与最优策略的关系需要写清楚。取势能 Φ(s) = −d(s)，严格的势能型奖励塑形（potential-based reward shaping，Ng、Harada 与 Russell，ICML 1999）为 F = γΦ(st) − Φ(st−1) = dt−1 − γdt，比论文采用的 dt−1 − dt 多 (1 − γ)·dt：当 γ = 0.9、dt = 5 米时严格形式比论文形式高 0.5。也就是说，论文的塑形在理论不变量之外给「离目标更远」的状态附加了温和惩罚，方向与任务目标一致；严格势能塑形的价值在于证明不改变最优策略集，当设计者需要保证这一点时，应按 γΦ(s′) − Φ(s) 构造。

4. 混合目标：两条轨迹、共享权重

混合的实现方式是：IL 与 RL 共享同一套网络权重，分别产生两条轨迹，IL 轨迹按教师动作前进，RL 轨迹按采样动作前进，两个分支的损失加权求和。

LMIX = LRL + λIL·LIL IL 项可视为动作序列上的语言模型，对 RL 训练起正则化作用；λIL 为混合权重，原文正文以符号给出，附录可见配置未列数值

论文消融给出混合的净效果：IL+RL 比 IL-only 高 2.9 个百分点，比 RL-only 高 22.5 个百分点（43.6 与 24.0 两个基线）。更值得读的是路径长度：RL-only 的平均导航长度达到 73.8 米，而 IL+RL 为 9.37 米，两者相差 7.88 倍；环境丢弃微调后为 10.7 米。RL-only 的行为画像因此很清楚：动作分布被终端信号牵着走，在评测环境里长时间游走且停止判定很差，任务类指标随之崩溃。IL 项的作用是把策略锚定在「指令的可读执行」附近，让 RL 的梯度只在局部修正，避免整条轨迹漂移。

用一组示意数值感受权重的量级：设某一批数据上 LRL = 0.82、LIL = 2.10。λIL = 0 时混合目标退化为纯 RL；λIL = 1 时 LMIX = 2.92，IL 项占 71.9%；λIL = 5 时 LMIX = 11.32，IL 项占 92.8%。这解释了论文附录未列 λIL 数值并不影响主结论：在该损失尺度下，只要 λIL 取正且不过小，训练动态就从「RL 主导」切换到「IL 主导、RL 修正」。工程含义是 λIL 应按阶段调整，不应固定为一个数。

5. 进度估计：可学习的稠密信号

Regretful 给出另一条把稠密信号接入训练的路线。它在 Self-Monitoring（Ma 等 2019）的基础上维护一个进度监控器：用文本接地注意力权重 αt 与隐藏状态预测当前完成度 ptpm ∈ [−1, 1]，并给出两种用法。

  • 进度监督：ptpm 以均方误差回归教学信号 ytpm（由剩余距离归一化得到），为注意力机制提供稠密梯度，约束文本接地与进度一致。
  • 进度作为回溯启发式：相邻两步的进度差 Δptpm = ptpm − pt−1pm 送入回溯模块（Regret Module），决定继续前进还是回到上一视点；回退后，已访问视点携带其进度估计作为标记（Progress Marker），降低重复走入低进度区域的动作概率。

训练目标把动作交叉熵、进度回归与熵奖励装在一起，论文取 λ = 0.5、β = 0.01：

L = λ·Σt ytnv log pt,k + (1 − λ)·Σt (ytpm − ptpm)2 − β·ΣtΣk −pt,k log pt,k ytnv 为教师动作；熵项在策略过于自信时保留探索空间。动作数 K = 6 时均匀分布熵为 ln 6 ≈ 1.792，β = 0.01 时熵项量级约 0.018，作用温和但持续

两个工程细节决定这条路线能否稳定。第一，进度输出在进入回溯模块前做 detach，被当作计算图叶子：进度模块只从均方误差接收梯度，避免策略损失反向污染进度估计，否则进度值会为了满足动作监督而漂移，回溯判断随之失真。第二，熵奖励是必需的：交叉熵训练会让策略在训练集中后期过度自信，模型几乎不再回退，回溯机制得不到训练样本，论文用熵项重新打开探索。消融读数为：只加进度标记 44%，只加回溯模块 47%，两者同开 48%（val-unseen SR），把进度估计挂到前进嵌入上只有 45%，关键增益来自回溯模块本身。

6. 第二阶段：回译数据上的混合训练

第二阶段的配方与第一阶段同构，但数据质量变了：speaker 生成的指令是机器产物，与人类标注存在风格与语义差距。训练上要做的调整有两处。其一，提高 IL 权重：EnvDrop 的开源实现说明，回译阶段增大模仿项权重，原因是生成句子质量不高，RL 容易被误导。其二，真实数据与合成数据一起训练：仓库说明的做法是把两者混在一起训练，不再分「先增广、后微调」两步，避免策略在两类分布之间来回切换。

第二阶段的效果分三档读数（val-unseen）：仅回译把 IL+RL 的 46.5% 提到 48.2%，增量 1.7 个百分点；加特征丢弃为 48.4%；加环境丢弃并使 speaker 与 follower 共享同一丢弃掩码，达到 52.2%，相对 IL+RL 提升 5.7 个百分点，约为仅回译增量的 3.35 倍。同表还给出两个对照：特征丢弃比环境丢弃低 3.8 个百分点，丢弃掩码不共享比共享低 3.2 个百分点。三组数字合起来说明，回译的收益主要由「环境层面的一致扰动」贡献，掩码的共享让 speaker 与智能体看到同一个虚构环境，生成的指令与轨迹才对齐。

8. 适用边界与失效模式

  • 教师动作依赖训练期特权信息：dt 与最短路都要求已知目标位置，这些信号只在训练环境可用，且只进入梯度，不进入推理期观测。任何把目标距离写入观测的实现都会造成信息泄漏，评测失效。
  • 早停口径必须统一：论文按 val-unseen 成功率早停，同一批数据既参与模型选择又用于最终报告时，数字会偏乐观。第 009、079 讲会给出更严格的协议讨论。
  • 合成数据不得触碰评测环境：预探索设置下用评测环境生成回译数据属于单独的榜单口径，与单次运行不可比。所有报告必须标注设置。
  • 框架版本敏感：EnvDrop 仓库说明同一套代码在 PyTorch 0.4.x 下 val-unseen 成功率为 52%，0.8 至 1.2 之间约 51%，1.7.1 下为 53.5%。复现实验必须固定框架版本，并报告多随机种子的均值。
  • 两阶段的目标不总一致：IL 的教师信号与 RL 的回报在指令歧义样本上可能给出相反方向，λIL 过大时 RL 修正被压制，过小时游走风险回归。判据是验证集上的 SR 与路径长度同时观察，任一项恶化就调整权重。

关键代码与解读

三段代码对应本讲三个核心机制：混合损失、奖励与回报、第二阶段的稳定性设计。均为 PyTorch 风格的示意实现。

片段 1：IL 与 A2C 的混合损失

import torch
import torch.nn.functional as F

def mixed_loss(logits, teacher_idx, sampled_logp, returns, value,
               lambda_il=1.0):
    """单步损失骨架：IL 走教师动作，A2C 走采样动作，共享同一 logits。"""
    il_loss = F.cross_entropy(logits, teacher_idx)        # 教师动作的负对数似然
    advantage = (returns - value).detach()                # 优势只作权重，不回传评论家
    policy_loss = -(sampled_logp * advantage).mean()      # 采样动作的策略梯度项
    value_loss = F.smooth_l1_loss(value, returns)         # 评论家回归到折扣回报
    return policy_loss + value_loss + lambda_il * il_loss

batch = dict(
    teacher_idx=torch.tensor([2, 0, 1, 1], dtype=torch.long),
    sampled_logp=torch.log_softmax(torch.randn(4, 6), dim=-1)
                  .gather(1, torch.tensor([[3], [1], [4], [0]])).squeeze(1),
    returns=torch.tensor([4.722, 3.580, 6.200, 3.000]),
    value=torch.tensor([4.100, 3.900, 5.800, 3.100]),
)
loss = mixed_loss(
    logits=torch.randn(4, 6, requires_grad=True),
    sampled_logp=batch["sampled_logp"],
    **{k: v for k, v in batch.items() if k != "sampled_logp"},
)
print(round(float(loss), 3))

解读：（1）IL 项与 RL 项共用同一组 logits，对应论文中「两条轨迹共享权重」的实现口径；教师动作索引与采样动作索引分别来自教师轨迹与采样轨迹。（2）advantage 上的 detach 是关键写法：优势只是策略项的权重，评论家的梯度只来自 value_loss，否则评论家会被策略目标拖偏。（3）λIL 默认取 1 仅为占位口径，回译阶段应提高；把权重做成可调参数，避免写死为常量，阶段切换时无需改代码结构。

片段 2：距离塑形与折扣回报

def shaped_rewards(dist, success, gamma=0.9):
    """dist 为逐步到目标的距离；非停止步给势能差，停止步只给终端奖励。"""
    rewards = [dist[t - 1] - dist[t] for t in range(1, len(dist) - 1)]
    rewards.append(3.0 if success else -3.0)             # 停止步终端信号
    returns = [0.0] * len(rewards)
    g = 0.0
    for t in reversed(range(len(rewards))):
        g = rewards[t] + gamma * g                       # 反向累积折扣回报
        returns[t] = g
    return rewards, returns

rewards, returns = shaped_rewards([8.0, 6.5, 8.5, 5.0, 1.5], success=True)
print([round(r, 2) for r in rewards])    # [1.5, -2.0, 3.5, 3.0]
print([round(g, 3) for g in returns])    # [4.722, 3.58, 6.2, 3.0]

解读：（1）非停止步的范围是 range(1, len(dist) - 1)，最后一段距离变化不参与塑形，由终端项接管，这与论文措辞严格一致。（2）回报反向累积，避免显式构造 γ 的幂；数值与正文算例一致。（3）d 来自训练期特权信息，只用于计算梯度；若在观测里加入 d，评测立即失效。此函数放在训练侧工具模块，评测侧代码禁止导入。

片段 3：第二阶段的监控与进度信号分离

def stage_switch(val_history, window=3, tol=0.3):
    """第一阶段进入平台期的简易判据：连续 window 次提升不足 tol 个百分点。"""
    if len(val_history) < window + 1:
        return False
    gains = [val_history[i] - val_history[i - 1]
             for i in range(len(val_history) - window, len(val_history))]
    return max(gains) < tol

def regret_step(logits, progress, progress_target, lambda_=0.5, beta=0.01):
    """Regretful 风格目标：动作交叉熵 + 进度回归 - 熵奖励。"""
    ce = F.cross_entropy(logits, progress_target.teacher_idx)
    pm = F.mse_loss(progress, progress_target.value)
    prob = torch.softmax(logits, dim=-1)
    entropy = -(prob * torch.log_softmax(logits, dim=-1)).sum(-1).mean()
    progress_for_regret = progress.detach()              # 进回溯模块前切断梯度
    return lambda_ * ce + (1 - lambda_) * pm - beta * entropy, progress_for_regret

print(stage_switch([43.0, 44.2, 45.0, 45.1, 45.15, 45.2]))   # True，进入第二阶段
print(round(0.01 * __import__("math").log(6), 4))        # 0.0179，熵项量级

解读：（1）stage_switch 用验证集最近若干次的提升幅度判断平台期，避免在 IL 仍在快速学习时过早引入合成数据。（2）进度项与动作项按 λ = 0.5 加权；熵项带负号，最大化熵即鼓励探索，量级约 0.018，与 β = 0.01 对应。（3）progress.detach() 让进度输出在回溯路径上成为常量：梯度只从均方误差流入进度模块，回溯模块的参数更新不会反向改变进度估计，这是论文明确说明的收尾设计。

常见误区

  • 纯 RL 训练「看起来在学」：训练回报缓慢上升，评测成功率却低于 IL，路径长度膨胀到 IL 的数倍。根因是稀疏终端奖励下的游走策略：智能体学会延长轨迹以碰运气，停止判定退化。修复：加入 IL 混合项与距离塑形，观察路径长度是否回到 10 米量级（EnvDrop 的 IL+RL 为 9.37 米，RL-only 为 73.8 米），必要时检查梯度裁剪配置并降低 RL 分支的学习率。
  • 把教师强制当默认推理方式：训练与验证都用教师动作回放，指标虚高；换成采样动作后性能骤降。根因是暴露偏差未处理。修复：RL 分支始终用采样轨迹；如需在线标注，参考 DAgger（Ross 等 2011）在策略访问状态上补充教师动作。
  • 势能塑形写成非势能形式：例如每走一步加固定奖励，策略学会原地打转刷分。修复：按 dt−1 − dt 构造，或用严格形式 γΦ(s′) − Φ(s) 保证最优策略不变；上线前用小图做「奖励黑客」对照实验。
  • 第二阶段直接全量换用合成数据：RL 被低质量合成指令误导，真实验证集掉分。修复：真实数据与合成数据混合训练；回译阶段提高 IL 权重；用真实 val-unseen 做早停，合成数据只贡献梯度。
  • 复现数字对不上就归因到方法：环境丢弃与回译的训练对框架版本、随机种子敏感，同一代码可差 2 个百分点以上。修复：固定依赖版本并写入实验记录，至少 3 个种子报告均值与标准差；训练侧监控路径长度、停止步位置与回报三条曲线，先排除实现差异再讨论方法结论。

  3. 改超参并预测：把 λIL 从 1 调到 0，再调到 10，预测训练早期成功率、路径长度与停止行为的变化方向；若 γ 从 0.9 调到 0.99，回报的等效视界与训练难度如何变化？ ★★
    提示
    λ = 0 退化为纯 RL，早期成功率下降、路径长度上升（参考 RL-only 的 73.8 米）；λ = 10 时 RL 修正被压制，成功率接近 IL 上限。γ = 0.99 把 0.9 的 1/(1−γ) = 10 步视界拉大到 100 步，方差增大、收敛变慢，需要更小的学习率或优势归一化。
  4. 推导题：证明 Φ(s) = −d(s) 时严格势能塑形 γΦ(s′) − Φ(s) 比论文形式 dt−1 − dt 多 (1 − γ)dt，并说明 γ = 0.9、dt = 5 米时该偏差的方向与量级。 ★★
    提示
    γΦ(st) − Φ(st−1) = −γdt + dt−1；比 dt−1 − dt 多 (1 − γ)dt = +0.5，即论文形式相当于对到达状态附加 0.5 的温和惩罚（距目标越远附加越多）。
  5. 设计题（★★★）：合成指令质量下降时，λIL 需要调高，但调得过高会压制 RL 对教师偏差的修正。设计一套「数据质量自适应」的混合权重方案：给出质量信号的定义（至少两种可测量），权重的调整规则，以及一个能证伪你方案优于固定权重的实验。最后分析该方案在合成分布与真实分布差异过大时的失效风险。 ★★★
    提示
    质量信号可考虑：speaker 生成句与人类指令的 n-gram 重合度、回译句在真实验证集上的困惑度、合成轨迹与最短路的偏离度。规则例如按批次的弱信号把 λIL 在 1 至 5 之间线性映射。证伪实验：固定总训练步数与数据配比，比较固定权重与自适应权重在真实 val-unseen 上的 SR/SPL 差异是否超过种子波动。失效风险：质量指标本身用合成数据估计时会把偏差带入权重，造成正反馈，需要保留一部分真实标注作为锚点。

小结

  • 两阶段骨架：第一阶段在标注数据上用 LMIX = LRL + λILLIL 混合训练；第二阶段在环境丢弃与回译三元组上按同一目标微调，并提高 IL 权重。
  • IL 提供稠密的教师监督，RL 用采样轨迹与终端奖励修正教师路径与指令语境的偏差；两者共享权重、各自产生轨迹。消融读数：IL 43.6%，RL 24.0%，混合 46.5%（val-unseen SR）。
  • 奖励设计：非停止步用距离势能差 rt = dt−1 − dt，停止步用 ±3 终端信号，γ = 0.9；严格势能形式与论文形式相差 −(1 − γ)dt，方向偏向靠近目标。
  • 稳定性判据与稠密信号：路径长度是 RL 失控的第一观察量；Regretful 的进度回归、detach 与熵奖励给出替代路线，测试集贪心解码 +5 点 SR、+8 点 SPL。
  • 第二阶段读数：回译 +1.7 点、环境丢弃合计 +5.7 点（相对 IL+RL），约为仅回译增益的 3.35 倍；匹配历史与共享掩码是主要贡献来源。
