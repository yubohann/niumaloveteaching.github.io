第二篇 · 离散方法谱系：从模块到预训练

第 035 讲｜HOP：历史与顺序预训练

第 034 讲把历史“怎么存”改成了显式 token，本讲回答“历史里该学什么”：HOP（Qiao 等 2022，CVPR 2022）在 MLM 与 TIM 之外加入轨迹顺序建模（TOM）、组顺序建模（GOM）与带历史的动作预测（APH），用 692.8 万对指令轨迹预训练，R2R test unseen 达到 64% SR / 59% SPL，REVERIE test unseen SPL 24.34、RGSPL 14.34。

  • 主题：历史感知预训练 / 顺序建模 / 带历史的动作预测
  • 关键公式：LTOM（N 类排序分类）；LGOM（三类判别）；LAPH（36 选 1）
  • 预计学时：60 分钟
  • 前置讲：第 034 讲（HAMT：层级 ViT 与长程历史）

学习目标

  • 会写：TOM、GOM、APH 三个预训练目标的输入构成、监督信号与损失形式，说明各自训练模型学习什么能力。
  • 会算：按 692.8 万对样本、全局批 512、15 个 epoch 实算预训练步数与每任务步数；给出 TOM 与 GOM 的随机基线。
  • 会实现：轨迹打乱与分组构造、[CLS] 分类头、36 选 1 的动作打分，以及任务采样训练循环。
  • 会判断：APH 与无历史 AP 的差别、前视图轨迹与当前全景的分工、合成语料占 98.42% 对结论边界的影响。
  • 会诊断：顺序标签泄漏、分类头类别数错配、历史与当前帧重叠、下游权重加载不全四类实现问题。

背景与动机

第 034 讲用层级 ViT 把每一步的全景摘要保留下来，解决了长程历史的“存储与计算”问题；留下的问题是“监督信号”：结构能记住全部历史，训练目标却只要求模型在给定指令与轨迹的条件下选对单步动作，历史中的顺序信息没有专门的目标去塑造。VLN 是部分可观测决策过程（POMDP），动作决策依赖过去经验；同时它又是时空任务，对轨迹的先后顺序敏感。前序预训练工作各有缺口：VLN-BERT（Majumdar 等 2020，ECCV 2020，arXiv:2004.14973）与 Airbert（Guhur 等 2021，ICCV 2021）做路径选择或图文匹配，不训练动作预测；PREVALENT（Hao 等 2020，CVPR 2020，arXiv:2002.10638）加了单步动作预测（AP），输入只有当前全景与全局指令，历史视觉上下文被丢弃；三者都没有显式挖掘指令与观测中的顺序信息。

本讲处理这条监督信号线：HOP（History-and-Order Aware Pre-training，Qiao 等 2022，CVPR 2022，arXiv:2203.11591v1）保留 MLM 与 TIM，新增 TOM、GOM 两个顺序目标，并把动作预测升级为带历史的 APH。产出是一张“逐目标构造与损失”的对照表，以及与 034 讲的分工：034 管历史结构的存与算，035 管历史表示的学与监督。下一讲 DUET 会把动作空间从邻居集合扩展到整张在线拓扑图，本讲的 APH 是这一扩展的直接前身。

核心原理

本讲按“模型骨架、既有目标、两个顺序目标、带历史的动作预测、训练协议、结果与边界”展开。所有论文数字标注 HOP（Qiao 等 2022，CVPR 2022，arXiv:2203.11591v1）与对应 split；随机基线与步数由 Python 实算，脚本要点见第 5 节片段 3。

1. 预训练骨架与两种视觉输入

HOP 的骨架沿用 LXMERT 式三段结构：语言编码器、视觉编码器与跨模态编码器。论文配置为 Ntext = 9、Nimage = 1、Ncross = 3 层，与 PREVALENT 相同。跨模态编码器每层含两个自注意力子层、一个双向交叉注意力子层与两个前馈子层，输出作为所有预训练目标与下游任务的共享表示。

视觉输入分两路。轨迹一路使用每步的前视图：用 ImageNet 预训练的 ResNet-152 抽取 2048 维特征，再拼接 128 维方向特征，得到 2176 维图像表示。方向特征由朝向 α 与俯仰 β 的四元组 [sin α; cos α; sin β; cos β] 重复 32 次构成（实算 4 × 32 = 128）。论文解释了使用前视图的原因：同一房间内相邻节点的全景高度相似，全景序列会稀释轨迹的动态与顺序信息；前视图序列的顺序差异更明显，适合顺序监督。动作预测一路使用当前步的 36 视图全景，即 12 个水平朝向乘 3 个俯仰位姿，与 023、034 讲的口径一致。两路输入服务于不同目标，这一分工是本讲所有目标的实现基础。

vi = [ vvis ; vd ] ∈ ℝ2176，vvis ∈ ℝ2048，vd = repeat( [sin α, cos α, sin β, cos β], 32 ) ∈ ℝ128 vi 为轨迹第 i 步的前视图表示；前视图序列进入顺序目标，当前全景进入 APH；下游微调按 RecBERT 的循环状态设计，见 032 讲

2. 既有目标：MLM 与 TIM

掩码语言建模（Masked Language Modeling, MLM）按 15% 概率随机遮盖指令 token，用周围词与轨迹推理被遮盖词：

LMLM(θ) = − 𝔼(w, τ) ∼ D log Pθ( wm | w∖m, τ ) w 为指令，wm 为被遮盖词，w∖m 为其余词，τ 为前视图轨迹；θ 为可训练参数，D 为预训练集

轨迹指令匹配（Trajectory-Instruction Matching, TIM）做全局二分类：以 50% 概率把轨迹换成不匹配的另一条，负样本只从同一环境内选取，迫使模型区分“路径是否被指令描述”，减少“环境风格是否相同”这条捷径。取 [CLS] 表示经全连接层与 sigmoid 得到匹配分 sθ(w, τ)，用二元交叉熵优化。与 031 讲 VLN-BERT 的兼容性打分、033 讲 Airbert 的路径指令二分类相比，TIM 的差异在负样本按环境配对，减少环境风格这条捷径。两者共同的缺口仍然存在：目标只约束“指令与轨迹是否匹配”，不约束轨迹内部顺序。

3. TOM：轨迹顺序建模

轨迹顺序建模（Trajectory Order Modeling, TOM）在细粒度层面对顺序下监督：随机选择原轨迹 50% 的图像打乱，得到重排轨迹 τ′，要求模型参照指令恢复每张图的原序。形式化为 N 类分类问题，N 为轨迹步数；把跨模态编码器的视觉输出经全连接层与 softmax，对重排轨迹中第 k 张图预测其原序 r′k：

LTOM(θ) = − 𝔼(w, τ′) ∼ D Σk=1..N yk log Pθ( r′k | w, τ′ ) yk = 1 当且仅当第 k 张图的预测原序等于其真实原序；N 为该轨迹步数，R2R 与 BnB 的路径长度为 5 至 7 张图

设计上有两个要点。第一，只打乱一半图像，保留一半锚点，模型可以借助未打乱的图像与指令对齐，监督信号密集且任务可解；全部打乱会把目标退化为全排列猜测。第二，分类空间随步数变化，路径 5 至 7 张图对应 5 至 7 类，随机基线为 1/N，实算为 20.0%、16.7%、14.3%。与直接预测未来步视觉特征的目标相比，重排分类的监督来自数据自身的顺序标签，稠密且不引入连续高维的回归空间。TOM 让模型学会把指令中的先后线索与视觉序列对齐，这正是“先左转再上楼梯”类表述所需的能力。

4. GOM：组顺序建模

组顺序建模（Group Order Modeling, GOM）在子轨迹层面下监督。把轨迹均分为两组 G1 与 G2，按三种排布之一构造输入：G2 接在 G1 之后（顺序，c = 1）、G2 放在 G1 之前（逆序，c = 2）、G2 被替换为其他轨迹随机抽样的图像组（不匹配，c = 3），三种情况各占 1/3。两组之间用 [SEP] 分隔，取 [CLS] 表示做三类判别：

LGOM(θ) = − 𝔼(w, (G1, G2)) ∼ D Σc∈{1,2,3} yc log Pθ( c′ | w, (G1, G2) ) 三类样本等概率构造，随机基线 33.3%；替换用的图像组来自其他轨迹，其中部分来自其他环境

TOM 与 GOM 的分工是尺度：TOM 恢复单张图的位置，监督稠密、感受野小，适合捕捉相邻步骤的先后；GOM 判断两个子段的相对关系，感受野大，适合捕捉“走过厨房之后才到走廊”这类段落级顺序。消融给出了两者的互补证据：单独叠加时，TOM 把 R2R val unseen SR 从 60.75 提到 61.81、GOM 提到 61.98；组合使用后（与 TIM、APH 同训）五任务达到 63.86 SR / 57.07 SPL，相对无预训练基线 54.19 / 49.35 提升 9.67 SR 与 7.72 SPL。顺序目标补的是“时间轴”维度，图文匹配仍由 MLM 与 TIM 承担。

5. APH：带历史的动作预测

带历史的动作预测（Action Prediction with History, APH）把动作目标从无历史升级为有历史。输入为指令 w、历史前视轨迹 τt−1 = ⟨v1, …, vt−1⟩ 与当前步 36 视图全景；输出为下一视图的选择，形式化为 36 类分类：

LAPH(θ) = − 𝔼(w, τ, vpano) ∼ D Σp=1..36 yp log Pθ( v′t+1 | w, τt−1, vtp ) vtp 为当前全景；yp 标记 36 张视图中哪一张是下一视图；无历史版本（AP）删除 τt−1 一项

历史的作用在论文的消融中有直接对照（R2R val unseen）：MLM + APH 为 62.01 SR / 56.13 SPL，MLM + AP（无历史）为 61.27 / 55.68，差 0.74 SR 与 0.45 SPL；论文还报告 APH 在预训练阶段的动作预测准确率收敛更快、更高。机制解释是子指令定位：指令是整段的，“turn right and walk past the kitchen” 中的哪一句正在被执行，取决于已经走过的部分；历史视觉证据让模型把当前观测对准指令的对应片段，这正是部分可观测条件下单帧无法完成的事。结论一：动作预测的收益来自历史上下文，APH 相对 AP 的小幅提升在三个下游任务与全部指标上一致。

6. 训练协议：任务采样与数据配比

预训练数据由两部分组成（数据来源与过滤规则见 HOP 3.3 节）：PREVALENT 提供 104K 原始 R2R 指令对与 6,482K 合成指令对，合计 6,586K；BnB 处理版提供 342K 图像序列-指令对，构造时删除了近半无题注图片，并把图像与对应题注分别拼接成 5 至 7 张图的路径，与 R2R 的长度口径一致。两者合计 6,928K，即 692.8 万对。实算占比：合成指令占 PREVALENT 的 98.42%，BnB 处理版占全部数据的 4.94%。

训练采用任务采样：每个 mini-batch 只训练五个目标中的一个，任务之间均衡。配置为 4 张 Tesla V100、单卡批 128（全局 512）、AdamW、学习率 1 × 10−5、15 个 epoch。实算步数：每 epoch 约 13,531 个批，15 个 epoch 共约 202,969 步，按任务均分每任务约 40,594 步。任务采样把“五个目标”折算成五份独立的训练预算，这是解读消融表的关键口径。

下游微调使用 RecBERT 式架构（复用预训练的语言与视觉表示，用循环状态承载历史），R2R 批 16、学习率 1 × 10−5、单卡 1080Ti；RxR 批 16、学习率 7 × 10−6、单卡 V100；NDH 与 REVERIE 批 8、学习率 1 × 10−5。R2R 训练数据为原始训练集加 PREVALENT 增广对，延续 030、033 讲的增广线。

8. 适用边界与失效模式

  • 历史只有前视图与方向：顺序目标依赖前视图序列，侧后方线索不进入预训练历史；对“左侧的窗户”这类依赖侧向观察的判断，预训练阶段没有直接监督。全景只在 APH 的当前步出现，历史与当前的视觉口径并不对称。
  • 短轨迹假设：TOM 的类别数等于步数，GOM 假设轨迹可均分为两段；R2R 与 BnB 的路径为 5 至 7 步。把目标直接迁移到 REVERIE、SOON 一类的长路径或含回退的轨迹时，分组边界与类别数都要重新设计。
  • 合成语料主导：预训练对中 98.42% 为 speaker 合成指令，语言分布受生成模型限制，这一点与 030、033 讲的结论一致；跨任务收益因此更多来自视觉与顺序表示，语言侧的泛化提升有限。
  • 下游结构瓶颈不变：微调仍使用循环状态压缩历史，034 讲讨论的早期记忆衰减问题依旧存在；预训练改善的是表示初始化，不改变下游推理期的信息瓶颈。
  • 计算预算明示：预训练 4 张 V100、15 个 epoch、约 20.3 万步；消融结论在同等任务采样预算下取得，直接增加任务数量而不增加步数会稀释每任务监督。

三段代码分别给出 TOM 的构造与损失、GOM 与 APH 的判别头、以及预训练规模的核算脚本。接口以公开实现（HOP-VLN）的设计为参照，版本演进时以仓库为准。

片段 1：TOM 的打乱构造与分类损失

import torch
import torch.nn as nn
import torch.nn.functional as F

def tom_batch(traj_feats, shuffle_ratio=0.5):
    """traj_feats: (T, D) 的前视图轨迹特征。
    随机打乱一半位置，返回重排特征与原序标签（标签给未打乱位置填 -1）。"""
    T = traj_feats.size(0)
    n_shuffle = max(1, int(round(T * shuffle_ratio)))      # T=6 时打乱 3 张
    perm = torch.randperm(T)[:n_shuffle]                   # 被选中的位置
    shuffled = traj_feats.clone()
    shuffled[perm] = traj_feats[perm[torch.randperm(n_shuffle)]]   # 只置换选中位置
    labels = torch.full((T,), -1, dtype=torch.long)        # -1 表示不打乱，不算损失
    labels[perm] = perm                                    # 目标：恢复原位置索引
    return shuffled, labels

class TomHead(nn.Module):
    def __init__(self, hidden=768):
        super().__init__()
        self.cls = nn.Linear(hidden, hidden)               # 逐图打分网络
        self.out = nn.Linear(hidden, 1)

    def forward(self, vis_out, labels):
        """vis_out: (T, D) 跨模态编码器的视觉输出；N 类分类对每张图独立打分。"""
        logits = self.out(torch.tanh(self.cls(vis_out))).squeeze(-1)   # (T,)
        logits = logits.unsqueeze(0).expand(labels.numel(), -1)        # (T, T) 每图对 N 个原序打分
        return F.cross_entropy(logits, labels, ignore_index=-1)

解读：（1）只置换选中位置，未选中位置保持原位并置标签为 −1，用 ignore_index 排除出损失，这是“打乱一半、保留锚点”的实现写法。（2）分类器的打分矩阵按“每张图对 N 个候选原序”展开，等价于 N 类的 cross_entropy；步数变化时无需改网络，只需改展开维度。（3）置换偶发地可能把某张图换回原位，此时标签仍为原序，监督仍然正确；不要用“标签等于当前顺序”来构造，否则会把不动点误判为负样本。

片段 2：GOM 三类判别与 APH 动作头

import torch
import torch.nn as nn
import torch.nn.functional as F

class GomHead(nn.Module):
    def __init__(self, hidden=768):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(hidden, hidden), nn.GELU(), nn.Linear(hidden, 3))

    def forward(self, cls_feat):
        """cls_feat: (B, D) 的 [CLS] 表示；输出三类相对顺序的 logits。"""
        return self.fc(cls_feat)

def gom_batch(g1, g2_pool, rng):
    """构造三类样本：顺序、逆序、替换。g2_pool 为其他轨迹的图像组池。"""
    u = rng.random()
    if u < 1.0 / 3.0:
        seq, label = torch.cat([g1, g2_pool.sample()], dim=0), 0     # c=1 顺序
    elif u < 2.0 / 3.0:
        seq, label = torch.cat([g2_pool.sample(), g1], dim=0), 1     # c=2 逆序
    else:
        seq, label = torch.cat([g1, g2_pool.sample_other()], dim=0), 2   # c=3 不匹配
    return seq, label

class AphHead(nn.Module):
    def __init__(self, hidden=768, views=36):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(hidden, hidden), nn.GELU(), nn.Linear(hidden, views))

    def forward(self, cls_feat, view_emb, view_mask):
        """教学版：以 [CLS] 表示与 36 张当前视图的相似度打分。"""
        logits = self.fc(cls_feat).unsqueeze(1) + (view_emb * cls_feat.unsqueeze(1)).sum(-1)
        return logits.masked_fill(~view_mask, float("-inf"))

解读：（1）GOM 用均匀随机数把三种构造各分 1/3，替换组从其他轨迹抽样，与论文的构造一致；[SEP] 在真实实现里由类型嵌入区分，示例省略了嵌入层。（2）APH 的打分融合“全局 [CLS] 分类项”与“视图相似度项”，教学版保留两项便于对照 032 讲的状态精炼写法；真实实现按论文取 [CLS] 经全连接层对 36 类打分。（3）不可见视图用 masked_fill 排除，保证 36 选 1 的归一化只在有效候选上进行。

片段 3：预训练规模实算

prev = 104_000 + 6_482_000        # PREVALENT：原始 R2R + 合成指令
bnb = 342_000                     # 处理后的 BnB 图像序列-指令对
total = prev + bnb                # 6,928,000 对，即 692.8 万
print(round(6_482_000 / prev * 100, 2))      # 98.42，合成指令占比
print(round(bnb / total * 100, 2))           # 4.94，BnB 占总量

bs, epochs = 128 * 4, 15                     # 4 卡，单卡批 128
steps = epochs * total / bs
print(round(steps))                          # 202969 步
print(round(steps / 5))                      # 40594，每任务约 4.06 万步

for n in (5, 6, 7):                          # TOM 类别数随轨迹长度变化
    print(n, round(100 / n, 1))              # 20.0 / 16.7 / 14.3 随机基线
print(round(100 / 3, 1))                     # 33.3，GOM 随机基线

解读：（1）数据混合比例、步数与基线全部可复算；把 6,928K 换成自己的语料规模即可复用。（2）步数按“全局批 × epoch”估算，真实训练含数据加载与任务采样的随机性，量级一致即可。（3）TOM 基线随 N 下降、GOM 基线固定，报告预训练指标时必须同时给出基线，单独的准确率没有解释力。

常见误区

  • 顺序标签泄漏：TOM 训练损失降到接近 0，下游却不涨。根因：构造重排轨迹时把位置索引拼进了输入特征，模型直接读标签。修复：输入只保留视觉与方向特征；打乱后的顺序标签只出现在损失侧，并写单测检查“输入特征与标签的相关性应为 0”。
  • TOM 分类头类别数错配：训练时步数 7 的样本进 5 类头，报索引越界或静默错标。根因：把 N 类写法实现为固定分类头。修复：按当前轨迹长度构造打分矩阵，超出有效步数的位置置 −1 并排除；批内混合长度时逐样本处理。
  • APH 的当前帧同时出现在历史里：离线指标虚高，评测掉点。根因：构造样本时把 vt 也放进了历史序列 τt−1，模型能从历史里读到答案。修复：历史严格截到 t−1 步；用打乱时间戳的对照实验验证模型对当前帧的依赖。
  • 无题注图片未过滤：MLM 与 TIM 在空文本样本上训练，梯度噪声变大。根因：直接使用 BnB 原始图片，近半没有题注。修复：按论文先删除无题注图，再拼接题注构造路径；统计每条样本的有效 token 数并设下限。
  • 下游只加载一半权重：预训练收益远低于论文。根因：微调脚本只复制语言塔参数，视觉塔与跨模态层重新初始化。修复：逐模块打印权重加载率，把“语言塔、视觉塔、跨模态层”三组的加载状态写入实验记录。

练习与思考

  1. 取 N = 5 的轨迹，按 TOM 打乱 50% 图像。写出打乱后需要恢复顺序的图像数与随机猜测的期望正确数，并计算随机基线。 ★
    提示
    N = 5 时打乱约 3 张；随机置换的期望不动点为 1，因此平均有 2 张需要移动到新位置；5 类均猜的基线为 1/5 = 20.0%。把 N 换成 6 与 7，基线分别为 16.7% 与 14.3%。
  2. 把任务采样改为“每批同时计算五个目标”。写出每任务获得的监督量变化与单批计算量变化，并说明什么条件下这种改法更划算。 ★
    提示
    每任务监督从约 4.06 万步升到 20.3 万步（5 倍），但单批前向与反向次数约 5 倍，总计算量按同一步数计也约 5 倍。当数据规模小、单任务收敛快时，联合计算的监督密度更高；当算力受限、任务间梯度冲突明显（如 TIM 与 TOM 对同一表示的要求不同）时，采样更稳。
  3. 把 GOM 的三类概率从 (1/3, 1/3, 1/3) 改为 (1/2, 1/4, 1/4)，预测多数类捷径的行为变化，并设计一个能暴露该捷径的评测。 ★★
    提示
    顺序类样本占一半，模型可能固定预测“顺序”获得 50% 的平凡准确率，判别能力退化。评测：分别报告三类样本上的平衡准确率与混淆矩阵，并设置“恒预测顺序”的基线；若模型增益接近该基线，说明策略未被压制。
  4. 设计顺序监督的消融：在同一预训练数据与步数下比较“无顺序目标、只 TOM、只 GOM、两者都开”四组，给出在标准 R2R 与长程 R4R 上的指标方向预测，并说明如何隔离 BnB 数据的干扰。 ★★
    提示
    预测：标准 R2R 上四组依次小幅上升；长程任务与含回程指令的任务对顺序更敏感，TOM 与 GOM 的收益更大。隔离办法：四组固定同一份数据（只用 PREVALENT，或都用 PREVALENT + BnB），数据侧只保留一个变量。
  5. 把 APH 从“36 视图选择”扩展为“地图节点选择”的预训练目标：写出标签的获取方式、与下游全局动作空间的接口，并分析它与第 036 讲 DUET 全局动作空间的关系；说明把该目标放进预训练的三个主要难点。 ★★★
    提示
    标签获取：专家轨迹的下一节点天然是地图节点标签；接口：预训练输出节点分数，与微调阶段的全局动作头同构。难点：其一，预训练仍是离线数据，需要先离线构建轨迹对应的拓扑图（036 讲讨论在线与离线图的状态分布差异）；其二，节点数随地图增长，分类空间不固定；其三，地图节点表示依赖部分观测的累积，预训练时可视范围比例受限，标签分布与在线推理不一致。

小结

  • HOP 在 MLM 与 TIM 之外新增三个 VLN 专属目标：TOM 恢复被打乱一半的轨迹顺序（N 类），GOM 判别两组子轨迹的相对关系（三类），APH 带历史预测 36 视图中的下一视图。
  • 三个顺序与动作目标的消融数值（R2R val unseen SR）：MLM + APH 62.01、MLM + GOM 61.98、MLM + TOM 61.81、MLM + TIM 61.52；五任务组合 63.86 / 57.07，相对无预训练 54.19 / 49.35 提升 9.67 SR 与 7.72 SPL。
  • 预训练数据 692.8 万对：PREVALENT 6,586K（合成占 98.42%）加 BnB 处理版 342K；4 卡 V100、全局批 512、15 epoch 约 20.3 万步，任务采样下每任务约 4.06 万步。
  • 结果：R2R test unseen 64 SR / 59 SPL、NE 3.83 米；RxR val unseen 42.3 SR、sDTW 0.33；NDH val unseen 混合设置 4.41 米；REVERIE test unseen SPL 24.34、RGSPL 14.34。
  • 边界：历史只含前视图与方向、顺序目标依赖短轨迹、合成语料主导语言分布、下游仍用循环状态承载历史。
