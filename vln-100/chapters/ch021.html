第二篇 · 离散方法谱系：从模块到预训练

第 021 讲｜Seq2Seq 基线全解剖

本讲把 R2R 原论文的序列到序列基线逐层拆开：指令编码（词嵌入 256、LSTM 512、语序反转）、观测与动作嵌入、Luong 注意力、动作分布与交叉熵损失；讲清训练标签按当前位置重规划这一关键机制，并用一个小 batch 实算逐步损失与梯度；最后解释 20.4%（test）为何是必须跨过的性能下限。

  • 主题：Seq2Seq 基线 / 注意力解码 / 行为克隆损失 / 训练体制
  • 关键公式：hi = LSTMenc(xi, hi−1)；πt = softmax(Wo·tanh(Wc[ct; h′t]))
  • 预计学时：60 分钟
  • 前置讲：第 020 讲（第一篇回顾：任务-数据-评测公共语言）

学习目标

  • 会写：给出基线模型的信息流公式链，从指令词到动作分布逐段写清符号与张量形状（Anderson 等 2018，R2R）。
  • 会算：对一个小 batch 实算逐步交叉熵、token 均值与 episode 均值，并写出 softmax 加交叉熵的梯度 p − y。
  • 会判断：区分 teacher-forcing 与 student-forcing 的输入分布与标签来源，说明标签按当前位置重规划为何是 student-forcing 可训练的前提。
  • 会实现：写出带掩码的行为克隆损失、注意力解码与贪心评测循环三个核心片段。
  • 会评估：把 val-seen 38.6%、val-unseen 21.8%、test 20.4% 当作复现验收锚点，并解释 seen 与 unseen 落差 16.8 点的结构成因。

背景与动机

第二篇讲离散方法谱系，起点是原论文自带的那个最小完整系统。020 讲建立的公共语言告诉我们：R2R 离散协议下的第一条性能底线由 Anderson 等 2018 的序列到序列（sequence-to-sequence，Seq2Seq）基线给出，student-forcing 训练在 val-seen 38.6%、val-unseen 21.8%，test 20.4%；人类在 test 为 86.4%。此后第二篇的每条方法线，都可视为对这套基线的某一处做替换或增强：022 换动作空间与数据、025 换匹配目标、030 之后换表征与预训练。

基线值得全解剖的理由有三条。第一，它是复现的标尺：特征口径、词表过滤、掩码与停止处理任何一处写错，数字都会明显低于 21.8%，而错误原因通常藏在实现细节里。第二，它把问题结构暴露得最清楚：观测只有前向 60° 视场，动作只有 6 个，历史完全由单个解码器循环状态承载，语言只经注意力读取一次；后续方法的每一次改进都针对其中一个约束。第三，它的失败模式定义了之后数年的研究议程：seen 与 unseen 的落差、提前停止、模态偏差都在该系统上首次变成可量化现象。

本讲要解决三件事：把前向与损失写成不跳步的公式链；用一个小 batch 实算损失与梯度，把「行为克隆」从口号变成可核对数字；把 teacher-forcing 与 student-forcing 的差异落到标签重规划这一实现机制上。022 讲将立即展示，替换动作空间并加入合成数据，同一底座可以发生多大的变化。

核心原理

1. 条件策略的 Seq2Seq 分解

VLN 策略写作 π(at | o≤t, ℓ)：给定截至 t 的观测历史和固定指令 ℓ，输出动作分布。原论文用一个带注意力机制的 LSTM 编码器与解码器实现它：编码器把指令压成隐藏状态序列，解码器在每一步读取当前图像特征与上一步动作嵌入，经注意力读取指令后输出 6 个动作的概率。

hi = LSTMenc(xi, hi−1)，h̄ = {h1, …, hL} xi 为第 i 个词的词嵌入（256 维）；L 为指令长度；h̄ 是注意力的上下文集合；编码器与解码器隐藏维度均为 512

两个被论文明确采用的工程选择写在编码侧。其一，语序反转：把 ⟨x1, …, xL⟩ 反转后送入编码器，借鉴 Sutskever 等在机器翻译中的做法，缩短句中首词与解码端最相关词之间的路径长度。其二，词表过滤：全部指令小写化，按空白分词，出现少于 5 次的词被过滤；R2R 词表约 3.1k 词，其中约 1.2k 个出现 5 次及以上，其余约 61.3%（实算）为长尾词。长尾里多是人名与偶然地标，这解释了后续方法为何反复回到词表泛化问题。

2. 观测与动作嵌入：解码器的输入拼接

解码器每一步的输入由两部分拼接：当前视角的图像特征与上一步动作的学习嵌入。图像特征用 ImageNet 预训练的 ResNet-152 做均值池化，得到 2048 维向量，训练全程冻结；动作嵌入维度 32，与词嵌入一样从随机初始化学习。

qt = [ fCNN(ot) ; e(at−1) ]，h′t = LSTMdec(qt, h′t−1) fCNN ∈ ℝ2048，e(at−1) ∈ ℝ32，qt ∈ ℝ2080；解码器循环状态承载全部历史，这是部分可观测条件下的记忆机制

论文对观测的规定是 640×480 分辨率、垂直视场 60° 的第一人称 RGB 图像。注意这是一个前向局部视图：智能体看不到身后与两侧，若指令要求左转，它必须先用 up/down/left/right 四个转镜动作找到目标方向再前进。动作空间限定为 6 个：左、右、上、下各转 30°，前进到视场中心最近的可达视点，以及停止。前进动作的定义把「看向哪里」与「走到哪里」绑定，动作序列因此既包含相机控制也包含位置移动。

训练加速的工程口径需要单独记住：由于转向与俯仰被离散成 30° 增量，官方仓库预先把每个全景切成 36 个视角（12 个水平朝向 × 3 个俯仰档），每视角缓存 2048 维 ResNet-152 特征；基线按当前朝向选取对应视角。全库 379,080 行、float32 下约 2.89 GiB；单帧特征 12 × 2048 × 4 字节 = 96 KiB，换原始像素则为每帧约 10.55 MiB，是特征表示的 112.5 倍（承 001、004 讲口径）。

3. 注意力与动作分布

解码每一步先用 Luong 等 2015 的一般对齐打分在指令编码序列上计算权重，再加权求和得到指令上下文 ct，最后与解码状态拼接经过一次变换得到动作 logits。

score(h′t, hi) = h′t⊤ Wa hi，αt,i = exp(scoret,i) / Σj exp(scoret,j) Wa ∈ ℝ512×512 为可学习参数；填充位置的 score 置为负极大值后再归一化
ct = Σi αt,i hi，h̃t = tanh( Wc [ct ; h′t] )，πt = softmax( Wo h̃t ) 论文写作 at = softmax(h̃t)，本课程按实现口径补出输出线性层 Wo ∈ ℝ6×512；πt ∈ Δ5 为 6 维动作分布

公式的适用条件有两条。指令固定：ℓ 在整个 episode 内不变，注意力每步在同一组 h̄ 上重新加权，模型学会在不同阶段读取指令的不同片段。视觉注意力缺位：论文明确不引入图像注意力，单帧特征直接进入解码器。这个缺失正是 022 讲全景动作空间与后续历史编码工作的起点。

4. 标签重规划：两种训练体制的真正区别

两种体制都在每一步用交叉熵最大化目标动作的似然，关键差别在「上一步输入什么」与「标签从哪里来」。论文把目标动作 at* 定义为：从智能体当前位姿 st 出发到目标 v* 的最短路径上的下一个动作。这个定义对任意偏离状态都成立，是 student-forcing 能够训练的核心。

体制上一步输入标签来源状态分布主要代价
teacher-forcing真值动作（训练时强制）当前位姿到目标的最短路首动作只落在真值轨迹上训练与测试输入分布不一致
student-forcing模型采样动作同上，对偏离后的位姿重新规划覆盖偏离状态训练更慢；采样方差
计划采样（scheduled sampling，论文未采用）按概率混合真值与采样同上介于两者之间论文实测差于全部采样

需要强调三个细节。第一，免费获得任意状态标签的前提是导航图已知且确定：仿真器可以随时算出当前节点到目标的最短路。真实机器人上这一点不成立，所以 student-forcing 属于仿真内可用的强监督手段。第二，student-forcing 等价于在线版本的 DAgger，把「策略访问到的状态」与「该状态下的专家动作」配对，缓解输入分布错位。第三，论文脚注说明计划采样表现更差，直接采用全部采样，这与很多任务的经验相反，原因在标签随处可得且动作空间小。

梯度同样可以手算。若某步目标为「前进」，则对 logits 的梯度为 ∂L/∂zj = pj − 1[j = 前进]：目标维为 0.80 − 1 = −0.20，其余五维为各自的概率 0.05、0.05、0.02、0.03、0.05（合计 0.20，与目标维的负值相抵）。这个 p − y 结构是所有 softmax 加交叉熵实现共享的形式，也是判断「损失实现是否有误」的最快检查点。

8. 适用边界与失效模式

  • 前向视野假设：观测只有 60° 垂直视场的前向图像，转弯必须消耗动作步。任何需要侧向或回望的任务在这个接口下先天吃亏，022 讲的全景动作空间直接消除该限制。
  • 历史压缩到单一循环状态：全部观测与动作历史压进 512 维解码状态，长 episode 下早期视觉证据会衰减。034 讲之后的层级历史编码是对该瓶颈的回应。
  • 视觉主干冻结：ResNet-152 特征不参与更新，接地能力受限于 ImageNet 语义，表征偏差问题在 010、011 讲已有量化证据。
  • 稀疏奖励不作为训练信号：基线只用行为克隆，任务奖励只在评测出现；029 讲的两阶段训练把强化学习接在同一底座上。
  • 标签重规划依赖完美定位与已知拓扑：student-forcing 的标签来自仿真器最短路，跨到连续环境（041 讲）后该机制需要重写。

设计决策：标签在训练循环内重规划，不预计算

若在数据侧按起点预计算一次最短路标签，student-forcing 一旦偏离，标签就与状态不匹配，损失最优化的是错误目标。正确做法是在每个训练步内，用当前位姿查询最短路并取首动作，使标签与策略访问的状态同步演化。输入侧决定访问哪些状态，标签侧保证每个访问状态都有正确的监督，两者合起来才是完整的 student-forcing 实现。

关键代码与解读

三段代码覆盖模型前向、带掩码与重规划标签的损失、贪心评测循环。代码按 PyTorch 风格编写，以公开实现的设计为参照，接口随版本演进。

片段 1：指令编码器加注意力解码器

import torch
import torch.nn as nn

class Seq2SeqPolicy(nn.Module):
    """R2R 原论文基线核心：指令编码器 + 注意力解码器。"""
    def __init__(self, vocab_size, hidden=512, word_dim=256, action_dim=32,
                 feature_dim=2048, n_actions=6):
        super().__init__()
        self.word_embed = nn.Embedding(vocab_size, word_dim)   # 词嵌入 256 维
        self.act_embed = nn.Embedding(n_actions, action_dim)   # 动作嵌入 32 维
        self.encoder = nn.LSTM(word_dim, hidden, batch_first=True)
        self.decoder = nn.LSTM(feature_dim + action_dim, hidden, batch_first=True)
        self.attn_w = nn.Linear(hidden, hidden, bias=False)    # Luong general 的 W_a
        self.combine = nn.Linear(2 * hidden, hidden)           # W_c 的 [c_t; h'_t] 部分
        self.head = nn.Linear(hidden, n_actions)               # 输出 6 个动作 logits

    def forward(self, words, feats, prev_actions, word_mask):
        """words: (B,L)；feats: (B,T,2048)；prev_actions: (B,T)；word_mask: (B,L)。"""
        enc_out, (h, c) = self.encoder(self.word_embed(words)) # 语序反转在数据侧完成
        logits = []
        for t in range(feats.size(1)):
            q = torch.cat([feats[:, t],
                           self.act_embed(prev_actions[:, t])], dim=-1)
            _, (h, c) = self.decoder(q.unsqueeze(1), (h, c))
            h_t = h.squeeze(0)                                  # (B,H)
            score = torch.bmm(self.attn_w(h_t).unsqueeze(1),
                              enc_out.transpose(1, 2))          # (B,1,L)
            score = score.masked_fill(~word_mask.unsqueeze(1), -1e9)
            alpha = torch.softmax(score, dim=-1)                # 注意力权重
            ctx = torch.bmm(alpha, enc_out).squeeze(1)          # (B,H)
            h_tilde = torch.tanh(self.combine(
                torch.cat([ctx, h_t], dim=-1)))                 # tanh(W_c[c_t; h'_t])
            logits.append(self.head(h_tilde))                   # (B,6)
        return torch.stack(logits, dim=1)                       # (B,T,6)

解读：（1）编码器输出保留整条序列作为注意力上下文；解码器初始状态直接沿用编码器末状态，这是本实现的选择，论文未展开该细节，替换为零初始化通常不影响主要结论，但应在实验记录中注明。（2）掩码在打分之后、softmax 之前施加，填充词的分数被置为负极大值，避免注意力把概率分配给无意义位置。（3）动作头输出 logits，softmax 与交叉熵合并计算以利用数值稳定的实现；采样时再单独做 softmax。参数量估算按该结构：词嵌入 793,600、编码器 1,574,912、解码器 5,310,464、注意力打分投影 262,144、组合层 524,800、动作头 3,078、动作嵌入 192，合计约 8.47M（逐步计算见练习 4）；ResNet-152 约 60M 参数在外部冻结，不计入策略参数。

片段 2：带掩码与标签重规划的行为克隆损失

import torch
import torch.nn.functional as F

def batch_bc_loss(policy, batch, shortest_first_action):
    """行为克隆损失：每一步标签由当前位置到目标的最短路重新生成。
    shortest_first_action(state, goal) 返回该状态下应执行的动作 id。"""
    words = batch["words"]                    # (B,L)
    feats = batch["feats"]                    # (B,T,2048)
    prev_actions = batch["prev_actions"]      # (B,T)，第 0 步为占位
    states = batch["states"]                  # (B,T)，每步的位姿
    goals = batch["goals"]                    # (B,)
    lengths = batch["lengths"]                # (B,)
    word_mask = words != 0

    logits = policy(words, feats, prev_actions, word_mask)     # (B,T,6)
    labels = torch.zeros_like(prev_actions)
    for b in range(words.size(0)):
        for t in range(int(lengths[b])):
            labels[b, t] = shortest_first_action(states[b, t], goals[b])

    step_loss = F.cross_entropy(
        logits.reshape(-1, logits.size(-1)), labels.reshape(-1),
        reduction="none").view(labels.shape)
    mask = torch.arange(logits.size(1))[None, :] < lengths[:, None]
    token_mean = (step_loss * mask).sum() / mask.sum()         # 只对有效步取平均
    return token_mean

解读：（1）标签循环在训练步内执行，保证每一次前向的监督目标与策略当前访问的位姿一致，这是 student-forcing 的必要条件；若把该函数换成按 episode 起点预计算的静态标签，偏离状态会得到错误梯度。（2）掩码同时服务两个目的：长度不同的 episode 组成 batch 时屏蔽填充步，并让分母恰为有效步数；本讲算例的全 batch token 均值为 2.3354 / 7 = 0.3336。（3）若改用 episode 平均，只需把分母换成 batch 内 episode 数；两种口径的训练动力学不同，切换口径必须同步调整学习率与报告格式。

片段 3：贪心评测循环

import torch

@torch.no_grad()
def greedy_decode(policy, env, max_steps=50):
    """评测用贪心解码：每步取概率最大的动作，直到停止或达到步数上限。
    为便于与训练逻辑对照，这里对前缀重算前向；产线实现应缓存循环状态。"""
    states, feats, prev_actions = [], [], []
    action = 0                                  # 起始动作占位
    for _ in range(max_steps):
        states.append(env.state())              # 先记录本步状态
        feats.append(env.observe_feature())     # 当前视角 2048 维特征
        prev_actions.append(action)
        words = torch.tensor([env.token_ids()]) # 指令固定，可预计算一次
        logits = policy(words,
                        torch.stack(feats).unsqueeze(0),
                        torch.tensor([prev_actions]),
                        words != 0)
        action = int(logits[0, -1].argmax())    # 贪心选择本轮新动作
        if action == env.STOP_ID:
            break                               # 预测停止：不调用 env.step
        env.step(action)                        # 执行后位姿与观测更新
    return states

解读：（1）评测代码里没有任何真值调用，目标只在循环结束后由评测器使用，这是防止未来信息泄漏的接口纪律。（2）停止动作先于环境步进判断：预测停止即结束，不再调用 env.step；把停止处理写错（例如停止后仍推进一步）会系统性改变 NE 与成功率。（3）前缀重算带来 O(T²) 前向开销，仅用于讲解与调试；正式评测缓存 LSTM 状态与注意力上下文，单步前向即可。贪心是论文的评测口径，beam search 属于额外搜索预算，报告时必须注明。

常见误区

  • 语序反转与截断顺序写反：症状是长指令表现异常，模型对句首描述不敏感。根因是官方仓库对反转后的序列做截断，且分词器默认长度 20，直接调用默认值会丢掉句首内容（004 讲有同源提示）。修复：显式传入编码长度（基线训练配置为 80），或先按原序截断再反转，并用手工样例断言首词仍被保留。
  • 标签未按当前位置重规划：症状是 student-forcing 训练损失正常下降，但评测成功率远低于 21.8%。根因是按 episode 起点预计算了静态标签，策略偏离后监督目标错误。修复：在训练循环内用当前位姿查询最短路，取首动作作为标签，并断言标签与状态同步更新。
  • 填充掩码遗漏：症状是损失数值随 batch 内最长序列波动，梯度被填充步稀释。根因是交叉熵对填充位置一并求平均。修复：按本讲片段 2 的方式同时屏蔽损失与注意力打分，并把分母固定为有效步数。
  • 停止动作处理不一致：症状是 NE 明显偏低但 SR 明显低于锚点，或轨迹长度恰好等于步数上限。根因通常是停止后仍执行一步、或把超步数当成功处理。修复：预测停止立即结束；超步数与超时统一计为失败并单列统计。
  • 用损失绝对值横向比较实现：症状是「损失更低所以模型更好」的误判。根因是平均口径、词表大小与掩码方式不同，损失尺度不可跨实现比较。修复：固定口径后再比；优先用 SR、NE、SPL 等任务指标做模型比较，损失只做训练健康度监控。

    提示
    冒烟测试与对照用 teacher-forcing，主训练用 student-forcing。标签构造：取当前位姿到目标的最短路首动作，两种体制相同，差别在输入状态从何而来。计划采样在标签随处可得、动作空间小的设定下引入额外混合噪声，实测更差。
  3. 模型走到偏离路径的节点 s，s 到目标需要 3 跳：先左转、再前进、再停止。写出该步的监督标签，并说明若沿用从起点预计算的标签会发生什么错误。 ★★
    提示
    该步标签为左转（最短路的首动作）。静态标签多半是前进或另一方向，模型会在错误方向上被继续强化；偏离越远、episode 越长，错误监督越多，最终表现为 unseen 成功率崩塌。

    提示

小结

  • 基线实现条件策略 π(at | o≤t, ℓ)：指令经 256 维词嵌入与 512 维 LSTM 编码并在数据侧反转词序；解码器输入图像特征（ResNet-152 均值池化 2048 维，冻结）与 32 维动作嵌入；Luong 注意力读取指令后经 tanh 与线性层输出 6 动作分布。
  • 损失为逐步交叉熵；标签定义为当前位置到目标最短路的首动作。标签在训练循环内重规划是 student-forcing 可训练的前提，等价于在线 DAgger；论文实测计划采样更差。
  • 小 batch 实算：7 个有效步损失总和 2.3354，token 均值 0.3336，episode 均值 1.1677；softmax 加交叉熵梯度为 p − y（目标 forward 时 −0.20，其余五维为各维概率）；策略参数量约 8.47M。
  • 性能锚点（离散 R2R，CVPR 2018）：student-forcing val-seen 38.6%、val-unseen 21.8%、test 20.4%（NE 7.85 m），人类 test 86.4%（NE 1.61 m）；落差 16.8 点（相对 43.52%），模型轨迹 8.13 m 短于最短路，存在提前停止。
  • 复现纪律：显式编码长度、有效步掩码、停止先于步进、评测不触真值、损失口径写清；特征缓存 36 视角、全库约 2.89 GiB。
  • 下一讲引入 speaker 模型：用合成指令把训练数据扩到 178,000 条路径规模，用务实重排在推理期选择解释力最强的路线，并顺带把动作空间升级为全景 36 视角。同一底座在 022 讲将被推到 val-unseen 54.6% 的新高度。
