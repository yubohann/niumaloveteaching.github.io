第一篇 · 任务、数据、仿真与评测地基

第 014 讲｜SOON / FAO：场景描述与任意起点

本讲把「从任意位置出发、只凭一段场景描述找到并确认目标」写成任务：SOON 把导航与目标定位拆成两个可分别评分的子任务，FAO 用四层描述与长程轨迹把起点独立性做成可评测协议。学完能解释场景描述指令与逐步指令的边界，会用 SFPL 口径汇总结果，并能写出图探索（Graph-based Exploration, GBE）的最小动作与教师信号实现。

  • 主题：场景描述型指令 / 任意起点 / 目标定位 / 图探索
  • 关键公式：SFPL = (1/N) Σ Snav Sloc L* / max(Lact, L*)
  • 预计学时：60 分钟
  • 前置讲：第 013 讲（REVERIE：远程物体指代）

学习目标

  • 会写：给出 SOON 两个子任务的成功条件（导航终点到目标位置小于 3 m；定位方向的预测角落入标注包围框），并说明两者为何必须分开评分。
  • 会算：核对 FAO 的 3,848 条指令与四个已公布 split 的指令数、轨迹数闭合关系，推导测试集条数与每指令轨迹数。
  • 会推：从 SPL 与定位成功率合成 SFPL，用自设算例说明定位失败与绕行对复合指标的不同影响。
  • 会判：区分场景描述指令、逐步指令与类别目标指令，指出各自对起点、语言粒度与监督信号的假设。
  • 会实现：把导航状态写成增量特征图，维护候选集 C 与动作空间 |A| = |C| + 1，并实现多目标教师动作。

背景与动机

第 013 讲的 REVERIE 把「高层指令加目标指代」做成了远程物体定位任务，但它的 episode 起点仍由 R2R 路径给定，起点分布与逐步指令任务共享。真实服务场景里的假设更弱：移动机器人在任意位置被唤起，用户只说目标长什么样子、周围有什么、大概在哪一片区域，不描绘逐步路线。Zhu 等 2021 在 CVPR 2021 提出的 SOON（Scenario Oriented Object Navigation，场景导向物体导航）放松了两条假设：起点任意（starting independent），指令目标导向（target oriented）。

放松之后出现三个新的任务结构问题。第一，路线描述失去意义，语言必须靠物体属性、物体关系与区域信息消歧，同一类物体在房内常有多个实例，描述要足以锁定唯一目标。第二，目标可被多个位置观察到，监督信号从单条最短路径变成一组可行轨迹，教师动作需要对多个目标位置取最近。第三，评测必须把「走到了目标附近」与「指出了目标在哪」分开计分，否则无法区分探索失败与识别失败。

为解决这些问题，该工作给出配套基准 FAO（From Anywhere to Object）与图探索方法 GBE。FAO 在 Matterport3D Simulator 上收集 3,848 组三句指令，覆盖 90 个场景中的 3,923 个目标物体，并保留超过 3 万条长程示范轨迹；GBE 把已探索区域写成增量特征图，用图卷积网络（Graph Convolutional Network, GCN）更新节点嵌入，直接在「已观察未访问」的候选节点上做一步决策。原文报告 GBE 在不使用预训练与辅助任务的前提下，在 R2R 与 FAO 两个任务上都超过当时的对照方法（Zhu 等, 2021，CVPR 2021）。

本讲要解决三件事：第一，把 SOON 两个子任务与相邻任务的边界写清楚；第二，把 FAO 的采集规则、规模与 split 算清楚；第三，推导 SFPL 口径并落成可运行的指标与图探索片段。评测指标 NE、OSR、SR、SPL 的通用定义已在 001、006、007 讲固定，本讲只展开目标定位相关的部分。

核心原理

1. 任务定义：导航与定位两个子任务

SOON 的一集（episode）给出一条场景描述型指令与一个任意起点，智能体在离散导航图上行动，直到选择停止。停止后同时判定两件事：导航成功指终点落在任一目标位置的 3 m 邻域内；定位成功指在停止位置的全景观察中，模型预测的目标方向落入标注包围框。写成指示函数：

Snav = 1[ ming ∈ G* dG(vT, g) < 3 m ]，Sloc = 1[ 预测方向落入标注包围框 ] vT 为停止位置，G* 为目标被观察到的位置集合，dG 为导航图最短距离；定位判定以导航成功为前提，导航失败时定位项不计

两点与 R2R 不同。其一，目标位置是集合 G*，SOON 原文明确说明目标物体可被多个位置观察，标注时把所有这类位置都记入，以降低「只有一处算对」的数据偏差；其二，观察内容包含全景 RGB-D、仿真器提供的 GPS 坐标（x, y）与当前及候选节点索引（Zhu 等, 2021，3 节）。第二点属于该基准的观测口径：它允许智能体直接读取自身平面坐标，与 R2R「坐标不进入观测」的约定不同，跨任务比较时必须标注。

2. 与相邻任务的边界

把第一篇出现的几类任务放在同一张表里，可以看清 SOON 的位置：它同时移动了起点轴与语言轴。语言粒度从粗到细的顺序是「类别词、场景描述、逐步指令」，起点轴从固定到任意排列，目标轴从单点到集合。

3. FAO 的采集流程与规模

FAO 的语言标注拆成五步：描述目标属性（颜色、大小、形状）；找出至少两个与目标相关的物体并描述关系；在仿真器中探索并描述目标所在区域；描述邻近区域；把前四步内容改写为连贯的三句话（Zhu 等, 2021，5.1 节）。前四步保证信息完整与表达多样，改写步让语言连贯自然。四层信息分别是物体属性、物体关系、区域描述与邻近区域描述，指令平均 38.6 词，词表 1,649 词；论文在 5.1 节同时报告 REVERIE 为 26.3 词、R2R 为 18.3 词，而引言处按另一分词口径报告 R2R 为 26 词。两处口径不同，引用时写明所用切口，这类差异属于分词规则差异，不改变量级结论。

几何标注覆盖 6,326 个包围框、3,923 个物体，平均每个物体 1.61 个框（同一物体可在多个位置被看见），场景层面平均每个场景 43.6 个标注物体与 42.8 条指令。轨迹采样规则为：固定目标位置、采样起点，要求两点的图距离超过 18 m；若某场景连续 5 次采样失败，阈值乘以 0.8 后重试。折扣序列可以直接算出：18 → 14.4 → 11.52 → 9.216 → 7.373 → 5.898（米）。该退让规则只影响采样成功率，不改变评测口径，但会让长轨迹在部分房型中缺席，分布检查应连同轨迹长度直方图一起报告。

轨迹长度统计上，训练集平均 9.6 跳，R2R 为 6.0 跳，比值 1.6；轨迹按起点到目标的图距离从 15 m 一直延伸到 60 m 以上，超过 R2R 以 4 至 6 段、约 10 m 为主的规模（Zhu 等, 2021，5.1 节）。更长的探索距离是场景描述任务的直接代价：语言不指明路线，智能体需要先按区域描述收缩搜索范围，再按物体关系完成定位，原文把这一过程描述为从大范围到小范围的粗到细导航。

4. 极坐标目标标注

目标位置用极坐标表示，2D 包围框的图像坐标只作判定参照。标注流程为：在 2D 视图上标注包围框的四个顶点，取中心点，再把中心点转成相对相机射线的水平角差 α 与俯仰角差，作为定位标签 (lh, le)。原文给出两点动机：REVERIE 式 2D 视角切分会把跨越两个视角的物体截断，造成漏标；2D 图像的透视畸变会给标注引入噪声（Zhu 等, 2021，3 节）。改用极坐标后，标签与相机朝向解耦，定位分支只需回归两个角度，训练目标为均方误差：

Lloc = (1/N) Σi=1..N [ (l̂hi − lhi)2 + (l̂ei − lei)2 ] lh 为水平角差，le 为俯仰角差，帽号表示预测值；包围框在定位成功判定中仍作为参照，训练标签与判定参照分离

需要留意口径：训练用角度回归，评测用「预测方向是否落入包围框」，两者一致的前提是角度到方向的映射正确。若复现时直接回归包围框中心像素坐标，再与角度标签比较，会因全景投影方式不同产生系统性偏差，修复方式见问题 4。

5. 评测口径：SFPL 的合成

导航指标沿用 NE、OSR、SR、SPL 的通用定义（见 001、006、007 讲）。定位指标为定位成功率，指在导航成功的 episode 中预测方向命中包围框的占比。把两者与路径效率合成，得到按路径长度加权的目标发现成功率 SFPL（Success weighted by Path Length and localization）：

SFPL = (1/N) Σi=1..N Sinav · Siloc · Li* / max(Liact, Li*) N 为 episode 总数；L* 为起点到目标的最短距离；Lact 为实际轨迹长度；权重方向与 SPL 一致，失败或缺定位记 0

符号与 R2R 的 SPL 一一对应：SPL 只乘导航成功指示，SFPL 再乘定位成功指示。由此得到三条可检验的性质：第一，SFPL 不会超过同批数据的 SPL；第二，定位失败把该条的权重整体清零，探索与识别两种失败被合并进一个数字；第三，SFPL 与 SPL 的比值不等于定位成功率，因为被清零条目的路径权重并不相同。用五条自设算例核对（路径与最短距离为教学用数字，不取自数据集）：

Python 实算：SR = 4/5 = 0.800；平均 SPL = 0.609；导航成功者中的定位率 = 3/4 = 0.750；平均 SFPL = 0.449。SFPL / SPL = 0.737，略低于 0.750，原因在条目 B：它的 SPL 权重 0.800 高于全批平均，被定位项清零后把比值压低。这条核验说明读 SFPL 时必须连同定位成功率与 SPL 一起看，单看复合数字无法区分「探索变差」与「识别变差」。

论文表 3 的测试集结果（FAO，未见房）给出三个参照点：人类 SFPL 为 51.1，GBE 为 1.4，随机策略为 0.0；SR 对应 90.4、11.9、2.1；SPL 对应 59.2、10.2、0.4。人机差距在 SR 上为 7.6 倍，在 SFPL 上放大到 36.5 倍，放大效应来自定位项与路径权重的双重筛选。随机策略的低分说明该基准不存在「不加条件也能拿分」的强捷径（Zhu 等, 2021，表 3）。

口径警示

原文式 (10) 的打印记号把两个长度的位置写作 lnav / max(lnav, lgt)，其中 lnav 被说明为导航轨迹长度、lgt 为起点到目标的最短距离。按字面读，若 lnav 为实际长度，则权重会随路径变长而增大（不短于参考距离时恒为 1），与 SPL 的语义方向相悖。复现时先用手算样例对齐方向：本课程按 SPL 惯例（最短距离作分子）实现，并在实验报告中同时单列 SPL 与定位成功率，避免复合指标的记号歧义影响结论。

6. GBE：图状态与多目标教师信号

GBE 的核心是把导航状态维护成一张增量特征图。图规划器持有三个集合：节点特征集 V 存已观察视觉特征，边集 E 记录已确认的可通行关系，节点嵌入集 M 由 GCN 在 V 与 E 上迭代更新。未访问节点的特征是多次观察的平均值；当前步的图特征取当前节点与 k 个邻居嵌入的均值，再与语言特征做跨模态匹配，一路送向候选动作分布，另一路回归定位角度（Zhu 等, 2021，4 节）。

fgt = (1 / (k + 1)) · Σi=0..k fMni，zi = Wnav [ f̃t, fci ]，pt(aci) = exp(zi) / Σj exp(zj) ni 为当前节点与邻居的编号；ci 为候选节点；动作空间 |A| = |C| + 1，多出的一个为停止动作 ac0

候选集 C 只包含「已观察、未访问」的节点，动作空间随探索动态变化，这一点与 R2R 固定的 6 动作接口不同。教师动作由多目标 Dijkstra 距离给出：对每个候选计算它到各目标位置的最小距离，取其中最小者对应的候选；若当前位置已在目标节点上，教师动作为停止。训练目标把三种信号相加：

Lnav = −λ1 Στ1 Σt at* log pt − λ2 Στ2 Σt at log pt At − λ3 Στ3 Σt ât log pt 第一项为示范轨迹的模仿学习（imitation learning），第二项为强化学习（At 为优势函数），第三项为图探索教师信号；ât 为式 (7) 的多目标教师动作

三项的动机在原文 4 节写得很直接：模仿学习只在示范轨迹上监督，在巨大的轨迹空间里占比极低，容易过拟合；强化学习能利用次优轨迹，却难端到端稳定收敛；图探索教师信号取两者之间，利用不完美策略采样出的轨迹、用最近目标逐步纠正，从而在探索中稳定训练。训练配置为 ResNet-101 视觉编码器、LSTM 语言编码器、RMSProp 优化器、学习率 1e-4、共 1 万次交互；三个损失权重 λ 的具体取值论文未报告，复现建议见实现思路一节的图探索超参表。

7. 消融给出的两条结论

原文在 FAO 测试集上做了两组消融。模态消融：视觉单模态 SR 9.8，语言单模态 1.8，双模态 11.9。语言单模态几乎无法完成任务，说明空间先验在目标导向导航中承担主要信号；双模态比视觉单模态高 2.1 个百分点，语言的价值集中在消歧与区域收缩。粒度消融：只有物体名（等价于类别目标导航）SR 7.3、SPL 6.2；加上属性与关系后 SR 6.2、SPL 4.9；再加区域描述后 SR 6.6、SPL 5.5；使用完整改写指令后 SR 11.9、SPL 10.2。中段数字没有单调上升，原文的解释是：物体名单独使用时歧义大，加入关系与区域信息后监督更细，模型收敛路径改变，最终收益要等到完整改写指令才体现；与「只有物体名」相比，完整指令的 SR 高 4.6 个百分点、SPL 高 4.0 个百分点。图探索本身的贡献为：关闭后 OSR 降 0.7、SR 降 0.5、SPL 降 1.5、SFPL 降 0.6，SPL 相对降幅 17.2%。

同一模型在 R2R 上的数字用于说明该方法并未针对 FAO 定制：val-unseen 上 NE 5.20、OSR 67.0、SR 53.9、SPL 43.4；test 上 NE 5.18、OSR 64.1、SR 53.0、SPL 43.4（Zhu 等, 2021，表 2）。

8. 适用边界与失效模式

  • GPS 特权观测：FAO 协议向智能体提供平面坐标与节点索引，真实机器人需要自行定位；迁移时观测字段与结果都不可直接比较，第三篇的连续环境与真机章节会重新定义这部分。
  • 目标唯一性依赖描述质量：数据集通过四层描述与「保证能被找到」的采集规则降低歧义，模型在描述不足时会把同类物体误判为停止点，定位分支只回归角度，不提供实例级验证。
  • 长轨迹的分布偏置：18 m 阈值退让让部分小房型缺少长程样本，按房型分层的轨迹长度可能不均匀，报告时需按房型给出分布。
  • 起点独立性只覆盖位置：训练与验证重采样起点，但初始朝向是否同步随机、朝向默认值是否记录，会影响可复现性；复现实验应把起点与朝向一起写入配置。
  • 复合指标的诊断力有限：SFPL 把探索失败与识别失败合成一个数，定位率与 SPL 必须并列报告；论文内部记号的方向歧义也要先用样例核验。

关键代码与解读

片段 1：FAO episode 与极坐标目标

from dataclasses import dataclass, field

@dataclass
class PolarTarget:
    heading: float          # 目标中心相对相机射线的水平角差, 弧度
    elevation: float        # 俯仰角差, 弧度
    bbox: tuple             # 原 2D 包围框, 只用于定位成功判定

@dataclass
class SOONEpisode:
    scan: str                       # MP3D 场景 ID
    instruction: str                # 三句场景描述
    start: str                      # 任意起点: 不受路径数据约束
    goal_nodes: list                # 目标可被观察的位置集合 G*
    target: PolarTarget
    trajectories: list = field(default_factory=list)   # 同起点多条示范

def nav_success(final_node, goal_nodes, graph_dist, thr=3.0):
    # 多目标取最小距离: 任一位置满足 3 m 即导航成功
    return min(graph_dist(final_node, g) for g in goal_nodes) < thr

def loc_success(pred_h, pred_e, target, tol=0.10):
    # 定位判定: 预测方向与标注方向的两个角度差都在容差内
    dh = abs((pred_h - target.heading + 3.14159265) % 6.28318531 - 3.14159265)
    de = abs(pred_e - target.elevation)
    return dh < tol and de < tol

解读：（1）目标位置用集合字段承载，训练、评测与教师动作共享同一个取最小距离的函数，避免三处口径分叉。（2）角度回归与包围框判定分成两个字段，训练标签用极坐标，判定参照仍保留原始框，两者通过角度到方向的映射对齐。（3）水平角差比较做了 2π 环绕处理，直接相减会在 ±π 边界产生错误差值；俯仰角差不做环绕，因为取值范围只有 ±π/2。

片段 2：多目标 Dijkstra 与教师动作

import heapq

def dijkstra(graph, src):
    """单源最短路, 边权为米; 图在探索中增量扩展。"""
    dist = {src: 0.0}
    pq = [(0.0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float("inf")):      # 过期堆项直接跳过
            continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

def teacher_action(current, candidates, goal_nodes, graph):
    """图探索教师: 去往离任一目标位置最近的候选节点。"""
    if current in goal_nodes:
        return None                            # 已在目标位置, 教师动作为停止
    d_from = {g: dijkstra(graph, g) for g in goal_nodes}
    best, best_d = None, float("inf")
    for c in candidates:                       # 候选集 C = 已观察未访问
        d = min(d_from[g].get(c, float("inf")) for g in goal_nodes)
        if d < best_d:
            best, best_d = c, d                # min 对多目标取最近
    return best                                # 无穷距离时由调用方回退为停止

解读：（1）教师动作与原文式 (7) 对应：先对每个候选求「到各目标的最小距离」，再在候选间取最小者。（2）函数只在训练侧调用，目标位置在评测中不可见，这份代码不得进入部署路径，避免未来信息泄漏。（3）「当前位置在目标集合内」直接返回停止，对应 SOON 中目标可被当前节点观察的情形；调用方对无穷距离做停止回退，防止候选集为空时崩溃。

片段 3：SPL 与 SFPL 汇总

def soon_metrics(rows):
    """rows: (L_star, L_act, S_nav, S_loc) 逐条记录。
    权重方向按 SPL 惯例: 最短距离作分子, max 防抄近路超过 1。"""
    n = len(rows)
    sr = sum(r[2] for r in rows) / n
    spl = sum(r[2] * r[0] / max(r[1], r[0]) for r in rows) / n
    # SFPL 再乘定位指示: 定位失败等于该条清零
    sfpl = sum(r[2] * r[3] * r[0] / max(r[1], r[0]) for r in rows) / n
    denom = sum(r[2] for r in rows)
    loc = sum(r[2] * r[3] for r in rows) / denom if denom else 0.0
    return sr, spl, loc, sfpl

rows = [                     # (L*, L_act, S_nav, S_loc), 单位为米
    (10.0, 11.0, 1, 1),
    (8.0, 10.0, 1, 0),       # 导航成功但定位失败: SFPL 清零, SPL 保留
    (12.0, 30.0, 1, 1),
    (9.0, 9.5, 0, 0),        # 导航失败: 两项都清零
    (15.0, 16.0, 1, 1),
]
sr, spl, loc, sfpl = soon_metrics(rows)
print(f"SR={sr:.3f} SPL={spl:.5f} loc={loc:.3f} SFPL={sfpl:.5f} ratio={sfpl/spl:.4f}")
# 输出: SR=0.800 SPL=0.60932 loc=0.750 SFPL=0.44932 ratio=0.7374

解读：（1）SPL 的分母取 max(Lact, L*)，成功且抄近路时权重上限为 1，绕行按实际长度惩罚。（2）SFPL 在 SPL 的表达式上多乘 Sloc，其余项不动，保证两指标可以直接比较差值。（3）定位率把导航失败的条目从分母排除，衡量的是「走到了之后能否指对」；实算 ratio 0.737 与 loc 0.750 的差异来自条目 B 的权重高于平均，说明复合指标与分解指标必须并报。

常见误区

  • 把目标当单点监督：训练正常但验证成功率明显低于论文。根因：同一物体可被多个位置观察，只对一条最短路径监督会否掉合法轨迹。修复：所有距离对位置集合 G* 取最小，教师动作与成功判定共用同一函数。
  • 起点分布沿用固定协议：在 FAO 上复现时仍按 R2R 的固定起点评测，数字虚高且不可比。根因：FAO 的验证体系把「换起点」单独拆成 val-seen-instruction。修复：评测时按 split 名读取起点重采样规则，同时报告三个验证集。
  • 按论文打印式实现 SFPL：实验结果出现「越绕越高」的异常。根因：式 (10) 的记号编排与 SPL 惯例方向相反，字面实现会把权重方向倒置。修复：先用手算样例核验（本讲片段 3 可作为样例），确认最短距离在分子后再跑全量。
  • 角度标签与像素标签混用：定位成功率低于预期，训练损失却在下降。根因：全景投影方式与包围框投影方式不一致，回归角度与像素判定之间存在系统偏差。修复：统一由相机射线定义角度，用一组已知方向的标注点做投影往返测试。
  • 混引两组语言统计：同一篇论文出现 38 与 38.6 两种指令长度，对照组 R2R 也有 26 与 18.3 两种口径。根因：分词规则与统计范围不同。修复：引用时标出出处小节与分词口径，横向比较只用同一口径下的数字。

小结

  • SOON 把起点任意与目标导向同时引入：导航成功看终点到位置集合 G* 的最小距离小于 3 m，定位成功看预测方向是否落入标注包围框，两个子任务分开计分。
  • FAO 用五步标注得到四层描述；3,848 条指令、3,923 个目标物体、6,326 个包围框；四个已公布 split 共 3,730 条指令、33,230 条轨迹，测试集 118 条为派生值。
  • 采样阈值为 18 m，连续失败每 5 次乘 0.8，得到 18 → 14.4 → 11.52 → 9.216 → 7.373 → 5.898 的退让序列；平均轨迹 9.6 跳为 R2R 的 1.6 倍。
  • SFPL 在 SPL 上再乘定位成功指示；五条算例得 SR 0.800、平均 SPL 0.609、定位率 0.750、平均 SFPL 0.449，比值 0.737 说明复合指标必须与分解指标并报；论文式 (10) 的记号方向需用样例核验。
  • GBE 维护节点特征、边与嵌入三个集合，动作空间为 |C| + 1；训练合成模仿、强化、图探索三项损失；消融显示视觉单模态 SR 9.8、双模态 11.9，完整改写指令把 SR 拉到 11.9。
