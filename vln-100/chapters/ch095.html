第五篇 · 基础模型与 2026 前沿

第 095 讲｜2026 快照 III：全景、蒸馏与效率

第 093、094 讲把系统评测与不确定性摊开之后，还有第三面账没有结算：效率。本讲用三篇 2026 年论文把「更准」拆成三件可计量的事（arXiv 版本已逐一核实，检索日 2026-10-01）。Wang、Wang、Liu、Qi、Lu、Zeng、Qi、Chen 2026（arXiv:2609.34759v1）的 PanoVLN 说明全景输入本身不带来收益：把透视图像直接换成等距柱状全景（equirectangular panorama, ERP）甚至可能掉点，收益来自三处配套修正，动作侧改为长动作序列加置信引导执行（confidence-guided execution, CGE）、监督侧构造 98K 条分支密集轨迹、表征侧用 PanoVGGT 几何特征做残差融合，最终以 4B 骨干在 R2R-CE / RxR-CE Val-Unseen 达到 77.3 / 78.0 SR，较前最优高 11.9 / 8.7 个百分点。Pan、Zheng、Sun、Zhang、Feng、Wang 2026（arXiv:2609.06476v1）的 O2C-Nav 把每步大模型调用压到一次：骨架化路点以编号标记投影到四视角 RGB 图上，模型选路点或输出回退包围框，由快速行进法（Fast Marching Method, FMM）规划无碰撞路径。Chen、Ge、Wang、Cao、Yang 2026（arXiv:2609.33097v1）的 QAD 用可学习查询槽做教师，再把「看哪里、做什么」经令牌自适应蒸馏（NTD）传给浅层学生，参数从 150.78M 压到 9.56M（论文口径减少 93.65%），R2R 测试未见 SR 仅从 80.43 降到 79.12。交付物是效率三本账：模态账、调用账、模型账。

  • 主题：全景适配 / 长动作序列 / 置信引导执行 / 单次调用 / 抽象路点表示 / 查询瓶颈 / 令牌自适应蒸馏
  • 关键公式：ut,i=−log qt,i(ât,i)；Et=max{k : k≤Emin 或 Ut(k)≤B}；sk=1−σ(mk)；V̄t=Vt+α·fψ(Gt)
  • 预计学时：75 分钟
  • 前置讲：第 094 讲（2026 快照 II：不确定性与验证器）

学习目标

  • 会解释：全景输入为何在动作、监督、表征三处需要配套修正；单次调用框架为何要先把路点抽象成图像标记；蒸馏为何选择查询瓶颈作为传递接口。
  • 会算：CGE 的累计不确定性、执行前缀长度 Et；参数与 GFLOPs 的压缩比；调用次数、等待占比与停顿数的关系；令牌自适应权重归一化。
  • 会实现：置信前缀选择、骨架采样与路点投影、NTD 加权蒸馏三段示意代码。
  • 会判断：三种效率手段各自的代价与失效条件，什么场景下值得用长序列换重规划频率，什么场景下必须保留多调用。
  • 会设计：在给定算力与延迟预算下组合模态、调用、模型三条线路，并写清选择依据与需要重标定的量。

背景与动机

第 093 讲的系统评测指出跨协议数字不可直接比较，第 094 讲把不确定性拆成校准覆盖、按需计算、求助延迟三类用法。两讲合起来回答「一步该不该信」，但没有回答「同样的准确率，能否用更少的输入、更少的调用、更小的模型换来」。VLN-CE 的部署代价恰好由这三项主导：输入侧，全景分辨率与历史帧数决定视觉令牌量；调用侧，每步查询大模型的次数决定延迟与通信开销；模型侧，参数量与浮点运算量决定边缘设备能否承载。三篇 2026 年论文各攻一面，且都给出了协议明确的数字，适合放在一张效率表里对照。

三篇论文的共同经验是：效率提升靠替换部件通常无效，必须连同训练目标与执行策略一起改。PanoVLN 的论文明确记录，在相同训练与推理设置下把透视图像换成 ERP 只会带来有限增益，部分配置还下降；O2C-Nav 指出把多种功能塞进单次调用会信息过载，必须先把决策空间压成稀疏标记；QAD 发现通用中间层蒸馏（注意力、特征、logits）不如直接传递一个导航语义明确的查询接口。这三条经验构成本讲的主线。

核心原理

本节按「全景三失配、长序列监督与 CGE、决策中心数据、几何融合、PanoVLN 结果、单次调用、查询瓶颈蒸馏、效率三账、边界」九步展开；派生数字先经 Python 实算，论文数字标注协议。

1. 全景的三处失配与三项修正

ERP 把 360°×180° 视场线性映射到矩形图像，智能体朝向居中，左右边界在身后相接。与透视图像相比，单张全景同时包含四个方向的通路、地标与路线分叉，理论上应支持更好的决策；实测却没有增益。论文给出的诊断是三个环节仍在按透视假设工作：动作预测的时域太短，模型看不到转弯之后的路线；监督数据中分支点稀疏，模型没有被训练去利用可见的多条路径；视觉特征只描述语义内容，缺少跨朝向的空间关系。对应三项修正即长动作序列、决策中心数据、几何感知表征。

判断全景方案是否真实用，先核对这三项是否同时到位；只换输入模态的系统属于未完成适配的半成品。

2. 长动作序列监督与置信引导执行

训练状态 t 的目标是一段长度为 H 的专家动作序列 A*t=(a*t,1,…,a*t,H)，轨迹结束后以停止动作补齐，策略自回归预测，损失为逐位负对数似然的平均。推理时执行多长由不确定性决定：对第 i 个预测位置的 logit zt,i(a)，先做 softmax 得 qt,i(a)，取生成动作 ât,i 的负对数概率

ut,i = −log qt,i(ât,i)，Ut(k) = Σi=1..k ut,i u 越大表示该位置越犹豫；U 是前缀累计不确定性

给定预算 B 与最短执行长度 Emin，执行前缀长度为 Et=max{k∈{1,…,H} : k≤Emin 或 Ut(k)≤B}，执行完后重新观察再规划。实算示例：四步不确定性 [0.08, 0.10, 0.25, 0.60]，累计值为 [0.08, 0.18, 0.43, 1.03]，Emin=2。B=0.20 时第四步越过预算、第三步也越界，Et=2；B=0.45 时第三步累计 0.43 仍在预算内，Et=3；B=0.70 时同样取 3。前两步因 Emin 保底直接通过，说明预算只在犹豫处生效。长时域监督与执行长度是两件事：训练用 H=18 的长目标教路线选择，执行用 CGE 决定何时再看一眼。

3. 决策中心的数据构造

论文构造 98K 条轨迹，覆盖 800 个 HM3D 场景，平均每场景 122.5 条。路线筛选要求分支点至少通向两个不同连通区域，渲染质量检查剔除网格破洞，随后去重；指令按旅行、分支、到达三类路段生成并与回放核对，运动方向、路径选择、停止位置三项检查全部通过才保留。训练状态选取也有讲究：相邻状态的观测相似、目标重叠，H=18 时以步长 6 采样，相邻网格目标的重叠从 17 个动作降到 12 个；持续转弯起点与终点附近额外加样。消融显示，在相同 H=18 与六动作执行的条件下，随机起点采样为 56.4 SR / 49.5 SPL，转弯与终止感知采样升到 62.8 / 57.2，NE 从 5.37 米降到 4.40 米。

4. 几何感知表征

当前 ERP 分配 Nc 个视觉令牌，每帧历史分配 Nh<Nc 个，支持路线选择的同时压低历史开销。冻结的 PanoVGGT 编码器从同一张 RGB 全景提取几何特征，按 ERP 坐标重采样、分组对齐到视觉令牌覆盖的区域，经 MLP 与残差尺度 α 融合：V̄t=Vt+α·fψ(Gt)，令牌数量与顺序保持不变。消融中换用 UniK3D、DA2、DAP 三种几何编码器效果参差，PanoVGGT 在 R2R 与 RxR 上分别把 SR 从 66.6 / 66.5 提到 68.6 / 67.1，说明跨朝向几何线索确实补上了语义特征的短板。默认配置：Qwen3.5-4B 加冻结 PanoVGGT，当前 ERP 960×480、历史 448×224，两极各裁 20°，几何编码输入 1036×518，历史取最近 100 帧中的至多 10 帧，α=0.2，融合在视觉合并器之后，单轮训练。

5. PanoVLN 的结果与消融

主表以 R2R-CE 与 RxR-CE Val-Unseen 协议报告，RGB 单模态、4B 骨干：R2R-CE SR 77.3、SPL 70.6、NE 2.83 米、OSR 83.1；RxR-CE SR 78.0、SPL 65.9、NE 2.85 米、nDTW 73.3。对照前最优（AwareVLN R2R 65.4、CorrectNav RxR 69.3）分别高 11.9 与 8.7 个百分点。仅用 R2R-CE / RxR-CE 训练数据的受限版本为 73.9 / 74.1 SR，加入自建决策数据后再涨。

执行策略消融使用同一几何无关检查点：固定执行 1 / 6 / 12 / 18 个动作的 SR 为 64.6 / 64.2 / 61.4 / 57.2，随机 1 至 18 为 61.3，CGE 为 66.6，对应 SPL 60.5 / 58.7 / 55.4 / 50.9 / 55.6 / 61.5。固定长前缀会执行越来越不可靠的动作，随机前缀忽略模型置信，CGE 同时优于最短固定前缀与全部长固定前缀，说明自适应长度本身贡献了约 9.4 个 SR 点。时域消融还给出一个关键对照：透视策略在 H=4 附近见顶，ERP 策略在 H=18 上更优。

真机实验在 Unitree Go2 上完成，Insta360 X5 固定在离地 1.5 米处，远端 RTX 3090 推理、显存约 12 GB、网络往返平均 272 毫秒；20 组配对指令上，PanoVLN 平均导航 86.4 秒、速度 25.7 厘米/秒、等待占比 13.6%、停顿 5.4 次、策略调用 7.4 次；对照 StreamVLN 为 117.8 秒 / 34.3 次调用 / 等待 27.1%，NaVid 为 135.2 秒 / 29.4 次调用，JanusVLN 为 412.9 秒 / 101.7 次调用。相对 StreamVLN，时间少 26.7%、调用少 78.4%、等待占比低 49.8%；长段执行配合置信前缀把调用频率压下来，这是运动连续性的直接来源。

6. 单次调用：抽象路点表示与确定性规划

O2C-Nav 的目标是每步只调用一次多模态大模型。做法分三层：先用深度与位姿增量构建二维可通行栅格，经形态学闭运算与中轴变换得到单像素骨架，保留度为 1 的走廊端点与度大于 2 的分叉，再按采样间隔做非极大值抑制，得到稀疏候选路点；随后把候选点按相机内参投影到四视角 RGB 图（0°/90°/180°/270°）上，渲染成带唯一编号的标记，历史访问点用另一颜色区分；大模型读指令、四视图、访问计数警告与物体列表，输出方向与路点编号，无候选时改输出回退包围框；最后把像素目标反投影为世界坐标，用快速行进法在可通行代价图上求无碰撞路径。骨架采样间隔 dsample=0.5 米最优，取 0.2 与 0.8 都变差；栅格 5 厘米，两格侵蚀给 0.10 米安全裕度。

目标检测用 Grounding DINO，历史窗口 5 步，回退包围框去掉后 SR 从 45.0 降到 40.0、SPL 从 31.2 降到 27.1，说明边缘场景仍需要兜底目标。候选数量为每步 9.56 个，多于 SmartWay 的 3.90 与 STRIDER 的 3.45，但调用只需一次，而对照方法为 2 至 3 次。R2R-CE 标准 100 集子集上，Gemini-2.5-Pro 版本 SR 49.3、NE 5.75 米；GPT-4o 版本 SR 42.0、SPL 31.2；RxR-CE 的 1,223 集英文子集上 Qwen3-VL-235B 版本 SR 28.4、SPL 18.7。失败审计覆盖 54 个失败回合：路点选择错误 36 个（66.7%）、到达后未停 12 个（22.2%）、楼梯等覆盖缺口 6 个（11.1%）。

效率方面给出了完整的单步分解：四视角采集 10.05 秒、建图 0.08 秒、骨架化 0.48 秒、投影 0.04 秒、大模型 8.17 秒、规划 0.76 秒，合计 19.58 秒（Jetson Orin NX）。对照 SmartWay 24.82 秒、STRIDER 37.72 秒，单次调用把端到端延迟比双调用与三调用方案分别压低 21.1% 与 48.1%，但绝对量级仍在十几秒，部署时要用异步执行与低层控制解耦，不能按逐帧闭环理解。

7. 查询瓶颈蒸馏：QAD

QAD 先训练一个导航证据显式的教师：局部支路编码当前视点一步可达候选，全局支路维护访问拓扑图，小型可学习查询槽经交叉注意力从两支里抽取全局与局部可导航查询（query），再由指令与查询对齐器把指令语义逐步融入查询，形成紧凑跨模态状态后接策略头。教师与学生的查询槽数相同（KL=KG=32），学生只缩深度：文本与全景编码层从 6 / 2 降到 1 / 1，查询生成器从 4 个交叉注意力块降到 1，对齐器从 3 层降到 1 层。

蒸馏分两层。预训练阶段用令牌自适应蒸馏（NTD）：对归一化后的师生查询逐槽求余弦相似度 mk，权重取 sk=1−σ(mk) 并在分支内归一化，越不对齐的槽位获得越大的权重，损失对全局、局部两支分别加权求 L2。示例：槽相似度 [0.8, 0.2] 给权重 [0.310, 0.450]、归一化后 [0.408, 0.592]，落差大的槽位被放大。微调阶段再加策略分布 KL，总损失 LD=α·LNTD+(1−α)·Lπ，α=0.5 时在 R2R 与 REVERIE 上取得最好的精度效率折中。

结果按统一测量协议（batch 8、指令 44 词、3 个候选节点、6 个历史节点，仅计前向）：参数 150.78M 到 9.56M，论文口径减少 93.65%；计算量 45.56 到 1.92 GFLOPs，降幅 95.8%，约 23.7 倍。精度损失很小：R2R 测试未见 80.43 / 71.98 降到 79.12 / 69.54 SR / SPL；RxR 验证未见 77.1 / 69.9 到 73.4 / 67.2；REVERIE 测试未见 60.19 / 44.21 到 59.03 / 43.12；SOON 测试未见 43.42 / 28.03 到 41.03 / 27.11。Jetson Nano 单步吞吐：学生 51.6 步/秒，教师 29.1，GOAT 15.9，学生约为教师 1.8 倍、GOAT 3.2 倍。消融给出结构结论：学生去掉 NTD 降到 70.23 SR，去掉策略 KL 降到 76.17，两者都去掉 67.21，令牌自适应权重换成均匀权重 77.52，通用注意力加特征加 logits 蒸馏 78.31，完整版本 79.12。传递「选哪里的证据」比传递通用中间表示更有效，接口本身的选择才是蒸馏的杠杆。

三本账可以叠加使用：模态账改变输入与执行节奏，调用账改变每步的推理组织，模型账改变承载模型的大小。组合时先确认瓶颈所在，若瓶颈是通信与调用，优先做调用账；若瓶颈是边缘显存与算力，优先做模型账；若瓶颈是输入信息不足导致的错误，模态账才有意义。

9. 边界与失效模式

  • 全景的收益有前提：论文的输入替换实验证明，缺少长时域监督与几何融合时 ERP 不产生增益；H=18 的配置也在 H=8 到 18 的区间内报告了单调改善，超出训练时域继续加长没有依据。
  • CGE 的预算 B 依赖状态分布：B 在训练分布外（例如楼梯、镜面走廊）会系统性地多执行或少执行，部署需要留出重标定数据；论文未提供 B 的跨场景迁移保证。
  • O2C 的延迟口径是决策阶段：19.58 秒包含四视角采集与建图，低层控制与传感器时间另计；跨论文比较延迟必须统一计时边界，19.58 秒不能与第 094 讲的 0.08 秒验证器路径直接并列。
  • 蒸馏的精度保持是分布内的：学生与教师共享查询槽设计，槽索引才可对齐；更换教师结构后 NTD 的逐槽相似度失去意义，需要重新设计传递接口。
  • 真机数字是小样本：PanoVLN 真机为 20 组配对指令，O2C 为每任务 10 次试验（VLN 5/10、ObjectNav 5/10），用于验证可行性，不用于方法排序。

实现思路与设计

三条线路可以独立接入现有导航栈，也可以组合。设计纪律相同：先定瓶颈，再改部件，最后用留出数据重标定阈值。

PanoVLN 接入流程

  1. 输入改造：当前帧用 ERP 高分辨率、历史帧降采样；两极裁切消除畸变最重的区域；总视觉令牌预算固定，当前与历史按 Nc / Nh 分配。
  2. 训练改造：目标改为 H 步动作序列，数据补充分支密集路线与转弯、终止状态；几何编码器冻结，只训投影 MLP 与主网络。
  3. 执行改造：按 CGE 规则取前缀，执行完重观察；Emin 保底避免高置信步频繁重规划。

O2C-Nav 接入流程

  1. 每步先建局部栅格与骨架，采样间隔 0.5 米；保留关键拓扑节点，历史点合并阈值取 0.5 米。
  2. 候选点投影到四视角并编号，访问过的点换色；维护访问计数，超过阈值时在提示中加入防循环警告。
  3. 模型输出路点编号或回退包围框；反投影后交给 FMM，低层执行与感知异步解耦。

QAD 接入流程

  1. 先训教师到收敛并冻结；学生缩深度但保持查询槽数与分支结构不变，槽索引逐位对应。
  2. 预训练只用 NTD；微调时 LD=α·LNTD+(1−α)·Lπ，α 在留出集上扫。
  3. 部署前按统一步骤测量参数、GFLOPs 与设备吞吐，三者一起报告。

关键代码与解读

三段代码分别给出 CGE 前缀选择、骨架路点采样与投影、NTD 加权蒸馏。示意实现，接口按三篇论文的公开公式重写。

片段 1：CGE 执行前缀选择

import math

def softmax(logits):
    m = max(logits)
    exps = [math.exp(z - m) for z in logits]
    total = sum(exps)
    return [e / total for e in exps]

def cge_prefix_length(logits_per_step, e_min=2, budget=0.45):
    """按累计不确定性选择执行前缀：预算内执行，E_min 保底。"""
    U = 0.0
    E = e_min
    for k, logits in enumerate(logits_per_step, start=1):
        p = softmax(logits)              # 四个动作上的概率
        a_hat = max(range(len(p)), key=lambda a: p[a])
        u = -math.log(p[a_hat])          # 单步不确定性 u_{t,i}
        U += u
        if k <= e_min or U <= budget:    # 最短执行或累计预算内
            E = k
    return E

# 实算示例：u=[0.08,0.10,0.25,0.60], E_min=2
# budget=0.20 -> E=2；budget=0.45 -> E=3；budget=0.70 -> E=3

解读：（1）u 取生成动作的负对数概率，越大越犹豫；U 逐位置累加，预算在犹豫处自然截断前缀。（2）Emin 用「或」条件先放入循环，高置信步不会因预算过紧退化成逐动作重规划。（3）函数只依赖每步 logits，可以挂在任何输出动作分布的策略后面；部署时把预算与最短长度写进配置，禁止硬编码在策略类里。

片段 2：骨架路点采样与四视角投影

def skeleton_waypoints(trav_mask, delta, d_sample, merge_eps):
    """从可通行掩码抽取稀疏候选：关键节点保留，沿线非极大值抑制。"""
    skeleton = medial_axis(trav_mask > 0)     # 单像素宽拓扑骨架
    key = [p for p in skeleton
           if degree8(p) == 1 or degree8(p) > 2]   # 端点与分叉
    sampled = nms_along(skeleton, d_sample / delta) # 间隔 d_sample 米
    return merge_close(key + sampled, merge_eps)    # 合并过近节点

def project_markers(points_world, pose, K):
    """把 3D 路点投影到四视角 RGB，渲染带编号的标记。"""
    uv = []
    for idx, p in enumerate(points_world):
        p_cam = world_to_camera(p, pose)        # 相机坐标系
        if p_cam[2] <= 0.05:                    # 后方或过近的点丢弃
            continue
        u = K[0][0] * p_cam[0] / p_cam[2] + K[0][2]
        v = K[1][1] * p_cam[1] / p_cam[2] + K[1][2]
        if 0 <= u < W and 0 <= v < H:          # 视场内才渲染
            uv.append((idx, u, v))
    return render_numbered_markers(uv)          # 历史点换色，候选点编号

解读：（1）关键节点（度 1 的端点、度大于 2 的分叉）全部保留，弥补均匀采样可能漏掉的转向口；安全裕度由栅格侵蚀另算，与采样间隔解耦。（2）投影后落在相机后方或视场外的点直接丢弃，避免向模型提供几何上无效的标记；编号是跨视角引用同一路点的唯一标识。（3）历史点与候选点用不同颜色，这一步把「显式记忆」做进了视觉输入，模型无需文本记录已访问位置。

片段 3：令牌自适应蒸馏权重

import torch
import torch.nn.functional as F

def token_adaptive_weights(q_teacher, q_student):
    """按槽位对齐程度给权重：越不对齐，蒸馏权重越大。"""
    t = F.normalize(q_teacher, dim=-1)       # (K, d)
    s = F.normalize(q_student, dim=-1)
    m = (t * s).sum(dim=-1)                  # 同槽位余弦相似度
    w = 1.0 - torch.sigmoid(m)
    return w / (w.sum() + 1e-6)              # 分支内归一化

def ntd_loss(queries):
    """全局与局部两支分别加权，权重和恒为一。"""
    qt_l, qs_l, qt_g, qs_g = queries
    wl = token_adaptive_weights(qt_l, qs_l)
    wg = token_adaptive_weights(qt_g, qs_g)
    ll = (wl * (qs_l - qt_l).pow(2).sum(-1)).sum()
    lg = (wg * (qs_g - qt_g).pow(2).sum(-1)).sum()
    return ll + lg

# 微调时 L_D = alpha * L_NTD + (1 - alpha) * KL(teacher || student)
# 示例：m=[0.8,0.2] -> 归一化权重 [0.408, 0.592]

解读：（1）师生共享查询槽设计，槽索引逐位可比，这是 NTD 成立的结构前提；换教师结构后必须重做接口。（2）权重由相似度经 sigmoid 反向映射，对齐差的槽位得到更大权重，分支内归一化保证总权重稳定。（3）策略 KL 与 NTD 用 α 配比，消融显示两者都不可省：去掉 NTD 或策略 KL 分别跌到 70.23 / 76.17 SR，通用 KD 对照仅 78.31，完整版 79.12。

常见坑

  • 只换输入模态就宣称全景增益：把透视图像换成 ERP 后指标原地踏步甚至下降。根因是动作时域、监督数据、视觉表征仍按透视假设设计。修复：三项修正同步落地，并用同一检查点做输入替换对照。
  • 把执行长度或预算当超参随意调：Emin 设得过小导致每步重规划，B 设得过大导致长前缀执行到不可靠动作。根因是两者语义不同。修复：Emin 按控制频率下限确定，B 在留出状态分布上标定，两者分开扫描。
  • 用单步延迟证明实时性：把含采集与建图的 19.58 秒与纯验证器路径的 0.08 秒并列比较。根因是计时边界不一致。修复：报告阶段分解（本例六个阶段全部列出），并把低层控制与感知分频解耦。
  • 学生过浅且删掉蒸馏接口：小模型直接监督训练后 LR 掉到 67.21 SR，远低于教师。根因是证据选择能力没有传递通道。修复：保留查询瓶颈作为传递接口，先 NTD 后策略 KL，α 在验证集上选。
  • 稀释候选路点或省略回退：dsample 偏离 0.5 米、去掉包围框回退都会掉点。根因是稀疏候选漏掉拓扑节点，边缘场景没有兜底目标。修复：保留关键节点、按统一间隔抑制，回退包围框保留并单独统计其触发率。

小结

  • 全景输入本身不产生增益：PanoVLN 的三项修正是长动作序列监督、决策中心数据、几何感知表征；R2R-CE / RxR-CE Val-Unseen 达 77.3 / 78.0 SR，较前最优高 11.9 / 8.7 个百分点。
  • CGE 用累计不确定性在预算内选择执行前缀，实算示例 B=0.20 / 0.45 / 0.70 对应前缀 2 / 3 / 3；消融中 CGE 的 66.6 SR 高于全部固定长度与随机前缀。
  • O2C-Nav 以骨架稀疏路点加编号标记做到每步一次调用：候选 9.56 个/步、单步 19.58 秒（Orin NX），比 SmartWay 与 STRIDER 低 21.1% 与 48.1%；失败集中在路点选择（66.7%）。
  • QAD 把查询瓶颈作为蒸馏接口：150.78M→9.56M（论文口径 93.65%）、45.56→1.92 GFLOPs，R2R 测试未见 79.12 SR；NTD 与策略 KL 缺一不可。
  • 效率三本账：模态账改输入与执行节奏，调用账改每步推理组织，模型账改承载规模；先定位瓶颈，再选部件，跨论文数字先对齐协议。下一讲进入快照第四篇：记忆与闭环纠错（第 096 讲）。
