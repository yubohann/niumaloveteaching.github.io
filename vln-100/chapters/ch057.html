第 057 讲｜视角与高度变化鲁棒性

本讲拆解 Sun 等 2025（RA-L 2026，arXiv:2507.08831v4）的 V2-VLNCE 与 VIL：相机高度与俯仰在 ±0.5 米 × ±30° 内变化时，ETPNav 在 R2R-CE val-unseen 的成功率从 56.8% 降到 47%，VIL 后回到 55%；跨 81 个固定视角的 SPL 标准差从 10.79 降到 3.59；真机 TurtleBot2 零样本实验中，办公室与休息区的成功率分别从 28% 提升到 44%、从 20% 提升到 48%。

  • 主题：视角不变性 / 对比学习 / 教师-学生蒸馏 / 真机部署
  • 关键公式：Lcl = −log exp(sim(q,k+)/τ) / [exp(sim(q,k+)/τ) + Σ exp(sim(q,k−)/τ)]；L = Lnav + λ1Lcl + λ2Lwpd
  • 预计学时：60 分钟
  • 前置讲：第 056 讲（指令错误与数据讹误鲁棒性）

学习目标

  • 会写：复述 V2-VLNCE 的视角采样定义、VIL 的两个组件（对比学习与路点蒸馏）与联合训练目标。
  • 会算：由训练高度范围反推标准高度；核算变化视角相对标准视角的指标损失，以及跨 81 视角的标准差降幅。
  • 会实现：视角与俯仰采样、同一朝向下的 InfoNCE 正负样本构造、冻结教师与适配器学生的蒸馏损失。
  • 会判断：给定一个机器人相机位姿，判断它相对训练分布是分布内还是分布外，并选择重训、后训练适配或数据增广路线。
  • 会诊断：对比学习表示坍塌、蒸馏信息泄漏、高度符号与测量误差三类问题的成因与修复。

背景与动机

第 056 讲处理指令侧扰动，本讲处理观测侧的同类问题。标准 VLN-CE 在固定视角下训练与评测：相机高度固定，俯仰为零。真实机器人上，相机安装位置由机械结构决定，不同平台的视角差异很大。论文把这一情形形式化为 V2-VLNCE：在每个 episode 中，从高度与俯仰的联合分布中采样一个视角，检验策略在视角变化下的稳定性。此前的 GVNav 只处理单一固定地面高度（0.8 米），并靠重新训练适配；论文的实验表明，单靠重训不足以覆盖高度与角度的连续变化。

论文的出发点与第 056 讲不同：不重建策略，做后训练适配。VIL（View Invariant Learning）在预训练检查点之上加两个轻量组件，对比学习让同一场景在不同视角下的特征靠近，教师-学生框架让路点预测器在变化视角下模仿标准视角的教师输出；两者与导航损失端到端联合优化。论文报告后训练只用 48 小时，而 ETPNav 完整训练约 11.5 天。

本讲先定义视角协议与指标，量化基线在视角变化下的损失，再讲 VIL 两个组件的数学形式与超参，随后给出仿真与真机结果、边界与失效模式。第 058 讲把这些结果落到系统集成：相机怎么装、观测怎么装配、策略怎么接进导航栈。

核心原理

本讲按「视角协议、数据与指标、基线敏感度、对比学习、路点蒸馏、联合训练、结果、边界」展开；所有换算由 Python 实算，论文数字标注表格与协议。

1. V2-VLNCE：视角协议

论文把相机视角表示为二元组 (h, θ)：h 为相对标准安装的高度偏移（米），θ 为俯仰或视角偏移（度）。V2-VLNCE 的采样分布为

(h, θ) ~ U([−0.5 m, 0.5 m]) × U([−30°, 30°]) 相对标准 VLN-CE 配置；每个 episode 采样一次，高度与角度相互独立（Sun 等 2025，R2R-CE 与 RxR-CE 协议）

论文真机实验给出训练时的高度范围为 0.75 米到 1.75 米，按 ±0.5 米偏移反推，标准安装高度为 1.25 米。这个推断在文档中只是一句算术，但它决定了如何判断部署视角的分布内与分布外：真机相机实测 0.7 米，比训练下限 0.75 米低 0.05 米，论文据此把真机实验定性为零样本的外分布（OOD）评测。

对照设置是 GVNav 的地面视角协议：固定高度 0.8 米、不改变角度，并重训模型适配。V2-VLNCE 同时覆盖高度与角度，且不要求重训核心策略，这是协议层面的主要区别。

2. 数据与指标口径

两个基准沿用连续环境协议：R2R-CE 共 5611 条轨迹，平均路径长度 9.89 米（An 等 2023 表 I），指令平均 32 词；RxR-CE 指令平均 120 词，是 R2R-CE 的 3.75 倍，平均路径 15.23 米，是 R2R-CE 的 1.540 倍。指标沿用第 006 至 008 讲的定义：NE（终点距离，米）、SR（终点距离低于 3 米）、OSR（oracle 停止下的成功率）、SPL、nDTW 与 SDTW。视角变化只改变观测的采集参数，episode、指令与目标不变，因此所有指标可与同 split 的标准视角结果配对比较。

3. 基线敏感度：视角变化造成的损失

把论文两张表放在一起看，可以量化「固定视角训练的策略在视角变化下损失多少」。以 R2R-CE val-unseen 为例，ETPNav 标准视角 SR 为 56.8、变化视角为 47，损失 9.8 个百分点；SPL 从 48.9 到 38，损失 10.9。BEVBert 的对应数字为 SR 59.1 到 49（10.1 个百分点）、SPL 49.2 到 39（10.2）。val-seen 的损失更大：ETPNav SR 65.8 到 49（16.8 个百分点）、SPL 59.2 到 42（17.2）。

4. 对比学习组件：稀疏的视角不变特征

VIL 在视觉编码器后接一个三层投影头 g(·)（参照 SimCLRv2 的设计）：第一层 g1 的输出 ftask 供导航任务使用，第三层 g3 的输出 fcontrast 供对比学习使用。为不破坏预训练检查点的特征分布，g1 初始化为单位矩阵，训练中逐渐适配。

对每个训练样本，同一场景生成两个视角：标准视角 Ostd 与随机偏移视角 Ovar。全景共 12 个朝向，间隔 30°。正样本对为同一朝向 j 在两种视角下的特征；负样本有两类：批内其它场景的同朝向特征（实现上把索引平移一位，取 (i + 1) mod B），以及同场景内相差 6 个朝向（180°）的难负样本 (i, (j + 6) mod 12)。损失为 InfoNCE：

Lcl = −log exp(sim(q, k+) / τ) / [ exp(sim(q, k+) / τ) + Σk− exp(sim(q, k−) / τ) ] q 为标准视角特征，k+ 为变化视角同朝向特征，sim 为余弦相似度，τ = 1.0

把 180° 朝向设为难负样本，是为了防止「所有帧特征都互相靠近」的退化解：正样本只跨视角、不跨朝向，表示必须保留朝向区分度。这个细节决定对比学习带来的增益，是复现时最容易做错的部分。

5. 教师-学生路点蒸馏

路点预测器是连续环境模型的标准部件（第 043 讲），负责从全景输入预测附近可导航路点的热力图。论文观察到：在标准视角训练的路点预测器换到地面视角后明显退化。GVNav 的修复方式是用目标视角数据重训预测器，成本高；VIL 改用蒸馏：

  • 教师网络从预训练检查点初始化，整个训练期间冻结，只接收标准视角观测；
  • 学生网络与教师结构相同，接收变化视角观测，只把输入线性层作为适配器设为可训练，其余权重冻结；
  • 蒸馏损失为 KL(softmax(Steacher) ‖ softmax(Sstudent))，两个 logits 先做 softmax 再算散度；
  • 构建局部拓扑图时按概率 p2 使用教师预测、按 1 − p2 使用学生预测，让学生逐步接管。

这套设计的关键取舍是「容量放在哪里」：适配器只有输入层，训练信号集中在视角差异最大的入口；策略主干与路点预测器主体保持预训练知识，避免在小规模后训练数据上过拟合。

6. 联合训练目标与超参

L = Lnav + λ1 Lcl + λ2 Lwpd 超参：λ1 = 0.2，λ2 = 10.0，p1 = p2 = 0.1，τ = 1.0；全部模块端到端联合优化，从官方预训练检查点初始化

p1 是构建图表示时选用变化视角特征的概率，p2 是构建拓扑图时选用教师路点的概率；两者都取 0.1，意味着训练早期大部分计算仍走标准视角与教师输出，适配是渐进完成的。λ2 = 10.0 远大于 λ1 = 0.2，反映路点质量对导航结果的直接影响更强。

7. 结果：仿真与真机

在 V2-VLNCE 设置下，VIL 加在 ETPNav 上的提升（由表 I 差值实算，单位为百分点）：R2R-CE val-unseen SR +8、SPL +7、OSR +6、nDTW +4、NE −0.68 米；val-seen SR +15、SPL +13、OSR +11、nDTW +7、NE −1.14 米。RxR-CE 上的提升更大：val-unseen SR +11、SPL +10、OSR +9、nDTW +10、NE −1.40 米；val-seen SR +15、SPL +15、OSR +13、nDTW +13、NE −2.08 米。论文摘要的「8% 至 15% SR 提升」即指上述百分点区间。加在 BEVBert 上同样有效：R2R-CE 变化视角 val-unseen SR 从 49 到 52、SPL 从 39 到 44。

标准视角下 VIL 不退化的证据：R2R-CE val-unseen 上 ETPNav 的 SR 从 56.8 到 58.3（+1.5）、SPL 从 48.9 到 49.7（+0.8）；BEVBert 的 SR 从 59.1 到 58.6（−0.5）、SPL 从 49.2 到 49.6（+0.4）；RxR-CE val-unseen 上 ETPNav 的 SR 从 53.8 到 55.6（+1.8）、SPL 从 43.9 到 46.2（+2.3）。结论二：面向变化视角的后训练在标准视角上总体持平或小幅提升，个别指标存在 −0.5 量级的波动，报告时必须同时给出两套视角的数字。

消融（R2R-CE，val-unseen）给出组件分工：只重训的模型在变化视角下 SPL 39.1，相对基线 38.4 仅提升 0.7，但标准视角 SPL 从 48.9 掉到 47.7（−1.2），说明数据增广式重训以标准视角性能换变化视角性能；加入对比学习后变化视角 SPL 37.2，未达预期；加入路点蒸馏后回到 42.7；三项齐全为 45.5。按「去掉一个组件看下降」的口径：路点蒸馏贡献变化视角 SPL 8.3、标准视角 SPL 4.1；对比学习贡献变化视角 SPL 2.8、标准视角 SR 0.7 与 SPL 1.0。结论三：路点蒸馏是主要增益来源，对比学习是补充项；这一排序提示复现时优先保证蒸馏链路正确。

8. 视角稳定性、真机配置与分布外外推

论文在 81 个固定视角上评测指标的标准差。ETPNav 的 SPL 标准差从 10.79 降到 3.59，按表中数值计算降幅 66.7%（论文正文记为约 65%）；SR 从 10.54 到 3.66（65.3%），NE 从 0.82 到 0.28（65.9%）。视角变化不仅压低均值，也放大波动；VIL 同时改善两者，这是部署场景更关心的性质。

真机相机安装位姿映射：论文用 Stretch RE-1、Stretch RE-1（工厂配置）与 LoCoBot 三种真实平台的相机外参在仿真中做固定视角评测。val-unseen 上，Stretch RE-1 的 SR 从 23.1 到 43.7（+20.6）、SPL 从 15.5 到 35.4（+19.9，相对提升 128.4%）；工厂配置 SR 从 22.7 到 40.3（+17.6）；LoCoBot 相机高度与标准接近，SR 从 54.2 到 56.0（+1.8）。提升幅度与视角偏离程度正相关：偏离越大，后训练适配的收益越大。

分布外外推用两个极端视角 (−0.5 m, 30°) 与 (0.5 m, −30°) 检验。训练分布取大范围 ±0.5 m/±30° 时，测试点落在分布边界；取小范围 ±0.4 m/±20° 时，测试点完全在训练支撑之外。小范围模型在 val-unseen 上仍把 SPL 从 25.9 提到 39.2（+13.3，视角 (−0.5 m, 30°)）、从 37.9 提到 44.2（+6.3，视角 (0.5 m, −30°)），与大范围模型的差距有限。真机实验为 TurtleBot2 平台：RICOH THETA X 全景相机、Ouster OS0 Rev6 激光雷达、Intel NUC 11 机载计算，两者外参标定后融合出 12 路对齐的 RGB-D 视图；机器人经 ROS 2 与远程服务器通信，服务器用 NVIDIA A5000 推理。训练高度覆盖 0.75 至 1.75 米，真机相机 0.7 米在外分布范围。两个环境各 5 条指令、每条从不同起点重复 5 次（每个环境 25 次运行）：办公室成功率 28% 到 44%，休息区 20% 到 48%。

9. 计算开销与边界

开销可以概括为「参数几乎不变、训练时间显著变短」：完整 VIL 模型 335.21M 参数（可训练 143.21M），基线 317.31M（可训练 142.93M），总参数量增加 17.9M，可训练参数只增加 0.28M；峰值显存从约 6000 MB 升到 6200 至 6300 MB；推理只多一次线性投影。ETPNav 完整训练约 11.5 天，VIL 后训练收敛 48 小时。按这两个原始数字计算，48 / 276 = 17.4%，论文正文概括为约 14%；两者不一致时以原始小时数与天数为准，概括值仅作参考。

  • 范围外推有限：小范围模型在两极端视角上仍有效，但更远的视角（如高于 1.75 米或俯仰超过 60°）没有实验证据。
  • 真机样本量小：单平台、两个环境、每个环境 5 条指令，结论的统计置信区间较宽；论文将其定位为概念验证。
  • 训练数据依赖：后训练建立在 R2R-CE 预训练与教师检查点之上，更换主干需要重新配置蒸馏。
  • 标准视角的轻微波动：BEVBert 在 R2R-CE val-unseen 的 SR 有 −0.5 的退化，属于报告口径内可接受的抖动，但不应隐去。
  • 评测口径：成功阈值 3 米、动作上限与停止判定按第 048 讲协议；变化视角实验不改变 episode 与目标，只改观测。

适配器路点预测器输入线性层可训练参数仅 0.28M 量级适配点放在视角差异入口
设计决策：后训练适配优先于重训，判据是「是否要保留导航预训练收益」

重训路线在变化视角上只有小幅收益且拖低标准视角，后训练路线在两类视角上都接近无损。若手头已有预训练检查点且算力以天为单位计，选择后训练；若目标视角与训练视角差异巨大（比如安装高度低于 0.5 米或俯仰超过 60°），需要先补视角覆盖数据，再考虑是否重训。

与相邻讲的分工：第 056 讲扰动指令，本讲扰动观测，二者共用「配对评测加相对量」的方法论；第 058 讲把本讲的真机相机位姿结论落到系统级接口，包括相机选型、外参标定与观测装配。

关键代码与解读

三段代码分别给出视角采样、跨视角对比损失、教师-学生蒸馏。接口按论文与公开实现的设计为参照，版本演进时以仓库为准。

片段 1：视角采样与观测构造

import random

STANDARD_HEIGHT_M = 1.25          # 由训练范围 [0.75, 1.75] 反推
STANDARD_PITCH_DEG = 0.0
HEADINGS = 12                     # 全景 12 个朝向，间隔 30 度

def sample_viewpoint(rng, dh=0.5, dtheta=30.0):
    """在标准视角上叠加高度与俯仰扰动，返回 (h, theta)，单位 米、度。"""
    h = rng.uniform(-dh, dh)              # U(-0.5, 0.5)
    theta = rng.uniform(-dtheta, dtheta)  # U(-30, 30)
    return h, theta

def build_observation(panos, h, theta):
    """给出 12 路观测的取景参数；重投影由具体成像模型实现，需与训练口径一致。"""
    views = []
    for j in range(HEADINGS):
        heading = j * (360.0 / HEADINGS)
        views.append({"heading": heading,              # 水平朝向
                      "height": STANDARD_HEIGHT_M + h,  # 绝对高度
                      "pitch": STANDARD_PITCH_DEG + theta})  # 绝对俯仰
    return views

rng = random.Random(0)
h, theta = sample_viewpoint(rng)
print(round(h, 3), round(theta, 2))   # 例如 -0.312 -17.4

解读：（1）标准高度由训练范围反推得到，代码里写成常量并在注释里给出推导，避免不同实验各写一个值。（2）采样函数返回偏移量，绝对姿态由装配参数（真机外参）相加得到，两者分离便于把仿真结果映射到真机。（3）视角重投影必须与预训练数据的成像口径一致（视场、裁剪、内参），否则协议里的 0.75 至 1.75 米与真机的 0.7 米无法对齐。

片段 2：跨视角对比损失

import torch
import torch.nn.functional as F

def view_contrastive(q, k_pos, k_cross, k_opposite, tau=1.0):
    """跨视角 InfoNCE：正样本为同朝向两种视角，负样本含跨场景与对向朝向。
    q / k_pos: (B, 12, D)；k_cross、k_opposite 与 q 同形状。"""
    q = F.normalize(q, dim=-1)
    k_pos = F.normalize(k_pos, dim=-1)
    logits_pos = (q * k_pos).sum(-1, keepdim=True) / tau        # (B, 12, 1)
    neg = torch.stack([F.normalize(k_cross, dim=-1),
                       F.normalize(k_opposite, dim=-1)], dim=-1)  # (B, 12, D, 2)
    logits_neg = torch.einsum("btd,btdn->btn", q, neg) / tau    # (B, 12, 2)
    logits = torch.cat([logits_pos, logits_neg], dim=-1)        # 正样本在第 0 位
    labels = torch.zeros(logits.shape[:-1], dtype=torch.long)
    return F.cross_entropy(logits.reshape(-1, logits.shape[-1]),
                           labels.reshape(-1))

# 负样本构造：批内平移一位取跨场景，同场景取 (j + 6) % 12 的对向朝向
k_cross = torch.roll(f_var, shifts=1, dims=0)
k_opposite = torch.roll(f_std, shifts=6, dims=1)
loss_cl = view_contrastive(f_std, f_var, k_cross, k_opposite)

解读：（1）正样本只跨视角不跨朝向：同一朝向 j 的标准与变化视角特征配对，保证朝向信息不被对齐掉。（2）对向朝向 (j + 6) mod 12 是难负样本，用于抑制「全景帧彼此靠近」的坍塌解；跨场景负样本用批内平移近似，实现成本低。（3）对比特征取自投影头第三层，导航任务使用第一层输出；两条支路共享编码器，这是端到端联合优化的接口。

片段 3：教师-学生路点蒸馏

import torch
import torch.nn.functional as F

def waypoint_distill(teacher, student, obs_std, obs_var):
    """教师冻结并接收标准视角，学生接收变化视角，只训练输入层适配器。"""
    with torch.no_grad():
        logits_t = teacher(obs_std)                  # 教师不回传梯度
    logits_s = student(obs_var)                      # 学生仅适配器可训练
    # F.kl_div(input=对数概率, target=概率) 计算 KL(target ‖ softmax(input))
    loss_wpd = F.kl_div(F.log_softmax(logits_s, dim=-1),
                        F.softmax(logits_t, dim=-1), reduction="batchmean")
    return loss_wpd

def build_graph(waypoints_teacher, waypoints_student, p2=0.1):
    """建图时按 p2 使用教师预测、按 1 - p2 使用学生预测。"""
    use_teacher = torch.rand(1).item() < p2
    return waypoints_teacher if use_teacher else waypoints_student

解读：（1）教师输入与评测时的学生输入严格分离：教师只看标准视角，学生只看变化视角，杜绝信息泄漏。（2）KL 的方向是「以教师分布为目标、学生分布为输入」，与论文公式 KL(softmax(Steacher) ‖ softmax(Sstudent)) 一致；写法上先对 logits 做 log_softmax 与 softmax 再调用。（3）适配器是路点预测器的输入线性层，训练时只把这一层设为 requires_grad，其余参数冻结；p2 = 0.1 表示建图早期以学生预测为主、逐步替换，复现时该概率要写入配置。

常见误区

  • 用单一固定高度代替视角协议：把 GVNav 的地面视角结论当作 V2-VLNCE 的结论，忽略俯仰维度与连续分布。根因是两组设置名称相近。修复：报告中写明「固定 0.8 米」或「±0.5 米 × ±30°」，两套数字不混排。
  • 高度与俯仰的符号与测量错误：外参标定后高度方向定义相反，或把安装测量误差（数厘米）当成无关紧要。根因是坐标系约定未统一。修复：在配置中固定「向上为正」并写单元测试；真机位姿相对训练范围的边距要显式计算（本例 0.7 对 0.75，边距 0.05 米）。
  • 对比学习正负样本构造错误：把同场景不同朝向当作正样本，表示丢失朝向信息并坍塌；或只取随机负样本，缺乏难负样本。根因是照搬通用视觉的增广口径。修复：正样本限定同朝向跨视角，负样本加入对向朝向；用最近邻检查表示是否保留 12 朝向的可分性。
  • 蒸馏信息泄漏：训练时学生偷看教师输入，或评测时仍调用教师。根因是数据流没有按角色隔离。修复：教师侧输入加 no_grad 与独立视角；评测只实例化学生；把 p2 调度写进训练日志。
  • 时间与口径混用：把「48 小时对 11.5 天」概括为约 14%，与原始数字计算出的 17.4% 不一致时无从取舍；或把后训练时长当作端到端部署成本。根因是概括值与原始值未分层记录。修复：原始小时与天数优先，概括值标注来源；部署成本另算感知与推理开销。

  1. 完成视角协议的算术：(a) 由训练高度范围 0.75 至 1.75 米反推标准高度；(b) 真机相机 0.7 米相对训练下限的边距是多少米，占 ±0.5 米范围的百分比是多少；(c) 若某机器人相机安装在 2.4 米，相对标准高度的偏移是否落在协议范围之外，应该补什么数据。 ★

小结

  • V2-VLNCE 在 ±0.5 米 × ±30° 内采样视角；由训练范围 0.75 至 1.75 米反推标准高度 1.25 米，真机 0.7 米构成 0.05 米边距的外分布情形。
  • 固定视角策略在变化视角下损失约 10 个百分点：R2R-CE val-unseen 上 ETPNav SR 56.8 到 47、SPL 48.9 到 38；BEVBert 同类损失 10.1 与 10.2 个百分点。
  • VIL 由跨视角对比学习与教师-学生路点蒸馏组成：λ1 = 0.2、λ2 = 10、p1 = p2 = 0.1、τ = 1.0；蒸馏是主要增益来源（变化视角 SPL +8.3），对比学习补充（+2.8）。
  • 变化视角下 ETPNav+VIL 的 SR 提升为 R2R-CE +8 至 +15 个百分点、RxR-CE +11 至 +15；标准视角总体持平或小幅提升，个别指标波动 −0.5 量级。
  • 跨 81 个视角的 SPL 标准差从 10.79 降到 3.59（按表值 66.7%，论文正文约 65%）；真机相机映射中偏离越大收益越大，Stretch RE-1 的 val-unseen SPL 从 15.5 到 35.4。
  • 真机概念验证：TurtleBot2 加全景相机与激光雷达、ROS 2 远程推理，办公室 28% 到 44%、休息区 20% 到 48%；后训练 48 小时对完整训练约 11.5 天（原始值计算 17.4%，论文概括约 14%）。
