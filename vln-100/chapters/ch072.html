第四篇 · 规模、记忆与泛化方法论

第 072 讲｜顺序建模深化（TOM/GOM/APH）

第 035 讲介绍了 HOP 的三个目标，本讲把监督信号当作设计对象：TOM 只打乱一半图像，逐图分类的复制基线高达 66.67% 至 80.00%，远高于 14.29% 至 20.00% 的随机基线；GOM 的三类先验各占三分之一；APH 相对 AP 在 R2R 上净增 0.74 个百分点。本讲给出构造细节、捷径与泄漏分析、消融读法，以及一套新增顺序目标的设计与验收表。

  • 主题：顺序监督 / 捷径基线 / 消融读法 / 目标组合 / 预训练预算
  • 关键数字：TOM 复制基线 66.67% 至 80.00%；GOM 随机基线 33.33%；APH 36 选 1；预训练 692.8 万对、15 轮、约 20.30 万步
  • 预计学时：60 分钟
  • 前置讲：第 071 讲（长程历史编码工程）与第 035 讲（HOP：历史与顺序预训练）

学习目标

  • 会算：TOM、GOM、APH 的随机基线与捷径基线，包括一半打乱场景下的逐图复制准确率，能判断一份目标设计是否存在可被捷径利用的固定位置。
  • 会读：从 HOP 的十行消融表中提取单目标边际收益、组合收益与数据替换效应，说明哪些结论稳健、哪些属于单次运行的噪声范围。
  • 会实现：轨迹打乱与标签映射、分组关系构造、按批任务采样的训练步骤三段代码。
  • 会设计：为新的顺序目标写出「构造、基线、捷径、泄漏、观测指标、归因方式」六列设计表，并配最小消融计划。
  • 会诊断：锚点泄漏、类别下标错配、负例来源混杂、动作标签越界四类问题。

背景与动机

第 035 讲把 HOP（Qiao 等 2022，CVPR 2022，arXiv:2203.11591v1）的三个新增目标讲过一遍：轨迹顺序建模（Trajectory Order Modeling, TOM）恢复被打乱图像的次序，组顺序建模（Group Order Modeling, GOM）判断两段子轨迹的前后或替换关系，带历史的动作预测（Action Prediction with History, APH）在给出历史轨迹与当前全景的条件下选下一步视图。本讲回答两个在定义层面看不到的问题：这些目标的监督信号是怎样构造出来的，以及它们的消融数字能支撑多强的结论。

顺序监督之所以值得单独设计，是因为轨迹的先后关系同时出现在指令与观测两侧。指令里的“然后”“接着”“回到”要求模型把语言的时间结构与视觉序列对齐；观测一侧，两个房间的视觉内容可能相近，只有进入的先后能区分。普通匹配目标（指令轨迹匹配、掩码语言建模）不直接约束次序，一个把图像倒序的模型仍可通过匹配测试。HOP 用测试结果说明这条线的价值：R2R 测试集成功率 64、路径长度加权成功率 59，去掉全部预训练后分别降到 55 与 50，差距各 9 个百分点；其中新增顺序目标在验证集上把成功率从仅掩码语言建模的 60.75 提到 63.86。

本讲的产出是一张消融设计表与一套读表规则。它与第 071 讲互补：071 保证历史算得动，本讲保证历史学得对。第 074 讲会从数据边界角度检查这类预训练语料的泄漏风险，本讲先立住目标侧的影子基线。

核心原理

本讲按「监督形式化、TOM 构造与捷径、GOM 构造、APH 构造、消融读法、预算与边界」展开。论文数字标注 HOP（Qiao 等 2022，CVPR 2022，arXiv:2203.11591v1）与验证集 split；基线与步数由本讲实算。

1. 顺序监督的三种形式：排列、关系与动作

设一条轨迹含 N 个观测，正确次序记为 r = (r1, …, rN)。完整排列空间有 N! 种，N = 5、6、7 时分别为 120、720、5,040 种，直接预测整条排列在计算上不可行，也缺少稠密监督。HOP 把顺序问题拆成三类可训练的形式：

目标输入构造监督形式类别数随机基线学习的能力
TOM打乱 50% 图像后的轨迹与指令逐图预测原始位置N1/N帧级时序定位
GOM两段子轨迹与指令前、后、替换三分类333.33%段级关系判断
APH指令、历史轨迹、当前 36 视图从 36 视图选下一步362.78%带历史的动作决策

三种形式的监督强度差异明显：TOM 每个样本提供 N 个标签，GOM 每个样本一个标签，APH 每个样本一个 36 类标签。设计新目标时先确定监督形式，再决定基线口径，顺序不能颠倒。

2. TOM 的构造与捷径：复制基线比随机基线高数倍

HOP 的做法是从原始轨迹随机选 50% 的图像打乱，其余保持原位，模型逐图预测它在原轨迹中的位置（论文未展开该实现细节，按公开实现的通行理解处理）。设打乱数量 k = ⌊N/2⌋。两个基线必须同时给出：

随机基线 = 1 / N；复制基线（逐图）= (N − k + 1) / N 复制基线指不做任何内容推理、把输入位置直接当预测位置时的逐图准确率；固定位置的 (N − k) 张图直接命中，被打乱的 k 张以 1/k 的概率碰对

实算：N = 5、k = 2 时随机基线 20.00%、复制基线 80.00%；N = 6、k = 3 时 16.67% 对 66.67%；N = 7、k = 3 时 14.29% 对 71.43%。只报告随机基线会把目标显得比实际难数倍，而一张只看位置、不看内容的模型就能拿到三分之二以上。结论一：保留一半锚点的设计天然携带位置捷径，任何新目标都应把复制基线列为默认对照，并通过加大打乱比例或改用错排构造来降低它。

更强构造有三种：全排列打乱（复制基线降到约 1/N）、错排（每个元素都不在原位，复制基线为 0）、部分打乱但按位置打掩码（不把固定位置计入损失）。三者与 HOP 原设计的差异需在同一数据与训练预算下对照，才可写进消融结论。

3. GOM 的构造：先验均匀，难点在负例来源

GOM 把轨迹均匀切成前后两组，三类样本对应三种构造：两组按轨迹顺序展示（类 1）、两段交换展示（类 2）、第二段换成其他轨迹的片段（类 3）。三类先验各三分之一，随机基线 33.33%。这个目标表面是顺序判断，实际混入了一维环境判别：类 3 的替换片段来自不同环境时，模型可以绕过顺序线索、直接用环境外观分辨真假。

HOP 在相邻的指令轨迹匹配目标里明确说明负例取自同一环境，使模型关注路径差异、淡化环境差异；GOM 的替换片段则取自其他轨迹。两个目标的负例来源不同，读数时不能互相解释。结论二：顺序目标的负例来源决定它真正训练的能力，构造表里必须写明负例选自同环境、同房间还是跨环境，并配一个只换来源的最小对照。

4. APH 的构造：把历史放进动作目标

APH 的输入是指令、第 t 步之前的完整历史轨迹与当前全景的 36 张视图，标签是专家轨迹下一步对应的视图，损失为 36 类交叉熵。随机基线 2.78%，但可导航视图通常只占其中少数，实际候选远小于 36，读准确率时要说明是在全 36 类上计算还是在可导航子集上计算。与无历史的动作预测（AP）相比，HOP 的消融给出：R2R 验证集成功率 62.01 对 61.27（净增 0.74），路径加权成功率 56.13 对 55.68（净增 0.45）；REVERIE 成功率 29.37 对 28.69（净增 0.68），RGSPL 14.16 对 13.64（净增 0.52）；NDH 目标推进 3.88 对 3.83（净增 0.05）。训练曲线上 APH 收敛更快且在验证集上精度更高（论文图 4 的读数）。

APH 与第 034 讲的单步动作预测（SAP）同源：都是动作分类，区别在历史取一整条轨迹，不取若干全景摘要；输入用前视图序列，不用全景特征。它把“历史有用”写进动作目标的梯度，减少对表示层面间接吸收的依赖。

5. 消融读法：边际收益、组合收益与数据效应分开看

HOP 表 5 的十行结果可以拆成三组对照。第一组是单目标边际收益（都相对仅 MLM 的 60.75 成功率）：TIM +0.77、TOM +1.06、GOM +1.23、APH +1.26、无历史 AP +0.52。第二组是组合：三个顺序与匹配目标（TIM、TOM 与 GOM）合到 63.09（比 MLM +2.34），再加 APH 到 63.86（比 MLM +3.11，相对提升 5.12%）。第三组是数据替换：把预训练语料换成 PREVALENT 加处理后的 BnB，R2R 降 0.34 到 63.52、路径加权升 0.15 到 57.22，而 REVERIE 成功率升 1.39 到 31.78、RGSPL 升 0.42 到 15.73，NDH 升 0.04 到 4.41。

三条读表规则。第一，小于 1 个百分点的差距在单次运行内难以与初始化噪声区分，HOP 未报告多次运行的标准差，读表时应把 TIM 与 AP 对 R2R 的单点增益视为待复核项，TOM、GOM、APH 刚过 1 个百分点，同样需要多次运行确认。第二，单项增益之和（0.77 + 1.06 + 1.23 + 1.26 = 4.32）大于组合相对 MLM 的增益（3.11），说明目标之间存在重叠的监督信息，边际收益不可线性外推。第三，数据替换在不同任务上方向不一致，R2R 的小幅下降与 REVERIE 的明显上升同时出现，语料描述风格与下游接地需求匹配时收益更大（论文对 BnB 的解释）。结论三：消融结论的最小证据单位是「同一初始化、同一数据、同一任务采样口径下的一组对照」，跨数据组的比较只能作为假设。

6. 预训练预算与任务采样

HOP 的预训练语料为 PREVALENT 的 104K 原始样本加 648.2 万合成样本，再加处理后的 BnB 34.2 万序列描述对，合计 692.8 万对；全局批大小 512（4 张 V100，每卡 128），15 轮。实算步数：每轮 6,928,000 / 512 = 13,531.25 步，按该值计 15 轮共 202,968.75 步，约 20.30 万步。每个批只抽一个目标训练，五个目标均匀采样时，每个目标每轮约 2,706 步、全程约 40,594 步。合成语料占 98.42%（不计 BnB 时），结论的边界应写明这一构成。

任务采样引入两个读数注意点：各目标的梯度步数相同，但每步的标签数与损失量级不同（TOM 每样本 N 个标签，GOM 一个），因此不能用损失均值横向比较目标难度；训练日志应分别记录各目标的样本数与评估精度，避免把采样比例的变化误读为目标贡献的变化。

7. 边界与失效模式

  • 锚点泄漏：一半图像保持原位时，位置信息本身成为可分特征，训练精度虚高且下游收益被高估。
  • 类别依赖：TOM 的类别数为轨迹步数 N，按固定 N 训练的分类头无法直接迁移到更长轨迹，长程任务需要补位或改成相对顺序目标。
  • 负例混杂：GOM 的类 3 与 TIM 的负例来源不同，读数时若把两者都解释为顺序能力，会把环境判别算进顺序判别。
  • 动作标签越界：APH 在全景上取 36 类，若实现时只在可导航子集上取标签，或历史里包含当前步之后的观测，都会产生信息泄漏。
  • 单点增益的稳定性：部分单目标增益不足 1 个百分点（TIM +0.77、AP +0.52），且全部结果无方差报告，直接作为选题结论风险高；需要至少三次运行与配对比较。

新目标的评估顺序固定为三步：先报随机基线，再报捷径基线，最后才报真实增益。任何一步缺失，结论都可能被捷径解释。若捷径基线高（如 TOM 的复制基线超过三分之二），先改构造降捷径，再谈下游收益；改动构造后必须重跑数据与组合两层对照，防止把难度变化误读为表示质量变化。

关键代码与解读

三段代码覆盖构造与训练两侧：TOM 的打乱与标签映射、GOM 的三类构造、按批任务采样的预训练步骤。

片段 1：TOM 打乱与标签映射

import torch

def tom_construct(order_ids, shuffle_ratio=0.5, generator=None):
    """返回打乱后的下标与逐图目标位置；order_ids 为轨迹下标序列。"""
    n = len(order_ids)
    k = int(n * shuffle_ratio)               # HOP 口径：约一半图像参与打乱
    perm = torch.randperm(n, generator=generator)
    moved = perm[:k].tolist()                # 被选中的位置集合
    fixed = [i for i in range(n) if i not in moved]
    anchor = list(order_ids)
    target = [moved[p] for p in torch.randperm(k, generator=generator).tolist()]
    for old_pos, new_pos in zip(moved, target):   # 被选中图像在选中槽位内交换
        anchor[new_pos] = order_ids[old_pos]
    # 目标：每张图在其原轨迹中的位置下标，类别数为 n
    labels = [None] * n
    for pos, oid in enumerate(anchor):
        labels[pos] = order_ids.index(oid)
    return anchor, labels, fixed

# 基线核算：复制基线 = 固定图占比 + 打乱图纯猜命中率
def tom_baselines(n, k):
    chance = 1.0 / n
    copy = (n - k) / n + (k / n) * (1.0 / k)   # (n-k+1)/n
    return chance, copy

解读：（1）打乱比例写成参数，便于按设计表跑 50% 与 100% 两组对照；（2）labels 取原始下标，避免用打乱后的槽位造成类别错配；（3）tom_baselines 直接返回两个基线，日志中与训练精度并列输出，防止只报随机基线；（4）固定位置集合 fixed 可用于位置掩码损失，作为降低锚点泄漏的备选实现。

片段 2：GOM 三类构造

def gom_construct(traj_features, other_features, generator=None):
    """返回两组特征与三分类标签：1 顺序、2 交换、3 跨轨迹替换。"""
    n = len(traj_features)
    mid = n // 2                             # 均匀切分为前后两段
    g1, g2 = traj_features[:mid], traj_features[mid:]
    r = torch.rand(1, generator=generator).item()
    if r < 1.0 / 3:
        return g1, g2, 1                     # 展示顺序与轨迹一致
    if r < 2.0 / 3:
        return g2, g1, 2                     # 前后两段交换展示
    return g1, other_features, 3             # 替换片段，来源必须在日志中声明

# 读数提醒：类 3 的替换若跨环境，模型可用外观线索绕过顺序推理；
# 消融时应补一个「同环境替换」对照，区分顺序能力与环境判别能力

解读：（1）三类先验各三分之一，构造上保持类别平衡，随机基线固定为 33.33%；（2）类 2 把两段交换展示，模型需要依据内容判断哪一段应在前，训练信号来自展示顺序与真实顺序的对比；（3）替换来源作为显式参数传入，便于做同环境与跨环境两组实验；（4）切分点固定在轨迹中点，与 HOP 的偶数切分口径一致，若改用随机切分需重新核算类别平衡。

片段 3：按批任务采样的预训练步骤

TASKS = ["mlm", "tim", "tom", "gom", "aph"]

def pretrain_step(batch, model, task_probs=None, generator=None):
    """每个批次只采样一个目标；task_probs 用于控制各目标步数占比。"""
    task = torch.multinomial(
        torch.tensor(task_probs) if task_probs else torch.ones(len(TASKS)) / len(TASKS),
        1, generator=generator
    ).item()
    name = TASKS[task]
    if name == "tom":
        anchor, labels, _ = tom_construct(batch["order_ids"])
        logits = model.tom_head(model.encode(batch, anchor))
        loss = torch.nn.functional.cross_entropy(logits, torch.tensor(labels))
    elif name == "gom":
        g1, g2, y = gom_construct(batch["traj"], batch["other"])
        logits = model.gom_head(model.encode_pair(g1, g2, batch["instr"]))
        loss = torch.nn.functional.cross_entropy(logits, torch.tensor([y]))
    else:
        loss = TASK_LOSS[name](model, batch)
    # 日志分别记录各目标的样本数与评估精度，禁止只用总损失横向比较
    return name, loss

解读：（1）每批一个目标与 HOP 的训练协议一致，任务概率可调，默认均匀；（2）各目标损失只在内部使用，回传前不做尺度统一，跨目标比较只依据评估精度与下游指标；（3）日志按目标分桶，防止采样比例变化被误读为目标贡献变化；（4）标签在构造函数内部生成并与样本同批，避免离线缓存标签在下游数据切分后发生错位。

常见误区

  • 只报随机基线不报捷径基线：TOM 的复制基线在 N = 5 至 7 时达到 80.00%、66.67%、71.43%，训练精度看起来很高，下游却没收益。根因是固定锚点泄漏位置。修复：构造与日志同时输出两个基线；用全排列或错排构造做对照，或把固定位置排除在损失之外。
  • 标签在打乱后按槽位编号：类别语义与原始位置错位，训练不收敛或精度异常波动。根因是构造与标签映射用了两套下标。修复：标签一律取原始轨迹下标，构造函数末尾用断言检查标签是 0 至 N−1 的排列。
  • GOM 负例来源未固定：跨环境替换使类别比随机更难还是更易取决于实现，复现结果对不上。根因是负例采样没有写进配置。修复：把来源（同房间、同场景、跨场景）写成显式参数并进入日志；补同环境对照实验。
  • APH 历史越界：构建历史时把当前步或其后一步的观测也放进去，动作标签被前置输入泄漏，预训练精度虚高。根因是切片边界写错。修复：历史切片固定为 [0, t)，加断言检查历史末步严格早于当前步。
  • 组合消融按单目标最优拼装：把各自最优的运行结果拼成组合结论，忽略了初始化与采样差异。根因是缺少同骨架对照。修复：组合与单目标共用同一初始化、数据与采样协议；报告三次运行的均值与标准误，小于两倍标准误的增益不作为结论。

练习与思考

  1. 对 N = 5、6、7、k = ⌊N/2⌋ 实算 TOM 的随机基线与逐图复制基线，并解释两者差距的来源。 ★
    提示
    随机 20.00%/16.67%/14.29%；复制 80.00%/66.67%/71.43%。固定位置的 N−k 张图直接命中，贡献 (N−k)/N；被打乱的 k 张纯猜贡献 (k/N)(1/k) = 1/N；合计 (N−k+1)/N。N 越小，固定图占比越高，复制基线越接近满分。
  2. 从消融表读数：分别计算 TIM、TOM、GOM、APH、AP 相对 MLM 的 R2R 成功率增益，指出哪些单点结论在「增益大于 1 个百分点」判据下不成立。 ★
    提示
    TIM +0.77、TOM +1.06、GOM +1.23、APH +1.26、AP +0.52。按 1 个百分点判据，TIM 与 AP 不成立，TOM 刚过线；这些数字来自单次运行且未报告方差，稳健结论需要三次运行。
  3. 推导与设计：把 TOM 从逐图 N 类分类改为整条排列预测，说明两种输出空间的大小差异、可行的训练目标（如指派问题或序列生成）与计算复杂度，并分析泄漏风险怎样变化。 ★★
    提示
    逐图分类输出空间 N 类，整排列输出空间 N!（N = 7 时 5,040 种）；可用匈牙利匹配做指派损失（复杂度多项式，约 N³），或用序列模型直接生成排列（复杂度随 N 增长）。整排列失去固定锚点，复制基线归零，但监督密度下降，需要更多样本或课程式难度。
  4. 组合增益分析：已知 TIM、TOM、GOM 三个单目标相对 MLM 的增益之和为 3.06，而三者组合相对 MLM 的增益为 2.34。给出两个能解释差距的机制假设，并各设计一个能区分它们的观测。 ★★
    提示
    假设一：目标共享同一份时空信息，先加的目标消耗了可用的监督容量，后加的边际收益递减。观测：按不同加入顺序重跑组合，若总增益与顺序无关则支持递减解释。假设二：不同目标互相干扰表示（例如顺序与匹配对同一特征的梯度方向冲突）。观测：分目标检查预训练头精度，若加入新目标后旧目标精度下降则为干扰。
  5. 设计任务：为一个新顺序目标（自选，例如「指令分句与轨迹分段对齐」）填写六列设计表，写出随机与捷径基线、两个泄漏风险、三层消融计划（单目标、组合、数据），并给出预算与验收断言。 ★★★
    提示
    构造示例：把指令按连接词切段，与轨迹按步分段做匹配，负例用段序交换。随机基线 1/(K!) 取决于段数，捷径基线为「按输入顺序直接匹配」。泄漏风险包括分句器与标注边界重合、分段数等于步数导致位置泄漏。消融按单目标加 MLM、组合、换语料三层执行，验收断言：下游两个任务同向增益大于 1 个百分点，且三次运行均值差大于两倍标准误。

小结

  • 顺序监督有三种可训练形式：排列（TOM）、关系（GOM）与动作（APH）。完整排列空间为 N!，逐图分类与三分类是它的可训练近似。
  • TOM 保留一半锚点，逐图复制基线为 (N−k+1)/N，N = 5 至 7 时达到 80.00%、66.67%、71.43%，数倍于随机基线；设计新目标必须同时报告两个基线，用全排列或错排构造降低捷径。
  • GOM 三类先验均匀、随机基线 33.33%，真正的设计变量是替换片段的来源；HOP 的替换跨轨迹，读数时要与指令轨迹匹配目标的同环境负例区分开。
  • APH 相对 AP 在 R2R 验证集上成功率净增 0.74、路径加权净增 0.45，REVERIE 成功率净增 0.68；把历史写进动作目标的梯度比寄望表示层面吸收更直接。
  • 读 HOP 消融表的三条规则：小于 1 个百分点的单点差距待复核；单项增益之和 4.32 大于四目标组合增益 3.11，边际收益不可线性外推；数据替换的效应按任务分别报告（R2R 降 0.34，REVERIE 升 1.39）。
  • 预算：692.8 万对语料、批 512、15 轮、约 20.30 万步；每批一个目标时各目标每轮约 2,706 步。合成语料占 98.42%（不计 BnB），结论边界需标注。
