第二篇 · 离散方法谱系：从模块到预训练

第 027 讲｜Regretful Agent：回溯与进度标记

把导航看成导航图上的搜索：进度监控器提供可学习的启发式分数，Regret Module 依据进度差分决定继续前进或回退一步，Progress Marker 把访问过的方向连同其进度估计一起喂给动作选择。三者组合让贪心解码获得接近搜索的效果，且不执行长轨迹。

  • 主题：离散方法 / 回溯 / 进度标记 / 搜索式解码
  • 关键公式：mtfr = αT[mtf, mtr]，Δvt,kmarker = ptpm − vt,kmarker
  • 预计学时：60 分钟
  • 前置讲：第 026 讲（SIL：自监督模仿学习）

学习目标

  • 复述「导航即图上搜索」的视角，并用测试集数字说明贪心解码与 beam search 的取舍（Ma 等，2019，R2R）：beam search 成功率高但路径极长、SPL 极低，贪心路径短但成功率不足。
  • 推导 Regret Module：前向嵌入与回溯嵌入的构造、进度差分到二路软权重的映射、融合向量的动作打分；解释 Wr ∈ R1×2 的作用与梯度分离的必要性。
  • 推导 Progress Marker：访问记忆、未访问方向填 1 的约定、差分 Δv 的方向语义、平铺拼接的维度核算。
  • 会算：屏蔽回溯后 NE、SR、OSR、SPL 四个指标的联合变化，并解释 SPL 反向上升的原因。
  • 会判断：进度标签的取值口径（起点 0、3 米内取 1、可低于 0）、训练期熵奖励为何是回溯能力可学习的前提、合成数据能否训练回溯模块。

背景与动机

第 024 讲的 Self-Monitoring 智能体已经带有进度监控器（progress monitor）：它作为文本定位的辅助正则项，并为 beam search 的候选路径提供重排信号；无 beam 的进度回退变体也只在进度下降时触发固定规则的退回。第 026 讲的 SIL 改进了策略参数，但测试时的解码方式没有改变，greedy 与 beam search 的分裂依旧存在。

这个分裂有两个数字支撑。Speaker-Follower 加 beam search 在 R2R 测试集上成功率 53.5%，但路径长度达到 1257.38 米，SPL 只有 0.01；同一方法用贪心解码时成功率降到 35.0%，路径长度 14.82 米，SPL 0.28（Ma 等，2019，表 5）。对机器人部署而言，执行上千条候选轨迹的测试时搜索不现实，而贪心策略的可靠性又不足。理想方案介于两者之间：像最佳优先搜索那样智能地选择动作，但只执行一条轨迹。

Regretful Agent 的立场是：导航过程本身就是导航图上的搜索，进度监控器就是一个已经训练好的启发式函数，缺的是搜索的两个基本动作：走错后回退，以及避免重复走进已探索且没有进展的方向。论文把这两件事分别做成 Regret Module 与 Progress Marker，模块化地接在 Self-Monitoring 基线上，端到端训练，推理时保持贪心，不执行 beam。

本讲要解决三件事：第一，把两个模块的公式与方向语义推导清楚，避免差分符号写反；第二，用消融与屏蔽实验数字说明增益来源；第三，写清它在训练稳定性与边界上的要求，例如熵奖励与梯度分离。

核心原理

1. 基线结构与进度标签口径

基线沿用第 024 讲的 Self-Monitoring 智能体：文本定位得到注意力分布 αt，视觉定位得到 v̂t，LSTM 融合历史，动作打分取隐藏态与定位文本的相关性：

ot,k = (Wa[ht, x̂t])T g(vt,k)，pt = softmax(ot) ht 为 LSTM 隐藏态，x̂t 为定位后的指令特征，vt,k 为第 k 个可导航方向的图像特征，g(·) 为多层感知机

进度监控器输出 ptpm ∈ (−1, 1)，训练目标是归一化剩余距离。把口径写成公式：以起点到目标的距离 d0 为基准，ytpm = 1 − dt/d0，其中 dt 为第 t 步位置到目标的导航图最短距离；当 dt 小于 3 米时目标取 1；轨迹中途若偏离到比起点更远的位置，目标允许低于 0（Ma 等，2019，2.4 节）。

d0dtytpm读法
10 米10 米0.00尚未前进
10 米4 米0.60已完成约六成
10 米12 米−0.20走远，目标为负值
10 米2.5 米1.003 米内直接取 1

监控器的输出层用 tanh，值域 (−1, 1)，与目标可以取负值的口径一致，这是公式与标签设计互相印证的一处细节。Regretful Agent 直接复用这个已训练的监控器，把它当作启发式，不再只当作正则项。

2. 图上搜索视角与两个缺口

把导航图记为 G = (V, E)，当前位置 vt ∈ V，目标未知。贪心解码每一步在候选邻居里取动作概率最大者，等价于一步前瞻的局部贪心；beam search 保留多条前缀，等价于大范围展开。两者之间是启发式搜索的空间：启发式给出「谁更像在接近目标」的排序，回溯提供「发现选错后撤回一步」的能力。

进度监控器正是现成的启发式。它的输出沿轨迹单调上升时，说明动作序列正在完成指令；下降或滞涨时，说明最近的动作可能偏离。两个缺口随之明确：谁来根据进度变化决定回退（Regret Module），回退之后如何避免再次选中已经证明没有进展的方向（Progress Marker）。

3. Regret Module：从进度差分到二路软权重

模块构造两个嵌入：前向嵌入沿用动作打分所用的隐藏态与定位文本，回溯嵌入取「指向上一访问位置」方向的图像特征投影：

mtf = Wa[ht, x̂t]，mtr = g(vt,r) vt,r 为当前视角下指向上一访问位置方向的图像特征；g(·) 与前文共用投影网络

决定前进或回退的信号是进度差分 Δptpm = ptpm − pt−1pm。论文没有设定硬阈值，改用 1×2 线性层把标量差分变成两个对数几率，再做二路 softmax：

αtfr = softmax(Wr Δptpm)， mtfr = (αtfr)T [mtf, mtr] Wr ∈ R1×2；软权重在 [0,1] 之间连续变化，避免人工设阈值

数值感受一下权重的形状。取 Wr = (2, −2)、Δp = −0.1 时，两个对数几率为 (−0.2, 0.2)，softmax 得前向权重 0.401、回溯权重 0.599；Δp = +0.1 时两权重对调（Python 实算）。权重符号结构由训练学出；单层线性映射是单调的，若要实现非单调规则（例如差分接近 0 时才考虑回溯），需要更深的映射网络或对差分做截断与缩放。

有一处工程细节必须照做：喂给 Regret Module 的进度监控器输出被 detach，作为计算图上的叶子节点。原因是监控器本身还有自己的均方误差目标，若回溯决策的梯度反传进去，监控器会被拉去服务「何时回退」的判别任务，其校准功能被破坏。

4. 动作选择与振荡阻断

融合向量替代原来的前向嵌入参与动作打分：

ot,k = (Wfr mtfr)T g(vt,k)，pt = softmax(ot) Wfr 输出维度 1024；接入 Progress Marker 后输入维度变为 1024 + 32 = 1056

当回溯权重占优，动作分布会偏向指向上一位置的方向，执行该动作即完成一次回退。论文附加一条规则：一旦执行回溯，屏蔽掉指向「刚离开的那个位置」的方向，防止 A、B 两点之间的来回振荡。回退一步后继续贪心选择，相当于在局部搜索树里剪掉最近的分支。

5. Progress Marker：给访问过的方向贴上进度标签

回退之后需要决定往哪走。Progress Marker 维护一个按视角编号索引的记忆 M，记录每个访问位置的进度监控器输出；若某方向指向的位置尚未访问，标记值填 1：

vt,kmarker = pipm（方向 k 指向访问过的位置 i ∈ M），否则为 1 每次重新访问位置 i 时更新其标记值；停止动作的标记固定为 0

标记值进入动作打分前先与当前进度作差：Δvt,kmarker = ptpm − vt,kmarker。差分的含义是「当前进度减去该方向过去带来的进度」：若某方向过去带来的进度高于当前进度，差分为负，说明该方向比现状更有前途，应当优先选择。论文明确约定低差分对应更高的选择机会。未访问方向填 1，当前进度通常远低于 1，差分为很负的值，因此保持探索倾向。论文给出的例子：起点、上一访问位置、未访问方向的差分分别为 0.08、−0.02、−0.71，后者的到达使进度最终升到 0.52。

差分被平铺 n = 32 次后与投影图像特征拼接：vt,kmarked = [g(vt,k), Δvt,kmarker]，再进入动作打分。平铺是为了平衡标量差与高维视觉特征的量纲，附录给出的权重矩阵从 1024×1024 变为 1024×1056，恰好多出 32 列。停止动作标记为 0，使 Δv 等于当前进度，避免停止动作被标记机制无端抑制或放大。

6. 训练目标与熵奖励

总损失由动作交叉熵、进度均方误差与熵奖励三项组成（符号约定与第 024 讲一致，第一项写为负交叉熵）：

L = −λ Σt log pt,k*(t) + (1−λ) Σt (ytpm − ptpm)2 − β Σt H(pt) λ = 0.5；β = 0.01；H(p) = −Σk pk log pk 为动作分布熵；训练期按类别采样执行动作，推理期取贪心

熵奖励是回溯能力可学习的关键。训练进行到一定阶段后，策略在训练集上错误率很低，样本里几乎不出现「走错再回退」的片段，回溯分支得不到有效梯度。熵项鼓励动作分布保持探索，使训练期主动制造错误，为回溯模块提供学习场景。数值上，5 路均匀分布的熵为 1.6094，集中分布（0.9, 0.1, 0, 0, 0）的熵为 0.3251；β = 0.01 时两项对损失的贡献分别为 0.0161 与 0.00325（实算）。这个量级不会主导损失，只提供持续的小幅探索压力。

训练与推理的差异同样明确：训练期采样动作积累回溯样本，推理期贪心解码但在内部执行「前进或回退」的软裁决，测试时不需要外部搜索。论文报告屏蔽回溯后未见环境成功率下降 2 个百分点、NE 上升 0.44 米；在纯合成数据上训练时，回溯智能体的 oracle 导航误差（ONE，允许在轨迹离目标最近处停止时的误差）3.47 米也优于基线的 4.09 米，说明回溯能力可以脱离真实轨迹标注单独学到。

7. 实验证据

测试集上，Regretful Agent 相对当时的 Self-Monitoring 基线把成功率从 43% 提到 48%（+5 个百分点，相对 +11.6%），SPL 从 0.32 提到 0.40（+8 个百分点，相对 +25.0%），累计报告为对前最好方法的 5% 绝对成功率与 8% 绝对 SPL 提升（Ma 等，2019，表 1 与摘要）。两个指标的相对涨幅不同，SPL 涨幅更大，与「回溯缩短无效探索」的设计目标一致。

方法（R2R 验证未见集，无数据增广）NE（米）SROSRSPL
Self-Monitoring5.980.440.580.30
仅 Progress Marker5.740.440.590.32
仅 Regret Module5.650.470.590.37
两者组合5.360.480.610.37

消融给出两点结论。第一，增益主体来自 Regret Module：只加回溯把成功率从 0.44 提到 0.47，只加标记停在 0.44；两者组合 0.48，标记在回溯之上再贡献 1 个百分点，SPL 的组合收益（0.30 到 0.37）在两模块间共享。第二，屏蔽实验证明因果：人为禁止所有回溯动作后，Regretful Agent 在未见集上的 NE 从 5.36 米升到 5.80 米（+8.2%）、SR 从 0.48 降到 0.46（−4.2%）、OSR 从 0.61 降到 0.55（−9.8%）；对基线做同样屏蔽时 SR 不变。回溯被屏蔽后 SPL 却从 0.37 升到 0.41（+10.8%），原因是禁止回退让轨迹变短，而失败样本的短轨迹拉高了 SPL。这个方向反转说明 SPL 不能单独解读，必须与 SR、NE、OSR 联合报告。

失败样本统计给出另一条佐证：含回溯动作的失败样本占比从基线的约 43% 降到约 38%（−5 个百分点，相对 −11.6%），说明模型不仅回退更频繁，回退也更准。

4. 与相邻讲的边界

与 024 讲的关系：024 把进度监控器当作正则与 beam 重排依据，027 把它升级为搜索启发式，并新增回溯与标记两个模块。与 026 的关系：SIL 在无标注环境扩充监督数据，回退能力则留在策略结构内部，两者可以叠加。设计上还需注意，回溯是对已访问节点的一步回退，不是任意历史节点的跳转；访问记忆只保存进度值，不保存完整子树，因此搜索能力是局部的。

关键代码与解读

以下片段按论文公式与公开实现习惯编写，聚焦机制。第一段实现 Regret Module，第二段实现动作选择与振荡阻断，第三段实现三项目标。

片段 1：Regret Module 前向

class RegretModule(nn.Module):
    def __init__(self, dim=1024):
        super().__init__()
        self.w_r = nn.Linear(1, 2)                 # W_r: 标量差分 -> 前向/回溯两个对数几率
        self.w_fr = nn.Linear(dim + 32, dim)       # 接入 Progress Marker 后的融合投影

    def forward(self, m_f, m_r, dp, marked_feats):
        alpha = torch.softmax(self.w_r(dp.view(-1, 1)), dim=-1)   # [前向权重, 回溯权重]
        m_fr = alpha[:, 0:1] * m_f + alpha[:, 1:2] * m_r          # 软融合，可微可导
        logits = [(self.w_fr(m_fr) * f).sum(dim=-1) for f in marked_feats]
        return torch.stack(logits, dim=-1), alpha

解读：（1）Wr 把标量差分映射为两个对数几率，等价于论文的 softmax(Wr Δp)，无需人工阈值。（2）融合向量 mfr 与每个方向的标记特征做内积，得到动作分数；真实实现里 w_fr 对融合向量只算一次，循环内复用可省算力。（3）返回的二路权重可用于监控：训练日志里统计回溯权重的均值，若长期停在 0.5 附近，说明进度差分缺少区分度，需检查监控器校准。（4）调用方必须传入 detach 后的 dp，梯度分离在数据准备阶段完成。

片段 2：标记构造与振荡阻断

def select_action(policy, nav_feats, m_f, m_r, dp, marker, progress, last_dir):
    # marker: 每个可导航方向的进度标记；未访问为 1，停止动作为 0
    dv = progress - marker                                  # 低差分优先，未访问方向差分最负
    marked = [torch.cat([g(v), dv[i].expand(32)]) for i, v in enumerate(nav_feats)]
    logits, alpha = policy.regret(m_f, m_r, dp, marked)     # 片段 1 的四输入前向
    if last_dir is not None and alpha[0, 1] > 0.5:          # 回溯权重占优，进入回退分支
        logits[last_dir] = -1e9                             # 屏蔽刚离开的方向，阻断 A-B 振荡
    return int(logits.argmax()), alpha                      # 推理期贪心，训练期换类别采样

解读：（1）差分的计算顺序与论文一致：当前进度减标记，值越低越有前途；未访问方向标记为 1，天然获得探索优先级。（2）标记平铺 32 次后与投影特征拼接，维度与片段 1 的输入对齐。（3）振荡阻断只在回溯分支启用；用 −1e9 屏蔽指回上一位置的方向，保留其余候选。（4）停止动作的标记为 0，由调用方在 marker 末尾附加，避免被差分机制扭曲。

片段 3：三项目标

def regretful_loss(logits, y_nv, p_pm, y_pm, lam=0.5, beta=0.01):
    # logits: 每步方向分布; y_nv: 演示方向; p_pm: 监控器输出; y_pm: 归一化剩余距离标签
    ce = F.cross_entropy(logits, y_nv)                      # 动作交叉熵，对应论文第一项
    mse = F.mse_loss(p_pm, y_pm)                            # 进度回归，监督监控器校准
    prob = logits.softmax(dim=-1)
    ent = -(prob * logits.log_softmax(dim=-1)).sum(dim=-1).mean()   # 动作熵
    return lam * ce + (1 - lam) * mse - beta * ent          # beta 提供训练期探索压力

解读：（1）三项权重与论文一致：λ = 0.5 平衡动作与进度，β = 0.01 控制熵奖励，量级上熵项不主导损失。（2）进度标签 y_pm 按第 1 小节口径生成，允许负值；监控器输出经 tanh 后值域匹配。（3）熵项只在训练期加入，推理期没有该项；若训练后期错误率过低导致回溯样本消失，可检查该系数是否被误设为 0。（4）实际训练在采样动作上计算交叉熵，与推理的贪心解码分开配置。

常见误区

  • 进度差分方向写反：Δp 为负时前进、为正时回退，指标远低于论文。根因：把差分当成「进度下降幅度」直接当正数使用。修复：按论文形式 Δp = pt − pt−1，并让 Wr 自行学习符号；用本讲算例做单元测试。
  • 监控器输出未 detach：进度监控器的均方误差先下降后震荡，动作指标一起变差。根因：回溯目标的梯度反传进监控器，校准任务被判别任务淹没。修复：进入 Regret Module 前 detach，监控器只接受自己的 MSE 监督。
  • 未阻断来回振荡：轨迹在相邻两点反复往返，路径长度暴涨而成功率不升。根因：回溯后指回上一位置的方向仍有较高动作概率。修复：回溯分支内屏蔽该方向，只在回溯生效的那一步执行。
  • 取消熵奖励：回溯权重长期停在 0.5，屏蔽回溯后指标几乎不变，说明模块没有真正参与决策。根因：训练后期策略很少走错，回溯样本稀缺。修复：保留 β = 0.01 的熵项，或在训练早期安排探索阶段。
  • 单独看 SPL 判断回溯价值：屏蔽回溯后 SPL 上升，得出「回溯有害」的结论。根因：SPL 同时混合成功率与路径长度，短而失败的轨迹也能抬高该值。修复：以 SR、NE、OSR、SPL 四联指标联合判断，参照本讲屏蔽实验的完整表格。

练习与思考

  1. 取 Wr = (2, −2)，分别计算 Δp = −0.1 与 +0.1 时的前向、回溯权重，并说明网络需要在训练中学到什么才能把「差分接近 0」处理成回退倾向。★
    提示
    Δp = −0.1 时对数几率为 (−0.2, 0.2)，回溯权重 0.599；+0.1 时对调。线性层只能给出单调的权重曲线，若要实现非线性软化，需要更深的小网络或对差分做截断与缩放。
  2. 推导 Progress Marker 的差分公式，说明未访问方向为何填 1，并证明「低差分优先」与「探索未访问方向」是同一规则的两个侧面。★
    提示
    Δv = pt − vmarker；未访问填 1 时 Δv = pt − 1，通常最负，因而获得最高选择机会。已访问且过去进度更高的方向同样得到负差分，规则统一。
  3. 复现屏蔽回溯的对照实验：对 Self-Monitoring 基线与 Regretful Agent 各跑一遍未见验证集，报告 NE、SR、OSR、SPL，并解释为什么屏蔽后 SPL 会上升。★★
    提示
    预期结果：Regretful 的 NE 上升约 0.44 米、SR 下降约 2 个百分点、OSR 下降约 6 个百分点，SPL 上升约 0.04；基线的 SR 不变。SPL 上升来自失败轨迹变短，属于指标口径的混合效应。
  4. 把熵系数 β 从 0.01 分别改为 0 与 0.1，预测回溯权重的分布、训练集成功率与未见集 SPL 的变化方向，并给出可检验的监控指标。★★
    提示
    β=0 时训练后期策略几乎不犯错，回溯分支缺少样本，回退权重趋近 0.5；β=0.1 时探索过强，训练集成功率下降，未见集可能先受益后受损。可监控每轮采样中回溯动作占比与其后进度是否上升。
  5. 把「一步回退」扩展为「回退到任意历史节点并继续搜索」：设计动作空间、状态与记忆结构、训练信号与推理流程，并说明与 beam search 在算力与轨迹长度上的边界。★★★
    提示
    动作空间可定义为「当前动作」加「跳转到记忆中的某节点」；训练信号可用进度差分与到达目标的稀疏奖励组合，需要为跳转动作单独设计标签。推理时限制跳转预算（次数或深度），否则退化为图上的穷举搜索，轨迹长度与 SPL 的权衡即边界所在。

小结

  • 把导航视为导航图搜索，进度监控器充当可学习启发式；Regret Module 用进度差分产生前向与回溯的软权重，Progress Marker 把访问位置的进度值贴到各候选方向，供回退后重新决策。
  • 方向语义：Δp 为负倾向于回退；标记未访问填 1、停止填 0，差分 Δv = pt − vmarker 越低越优先。监控器输出在进入回溯模块前 detach，保留其校准目标。
  • 数字要点：测试集成功率 43% 到 48%（+5 点），SPL 0.32 到 0.40（+8 点、相对 +25%）；屏蔽回溯后 NE 上升 8.2%、SR 降 4.2%、OSR 降 9.8%，SPL 上升 10.8%（与前三项方向相反），证明增益来自回溯且提醒指标需联合解读。
  • 消融要点：只加标记增益接近 0，只加回溯把未见集成功率从 0.44 提到 0.47，两者组合 0.48；标记机制仅增加约 32,768 个权重参数（约 0.125 MiB float32）。
  • 训练要点：三项目标（动作交叉熵、进度回归、熵奖励），λ = 0.5、β = 0.01；训练期采样保证回溯样本，推理期贪心加内部回退，不执行 beam。
