第四篇 · 规模、记忆与泛化方法论

第 070 讲｜地图预训练目标设计

第 067 至 069 讲解决了地图载体，本讲回答“地图之上训什么”。以 BEVBert（An 等 2023，ICCV 2023，arXiv:2212.04385v2）的 MLM、HSAP、MSI 三个目标为样本，把预训练目标当作设计对象：掩码对象怎么选、监督形状怎么定、5 : 5 : 1 的预算如何分配、目标与下游动作接口如何对齐。实算给出采样账、监督密度与消融阶梯的边际收益，并交付一份目标函数设计工作坊流程。

  • 主题：自监督目标设计 / 预算分配 / 预训练-微调对齐 / 消融方法
  • 关键数字：采样比 5 : 5 : 1；预训练 6.4M 样本；消融阶梯 48.29 → 63.60 SPL
  • 预计学时：60 分钟
  • 前置讲：第 069 讲（网格记忆与指令相关性）

学习目标

  • 会算：采样比对应的迭代数与样本数、每类目标的监督密度、边际收益与预算再分配点。
  • 会写：MSI 掩码与多标签损失、HSAP 融合打分、预算核算三段核心代码。
  • 会判断：目标组合的取舍（决策级与表示级）、预算分配、数据条件是否满足某目标。
  • 会设计：同预算消融阶梯、目标-下游对齐检查与泄漏自查清单。

背景与动机

第 067 讲用局部度量地图聚合观测，第 068 讲用全局拓扑图承担规划，第 069 讲用动态网格保留全局视觉证据。载体解决“信息放在哪里”，预训练解决“表示学成什么样”。第 037 讲介绍过 BEVBert 的架构与三个目标的机制，那一讲的重心在结构与结果。本讲把预训练目标本身当作设计对象，回答四个问题：目标母题有哪几类、监督信号从哪里来、训练预算如何在目标之间分配、目标与下游决策接口的距离如何影响微调收益。

这些问题在方法论上有直接的操作价值。目标组合决定预训练能学到什么：掩码语言建模学语言与视觉的对应，动作预测学决策接口上的排序，掩码语义想象学未观测区域的空间先验。预算分配决定这些能力各占多少训练量。对齐程度决定微调阶段哪些参数可以复用、哪些要丢弃。上述四点共同解释一个经验事实：预训练目标的数量存在收益上限，边际收益会随预算摊薄而下降。

本讲方法数字来自 BEVBert（An 等 2023，ICCV 2023，arXiv:2212.04385v2），对照目标来自 PREVALENT（Hao 等 2020，CVPR 2020，arXiv:2002.10638v2）、DUET（Chen 等 2022，CVPR 2022，arXiv:2202.11742v1）、HOP（Qiao 等 2022，CVPR 2022，arXiv:2203.11591v1）与 GridMM（Wang 等 2023，ICCV 2023，arXiv:2307.12907v4）；预算与边际数字先经 Python 实算，脚本逻辑见第 5 节片段 3。

核心原理

本讲按“目标母题、三目标解剖、预算算术、边际收益、对齐分析、消融设计、数据条件、工作坊”八步展开，论文数字标注来源与 split。

1. 四个目标母题

把 030 至 069 讲出现过的预训练目标按监督方式归类，可以得到四个母题。母题决定了目标需要什么数据、监督形状是什么、与下游动作接口的距离有多远。

母题代表目标监督对象数据条件与下游距离
掩码重建MLM（PREVALENT 起沿用）、MVM、MSI被掩码的词元、视角或格子的标签文本与语义标注可得表示级
动作预测SAP、HSAP、PID 伪标签专家或伪专家在该状态的动作轨迹与连通性可得决策级
对比匹配路径-指令匹配、图文对比轨迹与指令的配对关系成对数据充足表示级
顺序建模TOM / GOM / APH（HOP）轨迹片段顺序与历史次序轨迹分段可得表示级

母题之间可以叠加，价值来自互补。掩码重建提供密集的局部监督，动作预测直接对准决策接口，顺序建模补充时间结构。BEVBert 的组合覆盖前两类：MLM 与 MSI 属掩码重建，HSAP 属动作预测。选择组合时的第一判据是数据条件，第二判据才是目标数量。

2. 三目标解剖：掩什么、监督什么、怎么用

三个目标共享同一套混合地图输入（拓扑图加局部度量图），差别在掩码对象与监督形状。

目标掩码对象监督形状每样本监督密度推理通路
MLM15% 指令词元（L = 80 时为 12 个）词表分类（交叉熵）12 个标签拓扑与度量两路融合后相加
HSAP无掩码，输入专家轨迹前缀全局动作空间排序（交叉熵）1 个动作标签格分数换算到节点后与节点分数门控融合
MSI15% 度量格（441 格时为 66 格）40 类多标签（二元交叉熵）66 × 40 = 2,640 个二元标签指令与部分观测地图联合推理

三者的设计意图不同。MLM 让语言表示与地图表示在同一空间对齐；HSAP 把表示压到与下游一致的动作打分接口上，融合权重 δt 由 stop 节点表示与中心格表示生成；MSI 要求模型“想象”未观测区域的语义，逼出空间先验。监督密度差异极大：MSI 每个样本产生 2,640 个二元标签，是 MLM 的 220.0 倍；批大小 64 时单个批次的 MSI 标签达 168,960 个。密标签带来强梯度，也带来预算消耗，这是 MSI 只占 9.09% 采样的直接原因。

3. 预算算术：5 : 5 : 1 的三层账

BEVBert 预训练按 MLM : HSAP : MSI = 5 : 5 : 1 采样，即每 11 次迭代分配 5、5、1 次。按 10 万次迭代、批 64 实算：

目标占比迭代数（10 万）样本数累计监督量
MLM45.45%45,454.52,909,091约 34.9M 词元标签
HSAP45.45%45,454.52,909,091约 2.9M 动作标签
MSI9.09%9,090.9581,818约 38.4M 格标签

预训练总样本量为 64 × 100,000 = 6,400,000；微调为 16 × 40,000 = 640,000，两者比例 10 : 1。采样比的设计有一条隐含约束：MSI 的单样本计算量与标签量都最大，若与 MLM 等比例分配，单步延迟与显存会被它主导；把它压到 9.09% 后，各目标的迭代预算与其单样本代价成反比，总量结构更均衡。结论一：采样比的依据是“单样本代价 × 采样次数”的总量配平，各目标等量监督并不必要。

4. 消融阶梯与边际收益

BEVBert 的目标消融（R2R val unseen，论文表 6）从无预训练基线逐级加入目标：

配置SRSPLSR 增量SPL 增量每预算百分点收益（SPL）
从零开始60.2448.29基线基线基线
加 MLM73.5260.13+13.28+11.840.2605
加 HSAP74.0363.03+0.51+2.900.0638
加 MSI74.8863.60+0.85+0.570.0627

三点读法。第一，MLM 贡献最大，它同时提升 SR 与 SPL，因为语言-视觉对齐是其他能力的基础。第二，HSAP 的 SR 增量只有 0.51，SPL 增量却达 2.90，说明动作预测主要改善路径效率：它让打分直接对准动作排序，减少了绕路。第三，MSI 的两个增量都小于 1，但方向一致，属于低预算的辅助目标。按“每预算百分点收益”折算，HSAP 与 MSI 接近（0.0638 与 0.0627），都低于 MLM 的 0.2605。结论二：边际收益的读法是“同预算对照下的增量除以该目标的预算占比”；当新增目标的每点收益降到 MLM 的四分之一量级时，继续增加目标数量的意义下降，预算转投数据规模或迭代次数的回报更高。

需要提醒的是，消融阶梯中的“加 HSAP”与“加 MSI”都在已有目标之上测量，增量不能简单相加；三个目标的交互项（例如 HSAP 依赖 MLM 建立的语言接地）需要通过目标 dropout 实验单独估计。这一部分放进第 6 小节的消融设计。

5. 对齐分析：目标与下游接口的距离

预训练目标与下游微调的距离决定复用方式。把三个目标按距离排列：

目标对齐的下游能力复用方式主要风险
HSAP动作打分与门控融合打分器与融合模块原样进入微调预训练动作空间与在线图分布不一致时漂移
MLM指令理解与跨模态对齐编码器参数复用，MLM 头在微调阶段丢弃头参数量大（约 23.44M），丢弃造成预训练算力沉没
MSI未观测区域的空间先验编码器参数复用，MSI 头丢弃需要语义标签表，跨数据集迁移时标签集变化

头参数量值得单独核算：词表约 30,522 时 MLM 头约 768 × 30,522 ≈ 23.44M 参数，MSI 头约 30,720 参数，HSAP 打分器只有 768 维共享映射。MLM 头占据的参数最多，在微调时整体丢弃；HSAP 的打分器与下游共用同一接口，是“决策级对齐”在参数层面的体现。这条差异解释了一个设计经验：把主要预算投给决策级目标（HSAP 占 45.45%）并不浪费，因为它产生的参数与结构能直接进入下游；表示级目标的作用是打底，预算与目标数量都应适度。

6. 同预算消融设计

目标消融最常见的误读是预算不等：给新目标增加训练量，收益中混入了数据与迭代的贡献。可复用的消融协议包含四条纪律。第一，等预算：所有配置使用相同的总迭代数与批大小，只改变采样比。第二，等参数：对照分支补齐同量可训练参数，区分结构收益与容量收益。第三，单变量：一次只改一个目标的有无或强度（掩码率、采样占比）。第四，多 split 报告：R2R 与 REVERIE 的指令结构不同，MSI 类目标在两者上的效果可能分叉（REVERIE 版本直接替换为 MRC 与 OG，原因见第 7 小节）。评价指标按目标定位选择：动作类目标看 SPL 与 NE，表示类目标看接地类指标（RGS / RGSPL）与长程指令的 SR。

7. 数据条件与适用边界

目标能否启用由数据条件决定。MSI 需要格级语义标签，BEVBert 使用 Matterport3D 的 40 类标注；换到 HM3DSEM 或城市数据时，标签表与实例定义都可能变化，需重新对齐类别空间。REVERIE 的指令主要描述终点物体，缺少中间路径描述，MSI 在该数据集上失去监督意义，BEVBert 用掩码区域分类（MRC）与物体接地（OG）替换。MVM 需要全景的视角结构；顺序建模需要轨迹分段。跨目标共享一条经验：合成或增广数据适合预训练，不适合直接进入策略微调。DUET 的消融显示，合成指令在预训练阶段带来 SPL 1.63 的提升，在策略微调阶段不再有增益，论文解释为策略学习需要更干净的动作-状态对齐。

另一条边界是泄漏。掩码重建类目标必须在掩码之后再做特征构造：若位置嵌入或邻域特征里残留被掩码格的真值，目标退化为恒等映射，指标虚高；同理，预训练语料与评测指令的交叉污染会抬高下游数字，检查方法见第 074 讲。

目标组合的默认结构取“一主一辅”：决策级目标（HSAP 类）占预算的四成以上，保证打分器与融合模块直接进入下游；表示级目标（MLM 类）占四成左右，承担语言-视觉对齐；其余预算留给一个低比例的辅助目标（MSI 类），用来补空间先验或区域语义。判据有三条：数据条件是否齐备、边际收益是否仍高于 MLM 的四分之一量级、微调接口是否能复用该目标的输出结构。三条都通过时保留辅助目标；任一不通过时把它替换为数据条件满足的同类目标（例如 REVERIE 上以 MRC 与 OG 替换 MSI），或者把预算转投迭代次数。

关键代码与解读

三段代码分别给出 MSI 掩码与多标签损失、HSAP 融合打分接口、预算与边际收益核算。数字与正文一致，可作为设计工作坊的脚本骨架。

片段 1：MSI 掩码与多标签损失

import torch
import torch.nn.functional as F

def msi_batch(cell_feats, cell_labels, mask_ratio=0.15, generator=None):
    """按比例掩盖度量格；返回掩码、可见输入与监督标签。
    cell_feats: (C, D)；cell_labels: (C, 40) 多热向量。"""
    c = cell_feats.size(0)
    mask = torch.rand(c, generator=generator) < mask_ratio
    masked_input = cell_feats.clone()
    masked_input[mask] = 0.0                  # 被掩码格置零，位置嵌入保持不变
    return masked_input, mask, cell_labels

def msi_loss(cell_logits, cell_labels, mask):
    """只对被掩码格计算 40 类二元交叉熵。"""
    logits = cell_logits[mask]
    targets = cell_labels[mask].float()
    return F.binary_cross_entropy_with_logits(logits, targets)

# 检查：masked_input 在 mask 位置必须为 0；
# 位置嵌入只含几何量，不含该格语义，否则目标退化为恒等映射。

解读：（1）掩码只作用于格特征，位置嵌入保留，让模型仍能知道“被掩码的位置在哪里”。（2）监督标签取自语义标注的多热向量，损失只统计被掩码格；441 格、15% 掩码率时每样本约 66 格参与计算。（3）代码末尾的检查是泄漏防线：任何进入网络的输入（含邻域聚合特征）都不能携带被掩码格的标签信息。

片段 2：HSAP 融合打分与接口对齐

def hsap_scores(node_feat, cell_feat, cell_to_node, gate_feat, node_head, cell_head):
    """决策级目标：节点分数与格分数在交集上按门控融合。
    node_feat: (K + 1, D) 含 stop；cell_feat: (C, D)；
    cell_to_node: 格到节点的下标映射；gate_feat 取 [stop 节点; 中心格]。"""
    n_scores = node_head(node_feat).squeeze(-1)
    c_scores = cell_head(cell_feat).squeeze(-1)
    delta = torch.sigmoid(gate_feat)              # 简化写法，实际经前馈网络
    scores = n_scores.clone()
    idx = cell_to_node[0]
    scores[idx] = delta * n_scores[cell_to_node[1]] + (1.0 - delta) * c_scores
    return scores                                 # 与微调阶段的打分接口同构

# 对齐检查：预训练的打分器 node_head 与 cell_head 在微调阶段原样保留，
# 因此两个头的输出维度与候选排列顺序必须与在线图一致。

解读：（1）融合只在“格到节点”的交集上替换分数，其余节点保留拓扑分数，与第 037 讲的式 4 分段定义一致。（2）门控由 stop 节点与中心格表示生成，示例用标量简化，实际为前馈网络输出。（3）接口对齐的检查落在候选排列顺序上：预训练与在线阶段的节点编号若不一致，打分器复用后分数会错位，这是迁移阶段最容易漏掉的错误。

常见坑

  • 采样比未记录：复现时三个目标的比例不同，指标对不上，消融无法归因。根因：采样比写在训练脚本而没有写入配置与报告。修复：采样比、每目标迭代数与随机种子一并记录，作为消融表的必备字段。
  • 掩码泄漏：掩码重建目标的损失正常下降，下游指标却无提升。根因：位置嵌入、邻域聚合特征或标签构造里残留被掩码格的真值，目标退化为恒等映射。修复：掩码后构造输入，跑“随机标签应使指标崩掉”的自检；把泄漏检查写进训练入口断言。
  • 在 REVERIE 上启用 MSI：该目标损失下降但对 SR 无贡献。根因：REVERIE 指令以终点物体描述为主，缺少路径与区域描述，格级语义监督与任务不对齐。修复：按数据条件替换为 MRC 与 OG；在目标选择表中显式记录数据条件判据。
  • 消融预算不等：新增目标的收益中混入数据量与迭代次数的贡献。根因：对照实验给新目标额外训练量。修复：固定总迭代与批大小，仅改变采样比；必要时再补一组“把新增预算全部给 MLM”的对照，量化预算本身的效果。
  • 把训练策略误记为预训练目标：报告目标组合时把 PID 伪标签与 RL 混入，结论无法比较。根因：混淆“监督信号来源”与“预训练任务”。修复：按第 1 小节的母题表归类，PID 归入动作预测的数据来源，MSI 归入掩码重建；报告中分开陈述。

练习与思考

  1. 按 5 : 5 : 1 与 10 万次迭代、批 64 实算：三个目标各自的迭代数、样本数与预训练总样本量；再计算微调（4 万次迭代、批 16）的样本量与两者比例。 ★
    提示
    占比 45.45% / 45.45% / 9.09%；迭代数 45,454.5 / 45,454.5 / 9,090.9；样本数 2,909,091 / 2,909,091 / 581,818；预训练合计 6,400,000，微调 640,000，比例 10 : 1。
  2. 用消融阶梯（SPL 48.29 → 60.13 → 63.03 → 63.60）计算三个目标的每预算百分点收益，解释为什么新增目标的收益低于 MLM 的四分之一量级时应考虑停止加目标，并给出两种预算再分配方案。 ★
    提示
    ΔSPL 为 11.84 / 2.90 / 0.57，除以预算占比得 0.2605 / 0.0638 / 0.0627。两种再分配：把辅助目标的 9.09% 转投数据规模或迭代次数；或把 HSAP 的比例调高，强化决策级对齐。选择依据落在数据条件与微调接口复用度上，与目标数量无关。
  3. 为 RxR 设计一个表示级目标：RxR 指令长、含分段结构，可考虑“掩码指令分段与轨迹片段对齐”。写出掩码对象、监督形状、所需数据条件与建议预算占比，并预测它在 R2R 与 RxR 上的效果差异。 ★★
    提示
    掩码对象可取指令分段（每段约 1 至 3 句），监督形状为“片段-轨迹子段”的匹配分类或对比损失；数据条件为带时间对齐的指令（RxR 具备）。预算占比建议 10% 至 20%，作为表示级辅助。预测：RxR 上长指令的分段监督收益更大，R2R 上指令短、分段稀疏，收益有限。
  4. 设计 HSAP 与 MLM 的等预算消融：说明如何构造“把 HSAP 预算全部转给 MLM”的对照，固定哪些变量，报告哪些指标，并预测两条曲线（SPL 与 NE）的形态差异。 ★★
    提示
    对照配置取 10 : 0 : 1 与 5 : 5 : 1，总迭代与批大小一致；固定骨干、数据、随机种子与评测脚本。指标报告 SPL、NE 与 SR。预测：全预算给 MLM 时 SR 接近、SPL 与 NE 落后，因为动作排序缺少决策级监督；HSAP 的收益集中在效率指标上。
  5. 工作坊综合题：为一个长程城市导航基准（指令长、含分段，具备语义标注与轨迹，无物体框）设计完整的目标方案：选出 2 至 3 个互补目标并说明母题归属与数据条件；给出采样比与迭代数；列出同预算消融阶梯（至少三级）；写出一条掩码泄漏检查与两条预期失效模式；最后说明该方案与 BEVBert 默认配置的差异及理由。 ★★★
    提示
    目标组合示例：MLM（表示打底，45%）+ 动作预测（决策级，45%）+ 顺序建模或分段对齐（辅助，10%）；若语义标注充分，可把辅助目标换成 MSI 类。消融阶梯：无预训练 → 加 MLM → 加动作预测 → 加辅助目标，全部等预算。泄漏检查：掩码后断言邻域聚合与位置输入不含被掩码真值。预期失效：城市指令的空间尺度与室内不同，MSI 的 40 类标签表需要重定义；长程轨迹的动作空间大，HSAP 的候选排序需要分层或窗口化。与 BEVBert 的差异：以顺序或分段目标替换 MSI，理由是指令长度与分段结构更接近 HOP 类设定。

小结

  • 预训练目标分四个母题：掩码重建、动作预测、对比匹配、顺序建模；组合的价值来自母题互补，第一判据是数据条件。
  • BEVBert 三目标：MLM（15% 词元、12 个标签/样本）、HSAP（全局动作空间、1 个动作标签）、MSI（15% 格、66 格 × 40 类 = 2,640 个二元标签）；采样比 5 : 5 : 1。
  • 预算算术：10 万次迭代、批 64 时三个目标约 2.91M / 2.91M / 0.58M 样本，预训练合计 6.4M；微调 640K，比例 10 : 1；累计监督量 34.9M / 2.9M / 38.4M，迭代预算与单样本代价成反比。
  • 边际收益（R2R val unseen）：ΔSPL 11.84 / 2.90 / 0.57，每预算百分点 0.2605 / 0.0638 / 0.0627；新增目标低于 MLM 四分之一量级时，预算应转投数据或迭代。
  • 对齐：HSAP 的打分器与融合模块直接进入微调，MLM 头（约 23.44M 参数）丢弃；组合默认取一个决策级目标加若干表示级目标。
  • 消融协议四条纪律：等预算、等参数、单变量、多 split；掩码泄漏需在掩码后构造输入。下一讲进入长程历史编码工程，讨论历史窗口、压缩与重采样的显存与延迟权衡（第 071 讲）。
