第一篇 · 任务、数据、仿真与评测地基

第 011 讲｜环境偏差诊断

本讲把「跨环境掉分」从现象变成可诊断的对象：先固定带符号 gap 与分解恒等式，再用指令排除、图排除、环境再切分三类实验定位偏差来源，最后用语义特征替换 2048 维外观特征并核算修复收益。读完应能独立设计一套成对协议、可复核的偏差诊断实验。

  • 主题：偏差诊断 / 误差分解 / 环境再切分 / 语义特征
  • 关键公式：g = SRseen − SRunseen；Δg = ΔSRseen − ΔSRunseen
  • 预计学时：70 分钟
  • 前置讲：第 010 讲（捷径与模态偏差）

学习目标

  • 会算：对成对 seen/unseen 结果计算带符号 gap、|gap| 与相对降幅，并把 gap 变化分解为 seen 分量与 unseen 分量，验证恒等式 Δg = ΔSRseen − ΔSRunseen。
  • 会设计：复述三类诊断实验（指令排除、图排除、环境再切分），为每类写出操作、判据与混杂因素。
  • 会区分：path-seen、path-unseen、env-unseen 三级 locality（局部性），解释 X-split 与 Z-split 的构造差异与适用范围。
  • 会实现：用零向量屏蔽视觉特征做图排除实验，用 42 维语义面积特征替换 2048 维 ResNet 特征，并预测 gap 走向。
  • 会评估：识别再切分实验的训练数据缩减混杂，写出控制样本量与优化预算的补充实验设计。

背景与动机

第 009 讲固定了 seen 与 unseen 的评测协议，第 010 讲展示了模态层面的捷径：去掉视觉输入，某些指标可以上升。两讲合起来留下一个尚未回答的大问题：智能体在训练环境上表现良好，换到新建筑后成功率大幅下降，这个落差究竟来自语言、来自导航图，还是来自视觉环境本身？文献里把这一现象称作环境偏差（environment bias），它是 R2R 系列任务公认的第一困难，但在 2020 年前后仍缺少清晰解释。

本讲围绕 Zhang、Tan、Bansal 2020 在 IJCAI 2020 发表的环境偏差诊断工作（arXiv:2005.03086）展开。该工作提出三个问题：偏差在哪里（where）、为什么存在（why）、如何缓解（how）。它用环境再切分与特征替换两组诊断实验给出定位结论，并在不修改基线模型与训练方法的前提下，用语义特征显著缩小 R2R、R4R、CVDN 三个数据集上的 seen-unseen 落差。这三个数据集分别对应导航、路径保真与对话导航三种任务口径，结论因此具有跨任务的一般性。

本讲的落点放在可复用的诊断方法学上，不讨论单个模型的调参技巧。第 012 讲会转向数据侧修正（RxR 的路径采样与稠密对齐），第四篇的第 075、076 讲回到方法侧去偏，两者都建立在本讲的口径与实验设计之上。

核心原理

1. 口径先行：带符号 gap 与分解恒等式

本课程统一把跨环境落差写成带符号量，方向约定为「seen 减 unseen」：

g = SRseen − SRunseen SR 为该任务的主指标；R2R 与 R4R 用成功率，CVDN 用目标进度（Goal Progress，单位分）；正值表示 seen 更高，负值表示 unseen 反超

设某次改动前后的四元组为 (SRseen(0), SRunseen(0)) 与 (SRseen(1), SRunseen(1))，则 gap 的变化可以无损失地分解到两条边：

Δg = g1 − g0 = ΔSRseen − ΔSRunseen ΔSRseen = SRseen(1) − SRseen(0)，ΔSRunseen 同理；恒等式对任意实数成立，不需要任何模型假设

用论文的核心结果实算一次。基线用 ResNet-152 均值池化特征（2048 维）：R2R 上 val-seen 56.1、val-unseen 47.5，g0 = +8.6。换成 Learned-Seg 语义特征后：52.6 与 53.3，g1 = −0.7。两条边的变化为 ΔSRseen = −3.5、ΔSRunseen = +5.8，于是 Δg = −3.5 − 5.8 = −9.3，与 g1 − g0 = −0.7 − 8.6 = −9.3 严格一致。|gap| 从 8.6 降到 0.7，相对缩小 91.9%；其中 unseen 相对提升 12.2%，seen 相对下降 6.2%。

只看 |gap| 会误导排序

论文表 1 转引（greedy 解码，R2R val）：EnvDrop（Tan 等 2019）为 62.1 / 52.2，|gap| = 9.9；论文自己的基线为 56.1 / 47.5，|gap| = 8.6。若按 |gap| 排序，基线胜出，而它的 seen 与 unseen 都更低。反例说明：|gap| 必须与两条边的绝对水平并报，单独的 gap 既可能由 unseen 提升缩小，也可能由 seen 下降制造。

2. 诊断问题的三分结构

把 seen-unseen 落差按候选来源拆成三块，再逐块排除，是这套方法学的骨架。三块分别为自然语言指令、底层导航图、视觉环境；对视觉环境内部再追问「哪类信息造成偏置」，最后给出修复方案。下表给出每类实验的操作与结论，具体数字在后续小节展开。

3. 排除语言：指令距离分档

语言假设的常见表述是：unseen 环境的指令用词与训练集差别更大，模型听不懂才掉分。检验办法是把每条验证指令到训练集的距离量化成两个数：ROUGE-L 取对训练指令的最大相似度，BLEU-4 把全部训练指令当参考集计算。中文写作里两个量的口径都应写全：

disrouge(x, T) = mint ∈ T ROUGE-L(inst(x), inst(t)) x 为验证条目，T 为训练集，inst(·) 取指令文本；取最小值意味着「与最相似的训练指令有多接近」
disbleu(x, T) = BLEU-4(inst(x), {inst(t)}t ∈ T) 全部训练指令同时作为 BLEU-4 参考；分数越高表示语言模式越接近训练分布

论文的两个观察互相配合：其一，seen 与 unseen 两条验证集的语言距离分布没有显著差异；其二，在同一距离档内，seen 的成功率仍然明显更高。如果语言是主因，那么距离分布里的 unseen 应整体偏远，而且同档内两者应接近。两个条件都不成立，语言假设被排除。这一结论的边界是：它排除了「指令标注分布差异」这一直接原因，还没有排除模型内部对语言统计量的利用，第 056 讲会从鲁棒性角度继续讨论。

4. 排除导航图：视觉置零实验

图假设的常见表述是：不同建筑的连通结构不同，模型在训练图上过拟合了度分布与转弯模式。检验办法是把 ResNet 视觉特征全部替换为零向量，模型只能依据指令与候选图做决策。实算结果：val-seen 38.5、val-unseen 41.0，带符号 g = −2.5。两个事实值得注意：

  • 无视觉时落差近乎消失：整体水平下降到 40% 附近，但两条边的差距收敛到约 2.5 点。这与 Hu 等 2019 的无视觉设置结论一致，说明图结构与指令的联合分布在不同建筑间的迁移性远高于视觉外观。
  • unseen 高于 seen：g 为负，说明这个设置下的 seen 优势消失了。一种合理解释是：指令中的动作词与局部图结构仍能提供跨建筑可迁移的线索，两边验证集的难度接近，落差因此收敛。

该实验的实现要点在代码片段 3 给出：屏蔽发生在特征进入模型之前，且必须整段历史一致地屏蔽，否则模型仍可从残留帧中读取外观信息，结论无效。

5. 环境再切分：三级 locality

原版 R2R 的 val-seen 与训练集共享整座建筑，几乎每条 val-seen 路径的视点都出现在训练路径中，因此无法把「路径重叠」与「建筑重叠」两个因素分开。论文用几何位置做结构性再切分：X-split 沿水平坐标把每栋房子切成两片，Z-split 按楼层切开。每次取一侧作训练「环境」，另一侧作 val-path-unseen「环境」；原 val-unseen 保持不动，记为 env-unseen。这样得到三个新验证集：

  • val-path-seen：与训练路径有交集，但路径本身不重复；
  • val-path-unseen：与训练路径无交集，但建筑与训练集相同；
  • val-env-unseen：建筑整体隔离，即原 val-unseen。

再切分的混杂因素

X-split 与 Z-split 的训练数据分别缩至 11,631 与 10,894 条，相对原版减少 17.07% 与 22.32%；训练侧 SR 也从 88.3 变为 87.3 与 94.7。训练集不仅变小，组成也因分区而变化。因此「P-unseen SR 低于 P-seen」支持 locality 的存在，但具体落差数值不能直接解释为纯环境效应，复现时应补做等数据量的随机丢弃对照组。

6. 区域局部性：距离分档曲线

环境级局部性的进一步刻画按「验证路径离训练数据的图距离」分档。两个距离定义先用图最短距离写成公式：

disviewpoint(v, T) = minv′ ∈ path(t), t ∈ T disgraph(v, v′) 视点 v 到训练集的距离，取到任一训练视点的最小图距离；disgraph 为带权最短路，单位米
dispath(x, T) = maxv ∈ path(x) disviewpoint(v, T) 路径到训练集的距离，取路径上各视点距离的最大值；最远的视点决定整条路径的「新鲜度」

取 max 的含义是：一条路径只要有一个视点远离训练数据，整条路径就暴露在陌生区域中，因此用最远处代表路径距离，平均处会稀释远端视点的影响。论文表 3 的分档结果如下。

X-split（距离 m 与 SR %）5–13：56.314–16：56.217–21：50.522–57：43.6−12.7
Z-split（距离 m 与 SR %）5–10：58.511–13：47.914–17：42.918–52：44.1−14.4

总体趋势是离训练区域越远成功率越低，X-split 四个档单调下降。Z-split 前三档明显下降，第四档回升 1.2 点，这种尾部波动在分档样本量有限时常见。正确的报告方式是给出逐档曲线并注明分档边界，不对单调性做超出数据的断言；两张表的分档边界不同，绝对值也不应跨表比较。

7. why：偏置载体是低层外观

定位到视觉环境后，论文继续追问环境中的哪类信息被过度学习。嫌疑对象是 ResNet-152 在 ImageNet 预训练后均值池化得到的 2048 维特征：它保留了大量纹理、颜色与光照等低层外观信息，而每栋房子、每个房间都有自己的「风格」，同一语义标签在不同建筑里的外观差别很大。验证实验把视觉输入替换为 ImageNet-1000 分类概率（1000 维），这是一个保留语义类别、丢弃大部分低层外观的表示。替换后 R2R 变为 47.1 / 48.2，|gap| 从 8.6 降到 1.1，R4R 与 CVDN 的 |gap| 同样缩小。噪声很大的一组特征却缓解了偏置，支持低层外观是载体的判断。

论文随后给出三类更精细的语义表示。检测特征（Detection）来自在 Visual Genome 上训练的 Faster R-CNN，第 ci 类特征的构造为面积与置信度的加权和：

fdetect = [ac1, ac2, …, acn]，aci = Σobj 属于 ci Area(obj) · Conf(obj) 论文按全库面积占比筛选出 152 类，故 fdetect 为 152 维；面积与置信度相乘，弱检测对特征的贡献被压低

真值语义分割（GT-Seg）用 Matterport3D 的像素级标注统计每类面积占比，共 42 维（40 个语义类加 2 个结构类）。它依赖评测环境提供标注，属于上界参照。可部署版本是学习式语义分割（Learned-Seg）：训练一个多层感知机，从 2048 维 ResNet 特征回归 42 维面积比例，结构为 2048 → 512 → 256 → 42，前两层 ReLU、输出层 sigmoid、层间丢弃率 0.3，损失为逐类二元交叉熵；训练用 61 个训练环境中的 51 个，其余 10 个调参，训练完成后冻结，用于替换全部环境的视觉输入。

实算参数规模：2048 × 512 + 512 = 1,049,088，512 × 256 + 256 = 131,328，256 × 42 + 42 = 10,794，合计 1,191,210 个参数，float32 约 4.54 MiB。相对替换掉的 2048 维特征，42 维的压缩倍数为 2048 / 42 ≈ 48.8 倍。

8. 适用边界与失效模式

  • 单组结果无方差：论文未报告多种子方差，gap 差 1 至 2 点的结论需要复现实验自行补齐显著性检验（第 007 讲的统计口径在此适用）。
  • GT-Seg 的泄漏风险：真值语义分割来自评测环境的标注，用于研究可以，用于排行榜或真机部署则不可获得，引用其数字时必须标注口径。
  • 再切分的组成混杂：训练集被分区后规模与内容同时变化，落差数值包含容量效应，补等量随机丢弃对照组后才能把落差归因到 locality。
  • 视觉替换不是全部解药：语义特征缓解的是外观主导的偏差；历史编码、动作空间、停止策略造成的偏差不在本文诊断范围内，第 075 讲起会补方法侧工具。
  • 跨任务外推需核对协议：同一现象在室外 Touchdown 上也被观测到（作者按纬度再切分，Task Completion 从 17.5 降到 5.3），但该数据集的任务完成口径与 R2R 不同，数字只作现象佐证，不作直接比较。

实现思路与设计

本讲把诊断方法落成一条可执行流水线：固定口径、逐项排除、再切分验证、特征替换、成对报告。设计的第一原则是任何一次比较都同时给出 seen 与 unseen 两条边，第二原则是每次只动一个变量。

3 再切分X-split / Z-split 构造三级验证集两段落差的相对大小训练样本量减少 17.07% / 22.32%
4 特征替换ImageNet、Detection、GT-Seg、Learned-Seg 四档替换Δseen 与 Δunseen 各自的方向各特征的先验训练数据与维度不同
5 报告成对表格加分解列恒等式 Δg = Δseen − Δunseen 逐行成立无；不成立说明数字抄录或口径有误

把本讲方法迁移到 R2R-CE 或其他变体时，逐项核对五件事：主指标口径是否一致；re-split 的切分单位是否为建筑（按轨迹切会引入路径重叠）；视觉替换接口是否为「每视角定长向量」；特征先验侧是否与评测侧隔离；报告是否同时含 seen、unseen、g、|g| 四列。任一项不满足，诊断结论只能限定在满足的范围内陈述。

关键代码与解读

三段代码分别把成对口径、区域距离与特征替换落成可运行实现。所有输出与正文数字一致，均可离线复算。

片段 1：成对报告与 gap 分解

def pair_report(name, seen, unseen, unit="点"):
    """成对报告：四条字段齐备时，gap 分解才有定义。"""
    g = seen - unseen                      # 带符号 gap，正值为 seen 更高
    print(f"{name}: seen={seen:.1f} unseen={unseen:.1f} "
          f"g={g:+.1f}{unit} |g|={abs(g):.1f}")
    return g

g0 = pair_report("ResNet", 56.1, 47.5)     # +8.6
g1 = pair_report("GT-Seg", 55.6, 56.2)     # -0.6
d_seen = 55.6 - 56.1                       # -0.5
d_unseen = 56.2 - 47.5                     # +8.7
assert abs((g1 - g0) - (d_seen - d_unseen)) < 1e-9
print(f"delta_g={g1 - g0:+.1f} = d_seen {d_seen:+.1f} - d_unseen {d_unseen:+.1f}")
print(f"|g| 相对缩小 {(abs(g0) - abs(g1)) / abs(g0) * 100:.1f}%")  # 93.0%

解读：（1）函数返回带符号 g，打印 |g| 只作辅助；两套口径同时输出，避免排序误判。（2）断言把恒等式变成回归测试：任何一次实验后处理中的口径错乱都会被立即发现。（3）换入 Learned-Seg（52.6 / 53.3）时会得到 g = −0.7 与 91.9% 的 |g| 缩小，与正文一致。

片段 2：区域距离与路径距离

import heapq

def graph_dist(graph, src, dst):
    """导航图带权最短路，权重单位为米；不可达返回 inf。"""
    dist = {src: 0.0}
    pq = [(0.0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if u == dst:
            return d
        if d > dist.get(u, float("inf")):
            continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return float("inf")

def viewpoint_dist(v, train_nodes, graph):
    """视点到训练集的距离：到任一训练视点的最小图距离（论文式 4）。"""
    return min(graph_dist(graph, v, t) for t in train_nodes)

def path_dist(path, train_nodes, graph):
    """路径到训练集的距离：路径上视点距离的最大值（论文式 3）。"""
    return max(viewpoint_dist(v, train_nodes, graph) for v in path)

graph = {"a": [("b", 2.5)], "b": [("a", 2.5), ("c", 3.0)], "c": [("b", 3.0)]}
train = ["a"]
print(path_dist(["c"], train, graph))      # 5.5，最远视点决定整条路径

解读：（1）距离定义与第 001、006 讲的图距离口径一致，单位米；训练视点集合取训练路径上出现过的全部视点。（2）path_dist 取 max，语义是「路径上最陌生的那个视点」；若改取平均，靠近边界的路径会被系统性低估距离。（3）该函数只用于离线诊断分档，不进入训练侧，避免把训练集距离当作模型输入。

片段 3：视觉屏蔽与语义特征替换

import torch
import torch.nn as nn

class LearnedSeg(nn.Module):
    """2048 维外观特征映射到 42 维语义面积；训练后冻结并替换视觉输入。"""
    def __init__(self, in_dim=2048, num_classes=42):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 512), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(512, 256), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(256, num_classes), nn.Sigmoid(),   # 面积比例落在 [0, 1]
        )

    def forward(self, resnet_feat):
        return self.net(resnet_feat)                     # (B, V, 42)

def mask_visual(feats, mask_prob=1.0, generator=None):
    """图排除实验：按概率把视角特征置零，mask_prob=1.0 表示全部屏蔽。"""
    keep = torch.rand(feats.shape[:-1] + (1,), generator=generator) >= mask_prob
    return feats * keep

def check_area(feat42):
    """面积特征的值域检查：逐类独立，不做归一化。"""
    assert feat42.shape[-1] == 42
    assert float(feat42.min()) >= 0.0 and float(feat42.max()) <= 1.0

feats = torch.randn(4, 12, 2048)          # 批大小 4，每帧 12 视角
seg = LearnedSeg()
print(seg(feats).shape)                   # torch.Size([4, 12, 42])
print(mask_visual(feats, 1.0).abs().sum().item())  # 0.0，视觉信息完全屏蔽

解读：（1）替换层的输出形状保持 (B, V, d)，导航模型只需把输入维度从 2048 改为 42，其余结构不动，对应论文「不改模型与训练法」的设定。（2）mask_visual 用生成器参数支持固定随机种子；mask_prob = 1.0 退化为零向量屏蔽，mask_prob = 0.5 是介于两者之间的诊断档，用于观察屏蔽强度的影响。（3）check_area 把「sigmoid 输出、逐类独立」写成断言；若实现里误加 softmax 归一化，面积之和恒为 1，整类信息会被相邻类稀释，这种错误能在断言前就被形状与值域测试暴露。

常见误区

  • 用 |gap| 排序模型：症状是「gap 小者胜」的结论与 unseen 排名冲突；根因是 |gap| 可由 seen 下降制造。R4R 上 ImageNet 替换把 seen 砍 25.9 点、unseen 也降 1.8 点，|gap| 仍缩小到 0.2。修复：四列并报（seen、unseen、带符号 g、|g|），以 unseen 为主排序依据，gap 作诊断信息。
  • 再切分实验不做等量对照：症状是把 locality 落差全部解读为环境偏差；根因是训练样本减少 17% 至 22% 且组成变化。修复：补一组随机丢弃等量数据的对照组，固定优化预算与随机种子，比较两组的 P-unseen SR。
  • 替换特征后只报 unseen：症状是宣称「偏置已修复」但 seen 大幅下降；根因是语义特征削弱了外观记忆带来的 seen 红利。修复：成对报告并给出 Δseen、Δunseen 分解，把「unseen 上升且 seen 可接受」作为采用门槛。
  • 把语言距离实验过度外推：症状是以「分布无差异」断言语言完全无关；根因是 ROUGE-L / BLEU-4 只度量文本表面相似度，模型仍可利用词序与统计规律。修复：表述限定为「标注分布差异不是直接原因」，并补指令替换、遮蔽等因果探针实验。
  • 对区域曲线强行拟合单调下降：症状是结论与 Z-split 末档回升 1.2 点矛盾；根因是分档样本量有限、边界人为划定。修复：报告逐档数值与样本量，允许对尾部波动作中性描述，不给出超出数据的单调性主张。

练习与思考

  1. 给定 R2R 上 ImageNet 替换结果（47.1 / 48.2）与 Detection 替换结果（55.9 / 50.0），分别计算带符号 g、|g|、|g| 的相对缩小幅度以及 Δseen、Δunseen，并指出哪一种替换以牺牲 seen 换取 gap 缩小。★
    提示
    ImageNet：g = −1.1，|g| 由 8.6 降到 1.1（−87.2%），Δseen = −9.0、Δunseen = +0.7，seen 付出更大代价。Detection：g = +5.9，|g| 缩小 31.4%，Δseen = −0.2、Δunseen = +2.5，属于两头都稳的温和改善。
  2. 写出 disviewpoint 与 dispath 的公式，解释 path 层为何取 max 不取平均，并说明该距离为何只能用于离线分档。★
    提示
    最远视点决定路径是否进入陌生区域；平均会稀释少数陌生视点的影响。距离依赖训练集全体视点，训练侧可见会造成信息泄漏，因此只作诊断量。
  3. 把图排除实验从「全部置零」改为「随机屏蔽一半视角特征」（mask_prob = 0.5），预测 seen、unseen 与 |gap| 相对全屏蔽设置的变化方向，并给出依据。★★
    提示
    保留一半外观信息后，整体水平应高于全屏蔽（seen 与 unseen 同升），但残留的外观记忆会让 gap 从 −2.5 向正方向移动，|gap| 可能变大。这正是「屏蔽强度是连续变量」的体现，可用代码片段 3 的 mask_prob 扫描验证。
  4. 用 R4R 的 Learned-Seg 数字（54.6 / 30.7 → 38.0 / 34.3）完成 gap 分解，验证恒等式，并解释 seen 下降 16.6 点的机制。★★
    提示
    Δg = 3.7 − 23.9 = −20.2；Δseen = −16.6、Δunseen = +3.6，恒等式成立。R4R 的基线在 seen 上依赖外观记忆获得高 SR，换成 42 维语义表示后这部分红利消失，而 unseen 因学到的类别线索更可迁移而小幅上升。
  5. 为 X-split 设计一个控制训练数据量的复核实验：目标是把「locality 落差」与「训练量缩减」分离。要求写出对照组构造、训练预算控制方式、评价指标与至少两种可能的误报，并说明判据。★★★
    提示
    对照组：从原训练集随机丢弃 14,025 − 11,631 = 2,394 条（占 17.07%），保持场景覆盖分层；训练预算固定为相同迭代数与批大小，多种子重复。指标同时看训练 SR、P-seen SR、P-unseen SR。误报来源：随机丢弃改变了指令长度分布；X-split 的分区边界与房间结构相关。判据：若对照组在 P-unseen 上与 X-split 差异不显著，而 P-seen 显著更高，则 locality 结论成立；反之落差主要归因于容量与组成。

小结

  • 口径：跨环境落差用带符号 gap g = SRseen − SRunseen 表示，改动效果分解为 Δg = Δseen − Δunseen；|gap| 可被 seen 下降制造，必须四列并报。
  • 定位：语言距离分档与视觉置零实验分别排除指令与图；X-split / Z-split 把落差细分为路径级、区域级、环境级三层 locality，两段落差合计 12.2 点（X）与 20.1 点（Z）。
  • 归因：2048 维 ResNet 特征中的低层外观是偏置载体；ImageNet-1000、检测面积、真值分割、学习式分割四档替换普遍缩小 |gap|。
  • 实算：Learned-Seg 在 R2R 上把 seen 56.1 变为 52.6、unseen 47.5 变为 53.3，|gap| 缩小 91.9%；预测器 1,191,210 个参数、42 维输出，压缩约 48.8 倍。
  • 纪律：再切分训练量缩减 17.07% 与 22.32%，须补等量随机丢弃对照；GT-Seg 属研究上界，不可用于部署评测。
  • 下一讲转向数据侧的修正：RxR 用二层路径采样削弱最短路先验，用三种语言与词级时间对齐提供稠密监督，规模与统计口径都进入新的量级。
