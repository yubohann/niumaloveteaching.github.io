第四篇 · 规模、记忆与泛化方法论

第 075 讲｜偏差诊断方法学

第 074 讲把语料与评测的边界立清楚；本讲在干净边界内回答下一个问题：已见环境与未见环境之间的性能落差从哪里来。以 Zhang、Tan、Bansal 的偏差诊断工作（IJCAI 2020，arXiv:2005.03086）为主线，把诊断拆成三步：先排除语言与导航图两个候选原因，再用结构重划分把落差定位到路径级、区域级、环境级三层空间局部性，最后用语义特征替换验证「低层视觉外观是主因」的假设，并给出可复用的诊断模板 v1。

  • 主题：环境偏置 / 结构重划分 / 特征替换 / 语义特征
  • 关键数字：R2R 基线 56.1 与 47.5（落差 8.6）；语义分割特征 52.6 与 53.3（落差 −0.7，收窄 91.860%）；重划分后 path-unseen 与 env-unseen 相差 5.9 与 5.4 个点
  • 预计学时：60 分钟
  • 前置讲：第 074 讲（预训练数据边界与泄漏）

学习目标

  • 会复现：where-why-how 三段诊断链，按语言、导航图、视觉环境、特征表示逐项排除或确认候选原因。
  • 会算：已见与未见的落差、相对收窄幅度、重划分三级局部性差与区域距离分层成功率，并解释落差的符号约定。
  • 会实现：结构重划分（按坐标切分环境）、图距离分层、语义特征替换（含 2048 到 42 维的预测网络）三段最小代码。
  • 会判断：落差归零的两类情形（真实收窄与整体水平过低），单因素替换的归因边界，以及真值语义特征作为上界的使用方式。
  • 会设计：一份诊断模板 v1，含控制变量、扰动阶梯、测量三元组与多基线复核，能迁移到记忆、地图与基础模型类智能体。

背景与动机

第 074 讲解决了「结论能不能立」的问题：语料与评测之间必须给出交集矩阵与边界声明。边界之内还有第二个问题：同一个智能体在训练环境与未见环境上的表现相差多少、差在哪里。这个问题在 VLN 里长期存在，早期文献把它归因于「模型过拟合训练环境」，但缺少把候选原因逐项排除的实验设计。没有归因，改进手段只能凭经验叠加；有了归因，处方才有针对性。

Zhang、Tan 与 Bansal（IJCAI 2020）采用一套系统化的诊断实验。他们把落差来源拆成三个候选：自然语言指令、底层导航图、视觉环境，用指令文本距离分析排除语言，用零视觉输入实验排除导航图，再用 X 轴与 Z 轴结构重划分把视觉环境的影响细分为路径级、区域级、环境级三层局部性。确认低层视觉外观是主因后，他们用四类更高层的语义表示替换 ResNet 特征，在不改动模型结构与训练配方的条件下把落差显著收窄，并在 R2R、R4R 与 CVDN 三个数据集上验证。

本讲把这套诊断整理成可复用方法学：先讲现象与口径，再讲三段诊断，然后给出诊断模板 v1 与最小实现，最后讨论归因边界。第 076 讲接续给出因果去偏的处方；第 074 讲的边界纪律是本讲全部数字有效的前提。诊断的价值在于把「性能差」翻译成「哪一层、哪种信息、用什么干预可以改变」。

核心原理

本讲按「现象口径、语言排除、图排除、结构重划分、区域局部性、低层视觉成因、语义替换、模板与边界」八步展开。论文数字统一标注来源（arXiv:2005.03086v1，IJCAI 2020）；除特别说明外，实验只用模仿学习、不使用强化学习与数据增广，指标为贪心解码下的成功率（SR）。

1. 现象与口径：落差的定义与分布

本讲定义落差 Δ = SRseen − SRunseen，Δ 为正表示已见环境更好，Δ 为负表示未见环境略高。R2R 上的历史结果：Speaker-Follower 66.4 与 35.5，Δ = 30.9；RCM 66.7 与 42.8，Δ = 23.9；SMNA 67 与 45，Δ = 22；Regretful 69 与 50，Δ = 19；EnvDrop 62.1 与 52.2，Δ = 9.9；ALTR 55.8 与 46.1，Δ = 9.7。所有数字为贪心解码，口径相同。同一现象在 R4R 与 CVDN 复现：R4R 上 Speaker-Follower 51.9 与 23.8（Δ = 28.1）、RCM 55.5 与 28.6（Δ = 26.9）；CVDN 的目标进度（Goal Progress，单位近似为米）在 NDH 上为 5.92 与 2.10（Δ = 3.82）。室外数据同样存在：Touchdown 按纬度重划城市后，基线在训练子集与未见子集上的任务完成率为 17.5 与 5.3（Δ = 12.2）。

两个对照值得先记住。其一，Anderson 等 2019 的贝叶斯状态跟踪方法取得 31 与 31 的零落差，代价是水平过低；论文明确指出，收窄落差本身不构成目标，必须与未见环境的绝对水平并列报告。其二，论文自己的基线为 56.1 与 47.5（Δ = 8.6），只使用模仿学习，专门为归因实验保留干净的训练配方。落差是相对量，脱离未见水平单独优化会走向「两个集合都做差」的假胜利。

2. 排除语言：指令距离分析

第一个候选解释是「未见环境的指令与训练指令差异大，语言理解的难度造成落差」。检验方式是把每条验证指令与整个训练指令集合的距离量化：

disrouge(x, T) = mint∈T ROUGE-L(inst(x), inst(t)) dis 为指令距离；x 为验证样本，inst(x) 为其指令文本，T 为训练指令集合；另有 disbleu(x, T) = BLEU-4(inst(x), {inst(t)}t∈T)

结果有两个层次。第一，已见与未见的距离分布没有显著差别，两组指令在文本层面同源。第二，成功率确实随距离减小而上升，这一趋势在两组内都成立；但在相同距离处比较，已见环境的成功率仍显著高于未见环境。若语言是主因，控制距离后两组应接近，事实与此不符，语言被排除。表层文本距离还说明一件事：语言风格本身泛化较好，把未见环境的失败归因于「没见过这种说法」缺乏证据。

3. 排除导航图：零视觉输入实验

第二个候选是底层导航图（navigational graph）：顶点与连边结构本身可能被记忆。检验方式是把视觉特征整体置零，让智能体只依据指令与图结构决策。此时基线在已见与未见的成功率为 38.5 与 41.0，落差 Δ = −2.5，未见略高，且远小于通常的 10 个点以上。这说明图结构提供了可迁移的决策信息，未见过拟合。结合语言与图两步的排除，论文把落差定位到视觉环境。

4. 结构重划分：把环境效应拆成三层

原始划分无法单独观察视觉环境的作用：val seen 的几乎所有视角都出现在训练轨迹里，路径级、区域级与环境级三种效应叠在一起。论文提出结构重划分（structural re-splitting）：按水平坐标切一刀为 X-split，按竖直坐标把楼层分开为 Z-split，把训练环境切成两半，一半保留为训练，另一半作为同场景内的新验证区域。重划分后得到三个验证档位：路径已见（path-seen，与训练轨迹重叠）、路径未见（path-unseen，同一环境内未出现在训练轨迹中）、环境未见（env-unseen，原有 val unseen 数据，保持不变）。

5. 区域级局部性：按图距离分层

第三层用测地距离量化。先定义视角到训练数据的距离，再定义路径距离为该路径上所有视角距离的最大值：

disviewpoint(v, T) = minv′∈path(t), t∈T disgraph(v, v′) disgraph 为图上的最短路距离（Dijkstra 计算）；dispath(x, T) = maxv∈path(x) disviewpoint(v, T)

把 path-unseen 样本按路径距离分箱后，成功率随距离下降。X-split 四档（5 至 13、14 至 16、17 至 21、22 至 57 米）为 56.3、56.2、50.5、43.6，最大档比最小档低 12.7 个点；Z-split 四档（5 至 10、11 至 13、14 至 17、18 至 52 米）为 58.5、47.9、42.9、44.1，整体下降 15.6 个点，最后一档出现轻微回升（44.1 高于 42.9），提示分箱样本量与室内布局差异会给末端带来噪声，报告时应附每箱样本量。区域级局部性成立：离训练区域越远，成功率越低。

6. 成因确认：低层视觉外观

视觉环境内部还有多种可能：物体布局、房间连接、外观风格。论文的判别实验是把 2048 维 ResNet 特征替换为 ImageNet 1000 类分类概率。概率向量丢失了低层纹理与颜色细节，只保留高层类别语义。替换后落差大幅收窄：R2R 从 8.6 降到 1.1（收窄 87.209%），R4R 从 23.9 降到 0.2，CVDN 从 3.55 降到 2.59。但未见水平有得有失：R2R 为 48.2（比基线 47.5 高 0.7），R4R 为 28.9（比基线 30.7 低 1.8），CVDN 为 3.11（高 0.06）。机制解释：同一语义标签在不同房子与不同房间里的视觉呈现差异很大，ResNet 特征把这些「风格」也编码进去，模型记忆风格后在未见环境失效；高层语义对风格不敏感，因此泛化，但也丢掉了可用于导航的细节信息。落差收窄与未见水平提升是两个不同目标，ImageNet 特征只完成前者，给出的是机制证据与上界探针。

7. 处方验证：四类语义特征替换

沿高层语义方向继续，论文比较四类表示。检测特征（Detection）用 Faster R-CNN 在 Visual Genome 上检测物体，取每个类别的面积乘置信度求和，保留 152 个与导航相关的类别。语义分割特征把每个视角按像素标注 42 类（40 个语义类加 2 个结构类），取每一类面积占比得到 42 维；使用真值语义称为 GT-Seg，用训练环境学出的网络预测称为 Learned-Seg。预测网络为三层感知机：输入 2048 维 ResNet 特征，隐层 512 与 256 带 ReLU，输出 42 维经 Sigmoid，损失为逐类二值交叉熵，层间 Dropout 取 0.3；训练用 61 个训练环境中的 51 个，剩余 10 个用于调超参数。该网络参数量为 1,191,210。

8. 从一次实验到方法学：模板 v1

把上述流程抽象成五条规则，构成本讲的诊断模板 v1。规则一，控制变量：诊断期间模型结构、超参数、训练配方保持冻结，任何替换只改输入表示的一个因素。规则二，扰动阶梯：按语言、导航图、视觉环境、特征表示的顺序逐层排除，每层给出「置零、替换、重划分」三类操作中的一种。规则三，测量三元组：每个实验同时报告已见、未见与落差，另加空间分档（path-seen、path-unseen、env-unseen），缺少任一列的结论不进入汇总。规则四，归因复核：单因素替换的结论至少在一个异质基线上重复一次，两个模型上趋势一致才记为归因成立。规则五，报告纪律：给出样本量与不确定度。用 Wilson 区间做粗算：R2R val unseen 样本量 2,349，未见 53.3% 的 95% 区间约 [51.28, 55.31]，基线 47.5% 约 [45.49, 49.52]，两区间不重叠，5.8 个点的提升在近似独立口径下达到常规显著水平；配对检验需按 episode 级别重算，区间只用于快速判读。

适用边界也要写明：诊断结论建立在 Matterport3D 数据、ResNet-152 特征、仅模仿学习的基线与 2020 年前后的模型规模上。迁移到地图记忆类或基础模型类智能体时，「低层视觉成因」的结论需要重新检验，方法学部分（台阶式排除与双指标报告）可以复用。第 076 讲将在此基础上给出因果去偏的处方。

任何以「收窄落差」为卖点的方案必须同时报告未见环境的绝对水平与样本量，否则无法区分「真收窄」与「整体做差」。替换实验一次只改输入表示一个因素，模型结构与训练配方冻结，否则归因失效；结论至少在两个异质基线上复核。判据：若某方案在 R2R 把落差从 8.6 收窄到 3 以下、同时未见水平不下降、且在第二个基线上趋势一致，才记为诊断结论成立。

与相邻讲的分工：第 074 讲保证边界干净；本讲完成定位与归因；第 076 讲把归因结果转化为因果干预模块，处理可观测与不可观测混淆因子。三讲共享同一套报告纪律：落差、未见水平、样本量并列。

关键代码与解读

三段代码分别给出结构重划分、图距离分层与语义特征预测网络。数字与正文一致，用于复现实验骨架；生产实现中图距离应使用预计算的全对最短路表。

片段 1：结构重划分与三档验证集

def structural_resplit(trajectories, viewpoints, axis="x", cut=None):
    """按坐标把训练环境切两半，产出训练、path-seen、path-unseen 三档。"""
    train_vps, held_vps = set(), set()
    for vid, (x, z) in viewpoints.items():
        coord = x if axis == "x" else z
        (train_vps if coord < cut else held_vps).add(vid)
    train, p_seen, p_unseen = [], [], []
    for traj in trajectories:
        vps = set(traj["viewpoints"])
        if vps & held_vps == set():
            train.append(traj)            # 全在训练侧：进入训练集
        elif vps & train_vps == set():
            p_unseen.append(traj)         # 全在保留侧：路径未见
        elif vps & train_vps:
            p_seen.append(traj)           # 跨切分线且触及训练侧：路径已见
    assert not (set(t["id"] for t in train) & set(t["id"] for t in p_seen))
    return train, p_seen, p_unseen

# X-split 示例：14,025 条原始训练数据重划为 11,631 / 1,230 / 1,098
# 划分只用坐标与视角集合，禁止读取验证指令文本，避免二次泄漏

解读：（1）切分键取坐标轴，才能在同一环境内制造「近邻未见」区域；按场景编号切分只得到环境级隔离，覆盖不了路径与区域两层；（2）轨迹按与两侧视角集合的关系分三类，跨线且触及训练侧的轨迹归 path-seen，保证三档语义互斥；（3）划分脚本不读取验证指令，避免用文本信息调切分线造成隐蔽泄漏。

片段 2：图距离分层

import heapq, math

def dijkstra(adj, src):
    """单源最短路，adj 为邻接表，边权为米。"""
    dist = {src: 0.0}
    heap = [(0.0, src)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist.get(u, math.inf):
            continue
        for v, w in adj.get(u, []):
            nd = d + w
            if nd < dist.get(v, math.inf):
                dist[v] = nd
                heapq.heappush(heap, (nd, v))
    return dist

def path_distance(traj, train_vps, dist_to_train):
    """路径距离定义为路径上视角到训练数据距离的最大值。"""
    return max(dist_to_train.get(v, math.inf) for v in traj["viewpoints"])

def stratified_sr(trajs, bins, key_fn):
    """按路径距离分箱统计成功率与样本量。"""
    table = {b: [0, 0] for b in bins}       # 每箱记录 [成功数, 总数]
    for traj in trajs:
        for b in bins:
            if b[0] <= key_fn(traj) < b[1]:
                table[b][1] += 1
                table[b][0] += int(traj["success"])
                break
    return {b: (c / n if n else None, n) for b, (c, n) in table.items()}

# X-split 四档 SR：56.3 / 56.2 / 50.5 / 43.6，末端档样本少须附 n

解读：（1）距离先按视角到训练视角集合求最小图距离，再对整条路径取最大值，前者刻画「最近可借鉴的经验」，后者刻画「路径中最没依据的一段」；（2）分箱统计同时返回样本量，防止用几十条样本的末端箱下结论；（3）Dijkstra 在生产中替换为预计算的全对最短路，Matterport3D 单场景视角规模使查表成本远低于在线求最短路。

常见坑

  • 只报落差，不报未见水平：方案把落差从 8.6 压到 1，看似成功，未见水平可能同时下降。根因是把相对量当成目标。修复：所有表格并列「已见、未见、落差」三列，附加样本量与区间。
  • 把真值语义特征当成可部署方案：GT-Seg 在 R2R 未见达到 56.2，高于可用特征的 53.3。根因是忽略测试时语义标注不可得。修复：真值特征只作为上界参照，部署方案以预测特征为准，并在论文中明确两者关系。
  • 重划分时用验证数据调切分线：为了让 path-unseen 更「干净」而根据验证表现移动坐标切分线。根因是划分脚本读取了验证信息。修复：切分线只由训练环境的坐标分布确定，脚本冻结后不再调整；所有检查跑在划分之后。
  • 把单因素替换的收窄过度归因：换用 ImageNet 概率后落差降到 1.1，但未见水平几乎没升，且 R4R 的未见水平下降。根因是把「落差小」直接读成「表示更好」。修复：区分机制证据与处方证据，机制探针允许水平损失，处方方案要求落差与水平同时不劣化，并在异质基线上复核。
  • 区域分箱末端小样本：Z-split 最后一档 SR 回升（44.1 高于 42.9），直接解释成「远处更好」会得出相反结论。根因是分箱样本量不均、末端布局特殊。修复：每箱附样本量，末端合并或加置信区间，结论只描述主趋势。

小结

  • 环境偏置表现为已见与未见的落差，R2R 上从 8.6 到 30.9 个点不等；报告必须把落差与未见环境绝对水平并列，零落差只在与高水平同时出现时才有意义。
  • 诊断链第一步排除语言：指令的 ROUGE-L 与 BLEU-4 距离分布在两组同源，相同距离处已见仍占优；第二步排除导航图：视觉特征置零后两组为 38.5 与 41.0，落差 −2.5（绝对值 2.5）。
  • 结构重划分把环境效应拆成路径级、区域级与环境级：X-split 的 path-unseen 52.6 高于 env-unseen 46.7，Z-split 为 47.8 与 42.4；区域成功率随图距离下降，X 档间差 12.7 个点。
  • 成因是低层视觉外观：ImageNet 1000 类概率使 R2R 落差从 8.6 降到 1.1（收窄 87.209%），可见水平有得有失，机制解释是风格记忆。
  • 语义分割特征同时改善落差与未见水平：Learned-Seg 在 R2R、R4R、CVDN 的落差收窄 91.860% / 84.519% / 60.282%，未见提升 12.211% / 11.726% / 44.590%（CVDN 量纲为目标进度，按相对比例读）；SMNA 与 Regretful 复核一致，GT-Seg 只作上界。
  • 诊断模板 v1 的五条规则：控制变量、扰动阶梯、三元组测量、异质基线复核、样本量与区间报告；该模板可迁移到记忆与基础模型类智能体，结论边界随表示与模型规模更新。
