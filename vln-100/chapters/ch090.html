第五篇 · 基础模型与 2026 前沿

第 090 讲｜NaVILA：足式两级 VLA

本讲以 Cheng 等 2024 的 NaVILA（arXiv:2412.04453v2）为主线：高层视觉语言模型把观测与指令变成带空间量的语言中层动作（如 move forward 75cm），低层视觉运动强化学习策略把命令转成关节动作。两级结构用同一套 VLA 支撑 Unitree Go2、Unitree H1、Booster T1 三类平台，并给出 VLN-CE-Isaac 腿足导航基准与真机结果。学完能设计两级接口、核算频率账、判断仿真成功与腿足可行性的差距。

  • 主题：足式 VLN / 两级 VLA / 语言化中层动作 / 运动控制与评测
  • 关键数字：R2R-CE val-unseen SR 54.0、RxR-CE val-unseen SR 49.3、真机整体成功率 88%、碰撞率 3.09 降至 0.81
  • 预计学时：60 分钟
  • 前置讲：第 089 讲（Uni-NaVid：统一导航 VLA）

学习目标

  • 会算：中层动作到执行时长（前进 75 厘米在 0.5 米/秒下需 1.50 秒；转向 30 度在 30 度/秒下需 1.00 秒），以及「模型推理延迟与动作执行时长之比」对闭环的影响。
  • 会解释：把中层动作写成带空间量的自然语言有哪三点收益（跨平台复用、可用人类视频训练、时间尺度解耦），以及低层策略为什么需要视觉高度图。
  • 会实现：命令解析与执行、连续动作合并与停止类重平衡、LiDAR 高度图与策略观测构建三段示意代码。
  • 会判断：端到端低层 VLA、技能库加语言控制器、两级语言中层动作三种方案各自的适用条件与证据强度。
  • 会设计：腿足导航评测方案（VLN-CE-Isaac 式）与跨平台迁移实验，明确层级指标。

背景与动机

第 089 讲的 Uni-NaVid 把动作统一为前进 25 厘米、转向 30 度，动作粒度默认底盘能精确执行。换成四足或人形机器人，这个假设立即失效：基座要维持平衡、腿要落足、地面有碎石与台阶，低层动作空间变成 12 个关节电机的目标位置，高层模型无法直接输出。

一条直接路线是把 VLM 微调成端到端低层 VLA：输入图像与指令，输出关节动作。这条路在机械臂操作上已有成功案例，但在腿足导航上代价很大：低层动作样本昂贵、不同机器人关节配置不同、每次换平台都要重训，而且把自然语言推理与毫秒级平衡控制压进同一个模型，容易两头都不稳。

NaVILA 选择两级结构。高层视觉语言模型（基于 VILA 的图像式 VLM）输出「带空间信息的语言中层动作」，例如 move forward 75cm 或 turn right 30 degrees；低层视觉运动策略（visual locomotion policy）以强化学习训练，读取本体感受与激光雷达高度图，把命令换算成速度指令并跟踪为关节位置。这样做的收益有三点：低层策略可替换，同一 VLA 跨机器人复用；中层动作是自然语言，训练数据可扩展到人类游玩视频与问答数据；高层低频推理、低层高频控制，各自在合适的时间尺度工作。本讲按「两级形式化、数据与低层策略、评测、设计取舍、边界」展开。

核心原理

本节把两级结构形式化，给出中层动作到执行的换算、频率账、数据管线与各层评测数字。数字均来自 Cheng 等 2024（NaVILA，arXiv:2412.04453v2）。

1. 两级形式化与中层动作词表

系统由两个策略组成。高层把指令 I 与历史帧 ot−K:t 映射为语言中层动作 m；低层把本体感受 p、高度图 h 与 m 映射为关节目标 qd：

mt = πhigh(I, ot−K:t)，m ∈ {"forward d cm", "turn left/right θ°", "stop"}；qd = πlow(pt, ht, mt)，qd ∈ R12 d 取 25 / 50 / 75 厘米，θ 取 30 度；K 为历史帧数（实验覆盖 8 至 64）

低层把所有命令折算成两组速度：前进 0.5 米/秒，转向 π/6 弧度/秒（即 30 度/秒），停止为零速度，再按命令中的空间量设置执行时长。换算如下：

中层动作速度映射执行时长
forward 25 cm0.5 米/秒0.50 秒
forward 50 cm0.5 米/秒1.00 秒
forward 75 cm0.5 米/秒1.50 秒
turn left/right 30°±30 度/秒1.00 秒

用语言表达动作的好处是实现无关：低层策略换成另一个平台时，中层词表与 VLA 权重都不变。两级结构的接口稳定性来自「语言描述空间量」这一约定：既不像离散动作那样绑定机器人，也不像速度指令那样要求 VLM 掌握控制细节。

2. 时间尺度：两级频率账

高层是图像式 VLM，计算量大、单次推理慢；低层策略要在平衡与避障的毫秒尺度运行。两级不要求频率相同，关键量是推理延迟与动作执行时长的比值。以延迟 1.0 秒为例：执行 forward 75 cm 需 1.50 秒，比值 0.67，下一次推理可以在本轮执行期间完成；执行 forward 25 cm 只需 0.50 秒，比值 2.00，执行完必须等待推理。可见中层动作的空间量决定执行窗口，短动作会放大延迟影响。把三层延迟与两种距离的组合算出来：

单次 VLA 延迟执行 25 cm（0.50 秒）比值执行 75 cm（1.50 秒）比值闭环表现
0.5 秒1.000.33短动作恰好不等待，长动作有充足余量
1.0 秒2.000.67短动作会周期性停顿或盲走
1.5 秒3.001.00只有长动作可连续，短动作不可用

这解释了两级设计里两个看似细节的旋钮：为什么中层前进量要合并到 75 厘米（拉长执行窗口），以及为什么低层要独立处理避障与平衡（高延迟期间机器人仍要安全）。两级方案的质量上限由「高层决策正确率」与「低层命令跟踪精度」共同决定，任何一级的误差都会在另一级放大。

3. 训练数据管线

高层 VLA 的数据分四类。第一类来自真实人类视频：2K 条 YouTube 自我中心游览视频，经熵采样得到 20K 条代表性轨迹，用 MASt3R 估计相机位姿以还原逐步动作，再用 VLM 描述加语言模型改写生成指令。论文报告，这是首个直接用人类视频训练连续环境导航的工作；消融显示，加入人类视频后模型在户外复杂指令上的成功率从 0.00 提升到 0.83。第二类是仿真导航数据：R2R-CE 与 RxR-CE 用最短路跟随器生成动作序列。第三类是辅助导航数据：EnvDrop 增广指令、轨迹摘要任务、ScanQA 三维问答。第四类是通用 VQA 数据，用于保住开放世界理解。

动作标签层面有一个关键处理：把连续同向动作合并，最多 3 个。例如两个 25 厘米前进合成一个 50 厘米，三个合成 75 厘米，动作取值更丰富、序列更短、对低频动作的过拟合更弱。四类数据合起来训练一整轮，视觉编码器、投影器、语言模型全部解冻；推理时用正则表达式解析器抽取动作类型与参数，论文报告全部实验中的输出都能成功匹配到动作词表。

4. 低层视觉运动策略

低层用单阶段强化学习训练，算法为 PPO。动作空间是 12 个关节的目标位置 qd（Go2 的 18 个自由度中，基座 6 个不受控，腿 12 个受控），由刚度与阻尼系数转换成力矩。演员只接收真实可得的传感器数据：本体感受历史（角速度、姿态、关节位置、关节速度、上一动作）与高度图；评论器额外接收特权地形扫描以估计价值。高度图来自激光雷达点云：每格取范围内最低点作为可通行地表，再对最近 5 帧做逐格最大滤波以抑制瞬时噪声。传感器选激光雷达的原因是对透明物体与强阳光更稳健，深度相机与 RGB 在这两类场景会失效。训练在 Isaac Lab（Isaac Sim 的机器人学习框架）内进行，论文报告在 RTX 4090 上达到每秒 6 万帧以上的采样吞吐。

6. 边界与失效模式

  • 高延迟与长上下文成本：图像式 VLM 计算量大，论文把长上下文语言模型列为缓解放向；高层延迟直接限制短动作的可用性。
  • 平台尺寸与视角差：相机高度、倾角随平台变化，论文展示不重训迁移，但 H1 成功率明显低于 Go2，说明形态差异仍造成损失。
  • 仿真与腿足可行性差距：Habitat 允许 10 厘米级的缝隙，腿足机器人无法通过；直接沿用 Habitat 成功率会高估实际能力，VLN-CE-Isaac 的筛选与低层物理正是为补这个差。
  • 真实失败样本存在：论文在附录列出真机失败案例，包括复杂光照与拥挤场景；88% 的成功率对应 75 次试验中的部分失败，不应当作通用保证。
  • 中层词表是固定集：动作固定为前进三档、左右转向与停止，不支持后退、斜向、爬楼梯等指令；超出词表的意图会落到最近邻动作或被停止兜底。

实现思路与设计

两级方案的设计空间集中在四个接口：中层动作词表、速度与时长映射、数据配方、低层观测。四个接口确定后，高层与低层可以独立迭代。

方案对比与选择判据

方案高层输出训练数据需求跨平台适用条件
端到端低层 VLA关节动作大规模带动作标注的机器人数据差，换机重训单一平台、控制频率可控、数据充足
技能库加语言控制器技能名既有技能库与选择标注较好动作可枚举、技能覆盖任务
两级语言中层动作（NaVILA）带空间量的语言仿真轨迹 + 人类视频 + 问答好，换低层策略即可需要指令泛化与多平台，能接受两级标定成本

选择判据：当任务需要复杂指令理解与跨平台部署时，两级结构的总成本更低；当任务对毫秒级反应且动作空间封闭时，端到端更直接。NaVILA 的证据是：单目 RGB、无路点预测器条件下 R2R-CE SR 54.0、RxR-CE SR 49.3，跨数据集 RxR SR 34.3，同时真机 88%。

中层动作写进自然语言后，高层可以用人类视频与问答数据训练，低层可以独立吸收平台差异；执行时长由空间量与固定速度换算，频率账在接口层可计算。两级分工的判据是：语义与目标归高层，稳定性与安全性归低层；把两者压进同一模型会让训练数据与控制频率互相牵制。

与第 089 讲的分工：089 的统一格式把任务差异收敛为指令差异，动作仍是 25 厘米/30 度的离散低层动作；090 把动作提升为带量纲的语言，插入可替换的低层闭环。两讲共同点是「语言当接口」，差别在接口所处的抽象层级。

关键代码与解读

三段示意代码分别处理命令解析执行、数据侧动作合并与重平衡、低层高度图与观测构建。接口为通用写法，可接入 Isaac Lab 或自建仿真。

片段 1：中层命令的解析与执行

import re
import math

FWD_SPEED = 0.5            # 米/秒
TURN_SPEED = math.pi / 6   # 弧度/秒，等于 30 度/秒

def parse_mid_action(text):
    """把语言中层动作解析为 (类型, 数量)；数量带单位制。"""
    m = re.search(r"forward\s+(\d+)\s*cm", text)
    if m:
        dist = min(max(int(m.group(1)), 25), 75) / 100.0   # 限制到 25~75 厘米
        return ("forward", dist)
    m = re.search(r"turn\s+(left|right)\s+(\d+)", text)
    if m:
        sign = 1.0 if m.group(1) == "left" else -1.0
        ang = math.radians(min(max(int(m.group(2)), 15), 60))
        return ("turn", sign * ang)
    if "stop" in text:
        return ("stop", 0.0)
    raise ValueError(f"unparsed mid-level action: {text}")

def execute(cmd, policy):
    """换算时长并下发速度命令；返回本命令应占用的执行秒数。"""
    kind, val = cmd
    if kind == "stop":
        policy.command(0.0, 0.0)
        return 0.0
    if kind == "forward":
        policy.command(FWD_SPEED, 0.0)
        return val / FWD_SPEED              # 75 厘米 -> 1.50 秒
    policy.command(0.0, val)
    return abs(val) / TURN_SPEED            # 30 度 -> 1.00 秒

解读：（1）解析失败直接抛出异常，不做最近动作猜测；推理侧捕获后回退为停止，避免错误命令被低层执行。（2）数值裁剪保证超出词表的输出（如 forward 200cm）回到安全范围，同时保留模型细调空间量级的能力。（3）执行时长由速度常量换算，两级之间的时间预算在这个函数里闭合。

片段 2：连续动作合并与停止类重平衡

def merge_actions(seq, cap=3):
    """合并连续同向前进，最多 cap 个；得到 25 / 50 / 75 厘米三档。"""
    out, i = [], 0
    while i < len(seq):
        kind, val = seq[i]
        if kind == "forward" and abs(val - 0.25) < 1e-9:
            j = i
            while (j < len(seq) and seq[j][0] == "forward"
                   and abs(seq[j][1] - 0.25) < 1e-9 and j - i < cap):
                j += 1
            out.append(("forward", 0.25 * (j - i)))
            i = j
        else:
            out.append(seq[i])
            i += 1
    return out

def rebalance(samples, power=0.5):
    """按类别频次的反幂采样权重，缓解停止样本稀少导致的漏停。"""
    counts = {}
    for s in samples:
        counts[s["label"]] = counts.get(s["label"], 0) + 1
    weights = [1.0 / (counts[s["label"]] ** power) for s in samples]
    return weights

解读：（1）合并上限 3 把动作序列压到三分之一，同时把动作取值从单一 25 厘米扩展为三档，缓解类别不平衡。（2）只合并严格连续的 25 厘米前进，转向与停止原样保留，防止把「走、转、走」错误合并成一次长走。（3）反幂重采样比硬性过采样温和，停止类权重上升但不至于主导梯度；power 是可调旋钮。

片段 3：LiDAR 高度图与低层观测

import numpy as np

def height_map(points, size=64, res=0.1, ceiling=2.0):
    """点云到 2.5D 高度图：每格取最低点作为可通行地表。"""
    hm = np.full((size, size), np.inf, dtype=np.float32)
    for x, y, z in points:
        r = int(x / res + size / 2)
        c = int(y / res + size / 2)
        if 0 <= r < size and 0 <= c < size and z > 0.0:
            hm[r, c] = min(hm[r, c], z)     # 格内最低点，保留地表，忽略障碍顶端
    hm[~np.isfinite(hm)] = ceiling          # 无回波格用上限填充
    return np.clip(hm, 0.0, ceiling)

class TemporalHeightFilter:
    """对最近 history 帧逐格取最大，抑制单帧噪声与瞬时遮挡。"""
    def __init__(self, history=5):
        self.buf, self.history = [], history

    def __call__(self, points):
        self.buf.append(height_map(points))
        self.buf = self.buf[-self.history:]
        return np.max(np.stack(self.buf), axis=0)

def actor_observation(proprio_hist, height, command):
    """演员输入：本体感受历史 + 高度图 + 速度命令；不含真值线速度。"""
    return {"proprio": proprio_hist, "height": height, "command": command}

解读：（1）每格取最低点的语义是「地表高度」，障碍物顶端会被更高处的地表比较掉，策略据此判断可通行性。（2）无回波格填上限，让策略学到「未知即潜在障碍」的保守行为；这是玻璃与强光场景稳健性的来源之一。（3）演员观测故意不含线速度，真实系统无法直接测量，用本体感受历史隐式推断，避免训练-部署不一致。

常见误区

  • 频率账未闭环：高层延迟 1.0 秒却大量下发 25 厘米短动作，机器人走走停停甚至盲走。根因是中层动作的空间量与推理延迟未对齐。修复：按「延迟 / 执行时长」比值设计词表，缩短推理或把最短动作限制在 50 厘米以上；执行期间用低层避障兜底。
  • 单位与解析错误：模型输出 forward 0.75m 或 turn 30deg 时解析失败，回退成长时间停留。根因是正则只覆盖厘米与角度写法。修复：多模板解析并统一换算到米与弧度；解析失败回退停止且上报；对数值范围裁剪。
  • 动作合并改变标签分布：合并后 75 厘米样本变多、停止样本依旧稀少，真机出现冲到目标附近不停。根因是合并只压缩了前进类。修复：合并后做停止类重平衡；评测时单列停止召回或 NE 分布，避免只看 SR。
  • 用深度相机做高度图：玻璃幕墙、强阳光与低纹理地面下高度图缺失，视觉策略退化为盲走。根因是传感器选型。修复：改用激光雷达点云；对无回波格填保守值；保留本体感受历史作为兜底。
  • 把 Habitat 成功率当作腿足能力：Habitat 允许 10 厘米缝隙，四足无法通过，仿真数字虚高。根因是评测平台不匹配。修复：使用 VLN-CE-Isaac 式带低层物理的基准，报告可通行轨迹筛选比例（1,077 / 1,839 = 58.56%）与盲走对照，跨平台迁移单独评测。

练习与思考

  1. 时长与频率核算：(a) 0.5 米/秒下 forward 50 cm 与 75 cm 各需多久；(b) 若把前进速度提到 1.0 米/秒，三档时长如何变化，延迟 1.0 秒时哪些动作会「等推理」；(c) 说明提速对停止精度与碰撞风险的影响。 ★
    提示
    (a) 1.00 秒与 1.50 秒。(b) 变为 0.25 / 0.50 / 0.75 秒，延迟 1.0 秒时三档比值分别为 4.00 / 2.00 / 1.33，全部需要等待或盲走。(c) 提速缩短执行窗口，高层反应时间占比上升，停止距离变长，窄道与人群场景碰撞风险增加；需要更低延迟或更保守的短动作下限。
  2. 绝对与相对提升：(a) R2R-CE SR 54.0 对 37.0 的绝对差与相对差；(b) 跨数据集 RxR SR 34.3 对 23.8 的两种差；(c) 解释论文「超过 17%」表述对应的口径。 ★
    提示
    (a) +17.0 个百分点，相对 +45.95%。(b) +10.5 个百分点，相对 +44.12%。(c) 「超过 17%」指绝对百分点差（54.0 减 37.0），不指相对提升；写作时应写明两种口径，避免读者混淆。
  3. 改超参预测：把历史帧从 64 降到 8，同时把动作合并上限从 3 提到 5。(a) 预测高层延迟与中层动作分布的变化；(b) 预测 VLN 与真机表现分别受什么影响；(c) 设计一个能区分两种改动各自贡献的对照实验。 ★★
    提示
    (a) 帧数减少显著降低高层序列长度与延迟；合并上限提高使 100 厘米以上长动作出现，但超出低层稳健执行范围的风险上升。(b) VLN 短指令可能持平、长指令与需要回看的场景下降；真机上长动作减少停顿但停止精度与避障裕度受影响。(c) 2×2 对照：{8, 64} 帧 × {3, 5} 合并上限，固定其他条件，分别看 SR、NE、每步延迟与碰撞率。
  4. 设计题：为坡道与楼梯场景扩展中层词表。要求给出 (a) 新增动作的形式与参数范围；(b) 低层策略需要补充的观测与奖励项；(c) 三档评测（仿真、Isaac 式物理仿真、真机）各自验证什么；(d) 一条安全回退规则。 ★★
    提示
    (a) 可新增 climb 与 descend，参数为落差高度（如 10 至 20 厘米）或坡度角。(b) 观测补足足端接触与俯仰角，奖励加入姿态稳定与足底打滑惩罚。(c) 仿真验证语义与指令解析，Isaac 验证关节级可行性与碰撞，真机验证传感器噪声与安全性。(d) 坡度或落差超范围时拒绝执行并回退停止，同时上报高层。
  5. 复现设计（★★★）：把两级管线迁移到一台新腿足平台。要求 (a) 写出中层词表与速度映射表；(b) 给出低层训练的最小配方（仿真环境、观测、奖励、评测指标）；(c) 设计「高层零样本迁移 + 低层新训」与「整体重训」的对照；(d) 列出最可能失败的三个环节与对应的早期信号。 ★★★
    提示
    (a) 沿用 25/50/75 厘米与 ±30 度，按平台步态调整速度常量并重算时长。(b) PPO 单阶段；观测为本体感受历史加 LiDAR 高度图；奖励含速度跟踪、姿态、能耗与碰撞惩罚；指标为线速度误差、角速度误差与碰撞率。(c) 对照条件：同一高层权重分别接新旧低层策略，比较端到端 SR 与命令跟踪误差；整体重训作为上界。(d) 常见失败：相机高度变化导致高层语义漂移（信号为解析失败率与停止位置误差上升）、高度图分辨率不匹配（碰撞率上升）、停止类样本不足（超调）；先在仿真闭环里逐项定位。

小结

  • NaVILA 用两级结构解决腿足 VLN：高层 VLM 输出带空间量的语言中层动作（forward 25/50/75 cm、turn ±30°、stop），低层视觉运动 PPO 策略把命令换算成速度并跟踪为 12 个关节的目标位置。
  • 频率账是设计核心：0.5 米/秒与 30 度/秒下 75 厘米需 1.50 秒、30 度需 1.00 秒；延迟 1.0 秒时短动作比值 2.00，会周期性等待，长动作比值 0.67，可连续执行。
  • 数据管线用 2K 人类游览视频生成 20K 轨迹，合并连续动作（上限 3 个）并重平衡停止类；人类视频把户外复杂指令成功率从 0.00 提升到 0.83。
  • 结果：R2R-CE val-unseen SR 54.0 / SPL 49.0，RxR-CE SR 49.3 / SPL 44.0，跨数据集 RxR SR 34.3；VLN-CE-Isaac 上视觉策略对盲走 +14.0（Go2）与 +20.9（H1）个百分点；真机 75 次试验整体成功率 88%。
