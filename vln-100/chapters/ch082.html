第 082 讲｜NavGPT：纯 LLM 零样本推理

NavGPT（Zhou、Hong、Wu 2023，arXiv:2305.16986v3）把文本接口推到极限：不训练任何参数，把 24 个视角的描述、物体与深度、导航历史与系统规则拼成提示词，让 GPT-4 每步输出推理痕迹与下一个视角编号。R2R val-unseen 零样本 SR 34、SPL 29、NE 6.46，与训练方法差距约一倍，但推理过程可读、可分解、可纠错。本讲拆开它的四个输入、token 预算与失败模式。

  • 主题：文本接口 / 零样本推理 / 提示词工程 / token 预算
  • 关键数字：SR 34 对 72（达 47.22%）、24 视角、单步提示词 2,040 token、深度通道 +0.70 SR
  • 预计学时：60 分钟
  • 前置讲：第 081 讲（范式转移）

学习目标

  • 会算：零样本与训练方法的 SR、NE、SPL、OSR 间距；消融表逐项增益；逐步提示词 token 与上下文越限步数。
  • 会解释：NavGPT 决策式四个输入的职责、ReAct 式思维与动作的协同机制、24 视角几何与 3 米过滤的作用。
  • 会实现：观察转文本、提示词组装、输出解析与历史摘要四段示意代码。
  • 会判断：按消融表选择视角粒度与观察通道；把失败现象归因到描述损耗、摘要磨损、编号幻觉或距离盲区。
  • 会设计：一个受预算约束的提示词改进实验，并给出与训练方法的协议对照口径。

背景与动机

第 081 讲的文本接口买的是推理与解释能力，NavGPT 是这一接口的极端实现：系统不含任何可训练模块，全部行为来自现成大模型与提示词组织；执行的是 R2R 离散导航图上的零样本序列动作预测。论文要回答的问题直接指向能力边界：大模型能否在文本形式下理解交互世界、动作与后果，并据此完成导航。

在 VLN 方法谱系里，NavGPT 的位置独特。此前用 LLM 的工作多把模型当解析器或常识库（例如抽取地标、补充物体关系），决策仍由训练好的策略完成；NavGPT 把决策本身交给 LLM，推理痕迹进入历史，下一步能看到上一步的思考。论文报告定性能力包括：把指令分解为子目标、引入导航常识、从观察中识别地标、跟踪进度、异常时调整计划；还能根据历史重新生成指令与俯视轨迹。定量上，零样本 R2R val-unseen 成功率 34，低于同表训练方法的 72，作者把瓶颈归于视觉转语言的精度与历史摘要的信息损耗，并建议用多模态输入与显式推理反哺训练模型。

本讲的价值不在复现一套提示词，而在把「无训练系统」的账算清楚：每步调用多少次模型、提示词会长到多少、哪些信息在转写与摘要中丢失、失败集中在哪里。这些账与第 081 讲的接口预算、第 079 讲的协议口径完全兼容，是评估后续所有 LLM 导航智能体的基础。

核心原理

本节按「任务形式化、决策式与输入、思维与动作、视觉感知、历史管理、实验与消融、失败模式」七步展开，数字均来自 arXiv:2305.16986v3 与课程约定口径。

1. 任务形式化

指令为词序列 W = {w1, w2, …, wn}；第 t 步智能体位于导航图节点，观察 Ot 包含若干视角，候选集合 Ct+1 的元素个数记为 M = |Ct+1|，每个候选带相对角度 aiC。状态 st = (vt, θt, φt)，v 为节点位置，θ 与 φ 分别为朝向角与俯仰角。策略写作：

π(at | W, Ot, OtC, St; Θ) OtC 为候选观察；St 为状态转移；与第 081 讲通用式一致，区别在 Θ 不来自 VLN 训练，而来自大模型的语言语料

零样本口径下，智能体对 R2R 的每条轨迹都是全新任务；动作空间限定在导航图上，输出为候选编号，不允许移动到不存在的节点。R2R 共 7,189 条轨迹，训练、val-seen、val-unseen、test-unseen 场景数为 61、56、11、18，全部实验在 val-unseen 的 11 个场景 783 条轨迹上进行。

2. 决策式：四个输入与提示词管理器

NavGPT 每步输出的推理痕迹 Rt+1 与动作 At+1 由四类输入经提示词管理器 M 组织后交给 LLM：

⟨Rt+1, At+1⟩ = LLM( M(P), M(W), M(F(Ot)), M(H<t+1) ) P 为导航系统规则，W 为指令，F 为视觉基础模型转写，H 为历史三元组序列；M 负责统一为自然语言（论文式 (1)）

四类输入的职责分别是：系统规则声明任务定义、输出格式与「不得编造编号」的约束；指令原文全文进入；视觉转写把图像变成描述、物体与深度；历史 H<t+1 = [⟨O1, R1, A1⟩, …, ⟨Ot, Rt, At⟩] 记录观察、推理与动作三元组。提示词管理器是系统的可替换部件：模型不变，输入的序列化方式一变，行为随之改变，这一性质决定了后续所有消融实验都以输入组织为变量。

3. 思维与动作的协同

NavGPT 沿用 ReAct 的思路把动作空间扩为 Ã = A ∪ R，R 取值于全部语言空间，输出思维不触发环境交互。思维痕迹有两个作用：其一，先思考再动作，使 LLM 能在指令分解与策略制定上做高层规划；其二，推理痕迹写入历史，后续步骤继承前一步的规划，保持跨步一致并支持异常调整。把推理放进历史相当于把隐式状态显式化，这也是系统可解释性的来源：错误可以定位到某一步的具体判断。

4. 视觉感知器：24 视角、物体与深度

视觉转写按固定几何切分。水平方向以 45 度视场角、45 度间隔取 8 个朝向（0 至 360 度）；俯仰方向以 30 度间隔取 3 层，覆盖水平线上下各 30 度，层间重叠 15 度，总跨度 60 度；8 × 3 = 24 张自我中心视角图。每张图由 BLIP-2（ViT-G 加 FlanT5-XL）生成描述，俯仰三层由 GPT-3.5 汇总为一句。

除描述外，Faster R-CNN 检测物体边界框，取中心像素深度，计算相对朝向，仅保留距当前节点 3 米以内的物体；结果由提示词管理器并入当前观察。24 视角与 3 米过滤是精度与预算的折中：视角更密会放大描述冗余，过滤更远会引入识别噪声，065 与 079 讲的剂量与协议思路在这里以工程参数形式出现。

5. 历史管理与 token 增长

历史缓冲直接拼入提示词会让长度随步数线性增长，管理器用 GPT-3.5 将旧观察摘要后写回三元组。按课程假设做账：单步提示词 = 系统规则 250 + 指令 50 + 候选列表 80 + 24 条描述 × 30 = 720 + 物体 60 + 历史 8 段 × 110 = 880，合计 2,040 token；10 步累计 20,400 token，另有输出约 800 token。若不做摘要、把原始描述逐步重复送入，则第 t 步提示词约为 800t + 360 token：单步在 t = 1 为 1,160，t = 10 为 8,360；4,096、8,192、32,768 三档窗口分别在 t = 5、10、41 被越过；10 步累计 47,600 token，为摘要口径 20,400 的 2.333 倍。摘要器把每步提示词从线性增长压回常数级，代价是旧观察的信息不可逆损失，这一取舍是后文失败模式的主要来源之一。

7. 失败模式

  • 描述损耗：指令中的目标若未出现在任何视角描述中，系统只能被动探索；论文归因于图像转文本的精度上限与模型对物体的跟踪能力不足。
  • 摘要磨损：历史越长，摘要损失越多，全程感知不再完整，进度跟踪变差；这是第 5 节 token 账的直接代价。
  • 距离盲区与提前停止：目标一旦进入视野，智能体常立即停止；加入深度后 SR +0.70、SPL +1.29，验证了该现象。
  • 编号幻觉与解析失败：模型可能输出不存在的视角编号，需要解析层拦截；系统规则虽禁止编造编号，规则约束不足以替代硬校验。
  • 协议与版本漂移：结果依赖具体模型快照与提示词版本；论文在指令生成实验中特意不把推理痕迹放入输入以避免信息泄漏，提示词内容本身也是泄漏面（第 074、081 讲口径）。

设计决策与替代方案

  • 逐视角描述对全景单描述：逐视角保留方向局部性，24 次调用代价高；全景单描述省调用但易泛化房间级语句。消融的粒度结论支持 45 度、24 视角作为默认折中。
  • 每步摘要对按需摘要：论文用摘要器控制长度；另一方案是保留最近 k 段原文、仅对更早内容摘要。后者保留近期细节，适合对精确动作敏感的任务，本课建议窗口 8 段加溢出摘要作为对照起点。
  • 自由生成对约束解码：动作编号必须属于候选集合。解析层做硬校验，失败重试一次后再回退；不能把合法性寄托于系统规则文字。
  • 温度取值：复现导向时置零并记录快照；需要多方案探索时改为多次采样加投票，并把调用次数写入预算。

与相邻讲的分工：本讲是纯零样本极限；083 讲 NavGPT-2 冻结 LLM 加策略网络，把视觉语言表示接回可训练策略；084 讲把地图引入提示词；086 讲把思维链变成训练目标。

关键代码与解读

四段代码对应观察转文本、提示词组装、输出解析与历史摘要，均为以论文公开设计为参照的示意实现。

片段 1：24 视角描述与物体过滤

VIEW_FOV = 45                       # 水平视场角，消融结论支持 45 度
HEADINGS = range(0, 360, 45)        # 8 个朝向
ELEVATIONS = (30, 0, -30)           # 3 层俯仰，层间重叠 15 度

def describe_viewpoint(panorama, captioner, detect, depth_of):
    """把当前节点转成视角描述与 3 米内物体列表；共 24 次描述调用。"""
    views = []
    for elev in ELEVATIONS:
        for heading in HEADINGS:
            img = panorama.crop(heading=heading, elevation=elev, fov=VIEW_FOV)
            cap = captioner.generate(img, max_new_tokens=30)
            views.append((heading, elev, cap))
    objects = []
    for box in detect(panorama.front_view()):
        d = depth_of(box.center_pixel)          # 中心像素深度
        if d <= 3.0:                             # 3 米过滤：压缩列表降噪
            objects.append((box.cls, box.relative_heading, round(d, 2)))
    return serialize_views(views), serialize_objects(objects)

解读：（1）几何常量与消融表一致，改成 30 度或 60 度即可复现粒度实验。（2）物体三要素（类别、相对朝向、距离）与论文的检测加深度设计对应，深度取中心像素。（3）3 米阈值是工程折中：列表越短提示词越省，太短会把远处地标一并滤掉，建议按场景尺度重标定。

片段 2：提示词组装与预算护栏

def build_prompt(principle, instruction, views, objects, history, max_tokens):
    """按规则、指令、观察、历史顺序合并；历史从新到旧装填。"""
    blocks = [principle, "Instruction: " + instruction,
              "Observation: " + views, "Objects: " + objects]
    used = count_tokens(blocks)
    for triple in reversed(history):        # 新历史优先保留
        block = serialize_triple(triple)    # (观察摘要, 推理, 动作)
        if used + count_tokens(block) > max_tokens:
            break                           # 超预算即停，不截断半句
        blocks.append(block)
        used += count_tokens(block)
    return "\n".join(blocks), used
# 参考账：单步约 2,040 token；若把原始描述逐步重复，第 10 步为 8,360

解读：（1）顺序即先验：系统规则在最前稳定行为，历史从新到旧装填保证近期信息优先。（2）预算护栏按块判断，避免把三元组切成半句话；超限时丢弃的是最旧历史，与摘要器职责衔接。（3）函数返回实际使用量，调用方可以把 token 数写进决策记录，供第 081 讲的预算字段复用。

片段 3：输出解析与编号硬校验

import re

def parse_thought_action(text, valid_ids):
    """抽取推理与动作；编号不在候选集合时返回 None，触发重试或兜底。"""
    parts = text.split("Action:", 1)
    thought = parts[0].strip()
    if len(parts) != 2:
        return None, None
    m = re.search(r"viewpoint\s+(\d+)", parts[1])
    if m is None:
        return None, None
    vid = int(m.group(1))
    if vid not in valid_ids:                # 幻觉编号：拒绝，不猜测
        return None, None
    return thought, vid
# 注意：系统规则里的禁止编造文字不能替代这里的一次集合判断

解读：（1）解析是行为边界：任何不合法输出都返回空值，由上层决定重试或回退，绝不让越界编号进入执行器。（2）推理痕迹单独取出并写入历史，是 ReAct 协同机制落地的位置。（3）正则只认受控格式，减少自由文本歧义；格式偏离属于可以统计的解析失败率。

片段 4：历史缓冲与摘要

def update_buffer(buffer, obs, thought, action, summarizer, max_len=8):
    """追加三元组；溢出时把最旧观察与相邻观察合并摘要，保持常数级长度。"""
    buffer.append({"obs": obs, "thought": thought, "action": action})
    if len(buffer) > max_len:
        old = buffer.pop(0)
        merged = old["obs"] + "; " + buffer[0]["obs"]
        buffer[0]["obs"] = summarizer(merged, max_new_tokens=40)
    return buffer
# 摘要损耗不可避免：近期保留原文、远期摘要，是精度与 token 的折中

解读：（1）窗口 8 段对应第 5 节 token 账的 880 token 历史块，数值来自预算反推。（2）摘要只压缩观察文本，动作与推理保留原文，保证进度与规划信息不被二次损失。（3）摘要器版本与提示词模板要随系统快照登记，否则跨月复现的实验会因摘要措辞漂移。

常见坑

  • 把零样本数字与训练方法同榜比较：用 SR 34 对 72 得出「LLM 导航能力不足」或「文本接口不可行」。根因是训练口径不同，按第 079 讲属不可比。修复：标注「无训练对预训练加微调」，只读量级与推理能力，排名需求另设同预算消融。
  • 描述目标缺失时无限探索：指令地标未出现在任何描述中，智能体在环境中反复游走。根因是视觉转文本的单通道损耗。修复：加入物体检测与深度通道（消融显示 SR +4.86 与 +0.70）；对关键目标增加开放词汇检测或近景复检。
  • 历史摘要吃掉进度：长轨迹后系统忘记已走路径，回程与剩余距离判断失败。根因是摘要不可逆压缩。修复：近期保留原文、远期摘要；窗口与摘要频率作为超参消融；把进度字段单独保留在状态块中。
  • 放任编号自由生成：解析器接受任意整数，执行器报节点不存在。根因是缺少候选集合硬校验。修复：解析层做集合判断，失败重试一次后回退；统计越界率作为接口健康指标。
  • 距离盲区导致提前停止：目标刚进入视野就停止，SR 尚可但 SPL 低。根因是提示词中没有距离信息。修复：物体列表附中心像素深度；把「距目标多远」写进推理要求，消融增益为 SR +0.70、SPL +1.29。

    提示
    (A) 历史摘要磨损导致进度丢失；低成本修复为保留近期原文，架构级为外置拓扑记忆。(B) 距离盲区，缺深度信息；加深度通道，架构级为显式停止判定模块。(C) 编号幻觉，解析层硬校验，架构级为约束解码或候选编号重映射。回答 (c)：目标已进入描述说明识别成功，缺口是「还有多远」的量化信息，归因指向距离通道，与识别环节无关。

    提示
    (a) 系统 300、指令 50、观察 750（24×30 加余量）、物体 80、历史 600（近期原文加摘要）、进度 100，留 620 余量。(b) 示例：把目标描述提前到观察块首、进度块显式写剩余距离、历史窗口从 8 段缩到 6 段换原文；预测 OSR 上升、SPL 上升、SR 中性。(c) 每处改动单独上线的对照实验，固定其余块与模型快照。(d) 必填 split、步数上限、停止判定、解码、运行次数、集成、探索预算、地图先验、语料、模型选择、指标定义、算力；34 属零样本、72 属预训练加微调，直接比较只会把两种口径混成一条错误基线。

小结

  • NavGPT 把文本接口推到零样本极限：无任何可训练模块，决策式为四类输入（系统规则、指令、视觉转写、历史）经提示词管理器交给 LLM，输出推理痕迹与候选编号。
  • 视觉感知器以 45 度视场、8 朝向、3 层俯仰构成 24 视角，BLIP-2 逐视角描述，Faster R-CNN 加中心深度并做 3 米过滤；思维痕迹进入历史，承担跨步规划与异常调整。
  • 主结果（R2R val-unseen，GPT-4）：SR 34、SPL 29、NE 6.46、OSR 42，对 DuET 72 / 60 / 3.31 / 81 分别达到 47.22%、48.33%、NE 高出 95.17%、51.85%；783 条轨迹折算成功约 266 对 564 条；该比较按协议属不可比，只读量级。
  • 消融结论：24 视角 SR 16.67，比 12 视角高 6.48、比 36 视角高 2.78；加物体 SR +4.86，加深度再 +0.70、SPL +1.29；两项合计把 SR 从 11.11 提到 16.67，相对 50.05%。
  • token 账：单步提示词约 2,040 token，10 步约 20,400；不做摘要时第 10 步 8,360、累计 47,600，为摘要口径 2.333 倍；4,096、8,192、32,768 窗口的越界步数为 5、10、41。
  • 失败集中于描述损耗、摘要磨损、编号幻觉与距离盲区；下一讲 NavGPT-2 用冻结 LLM 加策略网络缩小与专用方法的差距，把本讲的推理能力接入可训练策略（第 083 讲）。
