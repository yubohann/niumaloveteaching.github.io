第一篇 · 任务、数据、仿真与评测地基

第 008 讲｜R4R 与 CLS：路径保真

本讲把评测标尺从「是否到达终点」推进到「是否按指令描述的走法到达」：先论证 SR、SPL 对中间路径的盲区，再完整推导覆盖度加权长度分 CLS（Coverage weighted by Length Score），给出可手算的图例与实现接口；后半段拆解 R4R 的路径拼接协议，并用复现实验说明把 CLS 写进奖励后语言依赖的可测变化（Jain 等，2019，ACL）。

  • 主题：评测指标 / 路径保真 / R4R 数据构造 / 保真奖励
  • 关键公式：CLS = PC · LS；PC = (1/|R|) · Σ exp(−d(r,P)/dth)
  • 预计学时：60 分钟
  • 前置讲：第 007 讲（指标 II：SPL、OSR 与统计口径）

学习目标

  • 会写：给出 CLS 的三个组成部分 PC、EPL、LS 的定义与适用条件，说明衰减尺度 dth 在 R2R 口径下的取值（Jain 等，2019，R4R 工作）。
  • 会算：在 6 节点小图上手算四条轨迹的 PC、EPL、LS、CLS，并与 SR、SPL 对照，指出三者对同一条轨迹结论分歧的位置。
  • 会实现：图距离预计算与 CLS 评分的核心片段，能接入 R2R / R4R 的评测循环并做正确性断言。
  • 会判断：给定「SR 高而 CLS 低」的样例，定位到哪一段路径偏离造成了覆盖损失。
  • 会设计：按 R4R 拼接规则生成扩展路径，说明拼接阈值对扩展路径数量与难度分布的影响。

背景与动机

第 006、007 两讲把 NE、TL、SR、SPL、OSR 的口径与边界用例讲完了。这一套指标回答同一个问题：「最终停在目标附近了吗，路径是否利落」。它们对中间过程几乎不设约束：R2R 的参考路径全部由最短路径采样产生，终点相同即视为任务完成。于是出现一种被论文点名的结构性偏差：智能体只要猜中终点，哪怕一路抄近道、跳过指令描述的转弯与门厅，也能拿到很高的 SR 与 SPL（Jain 等，2019）。

论文用一组对照说明问题的量级：在同一个起点与终点之间，一条「直奔目标」的红色轨迹与一条「沿描述绕行」的橙色轨迹相比，前者 SPL 拿到 1.0、CLS 仅 0.23，后者 SPL 仅 0.17、CLS 达 0.87（Jain 等，2019，图 1）。两个指标给出方向相反的判断，分歧来自测量对象：SPL 只看终点与总长度，CLS 看整条参考路径是否被覆盖。

测量对象一旦不同，训练激励也会分化。论文的另一条证据更直接：用 R2R 训练、在 R4R 上评测时，目标导向奖励的智能体在只给指令最后 5 个词与给全句两种条件下，CLS 都是 20.4；保真导向奖励的智能体从 34.6 降到 25.3（Jain 等，2019，表 4）。前者对指令中段不敏感，说明它学到的主要是「去哪儿」，后者才在被指标逼迫之后开始依赖「怎么走」。

本讲要完成三件事：第一，把 CLS 的推导与实现讲透，能独立复算；第二，讲清 R4R 的拼接规则与统计口径，理解为什么长而曲折的参考路径能把保真问题暴露出来；第三，把「指标改动如何改变训练出的智能体」这条实验证据整理成可复用的消融模板。评测协议版本说明：本讲数字均出自 R2R / R4R 原论文及 ACL 2019 版本，步数口径与离散导航图协议，与第 004 讲一致。

核心原理

1. 为什么现有指标看不见「半路走岔」

先把问题形式化。设参考路径 R = (r1, r2, …, r|R|)，预测路径 P = (p1, p2, …, p|P|)，两者都以导航图节点表示，p1 = r1。距离 d(n, m) 为图上的最短路径长度，d(n, P) = minp∈P d(n, p) 为节点到路径的最近距离。SR 只检查 d(p|P|, r|R|) 是否小于 3 m；NE 只看这对终点；SPL 在成功的前提下再乘一个长度效率因子，而该因子的分母是起点到终点的最短距离，对中途绕行不敏感。三者共同性质是：分数只依赖 P 的末端与总长度，对 P 的中间节点不敏感。

把「保真」写成可检验的要求，论文给出五条判据（Jain 等，2019，3.1 节），本课程整理为下表。这五条同时是阅读后续任何路径级指标的检查单。

判据要求SPL 的满足情况
路径相似性分数依赖 P 与 R 的全部节点，偏离参考路径应受惩罚不满足：只看终点
软惩罚差异按图距离连续衰减，偏离越远扣得越多不适用：成功为二值判定
唯一最优P 与 R 完全一致时得满分，其他路径不得达到同一分数不满足：多条等长最短路可同分
尺度不变不同数据集、不同图规模下口径一致满足：长度比无量纲
可计算可在多项式时间内批量评测满足

这五条中，「路径相似性」与「软惩罚」是 CLS 的设计核心：参考路径的每一个节点都要被预测路径「够到」，够不到的程度按图距离指数衰减；同时预测路径的长度要与它实际覆盖的比例相称，绕远与抄近都要扣分。

2. CLS 的定义与逐项推导

CLS 是路径覆盖分 PC 与长度分 LS 的乘积：

CLS(P, R) = PC(P, R) · LS(P, R) 取值范围 (0, 1]；P 与 R 完全一致时为 1

路径覆盖分衡量参考路径被预测路径覆盖的程度，对 R 的每个节点计算「到 P 的最近图距离」，做指数衰减后取平均：

PC(P, R) = (1 / |R|) · Σr∈R exp( − d(r, P) / dth ) d(r, P) = minp∈P d(r, p)；dth 为衰减尺度，R2R / R4R 口径取 3 m，与本任务的 3 m 成功阈值一致（Jain 等，2019，3.3 节）

衰减尺度同时承担归一化职责：距离为 dth 的节点贡献 e−1 ≈ 0.3679，距离为 2dth 的节点贡献 0.1353。dth 使指标对图的绝对尺度不敏感，这是判据「尺度不变」的来源。注意 PC 与「命中比例」的离散版本不同：软惩罚让「擦边」与「远离」得到不同分数，论文用软惩罚这一判据明确要求这种连续性。

长度分把预测路径长度 PL(P) 与「覆盖对应的期望最优长度」EPL 比较。若 PC = 0.5，说明只覆盖了参考路径的一半，那么合理的预测长度也应为参考长度的一半量级：

EPL(P, R) = PC(P, R) · PL(R)，PL(·) 为相邻节点图距离之和 PL(R) 为参考路径总长；EPL 是随覆盖度自适应的长度基准
LS(P, R) = EPL(P, R) / ( EPL(P, R) + | EPL(P, R) − PL(P) | ) PL(P) = EPL 时 LS = 1；偏差在分子分母中同步出现，抄近道与绕远路得到对称惩罚，取值范围 (0, 1]

把三段合起来读：PC 回答「该走的地方走了多少」，LS 回答「走这段路花了多少多余或过少的里程」，乘积同时约束覆盖与效率。与 SPL 的结构对照可以看出设计意图：SPL 的第一项是二值成功，第二项用起点到终点的最短距离归一化；CLS 把第一项换成连续的 PC，把第二项换成随覆盖度自适应的 EPL。这样，终点相同、中途不同的两条轨迹会被强烈区分开。

适用条件有三条，写作实验记录时应一并标注：其一，距离沿导航图边计算，使用欧氏直线距离会让「穿墙」路径被高估；其二，参考路径无环且 p1 = r1 时，论文证明满分当且仅当两路径完全一致（唯一最优判据）；参考路径含环时该性质失效，R2R / R4R 的采样规则保证参考路径为最短路，通常无环；其三，dth 与成功阈值正相关，换任务（街道、空中）要重新核定衰减尺度。复杂度方面：全图最短路可离线预计算，单节点 Dijkstra 复杂度 O(E + V log V)，全部节点为 O(EV + V² log V)；记忆化之后，PC 单条 O(|P| · |R|)，LS 单条 O(|P| + |R|)，批量评测开销与 SPL 同量级。

逐行读：完全一致轨迹 CLS = 1；SR = 1 但 SPL 仅 0.667，因为本图中最短距离 8 m 比参考路径 12 m 短，忠实执行者在 SPL 下被「按捷径基准」扣了效率分。抄捷径轨迹 SR = 1、SPL = 1.000（8 m 走到终点即最短），CLS 只有 0.4946：参考节点 B、C、D 到捷径的距离分别为 3、6、3 m，覆盖贡献 0.3679、0.1353、0.3679，PC 被压到 0.5742，LS 再加一层长度错配惩罚。差一步停在 SR 与 SPL 上全失（NE = 3 m，未满足严格小于 3 m），CLS 仍有 0.7653，说明它走过了大部分参考路径；若实验只看 SR，这类「接近成功」的进展被完全抹掉。折返绕路覆盖不差（PC 0.7472），长度 14 m 远超 EPL 8.97，LS 降到 0.6404。

这四条轨迹给出本讲最重要的一组判断：CLS 与 SR / SPL 测量的内容几乎没有重叠，把它们成对报告才有信息量。尤其注意第二行与第三行的交叉：抄捷径者 SR 满分而 CLS 中等，差一步停者 SR 为零而 CLS 更高。训练时若把奖励绑定在 SR 上，优化的方向与「按指令走」并不一致。

4. CLS 的性质、边界与失效模式

从定义可以直接推出几条性质，它们决定 CLS 在新任务上的迁移方式。

  • 失败不归零。P 未选择停止或停在错误位置时，只要轨迹存在，CLS 仍可计算。这与 SPL 「失败记 0」的口径相反，好处是保留部分进展信号，代价是「拿 CLS 当成功率使用」会系统性高估完成度，报告时必须与 SR 并列。
  • 长度分对称。LS 对「比 EPL 短」与「比 EPL 长」采用同一惩罚函数。抄捷径的智能体在覆盖下降后 EPL 同步下降，LS 惩罚被部分抵消，因此抄捷径的主要损失来自 PC，LS 只做二次修正。这一细节影响调参：只盯 LS 看不出保真问题。
  • 满分条件依赖参考路径无环。若 R 含有重复节点，一条更短的 P 也能覆盖全部节点，唯一最优判据失效。R2R / R4R 参考路径由最短路径采样保证无环，合成数据（例如模板拼接）需要单独检查。
  • dth 的敏感性。dth 缩小会放大远处节点的惩罚（覆盖分更快趋近 0），增大则让偏离被宽恕。做跨环境对比实验时应固定 dth 并写明数值；本讲所有算例统一取 3 m。
  • 与 STOP 机制解耦。CLS 衡量轨迹保真，不衡量停止决策的质量；把 CLS 加进奖励时通常与成功项相加（论文奖励式 1[成功] + CLS），停止判定仍由成功项承担。

5. R4R：把参考路径从「直达」改为「曲折」

R2R 的结构偏差来自采样规则：所有参考路径都是起点到终点的最短路径，最多 6 条边。这带来两个后果：一是路径本身不含「本可抄近但必须绕」的分支，保真与到达几乎重合；二是判据「路径相似性」无从检验，因为最短直达路径上不存在更有诱惑的替代走法（Jain 等，2019，2.2 节）。R4R（Room-for-Room）通过拼接现有路径解决这两点：把终点与另一条路径起点接近的两条路径首尾相连，得到更长、更曲折的参考路径，同时不动用新的人工或低保证度的机器标注。

拼接规则形式化如下。设两条路径 A = (a1, …, a|A|)、B = (b1, …, b|B|)，当且仅当 d(a|A|, b1) 小于拼接阈值时合并；合并结果 R = (a1, …, a|A|, c1, …, c|C|, b1, …, b|B|)，其中 C 是 a|A| 到 b1 的最短衔接段，两端重合时 C 为空。指令侧同样拼接：若 A 带 NA 条指令、B 带 NB 条指令，扩展路径带 NA × NB 条拼接指令。R2R 每条路径固定 3 条指令，因此一次成功拼接产生 9 条样本；论文报告的 R4R 训练样本数 233,613 恰好是 9 的整数倍（233,613 = 9 × 25,957），与本规则自洽。

6. 实验证据：奖励里加入 CLS 改变了什么

论文用 RCM（Reinforced Cross-Modal Matching，Wang 等 2019）为底座，对比两种奖励（Jain 等，2019，4.3 节）：目标导向奖励按「每步缩短到目标的图距离」给稠密信号，终局给成功指示；保真导向奖励在终局给「1[成功] + CLS(s1…T, R)」的稀疏信号。网络、训练数据、行为克隆预热与策略梯度流程保持一致，唯一的自变量是奖励。

奖励R4R val-unseen SR (%)R4R val-unseen CLS仅给最后 5 词时的 CLS完全不给指令时的 CLSR4R val-unseen NE (m)
目标导向28.620.420.417.48.45
保真导向26.134.625.323.08.08

三项读法。第一，保真奖励把 CLS 从 20.4 抬到 34.6（绝对 +14.2，相对 +69.6%），同时 NE 从 8.45 m 降到 8.08 m（−4.4%）。SR 略降 2.5 个百分点，属于指标间的正常换手：模型从「抢终点」转向「沿路走」，而 R4R 的终点判定不因路径更准而放松。第二，语言依赖的证据藏在消融列里：目标导向智能体在只给最后 5 个词的条件下 CLS 不变（20.4 → 20.4），说明指令中段对它的决策没有影响；保真导向智能体从 34.6 掉到 25.3（−26.9%），去掉指令后进一步掉到 23.0。保真要求迫使模型读取全句，这是比 SR 更敏感的语言理解探针。第三，在 R2R（直达路径）上，同一论文报告目标导向与保真导向的差距很小，SPL 与 CLS 的排序一致；换到 R4R 后两者分离，目标导向智能体的 SPL 甚至更高而 CLS 更低。同一套模型、同一套数据来源，仅评测集结构变化就能让「旧指标好用」的结论翻转。

设计决策：任何「到达型」基准都应配一条保真指标

判据很简单：如果参考路径全部是最短直达路径，SR 与 CLS 高度相关，加测 CLS 的边际信息有限；如果参考路径可以曲折（多房间、多楼层、跨域路线），两者的排序会分离，此时以 SR 为唯一主指标会系统性奖励「猜终点」的策略。R4R 的实验表明，把保真写进训练奖励是让模型真正使用语言指令的有效手段之一。

实现思路与设计

把 CLS 落进工程项目，需要三块设计：距离缓存与评分管线、奖励与训练配置、数据侧的 R4R 生成参数。本节按评测、训练、数据三个视角给出取舍表。

1. 评分管线

CLS 的瓶颈在距离查询。推荐在加载场景时用单源 Dijkstra 预计算全对最短路并缓存为稀疏字典；评测阶段只做查表。数据流如下：episode 的 scan → 载入 connectivity 图 → 预计算距离表 → 收集智能体轨迹 P → 计算 PC、EPL、LS、CLS → 与 SR、SPL、NE 一并写入记录。判别参数与默认值见下表。

参数默认值作用取值依据与边界
dth（衰减尺度）3 m（R2R / R4R）控制覆盖分随距离的衰减速度与原任务成功阈值一致；换到街道或空中任务须按场景尺度重设，否则软惩罚过强或过弱
距离度量图最短距离保证偏离被正确计量欧氏距离会低估穿墙捷径的偏离，仅在无连通图的任务中兜底
路径起点约定p1 = r1维持唯一最优性质若评测允许中途复位，需在记录中标明起点来源
轨迹截断按评测步数上限截断限制超长轨迹的 LS 惩罚范围截断长度与 benchmark 版本一并标注，提交前以评测页面公布的规则为准
报告口径全 episode 平均跨方法可比失败 episode 的 CLS 按实际轨迹计算，不归零；与 SR 并列展示
报告纪律

CLS 的平均口径与 SR 不同：失败轨迹贡献正分。只报 CLS 会让读者无法区分「接近成功」与「真正完成」。任何使用 CLS 的实验表都应同时给 SR（或 OSR）与 NE，并注明 dth、split、步数上限三件套。

2. 奖励与训练配置

论文的配置可作为复现起点：行为克隆预热若干轮后做策略梯度，每个策略梯度批次之间交错 K 个行为克隆批次，K 随训练指数衰减，最终过渡到纯策略梯度（Jain 等，2019，4.2 节）。保真奖励采用稀疏终局式，比逐步塑形更简单，论文报告塑形项没有带来可觉察差异。两种奖励的选择判据与主要风险如下表。

方案信号密度优化对象适用场景主要风险
目标导向（每步距离差 + 成功指示）稠密终点到达参考路径为直达、任务关心送达奖励「猜终点」行为；对指令中段不敏感
保真导向（1[成功] + CLS）稀疏覆盖与长度参考路径曲折、需要语言接地终局信号方差大；需与行为克隆预热配合；SR 可能小幅换手
混合（逐步距离差 + 终局成功 + 终局 CLS）稠密 + 稀疏到达与保真加权希望同时保住 SR 与 CLS两项权重需要扫描，权重不当会让保真项失效

3. R4R 生成参数

参数取值与依据放宽 / 收紧的后果
拼接阈值（终点到起点的图距离）以官方 r4r 实现为准；论文条件为 d(a|A|, b1) 小于阈值放宽：扩展路径更多、平均更长，衔接语义不连贯风险上升；收紧：样本量下降，难度提升有限
指令配对策略NA × NB 全组合保持与 R2R「多指令冗余」一致；组合爆炸时可按质量过滤抽样
衔接段长度两端重合时为空；否则取最短路衔接段越长，两条指令之间的语气断层越明显，抽检时应重点看这类样本
质量过滤指令-路径一致性抽检、路径无环检查无过滤会引入「后半句与路径无关」的噪声样本，直接削弱 CLS 与语言的相关性

与上一讲的差异需要写清：第 007 讲把 SPL、OSR 与统计口径收尾，讨论如何在报告层面避免可见性偏差；本讲改的是测量对象本身，把中间路径纳入分数。两者不是替代关系：SPL 仍是效率的第一指标，CLS 是保真的第一指标，遇到终点接近而走法不同的轨迹时，两个指标同时报告才能得到完整画像。

关键代码与解读

三段代码分别覆盖评分、数据生成与奖励，均可对照第 3 小节算例验证。接口以 R2R / R4R 公开设计为参照，字段名随实现版本演进。

片段 1：CLS 评分（可对照工作算例逐行验证）

import math

def path_length(path, dist):
    """路径长度为相邻节点图距离之和；空路径或单点路径记 0。"""
    return sum(dist(a, b) for a, b in zip(path, path[1:]))

def cls_score(pred, ref, dist, d_th=3.0):
    """按 Jain 等 2019 的 CLS 定义计算单条 episode 得分。

    pred / ref: 节点序列；dist(a, b): 图最短距离（米）。
    d_th: 覆盖衰减尺度，R2R / R4R 口径取 3 m。
    """
    if len(pred) == 0 or len(ref) == 0:
        return 0.0
    pl_ref = path_length(ref, dist)      # PL(R)，参考路径总长
    pl_pred = path_length(pred, dist)    # PL(P)，预测路径总长
    pc = 0.0
    for r in ref:                        # 逐个参考节点找与预测路径的最近距离
        d = min(dist(r, p) for p in pred)
        pc += math.exp(-d / d_th)        # 3 m 处贡献 exp(-1) 约 0.3679
    pc /= len(ref)                       # 覆盖分取参考节点平均
    epl = pc * pl_ref                    # 期望最优长度随覆盖度缩放
    ls = epl / (epl + abs(epl - pl_pred))
    return pc * ls                       # CLS = PC * LS

解读：（1）d_th 默认 3 m 与成功阈值一致，函数参数显式暴露以支持换任务时的重新核定。（2）PC 循环内对每个参考节点取到整条预测路径的最近距离，复杂度 O(|P| · |R|)；距离查表由外部缓存提供，不在评分循环里跑图搜索。（3）LS 分式对长度偏差对称，抄近与绕远同罚；分母恒大于零，PL(P) = EPL 时取到 1。（4）空轨迹返回 0 属于兜底分支，正常运行中轨迹至少含起点，便于挡住数据管线错误。

片段 2：R4R 路径拼接

def join_paths(path_a, path_b, gap, shortest_path, n_instr=3):
    """把终点与起点接近的两条参考路径拼成 R4R 扩展路径。

    gap: d(a_last, b_first)，由调用方按图距离计算；
    shortest_path: 查询两点最短路的回调，用于生成衔接段。
    """
    threshold = 3.0                       # 拼接阈值，以官方 r4r 实现为准
    if gap >= threshold:                  # 不满足接近条件，放弃该配对
        return None
    mid = shortest_path(path_a[-1], path_b[0])
    if mid and mid[0] == path_a[-1]:      # 去掉与端点重复的首项
        mid = mid[1:]
    if mid and mid[-1] == path_b[0]:      # 去掉与端点重复的末项
        mid = mid[:-1]
    path = list(path_a) + mid + list(path_b)
    return {
        "path": path,
        "direct": gap,                    # 直达长度留档，便于统计难度
        "n_join": n_instr * n_instr,      # 两条子路径各 3 条指令时的样本数
    }

解读：（1）阈值放在函数内是为了让调用方统一从配置注入，实际工程应作为参数传入并写入数据卡。（2）衔接段首尾去重，保证 R 中不出现连续重复节点，维持「参考路径无环」这一满分条件的前提。（3）返回的 direct 字段记录拼接处的直达距离，可用于事后统计「参考长度 ÷ 直达长度」的分布，就是第 5 小节比值表的来源。（4）n_join 提醒数据侧：一次拼接放大为多条指令组合，做数据集配比时按样本数计量，路径数只作辅助统计。

片段 3：保真型稀疏奖励

def fidelity_reward(trajectory, ref, dist, stopped, success, d_th=3.0):
    """终局奖励 = 成功指示 + CLS；轨迹未结束时返回 0。

    与目标导向的逐步奖励不同，这里只在 episode 结束时给信号，
    让成功项与保真项各管一段：前者负责停对，后者负责走对。
    """
    if not stopped and not success:
        return 0.0                        # 未终止的中间步不给奖励
    r = 1.0 if success else 0.0           # 停对目标才计入成功项
    r += cls_score(trajectory, ref, dist, d_th)
    return r

def gamma_return(rewards, gamma=0.95):
    """把稀疏终局奖励摊回回报；仅在训练器需要逐步回报时使用。"""
    g = 0.0
    out = [0.0] * len(rewards)
    for t in range(len(rewards) - 1, -1, -1):
        g = rewards[t] + gamma * g
        out[t] = g
    return out

解读：（1）奖励结构直接对应论文式（12）：终局给「成功 + CLS」，中间步为零；参数暴露 success 与 stopped 两个布尔量，便于评测时分别审计停止判定与保真得分。（2）成功项与 CLS 项量级都在 1 附近，无需额外缩放；若采用混合奖励，建议先固定两项系数再扫描学习率，避免两个旋钮耦合。（3）gamma_return 是训练器的工具函数，折扣因子 0.95 对应约 20 步的有效视野，与 R2R 离散协议 10 步量级的轨迹长度匹配；长轨迹任务需要重新折算。（4）把 CLS 计算保留在奖励函数内会带来重复计算，实现中应在 episode 结束时算一次并把值缓存给评测器，训练与报告共用同一份分数。

常见坑

  • 把 CLS 当成功率报。症状：论文表格只列 CLS 上涨，读者无法判断任务完成度是否同步变化。根因：CLS 对失败轨迹给正分，与 SR 的量纲与含义都不同。修复：任何 CLS 数字与 SR（或 OSR）、NE 成对出现，并在表注中标 dth 与 eval split。
  • 距离用欧氏直线。症状：抄捷径的轨迹 PC 被高估，跨房间偏离难以体现。根因：实现者直接对节点坐标做 L2 距离，绕开了连通图。修复：一律沿 connectivity 图求最短路；没有图数据时至少把房间边界作为不可跨越约束。
  • dth 取错或忘记写。症状：复现数字与原论文差出一截，或换数据集后 CLS 全部趋近 0。根因：dth 与场景尺度强相关，未固定的衰减尺度让分数不可比。修复：把 dth 写入配置与实验记录表，跨环境实验逐环境标定，默认从成功阈值起步。
  • 拿 R2R 的数字与 R4R 的数字直接比。症状：结论中出现「某方法在 CLS 上退步」的误判。根因：两个数据集的参考路径分布不同（约 10 m 直达与约 20 m 曲折），CLS 与 SR 的相关结构完全不同。修复：只在同一数据集内做方法对比；跨数据集只做趋势性描述，并标注路径长度分布。
  • 只加 CLS 奖励却不做语言消融。症状：CLS 涨了，但仍无法回答模型是否真的在用指令。根因：CLS 可能通过视觉地标匹配提升，指令中段的贡献未被检验。修复：照论文范式做三档消融（全句、仅最后 5 词、无指令），把 CLS 的跌幅作为语言依赖的量化指标。

小结

  • 现有指标的盲区：SR / NE 只看终点，SPL 的效率因子按起点到终点的最短距离归一，中间路径偏离不受惩罚；R2R 参考路径全部为直达最短路，进一步削弱了语言理解的检验力。
  • CLS = PC · LS：PC 用指数衰减度量参考节点被覆盖的程度（dth 取 3 m），EPL = PC · PL(R) 给出随覆盖自适应的长度基准，LS 对长度偏差做对称惩罚；满分当且仅当两路径完全一致（参考无环、同起点）。
  • 工作算例的结论：抄捷径者 SPL = 1.000 而 CLS = 0.4946；差一步停者 SR = 0 而 CLS = 0.7653。CLS 与 SR / SPL 几乎不重叠，须成对报告。
  • R4R 用「终点接近起点则拼接」的规则把参考路径从约 10 m 直达扩为约 20 m 曲折，训练样本 233,613 条为 3 × 3 指令组合的整数倍；参考长度约为直达长度的 2 倍，SPL 与 CLS 的评价方向由此分离。
  • 保真奖励实验：R4R val-unseen 上 CLS 20.4 → 34.6、NE 8.45 → 8.08，且仅给最后 5 词时保真智能体 CLS 下降 26.9%、目标导向智能体不变，证明保真要求提升了语言依赖。
