第二篇 · 离散方法谱系：从模块到预训练

第 022 讲｜Speaker-Follower：合成指令与增广

本讲解剖 Speaker-Follower（Fried 等 2018，NeurIPS）：把 speaker 当作可学习的逆模型接入训练与推理，训练期生成 178,000 条合成指令增广数据，推理期用务实重排在 40 条候选路线中选择解释力最强的一条；全景动作空间把 36 个视角与可达方向编码为候选，把 val-unseen 成功率从 19.9% 提到 54.6%，test 53.5% 约为学生强制基线的 2.62 倍。

  • 主题：双模型 / 务实推理 / 数据增广 / 全景动作空间
  • 关键公式：argmaxr PS(d | r)λ · PF(r | d)1−λ，λ = 0.95
  • 预计学时：60 分钟
  • 前置讲：第 021 讲（Seq2Seq 基线全解剖）

学习目标

  • 会写：给出跟随者 PF(r | d) 与说话者 PS(d | r) 的双模型定义，说明 speaker 为何是 follower 的逆模型。
  • 会算：在 log 空间组合务实重排分数，比较 λ = 0、0.95、1 三种取值下的路线选择，并解释权重比。
  • 会判断：区分训练期增广、推理期重排、全景动作空间三个组件的增益来源与适用条件。
  • 会实现：写出 speaker 贪心生成、状态因子化候选搜索与务实重排三个核心片段。
  • 会评估：解释 val-unseen 54.6%、test 53.5% 与组件消融的对应关系，并识别挑战赛提交中轨迹长度 1257.38 m 的退化信号。

背景与动机

021 讲的基线暴露了两个结构性问题。第一，数据不足：R2R 只有 7,189 条路径与 21,567 条指令，全部来自最短路采样，策略见过的好状态太少，student-forcing 探索到的偏离状态之间没有监督信号。第二，指令本身不是低层行为说明：人类指令只标出少量高层决策与地标，大量缺失信息（从哪个门进、在何处转弯、何时停下）需要智能体根据视觉环境自行推断，通用序列模型很难从零学会这类推断。

Speaker-Follower（Fried 等 2018，NeurIPS 2018，arXiv:1806.02724v2）针对这两点各给一剂药：训练期用一个在路线到指令方向训练过的模型反向生成新数据，扩大 follower 的状态覆盖；推理期让同一模型充当「指令解释力」的裁判，从 follower 的候选路线中挑出对当前指令解释得最好的那条。这两步共用同一个 speaker，也共用同一套全景表示。

它的历史位置也很清楚：test 53.5% 相对当时最佳方法 25.3% 提升 28.2 个百分点，相对 021 讲的学生强制基线 20.4% 提升 33.1 个百分点（成功率 2.62 倍）。增广与重排两条线此后被反复继承：028 讲的 EnvDrop 继续做回译式增广，025、027 讲把重排思想推广为匹配与回溯机制。理解本讲的三组件结构与各自增益，是读第二篇后续多数论文的前提。

本讲要解决三件事：把双模型与务实公式写清并手算 λ 的作用；把增广的数据账（178,000 条路线、24.76 倍）与微调策略讲透；把全景动作空间从 021 讲的前向 60° 视场升级到 36 视角表示，并解释它为何单独贡献 11.3 个点的未见成功率。全景动作空间的设计抉择将在 023 讲展开，本讲先给出必要机制。

核心原理

1. 双模型：跟随者与说话者互为逆映射

任务可以写成「在环境中为指令 d 找一条最合适的路线 r」。论文把该问题分解为两个序列到序列模型：跟随者 PF(r | d) 读指令输出动作，说话者 PS(d | r) 读路线输出指令。两者结构对称：都用 LSTM 编码输入序列，再用带注意力的 LSTM 解码输出。词嵌入可选 GloVe 初始化，用于改善稀有词泛化；视觉特征沿用 021 讲的 ResNet，训练期间冻结。

PF(r | d) = Πt PF(at | a<t, d)，PS(d | r) = Πj PS(wj | w<j, r) r 为状态与动作序列，d 为指令词序列；两个模型都是自回归分解，接线方式相同、输入输出方向相反

把 speaker 单独看成一个生成模型，它可以为任何路线写出一段人类风格的指令；把 follower 单独看成一个分类器，它把指令映射为动作。论文的贡献在于让两者在训练与推理两端协同：训练端用 speaker 生成的数据教 follower，推理端用 speaker 给 follower 的候选路线打分。共同的前提是两个模型共享同一套视觉表示与动作空间，否则 speaker 打出的分数与 follower 搜索的路线不在同一语义空间。

2. 务实推理：用解释力给候选路线排序

推理期的问题是：给定指令 d，在环境里选哪条路线。理性言语行为（Rational Speech Acts）框架给出的原则是选择「最可能让说话者说出该指令」的路线，也就是说，式（1）的先验形式是 argmaxr PS(d | r)。精确求解该最大化在连续组合空间上不可行，且两个模型都是判别式训练、在训练分布外校准较差，论文采用重排近似：先用 follower 生成 K 条候选，再按组合分数排序。

r* = argmaxr ∈ R(d) PS(d | r)λ · PF(r | d)1−λ，λ ∈ [0, 1] R(d) 为 follower 搜索产出的候选路线集合；λ 在验证集上调参；论文报告 λ = 0.95 时 seen 与 unseen 验证集同时最优

实现时在 log 空间计算：log 分数 = λ · log PS + (1 − λ) · log PF，避免长序列概率连乘下溢。λ 的两端给出可检验的退化：λ = 0 时退化为纯 follower 排序，λ = 1 时退化为纯 speaker 先验。λ = 0.95 意味着 speaker 项的权重是 follower 项的 19 倍（实算 0.95 / 0.05 = 19），路线选择以解释力为主、以生成概率为辅。论文另报告，只用 follower 分数对搜索候选排序时 val-seen 为 49.0%、val-unseen 为 30.5%；加入 speaker 后升到 57.2% 与 39.3%，同一批候选、同一底座，仅替换评分者就带来 8.2 与 8.8 个点的增益，这是务实重排价值最干净的证据。

3. λ 作用算例

设两条候选路线的对数概率如下：路线 A 更符合 follower 的生成偏好（log PF = −8.0）却较难解释指令（log PS = −12.0）；路线 B 相反（log PS = −10.0，log PF = −12.0）。按 log 空间组合分数：

路线log PSlog PFλ = 0（纯 follower）λ = 0.95λ = 1（纯 speaker）
A−12.0−8.0−8.0（胜）−11.8−12.0
B−10.0−12.0−12.0−10.1（胜）−10.0（胜）

读法：λ 从 0 变到 0.95，选择从 A 翻转到 B，翻转点由两条路线的分数差与权重共同决定。这个算例同时说明务实推理的两个使用条件。其一，候选质量是上限：若 B 不在 R(d) 中，speaker 再强也无法选它，因此 follower 的搜索必须付出 K = 40 的预算。其二，speaker 必须校准：当 λ 接近 1 时，分数几乎完全由 speaker 决定，speaker 在训练分布外的过度自信会直接变成错误选择；论文用 λ = 0.95 保留 5% 的 follower 项，正是留出校准余量。

4. 候选生成：状态因子化搜索

标准 beam search 让不同长度的部分路线按动作数竞争，而 VLN 的路线长度差异大，导致长路线在早期被过早淘汰。论文改用状态因子化搜索：部分路线在同一环境状态层面竞争，每个状态只保留分数最高的到访路线；状态定义为「离散位置 + 离散朝向 + 是否已预测停止」。

  • 展开规则：每轮取出当前最高分且未展开的路线，对每个可能动作生成后继路线，若后继状态尚无记录或新路线分数更高，则写入并允许重新展开。
  • 无环性质：路线分数是条件概率连乘，随之单调不增，因此搜索生成的路线不会两次经过同一状态；人类指令通常描述无环路线，此性质与任务结构一致。
  • 停止条件：累计 K = 40 条以停止动作结束的路线，或没有可展开的路线。
  • 附带收益：即使不做务实重排，只用 follower 分数在该搜索里选最优候选，也优于贪心解码，说明搜索结构本身有独立价值。

状态必须包含朝向与停止标记：漏掉朝向会把不同观察方向合并成同一状态，漏掉停止标记会让「已停下」与「继续走」互相覆盖。这个设计在实现上等价于带闭表的图搜索，区别在于动作概率非平稳、允许按更高分路线重新展开。

5. Speaker 驱动的数据增广

训练侧的核心事实是监督覆盖不足：R2R 只标注了 7,189 条最短路路径。论文在训练环境内按同样短路径规则采样 178,000 条新路线，用训练好的 speaker 做贪心解码为每条路线生成指令，构成合成集合 S，与原集合 D 合并训练 follower。规模账（实算）：路线数 178,000 / 7,189 = 24.76 倍，指令数 178,000 / 21,567 = 8.25 倍（合成集每路线 1 条，人工集每路线 3 条）；合成路线占合并集合的 96.1%。

训练流程分两段：在 S ∪ D 上按 student-forcing 训练 50,000 次迭代，再用原始人工数据 D 微调 20,000 次迭代。论文解释微调必要性的理由有二：合成指令带有 speaker 的噪声与模板化表达，长期训练会把风格偏差写入策略；收尾在人工数据上微调可以对齐人类措辞分布。增广量的边际收益也可测量：使用 25% 合成数据时 val-unseen 成功率为 22.8%，使用全部合成数据时为 24.6%，提升 1.8 个点（相对 7.9%）；论文把全量配置视为性能与计算开销的平衡点。

只加增广、不动其他组件的消融行为（val-unseen SR 19.9% → 24.6%，4.7 点；val-seen 40.3% → 46.8%，6.5 点）：增广对两个 split 都带来正向增益（相对 23.6% 与 16.1%），说明它主要扩张状态覆盖，并未偏袒某一环境集合。

6. 全景动作空间：36 视角与可达方向

021 讲的观测是前向 60° 视场，智能体必须先转镜看到目标方向才能前进。Speaker-Follower 把感知升级为 360° 全景离散表示，把决策升级为「直接选择下一个可通行方向」的高层动作，低层转镜由内建映射完成。

vt,i = [ φ(视角 i 的局部图像) ; sin ψi ; cos ψi ; sin θi ; cos θi ]，i = 1, …, 36 36 = 12 个水平朝向 × 3 个俯仰档，角度间隔 30°；φ 为 ConvNet 外观特征；后四维为朝向与俯仰的三角函数编码

第 t 步用上一轮记忆 ht−1 对全部 36 个视角做一跳视觉注意力：

at,i = (W1 ht−1)⊤ W2 vt,i，αt,i = exp(at,i) / Σj exp(at,j)，vt,att = Σi αt,i vt,i 注意力加权结果替代 021 讲的前向外观向量，作为序列模型的视觉输入

动作侧不做 36 个视角的逐一建模；做法是对当前视点可达的每个方向 j 编码 uj（外观特征加四维朝向编码），并用双线性打分输出概率；停止动作用零向量 u0 = 0 表示：

yj = (W3 ht)⊤ W4 uj，pj = exp(yj) / Σj′ exp(yj′) 候选方向由导航环境给出，被家具堵住的方向自然不会进入候选；选择后沿该方向移动到相邻位置

两组设计带来的独立增益（val-unseen SR 19.9% → 31.2%，11.3 点；val-seen 40.3% → 52.1%，11.8 点）说明：把感知从 60° 前向扩展到全景、把动作从转镜序列提升为方向选择，本身就是与数据增广、务实重排同量级的改进。前向视场只覆盖周围环境的一小部分，大量指令中的侧向地标在 021 讲接口下需要额外转镜动作才能进入视野，这是全景表示收益的直接来源。

8. 适用边界与失效模式

  • 合成指令的分布偏差：speaker 只见过最短路路线的人类描述，合成指令带有模板化与措辞偏差；其在训练中的正作用来自状态覆盖，语言多样性不是它的主要贡献。增广比例、微调步数都应按验证集搜索，不宜直接套用。
  • 推理成本成倍放大：K = 40 条候选的搜索与逐候选的 speaker 打分，把评测计算量提高一到两个量级。与其他方法比较时，应区分「训练改进」与「推理预算增加」两类收益。
  • λ 接近 1 的校准风险：speaker 在陌生场景中可能过度自信；论文保留 5% 的 follower 权重是校准余量，直接取 λ = 1 在大规模评测中未必更优。
  • 概率尺度对长度敏感：式（1）直接用序列概率组合，不同长度路线的对数概率和尺度不同。若复现时引入长度归一化，应作为独立消融并单独报告，避免与论文数字直接对比。
  • 增广只在训练环境内扩状态：采样路线来自训练场景，无法引入新建筑；跨环境泛化的结构部分仍由全景表示与重排承担。

关键代码与解读

三段代码覆盖 speaker 贪心生成、状态因子化搜索与务实重排。接口按公开实现的设计为参照，字段与版本随实现演进。

片段 1：speaker 为路线贪心生成指令

import torch

@torch.no_grad()
def speaker_greedy(speaker, route_inputs, max_len=40):
    """给定路线（视觉观察与动作序列）编码，贪心生成一条合成指令。
    route_inputs: (1,T,2048+32)，视觉特征与动作嵌入拼接后的路线序列。"""
    enc_out, (h, c) = speaker.encoder(route_inputs)      # 路线编码器
    word = speaker.bos_id
    words = []
    for _ in range(max_len):
        emb = speaker.word_embed(torch.tensor([[word]]))
        out, (h, c) = speaker.decoder(emb, (h, c))
        score = torch.bmm(speaker.attn(out[:, -1]).unsqueeze(1),
                          enc_out.transpose(1, 2))       # 对路线编码做注意力
        ctx = torch.bmm(torch.softmax(score, dim=-1), enc_out).squeeze(1)
        logits = speaker.head(torch.cat([out[:, -1], ctx], dim=-1))
        word = int(logits.argmax())                       # argmax 近似论文的贪心解码
        if word == speaker.eos_id:
            break
        words.append(word)
    return words

解读：（1）speaker 与 follower 结构对称，唯一变化是输入输出方向：路线序列进编码器，指令逐词出解码器。（2）贪心解码对应论文中 d̂ = argmaxd PS(d | r̂) 的近似，生成结果用于训练数据，不需要多样性；若要用它做重排打分，则应改用对数概率，不能直接使用生成出的词序列。（3）采样路线必须与人工数据同源：规则一致才能保证合成监督与真实任务同分布，否则增广会引入难以诊断的偏差。

片段 2：状态因子化候选搜索（骨架）

def state_factored_search(follower_logp, env, K=40):
    """状态因子化搜索：状态为(位置, 离散朝向, 是否已停止)。
    follower_logp(route, action) 返回该动作的对数概率；
    分数为路线逐步对数概率之和，允许更高分路线覆盖旧记录并重新展开。"""
    start = env.start_state()
    best = {start: (0.0, [])}                 # state -> (累计对数概率, 路线)
    finished = []
    while best and len(finished) < K:
        state = max(best, key=lambda s: best[s][0])   # 取最高分待展开状态
        score, route = best.pop(state)                # 弹出后允许重新入队
        if state[2]:                                  # 已预测停止，收为候选
            finished.append((score, route))
            continue
        for action in env.actions(state):
            logp = follower_logp(route, action)
            nxt = env.transition(state, action)
            cand = (score + logp, route + [action])
            old = best.get(nxt)
            if old is None or cand[0] > old[0]:       # 闭表加可重开
                best[nxt] = cand
    return finished

解读：（1）状态三元组缺一不可：位置与朝向共同决定观察，停止标记区分终态与途中状态；漏掉任一项会导致不同状态合并或候选重复。（2）「弹出后允许重新入队」是相对标准闭表的关键放宽：动作概率非平稳，先前到某状态的路线可能被更高分路线取代，重新展开保证近似搜索的质量。（3）路线分数是条件概率连乘、随步数单调不增，经同一状态绕回来的路线分数必低于该状态已有记录，闭表机制因此不会生成含环路线，这与人类指令通常描述无环路线一致。

片段 3：务实重排（log 空间）

def pragmatic_rank(candidates, speaker_logp, follower_logp, lam=0.95):
    """按 log 空间组合 speaker 与 follower 分数，返回降序排列的候选。
    speaker_logp(desc, route) 与 follower_logp(route, desc) 返回对数概率。"""
    scored = []
    for route, desc in candidates:
        ls = speaker_logp(desc, route)            # log P_S(d | r)
        lf = follower_logp(route, desc)           # log P_F(r | d)
        total = lam * ls + (1.0 - lam) * lf       # 等价于式 (1) 取对数
        scored.append((total, route, ls, lf))
    return sorted(scored, key=lambda item: -item[0])

cands = [("route_A", "desc"), ("route_B", "desc")]
logp_s = {"route_A": -12.0, "route_B": -10.0}     # speaker 偏好 B
logp_f = {"route_A": -8.0, "route_B": -12.0}      # follower 偏好 A
rank = pragmatic_rank(cands,
                      lambda d, r: logp_s[r],
                      lambda r, d: logp_f[r], lam=0.95)
for total, route, ls, lf in rank:
    print(route, round(total, 2), ls, lf)
# route_B -10.1 -10.0 -12.0；route_A -11.8 -12.0 -8.0

解读：（1）式（1）的概率连乘在 log 空间变成加权和，数值稳定性由对数概率保证；λ = 0 与 λ = 1 分别对应纯 follower 与纯 speaker，可作为消融两端。（2）算例输出显示 speaker 偏好压过 follower 偏好，路线 B 以 −10.1 胜出；这来自 19 倍的权重比压过了 follower 的分数优势。（3）desc 固定为同一句指令，两条候选只是路线不同；工程实现中候选与指令以元组绑定后传递，避免跨样本串线。

常见坑

  • 把合成数据当唯一监督：症状是训练集指标持续上升，val-unseen 明显低于 24% 档。根因是 speaker 的模板化措辞与噪声被策略吸收，且缺少人工数据的收尾微调。修复：按 50,000 加 20,000 两段执行，第二段只用人数据；增广比例从 25% 起做扫描。
  • 重排分数在概率空间直接连乘：症状是长候选的分数下溢为零或全部并列，排序退化为随机。根因是浮点下溢与长度尺度差异。修复：一律在 log 空间做加权和；如引入长度归一化，单独标注为消融。
  • λ 用测试集调参：症状是榜单成绩好于同配置的验证成绩，复现无法一致。根因是 λ 在 test 上被隐式拟合。修复：λ 只在 val 上调，报告时写明扫描范围与选中值；论文取 0.95 并在两个验证集上同时最优。
  • 搜索状态漏掉朝向或停止标记：症状是候选重复、路线互相覆盖或搜索循环。根因是状态等价类定义过粗或过细。修复：用「位置 + 离散朝向 + 停止标记」三元组，并对候选集合做去重断言。
  • 把推理预算当训练改进：症状是把自己 K = 40 重排的结果与别人的贪心解码直接比较。根因是推理预算未对齐。修复：报告 K、speaker 打分次数与解码方式；区分「同等预算」与「最大预算」两栏成绩，挑战赛的 OSR 96.0%（TL 1257.38 m）必须与 SR、NE 一起解读。

练习与思考

  1. 设三条候选路线的对数概率为：r1（log PS = −9.0，log PF = −10.0）、r2（−11.0，−8.5）、r3（−10.0，−11.5）。分别计算 λ = 0、0.95、1 时的排序，并指出哪种取值下 follower 的偏好能改变结果。 ★
    提示
    λ = 0：r2（−8.5）优于 r1（−10.0）优于 r3（−11.5）。λ = 0.95：r1 = −9.05，r2 = −10.875，r3 = −10.075，排序 r1、r3、r2。λ = 1：r1（−9.0）优于 r3（−10.0）优于 r2（−11.0）。只有当 follower 与 speaker 分数差足以跨过 19 倍权重时，follower 的偏好才会改变 λ = 0.95 的结果。
  2. 增广规模核算：178,000 条合成路线、7,189 条人工路线、每路线合成 1 条指令、人工每路线 3 条。计算路线倍数、指令倍数与合成路线占比，并说明为什么指令倍数小于路线倍数。 ★
    提示
    路线 178,000 / 7,189 = 24.76 倍；指令 178,000 / 21,567 = 8.25 倍；合成占合并路线集 96.1%。人工集每路线 3 条指令，合成集每路线 1 条，指令扩张速度因此慢于路线扩张速度。
  3. 设计回译式增广流程的脚本骨架（与机器翻译的回译同构）：(a) 写出六个阶段及每阶段的输入输出；(b) 给出两条质量控制断言；(c) 预测「合成比例提高到 100% 且取消微调」时验证指标的变化方向并说明原因。 ★★
    提示
    (a) 训练 speaker、采样路线、生成指令、混样训练、人工微调、验证筛选。(b) 抽查合成路线与人工路线的重合比例并据此去重；断言合成指令的地标词与路线观察匹配。(c) 取消微调会把措辞偏差留在策略里，val-unseen 下降；增广比例过高进一步放大偏差，正确做法是按验证集扫描比例并保留人工收尾。
  4. 根据组件消融表回答：(a) 三个组件单独加入时 val-unseen 的增益分别是多少点；(b) 为什么务实重排的单项增益大于数据增广；(c) 预测把候选数 K 从 40 降到 10 时重排增益如何变化，并给出验证方法。 ★★
    提示
    (a) 增广 +4.7 点、重排 +14.6 点、全景 +11.3 点。(b) 重排直接替换了候选选择规则，可利用全局解释力纠正局部贪心错误；增广只扩张训练状态覆盖，受合成噪声上限约束。(c) 候选覆盖率下降，重排增益缩小；在验证集上固定模型只改变 K，绘制 K 与 SR 的曲线，同时报告每个 K 的推理耗时。

    提示
    (a) 锚点约为 24.6%、34.5%、31.2%、54.6%，允许的实现差异应写进容差。(b) 在同一候选集上分别用 follower 分数与 λ = 0.95 组合分数排序：候选质量给上界，两者差值就是评分者贡献，论文对应 30.5% 与 39.3%。(c) 症状一：重排无增益、候选相似度高，先查 K 与状态去重；症状二：微调后指标倒退，先查合成比例与微调学习率。(d) 报告 K、speaker 前向次数、每 episode 耗时，并给出同等预算下的对照（例如 K = 40 的 follower-only 重排）。

小结

  • 双模型结构：follower 学 PF(r | d)，speaker 学 PS(d | r)，两者序列到序列同构、方向相反，共享视觉与动作表示。
  • 务实推理按 r* = argmax PSλ · PF1−λ 重排候选，论文取 λ = 0.95（speaker 权重为 follower 的 19 倍）；同一候选集上，仅把评分者从 follower 换成组合分数，val-seen 从 49.0% 升到 57.2%、val-unseen 从 30.5% 升到 39.3%。
  • 增广流程：采样 178,000 条训练环境路线（24.76 倍人工路线），speaker 贪心生成合成指令（合成路线占 96.1%），在 S ∪ D 上训练 50,000 步后在 D 上微调 20,000 步；只开增广时 val-unseen 19.9% → 24.6%。
  • 全景动作空间：12 朝向 × 3 俯仰 = 36 视角加四维朝向编码，注意力聚合全景并替代前向 60° 视场；动作在可达方向与停止之间双线性打分，是「位置加朝向」层次的直接移动。
  • 完整系统 val-unseen 54.6%（NE 4.83 m）、test 53.5% 加 OSR 63.9%（NE 4.87 m），相对学生强制基线为 2.62 倍；挑战赛提交 OSR 96.0% 伴随 TL 1257.38 m 的退化，说明指标必须成组解读。
