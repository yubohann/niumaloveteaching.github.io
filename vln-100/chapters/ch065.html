第四篇 · 规模、记忆与泛化方法论

第 065 讲｜数据增广的边界与风险

本讲把两种经典增广放进同一套边界分析：Speaker-Follower 的合成指令增广（Fried 等 2018）在 25% 剂量上拿到 2.9 个点，后 75% 剂量只补 1.8 个点，单位效率相差 4.83 倍；EnvDrop 的回译与环境丢弃（Tan 等 2019）在训练环境内只值 1.7 个点，换到真实未见环境却值 15.4 个点。收益递减、分布漂移、泄漏是三条边界线，本讲给出各自的度量方式、增广决策表与停止判据。

  • 主题：数据增广 / 剂量-响应 / 分布漂移 / 泄漏审计
  • 关键数字：增广 +4.7 点（SF，val unseen）、边际效率比 4.83、掩码绑定差 3.2 点、低质数据 −0.26 点
  • 预计学时：60 分钟
  • 前置讲：第 064 讲（数据工程再谈（承 033））

学习目标

  • 会算：由剂量-响应曲线算出分段边际效率、每千条合成样本的增量与饱和拟合参数，并据此写出停止判据。
  • 会解释：增广产生收益的三个条件（覆盖扩张、语义一致、环境或分布真正新增），以及收益转为零或负值的信号。
  • 会实现：剂量-响应汇总、泄漏审计（场景与路线标识交集、近重复检索）、指令漂移度量三段代码。
  • 会判断：对一个候选增广方案给出继续、限幅或放弃的结论，并写出增广决策表的一行。
  • 会设计：为新任务设计含剂量梯度、对照与协议标注的增广消融，明确主终点与停止规则。

背景与动机

第 064 讲把数据工程立成「合法、可复现、可审计」的底线；增广是数据工程的另一半。第 061 与 062 讲给出的规模路线用 1,291 个真实场景合成约 494 万条指令轨迹对，把 R2R test unseen 推到 80%；但同一篇工作的消融也显示，未修复的 Gibson 数据在增加 61% 数据量后，val unseen SR 从 76.59 掉到 76.33。规模本身不保证收益，质量与分布才是约束。

增广的历史比规模化更早。第 022 讲的 Speaker-Follower 在 61 个训练场景内采样 178,000 条新路线，用说话者模型生成指令，单独使用时把 val unseen SR 从 19.9% 提到 24.6%；第 028 讲的 EnvDrop 用回译加环境丢弃，在 R2R val unseen 上从混合训练的 46.5% 提到 52.2%。两篇论文都报告了正收益，也都在附录里留下边界：合成指令有模板风格，环境丢弃掩码必须绑定，未见环境回译属于预探索协议。

本讲把这两条线与第 062 讲的低质数据反例放在一起，回答三个问题：收益在什么剂量后停止增长；分布漂移怎样被度量与控制；泄漏从哪三个通道进入实验。产出是一张增广决策表、一套停止判据与一段泄漏审计代码，为第 066 讲转入记忆预算讨论做数据侧收尾。

核心原理

本讲按「共同结构、收益递减、环境瓶颈、分布漂移、泄漏通道、何时有害、决策表、失效模式」八步展开；全部数字标注来源与协议，实算脚本单独放置，正文只引用结果。

1. 增广的共同结构

把增广写成变换 T：(x, y) → (x′, y′)，其中 x 为输入（观测、环境、路线），y 为监督（指令、动作、目标）。按扩张对象分两类：分布内扩张把同一分布内的样本补密，分布外扩张把数据推到训练分布之外。Speaker-Follower 采样新路线并生成指令，属于训练场景内的密度扩张；EnvDrop 的虚拟环境让说话者与跟随者看到被一致遮蔽的房间，属于受控的分布外扩张；第 062 讲的合成管线用真实新扫描扩环境，属于真实的分布外扩张。三类的作用上限不同，混淆三者会把「覆盖收益」误读为「泛化收益」。

读表先记住两个量级：SF 的增广与推理组件相比是最小项（务实重排 +14.6 点、全景动作 +11.3 点、增广 +4.7 点，val unseen，同一论文表 1 口径）；EnvDrop 的增广收益集中在环境丢弃的绑定版本。两个结果都指向同一件事：增广的价值取决于它新增了什么约束，补密度排在补分布之后。

2. 收益递减：SF 的剂量-响应

SF 论文报告了训练数据中合成指令占比的两个锚点：25% 时 val unseen SR 为 22.8%，100% 时为 24.6%（基线 19.9%，无增广）。把数据比例记作 f，分段边际效率定义为 η = ΔSR / Δf。实算（Python）：第一段 f 从 0 到 0.25 拿到 +2.9 点，η₁ = 11.60；第二段 f 从 0.25 到 1.00 拿到 +1.8 点，η₂ = 2.40；两段效率比 4.83。换算到样本：前 44,500 条合成指令每千条贡献 0.0652 个点，后 133,500 条每千条贡献 0.0135 个点。

η(Δf) = ΔSR / Δf；效率比 = η前段 / η后段 = 11.60 / 2.40 = 4.83 停止判据：当下一档剂量的 ΔSR 低于 0.5 个点，或低于两次独立运行的标准误时，停止加码

用两点数据做描述性拟合可得 g(f) = G(1 − exp(−k f))，解出 G ≈ 4.82 点、k ≈ 3.68；该拟合在 25% 处覆盖饱和上界的 60.15%，在 100% 处覆盖 97.48%。注意这是两点定参的描述模型，没有第三个剂量点做独立验证，只能用于解释递减趋势，不能当作预测结论。论文把全量配置视为性能与计算开销的平衡点，并把 20,000 次人工数据微调放在 50,000 次增广训练之后；微调与增广训练步数比 0.40，充当风格校准段。

递减的机制来自覆盖：合成路线在训练场景内按同一最短路规则采样，早期样本覆盖新的起始点与转向组合，后期样本与既有轨迹高度重叠。第 028 讲用另一个口径给出同一结论：R2R 训练环境约 14K 条人工路线，候选最短路约 190K 条，标注覆盖率 7.368%；在训练环境内把回译铺满，验证未见集只从 46.5% 升到 48.2%。

3. 环境多样性是主瓶颈

EnvDrop 论文把「更多环境」与「更多数据」做了直接对照：在数据量相同的条件下，增加环境数量的曲线增长率高于在全部环境中随机选数据的曲线。回译放在训练环境上只值 1.7 个点；放在未见验证环境上，成功率从 46.5% 跳到 61.9%，再加环境丢弃到 64.5%。实算：第一跳 +15.4 点，相对提升 33.12%；第二跳只有 +2.6 点。前者的量级远超任何训练环境内的增广配方。

协议提醒

61.9% 与 64.5% 两个数字都来自 pre-exploration 协议：未见环境在评测前参与了回译训练。它们描述的是「机器人先熟悉全屋再执行指令」的场景，与标准零样本榜单不可直接比较。引用时必须同时标注协议与环境参与方式，否则会把泄漏包装成泛化。

规模化路线把环境瓶颈推得更远，也把质量门槛立了起来。第 062 讲的消融显示：HM3D 加未修复 Gibson 数据（数据量增加 61%）时 val unseen SR 为 76.33%，略低于不加的 76.59%；换成修复后的 Gibson 数据，SR 升到 78.08%。实算：修复带来的同规模增益 1.49 个点，低质扩张带来 −0.26 个点。环境是增长轴，质量是闸门：闸门不打开，扩张方向上的边际收益可能为负。

4. 分布漂移：语义一致与风格校准

合成指令的分布与人工指令存在系统差距，来源有三：说话者只在最短路与人工描述上训练，模板化措辞占比高；生成过程按贪心解码，多样性低于人工改写；路线采样规则一致，导致「起点描述加转向加地标」的句式重复出现。SF 论文的对策是把人工微调放在训练末段，让策略在人类措辞分布上收尾。EnvDrop 论文给出了更锐利的证据：环境丢弃的收益几乎全部来自掩码绑定。

绑定的含义是说话者与跟随者共用同一张环境掩码，保证「没有椅子的房间」在两侧是同一个房间。实算：绑定相对不绑定提升 3.2 个点，相对提升 6.53%；不绑定版本相对纯回译只多 0.8 个点。特征丢弃为什么几乎无效：逐元素独立掩码下，p = 0.4、同一环境 36 个视角时，某个维度在所有视角保持状态一致的概率为 0.636 + 0.436 ≈ 1.03×10−8，跨视角语义一致性几乎处处被破坏。漂移的度量应至少覆盖三项：合成与人工指令的 n-gram 重叠率、平均长度、句式模板占比；把合成比例写进数据卡片的已知偏差字段（第 064 讲）。

5. 泄漏的三条通道

增广数据在生成时若接触到评测信息，指标就不再是泛化证据。泄漏有三条通道，检查方法各不相同。

  • 场景级泄漏：在评测场景上生成指令或回译。EnvDrop 的 61.9% / 64.5% 属于此类（预探索协议）。检查：增广场景标识集合与评测场景标识集合的交集必须为空。
  • 监督级泄漏：增广直接使用评测路径、评测指令或评测标注作为生成条件，哪怕场景不同。检查：路线标识与指令标识交集；生成脚本的输入依赖清单。
  • 近重复泄漏：同一场景内的相邻视角图像在增广前后进入不同集合，视觉内容高度相似。检查：跨集合感知相似度检索，阈值参照第 064 讲的 0.95 口径。

三条通道的共同修复方式是把「评测集冻结 + 生成脚本隔离」写进流程：生成器只允许读取训练侧的清单与缓存，评测清单在发布后冻结并记校验值。这条纪律与第 064 讲的审计条目 11 是同一件事，本讲把它执行到增广环节。

6. 何时有害：三个条件与三种表现

把负面结果归成三个条件。条件一：扩张方向已饱和，继续加码只贡献重叠样本与模板句子（SF 后 75% 剂量）。条件二：新增数据与目标分布的距离超过模型可消化的范围，低质 Gibson 扩张带来 −0.26 个点。条件三：生成条件与训练条件不一致，掩码不绑定时指令与观测互相矛盾，收益从 3.2 点降到 0.6 点。

三个条件同时说明，「有害」很少表现为指标暴跌，更多表现为三种形态：增量趋零而成本照付；混合比例上升后验证曲线波动放大；某一分项（如 SPL）下降而 SR 不动。诊断方法是在同一配方下做剂量梯度，并同时报告训练成本。

8. 适用边界与失效模式

  • 增广替代不了环境：训练环境内铺满回译值 1.7 个点，真实新环境回译值 15.4 个点；把预算投在增广前先核对环境清单。
  • 剂量点太少无法定操作点：只有 0 与 100% 两个点时，任何「加满最好」的结论都缺少中间证据。
  • 风格漂移会在长训练中积累：SF 用末段人工微调收尾，缺这一步时措辞分布持续偏向合成侧。
  • 协议越界的数字不能进主表：预探索数字可以报告，必须与零样本数字分表。
  • 合成数据缺少动作性监督：指令可覆盖路线，低层动作与可通行性没有保障；增广数据用于动作监督时需要额外校验（第 033 讲边界）。

增广引入顺序按收益与风险排序：先用剂量曲线确认覆盖扩张还有多少空间；再解决语义一致（掩码绑定、人工微调）；最后才把预算投向环境级合成与质量修复。判据是每单位成本的 val unseen 增量：增量低于停止阈值时把预算移到环境侧，停止在加密同一批场景上加码。

与相邻讲的分工：第 022 与 028 讲解释两种增广的机制与主结果；第 062 讲给出规模化管线的质量证据；本讲把三者合并成边界分析与决策表。第 066 讲转入记忆范式的预算推导，那里处理的是「模型记什么、花多少内存」的另一半方法论。

关键代码与解读

三段代码分别给出剂量-响应汇总、泄漏审计与漂移度量。数字与正文一致，可直接作为实验记录脚本的骨架。

片段 1：剂量-响应与停止判据

def dose_response(fracs, sr):
    """输入增广剂量比例与对应 val-unseen SR，输出分段边际效率。"""
    rows = []
    for i in range(1, len(fracs)):
        d_f = fracs[i] - fracs[i - 1]          # 本段新增的数据比例
        d_s = sr[i] - sr[i - 1]                # 本段带来的 SR 增量（百分点）
        rows.append({
            "range": (fracs[i - 1], fracs[i]),
            "delta_sr": round(d_s, 2),
            "per_frac": round(d_s / d_f, 2),   # 每单位比例的增量
            "per_1k": round(d_s / (178000 * d_f / 1000), 4),  # 每千条合成指令
        })
    first, last = rows[0]["per_frac"], rows[-1]["per_frac"]
    stop = rows[-1]["delta_sr"] < 0.5          # 停止判据：末段增量低于 0.5 点
    return rows, round(first / last, 2), stop

# Speaker-Follower 口径（Fried 等 2018）：19.9 / 22.8 / 24.6
rows, ratio, stop = dose_response([0.0, 0.25, 1.0], [19.9, 22.8, 24.6])
# 末段效率比 4.83，末段增量 1.8 点：未触发停止，但已进入低效区

解读：（1）分段效率把「值不值得继续加」变成可比较的数，效率比大于 3 时优先检查覆盖是否饱和；（2）停止判据写成显式布尔量，便于多方案批量比较；阈值 0.5 点应结合两次运行的标准误调整；（3）每千条口径让不同规模的增广方案可比，避免用绝对数据量掩盖效率差异。

片段 2：泄漏审计

def leakage_audit(aug_index, eval_index, threshold=0.95):
    """审计增广数据与评测集的场景、路线与视觉近重复。"""
    scene_hit = set(aug_index["scenes"]) & set(eval_index["scenes"])
    route_hit = set(aug_index["routes"]) & set(eval_index["routes"])
    dup = []
    for key, feat in aug_index["images"].items():
        m = eval_index["search"](feat, top_k=1)
        if m and m[0]["scene"] in eval_index["scenes"] and m[0]["score"] >= threshold:
            dup.append((key, m[0]["scene"], round(m[0]["score"], 4)))
    report = {
        "scene_leak": sorted(scene_hit),        # 非空表示环境级泄漏
        "route_leak": sorted(route_hit),        # 非空表示监督级泄漏
        "near_dup": dup[:10],                   # 视觉近重复抽样
    }
    assert not scene_hit and not route_hit, report
    return report

# 审计通过后，增广集与评测集的生成脚本仍需隔离：
# 评测清单冻结并记录校验值，生成器只读取训练侧缓存

解读：（1）两级检查从粗到细：标识集合交集处理场景与监督泄漏，相似度检索处理近重复；（2）断言让审计失败直接中断流程，防止带病数据进入训练；（3）报告字段与数据卡片的「已知偏差」对齐，审计结果随数据版本一起冻结。

片段 3：指令漂移与掩码绑定检查

def instruction_drift(synth, human, n=4):
    """度量合成指令相对人工指令的 n-gram 重叠与长度分布。"""
    def grams(texts):
        out = set()
        for t in texts:
            w = t.split()
            out.update(tuple(w[i:i + n]) for i in range(len(w) - n + 1))
        return out
    s_g, h_g = grams(synth), grams(human)
    overlap = len(s_g & h_g) / max(len(s_g), 1)   # 合成侧被人工侧覆盖的比例
    mlen = [sum(len(t.split()) for t in x) / len(x) for x in (synth, human)]
    return {"gram_overlap": round(overlap, 3),
            "len_synth": round(mlen[0], 2),
            "len_human": round(mlen[1], 2)}

def binding_ok(speaker_mask, follower_mask):
    """EnvDrop 掩码绑定检查：同一三元组两侧掩码逐元素相同。"""
    same = bool((speaker_mask == follower_mask).all())
    # 论文口径：绑定 52.2 对不绑定 49.0，差 3.2 点；不通过不得进入训练
    return same

解读：（1）重叠率揭示模板化程度：数值过高说明合成指令在复用少量句式，应提高真实改写比例或降低合成剂量；（2）长度分布是第二个漂移信号，合成与人工的均值差超过一个词就要检查采样器；（3）绑定检查放在数据装载层，任何一次采样失误都会在训练前暴露，避免用 3.2 个点的代价做事后归因。

常见误区

  • 在评测环境上生成增广数据并当零样本结果报告：指标大涨，结论无法复用。根因是把预探索协议与标准零样本混表。修复：生成脚本只读训练侧清单；预探索数字单独成表并醒目标注协议。
  • 只报总增益不报剂量曲线：加满合成数据后发现收益低于预期，无法定位是覆盖饱和还是漂移。根因是实验只设 0 与 100% 两个点。修复：设 25% 步长的剂量梯度，输出分段效率表；把停止判据写进实验计划。
  • 图像级扰动破坏跨视角一致性：特征丢弃只值 0.2 个点，还引入互相矛盾的画面。根因是掩码按元素独立采样，跨视角一致概率约 1.03×10−8。修复：掩码按环境采样并由说话者与跟随者共用，保留朝向与空间结构。
  • 把增广当环境多样性的替代：训练环境内铺满数据也换不到新场景的泛化。根因是覆盖收益存在上界（训练环境内回译仅 +1.7 点）。修复：先核对环境清单与质量闸门，再决定增广预算；把环境扩张与数据扩张的成本并列比较。
  • 低质数据直接进预训练：数据量增加 61% 而指标微降。根因是质量分层缺失，渲染缺陷被当作多样性。修复：按缺陷比例分层验收，先修复再合并；修复前后各跑一次同配方对照。

小结

  • 增广收益按剂量递减：SF 前 25% 剂量拿 2.9 点、效率 11.60，后 75% 只补 1.8 点、效率 2.40，比值 4.83；描述性饱和拟合上界约 4.82 点。
  • 环境多样性是主瓶颈：训练环境内回译只值 +1.7 点，真实新环境回译值 +15.4 点；后者属于预探索协议，必须单独标注。
  • 分布漂移的核心是语义一致：掩码绑定相对不绑定值 3.2 点（52.2 对 49.0）；独立特征掩码的跨视角一致概率约 1.03×10−8，几乎必然自相矛盾。
  • 泄漏有三条通道（场景级、监督级、近重复），审计手段依次是标识交集、依赖清单与相似度检索；评测集冻结与生成脚本隔离是共同修复。
  • 质量闸门决定扩张方向的正负：未修复 Gibson 数据增加 61% 时 −0.26 点，修复后同规模 +1.49 点。
  • 增广决策表以「下一剂量增量低于 0.5 点」为停止判据，投入顺序为覆盖、一致、规模。下一讲转入记忆范式总览：把四类记忆载体的内存、延迟、精度三笔账推导成训练预算表（第 066 讲）。
