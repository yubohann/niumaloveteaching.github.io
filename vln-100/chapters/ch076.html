第四篇 · 规模、记忆与泛化方法论

第 076 讲｜因果去偏（BACL / FACL）

第 075 讲把落差定位到低层视觉外观；本讲把定位结果转成干预机制。以 GOAT（Wang 等 2024，arXiv:2404.10241）为主线：用结构因果模型区分可观测与不可观测混淆因子，分别用后门调整（BACL，back-door adjustment causal learning）与前门调整（FACL，front-door adjustment causal learning）在特征层做干预，配合跨模态特征池化（CFP）与自适应门控（AGF），在 R2R、REVERIE、RxR 与 SOON 上给出可复核的消融；本讲推导两条调整公式，拆解字典与估计器设计，并写清因果假设的失效边界。

  • 主题：因果推断 / 混淆因子 / 后门与前门调整 / 去偏模块
  • 关键数字：R2R val unseen SR 77.82 / SPL 68.13；BACL 与 FACL 合用相对基线 +2.55 SR 与 +3.44 SPL（相对 +3.388% 与 +5.318%）；文本注意力加视觉统计的组合最优；FACL 聚类数取 24；CFP 预训练使未见 SR 从 40.36 升到 43.47
  • 预计学时：70 分钟
  • 前置讲：第 075 讲（偏差诊断方法学）

学习目标

  • 会画：VLN 的结构因果模型，标出输入 X（视觉 V、语言 I、历史 H）、动作输出 A、可观测混淆因子与不可观测混淆因子，并指出后门路径与中介路径。
  • 会推：do 演算下后门调整公式 P(A|do(X)) = Σz P(A|X,z)P(z) 与前门调整公式的两段期望形式，解释每一步的独立性条件。
  • 会实现：BACL 的字典与两类期望估计器、FACL 的双查询跨采样、CFP 的注意池化与对比损失、AGF 的门控融合。
  • 会算：消融表的单模块与组合增量、模态贡献、CFP 在预训练与微调两阶段的增益，以及字典更新与聚类数的影响。
  • 会判断：因果假设的可证伪边界、期望近似的误差来源、数字引用与歧义指令两类残留失效，以及因果干预与数据增广两条去偏路线的互补关系。

背景与动机

第 075 讲完成了诊断：落差主要来自低层视觉外观与空间局部性，语义特征替换可以收窄落差。诊断给出方向，处方还需要机制。GOAT 的出发点是数据偏置的循环：造数据集、发现偏差、再造数据集，循环难以终止，因为完全平衡的数据几乎不存在。论文选择把重心从数据转向模型，用因果推断（causal inference）的干预手段训练出对混淆因子不敏感的表示。

因果视角的基本观察是：模型学到的条件概率 P(A|X) 混入了混淆因子（confounder）的贡献。混淆因子同时影响输入分布与动作分布，制造虚假相关（spurious correlation）。在 VLN 中，房间类型、指令关键词、装修风格、句式习惯、轨迹趋势都会同时出现在输入与标签侧：厨房里常用「厨房」这个词，训练集中「向右转」常出现在某类走廊。模型记住这些共现后，在未见环境里遇到相同词句却无相同布局时会失效。GOAT 把混淆因子分成可观测与不可观测两类，分别用后门调整与前门调整处理，干预放在特征层，输出层保留分类头。

本讲先建立结构因果模型，推导两条调整公式，再拆解 BACL、FACL、CFP 与 AGF 的实现与消融，最后讨论假设边界。第 075 讲的诊断结论是本讲干预位置的依据：视觉是主要矛盾，BACL 的视觉干预在逐模态剔除中权重最高。因果去偏不消灭偏置，它把偏置从「模型记忆的捷径」改写为「显式建模并减权的变量」。

核心原理

本讲按「因果模型、后门推导、BACL 设计、估计器选择、前门推导、FACL 设计、CFP 与对比学习、门控与流水线、结果与消融、边界」十步展开。论文数字统一标注来源（arXiv:2404.10241v1，Wang 等 2024），实验协议为 R2R / REVERIE / RxR-English / SOON，评测指标含 SR、SPL、NE、OSR、RGS 等。

1. 结构因果模型：输入、输出与两类混淆因子

在时刻 t，智能体接收全景视觉 V（划分为 36 个子图）、指令 I 与历史 H，输出动作 A。记输入集合 X = {V, I, H}，输出 Y = A。传统方法拟合观测关联 P(Y|X)，而数据生成过程还包含混淆因子 Z：它同时指向 X 与 Y，形成后门路径 X ← Z → Y。例如「房间类型」影响图像外观与指令用词（Z → X），也影响专家在该场景选择的动作分布（Z → Y）。

GOAT 把 Z 分为两类。可观测混淆因子记 Zo，包括视觉房间指称（room reference，记为 zvo）与语言指引关键词（记为 zio，如方位词与地标词）。不可观测混淆因子记 Zu，包括视觉装修风格（zvu）、句式习惯（ziu）与轨迹趋势（zhu）。不可观测意味着无法预先枚举取值，FACL 为它们插入中介变量 M，构造前门路径 X → M → Y。两类处理合起来覆盖跨模态输入的主要偏差来源。

语言方位词与地标词（74 类）句式习惯BACL 文本 + FACL 文本注意力

2. 后门调整：公式与推导

贝叶斯展开给出观测似然：

P(Y|X) = Σz P(Y|X, z) · P(z|X) P(z|X) 携带偏置权重：训练分布里高频的 z 会放大对应动作的贡献

干预（intervention）用 do 算子把 X 的取值从数据生成机制中切断，删除所有指向 X 的边。切断后 Z 与 X 相互独立，独立性规则给出 P(z|do(X)) = P(z)，于是：

P(Y|do(X)) = Σz P(Y|do(X), z) · P(z|do(X)) = Σz P(Y|X, z) · P(z) 第一步用全概率展开；第二步用 P(z|do(X)) = P(z) 与 P(Y|do(X),z) = P(Y|X,z)；z 遍历混淆因子取值，P(z) 为无偏权重

实现层面，论文避开对最终 Softmax 的直接调整，改在特征层定义模块 f(x, z)，用线性分解 f(x, z) = fx(x) + fz(z)，则调整后的表示等于自身映射加混淆因子期望：

B(x, z) = Ez[f(x, z)] = fx(x) + Ez[fz(z)] B 为后门调整后的特征；x、z 分别为当前输入与混淆因子特征；Ez 在混淆因子字典上求期望

早期工作在输出层用归一化加权几何均值（NWGM，normalized weighted geometric mean）近似 Ez[Softmax(·)]，只调整最后的概率。GOAT 把干预提前到隐藏特征：调整发生在特征层，后续所有层天然使用无偏表示。消融验证了这一设计：只在最终 Softmax 前干预得 SPL 66.80，浅层干预得 68.13，差 1.33 个点。

3. BACL 设计：字典、特征与两类期望

文本侧，用词性标注抽取方位词与地标词，构成 74 类关键词字典。每个词的表示取 RoBERTa 在该词所有出现位置的平均，字典随端到端训练迭代更新。视觉侧，用 BLIP 以固定提问「what kind of room is this?」获取每张子图的房间信息，配合 CLIP 图像特征取平均形成 50 类房间字典；视角相对智能体的方位（航向角与俯仰角的正余弦）作为方向嵌入。两路分别得到文本因果表示 Gs 与视觉因果表示 Vv，再进入后续编码。

期望 Ez[fz(z)] 有两种估计器。统计估计按训练集中各类别频次加权：

Ez[fz(z)] = Σi (|zi| / Σj |zj|) · fz(zi) 统计估计器：|zi| 为训练集中第 i 类混淆因子的出现次数，权重与频次成正比

注意力估计用当前输入与字典条目打分后归一化：

Ez[fz(z)] = Σi softmax(h ziT)i · fz(zi) 注意力估计器：h 为当前隐藏特征，zi 为第 i 类混淆因子特征；权重随输入变化

两种估计器的组合实验（R2R val unseen，SPL 与 SR）给出一个稳定的交互结论：文本统计加视觉统计为 64.78 与 75.22，文本统计加视觉注意力为 65.39 与 76.59，文本注意力加视觉统计为 68.13 与 77.82，双注意力为 65.83 与 75.95。最优组合是文本注意力、视觉统计。论文解释：文本结构化程度高且 RoBERTa 参与端到端训练，注意力能捕捉上下文差异；图像缺少显式因果结构且 CLIP 在实现中不参与训练，统计估计更稳定。估计器选择与方法假设绑定，属于一阶决策，不能当实现细节处理。

4. 前门调整：中介变量与两段期望

不可观测混淆因子无法枚举，后门路径不可切断，改用前门路径 X → M → Y：在输入与输出之间插入中介变量 M，它由输入选出，又参与动作预测。对 X 与 M 同时施加 do 算子：

P(Y|do(X)) = Σm P(m|do(X)) Σx′ P(x′) · P(Y|m, x′) = Ex′ Em|x[P(Y|m, x′)] m 为当前输入选出的中介特征；x′ 为整个表示空间中的潜在输入样本，与当前样本 x 不同；第一段期望对 x′ 采样，第二段对 m 在给定 x 下的分布求期望

在线性映射假设 f(x, m) = fx(x) + fm(m) 下，期望分解为两项之和 Em|x[m] + Ex′[x′]。两项都用注意力近似：一个查询 g1 = q1(x) 对全训练集的特征分布打分，得到跨采样期望 Ex′[x′]；另一个查询 g2 = q2(x) 对当前输入选出的中介特征打分，得到内采样期望 Em|x[m]。两项相加构成前门调整特征 F(x, x′)。实现上就是两组查询各自对问题集做一次多头注意力，因此可以直接嵌入既有 Transformer，改动量小。

跨采样集合的构造用 K 均值聚类：在预训练阶段用 CFP 抽出全局特征，对全训练集特征做聚类，聚成 24 类；微调阶段从聚类中心采样特征充当 x′。聚类的角色是把连续表示空间压缩成有限「风格原型」。聚类数太少会漏掉关键区分，太多会引入冗余与噪声，论文的扫描在 24 处取得 SR 与 SPL 双优。字典不是一次生成的常量：文本字典随 RoBERTa 更新，FACL 字典每隔 3,000 次迭代或 val unseen 出现更优时刷新，刷新带来约 +1.93 SPL。

5. CFP 与对比学习：把长序列压成全局特征

前门调整需要「每个样本一个全局特征」，而视觉、历史、指令序列长度可变，直接平均池化会丢失语义。CFP 模块先用一层 Transformer 编码，再做注意力池化：

A = tanh(H)， α = softmax(A Wa)， H̄ = tanh(αT H) H 为序列特征 [L, d]；Wa 为可学习列向量；α 为 [L] 权重；H̄ 为 [1, d] 全局特征

全局特征用对比学习对齐模态。对视觉全局特征 C̄l 与文本全局特征 C̄s，双向 InfoNCE 损失为：

Lls = −(1/2B) Σj log [exp(⟨C̄jl, C̄js⟩/t) / Σk exp(⟨C̄jl, C̄ks⟩/t)] − (1/2B) Σk log [exp(⟨C̄kl, C̄ks⟩/t) / Σj exp(⟨C̄jl, C̄ks⟩/t)] B 为批大小，t 为温度（取 1）；另有历史与融合两路的同类损失 Lgs 与 Lfs，总损失为三者之和

CFP 有两个用途：预训练阶段作为辅助任务改善跨模态对齐，微调阶段提供前门字典的全局特征。消融显示：预训练加 CFP 使 R2R val unseen 的 SR 从 40.36 升到 43.47（+3.11，相对 7.706%），SPL 从 37.88 升到 40.90（+3.02，相对 7.973%）；微调阶段用 CFP 池化替换平均池化，SPL 从 66.17 升到 68.13（+1.96，相对 2.962%）。

6. 门控融合与训练流水线

因果特征与原始上下文特征不互相替代，用自适应门控 AGF（adaptive gate fusion）按通道融合：

ω = δ(Rx Wx + Gx Wg + b)， Ux = ω ⊙ Rx + (1 − ω) ⊙ Gx Rx 为因果增强特征，Gx 为原始上下文特征，δ 为 Sigmoid，⊙ 为逐元素乘；去掉门控在 R2R val unseen 上损失 1.11 SPL

完整流水线为六步：任务形式化；显式写出可观测与不可观测混淆因子假设；构造字典与中介；选择估计器并计算调整特征；门控融合后进入跨模态编码与动作预测；训练中持续更新网络参数与混淆因子特征。配置方面：文本 6 层、全景 2 层、跨模态 3 层 Transformer；视觉用 CLIP-B/16 抽取，权重以 METER 初始化；预训练目标为掩码语言建模（MLM）、单步动作预测（SAP）与 CFP，目标导向任务另加物体定位目标；特征增广采用 EnvEdit；并在 R2R、REVERIE、RxR 上使用各自的合成扩展数据集。预训练在单块 Tesla V100 上最多 30 万次迭代，批大小 48，学习率 5e-5；微调最多 10 万次迭代，R2R 与 REVERIE 批大小 12、RxR 与 SOON 批大小 5，学习率 2e-5。说话人模型配合环境 dropout 提供动态伪标签。

7. 结果与消融：怎么读这张表

R2R 主表中，GOAT 的 val seen 为 SR 83.74 / SPL 79.48，val unseen 为 77.82 / 68.13，test unseen 为 74.57 / 64.94。对照组 BEVBert 为 81 / 74、75 / 64、73 / 62，三个子集的 SPL 相对提升分别为 7.405%、6.453% 与 4.742%（论文取整写作 7.41%、6.45%、4.74%）。与 DUET 的 val unseen 相比，SPL 提升 8.13（相对 13.550%）。跨任务结果：REVERIE val unseen 为 SR 53.37 / SPL 36.70 / RGS 38.43 / RGSPL 26.09；RxR-English val unseen 为 SR 68.2 / SPL 61.7 / nDTW 67.1 / sDTW 56.6；SOON val unseen 为 OSR 54.69 / SR 40.35 / SPL 28.05 / RGSPL 5.85。

模块消融（R2R val unseen）是理解本讲的关键：基线 75.27 / 64.69 / NE 2.72 / OSR 83.14；只用 BACL 为 76.37 / 67.13 / 2.60 / 83.99；只用 FACL 为 76.50 / 66.92 / 2.53 / 84.21；两者合用为 77.82 / 68.13 / 2.40 / 84.72。换算增量：BACL 单独 +1.10 SR 与 +2.44 SPL，FACL 单独 +1.23 SR 与 +2.23 SPL，合用 +2.55 SR 与 +3.44 SPL（相对 +3.388% 与 +5.318%）。两类混淆因子同时存在，单用一类只能拿走一部分增益。

逐模态剔除给出权重分布：BACL 去掉文本损失 1.76 SPL，去掉视觉损失 2.82；FACL 去掉文本损失 0.81，去掉视觉损失 1.06，去掉历史损失 2.12。视觉干预在 BACL 中权重最高，与第 075 讲的诊断互相印证；历史干预在 FACL 中增益突出。字典不更新损失 1.93，去掉门控损失 1.11，只在输出层干预损失 1.33。数字引用备注：论文正文写视觉剔除使 SR 下降 1.81%，按表格数值相减为 1.87%，相差 0.06 个百分点，本讲以表格为准并保留该口径说明。读消融表先看绝对值行，再看逐项剔除行，前者回答「总体贡献」，后者回答「谁不可或缺」。

8. 因果去偏的两条路线与失效边界

因果思路下有两条技术路线。第一条是干预调整，对混淆因子做后门或前门修正，代表为 GOAT 的 BACL 与 FACL；第二条是反事实数据增广，构造「若混淆因子取另一值，输入与标签会怎样」的配对样本，逼迫模型学习不变性，这一路线与第 065 讲的增广风险、第 074 讲的边界纪律共用同一套检查。两条路线互补：调整作用于模型内部表示，增广作用于数据分布。GOAT 自身也使用 EnvEdit 做特征级增广，说明两者可以叠加。

边界必须写清。其一，结构因果模型的假设不可由数据直接检验，选择「哪些变量进字典、哪些进中介」依赖先验；换一个假设，公式不变，结论的适用范围改变。其二，期望计算用注意力近似，论文明确把近似过程与模态偏好差异列为局限。其三，偏置被减权，未被清零：残留失效包括指令中的数量引用（把第 5 把椅子误判为第 8 把）与本身有歧义的指令（两个卧室都符合描述）。其四，因果方法无法补救数据边界缺陷：若评测样本已进入训练，任何干预都在偏置的地基上工作，第 074 讲的检查仍是前置条件。其五，字典与聚类引入额外状态，K 均值扫描显示聚类数与开销、噪声存在权衡。效率方面，论文用 thop 统计 GFLOPs，统一以批大小 8、指令长度 44、历史全局图节点 6 的单步前向对比，GOAT 以更少的 Transformer 层数在更低计算量下取得更高 SR 与 SPL，说明轻量骨干与因果干预可以同向。

关键代码与解读

三段代码分别给出后门调整、前门调整与 CFP 加门控融合的实现骨架。张量维度按论文设置简化，注释说明每处设计的原因；完整训练循环依赖仿真数据管线，接口以公开实现的设计为参照。

片段 1：后门调整模块 BACL

import torch
import torch.nn as nn
import torch.nn.functional as F

class BackdoorAdjust(nn.Module):
    """BACL：B(x, z) = f_x(x) + E_z[f_z(z)]，特征层干预。"""
    def __init__(self, dim=768, n_z=74, mode_text="attention",
                 mode_vision="statistic"):
        super().__init__()
        self.fx = nn.Linear(dim, dim)                 # 输入自身映射
        self.fz = nn.Linear(dim, dim)                 # 混淆因子映射
        self.dict = nn.Parameter(torch.randn(n_z, dim))   # 字典特征
        self.register_buffer("counts", torch.ones(n_z))   # 类别频次
        self.mode = {"text": mode_text, "vision": mode_vision}
    def expectation(self, query, modality):
        z = self.dict                                 # [K, d]
        if self.mode[modality] == "statistic":
            w = self.counts / self.counts.sum()       # 频次权重，与输入无关
        else:
            w = F.softmax(query @ z.t(), dim=-1)      # 注意力权重，随输入变化
        return w @ self.fz(z)                         # 加权期望 [B, d]
    def forward(self, x, modality):
        return self.fx(x) + self.expectation(x, modality)

# 组合消融（R2R val unseen SPL）：文本统计 + 视觉统计 64.78
# 文本注意力 + 视觉统计 68.13 为最优；估计器与模态假设绑定

解读：（1）字典作为可学习参数，文本字典随 RoBERTa 端到端更新，视觉字典按房间类别取均值后冻结；（2）统计权重用缓冲区保存，不参与梯度，保证频次语义稳定；注意力权重由当前输入打分，适合上下文敏感的文本；（3）干预发生在特征入口，后续所有编码层共享无偏表示，与只在 Softmax 前干预形成对照。

片段 2：前门调整模块 FACL

class FrontDoorAdjust(nn.Module):
    """FACL：E_{x'}[x'] + E_{m|x}[m]，x' 来自聚类字典。"""
    def __init__(self, dim=768, n_cluster=24):
        super().__init__()
        self.q1 = nn.Linear(dim, dim)                    # 跨采样查询
        self.q2 = nn.Linear(dim, dim)                    # 内采样查询
        self.value = nn.Linear(dim, dim)                 # 中介特征映射
        self.cluster = nn.Parameter(torch.randn(n_cluster, dim))  # K-means 中心
    def forward(self, x):
        g1 = self.q1(x)                                  # 查询全空间特征分布
        w_x = F.softmax(g1 @ self.cluster.t(), dim=-1)
        exp_x = w_x @ self.cluster                       # E_{x'}[x']  [B, d]
        m = self.value(x)                                # 当前样本的中介特征
        g2 = self.q2(x)                                  # 查询当前中介
        w_m = F.softmax(g2 @ m.t(), dim=-1)
        exp_m = w_m @ m                                  # E_{m|x}[m]  [B, d]
        return exp_x + exp_m

# 聚类数扫描以 24 为最优：过少漏区分，过多引入噪声与开销
# 两段期望合并后经 AGF 门控与上下文特征融合

解读：（1）两段期望对应前门公式的两个因子，跨采样项提供全数据分布的无偏参照，内采样项保留当前样本的中介信息；（2）聚类中心替代真值分布，把连续空间离散成 24 个风格原型，微调阶段按周期从中心附近采样；（3）实现上是两组查询对两组键值做注意力，可直接用多头注意力替换，改动量小。

片段 3：CFP 注意池化、对比损失与门控融合

class CFP(nn.Module):
    """跨模态特征池化：注意力池化出全局特征，门控融合因果特征。"""
    def __init__(self, dim=768, nhead=8):
        super().__init__()
        self.enc = nn.TransformerEncoderLayer(dim, nhead=nhead,
                                              batch_first=True)
        self.wa = nn.Linear(dim, 1)                      # 池化打分向量
        self.gate = nn.Linear(2 * dim, 1)                # AGF 门控
    def pool(self, h):
        a = torch.tanh(self.enc(h))                      # [B, L, d]
        alpha = torch.softmax(self.wa(a).squeeze(-1), -1)  # [B, L]
        return torch.tanh(alpha.unsqueeze(1) @ a).squeeze(1)
    def fuse(self, r, g):
        omega = torch.sigmoid(self.gate(torch.cat([r, g], -1)))
        return omega * r + (1 - omega) * g               # AGF 输出

def info_nce(a, b, t=1.0):
    """双向对比损失：视觉全局特征与文本全局特征互为目标。"""
    logits = a @ b.t() / t
    labels = torch.arange(a.size(0), device=a.device)
    return 0.5 * (F.cross_entropy(logits, labels)
                  + F.cross_entropy(logits.t(), labels))

# CFP 进预训练：R2R val unseen SR 40.36 -> 43.47（相对 7.706%）
# 去掉 AGF 损失 1.11 SPL；字典不更新损失 1.93 SPL

解读：（1）池化权重经 tanh 与 softmax 生成，长度可变序列压缩为单向量，供前门字典与对比学习共用；（2）InfoNCE 取双向平均，避免只把视觉对齐到文本的单侧约束；（3）门控让模型自行决定每个通道上因果特征与原始特征的比例，消融显示直接替换会损失 1.11 SPL。

常见误区

  • 两种估计器混着用不做消融：凭直觉给所有模态上注意力，R2R val unseen 的 SPL 从 68.13 掉到 65.83。根因是忽略模态属性与编码器是否参与训练。修复：按模态做四象限组合实验，文本用注意力、视觉用统计作为默认起点，更换编码器后重新验证。
  • 字典一次构建后冻结：预训练初期的字典特征与后期权重不匹配，损失约 1.93 SPL。根因是把字典当静态资源。修复：按周期或验证最优点刷新，刷新记录写入实验日志；刷新频率过高会引入噪声，先用 3,000 次迭代量级验证。
  • 只在输出层干预：照搬早期方法把调整放在 Softmax 前，损失 1.33 SPL。根因是忽略隐藏特征层的偏置。修复：把干预模块移到特征入口或浅层，保留输出层为最终分类头，用对照实验确认增益。
  • 把因果假设当成已证事实：结论措辞写成「消除偏置」，但假设不可检验、期望为近似。根因是混淆「减权」与「清零」。修复：措辞改为缓解，给出残留失效清单（数字引用、歧义指令），并把结构假设与近似误差写进局限。
  • 用因果去偏掩盖数据边界问题：评测集已泄漏时仍期待干预模块修复指标。根因是忽略第 074 讲的前置条件。修复：先过边界检查与交集矩阵，再谈去偏；边界不干净时降级结论，不做因果归因。

练习与思考

  1. 消融计算：R2R val unseen 基线与完整模型为 75.27 / 64.69 与 77.82 / 68.13（SR / SPL）。计算合用两类调整的绝对增量与相对增量；再算只用 BACL（76.37 / 67.13）时 SPL 增量占合用的比例。 ★
    提示
    绝对 +2.55 SR 与 +3.44 SPL；相对 +3.388% 与 +5.318%。BACL 的 SPL 增量为 2.44，占合用的 2.44 / 3.44 ≈ 70.9%，说明两类调整覆盖的混淆因子部分重叠但各自不可替代。
  2. 公式推演：从 P(Y|X) = Σz P(Y|X,z)P(z|X) 出发，逐步写出后门调整公式，说明每一步用到哪条独立性。再给定四类关键词频次 200、100、60、40，计算统计估计器的权重。 ★
    提示
    干预删除指向 X 的边后，z 与 X 独立：P(z|do(X)) = P(z)；同时 P(Y|do(X),z) = P(Y|X,z)，两式代入并展开全概率。权重总和 400：0.5、0.25、0.15、0.10。
  3. 估计器选择：给出文本估计器与视觉估计器的四种组合读数（文本统计 / 视觉统计 64.78，文本统计 / 视觉注意力 65.39，文本注意力 / 视觉统计 68.13，文本注意力 / 视觉注意力 65.83，单位 SPL）。计算两个模态的边际变化并解释交互效应；若把文本编码器替换为冻结模型，预测最优组合的变化方向。 ★★
    提示
    视觉固定统计时，文本从统计换注意力 +3.35；视觉固定注意力时 +0.44。文本固定统计时，视觉换注意力 +0.61；文本固定注意力时，视觉换注意力 −2.30。存在交互：注意力文本与统计视觉互补。冻结文本编码器后，注意力失去端到端更新优势，最优组合可能回到双统计或统计文本，需重新扫描。
  4. 超参预测：把 FACL 聚类数从 24 改为 8 与 64，预测 SR / SPL 的方向与训练开销变化，并写出验证方案与两条判据。 ★★
    提示
    8 类可能欠分割，风格原型合并，SR 与 SPL 下降；64 类可能过分割，噪声与开销上升，指标先平后降。验证方案：固定其他超参，对 8、16、24、32、64 扫描，记录显存与单步延迟。判据一：扫描曲线在 24 附近出现峰值；判据二：最优档位的逐模态剔除仍保持正增益。

    提示
    (a) 可观测：房间类型、深度中的障碍类别；不可观测：渲染风格、相机高度、轨迹趋势。(b) 深度可作为视觉中介或独立中介，干预放在深度编码器输出与跨模态融合之间。(c) 深度字典用几何类别统计，更新按验证最优点或固定周期。(d) 单模块消融看总体贡献，逐模态剔除看不可替代性，报告 SR / SPL / NE / 样本量。(e) 失效：干预后落差不变（假设不成立）；真实机与仿真趋势相反（近似失效）；数字引用与歧义指令残留；措辞用缓解与残留清单，不用消除。

小结

  • 结构因果模型把 VLN 输入 X = {V, I, H} 与动作 A 之间的虚假相关归因于混淆因子：可观测项包括 74 类关键词与 50 类房间指称，不可观测项包括装修风格、句式习惯与轨迹趋势。
  • 后门调整为 P(A|do(X)) = Σz P(A|X,z)P(z)，实现形式为特征层 fx(x) + Ez[fz(z)]；统计估计按频次加权，注意力估计随输入打分，文本注意力加视觉统计的组合在 R2R 达 68.13 SPL。
  • 前门调整插入中介：P(A|do(X)) = Ex′Em|x[P(A|m, x′)]，用两段注意力期望实现，跨采样来自 24 类 K 均值中心，字典每 3,000 次迭代或验证更优时刷新，刷新贡献 +1.93 SPL。
  • CFP 用注意池化与双向 InfoNCE 支撑全局特征与模态对齐：预训练加 CFP 使未见 SR 从 40.36 升到 43.47，微调替换平均池化使 SPL 提升 1.96；AGF 门控融合避免直接替换，缺少门控损失 1.11 SPL。
  • 组合消融：BACL 单独 +2.44 SPL、FACL 单独 +2.23 SPL、合用 +3.44 SPL；逐模态剔除中 BACL 视觉与 FACL 历史权重最高，与第 075 讲的视觉诊断结论互证。
  • 边界：假设不可检验、期望为近似、偏置被减权，未被清零，残留失效含数字引用与歧义指令；因果去偏不能替代第 074 讲的数据边界检查，结论措辞用缓解与残留清单。
