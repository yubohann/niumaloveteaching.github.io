第四篇 · 规模、记忆与泛化方法论

第 080 讲｜第四篇回顾：数据-表征-泛化闭环

本讲把第四篇 19 讲（061 至 079）收成一个闭环：数据环决定监督供给，表征环决定历史与空间信息能装下什么，泛化环决定这些投入能不能落到未见环境与真机；协议层横跨三环，任何一条结论都由三者与协议共同决定。学完能用一套审计器复核任意一条第四篇式结论，并看清它与第五篇基础模型接口的衔接点。

  • 主题：阶段回顾 / 方法论闭环 / 协议审计 / 第五篇接口
  • 关键数字：规模 352.35 倍、表征 +4.42 SR、少样本 +21.98 SR、协议差 11 点（17.74%）、真机 61 到 22（降 63.93%）
  • 预计学时：60 分钟
  • 前置讲：第 079 讲（评测公平性）

学习目标

  • 会算：数据环的规模倍数与密度比、表征环的误差折算、泛化环的失效代价（质量闸门、泄漏稀释、漂移累计）。
  • 会解释：三环各自的控制变量与协议标签，为什么不同环的增益不能直接相加。
  • 会实现：闭环审计器、数据台账与投入决策器三段示意代码，把回顾变成可执行流程。
  • 会判断：给定一条结论，判定归属环别、协议级别与失效风险，并给出降级或补实验的处理方式。
  • 会设计：阶段自测卡，以及从第四篇走向第五篇基础模型接口的选择表。

背景与动机

第四篇围绕三个问题推进：监督从哪里来（061 至 065）、历史与空间信息装在什么载体里（066 至 072）、训练与检验怎么做才可信（073 至 079）。路径回顾章在前面出现过两次：第 020 讲统一任务、数据与评测的公共语言，第 040 讲对比 seen 到 unseen 的两条路线，第 060 讲绘出仿真到现场的差距地图。本讲要给第四篇一个不同于清单罗列的收束方式：把三个问题串成一条有输入输出、有失效模式的闭环。

闭环的必要性来自第 079 讲的结论：数字是协议的产物。数据环的 352.35 倍规模、表征环的 +4.42 SR、泛化环的 +21.98 SR 分属不同协议，放在一张排名表里就会重演 62 到 73 的协议跳变。回顾的任务因此包含两件事：把每一环的代表性证据按协议登记，再把单环失效的代价量化，让读者知道哪个环节的投入最容易蒸发。

本讲还承担与第五篇的接口任务。Zhang 等 2024 的综述（arXiv:2407.07035v2，发布于 OpenReview，标题 Vision-and-Language Navigation Today and Tomorrow: A Survey in the Era of Foundation Models）用世界模型、人类模型、智能体模型三块组织 VLN 方法；Wang 等 2026 的综述与真机评测（arXiv:2607.09792，IEEE TASE 2026 录用）把方法按层次式与单体式、判别式与生成式两维分类，并报告单体 RGB 方法在仿真 61 成功率、真机降到 22（10 个真实场景）。这两个来源说明第四篇闭环仍然成立，只是闭环里新增了一个通用模型节点，节点以什么接口接入由下一讲展开。

核心原理

本讲按「闭环定义、三环证据、全景表、失效表、第五篇接口」五步回顾。所有数字沿用各讲口径，并在表格中标注协议标签。

1. 闭环定义：三环加一层协议审计

2. 数据环：规模账与质量账必须同报

规模账用三个分母同时呈现（来源：ScaleVLN，061 讲；分母为 R2R 训练集 14,025、R2R 全量 21,567、PREVALENT 自述 178,270）：4,941,710 条指令轨迹对分别是 352.35 倍、229.13 倍、27.72 倍。只报 352.35 会夸大相对成熟基线的优势，三分母并排后读者才能自行选择参照系。密度账更能暴露结构差异：ScaleVLN 每场景 3,827.8 条，R2R 训练集每场景 229.92 条，密度比 16.65；场景维度是 1,291 对 MP3D 90，即 14.34 倍，HM3D 单独是 11.11 倍。规模增长同时来自场景覆盖面与单场景采样密度，两类增长的泛化含义不同，回顾时必须拆开。

质量账给出规模的反例：Gibson 数据未修复时，环境数增加 61%，val-unseen SR 从 76.59 降到 76.33（−0.26），修复后同规模升到 78.08（+1.49），前后摆幅 1.75 个点；BnB 数据工程的清洗留存率为 46.300%，超过一半原始素材未进入训练。质量闸门没通过时，数据环的边际收益为负，投入应优先转向修复与清洗。

预算账区分两种训练阶段：预训练按 256 批大小、20,000 次迭代采样 5,120,000 个样本，对 4.94M 语料约为 1.036 遍；微调按 16 批大小、200,000 次迭代采样 3,200,000 个样本，对 14,025 条训练语料约为 228.16 遍。两个阶段的「遍数」量级相反，混在一起谈数据效率会得出错误结论。生成成本在原始工作中未完整报告，属于当前公开信息下的已知缺口。

3. 表征环：三类载体、一张预算式、一本误差账

表征环的载体分三类：记忆（066 的预算式）、地图（067 的局部度量、068 的全局拓扑、069 的网格）、历史与监督信号（070 至 072）。记忆预算式为：

M训练 ≈ B·(M载体 + M键值 + M激活) + M观察 B 为批大小；载体账只是入口，键值、激活与观察缓存必须同表计量（第 066 讲）

结构收益有对照：BEVBert 式混合地图在 R2R val-unseen（估计深度口径）为 74.67 SR，只用拓扑 70.25，只用度量 60.64，混合相对拓扑 +4.42，相对度量 +14.03；GridMM 的网格分辨率从 8 升到 20，SR 从 47.07 升到 49.86（+2.79，相对 5.93%），论文默认取 14 作为收益代价比的拐点。历史侧的成本核算同样具体：不缓存时单步视图编码量为 36t，缓存摘要后降到 36，t = 20 时相当于 720 对 36；层级融合相对全铺开方案的注意力矩阵比值为 33.37。

误差账决定表征环的上限：以 0.5 米每格的 BEV 为例，单次量化偏差 0.289 格折合 0.1445 米，30 步随机游走累计 2.18 格折合 1.09 米；可靠距离上界 r < c/(2δψ)，在 2 度朝向噪声下为 7.16 米。表征不是越精细越好，误差随距离与步数累积，局部地图的可靠半径应写入系统约束。

4. 泛化环：诊断、去偏、迁移、少样本与公平五件套

泛化环的证据按五条线登记。偏差诊断（075）：已见与未见的落差在不同设置下从 8.6 到 30.9 个点，极值比 3.59；控制语言与导航图后定位到低层视觉外观，语义分割特征把 R2R、R4R、CVDN 的落差收窄 91.860%、84.519%、60.282%。因果去偏（076）：BACL 单独 +2.44 SPL、FACL 单独 +2.23 SPL、合用 +3.44 SPL。跨语言迁移（077）：ResNet 基线 35.1 到双表示 40.4（+5.3 SR），CLIP 基线 41.7 到 44.4（+2.7）。少样本（078）：6 环境从 35.99 升到 57.97（+21.98，相对 61.07%），单环境比值 2.229，全环境只升 8.45，边际收益快速递减。公平审计（079）：62 到 73 的 11 个点（17.74%）几乎全部来自解码与集成，与方法本身无关。泛化环的每条线都自带协议，登记时必须同时记录 split、训练规模与推理预算，否则回顾会再次制造第 079 讲要消除的假排名。

7. 与第五篇的接口

第五篇把闭环里的「表征」与「策略」两块交给通用模型补强。Wang 等 2026（arXiv:2607.09792）给出的分类骨架是两维：动作范式分层次式与单体式，模型范式分判别式与生成式；真机评测显示单体 RGB 方法在仿真为 61 成功率，真机降到 22，降幅 63.93%，保留比例 36.07%；层次式框架真机为 51，比单体真机高 29 个点（相对 131.82%）。总结论是：仿真排名不能直接外推真机，接口形态（单体对层次）本身是影响真机落地的变量，这一点将由第五篇逐讲展开。Zhang 等 2024（arXiv:2407.07035v2）的框架则把方法归入世界模型、人类模型与智能体模型三块，通用模型可以分别接入三块，形成文本、地图、价值、动作四类接口，具体的类型学与预算账放在 081 讲。

实现思路与设计

回顾的产出物是两张可复用工件：闭环审计流程与阶段自测卡。设计目标是把「读完记得」变成「下线前填完」。

闭环审计五步

  1. 圈环：给结论标注 D、R、G 或 Π，混合结论拆成多条单环结论。
  2. 取协议：按第 079 讲十二项抽取字段，缺项标注「未声明」。
  3. 分级：同协议可比允许排名，近似可比并排分解，不可比只做定性陈述。
  4. 算失效：对每条结论找一条同尺度对照（质量闸门、漂移、泄漏、协议差）并量化。
  5. 落卡：把结论、协议、失效对照与下一步实验写入阶段自测卡，卡片按环分组。
设计决策：单环登记，跨环不求和

审计器在数据结构层面禁止把不同环的增益字段相加：每条记录只携带一个环标签与一个协议元组。把禁止求和写成类型约束，让流程替代写作纪律，是这套流程可复制的关键。

投入决策器

沿用第 065 讲与第 070 讲的判据：当某一环的下一剂量低于 0.5 个点时停止该环投入，把预算转向质量、表征或数据。决策器输入为各环候选剂量及其协议标签，输出下一笔预算的投向，并在剂量不足时输出停止原因。

关键代码与解读

三段代码分别给出闭环审计器、数据台账与投入决策器。均以第四篇公开设计为参照的示意实现。

片段 1：闭环审计器（环别、协议与风险标记）

from dataclasses import dataclass, field

HARD_FIELDS = ("split", "max_steps", "stop_rule")

@dataclass
class LoopClaim:
    text: str                     # 结论原文
    link: str                     # "data" / "repr" / "generalization"
    protocol: dict = field(default_factory=dict)
    numbers: dict = field(default_factory=dict)
    flags: list = field(default_factory=list)

def audit_claim(claim, baseline, marginal_gain=0.0, threshold=0.5):
    """三环审计：硬字段不同即降级；质量与边际阈值触发风险标记。"""
    diff = [k for k in HARD_FIELDS
            if claim.protocol.get(k) != baseline.get(k)]
    if diff:
        claim.flags.append("protocol_diff:" + ",".join(diff))
        claim.flags.append("qualitative_only")   # 不可比，只做定性陈述
    if claim.link == "data" and claim.numbers.get("retention", 1.0) < 0.5:
        claim.flags.append("quality_gate")       # 质量账未过，规模收益可为负
    if marginal_gain < threshold:
        claim.flags.append("shift_investment")   # 低于 0.5 点，转投其它环
    return claim
# 例：数据环登记 352.35 倍与留存率 46.300%，表征环登记 +4.42 SR

解读：（1）每条结论只允许一个环标签，从数据结构上堵住跨环求和。（2）硬字段（split、步数上限、停止判定）不同直接降级为定性陈述，对应第 079 讲三级判定的最严一档。（3）质量闸门与边际阈值是第四篇特有的两条业务规则，用数值标记替代文字提醒，输出可直接进入阶段自测卡。

片段 2：数据台账（倍数、密度与质量同报）

def data_ledger(pairs, scenes, base_pairs, base_scenes, retention):
    """规模账必须携带三个分母与一个质量指标，避免单一倍数叙事。"""
    per_scene = pairs / scenes
    base_density = base_pairs / base_scenes
    return {
        "pair_ratio": round(pairs / base_pairs, 2),        # 352.35（对 R2R 训练集）
        "scene_ratio": round(scenes / base_scenes, 2),     # 14.34（对 MP3D 90 场景）
        "density_ratio": round(per_scene / base_density, 2),  # 16.65
        "per_scene": round(per_scene, 1),                  # 3,827.8
        "retention": round(retention, 3),                  # 0.463（BnB 口径）
    }
# 质量闸门示例：Gibson 未修复 -0.26，修复 +1.49，摆幅 1.75

解读：（1）三个分母分别对应训练集、全量与更早的预训练语料，读者可按自己的参照系复核，这是第 061 讲对 4.62 倍冲突的处理方式。（2）密度比与场景比分开，揭示「同样的规模增长可以来自覆盖，也可以来自采样」。（3）留存率与规模同结构返回，调用方无法只取倍数而忽略质量。

片段 3：投入决策器（边际剂量低于阈值即转移）

def next_investment(doses, threshold=0.5):
    """doses 为 (环, 候选剂量) 列表，剂量单位为百分点且协议必须相同。"""
    usable = [(k, v) for k, v in doses if v >= threshold]
    if not usable:
        return {"action": "stop_all",
                "reason": "所有候选剂量低于 %.1f 点" % threshold}
    link, gain = max(usable, key=lambda kv: kv[1])
    return {"action": "invest", "link": link,
            "expected_gain": gain,
            "note": "单变量推进；换协议需重算剂量"}
# doses = [("data-scale", 2.9), ("synthesis", 1.8), ("repr-map", 2.79)]

解读：（1）阈值 0.5 点来自第 065 讲的停止判据与第 070 讲的边际比较，剂量必须带协议标签才允许进入比较。（2）决策器只选一项，强制单变量推进；多项同时上调会让下一轮消融无法归因。（3）全部候选低于阈值时返回停止并给出原因，把「不投」也变成显式决策。

常见误区

  • 跨环增益求和：把数据环 11 点、表征环 4.42 点、协议环 11 点相加得出「总进步」。根因是环间协议不同且控制变量不同。修复：按片段 1 的单环登记，跨环只做定性组合陈述，需要合计时必须先补同协议消融。
  • 只报规模不报质量：引用 352.35 倍时省略留存率 46.300% 与 Gibson 摆幅 1.75。根因是规模叙事更醒目。修复：规模账与质量账同表出现；质量未过闸门时规模结论降级。
  • 预训练与微调预算混报：把 1.036 遍与 228.16 遍写成同一个「训练量」。根因是两阶段的分母不同（4.94M 语料对 14,025 条）。修复：分阶段列采样量与分母，禁止合并。
  • 协议差冒充方法差：把 62 到 73 的跳变归因于模型结构。根因是解码与集成预算没有登记。修复：按第 079 讲分解差值，11 点（17.74%）标注为推理预算贡献。
  • 把仿真排名外推真机：用仿真排序预测真机表现。根因是忽略接口形态与域间落差。修复：仿真与真机分表；单体 RGB 的 61 到 22（降 63.93%）与层次式的真机 51 作为两个独立结论陈述（arXiv:2607.09792，10 个真实场景）。

小结

  • 第四篇 19 讲收成三环一审计：数据环管监督供给与质量，表征环管记忆与空间信息预算，泛化环管跨环境与跨域落地，协议层限定三环数字的可比性。
  • 数据环规模账要三分母并报：352.35、229.13、27.72 倍；密度比 16.65；质量反例为 Gibson 摆幅 1.75 与 BnB 留存率 46.300%；预训练 1.036 遍与微调 228.16 遍必须分阶段登记。
  • 表征环代表增益：混合地图 +4.42 SR、网格分辨率 +2.79 SR、MLM +13.28 SR；代价账为量化 0.1445 米、30 步漂移 1.09 米、可靠半径 7.16 米。
  • 泛化环五条线自带协议：落差 8.6 至 30.9、去偏 +3.44 SPL、跨语言 +5.3 SR、少样本 +21.98 SR（相对 61.07%）、协议差 62 到 73（17.74%）。
  • 闭环失效表把质量缺口、表征漂移、历史有损、目标饱和、泄漏与协议错配量化到具体点数，任一失效都足以吞掉相邻环节的投入。
  • 与第五篇的接口已经出现：真机上单体 RGB 从仿真 61 降到 22（降 63.93%），层次式真机 51；下一讲把通用模型接入闭环的方式整理成文本、地图、价值、动作四类接口，并给出选择判据（第 081 讲）。
