第三篇 · 协同控制与任务协同

第 055 章：多机器人围捕任务

从"盯住"到"围住"：把 N 台追击者均匀地摊到目标周围的圆环上，用分布式角度分配防止扎堆与交叉，用角度间隙与距离双判据确认合围，并处理逃逸者的反制。

  • 主题：任务协同 / 围捕与合围控制
  • 关键机制：环上角度分配、目标速度前馈、角度间隙判据、掉线重分配
  • 预计学时：60 分钟
  • 前置章节：第 054 章

学习目标

  • 理解围捕问题的目标构型：以目标为中心、半径 R 的环上均匀角分布，以及"均匀"对捕获的含义。
  • 会推导角度分配的两套实现：集中式等分与分布式"排序 + 圆上最小移动"匹配，能解释为什么必须防交叉。
  • 掌握围捕控制律：目标速度前馈 + 环位误差反馈，理解它与 042 章编队跟随的异同。
  • 会设计捕获判据：最大角度间隙、距离容差、速度可捕获性条件三者的组合。
  • 能设计掉线与目标机动下的角度重分配（含滞回），并分析逃逸者"最大间隙突逃"的反制方案。

背景与动机

054 章让队伍能持续估计一个移动目标的位置与速度。围捕是"跟踪的自然升级"：目标是形成包围圈、切断目标的逃逸方向，把它逼停或驱赶到指定区域；单纯跟着跑不构成围捕。现实任务里它对应多机拦截、野生动物驱赶、以及移动机器人的对抗演练，几乎所有"多对一"的协同演习都以围捕为收尾科目。

围捕的难点不在单机控制，而在空间的公平分配：目标周围能站的"好位置"只有一圈，N 台机器人必须各占一段角度、快而不乱地就位；谁占哪段、中途怎么交换、有人掉线怎么重排，都是一致性问题。它也是 056–061 章"协同操作与覆盖"的前奏，从这章开始，机器人之间的相对几何第一次成为被直接优化的对象。

核心原理

1. 目标构型与几何约束

围捕的期望构型：以目标估计位置 pe 为中心、半径 R 的圆环上，N 台机器人占据 N 个角位 θi = θ0 + 2πi/N。匀匀的角分布有两个物理意义：空隙均匀，目标向任意方向逃逸，最近的拦截者距离相同，不会有"明显的缺口"；相互不挤，相邻机器人沿环的弧距为 2πR/N，必须大于两机身最小间距：

R ≥ N·(r + m) / π 由弧距 2πR/N ≥ 2(r + m) 推出；r = 0.25 m、m = 0.15 m、N = 6 时 R ≥ 0.76 m，实际取 2.0 m 还要留出反应与控制余量

R 的选取是一个多目标权衡：小环收紧感强、拦截快，但对目标估计误差（054 章的 RMSE 约 0.3 m）与控制系统误差更敏感，且容易与目标发生接触；大环安全，但"口子"变大、驱赶感弱。经验区间是 3–5 倍目标估计标准差，本项目取 R = 2.0 m（RMSE 0.35 m 时约 5.7 倍标准差，稳健）。

2. 角度分配：从集中到分布式

约定的基准角 θ0 取目标运动方向的反方向（环的"正后方"），这样环随目标航向整体转动。分配要做的事：把 N 台机器人一一映射到 N 个角位，使所有机器人转动角度之和最小（减少横穿环绕的路径）。最简单的集中式分配直接按 id 发号（θi = 2πi/N + θ0），但对"已经在场上"的机器人可能产生大面积交叉：原本在 350° 的机器人被指到 0° 位是原地不动，被指到 180° 位就要横穿整圈，还可能穿过其它机器人。分布式方案更优：

  • 每台机器人广播自己的当前方位角（相对目标），2 Hz，几十字节。
  • 每台在自己的本地表里把所有人按方位角排序，再与排序后的角位序列做"圆上最小移动"匹配（枚举整体旋转偏移，取角度移动和最小者）。
  • 排序 + 按序配对天然无交叉（一维圆上的最优匹配），且每台用相同输入算出相同结果，无需中心仲裁。id 用于打破角度排序的平局，保证确定性。

重分配触发与滞回：目标大幅机动、成员掉线/加入、或某台偏离环位超过设定值（0.8 m）时重算；重算后的角位变化小于 20° 的不动，防止全员微调式的抖动。

3. 围捕控制律：前馈 + 反馈 + 硬约束

每台机器人的期望速度 = 目标速度前馈 + 环位误差反馈：

vi = ve + kp·(pi,d − pi)，pi,d = pe + R·[cos θi, sin θi] 前馈让环"跟着目标平移"，把"永远追"的滞后消掉；反馈缩小环位误差；两者叠加后再做限速

与 042 章领航-跟随的对照很有价值：结构完全相同（移动参考点 + 前馈），区别在参考点是估计出来的目标状态（带噪声与滞后），且"编队形状"是动态的旋转环。因此围捕必须叠加 044 章的互相避让（圆环上成员之间距离很近，安全层会频繁介入）与 054 章的估计质量监控，当估计协方差迹超过阈值时，环应自动放大 R（把不确定性反映到构型上），这是一条值得写进控制器的自适应规则。

4. 捕获判据：角度、距离、速度三条件

什么时候算"围住了"？单看距离会被骗：六台机器人挤在同一侧也满足距离条件。正确的判据至少两条，再加一条能力先决条件：

  • 角度条件：所有相邻角位的最大间隙 ≤ 1.25 × (2π/N)。N = 6 时均匀间隙 60°，判定门槛 75°，允许一定的不均匀，但不能有超过四分之一圈的缺口。
  • 距离条件：所有成员与目标的距离落在 R ± 0.6 m 内，且持续 2 s（瞬时穿越不算）。
  • 可捕获性先决条件：追击者的最大速度必须大于逃逸者的估计速度（含估计上界）。若逃逸者更快，"围住"只是瞬态，必须改为堵截策略（预测轨迹、提前占位）。

5. 逃逸反制：最大间隙突逃

理性的逃逸者会选择最大角度间隙方向全速突破。三步反制：(a) 随身间隙平衡，每台机器人微调自己的角位，向"自己所在半段的中点"靠近，让间隙均衡（等价于对间隙做负反馈）：θi 的自适应项与相邻间隙差成正比；(b) 收缩半径，发现目标朝某方向加速时，环半径按目标速度分量收缩（R' = R − α·ve·cos(方向差)），让包围圈"捏紧"；(c) 请求合流，多出的机器人（若有）不再进环，改为封在预计逃逸路线前方形成第二道线。注意所有调整都要限幅与滞回，否则环会围绕目标"呼吸"抖动。

6. 通信与服务降级

常规通信量很小：目标估计 10 Hz（来自 054 章）、成员方位与健康 2 Hz（几十字节）、捕获通告事件触发（Reliable）；掉线时其余成员重分配角度，间隙按存活成员重新均分，环暂时变大（R 不变、成员变少、间隙变大是自然结果，可用缩 R 补偿）。整个围捕系统没有中心节点：每台机器人本地跑同一套"排序匹配 + 前馈反馈 + 判定"，任何一台离线都只是"少一个角位"。

7. 数值算例：最小半径、一次分配与间隙代算

最小半径：R ≥ N(r + m)/π，N = 6、r = 0.25、m = 0.15 时 R ≥ 6 × 0.4/π = 0.764 m；这只是"相邻机身不重叠"的几何下限。实际取 R = 2.0 m 还叠了估计精度的账：目标估计 RMSE 约 0.35 m，2.0 m 约为其 5.7 倍，控制误差与目标机动各留一份余量。三档半径的对照：

环半径 R弧距（N = 6）对估计误差的容忍60° 补位时间适用场景
1.2 m1.257 m3.4 倍 RMSE1.05 s定位好、目标慢
2.0 m2.094 m5.7 倍 RMSE1.75 s常规室内（本章选择）
3.5 m3.665 m10 倍 RMSE3.06 s目标机动大、定位一般

R = 1.2 m 时环上弧距 1.257 m，仍大于 0.8 m 的安全底线，但对估计误差的容忍度只剩 3.4 倍，目标一个急转就会让环"咬到"目标；R = 3.5 m 时补位时间升到 3.06 s，对突逃的响应变慢。中间的 2.0 m 是本课参数下的平衡点，改半径时按这张表的三个判据同时复核，不要只盯一个维度。

一次分配：四台机器人当前方位（相对目标）为 30°、80°、200°、300°，角位均匀分布在 0°、90°、180°、270°。按"排序 + 圆上最小移动"枚举整体偏移：偏移 0 的配对是 30→0、80→90、200→180、300→270，总移动 30 + 10 + 20 + 30 = 90°；偏移 1 变为 30→90、80→180、200→270、300→0，总移动 60 + 100 + 70 + 60 = 290°，明显更差。算法选出偏移 0。总移动 90° 对应环上行进距离约 90 × π/180 × 2 = 3.14 m，四台平均 0.79 m；按 1.2 m/s 的环行速度，全员在 3 s 量级完成重排。

掉线与间隙代算：N = 6 均匀时每段间隙 60°，判据上限 75°；若一台掉线而其余仍占原来的六分位，最大间隙变成 120°，判据立即失效，所以掉线必须重分配；按 N = 5 均匀后间隙 72°、上限 90°，恢复合格。突逃情形也能量化：目标从环心到环上 2 m，以 0.8 m/s 跑需要 2.5 s；最近的机器人沿环补位，跨 60° 的弧长约 2.09 m，以 1.2 m/s 只需 1.75 s，来得及在目标到达环前补上缺口。1.75 s 对 2.5 s 的差就是"间隙平衡"策略的安全裕度；若把 R 扩大到 3 m，补位弧长升到 3.14 m、时间 2.6 s，反而追不上，这是半径不能盲目放大的另一个定量理由。

边界与失效：上面所有数字都假设"目标速度不超过 0.8 m/s、追击者上限 1.2 m/s"，速度可捕获性是硬前提。若目标加速到 1.5 m/s 并择最大间隙突破，补位时间被拉长，缺口会被穿破，此时切换堵截策略（第 5 节）：不再追求环位，改为在预测轨迹前方设卡。把"目标速度估计的上界"实时展示在监控里，指挥端能在穿破发生前看到风险累积。判据的优先级也要随之翻转：从"间隙是否均匀"转为"能否在目标前方形成二次拦截线"，两套判据在日志里用不同标签区分，复盘时才能分清失败原因。把"速度上界被突破"单独计数，它是评估目标行为模型是否失效的第一指标；若它长期出现，说明估计偏乐观，应主动放大 R 并下调可捕获性阈值，并与第 054 章的过程噪声 Q 联动调整。这条联动关系要写进交接文档：估计器每次升级后，都必须重跑围捕验收，两个模块的耦合比参数表看起来更深。若监控显示两者长期不同步，先修估计器，再动围捕参数。

实现思路与设计

  1. 输入：054 章的目标航迹（位置 + 速度 + 协方差）；全队成员方位（2 Hz）；模式指令（出击/保持/撤离）。
  2. 角度分配：本地排序 + 圆上最小移动匹配，50 ms 周期重算（含 20° 滞回）；id 破平局。
  3. 控制：前馈 + PD 控制 20 Hz；限速 1.2 m/s；环位误差超过 1 m 时先直线逼近（不做微调），进入 0.5 m 后交给微调。
  4. 安全层：044 章 ORCA 始终开启；环成员间距近，ORCA 的 τ 从 2.0 s 收到 1.2 s（构型内的相对运动更可预测）。
  5. 判定与通告：本地计算间隙与距离，连续 2 s 满足即广播 /fleet/capture（Reliable）；全队收到后进入"押送/等待指令"状态。
  6. 验收：N = 6、目标速度上限 0.8 m/s、10 组逃逸策略（含最大间隙突逃）：捕获率 100%；平均捕获时间小于 45 s；捕获时刻最大间隙小于 75°；成员间最小距离大于 0.4 m；无隔离（掉线 1 台后 30 s 内重分配完成）。

关键代码与解读

片段 1：环位期望速度（前馈 + 反馈）

import math
import numpy as np

def encircle_velocity(me_pos, target_est, theta_i, R=2.0,
                      k_p=0.8, v_max=1.2):
    """到分配角位的期望速度：目标速度前馈 + 环位误差反馈。"""
    px = target_est["pos"][0] + R * math.cos(theta_i)
    py = target_est["pos"][1] + R * math.sin(theta_i)
    ex, ey = px - me_pos[0], py - me_pos[1]
    vx = target_est["vel"][0] + k_p * ex       # 前馈：环随目标平移
    vy = target_est["vel"][1] + k_p * ey       # 反馈：收敛到自己的角位
    v = np.array([vx, vy])
    n = float(np.linalg.norm(v))
    return v * min(1.0, v_max / max(n, 1e-6))  # 限速：防止追击爆冲

解读：控制律与 042 章伺服从属机器人同源，但两个差别让这段代码更适合围捕。(1) 参考点是估计状态：target_est 里的位置和速度都带噪声，如果直接用估计速度做前馈，噪声会灌进控制环，工程上 target_est["vel"] 应来自 054 章滤波器的平滑输出，不要用位置差分现算。(2) 限速发生在前馈之后：环位远时前馈 + 反馈可能叠加超速（目标 0.8 m/s + 反馈 0.4 m/s），统一限速到 1.2 m/s 既保追击能力又给安全层留反应时间。这段返回值直接喂给 044 章的安全滤波器作为偏好速度，分层关系与 042 章完全一致。

片段 2：圆上最小移动的角度分配

def assign_angles(robot_angles, theta0=0.0):
    """分布式角度分配：按方位排序 + 圆上最小移动匹配（无交叉）。"""
    ids = sorted(robot_angles.keys())             # id 确定性破平局
    n = len(ids)
    slots = [theta0 + 2 * math.pi * k / n for k in range(n)]
    cur = sorted(ids, key=lambda i: robot_angles[i] % (2 * math.pi))
    best, best_cost = 0, float("inf")
    for s in range(n):                            # 枚举整体旋转偏移
        cost = 0.0
        for k, rid in enumerate(cur):
            d = (slots[(k + s) % n] - robot_angles[rid]) % (2 * math.pi)
            cost += min(d, 2 * math.pi - d)       # 圆上最短角距
        if cost < best_cost:
            best, best_cost = s, cost
    # 每台机器人用相同输入算出相同结果：无需中心仲裁
    return {cur[k]: slots[(k + best) % n] for k in range(n)}

解读：分配算法的灵魂是"排序 + 按序配对"：把所有人按当前方位排成一列，与同样排好序的角位序列一一对应，这样两个相邻的人永远配到两个相邻的位，一维圆上不可能出现交叉。剩下的自由度只有"整体转多少"（偏移 s），枚举 n 种可能取角度移动和最小者，O(n²) 对 n ≤ 20 完全够用。id 排序破平局解决角度几乎相等时的顺序不确定：没有它，两台机器人可能各自算出不同的配对，分配结果不一致，当场互穿。返回的字典每台只取自己那一份，但所有人算出的字典完全一致，这是"去中心但确定"的关键：输入相同（成员方位表最终一致）、算法确定，输出自然一致。

片段 3：捕获判据

def max_gap(angles):
    """最大角度间隙：均匀分布时每个间隙都是 2*pi/n。"""
    a = sorted(x % (2 * math.pi) for x in angles)
    n = len(a)
    return max((a[(i + 1) % n] - a[i]) % (2 * math.pi) for i in range(n))

def is_captured(angles, dists, R=2.0,
                gap_factor=1.25, dist_tol=0.6):
    """捕获判定：角度间隙收敛 + 全队距离到位（调用方再加 2 s 持续窗）。"""
    n = len(angles)
    gap_ok = max_gap(angles) <= gap_factor * (2 * math.pi / n)
    dist_ok = all(abs(d - R) <= dist_tol for d in dists)
    return bool(gap_ok and dist_ok)

解读：max_gap 用"环形相邻差"计算所有间隙取最大，注意取模要处理跨越 0° 的间隙（350° 与 10° 之间的间隙是 20° 不是 340°），这是角度编程里最常错的一处。is_captured 故意保持纯函数、不含持续窗口计时，"连续 2 s 满足"由调用方用状态机实现，因为持续判定还牵涉掉线成员的处理（掉线期间成员名单变化，持续窗应重置）。判据里的 gap_factor = 1.25 是"接近均匀"的工程界限：它给出的是"没有局部大缺口"的保证；绝对等分在有障碍物或狭窄地形的现场根本达不到，实现时不要追求教科书式的完美均匀。

常见坑

  • 不做分配直接冲：六台机器人全挤在目标后方同一侧，目标从正面轻松逃走。症状是"围捕成功"的判定永远不满足（间隙过大却距离都到位）。修复：角度分配强制生效；把"距离到位但间隙超限"做成遥测告警。
  • 环半径过小：机器人互相进入安全距离，ORCA 持续干预，环位控制与避让互相打架、原地画圈。修复：R 按公式下限并留 3 倍余量；成员间距小于 0.5 m 时自动扩大 R 修正项。
  • 估计滞后被直接放大：目标急转弯，环跟着"甩尾"追不上，空隙发生在目标机动一侧。修复：缓慢目标用估计前馈，机动目标提高 054 章过程噪声 Q 并适度放大 R（用不确定性换稳健）。
  • 角度再分配抖动：每帧都有微小重排，机器人绕圈横挪。修复：20° 滞回 + 只在触发条件（机动/掉线/偏离）下重算；把分配变化率做成指标。
  • 速度不足还想围捕：逃逸者速度超过追击者时，任何"尾随式围捕"都会失败。修复：先做可捕获性检查，不满足就切换堵截策略（预测轨迹提前占位、多道防线），不要用围捕的判据自欺欺人。

练习与思考

  1. N = 6、均匀分布时相邻角位间隔多少度？最大间隙判据放宽到 1.25 倍后是多少度？如果一台机器人掉线（N = 5）且环半径不变，均匀间隙变为多少？说明掉线后为什么必须重分配。★
    提示
    60° → 75°；掉线后若仍是 6 台时的角位，会出现 120° 的空档，远超 75°，必须按 5 台重分配。
  2. 环半径从 2.0 m 改为 1.2 m 与 3.5 m，预测：捕获时间、成员间最小距离、ORCA 介入频率、对估计误差的敏感度如何变化？给出选 R 的三个约束式。★★
    提示
    1.2 m：紧但易互挤、对估计误差敏感；3.5 m：宽松但口子大、捕获慢。三条约束：弧距下限、估计不确定性上限、目标机动反应距离。
  3. 为逃逸者设计"最大间隙突逃"策略（选择间隙方向、加速时机），然后设计对应的三步反制（间隙平衡、半径收缩、二道防线）与各自的触发阈值；用仿真比较反制前后捕获时间。★★★
    提示
    突逃时机选在环位重分配后（间隙瞬时失衡）；反制阈值以"目标加速度估计 + 间隙变化率"触发；二道防线由多余成员在逃逸路线 1.5 m 处待命。
  4. 把角度分配的滞回从 20° 改为 5° 与 45°，预测分配变化频率、环绕横挪距离、捕获时间的变化；说明如何用日志验证。★★
    提示
    5°：频繁重排、横挪多；45°：稳定但机动响应差。日志指标：每秒角位变更次数、机器人累计环绕行程、捕获时间。
  5. 设计"围捕 + 押送"的完整任务流：捕获确认后如何切换到编队方式（042/043 章的队形）把目标引导到指定区域，目标反悔时如何回退到围捕；写出状态机与切换条件。★★★
    提示
    捕获后环略微收缩并沿目标航向平移（蛇形押送）；目标脱离环位误差阈值即回到 CAPTURE 状态重新合围；状态机保留"降级人工"出口。

小结

  • 围捕构型 = 目标周围的等分环；弧距下限决定最小半径，估计不确定性决定实际半径取值。
  • 角度分配用"排序 + 圆上最小移动"实现无交叉、确定性的分布式匹配；20° 滞回防抖。
  • 控制律是前馈（目标速度）+ 反馈（环位误差）+ 限速，偏好速度交 044 章安全层执行。
  • 捕获三条件：最大间隙 ≤ 1.25×均匀值、距离 ±0.6 m 持续 2 s、速度可捕获性先决。
