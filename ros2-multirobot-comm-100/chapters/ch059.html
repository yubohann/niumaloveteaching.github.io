第三篇 · 协同控制与任务协同

第 059 章：多机器人协同抓取

从"接触"到"抓住"：选对抓点、算清抓力窗口、用屏障同步保证两台机械臂同时闭合与抬升，任何一步抢跑，物体都会倾斜甚至掉落。

  • 主题：任务协同 / 抓取动作与同步
  • 关键机制：力封闭判据、抓持力窗口、屏障同步状态机、倾角修正
  • 预计学时：60 分钟
  • 前置章节：第 058 章

学习目标

  • 区分形封闭（form closure）与力封闭（force closure），会判断双点抓持的力封闭条件。
  • 会计算抓持力的安全窗口：下限由摩擦与载荷决定，上限由物体强度与夹爪能力决定。
  • 掌握抓点选择的两条实用规则：对跖性（接触法向相对）与质心投影落在抓持连线上。
  • 能实现屏障（barrier）同步的抓取状态机：双方就绪才动作、超时确定性回退。
  • 会设计抬升阶段的倾角监测与修正，理解为什么"抢跑"是多机抓取的头号故障。

背景与动机

056–058 章处理"已经抓住/夹住之后怎么搬"。本章补上前传镜头：怎么抓。多机抓取与单机抓取的区别集中在三点：抓点不是机器人单方面选的（要两台协商同一组对跖点）；抓力要同时满足"不滑落"和"不压坏"两个方向的约束；动作时序必须同步，单机抓取失败了重来即可，多机抓取抢跑会造成物体倾覆、甚至撞坏夹爪。

动作层面之后，060 章会讲抓取后的精细操作（装配、交接）；059 与 060 合起来覆盖"抓取工业机器人"的完整技能树。本章的屏障同步与状态机模式，也是 064 章行为树协同决策的雏形，所有多机"必须一起做"的动作，都长这个样子。

核心原理

1. 形封闭与力封闭

抓取质量的经典判据分两级：形封闭（form closure），接触几何本身约束住物体的所有自由度，不需要任何摩擦。用两个平面接触显然做不到（物体可沿接触面滑动），至少需要四个精心布置的接触点。工程上更常见、也更容易实现的是力封闭（force closure），依靠摩擦，接触力的可行空间能张成整个力旋量空间。双点抓持的判据可以简化成一个漂亮的几何条件：两个接触点的连线方向，必须落在每个接触点的摩擦锥内（摩擦锥半角 = arctan μ）。

力封闭（双点）：夹角(接触法向, 指向另一接触点的方向) ≤ arctan μ μ = 0.6 时摩擦锥半角约 31°；对跖抓持（法向正对）夹角为 0°，天然满足；斜抓 40° 则超出锥角，靠摩擦抓不住

2. 抓持力窗口：下限防滑、上限防碎

夹爪法向力 N 必须满足一个区间。下限来自"不滑落"：n 个接触点、每个提供摩擦 μN，总摩擦力要抵抗重力（或更一般的载荷）：

μ·N·n ≥ m·g·s → Nmin = s·m·g / (μ·n) s 为安全系数（示例 1.5）；m = 3 kg、μ = 0.6、n = 2 时 Nmin ≈ 37 N

上限来自物体强度（薄壳件、玻璃瓶可能几十牛就变形）与夹爪能力。窗口是否为空是项目可行性的第一道判定：若 Nmin 超过物体的承受力，方案本身不可行，要么改抓点（用托底代替侧夹）、要么换摩擦材料（贴胶增大 μ）、要么改变抓取方式（变成托举+夹紧的组合）。运行时还要考虑动态载荷：加速、转弯、倾角都会把等效载荷放大 1.2–1.5 倍，安全系数正是为这些留的。

3. 抓点选择的两条实用规则

完全一般的抓点优化求解复杂，工程上先用两条规则筛出候选，再做简单校验：

  • 对跖性：两接触点法向近似相反（两面平行夹持），使接触力主要由法向承担、摩擦力只需抵抗切向载荷，这正是力封闭判据最舒服的工作点。
  • 质心投影落在抓持连线上：质心在"两接触点连线"这条轴上的投影应位于两点的中间区间（示例允许 ±0.1L 的偏移）。偏离太远时，重力相对抓持轴产生恒定力矩，表现为"物体一抬就歪、夹爪一侧持续吃力"。

实践中抓点还受物体表面结构约束（加强筋、标签、把手），规则给出的是"理想候选"，最终选择要在候选里挑"离理想最近且表面可抓"的点，并把实际选择的偏差（相对理想对跖点的角度、质心偏移）记录下来，它们是后续倾角修正的先行信息。

4. 屏障同步：谁也别抢跑

多机抓取的时序天然是分布式的两阶段问题：接触前各自接近、对齐，只有两台都报"对齐完成"才可以闭合夹爪（单侧先合拢会把物体推开或推到一侧）；抬升前各自完成闭合、抓力达标，只有两台都报"就绪"才可以起吊（单侧先抬，物体绕另一侧转，轻则歪斜重则脱落）。这正是分布式系统里的屏障（barrier）：每个参与者到达检查点后等待，全部到达才放行。

屏障必须有超时与确定性回退，否则一台故障会让另一台无限等待（与 043 章队形变换的 ACK 汇总、048 章 epoch 同步是同一类纪律）。示例：对齐屏障超时 15 s、就绪屏障超时 5 s（叫齐动作本身很快，5 s 不齐必有异常）；超时方在下一个安全点退让，状态机进入 FAILED 并允许重试。屏障的通信极简：每台发一条"我到了"（state + seq），收到全部同伴的对应消息即放行，状态事件走 Reliable QoS，量级是每秒几条消息。

5. 抬升与倾角修正

抬升阶段的第一秒最危险：抓持刚度、负载分布的实际状态开始显现。监测手段是倾角（物体上的 IMU 或视觉标记，目标 5° 以内，超过 3° 开始修正）。修正用"微分高度"：哪侧低，哪侧多抬一点，修正量限幅（模板代码 2 cm 量级）并低通，修正与抬起动作叠加在同一速度指令里。修正的限幅很重要：倾角修正本质是应急补偿，不能变成"用抬升动作玩平衡"；修正饱和后仍歪，说明抓点或抓力配置有本质问题，应放下重抓，不再继续抬。

6. 数值算例：抓点偏移的力矩账

抓点规则的定量来源是一次静力学核算。设箱体沿抓持轴长 L = 0.3 m，两接触点位于两端，质心偏离中点 e。竖直方向力平衡与对质心的力矩平衡联立，可得两侧摩擦需求：近侧 f近 = m·g·(L/2 + e)/L，远侧 f远 = m·g·(L/2 − e)/L。代入 m = 3 kg、g = 9.8 m/s²：e = 0 时两侧各 14.7 N；e = 0.05 m 时近侧升到 19.6 N，恰好是远侧 9.8 N 的两倍。再按 N = s·f/μ 换算夹持力需求（s = 1.5、μ = 0.6），近侧需要 49 N，而对称理想情形只需 36.75 N，偏移量不到边长的五分之一就把抓力需求抬高三分之一。这就是"质心投影落在抓持连线中段 ±0.1L"的量化依据：把 e 限制在 0.03 m 以内，近侧需求降到 44.1 N，仍在常见窗口内。

若执行器窗口只给到 40 N，同一算例可以反解出允许的最大偏移：40 N 对应 f近 ≤ 40×0.6/1.5 = 16 N，解出 e ≤ L×(16/(m·g) − 0.5) ≈ 0.3×(0.544 − 0.5) ≈ 0.013 m。结论有两条：抓力越充裕，对抓点对称性的容忍度越大；抓力贴近下限时，一两厘米的偏移就足以让一侧滑脱。工程上两条策略配合使用，先用对跖规则把偏移压到厘米级，再用倾角监测在运行时确认恒定力矩没有残余。

动载的账同样要算。抬升加速度 a = 0.5 m/s² 时，切向载荷从 m·g 变为 m·(g + a)，下限从 36.75 N 升到 38.63 N，增幅约 5%；转弯的横向惯性还要按矢量叠加进切向合力，安全系数 s = 1.5 正是为这类叠加项留的余量。另一个常被忽略的因数来自摩擦本身：橡胶垫干燥时 μ ≈ 0.6，沾油或凝露后可掉到 0.45 以下，届时对称下限升到 49 N，与"偏移 0.05 m 的近侧需求"同量级，两个因素叠加就能把窗口下限顶到结构上限之上。因此抓取任务的可行域要在最差组合（μ 取下限、载荷取动载峰值、偏移取实测最大值）下核算，不能只拿名义参数乐观估一次。

方案选择的依据由物体属性与失败代价决定：有加强底的箱体加一条托底支撑，竖直载荷改由几何承担，μ 从关键参数降为辅助参数；光滑玻璃件的吸盘方案必须配断电保压阀，否则一次掉电就是摔件；三指包络适合形状不规则且扰动预期高的场合，代价是接触力分配的建模与标定工作量上升。任何方案都要给出自己的"最差组合"核算，对跖性、力矩偏移、动载、摩擦退化这四项构成方案评审的统一检查表。

最后把控制误差折进窗口。抓力跟踪误差指实测夹持力与目标值的偏差，验收线是 ±3 N。若目标值取 40 N、误差与超调合计 3 N，最坏时刻夹持力落在 37 N，恰好贴住下限 36.75 N，没有任何余量；更稳妥的取法是目标 = 下限 + 2 × 跟踪误差 = 37 + 6 = 43 N，把"最差点仍高于下限"写成参数依据。反过来，若实测误差到了 5 N，窗口本身要重审：要么把目标抬到 47 N 并复核上限，要么更换更硬的夹爪传动把误差压回 3 N 以内。参数表里每个数都要能回答"谁在保证它"：安全系数保证动载与摩擦波动，跟踪误差预算保证目标值始终留在窗口之内，两个保证缺一不可。

实现思路与设计

  1. 任务设定：两台机械臂夹持一个 3 kg 箱体（0.3 m 立方）的两侧对跖面，μ = 0.6，抓持力目标 37 N（下限）到 60 N（结构上限）之间，取 40 N 起步。
  2. 抓点协商：leader 基于物体模型给出候选对跖点（两侧面中心各偏 0.05 m 使质心投影居中），两台机器人各自验证可达性（关节限位/碰撞），都确认后锁定抓点，广播 grasp_plan。
  3. 状态机：APPROACH → ALIGN → CLOSE → READY → LIFT → HELD；每个"双人动作"前有屏障，超时 15 s / 5 s 两级。
  4. 通信：/fleet/grasp_state（状态 + seq，Reliable，事件驱动 + 1 Hz 重播）；/fleet/grasp_force（实测/目标夹持力，10 Hz）；倾角来自物体 IMU（20 Hz）。
  5. 修正与回退：抬升倾角超 3° 触发限幅微分高度修正；超 8° 或修正饱和 → 放下重试（最多 2 次），仍失败转人工。
  6. 验收：20 次抓取：成功率大于 95%；抬升后倾角小于 3°；抓力跟踪误差小于 3 N；屏障超时触发率小于 5%（作为同步质量的度量）。

关键代码与解读

片段 1：力封闭判据与抓力窗口

import math

def force_closure_two_points(p1, p2, n1, n2, mu=0.6):
    """双点抓持力封闭：抓持连线须落在各自的摩擦锥内。"""
    def in_cone(contact, normal, other):
        d = (other[0] - contact[0], other[1] - contact[1])
        cos_a = (d[0] * normal[0] + d[1] * normal[1]) / max(math.hypot(*d), 1e-9)
        ang = math.acos(max(-1.0, min(1.0, cos_a)))
        return ang <= math.atan(mu)            # 摩擦锥半角 = arctan(mu)
    return in_cone(p1, n1, p2) and in_cone(p2, n2, p1)

def grip_force_window(mass, mu=0.6, n=2, safety=1.5, f_max=60.0):
    """抓力窗口：下限防滑，上限防压坏；返回 (下限, 上限)。"""
    f_min = safety * mass * 9.8 / (n * mu)     # 静态+动载包络的简化
    return f_min, f_max

解读：force_closure_two_points 把"抓不抓得住"翻译成两个角度比较，接触法向与"指向对方"方向的夹角都在摩擦锥内，物体才被"锁"住。注意它同时检查两个方向：只算一个接触点会漏掉"单边滑脱"的情形。角度用点积反余弦计算，避免直接算斜率除法在法向水平时的奇异。grip_force_window 的下限公式里 safety = 1.5 覆盖抬升瞬间的动载（加速度引起的等效载荷）与 μ 的波动（油污、湿度可让 μ 掉 20–30%）；上限 60 N 来自夹爪与物体两侧的较低者。返回窗口（下限与上限两个数），让状态机在窗口内做"先到目标、稳定后保持"的两段式逼近，避免一步冲到目标值。

片段 2：屏障同步的抓取状态机

def step_grasp(state, obs, dt):
    """抓取时序：APPROACH / ALIGN / CLOSE / READY / LIFT / HELD / FAILED。"""
    if state == "APPROACH":
        if obs["align_err"] < 0.02:             # 自身对齐到 2 cm 内
            return "ALIGN", 0.0
    elif state == "ALIGN":
        if obs["peer_aligned"]:                 # 屏障一：双方均对齐
            return "CLOSE", 0.0
        if obs["time_in_state"] > 15.0:
            return "FAILED", 0.0                # 对齐超时：确定性回退
    elif state == "CLOSE":
        if obs["force_reached"]:
            return "READY", 0.0
    elif state == "READY":
        if obs["peer_ready"]:                   # 屏障二：双方就绪才抬升
            return "LIFT", 0.0
        if obs["time_in_state"] > 5.0:          # 叫齐动作超时：回退
            return "FAILED", 0.0
    elif state == "LIFT":
        if obs["lift_done"] and obs["tilt_ok"]:
            return "HELD", 0.0                  # 完成，进入保持/下一步操作
    return state, obs["time_in_state"] + dt

解读：状态机的精华是两个屏障：ALIGN 到 CLOSE 之间、READY 到 LIFT 之间。屏障的输入 peer_aligned / peer_ready 来自同伴的 Reliable 状态消息；语义是"我这一侧完成了，且我已经看到你完成"，配合 seq 保证不会把旧消息当新完成（消息带自己的状态序列号，接收方只认比上次新的）。两个超时值刻意不同：15 s 给对齐（含机械臂运动时间），5 s 给叫齐（双方都已静止等待，5 s 不齐必是异常）。"FAILED 不是放弃"，状态机外层的调度器会在 3 s 后重新进入 APPROACH（最多 2 次），把瞬时故障与系统性故障区分开。整套结构就是分布式系统里的两阶段提交，只不过提交的对象是"抬"这个动作。

片段 3：抬升倾角修正

def tilt_correction(tilt_deg, k=0.015, limit=0.02, deadband=3.0):
    """倾角修正：输出 (左, 右) 的高度微调量，单位 m，限幅 2 cm。"""
    if abs(tilt_deg) < deadband:
        return 0.0, 0.0                         # 3° 以内视为正常
    corr = max(-limit, min(limit, k * tilt_deg))
    # 约定正倾角 = 右侧偏低：右侧多抬 corr，左侧少抬 corr
    return -corr, corr

def merge_lift_command(v_lift, corr_left, corr_right):
    """把修正叠加到抬升速度上（限速 0.05 m/s，防修正变主导）。"""
    v_l = max(-0.05, min(0.05, v_lift + corr_left * 2.5))
    v_r = max(-0.05, min(0.05, v_lift + corr_right * 2.5))
    return v_l, v_r

解读：修正函数有三个"克制"设计：死区（3° 内不动作，避免无谓的抖动与执行器磨损）、限幅（单周期最多 2 cm 的高度微调，再大就变成"重摆姿势"）、线性小增益（k = 0.015 m/°，5° 倾角对应 7.5 cm 的原始修正量，先被限幅到 2 cm，经 merge_lift_command 的系数换算为 5 cm/s，保持在抬升速度同一量级）。merge_lift_command 的 0.05 m/s 钳制保证修正不会让某一侧突然加速到危险速度。实机调参顺序：先把死区调到能覆盖 IMU 噪声（记录静止状态下的倾角读数标准差），再调 k 让 5° 偏差在 1–2 s 内回到死区内，最后验证限幅值不会让修正饱和（饱和率超过 10% 说明问题在抓点而不在修正）。

常见坑

  • 单侧先抬：物体绕另一侧旋转，倾角瞬间超限或直接脱落。修复：READY 屏障 + 5 s 超时；抬升动作本身做速度斜坡（0.05 m/s 起步），给另一侧留出跟上的时间。
  • 抓力不足滑脱：下限算错（漏了安全系数或 μ 取乐观值），抬升 1 s 后物体下滑。修复：μ 实测标定、s 取 1.5；抬升后立即检查接触点法向力是否维持窗口内，掉出窗口即降速或停下。
  • 抓力过大压坏物体：只有"夹紧"直觉没有上限。修复：窗口上限由物体强度测试得出并写进参数；接近上限时报警提醒，"抓得牢"的直觉在此会误导。
  • 屏障没有超时：一台故障，另一台在 READY 无限等待。修复：每个屏障配确定性超时与回退路径；"等待"也必须是有计划的行为（等多久、等不到怎么办）。
  • 抓点不对称遗留恒定力矩：质心投影偏离抓持连线，抬起后始终一侧吃力、倾角修正长期饱和。修复：抓点选择时校验质心投影落在连线中段 ±0.1L 内；已执行的任务记录实际偏差用于姿态前馈补偿。

练习与思考

  1. 3 kg 立方体、μ = 0.6、双点抓持、安全系数 1.5。计算抓力下限；若 μ 因油污降到 0.4，下限变为多少？说明为什么要在现场做摩擦标定。★
    提示
    N = 1.5×3×9.8/(2×0.6) ≈ 37 N；μ = 0.4 时约 55 N，逼近常见夹爪与结构上限，摩擦下降 1/3 会把方案推到不可行边缘。
  2. 对跖抓持与斜抓（接触法向相差 30°）各画摩擦锥图。斜抓时两接触点连线与法向的夹角是多少？在 μ = 0.6 下是否力封闭？★
    提示
    对跖夹角 0°；斜抓 30° 小于摩擦锥 31°，理论上仍封闭但余量只有 1°，任何扰动或 μ 下降都会破坏，工程上应尽量接近对跖。
  3. 设计一个"抢跑故障"复现实验：禁用 READY 屏障，让一侧提前 200 ms 抬升，记录倾角曲线与抓力变化；然后启用屏障重复实验，量化两者差异。★★
    提示
    抢跑时倾角峰值预期 10°+ 且抓力一侧超窗口；屏障后峰值回到 3° 内。用 IMU 10 Hz 以上采样，对比倾角峰值与恢复时间两个指标。
  4. 把屏障超时从 15 s / 5 s 改为 3 s / 1 s，预测：正常任务失败率（误判超时）与故障检测时间的权衡；给出一个用系统延迟分布（P50/P95/P99）定超时的计算流程。★★★
    提示
    超时值取"全链路延迟 P99 的 2–3 倍"；3 s 会误杀长对齐；先测对齐时间的分布再定，别拍脑袋。
  5. 为一个"薄壁塑料盒"（承受力上限 20 N）设计抓取方案：若侧夹的下限超过上限，列出至少三种替代方案并分析各自代价（托底、贴胶增大 μ、改变抓点、负压吸盘）。★★★
    提示
    托底 = 增加形封闭分量；贴胶 = μ 到 0.9 后下限约 25 N 仍高；吸盘 = 换物理机制；改抓点（靠近质心的加强边）= 降低所需力矩。方案选择要绑定可行性数据。

小结

  • 力封闭（双点）判据：抓持连线方向在各自摩擦锥（半角 arctan μ）内；对跖抓持天然最强。
  • 抓力窗口 = [1.5·mg/(nμ), 结构上限]；窗口为空则方案不可行，要改机制，硬调参数救不了。
  • 抓点两规则：对跖 + 质心投影落在抓持连线中段；偏差要记录用于后续补偿。
  • 多机抓取是分布式两阶段提交：两个屏障（对齐、就绪）+ 确定性超时回退；抢跑是头号故障。
  • 抬升用倾角微分修正（死区 3°、限幅 2 cm）；修正饱和说明抓点配置问题，放下重抓。下一章：多机器人协同操作，抓稳之后，两台机械臂如何一起做精细动作。
