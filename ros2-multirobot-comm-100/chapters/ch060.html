第三篇 · 协同控制与任务协同

第 060 章：多机器人协同操作

抓稳之后的精细活：把"物体运动"与"抓持内力"分成两层控制，用选择矩阵在自由方向控位置、在约束方向控力，靠三阶段交接与螺旋搜索完成装配级操作。

  • 主题：任务协同 / 双臂协同操作
  • 关键机制：物体层/内力层分解、选择矩阵混合控制、交接三阶段、螺旋搜索
  • 预计学时：65 分钟
  • 前置章节：第 059 章

学习目标

  • 掌握协同操作的两层控制结构：物体层（外部运动与力）与内力层（抓持维持），理解两层的解耦与各自的目标。
  • 会用选择矩阵 S 做混合位置/力控制：自由方向控位、约束方向控力，并解释刚度矩阵的构造。
  • 能设计交接（handover）三阶段流程：预抓、双持力的渐变、释放与回退，避免"双松掉落"与"双紧拧坏"。
  • 理解装配中的位置不确定性为什么必须用力反馈补偿，会实现螺旋搜索与力阈值保护。
  • 能处理分布式执行的相位错位问题：轨迹时间戳、本地插值与延迟补偿对内力稳定的意义。

背景与动机

059 章让物体离开地面，060 处理接下来的课题：在手里操作它。典型任务是插销入孔、旋转阀门、在两台机器人之间交接零件，这些动作里机器人与物体的关系从"搬"变成了"控"：既要控制物体到达精确位置（毫米级），又要控制接触力不超标（否则损坏工件），还要在需要时把物体从一台机器人"交给"另一台。接触状态从"确定"变成"随位置变化"：插销入孔前只有对准的自由度，入孔后沿轴的力约束才出现，控制策略必须随接触条件切换。

本章与 056 章共享同一套线性代数（抓持矩阵、伪逆、零空间），但从移动底盘换成了机械臂、从"物体级速度"深入到"任务空间的力位混合"。它也是 064 章行为树协同决策的试验场：交接、插入这些动作天然是行为树中的复合节点。

核心原理

1. 两层控制：物体层与内力层

协同操作的第一条设计律是把"想让物体做什么"与"想用多大力抓住"分开。物体层负责期望运动：轨迹规划给出物体的位姿、速度、加速度，换算成作用在物体上的期望合力旋量；内力层负责抓持：在抓持矩阵的零空间里设定夹持挤压力（056 章的分解直接复用，只是执行端变成了机械臂的关节力矩）。两层分开之后，"物体移动慢了"和"抓得太松"就成了两个独立的可观测、可调节的问题，混在一起调试会互相掩盖症状。

τ = JT·(G+·wobj + (I − G+G)·wint) wobj 为物体层期望旋量、wint 为内力层期望；J 为各臂的雅可比；公式示意从旋量到关节力矩的映射

2. 选择矩阵：哪里控位、哪里控力

接触会"吃掉"自由度。以插销入孔为例：垂直孔壁的两个方向被几何约束死（销与孔壁贴紧），这些方向上位置误差几乎没有意义，你无法同时控制销的横向位置和横向力，二者由接触刚度刚性耦合；而沿插入轴方向是自由的（接触前），可以控位置，插入后接触底/壁产生轴向力，又需要控力。工程解法是选择矩阵 S：对角阵，S 对应自由度做位置控制、I − S 对应自由度做力控制：

v = S·kp·epos + (I − S)·kf·(fmeas − fdes) S = diag(1, 1, 0)：x/y 控位（对准孔心），z 控力（下压力恒定），插孔任务的典型配置

S 不是一次设定的：接触前 z 也控位（空走接近），接触后才切到 z 控力。所以 S 是接触状态的函数，由力/位置特征自动切换（示例：轴向接触力超过 2 N 即认为进入约束状态）。切换要有滞回，否则在阈值附近会在两种控制律间反复横跳，力与位置指令交替抖动，这与前面章节所有状态切换是同一条纪律。

3. 不确定性：为什么必须让力说话

装配里位置不确定性来自三方：抓持偏差（±2 mm）、定位误差（±1 mm）、物体与孔的形状公差（±0.2 mm）。总不确定度超过孔销间隙（示例 0.5 mm）时，纯位置控制必然撞上孔沿：轻则卡住（"力大到推不动"），重则划伤或顶弯销。此时唯一的有效信息是接触力：撞上孔沿产生侧向力，接触上表面产生轴向力。装配的标准动作是螺旋搜索：保持恒定下压力（轴向力闭环），同时在垂直平面画螺旋（半径 0.5→2 mm、每圈 2 s），直到销"咬进"孔口（侧向力骤降、轴向力回落、深度传感器前进），用轨迹小幅"扫掠"换掉位置不确定性。这属于"没接触时的搜索、接触后的力控"两类行为的交替，与选择矩阵切换配合工作。

4. 交接：三阶段与力渐变

两台机械臂之间的零件交接是协同操作最具代表性的动作，标准三阶段：(1) 预抓，第二臂移到抓持位姿并就位（此时不施加抓力），确认到位（屏障，同 059 章）；(2) 双持（dual hold），两臂同时持有零件，抓持力按时间曲线渐变：第一臂从 fgrip 线性降到 0，第二臂从 0 升到 fgrip（示例 1.5 s）。渐变期间两臂都按同一刚体约束运动（物体实际上是"静止悬停"）；(3) 释放，第一臂张开退出，第二臂独持并继续任务。关键纪律有三条：力必须渐变不能瞬变（瞬变会在零件表面产生冲击）；过渡期间两臂的位置必须由同一物体位姿派生（056 章的对象坐标系）；过程可回退，任何异常（力超限、位置偏离、通信中断）回到"双持、双方力恢复到 fgrip"这个安全态，直接松手不在考虑之内。

5. 分布式执行：时间对齐就是内力

两台机械臂的内环控制（1 kHz 级）各自本地执行，但参考轨迹来自网络广播（30 Hz 级）：leader 发布物体目标位姿与速度（带时间戳），各臂本地插值并向外推送到执行时刻。相位错位的后果在精细操作里被直接放大：两臂参考差 50 ms，物体的实际运动就被"拧"了 50 ms，接触刚度高时内力可瞬间达到数十牛。所以：轨迹消息必须带时间戳；外推上限控制在两个广播周期；内环对外推结果做速率限幅（不许因为补时间差而超速）。断连降级与 056 章一致，停在当前位姿、保持抓持力、等待重新同步。

6. 数值算例：相位错位换算成内力

协同操作里最容易被低估的误差源是相位。设两臂的参考轨迹时延差 50 ms、物体以 0.1 m/s 平移，两臂实际位置就相差 0.1×0.05 = 5 mm；接触环节刚度取 5000 N/m（含夹爪传动与零件表面），这一位置差直接换算成 5000×0.005 = 25 N 的内力，超过本章 15 N 接触力上限约 67%。反过来解预算：若允许相位差贡献的内力不超过 10 N，位置差必须小于 10/5000 = 2 mm，对应时延差在 0.1 m/s 下不超过 20 ms。这就是"轨迹广播 30 Hz（周期 33 ms）"与"两臂参考差做成在线指标（超过 20 ms 告警）"两个设计参数的来源：广播周期决定相位分辨率，告警线由内力的安全预算直接推出。

同样的换算在交接前的悬停对峙中更敏感：两臂都静止时，接收臂的位置误差 δ 会以同样的刚度换算成侧向推力。δ = 2 mm 时推力为 10 N，已达上限的三分之二；所以"就位精度 2 mm"的模糊要求升级为一条由 15 N 上限反推的硬指标。把链路写成显式不等式：时延差乘速度得位置差，位置差乘刚度得内力，内力对照上限；任何一环改参数（物体速度提高、零件刚度更高），其余环节的允许值都要重算一遍。

7. 螺旋搜索的可达性与螺距账

螺旋搜索能否把孔"扫"到，取决于螺距（每圈半径增量）与孔销间隙的关系。位置不确定度由三部分组成：抓持偏差 ±2 mm、定位误差 ±1 mm、形状公差 ±0.2 mm，按均方根合成约 2.24 mm，因此搜索半径至少要覆盖 2.2 mm，模板取 2 mm 属于下限，实机部署建议 2.5–3 mm。覆盖的充分条件由螺距决定：螺距为 d 时，相邻两圈之间最坏情况会漏过 d/2 的间距，要保证销在任何方位都能咬进孔口，需满足 d/2 ≤ 孔销间隙。取间隙 0.5 mm，螺距上限为 1 mm；模板"两圈内半径长到 2 mm"的螺距恰为 1 mm，处于临界，建议放缓到 3–4 圈扫满（螺距 0.5–0.67 mm），每圈 2 s 对应总搜索时间 6–8 s。搜索期间轴向保持 5 mm/s 缓压：单次搜索周期的最大下压量 = 速度 × 周期，8 s 周期约 40 mm，足够销在找到孔口后咬入，又不会在未找到时把销压弯。

接触检测的时延也能从参数直接算出来。检测阈值 2 N、接触刚度 5000 N/m 对应压入深度 2/5000 = 0.4 mm；接近速度 5 mm/s 时，从碰触到力信号越线需要 0.4/5 = 0.08 s，即 S 矩阵最快也只能在碰触后约 80 ms 完成切换，这段时间累计位移 0.4 mm。这条"检测时延到穿透位移"的换算能回答两个常被争论的问题：接近速度为什么不能再快（速度翻倍，80 ms 里的位移与冲击力同步翻倍）；力阈值为什么不能再小（阈值低于 0.5 N 的传感器噪声就检不到，0.5 N 噪声对应 0.1 mm 量级的触发不确定性）。把这两个数字写进设计评审，参数改动就有共同语言。

实现思路与设计

  1. 任务：两台机械臂从交接台取件（3 kg 方件），一臂完成插销入孔（孔销间隙 0.5 mm），另一臂在旁待命支持。
  2. 轨迹层：leader 发布物体目标（Pose + Twist，30 Hz，Reliable + 时间戳）；各臂本地 200 Hz 插值执行。
  3. 混合控制：S 由接触状态决定（接触力阈值 2 N + 滞回），插孔阶段 S = diag(1, 1, 0)。
  4. 力控参数：轴向目标力 8 N（保持下压），横向阻抗 kf 从 0.5 起；接触力上限 15 N 触发回退。
  5. 交接：三阶段 + 1.5 s 力渐变 + 回退到双持；交接期间两臂位置锁到同一物体位姿。
  6. 螺旋搜索：接触且未入孔时启动（半径 2 mm、2 s/圈）；入孔判据 = 轴向力回落且深度前进大于 3 mm。
  7. 验收：30 次插孔：成功率大于 90%；峰值接触力小于 15 N；平均耗时小于 20 s；交接 20 次零掉落；断连注入 3 次全部安全回退。

关键代码与解读

片段 1：选择矩阵混合控制

import numpy as np

def hybrid_velocity(e_pos, f_err, S, k_p=150.0, k_f=0.5):
    """混合位置/力控制：S=1 的方向控位，(I-S) 的方向控力。"""
    v = S @ (k_p * e_pos) + (np.eye(3) - S) @ (k_f * f_err)
    return v

def select_matrix(contact_force, in_contact, hysteresis=1.0):
    """接触状态决定选择矩阵：未接触 => 全控位；接触 => z 轴控力。"""
    if in_contact and contact_force > 1.0:
        return np.diag([1.0, 1.0, 0.0]), True   # x/y 控位，z 控力
    return np.eye(3), False                      # 自由运动：全位置控制

解读：hybrid_velocity 的输出直接是任务空间速度修正，量纲统一到"米/秒"：位置项是刚度 × 误差（kp = 150 1/s，等效时间常数约 7 ms），力项是导纳 × 力误差（kf = 0.5 m/(s·N)），两个增益都调"多久收敛"，简化了工程调试。select_matrix 把 S 的切换条件封装：只有"已接触且力超过 1 N"才把 z 轴交给力控；退接触时（in_contact 为假）立即交回位置控制。这里 1.0 的刚度门限与 2 N 的检测阈值配合形成滞回（检测要 2 N、保持只要 1 N），避免在接触边界反复切换。注意 S 必须是"正交投影"形式的对角 0/1，如果给中间值（0.5），意味着同时控位与控力，在刚性接触下会出现两律对抗，接触力震荡。

片段 2：交接三阶段与力渐变

def step_handover(state, obs, dt):
    """交接：PRE_GRASP -> DUAL_HOLD -> RELEASE -> DONE（含回退）。"""
    if state == "PRE_GRASP":
        if obs["second_arm_in_place"] and obs["peer_confirmed"]:
            return "DUAL_HOLD", 0.0
        if obs["time_in_state"] > 10.0:
            return "FAILED", 0.0                 # 第二臂就位超时
    elif state == "DUAL_HOLD":
        t = min(obs["time_in_state"] / 1.5, 1.0) # 1.5 s 内完成力渐变
        obs["set_force"](1, (1.0 - t) * obs["f_grip"])   # 递出方降力
        obs["set_force"](2, t * obs["f_grip"])           # 接收方升力
        if obs["force_exceeded"] or obs["pose_drift"] > 0.01:
            # 异常回退：双方力恢复到 f_grip，重新双持
            obs["set_force"](1, obs["f_grip"])
            obs["set_force"](2, obs["f_grip"])
            return "DUAL_HOLD", 0.0
        if t >= 1.0 and obs["peer_force_ok"]:
            return "RELEASE", 1.5
    elif state == "RELEASE":
        if obs["first_arm_clear"]:
            return "DONE", 0.0
    return state, obs["time_in_state"] + dt

解读：渐变用 t = min(time/1.5, 1) 实现，一条时间归一化曲线，两臂的力指令是同一 t 的互补函数，天然保证"这一秒你说多少我加多少"的守恒感，不会出现双方都松的间隙。回退放在异常的最前面：一旦力超限或位姿漂移超过 1 cm，两边的力立即拉回满值再重新计时，这比"继续渐变然后祈祷"安全得多。peer_force_ok 是同伴对"我接稳了"的确认，进入 RELEASE 前必须等它（屏障），与 059 章同一模式；注意 RELEASE 返回的计时初值取 1.5 s（把渐变耗时从状态计时里延续过来，保证超时判断的连续性），不从 0 起算。这些时间常数（1.5 s、10 s）都应来自实测：交接表面摩擦、零件重量都会影响可行的渐变速率。

片段 3：接触检测与螺旋搜索

import math

def spiral_offset(t, r_max=0.002, period=2.0):
    """螺旋搜索轨迹：两圈内半径从 0 长到 r_max 的平面偏移。"""
    omega = 2.0 * math.pi / period
    r = r_max * min(t / (2.0 * period), 1.0)   # 半径缓慢生长，兼顾覆盖与稳定
    return r * math.cos(omega * t), r * math.sin(omega * t)

def insert_step(f_ax, f_lat, t, f_lat_thresh=1.0, f_limit=15.0):
    """插孔决策：未接触下压 / 接触螺旋 / 超限退出。"""
    if f_ax > f_limit or f_lat > f_limit:
        return "retract", (0.0, 0.0)           # 力超限：优先保护零件
    if f_lat < f_lat_thresh:
        return "insert", (0.0, -0.005)         # 无侧向接触：轴向缓压 5 mm/s
    dx, dy = spiral_offset(t)                  # 有侧向力：螺旋找孔
    return "search", (dx, dy)

解读：spiral_offset 的半径"生长"策略很讲究：固定半径会漏掉大偏移（销一直沿圆周滑），一次给到最大半径又会在接触处产生冲击；线性生长（两圈内 0→2 mm）先在小范围试探、再逐步扩大，覆盖 ±2 mm 的不确定度且起步柔和。insert_step 把装配策略压成三条分支，优先级是"保护零件"高于"完成任务"：力超限立即退出，这是所有力控任务的第一原则。轴向 5 mm/s 的缓压速度（约 0.005 m/s）来自经验：太快会在撞沿瞬间累积超过限值的力，太慢则制约效率；侧向接触判定 1 N，低于它认为"悬空"、高于它认为"碰到了孔沿或孔壁"。螺旋搜索的终止条件不在这个函数里（由外层用"轴向力回落 + 深度前进"判断成功），保持函数只管一步决策，便于状态机化与单测。

常见坑

  • 两臂参考轨迹相位错位：通信延迟导致两臂按不同"时刻"运动，接触刚度高时内力激增。修复：轨迹带时间戳、本地外推 + 速率限幅；把两臂参考差做成在线指标（超过 20 ms 告警）。
  • 纯位置控制硬插：位置不确定度超过孔销间隙，销撞孔沿、越推越卡，严重时顶弯。修复：接触后立即切到力控（S 条件切换）+ 螺旋搜索；接触力阈值 2 N 保证及时切换。
  • 交接时双方同时松手或同时紧握：松导致掉落，紧导致夹持力叠加拧坏零件。修复：力渐变互补函数 + 渐变期间双方力由同一时间曲线生成；进入前屏障确认，进入后监测力曲线形状。
  • 内力层没有独立控制：抓持力随物体运动漂移（加速度引起的惯性力被夹爪力"被动"吸收），长时间操作后抓持松动或紧绷。修复：内力层用零空间分量独立闭环（056 章分解），把夹持力从"副产品"提升为显式控制量。
  • 断连无降级：轨迹流中断后两臂各按最后指令继续，甚至各自回原点，把零件扯下来。修复：0.3 s 冻结、保持夹持；恢复后先做位姿共识；明确"任何单机异常都回到双持安全态"。

练习与思考

  1. 为"旋转阀门 90°"任务设计选择矩阵随时间的变化：接触前、接触后、旋转中三个阶段各方向的控位/控力配置，说明每次切换的触发条件。★
    提示
    接触前全控位；接触后法向（压向阀门）控力、面内控位；旋转时切向控速度/位、轴向保持恒定压紧力。
  2. 画出交接的力-时间曲线（两台各一条）：渐变 1.5 s、fgrip = 8 N。若发生回退（0.8 s 时触发），两条曲线如何走？用坐标草图说明并写一个伪代码分支。★★
    提示
    t=0.8 s 时 A 已降到 ~3.7 N、B 升到 ~4.3 N；回退令两者都回到 8 N（B 上升到 8 即可，A 需回升 4.3 N），再重新开始计时。
  3. 把接触力上限从 15 N 降到 8 N，预测：插孔成功率、平均耗时、传感器噪声引起的误触发率如何变化？给出标定"上限"的实验方法（逐步加载到开始损伤）。★★
    提示
    上限 8 N 与目标力同值，几乎无余量，误触发与失败率上升；标定用假件逐步加载、观察形变/划痕出现点，取其 60%。
  4. 设计一个"相位错位"注入实验：手动给其中一臂的轨迹时延加 30/60/100 ms，测量内力峰值。画出预期曲线并解释斜率含义。★★★
    提示
    内力 ≈ 接触刚度 × 速度 × 时延，随延迟近似线性增长；斜率即"每秒时延对应的等效内力"，是评估系统抗延迟能力的核心参数。
  5. 为"两臂插孔"设计验收指标矩阵（成功率、峰值力、耗时、相位差、回退率），写出每项的目标值、测量方式和失败处置流程；说明哪一项最先触碰时应停止整定。★★★
    提示
    峰值力最先触碰（安全项）：超过 15 N 立即停止参数整定、回到安全检查（抓点/对位/刚度）。验收矩阵的价值在于明确"安全的红线优先于效率达标"。

小结

  • 协同操作分两层：物体层管运动与外部力，内力层用零空间分量管抓持，两层独立闭环。
  • 选择矩阵 S 让自由方向控位、约束方向控力；S 是接触状态的函数，切换要滞回。
  • 位置不确定度必须靠力反馈补偿：接触后力控 + 螺旋搜索，力上限优先于任务效率。
  • 交接三阶段（预抓/双持/释放）+ 1.5 s 力渐变 + 异常回退到双持态，是防掉落防拧坏的骨架。
