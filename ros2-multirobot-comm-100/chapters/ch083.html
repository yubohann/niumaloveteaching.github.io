第四篇 · 系统集成与工程化

第 083 章：多机器人协同控制策略

从"会一种编队"到"一个策略库"：把领航-跟随、虚拟结构、行为法、势场、一致性统一看成期望速度的贡献源，用仲裁、平滑与限幅焊成一个可靠的控制策略层。

  • 主题：协同控制策略层（工程化组织）
  • 关键机制：策略族统一形式、权重仲裁、滞回切换、安全限幅
  • 预计学时：50 分钟
  • 前置章节：第 082 章

学习目标

  • 用统一形式理解五类经典协同控制策略：它们都只是"期望速度贡献源"，差别在信息依赖与几何假设。
  • 掌握策略层仲裁的三种工程手段，权重混合、优先级覆盖、状态机切换，以及各自导致的抖动模式与修复手法。
  • 理解平滑（低通/过渡函数）与限幅（按模长）为什么必须放在仲裁之后统一做，藏在每个策略内部会失效。
  • 会设计分层频率预算：任务层 1 Hz、策略层 20–50 Hz、控制层 100–500 Hz，并说清每一层失败的后果。
  • 能给一个具体场景写"策略选择矩阵"，把需求翻译成策略族、权重参数与切换阈值。

背景与动机

第 041–045 章你已经实现了单一策略：领航-跟随编队。但真实系统里"只做编队"的机器人活不过三天，它要避障、要因为低电量回充、要在任务点之间赶路，这些目标会同时冒出来并互相冲突：编队项想让你贴住队形，避障项想让你远离，回充项想让你拆队。如果这些逻辑散落在各个模块里各写各的，最后速度指令互相覆盖，表现为机器人抖、画圈、或者干脆"原地纠结"。

本章解决的就是这一层的工程化：把每一种协同控制策略降格为"贡献一个期望速度向量的源"，再建一个仲裁器决定各源的话语权，最后统一做平滑与限幅。这样，编队、避障、回充、学习策略（第 082 章）都变成可插拔的模块，换策略不动系统，调权重不动代码。

注意分工：本章讲策略层"怎么组织"，第 091 章讲从集中式到分布式控制机制的理论谱系与最优性-通信代价权衡。前者是工地，后者是图纸。

核心原理

1. 五类策略族的统一形式

经典协同控制策略常被分开讲，但它们有一个统一形式：每台机器人 i 的期望速度 ui 是若干"贡献源"的合成。看五类策略各自在算什么：

策略族期望速度的核心来源信息依赖天然弱点
领航-跟随自身到领航者（或前车）的期望偏移误差前车状态领航者一错全错，链式误差累积
虚拟结构全体跟踪一个虚拟刚体的对应点位虚拟结构中心队形刚硬，窄道里不会"拧身通过"
行为法多个行为向量的加权合成各行为所需传感器权重调不好就抖动、死锁
势场法引力与斥力的负梯度局部障碍与目标局部极小值（掉进陷阱不动）
一致性协议与邻居状态差的加权和（趋同项）邻居状态无编队偏移时只会"抱团趋同"

统一写成：

ui = Σk wk · ui(k)，其中 Σk wk = 1，0 ≤ wk ≤ 1 w 是"话语权"：编队给 0.6、避障按距离升到 0.9、回充按电量升到 0.9，归一化保证速度不会被叠加放大

一致性协议值得单独看一眼它的速度形式：ui = Σj∈N(i) [kp·((pj − dij) − pi) + kv·(vj − vi)]，即"位置向期望偏移靠、速度向邻居看齐"。kp 管收敛快慢，kv 管阻尼：kv 太小会来回过冲，太大则反应迟钝。离散控制周期 T 下的稳定直觉是 |1 − T·kv| < 1，即 kv < 2/T，T = 0.05 s 时 kv 上限约 40，工程上取 0.5–2 是因为要的是平稳，最快响应在这里是次要目标。

2. 为什么"仲裁"必须是一个独立层

冲突无法在策略内部解决：编队策略不知道今天电量低，避障策略不知道队形还有多重要。仲裁层是三件事的集中处理点：

  • 权重混合（blend）：所有源持续参与，按权重合成。优点是过渡连续；缺点是"平均出来的方向"可能谁都不满意（编队与避障半半，速度指向缝里）。
  • 优先级覆盖（subsumption/override）：高优先级行为直接接管输出。优点是安全项可靠；缺点是接管瞬间控制量跳变，必须配平滑。
  • 状态机切换（switch）：模式互斥，同一时刻只跑一个策略。优点是行为可解释；缺点是在阈值附近抖动，修法是滞回：进入与退出用两个不同阈值，中间形成死区。

工程上通常是混合用法：同类目标用权重混合（编队+趋近），异类目标用优先级覆盖（避障/急停），大阶段用状态机切换（任务/回充）。权重变化本身要限速率（例如每秒最多变化 1.0）或用一阶低通，否则"平滑的配方"照样输出抖动的速度。

3. 平滑与限幅：为什么放在仲裁之后统一做

三个理由。（1）一致性：每个源内部各自限幅，合成后仍可能超限（0.9 + 0.9 的向量和），只有出口统一限幅才可靠。（2）保方向：限幅要按向量模长缩放（u ← u·vmax/‖u‖），不能对各分量分别截断，分轴截断会改变方向，让机器人朝"截出来的斜向"跑。（3）可调性：出口低通的时间常数与加速度上限是一个旋钮，试车时统一调；藏在各源里就要到处找。

实现思路与设计

把策略层落成节点结构：上游是任务层（1 Hz，指定目标与模式），本层 20–50 Hz 出期望速度，下游 100–500 Hz 的速度控制器执行；安全限幅在出口常驻。

分层频率预算

层频率职责失败后果
任务/决策层1–5 Hz任务分配、模式选择（编队/回充/待命）行为迟滞但不危险
策略层20–50 Hz贡献源计算、仲裁、平滑编队松散、避障反应慢
速度控制层100–500 Hz轮速闭环、执行期望速度震荡、发散，最危险
安全限幅随控制周期速度/加速度上限、急停覆盖一旦失效，安全无从谈起

策略选择矩阵（起点模板）

场景特征主策略辅助源切换触发
开阔区保持队形虚拟结构或领航-跟随速度对齐（一致性）障碍距离 < 0.8 m 进入避障
窄道/门洞通行行为法（串行跟随车辙）势场斥力通过后 1.5 m 退出
大规模同构集群一致性协议 + 偏移局部斥力无需全局切换
电量低回充导航避障电量 < 25% 进入，充电至 80% 退出

参数起点：位置增益 kp = 0.8–1.5、阻尼 kv = 0.5–2.0；出口低通系数 0.3/0.7（旧值 30%、新值 70%，20 Hz 节拍下约 40 ms 时间常数）；vmax 取底盘额定速度的 80%（留 20% 给避障与整定）；加速度上限 0.5–1.0 m/s²。切换类阈值一律给 0.5–0.7 m 的死区。

设计决策：为什么 vmax 只用到额定值的 80%？

三个原因：速度饱和时机器人之间是"谁先到谁占位"，队形误差会突然放大；导航与避障需要速度余量做机动（想加速躲开却发现已到上限）；电机在 100% 占空比附近控制精度差。留 20% 余量后，编队误差通常能收敛在 10 cm 量级；贴着饱和边缘跑只会来回顶。

关键代码与解读

片段 1：仲裁器，权重混合 + 出口平滑 + 统一限幅

import numpy as np

def smoothstep(x, x0, x1):
    """0 到 1 的平滑过渡函数：用于按距离/电量连续调配权重，避免跳变。"""
    t = np.clip((x - x0) / (x1 - x0), 0.0, 1.0)
    return t * t * (3.0 - 2.0 * t)          # 3t²-2t³：两端斜率为 0

class StrategyArbiter:
    """策略层出口：把各贡献源合成为一个期望速度，统一平滑与限幅。"""
    def __init__(self, v_max=1.2):
        self.v_max = v_max                   # 额定速度的 80%，留机动余量
        self.prev = np.zeros(2)              # 上一步输出，用于一阶低通

    def arbitrate(self, u_form, u_avoid, u_return, obstacle_dist, battery):
        w_avoid = 0.9 * smoothstep(2.5 - obstacle_dist, 0.0, 1.5)  # 越近权重越高
        w_return = 0.9 * smoothstep(25.0 - battery, 0.0, 10.0)     # 电量越低越强
        w_form = max(0.0, 1.0 - w_avoid - w_return)                # 编队吃剩余权重
        u = w_form * u_form + w_avoid * u_avoid + w_return * u_return
        s = w_form + w_avoid + w_return
        u = u / s if s > 0 else np.zeros_like(u)   # 权重归一：防速度被"加总"放大
        u = 0.3 * self.prev + 0.7 * u               # 出口低通：滤掉权重抖动
        self.prev = u
        return self.limit(u)

    def limit(self, u):
        n = np.linalg.norm(u)
        return u * (self.v_max / n) if n > self.v_max else u  # 按模长缩放，保方向

解读：三个设计点。（1）smoothstep 取代线性斜坡，因为线性函数在阈值处斜率突变，权重虽然连续但导数不连续，加速度仍会跳；3t²−2t³ 两端斜率为零，控制量真正平滑。（2）权重归一化是防御性的：即使参数被调成 w_avoid + w_return > 1，合成速度的幅值也不超过任一单项的加权幅值，不会出现"乱调权重突然超速"。（3）先低通后限幅的顺序：先平滑可能把速度略微削小，再限幅确保输出严格满足约束，反过来的话平滑又可能把限幅后的值抬回去。

片段 2：两个贡献源，一致性编队项与势场斥力项

def formation_term(pos_i, vel_i, neighbors):
    """一致性编队项：位置误差 + 速度对齐。
    neighbors 里每项为 (邻居位置 p_j, 邻居速度 v_j, 期望偏移 d_ij)。"""
    k_p, k_v = 1.2, 0.8          # k_p 管收敛速度，k_v 管阻尼：先小后大调
    u = np.zeros(2)
    for p_j, v_j, d_ij in neighbors:
        # (p_j - d_ij) 才是"我在队形里该在的位置"；误差驱动给出速度意图
        u += k_p * ((p_j - d_ij) - pos_i) + k_v * (v_j - vel_i)
    return u

def repulsion_term(pos_i, obstacles, r_safe=1.0, eta=2.0):
    """势场斥力项：只在安全半径内生效，距离越近推力越大。"""
    u = np.zeros(2)
    for p_o in obstacles:
        d = pos_i - p_o
        dist = np.linalg.norm(d)
        if 1e-6 < dist < r_safe:
            # (1/dist - 1/r_safe)/dist² · d：经典斥力梯度形态
            u += eta * (1.0 / dist - 1.0 / r_safe) / dist**2 * d
    return u

解读：一致性项的形状是"差异驱动"，邻居多了自动求和，天然的分布式结构；d_ij 是编队几何的唯一入口，改变 d_ij 就切换队形（菱形、纵队、横列），不需要改控制器。斥力项用了经典势场的梯度形式：距离趋近 r_safe 时推力趋近零（连续衔接）、距离趋近零时按 1/dist³ 上升（快速离开）；工程上要有 dist 下限保护与最大推力截断，否则噪声让距离瞬间趋零时推力会爆表，这种"数学上无穷、工程上必截断"的细节正是理论与实现的差距所在。

片段 3：滞回切换，进入与退出阈值分开

class ModeSwitch:
    """带滞回的模式切换：同一变量用两个阈值，中间是死区。"""
    def __init__(self, enter=0.8, exit_th=1.5):
        self.enter = enter               # 障碍距离小于 0.8 m：进入避障
        self.exit_th = exit_th           # 退到 1.5 m 以上：才切回编队
        self.mode = "formation"

    def update(self, obstacle_dist):
        if self.mode == "formation" and obstacle_dist < self.enter:
            self.mode = "avoid"
        elif self.mode == "avoid" and obstacle_dist > self.exit_th:
            self.mode = "formation"
        # 0.8 ~ 1.5 m 之间：维持现状，不反复横跳
        return self.mode

# 与仲裁器配合：避障模式下把 u_avoid 的权重直接拉到 1.0（优先级覆盖）
sw = ModeSwitch()
mode = sw.update(0.9)    # 若上一步是 formation，此刻切到 avoid 并保持

解读：滞回是"防抖"的标准武器，代价是引入死区，机器人在 0.8–1.5 m 区间内的行为取决于历史（从远到近会进入避障，从近到远才退出），这正是我们想要的：宁可在临界区保持一个确定的行为，也不要每 20 ms 换一次主意。注意模式切换之后还要走仲裁器的出口平滑，因为模式切换会让合成速度突变；"状态机 + 出口低通"是标配组合。若场景里障碍距离本身噪声大，还应先对距离做中值滤波，阈值判断放在滤波后的量上。

常见坑

  • 权重突变导致速度抖动：距离一越过阈值就把避障权重从 0 跳到 0.9，机器人一顿一顿。修复：所有权重用 smoothstep 连续调配，并且出口加一阶低通。
  • 切换无滞回，在阈值上反复横跳：机器人贴线走时模式每秒切换几十次，轨迹呈锯齿。修复：进入/退出双阈值（0.8/1.5 m 这种 2:1 的比例是稳妥起点）。
  • 分轴限幅改变方向：对 vx、vy 各自截断到 1.2，合成向量方向被扭曲，机器人往墙边"斜着蹭"。修复：一律按模长缩放，并检查合成后模长是否超限。
  • 策略层频率不自觉地下调：主循环里做了重计算（比如每周期重新查 KD 树全邻居），频率从 50 Hz 掉到 8 Hz，避障反应突然变慢。修复：邻居查询做增量/降频（10 Hz），策略层只做轻量合成；用 ros2 topic hz 监控实际频率。
  • 忽略加速度约束：速度指令本身不超限，但每周期在 +1.2 与 −1.2 之间跳，等效角加速度超电机能力，轮子打滑。修复：在出口加显式加速度限幅（每周期速度变化 ≤ a_max·T），与低通配合使用。

练习与思考

  1. 改配置并预测结果：把仲裁器出口低通从 0.3/0.7 改成 0.7/0.3（更重的平滑），预测机器人对目标点阶跃指令的响应与避障切换延迟各有什么变化，再用仿真对比稳态误差与响应时间。★
    提示
    更重的平滑 → 时间常数约 3 倍，响应变慢、超调变小、避障切换的"冻结感"增强。预测的关键是：低通引入相位滞后，闭环带宽下降。
  2. 算一算：v_max = 1.2 m/s，仲裁输出 u = (0.9, 0.9)，按模长限幅后的速度是多少？如果改成"分轴各限到 1.2"结果如何、方向差多少度？★
    提示
    模长 1.273，缩放系数 0.943，得 (0.849, 0.849)；分轴限幅则原样保留 (0.9, 0.9)，但语义已超限（模长 1.273 仍超 v_max），所以分轴限幅根本管不住合成速度，方向也没被约束。
  3. 设计：为"白天队列巡逻 + 电量低于 25% 自动回充 + 全程避障"写一张仲裁表（源、权重曲线、切换阈值、滞回带、优先级），标注每个参数的物理依据。★★
    提示
    参考片段 1 与设计章节的矩阵：回充用优先级覆盖并平滑进入，避障权重按距离连续上升，巡逻是剩余权重的底；阈值给出的数值要说明来源（如 25% 电量 ≈ 往返充电桩 + 10% 应急）。
  4. 推导：对速度对齐项 u = kv·(vj − vi)，写出控制周期 T 下的离散更新 vi(t+T) = vi + T·u，证明对单一邻居收敛要求 kv < 2/T，并解释为什么工程取值远小于上限。★★
    提示
    误差 e = v_i − v_j 的更新是 e←(1 − T·k_v)·e，收敛要求 |1 − T·k_v| < 1。取值远小是因为：邻居速度本身在变、离散采样有抖动、多邻居求和使等效增益变大。
  5. 实验：三机器人纵队过 1.2 m 宽窄道，实现两个版本（A：纯阈值切换；B：滞回 + smoothstep 仲裁 + 出口低通），统计切换次数、速度指令的二阶差分（抖动指标）与通过时间，写 5 行结论。★★★
    提示
    预期：B 版切换次数下降一个数量级，抖动指标明显下降，通过时间略增 5–10%，把"平滑换来的时间代价"作为可接受性论证的一部分。

小结

  • 五类策略族统一成"期望速度贡献源"：领航-跟随、虚拟结构、行为法、势场、一致性只是信息依赖与几何假设不同。
  • 仲裁是独立层：同类目标权重混合、异类目标优先级覆盖、大阶段状态机切换；权重一律归一化并连续调配。
  • 平滑与限幅放在出口统一做：smoothstep 调权重、一阶低通滤抖动、按模长限幅保方向、加速度限幅保护执行器。
  • 切换必须带滞回：进入/退出双阈值，用确定的"犹豫"换取确定的轨迹。
  • 分层频率：任务 1 Hz / 策略 20–50 Hz / 控制 100–500 Hz / 安全限幅常驻；每层失败后果不同，监控要盯实际频率。
