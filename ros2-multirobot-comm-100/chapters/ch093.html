第 093 章：多机器人协同避障机制与安全保证

避障从"躲开"升级到"证明躲得开"：ORCA 的互惠半平面、控制屏障函数的安全过滤、对称僵局的打破，以及蒙特卡洛验证的违规率口径。

  • 主题：协同避障机制（安全保证）
  • 关键机制：速度障碍与互惠假设、ORCA 半平面约束、CBF 安全过滤、对称打破、蒙特卡洛验证
  • 预计学时：60 分钟
  • 前置章节：第 092 章

学习目标

  • 理解协同避障的本质困难：别人的未来动作未知，用"互惠假设"（双方各让一半）把它变成可计算问题。
  • 掌握 ORCA 机制：碰撞锥、相对速度、半平面约束 n·v ≥ c，以及多邻居时的可行速度投影。
  • 理解控制屏障函数（CBF）安全过滤：前置不变集的直觉、约束 ḣ ≥ −αh 的含义、"最小修正"为什么是它的灵魂。
  • 会处理对称僵局：同规则正面相遇时的确定性打破与流动策略，保证活性（不卡死）与安全并存。
  • 能设计验证方案：随机场景蒙特卡洛 + 最小间距分布 + 违规率口径，把"安全"变成可报告的数字。

背景与动机

第 044 章你学会了让机器人"看到障碍绕开"，第 084 章学会了用时空规划"提前错开"。但多机器人避障有一个本质困难，前两章只是绕开了它而没有正面解决：避障的对象是会自己做决定的机器人，不是会停在那里的墙。面对墙，你只要保证自己的轨迹不穿墙；面对队友，你的安全取决于"它下一步怎么走"，而它也在想你同样的问题。直接假设对方匀速直行（把队友当"活墙"），在对方也在避让你时就会互相误判：你绕它，它绕你，或者都绕向同一个方向再撞上。

更严峻的是"保证"二字。答辩现场与论文审稿最锋利的问题永远是：你怎么知道不会撞？"我测了 100 次没撞"是经验，不是保证。本章给你两件把"没撞"变成可论证的工具：互惠避让（ORCA 一类），把"对方也会让"写进数学假设，双方各承担一半避让责任；控制屏障函数（CBF），给任意控制器加一层"数学上不可能越界"的安全过滤。最后再给出验证方法论：随机化测试的违规率口径，用数字诚实地报告概率边界。

核心原理

1. 碰撞锥与互惠假设：把"对方会动"变成约束

先看几何。设 A 半径 rA、B 半径 rB，安全半径和 R = rA + rB。把 B 看成"以相对速度 vrel = vB − vA 运动的粒子"，A 看成点：若 vrel 落在一个以"B 相对 A 的方向"为轴、角度由 R 与距离决定的锥形区域内（碰撞锥），双方将在未来某个时刻小于 R。避障问题于是变成：调整 vA，让 vrel 驶出锥区。

谁负责调整、调整多少？这就是互惠（reciprocity）假设登场的时刻：假设对方采用与你同类的避障规则，于是"让出碰撞锥"这份工作量由双方各承担一半。数学上，把相对速度沿"锥边界最近方向"所需的修正量 u 一分为二：A 只需要让 vA 移动 u/2 对应的部分，剩下的 u/2 由 B 承担（前提：B 也确实在执行同类规则）。这个假设把"对方的未来"从不可知变成半可知，这套方法统称 ORCA（Optimal Reciprocal Collision Avoidance，最优互惠避障）。多邻居时，每个邻居产生一条半平面约束：

每条约束写作 nj · vA,new ≥ cj（n 为单位法线，指向可行侧） 求解 = 在全部半平面的交集里找"离期望速度 vpref 最近"的速度：min ‖v − vpref‖，逐条投影迭代 3–5 轮即得可用近似解

量级感：8 台机器人、tau = 2 s 决策时域、每次速度选择 2 ms 内解完、每人每秒 10 次速度更新，速度交换消息约 40 字节 × 邻居数，避障机制的通信代价被压在 KB/s 量级。互惠假设的边界也要说清：面对人、非协作车辆（不按规则让行）时假设失效，此时必须切换到"全责避让"模式：把对方速度的不确定性放大、安全半径加宽、甚至直接停下等人走（这是工程上对"不可信行为体"的标准处理）。

2. CBF 安全过滤：给任何控制器加数学护栏

ORCA 是"怎么规划避让"，CBF 是"如何保证不管上游怎么算都不越界"。设安全函数 h(x) ≥ 0 定义安全集合（例如两机间距：h = ‖pA − pB‖² − dmin²），控制屏障函数（Control Barrier Function, CBF）的机制是给 h 的衰减加一个"下限速率"：

约束：ḣ ≥ −α·h（α > 0 为衰减系数） 含义：h 允许减小，但最慢只能按指数速率退向 0，由此可证"h 永远不会跌破 0"（前向不变性）；α 越小约束越保守

证明骨架（也可以直接讲给答辩评委）：由 ḣ = −αh 的临界情形解得 h(t) ≥ h(0)·e−αt > 0，只要初始安全（h(0) > 0），之后任意时刻都安全。过滤器的用法：上游（规划器、学习策略、甚至人类遥控）给出期望速度 vnom，安全层求解"离 vnom 最近且满足约束 ḣ ≥ −αh 的速度"。这个"最小修正"性质是 CBF 工程化的关键：正常行驶时约束不是紧的，过滤器输出 = 期望输出（零干预）；只有当上游快要越界时，才以最小代价纠偏，所以它不会像"安全距离硬停车"那样破坏任务的流畅性。多个邻居、多条约束时，问题是一个小的二次规划（QP）；单邻居单约束时甚至可以解析投影（本章片段 2）。

3. 对称僵局与活性：安全之外的第二个字

互惠机制遇到完美的对称会瘫痪：两机正面相遇，双方都向右→各偏一点，看起来不错；但若实现里"右侧通行"没定义清楚，可能出现双方都停（互相礼让到底，livelock）或同向绕行再相遇的循环。解决方案按代价排序：（1）规则打破对称，全队约定"迎面时各自向右"（或按 robot_id 大小决定谁让），把对称变成不对称；（2）流动策略（flow），不允许速度瞬间清零，只允许缓慢减速：如果双方都减速，慢的那台先恢复加速（规则判定），几年工程实践下来"流动中队首先行"比"礼让到底"高效得多；（3）扰动打破，平局时加一个由 robot_id 派生的确定性偏置（与第 089 章"确定性平局打破"同构）。活性（liveness）与安全性（safety）是一对指标：安全说"永远不撞"，活性说"永远能走"，只测前者的话，"全体原地不动"是满分系统，而这显然不是你要的。

4. 验证方法论：把"没撞过"变成概率口径

安全机制的验收报告结构（回顾第 098 章之前先给出安全域的专用版本）：

  • 场景随机化：初始位姿、目标点、速度、半径、通信延迟、观测噪声各自按分布采样，覆盖"几何最坏组合"（对穿、窄道汇车、集群绕行）。
  • 批量运行：单个场景跑 2000–10000 次蒙特卡洛（纯软件，毫秒级每次），统计最小间距分布。
  • 违规率口径：违反 = 最小间距 < d_min 的事件数 / 总运行数；同时报告 P5 余量（第 5 百分位的最小间距减 d_min），违规率为 0 时要报告样本量（"0/10000"与"0/100"的信息量差了两个数量级）。
  • 假设敏感度：把互惠假设调包（部分机器人改为"不协作"），报告性能如何退化、安全是否仍由 CBF 兜底，这是审稿人最想看的"对抗性测试"。
  • 真机抽查：仿真全部通过后，选 3–5 个最坏案例上真机，验证模型误差（轮子打滑、控制延迟）是否侵蚀了安全余量。

实现思路与设计

控制管线中的位置：导航/规划（1–5 Hz）→ 避障规划（ORCA，10–20 Hz）→ CBF 安全过滤（每个控制周期，100–500 Hz）→ 电机。两层各司其职：ORCA 管"顺畅地绕开"，CBF 管"任何时刻都不越界"；CBF 的存在让上游可以更激进（允许上游输出被过滤），整体效率反而更高。

组件频率输入输出/保证
邻居状态交换10–20 Hz位姿 + 速度（第 087 章状态通道）一致的邻居快照
ORCA 速度选择10–20 Hz邻居快照 + 期望速度互惠可行速度（假设成立的条件下）
CBF 安全过滤控制周期本机状态 + 邻居状态 + 上游速度前向不变性：h(t) > 0（模型精确时）
紧急层控制周期接近传感器（超声/深度）刹车兜底（不依赖通信）

参数起点与理由

  • 安全距离 dmin= 0.6 m（= 两机半径和 0.5 m + 10 cm 余量）：余量覆盖定位误差（约 5 cm）与量化噪声。噪声大的场景按"3σ 原则"追加：定位 σ = 5 cm 时再加 10–15 cm。
  • 决策时域 tau = 2 s：短于 1 s 反应仓促（速度跳变大），长于 3 s 保守过度（绕行太远、错过时机）；tau 还要与速度匹配：v·tau 应显著大于 dmin（0.8 m/s × 2 s = 1.6 m > 0.6 m，合理）。
  • CBF 系数 α = 2.0（约 0.5 s 时间常数）：约束"最慢衰减速"，α 太大时过滤器干预过强（接近硬约束），太小时上游的越界行为得不到及时纠正。
  • 速度交换消息：位姿 + 速度 + 意图（下一目标点方向），约 40 字节；10–20 Hz 广播，20 台的量级 < 20 KB/s。

互惠假设的工程声明的写法（写进设计文档与论文假设表）："本机制的保证成立当且仅当：所有交互机器人运行同类互惠策略、状态交换延迟低于 100 ms、定位 1σ 误差小于 5 cm。任何一条不满足时，安全保证降级为 CBF 局部保证 + 紧急刹车。"把失效边界写清楚，比多跑一万次实验更有说服力。

关键代码与解读

片段 1：ORCA 半平面构造与互惠修正

import numpy as np

def orca_constraint(pA, vA, rA, pB, vB, rB, tau=2.0, vmax=1.2):
    """构造 A 对 B 的 ORCA 半平面 (n, c)：约束 n·v_new >= c。
    返回 None 表示"双方全速也不可能在 tau 内相遇"，无需约束。"""
    p = pB - pA
    v = vB - vA
    r = rA + rB
    dist = np.hypot(*p)
    if dist > r + vmax * tau:                 # 时域内不可能相遇：快速排除
        return None
    # 相对速度在连线方向上的投影：正在远离（>=0）时通常无需约束
    closing = v @ p
    w = v - p * min(0.0, closing / (dist**2))  # 剔除"远离分量"后的相对速度
    w_len = np.hypot(*w)
    if w_len > r / tau and closing >= 0:
        return None                            # 本就可安全通过：不添乱
    if w_len < 1e-9:
        return None                            # 正对且等速的退化情形（交给打破规则）
    n = w / w_len                              # 指向可行侧的边界法线
    u = n * (r / tau - w_len)                  # 把相对速度推回锥外所需修正量
    # 互惠：A 只承担一半修正，其余假设 B 承担（对等规则下二者合力刚好安全）
    return (n, float(n @ (vA + 0.5 * u)))

解读：这段是 ORCA 的"骨架示意"，边界几何做了教学简化（完整实现建议用成熟的 RVO2 系实现或按其论文逐式实现，但结构一致）。三处关键：（1）快速排除（首行距离判断），多机器人系统里大多数邻居对根本构不成威胁，先排除再精算，是保持低延迟的第一手段；（2）"远离时不添乱"，正在远离的邻居不加约束，否则"出于安全"的过度约束会让机器人无故绕行、队友也跟着绕，形成自激震荡；（3）0.5 的互惠系数是机制的心脏：它编码了"对方也在让"的假设，系数取 1.0（全责避让）会过于保守（把对方助让的部分重复计算），取 0.5 是在对等规则下的正确分工。

片段 2：CBF 安全过滤，沿梯度最小修正

import numpy as np

def cbf_filter(u_nom, p_self, v_other, p_other, u_nom_is_velocity=True,
               d_min=0.6, alpha=2.0, vmax=1.2):
    """单邻居 CBF 过滤（解析版；多邻居迭代或解小 QP）。
    u_nom 为期望速度；约束 dhdv·u_new >= -alpha*h + dhdv·v_other。"""
    dp = p_self - p_other
    h = float(dp @ dp) - d_min**2              # 安全函数：> 0 即安全
    dhdv = 2.0 * dp                            # ∂h/∂p_self
    rhs = -alpha * h + float(dhdv @ v_other)   # 约束右端（整理 ḣ >= -alpha*h 得到）
    u = np.array(u_nom, dtype=float)
    value = float(dhdv @ u)
    if value < rhs:                            # 违反（或恰好逼近边界）：最小修正
        u = u + ((rhs - value) / float(dhdv @ dhdv)) * dhdv
    nrm = np.hypot(*u)
    return u * min(1.0, vmax / max(nrm, 1e-9))  # 修正后再统一限速

解读：四行数学一行修正，把 CBF 的三个工程性质全表达了出来。（1）零干预：若上游本身安全（value ≥ rhs），函数原样返回，正常行驶时过滤器完全透明，不给任务添乱。（2）最小修正：沿 dhdv（安全函数梯度）方向做解析投影，这是"离 u_nom 最近的满足约束速度"的闭式解（单约束情形），修正量精确到不浪费一点机动性。（3）先修正后限速：修正可能把速度顶大，最后一步模长限幅保证执行器约束；与第 083 章"出口统一限幅"的纪律一致。注意 h 的边界值本身：当 h 很小时 rhs ≈ dhdv·v_other，约束几乎强制"远离运动"，CBF 在悬崖边是毫不留情的。

片段 3：蒙特卡洛验证台，最小间距的分布与违规率

import numpy as np

def monte_carlo_safety(simulate, trials=5000, seed=0, d_min=0.6):
    """随机场景批量验证：报告违规率与 P5 余量，"没撞过"不构成安全证据。"""
    rng = np.random.default_rng(seed)
    margins = []
    for _ in range(trials):
        # 场景随机化：起点、终点、初始速度、延迟，全按分布采样
        scene = {
            "starts": rng.uniform(-6, 6, size=(2, 2)),
            "goals":  rng.uniform(-6, 6, size=(2, 2)),
            "delay":  rng.uniform(0.0, 0.1),          # 0-100 ms 通信延迟
        }
        min_gap = simulate(scene, policy="orca+cbf", horizon=12.0)
        margins.append(min_gap - d_min)               # 相对安全距离的余量
    m = np.array(margins)
    return {
        "violation_rate": float((m < 0).mean()),      # 违规事件占比
        "p5_margin_m": float(np.percentile(m, 5)),    # 第 5 百分位余量
        "n": trials,                                   # 口径必须带样本量
    }

解读：验证台的三条纪律都在这段里。（1）随机化的维度要与假设对齐：起点终点覆盖几何多样性，delay 覆盖"互惠假设的时延边界"（0–100 ms 正是假设声明的边界），随机化不是乱撒，是把假设表逐项变成分布。（2）用"余量分布"替代布尔结果：P5 余量告诉你"最坏 5% 的场景离违规还有多远"，比违规率更能指导调参（余量偏薄就加大 d_min 的噪声补偿）。（3）样本量随结果一起报：违规率 0 时，"0/5000" 意味真实概率的 95% 置信上界约 6×10⁻⁴，这是安全报告的诚实写法，也是练习 5 的一部分。

常见坑

  • 对不可协作对象也用互惠假设：行人、手动遥控车、外来无人机会"不按套路出牌"，互惠假设当场失效。修复：行为体分级，注册在案的队友用互惠；未注册体一律按全责避让（自己承担 100% 修正）+ 加宽半径。
  • 对称僵局无打破规则：两机迎面完美对称，同时减速到零，安静地卡死。修复：确定性打破（比 robot_id 或"向右让"）+ 流动策略（慢者先恢复）；死锁检测并入第 084 章的监控告警。
  • 安全距离不含噪声余量：d_min 取物理半径和，定位一漂 10 cm 就贴脸。修复：d_min = 物理半径和 + 3σ（定位与测速综合）；且 CBF 的 α 与传感器速率匹配，观测 20 Hz 时按 50 ms 滞后估计最大越界速度。
  • 上游"知道"有过滤器而摆烂：把安全全部外包给 CBF，上游故意输出激进速度，过滤器长期在边界上工作，一旦模型误差出现就没有余量。修复：验收时统计"过滤器干预率"，健康系统干预率 < 5%；持续高位说明上游规划不合理，要回去改上游；调大 α 只会掩盖问题。
  • 验证场景覆盖偏窄：只在开阔地对穿测 100 次，窄道汇车、三机交汇、延迟 100 ms 组合全没测。修复：场景设计矩阵化（几何 × 密度 × 延迟 × 噪声），每个格子给固定预算，谁也不许被"顺手漏掉"。

练习与思考

  1. 算一算：A 在 (0, 0) 以 vA = (0.8, 0) 前进，B 在 (2.0, 0.1) 以 vB = (−0.8, 0) 迎面（正前方、横向错开 0.1 m）。rA = rB = 0.3 m，tau = 2 s。用片段 1 的公式手算：相对速度、是否命中豁免分支、以及朝向"向 +y 侧"的半平面 (n, c)。（提示：把 B 放到 y = 0 的完美对穿会命中 w = 0 的退化分支，恰好说明对称僵局该交给打破规则处理。）★
    提示
    v_rel = (−1.6, 0)，closing = −3.2（正在接近，不豁免）；剔除靠近分量后 w ≈ (−0.004, 0.080)，|w| ≈ 0.08 < R/tau = 0.3，需要约束。n = w/|w| ≈ (−0.05, 0.999)，u = n·(R/tau − |w|) ≈ 0.22 沿 n 方向；A 承担一半修正，沿 n 方向约 0.11 m/s（主要落在 +y 分量）。c = n·(v_A + u/2) ≈ 0.07，即 A 的新速度须满足 n·v_new ≥ 0.07；它原来的 n 分量只有 −0.04，正好补上这 0.11。
  2. 改配置并预测结果：把 d_min 从 0.6 m 减到 0.45 m（物理半径和就是 0.5 m，即欠 5 cm 余量）。预测蒙特卡洛实验中 violation_rate 与 P5 余量的变化方向，并说明为什么这会"在仿真里看起来还行、上真机立刻失效"。★
    提示
    σ=5 cm 的定位误差下，物理 0.5 m 的需求配上 0.45 m 的设定，等于 1σ 内必然违规，仿真里如果没注入定位噪声就看不出来；真机上误差天然存在，违规立刻显形。结论：d_min 必须 ≥ 物理半径和 + 3σ。
  3. 设计：一个混合场景，3 台注册机器人 + 2 个可移动机器人（无通信、按固定路线行驶）。给出行为体分级规则、各自的安全半径与避让责任分配（谁承担多少修正），以及"未注册体突然变向"时的兜底与告警设计。★★
    提示
    注册体互惠（各 0.5）；未注册体按最坏假设：速度不确定集放大 + 半径加宽（含预测误差）+ 自己承担 1.0 修正；突然变向触发紧急刹车层（不依赖通信的超声/深度兜底），同时上报告警供人工介入。
  4. 推导：设 h(t) 满足 ḣ(t) = −α·h(t)（约束取临界），证明 h(t) = h(0)·e−αt；再说明若约束是 ḣ ≥ −αh（不等式）且初始 h(0) > 0，为什么 h 永不跌破 0（提示：用比较原理或反证法构造 h 穿越 0 的时刻矛盾）。★★
    提示
    临界解直接积分得到；不等式情形用比较：设 g 为临界解（会永远 > 0），h(0) ≥ g(0)，且 ḣ ≥ ġ 恒成立，则 h(t) ≥ g(t) > 0，穿越零需要先追上指数为正的 g，矛盾。这就是前向不变性的最小证明。
  5. 实验：用片段 3 框架跑 5000 次（几何随机 + 延迟 0–100 ms），得到 violation_rate = 0。计算该结果的 95% 置信上界（提示：0 事件时上界 ≈ 3/N 的"三法则"），再跑一组"20% 机器人不协作"的对抗实验，填写安全报告模板：假设、样本量、违规率、P5 余量、对抗退化、结论。★★★
    提示
    三法则：0/5000 → 上界约 6×10⁻⁴（3/5000 量级）。对抗组里互惠型机器人的安全保证由 CBF 局部兜底，报告应显示违规率仍为 0 但干预率大幅上升、P5 余量变薄，用数据说明"保证的降级路径"。

小结

  • 协同避障的本质困难是"对方的未来未知"；互惠假设（双方各让一半）把它变成可计算约束，ORCA 是代表机制。
  • ORCA 半平面约束 n·v ≥ c：先快速排除无威胁邻居，再解"离期望速度最近"的可行速度；0.5 的互惠系数是假设与效率的平衡点。
  • CBF 安全过滤：约束 ḣ ≥ −αh 保证 h 的指数下界 → 前向不变性；"零干预 + 最小修正"让它能罩住任意上游（规划器或学习策略）。
  • 对称僵局用确定性与流动策略打破；安全（不撞）与活性（能走）必须成对验收。
  • 验证口径：蒙特卡洛场景矩阵化、违规率带样本量、P5 余量、对抗敏感度；假设边界写清楚比多跑实验更有力。
  • 实践规则：dmin = 物理半径和 + 3σ；对不可协作体全责避让；紧急刹车层永远不依赖通信。
