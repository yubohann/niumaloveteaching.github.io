第五篇 · 科研进阶与协同机制

第 092 章：多机器人协同导航机制

没有 GPS 的大楼里靠"互相看"导航：相对距离观测、可观测性与刚性图、锚点轮换、位姿图校正，以及队形退化时系统怎么知道自己"其实看不见"。

  • 主题：协同导航机制（相对观测与可观测定）
  • 关键机制：UWB 距离观测 EKF、Fisher 信息与刚性、锚点轮换、位姿图校正
  • 预计学时：60 分钟
  • 前置章节：第 091 章

学习目标

  • 理解协同导航的信息结构：里程计漂移、相对观测（距离/方位）、绝对锚点三者如何互补，缺一不可。
  • 掌握距离观测的 EKF 更新机制（雅可比、新息、增益），以及为什么一段距离观测只能约束"一个方向"的信息。
  • 理解可观测性的工程判据：Fisher 信息矩阵最小特征值，为什么"排成一条直线的距离测量编队"有不可观测方向。
  • 会用刚性图计数（2N−3）快速检查队形拓扑是否"撑得起来"，并据此设计锚点轮换机制。
  • 能设计退化处理：可观测性余量低于阈值时降速、补测、换形，导航系统要对自己的"看不清"有自知之明。

背景与动机

室外靠 GNSS（米级到厘米级）定绝对位置，室内 GNSS 失效，机器人退化成"盲人摸象"：轮速里程计每走 100 米漂 1–3 米，惯性单元几分钟漂出几十米。单机自救的办法是 SLAM（第 028 章），在环境里找特征回环。但在空旷仓库、地下管廊、灾难废墟这类"特征稀疏"的环境里，SLAM 也会失灵：四面白墙，没有回环，漂移无处可纠。

协同导航（cooperative navigation）给出了另一种答案：机器人互相观测，把彼此当作"会动的路标"。A 测 B、B 测 C、C 测固定的 UWB 锚点，观测链把绝对参考一路传递出去，全队共享一个坐标系统。它把"单机加传感器"的问题转化成"团队拓扑 + 观测图"的问题，属于第 086 章说的信息结构设计：你在图里连了哪些边，决定了你能看见哪些方向。

本章的机制视角与第 029 章（定位融合，工程实现）互补：029 讲怎么把观测喂进滤波器，本章讲"什么样的观测配置才有效、失效了怎么办"，可观测性分析是协同导航区别于普通定位融合的关键增量。

核心原理

1. 三类信息：里程计、相对观测、锚点

协同导航系统里所有信息按"约束什么"分三类：

信息来源频率/精度约束能力
相对运动（里程计/IMU）轮速、IMU 积分50–100 Hz，漂移 1–3%/距离短时平滑，长时漂移
相对观测（距离/方位）UWB、视觉、激光互测5–20 Hz，距离 5–20 cm约束"队形"（互相之间的相对几何）
绝对锚点固定 UWB 基站、已知地标1–10 Hz把队形钉到全局坐标系

三者缺一不可的直觉：相对观测锁住队形、锚点锁住整体平移旋转、里程计填帧间空隙。只有相对观测没有锚点：队形保持但整体漂走（全队一起漂得整整齐齐）；只有锚点没有相对观测：每台各自被锚点约束，队友之间看不见，遮挡环境下各自的位置估计互不一致；只有里程计：几分钟后图上全员乱飞。工程上"三类信息齐全"是验收的第一条，必须最先检查。

2. 一段距离观测能约束什么：EKF 的几何读法

UWB 测距给出的是"两台设备之间的距离 r = ‖p₁ − p₂‖"，噪声 5–20 cm。把一段距离观测注入位置估计，EKF 的更新公式给出一阶线性化后的答案：

预测距离 r̂ = ‖μ₁ − μ₂‖；雅可比 H = [ ∂r/∂p₁ ∂r/∂p₂ ] = [ uᵀ −uᵀ ]，u 为连线方向单位向量 关键读法：距离观测只沿"两点连线方向"提供信息，垂直于连线的方向分量（切向）完全不受约束

这个几何事实统治了本章所有设计：一段距离观测把不确定性椭圆从"全方向"压扁成"沿垂直方向的一条带"，机器人仍然可以在以对方为圆心的圆上任意滑动（需要角度信息或多段观测交集才能消掉）。两台对射问题、一个锚点圆问题、直线队形问题，本质都是"某些方向没人管"。可观测性分析就是把这些"没人管的方向"提前找出来。

3. 可观测性判定：Fisher 信息矩阵的最小特征值

把所有观测（每段距离、每个方位、里程计约束）各自的一阶雅可比 Jk 叠加成 Fisher 信息矩阵 F = Σ JkᵀRk−1Jk（Rk 为观测噪声协方差），可观测性就是一句话：

状态可观测 ⇔ F 正定（最小特征值 > 0）；工程上用 λmin(F) 当"可观测性余量" F 的特征向量就是"信息方向"：特征值越小的方向，估计越不确定；λmin ≈ 0 意味着某方向完全没人管

三个典型场景的读法：（1）直线队形 + 纯测距：4 台排成一条直线，每台只测相邻距离，整个队形可以沿"垂直于直线的方向"整体平移而不改变任何距离读数，也可以绕直线轴旋转；F 有对应零特征值，不可观测。（2）矩形/三角队形：距离约束相互交叉，内部的剪切与折叠会改变某些距离，这类形变被全部管住；剩下的整体平移与整体旋转（任何纯距离图都躲不开这两个零空间）要另靠锚点边锁住，两者齐备时 F 才正定。数学上有精确的图论判据：二维距离测量图要达到全局刚性（rigidity）至少需要 2N − 3 条边，且这些边不能"叠在局部小结构里"（现实是：别让全队依赖某三台互相观测、其他人靠一条线挂在外面）。（3）方位观测（bearing）：视觉给的角度约束性质完全不同，一段方位观测沿"垂直视线的方向"提供信息，与距离互补；距离 + 方位混合的图总信息量更高，这也是视觉辅助的 UWB 系统流行的原因。

4. 从可观测性到机制设计：锚点轮换与退化处理

真实系统里可观测性是动态的：队形走成直线、某台机器人遮挡、锚点基站信号被货物挡住，λmin 会周期性跌破阈值。机制侧的应对有四条，按代价排序：

  1. 重配队形（最重）：让一两个成员挪出直线，恢复刚性，代价是路径变长。
  2. 锚点轮换：把"靠近固定基站、能稳定看见锚点的机器人"指定为移动锚点，广播自己的高置信位姿供队友相对观测，相当于把绝对参考"接力"传递出去；轮换触发条件是当前临锚的 λ 贡献下降或它要离开视距。
  3. 临时降速（轻）：不确定性增长与速度成正比（走 1 米和走 3 米的漂移差 3 倍），λmin 低于阈值时降速 50%，把"漂移速率"压缩，等待观测几何恢复。
  4. 可靠停靠（最保守）：不确定度进入"不可接受"区间时停靠并原地保持观测（像陀螺一样维持对锚的视线），等外部条件改善，永远比"带着瞎猜的位置继续跑"安全。

四条机制构成一个分级退化策略，触发线由 λmin 与估计协方差共同定义：λmin 预报"将来会看不清"，协方差报告"现在已经看不清"，前者用于预防（重配、轮换、降速），后者用于止损（停靠）。

为什么同时看"未来"（λ）与"现在"（σ）：λ 是几何预报（还没走坏就先缩），σ 是账本现状（已经走坏就停），两个指标在实验里经常不同步：队形刚变成直线时 σ 仍然很小（还准着呢），但 λ 已经塌了，这时降速是便宜的预防；等 σ 涨起来再处理就贵了。

关键代码与解读

片段 1：距离观测的 EKF 更新，沿连线方向的信息注入

import numpy as np

def range_update(mu, P, r_meas, p_other, sigma_r=0.1):
    """用一段距离观测更新自身位姿（EKF，状态 [x, y, vx, vy]）。
    p_other 为对方位置（已知/来自对方广播的位姿）。"""
    d = mu[:2] - p_other
    r_hat = float(np.hypot(*d))
    if r_hat < 0.2:
        return mu, P                      # 过近：近场噪声与多径异常，整段跳过
    H = np.zeros((1, 4))
    H[0, 0], H[0, 1] = d[0] / r_hat, d[1] / r_hat   # 只沿连线方向有信息
    S = float(H @ P @ H.T) + sigma_r**2               # 新息方差
    K = (P @ H.T / S).flatten()                       # 卡尔曼增益（4 维向量）
    mu = mu + K * (r_meas - r_hat)                    # 沿梯度方向修正
    P = P - np.outer(K, H @ P)                        # 协方差收缩（简化式）
    return mu, P

解读：这段 15 行代码把第 2 小节的几何事实写成了可运行的形式：H 只有一行且只在 x、y 两个分量上非零，距离观测永远不直接修正速度，速度是通过 P 里的相关性被动微调的。三个工程细节：r_hat < 0.2 的近场保护（UWB 近场误差大且可能有直耦合多径，宁缺毋滥）；协方差用 P − K·(H·P) 简化式更新，数值上不如 Joseph 形式稳定，实机长跑建议换 Joseph 形式或每次更新后强制对称化；vx、vy 的被动修正意味着静止时的表现和运动时不同，测距频率跟不上运动时，更新会"拖后腿"，这正是要做运动补偿的原因。

片段 2：可观测性余量，F 的最小特征值当预警信号

import numpy as np

def observability_margin(poses, edges, sigma=0.1):
    """Fisher 信息矩阵的最小特征值：越小越接近"看不清的方向"。
    poses: [(x, y), ...]；edges: [(i, j), ...] 纯距离观测边。"""
    n = len(poses)
    F = np.zeros((2 * n, 2 * n))
    for i, j in edges:
        d = np.array(poses[i]) - np.array(poses[j])
        r = float(np.hypot(*d))
        u = d / r                          # 连线方向单位向量
        J = np.zeros((1, 2 * n))           # 这段观测对全状态的一阶影响
        J[0, 2*i:2*i+2] = u                # 对 i：沿连线的信息
        J[0, 2*j:2*j+2] = -u               # 对 j：反方向的信息（成对出现）
        F += (J.T @ J) / sigma**2          # 每段观测贡献一个秩 1 信息块
    return float(np.linalg.eigvalsh(F)[0])
    # 直线队形：除整体平移/旋转外，侧向弯曲也是零信息方向（额外零空间）
    # 方形队形：内部形变被交叉约束管住；整体平移/旋转的零空间要靠锚点边补

解读：把它当成"导航健康度仪表"的实现：输出量是纯几何的（只依赖队形与观测配置），与 Kalman 状态无关，所以可以离线或以 1 Hz 低频运行，对计算毫无压力，还能用于"走哪条路能把可观测性保下来"的路径级规划。注意信息块按 1/σ² 加权：用质量好的观测（小 σ）加权更大，如果视觉相对观测和 UWB 距离一起进 F，视觉的贡献会自动放大，这为"视觉辅助增强可观测性"提供了定量依据。函数返回最小特征值，配上一句日志（队形 + 余量），事故复盘时就是第一手证据。

片段 3：位姿图校正，把长时漂移一次性拉回来

from scipy.optimize import least_squares

def optimize_pose_graph(initial, edges):
    """位姿图优化（平移简化版）：节点 = 各机位姿，边 = 里程计/相对观测。
    完整实现应将位姿放进 SE(2)（含朝向），此处以平移模型展示结构。"""
    def residuals(x):
        out = []
        for (i, j, z_ij) in edges:
            pi, pj = x[2*i:2*i+2], x[2*j:2*j+2]
            out.extend((pj - pi) - z_ij)     # 约束残差：预测相对位姿 − 观测值
        return out
    # LM 求解：小幅初值扰动下二乘收敛快；初值用当前在线估计（热启动）
    sol = least_squares(residuals, initial, method="lm", max_nfev=200)
    return sol.x

# 边从三类来源累积：（i→j）里程计增量；UWB 距离（需两阶段的处理）；
# 关键：锚点约束必须至少有一条进图，否则整图仍可整体漂移

解读：位姿图与滤波器的分工：滤波器管"现在"，位姿图管"过去"，把累积的相对观测与里程计一起优化，把长时漂移一次拉回。三个工程要点：（1）热启动，初值用当前在线估计，LM 在好初值下几毫秒收敛；不要把上一次优化结果当万能初值（地图与队伍都在变）。（2）锚点边必须有：注释里那句话是刚性的，纯相对图优化完，整张图依然可以整体平移旋转（F 的零空间），锚点边把零空间锁住。（3）平移简化只是教学版：真实实现要 SE(2)/SE(3) 位姿与鲁棒核函数（防错误观测拽偏全局），这也是现成库（如 GTSAM 风格工具）值得直接用的原因。

常见坑

  • 直线队形仍全速前进：4 台排一列、只测相邻距离，侧向整体漂移不可观测，长走廊里越走越歪。修复：λmin 监控 + 插入"锯齿形"成员或安排侧向观测；至少保证有一条非共线观测边。
  • 把 UWB 距离当同步观测用：运动中的测距延迟 10–50 ms 当零延迟处理，1 m/s 下注 1–5 cm 系统偏差，还让滤波器"自信错位"。修复：时间戳 + 速度补偿到共同时刻；没有时间戳的测距设备不接入融合。
  • 忽略相对观测间的相关性：两台机器人各自都相对同一个临锚观测，误差强相关，直接独立融合导致协方差过度收缩。修复：沿用第 088 章结论，CI 保守融合；或者干脆在团队滤波器里显式维护交叉协方差。
  • 锚点单点依赖：全队只靠一个 UWB 基站，基站被货架遮挡，整队瞬间从"厘米级"掉到"漂移级"。修复：锚点轮换机制 + 多锚点几何（至少两个不同方位的锚，避免共线）。
  • 视觉相对观测认错对象：两台同款机器人外观一致，视觉把 A 认成 B，融合后位置估计直接跳变，导航里的"张冠李戴"是最危险的一类错误。修复：视觉相对观测必须带身份特征（AprilTag、灯语、唯一外观），置信度低于阈值宁可丢弃。

练习与思考

  1. 算一算：5 台机器人做纯距离协同导航，按刚性计数 2N − 3 至少需要多少条距离边？给出一个恰好达到下限的队形图与一个"边数够但仍不可观测"的反例（提示：把 4 条边挤在一个三角形里，第 5 台只挂了一条线）。★
    提示
    2×5−3 = 7 条边。反例：前 4 台组成完整三角+链（6 条边），第 5 台只有 1 条边挂出去，总边 7 条但第 5 台可绕弧线滑动。结论：边数只是必要条件，还要"处处刚性"。
  2. 改配置并预测结果：把锚点连接从"两台机器人各有 2 条锚边"减为"全队唯一 1 条锚边"。预测：(a) 整体坐标系会发生什么漂移模态；(b) λmin 如何变化；(c) 你的退化处置会如何触发。★
    提示
    单锚边只能钉住"这一个点"的相对位置，整队绕该点旋转的模态不可观测（圆环滑动）；λmin 掉到接近 0；触发预警（降速）甚至止损（停靠）。补充：两条非共线锚边可钉住平移+旋转。
  3. 设计：为一个"地下管廊 6 台机器人 300 米作业"场景写锚点轮换机制：谁有资格当临锚（判据）、临锚广播什么（字段）、何时轮换（触发条件）、轮换时旧临锚退出的协议（避免参考系跳变）。★★
    提示
    判据：对固定锚的观测质量 + λ 贡献 + 电量；广播：位姿 + 协方差 + 有效期；轮换：重叠双临锚（新旧同时广播 5–10 s）再切，直接切换会让队友参考系跳变。
  4. 推导：考虑"1 台机器人 + 1 个锚点 + 单段距离观测"的二维问题。写出 Fisher 信息矩阵，证明 λmin = 0（存在不可观测方向），并指出该方向是什么；再加第二个锚点（与第一个不重合），证明 λmin > 0。★★
    提示
    单锚：F = uuᵀ/σ²（u 为锚到机器人的连线方向），秩 1、二维空间里垂直 u 的方向特征值为 0，机器人可绕锚做圆周滑动（切向不可观测）。双锚：F = u₁u₁ᵀ/σ² + u₂u₂ᵀ/σ²，只要 u₁ 与 u₂ 不平行，两秩和满，λmin = 较小方向的信息量。
  5. 实验：4 台机器人、纯 UWB 测距、固定双锚。(a) 直线队形沿长廊走 100 米；(b) 方形队形走同样路径。各跑 5 次，记录末端位置 RMSE 与 λmin 时间序列；再用 (a) 的失败案例验证"λ 预警 → 降速"能否把末端误差压回可接受范围。★★★
    提示
    预期：(a) 出现沿走廊轴向与横向的整体漂移模态（横向不可观测），RMSE 随距离增长；(b) 稳定在 0.1–0.2 m。降速实验的关键读数：同一路径的误差 ≈ 漂移率 × 时间，速度减半、观测恢复后误差增长斜率明显变缓。

小结

  • 协同导航三信息：里程计（高频、漂移）、相对观测（锁队形）、绝对锚点（锁全局）；缺一不可。
  • 距离观测只约束连线方向（切向不可观测）；EKF 里表现为 H 的几何方向与协方差的"带状"收缩。
  • 可观测性判据：Fisher 信息矩阵最小特征值；直线距离队形存在侧向滑移与弯曲的额外零空间，矩形/三角队形把内部形变管住，整体平移与旋转留给锚点边消除。
  • 刚性计数 2N − 3 是必要条件不是充分条件；观测质量（σ、频率）直接进 F 的加权，视觉辅助能显著抬高余量。
  • 退化机制四级递进：重配队形 → 锚点轮换 → 降速 → 停靠；λmin 做预防、协方差做止损。
  • 实践纪律：测距带时间戳并补偿、CI 处理相关误差、锚点多方位冗余、视觉相对观测必须防认错。
