第三篇 · 协同控制与任务协同

第 058 章：协同搬运长物体

抬一根 2.4 米的型材过 90° 弯：两端机器人必须服从同一个刚体速度约束，用最小二乘与残差监控内应力，用经典"梯子过弯"判据预先算清几何可行性。

  • 主题：任务协同 / 刚体姿态约束搬运
  • 关键机制：刚体速度约束最小二乘、内应力残差、梯子过弯判据、柔顺修正
  • 预计学时：65 分钟
  • 前置章节：第 057 章

学习目标

  • 理解长物体搬运的首要矛盾是姿态一致性：长度越大，两端速度失配产生的内应力越大。
  • 掌握由多点速度最小二乘反解 (vo, ωo) 的方程与残差含义，会把它当作内应力在线指标。
  • 能用"梯子过弯"公式判断几何可行性，并设计分段转弯轨迹与末端速度约束。
  • 会设计柔顺修正：内应力超阈值时用限幅的小速度修正化解矛盾，不许硬顶。
  • 能分析时间不同步与里程打滑在长物体场景下被放大的机制，并给出补偿手段。

背景与动机

057 章的重物是"方的"，推力配平做到位，物体就老实。长物体是"细长的"：一根 2.4 m 的铝型材，两端各一台机器人，姿态偏差 1° 就对应两端 2 cm 的位置差；一端快 2 cm/s、另一端慢 2 cm/s，几秒钟内就产生几十牛的拉扯。长物体把所有位置与时间误差乘以长度放大，同时对几何空间提出刚性要求，过弯时物体的扫掠包络比机器人大一个数量级。

本章是协同搬运三部曲（056 框架 / 057 推重物 / 058 长物体）的收尾，也是 059、060 章"抓取与操作"的姿态控制前传：那里讨论的抓持矩阵与约束求解，与这里的最小二乘反解是同一套线性代数工具。工程上长物体搬运广泛出现于管廊、料架、门窗安装场景，是"多机器人协同质量"最直观的展示科目。

核心原理

1. 刚体速度约束：两根手指抬一根棍

长物体（长度 L，两端抓持点距中心 ±L/2）与小物体的本质区别：姿态（即物体的角速度 ωo）与平动同等重要，不再是可以忽略的次要变量。刚体约束要求两端的接触速度都由同一对 (vo, ωo) 派生：

v1,2 = vo ± ωo·[−ry, rx] 两端到中心距离大（r ≈ L/2），ωo 的微小误差被放大为两端的大速度差；L = 2.4 m、Δω = 0.05 rad/s 时两端差达 0.12 m/s

反过来，从两端实测速度反解对象速度是超定问题：3 个未知量（vox, voy, ωo）、每端 2 个方程（共 4 个），一般无精确解。最小二乘给出"最接近的刚体运动"，而残差的模长正是内应力指标，残差为零说明两端完全协调；残差 0.1 m/s 意味着某一端正被以这个速率"拽着走"，乘以等效刚度就是内力。在线监控这个残差，比等到电流报警早得多。

2. 内应力与柔顺：别用刚性对抗刚性

内应力的来源有四类：两端指令超出刚体可行空间、时间不同步（一端按 100 ms 前的指令走）、里程打滑（一端"以为"走了实际没走）、标定误差（抓持点距中心的距离不准）。对抗内应力的原则是用柔顺换取稳定：把抓持做成"可测量力 + 可调刚度"的虚拟弹簧，当内力超过阈值（示例 20 N）时，让"被拽"的一端产生一个限幅的小速度修正（0.05 m/s 量级），向矛盾方向退让半步。这与 057 章的导纳控制同源，只是作用对象从"机器人与地面"换成了"机器人与物体"。

为什么不让控制器"硬顶"？因为刚性对抗刚性会形成正反馈：A 拽 B、B 抵抗、力道增大、A 更用力。柔顺修正虽然让轨迹暂时偏离理想路径（毫米到厘米级），但把系统从"结构受力"模式切换到"位置误差"模式，后者可修正，前者只能损坏零件。

3. 过弯几何：梯子的经典判据

长物体过 90° 走廊拐角的经典问题（ladder around a corner）：两条走廊宽 A、B，能通过的最长物体（忽略宽度）为：

Lmax = (A2/3 + B2/3)3/2 A = B = 1.2 m 时 Lmax ≈ 3.4 m；考虑物体宽度 d 后，用有效宽度 (A − d, B − d) 代入

这个公式给的是"理想操控下"的上限，它还假设物体可以贴着墙角无摩擦滑动。现实中要留 20–30% 的裕度并核对门宽：直行段通过门要求门宽大于物体宽度加两侧余量；转弯时物体两端扫掠包络要求弯角处有净空，"绕中心旋转"策略需要额外 2–3 倍物体宽度的空间。若几何上不满足 L ≤ Lmax 的裕度版，任何控制算法都救不了，必须先改变几何（拆门、换路线、拆解物体）。这就是"先算几何、再谈控制"的顺序。

4. 转弯策略与末端速度

几何可行之后，轨迹分三段：(1) 对准段，把物体中心与航向对准弯道入口，速度降到 0.2 m/s；(2) 旋转段，物体绕自身中心旋转 90°，同时缓慢前移（纯原地旋转可能需要更大空间，边转边移更省空间）；(3) 直行段，进入新走廊，恢复速度。旋转段的核心约束是末端线速度：

vtip = ωo · L/2 ≤ vtip,max L = 2.4 m、vtip,max = 0.4 m/s → ω ≤ 0.33 rad/s；90° 旋转至少需要 (π/2)/0.33 ≈ 4.7 s

末端速度限制不只是"撞不撞"的问题，还是"拿不拿得住"的问题：末端加速度 ≈ ω̇·L/2，末端从静止加速到 0.4 m/s 只需要很小的 ω̇，但惯性力沿物体传到抓持点，L 越大力矩越大。所以旋转段还要限制角加速度（示例 ≤ 0.2 rad/s²），两端抓持力上限随之校核。

5. 时间同步与打滑：长物体的"放大镜"效应

两个在短物体上无害的误差，在长物体上会被放大：时间不同步，两端指令相差 100 ms，若物体正在以 0.2 rad/s 旋转，两端位置就相差约 0.2×0.1×1.2 = 2.4 cm 的弧长偏差；里程打滑，一端里程"虚报"了 3 cm/s，L/2 = 1.2 m 的另一端要真实走 3 cm/s 才能保持刚体约束，误差被几何放大。补偿手段：指令带时间戳、接收端外推到执行时刻（与 044/049 章同套机制）；打滑用视觉/共识的物体位移做闭环修正（与 057 章同套检测）。两条机制都要在"旋转段"提高优先级，旋转是误差最敏感的时段。

6. 数值算例：过弯几何、末端速度与残差标定

过弯几何：两条走廊宽 A = B = 1.2 m，物体宽度 0.1 m 时有效宽度 1.1 m，梯子公式给出 Lmax = (1.12/3 + 1.12/3)1.5 ≈ 3.11 m。长度 2.4 m 乘 1.25 的裕度系数是 3.0 m，压线通过；若物体宽度换成 0.3 m，有效宽度 0.9 m，Lmax ≈ 2.55 m，2.4 × 1.25 = 3.0 已经超过上限，直接判不可行。这条走廊的通行能力对物体宽度极其敏感，宽 0.1 m 到 0.3 m 就让结论翻转，预检必须用实测宽度，标称值靠不住。

末端速度与时间：ω 上限由末端速度反推：0.4/1.2 = 0.333 rad/s。90° 旋转的最短时间是 (π/2)/0.333 = 4.71 s；再叠加角加速度限制 0.2 rad/s²，升速段耗 0.333/0.2 = 1.67 s、转过 0.333²/(2×0.2) = 0.277 rad，降速段对称，剩下 1.571 − 0.554 = 1.017 rad 由匀速段用 3.05 s 走完，总时间约 6.4 s。这多出的 1.7 s 就是加速度限制的代价，排转弯节拍时要按 6.4 s 计算，4.7 s 只是理论下界。

时延应力的换算：ω = 0.3 rad/s 时两端末端速度 0.36 m/s；两端指令时延差 80 ms 对应弧长错位 0.36 × 0.08 = 2.9 cm；按等效刚度 500 N/m 换算约 14.4 N 的内力，已经用掉 20 N 告警线的七成。80 ms 的同步误差在 2.4 m 长物体上就能吃掉大部分告警余量，这就是旋转段要把同步要求压到 50 ms 以内的原因。

残差对标：用片段 1 的最小二乘做数值实验：两端名义速度都是 0.3 m/s，其中一端轮子打滑 +5 cm/s（实际 0.35 m/s）。拟合结果是 vo = 0.325 m/s、ω = 0，残差范数 0.0354 m/s，两端各分到约 2.5 cm/s 的"不可解释分量"，按 500 N/m 折算约 17.7 N 内力。5 cm/s 的打滑就已经接近 20 N 告警线，残差指标对打滑非常敏感；残差长时间贴着告警线运行，优先查轮速标定与地面状况，不要先怀疑算法。

几何预检的清单与拒绝阈值（出发前五分钟逐项过）：走廊与门宽要求大于物体宽度加 0.2 m；弯角净空按 Lmax 含 25% 裕度判定；斜坡坡度折算推力预算，超过 5% 要重算摩擦余量；地面摩擦系数低于 0.4 时把末端速度上限再压 30%；障碍物按方位扫掠包络核对；抓持点位置决定有效的 L/2，需与实际夹具安装位置一致。任何一项不满足就拒绝任务，先改路径、再改控制，顺序不能反。

7. 与相邻形态对照：长物体为什么最敏感

形态关键约束核心状态变量典型失败
单机搬运承载与自身动力学本机位姿倾覆、打滑

读表的判据：物体越细长，姿态（角速度）在状态里的权重越高，从可忽略（方形重物）到并列（长物体）再到主导（对接与插装）。长物体是所有形态里对时间同步最敏感的一档：内力残差的量纲是速度误差乘刚度，误差被 L/2 放大，所以同步与标定预算都要比短物体紧一档。下一章回到抓持形态时，这套残差监控与柔顺思想会直接复用，只是把"两端"换成"多抓持点"。

再补一个量级对照：若把 2.4 m 物体当成"大号单机"用车顶托架运输，等效轴距不足会让转弯扫掠半径远大于本方案；双端协同的扫掠半径由两端轨迹包络决定，任一端 0.15 m 的横向误差在 1.2 m 力臂上对应约 7° 的姿态偏差，超过本章 5° 的验收线。所以两端的路径跟随误差预算要收紧到 0.1 m 以内（对应约 4.8°），比第 049 章的通用预算（P95 小于 0.15 m）更紧；预算收紧后若跟随误差压不下去，优先降速，不放宽姿态验收。两类对照（形态表与误差预算）共同说明：长物体搬运的难点不在单机算法，而在把几何、同步与标定三件事同时做到位；排故时先查三者中偏离最大的一环，再动控制参数，这套顺序能省下大量反复调试的时间。

实现思路与设计

  1. 任务设定：两根抓持臂夹住 2.4 m × 0.1 m 铝型材的两端（接触点到中心 ±1.2 m），通过 1.2 m 宽走廊的 90° 弯；物体宽度 0.1 m，有效走廊宽 1.1 m，Lmax ≈ 3.1 m，裕度约 30%。
  2. 指令流：leader 发布对象 (vo, ωo)（20 Hz、Reliable）；各端按刚体约束折算接触速度；转弯段 ω 上限 0.33 rad/s，角加速度上限 0.2 rad/s²。
  3. 反馈流：两端上报实测接触速度与力（20 Hz）；leader 做最小二乘反解，残差作为内应力指标广播（10 Hz）。
  4. 柔顺：内力超过 20 N 触发柔顺修正（限幅 0.05 m/s），超 40 N 停机；修正量随时间衰减（弹簧模型）。
  5. 几何预检：任务开始前计算 Lmax（含宽度余量与 25% 裕度）、门宽、弯角净空，任一不满足直接拒绝任务。
  6. 验收：10 次过弯：到位误差小于 0.15 m、姿态误差小于 5°、内应力峰值小于 25 N、全程无停机；端部碰撞事件 0 次。

关键代码与解读

片段 1：两点速度最小二乘反解与残差

import numpy as np

def solve_object_twist(p1, v1, p2, v2):
    """由两个抓持点速度最小二乘解 (v_o, omega)；残差模长 = 内应力指标。"""
    center = 0.5 * (np.asarray(p1) + np.asarray(p2))
    r1 = np.asarray(p1) - center
    r2 = np.asarray(p2) - center
    # 每点两条方程：v_i = v_o + omega x r_i
    A = np.array([[1.0, 0.0, -r1[1]], [0.0, 1.0, r1[0]],
                  [1.0, 0.0, -r2[1]], [0.0, 1.0, r2[0]]])
    b = np.concatenate([v1, v2])
    sol, *_ = np.linalg.lstsq(A, b, rcond=None)
    residual = b - A @ sol                  # 两个点各自"无法被刚体解释"的分量
    return sol, float(np.linalg.norm(residual))

解读：这里用两个抓持点速度解三个未知量，4 个方程超定，lstsq 给出最小二乘解，它与 056 章对象位姿拟合是同一思想的"速度版"：从多个不完全一致的自由度里提取最可能的刚体运动，不一致量保留下来作为故障信号。残差模长直接作为内应力指标（单位 m/s），换算成牛顿只需乘等效刚度（示例 500 N/m 量级），命中 057 章"力是速度误差的映射"的同一逻辑。三个注意点：中心点直接取两端中点，对任意两点都成立（无需预先定义原点）；r 的符号约定要一致（否则 ω 反号）；两点几乎重合时矩阵病态，应检查 |p1−p2| 大于 0.2 m 才调用（长物体场景天然满足）。

片段 2：梯子过弯几何预检

def ladder_max(a, b):
    """经典结论：直角走廊宽 a、b 时能通过的最长细杆长度。"""
    return (a ** (2.0 / 3.0) + b ** (2.0 / 3.0)) ** 1.5

def corner_feasible(length, obj_width, corridor_a, corridor_b,
                    margin=1.25):
    """把物体宽度折减为有效走廊宽度，并留 margin 倍余量判定。"""
    eff_a = corridor_a - obj_width
    eff_b = corridor_b - obj_width
    if eff_a <= 0.05 or eff_b <= 0.05:
        return False, 0.0                    # 物体比走廊还宽：直接不可行
    limit = ladder_max(eff_a, eff_b)
    return length * margin <= limit, limit   # 要求 length x 1.25 <= 上限

解读：ladder_max 是少见的"拿来即用"的解析结论，它把"最长能搬多长"从仿真试错变成一行计算。两处工程化处理：宽度折减，物体有宽度 d，走廊实际可用空间是 A − d（物体中心线才能贴到理论极限），这个折减让判据保守化；裕度系数，公式假设无摩擦、无控制误差，实际乘 1.25 的保守因子，判据式写成"需求长度 × 1.25 ≤ 上限"。返回 (False, 0.0) 时不要试图调控制器参数硬上，几何不可行是物理约束，唯一出路是改路径、改几何或分解物体，这个函数的价值就是让团队在出发前五分钟得到这个结论。

片段 3：内应力柔顺修正

import numpy as np

def compliance_correction(f_meas, k_c=0.002, limit=0.05):
    """接触力超常时产生限幅的小速度修正：让半步，化解内应力。"""
    v_fix = np.array([-k_c * f_meas[0], -k_c * f_meas[1]])
    n = float(np.linalg.norm(v_fix))
    if n > limit:
        v_fix *= limit / max(n, 1e-9)        # 修正永不大于 0.05 m/s
    return v_fix

def stress_level(stress_norm, warn=20.0, stop=40.0):
    """三级处置：正常 / 柔顺修正 / 停机。"""
    if stress_norm < warn:
        return "normal"
    if stress_norm < stop:
        return "comply"
    return "stop"

解读：柔顺修正的本质是"以小幅轨迹偏差换取结构受力下降"，kc = 0.002 m/(s·N) 意味着 25 N 的拉力换来 0.05 m/s 的退让速度，方向与力相反（哪边被拽，哪边顺着走）。限幅 0.05 m/s 是关键：再大就不再是"柔顺"而变成"改变任务"，如果柔顺修正已经到限幅还是顶不住 20 N 的力，说明误差超过了柔顺能消化的范围，应该停机检查（标定、同步、打滑），这与 057 章打滑策略的分级思想完全一致。三级处置返回字符串，不直接执行动作，保持函数可测试；真正的停机/恢复逻辑在状态机里，且恢复要求"力回落到 10 N 以下持续 1 s"，留出回差防抖。

常见坑

  • 两端指令各自为政：两台机器人分别闭环到自己的目标点，或各用各的 ω 估计，刚体约束从源头被破坏。修复：所有运动指令由唯一的对象 (vo, ωo) 派生；两端只需执行换算。
  • 转弯前不做几何预检：到了弯口才发现转不过去，现场"磨蹭"（反复微调）半小时。修复：任务开始前用梯子判据 + 25% 裕度判定；不可行直接改路径。
  • 硬顶内应力：两端以位置控制刚性对抗，电流飙升、结构异响。修复：柔顺修正 + 阈值停机；把内应力残差作为一等公民指标接入监控。
  • 忽略末端速度限制：按中心速度 0.3 m/s 设计，旋转时末端实际 0.6 m/s，撞墙或甩脱。修复：ω 上限由 vtip/(L/2) 反推；角加速度同步限幅。
  • 时间不同步被长度放大：100 ms 的指令时延在旋转段变成两端 2–3 cm 的弧长错位，内应力周期波动。修复：指令带时间戳 + 外推执行；旋转段把同步要求提高到 50 ms 内（必要时提高广播频率）。

练习与思考

  1. 走廊 A = B = 1.2 m，物体宽度 0.1 m，长度 2.4 m。用梯子公式计算 Lmax 并判断可行（含 25% 裕度）。若物体宽度改为 0.3 m，结论是否变化？★
    提示
    有效宽 1.1 m，Lmax = (1.12/3×2)1.5 ≈ 3.1 m；2.4×1.25 = 3.0 ≤ 3.1 勉强通过。宽 0.3 m 时有效宽 0.9 m，Lmax ≈ 2.5 m，2.4×1.25 > 2.5 不可行。
  2. L = 2.4 m，ωo = 0.3 rad/s。计算两端末端线速度与相差的指令时延（80 ms，两端方向相同）造成的弧长错位；说明它等效多少内应力（等效刚度 500 N/m）。★★
    提示
    末端速度 = 0.3 × 1.2 = 0.36 m/s；错位 = 0.36 × 0.08 ≈ 2.9 cm；等效力 = 0.029 × 500 ≈ 14.5 N，已用掉 20 N 告警线的七成。
  3. 用最小二乘代码做数值实验：给两端注入随机噪声与一个系统性偏差（一端 +5 cm/s），观察残差如何随打滑增大；设计"残差—打滑比"的实测标定曲线方法。★★
    提示
    系统偏差直接进入残差（这是它的设计用途）；标定方法：人为给一端轮子加阻尼制造已知打滑，记录残差均值与力传感器的对应关系。
  4. 把柔顺增益 kc 从 0.002 改为 0.0005 与 0.01，预测：内应力峰值、轨迹偏差、系统振荡倾向的变化；给出一个能实测"柔顺是否足够"的扰动实验。★★★
    提示
    太小：柔顺不起作用、力峰高；太大：往复让路、轨迹蛇形。实验：一端程序化注入 -3 cm/s 的"拖拽扰动"，观察力峰值与恢复时间。
  5. 为长物体搬运写"几何预检清单"：至少八项检查（走廊宽度、门宽、弯角净空、地面摩擦、斜坡、障碍、物体宽度、抓持点位置），每项给出计算式或测量方法与拒绝阈值。★★★
    提示
    斜坡项要折算有效推力与打滑；障碍项核对方位扫掠包络；抓持点位置决定 L/2 的有效值与末端速度限制，清单的价值在于把"到现场才发现"变成"出发前拒绝"。

小结

  • 长物体的核心矛盾是姿态一致性；两端速度误差被 L/2 放大，ω 的限值由末端速度反推。
  • 两点速度最小二乘反解 (vo, ωo) 兼做状态估计与内应力监测：残差模长就是"不协调程度"。
  • 过弯先用梯子判据算 Lmax = (A2/3+B2/3)3/2（含宽度折减与 25% 裕度），几何不可行时任何控制都无解。
  • 内应力用柔顺修正（限幅 0.05 m/s）化解，20 N 告警、40 N 停机；时间同步与打滑检测在旋转段提级。
