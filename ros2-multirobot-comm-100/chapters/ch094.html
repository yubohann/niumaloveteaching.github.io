第五篇 · 科研进阶与协同机制

第 094 章：多机器人协同编队机制与稳定性分析

编队为什么"必定"收敛：图拉普拉斯、势函数与李雅普诺夫三件套，代数连通度决定收敛速度，驻留时间保证队形切换不炸，稳定性从直觉变成可检验的命题。

  • 主题：协同编队机制（稳定性分析）
  • 关键机制：拉普拉斯矩阵、一致性协议、势函数李雅普诺夫、代数连通度、驻留时间切换
  • 预计学时：65 分钟
  • 前置章节：第 093 章

学习目标

  • 掌握编队的图论描述：邻接矩阵、拉普拉斯矩阵 L = D − A，以及"连通性 → 形状收敛"的因果链。
  • 会构造带偏移的一致性编队控制律，并写出它的势函数（总形状误差）作为李雅普诺夫函数。
  • 理解稳定性证明的三步骨架：V ≥ 0、V̇ ≤ 0、等号仅在意向均衡态成立，并能将每一句对应到代码与实验。
  • 掌握代数连通度 λ₂ 的含义与典型值（链/环/全连接的对比），用 λ₂ 预估收敛时间。
  • 理解队形切换的稳定性条件：公共李雅普诺夫 + 驻留时间，能从实验中识别"切太快"的失败模式。

背景与动机

第 041–045 章你做过编队控制（领航-跟随、编队变换），那是"把队形开出来"；本章回答一个更硬的问题：凭什么相信队形一定收敛、而且不会在扰动、切换、通信变化下散架？凭感觉调参的编队，在仿真里整齐漂亮，一旦加入 100 ms 延迟或丢掉一条通信边，误差就可能不衰减甚至发散，而你无从判断是"参数没调好"还是"机制本身不收敛"。

本章把编队问题写成数学：队形是图上的一组相对约束，编队控制律是一个动力系统，稳定性用李雅普诺夫函数证明。这套语法的价值有三层：能证明（论文与答辩的硬通货）、能设计（λ₂ 告诉你换拓扑能把收敛快几倍）、能诊断（V 上升 = 立刻知道哪一步实现有问题）。它不是纯理论装饰，本章的每个定义后面都跟着"怎么在代码里算、怎么在实验里测"。

与第 091 章的分工：091 讲控制机制的"信息结构与代价精算"，本章讲编队这一具体机制的"动力学与稳定证明"；第 094 章的数学也是 095 章（势博弈）与 097 章（共识在规划中的用法）的共同底座。

核心原理

1. 从图到动力学：拉普拉斯矩阵是编队的"骨架"

把机器人抽象为图的节点，能互相观测/通信的成对关系是边。两个矩阵描述这张图：邻接矩阵 A（aij = 1 表示有边）与度矩阵 D（对角线存每台机器人的邻居数）。它们的差是拉普拉斯矩阵：

L = D − A；每行和为 0；对全 1 向量 L·1 = 0 L 的特征值可排序 0 = λ₁ ≤ λ₂ ≤ … ≤ λ_N；λ₂（代数连通度）> 0 ⇔ 图连通

为什么 L 是编队的骨架：考虑最简单的"速度对齐 + 位置趋同"动力学 ẋ = −L·x（x 是全体位置），分量形式 ẋi = −Σj∈N(i)(xi − xj)，每台机器人朝邻居的平均位置移动。它的解收敛到全体初值的平均（L 的零空间），收敛速率由 e−λ₂t 控制：λ₂ 越大收敛越快，λ₂ = 0（图断开）则分裂成互不相干的簇。这就是"代数连通度决定队形收敛速度"的完整含义。

加入间距偏移 dij（队形的几何形状），控制律变成"朝邻居的期望相对位置移动"：

ui = −kp·Σj∈N(i) [ (pi − pj) − dij ] − kv·vi kp 拉向队形（收敛速度），kv 速度阻尼（消灭过冲）；j∈N(i) 表示只有通信到的人才进公式，拓扑即算法

典型图的 λ₂ 感受一下（单位：1/s 量级，直接决定指数收敛的时间常数 1/λ₂）：全连接 N=5 时 λ₂ = N = 5（收敛极快但每条边都要通信）；环状 N=5 时 λ₂ = 2(1 − cos(2π/5)) ≈ 1.38（时间常数约 0.7 s）；链状 N=5 时 λ₂ = 2(1 − cos(π/5)) ≈ 0.38（时间常数约 2.6 s，效率最低）。同样的控制器、同样的增益，换个通信拓扑收敛慢 3.6 倍，这是"拓扑设计 = 性能设计"的定量证明。

2. 势函数：把"队形误差"变成一个能量

稳定性证明的第一步是找一个非负的标量函数 V，势函数（potential function），度量"整个队形离目标形状有多远"：

V = ½·Σ(i,j)∈E ‖(pi − pj) − dij‖² ≥ 0 每条通信边对"相对位置的违反量"贡献一个平方项；V = 0 ⇔ 队形精确达成（在偏移约束意义上）

注意三条性质，它们逐条对应实验里可测的东西：（1）非负性：V 是平方和，永远 ≥ 0；实验里画 V 曲线，它应该单调下降（带阻尼的振荡收敛）。（2）V̇ ≤ 0：对上面的控制律求导可得 V̇ = −Σi ‖∂V/∂pi‖² ≤ 0（无阻尼项时），势能被"梯度下降"消耗；加上 kv 阻尼后 V̇ ≤ 0 仍然成立且振荡更快消散。（3）零的刻画：V̇ = 0 只在每个偏导为零时取得，即所有边约束同时满足，恰好是队形达成的状态。三步合起来就是经典的 Lyapunov 论证："能量非负、不增、只有目标态不消耗" ⇒ 系统收敛到目标态（对连通图成立）。

相邻的第二种编队机制是距离型（刚性）编队：约束采用"相对距离"d̂ij（第 092 章的刚性概念），替代"相对偏移向量"。距离型的优点是不需要全局参考系（只须量距离），代价是势函数有多个局部极小（对称形状陷阱），需要初始构型离目标形状够近，两种机制在工程上都有使用，选择判据：有统一坐标系且通信稳定 → 偏移型（凸问题）；只有测距且要省通信 → 距离型（小心局部极小）。

3. 队形切换：稳定系统 + 稳定系统 ≠ 稳定切换

队形变换（纵队切横队）本质是切换系统：不同队形各自有稳定的李雅普诺夫函数 V₁、V₂，但在切换瞬间控制目标突变，动能可能骤增，切得太快，系统在两种势场之间来不及消耗能量，表现为队形撕裂、机器人擦身。控制理论给出的条件是两条：（1）公共李雅普诺夫函数（或每模式各自的函数满足衰减的拼接条件）；（2）驻留时间（dwell time），相邻切换之间强制等待足够长的时间，让 V 先下降一个可接受量。工程化的翻译：切换请求必须通过双门限，"距上次切换 ≥ 最短间隔"且"当前队形误差 V 已收敛到小值"。用第 083 章的滞回思想看：切换是最高优先级的模式变化，所以它也需要门槛和平滑。

切换路径本身也要设计：从纵队到横队，各机器人各自"直线走过去"会在中心撞成一团；标准做法是把切换建模为带时间参数的中间队形插值：dij(s) = (1−s)·dijold + s·dijnew，s 从 0 平滑到 1（时长 2–5 s），期间 V 对"当前时刻目标形状"度量，把一次大跳变变成一串小位移，每帧都在收敛。

实现思路与设计

编队节点与控制律的实现约定：

要素设计理由
控制频率50 Hz位置环常规档位；10 Hz 太慢会出现"一顿一顿"的队形呼吸
邻居位姿获取状态通道 10 Hz + 本地位姿外推控制 50 Hz 不应等待 10 Hz 的观测；外推用短时匀速模型
增益起点kp = 1.5 /s²（等效加速度/米），kv = 1.0 /s按"二阶系统阻尼比 0.5–0.8"估算：kv ≈ 2ζ√kp
拓扑选择环形优先（λ₂ 大），链状仅用于窄道纵队环状 λ₂ ≈ 1.38 vs 链状 0.38：同带宽下收敛快 3.6 倍
切换门限驻留 ≥ 2 s 且 V < 0.05 m²双重门限：时间 + 状态，缺一会放行"半稳"切换

验收指标（写进实验章）：稳态队形误差 RMSE < 10 cm（室内、无风）；收敛时间（从初始散开到 V 进入稳态 5% 带内）≤ 4 s；切换期间最小机间距 ≥ 0.6 m（与第 093 章同一口径）；丢一条边后误差回升幅度 ≤ 15% 且 10 s 内重新收敛。指标里"丢边测试"最容易被漏，但它正是 λ₂ 从 1.38 掉到 1.0 的真实检验。

设计决策：验收指标为什么选 V，不用"平均位置误差"？

平均位置误差（每台离自己目标点位多远）需要绝对参考系，且掩盖"形状错但整体平移"的情形（第 092 章的漂移模态在这里再现）。V 只由相对约束构成：它度量形状本身，与整队漂移无关，形状对、整体漂 10 cm，V 依然为 0；形状错、整体完美定位，V 也会报警。指标选得对，实验结论才不会被参考系误差污染。

关键代码与解读

片段 1：拉普拉斯矩阵与带偏移的编队控制律

import numpy as np

def build_laplacian(adj):
    """L = D − A。图连通 ⇔ λ2 > 0；λ2 直接换算收敛时间常数 1/λ2。"""
    deg = adj.sum(axis=1)
    return np.diag(deg) - adj

def formation_accel(pos, vel, adj, offsets, kp=1.5, kv=1.0):
    """带偏移的编队控制：u_i = −kp·Σ[(pi−pj)−dij] − kv·vi。
    offsets[i][j] 是期望的 p_i − p_j（有向偏移，双向边时两者互为反号）。"""
    n = len(pos)
    err = np.zeros_like(pos)
    for i in range(n):
        for j in range(n):
            if adj[i, j] > 0:                    # 拓扑决定谁进公式：通信边 = 控制项
                err[i] += (pos[i] - pos[j]) - offsets[i][j]
    return -kp * err - kv * np.asarray(vel)      # 位置误差驱动 + 速度阻尼
    # 注意 err 的结构与 (L⊗I) 展开一致：连通图上误差趋于零 ⇔ 队形达成

解读：这段 15 行是全章数学的代码化身。（1）邻接矩阵直接出现在循环条件里：v1 版可以把邻居列表换成"全队可见"（广播全队位置）这一不优雅版本，算出的控制量只在拓扑不同时才有差别，这正是"拓扑即性能"的字面含义。（2）双向边的偏移互为反号（dji = −dij）：实现时若两边写了不一致的偏移（比如都是"我左边的位置"），队形会收敛到一个扭歪的稳态，这类错误 V 不会震荡，只会稳定在一个错误的形状上，是复盘最花时间的一类 bug。建议：offsets 只由队形生成器生成，禁止手写。

片段 2：势函数监控，把李雅普诺夫函数放进仿真循环

import numpy as np

def potential(pos, adj, offsets):
    """V = ½·Σ_(边) ‖(pi−pj)−dij‖²：形状误差总能量（单调下降是理论保证）。"""
    n = len(pos)
    V = 0.0
    for i in range(n):
        for j in range(i + 1, n):
            if adj[i, j] > 0:
                e = (pos[i] - pos[j]) - offsets[i][j]
                V += 0.5 * float(e @ e)
    return V

解读：这个模式（理论量直接进仿真循环并落盘）是"可验证研究"的最低配置。日志里的 V 曲线同时服务三个目的：验收（单调下降、终值接近零）、诊断（哪一帧开始上升，倒查那一帧的限幅/切换事件）、论文配图（一条干净的 V(t) 收敛曲线胜过十张轨迹截图）。三个嫌疑的排错顺序也有讲究：先查 dt（数值积分不稳定会伪装成控制发散），再查限幅（饱和让理论假设失效），最后查增益与偏移矩阵的符号，按"便宜到昂贵"排序，别一上来就怀疑机制。

片段 3：队形切换，驻留时间 + 收敛门限双保险

class FormationSwitcher:
    """带驻留时间的队形切换：拒绝"半稳就切"与"切得太勤"。"""
    def __init__(self, dwell=2.0, v_threshold=0.05):
        self.dwell = dwell                 # 驻留时间：两次切换最短间隔（秒）
        self.v_threshold = v_threshold     # 收敛门限：V 低于它才允许切
        self.t_last = -1e9
        self.current = "column"

    def request(self, target, now, V_shape):
        if target == self.current:
            return None                    # 目标没变：不是切换请求
        if now - self.t_last < self.dwell:
            return None                    # 条件一：距上次切换不足驻留时间
        if V_shape > self.v_threshold:
            return None                    # 条件二：旧队形还没收敛，先站稳
        self.t_last = now
        self.current = target
        return target                      # 放行：由上层启动插值过渡（s: 0→1）

解读：把"驻留时间"和"收敛门限"做成两个独立的拒绝理由，是这段代码的核心设计，任何一个单独都不够：只有驻留时间，系统可能在"永远来不及收敛"的队形间来回切换（每个都站不稳就换）；只有收敛门限，可能在 V 恰好低迷的瞬间被高频反复利用（切换抖动本身消耗能量）。双门限与实践直觉一致：先站稳，再换队形，用插值平滑走过去。类里不做实际的插值过渡（那是队形生成器的职责），保持"决策与执行分离"，这与第 083 章仲裁器的哲学一脉相承。

常见坑

  • 链状拓扑在长队列上收敛过慢：10 台链状编队 λ₂ ≈ 0.1，时间常数 10 s，队尾误差大且"摆动传导"。修复：网格化的分层合队（长链加旁路链），或接受慢收敛但降低增益防震荡；婚礼队形（纵队）只在必要时用。
  • V 上升却归咎于机制：多半是数值积分步长太大或控制量饱和。修复：dt 至少比最短时间常数小一个数量级；饱和状态也进日志（限幅一开，理论即失效）。
  • 切换过程中机器人擦身：插值路径经过彼此。修复：过渡期给每台机器人加"路径优先级"（第 084 章的预约思想），或把过渡设计成两段式（先散开、再合拢）。
  • 丢边后无人发现：通信中断使某条边消失，L 变了、λ₂ 掉了，但控制器照常跑（只是精度变差），直到队形歪出指标才被发现。修复：运行期计算当前拓扑的 λ₂ 与连通性，掉边超阈值即告警（连不上图就用不相干的分簇模式，别假装无事）。
  • 距离型编队走进局部极小：几台机器人卡在对称位置互相"顶牛"，队形差但谁都不动。修复：加入微小扰动打破对称、换初始构型，或改用偏移型控制；把"V 长时间不降但也不接近零"设为专门告警条件。

  4. 推导：对带偏移的编队控制（无阻尼、无权图），验证 V̇ = −kp·Σi ‖∂V/∂pi‖² ≤ 0；并说明为什么只有"图连通"才能推出 V → 0（提示：图断开时 V 的下降只能保证每簇内部自洽，簇间偏移误差不在任何人的偏导里）。★★

    V̇ = Σ ∇ᵢV·ṗᵢ = Σ ∇ᵢV·(−k_p ∇ᵢV) = −k_p Σ‖∇ᵢV‖²。断开时跨簇的边根本不在 V 的求和里，两簇各自收敛到各自形状，但簇间的相对偏移（形状的一部分）不受约束，所以全局 V 未必到零。
  5. 实验：N = 5，分别跑(A) 环状拓扑、(B) 链状拓扑，记录 V(t) 收敛曲线并拟合收敛率，与 λ₂ 理论值对照；然后在 (A) 运行中途人为切断一条边 10 s，记录误差回升与恢复过程，给出"丢边容忍"结论。★★★
    提示
    拟合收敛率应接近 e^(−λ₂t)（带阻尼时略快）。断边 10 s：λ₂ 降为环→链的水平，误差以可测幅度回升，边恢复后按新 λ₂ 衰减，报告里给出"拓扑健康度 → 队形误差"的定量链条。

小结

  • 编队的骨架是图：L = D − A，行和为 0；ẋ = −Lx 收敛到平均，速率由代数连通度 λ₂ 决定。
  • 带偏移的编队律 ui = −kpΣ[(pi−pj)−dij] − kvvi；拓扑即算法，偏移矩阵只许由生成器产出。
  • 稳定性三步：V = ½Σ‖(pi−pj)−dij‖² ≥ 0；V̇ = −kpΣ‖∇iV‖² ≤ 0；等号仅在意向均衡。连通是 V → 0 的必要条件。
  • λ₂ 换算收敛速度：N = 5 时全连接 5 / 环状 1.38 / 链状 0.38，同控制器换拓扑差 3.6 倍。
  • 队形切换是切换系统：公共李雅普诺夫 + 驻留时间；插值过渡把大跳变拆成小位移。
  • 验收：稳态误差 < 10 cm、收敛 ≤ 4 s、切换最小间距 ≥ 0.6 m、丢边 10 s 内恢复，V 曲线是贯穿它们的主证据。
