多机器人协同学习课程 · ROS2 通信与系统集成

离线 HTML 教程 · 重原理、重设计、重注释 · 从 DDS 通信到协同系统集成

5 篇 100 章：通信基础 → 数据协同 → 协同控制 → 系统工程 → 科研进阶，每篇一个阶段项目。

通信基础 ×20 数据与协同感知 ×20 协同控制与任务 ×25 系统集成 ×20 科研进阶 ×15
阅读方式

1. 每章结构：学习目标 → 背景与动机 → 核心原理 → 实现思路与设计 → 关键代码与解读 → 常见坑 → 练习与思考 → 小结。

2. 代码片段是机制示意（rclpy / launch / CLI），重点在读懂"为什么这样写"；运行请以对应 ROS2 发行版与官方文档为准。

3. 每篇末尾的"阶段项目"章把本篇机制串成可验收的工程闭环，适合作为科创项目作业。
