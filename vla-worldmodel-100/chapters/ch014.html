第 014 章：基于世界模型的规划与VLA策略结合

本章把世界模型用作规划器内核：以交叉熵方法搜索动作序列、以策略输出作为提议分布热启动、以打分函数筛选候选轨迹，并给出规划与直接执行的切换准则。

  • 主题：世界模型 / 规划与策略结合
  • 关键公式：a* = argminâ E[Cost(τ̂(â))]
  • 预计学时：65 分钟
  • 前置章节：第 013 章

学习目标

  • 理解反应式策略与预测式规划两类决策模式的差异与适用条件。
  • 掌握交叉熵方法（Cross-Entropy Method, CEM）的规划循环：采样、推演、打分、精英重拟合。
  • 掌握策略与规划器的三种结合方式：提议分布热启动、局部精化、规划蒸馏。
  • 会设计打分函数：目标代价、成功判定、平滑性与终端价值的组合。
  • 能建立规划与直接执行的切换准则，并诊断打分错位、样本不足、超时三类问题。

背景与动机

004 章的策略一次前向即输出动作块，快但只依赖训练分布内的直觉；006 章的世界模型可以推演候选动作的后果，慢但能显式比较。规划就是利用世界模型“先试后做”的能力：在想象中评估多个候选动作序列，选出代价最低的一个再执行。策略与规划的结合让系统兼具反应速度与决策深度。

纯规划在公开工作中有两个已知短板：采样空间大时搜索效率低，且长视界推演的误差累积会污染打分。VLA 策略恰好补上第一点，它的输出分布是对“可行动作流形”的强先验，把搜索限制在高概率区域；短视界加终端价值的组合补上第二点。本章按此构造混合系统。

边界：006 章生成训练轨迹，本章生成执行决策；015 章关注信息获取，本章关注代价最小化；089 章展开长程规划的分层结构。

核心原理

1. 反应式与预测式两类决策

反应式策略直接映射观测到动作，代价是一次前向；预测式规划先在世界模型中推演候选动作序列的后果，再决策：

a*t:t+L-1 = argminâ Eô~pϕ[ Cost(ôt+1:t+L, â) ] L 为规划视界（5–10 步）；Cost 为打分函数；期望由世界模型多次采样近似

规划的优势在分布外场景：训练数据未覆盖的障碍布局、新的目标组合，策略的直觉可能不可靠，而世界模型可以比较多个候选的后果。代价是计算：候选数与视界相乘决定前向次数，实时性需要预算约束。两类模式的对照见下表。

决策模式世界模型前向相对开销分布外表现适用
反应式策略01 倍依赖训练覆盖常规执行
预测式规划约 1728 帧级约三个数量级候选比较，更稳高不确定与新任务

2. CEM 规划循环

连续动作空间的直接优化不可解，CEM 用迭代式分布拟合逼近最优序列：从初始分布采样 N 条动作序列，推演后保留代价最低的 K 条（精英集），用精英集重拟合分布的均值与方差，重复若干轮。

μ ← (1/K)·Σi∈精英 â(i) ；σ ← std精英(â) + σmin 精英比例通常 5%–15%；σmin 防止分布坍缩；迭代 3–5 轮后取均值序列

初始分布的选择决定搜索效率：从宽分布出发需要大样本量才能覆盖动作空间，用策略输出作为均值、以小方差起步的“热启动”把搜索集中在可行流形附近，同等样本数下解的质量显著提升。σmin 是防坍缩的正则：分布方差过零后迭代失去探索能力，陷入局部解。

每轮的收缩量可以量出来：标准正态下 64 个候选取代价最低的 8 个（12.5% 精英），精英集均值相对分布中心偏移 1.61σ，精英集标准差为 0.38σ。代入迭代：均值每轮朝低代价方向前进约 1.6 倍当前标准差，标准差三轮后降到 0.383 ≈ 0.055 倍初始值，与 σmin=0.05σdata 的下限几乎重合。维度升高会改变常数，不改结构：动作序列 8×7=56 维高斯候选的偏差范数集中在 σ√56 ≈ 7.5σ 的薄壳上，单轮采样覆盖不了整个空间，N=64 之所以可用，在于迭代收缩把薄壳逐轮推向低代价区域，机制核心是排序收缩对候选的逐轮筛选。

3. 策略与规划器的三种结合

按耦合深度排列：提议分布热启动，策略给出 μ 初值，规划器在附近精化，接口最轻；局部精化，在策略动作块上加一个低维修正量，规划只对修正量做搜索，搜索维度从 H·da 降到数十维；规划蒸馏，把规划结果作为监督数据回流训练策略，逐步把慢规划的能力搬进快策略。三者的共同前提是动作空间与归一化链一致，规划输出若在归一化空间而执行端未反变换，动作幅度整体错位。三者的对照见下表。

结合方式搜索对象相对成本部署形态
提议分布热启动完整动作序列中线上规划，样本量换质量
局部精化低维修正量低线上规划，实时性优先
规划蒸馏无（离线回流）训练期一次部署零规划开销

规划蒸馏的摊销逻辑值得单独说明：规划轨迹对 (上下文, 规划动作块) 作为监督回流后，策略在下一轮训练中直接学会规划器的输出模式，部署阶段只需一次前向。蒸馏的风险是容量错配：策略若小于规划器搜索到的模式复杂度，会学到“平均后的规划”，分布外场景的优势随之衰减；因此蒸馏数据集要带分布外样本，评估也必须在分布外子集上做，全网平均值会掩盖蒸馏的失效。

归一化链不一致的表现容易识别：规划在归一化空间返回 [0,1] 区间的动作序列，执行端若按原始量纲解释，各关节目标被整体乘上一个与量程相关的倍数，动作幅度系统性偏离。校验方式是把同一状态分别走策略路径与规划路径，比较两条输出在同一反变换下的数值分布，分布不重合即链路不一致，修复点通常在规划输出的反变换调用缺失或重复。

4. 打分函数设计

打分函数把推演轨迹映射为标量代价，通常由四项组合：目标代价（末端状态与目标的距离）、成功判定（成功分类器输出，022 章展开）、平滑性代价（相邻动作差分的范数）、终端价值（对剩余任务进度的估计）。

Cost(τ̂) = cgoal + ws·(1 - psucc) + wm·Σ‖ak+1 - ak‖ + wv·(-V̂(zL)) psucc 为成功概率；V̂ 为终端价值；权重按任务标定，全部作用于归一化空间

打分函数是规划质量的上限：权重失衡会让规划器优化错误的目标，出现“分数很高但任务失败”的代理目标错位。校验方法是对规划结果与真实执行结果做相关性分析，相关性低说明打分函数与真实目标脱节，需要逐项消融。

校验用秩相关：任务成败与代价之间通常不是线性关系，秩相关只依赖排序，对量纲和单调形变都不敏感，皮尔逊相关在这类关系上会失真。操作流程固定为四步：收集规划批次中每条候选的分数与执行后的真实结果标签；计算分数与结果的斯皮尔曼系数；对四项权重逐一做小范围扰动，记录系数变化，把系数下降最多的权重列为失配主嫌；最后按主嫌重新标定权重并复测。基线判据：系数低于 0.3 时规划收益不可信，此时先修打分函数再谈提高样本量。终端价值的权重还要与视界联动：视界从 8 缩短到 5 时远端信号减少，价值项的权重按成功率回归重新标定，避免缩短视界后规划退化为近视贪心。

四项权重的量级关系用算例固定：目标代价的典型范围在 1 附近（归一化空间），平滑性项按每步动作差分范数均值计算；两个候选目标代价相同、每步差分分别为 0.05 与 0.15 时，wm=0.1 让两者的代价差距达到 0.1×0.10×7 = 0.07，足以在接近的目标代价之间分出抖动更小的一方；若把 wm 提到 1.0，差距放大到 0.7，规划器会牺牲目标进度换取过度平滑。平滑项的作用边界是“打破接近平局”，主排序必须由目标与成功项承担。

5. 规划预算与切换准则

规划成本约为 N·(迭代数)·L 次世界模型前向，与策略单次前向相差两到三个数量级。切换准则按场景定义：不确定性高（预测误差大、策略输出方差大）或任务新（语言指令未出现在训练分布）时启用规划，常规执行走策略。工程上用预算上限兜底：规划必须在控制周期内返回，超时则退化为策略输出加块间融合（004 章），保证实时性不被规划拖垮。

预算核算给出统一口径：N=64、迭代 3 轮、L=8 时推演总量为 192 条候选序列，每条覆盖 9 个潜状态，约 1728 次帧级前向；策略单次前向只处理当前观测加历史，两者相差约三个数量级。热启动把有效搜索半径压到 0.3 倍，覆盖同半径所需样本数按半径比的维度次幂下降，实际做法是把目标从全域覆盖改为局部精化，预算主要花在排序上。切换阈值的量化起点：策略输出方差高于训练分布 90% 分位，或指令嵌入与训练集最近邻的余弦低于 0.3，任一命中即启用规划；阈值按误触发率校准，误触发率高于两成说明阈值偏松，规划算力被日常场景消耗。

适用边界还有一条硬条件：控制频率高的任务（动态平衡、高速分拣）留给单周期的计算预算本就很小，规划在这种频率下不可行，系统只能以策略前向加轻量安全校验运行。此时规划的角色从在线组件转为离线工具：用规划生成高质量轨迹回流训练（规划蒸馏），把深度决策的能力预置进策略权重，在线阶段保持纯反应式。这也给出一个取舍准则：如果任务频率不允许在线规划，就投资蒸馏；如果任务允许低频决策且有分布外风险，就在线规划。

实现思路与设计

混合系统四组件：策略提议器（输出均值动作块与方差）、CEM 规划器（精英迭代）、推演器（复用 011 章世界模型批量推演）、执行器（首块执行与融合）。切换器按不确定性与任务新颖度决定规划开关。

关键代码与解读

片段以模型预测控制与基于世界模型规划的公开设计为参照（CEM 与热启动是通行做法），接口随版本演进。第 1 段给出 CEM 规划循环。

片段 1：CEM 规划循环

import torch

@torch.no_grad()
def cem_plan(world, policy, context, cost_fn, L=8, N=64, K=8, iters=3,
             sigma0=0.3):
    """CEM 规划：采样动作序列、批量推演、精英重拟合，返回最优序列。"""
    mu, sigma = policy.propose(context)             # 策略给出均值与建议方差
    sigma = sigma * sigma0                          # 缩小到热启动尺度
    best = None
    for it in range(iters):
        # 采样候选：分布形状 (N, B, L, d_a)，同一分布覆盖批内所有环境
        eps = torch.randn(N, *mu.shape, device=mu.device)
        cand = mu.unsqueeze(0) + sigma.unsqueeze(0) * eps
        # 批量推演：候选维并入批次维，一次前向完成全部候选的想象
        latents = world.rollout(context, cand)      # (N, B, L+1, d_z)
        cost = cost_fn(latents, cand)               # (N, B) 每个候选的代价
        # 精英筛选：按批内排名选出代价最低的 K 个候选
        elite_idx = cost.topk(K, dim=0, largest=False).indices    # (K, B)
        elite = cand.gather(0, elite_idx[..., None, None].expand(-1, *cand.shape[1:]))
        # 重拟合均值与方差；sigma_min 比例在外部已并入下限保护
        mu = elite.mean(dim=0)
        sigma = elite.std(dim=0).clamp(min=0.05)
        best = (cand, cost)
    # 取最终分布的均值作为规划输出：比取单条最优更平滑
    return mu

解读：（1）候选维作为批量维的前导维，推演与打分全部向量化，避免了逐候选的 Python 循环，这是实时性的关键。（2）精英选择按环境独立执行（dim=0 上取 topk），批内不同环境互不干扰。（3）返回分布均值（不再只取单条最优候选）：均值对采样噪声更稳，与执行端的块间融合策略天然兼容。

片段 2：策略热启动与局部精化

@torch.no_grad()
def refine_with_policy(policy, world, context, cost_fn, steps=3):
    """局部精化：在策略动作块上加低维修正量，规划搜索修正量。"""
    mu, _ = policy.propose(context)                 # (B, L, d_a) 策略均值序列
    delta = torch.zeros_like(mu)                    # 修正量从零起步：默认信任策略
    for _ in range(steps):
        # 修正量采样范围很小：只在策略建议附近探索，搜索空间大幅缩小
        cand = mu + 0.1 * torch.randn(32, *mu.shape, device=mu.device)
        latents = world.rollout(context, cand)
        cost = cost_fn(latents, cand)
        # 选择当前最优修正方向并小幅前进：步长小于 1 保持稳定
        best_idx = cost.argmin(dim=0)
        delta = delta + 0.5 * (cand.gather(
            0, best_idx[None, ..., None, None].expand(1, *cand.shape[1:]))[0] - mu - delta)
    return mu + delta                               # 修正后的动作块交给执行器

解读：（1）搜索对象从完整动作序列变为零附近的修正量，修正量初始为零意味着“无规划时退化到策略输出”，安全性由结构保证。（2）候选数从 64 降到 32、步长取 0.5，均由低维搜索空间的收敛速度决定；具体取值应在实时预算下实测。（3）修正量机制与规划蒸馏共用同一表示：蒸馏的目标可以就是修正量分布，接口一致。

片段 3：打分函数组装

def make_cost(goal_fn, success_head, value_head, w_succ=1.0, w_smooth=0.1,
              w_value=0.5):
    """打分函数：目标代价、成功概率、平滑性与终端价值的组合。"""
    def cost(latents, actions):
        # 目标代价：末端潜状态与目标嵌入的距离，全程作用于归一化空间
        c_goal = goal_fn(latents[:, :, -1])
        # 成功判定：分类头对末端状态给出成功概率；取负号使代价最小化
        c_succ = -success_head(latents[:, :, -1])
        # 平滑性：相邻动作差分范数，惩罚抖动大的候选序列
        c_smooth = (actions[:, :, 1:] - actions[:, :, :-1]).norm(dim=-1).mean(-1)
        # 终端价值：对末端状态的任务进度估计，缺省为零表示不启用
        c_value = -value_head(latents[:, :, -1])
        # 四项均为 (N, B) 形状：逐候选逐环境求和，权重按任务标定
        return (score_goal(c_goal) + w_succ * c_succ + w_smooth * c_smooth
                + w_value * c_value)
    return cost

def score_goal(x):
    """目标代价的占位实现说明：真实系统由任务定义（距离、位姿误差等）。"""
    return x

解读：（1）四项代价全部在归一化空间计算，避免量纲混杂；权重乘在各项外侧便于统一标定。（2）成功与价值头在此只作推理（无梯度），其训练分别在 022 章与后续价值章节完成。（3）score_goal 保留为独立函数的目的是把任务特定的距离定义与通用权重结构分离，任务替换时只改一处。

常见坑

  • 打分与真实目标错位：规划器优化分数但不完成任务，成功头被“刷分”。修复：做分数与真实结果的秩相关分析，逐项消融校验各项权重。
  • 样本数不足：N 过小使精英集近似随机，CEM 退化为噪声搜索。修复：增大 N 或启用热启动缩小搜索空间，并监控精英集代价的方差。
  • 规划视界过长：L 超过误差可控区间，远端打分不可信。修复：缩短 L 并加终端价值补偿，两者联合标定。
  • 规划超时拖垮实时：控制周期被规划耗尽，机器人动作间隔抖动。修复：预算上限加超时退化为策略执行，保证最坏情况的时延。
  • 动作空间不一致：规划输出未反变换直接执行，动作幅度整体错位。修复：规划、策略、执行三段共用同一条归一化链（002 章）。

练习与思考

  1. N=64、L=8、迭代 3 轮，计算单次规划的世界模型前向次数与相对策略单次前向的倍数。★
    提示
    3×64=192 次序列推演，每次覆盖 L 步；相对策略单次前向约两个数量级，实时预算必须约束。
  2. 把精英数 K 从 8 降到 2，预测 CEM 收敛速度与方差的变化，给出观测指标。★
    提示
    收敛更快但方差大、易过早坍缩到局部解；用精英代价曲线的下降速度与波动幅度联合观察。
  3. 推导：说明热启动（以策略输出为初始均值）如何改变 CEM 的有效搜索半径，并给出候选预算的估算方法。★★
    提示
    初始 σ 缩小到 0.3 倍后，全域覆盖所需样本数按半径比的维度次幂下降（56 维下为 0.3 的 56 次幂量级）；CEM 单轮不追求全域覆盖，靠逐轮收缩逼近低代价区，预算按局部半径与迭代轮数折算。
  4. 设计切换准则的完整方案：不确定性度量、任务新颖度判定、超时兜底，写出各触发条件与默认动作。★★
    提示
    不确定性用预测误差与策略方差；新颖度用指令嵌入的分布外检测；任一超阈值启用规划，超时退化策略输出。
  5. 构造实验：比较纯策略、热启动 CEM、局部精化三种模式在分布外任务上的成功率与平均时延，给出选型结论模板。★★★
    提示
    预期分布外任务上两种规划模式成功率更高，局部精化时延最低；结论按“任务分布 + 实时预算”两轴给出推荐区间。

小结

  • 规划用世界模型“先试后做”，与反应式策略形成速度与深度的互补。
  • CEM 以采样、精英重拟合迭代逼近最优动作序列，热启动与方差下限是两个必备的稳定装置。
  • 策略与规划结合的三种方式：提议热启动、局部精化、规划蒸馏，均由同一条归一化链保证动作一致。
  • 打分函数决定规划质量上限，四项代价要用秩相关分析校验，防止刷分与真实目标脱节。
  • 规划预算必须设上限，超时退化为策略执行，实时性是系统级约束。
