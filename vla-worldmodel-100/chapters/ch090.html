第 090 章：世界模型的生成式预训练

掩码建模与扩散去噪如何从海量轨迹中学习动力学先验：两阶段训练、曝光偏差与课程式采样、条件引导与微调衔接的完整链条。

  • 主题：世界模型（World Model）/ 生成式预训练（generative pretraining）
  • 关键公式：掩码交叉熵与扩散噪声预测目标
  • 预计学时：55 分钟
  • 前置章节：第 089 章

学习目标

  • 理解生成式预训练与世界模型微调的分工：预训练学习通用的时空动力学先验，微调注入任务与本体特化信息。
  • 掌握掩码潜空间建模的目标与高掩码比例的作用，理解为什么掩码位置才产生训练信号。
  • 掌握扩散预训练的去噪目标推导要点，理解条件丢弃（condition dropout）与引导（guidance）的关系。
  • 理解曝光偏差（exposure bias）的来源，会设计课程式采样（scheduled sampling）的替换概率计划。
  • 能诊断分词器漂移、容量浪费与灾难性遗忘三类微调衔接故障。

背景与动机

真实机器人轨迹数据难以同时满足规模与质量：少量高质量遥操作数据珍贵，海量视频数据动作标注稀疏，生成式预训练是弥合这一缺口的桥梁。预训练阶段不要求动作标签完整、不要求任务成功，模型只需要学习"世界如何演化"的统计规律：物体如何随接触移动、遮挡如何消解、光照如何变化。这些规律以参数形式沉淀后，微调阶段只需少量任务数据即可激活为可用的世界模型与策略组件。

与第 003 章的直接监督训练相比，本章引入两个变化：目标函数从重建误差升级为掩码/去噪的概率目标；训练流程从单阶段变为预训练加微调的两阶段。第 087 章的离散码本在这里充当预训练的词表，第 091 章的规划模块消费预训练得到的动力学先验。生成式预训练的质量上限，直接决定联合训练后续环节的起点高度。

核心原理

生成式预训练的目标是学习条件分布 p(xt+1 | x≤t, at)，不同生成目标在似然下界、训练稳定性与采样成本上各有取舍。

1. 三种预训练目标的定位

  • 自回归下一词元预测：按时间顺序逐个生成，似然精确、采样顺序一致；代价是推理串行，长序列延迟高。
  • 掩码建模：随机遮蔽部分潜词元，并行预测全部遮蔽位置。训练效率高、双向上下文完整；采样时需要迭代填充，与自回归语义不同。
  • 扩散去噪：从噪声迭代生成整段未来，擅长连续信号与多模态分布；代价是采样步数多，需蒸馏加速。

联合训练场景推荐混合目标：离散潜空间用掩码建模学习表示与动力学，连续观测重建用扩散头保证生成质量。两个目标共享主干、梯度互补，掩码目标提供全局结构的强监督，扩散目标保留细粒度视觉保真度。

2. 掩码潜空间建模

把码字序列表示为索引 c1:T，随机采样掩码集合 M（每个位置独立以概率 p 被遮蔽），模型接收部分可见序列并预测被遮蔽位置：

Lmask = − Σt ∈ M log pθ( ct | c∉M ) 求和只在遮蔽位置；可见位置直接给出答案，不产生训练信号

掩码比例 p 的选择有明确规律：p 较低（0.15）时任务简单，模型可以参考大量可见邻域，学到局部插值；p 较高（0.6 以上）时可见上下文稀少，模型被迫学习全局结构与物理规律才能补全，表示质量更高。潜空间序列的时间冗余度高于文本，p 取 0.5–0.75 是常用区间。掩码向量用可学习嵌入替代（与第 081 章模态掩码同理），保证"缺失"本身是显式信号。

3. 扩散去噪目标

扩散模型定义前向加噪过程与逆向去噪过程，训练目标可化简为噪声预测：给定干净样本 x0、随机时刻 t 与高斯噪声 ε，构造带噪样本 xt，网络预测噪声：

xt = √ᾱt x0 + √(1 − ᾱt) ε，Ldiff = ‖ ε − εθ( xt, t, cond ) ‖2 ᾱt 为累积噪声系数；cond 为动作与语言条件

训练时以 10% 概率丢弃条件 cond，让网络同时学会有条件与无条件两种模式，推理期用引导系数 ω 组合：ε̂ = ε无 + ω(ε有 − ε无)，ω 大于 1 强化条件影响。引导越强，生成对条件的遵循越好，多样性越低；动作条件的实用区间约 1.5–3。蒸馏到 4–8 步采样后，延迟进入规划模块可接受范围。

4. 两阶段衔接与曝光偏差

预训练用真值前文预测下一词元（教师强制，teacher forcing），推理时前文来自模型自身输出。训练分布与推理分布的错位即曝光偏差：模型从未练习过"修正自己的错误"，误差沿 rollout 累积（与第 084 章的递归放大同源，此处源于训练机制）。课程式采样（scheduled sampling）按训练进度逐步提高替换概率：以概率 p(step) 用模型自己的预测替换真值作为输入，p 从 0 线性升到 0.3 左右。p 不可过大，否则早期训练被自身误差干扰。

微调阶段的另外两条经验：学习率比预训练低一个量级（2e-5 量级），防止破坏预训练特征；离散方案要监控分词器漂移，微调数据分布与预训练差异大时，码字使用分布偏移会让历史标注失效，需要周期性重新标注。灾难性遗忘的缓解手段是混合 replay：微调批次中保留 10%–20% 的预训练样本。

实现思路与设计

两阶段流程：第一阶段大规模预训练（掩码 + 扩散混合目标），第二阶段联合微调（策略损失 + 预测损失 + replay 混合）。

  1. 数据：预训练用 105–106 条轨迹片段，含动作标注与无标注视频；微调用 103 量级任务演示。
  2. 阶段一目标：掩码交叉熵（权重 1.0）加扩散去噪（权重 0.5），批量 256，学习率 1e-4，训练到验证掩码准确率平台。
  3. 阶段二目标：动作模仿损失、世界模型预测损失、replay 损失三项混合；学习率 2e-5，微调步数约为预训练的 1/10。
  4. 曝光偏差处理：阶段二启用课程式采样，替换概率从 0 线性升到 0.3；推理时与训练一致使用预测前文。
  5. 与第 003、087 章的差异：训练机制从单阶段监督升级为两阶段生成式；离散码本作为词表复用第 087 章方案。

设计决策：为什么高掩码比例反而提升表示质量？

低掩码时模型依赖可见邻域做局部插值，学到的映射接近复制；高掩码时可见信息不足以插值，模型必须调用全局结构（物体恒存、运动连续性）才能补全，约束越紧表示越抽象。代价是训练损失更大、收敛更慢，收益体现在迁移任务上，平衡点由下游微调指标决定。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：掩码潜空间建模损失

def masked_latent_loss(model, codes, mask_ratio=0.6):
    """掩码建模：遮蔽部分码字，只对被遮蔽位置计算交叉熵。"""
    B, T = codes.shape
    # 每个样本独立采样掩码：不同样本覆盖不同时间区域，梯度覆盖更均匀
    mask = torch.rand(B, T, device=codes.device) < mask_ratio
    emb = model.code_embed(codes)                       # 码字嵌入 (B, T, d)
    # 用可学习掩码向量替换：零向量会与真实嵌入混淆
    emb = torch.where(mask.unsqueeze(-1), model.mask_token.expand_as(emb), emb)
    logits = model.head(model.transformer(emb))         # (B, T, K) 码字分布
    # 可见位置直接对照答案，若计入损失会主导梯度、稀释建模目标
    return F.cross_entropy(logits[mask], codes[mask])

解读：掩码按样本、按位置独立采样，高比例下每个样本保留约 40% 可见词元，双向上下文仍足以确定大部分遮蔽内容。torch.where 生成新张量完成替换，原位张量保持不变，便于同一批次复用。mask 作为布尔索引，交叉熵只统计被遮蔽位置；训练早期遮蔽位置比例高、损失数值大，监控时按比例归一化便于跨配置对比。mask_token 为可学习参数，其梯度来自全部遮蔽位置的预测路径。

片段 2：扩散预训练单步（噪声预测）

def diffusion_pretrain_step(unet, x0, cond, alphas):
    """扩散预训练：随机时刻加噪，网络预测噪声。"""
    B = x0.size(0)
    t = torch.randint(0, len(alphas), (B,), device=x0.device)   # 均匀采样时刻
    a_bar = alphas[t].view(B, *([1] * (x0.dim() - 1)))          # 累积系数广播
    eps = torch.randn_like(x0)                                  # 目标噪声
    # 前向加噪有闭式解：无需迭代，单步即可构造任意时刻样本
    x_t = a_bar.sqrt() * x0 + (1 - a_bar).sqrt() * eps
    # 条件丢弃：以 10% 概率置零，训练出有条件与无条件两种模式
    drop = (torch.rand(B, 1, device=x0.device) < 0.1).to(cond.dtype)
    cond_train = cond * (1.0 - drop)
    eps_pred = unet(x_t, t, cond_train)
    return F.mse_loss(eps_pred, eps)                            # 简单噪声预测目标

解读：时刻均匀采样保证各噪声水平获得相同训练权重；若按损失重加权（例如感知重要性采样），可把容量向中间噪声水平集中，这是常见的加速手段。a_bar 的广播形状按输入维度动态构造，兼容图像与潜特征两种输入。条件丢弃率 0.1 是经验值：无条件模式仅用于引导组合，不需要大量样本；条件乘以 (1 − drop) 实现置零，与推理期的引导公式配套。噪声预测目标比直接预测 x0 数值稳定，梯度尺度在各时刻间更均衡。

片段 3：课程式采样与微调衔接

def scheduled_sampling_prob(step, total_steps, p_end=0.3):
    """替换概率从 0 线性升到 0.3：训练后期逐步用模型预测作为前文。"""
    frac = min(1.0, step / total_steps)
    return p_end * frac

def shift_inputs(model, codes, prob):
    """按概率用模型预测替换真值前缀，模拟推理期的误差分布。"""
    if prob <= 0.0:
        return codes
    # 一次性前向得到全部位置预测，再按伯努利掩码替换
    with torch.no_grad():
        pred = model.head(model.transformer(model.code_embed(codes))).argmax(-1)
    replace = torch.rand_like(codes.float()) < prob
    return torch.where(replace, pred, codes)

解读：替换概率线性上升是最简单的课程曲线，也可用余弦或阶梯形式；关键是早期保持接近教师强制，后期引入模型误差。shift_inputs 用 no_grad 生成替换值，防止替换路径产生二阶梯度；替换与损失位置相互独立，避免"自己监督自己"的循环。评估时关闭替换以保持口径稳定；替换后训练损失短期上升属正常现象，判断进展应看验证集 rollout 指标，单步损失数值暂不可比。

常见坑

  • 曝光偏差未处理：只在教师强制模式下微调，闭环 rollout 3 步后崩坏。症状是单步指标优秀、闭环指标骤降。修复：启用课程式采样，评测协议加入闭环 rollout 指标。
  • 分词器漂移：微调数据分布与预训练差异大，码字使用分布偏移，历史标注失效。症状是困惑度上升、重建质量下降。修复：周期性重标数据、监控码字分布偏移量。
  • 容量浪费：重建目标把容量消耗在感知不重要细节（纹理噪声）上。症状是重建指标高但对下游任务无迁移收益。修复：在潜空间计算预测损失，或对重建施加感知加权；把掩码目标权重提高。
  • 条件丢弃遗漏：训练时未做条件丢弃，推理期无法构造无条件分支，引导系数失效。症状是生成对动作条件不敏感。修复：补齐丢弃逻辑，验证有/无条件两条分支的输出差异。
  • 微调学习率过高：预训练特征被快速冲毁，性能低于从头训练的小模型。症状是微调初期损失骤降后又回升。修复：学习率降到 1e-5 至 3e-5，配合预热与余弦衰减、replay 混合。

练习与思考

  1. 从扩散前向过程的闭式解出发，说明 xt = √ᾱtx0 + √(1 − ᾱt)ε 的推导思路，并解释 t 均匀采样的训练含义。★★
    提示
    多步高斯叠加仍是高斯，均值方差按系数合并；均匀采样让网络在每个噪声水平都获得监督。
  2. 把掩码比例从 0.6 调到 0.15，预测掩码损失、训练速度与下游微调表现的变化。★
    提示
    掩码损失下降、收敛加快，但表示偏局部插值，下游迁移收益缩小；用微调后的任务指标验证。
  3. 设计预训练数据混合方案：给定无动作视频、有动作演示、模拟环境数据三类来源，给出采样比例与理由。★★
    提示
    无动作视频提供视觉多样性但不含控制信号，可配动作推断或掩码目标；比例按目标域匹配度分配，模拟数据用于补足危险场景。
  4. 设计替换概率的曲线：对比线性、余弦、阶梯三种计划，说明各自在训练早期与后期的行为差异。★★
    提示
    线性平稳；余弦前期慢后期快，适合长训练；阶梯便于分阶段切换并观察指标。
  5. 设计消融实验：验证掩码目标与扩散目标各自的迁移贡献，指标覆盖下游微调成功率与生成质量，说明控制变量。★★★
    提示
    固定数据、步数与骨干，只改目标组合（仅掩码、仅扩散、混合）；微调预算统一，报告多次种子均值。

小结

  • 生成式预训练从海量轨迹学习动力学先验，为联合训练提供高质量起点；掩码与扩散目标互补。
  • 高掩码比例迫使模型学习全局结构；损失只计遮蔽位置，掩码向量用可学习嵌入。
  • 扩散训练用噪声预测目标与条件丢弃，推理期引导系数控制条件强度与多样性。
  • 两阶段衔接的关键是曝光偏差处理（课程式采样）、低学习率微调与 replay 抗遗忘。
