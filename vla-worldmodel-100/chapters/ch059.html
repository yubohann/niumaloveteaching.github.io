第三篇 · 策略与世界模型深化

第 059 章：VLA策略的指令跟随精度

"说到做到"需要语言与视觉、动作的逐层对应：本章讲清接地（Grounding）的注意力机制、最小对比指令的间隔损失、以及按子句分解的评估协议与失败分类。

  • 主题：VLA 策略 / 语言条件（Language Grounding）
  • 关键公式：Lmargin = max(0, m + d(at, a+) − d(at, a−))
  • 预计学时：55 分钟
  • 前置章节：第 058 章 联合训练中的对抗性扰动

学习目标

本章把"指令跟随"从总体成功率拆解为可归因的子句级指标，并给出训练侧的增强手段。

  • 理解接地（Grounding）的机制：指令词元与视觉词元的交叉注意力如何形成区域对应，以及注意力权重与因果作用的区别。
  • 掌握指令跟随的失败分类：否定、空间关系、时序步骤、计数与属性绑定，能按类别设计数据与评估。
  • 掌握最小对比指令（Minimal Contrastive Instruction）的训练构造与间隔损失形式。
  • 能设计子句级评估协议：分解长指令为可判定的检查点，分别统计达成率与顺序正确性。
  • 能诊断语言先验短路：指令消融与反事实交换两种探针的使用方式。

背景与动机

总成功率是复合指标，同一条指令里"抓红色的"和"放到左边"可能一部分做对、一部分做错，平均值无法区分。指令跟随精度要求逐句核对：语言中的每个约束是否在行为中被满足，这需要把评估从轨迹终点前移到子句层面。训练侧的问题同样具体：模型可能只抓住指令中的动词而忽略修饰词，或者依赖场景中的频率先验执行默认动作。

第 046 章的对比对齐建立了跨模态的共同度量空间，本章在此之上检查语言条件的实际生效程度：对齐保证"能找到"，跟随保证"执行对"。两者之间还差一个环节：语言到动作的因果链路。本章用最小对比样本强化修饰词差异的动作区分度，用子句级评估定位失败环节，与第 047 章的零样本评估共同构成语言接口的完整验收。

核心原理

按"接地机制、失败分类、对比训练、评估协议"四条线索展开。

1. 接地：从注意力到因果

策略中的交叉注意力让每个指令词元从视觉词元中聚合信息。理想情况下，"红色"一词的注意力集中在红色物体区域，"左侧"的相关词元聚焦在左半空间的候选目标上。接地质量常用注意力权重可视化检查，但需要注意：注意力权重高只说明信息流动的方向，不证明该词元对输出有因果作用；验证因果需要消融：屏蔽该词元的注意力或替换词元后观察动作变化。

因果接地的一个判据是词元级敏感性：动作输出对指令中目标名词的嵌入变化敏感，对填充词不敏感。把敏感性做成指标（词元替换后的动作分布距离），可以对整批指令给出接地质量的定量读数，替代主观的注意力图观察。

2. 失败分类与句式难度

类别示例结构难点数据对策
否定"不要碰右侧物体"语言先验偏向执行动词，否定的作用范围易被忽略正负样本成对出现，负例含现场物体
空间关系"把块放到杯子左边"参照系歧义：观察者视角与物体自身视角不一致统一参照系标注，同一场景多视角复述
时序步骤"先开抽屉再放进去"顺序约束需要跨阶段维持阶段化标注，顺序错误单独计分
计数与属性"拿两个蓝色积木"数量与颜色绑定，容易取一个或取错色数量课程，属性组合平衡采样

句式的难度不平等：同一动词下的否定、时序结构训练样本稀缺时，模型会用高频模式覆盖稀缺结构，表现为"回答得通顺但执行错误"。数据侧的解法是按结构分层采样，保证每类结构的样本占比不低于阈值；评估侧按结构分组报告，避免总体指标掩盖单类塌陷。

3. 最小对比训练

最小对比指令只在单一语义维度上不同（颜色、方向、数量），迫使模型区分该维度的动作后果。训练损失在动作分布上施加间隔约束：

Lmargin = max(0, m + d(at, a+) − d(at, a−)) at 为当前输出，a+ 为正确指令下的示范动作，a− 为对比指令下的目标；d 为动作空间距离，m 为间隔

间隔损失的作用方向明确：拉大正确与错误指令对应的动作距离，低于间隔 m 的区分度持续产生梯度。对比指令的动作目标来自数据（同一场景分别执行两条指令的示范），因此该损失不引入新标注，只要求数据采集时成对记录。

数值算例：取 m = 0.5、dpos = 0.2、dneg = 0.4：损失 = max(0, 0.5 + 0.2 − 0.4) = 0.3，训练同时拉近正距离、推远负距离；dneg 增大到 0.7 以上（即 dneg − dpos ≥ m）后损失归零，区分度达标不再产生梯度。

4. 子句级评估协议

把指令分解为可判定的检查点：每个约束（目标属性、放置位置、顺序、数量）对应一个布尔判定，轨迹结束后统一核对。子句达成率、顺序正确率与总体成功率三项分开统计，可以定位失败环节；配合逐帧状态记录，还能区分"没做到"与"做了又破坏"。判定函数尽量用状态量，避免评估器自身的视觉误差混入判定。

实现思路与设计

实现覆盖对比数据构造、间隔损失配置与评估脚本三部分。

数据流

  1. 采集阶段：同一初始场景对最小对比指令成对执行，记录两条轨迹。
  2. 训练阶段：间隔损失与模仿损失联合优化，正负动作来自配对轨迹的同一阶段。
  3. 评估阶段：按子句判定函数统计达成率，按结构类别分组汇总。
  4. 诊断阶段：词元替换探针与指令消融，量化语言条件的因果敏感性。

与前一章的差异点

第 058 章的扰动作用于潜状态，检验系统对状态偏移的稳健性；本章的对比信号作用于语言条件，检验策略对语义差异的区分度。两章的探针可以组合：在受扰场景下重复词元替换实验，能把"语言没生效"与"视觉条件丢失"两类失败分开归因。

片段 1：词元替换的因果敏感性探针

import torch

@torch.no_grad()
def token_swap_sensitivity(policy, obs, tokens, tokenizer, target_pos, alt_word):
    """替换指令中的目标词，测量动作分布的因果敏感性。
    设计意图：注意力权重只说明信息流，替换实验才能验证语言条件的因果作用。"""
    enc_orig = policy.encode_text(tokens)                 # 原始指令编码
    swapped = list(tokens)
    swapped[target_pos] = alt_word                        # 只改动一个语义单元
    enc_swap = policy.encode_text(tokenizer(swapped))
    dist_a = policy.action_dist(obs, enc_orig)
    dist_a_alt = policy.action_dist(obs, enc_swap)
    # 敏感性用两条动作分布的距离度量：越大说明该词元的因果作用越强
    sens = (dist_a.mean - dist_a_alt.mean).norm(dim=-1).mean()
    # 对照探针：替换填充词，敏感性应当接近零
    fill_pos = find_filler_position(tokens)
    enc_fill = policy.encode_text(tokenizer(swap(tokens, fill_pos)))
    sens_fill = (dist_a.mean - policy.action_dist(obs, enc_fill).mean).norm(dim=-1).mean()
    return sens.item(), sens_fill.item()

解读：（1）替换粒度是单个语义单元（名词、方向词、颜色词），敏感性读数直接检验词元的因果作用，比注意力可视化更接近行为层证据。（2）填充词对照提供基线：目标词敏感性应显著高于填充词，两者接近说明语言条件整体未生效。（3）探针在评估集上批量运行，输出可聚合为每类结构的平均敏感性，是训练过程的监控指标之一。

片段 2：最小对比间隔损失

import torch
import torch.nn.functional as F

def contrastive_margin_loss(policy, obs, tokens_pos, tokens_neg, action_pos, margin=0.5):
    """最小对比指令的间隔损失：正确指令的动作应比对比指令更接近示范。"""
    pred = policy.action_mean(obs, policy.encode_text(tokens_pos))
    # 负向目标：用模型在对比指令下的当前输出，构造"应当远离"的参照
    with torch.no_grad():
        target_neg = policy.action_mean(obs, policy.encode_text(tokens_neg))
    d_pos = (pred - action_pos).flatten(1).norm(dim=1)     # 到正确示范的距离
    d_neg = (pred - target_neg).flatten(1).norm(dim=1)     # 到对比指令输出的距离
    # 间隔约束：两者差距不足 margin 时产生梯度，拉开语义维度的区分度
    return F.relu(margin - d_neg + d_pos).mean()

解读：（1）间隔写法为"间隔加正距离减负距离"，与公式一致；relu 截断保证区分度达标后不再产生梯度。（2）负向参照取模型自身在对比指令下的输出，训练信号在模型内部自洽，避免依赖额外的负例轨迹标注；若数据中存在对比指令的真实示范，替换为真实目标更稳。（3）损失作用在动作均值上，与扩散头兼容：先取分布的均值再计算距离，梯度经均值回传。

片段 3：子句级评估

def evaluate_clauses(rollout, clauses, state_fn):
    """按子句判定函数统计达成率与顺序正确性。
    设计意图：把总体成功率拆到约束粒度，定位失败环节。"""
    traj = rollout()                                  # 执行轨迹，含逐帧状态
    results = []
    for clause in clauses:
        achieved = any(clause.check(state_fn(frame)) for frame in traj.frames)
        # 检查点记录首次达成与最终状态：区分"没做到"与"做到又破坏"
        final_ok = clause.check(state_fn(traj.frames[-1]))
        results.append({"clause": clause.text, "achieved": achieved, "final": final_ok})
    order_ok = check_order(results)                   # 时序子句的先后关系是否满足
    success = all(r["final"] for r in results) and order_ok
    return {"clauses": results, "order_ok": order_ok, "success": success}

解读：（1）每个子句记录"曾经达成"与"最终保持"两个布尔量，前者失败说明没做到，后者的失败说明执行中途破坏了此前结果，两类问题的修复方向不同。（2）顺序正确性单独统计：条件达成集合相同但顺序错误的任务不能计为成功，这是多步指令评估最常见的漏网情形。（3）判定函数基于状态量实现，评估脚本与仿真或真机的状态接口对齐，视觉判定的误差不进入指标。

常见坑

  • 否定结构被忽略：策略执行了被禁止的动作且成功率不低。修复：正负样本成对采集，否定句单独评估，必要时对否定词元加接地监督。
  • 参照系歧义未统一：左右方向在不同视角下含义变化，模型时对时错。修复：数据标注统一参照系并在指令中显式化，评估时固定相机视角。
  • 语料模板化：同一结构的大量改写挤占样本，语法覆盖窄。修复：按结构分层采样，控制模板重复率。
  • 把注意力图当作接地证明：可视化好看但消融后行为不变。修复：用词元替换探针做因果验证，报告敏感性数值。
  • 顺序错误未单独判定：多步指令中步骤全做但顺序错误仍被判成功。修复：子句级评估加入顺序检查，与达成率分开报告。

练习与思考

  1. 构造：为"把红色积木放到蓝色盒子左边"设计子句检查点清单，说明每个检查点的判定量与顺序约束。★★
    提示
    检查点一：红色积木被抓取；检查点二：积木进入盒子左半空间；检查点三：放置后位置保持。顺序约束：抓取先于放置，放置位置先于松手判定。
  2. 把间隔 m 从 0.5 提到 2.0，预测三件事的变化：对比结构上的动作区分度、动作平滑性、总体成功率，并说明验证方式。★★
    提示
    区分度上升，平滑性下降，总体成功率可能先升后降。验证：分结构统计成功率与动作二阶差分，找到间隔的工作区间。
  3. 设计消融实验区分"语言没生效"与"视觉条件丢失"两类失败：写出探针组合与判读规则。★★★
    提示
    词元替换探针测语言因果；观测替换或遮蔽探针测视觉因果。语言敏感性与视觉敏感性都低说明两路都弱，只有语言低则问题在语言侧。
  4. 讨论：为什么子句级评估需要"曾经达成"与"最终保持"两个量？分别对应哪类修复动作？★★
    提示
    曾经未达成对应能力缺失（数据或容量的补充）；达成后破坏对应稳定性不足（动作顺序或收敛后的维持策略调整）。

小结

  • 接地是语言词元到视觉区域的对应，注意力可视化只能提示信息流，因果作用由替换探针验证。
  • 指令跟随按否定、空间、时序、计数属性分类评估，稀缺结构需要分层采样保护。
  • 最小对比指令的间隔损失拉开语义维度的动作区分度，负向参照可取自模型自身输出。
  • 子句级评估区分"没做到"与"做到又破坏"，顺序正确性必须单独判定。
  • 语言先验短路用指令消融与反事实交换诊断，与零样本评估共用反事实口径。
