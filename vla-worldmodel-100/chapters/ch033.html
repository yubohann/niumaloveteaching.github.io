第二篇 · 联合训练进阶与策略能力

第 033 章：VLA策略的跨具身迁移

不同机器人的自由度、末端执行器与控制频率各不相同；本章讲清动作空间对齐的两条路线、具身嵌入的条件化设计，以及负迁移来源的隔离方法。

  • 主题：跨具身迁移（cross-embodiment transfer） / 动作空间对齐（action space alignment）
  • 关键公式：a′ = Te a + be（仿射对齐）；统一动作接口取末端相对位姿；共享主干加具身条件解码
  • 预计学时：55 分钟
  • 前置章节：第 032 章

学习目标

  • 理解跨具身迁移的动机与障碍：视觉语言表征可共享，动作空间与本体结构不可直接共享。
  • 掌握动作空间对齐的两条路线：统一到末端相对位姿的规范接口，与按具身仿射映射的适配层。
  • 掌握具身嵌入（embodiment embedding）的条件化设计，会为多具身数据设计共享主干加专用解码器的结构。
  • 会设计数据混合比例与课程顺序，并隔离姿态感知的负迁移来源。
  • 能诊断关节角直映射、控制频率差异与本体维度错配三类问题。

背景与动机

具身数据的规模瓶颈促使跨具身（cross-embodiment）训练：单台机器人的演示数据有限，而不同机器人、不同末端执行器的数据加在一起能覆盖更广的任务与场景。视觉与语言层面的共享相对直接：物体识别、空间关系、指令理解与具体身体无关，共享主干可以获得显著的正迁移。

动作层面的共享则困难得多。七自由度机械臂、六自由度末端控制器、双臂系统与移动底盘的动作维度、物理含义与坐标系各不相同；同一句"把杯子拿起来"在不同身体上对应完全不同的关节序列。直接混合原始动作数据训练的模型无法收敛，动作空间必须先对齐（action space alignment）。

本章与第 032 章的衔接：因果推理关注动作的干预效应，本章关注动作表示在不同身体间的可迁移性。对齐后的统一动作接口也为第 041 章之后的策略深化与第 086 章的连续控制提供公共约定。

核心原理

1. 动作空间对齐的两条路线

路线一：规范接口（canonical interface）。把各具身的动作统一到与身体无关的表示：末端执行器的相对位姿增量（平移 3 维 + 旋转 6 维的连续表示）加夹爪开合 1 维，共 10 维。每条数据在采集时由运动学求解器（逆运动学或正运动学差分）转换到该空间，策略只预测规范动作，执行时再映射回具体关节。

路线二：仿射适配（affine adaptation）。为每个具身学习一个从规范动作到本体动作的映射：

ae = Te · acanon + be Te 与 be 为具身 e 的可学习缩放与偏置；轻量参数集，每具身独立

仿射映射的适用边界需要明确：它适合自由度相同、仅量纲与零点差异的具身（例如同构平台的机械参数差异）；对不同运动学结构的具身（自由度数量不同、并联机构与串联机构混合），线性映射无法表达非线性运动学耦合，应改用小型多层感知机或直接走规范接口。工程上常见组合是"规范接口为主、仿射层处理残余差异"。

数值算例：两台同构机械臂，关节 A 的量程为 [−90°, 90°]，关节 B 为 [0°, 180°] 且转动方向相反。逐关节对齐取 aB = −aA + 90°，换算弧度后即 T = −1、b ≈ 1.5708：A 取 −90° 时 B 得 180°，A 取 90° 时 B 得 0°，两端点精确重合，全区间线性成立。这类共线缩放的具身，仿射层两个参数即可完成对齐；若两臂第二关节轴线相差一个绕基座的固定旋转，则先在规范空间做坐标变换，再进仿射层。

执行侧的规范动作到关节映射由逆运动学承担，它的成本与失败模式需要纳入设计：每块 40 步的规范动作对应 40 次求解，在 50 Hz 回路中占用可观的计算时间；位形接近奇异时求解可能失败或关节速度激增，需要回退策略（沿用上一组可行关节、切换阻尼最小二乘求解）并把求解失败率纳入监控。规范接口的价值在于把动作语义与求解器实现解耦：策略不感知求解细节，求解器按具身各自替换。

2. 具身嵌入与条件化结构

共享结构的核心设计是条件化：骨干参数共享，动作解码器以具身标识为条件：

π( a | o, l, e ) = Decodere( Encodershared(o, l) ) ，e 为具身标识 Encodershared 共享参数；Decodere 可为独立头、带嵌入条件的共享头，或二者混合

三种条件化粒度：独立解码头（每具身一套，参数量线性增长，隔离性最强）；嵌入条件共享头（具身标识编码为向量，与特征拼接或调制，参数共享、隔离性最弱）；混合结构（共享一组专家解码器，用嵌入做门控路由，容量与隔离的折中）。选择依据是具身数量与数据量：具身数以十计时混合结构合适，三五个具身时独立头更简单。

参数量视角：设有 E 个具身、单头参数量 P（约百万量级）、嵌入维度 16。独立头总参数量约 E · P，E = 10 时约 10M；嵌入共享头约 P + E × 16 ≈ 1M（相对 P 可忽略），隔离性最弱；混合结构用 N = 4 个专家（约 4M）加一个路由网络（十万量级）。具身数增至二十以上时独立头的参数压力明显，混合结构的边际成本保持稳定。

辅助损失可以强化具身对齐：用具身嵌入与视觉特征做对比预测（从状态与具身预测未来动作的规范表示），迫使共享表征保留跨具身可迁移的动力学信息。共享层承载"动作的效果"，专用层承载"动作的表达"，这是条件化结构的划分原则。

3. 数据混合与负迁移隔离

多具身数据混合的配比影响迁移方向：数据量大的具身主导共享表征，相似的具身互相受益，差异大的具身之间产生负迁移。隔离手段有三层：

  • 结构隔离：冲突集中的层段不共享（例如动作头全部分离，视觉编码器共享）。
  • 采样配比：按任务覆盖设定采样权重，数据量不直接决定配比，小具身可用重采样提升占比。
  • 课程顺序：先训练相似具身组，再加入差异具身，避免早期共享表征被异质数据撕扯。

本体感受（proprioception）维度的对齐单独处理：不同具身的关节数不同，输入张量形状不一致。方案是填充加掩码：按最大维度填充零，附维度掩码，网络对填充位置输出零注意力；或用集合编码（对被本体量做逐元素嵌入后池化），形状无关。相机配置差异（腕部相机有无、安装角）同样用配置掩码表达，缺失通道按零填充并在具身嵌入中标注。

负迁移可以用配对消融直接量化：同一评估协议下比较单具身基线与联合模型在各具身上的成功率差值 Δ。示例数据：具身 A 为 80% 对 79%（Δ = −1%），具身 B 为 75% 对 73%（Δ = −2%），具身 C 为 70% 对 58%（Δ = −12%）。前两个差值在评估噪声范围内，C 的 −12% 指向结构性冲突；处理顺序是先把 C 的动作头分离并重跑消融，观察差值是否收敛到 −3% 以内，再决定是否扩大隔离范围。

控制频率差异的数值形态：一段 10 Hz 采集的演示，8 步动作块覆盖 0.8 秒；把同一块直接送进 50 Hz 执行器，0.16 秒即耗尽，动作速度被放大 5 倍。数据管线的正确做法是按目标频率重采样：20 Hz 目标把块展开为 16 步（0.8 秒 × 20 Hz），50 Hz 目标展开为 40 步；或在执行侧按时间戳线性插值并同步缩放动作幅值。控制频率本身作为具身嵌入的一个标量维度进入条件，让策略在未见频率档位之间内插。

4. 跨具身世界模型

世界模型的动作条件预测同样面对具身差异：同一观测下不同身体的动作效果不同。解决办法与策略侧一致：动力学函数共享（物体运动规律与身体无关），动作输入经具身适配层转换到规范空间后进入动力学；预测输出（未来帧、奖励）共享解码。这样世界模型学到的是"规范动作下的场景演化"，策略适配层与动力学适配层共享同一套规范空间约定，联合训练时两组适配层可以互相约束、共同更新。

适配层的规模核算：取设计起点表的两层 MLP（输入 10 + 16 = 26，隐层 64，输出 7），参数量为 26 × 64 + 64 + 64 × 7 + 7 ≈ 2.2 × 103，相对百万级的骨干可忽略；新增一个具身只需约两千个参数与一行嵌入。

适配层的轻量决定了跨具身扩展的工程代价主要落在数据采集与规范空间的坐标约定上，模型侧压力很小。反过来，规范空间的约定错误会同时污染策略与动力学，且难以从损失曲线上直接看出，往返一致性测试是必要的防线。

实现思路与设计

跨具身系统由规范空间定义、适配层、条件化解码与数据管线四部分组成。与第 032 章的差异：032 在同一具身上做干预推演，本章处理多具身之间的表示统一。

  1. 规范空间定义：末端相对位姿（平移 3 + 6D 旋转表示 6 + 夹爪 1，旋转用六维连续表示避免万向锁）。
  2. 适配层：每具身一个适配模块（仿射或两层 MLP），输入规范动作输出本体动作，参数随策略联合训练。
  3. 条件化解码：共享骨干加混合解码结构；具身标识编码为 16 维嵌入，与特征做特征级线性调制。
  4. 数据管线：动作统一转换为规范空间存储；本体向量按最大维度填充加掩码；数据采样按任务覆盖加权。

跨具身评估需要统一协议：各具身使用同一任务集与同一初始状态分布（按物体布局分层抽样），结果按具身分组并与单具身基线对照；坐标系约定的单元测试覆盖"规范动作到关节再到规范动作"的往返一致性，误差上界按执行器分辨率设定。往返测试能在训练之前暴露坐标约定错误，排查成本远低于训练后的对照实验。

设计决策：旋转为什么采用六维表示？

欧拉角存在万向锁与周期跳变，同一旋转在两套等价角度间的数值插值会经过奇异区，对回归式动作头不友好。六维表示（旋转矩阵前两列）连续且无奇异性，插值与平均都有良好定义，代价是必须经过格拉姆-施密特正交化还原为有效旋转。跨具身场景下各具身坐标系不同，旋转表示的连续性比紧凑性更重要。

关键代码与解读

片段 1：具身适配层与条件化解码

import torch
import torch.nn as nn

class EmbodimentAdapter(nn.Module):
    """每个具身一套适配参数：规范动作到本体动作，兼作具身条件注入点。"""
    def __init__(self, canon_dim=10, body_dim=7, emb_dim=16):
        super().__init__()
        self.embed = nn.Embedding(16, emb_dim)      # 具身标识表，最多 16 个具身
        # 适配层以具身嵌入为条件：同一个规范动作在不同具身上解出不同本体动作
        self.net = nn.Sequential(
            nn.Linear(canon_dim + emb_dim, 64), nn.SiLU(),
            nn.Linear(64, body_dim))

    def forward(self, canon_action, embodiment_id):
        e = self.embed(embodiment_id)               # [B, emb_dim]
        x = torch.cat([canon_action, e], dim=-1)
        return self.net(x)                         # [B, body_dim] 本体动作

class SharedPolicy(nn.Module):
    """共享骨干 + 条件化适配头：表示共享，动作表达按具身分离。"""
    def __init__(self, adapter):
        super().__init__()
        self.backbone = build_vision_language_backbone()  # 共享参数
        self.adapter = adapter

    def forward(self, obs, lang, embodiment_id):
        feat = self.backbone(obs, lang)             # 跨具身共享的表征
        canon = self.canon_head(feat)               # 规范动作头（共享）
        return self.adapter(canon, embodiment_id)   # 本体动作（按具身分离）

解读：（1）共享部分承担"动作的效果"，适配层承担"动作的表达"，与条件化结构原则对应；（2）适配层用 MLP，保留表达非线性运动学耦合的容量，纯仿射在耦合处不足；宽度 64 在参数与表达力之间折中；（3）具身嵌入与规范动作拼接后进入适配层，同一状态下不同具身得到不同输出；（4）canon_head 为共享部分，跨具身训练时收到所有具身的梯度，是迁移的主要承载层。

片段 2：数据混合采样与本体掩码

import numpy as np

class EmbodimentSampler:
    """按任务覆盖加权采样具身，并维护本体向量的填充掩码约定。"""
    def __init__(self, embodiment_ids, cover_weights, min_share=0.1):
        weights = np.asarray(cover_weights, dtype=np.float64)
        # 权重归一化后施加最小占比：小具身的下限保护
        weights = weights / weights.sum()
        weights = np.maximum(weights, min_share)
        self.weights = weights / weights.sum()
        self.ids = list(embodiment_ids)

    def sample(self, n):
        # 按权重有放回抽取具身标识，供批次构造使用
        return np.random.choice(self.ids, size=n, p=self.weights)

def collate_with_proprio(samples, max_prop=20):
    """本体向量按最大维度填充加掩码；掩码随批次下发，网络对填充位忽略。"""
    batch = {"proprio": [], "proprio_mask": [], "embodiment_id": []}
    for sample in samples:
        vec = np.asarray(sample["proprio"], dtype=np.float32)
        pad = np.zeros(max_prop, dtype=np.float32)
        mask = np.zeros(max_prop, dtype=np.float32)
        pad[: len(vec)] = vec                     # 实际维度按顺序摆放
        mask[: len(vec)] = 1.0                    # 有效位为 1，填充位为 0
        batch["proprio"].append(pad)
        batch["proprio_mask"].append(mask)
        # 具身标识沿样本下发：适配层与掩码约定共享同一标识体系
        batch["embodiment_id"].append(sample["embodiment_id"])
    return batch

解读：（1）采样按任务覆盖加权，避免数据量大的具身垄断批次；最小占比 10% 为下限保护；（2）本体填充位与有效位用掩码区分，网络对填充位输出零注意力，避免"零值被当成真实关节角"；（3）具身标识随批次下发，适配层与掩码约定共享同一标识体系；（4）填充维度取所有具身的最大值，新增具身时只需扩维并在新模型版本中处理。

常见坑

  • 关节角直接跨具身共享：不同机器人的关节顺序与量程不同，共享动作空间训练无法收敛。修复：统一到末端相对位姿的规范空间，或按具身加适配层隔离。
  • 忽略控制频率差异：同一示范数据在不同具身上执行时动作的时间尺度不同，迁移后动作过快或过慢。修复：统一按时间尺度重采样动作序列，并在具身嵌入中加入控制频率条件。
  • 本体维度错配未掩码：填充的零值参与计算，网络把"零关节角"当作真实输入。修复：掩码随批次下发并参与注意力或归一化计算，缺失相机通道同样处理。
  • 负迁移来源未隔离：差异大的具身共用动作头，互相拖累。修复：动作头按具身分离，先共享视觉语言层；用消融实验测量各具身单独训练与联合训练的差值。
  • 相机与坐标约定不统一：各具身相机外参与末端坐标系定义不同，规范动作的物理含义随之漂移。修复：数据管线中统一坐标定义与朝向约定，转换代码单点实现并配单元测试。

练习与思考

  1. 具身 B 的数据量是具身 A 的三倍。把采样配比从"按数据量"改为"按任务覆盖"后，预测两个具身的成功率变化方向，并说明背后的机制。★
    提示
    具身 A 的批次占比上升，其成功率提升；具身 B 在共享表征中的主导减弱，短期可能略降，长期因表征更均衡而恢复。机制是有效更新量由采样频率与梯度尺度共同决定。
  2. 推导：证明对两个同构具身（仅零点与量纲差），线性映射 aB = T·aA + b 可以精确对齐动作空间；再举一个线性映射无法对齐的例子并说明原因。★★★
    提示
    同构具身的关节空间线性同构，逐关节缩放与平移即可对齐。反例：串联臂与并联臂或自由度数量不同的具身，关节空间维度与拓扑不同，运动学映射非线性且维度不匹配。
  3. 设计消融实验测量负迁移：对三个具身分别训练单具身模型与联合模型，比较各具身成功率差值。给出结论的判定标准与需要控制的变量。★★
    提示
    判定标准：联合模型在每个具身上不低于单具身模型的 95% 作为无显著负迁移的界限；控制变量包括参数量、训练步数、数据量与评估初始状态集。
  4. 把旋转表示从欧拉角换成六维表示，预测动作回归的稳定性与插值行为的变化，说明对抓取类精细任务的实际影响。★★
    提示
    欧拉角在奇异区附近回归目标跳变，动作抖动大；六维表示连续，插值稳定。抓取任务对末端姿态精度敏感，换用六维后失败率通常下降，代价是动作维度增加。
  5. 计算：10 Hz 采集的 8 步动作块在 20 Hz 与 50 Hz 执行器上直接回放，各自耗时多少、速度放大几倍？给出两种把时长还原到 0.8 秒的方案。★★
    提示
    20 Hz 下 8 / 20 = 0.4 秒（放大 2 倍），50 Hz 下 8 / 50 = 0.16 秒（放大 5 倍）。方案一：数据管线把块重采样为 16 步（20 Hz）或 40 步（50 Hz）；方案二：执行侧保留原块并按时间戳线性插值，动作幅值与时间成比例缩放，重采样位置统一在数据管线单点实现。

小结

  • 跨具身迁移的价值在视觉语言层，难题在动作空间的形式差异。
  • 动作对齐两条路线：规范接口（末端相对位姿）提供身体无关表示，仿射适配层处理量纲与零点差异。
  • 条件化结构按"共享层承载动作效果、专用层承载动作表达"划分，具身嵌入提供条件信号。
  • 负迁移通过结构隔离、采样配比与课程顺序三层手段控制，消融实验是测量手段。
  • 本体感受维度用填充加掩码对齐，相机与坐标约定需要在数据管线中单点统一。
