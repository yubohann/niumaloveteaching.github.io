第二篇 · 联合训练进阶与策略能力

第 037 章：联合训练中的强化学习集成

把策略优化放进世界模型的想象里执行，联合训练由此获得超越演示数据的能力；本章讲清想象 RL 的结构、梯度隔离的必要性与更新节奏的设计。

  • 主题：想象强化学习（imagination-based RL） / 联合更新节奏
  • 关键公式：Lactor = −E[ Σ λ-return 的对数概率加权 ]；stop-gradient 隔离；WM 与策略更新频率比
  • 预计学时：55 分钟
  • 前置章节：第 036 章

学习目标

  • 理解想象 RL 的循环结构：世界模型 rollout、奖励与价值预测、λ-return 计算、actor 与 critic 更新。
  • 掌握梯度隔离（stop-gradient）的作用与取舍：保护动力学表征与允许轻度联合之间的边界。
  • 掌握想象偏差的放大机制与三类保守化手段：不确定性惩罚、模型集成、短时域。
  • 会设计世界模型与策略的更新频率比、目标网络与回放混合比例。
  • 能诊断想象回报虚高、critic 过估计与梯度泄漏三类问题。

背景与动机

第 023 章的模仿初始化让策略达到演示数据的水平，但模仿学习的上限是演示者的水平，且对演示未覆盖的状态缺乏恢复能力。强化学习（Reinforcement Learning, RL）允许策略在试错中超越演示，代价是真实交互昂贵。世界模型提供第三条路径：在潜空间里执行想象 rollout（imagination rollout），用预测的奖励与价值信号更新策略，真实交互只用于校正世界模型。

集成带来的新问题集中在耦合上：策略、奖励头、价值头与动力学共享表征，任何一方的梯度都可能扰动其他方。例如策略目标的梯度若穿透进动力学，动力学会被"改造成对策略有利的样子"，想象轨迹逐渐失真。梯度隔离与更新节奏是本章的核心机制。

本章与第 022 章（奖励预测）与第 031 章（不确定性）的衔接：奖励头提供想象回报，不确定性输出提供保守化信号；三者组合成完整的想象训练闭环。

核心原理

1. 想象 RL 的循环结构

一个想象训练周期由四步构成：从回放缓冲采样真实潜状态作为起点；世界模型推进 H 步生成想象轨迹；奖励头与价值头为每步打分；按 λ-return 计算目标并更新 actor 与 critic。策略目标为：

Lactor = − E想象轨迹 [ Σt log πθ( at | zt ) · Ât ] − η · H(πθ) Ât 为 λ-return 减去基线得到的优势估计；η 为熵正则系数；想象轨迹由冻结角色的世界模型生成

策略目标的梯度形式来自得分函数估计：目标期望回报对参数的梯度为 ∇J = E[ ∇log π(a|z) · G ]，用优势 Â 替换回报 G 只改变基线、不改变期望，换来更小的方差，这就是损失中"对数概率乘优势"的来源。策略只通过这些梯度步移动动作分布，想象轨迹本身不携带可回传的监督，隔离设计因此可行且必要。

critic 用回归损失拟合 λ-return，目标值经过 stop-gradient 处理。想象轨迹的推进存在两种精度模式：短时域（5 至 8 步）高频更新，偏差小但信用链短；长时域（15 步以上）信用链长但预测误差大。常见折中是 15 步并配合第 036 章的误差修正。

数值算例：H = 3、奖励均为 1、critic 预测值 [0.9, 0.8, 0.7]、γ = 0.99、λ = 0.95，按递推 Rt = rt + γ[(1 − λ)V(zt+1) + λRt+1] 从末端计算：R2 = 1 + 0.99 × 0.7 = 1.693；R1 = 1 + 0.99 × (0.05 × 0.7 + 0.95 × 1.693) ≈ 2.627；R0 = 1 + 0.99 × (0.05 × 0.8 + 0.95 × 2.627) ≈ 3.510。对照两个极端：λ = 0 退化为单步目标 1 + 0.99 × 0.8 = 1.792，λ = 1 退化为蒙特卡洛回报 3.649。λ 在两端之间的插值让目标在自举的低方差与完整回报的低偏差之间移动，0.95 靠近蒙特卡洛一侧，信用分配更充分，目标方差也更高，这与想象训练用小学习率、多更新步的做法互相配套。

2. 梯度隔离：边界与取舍

策略目标的梯度默认会沿想象轨迹穿透到世界模型与奖励头。两类隔离方案：

  • 完全隔离：想象轨迹的潜状态与奖励全部 detach，梯度只更新 actor 与 critic。动力学表征由独立的预测损失维护，稳定性最高。
  • 轻度联合：允许策略梯度部分穿透进奖励头（不穿透动力学），让奖励预测与策略目标协调，代价是奖励信号可能被策略目标塑形。

选择依据是训练阶段：早期以世界模型质量为瓶颈，完全隔离；后期世界模型稳定、瓶颈转到奖励刻画时，可引入轻度联合并用验证指标监控奖励头的校准误差。无论哪种方案，动力学核心的表征更新都应与策略目标的梯度分离，最稳健的组合是"动力学只学预测、奖励头可选择性接收策略梯度"。

隔离边界的推导：策略损失对世界模型参数的依赖为 ∂Lactor / ∂θwm = Σt (∂L / ∂zt) · (∂zt / ∂θwm)。把想象轨迹的潜状态与奖励 detach，等价于强制 ∂zt / ∂θwm = 0，求和项整体归零，世界模型只剩自身的预测损失一条更新通道。轻度联合保留奖励头的对应雅可比项，策略目标可以微调奖励头形状，同时要防止激励偏移，即奖励头被整体抬高以放大优势。

方案梯度可达模块稳定性主要风险适用阶段
完全隔离actor 与 critic高奖励刻画滞后于策略需求早期，世界模型未稳
轻度联合再加奖励头中奖励被策略目标塑形模型稳定、瓶颈在奖励
完全联合全部模块低动力学被改造，想象失真不宜作为默认方案

3. 想象偏差的放大与保守化

策略在想象中优化会主动寻找模型预测的高回报区域，这些区域往往正是模型误差最大的位置，偏差沿优化方向被放大。三类保守化手段配合使用：

手段机制代价
不确定性惩罚想象回报减去 κ·σtotalκ 过大导致探索停滞
模型集成多模型预测取悲观下界计算成本成倍
短时域更新限制信用链长度长程行为学习变慢

另一条正交的防线是真实数据锚定：想象批次中混入一定比例的真实轨迹损失（监督项），策略在追求想象回报时必须保持对真实数据的拟合。监控指标是"想象回报与真实回报的差值"：差值持续扩大而不收敛，说明保守化不足或模型误差被利用。

放大机制的量化视角：设模型在策略访问区域的平均回报高估为 δ，折扣 γ = 0.99 时单步高估对总回报的贡献被 1 / (1 − γ) = 100 的折扣因子放大。δ = 0.05 的单步乐观在长时域下可累积出约 5 个单位的虚高回报，足以让策略放弃真实回报 0.5 但估计准确的选项。该放大链解释了保守化惩罚必须随 γ 与时域一起调整的原因：固定常数在多任务之间不可迁移。

4. 更新频率与节奏

世界模型与策略的更新频率比决定两者的相对步速。更新世界模型太频繁，策略的目标函数持续移动，训练不稳；更新策略太频繁，模型误差被反复利用，偏差累积。比例背后的匹配原理：每个参数组的学习进度可以用验证损失的下降速率近似刻画，两模块速率接近时耦合系统最稳。世界模型损失进入平台期而更新继续，等于给策略提供重复的目标；策略损失进入平台期而更新继续，等于在固定目标上过优化。实现上用验证损失的滑动平均斜率估计速率，比例按速率比微调，避免长期固定在单一数值。经验节奏：

每收集 1 批真实数据 → 世界模型更新 1 步 → 想象 RL 更新 1 至 2 步 比例按两者验证指标的收敛速度微调；critic 目标网络按固定间隔硬同步或 EMA 平滑更新

critic 的过估计在想象训练中尤为常见：想象轨迹覆盖有限、λ-return 目标的方差大，critic 对乐观区域的估计偏高，策略进而聚集到这些区域。标准对策是双 critic 取最小值（clipped double Q）与目标网络延迟更新。BC 正则项（对演示数据的似然）作为额外的锚，抑制策略偏离数据分布过远，与第 023 章的回放机制同源。

节奏的数值含义：1 : 2 的比例下，每 100 个真实批次对应 100 次世界模型更新与 200 次策略更新，策略看到的目标平均只落后一个模型版本；改成 1 : 10 后，100 次模型更新对应 1000 次策略更新，平均每个模型版本被优化 10 次，模型误差被反复利用的机会多一个量级。目标网络软更新系数 0.01 对应约 1 / 0.01 = 100 次更新的跟踪时间常数，与策略步速同阶；系数再小，critic 会跟不上快速移动的目标。

三类保守化手段的组合顺序：先定短时域上限（不超过可预测时域的三分之二），再把不确定性惩罚当作主开关（κ 按真实回报差值曲线调度），模型集成只在高风险任务上启用（推理成本成倍）。监控上把"想象回报减去真实回报"按训练步画曲线，曲线收敛到零附近说明保守化强度与外推风险的平衡点已经找到。

实现思路与设计

想象 RL 集成的工程结构由数据循环、模型更新、想象训练与监控四部分组成。与第 036 章的差异：036 修预测精度，本章把预测接入策略优化闭环。

  1. 数据循环：真实交互数据进入回放缓冲，同时用于世界模型监督、BC 锚定与起始状态采样。
  2. 模型更新：世界模型按预测损失独立更新；奖励头完全隔离更新，策略与价值只消费其输出。
  3. 想象训练：每步从缓冲取起点，rollout 15 步，λ-return 计算目标，actor 与 critic 各更新一步。
  4. 监控：想象回报与真实回报差值、不确定性均值、critic 预测误差、BC 锚定损失四项指标联动。

差值在训练早期因模型乐观而自然为正；持续扩大说明策略正在利用模型误差。此时优先检查三个参数：不确定性惩罚是否过低、想象步长是否超过可预测时域、世界模型更新是否落后于策略。三项排查按顺序执行，避免同时调整多个变量。

回放混合比例的数值约定：每个想象批次（64 条起点）配套一个等量的真实锚定批次，BC 正则以权重 0.1 加入，实际梯度占比约为 1 : 10 量级；锚定过强会让策略退回演示行为，过弱则在想象波动时恢复能力不足。验收标准是演示集上的动作误差随训练上升不超过 10%，超出说明锚定力度不够。

四项监控的联动判读：想象回报差值上升且不确定性均值上升，指向模型覆盖面不足（补数据或收紧探索范围）；差值上升而不确定性平稳，指向惩罚过弱（上调 κ）；差值平稳而 critic 预测误差上升，指向目标方差过大（降 λ 或降 critic 学习率）；BC 锚定损失上升说明策略偏离演示分布，先检查想象时域再检查锚定权重。更新节奏的验收以真实回报曲线为准，想象回报曲线只作参考，世界模型验证损失与真实成功率同步改善才说明节奏健康。

隔离边界有一个自然的例外：策略消费真实数据的 BC 路径不经过想象轨迹，不受 detach 边界影响；设计文档中应把该路径单独标出，避免调试隔离问题时把它误判为泄漏通道。

关键代码与解读

以下片段参照公开的潜空间想象 RL 实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：想象轨迹上的 actor 与 critic 更新

import torch

def imagine_and_update(policy, world_model, reward_head, critic, z0,
                       horizon=15, gamma=0.99, lam=0.95, kappa=0.3):
    """想象 rollout 与策略更新：所有目标量 detach，梯度只回到策略与价值。"""
    z = z0
    logps, rewards, values, uncs = [], [], [], []
    for t in range(horizon):
        a, logp = policy.act_with_logprob(z)
        # 世界模型前向在 no_grad 语义下使用：动力学不被策略目标扰动
        stats = world_model.predict_stats(z, a)
        z = stats["mean"]
        r = reward_head(z, a)
        # 保守化：从预测回报中扣除不确定性惩罚
        rewards.append(r - kappa * stats["total"].mean())
        logps.append(logp)
        values.append(critic(z))
        uncs.append(stats["epistemic"].mean())

    # λ-return 反向递推：目标全部 detach，作为回归与加权的常数
    with torch.no_grad():
        ret = values[-1]
        targets = []
        for t in reversed(range(horizon)):
            next_v = values[t] if t == horizon - 1 else values[t + 1]
            ret = rewards[t] + gamma * ((1 - lam) * next_v + lam * ret)
            targets.append(ret)
        targets = torch.stack(list(reversed(targets))).detach()

    adv = targets - torch.stack([v.detach() for v in values])
    actor_loss = -(torch.stack(logps) * adv).mean()
    critic_loss = torch.nn.functional.mse_loss(torch.stack(values),
                                               targets)
    return actor_loss, critic_loss

解读：（1）想象轨迹中的奖励与价值全部经 detach 后参与策略目标，梯度不进入动力学与奖励头，实现完全隔离；（2）奖励扣除 κ·σ 后进入回报，保守化在目标层实现，与第 031 章的分解项直接衔接；（3）优势用 detach 的价值做基线，critic 只通过自身的回归损失更新；（4）函数返回两个损失分别回传，更新顺序由调用方控制，便于实现"actor 一步、critic 一步"的节奏。

片段 2：联合更新循环与 BC 锚定

def joint_rl_step(modules, replay, batch):
    """联合步：按比例调度世界模型、RL 与 BC 三类损失。"""
    wm_loss = modules["wm"].prediction_loss(batch["obs"], batch["action"],
                                            batch["next_obs"])
    # 世界模型独立更新：预测目标与策略目标互不干扰
    wm_loss.backward()
    modules["wm_opt"].step()
    modules["wm_opt"].zero_grad()

    # 想象起点从回放缓冲采样真实潜状态，保证分布锚在真实数据上
    z0 = modules["wm"].encode(replay.sample_starts(64))
    actor_loss, critic_loss = imagine_and_update(
        modules["policy"], modules["wm"], modules["reward"],
        modules["critic"], z0, horizon=15)
    # BC 锚定：用同一批演示数据约束动作分布，权重 0.1
    bc_loss = modules["policy"].bc_loss(batch["obs"], batch["action"])
    (actor_loss + 0.1 * bc_loss).backward()
    modules["policy_opt"].step()

    critic_loss.backward()
    modules["critic_opt"].step()
    modules["critic_opt"].zero_grad()
    modules["policy_opt"].zero_grad()
    return {"wm": float(wm_loss), "actor": float(actor_loss.detach()),
            "critic": float(critic_loss.detach()), "bc": float(bc_loss.detach())}

解读：（1）三类损失分别回传、使用独立优化器，参数组天然隔离，避免一次回传中梯度互相污染；（2）世界模型先更新再生成想象，保证策略消费的是最新模型；（3）BC 锚定与 actor 损失同批回传但权重小，作用类似正则项，防止策略在想象中跑偏；（4）返回各损失分量，监控面板按分量画曲线，是排查训练异常的入口。

常见坑

  • 梯度泄漏进世界模型：策略目标回传时穿透动力学，模型被"改造成对策略有利"。症状是预测误差缓慢上升而想象回报上升。修复：想象轨迹的潜状态与奖励 detach，动力学单独更新。
  • 想象回报虚高：策略聚集到模型误差区域，真实回报不涨。修复：检查想象与真实回报差值曲线，加大不确定性惩罚或缩短想象步长。
  • critic 过估计：价值预测持续高于实际 λ-return，优势估计有偏。修复：双 critic 取最小值、目标网络延迟更新、减小 critic 学习率。
  • 更新频率失衡：世界模型更新过快导致目标移动，或策略更新过快利用陈旧模型。修复：按两模块验证指标收敛速度设定比例，本调 1 : 2 作为起点。
  • 缺少 BC 锚定：策略在想象中漂移到演示分布外，真实执行时恢复能力缺失。修复：保留小权重 BC 正则与演示回放批次。

    路径为"策略参数 ← 对数概率 ← 潜状态 ← 世界模型参数"；潜状态 detach 后，策略梯度无法越过该边界回到动力学参数，唯一进入世界模型的是其自身的预测损失。
  3. 设计梯度隔离消融：完全隔离、仅奖励头接收策略梯度、不隔离三组，预测奖励头校准误差、预测误差与最终成功率三项指标的排序。★★
    提示
    不隔离组预测误差最大、校准最差；仅奖励头接收介于两者之间；完全隔离组预测最稳，但奖励刻画与策略目标的协调需要更长训练。成功率排序取决于数据量，通常完全隔离在中小规模下更优。
  4. 把不确定性惩罚 κ 从 0.3 按线性调度升到 0.8 再回落。说明这种"先保守后放开"调度可能带来的训练行为变化与适用条件。★★
    提示
    早期保守抑制模型误差利用，随模型改进放开以允许探索；适用条件是模型质量确实随时间提升且可验证，否则放开阶段会把早期积累的偏差暴露出来。
  5. 计算：H = 3、r = [1, 1, 1]、V = [0.9, 0.8, 0.7]、γ = 0.99、λ = 0.95，按递推求三个 λ-return 目标；再给出 λ = 0 与 λ = 1 的 R0 对照。★★
    提示
    递推得 R2 = 1.693、R1 ≈ 2.627、R0 ≈ 3.510；λ = 0 时 R0 = 1.792，λ = 1 时 R0 ≈ 3.649。手算后与代码核对，重点观察 (1 − λ) 的自举权重如何把目标拉向 critic 预测。

小结

  • 想象 RL 在潜空间执行策略优化，真实交互用于校正模型，突破模仿学习的数据上限。
  • 梯度隔离保护动力学表征，选择完全隔离或轻度联合取决于世界模型与奖励头的成熟度。
  • 想象偏差通过不确定性惩罚、模型集成与短时域三类手段保守化，想象与真实回报差值是最重要的监控项。
  • 更新频率比决定训练稳定性，critic 过估计用双 critic 与目标网络抑制。
  • BC 锚定保持策略与演示数据的联系，与回放机制配合使用。
