第三篇 · 策略与世界模型深化

第 047 章：VLA策略的零样本泛化

零样本泛化的来源是共享语义结构，数据规模本身给不出这一能力：本章把泛化拆成改写、组合、实例、场景四个因素，给出留出评估协议、改写一致性约束与捷径诊断方法。

  • 主题：VLA 策略 / 泛化（Generalization）
  • 关键机制：组合性泛化、改写一致性、反事实评估
  • 预计学时：55 分钟
  • 前置章节：第 046 章 联合训练中的多模态对齐

学习目标

本章把"零样本"从宣传口径还原为可分解、可测量的实验设计问题。

  • 理解零样本泛化（Zero-Shot Generalization）的定义边界：目标任务未参与梯度更新，且训练数据不包含任务的成功示范。
  • 能把泛化拆成指令改写、组合新任务、新实例、新场景四个因素，并为每个因素设计留出（Held-out）划分。
  • 理解组合性泛化与语义对齐的关系：新组合在嵌入空间中表现为语义因子的重排，表示空间的因子化程度决定泛化上限。
  • 掌握改写一致性（Paraphrase Consistency）约束的构造方式与权重选择依据。
  • 能诊断语言捷径与视觉捷径：区分"真正依赖指令与视觉"与"依赖数据频率统计"的模型行为。

背景与动机

部署现场的任务描述与训练集不会逐字相同，操作对象的颜色、形状与新场景的布局也持续变化。零样本泛化衡量策略在完全未训练过的任务变体上直接执行的能力，是 VLA 相对传统策略的核心卖点之一。问题在于这一能力的来源常被误读：扩大数据规模可以提升同分布精度，泛化到未见组合依赖的是表示空间的语义结构，两者需要不同的训练与评估手段。

训练集构建方式直接决定零样本指标的含金量。若留出任务的成功示范以任何形式进入训练（包括语义等价的模板、同场景其他变体），指标测量的是插值能力；零样本能力的口径要求留出任务完全隔离。前一章的对齐机制提供语义共享的基础，本章在其上补充一致性约束与评估协议，回答"对齐到什么程度才算泛化可用"。

核心原理

依次讨论泛化的因素分解、组合性的表示条件、一致性约束与捷径来源。

1. 泛化因素分解

因素训练集状态留出方式考察的能力
指令改写同义句式中部分保留留出改写模板与词汇语言鲁棒性，与任务本身无关的表层变化
组合新任务动词与名词各自出现，组合不出现在训练集按动词与物体的组合划分因子化与重组能力，零样本的核心
新实例物体类别可见，具体实例未见留出形状或颜色变体视觉语义的类内泛化
新场景布局与光照变化留出场景配置对背景与相机变化的鲁棒性

四类因素的难度依次上升：指令改写只考验语言编码器的平滑性，组合新任务要求指令嵌入与视觉嵌入同时因子化，任何一侧把"动词加名词"纠缠成整体编码，组合迁移都会失败。评估报告应按因素分组给出成功率，总体平均值会掩盖组合任务的塌陷。

2. 组合性泛化与表示因子化

把任务语义分解为若干因子（动词 v、物体 o、空间关系 r），任务嵌入可视为因子嵌入的组合。当训练集覆盖单个因子的大部分取值、但缺少部分组合时，模型必须依据因子级结构外推。因子化的表示空间中，新组合对应已知嵌入向量的重排，模型只要学会因子之间的操作语义即可完成迁移；纠缠的表示空间中，新组合落在无监督区域，输出不可预期。

从误差分解的角度，零样本任务上的误差包含三部分：近似误差（模型容量）、估计误差（训练样本量）与分布偏移误差（训练与目标分布的距离）。分布偏移项与表示空间的几何直接相关：对齐良好的嵌入把新组合映射到已知嵌入附近，偏移项较小；嵌入退化时该项主导，增加数据量也无法弥补。

3. 改写一致性约束

统一句式的数据让语言编码器把固定的修饰结构当成任务线索。改写一致性约束对同义指令施加输出分布层面的约束：

Lcons = KL( π(a | s, l1) ‖ π(a | s, l2) )，l1、l2 互为改写 同一观测下两条语义相同指令的动作分布应当接近；双向 KL 或对称 JS 散度可避免方向偏置

约束的作用是压缩语言编码器对表层形式变化的敏感度，把方差预算留给语义差异。权重取值需要与任务损失对齐：过小无效，过大时策略倾向于忽略语言条件，退化为视觉-only 策略。监控手段是报告"同义指令动作分布距离"与"反义指令动作分布距离"的比值，健康区间是前者远小于后者。

4. 捷径：语言先验与视觉捷径

数据中存在可利用的频率结构时，模型会选择低成本的捷径。语言先验指策略忽略视觉输入、直接从指令统计预测高频动作（例如训练集中"抓取"总是指向同一位置）；视觉捷径指策略忽略指令、对场景中的显著物体执行默认动作。两类捷径在分布内指标上表现良好，在零样本划分下迅速暴露。

诊断手段是反事实评估：固定观测交换指令、固定指令交换目标物体，观察动作是否随之改变。反事实一致率过低说明对应模态被忽略，需要在训练中增加需要该模态的困难样本，或提高对齐与一致性约束的权重。

实现思路与设计

设计分数据划分、损失配置与评估协议三部分，全部围绕"避免泄漏、分组报告"两条原则。

数据划分流程

  1. 枚举任务因子：动词集合、物体集合、关系集合，构建组合覆盖矩阵。
  2. 按矩阵选出留出组合，确保留出组合的动词与物体各自在训练集中出现过。
  3. 检查文本模板与场景配置不跨划分复用，剔除语义等价的重复模板。
  4. 训练集只包含留出组合之外的示范；评估集为留出组合重新采集的片段。

超参数表

参数默认值作用取值依据
一致性权重0.2改写一致性损失配比与对比权重同量级；任务损失为主，一致性为辅
改写样本比例30%批次中含改写的样本占比过低约束覆盖不足，过高挤占任务样本
留出组合比例20%评估任务占全部组合的比例低于 10% 评估方差大，高于 30% 训练覆盖退化
评估片段数每组合 30 条统计显著性按二项分布估计，成功率标准差约 0.09
反事实评估开关开启捷径诊断与主指标同期报告，成本仅一次额外前向

评估精度可以事先算清：每组合 30 条片段、真实成功率 0.7 时，成功率的标准误约 8.4 个百分点（√(0.7 × 0.3 / 30)）；标准误与片段数的平方根成反比，减半需要约 4 倍片段数（120 条约 4.2 个百分点）。两组方法的成功率差值标准误约为单组的 √2 倍（约 12 个百分点），小于该量级的差异不宜直接宣布优劣；报告时给出区间与片段数，跨天重采一批复核稳定性。

与前一章的差异点

第 046 章的对比对齐是训练机制，作用于表示空间的距离结构；本章的泛化是评估目标与数据划分方法，检验对齐机制的收益。同一套嵌入可以由对齐训练得到，泛化指标是它的验收测试；反过来，泛化评估暴露的失败模式又指导对齐损失中配对构造的调整。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖组合划分、一致性损失与分组评估。数值与上表一致。

片段 1：组合留出划分

def compositional_split(tasks, holdout_ratio=0.2, seed=0):
    """按动词与物体的组合做留出划分。
    设计意图：保证留出组合的两端因子在训练集可见，测的是重组能力；新词泛化由另一类划分检验。"""
    import random
    rng = random.Random(seed)
    all_pairs = [(v, o) for v in tasks["verbs"] for o in tasks["objects"]]
    n_holdout = max(1, int(len(all_pairs) * holdout_ratio))
    holdout = set(rng.sample(all_pairs, n_holdout))
    train_pairs = [p for p in all_pairs if p not in holdout]
    # 断言两端因子仍被训练集覆盖：缺少覆盖时留出集不再测组合泛化
    assert {v for v, _ in train_pairs} == set(tasks["verbs"]), "有动词未出现在训练组合中"
    assert {o for _, o in train_pairs} == set(tasks["objects"]), "有物体未出现在训练组合中"
    return train_pairs, sorted(holdout)

解读：（1）两条断言是划分合法性的最低检查：任何一条失败，评估结论就不能称为组合泛化，只能称为新词或新物体泛化。（2）留出集合固定随机种子生成并保存，保证不同模型版本使用同一划分，指标可比。（3）实际数据中一个任务可能对应多条指令，划分要先在任务层完成，再把该任务的全部指令一起移出训练集，避免同任务改写残留造成泄漏。

片段 2：改写一致性损失

import torch
import torch.nn.functional as F

def paraphrase_consistency(policy, obs, instr_a, instr_b, weight=0.2):
    """对同义指令的动作分布施加对称散度约束。
    设计意图：压缩语言编码器对表层形式变化的敏感度，把方差预算留给语义差异。"""
    dist_a = policy.action_dist(obs, instr_a)   # 分布对象，支持 log_prob 与采样
    dist_b = policy.action_dist(obs, instr_b)
    # 用动作块上的对数概率差近似 KL 的蒙特卡洛估计，避免解析密度不可得
    samples = dist_a.rsample((4,))              # 每条观测采样 4 组动作块做估计
    log_ratio = dist_a.log_prob(samples) - dist_b.log_prob(samples)
    kl_ab = log_ratio.mean()
    # 对称化：单向 KL 会让某一方向的分布塌缩，双向平均更稳定
    samples_b = dist_b.rsample((4,))            # 反向 KL 必须从目标分布自身采样
    kl_ba = (dist_b.log_prob(samples_b) - dist_a.log_prob(samples_b)).mean()
    return weight * 0.5 * (kl_ab + kl_ba)

解读：（1）扩散式或高斯式动作头都通过重参数化采样获得可导样本，对数概率差提供 KL 的无偏估计；采样数 4 是方差与开销的折中。（2）对称化处理避免单向 KL 把分布推向另一个分布的众数时产生塌缩；对称后的梯度对两条指令公正。（3）该损失只回传语言编码器与动作头，不回传视觉主干，防止视觉特征被语言一致性目标扭曲，这一边界需要在实现中显式设置。

片段 3：分组评估与反事实诊断

@torch.no_grad()
def zero_shot_report(rollout_fn, heldout_tasks, trials=30):
    """按任务报告成功率，并输出反事实一致率。"""
    report = {}
    for task in heldout_tasks:
        success, counterfactual = 0, 0
        for _ in range(trials):
            env = task.make_env()
            success += int(rollout_fn(env, task.instruction))     # 正常评估
            # 反事实：交换目标物体名称，若动作完全不变说明语言条件被忽略
            swapped = task.swap_object()
            counterfactual += int(rollout_fn(env, swapped) != rollout_fn(env, task.instruction))
        report[task.name] = {"success": success / trials,
                             "cf_consistency": counterfactual / trials}
    # 均值与逐任务明细同时输出：平均值会掩盖个别组合的塌陷
    avg = sum(r["success"] for r in report.values()) / len(report)
    print(f"零样本组合平均成功率 {avg:.2%}，明细 {len(report)} 项")
    return report

解读：（1）反事实一致率通过交换指令中的目标物体测量"指令是否真正进入决策"；该比率接近零说明策略忽略了语言条件。（2）每组合 30 条片段使成功率的标准误约 0.09，报告时以平均值加减误差呈现，避免把单次波动当成方法差异。（3）评估函数固定评估集与随机种子；场景初始状态使用固定序列，保证不同检查点面对同一批初始条件。

常见坑

  • 留出组合的因子泄漏：留出组合的动词或物体在训练集中从未以任何组合出现，评估实际测量的是新词泛化。修复：划分后执行因子覆盖断言。
  • 同任务改写残留：任务级划分前先按指令去重，避免同一任务的改写句子留在训练集。修复：以任务标识为单位划分，按句子划分会留下同任务的改写。
  • 只测改写不测组合：指标好看但组合能力未知。修复：按四因素分组报告，组合任务单独列出。
  • 语言捷径未被发现：成功率虚高来自指令频率统计。修复：反事实交换评估，观察动作分布是否随指令变化。
  • 评估样本过少：每组合十几条片段，报告差异落在噪声范围内。修复：按二项分布估计标准误，每组合至少 30 条，跨天重采以检验稳定性。

练习与思考

  1. 构造一个 3 动词 × 4 物体的组合矩阵，设计留出 20% 组合的划分，并指出划分中必须满足的两条覆盖条件。★★
    提示
    共 12 个组合，留出 2 至 3 个。条件一：每个动词至少出现在一个训练组合中；条件二：每个物体至少出现在一个训练组合中。留出组合的两端因子均可见。
  2. 把一致性权重从 0.2 提高到 2.0，预测三件事的变化：同义指令动作分布距离、反义指令动作分布距离、零样本组合成功率，并说明如何验证判断。★★
    提示
    同义距离下降；反义距离可能同样下降（语言条件被整体削弱），组合成功率大概率下降。验证：打印两类距离的比值与语言注意力权重分布。
  3. 推导：把零样本误差写成近似误差、估计误差、分布偏移误差三项之和的形式，说明哪一项由表示空间的对齐质量主导。★★★
    提示
    近似误差由容量决定，估计误差随样本数下降，分布偏移误差衡量训练与目标分布在表示空间中的距离。对齐把新组合映射到已知嵌入附近，主要压缩第三项。
  4. 设计反事实评估的两个变体：交换指令、交换物体位置，分别说明它们诊断哪类捷径、指标如何计算。★★
    提示
    交换指令诊断语言被忽略；交换物体位置诊断视觉被忽略。指标用"动作分布距离"或"动作改变率"，与正常条件下的分布距离做比值参照。

小结

  • 零样本泛化按指令改写、组合、实例、场景四因素分解，评估必须分组留出并报告明细。
  • 组合泛化的上限由表示空间的因子化程度决定，纠缠表示下增加数据无法弥补。
  • 改写一致性约束压缩表层形式敏感度，权重需与任务损失对齐，过大导致语言条件被忽略。
  • 语言捷径与视觉捷径用反事实交换诊断，一致率过低时需增加困难样本或调整约束权重。
  • 留出划分以任务为单位，划分后执行因子覆盖断言，固定划分与初始条件保证指标可比。
