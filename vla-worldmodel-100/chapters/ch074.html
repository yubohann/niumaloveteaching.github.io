第四篇 · 训练机制与应用集成

第 074 章：VLA策略的视觉语言预训练

本章讲 VLA 的视觉语言预训练（Vision-Language Pretraining）：对比、生成与定位三类目标各自提供什么能力，图文数据、指令数据与示教数据如何配比，以及从预训练模型到策略网络的微调路线。

  • 主题：预训练 / 视觉语言表征与微调
  • 关键公式：L = λcLcontrastive + λgLcaption + λrLgrounding
  • 预计学时：55 分钟
  • 前置章节：第 073 章：联合训练中的稀疏奖励处理

学习目标

  • 理解三类预训练目标的互补关系：对比负责全局对齐、生成负责细粒度语义、定位负责空间精度。
  • 掌握表示到策略的差距来源，理解全局语义对齐为何不足以支撑精细操作。
  • 掌握微调路线设计：冻结骨干、低秩适配与全量微调的适用条件，以及语言能力的保护手段。
  • 能实现对比加生成加定位的联合预训练步、指代定位头与冻结微调配置，理解损失配比的确定方式。
  • 会诊断语言能力遗忘、数据配比失衡与视觉词元预算冲突问题，能设计预训练到策略的过渡实验。

背景与动机

本节说明预训练在 VLA 训练体系中的位置：示教数据只覆盖有限任务与语言模板，从零训练的策略在指令改写与场景变化下迅速失效。视觉语言预训练把互联网规模的图文对应关系压缩进编码器，用两类知识为下游策略提供起点：语言与视觉的对应关系（“左前方”与画面区域的绑定），以及物体与属性的语义体系。表示的可迁移程度取决于目标设计。本章按目标、配比、过渡三部分展开。

核心原理

1. 三类预训练目标与各自的能力

对比目标把匹配的图像与文本拉近、不匹配的推远，得到全局语义对齐；生成目标（图像条件文本生成）要求模型展开细粒度描述，迫使视觉特征携带可读的局部信息；定位目标学习指代与区域坐标的对应，输出空间精度。三者可以共享一个骨干：

L = λc Lcontrastive + λg Lcaption + λr Lgrounding λ 为三项权重；对比项通常占主导，生成与定位项之和不超过对比项

三者失效模式互补：只用对比则属性绑定模糊；只加生成则坐标无从监督；定位项是精细操作迁移中最相关的一项。三类目标的监督形式与能力边界对照如下：

目标监督形式提供的能力覆盖不到的部分单独使用的失效模式
对比批内图文匹配全局语义对齐、跨模态检索属性与区域绑定、坐标属性绑定模糊，颜色与位置互换不被惩罚
生成图像条件文本似然细粒度可读特征、局部语义空间坐标的显式监督描述流畅但指向不准
定位指代与区域配对空间精度、指代消解语义广度、语言泛化局部过拟合，新类别指令失效

组合策略按下游任务的需求排序：操作任务的空间需求最高，定位项不能省；语义广度决定指令改写鲁棒性，对比项保底；生成项在两者之间补细粒度绑定。三项权重不必长期保持不变：预训练前期以对比与生成建立语义，后期提高定位权重收束空间精度，收束顺序与课程安排一致。

2. 从表示到策略的差距

预训练表示服务检索与分类，策略服务动作。差距有三处：空间精度（全局池化会抹掉局部结构）、时间结构（图文对是静态快照）、动作语义（接触关系不在预训练数据中）。定位类目标缩小空间差距，时序与动作侧由世界模型联合训练补齐，这正是课程的推进顺序。

3. 数据配比与词元预算

预训练数据分三类：互联网图文对提供语义广度，指令数据（指代、区域描述）提供语言与空间绑定，机器人示教提供动作与接触知识。配比经验是语义广度占主体，指令数据在一到两成，示教数据按采集规模决定。示教比例过低则微调阶段遗忘快，过高则语义泛化受限。视觉词元预算是另一条硬约束：Transformer 编码器的计算量随词元数平方增长，256 个视觉词元的推理延迟可能是 64 个的四倍量级；用查询压缩或池化把词元从 256 压到 64，代价是空间分辨率，收益是控制频率。压缩与精度的平衡点按任务允许的空间误差确定。

4. 数值算例：词元压缩节省的计算量

取骨干隐层维度 d = 768。单层每词元的线性部分（查询键值输出四个投影加前馈网络）乘加量约为 4 × 768 × 768 + 2 × 768 × 3072 ≈ 708 万；注意力子项为 2 × L2 × 768，随词元数 L 平方增长。代入两个配置：

L = 256：线性 256 × 708 万 ≈ 1.81 G，注意力 ≈ 0.101 G，合计 ≈ 1.91 G L = 64：线性 64 × 708 万 ≈ 0.453 G，注意力 ≈ 0.006 G，合计 ≈ 0.459 G 乘加量单位 G 为十亿次；注意力子项从 0.101 G 降到 0.006 G，约 16 倍；总计约 4.2 倍

数值结果给出两条预算判断：（1）词元数从 256 压到 64 的总前向计算约降 4.2 倍，其中注意力子项降 16 倍、线性部分降 4 倍，当 L 继续降到 16 时线性部分成为瓶颈，压缩的边际收益迅速衰减；（2）四倍的计算下降通常直接转化为可用的控制频率提升，压缩的代价是空间分辨率下降，衡量的标准是任务最小操作对象的像素尺寸：压缩后每个视觉词元覆盖的原始像素区域不应大于目标物体尺寸，否则定位头失去区分能力。

5. 微调路线：冻结、适配与解冻

过渡路线沿用迁移学习的分级思路：冻结骨干训练动作头建立基线；语言侧始终冻结，防止指令理解能力退化；视觉末段按验证曲线决定是否低秩适配；全量微调只在示教数据达到千条量级后考虑。语言能力用指令—场景匹配小验证集监控：匹配精度下降超阈值即回退冻结或降低学习率。表示与预训练偏离过快是学习率过高的辅助信号。

实现思路与设计

本节给出完整配方：阶段一在图文数据上训练对比与生成目标，骨干采用 ViT 与文本编码器的双塔加交叉注意力结构；阶段二注入定位目标，训练指代定位头；阶段三冻结骨干，用示教数据训练动作头与世界模型；阶段四按验证曲线做视觉末段适配。评估协议包含三项：指令匹配精度（语言能力）、指代定位误差（空间能力）、动作成功率（任务能力）。与第 073 章的差异：第 073 章处理奖励信号，本章处理表征来源与预训练配方。

设计决策：为什么定位项使用交叉注意力

全局特征已把空间信息池化掉。交叉注意力让语言词元检索视觉词元，注意力分布即指代区域的软标注。注意力加回归的组合兼顾空间精度与可解释性，与第 068 章的归因工具衔接。

四阶段路线的执行细节

  • 阶段边界由验证指标触发。阶段一持续到对比检索召回进入平台期；阶段二持续到定位误差进入平台期；阶段三的动作头训练以语义指标不再下降为进入条件；阶段四的视觉适配由动作成功率平台期触发。每阶段有独立的进入与退出判据，避免按固定步数机械切换。
  • 词元压缩的两种手段。查询式压缩用一组可学习查询词元对视觉特征做交叉注意力，输出固定数量词元，信息保留好但多一次注意力计算；池化压缩直接对相邻词元做平均或合并，零额外参数但边界信息损失大。目标尺寸小的任务优先查询式。
  • 阶段间的学习率重置。每次切换阶段时按新参数组的尺度重设学习率并重新 warmup，沿用上一阶段的调度会让新一轮参数在错误步长下起步。
  • 领域增量预训练的插入点。部署场景与语料分布差距大时，在阶段三之前插入一轮场景数据的指代与描述任务，训练规模取主预训练的百分之几量级，语料以场景图像配自动生成描述为主。
  • 评估隔离。三项能力指标的验证集与策略训练数据严格分离，指令匹配验证集用模板未覆盖的句式构造，防止评估泄漏推高虚指标。

关键代码与解读

以下片段以视觉语言模型与机器人策略微调的公开设计为参照，接口随版本演进。三个片段分别覆盖联合预训练步、定位头与微调配置。

片段 1：对比、生成与定位的联合预训练步

import torch
import torch.nn.functional as F

def vlm_pretrain_step(model, batch, temp=0.07):
    """三类目标的联合预训练步：共享骨干，分头计算。"""
    img_feat = model.encode_image(batch["image"])       # 全局视觉特征
    txt_feat = model.encode_text(batch["caption"])      # 全局文本特征
    # 对比项：批内负样本，对角为匹配对
    logits = img_feat @ txt_feat.t() / temp
    labels = torch.arange(logits.shape[0], device=logits.device)
    loss_clip = F.cross_entropy(logits, labels)
    # 生成项：以视觉特征为前缀自回归预测描述，补充细粒度语义
    loss_cap = model.caption_loss(batch["caption_tokens"], img_feat)
    # 定位项：回归指代区域坐标，注入空间精度
    pred_box, _ = model.ground_head(model.visual_tokens(batch["image"]),
                                    txt_feat)
    loss_ground = F.l1_loss(pred_box, batch["boxes"])
    return loss_clip + 0.5 * loss_cap + 0.5 * loss_ground

解读：（1）三项共享骨干：对比更新全局投影，生成更新解码路径，定位更新交叉注意力。（2）坐标用归一化框参数，L1 对离群标注稳健，比 L2 更适合噪声框。（3）权重 0.5 作为起点，随训练按三项损失的收敛速度比值微调，防止任一项长期主导表征。

片段 2：指代定位头

import torch
import torch.nn as nn

class GroundingHead(nn.Module):
    """定位头：语言为查询、视觉词元为键值，注意力即指代分布。"""
    def __init__(self, dim=768, n_heads=8):
        super().__init__()
        self.attn = nn.MultiheadAttention(dim, n_heads, batch_first=True)
        self.box = nn.Sequential(nn.Linear(dim, 256), nn.SiLU(),
                                 nn.Linear(256, 4))

    def forward(self, visual_tokens, phrase_feat):
        query = phrase_feat.unsqueeze(1)                 # B x 1 x D
        # 交叉注意力：返回被指代区域的特征与注意力权重
        region, attn_w = self.attn(query, visual_tokens, visual_tokens)
        box = torch.sigmoid(self.box(region.squeeze(1)))  # 归一化坐标
        return box, attn_w

解读：（1）查询用语言短语特征：定位的语义由语言决定，视觉只提供被检索的内容。（2）sigmoid 输出保证坐标落在单位区间，训练时同时约束中心与宽高。（3）注意力与框共享特征，一致时定位更可信。

片段 3：冻结骨干的策略微调配置

import torch

def build_finetune_optimizer(model, lr_head=3e-4, lr_adapt=3e-5):
    """预训练到策略的过渡配置：默认只训动作头。"""
    for p in model.backbone.parameters():
        p.requires_grad = False              # 视觉语言骨干冻结
    # 语言编码器始终冻结：保护指令理解，防止策略梯度侵蚀
    for p in model.text_encoder.parameters():
        p.requires_grad = False
    groups = [{"params": model.action_head.parameters(), "lr": lr_head}]
    if hasattr(model, "visual_adapter"):
        # 可选适配层：数据规模不足时用低秩增量替代解冻
        groups.append({"params": model.visual_adapter.parameters(),
                       "lr": lr_adapt})
    return torch.optim.AdamW(groups, weight_decay=0.01)

解读：（1）冻结顺序体现优先级：语言最保守，视觉中间，动作头最自由。（2）适配层插在视觉侧，语言保护成本最低。（3）weight_decay 对动作头同样生效，微调阶段过拟合主要发生在动作头，正则在这里收益最大。

常见坑

  • 语言能力遗忘：策略微调后指令改写鲁棒性下降。症状为同义指令成功率分化。修复：语言编码器冻结，定期跑指令匹配验证集，异常时回退学习率。
  • 数据配比失衡：对比目标占比过高，空间精度不足，表现为抓取点偏移。修复：提高定位与生成项权重，检查定位标注覆盖率。
  • 视觉词元预算冲突：压缩过狠使小物体分辨不清，压缩不足拖慢控制频率。修复：按任务中最小操作对象的像素尺寸确定词元数，用消融实验标定边界。
  • 定位标注噪声：框标注存在系统性偏移时，模型学到偏移的均值。修复：抽检标注一致性，对高噪声子集降权或改用点标注加高斯软目标。
  • 预训练分布与部署场景脱节：目标物体在图文语料中罕见，语义覆盖不足。修复：用场景数据构造指代与描述任务做领域增量预训练，再进入策略微调。

    改写失效指向语言侧遗忘或语义覆盖不足；抓取点偏移指向定位目标缺失；抖动指向动作侧与世界模型接触动力学训练不足。三者分别用指令匹配、定位误差、接触段动作误差验证。

    提示
    定位误差下降但对比检索精度可能回落，表征向空间任务倾斜；风险是语义泛化受损，表现为新类别指令成功率下降。
  3. 推导题：说明视觉词元数从 256 压到 64 时自注意力计算量的变化倍率，并给出控制频率受限时优先压缩还是优先减层级的判据。★★
    提示
    自注意力随词元数平方下降约 16 倍，线性层部分随词元数下降 4 倍；瓶颈在注意力则压缩词元，瓶颈在层串联则减层。
  4. 实验设计：设计预训练到策略的消融矩阵：骨干冻结与否、是否启用定位目标、是否领域增量预训练，报告三项能力指标与动作成功率，定位各项改动的主要贡献。★★
    提示
    冻结消融影响训练稳定性，定位消融影响抓取精度，增量预训练影响场景适配；报告需分阶段指标。
  5. 设计题：为多语言指令设计预训练与微调协议：对比与生成目标如何覆盖多语言、语言侧冻结策略是否需要调整、多语言能力如何验证。★★★
    提示
    多语言图文对扩充对比与生成数据；语言编码器冻结仍适用，但需按语族检查词表覆盖率；验证用跨语言指令同任务成功率一致性。

小结

  • 三类目标互补：对比给全局对齐，生成给细粒度语义，定位给空间精度。
  • 预训练表示与策略需求存在空间、时序与动作语义三处差距，后两者由世界模型联合训练补齐。
  • 数据配比与视觉词元预算是两条硬约束：语义广度占主体，词元数按最小操作对象尺寸标定。
  • 微调沿用分级路线：语言侧始终冻结，动作头先训，视觉末段按验证曲线适配，遗忘用指令匹配集监控。
