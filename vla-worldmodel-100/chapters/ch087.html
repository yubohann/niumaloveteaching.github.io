第 087 章：世界模型的离散化状态预测

把潜状态量化成码本索引，用分类分布预测未来：向量量化、直通估计、交叉熵转移与温度采样如何共同建模多模态未来。

  • 主题：世界模型（World Model）/ 离散表示（discrete representation）
  • 关键公式：向量量化损失与分类式转移的交叉熵
  • 预计学时：50 分钟
  • 前置章节：第 086 章

学习目标

  • 理解连续潜变量的预测困境：均方误差回归对多模态未来取均值造成"均值塌陷"，离散化如何从根本上改变分布表达。
  • 掌握向量量化变分自编码器（Vector Quantized Variational Autoencoder, VQ-VAE）的机制：最近邻量化、直通估计（straight-through estimator）、承诺损失与指数移动平均（EMA）码本更新。
  • 掌握分类式转移的交叉熵训练、标签平滑与推理期温度采样的作用。
  • 会用困惑度（perplexity）监控码本使用率，识别码本坍缩（codebook collapse）与死码（dead code）。
  • 能对比离散与连续两种预测方案在误差指标、多模态保真度与规划可用性上的差别。

背景与动机

连续潜状态的均方误差训练会把多模态未来预测成均值，而均值状态往往在物理上不存在。面对分岔路口，两种未来都合理，均方误差最优解是两者的中间值，想象 rollout 从中间值出发继续演化，轨迹失去物理意义。扩散模型可以表达多模态，但每次采样需要多步迭代，与规划模块的高频调用冲突。

离散化给出中间路线：把潜状态映射到有限码本，预测变成对码字索引的分类分布。分类分布天然是多峰的，概率质量显式可得，采样一步完成，下游还能对码字做树搜索（第 091 章展开）。代价是量化误差与码本维护的工程复杂度。第 027 章讨论过动作空间的离散化，本章处理状态潜空间的离散化，两者机制相通、对象不同，可组合使用。

核心原理

离散化预测由两级组成：第一级用向量量化把连续观测压缩成码字序列，第二级在码字空间上训练分类式转移核。

1. 向量量化与直通估计

编码器把观测映射为连续向量 ze，量化器在码本 {e1, …, eK} 中检索最近邻，输出量化向量 zq = ek，k = argminj ‖ze − ej‖。检索操作不可微，训练用直通估计绕过：前向传播使用量化值，反向传播把梯度从解码器原样传给编码器：

zst = ze + sg[ zq − ze ]，反向梯度 ∂zst/∂ze = I sg 为停止梯度算子（stop-gradient），前向为恒等映射、反向为零

训练损失由三项构成：

LVQ = ‖ x − D(zq) ‖2 + ‖ sg[ze] − e ‖2 + β ‖ ze − sg[e] ‖2 依次为重建项、码本项与承诺项；β 通常取 0.25，D 为解码器

码本项把码字拉向编码器输出，承诺项把编码器输出拉向码字，两侧相对运动防止一方主导。使用指数移动平均更新码本时，码本项可由 EMA 替代，损失只剩重建与承诺两项；EMA 衰减系数 0.99 对应约 100 批的时间常数，码本缓慢跟踪编码分布，比纯梯度更新稳定。

2. 分类式转移与采样

量化后的世界模型在码字空间演化：给定当前码字 c 与动作 a，转移核输出下一码字的分布 pθ(c′ | c, a) = softmax(logits(c, a)/T)，训练用交叉熵：

LCE = − log pθ( c′ | c, a )，采样时按温度 T 缩放 logits T 小于 1 更确定，T = 1 还原模型分布

多模态未来的优势在此显现：模型可以在多个码字上分配非零概率，采样得到不同的想象轨迹，规划模块可以对不同分支分别评估。温度采样控制想象轨迹的多样性：T 接近 0 退化为确定性预测，误差小但多样性丢失；T 大于 1 噪声放大影响规划质量。rollout 常用 T = 0.8 至 1.0，训练最后一层也可施加标签平滑（label smoothing）抑制过自信。

3. 码本健康度监控

码本坍缩是最常见的失效：少数码字吸收全部样本，其余成为死码，有效表达力骤降。困惑度量化码本使用率：

perplexity = exp( − Σk pk log pk ) pk 为第 k 个码字的使用频率；接近 1 即坍缩，接近码本容量即均衡

健康训练中，早期困惑度快速上升，随后稳定在码本容量的 20%–60%。若长期低于 10%，需要采取死码重启：把使用率最低的码字重新初始化为近期样本的编码向量。单码本表达力有限时采用多码本方案：每个时间步用 2–4 个码字表示（例如空间网格分块后各自量化），转移核分别预测各位置码字，表达力随码字数近似指数增长。

4. 与连续预测的对照

维度连续潜状态 + MSE离散码字 + 交叉熵
多模态未来均值塌陷，分布在两峰之间多峰分布显式表达，采样分支清晰
训练信号回归梯度，尺度敏感分类梯度，尺度无关
推理成本单步前向单步前向 + 采样
规划接口连续优化支持树搜索与取顶枚举
主要代价均值偏差量化误差与码本维护

实现思路与设计

流水线为：分词器预训练 → 冻结分词器 → 转移核分类训练 → 温度采样 rollout。分词器与转移核分阶段训练，避免量化目标与预测目标互相干扰。

  1. 分词器预训练：编码观测到 ze，码本 1024 个、维度 32，解码器重建观测；训练目标是重建损失与承诺损失之和。
  2. 冻结与标注：为全部数据集标注码字索引序列，形成 (ct, at, ct+1) 三元组样本。
  3. 转移核训练：交叉熵配 0.05 标签平滑，批量 256，学习率 3e-4；同时预测未来 1 步与 3 步码字，多步目标提高长期一致性。
  4. rollout：温度 0.9、top-k = 50 截断后采样；每 4 步检查一次解码观测的合理性（预测误差监测）。
  5. 与第 027 章的差异：离散化对象从动作扩展为状态潜空间；与第 090 章的衔接在于掩码离散建模的生成式目标。

设计决策：为什么分词器要冻结后再训练转移核？

若联合训练，转移核的梯度会经码字索引（不可微）无法回传，只能更新编码器侧，两侧目标不一致导致码本漂移、标注失效。分阶段训练让码字含义稳定，转移核在固定符号系统上学习动力学。后续如需微调分词器，必须对整个数据集重新标注，成本高；因此分词器的训练质量决定整套离散方案的上限，值得单独投入。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：向量量化器（EMA 码本与直通估计）

class VectorQuantizer(nn.Module):
    """把连续潜向量映射到码本最近邻，梯度用直通估计穿过量化操作。"""
    def __init__(self, n_codes=1024, d_code=32, beta=0.25, decay=0.99):
        super().__init__()
        self.embed = nn.Embedding(n_codes, d_code)
        nn.init.uniform_(self.embed.weight, -1.0 / n_codes, 1.0 / n_codes)
        self.beta, self.decay, self.n_codes = beta, decay, n_codes
        # EMA 缓冲：码本统计量只增不减地缓慢跟踪编码分布
        self.register_buffer("ema_count", torch.ones(n_codes))
        self.register_buffer("ema_weight", self.embed.weight.detach().clone())

    def forward(self, z_e):
        # 距离展开：||z||^2 - 2 z·e + ||e||^2，避免构造 (B, K, d) 大张量
        dist = (z_e ** 2).sum(-1, keepdim=True) - 2 * z_e @ self.embed.weight.t() \
               + (self.embed.weight ** 2).sum(-1)
        idx = dist.argmin(dim=-1)                  # 最近邻检索，前向硬选择
        z_q = self.embed(idx)
        z_st = z_e + (z_q - z_e).detach()          # 直通：前向量化，反向恒等
        if self.training:
            onehot = F.one_hot(idx, self.n_codes).float()
            self.ema_count.mul_(self.decay).add_(onehot.sum(0), alpha=1 - self.decay)
            self.ema_weight.mul_(self.decay).add_(onehot.t() @ z_e, alpha=1 - self.decay)
        # 承诺损失：只把编码器输出拉向码字；码本由 EMA 更新，不走梯度
        commit = self.beta * F.mse_loss(z_e, z_q.detach())
        return z_st, idx, commit

解读：距离展开式利用矩阵乘法一次算出全部码字距离，复杂度从 O(BKd) 的内存密集变为 O(BK + BKd) 计算；argmin 的硬选择由直通估计获得梯度近似。onehot.t() @ z_e 是稀疏聚类的贪心形式：用批量内分配到该码的向量均值更新码字。承诺损失只保留单向约束，因为码本侧的更新由 EMA 承担，两者组合等价于完整 VQ 目标而不引入额外梯度路径。idx 即离散序列的标注来源。

片段 2：分类式转移核与交叉熵目标

class DiscreteTransition(nn.Module):
    """在码字空间上预测下一时刻分布：分类分布天然支持多模态未来。"""
    def __init__(self, quantizer, d_code=32, d_act=7, n_codes=1024):
        super().__init__()
        self.quantizer = quantizer
        # 输入为当前码字嵌入与动作向量，输出为 K 类 logits
        self.trunk = nn.Sequential(nn.Linear(d_code + d_act, 256), nn.GELU(),
                                   nn.Linear(256, n_codes))

    def forward(self, idx, act):
        cur = self.quantizer.embed.weight[idx]     # 当前码字向量 (B, d_code)
        return self.trunk(torch.cat([cur, act], dim=-1))

def transition_loss(logits, idx_next, smoothing=0.05):
    """交叉熵 + 标签平滑：防止模型把概率全部压到单一未来码字上。"""
    return F.cross_entropy(logits, idx_next, label_smoothing=smoothing)

解读：转移核输入只用当前码字嵌入与动作，不依赖解码后的像素，计算量与前向一致。分类输出维度等于码本容量，参数量集中在最后线性层（256 × 1024 约 26 万参数），相比自回归像素预测轻量得多。标签平滑让正确类的目标概率为 0.95，其余概率质量均匀分配，梯度不会因 logits 差距过大而爆炸，也为采样阶段的多样性保留余量。多步监督只需对 t+2、t+3 的码字分别挂同一 loss 求和，共享转移核的递归结构。

片段 3：温度采样与码本困惑度监控

def sample_next_code(logits, temperature=0.9, top_k=50):
    """rollout 采样：温度缩放 + top-k 截断，一步完成。"""
    scaled = logits / max(temperature, 1e-6)
    # top-k 截断过滤低概率尾部，防止偶发噪声码污染想象轨迹
    kth = torch.topk(scaled, top_k, dim=-1).values[:, -1:]
    scaled = scaled.masked_fill(scaled < kth, float("-inf"))
    probs = torch.softmax(scaled, dim=-1)
    return torch.multinomial(probs, num_samples=1).squeeze(-1)

def codebook_perplexity(ema_count):
    """有效码数量：接近 1 表示坍缩，接近 K 表示均衡。"""
    p = ema_count / ema_count.sum()
    return torch.exp(-(p * (p + 1e-10).log()).sum())

解读：top-k 保留 logits 排序最高的 k 个位置，温度缩放是保序变换，先缩放后截断与先截断后缩放得到同一集合、结果等价；masked_fill 把尾部 logits 置负无穷，softmax 后概率严格为零，避免采样到尾部噪声码。multinomial 的采样只需一次前向，这是离散方案相对扩散采样的速度优势。困惑度函数直接消费量化器维护的 EMA 计数，训练循环中定期记录即可画出码本健康曲线；低于阈值触发死码重启时，把对应码字权重替换为当前批量内随机样本的编码向量，并把对应 EMA 计数复位。

常见坑

  • 码本坍缩：少数码字吸收全部样本。症状是困惑度长期低于码本容量的 10%，重建变模糊。修复：死码重启、自查承诺系数是否过大、必要时降低码本容量提高利用率。
  • 承诺系数失衡：β 过大时编码器输出被强行压向码字，重建质量下降；β 过小时码字频繁切换，标注序列抖动。修复：从 0.25 起步，观察重建损失与量化误差两条曲线是否同量级。
  • 采样温度失配：训练用软目标而 rollout 用低温贪心，想象轨迹退化为单条确定路径，规划丧失分支评估能力。症状是 rollout 多样性随步长快速衰减。修复：对齐训练平滑度与采样温度，监控不同种子的轨迹分歧度。
  • 分词器与转移核联合训练：试图端到端优化整个系统，码字含义漂移导致历史标注失效。症状是转移核损失反弹、困惑度波动。修复：冻结分词器，重新标注后再训练转移核；需要迭代时按周期批量重标。
  • 多步监督缺失：只训练单步转移，多步 rollout 误差快速累积。症状是单步分类精度超过 95% 而 5 步后解码图像失真。修复：加入 t+2、t+3 的多步交叉熵目标，或配合第 036 章的误差修正机制。

练习与思考

  1. 说明直通估计的梯度语义：为什么反向传播可以忽略 argmin 操作，用恒等映射近似？并给出该近似的失效场景。★★
    提示
    量化误差在大码本、低维流形上较小，恒等近似误差可控；码本稀疏、编码分布偏移大时近似失效，梯度方向与真实下降方向偏差增大。
  2. 把码本容量从 1024 降到 256，预测重建质量、困惑度与转移核精度的变化，并说明判断依据。★
    提示
    重建变差、困惑度占比提高；转移核分类任务变容易但表达上限下降，最终看解码轨迹的物理合理性。
  3. 设计死码重启流程：选择重启对象、初始化方式与重启频率，并说明如何验证码本恢复健康。★★
    提示
    按 EMA 计数选最低频码字，用近期样本编码初始化；重启用困惑度曲线与重建误差双指标验证。
  4. 推导 top-k 截断后 softmax 的概率归一性，说明温度缩放与 top-k 截断的先后顺序为何不影响保留集合，并给出温度必须施加在 softmax 之前的理由。★★
    提示
    top-k 选择最大的 k 个 logits；温度缩放是保序变换，两种顺序保留同一集合、结果等价。真正有顺序约束的是温度与 softmax：缩放必须在 softmax 之前施加。
  5. 设计对比实验：在含分岔未来的导航数据上比较连续 MSE、离散分类与扩散三种预测方案，指标覆盖多模态保真度与单步推理耗时。★★★
    提示
    多模态保真度可用预测分布与真实未来集合的匹配度（例如多轨迹覆盖指标）；耗时用单步延迟分位数报告。

小结

  • 连续均方误差把多模态未来压成均值，离散码字把预测变为分类分布，从根本上保留多峰结构。
  • 向量量化用最近邻检索加直通估计训练，码本经 EMA 缓动更新，承诺损失约束编码器输出。
  • 转移核用交叉熵加标签平滑训练，推理期温度与 top-k 控制想象轨迹的多样性与稳定性。
  • 困惑度是码本健康的核心监控指标，坍缩时用死码重启恢复；分词器冻结是标注稳定的前提。
