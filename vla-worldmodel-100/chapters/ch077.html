第四篇 · 训练机制与应用集成

第 077 章：VLA策略的模仿与强化结合

本章讲模仿学习（Imitation Learning）与强化学习（Reinforcement Learning, RL）的结合：示范与在线数据按比例混合、优势加权行为克隆、Q 过滤与双 Q 保守估计，把示教的稳定性与 RL 的性能上限接在一起。

  • 主题：策略学习 / 离线示范与在线强化
  • 关键公式：Lactor = −E[ exp(A/β) · log π(a|s) ]，回放混合比 0.5
  • 预计学时：55 分钟
  • 前置章节：第 076 章：联合训练中的多模态生成

学习目标

  • 理解模仿与强化两类信号的互补性：示范提供先验分布与稳定性，RL 提供超越示范的性能上限。
  • 掌握示范与在线数据的混合机制，理解混合比例对示范保持与在线提升的双向影响。
  • 掌握优势加权行为克隆（Advantage-Weighted Actor-Critic, AWAC）的推导直觉与权重截断的必要性。
  • 能实现混合回放采样、优势加权策略损失与 Q 过滤执行，理解双 Q 保守估计的抑制过估计作用。
  • 会诊断示范比例失衡、分布外自举发散与离线到在线切换失稳问题，能设计分阶段验证实验。

背景与动机

本节说明结合两类监督的核心矛盾：纯模仿在示范分布内稳定，但示范覆盖不到的状态上错误会复合，性能上限受演示质量约束；纯在线强化探索成本高，冷启动阶段动作随机，在真实硬件上不具备可行性。结合方案提供一条渐进路径：先用示范数据把策略拉到可用水平，再让在线学习在示范邻域内改进。实现上的核心问题是“不遗忘、不越界”：不遗忘指在线更新不得侵蚀示范分布上的能力，不越界指策略探索不得离开价值估计可靠的区域。本章的三种技术（混合回放、优势加权、Q 过滤）分别对应这两个约束的不同侧面。

核心原理

1. 混合回放：数据层的结合

示范数据与在线数据共存于回放缓冲区，按固定比例混合采样。比例的控制作用直接：示范占比过高时在线数据被稀释，RL 的改进被平均掉；占比过低时策略缓步漂离示范分布，早期错误被反复自举放大。常用起点是示范与在线各半，并按训练阶段微调：在线数据积累不足时示范占比上调，在线覆盖充分后逐步下调到两成左右。混合发生在采样器内部，训练循环对数据来源无感知，超参数集中在一个位置。

2. 优势加权行为克隆：目标层的结合

AWAC 把 RL 的改进写进模仿目标：对动作做优势加权，优势为正的样本权重放大，负的样本权重压缩：

Lactor = −E[ w(s, a) · log πθ(a | s) ]，w = exp( A(s, a) / β )，A = Q − V β 为温度：β 越大权重越平坦；w 需上截断以控制方差（常用上限 10）

该目标的直觉是“在示范动作中标注分数，好动作多学、坏动作少学”。它与策略梯度相比更稳：动作来自数据，避免了在线采样的高方差；与纯行为克隆相比有改进方向：权重的排序来自价值估计。代价是改进上限受数据支撑限制，权重只重排已有动作，无法创造分布外的新行为。探索新行为仍需在线的价值驱动更新或 Q 过滤执行。

3. 数值算例：优势权重的分布集中度

取一个批次内三个样本的优势值为 [2, 0, −2]，截断上限 10。温度 β = 0.5 时原始权重为 exp(4) ≈ 54.6、exp(0) = 1、exp(−4) ≈ 0.018；截断把首项压到 10，归一化权重约为 0.91、0.09、0.002，有效样本数（权重平方和倒数）约为 1.2。β = 2.0 时权重为 2.72、1、0.37，归一化后约 0.67、0.24、0.09，有效样本数约 2.0。

wi = min(10, exp(Ai/β))，有效样本数 Neff = 1 / Σi pi2 p 为归一化权重；Neff 越低表示批次梯度越接近少数高分样本

数值结果给出两条调参依据：（1）β 从 0.5 升到 2.0 让有效样本数从 1.2 升到 2.0，批次梯度从“少数样本主导”回到“多样本平均”，β 的选择以有效样本数标定，损失曲线只反映似然拟合、不反映权重集中度；（2）截断上限在 β 小时实际生效（54.6 被压到 10），它保护的正是有效样本数不因单个极端优势样本塌缩，上限与 β 应联合扫描。

4. Q 过滤：执行层的结合

Q 过滤在执行时比较动作价值：RL 策略给出的动作若价值低于参考动作（示范策略或安全策略），则回退参考动作。执行层的过滤把“越界”风险挡在最后一道关口。过滤阈值应含余量：Q 估计误差与策略切换成本都要求行动作“明显占优”才被采纳，margin 按价值估计的置信区间确定。与优势加权的分工明确：加权在训练期塑形分布，过滤在推理期兜底。四个结合层面的定位对照如下：

结合层机制主要收益主要风险诊断指标
数据层混合回放按比例采样保持示范分布的重力比例失衡，在线改进被稀释或过早漂离实际配比与动作分布统计距离
目标层优势指数加权模仿用价值排序重排已有动作权重集中导致批次方差大权重有效样本数
执行层Q 过滤加余量越界动作被挡在执行前滤网过松失效或过紧阻碍改进采纳率
过渡层保守惩罚与学习率渐退离线到在线切换平滑放松过快造成价值表突变切换期前若干回合成功率

四层可同时启用，各自的诊断指标独立监控。经验上的优先级：先修数据层的配比，再调目标层的温度与截断，执行层与过渡层放在最后，因为前两层的问题会伪装成后两层的故障。任何一层的指标异常时，先检查上游层的假设是否仍然成立。

5. 双 Q 与离线到在线的过渡

价值侧的稳定是全流程基础。双 Q 学习维护两套 Q 估计，取较小值构造目标，抑制单套估计的过估计；离线阶段可在目标上加入对分布外动作的惩罚（保守估计），在线阶段衰减惩罚并提高学习率。离线到在线的切换是风险点：保守估计放松后价值表面突变，策略可能跳向未经检验的区域。过渡策略是渐进放松：惩罚系数与学习率在过去若干步内插值上升，同时监控在线回合的前若干次成功率，异常即回退参数。

实现思路与设计

本节给出训练流程：阶段一用示范数据做行为克隆预训练；阶段二引入混合回放与优势加权目标，双 Q 带保守惩罚；阶段三在线数据稳定增长后衰减保守惩罚、提高学习率，Q 过滤负责执行兜底；世界模型生成的想象数据作为在线数据的补充，占比不超过两成。与第 076 章的差异：第 076 章改造生成模型，本章组织两类监督信号的训练流程与数据配比。

设计决策：为什么 Q 过滤参考值用双 Q 下界

过滤比较的是“行动作好于参考”这一判断，判断的可靠性取决于估计误差方向。取双 Q 的较小值使两个判断都偏保守：行动作按下界评估，参考动作同样按下界评估，误采纳的概率被压低。在安全边际优先的场景里，一致地低估比偶尔高估更可取，过滤逻辑与训练逻辑使用同一套保守口径。

阶段推进与配比调度的判据

  • 阶段一的出口判据。行为克隆预训练持续到示范集验证成功率进入平台期，且动作分布与示范数据的统计距离低于阈值；未达标的先修数据质量，不进入混合阶段。
  • 阶段二的配比调度。在线数据总量达到示范数据的四分之一后开始下调示范比例，每次下调 0.1，观察两个训练周期；在线成功率下滑即回退一档。同理上升方向用于在线数据不足时的补偿。
  • 保守惩罚的放松曲线。惩罚系数与学习率沿同一时间表插值，周期覆盖至少数百个更新步；每个插值点后检查切换期成功率与 Q 值分布，Q 值分布整体抬升超过一个标准差即暂停放松。
  • 想象数据的接入纪律。想象样本只补充在线桶且占比不超过两成，来源标注随样本存储；想象与真实样本的价值目标分开统计，偏差超过阈值时先缩减想象占比。
  • 过滤参考策略的版本管理。参考策略每经过固定评估周期更新一次，更新前用保守口径对比新旧参考在新数据上的成功率，退化则跳过该次更新。

关键代码与解读

以下片段以离线强化与示范混合训练的公开实现为参照，接口随版本演进。三个片段分别覆盖混合回放、优势加权损失与 Q 过滤。

片段 1：示范与在线数据的混合采样

import torch

class MixedReplay:
    """按固定比例混合示范与在线样本的采样器。"""
    def __init__(self, demo_buffer, online_buffer, demo_ratio=0.5):
        self.demo = demo_buffer
        self.online = online_buffer
        self.demo_ratio = demo_ratio

    def sample(self, batch_size=256):
        n_demo = int(batch_size * self.demo_ratio)
        d = self.demo.sample(n_demo)
        o = self.online.sample(batch_size - n_demo)
        # 在采样器层合并：训练循环对数据来源无感知
        return {k: torch.cat([d[k], o[k]], dim=0) for k in d}

解读：（1）比例调整只改一个参数，便于按训练阶段调度。（2）两个缓冲区的样本结构必须对齐（字段同名同形），否则拼接处出现缺失键。（3）在线样本不足时自动回填示范样本是实用变体，注意记录实际配比用于分析。

片段 2：优势加权行为克隆

import torch

def awac_actor_loss(policy, batch, critic, beta=0.5, clip_w=10.0):
    """优势加权负对数似然：放大正优势动作的权重。"""
    with torch.no_grad():
        # 双 Q 取下界：保守价值用于权重，避免过估计样本被放大
        q = critic.q_min(batch["obs"], batch["action"])
        v = critic.value(batch["obs"])
        adv = q - v
        w = torch.exp(adv / beta).clamp(max=clip_w)      # 截断控制方差
    logp = policy.log_prob(batch["obs"], batch["action"])
    # 加权负似然：好动作多学、坏动作少学
    return -(w * logp).mean()

解读：（1）权重计算在 no_grad 下完成：价值网络通过单独的价值损失更新，不从策略损失回传。（2）β 过大时权重接近 1，目标退化为行为克隆，可按权重分布的有效样本数监控。（3）截断上限保护批次统计：个别高分样本不会独占梯度。

片段 3：Q 过滤执行

@torch.no_grad()
def q_filtered_action(policy, reference, critic, obs, margin=0.05):
    """只采纳明显占优的 RL 动作，否则回退参考策略。"""
    a_rl = policy.act(obs)
    a_ref = reference.act(obs)                          # 示范或安全策略
    # 两侧都按下界评估：误采纳概率被压低
    q_rl = critic.q_min(obs, a_rl)
    q_ref = critic.q_min(obs, a_ref)
    # 仅在“价值高出一个余量”时采纳行动作
    take = (q_rl > q_ref + margin).float().unsqueeze(-1)
    return take * a_rl + (1.0 - take) * a_ref

解读：（1）输出的动作来源可能逐样本不同，执行层需要按动作块整体选择，避免批次内混源造成风格抖动。（2）margin 与价值估计置信区间挂钩，估计噪声大时上调。（3）采纳率是重要监控：长期接近零说明策略改进无法通过过滤，接近一说明过滤形同虚设。

常见坑

  • 示范比例失衡：比例过低时策略快速漂离演示分布，早期成功率先降后升。修复：维持下限比例，监控动作分布与示范数据的统计距离。
  • 分布外自举发散：Q 目标使用策略自产但数据未覆盖的动作，价值被推高。修复：双 Q 取下界，离线阶段加保守惩罚，限制目标动作的来源数据支撑。
  • 优势尺度不稳：优势未归一化时 β 失去可比性，权重在批次间剧烈波动。修复：优势按批归一化，β 按归一化后的尺度设定。
  • 离线到在线切换失稳：保守惩罚一次撤除造成价值表突变。修复：惩罚与学习率渐进插值，观察期失败即回退。
  • Q 过滤参考策略太弱：参考动作价值低，滤网不起作用。修复：参考策略选保守但可靠的版本并定期更新，margin 按实测误采纳率校准。

练习与思考

  1. 分析题：纯模仿与纯在线的失败模式各是什么？给出一个混合方案在冷启动、稳定期与收敛期三个阶段的示范占比建议，并说明依据。★★
    提示
    纯模仿受上限约束、分布外错误复合；纯在线冷启动昂贵且不安全。占比从高（0.7 以上）逐步降到 0.2，依据是在线数据覆盖度与成功率的稳定性。
  2. 把片段 2 的 β 从 0.5 改为 5.0，预测权重分布、策略改进速度与演示保持能力的变化。★
    提示
    β 增大后权重接近均匀，目标退化为行为克隆，改进停滞但演示保持好；β 过小时权重被少数高分样本主导，方差大。
  3. 推导题：从带 KL 约束的策略改进目标出发，说明 AWAC 的指数权重是拉格朗日解的近似形式。★★
    提示
    最大化 E[Q] 减去 (1/β)·KL(π||π_demo) 的闭式解为 π ∝ π_demo · exp(Q/β)，取对数似然目标并用优势替代 Q 即得权重形式。
  4. 实验设计：比较无过滤、固定 margin 过滤与自适应 margin 过滤三种执行方式，报告采纳率、在线回合成功率与回退次数三项指标。★★
    提示
    固定 margin 在价值噪声大的阶段误采纳偏多；自适应 margin 按置信区间放大，采纳率更合理；报告须同时给成功与安全两类结果。
  5. 设计题：为“在线数据增长缓慢”的部署场景设计训练协议：想象数据占比、示范回退条件、过滤参考的更新节奏，并说明怎样防止各来源互相稀释。★★★
    提示
    想象占比上限两成并标注来源；示范回退按成功率分位触发；过滤参考按周更新；三类数据分桶监控统计距离；稀释问题在桶级指标上暴露，全局损失看不出。

小结

  • 模仿与强化互补：示范给先验与稳定，RL 给上限；结合纪律是不遗忘、不越界。
  • 混合回放把结合放在数据层，示范占比从高位随在线覆盖度逐步下调。
  • AWAC 用优势指数权重重塑模仿目标，权重截断控制方差；改进受数据支撑上限约束。
  • Q 过滤在执行层兜底，双 Q 下界与余量共同压低误采纳；离线到在线切换用渐进放松实现。
