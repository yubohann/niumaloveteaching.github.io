第 075 章：世界模型的隐空间规划

本章讲世界模型的隐空间规划（Latent Space Planning）：在隐状态空间展开候选轨迹并用价值函数评估，比较采样与梯度两类规划器，讨论规划质量的评估与规划失败的恢复切换。

  • 主题：规划 / 隐空间搜索与评估
  • 关键公式：maxa1:H E[ V(zH) ]，zk+1 = fθ(zk, ak)
  • 预计学时：55 分钟
  • 前置章节：第 074 章：VLA策略的视觉语言预训练

学习目标

  • 理解隐空间规划的基本设定：在低维隐状态上展开轨迹，用价值函数评估候选，省去逐帧重建。
  • 掌握采样规划与梯度规划两类方法的机制、适用条件与失效模式，能解释可微性与局部最优的取舍。
  • 理解价值函数误差对规划排序的影响，掌握目标条件价值的拼接用法与校准思路。
  • 能实现隐空间 CEM 规划、梯度规划与规划质量评估，掌握规划与策略的切换协议。
  • 会诊断潜空间距离失真、价值偏差主导与想象分布偏移问题，能设计规划器的对照实验。

背景与动机

本节说明隐空间规划针对的评估瓶颈：在像素空间展开搜索需要重建每一帧并渲染比较，代价高昂且评估噪声大；在隐空间展开搜索直接在与动力学同构的表示上进行，评估由价值函数给出。隐空间规划把两个问题接在一起：世界模型保证“展开的可行性”，价值函数保证“选择的最优性”。相比第 072 章的滚动时域控制，本章聚焦规划器本身：搜索形式、评估方式与失败处理。

核心原理

1. 问题设定：在隐空间搜索什么

给定当前隐状态 z0 与目标条件 g，规划求解动作序列使末端价值最大：

maxa1:H E[ V(zH, g) ]，zk+1 = fθ(zk, ak) H 为规划步长；V 为目标条件价值函数；搜索空间是动作序列空间或潜在子目标空间

两条搜索路线：动作序列空间直接搜动作；子目标空间先搜隐向量中间目标，低层策略负责到达。子目标空间压缩了搜索深度但引入“隐距离可达性”问题：隐空间的线性插值未必对应物理可行的路径。选择依据是低层策略的可靠性与隐空间的平滑性。

2. 采样规划与梯度规划

采样规划沿用 CEM 框架，在隐空间直接评估价值，省去重建误差；梯度规划利用世界模型的可微性，对动作序列直接反向传播最大化末端价值。两者权衡明确：梯度规划收敛快，但易落局部最优且要求动力学全程可微；采样规划无梯度假设、可并行，开销随维度增长。组合方案是采样初始化加梯度精修：CEM 给出良好初值，梯度步在邻域内提升精度，两类失效模式被彼此的多样性覆盖。三类规划器的工程特性对照如下：

维度采样规划（CEM）梯度规划混合（采样初始化加梯度精修）
可微性要求无动力学全程可微，接触需软化无硬要求，梯度段需可微
单轮开销候选数 × 视野次前向视野次前向加反向，步数轮前段采样加后段梯度
并行性高，候选批量展开中，序列展开天然串行较高
局部最优风险低，多样本覆盖高，依赖初值低
收敛精度受候选数限制收敛后精度高高
典型失效高维搜索覆盖不足梯度断裂与次优盆地两段预算分配失衡

选择依据：维度低或动力学含硬切换时用采样规划；动力学生成器平滑可微且需要高精度时用梯度规划；多数操作场景用混合方案，采样占比取总预算的三分之二，梯度精修占三分之一，这个比例在轨迹精度与鲁棒性之间折中。预算比例比单步算法选择更影响最终表现，调整顺序应先配比后算法。

3. 评估函数：价值误差如何破坏排序

规划质量的上限由评估函数决定：候选排序错误意味着正确轨迹被丢掉。设价值估计误差为 ε，两条候选的真实价值差为 Δ，当 ε 与 Δ 同量级时排序随机化。缓解手段有三：多步回报与终端价值混合，误差被平均；集成价值头按分歧降权；目标条件价值用对比式训练直接优化排序。规划器与价值函数必须配套评估：报告候选集内的排序相关系数，比报告价值回归误差更能预测规划表现。

4. 数值算例：价值误差与排序概率

取两条候选轨迹，真实价值差 Δ = 0.1；价值估计误差独立同分布，标准差 ε = 0.15。误差差值的标准差为 √2 ε ≈ 0.212，排序正确的概率近似为正态分布函数 Φ(Δ / (√2 ε)) = Φ(0.471) ≈ 0.68，即约三成概率把更差轨迹排到前面。把 ε 降到 0.05（集成加多步平均），Φ(0.1 / 0.0707) = Φ(1.414) ≈ 0.92；若再把候选质量差距拉开到 Δ = 0.3，Φ(4.24) 趋近 1.0。

P(排序正确) ≈ Φ( Δ / (√2 ε) ) Φ 为标准正态累积分布函数；Δ 为候选真实价值差，ε 为单点价值估计误差标准差

数值结果给出两条规划设计结论：（1）误差 ε 减半使排序正确率从 68% 提升到 92%，误差收缩的收益非线性，集成价值头的成本通常比增加候选数划算；（2）拉开候选间的真实价值差（改进候选生成或加大搜索幅度）收益更快，Δ 从 0.1 升到 0.3 时同量级误差下排序几乎不再犯错，这就是“CEM 初始化加梯度精修”把好候选留在精英集的理论依据。

5. 规划失败与恢复

规划失败的表现是价值预估低、候选分歧大或动作越界。恢复（Recovery）机制在失败时切换到策略直出：策略在训练分布内至少能给出可行动作，规划只在其上增益。训练恢复行为需要对应数据：演示中加入从异常状态回归正常流程的片段，或由规划失败触发接管并存入回放。恢复课程的关键是覆盖失败状态分布：只训练正常轨迹的策略在接管时面临分布外输入，成功率下降。切换条件必须可观测：价值分位、候选方差与动作合法率是三个简单判据。

实现思路与设计

本节给出规划器配置：主规划器为隐空间 CEM（候选 128、迭代 3 轮、视野 8）；价值头采用目标条件训练并配双头集成；低层执行用策略或 MPC 跟踪首段计划；失败判据为价值分位低于训练分布 10 分位或候选标准差超阈值，触发策略接管。与第 072 章的差异：第 072 章优化控制回路结构，本章聚焦规划器与评估函数本身的匹配设计。

设计决策：为什么恢复动作保留规划形状

策略接管时若直接输出与规划风格差异极大的动作，执行器面临控制模式突变。保留规划形状指接管动作仍按动作块形式输出，只把来源从规划器换成策略，幅度与频率保持连续。切换的平滑性属于工程正确性：规划质量再高，切换瞬间的抖动也会损害任务执行，恢复机制必须把动作连续性作为约束条件。

价值头与恢复数据的管理要点

  • 集成价值头的独立初始化。双头从不同随机种子初始化并各自采样子集训练，分歧才是误差的有效代理；同一初始化与同一数据训练出的双头分歧接近零，误报率上升。
  • 目标条件的拼接方式。目标嵌入与隐状态拼接后进入价值头，或作为注意力查询检索隐状态；后者在目标维度较高时更稳定，前者实现简单。两种方式的目标嵌入都应经过归一化，避免目标尺度远大于隐状态尺度。
  • 接管轨迹的标注与配比。接管样本记录触发原因（价值分位、分歧、越界）与恢复结果，训练时按原因分层采样，防止某类失败样本主导。
  • 防止接管依赖。统计接管率随训练的变化，接管率长期高于设定阈值说明规划器与价值头没有从接管数据中改进，需要检查接管样本是否真正回流了价值头训练。
  • 评估协议。规划质量的离线评估报告三项：规划成功率、失败判据的误报率与候选排序相关系数；在线评估报告任务成功率与接管率。两组指标趋势相反时以在线为准。

关键代码与解读

以下片段以隐空间规划与基于价值的搜索的公开实现为参照，接口随版本演进。三个片段分别覆盖采样规划、梯度规划与切换协议。

片段 1：隐空间 CEM 规划

import torch

def latent_cem_plan(world_model, value_fn, z0, goal=None,
                    n=128, elite=8, iters=3, H=8, a_dim=7):
    """在动作序列空间采样，价值头评估末端隐状态。"""
    mu = torch.zeros(H, a_dim, device=z0.device)
    sigma = torch.ones(H, a_dim, device=z0.device) * 0.4
    for _ in range(iters):
        cand = mu + sigma * torch.randn(n, H, a_dim, device=z0.device)
        z = z0.expand(n, -1).clone()
        for k in range(H):
            z = world_model.step(z, cand[:, k])       # 批量并行展开
        # 目标条件价值：拼接目标嵌入由价值头内部处理
        score = value_fn(z, goal) if goal is not None else value_fn(z)
        mu = cand[score.topk(elite).indices].mean(dim=0)
        sigma = cand[score.topk(elite).indices].std(dim=0).clamp_min(0.05)
    return mu

解读：（1）评估发生在隐空间：不重建像素，单次展开的开销只包含世界模型前向与价值头前向。（2）topk 后重复取候选两次（均值与标准差），实现上可缓存索引避免重复计算。（3）动作维度较高时，标准差按维度学习：方向性强的维度自然收缩更快。

片段 2：梯度规划器

def gradient_plan(world_model, value_fn, z0, H=8, steps=30, lr=0.05):
    """对动作序列直接反向传播：要求动力学全程可微。"""
    acts = torch.zeros(H, 8, requires_grad=True)      # 8 维动作示意：含夹爪
    opt = torch.optim.Adam([acts], lr=lr)
    for _ in range(steps):
        z = z0
        for k in range(H):
            z = world_model.step(z, acts[k])          # 路径可微，梯度可穿透
        loss = -value_fn(z).mean()                    # 最大化末端价值
        opt.zero_grad()
        loss.backward()
        opt.step()
        with torch.no_grad():
            # 投影回合法动作范围：梯度步可能越界
            acts.clamp_(-1.0, 1.0)
    return acts.detach()

解读：（1）可微性是前提：接触与碰撞若用硬开关实现，梯度路径断裂，需换成软约束或改用采样规划。（2）投影在每一步结束后执行，保证中间迭代不评估非法动作。（3）返回值 detach：规划结果进入执行队列，不携带计算图。

片段 3：规划评估与恢复切换

@torch.no_grad()
def plan_or_recover(world_model, value_fn_pair, policy, z0,
                    goal=None, value_floor=None):
    """规划与恢复切换：价值低于标定下限或集成分歧过大时退回策略。"""
    plan = latent_cem_plan(world_model, value_fn_pair[0], z0, goal=goal)
    z = z0
    for k in range(plan.shape[0]):
        z = world_model.step(z, plan[k])
    # 双头集成：均值作评分，分歧作不确定性
    vals = torch.stack([vf(z, goal) for vf in value_fn_pair], dim=0)
    score, disagreement = vals.mean(0), vals.std(0)
    # 价值下限在训练期用规划成功样本价值分布的低分位标定，运行期复用同一口径
    low = value_floor is not None and float(score) < value_floor
    if low or float(disagreement) > 0.5:
        return policy(z0), "recover"      # 策略直出，保持动作块形状
    return plan[0], "plan"

解读：（1）失败判据组合两类信号：绝对水平（价值分位）与相对可靠性（集成分歧）。（2）分位阈值在训练期用规划成功样本的价值分布标定，运行期复用同一口径。（3）接管返回策略动作块，与规划输出同形，执行层无须区分来源。

常见坑

  • 潜空间距离失真：隐空间相邻的两个状态物理上可能相距很远，子目标插值生成的路径不可行。修复：可达性用低层策略成功率验证，插值失败时改用动力学展开搜索。
  • 价值误差主导排序：候选间真实价值差小于价值估计误差，规划选择随机化。修复：多步回报混合评估、集成降权与排序相关系数监控三件套。
  • 梯度规划陷入局部最优：非凸价值地形上从零初始化收敛到次优盆地。修复：CEM 初始化加梯度精修，或多起点并行优化取最优。
  • 想象分布偏移：规划轨迹落在训练分布外，模型预测失准而价值偏高。修复：对隐空间位置做密度估计，偏离分布的轨迹价值打折。
  • 规划与策略风格冲突：规划产出的动作序列与低层执行策略不匹配，跟踪退化。修复：用策略数据微调规划器动作分布，或把规划输出经策略投影后再执行。

练习与思考

  1. 分析题：动作维度 7 与隐维 64 两种搜索空间，规划各自搜索的是什么、每轮评估候选数如何计算、哪种情况适合子目标空间。★★
    提示
    动作空间搜索 H × 7 维序列；子目标空间搜索子目标数 × 64 维向量，深度换宽度；低层策略可靠时子目标空间更省。
  2. 把片段 2 的优化步数从 30 增到 200，预测规划耗时与末端价值的变化，说明收益递减的机制。★
    提示
    耗时近似线性增长；价值在数十步后进入平台，继续优化只是拟合价值头的局部噪声，不会转化为真实任务回报。
  3. 推导题：设价值估计误差为 ε、候选真实价值差为 Δ，分析排序正确概率的下界，并给出降低该概率所需的条件与两种缓解手段。★★
    提示
    误差独立同分布时排序正确率随 Δ/ε 增大而趋近 1；当 Δ ≤ 2ε 时排序接近随机。缓解：加大 Δ（拉开候选质量）或减小 ε（集成与多步平均）。
  4. 实验设计：比较纯 CEM、纯梯度、采样初始化加梯度精修三种规划器，在相同评估预算下报告成功率、规划耗时与失败样本的价值排序相关系数。★★
    提示
    纯梯度最快但易陷入次优；纯 CEM 覆盖好开销大；混合方案在多数地形上兼顾两者，排序相关系数最能解释成功率差异。
  5. 设计题：为恢复接管设计训练数据协议：接管触发条件、接管轨迹如何入库、如何防止接管样本比例上升后策略变得过度保守。★★★
    提示
    触发条件可观测化（分位与分歧）；接管轨迹均入回放并标注来源；控制接管样本比例上限，监控策略动作熵以防过度保守。

小结

  • 隐空间规划在与动力学同构的表示上搜索，评估由价值函数承担，规划质量受评估函数上限约束。
  • 采样规划无梯度假设且可并行，梯度规划收敛快但依赖可微性；采样初始化加梯度精修是常用组合。
  • 价值排序误差是规划失败的第一来源，多步混合、集成分歧与排序相关系数监控构成评估侧的保险。
  • 恢复机制把规划失败切换为策略接管，切换判据须可观测，接管轨迹回流训练覆盖失败分布。
