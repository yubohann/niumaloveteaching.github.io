第 068 章：VLA策略的决策可解释性

本章讲 VLA 策略的决策可解释性（Decision Interpretability）：用动作梯度归因定位关键视觉区域，用注意力传播（Attention Rollout）聚合多层路由，用反事实遮挡与概念瓶颈把“策略看了哪里”推进到“为何这样动作”。

  • 主题：策略诊断 / 归因与解释方法
  • 关键公式：αk = (1/Z) Σi,j ∂y / ∂Ak,i,j，R = Πl(0.5 Al + 0.5 I)
  • 预计学时：50 分钟
  • 前置章节：第 067 章：联合训练中的对比学习

学习目标

  • 理解 VLA 策略为什么需要决策可解释性：动作归因、安全审查与数据改进都依赖可信的证据定位。
  • 掌握梯度类归因方法：显著性图（Saliency Map）与动作梯度加权类激活图（Grad-CAM）的推导与适用场景。
  • 掌握注意力传播的聚合规则，理解残差连接为什么需要单位阵补偿，以及注意力权重与因果贡献的区别。
  • 能实现反事实遮挡探测与概念瓶颈（Concept Bottleneck）接口，理解忠实性（Faithfulness）评估的含义。
  • 会诊断显著性噪声、动作块解释错位与概念标注泄漏问题，能设计解释稳定性实验。

背景与动机

本节说明可解释性针对的工程困境：策略失败时只知道动作错了。抓取失败可能是视觉定位偏移、语言理解错误或动作头外推异常，缺少证据就无法决定修复路径。可解释性提供两类证据：表示层证据回答“策略看了哪里”，决策层证据回答“改动哪里会改变动作”。两类证据服务不同场景：排查感知问题与安全审查。本章按从轻到重的顺序组织三类工具：梯度归因、注意力传播、反事实与概念接口，并始终强调同一件事：解释是诊断工具，因果结论需要受控扰动验证。

核心原理

1. 梯度归因：从显著性到动作分量

最直接的归因是对输入求梯度：显著性图取 |∂a/∂x|。逐像素梯度噪声大，梯度加权类激活图（Gradient-weighted Class Activation Mapping, Grad-CAM）改为对中间特征图归因：先求目标标量 y 对特征图 Ak 的梯度并按空间平均得到通道权重，再对通道加权求和：

αk = (1/Z) Σi,j ∂y / ∂Ak,i,j，L = ReLU(Σk αk Ak) y 取动作块某一维的输出，Z 为特征图空间尺寸，ReLU 只保留正向贡献通道

对 VLA 的关键改造是目标标量的选择：动作块是 8 到 16 步的向量序列，归因到“整个动作块”会把不同维度的证据混在一起。按动作分量分别归因（例如单独看第五步的前后位移分量），热图才与具体控制意图对应。多个分量的热图差异本身即诊断信息。

2. 数值算例：三类归因工具的开销核算

设输入为 224 × 224 图像，中间特征图为 14 × 14、256 通道，规划一次完整评估把单次前向记为 1 个计算单位。三类工具的开销：Grad-CAM 需要 1 次前向加 1 次反向，约 2 个单位，通道权重的空间平均共 256 × 196 = 50176 项，由一次反向全部给出；遮挡探测取 7 × 7 网格需要 49 次前向，即 49 个单位；注意力传播需要存下各层注意力矩阵，12 层、每层 197 × 197 ≈ 38809 个元素，逐层相乘合计约 12 × 1973 ≈ 9180 万次乘加，约为一次反向的量级。

开销比：遮挡（49） > Grad-CAM（2） ≈ 注意力传播（约 3） 口径为前述设定下的计算单位；网格加密到 14 × 14 时遮挡升到 196 个单位

数值结果给出工具链的排序依据：（1）Grad-CAM 与注意力传播属于“一次评估级”开销，可以对全部失败样本批量运行；遮挡探测是“数十次评估级”开销，适合对少量高价值样本做深度验证；（2）遮挡网格从 7 × 7 加密到 14 × 14，前向次数按平方增长到 196 次，分辨率提升两倍的同时开销放大四倍，实验设计需要按样本预算取舍。

3. 注意力传播：聚合多层路由

单层注意力矩阵只描述本层路由，不可直接解读。注意力传播（Attention Rollout）把各层路由矩阵逐层相乘，得到累计影响：

R = Πl (0.5 Al + 0.5 I)，Ãl = 0.5 Al + 0.5 I 先对每层注意力加单位阵 I 再归一化：补偿残差连接的直通路径，I 表示“信息原样传递”

残差结构允许信息跳过注意力层直达输出，加入 I 为直通路径分配固定比例的通路。注意力可视化有明确的解释边界：注意力权重衡量信息路由强度，因果贡献需要扰动实验单独确认；把注意力热区直接当作“决策依据”是常见的方法学错误。三类解释工具的证据性质对照如下：

工具证据类型开销量级空间分辨率可靠条件
梯度类归因局部敏感性，输入微小变化的影响一次评估级中，受特征图分辨率限制模型局部近似平滑，样本量大时平均
注意力传播信息路由强度，非因果一次评估级词元级只作假设来源，需扰动交叉验证
反事实遮挡区域级因果证据数十次评估级网格级，随网格加密提升填充方式受控，结论不细于网格
概念接口概念层的可读读数常驻结构，近零额外开销概念粒度概念标注独立于模型预测

证据强度按自上而下递增排序：梯度与注意力给出待验证的假设，遮挡与概念干预给出可进入诊断流程的证据。组合用法是先用低成本工具圈定候选区域，再对候选区域做遮挡验证，最后用概念接口解释“为什么这个区域重要”。工具组合的分工是假设生成与假设检验：低开销工具批量提出候选，高开销工具少量验证，顺序颠倒会浪费预算。

4. 反事实解释：改动什么会改变动作

反事实（Counterfactual）方法改变输入的可控因素，观察动作的变化幅度。遮挡探测用图像均值填充候选区域，动作变化幅度大的区域被判定为决策关键区域。系统性做法是最小充分改变：找到使动作方向翻转的最小修改。遮挡块同时改变纹理与边界，结论只能定位到区域级；细粒度结论需要可控渲染的合成数据。

5. 概念瓶颈与忠实性评估

概念瓶颈模型（Concept Bottleneck Model）在感知与动作之间插入一组可命名概念（物体位置、夹爪开合度、目标颜色距离），动作头只允许消费概念向量。该结构把解释升级为“概念读数”，审查者可直接检查概念值；代价是标注成本与表达力损失。评估解释质量有两个维度：忠实性（Faithfulness）检验解释高亮区域被移除后预测是否真的变化，稳定性（Stability）检验输入微小扰动下解释是否连续。通过忠实性与稳定性双重检验的解释，才具备进入诊断流程的资格。

实现思路与设计

本节给出诊断工具链：以验证集失败样本为输入，依次运行动作分量 Grad-CAM、注意力传播与遮挡探测，三类证据交叉比对；概念瓶颈作为可选的常驻结构，在策略主干末端插入概念层，训练目标为动作损失加概念一致性损失。工具链输出热图、路由矩阵与扰动曲线。与第 067 章的差异：第 067 章改变训练目标，本章不改变模型结构，只增加诊断通路。

设计决策：为什么解释工具不参与训练图

三类归因工具都依赖对已训练参数的求导或扰动，在验证样本上离线运行。挂进训练循环会拖慢训练，且归因方差会作为噪声反馈进优化。解释是诊断与审查环节的工具，输出进入人工分析与数据改进流程，训练管线保持单一目标。

工具链的运行协议

  • 输入样本的筛选。以验证集失败样本为主，按失败模式分组（抓取偏移、抓空、碰撞、超时），每组抽固定数量做解释；随机样本作为对照组，避免只解释失败造成的选择偏差。
  • 随机状态固定。解释运行固定模型随机状态与数据增强配置，同一输入两次运行的热图差异超过阈值时先排查随机源，再做多轮平均。
  • 交叉验证口径。Grad-CAM 与遮挡热图的高亮区域用交并比度量一致性；一致样本进入结论流程，分歧样本标注为“需要进一步分析”并升级到概念层检查。
  • 解释结果的归档。每次解释运行保存输入标识、工具配置、随机种子与输出热图，形成可追溯的诊断档案；数据改进决策引用具体档案编号。
  • 概念层的更新节奏。概念标注体系随任务变化扩充，但概念层重训练后需要重跑分位数校准，前期结论不直接沿用。

关键代码与解读

以下片段以梯度类激活图与注意力可视化的公开实现为参照，接口随版本演进。三个片段分别覆盖动作分量归因、注意力传播与反事实探测。

片段 1：动作分量的 Grad-CAM

import torch

def action_gradcam(model, image, lang, act_index=2, comp=0):
    """归因到动作块某一步的某一分量：热图回答“哪个区域驱动了该分量”。"""
    feats = model.encode_visual(image)             # 需要保留梯度的特征图
    feats.retain_grad()                            # 非叶张量默认不存梯度
    action = model.action_head(feats, lang)        # B x T x A 动作块
    score = action[:, act_index, comp].sum()       # 目标标量：某步的某分量
    model.zero_grad()
    score.backward()
    # 通道权重取全局平均梯度：该通道对该动作分量的敏感度
    w = feats.grad.mean(dim=(2, 3), keepdim=True)  # B x C x 1 x 1
    cam = (w * feats).sum(dim=1)                   # B x h x w 通道加权和
    # ReLU 只保留正向贡献：负通道视为抑制该动作的信号
    cam = torch.relu(cam)
    cam = cam / (cam.amax(dim=(1, 2), keepdim=True) + 1e-6)
    return cam.detach()

解读：（1）retain_grad 是必要步骤：中间张量默认不保留梯度，缺少它 grads 为空。（2）目标标量取分量求和，避免动作块其余维度稀释信号。（3）逐样本归一化使不同样本的热图可比，叠加到原图前再上采样到输入分辨率。

片段 2：注意力传播聚合多层路由

import torch

def attention_rollout(attentions, discard_ratio=0.9):
    """聚合多层注意力为累计路由矩阵，补偿残差直通路径。"""
    result = None
    for A in attentions:                  # 每层形状 B x heads x N x N
        A = A.mean(dim=1)                 # 多头平均：合成单头路由
        # 丢弃每行最低的比例：逐行取分位阈值，抑制低强度噪声路由
        k = max(1, int(A.shape[-1] * discard_ratio))
        thresh = A.kthvalue(k, dim=-1, keepdim=True).values
        A = torch.where(A < thresh, torch.zeros_like(A), A)
        I = torch.eye(A.shape[-1], device=A.device)
        A_hat = 0.5 * A + 0.5 * I         # 单位阵代表信息直通
        A_hat = A_hat / A_hat.sum(dim=-1, keepdim=True)
        result = A_hat if result is None else A_hat @ result
    return result                         # B x N x N 从输入到输出的累计影响

解读：（1）逐层右乘的语义是路由复合：输出对输入的依赖等于逐层传播矩阵的乘积。（2）丢弃阈值按行内分位确定，自适应不同样本的注意力分布。（3）0.5 的混合系数是经验起点，等价于假设直通与注意力各占一半通路，对系数不敏感时可保持固定值。

片段 3：反事实遮挡探测

import torch

@torch.no_grad()
def counterfactual_probe(model, image, lang, base_action, grid=7):
    """遮挡网格逐块测动作变化：变化大的区域对决策贡献强。"""
    H, W = image.shape[-2], image.shape[-1]
    ph, pw = H // grid, W // grid
    deltas = torch.zeros(grid, grid, device=image.device)
    fill = image.mean()                   # 均值填充：不引入新的视觉线索
    for gy in range(grid):
        for gx in range(grid):
            occluded = image.clone()
            occluded[:, :, gy * ph:(gy + 1) * ph, gx * pw:(gx + 1) * pw] = fill
            act = model.action_head(model.encode_visual(occluded), lang)
            # 变化幅度用 L2 范数：方向与幅度同时计入
            deltas[gy, gx] = (act - base_action).norm(dim=-1).mean()
    return deltas                         # grid x grid 贡献图

解读：（1）逐块克隆输入保证扰动独立，代价是 grid 平方次前向，7 × 7 网格共 49 次，可以接受。（2）均值填充的选择需要说明局限：它同时移除纹理与产生遮挡边界，结论定位在区域级。（3）贡献图与 Grad-CAM 热图交叉比对：两类证据一致时结论更可信，分歧处提示进一步分析。

常见坑

  • 把注意力热区当因果依据：注意力权重高只说明路由强，不保证该输入被实际使用。修复：任何注意力结论都用遮挡或替换实验交叉验证。
  • 显著性图噪声误读：逐像素梯度充满高频噪声，偶然亮点被当成证据。修复：改用中间层 Grad-CAM，或对多次采样的解释做平均。
  • 动作块解释错位：对整块动作归因，热图混合了多个时间步的意图。修复：按步与分量拆开归因，检查相邻步热图的连续性。
  • 概念标注泄漏：概念标签由模型预测生成后又用于监督，瓶颈层学到的是模型自身偏见。修复：概念标签独立来源，混合少量人工标注做校准。
  • 单次解释方差大：随机增强、dropout 与遮挡采样的随机性使两次运行的热图差异明显。修复：固定评估时的随机状态，并对解释图做多次平均。

练习与思考

  1. 计算题：224 × 224 输入、特征图 14 × 14，计算 Grad-CAM 通道权重的空间平均项数量；遮挡探测用 7 × 7 网格时需要多少次前向，说明两者开销量级差异的来源。★
    提示
    空间平均每通道 196 项，一次反向即可完成全部通道；遮挡需要 49 次完整前向，是归因方法中最重的方案。
  2. 把片段 2 的混合系数从 0.5 改为 0.9（更偏注意力），预测路由矩阵的集中度与浅层词元受关注程度的变化。★
    提示
    系数越大注意力路径权重越高，路由更集中尖锐；残差直通被压低后，深层输出对浅层词元的直接传递被低估。
  3. 推导题：说明注意力传播中逐层右乘为何对应信息复合，并解释单位阵项使乘积矩阵保持行和为 1 的作用。★★
    提示
    每层路由是行随机矩阵，乘积仍行随机；归一化保证累计影响守恒，单位阵防止残差路径被注意力锐化吞掉。
  4. 实验设计：对同一批失败样本比较 Grad-CAM 热图与遮挡贡献图，统计两者高亮区域的交并比（IoU）。★★
    提示
    一致样本多为感知端定位错误；分歧样本常见于语言条件主导的决策，视觉区域本身无强贡献，需要转向语言侧归因。
  5. 设计题：为概念瓶颈设计一套概念集合与验证协议：概念如何选取、如何避免与前缀语义重复、怎样用干预概念值的方式检验动作对概念的依赖。★★★
    提示
    概念取可测量、可操作、与动作单调相关的量（相对位置、距离、开合）；干预实验直接把某概念置为反值，观察动作方向变化，验证依赖关系真实存在。

小结

  • 决策可解释性提供表示层与决策层两类证据，分别回答“看了哪里”与“改动哪里会改变动作”。
  • Grad-CAM 按动作分量归因，通道权重来自全局平均梯度；动作块必须拆步检查，避免意图混合。
  • 注意力传播用逐层乘积聚合路由，单位阵补偿残差直通；注意力强度与因果贡献需要分开确认。
  • 反事实遮挡提供区域级因果证据，概念瓶颈把解释升级为可读的概念读数，两者都以忠实性与稳定性为评估标准。
