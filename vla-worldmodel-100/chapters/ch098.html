第 098 章：VLA策略的模型不确定性感知

把策略的"知道自己不知道"变成可计算的量：不确定性的分解、校准与风险敏感动作选择，以及何时应该弃权交给保守策略。

  • 主题：VLA 策略（Vision-Language-Action, VLA）/ 不确定性感知（uncertainty awareness）
  • 关键公式：总方差分解与 CVaR 风险目标
  • 预计学时：55 分钟
  • 前置章节：第 097 章

学习目标

  • 区分偶然不确定性（aleatoric）与认知不确定性（epistemic），理解两者在决策中的不同处理方式。
  • 掌握全方差公式（law of total variance），会从集成模型输出计算两类不确定性。
  • 掌握温度缩放校准与可靠性评估基本方法，理解校准漂移的成因与监控。
  • 掌握 CVaR 风险目标与动作块的风险聚合，会按风险敏感准则筛选候选动作。
  • 会设计弃权（abstention）机制与保守回退策略，平衡过度弃权与风险暴露。

背景与动机

策略输出的置信度与真实正确率经常脱节：模型在陌生场景中可以给出高置信的错误动作。不确定性感知让系统把"把握不足"显式量化，并在决策层使用：低风险时正常执行，风险升高时趋于保守，超过阈值时弃权交给保守策略或请求人工介入。

第 031 章估计了世界模型的不确定性并用作训练信号，第 095 章用残差监控故障。本章关注策略侧的完整链路：不确定性的来源分解、数值校准、动作选择中的风险使用。三者缺一不可：分解决定处理策略是否对症，校准决定阈值是否可靠，风险目标决定决策是否与业务容忍度匹配。这一步是从"能完成任务的策略"走向"可托付的策略"的关键。

核心原理

不确定性感知由三层构成：正确分解两类不确定性、把概率校准到可信、在决策中用风险准则评估候选动作的尾部损失。

1. 两类不确定性与总方差分解

偶然不确定性来自数据生成过程的固有随机（传感器噪声、环境随机性），增加数据也消除不了；认知不确定性来自模型知识不足（训练未覆盖的状态），增加覆盖可以消除。对集成模型（E 个成员，每个输出均值 μe 与方差 σe2），总方差按全方差公式（law of total variance）分解：

σtotal2 = 𝔼e[ σe2 ] + Vare[ μe ] 第一项为偶然不确定性（成员内部方差的平均），第二项为认知不确定性（成员均值之间的方差）

两项的决策含义不同：认知不确定高说明状态超出知识范围，正确响应是探索或弃权；偶然不确定高说明环境本身噪声大，正确响应是留出安全裕度、降低动作激进程度。把两类混在一起会导致错误决策：把传感器噪声当知识不足会频繁弃权，把分布外状态当噪声会带着过度自信继续执行。

2. 校准

深度网络的概率输出普遍过度自信，需要校准。温度缩放是最简单有效的手段：在验证集上拟合单一温度 T，推理时用 softmax(logits / T) 替换原概率。校准效果用期望校准误差（Expected Calibration Error, ECE）衡量：把预测按置信度分桶，比较每桶的平均置信度与实际准确率，加权求差。微调之后必须重新校准：分布变化与参数更新都会破坏原有校准；校准参数与模型版本一一对应保存。

3. 风险敏感选择

期望回报最大化的动作在尾部风险高的场景不可接受。条件风险价值（Conditional Value at Risk, CVaR）关注最差比例场景的平均回报：

CVaRα(R) = 𝔼[ R | R ≤ VaRα(R) ]，目标 = (1 − β)·𝔼[R] + β·CVaRα(R) α 为尾部比例（常取 0.05–0.1）；VaR 为 α 分位点；β 控制保守程度

CVaR 的计算用候选动作的回报样本排序近似：对每个候选动作块，取 S 个场景（来自集成成员或环境噪声重采样）的回报，升序排序后对最差 k = ⌈αS⌉ 个取平均。动作块的风险聚合要覆盖块内各步：逐步不确定性用累积方差公式传播，块级风险取"最差步的 CVaR"，步均值的 CVaR 会掩盖关键步的尾部风险。

4. 弃权与保守回退

弃权是把决策权交还给系统：当认知不确定性超过阈值且无候选动作满足风险约束时，切换到保守策略（低速、已验证技能、远离未覆盖区域），或停在安全位置等待。弃权的代价是效率损失，误弃与漏弃的代价不对称：漏弃可能导致事故，误弃只是任务延迟。阈值选择反映这种不对称：宁可多弃，不可漏弃，但要在验证数据上用"弃权率与故障率"两条曲线找拐点，避免过度弃权让系统不可用。

实现思路与设计

策略侧集成 5 个动作头，输出均值与方差；风险过滤在动作块候选上执行；校准参数随检查点保存。

  1. 集成结构：共享主干加 5 个独立动作头，训练用不同初始化与数据顺序；成员差异是认知不确定性估计的来源。
  2. 校准：每次微调结束后在留出集上拟合温度，验证 ECE 低于 0.05 才允许部署。
  3. 风险过滤：策略采样 C = 16 个候选动作块，每个候选在集成成员上评估回报，取 α = 0.1、β = 0.5 的组合目标打分，选最优。
  4. 弃权：认知不确定性超过验证集 99% 分位且最优候选的风险打分低于安全线时，切换保守策略。
  5. 与第 031 章的差异：不确定性从世界模型侧扩展到策略侧，新增校准流程与决策层的风险使用。

设计决策：为什么风险聚合要取最差步？

动作块的执行是逐帧的，任何一帧的失败都会破坏整个块的效果。若按步均值的 CVaR 打分，一个高风险的中间帧会被周围安全帧平均掉，候选排名失真。取最差步的风险值匹配"块内最薄弱环节决定成败"的执行语义。代价是打分对单帧噪声更敏感，可用滑动窗口平滑边际风险作为缓解。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：不确定性的两类分解

def uncertainty_decompose(means, log_vars):
    """总方差分解：成员内部方差为偶然，成员均值间方差为认知。"""
    # means: (E, B, D) 集成成员预测均值；log_vars: (E, B, D) 各自的 log 方差
    aleatoric = log_vars.exp().mean(dim=0)       # E[σ_e^2]，数据噪声贡献
    epistemic = means.var(dim=0)                 # Var[μ_e]，知识不足贡献
    total = aleatoric + epistemic                # 全方差公式：总方差 = 偶然 + 认知
    return aleatoric, epistemic, total

def chunk_risk(aleatoric, epistemic, alpha=0.1):
    """块级风险聚合：逐步风险取最差步，尾部比例按步执行。"""
    # 形状 (B, T, D) 的逐步不确定性：时间维取最大值的分位数
    ale = aleatoric.max(dim=1).values.mean(dim=-1)      # 偶然：最差步均值
    epi = epistemic.max(dim=1).values.mean(dim=-1)      # 认知：最差步均值
    return {"aleatoric": ale, "epistemic": epi}

解读：分解实现只需两行：内部方差取均值、成员均值取方差，与公式逐项对应。成员数 5 时 var(dim=0) 用无偏估计的小样本方差，数值噪声可接受。chunk_risk 在时间维取最大值再对动作维平均，体现"最差步决定块风险"的语义；若任务对某些动作维度更敏感，可在平均前对维度加权。分解结果分别用于不同决策：认知项驱动弃权判定，偶然项进入风险过滤的目标函数。

片段 2：CVaR 风险过滤

def cvar_filter(chunk_returns, alpha=0.1, beta=0.5):
    """对候选动作块按风险敏感目标打分：均值与 CVaR 的凸组合。"""
    # chunk_returns: (B, C, S) 候选数 C，场景样本 S（来自集成成员）
    S = chunk_returns.size(-1)
    k = max(1, math.ceil(S * alpha))             # 尾部场景个数，即 ⌈αS⌉
    sorted_r = chunk_returns.sort(dim=-1).values # 升序排列
    cvar = sorted_r[:, :, :k].mean(dim=-1)       # 最差 k 个场景的平均回报
    mean = chunk_returns.mean(dim=-1)            # 期望回报
    score = (1.0 - beta) * mean + beta * cvar    # 凸组合：beta 越大越保守
    return score.argmax(dim=-1)                  # 返回最优候选的索引

解读：场景样本 S 来自集成成员与动作头采样，样本量有限时 k 至少取 1，避免空尾部。排序与取均值是 CVaR 的样本估计，与分位数估计相比对小样本更稳健。凸组合保持目标对期望与尾部的连续权衡，beta = 0 退化为期望最大化、beta = 1 退化为纯 CVaR，取值由事故代价标定。函数只返回索引，动作取出与安全裁剪由执行层完成；全部候选与打分写入日志，用于事后分析决策偏好。

片段 3：温度校准

def fit_temperature(logits_val, labels_val):
    """温度缩放：验证集上拟合单一温度，用 LBFGS 优化负对数似然。"""
    log_T = torch.zeros(1, requires_grad=True)   # 参数化 log T，保证温度恒正
    opt = torch.optim.LBFGS([log_T], lr=0.1, max_iter=50)
    def closure():
        opt.zero_grad()
        # NLL：温度不改变排序，只改变概率的尖锐程度
        loss = F.cross_entropy(logits_val / log_T.exp(), labels_val)
        loss.backward()
        return loss
    opt.step(closure)
    return log_T.exp().item()                    # 校准后的温度 T*

def ece(logits, labels, n_bins=15):
    """期望校准误差：置信度分桶后与准确率的加权差。"""
    probs = F.softmax(logits, dim=-1)
    conf, pred = probs.max(dim=-1)
    acc = (pred == labels).float()
    edges = torch.linspace(0, 1, n_bins + 1, device=logits.device)
    e = torch.zeros((), device=logits.device)
    for i in range(n_bins):
        in_bin = (conf > edges[i]) & (conf <= edges[i + 1])
        if in_bin.any():
            gap = (acc[in_bin].mean() - conf[in_bin].mean()).abs()
            e = e + gap * in_bin.float().mean()  # 桶占比加权
    return e.item()

解读：温度缩放的优化目标与训练一致（负对数似然），但参数只有一个，几十次迭代即收敛；LBFGS 比一阶方法在低维参数上更快。log_T 参数化保证 T 恒正，避免无效解。ECE 的桶边界含左不含右，最后一桶覆盖到 1 需要单独处理边界样本；桶数 15 是常用折中，任务数据量小时减到 10。校准后必须重算 ECE 并记录版本，作为部署检查项之一；推理时温度与集成成员概率的聚合顺序要固定：先对每个成员校准再加权平均。

常见坑

  • 共模错误低估认知不确定性：集成成员共享训练数据，在同一分布外状态上同时犯错，成员间方差很小。症状是陌生场景下不确定性低。修复：成员用不同数据子集或增强视图训练，加入数据顺序扰动与超参扰动，配合残差监控互补。
  • 校准漂移：微调或环境变化后未重新校准，阈值失效。症状是弃权率忽然变化。修复：每次模型更新重跑校准，部署期监控 ECE 与弃权率曲线。
  • 过度弃权：阈值过于保守，系统频繁切到回退策略。症状是任务效率显著低于基线。修复：用弃权率与故障率的联合曲线找拐点，把阈值上移到故障率曲线的平台段。
  • 两类不确定性混用：把偶然噪声当作知识不足，静止的噪声场景触发弃权。修复：决策规则以认知项为主导判定弃权，偶然项进入风险裕度。
  • 风险口径与执行不一致：过滤用步均值 CVaR，执行按单帧安全约束，两者对高风险帧的判定不同。修复：统一为最差步口径，或让执行层消费过滤层的逐步风险曲线。

练习与思考

  1. 推导全方差公式的分解式，说明两项分别对应哪类不确定性、各用什么方式消除。★★
    提示
    对联合分布 p(θ)p(x|θ) 展开 Var[x]；内部期望方差对应偶然，均值方差对应认知；前者靠冗余观测平滑，后者靠数据覆盖消除。
  2. 把 CVaR 尾部比例 α 从 0.1 调到 0.3，预测动作保守程度与任务效率的变化。★
    提示
    尾部扩大后 CVaR 与均值接近，保守缓解；事故场景下的保护能力下降，用事故率验证。
  3. 设计校准评估流程：给出校准集划分、温度拟合、ECE 计算与部署门槛的完整步骤。★★
    提示
    校准集与评估集分离；拟合后先在评估集验 ECE，再按版本记录温度值；微调后重复全流程。
  4. 设计弃权阈值的选择实验：给出数据采集、曲线绘制与阈值确定方法，说明误弃与漏弃的不对称代价。★★
    提示
    扫描阈值画弃权率与故障率曲线；代价函数加权后取最优点，权重由事故严重度决定。
  5. 设计区分两类不确定性的对照实验：构造高噪声场景与分布外场景，验证分解指标能否各自响应。★★★
    提示
    高噪声场景看偶然项上升、认知项平稳；分布外场景看认知项上升；用两组数据交叉验证指标语义。

小结

  • 不确定性分偶然与认知两类，全方差公式从集成输出估计；两类对应不同决策响应。
  • 温度缩放在验证集拟合，校准参数随模型版本保存；ECE 作为部署门槛，微调后重新校准。
  • 风险敏感选择用 CVaR 与期望的凸组合打分候选动作块，块级风险取最差步口径。
  • 弃权阈值按"弃权率与故障率"联合曲线标定，认知项主导弃权判定，偶然项进入安全裕度。
