第一篇 · 基础框架与联合训练

第 008 章：基于世界模型的想象rollout增强VLA训练

本章把 006 章生成的想象轨迹写进策略训练：以置信度加权的监督项、真伪混合采样比例、可靠性过滤与防确认偏差的锚定机制，构成“生成到消费”的完整回路。

  • 主题：联合训练 / 想象数据增强
  • 关键公式：wk = γk · ck
  • 预计学时：60 分钟
  • 前置章节：第 007 章

学习目标

  • 理解想象 rollout 增强策略训练的三条路径：一致性监督、结果筛选、状态覆盖扩充。
  • 掌握置信度加权损失的构造：时域衰减、预测置信度、来源标记三要素的合成。
  • 掌握真伪混合采样的比例设计与调整原则，理解比例失控的失效模式。
  • 能实现可靠性过滤：动作量程检查、集成分歧过滤与人工抽查接口。
  • 能设计实验量化想象增强的净收益，并识别自我确认偏差的早期信号。

背景与动机

006 章解决“如何生成”，007 章解决“何时训谁”，本章解决最后一环：轨迹如何进入策略损失。想象动作是策略自身输出，直接叠加训练属于自蒸馏，易把误差固化为偏好；想象观测带模型误差，未筛选会污染监督。增强机制的本质是在“更多数据”与“更可信数据”之间建立加权与过滤。

本章同时承接 005 章的损失设施与 006 章的取舍原则：短视界轨迹、来源标记、不确定性门控在此全部派上用场。完成本章后，第一篇的联合训练闭环（预测、生成、排班、消费）全部就位，009 章转向梯度的微观分析。

边界：013 章管理真实经验的存取采样，本章管理生成数据的加权过滤，两者在采样器层对接；015 章关注如何生成更有信息量的动作，本章假设动作来源已给定。

核心原理

1. 三条增强路径

想象数据对策略训练的贡献分三个层次。一致性监督：对想象轨迹中策略给出的动作再次施加动作损失，抑制策略在自身分布上的漂移，相当于把“行为一致性”作为正则项；结果筛选：世界模型推演出的终点状态交给任务判定（成功分类器或代价函数），把结果信号回传给轨迹上的动作，形成粗粒度的偏好改进；状态覆盖扩充：想象轨迹访问真实数据未覆盖的状态，补充这些状态下的动作监督，提升访达区域的泛化。

三条路径共用同一批轨迹，但对应的损失项与权重不同：一致性路径用小权重全量参与，筛选路径只对高判别度的轨迹生效，覆盖路径按状态新颖度加权。实现上以“来源与置信度字段”统一承载这些差异（005 章的权重设施直接复用）。三条路径的定量对照见下表。

路径信号来源损失形式权重档主要风险
一致性监督策略在想象轨迹上的输出动作回归或流匹配损失真实权重的 0.2 倍，全量常开自我强化导致动作模式坍缩
结果筛选终点判定器或代价函数轨迹级偏好加权仅高判别度轨迹生效，随机跳批对判别器过拟合
状态覆盖扩充状态新颖度统计按新颖度加权的动作监督新颖度高分档加权低质量状态拉低泛化

1.1 结果筛选与策略梯度的联系

结果筛选的权重设计可以追到得分函数引理：设终点判别器给出轨迹回报 R(τ)，对期望回报求策略参数梯度得到 E[R(τ)·∇log π(a|s)]，估计量只依赖回报与动作对数概率。判别器不可微时，常用替代做法是把批次内轨迹按 R 排序，构造软权重 w(τ) = exp(R(τ)/T) / Σ exp(R(τ')/T) 后做加权回归。温度 T 控制筛选的软硬：T 趋近零时只保留最优轨迹，梯度方差大且样本利用率低；T 偏大时权重接近均匀，筛选信号被稀释。工程上按批次得分分布取 T，使有效样本数约占批次的两到三成。

2. 置信度加权损失

每条想象样本的监督权重由三个因子合成：

wk = γk · ck · mk k 为轨迹内步号；γk 为时域衰减，ck 为预测置信度，mk 为来源标记权重（真实数据为 1）

三个因子各自解决一类误差：时域衰减压制远端误差累积（006 章的视界结论在此落地）；置信度把世界模型不确定的样本降权，ck 需经校准后才能跨样本比较，直接使用原始不确定分数会因尺度不一而失效；来源标记保证真实与想象的监督强度可控，是防确认偏差的第一道闸门。

用一个八步轨迹把权重算到底：γ=0.9，置信度从步 0 的 0.90 递减到步 7 的 0.40，来源为想象（m=0.2），各步权重依次为 0.180、0.153、0.130、0.102、0.079、0.059、0.048、0.038，合计 0.789；同样长度、置信度恒为 1 的真实轨迹权重合计 5.695。等步数下一条想象轨迹的监督质量只相当于真实轨迹的 13.8%，这就是“以数量补强度”的量化含义：要补齐质量差距，想象样本数量需达到真实样本的约七倍，或者接受小权重下的慢速正则效果。另一个推论来自权重质心：把无限长衰减的权重 Σγk 归一化后，质心为 γ/(1-γ)，γ=0.9 时对应第 9 步；上式截断到 8 步时实际质心约在第 3 步。两种口径都表明确有效监督集中在前十步以内，视界截断取 10 到 15 步与衰减曲线匹配。

ck 的校准用可靠性分箱检查：把样本按预测置信度分箱，统计每箱内的实际正确率，期望校准误差（Expected Calibration Error, ECE）定义为各箱正确率与平均置信度之差的绝对值按样本数加权求和。一个三箱算例：置信度均值 0.60 的箱实际正确率 0.62（50 条），0.80 的箱实际 0.80（30 条），0.95 的箱实际 0.88（20 条），ECE = 0.5×0.02 + 0.3×0.00 + 0.2×0.07 = 0.024。校准良好时 ck 的数值接近真实正确率，权重才具有跨样本可比的语义。未校准的置信度只保留排序信息，直接进入加权公式会系统性高估高质量样本。

3. 真伪混合比例

训练批次由真实与想象两部分组成，想象占比记作 1-α：

batch = α · real + (1-α) · imagined ，α 起步取 0.8 α 为真实数据占比；随世界模型质量提升可缓降至 0.5，低于 0.5 需谨慎

α 的调整依据是世界模型的验证误差：预测质量高时想象数据可信度上升，α 可下调换取覆盖增益；质量未提升前保持高 α 锚定真实分布。α 的下界由确认偏差风险决定：想象占比超过一半后，策略逐渐向自身输出收敛，真实示教分布被边缘化，表现为验证集成功率缓慢下滑而训练损失持续下降。监控真实验证集是唯一可靠的早期信号。

把“想象自强化”写成递推式可以看清 α 的作用。设第 t 轮策略相对示教分布的偏离为 et，每轮想象数据把偏离按系数 β 自强化（0<β<1），真实数据每轮施加 δ 的纠偏，两项都被想象占比 (1-α) 触发，则 et+1 = (1-α)·β·et + (1-α)·δ，稳态偏离 e* = (1-α)·δ / (1-(1-α)·β)。代入 α=0.8、β=0.5、δ=0.1 得 e*≈0.022；把 α 降到 0.5 得 e*≈0.067，偏离扩大三倍。因子 (1-α) 同时缩小自强化与纠偏两项，分母决定累积放大倍数，这是 α 下限 0.5 的定量来源。

再加一层加权视角：名义想象批次占比 20% 并不等于 20% 的梯度质量。沿用上一节的权重数字，想象样本平均权重 0.099，真实样本平均权重 0.712，有效占比按 1×w̄im / (4×w̄re + 1×w̄im) 计算只有 3.4%。α=0.8、imag_w=0.2 的配置实际把想象数据的梯度贡献压到约三个百分点，评估强度时应按有效占比展开，名义占比会系统性高估。调整节奏同样有讲究：每 5000 步评估一次、单次变动不超过 0.05，并把调整对齐到 007 章的阶段切换点执行；比例突变落在阶段内部时，损失曲面同时经历数据分布与任务目标两次变化，曲线拐点无法归因，对齐切换点后归因问题自动消失。

4. 防确认偏差的两道锚

确认偏差指策略把自己的输出当成正确答案反复强化。两道锚定机制：数据锚，保持真实数据占比下限，且在想象批次中混入少量真实动作块作为对照；采样锚，想象动作的生成保留一定温度（006 章的 0.7 附近），避免策略用单一模式填满想象集。实验上可以用“想象集动作熵”与“真实验证成功率”两条曲线联合观察：熵下降且成功率不降属于收敛，熵下降且成功率下滑属于坍缩。监控规则可以写成联合条件：以最近 20 次真实验证为一窗，窗内平均成功率比历史最优低 3 个百分点，且想象集动作熵低于早期分布 30% 分位，同时满足才判定为坍缩早期信号，触发 α 上调与想象路径暂停；单独熵下降按收敛处理，避免误停。

5. 可靠性过滤

进入损失之前，想象样本经过三层过滤：动作量程检查（超出训练数据统计范围的样本直接剔除）、集成分歧过滤（多个世界模型副本的预测分歧超过阈值的样本降权，031 章展开）、人工抽查接口（按固定间隔抽样关键帧供复核，保留问题回溯能力）。过滤规则宁严勿宽：想象数据的边际价值随质量下降迅速衰减，而错误监督的伤害是持续累积的。

分位阈值的行为用一批十维置信度数值过一遍：批次置信度为 0.95、0.90、0.88、0.80、0.75、0.70、0.60、0.55、0.50、0.30，取 20% 分位（线性插值）得阈值 0.54，保留掩码滤掉 0.50 与 0.30 两条，剔除率 20%，与设定的分位一致。剔除率是过滤配置的校验指标：分位取 0.2 时长期剔除率应稳定在 20% 附近，若实际剔除率长期远低于设定值，说明置信度分布过度集中，阈值实际未起作用，需要改用在验证集上拟合的绝对阈值；若剔除率远高于设定值，误差集中在置信度尾部，应先复查世界模型本身的校准质量。过滤管线的计算成本也纳入预算：量程与分位检查是标量运算，开销可忽略；集成分歧需要 K 个模型副本前向，成本随副本数线性增长，当分歧过滤的剔除率低于 1% 时可把检查频率降到每四批一次，把算力留给主回路。

6. 适用边界与失效清单

想象增强的收益有明确边界，三条判据决定其开关与强度：其一，世界模型单步预测误差未进入平台期时，生成数据的监督价值被预测误差抵消，此时应暂停想象路径并先完成 007 章的预热，来源权重随质量回升再恢复；其二，真实占比 α 贴住下界 0.5 后，稳态偏离按第 3 节的递推式扩大到约 0.067，约为 α=0.8 时的三倍，任何继续下调的方案都要以真实验证成功率为准；其三，置信度分位阈值推到边界附近时，过滤分别退化为近乎全通过与近乎空批，前者的污染样本直接进入损失，后者让想象样本供给断裂。三条监控线与失效一一对应：单步预测误差、真实验证成功率、剔除率，任一越线先暂停想象路径做对照，确认收益恢复后再分档开启。

实现思路与设计

数据侧：生成器（006 章）产出带来源、置信度、步号字段的轨迹；采样器按 α 比例混合真实与想象批次；过滤器执行三层检查；损失侧按 wk 加权。四个环节全部声明式配置，便于消融。

设计决策：想象损失以小权重常开，筛选信号按批启用

一致性路径的权重保持小而稳定（例如真实权重的 0.2），提供持续的正则效果；结果筛选路径依赖任务判别器质量，按批次启用并随机跳过部分批次，使策略不会对单一筛选器过拟合。两条路径的开关独立配置，消融实验可分别归因。

消融实验按 2×2 因子设计：因子一为想象路径开关，因子二为可靠性过滤开关，四格分别是无想象、纯想象、纯过滤、组合配置，同一步数预算与同一初始权重下各跑一次。净收益按三重差分归因：组合格相对无想象格的差值拆成“数据量效应”（纯想象格）与“过滤质量效应”（组合格减纯想象格再减去纯过滤格相对基准的扰动），每项带置信区间报告，单次差值小于随机种子波动幅度时不作结论。

衔接与差异：本章把 006 章输出的轨迹当作一等公民接入损失，把 005 章的归一化与折扣设施用到第二个场景；007 章的排班决定生成节奏，本章决定消费方式；022 章将把结果筛选升级为奖励预测模型。

关键代码与解读

片段以基于模型的策略增强与自训练（Self-Training）的公开设计为参照，接口随版本演进。第 1 段给出置信度加权的策略损失。

片段 1：置信度加权的策略损失

def weighted_policy_loss(pred, target, step_idx, confidence, provenance,
                         gamma=0.9, real_w=1.0, imag_w=0.2):
    """想象数据加权监督：时域衰减乘置信度，再乘来源标记权重。"""
    base = nn.functional.huber_loss(pred, target, reduction="none").mean(-1)
    # 时域衰减：与 005 章预测折扣同口径，压制远端累积误差的样本
    w = gamma ** step_idx.float()
    # 置信度已在校准集上归一化到 (0,1]：原始不确定分数不可跨样本比较
    w = w * confidence.clamp(min=0.0, max=1.0)
    # 来源标记区分真实与想象：想象样本整体降权，真实样本保持满权
    w = w * torch.where(provenance > 0, torch.full_like(w, imag_w),
                        torch.full_like(w, real_w))
    # 加权归一化：除以权重和，避免批次内样本数变化引起损失尺度漂移
    return (base * w).sum() / w.sum().clamp(min=1e-6)

解读：（1）三个因子相乘后统一归一化，避免了分别加权再相加的尺度歧义。（2）confidence 用 clamp 限幅，防止校准误差导致个别样本权重异常放大。（3）provenance 用数值编码，为将来扩展“人工标注”“其他数据集”等来源留出编码空间，同时让采样器只需处理一个字段。

片段 2：真伪混合采样器

class MixedSampler:
    """按真实占比 α 混合两路数据源；α 随世界模型质量分档调整。"""
    def __init__(self, real_loader, imag_loader, alpha=0.8, step_ratio=0.25):
        self.real, self.imag = real_loader, imag_loader
        self.alpha, self.step_ratio = alpha, step_ratio

    def set_alpha(self, alpha):
        # α 只允许在安全区间内下调：低于 0.5 后确认偏差风险迅速上升
        self.alpha = max(0.5, min(1.0, alpha))

    def __iter__(self):
        real_iter, imag_iter = iter(self.real), iter(self.imag)
        # 真伪步数比由 α 换算：α=0.8 时每 4 个真实批次搭 1 个想象批次
        n_real = max(1, int(round(self.alpha / max(1e-9, 1.0 - self.alpha))))
        while True:
            for _ in range(n_real):
                yield next(real_iter), "real"
            yield next(imag_iter), "imagined"

解读：（1）α 的换算写成固定步数比，批次构成完全确定，训练可复现且容易核对配比。（2）set_alpha 内置 0.5 下界，把防确认偏差的安全约束写进接口，让约束在调用路径上强制执行。（3）产出附带来源标签，下游损失直接消费该字段，避免多层传递中来源信息丢失。

片段 3：可靠性过滤

@torch.no_grad()
def filter_imagined(actions, confidences, action_lo, action_hi,
                    conf_q=0.2, disagreement=None, dis_thresh=None):
    """三层过滤：量程检查、置信度分位、集成分歧；返回保留掩码。"""
    # 第一层：超出训练集分位范围的动作直接剔除，不参与任何损失
    in_range = ((actions >= action_lo) & (actions <= action_hi)).all(dim=-1)
    # 第二层：置信度低于批次 20% 分位的样本降级（此处选择剔除）
    q = torch.quantile(confidences.float(), conf_q)
    trusted = confidences >= q
    keep = in_range & trusted
    # 第三层：集成分歧过滤，阈值由验证集校准；未接入集成时跳过
    if disagreement is not None and dis_thresh is not None:
        keep = keep & (disagreement <= dis_thresh)
    return keep

解读：（1）过滤全部在 no_grad 下进行，且只返回掩码、不改写输入张量，过滤决策与数据使用解耦，便于统计剔除率。（2）量程检查复用 002 章的分位口径，保持全课程一致。（3）三层过滤的顺序按代价从低到高排列，先做廉价的标量比较再做集成推理，分歧过滤可选接入，避免在集成模块就绪前阻塞主回路。

常见坑

  • 确认偏差积累：训练损失持续下降而真实验证成功率下滑，动作熵同步下坠。修复：上调 α、检查采样温度，暂停想象路径做对照。
  • 原始置信度直接加权：未校准的不确定分数跨样本尺度不一，权重实质上由少数样本主导。修复：在校准集上把分数映射到统一区间再使用。
  • 来源标记丢失：数据管线中途拼批时丢掉标记，想象与真实同权参与。修复：把来源作为批次字典的必备字段，入口处断言非空。
  • 过滤过宽等同不过滤：阈值形同虚设，污染样本进入损失。修复：定期报告三层过滤的剔除率，剔除率趋近零时复核阈值。
  • 筛选器过拟合：结果筛选路径每批启用，策略针对判别器弱点优化。修复：筛选路径随机跳批启用并做判别器更新。

练习与思考

  1. 设 γ=0.9、imag_w=0.2、某想象样本在第 5 步且置信度 0.8，计算其相对真实样本首步的权重倍数。★
    提示
    权重为 0.95×0.8×0.2 ≈ 0.094 倍，接近一个数量级的降权，想象监督的边际贡献偏靠数量补齐单条强度。
  2. 把 α 从 0.8 降到 0.5 并保持其他配置不变，预测真实验证集成功率与动作熵两条曲线的走向。★
    提示
    占比提高后覆盖增益与偏差风险同升；世界模型质量达标时成功率小幅上行，否则下滑且动作熵下降。
  3. 推导：若策略误差每轮被自身输出以系数 β 放大（0<β<1），写出无真实数据锚定时策略偏离示教分布的递推式，并解释 α 的作用。★★
    提示
    偏离量按 (1-α)β 的比例逐轮累积；α 越大，每轮引入真实分布校正的强度越高，稳态偏离越小。
  4. 设计增强净收益的消融实验：同一步数预算下比较无想象、想象不筛、想象加筛三组，给出指标与归因方法。★★
    提示
    指标：真实验证成功率、状态覆盖度、想象剔除率；三组对比分别归因数据量效应与过滤质量效应。
  5. 构造确认偏差的复现实验：把动作采样温度降为 0.1 并禁用过滤，记录真实成功率与动作熵的联合演化，给出预警阈值的设计思路。★★★
    提示
    预期熵快速下坠、成功率随后回落；预警用“熵低于早期分位且成功率连续两次下滑”的联合条件。

小结

  • 想象增强分三条路径：一致性监督、结果筛选、状态覆盖扩充，共用来源与置信度字段。
  • 加权公式 wk = γk·ck·mk 把时域衰减、置信度、来源标记统一到一个乘式。
  • 真伪混合比例 α 锚定真实分布，下界 0.5 是防确认偏差的工程约束。
  • 两层锚定（数据锚、采样锚）配合双层监控（动作熵、真实成功率）识别坍缩。
  • 可靠性过滤宁严勿宽，剔除率本身是需要监控的运行指标。
