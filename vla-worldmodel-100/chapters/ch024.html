第二篇 · 联合训练进阶与策略能力

第 024 章：世界模型的对抗性训练

传感器噪声与视觉扰动会让世界模型的预测偏离真实动力学；本章讲清对抗风险的最小最大形式、扰动预算的设定依据，以及潜空间一致性正则在联合训练中的接入方式。

  • 主题：对抗训练（adversarial training） / 鲁棒优化
  • 关键公式：minθ E[ max‖δ‖≤ε L(fθ(x+δ), y) ]；PGD 迭代；潜空间一致性损失
  • 预计学时：50 分钟
  • 前置章节：第 023 章

学习目标

  • 理解对抗风险（adversarial risk）的最小最大结构，能解释内层最大化与外层最小化各自的作用。
  • 掌握投影梯度下降（Projected Gradient Descent, PGD）生成扰动的步骤，理解扰动预算 ε 与步长的选择依据。
  • 掌握潜空间一致性（latent consistency）正则，能把干净输入与扰动输入的表示对齐。
  • 会设计联合训练的对抗批次：干净损失、对抗损失与一致性损失的混合比例与调度。
  • 能诊断对抗训练的三类副作用：干净性能下降、扰动伪影、对抗验证泄漏。

背景与动机

世界模型（World Model）在训练分布内表现稳定，部署时却会遭遇传感器噪声、镜头遮挡、光照突变与镜头脏污等扰动。这些扰动超出训练数据随机噪声的范围：它们沿"最不利于预测"的方向改变输入，可能让整段想象 rollout（imagination rollout）偏离真实动力学，进而误导策略。

对抗训练把最坏情况纳入优化目标：训练时主动构造让预测误差最大的扰动，再要求模型在该扰动下仍然给出正确预测。与第 028 章的域随机化（domain randomization）相比，随机化覆盖自然扰动的分布，对抗训练聚焦扰动空间中的最坏方向，两者互补：前者保证平均性能，后者抬高下界。

本章与上一章的衔接点在于：模仿初始化提供了稳定的起点表征，对抗训练在此基础上为世界模型加上鲁棒边界；被扰动的观测仍要能驱动正确的动作与帧预测，这要求策略分支与动力学分支共享的表示具备一致性。

核心原理

1. 对抗风险的最小最大形式

标准经验风险最小化只优化平均损失，对抗训练求解的是一个嵌套优化：

minθ E(x,y)~D [ max‖δ‖≤ε L( fθ(x + δ), y ) ] x 为观测输入，δ 为扰动，ε 为扰动预算，内层最大化寻找最坏扰动，外层最小化在这种扰动下的损失

内层问题的精确解不可得（损失对 δ 非凸），用一阶方法近似：沿梯度上升方向迭代移动 δ，每步投影回半径 ε 的球内。这就是投影梯度下降（PGD）。单步版本（FGSM）只沿符号梯度走一步，训练更快但鲁棒增益较弱。

δk+1 = Π‖δ‖≤ε [ δk + η · sign( ∇δ L(fθ(x+δk), y) ) ] Π 为投影算子；η 为扰动步长，常用 ε/4 配 4 至 8 步迭代

从经验风险到对抗风险，训练目标的改变在于把评估对象从数据点邻域的均值换成邻域内的最坏点：模型获得的是下界保证，平均指标可能不变甚至略降，但在有界扰动下不再存在“精心构造的失败输入”。三种扰动协议的定位对照见下表：随机噪声覆盖自然扰动的平均形态，FGSM 用一次反向取单步最坏方向，PGD 多步逼近更接近真正的内层最优。

扰动协议生成成本覆盖方向训练收益
随机噪声无额外反向平均噪声分布自然扰动下的平均鲁棒
FGSM1 次反向单步最坏方向较弱，适合快速基线
PGD（4 步）4 次反向多步逼近的最坏方向强，常规推荐

一阶近似下约束形式决定扰动结构，用线性损失算例对比：梯度 g = (3, −4)，‖g‖₂ = 5。L∞ 约束的最优扰动为 ε·sign(g) = (ε, −ε)，损失增量 g·δ = 7ε；L2 约束的最优扰动为 ε·g/‖g‖ = (0.6ε, −0.8ε)，损失增量只有 5ε。同样的预算下 L∞ 能把损失抬高四成，代价是扰动集中到少数坐标、空间上呈散点状；L2 的扰动均匀铺开，更接近弥散噪声。像素扰动研究多用 L∞ 刻画最坏情形，传感器噪声建模则更接近 L2 或实测分布，两者覆盖的故障类型不同。迭代步数的成本也需记账：4 步 PGD 对每个对抗样本额外做 4 次反向，批内占比 30% 时相当于增加 1.2 倍批量的反向计算，训练单步计算量上升约八成。

2. 扰动预算与语义保持

图像输入下常用的预算是 ε = 8/255 ≈ 0.031（按 [0, 1] 归一化像素），对应人眼可察觉但语义不变的变化幅度。预算选择需要平衡两个目标：ε 过小无法覆盖真实传感器扰动，过大则扰动本身破坏语义（物体类别改变），模型学到的是"对语义破坏的鲁棒"，真实场景中这些扰动不会出现，纯属浪费容量。

预算的换算口径要写清，避免训练与评估各说各话：8/255 在 [0, 1] 归一化下是 0.0314，在 8 位像素下是 8 个灰阶，相对动态范围 3.1%；若输入做了标准化（减均值除方差），同一物理扰动的数值幅度会随通道方差缩放，ε 必须按标准化后的尺度重新折算，否则实际扰动强度与设定值偏差数倍。传感器实测标定是确定 ε 的最终依据：采集静止场景下相机噪声的逐像素极差，取 95% 分位作为起点，再按任务鲁棒需求上下微调。

连续时序下的扰动还需要考虑时间一致性：逐帧独立采样扰动会产生高频闪烁，而真实传感器故障（镜头脏污、曝光漂移）在时间上相关。常用做法是在一段窗口内共享扰动掩码，或对扰动序列施加低通约束。扰动的时序结构决定鲁棒边界覆盖的故障类型，逐帧独立扰动主要覆盖瞬时视觉噪声。

两种协议的时间相关性可以量化：逐帧独立采样时相邻帧扰动的相关系数为 0，覆盖的是单帧尺度的瞬时噪声；窗口共享掩码时窗口内相关系数为 1，一个掩码持续覆盖整个窗口（例如 10 帧），对应“镜头被遮挡或脏污持续一段时间”的故障形态。真实相机故障介于两者之间（相关系数 0.5 到 0.9 的中间态），训练协议按实测自相关函数选择窗口长度，评估集则两类都要包含，只测一类会高估或低估鲁棒边界。

3. 潜空间一致性与联合接口

仅要求输出鲁棒会在输出空间留下很大自由度。对联合训练更有效的约束在潜空间：干净输入与扰动输入应映射到相近的潜状态，使动力学预测与策略解码都保持稳定：

Lcons = ‖ E(x) − E(x + δ) ‖22 或 1 − cos( E(x), E(x + δ) ) E 为共享编码器；余弦形式对特征整体尺度不敏感，适合中高层特征对齐

一致性约束的强度需要控制：过强会把编码器压向对扰动不变的表征，损失任务判别性（例如对光照变化过度不变会削弱阴影线索的利用）。实践中先在编码器中段特征上施加一致性，输出层保持区分能力。

余弦形式的一致性损失把“特征夹角”直接映射为损失值：夹角 15° 时损失 0.034，30° 时 0.134，45° 时 0.293，60° 时 0.500，90° 时达到上限 1.0。健康训练中干净与扰动特征的夹角应稳定在 20° 以内，对应损失 0.06 量级；若夹角长期大于 45°，说明扰动把表示推到了另一个区域，优先检查 ε 是否超过语义保持范围，其次检查一致性权重是否过小。该读数可以作为训练日志里的固定监控项，比只看总损失更能定位问题来源。

联合训练的总损失由三部分构成：

L = Lclean + β · Ladv + λc · Lcons β 控制对抗训练强度，λc 控制一致性强度；β = 0.3 与 λc = 0.1 是常用起点

4. 鲁棒性与保真度的权衡

对抗训练会轻微降低干净样本上的精度，因为模型容量被部分用于覆盖扰动邻域。这种取舍存在可量化的边界：把扰动空间视为需要覆盖的区域，容量固定时覆盖区域越大，干净分布的拟合精度越低。缓解手段有三：其一，对抗批次只占每步批次的一部分（如 30%），其余保持干净；其二，从 ε = 0 逐步增大到目标值（课程式对抗训练），避免早期容量被全部占用；其三，对浅层与深层施加不同强度的对抗要求，浅层容忍度更高。

取舍的监控目标写成可验收的指标：干净留出集误差相对纯干净训练的上升控制在 1 个百分点以内，同时对抗扰动误差下降不少于三成；两者不能同时满足时，先降对抗批次占比，再动 ε。课程式升温的常见形态是线性：ε 在前 20% 训练步内从 0 升到 8/255，升温中点处取 4/255，早期模型先拟合干净分布，扰动邻域随容量增长逐步纳入。若升温过快，等价于把全强度对抗直接前置，干净误差在早期就被抬高且难以回落。

对抗训练与想象 rollout 的交互是本章的联合训练接口：扰动观测进入编码器后，潜状态偏移会沿 rollout 的步数放大，动力学的多步预测误差随之上升；一致性项正是压制这一偏移的机制。观测口径是把潜空间一致性损失与想象轨迹的 5 步预测误差并列监控：一致性损失下降而多步误差不降，说明扰动改变了动力学，影响范围已超出表示层面，应转向检查动力学模块是否也参与了对齐（例如在潜状态序列上追加一致性约束）。

策略分支的鲁棒要求用动作抖动上界表达：对同一观测施加预算内扰动，策略输出动作的变化范数应控制在动作量程的 5% 以内；超过该上界时，即使世界模型预测稳定，执行端也会因动作抖动触发保护或产生振荡。监控方式是在鲁棒评估集中加一项“扰动动作差异”指标，与预测误差一起报告；两者背离（预测稳而动作抖）时，把一致性约束的位置前移到策略解码器的输入特征上。

实现思路与设计

对抗训练接入联合训练分四步：扰动生成器、双路前向、损失混合、鲁棒性评估。与第 023 章的差异：023 关注策略的动作分布先验，本章关注模型在扰动观测下的表示与预测稳定性。

  1. 扰动生成：每个批次抽取 30% 样本做 PGD，迭代 4 步，步长 ε/4，扰动约束在 L∞ 球内；时序样本按窗口共享扰动。
  2. 双路前向：干净与扰动两路共享编码器，分别计算预测损失；一致性损失加在编码器中段特征上。
  3. 损失混合与调度：β 从 0 线性升到 0.3（前 20% 训练步）；一致性系数固定在 0.1。
  4. 鲁棒评估：留出集上分别报告干净误差、ε 扰动误差与随机噪声误差，三者对照说明鲁棒边界的来源。

关键代码与解读

以下片段参照公开的对抗训练与鲁棒表示学习实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：PGD 扰动生成

import torch
import torch.nn.functional as F

def pgd_perturb(model, obs, action, eps=8/255, steps=4, alpha=None):
    """在 L∞ 球内做投影梯度上升，生成最坏扰动。"""
    if alpha is None:
        alpha = eps / 4
    # 从球内随机点出发：避免每次都从零开始，增加扰动多样性
    delta = torch.empty_like(obs).uniform_(-eps, eps).detach()
    for _ in range(steps):
        delta.requires_grad_(True)
        # 内层目标：最大化预测误差（暂停对模型参数的更新）
        loss = F.mse_loss(model.predict(obs + delta, action), model.target(obs))
        grad = torch.autograd.grad(loss, delta, only_inputs=True)[0]
        # 沿梯度符号方向移动，再投影回 L∞ 球
        delta = (delta.detach() + alpha * grad.sign()).clamp(-eps, eps)
    return delta.detach()

解读：（1）随机起点加多步上升比单步 FGSM 找到的最坏扰动更强，这也是训练鲁棒性更好的原因；（2）用符号梯度归一每维步长，避免梯度尺度差异让某些像素主导扰动；（3）目标用目标网络 target 的预测或真实下一帧，防止扰动只针对当前参数；（4）detach 后返回，扰动不带梯度，训练损失里对抗项只更新模型参数。

片段 2：对抗训练步与潜空间一致性

def adversarial_step(model, batch, beta=0.3, lam_c=0.1):
    """一个对抗训练步：干净与扰动两路前向，混合三种损失。"""
    obs, action, next_obs = batch["obs"], batch["action"], batch["next_obs"]
    # 扰动只对部分样本生效，控制干净性能的损失
    adv_mask = torch.rand(obs.shape[0], device=obs.device) < 0.3
    delta = torch.zeros_like(obs)
    if adv_mask.any():
        delta[adv_mask] = pgd_perturb(model, obs[adv_mask], action[adv_mask])

    # 编码器中段特征用于一致性：高层特征保留判别性，低层特征噪声大
    z_clean, f_clean = model.encode(obs, return_mid=True)
    z_adv, f_adv = model.encode(obs + delta, return_mid=True)

    loss_clean = model.prediction_loss(z_clean, action, next_obs)
    # 对抗项只统计被扰动样本，权重按占比放大到全批尺度
    loss_adv = model.prediction_loss(z_adv[adv_mask], action[adv_mask],
                                     next_obs[adv_mask]) * (adv_mask.float().mean().clamp(min=1e-6) / 0.3)
    # 余弦一致性：只对齐方向，特征幅度不被压缩
    loss_cons = (1 - F.cosine_similarity(f_clean, f_adv, dim=-1)).mean()
    return loss_clean + beta * loss_adv + lam_c * loss_cons

解读：（1）对抗样本占比 30%，损失按占比缩放，使对抗项的期望贡献稳定在 β 的量级，不随批次中扰动样本数波动；（2）一致性施加在编码器中段特征，兼顾鲁棒与判别：浅层特征包含高频细节，强行对齐会损失纹理鉴别力；（3）余弦相似度对大尺度特征差异不敏感，适合跨样本对齐；（4）片段与片段外的调度逻辑分离，β 的升温在训练循环层实现，保持损失函数纯粹。

常见坑

  • 扰动预算过大破坏语义：ε 设到 16/255 以上时，模型学到对语义破坏的鲁棒，真实性能不再提升。症状是扰动验证误差改善而真实场景成功率停滞。修复：按传感器实测噪声标定 ε，并从 4/255 起做预算扫描。
  • 只扰动观测、不扰动动作通道：世界模型的输入包含动作，执行器噪声与校准误差同样会污染动作条件，遗漏该通道会让联合鲁棒存在缺口。修复：对动作通道施加按量程缩放的 L∞ 扰动，与观测扰动联合训练。
  • 干净性能显著下降：全批次对抗导致容量全部用于覆盖扰动邻域。修复：把对抗样本占比降到 30% 以下，或采用课程式对抗训练，ε 从 0 逐步升至目标值。
  • 对抗验证泄漏：在验证集上重新生成扰动并调参，指标虚高。修复：验证扰动协议与训练协议分离，报告时注明扰动生成方式与是否冻结。
  • 忽略扰动的时序结构：逐帧独立扰动训练出的模型对连续故障（镜头遮挡数秒）依然脆弱。修复：在窗口内共享扰动掩码，评估协议中包含分段连续扰动场景。

    提示
    扰动集误差持续下降（训练目标直接优化它），干净集误差持续上升，真实成功率在中等 ε 处达到峰值后回落；拐点最先出现在真实成功率上，因为它同时受两个方向影响。
  2. 推导单步 FGSM 形式：从一阶泰勒展开 L(x + δ) ≈ L(x) + δT∇xL 出发，说明最优 δ 取 −ε·sign(∇xL)（最大化损失时取正号），并解释为何符号函数在 L∞ 约束下是最优解。★★★
    提示
    在 ‖δ‖∞ ≤ ε 下最大化 δTg，每维独立取边界符号即为最优；L2 约束下最优解改为沿梯度方向归一化，两者对扰动结构的影响不同。
  3. 设计鲁棒性评估协议：给出三类扰动（瞬时随机噪声、分段连续遮挡、对抗扰动）的测试集构造方式与指标，并说明如何避免对抗验证泄漏。★★
    提示
    瞬时噪声按传感器实测分布采样；连续遮挡按时间窗口掩码；对抗扰动用冻结生成器或固定步数的协议。三类分别报告，结论区分"对自然扰动鲁棒"与"对最坏扰动鲁棒"。
  4. 把一致性损失从余弦形式换成平方距离形式，并乘以特征方差归一化。预测两种形式在训练早期（表征尚未稳定）的行为差异。★★
    提示
    平方距离直接压缩特征幅度，早期会拖慢表征分化；按方差归一后大部分尺度差异被吸收，方向对齐成为主导，训练早期更平稳。可从小批量上观察特征范数的变化曲线验证。

小结

  • 对抗训练求解最小最大问题，内层用 PGD 近似最坏扰动，外层在扰动下最小化损失。
  • 扰动预算按传感器实测噪声标定，过大预算破坏语义并使真实性能回落。
  • 潜空间一致性约束让干净与扰动输入共享表示，中段特征是最佳施加位置。
  • 对抗批次占比、升温调度与损失权重共同控制鲁棒性与干净性能的平衡。
  • 扰动的时序结构决定覆盖的故障类型，连续遮挡场景需要窗口共享扰动。
