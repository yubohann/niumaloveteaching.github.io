第三篇 · 策略与世界模型深化

第 056 章：VLA策略的视觉特征提取

视觉入口决定策略能"看到"什么：本章讲清补丁词元与全局词元的分工、多尺度特征的组装方式、冻结主干加适配器的参数效率，以及分辨率与注意力成本的换算。

  • 主题：VLA 策略 / 视觉表示（Visual Representation）
  • 关键公式：Ntokens = (H/p)·(W/p)，注意力成本 O(N²d)
  • 预计学时：55 分钟
  • 前置章节：第 055 章 联合训练中的目标条件设置

学习目标

本章围绕视觉编码器的输出组织与参数策略展开，连接感知精度与部署成本。

  • 理解补丁词元（Patch Token）与全局词元（CLS Token）的分工：前者保留空间精度，后者聚合全局语义。
  • 理解自监督预训练特征的两个来源（对比对齐与自蒸馏）的差异，以及冠词元（Register Token）对注意力稳定性的作用。
  • 掌握多尺度特征提取的层选择与位置嵌入插值，能换算分辨率、词元数与注意力成本。
  • 掌握冻结主干加低秩适配器（LoRA 风格）的微调策略及其相对全量微调的优势。
  • 能设计特征缓存与失效规则，在不引入陈旧特征的前提下降低重复编码开销。

背景与动机

VLA 策略的全部决策建立在视觉特征之上，特征的空间分辨率、语义层次与稳定性直接决定抓取与装配的精度上限。操作任务对空间细节的要求高于图像分类：末端与目标的相对位姿、接触点的细粒度位置都藏在补丁级特征里，只取全局词元的表示会丢失这些信息。同时，视觉编码器是模型中最重的模块，分辨率与词元数决定训练与推理的主要成本，特征组织方式因此是精度与算力的联合优化问题。

预训练来源决定特征的先验结构：对比学习（如 SigLIP 风格）把图像与语言拉入同一空间，天然利于指令条件化；自蒸馏（如 DINOv2 风格）强调局部一致性与密集语义，适合空间任务。本章讨论如何在两者之间选择与组合，并用多尺度与适配器机制把预训练特征迁移到机器人数据分布。前一章完成目标条件的输入结构，本章深入感知入口本身的组织。

核心原理

按"词元组织、预训练来源、多尺度、微调、缓存"五条线索展开。

1. 补丁词元与全局词元

视觉主干把图像切成 p×p 的图块，线性投影后得到词元序列，外加一个全局词元。词元数量为：

N = (H/p)·(W/p) + 1 224×224 图像、图块 14 时约 257 个词元；换成图块 8 时词元数约 785，注意力成本上升约 9 倍

全局词元经层层注意力聚合整幅图像的信息，适合任务语义与场景识别；补丁词元保留各自位置的局部特征，是空间操作的必需输入。策略的交叉注意力应以补丁词元为键值，让语言查询直接指向空间区域；把全局词元作为附加条件注入，兼顾场景上下文。两类词元混用时需要在融合层区分来源，否则空间结构被全局平均稀释。

2. 预训练来源与注意力稳定性

对比对齐特征的优势在跨模态迁移：嵌入空间与语言对齐，指令条件化需要的映射更短；自蒸馏特征的优势在密集预测：每个补丁的词元都承载可用的局部语义，适合抓取点回归。两者的选择依据下游接口：若策略以语言为条件且需要与目标嵌入共享空间，优先对比对齐主干；若任务主要是几何操作且语言只提供子任务提示，自蒸馏特征的局部结构更有利。

自监督主干存在一个工程细节：注意力图上偶尔出现高范数的孤立词元（伪影），干扰下游读取。冠词元是缓解手段：在输入序列中追加若干无输出的可学习词元，承载这些异常激活，使补丁词元的注意力分布更干净。投资多个冠词元的成本是少量词元开销，收益是特征稳定性的提升。

3. 多尺度特征与位置嵌入插值

不同深度的特征携带不同层次的信息：浅层偏纹理与边缘，中层偏部件与形状，深层偏语义与任务相关区域。多尺度提取把若干层的补丁特征拼接或相加，经线性层统一维度后送入融合模块。层选择的原则是覆盖至少两个尺度：中层的几何信息与深层的语义信息组合，比单独使用任意一层在操作任务上更稳健。

分辨率变化时位置嵌入需要插值。位置嵌入记录词元的空间位置，输入分辨率与预训练不一致时形状不符，双线性插值把它重采样到目标网格。插值会平滑位置编码的高频成分，分辨率差异大的场景应改用带分辨率自适应的预训练主干，或对插值后位置编码做一次轻量微调。

4. 冻结主干与低秩适配

机器人数据规模通常小于视觉预训练数据几个数量级，全量微调容易过拟合与遗忘。低秩适配器在冻结权重旁增加小秩矩阵：

W′ = W + (α/r)·B·A，A ∈ Rr×din，B ∈ Rdout×r r 取 8 至 32；A 按高斯初始化，B 初始化为零，训练起点等价于原模型

适配器把可训练参数压缩到原模型的千分之一量级，梯度只流经低秩通路，预训练特征的几何结构被保留，小数据下的过拟合风险显著下降。注入位置建议从后半层开始，浅层特征的通用性最强，修改的收益低而破坏风险高。

5. 特征缓存

控制回路中相邻观测高度重叠，重复编码的计算浪费可观。特征缓存按观测的唯一标识索引，命中时直接复用。失效规则是缓存设计的关键：场景变化（新帧与缓存帧的像素差超过阈值）、相机运动、任务阶段切换都应触发失效，缓存新鲜度不足时下游条件化的误差比节省的算力更昂贵。缓存只适用于静态观测段（例如执行动作块期间相机基本静止），移动平台场景收益有限。

实现思路与设计

设计围绕分辨率、层选择、适配器与缓存四项配置展开，全部以词元预算为约束。

词元预算换算

  1. 输入分辨率 224×224、图块 14，得到 256 个补丁词元加 1 个全局词元。
  2. 策略交叉注意力的键值为补丁词元，成本与 N² 相关；N 翻倍时该项变为约 4 倍。
  3. 多尺度拼接不增加键值长度（层间特征共享同一网格），只增加融合层输入维度。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段 1：多尺度补丁特征与位置嵌入插值

import torch
import torch.nn.functional as F

def multi_scale_patches(backbone, images, layers=(6, 12, 18), target_grid=16):
    """提取多层补丁特征并统一到目标网格。
    设计意图：中浅层提供几何细节，深层提供语义区域，融合后覆盖两个尺度。"""
    _, intermediates = backbone.forward_with_intermediates(images, layers)
    feats = []
    for tokens in intermediates:
        # tokens 含全局词元与补丁词元：切掉全局词元，只保留空间特征
        patch_tokens = tokens[:, 1:]
        n = patch_tokens.size(1)
        side = int(n ** 0.5)                        # 假设方形网格，实际按配置校验
        grid = patch_tokens.transpose(1, 2).reshape(tokens.size(0), -1, side, side)
        # 不同层网格一致时插值退化为恒等；分辨率策略变化时此处兜底对齐
        if side != target_grid:
            grid = F.interpolate(grid, size=(target_grid, target_grid),
                                 mode="bilinear", align_corners=False)
        feats.append(grid.flatten(2).transpose(1, 2))   # 还原为词元序列
    return torch.cat(feats, dim=-1)                 # 末维拼接，供融合层降维

解读：（1）切片去掉全局词元，空间特征与全局语义在通道上分开管理，避免两类信息混在同一张量里难以区分来源。（2）插值兜底保证不同层或不同分辨率策略下的网格一致，拼接前的对齐检查是防止形状错误的必要步骤。（3）末维拼接把融合层输入维度变为三层之和（如 3×768），融合层线性投影回目标维度，参数量可控。

片段 2：低秩适配器注入

import torch
import torch.nn as nn

class LoRALinear(nn.Module):
    """冻结原始线性层，旁路插入低秩适配器。
    设计意图：可训练参数压到千分之一量级，小数据下保住预训练特征结构。"""
    def __init__(self, base: nn.Linear, rank=16, alpha=2.0):
        super().__init__()
        self.base = base
        for p in self.base.parameters():
            p.requires_grad = False                 # 主干权重冻结
        d_in, d_out = base.in_features, base.out_features
        self.A = nn.Parameter(torch.randn(rank, d_in) * 0.02)   # 高斯初始化
        self.B = nn.Parameter(torch.zeros(d_out, rank))         # 零初始化：起点等价原模型
        self.scale = alpha / rank

    def forward(self, x):
        # 主干输出加低秩旁路，训练起点两者叠加退化为原函数
        return self.base(x) + self.scale * (x @ self.A.t() @ self.B.t())

解读：（1）B 初始化为零保证训练起点与预训练模型完全一致，损失曲线从原水平开始下降，便于与冻结基线对照。（2）适配器只增加两个小矩阵，优化器参数组只包含 A、B，与主干权重分组管理，学习率可以独立设置。（3）注入位置由外部配置决定，选择后半层的注意力与多层感知机投影；注入列表写入训练配置，随检查点一起保存，避免推理时遗漏。

片段 3：带失效规则的特征缓存

class FeatureCache:
    """最近一帧的视觉特征缓存：像素差超阈值时判定失效并重新编码。"""
    def __init__(self, mse_threshold=0.02):
        self.threshold = mse_threshold
        self.last_feats = None
        self.last_image = None

    def get(self, image_tensor, encoder):
        # 细粒度校验：与最近一次编码的观测比较像素均方误差
        if self.last_image is not None:
            mse = (image_tensor - self.last_image).pow(2).mean().item()
            if mse <= self.threshold:
                return self.last_feats, True      # 场景未变，直接复用特征
        feats = encoder(image_tensor)
        # 缓存张量截断梯度：防止计算图随缓存存活造成显存泄漏
        self.last_feats = feats.detach()
        self.last_image = image_tensor.detach().clone()
        return feats, False

解读：（1）像素均方误差阈值按相机静态段的噪声水平校准：静止时帧间差异接近零，阈值只需覆盖噪声；阈值过松会把缓慢变化误判为静止，条件化基于过期场景。（2）只保留最近一帧的缓存，实现简单且失效判定准确；多帧缓存需要帧内容匹配或关键帧策略，复杂度显著上升而收益有限。（3）缓存值 detach 后保存，避免计算图随缓存存活造成的显存泄漏，这是缓存实现最常见的错误来源。

常见坑

  • 提高分辨率不核算词元成本：输入从 224 提到 448，注意力成本约 16 倍，训练直接超预算。修复：先换算 N，再决定是否换主干或提高图块尺寸。
  • 只用全局词元做操作：抓取点估计缺少空间精度，末端偏移明显。修复：策略交叉注意力以补丁词元为键值，全局词元作为附加条件。
  • 冻结主干与目标分布失配：机器人相机视角与预训练分布差异大，冻结特征质量不足。修复：后层注入适配器并适度解冻最后一层，验证集上确认收益。
  • 位置嵌入插值后不微调：分辨率改变导致位置语义偏移。修复：插值后对位置编码做少量步数的微调，或使用支持多分辨率的预训练主干。
  • 缓存未设失效规则：场景变化后沿用旧特征，条件化误差被放大。修复：像素差或时间戳双阈值触发失效，缓存张量截断梯度。

练习与思考

  1. 换算：384×384 输入、图块 16 时的补丁词元数；相比 224×224、图块 14 的配置，注意力成本大约是多少倍？★
    提示
    384/16 = 24，得到 24² = 576 个词元；旧配置 224/14 = 16，得到 256 个。词元比 2.25，注意力成本按平方约 5 倍。
  2. 把适配器秩 r 从 16 提到 128，预测三件事的变化：可训练参数量、小数据下的验证误差、大规模数据下的收益，并说明验证方式。★★
    提示
    参数量线性上升，小数据下验证误差先降后升（过拟合），大数据下收益更大。验证：分数据规模档位训练对照。
  3. 设计实验比较三类视觉特征方案：冻结主干全局词元、冻结主干多尺度补丁、加适配器多尺度。写出指标（抓取点误差、任务成功率）与预期排序。★★★
    提示
    抓取点误差对空间特征敏感，多尺度补丁应优于全局；适配器在域差大时补足。固定其他变量，报告两组指标与配对显著性。
  4. 讨论：特征缓存在哪些控制模式下的收益最大？给出一个失效规则设计，并说明误用缓存的后果。★★
    提示
    观测静止段（执行动作块、等待阶段）收益最大；失效规则用像素差阈值加最大缓存时长。误用导致条件化基于过期场景，动作对当前目标失效。

小结

  • 补丁词元保留空间精度，全局词元聚合语义；操作任务必须以补丁词元作为注意力的键值。
  • 对比对齐与自蒸馏两类预训练特征各有优势，选择依据下游接口与语言条件化需求。
  • 多尺度提取覆盖几何与语义两个层次，位置嵌入插值是分辨率变化时的必要处理。
  • 冻结主干加低秩适配器把小数据微调的风险控制在低秩通路内，注入位置从后半层开始。
  • 特征缓存必须有失效规则与容量上限，缓存张量截断梯度防止显存泄漏。
