第二篇 · 联合训练进阶与策略能力

第 022 章：基于世界模型的奖励预测

真实奖励稀疏且昂贵时，可在世界模型潜空间里训练奖励预测头，把逐步信号变成密集的代理回报；本章讲清奖励头的结构、λ-return 的信用分配机制，以及奖励偏差放大的抑制手段。

  • 主题：奖励建模（reward modeling） / 信用分配（credit assignment）
  • 关键公式：r̂t = Rψ(zt, at)；Gt = Σ γk r̂t+k；λ-return 递推
  • 预计学时：50 分钟
  • 前置章节：第 021 章

学习目标

  • 理解奖励预测（reward prediction）与价值函数（value function）的区别与联系：前者给出即时标量信号，后者给出长期回报估计。
  • 掌握奖励头的三种参数化：高斯回归、二值分类与排序，以及各自适用的奖励类型。
  • 掌握信用分配（credit assignment）的两条路线：折扣累积回报与 λ-return，理解偏差与方差的权衡。
  • 会设计奖励归一化（reward normalization）方案，抑制奖励尺度漂移对策略更新的干扰。
  • 能诊断奖励黑客（reward hacking）与奖励滞后（delayed reward）两类典型失效。

背景与动机

具身任务里的真实奖励往往稀疏且昂贵：抓取成功是一个稀疏指示信号，进度奖励需要人工设计，接触力与对齐误差需要专门测量。稀疏奖励让策略优化面对巨大的信用分配难度，少数成功轨迹之外几乎没有学习信号。

世界模型（World Model）给出另一条路线：真实的奖励可以在潜空间（latent space）里被预测。既然世界模型已经学会了从潜状态预测下一帧，它同样可以学会从潜状态与动作预测标量奖励。得到的奖励预测头（reward head）在想象 rollout（imagination rollout）中逐步给出密集信号，策略可以在想象中优化代理回报，大幅降低对真实奖励的依赖。

本章与第 021 章的多任务协调直接衔接：奖励预测是共享骨干上的一个任务头。奖励信号的质量决定策略学习的方向，因此奖励刻画的偏差与尺度问题需要单独处理。

核心原理

1. 奖励头的结构形式

奖励头把潜状态与动作映射为标量：

r̂t = Rψ(zt, at) zt 为世界模型在时刻 t 的潜状态，at 为动作，ψ 为奖励头参数

结构上通常取两层多层感知机（MLP），输入为潜状态与动作嵌入的拼接。拼接进入共享 MLP 的原因是奖励依赖状态与动作的交互项（同一个动作在不同状态下奖励不同），拼接后由 MLP 自行学习交互，参数更省；双塔结构把两路输入分开编码，交互项需要额外的显式设计。

训练目标的参数化按奖励类型选择：

奖励类型参数化损失适用场景
连续进度（对齐误差、距离）均值 + 方差双头高斯负对数似然信号连续且含噪
稀疏指示（成功 / 失败）单 logit二值交叉熵事件式奖励
偏好比较（A 优于 B）共享打分 + 差值Bradley-Terry 排序损失人工偏好标注

双头高斯参数化的价值在于同时给出置信度：方差头估计的 σt 可进入策略目标作保守化惩罚，把奖励预测不确定的状态区域降权，这一机制与第 031 章的不确定性估计直接对接。

2. 信用分配：从即时信号到长期回报

奖励头输出的是即时信号，策略优化需要的是长期回报。折扣累积回报定义为：

Gt = Σk=0H−1 γk r̂t+k γ 为折扣因子，H 为想象推进步长，常用 5 至 15

纯 Monte Carlo 式累积的方差高：第 t 步的回报依赖其后 H 个奖励预测，任何一步的偏差都会叠加。λ-return 在 Monte Carlo 与单步自举（bootstrap）之间插值：

Gtλ = r̂t + γ [ (1 − λ) V(zt+1) + λ Gt+1λ ] λ 接近 1 退化为累积回报，λ 接近 0 退化为单步自举；λ = 0.95 是常用起点

递推形式便于实现：从想象轨迹末端反向计算，每个时刻只需一步奖励与价值估计。直觉上，λ 控制"向前看多远"：远期信号可靠时提高 λ，远期信号噪声大时降低 λ 以增加自举、缩短信用链。信用链长度与想象步长 H 共同决定策略能学到的动作时间跨度。

递推展开可以写清每一步的权重：把 Gtλ 的式子在时间上逐层代入，得到显式展开

Gtλ = Σk=0H−1−t (γλ)k [ r̂t+k + γ(1−λ)·V(zt+k+1) ] + (γλ)H−t·V(zH) 第 k 步奖励的系数为 (γλ)k；末端自举项按 (γλ)H−t 缩水，λ 与 γ 以乘积形式共同控制有效视野

数值算例：取 γ = 0.99、λ = 0.95、H = 3，奖励全为 1，各步价值估计均为 5。按公式：G2λ = 1 + 0.99 × 5 = 5.95；G1λ = 1 + 0.99 × (0.05 × 5 + 0.95 × 5.95) = 6.843；G0λ = 1 + 0.99 × (0.25 + 0.95 × 6.843) = 7.684。三个对照：λ = 0 时三个值全部退化为 5.95（纯单步自举，奖励只影响一步）；λ = 1 时 G0λ = 7.822（完整折扣累积，奖励的信用向后展开最远）。有效视野读数：1 / (1 − γλ) = 1 / (1 − 0.9405) ≈ 16.8 步，与想象步长 15 同量级，说明这组参数下信用链恰好覆盖整段想象轨迹；把 λ 降到 0.5，视野缩到约 2 步，第 5 步之后的奖励对 G0λ 几乎无贡献，策略学到的动作时间跨度显著变短。

λγλ有效视野G0λ（同一算例）偏差与方差倾向适用信号
001 步5.950偏差高、方差低价值头可靠且奖励噪声大
0.50.495约 2 步6.653折中中等噪声的过渡档
0.950.9405约 16.8 步7.684方差高、偏差低奖励头较准时的默认档
10.99约 100 步7.822方差最高长时信用、末端自举不可信

表的读法：同一组奖励与价值输入下，λ 越大，远期奖励进入目标越多，G0λ 单调上升（5.95 到 7.82），策略被鼓励的动作跨度同步拉长；代价是回报目标依赖更长的预测链，方差随视野近似线性增长。选择 λ 的实用检查是让 1 / (1 − γλ) 与想象步长 H 同量级：γ = 0.99 时，λ = 0.95 对应约 17 步，与 H = 15 匹配；若 H 只有 5 步，λ 保持 0.95 会让视野远超轨迹长度，末端价值项实际上从未被有效训练。

3. 奖励尺度与归一化

奖励量级随任务阶段漂移（接触阶段的力信号远大于接近阶段），未归一化的奖励会让策略更新步长在早期被大信号主导、后期被小信号淹没。运行式标准化是标准做法：

r̃t = ( rt − μrun ) / ( σrun + ε) μrun、σrun 为奖励流水的均值与标准差，更新时使用滑动平均，ε 取 1e-8

归一化的作用是把有效学习率从奖励量级中解耦：不同任务的奖励尺度差异被压缩到同一量级，方便复用同一组优化超参数。实现细节上滑动窗口过长会让归一化滞后于分布漂移，过短会让归一化系数抖动，常用窗口为 104 至 105 步。数值行为过一遍：奖励流水均值 0.5、标准差 2.0 时，原始奖励 3.5 被映射为 (3.5 − 0.5) / 2.0 = 1.5；若接触阶段奖励量级突然扩大十倍，滑动统计要经过约一个窗口长度的滞后才完成追踪，期间归一化输出偏小、实际更新被短暂放大，这正是窗口不能过长的原因。另一个实现细节是冻结期：奖励头重训或任务切换时暂停 μ、σ 的更新若干步，避免新旧分布的混合统计污染归一化系数。

4. 奖励偏差的放大与抑制

想象回报的估计偏差由奖励预测误差与价值自举误差叠加而成。设单步奖励预测误差为 εr、价值误差为 εV，H 步想象回报的误差上界近似为：

|Gt − Ĝt| ≤ Σk=0H−1 γk εr,k + γH εV 误差随步长近线性累积，末端自举项被 γH 缩水，注意两项的取舍

三种抑制手段：其一，缩短 H 并依赖价值自举；其二，用奖励头的方差输出作惩罚，把高风险预测降权；其三，定期用真实奖励校正，混合真实片段与想象片段训练。策略若发现模型误差方向，会朝"骗过奖励头"的区域漂移，这是奖励黑客的来源。奖励头与真实奖励的偏差监控应作为常规指标，定期执行。

误差分布的数值读数：取 γ = 0.99、H = 15、εr = 0.02、εV = 0.1 代入上界，奖励项约 (1 − 0.9915) / 0.01 × 0.02 ≈ 0.280，自举项 0.9915 × 0.1 ≈ 0.086，合计约 0.366。若任务的成功奖励量级为 1，回报估计的误差预算已达信号的三分之一，这正是想象步长不能随意加长、以及末端自举误差必须单独控制的量化原因。两个方向的收益对比：把 H 从 15 缩到 8，奖励项收缩到约 0.155 而自举项升至 0.092，合计降到 0.247；把奖励头误差 εr 减半到 0.01，合计降到 0.226。两条路径都有效，且奖励头精度的收益随 H 增大而放大，短期收益则更多来自缩短 H。

适用边界与失效模式

五个边界情形。其一，事件式奖励用高斯参数化：成功是二值事件，高斯 NLL 会把概率质量摊在连续轴上，分类参数化（交叉熵）才是正确形式，两者在稀疏成功信号下的收敛速度差异明显。其二，分阶段量纲混用：接触力信号与距离进度信号量级相差两个数量级以上，归一化必须按阶段或按信号分组统计，全局一套均值会被大信号拽偏。其三，想象回报与真实回报的口径脱节：想象环境消费的是奖励头输出（含稠密塑形），真实环境给出的多为稀疏成功信号，两套口径若不定期对齐，策略会朝“刷想象塑形项”的方向漂移。其四，方差惩罚未校准：方差头的 σ 未经温度缩放就进入惩罚项，惩罚强度与真实不确定性脱钩，校准时序应安排在策略消费之前。其五，回报目标未隔离梯度：λ-return 若不带停止梯度地接进策略损失，梯度会沿回报路径回传进世界模型，动力学表征被策略目标扰动，训练稳定性下降。

实现思路与设计

奖励预测的工程结构分四步：数据标注、奖励头训练、λ-return 计算、策略优化接口。与第 021 章的差异在于：021 处理共享参数的梯度协调，本章处理奖励信号的构造与偏差控制。

  1. 数据流：真实轨迹（观测、动作、奖励标注）经世界模型编码器得到潜状态序列，组成训练对 (zt, at, rt)。奖励标注可来自环境测量或人工标签。
  2. 奖励头训练：在潜状态上冻结世界模型，只更新奖励头参数，避免奖励梯度反向污染动力学表征。
  3. 想象 rollout：策略在潜空间推进 H 步，每步调用奖励头与价值头，得到轨迹级回报。
  4. 策略优化：λ-return 作为优势估计的目标，配合奖励归一化与方差惩罚项。

关键代码与解读

以下片段参照公开的潜空间奖励建模与 λ-return 实现设计，版本中立；PyTorch 风格，细节接口随版本演进。

片段 1：双头奖励预测器与归一化

import torch
import torch.nn as nn

class RewardHead(nn.Module):
    """在潜空间预测奖励：均值与方差双头，方差用于保守化。"""
    def __init__(self, latent_dim, action_dim, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(latent_dim + action_dim, hidden), nn.SiLU(),
            nn.Linear(hidden, hidden), nn.SiLU())
        self.mean = nn.Linear(hidden, 1)
        # 方差用 log σ² 输出：恒正且无约束，数值上更稳定
        self.log_var = nn.Linear(hidden, 1)

    def forward(self, z, a):
        h = self.net(torch.cat([z, a], dim=-1))
        return self.mean(h).squeeze(-1), self.log_var(h).squeeze(-1)

def reward_nll(pred_mean, pred_log_var, target):
    # 高斯负对数似然：残差大时 σ 头自动放大，避免被异常值主导
    inv_var = torch.exp(-pred_log_var)
    return 0.5 * (inv_var * (target - pred_mean) ** 2 + pred_log_var).mean()

解读：（1）方差头与均值头共享主干，两路输出在同一批数据上联合优化，σ 起到自动降权异常样本的作用；（2）用 log σ2 输出保证数值稳定，指数运算无溢出风险（配合梯度裁剪）；（3）损失取批量均值，与第 021 章的多任务加权兼容，可作为共享骨干上的一个任务头接入。

片段 2：λ-return 的反向递推

def lambda_return(rewards, values, gamma=0.99, lam=0.95):
    """反向递推计算 λ-return：每一步混合自举项与累积项。"""
    # rewards/values 形状为 [H, B]，H 为想象步长
    H = rewards.shape[0]
    # 末端自举：最后一步之后的价值由价值头给出
    g = values[-1]
    out = torch.zeros_like(rewards)
    for t in reversed(range(H)):
        # λ=0 时退化为 r + γV；λ=1 时退化为完整累积回报
        next_v = values[t] if t == H - 1 else values[t + 1]
        g = rewards[t] + gamma * ((1 - lam) * next_v + lam * g)
        out[t] = g
    return out

解读：（1）反向递推只需一趟循环，每个时刻复用下一时刻的结果，计算复杂度与 H 成正比；（2）价值项参与混合的系数 (1−λ) 与 λ 对应公式中的插值；（3）嵌入无梯度上下文使用时，λ-return 只作为回归目标，梯度不穿过它进入世界模型，保护动力学的表征稳定性；（4）末端自举的 values[-1] 来自价值头在该潜状态上的估计，自举误差通过 γH 衰减后才进入回报。

片段 3：想象中的策略目标组合

def actor_objective(logp, ret, rew_var, kappa=0.5):
    """想象轨迹上的策略目标：回报最大化 + 方差保守化 + 熵正则。"""
    # 方差惩罚：奖励头不确定性高的时刻降低其贡献
    penalty = kappa * torch.sqrt(rew_var.detach())
    adv = (ret - penalty).detach()          # 优势目标不反传进奖励头
    policy_loss = -(logp * adv).mean()      # 策略梯度：提升高优势动作概率
    # 熵正则防止策略过早坍缩，系数与想象步长同量级即可
    entropy = -(logp.detach() * logp).mean()
    return policy_loss - 1e-3 * entropy

解读：（1）惩罚项使用 rewards 方差头的输出并 detach，避免策略把奖励头推往"低估方差"的捷径；（2）优势 adv 同样 detach，策略只消费回报估计，不向奖励预测回传梯度；（3）熵正则系数极小，作用在于防止动作分布方差过早收缩，具体取值与动作空间维度相关；（4）若需要与世界模型联合更新，删去 detach 即可让梯度穿透，代价是动力学表征会被策略目标扰动，训练稳定性下降。

常见坑

  • 奖励尺度漂移未处理：症状是训练前期策略进步快、后期停滞，梯度范数统计显示奖励驱动的更新被淹没。修复：启用运行式标准化，窗口取 5×104 步量级，并监控归一化前后奖励分布的均值与方差。
  • 奖励滞后未对齐：奖励在动作之后若干步出现（如抓起后才给出成功信号），直接按同时刻配对训练奖励头会学出错误的因果关系。修复：按标注延迟量做时间平移对齐，或把奖励建模为动作历史窗口的函数。
  • 奖励黑客：策略学会利用奖励头误差，指标上想象回报上涨、真实环境成功率下降。修复：定期用真实奖励评估奖励头误差，混合真实片段训练，必要时降低想象步长。
  • 信息泄漏：训练奖励头时潜状态 zt 已包含未来帧编码信息，奖励头"看到未来"。修复：确认潜状态为因果编码（只依赖 t 及之前观测），检查世界模型编码器的掩码设计。
  • 折扣因子与步长不匹配：γ = 0.99 时有效跨度约 100 步，而想象步长仅 5 步，远期回报几乎未进入信用链。修复：按任务时长调整 γ，或增大 H，使 γH 落在 0.5 至 0.9 区间。

练习与思考

  1. 任务平均时长约 200 步。若要求 γH ≈ 0.6、H = 15，求合适的 γ（保留三位小数），并说明取 γ = 0.999 时训练会出现的现象。★
    提示
    γ = 0.61/15 ≈ 0.967。γ = 0.999 时有效跨度超过千步，想象回报的方差急剧上升，价值估计难以收敛，实测表现为回报曲线抖动。
  2. 把 λ 从 0.95 改为 0.5，预测想象回报的偏差与方差分别如何变化，以及策略学习速度的走向。★★
    提示
    λ 减小提高自举权重，方差下降、偏差上升（依赖价值估计的质量）；若价值头已较准，学习更稳定；价值头不准时，增加的偏差会拖慢甚至压住策略的改进。
  3. 推导：从 Gtλ = r̂t + γ[(1−λ)V(zt+1) + λGt+1λ] 展开递推，写出 Gtλ 关于各步奖励与末端价值的显式展开式，并解释 λ 的指数权重含义。★★★
    提示
    展开后第 k 步奖励的系数为 (γλ)k，末端价值的系数为 (γλ)H；有效信用视野由乘积 γλ 决定，λ 调节自举与累积的配比，与折扣 γ 各自独立作用。
  4. 设计实验验证奖励归一化的必要性：同一任务在奖励量级 ×1 与 ×100 两种设置下训练，固定其余超参数，预测学习曲线的差异并给出至少两个衡量指标。★★
    提示
    ×100 时策略梯度有效步长放大百倍，早期容易出现动作分布崩塌或回报振荡；指标可用回报曲线面积、成功率、梯度范数中位数。归一化后两种设置的曲线应基本重合。
  5. 设计一个奖励黑客诊断协议：在真实环境中每训练 N 步评估一次，记录想象回报与真实成功率的比值、奖励头在留出集上的误差。给出判定"已发生黑客"的判据与两级修复措施。★★★
    提示
    判据：想象回报持续上升而真实成功率走平或下降，同时奖励头外推误差上升。一级修复为缩短 H 并提高真实片段混合比例；二级修复为冻结策略、重新校准奖励头后再继续。

小结

  • 奖励预测头把潜状态与动作映射为标量信号，为想象 rollout 提供密集监督，缓解真实奖励稀疏的问题。
  • 参数化按奖励类型选择：连续信号用高斯双头，事件信号用分类，偏好数据用排序损失。
  • λ-return 在累积回报与单步自举之间插值，有效信用视野由 γλ 控制。
  • 奖励归一化把有效学习率与奖励量级解耦，滑动窗口长度需要与分布漂移速度匹配。
  • 奖励黑客与奖励滞后是两类典型失效，分别用真实奖励校正与时间对齐处理。
  • 下一章进入模仿学习初始化：用专家数据把策略与世界模型预热到可用起点，再衔接联合训练。
