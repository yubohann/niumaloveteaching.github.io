第三篇 · 策略与世界模型深化

第 058 章：联合训练中的对抗性扰动

对抗扰动在联合训练中扮演双重角色：为世界模型生成分布边缘的困难样本，同时压制策略对模型误差的利用；本章讲清潜空间扰动、对抗 rollout 与稳定化配比。

  • 主题：联合训练 / 鲁棒优化（Robust Optimization）
  • 关键公式：minθ max‖δz‖≤εz E[Lwm(z + δz, a) + λ·Lpol(z + δz, g)]
  • 预计学时：60 分钟
  • 前置章节：第 057 章 世界模型的随机性建模

学习目标

本章把对抗扰动从单模块防御扩展为联合训练内的互适应机制。

  • 理解联合训练中的两类对抗用法：困难样本生成与模型利用（Model Exploitation）压制。
  • 掌握潜空间对抗扰动的构造：扰动球定义、内层最大化目标与相对像素空间的成本优势。
  • 掌握对抗 rollout（Adversarial Rollout）的生成方式：沿想象轨迹施加扰动以放大预测误差。
  • 掌握联合对抗目标的稳定性配置：内外层学习率比例、干净与对抗样本配比、扰动强度课程。
  • 能设计评估协议：最坏情况预测误差、策略在对抗世界模型下的性能与名义性能的差距。

背景与动机

第 041 章处理策略对输入扰动的鲁棒性，威胁模型在策略输入端；本章处理联合训练内部的另一类对抗关系：策略在想象 rollout 中学习时，会主动寻找世界模型误差较大的状态区域，把预测错误当作免费回报，这种行为称为模型利用（Model Exploitation）。被利用的误差叠加误差累积，策略在真实环境中表现为对模型缺陷的过拟合。

对抗扰动提供双向修补：对世界模型一侧，扰动生成分布边缘的困难样本，迫使预测在更宽的状态邻域内保持一致；对策略一侧，在受扰状态下对齐动作输出，削弱对单点预测的依赖。与第 057 章的关系是互补的：随机潜状态表达未来的多样性，对抗扰动则聚焦最坏情况的方向；前者覆盖分布，后者覆盖尾部。本章按机制、构造、稳定、评估的顺序展开。

核心原理

从模型利用的成因出发，给出潜空间扰动、对抗 rollout 与稳定化设计。

1. 模型利用的成因与对抗视角

想象 rollout 的价值由世界模型的回报预测给出。策略优化在模型内进行，模型误差在状态空间中分布不均：个别方向的预测偏差会打开"低成本高回报"的捷径，策略沿捷径收敛，真实环境中回报骤降。对抗视角把这一现象形式化为联合目标的 min-max 结构：外层优化模型与策略参数，内层在状态或潜变量的扰动球内寻找使联合损失最大的方向。训练在"最坏扰动"上降低损失，等价于在状态邻域上要求模型与策略同时保持正确。

minθ max‖δz‖ ≤ εz Etraj[ Lwm(z + δz, a) + λ · Lpol(z + δz, g) ] δz 定义在潜空间，εz 按潜状态范数的比例设定；两项损失共享同一扰动，迫使两侧互适应

2. 潜空间扰动的构造

扰动可以直接定义在潜空间，相对像素空间扰动有三项优势：潜变量维度远低于像素维度，扰动计算成本低；扰动方向直接对应动力学敏感方向，定位模型弱点更直接；且潜空间扰动同时考验动力学头与策略，覆盖两个模块的耦合。构造方式沿用投影梯度上升：δ ← Πε(δ + α·sign(∇δL))，内层步数 3 至 5，步长按 εz/步数设置。

潜空间扰动的适用边界在于语义有效性：潜空间中范数小的扰动可能在解码后对应大幅视觉变化（各维度敏感性不均），因此 εz 的校准以"解码后像素变化量"为基准，先把 εz 调到解码变化与像素扰动 8/255 相当的量级，再开展训练。

数值算例：潜状态平均范数 10、比例 0.1 给出 εz = 1.0；内层 3 步的符号步长为 1/3 ≈ 0.333，累计位移不超过预算。像素侧对照 8/255 ≈ 0.031：若解码验证显示潜位移 0.03 已达该像素量级，实际预算应下调到 0.03 附近，校准把两个空间的尺度直觉对齐。

3. 对抗 rollout 与困难样本

对抗 rollout 把扰动沿时间轴传播：从真实起点出发，世界模型前推的同时在内层寻找扰动序列，使多步累计预测误差最大。生成的困难轨迹有两个用途：其一，作为额外监督样本补进世界模型训练，权重按扰动强度加权；其二，作为策略的困难训练集，配合第 044 章的奖励塑形使用。单步困难样本考验局部敏感性，多步困难轨迹考验误差累积路径，两类样本的互补性来自各自暴露的失效模式不同。

扰动序列的搜索成本随步数线性增长，实践中把内层搜索限制在前若干步，之后固定扰动模式外推，用近似换成本。

4. 稳定化设计

min-max 训练的已知风险是振荡：内层扰动强度变化快于外层参数适应，损失在两个模式间跳变。稳定化配置包含四项：其一，内外层步长比例，内层扰动搜索不参与外层学习率；其二，干净样本占比保持在 70% 以上，对抗样本只定义分布边缘，主分布由干净样本维持；其三，扰动强度课程，从 εz 的 30% 爬升到 100%，给参数适应时间；其四，模型-策略一致性约束，对受扰状态下的动作输出与干净状态输出施加小幅 L2 约束，限定互适应的幅度。

一致性约束的权重需要与对抗损失的量级匹配，过强时策略退化为对扰动不敏感的保守解，与对抗训练的目标相同但成本更高，因此优先用干净配比控制敏感度。

实现思路与设计

训练的每个外层步包含一次内层扰动搜索与一次混合损失更新，成本约为常规联合训练步的 4 至 8 倍。

训练循环

  1. 从真实轨迹与想象轨迹混合采样潜状态批次。
  2. 内层在潜空间执行 3 步投影梯度上升，得到扰动批次。
  3. 外层计算干净损失与对抗损失的加权和，更新世界模型与策略。
  4. 每 1000 步报告最坏情况预测误差与两项损失的比值。

与第 041 章的区别

第 041 章的威胁模型在策略输入像素，目标是策略自身的鲁棒；本章的扰动定义在潜空间，目标是世界模型与策略的互适应，损失同时覆盖两个模块。两章共享投影梯度上升的实现骨架，但作用对象、损失组成与评估口径不同：前者报告失稳比例，本章报告最坏预测误差与名义性能差距。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖潜空间扰动、对抗 rollout 生成与混合损失。数值与上表一致。

片段 1：潜空间投影梯度扰动

import torch
import torch.nn.functional as F

def latent_perturbation(world_model, policy, z, actions, goals, eps_ratio=0.1, steps=3):
    """在潜空间内搜索使联合损失最大的扰动。
    设计意图：潜维度远低于像素维度，扰动搜索直接指向动力学敏感方向。"""
    scale = z.norm(dim=-1, keepdim=True).mean()      # 用平均范数设定球半径
    eps = eps_ratio * scale
    delta = torch.zeros_like(z, requires_grad=True)
    with torch.enable_grad():
        for _ in range(steps):
            z_adv = z + delta
            # 联合损失：世界模型预测误差加策略条件损失，两侧共享扰动
            loss_wm = F.mse_loss(world_model.predict(z_adv, actions),
                                 world_model.predict(z, actions).detach())
            loss_pol = policy.condition_loss(z_adv, goals)
            loss = loss_wm + 0.5 * loss_pol
            grad = torch.autograd.grad(loss, delta)[0]
            with torch.no_grad():
                delta = delta + (eps / steps) * grad.sign()   # 符号方向均分步长
                delta = delta.clamp(-eps, eps)                # 投影回扰动球
            delta.requires_grad_(True)
    return (z + delta).detach()

解读：（1）球半径按潜状态平均范数的比例设定，比固定数值对尺度变化更稳健；后续用解码变化量复核，如果解码后变化远超像素 8/255 量级应下调比例。（2）世界模型损失以干净预测为参照目标，度量的是扰动导致的一致性破坏；参照目标 detach 后不反向传播。（3）步长用 eps/steps 均分，保证三步累计不超过预算；内层循环只更新扰动，不触碰模型参数，梯度图每轮重建避免累积。

片段 2：对抗 rollout 的困难轨迹生成

@torch.no_grad()
def adversarial_rollout(world_model, z0, action_seq, search_steps=4, eps_ratio=0.1):
    """沿想象轨迹传播扰动，放大多步累计预测误差。"""
    z = z0
    delta_fixed = None
    hard_trajs = []
    for t, action in enumerate(action_seq):
        if t < search_steps:
            # 前若干步内层搜索：估计当前敏感方向并记录扰动
            z_adv = latent_perturbation(world_model, world_model.policy_head,
                                        z, action, goals=None, eps_ratio=eps_ratio)
            delta_fixed = (z_adv - z).detach()
        else:
            # 搜索窗口之外沿用最后的扰动方向：用近似换成本
            z_adv = z + delta_fixed
        z = world_model.step(z, action)              # 干净轨迹继续推进
        z_adv = world_model.step(z_adv, action)      # 受扰轨迹同步推进
        hard_trajs.append(z_adv)
    return torch.stack(hard_trajs, dim=1)            # 供困难样本训练使用

解读：（1）受扰轨迹与干净轨迹同步推进，两者共享动作序列，差异全部来自初始扰动的传播效应，困难程度可直接量化。（2）搜索限定在前 4 步：扰动敏感方向在短时间内变化有限，窗口外的固定扰动是成本近似，若验证显示敏感方向漂移明显再扩大窗口。（3）生成的困难轨迹进入世界模型训练时按扰动强度加权，避免困难样本数量在不平衡时压过主分布。

片段 3：干净与对抗混合的联合损失

def robust_joint_loss(model, batch, adv_ratio=0.3, adv_weight=0.5, consistency=0.1):
    """联合训练步的混合损失：干净分支为主，对抗分支定义边缘。"""
    z, actions, goals, targets = batch
    n_adv = int(z.size(0) * adv_ratio)
    # 干净分支：标准联合损失，维持主分布拟合能力
    loss_clean = model.joint_loss(z, actions, goals, targets)
    if n_adv > 0:
        z_sub = z[:n_adv]
        z_adv = latent_perturbation(model.world_model, model.policy,
                                    z_sub, actions[:n_adv], goals[:n_adv])
        # 对抗分支：在最坏扰动上降低联合损失，权重低于干净分支
        loss_adv = model.joint_loss(z_adv, actions[:n_adv], goals[:n_adv], targets[:n_adv])
        # 一致性项：限定受扰与干净状态下动作输出的差异幅度
        loss_cons = (model.policy(z_adv, goals[:n_adv])
                     - model.policy(z_sub, goals[:n_adv]).detach()).pow(2).mean()
        return loss_clean + adv_weight * loss_adv + consistency * loss_cons
    return loss_clean

解读：（1）对抗样本从批内切片生成，比例参数直接控制成本与配比两个维度。（2）对抗损失复用同一 joint_loss 接口，确保两个分支的监督口径一致，差异只来自输入。（3）一致性项以干净输出为参照，把互适应幅度显式限定；缺少它时对抗分支可能把策略推向与干净行为差异过大的解。

常见坑

  • 扰动预算未经解码校准：εz 按潜范数设定但在解码后对应巨大的视觉变化，困难样本语义失真。修复：用解码变化量校准预算，对齐像素扰动 8/255 量级。
  • 内层搜索步数过多：单步成本随步数线性上升，边际收益很小。修复：3 至 5 步封顶，把预算转向配比与课程。
  • 对抗样本占比过高：主分布拟合退化，名义性能下降。修复：占比控制在 30% 以内，报告干净与对抗两组指标。
  • 只用视觉扰动：忽略了动作条件与潜状态的耦合方向，模型误差仍被利用。修复：扰动在潜空间搜索，联合损失同时覆盖预测与条件两个头。
  • 评估不用攻击对照：训练报告好看，部署时被模型自身的误差捷径击败。修复：评估包含最坏扰动扫描，报告名义与最坏性能的差距。

练习与思考

  1. 推导：说明为什么 min-max 目标中的内层最大化可用有限步投影梯度近似，并解释扰动强度课程如何影响内外层更新的相对速度。★★
    提示
    内层是非凹问题，有限步只能近似局部最优；强度课程让 εz 缓慢上升，避免内层目标突然变陡导致外层跟不上。
  2. 把对抗样本占比从 0.3 提到 0.6，预测三件事的变化：干净分布预测误差、最坏情况误差、训练单步成本，并说明验证方式。★★
    提示
    干净误差上升，最坏误差先降后平，成本随占比近似线性。验证：固定步数比较两组曲线的交叉与各自收敛水平。
  3. 设计一个"模型利用检测"实验：构造策略在想象中回报上升而真实环境中下降的场景，说明要记录哪些量、如何归因到模型误差。★★★
    提示
    记录想象回报与真实回报的差值曲线；把想象轨迹回放于真实环境，比较动作序列的预测结果与实际结果，差值集中在哪些状态段即误差来源。
  4. 讨论：潜空间扰动与像素空间扰动各自的成本与覆盖范围差异，说明组合使用时如何分配预算。★★
    提示
    像素扰动覆盖感知链路但计算贵；潜扰动覆盖动力学与策略耦合且便宜。常见分配：像素扰动低频批处理用于感知鲁棒，潜扰动高频用于联合步。

小结

  • 联合训练中的对抗扰动同时服务困难样本生成与模型利用压制，形式化为参数外层与扰动内层的 min-max 结构。
  • 潜空间扰动成本低、方向敏感，预算以解码变化量为基准校准。
  • 对抗 rollout 把扰动沿时间传播生成困难轨迹，搜索窗口用近似换成本。
  • 稳定化配置包含步长比例、干净占比、强度课程与一致性约束四项。
  • 评估必须报告最坏扰动误差与名义性能差距，训练报告不能替代攻击对照。
