第一篇 · 基础框架与联合训练

第 001 章：搭建VLA与世界模型联合训练的基础框架

本章给出全课骨架：把输出动作的 VLA 策略与预演未来的世界模型放进同一训练循环，讲清三模态输入、动作块输出、共享主干与双头损失，并落到一份可运行风格的 PyTorch 结构。

  • 主题：VLA 策略 / 世界模型 / 联合训练总览
  • 关键公式：Ljoint = Lwm + λ·Lpolicy
  • 预计学时：60 分钟
  • 前置章节：无（本课程从这里开始）

学习目标

  • 建立联合训练（Joint Training）总图：VLA 策略与世界模型各自的输入、输出与动作接口。
  • 理解三模态输入（视觉、语言、本体感知）与动作块（Action Chunk）输出表示。
  • 理解世界模型（World Model）作为可学习模拟器的定位，以及想象 rollout（Imagination Rollout）的含义。
  • 掌握联合损失 Ljoint = Lwm + λ·Lpolicy 的构成与梯度路径，认识尺度失衡问题。
  • 会写共享主干加双头的 PyTorch 骨架，能诊断联合训练中的典型不稳定现象。
  • 能设计小规模联合训练对比实验，用可量化指标验证收益。

背景与动机

本章回答：VLA 策略与世界模型为何同训、以何接口耦合、损失如何组合。单独训练 VLA 策略依赖大规模示教数据，且只在见过的状态分布上可靠；单独训练世界模型只得到预测能力，无法直接完成任务。联合训练让同一份数据同时监督“如何行动”与“行动会导致什么”，两个任务的表征互相注入，数据效率与泛化能力同时受益。

该思路在公开工作中反复出现：RT 系列与 OpenVLA 系列展示视觉语言动作模型（Vision-Language-Action, VLA）的端到端训练，Dreamer 系列展示潜空间（Latent Space）世界模型上的想象 rollout 替代部分真实交互，扩散策略（Diffusion Policy）把动作生成建模为条件去噪过程。本课程统一为：策略生成动作，世界模型预演后果，训练共享数据与表征。

本章立起骨架，后续逐块展开：数据预处理（002）、下一帧预测（003）、动作生成（004）、损失设计（005）、想象轨迹与交替训练（006–008）、梯度流分析（009）。

核心原理

1. 两个组件与一个动作接口

VLA 策略是观测与语言到动作的映射，世界模型是观测与动作到未来观测的映射，动作是二者唯一需要的耦合变量。

πθ(at:t+H-1 | ot-k:t, l) θ 为策略参数；o 为视觉观测，l 为语言指令；k 为上下文帧数（1–2），H 为动作块长度（8–16）
pϕ(ot+1:t+m | o≤t, a≤t) ϕ 为世界模型参数；m 为预测步长（5–15）；条件中的 a≤t 说明预测受动作驱动

两式共享 t 之前的观测，区别在输出：策略给出动作块，世界模型给出未来观测或其潜空间表示。联合训练时历史动作来自数据集，想象 rollout 时由策略生成，世界模型进入自回归推演。

2. VLA 的三模态输入与动作块输出

三路模态的物理含义与时间基准是后续对齐操作的基础：

  • 视觉：RGB 帧，输入尺寸常规为 224×224 或 256×256，经分块（Patchify）成为 token 序列；短历史窗口（k 取 1–2）以低成本携带运动信息。
  • 语言：指令经分词嵌入，长度截断在 32–64 token，承载任务语义与目标物体描述。
  • 本体感知（Proprioception）：关节角、夹爪开度、末端位姿等低维向量，维度常见 7–16，用于消除视觉歧义（同一画面下不同姿态对应不同动作）。

输出端动作块指一次前向预测 at:t+H-1 ∈ RH×da，单步维度 da 例如 6 关节加 1 夹爪为 7。动作块的价值在于摊薄推理开销：10 Hz 控制、H=16 时策略每秒推理不足一次；代价是块内对突发变化的响应变慢，块长即“响应性对计算量”的折中。动作表示分连续回归、离散 token 自回归、条件扩散去噪三类，004 章展开。

用数字核对摊薄效果：控制频率 10 Hz 对应控制周期 0.1 秒，H=16 的动作块覆盖 1.6 秒。若每个控制步都调用策略，1 秒需要 10 次前向；改为滚动时域、每执行 8 步重规划一次，1 秒只需 1.25 次前向，调用量降到八分之一。代价同样可量化：块内不引入新观测，突发变化最长延迟 0.8 秒才被重规划吸收。

3. 世界模型：可学习模拟器

世界模型的定位是用学习得到的动力学替代真实环境的前向演化，让训练在“想象”中扩充数据。像素空间模型直接预测未来图像，直观但计算量大；潜空间模型先编码观测为 zt，再学动力学 p(zt+1 | z≤t, a≤t) 与解码器 p(ot | zt)，计算量小、抽象程度高。

多步开环预测的误差累积是固有难点：每步误差被动力学继续放大，上界随步数增长。

E‖ôt+k - ot+k‖ ≤ Σi=1..k Ldynk-i · εi Ldyn 为动力学 Lipschitz 常数，εi 为第 i 步单步误差；Ldyn 大于 1 时误差逐级放大

由此得两个原则：训练用短展开控制放大，使用时把单次想象限制在 5–15 步。003、006、011 章分别从下一帧预测、想象轨迹、动作条件视频预测深化。

4. 联合训练的信息流与梯度路径

基本拓扑是“共享主干 + 双头”：共享主干 ψ 同时服务策略头与预测头，两路损失在 ψ 上叠加。共享是表征效率的来源，也是训练不稳定的来源：同一参数同时接收两个任务梯度，量纲差异直接体现在更新方向上。

Ljoint(θ, ϕ; ψ) = Lwm(ϕ; ψ) + λ · Lpolicy(θ; ψ) λ 为策略损失权重（默认 0.5）；两项都依赖共享主干 ψ
∇ψLjoint = ∇ψLwm + λ · ∇ψLpolicy 两路梯度线性叠加；范数相差一个数量级以上时，小的一路近似被抑制

处理手段有三类：调整 λ、对损失做同量纲归一化、在部分路径上切断梯度（Stop-gradient），取舍与诊断留到 009 章。先记住结论：联合训练的第一调控旋钮是两路损失的相对尺度。

5. 目标函数的分工

世界模型损失混合两种模式：教师强制（Teacher Forcing）以真实观测为条件预测下一帧，信号稳定；短展开以自生成潜变量继续推演，缓解分布偏移（Exposure Bias）。策略损失按动作表示选择：连续动作用 Huber，扩散生成用去噪均方误差，离散 token 用交叉熵；完整组合见 005 章。

6. 数值算例：损失尺度失衡的量化

设某步的世界模型损失 Lwm = 2.0、策略损失 Lpolicy = 0.2，λ 取默认 0.5。代入 Ljoint = Lwm + λ·Lpolicy 得 2.1，策略路贡献 0.1，占比 4.8%。若希望两路贡献对等，需要 λ = 10，与默认值相差 20 倍。四个 λ 档位的对比：

λ总损失策略路贡献策略占比
0.052.010.010.5%
0.5（默认）2.100.104.8%
2.02.400.4016.7%
10.04.002.0050.0%

该表给出两点判断依据。其一，固定权重下的稳定平衡通常不存在：两路损失量级随数据与训练阶段变化，某一时刻合适的 λ 到下一阶段可能失衡十倍。其二，损失占比只作近似：真正决定更新方向的是两路梯度范数，经过非线性层后损失占比与梯度占比不再相等，005 章的运行归一化与不确定性加权针对这一差距。

∂Ljoint/∂ψ = ∂Lwm/∂ψ + λ·∂Lpolicy/∂ψ 对共享主干 ψ 的更新方向由两路梯度的向量和决定；夹角大于 90° 时两路梯度互相抵消，等效步长下降

再算一次前向规模，作为显存与算力的估算起点。视觉前端用 6×6 卷积、步长 6 处理 224×224 输入：输出边长 floor((224-6)/6) + 1 = 37，每帧 1369 个 token，图像右侧与下边缘各 2 像素未被覆盖。加上 1 个本体 token 与 48 个语言 token，单帧序列长度 1418；上下文取 k=2 帧时长度约 2787，注意力矩阵规模约 7.8×106 项，这是 016 章显存预算公式中的主导项。

7. 两路梯度叠加的几何

把权重调节的效果放到向量空间观察更清楚。设世界模型梯度范数 ‖gwm‖ = 2.0，策略梯度范数 ‖gpolicy‖ = 0.2，夹角 60°，λ = 0.5。合成梯度范数为 sqrt(4 + 0.01 + 2×0.5×2.0×0.2×0.5) ≈ 2.05，相对原方向只增加约 2.6%；合成方向与原方向的夹角约 2.4°。若把策略梯度范数换成 1.0，其余不变，偏转角增至约 11°。量级落后一个数量级的路径，即便权重不为零，对更新方向也几乎没有塑形能力。005 章的归一化把两路拉回同量级后再谈权重，正是为了让 λ 的每个刻度都产生可测量、可解释的效果。

8. 适用边界与失效模式

联合训练不是默认更优的配置，以下条件会让收益缩小甚至反向。这些条件适合在实验开始前逐条检查，比训练出现异常后再归因的代价低得多：

  • 两路任务的表征需求冲突：预测任务需要保留光照与纹理细节，动作决策只需要任务相关量。冲突强时共享主干在两组特征方向之间折中，两路指标同时低于单独训练。判据是 009 章的干涉诊断：任务间梯度余弦长期为负。
  • 世界模型不可信：预测误差较大的阶段，其输出作为监督信号等于噪声源，策略任务被带偏。此类状态需要先做预热或对预测路径降权，机制见 007 章与 005 章。
  • λ 取到极端：λ 趋近零时联合退化为世界模型单独训练，λ 过大时策略项淹没预测项，共享表征失去动力学塑造。工程上把 λ 搜索范围限制在 0.05 到 10，超出即按配置异常处理。
  • 时间对齐错误：三路模态时间基准不一致时两路损失都能下降，学到的映射却错位，闭环指标与训练指标背离。数据侧校验（002 章）是唯一可靠的防线，损失曲线无法代替。
  • 算力预算不足：两个头共享一次前向，但激活显存高于任一单独任务，长窗口联合训练进一步放大占用。缓解顺序为梯度检查点、混合精度、梯度累积（016 章）；降低批量时必须同步下调学习率，单独降批量会让训练动态偏离标定条件。

共享程度本身是一条连续谱：完全共享、主干共享加独立头、多层共享、完全独立。共享越深，表征复用越充分，任务干扰也越直接。本课骨架取主干共享加独立头作为默认；加深共享的判据是可度量的：两路验证指标都劣化时退回浅共享，010 章给出层间共享的细化设计。判据建议写进实验配置：共享加深后任一路验证指标劣化超过 2% 即回退，两路同时持平或改善才保留加深。

实现思路与设计

实现可拆成六环节：按 episode 切出长度 k+H+m 的时间窗；视觉与语言前端独立编码，本体感知线性映射；三模态 token 拼接过共享主干；策略头生成动作块，预测头输出下一潜变量；两路损失加权求和并分项监控；梯度汇入主干，裁剪后统一更新。

训练组织方式对比

联合训练有四种组织方式，取舍落在数据利用、稳定性与工程复杂度三条轴上：

组织方式数据利用稳定性工程复杂度
独立训练两个模型各自单任务监督高低，推理需串联两个模型
两阶段串行（先预测后策略）预测侧得不到策略信号高中，含阶段切换
同步联合单份数据同时驱动两个头低，需控制尺度低
交替联合（007 章）接近同步联合，有阶段损失中，依赖排班中

选择顺序建议为：先跑同步联合基线，出现持续失衡再切交替，表征需求冲突明显时才退回两阶段串行。

差异点：本章只求能跑通的骨架，深度融合、rollout 策略、交替训练分别由 010、006、007 章展开。

关键代码与解读

以下片段以各开源实现的公开设计为参照（RT 系列、OpenVLA、Dreamer 系列、扩散策略），接口随版本演进。第 1 段给出共享主干与双头结构。

片段 1：共享主干与双头的模块骨架

import torch
import torch.nn as nn

class VLAWorldModel(nn.Module):
    """联合训练最小骨架：共享主干 + 策略头 + 世界模型头。"""
    def __init__(self, d_model=512, depth=8, nhead=8,
                 action_dim=7, chunk=16, latent_dim=256, vocab=32000):
        super().__init__()
        # 视觉前端：6x6 大核大步长卷积把 224x224 图快速降采样为 patch 序列，省算力
        self.patch = nn.Conv2d(3, d_model, kernel_size=6, stride=6)
        # 语言前端：指令 token 嵌入表；词表大小与所用分词器一致
        self.text_embed = nn.Embedding(vocab, d_model)
        # 本体感知前端：关节角与夹爪等低维状态映射到主干维度，消除视觉歧义
        self.proprio = nn.Linear(9, d_model)
        # 共享主干：三模态 token 拼接后统一做自注意力，两路任务共享该融合表征
        layer = nn.TransformerEncoderLayer(d_model, nhead, 4 * d_model,
                                           batch_first=True, norm_first=True)
        self.trunk = nn.TransformerEncoder(layer, num_layers=depth)
        # 策略头：可学习动作查询，一次前向产出整段动作块，摊薄推理开销
        self.action_queries = nn.Embedding(chunk, d_model)
        self.action_head = nn.Linear(d_model, action_dim)
        # 世界模型头：把融合表征投影到下一时刻潜变量，供 rollout 使用
        self.world_head = nn.Sequential(nn.Linear(d_model, d_model), nn.GELU(),
                                        nn.Linear(d_model, latent_dim))

    def forward(self, image, text_ids, proprio):
        # 图像 (B,3,224,224) 经卷积与展平得到 (B,L,d_model) 的视觉 token
        vis = self.patch(image).flatten(2).transpose(1, 2)
        txt = self.text_embed(text_ids)                 # (B,T,d_model)
        prop = self.proprio(proprio).unsqueeze(1)       # (B,1,d_model)
        # 三模态按固定顺序拼接：视觉、本体、语言；顺序固定避免跨章对齐混乱
        tokens = torch.cat([vis, prop, txt], dim=1)
        memory = self.trunk(tokens)                     # 融合表征 (B,L+T+1,d)
        pooled = memory.mean(dim=1)                     # 全局池化得到场景与指令摘要
        # 动作查询加摘要广播：一次矩阵广播生成整块动作 (B,chunk,action_dim)
        q = self.action_queries.weight.unsqueeze(0)
        action = self.action_head(q + pooled.unsqueeze(1))
        z_next = self.world_head(pooled)                # 预测下一时刻潜变量
        return action, z_next

解读：（1）模块划分遵循“前端独立、主干共享”，避免早期梯度互扰。（2）视觉前端用 6×6 大步长卷积代替标准分块嵌入，是缩放算力的常用手段。（3）动作查询与场景摘要相加后广播，等价于同一场景下并行生成 H 个动作槽位；真实系统常用解码器注意力读取视觉 token，004 章给该变体。（4）forward 同时返回动作与潜变量，共享主干只前向一次，两路损失复用同一份计算。

片段 2：联合损失合成

def joint_loss(action_pred, action_gt, z_pred, z_gt, lam=0.5, valid_mask=None):
    """两路监督合成为一个目标：世界模型损失 + λ 倍策略损失。"""
    # 动作损失用 Huber：示教数据偶有离群动作，L2 会放大其影响，Huber 更稳
    l_pol = nn.functional.huber_loss(action_pred, action_gt, reduction="none")
    if valid_mask is not None:
        # 变长 episode 尾部用掩码剔除，避免补零动作污染训练信号
        l_pol = (l_pol * valid_mask.unsqueeze(-1)).sum() / valid_mask.sum().clamp(min=1)
    else:
        l_pol = l_pol.mean()
    # 世界模型损失用余弦相似度：潜变量只约束方向与结构，不强制绝对尺度对齐
    l_wm = (1.0 - nn.functional.cosine_similarity(z_pred, z_gt, dim=-1)).mean()
    # λ 控制两路梯度比例：起步 0.5，训练中按两路损失量级微调
    total = l_wm + lam * l_pol
    return total, {"policy": float(l_pol), "world": float(l_wm)}

解读：（1）两路分开计算再合成，物理含义与量纲不同，分开才能分别监控与调权。（2）返回标量字典是诊断梯度失衡的前置条件：观察到两路损失曲线，才能判断谁在主导更新。（3）余弦相似度仅作示意，003 章改用像素重建与感知损失组合。

片段 3：一步联合更新

def train_step(model, opt, batch, lam=0.5, clip=1.0):
    """一步联合更新：单份 batch 同时驱动两个头，共享主干一次反向。"""
    image, text_ids, proprio, action_gt, z_gt, mask = batch
    model.train()
    action_pred, z_pred = model(image, text_ids, proprio)   # 单次前向复用
    loss, parts = joint_loss(action_pred, action_gt, z_pred, z_gt, lam, mask)
    opt.zero_grad(set_to_none=True)     # 置空代清零：省一次张量分配，显存更友好
    loss.backward()                     # 两路梯度在此叠加到共享主干参数上
    # 梯度裁剪：两路叠加后范数易现尖峰，裁到 1.0 防止单步更新过猛
    torch.nn.utils.clip_grad_norm_(model.parameters(), clip)
    opt.step()
    return parts                        # 返回分量供训练曲线监控

解读：（1）一次前向、一次反向，这正是联合训练相对“轮流训练两个模型”的算力优势。（2）裁剪阈值 1.0 是常规起步值，作用是限制最坏情况下的有效学习率。（3）此片段为朴素同步更新；007 章给出交替训练策略，用于两任务学习速率差异较大的情形。

常见坑

  • 模态时间对齐错位：图像与动作相差一帧，相邻帧差异小，损失曲线看不出异常，闭环性能却明显偏低。修复：按时间戳索引对齐，抽查动作起止两端与前后帧的对应关系。
  • 梯度尺度失衡：预测损失数值大一到两个数量级，主干被预测任务主导，动作误差下降缓慢。修复：损失归一化到同量级、下调 λ 或对预测路径切梯度。
  • 动作时空分辨率不匹配：数据 10 Hz 采集、模型按 50 Hz 设定时间步，模型学到的“一步”差 5 倍，动作幅度系统性偏大或偏小。修复：数据层统一下采样，配置中显式标注 dt。
  • 未来信息泄漏：窗口切片把 t 之后的观测接入当前编码，训练损失异常低、开环执行迅速失败。修复：对窗口索引写单元测试，断言编码端最大索引不超过 t。
  • 双头容量分配失衡：主干过窄使两个任务互相干扰，两路损失此消彼长。修复：增大 dmodel，或给两个头加任务专用适配器（Adapter）。

练习与思考

  1. 图像 224×224、卷积核 6×6、步长 6，动作块 H=16，语言 token 上限 48。计算进入主干的 token 数，并解释本体感知为何只占 1 个 token。★
    提示
    视觉 (224/6)² ≈ 1369，加 1 个本体加 48 个语言。低维状态映射为单 token 已足以携带信息，增加 token 收益很小。
  2. 把 λ 从 0.5 改为 0.05，其他配置不变，预测两路损失曲线与动作误差的走向并说明依据。★
    提示
    策略梯度压缩约 10 倍，动作损失下降变慢，主干更偏向预测任务；动作指标同时恶化则需回调 λ 或改用归一化。
  3. 证明 k 步开环误差上界为 Σ Ldynk-iεi，讨论 Ldyn 接近 1 与大于 1 的实践含义。★★
    提示
    对递推归纳：每步误差先放大 Ldyn 倍再叠加新噪声。略小于 1 时收敛到常数倍，大于 1 时指数增长。
  4. 设计消融实验：同一数据集与参数量下比较仅策略训练、仅世界模型训练、联合训练，给出两个可量化指标与预期结论。★★
    提示
    指标：动作验证集 L1 误差与多步预测误差。预期联合训练两项均不低于单独训练，数据量减半时优势更明显。
  5. 把共享主干拆成两个独立分支、总参数量翻倍，与共享主干对比相同步数的表现，说明如何做到公平比较。★★★
    提示
    公平性要点：优化器、批量、步数一致，独立分支需缩减宽度使总参数量对齐。

小结

  • 联合训练总图：策略 πθ(a | o, l) 输出动作块，世界模型 pϕ(o' | o, a) 预演后果，动作是耦合接口。
  • 三模态输入（视觉、语言、本体感知）与动作块输出（H 取 8–16）是后续全部章节的公共约定。
  • 世界模型的可学习模拟器定位与误差累积机理决定单次想象长度限制在 5–15 步。
  • Ljoint = Lwm + λ·Lpolicy 的两路梯度在共享主干叠加，第一调控旋钮是损失相对尺度。
  • 骨架代码四要点：前端独立、主干共享、双头单次前向、分量监控。
