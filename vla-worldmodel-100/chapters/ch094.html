第 094 章：联合训练中的多模态对比学习

用 InfoNCE 把观测、语言与动作拉进同一表示空间：困难负样本挖掘、动量编码器与梯度冲突监控，让对比目标真正服务联合训练。

  • 主题：联合训练（joint training）/ 多模态对比学习（multimodal contrastive learning）
  • 关键公式：InfoNCE 损失与对齐均匀性分解
  • 预计学时：50 分钟
  • 前置章节：第 093 章

学习目标

  • 理解对比学习在联合训练中的位置：跨模态正样本构造与 InfoNCE 的梯度语义。
  • 掌握对齐性（alignment）与均匀性（uniformity）两个指标，能用它们诊断表示空间质量。
  • 掌握困难负样本挖掘与假负样本过滤的工程细节，理解温度与负样本量的相互作用。
  • 会使用动量编码器与队列扩大负样本规模，理解动量系数的稳定性含义。
  • 会监控对比损失与模仿损失的梯度冲突，设计权重与调度方案。

背景与动机

对比学习为联合训练提供第三种监督形态：不依赖回归标签与生成重建，用"相似与不相似"的关系塑造表示。观测、语言与动作天然存在对应关系（同一时刻的三元组互为正样本），对比目标把这种关系转化为表示空间的几何约束：正样本靠近、负样本远离。相比重建目标，对比目标的容量不会消耗在像素细节上，判别性特征被优先保留。

第 067 章讨论了对比学习的一般框架，本章聚焦联合训练中的多模态扩展：动作模态如何参与对比、困难负样本与假负样本如何区分、对比损失与模仿损失的梯度如何协调。这些细节决定对比目标带来的是增益还是干扰。第 092 章的语言对齐损失是本章的特例，本章把对齐面扩展到视觉与动作，形成完整的三元组约束。

核心原理

对比学习的核心是一个可调温度下的分类问题：批次内为每个锚点找出正确的配对，表示空间在"拉近正样本、推远负样本"的博弈中成形。

1. InfoNCE 与梯度语义

给定锚点 zi 与候选池 {z+, z−j}，InfoNCE 损失为：

L = − log [ exp( s(zi, z+) / T ) / ( exp( s(zi, z+) / T ) + Σj exp( s(zi, zj−) / T ) ) ] s 为余弦相似度；T 为温度；分母遍历正样本与全部负样本

对相似度求梯度可获得直观理解：正样本对收到"提升相似度、幅度正比于当前错误概率"的梯度；负样本对被推远，且被模型误判为难负样本的动作收到最大梯度。这解释了负样本质量的重要性：随机负样本与锚点差异大，梯度早饱和；与锚点接近但语义不同的负样本提供最有效的学习信号。

2. 对齐性与均匀性

对比表示的质量可用两个互补指标刻画：

  • 对齐性：正样本对相似度的期望，越大越好；
  • 均匀性：全部表示两两相似度的对数期望，越小说明表示铺得越开。

联合训练中要同时监控两者：对齐性好而均匀性差说明表示聚成少数簇，遇到新组合时无法区分；均匀性好而对齐性差说明正样本没有真正拉近，跨模态迁移失效。两个指标同时记录在训练日志中，对比不同负样本策略时以前者定位问题、以两者联合评估收益。

3. 困难负样本与假负样本

挖掘困难负样本的常规做法：按相似度排序取 top-k 非正样本对，混入训练损失。其风险来自假负样本：同一语义的不同样本被当作负样本（同一指令在相邻时刻的两个观测），推远它们会损害表示。过滤规则：同一轨迹时间距离小于窗口（例如 10 帧）的样本对不互为负样本；同一任务的语义近邻按相似度分布设置阈值。过滤会缩减负样本池，用动量队列补回规模。

4. 动量编码器与队列

负样本量与批次大小绑定，批量受限时可用队列：把历史批次的表示入队，当前锚点对队列内表示计算负样本损失。队列表示由较早参数生成，与当前参数不一致会引入偏差，动量编码器（参数按 θtarget ← m·θtarget + (1 − m)·θonline 缓动）让新旧表示分布接近，m = 0.999 对应约 1000 步的时间常数。队列中样本的"负样本身份"同样要维护：过期正样本对需要剔除。

实现思路与设计

对比分支挂接在共享潜空间之后：三类投影头输出对比嵌入，损失与模仿、预测损失相加，权重调度按训练阶段调整。

  1. 正样本构造：同一时间步的 (观测, 语言指令, 动作块) 互为正样本；相邻时刻（10 帧内）的观测不作为彼此负样本。
  2. 负样本池：批次内负样本加动量队列（4096 条），每条记录来源任务与轨迹编号用于过滤。
  3. 温度：可学习参数，初值 0.07；过低（0.02 以下）易坍缩，过高区分度不足。
  4. 损失权重：前 1e4 步从 0.05 线性升到 0.3，避免早期压制模仿学习；后期维持 0.2。
  5. 与第 067 章的差异：对齐面从两模态扩展到三元组，加入队列、困难负样本与梯度冲突监控；与第 092 章的对比损失统一到同一框架。

设计决策：为什么温度设为可学习参数？

固定温度需要为每个数据集与训练阶段重新调参：早期表示粗糙，合适温度偏高；后期表示精细，温度应下降放大区分度。让温度随梯度学习，等价于自动调节"损失锐度"，收敛后温度往往落在 0.05–0.1 区间。学习率的设置要单独约束（比主学习率高一个量级但设上限），否则温度可能发散到无效区域。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：InfoNCE 与动量编码器

def info_nce(z_a, z_b, temperature=0.07):
    """InfoNCE：对角线为正样本，其余配对为负样本。"""
    z_a = F.normalize(z_a, dim=-1)               # 单位化：内积即余弦相似度
    z_b = F.normalize(z_b, dim=-1)
    logits = z_a @ z_b.t() / temperature         # (B, B) 相似度矩阵
    labels = torch.arange(z_a.size(0), device=z_a.device)
    return F.cross_entropy(logits, labels)       # 行方向分类：为每个锚点找配对

def momentum_update(online, target, m=0.999):
    """动量编码器：目标侧参数缓慢跟踪在线侧，供队列表示保持分布一致。"""
    with torch.no_grad():                        # 目标侧不参与优化器更新
        for p_on, p_tg in zip(online.parameters(), target.parameters()):
            p_tg.mul_(m).add_(p_on, alpha=1.0 - m)   # 指数移动平均

解读：info_nce 把对比学习实现为"配对检索"的分类任务，交叉熵目标与公式逐项对应；批次内每个锚点的负样本即其他样本，批量越大负样本越丰富。normalize 把表示约束到单位球面，模长自由度被移除，相似度语义纯净。动量更新的 mul_ 与 add_ 是原地操作，避免为参数副本分配显存；系数使用经验值 0.999，队列很长时也可用 0.9999。目标编码器与在线编码器共享结构，初始化时复制参数。

片段 2：困难负样本挖掘与过滤

def hard_negatives(z_anchor, z_pool, pos_idx, traj_id, frame_id, topk=4, window=10):
    """取最相似的候选作为困难负样本，并过滤同轨迹近邻（假负样本）。"""
    sim = F.normalize(z_anchor, dim=-1) @ F.normalize(z_pool, dim=-1).t()
    B = z_anchor.size(0)
    # 屏蔽正样本本身
    sim[torch.arange(B), pos_idx] = -float("inf")
    # 屏蔽同轨迹且时间接近的候选：它们是语义近正样本
    same_traj = traj_id[:, None] == traj_id[None, :]
    near_time = (frame_id[:, None] - frame_id[None, :]).abs() <= window
    sim[same_traj & near_time] = -float("inf")
    idx = sim.topk(topk, dim=-1).indices        # (B, topk)
    return z_pool[idx]                          # 困难负样本嵌入

解读：相似度矩阵同时承担两个功能：排序取 top-k 与掩码过滤。traj_id 与 frame_id 是数据管道的附加元信息，让过滤规则可执行；没有这两个字段时只能靠相似度阈值近似。-inf 屏蔽保证被排除项不会出现在 top-k 结果中。困难负样本在损失中作为额外负样本与批次负样本拼接使用；若与队列负样本混用，需保持温度一致，否则两组的梯度尺度失衡。

片段 3：梯度冲突监控

def grad_cosine(model, loss_main, loss_aux, params=None):
    """两组损失的梯度余弦：接近 -1 表明目标冲突，需调整权重或调度。"""
    if params is None:
        params = [p for p in model.parameters() if p.requires_grad]
    g_main = torch.autograd.grad(loss_main, params, retain_graph=True, allow_unused=True)
    g_aux = torch.autograd.grad(loss_aux, params, retain_graph=True, allow_unused=True)
    # 拼接为扁平向量；缺失梯度用零填充，保证两组维度对齐
    flat_main = torch.cat([(g if g is not None else torch.zeros_like(p)).reshape(-1)
                           for g, p in zip(g_main, params)])
    flat_aux = torch.cat([(g if g is not None else torch.zeros_like(p)).reshape(-1)
                          for g, p in zip(g_aux, params)])
    return F.cosine_similarity(flat_main.unsqueeze(0), flat_aux.unsqueeze(0)).item()

解读：函数在训练循环中周期性调用（例如每 200 步），代价是一次额外的反向传播，可用小批量样本降低成本。allow_unused 处理两损失触及参数集合不同的情况，缺失项补零后两组向量维度一致。判读标准：余弦大于 0 表示方向协同，接近 0 表示正交、可共存，持续小于 −0.5 表示对抗，需要降低对比权重或改用交替更新。该工具同样适用于多任务奖励、跨模态预测等其他损失组合，是联合训练的基础诊断设施。

常见坑

  • 假负样本：同轨迹相邻帧互为负样本，推远语义近邻。症状是对齐指标不升、时序特征变差。修复：用轨迹编号与时间差过滤，或用相似度阈值剔除疑似正样本。
  • 温度坍缩：温度学习到过小值，损失对少数难样本过度敏感。症状是损失震荡、表示退化。修复：给温度设下界（例如 0.02），监控其轨迹。
  • 队列分布漂移：动量系数过小或过大，队列表示与当前表示分布不一致。症状是队列损失与批次损失差距大。修复：调 m 至 0.999 或 0.9999，缩短队列，或只保留最近入队的样本。
  • 对比压制主任务：权重过高时动作精度下降，梯度余弦为负。症状是模仿损失反弹。修复：降低权重、加预热、用梯度投影或交替更新解耦。
  • 指标误读：只看损失值不看对齐与均匀性分解，改进方向不明。修复：固定监控两项指标，每次调整负样本策略后对比两指标与下游任务表现。

练习与思考

  1. 推导 InfoNCE 对正相似度的梯度形式，说明为什么"当前错误概率越大梯度越大"。★★
    提示
    对数似然对相似度求导得到 (1 − p正) 形式；样本被错分时 p正 小，梯度大。
  2. 把温度从 0.07 调到 0.3，预测损失曲线、对齐性与均匀性的变化。★
    提示
    分布平滑，难样本权重下降，对齐变慢但训练更稳；均匀性短期可能先升。
  3. 设计困难负样本策略并给出过滤规则：分别针对"同轨迹近邻""相似场景异任务"两类假负样本。★★
    提示
    前者用时间差窗口过滤，后者用任务标签或语义相似度阈值过滤；记录被过滤比例。
  4. 计算队列长度 4096、批量 256 时负样本规模对损失数值的影响量级，说明为何队列收益递减。★★
    提示
    损失近似的对数项随负样本数缓慢增长；梯度贡献集中在少量难样本上，规模到数千后边际收益下降。
  5. 设计梯度冲突实验：对比"固定权重""预热调度""梯度投影"三种方案在联合训练中的表现，说明指标与结论。★★★
    提示
    指标含动作误差、对比损失、梯度余弦曲线；梯度投影在冲突方向上去除分量，适合强冲突场景。

小结

  • 多模态对比学习用正负样本关系塑造共享表示，观测、语言与动作三元组互为正样本。
  • 对齐性与均匀性两个指标联合诊断表示质量，比单看损失值更能定位问题。
  • 困难负样本提供最强梯度，但要过滤同轨迹近邻与语义近邻，防止假负样本损害表示。
  • 动量编码器与队列扩大负样本规模，动量系数控制队列分布的稳定性。
  • 对比损失与模仿损失的梯度冲突用余弦监控，权重预热与投影是两种干预手段。
