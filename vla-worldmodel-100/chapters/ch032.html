第二篇 · 联合训练进阶与策略能力

第 032 章：基于世界模型的因果推理

策略评估要回答"如果当时执行别的动作会怎样"；本章讲清关联、干预与反事实三级问题的区别，世界模型作为结构因果模型的干预接口，以及行为策略混杂的校正方法。

  • 主题：因果推理（causal inference） / 干预与反事实（intervention and counterfactual）
  • 关键公式：P( y | do(a) ) 与 P( y | a ) 的区别；反事实 rollout；逆概率加权（IPS）
  • 预计学时：55 分钟
  • 前置章节：第 031 章

学习目标

  • 理解关联、干预、反事实三级问题的定义差异，能说明为什么观测条件分布无法直接回答干预问题。
  • 掌握世界模型作为结构因果模型（Structural Causal Model, SCM）的干预接口设计：动作通道的强制替换与历史一致性。
  • 掌握行为策略混杂（confounding）的机制，以及逆概率加权与随机化数据两类校正手段。
  • 会设计反事实 rollout 协议：固定初始潜状态、替换动作序列、对照真实环境验证。
  • 能识别把预测当因果、干预不一致与潜状态泄漏未来信息三类推理错误。

背景与动机

联合训练中大量决策依赖"如果"问题：候选策略比当前策略好吗，失败轨迹里哪一个动作是关键错误，某个动作换一种执行方式结果会不同吗。这些问题属于因果层级，观测数据中的条件关联无法直接回答：动作与结果的相关性同时包含动作效应与状态混杂（状态既影响动作选择，也影响结果）。

世界模型提供一条独特路径：它近似了环境的动力学函数，可以对动作进行干预（intervention）后再前向推演，得到干预分布的估计。这正是结构因果模型的能力：给定 zt+1 = f(zt, at, εt) 的近似 f，把 at 强制设定为任意值，推演后续轨迹。

本章与第 031 章的衔接：不确定性估计告诉我们在哪些区域预测可信，因果干预的有效范围受此约束；与第 030 章的衔接：反事实推演本质上是条件 rollout，其质量上限由可预测时域决定。

核心原理

1. 三级问题：关联、干预、反事实

因果阶梯的三级问题在数学对象上严格区分：

层级对象策略场景数据来源
关联P( y | a )观察执行动作 a 后的结果分布观测数据直接统计
干预P( y | do(a) )强制所有轨迹执行动作 a 的结果实验或模型干预
反事实ya′（同一初始状态）这条轨迹若改为动作 a′ 会怎样结构模型加个体信息

三者的差别可以用一个混杂例子说明：操作员在物体接近目标时才执行精细动作，观测数据中"精细动作与高成功率相关"可能主要来自接近目标的有利状态。P( y | do(精细动作) ) 强制所有状态执行该动作，去掉了状态的筛选效应。策略评估关心的是干预量：新策略改变了动作生成机制，评估必须回答该机制下的结果分布。

数值算例：状态分"接近目标"与"远离目标"两类各占一半；行为策略在接近状态下 100 次试验执行 80 次精细动作，远离状态下只执行 20 次。成功率设定为接近精细 0.9、接近粗略 0.6、远离精细 0.4、远离粗略 0.5。观测统计给出精细动作 100 次成功 80 次（80%），粗略动作 100 次成功 52 次（52%），相差 28 个百分点；后门调整计算干预效应：do(精细) = 0.5 × 0.9 + 0.5 × 0.4 = 0.65，do(粗略) = 0.5 × 0.6 + 0.5 × 0.5 = 0.55，干预差距只有 10 个百分点。状态筛选贡献了 18 个百分点的表观差距，直接使用观测数字会高估精细动作的价值。

后门调整公式给出干预量的可计算形式：P( y | do(a) ) = Σz P( z ) · P( y | a, z )，其中 P( z ) 取目标状态分布（自然出现频率或任务要求的分布），P( y | a, z ) 按状态分层从数据估计。公式成立依赖三个识别假设：一致性（干预值对应唯一的结果机制）、可忽略性（状态覆盖全部共同原因，无未观测混杂）、正值性（每个状态上每个动作都有非零出现概率）。正值性失效时部分分层无数据，IPS 权重趋向无穷，这正是权重爆炸在因果层面的根源。

2. 世界模型作为结构因果模型

把潜动力学写成结构方程：

zt+1 = fθ( zt, at, εt ) ，ot = gθ( zt ) fθ 为动力学函数，gθ 为观测解码器，εt 为外生噪声；动作 at 是父节点之一

干预 do(at = ã) 在结构上等价于截断该变量的生成机制：把 at 从"由策略 π 生成"改为"固定为 ã"，其余结构方程不变。联合分布随之截断分解：

P( z1:T, o1:T | do( at = ã ) ) = P( z1 ) Πs P( zs+1 | zs, as ) · P( os | zs ) ，其中 at ≡ ã 截断的关键：被干预变量的父节点（此处为影响策略的历史）与该变量的边被切断

工程含义：干预无法靠"把动作输入换成新值继续前滚"一步完成，还需要检查潜状态中是否混入了被干预变量的信息。若状态 zt 由包含 at 的编码器产生（例如动作历史被编码进潜状态），替换动作只改了动力学输入，历史通道仍然携带旧动作，干预不一致。正确做法是干预在历史重放层面进行：从干预点之前的共同历史出发，分支推演。

3. 行为策略混杂与校正

训练数据由行为策略（behavior policy）πb 采集，动作分布依赖状态：a ~ πb(·|z)。评估新策略 πe 的期望回报时，直接用数据中的动作-结果配对会得到有偏估计。两类校正：

IPS：V̂(πe) = (1/N) Σi [ πe(ai | zi) / πb(ai | zi) ] · Gi 重要性权重是策略概率比；权重方差随 πe 与 πb 的偏离急剧增大，需要裁剪

逆概率加权（Inverse Propensity Scoring, IPS）重加权观测样本逼近干预分布，方差大；双重稳健估计（Doubly Robust）结合奖励模型与 IPS，两者任一正确即可无偏。第三条路径最直接：用随机化数据（探索噪声覆盖动作空间）训练世界模型，模型在动作分布宽的地方学得准，干预外推可靠。三条路径在实践中混合使用：世界模型做主要推演工具，IPS 类方法做交叉验证。

双重稳健估计的组合形式：V̂DR = (1/N) Σi [ Σa πe(a | zi) · Q̂(zi, a) + wi · ( Gi − Q̂(zi, ai) ) ]，其中 Q̂ 为对条件回报的回归模型，wi 为策略概率比。结构上它用回归模型作基线，只在基线的残差上做重加权：回归准确时重加权项接近零、方差小；回归有偏时重加权项修正偏差。两个组件任一正确，估计即保持无偏，这是"双重稳健"名称的来源。

数值算例：100 条轨迹中 90 条权重为 1、10 条权重为 10，权重和为 190，平方和为 90 × 1 + 10 × 100 = 1090，有效样本量 ESS = 1902 / 1090 ≈ 33.1。名义样本 100 条，等效样本只有约 33 条，估计方差约为名义规模对应的 3 倍。工程阈值取 ESS 低于样本数的三分之一时停止使用 IPS 结论，改用随机化数据或模型推演，并检查高权重样本集中在哪些状态，那里通常是行为策略覆盖稀薄或正值性失效的区域。

4. 反事实 rollout 与一致性条件

反事实推理在联合训练中的三个用法：策略评估（候选动作序列对比）、信用分配（替换单个动作观察结果差异）、数据增强（反事实对作为偏好数据）。三者共用同一机制：固定初始潜状态 z0，从干预点开始替换动作序列，推演两条分支并比较结果。

一致性条件的三个检查点：其一，两条分支在干预点之前共享完全相同的潜状态与历史；其二，被替换动作之后的"结果观测"必须由模型重新生成，不能沿用原轨迹的观测；其三，反事实结论需要真实环境抽样验证：随机选一部分反事实对比在真实环境重放，统计预测差异与真实差异的相关性。反事实推演的前提是结构模型的正确性，模型误差会直接污染因果结论，验证环节不可省略。

反事实的个体性还要求噪声对齐：zt+1 = f(zt, at, εt) 中同一初始状态对应同一族噪声实现，比较 ya 与 ya′ 时应重放同一次 ε（同源噪声），否则得到的是两个边际分布样本的对比，个体层面的归因混入采样噪声。实现上为两条分支固定同一种子，随机性模型使用重参数化采样，让分支共享同一组 ε 抽样；只有在噪声不可辨识或模型不提供重参数化接口时，退而报告分布层面的对比并注明口径。噪声的共享范围也要界定：环境动力学噪声在两分支间共享，策略自身的探索噪声不共享（干预的目标正是替换动作生成机制），两类噪声混同会让分支差异的来源无法解释。

实现思路与设计

因果推理模块由干预接口、分支推演与校正评估三部分组成。与第 031 章的差异：031 给出预测的可信度，本章在可信范围内做干预与反事实推演。

  1. 干预接口：世界模型的动作通道支持显式覆盖模式：forward(z, a, intervene=True) 时跳过动作编码器的历史混合，直接使用给定动作。
  2. 分支推演器：从共享前缀开始，运行两条及以上动作序列分支，输出各分支的回报与中间量指标。
  3. 校正评估：在随机化数据比例不足时，用 IPS / 双重稳健估计对观测数据做校正，与模型推演结果交叉对照。
  4. 验证协议：抽 5% 的反事实对比在真实环境重放，报告预测差异与真实差异的秩相关。

分支推演的长度上限由第 030 章的可预测时域 k* 决定：推演超过 k* 后，两条分支的差异被模型误差主导，与动作效应的比例持续下降，因果结论的信噪比恶化。工程上把分支长度设在 k* 的一半到三分之二之间；需要更长的因果视野时，把干预点后移、缩短单次分支，再沿链式干预点拼接结论；单次推演拉长只会放大模型误差。分支中每一帧的潜状态差同时是信用分配的原始信号，逐帧读取差值曲线可以定位分岔发生的时间位置。

设计决策：干预为什么必须从历史重放开始？

潜状态通常由观测与动作历史联合编码，包含"过去执行了什么"的信息。只替换当前动作而保留旧潜状态，等于同时保留被干预变量的部分信息，两个分支不再从同一世界状态出发，对比失去因果含义。从共享前缀重放并在干预点分叉，是保证一致性条件的最小实现。

关键代码与解读

以下片段参照公开的模型基策略评估与因果推演实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：干预式分支推演

import torch

@torch.inference_mode()
def counterfactual_branch(world_model, obs_prefix, act_prefix, actions_a, actions_b):
    """反事实推演：共享前缀后分叉两条动作序列，输出两分支的潜轨迹。"""
    # 从共享历史编码起点：两条分支从完全相同的潜状态与历史出发
    z = world_model.encode_sequence(obs_prefix, act_prefix)[-1]
    branches = {"a": [], "b": []}
    z_a, z_b = z, z
    for t in range(len(actions_a)):
        # intervene=True：阻断动作编码器对历史动作的混合，强制使用给定动作
        z_a = world_model.transition(z_a, actions_a[t], intervene=True)
        z_b = world_model.transition(z_b, actions_b[t], intervene=True)
        branches["a"].append(z_a)
        branches["b"].append(z_b)
    # 返回潜轨迹；回报差与状态差由调用方按指标口径消费
    return {k: torch.stack(v) for k, v in branches.items()}

解读：（1）前缀共享是因果一致性的实现要点：encode_sequence 得到同一潜状态，分叉从干预点开始；（2）intervene=True 关闭动作通道对历史动作的混合，保证给定的动作序列是唯一动作输入；（3）两分支同步推进，状态差随时间展开，归因定位（哪个动作造成分岔）可以逐帧读取；（4）推理模式关闭梯度，反事实推演作为评估工具，不进入训练图。

片段 2：逆概率加权校正

def ips_value_estimate(logp_eval, logp_behavior, returns, clip=10.0):
    """用行为数据加重要性权重估计新策略的期望回报。"""
    # log 空间相减再加权：避免概率比连乘的数值下溢
    log_ratio = (logp_eval - logp_behavior).sum(dim=-1)   # 每条轨迹一个比值
    ratio = torch.exp(log_ratio).clamp(max=clip)          # 裁剪控制方差
    # 自归一化：除以权重之和，降低权重尺度漂移的影响
    estimate = (ratio * returns).sum() / ratio.sum().clamp(min=1e-8)
    # 有效样本量：比值集中时数值小，提示估计不可靠
    ess = ratio.sum() ** 2 / (ratio ** 2).sum().clamp(min=1e-8)
    return {"value": float(estimate), "ess": float(ess)}

解读：（1）比值在 log 空间计算后指数还原，长轨迹连乘的数值问题被规避；（2）裁剪上界防止个别极端权重主导估计，自归一化让权重整体尺度不影响结果；（3）有效样本量（ESS）监控估计质量：ESS 过小说明新策略与行为策略偏离过大，IPS 估计不可信，应转向随机化数据或模型推演；（4）IPS 的结果用于与世界模型推演交叉验证，两套方法结论背离时优先怀疑数据覆盖不足。

片段 3：反事实结论的真实验证

def validate_counterfactual(world_model, env_stub, replays, n_samples=20):
    """从反事实对比中抽样，在真实环境重放，检查预测与真实的秩相关。"""
    pairs = []
    for sample in replays[:n_samples]:
        # 真实环境重放两条动作分支，记录回报差
        real_gap = env_stub.replay_gap(sample["prefix"], sample["acts_a"],
                                       sample["acts_b"])
        # 模型侧用同一前缀与动作序列推演，得到预测回报差
        branch = counterfactual_branch(world_model, sample["prefix"]["obs"],
                                       sample["prefix"]["act"],
                                       sample["acts_a"], sample["acts_b"])
        pred_gap = world_model.return_gap(branch, sample["rewards"])
        pairs.append((real_gap, pred_gap))
    import numpy as np
    arr = np.asarray(pairs)
    # Spearman 秩相关：只关心排序一致性，对绝对尺度差异不敏感
    rank_corr = float(np.corrcoef(
        arr[:, 0].argsort().argsort(),
        arr[:, 1].argsort().argsort())[0, 1])
    return {"rank_corr": rank_corr, "n": len(pairs)}

解读：（1）验证只关心"模型排序与真实排序是否一致"，采用秩相关口径（绝对误差的尺度差异与决策排序无关），符合反事实用于决策排序的用途；（2）抽样规模小（20 对量级）是因为真实重放成本高，抽样率按预算设定；（3）秩相关低于验收阈值时，模型的反事实结论只能用于生成假设，不能直接作为决策依据；（4）重放接口 replay_gap 与环境解耦，仿真与真实平台提供各自实现。

常见坑

  • 把预测当因果：直接用模型对观测数据的拟合曲线解释动作效应，忽略状态混杂。修复：所有策略评估走干预接口，禁止用条件预测替代干预推演。
  • 干预不一致：替换当前动作但潜状态仍携带旧动作历史，两分支起点不同。修复：从共享前缀重放并在干预点分叉，动作编码器提供 intervene 模式。
  • 权重极端导致 IPS 方差爆炸：新策略与行为策略偏离大时多个权重超界。修复：监控有效样本量，低于阈值时改用随机化数据或模型推演，裁剪上界按权重分布分位数设定。
  • 潜状态泄漏未来信息：编码器在设计上看到了干预点之后的信息，反事实对比的"结果"实际已知。修复：检查编码器的因果掩码，用时间切分测试验证潜状态不包含未来帧信息。
  • 反事实结论与真实环境脱节：模型推演排序正确性未经检验便投入决策。修复：保留 5% 抽样重放协议，秩相关低于阈值时限制结论的使用范围。

练习与思考

  1. 某任务中"缓慢接近"与成功率正相关。说明这种相关为何可能由状态混杂产生，并设计一个小实验区分相关与干预效应。★
    提示
    接近目标的操作员更倾向选择缓慢动作，成功率高的原因是状态有利。实验：在相同初始状态下用模型或真机随机分配两种动作速度，比较成功率差，即近似 do(缓慢) 的效应。
  2. 推导：写出截断因子分解 P( z1:T | do( at = ã ) ) 的完整表达式，标出被切断的边对应的因子。★★★
    提示
    截断后 at 不再由策略条件分布 P( at | zt ) 生成，对应因子被移除并替换为点质量 δ( at − ã )；其余动力学与观测因子保持不变。
  3. 设计混杂校正实验：同一评估任务分别用原始数据、IPS 加权、随机化数据训练的世界模型推演三种方式估计新策略回报，预测三者的一致性与各自失效条件。★★
    提示
    三种方法在动作覆盖充分时结论接近；策略偏离大时 IPS 方差上升、世界模型外推误差上升、随机化数据最稳但采集成本最高。失效条件分别是 ESS 过低、动作分布外推、预算不足。
  4. 把真实验证抽样率从 5% 提高到 20%。预测验证结论的置信区间宽度与可覆盖的干预类型范围的变化，说明抽样率的实际约束。★★
    提示
    抽样率提高缩小秩相关的置信区间并支持按干预类型分层验证；约束是真机重放的时间成本，分层后每类样本量可能不足，需要按预期误差分配样本。
  5. 计算：100 条轨迹中 90 条重要性权重为 1、10 条为 10，求 ESS；再把裁剪上界从 10 降到 3，说明 ESS 与估计偏差各如何变化。★★
    提示
    ESS = 190² / 1090 ≈ 33.1。裁剪到 3 后权重为 90 条 1 加 10 条 3：权重和 120，平方和 90 + 90 = 180，ESS = 14400 / 180 = 80，方差明显缩小，但高权重样本的贡献被截断，偏差上升。裁剪上界的选择是方差与偏差的权衡，按权重分布的 99 分位设定是稳健起点。

小结

  • 关联、干预与反事实属于不同层级的问题，策略评估必须使用干预量。
  • 世界模型作为结构因果模型，干预等价于截断动作的生成机制，从共享历史分叉是实现的必要条件。
  • 行为策略造成的混杂可用 IPS 与随机化数据两类手段校正，有效样本量是估计可信度的监控指标。
  • 反事实推演服务于策略评估、信用分配与数据增强，结论需用真实环境抽样重放验证排序一致性。
  • 潜状态泄漏未来信息与干预不一致是两类结构性错误，分别用因果掩码与历史重放检查排除。
