第三篇 · 策略与世界模型深化

第 046 章：联合训练中的多模态对齐

指令、视觉与动作三种模态要进入同一个度量空间才能互相检索与条件化：本章讲透对比对齐目标（InfoNCE）的推导、温度参数的作用与模态间隙（Modality Gap）的诊断方法。

  • 主题：联合训练 / 表示对齐（Representation Alignment）
  • 关键公式：L = −log exp(sim(q, k+)/τ) / Σj exp(sim(q, kj)/τ)
  • 预计学时：55 分钟
  • 前置章节：第 045 章 世界模型的隐空间插值

学习目标

本章把"对齐"从直观描述变成可计算的目标函数，并给出诊断与调参依据。

  • 理解多模态对齐的目标：语义对应的样本在共享嵌入空间中距离近，语义无关的样本距离远。
  • 掌握 InfoNCE 目标的结构与梯度行为，能解释温度参数 τ 如何调节负样本的惩罚强度。
  • 理解模态间隙的成因与后果，掌握投影头、白化与居中三类缓解手段。
  • 能区分表示对齐与特征融合两类机制，说明它们在联合训练中的分工。
  • 会设计对齐诊断指标：跨模态检索准确率、有效秩与相似度分布。

背景与动机

联合训练中的三种模态来自不同编码器：视觉主干处理图像词元，语言编码器处理指令词元，动作模块处理关节轨迹。各编码器独立预训练后，其输出空间的几何结构互不兼容。不经对齐地把它们拼接送入融合模块，相当于假设两套任意坐标系可以直接相加，融合层的容量被浪费在补偿坐标系差异上。

对比对齐提供了一个低成本的结构先验：指令"把红色积木放到左侧托盘"的嵌入应当靠近完成该任务的轨迹嵌入，并远离"放到右侧托盘"的轨迹嵌入。这一约束不需要逐帧动作标签，只需要语义配对关系，天然适合从海量示教数据中挖掘监督。对齐完成后，检索、条件化与零样本组合（第 047 章）都建立在同一个度量空间上，联合训练的三个损失项共享一致的表示。本章讲解目标函数与实现，同时指出把对齐等同于融合的常见误区。

核心原理

从对齐目标的形式化入手，依次分析温度、模态间隙与诊断口径。

1. InfoNCE：对比目标的概率解释

给定查询 q（例如指令嵌入）与一组键 {k1, k2, …, kN}（例如同一批次的轨迹嵌入），其中只有 k+ 与 q 语义配对。把配对建模为 N 类分类问题，正确类别为正样本，目标函数为：

L = −log exp(sim(q, k+)/τ) / Σj=1N exp(sim(q, kj)/τ) sim 为余弦相似度；温度 τ 控制分布的尖锐程度，批量内其余样本充当负样本

对该损失求梯度，正样本方向与每个负样本方向的梯度系数由 softmax 概率加权：负样本与其相似度越高（越难区分），施加的排斥力越大；相似度低的简单负样本几乎不产生梯度。这与难例挖掘的直觉一致，也说明损失的信息量集中在"当前模型难以区分的样本对"上。把系数写开：正样本的系数为 −(1 − p+)/τ，负样本 j 的系数为 pj/τ，p 为 softmax 概率；pj 越大，拉开该负样本的力度越大。

2. 温度参数的作用

温度 τ 决定相似度分布被放大或压缩的程度。τ 偏小时分布尖锐，训练集中于最难的负样本，梯度局部化且容易饱和到不可微区域；τ 偏大时分布平坦，所有负样本被均匀对待，区分能力提升缓慢。实践中的做法是把 ln(1/τ) 作为可学习参数，按温度初值 0.07 对应 ln(1/0.07) ≈ 2.66 初始化，让模型自行调节。学习得到的尺度参数变化幅度趋平，往往意味着对齐已接近饱和，进一步压低 τ 只会放大噪声梯度。

温度还与嵌入范数相互作用。相似度取余弦时嵌入范数被归一化，温度是唯一的尺度参数；若使用点积相似度，范数本身也进入温度，实施时应固定其中一方。联合训练中的实现通常统一使用余弦相似度，避免两个模块的范数尺度互相干扰。

3. 模态间隙：对齐并不消除几何偏移

不同编码器初始化不同、模态统计不同，即使配对样本被拉近，两组嵌入仍会占据嵌入空间中两个不同的锥形区域，配对样本之间存在稳定的偏移，这一现象称为模态间隙。模态间隙不影响检索排序，却会影响生成式融合：以语言嵌入为中心做条件化时，距离偏移使注意力分布的峰值偏离正确的视觉词元。

三类缓解手段按成本递增：其一，在共享投影头之前对两组嵌入做居中，减去各自的模态均值，直接消除一阶偏移；其二，对两组嵌入做白化（Whitening），统一协方差结构，同时消除一阶与二阶差异；其三，使用跨模态重建或图像描述生成等更强监督，把两组嵌入拉入同一生成过程。工程顺序建议先做居中，再评估白化，最后考虑引入生成监督。

数值示例给出量级感：设共享语义分量的范数为 1，两组模态均值各为 √2、与语义分量及彼此正交，配对嵌入的余弦相似度被均值差压到 1/3；减去各自模态均值后，同一对嵌入的余弦恢复到 1。相似度的绝对值被一阶偏移系统性压低，而检索依赖的是相对次序、对这类整体压低不敏感，生成式融合读取相似度绝对值与注意力峰值位置，受阻更明显。

4. 对齐与融合的分工

表示对齐作用在样本级嵌入上，约束的是全局相似度结构；特征融合作用在词元级特征上，约束的是局部条件映射。两者不可互相替代：对齐让跨模态检索可行，融合让动作生成可控。联合训练的损失中，对比项负责表示，任务项负责行为，交叉注意力负责把对齐后的词元接入策略网络。三个环节共享同一个嵌入空间是联合训练收敛效率高于分别训练的原因，也是本章与第 010 章融合模块的分工边界。

实现警告：批量内的假负样本

同一场景可能存在多条语义相近的指令（"抓起杯子"与"拿起水杯"），它们互为负样本会施加错误排斥。缓解方式：对指令文本做去重与同义合并，或对相似度超过阈值的样本对使用去偏系数降低排斥强度。数据质量不足时，加大批量会放大这一问题，需要先清洗再扩容。

与前一章的差异点

第 045 章处理单一潜空间内部的几何路径，只涉及世界模型自己的编码器；本章处理多个编码器之间的度量关系，涉及的参数分布在视觉、语言与动作三个模块。插值关注路径的连续性，对齐关注样本对之间的距离结构，两个问题的度量口径完全不同。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖对比损失、投影与居中的实现，以及检索诊断。温度设定与上表一致。

片段 1：带可学习温度的 InfoNCE

import torch
import torch.nn.functional as F

def info_nce(query, key, temperature=0.07):
    """批次内对比对齐：对角线为正样本，其余为负样本。
    设计意图：用批量构造的负样本替代显式难例挖掘，成本随批量线性增长。"""
    q = F.normalize(query, dim=-1)          # 余弦相似度：先归一化再点积
    k = F.normalize(key, dim=-1)
    logits = q @ k.t() / temperature        # (B, B) 相似度矩阵
    # 对角线标签：第 i 个查询的正确键是同索引的第 i 个键
    labels = torch.arange(q.size(0), device=q.device)
    # 两个方向都算一次：查询到键与键到查询，梯度更稳
    loss_qk = F.cross_entropy(logits, labels)
    loss_kq = F.cross_entropy(logits.t(), labels)
    return 0.5 * (loss_qk + loss_kq)

解读：（1）温度作为普通入参传入，实际训练中传入 logit_scale.exp() 形式的可学习标量，本片段保持接口简洁。（2）双向损失是对称目标的常用实现：单向版本容易让某一侧嵌入塌缩到低秩结构，双向在两侧都施加排斥。（3）相似度矩阵为 B×B，批量 256 时约 6.5 万项，显存开销可忽略；瓶颈在负样本质量，单纯增加数量收益有限。

片段 2：投影头与模态居中

class AlignedProjection(torch.nn.Module):
    """把不同模态的主干特征投影到共享度量空间。
    设计意图：投影头吸收模态差异，主干特征保持各自预训练时的统计不变。"""
    def __init__(self, in_dim, out_dim=256, momentum=0.99):
        super().__init__()
        self.proj = torch.nn.Linear(in_dim, out_dim, bias=False)
        self.register_buffer("mean", torch.zeros(out_dim))
        self.momentum = momentum

    def forward(self, features, update_stats=False):
        z = self.proj(features)
        # 训练期滑动更新模态均值：消除两组嵌入的一阶偏移（模态间隙的均值成分）
        if update_stats:
            with torch.no_grad():
                self.mean.mul_(self.momentum).add_(z.mean(dim=0), alpha=1 - self.momentum)
        return F.normalize(z - self.mean, dim=-1)   # 居中后归一化，供对比损失使用

解读：（1）投影头无偏置且输出归一化，嵌入空间退化为单位球面，两模态的差异被压缩为球面上的角分布差异，便于用余弦度量。（2）模态均值以滑动方式估计，训练早期统计不稳时居中幅度自动放大，随着统计收敛趋于稳定，无需手动切换。（3）基底统计存放在 buffer 中，随模型保存与加载，评估阶段与训练阶段使用同一居中口径，避免指标口径漂移。

片段 3：跨模态检索诊断

@torch.no_grad()
def retrieval_accuracy(encode_text, encode_traj, pairs, k=5):
    """指令检索轨迹的对齐诊断：报告 Top-1 与 Top-k 命中率。"""
    texts = torch.stack([encode_text(t) for t, _ in pairs])
    trajs = torch.stack([encode_traj(tr) for _, tr in pairs])
    sim = texts @ trajs.t()                  # (N, N) 相似度矩阵，对角线为正确配对
    rank = sim.argsort(dim=-1, descending=True)
    labels = torch.arange(len(pairs)).unsqueeze(1)
    top1 = (rank[:, :1] == labels).any(dim=1).float().mean().item()
    topk = (rank[:, :k] == labels).any(dim=1).float().mean().item()
    # 随机基线是 1/N；长时间停在同一数值说明对齐项未产生有效梯度
    print(f"指令到轨迹检索：Top-1 {top1:.2%}，Top-{k} {topk:.2%}，随机基线 {1/len(pairs):.2%}")
    return top1, topk

解读：（1）检索准确率不需要额外标签，直接复用训练时构造的配对，是成本最低的对齐监控指标；随机基线随评估集规模变化，报告时一并给出便于解读。（2）Top-1 停滞而 Top-k 上升，说明正样本在嵌入空间中仍然靠近，但精细排序能力不足，通常对应温度偏高或负样本区分度不够。（3）诊断使用独立评估配对，与训练批次来源分离，避免把记忆效果误读为对齐效果。

常见坑

  • 批量内存在假负样本：语义相同的样本被当作负样本排斥，嵌入空间中同义指令互相远离。修复：清洗重复指令，或对高相似度样本对降低排斥权重。
  • 温度固定为极小值：梯度集中在少数难负样本上，训练早期即饱和。修复：温度用可学习参数并设合理初值，观察其学习轨迹。
  • 只对齐全局嵌入：指令整体与轨迹整体对齐，忽略"左侧""红色"等细粒度词元与对应视觉区域的联系。修复：增加词元级对齐或使用第 059 章的指令跟随诊断。
  • 对齐权重过大：对比损失压过动作损失，策略条件化质量下降。修复：把对比权重控制在任务损失的十分之一量级，并监控两项的梯度范数比值。
  • 忽略模态间隙直接融合：注意力峰值系统性偏移，表现为策略对指令中目标物体的关注不足。修复：先做居中与白化，再评估融合层的注意力分布。

练习与思考

  1. 推导：写出 InfoNCE 对正样本相似度的梯度表达式，说明它为什么随负样本相似度上升而增大。★★
    提示
    对 logits 求导得到 softmax 概率：负样本 j 的梯度系数等于其概率 pj，正样本的系数为 p+−1。错分概率越高的负样本梯度越大。
  2. 把对比损失权重从 0.1 提高到 1.0，预测三个指标的变化方向：检索准确率、任务成功率、动作损失量级，并说明用什么日志验证判断。★★
    提示
    检索上升，任务成功率可能下降，动作损失变大。检查两项损失的梯度范数比值与验证集成功率曲线，确认是否存在表示对齐压制行为学习的迹象。
  3. 设计实验验证模态间隙的存在与缓解效果：比较居中前后两组嵌入的均值距离、检索准确率与融合注意力峰值位置。★★★
    提示
    均值距离直接度量一阶偏移；检索准确率对居中不敏感（排序不变），注意力峰值位置应显著改善。若居中后检索下降，检查统计更新率与评估口径是否一致。
  4. 构造一个"指令与目标帧"配对的对齐方案，说明正负样本选择、采样比例与它相比"指令与轨迹"配对的增量价值。★★
    提示
    目标帧对强调任务完成状态的语义，弥补整条轨迹平均后信息被稀释的问题；正样本取完成时刻的帧特征，负样本取同批次其他任务的目标帧。

小结

  • 多模态对齐把语义对应的样本拉近，用批量负样本构造训练信号，InfoNCE 是标准目标。
  • 温度调节梯度分布：小温度聚焦难负样本，可学习温度是更稳妥的实现方式。
  • 对齐不消除模态间隙，居中、白化与生成监督按成本递增依次缓解。
  • 对齐约束全局相似度结构，融合约束局部条件映射，两者分工不可替代。
  • 检索准确率、相似度分布与梯度范数比值构成对齐质量的诊断组合。
  • 下一章讨论对齐带来的直接收益：零样本泛化（Zero-Shot Generalization）在未见指令与未见组合上的表现来源与评估协议。
