第三篇 · 策略与世界模型深化

第 045 章：世界模型的隐空间插值

两个潜状态之间的路径决定了合成中间状态的语义质量：本章讲清线性插值与球面线性插值的几何差异、语义连续性的度量方式，以及插值数据进入训练集的过滤与配比原则。

  • 主题：世界模型 / 潜空间几何（Latent Space Geometry）
  • 关键公式：slerp(z1, z2, t) = sin((1−t)Ω)/sinΩ · z1 + sin(tΩ)/sinΩ · z2
  • 预计学时：50 分钟
  • 前置章节：第 044 章 VLA策略的奖励塑形

学习目标

本章围绕"潜空间中的两点之间如何走"这一几何问题，连接训练数据合成与规划两个用途。

  • 理解流形假设（Manifold Hypothesis）对插值有效性的约束，能判断一对潜状态是否适合插值。
  • 掌握线性插值与球面线性插值（Spherical Linear Interpolation, slerp）的公式与几何差异，理解范数归一化潜变量必须使用 slerp 的原因。
  • 会设计语义连续性度量：解码图像距离与潜距离的单调关系，以及先验密度过滤。
  • 能把插值生成的伪过渡样本用于世界模型训练，配置合理的样本比例与一致性约束。
  • 能识别离流形插值、离散潜变量插值两类失效模式并给出替代方案。

背景与动机

世界模型在潜空间中预测动力学，潜空间的结构决定了预测的质量。真实轨迹采样得到的潜状态对之间往往间隔较大，尤其在低帧率或稀疏演示数据中，相邻潜状态之间的过渡缺乏监督。插值提供了在潜空间中合成中间状态的手段：不经过解码与再编码，直接在两个潜状态之间取路径，把路径上的点解码为伪过渡帧或作为动力学监督目标。

插值的质量取决于路径是否落在数据流形上。走直线的路径在曲面上会穿出流形，解码结果退化为模糊或扭曲的图像；走测地线的路径保持在流形附近，语义按顺序平滑变化。规划模块同样受益于这一性质：两个规划航点之间的潜状态可以按路径混合，产生平滑的中间目标，供策略逐步追踪。本章先建立几何直觉，再给出可复用的实现与过滤流程。

两类用途对路径的要求不同：数据合成要求路径点可解码且语义合理，验收用解码指标与密度过滤；规划航点混合要求路径可控、能随时读出中间目标，验收用跟踪误差与到达时间。同一套插值公式服务两类用途，验收口径在实现中分开管理，避免用一种用途的指标去证明另一种用途的效果。

核心原理

从流形假设出发，依次讨论两种插值路径、语义连续性与密度约束。

1. 流形假设与潜空间的局部欧氏性

编码器把高维观测映射到低维潜空间，真实数据在潜空间中集中于低维子流形附近。子流形上任意点的局部邻域近似平坦，小步长插值在局部有效；两点距离较远时，测地线偏离弦线，"直线穿过流形内部"的假设失效。插值的实用性判断由此依赖于两点距离：同一轨迹上相邻时间步的潜状态适合直接插值，跨任务、跨场景的远距离潜状态对需要先做路径分段或选择弧长参数化路径。

距离界限可以用潜空间的自然单位表述：取同一轨迹时间差 1 步的潜距离中位数 d1 作为单位，采样对的时间差限制在潜距离不超过 5 d1 的范围；超过该范围时路径分段为多段短插值再拼接。自然单位随表示更新而漂移，采样规则用相对口径（暗含按次校准）比固定阈值稳健。

流形假设的经验依据：潜在因子（物体位姿、关节配置、光照）的数量远低于像素维度，两个观测共享同一组潜在因子时，其潜表示落在低维子流形上的相近区域。插值有效的场景正是潜在因子沿路径连续变化；当两端状态对应不同的任务阶段或不同的物体配置时，中间的潜在因子组合可能不对应任何可达的现实配置，路径穿过的是流形之间的空隙，此时解码结果随即失真。

2. 线性插值与球面线性插值

线性插值定义为 z(t) = (1 − t)·z1 + t·z2，路径是两点之间的弦。对范数归一化或近似单位范数的潜变量（例如部分世界模型对潜状态做球面归一化），弦线会穿入球的内部：

‖z(t)‖² = (1 − t)²‖z1‖² + 2t(1 − t)·z1Tz2 + t²‖z2‖² z1、z2 正交且等范数时，中点范数为原范数的 √2/2，衰减约 29%

球面线性插值沿大圆弧走：

slerp(z1, z2, t) = sin((1−t)Ω)/sinΩ · z1 + sin(tΩ)/sinΩ · z2，Ω = arccos(z1Tz2 / (‖z1‖‖z2‖)) Ω 为两向量夹角；t 从 0 到 1 时路径保持单位范数，角速度恒定

slerp 给出对照：夹角 90°、t = 0.5 时两个正弦权重均为 sin 45° / sin 90° ≈ 0.7071，插值点范数为 0.7071 × √2 = 1，全程无衰减。夹角越大线性插值的范数损失越严重，而训练良好的潜表示中正交方向占主导，采样对之间的夹角常在 60° 以上，这就是归一化潜变量必须使用 slerp 的直接理由。

选择规则可以压缩成两句：潜变量做过范数归一化时用 slerp；未归一化的高斯潜变量用线性插值即可，但要注意两点范数差过大时插值路径会偏向范数一端，应先按统计量白化再插值。

3. 语义连续性与密度约束

路径合格的判据有两条。第一条是单调性：沿路径解码，语义属性（目标位置、关节配置）应当单调变化，解码图像距离与路径参数近似成正比。第二条是密度：插值点在被训练分布覆盖的区域内，可以用先验网络的对数似然或码本重构误差近似衡量。低于先验似然某分位的插值点视为离流形点，直接过滤掉，成本远低于让世界模型去拟合错误的过渡。

比值曲线的数值示例：健康路径相邻解码距离与潜步长的比值序列约为 1.2、1.1、1.3、1.2，平坦且在 1 附近；穿越低密度区的路径末段比值跳到 3.1，曲线末端抬起，说明路径重新进入高密度区时解码对潜扰动放大。监控指标取比值曲线的最大值与最小值之比，健康路径通常落在 1 到 2 之间，超过 3 进入排查。

密度过滤的执行口径：把当批候选插值点的先验对数似然排序，删除最低的 15%。批量 80 个候选点对应删除 12 个，删除比例随路径质量波动，可以当作采样质量的诊断读数；连续多个批次的删除比例超过 40% 时，说明采样到的潜状态对本身过于分散，应先收紧时间差约束；继续加大过滤力度只会进一步损失有效样本。

离散码本潜变量的替代路径有两条：在连续嵌入空间插值后重新取最近码本，或在码字对数概率空间插值后再取最大值。前者引入量化跳变，路径上的解码图像会出现阶梯式变化；后者路径平滑，但可能经过低概率码字，重建需要用码本概率加权。两条路径的对照实验口径一致：固定潜状态对与步数，比较解码距离比值曲线的平坦度与下游单步误差。

插值数据的价值还体现在一致性约束上：把插值点 z(t) 与其邻点 z(t + Δ) 组成伪过渡样本，要求动力学预测 p(z(t + Δ) | z(t), a(t)) 与插值方向一致，其中动作由相邻真实动作插值得到。该约束把潜空间的局部光滑性写入动力学模型，缓解稀疏帧率下的跳跃预测。

比例与损失的核算：批量 256、伪样本比例 15% 时每批约 38 个伪过渡样本，配合 0.1 的一致性权重，伪样本在总损失中的名义份额约为 38 × 0.1 / (218 + 3.8) ≈ 1.7%；比例提到 30% 时名义份额约 4%。损失份额不大，但训练分布中三成样本来自插值路径，模型对这些区域的拟合被强化，真实数据的密度估计相应被稀释，这是比例上限落在 20% 至 30% 之间的原因。

实现思路与设计

流程分采样、插值、过滤、混合四步，伪过渡样本以固定比例混入世界模型训练批次。

数据流

  1. 从回放缓冲采样潜状态对：优先取同一轨迹内时间差 2 至 5 步的对，距离适中且语义相关性强；时间差与插值步数联动，保持相邻间隔大致恒定。
  2. 按潜变量类型选择插值方式，每对生成 4 至 8 个中间点。
  3. 用先验对数似然过滤低密度点，保留分位阈值以上的样本。
  4. 伪过渡样本占比控制在 10% 至 20%，与真实轨迹混合后进入训练。

采样密度核算：时间差 5 步、生成 6 个中间点的组合把相邻数据密度提高到原来的约 7 倍；时间差放宽到 10 步而中间点数不变时，单段路径长度翻倍，路径穿过低密度区的概率上升，因此时间差与步数应同向调整，保持相邻间隔大致恒定。

规划用途的时间参数核算：一条从起点到终点的潜路径需要在 2 秒内走完、控制频率 50 Hz 时共 100 个控制周期，混合参数 t 每周期推进 1 / 100 = 0.01，每个周期解码当前航点潜状态作为策略的目标条件。推进速度与动作执行速度不匹配的两种症状：推进过快等效于目标抖动，跟踪误差上升；推进过慢任务超时，且策略在余下路径上反复微调消耗执行预算。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖 slerp 实现、伪过渡样本生成与连续性度量。数值与上表一致。

片段 1：带数值保护的球面线性插值

import math
import torch

def slerp(z1, z2, t, eps=1e-6):
    """球面线性插值：沿单位球大圆路径混合两个潜向量。
    设计意图：归一化潜变量用线性插值会缩短范数，slerp 保持路径全程等范数。"""
    z1n = torch.nn.functional.normalize(z1, dim=-1)
    z2n = torch.nn.functional.normalize(z2, dim=-1)
    # 夹角余弦裁剪到 [-1+eps, 1-eps]：避免 arccos 在端点处梯度无穷大
    cos_omega = (z1n * z2n).sum(dim=-1, keepdim=True).clamp(-1.0 + eps, 1.0 - eps)
    omega = torch.acos(cos_omega)
    # 夹角接近零时公式出现 0/0，退化为线性插值并提前返回
    if omega.abs().max() < 1e-3:
        return (1.0 - t) * z1 + t * z2
    sin_omega = torch.sin(omega)
    # 两个正弦权重之和等于 sin(omega)，保证 t=0 与 t=1 精确落在端点上
    w1 = torch.sin((1.0 - t) * omega) / sin_omega
    w2 = torch.sin(t * omega) / sin_omega
    return w1 * z1n + w2 * z2n

解读：（1）输入先归一化，让函数对未归一化输入同样可用；若上游潜变量本身就是单位范数，这一步是恒等变换，不引入额外误差。（2）余弦裁剪与近零夹角早退是两个数值保护点，缺少前者会在两点接近时产生 NaN，缺少后者在两点几乎重合时损失权重溢出。（3）返回结果保持在单位球面上，与下游动力学网络的输入统计一致；若下游接口期望原始尺度，应在调用处乘回范数。

片段 2：伪过渡样本的生成与过滤

@torch.no_grad()
def make_interpolated_pairs(model, latent_pairs, steps=6, quantile=0.15):
    """从潜状态对生成伪过渡样本：插值、解码、密度过滤三步。"""
    z1, z2, a1, a2 = latent_pairs
    samples = []
    for i in range(1, steps + 1):
        t = i / (steps + 1)                     # 端点不取，避免与真实样本重复
        z_t = slerp(z1, z2, t)                  # 中间潜状态
        a_t = (1.0 - t) * a1 + t * a2           # 动作同步插值，保持过渡条件一致
        # 先验对数似然作为密度代理：低密度点解码质量差，直接丢弃
        logp = model.prior_log_prob(z_t)
        keep = logp >= torch.quantile(logp, quantile)
        samples.append((z_t[keep], a_t[keep]))
    return samples

解读：（1）插值参数取 i/(steps+1) 跳过两端点，伪样本与真实样本之间保持间隔，避免训练集出现近乎重复的样本对。（2）动作与潜状态同步插值，伪过渡的动作条件是端点的凸组合，与世界模型"动作驱动状态变化"的接口保持一致。（3）过滤使用先验对数似然的分位阈值；固定数值在不同训练阶段会失效，先验尺度漂移时分位口径自动跟随。

片段 3：语义连续性度量

@torch.no_grad()
def continuity_report(model, z1, z2, steps=20):
    """沿插值路径报告潜距离与解码距离的单调关系，用于诊断路径质量。"""
    ts = torch.linspace(0.0, 1.0, steps)
    latents = [slerp(z1, z2, t) for t in ts]
    # 逐点解码：把潜状态映射回观测空间，计算相邻解码帧的距离
    frames = [model.decode(z) for z in latents]
    decoded_step = [(frames[i + 1] - frames[i]).norm(dim=-1).mean()
                    for i in range(steps - 1)]
    latent_step = [(latents[i + 1] - latents[i]).norm(dim=-1).mean()
                   for i in range(steps - 1)]
    ratio = torch.tensor(decoded_step) / torch.tensor(latent_step).clamp(min=1e-8)
    # 比值曲线接近常数说明语义变化均匀；两端翘起说明路径穿出流形
    print(f"解码距离与潜距离比值：起点 {ratio[0]:.3f} 中点 {ratio[steps//2]:.3f} 终点 {ratio[-1]:.3f}")
    return ratio

解读：（1）比值曲线是路径质量的直接读数：接近常数表示语义均匀变化，端部抬升通常意味着路径进入了低密度区，解码对潜扰动的放大随之加剧。（2）报告取起点、中点、终点三个位置，足以覆盖大部分异常形态；若要做论文级图表，可扩展到完整曲线并叠加先验似然。（3）该度量不需要真实标签，可以在训练过程中定期对随机潜状态对执行，作为世界模型表示质量的监控指标之一。

常见坑

  • 对离散码本潜变量做数值插值：码本是离散类别，插值出的向量不对应任何有效词元，解码结果随机。修复：在连续嵌入空间插值后重新取最近码本，或改用码本上的概率插值。
  • 归一化潜变量用线性插值：中点范数衰减，解码图像模糊。修复：改用 slerp，或先还原范数再插值。
  • 跨轨迹远距离插值：两点时间差过大，路径穿过低密度区，世界模型学到非物理过渡。修复：限制采样时间差，并对生成样本做密度过滤。
  • 伪样本比例失控：为快速扩大数据集把比例提到 50% 以上，真实动力学被稀释，单步预测误差先降后升。修复：比例控制在 10% 至 20%，用验证集单步误差确定上限。
  • 插值样本泄漏进评估集：训练插值路径与评估轨迹共享端点，评估指标虚高。修复：按轨迹划分训练与评估，按帧划分会让共享端点的插值路径泄漏进评估集。

    提示
    样本量明显减少，过滤更严使单步误差下降但收益可能被样本不足抵消。对照实验固定其他变量，比较训练曲线上限与收敛速度。
  3. 设计实验：验证 slerp 路径的解码质量优于线性插值。写出对照组、指标（解码距离比值曲线的平坦度、下游单步误差）与预期结果。★★★
    提示
    同一批潜状态对分别用两种插值生成样本，训练两个世界模型，比较第五步与第十五步的累计误差。注意控制伪样本比例与过滤条件一致。
  4. 规划用途：给定两个目标潜状态代表起点与终点，设计"潜空间航点混合"的流程，让策略逐步追踪。说明混合参数与控制器周期的关系。★★
    提示
    按控制周期在路径上推进参数 t，每个周期解码当前航点潜状态作为目标条件；推进速度与动作执行速度匹配，过快等效于抖动目标，过慢导致任务超时。
  5. 计算：两个等范数向量的夹角为 60°、90°、120° 时，线性插值中点的范数衰减各为多少？再给出 slerp 在 90°、t = 0.5 处的权重取值。★★
    提示
    中点范数为 √((1 + cos Ω) / 2)：60° 得 0.866（衰减 13.4%）、90° 得 0.707（29.3%）、120° 得 0.5（50%）；slerp 在 90°、t = 0.5 的权重为 sin 45° / sin 90° ≈ 0.7071，输出范数保持 1。用 Python 对三个夹角复算一遍。

小结

  • 插值的有效性受流形假设约束，局部邻域内近似欧氏，远距离路径需要分段或弧长参数化。
  • 归一化潜变量必须使用 slerp 保持范数；未归一化高斯潜变量用线性插值并先做尺度对齐。
  • 路径质量用解码距离与潜距离的比值曲线诊断，平坦曲线对应语义均匀变化。
  • 伪过渡样本以 10% 至 20% 比例混入训练，配合密度过滤与动作同步插值。
  • 离散码本潜变量不能直接数值插值，需在嵌入空间处理或改用概率形式。
