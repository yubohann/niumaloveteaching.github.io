第 078 章：世界模型的动态因果发现

本章讲世界模型的动态因果发现（Dynamic Causal Discovery）：用滞后结构与稀疏约束从时序数据中恢复变量依赖，用结构掩码把因果图写进动力学，用干预实验验证因果方向，把相关证据升级为方向结论。

  • 主题：世界模型 / 结构学习与因果推理
  • 关键公式：xt = Στ≥1 Aτ xt−τ + εt，L = Lpred + λ‖A‖group
  • 预计学时：55 分钟
  • 前置章节：第 077 章：VLA策略的模仿与强化结合

学习目标

  • 理解因果结构对世界模型的价值：可干预的模块化动力学在分布外与干预情形下比黑箱相关预测更可靠。
  • 掌握格兰杰因果（Granger Causality）与滞后线性模型，理解组稀疏惩罚塑造结构的方式。
  • 掌握结构掩码的动力学建模：用连续松弛的结构参数控制维间依赖，把图的稀疏先验写进网络。
  • 能实现稀疏结构学习、掩码动力学与干预验证实验，理解相关证据与因果证据的界限。
  • 会诊断瞬时与滞后因果混淆、非平稳边漂移与潜混杂问题，能设计干预数据采集实验。

背景与动机

本节说明因果结构针对的泛化缺陷：相关预测模型学到的是观测共现。分布内预测准确，干预或分布外场景下系统性失准：把“同时出现”当成“互相导致”，在主动干预改变环境后预测崩溃。因果结构把动力学分解为模块化转移：每个变量只依赖父节点集合，干预时只需替换单个机制。模块性带来干预可靠与分布外稳定两个收益。本章用滞后结构发现与稀疏约束估计依赖图，用结构掩码把它写入世界模型，并用干预实验闭环验证。

核心原理

1. 格兰杰因果与滞后结构

时序上的格兰杰因果定义：若加入变量 i 的过去能显著提升对变量 j 当前的预测，则称 i 格兰杰导致 j。滞后线性模型把该定义写成回归：

xt = Στ=1..P Aτ xt−τ + εt Aτ 为第 τ 阶滞后系数矩阵，(Aτ)ij ≠ 0 表示变量 i 的过去影响变量 j；P 为滞后阶数

结构估计依赖稀疏假设：对 A 施加组稀疏惩罚（同一对变量的各阶系数成组）能同时完成阶数聚合与结构选择。格兰杰因果是预测意义上的因果，与干预意义上的因果存在差距：遗漏的潜变量会让两条无关序列通过共同驱动产生虚假边。结论强度的分级很重要：时序数据支持“预测性依赖”，干预数据才支持“因果方向”。

2. 结构掩码动力学

世界模型的隐变量没有物理名称，结构学习直接在隐维上进行：为每一对隐维 (i, j) 维护结构参数，经连续松弛（sigmoid 或 Gumbel 近似）得到软掩码 M ∈ [0,1]d×d，动力学只允许父节点集合参与更新：

h′ = h + f( h ⊙ MT, a ), M = σ(Θ) Θ 为可学习结构参数；σ 为 sigmoid；对角元素保留自依赖，a 为动作条件

掩码与预测损失联合训练：预测误差驱动掩码保留必要连接，稀疏惩罚把无贡献连接压向零。连续松弛避免离散搜索的组合爆炸；掩码为软结构，分析时按阈值二值化。与图结构表示（第 063 章）的差别在于学习的是结构本身：图网络的对象与边由输入给定，本章的边由数据推断。

3. 数值算例：软掩码的初始化与二值化

结构参数初始偏负的取值影响训练起点。初始 logits 取 −2 时，掩码 σ(−2) = 1 / (1 + e2) ≈ 0.119，所有边从接近关闭的状态起步；若初始取 0，掩码恰好为 0.5，正落在常用二值化阈值上，训练早期的微小梯度就能让边在开与关之间翻转，结构在初始化附近剧烈抖动。训练收敛后的软掩码示例为 [0.90, 0.67, 0.52, 0.48, 0.20]：

阈值 0.5 二值化 → [1, 1, 1, 0, 0]（五条边中的三条保留） 阈值 0.4 二值化 → [1, 1, 1, 1, 0]（0.48 的边在口径变化下翻转） 0.48 与 0.52 的实际预测贡献接近，二值化后却被划到两侧

数值结果给出三条分析纪律：（1）阈值附近的边处于“证据不足”区间，单次训练的结论不可靠，用多随机种子重复训练统计边的点亮频率，频率高于 0.8 判定为稳健边、低于 0.2 判定为噪声边、中间区间留待干预实验裁定；（2）初始偏负让训练从稀疏端开始，配合组稀疏惩罚减少无用边在起点处的能量浪费；（3）报告结构时同时给出阈值与软值，只报告二值化图会掩盖边界边的不确定性。

4. 瞬时依赖与滞后依赖的区分

真实系统同时存在瞬时依赖（同刻变量约束）与滞后依赖（上刻影响下刻）。滞后模型只含后者；同时刻变量的方向无法仅凭观测分辨。处理原则是显式建模：同刻约束写成无向因子，跨时刻影响写成有向边；或用时间聚合只保留可辨识的滞后结构。采样频率过低时快速因果链被折叠成同刻相关，估计只能得到聚合效果。

5. 干预与反事实检验

因果声明的检验需要干预：对变量做 do 操作（强制取值），观察下游变量变化是否符合推断图。干预数据来源有三：环境主动操作、仿真参数干预与目标条件近似（第 055 章）。评估指标分两类：干预下预测误差（模型能否正确响应干预），以及干预效应的传播范围（推断图的后代集合与实际变化集合的重合度）。没有干预数据时，因果结论只能标注为假设，世界模型的规划与安全分析不应依赖未验证的方向性声明。潜混杂的处理：记录潜在共同原因变量，或用跨环境不变性检验筛选机制。证据等级与验证方式的对照如下：

证据类型支持的可识别结论所需数据主要风险
时序相关性同期共现，共动模式单环境观测潜混杂，共现与因果不可分
滞后预测（格兰杰）滞后预测依赖方向观测时序，含足够激励瞬时因果被折叠，采样率敏感
跨环境不变性候选机制在环境变化下的可靠性多个环境的数据环境覆盖不足时筛不出混杂

反事实推断特定情形下的因果效应估计因果图加结构方程结构方程误设导致估计偏差

证据等级按上表自上而下递增：规划与安全相关的结构至少需要跨环境不变性支持，涉及高风险动作的方向声明应有干预证据。工程上先收集多环境数据筛选机制，再对筛选出的高影响边安排干预实验，用最少的干预预算获得方向结论。证据等级不足的边在部署时按“不确定连接”处理：预测照常使用，但下游决策不依赖其方向做硬性推理。

实现思路与设计

本节给出集成方案：在隐空间世界模型的转移核上挂结构掩码；结构参数与动力学联合训练，稀疏惩罚用组范数；每固定步数将掩码二值化并冻结一段时间，用干预数据验证后再解冻。数据侧记录环境参数（摩擦、质量、光照）作为潜在混杂候选。与第 077 章的差异：第 077 章组织监督信号，本章给世界模型加结构先验与验证流程。

设计决策：为什么结构参数单独设学习率

结构参数与动力学权重的尺度与收敛速度不同：结构决定“谁影响谁”，早期需要快速探索连接模式；一旦确定又需要稳定防止反复抖动。结构参数需要独立的学习率与更新周期：探索期大步，稳定期小步或冻结。

多环境数据与结构稳定性的管理要点

  • 环境变量的选择与记录。优先变化物理参数（摩擦、质量、光照）与自身磨损状态，这些变量最可能成为潜混杂；每段数据记录环境标识，跨环境检验按环境分组统计边的不变性。
  • 激励充分性检查。格兰杰检验要求各变量有足够的时间变化幅度；对长期处于静止状态的变量，其入边不可识别，数据采集阶段应主动加入小幅激励动作。
  • 多种子结构聚合。结构学习至少重复 5 个随机种子，按点亮频率分级为稳健边、边界边与噪声边；边界边进入干预实验清单，噪声边从分析图中剔除。
  • 结构版本与回滚。每次结构冻结产生一个版本快照，记录二值化阈值、种子聚合结果与验证指标；新版本影子运行期间旧版本继续执行，重合度与任务指标不降才切换。
  • 漂移检测的观测口径。部署期用干预重合度的滑动均值与边稳定度两项指标做漂移检测，任一指标越过阈值时触发重估流程；等任务成功率下降才反应已属滞后。

关键代码与解读

以下片段以稀疏时序结构学习与结构掩码网络的公开设计为参照，接口随版本演进。三个片段分别覆盖组稀疏结构、掩码动力学与干预验证。

片段 1：滞后结构与组稀疏惩罚

import torch
import torch.nn.functional as F

def granger_sparse_loss(x, A, order=2, l1=1e-3):
    """滞后线性因果模型：预测误差加组稀疏惩罚。"""
    T = x.shape[0]
    target = x[order:]                         # 从第 order 步起可被完整预测
    pred = torch.zeros_like(target)
    for tau in range(1, order + 1):
        # 历史切片与目标逐步对齐：x_{t-tau} 预测 x_t
        hist = x[order - tau: T - tau]
        pred = pred + torch.einsum("ij,tbj->tbi", A[tau - 1], hist)
    mse = F.mse_loss(pred, target)
    # 组范数：同一变量对的所有滞后阶作为一组，联合选择或淘汰
    group = A.pow(2).sum(dim=0).sqrt().sum()
    return mse + l1 * group

解读：（1）einsum 的下标把“来源变量维”统一累加，系数矩阵的列对应目标变量。（2）组范数同时完成两件事：同一对变量的滞后系数整体收缩（阶数聚合），与跨对比较选出连接（结构选择）。（3）输出损失供优化器使用，结构分析在训练后按阈值提取。

片段 2：结构掩码动力学

import torch
import torch.nn as nn

class CausalDynamics(nn.Module):
    """结构掩码动力学：依赖关系由可学习的软结构控制。"""
    def __init__(self, dim=64, a_dim=7, hidden=128):
        super().__init__()
        # 结构参数初始偏负：起点接近全断开，连接由数据逐步点亮
        self.edge_logits = nn.Parameter(torch.full((dim, dim), -2.0))
        self.mlp = nn.Sequential(nn.Linear(dim + a_dim, hidden), nn.SiLU(),
                                 nn.Linear(hidden, dim))

    def forward(self, h, a):
        mask = torch.sigmoid(self.edge_logits)     # 连续松弛的结构
        with torch.no_grad():
            mask.fill_diagonal_(1.0)               # 自依赖恒开：保证状态记忆
        parents = h @ mask.t()                     # 每个状态只接收父节点信息
        return h + self.mlp(torch.cat([parents, a], dim=-1))

解读：（1）负初始值让掩码起点接近零：所有边先关闭，预测损失逐步“点亮”必要连接，比全开再剪枝更稳定。（2）对角强制为 1：没有自依赖的隐状态会丢失自身历史。（3）sigmoid 梯度会把无用边推向更小的值。

片段 3：干预方向的验证实验

import torch

@torch.no_grad()
def intervention_effect(model, obs, action, var_idx, value):
    """do 操作验证：强制变量取值，测量下游预测的变化范围。"""
    base = model.predict(obs, action)
    obs_do = obs.clone()
    # do 操作只改目标变量：其余变量保持观测值，模拟外部强制输入
    obs_do[:, var_idx] = value
    do = model.predict(obs_do, action)
    effect = (do - base).abs().mean(dim=0)         # 各维受影响强度
    # 推断图的后代集合与实测受影响集合比较：方向验证的核心对照
    graph_descendants = model.descendants([var_idx])   # 结构掩码的传递闭包
    overlap = len(set(graph_descendants) & set((effect > 0.05).nonzero().tolist()))
    return effect, overlap

解读：（1）do 操作与条件观测的差别是只改目标变量、不联动其他变量，这正是干预分布的定义。（2）实测影响集合由阈值判定，阈值按预测噪声水平设置。（3）后代集合与受影响集合的重合度高于随机基线时，方向证据成立；重合度低时应检查掩码阈值与潜混杂。

常见坑

  • 相关当因果：共同驱动源产生虚假边，部署干预后预测失效。修复：记录并纳入潜在混杂变量，用跨环境不变性检验筛选边。
  • 瞬时与滞后混淆：把同刻交互当成跨刻因果，方向估计错误。修复：采样频率匹配因果链时间尺度，同刻约束单独建模。
  • 非平稳边漂移：环境参数变化使真实结构改变，旧掩码失配。修复：按环境分段验证，掩码小范围内缓慢更新。
  • 过度稀疏漏边：惩罚过强把弱但真实的连接压没，干预预测出现系统性偏差。修复：按预测损失量级标定惩罚，用干预重合度选择强度，训练损失只反映拟合。
  • 因果声明超出证据：仅凭观测数据输出方向性结论并用于安全决策。修复：无干预数据的结论标注为假设，规划与安全分析仅使用干预验证过的结构。

练习与思考

  1. 分析题：给出三变量系统的真实结构 X 导致 Y、Y 导致 Z，但数据只观测到 X 与 Z 的滞后相关。说明格兰杰检验会给出什么结论，干预 X 后预测会如何出错。★★
    提示
    X 到 Z 的滞后影响可能被检出，但传导动态错误；干预 X 且固定 Y 后效应消失，模型仍预测存在，误差暴露。
  2. 把片段 1 的组稀疏强度从 1e-3 增到 1e-1，预测恢复图的边数与干预预测误差的变化。★
    提示
    边数大幅减少，训练 mse 上升；部分真实弱边被剪掉后干预下误差增大，说明稀疏度调节需以干预指标为准，训练损失只反映拟合优劣。
  3. 推导题：说明滞后模型为什么无法识别瞬时因果方向，并给出含瞬时项的结构方程写法与可辨识条件。★★
    提示
    同刻两个变量互为条件即出现对称解；结构方程 x_1 = f(x_2, u_1)、x_2 = g(x_1, u_2) 需噪声独立性与无环假设才能定向，或引入外部干预打破对称。
  4. 实验设计：设计干预验证协议：干预变量选择、方向验证批次数、重合度基线与结论分级。★★
    提示
    优先干预高介数变量；每方向至少两批对照；基线用随机边置换的后代重合度分布；结论分三级：一致、部分一致、不支持。
  5. 设计题：为“结构随时间缓慢变化”的长期部署设计结构维护协议：重估触发条件、新旧结构比较方式、切换时的回滚策略。★★★
    提示
    触发条件用干预重合度的滑动均值下降；新旧结构逐边比较并按影响范围分级；切换采用双结构影子运行，重合度不降才正式启用。

小结

  • 因果结构给世界模型带来模块性：干预只替换单个机制，其余保持不变，是分布外稳定的来源。
  • 格兰杰因果用滞后回归加组稀疏实现，属预测性因果，潜混杂是虚假边的主要来源。
  • 结构掩码把因果图写进动力学，软掩码联合训练、分析时二值化，结构参数需要独立的更新节奏。
  • 因果声明必须用干预验证：后代集合与实测影响的重合度是核心指标。
