第五篇 · 系统集成与研究实践

第 100 章：联合训练中的多模态数据不平衡处理

长尾任务、语言与模态缺失率的分布失衡如何扭曲训练：有效样本数加权、温度重采样、Logit 调整与想象增强，以及全课程技术地图的收束。

  • 主题：联合训练（joint training）/ 数据不平衡（data imbalance）
  • 关键公式：有效样本数加权与温度采样
  • 预计学时：60 分钟
  • 前置章节：第 099 章

学习目标

  • 理解多模态数据不平衡的三个轴：任务频次长尾、语言与模态缺失率差异、本体数据量差异，及其对训练与评测的双重扭曲。
  • 掌握有效样本数（effective number）加权的推导与行为，理解其与朴素过采样的差别。
  • 掌握温度重采样与 Logit 调整两组手段，会按训练阶段安排从平衡到自然的退火。
  • 会用世界模型合成尾部样本做数据再平衡，并识别合成偏差放大的风险。
  • 建立分组评测意识：以最差组指标衡量系统质量，整体均值会掩盖组间差距，完成全课程方法的整合。

背景与动机

联合训练的数据天然长尾：高频任务占据多数样本，低频但重要的任务（罕见物体抓取、危险规避）梯度贡献微弱，评测时又被均值指标掩盖。多模态数据还叠加了更多不平衡：各语言的指令数量悬殊、触觉与深度模态的缺失率不同、不同本体的轨迹量差异大。若对分布失衡不加处理，模型在均值上表现良好，在最差组上不可用。

本课程此前的章节分别处理过模态缺失（第 081 章）、语言分布（第 092 章）与跨域数据（第 099 章），本章把这些问题统一到不平衡视角下：它们都是同一组技术（采样、加权、调整、合成）在不同轴上的应用。作为全课程最后一章，本章同时收束五篇内容，给出从数据到部署的完整技术地图与后续研究方向。

核心原理

不平衡处理的目标是让尾部组获得足够的有效梯度，同时保留自然分布的先验信息；把分布完全拉平会损失先验，通常并不更优。

1. 不平衡的三个轴与两种扭曲

  • 任务轴：技能与场景频次的长尾，头部任务贡献多数样本；
  • 模态轴：语言数量分布、各模态缺失率、传感器覆盖率不齐；
  • 本体轴：不同机器人平台的数据量差异。

扭曲发生在两处：训练端，经验风险被样本量大的组主导，尾部组的梯度被稀释；评测端，均值指标同样被头部组主导，尾部失败不可见。因此不平衡处理必须同时覆盖训练与评测：训练端用采样与加权平衡梯度，评测端用分组指标暴露尾部。只做一半会导致"看起来解决、实际更糟"：训练平衡后若仍看均值，改进不可见；评测分组后若不改训练，差距刺眼但无对策。

2. 温度重采样

重采样通过改变采样概率调整有效分布：

P(i) ∝ niα，α ∈ [0, 1] ni 为组 i 的样本数；α = 0 为完全均匀，α = 1 为自然分布

α 是平衡强度的连续旋钮：中间值（0.5 附近）在提升尾部覆盖与保留自然先验之间折中。相比简单过采样（复制尾部样本），温度采样控制的是各组被抽取的次数比例，重复度更低；相比欠采样（丢弃头部样本），不损失数据。采样只改变频率，不改变单样本的贡献上限，与损失加权配合使用效果更完整：采样解决批次内的组比例，加权解决组内单样本的梯度强度。

3. 有效样本数与损失加权

朴素的逆频率加权（权重与 1/ni 成正比）在头部组会过度放大单样本噪声。有效样本数模型考虑边际收益递减：

En = ( 1 − βn ) / ( 1 − β )，wi ∝ 1 / Eni，β 取 0.999 量级 En 随 n 增大趋近饱和值 1/(1−β)；β 越小饱和越快

当 n 增大时 En 增长放缓，权重不会无限下降，头部样本仍保留学习价值。归一化后权重均值为 1，与任务损失的尺度兼容。另一条路线是 Logit 调整：训练时把各组先验并入 logits：zy ← zy + τ·log πy，其中 πy 为组先验，τ 控制调整强度。Logit 调整的理论依据是贝叶斯最优分类器在平衡与自然分布间的后验换算，改的是决策边界，与调整损失权重的重加权互补。推理时是否需要还原先验由部署目标决定：追求均衡性能保留调整，追求与自然分布匹配的校准则相应修正。

4. 合成增强与退火

世界模型可以把尾部组样本增强：用少量真实尾部数据锚定分布，在其潜状态邻域内 rollout 生成变体（第 081 至 099 章的机制在此汇聚）。合成样本的风险是放大模型自身偏差：模型对尾部组的表示本来就不准，生成的"变体"会强化错误模式。控制手段有三：合成数据占比上限（例如 30%）、按合成来源的预测分歧降权（第 091 章的悲观加权）、只用于输入侧增强而不直接改变价值目标。

训练后期应把采样与加权退火：从强平衡逐步回到自然分布，让最终模型的概率校准与部署分布一致。退火按训练步数执行，退火终点建议保留轻度的平衡（α 终值 0.7 量级），完全回到自然分布会让尾部组在最后阶段重新吃亏。

实现思路与设计

流水线为：分组统计 → 温度采样 → 有效样本数加权与 Logit 调整 → 想象增强尾部 → 分组评测与退火。

  1. 分组定义：以（任务，语言，模态可用性，本体）四元组划组，统计各组样本量与缺失率。
  2. 采样器：温度 α 从 0.3 起步，按步数退火到 0.7；每次批次保证组的最小配额。
  3. 加权：有效样本数权重 β = 0.999，归一化到均值 1；Logit 调整 τ = 1.0 仅在多语言指令头启用。
  4. 想象增强：对样本量低于阈值的尾部组，用世界模型生成因子 2–3 倍的变体，权重按分歧打折。
  5. 评测：整体指标与分组指标并列报告，重点观察最差组与组间差距；退火前后各评测一次。

设计决策：采样与加权为什么需要同时使用？

采样控制批次内的组比例，但组内样本的重复度上升；加权控制单样本的梯度强度，但不改变批次构成。长尾极端的组（样本量相差三个数量级）单靠采样需要极高重复度才能出现在多数批次中，单靠加权则头部组的梯度被过度削弱。两者组合：采样把组比例拉到可用范围，加权在组内做精细平衡，再用合成增强降低采样重复度。三层叠加的复杂度换来的是不同极端程度下都可调的空间。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：有效样本数加权

def effective_number_weights(counts, beta=0.999):
    """有效样本数权重：随样本量增大饱和，避免逆频率的过度惩罚。"""
    counts = torch.as_tensor(counts, dtype=torch.float32)
    eff = (1.0 - beta ** counts) / (1.0 - beta)      # E_n 随 n 饱和于 1/(1-beta)
    w = 1.0 / eff
    w = w / w.mean()                                 # 归一化到均值 1
    # 上限保护：极端小组权重不超过 100 倍，防止梯度尖峰
    return torch.clamp(w, max=100.0)

解读：beta ** counts 对小 n 接近 1−ε，En 接近 n，权重近似逆频率；对大 n 趋近饱和，权重趋于常数。归一化让加权后的损失与原始损失量级一致，超参迁移性更好。clamp 上限保护针对退化情形：某组只有一两个样本时权重可达数百倍，梯度被单样本主导。权重按组应用在样本级损失上（先算每样本损失，再按组索引加权求均值），不能直接乘在批量均值上，否则组内比例会被重新抹平。

片段 2：温度采样与退火

class TemperedSampler:
    """温度采样：按样本数的 α 次幂分配抽取概率，α 随训练退火。"""
    def __init__(self, counts, alpha_start=0.3, alpha_end=0.7, total=5e5):
        self.counts = torch.as_tensor(counts, dtype=torch.float32)
        self.a0, self.a1, self.total = alpha_start, alpha_end, total
        self.step = 0

    def weights(self):
        alpha = self.a0 + (self.a1 - self.a0) * min(1.0, self.step / self.total)
        p = self.counts ** alpha                     # 未归一化的抽取概率
        return p / p.sum()

    def sample(self, size):
        self.step += size
        idx = torch.multinomial(self.weights(), size, replacement=True)
        return idx                                   # 返回被抽中的组索引

解读：counts ** alpha 让样本多的组保持概率优势但差距被压缩，α 越小差距越平。增量步数按抽取量累计，退火由"已抽取样本数"驱动；迭代次数在不同批量配置下与样本量的换算不同，按样本数计保证退火节奏一致。multinomial 的 replacement=True 允许尾部组被重复抽取，这是采样与合成增强互补的原因：重复度由增强数据稀释。实际实现常在组索引抽出后，再在组内均匀选具体样本，形成两级采样，便于控制组内时间与场景多样性。

片段 3：Logit 调整与分组评测

def logit_adjust(logits, group_prior, tau=1.0):
    """Logit 调整：训练时把组先验并入 logits，修正长尾决策边界。"""
    # group_prior: (G,) 组先验概率；logits: (B, G)
    return logits + tau * torch.log(group_prior + 1e-8)

def group_metrics(pred, label, group_id, n_groups):
    """分组评测：返回每组准确率与最差组，暴露被均值掩盖的尾部。"""
    acc = torch.zeros(n_groups)
    for g in range(n_groups):
        mask = group_id == g
        if mask.any():
            acc[g] = (pred[mask] == label[mask]).float().mean()
    worst = acc[acc > 0].min().item()                # 忽略空组
    return acc.tolist(), worst

解读：logit_adjust 在损失计算前施加先验修正，tau 控制强度；先验从训练集统计得到并随检查点保存，评测端保持同一配置。group_metrics 的最差组指标是长尾评测的核心数字：整体均值提升而最差组下降的改动一律回退。生产系统中把最差组与组间方差一并纳入发布门槛，避免"平均指标达标、关键组失效"的部署事故。该函数与全课程的评测协议保持一致，可与组合划分（第 083 章）、留出语言（第 092 章）、留出域（第 099 章）的评测拼装成完整报告。

常见坑

  • 过采样重复过拟合：简单复制尾部样本，模型容易记住少数样本、学不到泛化模式。症状是尾部组训练损失极低、验证不升。修复：温度采样降低重复度、合成增强扩充样本、正则化加强。
  • 加权与归一化冲突：组权重与第 082 章的奖励归一化、第 081 章的不确定性加权交错使用，量级反复缩放。症状是损失曲线阶跃。修复：明确各环节的缩放顺序，记录每一层缩放后的统计量。
  • 只报整体指标：均值达标即认为改进有效，尾部退化不可见。修复：分组指标与最差组进入固定报告，发布门槛包含最差组下限。
  • Logit 调整推理期不一致：训练加调整而推理不加（或反之），概率校准与决策边界错位。修复：把调整配置写入模型元数据，训练与推理共用同一读取路径。
  • 合成偏差放大：世界模型对尾部组本就不准，合成样本强化错误。症状是尾部组在合成数据上表现好、真实数据上不变或变差。修复：合成占比上限、分歧加权、用真实留出集单独验证合成收益。

练习与思考

  1. 分析有效样本数公式的极限行为：n → ∞ 时权重趋于何值？β 取 0.99 与 0.9999 时饱和速度差多少？★★
    提示
    w ∝ (1−β)/(1−βn) → 1−β；β 越大饱和越慢，头部与中部的权重区分持续更久。
  2. 把采样温度终值从 0.7 改为 1.0（完全回到自然分布），预测尾部组评测与整体校准的变化。★
    提示
    整体校准更贴近部署分布，但尾部组在最后阶段梯度不足，最差组指标可能回落。
  3. 设计分组评测报告模板：列出组定义维度、每组样本量、准确率、最差组的展示方式与发布门槛。★★
    提示
    四元组分组可能稀疏，先按单维度消融再组合；门槛建议为最差组不低于整体指标的 80%。
  4. 推导 Logit 调整在二分类下的决策边界变化，说明 τ = 1 时边界如何回到平衡先验。★★
    提示
    调整后比较 z1 + τlogπ1 与 z0 + τlogπ0；τ = 1 时边界等价于先验比的对数偏移，恰好抵消训练分布的先验。
  5. 设计完整消融：采样、加权、Logit 调整、想象增强四组开关，指标覆盖整体、最差组、校准误差与训练成本，说明结论的组织方式。★★★
    提示
    24 组全开消融在成本高时可用逐项叠加；报告每组的最差组收益与成本增量，给出推荐组合。

小结

本章把多模态数据不平衡统一到三个轴与四种手段：任务、模态、本体三轴的不平衡，用温度采样、有效样本数加权、Logit 调整与想象增强组合处理；评测以分组指标与最差组为准。

  • 不平衡同时扭曲训练与评测，处理方案必须成对落地；最差组指标是长尾系统质量的底线数字。
  • 温度采样控制组比例、有效样本数加权控制梯度强度、Logit 调整修正决策边界，三者作用面不同、可叠加。
  • 世界模型合成尾部样本要设占比上限并做分歧降权，防止模型偏差被增强样本放大。
  • 采样与加权随训练退火回自然分布，保留轻度平衡以保护尾部组。

研究展望

  • 世界模型的保真度与规划误差的定量关系仍未闭环，长程预测误差界、可验证的想象质量控制是开放问题。
  • 多模态表示的统一词表（视觉、语言、动作、触觉的统一分词）有望简化联合训练的接口，代价与收益尚无定论。
  • 不确定性感知的分层部署（感知、预测、决策各自标定并联合验收）缺少标准协议，值得作为系统研究推进。
  • 评测体系的缺口在跨域与长尾的交叉区：留出域与最差组的联合评测目前多靠拼接，缺少统一基准。

课程走到这里，你已经掌握了从联合训练框架搭建、策略与世界模型深化，到系统集成与评测再平衡的完整方法链。后续的每一步推进（更长的任务、更杂的环境、更严的安全要求），都可以回到本章的技术地图上定位：找到闭环中最弱的一环，用对应章节的机制去加固，再用分组评测验证加固是否真实生效。
