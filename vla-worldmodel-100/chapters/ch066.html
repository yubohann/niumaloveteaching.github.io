第 066 章：世界模型的记忆增强

本章讲世界模型的记忆增强（Memory-Augmented World Model）：用键值记忆（Key-Value Memory）与读写头给动力学提供显式寻址的长期存储，讨论读取的软注意力、写入的门控与使用度衰减，以及基于记忆的检索式回放。

  • 主题：世界模型 / 外部记忆与长时依赖
  • 关键公式：mt = Σi αti vi，αti = softmax(qt·ki / τ)
  • 预计学时：50 分钟
  • 前置章节：第 065 章：VLA策略的迁移学习

学习目标

  • 理解外部记忆（External Memory）给世界模型补充什么：隐状态容量有限，长时依赖需要可寻址的显式存储。
  • 掌握键值记忆的读取机制：余弦相似度加温度的软注意力，以及温度的锐化作用。
  • 掌握写入机制：使用度衰减、最少使用槽位选择、门控写入三个部件如何防止记忆污染。
  • 能实现记忆增强的动力学前向与检索式回放采样，理解记忆读写与动力学梯度路径的隔离设计。
  • 会诊断记忆塌缩、写入污染与遗忘失衡问题，能设计槽数与门控阈值的对照实验。

背景与动机

本节说明外部记忆针对的容量瓶颈：循环隐状态把全部历史压进固定维度的向量。当任务需要记住数秒前某个物体的位置、已经失败的尝试或指令中的早期约束时，逐帧蠕变的重写让早期信息逐渐稀释。外部记忆把历史显式存放：键负责索引，值负责内容，读写头按相似度寻址。世界模型的动力学由此获得可检索的“经验库”：预测时可读取相似历史模式，想象训练可复用存储的隐状态。本章讨论读写机制设计与两个训练风险：记忆塌缩与写入污染。

核心原理

1. 寻址式存储：读的机制

键值记忆由 N 个槽位组成，每个槽有键 ki（用于匹配）与值 vi（承载内容）。读取用查询向量 q 与全部键做相似度匹配，经 softmax 加权求和：

m = Σi αi vi，αi = softmax(q·ki / τ) τ 为温度（Temperature）：τ 越小读头越尖锐，τ 越大读取越分散，接近对全部槽取平均

该读取是内容寻址（Content-Based Addressing）：查询与键的相似度决定读取内容，与槽位编号无关。温度决定记忆的检索粒度：多读头配小温度可以并行提取多个历史模式，单读头配大温度适合获取全局统计。查询向量的构造决定记忆的语义类别：用当前隐状态做查询得到状态记忆，用语言嵌入做查询得到任务记忆。

2. 数值算例：温度对读取分布的塑造

取三个槽位，查询与它们的余弦相似度为 0.9、0.6、0.3。温度 τ = 0.1 时相似度除以温度得到 logits [9, 6, 3]，softmax 后的权重约为 0.950、0.047、0.002：读取几乎完全由第一个槽位贡献，寻址尖锐。把温度调到 τ = 1.0，logits 变为 [0.9, 0.6, 0.3]，权重约为 0.437、0.324、0.240：读取接近三个槽位的均匀平均，寻址性消失。

τ = 0.1：α ≈ (0.950, 0.047, 0.002)；τ = 1.0：α ≈ (0.437, 0.324, 0.240) 两个温度下最优槽位均被选中，差别在于其余槽位被混入的比例：5% 与 56%

数值结果给出两条实践判断：（1）温度从 0.1 升到 1.0 时，次优槽位的混入比例从 5% 上升到 56%，检索信号被稀释一个数量级；（2）相似度间隔决定温度敏感度，间隔大时温度容差宽，间隔小时必须用小温度才能保持寻址，这也解释了为什么键表示需要去相关正则，让语义不同的槽位保持足够的相似度间隔。

3. 写入：使用度衰减与门控

写入的质量决定记忆库的信噪比。三个部件配合：使用度衰减记录每个槽最近的读写强度，ut = γut−1 + αt，γ 取 0.99 量级，长期不用的槽使用度指数下降；写入位置优先选择最少使用的槽，保证新内容有位置可放；门控写入用标量 g ∈ [0, 1] 缩放写入量，vi ← (1 − gαi)vi + gαivnew，低置信样本的 g 趋近零。门控信号常取自预测置信度或预测误差的负值。记忆污染的主要来源是无门控的批量写入：一次错误预测写入的噪声会在后续读取中被反复放大。

4. 记忆塌缩与容量分配

若读取权重长期集中在少数几个槽，其余槽退化为无效容量，称为记忆塌缩（Memory Collapse）。成因是正反馈：被读得多的槽获得更多训练梯度，键表示进一步优化，读权重更集中。缓解手段包括使用度惩罚（对高频槽的读取加惩罚项）、键去相关正则（压低槽间键相似度）与熵正则（对读取分布施加熵下界）。槽的有效利用率是记忆模块第一监控指标：统计读取权重的熵与覆盖槽数，健康状态下两者应随训练缓慢上升，快速塌缩表明容量正在退化。

5. 与联合训练的接口

记忆以两条路径参与联合训练。第一条是条件路径：读取向量拼接进动力学输入，参与下一步预测，梯度经读取路径回流到查询投影。第二条是回放路径：用记忆键检索相似历史隐状态作为 rollout 起点，避免样本同质。写入路径应在 no_grad 下执行：记忆内容是历史快照，让其接受目标梯度会把预测误差反写成记忆错误。两条路径一读一写，共同决定记忆在世界模型中的角色。四种长时依赖承载方式的工程特性对照如下：

承载方式容量单步访问成本可寻址性主要风险适用依赖跨度
循环隐状态固定维度，随隐层维度线性常数级无，只能整体读取早期信息被逐帧重写稀释短程，数帧到数十帧
注意力上下文窗口随窗口长度线性随窗口平方增长软寻址，权重由相似度给出窗口之外的依赖不可见中程，受窗口限制

选择依据是依赖跨度与成本约束的匹配：数帧内的依赖由循环隐状态承担最经济；任务阶段内的依赖用上下文窗口或键值记忆；跨回合的经验复用交给检索式回放。四者可以叠加：注意力主干加键值记忆是当前世界模型常见的组合，回放系统独立于网络之外。先明确要解决的依赖跨度，再选择承载方式，最后才调容量参数，顺序颠倒会把容量问题误诊为机制问题。

实现思路与设计

本节给出接入方案：在世界模型隐空间旁挂一个键值记忆模块；查询由当前隐状态与语言嵌入经投影拼接生成；读取向量并入动力学输入；写入用预测置信度做门控，置信度低于阈值时跳过；检索式回放从记忆取 rollout 起点。训练分两段：先冻结记忆训练动力学，稳定后解冻并加入使用度与熵正则。与第 065 章的差异：第 065 章改变可训练参数集合，本章给网络增加一条带读写协议的外部存储通路。

设计决策：为什么写入在 no_grad 下执行

记忆是历史的映射表，值应当忠实记录当时的状态摘要。若写入路径接受目标函数的梯度，优化器会修改记忆内容来迎合损失，等价于篡改历史证据，读取路径学到的是被优化过的假记忆。梯度只允许经读取进入网络参数，存储本体保持只写不导，这是记忆模块与普通可训练张量的根本区别。

容量与淘汰的参数标定

  • 半衰期与衰减因子。使用度按 u ← γu 衰减时，半衰期等于 ln 0.5 / ln γ：γ = 0.99 对应约 69 次读写，γ = 0.995 对应约 138 次，γ = 0.98 对应约 34 次。先估算任务最长依赖跨度对应的读写次数，再取覆盖该跨度的 γ；顺序反过来会让参数取值失去任务依据。
  • 槽位扩容的触发条件。读权重的覆盖槽数长期低于总槽数的一半时，扩容无意义；覆盖槽数接近槽位上限、且读取熵持续上升时才是扩容信号。扩容时新增槽位从当前键分布的扰动副本初始化，避免全部新槽起步于同一位置。
  • 门控阈值的标定。统计训练早期预测误差的分布，取 70% 到 80% 分位作为写入阈值起点；阈值过低会把大量低质样本写进记忆，过高则记忆更新缓慢。
  • 键维度的下限。键维度低于 64 时，同批次内的键相似度普遍偏高，寻址性差；键维度与值维度不必相同，键可以比值更窄以节省相似度计算，但不宜低于 64。
  • 回放去重间隔的确定。去重间隔按轨迹的时间相关长度设定：动力学自相关衰减到接近零的帧距即为合理间隔，写死 8 只是常见起点，长时缓变任务的间隔应更大。

关键代码与解读

以下片段以记忆网络与检索增强模型的公开设计为参照，接口随版本演进。三个片段分别覆盖读写实现、记忆条件动力学与检索式回放。

片段 1：键值记忆的读与写

import torch
import torch.nn as nn
import torch.nn.functional as F

class KeyValueMemory(nn.Module):
    """键值记忆：读用软注意力，写用使用度与门控。"""
    def __init__(self, n_slots=256, dim=128, decay=0.99):
        super().__init__()
        self.keys = nn.Parameter(torch.randn(n_slots, dim) * 0.01)
        self.values = nn.Parameter(torch.zeros(n_slots, dim))
        # usage 记录最近读写强度：衰减后长期不用的槽位使用度趋近零
        self.register_buffer("usage", torch.zeros(n_slots))
        self.decay = decay

    def read(self, query, tau=0.1):
        # 余弦相似度加温度：tau 小读头尖锐，tau 大读取接近全局平均
        sim = F.normalize(query, dim=-1) @ F.normalize(self.keys, dim=-1).T
        alpha = (sim / tau).softmax(dim=-1)          # B x N
        self.usage = self.decay * self.usage + alpha.sum(0).detach()
        return alpha @ self.values                   # B x D

    def write(self, query, value, gate):
        """把内容写入使用度最低的槽位；门控控制写入量。"""
        with torch.no_grad():                        # 写入不进入梯度图
            # 写入位置优先选择使用度最低的槽位：保证新内容有位置可放
            slot = self.usage.argsort()[: query.shape[0]]
            g = gate.clamp(0.0, 1.0).unsqueeze(-1)   # 低置信样本 g 接近零
            self.keys[slot] = (1 - g) * self.keys[slot] + g * F.normalize(query, dim=-1)
            self.values[slot] = (1 - g) * self.values[slot] + g * value
            self.usage[slot] += 1.0                  # 记录写入，供淘汰与惩罚使用

解读：（1）写入位置按使用度升序选择，新内容优先进入最空闲的槽位；键向写入的查询靠拢，后续同类查询仍能按相似度检索到。（2）门控钳位到 [0,1] 后作为插值系数：物理含义是“新值覆盖旧值的比例”。（3）usage 在读写两处都更新，读取权重之和反映使用强度，为使用度惩罚提供统计量。

片段 2：记忆条件化的动力学一步

def memory_conditioned_step(model, h, a, memory, lang_emb):
    """动力学一步：先读记忆，再与动作一起进入转移核。"""
    # 查询由隐状态与语言嵌入拼接：记忆内容随任务语义切换
    query = model.query_proj(torch.cat([h, lang_emb], dim=-1))
    m = memory.read(query, tau=model.read_tau)       # B x D 读取向量
    # 记忆向量与动作条件拼接：把历史经验显式注入当前预测
    step_in = torch.cat([h, model.act_embed(a), m], dim=-1)
    h_next = model.transition(step_in)
    # 写入候选值为新隐状态摘要；门控由预测不确定性给出
    gate = torch.sigmoid(model.write_gate(torch.cat([h_next, m], dim=-1)))
    memory.write(query.detach(), h_next.detach(), gate)
    return h_next

解读：（1）查询构造融合了任务语义（语言）与状态（隐状态），使同一状态在不同任务下检索不同记忆。（2）写入值 detach 后再入记忆：存储的是快照，不携带计算图。（3）门控由网络输出，训练中自然学会“不确定时不写”，门控阈值在推理时可直接复用。

片段 3：检索式回放的去重采样

@torch.no_grad()
def retrieve_similar(memory, query, n_pick=32, min_gap=8):
    """按查询相似度检索记忆槽，供想象训练的起点多样化。"""
    sim = F.normalize(query, dim=-1) @ F.normalize(memory.keys, dim=-1).T
    # 先取两倍候选：去重会淘汰掉一批，候选池必须留足余量
    cand = sim.topk(n_pick * 2, dim=-1).indices[0].tolist()
    picked, seen = [], set()
    for idx in cand:
        # 与已选槽的索引间距过小视为同一历史片段，跳过以保证多样性
        if all(abs(idx - s) >= min_gap for s in seen):
            picked.append(idx)
            seen.add(idx)
        if len(picked) == n_pick:
            break
    return memory.values[picked]                     # n_pick x D 回放起点

解读：（1）记忆槽的顺序近似按时间写入，索引间距充当时间间隔的粗略代理。（2）去重的目的是增加回放样本的覆盖：同质样本对动力学训练的边际收益低。（3）返回的起点仅含值向量，后续 rollout 由动力学自行展开，检索只负责“从哪里开始想象”。

常见坑

  • 记忆塌缩：读取权重集中到少数槽，其余容量闲置。症状为读取熵快速下降。修复：加入使用度惩罚与键去相关正则，监控覆盖槽数。
  • 写入污染：错误预测以高置信门控写入，噪声记忆被反复读取放大。修复：门控阈值按预测误差分位标定，对高误差样本强制跳过写入。
  • 使用度衰减过快：γ 过小时长期记忆被快速淘汰，跨回合依赖丢失。修复：按任务时长设定半衰期，γ 调到使半衰期覆盖最长依赖跨度。
  • 记忆与动力学联合冷启动：随机初始化阶段记忆内容近似噪声，干扰预测学习。修复：先冻结记忆训练动力学，稳定后再联合微调。
  • 槽位增加带来的读写延迟：槽数翻倍使注意力矩阵与检索开销同步上升。修复：按有效利用率扩容，优先提高压缩效率，再考虑加槽。

练习与思考

  1. 计算题：N = 256、键维 128，计算读取注意力的相似度矩阵规模与每次读取的乘加量级；解释为什么批量 B = 32 时该开销相对动力学主干可以忽略。★
    提示
    相似度矩阵 B × N = 32 × 256，乘加约 1e6 量级；主干单层 MLP 的单次乘加即达到 1e8 量级，记忆读写开销占比不足百分之一。
  2. 把片段 1 的温度 τ 从 0.1 调为 1.0，预测检索精度与记忆覆盖槽数的变化。★
    提示
    τ 增大后读取分布更平坦，检索变模糊、覆盖槽数上升但单次读取信噪比下降；需在寻址性与利用率之间取工作点。
  3. 推导题：写出代价函数对查询投影参数的梯度，说明读取路径为什么能反向训练，而写入路径不能。★★
    提示
    读取的 m = αv 对查询可导，梯度经 α 回传；写入在 no_grad 下执行且值为 detach 快照，路径上不存在可导连接，梯度自然为零。
  4. 实验设计：在需要记忆早期指令约束的长时任务上，比较三组配置：无记忆、记忆无门控、记忆带门控与使用度惩罚。报告成功率、读取熵曲线与关键槽位的内容可视化解。★★
    提示
    预期带门控版本最好：无门控版本早期训练快但后期被污染样本拖累；读取熵曲线用于诊断塌缩。
  5. 设计题：为多相机场景设计记忆分区方案：是否按相机分区、键的表示如何避免跨相机的虚假相似、检索时如何保证时间与空间的联合一致性。★★★
    提示
    键中拼接相机标识与位置编码可抑制跨相机串读；分区会带来容量碎片，可先共享槽位再按标识做软掩码；检索一致性用时间戳与位置的联合查询实现。

小结

  • 键值记忆把历史显式存放：键做内容寻址，值承载内容，读取为温度可调的软注意力。
  • 写入三件套：使用度衰减、最少使用槽选择、门控写入，共同控制记忆库的信噪比。
  • 记忆塌缩是首要训练风险，读取熵与覆盖槽数是最直接的监控指标。
  • 记忆经读取路径参与梯度，存储本体只写不导。
