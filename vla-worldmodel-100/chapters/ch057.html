第三篇 · 策略与世界模型深化

第 057 章：世界模型的随机性建模

未来天然多模态：本章讲清随机潜状态如何表达多种可能、KL 平衡与自由位如何防止潜变量失效，以及采样策略在规划中的使用边界。

  • 主题：世界模型 / 不确定性（Uncertainty）
  • 关键公式：ELBO = Eq[log p(x | z)] − β·KL(q(z | x) ‖ p(z))
  • 预计学时：55 分钟
  • 前置章节：第 056 章 VLA策略的视觉特征提取

学习目标

本章把随机性从"加噪声"升级为"可推断的隐变量结构"，覆盖建模、正则与使用三个层面。

  • 理解未来多模态性（Multimodality）与确定性回归均值的失效：预测模糊的根源是模式平均。
  • 区分偶然不确定性（Aleatoric Uncertainty）与认知不确定性（Epistemic Uncertainty），理解两者的建模与消解方式。
  • 掌握随机潜状态的变分下界（ELBO）、重参数化采样与 KL 平衡（KL Balancing）的损失形式。
  • 掌握自由位（Free Bits）与离散潜变量的承诺损失（Commitment Loss），能诊断后验塌缩（Posterior Collapse）。
  • 能根据用途选择采样策略：规划用采样分布，动作生成用低噪声估计，评估报告不确定性标定。

背景与动机

同一观测与动作之后的环境演化常常存在多个合理分支：杯子可能从两指之间滑落，也可能被稳妥抓起；球落地后可能回弹也可能滚入角落。确定性世界模型以均方误差为训练目标，最优解是多分支的加权均值，视觉上表现为模糊，语义上表现为"两边都不像"的折中状态；以其为条件的策略随之学到保守或摇摆的行为。

随机性建模把"哪一种未来会发生"变成显式的隐变量，模型输出从单点预测变为概率分布。这带来三项收益：预测样本覆盖多个分支；不确定性信号可用于规划中的风险权衡；隐变量本身成为探索与目标采样的信息来源。代价是训练目标从简单回归变为变分推断，损失设计不当会出现潜变量失效。本章按"为什么、怎么建、怎么稳、怎么用"推进，第 042 章的循环核心在此获得其完整的训练形式。

核心原理

从多模态性的来源出发，依次给出变分目标、稳定机制与使用策略。

1. 多模态未来与两类不确定性

未来的分布 p(xt+1 | x≤t, a) 在分支点处呈多峰形态。误差平方损失的最优预测是条件均值，落在峰之间的低概率区域。建模思路是把预测分布展开为"隐变量加确定性映射"：z 选择分支，解码器在给定 z 时给出单峰（或弱多峰）分布。偶然不确定性来自环境本身的随机性，增加数据无法消除，用随机潜变量或输出分布参数表达；认知不确定性来自数据覆盖不足，随数据增加收敛，用集成或贝叶斯近似表达。两类不确定性的用途不同：前者影响规划的风险评估，后者指示探索方向。

2. 变分下界与随机潜状态

后验 q(z | x, h) 吸收当前观测，先验 p(z | h) 只依赖历史；训练目标为证据下界：

ELBO = Eq(z|x,h)[log p(x | z, h)] − β · KL(q(z | x, h) ‖ p(z | h)) 第一项是重构的对数似然，第二项用 KL 把后验拉向先验；β = 1 对应标准变分推断，工程上常做缩放

重参数化采样 z = μ + σ·ξ，ξ 为标准正态噪声，使梯度穿过采样操作。训练完成后推理期只用先验采样，世界模型由此能够脱离观测推演多个未来分支；分支的多样性由先验方差与采样温度控制。

3. 后验塌缩与 KL 平衡

当解码器容量足够强时，它可以忽略 z 直接从 h 重建观测，KL 项因 q 与 p 对齐而趋近零，潜变量失去信息，这一现象称为后验塌缩。诊断方式是测量 z 与观测的互信息或对 z 做置换实验：若置换潜变量后重构质量不变，说明潜变量已失效。

稳定的实现使用 KL 平衡：把 KL 拆成两个方向的停梯度项，分别控制动力学与表示的学习压力：

LKL = βdyn · KL( sg(q) ‖ p ) + βrep · KL( q ‖ sg(p) ) sg 为停止梯度；βdyn 占大头（如 0.8）训练先验逼近后验，βrep 训练后验保持信息

另一道保险是自由位：低于阈值的 KL 不产生梯度，给每个潜维度保留至少若干 nat 的信息容量。自由位防止 KL 项在训练早期把后验压平，阈值随训练推进可下调。离散潜变量场景则用承诺损失：编码器输出向最近码本词元靠拢，码本向编码器输出靠拢，两侧各设系数，防止码本塌缩与编码器漂移。

数值算例：32 维潜变量、每维自由位 0.5 nat，KL 项至少保留 16 nat 的信息容量，可区分 e16 ≈ 8.9×106 种未来分支；任务族可区分的演化模式在千种量级（ln 1000 ≈ 6.9 nat）时，32 维容量充足，继续上调维度只会推高 KL 平衡难度。

4. 采样策略与使用边界

采样引入的方差对下游有双重影响：规划需要多样性，动作执行需要稳定。工程规则：想象 rollout 用采样，从同一潜状态生成多个分支供策略与规划评估；动作输出用后验均值或低温度采样，避免控制信号抖动。温度 τ 缩放先验方差，τ 小于 1 收缩分支、大于 1 扩充分支；规划时的蒙特卡洛评估对 τ 敏感，应把 τ 作为显式超参数校准。

不确定性标定（Calibration）是验收环节：把预测区间的覆盖率与名义置信度比较，覆盖率显著低于名义值时不确定性被低估，规划会冒不该冒的风险。标定曲线在留出集上绘制，按任务阶段分层报告。

实现思路与设计

训练目标由重构损失与 KL 组合构成，β 调度与自由位共同控制信息容量。

损失结构

  1. 重构项：观测对数似然（像素回归或离散分类），主导学习信号。
  2. KL 项：按平衡系数拆分动力学与表示两个方向。
  3. 自由位：每维度 KL 低于阈值部分截断梯度。
  4. 调度：β 随训练从 0.5 升到 1.0，自由位阈值从 1.0 nat 降到 0.5 nat。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖 KL 平衡损失、离散潜变量与规划采样。数值与上表一致。

片段 1：KL 平衡与自由位

import torch
import torch.nn.functional as F

def kl_balanced_loss(mu_q, log_std_q, mu_p, log_std_p, beta_dyn=0.8, free_bits=0.5):
    """按方向拆分的 KL：先验学习与后验保持各自控制，防止后验塌缩。"""
    # 动力学项：KL(sg(q) || p)，梯度只流向先验，让先验学会预测后验
    kl_dyn = kl_gaussian(mu_q.detach(), log_std_q.detach(), mu_p, log_std_p)
    # 表示项：KL(q || sg(p))，梯度只流向编码器侧，保持后验对观测的编码
    kl_rep = kl_gaussian(mu_q, log_std_q, mu_p.detach(), log_std_p.detach())
    # 自由位：逐维 KL 低于阈值部分不产生梯度，保住每维最低信息量
    kl_rep = torch.clamp(kl_rep - free_bits, min=0.0) + free_bits
    return (beta_dyn * kl_dyn + (1 - beta_dyn) * kl_rep).mean()

def kl_gaussian(mu_a, log_std_a, mu_b, log_std_b):
    """KL( N(a) || N(b) ) 的逐维解析式，两个分布均为对角高斯。"""
    var_a, var_b = log_std_a.exp().pow(2), log_std_b.exp().pow(2)
    return 0.5 * ((mu_a - mu_b).pow(2) / var_b + var_a / var_b
                  - 1.0 + 2.0 * (log_std_b - log_std_a))

解读：（1）两个方向共用同一解析式，目标侧参数 detach 后梯度流向分离：动力学项训练先验逼近后验，表示项训练后验保持信息。（2）自由位用 clamp 实现：每维 KL 先减去阈值、取零后再加回，低于阈值的部分梯度为零，高于阈值的部分正常回传。（3）βdyn 与 βrep 之和约束为 1，调度时只动一个参数，实验对照清晰。（4）滑动平均统计逐维 KL 值，若某些维度长期为零且置换实验无影响，说明维度浪费，可缩减潜变量维度。

片段 2：离散潜变量的直通与承诺

def discrete_latent_loss(encoder_out, codebook, commitment=0.25):
    """离散码本量化：编码器输出向码本靠拢，码本向编码器靠拢。"""
    # 最近词元索引：距离按欧氏范数，用广播计算 (B, T, K)
    dist = (encoder_out.unsqueeze(-2) - codebook).pow(2).sum(-1)
    idx = dist.argmin(dim=-1)
    z_q = codebook[idx]                          # 量化后的潜向量
    # 直通估计器：前向用量化值，反向把梯度传给编码器输出（不再求导码本）
    z_st = encoder_out + (z_q - encoder_out).detach()
    # 承诺损失促编码器收敛到码字附近；码本损失更新词元本身
    loss_commit = F.mse_loss(z_q.detach(), encoder_out) * commitment
    loss_codebook = F.mse_loss(z_q, encoder_out.detach())
    # 码本利用率监控：长期未使用的词元触发重置（工程实现中另行处理）
    usage = torch.bincount(idx.flatten(), minlength=codebook.size(0))
    return z_st, loss_codebook + loss_commit, usage

解读：（1）直通写法 encoder_out + (z_q − encoder_out).detach() 保证前向输出等于量化值，反向只经过编码器路径，码本通过独立损失更新。（2）两个损失的方向分开：承诺项把编码器拉向码字，码本项把码字拉向编码器，系数不对等时两侧速度失衡。（3）词元使用统计是诊断码本健康度的直接读数，长期零使用的词元应在训练中重置为随机编码器输出，避免容量浪费。

片段 3：规划中的多分支采样与不确定性

@torch.no_grad()
def sample_futures(model, h0, action_seq, n_samples=8, temperature=1.0):
    """从同一历史生成多条未来分支，供规划评估与风险分析。"""
    futures = []
    for _ in range(n_samples):
        h = h0
        traj = []
        for action in action_seq:
            # 先验采样：温度缩放标准差，控制分支发散程度
            mu, log_std = model.prior(h)
            z = mu + torch.randn_like(mu) * log_std.exp() * temperature
            h = model.step(h, action, z)         # 确定性递推吸收采样噪声
            traj.append(model.decode(h))
        futures.append(torch.stack(traj))
    stack = torch.stack(futures)                 # (S, T, C, H, W)
    # 分支间方差是偶然不确定性的经验估计，供风险敏感的规划使用
    return stack, stack.var(dim=0)

解读：（1）多条分支共享同一历史与动作序列，输出差异完全来自潜变量采样，方差因此是偶然不确定性的干净估计。（2）温度缩放只影响采样标准差，不改变先验均值；规划评估时把温度作为风险偏好的显式旋钮，高温度覆盖更多分支、评估更保守。（3）分支方差在规划目标中可作为惩罚项：期望回报相同的情况下选择方差更低的行为，这一用法要求方差经过标定，否则惩罚强度失去含义。

常见坑

  • 后验塌缩：KL 项趋零、重构良好但潜变量无效。修复：KL 平衡、自由位、置换实验诊断三件套，必要时降低解码器容量。
  • 只用均值解码：预测模糊，多模态分支被平均。修复：训练使用采样重构，评估同时报告采样与均值两种输出。
  • KL 权重过大：先验过早主导，潜变量来不及编码观测信息。修复：β 从 0.5 起步缓慢上升，监控重构与 KL 两条曲线的交叉动态。
  • 混淆偶然与认知不确定性：用潜变量采样方差指示数据不足，探索策略被误导。修复：认知不确定性用集成分歧或贝叶斯近似，两类信号分开记录。
  • 采样噪声进入控制：动作输出用高温采样导致抖动。修复：动作生成用后验均值或 τ 小于 1 的低噪声采样，采样仅用于想象与受扰场景。

练习与思考

  1. 推导：写出两个对角高斯分布之间 KL 的逐维解析式，说明自由位截断为何只影响低于阈值的维度。★★
    提示
    KL = 0.5·Σ(σq²/σp² + (μq−μp)²/σp² − 1 + log(σp²/σq²))；逐维独立，clamp 后低值维度的梯度为零。
  2. 把自由位阈值从 0.5 提到 2.0 nat，预测三件事的变化：重构质量、潜变量分支多样性、KL 总量，并说明验证方式。★★
    提示
    重构可能变好或持平，分支多样性上升，KL 总量上升。验证：多分支预测的覆盖度与留出集重构误差同时报告。
  3. 设计诊断实验区分偶然与认知不确定性：构造数据充足与数据稀缺两类状态，说明用什么信号区分，并给出排查步骤。★★★
    提示
    数据稀缺处集成分歧高、潜变量方差不一定高；数据充足处两者都应低。排查从集成分歧开始，再看潜变量方差是否随之变化。
  4. 规划实验：同一动作序列、温度从 0.5 扫到 2.0，说明任务成功率的预期形态与风险惩罚的关系。★★
    提示
    温度过低时分支保守、探索不足；过高时预测失真、评估失准。成功率曲线通常呈倒 U 形，最优温度与风险惩罚权重联动。

小结

  • 确定性回归在多模态未来上输出模式均值，随机潜变量把分支选择显式化。
  • 偶然不确定性由随机潜状态表达，认知不确定性由集成或贝叶斯近似表达，两者用途不同。
  • 变分目标为重构减 KL，KL 平衡与自由位是防止后验塌缩的两道保险。
  • 离散潜变量用直通估计器加承诺损失训练，码本利用率是需要持续监控的指标。
  • 采样策略按用途区分：想象用采样、动作输出用低噪声估计，温度是风险偏好的显式旋钮。
