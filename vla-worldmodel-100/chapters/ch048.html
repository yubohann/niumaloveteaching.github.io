第三篇 · 策略与世界模型深化

第 048 章：世界模型的在线学习

部署后数据分布持续变化，世界模型需要在线吸收新数据：本章讲清稳定性与可塑性的权衡、回放机制的设计，以及带指数滑动锚点与漂移检测的在线更新流程。

  • 主题：世界模型 / 持续学习（Continual Learning）
  • 关键公式：Lonline = Lpred + β·‖θ − θ̄‖²
  • 预计学时：55 分钟
  • 前置章节：第 047 章 VLA策略的零样本泛化

学习目标

本章围绕"持续更新而不遗忘"这一对矛盾，给出可运行的缓冲区、锚点正则与触发机制。

  • 理解在线学习（Online Learning）的设定差异：数据单遍到达、分布漂移未知、无完整重训窗口。
  • 理解灾难性遗忘（Catastrophic Forgetting）的成因，掌握回放比例（Replay Ratio）对遗忘的抑制机制。
  • 掌握指数滑动平均（EMA）锚点正则的形式与权重含义，能解释它如何限制参数偏离。
  • 会实现漂移检测器，用预测误差统计量的变化触发或暂停在线更新。
  • 能识别在线学习中的正反馈风险：用自身预测污染缓冲区导致误差放大。

背景与动机

离线训练世界模型假设数据分布固定，部署现场却持续引入新物体、新光照与新动力学（例如负载变化改变了关节响应）。完全冻结模型会积累预测偏差，完全在线微调又会覆盖原有能力，在线学习的工程目标是在两个极端之间找到受控的更新幅度。

与离线联合训练相比，在线阶段的三项条件同时变化：样本单遍到达无法反复取样；真实动作标签可能延迟或稀疏；算力预算被控制在推理任务之外的窄窗口。这些条件排除了很多离线手段（重训、大批量对比），把设计空间压缩到回放、正则与触发三类机制的组合。本章按"缓冲区、更新步、检测器"三段结构展开，前三节的机制（对齐、泛化评估）至此进入持续运行形态。

核心原理

先分析遗忘的机制，再依次给出回放、锚点与漂移检测的作用方式。

1. 灾难性遗忘的机制

世界模型的参数在离线阶段承载了跨任务共享的动力学结构。在线更新作用于新分布样本时，梯度方向由新数据的损失主导，共享参数被推向同时降低新损失却升高旧损失的区域。遗忘量随更新步数与学习率的乘积增长，随旧数据在更新批次中的占比下降；当新分布样本占比接近 100% 时，遗忘在数百步内即可发生。

在联合训练框架中，遗忘的后果有两条传播路径：预测误差上升使想象 rollout 质量下降，策略在劣质想象数据上继续训练；潜空间结构漂移使已缓存的动作条件与状态编码失效。两条路径都要求在线更新的幅度受到显式约束。

2. 回放缓冲与回放比例

回放把历史样本与流式新样本混合训练。缓冲区通常采用蓄水池采样（Reservoir Sampling）或环形缓冲：蓄水池采样对任意长度的数据流保持近似均匀的历史覆盖，环形缓冲则保留最近窗口、对旧样本无偏置淘汰。定义回放比例（Replay Ratio）为每次新样本触发的额外训练步数：

RR = 训练步数 / 新样本数，典型取值 1 至 4 RR = 1 表示每条新样本配一次更新；RR 过高时旧数据被反复使用，新分布适应变慢

回放比例与缓冲区容量共同决定新旧分布的混合比例。工程经验是让批次中新样本占比不超过 50%，保留至少一半容量给历史样本。回放抑制遗忘的直接原因在于梯度方向：混合批次的梯度近似新旧损失的加权折中，参数被约束在同时满足两端的区域。

3. EMA 锚点正则

参数空间正则提供第二道防线。以指数滑动平均参数为锚点，在线损失为：

Lonline = Lpred + β · Σi ‖θi − θ̄i‖²，θ̄ ← λθ̄ + (1 − λ)θ θ̄ 为 EMA 参数；β 控制允许的偏离幅度，λ 接近 1 时锚点缓慢跟随主体参数

锚点项把参数拉回离线解附近的邻域，β 越大邻域越小、遗忘越少、适应越慢。λ 的选择决定锚点的时间尺度：λ 取 0.999 时锚点记忆约千步尺度的参数状态，能够逐步跟随分布漂移，同时过滤单批次的噪声梯度。与冻结全部参数相比，这一机制允许共享层小幅调整，把适应能力集中在可塑性更高的解码器与动力学头上。

4. 漂移检测与更新门控

盲目的持续更新会浪费算力并把噪声写入参数。漂移检测器监控预测误差的统计量：对滑动窗口内每一步的预测损失计算均值与分位数，与基准窗口比较，超过阈值则判定分布漂移，开启或加强对在线更新。检测器的价值在于把"是否更新"变成可审计的判据：无漂移区间只做前向推理，漂移区间才付出训练算力。

检测器同时负责异常拦截：单步预测误差远超历史分位时，样本更可能来自传感器故障或标定错误，应先隔离，暂不进入训练。实现上维护两个窗口，正常窗口用于更新基准，异常池用于人工或自动复核，两者共享同一份统计逻辑。

三类机制的定位并排对照：

机制作用对象抑制的问题主要代价
回放缓冲训练样本分布旧分布遗忘缓冲显存与采样开销
EMA 锚点参数偏离幅度快速覆盖离线解新分布适应速度下降
漂移门控更新时机无漂移期算力浪费与噪声写入检测延迟与阈值标定成本

数值示例：交互频率 30 Hz、缓冲区 50000 条时，覆盖约 27.8 分钟的历史（50000 / 30 / 60）；λ = 0.999 的锚点记忆约 1000 步，折算约 33 秒。锚点跟随的是分钟内的参数状态，跨小时的分布漂移由回放样本承载，两者的时间尺度相差约 50 倍，配置时把长时记忆交给回放样本。

实现思路与设计

在线系统的数据流为：流式样本进入缓冲区，检测器决定是否触发更新，更新批次由新样本与历史回放混合构成。

数据流

  1. 每个交互步产生一条转移（观测、动作、后继观测），写入环形缓冲。
  2. 检测器更新预测误差统计，与漂移阈值比较。
  3. 检测到漂移时，从缓冲区按新老配比采样批次，执行带锚点正则的更新。
  4. 每若干步评估旧分布验证集上的预测误差，监控遗忘。

设计决策：为什么冻结视觉编码器？

在线数据量级远小于离线预训练，视觉编码器在少量新数据上继续更新会快速过拟合到近期场景，破坏跨任务的共享特征。把编码器冻结、把在线更新限定在动力学头与解码器，能把可塑性集中在与漂移直接相关的模块上。若漂移确实发生在视觉域（例如新相机标定），应通过一次性标定流程重建编码器统计；交给在线更新逐步修正会引入额外风险。

与前一章的差异点

第 047 章在固定数据集上测量泛化，评估协议围绕划分设计；本章的数据持续到达，没有稳定的评估集边界，验证方式改为在保留的旧分布样本上定期回归测试。泛化关注分布内的因子重组，在线学习关注分布随时间的移动，两者的基准集都需要冻结以保持可比。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖环形缓冲、带锚点的在线更新与漂移门控。数值与上表一致。

片段 1：环形回放缓冲

import numpy as np

class RingBuffer:
    """固定容量的环形缓冲：新样本覆盖最旧样本，保留最近窗口的分布。"""
    def __init__(self, capacity=50000, obs_dim=256, act_dim=7):
        self.capacity = capacity
        self.obs = np.zeros((capacity, obs_dim), dtype=np.float32)
        self.act = np.zeros((capacity, act_dim), dtype=np.float32)
        self.ptr, self.size = 0, 0

    def add(self, obs, act):
        # 覆盖式写入：容量满后最旧样本被替换，无需搬移数组
        self.obs[self.ptr] = obs
        self.act[self.ptr] = act
        self.ptr = (self.ptr + 1) % self.capacity
        self.size = min(self.size + 1, self.capacity)

    def sample(self, batch=64, new_ratio=0.5, fresh=None):
        # 按新老配比组装批次：新样本来自流式队列，历史样本来自缓冲区
        n_new = int(batch * new_ratio)
        n_old = batch - n_new
        idx = np.random.randint(0, self.size, size=n_old)
        old = (self.obs[idx], self.act[idx])
        if fresh is not None:
            f_obs, f_act = fresh
            return np.concatenate([old[0], f_obs[:n_new]]), np.concatenate([old[1], f_act[:n_new]])
        return old

解读：（1）环形缓冲用覆盖代替淘汰，写指针循环推进，内存与时间开销都是常数量级；缺点是老的极端场景会被逐步挤出，需要按任务重要性保留少量长尾样本。（2）采样默认等概率，若某些历史场景对下游更关键，可引入按任务标识的分层配比。（3）新样本占比作为显式入参，便于在漂移检测触发时临时提高，恢复稳定后回落，配比调整与其他超参数解耦。

片段 2：带锚点正则的在线更新步

import torch
import torch.nn.functional as F

def online_update(model, anchor, optimizer, batch, beta=0.01, lam=0.999):
    """在线更新一步：预测损失加锚点惩罚，并更新锚点自身。"""
    obs, act, next_obs = batch
    pred = model.predict_next(obs, act)
    loss_pred = F.mse_loss(pred, next_obs)
    # 锚点惩罚：把参数拉回离线解邻域，抑制对旧分布的遗忘
    loss_anchor = sum((p - p_anchor).pow(2).sum() for p, p_anchor in
                      zip(model.dynamics_parameters(), anchor.parameters()))
    loss = loss_pred + beta * loss_anchor
    optimizer.zero_grad()
    loss.backward()
    # 只更新动力学与解码分支，视觉编码器冻结以保护共享特征
    optimizer.step()
    # 锚点缓慢跟随：lambda 接近 1 时过滤单批次噪声，跟随真实漂移
    with torch.no_grad():
        for p, p_anchor in zip(model.dynamics_parameters(), anchor.parameters()):
            p_anchor.mul_(lam).add_(p.detach(), alpha=1 - lam)
    return loss_pred.item()

解读：（1）锚点参数存放在独立副本中，只参与惩罚与跟随，不接收梯度；实现上可用参数快照加停梯度，避免两套参数互相追逐。（2）惩罚只覆盖动力学分支，视觉编码器既不在优化器参数组中，也不进入惩罚项，边界清晰。（3）注意锚点跟随使用停止梯度的参数值，若直接引用会形成循环计算图，训练时表现为显存缓慢增长。

片段 3：漂移检测与更新门控

import collections

class DriftGate:
    """用预测误差的滑动统计触发在线更新，抑制无漂移期的无效训练。"""
    def __init__(self, window=500, threshold=3.0):
        self.errors = collections.deque(maxlen=window)
        self.threshold = threshold

    def update(self, err):
        self.errors.append(err)
        if len(self.errors) < self.errors.maxlen // 2:
            return False                        # 统计量未稳定前不触发
        baseline = np.mean(list(self.errors)[:self.errors.maxlen // 2])
        recent = np.mean(list(self.errors)[-self.errors.maxlen // 2:])
        # 近期误差超过基线的 threshold 倍，判定分布漂移
        return recent > self.threshold * max(baseline, 1e-8)

解读：（1）窗口对半划分，前半段作为基准、后半段作为近期统计，比较只在稳定样本量后进行，减少冷启动误报。（2）阈值取倍数，对不同任务的误差量纲自适应，绝对差则需要按任务单独标定；3 倍阈值对应近似 5% 以下的误报率，实际部署需在回放数据上校准。（3）触发后建议附带冷却时间与最大更新频率，防止持续漂移期把算力全部投入训练，推理任务仍要维持预算。

常见坑

  • 全参数在线微调：数百步内旧分布误差翻倍。修复：冻结视觉编码器，只更新动力学与解码分支，并监控旧分布验证误差。
  • 正反馈循环：把模型自己想象的转移写回缓冲区，误差被当作数据学习。修复：缓冲区只接收真实交互转移，想象数据用于策略训练但不进入在线更新样本。
  • 归一化统计漂移：输入归一化参数沿用离线值，新场景像素分布变化使激活偏移。修复：输入统计用滑动方式在线更新，模型内部统计保持冻结。
  • 学习率沿用离线配置：在线更新使用 1e-4 量级步长，几次更新即造成明显遗忘。修复：在线学习率降低约一个数量级，配合锚点正则。
  • 缓冲区被异常样本污染：传感器故障段的样本进入回放并被反复学习。修复：用误差分位隔离异常，异常样本进入复核池，不进入训练缓冲。

练习与思考

  1. 推导：若每步更新中新样本占比为 p，回放比例为 RR，说明遗忘速度随 p 上升、随 RR 下降的直觉机制，并给出一个监测遗忘的指标。★★
    提示
    p 决定梯度中新分布方向的主导程度，RR 决定旧样本参与的频率。监测指标：冻结的旧分布验证集上的单步预测误差，按周或按千步记录。
  2. 把锚点权重 β 从 0.01 改为 0.2，预测三件事的变化：新分布适应速度、旧分布遗忘程度、更新损失的可见幅度，并说明如何验证。★★
    提示
    适应变慢，遗忘减少，损失中锚点项占比上升。验证：分别在新旧分布验证集上画误差曲线，观察交叉点位置。
  3. 设计漂移检测的校准流程：用一段已知无漂移的回放数据估计误报率，再用一段人为切换场景的数据估计检测延迟。★★★
    提示
    无漂移段扫阈值得到误报率曲线；人为切换点距首次触发的步数即检测延迟。两指标存在权衡，报告时给出工作点；单点会隐藏权衡关系。
  4. 讨论：若漂移发生在视觉域（新镜头畸变），冻结编码器的方案为何失效？给出两条替代路径并比较成本。★★
    提示
    冻结方案无法修正输入分布变化。路径一：一次性标定并重算归一化统计；路径二：轻量适配器在编码器末端在线更新。前者成本低但需人工流程，后者自动但需额外正则约束。

小结

  • 在线学习的约束是单遍数据、未知漂移与有限算力，设计空间收敛到回放、正则、触发三类机制。
  • 灾难性遗忘随新样本占比与更新强度上升，回放比例与混合配比是直接的控制量。
  • EMA 锚点正则把参数约束在离线解邻域，β 控制适应与保留的权衡，λ 控制锚点时间尺度。
  • 漂移检测器把"是否更新"变成可审计判据，同时承担异常样本拦截。
  • 缓冲区只接收真实转移，归一化统计在线更新、模型内部统计冻结，避免正反馈与激活漂移。
