第 083 章：VLA策略的视觉推理

把"红色方块放到蓝色圆柱左边"这类指令落地，需要对象级表示、关系推理与语言绑定三层能力：本章讲组合泛化的困难与可实现的推理结构。

  • 主题：VLA 策略（Vision-Language-Action, VLA）/ 视觉推理（visual reasoning）
  • 关键公式：槽位注意力的软分配与关系模块的成对聚合
  • 预计学时：50 分钟
  • 前置章节：第 082 章

学习目标

  • 理解组合泛化（compositional generalization）的困难来源：属性与对象的组合空间远大于训练覆盖，分布外组合暴露表示耦合问题。
  • 掌握对象中心表示的核心机制：槽位注意力（slot attention）的软分配、迭代细化与置换等变（permutation equivariance）性质。
  • 掌握关系模块（relation module）的成对特征构造与聚合方式，理解有序拼接与差向量如何共同编码不对称关系。
  • 会搭建"指令解析 → 对象绑定 → 关系落地"的推理流水线，并设计组合划分（compositional split）的评测协议。
  • 能诊断虚假相关（spurious correlation）、槽位坍缩（slot collapse）与绑定错位三类失败模式。

背景与动机

视觉推理的核心难题是组合泛化：识别训练分布内的对象并不困难，把已见属性组合成从未出现的搭配才是分水岭。假设训练数据中红色只出现过方块、蓝色只出现过圆柱，测试要求执行"蓝色方块"与"红色圆柱"，端到端策略往往把颜色与形状纠缠在同一组特征里，无法解耦重组。

此外，指令中的关系谓词（左边、上面、之间）作用于对象对，要求模型具备成对推理能力；语言中的指称（"那个小的"）需要与画面中的具体实例绑定。第 056 章讨论了视觉特征提取的基本结构，本章在其基础上引入对象级分解关系级推理，并在训练与评测协议上强制组合划分，检验真实的泛化能力。这一能力直接决定策略层面对新指令的执行上限。

核心原理

视觉推理由三块拼成：对象中心表示把场景分解为槽位，关系模块对槽位对推理，语言绑定把指令指称落到具体槽位。下面逐块展开。

1. 组合泛化的形式化

设场景由对象集合 O 与属性集合 A（颜色、形状、大小）构成。训练分布覆盖组合子集 Dtrain ⊂ A × O，评测分布包含 Dtest ⊂ A × O 且 Dtest ∩ Dtrain = ∅。若模型的特征表示把属性与对象纠缠（例如"红色"总是以"方块特征"的形式存在），在测试组合上误差必然增大。组合泛化的实现路径是表示解耦（disentanglement）：对象由独立槽位承载身份与位置，属性由轻量分类头从槽位特征中读出，两者的参数通道尽量分离。

Dtest ∩ Dtrain = ∅，泛化目标为 minθ 𝔼(a,o)~Dtest [ ℓ( fθ(a, o), y ) ] a 为属性，o 为对象；仅在训练组合上可优化的模型需要在未见组合上同样成立

2. 槽位注意力：把场景分解为对象

槽位注意力维护 K 个可学习的槽位向量（slot vector），通过 N 个图像块（patch）特征的反复竞争生成对象级表示。每轮迭代包含三步：槽位发出查询 q，图像块提供键 k 与值 v；注意力矩阵沿槽位维度做 softmax，使每个图像块的信息在槽位之间分配；槽位经循环网络（GRU）与 MLP 更新。关键细节是归一化方向：沿槽位维归一化让图像块的信息被竞争性分配，沿图像块维归一化则退化为普通池化。

attnk,n = exp( qk · kn / √d ) / Σk′ exp( qk′ · kn / √d )，slotsk ← GRU( Σn attnk,n vn, slotsk ) d 为槽位维度；分母遍历槽位索引 k′，体现块对槽位的竞争

该结构对对象置换等变：输入图像块顺序改变时，槽位集合的语义分配不依赖块索引。槽位数量 K 大于实际对象数时，多余槽位收敛到背景或空区域，这一性质支持对象数量的泛化。槽位与对象的对应通常不固定，训练时用匈牙利匹配（Hungarian matching）对齐监督标签。

3. 关系模块：成对推理

关系谓词是二元谓词，作用于对象对 (i, j)。关系模块把每对槽位特征拼接为边特征 eij = g( [ oi, oj, |oi − oj| ] )，其中有序拼接承载不对称信息，差向量的绝对值度量相对位移："A 在 B 左边"与"B 在 A 左边"由 eij 与 eji 分别承载。边特征用于两个方面：直接输出关系分类（左、右、上、下、接触、远离），以及聚合回节点特征供下游绑定使用。

eij = gθ( [ oi ‖ oj ‖ |oi − oj| ] )，oi′ = hψ( [ oi ‖ Σj≠i eij ] ) ‖ 表示向量拼接；g 为边网络，h 为节点更新网络

成对计算的复杂度为 O(K2)，K 取 7–12 时可接受；进一步扩展到三阶关系（"位于两物之间"）可用小规模超边，代价是组合数上升。

4. 语言绑定与链式落地

指令解析把自然语言拆成谓词元组（动作，对象属性，关系，参考对象），例如"把红色方块放到蓝色圆柱左边"解析为（放置，{红，方块}，左边，{蓝，圆柱}）。绑定阶段用交叉注意力（cross attention）让每个谓词元组查询槽位集合，注意力权重给出指称对象；当两个对象属性接近时，关系谓词作为消歧证据参与打分。落地阶段按谓词顺序生成子目标序列，"先接近、再抓取、后放置"，每个子目标由低层策略执行。链式子目标的好处在于把长指令的执行失败定位到具体环节，诊断粒度从任务级细化到谓词级。

实现思路与设计

推理流水线为：图像主干特征 → 槽位注意力 → 关系模块 → 指令绑定 → 子目标序列 → 低层动作头。训练时叠加两项辅助损失，评测时使用组合划分协议。

  1. 视觉主干：沿用第 056 章的特征提取器，输出 16×16 的图像块特征，每块 256 维。
  2. 槽位与关系：7 个槽位、迭代 3 轮；关系模块输出 6 类谓词 logits，供辅助监督。
  3. 指令编码：语言编码器输出词元序列，解析器（模板规则或轻量序列模型）抽出谓词元组。
  4. 辅助损失：槽位重建损失（用槽位解码出对应图像块）与关系分类损失，权重各 0.1，主损失为动作与子目标监督。
  5. 与第 056 章的差异：特征提取升级为对象级分解加成对推理，评测协议新增组合划分；主干结构不变，便于消融对比。

设计决策：为什么用槽位重建做辅助损失？

重建迫使每个槽位保留足够的对象级信息（颜色、形状、位置），否则解码器无法恢复图像块。重建目标与动作目标互补：动作损失只关心任务相关对象，重建损失覆盖全部对象，抑制表示被少数目标对象独占。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：槽位注意力模块

class SlotAttention(nn.Module):
    """对象级分解：K 个槽位竞争解释全部图像块。"""
    def __init__(self, n_slots=7, d_slot=128, d_in=256, iters=3):
        super().__init__()
        self.n_slots, self.iters = n_slots, iters
        self.norm_in = nn.LayerNorm(d_in)
        self.to_q = nn.Linear(d_slot, d_slot)   # 查询由槽位发出，表示"我在找什么"
        self.to_k = nn.Linear(d_in, d_slot)     # 键值由图像块提供，表示"我是什么"
        self.to_v = nn.Linear(d_in, d_slot)
        # 槽位初值可学习：不同槽位从不同方向出发，降低对称僵局概率
        self.slots_mu = nn.Parameter(torch.randn(1, n_slots, d_slot) * 0.02)
        self.slots_logsigma = nn.Parameter(torch.zeros(1, n_slots, d_slot))
        self.gru = nn.GRUCell(d_slot, d_slot)
        self.mlp = nn.Sequential(nn.Linear(d_slot, 2 * d_slot), nn.ReLU(),
                                 nn.Linear(2 * d_slot, d_slot))

    def forward(self, x):
        # x: (B, N, d_in) 图像块特征；返回槽位表示与最终分配矩阵
        x = self.norm_in(x)
        k, v = self.to_k(x), self.to_v(x)
        b = x.size(0)
        slots = self.slots_mu + torch.exp(self.slots_logsigma) * torch.randn(
            b, self.n_slots, k.size(-1), device=x.device)
        attn = None
        for _ in range(self.iters):
            q = self.to_q(slots)
            # 键与查询做内积后沿槽位维 softmax：块对槽位的竞争性分配
            logits = torch.einsum("bnd,bmd->bmn", k, q) / (q.size(-1) ** 0.5)
            attn = torch.softmax(logits, dim=1)
            # 沿块维归一化表示块的质量守恒，防止某些块被多槽位重复计数
            attn = attn / (attn.sum(dim=-1, keepdim=True) + 1e-8)
            updates = torch.einsum("bnm,bnd->bmd", attn, v)
            slots = self.gru(updates.reshape(-1, updates.size(-1)),
                             slots.reshape(-1, slots.size(-1)))
            slots = slots.reshape(b, self.n_slots, -1)
            slots = slots + self.mlp(slots)      # 残差式更新，稳定深层堆叠
        return slots, attn

解读：两次归一化方向不同，第一次沿槽位维产生竞争，第二次沿块维保证质量守恒，这是槽位注意力与原版注意力的核心区别。槽位初值从可学习的均值与方差采样，随机性在多次前向中帮助不同槽位收敛到不同对象；若固定初值，对称场景下多个槽位可能收敛到同一对象（槽位坍缩）。slots + self.mlp(slots) 的残差设计让更新幅度可控，迭代 3 轮即可稳定。attn 在推理阶段还可作为可视化工具，验证每个槽位覆盖的区域是否符合语义。

片段 2：关系模块与不对称边特征

class RelationModule(nn.Module):
    """成对关系打分：边特征同时用于关系分类与节点更新。"""
    def __init__(self, d_slot=128, d_rel=64, n_rel=6):
        super().__init__()
        # 拼接 [o_i, o_j, |o_i - o_j|]：有序拼接承载方向，差向量度量相对位移
        self.edge_mlp = nn.Sequential(nn.Linear(3 * d_slot, d_rel), nn.ReLU(),
                                      nn.Linear(d_rel, d_rel))
        self.node_mlp = nn.Sequential(nn.Linear(d_slot + d_rel, d_slot), nn.ReLU())
        self.rel_head = nn.Linear(d_rel, n_rel)

    def forward(self, slots):
        b, n, d = slots.shape
        si = slots.unsqueeze(2).expand(b, n, n, d)   # 主对象
        sj = slots.unsqueeze(1).expand(b, n, n, d)   # 参考对象
        edge = self.edge_mlp(torch.cat([si, sj, (si - sj).abs()], dim=-1))
        # 每个对象汇总与其余全部对象的边：关系证据进入节点表示
        nodes = self.node_mlp(torch.cat([slots, edge.sum(dim=2)], dim=-1))
        return nodes, self.rel_head(edge)            # 关系 logits: (B, N, N, 6)

解读：unsqueeze + expand 构造全部有序对，避免显式循环；内存代价 O(BN2d)，K = 7 时约为 50 倍单槽位开销，仍在可控范围。边网络输出同时服务于两条通路：分类头监督关系谓词，聚合通路把关系证据写回节点表示。若只保留分类头，关系信息不会影响动作决策，指令中的关系谓词便无法落地。sum 聚合选择无参数求和，比注意力聚合更稳定；对象数变化时语义不变。

片段 3：组合划分采样器

def compositional_split(records, held_out_pairs, rng, batch_size=128):
    """按属性组合划分数据：训练集与评测集的组合空间不相交。"""
    train_pool, eval_pool = [], []
    for r in records:
        key = (r["color"], r["shape"])          # 属性组合作为划分键
        (eval_pool if key in held_out_pairs else train_pool).append(r)
    # 训练批次只从已见组合采样，评测集只在未见组合上构造
    idx = rng.choice(len(train_pool), size=batch_size, replace=False)
    return [train_pool[i] for i in idx], eval_pool

解读：划分键选用属性组合，保证测试集考察的是"未见搭配"；按完整场景划分只会得到"未见场景"。采样器在数据加载层强制生效，避免任何训练批次泄露留出组合。held_out_pairs 的选择有两条约束：每个属性值都要在训练集中出现，避免把组合泛化与属性覆盖问题混在一起；留出比例按评测严格度设定，例如颜色 5 种、形状 6 种（共 30 个组合）时留出 6 个组合，占组合空间的 20%。评测报告需同时给出已见组合与未见组合两组数字，两者差距即组合泛化间隙（compositional gap），是衡量推理结构有效性的核心指标。

常见坑

  • 虚假相关：训练集中红色对象总在左侧，模型用位置特征代替颜色推理。症状是留出组合准确率骤降而训练集准确率不变。修复：组合划分评测加随机化位置增强，检查颜色分类头对位置的互信息。
  • 槽位坍缩：多个槽位收敛到同一显著对象，其余对象无槽位承载。症状是重建图中背景区域模糊、对象计数错误。修复：检查注意力熵，必要时对分配矩阵加入熵正则或提高槽位初值随机性。
  • 绑定错位：两个同色对象并存时指称解析到错误实例。症状是关系谓词正确但作用对象错误。修复：让关系谓词参与绑定打分，或对近似实例引入位置量化特征辅助消歧。
  • 只测已见组合：评估报告缺失留出组合，推理结构的收益无法度量。修复：评测协议固定包含组合划分，并报告组合泛化间隙。
  • 关系方向处理错误：把左右关系当作对称处理（只保留 |oi − oj| 一类对称量，丢掉有序拼接），模型学不到方向。修复：保留有序拼接 [oi, oj]，差向量作为辅助几何特征。

练习与思考

  1. 证明槽位注意力的置换等变性质：当图像块集合按任意置换重排时，槽位表示（集合意义下）不变。指出成立所需条件。★
    提示
    注意力对块的求和遍历与块顺序无关；成立条件是槽位初值的随机性固定或对置换对称，否则需在期望意义下体现。
  2. 把槽位数量从 7 改为 4 后重新训练，预测对象计数任务与重建质量的走向，并解释多余槽位的作用。★
    提示
    场景对象数超过 4 时发生竞争，重建变差；多余槽位原本用于吸收背景，减少后背景信息挤占对象槽位。
  3. 设计一个组合划分方案：属性为 5 种颜色 × 6 种形状（共 30 个组合），给出留出的 6 个组合（约 20%）与理由，并说明如何避免划分键泄露。★★
    提示
    让 6 个留出组合覆盖全部 5 种颜色与 6 种形状（例如每个形状配一个颜色），同时保证每个属性值在训练集中出现；检查数据加载、增强与评测全部使用同一切分。
  4. 交换两个样本的语言词元后观察绑定注意力矩阵，设计实验验证绑定依赖对象属性、排除位置捷径。★★
    提示
    构造同位置不同属性的两对场景，比较注意力峰值对象；若绑定随属性变化而变化，则为属性驱动。
  5. 分析三阶关系（"位于两个物体之间"）的 O(K3) 计算代价，提出两种降复杂度方案（例如先筛选候选对再组合），并估计 K = 10 时的相对开销。★★★
    提示
    先做空间邻近筛选把候选对从 45 降到 10 以内，再做超边组合；用期望候选数替代组合上界估算。

小结

  • 视觉推理的分水岭是组合泛化，评测必须使用组合划分并报告组合泛化间隙。
  • 槽位注意力通过沿槽位维的竞争分配把场景分解为对象级表示，二次归一化与随机初值是防坍缩关键。
  • 关系模块用有序对编码不对称谓词，绝对差向量补充相对位移，边特征同时服务分类与节点更新。
  • 语言绑定借助交叉注意力把谓词元组落到槽位，关系谓词参与消歧；链式子目标提供谓词级诊断粒度。
