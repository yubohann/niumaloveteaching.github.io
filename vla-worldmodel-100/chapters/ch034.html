第二篇 · 联合训练进阶与策略能力

第 034 章：联合训练中的语言条件世界模型

同一观测下不同指令对应不同未来；本章讲清语言条件的注入方式、条件丢弃与分类器无关引导，以及语言泄漏与条件敏感性两类诊断。

  • 主题：条件世界模型（conditional world model） / 语言条件注入
  • 关键公式：p( xt+1 | x≤t, at, l )；条件丢弃（condition dropout）；引导系数 w
  • 预计学时：50 分钟
  • 前置章节：第 033 章

学习目标

  • 理解语言条件在预测中的作用：未来分布是多峰的，指令决定进入哪一个模式。
  • 掌握三种条件注入方式（交叉注意力、自适应层归一化调制、前缀 token）的结构与适用位置。
  • 掌握条件丢弃与引导系数的组合使用，能调节条件强度并解释其副作用。
  • 会设计条件敏感性检查与语言泄漏检查，验证条件通道真实生效且未携带未来信息。
  • 能诊断条件被忽略、动作被条件淹没与指令粒度错配三类问题。

背景与动机

无条件的视频预测在面对"把杯子推到桌边"与"把杯子放回托盘"这类场景时陷入两难：同样的观测与动作历史，未来有多个合理走向，回归式预测输出各模式的加权平均，两组轨迹都预测不准。任务指令给出的是模式选择的信息，条件世界模型（conditional world model）把指令嵌入为条件变量，把预测分布分解为"以指令为索引的多个模式"。

与 VLA 策略共享语言编码器带来双重收益：策略的语言理解能力可以迁移到预测，预测任务又反向为语言编码器提供动作后果层面的监督。联合训练的关键是梯度流设计：语言编码器同时接收动作预测损失与未来预测损失的梯度，两者对语言表征的需求需要协调。

本章与第 033 章的衔接：跨具身对齐统一了动作空间，语言条件统一了任务条件；两者叠加后，世界模型可以对"任意身体、任意指令"做条件预测。第 035 章的闭环控制将消费条件预测的输出。

核心原理

1. 条件预测的形式与注入位置

语言条件世界模型的预测目标为：

p( xt+1 | x≤t, at, l ) x≤t 为历史观测，at 为当前动作，l 为语言指令；条件对整段预测生效，属于全局条件

三种注入方式的结构与代价：

方式结构表达力成本
交叉注意力预测器各层以视觉特征为查询、语言 token 为键值强，可细粒度对齐序列长度增加，显存上升
自适应层归一化语言嵌入生成缩放与偏置，调制每层归一化中，全局风格调制轻量，参数量小
前缀 token语言嵌入作为序列前缀参与自回归中，与语言模型同构序列变长，需注意因果掩码

选择依据：需要对象级细粒度条件（"把红色积木放到蓝色盒子"）时用交叉注意力；只需要任务级风格（"慢速移动"）时自适应层归一化成本更低；与自回归世界模型同构的框架里前缀 token 最自然，但要防止语言 token 位置泄漏帧间信息。

前缀 token 的因果掩码细节值得单独说明：语言 token 位于序列前端时，自回归注意力保证后续帧只能看到语言前缀，方向正确；若语言 token 插在序列中段或尾部，帧间注意力可能经由语言位置间接读到未来帧，泄漏检查应覆盖注意力可见性分析，不能只看预测误差。

2. 条件丢弃与分类器无关引导

训练时以一定概率（如 10%）把语言条件替换为空条件，模型同时学会条件预测与无条件预测。推理时按分类器无关引导（Classifier-Free Guidance, CFG）组合两者：

x̂t+1 = fθ( zt, at ) + w · [ fθ( zt, at, l ) − fθ( zt, at ) ] w 为引导系数：w = 1 退化为普通条件预测；w 大于 1 放大条件方向的作用；w = 0 退化为无条件预测

引导的机制是把"条件带来的变化方向"外推：w 越大预测越贴合指令，但过度外推（w 明显大于 2）会让预测偏离数据流形，出现饱和伪影。生成建模中的经验区间是 1.5 至 2.0，世界模型场景下由于还要保证物理一致性，常用更保守的 1.2 至 1.5。

该外推可用分数（score）分解解释：若 f 近似数据对数密度的梯度，对数密度按条件分解为 log p(z | l) = log p(z) + log p(l | z)，条件与无条件预测之差对应隐式分类器的梯度方向。用 w 缩放该方向，等价于把条件分布按 [p(l | z)]w − 1 重新加权：w 大于 1 锐化更贴合指令的模式，w 小于 1 松弛条件，w = 1 保持训练时的原始条件强度。

数值算例：一维潜变量上无条件预测 0.2、条件预测 0.5，条件方向幅度为 0.3。w = 1.3 时输出 0.2 + 1.3 × 0.3 = 0.59；w = 2 时 0.8；w = 2.5 时 0.95。若训练数据中该变量的取值范围为 [0, 0.6]，则 w 超过 1 + (0.6 − 0.5) / 0.3 ≈ 1.33 后输出已越过观测范围，落到流形之外。世界模型场景取 1.2 至 1.5 与此机制一致：小幅锐化保留动作通道的作用，在出界之前停止。

条件丢弃率的数值形态：批次 64 时丢弃率 10% 对应每批平均 6.4 个空条件样本，条件分支与无条件分支的梯度更新比例约为 9 : 1。丢弃率升到 30% 时条件样本降到约 45 个，模型在条件输入下的有效学习量下降三成；丢弃率为 0 时无法获得无条件分支，引导在部署时不可用。10% 是让两个分支都获得足够更新的起点，部署以纯条件推理为主时可适度下调。

3. 对齐损失与多粒度条件

仅靠预测损失的语言监督偏弱：指令与预测帧的相关性需要显式鼓励。对比对齐损失把指令嵌入与未来帧特征拉到同一空间（细节在第 038 章展开）：

Lalign = − log [ exp( s(zl, zf) / τ ) / Σ负样本 exp( s(zl, zf−) / τ ) ] zl 为指令嵌入，zf 为对应未来片段特征，负样本取同批次其他片段的特征，τ 为温度

多粒度条件把指令拆成对象级与动作级短语分别对齐：对象短语对齐到物体区域特征，动作短语对齐到运动区域特征。实现上需要短语级标注或自动解析（依存分析提取名词组与动词组）。颗粒度与预测步长需要匹配：动作短语对应短时运动（数步），对象短语对应整个预测窗口的语义不变性。

对齐温度的作用可以用数值感受：τ = 0.07 时，相似度差 0.2 对应权重比 exp(0.2 / 0.07) ≈ 17 倍，损失对负样本的选择非常敏感；τ = 0.2 时同一差值只对应 exp(1.0) ≈ 2.7 倍，对齐信号变平滑。温度随批次内负样本数量调整：负样本越多，可用的温度越小以保持区分度；负样本很少时温度过小会让梯度集中在个别样本上，训练抖动。

4. 语言泄漏与条件敏感性

语言泄漏（language leakage）指条件通道携带了预测目标的信息，模型靠"抄答案"降低损失。三类来源：指令中包含未来状态的描述（"抓起杯子后移动到托盘上方"作为指令出现）；语言编码器与状态编码器共享了未来帧的注意力路径；数据切分时同一条轨迹的指令与未来片段出现在同一批。检查方法：把同一指令配到不同的历史观测上，若预测差异异常小，说明预测不依赖历史，正在利用指令中的未来信息。条件敏感性与泄漏检查是一对：条件必须改变预测（敏感性），但改变的程度必须来自合法的任务信息（无泄漏）。

条件敏感性检查：固定历史与动作，替换语义相关的不同指令，预测应显著不同；替换同义改写指令，预测应基本不变。两个方向共同验收条件通道：前者的差异验证条件生效，后者的稳定验证语言表征的语义不变性。

合法条件的边界需要写进数据规范：指令描述目标与意图（"把红色积木放进蓝色盒子"），不描述执行过程与时刻（"先向右移动再下压"属于轨迹级信息）。含过程描述的指令让预测任务退化为轨迹重构，表面误差下降，条件通道学到的却是被禁止的答案通路。数据清洗按词表过滤时序词与方位时序描述，并在人工抽查中确认指令改写后任务意图不变；改写评测量本身也应纳入数据资产，供泄漏检查复用。

实现思路与设计

语言条件世界模型在联合训练框架中的改造分四步：语言编码器接入、条件注入、条件丢弃训练、推理引导。与第 033 章的差异：033 统一动作空间，本章统一任务条件。

  1. 语言编码器：与 VLA 策略共享权重；先冻结窗口结束后解冻联合微调，学习率取骨干的十分之一。
  2. 条件注入：预测器 Transformer 每层加入自适应层归一化调制；需要细粒度对齐的任务叠加二层交叉注意力。
  3. 条件丢弃：训练时 10% 的批次用空条件，保证 CFG 可用；空条件用固定的占位嵌入。
  4. 推理引导：w 默认 1.3；在两个候选值（如 1.0 与 1.5）上做敏感性扫描，按物理一致性指标选择。

与跨具身条件的协同需要留意一处冲突：指令中的动作词可能带有具身特异性（"用两指捏住"），不同本体无法执行同一种捏取。处理原则是让指令停留在意图层，动作实现交给具身适配层；数据规范把同类动作词按意图归并（捏、夹、抓统一为抓取），执行细节由本体能力决定，避免策略学到无法迁移的动作描述。

注意：条件过强会让动作通道失效

引导系数过大或对齐权重过高时，预测完全由指令驱动，动作输入对预测的影响被淹没，想象轨迹不能反映"如果换个动作会怎样"。检查方法：固定观测与指令，替换动作输入，预测差异应大于阈值。动作敏感性是条件世界模型可用性的底线指标。

三项检查的数值例子：某版本测得语义差异 0.05、改写差异 0.004、动作差异 0.030。语义与改写之比为 12.5，满足 5 倍阈值；动作差异为语义差异的 60%，高于"不低于一半"的验收线，条件通道与动作通道的强度关系健康。若动作差异降到 0.01（不足语义差异的 25%），判定为条件淹没动作，处理顺序是先把 w 下调到 1.1、检查对齐损失权重的实际梯度贡献，再重跑三项检查。

关键代码与解读

以下片段参照公开的条件生成与世界模型实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：语言条件注入与条件丢弃

import torch
import torch.nn as nn

class LangConditionedBlock(nn.Module):
    """在预测器块上用自适应层归一化注入语言条件，含条件丢弃。"""
    def __init__(self, dim, lang_dim, drop_p=0.1):
        super().__init__()
        self.norm = nn.LayerNorm(dim, elementwise_affine=False)
        self.mlp = nn.Sequential(nn.Linear(dim, dim * 4), nn.SiLU(),
                                 nn.Linear(dim * 4, dim))
        # 语言嵌入到调制参数：输出 2*dim 的缩放与偏置
        self.to_mod = nn.Linear(lang_dim, dim * 2)
        self.null_lang = nn.Parameter(torch.zeros(lang_dim))  # 空条件占位
        self.drop_p = drop_p

    def forward(self, x, lang_emb):
        keep = torch.rand(x.shape[0], 1, device=x.device) > self.drop_p
        # 条件丢弃：被丢样本用空条件，同一次前向两种模式共存
        cond = torch.where(keep, lang_emb, self.null_lang.expand_as(lang_emb))
        scale, shift = self.to_mod(cond).chunk(2, dim=-1)
        h = self.norm(x) * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)
        return x + self.mlp(h)

解读：（1）自适应层归一化把语言嵌入变成逐通道的缩放与偏置，注入成本是两层线性，显著低于交叉注意力；（2）条件丢弃按样本级随机执行，同一批次中约 10% 的样本走空条件，训练效率高于"整批全丢"；（3）空条件用可学习参数表示，与零向量语义不同，网络可以区分"无指令"与"低维零嵌入"两种情形；（4）残差结构保证丢弃条件下仍能正常前向，两种模式共享全部底层参数。

片段 2：分类器无关引导的单步预测

@torch.inference_mode()
def guided_transition(world_model, z, a, lang_emb, w=1.3):
    """CFG 组合条件与无条件预测：外推条件方向，w 控制强度。"""
    # 无条件分支：语言替换为空条件，其余输入完全一致
    z_uncond = world_model.transition(z, a, cond=world_model.null_lang)
    # 条件分支：正常语言嵌入
    z_cond = world_model.transition(z, a, cond=lang_emb)
    # 线性外推：w=1 退化为条件预测，w 大于 1 强化条件的作用
    z_next = z_uncond + w * (z_cond - z_uncond)
    return z_next

解读：（1）两次前向共享除条件外的全部输入，差向量是"纯粹由语言引起的变化方向"；（2）外推发生在潜空间，相比像素空间更容易保持物理量的一致性，潜空间的过冲由后续不确定性检查兜底；（3）推理开销翻倍，实时场景可把两条分支合并为一次批量前向；（4）w 需要扫描选择，评估指标除预测误差外必须包含动作敏感性与物理一致性。

片段 3：条件敏感性与泄漏检查

@torch.inference_mode()
def condition_checks(world_model, batch, lang_emb, lang_paraphrase, lang_other):
    """三项检查：敏感性（换指令变）、不变性（同义改写不变）、动作敏感性。"""
    a = batch["action"]
    z = world_model.encode(batch["obs"])
    base = world_model.transition(z, a, cond=lang_emb)
    # 1) 语义不同的指令：预测应显著偏离基线
    diff_other = (world_model.transition(z, a, cond=lang_other) - base).abs().mean()
    # 2) 同义改写：预测应接近基线，验证语义不变性
    diff_para = (world_model.transition(z, a, cond=lang_paraphrase) - base).abs().mean()
    # 3) 替换动作：差异应大于阈值，证明预测仍受动作驱动
    a_alt = batch["action_alt"]
    diff_act = (world_model.transition(z, a_alt, cond=lang_emb) - base).abs().mean()
    return {"diff_other": float(diff_other), "diff_para": float(diff_para),
            "diff_act": float(diff_act)}

解读：（1）三项差值构成条件通道的验收三角：语义差异大、改写差异小、动作差异大；（2）阈值按验证集的分布设定，例如语义差异应为改写差异的 5 倍以上；（3）动作差异过小是"条件淹没动作"的直接信号，需要下调引导系数或对齐权重；（4）检查脚本与训练流程分离，作为模型版本的回归测试资产保留。

常见坑

  • 语言泄漏：指令文本包含未来状态描述，模型靠条件通道"抄答案"。症状是预测误差很低但动作敏感性差。修复：清洗指令文本，限定为任务级意图；用"同指令配不同历史"的检查暴露依赖。
  • 条件被忽略：条件丢弃率过高或对齐权重过低，模型退化为无条件预测。修复：检查被丢弃样本与正常样本的损失差，差异过小说明条件通道没有被有效使用。
  • 动作被条件淹没：引导系数过大，预测主要随指令变化。修复：动作敏感性检查作为验收项，超标时下调 w。
  • 指令粒度与预测步长错配：动作级短语对齐到长时窗口，语义不对应。修复：按短语类型分组对齐，短时窗口对齐动词组，长时窗口对齐对象组。
  • 语言编码器长期冻结：联合训练后期条件仍停留在预训练语义，与动作后果脱节。修复：解冻窗口与较低学习率并行，先解冻顶层再逐层放开。

练习与思考

  1. 把引导系数 w 从 1.3 提升到 2.5。预测预测误差、动作敏感性与物理一致性指标的变化，并指出该类任务中 w 的上限由什么决定。★
    提示
    条件贴合度上升、预测误差在语义相关区域可能下降，但外推过冲让物理一致性恶化、动作敏感性下降。上限由物理一致性与动作敏感性的容忍阈值共同决定，无法事先固定。
  2. 推导：在潜空间线性外推下，证明 w = 1 时引导预测等于条件预测，w = 0 时等于无条件预测；并说明 w 取负值会发生什么。★★★
    提示
    代入定义式即得两个端点；w 为负时预测沿"反条件"方向外推，得到与指令语义相反的预测，物理上通常无意义，但可作为条件通道方向的诊断探针。
  3. 设计条件丢弃率的消融：0%、10%、30% 三组，预测各组在"有指令"与"无指令"推理下的预测误差差异，并给出选择依据。★★
    提示
    0% 时无法做 CFG 且无指令推理性能差；30% 时条件利用率不足；10% 在两类推理间取得平衡。选择依据是部署时两种推理模式的占比，纯条件推理场景可降低丢弃率。
  4. 构造一个语言泄漏场景并说明用哪项指标检测：指令写作"把杯子推到桌沿"，而训练片段里所有该类轨迹都在第 10 步后停止。预测该模型的失败模式与检查方法。★★
    提示
    模型把"桌沿"与"第 10 步停止"绑定，换场景后时间尺度错乱。检查方法是同指令配不同长度历史、跨场景评估，以及动作敏感性检查；修复从指令文本规范与数据多样性入手。
  5. 计算：无条件预测 0.2、条件预测 0.5，写出 w = 0、1、1.3、2 的输出；数据取值范围 [0, 0.6] 时，求外推越界的最小 w。★★
    提示
    输出为 0.2 + w × 0.3：w = 0 得 0.2，w = 1 得 0.5，w = 1.3 得 0.59，w = 2 得 0.8。越界条件 0.2 + 0.3w 大于 0.6 给出 w 大于 1.333。安全 w 取决于条件方向幅度与数据范围之比，逐任务扫描比全局定值可靠。

小结

  • 语言条件把多峰未来分解为任务索引的模式，克服无条件平均预测的模糊。
  • 注入方式按粒度选择：交叉注意力适合对象级条件，自适应层归一化适合任务级调制。
  • 条件丢弃训练出空条件分支，引导系数外推条件方向，取值受物理一致性与动作敏感性约束。
  • 对齐损失提供显式语言监督，多粒度短语对齐需要与预测步长匹配。
  • 条件敏感性、语义不变性与动作敏感性三项检查共同验收条件通道，泄漏检查防止"抄答案"。
