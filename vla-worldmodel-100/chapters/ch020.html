第一篇 · 基础框架与联合训练

第 020 章：世界模型在部分可观测环境中的应用

本章收束第一篇：把世界模型用作学习到的信念构造器，处理遮挡、视野受限与观测缺失，讲清递推记忆的状态更新、序列训练中的预热段设计，以及记忆能力的探测式评估。

  • 主题：世界模型 / 部分可观测
  • 关键公式：bt = f(bt-1, ot, at-1)
  • 预计学时：65 分钟
  • 前置章节：第 019 章

学习目标

  • 理解部分可观测（Partial Observability）的四种来源及其对策略与预测的影响。
  • 掌握信念状态（Belief State）的递推定义，理解历史作为近似充分统计量的含义。
  • 掌握递推记忆结构的选择：帧堆叠、门控循环单元（Gated Recurrent Unit, GRU）与历史注意力的取舍。
  • 掌握序列训练中的预热段（Burn-in）设计，理解冷启动状态对损失与梯度的影响。
  • 能设计记忆探测评估，区分“模型记住了”与“策略依赖了记忆”两类结论。

背景与动机

绝大多数单帧信息不足以决定行动：桌沿后的杯子、被遮挡的接触点、离开视野正在移动的物体，都要求系统利用历史推断当前状态。部分可观测把问题从“从观测映射动作”升级为“从观测历史推断状态、再据状态映射动作”，世界模型在这条链路上承担状态推断器的角色。

联合训练在此有结构性优势：世界模型的训练目标就是“从历史预测未来”，该目标逼着隐状态携带观测中不可见但可推断的信息（速度、被遮挡物体的存在）；共享主干时，这类推断能力自然流入策略路径。

本章收束第一篇：把前 19 章机制放进部分可观测视角检验。与后篇接口：066 章扩展记忆结构，036 章处理长程预测误差，017 章的潜变量是本章记忆设计的直接来源。

核心原理

1. 观测不完全的四种来源

遮挡：目标被自身结构或环境物体挡住；视野限制：传感器物理覆盖之外的状态不可见；传感噪声：观测是状态的失真投影；时延：看到的是若干步之前的世界。四种来源共同要求系统维护“当前状态可能是什么”的分布，即信念状态：

bt(s) = P( st = s | o≤t, a<t ) ，πθ(at) = πθ(at | bt) b 为信念分布；策略以信念为输入的表示能力强于仅以当前观测为输入

严格贝叶斯更新需要已知动力学与观测模型，真实系统两者都未知且高维；工程替代是学习递推状态近似信念：用有限维隐向量承载继续预测所需的信息，预测损失充当训练信号。

数值算例：信念的递推更新

取一个两位置二值例子：物体在一个遮挡物后有左、右两种可能位置，先验各 0.5。连续三帧都看不见物体，观测似然为 P(看不见 | 左) = 0.3、P(看不见 | 右) = 0.6。逐帧更新：第 1 帧后 P(左) = (0.5 × 0.3) / (0.5 × 0.3 + 0.5 × 0.6) = 0.333；第 2 帧后 0.2；第 3 帧后 0.111。用对数几率看更清楚：每帧更新把对数几率加上 ln(0.3 / 0.6) = −0.693，三帧累加得 −2.08，还原概率即 0.111。这个加性结构解释了为什么递推状态可以“少而准”：只要隐向量承载的是对数几率一类的充分统计量，逐步累积与一次性批处理的结果一致，逐帧更新不损失信息。反过来，若两位置的看不见似然相同（0.5 对 0.5），更新量为零，信念停在先验，观测对该区分不提供任何信息，这正是“单帧无解”的数学形式。

2. 历史的递推编码

信念的递推形式为“旧信念加新观测与上一动作”：

bt = fψ(bt-1, zt, at-1) ，zt = enc(ot) z 为当前帧编码；fψ 为递推更新（GRU 或注意力层），输出即策略与世界模型共享的记忆表示

递推结构的容量决定可记住的历史长度：GRU 的隐藏状态是固定长度向量，长期信息按门控逐级衰减；历史注意力对全序列取用，长程保持能力强但成本随序列增长。工程折中是“短窗口注意力加递推摘要”：近几步用注意力保持精确，更早的历史压缩进递推状态。017 章的确定性循环状态与此处的记忆表示同源，类别潜变量负责新信息、递推状态负责累积历史。

三类结构的定量对照如下表。逐帧特征按 196 个 patch、每 patch 512 维计，单帧特征约 10 万个数值。

结构有效记忆序列 32 步的状态开销长程行为典型失效
帧堆叠（4 帧）固定 3 步间隔内的差分信息约 40 万数值（4 × 196 × 512）窗口外信息整体丢失依赖时长超过窗口即失效
GRU 摘要（512 维）门控衰减，约 1/（1 − 门控均值）步约 1.6 万数值（32 × 512）按衰减系数逐级遗忘冷启动状态污染前段损失
短窗注意力 + 递推窗口内精确，窗口外衰减约 42 万数值（40 万 + 1.6 万）近精确、远压缩窗口长度与依赖时长不匹配

衰减速度的读法：若有效携带系数为 0.9，t 步之后旧信息的权重为 0.9t，7 步后剩 0.478，16 步后剩 0.185，30 步后只剩 0.042。也就是说，训练序列长度 32 步时，早期观测对末步预测几乎不再有直接贡献，凡是需要跨过 30 步以上的依赖（例如“十秒前目标从哪侧绕入”），必须靠注意力窗口或外部记忆补足，指望 GRU 单独记住并不现实。窗口长度、训练序列长度与依赖时长三者需要按这张表互相校核。

3. 预测目标如何逼出隐含状态

记忆如何学会推断不可见信息：物体移入遮挡后观测不再含其位置，但预测下一帧的损失要求模型知道它在哪里、以什么速度移动，梯度把该信息压入隐状态。单帧不可见、多帧可推断、未来可验证，是记忆必须携带的内容。评估据此设计“单帧无解、多帧有解”的探测任务。

一个具体算例：物体以 0.1 米/秒匀速移动，控制频率 10 赫兹，单帧观测只能给出当前位置，无法区分静止与运动。连续两帧的位置差为 1 厘米，差分即可恢复速度方向与大小；物体被遮挡 5 帧后重现，若记忆保存了速度，预判的重现位置比遮挡时刻前进约 5 厘米，预测损失只有在隐状态携带速度时才能压低。训练信号的作用链条是：差分可推断、遮挡期不可见、重现帧可验证，三步共同迫使隐状态保存速度这一隐含变量，而单帧输入在信息上根本不足，这是探测任务必须按“单帧无解”构造的原因。

4. 序列训练与预热段

递推网络的训练按序列展开，起始状态的处理是关键细节。标准做法是预热段（Burn-in）：序列前若干步只前向不计算损失，让隐状态从初始值收敛到与真实历史相容的状态，随后才开始监督。缺少预热段时，序列前段的损失建立在冷启动状态上，梯度会把“初始状态偏差”误判为模型能力不足，训练信号被系统性污染。预热段长度与递推结构的时间常数匹配，通常取 4–16 步；序列切分点必须在 episode 边界，否则隐含的跨序列记忆泄漏会虚高评估。

预热长度的定量依据：冷启动偏差按携带系数逐级衰减，系数 0.9 时 8 步后残留 0.430、16 步后残留 0.185。预热段只要把残留压到与状态噪声同量级即可，继续加长收益很小：8 步预热将偏差压掉约 57%，16 步压掉约 81%，二者的差约 24 个百分点，而算力开销翻倍。若诊断指标显示预热末状态范数仍偏高，优先检查重置逻辑与序列边界处理，再考虑把预热从 8 步调到 12 或 16 步。

5. 记忆评估：探测与依赖分离

两类结论分开测量。记忆探测：冻结模型，用线性探测检验隐状态是否携带被遮挡对象的位置，属表示层结论。依赖检验：构造单帧无解但历史有解的任务，对比完整历史与仅当前帧输入的成功率差，属行为层结论。记住而不用说明通路未接通，多因数据中反应式可解比例过高。

数值对照：设遮挡任务上完整历史的成功率为 0.86、仅当前帧为 0.42，依赖度 = 0.44；同时线性探测器从冻结隐状态解码被遮挡位置的准确率为 0.78（多数类基线 0.5）。四个象限的读法：依赖度高且探测准，记忆既被保存又被使用；依赖度低而探测准，表示层有信息但策略通路未接通，应提高历史依赖任务的训练占比；依赖度高而探测不准，说明策略绕过了隐状态另找捷径（例如从动作历史反推），需要检查输入通道是否泄漏了替代信息；两者都低，任务本身对该记忆结构不可解，回到结构选型。

失效模式与边界

四种情形会让记忆机制失效。其一，似然对称：观测对关键区分不提供信息（上例中两种位置的看不见概率相同），任何递推都只能停在先验，先修观测配置再谈模型。其二，混淆重置：丢帧置零与轨迹边界清零共用同一个零值状态，网络无法区分“没有观测”与“新轨迹开始”，两者必须用不同标记（掩码加空观测嵌入、显式重置位）表达。其三，状态范数漂移：长序列下递推状态范数单调增长或衰减，拼接进主干后尺度失控，层归一化把状态压回稳定范围，代价是绝对幅度信息被抹掉，若任务依赖幅度（例如速度大小），应在归一化前提取。其四，窗口与依赖时长错配：近端窗口 4 帧、递推半衰期 7 步的组合对 10 步以上的依赖已经偏弱，评估中若发现长依赖任务失败率远高于短依赖任务，优先按上节的衰减表重设窗口与训练长度，再排查其它原因。

实现思路与设计

模块组织：帧编码器（复用 010 章视觉前端）加递推更新（GRU）构成信念编码器；输出记忆向量供策略头与世界模型头消费；序列采样按 episode 切段；预热段与损失段的切分在数据整理器中完成。

参数取舍的依据展开三点。隐藏维度取 512：与主干维度一致便于拼接，增大到 1024 时信念容量翻倍，代价是递推状态与主干之间的映射层参数同步增大，且在遮挡任务上的增益通常小于方差；若任务同时维护多个被遮挡物体的状态，再考虑升到 768 或 1024。序列长度取 32：梯度沿时间传播的范围与信息衰减（0.9 系数约 30 步后剩 4%）成正比，超过衰减常数数倍的序列长度只增加显存；需要更长依赖时应把长度与注意力窗口一起调，单独拉长序列无法跨越衰减常数。预热 8 步与最近注意力 4 帧是分工：前者负责让递推状态脱离冷启动，后者负责把近处细节从压缩中还原，两者的评估分开做消融，避免同时改动混淆归因。

设计决策：信念编码器先于联合训练独立验证

信念编码器的推断能力可在不加载策略头时单独验证：考察遮挡场景的多步预测误差与隐含量探测准确率。先独立验证再接入联合训练，把“没学会”与“未被使用”两类问题分开定位。

关键代码与解读

片段以循环世界模型与序列决策的公开设计为参照（递推状态与预热段是通行做法），接口随版本演进。第 1 段给出信念编码器。

片段 1：递推信念编码器

import torch
import torch.nn as nn

class BeliefEncoder(nn.Module):
    """信念编码器：逐帧编码后经 GRU 递推，输出记忆向量序列。"""
    def __init__(self, d_model=512, hidden=512):
        super().__init__()
        self.cell = nn.GRUCell(d_model, hidden)
        self.norm = nn.LayerNorm(hidden)

    def forward(self, frame_feats, reset_mask=None, h=None):
        # frame_feats (B, T, d)：来自视觉前端的逐帧特征序列
        B, T, _ = frame_feats.shape
        if h is None:
            h = torch.zeros(B, self.cell.hidden_size, device=frame_feats.device)
        outs = []
        for t in range(T):
            if reset_mask is not None:
                # episode 边界把隐状态清零：跨轨迹记忆是评估虚高的常见来源
                h = h * (1.0 - reset_mask[:, t:t + 1].float())
            h = self.cell(frame_feats[:, t], h)
            outs.append(self.norm(h))
        # 返回全序列记忆：预热段与损失段的切分由调用方处理
        return torch.stack(outs, dim=1), h

解读：（1）重置掩码在每步更新前施加，边界帧不会把上一条轨迹的记忆带入新轨迹；掩码随批次传入，编码器本身不判断 episode 逻辑。（2）逐帧循环是最直观实现，训练时可改用融合算子把时间维并行化；接口保持不变。（3）输出加层归一化稳定递推状态的尺度，长序列下防止状态范数漂移，便于与主干特征直接拼接。

片段 2：预热段与损失段切分

def sequence_loss(encoder, heads, seq_batch, burn_in=8):
    """序列损失：前 burn_in 步只更新状态不计损失，之后才监督。"""
    feats = seq_batch["frame_feats"]
    reset = seq_batch["reset_mask"]
    mem, _ = encoder(feats, reset_mask=reset)
    # 预热段用 no_grad 前向之外的方式处理：状态已含梯度，这里裁剪到损失段
    mem_loss = mem[:, burn_in:]
    # 每个时间步的监督：动作块损失与未来帧预测损失（005 章的组合）
    loss = heads.compute(mem_loss, seq_batch, offset=burn_in)
    # 记录预热段的状态范数：过多序列需要更长的预热，提示时间常数不匹配
    with torch.no_grad():
        warm_norm = mem[:, burn_in - 1].norm(dim=-1).mean()
    return loss, {"warm_state_norm": float(warm_norm)}

解读：（1）切分只截取损失段，但递推从序列起点开始：预热段的作用正是把状态带到“与真实历史相容”的位置。（2）预热段状态仍携带梯度（来自后续损失的回传路径）；与“冻结预热”实现不同，后者会切断长时依赖信号。（3）预热末状态范数作为诊断指标：偏高说明状态未收敛，需加长预热或检查重置逻辑。

片段 3：记忆依赖的行为检验

@torch.no_grad()
def memory_dependence_eval(policy, env, seeds):
    """行为层检验：同一任务在完整历史与仅当前帧两种输入下的成功率差。"""
    full_scores, frame_scores = [], []
    for seed in seeds:
        # 完整历史输入：策略通过信念编码器使用记忆
        y_full = run_episode(policy, env, seed, mode="memory")
        # 仅当前帧输入：绕过递推，检验单帧可解性；差值即记忆依赖度
        y_frame = run_episode(policy, env, seed, mode="frame_only")
        full_scores.append(y_full)
        frame_scores.append(y_frame)
    diff = float(torch.tensor(full_scores).mean() - torch.tensor(frame_scores).mean())
    return {"memory": float(torch.tensor(full_scores).mean()),
            "frame_only": float(torch.tensor(frame_scores).mean()),
            "dependence": diff}

def run_episode(policy, env, seed, mode):
    """单次试验：按模式决定输入通道，环境控制目标移出视野的时机。"""
    obs = env.reset(seed=seed)
    history = []
    done, info = False, {"success": 0.0}
    while not done:
        if mode == "frame_only":
            hist = [obs]                     # 仅当前帧：记忆通道被截断
        else:
            history.append(obs)              # 完整历史：信念编码器可用
            hist = history[-8:]              # 近端窗口与递推摘要配合（本页第 2 节）
        action = policy.act(hist)
        obs, done, info = env.step(action)
    return float(info["success"])

解读：（1）两种模式共享初始状态与控制逻辑，唯一变量是输入通道，“记忆依赖度”即配对成功率差，与 019 章的配对评估同一方法论。（2）任务设计保证在约定步数后目标移出视野：单帧无解、历史有解，差值才有判别意义。（3）输入通道切换只改历史截取方式，不触碰策略与环境逻辑，因此两种模式的对照足够干净；历史窗口长度与递推结构的配置与设计节一致。

常见坑

  • 边界未重置：序列跨 episode 切分或重置掩码遗漏，记忆泄漏使训练与评估双虚高。修复：数据整理器在边界处断言重置掩码位置。
  • 预热段缺失：序列前段损失建立在冷启动状态上，梯度被初始偏差污染。修复：统一加 4–16 步预热，预热长度与状态范数诊断联动。
  • 记忆通而不用的捷径：训练数据多为单帧可解任务，策略学会忽略记忆，遮挡场景骤降。修复：训练集保证一定比例的历史依赖任务，并用依赖度指标监控。
  • 缺帧处理不当：丢帧置零与真实黑屏混淆，信念更新被误导。修复：用掩码加空观测嵌入区分“无观测”与“观测为零”，与 010 章约定一致。
  • 注意力窗口过长：近端注意力覆盖全部历史，成本上升且长程梯度不稳。修复：注意力只保留近端窗口，远端信息交给递推摘要。

小结

  • 部分可观测要求从历史推断状态，世界模型的学习目标天然训练隐含信息的推断。
  • 信念递推 bt = f(bt-1, zt, at-1) 的工程实现是递推记忆加短窗口注意力的组合。
  • 预热段让递推状态收敛后再计损失，缺失会造成系统性梯度污染。
  • 记忆评估分离两层结论：表示层探测“是否记住”，行为层检验“是否使用”。
  • 缺帧用掩码与空观测嵌入处理，边界重置是评估可信度的底线。
