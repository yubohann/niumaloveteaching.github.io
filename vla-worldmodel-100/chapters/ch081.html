第 081 章：世界模型的跨模态预测

让世界模型在同一条潜空间里同时预测未来的图像、本体感觉与触觉：多目标监督如何把共享表示压向跨模态语义层，以及模态缺失时保持稳定的训练方法。

  • 主题：世界模型 / 跨模态预测（cross-modal prediction）
  • 关键公式：共享潜空间下的多模态预测损失与不确定性加权（uncertainty weighting）
  • 预计学时：45 分钟
  • 前置章节：第 080 章

学习目标

  • 理解跨模态预测（cross-modal prediction）的动机：多输出监督如何塑造更抽象的共享潜空间（shared latent space）。
  • 掌握多模态编码器、共享转移核与多解码器的结构，理解模态 dropout（modality dropout）为何能带来缺失模态下的鲁棒性。
  • 会从高斯似然出发推导不确定性加权损失，解释 log σ 项防止方差无界增长的机制。
  • 会诊断模态主导（modality dominance）、时间对齐错位（temporal misalignment）与解码器泄漏（decoder leakage）三类训练故障。
  • 能设计消融实验，检验共享潜空间是否真正学到跨模态语义。

背景与动机

单模态预测目标会把潜空间引向纹理细节，跨模态预测把表示压向所有模态共同需要的语义层。只预测下一帧图像的世界模型，可以用大量容量拟合光照、纹理这类与动作无关的成分，短期预测误差很小，潜空间却缺乏对规划有用的语义。若要求同一个潜状态同时预测图像、本体感觉（proprioception）、触觉读数（tactile reading）与任务进度，只有跨模态共享的抽象信息才被保留，冗余细节在容量竞争中被挤出，这与信息瓶颈（information bottleneck）的思想一致。

在联合训练（joint training）框架中，跨模态预测同时充当高效率的辅助监督（auxiliary supervision）：动作块与未来状态之间的因果关系在多个预测头下被反复约束，样本效率高于单一图像重建。第 003 章只处理"预测下一帧图像"，本章把预测目标扩展为异构模态集合，并解决由此带来的梯度尺度失衡与模态缺失两类问题。

核心原理

跨模态预测的完整形式包含三部分：共享潜状态、动作条件转移、多解码器预测。先给出统一的目标函数，再逐项解释其作用。

1. 共享潜空间与多模态预测目标

设模态集合为 M（例如图像、本体感觉、触觉），第 m 个模态在 t 时刻的观测记为 xt(m)，动作块记为 at（连续 8 步控制量的拼接）。世界模型先把各模态编码进共享潜状态 zt，再由动作条件转移核预测下一时刻潜状态：

zt+1 = fθ( zt, at )，x̂t+1(m) = Dm( zt+1 ) θ 为转移核参数；Dm 为第 m 个模态的独立解码器；x̂ 表示预测值

训练目标是最大化所有模态的未来观测对数似然之和：

Lpred = 𝔼 [ Σm∈M −log pθ( xt+1(m) | zt+1 ) ] 同一个 zt+1 要支撑全部模态的预测，容量竞争自动筛掉模态私有细节

这一目标塑造表示靠的是梯度的公共通道：所有模态的预测误差都要经由 zt+1 反向传播，只有对多个模态都有增益的特征维度才会被保留并放大。视觉高频纹理对本体感觉预测几乎无贡献，梯度在跨模态平均下被削弱；物体运动方向、接触状态这类跨模态一致的信息获得多路梯度叠加，表示维度被显著强化。

2. 不确定性加权：让网络自己决定各模态的权重

图像像素均方误差（mean squared error, MSE）的量级远大于本体感觉的误差量级，直接相加会让图像项主导梯度。若假设第 m 个模态的预测误差服从均值 μm、方差 σm2 的高斯分布，则负对数似然为：

L = Σm [ (1 / (2σm2)) · Lm + log σm ] Lm 为第 m 个模态的平方误差；σm 由网络学习

式中的第一项按精度 1/σm2 加权，误差大的模态权重自动降低；第二项 log σm 惩罚方差增大，防止网络把所有 σm 推到无穷来逃避学习。两项博弈的平衡点是 σm2 收敛到该模态的真实残差水平，加权系数由数据自动标定，无需人工调参。

用两个模态的量级体会这组平衡：设视觉项平方误差为 0.04、本体感觉项为 0.0004，最优解满足 σ*2 = 残差，即 σ* 分别为 0.2 与 0.02；残差更小的模态自动获得更高权重：视觉与本体感觉的残差之比为 100 比 1，两者的精度权重之比恰为其倒数，即本体感觉的权重是视觉的 100 倍。σ 向 0 收缩时精度项爆炸，向无穷增大时 log σ 项线性增长，两个方向都被惩罚，σ 只能停在残差水平；这也是实现中 sm 初值取 0（σ = 1）后能自动收敛到各模态残差量级的依据。

3. 模态 dropout：缺失模态下的表示稳定性

训练数据常含缺失模态（触觉传感器部分时刻无效、深度相机偶发丢帧）。若训练时始终全模态输入，推理阶段缺失任一路会令输入分布突变，潜状态偏移导致系统性预测错误。模态 dropout 在训练时以概率 p 随机屏蔽个别模态，用可学习的掩码嵌入（mask token）替代其编码，迫使转移核学会"用可用模态推理"：

L = 𝔼k ~ Bern(1−p) [ Σm∈M −log pθ( xt+1(m) | fθ( zt ⊙ k, at ) ) ] k 为模态保留掩码向量；期望覆盖全部 2|M| 种可见组合

用掩码嵌入替代缺失模态：零向量与真实特征空间中的点无法区分，网络会将其误读为"某一类真实输入"。可学习的掩码嵌入占据独立的方向，为转移核提供明确的"此处缺失"信号。

4. 时间栅格对齐

不同模态的采样率不同：相机 10–30 Hz，本体感觉与触觉可达 50–100 Hz，动作块以控制周期为单位。共享潜状态要求各模态在时间上严格对应同一物理时刻，否则预测标签对应错误的时刻，转移核学到的因果关系被系统性地污染。常见做法是以最低速模态为基准栅格，对高速模态取最近邻或线性插值，并在数据加载阶段完成对齐；对齐误差控制在 1 个基准周期内。

实现思路与设计

数据流为：逐模态编码 → 时间栅格对齐 → 融合投影 → 动作条件转移 → 多解码器与不确定性加权损失。训练循环中另有两处工程处理：模态 dropout 在编码之后、融合之前执行；对齐结果在数据加载器中缓存。

  1. 逐模态编码：图像用轻量卷积下采样，本体感觉与触觉用两层多层感知机（multilayer perceptron, MLP），全部投影到同一维度 dz。
  2. 时间对齐：以 10 Hz 视觉为基准栅格，对 50 Hz 状态序列做线性插值；动作块按控制周期切片，保证 at 覆盖 zt 到 zt+1 的完整时间跨度（第 087 章将讨论离散化替代方案）。
  3. 融合与转移：各模态编码相加或拼接后投影，输入门控循环单元（gated recurrent unit, GRU）转移核，动作块经独立线性层嵌入后作为条件。
  4. 损失组合：三路解码误差按不确定性加权；另加 0.01 系数的潜状态平滑正则，抑制相邻步潜状态的抖动。
  5. 与第 003 章的差异：预测目标由图像单路扩展为三路，新增可学习不确定性参数与模态 dropout；转移核结构保持不变，便于在已有代码上增量升级。

设计决策：融合点为什么选在编码之后？

像素级融合要求所有模态空间对齐，触觉与本体感觉没有图像结构，无法承受卷积操作；编码后融合让每个模态保留自身的归纳偏置（inductive bias），在低维共享空间中完成交互，代价是丢失极低层的跨模态对应。融合时机的系统讨论见第 088 章。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：多模态编码器与动作条件转移核

class CrossModalWorldModel(nn.Module):
    """跨模态世界模型：逐模态编码 + 共享潜空间 + 动作条件转移。"""
    def __init__(self, d_z=512, chunk=8):
        super().__init__()
        # 视觉支路用两级卷积先降采样再压平：低层纹理在此被大量丢弃
        self.enc_img = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=5, stride=4), nn.ReLU(),
            nn.Conv2d(32, 64, kernel_size=3, stride=2), nn.ReLU(),
            nn.AdaptiveAvgPool2d(4), nn.Flatten(), nn.Linear(64 * 16, d_z),
        )
        # 本体感觉与触觉是低维向量，两层 MLP 足够；过深反而过拟合
        self.enc_prop = nn.Sequential(nn.Linear(22, 128), nn.ReLU(), nn.Linear(128, d_z))
        self.enc_tac = nn.Sequential(nn.Linear(64, 128), nn.ReLU(), nn.Linear(128, d_z))
        # 融合层把各模态拼接后投影：权重由线性层学习，优于等权相加
        self.fuse = nn.Sequential(nn.Linear(3 * d_z, d_z), nn.LayerNorm(d_z), nn.GELU())
        # 动作块单独嵌入作为转移条件，避免与观测编码竞争同一组参数
        self.act_embed = nn.Linear(chunk * 7, d_z)
        self.transition = nn.GRUCell(d_z + d_z, d_z)

    def forward(self, img, prop, tac, act_chunk, z_prev=None):
        z_obs = self.fuse(torch.cat(
            [self.enc_img(img), self.enc_prop(prop), self.enc_tac(tac)], dim=-1))
        if z_prev is None:
            z_prev = z_obs  # 首帧没有历史，用当前观测初始化潜状态
        cond = torch.cat([z_obs, self.act_embed(act_chunk)], dim=-1)
        z_next = self.transition(cond, z_prev)
        return z_obs, z_next  # z_next 交给各模态解码器共同使用

解读：逐模态编码器保持各自归纳偏置：视觉支路用卷积承担空间约简，低维模态用 MLP 承担特征混合。融合采用拼接后投影：平均会强制各模态权重相等，在信息量差异大时损失精度。act_embed 独立成层，避免动作与观测的统计差异在共享嵌入中互相污染。GRU 转移核参数量恒定，展开 5 步复用同一模块，显存与步长线性增长。

片段 2：多解码器与不确定性加权损失

class PredictiveHeads(nn.Module):
    """三个模态解码器 + 可学习 log 方差，实现不确定性加权。"""
    def __init__(self, d_z=512, n_mod=3):
        super().__init__()
        out_dims = (3 * 64 * 64, 22, 64)  # 下采样图像、本体感觉、触觉
        self.heads = nn.ModuleList([
            nn.Sequential(nn.Linear(d_z, 256), nn.GELU(), nn.Linear(256, od))
            for od in out_dims
        ])
        # s_m = log σ_m^2：初值 0 对应方差 1，各模态初始等权
        self.log_var = nn.Parameter(torch.zeros(n_mod))

    def loss(self, z_next, targets):
        total = z_next.new_zeros(())
        for m, (head, y) in enumerate(zip(self.heads, targets)):
            pred = head(z_next)
            mse = F.mse_loss(pred, y)
            # exp(-s) 即精度加权；s 项阻止网络把方差推大来逃避学习
            s = torch.clamp(self.log_var[m], min=-6.0, max=6.0)
            total = total + torch.exp(-s) * mse + s
        return total

解读：log_var 作为优化变量参与训练，梯度会同时流向加权系数与网络参数，形成"难模态降权、易模态升权"的自适应平衡。clamp 把 s 限制在 ±6 区间，对应方差在 e−6 到 e6 之间，防止早期训练某一模态残差极大时权重数值溢出。替代方案是人工设定固定权重，缺点是随训练推进最优权重会漂移；固定权重仍可作为首轮调试的基线。

片段 3：模态 dropout 与掩码嵌入

def modality_dropout(tokens, mask_embed, p=0.15, training=True):
    """tokens: (B, M, d_z) 各模态编码；mask_embed: (M, d_z) 可学习掩码。"""
    if not training or p <= 0.0:
        return tokens
    B, M, _ = tokens.shape
    keep = torch.bernoulli(tokens.new_full((B, M), 1.0 - p))
    # 至少保留一个模态：整样本全屏蔽会退化为纯噪声样本
    all_masked = keep.sum(dim=1) == 0
    keep[all_masked, 0] = 1.0
    # 用掩码嵌入替换缺失模态：零向量会被误读为真实特征
    mixed = tokens * keep.unsqueeze(-1) + mask_embed.unsqueeze(0) * (1.0 - keep).unsqueeze(-1)
    return mixed

解读：keep 按样本、按模态独立采样，期望覆盖 23 = 8 种可见组合。all_masked 保护分支保证每样本至少有一路输入，否则损失中观测信息为零，转移核只能学到先验均值，浪费算力且污染梯度。mask_embed 与编码器一同训练，其梯度来自所有被屏蔽样本，收敛后代表"该模态缺失"这一语义方向。部署阶段若检测到某模态失效，同样注入 mask_embed；跳过错位会让输入分布与训练不一致。

常见坑

  • 模态主导：图像均方误差量级可达 0.1 以上，状态误差常在 1e-3 以下，直接相加让梯度几乎全部来自视觉分支。症状是状态预测长期不收敛。修复：采用不确定性加权，或先对各模态误差做标准化再求和。
  • 时间栅格错位：把 10 Hz 图像与 50 Hz 状态按数组索引直接配对，预测标签对应错位时刻。症状是 rollout 早期误差尚可、3 步后急剧发散。修复：按时间戳重采样到统一栅格。
  • 解码器泄漏：解码器输入混入当前帧特征，预测任务退化为复制当前帧，潜空间学不到动力学。症状是单步预测指标极好、多步 rollout 完全失效。修复：结构性隔离输入，并对比"t 时刻基线预测器"的参照指标。
  • 方差逃逸：某模态标签含大量噪声时，sm 持续增大、该模态几乎退出训练。症状是训练损失下降但评测指标停滞。修复：对 s 设上限并监控各模态实际权重曲线。
  • 缺模态表示漂移：训练全程全模态，推理缺少触觉时潜状态偏离训练分布。症状是缺模态条件下误差为全模态的 3 倍以上。修复：模态 dropout 概率调到 0.15–0.25，评测协议固定包含缺模态场景。

练习与思考

  1. 从高斯负对数似然 −log N(x; μ, σ2) 出发，推导 L = Lm / (2σm2) + log σm，并说明 log σ2 参数化相对 σ2 参数化的优点。★
    提示
    展开高斯密度取负对数：平方项除以 2σ2，归一化项给出 log σ。对数参数化保证 σ 恒正，且梯度尺度与残差量级匹配。
  2. 把模态 dropout 概率从 0.15 调到 0.5，预测训练收敛速度与缺模态评测结果的变化，并解释原因。★
    提示
    收敛变慢（有效信息减少），但全缺模态场景误差下降；0.5 使近一半样本损失信息，梯度方差增大。
  3. 设计一个消融实验，验证共享潜空间学到了跨模态语义。提示方向：跨模态检索、线性探测、模态替换重建。★★
    提示
    冻结骨干后用 z 线性预测接触状态（线性探测），再与单模态基线对比；或交换两样本的触觉编码，观察图像预测是否按触觉方向变化。
  4. 若把不确定性加权改为固定权重（视觉 1.0、状态 1.0、触觉 1.0），分析两类模态梯度尺度失衡的后果，并给出两种平衡方案。★★
    提示
    视觉项数值主导，状态与触觉梯度被相对削弱。方案一：各模态误差除以运行方差；方案二：损失按参数量级重标定后用 GradNorm 式动态权重。
  5. 设计实验：在触觉缺失条件下评估 rollout 误差随预测步长（1、3、5、10 步）的增长曲线，与全模态条件对比，判断表示漂移何时开始。★★★
    提示
    固定测试集与随机种子，分别用掩码与真实触觉 rollout；误差比值在第几步超过 2 倍，即漂移起始点。预期缺模态曲线斜率更大。

小结

  • 跨模态预测要求同一潜状态支撑多个模态的未来预测，容量竞争筛掉模态私有细节，表示被压向共享语义层。
  • 不确定性加权从高斯似然导出，exp(−s) 加权配 s 正则，让各模态权重随残差水平自动收敛。
  • 模态 dropout 配可学习掩码嵌入，使转移核在任意模态子集下可用，且缺失信号可区分。
  • 时间栅格对齐与解码器泄漏检查是训练稳定的两个前提，两者均需在评测协议中显式覆盖。
