第 084 章：世界模型的对抗性鲁棒性

微小观测扰动如何经多步 rollout 递归放大成系统性预测偏差：误差传播的收缩条件、对抗训练与谱范数约束，以及能看穿"梯度掩蔽假象"的评测协议。

  • 主题：世界模型（World Model）/ 对抗鲁棒性（adversarial robustness）
  • 关键公式：潜动态误差递归 et+1 ≤ L·et + ν 与谱范数约束
  • 预计学时：55 分钟
  • 前置章节：第 083 章

学习目标

  • 理解对抗扰动的威胁模型：扰动预算 ε、攻击目标（单步还是多步 rollout）与白盒/黑盒攻击的差别。
  • 会推导潜动态误差递归式，解释 Lipschitz 常数 L 小于 1 与大于 1 时误差几何级数收敛与爆炸的两种走向。
  • 掌握对抗训练的内层最大化实现（投影梯度下降），理解训练代价与干净精度的权衡。
  • 掌握谱归一化约束转移层灵敏度的方法，理解残差缩放系数对收缩性的影响。
  • 会设计包含扰动网格、攻击步数与迁移攻击的鲁棒性评测协议，避免梯度掩蔽造成的虚假鲁棒。

背景与动机

世界模型的危险性在于误差的时间累积：单步预测的微小偏移会沿 rollout 递归放大，最终把规划引向完全错误的状态。与分类模型的对抗样本问题相比，世界模型的攻击面更宽：扰动不仅影响当前预测，还通过递归转移污染全部未来想象轨迹（imagination rollout），而规划与控制模块恰好依赖这些轨迹做决策。

第 024 章从数据增强的角度讨论过对抗训练的一般做法，关注单步预测的稳健性；本章聚焦多步 rollout 的发散机制与系统性防御。两者组合使用：增强保证输入分布覆盖扰动邻域，收缩性约束控制误差传播的放大系数。对系统集成而言，鲁棒性是上线前的准入门槛，需要可量化、可复现的评测协议，评测本身的设计往往比防御方法更容易出错。

核心原理

对抗鲁棒性问题可分解为威胁模型、误差传播动力学、防御手段三层，逐层建立后即可组合出完整方案。

1. 威胁模型

扰动被约束在 L∞ 球内：‖δ‖∞ ≤ ε，像素值域 [0,1] 上 ε 常取 2/255 至 8/255。攻击者的目标函数决定攻击强度：若只最大化单步预测误差，扰动经一次转移即被消耗；若最大化 H 步 rollout 的累计误差，扰动会被转移核反复放大，危害高出一个量级。训练防御时必须按多步目标构造攻击，否则防御方向与真实威胁错位：设世界模型转移核为 fθ，观测编码器为 E，H 步攻击目标为：

max‖δ‖∞ ≤ ε Σk=1H ‖ fθk( E(o + δ), a1:H ) − fθk( E(o), a1:H ) ‖2 fk 表示转移核的 k 次复合；攻击目标是让扰动在想象轨迹上持续生效

2. 误差递归与收缩性

设潜状态扰动为 et，转移核满足 Lipschitz 连续性（Lipschitz continuity），常数为 L；每步还引入与状态相关的固有误差 ν（模型近似误差的下界）。误差传播满足：

et+1 ≤ L · et + ν L 为转移核在潜空间的最大灵敏度；ν 为单步固有误差

展开递归得 eT ≤ LTe0 + ν·(LT−1)/(L−1)。两种走向截然不同：L 小于 1 时误差有上界 ν/(1−L)，初始扰动的影响以 LT 衰减；L 大于 1 时初始误差按 LT 放大，rollout 步数 H = 10、L = 1.2 时放大倍数约 6.2，L = 1.5 时达到 57.7。对抗训练降低的是 ν 与输入的局部灵敏度，谱范数约束直接压低 L 的上界，两类手段互补。

3. 对抗训练的内层最大化

鲁棒优化目标为：

minθ max‖δ‖∞ ≤ ε Lpred( fθ, o + δ, a ) 外层最小化预测损失，内层寻找最坏扰动；内层用投影梯度下降近似求解

内层用 k 步投影梯度下降（projected gradient descent, PGD）：沿梯度符号方向定步长上升，每步投影回 ε 球。实践参数为步数 7–10、步长 ε/4。对抗训练把模型显式暴露在最坏邻域，等价于对每个样本做数据增强，但增强方向由当前模型决定、强度按最坏情况标定，效率高于随机增强。代价是干净数据精度通常下降 1–3 个百分点，批量计算量上升约 k 倍，这是鲁棒性与精度的常规权衡。

4. 收缩性约束与部署期防御

谱归一化（spectral normalization）用幂迭代估计转移层权重的主奇异值 σmax，前向时用 W/σmax 替代原权重，使每层 Lipschitz 常数不超过 1。多层复合后整个转移核的常数可控。使用残差形式时需引入缩放系数 α：h′ = h + α·g(h)，单层灵敏度上界约为 1 + α，α 取 0.5 以下配合 tanh 压缩可以保证整体收缩。约束过紧会损失模型的表达能力，训练损失上升，需要在 L 目标值（例如 0.9）与拟合能力之间权衡。

部署期防御包括两类：随机平滑（randomized smoothing）对同一观测的多个增强视图分别编码，取潜状态中位数，单个视图内的扰动被中位数操作稀释；预测误差监测把编码器输出与历史潜状态的预测偏差作为异常分数，超过阈值时冻结规划并请求重新观测（第 095 章展开）。四类防御的作用对象与边界差异如下：

防御手段作用对象主要成本适用边界与失效
对抗训练（多步 PGD）输入局部灵敏度与固有误差 ν批量计算量约 k 倍，干净精度降 1–3 个百分点只覆盖训练设定的扰动预算与攻击视野
谱归一化与残差缩放转移核 Lipschitz 常数 L表达能力受限，训练损失上升约束过紧时干净精度受损
随机平滑单次观测的扰动敏感度多视图前向的推理开销稀释幅度受视图数与平滑半径限制
预测误差监测运行期异常与漂移维护历史统计并标定阈值只触发停靠与重观测，不修复根因

实现思路与设计

训练循环为：构造多步攻击扰动 → 对抗样本与干净样本混合前向 → 预测损失加谱约束正则 → 交替更新。评测协议独立于训练，覆盖扰动网格与迁移攻击。

  1. 攻击构造：每批量抽取一半样本做 PGD 攻击（7 步、ε 从 {2/255, 4/255} 随机），攻击目标为 5 步 rollout 误差。
  2. 前向与损失：干净与对抗样本拼接前向，预测损失按样本加权平均；转移层施加谱归一化，权重由幂迭代在线估计。
  3. 目标网络：编码器保留指数移动平均（EMA）副本，攻击对该副本构造，缓解攻击对当前参数的过拟合。
  4. 评测：固定 ε ∈ {1/255, 2/255, 4/255, 8/255}、步数 ∈ {5, 10, 20}、rollout 步长 ∈ {5, 10} 的三维网格；另跑迁移攻击（用另一模型参数构造扰动）验证非梯度掩蔽鲁棒。
  5. 与第 024 章的差异：增强策略从单步扩展到多步目标，新增谱约束与完整评测协议；训练主体结构不变。

设计决策：为什么攻击目标取多步 rollout 误差？

单步攻击只在编码器输出附近寻找最坏点，扰动上一次转移即被吸收；多步目标让扰动在每个转移步都保持效力，暴露真实的累积风险。训练时按下游使用的预测步长设置攻击视野，防御才与部署威胁对齐。这一原则与第 089 章规划视野的设置逻辑一致：防御与使用必须同尺度。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：面向多步 rollout 的 PGD 攻击

def pgd_rollout_attack(model, obs, act_seq, eps=4/255, steps=7, step_size=1/255, horizon=5):
    """内层最大化：寻找使多步 rollout 误差最大的观测扰动。"""
    # 随机初值避免梯度为零时攻击失效；分布在预算球内
    delta = torch.empty_like(obs).uniform_(-eps, eps)
    # 干净轨迹作为攻击参照，detach 防止攻击梯度污染模型参数
    with torch.no_grad():
        z_ref = model.rollout_latents(obs, act_seq, horizon=horizon)
    for _ in range(steps):
        delta.requires_grad_(True)
        z_adv = model.rollout_latents(obs + delta, act_seq, horizon=horizon)
        # 对全部预测步求和：任何单步的偏差都计入攻击收益
        loss = sum(F.mse_loss(z_adv[k], z_ref[k]) for k in range(horizon))
        grad = torch.autograd.grad(loss, delta)[0]
        # 符号梯度上升 + L∞ 投影：保持扰动在预算球内
        delta = (delta + step_size * grad.sign()).detach().clamp(-eps, eps)
    return delta.detach()

解读：z_ref 在 no_grad 下计算并固化，攻击只对扰动求梯度，避免昂贵的二阶计算。损失对全部 horizon 步求和，与误差递归分析对应：扰动的危害等于各步偏差的累计。步长取 ε/4 是常用稳定配置，步数 7 在计算与效果间折中。torch.empty_like(obs).uniform_ 的随机初值可防止某次迭代梯度恰为零导致的攻击停滞。该函数只用于构造训练样本与评测，不参与参数更新。

片段 2：谱归一化转移层与收缩残差

class SpectralLinear(nn.Module):
    """谱归一化线性层：幂迭代估计主奇异值，把权重缩放到单位谱范数。"""
    def __init__(self, in_dim, out_dim, n_power=1):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(out_dim, in_dim) * 0.02)
        self.register_buffer("u", torch.randn(out_dim))
        self.n_power = n_power

    def forward(self, x):
        with torch.no_grad():
            v = F.normalize(self.weight.t() @ self.u, dim=0)
            for _ in range(self.n_power):
                u = F.normalize(self.weight @ v, dim=0)
                v = F.normalize(self.weight.t() @ u, dim=0)
            self.u.copy_(u)
        sigma = self.u @ self.weight @ v      # 主奇异值估计值
        return F.linear(x, self.weight / sigma.clamp(min=1e-6))

class ContractiveTransition(nn.Module):
    """收缩残差转移：h' = h + α·tanh(SN(f(h)))，灵敏度上界约 1 + α。"""
    def __init__(self, d_z=512, n_layers=2, alpha=0.5):
        super().__init__()
        self.alpha = alpha
        self.layers = nn.ModuleList([SpectralLinear(d_z, d_z) for _ in range(n_layers)])

    def forward(self, h):
        for layer in self.layers:
            # tanh 压缩值域，与谱归一化共同压低整体 Lipschitz 常数
            h = h + self.alpha * torch.tanh(layer(h))
        return h

解读：幂迭代每前向只走少量步即可跟踪主奇异向量，因为权重在训练中变化缓慢；register_buffer 让 u 随模型保存与加载，不参与优化。sigma.clamp(min=1e-6) 防止奇异值为零时除零。缩放后的权重不覆盖原参数，梯度仍流向原始 weight，优化器感知的是缩放后的有效映射。残差缩放 α = 0.5 使单层灵敏度上界约 1.5，两层复合约 2.25，配合 tanh 的处处导数不超过 1，整体灵敏度可控；若 α 取 1.0，收缩界失效，误差放大风险回升。

片段 3：rollout 漂移评测

def rollout_drift(model, obs, act_seq, eps_list=(1/255, 2/255, 4/255), horizon=10):
    """评测协议：按扰动预算网格测量潜状态漂移随 rollout 步长的放大曲线。"""
    curve = {}
    for eps in eps_list:
        delta = pgd_rollout_attack(model, obs, act_seq, eps=eps)
        z_ref = model.encode(obs).detach()
        z_adv = model.encode(obs + delta).detach()
        errs = []
        for k in range(horizon):
            # 参考与对抗轨迹同步推进：同一动作序列下比较潜状态
            z_ref = model.step(z_ref, act_seq[:, k])
            z_adv = model.step(z_adv, act_seq[:, k])
            errs.append((z_adv - z_ref).norm(dim=-1).mean().item())
        curve[eps] = errs
    return curve

解读：同步推进保证两条轨迹消费同一动作序列，差异全部来自初始扰动。曲线形状直接反映 L 的两个区域：衰减曲线对应收缩动态，线性上升对应临界，指数上升对应发散。评测还须补充迁移攻击：用另一个训练种子模型的梯度构造扰动施加到当前模型，若迁移攻击下误差显著上升而白盒攻击下平稳，说明白盒数字由梯度掩蔽造成，防御并未生效。该判读方法同样适用于真实传感器的噪声注入测试，两者互为参照。

常见坑

  • 只攻击单步：防御在单步指标上表现良好，实际规划中仍失败。症状是单步对抗误差低、10 步 rollout 误差仍暴涨。修复：攻击目标改为多步累计误差，视野与规划步长对齐。
  • 梯度掩蔽假象：白盒攻击数字漂亮，迁移攻击与查询攻击立刻击穿。症状是两类攻击结果差距大于 3 倍。修复：评测纳入迁移攻击并在报告中同时给出两组数字。
  • 谱约束过紧：L 目标压到 0.5 以下，转移核表达能力不足，干净预测误差上升 20% 以上。修复：从 0.9 起步，按验证集干净误差与鲁棒误差的帕累托前沿调整。
  • 批次统计泄露：使用批归一化（BatchNorm）的编码器在对抗输入下统计量偏移，间接放大了扰动灵敏度。修复：鲁棒场景改用层归一化（LayerNorm）或冻结批统计。
  • 评测集泄漏：攻击使用的观测与训练样本重叠，评测数字虚高。修复：攻击与评测都使用留出集，且随机种子、动作序列公开记录保证可复现。

练习与思考

  1. 由 et+1 ≤ L·et + ν 推导 eT 的几何级数上界，并计算 L = 1.2、ν = 0.01、T = 10 时初始扰动衰减后的稳态误差水平。★
    提示
    eT ≤ LTe0 + ν(LT−1)/(L−1)；L>1 时两项都增长，代入数值即可。
  2. 把对抗训练比例从 50% 调到 100%，预测干净精度与鲁棒精度的变化方向，并说明原因。★
    提示
    干净精度下降更多，鲁棒精度略升；全对抗改变了数据分布的重心，容量被鲁棒性占据。
  3. 推导残差块 h′ = h + α·g(h) 的 Lipschitz 上界（g 的常数不超过 1），说明 α 超过什么取值后收缩条件破坏。★★
    提示
    上界为 1 + α；α 大于 0 即增大灵敏度，多层复合需要 α 使 (1 + α)m·其它缩放小于 1，实践中 α 取 0.5 以下。
  4. 设计一个迁移攻击评测流程：指定模型对、攻击预算网格与统计量，说明如何区分"真鲁棒"与"梯度掩蔽"。★★★
    提示
    跨模型迁移误差与白盒误差的比值是关键量；若比值接近 1 说明梯度路径未被遮蔽；补充随机搜索攻击作为无梯度基线。
  5. 针对本章的防御组合设计一个自适应攻击：攻击者知道谱约束与对抗训练同时存在，给出攻击目标函数的修改方案与预算分配。★★★
    提示
    攻击目标改为对收缩转移的输出熵或对策略动作分布的影响；预算沿梯度方向集中投放，检验防御的极限；均匀分配达不到同等强度。

小结

  • 世界模型的对抗风险来自误差时间累积，攻击目标必须按多步 rollout 构造，视野与规划步长对齐。
  • 误差递归 et+1 ≤ L·et + ν 给出清晰判据：L 小于 1 有界，L 大于 1 指数放大。
  • 对抗训练以内层 PGD 近似最坏扰动，代价是干净精度与计算量；谱归一化与残差缩放直接压低 L。
  • 评测协议要覆盖扰动网格、攻击步数与迁移攻击，梯度掩蔽会制造虚假鲁棒。
