第二篇 · 联合训练进阶与策略能力

第 030 章：世界模型的长期预测能力评估

单步误差小并不意味着想象轨迹可用；本章讲清多步 rollout 误差曲线的测量方法、误差增长率的拟合，以及"可预测时域"这一统一口径的定义与报告方式。

  • 主题：长期预测评估（long-horizon evaluation） / 误差增长分析
  • 关键公式：ek = E‖x̂t+k − xt+k‖；ek ≈ ε (1 + λ)k；可预测时域 k* = log(T/ε) / log(1 + λ)
  • 预计学时：50 分钟
  • 前置章节：第 029 章

学习目标

  • 理解长期预测评估的地位：想象 rollout 服务于规划与策略优化，评估必须测量多步表现，单步口径无法反映误差累积。
  • 掌握三层指标体系：像素级指标、潜空间指标与任务量指标，理解各自的盲区。
  • 掌握误差增长曲线的测量与拟合方法，会用增长率 λ 计算可预测时域 k*。
  • 会设计评估协议：初始状态集、动作序列来源、多随机种子与置信区间报告。
  • 能识别像素指标饱和、训练集内序列与动作分布错配三类评估陷阱。

背景与动机

世界模型（World Model）的单步预测误差通常很小，因为相邻帧共享绝大部分内容；但想象 rollout（imagination rollout）是自回归的：每一步的预测输出成为下一步的输入，误差沿步长累积。单步指标好而多步轨迹发散的情形十分常见，用单步误差评估世界模型的可用性会得出误导结论。

长期预测能力直接决定下游用法：规划需要向前推演 10 至 50 步筛选动作序列，策略优化依赖 15 步量级的想象轨迹计算回报。模型在 10 步内保真、20 步后发散，对应的规划时域与训练设计完全不同。评估的任务是给出这个边界，并把它表达为可比较的量。

本章与下一章的分工：本章测量"预测在多远处开始不可信"，第 031 章给出"模型自己知道哪里不可信"的不确定性估计。两者结合才能支撑安全的想象使用；第 036 章的多步误差修正则建立在本章的误差谱分析之上。

核心原理

1. 三层指标体系

单一指标无法刻画长期预测质量，按信息层次划分三类：

层次指标测量对象盲区
像素级PSNR、SSIM、LPIPS外观保真度模糊预测在部分指标上得分偏高
潜空间潜状态距离、分布距离动力学一致性与任务成功率的关联需要验证
任务量物体位置误差、接触状态、奖励预测误差任务相关量需要标注或估计器，成本较高

三层的用途不同：像素指标适合回归测试与版本对比；潜空间指标训练中可实时监控；任务量指标与下游性能的关联最强，作为最终判据。报告时三层同时给出，任何一层的单独结论都可能被其他层证伪。

任务量指标到阈值的映射是协议的关键一步：先在验证集上统计潜空间距离与物理误差的对应关系，例如潜距离 0.02 对应物体位置误差约 1 cm，而抓取任务容许 1 cm 的定位偏差，于是 T = 0.02 获得任务含义。映射关系随任务阶段变化（接触阶段对位置误差更敏感），阈值应按阶段分别标定，用同一阈值横跨全任务会高估或低估可用时域。

像素指标存在饱和现象：预测越模糊，均方误差类指标越"安全"（远离所有可能帧的平均值），条件生成指标（LPIPS）对模糊敏感。评估协议应同时包含两类指标，让模糊解与发散解都能被捕捉。

饱和机制的具体形态：均方误差的最优解是条件期望，预测逐像素条件均值的帧整体模糊，而模糊帧与任何真实帧的逐像素差距都小；条件生成指标比较特征分布的距离，模糊帧因纹理细节缺失被判远。两类指标因此对同一预测给出相反结论，并列报告是对冲该机制的标准做法。

2. 误差增长曲线与可预测时域

多步误差曲线的定义与常见增长模型：

ek = E起点, 动作 [ d( x̂t+k, xt+k ) ]
ek ≈ ε (1 + λ)k 或 ek ≈ ε + c·k ε 为单步误差，λ 为增长率；指数模型适合描述混沌扩散，线性模型适合描述系统性漂移主导的区间

把误差曲线在双对数或半对数坐标下拟合，得到增长率 λ。可预测时域定义为误差穿越给定阈值 T 的步数：

k* = log( T / ε ) / log( 1 + λ ) 阈值 T 按任务需求设定：规划用的潜状态误差阈值应与规划质量要求挂钩

该定义的工程价值在于把"模型能预测多远"转化为一个可追踪的标量：λ 的下降（训练进步）与 T 的收紧（任务要求提高）都会改变 k*。报告可预测时域时必须同时给出 T 的取值，脱离阈值的时域数字无法比较。

数值算例：取 ε = 0.01、阈值 T = 0.02（单步误差的两倍）、λ = 0.05，则 k* = log 2 / log 1.05 = 0.6931 / 0.04879 ≈ 14.2 步；单步误差在 k = 10 时累计到 0.01 × 1.0510 ≈ 0.0163，尚未穿越阈值，与公式一致。增长率档位直接改写时域，各档在相同阈值下的 k* 如下：

λk*（T = 2ε）典型含义
0.0169.7缓慢漂移主导，长时域基本可用
0.0235.0平稳区，覆盖中等规划时域
0.0514.2常见训练中期水平
0.107.3混沌扩散显著，仅支持短时域

把 λ 从 0.10 压到 0.05，时域从约 7 步扩到约 14 步，翻倍；λ 属于对数尺度的量，改进收益在时域上被放大，这解释了误差增长控制为何比单步精度更值得投入。

λ 的动力学来源可以解析：对线性潜动力学 zt+1 = A zt，初始误差 δ0 经 k 步传播为 Akδ0，误差模长的每步渐近增长因子等于 A 的谱半径 ρ(A)（最大特征值模），因此 λ = ρ(A) − 1。谱半径 1.05 的线性模型对应 λ = 0.05，与算例一致；谱半径接近 1 说明动力学接近稳定，局部误差不被放大。非线性模型在工作点线性化后，各雅可比矩阵的谱半径随状态变化，实测 λ 是轨迹上的平均效应，因此同一模型在不同任务阶段的 λ 可以明显不同，评估需要按阶段分层。

3. 开环与闭环评估

开环评估用一条固定的动作序列驱动模型 rollout，测量预测偏差；闭环评估把策略放进世界模型，让策略根据模型预测选择动作，测量任务完成情况。两者回答不同问题：开环测"预测器"，闭环测"预测器加策略的联合可靠性"。闭环中策略会主动避开模型不确定的区域，闭环表现可能好于开环曲线的悲观外推；反过来，策略也可能利用模型误差刷高闭环指标。评估协议需要成对报告，并在闭环中周期性地用真实环境校验。

自回归采样偏差（exposure bias）的测量方法：比较两种 rollout 起点，一种从真实帧序列切换，一种从模型预测帧切换，若后者的误差曲线显著更高，说明模型对自身预测的分布外输入脆弱，训练时引入模型生成帧（教师强制之外的噪声注入）可以缓解。

两种起点的对照可以提炼成一个可追踪的标量：记真实起点 rollout 的第 10 步误差为 ereal10、模型起点为 emodel10，比值即采样偏差的放大倍数。比值接近 1 说明模型对自身预测的输入不敏感，训练中可以放大想象数据的占比；比值超过 2 时先安排噪声注入与数据增强，再考虑提高想象占比，否则会把分布外脆弱性一并放大。

4. 误差增长的两种成分

把多步误差拆成不可约随机性与模型误差两部分：不可约部分来自环境的固有随机性（相同观测与动作下状态仍有分布），模型完美也无法消除；模型部分来自参数误差与结构失配，随步长扩散。诊断方法：在同一条件下多次采样，若模型预测的方差与真实状态的条件方差相当，说明不可约部分主导，继续压缩模型误差收益有限，应转向让下游规划对随机性更稳健（增加采样数、采用保守的回报估计）；反向情形（模型方差远高于真实方差）说明模型自身引入了额外不确定性，优先排查训练数据的标注噪声与表达坍缩。

5. 评估协议设计

协议四要素：初始状态集（覆盖任务阶段与物体布局，规模 50 至 200 条）、动作序列来源（策略 rollout、行为演示、随机探索三组对照）、rollout 长度（至少覆盖目标规划时域的 2 倍）、统计口径（均值与分位数、置信区间、多种子）。动作序列分布是评估中最容易被忽视的变量：只在演示动作上评估会系统性高估模型能力，加入探索动作组才能暴露边界。样本量与精度直接挂钩：误差曲线的逐点均值标准误为 σ / √n，单点标准差 σ = 0.01、n = 100 条轨迹时标准误为 0.001；把置信区间宽度减半需要把轨迹数扩到四倍（n = 400 时标准误 0.0005）。λ 的估计方差还受拟合区间长度影响，前 80% 段保留的步数越多，λ 的置信区间越窄。

实现思路与设计

评估流水线由数据集构建、rollout 执行、指标计算与报告四段组成。与第 029 章的差异：029 关注部署时的时序约束，本章关注模型预测能力的测量方法学。

  1. 数据构建：从留出轨迹池抽初始状态，按任务阶段分层，保证各阶段样本量均衡。
  2. 动作序列：三组来源（当前策略、演示、平滑随机）分别 rollout，报告按来源分层。
  3. 指标计算：每步计算像素、潜空间与任务量三层指标，记录完整曲线，保留拐点与形态信息。
  4. 报告：给出误差曲线图、拟合的 λ 与设定阈值下的 k*，附置信区间与协议参数。

参数默认值作用取值依据

技巧：用"误差减半时域"作为稳健口径

固定阈值 T 在不同模型间不可比（单步误差基线不同）。改用相对口径：误差达到单步误差 2 倍、4 倍的步数。该口径不受归一化尺度影响，跨模型比较时更稳健，也便于对训练过程画趋势曲线。

评估的频率与门禁同样需要设计：每次保存检查点跑缩短版评估（20 条轨迹、3 个随机种子），完整评估按固定间隔执行；版本晋级设置门禁，λ 与 k* 同时不劣化、任务量指标不下降才允许替换线上模型。缩短版评估方差较大，门禁阈值取置信区间上界；点估计会把评估噪声当作真实退化，也会漏掉被噪声掩盖的真实退化。

关键代码与解读

以下片段参照公开的 world model 评估实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：多步 rollout 评估循环

import torch

@torch.inference_mode()
def rollout_metrics(world_model, init_states, action_seqs, horizon=50):
    """沿固定动作序列自回归推进，逐歩记录三层指标。"""
    z = world_model.encode(init_states)          # [B, D]
    # 指标字典按步数追加：保留完整曲线，拒绝只看端点
    curve = {"latent_l2": [], "recon_l1": []}
    for k in range(horizon):
        a = action_seqs[:, k]
        z = world_model.transition(z, a)          # 自回归：上一步输出即输入
        curve["latent_l2"].append(world_model.latent_error(z, k))
        curve["recon_l1"].append(world_model.recon_error(z, k))
    # 堆叠为 [H, B]，便于随后按维度聚合并画置信区间
    return {key: torch.stack(value).mean(dim=1)
            for key, value in curve.items()}

解读：（1）自回归结构与训练一致，任何"用真实帧替换预测帧"的评估都属于另一种协议，不能混用；（2）逐步记录完整曲线：曲线形态（线性段与发散段的转折）本身就是诊断信息；（3）latent_error 与 recon_error 分别对应当前潜状态与真实状态的比较，实现上需要评估器持有真实序列；（4）推理模式关闭梯度，评估批可以放大以摊薄开销。

片段 2：误差增长拟合与可预测时域

import numpy as np

def fit_horizon(steps, errors, threshold=None):
    """拟合误差增长模型，返回增长率 lambda 与可预测时域 k*。"""
    errors = np.asarray(errors, dtype=np.float64)
    if threshold is None:
        threshold = 2.0 * errors[0]               # 相对口径：单步误差的两倍
    # 在 log 空间做线性拟合：log e_k ≈ log eps + k log(1+lambda)
    valid = errors > 0
    k = steps[valid]
    log_e = np.log(errors[valid])
    slope, intercept = np.polyfit(k, log_e, 1)
    lam = np.exp(slope) - 1.0
    eps = np.exp(intercept)
    # 可预测时域：误差穿越阈值所需步数；λ 过小则按线性外推
    if lam > 1e-6:
        k_star = np.log(threshold / eps) / np.log(1.0 + lam)
    else:
        k_star = (threshold - eps) / max(slope, 1e-9)
    return {"lambda": float(lam), "eps": float(eps), "k_star": float(k_star)}

解读：（1）在 log 空间拟合把指数模型转化为线性回归，极值点对拟合的影响被压缩；（2）阈值缺省用"单步误差两倍"的相对口径，跨模型可比较；（3）λ 接近零时指数公式数值不稳定，切换到线性外推分支；（4）拟合区间应由调用方截取（例如前 80%），避免发散尾段拉高 λ，本函数只负责拟合本身。

片段 3：开环与闭环的对照评估

def closed_loop_eval(world_model, policy, env_stub, n_episodes=50):
    """闭环评估：策略与模型交互，返回任务量与预测误差两组指标。"""
    results = {"success": [], "pred_err": []}
    for _ in range(n_episodes):
        z = world_model.encode(env_stub.reset())
        done = False
        while not done:
            a = policy.act(z)                      # 策略只看模型潜状态
            z_next = world_model.transition(z, a)
            # 周期性用真实环境校验：防策略利用模型误差表面得分
            if env_stub.tick % 10 == 0:
                results["pred_err"].append(
                    world_model.latent_error(z_next, env_stub.state()))
            a_exec = policy.postprocess(a)         # 真实环境执行同一动作
            done = env_stub.step(a_exec)
            z = z_next
        results["success"].append(env_stub.success)
    return {k: float(np.mean(v)) for k, v in results.items()}

解读：（1）闭环评估中策略在模型内规划、真实环境执行，指标同时包含成功率与预测误差，防止"模型内成功、现实中失败"被成功率单指标掩盖；（2）周期性真实校验是发现奖励黑客式行为的探针，间隔越密越可靠但成本越高；（3）动作经 postprocess 后再进真实环境，保证与部署链路一致；（4）结果按回合聚合，报告时给出均值与置信区间。

常见坑

  • 只报告单步误差：单步指标接近，多步行为一个保真一个发散。修复：任何模型版本对比都附多步曲线与 k*，单步指标仅作为附属信息。
  • 像素指标饱和误导：模糊预测在均方误差上更"安全"。症状是像素指标改善而闭环成功率下降。修复：联合使用条件生成指标与潜空间指标，闭环评估作为最终判据。
  • 评估序列来自训练集：初始状态与动作序列与训练重叠，指标虚高。修复：按轨迹级切分训练与评估数据，检查初始帧的重叠率。
  • 动作分布错配：只用演示动作评估，高估模型在探索动作上的可靠性。修复：加入探索组与平滑随机组，按来源分层报告。
  • 混淆自回归漂移与模型误差：评估起点从模型生成帧切换时误差跳升，被误判为模型退化。修复：分别报告两种起点协议的曲线，漂移差异本身是重要诊断指标。
  • 拟合区间包含饱和尾段：误差曲线进入饱和区后弯曲变平，整段做对数线性拟合会把 λ 压低、k* 抬高，报告出远超实际发散点的时域。修复：把拟合窗口截到曲线拐点之前（协议默认前 80% 段），在图中同时画拟合线与原始曲线，拐点位置异常时优先检查数据，调参放在其后。

练习与思考

  1. 把误差阈值 T 从单步误差的 2 倍收紧到 1.5 倍。预测 k* 的变化方向与幅度由什么决定，并说明这一收窄对规划时域选择的影响。★
    提示
    k* = log(T/ε) / log(1+λ)，阈值收紧使分子减小，k* 缩短；缩短幅度与 λ 同向放大。规划时域应设在 k* 以内，阈值收窄要求更短的规划或更准的模型。
  2. 推导：若误差按 ek = ε(1+λ)k 增长，证明 k* = log(T/ε) / log(1+λ)；并说明当 λ 接近零时该公式的极限形式。★★★
    提示
    两边取对数解出 k 即得；λ 趋近零时 log(1+λ) ≈ λ，故 k* ≈ log(T/ε) / λ。若改用线性增长模型 e_k = ε + ck 且 c = ελ，则 k* = (T/ε − 1) / λ，两个近似在 T 接近 ε 时一致（此时 log(T/ε) ≈ T/ε − 1）。T = 2ε、λ = 0.02 时两种口径相差明显：对数式给出 35.0，线性式给出 50.0，报告时必须注明所用模型。
  3. 设计动作分布消融：比较演示、策略、平滑随机三组动作下的误差曲线，预测哪一组的 k* 最大、哪一组最能暴露模型边界，并说明选择动作分布的方法论。★★
    提示
    演示组通常 k* 最大（与训练分布最接近）；平滑随机组噪声大但覆盖广，最能暴露边界；选择依据是部署侧真实动作分布，评估集应尽量贴近它并覆盖其尾部。
  4. 构造一个"开环指标好、闭环指标差"的场景，解释机制并给出至少两种针对性的修复手段。★★
    提示
    策略利用模型误差（预测偏好特定动作）刷高闭环回报，而真实执行失败；开环曲线看不出这一点。修复：周期真实校验、对想象回报做不确定性惩罚、缩短规划时域到 k* 以内。
  5. 计算：ε = 0.01、λ = 0.05，阈值取 4 倍单步误差时 k* 为多少？与 2 倍阈值的结果对照，说明阈值档位变化对 k* 的影响规律。★★
    提示
    k* = log 4 / log 1.05 ≈ 28.4，恰为 2 倍阈值结果 14.2 的两倍（因 log 4 = 2 log 2）；阈值再加到 8 倍时 k* ≈ 42.6，只放大 1.5 倍。规律是 k* 随 log T 线性增长，阈值档位提升的边际收益递减。可用 Python 直接计算三档核对。

小结

  • 长期预测评估必须基于自回归 rollout，单步指标不足以判断可用性。
  • 三层指标（像素、潜空间、任务量）互补，报告时同时给出并注明各自盲区。
  • 误差增长曲线拟合出增长率 λ，结合阈值定义可预测时域 k*，使"能预测多远"成为可比较的标量。
  • 开环评估测预测器，闭环评估测预测器与策略的联合可靠性，两者成对报告。
  • 动作序列分布与数据切分是评估协议中最易出错的两个变量，需要分层与防泄漏设计。
  • 下一章进入不确定性估计：让模型在误差增长之前就给出"这里的预测不可信"的信号。
