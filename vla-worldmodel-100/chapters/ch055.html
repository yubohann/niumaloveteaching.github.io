第三篇 · 策略与世界模型深化

第 055 章：联合训练中的目标条件设置

把"去哪"变成网络的输入：本章讲清目标嵌入的三种形态、后见重标记（HER）如何把失败轨迹转为监督、目标采样课程如何控制难度分布。

  • 主题：联合训练 / 目标条件（Goal Conditioning）
  • 关键公式：LHER = −log π(at | st, st+k)，rrelabel = 1[d(st+k, g) ≤ ε]
  • 预计学时：55 分钟
  • 前置章节：第 054 章 世界模型的物理一致性约束

学习目标

本章围绕"目标作为条件变量"这一改造，连接表示、监督与采样三个环节。

  • 理解目标条件策略与目标条件世界模型的形式：π(a | s, g) 与 p(s′ | s, a, g) 的条件结构。
  • 掌握目标嵌入的三种形态（状态坐标、图像潜状态、语言嵌入）及其统一的度量空间要求。
  • 掌握后见重标记（Hindsight Experience Replay, HER）的构造过程，能解释它为何把失败轨迹转为监督、以及远目标重标记的偏置来源。
  • 掌握时间对比表示（Time-Contrastive Representation）与目标距离的关系，理解 V(s, g) ≈ −d(s, g) 的直觉。
  • 能设计目标采样课程：按可达性分配采样概率，控制难度分布与正样本比例。

背景与动机

目标条件设定把任务族压缩进一个网络：同一策略接收不同目标，执行"到达目标状态"的通用行为。相比为每个任务单独训练策略，目标条件化带来两个直接收益：数据在不同任务间共享，监督信号的总量按任务数放大；部署时新任务只需给出目标嵌入，无需重新训练。这与第 047 章的零样本泛化互补，前者处理指令语义，本章处理目标状态的空间结构。

困难在于监督信号的组织。任务成功是稀疏的终端信号，随机探索命中的目标寥寥无几，绝大多数轨迹对原始目标是失败样本。后见重标记改变视角：一条失败轨迹对"轨迹中实际到达的状态"而言是成功样本，重标记把这些状态作为新目标写回缓冲。同一份交互数据由此产生与轨迹长度同量级的有效监督，这是目标条件训练能从小数据起步的关键机制。

核心原理

依次讨论条件结构、重标记、距离表示与采样课程。

1. 条件结构与目标嵌入

目标以条件变量进入策略与世界模型。常见嵌入形态有三类：

形态表示优点风险
状态坐标关节位姿或末端位姿向量精确、无表示误差依赖状态估计，尺度随本体变化
图像潜状态目标帧经编码器得到的潜向量复用世界模型编码器，语义丰富潜空间距离与可达步数不完全一致
语言嵌入指令文本经语言编码器得到的向量与用户接口自然对接需要与视觉目标嵌入对齐（第 046 章）

混合形态要求嵌入进入同一度量空间，否则不同来源的目标无法比较。条件注入的典型方式是特征调制（Feature-wise Linear Modulation, FiLM）：目标嵌入经线性层产生缩放与偏置，作用于策略中间特征。这一方式不改变主干结构，适用于任意层数与任意模态的回退。

2. 后见重标记

HER 的流程：采样一条轨迹后，从轨迹的未来状态中选取若干作为重标记目标，把该轨迹改写成对重标记目标的成功或接近成功样本。未来策略（Future Strategy）取目标时刻之后的轨迹状态作为重标目标，是最常用的变体：

g ← st+k（k 为该轨迹内的时间偏移），rrelabel = 1[d(st+k, g) ≤ ε] 重标记目标的奖励在到达时刻为 1；轨迹中其余时刻的奖励按距离函数重算或保持为 0

重标记改变的是目标的分布，不改变最优行为：对任意状态 s 与任意目标 g，"走向 g"的最优动作与目标来源无关；因此对重标记样本的学习仍然面向正确的目标条件策略。偏置出现在远目标上：轨迹实际到达 st+k 的过程中可能绕过障碍或依赖特定初始化，沿该轨迹回溯学习的"走向 st+k"在 s0 处未必最优，k 越大偏置越强。控制 k 的分布是缓解手段。

数值算例：一条 T = 100 步的轨迹可供重标记的起点为 t = 0 至 95（剩余步数不少于下界 4），共 96 个；偏移 k 在 [4, 16] 均匀采样（均值 10），每个起点的目标都在其窗口内被到达，成功信号从原始目标的约 1 个放大到 96 个，接近两个数量级。

3. 距离表示与时间对比

目标条件价值可近似为目标与状态之间的距离：离目标近，价值高。时间对比表示直接训练"潜距离与到达步数成正比"的嵌入：

LTC = −log exp(−‖f(st) − f(st+k)‖) / Σj exp(−‖f(st) − f(st+j)‖) 同一轨迹内，时间差越小的状态对在嵌入空间越近；这个软排序目标把时间结构写入表示

目标距离的负值可以直接充当势函数（第 044 章），也可以作为课程采样的可达性估计：d(s, g) 小目标视为近目标，采样的难度分布由距离估计调制。该表示的精度依赖轨迹多样性，单一轨迹内的时间对比无法区分"空间相似但不可达"的状态对。

4. 目标采样课程

均匀采样目标时，远目标与不可达目标占据大量比例，正样本稀疏。课程采样按估计可达性分配概率：当前状态附近的目标获得更高采样权重，随训练推进逐步扩大采样半径。课程的关键参数是难度分布的上界：目标难度用距离估计或世界模型的剩余到达步数衡量；上界随时间推进，使正样本比例维持在可学习区间（经验上 30% 至 60%）。

实现思路与设计

设计覆盖重标记比例、目标嵌入维度与课程调度三部分，训练批次混合原始目标与重目标样本。

数据流

  1. 环境轨迹入缓冲时保留全程状态序列，供未来策略重标记使用。
  2. 批次组装：原始目标样本与重标记样本按比例混合，重标记偏移 k 从配置的分布采样。
  3. 目标嵌入与世界模型潜状态共享编码器，注入策略时经 FiLM 调制。
  4. 课程调度器按距离估计调整目标采样分布，并记录正样本比例。

与前一章的差异点

第 054 章约束预测的物理合理性，作用于世界模型的输出空间；本章改变策略与世界模型的输入条件结构，把任务族的差异归入目标嵌入。两章在联合训练中互为支撑：目标条件化的想象 rollout 可以围绕指定目标展开，物理一致性保证长程想象不偏离可执行范围。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖重标记、目标条件融合与课程采样。数值与上表一致。

片段 1：未来策略重标记

import numpy as np

def relabel_with_future(traj, k_min=4, k_max=16, eps=0.05, ratio=0.8):
    """后见重标记：从轨迹未来状态中抽取新目标，重写奖励。"""
    states = traj["states"]                       # (T, D) 全程状态序列
    T = len(states)
    relabeled = []
    for t in range(T - 1):
        if T - t - 1 < k_min:
            continue                              # 剩余步数不足下界，起点无效
        if np.random.rand() > ratio:
            continue                              # 保留部分样本的原始目标
        # 偏移 k 从区间均匀采样：k 越小偏置越弱，样本越容易到达
        k = np.random.randint(k_min, min(k_max, T - t - 1) + 1)
        goal = states[t + k]
        # 重标记奖励：轨迹到达目标时刻记 1，其余时刻按距离阈值判定
        reward = np.array([1.0 if np.linalg.norm(states[i] - goal) <= eps else 0.0
                           for i in range(t, T)])
        relabeled.append({"obs": traj["obs"][t], "action": traj["actions"][t],
                          "goal": goal, "reward": reward})
    return relabeled

解读：（1）未来策略保证重标记目标在该轨迹中确实可达，轨迹本身就是"到达该目标"的示范，监督信号真实存在。（2）k 的下界过滤掉过近目标：偏移 1 至 2 步的目标缺乏区分度，容易让策略学到恒等行为。（3）奖励重算按与目标的状态距离，判定阈值与评估口径共用同一 ε，避免训练与验收标准不一致。

片段 2：目标条件的特征调制

import torch
import torch.nn as nn

class GoalFiLM(nn.Module):
    """用目标嵌入调制策略中间特征：缩放与偏置两步。"""
    def __init__(self, goal_dim=256, feat_dim=512):
        super().__init__()
        # 一次线性层同时输出缩放与偏置，参数效率高于两个独立层
        self.to_gamma_beta = nn.Linear(goal_dim, 2 * feat_dim)
        # 初始化缩放为接近 1：训练初期保持主干行为，目标影响渐进引入
        nn.init.zeros_(self.to_gamma_beta.weight)
        nn.init.zeros_(self.to_gamma_beta.bias)

    def forward(self, feats, goal_embed):
        gamma, beta = self.to_gamma_beta(goal_embed).chunk(2, dim=-1)
        return feats * (1.0 + gamma) + beta       # 恒等初始化的调制

解读：（1）缩放参数初始化为零、输出用 1 + γ 的形式，训练起点等价于无条件的策略，目标条件的影响从零开始增长，避免随机初始化破坏已预训练的主干。（2）目标嵌入与特征维度的对齐由线性层完成，任意模态的目标只需提供向量形式。（3）FiLM 可插入主干多个深度，浅层调制影响语义选择，深层调制影响动作细节；从深层开始插入是更稳的起点。

片段 3：按可达性加权的课程采样

import numpy as np

def sample_goals(states, current, radius, n=64):
    """课程采样：优先选择当前可达半径内的目标，维持正样本比例。"""
    dists = np.linalg.norm(states - current[None, :], axis=-1)   # (M,) 目标候选距离
    # 可达性权重随距离衰减：半径内的目标高概率，半径外快速降权
    weights = np.exp(-(dists / max(radius, 1e-6)) ** 2)
    weights = weights / weights.sum()
    idx = np.random.choice(len(states), size=n, p=weights, replace=False)
    return states[idx]

# 课程调度：随训练步数扩张半径，同时记录正样本比例
# radius = min(radius_max, radius_init * 2 ** (step / (0.2 * total)))

解读：（1）高斯核权重让采样集中在当前可达范围，半径参数是唯一的难度旋钮，调度简单可预测。（2）每 20% 训练步数半径翻倍，与上表一致；扩张期间监控正样本比例，跌破 30% 时暂停扩张。（3）目标候选来自回放缓冲中的真实状态，采样分布由物理可达性约束，不会生成无法到达的虚构目标。

常见坑

  • 目标泄漏：把目标时刻已到达的状态特征混入当前观测输入，策略直接读取答案，训练损失下降但真实任务失败。修复：严格分离观测与目标输入，泄漏场景用消融验证。
  • 目标与状态表示不一致：目标用坐标表示，状态用潜状态表示，两者距离无意义。修复：统一嵌入空间，或对两套表示训练显式对齐损失。
  • 远目标重标记比例过高：价值估计被偏置样本污染。修复：限制 k 的上界并监控各 k 区间的价值误差。
  • 课程扩张过快：正样本比例跌破区间的下界，学习停滞。修复：按正样本比例反馈调节扩张速率，固定时间表无法对比例跌破作出响应。
  • 语言目标与图像目标混用未对齐：策略对两类目标的行为不一致，接口切换时性能跌落。修复：用第 046 章的对比对齐把两类嵌入拉到同一度量空间。

练习与思考

  1. 证明思路：说明重标记不改变目标条件最优策略，但改变训练目标的分布，解释偏置出现在哪些样本上。★★
    提示
    目标的语义独立于数据来源，约束"到达 g"的最优行为唯一。偏置来自轨迹回溯：远目标的示范路径在起点处未必是该目标的最优路径，k 越大越明显。
  2. 把重标记比例从 0.8 降到 0.3，预测三件事的变化：正样本比例、原始目标成功率、训练损失下降速度，并说明验证方式。★★
    提示
    正样本比例下降，原始目标成功率可能先降后稳，损失下降变慢。验证：分别报告原始目标与重标记目标的成功率曲线。
  3. 设计时间对比表示的训练目标：写出正负样本构造、损失形式与对"空间相似但不可达"状态对的局限，并给出改进思路。★★★
    提示
    同一轨迹内不同时间差的状态对作为排序样本；单轨迹无法区分不可达对。改进：跨轨迹对比加动力学可达性标签。
  4. 讨论：目标距离作为势函数（第 044 章）与作为课程难度（本章）两种用法对距离估计精度的要求有何不同？★★
    提示
    势函数要求单调且量与回报尺度匹配，估计误差直接偏置学习目标；课程只要求相对排序可靠，对绝对尺度不敏感。后者容错更高。

小结

  • 目标条件化把任务族压缩进单一策略与世界模型，数据跨任务共享，新任务以目标嵌入驱动。
  • HER 用轨迹未来状态重写目标与奖励，把失败轨迹转为有效监督，偏置随目标距离增长。
  • 时间对比表示让潜距离近似到达步数，可同时服务势函数与课程难度估计。
  • 课程采样按可达性分配概率，正样本比例维持在 30% 至 60% 的可学习区间。
  • 目标泄漏与表示不一致是两类高频错误，分别用输入分离与统一嵌入空间解决。
