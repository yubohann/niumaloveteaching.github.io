第 007 章：VLA与世界模型交替训练策略

本章把联合更新拆成排班问题：预热期的设定、块交替的节奏、世界模型 EMA 目标的稳定性控制，以及冻结切换中容易忽视的状态残留，目标是让两个子任务各自收敛而不互相打断。

  • 主题：联合训练 / 交替训练策略
  • 关键公式：φ̄ ← ρ·φ̄ + (1-ρ)·φ
  • 预计学时：60 分钟
  • 前置章节：第 006 章

学习目标

  • 理解交替训练的动机：两路任务学习速率差异与梯度干扰，以及坐标上升视角下的近似解释。
  • 掌握预热期与块交替的排班设计，能解释块长与切换频率对收敛的影响。
  • 掌握世界模型指数滑动平均（Exponential Moving Average, EMA）目标的更新机制与陈旧性权衡。
  • 能识别冻结切换中的状态残留问题（优化器动量、归一化统计、随机性模块）。
  • 能设计实验比较同步联合、交替与预热加交替三种排班的收敛行为。

背景与动机

001 至 005 章采用同步联合更新。两路任务学习速率相近时同步效率最高；世界模型尚不可信时，其预演信号会带偏策略，策略梯度还被预测梯度稀释。交替训练把“同时满足两个目标”换成“轮流专注一个目标”，用排班换取稳定与可控。

该策略在基于模型的强化学习与生成式世界模型训练中广泛出现：先用数据把世界模型训到可用，再用其预演服务策略，并以滑动平均目标副本稳定训练。本章把这些经验固化成可配置流程。

与 008 章的分工：本章解决“何时训谁、节奏怎么排”，008 章解决“生成数据如何写进策略损失”。

核心原理

1. 为什么交替：干扰与速差

同步更新的两路梯度在共享参数上相加，两个问题同时存在：速差，预测任务早期损失大、收敛慢，策略任务收敛快，同一学习率对两者不可能同时合适；干扰，两路梯度方向夹角大于 90 度时互相抵消，等效学习率下降。交替训练在每个阶段只保留一路梯度，把两个问题分别消解。

交替更新：φ ← φ - η·∇φLwm（第一阶段） ； θ ← θ - η·∇θLpolicy（第二阶段） φ 为世界模型参数，θ 为策略参数；两阶段各自使用独立优化器与学习率

从优化视角看，交替更新是坐标上升式近似：固定一组优化另一组，轮流逼近联合驻点。耦合越弱（下游头彼此独立），交替越接近同步联合的效果。用一个二次型算例量化这一判断：目标 f(x, y) = (x2 + 2bxy + y2)/2，交替固定一个变量优化另一个时，一轮后的误差收缩因子为 b2。该收缩因子两步可以推出：先对 x 极小化得 x = -b·y，再对 y 极小化得 y = -b·x，消元后慢模态幅度每轮乘 b2。数值代入：b=0.3 时每轮收缩到 0.09，四轮后剩 0.094 ≈ 6.6×10-5；b=0.5 时每轮 0.25，八轮后剩 0.258 ≈ 1.5×10-5；b=0.9 时每轮 0.81，八轮后仍剩 0.818 ≈ 0.19。耦合越强，交替逼近联合驻点的代价越大，此时应减小块长回到更细粒度的同步配平；继续加大块长会进一步放大逼近误差。

梯度干扰的强度可以定量刻画。把两路梯度记为 g1 与 g2，同步更新等效于沿合成方向 g1+g2 前进一步，其模平方展开为 |g1|2 + |g2|2 + 2|g1||g2|·cosψ，其中 ψ 为两向量夹角。把两路梯度都归一化为单位模长，合成梯度模随夹角的变化见下表。单路更新步长恒为 1，夹角 120 度时合成模恰好回落到 1，超过 120 度后同步更新连单路都比不过；夹角 90 度到 120 度之间，合成仍优于单路，但与两路分开更新相比已损失大量有效步长。训练早期预测任务与策略任务对共享主干提出的表征需求常常冲突，梯度夹角超过 90 度并不罕见，这是交替排班在早期收益最大的定量解释。

夹角 ψcosψ合成梯度模判读
0°1.0002.000方向完全一致，有效步长两倍于单路
60°0.5001.732增益大部分保留
90°0.0001.414正交，合成模为单路的 1.414 倍
120°-0.5001.000危险线：合成模等于单路
180°-1.0000.000完全抵消，训练停滞

一种常见误区是在同一批次内分别计算两路损失并顺序反传，把这种实现当作交替训练。两者并不等价：两次 step 之间参数已经变化，第二路梯度建立在第一路更新后的参数上，动量缓冲在两步间交错累积，方向统计混杂；这种拼接无法替代一个阶段的连续优化。真正的交替训练以块为单位隔离梯度路径（片段 1），阶段内完成若干完整更新后再切换。

2. 排班设计：预热、块长与比例

排班三要素：预热期、块长、交替比例。预热期只训世界模型，因为模拟器不可用时策略等于用噪声当老师；预热长度以单步预测误差进入平台期为判据，常用两千到五千步。切换过频则任务反复重启，块长过大则退化为分段独立训练；块长常规取五百到两千步，与数据规模成正比。

比例调度：wm_share(step) = 0.5 - 0.2 · min(1, (step - warmup)/ramp) 预热后世界模型份额从 0.5 缓降到 0.3；训练后期把更多算力让给策略

设计逻辑：早期多训预测器提升质量，后期多训策略吸收信号；渐变份额比固定比例更贴合两阶段需求。

3. EMA 目标与陈旧性权衡

策略训练时若直接使用当前世界模型生成目标，目标会随每次参数更新变化，产生“追逐移动靶”现象。标准解法是维护一份指数滑动平均副本（目标网络）：

φ̄ ← ρ·φ̄ + (1-ρ)·φ ρ 取 0.999 时目标网络的等效滞后约 1000 步；ρ 越大目标越稳、跟随越慢

更新只作用于权重本身，不携带任何梯度。ρ 的选择是一次权衡：目标过新则噪声大，目标过旧则策略在学习过时的动力学。缓解手段是设置硬同步周期（如每两千步把在线权重整体复制到目标网络），让滞后有上界；切换交替阶段时先做一次硬同步，保证阶段间行为一致。

指数权重的形状提供另一种解读：目标网络是历史权重的加权和，第 k 步之前参数的权重为 (1-ρ)ρk。ρ=0.999 时，从最新参数往回累计到总权重一半需要 693 步（方程 ρk=0.5 的解析解 ln0.5/lnρ ≈ 692.8），即目标网络一半以上的影响来自最近 693 步以内的参数；再往后看，第 999 步前的权重仍占 (1-ρ)ρ999，与最新参数权重之比为 0.368，累计滞后约千步，与前一节的稳态推导互相印证。这个视角说明硬同步的价值：它把全部历史权重替换为当前权重，累计陈旧度瞬间清零，因此平滑更新与硬同步必须成对使用。

4. 冻结切换中的状态残留

冻结一次切换要处理三层状态，只冻结参数是不够的：优化器层，为两个子模型使用独立优化器，避免 A 任务的动量进入 B 任务的第一批更新，必要时在切换时清空动量缓冲；归一化层，批归一化的滑动统计在参数冻结后仍会随前向更新，需把冻结模块置于评估模式，否则统计漂移会缓慢改变冻结模型的输出；随机性层，丢弃概率等随机模块在冻结侧应失效，冻结模块进入评估模式即可同时解决这两点。

5. 何时保留同步联合

交替的优势有前提：数据同源、损失量级接近、主干容量充足时，同步联合的表征耦合更好。判定标准量化为每千步验证损失下降率，交替高出两成以上才值得引入排班复杂度。工程上保留两种模式的配置开关，用对照实验定夺。

6. 推导与算例：EMA 滞后与排班形态

先补 EMA 的滞后推导。设在线参数每步前进 v，目标网络按 θ̄ ← ρ·θ̄ + (1-ρ)·θ 更新，记滞后 Lt = θt - θ̄t，展开递推得 Lt = ρ(v + Lt-1)，稳态解为 L* = ρ·v/(1-ρ)。ρ=0.999、v=1e-3 时稳态滞后约 1.0 个参数单位；ρ=0.99、v 同为 1e-3 时约 0.099。目标网络的等效权重年龄均值为 ρ/(1-ρ)，ρ=0.999 时约 999 步，与稳态滞后互相印证。

硬同步把上界写死：每 2000 步整体复制一次，偏差在周期内最多累积 2000v = 2 个参数单位，周期内的平均偏差约 1000v。平滑更新压制高频抖动（方差），硬同步限制长期漂移（上界），两者解决不同问题，配置中成对出现。

排班形态用数字过一遍：预热 2000 步、块长 500、比例 1:1 时，第 2000 到 3999 步的阶段序列为 世界模型（2000 至 2499）、策略（2500 至 2999）、世界模型（3000 至 3499）、策略（3500 至 3999），循环周期 1000 步。份额曲线在第 2000、4500、7000 步分别取 0.5、0.4、0.3。预热长度换算成样本量：批量 128 时 2000 步对应 25.6 万样本，数据规模不足时需要按比例缩短预热，否则预热期本身就会过拟合。

切换清理的量级也给出数字：优化器一阶动量按 β1=0.9 每步衰减，不清理时旧任务动量在第 20 步残留 12.2%、第 30 步残留 4.2%、第 50 步后低于 1%，即切换后的前二三十步更新方向持续受旧任务影响；清空的代价只是一次缓冲置零，属于低代价高收益的操作。

排班稳定性收敛速度实现成本适用

7. 边界与失效模式

  • 硬同步落在策略阶段中段：目标网络突然更新会让策略损失跳变。修复：把硬同步对齐到阶段切换点执行，与本节切换清理函数同批处理。
  • ρ 与块长失配：ρ=0.99 时等效滞后约 100 步，短于块长 500，目标网络几乎等于在线网络，平滑作用消失。修复：按“等效滞后覆盖一个块长以上”选择 ρ，块长 500 到 2000 时配 ρ=0.999。
  • 评估与部署共用目标网络：目标网络落后于在线权重，作为评估模型会低估当前能力，作为部署模型反而更平滑。修复：评估明确标注权重来源，在线与 EMA 两条曲线并列展示。
  • 冻结侧未退出训练模式：丢弃与批归一化在冻结参数上继续改变前向输出，等价于参数仍在漂移。修复：切换函数统一置评估模式，并在切换后对比冻结模块输出与切换前的差异。
  • 阶段间采样口径漂移：世界模型阶段消费未来观测窗口，策略阶段消费动作块窗口，若两阶段各自重置采样器，批次构成在切换点跳变，损失曲线出现假拐点。修复：采样器状态跨阶段连续（016 章的检查点含采样进度），两阶段读取同一来源配额。

实现思路与设计

训练系统拆成四层：排班器（按步输出阶段与比例）、冻结管理（参数、模式、优化器三件事）、目标网络（EMA 副本与硬同步）、单阶段损失（复用 005 章的损失设施）。四层解耦后，排班策略的修改不触碰损失实现，便于消融。

片段 1：排班器与交替更新循环

def phase_of(step, warmup=2000, block=500, wm_ratio=1, pol_ratio=1):
    """按训练步返回当前阶段：预热期只训世界模型，随后按块交替。"""
    if step < warmup:
        return "world"                       # 模拟器不可用时，策略没有可信老师
    k = (step - warmup) // block             # 从预热结束起计算的块编号
    period = wm_ratio + pol_ratio
    # 每个周期前 wm_ratio 个块训世界模型，其余块训策略
    return "world" if k % period < wm_ratio else "policy"

def set_trainable(module, flag):
    """切换 requires_grad；冻结侧不产生梯度，梯度只从激活头汇入共享主干。"""
    for p in module.parameters():
        p.requires_grad_(flag)

def train_alternating(policy, world, opt_p, opt_w, batches,
                      warmup=2000, block=500):
    """交替训练主循环：每个阶段只走一路损失与一个优化器。"""
    for step, batch in enumerate(batches, start=1):
        if phase_of(step, warmup, block) == "world":
            set_trainable(policy, False)
            loss, parts = world_loss(world, batch)      # 005 章的预测损失
            opt_w.zero_grad(set_to_none=True)
            loss.backward()
            opt_w.step()
        else:
            set_trainable(world, False)
            loss, parts = policy_loss(policy, batch)    # 动作或预演监督损失
            opt_p.zero_grad(set_to_none=True)
            loss.backward()
            opt_p.step()
        set_trainable(policy, True)         # 恢复可训练标记，避免冻结状态外溢
        set_trainable(world, True)

解读：（1）阶段判定是纯函数，输入步数输出字符串，可脱离模型做穷举测试。（2）冻结通过 requires_grad 实现，配合独立优化器，梯度只在当前激活头的路径上产生；共享主干仍随激活头更新，保留联合表征收益。（3）循环末尾统一恢复标记，防止异常中断把冻结状态遗留到下一阶段，这是长时间训练中难以排查的隐性故障点。

片段 2：EMA 目标网络

import copy

class EMATarget:
    """世界模型的指数滑动平均副本：为策略训练提供平滑的预测目标。"""
    def __init__(self, world, decay=0.999):
        self.decay = decay
        # 深拷贝并整体关闭梯度：目标网络只经 EMA 更新，不参与反向传播
        self.target = copy.deepcopy(world)
        for p in self.target.parameters():
            p.requires_grad_(False)

    @torch.no_grad()
    def update(self, world):
        # 逐参数向在线网络靠拢：decay 越大目标越稳，跟随越慢
        for pt, po in zip(self.target.parameters(), world.parameters()):
            pt.mul_(self.decay).add_(po.detach(), alpha=1.0 - self.decay)

    @torch.no_grad()
    def hard_sync(self, world):
        # 硬同步给出滞后上界：每 2000 步执行一次，防止目标长期陈旧
        self.target.load_state_dict(world.state_dict())

解读：（1）目标网络整体 detach，确保任何调用路径都无法把梯度写入目标参数，稳定性由结构保证，调用纪律只作兜底。（2）EMA 更新用原地运算，避免每步分配新张量；参数数量与在线网络相同，显存占用翻倍属于预期成本。（3）硬同步与平滑更新并存：前者限制最大滞后（上界），后者消除高频抖动（方差），两者解决不同问题。

片段 3：比例渐变与切换清理

def wm_share(step, warmup=2000, ramp=5000):
    """阶段内算力份额：世界模型份额从 0.5 缓降到 0.3。"""
    if step < warmup:
        return 1.0                          # 预热期份额为一，全部算力给世界模型
    x = min(1.0, (step - warmup) / float(ramp))
    return 0.5 - 0.2 * x                    # 线性退火，避免份额突变引起曲线拐点

def on_phase_switch(module, optimizer, clear_momentum=True, hard_sync_fn=None):
    """切换时的清理：评估模式冻结统计，清空跨任务的动量残留。"""
    # 冻结侧进入评估模式：批归一化统计与随机失活同时失效，杜绝缓慢漂移
    module.eval()
    if clear_momentum:
        # 旧任务的动量方向对新任务的早期更新有害，切换时清空缓冲
        for state in optimizer.state.values():
            for key in ("exp_avg", "exp_avg_sq"):
                if key in state:
                    state[key].zero_()
    if hard_sync_fn is not None:
        hard_sync_fn()                      # 可选：阶段切换时同步目标网络

解读：（1）份额用线性退火逐段过渡，训练曲线的拐点更少，便于判断超参数改动的影响。（2）切换函数把“模式、动量、目标同步”三件事收口到一处，冻结切换不完整是交替训练最常见的隐性故障。（3）清动量默认开启，若两阶段梯度尺度经归一化后接近，可关闭以减少计算。

常见坑

  • 无预热直接交替：策略在不可信的世界模型上训练，策略损失反复反弹。修复：加预热期并以预测误差平台期为起始判据。
  • 切换过频：两个任务都没进入下降通道就被打断，损失曲线呈锯齿。修复：增大块长，或改比例退火让阶段内目标更单一。
  • 目标网络陈旧：ρ 过大又无硬同步，策略在学习过时动力学上表现尚可、换到真实环境即失败。修复：设置硬同步周期，并监控目标与在线输出的偏差。
  • 冻结残留：参数冻结但批归一化统计仍在漂移，冻结模型输出缓慢改变。修复：冻结侧置评估模式，切换函数统一处理。
  • 单优化器跨任务复用：动量缓冲在两个任务间传递，切换后首批更新方向异常。修复：独立优化器，或切换时清空动量。

  1. 预热 2000 步、块长 500、比例 1:1，写出第 2000 到 4000 步的阶段序列，并标出策略阶段的步数区间。★
    提示
    块编号 0 到 3；序列为 世界模型、策略、世界模型、策略。策略阶段为 2500 至 2999 与 3500 至 3999 步区间。
  2. 把 EMA 系数 ρ 从 0.999 改为 0.99，目标网络的滞后与稳定性各怎样变化，给出观测指标。★
    提示
    滞后从约千步降到约百步，目标更跟得上在线改进，但噪声增大；观测策略损失方差与目标输出的逐步偏差。
  3. 推导：由 EMA 递推式证明第 t 步目标与在线的偏差以 ρt 衰减，并说明硬同步如何给出偏差上界。★★
    提示
    偏差项按 ρ 的幂次衰减，约 1/(1-ρ) 步后进入稳态；硬同步把累积偏差直接清零，周期越长上界越大。
  4. 设计对照实验：同步联合、交替、预热加交替三种排班，给出至少三个对比指标与判定交替优越性的标准。★★
    提示
    指标：每千步验证损失下降率、两路验证指标、训练曲线稳定性。判定标准需写成阈值，例如下降率高出 20% 且无锯齿。
  5. 构造冻结残留的复现实验：开启冻结但保留批归一化更新，量化冻结模块输出的漂移幅度，并给出修复前后的对照。★★★
    提示
    固定输入、逐步前向冻结模块并统计输出均值方差变化；预期统计漂移随时间累积，置评估模式后趋近于零。

小结

  • 交替训练用排班消解速差与梯度干扰，是对联合目标的坐标上升式近似。
  • 排班三要素：预热期、块长、交替比例；预热以预测误差平台期为判据。
  • EMA 目标网络抑制“追逐移动靶”，ρ 控制平滑度，硬同步提供滞后上界。
  • 冻结切换必须处理优化器动量、归一化统计与随机性模块三层状态。
  • 同步联合在任务兼容时仍是首选，是否交替应由每千步收敛率对照实验决定。
