第 064 章：联合训练中的多尺度处理

本章讲联合训练中的多尺度处理（Multi-Scale Processing）：用双速率分层接口协调高频动作与低频子目标，用多时间跨度损失监督世界模型，用特征金字塔对齐全局布局与局部接触细节。

  • 主题：联合训练 / 时空多尺度架构
  • 关键公式：L = Σℓ wℓ Lℓ，分层接口 g = πhigh(o, l)，a = πlow(o, g)
  • 预计学时：50 分钟
  • 前置章节：第 063 章：世界模型的图结构表示

学习目标

  • 理解多尺度处理要解决的梯度冲突：快变与慢变结构被同一网络拟合时的干扰。
  • 掌握双速率分层接口的设计：高层低频输出子目标（Subgoal），低层高频跟踪。
  • 掌握世界模型的多时间跨度损失，理解 stride 组合与权重配置对长期预测能力的影响。
  • 能实现特征金字塔（Feature Pyramid）融合与多分辨率预测头，理解粗分辨率与细分辨率监督的梯度特性。
  • 会诊断尺度错位、低分辨率主导与上采样伪影污染等问题，能设计 coarse-to-fine 权重课程实验。

背景与动机

本节说明多尺度处理针对的训练矛盾：联合训练同时包含快变与慢变结构。接触瞬间的力、位移与抓取姿态在数十毫秒内变化，任务阶段、指令语义与场景布局在数秒尺度上演化。单一时间尺度监督让共享主干同时拟合两种变化的梯度，方向经常相反，训练表现为损失震荡或某一侧欠拟合。空间维度同样如此：避障需要全局分辨率较高的视野，插孔与拧螺丝依赖局部接触细节。多尺度处理让每一级只承担与其分辨率匹配的预测任务，梯度冲突由此缓解。

核心原理

1. 时间多尺度：双速率分层接口

分层控制是运动的经典组织方式：慢速决策与快速反射运行在不同频率上。对应架构是双速率策略，高层以 8 Hz 输出子目标 g（如抓取位姿、路径点），低层以 48 Hz 以子目标为条件输出细粒度动作：

gk = πhigh(ot, l)，at:t+s = πlow(ot, l, gk)， s = 6 s 为时间下采样因子（Downsample Factor），高层每 s 步刷新一次子目标

刷新周期是核心超参数。刷新过密时高层与低层频率接近，分层退化为单速率结构；刷新过疏时子目标滞后于场景变化，跟踪误差在刷新周期内持续累积。选择 s 的依据是子目标的语义半衰期：抓取位姿在接近阶段变化慢，s 可以取 6 到 8；接触调整阶段变化快，s 应降到 2 到 3。

2. 世界模型的多时间跨度损失

不同时间间隔的监督信号携带不同信息：近邻项约束局部平滑，长间隔项约束长期结构。多尺度损失在隐空间同时监督多个时间间隔：

L = Σℓ wℓ · Lℓ，Lℓ = ‖fθsℓ(ht, a) − ht+sℓ‖2 sℓ 为第 ℓ 级的预测间隔（stride），fs 表示模型自回归执行 s 步

stride 组合常取 (1, 4, 8)，小间隔项数量多、梯度密，大间隔项数量少、梯度稀。大间隔监督把长期偏差直接暴露给训练目标，防止模型只优化一步预测而在想象 rollout 中迅速漂移。权重随 stride 递减（见表），让信息量大的近邻项保持主导，长间隔项提供结构约束。

3. 数值算例：监督对数量与权重的有效贡献

取一段长度 T = 9 的隐状态序列（8 个动作步加终点），stride 组合为 (1, 4, 8)。每一级的监督对数量为：stride 1 覆盖起点 0 至 7 共 8 对；stride 4 覆盖起点 0 与 4 共 2 对；stride 8 覆盖起点 0 共 1 对。把对数量与默认权重相乘，得到各级的加权监督量：8 × 1.0 = 8.0，2 × 0.5 = 1.0，1 × 0.25 = 0.25，总量 9.25。各级占比约为 86.5%、10.8%、2.7%。

该算例给出两个可供迁移的判断：（1）逐项对数量差一个数量级时，长间隔项的权重即使翻四倍，其监督占比仍只有约 10%，改变占比必须同时变动权重与起点采样密度；（2）若把 stride 8 的权重直接设为 4.0，占比升至 30.8%，此时低分辨率监督开始与近邻项分庭抗礼，细节拟合可能不足，表现为想象图像模糊、精细操作成功率下滑。权重扫描应从算例比例出发，观察占比与验证指标的同向变化再定档。

监督占比ℓ = wℓ · Nℓ / Σℓ′ wℓ′ · Nℓ′，Nℓ = ⌈(T − sℓ) / sℓ⌉ Nℓ 为第 ℓ 级的监督对数量，T 为序列长度，sℓ 为该级 stride

4. 空间多尺度：金字塔融合

视觉编码器天然输出多分辨率特征：深层语义强、分辨率低，浅层细节多、分辨率高。特征金字塔（Feature Pyramid）经自顶向下路径融合两者：高层特征上采样后与低层相加，再经平滑卷积统一通道。对 VLA 的意义在于动作需求的空间分辨率不同：末端位置的精细调整需要高分辨率局部特征，碰撞规避需要低分辨率全局布局。金字塔融合让单个编码器同时服务两类需求。

5. 组合与权重：梯度方差的视角

多尺度损失反向到共享主干时，各级梯度的统计特性不同：长间隔项的梯度方差小但偏差大，指向粗糙解；短间隔项的梯度方差大但偏差小。固定权重的风险是训练早期被平滑项主导。常用策略有两种：coarse-to-fine 课程，早期提高长间隔权重建立结构，后期切为近邻项主导；不确定性加权，按各级预测残差的滑动方差取 wℓ ∝ 1/(σℓ2 + ε)，让噪声大的级别自动降权。多尺度训练的本质是偏差与方差的分配问题，权重即是分配旋钮。三类权重策略的工程特性对照如下：

策略机制优点风险适用条件
固定权重训练全程权重不变实现简单、结果可复现早期平滑项主导或后期细节欠拟合数据分布稳定、已有调参经验
coarse-to-fine 课程早期长间隔项权重大，按步数线性切换至近邻主导先建结构后补细节，收敛稳切换点需要标定，过早切换造成结构未定型长程任务、从随机初始化训练
不确定性加权wℓ ∝ 1/(σℓ2 + ε)，σ 取残差滑动方差免手工扫描，自动适配训练早期方差估计不稳，权重抖动多任务联合、损失量级差异大

组合顺序建议：先用固定权重建立基线并记录各级残差曲线；若发现早期震荡或后期模糊，再切换不确定性加权；coarse-to-fine 课程适合总训练步数充裕且切换点可离线标定的场景。三种策略都建立在同一前提上：各级损失可在同一坐标下比较量级，权重调整才有意义。

实现思路与设计

本节给出组合方案：视觉编码器输出金字塔特征；高层头每 6 步输出一次子目标；低层头每步输出动作；世界模型在隐空间执行 stride 为 1、4、8 的预测，共享动力学、独立损失头。子目标空间与世界模型隐空间对齐后可复用同一套表示。与第 063 章的差异：第 063 章改造状态表征的拓扑结构，本章改造处理粒度的时间与空间分辨率。

设计决策：长间隔监督由世界模型承担的理由

策略的低频决策由子目标接口承担，世界模型获得显式的长间隔监督：同一动力学函数同时预测 1 步、4 步、8 步后的状态。该设计让长间隔约束直接塑造动力学的一致性。长期监督放在世界模型侧，策略侧信号保持短程与密集，两层各取所需。

刷新周期与相位管理的实现要点

  • 刷新相位随机化。训练时随机抽取下采样起点相位，让每个动作步都有机会处于刷新步与非刷新步。固定相位会让一部分动作步永远只被当作“继承者”训练，另一部分永远只被当作“刷新者”训练，两类的梯度分布不同。
  • 子目标表示的对齐。高层输出子目标后，低层需要将其与当前观测特征联合编码。子目标若为位姿向量，先经 MLP 映射到与隐特征同维；若为路径点序列，用动作编码器逐步消费。表示不对齐时低层只能学到对子目标的近似忽略。
  • 刷新步的梯度放大。低层梯度只在刷新步回流高层，刷新步的 batch 承担全部高层监督。若刷新与不刷新的样本比例悬殊，高层梯度噪声大；可用对刷新步加权或延迟累积缓解。
  • 推理期与训练期节奏一致。推理时同样按步号刷新，不根据观测变化率触发。自适应触发会引入推理路径不确定性，且训练分布未覆盖任意触发节奏。
  • 切换期调度。接触阶段把 s 从 6 降到 2 时，刷新频率上升带来高层开销增加；只需在阶段切换点前后各留一段过渡期，让低层网络适应新的子目标刷新率。

关键代码与解读

以下片段以分层策略与多尺度预测的公开设计为参照，接口随版本演进。三个片段分别覆盖双速率接口、多时间跨度损失与金字塔融合。

片段 1：双速率策略接口

import torch.nn as nn

class DualRatePolicy(nn.Module):
    """双速率策略：高层 8 Hz 产子目标，低层 48 Hz 产动作。"""
    def __init__(self, vision, high_head, low_head, downsample=6):
        super().__init__()
        self.vision = vision          # 两种速率共享视觉编码器，参数不翻倍
        self.high_head = high_head    # 输出隐子目标 g：抓取位姿或路径点
        self.low_head = low_head      # 以（观测, 子目标）为条件输出动作
        self.s = downsample           # 时间下采样因子：48 / 8 = 6

    def forward(self, obs_feats, lang, subgoal, step):
        # 是否刷新只由步号决定：刷新节奏确定，低层不依赖高层输出抖动
        refreshed = (step % self.s == 0)
        if refreshed:
            # 高层消费融合后的金字塔特征；慢变量不需要每帧重新编码
            subgoal = self.high_head(obs_feats, lang)
            self.prev_subgoal = subgoal.detach()   # 缓存供后续步使用
        else:
            subgoal = self.prev_subgoal            # 刷新间隔内子目标恒定
        # 低层每步都重新前向：高频反馈压制跟踪误差的累积
        action = self.low_head(obs_feats, subgoal)
        return action, subgoal, refreshed

解读：（1）刷新由步号驱动，训练与推理的节奏一致，避免高层输出噪声引发子目标抖动。（2）子目标缓存 detach：刷新间隔内低层梯度不回流高层，两层优化解耦，梯度只经刷新步传递。（3）共享视觉编码器是成本关键：两层分别编码会使开销接近翻倍。

片段 2：世界模型的多时间跨度损失

import torch

def multiscale_world_loss(model, obs_seq, action_seq,
                          strides=(1, 4, 8), weights=(1.0, 0.5, 0.25),
                          beta=1.0):
    """多时间跨度预测损失：同一动力学函数接受不同间隔的监督。"""
    feats = model.encode(obs_seq)                 # T x B x D 隐状态序列
    loss = 0.0
    for stride, w in zip(strides, weights):
        # 只取能整除间隔的起点：对齐监督对，不做插值近似
        idx = torch.arange(0, feats.shape[0] - stride, stride,
                           device=feats.device)
        h0 = feats[idx]
        # 取起点至起点加 stride 的整段动作窗：长间隔预测需要中间动作信息
        win = idx[:, None] + torch.arange(stride, device=feats.device)
        a = action_seq[win]
        pred = model.dynamics(h0, a, steps=stride)
        target = feats[idx + stride].detach()     # 目标不产生梯度：纯监督信号
        # 大间隔项权重按 beta 统一缩放，便于整体与重建损失配平
        loss = loss + beta * w * ((pred - target) ** 2).mean()
    return loss

解读：（1）stride 采样让同一段序列被复用三次，样本效率远高于分别构造三份数据。（2）目标特征 detach：世界模型编码器自己不接受多尺度目标的梯度回流，避免误差从长间隔路径污染表征。（3）beta 是整体配平系数，与重建损失共享量级控制；单级权重在内部比例中保留。

片段 3：特征金字塔融合

import torch.nn as nn
import torch.nn.functional as F

class PyramidFusion(nn.Module):
    """空间多尺度融合：高层语义与低层细节对齐相加。"""
    def __init__(self, dim=256):
        super().__init__()
        # 横向 1x1 卷积统一通道：参数量小，不改变各层已有语义
        self.lateral = nn.ModuleList(
            [nn.Conv2d(c, dim, 1) for c in (64, 128, 256)])
        self.smooth = nn.Conv2d(dim, dim, 3, padding=1)

    def forward(self, c3, c4, c5):
        # 自顶向下：语义强的深特征上采样后与浅层细节逐元素相加
        p5 = self.lateral[2](c5)
        p4 = self.lateral[1](c4) + F.interpolate(p5, scale_factor=2,
                                                 mode="nearest")
        p3 = self.lateral[0](c3) + F.interpolate(p4, scale_factor=2,
                                                 mode="nearest")
        # 平滑卷积抑制最近邻上采样带来的棋盘伪影
        return self.smooth(p3)                     # B x dim x H x W

解读：（1）采用逐元素相加：通道数不变，后续头的参数量与单尺度时一致。（2）最近邻上采样计算便宜，棋盘伪影由平滑卷积抑制。（3）融合特征同时供高层头与低层头使用：高层取全局池化后的表示，低层保留空间维度做局部决策。

常见坑

  • 尺度错位：长间隔预测只给起点动作，缺失中间动作信息。修复：动力学按累计动作序列迭代，或把整段动作块编码为条件。
  • 低分辨率主导：长间隔、低分辨率项权重设置过大，细节预测长期欠拟合。症状为想象图像模糊、精细操作成功率低。修复：随训练阶段下调长尺度权重，或采用不确定性加权。
  • 时间下采样相位误差：下采样起点固定在一个相位上，其他相位的动力学从未被监督。修复：训练中随机化起点相位，或对多相位取平均损失。
  • 上采样伪影污染动力学：最近邻上采样的棋盘纹被世界模型学成真实结构，想象中出现周期性伪影。修复：上采样后用平滑卷积，或改用双线性插值并附加细节监督。
  • 刷新周期一刀切：接近与接触阶段共用同一 s，接触期子目标滞后。修复：按阶段调度 s，或让低层在刷新间隔内微调子目标。

    提示
    监督对数量约为 8、2、1。去掉 stride 8 后一步预测不变，但 8 步 rollout 的误差增长斜率显著变陡。
  2. 把片段 1 的 s 从 6 改为 1，预测训练曲线与推理时延的变化，并解释为什么此时分层结构名存实亡。★
    提示
    s = 1 时每步刷新，两层频率相同，子目标缓存失效；高层参数量照旧，推理时延上升，慢变结构的正则作用消失。
  3. 推导题：设短间隔项梯度方差为 σ12、长间隔项为 σ22 且 σ12 大于 σ22。说明定权重的期望梯度由哪一项主导，并给出使两项方差贡献相等的权重比。★★
    提示
    权重按方差倒数分配时贡献均衡，即 w1/w2 = σ22/σ12。定权重相当于固定了方差预算的倾斜方向。
  4. 实验设计：在插孔任务上比较三组配置，(a) 单速率、(b) 双速率固定 s = 6、(c) 双速率阶段调度 s（接近 6、接触 2）。报告成功率、接触期跟踪误差与推理时延。★★
    提示
    预期 (c) 最优：接触期高频刷新降低跟踪误差；(b) 接触期滞后；单速率无子目标接口，长程规划能力弱。
  5. 设计题：为金字塔融合设计“分辨率与监督强度匹配”的方案：不同分辨率的预测头监督什么量，权重如何随阶段变化，怎样验证低分辨率项没有吞掉细节梯度。★★★
    提示
    低分辨率头监督全局布局与粗运动，高分辨率头监督接触细节；监控各层梯度的范数占比，若低分辨率占比长期超过阈值即需调低其权重。

小结

  • 多尺度处理把快变与慢变结构拆分到不同层级，缓解主干上的梯度冲突。
  • 时间维度用双速率接口：高层低频输出子目标，低层高频跟踪，刷新周期 s 按子目标语义半衰期选择。
  • 世界模型用多时间跨度损失监督 1、4、8 步预测，长间隔项把 rollout 漂移暴露给训练目标。
  • 空间维度用特征金字塔融合全局与局部特征，权重分配是多尺度训练中偏差与方差的核心旋钮。
