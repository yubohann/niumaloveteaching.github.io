第 072 章：世界模型的模型预测控制

本章讲世界模型与模型预测控制（Model Predictive Control, MPC）的结合：用采样优化在隐空间求解有限时域问题，用终端价值近似长视野回报，用滚动重规划把开环想象变成闭环控制。

  • 主题：规划与控制 / 滚动时域优化
  • 关键公式：min E[ Σk c(sk, ak) + Vterm(sH) ]
  • 预计学时：55 分钟
  • 前置章节：第 071 章：VLA策略的强化学习调参

学习目标

  • 理解滚动时域（Receding Horizon）原理：每步只执行规划首段并立即重规划，闭环反馈如何抑制模型误差累积。
  • 掌握采样类优化器（CEM 与 MPPI）的流程：采样、评估、精英更新、方差控制的四步循环。
  • 理解终端代价（Terminal Cost）的作用：短视野加价值网络近似长视野回报，价值偏差如何改变规划行为。
  • 能实现 CEM 规划、批量序列评估与滚动控制循环，掌握动作块接口与重规划频率的设计。
  • 会诊断视野过长、分布塌缩与重规划冲突问题，能设计视野与模型误差的匹配实验。

背景与动机

本节说明模型预测控制针对的误差累积问题：开环想象一次性规划整条动作序列并全部执行，模型误差沿序列滚雪球，全局计划越到后段越不可靠。MPC 的思想是只在信任的短窗口内规划，执行后立刻用真实观测刷新状态重新规划。每一步的规划窗口短，模型误差可控；重规划频率高，闭环反馈把漂移压回目标轨迹。学习模型给出 MPC 所需的转移与代价，采样优化器回避了对不可微动力学求梯度的问题。本章围绕视野、优化器与价值近似三个设计点展开。

核心原理

1. 滚动时域与代价目标

MPC 每步求解有限时域优化问题：

mina1:H E[ Σk=1..H c(ŝk, ak) + Vterm(ŝH) ]，ŝk+1 = f̂(ŝk, ak) f̂ 为世界模型预测，c 为阶段代价，Vterm 为终端价值，H 为规划视野

求解后只执行首段动作，其余丢弃。“解全段、行首段”提供三层保护：误差局限于短窗口；新观测每步注入；优化失败仍有合法动作可用。滚动时域本质是用重规划的算力换取对模型误差的鲁棒性，重规划间隔是需要显式设计的关键参数。

2. 数值算例：重规划间隔对误差累积的抑制

设世界模型单步状态预测误差为 ε = 0.02（归一化状态空间下的偏差量级），每次重规划用真实观测刷新状态、把已累积偏差清零，重规划间隔为 r 步、规划视野为 H 步。三种执行方式的段内最大偏差近似为：

开环全执行：最大偏差 ≈ Hε = 10 × 0.02 = 0.2 重规划间隔 4：最大偏差 ≈ rε = 4 × 0.02 = 0.08 重规划间隔 1：最大偏差 ≈ ε = 0.02 假设误差在窗口内近似线性累积、重规划时被观测刷新截断

数值结果给出两条设计依据：（1）偏差上限与重规划间隔成正比，间隔从 10 步降到 4 步把偏差从 0.2 压到 0.08，继续降到 1 步只再压缩到 0.02，收益递减与规划开销的增长形成权衡点；（2）把 ε 实测出来是设置视野的前提：若任务偏差预算为 0.05，则间隔必须不超过 2 步，或先把模型误差训到 ε ≤ 0.0125 再放宽间隔。经验上先测 ε、再按 ε 定 r 与 H，顺序不能颠倒。

3. 采样优化：CEM 与 MPPI

学习模型的动力学对动作不可微或梯度噪声大时，采样优化是首选。交叉熵方法（Cross-Entropy Method, CEM）迭代三步：按当前高斯分布采样 N 条候选序列；批量展开并评估累计代价；取前 K 条精英更新分布均值与标准差。MPPI（Model Predictive Path Integral）理论上是软加权版本：用 exp(−回报/温度) 作为权重对全部候选加权平均，等价于对低代价样本的指数倾斜。CEM 精英化收敛快但方差易过早塌缩；MPPI 保留全部样本信息，更平滑。四类优化器的特性对照如下：

优化器分布更新规则样本利用率收敛速度主要风险或限制
随机射击基线不更新，取最优样本最低，仅用一条单轮即止精度受候选数对数限制
CEM精英集的均值与标准差只用精英快，两到四轮收敛方差过早塌缩
MPPI全部样本的软加权平均全部样本平稳，需更多轮温度标定依赖回报尺度
可微 MPC 梯度法沿解析梯度下降局部梯度依赖模型可微性梯度噪声与局部极值

选择依据：廉价基线先用随机射击确定候选规模下界；常规场景用 CEM；代价函数噪声大或希望规划平滑时用 MPPI；动力学生成器可微且梯度稳定时可用梯度法细化 CEM 的结果。标准差下限是采样类优化器的共同保险丝：分布塌缩到单点后，优化器失去再探索能力。

4. 终端代价：把无限视野装进有限窗口

有限视野的贪心规划具有短视性：视野末端之外不再计分，动作序列会把代价推向窗口外。终端价值 Vterm 估计“从末端状态出发还能拿多少回报”，把无限视野截断为 H 步加一次价值查询。终端价值可以来自价值网络、启发式距离或学习到的回报预测器。终端价值的偏差会直接塑形规划行为：低估末端价值导致保守停滞，高估导致贸然深入危险区域。实践校准方式是固定策略回放：比较不同 Vterm 下规划选择与真实回报的秩相关，相关过低说明价值头与规划目标不一致。

5. 规划、策略与计算预算的接口

VLA 策略在 MPC 架构中承担两种角色之一：作为候选生成器，策略输出的动作块参数化采样分布的中心，规划只做局部搜索；或作为终端策略，价值由策略在校正回报上评估。预算分配上，单步规划开销约等于 N × H 次世界模型前向，N = 64、H = 10 时是 640 次前向，需要与推理帧率共同核算。视野的选择要与模型单步误差匹配：经验规则：视野内累计预测误差不超过任务偏差预算，模型越准视野越长。

实现思路与设计

本节给出集成方案：世界模型提供隐状态编码与单步预测；CEM 规划器在动作块空间搜索；终端价值网络以隐状态为输入；VLA 策略作为采样先验，其输出均值作为 CEM 初始分布中心，把学习到的行为先验注入搜索。控制循环每 4 步重规划一次，期间执行计划队列。与第 071 章的差异：第 071 章调整策略优化的超参数，本章改变策略的执行方式，从“直接输出动作”变为“输出先验加闭环搜索”。

规划视野 H10优化窗口长度与单步模型误差和任务偏差预算匹配
候选数 N64搜索覆盖度评估开销与方差折中，GPU 批量展开

设计决策：为什么仅把策略当作采样先验

纯采样的 CEM 在平坦代价区域浪费时间，纯策略的输出缺少局部修正能力。策略先验加局部搜索的组合让两者互补：策略把采样中心放在高回报区域附近，CEM 只需在其邻域做精细搜索，候选数与迭代轮数都可以减半。先验质量决定搜索预算的性价比，策略与世界模型联合训练的收益在 MPC 架构中被直接变现。

预算分配与计算开销核算

  • 前向次数的核算口径。单次规划的世界模型前向次数为 N × H × 迭代轮数；N = 64、H = 10、3 轮对应 1920 次前向，按每 4 步重规划摊销后每控制步约 480 次。实时预算紧张时优先降 N，代价函数的评估方差随 N 的平方根下降，N 从 64 降到 32 只损失约 30% 的估计精度。
  • 迭代轮数的边际收益。两轮之后精英集的均值变化通常已进入代价函数噪声量级，第三轮之后的收益主要来自方差收缩；预算有限时固定两轮并把差额加到候选数上。
  • 规划频率的自适应。平坦区域（代价梯度小）可拉长重规划间隔，接触密集区缩到 1 步；间隔由代价函数的局部敏感度指标触发切换，切换点做滞回避免抖动。
  • 隐状态复用。候选展开只从当前隐状态分叉一次，后续步共享批量展开；起步编码与终端价值查询各只需一次前向，相对展开开销可以忽略。
  • 提前终止。展开过程中若候选的累计代价已超过当前精英集最差值的下界，该候选可提前截断；大批候选下这一剪枝能省 20% 以上的前向量。

关键代码与解读

以下片段以采样规划与滚动控制的公开实现为参照，接口随版本演进。三个片段分别覆盖 CEM 优化、批量序列评估与控制循环。

片段 1：CEM 规划器

import torch

def cem_plan(world_model, value_fn, h0, cost_fn,
             n_samples=64, n_elite=8, iters=3,
             horizon=10, action_dim=7, sigma_init=0.5, proposal=None):
    """交叉熵方法：采样动作序列，精英集迭代更新分布。"""
    # 策略先验作为分布中心：proposal 为 VLA 输出的动作块均值
    mu = proposal.clone() if proposal is not None else torch.zeros(horizon, action_dim)
    sigma = torch.ones(horizon, action_dim) * sigma_init
    for _ in range(iters):
        noise = torch.randn(n_samples, horizon, action_dim) * sigma
        cand = (mu + noise).clamp(-1.0, 1.0)       # 归一化动作空间的合法范围
        ret = evaluate_sequences(world_model, value_fn, h0, cand, cost_fn)
        elite = cand[ret.topk(n_elite).indices]    # 按回报取精英集
        mu = elite.mean(dim=0)
        # 标准差带下限：塌缩到单点后优化器将无法再探索
        sigma = elite.std(dim=0).clamp_min(0.05)
    return mu                                        # 返回均值序列供执行

解读：（1）proposal 参数让策略先验可插拔，未提供时退化为标准 CEM。（2）候选序列裁剪到动作合法区间，避免评估不可执行的动作浪费预算。（3）返回均值：均值的方差比精英单条更低，执行更平滑；需要保留多样性时可在首个动作上加小噪声。

片段 2：批量序列评估与终端价值

@torch.no_grad()
def evaluate_sequences(world_model, value_fn, h0, cand, cost_fn):
    """批量展开候选序列：返回回报（负累计代价加终端价值）。"""
    n, H, _ = cand.shape
    h = h0.expand(n, -1).clone()         # 起点广播到全部候选
    total = torch.zeros(n, device=h.device)
    for k in range(H):
        # 世界模型单步推演：全部候选并行共享一次前向
        h = world_model.step(h, cand[:, k])
        total = total - cost_fn(h)       # 阶段代价取负累加为回报
    # 终端价值：近似视野之外剩余的回报，缺省时规划会短视
    total = total + value_fn(h)
    return total.detach()

解读：（1）expand 后 clone：n 条候选共享起点张量的存储，展开时按需复制，显存可控。（2）no_grad 包裹：评估路径不建图，预算全部用于前向。（3）终端价值与阶段回报的单位必须一致，否则视野末端会被人为放大或压低。

片段 3：滚动控制循环

def mpc_control_loop(world_model, value_fn, policy, env,
                     steps=200, horizon=10, replan_every=4):
    """滚动时域控制：周期重规划 + 队列执行 + 观测刷新。"""
    obs = env.reset()
    h = world_model.encode(obs)
    queue = []
    for t in range(steps):
        if not queue:                     # 队列为空时重规划
            proposal = policy.act_chunk(h)          # 策略先验动作块
            plan = cem_plan(world_model, value_fn, h, env.cost,
                            proposal=proposal, horizon=horizon)
            queue = [a for a in plan[:replan_every]]   # 深拷贝计划首段为执行队列
        a = queue.pop(0)                  # 执行队列首个动作
        obs, done = env.step(a)
        h = world_model.encode(obs)      # 真实观测刷新：闭环修正漂移
        if done:
            break
    return t

解读：（1）队列机制把“重规划间隔”与“规划视野”解耦：视野 10 步而只执行 4 步即触发重规划。（2）每步用真实观测重新编码隐状态，模型漂移不会跨段累积。（3）队列在阻塞或安全事件时可整体清空，实现“立即重规划”的降级路径。

常见坑

  • 视野超过模型可信范围：长视野评估的回报主要由模型误差决定，规划偏爱误差恰好有利的方向。修复：缩短视野并用终端价值补足回报，或按逐位置预测误差给惩罚加权。
  • CEM 分布过早塌缩：标准差下限缺失或精英过少，首轮采样后分布即收缩到单点。修复：设置标准差下限、适度增加精英数、保留策略先验的多样性扰动。
  • 终端价值缺失或偏差大：规划在视野末端前刹车或冲过头。修复：校准价值头，或临时用启发式距离函数作终端代价并观察行为变化。
  • 重规划频率与执行频率冲突：重规划开销超出控制周期，动作队列耗尽出现停顿。修复：按推理预算选择间隔，必要时降低候选数或使用更小的世界模型推理配置。
  • 候选动作越界：采样动作超出关节或位姿限制，评估得分虚高但不可执行。修复：在评估前统一投影到合法区间，并把合法性检查纳入代价函数。

练习与思考

  1. 计算题：N = 64、H = 10、迭代 3 轮，计算单次规划的世界模型前向次数，并说明它与策略单次前向的数量级差；按每 4 步重规划一次，计算平均每控制步的前向次数。★
    提示
    64 × 10 × 3 = 1920 次前向，与策略单次前向相差两到三个数量级；分摊到 4 步执行，平均每控制步约 480 次前向。说明需要批量展开与模型压缩才能满足实时预算。
  2. 把片段 1 的精英数 K 从 8 改为 2，预测优化精度、方差与规划行为的稳定性。★
    提示
    K 过小使分布更新噪声大、易塌缩到偶然高回报样本；三到四轮后分布方差可能归零，规划退化为单次采样。
  3. 推导题：说明 MPPI 的软加权平均与 CEM 的精英截断在极限情形下的关系（温度趋近 0 与精英数趋近 1 各自对应什么）。★★
    提示
    温度趋近 0 时权重集中到最优样本，与精英数趋近 1 一致；温度增大则权重平坦，规划向全体候选的均值过渡。
  4. 实验设计：固定候选数与迭代轮数，在视野 H ∈ {5, 10, 15, 20} 下比较任务成功率与末端回报估计误差，确定模型误差开始主导规划收益的视野阈值。★★
    提示
    成功率通常随 H 先升后降；末端误差随 H 单调上升，两条曲线交叉点即视野阈值，与单步误差量级共同决定。
  5. 设计题：为安全关键任务设计渐进降级方案：规划超时、模型置信度骤降、执行器异常三个事件下队列如何处置，怎样保证降级过程动作连续可执行。★★★
    提示
    超时保留旧队列继续执行；置信度骤降触发提前重规划并收缩动作幅度；执行器异常清空队列切换安全停止轨迹；三类事件统一为“队列动作替换”接口。

小结

  • MPC 用滚动时域把开环想象变成闭环控制：解全段、行首段、常重规划，模型误差被限制在短窗口内。
  • CEM 与 MPPI 是两类采样优化器：精英截断收敛快，软加权更平滑；标准差下限防止分布塌缩。
  • 终端价值把无限回报截断为有限视野加一次查询，其偏差直接塑形规划行为，需要独立校准。
  • 规划开销为 N × H 乘世界模型前向，视野选择与单步模型误差、任务偏差预算共同决定。
