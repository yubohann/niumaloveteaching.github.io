第 097 章：联合训练中的强化学习探索

稀疏奖励下如何主动发现新状态：随机网络蒸馏、集成分歧与潜空间伪计数的内在奖励设计，以及探索强度的退火与示范锚定。

  • 主题：联合训练（joint training）/ 强化学习探索（exploration）
  • 关键公式：随机网络蒸馏的预测误差奖励与内在奖励退火
  • 预计学时：50 分钟
  • 前置章节：第 096 章

学习目标

  • 理解稀疏奖励场景的探索困难，区分状态覆盖不足与局部最优两类失败模式。
  • 掌握随机网络蒸馏（Random Network Distillation, RND）的内在奖励机制，理解其与计数式探索的联系及局限。
  • 掌握在潜空间计算新颖度的三条原则：避开像素噪声、集成估计分歧、按训练进度退火强度。
  • 会设计示范锚定损失，防止探索策略偏离演示分布过远造成安全风险与技能退化。
  • 能诊断噪声电视问题、奖励循环与内在奖励量级失控三类探索故障。

背景与动机

稀疏奖励下，策略在发现第一个成功之前收不到任何有效梯度，探索机制负责把"发现"变成可以主动发生的行为。演示数据覆盖的场景有限，任务边界处的意外状态（滑落、卡住、碰撞）必须靠自主试验才能学到处理方式。联合训练提供了独特条件：世界模型可以在想象中低成本地检验上百个动作分支，探索不必全部消耗在真实交互上，但想象探索受模型覆盖限制，仍然需要真实世界的探索来扩展模型知识。

第 015 章介绍了探索策略的基本概念，第 091 章的 Dyna 循环涉及想象数据生成。本章聚焦探索信号的构造与调度：新颖度如何度量、如何在潜空间稳健估计、如何随训练退火，以及如何与示范数据平衡。这些设计决定策略能否跨越稀疏区与训练后期的稳定性。

核心原理

探索的本质是给状态附上"新颖度"标记，并把新颖度转化为奖励信号；难点在于新颖度的度量要抗噪、可退火、不失控。

1. 内在奖励的构造路线

  • 计数式：统计状态访问次数 N(s)，奖励与 1/N(s) 相关。概念直接、理论清晰；高维状态下无法直接计数，需要离散化或密度估计近似。
  • 预测误差式：用可学习的预测器对状态打分，预测误差大表示模型没见过。随机网络蒸馏（RND）是这条路线中最稳健的实现：固定随机权重的目标网络给出稳定标签，预测网络跟踪目标的难度即新颖度。
  • 分歧式：多个动力学模型或价值头对同一状态预测不一致，分歧大表示训练覆盖不足。计算简单、语义直观，适合与联合训练已有的集成结构复用。

2. RND 的机制与局限

RND 的奖励形式为：

rint(s) = ‖ fθ(s) − f̄(s) ‖2 f̄ 为固定随机初始化的目标网络，fθ 为可训练预测网络

训练中预测网络逐渐学会目标网络的映射，频繁访问的状态误差下降，新颖状态误差保持高位，形成"探索过的变不新、没见过的才新鲜"的动态。其局限是随机性敏感：目标映射对状态中的随机成分同样产生误差，若状态包含视觉噪声、光照抖动等不可控变量，智能体会追着噪声跑，即噪声电视问题（noisy-TV problem）。联合训练中的对策明确：把 RND 输入从像素改为世界模型潜状态，潜状态经训练已压缩掉大部分不可控细节；再加集成多条 RND 链取最小误差，降低单链偶然高分的影响。

3. 退火与量级控制

内在奖励是辅助工具，长期保持强探索会干扰任务学习。总奖励为外在与内在的加权和：

rtotal = rext + λ(step) · rint，λ 从 1.0 按训练预算线性降到 0.1 λ 的退火按训练步数执行；可按任务成功率触发的条件退火替代

量级控制同样重要：不同状态的 RND 误差量级差异大，直接用会让奖励方差爆炸。标准做法是用回报的运行标准差归一化（与第 082 章的奖励归一化同源），把内在奖励压到与任务奖励同量级。退火过早会让稀疏区未被充分探索，过晚则策略长期沉迷新奇状态，两种失误都能从"任务成功率与状态覆盖率两条曲线"的组合中读出。

4. 想象探索与示范锚定

联合训练允许把探索搬进世界模型的想象：给想象 rollout 中的状态计算分歧奖励，智能体在虚拟分支中尝试高风险行为，不消耗真实交互。想象探索的效果受模型覆盖限制，模型未知区域无法提供可靠的想象分支，因此需要保留固定比例的真实探索（例如每十个批次一个）。

探索的边界由两个约束界定：安全约束（禁止进入碰撞区域等）与示范锚定。示范锚定用散度约束策略分布不要偏离演示行为分布过远：

Lanchor = β · KL( πθ(·|s) ‖ πdemo(·|s) ) β 控制偏离代价；演示分布由行为克隆模型近似

锚定的作用是双重的：限制探索风险范围，同时防止策略在探索中发现"刷分"捷径而放弃演示中的标准技能。β 不设过大，否则探索自由度被压缩到演示邻域内，无法发现新策略；经验取值为让锚定项与任务损失量级相当。

实现思路与设计

探索系统由三块组成：潜空间 RND 提供新颖度、集成分歧提供不确定度、调度器负责退火与归一化。想象探索与真实探索按固定比例混合。

  1. RND 输入：世界模型潜状态（512 维），输出 256 维；目标网络每 5e4 步重新随机初始化一次，防止预测网络完全追平后奖励退化。
  2. 分歧奖励：世界模型集成 5 个成员的预测标准差，经归一化后与 RND 奖励相加，权重各 0.5。
  3. 退火：λ 按训练步数从 1.0 线性降到 0.1；任务成功率连续两个评估周期超过目标后额外加快衰减。
  4. 真实探索配额：每 10 个训练批次保留 1 个批次的数据来自带探索噪声的真实交互。
  5. 与第 015 章的差异：探索信号从动作空间噪声升级为潜空间新颖度与分歧的合成，新增退火条件与示范锚定。

设计决策：为什么 RND 目标网络要周期性重置？

预测网络持续训练会逐步拟合目标映射，全部已见状态的新颖度趋近于零，探索动力衰减。重置目标网络相当于重设新颖度参照系，再次拉开预测误差的动态范围。重置频率要在两个失效间平衡：过慢探索停滞，过快所有状态都显得新，奖励退化为常数偏置；5e4 步是与策略训练收敛节奏匹配的经验值。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：潜空间 RND 模块

class LatentRND(nn.Module):
    """潜空间随机网络蒸馏：目标固定、预测可训，误差即新颖度。"""
    def __init__(self, d_in=512, d_out=256):
        super().__init__()
        self.target = nn.Sequential(nn.Linear(d_in, d_out), nn.ReLU(),
                                    nn.Linear(d_out, d_out))
        self.predictor = nn.Sequential(nn.Linear(d_in, d_out), nn.ReLU(),
                                       nn.Linear(d_out, d_out))
        for p in self.target.parameters():
            p.requires_grad_(False)          # 目标固定：新颖度参照系稳定

    @torch.no_grad()
    def bonus(self, z):
        # 预测误差作为奖励：依据来源为固定映射的拟合难度
        t = self.target(z)
        p = self.predictor(z)
        return (p - t).square().mean(dim=-1)

    def reset_target(self):
        """周期重置：重新随机化目标映射，恢复新颖度区分度。"""
        for layer in self.target:
            if isinstance(layer, nn.Linear):
                nn.init.orthogonal_(layer.weight)
                nn.init.zeros_(layer.bias)

解读：输入取世界模型潜状态，像素中的不可控细节在潜空间已被压缩，噪声电视问题被结构性抑制。bonus 加 no_grad，奖励计算不进入梯度路径，预测网络只通过独立损失训练。reset_target 用正交初始化重置权重，保持输出尺度稳定。工程上还可对多条 RND 链取最小误差，进一步压噪声：真新颖在绝大多数链上都高，噪声只在个别链上碰巧高。

片段 2：内在奖励归一化与退火

def intrinsic_coeff(step, total_steps, start=1.0, end=0.1):
    """退火系数：按训练步数线性下降，终值保留少量探索余量。"""
    frac = min(1.0, step / total_steps)
    return start + (end - start) * frac

class RunningStd:
    """运行标准差估计：把内在奖励压到与任务奖励同量级。"""
    def __init__(self, beta=0.99):
        self.std, self.beta = 1.0, beta
    def update(self, x):
        # 用批次标准差做 EMA：量级统计不需精确，稳定即可
        self.std = self.beta * self.std + (1.0 - self.beta) * x.std().item()
    def scale(self, x):
        return x / (self.std + 1e-8)

解读：退火的线性形式简单可控，条件加速作为可选分支。RunningStd 用批次标准差做统计，噪声小于单样本估计；初值 1.0 表示未标定阶段不做缩放，随数据逐渐收敛到真实量级。归一化与退火的先后顺序为：先按运行标准差缩放、再乘 λ，保证 λ 的语义是"相对强度"这一比例量，与奖励绝对数值无关。日志记录 λ 调度轨迹与缩放后奖励均值，用于发现量级异常。

片段 3：示范锚定与想象分歧奖励

def demo_anchor_loss(policy_logits, demo_logits, beta=0.1):
    """示范锚定：KL 约束防止探索策略偏离演示分布过远。"""
    logp = F.log_softmax(policy_logits, dim=-1)
    q = F.softmax(demo_logits, dim=-1)       # 演示分布由行为克隆模型给出
    return beta * F.kl_div(logp, q, reduction="batchmean")

def imagination_bonus(world_model, z):
    """想象探索奖励：集成分歧作为不确定度，指导虚拟分支选择。"""
    preds = torch.stack([m.predict_mean(z) for m in world_model.ensemble])  # (E, B, d)
    # 分歧越大说明模型未覆盖，优先探索；用均值抗单链异常，最大偏差易被个别链拉高
    return preds.std(dim=0).mean(dim=-1)

解读：锚定损失用 kl_div 的 batchmean 归约，梯度尺度与批次对齐；beta 取 0.1 表示锚定是软约束。imagination_bonus 对集成分歧取标准差均值，多链结构本身提供的抗噪性优于单模型。想象分歧与 RND 的差异在信息源：分歧反映模型覆盖，RND 反映潜空间新颖度；两者交集高的状态最值得真实探索。执行侧仍需安全过滤器把探索动作限制在允许范围内，安全检查不参与训练损失。

常见坑

  • 噪声电视问题：内在奖励被不可控随机源吸引，策略追着噪声打转。症状是探索奖励高但状态覆盖率不升。修复：RND 输入改潜状态、多链取最小、按不可控变量做数据增强再算奖励。
  • 奖励循环：策略学会反复触发高分新奇事件（来回穿越边界）刷内在奖励。症状是同一轨迹反复出现在日志中。修复：内在奖励按折扣累计、避免逐步重复计算，对已访问状态的重复触发降权。
  • 量级失控：内在奖励未归一化，数值远超任务奖励，任务学习被淹没。症状是任务损失与探索奖励曲线脱节。修复：运行标准差归一化、λ 上界约束、分别记录两类奖励的均值方差。
  • 退火失当：过早退火使稀疏区未探完，过晚使后期抖动。症状分别是成功率曲线早期停滞与后期波动。修复：用成功率触发的条件退火替代纯步数调度，并保留 0.1 的终值。
  • 探索安全越界：探索动作触发热故障（碰撞、越界）。症状是探索期故障检测频繁报警。修复：安全过滤器前置、锚定权重提高，危险区域优先在想象中探索，真实执行只在安全范围内进行。

练习与思考

  1. 说明 RND 与计数式探索的联系：为什么随机映射下的预测误差近似访问计数的倒数关系？★★
    提示
    高频访问状态的映射被充分拟合，误差下降；低频状态误差保持，行为与 1/N(s) 的反比关系一致。
  2. 把退火终值从 0.1 改为 0.0，预测训练后期与评估期的行为差异。★
    提示
    后期完全退化为任务奖励优化，探索停止；遇环境变化时复原能力下降，评估期可能陷入局部最优。
  3. 构造噪声电视测试：给出一个含随机屏幕闪变的场景描述，说明如何验证内在奖励对噪声的敏感性。★★
    提示
    比较像素输入与潜状态输入下的奖励分布；若像素版奖励集中在噪声区域，问题复现。
  4. 设计探索效果评估：指标覆盖状态覆盖率、发现的任务数、任务成功率，说明各指标的数据来源与统计口径。★★
    提示
    覆盖率用潜空间聚类簇计数；发现数用成功事件日志；成功率用固定评测协议，三者定期快照。
  5. 设计探索与安全的平衡实验：在含危险区的任务中对比三种锚定强度下的事故率与探索收益，给出结论模板。★★★
    提示
    危险区固定注入，事故率用越界次数；收益用新技能解锁数；预期强锚定事故低、收益略低。

小结

  • 探索机制把新颖度转化为奖励：计数式、预测误差式（RND）与分歧式三条路线互补。
  • RND 在潜空间计算天然抗噪，多链取最小进一步抑制噪声电视问题；目标网络周期重置维持区分度。
  • 内在奖励按运行标准差归一化再乘退火系数 λ，量级与任务奖励可比；退火可用成功率条件触发。
  • 想象探索低成本但受模型覆盖限制，保留固定比例的真实探索；示范锚定约束探索范围与技能漂移。
