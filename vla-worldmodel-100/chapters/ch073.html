第四篇 · 训练机制与应用集成

第 073 章：联合训练中的稀疏奖励处理

本章讲稀疏奖励（Sparse Reward）下的信用分配（Credit Assignment）：用事后经验回放把失败轨迹变为正样本，用势函数塑形在不改变最优解的前提下提供稠密信号，用世界模型生成可达子目标控制探索方向。

  • 主题：强化学习 / 信用分配与奖励设计
  • 关键公式：F(s, a, s′) = γΦ(s′) − Φ(s)，R = Rext + β · Rint
  • 预计学时：55 分钟
  • 前置章节：第 072 章：世界模型的模型预测控制

学习目标

  • 理解稀疏奖励下信用分配的两难：成功前梯度信号接近零，价值传播与探索同时受阻。
  • 掌握事后经验回放（Hindsight Experience Replay, HER）的机制与目标分布偏差，能实现未来目标重标记。
  • 掌握势函数奖励塑形（Potential-Based Reward Shaping）的定理与推导直觉，能区分保序塑形与破坏最优性的塑形。
  • 能实现随机网络蒸馏式内在奖励与子目标生成，理解奖励组合中退火的作用。
  • 会诊断非势塑形、重标记偏差与内在奖励主导问题，能设计塑形有效性对照实验。

背景与动机

本节说明稀疏奖励处理针对的学习困难：长程操作任务的奖励只在成功瞬间出现，前置状态的回报几乎全为零。价值网络缺少回溯信号，策略梯度在成功前近似无效；同时探索需要足够长的正样本链条才能把信用传回起点。两类干预对应两个方向：改变数据分布，让失败轨迹也能产生监督信号；改变奖励结构，在训练期提供稠密引导。世界模型提供第三种资源：生成可达子目标，把长程任务分解为短程阶段，让外部奖励在阶段层面变密。

核心原理

1. 事后经验回放：把失败翻译成成功

HER 的核心是目标重标记：回合结束后，把实际达成的状态 φ(sT) 当作“如果当初的目标是它”的新目标，重算整个回合的奖励。同一个失败回合对某些子目标而言是完整成功的正样本：

g′ = φ(sfut)，r′t = 1[ ‖φ(st+1) − g′‖ ≤ δ ] φ 为状态到目标空间的映射，δ 为达成阈值；future 策略从 t 之后的时刻取样

重标记使每个回合贡献多个正样本，信用分配从“等待偶然成功”变为“在已达成目标上学习”。目标分布偏差是代价：重标记目标集中在可达集合，策略对不可达或罕见目标的估计不足。缓解方式有二：保留一部分原始目标样本，让目标分布覆盖测试分布；δ 过大会把远未达成的状态判成成功，注水目标污染价值函数。

2. 势函数塑形：不改变解的改变

势函数塑形在奖励中加入势函数差：

F(s, s′) = γΦ(s′) − Φ(s)，R′(s, a, s′) = R(s, a, s′) + F(s, s′) 定理：加入任意势函数差项不改变最优策略集合与最优价值差

推导直觉是望远镜求和：中间项两两抵消，总塑形回报只依赖首末势，轨迹排序与最优动作不变。实现要点是与终止处理保持一致：终止状态应满足 Φ = 0，否则终止时引入常值偏差，等价于改变了任务目标。Φ 可取“负的到目标距离”等启发式。

3. 数值算例：望远镜求和的逐项验证

取 γ = 0.5、长度 4 的一条轨迹，势序列 Φ = [1.0, 0.5, 0.4, 0.0]（末步势为零）。逐项计算塑形奖励 Ft = γΦ(st+1) − Φ(st)：F0 = 0.5 × 0.5 − 1.0 = −0.75；F1 = 0.5 × 0.4 − 0.5 = −0.3；F2 = 0.5 × 0 − 0.4 = −0.4。按折扣求和：−0.75 + 0.5 × (−0.3) + 0.25 × (−0.4) = −1.0。用公式直接计算：γ3Φ(s3) − Φ(s0) = 0 − 1.0 = −1.0，两者一致。

Σt γtFt = γT−1Φ(sT−1) − Φ(s0) 逐项展开后相邻项的 γ 幂次两两抵消，只剩首末势

再取一条“绕路”轨迹，势序列为 [0.1, 0.9, 0.2, 0.0]：中间先升后降。逐项塑形为 F0 = 0.35、F1 = −0.8、F2 = −0.2，折扣求和 = 0.35 − 0.4 − 0.05 = −0.1，同样等于首末势之差 0 − 0.1。两条轨迹的塑形总量只由起点与终点决定，与中间路径无关。数值验证给出两条实践含义：势函数取“负距离”时，走向目标的正向增量在早期提供引导，接近行动的塑形量自动衰减；轨迹中途的势波动无论多剧烈，都不会在总回报中留下痕迹，因此势函数只需关注端点定义的正确性。

4. 内在奖励：把新颖性变成信号

内在奖励（Intrinsic Reward）度量“这个状态有多少信息增量”。随机网络蒸馏（Random Network Distillation, RND）用固定随机网络与可训练预测器的输出误差作为新颖度：误差大表示该状态从未被拟合过，即未见。预测器持续训练使误差衰减，新颖度自然消退。内在奖励的交易是探索与利用的再分配：系数 β 过大时策略为拿新颖度奖励而回避任务，表现为原地绕圈；总奖励按 R = Rext + β(t)Rint 组合并让 β 随时间退火，把探索预算逐步收回。稀疏奖励处理的四类手段在机制与代价上的对照如下：

手段作用位置是否改变最优策略主要收益主要代价诊断指标
事后重标记 HER数据分布不改变目标，但重标记目标分布偏移正样本密度从零变为成批对罕见目标估计不足原始与重标记目标的分目标成功率
势函数塑形奖励重参数化不改变（定理保证）成功前的稠密引导梯度依赖势函数设计质量轨迹排序一致性与终点势归零
内在奖励 RND奖励目标本身改变，需要退火回收逃离局部最优的探索动力与任务奖励竞争注意力内外奖励量级比与动作多样性
世界模型子目标任务结构分解间接改变训练难度分布长程任务分解为短程阶段子目标可达性估计误差阶段成功率与目标池覆盖

组合方式按任务诊断决定：正样本不足时先加 HER 与子目标分解，梯度稀疏时加塑形，探索停滞时加内在奖励。四者的作用层面互不重叠，可以同时启用，但每新增一项都要有对应的诊断指标，避免信号叠加后无法归因。凡是改变最优策略的信号（内在奖励与子目标难度）必须设计回收或退火机制，凡是仅重参数化的信号（塑形）无需回收。

5. 世界模型生成子目标

世界模型把“生成可达子目标”变成可计算问题：从回放缓冲区采样曾经达成的状态作为候选目标，按当前策略下的可达性打分（用世界模型展开估测成功概率）；或从目标反向展开取倒数若干步状态作阶段目标。子目标序列把长程任务拆成短程问题，每段都有阶段奖励。设计纪律是可达性优先：目标按成功率窗口（约 0.3 至 0.7）筛选，过难无信号，过易无信息。

实现思路与设计

本节给出组合方案：回放缓冲区同时保存原始目标与重标记目标样本，比例各半；奖励组合为外部奖励加势函数塑形再加退火内在奖励；世界模型每周评估一次候选子目标池的可达性，为课程难度提供依据。VLA 策略按目标条件接口消费子目标（目标作为动作头附加输入）。与第 072 章的差异：第 072 章优化给定代价下的动作序列，本章改造奖励与目标信号本身。

设计决策：为什么塑形系数可以取 1 而内在奖励必须退火

势函数塑形有理论保证：改变的是学习速度，与最优解无关，因此强度可以直接取自然尺度。内在奖励把“新颖”注入目标，最优解随系数移动，长期高系数会把策略引向探索本身。重参数化与目标修改的区别决定了调节方式。凡是改变最优策略的信号，都必须设计回收机制。

HER 与退火曲线的实现要点

  • 未来采样策略的选择。future 策略从 t 之后均匀取样，覆盖面广；final 策略只用回合终点，样本更接近“真实成功”；episode 策略允许取任意时刻，覆盖最广但包含不可达目标。默认用 future，若评估显示远端目标成功率低则混入 final 样本。
  • 达成阈值的标定。δ 先从任务允差的物理量出发（如位置 5 毫米），再叠加测量噪声的 3 倍标准差；两项分开记录，便于日后归因。
  • 重标记样本的批次配比。批次内保留约一半原始目标样本，若训练中策略在原始目标上的成功率持续低于重标记目标，说明原始目标难度过高或 δ 与任务允差不匹配，先检查这两项再调网络。
  • 退火曲线的形状。内在奖励系数按训练进度线性或余弦退火到下限；阶跃切换会让策略行为突变，价值函数需要重新适应。下限保留少量探索预算，便于后期逃离局部最优。
  • 子目标池的刷新节奏。候选池按周期间隔重估可达性，间隔过短会引入评估噪声，过长会让课程跟不上策略能力；用策略成功率的漂移速度决定间隔，成功率快速上升期缩短间隔。

关键代码与解读

以下片段以事后回放与势函数塑形的公开实现为参照，接口随版本演进。三个片段分别覆盖重标记采样、塑形奖励与内在奖励。

片段 1：未来目标重标记

import torch

def her_relabel(states, achieved, actions, k_future=4, delta=0.05):
    """把未来达成状态当作新目标，重新判定每一步奖励。"""
    T = states.shape[0]
    samples = []
    for t in range(T - 1):
        for _ in range(k_future):
            # 未来采样：目标必须来自 t 之后，hindsight 才成立
            fut = torch.randint(t + 1, T, (1,)).item()
            goal = achieved[fut]
            # 达成判定：下一步状态到新目标距离是否在阈值内
            reached = (achieved[t + 1] - goal).norm() <= delta
            reward = float(reached)
            samples.append((states[t], actions[t], goal, reward, states[t + 1]))
    return samples

解读：（1）未来采样从 t + 1 起，避免“用过去状态当目标”造成的不可达重标记。（2）达成判定用目标空间距离，δ 与任务允差绑定，是重标记质量的旋钮。（3）返回的样本结构与原回放格式一致，采样器无需感知重标记来源。

片段 2：势函数塑形与组合奖励

import torch

def shaped_reward(r_ext, phi, gamma=0.99):
    """势函数塑形：F = gamma * Phi(s') - Phi(s)，保序不保值。"""
    phi_next = phi[1:]                         # 轨迹上的势序列
    phi_cur = phi[:-1]
    F = gamma * phi_next - phi_cur
    # 塑形只是重参数化：轨迹排序不变，最优策略不变
    return r_ext + F

def potential_from_distance(goal, states):
    """距离型势函数：越接近目标势越高，终止处自然归零。"""
    dist = (states - goal).norm(dim=-1)
    # Phi = -dist 满足“终点为零”的常用约定：到达时距离为零
    return -dist

解读：（1）势塑形项逐帧计算，总回报只依赖首末势，中间抵消是定理成立的关键。（2）距离型势函数天然满足到达时归零的约定，实现简单、覆盖多数到达类任务。（3）若势函数为学习所得，需保证其平滑性：势的剧烈波动等价于向奖励注入噪声。

片段 3：RND 内在奖励与退火组合

import torch.nn as nn

class RND(nn.Module):
    """随机网络蒸馏：预测误差度量新颖度，随拟合衰减。"""
    def __init__(self, in_dim=128, hidden=256, out_dim=64):
        super().__init__()
        # 目标网络固定随机权重：作为稳定的“新颖度参照”
        self.target = nn.Sequential(nn.Linear(in_dim, hidden), nn.SiLU(),
                                    nn.Linear(hidden, out_dim))
        for p in self.target.parameters():
            p.requires_grad = False
        self.predictor = nn.Sequential(nn.Linear(in_dim, hidden), nn.SiLU(),
                                       nn.Linear(hidden, out_dim))

    def forward(self, feat, beta=0.1):
        with torch.no_grad():
            tgt = self.target(feat)
        prd = self.predictor(feat)
        # 预测误差即新颖度：见过的状态误差被训练压低，自然消退
        return beta * ((prd - tgt) ** 2).mean(dim=-1, keepdim=True)

def combine_rl_reward(r_ext, r_shape, r_int, progress):
    """总奖励组合：内在奖励按训练进度线性退火。"""
    # 进度 0 到 1 映射退火系数 1 到 0.2，保留少量持续探索
    beta = 1.0 - 0.8 * progress
    return r_ext + r_shape + beta * r_int

解读：（1）目标网络冻结使误差变化只来自预测器拟合，度量口径稳定。（2）误差随访问次数下降，等价于自动的探索衰减，无需手工维护计数表。（3）退火保留下限而不归零：完全移除内在奖励后策略在局部最优附近失去逃逸动力。

常见坑

  • 非势塑形破坏最优性：每一步加固定奖励或对接近目标加倍奖励，策略被引导绕路刷分。修复：塑形一律写成势函数差形式，用轨迹排序实验验证最优策略未变。
  • 重标记阈值过松：δ 过大使远未达成的状态被判为成功，价值函数注水。修复：按任务允差与测量噪声设定 δ，人工抽检重标记成功率。
  • 目标分布全为可达状态：原始目标样本被全部替换，策略在部署分布上估计不足。修复：保留原始目标比例，评估集同时覆盖原始与重标记目标。
  • 内在奖励主导：β 过大时策略追逐新颖度、任务回报下降。修复：监控内外奖励的量级比，按进度退火，必要时对内在奖励做归一化。
  • 子目标不可达：世界模型生成的子目标超出当前策略能力，阶段奖励恒为零。修复：用可达性评分过滤，难度维持中等成功率窗口，随能力增长上调。

练习与思考

  1. 推导题：对任意势函数 Φ，证明沿轨迹的塑形总回报 Σ γtFt = γTΦ(sT) − Φ(s0)，并据此说明轨迹间排序不变。★★
    提示
    逐项展开 Ft = γΦ(st+1) − Φ(st)，相邻项的 γ 幂次两两抵消，剩余首末项；总回报差只依赖起末状态，轨迹内动作选择不受影响。
  2. 计算题：回合长度 T = 50，k = 4 时一个失败回合产生多少重标记样本？若其中 60% 的成功判定为真，正样本数是多少，与不重标记相比提升多少倍？★
    提示
    约 196 条样本，正样本约 118 条；不重标记时失败回合正样本为零，提升无从比较，属从零到有的量级变化。
  3. 把片段 3 的退火下限从 0.2 改为 0，预测后期探索行为与最终回报的变化，并解释为何保留少量内在奖励可能有利。★
    提示
    退火到零后策略在局部最优附近失去逃逸动力；保留少量内在奖励提供持续微探索，代价是回报方差略增。
  4. 实验设计：在长程装配任务上比较四组配置：纯稀疏、稀疏加 HER、稀疏加塑形、三者全开，报告首次成功所需样本量与最终成功率，并分析各组失败模式。★★
    提示
    HER 主要改善正样本密度，塑形主要改善早期梯度；全开组合样本效率最高，但需监控塑形是否掩盖外部奖励的真实进展。
  5. 设计题：为多阶段任务设计子目标生成协议：候选目标池如何构建、可达性如何用世界模型估计、阶段切换的判据、失败回退的逻辑。★★★
    提示
    候选池按难度分桶；世界模型展开估计成功率；切换用穿越窗口中值判定；连续 K 回合失败回退上一阶段。

小结

  • 稀疏奖励的处理分两条主线：改数据分布（重标记）与改奖励结构（塑形与内在奖励）。
  • HER 把失败回合重标记为对子目标的成功，代价是目标分布偏向可达集合，需要保留原始目标样本。
  • 势函数塑形有保序定理：F = γΦ(s′) − Φ(s) 只加快学习、不改变最优解；非势塑形会移动最优策略。
  • 内在奖励真正改变任务目标，必须按进度退火；世界模型生成的子目标按中等成功率窗口控制难度。
