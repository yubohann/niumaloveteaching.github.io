第 096 章：世界模型的层次化结构

两种时间尺度上的潜动态如何协同：粗步长高层动力学、子目标条件化、边界检测与半马尔可夫价值更新，把长程预测的成本压回可控范围。

  • 主题：世界模型（World Model）/ 层次化结构（hierarchical structure）
  • 关键公式：半马尔可夫价值与时长的折扣自举
  • 预计学时：55 分钟
  • 前置章节：第 095 章

学习目标

  • 理解时间抽象的必要性：控制环频率与控制决策频率相差一个量级以上，单一时间尺度的模型两头不讨好。
  • 掌握两级潜动态的结构：高层粗步长演化与低层细步长执行，理解子目标条件化的信息通道。
  • 掌握时间边界检测的两类信号（差分幅度与预测误差）以及边界对比损失的构造。
  • 掌握半马尔可夫决策过程的价值形式，理解 γτ 按实际时长折扣的自举。
  • 能诊断层级不一致、边界漂移与两时间尺度梯度干扰三类故障。

背景与动机

单一时间尺度的世界模型无法同时服务控制与规划：控制需要毫秒级细节，规划需要数十步的跨度。按控制周期展开 32 步，模型误差累积且计算量线性增加；只在粗粒度建模，又丢掉了接触、微调等精细动力学。层次化结构把两个需求分给两层：低层保留细粒度动态，高层以 8–16 步为单元演化，规划在粗时间尺度上进行，控制交由低层执行。

第 089 章的长期规划已经使用了子目标分解，但层级停留在规划算法层面；本章把层次结构下沉到世界模型本身：高层动力学有独立的转移核与状态空间，边界检测从数据中学习时间分段，价值更新服从半马尔可夫折扣。这一结构是时间抽象在世界模型侧的实现，与第 097 章的探索、第 099 章的迁移共享同一潜空间基础。

核心原理

层次化世界模型由三层要素构成：粗粒度高层动力学、子目标条件化的低层动力学、连接两层的时间边界机制。

1. 两级潜动态

低层沿用前文的潜动力学，按控制周期步进；高层以固定步长 H（8–16 个控制步）演化，状态为粗粒度潜变量 zhi。高层转移以子目标 g 为条件：

zhik+1 = fhi( zhik, gk )，低层：zt+1 = flo( zt, at ; gk ) gk 为第 k 段子目标潜向量；低层转移额外接收子目标作为条件

两级之间的信息流是单向的：高层为低层提供子目标条件，低层的执行结果反过来校准高层的可达性。层级一致性问题是这种结构的核心风险：高层预测的粗状态必须与低层实际执行 H 步后到达的状态一致，否则规划建立在不可达的想象上。一致性用跨层损失约束：低层展开 H 步的末端潜状态与高层单步结果计算距离。

2. 时间边界检测

子目标的分段边界从哪里来？两类信号可用：低层潜状态的时间差分幅度（边界处变化率突增）与低层预测误差（边界处模型失配）。边界检测头对每个时间位置输出边界概率，用监督标签（演示数据中人工或规则标注的阶段）训练，或用无监督的对比损失：

Lbound = relu( margin + 差分非边界均值 − 差分边界均值 ) 要求边界处的时间差分显著大于非边界处，margin 控制间隔

无监督对比形式的直觉与第 094 章的时间对比学习相通：同一子目标内部的状态应相似，跨边界的相邻状态应差异大。有标签数据存在时用交叉熵监督更直接；两种信号可叠加。边界质量直接影响高层转移的训练样本质量，边界漂移（同一语义阶段被切成长短不一的片段）会让高层动力学学到不一致的时间跨度，需要用相对边界的对齐机制约束（例如预测剩余时长并在边界处校验）。

3. 半马尔可夫价值

高层决策的时间单位是子目标，持续时长 τ 因段而异，价值形式相应改变。半马尔可夫决策过程（semi-Markov decision process, semi-MDP）的原生形式为：

V(s) = maxo 𝔼[ Σk=0τ−1 γk rk + γτ V(s′) ] o 为选项（option）或子目标方案；τ 为其持续时间；自举项按 γτ 折扣

自举折扣按实际时长 γτ 计算是核心修正：时长 10 的子目标与时长 3 的子目标对远期回报的折算不同，用固定折扣会让价值估计系统性偏移，规划器偏好短时选项。两时间尺度的 TD 更新分别在高、低层进行：低层按控制步更新，高层在子目标终点更新，两套目标的折扣因子需要换算一致（高层折扣可用 γhi = γloH 或直接使用 γτ 实测值）。

4. 计算收益

层次化的直接收益是规划成本的压缩：高层规划 4 个子目标、每个跨 8 个控制步，等效覆盖 32 步的视野，而世界模型只做了 4 次粗粒度前向加低层执行。误差方面，高层在粗时间尺度上的单步误差需要实测：粗状态的预测误差通常大于单步细状态，但累积步数少，总误差往往低于细粒度长展开。收益是否成立最终由"覆盖率与误差的乘积"决定，按任务实测对照单层基线。

实现思路与设计

训练分为联合阶段与分层阶段：先训练低层潜动力学，再固定低层训练高层与边界，最后两阶段微调打通一致性损失。

  1. 低层：沿用第 081–087 章的世界模型，步长等于控制周期；输出潜状态序列供边界检测使用。
  2. 边界检测：在低层潜序列上训练边界头，演示数据的阶段标注作监督，无标注数据用对比损失。
  3. 高层：按边界切分子目标段，聚合段内潜状态为粗状态；高层转移以子目标为条件，预测下一段粗状态。
  4. 一致性损失：低层段末状态与高层粗状态的距离，权重 0.1，两个时间尺度联合微调时生效。
  5. 与第 089 章的差异：规划器的子目标空间由模板扩展为学习到的潜向量；高层动力学提供可达性检查。

设计决策：高层状态为什么选择分开编码？

对低层状态做时间平均池化得到的高层状态，会把段内的关键细节（接触瞬间）稀释掉；分开编码让高层保留对段级语义有判别力的成分（进度、物体相对位置、稳定性），低层保留执行细节。代价是需要一致性损失约束两侧的可对齐性，以及额外的参数量；池化方案可作为消融基线。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：高层动力学与子目标条件

class HighLevelDynamics(nn.Module):
    """高层潜动态：单步跨 H 个控制步，以子目标为条件演化。"""
    def __init__(self, d_hi=256, d_g=64, d_lo=512, stride=8):
        super().__init__()
        self.stride = stride
        self.proj_g = nn.Linear(d_g, d_hi)       # 子目标潜向量投影
        self.align = nn.Linear(d_lo, d_hi)       # 一致性比较用的低层投影头
        self.cell = nn.GRUCell(2 * d_hi, d_hi)

    def forward(self, z_hi, g):
        # 条件 = 当前粗状态 + 子目标：高层转移编码"从哪到哪"
        cond = torch.cat([z_hi, torch.tanh(self.proj_g(g))], dim=-1)
        return self.cell(cond, z_hi)             # 输出该段结束时的粗状态

    def consistency_loss(self, z_hi_next, z_lo_segment_end):
        """跨层一致性：高层单步结果应与低层段末状态对齐。"""
        # 低层段末投影到高层空间后比较；停梯度只校正高层预测
        proj = self.align(z_lo_segment_end).detach()
        return F.mse_loss(z_hi_next, proj)

解读：高层转移核每调用一次覆盖 8 个控制步，规划 4 个子目标等效 32 步视野而只需 4 次前向，这是层次化的算力收益来源。tanh 压缩子目标投影值域，与其他潜向量量级对齐，避免条件项主导输入。consistency_loss 对低层侧目标停止梯度，只校正高层预测；若希望两侧共同调整，可取消 detach 但需降低权重。一致性比较使用独立的 align 投影头，避免两个方向的梯度互相污染。

片段 2：边界对比损失

def boundary_contrast_loss(feats, is_boundary, margin=0.1):
    """无监督边界检测：要求边界处的时间差分显著大于非边界处。"""
    # feats: (B, T, d) 低层潜序列；is_boundary: (B, T-1) 布尔标签
    dissim = (feats[:, 1:] - feats[:, :-1]).norm(dim=-1)   # 相邻步差分幅度
    pos = dissim[is_boundary]                 # 边界位置差分
    neg = dissim[~is_boundary]                # 非边界位置差分
    if pos.numel() == 0 or neg.numel() == 0:
        return feats.new_zeros(())            # 批次内无边界时跳过该损失
    # 铰链形式：边界差分至少高出 margin，达标后梯度为零
    return torch.relu(margin + neg.mean() - pos.mean())

解读：损失把边界检测转化为差分分布的对比，与第 094 章的时间近邻过滤思路同源：同段内状态差异小、跨段差异大。margin 取差分分布的标准差量级，过大导致所有位置都被推成边界，过小则边界与非边界难以区分。批次内可能没有边界样本（长段占据整个序列），此时直接跳过，训练循环需保证批次划分时边界样本的出现频率。有标注时叠加交叉熵损失；两种损失共享同一批特征，骨干梯度从两个来源汇总。

片段 3：半马尔可夫价值自举

def option_value_target(rewards, durations, next_value, gamma=0.99):
    """半马尔可夫价值目标：自举按实际时长 τ 折扣（γ^τ）。"""
    # rewards: (B, tau_max) 段内逐步奖励；durations: (B,) 实际时长
    B, tau_max = rewards.shape
    steps = torch.arange(tau_max, device=rewards.device).unsqueeze(0)
    mask = steps < durations.unsqueeze(1)     # 屏蔽填充位置的奖励
    disc = gamma ** steps
    ret = (rewards * disc * mask).sum(dim=-1)
    # 关键修正：自举折扣按实际时长取 γ^τ，固定 γ 会系统性偏移
    bootstrap = (gamma ** durations).to(next_value.dtype) * next_value
    return ret + bootstrap

解读：mask 处理段的填充对齐，不同时长的段在同一批次内拼接时避免填充位污染回报。gamma ** steps 逐位生成折扣序列，避免逐周期乘法。gamma ** durations 是半马尔可夫修正的落点：固定折扣 γ 会低估长段的回报折算，让规划偏好短时选项；按真实时长折扣后，长段与短段的回报在同一口径下可比。价值头的输入为粗状态，目标在子目标边界处生成；训练数据需覆盖实际任务的时长范围，超长段截断并单独处理。

常见坑

  • 层级不一致：高层预测的粗状态低层无法到达，规划构建在不可达想象上。症状是高层规划成功率高而真实执行率低。修复：一致性损失、规划前用低层快速预演 H/2 步校验可达性。
  • 边界漂移：同一语义阶段被切成不同长度的片段，高层学到的时间跨度不一致。症状是高层转移在相似场景下预测时长波动大。修复：边界标签统一、加时长预测辅助任务、无监督对比损失与监督边界联合训练。
  • 两尺度梯度干扰：联合微调时高层与低层的损失互相拉扯，某一侧指标反弹。症状是低层单步误差与高层一致性损失同时上升。修复：分阶段训练为主、联合微调权重压低。
  • 折扣口径不统一：高层固定折扣未按实测时长换算为 γτ，与低层 γ 的折算不一致，规划偏好短时选项。症状是子目标选择偏向容易快速完成的选项，长程收益被忽视。修复：按实测时长折扣，或显式使用半马尔可夫价值形式。
  • 步长设置不当：H 过大时高层单步预测误差过大，H 过小时层次化收益消失。症状分别是可达性差与规划成本没有下降。修复：扫描 H = 4–16，以"粗预测误差与规划成本的乘积"选择。

练习与思考

  1. 说明半马尔可夫价值中 γτ 与固定折扣 γ 的差异，构造一个时长异质的例子说明固定折扣带来的选择偏差。★★
    提示
    固定折扣下长段的远期回报被过度折算；例子用 3 步与 12 步两个选项，估算折扣后回报排序的变化。
  2. 把高层步长从 8 改为 16，预测高层预测误差、规划成本与一致性的变化。★
    提示
    误差上升、成本下降，一致性更难满足；用粗误差与规划延迟的乘积选择步长。
  3. 设计边界检测的评估方案：给出指标（边界位置的 F1、边界时延）与标定数据来源。★★
    提示
    用人工标注的段边界作金标准；允许 ±1 步容差；检查不同任务的边界检出一致性。
  4. 推导高层折扣与低层折扣的换算关系，说明时长随机时换算的近似误差。★★
    提示
    固定时长时 γhi = γloH 精确；时长波动时用 𝔼[γτ] 近似，方差大时误差不可忽略。
  5. 设计单层与层次的对照实验：覆盖规划视野、预测误差、计算延迟、任务成功率四类指标，说明控制变量与预期结论。★★★
    提示
    统一参数量上限与训练步数；层次方案预期在长程任务上计算延迟低且误差增长慢。

小结

  • 层次化世界模型用高层粗步长动力学与低层细步长动力学分工，覆盖控制细节与长程规划两类需求。
  • 子目标通过条件通道注入低层；跨层一致性损失约束高层的预测与低层的执行结果对齐。
  • 时间边界用差分对比或监督信号检测，边界质量决定高层训练样本的时间跨度一致性。
  • 半马尔可夫价值按实际时长 γτ 折扣自举，两时间尺度的折扣口径必须统一。
