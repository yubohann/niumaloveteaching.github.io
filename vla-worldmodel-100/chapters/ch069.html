第 069 章：世界模型的动态规划集成

本章讲世界模型与动态规划（Dynamic Programming, DP）的集成：把学习到的转移与奖励组织成经验转移表，在潜空间离散状态上做值迭代与软值迭代，并分析贝尔曼备份对模型误差的放大机制。

  • 主题：世界模型 / 规划与值迭代
  • 关键公式：Vk+1(s) = maxa [ r̂(s,a) + γ Σs′ P̂(s′ | s, a) Vk(s′) ]
  • 预计学时：55 分钟
  • 前置章节：第 068 章：VLA策略的决策可解释性

学习目标

  • 理解动态规划与世界模型的分工：DP 提供备份框架与收敛保证，学习模型提供转移概率与奖励的估计。
  • 掌握价值迭代的压缩映射性质，能写出收敛条件 |γ| 小于 1 与无穷范数误差衰减的推导要点。
  • 掌握潜空间离散化的两条路线（向量量化码本与网格投射），理解经验转移表与拉普拉斯平滑的作用。
  • 能实现值迭代与软值迭代，理解软最大对备份平滑、探索性与鲁棒性的影响。
  • 会诊断转移稀疏、过估计与误差放大问题，能设计保守备份对照实验。

背景与动机

本节说明动态规划集成的动机：想象 rollout 只评估采样到的轨迹。模型预测若干条想象轨迹并选择回报最高的一条，评估精度受采样数量限制，且无法回答“从这个状态出发最优能拿多少回报”。值迭代给出整张状态空间的价值表：备份一次覆盖全部动作分支，规划视野由折扣因子强制展开到无限步。学习模型提供 DP 需要的两件输入：转移概率与即时奖励。难点在状态空间：连续潜空间的期望不可精确计算，需要离散化与经验转移表。本章围绕离散化、备份与误差控制展开。

核心原理

1. 贝尔曼备份与压缩映射

定义贝尔曼最优算子 T：

(T V)(s) = maxa [ r̂(s, a) + γ Σs′ P̂(s′ | s, a) V(s′) ] r̂ 与 P̂ 来自世界模型与经验统计；γ 为折扣因子，控制有效规划视野 1/(1−γ)

对任意两个价值函数 V1、V2，有 ‖T V1 − T V2‖∞ ≤ γ ‖V1 − V2‖∞：max 算子的非扩张性与期望的线性性共同给出 γ 倍压缩。压缩映射定理保证 T 有唯一不动点 V*，值迭代从任意初值出发收敛到 V*。γ 越小收敛越快但规划短视，γ 趋近 1 时视野拉长而收敛变慢，误差放大也更严重。

2. 数值算例：两状态值迭代的手算过程

构造两状态问题。状态 s1 有两个动作：动作 a 得奖励 0 并确定转移到 s2；动作 b 得奖励 1 并确定留在 s1。状态 s2：动作 a 得 0 留在 s2；动作 b 得 0 转移到 s1。折扣 γ = 0.9，价值从零初始化：

V1 = (1, 0)；V2 = (1.9, 0.9)；V3 = (2.71, 1.71)；V* = (10, 9) 每轮备份：V(s1) 取 max(0.9·V(s2), 1 + 0.9·V(s1))；V(s2) 取 max(0.9·V(s2), 0.9·V(s1))

逐轮检查压缩行为：相邻两轮之差的无穷范数依次为 1、0.9、0.81，每轮恰乘 γ；到第 3 轮时与不动点的距离为 10 − 2.71 = 7.29 = 0.93 × 10，几何收敛的指数与理论一致。不动点验证：V*(s1) = max(0.9 × 9, 1 + 0.9 × 10) = max(8.1, 10) = 10，动作 b 的无限循环把每步奖励 1 折现为 1 / (1 − 0.9) = 10。数值结果给出两条直觉：（1）初值任取（此处取零）不影响收敛目标，只影响起点误差；（2）残差按 γ 等比衰减，迭代轮数的选择等价于在“精度 0.9k”与计算量之间取值。

3. 潜空间离散化与经验转移表

连续潜状态需要映射到有限状态集。向量量化码本（Vector Quantization Codebook）把每个潜状态投射到最近的码字，码字数取 1024 到 4096；网格投射适合低维潜空间，按每一维分桶。粒度是分辨率与样本量的权衡：状态数增加使每个状态动作对的访问稀疏。经验转移表按访问计数归一化得到 P̂(s′|s,a)，配拉普拉斯平滑 α，未访问的状态对获得均匀小概率，规划不会把“未见过”误判为“不可达”。两种离散化路线的特性对照如下：

维度向量量化码本网格投射
粒度控制码字数 k，单参数控制每维分桶数，组合数随维数爆炸
对数据的适应码字随数据分布自适应，落在高密度区均匀切分，低密度区浪费分辨率
边界行为码字边界附近状态抖动时索引跳变桶边界处同样跳变，且各维独立
适用维数中高维均可用仅低维（两维到四维实用）
实现复杂度需码本训练与最近邻检索取整与分桶，实现最简

选择依据：隐空间维度超过四维时优先码本；低维且分布均匀时网格最省事。两条路线共同的代价是边界跳变，缓解手段相同：对价值表做空间平滑，或让码本训练加入承诺损失减少边界样本的摇摆。离散化方案的选择要服务于转移统计的密度：状态数过密时宁可加大粒度，也不要维持一张大部分为空的高分辨率表。

4. 误差放大与过估计

贝尔曼备份把模型误差乘以 γ 累计：若单步转移模型误差为 ε，无限步备份后的价值误差上界约为 ε/(1−γ)。γ = 0.99 时放大倍数达到 100，这是动态规划集成最需要警惕的数值效应。第二类误差来自 max 算子：Q 值噪声经 max 取上界，噪声上方的动作被优先选择，称为过估计（Overestimation）。缓解手段有三类：双估计（Double Q）用两套估计交叉取值抵消噪声；保守惩罚对不确定对减项；软最大把备份变为光滑加权平均。备份的频率越高，过估计的累积越明显，评估时用真实环境回报校准价值表是必要步骤。

5. 软值迭代：把 max 换成软最大

熵正则版备份把 max 替换为软最大：

V(s) = τ log Σa exp( Q(s, a) / τ ) τ 为温度：τ 趋近 0 时退化为硬最大值，τ 增大时备份向动作平均过渡

软最大对噪声更鲁棒：单个动作的估计尖峰被指数加权平均压低。提取策略时用 softmax(Q/τ)，最优策略天然带熵，遇到模型不确定的状态会自动混合动作，探索性因此内建在规划里。温度与动作噪声相关：噪声大时上调温度，备份更保守。软值迭代用表达力换稳定性，代价是价值表对奖励尺度更敏感。

用数值观察温度的作用：某状态三个动作的价值为 2.0、1.9、1.8。硬最大备份给出 V = 2.0；软最大取 τ = 0.1 时 V = 0.1 × log(e20 + e19 + e18) ≈ 2.04，与硬最大接近，动作权重约 (0.67, 0.24, 0.09)；取 τ = 0.5 时 V ≈ 2.46，权重明显摊平。数值给出两个使用口径：（1）温度在 0.1 量级时软最大接近硬最大，把温度当“抗噪开关”使用时应从更小的值起步逐步上调；（2）τ 增大时价值整体抬升（对数项随温度增长），跨温度比较价值表之前必须先统一温度与奖励尺度，否则新旧价值不可比。

实现思路与设计

本节给出集成管线：世界模型隐状态经码本质量化后建立状态索引；交互数据按 (s, a, s′) 三元组写入计数表；每固定步数从计数表拟合转移概率并运行值迭代得到价值表；VLA 策略在动作采样时查询价值表做候选筛选，或把价值作为子目标评分。转移表用衰减计数适应非平稳动力学。与第 068 章的差异：第 068 章做诊断，本章把世界模型的预测能力转化为显式的规划结构。

设计决策：为什么用计数衰减替代重建转移表

动力学可能缓慢漂移（新工具、磨损），旧计数逐渐失真。直接重估全表代价高且丢弃历史。指数衰减是常见折中：每次访问先缩放全表计数再累加新观测，等效于近期数据高权重。衰减因子按漂移速度设定，过小价值表抖动，过大适应滞后。价值表的时间常数应与模型的适应速度匹配。

价值表质量的校核流程

  • 访问覆盖统计。统计有非零访问的状态动作对占比：低于三成说明码本过大或数据不足，先降码本规模；覆盖与分辨率的平衡点按任务成功率判断，记忆表规模仅作为参考量。
  • 备份残差留痕。每轮值迭代记录无穷范数残差，曲线应呈等比衰减；衰减中途平台化说明平滑项或计数衰减在持续注入噪声，需要先冻结转移表再迭代。
  • 价值校准。抽固定回合用真实环境回报与价值表对照，系统性偏高即过估计，检查 max 备份与计数平滑的参数；校准点同时用于选择软最大温度。
  • 迭代预算的裁剪。残差低于奖励噪声水平后停止迭代；继续迭代只是在拟合计数噪声，还会放大平滑常数带来的偏差。
  • 版本与重算范围。模型更新后优先重算高访问状态的价值，低访问区域等新数据自然覆盖；重算与旧表的融合按访问量加权，避免未访问区域的价值被搅动。

关键代码与解读

以下片段以值迭代与潜空间规划的实现为参照，接口随版本演进。三个片段分别覆盖经验转移表、同步值迭代与软值迭代。

片段 1：经验转移表与拉普拉斯平滑

import torch

class TransitionTable:
    """经验转移统计：维护 (s, a, s') 计数并归一化为概率。"""
    def __init__(self, n_states=4096, n_actions=8, alpha=1e-2, decay=1.0):
        self.register = torch.zeros(n_states, n_actions, n_states)
        self.alpha = alpha            # 平滑强度，防止未访问对概率为零
        self.decay = decay            # 小于 1 时旧计数指数遗忘，适应漂移

    def observe(self, s_idx, a_idx, s_next):
        if self.decay < 1.0:
            self.register *= self.decay                 # 全表衰减：近期观测权重更高
        idx = (s_idx, a_idx, s_next)
        self.register.index_put_(idx, torch.ones_like(s_idx, dtype=torch.float),
                                 accumulate=True)

    def prob(self):
        # 平滑后按最后一维归一化：P(s'|s,a) 每行和为 1
        num = self.register + self.alpha
        return num / num.sum(dim=-1, keepdim=True)

解读：（1）计数表按状态动作对索引，转移分布天然稀疏，4096 状态 × 8 动作的组合在数十万条样本下仍可维护。（2）衰减在每次观测前执行，等价于给全部历史计数乘遗忘因子，无需记录观测时间。（3）平滑常数与计数同量纲，注入的是软先验：未访问组合被赋予均匀分布的小概率质量。

片段 2：同步值迭代与策略提取

@torch.no_grad()
def value_iteration(P, R, gamma=0.99, iters=200, tol=1e-4):
    """同步值迭代：逐轮备份，无穷范数收敛检查。"""
    V = torch.zeros(P.shape[0])                    # 状态价值从零初始化
    for _ in range(iters):
        # Q(s,a) = r + gamma * E_{s'}[V]；einsum 把转移求和与动作维广播合并
        Q = R + gamma * torch.einsum("sat,t->sa", P, V)
        V_new = Q.max(dim=1).values                # 贪心备份：取最优动作价值
        if (V_new - V).abs().max() < tol:
            V = V_new
            break                                  # 残差低于阈值即可停止
        V = V_new
    # 用收敛后的价值再算一次 Q，提取贪心策略
    policy = (R + gamma * torch.einsum("sat,t->sa", P, V)).argmax(dim=1)
    return V, policy

解读：（1）同步备份意味着每一轮全部状态一起更新，向量化后一次矩阵运算完成，适合 GPU。（2）收敛检查用无穷范数：它恰好是压缩映射分析中使用的范数，判据与理论对齐。（3）策略提取复用最终 Q 值，返回确定性策略供候选评分。

片段 3：软值迭代与温度策略

@torch.no_grad()
def soft_value_iteration(P, R, gamma=0.99, tau=0.1, iters=200):
    """熵正则值迭代：软最大替代硬最大，备份更平滑。"""
    V = torch.zeros(P.shape[0])
    for _ in range(iters):
        Q = R + gamma * torch.einsum("sat,t->sa", P, V)
        # 软最大：tau 小时接近 max，tau 大时接近动作平均
        V = tau * torch.logsumexp(Q / tau, dim=1)
    Q = R + gamma * torch.einsum("sat,t->sa", P, V)
    # 最优策略为 softmax：不确定状态下自动混合动作，探索性内建
    policy = (Q / tau).softmax(dim=1)
    return V, policy

解读：（1）logsumexp 在数值上等价于先减最大再指数，避免 Q/tau 较大时上溢。（2）软最大备份对单个动作的估计尖峰取指数加权，噪声上界被压低，过估计风险随之下降。（3）温度策略采样时按概率选择动作，天然带熵，部署时若需要确定性执行则取 argmax 并在验证集上对比两种口径的成功率。

常见坑

  • 转移统计稀疏：码本过大，多数状态动作对从未访问，转移表近似均匀分布，规划退化。修复：缩小码本、合并相近码字，或对未访问对直接使用模型预测的转移。
  • 过估计累积：价值表整体高于真实回报。修复：双估计、保守惩罚与软最大三选一，用真实回报校准。
  • 模型误差放大：单步预测精度的微小提升被 γ 放大后价值差异显著。修复：降低 γ、限制备份步数，或对模型不确定区域的 Q 值施加惩罚。
  • 离散化边界跳变：潜状态在码字边界附近抖动，相邻状态价值不连续，策略在边界反复横跳。修复：码本训练加入承诺损失，或对价值表做空间平滑。
  • 奖励尺度未归一化：即时奖励量级差异大时温度与收敛阈值失去意义，软值迭代对尺度的敏感性被放大。修复：奖励先归一化到单位尺度，再交给值迭代。

练习与思考

  1. 推导题：证明贝尔曼最优算子是 γ 压缩的，即对任意 V1、V2 有 ‖TV1 − TV2‖∞ ≤ γ‖V1 − V2‖∞，并说明该性质为何保证值迭代收敛。★★
    提示
    先对单个状态动作对用 |max 差| 不超过逐项差的绝对值上界，再由期望的线性性与概率和为 1 提取 γ，最后取无穷范数。压缩映射定理给出唯一不动点与几何收敛。
  2. 计算题：γ = 0.99、单步模型误差 ε = 0.01（奖励单位尺度），用 ε/(1−γ) 估算价值误差上界；若 γ 降到 0.9，上界变为多少，说明规划视野与误差的交换。★
    提示
    γ = 0.99 时上界约 1.0；γ = 0.9 时约 0.1。视野从 100 步缩到 10 步，误差放大同步下降一个量级。
  3. 把片段 2 的收敛阈值从 1e-4 放宽到 1e-2，预测迭代轮数与价值误差的变化。★
    提示
    阈值放宽后迭代轮数明显减少，价值误差上界约为阈值/(1−γ)。阈值低于奖励噪声时继续迭代只是在拟合噪声。
  4. 实验设计：在有噪声奖励估计的环境上比较硬最大、软最大（τ = 0.05、0.2）与双估计四种备份方式，报告价值表误差、策略真实回报与动作分布熵。★★
    提示
    硬最大价值偏高、真实回报偏差大；软最大温度增大后价值更保守、策略熵上升；双估计与软最大组合通常最稳，代价是价值略偏保守。
  5. 设计题：为“规划与模型预测使用不同版本动力学”的场景设计一致性协议：价值表如何标注模型版本、模型更新后价值表如何部分重算、怎样避免策略在版本交替处震荡。★★★
    提示
    价值表附带模型版本号；模型更新后优先重算高访问状态的价值；新价值表与旧表按版本差做插值上线，检测到策略翻转率上升时暂停切换。

小结
