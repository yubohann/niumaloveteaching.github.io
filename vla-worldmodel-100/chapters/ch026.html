第二篇 · 联合训练进阶与策略能力

第 026 章：VLA策略的注意力可视化

注意力权重是策略内部唯一接近"思路"的可读信号；本章讲清跨模态注意力矩阵的提取、rollout 聚合的原理、熵指标的含义，以及用掩码消融校验相关性的方法。

  • 主题：注意力分析（attention analysis） / 可解释性（interpretability）
  • 关键公式：α = softmax(QKT/√dk)；rollout 聚合 Â = Πt(I + Ât)；注意力熵 H = −Σ α log α
  • 预计学时：45 分钟
  • 前置章节：第 025 章

学习目标

  • 理解跨模态注意力（cross-modal attention）矩阵的结构：语言 token 与视觉 patch 之间的权重如何计算与读出。
  • 掌握注意力 rollout 的聚合原理，能解释残差连接下逐层乘积累积的信息流近似。
  • 掌握注意力熵（attention entropy）等量化指标，会用它们诊断"注意力分散"与"注意力锁定"两种模式。
  • 会把 patch 级注意力上采样到像素空间并与原图叠加，检查指令与物体区域的对应关系。
  • 能设计掩码消融实验，校验注意力位置与策略行为之间的相关性强度。

背景与动机

VLA 策略（Vision-Language-Action）输出的是动作向量，失败时只能看到动作异常，看不到内部原因。指令被忽略、视觉特征错位、语言指向错误对象，这三类问题在失败样本中的表象相似。注意力权重（attention weight）提供了一条可读出内部的通道：查询 token 把注意力分配在哪些视觉 patch 上，直接反映模型当前使用哪些输入信息。

可视化同时存在过度解读的风险：注意力权重反映的是前向计算中的信息路由，与"模型决策依据"之间存在距离。本章的立场是把注意力当作诊断线索：先用可视化提出假设（例如"指令中的目标词没有落在目标物体上"），再用掩码消融等干预实验验证假设。

本章与第 025 章的衔接在于：元学习让模型适应新环境，适应是否破坏了原有的模态对齐需要检查工具；注意力可视化正是检查语言与视觉对齐是否随训练保持的手段，也为第 038 章的语义理解增强提供诊断依据。

核心原理

1. 跨模态注意力矩阵的构成

Transformer 中的缩放点积注意力为：

Attn(Q, K, V) = softmax( Q KT / √dk ) · V Q、K、V 分别为查询、键、值投影；dk 为键维度，缩放因子防止内积随维度增长而饱和

跨模态注意力中，语言 token 作为查询、视觉 patch 作为键值（或反向），得到的矩阵形状为 [语言 token 数, patch 数]。矩阵的第 i 行是第 i 个词对全部图像区域的一行概率分布。对指令理解的关键词行（如动词与宾语词）可以直接读出其关注的区域。

“关注到目标物体”需要一个可比的基准：把目标框覆盖的 patch 集合记作 B，关键词行在框内的注意力质量占比为 Σj∈B αj。若目标框占画面 10% 面积，均匀注意力的框内质量期望也是 10%；实测框内质量 60% 意味着相对均匀基线提升 6 倍，这类“质量占比对面积占比”的比值就是常用的对齐读数，等价于以面积先验修正后的 IoU 口径。目标框来自检测标注或人工框选，评测集上的框质量直接影响该指标的噪声水平，低质量框会让读数系统性偏低。

多头（multi-head）结构下每个头学到不同的路由模式，层与层之间也分层分化：浅层倾向局部纹理与位置，中层出现对象级对齐，深层聚合与任务相关的区域。单看某一个头会得出误导性结论，聚合需要跨越所有头与部分层。跨头平均还有一个前置检查：若各头的热区互不重叠、彼此覆盖画面的不同区域，平均后得到的是弥散图，热区信息被抹平；此时先按头做聚类（例如对头间注意力行向量算相关矩阵），再报告“对齐头”“位置头”等分组结果，比直接平均更接近真实路由。头间相关矩阵本身也是训练监控项，全部头高度相关说明注意力容量浪费，头间完全无关则说明缺乏共识对齐。

2. 注意力 rollout：跨层聚合

把每层的注意力与残差连接一起考虑，信息从输入到第 L 层的传播近似为逐层矩阵的乘积：

Â = Πt=1L ( I + Ât )，最终按行归一化 Ât 为第 t 层平均后的注意力矩阵，I 对应残差直连路径；行归一化保证输出仍为分布

直觉解释：每一层都在"重新路由"信息，第 t 层的注意力表示一步转移的概率，多层叠加后的乘积近似表示从输入 token 出发经过 L 步随机游走到达各 patch 的总概率。加入 I 是因为残差路径允许信息不经过注意力直接传递。rollout 的价值在于把"某一层的注意力"升级为"跨层的信息流估计"，对深层网络的诊断更可靠。需要注意矩阵乘法要求各层注意力方阵对齐，rollout 适用于同一 token 空间内的注意力（视觉自注意力或语言自注意力）；跨模态注意力的形状为矩形，跨层聚合改用按层归一化加权求和，不能直接连乘。

残差项的权重含义可以量化：注意力行和为 1、残差直连权重也为 1 时，(I + A) 的行和为 2，行归一化后等价于每步以约 1/2 的概率沿注意力转移、1/2 的概率停留在原地，即带重启的随机游走；重启概率让 rollout 的热区偏向输入 token 附近，离起点越远的区域需要连续多层的高权重路径才能积累出高概率。这也给出了回溯层数的上限（表中取 6 层）：层数越多，重启项让热区越趋近均匀，可读性被逐步稀释。

3. 注意力熵：分散与锁定的判据

单行注意力的熵定义为：

H(α) = − Σj αj log αj αj 为一个查询 token 对第 j 个 patch 的注意力权重；patch 数为 N 时，均匀分布的熵为 log N

熵接近 log N 说明注意力近似均匀，模型没有聚焦任何区域；熵接近 0 说明权重集中在单个 patch，可能是过度锁定。两种极端都对应具体的故障模式：均匀分布常出现在语言条件未生效或视觉特征退化时；过度锁定常见于视觉干扰物少、训练样本单一导致的过拟合路由。把熵作为训练过程中的监控指标，比逐个样本看图更高效。

把典型分布代入数字（N=196，log N = 5.278）：均匀分布熵 5.278，归一化熵为 1.0；70% 质量集中在单个 patch、其余均匀铺开的分布熵 2.193，归一化熵 0.415；98% 集中在一处的近 one-hot 分布熵 0.203，归一化熵 0.039。配置表中的告警上界 0.9·log N = 4.750 对应归一化熵 0.9，落在均匀分布与“明显聚焦”之间，用来筛出“什么都没看”的样本；过度锁定的告警线在另一端，归一化熵低于 0.1（约等于 98/2 分布）时进入人工检查。用归一化熵跨分辨率比较也成立：分辨率从 224 提到 256 时 patch 数从 196 增到 256，log N 变化约 0.27，归一化后两组数字仍可直接对照。监控的采样与聚合方式：每个验证周期按批次统计熵的中位数与 95% 分位两条曲线，中位数反映总体对齐水平，95% 分位捕捉“分散型”尾部；两条曲线同时抬升通常对应语言条件失效，单独 95% 分位抬升多为个别难样本。

动作块内部的时间维度也要检查：动作块长度 8 时按块内位置分别统计熵，健康模式下块首熵略高（模型重新决策），块内逐步递减（进入执行细化）；块尾熵明显回升说明执行后期对目标区域的锁定减弱，这类模式与 023 章的块间跳变监控互补，一个看表示、一个看输出。若块内熵曲线平坦且始终偏高，优先怀疑动作分块的时间建模不足，语言对齐放在其后排查。

重复前向的一致性评估给出数值口径：同一指令与图像在固定权重下两次前向，行归一化注意力分布用 JS 散度比较，0.01 以内视为一致，0.05 以上进入排查；不一致的来源按顺序检查随机性模块是否残留训练模式、批归一化统计是否在评估路径被更新、是否启用了非确定性内核。推理期策略应保持评估模式，这条纪律与 007 章的冻结清理同源：注意力可读性的前提是前向本身可重复。

4. 可视化到像素与因果校验

像素叠加的步骤：patch 注意力取平均或按 token 分组，reshape 成网格，双线性上采样到输入分辨率（如 224×224），按行归一化后与输入图像按权重叠加。上采样时需要注意 patch 网格与卷积步幅的对应关系，错位会导致热区偏移。

因果校验用掩码消融实现：把注意力最高的若干 patch 区域替换为均值色或模糊，重新前向，观察动作输出与原始输出的差异。若遮挡热区导致动作显著改变，说明该区域是决策依赖的输入；若动作几乎不变，说明注意力权重与决策之间只有相关关系。可视化提出假设，消融负责证伪，两者配套使用才能形成可靠结论。

消融的干预量需要记账：Top 16 个 patch 占 196 个 patch 的 8.2% 画面面积，遮挡后动作变化幅度与该面积占比没有直接可比性，判读要对照“随机遮挡同样面积”的对照组：若随机遮挡平均改变动作 0.5%（动作量程占比），热区遮挡改变 5% 以上，才能主张热区参与决策。动作变化幅度用动作量程归一化后再报告，不同任务之间才可比较；低于量程 1% 的变化落在执行噪声内，不作为证据。

实现思路与设计

可视化工具链由四步构成：钩子提取、聚合计算、指标统计、像素渲染。与第 025 章的差异：025 关注参数层面的适应，本章关注前向计算的信息路由，定位是诊断工具，作用范围限于分析与排查。

  1. 钩子提取：对跨模态注意力模块注册前向钩子，捕获注意力权重矩阵，避免修改模型代码。捕获开销可以预先核算：单层单批次的注意力张量（8 头、48 查询、196 键）约 294 KB，12 层合计约 3.5 MB，相对激活显存可忽略；开销主要不在存储而在采集时机，批量评估时按采样率抽取样本，逐样本采集只在异常样本复查时启用。
  2. 选择层与头：分析阶段聚合全部层与头；单点检查时按"深层 + 高熵头"筛选，减少视觉噪声。
  3. 指标统计：对每个验证样本统计熵、关键词行与目标框的 IoU（交并比）、rollout 热区重心偏移。
  4. 渲染与对照：把热区叠加到原图，与动作输出的异常时刻对照，形成"失败样本 → 假设 → 消融验证"的完整链路。

关键代码与解读

以下片段参照公开的注意力分析与 rollout 实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：前向钩子提取跨模态注意力

import torch

class AttentionCapture:
    """用前向钩子捕获指定模块的注意力权重，不修改模型源码。"""
    def __init__(self, model, layer_indices):
        self.buffers = {}
        self.handles = []
        blocks = model.cross_attn_blocks          # 注意力模块列表
        for idx in layer_indices:
            # 闭包捕获 idx：默认参数绑定避免循环变量晚绑定问题
            def hook(module, inputs, output, idx=idx):
                # output 约定包含 attn_weights 字段，形状 [B, heads, Tq, Tk]
                self.buffers[idx] = output["attn_weights"].detach()
            self.handles.append(blocks[idx].register_forward_hook(hook))

    def release(self):
        # 钩子不清除会持续占用显存并影响后续前向
        for h in self.handles:
            h.remove()
        self.handles = []

    def stacked(self):
        # 按层号排序拼成 [L, B, heads, Tq, Tk]，供聚合使用
        keys = sorted(self.buffers)
        return torch.stack([self.buffers[k] for k in keys])

解读：（1）钩子方式把采集逻辑与模型定义解耦，同一套工具可复用到不同结构；（2）闭包用默认参数绑定层号，避免 Python 循环变量的晚绑定错误，这类错误在多层采集时非常隐蔽；（3）detach 后存储，注意力张量不参与反向图，显存占用可控；（4）release 显式移除钩子，调试完立即释放，避免推理性能被持续拖累。

片段 2：rollout 聚合与熵指标

import torch
import torch.nn.functional as F

def attention_rollout(attn_stack, min_keep=0.0):
    """跨层 rollout：同一 token 空间的方阵注意力逐层 (I + A) 连乘。"""
    L, B, H, n, m = attn_stack.shape
    if n != m:
        raise ValueError("rollout 仅适用于方阵注意力；跨模态矩形矩阵请用按层加权求和")
    attn = attn_stack.mean(dim=2)               # 跨头平均，消除单头偏差
    # 丢弃注意力最低的分量：抑制噪声在长链乘法中累积主导结果
    if min_keep > 0:
        thresh = attn.quantile(min_keep, dim=-1, keepdim=True)
        attn = attn * (attn >= thresh)
    # 起点为单位阵：对应"尚未经过任何注意力路由"的恒等分布
    result = torch.eye(n, device=attn.device).expand(B, n, n)
    for l in range(L):
        # a @ result 为注意力路径，+ result 为残差直连路径
        result = attn[l] @ result + result
    return result / result.sum(dim=-1, keepdim=True).clamp(min=1e-8)

def row_entropy(attn_rows):
    """按行计算注意力熵：监控分散度，单位 nat。"""
    p = attn_rows.clamp(min=1e-9)
    return -(p * p.log()).sum(dim=-1)

解读：（1）先跨头平均再做 rollout，顺序不可颠倒：先 rollout 再平均会放大明显偏斜的头；（2）残差项实现为 result = A·result + result，与 (I + A) 连乘等价，累乘顺序从浅到深；（3）阈值过滤去掉极小权重，防止长链乘法中噪声分量累积主导结果，阈值比例需在验证集上调；（4）行归一化保证输出是概率分布，熵计算才有意义；clamp 防止全零行除零。

片段 3：掩码消融校验

def mask_top_patches(model, obs, action_idxs, top_k=16):
    """把注意力最高的 patch 置为均值色，观察动作输出的变化幅度。"""
    with torch.no_grad():
        base_action = model.act(obs)
    attn = model.last_attn_row(action_idxs)       # [P] patch 级权重
    patch_px = 16                                  # 视觉编码器的 patch 像素尺寸
    grid = obs.shape[-1] // patch_px               # 每边 patch 数，224 输入对应 14
    keep = torch.topk(attn, top_k).indices
    # 一维 patch 索引还原为网格坐标，再映射到像素块边界
    rows, cols = keep // grid, keep % grid
    obs_masked = obs.clone()                      # 观测按 [C, H, W] 组织
    fill = obs_masked.mean()                      # 全图均值色，避免黑块成为新特征
    for r, c in zip(rows.tolist(), cols.tolist()):
        obs_masked[:, r * patch_px:(r + 1) * patch_px,
                   c * patch_px:(c + 1) * patch_px] = fill
    with torch.no_grad():
        new_action = model.act(obs_masked)
    # 动作变化幅度：显著变化支持"该区域参与决策"，微弱变化提示相关性不足
    return (new_action - base_action).abs().mean().item()

解读：（1）遮挡填充用全图均值色：黑色填充会让“黑色方块”本身成为新的视觉特征，污染结论；（2）步长切片 r::patch_size 按网格跨步填充整块区域，与 patch 划分方式对应，上位采样更容易对齐；（3）输出单标量动作变化幅度，便于批量统计与阈值判定；（4）该实验可以反向使用：把低注意力区域置均值后若动作大幅变化，说明模型依赖的线索未被注意力热区覆盖。

常见坑

  • 单层单头下结论：某个头在某层的热区恰好覆盖目标物，便推断"模型理解了指令"。修复：跨层跨头聚合后再看，并用消融实验验证因果性。
  • softmax 饱和导致误判：未做缩放或训练不稳定时，softmax 输出接近 one-hot 或均匀分布，熵指标失去分辨力。修复：检查注意力 logits 的范数分布，必要时在训练上加入注意力温度或熵正则。
  • patch 网格与上采样错位：卷积步幅与 patch 划分不一致时，热区整体偏移半格到一格，容易得出"注意力落在背景上"的错误结论。修复：用已知位置的人工测试图（例如棋盘标记）校准映射关系。
  • 把相关性当作因果证据：注意力权重高只说明信息路由活跃，决策可能依赖其他通道。修复：所有结论都配掩码消融，报告动作变化幅度。
  • 忽略时间维度：动作分块策略一次输出多步动作，注意力在不同时间步之间可能变化。修复：按块内位置分别统计熵与热区，检查块首与块尾的模式差异。

练习与思考

  1. 把注意力 softmax 的温度系数从 1 调大到 2（logits 除以 2），预测熵指标与热区形态的变化，并说明这种变化对诊断的影响。★
    提示
    温度增大让分布更平滑，熵上升、热区扩散；诊断上会掩盖"过度锁定"问题，但降低对噪声 patch 的敏感性。温度只是观测视角，不应在推理中随意修改，比较时需固定。
  2. 推导 rollout 公式：设某一层注意力为 A、残差路径权重为 1，写出 (I + A) 连乘前两层后的展开式，说明它为何近似二步随机游走的概率。★★★
    提示
    (I + A1)(I + A2) = I + A1 + A2 + A1A2；各项对应"不经过注意力""只经过一层""先经 A2 再经 A1"三类转移路径，A1A2 即二步路径的概率。
  3. 设计注意力一致性评估：同一指令在两次前向（不同批次位置）中注意力分布应基本相同。给出一个可计算的相似度指标与判定阈值，并说明哪些因素会造成不一致。★★
    提示
    可用行归一化后分布间的余弦相似度或 JS 散度；不一致来源包括批归一化统计、随机性模块（dropout 残留）、浮点非确定性。阈值按验证集正常样本分布取 5% 分位。
  4. 把掩码消融从"遮挡高注意力区域"改为"遮挡高梯度区域"，预测两者结论的差异，并说明哪一类干预更接近"决策依据"的定义。★★
    提示
    高梯度区域对应输出对输入的敏感位置，遮挡后动作变化更直接；两者重叠度高说明注意力与敏感性一致，重叠度低则提示注意力路由经过了多层变换。敏感性视角更接近决策依赖。

小结

  • 跨模态注意力矩阵给出语言 token 与视觉 patch 之间的信息路由，是策略内部最易读的诊断信号。
  • rollout 通过 (I + A) 连乘把单层注意力升级为跨层信息流估计，行归一化保证分布语义。
  • 注意力熵把"分散"与"锁定"转化为可监控的标量指标，适合批量筛选异常样本。
  • 可视化提出假设，掩码消融负责校验因果性，两者配套使用才构成可靠结论。
  • 常见误判来自单头单层取样、softmax 饱和与网格错位，聚合与校准是基本纪律。
