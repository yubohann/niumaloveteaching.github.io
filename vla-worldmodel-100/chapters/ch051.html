第三篇 · 策略与世界模型深化

第 051 章：世界模型的样本效率提升

真实交互是最贵的资源：本章讲清想象 rollout 的数据放大机制与其偏差代价、优先级回放的重要性修正、重分析刷新目标的原理，给出以真实交互步数为横轴的度量口径。

  • 主题：世界模型 / 数据效率（Data Efficiency）
  • 关键机制：想象 rollout、优先级回放、重分析、辅助自监督
  • 预计学时：55 分钟
  • 前置章节：第 050 章 VLA策略的模型压缩

学习目标

本章围绕"用同一份真实数据榨取更多学习信号"展开，同时明确各机制的代价与边界。

  • 理解样本效率（Sample Efficiency）的度量口径：以真实交互步数为横轴画性能曲线，梯度步数横轴反映计算量、反映不了数据利用率。
  • 理解想象 rollout（Imagination Rollout）的数据放大机制，以及模型偏差随展开长度累积的定量趋势。
  • 掌握优先级回放（Prioritized Replay）的采样分布与重要性采样修正，能解释缺少修正时的估计偏差。
  • 掌握重分析（Reanalysis）的作用：用当前编码器刷新历史转移的潜状态，抑制表示漂移。
  • 能配置辅助自监督损失，理解其重塑表示与控制容量的权衡。

背景与动机

真实交互的成本由机器人时间、磨损与安全约束共同决定；仿真交互成本低，但与真实动力学存在差距。世界模型的核心承诺是用模型的想象替代部分真实交互：训练好的世界模型可以生成任意数量的 rollout，把每条真实转移的利用次数从个位数提升到数十次量级，这是模型基方法提升样本效率的主要路径。

放大的代价是偏差。世界模型对动力学的近似误差在 rollout 中逐步累积，想象数据偏离真实分布越远，从中提取的学习信号越不可靠。样本效率工程的准则是：在偏差可控的前提下尽可能提高复用倍率，并用优先级与重分析把有限的数据预算投向信息量最大的样本。前一章完成了部署形态的压缩，本章回到训练侧，解决数据预算紧张场景下的学习机制。

核心原理

按"放大、修正、刷新、度量"四条线索展开。

1. 想象 rollout 的数据放大与偏差代价

每条真实转移 (s, a, r, s′) 存入回放缓冲后，可用于两类更新：在世界模型损失上直接监督动力学，以及作为想象 rollout 的起点生成多步预测序列供策略学习。定义复用倍率 k 为每条真实转移平均贡献的学习样本数，模型基方法的 k 常达到 10 至 50。偏差方面，设单步预测误差为 ε1，展开 H 步后状态分布偏离量近似按 O(H·ε1) 累积（初值敏感系统的上界更高）。

想象数据的有效价值衰减 ≈ 1 − c·H·ε1 c 为动力学敏感度常数；H 取 5 至 15 是常见工作区间，超过后偏差主导

展开长度的选择原则是"误差主导前停止"：监控第 H 步预测误差与真实分布的偏差，偏差超过阈值时缩短 H 或提高世界模型的训练优先级。这与第 045 章插值伪样本的比例控制同一逻辑，只是偏差来源从路径几何改为动力学误差。

数值示例：ε1 = 0.02、c = 1、H = 10 时折扣约 0.8，复用倍率 k = 10 对应的净效率约 8 倍；净收益消失的临界折扣为 1/k = 0.1。监控第 H 步误差的作用是把折扣读数维持在临界线以上，H 的调整才有依据。

2. 优先级回放与重要性修正

均匀回放把同样的采样概率分配给所有历史转移，低频但高信息量的样本（罕见接触、任务关键阶段）被稀释。优先级回放按转移的时序差分误差或预测误差构造采样分布：

pi ∝ (|δi| + ε0)α，wi = (N · pi)−β / maxj wj δi 为误差信号；α 控制优先级强度，β 控制重要性修正强度，随训练从 0.4 升至 1.0

改变采样分布会改变期望梯度的估计对象，缺少重要性权重 wi 时更新有偏，表现为对高优先级样本过拟合、旧分布性能回落。权重上限归一化保证数值稳定；β 从 0.4 起步缓慢升到 1.0，是"先利用优先级、后修正偏差"的常用节奏。

3. 重分析：刷新历史转移的潜状态

潜状态由编码器实时计算，编码器在训练中持续更新，回放缓冲中存储的旧潜状态与新编码器不再匹配，直接复用会造成目标漂移。重分析的做法是：每隔固定步数，用当前编码器对缓冲中的历史观测重新编码，刷新潜状态与动力学头输入的统计；开销集中在编码器前向，可分批执行。

重分析频率是成本与新鲜度的权衡：过于频繁浪费算力，过于稀疏则旧潜状态与新表示脱节。与重分析互补的机制是优先存储观测、训练时实时编码中间表示，把不一致问题转化为编码算力问题。两种方案按其计算预算选择。

4. 辅助自监督与控制容量

辅助损失通过额外的预测任务塑造表示：重建当前观测、预测未来帧的对比目标、时序对比表示（相邻时刻的潜状态距离小于远距时刻）、以及两视图增强的一致性目标。辅助损失的作用是把表示空间的几何约束写入编码器，使小样本下学到的特征更接近任务相关结构；代价是容量被这些目标占用，权重过大时动力学预测精度下降。

工程上给辅助损失设置与主损失同量级的初始权重（0.05 至 0.2），并监控两项损失的梯度范数比值。辅助目标的收益在真实样本量最小的阶段最大，随数据量上升递减，权重可随训练进程调度下调。

5. 度量口径

样本效率的横轴是真实交互步数，纵轴是任务回报或成功率。对比不同机制时必须固定真实交互预算：把梯度步数、参数量或训练时长作为横轴的比较会掩盖数据放大机制的差异，同一份数据被复用的方式才是变量。同时报告达到目标成功率所需的交互步数与单位交互步数的收益增速，两者共同刻画效率。

实现思路与设计

训练流程区分真实数据阶段与想象阶段：先积累启动数据，再进入想象占主导的循环。

流程

  1. 启动阶段：随机策略或演示数据积累 5000 至 20000 条真实转移，训练世界模型至单步误差收敛。
  2. 想象阶段：从缓冲采样起点，世界模型展开 H 步，策略在潜空间中学习。
  3. 刷新阶段：每 1000 至 5000 步执行重分析，刷新内容见机制部分。
  4. 评估阶段：固定真实交互预算下的回报曲线，作为所有机制对比的统一口径。

与前一章的差异点

第 050 章在部署侧压缩计算量，样本效率在训练侧压缩数据量；两者都受"精度约束下的预算优化"这一框架支配，但变量分别为位宽与真实交互步数。压缩后的模型仍可使用本章的复用机制，后者的偏差趋势由动力学误差决定，与数值精度基本独立。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖想象 rollout 训练、优先级采样与重分析刷新。数值与上表一致。

片段 1：想象 rollout 的批量训练

import torch
import torch.nn.functional as F

def imagined_rollout_update(model, policy, optimizer, starts, horizon=10, gamma=0.99):
    """从起始观测展开想象序列，策略在潜空间内学习。
    设计意图：每条真实转移经展开复用多次，梯度不依赖额外环境交互。"""
    obs, actions = starts
    h = model.encode(obs)                      # 起始潜状态来自真实观测
    returns, losses = [], []
    for t in range(horizon):
        z = model.latent(h)                    # 当前潜状态：想象中的"观测"
        a, logp = policy.sample(z)             # 策略采样动作，保留对数概率供更新
        h = model.step(h, a)                   # 动力学前推：世界模型提供下一状态
        r = model.predict_reward(h)            # 奖励头给出想象奖励
        value = policy.value(h)
        # 回报用自举截断：展开末尾不跨出 H 步之外，避免更深的误差累积
        returns.append(r + gamma * value.detach())
        losses.append(-logp * (r + gamma * value.detach()))
    optimizer.zero_grad()
    torch.stack(losses).mean().backward()      # 示例：策略梯度的简化形式
    optimizer.step()
    return torch.stack(returns).mean().item()

解读：（1）潜状态序列完全由世界模型生成，环境中只发生起点的一次真实观测；复用倍率等于起点数量乘以 H。（2）回报在 H 步处截断并自举价值，展开长度是偏差控制的显式旋钮。（3）示意使用最简策略梯度形式，实际实现常以演员评论家（Actor-Critic）结构替换，关键结构（想象序列、自举截断）保持不变。

片段 2：优先级采样与重要性权重

import numpy as np

class PrioritizedBuffer:
    """按误差信号加权的采样器：高信息量样本获得更高被采概率。"""
    def __init__(self, capacity=100000, alpha=0.6, beta=0.4):
        self.alpha, self.beta = alpha, beta
        self.priorities = np.zeros(capacity, dtype=np.float32)
        self.data, self.ptr, self.size = [], 0, 0

    def add(self, transition, priority=None):
        # 新样本默认给当前最大优先级：未被评估前先保证至少被采样一次
        p = priority if priority is not None else self.priorities[:self.size].max(initial=1.0)
        if self.size < len(self.priorities):
            self.data.append(transition)
        else:
            self.data[self.ptr] = transition
        self.priorities[self.ptr] = p
        self.ptr = (self.ptr + 1) % len(self.priorities)
        self.size = min(self.size + 1, len(self.priorities))

    def sample(self, batch=64):
        p = self.priorities[:self.size] ** self.alpha
        probs = p / p.sum()
        idx = np.random.choice(self.size, size=batch, p=probs)
        # 重要性权重抵消分布偏移；除以最大权重做归一化，避免数值过大
        w = (self.size * probs[idx]) ** (-self.beta)
        w = w / w.max()
        return idx, w.astype(np.float32)

解读：（1）新样本获得当前最大优先级，保证覆盖后再按误差重排，避免未评估样本被永久埋没。（2）重要性权重在采样时返回，训练步把它乘到对应样本的损失上，这一步是消除估计偏差的关键。（3）β 可随训练从 0.4 线性升到 1.0，实现先快后准的过渡；实现上把 β 作为可变属性，每步由调度器更新即可。

片段 3：重分析刷新潜状态

@torch.no_grad()
def reanalyze(model, buffer, batch=256):
    """用当前编码器重算缓冲中历史观测的潜状态。
    设计意图：抑制编码器演化造成的目标漂移，让新旧样本共享同一表示口径。"""
    for idx in buffer.sample_indices(batch):
        obs, act, next_obs = buffer.get(idx)
        # 只刷新潜状态与动力学输入，原始观测与奖励保持不变
        z_new = model.encode(obs)
        z_next_new = model.encode(next_obs)
        buffer.update_latents(idx, z_new, z_next_new)
    return buffer.stats()                      # 返回刷新统计，供日志监控

解读：（1）重分析只改写派生字段，历史原始数据不动，随时可重复执行；分批处理把编码开销摊平到多个训练步。（2）监测刷新前后潜状态的分布距离，距离过大说明编码器漂移速度快于刷新频率，应缩短周期或减缓编码器更新速率。（3）该机制与在线学习（第 048 章）的锚点正则互补：锚点限制漂移速度，重分析消化已有的漂移。

常见坑

  • 想象展开过长：复用倍率上升但策略在自洽的模型误差环境里过拟合，真实环境成功率反降。修复：监控第 H 步误差，缩短展开或提高世界模型训练占比。
  • 优先级采样缺少重要性修正：高误差样本被反复学习，旧分布性能回落。修复：损失乘重要性权重，β 随训练上调。
  • 重分析频率过高：编码算力挤占训练预算，收益递减。修复：按潜状态分布距离触发刷新，替代固定周期。
  • 辅助损失压过主损失：重建任务占优，动力学预测退化。修复：辅助权重控制在 0.2 以内，监控分项梯度范数。
  • 横轴口径不统一：用梯度步数横轴对比机制，结论不可迁移。修复：所有对比统一到真实交互步数，报告达到目标成功率的步数。

练习与思考

  1. 推导：若单步模型误差为 ε1，说明展开 H 步后状态分布的偏差近似按 H·ε1 累积的直觉过程，并指出哪些系统会违反该近似。★★
    提示
    每步引入误差并沿动力学雅可比放大，线性化后偏差是各步误差贡献之和。混沌系统或接触密集系统雅可比范数大于 1，偏差按指数增长。
  2. 把优先级指数 α 从 0.6 提到 1.0，预测三件事的变化：高误差样本被采次数、旧分布性能、达到目标成功率所需真实步数，并说明验证方式。★★
    提示
    采样高度集中，旧分布性能回落（缺少修正时更明显），前期收敛更快但后期停滞。验证：分别画新旧任务成功率曲线并检查重要性权重分布。
  3. 设计实验比较三种样本效率机制（展开复用、优先级、重分析）的独立贡献：说明如何构造因子实验与控制真实交互预算。★★★
    提示
    2×2×2 因子设计，横轴固定为真实交互步数，每格三次随机种子。独立贡献用主效应表示，交互效应用同一预算下的曲线差距表示。
  4. 讨论：为什么辅助自监督的收益在小数据阶段最大？结合表示学习与控制容量的关系解释，并给出权重调度方案。★★
    提示
    小数据下表示结构主要靠自监督先验提供，数据增多后任务梯度自身足以塑造表示。权重可从 0.2 线性衰减到 0.02，跨训练过程监控梯度范数比值。

小结

  • 样本效率以真实交互步数为横轴度量，想象 rollout 把单条转移的复用倍率提升到十倍以上量级。
  • 复用倍率的代价是 O(H·ε1) 量级的偏差累积，展开长度按误差监控结果确定。
  • 优先级回放集中学习信号，重要性权重修正采样偏差，β 先低后高完成过渡。
  • 重分析用当前编码器刷新历史潜状态，与锚点正则互补，按分布距离触发。
  • 辅助自监督在数据稀缺阶段收益最大，权重与主损失同量级并随数据增长下调。
