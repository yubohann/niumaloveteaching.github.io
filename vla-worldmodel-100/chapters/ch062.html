第 062 章：VLA策略的贝叶斯推断

本章讲 VLA 策略在动作输出上的贝叶斯推断（Bayesian Inference）：用变分后验与证据下界让动作头输出概率分布，分解偶然与认知不确定性，并用后验采样驱动不确定性感知的决策。

  • 主题：策略网络 / 概率建模与不确定性
  • 关键公式：log p(a | o, l) ≥ Eq(θ)[log p(a | θ, o, l)] − KL(q(θ) ‖ p(θ))
  • 预计学时：50 分钟
  • 前置章节：第 061 章：联合训练中的异步更新

学习目标

  • 理解为什么接触丰富的操作任务需要分布化的动作输出，混合密度网络（Mixture Density Network, MDN）怎样表达多模态。
  • 掌握变分推断（Variational Inference）与证据下界（Evidence Lower Bound, ELBO）的推导脉络，理解拟合项与 KL 项各自管什么。
  • 掌握三条轻量后验近似路线：蒙特卡洛 dropout（MC Dropout）、贝叶斯反向传播（Bayes by Backprop）、拉普拉斯近似（Laplace Approximation）的取舍。
  • 能区分偶然不确定性（Aleatoric Uncertainty）与认知不确定性（Epistemic Uncertainty），实现后验采样与带保护阈值的动作选择。
  • 会诊断方差塌缩、KL 权重失衡、模式坍缩等问题，并能设计校准（Calibration）实验。

背景与动机

本节说明贝叶斯推断针对的失效模式：单点动作估计在多模态任务中被模式平均破坏。接触丰富的操作存在多种可行解，绕过障碍可以走左侧也可以走右侧，夹取可以从上方也可以从侧面。若动作头只回归条件均值，训练目标会把多个模式平均成一个位于模式之间的动作，该动作往往不可行。分布化输出解决模式平均问题；参数层面的后验进一步回答第二个问题：策略何时应该知道自己不确定，从而减速、探索或请求介入。联合训练中世界模型提供动作条件似然，贝叶斯动作头的后验与世界模型不确定性共同构成想象训练的权重来源。

核心原理

1. 动作输出为什么需要分布

设观测图像 o 与语言指令 l 条件下的动作分布为 p(a | o, l)。混合密度网络用 K 个高斯分量表示该分布：

p(a | o, l) = Σk=1..K πk(o, l) · N(a; μk(o, l), σk2(o, l)) πk 为模式权重（经 softmax 归一化），μk、σk 为第 k 个分量的均值与标准差

分量的加权组合覆盖多模态，每个分量的方差刻画局部噪声。推理时按模式概率采样一个分量，得到的动作落在某个真实模式内，规避了混合全部模式产生的不合法均值。这一层解决输出侧的问题，参数本身仍被当作确定量。

2. 数值算例：混合密度似然的手算

取动作维度为一维（夹爪开合宽度），分量数 K = 3，某观测下网络输出模式权重 π = (0.5, 0.3, 0.2)，三个高斯分量的均值为 0.0、0.6、−0.5，标准差为 0.10、0.20、0.15，示教动作为 a = 0.2。各分量在该点的密度为：

N(0.2; 0, 0.10) ≈ 0.540，N(0.2; 0.6, 0.20) ≈ 0.270，N(0.2; −0.5, 0.15) ≈ 0.00005 密度公式 N(x; μ, σ) = (1/(σ√(2π)))·exp(−(x−μ)2/(2σ2))

加权混合密度 p(a = 0.2) = 0.5 × 0.540 + 0.3 × 0.270 + 0.2 × 0.00005 ≈ 0.351，混合负对数似然约为 −log 0.351 ≈ 1.047。对照单点回归：模式均值加权后输出 μ̄ = 0.5 × 0 + 0.3 × 0.6 + 0.2 × (−0.5) = 0.08，该动作既不接近模式 1 的中心 0.0，也不接近模式 2 的中心 0.6，若抓取宽度容差为 ±0.05，则均值动作落在两个模式的间隙中，执行必然失败。数值结果给出三点解读：（1）混合似然只要求任一分量对真值给出高密度，模式 3 贡献不足万分之一，软分配自动把容量让给模式 1、2；（2）模式权重与分量密度共同决定似然，密度高但权重过低的分量无法救回样本；（3）模式平均的失败在数值上表现为似然对间隙区域无梯度贡献，训练目标自然阻止输出落入间隙。

3. 变分后验与证据下界

贝叶斯推断把动作头参数 θ 视为随机变量。先验 p(θ) 编码训练前的置信，实践中取标准正态；目标是后验 p(θ | D) ∝ p(D | θ)p(θ)，其中 D 为观测数据。后验不可解析时引入变分分布 q(θ) 近似，最大化证据下界：

log p(a | o, l) ≥ Eq(θ)[log p(a | θ, o, l)] − KL(q(θ) ‖ p(θ)) 第一项为期望对数似然（拟合数据），第二项为 KL 散度（约束后验不偏离先验）

重参数化技巧让期望项可导：把采样写成确定性变换

a = μθ(o, l) + σθ(o, l) ⊙ ε, ε ~ N(0, I) ε 的随机性与 θ 无关，梯度可穿过采样路径直达 μ 与 σ

ELBO 的两个项形成张力：似然项把后验拉向数据，KL 项把它拉回先验，训练在这一平衡点上收敛。联合训练时动作似然与世界模型重建项共享感知特征，拟合项自然融合两类监督。

4. 后验近似的三条工程路线

蒙特卡洛 dropout 把 dropout 的伯努利掩码视为变分分布，推理时保持 dropout 开启，多次前向的差异给出认知不确定性，改动量最小。贝叶斯反向传播把线性层权重参数化为对角高斯，用重参数化采样与闭式 KL 训练，保真度更高。拉普拉斯近似在最大后验点 θ* 处做二阶展开，q(θ) = N(θ*, Σ)，Σ = (−∇2log p(θ* | D))−1，工程上用对角 Fisher 矩阵近似以避开精确 Hessian。三条路线的保真度与开销同步递增：MC dropout 最省，贝叶斯反向传播居中，拉普拉斯近似需要额外的二阶统计估计。

5. 不确定性的分解与决策用途

预测熵可分解为两个来源：偶然不确定性由数据噪声引起，例如接触摩擦与传感器噪声，不随数据量增多而消失；认知不确定性由参数后验的分散程度决定，随数据覆盖扩大而收缩。样本间方差估计认知部分，头内输出的 σ 估计偶然部分。决策侧的用法：认知不确定性高时降低执行速度、触发数据采集；想象训练中按世界模型的认知不确定性给想象样本降权。不确定性的来源判断错误，探索与保护都会落在错误的目标上。

实现思路与设计

本节给出两级递进方案。第一级在输出层：动作头改为混合密度头，训练用混合负对数似然（对分量做 log-sum-exp 归约，保持数值稳定），推理按模式采样。第二级在参数层：把动作头末端一到两层线性层替换为平均场贝叶斯层，训练目标换成 ELBO。联合训练流程：每个 batch 计算世界模型重建损失与动作 ELBO，加权求和；想象 rollout 样本按世界模型认知不确定性加权。与第 061 章的差异：本章不改并发协议，只改输出分布与参数后验的表达。

设计决策：先输出层后参数层的递进路线

输出层分布直接改善多模态建模与噪声拟合，成本低，推理路径不变。参数后验提供认知不确定性，但每次后验采样需要一次完整前向，推理预算乘以采样数 S。两级收益因此可以分开验证。不确定性的来源决定它的用途，认知分量用于探索与保护，偶然分量用于噪声建模。

采样预算与训练调度的取值依据

  • 采样数 S 与方差估计误差。样本标准差估计的相对标准差约为 1/√(2(S−1))：S = 8 时约 27%，S = 16 时约 18%，S = 32 时约 13%。保护逻辑对噪声敏感时，取 S = 16 并对 epis 做系数 0.9 的指数滑动平均，等效地把有效样本量提高数倍。
  • KL 退火。训练前 10% 步数内令 β 从 0 线性升至目标值，避免训练早期 KL 项把后验压回先验、抑制动作拟合；退火结束后保持恒定，便于变更阶段单独观察 NLL 曲线。
  • 对数方差截断范围。动作经均值方差归一化到单位尺度后，[−5, 0] 对应标准差 [0.067, 1.0]，下端防塌缩，上端防用大方差逃避拟合；截面数据尺度差异大时按分位数重设，不直接迁移。
  • 保护阈值。在验证集上统计 epis 的分位数，取 90% 分位值作为 var_thresh 起点；阈值过小会让保护逻辑在正常样本上频繁触发，表现为动作持续偏软。
  • 先验标准差。标准正态先验是均匀无信息的默认选择；若已知目标域动作范围，可把先验标准差设为该范围量级，减少后期适配的 KL 代价。

关键代码与解读

以下片段以概率动作头与贝叶斯层的公开设计为参照，接口随版本演进。三个片段分别覆盖混合密度头、贝叶斯线性层与后验采样决策。

片段 1：混合密度动作头

import torch
import torch.nn as nn

class VariationalActionHead(nn.Module):
    """混合密度动作头：用 K 个高斯分量表达多模态动作分布。"""
    def __init__(self, feat_dim=512, act_dim=7, n_modes=5):
        super().__init__()
        self.n_modes, self.act_dim = n_modes, act_dim
        self.trunk = nn.Sequential(nn.Linear(feat_dim, 256), nn.SiLU())
        # 三组输出共享主干：logits 选模式，mu / sigma 描述模式形状
        self.logits = nn.Linear(256, n_modes)
        self.mu = nn.Linear(256, n_modes * act_dim)
        self.log_sigma = nn.Linear(256, n_modes * act_dim)

    def _params(self, feat):
        h = self.trunk(feat)
        mu = self.mu(h).view(-1, self.n_modes, self.act_dim)
        # 对数方差截断到 [-5, 0]：防塌缩到 0，也防用大方差逃避拟合
        sigma = torch.exp(self.log_sigma(h).clamp(-5.0, 0.0))
        sigma = sigma.view(-1, self.n_modes, self.act_dim)
        return self.logits(h), mu, sigma

    def sample(self, feat):
        # 重参数化采样 a = mu + sigma * eps，梯度可穿过随机路径
        logits, mu, sigma = self._params(feat)
        a = mu + sigma * torch.randn_like(mu)
        # 按模式概率抽取分量：决策只执行一个动作，混合全部模式会产生折中假动作
        k = torch.distributions.Categorical(logits=logits).sample()
        return a[torch.arange(a.shape[0]), k]

    def mean_sigma(self, feat):
        # 偶然不确定性标注：各模式 sigma 按模式概率加权平均
        logits, _, sigma = self._params(feat)
        w = logits.softmax(dim=-1).unsqueeze(-1)
        return (w * sigma).sum(dim=1)

解读：（1）logits、mu、sigma 三组输出共享主干，参数量增加有限。（2）对数方差参数化配合截断，同时解决数值稳定性与模式退化两个问题。（3）sample 中模式选择用离散采样，决策路径无需梯度；训练路径则通过混合似然对所有模式做软分配。

片段 2：平均场贝叶斯线性层与 ELBO 目标

import math
import torch.nn.functional as F

class BayesianLinear(nn.Module):
    """平均场贝叶斯线性层：权重为对角高斯后验，替换动作头末端线性层。"""
    def __init__(self, in_dim, out_dim, prior_std=1.0):
        super().__init__()
        self.prior_std = prior_std
        self.weight_mu = nn.Parameter(torch.zeros(out_dim, in_dim))
        # 初始后验标准差取小值：等价于初始化接近确定性的策略
        self.weight_log_sigma = nn.Parameter(torch.full((out_dim, in_dim), -3.0))
        self.bias_mu = nn.Parameter(torch.zeros(out_dim))

    def forward(self, x):
        # 训练与推理都重采样权重：多次前向即构成后验预测样本
        sigma = torch.exp(self.weight_log_sigma.clamp(-8.0, 0.0))
        w = self.weight_mu + sigma * torch.randn_like(self.weight_mu)
        return F.linear(x, w, self.bias_mu)

    def kl(self):
        # 对角高斯后验与 N(0, prior_std^2) 先验的闭式 KL：常数项一并计入
        sigma = torch.exp(self.weight_log_sigma.clamp(-8.0, 0.0))
        return ((sigma ** 2 + self.weight_mu ** 2) / (2 * self.prior_std ** 2)
                - 0.5 + math.log(self.prior_std)
                - torch.log(sigma + 1e-8)).mean()

def elbo_loss(nll, bayes_layers, beta=1e-3):
    """证据下界目标：动作拟合项加上 β 倍 KL 距离。"""
    kl = sum(layer.kl() for layer in bayes_layers)
    # β 太小退化为点估计，太大使后验贴回先验；从 1e-3 量级起步
    return nll + beta * kl

解读：（1）权重的均值与对数标准差都是可学习参数，采样发生在 forward 内部，对调用方透明。（2）KL 有闭式解，逐元素计算后取均值，量级与 NLL 可比，便于扫 β。（3）片段 1 的混合似然按 log-sum-exp 归约：−log Σk πkN(a;μk,σk)，避免逐模式最大值的硬分配造成模式坍缩。

片段 3：后验采样与不确定性感知决策

@torch.no_grad()
def posterior_action(head, feat, n_samples=8, var_thresh=0.05):
    """后验预测决策：期望动作执行，不确定性超限时收缩幅度。"""
    # 动作头内含贝叶斯层时，每次 sample 都会重采样权重；
    # 样本间差异同时包含参数不确定性与输出噪声两部分
    acts = torch.stack([head.sample(feat) for _ in range(n_samples)])
    mean_a = acts.mean(dim=0)                  # 期望动作：多模态下的折中解
    epis = acts.var(dim=0).sum(dim=-1)         # 样本间方差：认知不确定性
    alea = head.mean_sigma(feat).sum(dim=-1)   # 头内方差：偶然不确定性
    # 保护策略：认知不确定性越高，动作幅度收缩越强，表现为减速观望
    scale = torch.clamp(var_thresh / (epis + 1e-6), max=1.0)
    return mean_a * scale.unsqueeze(-1), epis, alea

解读：（1）采样数 S 决定方差估计质量，S = 8 是短推理预算下的常用折中。（2）两类不确定性分开返回，上游可以分别用于保护（epis）与噪声建模（alea）。（3）动作幅度收缩是可选的保护手段，也可以把 epis 作为触发条件交给高层决策切换为谨慎模式。

常见坑

  • 方差塌缩：σ 趋近 0，负对数似然出现除零与对数爆炸，症状为损失尖刺。修复：对数方差参数化并截断上下界，似然项加数值稳定量。
  • KL 权重失衡：β 过大时后验贴回先验，动作趋于保守平均；β 过小时退化为最大后验点估计，认知不确定性名存实亡。修复：监控 NLL 与 KL 的量级比，先固定 NLL 尺度再扫描 β。
  • 模式坍缩：混合似然中部分分量长期得不到样本，πk 趋近 0，有效容量只剩一两个模式。修复：软分配似然、对低权重分量定期重初始化、必要时加入负载均衡正则。
  • 两类不确定性混淆：把输出 σ 大当作参数不确定，探索决策采集到重复无效数据。修复：探索只用样本间方差，σ 只进入噪声建模与似然。
  • MC 采样数不足：S = 2 时方差估计抖动，保护逻辑导致动作幅度忽大忽小。修复：S 取 8 以上，并对 epis 做指数滑动平均。

练习与思考

  1. 数值计算：先验为标准正态，后验为对角高斯，参数均值 0.2、标准差 0.5。代入 KL 闭式解计算 θ 与该先验的 KL 值，并与片段 2 的实现对照。★
    提示
    KL = 0.5(σ2 + μ2 − 1 − 2log σ) = 0.5(0.25 + 0.04 − 1 + 1.386) ≈ 0.338。
  2. 把片段 2 的 β 从 1×10−3 改为 1.0，预测训练损失构成的变化（NLL 项与 KL 项的量级）、动作多模态性与成功率的变化。★
    提示
    KL 项主导后，后验靠近先验，动作输出趋同，NLL 变差、成功率下降。合理区间通常落在 1e-4 到 1e-2。
  3. 推导题：用 Jensen 不等式证明 ELBO 是边缘对数似然 log p(a | o, l) 的下界，并写出下界与真值的差（即 KL(q(θ) ‖ p(θ | D))）。★★
    提示
    把 log p(a|o,l) 写成 log Eq[p(a|θ)p(θ)/q(θ)]，对 log 用 Jensen：≥ Eq[log p(a|θ)] − Eq[log q(θ)/p(θ)]，差值即后验变分间隙。
  4. 实验设计：在三模态到达任务上比较单点回归头、混合密度头、混合密度头加贝叶斯末端三种配置，报告成功率、动作多模态覆盖率与校准误差（Expected Calibration Error, ECE）。★★
    提示
    MDN 改善多模态覆盖，贝叶斯末端进一步改善校准；ECE 按置信度分桶计算。
  5. 设计题：为想象 rollout 训练设计不确定性加权协议，要求说明世界模型认知不确定性如何估计、样本权重如何映射、怎样防止权重过早坍缩为零。★★★
    提示
    用世界模型集成的输出分歧估计认知不确定性；权重取 exp(−λ·分歧) 并设置下界，避免全零；对分歧做滑动平均以稳定权重。

小结

  • 动作输出需要分布表达：混合密度头用 K 个高斯分量覆盖多模态，按模式采样避免折中假动作。
  • 变分推断用 ELBO 近似后验：拟合项拉向数据，KL 项约束偏差，重参数化让采样路径可导。
  • 三条后验近似路线按开销递增排列：MC dropout、贝叶斯反向传播、拉普拉斯近似；先输出层、后参数层是稳妥的递进顺序。
  • 不确定性分两类：样本间方差对应认知部分，用于探索与保护；头内 σ 对应偶然部分，用于噪声建模。
  • 下一章把分布思想从动作推广到状态空间：世界模型的图结构表示，用节点与关系建模物体交互并保持置换等值性。
