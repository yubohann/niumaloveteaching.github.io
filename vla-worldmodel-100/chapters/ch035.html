第二篇 · 联合训练进阶与策略能力

第 035 章：VLA策略的闭环控制

动作块一次生成多步，执行完再规划会漂移；本章讲清滚动时域的重规划节奏、反馈误差的稳定性条件，以及用世界模型做延迟补偿的方法。

  • 主题：闭环控制（closed-loop control） / 滚动时域（receding horizon）
  • 关键公式：et+1 = (1 − K) et + wt（误差动力学）；重规划间隔与延迟匹配约束
  • 预计学时：50 分钟
  • 前置章节：第 034 章

学习目标

  • 理解开环执行与闭环反馈的本质差异：误差是否受控取决于回路设计。
  • 掌握滚动时域控制的三要素：预测窗口、执行步数与重规划触发条件。
  • 掌握反馈增益的稳定性分析，会用误差动力学判断震荡与迟钝两种失效。
  • 会用世界模型前滚补偿观测延迟，并评估补偿误差与直接使用陈旧观测的取舍。
  • 能诊断执行整块不重规划、重规划过频与观测异常直接进策略三类问题。

背景与动机

动作分块让策略一次输出 Hc 步动作，天然接近开环执行：若把整块动作执行完再重新观测规划，执行期间的模型误差、外部扰动与执行偏差都不会被反馈修正，块尾的状态偏离在下一轮规划时已经发生，轨迹出现周期性漂移与折线。

闭环控制（closed-loop control）把执行回路闭合：只执行块的前 k 步，用新观测重新规划，滚动推进（receding horizon）。反馈让误差受控，代价是推理频率上升、动作衔接可能抖动。重规划节奏、延迟补偿与观测质量控制共同决定回路稳定性。

本章与第 034 章的衔接：语言条件世界模型提供条件预测，闭环回路消费该预测做前滚补偿；与第 036 章的衔接：多步误差修正降低预测偏差，直接提升闭环跟踪质量。

核心原理

1. 开环与闭环的误差动力学

把跟踪误差记为 et。开环执行下误差按扰动累加，无恢复机制；闭环反馈下误差满足一阶递推：

et+1 = ( 1 − K ) et + wt K 为反馈增益（0 至 1 区间对应比例修正），wt 为各周期扰动；离散系统的稳定条件为 0 < K < 2

直觉：K = 1 时一步消除误差（理想修正）；K 小于 1 时误差按几何速率衰减；K 落在 1 与 2 之间时误差符号交替、幅度衰减，产生震荡；K 超过 2 后幅度逐周期放大；K 接近 0 时衰减极慢，响应迟钝。策略输出的动作修正量对应 K 的大小：过于激进的修正策略（对误差反应过度）在闭环中等价于 K 大于 1，表现为围绕目标的高频振荡。闭环调试的核心是校准修正强度，让等效增益落在欠阻尼与过阻尼之间的合适区间。

递推式的来源可以做一步推导：每周期策略按当前误差的 K 倍做反向修正，误差被压掉 K · et，同时扰动注入 wt，于是 et+1 = et − K et + wt。把递推展开为几何级数，常数扰动 w 下的稳态误差为 e∞ = w · Σi≥0 (1 − K)i = w / K，成立条件是 |1 − K| 小于 1，即 0 小于 K 小于 2。

数值算例：扰动 w = 0.01（归一化误差单位）。K = 0.2 时稳态误差 0.05；K = 0.5 时 0.02；K = 1 时 0.01，一步消除后由新扰动补充。收敛速度方面，误差衰减到初值 1% 所需周期数为 ln 0.01 / ln|1 − K|：K = 0.2 约 21 个周期，K = 0.5 约 7 个，K = 0.8 约 3 个。K 落在 1 与 2 之间时衰减同样成立但符号交替，K = 1.5 时序列为 1.0、−0.49、0.255、−0.118…，收敛轨迹带明显振荡。K 超过 2 后 |1 − K| 大于 1，误差每周期放大 |1 − K| 倍，K = 2.5 对应每周期放大 1.5 倍，10 个周期后幅度膨胀约 58 倍。

K 区间误差形态症状
0 至 0.3单调衰减，速度慢响应迟钝，扰动恢复慢
0.3 至 1单调衰减，速度适中跟踪性与平滑性平衡
1 至 2交替衰减，带振荡稳态偏差小但轨迹抖动
2 及以上指数发散高频振荡，回路失稳

等效增益与策略的修正强度一一对应：策略对误差的修正量除以误差即 K 的代理量，可以在闭环日志中逐周期估计，作为调参的观测变量；估计窗口与重规划间隔对齐，跨块统计会把衔接过渡段混入，得到偏低的混合估计。

2. 滚动时域：窗口、执行步数与重规划

滚动时域的循环结构：预测窗口 H，每轮执行 k 步（k ≤ H），然后基于新观测重新规划。参数关系：

重规划间隔 = k · Δt ，单元成本 ≈ Cinfer / k ，跟踪滞后 ≈ (k / 2) · Δt Δt 为控制周期；k 增大降低推理频率但增加反馈滞后，k 减小相反

k 的取值由三方面约束共同决定：推理预算（推理耗时必须小于 k·Δt，预留余量）；环境变化速度（快速动态环境需要更小的 k）；动作平滑性（k 过小会让块间衔接过密，抖动上升）。经验上 k 取 H 的 1/4 至 1/2。重规划触发不必严格按固定 k：当跟踪误差超过阈值、或观测出现大变化时提前触发，平稳阶段允许执行更长，这种事件驱动结构在效率与质量间取得更优平衡。

数值算例：Δt = 20 ms、k = 4 时重规划间隔 80 ms，平均跟踪滞后约 (4 / 2) × 20 = 40 ms；把滞后折算成回路相位，1 Hz 轨迹分量对应 14.4°、2 Hz 对应 28.8°，与延迟预算的量级一致。k = 1 时滞后降到 10 ms，推理频率升到四倍；k = 8 时滞后 80 ms，2 Hz 分量的相位损失约 57.6°，跟踪误差随之上升。滞后与增益存在耦合：滞后越大，同一增益下的稳定裕度越小，调参顺序是先按推理预算固定 k 的下限，再在闭环中校准修正强度。

块间衔接的数值约定：新块与旧块的重叠区长度为 k 步（k = 4、Δt = 20 ms 对应 80 ms），衔接权重按重叠位置线性过渡，第 i 步取新块权重 i / (k + 1)、旧块权重为 1 减去该值，两者之和恒为 1；线性过渡让动作的一阶差分连续，避免硬切换造成速度跳变。若新旧块差异异常大（大扰动后的重规划），折中过渡会把中间动作拉向两个目标之间，此时改为从新块起点直接接管并依赖速率限制平滑。

3. 观测时效性与世界模型前滚补偿

推理耗时 d 个周期，决策时拿到的观测已经过时。两种处理：直接使用陈旧观测（把延迟当作既定的固有条件，训练时加入延迟增强），或用世界模型把状态前滚到当前时刻：

ẑt = fθ( zt−d, at−d 至 at−1 ) ，补偿状态用于策略输入 前滚使用已执行的动作序列，d 步的计算开销与延迟成正比

补偿的收益与风险：d 较小（1 至 3 个周期）时收益明显，状态估计误差低于陈旧观测本身的偏差；d 较大时前滚误差累积（世界模型的多步预测误差），补偿可能不如直接使用观测。选择判据是两条误差的比较：前滚误差估计（用不确定性输出近似）小于观测陈旧导致的动作偏差时启用补偿，否则关闭。观测异常（丢帧、跳变）单独处理：与预测状态的偏差超过阈值时，丢弃该观测或用前滚状态替代，避免异常值直接驱动策略。阈值标定用验证集上"观测与一步预测状态的偏差"分布，取 99 分位作为参考（示例：均值 0.02、99 分位 0.05）；连续两帧超限才触发隔离，单帧超限只降低权重，避免检测器误报引发不必要的重规划。

数值算例：设状态每周期自然漂移 0.02（归一化单位），延迟 d = 3 时陈旧观测的偏差约 0.06；世界模型单步误差标准差 0.01、随机误差独立时前滚 3 步的误差按 √d 增长约 0.017，补偿净收益约 0.043。延迟升到 d = 6 时前滚误差约 0.024，陈旧偏差 0.12，补偿仍占优；但若模型存在系统失配（单步偏差 0.02 随步数线性累积），d = 6 的前滚误差升到 0.12，与陈旧偏差持平，此时应关闭补偿。开关阈值因此无法固定为某个步数，它由两条误差曲线的交点给出，随模型版本更新重新标定。

4. 闭环评估与消融设计

闭环性能无法从开环指标外推：开环误差小的模型在闭环中可能因修正过强而震荡，开环误差大的模型可能因保守修正反而稳定。评估必须包含闭环试验：固定初始状态集，记录跟踪误差曲线、动作平滑度（二阶差分）与任务成功率。消融变量：k 的取值、是否前滚补偿、重规划触发方式（固定周期或事件驱动）。闭环指标中最有诊断价值的是误差曲线的形态：单调收敛表示增益合适，等幅震荡表示增益过大，缓慢漂移表示增益不足或存在未补偿的系统偏差。

闭环评估建议补充两条标准测试：阶跃测试（目标突然移动）与扰动测试（执行中途施加可测外力）。阶跃测试给出上升时间与超调量，K = 0.5 的回路约 4 个周期进入目标带、基本无超调，等效 K = 1.5 的回路超调明显并以振荡方式收敛；扰动测试给出恢复时间与稳态偏差。两类测试结合可以区分失配来源：恢复慢且稳态偏差不为零指向系统偏差或增益不足，振荡收敛指向增益偏大。两组测试都应在同一初始状态集上重复多个种子，报告误差曲线族；单条曲线会掩盖种子间的波动。

实现思路与设计

闭环控制回路由观测处理、状态估计、重规划调度与执行四段组成。与第 034 章的差异：034 设计条件预测，本章设计消费预测的控制回路。

  1. 观测处理：时间戳对齐；异常检测（与预测状态偏差超阈值时标记）；丢帧用前滚状态补齐。
  2. 状态估计：按延迟量决定是否前滚；前滚使用已执行动作序列与条件世界模型。
  3. 重规划调度：默认每 k = 4 步重规划一次；跟踪误差超阈值或观测剧变时提前触发。
  4. 执行：块间用插值衔接；动作速率限制按执行器规格设定。

设计决策：为什么重规划触发要事件驱动与周期混合？

纯周期触发在平稳阶段浪费推理，在扰动阶段响应不足。加入误差阈值触发后，平稳阶段自动拉长执行段，扰动出现时立即重规划，平均推理频率下降而响应质量上升。实现上只需在每步检查误差与阈值，触发条件并入同一调度器，复杂度增加很小。

事件驱动的节省可以量化：固定 k = 4 时每 4 步一次推理，稳态推理占空比约 25%；加入误差阈值后，平稳段执行段通常拉长到 8 至 12 步，占空比降到 8% 至 12%，扰动段仍按 2 至 4 步触发。整体推理次数下降约一半，响应质量由阈值保证。阈值取静态误差带的两倍作为起点：过低会让系统退化为每步重规划，过高则与纯周期触发无异。

速率限制的数值形态：执行器额定角速度 2 rad/s、控制周期 20 ms 时，单步允许的最大角增量约 0.032 rad（额定值的 80%），速率限制的斜率参数按此换算写入配置，更换执行器只改这一个数。限制过松失去保护作用，过紧会让策略输出被系统性削减、跟踪滞后增大；标定方法是从紧限制出发逐步放宽，到刚好不再触发截断的位置再回退一档。

关键代码与解读

以下片段参照公开的滚动时域控制实现设计，版本中立；PyTorch 与 NumPy 风格，接口随版本演进。

片段 1：闭环滚动执行主循环

class RecedingHorizonLoop:
    """滚动时域：执行 k 步、重规划、前滚补偿与异常隔离在同一循环内完成。"""
    def __init__(self, policy, world_model, k=4, horizon=16, err_thresh=0.05):
        self.policy = policy
        self.world_model = world_model
        self.k = k
        self.horizon = horizon
        self.err_thresh = err_thresh
        self.plan = None                          # 当前动作块与对应起始时刻

    def step(self, obs, tick, last_actions):
        if self.plan is None or tick % self.k == 0 or self._error_large(obs):
            # 前滚补偿：用已执行动作把旧观测状态推进到当前时刻
            z = self.world_model.encode(obs)
            z = self.world_model.roll_forward(z, last_actions)
            self.plan = self.policy.act(z, horizon=self.horizon)
        a = self.plan.pop(0) if self.plan else None
        # 动作速率限制：与上一动作的差幅超过上限时截断，保护执行器
        return self._rate_limit(a, last_actions[-1] if last_actions else None)

    def _error_large(self, obs):
        # 事件驱动触发：观测与上一预测状态的偏差超阈值时提前重规划
        pred = self.world_model.predict_obs()
        return float((obs - pred).abs().mean()) > self.err_thresh

    def _rate_limit(self, a, prev):
        if a is None or prev is None:
            return a
        delta = (a - prev).clamp(-0.1, 0.1)       # 速率上限按执行器规格设定
        return prev + delta

解读：（1）重规划条件把周期与事件合并：tick 取模判断周期触发，_error_large 判断事件触发；（2）前滚补偿在重规划入口统一执行，动作历史来自执行侧记录，保证推演的起点与真实一致；（3）速率限制放在最后一道，任何来源的动作都经过同一整形，避免异常动作直达执行器；（4）计划队列为空时返回 None，上层按保持策略处理，该边界在国内常见系统中容易被忽略。

片段 2：延迟补偿的取舍判断

@torch.inference_mode()
def compensate_or_not(world_model, z_stale, acts_since, delay_ticks, thresh=3):
    """延迟补偿决策：前滚误差估计小于陈旧误差时启用前滚。"""
    if delay_ticks <= 1:
        return z_stale, "直接使用"                 # 一个周期内的延迟影响可忽略
    z_roll, unc = world_model.roll_forward_with_uncertainty(z_stale, acts_since)
    # 前滚误差用不确定性输出近似：超过延迟容忍区间则放弃补偿
    if unc.mean() > world_model.unc_calibrated_bound(delay_ticks):
        return z_stale, "放弃补偿"
    return z_roll, "启用前滚"

解读：（1）延迟不超过一个周期时直接使用观测，前滚收益低于其引入的误差；（2）前滚误差用校准后的不确定性上界比较，与第 031 章的校准流程衔接：未校准的 σ 不能用于该决策；（3）返回决策标签便于日志统计各类场景的触发比例，为参数调整提供依据；（4）该函数是纯决策逻辑，不改变状态，测试与线上推理共用同一实现。

常见坑

  • 执行整个动作块不重规划：块尾漂移明显，轨迹呈折线。症状是块边界处跟踪误差周期性跳升。修复：每 k 步重规划，k 取块长的 1/4 至 1/2。
  • 延迟未补偿：执行器看到的是一到多个周期前的决策，快速动态任务中表现为超调与震荡。修复：按延迟量前滚补偿，或训练时把延迟注入状态（历史动作加时间戳）。
  • 重规划过频：每步推理让块间衔接过密，动作抖动、推理预算超支。修复：周期与事件混合触发，平稳阶段拉长执行段；平滑衔接区用插值过渡，硬切换会带来速度跳变。
  • 观测异常直接进策略：丢帧或检测跳变让策略输出异常动作。修复：观测与预测状态的偏差检测，超阈值时丢弃观测并用前滚状态替代。
  • 用开环指标代替闭环指标：开环预测误差改善被当作闭环性能提升，实际因修正过强而震荡。修复：闭环试验固定初始状态集，报告误差曲线形态，单点数值会掩盖震荡与漂移。

练习与思考

  1. 把执行步数 k 从 4 减到 1（每步重规划）。预测跟踪误差、动作抖动与推理频率三项指标的变化，并指出该配置适用的任务类型。★
    提示
    跟踪误差在快速动态任务中下降，抖动与推理频率上升；适用高动态、高精度且推理预算充足的任务。慢速任务中收益小、成本高。
  2. 推导：误差递推 et+1 = (1 − K)et + wt 在常数扰动 w 下的稳态误差，并说明 K 取 0.5、1.5、2.5 三种情形的响应形态。★★★
    提示
    稳态误差为 w/K；K = 0.5 时误差缓慢衰减到 2w，K = 1.5 时交替收敛但稳态为 0.67w、带震荡，K = 2.5 时不满足稳定条件，误差幅度指数增长。
  3. 设计前滚补偿的消融实验：延迟分别设为 1、3、5 个周期，补偿开关两种设置，预测四组以上的闭环指标组合，并给出启用补偿的判据。★★
    提示
    延迟 1 周期时补偿收益微小；3 周期时补偿显著降低跟踪误差；5 周期时前滚误差累积加快，收益收窄，模型系统失配明显时转负。判据是延迟量与模型可预测时域 k* 的比较。
  4. 构造一个观测异常场景（连续两帧丢帧），说明无隔离机制时闭环的行为退化过程，并给出修复后的预期指标变化。★★
    提示
    丢帧时若沿用旧观测，策略把已过时状态当当前状态，修正方向错误、误差放大；隔离机制用前滚状态替代后误差曲线连续。预期变化是跟踪误差峰值的显著削平。
  5. 计算：扰动 w = 0.01 时 K 取 0.2、0.5、1.0、1.5 的稳态误差；再求 K = 0.5 与 K = 1.5 时误差衰减到初值 1% 所需的周期数，解释两者数值相同而形态不同的原因。★★
    提示
    稳态误差为 w / K：0.05、0.02、0.01、约 0.0067。衰减周期数由 |1 − K| 决定，K = 0.5 与 K = 1.5 的 |1 − K| 同为 0.5，都需要约 6.6 个周期；前者符号不变（单调），后者符号交替（振荡）。选择按应用对平滑性与稳态精度的偏好取舍。

小结

  • 开环执行让误差自由累积，闭环反馈把误差动力学约束在一阶递推形式内。
  • 滚动时域由窗口、执行步数与触发条件三要素定义，k 取窗口的 1/4 至 1/2 是常见起点。
  • 反馈增益的等效值决定误差收敛形态：过大震荡、过小迟钝，闭环试验是唯一可靠的调参依据。
  • 延迟补偿按前滚误差与陈旧误差的比较决策，校准后的不确定性是判断依据。
  • 观测异常通过偏差检测与前滚替代隔离，避免污染策略输入。
