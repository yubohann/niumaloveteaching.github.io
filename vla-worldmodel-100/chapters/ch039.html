第二篇 · 联合训练进阶与策略能力

第 039 章：世界模型的动态学习率调整

联合训练中骨干、动力学、动作头与语言编码器的梯度尺度各不相同；本章讲清参数组差异化设计、预热与退火的调度原理，以及基于验证信号的反应式调整。

  • 主题：学习率调度（learning rate schedule） / 多模块协同训练
  • 关键公式：warmup 线性上升；余弦退火 ηt = ηmin + (ηmax − ηmin)·(1 + cos(πt/T))/2；平台检测
  • 预计学时：50 分钟
  • 前置章节：第 038 章

学习目标

  • 理解自适应优化器下"有效步长"的构成，能解释为什么相同学习率在不同模块上产生不同的实际更新量。
  • 掌握参数组差异化设计：骨干、动力学核心、解码头与语言编码器各自的学习率比例。
  • 掌握预热（warmup）与余弦退火（cosine annealing）的调度形式与适用条件。
  • 会设计基于验证信号的反应式调整：平台检测、梯度范数监控与想象误差反馈。
  • 能诊断预热失效、调度与批量不同步、动力学学习率过大三类问题。

背景与动机

联合训练的参数量集中在四类模块：视觉骨干、世界模型动力学、动作头与语言编码器。四类模块的梯度统计差异显著：预训练骨干的梯度经过大量数据打磨、范数较小；新初始化的解码头梯度初期很大；语言编码器在对比损失下梯度方向嘈杂。用单一学习率训练时，某个模块要么欠拟合要么过冲，训练曲线上表现为"一个指标稳定、另一个震荡"。

学习率调度解决两件事：训练早期的稳定性（预热避免随机初始化的大梯度破坏预训练权重）与训练后期的收敛质量（退火让参数在低谷附近精修）。联合训练还多一层约束：世界模型的学习率直接影响想象轨迹的稳定性，而策略的优化目标依赖想象轨迹，两者通过更新节奏耦合。

本章与第 037 章的衔接：RL 集成的更新频率比决定"多久更新一次"，学习率决定"每次更新多大"，两者共同决定模块间相对步速；与第 040 章的正则化衔接：调度与正则共同控制有效容量。

核心原理

1. 有效步长与模块间的隐式不平衡

Adam 类优化器的更新近似为该模块梯度方向上的等范数步：

Δθ ≈ − η · m̂ / ( √v̂ + ε ) ，单步范数近似与 η 成正比、与梯度尺度弱相关 m̂、v̂ 为一阶与二阶矩估计；归一化让 Adam 对梯度尺度不敏感，但仍受梯度方向一致性影响

Adam 的归一化抵消了纯尺度差异，却带来新的不平衡：梯度方向一致性高的模块（稳定的预测任务）二阶矩小，实际步长接近满额；梯度方向嘈杂的模块（对比对齐、探索中的策略）二阶矩大，有效步长被压缩。因此"所有模块同一学习率"在实践中等价于对嘈杂模块欠训练、对稳定模块过训练。参数组比例的设定依据是各模块梯度的信噪比，信噪比高的模块给更小的学习率。

单步范数的上界可以解析：Adam 的更新在偏差修正后满足 ‖Δθ‖ ≤ η · (1 − β1) / √(1 − β2)。常用超参 β1 = 0.9、β2 = 0.999 对应系数 (1 − 0.9) / √0.001 ≈ 3.16，训练最初几步的有效步长可达名义学习率的 3 倍以上。这个放大作用在预训练权重上尤其危险：二阶矩估计尚未稳定，个别方向的巨大更新会破坏已打磨好的特征。预热期的线性上升让二阶矩统计在低步长下完成收敛，代价只是总步数中几个百分点的进度。

2. 预热与退火的调度形式

两类基础调度组合成常用曲线。预热阶段线性上升：

ηt = ηmax · t / Twarm ，t 不超过 Twarm Twarm 常取总步数的 3% 至 10%；预训练权重、大批量、Adam 优化器都需要预热期稳定二阶矩

退火阶段余弦形式：

ηt = ηmin + ( ηmax − ηmin ) · ( 1 + cos( π · t / Ttotal ) ) / 2 ηmin 取峰值的 1% 至 10%；余弦曲线在后期变化平缓，参数在低谷附近停留更久

数值算例：基准 ηmax = 1 × 10−4、ηmin = 1 × 10−5、总步数 10 万、预热占 5%（5000 步）。第 5000 步学习率为 1 × 10−4；退火进行到一半（约第 52500 步）时 η = 1 × 10−5 + 9 × 10−5 × 0.5 = 5.5 × 10−5；进度 0.25 与 0.75 处分别为约 8.68 × 10−5 与 2.32 × 10−5，两端平缓、中段变化快，与余弦函数的导数形态一致。末期保留 1 × 10−5 供持续适应新数据。

替代方案是一次循环（one-cycle）：上升、平台、下降三段组合，追求固定步数下的快速收敛；以及分段常数加平台触发。选择依据是训练预算是否固定：固定预算用余弦或一次循环，开放预算用平台触发的反应式调度。联合训练还会在退火之外补充一个常驻的稳定期（恒定为峰值 10%），防止世界模型在训练最末期因学习率过小停止适应新数据。四种调度形态的对照：

调度收敛速度稳定性适用预算
恒定学习率中末期易震荡试跑与基线
预热 + 余弦中，末期平稳高固定步数训练
一次循环快中，依赖退火段质量固定预算的短周期任务
平台触发视数据而定高，需要冷却期开放预算

批量与学习率的缩放规则：批量扩大 k 倍时，线性规则把学习率乘 k，平方根规则乘 √k。批量 256 扩到 1024（4 倍）时线性规则取 4 倍、平方根规则取 2 倍。经验上小批量用线性规则、大批量用平方根规则并配合更长的预热；联合训练改动批量时必须同步重算调度曲线的总步数，让所有模块在同一时基上退火。

3. 参数组比例

四类模块的起点比例（以骨干为基准 1 倍）：

模块相对学习率理由
视觉语言骨干1×（如 1×10−4）预训练充分，需保护
世界模型动力学1× 至 2×与骨干同源起步，稳定性优先
动作头 / 解码头3×随机初始化，需要快速形成输出分布
语言编码器0.5×对比梯度嘈杂，抑制更新幅度

学习率与更新频率的乘积核算：世界模型每 4 步更新一次、学习率 2 × 10−4，与每 2 步更新一次、学习率 1 × 10−4，对每步数据产生的期望更新量分别为 2 / 4 = 0.5 与 1 / 2 = 0.5，相对步速相同；两种配置的差别在梯度噪声的累积方式，低频大步配置的更新方向更陈旧，稳定性略差。参数变更记录应同时包含学习率与更新频率，避免两者分别漂移。

预热比例的经验边界：低于总步数 3% 的预热在预训练骨干上常常不足，个别批次出现损失尖峰；超过 10% 会明显压缩高学习率区间的时长，总预算小的任务尤其敏感。预热是否充分的直接证据在前数千步的损失曲线上：健康曲线单调下降且无反复尖峰；预热不足时曲线出现阶梯状回跳，回跳位置伴随梯度范数的量级尖峰。

比例的调整信号来自逐模块梯度范数与损失曲线的联合监控：某模块损失长期高于同组其他模块且梯度范数偏低，说明学习率不足；损失震荡且梯度范数尖峰频繁，说明学习率过大。世界模型的动力学核心另有特别约束：其学习率影响想象轨迹的稳定性，调大后若想象回报曲线抖动加剧，即使训练损失下降也应回调。动力学学习率的验收指标落在下游：想象与真实回报差值的稳定性。

与权重衰减的交互：解耦权重衰减（AdamW）在更新中附加 −ηλθ 项，学习率大的模块衰减也快。动作头学习率是骨干的 3 倍时，同样的 λ 让动作头参数以约三倍速度向零收缩，输出层收缩过强会让输出分布偏平。工程上给高学习率模块单独降低 λ（例如减半），或把偏置与归一化参数排除在衰减之外。

监控的三个口径：梯度范数记录中位数与 95 分位，中位数反映典型更新量、95 分位反映尖峰强度；损失曲线按模块分组记录（视觉对齐、动力学预测、动作回归、语言对齐），组间的"剪刀差"（一组下降、另一组上升）是参数组比例失衡的最早信号；想象回报差值按 100 步窗口滑动平均，避免单窗口噪声触发误判。

参数组的拆分粒度需要克制：四组是起点，继续按层或按张量细分会让学习率搜索空间迅速膨胀，调参成本超过收益；确有单层敏感的特殊情况（例如动作输出的最后一层）时用乘子单独处理，并在训练记录中标注例外。跨版本对比时固定分组定义，分组变更按模型结构变更对待。

4. 反应式调整与平滑

固定调度之外，基于验证信号的反应式调整提供第二层保护：验证损失在窗口内不再改善时按比例下调学习率。三个工程细节决定其效果：

  • 检测窗口：窗口长度应覆盖损失曲线的噪声周期，过短会频繁触发；常用为 500 至 2000 步。
  • 下调比例与下限：每次下调至 0.3 至 0.5 倍，设全局下限防止学习率趋零。
  • 平滑与滞后：对验证损失取移动平均后再比较，并且下调后设置冷却期，避免连续触发。

平台触发的数值形态：初始学习率 1 × 10−4、下调比例 0.4、下限为初始值的 5%（5 × 10−6）。连续触发时学习率序列为 1 × 10−4、4 × 10−5、1.6 × 10−5、6.4 × 10−6，第四次触发时触及下限并按 5 × 10−6 截断；每次触发之前至少经过一个检测窗口加一个冷却期（默认 1000 + 2000 步），一万步内最多触发三次。平台调整与退火曲线的叠加需要在调度器层面统一实现（把触发降幅折算为衰减因子并与曲线相乘），两个独立的写入者会互相覆盖，这是实现时最容易出错的位置；触发事件写入训练记录后，复盘时核对每次下调对应的验证损失改善量，改善量低于阈值的触发会被识别为误触发。

除验证损失外，可选信号还有梯度范数（尖峰频率）与不确定性输出（校准漂移）。多信号并用时需要避免同时触发多个变量调整，一次训练周期内只动一个参数，是排查归因的基本纪律。

实现思路与设计

学习率系统由参数组定义、调度器、监控与调整策略四部分组成。与第 038 章的差异：038 调整损失权重与数据构成，本章调整优化的步长结构。

  1. 参数组定义：四个模块四组，按上表比例乘以基准学习率；解耦的权重衰减（AdamW）单独配置。
  2. 调度器：线性预热（总步数 5%）接余弦退火（降至峰值 10%）；编写为按步计算的纯函数，便于复现。
  3. 监控：按模块记录梯度范数的中位数与 95 分位、损失曲线、想象与真实回报差值。
  4. 调整策略：默认固定调度；验证平台触发时按比例下调并进入冷却期；每次调整写入训练记录供复盘。

关键代码与解读

以下片段参照公开的训练调度实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：参数组与预热余弦调度

import math
import torch

def build_param_groups(model, base_lr=1e-4):
    """四类模块四组学习率：比例依据梯度信噪比设定。"""
    return [
        {"name": "backbone", "lr": base_lr,
         "params": model.backbone.parameters()},
        {"name": "dynamics", "lr": base_lr * 1.5,
         "params": model.world_model.dynamics.parameters()},
        {"name": "heads", "lr": base_lr * 3.0,
         "params": model.action_head.parameters()},
        {"name": "language", "lr": base_lr * 0.5,
         "params": model.language_encoder.parameters()},
    ]

def warmup_cosine(step, total, warmup_ratio=0.05, min_ratio=0.1):
    """线性预热接余弦退火；返回学习率倍数，纯函数便于复现。"""
    warm = max(1, int(total * warmup_ratio))
    if step < warm:
        return step / warm                       # 预热期线性上升
    progress = (step - warm) / max(1, total - warm)
    progress = min(progress, 1.0)
    # 余弦曲线：1 降到 min_ratio，后期变化平缓
    cos_term = (1 + math.cos(math.pi * progress)) / 2
    return min_ratio + (1 - min_ratio) * cos_term

def make_scheduler(optimizer, total_steps):
    # LambdaLR 按倍数缩放各组基准学习率，组间比例保持不变
    return torch.optim.lr_scheduler.LambdaLR(
        optimizer, lambda s: warmup_cosine(s, total_steps))

解读：（1）四组学习率用同一条调度曲线缩放：比例关系在整个训练过程中保持，避免组间比例随调度漂移；（2）LambdaLR 记录初始学习率并逐组相乘，实现上只需一个调度器；（3）调度写成纯函数，步数与曲线形态可回放验证，与训练框架的日志对照即可核对；（4）退火终点保留 10%：世界模型在整个训练周期都要适应新数据，零学习率会让其僵化。

片段 2：基于验证平台的动态调整

class PlateauController:
    """验证平台检测：平滑曲线在窗口内无改善时按比例下调学习率。"""
    def __init__(self, optimizer, window=1000, factor=0.4,
                 cooldown=2000, floor_ratio=0.05):
        self.optimizer = optimizer
        self.window = window
        self.factor = factor
        self.cooldown = cooldown
        self.floor_ratio = floor_ratio
        # 记录各组初始学习率：下限按初始值比例计算，与调度缩放独立
        self.initial = [g["lr"] for g in optimizer.param_groups]
        self.best = float("inf")
        self.history = []
        self.last_adjust = -10 ** 9

    def update(self, step, val_loss):
        self.history.append(val_loss)
        smoother = sum(self.history[-10:]) / min(len(self.history), 10)
        if step - self.last_adjust < self.cooldown:
            return False                          # 冷却期内只观察不调整
        if smoother < self.best - 1e-4:
            self.best = smoother                  # 仍有改善：刷新最优值
            return False
        if len(self.history) < self.window:
            return False
        # 触发：各组学习率等比下调，下限锚定初始值防止趋零
        for group, init_lr in zip(self.optimizer.param_groups, self.initial):
            group["lr"] = max(group["lr"] * self.factor,
                              init_lr * self.floor_ratio)
        self.last_adjust = step
        self.history = []
        return True

解读：（1）先对最近 10 个记录点平滑再比较，抑制验证损失的短期噪声；（2）冷却期防止连续触发造成的断崖式下降；（3）下调作用于全部参数组且保持组间比例，与调度器的设计原则一致；（4）下限用"初始学习率 × floor_ratio"实现，学习率不会跌破初始值的 5%，防止无界趋零；触发返回 True 供调用方记录，调整事件进入训练记录供复盘。

常见坑

  • 预热过短或缺失：训练前几百步损失尖峰、个别层权重被破坏。修复：预热覆盖总步数的 5% 左右；大批量训练时加倍。
  • 调度与批量变化不同步：批量加倍而未调整学习率，有效步长变化。修复：批量改变时按线性缩放同步调整学习率，并且调度曲线的总步数以"样本量"为单位；批量变化时迭代次数会随之漂移。
  • 动力学学习率过大：想象回报曲线抖动、真实回报差值扩大。修复：回调动力学倍率，验收指标用下游想象稳定性；其自身损失下降不足以说明动力学健康。
  • 所有模块共用学习率：动作头欠拟合与骨干过拟合同时出现。修复：按模块梯度信噪比拆组，比例为起点微调。
  • 平台检测窗口过短：验证噪声频繁触发下调，学习率断崖式下降。修复：窗口覆盖噪声周期，平滑后再判定，加冷却期。

练习与思考

  1. 把退火终点从峰值的 10% 降到 1%。预测训练末期验证损失、世界模型对新数据的适应速度与误差增长曲线的变化。★
    提示
    末期验证损失略降（精修更充分），但新数据适应变慢，误差增长曲线在跨分布评估上劣化。联合训练中"持续适应"的价值通常高于最后的精修收益。
  2. 推导：余弦调度在第 t/T = 0.5 时的学习率值，并证明该点的变化率在整段退火中最大（两端变化率趋零）。★★★
    提示
    t/T = 0.5 时 cos(π/2) = 0，η = (ηmax+ηmin)/2；导数 −(ηmax−ηmin)·π·sin(πt/T)/(2T) 在两端为零、在该点绝对值最大，曲线中段下降最快、末端渐缓，参数在低谷附近停留更久。
  3. 设计调度消融：恒定学习率、预热加余弦、一次循环三种调度，在相同总步数下比较验证损失与想象稳定性指标，给出选择依据。★★
    提示
    恒定学习率末期损失最高；一次循环前中期收敛快但末期可能过冲；预热加余弦最稳。选择依据是训练预算是否固定与是否允许中段暂停评估。
  4. 把平台检测的下调比例从 0.4 改为 0.9（温和下调）。预测触发频率、训练损失轨迹与最终性能的变化，说明下调比例设计的权衡。★★
    提示
    温和下调让触发更频繁、轨迹更平滑但总降幅有限；激进下调单次到位但易过度。权衡点由"达到目标损失所需的总下调量"与"触发次数成本"决定。
  5. 计算：ηmax = 1 × 10−4、ηmin = 1 × 10−5，预热 5000 步、总步数 10 万，求第 2500、5000、52500、75000 步的学习率。★★
    提示
    预热期线性：第 2500 步为峰值一半 5 × 10−5；第 5000 步达峰值 1 × 10−4；退火进度 0.5 时 5.5 × 10−5；进度约 0.737（第 75000 步）约 2.45 × 10−5。手算结果与纯函数调度器的输出核对一次。

小结

  • Adam 的归一化让有效步长取决于梯度方向的信噪比，模块间的学习率差异由此而来。
  • 四类模块的参数组比例以骨干为基准，动作头加速、语言编码器减速、动力学以想象稳定性验收。
  • 线性预热保障早期稳定，余弦退火完成后期精修，退火终点保留小额学习率维持持续适应。
  • 平台触发的反应式调整需要窗口、平滑与冷却期三件套，调整保持组间比例。
  • 学习率与更新频率的乘积决定模块相对步速，两个参数统一记录、统一调整。
  • 下一章进入正则化技术：控制有效容量，防止联合训练在有限数据上过拟合。
