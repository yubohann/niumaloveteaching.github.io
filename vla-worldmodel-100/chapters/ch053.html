第三篇 · 策略与世界模型深化

第 053 章：VLA策略的时序动作生成

从单步动作到动作块：本章讲清分块预测如何抑制误差累积、滚动视界与时间集成如何衔接相邻块，以及序列级扩散生成在时间维上的计算组织。

  • 主题：VLA 策略 / 动作生成（Action Generation）
  • 关键公式：atens = Σi wi · at(i)，wi = exp(−m·i)
  • 预计学时：55 分钟
  • 前置章节：第 052 章 联合训练中的多智能体扩展

学习目标

本章围绕动作输出的时间结构，连接生成质量与闭环反应性两个目标。

  • 理解动作分块（Action Chunking）抑制误差累积的机制，以及它与开环视界长度的关系。
  • 掌握滚动视界（Receding Horizon）执行协议：预测、执行、重规划的循环与延迟补偿。
  • 掌握时间集成（Temporal Ensembling）的加权公式与权重选择，能解释相邻块边界的平滑性来源。
  • 理解序列级扩散生成在时间维上的组织方式，以及少步采样与一致性约束的作用。
  • 能设计分块长度、执行长度与重规划频率的联合配置，并用闭环指标验证。

背景与动机

单步动作生成在每个控制周期都依据最新观测输出一个动作，误差随周期逐步累积，长期任务中微小的方向偏差会放大为显著偏移。动作分块把一次前向的输出扩展为长度为 H 的动作序列，策略在块内保持开环，单位任务所需的决策次数降为原来的 1/H，每次决策的误差不再逐周期进入闭环，误差累积的路径被截断为块级别。

开环长度带来新的问题：块内不响应新观测，长块对突发扰动迟钝；相邻块独立生成时边界处可能出现跳变。滚动视界与时间集成分别解决这两个问题：只执行每块的前若干步并随即重规划，把最新观测纳入下一块；对重叠的多个块做加权融合，用预测冗余换取平滑。本章按"分块、滚动、集成、序列生成"的顺序展开，前一章处理多个智能体的空间结构，本章处理单个智能体的时间结构。

核心原理

先分析分块的误差机制，再讨论执行协议、融合权重与序列生成器。

1. 分块预测与误差累积

设单步误差为 ε1，闭环执行 L 步时的累计偏差近似正比于 L·ε1（方向性误差会放大，随机误差按 √L 累积）。分块策略在 H 步内固定输出，块内偏差不再被新决策修正，但决策次数减少使方向误差的注入次数下降。两股作用的权衡给出分块长度的有效区间：

累计偏差 ≈ (L / H) · εH + H · εdrift εH 为单次决策误差，εdrift 为块内开环漂移率；最优 H 随任务动力学速度与策略精度变化

任务动力学快（接触频繁、物体易滑动）时 εdrift 大，块应缩短；策略精度高、动作平滑时 εH 小，块可以放长。实际配置通常从 H = 8 至 16 起步，按闭环成功率扫描。

2. 滚动视界执行

滚动视界协议规定每次只执行块的前 E 步（E 小于 H），随后用最新观测重新生成下一块。E 与 H 的比例决定反应频率：E = H 是纯开环分块，E = 1 退化为逐步重规划。重规划频率提高会放大单次决策误差的注入，但同时把最新观测引入控制回路，两者的平衡点通常在 E 为 H 的三分之一到二分之一处。

延迟补偿是该协议的工程要点：推理耗时与执行耗时使块起点对应的观测滞后于当前时刻。做法是以预测的未来状态为条件生成动作块，或者在执行时跳过已过时的前几步。

3. 时间集成：边界平滑的加权融合

相邻两次决策生成的两个块在时间上重叠。时间集成为每个时刻的多个预测赋予指数衰减权重：

atens = Σi wi · at(i) / Σi wi，wi = exp(−m · agei) agei 为第 i 个块距今的步数；m 越大越信任最新预测，m 越小越平滑

融合的平滑来自预测冗余：同一个时刻被多个块覆盖，独立误差在加权平均中互相抵消，块边界的跳变被两侧预测的叠加缓冲。m 的选择对应滤波器带宽：过大接近"只用最新块"，边界仍可能抖动；过小则动作滞后于最新预测，响应变慢。0.1 附近的取值是常用起点。

数值算例：同一时刻被三个块覆盖、年龄分别为 0、1、2 步时，m = 0.1 的权重为 1.000、0.905、0.819，归一化后约 0.367、0.332、0.301，最新块只占约 37% 权重；m 增大到 0.5 时权重变为 0.506、0.307、0.186。前者融合平滑，后者响应快、抗抖动弱。

4. 序列级生成：扩散与一致性

扩散式动作头把整条动作块作为生成对象，去噪过程在时间维与动作维的联合张量上进行。相比逐步生成，序列级生成可以在去噪的每一步引入时间维约束（平滑度、速度上限、块间一致性），约束直接作用于生成分布。计算组织上，时间维参与注意力或卷积，显存随 H 线性以上增长，少步采样器（1 至 4 步蒸馏版本，见第 049 章）把去噪成本压回实时区间。

块间一致性约束的形式是相邻块在重叠区段上的预测差：Lboundary = ‖at(i) − at(i+1)‖²overlap。该损失可以在生成模型的微调阶段加入，把"相邻块接近"写入分布，减少集成模块的负担。

实现思路与设计

配置围绕三个长度参数（块长 H、执行长 E、集成系数 m）与一个延迟补偿开关展开。

控制循环

  1. 观测经编码器与世界模型潜状态进入策略，生成长度 H 的动作块。
  2. 把新块写入集成缓冲，按权重合成动作并执行 E 步。
  3. 执行期间并行推理下一块，用延迟补偿对齐块起点与当前时刻。
  4. 每 E 步循环一次，闭环评估项为成功率、动作抖动与单步延迟。

设计决策：为什么执行长度小于块长？

块长决定单次决策覆盖的时间范围，执行长决定观测反馈的引入频率，两者职责不同。若执行长等于块长，控制回路退化为开环序列发生器，接触密集任务的漂移无法被纠正；执行长过短则每次只用块的前几步，长块的预测能力被浪费，但推理频率上升。把两者分开配置，可以在推理预算不变的前提下独立调节反应性与平滑度，集成缓冲同时提供了块间的预测冗余。

与前一章的差异点

第 052 章处理智能体之间的空间耦合，输出仍是每个成员的动作结构；本章处理单智能体动作序列的时间耦合，输出维度从动作维扩展到时间乘动作维。两章的组合形态是联合动作块：世界模型预测联合未来，策略为每个成员生成时序块，集成机制按成员独立执行。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖时间集成缓冲、滚动执行循环与序列平滑约束。参数与上表一致。

片段 1：时间集成缓冲

import numpy as np

class TemporalEnsembler:
    """维护多个重叠动作块，按指数衰减权重合成当前时刻的动作。"""
    def __init__(self, action_dim=7, chunk=16, m=0.1):
        self.chunk, self.m = chunk, m
        self.buffer = np.zeros((chunk + 1, action_dim), dtype=np.float32)
        self.weights = np.zeros(chunk + 1, dtype=np.float32)

    def add_chunk(self, chunk_actions):
        # 新块第 k 步预测的是当前时刻之后第 k 步：按年龄 exp(-m * k) 累加到对应位置
        w_new = np.exp(-self.m * np.arange(self.chunk))
        self.buffer[:self.chunk] += chunk_actions * w_new[:, None]
        self.weights[:self.chunk] += w_new

    def get_action(self):
        # 加权平均：分母为零时返回零动作，防止冷启动除零
        w = np.maximum(self.weights[0], 1e-8)
        action = self.buffer[0] / w
        # 时间轴前移一格：已执行的一步被丢弃，下一控制步的预测上移
        self.buffer[:-1] = self.buffer[1:]
        self.weights[:-1] = self.weights[1:]
        self.buffer[-1] = 0.0
        self.weights[-1] = 0.0
        return action

解读：（1）缓冲按控制步滚动，新块与前一块在时间轴上自动对齐，集成在动作层完成，策略无需感知其他块的存在。（2）权重按年龄指数衰减，同一时刻被越新的块覆盖、权重越大，实现"新块主导、旧块收尾"的平滑过渡。（3）同一时刻可能被三个以上块覆盖（当 E 小于 H/2 时），数据结构天然支持多块叠加，加权求和的方差随覆盖数增加而下降。

片段 2：滚动视界控制循环

def rollout_with_receding_horizon(policy, env, chunk=16, execute=8, max_steps=400):
    """滚动视界执行：每次生成块，执行前 E 步后重规划。"""
    obs = env.reset()
    ensembler = TemporalEnsembler(action_dim=7, chunk=chunk)
    steps = 0
    while steps < max_steps:
        # 生成新块并写入集成缓冲；推理耗时与执行耗时由延迟补偿参数吸收
        chunk_actions = policy.predict_chunk(obs)
        ensembler.add_chunk(chunk_actions)
        for _ in range(execute):
            action = ensembler.get_action()
            obs, reward, done = env.step(action)
            steps += 1
            if done:
                return steps
    return steps

解读：（1）内层循环执行 E 步期间策略不推理，推理可以异步并行展开，控制周期由执行速度决定，推理耗时不再占用控制周期，这是分块结构在高延迟模型上的部署优势。（2）每次重规划都读取最新观测 obs，块起点的潜状态由此跟上环境变化，块长的开环窗口被执行长切分。（3）延迟补偿在此骨架外实现：若推理耗时超过一个控制周期，应在生成时以预测的未来状态为条件，或把执行起点前移数步。

片段 3：块间平滑约束

import torch
import torch.nn.functional as F

def boundary_smoothness_loss(policy, obs, chunk=16, overlap=6, weight=0.05):
    """块间一致性：相邻两次决策在重叠区段的预测应当接近。"""
    chunk_a = policy.predict_chunk(obs)
    # 模拟执行若干步后的观测：用块内动作在世界模型中前推，得到重规划时刻的条件
    obs_next = policy.world_model.imagine(obs, chunk_a[: chunk - overlap])
    chunk_b = policy.predict_chunk(obs_next)
    # 重叠区段对齐：chunk_a 的尾部与 chunk_b 的头部描述同一段未来
    tail = chunk_a[chunk - overlap:]
    head = chunk_b[:overlap]
    return weight * F.mse_loss(tail, head)

解读：（1）约束把"相邻块预测一致"写入训练目标，部署时集成模块承担的平滑职责被部分前置到策略内部。（2）重规划时刻的观测由世界模型前推获得，训练循环因此不需要真实环境交互，代价是世界模型误差会进入监督目标，权重不宜过大。（3）重叠区长度取 6 与执行长参数呼应：重叠区覆盖实际会发生的边界区间，过短约束不到作用点，过长收窄策略的自由度。

常见坑

  • 块边界跳变：相邻块独立生成且无集成，执行动作出现阶跃。修复：时间集成或边界一致性约束，先开集成验证收益。
  • 块长设得过长：报告里的平均误差正常，闭环中末端偏移明显。修复：按第 H 步预测误差扫描块长，快动力学任务缩短。
  • 集成权重过小或过大：m 过小动作滞后，m 过大边界仍抖。修复：在固定测试轨迹上扫描 m，观察动作的频谱与任务成功率。
  • 忽略推理延迟：大模型单次推理超过控制周期，动作块整体过时。修复：异步推理加延迟补偿，或缩短块长提高重规划频率。
  • 序列扩散直接逐时刻独立去噪：时间维失去耦合，块内出现高频抖动。修复：去噪网络在时间维共享参数并对相邻步做注意力或卷积耦合。

练习与思考

  1. 推导：在"决策误差注入加块内开环漂移"的简化模型下，写出累计偏差随块长变化的表达式，说明最优块长的存在条件。★★
    提示
    表达式为 (L/H)εH + Hεdrift，对 H 求导得最优 H = √(L·εH/εdrift)。两项都为正时曲线呈 U 形。
  2. 把执行长 E 从 8 减到 2，块长保持 16，预测三件事的变化：重规划频率、单次决策误差的注入次数、对突发扰动的响应速度，并说明验证指标。★★
    提示
    重规划频率上升 4 倍，误差注入次数增加，响应变快。验证：固定轨迹上人为加入扰动，测量恢复时间与动作抖动指标。
  3. 设计实验比较三种边界处理：无处理、时间集成、边界一致性约束。写出控制变量、指标（动作二阶差分、任务成功率）与预期排序。★★★
    提示
    固定块长与执行长、同一策略权重，只换边界机制。动作二阶差分衡量平滑度，成功率衡量任务影响；集成的平滑收益通常最直接。
  4. 讨论：为什么分块结构在高延迟模型上的部署优势更明显？结合控制周期与推理耗时的关系说明。★★
    提示
    控制周期由执行速度决定，推理在后台并行进行；单步策略则要求推理周期不大于控制周期。推理越慢，分块结构越接近唯一可行方案。

小结

  • 动作分块把决策次数降为 1/H，误差累积路径被截断为块级别，代价是块内开环。
  • 滚动视界用执行长 E 切分开环窗口，E 与 H 的比例决定反应性与决策误差注入的平衡。
  • 时间集成按指数衰减权重融合重叠块，用预测冗余换取边界平滑，m 调节滤波带宽。
  • 序列级扩散生成在时间维引入约束，少步采样器把部署成本压回实时区间。
  • 延迟补偿与异步推理是分块结构落到真实控制周期的两个必要条件。
