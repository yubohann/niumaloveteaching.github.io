第三篇 · 策略与世界模型深化

第 052 章：联合训练中的多智能体扩展

从单体到多体，联合动作空间与状态空间同时膨胀：本章讲清集中训练分散执行（CTDE）框架、共享世界模型的置换不变性设计，以及反事实基线如何完成信用分配。

  • 主题：联合训练 / 多智能体系统（Multi-Agent Systems）
  • 关键公式：Ai = Q(s, a) − Σa′i πi(a′i) · Q(s, (a−i, a′i))
  • 预计学时：60 分钟
  • 前置章节：第 051 章 世界模型的样本效率提升

学习目标

本章处理多体场景下世界模型与策略的结构改造，核心是参数共享与对称性。

  • 理解多智能体扩展的两个膨胀源：联合动作空间随智能体数量指数增长，联合状态分布随交互耦合变得非平稳。
  • 掌握集中训练分散执行（Centralized Training with Decentralized Execution, CTDE）的框架：训练期用全局信息，执行期只用本体的局部观测与共享潜状态。
  • 掌握共享世界模型的置换不变性（Permutation Invariance）设计：智能体嵌入、对称池化与掩码处理。
  • 掌握反事实基线（Counterfactual Baseline）的信用分配机制，能写出其优势函数形式。
  • 能估算多智能体注意力与联合预测的计算量增长，并给出规模上限的工程判据。

背景与动机

协作操作场景（双机械臂协同搬运、多移动平台编队）中，每个智能体的最优动作依赖其他成员的行为，动力学不再可由单体的世界模型描述。朴素扩展会遇到两个膨胀源：联合动作空间的维度是单体维度的 N 倍幂次量级，联合状态的样本复杂度随耦合强度上升；每个智能体观察到的环境因队友策略变化而持续漂移，单体视角下问题退化为非平稳过程。

联合训练框架提供了两个抓手：用共享世界模型把全体成员的状态演化放进同一个预测问题，缓解每个智能体各自建模的重复与冲突；用集中训练分散执行把全局信息限制在训练阶段，执行时每个成员只依赖本体观测与共享潜变量，保持部署的可行性。前一章的样本效率机制在此依然适用，本章补充的是结构与信用分配层面的扩展。

核心原理

依次讨论联合建模、对称性、信用分配与规模四项内容。

1. 联合世界模型与因子化设计

把全体观测与动作记为联合量 (o1:N, a1:N)，联合世界模型预测下一步的联合观测分布。直接建模需要覆盖 |A|N 量级的动作组合，样本需求不可接受。因子化假设把预测拆成共享动力学与个体差异两部分：共享主干学习交互规律，个体条件（智能体类型、目标、局部观测）作为条件变量输入，输出对每个成员的预测。

p(o′1:N | o1:N, a1:N) ≈ Πi p(o′i | hshared, oi, ai, m1:N) hshared 为联合潜状态；m1:N 为轻量消息，聚合队友的动作意图；因子化把指数复杂度降为线性加消息聚合

因子化的代价是忽略高阶交互（例如两个成员同时抢占同一空间的耦合效应）。补偿方式是让共享潜状态 hshared 经由注意力聚合全部成员信息，把主要交互结构收入其中。

2. 置换不变性：对称性的结构约束

同类智能体互换编号后环境行为不变，模型输出不应依赖编号排列。满足置换不变性的聚合函数包括求和、均值、最大值与注意力池化，它们对输入顺序不敏感。实现上为每个位置搭配智能体嵌入（Agent Embedding）区分个体类型，聚合函数负责合并信息；编号本身只能作为嵌入输入，不能作为位置参数直接参与计算，否则模型会记住训练时的编号约定。

异质团队（机械臂加移动平台）需要类型嵌入区分，同质团队的类型嵌入退化为共享参数。两种情况共用同一套池化代码，由嵌入表大小控制表达力。掩码机制负责处理变长团队：填充位置的注意力权重置为负无穷，池化时排除，保证不同成员数量的批次可以混合训练。

3. 信用分配与反事实基线

联合回报归属到个体的困难在于队友行为的混淆：任务失败可能源于任意成员的失误。反事实基线为每个成员构造"只有该成员动作变化、其他成员保持原动作"的对局分布，用实际动作价值减去该分布下的期望价值：

Ai(s, a) = Q(s, a) − Σa′i πi(a′i | ·) · Q(s, (a−i, a′i)) 求和只对第 i 个成员的动作进行，规模等于单体动作空间，可在计算图上一次前向完成

反事实优势度量"该成员的动作相对其平均水平带来多少增益"，正值表示贡献、负值表示拖累，梯度信号由此准确落到责任成员身上。其计算成本主要来自对所有候选动作的并行评估，借助批量维度可一次性完成，在离散动作场景中尤为高效。

数值算例：N = 8 个成员、每成员 6 个离散动作：枚举全部联合对局需要 68 = 1679616 次价值评估；反事实基线只对每个成员枚举其自身动作、其余成员保持原动作，共 8 × 6 = 48 次评估，评估次数降为全枚举的约 1/35000。

4. 集中训练分散执行与规模上限

CTDE 的执行接口规定：策略网络输入为局部观测、本体状态与共享潜状态的一部分，不依赖其他成员的实时观测。共享潜状态在执行期通过低速通信或预测获得，通信受限时用世界模型的预测值代替，质量随通信降级平滑下降，这是联合训练框架相对纯通信方案的鲁棒性来源。

规模方面，两两注意力聚合的成本为 O(N²)，成员数量到 16 以上时该项开始主导计算；分层聚合（先组内池化再组间池化）把成本降到 O(N·g)。联合预测输出的维度随 N 线性增长，显存按批内最大团队规模对齐。工程判据：当 N²d 接近单成员前向成本的量级时，切换分层聚合。

实现思路与设计

设计围绕"共享主干、对称聚合、集中评论"三件套展开，训练批次按团队规模对齐并掩码。

数据流

  1. 环境返回各成员的局部观测与全局状态，按批内最大团队数填充并对齐掩码。
  2. 共享编码器逐成员提取特征，叠加类型嵌入后进入对称聚合模块。
  3. 世界模型输出联合预测，策略头按成员输出动作分布，评论头输出联合价值。
  4. 损失项：联合预测损失、策略梯度损失、反事实优势项、以及团队规模无关的掩码归一化。

与前一章的差异点

第 051 章优化单条转移的复用方式，数据规模是变量；本章改变模型的条件结构与样本的组织方式，智能体数量是变量。样本效率机制在多体场景仍然叠加使用：优先级信号可改为联合预测误差，重分析则按成员分别执行。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖共享主干、对称聚合与反事实优势。规模设定与上表一致。

片段 1：共享主干与类型嵌入

import torch
import torch.nn as nn

class SharedAgentTrunk(nn.Module):
    """所有成员共享的编码主干：同一份参数处理每个成员的观测。
    设计意图：参数共享把参数量与团队规模解耦，个体差异由类型嵌入表达。"""
    def __init__(self, obs_dim=128, feat_dim=256, n_types=4, type_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(obs_dim, feat_dim), nn.ReLU(),
                                     nn.Linear(feat_dim, feat_dim))
        # 类型嵌入区分角色（例如左右臂、底盘），同质团队共享同一嵌入
        self.type_embed = nn.Embedding(n_types, type_dim)
        self.fuse = nn.Linear(feat_dim + type_dim, feat_dim)

    def forward(self, obs, agent_type):
        # obs: (B, N, obs_dim)；agent_type: (B, N) 整型编号
        h = self.encoder(obs)                      # (B, N, feat_dim)，逐成员独立编码
        e = self.type_embed(agent_type)            # (B, N, type_dim)
        return self.fuse(torch.cat([h, e], dim=-1))

解读：（1）编码器在所有成员间共享，参数量不随 N 增长；团队扩容时只增加批内维度，训练样本的统计效率随之提升。（2）类型嵌入以整型编号索引，编号语义由配置固定（0 为左臂、1 为右臂等），训练前必须冻结映射关系，避免混用。（3）融合层把个体特征与角色特征合并，后续聚合模块无需感知角色细节。

片段 2：掩码注意力池化保证置换不变性

class SymmetricPool(nn.Module):
    """置换不变的注意力池化：输出与成员排列顺序无关。"""
    def __init__(self, feat_dim=256, n_heads=4):
        super().__init__()
        self.q = nn.Linear(feat_dim, feat_dim)     # 查询来自全局摘要
        self.kv = nn.Linear(feat_dim, 2 * feat_dim)
        self.out = nn.Linear(feat_dim, feat_dim)
        self.n_heads = n_heads

    def forward(self, feats, mask):
        # feats: (B, N, D)；mask: (B, N)，True 表示有效成员
        k, v = self.kv(feats).chunk(2, dim=-1)
        q = self.q(feats).mean(dim=1, keepdim=True)          # 对称摘要：对成员取均值
        attn = (q * k).sum(-1) / (feats.size(-1) ** 0.5)     # (B, N)
        # 填充位置置负无穷：softmax 后权重为零，不参与任何输出
        attn = attn.masked_fill(~mask, float("-inf"))
        weight = torch.softmax(attn, dim=-1).unsqueeze(-1)
        pooled = (v * weight).sum(dim=1)                     # (B, D) 顺序无关的聚合
        return self.out(pooled)

解读：（1）查询由所有成员特征的均值生成，均值对排列不变，保证池化输出与编号顺序无关；直接取首个成员特征会破坏该性质。（2）负无穷填充是掩码的标准写法，softmax 在数值实现上把负无穷项权重归零；若用乘 0 代替，softmax 会把概率质量重新分配到填充位，产生隐式偏置。（3）单头写法便于阅读，多头实现只需在特征维拆分计算，掩码逻辑不变。

片段 3：反事实优势的批量计算

import torch

def counterfactual_advantage(joint_q_fn, policy_dist, actions, n_samples=8):
    """反事实基线：只改变单个成员的动作，计算其他成员不变时的价值期望。
    离散动作空间可枚举全部候选；连续空间从该成员分布采样近似。"""
    b, n, a = actions.shape
    joint_actions = actions.unsqueeze(1).repeat(1, n_samples, 1, 1)   # (B, S, N, A)
    candidates = policy_dist.rsample((n_samples,))                    # (S, B, N, A)
    candidates = candidates.permute(1, 0, 2, 3)                       # (B, S, N, A)
    q_actual = joint_q_fn(actions).squeeze(-1)                        # (B,) 实际对局价值
    advantages = []
    for i in range(n):
        # 构造反事实对局：第 i 个成员替换为采样候选，其余成员的原始动作不动
        cf = joint_actions.clone()
        cf[:, :, i] = candidates[:, :, i]
        baseline = joint_q_fn(cf).mean(dim=1)     # 对候选求期望得到该成员的反事实基线
        advantages.append(q_actual - baseline)    # 正为贡献，负为拖累
    return torch.stack(advantages, dim=1)         # (B, N) 逐成员优势

解读：（1）示意代码省略了逐成员的候选动作生成细节，核心结构是"替换单成员、保持其余不变"的反事实构造；离散动作场景直接把候选动作展开为枚举。（2）价值函数一次前向评估全部反事实对局，批量维度 S 承担枚举成本，实现上把 S 与 N 折叠进批维可进一步提升吞吐。（3）优势的期望为零，训练信号被中心化，方差显著低于直接使用联合价值，这是多体信用分配的常用稳定手段。

常见坑

  • 编号进入位置参数：把成员编号作为位置编码输入注意力，模型依赖训练编号约定，测试时换队友顺序性能骤降。修复：编号只经嵌入表进入，聚合用对称函数。
  • 掩码处理错误：填充位参与 softmax 或损失平均，小团队样本被系统性放大。修复：注意力掩码置负无穷，损失按有效成员数归一化。
  • 异质团队强制共享全部参数：不同类型成员共享同一编码器，表示被平均，个体性能下降。修复：共享主干加类型嵌入，必要时为不同类型配置独立输出头。
  • 联合动作空间直接枚举：成员数量增加后组合数爆炸，训练无法进行。修复：因子化预测加反事实采样，动作空间按成员独立处理。
  • 忽视两两注意力的平方增长：N 增大后显存与延迟超出预算。修复：分层聚合或先池化后交互，按 N²d 判断切换点。

练习与思考

  1. 证明：均值、求和、最大值池化满足置换不变性，而带位置编码的加权求和一般不满足。说明这一定义对多智能体模型设计的要求。★★
    提示
    前三种函数对输入排列的输出不变；加权求和的权重随位置变化，交换两个成员后输出改变。要求模型对成员编号的处理只能通过对称函数。
  2. 把反事实采样数从全枚举改为 8 个随机样本，预测三件事的变化：信用分配方差、训练稳定性、单步计算量，并给出选择依据。★★
    提示
    方差上升、稳定性略降、计算量下降。离散小动作空间用枚举，连续或大动作空间用采样并配合优势中心化。
  3. 设计实验：验证模型对成员编号置换的等变性质。写出置换操作、对比指标与期望结果。★★★
    提示
    随机置换输入成员的顺序（同步置换类型嵌入与观测），比较输出联合预测；策略输出应按同一置换重排后逐项接近。
  4. 估算：N=4 与 N=16 时两两注意力聚合的相对成本，说明分层聚合如何把增长压回线性。★★
    提示
    两两聚合成本按 N² 增长，16 相比 4 约为 16 倍；分层先组内 O(N·g) 再组间 O(g²)，总体按 N 线性。

小结

  • 多智能体扩展的两个膨胀源是联合动作空间的指数规模与耦合带来的非平稳性，因子化设计把复杂度压回线性加消息聚合。
  • 共享世界模型按智能体类型嵌入区分子群，聚合函数用对称结构保证置换不变性。
  • CTDE 把全局信息限制在训练阶段，执行期依赖局部观测与共享潜状态，通信降级时用预测替代。
  • 反事实基线为每个成员构造单变量对局，优势期望为零，是低方差信用分配的标准手段。
  • 规模判据：两两注意力的 N²d 成本接近单成员前向量级时切换分层聚合。
