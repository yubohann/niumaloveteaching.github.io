第 071 章：VLA策略的强化学习调参

本章讲 VLA 策略强化学习（Reinforcement Learning, RL）阶段的超参数体系：广义优势估计（Generalized Advantage Estimation, GAE）的偏差方差权衡、裁剪代理目标的步长约束、熵奖励与探索、以及奖励尺度与学习率的解耦。

  • 主题：策略优化 / RL 超参数与稳定性
  • 关键公式：At = Σl≥0 (γλ)l δt+l，L = E[min(ρA, clip(ρ, 1−ε, 1+ε)A)]
  • 预计学时：55 分钟
  • 前置章节：第 070 章：联合训练中的多模态数据增强

学习目标

  • 理解强化学习调参与监督学习调参的差别：数据分布随策略变化，超参数影响的是优化稳定性与探索行为。
  • 掌握 GAE 的推导脉络，能解释 γ 与 λ 各自控制什么，以及 λ 在偏差与方差之间的插值作用。
  • 掌握裁剪代理目标的构造与 ε 的含义，理解比率分布是比单点损失更重要的诊断对象。
  • 能实现 GAE 计算、PPO 组合损失与自适应 KL 系数，理解优势归一化与价值裁剪各自的职责。
  • 会诊断裁剪失效、熵塌缩与奖励尺度失衡问题，能设计超参数敏感性扫描实验。

背景与动机

本节说明 RL 调参针对的稳定性问题：策略梯度估计方差大且数据分布随策略更新漂移。联合训练中 VLA 策略在想象轨迹上学习，微小超参数差异会导致训练在探索不足与更新过猛之间摆动。世界模型提供的奖励与价值估计还带有模型偏差，价值网络对偏差的拟合会反过来污染优势估计。本章按“估计、约束、尺度”三层组织：GAE 控制优势的偏差方差平衡，裁剪与 KL 控制更新步长，归一化与系数控制各类损失的量级。调参的目标是让这三个层面各自工作，互不代偿。

核心原理

1. 优势估计：从一步自举到蒙特卡洛

时序差分残差 δt = rt + γV(st+1) − V(st) 度量“实际比预期好多少”。单步残差偏差大、方差小，蒙特卡洛回报方差大、偏差小。GAE 用指数加权插值：

At = Σl≥0 (γλ)l δt+l λ = 0 退化为一步自举（低方差高偏差），λ = 1 为蒙特卡洛（高方差低偏差）

γ 与 λ 职责不同：γ 是任务定义的一部分，决定规划视野与最优策略的折扣；λ 是估计器的偏差方差旋钮，不改变任务。调参纪律是先固定 γ（与规划视野匹配），再扫描 λ；两者混调会把分布问题伪装成估计问题。λ 的常用区间为 0.9 至 0.98，想象训练中轨迹短、模型误差随步数增长，λ 宜取区间下限。

2. 数值算例：GAE 的手算展开

取长度 3 的轨迹，奖励 r = [1, 0, 2]，价值估计 V = [0.5, 0.5, 1.0]，γ = 0.99，λ = 0.95，轨迹在末步终止（末步之后价值为零）。先算单步残差：δ2 = 2 + 0.99 × 0 − 1.0 = 1.0；δ1 = 0 + 0.99 × 1.0 − 0.5 = 0.49；δ0 = 1 + 0.99 × 0.5 − 0.5 = 0.995。再自后向前累积：

A2 = 1.0；A1 = 0.49 + 0.9405 × 1.0 = 1.4305；A0 = 0.995 + 0.9405 × 1.4305 ≈ 2.340 γλ = 0.99 × 0.95 = 0.9405；A0 的展开为 δ0 + γλδ1 + (γλ)2δ2

三点解读：（1）λ = 0 时 A0 退化为 δ0 = 0.995，λ = 0.95 时前向残差被折入，优势从 0.995 增至 2.340；（2）折扣乘子 γλ = 0.9405 使更远的残差按几何级数衰减，衰减速度为 λ 控制；（3）回报估计等于优势加基线：returns = A + V = [2.840, 1.9305, 2.0]，价值网络回归这组目标，策略对优势为正的动作提高概率。手算结果与倒序单循环实现逐项对应，可用于验证代码实现。

3. 裁剪代理目标：把步长约束写进损失

策略梯度需要“信任域”：每次更新后新旧策略的分布不能偏离太远。裁剪代理目标用概率比 ρ = πθ(a|s) / πold(a|s) 实现软约束：

LCLIP = E[ min( ρA, clip(ρ, 1−ε, 1+ε) A ) ] ε 控制允许的单步比率偏离，常用 0.1 至 0.3；比率超出区间时该项梯度被压平

min 的选取规则意味着：优势为正时比率被压在上界，优势为负时被压在下界，两种方向的“步子过大”都被抑制。比设置 ε 更重要的是监控比率分布：中位数应贴近 1，分布的 95 分位持续贴住裁剪边界说明学习率过大或批次相关性过强。KL 惩罚是裁剪的替代方案，软约束在手写实现中更稳，二者择一即可。四种信任域约束机制的对照如下：

机制约束形式实现成本第一诊断量主要风险
比率裁剪损失内截断比率低，几行代码比率分布分位数边界外仍有微小梯度，长期裁剪失效
固定 KL 惩罚损失加 λ·KL 项低平均 KL 与损失占比系数需随训练阶段调整
自适应 KL 系数按 KL 偏离反馈调系数中，增加反馈逻辑KL 与系数的联合轨迹系数震荡引入二阶不稳定
信赖域二阶法费雪矩阵约束更新高，二阶统计与共轭梯度约束违反度计算重，工程实现复杂

工程选择顺序：以比率裁剪为首选，实现与调参成本最低；KL 作为监控量并行记录，出现裁剪失效时再升级为自适应系数；信赖域二阶法只在需要极精细步长控制的场景使用。无论选哪种机制，比率分布与 KL 都是必须保留的诊断信号，约束机制可以替换，诊断纪律不变。

4. 熵奖励：探索的油门

策略熵 H(π) 度量动作分布的随机性。熵塌缩到零意味着策略对每个状态输出近乎确定的动作，探索停止，性能卡在局部最优。熵奖励在损失中加入 −βH 项鼓励保持随机性：β 过小时早期收敛过快，β 过大时策略长期保持高熵、动作噪声影响执行精度。高斯动作头的熵有闭式解，与对数标准差成正比；观察策略的 log-σ 输出是最直接的诊断：训练初期持续下降属正常，下降到接近固定下界时需要上调 β 或检查优势尺度。

5. 尺度：奖励、优势与损失的归一化

RL 损失里三种量纲混在一起：奖励与环境单位无关，优势的尺度由奖励与价值误差共同决定，价值回归的损失随回报尺度平方增长。归一化是解耦手段：优势按批次做零均值单位方差归一化，把学习率从奖励量纲里解放；价值损失可选用裁剪或 Huber 形式，抑制个别大误差样本主导梯度；奖励本身建议在环境封装层做固定缩放，使 γ = 0.99 时回报量级落在 10 的量级。优势归一化只改变尺度、保持样本顺序，最优解不变；它让同一套学习率能跨任务复用。世界模型价值估计的系统性偏差无法用归一化消除，需要用后验校准或降低想象数据的权重单独处理。

用数值感受尺度失衡的量级：设价值目标为 [0.1, 0.2, 0.15]，价值估计为 [0.12, 0.18, 0.14]，价值均方误差为 ((0.02)2 + (0.02)2 + (0.01)2) / 3 ≈ 0.0003。把奖励整体放大 100 倍后，目标与估计同步变为 [10, 20, 15] 与 [12, 18, 14]，均方误差变为 3.0，放大约 1 万倍；优势项与策略梯度同步放大约 100 倍。此时固定学习率下策略更新剧烈、价值项主导总损失。优势按批归一化可把策略项还原到单位尺度，价值项则靠 Huber 或误差裁剪抑制，环境层的固定缩放进一步让两类量级可预测。三层措施各管一段量纲，缺一层就会出现某一项独大的训练曲线。

实现思路与设计

本节给出调参模板：策略与世界模型联合训练时，RL 部分采用 PPO 组合损失（策略裁剪项、价值回归项、熵项），比率与优势按批计算；GAE 在轨迹收集时同步完成；自适应 KL 系数作为裁剪的补充监控；优化器采用 Adam，学习率 3×10−4 配 1000 步线性 warmup。与第 070 章的差异：第 070 章处理数据分布，本章处理优化过程的稳定性与尺度。

超参数默认值作用取值依据
折扣因子 γ0.99任务视野有效视野约 100 步，与任务长度匹配
GAE 参数 λ0.95偏差方差插值想象轨迹短时降到 0.9
裁剪范围 ε0.2单步比率约束常用默认；比率 95 分位持续贴界时下调学习率
熵系数 β0.01探索强度按 log-σ 下界监测调整

RL 训练曲线噪声大，多个超参数同时改动会让归因失效。建议的排查顺序：先看比率分布是否健康（中位数与分位数），再看熵代理（log-σ 或动作方差），最后看价值误差。损失曲线的绝对值在不同配置间不可比，比较用滚动窗口内的相对下降与最终任务回报。把比率分布当作第一诊断对象，是 PPO 类算法最省时间的纪律。

调参执行的顺序与判据

  • 数据复用轮数。同批数据反复优化会让比率逐渐偏离 1，裁剪率上升。先取 3 到 5 轮（epoch）建立基线，裁剪率超过 20% 时先降复用轮数再考虑回调学习率。
  • warmup 的作用域。warmup 只针对策略与价值网络的主干参数，熵系数与裁剪范围不参与退火；warmup 期间同步记录比率分布，便于观察初始化阶段的分布漂移。
  • 优势归一化的作用范围。归一化只在批次维度做，跨批次不共享统计量；批次过小时（小于 64）方差估计抖动明显，可改用整个 rollout 缓冲区的统计量。
  • 价值损失系数的调整时机。价值误差的下降速度长期慢于策略损失时上调系数，上限取到策略项的 2 倍；继续上调会把主干梯度拉向价值回归而拖慢策略改进。
  • 扫描预算的分配。单次扫描只动一个参数并至少重复 3 个随机种子，种子间回报方差接近参数效应时延长训练步数；增加参数档位只会把种子噪声一并放大。

关键代码与解读

以下片段以近端策略优化（Proximal Policy Optimization, PPO）的公开实现为参照，接口随版本演进。三个片段分别覆盖 GAE、组合损失与自适应 KL。

片段 1：广义优势估计

import torch

def compute_gae(rewards, values, dones, gamma=0.99, lam=0.95):
    """由后向前累积时序差分残差：一次遍历即可完成。"""
    T = rewards.shape[0]
    adv = torch.zeros_like(rewards)
    carry = torch.zeros_like(rewards[0])
    for t in reversed(range(T)):
        # 终止步之后价值为零：done 处以 (1 - done) 截断自举链
        if t + 1 < T:
            next_v = values[t + 1]
            cont = 1.0 - dones[t]
        else:
            next_v = torch.zeros_like(values[0])
            cont = torch.zeros_like(dones[t])
        delta = rewards[t] + gamma * next_v * cont - values[t]
        # 递归项与折扣因子、Lambda 连乘：等价于指数加权的残差和
        carry = delta + gamma * lam * cont * carry
        adv[t] = carry
    returns = adv + values                  # 回报估计：优势加基线
    return adv, returns

解读：（1）倒序单循环的实现复杂度为 O(T)，与逐项展开求和等价。（2）终止截断用乘法实现，避开条件分支，向量化友好，也能处理批量中部分样本终止的情形。（3）returns 与 adv 同时返回：价值网络回归 returns，策略使用归一化后的 adv，两者共用一次计算。

片段 2：PPO 组合损失

import torch

def ppo_loss(logp_new, logp_old, adv, values, returns, entropy,
             eps=0.2, vf_coef=0.5, ent_coef=0.01, normalize_adv=True):
    """裁剪代理目标 + 价值回归 + 熵奖励。"""
    ratio = torch.exp(logp_new - logp_old)        # 概率比 rho
    if normalize_adv:
        # 优势归一化：把学习率从奖励量纲中解耦，不改变样本相对顺序
        adv = (adv - adv.mean()) / (adv.std() + 1e-8)
    unclipped = ratio * adv
    # 裁剪只对“超出区间方向”的样本生效，其余样本梯度保持原样
    clipped = torch.clamp(ratio, 1.0 - eps, 1.0 + eps) * adv
    policy_loss = -torch.min(unclipped, clipped).mean()
    value_loss = torch.nn.functional.mse_loss(values, returns)
    # 熵项取负号：最大化熵意味着在损失中减去 entropy
    return policy_loss + vf_coef * value_loss - ent_coef * entropy.mean()

解读：（1）先归一化优势再计算裁剪项，避免大回报任务在裁剪边界上误判“步子过大”。（2）torch.min 的方向与原论文一致：对两个候选取悲观值，任一方向的偏离都被限制。（3）价值损失用未裁剪的 MSE；若个别回报尖峰主导梯度，可改用 Huber 或对误差裁剪。

片段 3：自适应 KL 系数

def adapt_kl_coef(kl, coef, target=0.01, factor=1.5,
                  coef_min=1e-4, coef_max=10.0):
    """按 KL 偏离目标的程度缩放惩罚系数：信任域的反馈控制。"""
    if kl > 2.0 * target:
        # 更新过猛：放大惩罚，下一轮把策略拉回目标附近
        coef = min(coef * factor, coef_max)
    elif kl < 0.5 * target:
        # 更新过保守：缩小惩罚，允许更大步长提升样本效率
        coef = max(coef / factor, coef_min)
    # 落在目标区间内保持系数：避免系数震荡本身引入的不稳定
    return coef

解读：（1）上下界防止系数失控：上界避免策略冻结，下界避免惩罚消失。（2）目标 KL 取 0.01 量级是常用默认，与裁剪 ε = 0.2 在数量级上互相匹配。（3）该函数与裁剪机制共存时，KL 只作为监控与微调，不承担主要约束职责。

常见坑

  • γ 与 λ 混调：同时改动两个参数后无法归因，误把任务定义变更当作估计器改进。修复：γ 一经确定不再改，λ 单独扫描并记录。
  • 裁剪失效：比率长期越过裁剪边界，损失看似平稳而策略没有改善。修复：检查学习率与批次相关性，降低学习率或缩短数据复用轮数。
  • 熵塌缩：log-σ 输出收敛到硬下界，动作分布退化为点质量。修复：上调熵系数，或检查优势尺度是否过大压制了熵项梯度。
  • 奖励尺度失衡：不同任务回报量级相差百倍，同一学习率下部分任务发散。修复：环境封装层做固定缩放，优势按批归一化，学习率不随任务调整。
  • 价值过拟合模型偏差：价值网络精确拟合世界模型回报，想象回报与真实回报差距扩大。修复：降低想象数据在价值回归中的权重，定期用真实回报校准价值头。

练习与思考

  1. 推导题：从 δt 与递归定义出发，把 GAE 展开为 Σ(γλ)lδt+l 的形式，并指出 λ = 1、γ = 1 时退化为哪种估计。★★
    提示
    逐层代入递归 carry 定义即可展开；λ = 1 且 γ = 1 时退化为蒙特卡洛优势（回报减基线）。
  2. 把片段 1 的 λ 从 0.95 改为 0.5，预测优势估计的方差、训练曲线平滑度与最终回报的变化。★
    提示
    λ 变小后方差下降、曲线更平滑，但偏差上升，最终回报可能略降；短轨迹任务对 λ 的下降更不敏感。
  3. 把片段 2 的 ε 从 0.2 改为 0.05，预测比率分布形态、有效样本比例与学习速度，并说明何种情况下小 ε 合理。★
    提示
    小 ε 下更多样本被裁剪，有效样本比例下降、学习放缓；价值估计精度高、批次相关性弱的场景可以接受更小的 ε。
  4. 实验设计：在固定 γ 下对 λ ∈ {0.8, 0.9, 0.95, 0.99} 与熵系数 {0.001, 0.01, 0.05} 做网格扫描，报告回报、比率 95 分位与策略熵三项指标，给出推荐组合与理由。★★
    提示
    以小网格先定 λ 再看熵系数：λ 影响学习信号质量，熵系数影响探索；三维报告避免只盯回报做选择。
  5. 设计题：为想象数据与真实数据混合训练的设定设计调参协议：两类数据的优势尺度如何统一、价值回归如何加权、裁剪范围是否需要分档。★★★
    提示
    用任务级尺度归一化统一优势量纲；价值回归按数据来源加权（真实数据权重更高）；想象数据的分布偏移大，裁剪范围可单独收紧。

小结

  • GAE 是偏差方差旋钮：γ 属任务定义，λ 属估计器，先定 γ 再扫 λ。
