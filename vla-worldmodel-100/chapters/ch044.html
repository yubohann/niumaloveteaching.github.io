第三篇 · 策略与世界模型深化

第 044 章：VLA策略的奖励塑形

稀疏的成功信号难以支撑高维动作空间的探索，本章讲透势函数塑形（Potential-Based Shaping）的策略不变性证明思路，以及从世界模型学习势函数的工程做法与失效模式。

  • 主题：强化学习 / 奖励设计（Reward Design）
  • 关键公式：F(s, s′) = γΦ(s′) − Φ(s)
  • 预计学时：55 分钟
  • 前置章节：第 043 章 联合训练中的批次大小影响

学习目标

本章围绕"如何在提供稠密学习信号的同时不改变任务的最优解"展开。

  • 理解稀疏奖励场景下信用分配（Credit Assignment）困难的具体来源，能描述探索失败与梯度信号缺失的因果关系。
  • 掌握势函数塑形 F(s, s′) = γΦ(s′) − Φ(s) 的策略不变性：能写出望远镜求和证明的核心步骤。
  • 掌握三类势函数来源：任务距离、成功概率、世界模型潜空间距离，并理解各自的误差特性。
  • 能设计塑形权重退火（Annealing）方案，抑制代理奖励被策略钻空子（Reward Hacking）的风险。
  • 能组合模仿损失、任务奖励与塑形项，说明每一项的尺度与梯度贡献。

背景与动机

VLA 策略经模仿学习初始化后，动作分布已经接近演示数据，但在成功率、效率或新场景上继续提升需要强化学习微调。许多操作任务只有二元成功信号：轨迹结束时判定是否完成任务，中间过程没有任何反馈。高维连续动作空间中，随机探索命中成功状态的概率极低，策略几乎收不到可用的梯度，这就是稀疏奖励的核心困难。

直接添加中间奖励是最直觉的解法，风险在于改变了任务定义：如果代理奖励与实际目标不一致，最优策略会漂移到代理指标的极值点。势函数塑形给出一个受定理保护的方案：只要中间奖励写成状态势的差分形式，任意策略的回报只发生常数平移，最优策略集合保持不变，稠密信号与任务语义可以同时获得。本章的工程重心在于势函数从何而来，以及它作为近似估计时如何控制副作用。

核心原理

先给出不变性定理的形式化叙述，再讨论势函数的三类来源与近似误差的影响。

1. 稀疏奖励与信用分配

回合制任务中，回报 R = Σt γt rt 仅在终止步取非零值，时序差分（Temporal Difference, TD）方法需要把终端信号沿轨迹反向传播。轨迹长度 L 与探索维度 D 同时增大时，随机轨迹命中成功集合所需的样本数近似指数级增长，信用分配的信噪比随之崩塌。塑形的目标是把"任务完成度"这一潜变量提前暴露给学习器，让每一步更新携带方向信息。

命中率可以用一个简单模型感受：设单步随机动作落入有利区域的概率为 p，独立情形下整条 L 步轨迹全部有利的概率为 pL。p = 0.3、L = 10 时命中率约 5.9 × 10−6，平均每 17 万条轨迹才出现一次有利序列；接入稠密信号后，每一步更新都携带方向信息，样本需求从"等待命中"变为"持续爬坡"，这是塑形在最基础层面的收益来源。

2. 势函数塑形与策略不变性

设原任务奖励为 r，定义塑形项：

F(s, s′) = γΦ(s′) − Φ(s) Φ 为定义在状态空间上的实值函数，γ 为折扣因子，s′ 为后继状态

塑形后的奖励为 r′ = r + F。沿一条轨迹做望远镜求和：

Σt=0L−1 γt F(st, st+1) = γLΦ(sL) − Φ(s0) 中间项两两抵消；回合制任务中若终态势为零或 γ 截断足够强，塑形总量与策略无关

塑形项的折扣回报等于终态势与初始势的差，与途中经过的状态顺序无关，因此任意两个策略的回报差保持不变，最优策略集合不变。这就是策略不变性（Policy Invariance）的核心。需要注意的是终态处理：若终态势不为零，不同策略到达终态的时刻不同，γLΦ(sL) 会引入策略相关的偏差；实现中通常把终止状态的势显式设为零，或者确认 γ 足够小使该项可忽略；每轮轨迹的塑形总和都应与两端势差逐轮对照，偏差出现即说明终态处理或 γ 因子被改错。

数值算例：取 γ = 0.99，沿轨迹的势为 Φ(s0) = 0.1、0.3、0.5、0.7、Φ(s4) = 0.9，共 4 步。逐步差分 Ft = γΦ(st+1) − Φ(st) 依次为 0.197、0.195、0.193、0.191；折扣求和 0.197 + 0.99 × 0.195 + 0.992 × 0.193 + 0.993 × 0.191 ≈ 0.7645，与闭式 γ4Φ(s4) − Φ(s0) = 0.9606 × 0.9 − 0.1 = 0.7645 一致。望远镜求和在数值上同样成立，中间项只是被重新分配到轨迹两端。

3. 势函数的三类来源

来源定义方式优点风险
任务距离Φ(s) 取目标位姿与当前位姿距离的负值无需训练，语义明确距离度量难设计，绕障场景下直线距离失真
成功概率Φ(s) 取判别器给出的任务完成概率可从演示与失败数据训练判别器分布外输出不可靠，成为被利用的入口
潜空间距离Φ(s) 取世界模型编码到目标编码的负距离直接复用联合训练的世界模型潜空间度量对语义距离的保真度有限

当 Φ 由独立网络学习时，塑形项只近似势函数形式，不变性不再严格成立，误差项的作用如同一个小幅代理奖励。控制误差影响的工程手段是权重退火：训练早期用较大的塑形权重提供稠密信号，后期把权重降到零，让最终策略由任务奖励单独塑造。

直接加分与势差分的行为差异可以用一个往返移动的例子说明：目标距离从 0.5 缩到 0.3 再回到 0.5。直接加分规则（每次靠近加 0.2）一个往返净得 0.2，重复 k 次净得 0.2k，不设上限；势函数取负距离时，靠近一步得 γ × (−0.3) − (−0.5) = 0.203，返回一步得 γ × (−0.5) − (−0.3) = −0.195，往返净得约 0.01，重复往返的总收益被望远镜和锁定在不超过 0.5（等于初始势的绝对值），不会随重复次数线性增长。势差分的这种封顶特性就是它抗刷分的结构来源。

三类来源的误差特性需要按来源分别对待。距离势的典型失真场景：目标在障碍另一侧，直线距离 0.3 米，绕行实际需要 1.2 米；势函数取直线距离时，策略被推向紧贴障碍的位置，那里距离读数最小但任务不可达。验证方法是对训练中出现的"高势停滞点"做回放分析，若停滞点的真实剩余到达步数远大于势函数隐含的临近程度，说明度量与任务拓扑不一致。

判别式势函数的误差形态：判别器在训练分布内校准良好，在分布外的某个区域把真实的成功概率 0.2 高估到 0.8，势差在该区域持续为正，策略有明确动机停留其中。对冲手段有三层：判别器数据纳入失败与半途轨迹；对判别器输出施加温度或带宽限制；退火把长期收益归零。三层同时部署时，分布外高估只影响过渡期，不再塑造最终策略。

4. 奖励组合与模仿正则

VLA 的强化微调通常把三类信号组合：任务奖励 rtask（成功为 1，其余为 0）、塑形项 F（带权重 β）、以及相对参考策略的 KL 正则（带权重 κ）。KL 项约束策略不要偏离模仿初始化太远，兼作探索的信任域。组合后的每步奖励写为：

rt = rtask + β · F(st, st+1) − κ · log(π(at | st) / πref(at | st)) β 从 1.0 线性退火到 0；κ 常取 0.01 至 0.1，量级与动作对数概率的方差匹配

三项的量级需要事先对齐：任务奖励是 0 到 1 的量级，塑形项与势函数同尺度，KL 项无界。实现时应打印每一项的方差，确保没有任何一项按一两个数量级压过其余项。

KL 项线性形式的来历可以两步得到：完整 KL 的梯度为 Eπ[∇log π · (log(π/πref) + 1)]，其中常数 1 一项在期望下无贡献（Eπ[∇log π] = 0），训练时只用 log(π/πref) 乘以对数概率梯度即可等价，省去完整 KL 所需的配对采样。对数概率差保留逐时间步形状，便于与奖励项按同一折扣序列求和。尺度对齐的做法示例：在验证集上分别统计三项的均值与标准差，把任务奖励与塑形项归到相近量级，KL 项按 0.05 的权重进入；任何一项的标准差超过其余两项之和时，先做缩放再开始训练；等策略跑偏后回头调整的代价高得多。

实现思路与设计

设计围绕"势函数来源、退火节奏、验证口径"三条主线展开。

数据流

  1. 环境或世界模型产生轨迹，记录状态、动作、任务结果。
  2. 势函数模块对轨迹每一步输出 Φ(st)，按差分公式计算 F 并写入回报缓冲。
  3. 回报缓冲同时保存固定参考策略 πref 的对数概率，供 KL 项计算。
  4. 策略优化目标 = 任务回报加塑形回报减去 KL 惩罚；每 1000 步打印三项分量的统计量。

超参数表

参数默认值作用取值依据
β 初始值1.0塑形权重与任务奖励同尺度时从 1.0 起步，避免初期信号被淹没
β 退火区间训练步的 40% 至 70%线性降到 0留足稠密探索期，尾段由任务奖励完成精调
κ0.05KL 正则权重0.01 约束过松，0.1 以上策略更新幅度过小
γ0.99折扣因子遥操作任务回合长 100 至 300 步，0.99 对应约 100 步的有效视野
Φ 更新周期每 5000 步重训势函数过频引入非平稳性，过疏滞后于策略进步
设计决策：为什么要把塑形权重退火到零？

塑形项在近似误差存在时等价于一个低幅代理奖励，长期使用会把策略的最优解牵引向代理指标。把权重压到零后，最终性能由任务奖励决定，退火期同时充当"去除代理依赖"的过渡。若塑形项由精确的解析势函数给出（例如已知的目标距离函数），不退火也不破坏不变性，此时应保留全程塑形以维持学习效率。

与前一章的差异点

第 043 章调整的是优化器的统计行为，作用对象是梯度；本章修改的是奖励函数本身，作用对象是学习目标。奖励塑形的错误无法靠调批量或学习率弥补，两者属于不同层级：先保证奖励语义正确，再优化训练动态。

退火进度的数值形态：总训练 5 万步、退火区间为 40% 至 70% 时，退火从第 2 万步开始、第 3.5 万步结束；第 3 万步的进度为 (30000 − 20000) / 15000 ≈ 0.67，塑形权重 β ≈ 0.33。曲线斜率与退火区间长度成反比，区间越短切换越陡，切换点附近回报分布变化越剧烈，价值函数的重估压力也随之上升。

验收清单按顺序执行：其一，核对每个训练轮的塑形总量在数值上等于终态势与初始势的差（容差按浮点精度）；其二，对比塑形开关两组在固定初始状态集上的任务成功率；其三，检查高势停滞点的分布，确认没有策略聚集在度量失真区域；其四，确认退火结束后的策略完全不依赖塑形项（把 β 置零重评一次）。四项都通过，塑形配置才允许进入正式的强化微调流程。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

三个片段覆盖势函数计算、势函数训练与奖励组装退火。接口以通用设计为参照。

片段 1：势函数塑形的回报改写

import torch

def apply_potential_shaping(phi, states, next_states, gamma=0.99, beta=1.0):
    """把任务奖励改写为塑形奖励：F = gamma * Phi(s') - Phi(s)。
    设计意图：用状态势的差分提供每步方向信号，同时保持最优策略集合不变。"""
    with torch.no_grad():
        phi_s = phi(states)            # 当前势：目标越近，势越大（或取负距离）
        phi_next = phi(next_states)
    # 差分形式是策略不变性的充要结构，任何缺少 gamma 因子的变体都会破坏该性质
    shaping = gamma * phi_next - phi_s
    return beta * shaping

解读：（1）势函数在 no_grad 下计算，塑形项只作为奖励信号进入回报缓冲，不参与对势函数本身的梯度回传，避免策略与势函数互相追逐造成非平稳。（2）γ 因子缺少时望远镜求和不再完全抵消，策略可以通过改变终结时机来放大塑形收益，这是实现中最隐蔽的不变性的破坏方式。（3）β 作为输出缩放，让退火只改变塑形幅度，塑形形状由 Φ 固定，便于对照实验开关塑形的效果。

片段 2：从世界模型学习势函数

class LearnedPotential(torch.nn.Module):
    """从潜状态回归任务完成度的势函数网络。
    设计意图：复用世界模型编码器，避免为势函数单独维护一套视觉表示。"""
    def __init__(self, feat_dim=256):
        super().__init__()
        # 三层小网络即够用：势函数只需单调靠近目标，不必拟合复杂决策边界
        self.net = torch.nn.Sequential(
            torch.nn.Linear(feat_dim, 128), torch.nn.ReLU(),
            torch.nn.Linear(128, 64), torch.nn.ReLU(),
            torch.nn.Linear(64, 1))

    def forward(self, state_features):
        # 输出即完成度：约定"势越大越接近目标"，与最大化的学习目标方向一致
        return self.net(state_features).squeeze(-1)

def train_potential(phi, world_model, episodes, epochs=3):
    """用蒙特卡洛回报训练势函数：目标为归一化的未来完成度。"""
    optimizer = torch.optim.Adam(phi.parameters(), lr=3e-4)
    for _ in range(epochs):
        for states, outcomes in episodes:
            feats = world_model.encode(states).detach()   # 特征来自冻结的世界模型编码器
            target = outcomes.float()                     # 0 失败 1 成功，作为完成度标签
            loss = torch.nn.functional.mse_loss(phi.net(feats).squeeze(-1), target)
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()                              # 势函数独立训练，不进入策略梯度
    return phi

解读：（1）势函数的监督目标是终端完成度标签，网络容量刻意保持小规模，减小分布外的过拟合空间；容量过大时势函数在训练分布外给出任意值，塑形会牵引策略进入这些区域。（2）世界模型编码器冻结并截断梯度，保证势函数的更新不扰动联合训练中的共享表示。（3）网络原始输出即完成度，"接近目标"对应更大的势，与最大化回报的方向一致，避免符号错误在训练后期才被发现。

片段 3：三项奖励的组装与退火

def compose_reward(batch, beta, kappa=0.05, gamma=0.99):
    """组装任务奖励、塑形奖励与 KL 正则，beta 由外部调度器给出。"""
    r_task = batch["success"].float()                 # 终端二元奖励，其余步为 0
    phi_s = batch["phi"]                              # 轨迹各步的势，离线预计算
    phi_next = torch.roll(phi_s, shifts=-1, dims=1)   # 后继势；末步后继约定为 0
    phi_next[:, -1] = 0.0                             # 终态势归零，保住策略不变性
    f_shaping = gamma * phi_next - phi_s
    log_ratio = batch["logp"].detach() - batch["logp_ref"].detach()
    # KL 项的线性形式在重要性采样框架下无偏，实现上比完整 KL 更稳定
    r_total = r_task.unsqueeze(1) + beta * f_shaping - kappa * log_ratio
    return r_total

解读：（1）终态后继势归零是保证不变性的关键一行，缺少它时不同长度的轨迹获得不同的塑形总量，最优策略集合被隐性修改。（2）KL 项用对数概率差的一次形式，在策略梯度框架下与完整 KL 的梯度一致，且无需成对采样，计算稳定。（3）三项都保留逐时间步的形状，后续按折扣求和；β 由调度器传入，便于在训练脚本中统一控制退火进度。

常见坑

  • 用非势函数形式的中间奖励：例如对"靠近目标"直接加分而不做差分，策略学会反复靠近又远离来刷分。症状是塑形回报上升而任务成功率停滞。修复：一律改写为 γΦ(s′) − Φ(s) 形式。
  • 终态势未归零：不同终止时长的轨迹塑形总量不一致，策略偏好拖延或抢断。修复：末步后继势显式置零，或在回合结束时把 Φ 归零。
  • 塑形尺度未归一化：Φ 的量级远大于任务奖励时，策略完全跟随代理指标。修复：统计两项的分量方差，先把 Φ 归一到与任务奖励同量级。
  • 判别式势函数被钻空子：成功判别器在被策略主动探索的区域输出高分，出现"悬停在目标附近不敢闭合"的行为。修复：判别器训练数据覆盖失败轨迹，同时执行权重退火。
  • 势函数更新频率过高：塑形信号随势函数一起漂移，价值估计难以收敛。修复：势函数更新周期设为策略更新周期的数十倍，并冻结其特征来源。

小结

  • 稀疏奖励的困难来自探索命中率与信用分配的指数级恶化，稠密信号是继续微调的前提。
  • 势函数塑形 F = γΦ(s′) − Φ(s) 通过望远镜求和保证回报只发生常数平移，最优策略集合不变。
  • 终态势归零与 γ 因子是维持不变性的两个实现要点，缺一都会引入策略相关偏差。
  • 势函数可来自任务距离、成功判别器或世界模型潜空间；学习得到的势函数需要权重退火控制近似误差。
  • 奖励组合必须对齐分量尺度，KL 正则约束策略留在模仿初始化的信任域内。
  • 下一章转向世界模型的潜空间几何：隐空间插值（Latent Interpolation）如何生成语义连续的中间状态并复用为训练数据。
