第二篇 · 联合训练进阶与策略能力

第 031 章：联合训练中的模型不确定性估计

策略会利用世界模型的预测误差，不确定性信号是保守化的前提；本章讲清认知与偶然两类不确定性的方差分解、深度集成与异方差头的实现，以及校准评估方法。

  • 主题：不确定性估计（uncertainty estimation） / 方差分解
  • 关键公式：Var[y] = E[σ2] + Var[μ]；高斯负对数似然；ECE 校准误差
  • 预计学时：55 分钟
  • 前置章节：第 030 章

学习目标

  • 理解不确定性的两类分解：偶然不确定性（aleatoric）与认知不确定性（epistemic），以及各自的方差来源与消除途径。
  • 掌握两种实现路线：异方差高斯头与深度集成（deep ensemble），能写出总方差分解的估计式。
  • 会把不确定性接入策略目标：保守化惩罚、想象回报降权与数据采集的探索信号。
  • 会做校准评估：可靠性图与期望校准误差（ECE），理解温度缩放的作用。
  • 能诊断 σ 塌缩、集成相关性过强与两类不确定性误用三类问题。

背景与动机

世界模型对训练分布内的状态预测准确，对分布外状态会给出自信但错误的预测。策略在想象 rollout 中优化，天然倾向于寻找模型误差大的区域：那里预测回报高而实际执行差。没有不确定性信号的联合训练会在这种"模型利用"下逐渐失效。

不确定性估计给模型加一层自知：对每个预测同时输出"有多不确定"。两类来源需要分开处理。偶然不确定性来自观测与动力学的固有噪声，数据再多也无法消除，适合用于保守化；认知不确定性来自训练数据不足，随数据增加而减小，适合驱动探索与数据采集。

本章承上启下：第 030 章的误差曲线告诉我们在多远处预测开始不可信，本章让模型在单点预测上给出可信度；第 032 章的因果推理与第 036 章的误差修正都依赖这一信号做加权与校正。

核心原理

1. 两类不确定性的分解

对预测目标 y，模型输出均值与方差，总方差按全方差公式分解为：

Var[ y | x ] = Eθ[ σ2θ(x) ] + Varθ[ μθ(x) ] 第一项为偶然不确定性：各成员自身的噪声预测的平均；第二项为认知不确定性：成员间均值的离散度

分解的直觉：面对传感器噪声大的区域，每个模型都报告高方差（第一项大），它们对均值的判断却一致（第二项小）；面对训练数据稀疏的区域，每个模型都"自信"（单项方差小），但不同模型的预测互相矛盾（第二项大）。策略保守化用总方差，探索信号只用第二项，混用会让探索在纯噪声区域打转。

数值算例：K = 3 个成员对同一状态的均值预测为 0.4、0.5、0.6，成员内方差为 0.01、0.02、0.01。集成均值为 0.5；认知项为均值离散度 (0.01 + 0 + 0.01)/3 ≈ 0.00667；偶然项为成员内方差的平均 (0.01 + 0.02 + 0.01)/3 ≈ 0.01333；总方差约 0.02，其中偶然项占约三分之二。K = 3 时样本方差低估总体离散，乘以校正因子 K/(K−1) = 1.5 后认知项升到 0.01，与样本的最大偏差平方一致。该修正随 K 增大快速收敛：K = 5 时因子 1.25，K = 20 时 1.053。

2. 实现路线：异方差头与深度集成

异方差高斯头让网络输出 log σ2，用负对数似然训练：

LNLL = Σi [ ( yi − μθ(xi) )2 / (2 σθ2(xi)) + log σθ(xi) ] 残差平方项与 log σ 项相互制衡：σ 增大降低第一项但抬高第二项，平衡点给出条件噪声的估计

平衡点可以显式求解：固定残差 r = y − μ，损失对 σ2 求导并置零，得到 −r2 / (2σ4) + 1 / (2σ2) = 0，解得 σ2 = r2，最优噪声方差等于残差平方。数值核对：r = 0.1 时损失在 σ = 0.1 处最小，σ 偏离时梯度沿 (r2 − σ2) 的方向把参数拉回。平衡点是逐样本的：异方差头对每个状态学习各自的 σ，噪声大的状态学到较大的 σ，这就是"逐状态条件噪声"的准确含义。该推导也确定了 log σ 项的作用：它是对 σ 增长的唯一抑制力，去掉后 σ 不再有内点最优，会被推向上界，方差无界增大。

异方差头估计的是条件噪声（接近偶然不确定性），对认知不确定性不敏感：单个网络在分布外依然自信。深度集成（deep ensemble）用 K 个独立初始化的模型训练同一任务，预测时聚合：

μ̄(x) = (1/K) Σk μk(x) ，σ̄2(x) = (1/K) Σk ( μk(x) − μ̄(x) )2 + (1/K) Σk σk2(x) 均值离散度项对应认知不确定性，成员内方差项对应偶然不确定性；K 常取 5 至 10

集成成员必须独立初始化：共享初始权重会让成员在训练中保持高相关，均值离散度系统性偏小，认知不确定性失去分辨力。成员间的多样性还可通过数据子采样与训练步扰动增强。MC dropout 是集成的廉价近似：推理时保持 dropout 开启多次前向，采样方差作为认知不确定性的近似，效果弱于真集成但成本低一个量级。三条路线的定位对照：

路线覆盖的方差成分相对成本主要盲区
异方差高斯头偶然项（逐状态噪声）1 倍前向分布外仍自信，认知项缺失
深度集成偶然项 + 认知项K 倍前向，可批处理成员相关性过强时认知项偏小
MC dropout认知项近似数倍前向，同权重共享采样方差偏低，校准性弱于真集成

选择依据是接入点：只做保守化惩罚时，异方差头足够且最省；需要驱动探索与数据采集时，认知项不可替代，选深度集成；推理预算极紧且只需粗粒度排序时，MC dropout 是退而求其次的方案。

3. 接入策略：保守化与探索

想象 rollout 中的回报按不确定性降权：

G̃t = Gt − κ · σtotal(zt, at) κ 为保守化强度；总方差取集成总方差或异方差头的输出，两者可以按可用性选择

保守化直接改变策略的优化地形：高不确定区域被压低，策略向预测可信区域集中。κ 的取值形成连续谱：κ = 0 完全乐观（易被模型误差吸引），κ 过大让策略只敢在已充分覆盖的区域行动，探索停滞。常见做法是把 κ 作为训练调度量，早期偏保守、后期随模型质量提升逐步放松。

数值算例：两个候选动作的模型预测回报与总标准差分别为 (1.0, 0.1) 与 (1.2, 0.4)。κ = 0.5 时有效值为 1.0 − 0.05 = 0.95 与 1.2 − 0.2 = 1.0，策略仍选后者；κ = 1.0 时两值变为 0.9 与 0.8，排序反转，低方差选项获得优先。保守化改写候选间的排序，回报的整体平移不改变选择，排序反转的临界值由回报优势与标准差之差的比值给出：1.0 − 0.1κ = 1.2 − 0.4κ 解得 κ = 0.2 / 0.3 ≈ 0.67，超过该值后高不确定选项被淘汰。

探索信号用认知不确定性：在数据采集阶段选择 σ̄2（离散度项）高的状态区域优先采样，等价于主动学习。注意探索须在安全边界内进行：认知不确定性高的区域可能包含危险配置，探索策略应叠加物理约束或安全过滤。

采样预算的分配可以用一个简单判据：把候选状态按认知项从大到小排序，取前 10% 送入环境采集数据并更新模型，认知项随覆盖增加回落，形成采集与校正的循环。单轮采集量控制在总预算的 5% 至 10%，批次过大会让新数据的主导效应掩盖旧数据分布，出现遗忘风险。

4. 校准评估

不确定性只有在校准后才可解释：预测"70% 置信"的事件应以约 70% 的频率发生。期望校准误差（Expected Calibration Error, ECE）把预测置信度分箱，比较每箱的置信度均值与准确率：

ECE = Σb ( |Bb| / N ) · | acc(Bb) − conf(Bb) | Bb 为第 b 个置信度箱，acc 为实际准确率，conf 为平均置信度

回归任务的校准可用"区间覆盖率"替代：以 μ ± σ 构造 68% 区间，检查真实值的落入比例是否接近 68%。温度缩放（对 log σ2 乘一个标量）在验证集上拟合，是最简单的后校准手段。把未校准的 σ 直接接进惩罚项，等价于用一个未标定的传感器做安全判断，阈值毫无意义。

数值算例：三个置信箱的样本数、平均置信度、实际准确率分别为 (100, 0.55, 0.50)、(200, 0.70, 0.68)、(100, 0.90, 0.80)，样本总数 400。逐箱误差为 |0.50 − 0.55| = 0.05、|0.68 − 0.70| = 0.02、|0.80 − 0.90| = 0.10，按样本占比加权：ECE = 0.25 × 0.05 + 0.5 × 0.02 + 0.25 × 0.10 = 0.0475。第三个箱贡献 0.025，占总量一半以上；高置信区间的过度自信通常是校准修正的重点，温度缩放的拟合也应优先压低这一段的偏差。

名义覆盖率与高斯理论值的一致性检查：正态分布 1σ 区间的理论覆盖率为 68.27%，校准良好的模型在验证集上的实测覆盖率应落在 66% 至 70% 之间；2σ 与 3σ 对应 95.45% 与 99.73%，作为多级检查的参照。实测覆盖率在三级上同步偏离时，缩放单个标量不够用，需要检查均值预测的系统偏差或噪声分布的厚尾。

实现思路与设计

不确定性系统由多头结构、训练损失、聚合推理与接入点四部分组成。与第 030 章的差异：030 测量误差客观增长，本章让模型主观报告可信度，两者互为验证。

  1. 结构：共享骨干加 K = 5 个预测头（或 5 个完整模型）；头部分 3 层 MLP，宽度 256。
  2. 训练：每个成员独立初始化与独立数据顺序，损失为高斯负对数似然；骨干可共享（低成本）或独立（高保真）。
  3. 聚合推理：批量前向各成员，输出总方差与分解项；推理开销约 K 倍前向，配合第 029 章的量化与批处理压缩。
  4. 接入点：奖励/价值目标加惩罚项；数据采集用离散度项排序；监控面板跟踪校准指标。

监控面板的三条曲线与训练同步更新：σ 的分位数带（识别膨胀与塌缩）、成员预测相关系数矩阵的平均值（识别集成退化）、覆盖率曲线（1σ 与 2σ 两级）。三者出现背离时优先怀疑数据与校准集，再怀疑损失实现：例如总损失下降而覆盖率恶化，说明模型用 σ 换取了似然数值的改善，属于典型的目标被改写的信号，排查按损失实现、校准集、数据分布的次序进行。

注意：σ 塌缩与 σ 膨胀两种失控

负对数似然的平衡点是 σ2 ≈ 残差平方：训练早期残差大，σ 随之上移，这在正常范围内是期望行为，模型如实报告当前拟合水平。两种失控需要区分：其一，损失实现漏掉 log σ 项时，σ 失去唯一抑制力，被推向上界，方差无界膨胀；其二，数据看似无噪声（均值拟合过于精确）时平衡点落在 σ2 ≈ 0，个别异常残差的梯度按 1/σ3 放大，训练出现尖峰抖动。两者都表现为校准指标劣化，需监控 σ 的分位数曲线：持续上移贴近钳位上界对应第一种失控，贴近钳位下界对应第二种失控。

关键代码与解读

以下片段参照公开的深度集成与异方差建模实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：集成总方差与两类分解

import torch

def ensemble_stats(member_means, member_log_vars):
    """聚合 K 个成员：返回总方差、偶然项与认知项。"""
    # 输入形状 [K, B, D]，K 个成员对同一批样本的预测
    mu_stack = torch.stack(member_means)          # [K, B, D]
    lv_stack = torch.stack(member_log_vars)       # [K, B, D]
    mu_bar = mu_stack.mean(dim=0)                 # 集成均值
    # 认知项：成员均值的离散度，数据覆盖越多该项越小
    epistemic = ((mu_stack - mu_bar) ** 2).mean(dim=0)
    # 偶然项：成员自身噪声预测的平均
    aleatoric = torch.exp(lv_stack).mean(dim=0)
    return {
        "mean": mu_bar,
        "epistemic": epistemic,
        "aleatoric": aleatoric,
        "total": epistemic + aleatoric,
    }

解读：（1）两个分解项分别用均值的样本方差与方差的平均估计，与全方差公式逐项对应；（2）K 固定时离散度估计有偏（样本方差低估），工程上乘 K/(K−1) 校正；（3）返回值用字典组织，不拼接成单一张量，下游按用途取项：保守化用 total、探索用 epistemic、置信展示用 aleatoric；（4）该函数与具体网络结构解耦，共享骨干或独立模型的集成都能复用。

片段 2：异方差负对数似然训练

import torch.nn.functional as F

def gaussian_nll(pred, target, clamp_log_var=(-4.0, 4.0)):
    """高斯负对数似然：predict 输出均值与 log σ² 两个通道。"""
    mean, log_var = pred[:, :, 0], pred[:, :, 1]   # pred 形状 [B, D, 2]
    # 钳位区间防止早期训练把 σ 推入极端值：上下界对应 σ 约 0.14 与 7.4
    log_var = log_var.clamp(*clamp_log_var)
    inv_var = torch.exp(-log_var)
    # 残差平方项驱动均值拟合，log σ 项校准噪声尺度，缺一不可
    return 0.5 * (inv_var * (target - mean) ** 2 + log_var).mean()

def calibrate_temperature(log_vars, residuals, grid=(0.5, 1.0, 1.5, 2.0)):
    """温度缩放：在验证集上为 log σ² 找一个缩放系数，改善区间覆盖率。"""
    best, best_err = 1.0, None
    for t in grid:
        # 温度 t 整体缩放 log σ²：t 大于 1 表示放大方差
        covered = (residuals.abs() <= torch.exp(0.5 * t * log_vars)).float()
        err = (covered.mean() - 0.68).abs()     # 目标覆盖率 68%（1σ 区间）
        if best_err is None or err < best_err:
            best, best_err = t, err
    return best

解读：（1）log σ2 钳位是训练稳定的必要工程手段，区间对应 σ 的合理动态范围；（2）残差项与 log σ 项必须同乘系数 0.5 同时出现，缺少 log 项会让 σ 无上界膨胀，方差估计迅速失去意义；（3）温度缩放只拟合一个标量，不改变均值预测，是最小侵入的后校准；（4）覆盖率用 1σ 区间检查，生产环境应补充 2σ、3σ 的多级检查，仅拟合单级可能在另一级偏移。

片段 3：不确定性接入想象目标与数据采集

def imagine_with_penalty(policy, world_model, z0, kappa=0.5, horizon=15):
    """想象回报减去不确定性惩罚；探索用离散度项单独排序。"""
    z = z0
    ret, unc_total, unc_epi = 0.0, 0.0, 0.0
    gamma = 0.99
    for t in range(horizon):
        a = policy.act(z)
        stats = world_model.predict_stats(z, a)    # 含 mean 与方差分解
        reward = world_model.reward(z, a)
        # 逐步累积折扣惩罚：不确定区域的有效回报被压低
        ret = ret + (gamma ** t) * (reward - kappa * stats["total"].mean())
        unc_total += stats["total"].mean().item()
        unc_epi += stats["epistemic"].mean().item()
        z = stats["mean"]                          # 用集成均值推进潜状态
    return {"return": ret, "unc_total": unc_total, "unc_epi": unc_epi}

解读：（1）惩罚与回报同步折扣，越远期的不可信预测惩罚越轻，与信用分配的时间结构一致；（2）潜状态推进用集成均值，均值是两个分解项都围绕的中心，单成员输出会引入成员偏差；（3）统计量分开累计，便于分析惩罚到底来自偶然项还是认知项；（4）数据采集阶段把 unc_epi 作为排序键选轨迹，与惩罚使用的 total 分开，避免在纯噪声区域浪费采样预算。

常见坑

  • σ 滥用为"逃避惩罚"的工具：模型在困难样本上抬高 σ 换取损失下降，不确定性失去分辨力。修复：监控 σ 分布随训练的变化，对 σ 设置上界，或改用不需要 σ 的集成离散度项。
  • 集成共享初始化：成员预测高度相关，认知项接近零，分布外样本被误判为可信。修复：成员独立初始化，抽样不同数据顺序，训练后检查成员预测的相关系数。
  • 两类不确定性误用：用偶然项驱动探索，在传感器噪声区域反复采样；用认知项做安全惩罚，在数据密集区域过度保守。修复：明确约定各接入点使用的分量，代码层将分解项作为独立返回值。
  • 未校准直接设阈值：σ 未经温度缩放，阈值对应的实际覆盖率与名义值偏差大。修复：每个模型版本都在留出校准集上拟合温度并报告覆盖率曲线。
  • 推理开销失控：K 个成员的推理成本线性增长，控制回路超预算。修复：骨干共享加头独立降低大部分成本；批处理把 K 次前向合并为一次批计算；必要时用 MC dropout 近似。

练习与思考

  1. 把保守化强度 κ 从 0.5 提到 2.0。预测想象回报曲线、真实成功率与探索覆盖范围的变化，并指出哪个指标最先恶化。★
    提示
    想象回报因惩罚加重而整体下移，策略收缩到高通量区域，覆盖率下降；真实成功率在 κ 过大时因探索停滞先恶化。最先可观察的是想象回报与状态覆盖面积的收缩。
  2. 推导：从全方差公式 Var[y] = E[Var(y|θ)] + Var[E(y|θ)] 出发，说明两项的样本估计式分别对应成员内方差平均与成员均值离散度。★★★
    提示
    把 θ 视为成员索引的随机变量：E[Var(y|θ)] 用 (1/K)Σσ²k 估计，Var[E(y|θ)] 用 (1/K)Σ(μk−μ̄)² 估计，两式相加即集成总方差。
  3. 设计校准实验：用验证集分别检验温度缩放前后的 1σ 与 2σ 覆盖率，预测缩放系数大于 1 与小于 1 分别对应模型置信过度的哪种模式。★★
    提示
    覆盖率低于名义值时模型过度自信，最优温度通常大于 1（放大方差）；覆盖率高于名义值时温度小于 1。两级覆盖率应当同步改善，只改一级说明置信偏差的形状更复杂。
  4. 把集成成员数从 5 增到 20，预测认知项估计的偏差、推理成本与下游探索效率的变化，并说明 K 的选择依据。★★
    提示
    样本方差偏差按 K/(K−1) 缩小，K = 5 时的相对偏差约 25%，K = 20 时约 5%；线性增长的成本限制 K 的实用上限，选择依据是方差估计误差与推理预算的交点。
  5. 计算：三个置信箱的 (样本数, 平均置信度, 实际准确率) 为 (100, 0.55, 0.50)、(200, 0.70, 0.68)、(100, 0.90, 0.80)，求 ECE 并指出贡献最大的箱。★★
    提示
    ECE = (100/400) × 0.05 + (200/400) × 0.02 + (100/400) × 0.10 = 0.0125 + 0.01 + 0.025 = 0.0475；第三个箱贡献 0.025，占一半以上，高置信箱的过度自信是校准重点。改温度缩放后应观察该箱偏差是否同步下降。

小结

  • 不确定性分为偶然与认知两类，方差分解给出各自的可估计形式。
  • 异方差头估计条件噪声，深度集成同时覆盖两类不确定性，成员独立初始化是前提。
  • 保守化用总方差惩罚想象回报，探索用认知项驱动数据采集，两类接入点不可混用。
  • σ 校准通过温度缩放与覆盖率检查完成，未校准的阈值不具备安全含义。
  • σ 塌缩、集成相关性过强与推理开销是实现的三个主要风险，对应监控与近似方案。
