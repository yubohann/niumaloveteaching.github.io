第三篇 · 策略与世界模型深化

第 041 章：VLA策略的对抗样本鲁棒性

从对抗样本（Adversarial Example）在视觉编码器（Vision Encoder）中的传播机制出发，讲清攻击构造、对抗训练的 min-max 目标与鲁棒性评估协议，让 VLA 策略在受扰输入下保持动作稳定。

  • 主题：VLA 策略 / 对抗鲁棒性（Adversarial Robustness）
  • 关键公式：minθ max‖δ‖∞≤ε E[L(πθ(x+δ), a*)]
  • 预计学时：55 分钟
  • 前置章节：第 040 章 联合训练中的正则化技术

学习目标

本章围绕"扰动输入下动作稳定性"这一目标，覆盖原理、实现、诊断与实验设计四个层次。

  • 理解对抗扰动（Adversarial Perturbation）在视觉编码器中逐层传播与放大的机制，能解释动作头（Action Head）对输入扰动敏感的原因。
  • 掌握快速梯度符号法（Fast Gradient Sign Method, FGSM）与投影梯度下降（Projected Gradient Descent, PGD）的构造过程，理解符号梯度在无穷范数约束下的最优性。
  • 掌握对抗训练的 min-max 目标、内层攻击步数与干净、对抗损失混合权重的选取依据。
  • 能区分干净精度（Clean Accuracy）与对抗精度（Adversarial Accuracy），设计包含多档扰动预算（Perturbation Budget）的评估协议。
  • 能诊断灾难性过拟合（Catastrophic Overfitting）与批归一化（Batch Normalization, BN）统计污染两类训练故障，并给出修复方案。

背景与动机

VLA 策略直接以像素为输入，视觉特征到动作的映射在训练分布内足够平滑，在分布外的邻域却没有约束。沿梯度方向构造的微小扰动可以让人眼看到相同的场景，却让策略输出明显偏移的动作块。在抓取与装配这类精度敏感的任务中，几度的关节角偏移就可能造成对位失败。

与第 019 章的鲁棒性测试、第 040 章的一般正则化相比，本章处理的问题更尖锐：扰动由攻击者在当前参数上求解得到，属于对模型决策边界的最坏情况探针；数据增强注入的噪声没有利用梯度信息，无法覆盖这种最坏情形。对抗训练把最坏情况优化写进目标函数，得到的策略对一整片输入邻域保持一致输出。

在联合训练的整体结构中，策略鲁棒性还影响世界模型的训练质量：受扰策略产生的动作分布更稳定，想象 rollout（Imagination Rollout）中的动作条件更接近真实执行，由此减小模型误差的累积。本章先讲透攻击与防御的数学形式，再给出可直接移入训练循环的实现骨架。

核心原理

本节按照"扰动如何构造、扰动如何传播、训练如何改写、评估如何落地"的顺序展开。

1. 对抗扰动的构造：从一阶展开到符号梯度

设策略 πθ 的输入图像为 x，专家动作为 a*，攻击在无穷范数球内寻找使损失最大化的扰动 δ：

δ* = argmax‖δ‖∞ ≤ ε L(πθ(x + δ), a*) ε 为扰动预算，单位与像素同量纲；以 8 位图像论，ε = 4/255 对应的最大像素改动约为 1.6%

对损失做一阶泰勒展开：L(x + δ) ≈ L(x) + δT∇xL。在无穷范数约束下，把全部预算分配给梯度绝对值最大分量的方向最有利，最优解写为 δ* = ε · sign(∇xL)，这就是 FGSM。FGSM 的实质是把梯度视为局部线性模型，一步走到球面边界；当损失曲面弯曲明显时，单步解会低估可达的最大损失。

PGD 以迭代方式修正这个偏差：每次沿符号梯度上升一小步 α，再把结果投影回 ε 球。随机起点让多次攻击从球内不同位置出发，配合 5 至 10 步迭代，通常能得到接近局部最优的扰动，成为评价鲁棒性的标准攻击。

一阶近似下的一步增益可以算清：设某像素处三个通道的梯度为 (0.3, −0.1, 0.05)，ε = 4/255 ≈ 0.0157，则 FGSM 在该像素上把损失提升约 ε × (0.3 + 0.1 + 0.05) = 0.0157 × 0.45 ≈ 0.0071；若把全部预算只给绝对值最大的单通道，上界只有 0.0157 × 0.3 ≈ 0.0047，约为前者的三分之二。全分量按符号分配预算是一阶最优的表现形态，这也解释了 FGSM 实现里 sign 与逐分量裁剪不可替换的原因。

攻击强度与代价的档位对照：

攻击方式每步额外成本覆盖的劣化方向典型用途
随机噪声扰动接近零任意方向，不含梯度信息数据增强
FGSM1 次前向与反向一阶线性方向快速筛查与预算估计
PGD（7 步随机起点）约 7 次前向与反向非线性局部最优训练内层与常规评估
PGD（20 步多起点）约 20 次乘以起点数更强的局部搜索版本上线的上限评估

评估攻击应比训练内层攻击更强：训练用 7 步时评估取 10 至 20 步并加随机起点，给出"训练攻击之外的余量"。报告鲁棒性数字时同时写明攻击配置（步数、起点数、是否多起点取最坏），脱离配置的数字之间不可比较。

2. 扰动在视觉编码器中的传播与放大

视觉编码器（例如 ViT 主干）首先把图像切成图块（Patch），经线性投影 W 得到词元（Token）。输入扰动 δ 造成的首个特征偏移为 Δf = W δ，其大小受 W 的奇异值控制：投影矩阵在梯度较大的方向上放大扰动，即使 δ 的每个分量都不超过 ε。随后各层的自注意力（Self-Attention）与多层感知机（MLP）继续对偏移做线性与非线性混合，LayerNorm 把激活重新标准化，深层特征偏移由此与输入扰动的方向解耦，形成攻击者容易利用的"高敏感子空间"。

动作头的敏感度可以写成 Lipschitz 形式：

‖π(x + δ) − π(x)‖ ≤ Lhead · ‖f(x + δ) − f(x)‖ ≤ Lhead · Jenc · ‖δ‖ f 为视觉特征，Jenc 为编码器在 x 处的局部 Lipschitz 常数；动作块长度为 H 时，误差还会在块内逐步累积

从数据流形的角度看，对抗扰动把图像推出训练分布的高密度区域，编码器在流形外缺少约束，特征映射的局部常数随之变大。这一视角解释了为何干净精度高的模型仍然脆弱，也提示了改进方向：在输入邻域上施加一致性约束，等价于压制 Jenc 的局部上界。

3. 对抗训练：把最坏情况写入目标

对抗训练求解一个 min-max 问题：

minθ E(x,a*)[ max‖δ‖∞ ≤ ε L(πθ(x + δ), a*) ] 内层搜索最坏扰动，外层在该扰动上做梯度下降；内层用 PGD 的有限步近似，步数记为 K

与经验风险最小化（Empirical Risk Minimization, ERM）相比，训练分布的支撑集从离散样本点扩展为每个样本周围的 ε 球，模型被迫在这一邻域内给出接近一致的输出。代价是决策边界更平滑，干净样本上的拟合能力下降，出现鲁棒性与精度之间的权衡（Robustness-Accuracy Tradeoff），在图像分类任务中常观察到 2 至 5 个百分点的干净精度损失。

内层近似的质量决定训练效果。若只用 K = 1 的 FGSM，随着外层参数更新，损失曲面在扰动点附近逐渐变得尖锐，对抗精度会在训练后期突然塌陷，这一现象称为灾难性过拟合。修复手段包括：随机起点加 5 至 10 步 PGD、在攻击目标中加入 KL 正则项、以及权重指数滑动平均（Exponential Moving Average, EMA）。

4. 与联合训练的交互与评估口径

在联合训练框架中，策略与世界模型互为训练信号来源。鲁棒化后的策略在想象 rollout 中输出更稳定的动作条件，世界模型的动作条件预测误差随之下降；反过来，世界模型对受扰观测的预测一致性，又能作为策略正则的辅助监督来源。两者形成正反馈的前提是扰动预算与想象步长匹配：预算过大时想象轨迹偏离流形，正反馈退化为噪声注入。预算过大的可操作判据是联动指标：8/255 档上想象成功率相比干净档次下降超过 5 个百分点时，说明扰动已把轨迹推出训练流形，应回退预算或缩短想象步长。

评估需要区分三个口径：干净精度（无扰动）、对抗精度（给定 ε 的 PGD 攻击）、以及动作偏差曲线（ε 从 0 扫到上限时的平均动作误差）。只看单一数字容易误判，鲁棒性报告应同时给出至少三档预算的结果。

实现思路与设计

实现分为攻击模块与训练步骤两部分，攻击模块独立封装以便在评估中复用同一实现。

数据流

  1. 从批次中取出干净观测 x 与专家动作 a*，克隆一份用于生成对抗观测。
  2. 内层攻击：把策略临时切换到推理模式，冻结 BN 滑动统计，执行 K 步随机起点 PGD，得到 xadv。
  3. 外层更新：计算 Lclean 与 Ladv 的加权和，一次反向传播更新全部参数。
  4. 每隔 N 步在固定评估集上报告三档 ε 的动作偏差，监控干净与对抗精度的变化趋势。

超参数表

参数默认值作用取值依据
ε4/255扰动预算上界2/255 几乎不可见但防御收益小；8/255 是通用评估上限；超过 16/255 会改变图像语义
α1/255PGD 单步尺寸取 ε/4 附近；过小需要更多步数，过大错过球内最优方向

设计决策：为什么攻击要切到推理模式并冻结 BN？

BN 在训练模式下用当前批次统计并更新滑动均值与方差。若攻击前向也在训练模式下进行，K 步迭代生成的对抗批次会被计入统计，滑动统计逐渐偏向受扰分布，干净分支的归一化随之失配。把攻击前向放到推理模式、只让外层更新步骤使用训练模式，可以保证 BN 统计来自干净数据。使用 LayerNorm 的主干不受此问题影响，混合结构仍需按此规则处理。

与前一章的差异点

第 040 章的正则化手段（权重衰减、dropout、标签平滑）作用在参数或激活的统计意义上，目标是改善泛化；本章把"最坏情况"显式写进优化目标，通过内层梯度搜索构造训练样本，目标是压缩输入邻域上的输出变化。前者不引入额外的反向传播开销，后者每步多出 K 次攻击前向与反向，代价约为常规训练步的 3 至 8 倍。

开销的构成可以拆开看：普通训练步为 1 组前向加 1 组参数反向；对抗训练在内层需要 K 组前向与输入反向（输入反向只回传到输入，比参数梯度便宜），外层再加 1 组干净与 1 组对抗的前反向，K = 7 时总以倍数计的实测开销通常落在 6 至 9 倍。把内层步数从 7 降到 5 是常见的降本档位，节省约两成攻击开销，鲁棒收益的损失需要按评估集实测确认。

关键代码与解读

以下片段用 PyTorch 风格写出核心机制，接口命名以公开实现的通用设计为参照，具体名称随版本演进。数值设定与上表一致。

片段 1：PGD 攻击，作用在图像输入上

import torch
import torch.nn.functional as F

def pgd_attack(policy, images, actions, eps=4/255, alpha=1/255, steps=7):
    """在无穷范数球内最大化预测动作与专家动作的偏差。
    设计意图：扰动定义在像素空间，梯度必须穿过整个视觉编码器回传到输入。"""
    delta = torch.zeros_like(images)
    # 随机起点让攻击覆盖球内多个方向，避免单点梯度造成攻击不充分
    delta.uniform_(-eps, eps)
    # 评估代码常被 no_grad 包裹，这里显式开启梯度：攻击必须求输入端的梯度
    with torch.enable_grad():
        for _ in range(steps):
            delta.requires_grad_(True)
            x_adv = (images + delta).clamp(0.0, 1.0)      # 像素必须保持在合法区间
            pred = policy.action_head(policy.encode_vision(x_adv))
            loss = F.mse_loss(pred, actions)              # 连续动作：偏差越大攻击越成功
            grad = torch.autograd.grad(loss, delta)[0]
            with torch.no_grad():
                delta = delta + alpha * grad.sign()       # 无穷范数下的一阶最速上升方向
                delta = delta.clamp(-eps, eps)            # 投影回球内，PGD 的核心步骤
    return (images + delta).clamp(0.0, 1.0).detach()

解读：（1）攻击目标用 MSE：动作头输出连续动作块，偏差本身就是攻击要放大的量；分类交叉熵适用于离散标签，对回归任务，最大化 MSE 与最小化负对数似然在梯度方向上一致。（2）requires_grad_ 在每轮循环开头设置，配合 no_grad 中的无梯度更新，让 delta 始终是图的叶子节点，避免每轮累积计算图。（3）投影步骤不可省略：若只做裁剪而不投影，扰动经多步累积会超出预算，得到的对抗样本在评估中不可复现。

片段 2：对抗训练的单步优化

def adversarial_train_step(policy, optimizer, images, actions, eps=4/255, lam=1.0):
    """一次外层最小化：干净分支与对抗分支的损失加权求和后统一更新。"""
    # 攻击前向切到推理模式：防止对抗批次污染 BN 滑动统计
    policy.eval()
    x_adv = pgd_attack(policy, images, actions, eps=eps)
    policy.train()
    # 干净分支保证任务精度，对抗分支压低最坏情况损失，两者缺一都会失衡
    loss_clean = F.mse_loss(policy(images), actions)
    loss_adv = F.mse_loss(policy(x_adv), actions)
    loss = loss_clean + lam * loss_adv
    optimizer.zero_grad()
    loss.backward()
    # 对抗训练梯度尖峰频繁，裁剪避免偶发大步更新破坏已获得的鲁棒性
    torch.nn.utils.clip_grad_norm_(policy.parameters(), max_norm=1.0)
    optimizer.step()
    return {"clean": loss_clean.item(), "adv": loss_adv.item()}

解读：（1）混合权重 λ 放在对抗项一侧，便于把干净分支固定为基准量纲，调参时只动一个旋钮。（2）每次外层更新都重新求解当前参数下的最坏扰动，实现 min-max 的交替近似；固定一份离线对抗集训练会在参数更新后失效，退化为普通数据增强。（3）返回两个损失分量便于监控：对抗损失与干净损失的比值持续拉大，是攻击强度超出防御容量或 λ 需要下调的信号。

片段 3：多预算鲁棒性评估

@torch.no_grad()
def eval_robustness(policy, loader, eps_list=(0.0, 2/255, 4/255, 8/255), steps=10, tau=0.1):
    """在固定评估集上扫描扰动预算，报告平均动作偏差与失稳比例。"""
    policy.eval()
    rows = []
    for eps in eps_list:
        err_sum, unstable, total = 0.0, 0, 0
        for images, actions in loader:
            # eps 为 0 时退化为干净精度，作为其余档位的对照基线
            x_eval = images if eps == 0 else pgd_attack(policy, images, actions, eps=eps, steps=steps)
            pred = policy(x_eval)
            # 逐样本的动作块 L2 偏差：避免批次平均掩盖个别严重偏移
            per_sample = (pred - actions).flatten(1).norm(dim=1)
            err_sum += per_sample.sum().item()
            unstable += (per_sample > tau).sum().item()   # 超过阈值 tau 记为一次失稳
            total += images.size(0)
        rows.append((eps, err_sum / total, unstable / total))
        print(f"eps={eps:.3f} 平均动作偏差={err_sum/total:.4f} 失稳比例={unstable/total:.2%}")
    return rows

解读：（1）评估用固定种子与固定步数，保证不同检查点之间的数字可比；评估期步数取 10，略高于训练期，防止把"只防住了训练攻击"误报成鲁棒。（2）逐样本统计偏差，整批平均会让个别样本的严重偏移被稀释，失稳比例这一列专门捕捉这类失败。（3）阈值 τ = 0.1 是归一化动作空间上的经验值，实际项目应结合任务允许的位置误差换算。若评估集很小，应报告置信区间；单点数值不足以支撑结论。

常见坑

  • BN 统计被对抗样本污染：症状是干净精度随训练下降、滑动方差持续偏大。原因是攻击前向未切推理模式。修复：攻击阶段 eval()，仅外层更新使用 train()。
  • 单步攻击训练出"假鲁棒"：训练曲线上对抗损失很低，评估时 10 步 PGD 轻松击穿，属于灾难性过拟合。修复：随机起点加多步内层攻击，或引入 EMA 权重评估。
  • 扰动预算盲目取大：ε 超过 8/255 后策略趋向保守，动作幅度整体收缩，任务成功率下降。修复：以干净精度损失不超过 3 个百分点为约束，扫描出可用预算。
  • 攻击目标方向写反：用 loss = -F.mse_loss(...) 再配梯度下降，等价于在最小化偏差，得到的"对抗样本"毫无威胁，防御实验结论失真。修复：统一规定内层最大化偏差，并用干净模型验证攻击成功率。
  • 把高斯噪声增强当作对抗训练：随机噪声与梯度攻击覆盖的子空间不同，前者无法暴露决策边界附近的最坏方向，评估显示的提升往往在强攻击下消失。修复：两者可以叠加，但鲁棒性结论必须以梯度攻击为准。

练习与思考

  1. 在一阶线性近似下推导：为什么无穷范数球内的最优扰动是 ε · sign(∇xL)？提示从柯西不等式或分量分解入手，并说明该结论在损失曲面弯曲时如何失效。★★
    提示
    写出 L(x+δ) ≈ L(x) + δᵀg，约束为 |δᵢ| ≤ ε。每个分量独立取 δᵢ = ε·sign(gᵢ) 时内积最大。曲面弯曲时一阶模型低估真实损失，需要多步迭代修正。
  2. 把 λ 从 1.0 改为 0.1，其余不变，预测三件事：干净精度、对抗精度、动作幅度的变化方向，并说明理由。★★
    提示
    对抗项权重降低后，优化重心回到干净分布，干净精度回升，对抗精度下降；动作幅度受平滑约束减小，应回升并接近未防御模型。跑一轮实验验证方向。
  3. 设计对照实验：攻击只发生在视觉特征空间（对特征加噪声后再解码动作），与像素空间攻击比较策略的动作偏差。说明该设计能隔离哪个变量、结论如何解读。★★★
    提示
    特征空间攻击绕过编码器的放大环节，直接检验动作头的 Lipschitz 性质。两组的差反映编码器对敏感度的贡献比例，可用于定位防御重点。
  4. 给出一个可操作的"鲁棒性验收清单"：扰动预算档位、攻击步数、评估集规模、通过标准、以及世界模型想象成功率这一联动指标。★★
    提示
    建议至少三档 ε（2/255、4/255、8/255），攻击步数 10 至 20，评估集不少于 500 个片段；通过标准可设为 8/255 下失稳比例低于 10% 且干净精度损失不超过 3 个百分点；想象成功率同步报告以验证联合训练未被鲁棒化拖累。
  5. 计算：某像素处损失对输入三个通道的梯度为 (0.3, −0.1, 0.05)，ε = 4/255 时 FGSM 在该像素把损失提升多少（一阶近似）？若预算只给绝对值最大的单通道，上界是多少？★★
    提示
    三通道同时扰动：0.0157 × (0.3 + 0.1 + 0.05) ≈ 0.0071；单通道上界 0.0157 × 0.3 ≈ 0.0047，前者约为后者的 1.5 倍。全分量按符号分配预算是一阶最优，这也说明 PGD 更新取 sign；直接乘梯度值会让各分量按模长分配预算，偏离一阶最优。

小结

  • 对抗扰动在无穷范数球内沿符号梯度方向构造，FGSM 是一阶近似，PGD 用迭代与投影逼近最坏情况。
  • 扰动经图块投影与注意力混合在视觉编码器内被放大，动作头的 Lipschitz 常数与动作块长度共同决定输出偏差上界。
  • 对抗训练求解 min-max 目标，内层攻击步数 K 与随机起点决定防御质量；单步攻击会导致灾难性过拟合。
  • 干净精度与对抗精度存在权衡；评估必须扫描多档预算并报告逐样本失稳比例。
  • 攻击前向需冻结 BN 统计；混合损失权重 λ 与梯度裁剪是训练稳定性的两个关键旋钮。
