第 082 章：联合训练中的多任务奖励设计

从势函数奖励塑形到偏好奖励模型：多种奖励来源如何组合、归一化与防作弊，才能让联合训练在多任务之间共享稳定信号。

  • 主题：联合训练（joint training）/ 多任务奖励合成
  • 关键公式：势函数塑形恒等式与 Bradley-Terry 偏好损失
  • 预计学时：50 分钟
  • 前置章节：第 081 章

学习目标

  • 理解多任务奖励合成的三个来源：任务原生奖励、势函数塑形（potential-based shaping）与模型预测奖励，以及各自的适用边界。
  • 掌握势函数奖励塑形定理的推导：塑形项在轨迹上望远镜求和后只余端点项，因此不改变最优策略集合。
  • 会实现按任务维护运行统计的奖励归一化（reward normalization），并解释均值方差指数移动平均（exponential moving average, EMA）更新的数值细节。
  • 会从 Bradley-Terry 模型出发推导成对偏好损失，理解 margin 项与集成分歧惩罚的作用。
  • 能识别奖励黑客（reward hacking）的典型模式，并给出至少三种防御设计。

背景与动机

多任务联合训练的第一困难是奖励信号在任务之间不可比：量纲、稀疏度与可信度都不同。抓取任务的成功信号是 0/1 稀疏量，行走任务的跟踪误差是连续稠密量，偏好奖励来自分类器估计、带有系统偏差。若把它们直接相加，训练动态会被量级最大的那一项支配。

奖励设计要同时解决三件事：为稀疏任务补充中间引导信号（塑形），把不同任务的回报压到可比尺度（归一化），为难以手工定义的目标提供可学习的代理（偏好建模）。第 022 章讨论过世界模型预测奖励的基本做法，第 044 章聚焦单任务的奖励塑形；本章处理多任务组合时的权重标定、统计归一化与激励相容（incentive compatibility）问题，这是把前四篇的机制整合进系统时的必经环节。

核心原理

奖励合成的总体形式是加权和，其中每一项都承担明确的引导职责，且塑形项必须满足势函数条件才不引入策略偏差。

1. 三类奖励来源的分工

  • 任务原生奖励（task reward）：任务本身的成功指示或跟踪误差，语义最可靠，但稀疏任务中绝大部分时间步为零。
  • 塑形奖励（shaping reward）：由势函数 Φ 生成的稠密引导项，把"离目标多远"的变化编码为逐步激励，作用是在稀疏信号之间架桥。
  • 模型预测奖励（learned reward）：奖励头在世界模型潜状态上估计进度或成功概率，由标注数据或偏好对训练而来，覆盖手工规则难以刻画的目标（例如"动作自然"）。

合成形式为：

Rtotal(st, at, st+1) = wtask · rtask + wΦ · ( γΦ(st+1) − Φ(st) ) + wpref · rθ(st, at) w 为各源权重；γ 为折扣因子；rθ 为可学习奖励头

2. 势函数塑形定理与望远镜求和

塑形项取势的差分形式有严格的理由。沿一条长度 T 的轨迹对塑形项做折扣求和：

Σt=0T−1 γt ( γΦ(st+1) − Φ(st) ) = γT Φ(sT) − Φ(s0) 相邻项相互抵消，只剩终点与起点两个端点项

由于 Φ(s0) 与策略无关，而 γTΦ(sT) 只依赖终止状态，塑形项对所有轨迹改变的是回报数值的分布，轨迹之间的偏好排序保持不变。这就是势函数奖励塑形（potential-based reward shaping, PBRS）定理：只要塑形项写成 γΦ(s′) − Φ(s)，最优策略集合不变，稠密引导与策略正确性可以兼得。反之，任何形如"每存活一步 +c"的常数项都会在求和后累积出与步数成正比的偏置，诱导拖延甚至绕圈刷步数的行为。

Φ 的常见构造有两种：距离型（离目标欧氏距离取负）与概率型（进度头输出的完成度概率）。概率型只需轨迹级成功标签即可训练，成本低，缺点是进度头的偏差会传导进奖励。

用距离型势函数走一遍数值：取 γ = 0.99，手爪到目标距离从 0.5 逐段收缩到 0.1（0.5、0.4、0.3、0.2、0.1），令 Φ = −距离，逐步塑形奖励为 0.104、0.103、0.102、0.101，折扣求和约 0.404；端点公式给出 γ4Φ(s4) − Φ(s0) = 0.994 × (−0.1) − (−0.5) ≈ 0.404，两者一致。逐步奖励只有 0.1 量级，累计量却由起点与终点的势差主导：中间路径如何绕行都不改变总量，这正是势函数塑形可以把引导密度调高的依据。

3. 跨任务的奖励归一化

设第 k 个任务的回报量级为 μk 与标准差 σk，归一化后的奖励为 r̂ = ( r − μk ) / σk。统计量用运行 EMA 估计，更新公式如下（下文代码给出二阶矩递推实现）：批量均值与二阶矩各做一次 EMA 混合，方差由二阶矩减均值平方得到。两个工程细节值得注意：

  • 统计量按任务独立维护，跨任务共享统计会把量纲差异重新引入；
  • 截断（clip）不可省略，早期统计欠估计时标准差不稳定，会出现几十倍放大的异常奖励，截断到 ±10 量级即可抑制。

归一化后，另一个平衡工具是权重。人工设定 w 需要反复试凑；更稳健的做法是把上一章的不确定性加权思想迁移过来，让每个任务维护可学习的 log 方差 sk，损失为 Σk exp(−sk)Lk + sk，权重随各任务残差自动标定。

4. Bradley-Terry 偏好损失

当目标难以用规则表达时，用成对比较数据训练奖励头。设轨迹 τw 优于 τl，Bradley-Terry 模型给出比较概率：

P( τw ≻ τl ) = σ( rθ(τw) − rθ(τl) )，Lpref = −log P( τw ≻ τl ) σ 为 sigmoid；rθ(τ) 为轨迹级累计打分

实践中常加入 margin 项，把 logits 写成 ( rθ(τw) − rθ(τl) − m )，保证区分度不足时仍有非零梯度。偏好奖励头必须与集成分歧惩罚联合使用：多个头对方差大的状态给出悲观修正 r̂ = mean − β·std，抑制在训练分布外的高分预测，这是防奖励黑客的结构性手段之一。

实现思路与设计

奖励系统挂接在世界模型潜状态上：进度头产势函数，奖励头产偏好分数，归一化器按任务维护统计，三者通过加权合成进入策略改进循环。

  1. 数据流：世界模型潜状态 zt 一分三路，分别送入任务原生奖励计算（环境返回）、进度头与偏好奖励头；合成后按任务归一化，写入回放缓冲区（replay buffer）。
  2. 进度头训练：输出完成度概率 p ∈ [0,1]，用轨迹级成功标签做停时监督（当前帧之前全为负、成功后全为正），损失为二元交叉熵（binary cross entropy, BCE）。
  3. 奖励头训练：偏好对来自演示轨迹的成功/失败配对，按 Bradley-Terry 损失优化，集成 5 个头取均值减 0.5 倍标准差。
  4. 塑形退火：wΦ 在前 1e5 训练步内从 1.0 线性降到 0.1。退火按训练步数执行，避免策略长期依赖塑形信号而学不到任务本身的成功判据。
  5. 与第 044、022 章的差异：第 044 章处理单任务塑形曲线，第 022 章只做奖励预测；本章是三来源合成、按任务归一化与激励相容设计的系统方案。

设计决策：塑形项为什么按步数退火？

早期策略随机、任务奖励稀疏，塑形项提供主要梯度；训练中后期若塑形强度不变，策略会优化塑形代理而偏离真实成功判据（代理目标与真实目标的差距即近似误差）。按训练步数退火让引导信号"先强后弱"，最终由任务原生奖励主导，兼顾收敛速度与目标一致性。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：三来源奖励合成与势差计算

def compose_reward(step_reward, phi_next, phi, pref_score, step, anneal_steps=100000,
                   gamma=0.99, w_task=1.0, w_pref=0.2):
    """合成多任务奖励：任务项 + 势差塑形 + 偏好打分。"""
    # 塑形项必须取势的差分：轨迹求和后只剩端点项，不改变最优策略
    shaping = gamma * phi_next - phi
    # 按训练步线性退火：早期强引导，后期回归任务原生奖励
    w_phi = 1.0 - 0.9 * min(1.0, step / anneal_steps)
    return w_task * step_reward + w_phi * shaping + w_pref * pref_score

def progress_potential(z, progress_head):
    """概率型势函数：进度头输出完成度 p ∈ [0,1]，直接作为 Φ。"""
    # 势函数单调越大越好，与"离目标越近"的直觉一致
    return progress_head(z)

解读：shaping 严格按 γΦ(s′) − Φ(s) 计算，任何省略 γ 的变体（例如 Φ(s′) − Φ(s)）会在折扣求和后残留与 γ 不匹配的项，严格意义上不再保证策略不变性。w_phi 用 min(1.0, 步数/退火长度) 截断，防止训练步数超过退火长度后权重变为负数。概率型势函数直接使用进度头的输出，其优势是训练信号来自轨迹级标签，无需逐步标注；代价是进度头的偏差会传导进奖励，因此进度头需要单独的验证集监控校准误差。

片段 2：按任务维护的运行归一化器

class RewardNormalizer:
    """按任务维护回报的运行均值与方差，把不同量纲的奖励压到可比尺度。"""
    def __init__(self, n_tasks, beta=0.999, clip=10.0):
        self.mean = np.zeros(n_tasks)
        self.var = np.ones(n_tasks)   # 初值 1：避免首次归一化除以零
        self.beta, self.clip = beta, clip

    def update(self, task_id, batch_returns):
        m, v = self.mean[task_id], self.var[task_id]
        batch_mean = batch_returns.mean()
        # 二阶矩递推：E[x^2] = Var[x] + E[x]^2，无需保存历史批次
        batch_sq = (batch_returns ** 2).mean()
        self.mean[task_id] = self.beta * m + (1 - self.beta) * batch_mean
        sq = self.beta * (v + m * m) + (1 - self.beta) * batch_sq
        self.var[task_id] = max(sq - self.mean[task_id] ** 2, 1e-8)

    def normalize(self, task_id, reward):
        std = np.sqrt(self.var[task_id])
        # 截断防止早期统计欠估计时产生极端缩放值
        return np.clip((reward - self.mean[task_id]) / (std + 1e-6),
                       -self.clip, self.clip)

解读：统计量按 task_id 索引，各任务量纲互不污染。方差更新采用二阶矩减法，只需常数存储；max(方差, 1e-8) 防止数值误差导致方差为负。标准调用时序是先归一化本批次、后更新统计；评测阶段冻结统计量并从检查点恢复，否则同一条轨迹在不同轮次会得到不同奖励值，指标不可复现。

片段 3：偏好奖励头与悲观集成

def preference_loss(heads, traj_w, traj_l, margin=0.05, beta_std=0.5):
    """Bradley-Terry 偏好损失 + 集成分歧惩罚（乘性悲观修正）。"""
    # 轨迹级打分 = 各时间步打分求和；heads 为奖励头集成列表
    r_w = torch.stack([h(traj_w).sum(dim=1) for h in heads])   # (E, B)
    r_l = torch.stack([h(traj_l).sum(dim=1) for h in heads])
    # 悲观修正：方差大的样本给出更低的有效打分，抑制分布外高分
    r_w_eff = r_w.mean(dim=0) - beta_std * r_w.std(dim=0)
    r_l_eff = r_l.mean(dim=0) - beta_std * r_l.std(dim=0)
    # margin 保证区分度小时仍有梯度；目标恒为 1（胜者应被正确排序）
    logits = (r_w_eff - r_l_eff) - margin
    return F.binary_cross_entropy_with_logits(logits, torch.ones_like(logits))

解读：打分在时间维求和得到轨迹级回报，与 Bradley-Terry 的轨迹比较语义一致。beta_std 的悲观修正让集成成员分歧大的样本获得较低有效分，训练目标因此偏好"所有头一致认可"的行为，这是抑制奖励黑客的关键结构。替代方案是集成分头独立损失取均值，缺点是缺少悲观项，分布外状态仍可能获得高打分。注意 torch.ones_like 作为目标表示"胜者永远在正类"，与公式 P(τw ≻ τl) 完全对应。

常见坑

  • 非势差塑形改变最优策略：用"每步 +0.1"代替势差，策略学会原地绕圈刷分。症状是回报曲线上升而任务完成率下降。修复：塑形项一律写成 γΦ(s′) − Φ(s)，并对刷分行为构造回归测试轨迹。
  • 归一化统计不冻结：评测时统计量随数据继续漂移，同一策略两次评测得分不同。修复：评测前冻结统计并从检查点加载；训练日志中记录统计量的漂移幅度。
  • 成功分类器被欺骗：分类器在训练分布外给出高分，策略停在传感器前反复触发。修复：集成悲观修正、定期用在线轨迹回灌再训练分类器、对置信度过高的区域加入对抗负样本。
  • 权重人工设定且跨任务复用：在任务 A 调好的权重迁移到任务 B 后训练崩溃。修复：切换到不确定性加权或按各任务回报方差动态重标定，权重表随任务集重新拟合。
  • 塑形退火与探索期错位：退火过早导致稀疏任务无梯度，过晚则策略固化在塑形代理上。修复：以任务成功率（例如达到 30%）作为退火触发信号，替代固定步数触发。

练习与思考

  1. 证明望远镜恒等式：Σt=0T−1 γt(γΦ(st+1) − Φ(st)) = γTΦ(sT) − Φ(s0)，并说明它如何保证最优策略不变。★
    提示
    逐项展开后相邻项相消；端点项只依赖初始状态与终止状态，与中间动作选择无关，因此不改变轨迹间偏好排序。
  2. 把折扣因子 γ 从 0.99 改为 0.95，预测同一势函数下塑形回报的变化，并解释端点项 γTΦ(sT) 随 T 衰减的影响。★
    提示
    γ 变小使长轨迹端点项更快衰减，塑形容量降低，稠密引导变弱；极端情况下接近"塑形无效"。
  3. 为"抓取杯子并放到托盘"任务设计势函数 Φ，要求只依赖可观测量（手爪与杯子距离、杯子与托盘距离、杯子姿态），并说明各分量符号方向。★★
    提示
    Φ = −d(手,杯)（抓取前有效）− d(杯,盘)（抓取后有效）− 姿态偏差惩罚；用抓取状态指示器平滑切换两个阶段。
  4. 把偏好项权重从 0.2 提高到 1.0，预测训练动态：任务奖励梯度相对被压制后会出现什么现象？给出诊断指标。★★
    提示
    策略趋向分类器的高分区域，任务完成率可能下降；监控任务奖励与偏好打分的相关曲线，若相关为负即为代理目标分歧。
  5. 构造一个刷分策略（例如缓慢靠近但不接触目标），测试成功分类器是否会给出高分；设计至少三种防御并写出评估协议。★★★
    提示
    用播放型脚本生成刷分轨迹，测量分类器打分；防御包括集成悲观、在线回灌、分布外检测（第 095 章）与成功条件的多信号校验。

小结

  • 多任务奖励由任务原生项、势差塑形项与偏好奖励项合成，各项权重的作用与可信度不同。
  • 塑形必须写成 γΦ(s′) − Φ(s)，望远镜求和保证策略不变性；常数型塑形会诱导拖延与刷分。
  • 归一化统计按任务独立维护、截断保护、评测冻结；权重可交给不确定性加权自动标定。
  • 偏好奖励用 Bradley-Terry 损失训练，配集成分歧悲观修正抑制分布外高分。
