第三篇 · 策略与世界模型深化

第 049 章：联合训练中的知识蒸馏

软标签携带的类间结构是蒸馏的信息来源：本章讲透温度参数与梯度尺度的关系、特征级蒸馏的层间映射，以及动作分布蒸馏从对数概率匹配到采样匹配的三种形态。

  • 主题：联合训练 / 知识蒸馏（Knowledge Distillation）
  • 关键公式：L = (1−α)Ltask + ατ² KL(ptτ ‖ psτ)
  • 预计学时：55 分钟
  • 前置章节：第 048 章 世界模型的在线学习

学习目标

本章区分蒸馏的三种信息形态，并给出与联合训练结合的损失配置。

  • 理解软标签（Soft Label）携带的暗知识（Dark Knowledge）：类间相似结构如何迁移任务语义。
  • 掌握温度缩放与 τ² 系数的梯度推导，能解释缺少 τ² 时训练动态的异常表现。
  • 掌握特征蒸馏的层间映射与投影头设计，理解它在学生容量不足时的补充作用。
  • 能针对连续动作块设计三种蒸馏形态：对数概率匹配、采样匹配、教师 rollout 的轨迹匹配。
  • 能诊断容量差（Capacity Gap）与教师误差传播两类蒸馏失效模式。

背景与动机

联合训练得到的教师模型由大规模视觉语言主干、世界模型与动作头组成，参数量与推理成本都不适合直接部署。蒸馏把教师的行为压缩进小模型，与量化、剪枝（第 050 章）共同构成部署前的收尾流程，其中蒸馏的独特价值在于信息形态：硬标签只给出"正确答案是哪一个"，软标签给出教师对全部候选的相对偏好，后者编码了任务空间的相似结构。

在 VLA 语境下，这份结构信息尤为重要：动作块是连续量，类别化的硬标签不存在；教师对相邻动作的偏好分布直接反映其对动作平滑性、任务阶段的判断，学生匹配整条分布比匹配单点能得到更平滑的策略。本章先推导温度与梯度尺度的关系，再处理连续动作分布与特征层的蒸馏实现，最后给出与强化学习微调共存时的注意事项。

核心原理

从软标签的信息量出发，逐层推进到梯度分析与三种蒸馏形态。

1. 软标签与暗知识

分类场景中，教师对输入 x 输出 logits zt，带温度 τ 的软化分布为 ptτ = softmax(zt/τ)。硬标签把全部概率质量集中在真实类别上，软化分布则在语义相近的类别上保留次高概率。这些"错误的"次高概率携带类间距离信息：对机械臂动作分类器而言，教师对相邻关节角度的概率分配模式，反映动作空间的连续结构，学生通过匹配整条分布继承这份几何先验。

分类设置之外，VLA 的动作头常输出高斯或扩散分布。分布蒸馏把"类别"替换为"动作块上的概率密度"，思想不变：匹配教师的整条分布；众数之外的形状信息同样要迁移。温度对应扩散时间步或分布的方差缩放，后面的工程部分给出具体接口。

2. 温度与梯度尺度

标准蒸馏损失与梯度如下。对学生 logits zs 求导：

LKD = τ² · KL(ptτ ‖ psτ)，∂L/∂zs,i = τ · (ps,iτ − pt,iτ) 温度 τ 使 softmax 输出的差异被压缩约 1/τ 倍，τ² 系数把梯度幅度拉回与温度无关的量级

推导要点：softmax 对 logits 的导数含 1/τ 因子，KL 对概率的导数再乘回 τ，梯度中出现 τ 的一次幂；概率差异本身随温度升高被压缩，两项合并后梯度大致按 1/τ 缩放。乘上 τ² 后梯度尺度与 τ 近似无关，避免"改了温度就改了有效学习率"这一隐性耦合。缺少 τ² 时的典型症状是温度越高蒸馏信号越弱，训练曲线表现为学生几乎不向教师靠拢。

温度取值区间为 1 至 10，VLA 实践中常用 2 至 4。温度过高使分布接近均匀，类间结构被噪声淹没；温度过低则退化为硬标签，暗知识消失。

数值示例：教师 logits 取 (3, 1, 0)、学生取 (2, 1, 0)，学生对 logits 的梯度范数在 τ = 1 时约 0.23；τ = 3 时带 τ² 系数约 0.31，与前者同量级；去掉 τ² 系数则降到约 0.03，缩到原来的约七分之一。这就是"改了温度就改了有效学习率"的数值形态，也是 τ² 系数不可省略的原因。

3. 特征蒸馏与层间映射

输出层蒸馏只约束最终决策，中间表示的自由度没有被利用。特征蒸馏对教师与学生中间层特征施加相似性约束：

Lfeat = Σl γl · ‖gl(fsl) − ftl′‖² gl 为学生特征的投影与上采样；l、l′ 为教师与学生的层映射，通常按网络深度比例对齐

层映射的选择依赖两套网络的深度比例：学生层数少于教师时，中间层按照相对深度比例配对，相邻教师层的特征可通过平均或插值合并作为监督目标。特征蒸馏对容量差有缓冲作用：即使学生的输出层容量不足以复现教师全部分布，中间特征的对齐仍能保住大部分表示结构。权重 γl 通常随深度递增，浅层特征差异对最终行为的影响更间接。

4. 连续动作的三种蒸馏形态

形态监督信号适用条件代价
对数概率匹配教师分布的对数密度教师与学生使用同构的动作分布族低，一次前向
采样匹配教师分布中采样动作块，学生做回归或最大似然分布族异构（如扩散教师、高斯学生）中，需要教师采样
轨迹匹配教师在环境中的完整 rollout追求行为级复制，目标超出分布级相似高，需要环境交互

采样匹配是异构分布族之间的通用桥梁：从教师扩散模型中采动作块，学生以最大化其对数概率的方式匹配，等价于最小化前向 KL 的采样估计。轨迹匹配把状态分布也纳入对齐，学生错误导致的偏离状态会暴露在教师标签下，适合对可靠性要求高、成本可接受的场景。三种形态可按训练阶段组合：先用轨迹匹配建立行为骨架，再用采样匹配提升分布精度。

实现思路与设计

教师由联合训练产出，蒸馏阶段冻结教师并混合三种信息形态。

数据流

  1. 从回放缓冲采样观测与动作，教师前向产出软标签与中间特征。
  2. 学生前向计算任务损失、输出蒸馏损失与特征蒸馏损失。
  3. 按权重求和更新学生参数，教师不做任何梯度更新。
  4. 每轮评估报告学生与教师的动作误差比值与检索类指标。

与前一章的差异点

第 048 章在线更新时参数持续变化，数据单遍到达；蒸馏阶段教师冻结，数据可反复使用，训练条件接近离线。蒸馏与在线学习可以衔接：先蒸馏得到可部署的学生，在线阶段只更新学生的动力学分支，参数规模的缩小使在线更新更稳定。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖输出蒸馏、特征蒸馏与连续动作的采样匹配。数值与上表一致。

片段 1：带 τ² 系数的输出蒸馏

import torch
import torch.nn.functional as F

def kd_loss(student_logits, teacher_logits, temperature=3.0):
    """软标签蒸馏：匹配教师与学生在升温分布上的差异。
    设计意图：τ² 系数补偿 softmax 求导带来的 1/τ 缩放，稳定有效梯度。"""
    t = temperature
    s_soft = F.log_softmax(student_logits / t, dim=-1)   # 学生输出取对数概率，KL 数值更稳
    t_soft = F.softmax(teacher_logits / t, dim=-1).detach()
    # reduction 取 batchmean：KL 的量纲与批内平均一致，避免随批量漂移
    kl = F.kl_div(s_soft, t_soft, reduction="batchmean")
    # τ² 是尺度补偿项；缺少时温度越高梯度越弱
    return kl * (t ** 2)

解读：（1）教师分支做 detach，蒸馏只更新学生，防止教师参数被拖入学生损失的梯度流。（2）学生用 log_softmax，避免先 softmax 再取对数时概率下溢导致的无穷值，这是数值稳定的标准写法。（3）τ² 与 KL 的乘积使整体目标对温度的敏感性大幅降低；调参时的经验顺序是先固定 τ = 3，调好其他项后再微调温度。

片段 2：特征蒸馏与层映射

class FeatureDistill(torch.nn.Module):
    """学生中间特征到教师特征空间的投影与对齐。
    设计意图：输出层容量有限的场景下，用中间层监督保住表示结构。"""
    def __init__(self, student_dim=512, teacher_dim=768):
        super().__init__()
        # 投影到教师维度：学生可以更窄，对齐发生在教师空间
        self.proj = torch.nn.Sequential(
            torch.nn.Linear(student_dim, teacher_dim),
            torch.nn.LayerNorm(teacher_dim))     # 归一化对齐特征尺度

    def forward(self, student_feats, teacher_feats):
        # 学生特征逐层投影后与教师特征做归一化平方误差
        proj = self.proj(student_feats)
        target = teacher_feats.detach()          # 教师特征冻结
        return F.mse_loss(proj, target)

解读：（1）投影头放在学生侧，教师特征保持原样，避免修改教师的前向路径；投影头只在蒸馏阶段训练，部署时可丢弃。（2）LayerNorm 把两套特征拉到可比的尺度，缺少归一化时 MSE 会被尺度差异主导，浅层特征的对齐信号被深层特征淹没。（3）层映射由外部配置决定：学生 12 层、教师 24 层时按 1:2 比例配对，教师相邻层的特征取平均作为监督目标。

片段 3：连续动作的采样匹配

def sample_match_loss(student_dist, teacher_dist, n_samples=4, temperature=1.0):
    """采样匹配：从教师分布采样动作块，最大化学生分布对其的对数概率。
    设计意图：对数概率匹配要求同构分布族，采样匹配对异构分布族同样适用。"""
    with torch.no_grad():
        # 教师采样：扩散或高斯动作头均提供 rsample 接口，温度缩放控制采样离散度
        teacher_actions = teacher_dist.rsample((n_samples,)) * temperature
    # 学生只需对采样点给出密度：等价于最小化前向 KL 的蒙特卡洛估计
    log_prob = student_dist.log_prob(teacher_actions)
    # 负号转成最小化目标；对采样维求平均降低方差
    return -log_prob.mean()

解读：（1）教师采样在 no_grad 下执行，学生通过 log_prob 对采样点计算密度，梯度只回传学生参数，避免对教师采样过程求导的高额开销。（2）温度缩放控制教师采样的离散程度，高温采样覆盖尾部、低温聚焦众数，课程上可以从高温起步逐步降温。（3）采样数取 4 是方差与成本的折中；若学生分布方差偏小、无法覆盖教师样本，应调大 student 分布的可学习方差参数；增加采样数解决不了覆盖不足。

常见坑

  • 缺少 τ² 系数：温度设为 4 后蒸馏信号近乎消失，学生长时间停在随机初始化附近。修复：损失乘 τ²，并用梯度范数日志确认尺度不随温度漂移。
  • 容量差过大：学生参数量只有教师的三十分之一，蒸馏损失停在较高水平且任务成功率低于直接训练。修复：适度放大学生，或改用特征蒸馏加输出蒸馏的组合。
  • 教师误差被复制：单教师在某类场景系统性偏移，学生在同场景继承偏移。修复：教师集成取平均，并在蒸馏评估中单独报告该场景指标。
  • 蒸馏与强化微调冲突：蒸馏锚定教师行为，强化学习要求探索新行为，两项目标互相拉扯。修复：先完成蒸馏再微调；若必须并行，把蒸馏权重随训练进程衰减。
  • 特征尺度未对齐：未加归一化的 MSE 特征损失被个别大尺度层主导，其余层的监督形同虚设。修复：投影头输出加归一化，并逐层记录损失分量。

练习与思考

  1. 推导：对教师与学生 logits 的 KL 损失求学生 logits 的梯度，证明梯度中出现 τ 的一次因子，说明 τ² 系数如何完成尺度补偿。★★★
    提示
    softmax 对 logits 的雅可比含 1/τ；KL 对概率的导数与概率差成正比；两者相乘后梯度约含 τ 的一次幂。乘 τ² 后总尺度近似与 τ 无关。
  2. 把输出蒸馏权重 α 从 0.7 降到 0.2，预测三件事的变化：任务损失收敛速度、动作平滑度、学生与教师的分布距离，并说明验证方式。★★
    提示
    任务损失收敛更快，动作平滑度下降，与教师分布距离变大。验证：在教师与本学生的动作块上计算分布距离指标，并做动作轨迹的可视化对照。
  3. 设计一个异构分布族的蒸馏方案：教师为扩散动作头、学生为高斯动作头，写出监督信号、温度或方差参数的调节方式。★★★
    提示
    用采样匹配：从教师分布采样动作块，学生以对数概率最大化匹配；学生方差需可学习并设下限，避免塌缩到单点。对照实验用教师采样的覆盖度衡量。
  4. 讨论：轨迹匹配相比采样匹配多出的信息是什么？在什么条件下这份信息的收益能够抵消环境交互成本？★★
    提示
    轨迹匹配把学生自身诱导的状态分布纳入监督，纠正偏离教师轨迹后的行为。收益在长程任务、误差累积显著时最大；交互成本低或可并行仿真时更值得采用。

小结

  • 软标签携带类间相似结构，蒸馏把教师的分布几何迁移给学生，信息量高于硬标签。
  • 温度压缩概率差异，τ² 系数补偿梯度尺度；缺少它会导致温度与有效学习率隐性耦合。
  • 特征蒸馏通过层映射与投影头补齐中间层监督，对容量差有缓冲作用。
  • 连续动作的蒸馏有对数概率匹配、采样匹配、轨迹匹配三种形态，按分布族同构性与成本选择。
  • 容量差与教师误差传播是主要失效模式，集成教师与特征蒸馏是常用缓解手段。
