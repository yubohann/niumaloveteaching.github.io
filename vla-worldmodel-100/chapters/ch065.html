第 065 章：VLA策略的迁移学习

本章讲 VLA 策略的迁移学习（Transfer Learning）：从源域预训练出发，用低秩适配（Low-Rank Adaptation, LoRA）与渐进解冻适配目标域，用弹性权重固化（Elastic Weight Consolidation, EWC）抑制遗忘，并用目标域验证集识别负迁移。

  • 主题：策略网络 / 迁移与参数高效微调
  • 关键公式：W′ = W + BA（秩 r ≪ d），L = Ltask + (λ/2)Σi Fi(θi − θ*i)2
  • 预计学时：50 分钟
  • 前置章节：第 064 章：联合训练中的多尺度处理

学习目标

  • 理解迁移学习在 VLA 中的设定：源域预训练提供了什么，目标域适配需要改变哪部分参数。
  • 掌握参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）的两条主线：低秩适配与瓶颈适配器（Adapter）的结构与注入位置。
  • 掌握灾难性遗忘（Catastrophic Forgetting）的成因与 EWC 正则的推导直觉，能读懂 Fisher 信息量的作用。
  • 能实现 LoRA 包装、EWC 惩罚项与渐进解冻的参数组配置，理解各层学习率的设置依据。
  • 会识别负迁移（Negative Transfer）与特征统计错配问题，能设计目标域数据量分档的迁移实验。

背景与动机

本节说明迁移学习针对的数据困境：目标域数据往往稀少。为某个特定工位、特定夹爪采集的示教轨迹可能只有数百条，从零训练 VLA 会严重过拟合。源域预训练模型已经具备视觉编码、语言理解与基本操作技能，迁移学习的目标是在尽量少改动参数的前提下把能力适配到目标域。关键问题在于改多少与改哪里：全量微调容易覆盖预训练知识并造成灾难性遗忘；只调输出层又可能不足以弥合视觉与动作分布的差距。本章围绕适配容量、正则约束与对齐目标三个旋钮展开。

核心原理

1. 迁移的设定与负迁移

设源域分布 pS(o, l, a) 与目标域分布 pT(o, l, a)，预训练在源域上最小化风险 RS(θ)，迁移目标是借助 θS* 降低目标域风险 RT(θ)。迁移有效的条件是两域共享可复用的低层结构：边缘、纹理、语言语法、基本抓取模式。若目标域任务结构差异过大（例如从桌面操作迁移到灵巧手内操作），源初始化可能差于随机初始化，现象称为负迁移（Negative Transfer）。负迁移的判别方法是做受控对比：同预算下用源初始化与随机初始化各训练一次，比较目标域验证曲线。

2. 参数高效微调：改哪里与改多少

低秩适配冻结原权重 W，只训练两个小矩阵：

W′ = W + B A，A ∈ Rr×d，B ∈ Rd×r，r ≪ d A 用高斯初始化，B 初始化为零：训练起点与预训练模型完全一致

B 零初始化保证初始输出无扰动，训练中适配增量从零平滑增长。秩 r 控制适配容量：r = 8 到 16 覆盖多数视觉语言骨干的适配需求，参数量约为主干的可训练比例千分之一量级。注入位置通常选择注意力层的查询与值投影矩阵（Q、V）：这两处直接决定“看什么”与“取什么信息”，对动作条件的语义最敏感。瓶颈适配器采用降维、激活、升维的串联结构，插在残差分支上，效果与 LoRA 接近，推理时多一层前向开销。适配位置的选择比秩的大小更重要：浅层适配改变感知风格，深层适配改变任务语义。四档适配范围按目标域数据量递进排列，对照如下：

适配方案可训练范围目标域数据量参考遗忘风险表达力典型适用
冻结主干只训动作头动作头数十条无最低同工位小改动、坐标校准
LoRA / 适配器注意力投影的低秩增量数百条低中常规目标域适配
末段部分解冻编码器末段加动作头数千条中较高视觉风格差异明显
全量微调全部参数上万条高，需要 EWC 或回放最高任务结构级差异

数据量参考值给出的是同量级的经验区间，实际边界受域间差异影响：差异越大，同一数据量下需要越大的适配范围。选择规则可以概括为：先取最小的适配范围跑通基线，再按验证曲线的欠拟合程度逐级扩大，扩大后同步加强遗忘抑制。

3. 遗忘的抑制：EWC 与回放

全量微调会把参数推离对源任务重要的位置，造成灾难性遗忘。EWC 用 Fisher 信息矩阵度量每个参数对源任务的重要性，对重要参数施加二次惩罚：

L = Ltask(θ) + (λ/2) Σi Fi (θi − θ*S,i)2 Fi 为源任务似然对参数 i 的 Fisher 信息（用源域数据估计），θ*S 为源域最优参数

Fisher 信息大的参数被强锚定，信息量小的参数自由适配目标域。联合训练中还有更直接的手段：回放缓冲区保留一部分源域数据，目标域 batch 与源域 batch 按比例混合。EWC 不需要保留源数据但只给出近似保护，回放保护更可靠但消耗存储与计算，两者按数据可得性选择。实践中常见组合是 70% 目标域加 30% 源域的混合比例起步。

4. 数值算例：Fisher 加权的惩罚分配

取两个参数示例：源域最优值 θ*1 = 0.8 与 θ*2 = 0.3，源域 Fisher 信息 F1 = 100 与 F2 = 1，强度 λ = 1×103。目标域训练后两个参数分别偏离 0.1 与 0.2，代入惩罚式：

(λ/2)(F1Δ12 + F2Δ22) = 500 × (100 × 0.01 + 1 × 0.04) = 500 × 1.04 = 520 第一个参数的贡献 500，占 96%；第二个参数的贡献 20，占 4%

惩罚梯度的差异更直观：∂惩罚/∂θ1 = λF1Δ1 = 10000，∂惩罚/∂θ2 = λF2Δ2 = 200，前者是后者的 50 倍。数值结果给出三条读法：（1）同样量级的参数偏离，惩罚按 Fisher 比例放大，高曲率方向的移动代价天然更高；（2）λ 的作用与 Fisher 同向，调大 λ 等于把所有参数的保护强度整体提升，参数之间仍按 Fisher 分层；（3）扫描 λ 时应观察源域回访精度的下降速度，λ 每加大一个数量级、回访精度曲线变平的点即为可用上界。

再做一次 LoRA 的参数量核算：骨干隐层维度 d = 2048、24 层注意力、每层在 Q 与 V 两个投影注入、秩 r = 16。每个投影的可训练参数为 d × r + r × d = 2 × 2048 × 16 = 65536；每层两个投影合计 131072；24 层合计约 315 万。对照被冻结的部分：Q、V 投影每个 419 万参数、两层合计 838 万、24 层约 2.01 亿。适配参数占该部分的比例约 1.6%。骨干越大该比例越低：24 层、d = 4096 的骨干上占 Q、V 部分约 0.8%；7B 级视觉语言骨干（32 层、隐维 4096）上适配参数约 840 万，占骨干总参数约千分之一量级。这是参数高效微调在大型预训练模型上稳定的直接原因。

5. 对齐目标：把两域特征拉近

当目标域视觉风格差异明显（光照、相机、背景），可在特征空间加对齐损失。最大均值差异（Maximum Mean Discrepancy, MMD）度量两域特征分布的距离：MMD2 = ‖ES[φ(z)] − ET[φ(z)]‖2，用核函数展开后可写成 Gram 矩阵的均值组合。对抗式对齐（DANN 式）训练域判别器并用梯度反转让特征无法区分域标签。对齐强度需要控制：过度对齐会让特征丢失任务判别性，症状是两域验证误差同时上升。

实现思路与设计

本节给出四阶段适配流程。第一阶段冻结主干只训动作头，建立目标域基线；第二阶段注入 LoRA 并解冻动作头联合训练；第三阶段按验证曲线决定是否解冻视觉编码器末段；第四阶段用混合回放与 EWC 正则在目标数据增量的同时锁定源能力。世界模型侧同步做轻量适配：冻结重建主干，只调奖励头与动作条件编码器。与第 064 章的差异：本章改变可训练参数集合，训练流程与数据配比需相应调整。

超参数默认值作用取值依据
LoRA 秩 r16适配容量目标域数据数百条时 r 超过 32 易过拟合
LoRA 缩放 α32增量幅度常取 2r 使初始增量量级稳定
注入位置Q、V 投影影响语义选择注意力语义路径，性价比最高
EWC 强度 λ1×103源能力保护按源任务损失量级扫描确定
源域回放比例0.3遗忘抑制兼顾目标适配速度与源能力保持
动作头学习率3×10−4最快适配层十倍于 LoRA 层学习率
设计决策：为什么动作头学习率高于适配层

动作头承担目标域的坐标与尺度差异，需要快速重新校准；LoRA 层修改的是语义表示，过快的更新会破坏预训练语义。分组学习率把两类更新解耦：动作头 3×10−4，LoRA 层 3×10−5，冻结主干零更新。把学习率当作“修改权限”的分级工具，是迁移训练的基本纪律。

容量与正则的标定流程

  • 秩的先粗后细。先取 r = 8 与 r = 32 两个端点各跑一轮，观察验证曲线：两端差异不显著则取 8，差异明显则在区间内取 16；每次加秩的收益若低于噪声水平即停止。
  • alpha 与学习率的联动。缩放系数 alpha/r 改变增量幅度，学习率改变更新步长，两者作用叠加。固定 alpha = 2r 后再调学习率，可避免两轴同时漂移造成的调参混乱。
  • EWC 强度的扫描区间。从目标域损失初始量级的百分之一起步，每一档放大十倍，记录源域回访精度与目标域验证精度的两条曲线，选择回访精度开始陡降前的一档。
  • 回放比例的成本核算。回放比例 p 使每步计算量增加约 p/(1−p) 的采样与存储开销；从 0.2 起步，若回访精度不达标再升到 0.3，超过 0.4 后目标域收敛明显变慢。
  • 统计量重估的时机。归一化层的运行统计在解冻任何主干模块后都需要重估一轮，用目标域数据做数百步的无梯度前向即可完成。

关键代码与解读

以下片段以参数高效微调与持续学习的公开设计为参照，接口随版本演进。三个片段分别覆盖 LoRA 包装、EWC 惩罚与分组优化配置。

片段 1：LoRA 包装线性层

import math
import torch
import torch.nn as nn

class LoRALinear(nn.Module):
    """冻结原权重，旁路训练低秩增量：目标域适配的最小改动方案。"""
    def __init__(self, base, r=16, alpha=32.0):
        super().__init__()
        self.base = base                          # 预训练线性层，requires_grad=False
        for p in self.base.parameters():
            p.requires_grad = False
        dim_in, dim_out = base.in_features, base.out_features
        self.A = nn.Parameter(torch.empty(r, dim_in))
        # B 零初始化：起始增量 BA = 0，迁移起点与预训练权重完全一致
        self.B = nn.Parameter(torch.zeros(dim_out, r))
        nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))  # A 用常规初始化
        self.scale = alpha / r                    # alpha/r 使不同 r 的增量量级可比

    def forward(self, x):
        # 旁路与前向并行：增量从零开始平滑生长，训练不会跳变
        return self.base(x) + self.scale * (x @ self.A.T @ self.B.T)

解读：（1）冻结 base 参数使优化器只维护两个小矩阵，显存中的优化器状态大幅下降。（2）B 零初始化是 LoRA 的稳定性关键：否则起始前向输出立即偏离预训练模型。（3）alpha/r 缩放让更改秩 r 时不必重扫学习率，等价增量幅度保持稳定。

片段 2：EWC 惩罚项与 Fisher 估计

import torch

def estimate_fisher(model, source_batches, n_batches=16):
    """用源域数据估计对角 Fisher 信息：参数对源任务重要性的近似。"""
    fisher = {n: torch.zeros_like(p) for n, p in model.named_parameters()
              if p.requires_grad}
    model.eval()
    for batch in list(source_batches)[:n_batches]:
        model.zero_grad()
        # 对数似然的平方梯度近似对角 Fisher，无需二阶导数
        loss = model.loglikelihood(batch)
        loss.backward()
        for n, p in model.named_parameters():
            if p.grad is not None:
                fisher[n] += p.grad.detach() ** 2 / n_batches
    model.train()
    return fisher

def ewc_penalty(model, fisher, star_params, lam=1e3):
    """二次惩罚：Fisher 大的参数被锚定在源域最优值附近。"""
    penalty = 0.0
    for n, p in model.named_parameters():
        if n in fisher:
            penalty = penalty + (fisher[n] * (p - star_params[n]) ** 2).sum()
    return 0.5 * lam * penalty

解读：（1）对角 Fisher 用梯度平方估计，计算成本约等于一次前向反向，工程上完全可承受。（2）star_params 是源域训练结束时的参数快照，必须与之对齐存储。（3）惩罚按 Fisher 加权：源任务不敏感的参数几乎不受约束，适配自由度得以保留。

片段 3：分组学习率与渐进解冻

def build_param_groups(model, lora_lr=3e-5, head_lr=3e-4, enc_lr=3e-5):
    """把参数分成三档学习率：修改权限的分级工具。"""
    lora, head, encoder = [], [], []
    for n, p in model.named_parameters():
        if not p.requires_grad:
            continue
        if n.endswith(".A") or n.endswith(".B"):
            lora.append(p)                        # 适配层：慢速更新语义
        elif n.startswith("action_head"):
            head.append(p)                        # 动作头：快速校准坐标尺度
        else:
            encoder.append(p)                     # 视觉末段：第三阶段才解冻
    return [{"params": lora, "lr": lora_lr},
            {"params": head, "lr": head_lr},
            {"params": encoder, "lr": enc_lr}]

def unfreeze_encoder_top(model):
    """第三阶段：解冻视觉编码器末段，用小学习率打磨感知风格。"""
    blocks = list(model.vision.blocks)[-2:]       # 只解冻最后两个块
    for blk in blocks:
        for p in blk.parameters():
            p.requires_grad = True
    return model

解读：（1）三档学习率对应三类修改：语义适配、输出校准、感知打磨。（2）解冻从末段开始：末段特征最接近任务语义，改动风险最小；全解冻留到数据充足时再考虑。（3）解冻决策由验证曲线平台期触发，不采用固定步数。

常见坑

  • 负迁移未识别：源初始化差于随机初始化，训练长期落后基线。修复：受控对比实验，若曲线始终落后则改用部分层初始化或域内预训练。
  • 冻结层统计量未更新：主干冻结但归一化层的运行统计仍是源域值，目标域特征分布错配。修复：重估统计量或将归一化层加入可训练集合。
  • 目标域数据过少时全量微调：训练损失迅速下降而验证损失上升，遗忘同时发生。修复：退回适配层方案，扩大 EWC 强度与回放比例。
  • LoRA 秩设置过大：秩接近满秩时适配退化为全量微调的弱化版，失去正则与省显存的优势。修复：从 r = 8 起步，按验证曲线加秩，观察收益递减点。
  • 对齐损失压制判别性：MMD 权重过大，两域特征趋同但任务特征变糊。修复：对齐只作用于浅层特征，权重随训练衰减，监控两域验证误差是否同升。

练习与思考

  1. 计算题：骨干注意力层维度 d = 2048，LoRA 注入 Q、V 两个投影，秩 r = 16。计算可训练参数量与占原权重的比例，并解释该比例为何能在数百条样本上稳定训练。★
    提示
    每层两个投影合计 2 × 2 × d × r = 131072 参数；占该层 Q、V 原权重（838 万）的约 1.6%，过拟合风险大幅下降。
  2. 把片段 2 的 λ 从 1×103 调大为 1×106，预测源域回访精度与目标域收敛速度的变化。★
    提示
    λ 过大时参数被牢牢锚定，源精度几乎不降但目标适配停滞，收敛速度显著变慢。λ 的合理区间由源损失量与目标损失量的比值决定。
  3. 推导题：说明对角 Fisher 近似下 EWC 惩罚项与参数的函数关系，并解释为什么 Fisher 加权等价于在参数空间定义了一个各向异性的度量。★★
    提示
    惩罚是二次型 (θ−θ*)Tdiag(F)(θ−θ*)，Fisher 大的方向曲率大即“距离更贵”；各向异性度量决定了目标域适配可移动的自由方向。
  4. 实验设计：目标域样本量分 100、300、1000 三档，比较冻结动作头、LoRA 适配、全量微调三种方案，报告目标域成功率与源域回访精度，验证“数据量决定适配容量”的经验规律。★★
    提示
    预期 100 档冻结头占优，300 档 LoRA 占优，1000 档全量微调开始反超；回访精度在无遗忘抑制时随适配容量上升而下降。
  5. 设计题：为“同工位更换夹爪”的迁移场景设计完整适配方案：哪些参数解冻、是否需要 EWC、回放比例如何定、如何验证负迁移不存在。★★★
    提示
    夹爪变化主要影响末端动作与接触动力学，动作头加 LoRA 即可；相机与世界模型共享，EWC 强度可调低；源数据回放 20% 至 30%；负迁移用随机初始化对照曲线验证。
