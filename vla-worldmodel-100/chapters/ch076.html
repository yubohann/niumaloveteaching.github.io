第四篇 · 训练机制与应用集成

第 076 章：联合训练中的多模态生成

本章讲多模态生成（Multimodal Generation）在联合训练中的应用：用扩散与流匹配统一建模动作块与未来观测，共享去噪骨干、分离模态损失、少步采样与引导，让动作生成与帧预测互相约束。

  • 主题：生成式建模 / 扩散与流匹配
  • 关键公式：E[ ‖ε − εθ(xt, t, c)‖2 ]，少步采样与引导 ε = εu + w(εc − εu)
  • 预计学时：55 分钟
  • 前置章节：第 075 章：世界模型的隐空间规划

学习目标

  • 理解联合生成的动机：动作与未来观测来自同一物理过程，联合建模为两者提供互相验证的监督。
  • 掌握扩散与流匹配的训练目标，理解加噪调度、噪声预测参数化与速度场回归的区别。
  • 掌握联合令牌序列的架构设计与模态解耦手段，理解模态损失分别归约的必要性。
  • 能实现扩散动作损失、联合去噪损失与少步采样加引导，理解引导系数与动作可行性的关系。
  • 会诊断模态互相污染、引导过激与生成动作不可执行问题，能设计生成质量与执行成功率的分层评估。

背景与动机

本节说明联合生成针对的表示瓶颈：动作回归与帧预测在联合训练中通常各用一套头，动作损失只约束数值精度，未来帧损失只约束视觉相似度。两条监督互不引用，世界模型学到的动力学与策略学到的动作之间缺少显式连接。多模态生成从分布层面统一两者：给定当前观测与语言，联合生成“接下来的动作块与它导致的帧变化”。动作解释帧如何被改变，帧约束动作必须物理可行，互相验证的监督提高了两者的一致性。生成式建模还天然表达多模态分布，与第 062 章的动作分布建模衔接。

核心原理

1. 扩散与流匹配：两种生成参数化

扩散模型定义前向加噪过程：对数据 x0 逐步添加高斯噪声，t 步后的样本为

xt = √ᾱt · x0 + √(1 − ᾱt) · ε，训练目标 E[ ‖ε − εθ(xt, t, c)‖2 ] ᾱt 为累计保留系数，c 为条件（观测与语言）；网络学习从含噪样本预测噪声

流匹配（Flow Matching）直接回归从噪声分布到数据分布的速度场 vθ，直线路径使采样步数可以大幅压缩。两者的工程差别集中在采样效率：扩散需要数步到上百步，流匹配在结构化条件下常用十步以内；训练目标差异不大，实现可共用同一骨干。选择依据是控制频率预算与生成质量的平衡点。

2. 数值算例：噪声参数化的误差放大

前向加噪写成 xt = √ᾱt x0 + √(1 − ᾱt) ε。取 ᾱt = 0.01（接近纯噪声段）：数据系数 √0.01 = 0.1，噪声系数 √0.99 ≈ 0.995，即 xt ≈ 0.1 x0 + 0.995 ε；若网络预测的噪声误差为 δ = 0.1，反推 x0 时的误差被放大 0.995 / 0.1 ≈ 9.95 倍，接近 10 倍。取 ᾱt = 0.81（中段）：系数为 0.9 与 0.436，同样的噪声误差对应 x0 误差放大系数 0.436 / 0.9 ≈ 0.48，误差被衰减。

预测 x0 时的误差放大系数 = √(1 − ᾱt) / √ᾱt ᾱ 越小放大越强：纯噪声段约 10 倍，中段小于 1 倍，训练早期附近趋于 0

数值结果解释了参数化选择的实践准则：（1）噪声参数化在整个时间段内的误差传播相对均衡，预测 x0 在接近纯噪声的区段把误差放大近十倍，这是噪声预测成为默认参数化的量化依据；（2）调度设计的核心是让训练样本在各 ᾱ 区段分布合理，若大量时间步落在纯噪声端，即使参数化正确，该区段的学习信号也因信噪比过低而贡献有限。两种生成范式的工程特性对照如下：

选择依据：控制预算宽松、质量优先时用成熟扩散管线；控制频率受限或需要低延迟时优先流匹配与蒸馏组合。两者共享骨干与条件注入设计，切换成本主要在损失与采样实现，训练数据与评估协议可以复用。先按延迟预算选范式，再在范式内调调度与步数，顺序反过来会把采样问题误判为模型容量问题。

3. 联合建模：共享骨干与模态解耦

联合生成把动作块与未来帧编码为同一序列的令牌：动作令牌携带控制信息，视觉令牌携带预测结果，二者共享去噪骨干，靠模态嵌入区分归属。损失按模态分别归约：动作与视觉的噪声方差尺度不同，混合归约会让梯度向方差较大的模态倾斜。共享骨干提供跨模态一致性，模态嵌入与分离损失防止互相污染；去噪时间步可以全模态共享（实现简单），也可以分模态调度（动作快、视觉慢，保证各自信噪比匹配）。

4. 条件与引导

去噪器的条件 c 包含当前观测、语言与任务状态。无分类器引导（Classifier-Free Guidance）训练时以一定概率丢弃条件，采样时用条件与非条件估计外推：

ε = εu + w · (εc − εu) w 为引导强度：w = 1 等价于纯条件生成，w 增大强化条件跟随，过大会牺牲多样性并放大伪影

引导强度的双面性在动作生成中更尖锐：w 过大使动作过激、集中在条件方向而丢失可行域内的多样性；w 过小则指令跟随弱。动作生成的引导系数经验区间为 1 至 2，需要与执行层配合评估：生成似然漂亮而执行成功率下降是引导过强的典型信号。

5. 采样预算与可执行性

实时控制的采样预算按控制周期分配：8 步采样的单次前向开销是 1 步的八倍，须与编码器、规划器共享预算。三个压缩手段：少步采样器（DDIM 式的确定性更新）、蒸馏（一致性模型把多步压缩为一步到四步）、缓存复用（相邻控制步的条件变化小，复用部分中间结果）。生成动作进入执行前必须过滤：越界分量投影、速度与加速度限幅、碰撞检查。生成质量的评估分两层：分布距离（与数据集动作的统计距离）与执行成功率，后者才是最终口径。

实现思路与设计

本节给出组合方案：动作块与下采样后的未来帧统一令牌化，共享一个去噪骨干；观测与语言经条件编码器注入；训练损失为动作项与视觉项之和，权重按标准差比配平；推理用 8 步采样加引导系数 1.5，动作合法化后交给执行层。世界模型的帧预测与策略的动作生成共享该骨干的中间表示。与第 075 章的差异：第 075 章在已有动力学上做搜索，本章改变生成模型本身，使动作与帧在分布层面互相约束。

设计决策：为什么动作与视觉的噪声水平保持同步

若两模态使用独立时间步，去噪器需要处理“动作已清晰而视觉仍模糊”的组合状态，跨模态一致性约束在训练中难以建立。同步噪声水平让两者沿同一去噪轨迹推进：清晰程度一致时，动作解释帧变化的对应关系可以逐时间步建立。代价是视觉模态的收敛节奏被动作模态牵制，缓解方式是按模态调整损失权重；拆分时间步会让去噪器重新面对清晰度错位的组合状态。

推理预算与质量分层的执行要点

  • 步数与延迟的换算。每步采样包含条件与无条件两次去噪前向（引导模式），8 步对应 16 次前向；批次合并两次前向后可摊薄为约 8 次等效开销。延迟预算不足时先减步数到 4，再考虑一致性蒸馏。
  • 蒸馏的部署检查。一致性模型把多步压缩为一到四步，蒸馏目标与教师采样轨迹绑定；部署前用未见条件的验证集检查蒸馏样本的模态覆盖，蒸馏过度会集中在教师的高频路径上，多样性下降。
  • 引导系数的扫描口径。以执行成功率为准绳扫描 w ∈ [1.0, 2.0]，同时报告生成样本与数据集动作的分布距离；两项指标背离时以成功率为准，避免选择“看起来更像数据、执行反而更差”的工作点。
  • 合法化的触发率监控。采样后投影的触发率长期偏高说明训练数据含非法片段或调度不匹配；先检查数据侧，再考虑增大训练步数覆盖。
  • 模态权重的调整顺序。先固定视觉权重训练动作项到收敛，再联合微调视觉项；同时起步会让两模态在早期互相争夺骨干容量。

关键代码与解读

以下片段以扩散策略与多模态扩散模型的公开设计为参照，接口随版本演进。三个片段分别覆盖扩散动作训练、联合去噪与少步采样引导。

片段 1：扩散动作头的训练步

import torch
import torch.nn.functional as F

def diffusion_action_loss(model, obs_feat, lang_feat, action):
    """扩散动作训练：随机时间步加噪，回归注入的噪声。"""
    b = action.shape[0]
    t = torch.randint(0, model.n_steps, (b,), device=action.device)
    alpha_bar = model.alpha_bar[t].view(b, 1, 1)     # 累计保留系数查表
    eps = torch.randn_like(action)
    # 前向加噪：闭式表达，无需逐步模拟
    x_t = alpha_bar.sqrt() * action + (1 - alpha_bar).sqrt() * eps
    cond = model.condition(obs_feat, lang_feat)
    pred = model.denoiser(x_t, t, cond)
    # 预测噪声是最常用的参数化；预测 x0 或 v 是等价变体
    return F.mse_loss(pred, eps)

解读：（1）随机时间步使每个 batch 覆盖全噪声谱，无需按步调度。（2）闭式加噪避免逐步推导，训练成本与单次前向持平。（3）条件在训练期以概率丢弃（片段 2 给出），此处假定传入已处理的条件。

片段 2：联合令牌去噪与模态分离损失

def joint_generation_loss(model, obs, lang, action, future_frame, drop_p=0.1):
    """动作与未来帧联合去噪：共享骨干，损失按模态分离。"""
    act_tokens = model.act_tokenizer(action)          # B x La x D
    vis_tokens = model.visual_tokenizer(future_frame) # B x Lv x D
    tokens = torch.cat([act_tokens, vis_tokens], dim=1)
    b, L, _ = tokens.shape
    t = torch.randint(0, model.n_steps, (b,), device=tokens.device)
    alpha_bar = model.alpha_bar[t].view(b, 1, 1)
    eps = torch.randn_like(tokens)
    x_t = alpha_bar.sqrt() * tokens + (1 - alpha_bar).sqrt() * eps
    # 条件丢弃：以 drop_p 概率置空，训练同一骨干兼做有条件与无条件生成
    keep = (torch.rand(b, 1, 1, device=tokens.device) > drop_p).float()
    cond = model.condition(obs, lang) * keep
    pred = model.denoiser(x_t, t, cond, mode_embed=model.mode_ids(L))
    la = act_tokens.shape[1]
    # 分离归约：两模态噪声尺度不同，混算会偏袒大方差模态
    loss_act = F.mse_loss(pred[:, :la], eps[:, :la])
    loss_vis = F.mse_loss(pred[:, la:], eps[:, la:])
    return loss_act + 0.5 * loss_vis

解读：（1）模态嵌入按令牌位置注入，骨干无需知道序列布局。（2）条件丢弃概率作用于整样本：保证无条件分支看到完整样本，逐令牌丢弃会打散条件。（3）0.5 的视觉权重是起点，按两模态损失收敛速度差异调整，防止视觉项淹没动作项。

片段 3：少步采样与引导

@torch.no_grad()
def sample_actions(model, obs, lang, steps=8, guidance=1.5):
    """少步采样加无分类器引导：生成一个动作块。"""
    x = torch.randn(obs.shape[0], model.act_len, model.act_dim,
                    device=obs.device)
    ts = torch.linspace(model.n_steps - 1, 0, steps).long()
    cond = model.condition(obs, lang)
    for i in range(steps):
        t = ts[i].expand(x.shape[0])
        # 两次前向：条件与无条件估计，外推放大条件方向
        eps_c = model.denoiser(x, t, cond)
        eps_u = model.denoiser(x, t, cond=torch.zeros_like(cond))
        eps = eps_u + guidance * (eps_c - eps_u)
        x = model.ddim_step(x, eps, t)                # 确定性更新，步长按 t 查表
    # 合法化：越界分量投影回可执行范围，防止生成不可执行动作
    return x.clamp(-1.0, 1.0)

解读：（1）条件与无条件两次前向是引导的固有开销，批次合并可摊薄。（2）确定性更新使相同条件与初噪的生成可复现。（3）钳位是最后防线，训练中应让实际触发率保持在低位。

常见坑

  • 模态互相污染：视觉项的梯度改变动作生成质量，动作方差异常增大。修复：分离损失归约，强化模态嵌入。
  • 引导过激：w 过大后动作多样性消失、执行成功率下降。修复：按执行成功率选择引导系数，控制在 1 至 2。
  • 采样调度不当：少步数配线性时间表产生明显伪影。修复：改用余弦或指数调度。
  • 生成动作不可执行：速度突变或越出关节范围。修复：数据侧剔除非法片段，采样后投影限幅，统计触发率。
  • 视觉项拖慢动作收敛：噪声尺度未配平，动作项长期欠拟合。修复：按噪声标准差配平权重，先动作后视觉。

练习与思考

  1. 计算题：8 步采样相对 100 步的全采样，前向次数下降多少倍？说明确定性少步采样为什么能在保持质量的条件下完成这项压缩。★
    提示
    约 12.5 倍。少步更新用确定性映射替代随机重采样，误差主要在低噪声段，配合良好的调度可把损失压到可接受范围。
  2. 把片段 3 的引导系数从 1.5 调到 3.0，预测动作多样性、指令跟随度与执行成功率的变化。★
    提示
    指令跟随度上升、多样性下降，执行成功率通常先平后降；超过 2 后动作幅度偏激，成功率下降明显。
  3. 推导题：说明噪声预测目标与分数函数的关系（ε 与 ∇log p 的比例因子），并解释该关系为什么使扩散可以理解成学习数据分布的梯度场。★★
    提示
    ε = −√(1−ᾱ) · ∇xlog p(x_t)，预测噪声等价于估计对数密度的梯度场，采样沿梯度方向移动到高密度区域。
  4. 实验设计：对视觉损失权重 {0.1, 0.5, 1.0} 做扫描，报告动作执行成功率与帧预测误差两项指标，找出权重与两项指标的交换曲线。★★
    提示
    视觉权重增大后预测误差下降但动作成功率可能回落；曲线交叉点即推荐工作点，因任务对两者的敏感度不同而因场景而异。
  5. 设计题：设计流匹配替代扩散的对照实验：训练目标、采样步数、质量指标三层对齐，说明什么条件下流匹配明显占优。★★★
    提示
    同一骨干与数据下比较回归速度场与回归噪声；采样步数从 4 到 32 扫，流匹配在低步数段优势最大；高步数段两者趋近。

小结

  • 联合生成统一动作与未来帧：动作解释帧变化，帧约束动作物理可行。
  • 扩散回归噪声、流匹配回归速度场，训练目标接近，工程差别集中在采样效率。
  • 共享骨干配合模态嵌入与分离损失，防止模态互相污染。
  • 引导系数按执行成功率选择，少步采样与蒸馏共同控制推理延迟。
