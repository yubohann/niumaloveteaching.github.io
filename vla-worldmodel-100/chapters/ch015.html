第一篇 · 基础框架与联合训练

第 015 章：联合训练中的探索策略

本章处理数据覆盖不足的问题：动作层噪声注入与调度、基于预测误差的内在奖励、规划打分中的信息增益项，以及真实环境探索的安全约束与想象探索的边界。

  • 主题：联合训练 / 探索策略
  • 关键公式：rint = ‖ôt+1 - ot+1‖（预测误差型内在奖励）
  • 预计学时：60 分钟
  • 前置章节：第 014 章

学习目标

  • 理解演示数据覆盖不足对策略泛化的限制，明确探索在联合训练中的位置。
  • 掌握动作层探索机制：噪声注入、温度采样与调度衰减，理解安全裁剪的必要性。
  • 掌握基于世界模型的内在奖励（Intrinsic Reward）构造：预测误差与集成分歧两种信号。
  • 理解信息增益在规划打分中的接入方式，及其与代价最小化的权重关系。
  • 能设计真实环境探索的安全边界与想象探索的可信度门控，并诊断伪好奇类问题。

背景与动机

示教数据只覆盖任务空间的一小片区域：走过的路径、抓过的物体摆放、习惯的节奏。策略在覆盖区内可靠，进入未覆盖状态后输出分布外动作的概率上升，世界模型的预测可信度同步下降。探索的目标是主动获取覆盖，让两者的可靠区域一起扩张。

联合训练提供了两种探索场所：真实环境中的动作扰动代价高但信息真实；世界模型中的想象探索代价低，但受预测保真度限制，在未覆盖区域恰恰是最不可信的地方。本章的机制设计围绕两者的互补展开：小规模真实的定向探索校准模型，大规模想象探索扩展策略训练分布。

边界：006、008 章的采样噪声服务于生成多样性，本章的探索服务于信息获取；013 章存取探索经验；037 章把内在奖励并入强化学习目标。

核心原理

1. 探索的两个场所与备选信号

探索行为需要方向，随机扰动获取的信息量低，有方向的探索依赖“新颖度”信号：动作分布外、状态访问稀少、预测误差大，三个维度都可以作为新颖度来源。其中预测误差最具可操作性：世界模型本身就是误差测量仪，一次前向即可输出当前状态的可预测程度。真实环境探索按周期性小批量执行，想象探索在每次 rollout 时按比例混入探索性分支。三个来源的对照见下表，组合使用是常规做法：预测误差为主信号，访问计数作惩罚项，动作分布外作辅助标记。

新颖度来源判据单次成本主要失效
动作分布外策略密度低于阈值低把策略自身盲区当成环境新颖
状态访问稀少访问计数或密度估计中（需维护统计）高维观测下计数稀疏不可靠
预测误差大世界模型前向误差一次推演不可预测噪声被误判为新颖

2. 动作层探索与调度

最基础的机制是在策略输出上叠加噪声：

aexplore = clip( πθ(o) + ε , amin, amax ) ，ε ~ N(0, σ2(step)) σ 随训练步数衰减；裁剪把探索限制在安全动作区间

σ 的调度遵循“先宽后窄”：早期覆盖优先，噪声标准差取数据标准差的 0.1 量级；随任务成功率上升逐步收紧。裁剪是硬约束：机器人动作超出安全区间可能造成碰撞或过载，探索空间必须由安全工作域先行界定。离散动作则以温度采样替代噪声，温度调度曲线与 σ 同构。

噪声覆盖范围用高斯分位估计：±1.96σ 覆盖 95% 的采样质量，±3σ 覆盖 99.73%；σ=0.1σdata 时绝大多数扰动落在数据标准差的 ±0.3 倍以内，安全余量按此口径核算。限幅的副作用也要记账：动作贴近边界时裁剪把对称噪声变成单边，探索方向被系统偏置，边界附近的样本统计失真；诊断方式是统计被裁剪样本在动作各维的占比，占比超过 5% 说明初始 σ 相对工作域过宽。

离散动作的对应形式是温度采样：logits 除以温度 T 后做 softmax，T 越大分布越平坦。两种调度可以共用同一条“熵曲线”标定：高斯分布的熵为 H = ½·ln(2πeσ2)，σ 减半时熵减少 ln2 ≈ 0.69 纳特；softmax 分布的熵随 T 单调变化，把调度目标写成“从高熵降到低熵的固定比例”（例如保留两成探索熵）即可在连续与离散动作间保持一致口径。

3. 内在奖励：预测误差与集成分歧

把预测误差转成奖励信号，纳入策略改进：

rint(t) = ‖ôt+1 - ot+1‖1（或潜空间等价形式） 误差越大表示状态越新颖；奖励经运行均值归一化后与任务奖励合并

直接用预测误差有已知缺陷：随机环境中的不可预测噪声会持续产生高误差，探索者围着噪声源打转，即伪好奇问题。区分手段是用集成分歧替代原始误差：多个世界模型副本的预测方差度量认知不确定性，环境固有噪声会被各副本一致预测，方差很低。集成规模取 4–6 个副本的折中，每副本一轮前向，成本可控。

伪好奇的本质是两类不确定性混杂，总方差分解可以把它拆开：对集成预测取 Var = Em[σm2] + Varm[μm]，第一项是各副本自身预测方差（环境固有噪声，不可通过学习消除），第二项是副本均值的离散程度（认知不确定性，数据增加后下降）。原始预测误差同时包含两项，闪烁干扰区因此持续获得高奖励；集成分歧只取第二项，对固有噪声免疫。对照场景：闪烁干扰区第一项高、第二项低，奖励接近零；未见动态区第二项高，奖励显著，探索被导向真正可学习的区域。

标注成本需要按次数记账：一条 9 状态的轨迹配 5 个副本，需要 5×9 = 45 次推演前向；按每千步一批次的标注频率，集成开销相对主训练循环占比很小，这也是集成信号适合做数据标注而不适合做逐步在线奖励的原因。

内在奖励的归一化不是可选步骤：预测误差的量纲随模型改进持续缩小，直接与任务奖励相加会让早期高误差淹没任务信号、后期信号消失。实现用运行统计：r̂ = (r - μrun)/(σrun + ε)，μ、σ 按滑动窗口 1 万步更新；归一化后内在奖励均值在 0 附近、方差为 1，权重 0.1 的含义因此稳定为“任务奖励量级的十分之一”，跨训练阶段可比。

计数型新颖度是另一条互补路线，常用 1/√N(s) 形式：访问次数从 1 增到 100 时奖励从 1 降到 0.1，衰减平滑且无需模型前向。两条路线各有短板：计数对高维状态的离散化敏感，集成依赖模型质量；两者按来源标记分别进入缓冲，训练时按可用性选择，模型尚未训好时先用计数信号。

4. 规划打分中的信息增益

014 章的规划打分函数可以加入信息增益项，让规划器主动选择“能减少模型不确定性”的动作序列：

Cost′(τ̂) = Cost(τ̂) - λig·IG(τ̂) ，IG 近似为集成分歧或其下降量 λig 取 0.1 起步；过大时规划器牺牲任务进度换信息

信息增益的精确计算需要推断更新，工程上用可计算代理：候选轨迹末端状态的集成分歧，或访问频次的负对数（新颖度计数）。λig 需要在“任务完成”与“模型改进”之间标定：观察两项分量的占比曲线，占比过高说明规划器变成了探索器，需要下调。

权重翻转的临界点用两个候选算例固定：候选 A 代价 1.00、信息增益 0.0，候选 B 代价 1.05、信息增益 0.4。λig=0.1 时 B 的修正代价为 1.05-0.04=1.01，A 胜出；λig=0.2 时 B 变为 0.97，反超 A，规划器开始用 5% 的任务代价换取 0.4 单位的信息。占比监控口径：滚动窗口内信息项绝对值除以总代价绝对值，比例超过 30% 判定探索压过任务，低于 5% 时该项可关闭以减少打分噪声；这两条线比“感觉探索多了”可靠得多。

5. 安全约束与想象边界

真实探索的三层防护：动作限幅（物理工作域）、速率限制（相邻步变化率上界）、接管机制（人工或规则检测异常时切换保守策略）。想象探索的门控：在不确定性超阈值的区域，世界模型失去参考价值，基于想象的探索信号视为无效；探索性分支的置信度按 006 章的门控返回，低置信分支只用于模型自身的检验，不进入策略训练（008 章的过滤规则）。

速率限制的标定方式：以关节速度上限乘控制周期得到每步变化上界，先做空机验证确认限制触发时机构无异常抖动，再接入真实探索。接管机制需要可演练的触发条件，例如连续 5 步新颖度超阈值且速率限制持续触发，或安全监督报出碰撞预警；触发后切换保守策略并记录现场数据，这类数据往往正是最有价值的新颖样本，标注后进入缓冲的高优先级队列。

想象探索的有效边界由模型误差界定：预测误差高于训练集 90% 分位的状态区，想象轨迹的统计性质与真实分布脱节，基于它的探索信号视为无效，该区域只能靠真实环境的定向探索获取数据。边界随模型改进重新标定，标定频率与验证周期一致；边界外扩的速度本身是衡量世界模型进步的直接指标。

覆盖进展用可量化指标跟踪：状态空间按任务相关维度网格化，占用率为有访问网格数除以总网格数。探索的目标是在任务成功率不下降的前提下提高占用率，两个指标必须同时报告，单看覆盖率会把“到处乱跑”当成进展。稳定判据是连续两个验证周期的占用率增幅低于 1% 且成功率持平，此时可以收紧噪声进入利用阶段。

实现思路与设计

探索系统四个组件：噪声调度器（动作层）、新颖度估计器（集成世界模型）、奖励合成器（任务奖励与内在奖励加权）、安全监督器（限幅、速率与接管）。想象与真实两条路径共享新颖度估计，探索预算独立配置。

设计决策：探索信号只用于数据选取，不直接驱动推理动作

训练期的探索噪声与内在奖励用于选取和加权经验；推理期策略保持确定性输出（004 章原则）。把“探索数据的选择”与“部署行为的确定”分离，避免训练信号泄漏到推理行为，也让探索强度可以自由调整而不影响上线表现。

衔接与差异：006 章的动作噪声在此获得调度机制；008 章的数据过滤为低置信探索样本提供出口；013 章的缓冲为探索样本提供存储与来源标记；037 章会把内在奖励并入强化学习目标。

关键代码与解读

片段以基于模型的探索与集成不确定性估计的公开设计为参照，接口随版本演进。第 1 段给出带安全约束的探索噪声。

片段 1：探索噪声与安全约束

import torch

def explore_action(policy_out, sigma, a_lo, a_hi, rate_limit=None, prev=None):
    """动作层探索：按调度后的尺度加噪，经限幅与速率限制后输出。"""
    eps = sigma * torch.randn_like(policy_out)
    a = policy_out + eps
    # 第一层：工作域限幅，探索永远不越出安全动作区间
    a = torch.clamp(a, min=a_lo, max=a_hi)
    if rate_limit is not None and prev is not None:
        # 第二层：速率限制，相邻步变化过快会损伤机构或触发保护
        delta = torch.clamp(a - prev, min=-rate_limit, max=rate_limit)
        a = prev + delta
    return a

def sigma_schedule(step, sigma0=0.1, decay_steps=50_000, sigma_min=0.02):
    """噪声尺度调度：线性退火到下限，下限保留少量持续探索能力。"""
    ratio = min(1.0, step / float(decay_steps))
    return max(sigma_min, sigma0 * (1.0 - ratio))

解读：（1）两类约束串联执行：先限幅再限制速率，顺序不能互换，速率限制可能把动作推回非安全区，需要按此顺序验证边界行为。（2）下限 σmin 保留持续探索能力，完全归零后系统对分布漂移的敏感性再也无法被探测。（3）调度函数是纯函数，步数与曲线可单元测试，方便在实验记录中还原任意时刻的探索强度。

片段 2：集成分歧型内在奖励

@torch.no_grad()
def intrinsic_reward(ensemble, context, action):
    """集成分歧型内在奖励：副本预测方差度量认知不确定性，避开环境噪声。"""
    preds = [world.dynamics(context, action) for world in ensemble.models]
    stacked = torch.stack(preds, dim=0)           # (M, B, d_z)
    # 逐样本方差再对潜维度平均：方差大表示副本对该状态的认知不一致
    disagreement = stacked.var(dim=0, unbiased=False).mean(dim=-1)
    return disagreement                            # (B,) 作为内在奖励原值

def combine_rewards(task_reward, intrinsic, w_int=0.1, step=0, decay=50_000):
    """奖励合成：内在奖励随训练衰减，任务奖励始终主导。"""
    # 归一化后合并：内在奖励经运行统计缩放到与任务奖励同量级（005 章设施）
    w = w_int * max(0.0, 1.0 - step / float(decay))
    return task_reward + w * intrinsic

解读：（1）副本逐个前向以保持各自独立的随机性来源；集成 5 份的成本仅用于数据标注，不做每步在线计算。（2）以逐样本方差作为预测误差口径：环境固有权重噪声被各副本一致预测，方差低，从而避开伪好奇。（3）内在奖励权重随训练衰减到零，保证后期收敛回任务目标，衰减窗口与噪声调度同量级。

片段 3：探索分支的标注与筛选

@torch.no_grad()
def tag_exploration(actions, base_actions, sigma, reward_int, q_int=0.9):
    """探索样本标注：标记来源与新颖度等级，供缓冲分层与训练加权使用。"""
    # 与策略基线动作的偏差幅度：判断该步是否属于探索性动作
    deviation = (actions - base_actions).norm(dim=-1)
    is_explore = deviation > 1.0 * sigma
    # 新颖度分位阈值：只有显著高于常规水平的内在奖励才算高新颖样本
    thresh = torch.quantile(reward_int.float(), q_int)
    is_novel = reward_int >= thresh
    # 返回两级标签：缓冲按标签分层，训练损失按新颖度加权（008 章接口）
    tags = {"explore": is_explore, "novel": is_novel}
    return tags

def keep_for_training(tags, max_ratio=0.3):
    """筛选入训样本：高新颖样本比例设上限，防止探索数据主导训练分布。"""
    # 高新颖样本信息量大但偏离任务分布，比例失控会让策略退化为探索者
    novel = tags["novel"]
    if novel.float().mean() > max_ratio:
        # 随机下采样到配额内：保留信息量，同时锁住分布占比
        keep_prob = max_ratio / novel.float().mean()
        mask = novel & (torch.rand_like(novel.float()) < keep_prob)
        return tags["explore"], mask
    return tags["explore"], novel

解读：（1）偏差阈值以噪声尺度为单位，任何时刻的判定标准随调度自动缩放，无需手工维护。（2）两级标签分工：explore 标签用于缓冲分层，novel 标签用于损失加权与比例控制。（3）入训配额上限是对“探索数据反噬”的结构性防御，与 008 章的 α 下界形成对称约束：一边限制想象占比，一边限制探索占比。

常见坑

  • 噪声过大损伤硬件：σ 未受约束，探索动作触发机械保护或碰撞。修复：限幅与速率限制作为强制层，噪声调度设置上限并与安全工作域联合标定。
  • 伪好奇打转：机器人围着闪烁灯光或移动人员反复探索。修复：以集成分歧替换原始误差，并对持续高新颖区域做访问频次惩罚。
  • 探索数据分布反噬：高新颖样本无上限入训，策略退化为探索者，任务成功率下滑。修复：入训配额上限（0.3 起），并监控任务与探索两类样本的损失占比。
  • 想象探索越界：在预测不可信区域生成大量“想象出来的新颖”，训练数据被幻觉污染。修复：探索分支过 006 章的不确定性门控，低置信轨迹不标注新奇。
  • 调度与成功率脱节：噪声衰减周期固定且与任务进展无关，过早收敛或过晚稳定。修复：调度曲线挂接任务成功率的分段函数，联合观察后再定周期。

练习与思考

  1. σ0=0.1、衰减周期 5 万步、下限 0.02，写出第 0、2.5 万、5 万步的噪声尺度，并说明下限的工程意义。★
    提示
    依次为 0.1、0.05、0.02；下限保证系统在长期运行中持续具备分布漂移探测能力。
  2. 把内在奖励权重从 0.1 提到 0.5，预测探索行为与任务成功率的变化，给出观测指标。★
    提示
    探索行为显著增多、状态覆盖上升，但任务成功率预期下滑；用覆盖率与成功率的双曲线交叉点判断权重上限。
  3. 推导：说明集成分歧为什么能区分认知不确定性与环境固有噪声，并给出一个反例情形。★★
    提示
    固有噪声被各副本一致预测，方差低；反例是副本初始化差异过大时，固有噪声也会被估计成认知不确定，需要共享训练数据与初始化校准。
  4. 设计探索调度的完整方案：以任务成功率为输入的衰减函数、下限、与噪声尺度的联动，写出触发规则。★★
    提示
    成功率连续三档（如 0.3、0.6、0.8）对应噪声折半；下限保持常数；成功波动时维持档位不变，防止调度振荡。
  5. 构造实验：在一个含随机闪烁干扰的环境中分别用预测误差与集成分歧做内在奖励，比较探索行为分布与任务表现，解释差异。★★★
    提示
    预测误差版会把大量时间花在干扰源附近；集成分歧版对该区域方差低、探索少，任务表现更优。用状态访问热图对比两者。

小结

  • 探索扩张策略与世界模型的可靠区域，真实与想象两个场所互补。
  • 动作层噪声按调度先宽后窄，限幅与速率限制是强制性的安全层。
  • 内在奖励用集成分歧替代原始预测误差，规避伪好奇，权重随训练衰减。
  • 规划打分可加信息增益项，λig 按两项代价占比标定。
  • 探索数据有两道占比约束：入训配额与想象占比，防止探索反噬训练分布。
