第二篇 · 联合训练进阶与策略能力

第 028 章：联合训练中的随机化

把环境参数当作随机变量采样，训练目标从单环境最优变为分布上的期望最优；本章讲清随机化参数的分类与分布设计、强度的课程式推进，以及想象 rollout 中的随机化注入。

  • 主题：域随机化（Domain Randomization, DR） / 分布稳健训练
  • 关键公式：minθ Eξ~p(ξ)[ L(θ; ξ) ]；ADR 边界扩张判据
  • 预计学时：50 分钟
  • 前置章节：第 027 章

学习目标

  • 理解域随机化的优化目标：在环境参数分布上的期望风险，与其覆盖目标域的能力边界。
  • 掌握三类随机化参数（视觉、动力学、布局）的建模方式与分布设计原则。
  • 掌握课程式随机化与自动域随机化（Automatic Domain Randomization, ADR）的边界更新机制。
  • 会设计与世界模型联合训练时的随机化注入方案：想象 rollout 的条件采样与评估协议。
  • 能诊断随机化过强、时序不相关与覆盖不足三类典型问题。

背景与动机

世界模型与策略在有限的环境条件下训练，部署环境的物理参数、光照与传感器特性与之存在系统性差异。逐项建模这些差异既昂贵又不可穷尽，域随机化（Domain Randomization, DR）换一个思路：把环境参数当作随机变量，每次训练从分布中采样一组参数，让模型在参数分布上整体表现良好。

与第 024 章的对抗训练形成分工：随机化优化分布的期望性能，覆盖自然差异；对抗训练聚焦分布内的最坏方向，抬高性能下界。联合训练中两者互补使用：动力学参数的随机化让世界模型学会一族动力学，对抗扰动让它在给定参数下抵抗观测噪声。

随机化的收益随强度呈非单调变化：强度不足无法覆盖目标域，强度过大会让任务本身变得难以学习，模型在"平均环境"上欠拟合。随机化强度的推进节奏与参数范围的设计，是本章的核心工程问题。

核心原理

1. 期望风险与覆盖条件

记环境参数向量为 ξ（质量、摩擦、光照、纹理、延迟等），域随机化求解：

minθ Eξ~p(ξ) [ L(θ; ξ) ] p(ξ) 为随机化分布；训练目标是对该分布的期望，而不再是对单一环境的损失

期望风险的泛化能力取决于覆盖关系：目标域（部署环境的参数集合）越接近 p(ξ) 的支撑集，期望性能对部署性能的代理越可靠。两个边界情形：p(ξ) 塌缩为单点即普通训练，部署偏移直接体现为性能损失；p(ξ) 过宽导致任务在部分采样点上不可解（例如摩擦系数过小导致抓取物理上无法完成），标签噪声化、欠拟合。

覆盖是否充分可以用一个可操作的指标度量：在参数空间上定义任务相关区域 Ω（目标域差异可达的参数子集），比较随机化分布落在该区域内的概率质量 ∫Ω p(ξ)dξ 与目标域参数的真实占比。质量不足说明支撑集未覆盖目标域，延长训练无法补救；质量过剩说明范围过宽，额外子集上的采样只贡献方差代价。工程中把 Ω 按参数维度离散为格子，统计格子采样频次与目标域频次的比值，作为覆盖缺口的诊断量。

类别典型参数采样分布注意事项

2. 期望风险的二阶展开

期望目标与单环境目标的差额可以定量拆开。把 L(θ; ξ) 在参数分布均值 ξ̄ 处做二阶泰勒展开：

L(θ; ξ̄ + δ) ≈ L(θ; ξ̄) + ∇ξLTδ + (1/2) · δTH δ，δ = ξ − ξ̄ H 为损失关于 ξ 的海森矩阵；∇ξL 为对参数的梯度

对随机变量 δ 取期望，一次项因 E[δ] = 0 消失，得到 E[L] ≈ L(θ; ξ̄) + (1/2) · tr(HΣ)，Σ 为随机化分布的协方差矩阵。该式给出三条定量结论：代价由曲率与方差共同决定，损失对某参数越敏感（海森特征值越大），同样扰动幅度付出的期望代价越高；方差扩大 k 倍则惩罚扩大 k 倍，对应区间宽度扩大 √k 倍；若某方向的曲率为负（任务在该方向不可解），展开失效，极端采样点把期望损失拉爆，这正是可解性上界的来源。

数值算例：设质量倍率 m 的损失在最优值 m* = 1.0 附近为二次型 L = c(m − 1.0)2，c = 4。均匀采样 m ~ U[0.7, 1.3] 时方差为 0.62 / 12 = 0.03，期望损失为 4 × 0.03 = 0.12；收窄到 U[0.9, 1.1] 后方差为 0.04 / 12 ≈ 0.00333，期望损失 ≈ 0.0133，仅剩约九分之一。宽度收窄到三分之一换来九倍的期望损失下降，覆盖能力同时收窄，这一权衡是强度设计要处理的核心矛盾。

3. 强度上界与课程式推进

任务可解性给出随机化强度的物理上界，但工程上界通常更紧：训练早期模型容量与数据均不充分，大范围随机化让梯度方向分散，学习效率骤降。课程式随机化把范围从窄到宽逐步扩张：

ξt ~ pt(ξ)，范围半径 rt = r0 + (rmax − r0) · min(t / Tramp, 1) rt 为第 t 步的随机化幅度；Tramp 为整个扩张过程覆盖的训练步数

自动域随机化（Automatic Domain Randomization, ADR）把扩张交给数据：每个参数维护一个范围 [lo, hi]，按任务表现决定边界扩张或收缩。判据设计示例：在一批采样环境中评估成功率，高于上阈值则扩张边界，低于下阈值则收缩。ADR 把"何时加难度"从人工调度变成反馈控制，代价是需要额外的评估预算与稳定的表现估计。

数值算例：设摩擦系数范围初始为 [0.4, 0.9]，中心 0.65、宽度 0.5，步长系数 5% 时每侧单次调整 0.025，扩张呈等比序列：第 1 次后 [0.375, 0.925]，第 2 次后 [0.3475, 0.9525]，宽度按 1.1 倍递增；若任务可解性下限为 0.35，第 2 次扩张即越界，成功率跌破下阈值 0.5 并触发收缩，边界在 [0.3475, 0.9525] 附近震荡。把步长系数降到 2%，同等越界余量需要约 5 次扩张才触及，震荡幅度更小，扩张速度也更慢。

4. 时序一致性与相关采样

逐帧独立采样视觉参数会产生高频闪烁，这类扰动在真实传感器上极少出现，训练出的模型对"纹理快速跳变"免疫，却对缓慢漂移（曝光渐变、镜头脏污累积）敏感。正确做法是让参数在时间上相关：每个回合采样一次固定参数，或使用一阶自回归过程在回合内缓慢漂移。

ξt = ρ · ξt−1 + √(1 − ρ2) · ηt，ηt ~ N(0, Σ) ρ 为时间相关系数，取 0.9 至 0.99；该过程保持平稳分布，同时给出平滑漂移

动力学参数的时序结构同样重要：质量在执行过程中缓慢变化（负载渗漏），摩擦在运动发热后下降，这类漂移比每步跳变更接近真实。随机化的时间结构决定模型学会的"适应速度"：回合固定参数训练出快速辨识能力，缓慢漂移训练出在线跟踪能力。

相关系数 ρ 的工程含义可用相关时间度量：一阶自回归过程的记忆长度约为 1/(1 − ρ) 步，ρ = 0.95 对应约 20 步，ρ = 0.99 对应约 100 步。控制周期为 50 ms 时分别约为 1 秒与 5 秒，落在快速抖动与缓慢漂移两个时间尺度上。选取 ρ 时先测量目标故障的自相关时间，再对齐到最近的档位，比按经验取值更可靠。

5. 与世界模型联合的注入位置

随机化在联合训练中有三个注入位置，各自影响不同的模块：数据采集阶段（真实或仿真环境按采样参数运行）决定世界模型与策略看到的数据分布；想象阶段（rollout 时按采样参数对潜动力学施加条件）让策略在想象中见多识广；评估阶段（固定一组留出参数）给出稳健性指标。三者需要分离管理：评估参数集不能在训练中出现，否则稳健性指标失去意义。

注入位置之间还需保持参数语义一致：训练采样器输出的参数向量应能同时驱动环境仿真与想象阶段的动力学条件调制，否则世界模型学到两套彼此脱节的映射，评估时对真实参数的响应出现偏差。实现上把参数向量规范到统一量纲（例如归一化到 [0, 1] 的物理缩放空间），再分别送入环境接口与条件编码器，采样日志记录原始值与归一化值两列以便还原。

实现思路与设计

随机化系统由参数空间定义、采样器、课程控制器与评估协议四部分组成。与第 027 章的差异：027 处理动作接口的精度问题，本章处理训练环境分布的广度问题。

  1. 参数空间清单：按视觉、动力学、布局三类列出参数、量纲与合法范围，标注任务可解性约束。
  2. 采样器：按回合采样基础参数，回合内按自回归过程漂移；采样日志与训练步绑定，保证可复现。
  3. 课程控制器：默认线性扩张；有稳定评估预算时切换 ADR，边界更新频率约每 1000 步一次。
  4. 评估协议：留出参数集分为"分布内采样"与"分布外偏移"两组，分别报告成功率，观察覆盖缺口。

注意：评估参数集与训练参数集必须分离

把评估用的环境参数写入训练采样器，相当于把测试集并入训练集。工程上为训练采样器与评估采样器分别设置随机种子区段，并在采样日志中核对两组参数无交集，这是稳健性实验可信的前提。

关键代码与解读

以下片段参照公开的域随机化与 ADR 实现设计，版本中立；PyTorch 与 NumPy 风格。

片段 1：回合级采样与时间相关漂移

import numpy as np

class Randomizer:
    """回合级基础采样 + 回合内自回归漂移，覆盖慢变故障与固定参数两类情形。"""
    def __init__(self, rho=0.95, seed=0):
        self.rho = rho
        self.rng = np.random.default_rng(seed)
        self.state = None

    def reset(self):
        # 每回合重新采样基础参数：纹理、布局等不随时间变化的量
        self.state = {
            "light": self.rng.uniform(0.5, 1.5),      # 光照倍率
            "mass": self.rng.normal(1.0, 0.1),        # 负载质量倍率，截断在可解范围
            "friction": self.rng.uniform(0.4, 0.9),
        }
        self.state["mass"] = float(np.clip(self.state["mass"], 0.7, 1.3))
        return dict(self.state)

    def step(self):
        # 自回归漂移：围绕基准值波动，平稳方差为 σ²/(1−ρ²)
        base = {"light": 1.0, "mass": 1.0, "friction": 0.65}
        for key in ("light", "mass", "friction"):
            mu = base[key]
            noise = self.rng.normal(0.0, 0.01)
            self.state[key] = (mu + self.rho * (self.state[key] - mu)
                               + np.sqrt(1 - self.rho ** 2) * noise)
        return dict(self.state)

解读：（1）回合级采样覆盖"固定但未知"的参数，回合内漂移覆盖"缓慢变化"的参数，两类故障模式对应两种适应能力；（2）质量采样用正态分布再截断，避免均匀分布把极端值采成常见值；（3）自回归系数 ρ 控制漂移的平滑尺度，ρ 越大变化越缓慢；（4）以返回字典的方式传递参数，不写全局状态，方便采样日志与复现，训练循环拿到参数后写入环境 config。

片段 2：ADR 边界更新

def adr_update(ranges, success_rate, lo=0.5, hi=0.8, step=0.05):
    """ADR 边界更新：表现好则扩张范围，表现差则收缩，保持在学习区间内。"""
    expanded, shrunk = [], []
    for name, (low, high) in ranges.items():
        width = (high - low) * step           # 单次调整幅度与当前宽度成比例
        if success_rate > hi:
            # 高成功率说明当前难度已可掌握，扩张覆盖更多参数
            ranges[name] = (low - width, high + width)
            expanded.append(name)
        elif success_rate < lo:
            # 低成功率说明难度过高，收缩回可学习区间
            ranges[name] = (low + width, high - width)
            shrunk.append(name)
    return ranges, expanded, shrunk

解读：（1）扩张与收缩对称设计，形成围绕目标成功率的闭环控制；（2）调整幅度按当前宽度比例化，范围小的时候步长也小，避免震荡；（3）阈值区间 [0.5, 0.8] 留出死区，成功率在区间内时不调整，减少噪声触发的抖动；（4）返回改动清单便于记录与调试，若某参数长期只收缩，说明初始范围越过了可解边界。

片段 3：想象阶段的随机化条件注入

def imagine_with_randomization(world_model, policy, z0, rand_vec):
    """把随机化参数作为条件向量注入潜动力学，训练分布内的想象轨迹。"""
    z = z0
    trajectory = []
    for t in range(15):                       # 想象步长 15
        a = policy.act(z, rand_vec)           # 策略同样看到随机化条件
        # 世界模型动力学以条件向量调制潜更新，泛化到该参数区间
        z = world_model.transition(z, a, rand_vec)
        trajectory.append((z, a))
    return trajectory

解读：（1）随机化向量同时进入策略与动力学，保证两者对同一组环境参数形成一致的条件；（2）条件向量在训练时从采样器抽取、评估时固定为标称值，实现训练覆盖与评估稳定的分离；（3）想象轨迹在随机化条件下的分布，正是期望风险的蒙特卡洛估计对象；（4）若条件向量维度过大，可先用编码器压缩为低维嵌入，与语言条件共享嵌入空间的思路一致。

常见坑

  • 随机化只在训练开始时采样一次：整个训练过程中环境参数固定，模型没有学到分布上的稳健性。修复：按回合或按固定间隔重采样，回合内按明确的时间结构（固定或漂移）处理。
  • 随机化强度越界：部分采样参数下任务物理上无法完成（摩擦过小、光照过暗），噪声标签拖垮训练。症状是训练成功率整体低于可接受水平。修复：按任务可解性收缩范围，ADR 自动处理边界。
  • 忽略时序相关性：逐帧独立采样让模型只适应高频闪烁，对缓慢漂移脆弱。修复：回合内使用自回归漂移，ρ 按真实故障的时间尺度设定。
  • 评估协议混入训练参数：稳健性指标虚高。修复：训练与评估采样器使用独立种子区段，报告中给出参数分布的重叠检查。
  • 随机化掩盖数据质量问题：传感器标定错误、坐标系偏差等系统性缺陷被"当作随机性"吸收，部署后依然存在。修复：随机化范围与标定误差分开建模，标定修正作为确定性预处理，不进入随机分布。

    提示
    分布内成功率上升更快，分布外成功率短期可能下降（覆盖变窄）；收益边界由目标域的质量分布决定，覆盖不足时泛化指标停滞。
  2. 推导：设 ρ = 0.95、单步噪声标准差为 0.01 的自回归过程，求 ξ 的平稳方差；再把 ρ 提高到 0.99，说明漂移速度与平稳方差各如何变化。★★★
    提示
    平稳方差为 σ² / (1 − ρ²)；ρ = 0.95 时约 0.01² / 0.0975 ≈ 0.001，ρ = 0.99 时约 0.01² / 0.0199 ≈ 0.005。提高 ρ 让漂移更慢但波动幅度更大，需要与真实故障的时间尺度对照选择。
  3. 设计 ADR 的阈值消融：把上阈值从 0.8 改为 0.6（更激进扩张），预测边界宽度曲线与训练成功率曲线的形态变化。★★
    提示
    更激进的扩张让范围增长更快，成功率曲线下移且波动加大；设死区过窄则边界来回震荡。可以画边界宽度与成功率的两条时序曲线交叉对照。
  4. 设计一个覆盖分析实验：用目标域的 5 类外观（材质、光照组合）与随机化分布做二维对照，给出"覆盖缺口"的判定指标与补采样策略。★★
    提示
    对每类外观统计随机化分布在该区域的采样密度，密度低于阈值的格子标记为缺口；补采样策略为在缺口区域内做拒绝采样或局部加密，评估留出集上各外观分组的成功率是否均衡。
  5. 推导：随机化分布为均匀分布且中心不变时，把区间宽度扩大 2 倍，二阶近似的期望惩罚扩大多少倍？结合 c = 4、U[0.9, 1.1] 的算例给出扩张后的期望损失。★★
    提示
    均匀分布方差与宽度平方成正比，惩罚 (1/2)tr(HΣ) 随方差线性变化，宽度扩 2 倍则方差扩 4 倍、惩罚扩 4 倍；算例中期望损失从约 0.0133 升到约 0.0533。可用 10 万样本的蒙特卡洛均值与解析值双重核对。

小结

  • 域随机化把训练目标变为环境参数分布上的期望风险，覆盖条件是性能保证的来源。
  • 随机化参数分视觉、动力学与布局三类，分布设计需要与目标域逐项对照。
  • 课程式扩张与 ADR 控制强度推进，任务可解性与学习效率共同约束有效范围。
  • 参数的时间结构决定模型学到的适应类型，缓慢漂移用自回归过程建模。
  • 随机化与对抗训练互补：前者覆盖自然差异的期望性能，后者抬高最坏方向的下界。
