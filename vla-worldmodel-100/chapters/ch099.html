第 099 章：世界模型的跨环境迁移

从域潜变量的隐式系统辨识，到共享动力学加仿射调制、不变性正则与测试时自适应：世界模型如何把动力学知识带到没有见过的环境。

  • 主题：世界模型（World Model）/ 跨环境迁移（cross-environment transfer）
  • 关键公式：域条件动力学与不变性正则
  • 预计学时：55 分钟
  • 前置章节：第 098 章

学习目标

  • 理解环境差异的分层：观测外观变化、动力学参数变化、任务分布变化，三类差异对应不同的迁移手段。
  • 掌握上下文编码器（context encoder）的隐式系统辨识思路，理解为什么辨识输入必须包含动作序列。
  • 掌握共享骨架加仿射调制（feature-wise linear modulation, FiLM）的结构，理解其与全参数复制的成本差异。
  • 理解不变性与可塑性的权衡，会使用跨域风险方差惩罚约束表示的域不变性。
  • 会设计测试时自适应流程与留一域（leave-one-domain-out）评估协议。

背景与动机

训练环境与部署环境几乎必然不同：地面更滑、摄像头高度变了、执行器响应慢了 20 毫秒，这些差异会直接改变动力学，使预测失准、策略失稳。把每个新环境当作全新任务从零训练，数据与算力都不可行；迁移学习的目标是让模型在新环境中用极少数据恢复精度。

第 065 章与第 085 章分别从迁移学习与元学习角度处理了任务适配，本章针对世界模型的动力学属性：环境差异中最难处理的是物理参数变化（摩擦、负载、延迟），它们不改变任务语义却改变状态转移规律。方案是把"是什么环境"编码为潜变量，让一个共享动力学模型按潜变量调制。评估用留一域协议，检验的泛化边界与第 083 章的组合划分在方法论上同源。

核心原理

跨环境迁移的核心问题是分离"不变"与"可调"：把跨环境稳定的动力学骨架共享，把环境特有的参数交给潜变量调制。

1. 环境差异的分层与迁移手段

  • 观测外观差异：光照、色调、相机内参。适合用数据增强与域随机化覆盖，视觉编码器的鲁棒性训练即可吸收。
  • 动力学参数差异：摩擦系数、质量惯性、致动延迟。不会因数据增强消失，需要显式建模为潜变量并调制转移核。
  • 任务分布差异：物体类别、指令范围变化。属于语义层差异，靠语言与视觉表示的泛化处理（第 083、092 章）。

三类差异的处理手段不同，混在一起调参会互相干扰。工程上先把外观差异用随机化压掉，再处理动力学差异，最后评估任务差异。本章聚焦第二类，它是世界模型迁移的主要矛盾。

2. 上下文编码与域条件动力学

环境参数不可直接观测，从交互历史中推断，即隐式系统辨识：

zdom = cφ( zt−K:t, at−K:t )，pθ( st+1 | st, at, zdom ) cφ 为上下文编码器；K 为历史窗口长度（16–32 帧）

辨识输入必须包含动作序列：不同摩擦系数在"静止"观测下无法区分，只有在动作响应（滑移距离、加速时间）中才暴露。窗口长度决定辨识质量：太短不足以激励差异，太长引入陈旧信息。域潜变量的维度（32–64）是容量约束：维度太小压不进多个参数，太大会记住训练环境的特例而丧失泛化。

3. 结构：共享骨架与仿射调制

把域潜变量注入共享动力学的常用方式是仿射调制（feature-wise linear modulation）：共享骨架产生中间特征，域潜变量生成逐通道的缩放与平移参数：

h′ = γ(zdom) ⊙ h + β(zdom) γ、β 由域潜变量的线性映射生成；⊙ 为逐元素乘积

相比为每个环境复制整套转移核，共享骨架加调制的参数量与环境数无关，且新环境无需新增参数即可应对。调制网络的容量要克制：生成 γ、β 的映射过大会重新引入环境特例记忆。另一种实现是条件拼接（把 zdom 直接拼进输入），表达力低于仿射调制但更简单；两者在中小规模下差距有限，复杂动力学（延迟、非线性摩擦）下调制方案更稳。

4. 不变性正则与可塑性权衡

如果模型完全依赖域潜变量，会把共享骨架退化为恒等映射，每个环境全靠潜变量编码，泛化到新环境时骨架无信息可用。约束手段是跨域风险惩罚：同一共享骨架在不同域上的预测损失应尽量接近，防止对单一域过拟合：

Linv = Vard( Ld )，Ld 为域 d 的预测损失 方差惩罚促使各域损失均衡，抑制骨架偏向某一域

权衡点在于不变性的强度：正则过强时骨架拒绝吸收任何域相关结构，连合法的物理规律（重力方向、运动连续性）都可能被抹平；正则过弱时骨架过拟合训练域。经验做法：只对骨架的低层与中层施加不变惩罚，高层与调制路径保留可塑性；权重从 0.1 起步，按留出域的表现调整。

5. 测试时自适应

进入新环境后用预测误差做自监督，只更新上下文编码器（或在其上加一条轻量适配路径），主体冻结。每步的适应信号是"预测与真实下一潜状态的误差"，无需动作标签。三个安全约束：适配步长小（1e-3 量级）、只在置信度高的段执行（残差监控正常时）、适配结果限幅（域潜变量与训练分布的距离约束）。自适应与第 095 章的残差监控联动：适配期间误差异常升高则回滚到适配前状态。

实现思路与设计

训练流程：域随机化预训练共享动力学 → 加域潜变量调制与不变正则 → 新环境测试时自适应域编码。

  1. 域划分：按物理参数区间划分训练域（摩擦 4 档 × 负载 3 档 = 12 个域），留出 2 个域评测。
  2. 域编码：窗口 16 帧，域潜变量 32 维；编码器与转移核联合训练，但只在动力学损失上回传。
  3. 调制注入：转移核中段两层用仿射调制，低层保持纯共享，保护底层特征。
  4. 正则与评测：不变正则权重 0.1，只作用于骨架；留出域上零样本与少样本（50 条轨迹）两组指标。
  5. 与第 065、085 章的差异：迁移对象是世界模型动力学，手段为域潜变量调制与测试时自适应，与参数高效微调互补。

设计决策：为什么测试时只更新域编码而不微调主干？

主干承载跨环境共享的动力学知识，在线微调的风险高：少量数据的梯度方向可能与全局知识冲突，错误更新难以发现。域编码是低维瓶颈，更新对全局影响可控，出错也容易通过限幅与回滚保护。环境差异超出域编码容量时，应触发离线再训练流程，在线适配无法弥补容量缺口。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：上下文编码器与域调制动力学

class ContextEncoder(nn.Module):
    """隐式系统辨识：从最近 K 帧的状态与动作推断域潜变量。"""
    def __init__(self, d_z=512, d_a=7, d_dom=32, k=16):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(k * (d_z + d_a) + 1, 256), nn.GELU(),
                                 nn.Linear(256, d_dom))
    def forward(self, z_hist, a_hist):
        # 动作序列是辨识的必需输入：不同摩擦只在动作响应中可区分
        flat = torch.cat([z_hist.flatten(1), a_hist.flatten(1)], dim=-1)
        # 变化率统计辅助区分"外观变化"与"动力学变化"
        delta = (z_hist[:, 1:] - z_hist[:, :-1]).norm(dim=-1).mean(1, keepdim=True)
        return torch.tanh(self.net(torch.cat([flat, delta], dim=-1)))

class ModulatedDynamics(nn.Module):
    """仿射调制动力学：共享骨架 + 域潜变量生成的 γ、β。"""
    def __init__(self, d_z=512, d_a=7, d_dom=32, hidden=512):
        super().__init__()
        self.trunk = nn.Linear(d_z + d_a, hidden)     # 共享骨架入口
        self.to_gb = nn.Linear(d_dom, 2 * hidden)     # 调制参数生成
        self.head = nn.Linear(hidden, d_z)
    def forward(self, z, a, z_dom):
        h = torch.relu(self.trunk(torch.cat([z, a], dim=-1)))
        gamma, beta = self.to_gb(z_dom).chunk(2, dim=-1)
        # 仿射调制：环境差异作用于共享特征，参数量与环境数无关
        return self.head(torch.relu(gamma * h + beta))

解读：flatten(1) 把历史窗口展平为定长向量，窗口长度固定后输入维度确定；变化率统计是廉价但有效的辅助特征。tanh 约束域潜变量取值，为测试时自适应的限幅提供天然边界。to_gb 是全模型唯一直接依赖域潜变量的映射，容量刻意保持为一层线性；若调制成多个 MLP 层，会把环境特例记忆重新引入。调制的顺序为"调制后激活"，比"激活后调制"更稳定，保证 γ、β 同时作用于正负特征。

片段 2：跨域风险方差惩罚

def domain_invariance_penalty(losses_by_domain):
    """不变性正则：各域损失的方差，抑制骨架偏向单一域。"""
    # losses_by_domain: (D,) 每个域的批量平均预测损失
    return losses_by_domain.var(unbiased=False)

def weighted_total_loss(loss_pred, losses_by_domain, lam=0.1):
    """组合目标：预测损失 + 域均衡项。"""
    # 只对骨架参数施加不变正则由优化器分组实现（见训练循环设置）
    return loss_pred + lam * domain_invariance_penalty(losses_by_domain)

解读：方差惩罚的取值范围与域数量相关，D 较小时梯度尺度小，可用放大系数补偿；unbiased=False 避免小样本下除零。正则只作用于共享骨架靠参数分组实现：调制网络与域编码器不参与该损失的梯度，保持可塑性。替代方案是对每域损失做相对归一化后取最大（组鲁棒目标），更激进但易被单域主导；方差形式更平滑，适合作为默认。训练日志记录各域损失曲线，方差惩罚是否生效以曲线收敛程度为证据。

片段 3：测试时自适应域编码

def tta_step(context_encoder, world_model, z_hist, a_hist, z_target, lr=1e-3):
    """测试时自适应：冻结主体，只用预测误差更新域编码器。"""
    z_dom = context_encoder(z_hist, a_hist)
    pred = world_model.step(z_hist[:, -1], a_hist[:, -1], z_dom)
    loss = F.mse_loss(pred, z_target.detach())        # 自监督：真实下一状态为目标
    grads = torch.autograd.grad(loss, context_encoder.parameters())
    with torch.no_grad():
        for p, g in zip(context_encoder.parameters(), grads):
            p.add_(g, alpha=-lr)                      # 小步更新，越低维越安全
    return z_dom.detach()

def clamp_domain_latent(z_dom, ref_mean, ref_std, k=3.0):
    """域潜限幅：与训练分布的距离超过 k 倍标准差时裁剪，防止漂移。"""
    return torch.clamp(z_dom, ref_mean - k * ref_std, ref_mean + k * ref_std)

解读：tta_step 用 torch.autograd.grad 只取域编码器的梯度，主干完全冻结；目标侧 detach 防止任何回流。clamp_domain_latent 用训练域的潜变量统计量做边界约束，域编码漂移到分布外时被拉回，这是测试时自适应的安全阀。适配期间与残差监控联动：若适配后预测残差高于适配前，回滚到适配前的编码器状态。参考统计量在训练结束时汇总保存，随模型版本发布。

常见坑

  • 过度不变：不变正则过强，骨架连摩擦相关的合法结构也拒绝学习。症状是留出域适配后精度仍差。修复：降低权重、只对低层施加正则、检查调制路径是否承担了应学的结构。
  • 捷径编码：上下文编码器只学到与域标签相关的表面线索（时间、场景 ID），真实物理参数未进入编码。症状是训练域表现好、参数重排的留出域失效。修复：训练时随机化表面线索，验证编码器与真实物理参数的互信息。
  • 测试时自适应漂移：连续自适应把域编码推离分布，性能逐步退化。症状是适配越久误差越大。修复：限幅、小学习率、定期回滚检查点、只在残差正常时段适配。
  • 留一域泄漏：同一场景的不同时段被分到训练与留出域，评测虚高。修复：按物理参数与场景双重维度切分，逐条核查域标签。
  • 评估不完整：只报告零样本迁移，缺少少样本与自适应结果。修复：固定三档协议（零样本、50 条轨迹微调、在线自适应）并成对报告。

练习与思考

  1. 说明为什么系统辨识输入必须包含动作序列：构造一个仅凭观测无法区分两种摩擦系数、加入动作后可区分的最小例子。★★
    提示
    静止场景下两种摩擦的观测相同；施加推力动作后滑移距离不同，响应差异暴露参数。
  2. 把域潜变量维度从 32 改为 4，预测零样本迁移与自适应后的表现。★
    提示
    容量不足压不进多参数差异，零样本变差；自适应只能在低维子空间内调整，上限受限。
  3. 设计域划分方案：物理参数 × 场景双重维度，给出训练域与留出域的切分理由。★★
    提示
    训练覆盖参数网格的内点，留出取网格边缘与场景类别中的一种；确保留出域在参数与场景两个维度上都未出现组合。
  4. 推导仿射调制的参数量，与"每域一份转移核"方案对比 D = 12 个域时的差距。★★
    提示
    调制方案参数量与 D 无关（一次线性映射）；复制方案随 D 线性增长，差距约 D 倍量级。
  5. 设计跨环境迁移的完整评测协议：覆盖零样本、少样本、在线自适应三档，说明指标与防泄漏检查项。★★★
    提示
    指标含预测误差与任务成功率；检查项包括域切分审计、自适应限幅生效验证、回滚流程演练。

小结

  • 环境差异分外观、动力学与任务三层，动力学参数差异需要潜变量建模，无法靠增强消除。
  • 上下文编码器从历史状态与动作推断域潜变量，动作序列是辨识的必需输入。
  • 共享骨架加仿射调制把环境差异注入动力学，参数量与环境数无关；不变正则防止骨架过拟合单一域。
  • 测试时只更新域编码器，配限幅与残差监控联动；超出域编码容量的差异触发离线再训练。
