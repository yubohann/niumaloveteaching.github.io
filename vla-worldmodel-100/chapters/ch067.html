第 067 章：联合训练中的对比学习

本章讲联合训练中的对比学习（Contrastive Learning）：用 InfoNCE 目标对齐观测、语言与动作表示，讨论正负样本构造、假负例屏蔽、温度控制与主任务损失的自动加权。

  • 主题：联合训练 / 表征对齐目标
  • 关键公式：L = −log exp(sim(z, z+)/τ) / Σj exp(sim(z, zj)/τ)
  • 预计学时：50 分钟
  • 前置章节：第 066 章：世界模型的记忆增强

学习目标

  • 理解对比学习在联合训练中的角色：为视觉与语言分支提供表示层面的对齐信号。
  • 掌握 InfoNCE 目标的推导脉络与互信息下界的含义，理解它与 Softmax 分类损失的关系。
  • 掌握正负样本构造的三条线路：时间邻近、跨模态配对、视图增强，以及假负例（False Negative）的识别与屏蔽。
  • 能实现跨模态对比损失、时间对比屏蔽与可学习温度，理解温度对梯度分布的影响。
  • 会诊断表示塌缩、假负例污染与对比项压过主任务的问题，能设计权重扫描实验。

背景与动机

本节说明对比学习补充的监督缺口：联合训练的主损失是预测式与回归式。世界模型重建帧、VLA 回归动作，两者都只约束输入输出映射的局部正确性，不直接约束表示空间的结构。结果是同类语义的表示可能分散，跨模态对应关系松散。对比学习把“哪些样本语义相同”作为监督信号：拉近正样本对的表示，推远负样本对。在 VLA 与世界模型共享视觉编码器的联合设定中，对比项同时约束三种关系：指令与观测的跨模态对应、相邻时刻的状态连续性、同一场景不同增强视图的不变性。本章讨论构造、屏蔽与温度三个设计轴。

核心原理

1. InfoNCE 与互信息下界

给定正样本对 (z, z+) 与 K 个负样本 zj，InfoNCE 损失定义为

L = −log exp(sim(z, z+)/τ) / Σj=1..K exp(sim(z, zj)/τ) sim 为余弦相似度，τ 为温度；分母含正样本与全部负样本

该形式与 K + 1 类分类一致：从候选集中把正样本识别出来。信息论结论是它构成互信息的下界：I(z; z+) ≥ log(K + 1) − L，负样本越多下界越紧。负样本数量决定监督强度：批量 256 时每个正样本对 255 个负样本，这是大批量对比训练更有效的理论解释。

2. 数值算例：假负例对损失的贡献

取一个锚点，正样本相似度 0.8，两个负样本相似度 0.5 与 0.2，温度 τ = 0.1，则 softmax 的 logits 为 [8, 5, 2]。未屏蔽时：正样本的对数概率为 log(e8 / (e8 + e5 + e2)) = log(2980.96 / 3136.76) ≈ −0.051，损失约 0.051。其中相似度 0.5 的候选若实际为假负例，它占据了约 4.7% 的概率质量，等于每次更新都在把这一对语义等价的表示推开。屏蔽该位置后，分母变为 2988.35，损失降到约 0.0025，下降约 95%。

未屏蔽 L ≈ 0.051，屏蔽后 L ≈ 0.0025 假负例在分母中的质量占比 e5 / (e8 + e5 + e2) ≈ 4.7%，代表持续的推开梯度

数值结果给出三条判断：（1）假负例的危害与它的相似度成正比，越接近正样本的假负例造成的推开梯度越强；（2）屏蔽是精确手术：只移除指定位置，其余候选的归一化照常进行；（3）与正样本的相似度差仅 0.3 的假负例已能贡献近半的损失量，说明语义等价判定需要覆盖相似度较高的样本，仅屏蔽明显重复项远远不够。

3. 正负样本构造的三条线路

时间邻近：同一轨迹相邻帧互为正样本，跨轨迹为负样本，约束动力学的局部平滑性。跨模态配对：同一时刻的观测与指令互为正样本，来自其他样本的模态为负样本，约束指令与场景的对应。视图增强：同一帧的两次增强互为正样本，约束外观变化下的表示不变性。三条线路共享同一套 InfoNCE 形式，差别在正样本集合的定义。困难负样本（Hard Negative）的训练价值最高：与锚点相似度高但语义不同的样本。批量内采样之外，可用记忆库扩大负样本池，代价是键表示的陈旧性。三条线路的特性与风险对照如下：

线路正样本定义负样本来源学习信号典型风险
时间邻近同轨迹相邻帧跨轨迹样本动力学局部平滑性相邻帧过于相似，正对信息量低；快速运动段被误平滑
跨模态配对同一时刻的观测与指令其他样本的异构模态指令与场景的语义对应指令措辞重复造成假负例
视图增强同一帧的两次增强视图其他帧的视图外观变化下的表示不变性增强过强改变语义，不变性约束失焦

三条线路可以叠加使用，权重按诊断结果分配：跨模态检索指标弱时提高跨模态配对权重，想象动力学漂移时提高时间邻近权重，相机或光照变化下成功率下降时提高视图增强权重。叠加的前提是各线路的正样本集合互不冲突：同一对样本在一条线路里是正对、在另一条里是负对，会形成互相抵消的梯度。

4. 假负例：对比学习的隐形敌人

语义相同却被当作负样本的配对称为假负例（False Negative）。典型来源：同一场景的不同视角、同一指令的不同改写、同一时刻的相邻帧被跨样本采样。假负例把正确对齐的表示推开，表现为表示空间中的语义簇被撕裂。补救分两步：识别，用轨迹标识、语义等价标签或相似度阈值圈定可能等价的对；屏蔽，在相似度矩阵上把假负例位置置为负无穷后再做 log-sum-exp。屏蔽范围不宜过大：过度屏蔽会减少有效负样本，削弱对比强度。

5. 温度与权重：尺度的两个旋钮

温度 τ 控制分布锐度。τ 过大时 softmax 接近均匀，梯度信号被摊薄；τ 过小时训练被最难负样本主导，容易震荡。经验区间为 0.03 至 0.1，或参数化为可学习标量（CLIP 式的 logit scale）。权重的第二个旋钮是它在总损失中的占比：对比项梯度的尺度与主损失不同，固定相加需要反复手调。按不确定性自动加权是常用替代：可学习对数方差 log σ2 使总损失形如 L/(2σ2) + log σ，高方差项自动降权，权重无须手工扫描。

实现思路与设计

本节给出接入方案：观测编码器与语言编码器输出投影后的嵌入；跨模态对比在批量内计算双向 InfoNCE；时间对比在世界模型隐状态序列上计算，同轨迹邻近帧为正；假负例屏蔽依据轨迹标识与时间距离生成布尔掩码；总损失为世界模型重建项、动作回归项与对比项的不确定性加权组合。对比项只更新编码器与投影头，动作头不参与。与第 066 章的差异：第 066 章增加存储通路，本章增加表示层面的训练目标。

设计决策：为什么对比项不更新动作头

对比目标是表示空间的几何约束，动作头负责数值回归。若动作头承受对比梯度，其特征会同时服务两种目标：对齐的几何需求与动作的数值精度，容易产生折中解。把对比梯度限制在编码器与投影头，动作头保持纯净的回归任务，是两类目标解耦的关键。投影头在推理时可丢弃，部署表示与训练表示因此可以不同。

大批量负样本的实现要点

  • 跨设备负样本收集。批量 256 在单设备显存受限时用全收集（All-Gather）拼接各设备的嵌入，相似度矩阵按全局批量计算；代价是通信量与显存随后备池规模平方增长，可按梯度缓存分块近似。
  • 向量归一化与数值稳定。相似度矩阵计算前必须归一化嵌入；温度用可学习缩放参数时，logit 的量级变为相似度乘缩放，矩阵乘法的浮点误差在缩放参数大时被同步放大，混合精度训练需要保持相似度计算在单精度。
  • 掩码的对角线保护。假负例掩码与正样本掩码必须避免覆盖对角线，否则正样本被自己屏蔽，损失退化为常数并破坏梯度；生成掩码后做一次对角检查是廉价的防护。
  • 有效负样本计数。每个锚点在屏蔽后统计剩余负样本数，低于下界（如 32）时对该样本降权或跳过，防止个别样本的对比项方差失控。
  • 投影头的维度。投影头输出维度取 128 到 256，过窄会限制对齐信息的表达，过宽使相似度矩阵的信噪比下降；维度变化后温度需要重新标定。

关键代码与解读

以下片段以对比视觉语言模型与自监督表征学习的公开设计为参照，接口随版本演进。三个片段分别覆盖跨模态 InfoNCE、时间对比屏蔽与温度加权。

片段 1：跨模态 InfoNCE

import torch
import torch.nn.functional as F

def info_nce(obs_emb, lang_emb, scale, false_neg_mask=None):
    """跨模态对比：批量对角为正样本，行内其余为负样本。"""
    z_o = F.normalize(obs_emb, dim=-1)      # 归一化把相似度约束到 [-1, 1]
    z_l = F.normalize(lang_emb, dim=-1)
    logits = scale * z_o @ z_l.T            # B x B，scale 为 1/tau 的可学习缩放
    if false_neg_mask is not None:
        # 掩码排除语义等价的非对角位置（对角线必须保持可见）
        logits = logits.masked_fill(false_neg_mask, float("-inf"))
    labels = torch.arange(logits.shape[0], device=logits.device)
    # 双向损失：观测到语言、语言到观测各一次，防止单侧嵌入塌缩
    loss_o2l = F.cross_entropy(logits, labels)
    loss_l2o = F.cross_entropy(logits.t(), labels)
    return 0.5 * (loss_o2l + loss_l2o)

解读：（1）归一化后相似度等于余弦值，温度通过独立缩放参数注入，分工清晰。（2）假负例掩码在 log-sum-exp 之前生效，被屏蔽位置不参与归一化分母。（3）双向计算是标准做法：单向版本已足够优化目标，但两侧嵌入的梯度强度不对称，双向更稳健。

片段 2：时间对比与假负例屏蔽

import torch
import torch.nn.functional as F

def temporal_contrastive(feats, traj_ids, pos_window=1, shield_window=8):
    """时间对比：同轨迹邻近帧为正样本，跨轨迹样本为负样本。"""
    z = F.normalize(feats, dim=-1)
    sim = z @ z.T                                 # T x T 相似度矩阵
    idx = torch.arange(feats.shape[0], device=feats.device)
    gap = (idx[:, None] - idx[None, :]).abs()     # 两两时间距离
    pos = gap <= pos_window                       # 正样本集合：邻近帧
    # 假负例：同轨迹且时间距离在屏蔽半径内的非正样本对
    same_traj = traj_ids[:, None] == traj_ids[None, :]
    false_neg = same_traj & (~pos) & (gap <= shield_window)
    sim = sim.masked_fill(false_neg, float("-inf"))
    # 转成对数概率后只对正样本对求平均，等价于多正样本版 InfoNCE
    log_prob = sim - torch.logsumexp(sim, dim=1, keepdim=True)
    return -log_prob[pos].mean()

解读：（1）正样本集合用时间距离定义，屏蔽半径单独控制，两个窗口解耦便于分别扫描。（2）多正样本版本对全部正样本对平均，正样本覆盖更充分。（3）屏蔽只在同轨迹内生效：跨轨迹的相近帧语义可能不同，属合法负样本。

片段 3：温度参数化与不确定性加权

import torch.nn as nn

class ScaleParam(nn.Module):
    """可学习相似度缩放：以对数空间参数化，等价于可学习温度。"""
    def __init__(self, init_scale=14.0):
        super().__init__()
        self.log_scale = nn.Parameter(torch.tensor(init_scale).log())

    def forward(self):
        # 钳位到 [2, 50]：温度 0.02 到 0.5，防止锐度失控
        return self.log_scale.exp().clamp(2.0, 50.0)

class UncertaintyBalancer(nn.Module):
    """多任务不确定性加权：可学习对数方差自动平衡损失尺度。"""
    def __init__(self, n_tasks=3):
        super().__init__()
        self.log_var = nn.Parameter(torch.zeros(n_tasks))

    def forward(self, losses):
        total = 0.0
        for i, l in enumerate(losses):
            sigma2 = torch.exp(self.log_var[i])
            # L/(2 sigma^2) + log sigma：高方差任务自动降权，log 项防权重无界放大
            total = total + l / (2 * sigma2) + 0.5 * self.log_var[i]
        return total

解读：（1）缩放参数用对数空间优化避免正数约束，钳位区间由温度经验区间换算而来。（2）不确定性加权把权重交给数据：重建、动作、对比三项各自维持合适的梯度尺度。（3）log_var 的梯度同时作用在权重与网络参数上，形成自适应的尺度平衡，比手工扫权重更省调参预算。

常见坑

  • 表示塌缩：编码器把所有输入映射到近似同一点，对比损失趋近 log K 的平台值。修复：检查负样本是否被误屏蔽殆尽，确认温度未超出下界，必要时加入均匀性正则。
  • 假负例污染：同一场景不同视角被推到相反方向，语义簇撕裂。修复：按轨迹与语义标签生成屏蔽掩码，用相似度分布的分位确定屏蔽半径。
  • 温度过小：训练被最难负样本主导，损失剧烈震荡。修复：把缩放参数钳位到经验区间上限，或改用可学习温度让其自适应回升。
  • 对比项压过主任务：对比损失数值下降漂亮，动作精度恶化。修复：降低对比项权重或交给不确定性加权，监控动作头梯度范数占比。
  • 屏蔽范围过大：为防假负例把近半批量屏蔽，有效负样本不足，监督退化。修复：限制屏蔽半径，统计每个锚点的有效负样本数并设下界。

练习与思考

  1. 推导题：从 I(z; z+) ≥ log(K+1) − L 出发，解释为什么负样本数量 K 越大监督越强，并给出 K 从 255 减到 31 时下界的损失量。★★
    提示
    log 256 − log 32 = log 8 ≈ 2.08，负样本减少使互信息下界下降约 2 纳特量级，这是大批量对比训练更有效的定量解释。
  2. 把片段 1 的缩放下限从 2 改为 1（温度 1.0），预测训练损失与下游动作精度变化。★
    提示
    温度过高使 softmax 接近均匀，对比梯度被摊薄，损失停留在高位，下游对齐质量下降。
  3. 把片段 2 的屏蔽半径从 8 调为 32，预测有效负样本数与表示对齐质量的变化。★
    提示
    轨迹内负样本被大量屏蔽，有效负样本数骤减，对齐信号变弱；语义簇的中心距离缩短，泛化变差。
  4. 实验设计：比较固定权重（0.05、0.1、0.2）与不确定性加权四种方案，在同一联合训练配方上报告动作成功率、跨模态检索召回与三项损失的最终量级。★★
    提示
    固定权重方案对超参敏感，最优值随训练阶段漂移；不确定性加权通常接近最优固定值且免扫描，代价是引入少量额外参数。
  5. 设计题：为“语言改写等价”设计假负例识别方案：如何在不依赖人工标注的前提下生成等价组，如何把等价组转成屏蔽掩码，怎样验证屏蔽没有过度。★★★
    提示
    用大模型对指令做改写生成等价组，组成员对之间互相屏蔽；验证方式是统计有效负样本数下界与表示的均匀性指标，两者同时监控。

小结

  • 对比学习为联合训练提供表示层面的对齐信号，InfoNCE 是识别正样本的 K+1 类目标，构成互信息下界。
  • 正样本来自三条线路：时间邻近、跨模态配对、视图增强；困难负样本以大负样本池获得。
  • 假负例用轨迹标识与距离阈值识别并屏蔽，屏蔽范围与有效负样本数需要同时监控。
  • 温度控制分布锐度，权重控制与主任务的平衡；不确定性加权免去手工扫描，收敛后观察权重漂移即可。
