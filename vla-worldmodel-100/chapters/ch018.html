第一篇 · 基础框架与联合训练

第 018 章：联合训练中的课程学习

本章给训练过程加难度调度：用可量化难度分数对样本排序，用配速函数控制难样本的引入节奏，让世界模型与策略各自按能力推进，并在全分布评估下防止课程偏置。

  • 主题：联合训练 / 课程学习
  • 关键公式：d(t) = Dmin + (Dmax - Dmin)·(t/T)p
  • 预计学时：60 分钟
  • 前置章节：第 017 章

学习目标

  • 理解课程学习（Curriculum Learning）在联合训练中的定位：难度排序与引入节奏；它与数据筛选的区别在于全部样本最终都会进入训练。
  • 掌握难度分数的构造方法：轨迹统计量、世界模型预测误差、成功判定三类信号。
  • 掌握配速函数与推进准则：阈值随训练步推进，样本按难度分数加权进入批次。
  • 能协调世界模型与策略两套课程，避免能力错位与耦合震荡。
  • 能设计全分布评估与防课程偏置的回归检查，诊断永久排除类错误。

背景与动机

数据里天然存在难度梯度：短指令与长指令、平缓轨迹与急变轨迹、单步与多阶段操作。均匀采样下早期模型被难样本的大误差主导更新，易样本信号被稀释。课程学习控制难样本的引入节奏，让模型在能力匹配的区间接收信号。

联合训练让课程问题变成双目标：世界模型偏好的“易”是可预测的动态，策略偏好的“易”是简单的任务结构，两者并不总是一致。简单任务里可能出现难预测的接触动态，复杂任务里也可能有可预测的平缓运动。本章的处理是把难度分数设计成多信号组合，并为两个子模型维护独立配速，协调部分只负责防止节奏互扰。

边界：007 章排班“训谁”，本章调度“喂什么难度”；013 章的缓冲提供来源与统计，本章在采样器加难度维度；039 章的学习率调度作用于优化器，与本模型侧节奏独立。

核心原理

1. 课程学习的目标与形态

课程学习由三件要素构成：难度度量（给每个样本一个分数）、配速函数（随训练推进放行更高难度的样本）、推进准则（依据能力指标确认放行时机）。它与数据筛选的本质区别是：所有样本最终都会被纳入训练，课程只改变引入顺序与短期权重。这一区别决定了评估方式：最终模型必须在全分布上评估，任何“只保留易样本”的做法都会让课程退化为筛选。三种采样策略的对照见下表。

策略难样本处理放行冲击最终覆盖适用
均匀采样全程满权重无全覆盖难度分布平缓
硬阈值课程放行前完全排除大（突入陌生分布）依赖放行完成度难度梯度极端的场景
平滑加权课程全程保留低权重小（渐变过渡）全覆盖常规推荐

2. 难度度量

难度分数可以从三个层面构造。数据侧：轨迹时长、动作变化率、指令长度与从句数量，反映任务结构性复杂度；模型侧：世界模型对该样本的预测误差，反映“对当前模型而言”的动态不可预测度，属于自适应难度；结果侧：成功判定与失败次数，反映任务的实际攻克难度。三者归一化后加权求和，权重按任务标定。模型侧信号随训练变化，需要固定参考模型或滑动平均，防止分数与模型一起漂移形成自激。

归一化的处理细节影响分数分布：轨迹长度先取 log1p 再除以 6，50 步、200 步、1000 步的轨迹分别贡献 0.66、0.88、1.15 的长度项，对数变换把“步数翻倍”的差距压成常量级差，超长轨迹不再垄断难度上限；动作变化率项除以 0.5 的参考尺度，把“平均每步动作变化超过半个数据标准差”视为高难度档。三项加权后整体截断到 [0,1]，权重默认 0.4、0.4、0.2：结构侧与模型侧并重，结果侧只作修正项，因为成功标签的粒度最粗、噪声最大。

模型侧信号的参考来源有三档，按客观性与时效性取舍：固定快照完全客观但随训练过时，适合课程前段；滑动平均跟随模型但有漂移倾向，适合后段；双参考组合把两者并用，用快照负责分档、滑动平均负责箱内排序，兼顾稳定与时效。分数漂移的监控指标是相邻两个刷新周期之间全体样本难度分数的平均变化幅度，超过 0.05 说明参考模型或统计口径不稳，需要先稳住评分再谈配速。

3. 配速函数与批次加权

配速函数定义难度阈值的推进曲线：

d(t) = Dmin + (Dmax - Dmin) · (t/T)p t 为训练步，T 为课程总长度；p 取 1 为线性，取 2 为前期慢速后期加速；阈值单调不减

样本按难度分数与阈值的相对关系加权：低于阈值的样本常规权重，高于阈值的样本按差距平滑降权，仍然保留在训练池中：

wi = σ( (d(t) - Di) / τ ) σ 为 sigmoid；τ 控制过渡带的宽度，τ 小接近硬阈值，τ 大过渡平滑

平滑加权相对硬阈值的优势：难样本始终保有少量监督，模型不会在放行时面对完全陌生的分布；τ 的取值与难度分数的噪声水平匹配，噪声大时取宽过渡带。

两条曲线代入数字。配速函数取 dmin=0.2、dmax=1.0、p=2 时，进度 25%、50%、75%、100% 处的阈值为 0.25、0.40、0.65、1.00，前段四分之一训练只放行到 0.25 档，末段四分之一从 0.65 冲到 1.00，形状与“基础先成形、后期赶进度”的需求对应。指数的作用方向也要记清：p 小于 1 时曲线前段陡，p=0.5 时进度 25% 就放行到 0.6 档，适合难度分布平缓、早期即需要多样本的任务；p 大于 1 时前段缓，适合基础能力形成慢、需要长预热的任务。p 的选择依据是“能力指标何时达标”的观测曲线，两条曲线同向时课程才是匹配的。加权函数在 τ=0.2 时：难度低于阈值 0.4 的样本权重 0.881，低 0.2 的取 0.731，恰好等于阈值的取 0.5，高 0.2 的降到 0.269，高 0.4 的只剩 0.119；把 τ 收到 0.02，差 0.2 的两侧权重变为 1.000 与 0.000，行为退化为硬阈值。过渡带宽度的选择因此有了标尺：τ 与难度分数的噪声同量级时，放行边界附近的权重抖动被平滑掉。

4. 两套课程的协调

世界模型与策略各有一条配速曲线，协调原则有两条：其一，世界模型的配速领先策略半步，让模拟器先具备对应难度区间的预测能力，策略再进入该区间；其二，两条曲线的时间常数错开，避免同一时刻两侧难度同时跳变造成损失震荡。协调只通过这些参数实现，两个调度器本身保持解耦，各自的可测试性不被破坏。若观察到损失在放行点附近周期性震荡，优先检查两条曲线的推进事件是否重合。

推进事件的重合频率可以预估：两条周期性放行事件的周期分别为 a、b 步时，重合周期为最小公倍数 lcm(a,b)。世界模型每 5000 步放行、策略每 4000 步放行时，重合周期为 20000 步，平均每两万步出现一次同点共振；把策略周期调成 4500 后重合周期升到 45000 步，共振频率降一半以上；调成 3500 则重合周期 35000 步。选择错开间隔的规则因此明确：在整数周期下取最小公倍数尽量大的组合，即两个周期互质或公因子小，避免倍数关系带来的高重合率。共振的检测口径固定为：取放行步前后各 200 步的损失窗口，与常规窗口比较方差，共振窗口的方差显著偏高；把两次放行的步数差序列做周期性检验，间隔分布的周期性即共振强度的直接证据。

5. 评估与防偏置

三项检查固定执行：全分布评估，按难度分箱报告各箱指标，最终模型必须在高难度箱上不劣于均匀采样基线；回归检查，易样本子集的表现随训练不应下滑，下滑说明难样本挤占了容量；放行完整性，统计训练全程被充分放行的样本比例，长期停留在低权重的样本意味着课程卡住或配速过慢。

放行完整性的量化口径：为每个样本累计训练全程的课程权重，累计值低于均匀训练同长度窗口一半的样本视为未充分放行；健康运行下该比例低于 1%，超过 5% 时检查推进准则的阈值与刷新周期，常见原因是成功阈值设置过高或评估样本不足导致放行停滞。全分布评估的判据写成可执行的三条：高难度箱相对均匀采样基线不劣（差距落在噪声带内）、总体指标不劣、达到同等指标所用步数更少；三条同时成立才判定课程有效，缺第一条属于课程偏置，缺第三条说明课程只增加了开销。

在线数据的接入是课程的另一处边界：新采集经验没有历史难度统计，结构侧信号可以即时计算，模型侧与结果侧信号需要参考模型与标注判定。引导期的规则是先用结构侧单独定档、按中等权重入队，待参考模型对其完成一轮评分后再并入三信号合成；若跳过这一步，新数据会以默认分数大量涌入低难度区，课程的前段节奏被稀释。

难度分与数据质量要分开对待：难度高不等于价值高，失败率高、变化剧烈的样本里混有标注错误与异常轨迹，它们会获得高难度分并长期占用高难度档。处理规则是对最高难度箱做人工抽查，抽查比例按箱内样本量从 1% 起步、上限 5%，异常样本按 002 章的清洗规则出队，清洗记录回写到难度统计，避免同一批异常反复进入评分；抽查覆盖的是箱内边界样本，主体评分仍由自动信号决定，若抽查发现系统性偏差，则下调模型侧信号权重并重新定档。

实现思路与设计

系统结构：难度估计器（离线与在线双通道）、配速控制器（两条曲线与推进事件）、加权采样器（在 013 章采样器上加难度维度）、评估器（分箱报告）。难度分数每轮评估刷新一次，不随每步波动。

设计决策：难样本的降权保留

课程的目标是节奏管理：硬阈值会让难样本在放行前完全缺席，放行瞬间梯度冲击更大。平滑加权保证任何阶段都有少量难样本提供远期信号，放行因此渐变；一个加权函数替代了阈值、重采样、排除列表三套机制。

衔接与差异：013 章的缓冲按来源分层，本章在同一层面增加难度维度，二者由同一权重传递链合并；007 章的阶段切换与本章的难度推进是正交调度，实现上共用“纯函数控制器 + 单元测试”的模式；039 章的学习率调度作用于优化器，不介入样本侧。

关键代码与解读

片段以课程学习与自步学习的公开设计为参照，接口随版本演进。第 1 段给出难度分数构造。

片段 1：难度分数构造

import numpy as np

def difficulty_score(ep, pred_error_fn, w_struct=0.4, w_pred=0.4, w_succ=0.2):
    """三信号合成难度分数：结构复杂度、预测误差、成功率。"""
    # 结构侧：轨迹长度与动作变化率归一化后平均，反映任务复杂度
    length = np.log1p(len(ep["action"]))
    jitter = np.mean(np.linalg.norm(np.diff(ep["action"], axis=0), axis=-1))
    struct = 0.5 * (length / 6.0) + 0.5 * (jitter / 0.5)
    # 模型侧：固定参考模型给出的平均预测误差，记录“对当前模型的可预测度”
    pred = pred_error_fn(ep)                    # 建议用滑动平均参考，防自激
    # 结果侧：失败样本难度更高；成功率字段来自数据标注或判定器
    succ = 1.0 - float(ep.get("success", 0.5))
    raw = w_struct * struct + w_pred * pred + w_succ * succ
    # 截断到 [0,1]：后续配速函数与过渡带参数都按归一化尺度设定
    return float(np.clip(raw, 0.0, 1.0))

解读：（1）三个信号在合成前各自归一化，权重才有可比性；长度的对数变换压缩长尾，避免超长轨迹垄断难度上限。（2）预测误差由外部函数注入，不在分数构造内部计算；参考模型的选择（固定快照或滑动平均）留作配置项，防止分数随训练模型一起漂移。（3）输出严格归一化到 [0,1]，与配速函数的取值范围耦合，修改任一侧都需同步检查。

片段 2：配速与平滑加权

def pacing_threshold(step, total, d_min=0.2, d_max=1.0, p=2.0):
    """配速函数：难度阈值随训练步单调推进，前慢后快。"""
    ratio = min(1.0, step / float(total))
    return d_min + (d_max - d_min) * (ratio ** p)

def curriculum_weight(scores, threshold, tau=0.2):
    """平滑加权：难度低于阈值的样本常规权，高于阈值的按差距降权。"""
    # sigmoid 过渡：τ 越大过渡带越宽，难样本在放行前保留的监督越平滑
    return 1.0 / (1.0 + np.exp((scores - threshold) / tau))

def combine_weights(curriculum_w, source_w, priority_w):
    """权重合并：课程、来源、优先级三路相乘，入口统一在采样器。"""
    # 三项职责独立可解释：课程管难度节奏，来源管分布配比，优先级管信息量
    return curriculum_w * source_w * priority_w

解读：（1）阈值单调不减由公式结构保证（ratio 单调、p 为正），无需额外断言即可排除“难度回退”的异常调度。（2）sigmoid 的形式让“恰好处于阈值上的样本”权重为 0.5，过渡对称且无参数突变。（3）三路权重取相乘，最大或平均都会掩盖单因子的低权重：任何一路的低权重都应压低该样本的贡献，乘式是唯一保持各因子独立语义的组合方式；权重链与 008 章的来源权重、013 章的优先级在损失端统一归一到样本。

片段 3：推进准则与放行事件

def should_promote(wm_error, policy_success, wm_thresh=0.1, succ_thresh=0.6):
    """推进准则：世界模型误差低且策略成功率达标，才放行下一难度箱。"""
    # 双条件落地“世界模型领先半步”：模拟器先具备预测能力，策略再进入
    return (wm_error < wm_thresh) and (policy_success > succ_thresh)

def promote_once(state, n_boxes, step):
    """放行事件记录：推进步数序列是两套课程共振检测的直接证据。"""
    # 事件只增不改：间隔分布的周期性是调度错开效果的量化依据
    state["event_steps"].append(step)
    state["level"] = min(state["level"] + 1, n_boxes - 1)
    return state

解读：（1）推进由两个子模型的指标共同判定，任何一侧不达标都不放行，防止难度推进快于任一子模型的能力。（2）事件序列供离线分析：把世界模型与策略的放行步数画在同一时间轴上，重合事件即共振候选。（3）箱级上限用 min 截断，训练末期停留在最高箱继续全分布训练，与配速函数的终点行为一致。

常见坑

  • 课程偏置：训练末期难样本仍被显著降权，模型只在易分布上收敛。修复：配速函数在末尾强制到全分布，评估按难度分箱检查高难度箱指标。
  • 难度自激：预测误差用当前模型计算，分数随模型漂移，课程失去客观基准。修复：参考模型用固定快照或滑动平均，刷新周期与评估周期对齐。
  • 两套课程共振：世界模型与策略的配速推进事件重合，损失在放行点周期性震荡。修复：错开时间常数（世界模型领先半箱），并检查推进事件的步数分布。
  • 放行卡死：推进准则衔接不当，难样本长期停在低权重，统计上从未被充分训练。修复：监控样本累计权重分布，设定单样本累计权重下限。
  • 难度口径跨集泄漏：难度分数在训练与验证数据上联合统计，难度分箱不可比。修复：难度统计只在训练集执行，验证集沿用训练侧口径。

    过渡带接近硬阈值，放行点附近损失尖峰明显；用放行步附近的损失方差对比两种配置。
  3. 推导：说明 sigmoid 加权在 τ 趋近零与趋近无穷两个极限下分别退化为哪种调度，并给出中间取值的语义。★★
    提示
    τ 趋零退化为硬阈值放行；τ 趋大退化为按难度线性软化的均匀调度；中间取值表示“接近阈值的样本部分参与”。
  4. 设计两套课程的协调方案：给出两条配速曲线的领先量、推进事件的错开规则与共振检测指标。★★
    提示
    世界模型领先半箱推进；两条曲线的推进步数取互质间隔错开；用放行点附近损失方差的周期分量检测共振。
  5. 构造实验：均匀采样与课程采样训练到相同步数，按难度分箱报告指标并检验“高难度箱不劣”的判定，说明课程是否有效。★★★
    提示
    分别报告五箱指标与总体指标；课程有效的判据是高难度箱不劣、总体不劣、且达到同等指标所需步数更少。

小结

  • 课程学习管理难度的引入节奏，所有样本最终都进入训练，与数据筛选的边界在此。
  • 难度分数由结构、预测误差、结果三路信号归一化合成，参考模型需防漂移自激。
  • 配速函数单调推进，sigmoid 平滑加权把放行过程展成渐变过渡。
  • 世界模型领先半箱、时间常数错开，是两套课程协调的两条准则。
  • 评估按难度分箱、检查易样本回归与放行完整性，全分布指标是课程的验收底线。
