第二篇 · 联合训练进阶与策略能力

第 036 章：世界模型中的多步预测误差修正

自回归 rollout 的误差沿步长放大，训练分布与推理分布不一致是根源；本章讲清多步训练目标、教师强制课程与显式修正网络三种压缩误差增长的手段。

  • 主题：多步误差修正（multi-step error correction） / 自回归训练调度
  • 关键公式：L = Σk wk d( x̂t+k, xt+k )；课程采样概率 pi；滚动校正 z̃ = ẑ + cφ(ẑ)
  • 预计学时：55 分钟
  • 前置章节：第 035 章

学习目标

  • 理解自回归误差放大与暴露偏差（exposure bias）的机制：训练用真实前缀，推理用模型自己的预测前缀。
  • 掌握多步训练目标的构造方法：训练视野截断、权重设计与时间维度反向传播的稳定化。
  • 掌握教师强制课程（scheduled sampling）的概率调度，理解其与推理分布对齐的作用。
  • 会设计显式修正网络：输入、结构、训练目标与残差形式的选择。
  • 能诊断远期权重过大、反向传播不稳定与修正网络退化三类问题。

背景与动机

第 030 章测量了误差增长曲线，第 035 章在控制回路层面做了补偿。本章回到训练层面：误差增长的根源之一是训练与推理的分布不一致。训练时模型每一步都看到真实的历史帧（教师强制，teacher forcing），推理时每一步看到的是自己上一步的预测。一旦某步出现小误差，输入分布偏离训练分布，下一步误差更大，形成正反馈漂移。

修正手段分三个层次。目标层：多步预测损失，让模型在训练中直接对 k 步后的精度负责，超越单步监督。调度层：教师强制课程（scheduled sampling），训练后期逐步用模型预测替代真实输入，让模型适应自己的误差。结构层：显式修正网络，对预测状态做残差校正，补偿系统性的预测偏差。

本章与第 035 章的闭环衔接：误差修正直接抬高可预测时域 k*，让滚动时域窗口可以加长；与第 030 章的评估衔接：修正效果用误差增长曲线与 k* 的变化来验收。

核心原理

1. 暴露偏差的形式化

记单步预测器的误差为 ε，理想情况下第 k 步的误差来自 k 次独立的单步误差叠加；在自回归正反馈下误差被放大：

ek+1 = ek + ε · ( 1 + c · ek )，近似展开得 ek ~ ε · k + c · ε2 · k2 / 2 c 为误差对输入的敏感度（预测器误差函数在数据流形附近的曲率）；第二项即正反馈贡献的平方增长

该递推可以精确求解：把 ek+1 = (1 + εc)ek + ε 视作常系数线性递推，初值 e0 = 0 时解为 ek = ((1 + εc)k − 1) / c。对 (1 + εc)k 做二项展开，前两项给出 ek ≈ kε + cε2k(k − 1)/2，与上文展开一致。解的形式给出两个结论：每步的增长因子为 1 + εc，对应第 030 章指数模型的 λ = εc；敏感度 c 每翻一倍，λ 同步翻倍，远期误差按指数放大。

数值算例：ε = 0.01、c = 5 时精确解在 k = 10 处为 ((1.05)10 − 1)/5 ≈ 0.126，二阶近似给出 0.1 + 0.025 = 0.125，两者接近；忽略正反馈的线性误差只有 0.1，正反馈项贡献约四分之一。若通过课程训练把 c 压到 0.5，k = 10 的误差降到约 0.102，接近线性上界。远期误差的压缩空间来自削减 ε 与 c 两者之一，其中 c 由训练分布对齐直接决定。

当 c 不可忽略时，误差呈超线性增长，对应第 030 章指数模型的 λ 项。训练中减少 c 的有效方法是让预测器见过"带误差的输入"：教师强制课程逐步注入模型自身的预测，使训练分布向推理分布收敛。经验上存在权衡：课程推进过快，早期模型在自身噪声上训练，学习效率下降；推进过慢，推理时的分布偏移未被覆盖。概率调度的形状（线性、指数）比终点值更重要，通常采用从 0 缓慢起步、后期加速的曲线。

2. 多步训练目标

把训练损失从单步扩展为 k 步 rollout 损失：

Lmulti = Σk=1K wk · d( x̂t+k, xt+k ) d 为逐帧距离（潜空间距离或重构损失），wk 为步长权重；K 为训练视野，常取评估时域的一半

权重设计与视野选择的经验：wk 随 k 温和增长（线性或平方根）可以强调远期目标；wk 过大且 K 过大时，训练信号被远期误差噪声主导，短期精度下降。视野 K 不必等于推理时域：K 取推理时域的 1/2 至 2/3 是常见折中。实现上，多步 rollout 需要在时间维反向传播（backpropagation through time），计算图随 K 线性增长，显存压力显著；缓解手段有：随机采样 K 内的子序列（每次只回传部分步）、对中间状态 detach（只让最后几步携带梯度）、梯度检查点（checkpointing）。

权重的数值感受：K = 15、wk = √k 时权重和 Σ√k ≈ 40.5，第 1 步归一化权重约 0.025，第 15 步约 0.096，末步权重是首步的 √15 ≈ 3.9 倍；换成线性权重则比值 15 倍，远期信号明显更强。若权重按指数 λk 增长，末步将主导总损失，近期精度的梯度被稀释，这是远期权重过大的直接来源。

视野本身也可以课程化：训练早期用 K = 5 稳定优化，中期扩到 15，末期尝试 25 至 30 并回头核对评估。理由是早期模型误差大，长视野的损失大部分由模型自身噪声构成，梯度方向混乱；短视野先建立单步与短程精度，长视野随模型改进逐步生效。扩张时机用验证集 k* 的连续两轮改善来判定，比按固定步数切换更贴合实际训练进度。

3. 教师强制课程与软混合

课程采样的两种实现：硬替换与软混合。硬替换按概率 pi 在"真实帧"与"模型预测帧"之间二选一；软混合把两者加权平均后作为输入：

x̃t = ( 1 − pi ) · xt真实 + pi · x̂t ，pi = min( 1, i / Tramp ) i 为训练步计数，Tramp 为课程覆盖的步数；软混合的输入连续，梯度路径更平滑

软混合的代价是引入非真实的"模糊帧"输入，模糊帧在现实中不出现；它作为过渡形态在训练中可用，推理时不存在。实践中混合使用：潜空间预测任务用硬替换（潜状态无模糊概念），像素空间任务用软混合再逐步收敛到硬替换。替代的简化调度是固定比例（例如全程 30% 用预测帧），实现最简单，适合快速基线。

数值例子：课程覆盖总步数的 60%、上限 0.5 时，训练 30% 步数处替换比例为 0.25，60% 处达到 0.5 并保持。硬替换的采样波动随比例上升：比例 0.5 时单条短片段内真实前缀的占比服从二项分布，片段越长波动越小；按片段统计的实际生效比例要比按步统计更早上报，监控用片段级平均。

4. 显式修正网络

修正网络对预测状态做残差校正，形式为：

z̃t+1 = ẑt+1 + cφ( ẑt+1, zt, at ) ，cφ 为门控残差网络 cφ 输出校正方向；门控项由预测不确定性调制，不确定高时减小校正幅度防止有害修正

修正的收益可以用偏差与噪声分解估算：设预测误差由系统偏差 0.03 与随机噪声 0.01 组成，修正网络能学到的上限是系统偏差部分，理想修正后剩余误差接近 0.01，总误差从 √(0.032 + 0.012) ≈ 0.032 降到约 0.01，降幅约 68%。若监督数据只覆盖部分场景，未覆盖场景的偏差仍留在残差中，收益按覆盖比例打折，评估修正效果应分场景报告；只看总均值会掩盖未覆盖场景的偏差。

训练修正网络的监督来自真实转移：给定真实前缀与预测状态，校正目标为 zt+1真实 − ẑt+1。两个设计要点：其一，修正网络在冻结的预测器上训练（或交替训练），避免两者互相适应形成退化解；其二，门控项用预测不确定性（第 031 章的校准输出），让修正集中在系统性偏差可学、随机噪声为主的位置不动。若修正网络训练后发现输出接近零，说明预测器已无系统性偏差可修正，或者监督信号不足（分布外样本太少），需要先排查两者。显式修正不能替代多步训练：它补偿系统性偏差，压缩的是误差增长曲线中的漂移分量，扩散分量仍由训练目标处理。

门控的数值形态：门控参数初始为零时 sigmoid(0) = 0.5 是上限系数，不确定性 unc = 0.2 处门控值为 0.5 × 0.8 = 0.4，校正输出被压到四成；unc 升到 0.8 时门控值为 0.1，几乎不修正。上限系数随训练增长但增速受监督约束：修正目标明确的区域增长快，样本稀疏的区域维持保守。

5. 三种手段的分工

手段作用机制压缩的误差分量主要成本
多步目标训练直接监督 k 步后的状态增长斜率（λ 项）显存与训练时间随 K 增长
课程采样训练输入分布向推理分布对齐正反馈敏感度 c早期监督质量下降
修正网络残差校正系统性偏差曲线整体高度（ε 项）独立训练环节与部署开销

三者的组合顺序建议：先用多步目标与课程采样把斜率压下来，再训练修正网络压低曲线整体高度；顺序颠倒时修正网络要先补偿一个仍在增长的误差曲线，容易过拟合到旧版本的偏差形态；三者的超参按同一顺序分阶段标定，避免同时变动造成的归因困难。

实现思路与设计

误差修正系统的改造分四步：目标扩展、课程调度、修正网络与评估闭环。与第 035 章的差异：035 在部署回路上补偿延迟，本章在训练过程中压缩误差增长。

  1. 目标扩展：单步损失加多步 rollout 损失，视野从 1 逐步增到 15，权重取平方根增长；中间状态用梯度检查点控制显存。
  2. 课程调度：教师强制比例从 0 线性升到 0.5，覆盖训练前 60% 的步数；剩余步数保持 0.5 的稳态混合。
  3. 修正网络：两层 MLP（宽度 128）加门控，在预测器冻结的窗口内单独训练 3000 步，之后转交替训练。
  4. 评估闭环：每轮训练结束重测误差增长曲线与 k*，与修正前对照，修正幅度写入模型卡。

修正网络的训练样本来自两类前缀：真实前缀（覆盖单步偏差）与模型 rollout 前缀（覆盖累积偏差），按 1:1 混合。来源失衡会让修正网络只学到其中一种偏差形态：全用真实前缀时校正偏向单步误差、对累积漂移无效；全用 rollout 前缀时校正被较大的累积误差主导，单步位置的修正过强。

技巧：用潜空间训练多步目标，用像素空间验收

多步训练在潜空间进行：状态向量的多步损失计算便宜、梯度稳定。验收仍在像素与任务量指标上做：潜空间损失的下降不保证解码质量，每轮训练后重测像素误差与可预测时域，防止"潜空间自洽但解码漂移"的假进步。

BPTT 稳定性的监控口径：逐段记录梯度范数，正常训练时段的平均范数应稳定在有限区间（示例：0.1 至 1），出现量级跃迁（超过历史均值的 10 倍）时先降视野或加裁剪，再检查数据是否混入异常序列。裁剪阈值取历史 99 分位略上方；长期贴住阈值的训练处在临界噪声状态，即使没有发散也会拖慢收敛。

验收口径的细化：k* 提升要配合误差曲线族报告（多种子、多初始状态），单条曲线的端点改善容易由采样噪声造成；λ 与 ε 分开报告，修正网络主要压低 ε、多步目标主要压低 λ，两者的分工在指标上可以分离验证；报告同时给出拟合窗口与阈值口径，确保不同版本之间可比。

关键代码与解读

以下片段参照公开的潜空间 rollout 训练与课程采样实现设计，版本中立；PyTorch 风格，接口随版本演进。

片段 1：潜空间多步训练损失

import torch
import torch.nn.functional as F

def multi_step_latent_loss(world_model, z0, actions, targets, weights):
    """K 步 BPTT：逐歩预测潜状态，按权重累计与真实潜目标的距离。"""
    z = z0
    losses = []
    for k in range(len(actions)):
        z = world_model.transition(z, actions[k])
        # 每个中间步都参与损失：远期误差提前暴露给优化器
        losses.append(F.mse_loss(z, targets[k], reduction="none").mean(-1))
    losses = torch.stack(losses)                 # [K, B]
    # 权重按步长预生成：[K] 向量，平方根曲线强调远期但不淹没近期
    weighted = (losses * weights.view(-1, 1)).sum() / weights.sum()
    return weighted

def truncated_bptt_loss(world_model, z0, actions, targets, seg_len=5):
    """截断 BPTT：只对每段末几步保留梯度，控制显存与梯度爆炸。"""
    z = z0.detach()                              # 段首切断梯度，限制传播深度
    total = 0.0
    for start in range(0, len(actions), seg_len):
        for k in range(start, min(start + seg_len, len(actions))):
            z = world_model.transition(z, actions[k])
            if k >= start + seg_len - 2:         # 只让段末两步携带梯度
                total = total + F.mse_loss(z, targets[k])
            else:
                z = z.detach()
    return total

解读：（1）每个中间步都算损失，远期误差在训练中可见，这是"多步目标"与"只看末步"的本质区别；（2）权重归一化后损失尺度与单步损失可比，学习率无需重调；（3）截断版本在段边界 detach，限制梯度传播深度，显存从 O(K) 降到 O(段长)；（4）段内保留末步梯度是"局部多步"的近似，用更短的有效信用长度换取稳定性，适合大规模训练。

片段 2：课程采样与修正网络

def scheduled_sampling_ratio(step, total_steps, max_ratio=0.5):
    """教师强制课程：0 到 max_ratio 线性上升，覆盖前 60% 训练步。"""
    ramp = 0.6 * total_steps
    ratio = min(step / ramp, 1.0) * max_ratio
    return ratio

def rollout_with_sampling(world_model, z_real, z_pred, ratio, rng):
    """按课程比例混合真实前缀与预测前缀，生成下一步输入。"""
    if rng.random() < ratio:
        return z_pred                              # 使用模型自己的预测：适应推理分布
    return z_real                                  # 使用真实状态：保持稳定监督

class CorrectionNet(torch.nn.Module):
    """门控残差修正：对系统性预测偏差做补偿，不确定高时收缩校正。"""
    def __init__(self, dim=128):
        super().__init__()
        self.net = torch.nn.Sequential(
            torch.nn.Linear(dim * 2 + 7, 128), torch.nn.SiLU(),
            torch.nn.Linear(128, dim))
        # 可学习门控：初始接近 0，让校正从零开始逐步生效
        self.gate = torch.nn.Parameter(torch.zeros(1))

    def forward(self, z_pred, z_prev, action, unc):
        inp = torch.cat([z_pred, z_prev, action], dim=-1)
        gate = torch.sigmoid(self.gate) * (1.0 - unc)   # 不确定性越高校正越弱
        return z_pred + gate * self.net(inp)

解读：（1）课程比例单调上升，后期稳定在 0.5：完全使用预测帧会让训练分布与真实数据脱节，保留一半真实前缀维持监督质量；（2）采样按轨迹逐步决定，复现时用固定种子；（3）修正门控初始为零，训练早期不干扰预测器，避免随机初始化的修正网络破坏训练；（4）门控与不确定性相乘，把校正限制在模型"确信自己偏了"的位置，校准质量直接决定该机制的效果（与第 031 章衔接）。

常见坑

  • 只训单步却期望长期稳定：模型对单步误差最优，对自身误差的累积没有训练信号。修复：加入多步 rollout 损失，视野按评估时域折中。
  • 远期权重过大：wk 指数增长时训练信号被远期噪声主导，早期预测精度下降。修复：权重取平方根或线性增长，并检查各步损失的分项曲线。
  • BPTT 梯度爆炸：长视野反向传播时梯度范数失控，训练发散。修复：截断 BPTT、梯度裁剪、检查点组合使用；监控逐段梯度范数。
  • 修正网络退化为恒等：校正输出趋近零，指标无变化。修复：检查监督样本是否覆盖系统性偏差场景；先训练预测器再固定训练修正器，避免两个网络互相适应。
  • 教师强制比例全程固定：高位固定让早期训练不稳定，低位固定无法覆盖推理分布。修复：采用单调课程曲线，末段保留一定比例的真实前缀作为监督锚点。

练习与思考

  1. 把多步视野 K 从 15 增到 30。预测显存占用、单步训练时间与可预测时域 k* 的变化，指出边际收益转负的大致位置与判断方法。★
    提示
    显存与时间近似线性上升；k* 的改善在大约 K 超过评估时域后饱和。判断方法是画"K 与 k* 提升"的曲线，找到斜率明显下降的拐点。
  2. 推导：在误差敏感度 c 的假设下，从 ek+1 = ek + ε(1 + c·ek) 出发，解出 ek 的近似闭式表达，说明 c = 0 与 c 较大两种情形下误差增长形态的差异。★★★
    提示
    展开递推得 ek ≈ εk + cε²k²/2，c = 0 时线性增长，c 较大时二次项主导、呈超线性。这正是误差曲线从线性段过渡到发散段的机制。
  3. 设计课程调度消融：线性曲线、指数曲线与固定 0.5 三种调度，预测它们在前中期训练的损失曲线差异与最终 k* 的排序。★★
    提示
    固定 0.5 前中期损失偏高（噪声输入多）；线性居中；指数前段慢后段快，前中期最稳。最终 k* 通常线性与指数接近且优于固定，差异的主要来源是末段分布对齐程度。
  4. 修正网络与多步训练同时启用时，如何区分误差改善的来源？设计一个 2×2 消融并说明对各项指标的预期。★★
    提示
    2×2 为多步目标开关 × 修正网络开关；多步主要改善误差增长曲线的斜率（λ），修正主要降低曲线整体高度（ε 项）。曲线上两种变化模式可直接读出。
  5. 计算：ε = 0.01、c = 5 时用精确解求 e10，与二阶近似 kε + cε2k2/2 对照；再求 c 降到 0.5 时的 e10，评价削减 c 的收益量级。★★
    提示
    精确解 ((1.05)10 − 1)/5 ≈ 0.126，近似 0.125；c = 0.5 时精确解约 0.102，接近线性上界 0.1。削减 c 的收益随乘积 εc 增大而放大，可用 εc 量级快速估算压缩空间。

小结

  • 暴露偏差来自训练与推理的输入分布不一致，正反馈让误差超线性增长。
  • 多步 rollout 损失让模型对远期误差负责，权重与视野需要在噪声与覆盖之间折中。
  • 教师强制课程逐步注入模型预测，概率调度形状比终点值更重要。
  • 显式修正网络补偿系统性偏差，门控与不确定性相乘限制校正范围。
  • BPTT 的显存与稳定性问题用截断、检查点与梯度裁剪组合处理。
