第三篇 · 策略与世界模型深化

第 054 章：世界模型的物理一致性约束

像素级损失对物理规律无感知：本章讲清守恒量残差、时间光滑性与光流一致性三类正则的构造方式，以及惩罚权重从软约束到验证口径的完整流程。

  • 主题：世界模型 / 物理先验（Physics Priors）
  • 关键公式：L = Lpred + λ1·‖Φ(x̂t+1) − Φ(x̂t)‖2 + λ2·‖x̂t+2 − 2x̂t+1 + x̂t‖²
  • 预计学时：55 分钟
  • 前置章节：第 053 章 VLA策略的时序动作生成

学习目标

本章把物理常识转化为可微正则项，同时明确约束的适用边界与验证口径。

  • 理解纯数据驱动世界模型的物理失效模式：穿透、瞬移、能量自发增减、非刚性形变。
  • 掌握守恒量残差正则的形式，理解可观测代理量（Proxy）与学习不变量两类实现的差异。
  • 掌握时间光滑性（二阶差分）与光流一致性两类运动学约束的构造与梯度行为。
  • 理解惩罚方法（Penalty Method）的偏置来源，能设计权重爬升（Ramp）方案平衡拟合与约束。
  • 能建立约束有效性的验证协议：残差指标、长时漂移与下游任务成功率的组合。

背景与动机

世界模型的训练目标是预测误差，误差在像素空间度量，物理规律没有直接进入损失。模型因此可能生成视觉上合理、物理上错误的未来：物体穿透桌面、速度突变为零、接触瞬间位置跳变。这些错误在单步指标上往往不可见，在多步想象中放大，最终以策略在错误想象环境里学到的无效行为显现。

物理一致性约束把已知规律写成对预测的残差惩罚：演化过程中守恒量的漂移、轨迹的光滑性、相邻帧之间的运动学关系。与第 036 章的多步误差修正相比，本章的机制作用在训练损失层，属于结构性正则；误差修正在推理层对预测做后处理，两者可以叠加。约束的难点在于适用边界：接触与摩擦场景本身耗散能量，把守恒律强行施加会引入系统性偏置，需要分场景设计。

核心原理

按"守恒、运动学、组合、验证"四条线索展开。

1. 守恒量残差

对封闭系统，某些标量沿时间保持不变（能量、动量、质量）。世界模型没有直接的物理量输出，需要在观测空间构造代理量：颜色分割估计物体质心、帧差估计速度、已知标定下的深度估计高度。代理量的估计误差会进入残差，因此惩罚权重必须与估计噪声匹配，权重过大会让模型拟合噪声。

Lcons = ‖Φ(x̂t+1) − Φ(x̂t)‖2 Φ 为守恒量代理算子；对自由段轨迹施加，接触段按动力学状态开关

当代理量难以定义时，替代方案是学习不变量：用一个辅助网络在预测序列上估计"应当守恒的量"，同时对辅助网络施加不变性损失。学习不变量的风险是退化：辅助网络可以输出常数通过全部约束，需要加入方差下限或重建任务防止塌缩。

2. 运动学约束

时间光滑性约束限制预测序列的二阶差分，即加速度的幅度：

Lsmooth = Σt ‖x̂t+2 − 2x̂t+1 + x̂t‖2 二阶差分对应离散加速度；该约束抑制高频抖动，但会模糊真实的快速接触

光流一致性约束比较两组流场：预测帧对之间的光流，与真实帧对之间的光流。若世界模型的运动组织正确，预测的光流应接近真实的光流：

Lflow = ‖Flow(x̂t, x̂t+1) − Flow(xt, xt+1)‖1 光流可用可微估计器或冻结的预训练估计器计算；L1 对离群像素更稳健

光流约束传递运动结构，比逐像素 MSE 更直接地约束物体的运动组织，对颜色细节不作要求；其噪声来自估计器在纹理稀疏区域的误差，权重与估计器置信度成反比是更精细的做法。

3. 惩罚方法的偏置与课程

惩罚方法把硬约束转化为软惩罚：L = Lpred + λ·C(x̂)。λ 增大时约束残差下降、预测保真度有偏，λ 过大时模型输出向"满足约束的平滑解"坍缩，表现为预测模糊。这一偏置与拉格朗日乘子法的解存在系统性差距，工程上通过权重爬升与早停控制。

权重爬升方案：前 20% 训练步使用小权重（约束先被软性引入），随后线性升到目标值。爬升的意义在于让模型先掌握基础动力学，再逐步收紧约束；一步到位的大权重会让训练早期就偏向退化解。接触段的开关同样重要：用动力学状态或接触检测器的输出调制约束强度，自由段全强度、接触段降幅。

数值算例：设分割质心的估计噪声为 1.5 像素每帧，相邻两帧残差的噪声标准差约 2.1 像素（√2 倍），平方残差底约 4.5 平方像素。真实的守恒漂移若达 10 像素，平方残差为 100，比噪声底高约 22 倍；λ1 应让这一量级的真实漂移在总损失中可见，同时不把噪声底放大成主导项。

4. 验证协议

约束是否有效需要三项独立验证：其一，残差指标在验证集上下降且未以拟合退化为代价；其二，长时漂移改善，5 步与 15 步的累计误差差距缩小；其三，下游任务的成功率不被模糊化损害。三项指标出现分歧时以任务成功率为准，前两项是诊断信息。验证集必须包含自由段与接触段两类片段，分别报告。

实现思路与设计

训练流程在预测损失之上叠加三项正则，权重按场景与训练阶段调度。

损失结构

  1. 主损失：多步预测的像素与感知损失，保持主导地位。
  2. 守恒残差：对自由段预测施加，接触段按调制系数衰减。
  3. 光滑性：全段轻量施加，权重较小，避免模糊接触动态。
  4. 光流一致性：全段施加，权重按估计器置信度加权。

与前一章的差异点

第 053 章约束策略输出动作序列的时间结构，损失施加在动作空间；本章约束世界模型预测的物理合理性，损失施加在观测空间与潜空间。两者在联合训练中协同：动作块的平滑约束降低世界模型输入的高频抖动，物理残差约束反过来提升想象 rollout 的可信长度，间接扩大动作生成训练的可用视界。

关键代码与解读

以下片段以公开实现的通用设计为参照，接口命名随版本演进。

片段覆盖守恒与光滑残差、光流一致性、以及权重爬升调度。数值与上表一致。

片段 1：守恒残差与二阶光滑惩罚

import torch
import torch.nn.functional as F

def physics_penalties(preds, contact_flags, lambda1=0.05, lambda2=0.01):
    """对预测序列施加守恒残差与二阶光滑惩罚。
    设计意图：守恒量用代理算子 Phi 估计，接触段按调制系数衰减。"""
    # preds: (B, T, C, H, W)；contact_flags: (B, T-1)，1 表示接触段
    phi = segment_centroid_operator(preds)         # 代理量：分割质心加帧差速度
    drift = (phi[:, 1:] - phi[:, :-1]).pow(2).sum(-1)   # 逐时刻守恒量漂移
    # 接触段耗散能量，守恒约束降为 0.2 倍强度，避免引入系统性偏置
    modulation = torch.where(contact_flags > 0.5, 0.2, 1.0)
    loss_cons = (drift * modulation).mean()
    # 二阶差分 = 离散加速度；惩罚其平方抑制预测序列的高频抖动
    accel = preds[:, 2:] - 2 * preds[:, 1:-1] + preds[:, :-2]
    loss_smooth = accel.pow(2).mean()
    return lambda1 * loss_cons + lambda2 * loss_smooth

解读：（1）代理算子用可微分割的质心与速度近似动量等不变量，噪声水平决定权重上限；实现中分割网络冻结，避免约束与分割互相追逐。（2）接触调制在张量级完成，调制系数来自数据标注或接触检测器；缺少这一机制时模型在接触段被迫保持守恒，表现为物体"粘"在接触面。（3）光滑项作用于像素张量，计算量为 O(B·T·C·H·W)，与主损失同阶；若训练显存紧张可改为在潜空间施加，用潜状态的二阶差分近似。

片段 2：光流一致性

def flow_consistency_loss(preds, reals, flow_estimator, weight=0.1):
    """预测帧对的运动结构应当与真实帧对一致。"""
    # 估计器冻结：流场只作为监督信号，不参与自身训练
    with torch.no_grad():
        flow_real = flow_estimator(reals[:, :-1], reals[:, 1:])
        confidence = flow_estimator.confidence(reals[:, :-1], reals[:, 1:])
    flow_pred = flow_estimator(preds[:, :-1], preds[:, 1:])
    # L1 损失对纹理稀疏区的估计噪声更稳健，置信度低的位置自动降权
    per_pixel = (flow_pred - flow_real).abs().sum(dim=2)
    loss = (per_pixel * confidence).mean()
    return weight * loss

解读：（1）真实流场在 no_grad 下计算并冻结为目标，预测流场保留梯度，方向明确。（2）置信度加权来自估计器自身的输出，低置信像素（无纹理、遮挡）贡献下降，减少噪声进入监督信号。（3）流场对比的是运动组织，模型在颜色、纹理上的偏差不被惩罚，这使约束与感知损失互补而不重复。

片段 3：权重爬升调度

def penalty_weight(step, total, target=0.05, warmup_ratio=0.2):
    """惩罚权重线性爬升：前 20% 步数从 0 升到目标值，之后保持不变。"""
    warmup = int(total * warmup_ratio)
    if step < warmup:
        # 早期小权重：先让模型掌握基础动力学，再逐步收紧约束
        return target * step / max(1, warmup)
    return target

# 训练循环中的使用方式

# loss = loss_pred + w * physics_penalties(preds, contact_flags)

解读：（1）爬升把约束引入时机作为独立旋钮，与目标权重解耦；改变目标权重不会改变引入节奏，实验对照更清晰。（2）若验证残差在爬升结束后仍未下降，应检查代理量定义与数据标注；继续调大权重只会把偏置放大。（3）调度函数保持纯函数形式（不依赖全局状态），便于单元测试与曲线可视化。

常见坑

  • 惩罚权重一步到位：训练早期约束主导，预测退化为平滑模糊的均值解。修复：采用权重爬升，前 20% 步数小权重引入。
  • 在接触段强行守恒：物体贴附或穿透的伪影反而增加。修复：按接触状态调制约束强度，接触段降至 20% 量级。
  • 代理量噪声被当作误差学习：分割或流估计器的抖动进入梯度，模型学会复现噪声。修复：估计器冻结，权重与置信度匹配，验证残差是否随权重下降而饱和。
  • 只在短时窗口验证：5 步指标改善但 15 步漂移更差，约束的收益被掩盖。修复：验证协议覆盖 5、15、30 步三档，分别报告。
  • 学习不变量塌缩为常数：辅助网络输出常数即可满足守恒残差。修复：加方差下限或与重建任务联合训练，监控不变量输出的方差。

    自由段施加动能加势能近似守恒；碰撞瞬间能量耗散，改为约束反弹系数在合理区间。接触标注可来自仿真状态或力传感。
  2. 把光滑权重 λ2 从 0.01 提高到 0.5，预测三件事的变化：动作段预测模糊度、接触瞬态保真度、任务成功率，并说明验证方式。★★
    提示
    模糊度上升，接触瞬态被抹平，成功率大概率下降。验证：在接触密集片段上看快速运动的预测帧差与成功率曲线。
  3. 推导：惩罚方法的解与硬约束最优解之间的偏置如何随 λ 变化？说明为什么 λ 增大时预测趋向"平滑解"。★★★
    提示
    惩罚项梯度与主损失梯度在最优点的平衡决定偏离量，λ 越大平衡点越靠近约束可行集，而可行集内的最优点往往是低方差解，即平滑解。
  4. 设计实验验证光流一致性的增量贡献：与控制组（仅预测损失）、消融组（去除置信度加权）比较，给出指标口径。★★
    提示
    指标：验证集流场误差、15 步累计像素误差、下游成功率。消融组验证置信度加权是否降低噪声敏感度。

小结

  • 物理一致性约束把守恒、光滑与运动学关系写成可微惩罚，弥补像素损失对物理规律的无感知。
  • 守恒残差依赖代理量或学习不变量，代理量的估计噪声决定权重上限，接触段需要降幅调制。
  • 二阶差分与光流一致性分别约束高频抖动与运动结构，后者对纹理细节的偏差不敏感。
  • 惩罚方法存在系统性偏置，权重爬升与场景调制是控制偏置的两条主线。
  • 验证协议覆盖残差、长时漂移与任务成功率三项，验证集按自由段与接触段分层。
