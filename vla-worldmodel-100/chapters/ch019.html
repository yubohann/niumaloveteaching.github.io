第一篇 · 基础框架与联合训练

第 019 章：VLA策略的鲁棒性测试

本章建立策略质量防线：分布偏移的分类、扰动强度阶梯的测试套件、配对评估协议与鲁棒性曲线，以及把失效归因到感知、语言、控制三个子系统的探测方法。

  • 主题：VLA 策略 / 鲁棒性测试
  • 关键公式：AUCrob = ∫ SR(强度) d(强度)（鲁棒性曲线面积）
  • 预计学时：60 分钟
  • 前置章节：第 018 章

学习目标

  • 理解 VLA 策略鲁棒性的定义与三类分布偏移：观测偏移、语言偏移、动力学偏移。
  • 掌握扰动套件的设计方法：扰动家族、强度阶梯与组合策略，控制测试规模。
  • 掌握配对评估协议与鲁棒性指标：成功率曲线、曲线面积、最差分组表现。
  • 能实现失效归因探测：区分感知失效、语言理解失效与控制失效。
  • 能统计检验两组策略的鲁棒性差异，避免样本量不足导致的错误结论。

背景与动机

训练集上的指标只能说明策略在已知分布内的拟合程度，部署面对的光照漂移、指令改写、物体摆放变化都在训练分布之外。鲁棒性测试回答的问题是：当输入条件偏离训练分布时，策略性能的衰减形态是什么，衰减到什么程度会越过任务可接受的底线。

联合训练系统的鲁棒性还有一层特殊结构：策略的输入包含世界模型的预演（规划路径）与想象数据（训练路径），世界模型自身的预测退化会以间接方式传导到策略表现。测试需要分离“策略本身的鲁棒性”与“依赖组件的传导退化”，否则归因错误会让修复方向南辕北辙。

与相邻章节的边界：041 章研究对抗样本与对抗训练，攻击目标是最大化失效；本章是常规条件下的系统性测试与归因。019 章的失败清单将回流到数据管线（002 章）、课程调度（018 章）与探索机制（015 章），构成训练闭环的末端检查。

核心原理

1. 鲁棒性的定义与三类分布偏移

鲁棒性指策略在分布偏移下保持任务成功的能力，其强弱由整条“衰减曲线”刻画，单一数值会丢失衰减形态。偏移按来源分三类：观测偏移，画面侧的照度、遮挡、相机位姿、噪声变化；语言偏移，指令改写、指代方式变化、措辞歧义；动力学偏移，负载质量、摩擦、执行延迟、传感偏置的变化。三类偏移在系统中的传导路径不同，测试必须分别设计并单独报告。

SR(s) = P(任务成功 | 扰动强度 = s) ，AUCrob = ∫0smax SR(s) ds / smax SR 为成功率；曲线面积把整条衰减曲线压缩为单一指标，便于版本对比

数值算例：鲁棒性曲线的面积计算

以照度扰动为例，五级阶梯的亮度乘数为 0.6、0.8、1.0、1.2、1.4（第 2 节的亮度函数取 span = 0.4）。三个候选策略在同一套 200 次配对试验上的成功率如下表。

策略等级 0等级 1等级 2等级 3等级 4AUCrob
A0.960.930.850.650.300.765
B0.900.880.840.780.700.825
C1.000.990.900.500.100.735

面积按梯形法计算，策略 A 为：AUCrob = (1/4) × [ (0.96+0.93)/2 + (0.93+0.85)/2 + (0.85+0.65)/2 + (0.65+0.30)/2 ] = 3.06 / 4 = 0.765。三点结论：其一，策略 B 峰值最低而面积最大，最差等级仍有 0.70，适合对极端照度要求波动容忍的下游任务；其二，策略 C 在标称照度附近接近满分，等级 3、4 快速恶化，AUC 被拖到 0.735，属于低强度表现强、高强度急剧恶化的形态；其三，只比较等级 2 的单点成功率会把 C 排在 A 之前，整条曲线加尾部分组才能暴露差异。

面积口径也有陷阱：梯形法假设相邻等级之间近似线性，若曲线在两级之间出现断崖（例如遮挡面积从 0.3 升到 0.4 时成功率减半），五点采样会高估面积。补救是同时报告最差等级成功率与降到标称成功率七成的临界等级，与 AUC 三项并列。

2. 扰动套件：家族与强度阶梯

扰动空间是组合爆炸的，套件设计的目标是用有限测试覆盖主要风险。方法：每个偏移类别选三到五个代表性“扰动家族”（例如观测类选照度、遮挡、噪声、模糊），每个家族设五级强度阶梯（以训练分布统计为基准的倍数），先做单家族测试，再对关键组合做抽查。强度阶梯以可量化单位定义：照度按亮度均值偏移的百分比、遮挡按画面面积占比、延迟按控制周期倍数，保证测试可复现、可跨版本比较。

组合规模：F 个家族、L 级阶梯、单家族 n 次时全套为 F·L·n；两两组合全测按平方增长。常规策略是单家族全测，组合只测由单家族结果挑出的高敏感对，验证交互效应。

阶梯跨度的标定方法：取训练集照度统计量，等级 2 用均值 μ 作对照，等级 0 与 4 分别取 μ−2σ 与 μ+2σ，五级等距覆盖约四倍标准差。留余量的原因是部署侧实测照度若覆盖 μ ± 1.5σ，曲线端点附近仍需保留可测的退化信息；当实现采用固定倍数（如 0.6 至 1.4 倍基准）时，应核对两种口径是否落在同一量级，偏差过大说明训练基准定义需要重新核对。

3. 配对评估协议

配对评估指同一初始状态在对照与扰动条件下各执行一次，差异只归因于扰动。非配对评估会把任务方差混入估计，样本不足时结论不可靠。样本量按目标分辨率确定，区分 5 个百分点差异约需每条件上百次试验，报告给出置信区间。

Δ̂ = (1/n)·Σi( yi扰动 - yi对照 ) ，CI = Δ̂ ± 1.96·σΔ/√n 配对差分的方差远小于两组独立方差；y 为成败指示量

数值算例：三路归因的恢复量分解

设对照条件成功率 0.95、扰动条件 0.55，总退化 0.40。三路探测各自只替换单一环节：真值状态替换后成功率 0.80，恢复 0.25，占总退化的 62.5%；标准指令替换后 0.72，恢复 0.17，占 42.5%；开环重放 0.62，恢复 0.07，占 17.5%。三项份额相加超过一，因为替换任一路径都会顺带缓解其他路径上的传导（感知变准之后，语言指令的条件作用也随之恢复），归因份额用于排序修复优先级，不具备严格的可加分割含义。读法与判据：感知份额最高时先补视觉数据增强；语言份额接近零时语言编解码不是瓶颈；开环恢复量接近零说明失败主要发生在动作选择环节，约束了控制侧的改进空间。为避免三种条件相互污染，探测必须遵循单一替换原则，禁止一次替换两个环节的联合探测。

数值算例：配对设计的样本量

样本量由目标分辨率反推：n ≈ (z0.975 + z0.8)2 · σΔ2 / δ2 ≈ 7.85 · σΔ2 / δ2。设历史版本统计给出的配对差分标准差 σΔ = 0.35（口径为成败指示量），要分辨 δ = 0.05 的退化需 n ≈ 7.85 × 0.1225 / 0.0025 ≈ 385 次；降到 200 次时，置信半径扩大为 1.96 × 0.35 / √200 ≈ 0.049，区间宽度约 10 个百分点，5 个百分点级别的结论无法成立。把分辨率提高到 3 个百分点，样本量约需 7.85 × 0.1225 / 0.0009 ≈ 1069 次，是 5 个百分点情形的约 2.8 倍，与 δ 平方反比的缩放一致。

配对设计的方差优势来自协方差项：Var(Δ) = σA2 + σB2 − 2ρσAσB。取 σA = σB = 0.5、组间相关 ρ = 0.3，配对方差约 0.35/n，非配对比较约 0.5/n，所需样本量按 (1 − ρ) 的因子缩小；ρ 越高节省越多，这正是固定种子池的价值所在。

4. 失效归因探测

成功率下降只是表象，归因需要探测手段。感知探测：把策略输入替换为真值状态（仿真中可得）重跑，若表现恢复说明失效主要在感知侧；语言探测：把扰动指令替换为训练分布内的同义标准指令，若恢复说明语言编码与泛化是瓶颈；控制探测：执行开环动作序列重放，若失败说明动作序列生成受扰动影响，动作执行本身正常。三个探测分别对照一次，可将失效分布到三个子系统，指导修复资源的分配。

5. 与联合训练回路的衔接

产出形成清单：观测类失效转数据增强（002 章），语言类失效转改写覆盖检查（012 章），动力学类失效转随机化与自适应需求（028、080 章）。世界模型单独测量：多步预测误差重复同一阶梯，若策略退化伴随预测退化，应先修世界模型。

适用边界与失效模式

套件与指标在四种情形下给出误导结论。其一，强度标定超出量程：部署侧出现 2 倍基准照度的强光，而阶梯上限只到 1.4 倍，曲线右端行为未被覆盖，AUC 只反映端内积分，报告须附带阶梯覆盖范围的声明。其二，跨家族直接加总：照度按亮度倍率、遮挡按面积占比、延迟按周期倍数，三类单位不可公度，只能分别报告面积，不能平均成一个总分。其三，天花板与地板效应：等级 0 就接近满分时，左侧面积对区分度无贡献，改进空间全部挤在右侧，应把采样密度向高等级倾斜。其四，任务难度与扰动耦合：同一扰动在不同初始状态上的退化幅度可能相差数倍，只报总体曲线会掩盖分组差异，需按初始状态分组报告最差分组，这正是最差分组阈值存在的理由。

组合交互的判定尺度

单家族退化量与组合退化量构成交互检验：设仅视觉扰动的配对退化 Δv = 0.08、仅动力学扰动 Δd = 0.06，两者组合实测 Δc = 0.20。若失效路径独立，组合退化应接近相加的 0.14；实测超出 0.06，比值 0.20 / 0.14 ≈ 1.43，说明两条路径存在乘性交互（例如视觉误判让动力学修正动作本身成为扰动源）。比值在 1.2 以内按独立路径处理，超过 1.5 时应按组合条件重新设计训练增强，而不再把两条路径拆开各自修补。

实现思路与设计

测试系统四层：扰动生成器（按家族与阶梯参数化）、配对执行器（固定种子分配初始状态）、指标聚合器（成功率曲线、面积、置信区间）、归因探测器（三类替换重跑）。全部测试配置以声明式文件描述，套件版本与模型版本绑定归档。

设计决策：以固定种子池替代随机抽样

初始状态与随机源来自固定种子池，任何版本、任何条件的测试都在同一批初始状态上执行。配对差分因此消除任务方差；跨版本对比时，同一状态上的成败翻转直接对应模型变化。种子池本身按覆盖度分层抽取（目标位置、物体摆放、指令类型的组合），确保“固定”不以牺牲代表性为代价。

衔接与差异：018 章的评估器提供分箱报告，本章把分箱维度从难度扩展为扰动类别；041 章在对抗样本方向深入；本章的归因结果与 008 章的失效过滤共用“来源标记”的数据通路。

关键代码与解读

片段以机器人仿真评测与鲁棒性基准的公开设计为参照，接口随版本演进。第 1 段给出扰动阶梯生成。

片段 1：扰动家族与强度阶梯

import numpy as np

def brightness_ladder(level, base=1.0, span=0.4):
    """照度扰动：以亮度乘数为参数，五级阶梯对称覆盖暗与亮。"""
    # level 取 0–4：低于 2 偏暗、高于 2 偏亮，2 为对照强度
    return base * (1.0 + span * (level - 2) / 2.0)

def occlusion_ladder(level, area_ratio=0.4):
    """遮挡扰动：以画面面积占比为强度，位置由固定种子决定保证可复现。"""
    # 面积与等级线性挂钩：等级 0 无遮挡，等级 4 占画面四成
    return area_ratio * level / 4.0

def delay_ladder(level, control_period=0.1):
    """执行延迟扰动：以控制周期倍数为强度，模拟通信与执行滞后。"""
    # 延迟单位化到控制周期：等级 4 对应约两个周期的滞后
    return control_period * (level * 0.5)

def build_suite(level, rng):
    """组装一次测试条件：各家族按当前等级参数化，随机量由种子池驱动。"""
    return {
        "brightness": brightness_ladder(level),
        "occlusion_area": occlusion_ladder(level),
        "occlusion_site": rng.integers(0, 4),   # 四个象限中的遮挡位置
        "delay": delay_ladder(level),
    }

解读：（1）每个家族的参数化都以可量化物理量为单位，测试条件可以跨版本复现与解释，不采用“低中高”这类无刻度描述。（2）随机量（遮挡位置）由传入的随机源决定，种子池管理集中在调用方，测试函数保持纯函数。（3）各阶梯函数的 span 与上限都是配置项，强度范围的标定依据是训练分布的统计量，每个取值都追溯到统计数据。

片段 2：配对评估与置信区间

def paired_eval(run_fn, seeds, perturb_fn, alpha=0.05):
    """配对评估：同一种子下执行对照与扰动两组，输出配对差与置信区间。"""
    diffs = []
    for seed in seeds:
        # 对照与扰动共享初始状态与随机源派生：差的唯一来源是扰动条件
        y_ctrl = run_fn(seed, condition=None)
        y_pert = run_fn(seed, condition=perturb_fn(seed))
        diffs.append(float(y_pert) - float(y_ctrl))
    d = np.asarray(diffs)
    # 配对差分均值与标准误：方差通常远小于两组独立比较
    mean_d = d.mean()
    se = d.std(ddof=1) / np.sqrt(len(d))
    # 正态近似置信区间；试验数小于三十时应改用自助法
    ci = 1.96 * se
    return {"delta": mean_d, "ci_low": mean_d - ci, "ci_high": mean_d + ci}

解读：（1）种子同时驱动初始状态与扰动随机量，条件分配完全确定，重复运行结果一致。（2）聚合用配对差分，两组分别聚合会混入任务方差：配对设计把任务难度从指标中消掉，样本量需求显著下降。（3）置信区间随结果一同返回，报告“退化 12 个百分点（区间 ±4）”比单点数值更可用于决策；小样本场景的分布假设不成立，注释中给出替代方案。

片段 3：失效归因探测

def attribution_probe(run_policy, run_oracle_state, run_oracle_lang,
                      seed, condition):
    """三路探测：分别替换感知、语言、控制条件，定位失效所在子系统。"""
    # 感知探测：输入替换为真值状态；恢复说明失效主要在感知侧
    y_state = run_oracle_state(seed, condition)
    # 语言探测：指令替换为训练分布内标准表述；恢复说明语言泛化是瓶颈
    y_lang = run_oracle_lang(seed, condition)
    # 控制探测：开环重放不受扰动影响的动作序列并观察执行结果
    y_control = run_policy(seed, condition, probe="open_loop")
    # 三路结果与原始条件对照，恢复幅度最大的路径即主要失效来源
    return {"oracle_state": y_state, "oracle_lang": y_lang,
            "open_loop": y_control}

解读：（1）三个探测以“替换单一环节、其余保持扰动”为原则，恢复幅度构成归因证据；全部替换的联合探测会失去分辨力。（2）开环控制探测只检验动作序列的可执行性，与感知、语言路径独立，三者构成完备的二分。（3）探测结果进入测试报告模板，与扰动家族维度交叉后得到“哪类扰动经由哪条路径失效”的矩阵，直接指导修复优先级。

常见坑

  • 非配对比较：对照与扰动用不同种子，任务方差混入鲁棒性估计。修复：固定种子池配对执行，指标改为配对差分。
  • 只测单一家族：仅测照度或仅测改写，高估整体鲁棒性。修复：三类偏移至少各覆盖一个家族，关键组合做抽查。
  • 只看平均成功率：个别状态的长尾崩溃被平均值掩盖。修复：报告最差分组，并设分组底线阈值。
  • 样本量不足下结论：几十次试验的差异在置信区间内不可区分。修复：按目标分辨率计算样本量，报告同时给出置信区间与点估计。
  • 测试分布泄漏进训练：扰动测试集被用于调参多轮后失去独立性。修复：保留一份不参与调参的最终验收测试集，仅在里程碑时启用。

练习与思考

  1. 五级照度阶梯、span=0.4、基准亮度 1.0，计算各级亮度乘数，说明为什么强度阶梯要对称覆盖两侧。★
    提示
    乘数依次为 0.6、0.8、1.0、1.2、1.4；部署环境的偏暗与偏亮都会出现，单侧阶梯会漏检一侧失效。
  2. 把单条件试验数从 200 降到 50，预测置信区间宽度与结论可靠性的变化。★
    提示
    区间宽度约翻倍（√4），可分辨差异从约 5 个百分点退化到约 10 个百分点以上，小差异结论不再可靠。
  3. 推导：说明配对差分方差小于两组独立比较方差的来源，并给出两者关系的表达式。★★
    提示
    Var(A-B) = Var(A) + Var(B) - 2·Cov(A,B)；同一初始状态下两组高度正相关，协方差项显著抵消方差。
  4. 设计一套完整鲁棒性测试方案：偏移类别、家族与阶梯、样本量、归因探测与报告模板，说明各部分的先后顺序。★★
    提示
    顺序：单家族全阶梯扫描定位敏感方向，再对高敏感对做组合抽查，最后对失效方向执行三路归因探测；报告按“扰动类×恢复路径”矩阵组织。
  5. 构造实验：同一策略在“仅视觉扰动”“仅动力学扰动”“两者组合”下的配对退化量，检验交互效应是否存在，解释结论对修复策略的含义。★★★
    提示
    组合退化大于两者之和说明存在乘性交互，修复需针对组合条件；接近相加说明失效路径独立，可分别处理。

小结

  • 鲁棒性由衰减曲线刻画，偏移分观测、语言、动力学三类分别测试与报告。
  • 扰动套件以家族加五级强度阶梯组织，组合测试只抽查高敏感对以控制规模。
  • 配对评估消除任务方差，指标用配对差分与置信区间表达，样本量按分辨率计算。
  • 三路归因探测（真值状态、标准指令、开环重放）把失效定位到感知、语言、控制子系统。
  • 世界模型的退化会经规划与想象路径传导，需单独测量预测误差的扰动曲线。
