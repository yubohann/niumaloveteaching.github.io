第四篇 · 训练机制与应用集成

第 079 章：联合训练中的模型集成

本章讲联合训练中的模型集成（Model Ensemble）：从偏差方差分解出发理解集成为何有效，用独立初始化与自举采样制造多样性，把成员分歧当作不确定性估计，并用加权与蒸馏控制推理成本。

  • 主题：模型可靠性 / 集成与不确定性
  • 关键公式：Var(平均) = ρσ2 + (1−ρ)σ2/M，预测 = 成员均值，不确定性 = 成员方差
  • 预计学时：50 分钟
  • 前置章节：第 078 章：世界模型的动态因果发现

学习目标

  • 理解集成的偏差方差分解：为什么成员误差去相关时平均能降低预测方差，而偏差不随之下降。
  • 掌握多样性来源的分类：独立初始化、数据自举、训练轨迹差异与结构差异，理解同质化集成的失效机制。
  • 掌握分歧作为认知不确定性估计的用法，能区分它与第 062 章参数后验、第 075 章评估误差的联系与差别。
  • 能实现成员前向与分歧计算、自举采样训练与加权融合，掌握蒸馏回单模型控制推理成本。
  • 会诊断共享初始化、成员数收益递减与快照集成配置问题，能设计多样性度量实验。

背景与动机

本节说明集成针对的可靠性问题：单个世界模型或策略的预测在数据稀疏区域不可靠，且没有内部信号提示“此处不可靠”。集成用多个独立训练的成员构成预测委员会：均值通常比单成员更准确，成员分歧直接给出不确定性读数。在联合训练中，集成分歧有四处用途：想象数据按分歧降权、规划候选按分歧打分、数据采集优先覆盖高分歧区域、模型更新时检测分布漂移。代价是训练与推理成本的线性增长，工程上的问题变成“用多少成员、怎样保持多样性、怎样把成本收回”。

核心原理

1. 偏差方差分解与集成的增益来源

回归误差可分解为偏差、方差与噪声三项。集成对噪声与偏差作用有限，主要降低方差项。设单成员误差方差为 σ2，成员间误差相关系数为 ρ，平均 M 个成员的方差为

Var = ρσ2 + (1 − ρ)σ2 / M ρ 为成员间误差相关系数：ρ 越小，成员数 M 的收益越大；ρ → 1 时集成退化为单模型

该公式给出两条工程结论：多样性（低 ρ）比成员数更重要，同质成员的边际收益迅速衰减；M 从 2 增到 5 的收益远大于从 10 增到 20。集成降低的是方差，系统偏差（例如世界模型对接触动力学的简化）不会因为成员增多而消失。

2. 数值算例：方差随成员数与相关性的变化

取单成员误差方差 σ2 = 1，代入公式 Var = ρ + (1 − ρ) / M 计算几组典型配置：ρ = 0.9 时，M = 2 得 0.95、M = 5 得 0.92、M = 10 得 0.91，成员从 5 增到 10 只把方差再压 1%，且无论 M 多大，方差都不低于 0.9；ρ = 0.3 时，M = 2 得 0.65、M = 5 得 0.44、M = 10 得 0.37；ρ = 0.1 时，M = 5 得 0.28。

ρ = 0.9：M = 5 → 0.92（相对单成员仅降 8%） ρ = 0.3：M = 5 → 0.44（降 56%） ρ = 0.1：M = 5 → 0.28（降 72%） 方差下限为 ρ：相关性决定集成可达的上限，成员数只在 (1−ρ) 的余量内做功

数值结果给出两条资源配置结论：（1）成员误差相关性从 0.9 降到 0.3，同样 5 个成员的方差降幅从 8% 放大到 56%，投入在多样性上的代价（独立初始化、自举、结构差异）比增加成员数回报更高；（2）方差的地板由 ρ 设定，当 ρ = 0.9 时把成员从 5 加到 20 也只能把方差从 0.92 压到约 0.905，成员数扩容前先测误差相关矩阵，ρ 高时先修多样性来源。

3. 多样性从哪里来

四类来源按成本排序：独立随机初始化，成本最低，适合小成员；数据自举（有放回采样），让成员看到不同子集；训练轨迹差异（不同数据顺序、学习率调度、检查点快照）；结构差异（不同隐维、不同动力学族），多样性最高但维护成本最大。同质化是集成最常见的失效：共享同一初始化、同一数据顺序的成员误差高度相关，集成收益趋近于零。验证多样性的直接指标是成员误差的相关系数矩阵与分歧的分布宽度：分歧长期接近零即同质化报警。四类来源的定量特征对照如下：

多样性来源额外训练成本典型误差相关量级多样性强度适用条件
独立初始化无额外成本，随成员训练0.7 至 0.9，取决于网络宽度基础来源所有集成的默认起点
数据自举采样实现成本，可忽略在初始化基础上再降 0.1 至 0.2中等数据量充足、样本多样性高
训练轨迹差异与快照复用同一次训练，成本低0.6 至 0.8，快照间隔决定中等偏低训练循环已有学习率循环
结构差异训练成本最高，维护多套0.3 至 0.6最强对不确定性质量要求高的场景

组合策略：独立初始化加自举是标准配方，覆盖多数场景；延迟受限时用快照集成省训练；需要高质量分歧时再引入结构差异。误差相关量级是经验区间，实际取值按每个任务实测，测量方式为固定测试集上成员预测残差的两两相关矩阵。

把实测相关矩阵代入方差公式做配置决策：某次训练后成员两两误差相关矩阵的平均值为 0.72，M = 5 时集成方差为 0.72 + 0.28 / 5 = 0.776；保持配置不变把成员加到 10 个，方差为 0.72 + 0.28 / 10 = 0.748，改善不足 4%。改用自举采样把平均相关压到 0.50，5 个成员的方差为 0.5 + 0.1 = 0.6，改善 23%；再引入结构差异把平均相关压到 0.30，方差为 0.3 + 0.14 = 0.44。数值给出行动顺序：先测相关矩阵再动成员数，相关高于 0.7 时把预算投给多样性来源（自举、结构差异），相关进入 0.5 以下后才用成员数做微调。

4. 分歧作为不确定性

成员预测的方差估计认知不确定性：数据覆盖充分处成员收敛到相近预测，分歧小；数据稀疏处成员外推方向不同，分歧大。与第 062 章的关系：参数后验采样与集成分歧都是认知不确定性的近似，集成不依赖变分假设，实践上更易实现；与第 075 章的关系：规划中的价值集成正是本章分歧用法在规划器上的实例。分歧是相对量：它反映成员对该样本的一致程度，绝对量级随成员数与任务尺度漂移，校准需要与真实误差的联合分布对照，常用分位数映射做温度式修正。

5. 成本控制：加权、快照与蒸馏

推理成本的三个压缩层次：加权集成按验证表现或似然给成员赋权，权重小的成员可以裁剪；快照集成复用同一次训练的学习率循环，在周期低谷保存检查点，省去重复训练但多样性低于独立训练；蒸馏把集成均值行为压回单模型，推理成本回到一倍，代价是放弃分歧读数。需要不确定性读数时保留两到三个成员是常见配置，需要极致延迟时用蒸馏后的单模型加轻量分歧头。训练成本的对称控制是参数高效集成：共享骨干、成员只保留独立预测头，多样性受一定损失。

实现思路与设计

本节给出配置：世界模型用 5 个成员（独立初始化加自举采样），策略用 3 个成员；世界模型分歧用于想象数据加权与数据采集优先级；策略分歧用于动作方差调节与安全切换；推理主路径使用加权集成，若延迟超预算则切换到双成员加蒸馏头的组合。与第 078 章的差异：第 078 章学习单个模型的结构，本章用多模型委员会处理预测可靠性与不确定性。

设计决策：为什么分歧要按成员数归一化后再用

原始分歧是成员间方差，量级随成员数与任务尺度漂移，直接作为阈值使用会把工作点绑死在某一配置上。归一化方式有两种：除以集成的整体方差得到相对分歧（0 至 1 区间），或映射到历史分歧分布的分位数。把分歧用相对量表述，想象加权、规划打分与安全切换三个下游可以共享同一套阈值口径。

成员数与推理路径的决策流程

  • 成员数的判定依据。先训练 3 个成员测量误差相关矩阵，若平均相关低于 0.5，扩展到 5 个并观察验证误差的下降幅度；下降低于噪声水平即停止。成员数由“相关矩阵加边际收益曲线”共同决定，不由默认值决定。
  • 加权与等权的选择。成员验证表现差异明显（超过一个标准误）时用验证加权的凸组合；差异不显著时保持等权，加权会引入对验证集过拟合的权重。
  • 推理路径的降级链。主路径为全部成员加权集成；延迟超预算时按权重从低到高逐步停用成员；仍超预算改用双成员加蒸馏头；极端受限时只用蒸馏学生并在服务端监控分歧代理指标。
  • 分歧读数的保留。蒸馏时在学生的辅助头上回归教师分歧，用保留集校准；辅助头是轻量多层感知机，推理开销相对主干可忽略。
  • 权重与成员索引的版本绑定。权重向量、成员注册顺序与检查点构成一个部署单元，任一变动触发全量回归测试，防止顺序错位造成的静默错误。

关键代码与解读

以下片段以深度集成的公开设计为参照，接口随版本演进。三个片段分别覆盖集成前向与分歧、成员训练与加权融合。

片段 1：集成前向与分歧计算

import torch

@torch.no_grad()
def ensemble_predict(members, obs, action=None):
    """集成预测：均值给结果，分歧给不确定性。"""
    preds = torch.stack([m(obs, action) for m in members])   # M x B x D
    mean = preds.mean(dim=0)
    # 成员间方差即认知不确定性：数据覆盖处收缩，稀疏处放大
    disagreement = preds.var(dim=0).sum(dim=-1)              # B
    # 相对分歧：除以整体尺度，便于跨配置统一阈值
    scale = preds.var(dim=0).mean(dim=-1).clamp_min(1e-6)
    return mean, (disagreement / (disagreement + scale)).detach()

解读：（1）members 为独立 PyTorch 模块列表，逐个前向即可，无需共享计算图。（2）方差对特征维求和：动作维度与隐维的误差都计入不确定性。（3）相对分歧采用“分歧占总方差比例”的写法，输出天然落在 0 到 1 区间。

片段 2：自举采样的成员训练

import torch

def train_member(seed, dataset, build_fn, steps=5000, batch=256):
    """成员训练：独立初始化与自举采样提供两类多样性。"""
    torch.manual_seed(seed)
    model = build_fn()                    # 不同种子：参数初始化不同
    opt = torch.optim.AdamW(model.parameters(), lr=2e-4, weight_decay=1e-2)
    for _ in range(steps):
        # 有放回采样：不同成员依赖不同的数据子集视角
        idx = torch.randint(0, len(dataset), (batch,))
        batch_data = dataset.gather(idx)
        loss = model.training_step(batch_data)
        opt.zero_grad()
        loss.backward()
        opt.step()
    return model

解读：（1）种子先于构建：网络初始化的随机性决定成员的起点差异，是多样性的第一来源。（2）有放回采样保持单步样本量不变，统计上近似从经验分布重采样。（3）成员间不共享优化器状态：学习率与动量轨迹的差异也是多样性的一部分。

片段 3：加权融合与蒸馏回单模型

import torch

def weighted_predict(members, weights, obs, action=None):
    """按验证表现加权：权重归一化后做凸组合。"""
    preds = torch.stack([m(obs, action) for m in members])
    w = torch.tensor(weights, device=preds.device)
    w = w / w.sum()
    return (preds * w.view(-1, 1, 1)).sum(dim=0)

def distill_ensemble(teachers, student, data, steps=2000):
    """把集成均值蒸馏回单模型：推理成本回到一倍。"""
    opt = torch.optim.AdamW(student.parameters(), lr=1e-4)
    for _ in range(steps):
        batch = data.sample(256)
        with torch.no_grad():
            # 教师均值作软目标；方差信息可注入学生的辅助头
            target = torch.stack([m(batch.obs) for m in teachers]).mean(dim=0)
        loss = torch.nn.functional.mse_loss(student(batch.obs), target)
        opt.zero_grad()
        loss.backward()
        opt.step()
    return student

解读：（1）权重向量与成员顺序绑定，验证时的成员索引必须与训练注册顺序一致。（2）凸组合保证不放大尺度，权重和为 1。（3）蒸馏只回传学生梯度，教师保持冻结；若下游需要不确定性，可在学生上加辅助分歧头并单独监督。

常见坑

  • 共享初始化导致同质化：成员误差相关系数接近 1，集成退化为单模型。修复：先于构建设置不同种子，用误差相关矩阵验证多样性。
  • 只看均值丢弃分歧：推理接口只返回预测，不确定性信息浪费。修复：接口统一返回均值与分歧两路，下游按需使用。
  • 成员数盲目增加：方差按 1/M 下降但边际收益递减，显存与延迟线性上升。修复：按分歧收敛曲线定成员数，超过收益平台即停止。
  • 快照集成节奏错误：学习率循环周期过短，检查点差异不足。修复：快照间隔取循环周期的四分之一到一半，验证检查点多样性。
  • 蒸馏丢失校准：学生贴合均值但不确定性与真实误差脱节。修复：蒸馏后重新标定分歧头，用保留集校准分位数映射。

练习与思考

  1. 计算题：ρ = 0.9、σ2 = 1 时，成员数从 1 增到 5 的方差各是多少？再把 ρ 降到 0.3 重算，解释多样性为何比堆成员更关键。★
    提示
    ρ = 0.9 时 M = 5 的方差约 0.92；ρ = 0.3 时约 0.44。低相关成员把同样的成员数兑现成更高的方差下降。
  2. 把片段 2 的自举关闭（bootstrap=False 的变体），预测成员误差相关系数与集成收益的变化。★
    提示
    共享数据视图后相关系数上升，集成收益下降；若同时共享初始化，收益接近零。
  3. 推导题：由 Var = ρσ2 + (1−ρ)σ2/M 出发，推导成员数翻倍带来的方差下降比例，并说明该比例与 ρ 的关系。★★
    提示
    下降比例 = (1−ρ)σ2/(2M) 相对当前方差；ρ 越大，翻倍收益越小，ρ = 1 时为零。
  4. 实验设计：对独立初始化、自举、快照、结构差异四种多样性来源做消融，报告误差相关矩阵、分歧分布与预测误差，找出最优性价比组合。★★
    提示
    初始化加自举通常覆盖大部分收益；快照最省训练成本但相关性偏高；结构差异收益最高、维护成本也最高。
  5. 设计题：为安全切换设计基于分歧的协议：阈值如何按相对分歧标定、切换动作如何保持连续、怎样避免分歧短暂尖峰引发频繁切换。★★★
    提示
    阈值取历史分布的 95 分位并按任务标定；切换输出保持动作块形状；用滞回加持续时长条件过滤尖峰。

小结

  • 集成降低的是方差：增益取决于成员误差相关性，多样性比成员数更关键。
  • 多样性来源按成本排序：独立初始化、自举采样、训练轨迹差异、结构差异。
  • 成员分歧是认知不确定性的实用估计，需归一化为相对量并与真实误差校准。
  • 成本回收三层次：加权裁剪成员、快照集成省训练、蒸馏回单模型。
