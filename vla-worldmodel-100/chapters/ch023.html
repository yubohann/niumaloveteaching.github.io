第二篇 · 联合训练进阶与策略能力

第 023 章：VLA策略的模仿学习初始化

强化学习从零探索几乎不可行，专家演示可把策略预热到可用起点；本章讲清行为克隆的分布偏移机理、复合误差的放大规律，以及初始化到联合微调的衔接设计。

  • 主题：模仿学习（Imitation Learning） / 行为克隆（Behavior Cloning, BC）
  • 关键公式：LBC = −E[log πθ(a|s)]；复合误差约 O(εT2)；DAgger 聚合
  • 预计学时：50 分钟
  • 前置章节：第 022 章

学习目标

  • 理解行为克隆（Behavior Cloning, BC）作为初始化手段的角色：为联合训练提供动作分布先验，降低探索难度。
  • 掌握分布偏移（distribution shift）与复合误差（compounding error）的机理，能解释误差随任务步长的 O(εT2) 放大。
  • 掌握数据聚合（DAgger）与噪声注入两类纠正手段的设计要点与代价。
  • 会设计三阶段流程：BC 预训练、世界模型预训练、联合微调，并给出各阶段学习率与参数分组。
  • 能诊断"初始化后指标崩溃"的三种常见原因：学习率过大、动作分布多峰被平均、专家数据覆盖不足。

背景与动机

联合训练的目标是让策略在世界模型中想象、在真实数据上校正。若策略从随机初始化开始，早期动作分布接近噪声：在世界模型里想象出的轨迹毫无结构，奖励预测头与价值头只能拟合噪声，真实环境中探索的代价也不可接受。模仿学习初始化（imitation learning initialization）用专家演示先把策略拉到接近数据分布的起点，之后联合训练只需修正与提升。

行为克隆是最直接的形式：把专家轨迹当作监督数据，最大化专家动作的似然。它的问题在于训练与部署的分布不一致：训练时状态来自专家分布，部署时状态来自策略自身分布，一步偏差把策略推向专家数据未覆盖的状态区域，误差沿任务步长放大，这就是复合误差。

本章位于第 022 章的奖励预测之后：奖励与价值从数据中给出优化方向，模仿初始化决定优化的起点。后续的强化学习集成（037）与模仿强化结合（077 所在篇）都以这里的三阶段衔接为基础。

核心原理

1. 行为克隆的极大似然框架

给定专家数据集 D = {(st, at)}，行为克隆最小化负对数似然：

LBC(θ) = − E(s,a)~D [ log πθ(a | s) ] πθ 为参数化策略；连续动作下对应高斯或混合密度参数化，离散动作下对应交叉熵

高斯参数化下损失退化为加权均方误差，混合密度（Mixture Density Network）或离散分箱可以表示多峰动作分布。动作分块（action chunking）把未来 Hc 步动作作为一个整体预测，Hc 常取 8 至 16，一次前向输出整段动作，降低累计推理次数，同时让专家演示中的时间相关性被直接建模。块长的取值依据是专家演示的时间平滑尺度：演示中一个动作决策的影响通常覆盖 8 到 16 个控制步，块长过短则推理频率高且时间相关性建模弱，过长则序列监督难度上升，动作误差先恶化后波及在线成功率。

三种初始化路线的定位对照见下表：行为克隆数据需求最低但误差随步长平方增长；DAgger 用持续标注把增长降为线性；强化学习不依赖专家分布，但需要可用的奖励与大量交互。三阶段流水线的分工正是先取 BC 的低成本、再用联合微调引入交互信号。

2. 分布偏移与复合误差

设策略在专家状态分布上的单步错误率为 ε。训练时策略只在专家访问过的状态上被监督；部署时策略自身的动作把状态推离专家分布，偏移量随步数累积。误差放大的直觉推导如下：

记第 t 步的状态分布偏移量为 dt ≈ O(ε·t)，则该步错误率约为 ε·(1 + dt)； 累积误差 Σt=1T ε·t = O(εT2) 关键假设：状态分布偏移与已执行步数近似成正比；若策略能自我纠正，增长被抑制

结论：行为克隆的累积误差随任务步长平方增长。这就是长任务上纯 BC 精度急剧恶化的原因。代入数字感受增长速度：ε=0.05 时，T=25、50、100 的累积误差量级分别为 16.25、63.75、252.50，任务长度每翻倍，误差量级翻四倍；同参数下线性界的对应值只有 1.25、2.50、5.00，两条曲线在 T=100 时相差约 50 倍。任务从 25 步延长到 100 步，纯 BC 需要的单步精度要提升约 16 倍才能维持同样的累积误差，这解释了为什么长任务必须引入纠正机制。数据聚合（DAgger）把策略部署时访问到的状态补齐专家标注，使训练分布覆盖部署分布：

Dk+1 = Dk ∪ { (s, π*(s)) : s ~ dπk } dπk 为第 k 轮策略的状态分布；覆盖后累积误差界降为 O(εT)

代价是每轮需要专家在策略访问的状态上给出动作，人工成本随轮数线性增长。替代方案是噪声注入：对专家动作加入扰动构造偏离状态，再附上回到专家的纠正动作，用合成数据近似 DAgger 的覆盖效果。合成量的经验口径：每条专家轨迹生成 2 到 3 条扰动样本，扰动幅度按动作范围的 2% 起步，超过 10% 后偏离状态过于极端、纠正动作的标注质量失真；合成样本与真实标注样本按约 1:1 混合进入 BC 训练，纯合成数据会让动作头对扰动分布过拟合。

3. 从初始化到联合微调

BC 训练出的视觉语言骨干与动作头构成初始参数。联合微调阶段同时更新世界模型与策略，三处衔接设计决定成败：

  • 参数分组学习率：预训练骨干用小学习率（如 5×10−5），新初始化的世界模型解码器用标准学习率（如 2×10−4），保护已学到的表征。
  • 回放比例：微调批次中保留一定比例的专家数据（如 25%），抑制对专家行为的遗忘（catastrophic forgetting）。
  • 动作头对齐：世界模型的动作条件接口需与动作头输出格式一致（维度、归一化范围），否则联合梯度无法正确流经动作通道。

初始化的质量用两个量刻画：专家状态上的动作误差（拟合度）与策略自身访问状态上的动作误差（泛化度）。前者高说明容量或优化不足，后者高说明覆盖不足，两者的修复手段不同。

回放比例的监控阈值给出可执行口径：联合微调开始后，专家回放批次上的动作误差相对预训练末值上升超过 20% 即判定遗忘加速，先把回放比例从 25% 提到 40% 并复查；若提升后仍持续上升，问题出在骨干学习率上，按“预训练越充分、学习率越小”的原则再下调一档。回放误差的采样频率与评估周期对齐，比例调整本身记录进训练日志，避免多因素同时变动导致归因困难。

三阶段的步数分配有经验比例：BC 预训练与联合微调约 1:4，世界模型预训练与 BC 并行进行、共用同一批专家轨迹，不额外占用阶段时长。阶段切换的判据是留出集动作误差连续两个评估周期变化低于 2%，进入平台期即切换；若误差仍在快速下降时提前切换，联合微调会用宝贵的交互数据重复 BC 的工作，整体效率反而下降，且两个阶段的学习率配置需要重新标定。

4. 多峰动作与损失选择

专家演示里存在"绕过障碍可从左或从右"这类多峰情形。均方误差对多峰分布的最优解是各峰的条件均值，恰好落在两个峰之间的低概率区域。三种处理：混合密度头输出 K 个高斯分量；离散动作分箱配交叉熵（与 027 的分箱机制同源）；扩散式动作头对多峰分布建模。选择依据是动作维度与推理预算：分箱只需一次前向，混合密度需要 K 组参数，扩散头需要多步去噪。

参数代价的量级：动作 7 维时，单高斯头每个时刻输出 7 个均值与 7 个方差；混合密度取 K=5 时每个时刻输出 5×(7+7+1) = 75 个参数，接近单高斯的六倍。参数增长不改变推理前向次数，混合密度因此比扩散头更适合实时控制；代价在训练侧，分量数过多时小样本分量容易退化，K 的扫描按专家数据的模式数确定，通常 3 到 5 足够覆盖抓取场景的典型多峰。多峰数据还有一个来源是操作者风格差异：多操作员演示同一任务时，轨迹间的系统性差异会被动作头学成模式，检查手段是按操作员分组报告动作误差，组间差异大时先统一演示规范或标注操作员身份。

实现思路与设计

推荐三阶段流水线，各阶段的产物与目标明确分离。与第 022 章的差异：022 在已可用的策略上补充奖励信号，本章解决策略从不可用状态到可用状态的启动问题。

  1. 阶段一：BC 预训练。数据为专家轨迹，目标为动作似然；训练到专家状态上的动作误差进入平台期。视觉骨干可加载通用预训练权重加速。
  2. 阶段二：世界模型预训练。用同一批轨迹训练动力学预测与奖励/价值头，动作条件通道与阶段一的动作格式保持一致。
  3. 阶段三：联合微调。混合三类批次：专家回放、在线交互、想象 rollout，比例约 2 : 1 : 1；策略与动力学模块差异化学习率。
  4. 评估协议。每阶段固定一组留出初始状态，报告成功率与平均动作误差；联合微调阶段额外报告专家回放批次上的动作误差，监控遗忘。

技巧：用动作块重叠缓解边界突变

动作块预测在块与块衔接处容易出现跳变。执行时采用滑动窗口：每次前向预测 Hc 步，只执行前 k 步（如 k = 4），下一轮以新观测重新预测。重叠执行让衔接点由两次预测的插值覆盖，边界突变显著减少，代价是推理频率提高约 Hc/k 倍。

关键代码与解读

以下片段参照公开的模仿学习与动作分块实现设计，版本中立。PyTorch 风格，接口随版本演进。

片段 1：动作分块的 BC 损失

import torch
import torch.nn.functional as F

def bc_chunk_loss(policy, obs, action_chunk, pad_mask, chunk_len=8):
    """行为克隆：一次预测 H_c 步动作块，按有效步掩码求损失。"""
    # 观测编码与世界模型共享骨干，此处只取策略分支的输出
    feat = policy.encode(obs)                       # [B, D]
    pred = policy.action_head(feat)                 # [B, H_c, A]
    # 序列尾部不足 H_c 步的样本用掩码剔除，避免用零填充训练出停步动作
    diff = (pred - action_chunk)                    # [B, H_c, A]
    # 按 H_c 平均、不求和：块长变化时损失尺度不变，学习率无需重调
    loss = F.smooth_l1_loss(diff, torch.zeros_like(diff),
                            reduction="none").mean(-1)          # [B, H_c]
    loss = (loss * pad_mask).sum() / pad_mask.sum().clamp(min=1.0)
    return loss

def bc_train_step(policy, batch, optimizer):
    loss = bc_chunk_loss(policy, batch["obs"], batch["action"],
                         batch["mask"])
    optimizer.zero_grad()
    loss.backward()
    # 预训练阶段也需要裁剪：演示数据里的异常轨迹会产生尖峰梯度
    torch.nn.utils.clip_grad_norm_(policy.parameters(), max_norm=1.0)
    optimizer.step()
    return float(loss.detach())

解读：（1）平滑 L1 损失对动作异常值比均方误差更稳健，抓取演示中偶发的抖动样本不会主导梯度；（2）掩码按"有效步数求和、总数归一"处理，等价于对每个样本按真实长度求平均；（3）损失按块长平均，块长从 8 改为 16 时损失尺度不变，学习率无需重调；（4）预训练阶段的梯度裁剪防止个别轨迹的尖峰破坏表征学习的稳定性。

片段 2：从预训练切换到联合微调的参数分组

def build_finetune_param_groups(policy, world_model,
                                backbone_lr=5e-5, head_lr=2e-4):
    """联合微调阶段：按模块职能划分学习率，保护预训练表征。"""
    groups = [
        # 预训练骨干：小学习率，允许缓慢适配
        {"params": policy.backbone.parameters(), "lr": backbone_lr},
        # 动作头与策略分支：标准学习率
        {"params": policy.action_head.parameters(), "lr": head_lr},
        # 世界模型新增的解码器：初始化较新，需要更大步长
        {"params": world_model.decoder.parameters(), "lr": head_lr},
        # 世界模型动力学核心：中期学习率，过大会破坏想象稳定性
        {"params": world_model.dynamics.parameters(), "lr": 1e-4},
    ]
    return groups

def build_optimizer(policy, world_model):
    # AdamW 的权重衰减与自适应学习率解耦，适合多模块差异化的场景
    return torch.optim.AdamW(build_finetune_param_groups(policy, world_model),
                             weight_decay=0.01)

解读：（1）参数分组体现"预训练越充分、学习率越小"的原则，骨干承载通用表征，改动过快会破坏视觉语言对齐；（2）世界模型动力学核心给中间档学习率（1×10−4），它既需要适应新数据，又直接决定想象轨迹质量，稳定性要求高于解码头；（3）权重衰减（weight decay）统一设置，不与分组冲突，因为 AdamW 将衰减项与梯度更新解耦；（4）该分组表可直接作为消融实验的对象，验证各阶段学习率设计的必要性。

常见坑

  • 只用成功轨迹训练：策略从未见过如何从失败状态恢复，联合微调时进入偏差状态后无法纠正。修复：采集含恢复行为的演示（人工干预回正的路段），或在 BC 数据中加入从扰动状态出发的纠正片段。
  • 均方误差拟合多峰动作：症状是策略输出恒定在两个模式的中间位置，抓取动作"犹豫不决"。修复：改用混合密度头、离散分箱或扩散头，并检查专家数据的模式数。
  • 联合微调学习率过大：症状是微调开始后专家回放误差迅速上升、在线成功率先升后降。修复：把骨干学习率降到预训练阶段的五分之一以下，提高专家回放比例。
  • 动作格式不对齐：BC 输出归一化动作，而世界模型动作通道按原始物理量训练，联合梯度失效。修复：统一动作归一化约定（如线性映射到 [−1, 1] 并按维度记录量程），在数据加载层做单点转换。
  • 评估只看在线成功率：在线成功率受初始状态采样影响大，掩盖动作误差的恶化。修复：同时报告固定留出集上的动作误差与在线成功率，两者背离时优先排查数据分布问题。

练习与思考

  1. 动作块长度从 8 改为 16，其余不变。预测专家状态上的动作误差与在线成功率的变化趋势，并说明哪一项先恶化、为什么。★
    提示
    块长增大让序列建模更难，动作误差通常先上升；在线成功率因推理次数减半、执行更连贯可能短期持平。块长超过专家演示的时间平滑尺度后，两者同时恶化。
  2. 在放大假设 dt ∝ εt 下推导累积误差 O(εT2)；若策略每步有概率 p 自我纠正（把偏移减半），给出累积误差的新量级估计。★★★
    提示
    未纠正时 dt+1 = dt + O(ε)，求和得 εT2/2 量级。引入纠正后 dt+1 = (1 − p)·dt + O(ε)，偏移收敛到 O(ε/p) 的稳态，累积误差降为 O(εT/p)；DAgger 的效果可视为把 p 提升到接近 1。
  3. 设计 DAgger 协议：给出每轮的部署范围（从哪些初始状态出发）、专家标注量、停止条件，并估计标注量相对首轮行为克隆数据的增量比例。★★
    提示
    每轮从留出初始状态集出发运行当前策略，记录访问状态并请求标注；停止条件可设为在线成功率两轮提升小于阈值；单轮标注量与失败路段长度成正比，一般小于首轮数据的 20%。
  4. 设计与验证"噪声注入"替代方案：给出噪声分布（按维度缩放还是不缩放）、注入位置（观测还是动作）、纠正目标（回到专家动作还是专家轨迹最近点），并写出一条可证伪的预测。★★
    提示
    常见选择为按动作量程逐维缩放的高斯噪声、注入动作通道、纠正目标取专家动作；可证伪预测：注入比例从 0 增到 30% 时，留出扰动状态上的恢复成功率单调上升，超过 50% 后下降。
  5. 三阶段流程中，若把阶段二的动力学预训练去掉直接进入联合微调，预测训练稳定性与最终成功率的变化，并说明用哪个指标最先观察到差异。★★
    提示
    想象 rollout 的早期误差增大，策略更新噪声上升，表现为想象回报曲线抖动；最先观察到差异的指标是想象轨迹的预测误差与策略熵，联合微调的总损失变化反而滞后。

小结

  • 模仿学习初始化用专家演示为联合训练提供动作先验，解决强化学习冷启动的探索困难。
  • 行为克隆的累积误差随任务步长平方增长，根源是训练分布与部署分布的偏移。
  • DAgger 通过覆盖策略访问状态把误差界降为线性，代价是持续的专家标注；噪声注入提供低成本近似。
  • 多峰动作分布需要混合密度、离散分箱或扩散式动作头，均方误差会输出无意义的中间值。
  • 联合微调的关键衔接是差异化学习率、专家回放与动作格式对齐。
