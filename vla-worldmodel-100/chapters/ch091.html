第 091 章：联合训练中的强化学习与规划结合

策略引导搜索、搜索改进策略：PUCT 选择、访问计数蒸馏与 Dyna 式想象数据循环，让世界模型、价值与策略在同一个闭环里互相校准。

  • 主题：联合训练（joint training）/ 强化学习与规划（RL and planning）
  • 关键公式：PUCT 选择与访问计数策略目标
  • 预计学时：55 分钟
  • 前置章节：第 090 章

学习目标

  • 理解强化学习与规划的信号互补性：搜索提供前瞻与样本效率，参数化策略提供直觉与低延迟执行。
  • 掌握 PUCT 选择公式的推导结构，解释探索项中先验与访问计数的分工。
  • 掌握访问计数到策略目标的转换与交叉熵蒸馏，理解摊销（amortization）如何让推理期免于搜索。
  • 会搭建 Dyna 式循环：真实数据与想象数据的混合比例、悲观加权与短 rollout 深度设置。
  • 能诊断模型利用（model exploitation）、策略搜索失配与价值乐观三类故障。

背景与动机

纯强化学习样本效率低，纯规划算力开销大，两者结合让一份数据同时驱动搜索改进与策略更新。在机器人场景中收集真实数据的代价高，世界模型把同一批数据放大为无限次可复用的想象实验；搜索算法（如蒙特卡洛树搜索）用世界模型做前瞻，找到比当前策略更好的动作，这些发现再蒸馏回参数化策略，策略变得更好后又为下一轮搜索提供更准的先验，形成互相改进的循环。

第 014 章介绍了规划与策略结合的基本形态，第 037 章讨论了强化学习组件的集成。本章聚焦两者的深度耦合：搜索与策略互为输入输出的 PUCT 结构、访问计数作为策略目标、以及 Dyna 式数据循环中想象数据的可信度控制。第 089 章的长期规划与本章的高频决策在时间尺度上互补，共用同一套价值头与世界模型。

核心原理

结合的系统由三件套构成：搜索树（PUCT 选择与回传）、策略先验（搜索的输入）、访问计数蒸馏（搜索的输出）。

1. PUCT 选择

蒙特卡洛树搜索（Monte Carlo Tree Search, MCTS）在状态 s 展开候选动作，选择阶段按 PUCT 打分：

U(s, a) = Q(s, a) + cpuct · P(s, a) · √( Σb N(s, b) ) / ( 1 + N(s, a) ) Q 为访问均值价值；P 为策略先验；N 为访问计数；cpuct 控制探索强度

两项分工清晰：Q 项利用已知的好动作，探索项给低访问动作机会。探索项里 P(s, a) 让先验高的动作优先试，√(ΣN)/(1 + N) 随该动作被访问而衰减，访问越多越难再被选中，保证探索预算向未评估的分支倾斜。策略先验的质量直接决定搜索效率：先验接近均匀时，搜索要花大量模拟才能找到好分支；先验准确时，少量模拟即可聚焦。这就是"策略引导搜索"的含义，也是策略改进与搜索质量的正反馈来源。

2. 搜索改进策略：访问计数目标

搜完一轮后，根节点的访问分布包含搜索的全部结论：

πtarget(a) ∝ N(s, a)1/τ τ 为温度；τ = 1 时比例于访问计数，τ 趋于 0 时趋近贪心选择

策略网络以 πtarget 为目标做交叉熵训练，把搜索结论蒸馏进参数：推理时即可免搜索直接推断，或只做浅层搜索。这一机制称为摊销（amortization）：把昂贵的搜索计算分摊到参数里，换取低延迟。蒸馏的步调要与搜索质量匹配：搜索本身依赖策略先验，若在搜索尚未收敛（模拟次数不足）时强行蒸馏，噪声目标会污染策略；常见做法是前若干轮用较大温度（τ = 1）平滑目标，搜索稳定后降到 τ = 0.3 以下提高锐度。

3. Dyna 式数据循环

Dyna 结构把世界模型的想象数据并入训练：从真实数据的潜状态出发，用当前策略在模型内 rollout 若干步，每一步得到预言奖励与下一潜状态，作为训练样本回流到价值与策略更新。想象数据的关键参数有两个：

  • rollout 深度 H：深度越大，时间跨度越远，但模型误差随时间累积（第 084 章的递归界）；常取 5–15 步，价值头从末端状态自举，把误差截断在可控范围内。
  • 可信度权重：模型可能对乐观错误的区域反复利用（模型利用，model exploitation）。加权方案在奖励上施加悲观修正：r̂ = r − β·σensemble，其中 σ 为多模型集成的预测标准差，分歧大的区域自动打折。

真实与想象数据的比例是训练稳定性的旋钮：想象占比过高时策略被模型误差带偏，过低时样本效率优势消失。经验区间为想象数据占 30%–60%，并随训练推进、模型误差下降而逐步提高。

4. 价值乐观与自举

搜索与 Dyna 都依赖价值估计，价值高估会经搜索放大：Q 值高的分支获得更多访问，其自举目标又来自同一个价值函数，形成自我强化。缓解手段：双价值头取较小值、集成悲观下界、对想象分支的价值目标施加折扣衰减（把 γ 调低，缩短有效视野）。价值头在真实数据上做 n 步 TD（第 089 章）保证接地，在想象数据上只做辅助更新并配权重。

实现思路与设计

训练循环为：真实批次更新世界模型与价值 → 想象 rollout 扩充数据 → 搜索生成策略目标 → 策略蒸馏更新。四步共享同一批量数据，节奏按周期交替。

  1. 搜索配置：模拟次数 64，深度 5，动作候选由策略先验取 top-8；搜索在潜空间进行，不渲染观测。
  2. 策略先验：策略头输出动作分布，取对数概率作为 P(s, a)；策略与搜索的动作空间一致（连续动作离散化为 32 个档位，第 027 章方案）。
  3. 蒸馏温度：前 2e4 步 τ = 1 平滑目标，之后线性降到 0.3。
  4. Dyna 混合：想象数据占比从 0.3 升到 0.5；每步奖励施加 β = 0.5 的分歧悲观修正。
  5. 与第 037、014 章的差异：强化学习组件与规划器经访问计数与先验实现双向耦合，不再并列独立；新增可信度控制。

设计决策：搜索与策略为什么互为输入输出？

搜索无先验时退化为盲目枚举，算力开销大；策略无搜索时受限于训练分布，难以在关键分岔处找到更优解。互教结构让两者同时改进：策略给搜索提供高效起点，搜索给策略提供超越自身的监督目标。代价是训练环路复杂，任意环节（先验、价值、模型）的偏差都会经环路放大，需要按组件分别监控。

关键代码与解读

以下片段为 PyTorch 风格示意，接口命名以各开源实现的公开设计为参照，随版本演进可能变化。

片段 1：PUCT 选择与回传

def puct_select(node, c_puct=1.5):
    """PUCT 选择：Q 利用项 + 先验加权的探索项。"""
    sqrt_total = math.sqrt(sum(ch.n for ch in node.children.values()) + 1e-8)
    best_a, best_score = None, -float("inf")
    for a, ch in node.children.items():
        # 探索项随访问次数衰减：低访问动作获得评估机会
        u = c_puct * node.prior[a] * sqrt_total / (1 + ch.n)
        score = ch.q + u
        if score > best_score:
            best_a, best_score = a, score
    return best_a

def backup(path, leaf_value, gamma=0.99):
    """回传：叶子价值沿路径反向传播，节点 Q 用增量均值更新。"""
    g = leaf_value
    for node, action in reversed(path):
        ch = node.children[action]
        ch.n += 1                                # 访问计数累加
        ch.q += (g - ch.q) / ch.n                # 增量均值，等价访问平均
        g = node.reward + gamma * g              # 叠加上一步奖励继续上溯
    return g

解读：探索项的实现与公式逐项对应，sqrt_total 用根到该节点所在层的总访问量近似，工程实现常直接用父节点访问量。1e-8 防止初始时刻除零。回传的增量均值公式 Q ← Q + (G − Q)/N 只需维护 Q 与 N 两个标量，无需保留全部回报样本，这正是树搜索省内存的关键。gamma 与价值头训练时保持一致，否则搜索的折扣口径与自举价值不匹配，Q 值会出现系统性偏移。

片段 2：访问计数蒸馏

def visit_policy_target(root, temperature=1.0):
    """访问计数转策略目标：τ 控制目标的平滑与锐利程度。"""
    counts = {a: ch.n for a, ch in root.children.items() if ch.n > 0}
    total = sum(counts.values())
    if total == 0:
        return None                              # 全部未访问时放弃本次蒸馏
    weights = {a: (n / total) ** (1.0 / temperature) for a, n in counts.items()}
    z = sum(weights.values())
    return {a: w / z for a, w in weights.items()}

def distill_loss(policy_logits, action_ids, target, valid_mask):
    """交叉熵蒸馏：把搜索结论写进策略参数（摊销）。"""
    tgt = torch.zeros_like(policy_logits)
    for a, p in target.items():
        tgt[:, a] = p                            # 连续动作先映射到离散档位
    # 只在有效动作档位上计算：填充档位的目标概率为零
    logp = F.log_softmax(policy_logits, dim=-1)
    return -(tgt * logp * valid_mask).sum(dim=-1).mean()

解读：温度指数作用在归一化后的计数上，τ = 1 与访问占比成正比，τ = 0.3 放大头部差异、接近贪心。全零计数样本直接跳过，避免蒸馏空目标。valid_mask 屏蔽动作空间中的无效档位（例如超出关节限位的档位），防止策略把概率质量分配到物理不可行动作。蒸馏损失与模仿损失可共用同一套动作头，训练时按批交替；若两目标冲突明显，用梯度余弦相似度监控并调整采样比例。

片段 3：Dyna 想象数据的悲观加权

def imagine_batch(world_model, value_fn, policy, z0, depth=8, gamma=0.99, beta=0.5):
    """从真实潜状态出发做想象 rollout，返回悲观修正后的训练样本。"""
    z, samples = z0, []
    with torch.no_grad():
        for k in range(depth):
            a = policy.act(z)                    # 策略在潜空间选动作
            z_next = world_model.step(z, a)
            r = world_model.reward(z, a, z_next)
            # 集成预测分歧作为不确定度：分歧大的区域奖励打折
            std = world_model.ensemble_std(z, a)
            r_eff = r - beta * std
            samples.append((z, a, r_eff, gamma ** k))
            z = z_next
    # 末端价值由价值头自举，把想象误差截断在 depth 之内
    samples.append(("bootstrap", value_fn(z).detach(), 0.0, gamma ** depth))
    return samples

解读：想象数据全程在潜空间生成，不渲染图像，单步成本远低于真实环境交互。r_eff 的悲观修正让模型不确定区域的样本权重降低，是抑制模型利用的第一道闸门；第二道闸门是末端自举，深度之外不再展开，回报由价值头估计。返回的样本含折扣系数 gamma ** k，训练侧按标准 TD 目标组装。policy.act 始终用当前策略采样，保证想象分布与训练分布同步漂移；若用旧策略采样，需要按重要性比校正分布差异。

常见坑

  • 模型利用：搜索/策略反复进入模型预测乐观的区域，真实回报远低于估计。症状是想象回报持续上升而真实评测停滞。修复：集成分歧悲观修正、限制想象数据占比、定期用真实 rollout 校准。
  • 蒸馏过早：搜索模拟次数不足时蒸馏，噪声目标污染策略。症状是策略损失震荡、动作分布抖动。修复：温度前高后低、设置最小模拟次数门槛、按搜索质量分层蒸馏。
  • 先验分布外：策略先验对搜索未探索的分支给出过低概率，搜索被先验锁死。症状是访问分布与先验高度一致，搜索无增益。修复：提高 cpuct、对先验做温度平滑、增加根节点噪声（Dirichlet 扰动）。
  • 价值口径不一致：搜索折扣、价值训练折扣、想象折扣三者不一致，Q 值与自举目标系统性偏移。症状是 Q 值曲线与真实回报长期分离。修复：全链路统一 γ，并在日志中记录各环节的折扣设定。
  • 想象数据比例失控：想象占比过高，训练被模型误差主导。症状是价值函数在真实数据上的 TD 误差上升。修复：设上限并随模型验证误差动态调整，模型误差高时自动降占比。

练习与思考

  1. 分析 PUCT 探索项在 N(s, a) 从 0 增大到很大的过程中的行为，说明它如何从"鼓励尝试"过渡到"让位给 Q 值"。★
    提示
    N = 0 时探索项最大，随 N 增大按 1/(1+N) 衰减；访问足够多后 Q 项主导选择。
  2. 把蒸馏温度从 1.0 改为 0.1，预测策略输出与后续搜索覆盖的变化。★
    提示
    目标趋向单峰，策略变贪心，后续搜索的多样性下降；先验塌缩后容易错过非贪心分支。
  3. 推导访问计数增量均值 Q ← Q + (G − Q)/N 与算术平均的等价性，说明数值稳定性考虑。★★
    提示
    归纳法可证两者恒等；增量形式避免存储历史回报且数值误差不随样本累积。
  4. 设计模型利用检测实验：构造模型在某区域高估回报的场景，验证悲观加权与末端自举各自的作用。★★★
    提示
    人为放大某状态预测奖励，观察策略是否聚集；分别关闭悲观项与自举项对比真实回报曲线。
  5. 设计摊销实验：比较"每步完整搜索""搜索训练、推理免搜索""浅搜索蒸馏"三种配置的决策质量与单步延迟，给出结论模板。★★★
    提示
    质量用真实环境成功率，延迟用分位数；预期完整搜索质量最高、免搜索延迟最低，浅搜索居中。

小结

  • 搜索与策略互为输入输出：先验引导搜索聚焦，访问计数蒸馏让策略吸收搜索结论。
  • PUCT 的探索项用先验加权、按访问次数衰减；回传用增量均值，口径与价值训练一致。
  • Dyna 循环用想象数据扩充训练，深度 5–15、悲观加权与末端自举共同限制模型误差危害。
  • 价值乐观会经搜索放大，需要双头或集成手段抑制；想象数据占比随模型质量动态调整。
