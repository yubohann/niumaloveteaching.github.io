第一篇 · 基础框架与联合训练

第 009 章：联合训练中的梯度流分析

本章从微观视角审视两路训练：梯度在共享结构中的两条路径、干涉程度的余弦度量、展开预测的截断回传，以及停止梯度（Stop-gradient）的正确使用位置。

  • 主题：联合训练 / 梯度流分析
  • 关键公式：g = gwm + λ·gpolicy，cos(gwm, gpolicy) 度量干涉
  • 预计学时：65 分钟
  • 前置章节：第 008 章

学习目标

  • 理解共享结构中两路梯度的合成规则与逐层范数分布。
  • 掌握用余弦相似度量化梯度干涉的方法，能解读冲突、正交、协同三类情形。
  • 理解截断式时间反向传播（Truncated Backpropagation Through Time, TBPTT）的动机与实现要点。
  • 掌握停止梯度的三类正确位置：想象状态、目标网络、历史潜状态。
  • 能搭建梯度诊断工具链：逐层范数、任务间余弦、梯度裁剪与累积次序。

背景与动机

005 章与 007 章从损失值与排班层面控制了联合训练，本章进入更微观的层面：参数收到的梯度到底长什么样。两路损失数值平衡不等于梯度平衡，逐层传播的缩放、激活函数的导数区间、残差与归一化的结构都会改变各层实际收到的梯度范数。只看总损失下降，无法解释“某一层学得快、另一层停滞”的现象。

展开预测加长了梯度路径：m 步展开对应 m 次 Jacobian 连乘，梯度方差随步数增长；想象 rollout 又把策略损失与动力学相连，不控制时策略梯度会沿展开路径改写世界模型。解法是截断回传与停止梯度。

本章定位为工具章：给出诊断方法与切断规则，010 章起持续复用。结论均以可测量的梯度统计量为依据。

核心原理

1. 两路梯度的合成与逐层分布

共享主干参数 ψ 同时接收两个头的回传梯度，合成规则是线性叠加：

gψ = gwm + λ·gpolicy gwm、gpolicy 分别为两路损失对 ψ 的梯度；λ 为策略权重

逐层分布才是诊断重点：不同层对两路任务的需求不同，视觉底层偏预测、动作邻近层偏策略。逐层梯度范数与权重更新范数的比值（有效步长）定位主导方；有效步长长期低于全局中位数十分之一，说明该层近乎冻结，需检查路径切断与尺度失衡。

有效步长用数字示例：学习率 1×10-4、某层梯度范数 0.5 时，每步权重移动约 5×10-5；全局中位数对应范数 2.0 时该层比值为 0.25，属健康区间；比值降到 0.1 对应范数 0.2，按十分之一下限的判据应标记为近乎冻结。注意有效步长要把优化器行为计入：Adam 系列把更新幅度归一到与梯度范数弱相关，观察量应改用更新量范数，直接看梯度范数会得出失真的失衡结论。

线性叠加的后果用一组数字看清：取 ‖gwm‖=2.0、‖gpolicy‖=0.5，合成范数平方为 4 + 0.25 + 2×2.0×0.5×cosψ，ψ 增大时合成范数单调收缩，cosψ=-0.3 时合成范数 1.91，比大范数单路还低约 4.5%。更值得注意的是不对称性：小范数一路只有大范数的四分之一，但 cosψ=-1 时仍把合成范数从 2.0 压到 1.50，削减四分之一。干涉的削减能力由夹角决定，与弱势一路的范数不成比例，因此不能只按损失值判断“哪一路可以忽略”。

2. 梯度干涉的度量

把两路梯度各自展平拼接，计算余弦相似度：

cos(gwm, gpolicy) = ⟨gwm, gpolicy⟩ / (‖gwm‖·‖gpolicy‖) 接近 1 为同向协同；接近 0 为近似正交；显著为负表示更新方向相互抵消

余弦持续为负时两路在共享参数上拉扯，等效学习率下降。处理按代价递增：调 λ（治标）、为冲突层加适配器（隔离容量）、投影式更新（如 PCGrad，把一路梯度投影到另一路的正交补）。先量化再决定，多数场景适配器即可。

投影式更新用二维数字演示完整过程：g1=(1.0, 0.5)、g2=(-1.2, 0.3)，点积 -1.05，余弦约 -0.76，属于强冲突；投影系数 t = (g1·g2)/‖g2‖2 = -1.05/1.53 ≈ -0.686，更新后 g1' = g1 - t·g2 ≈ (0.177, 0.706)，与 g2 的余弦精确为 0，范数从 1.118 降到 0.728，缩小 35%。正交化消除负干涉的代价是削弱本路步长，冲突越强削弱越多，这是投影法必须配合学习率复标定的原因。三种处理手段的对照见下表。

手段额外开销效果适用判据
调 λ无整体减弱弱势一路，冲突未被消除余弦仅轻微为负（如大于 -0.1）
加适配器少量参数与算力为冲突任务隔离容量，主干干涉缓解中层表征冲突持续存在
正交投影每步额外一次向量投影成对梯度的负干涉归零，本路步长被削弱冲突严重（余弦低于 -0.5）

诊断的粒度选择同样关键：全局余弦把各层梯度在展平空间拼接，结果会被参数量最大的层主导。视觉主干通常占共享参数的九成以上，它与预测任务天然协同，全局余弦因此长期为正，掩盖动作邻近层的强冲突。可靠做法是三层视图并列：全局余弦看总体趋势，逐层余弦定位冲突所在，参数量加权平均给出可比总量。冲突定位到具体模块后，适配器与投影按模块施加，避免对全网络做无差别处理。

投影法本身还有两个执行细节。其一，成对投影的结果依赖任务处理顺序，固定顺序会让先处理的梯度持续占据主导，通行做法是每步随机打乱顺序并在多次采样上取平均。其二，任务数为 T 时成对投影共 T(T-1)/2 组，开销随任务数平方上升，冲突诊断把这些算力导向余弦最负的若干任务对即可，无需全量投影。

3. 截断式时间反向传播

m 步预测损失若完整回传，梯度路径长、显存占用大、方差高。截断式回传把展开切成若干段，每段内部正常回传，段边界切断：

∇θL ≈ Σ段 ∇θL段（段内完整回传，段间以 detach 断开） 段长 k 取 4–8；k=m 时退化为完整回传，k=1 时退化为逐段单步

截断的代价是梯度估计有偏，收益是显存与方差的显著下降。段长的选择依据是误差累积速度：预测误差在 k 步内仍小时，段内回传是有效信号；超过该范围后梯度已被噪声主导，切断反而提高信噪比。006 章的视界结论与本章的段长是同一条误差规律在两个环节的体现。

路径长度的影响可以按 Jacobian 谱半径 ρJ 的幂次估算：单步传播系数为 ρJ，m 步连乘为 ρJm。ρJ=0.9 时 8 步系数 0.43、16 步 0.19，远处梯度信息平滑衰减直至被噪声淹没；ρJ=1.1 时 8 步系数 2.14、16 步 4.60，梯度爆炸风险随步数指数放大，梯度裁剪只能压制表面现象。被截断丢弃的依赖占比约等于 ρJk：k=8、ρJ=0.9 时约 43%，k=12 时降到 28%，截断偏差随段长指数减小；段长从 8 提到 12 把偏差压缩约三分之一，显存与方差同步上升，取值即是这条曲线上的折中点。

线性动力学下的截断偏差有闭式可查。取潜状态递推 zt = A·zt-1 + B·at，起点潜状态对第 m 步的影响为 Am，段长 k 之外的依赖整体被丢弃，偏差项正比于 ‖Ak‖。A 的谱半径大于 1 时需要完整回传，因为梯度范数按 ρm 发散，截断在控制偏差的同时也压住了爆炸；谱半径小于 1 时完整回传本身健康，截断的主要收益退化为显存与方差的节省。这段推导给出选段长的流程：先在短展开上估计 A 的谱半径，再按“丢弃占比低于一成”反解 k，最后用显存预算校验可行性。

4. 停止梯度的三类位置

停止梯度（Stop-gradient，代码中的 detach）的作用是切断指定路径的反向传播，同时保留前向数值。三类标准位置：想象状态，策略在想象状态上训练时，状态视为环境常量，策略梯度不回流动力学；目标网络，EMA 副本整体 detach，稳定性由结构保证；历史潜状态，截断回传的段边界，切断更早历史。

反向的规则同样重要：动作路径通常保留梯度，策略需要知道自己动作导致的后果，才能通过动力学学习“动作选择的后果一致性”。判断口诀是“谁被当作环境，谁就被切断”：被切断的一方由自己的损失独立训练，不被另一方的损失改写。切断的显存收益可以直接记账：15 步想象 rollout 配段长 8 时只保留约 8 步的反向图，节点数约为完整回传的 53%，总展开越长节省比例越高。切断同时改变梯度语义：状态作为常量时，策略学到的是“在此状态下该做什么”，状态如何因自己的动作改变不再进入梯度，这一取舍在多步闭环任务中需要用后续动作路径的梯度补偿。

5. 数值精度与累积的影响

两个工程因素影响梯度流。混合精度下小梯度可能下溢，损失缩放（Loss Scaling）补偿；梯度累积（Gradient Accumulation）下裁剪必须在累积后执行，微批上裁剪会改变相对贡献。前者表现为精度间余弦偏差，后者表现为范数与配比不符。

下溢的量级用数字界定：FP16 的最小正规数约 6.1×10-5，最小次正规数约 6.0×10-8，梯度 1×10-8 未缩放时直接归零；乘以缩放因子 216 = 65536 后变为 6.6×10-4，恢复为正规数参与更新，回溯阶段再统一除以缩放因子。判据是“反传前检查梯度绝对量级是否低于最小次正规数”，低于即必须启用缩放。裁剪口径的差异同样可量化：两组参数梯度范数为 5（向量 (3,4)）与 1.414，全局范数 5.196，max_norm=1.0 时全局裁剪让两组同乘 0.192，组间比例保持不变；逐层裁剪把两组分别乘 0.2 与 0.707，比例被改写。任务配比依赖梯度比例关系时只能使用全局裁剪，逐层裁剪适用于按层重置学习速度的场景。

实现思路与设计

诊断工具链分三层：采集层（hooks 记录逐层梯度范数）、分析层（任务间余弦、有效步长、截断统计）、告警层（阈值触发）。工具作为训练循环的可插拔组件，开销控制在每 N 步采样一次的频率。开销本身可以定量核算：采集每一步的梯度范数是 O(参数量) 的归约运算，相对前向与反向的 O(参数量×批次规模) 属于小项；以每 100 步采样一次计，诊断带来的额外计算在千分之一量级，显存只需为被采样层保留梯度副本，按层白名单配置即可。

设计决策：诊断先于修复

冲突、失衡、截断不当都会表现为“某路损失不降”，修法各异。规则是先取三个测量值（两路范数、任务间余弦、逐层有效步长）再选方案，任何修改都要用前后测量对比说明效果。

衔接与差异：005 章在损失层面调平衡，本章在梯度层面验证与补充；007 章的冻结机制以参数为单位，本章的停止梯度以路径为单位，两者可以在同一训练循环中共存；010 章的多模态融合模块会复用本章的诊断工具检查模态间梯度分布。

关键代码与解读

片段以 PyTorch 官方自动微分接口与公开的梯度诊断实践为参照，接口随版本演进。第 1 段给出两路梯度采集与干涉度量。

片段 1：任务梯度采集与余弦度量

import torch
import torch.nn as nn

def task_gradients(loss, shared_params):
    """提取一个任务损失对共享参数的梯度；未触及的参数补零便于拼接。"""
    grads = torch.autograd.grad(loss, shared_params,
                                retain_graph=True, allow_unused=True)
    # allow_unused：冻结或未触达的参数返回 None，补零后形状对齐
    return [g if g is not None else torch.zeros_like(p)
            for g, p in zip(grads, shared_params)]

def grad_cosine(g_wm, g_pol):
    """两路梯度展平后计算余弦相似度：负值表示更新方向相互抵消。"""
    flat_wm = torch.cat([g.flatten() for g in g_wm])
    flat_pol = torch.cat([g.flatten() for g in g_pol])
    # 先做范数检查：任一范数为零时余弦无定义，直接返回零避免异常传播
    if flat_wm.norm() == 0 or flat_pol.norm() == 0:
        return torch.zeros((), device=flat_wm.device)
    return nn.functional.cosine_similarity(flat_wm, flat_pol, dim=0)

解读：（1）两路梯度分别用 autograd.grad 提取；loss.backward 默认在反传后释放计算图，且梯度累加进参数缓存无法单独取回，不适合连续采集。retain_graph 保证第二次调用时计算图仍可用。（2）allow_unused 与补零处理让诊断在冻结、部分路径切断等状态下依然可运行，工具本身不应因训练配置变化而失效。（3）范数为零的兜底是必要的：当某一路损失与共享参数完全无关时，余弦计算的除零会产生 NaN 并污染后续统计。

片段 2：截断式展开回传

def truncated_rollout_loss(world, context, actions, targets, k=8):
    """截断回传：每推进 k 步切断一次历史，梯度路径长度有上界。"""
    z = world.encode(context)              # 起点编码参与回传（编码器可训练）
    total = z.new_zeros(())
    for step, (a, gt) in enumerate(zip(actions, targets)):
        z = world.dynamics(z, a)           # 动力学前推：潜状态携带梯度
        pred = world.decode(z)
        total = total + nn.functional.l1_loss(pred, gt)
        # 每 k 步把潜状态置为常量：梯度最多穿透 k 步，显存只随 k 增长，与总长解耦
        if (step + 1) % k == 0:
            z = z.detach()
    return total / len(actions)

解读：（1）截断周期作用在潜状态上，语义清晰：状态是历史信息的载体，切断状态即切断历史。（2）段内损失仍用完整精度回传，只有跨段路径断开，梯度估计是有偏但方差可控的折中。（3）k 的默认值与 006 章视界同量级：视界决定“生成多远”，段长决定“回传多远”，两者由同一条误差曲线标定。

片段 3：想象监督中的梯度管控

@torch.no_grad()
def imagined_states(world, context, actions):
    """生成策略监督用的想象状态：全程无梯度，状态视为环境常量。"""
    z = world.encode(context)
    states = []
    for a in actions:
        z = world.dynamics(z, a)
        states.append(z)
    return states

def policy_imagination_loss(policy, states, act_targets):
    """在想象状态上监督策略：梯度只流向策略，动力学不被策略损失改写。"""
    total = 0.0
    for z, target in zip(states, act_targets):
        # states 由 no_grad 生成：前向可用、反向断链，谁是环境谁被切断
        pred = policy.decode_action(z)
        total = total + nn.functional.huber_loss(pred, target)
    return total / len(states)

解读：（1）两个函数分工明确：状态生成置于 no_grad，策略损失只处理策略参数，梯度管控由“生成函数无梯度”这一结构事实保证，不依赖调用方自觉。（2）该模式与 007 章交替训练互补：交替训练按阶段隔离，本模式在同一批次内按路径隔离，两者可组合。（3）若研究目标需要策略梯度影响动力学（联合优化动力学以适配策略改进），去掉 no_grad 即可，但必须补上梯度裁剪与干涉诊断。

常见坑

  • 想象状态忘记 detach：策略损失沿展开路径改写世界模型，预测任务验证误差上升。修复：状态生成统一走 no_grad 包装，并用干涉诊断定期抽查。
  • retain_graph 缺失：两路梯度依次提取时第二次调用报错，或回退实现误用 backward 导致梯度被清。修复：诊断代码统一使用 autograd.grad 并显式 retain_graph。
  • 裁剪与累积次序错误：在微批上裁剪改变了各微批贡献比例，等效于加权失衡。修复：累积完成后裁剪一次，并把该次序写入训练循环的断言。
  • 截断点设置错误：detach 位置前移导致梯度穿透不过一步，损失下降停滞。修复：用“单步截断对照”验证：k=1 时梯度只影响最后一步，输出应与理论值一致。
  • 低精度下小梯度下溢：混合精度训练中小梯度归零，层级间学习速度分化。修复：启用动态损失缩放，并在诊断中对比两种精度下的梯度范数。

练习与思考

  1. 两路梯度范数分别为 2.0 与 0.5、余弦为 -0.3，估算合成梯度的范数范围，并说明为什么负余弦会降低等效步长。★
    提示
    合成范数介于 1.5 与 2.5；负余弦使部分分量相消，实际范数偏向下限，等效学习率下降。
  2. 把截断段长 k 从 8 调到 2，预测显存占用与梯度方差的变化，给出验证方法。★
    提示
    显存随 k 近似线性下降，方差降而偏差增；用固定批次梯度方差与预测验证误差联合评估。
  3. 推导：证明停止梯度位置在“被当环境的一方”时，另一方的梯度估计仍可无偏地优化自身目标；若位置写反会发生什么。★★
    提示
    对方参数视为常数时，自身梯度只依赖自身参数，估计无偏；写反则梯度穿过对方参数，目标被改写，出现互改耦合。
  4. 设计梯度干涉的完整诊断流程：采集频率、统计量、告警规则与升级路径，写出关键步骤的顺序。★★
    提示
    采集两路范数、余弦与逐层有效步长；余弦持续为负先查 λ 与适配器，再评估投影法；升级须有前后测量对比。
  5. 构造实验：在同一训练配置下分别启用与停用想象状态的 detach，比较世界模型验证误差与策略成功率的联合变化，解释差异来源。★★★
    提示
    停用后策略梯度改写动力学，预测误差上升、策略短期或改善但迁移变差；该实验直接证明路径隔离的必要性。

小结

  • 两路梯度在共享参数上线性叠加，逐层有效步长是定位失衡的基本测量。
  • 任务间余弦度量干涉：持续负值才需要处理，多数场景用适配器隔离即可。
  • 截断式回传把梯度路径长度控制在段长 k 内，代价是有偏、收益是显存与方差。
  • 停止梯度的口诀：谁被当作环境，谁就被切断；动作路径通常保留梯度。
  • 裁剪在累积后执行，低精度训练配损失缩放，两件事都直接影响梯度流的实际效果。
  • 梯度工具链就位后，进入模块实现：多模态输入融合模块。
