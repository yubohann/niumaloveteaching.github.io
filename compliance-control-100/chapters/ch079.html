第 079 章：导纳控制中的力矩限制

导纳控制器输出的是"运动指令"，但真正干活的是关节电机，运动需求最终要翻译成力矩。本章处理这条链路上最底层的约束：力矩别超，姿态别歪。

  • 主题：安全约束 / 执行器力矩限制与包络
  • 关键公式：τ = Jᵀ·F（虚功原理）；等比缩放 τ' = λ·τ，λ = min(1, τmax/‖τ‖)
  • 预计学时：40 分钟
  • 前置章节：第 078 章（速度限制）

学习目标

  • 理解从"任务空间运动"到"关节力矩"的完整映射链路，知道力矩超限会在哪个环节暴露出来。
  • 掌握力矩-速度包络（torque-speed envelope）的概念：电机高速时可用力矩下降，限制必须随速度变化。
  • 会用整向量等比缩放处理力矩饱和，并解释为什么"分关节独立削顶"会扭曲末端力的方向。
  • 坚守一条工程铁律：限幅只作用于动态/交互力矩，重力补偿通道永远不受限。
  • 会读饱和诊断：从 λ 的时长与分布判断"任务根本不可行"还是"瞬时冲击"。

背景与动机

很多柔顺控制教程只讲到"力 / 位置"就打住了，但真实系统的最后一环是关节电机：它有自己的持续力矩、峰值力矩、以及随转速下降的力矩包络。导纳控制器算出来的运动修正，最终都要由内环（位置环或力矩环）换算成电机电流去执行，如果这一步超了限，行为会以两种方式坏掉：（1）内环静默饱和，机器人"跟踪不上"，导纳设计的柔顺关系不再成立（你以为机器人在让位，其实它僵在原地）；（2）反复撞极限会引发限幅振荡，听起来像关节在"打嗝"。

还有一个容易被忽视的耦合：接触力是通过 Jᵀ 映射到关节的。任务空间里"均匀"的力，在关节空间可能极不均匀，离基座近的关节往往承担数倍于其他关节的力矩。所以"末端力不超过 30 N"和"关节力矩不超过额定值"是两个必须同时校核的约束，本章讲怎么把它们统一处理。

核心原理

1. 映射链：从末端力到关节力矩

由虚功原理，末端力 F 与关节力矩 τ 的对偶关系是：

τ = Jᵀ·F J 为 6×n 雅可比；F 为 6 维力旋量（力+力矩）；τ 为 n 维关节力矩

举个量级感受一下：手臂完全伸展时，末端 20 N 的水平力在肩关节可能对应 20 N × 0.7 m ≈ 14 N·m 的力矩；如果肩关节额定 30 N·m，留给重力补偿与动态需求的余量就只剩一半。这就是为什么 末端力的限制阈值必须与关节力矩预算联合标定，而不能只在任务空间拍脑袋。

2. 力矩-速度包络：限制不是常数

电机的可用力矩不是一个常数：低速段为恒力矩区（受电流/磁饱和限制），高速段进入恒功率区，可用力矩随转速反比下降（τ ∝ P/ω）。安全检查必须使用当前转速下的可用力矩：

τmax(ω) = min( τpeak, Pmax / max(|ω|, ω0) ) ω：关节角速度；ω₀：恒力矩区边界速度；高速时按恒功率降额

柔顺任务里速度不一定高，但"高速重载擦除"这类工艺会同时逼近两个边界，只查力矩常数表会在包络拐点处失效。

3. 等比缩放：保方向的力矩限幅

力矩向量 τ 在 n 维关节空间里。当某些关节触碰上限时，如果分关节独立削顶（np.clip 风格），结果向量的"方向"改变了，映射回任务空间后，末端力的方向被扭曲：想沿法向压 20 N，实际给出的是"法向 15 N + 切向 8 N"，接触质量立刻变差。正确做法与 078 章的速度限制同构：

λ = min(1, mini τmax,i(ωi) / |τi|) ，τ' = λ·τ 取所有关节中最紧的那个比值，统一缩放整个向量，方向完整保留

代价是"一关节饱和、全身降力"：需要 14 N·m 的肩关节只有 10 N·m 可用时，整条手臂的输出能力都被压到 71%。这是正确的代价，因为保持力的方向对接触任务来说，往往比保持幅值更重要（想想打磨：切向偏移会啃伤工件，法向欠一点只是效率低些）。

4. 铁律：重力通道不参与限幅

执行器输出总力矩可以分解为 τ = τgravity + τtask。限幅逻辑只能检查与缩放 τtask（动态与交互部分）。原因很直接：τgravity 是"让机器人悬在当前位置"的物理必需项，把它削掉等于瞬间抽走支撑，机器人会下坠 10–50 mm 再重新找到平衡，这在接触任务里就是压伤工件或触发保护。工程实现上常让重力项走独立通道（前馈直加），任何限幅器都不许碰它。

实现思路与设计

  1. 标定数据表：为每个关节录入 τpeak、τcont（持续值，约 60–70% 峰值）、ω₀、Pmax，并把包络函数实现为一个纯函数（单元测试友好）。
  2. 按周期计算：每个控制周期由动力学模型算 τtask（导纳等效的关节侧力矩 + 交互力矩），再过一遍包络检查与等比缩放。包络随实时 ω 变化。
  3. 诊断三件套：记录 λ、饱和关节集合、饱和持续时长。λ < 1 单次出现＝瞬时冲击；λ < 1 持续 > 200 ms＝任务不可行信号，应回看 Md/Kd 或规划。
  4. 热约束（慢环）：另设一个 1 s 窗口的 RMS 电流/力矩检查（τcont），它的时间尺度比控制周期大三个数量级，用滑动平均实现即可。
  5. 与安全层对接：连续 500 ms 处于深度饱和（λ < 0.5）→ 触发安全层降速/停止（与 098 章衔接），并上报。
设计决策：为什么用"最紧比值"，不让"欠载关节帮忙多出力"？

你可能会想：既然肩上饱和、肘上还有余量，何不让肘部分担、合力方向不变，这其实是力矩分配的优化问题（QP，min‖τ−τdes‖² s.t. 包络约束），在冗余机器人上确实更优。但对"保方向"这一目标，等比缩放是保守且无误伤的答案：它不引入任何分配算法带来的新动态，任何分配失真都会在接触力上显现。工程上先上等比缩放，剩余能力再由 075 章的零空间框架利用，两层解耦，各管各的。

关键代码与解读

片段 1：包络函数与等比缩放

import numpy as np

def torque_envelope(tau, omega, tau_peak, omega0, p_max):
    """逐关节计算当前可用力矩，再返回等比缩放后的力矩与缩放因子。
    假设恒力矩区边界为 omega0，超过后按恒功率降额。"""
    tau = np.asarray(tau, dtype=float)
    w = np.abs(np.asarray(omega, dtype=float))
    # 恒功率区：P/w；加 max(w, 1e-6) 防止零速除零
    tau_cap = np.minimum(tau_peak, p_max / np.maximum(w, 1e-6))
    # 除法只对"有需求"的关节有意义：tau≈0 时比值视为无穷（不成为瓶颈）
    ratio = np.where(np.abs(tau) > 1e-9, tau_cap / (np.abs(tau) + 1e-12), np.inf)
    lam = min(1.0, float(np.min(ratio)))
    return lam * tau, lam, tau_cap

解读：三个实现细节：（1）零速特判用 max(w, 1e-6)，静止时恒功率公式会除零，而物理上静止取"恒力矩区"数值才是对的；（2）比值只对"有需求的关节"计算（np.where），否则一个静止关节会贡献无穷大比值、把 λ 拉回 1，掩盖真正的瓶颈；（3）返回 tau_cap 供诊断，你可以直接看到"此刻哪几个关节在拖后腿"。同时返回 λ，是因为调用方需要它做饱和诊断。

片段 2：任务空间力的关节侧校核（联合标定）

def check_task_force_limit(J, f_task, tau_cap, margin=0.6):
    """给定任务空间力需求与当前雅可比，检查关节侧余量。
    margin=0.6：动态力矩最多用掉可用力矩的 60%。"""
    tau_needed = J.T @ f_task                        # 虚功原理映射
    worst = np.max(np.abs(tau_needed) / (tau_cap * margin))
    ok = worst <= 1.0
    print(f"任务力矩占比最大关节: {worst*100:5.1f}%  "
          f"{'可行' if ok else '超限：降低力目标或改变姿态'}")
    return ok

# 用法：在规划阶段对"典型姿态 + 最大力"预检，把饱和挡在运行之前
# 例：手臂伸展姿态下末端 30 N，映射后某关节需要 16 N·m，
# 而该关节动态可用预算只有 12 N·m → 规划阶段就应把力目标压到 22 N

解读：注意这是在规划阶段使用的检查器：拿最恶劣的预期姿态去算，提前约束力/力矩目标，保证正常工况留有余量（60% 用度），与 076 章"阈值留 1.5 倍余量"的思想一致。运行时的等比缩放只是兜底，功能上它不应该频繁触发。

片段 3：接进导纳回路的完整形态

def admittance_torque_step(dyn, q, dq, f_ext, q_des_fn, dt=1e-3):
    """导纳 + 力矩限幅的关节侧实现骨架（单周期）。"""
    # 1) 导纳生在任务空间产生位置修正，经 IK/微分映射到关节目标
    q_des = q_des_fn(f_ext, q, dq)
    # 2) 内环需要的"动态力矩"（简化：PD + 惯量补偿的教学形式）
    tau_task = dyn.pd_task(q, dq, q_des, dt)

    # 3) 等比缩放：包络随实时速度更新；lambda 进日志
    tau_limited, lam, _ = torque_envelope(
        tau_task, dq, dyn.tau_peak, dyn.omega0, dyn.p_max)

    # 4) 重力前馈独立通道：绝不参与限幅
    tau_cmd = dyn.tau_gravity(q) + tau_limited
    return tau_cmd, lam

解读：最后一行是本章反复强调的铁律的代码化，tau_gravity(q) 在限幅器外面直接相加。真实系统里重力项可能还带摩擦前馈、负载估计（091–093 章），它们都在"不可限"通道。日志里 lam 长期小于 1 的时段，就是你该回去检查参数与规划的时段。

常见坑

  • 把重力补偿限掉：最危险的错误。限幅激活瞬间机器人下坠，接触力冲高，比不限幅更危险。重力项永远独立通道直加。
  • 分关节独立 clip：末端力方向被扭曲，与 078 章分轴限速同源的问题，发生在力空间。永远用等比缩放或 QP 分配。
  • 用常数力矩上限：忽略了恒功率降额，在高速工艺段（如快速擦除）实际可用力矩远低于查表值，表现为"莫名其妙的跟踪失败"。
  • 只看峰值不管 RMS：短时峰值达标但 1 s 均方值超持续额定，会导致电机过热降额（甚至烫损）。慢环 RMS 检查必不可少。
  • 饱和当成调参问题硬扛：λ 长时间 < 0.8 说明任务与硬件不匹配（Md 太小、Kd 太大、姿态太吃亏），继续调控制参数只是在掩盖问题，先改任务或姿态。

练习与思考

  1. 用 2 关节平面臂（J 可直接推出）验证：末端 20 N 竖直力在小臂延展姿态下，肩/肘关节力矩分别是多少？哪个先触限？★
    提示
    平面 2R 臂 L₁=L₂=0.35 m：肩关节力矩 ≈ 20×(0.35+0.35cosθ₂) 量级；θ₂=0（伸直）时最大 ≈14 N·m，肘关节约为一半。数字会告诉你"伸展姿态最费肩"。
  2. 手算包络：τpeak=30 N·m、ω₀=2 rad/s、Pmax=45 W。关节以 5 rad/s 旋转时可用力矩是多少？10 rad/s 呢？★
    提示
    恒功率区 τ=P/ω：5 rad/s → 9 N·m；10 rad/s → 4.5 N·m（下限再受峰值 30 约束，这里不触及）。这就是"高速软脚"的定量含义。
  3. 推导：等比缩放 τ'=λτ 对任务空间力的影响是什么？为什么它"保方向"？请用 τ = JᵀF 与伪逆的关系写出 F' 的表达式。★★
    提示
    F' = (Jᵀ)⁺λτ = λF（在 Jᵀ 行满秩时），因此方向不变、幅值按 λ 缩放，与速度章节的"整向量缩放保方向"是同一定理的两次现身。
  4. 设计一个诊断规则：区分"瞬时冲击"与"任务不可行"的饱和。给出你使用的特征量（λ 的时长分布？饱和关节集合的稳定性？）与阈值，并说明每条规则的误报来源。★★★
    提示
    例如：连续 50 个周期 λ<0.9 且同一个关节始终为瓶颈 → 判"不可行"；λ 突降又 3 个周期内回归 → 判"冲击"。误报来源：高动态任务的合法瞬时饱和、传感器尖峰。
  5. 把"重力项参与限幅"作为故意植入的 bug，推演一个 10 秒的恒力打磨场景中会发生什么（用一阶推理即可）：下坠幅度、力尖峰、保护触发链条。★★★
    提示
    限幅触发→丢重力支撑→下坠 δ≈(g/2)t² 在几个周期内积累到毫米级→接触力尖峰 K_env·δ（K_env=10⁵ 时 1 mm 就是 100 N）→力传感器超量程/触发保护。这条链值得写进团队的安全 review 清单。

小结

  • 映射链：末端力经 τ = JᵀF 进入关节空间；"任务空间均匀"不等于"关节空间均匀"。
  • 力矩限制必须使用速度相关包络 τmax(ω)，恒功率区的降额常被忽略。
  • 限幅用"最紧比值等比缩放"，保方向不扭曲接触力；分关节 clip 是错误做法。
  • 铁律：重力前馈不参与限幅；λ 的时长分布是"任务是否可行"的关键诊断。
