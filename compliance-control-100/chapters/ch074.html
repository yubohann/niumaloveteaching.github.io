第四篇 · 高级柔顺任务与约束

第 074 章：阻抗控制中的奇异值分解

把雅可比拆成"三个方向尺度的组合"：奇异值告诉你哪里跑得快、哪里压得狠、哪里又慢又糊；刚度、速度、阻尼因子都跟着它调度。

  • 主题：SVD / 奇异位形 / 方向调度
  • 关键公式：J = UΣVT；σ̃i = σi/(σi2+λ2)
  • 预计学时：55 分钟
  • 前置章节：第 073 章

学习目标

  • 会解释奇异值分解 J = UΣVT 的物理含义：U 里的方向是末端的"运动/受力主方向"，σ 是各方向的增益。
  • 理解速度椭球（轴 σi）与力椭球（轴 1/σi）的对偶关系：弱方向"跑不动但压得狠"。
  • 会用 SVD 直接写出阻尼伪逆（σ̃ = σ/(σ²+λ²)），并按最小奇异值调度 λ 与速度缩放。
  • 会把阻抗刚度在 SVD 主方向上整形：弱方向软下来，避免"力控不精"变成"力控不稳"。
  • 会监控可操作度 w = Πσi 与条件数，并把它们变成 λ、速度、力限幅三类调度动作。
  • 知道刚度矩阵自身的特征分解与 SVD 的关系（对称正定时二者一致），会用它校验 K 的方向设计。

背景与动机

第 073 章用阻尼伪逆"压住"了奇异附近的速度爆炸，但那是事后补救。真正理解奇异要回到雅可比的骨架：奇异值分解。它把末端空间切成几个正交主方向，每个方向配一个增益 σi，σ 大，方向灵活；σ 小，方向"僵"。六轴以上机械臂在完全伸展、腕部对齐、肩腕奇异线等位形附近，总有一两个方向掉进"僵"的状态。

对柔顺控制来说，奇异位形的问题不在"能不能控"，而在"在那个方向上你的力与运动能力完全不对称"：跑不动，但压得住；而且力控精度极差（关节侧的一点点噪声会被放大成大的末端力误差）。本章的目标是把这种不对称翻译成三组可执行的调度，速度缩放、刚度整形、力限幅，让阻抗控制器在接近奇异时"自觉地变温柔"。

核心原理

1. SVD 的物理图像：三个尺度、两组方向

J = U Σ VT， σ1 ≥ σ2 ≥ … ≥ σm ≥ 0 U：末端空间正交方向；V：关节空间正交方向；Σ：对角增益（m×n 时取前 m 个）

读法：把关节速度取成 V 的某一列 vi，末端速度就是 σi·ui，σi 是"单位关节速度能换来的末端速度"，单位是无量纲（或 m/rad 归一后）。数值例：7 轴臂在接近奇异处可能出现 σ = [1.5, 1.2, 0.8, 0.45, 0.15, 0.06]：沿 u6 方向想得到 1 m/s 的末端速度，需要 1/0.06 ≈ 16.7 rad/s 的关节速度，超过大多数关节上限，这就是"跑不动"。从 q̇ = VΣ−1UTẋ 的形式也能看出：σ 小的方向，逆映射里是 1/σ，爆炸正是从这来的。

2. 两个椭球：弱方向的"跑不动"与"压得狠"

把雅可比与转置成对来读，是本章最重要的一步：

速度：‖q̇‖=1 时 ẋ 沿 ui 的最大值 = σi（速度椭球轴 σi）
力：τ = JTF；沿 ui 的 F 所需关节力矩‖τ‖ = σi·F（力椭球轴 1/σi） 两椭球互为倒数：σ 小 = 移动弱 + 以同等力矩能顶住的力更大

两个推论直接改变柔顺策略：（1）力"报不准"，用最小二乘从关节力矩反推末端力时，沿 ui 的力估计增益是 1/σi：关节侧 0.05 N·m 的噪声在 σ = 0.06 方向上放大成约 0.8 N 的虚假力；阻抗若对这个方向也"认真响应"，控制指令里全是噪声。反过来说，（2）力"压得住"，在奇异方向上机器人像一根柱子，顶得很稳，力峰值能力更高。所以奇异方向的正确用法是：可以压、但别想又快又准地调力，其刚度与带宽都应降到该方向的"可信带宽"内。

3. 用 SVD 写阻尼伪逆与调度

有了 SVD，阻尼伪逆不用矩阵求逆，直接对每个奇异值做滤波：

J⁺λ = V Σ̃ UT， σ̃i = σi/(σi2 + λ2) λ = 0 时退化为精确伪逆；σ≫λ 时 σ̃ ≈ 1/σ；σ≪λ 时 σ̃ ≈ σ/λ2（被截断）

调度规律：λ 按最小奇异值给，常用的软切换是 λ = λ0√(max(0, 1 − σmin2/σth2))：σmin 远离阈值时 λ = 0（精确跟踪），逼近阈值时 λ 升至 λ0（强截断）。别小看这条式子，它把 ch073 里"要不要阻尼、阻尼多大"的工程直觉变成了连续函数。同时给两类派生量做联动：速度缩放 sv = min(1, σmin/σth)（慢下来给关节速度留余量）与力限幅 Fmax = F0·(σmin/σth)（弱方向的力控不可信，限住它）。工程直觉：接近奇异时你要做的是"三降"，降速度、降刚度、降力限；加大增益硬顶只会把失稳风险放大。

4. 刚度矩阵自身的特征分解

任务空间的刚度 Kd 总是做成对称阵，其 SVD 与特征分解一致：Kd = QΛQT，Λ 是六个主刚度，Q 的列是"最硬/最软方向"。校验两件事：（1）方向，Q 的列是否与任务帧（ch064）、SVD 主方向（本章）或工具轴预期的方向对齐（取决于你的设计来源）；（2）条件数，Λmax/Λmin 超过 103 时，力的方向分配会异常尖锐，任何小的坐标系误差都会把大刚度"歪"到不该管的方向上。把 SVD 主方向与刚度主方向并列打印出来对照，是排查"力控偏心"问题最快的方法。

三类信息一表汇总：σi 管末端能力，Λ 管你的设计刚度，二者对齐程度决定效果。比如把 Kd 的软方向设成 u6（弱轴）：沿它受力时机器人让位最多（软），而该方向本来就跑不动，所以"软"不会导致失控；如果反过来在 u6 上做大刚度，那么任何位置误差都会在弱方向上生成嘎吱作响的巨大力，真正的"拧着劲"。

实现思路与设计

  1. 每个周期算一次 SVD：J 是 6×n，SVD 成本在 1 kHz 下可接受；只要 σmin、σmax、U 的前几列与 w = Πσi。
  2. 调度三件套：λ(σmin)、速度缩放 sv、力限幅 Fmax，同一份 σ 数据源，保证三个动作相位一致。
  3. 刚度整形：由任务刚度 Ktask 先建主方向刚度，再按 ki ← ki·clip(σi/σth, β, 1) 在弱方向降下来（β 取 0.3–0.5 的降幅下限，别降到 0）。
  4. 健康监控：每 100 ms 打印 σmin、条件数、w、当前 λ 与缩放系数；任一越限报警并列动作。
  5. 任务级兜底：σmin < 0.02 时冻结任务的力控制通道（进入"保持"），同时启用零空间机动（抬肘离开奇异）。
  6. 验证：沿一条经过肩部奇异的直线运动，记录 λ、sv、末端速度误差与关节速度峰值，确认"关节不爆、末端误差可控"。

数字起点：λ0 = 0.08、σth = 0.15、β = 0.4；w 的参考值取"位形良好时"的 60%。

关键代码与解读

片段 1：SVD 分解 + 三件套调度

import numpy as np

def singular_health(J, lam0=0.08, sigma_th=0.15, beta=0.4):
    """一次 SVD，产出：阻尼伪逆所需的 sigma 列、lambda、速度缩放、力限幅系数。"""
    U, s, Vt = np.linalg.svd(J, full_matrices=False)
    smin, smax = s[-1], s[0]
    # lambda 软切换：smin 远离阈值时 0（精确），逼近阈值时升到 lam0（强截断）
    ratio = min(1.0, smin / sigma_th)
    lam = lam0 * np.sqrt(max(0.0, 1.0 - ratio ** 2))
    scale_v = ratio                      # 速度缩放：慢下来，给关节速度留余量
    scale_f = max(beta, ratio)           # 力限幅系数：弱方向力控不可信，限住
    w = float(np.prod(s))                # 可操作度：全局健康指标
    cond = smax / max(smin, 1e-9)        # 条件数：>1e3 时刚度方向分配变得敏感
    return U, s, Vt, dict(lam=lam, scale_v=scale_v, scale_f=scale_f, w=w,
                          cond=cond, smin=smin)

def svd_dls(J, lam):
    """由 SVD 直接构造阻尼伪逆：V * diag(s/(s^2+lam^2)) * U^T。"""
    U, s, Vt = np.linalg.svd(J, full_matrices=False)
    s_tilde = s / (s ** 2 + lam ** 2)
    return Vt.T @ np.diag(s_tilde) @ U.T

解读：把 svd_dls 和 singular_health 分开，是为了让"每周期都算的分解"只做一次、两个用途共享（工程上 SVD 的 90% 成本是分解本身，别重复算）。三个调度量都从 smin/sigma_th 的同一个比值派生，保证速度、力限、阻尼的动作同步，它们若各用各的阈值，会出现"速度已经怕了、阻尼还没上"的错拍，末端在奇异入口能感觉到一次可辨的顿挫。数值体验：σ = [1.5, 1.2, 0.8, 0.45, 0.15, 0.06] 时 ratio = 0.4，λ ≈ 0.073、速度缩到 40%、力限 0.4 倍，这正是"三降"。

片段 2：SVD 主方向上的刚度整形

def shape_stiffness(K_task, J, sigma_th=0.15, beta=0.4, alpha=1.0):
    """把任务刚度沿奇异方向整形：弱方向按 (sigma/sigma_th)^alpha 降下来。"""
    U, s, _ = np.linalg.svd(J, full_matrices=False)
    # 把 K_task 投影到 U 的主方向：对角元就是各方向的等效刚度（近似）
    K_diag = np.diag(U.T @ K_task @ U)
    w_i = np.clip((s / sigma_th) ** alpha, beta, 1.0)   # 每个方向的保留系数
    K_shaped = U @ np.diag(K_diag * w_i) @ U.T
    # 整形后仍是"旋转后的对角阵"：对称性由构造保证，正定性由 w_i>0 保证
    return K_shaped, K_diag, w_i

# 演示：弱方向刚度被压低、强方向保持
K_task = np.diag([800., 800., 1200., 20., 20., 8.])
rng = np.random.default_rng(1)
J = rng.normal(size=(6, 6)) / 3.0
U, s, _ = np.linalg.svd(J, full_matrices=False)
K_sh, diag_before, w_i = shape_stiffness(K_task, J)
print("奇异值:", np.round(s, 3))
print("保留系数:", np.round(w_i, 2))
print("整形前后平移主刚度:", np.round(diag_before[:3], 1), "->",
      np.round(np.diag(U.T @ K_sh @ U)[:3], 1))

解读：这段代码把一个容易做错的事情做简单了，"沿奇异方向调刚度"听起来要重新设计整个矩阵，实际上只要把 K 旋到 U 的坐标系、按 wi 缩放对角元、再转回来。注意 K_diag = diag(Uᵀ K U) 用的是"取对角近似"：K 的主轴通常与 U 不严格对齐，交叉项被忽略了。这在教学演示里无害，工程上如果交叉项本来很大（比如你精心设计过柔顺中心），应先决定谁是主设计意图，RCC 类任务以柔顺中心优先，奇异调度只作用于"未耦合的刚度主方向"上，别让两个设计互相拆台。beta 下限 0.4 的意义：完全把弱方向放到 0 刚度，机器人会变成该方向的"自由漂浮"，接触瞬间毫无抵抗力；保留 40% 让软而不失底。

片段 3：健康监控与降级状态机

class SingularityMonitor:
    """把 sigma_min 变成四级状态：正常/注意/降级/保持。"""
    def __init__(self, sigma_th=0.15, f0=20.0):
        self.sigma_th, self.F0 = sigma_th, f0
        self.level = "normal"

    def update(self, health):
        smin = health["smin"]
        if smin > 0.6 * self.sigma_th:
            self.level = "normal"
        elif smin > 0.3 * self.sigma_th:
            self.level = "caution"         # 开始降速降力，刚度整形介入
        elif smin > 0.1 * self.sigma_th:
            self.level = "degraded"        # 力通道半增益，零空间开始抬肘机动
        else:
            self.level = "hold"            # 冻结力控、保持姿态并上报
        action = {
            "normal":   dict(v_scale=1.0, f_scale=1.0, null_hint=0.0),
            "caution":  dict(v_scale=0.6, f_scale=0.8, null_hint=0.3),
            "degraded": dict(v_scale=0.3, f_scale=0.4, null_hint=1.0),
            "hold":     dict(v_scale=0.0, f_scale=0.0, null_hint=1.0),
        }[self.level]
        # 迟滞：升级立即、降级延迟（防止在边界抖动时反复切换）
        return self.level, action

mon = SingularityMonitor()
for smin in (0.30, 0.12, 0.06, 0.03, 0.02, 0.08, 0.20):
    U = None
    health = dict(smin=smin)
    lvl, act = mon.update(health)
    print(f"sigma_min={smin:4.2f} -> {lvl:9s} v_scale={act['v_scale']:.1f} "
          f"f_scale={act['f_scale']:.1f}")

解读：状态机的四个档位对应四组动作，输出的 null_hint 表示"让零空间接管多少"，恰好衔接 ch073 的通道。三个工程要点：其一，采用离散档位，是因为"降级"往往要伴随人机界面提示与日志，档位化便于追溯；其二，注释里写了"升级立即、降级延迟"的原则，示例代码为了简洁没实现迟滞计数器，真实实现请加 0.3–0.5 s 的降级确认时间，否则 σmin 在阈值附近的噪声会让机器人反复进入/退出一类保护动作，用户看到的是一顿一顿的行为；其三，最后一行的 U = None 是演示用占位行，请在真实代码中删除，保留未使用变量是可靠性评审里最常见的低级问题。

常见坑

  • 只在奇异时才做 SVD：等 σmin 报警才开始调度，动作滞后。修复：每个周期都算（或节流到每 10–20 ms 一次，配合插值），让调度量连续可用。
  • 把 U 的列序当固定：SVD 的列序由奇异值排序保证，σ 交换时"第 6 列"会变成另一个方向，按列号引用的调度会错乱。修复：按奇异值索引（σi 与 ui 成对），或对 U 做符号规范化（保证跨周期连续：与本周期上一拍的 U 做 SVD 对齐）。
  • 弱方向的刚度削到零：觉得"跑不动不如不管"，结果该方向完全自由，接触瞬间"打滑让位"过大。修复：保留 β = 0.3–0.5 的下限刚度。
  • 条件数忽然变差仍按老刚度：K 的主方向与 U 失配时，弱方向的实际受力远大于设计，位置误差被放大成巨力。修复：健康监控里加一条"K 主方向与 U 的夹角 > 30° 告警"，必要时把 K 旋到 U 之前先经过任务帧过滤。
  • 忘记力估计的噪声增益：在弱方向上按"正常带宽"做力的微分/积分，1/σ 的噪声放大直接让指令抖动。修复：力通道低通截止与 σmin 联动（σ 越小带宽越低）。

练习与思考

  1. 说明：对 J = UΣVT，为什么沿 ui 方向顶住力 F 所需的关节力矩是 σiF？它与量 F/σi 各自描述什么？（提示：从 τ = JTF 出发。） ★
    提示
    JTui = σivi；同时注意"以有界关节力矩能顶住的最大力"是 1/σi·‖τ‖，两个事实合起来解释"压得狠但控不准"。
  2. 算例：σ = [2.0, 1.0, 0.6, 0.3, 0.1, 0.04]，λ0 = 0.1、σth = 0.2：计算 σ̃i 六个值，并指出哪个方向的"速度增益"被 λ 削得最多。 ★★
    提示
    σ̃ = σ/(σ²+λ²)：σ = 0.04 时 σ̃ ≈ 0.04/(0.0016+σ_th 对应的 λ²)，注意先由 σmin 算 λ，再逐通道计算。
  3. 实验：沿一条穿过腕部奇异的直线做 0.05 m/s 的接触运动，分别在"无调度"与"三件套调度"下记录关节速度峰值、末端速度误差与接触力波动，列表比较。 ★★
    提示
    无调度时关节速度峰值与力波动都会明显放大；调度后应有"慢而稳"的过渡段，牺牲速度换安全，正是设计意图。
  4. 设计：某任务要求经过肩奇异区域时接触力不超过 25 N、末端速度不超过 0.08 m/s。给出 σth、λ0、β、F0 与监控档位的完整参数组，并写出你的验证流程。 ★★★
    提示
    F0 取 25 N 略留余量；速度上限由 sv(σmin) 连续缩放保证；验证用"奇异扫掠 + 力阶跃"两种激励。
  5. 思考题：为什么接近奇异时应当降刚度，升刚度会发生什么？结合"弱方向位置误差被放大成力"与"力估计噪声增益 1/σ"两点各写一句。 ★★
    提示
    大刚度在弱方向把本已不准的位置/力信息放大成巨大的错误力；小刚度让系统"听不清就不表态"，稳定性更好。

小结

  • J = UΣVT 把末端空间分成主方向：σi 是"单位关节速度换来的末端速度"，1/σi 是逆映射的爆炸源。
  • 速度椭球轴 σi、力椭球轴 1/σi：弱方向跑不动但压得狠，且力估计噪声被放大 1/σ，"能压不能精调"。
  • SVD 直接给出阻尼伪逆 σ̃ = σ/(σ²+λ²)，λ 按 σmin 软切换；速度缩放与力限幅同源调度，保证动作同步。
  • 刚度按主方向整形：ki ← ki·clip(σi/σth, β, 1)，保留 30–50% 下限；K 自身的特征分解用于校验方向与条件数。
  • 四级健康状态机（正常/注意/降级/保持）把 σmin 翻译成可追溯的动作与告警。
  • 下一章把"多层目标"正式化：任务优先级，同一时刻多个期望互相冲突时，谁让谁。
