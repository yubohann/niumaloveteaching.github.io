第 087 章：导纳控制中的动态面控制

反步法每多一层就要对虚拟控制求一次导，噪声和阶数一起爆炸。动态面控制（DSC）用一只一阶低通滤波器顶替解析求导：滤波器的输出及其"自带导数"都是代数运算，从此层数随便加。代价是稳定性从渐近降级为实用稳定，误差球的大小正比于滤波时间常数。

  • 主题：动态面控制（dynamic surface control, DSC）
  • 关键公式：τfα̇f + αf = α，α̇f = (α − αf)/τf
  • 预计学时：60 分钟
  • 前置章节：第 086 章

学习目标

  • 能说清"微分爆炸"为什么发生：反步第 k 层需要第 k−1 层虚拟控制的时间导数，阶数越高、噪声放大越严重。
  • 掌握 DSC 的核心替换：把 α̇ 换成滤波器状态导数 α̇f = (α − αf)/τf，整个控制律里不再有任何数值微分。
  • 会推导含滤波误差 y = αf − α 的李雅普诺夫函数，理解"半全局实用稳定"的含义与误差球 −y²/τf + |y||α̇| 的来源。
  • 会用偏置公式 ebias ≈ τf·|α̇|max 与截止频率 1/(2πτf) 选择滤波时间常数。
  • 能设计"导纳外环 + DSC 内环"的两层结构，并在二阶与三阶（含电机动态）情形下说明 DSC 的收益差异。

背景与动机

上一章的反步法有一处"隐雷"：控制律里的 α̇1 需要虚拟控制的导数。对二阶系统，我们用速度测量和阻抗模型的解析量把它算干净了；但如果被控对象再多一层，最典型的是电机电流环或柔性关节，第三层就需要 α̇2，其中必然出现信号的高阶导数。导数运算在数字系统里等于"拿噪声乘以 1/Δt"：1 ms 采样下，0.5 mm 的位置噪声经一次差分变成 0.5 m/s，再差一次就是 500 m/s²，直接淹没真实信号。

动态面控制（dynamic surface control, DSC）的方案出奇地简单：不让虚拟控制 α 进入求导通道，改为让它先过一只一阶低通变成 αf；控制律里需要 α̇ 的地方，用滤波器自己"送"出来的 α̇f = (α − αf)/τf 代替。低通的存在让 αf 平滑、可微，也让噪声在进入控制律之前被衰减。换来的代价是滤波误差 y = αf − α 必须当作新的误差对待：它带来一个与 τf 成正比的跟踪偏置，使稳定性从"渐近收敛"降级为"收敛到一个可计算的小球"。

导纳控制为什么需要 DSC？因为导纳外环生成的参考本身就是"被力噪声驱动"的信号：xr(t) 里含着传感器噪声与接触瞬态。内环如果对这些参考做微分，等于把噪声请进力矩回路。DSC 把"参考滤波"和"虚拟控制滤波"统一成一套滤波器组，是导纳—位置内环接口上最自然的工程解法。

核心原理

1. 微分爆炸：问题到底出在哪一层

回顾反步法的两层推导：第一层虚拟控制 α1 = ẋd − c1e1；第二层需要

α̇1 = ẍd − c1ė1，ė1 = ẋ − ẋd 目前为止只用一阶信息：ẍd（解析）与速度测量

对二阶系统，这就是全部；没有真正意义上的"微分"。但把电机动态加进来，系统变成三阶（位置—速度—电动力矩），第三层会要求 α̇2，而 α2 里含 α̇1 的组合，于是需要 α̈1 = ẍ̈d − c1ė̈1，对速度再求一次导，意味着对位置做二阶差分。阶数每加一层，噪声就被 Δt−1 再放大一次，这在工程上不可接受。这不是数学技巧问题，是物理现实：数字信号的高阶导数本质不可用。

2. DSC 的核心替换：让滤波器替你求导

引入一阶低通滤波器，输入是虚拟控制 α，输出为 αf：

τf·α̇f + αf = α，αf(0) = α(0) τf：滤波时间常数（s）；α 是"想跟踪的虚拟控制"，αf 是"实际使用的版本"

关键观察，把方程移项：

α̇f = (α − αf)/τf 滤波输出的导数 = 两个已测量（或已计算）量之差的代数组合：不再需要任何差分

控制律把 α̇1 换成 α̇f1，把 e2 = ẋ − α1 换成 e2 = ẋ − αf1（用滤波后的虚拟控制做误差），就得到了 DSC 控制律。工程直觉：DSC 相当于给每一层楼梯装一个"缓冲垫"，你不再要求执行层立刻实现虚拟控制，只要求它跟上一个"稍慢半拍但平滑"的版本；缓冲垫的厚度就是 τf，代价是压不掉的滞后。

3. 滤波误差的动态：偏置从哪来、怎么被约束

定义滤波误差 y = αf − α。对它求导并代入滤波器方程：

τf·ẏ = α − αf − τf·α̇ = −y − τf·α̇ y·ẏ = −y²/τf − y·α̇

把 y 纳入李雅普诺夫函数 V = ½e12 + ½e22 + ½y2（以单位质量归一化示意），其中 e2 的定义已改为 ẋ − αf。推导后你会得到三项结构：

V̇ ≤ −c1e12 − c2e22 − y2/τf + |y|·|α̇|max + 交叉项 |α̇|max 在状态有界的紧集上有界（±c1、e1、xd 的高阶项共同决定）

对最后的正项用配方法（完全平方）：|y||α̇|max ≤ y²/τf + τf·|α̇|max2/4，于是 V̇ ≤ −c1e12 − c2e22 + τf|α̇|max2/4。这说明状态收敛到一个半径为 O(√(τf)) 的球，这就是 DSC 的"实用稳定"（practical stability）：收敛目标是由 τf 指定大小的残差球，并不收敛到零。同时论证依赖"|α̇| 有界"，而有界性只在状态进入紧集后才成立，所以严格说叫半全局实用稳定，对工程而言，这个承诺已经足够：球足够小就行。

4. 取舍与"比反步多出来的东西"

τf 的两端都难走：τf 太小，滤波器几乎不放水，噪声照旧钻进控制律，退化成"加了个寂寞的反步"；τf 太大，滤波滞后变大，跟踪偏置按 ebias ≈ τf·|α̇|max 线性增长，还会和导纳外环的动力学耦合出新的振荡模态。实用的选择流程：先由"允许偏置"反推 τf ≤ eallow/|α̇|max，再由"信号带宽"确认截止频率 1/(2πτf) 高于你最关心的动态频率（导纳带宽的 2–3 倍）。

相比反步法，DSC 多出来的东西是"可扩展性"：三阶、四阶被控对象只是多串几只滤波器，全部是代数运算，计算量线性增长，而且噪声不会随层数恶化。它丢掉的是"严格最优"：残差球与滤波器偏置是硬性下限，不像反步那样理论上可以压到零。与滑模相比，DSC 依然是连续控制律，没有 sat/sgn 的抖振，因此更适合"安静"的柔顺任务。三者的定位可以记成一句话：反步法最精确但层数有限；DSC 用一点精度换任意层数与噪声鲁棒；滑模用抖振换不确定性的不敏感性。

实现思路与设计

  1. 梳理层数：一维任务轴 + 理想力矩源（二阶）：反步两层就够，DSC 主要用来滤参考与噪声；含电机动态（三阶）：从速度层开始每层一只滤波器。
  2. 先滤参考、再滤虚拟控制：导纳外环输出的 xr、ẋr 先过 20–50 Hz 单边滤波；每层虚拟控制 αi 过 τfi 滤波，注意保持"层与层的滤波时间常数递减"（外层慢、内层快），如 τf1 = 20 ms、τf2 = 10 ms。
  3. 控制律改用滤波量：ei 用滤波后的 αf,i−1 定义；导数项统一写 α̇f,i = (αi − αf,i)/τf,i，代码里绝不允许出现 np.diff 或手动差分。
  4. 增益与偏置核算：c1 = 15–30 s−1、c2 = 30–60 N·s/m；用 ebias = τf·|α̇|max 预估偏置（例：τf = 10 ms、|α̇| ≈ 20 m/s²，偏置约 0.2 mm）。
  5. 频域检查：确认滤波截止频率 1/(2πτf) 高于需要保留的动态（导纳带宽 3–10 Hz）的 2–3 倍，又低于噪声主频段。
  6. 限幅与监控：力矩限幅照旧；监控滤波误差 y = αf − α 的幅值，若长期大于预估偏置的 3 倍，说明 τf 太大或参考过冲。
设计决策：DSC 与普通"信号低通"有什么本质区别？

普通低通只是事后修修补补；DSC 把滤波误差 y 写进了李雅普诺夫函数，证明里明确知道"自己在哪偏了、偏多少有界"。这带来两个工程好处：（1）偏置有公式可算，选 τf 时有数可依，不必靠"滤到看起来顺滑为止"；（2）多级滤波的稳定性是整体论证的，不会出现"这级滤得很干净、下级的相位却被抽走"的隐性失稳。代价是把"渐近稳定"换成"实用稳定"，如果你的任务精度要求逼近残差球的下界（比如 0.1 mm 级），就该减少层数或回到解析求导。

关键代码与解读

片段 1：一阶滤波元件与 DSC 控制律

import numpy as np

class FirstOrderFilter:
    """DSC 的核心元件：一阶低通，替代虚拟控制的解析求导。"""
    def __init__(self, tau_f=0.01):
        self.tau_f = tau_f    # 时间常数：偏置 tau_f*|alpha_dot| vs 噪声衰减的折中
        self.y = 0.0          # 滤波器状态（输出 alpha_f）

    def step(self, target, dt):
        # 离散实现：y += (target - y)*dt/tau_f（半隐式，dt << tau_f 时稳定）
        self.y += (target - self.y) * dt / self.tau_f
        # 滤波器输出的导数由代数关系直接给出，这正是 DSC 免去微分的关键
        return self.y, (target - self.y) / self.tau_f


class DSCInnerLoop:
    """导纳内环：两层 DSC，跟踪 (x_r, dx_r, ddx_r)。"""
    def __init__(self, c1=25.0, c2=40.0, m_hat=2.0, tau_f=0.01):
        self.c1, self.c2, self.m_hat = c1, c2, m_hat
        self.f1 = FirstOrderFilter(tau_f)     # 第一层虚拟控制的滤波器

    def control(self, x, v, x_d, dx_d, ddx_d, dt):
        e1 = x - x_d
        alpha1 = dx_d - self.c1 * e1          # 虚拟控制：期望速度（未滤波）
        a1f, a1f_dot = self.f1.step(alpha1, dt)  # 滤波版本 + 它的"免费导数"
        e2 = v - a1f                           # 误差基于滤波后的虚拟控制
        # 控制律：不再需要 alpha1 的解析导数，全部用滤波器的代数输出
        u = self.m_hat * a1f_dot - e1 - self.c2 * e2
        return float(u), e1, e2, (a1f - alpha1)

解读：与第 086 章的反步控制律对比，唯一的变化是把 alpha_dot 换成了 a1f_dot、把 e2 的基准从 alpha 换成 a1f，替换点极小，收益极大。请特别注意：a1f_dot = (target − y)/τ_f 是滤波器方程移项的结果，不需要对任何信号做差分；返回的滤波误差 a1f - alpha1 用于监控偏置是否超出预估。当 τf → 0 时本片段趋近于反步法，但离散实现下 τf 不应小于 2–3 个采样周期，否则滤波方程本身会数值失稳。

片段 2：反步 vs DSC 在含噪测量下的对照

import numpy as np

def run_case(mode, dt=1e-3, n=3000, noise_rms=0.01):
    """mode: 'bs' 反步（用测量速度） / 'dsc' 动态面。"""
    rng = np.random.default_rng(7)
    m, f_c = 2.0, 8.0
    m_d, d_d, k_d = 1.0, 60.0, 1500.0
    c1, c2, m_hat = 25.0, 40.0, 2.0
    tau_f, x = 0.01, 0.0
    v = x_d = dx_d = a1f = 0.0
    rms_e, tau_log = 0.0, []
    for i in range(n):
        f_env = 5000.0 * (x - 0.001) if x > 0.001 else 0.0
        ddx_d = (-f_env - d_d * dx_d - k_d * (x_d - 0.02)) / m_d
        dx_d += ddx_d * dt
        x_d += dx_d * dt
        v_meas = v + rng.normal(0.0, noise_rms)   # 1 cm/s 的测速噪声（真实存在）
        e1 = x - x_d
        alpha1 = dx_d - c1 * e1
        if mode == "bs":
            alpha1_dot = ddx_d - c1 * (v_meas - dx_d)  # 反步：噪声直接进控制律
            e2 = v_meas - alpha1
        else:
            a1f += (alpha1 - a1f) * dt / tau_f         # DSC：噪声被低通衰减
            alpha1_dot = (alpha1 - a1f) / tau_f
            e2 = v_meas - a1f
        u = m_hat * alpha1_dot - e1 - c2 * e2
        v += (u - f_env - f_c * np.tanh(v / 0.01)) / m * dt
        x += v * dt
        rms_e += ((x - x_d) ** 2 - rms_e) / (i + 1)
        tau_log.append(u)
    return rms_e, np.std(tau_log[-500:])   # 跟踪 RMS、末端控制量的抖动强度

for mode in ("bs", "dsc"):
    rms_e, jit = run_case(mode)
    print(f"{mode:3s}  跟踪 RMS={rms_e*1000:6.2f} mm  控制量抖动={jit:6.3f} N")

解读：预期结果是 dsc 行的跟踪 RMS 与 bs 相当（都好），但控制量抖动明显更小，因为噪声经滤波器后不再乘以 c1 放大进力矩。这里要诚实说明：在二阶系统上 DSC 的收益主要在"噪声通路"；当被控对象升到三阶（加入电机动态）时，反步需要二阶差分，DSC 的收益会从"更干净"升级为"还能不能工作"。实现细节：v_meas 故意用固定种子噪声，保证两种模式面对同一噪声序列，对照才公平；日志只取末段 500 拍统计抖动，避开初始瞬态。

片段 3：滤波时间常数的选取表

def tune_tau_f(candidates, alpha_dot_max, e_allow):
    """给出候选 tau_f 的截止频率与偏置估计，帮你一步选型。"""
    for tau_f in candidates:
        fc = 1.0 / (2.0 * np.pi * tau_f)          # 低通截止频率（Hz）
        bias = tau_f * alpha_dot_max              # 跟踪偏置估计（m）
        verdict = "可用" if bias < e_allow else "偏置超标"
        print(f"tau_f={tau_f*1000:4.0f} ms  截止 {fc:5.1f} Hz  "
              f"偏置≈{bias*1000:5.2f} mm  判定: {verdict}")

# 场景：虚拟控制的导数 |alpha_dot| 不超过 20 m/s^2，允许偏置 0.3 mm
tune_tau_f([0.05, 0.02, 0.01, 0.005], alpha_dot_max=20.0, e_allow=3e-4)
# 再把允许偏置放宽到 1 mm，看看哪些被"救回来"

解读：输出表把两个约束（截止频率要够高、偏置要够小）摆在同一行里。以 |α̇|max = 20 m/s²、允许偏置 0.3 mm 为例：τf = 0.02 s 的偏置 0.4 mm 超标，0.01 s 的偏置 0.2 mm 可用（截止 16 Hz，对 3–10 Hz 的导纳动态足够），0.005 s 更精确但抗噪余量变小。注意这个工具的哲学：先定"能容忍多大的滞后"，再定"要滤多少噪声"，顺序不能反，先想滤干净往往会把 τf 选大，最后被偏置预算打回重来。在多级 DSC 里对每层分别运行此表，并保证 τf1 > τf2 > …（外层信号更慢、更脏）。

常见坑

  • τf 小于 2–3 个采样周期：离散滤波方程 y += (α−y)Δt/τf 的步长比时间常数还"粗"，输出开始数值振铃。修复：τf ≥ 3Δt（1 kHz 下不小于 3 ms），并用阶跃响应仿真验证。
  • 误差定义忘改用 αf：控制律用了滤波导数，却仍用 e2 = ẋ − α 定义误差，证明里的交叉项不抵消，表现为缓慢振荡。修复：凡是进入李雅普诺夫推导的量，全部统一到滤波版本。
  • 层间滤波顺序颠倒：外层慢信号配小 τf、内层快信号配大 τf，高频段相位被交错抽走，系统出现难以定位的低幅振荡。修复：τf1 > τf2，级间至少差 2 倍。
  • 用 DSC 掩盖参考跳变：参考阶跃时滤波器输出一串斜坡，误差 e1 在过渡期很大，若同时放宽了增益会让偏差累积。修复：规划器输出平滑（S 型或余弦过渡），DSC 只负责"顺滑接口"，不负责"消化阶跃"。
  • 把实用稳定当渐近稳定宣传：验收指标定成 0 残差，结果永远差 τf|α̇| 那一口气。修复：验收标准写明"稳态偏置 ≤ τf|α̇|max"，或在滤波后加一路慢积分（带抗饱和）清零偏置。

  3. 把片段 2 的噪声 RMS 从 0.01 提高到 0.05 m/s，跑 bs 与 dsc，观察两者跟踪 RMS 与控制量抖动的分化，解释"为什么反步对测量噪声更敏感"。★★

    反步的 α̇1 = ẍd − c1(vmeas−ẋd) 让噪声乘 c1 = 25 直接进力矩；DSC 先衰减再乘，且 α̇1f 自身的噪声也被 τf 限制。
  4. 设计三阶扩展实验：在片段 2 的被控对象前串联 ucmd → u 的一阶电机滞后（τm = 8 ms），反步版本用二阶差分估计 α̈1；比较两版在噪声下的可用性，并给出 DSC 版本应新增的滤波器参数。★★★
    提示
    二阶差分对 0.01 m/s 噪声的放大是 (25)²·(噪声/Δt) 量级，反步版本力矩会被噪声淹没；DSC 只需在第二层再串 τf2 ≈ 5 ms 的滤波器，并保证级间 2 倍关系。

小结

  • 微分爆炸的根源：反步第 k 层需要虚拟控制的高阶导数，数字信号的高阶差分把噪声按 Δt−k 放大。
  • DSC 的替换：τfα̇f + αf = α；用 α̇f = (α−αf)/τf 替代解析导数，控制律里再无差分。
  • 代价：滤波误差 y 进入李雅普诺夫函数，稳定性从渐近降为（半全局）实用稳定，残差球 ∝ √τf，偏置 ≈ τf|α̇|max。
  • 选 τf 的顺序：先按偏置预算定上限，再用截止频率确认动态保留；层间滤波时间常数递减且至少差 2 倍。
