第五篇 · 鲁棒控制与工程实践

第 089 章：导纳控制中的H∞控制

如果扰动来自人、来自振动、来自你测不准的环境刚度，"最坏情况"就是一个需要被量化的词。H∞ 控制用"从扰动到性能输出的最坏放大倍数"当设计指标：范数小，意味着无论哪个频率、哪种环境，扰动都不会被放大。本章讲清范数的物理含义、灵敏度整形、Riccati 与 γ 迭代，以及它的保守代价。

  • 主题：H∞ 控制（H-infinity control）/ 鲁棒性能
  • 关键公式：‖Tzw‖∞ = supω σ̄(T(jω))，min ‖[W1S; W2T]‖∞
  • 预计学时：70 分钟
  • 前置章节：第 088 章

学习目标

  • 理解 H∞ 范数的物理含义：系统在最坏频率上对输入能量的最大放大倍数，并会计算一个给定传递函数的 H∞ 范数。
  • 掌握小增益定理的工程读法：不确定性有多大，闭环放大就必须压到多小，‖W2T‖∞ < 1 就是"稳定余量证明"。
  • 会写导纳接触回路的灵敏度 S = 1/(1+KenvGa) 与互补灵敏度 T，并解释混合灵敏度 min‖[W1S; W2T]‖∞ 在整什么。
  • 了解 H∞ 状态反馈的 Riccati 方程结构与 γ 迭代思想，能说清"γ 越小越好、但存在下界"。
  • 能列出 H∞ 的三笔代价：最坏情况保守、权重整定靠经验、控制器阶数上升；并能判断什么场景值得用。

背景与动机

前面几章的方法各有各的"抗扰哲学"：滑模把扰动当有界量硬扛，自适应在线改参数，MPC 用约束与前瞻。但它们都回避了一个问题：扰动不是单一频率、单一幅度的，它是全频段的、成片的、最坏情况下还可能恰好踩在你的共振点上。导纳控制的典型场景里，扰动来自三处：人的手（0.5–5 Hz 的宽带力量）、工件与夹具的振动（几十到几百赫兹）、以及你根本测不准的环境刚度（同一批工件里 Kenv 相差十倍）。

H∞ 控制给出的回答是"把最坏情况做成指标"：设计目标是"无论频率如何、无论 Kenv 在区间里怎么变，从扰动到性能输出的放大倍数不超过一个给定值 γ"，并不满足于"在某个工况下表现好"。γ 就是最坏情况放大倍数；能把它压到多小，取决于系统带宽、执行器权限与稳定性的三方博弈。这个指标天然带着保守性，但保守的另一面是"可认证"：安全等级高的协作场景、医疗器械、需要一次性给出鲁棒性证明的场合，H∞ 的账本比"试出来的参数"可信得多。

本章把这条链路完整走一遍：范数是什么（物理含义）→ 小增益定理（为什么它能证明稳定）→ 灵敏度整形（权重放哪里）→ Riccati 与 γ 迭代（怎么算）→ 数值实验（导纳回路的最坏情况灵敏度）。

核心原理

1. H∞ 范数：一个数概括"最坏放大倍数"

对一个稳定系统 G，输入信号 w、输出 z = G·w。定义

‖G‖∞ ≜ supω σ̄(G(jω)) σ̄(·)：最大奇异值（SISO 时就是 |G(jω)|）；sup：对所有频率取上确界

它的物理含义可以用能量说清：对任何频率成分的扰动，输出幅值最多被放大 ‖G‖∞ 倍（等价地，能量最多放大其平方）。例如 ‖S‖∞ = 2 表示"最坏频率上，环境扰动会在接触力里放大 2 倍"；‖T‖∞ = 1.05 表示"参考与扰动在闭环里几乎不放大"。H∞ 范数给出的是包住所有频率的上限线，它描述的不是平均表现，设计者因此可以对着一条曲线说话，无需只盯曲线中的某一点。

小增益定理把它变成稳定判据：若把不确定性建模成 Δ（一个满足 ‖Δ‖∞ ≤ 1 的稳定系统），闭环稳定的充分条件是

‖M(jω)·Δ(jω)‖∞ < 1，工程写法：‖W2T‖∞ < 1 W2：不确定性上界形状（如低频 50%、高频 100%）；T：互补灵敏度

工程直觉：小增益条件是一条"稳定预算"，不确定性拿走多少，你的闭环增益就必须让出多少；把 W2T 的幅频曲线画出来，它顶到 1 的频率就是鲁棒稳定的最后防线。

2. 导纳接触回路：S 与 T 各管什么

把导纳回路抽象成标准反馈结构。导纳滤波器（力 → 位置修正）为 Ga(s) = 1/(Mds² + Dds + Kd)，环境提供回路增益 L(s) = Kenv·Ga(s)。两个最重要的传递函数：

S(s) = 1/(1 + L(s))（灵敏度）， T(s) = L(s)/(1 + L(s))（互补灵敏度）， S + T = 1 S：环境表面扰动 xe 到接触力偏差的"力放大通道"；T：参考/测量噪声到位置的通道

在接触任务里，S 的峰值决定"环境一抖，力抖多少"：由于 S 在穿越频率附近必然隆起（Bode 积分约束），任何反馈设计都不可能让 S 在所有频率上小于 1，你能做的是控制它的峰值与位置。这就是为什么 H∞ 用混合灵敏度加权：低频段（人的推拉、工件缓漂）要求 S 小，用 W1 压；高频段（噪声、谐振）要求 T 小，用 W2 压；两者冲突的过渡段就是设计者要"选边"的地方。

3. 解法：Riccati 方程与 γ 迭代

标准问题：给定广义被控对象（状态空间 A, B1, B2, C1, D12），求控制器 K 使 ‖Tzw‖∞ < γ。状态反馈情形归结为求 P ≥ 0 满足代数 Riccati 方程（ARE）：

ATP + PA + C1TC1 + P(γ−2B1B1T − B2R−1B2T)P = 0 R = D12TD12；注意中间项带 γ−2 的"负号结构"，这就是 H∞ 与 LQR 的全部差别

γ 迭代的逻辑：ARE 有非负解 ⟺ 该 γ 可实现。于是从一个大 γ 开始，二分下压：可行就继续压，不可行就退回，最小可行 γ 就是最优 H∞ 性能。γ 存在下界：γ 太小时 ARE 的二次项变号、无解，物理上对应"你要求闭环比 Bode 积分允许的还安静"。控制量 u = −R−1B2TP·x（状态反馈版）；输出反馈版则用两个 Riccati 方程 + 观测器，工程上直接调用求解器即可。

工程直觉：LQR 只跟 Q、R 较劲，H∞ 多了一个 γ，它把"最坏情况"也放进了方程，代价是解出的控制器更保守、阶数更高（与权重滤波器同阶）。权重 W1、W2 是这项技术里真正的"手艺"：它们不改变数学，只改变你告诉优化器"哪里重要"。常用的起点：W1 = (s/ωb+ε)−1（低频高增益，压 S），W2 取常数 0.5–1（全频段不确定性余量）。

4. 代价与适用边界

第一笔代价是保守性：最坏情况设计对"平均工况"来说总是偏慢偏软，为了在 Kenv 上限处不振荡，你在下限处牺牲了响应速度。第二笔是权重整定：W1、W2 调不好，要么无解、要么解出"听起来很硬、摸起来很钝"的控制器；它不像 Kd、Dd 那样有直观手感。第三笔是阶数与实现：控制器阶数 = 被控对象 + 权重阶数之和，输出反馈还要观测器，离散实现要小心数值条件。适用判断很直接：当"环境参数范围已知、稳定性需要一次性证明、任务节奏不快"时用 H∞；当任务是快速迭代的工艺参数试错时，用第 083 章的自适应增益更划算。两者甚至能组合：H∞ 保底、自适应在包络内微调。

实现思路与设计

  1. 建模：把导纳回路写成 L(s) = KenvGa(s)，确定 Kenv 的区间 [Kmin, Kmax]（本例 [103, 105] N/m）。
  2. 定义性能通道：选 S（力放大）为主通道，T（噪声到位置）为次通道；写出混合灵敏度结构。
  3. 选权重：W1 = 1/(s/ωb+0.01)，ωb 取任务带宽（如 6 rad/s，对应人的推拉）；W2 = 0.5（不确定性 50% 余量）。
  4. 求解与验证：对每个候选设计，在 Kenv 区间上扫描 ‖S‖∞、‖W2T‖∞，画出最坏包络；用 γ 迭代核对最优值。工程上这一步可以完全在频域做（回路整形），再交给求解器做精确 H∞。
  5. 离散与实现：控制器离散化（Tustin，1 kHz），检查离散后的范数退化（一般 <5%）；状态限幅与观测器初始化（从"零外力"状态启动）。
  6. 监控：在线记录 S 峰值对应的频率漂移，若实际接触的峰值频率明显偏离设计值，说明 Kenv 出了区间，触发参数复核。
设计决策：为什么 H∞ 设计里"把 S 压小"不能过头？

S 小意味着"扰动到力的通道安静"，但 S + T = 1 决定了 S 小的频段里 T 必然大；T 大意味着测量噪声、参考抖动会大量进入位置指令。同时 Bode 积分定理告诉你：S 在某频段压得越深，必然在另一频段隆起越高（"水床效应"）。所以 H∞ 设计的本质是"把 S 的隆起放到你能接受的频段"，"把 S 压到最小"本身无法实现，对手（人、振动）在哪个频段活动，你就把安静留给哪个频段。权重 W1 的形状，就是你在这张水床上按下去的位置。

关键代码与解读

片段 1：计算灵敏度范数并对环境刚度取最坏

import numpy as np

def sensitivity(w, m=1.0, d=44.7, k=500.0, k_env=1e4):
    """导纳接触回路灵敏度 S(jw) = 1/(1 + K_env*G_a)，G_a = 1/(Ms^2+Ds+K)。"""
    s = 1j * w
    G_a = 1.0 / (m * s**2 + d * s + k)
    return 1.0 / (1.0 + k_env * G_a)

def hinf_norm(tf_func, w):
    """频域扫描求 H∞ 范数：幅频响应的上确界（工程上密网格足够准）。"""
    gains = np.abs(tf_func(w))
    i = int(np.argmax(gains))
    return float(gains[i]), float(w[i])

w = np.logspace(-1, 3.5, 4000)          # 0.1 ~ 3000 rad/s 的对数网格
for d in (15.0, 44.7, 120.0):           # 三种阻尼：欠阻尼 / 临界 / 过阻尼
    worst, worst_k = 0.0, 0.0
    for k_env in np.logspace(3, 5, 25): # 环境刚度在 [1e3, 1e5] 内取最坏
        val, _ = hinf_norm(lambda w_, d=d, k_env=k_env:
                           sensitivity(w_, d=d, k_env=k_env), w)
        if val > worst:
            worst, worst_k = val, k_env
    print(f"D_d={d:5.1f} N*s/m  最坏 ||S||inf={worst:4.2f}  "
          f"发生在 K_env≈{worst_k:.0e} N/m")

解读：这段代码把"H∞ 思维"压缩成两行逻辑：先对频率取上确界（范数），再对环境参数取最坏（鲁棒）。预期结果：D = 15（欠阻尼）时最坏 ‖S‖∞ 达 20 以上，环境一抖力就放大二十倍；D = 44.7（临界）压到 7 左右；D = 120 降到约 2.9。注意最坏值都出现在 Kenv=105 的钢件上，环境越硬、接触阻尼比被稀释得越厉害（第 016 章的"软导纳悖论"）；要把最坏 ‖S‖∞ 压到 2 以内，本例需要 D ≥ 200 N·s/m 量级。注意 lambda 里用 d=d, k_env=k_env 的默认参数写法，这是 Python 闭包的经典坑，不这样写会捕获循环变量的最终值，三条曲线会变得一模一样。H∞ 范数的精确值可用 Hamiltonian 二分求得，但 4000 点对数网格的误差通常小于 1%，工程上足够。

片段 2：小增益稳定余量检查

def comp_sensitivity(w, d, k=500.0, k_env=1e4, m=1.0):
    """互补灵敏度 T = L/(1+L)，L = K_env*G_a。"""
    s = 1j * w
    L = k_env / (m * s**2 + d * s + k)
    return L / (1.0 + L)

def robust_margin(d, w, w_m=0.5):
    """对所有 K_env 检查 ||W_m*T||inf；w_m 是乘性不确定性的上界形状。"""
    worst = 0.0
    for k_env in np.logspace(3, 5, 40):
        gains = w_m * np.abs(comp_sensitivity(w, d, k_env=k_env))
        worst = max(worst, float(np.max(gains)))
    return worst

for d in (15.0, 44.7, 120.0):
    margin = robust_margin(d, w)
    verdict = "鲁棒稳定（有余量）" if margin < 1.0 else "余量不足，需加大阻尼或降带宽"
    print(f"D_d={d:5.1f}  ||W2*T||inf={margin:4.2f}  {verdict}")

解读：Wm = 0.5 表示"允许环境刚度有 50% 量级的不确定性"。判据 ‖W2T‖∞ < 1 的读法：把不确定性想象成"最会找茬的频率成分"，T 的峰值就是它最容易得手的地方；WmT 的峰值低于 1，任何不超过 50% 的建模误差都不会把闭环推出发散。预期结果：三档阻尼的 ‖W2T‖∞ 分别为约 10.5、3.5、1.3，都还没压到 1 以下："50% 不确定性 + 最坏钢件"对轻阻尼设计是实打实的缺口：要让判据过关，D 需要加大到 200 N·s/m 以上（本例 D = 200 时约 0.83）。这张表就是给评审看的"稳定余量证据"：它把缺口量化成数字，直接支撑"加阻尼、降带宽还是缩小不确定性范围"的决策。

片段 3：一维 γ 迭代，Riccati 可行性的二分

def riccati_feasible(gamma, a=-1.0, b1=1.0, b2=1.0, q=10.0, rho=1.0):
    """一阶系统的 H∞ ARE 可行性：c*p^2 - 2a*p - q^2 = 0，c = b2^2/rho^2 - b1^2/gamma^2。"""
    c = (b2 / rho) ** 2 - (b1 / gamma) ** 2
    if c <= 0.0:
        return False, 0.0                 # 二次项非正：无稳定非负解
    p = (a + np.sqrt(a * a + c * q * q)) / c   # 取正根，保证 P 非负
    return p > 0.0, p

def gamma_iterate():
    """二分寻找最小可行 gamma：可行区间在上，不可行区间在下。"""
    lo, hi = 1e-3, 1e3
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        ok, _ = riccati_feasible(mid)
        if ok:
            hi = mid                      # 可行：尝试更小的 gamma
        else:
            lo = mid                      # 不可行：抬高下界
    return hi

print(f"最小可行 gamma = {gamma_iterate():.4f}")   # 理论下界 b1*rho/b2 = 1.0

解读：这是把"γ 迭代"完整拆开的最小示例。一阶系统的 ARE 退化成二次方程 c·p² − 2ap − q² = 0，其中 c = b2²/ρ² − b1²/γ²；c ≤ 0 时 ARE 无稳定非负解，这就是 γ 下界的来源，本例中 γmin = b1ρ/b2 = 1.0，程序二分 60 次后应给出 1.0000 附近的值。多输入多输出系统里，这一步换成"求 Hamiltonian 矩阵特征值"的矩阵版二分，逻辑完全一样：可行性是二分判据，范数是搜索目标。把这段代码当作 H∞ 求解器的"心脏起搏器"，它让你不再把 γ 迭代当黑盒。

常见坑

  • 只在标称环境验证范数：对 Kenv = 1×104 设计得很漂亮，换到 105 峰值翻三倍。修复：范数必须对参数区间取最坏（片段 1 的外层循环），并把最坏值写进设计验收。
  • 权重无解硬凑：W1 低频增益定得过高（如要求 S < 0.01 到 20 rad/s）导致 γ 迭代无解，以为是求解器问题。修复：先画 Bode 积分预算，S 的压低深度与带宽乘积受限于系统"非最小相位"与执行器权限，给权重留物理裕量。
  • 忘记水床效应：把 S 在低频压到 0.05，结果 30–60 Hz 处隆起 8 倍，恰好落在减速器谐振上。修复：W1 之外再用 W2 或陷波权重"钉"住危险频段。
  • 离散化后不复查范数：Tustin 变换在接近 Nyquist 的频率上相位失真，鲁棒余量可能掉一半。修复：离散后再扫一遍 ‖W2T‖∞，并确认采样频率至少是设计带宽的 20 倍。
  • 用 H∞ 控制器硬做接触：控制器本身是线性系统，接触的"单向性"（不能拉）没被建模，压缩工况下可能产生"吸住"指令。修复：控制器输出后接单向约束与力限幅，或只在"接触段"启用（自由段用位置控制）。

练习与思考

  1. 解释为什么 ‖S‖∞ 至少为 1（提示：考虑 ω → ∞ 与 S + T = 1），并说明"环境表面缓漂"和"高频振动"分别对应 S 的哪一段频率。★
    提示
    高频时 L → 0、S → 1，所以 sup|S| ≥ 1；缓漂对应低频（S 应小），振动对应穿越频率附近的隆起（S 峰值出现处）。
  2. 用片段 1 的代码，把 Md 从 1.0 改为 0.3 和 3.0 kg，记录最坏 ‖S‖∞ 与对应 Kenv。解释"虚拟质量改变的是什么"（提示：S 的峰值频率）。★★
    提示
    峰值频率 ∝ √((K+Kenv)/M)；M 变小峰值频率上移、峰值高度受 D 支配变化不大。M 主要动的是"隆起在哪里"，D 动的是"隆起多高"。
  3. 把 Wm 从 0.5 提到 1.0（不确定性 100%），重新跑片段 2，说明为什么"允许的不确定性越大、需要的阻尼越大"；再给出一个 D 的推荐值使 ‖W2T‖∞ < 0.8。★★
    提示
    Wm 翻倍等价于把判据收紧一半；T 的峰值随 D 增大而下降，一般需要 D ≥ 2√(M(K+Kenv,min)) 量级再上浮 30–50%。
  4. 推导片段 3 中一阶 ARE 的"正根公式"，并证明 γmin = b1ρ/b2；再把 a 改为 +1（不稳定被控对象），观察 γmin 是否变化。★★★
    提示
    可行性只取决于 c > 0（与 a 无关的二次项符号条件），所以 γmin 不变，但 p 的正根存在性对 a 的符号敏感，试试 a = −1 与 a = +1 的根分布差异。

小结

  • H∞ 范数 = 最坏频率上的最大放大倍数；它把"全频段、全参数范围"的鲁棒性变成一个可以比较、可以验收的数。
  • 小增益定理：不确定性有多大，闭环增益就要让出多少；‖W2T‖∞ < 1 是鲁棒稳定的工程判据。
  • 导纳回路的两个核心传递函数：S = 1/(1+KenvGa)（扰动→力）与 T（噪声→位置）；混合灵敏度 min‖[W1S; W2T]‖∞ 就是在水床上选按压位置。
  • 解法核心：Riccati 方程可行性 + γ 迭代；γ 有物理下界，控制器阶数高于被控对象。
  • 代价：保守、权重难调、阶数高；适合"参数范围已知、需要稳定证明"的场景。下一章进入"鲁棒与估计"一组最后一站：无传感器力控制，当连力传感器都没有时，外力从哪里来、能估多准。
