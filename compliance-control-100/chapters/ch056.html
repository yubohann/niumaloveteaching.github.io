第 056 章：基于神经网络的阻抗控制

摩擦、回差、耦合，这些"写不出解析式"的效应过去靠查表或高增益硬扛。本章让 RBF 神经网络在线逼近它们，并把权重更新律从李雅普诺夫函数里推出来：补偿项接在阻抗控制旁边，学习过程自带稳定性证书。

  • 主题：RBF 网络 / 在线自适应补偿
  • 关键公式：F̂ = Ŵ⊤φ(s)， Ŵ̇ = −Γ(φs + σŴ)（s 为误差组合面）
  • 预计学时：60 分钟
  • 前置章节：第 055 章（基于模糊逻辑的阻抗参数调整）

学习目标

  • 理解神经网络在阻抗控制中的正确位置：作为旁路模块补偿未知非线性，控制器主干保持原来的结构。
  • 掌握 RBF 网络的三要素：中心、宽度、权重，以及"输入归一化"为什么决定成败。
  • 会从李雅普诺夫函数推导权重更新律 Ŵ̇ = −Γ(φs + σŴ)，并解释 σ 泄漏项的作用。
  • 会设计误差组合面 s = ė + λe 以及它和阻抗参数（kd、λ）之间的换算。
  • 能写出带输出限幅、权重钳制、使能门的安全包装，理解"NN 永远不接管安全关键路径"。

背景与动机

第 051 章用最小二乘辨识了"结构化"的参数（惯量、摩擦系数），但有些效应并不适合参数化：减速器回差随负载与温度变化、多关节耦合的复杂形态、接触面几何导致的非线性力-位映射。传统解法是加大控制增益"压过去"，代价是稳定性裕度被吃掉；或者做表查值，代价是工况一变就失配。

神经网络（neural network）提供的是"函数逼近"能力：给定足够多的基函数，它能逼近任意连续非线性（万能逼近定理），而且在线版本可以把权重更新的稳定性像自适应控制一样证明。本章选的 RBF（径向基函数）网络是最适合实时控制的一类：它是线性于权重的（输出对权重是线性映射），这让更新律的推导和收敛证明都落在"自适应控制"的成熟框架里，避开深度学习那套需要海量数据和随机梯度的路径。一句话边界：模糊（第 055 章）写知识、RL（第 057 章）学策略，而 NN（本章）学"函数的形状"。

核心原理

1. RBF 网络：高斯基函数与它的直觉

单输出 RBF 网络的输出是基函数的加权和：

F̂(x) = Ŵ⊤φ(x) = Σi=1N ŵi·exp( −‖x − ci‖² / (2σ²) ) ci：第 i 个基函数的中心（在输入空间中的"采样点"）；σ：宽度（决定覆盖范围）；ŵi：权重

直觉：每个基函数像一盏灯，在中心 ci 附近"照亮"输入空间的一小块；网络输出就是所有灯光的加权叠加。万能逼近说的是：灯够多（中心够密）、权重调得好，任意连续曲线都能拼出来。对于摩擦补偿这类任务，输入常取速度（或速度与位置），中心按经验铺在速度范围内，宽度取中心间距的 1–1.5 倍（相邻基函数充分重叠，避免"灯与灯之间的黑区"）。

三个实践要点：（1）输入必须归一化，速度 0.05 m/s 直接进网络会让所有中心挤在原点附近，学习立刻退化；除以尺度（如 0.05 m/s）后中心和宽度才可控。（2）中心不必在线学，它们决定"分辨率"，固定即可；真正学习的是权重，这让问题保持线性。（3）网络输出的物理量纲要显式，本章输出补偿力（N）或补偿力矩（N·m），输出限幅按执行器预算设置。

2. 把补偿项接入阻抗回路

控制律采用"PD + 摩擦/非线性补偿"的形式（可看作阻抗控制的计算力矩版本）：

τ = m(ẍd − λė) − kd·s + F̂(x)， s = ė + λe， e = x − xd s：误差组合面（滑模面的简化版）；λ：组合系数；F̂：神经网络补偿项；kd：组合面的比例增益

把 τ 代入含未知非线性 f(x,ẋ) 的对象 mẍ = τ − f：

m·ṡ = −kd·s + (F̂ − f) = −kd·s − F̃， F̃ = f − Ŵ⊤φ = W̃⊤φ W̃ = W* − Ŵ：权重估计误差；F̃：补偿残差；s → 0 意味着 e → 0（一阶滑模的经典结论）

3. 权重更新律：从李雅普诺夫函数长出来

取李雅普诺夫函数 V = ½m·s² + ½·W̃⊤Γ−1W̃（动能部分 + 参数误差部分的"能量"），对它求导并代入误差动力学：

V̇ = s(−kds − W̃⊤φ) − W̃⊤Γ−1Ŵ̇， 取 Ŵ̇ = −Γ·φ·s ⟹ V̇ = −kd·s² ≤ 0 关键观察：交叉项 −sW̃ᵀφ 与更新项 W̃ᵀφ·s 精确相消，这正是"线性于权重"带来的礼物

V̇ ≤ 0 说明 s 有界且 s → 0（在激励充分时），权重误差有界。工程上再加一项泄漏（σ-modification）：

Ŵ̇ = −Γ(φ·s + σ·Ŵ) σ 项让权重"缓慢泄向零"：当激励退化（φ→0）时防止权重在噪声方向上漂移；代价是留下一份小残差

工程直觉：这个更新律属于"自适应"，与"训练"是两回事，每一毫秒根据当前误差把权重往减小误差的方向推一点，Γ 是学习速率，稳定性由上面的相消结构保证。它不需要数据集、不需要反向传播、不需要学习率调度，代价是只能学"线性于权重"的逼近器（RBF、多项式等）。

4. 安全边界：NN 的职责范围

把三条红线写进设计：（1）补偿项输出限幅（不超过执行器力矩预算的 30%）；（2）权重钳制（‖Ŵ‖∞ ≤ 20，防个别特征饱和后权重发散）；（3）使能门（只在有接触/有运动、状态量在训练分布内时更新）。第 057 章会更系统地讨论"学习模块与安全回路的分层"，本章先立住规矩：神经网络可以改变"控制精度"，但任何时刻都不允许单独决定安全行为。

实现思路与设计

以"速度相关摩擦补偿"为例（控制周期 1 ms）：

  1. 输入选择：x₁ = v̂ / 0.05（归一化速度）；如果非线性与位置相关，再加 x₂ = x / 0.05。本章用单输入 9 中心。
  2. 中心与宽度：中心在 [−4, 4] 等距 9 个；σ = 1.0（间距 1、重叠充分）。
  3. 学习速率：Γ = 300（1/s 量级）；泄漏 σ = 0.05；更新频率与回路同频（1 kHz）但往往降采样到 100–200 Hz 以省算力、减噪声。
  4. 组合面参数：λ = 10 s⁻¹、kd = 30（等效刚度为 kdλ = 300 N/m 量级、阻尼 mλ + kd = 40 N·s/m），先让基础 PD 闭环稳定（ζ ≥ 1），再开学习。
  5. 上机顺序：仿真预训练（可选）→ 空载验证权重不漂 → 接触验证补偿方向 → 再开自适应的使能门。

验收：无补偿时的稳态误差带（库仑摩擦/刚度）应在新方案里缩小到 1/3 以下；权重曲线在 2 s 内进入平台（不再增长）；关掉学习后误差缓慢回退（证明补偿真的在起作用）。

关键代码与解读

片段 1：RBF 补偿器（基函数 + 更新律）

import numpy as np

class RBFCompensator:
    """RBF 在线补偿器：逼近未知非线性(如摩擦)。权重更新由李雅普诺夫
    推导保证稳定：W_dot = -Gamma*(phi*s + sigma*W)。"""
    def __init__(self, n=9, width=1.0, gamma=300.0, sigma=0.05):
        self.c = np.linspace(-4.0, 4.0, n)   # 归一化输入 [-4,4] 上等距中心
        self.width, self.gamma, self.sigma = width, gamma, sigma
        self.w = np.zeros(n)                 # 权重从零出发(先“不补偿”)
        self.last_phi = np.zeros(n)

    def phi(self, x):
        # 高斯基函数：宽度 1、间距 1 → 相邻重叠充分，无“黑区”
        return np.exp(-0.5 * ((x - self.c) / self.width) ** 2)

    def output(self, x):
        self.last_phi = self.phi(x)          # 缓存供更新使用(同拍一致)
        return float(self.w @ self.last_phi)

    def adapt(self, s, dt):
        # W += -Gamma*(phi*s + sigma*W)*dt
        # 第一项：让补偿减小误差；第二项(泄漏)：激励退化时权重回零
        self.w += -self.gamma * (self.last_phi * s + self.sigma * self.w) * dt
        return self.w

解读：（1）权重初值为零等于"开始时完全依靠基础 PD"，工程上比随机初始化安全得多，也让"学习是否有效"可以对照。（2）output 里缓存 last_phi，避免在 adapt 里重算：差之毫厘的输入（一拍的 v̂ 差异）会让更新用的基函数与输出时不一致，长期造成小幅系统性偏差，这类"同拍一致性"是自适应代码的通用纪律。（3）泄漏项 σ = 0.05 相对 Γ = 300 是"慢泄"：时间常数约 1/(Γσ) ≈ 0.07 s 的等效收缩，听起来快，但泄漏只作用于权重本身，不碰误差项，实际效果是在无激励时防止漂移。（4）如果发现学习"学不动"，先查输入归一化，再查 Γ；如果发现权重缓慢发散，查泄漏与钳制，这两类现象占了 NN 现场问题的九成。

片段 2：摩擦补偿闭环仿真（学习前/后对比）

def friction(v):
    """未知摩擦：库仑 2 N + 黏性 3 v + 低速增强(Stribeck 型)。"""
    return 2.0*np.sign(v) + 3.0*v + 1.5*np.exp(-(v/0.02)**2)*np.sign(v)

def run(use_nn, x0=-0.02, t_end=6.0, dt=1e-3):
    """调节任务：把末端从 -20 mm 拉回 0。无补偿时被库仑摩擦拖成
    缓慢的粘滑爬行；NN 学会摩擦后误差带大幅收窄。"""
    m, lam, k_d = 1.0, 10.0, 30.0
    x, v = x0, 0.0
    nn = RBFCompensator()
    errs = []
    for k in range(int(t_end / dt)):
        e = x - 0.0
        s = v + lam * e                    # 误差组合面
        f_hat = nn.output(v / 0.05) if use_nn else 0.0   # 归一化输入
        tau = m * (-lam * v) - k_d * s + f_hat           # 基础PD + 补偿
        a = (tau - friction(v)) / m
        v += a * dt
        x += v * dt
        if use_nn:
            nn.adapt(s, dt)                # 由 s 驱动的在线权重更新
        errs.append(abs(e))
    tail = np.mean(errs[int(3.0/dt):])     # 后半程平均误差
    return tail * 1000.0, nn.w

for flag in (False, True):
    tail_mm, w = run(flag)
    print(f"use_nn={flag}  后半程平均误差={tail_mm:6.2f} mm")

解读：（1）无补偿时，库仑摩擦把收敛拖成粘滑爬行：后半程平均误差约 2.8 mm、收敛时间以十秒计（摩擦死区的经典参考宽度 c/kPD = 2 N / 300 N·m⁻¹ ≈ 6.7 mm）；开学习后补偿残差被压到 1 mm 以下、收敛缩到几秒，这就是在线自适应最直观的收益。（2）注意更新由 s 驱动，不用原始误差 e：s = v + λe 同时惩罚"位置偏差"与"速度偏差"，让收敛过程中权重不至于对瞬时速度噪声过敏（λ 的滤波作用）。（3）把 λ 从 10 调到 30（更强调速度项）学习更快但权重抖动更大，组合面参数不是随便取的，它决定了"学习信号"的干净程度。（4）打印的 nn.w 可以画出权重演化：前 1–2 s 快速上升后进入平台，平台高度对应摩擦幅值在基函数坐标下的分解，如果它一直线性增长不收敛，先怀疑 Γ 太大或泄漏项被写掉。

片段 3：安全包装（限幅 + 钳制 + 使能门）

class SafeNN:
    """NN 的安全包装：输出限幅、权重钳制、使能门。
    原则：学习模块可以改善性能，但绝不单独决定安全行为。"""
    def __init__(self, comp, f_max=5.0, w_max=20.0):
        self.comp, self.f_max, self.w_max = comp, f_max, w_max
        self.enabled = False

    def output(self, x):
        f = self.comp.output(x)
        return float(np.clip(f, -self.f_max, self.f_max))   # 力矩预算的 30%

    def adapt(self, s, dt, contact, v_hat, e_hat):
        # 使能门：有接触或有运动、且状态在训练分布内才允许学习；
        # 否则冻结权重，让“异常工况”不污染学到的模型
        self.enabled = (contact or abs(v_hat) > 1e-3) and abs(e_hat) < 0.05
        if self.enabled:
            self.comp.adapt(s, dt)
        # 权重钳制：∞-范数上界，防个别基函数饱和后权重发散
        self.comp.w = np.clip(self.comp.w, -self.w_max, self.w_max)
        return self.enabled

# 用法：τ = τ_PD + safe_nn.output(x) ；每拍调用 safe_nn.adapt(s, dt, ...)

解读：（1）输出限幅取"力矩预算的 30%"是行业常见经验：补偿项即使完全错误，也只吃掉三成力矩，安全回路与重力补偿仍有余量兜底。（2）权重钳制用 ∞-范数，不用 2-范数：实现便宜（一行 clip），且直接限制最大权重，与"输出限幅"形成"双保险"（权重有界 ⟹ 输出有界，但输出限幅在物理量上更直接）。（3）使能门两个条件各有含义：有运动/接触保证 s 里有有效信息（静止时学的只是噪声）；状态在小范围保证输入落在基函数覆盖区（越界外推的输出没有质量保证）。（4）注意 adapt 被调用但门关闭时"什么也不做"是刻意的：不要用"零更新"以外的手段（如把 s 强行置零再更新），那会引入隐性状态。真机调试时把 enabled 打到日志里，能直接看出"哪些时间段在学"。

常见坑

  • 输入不归一化：v ∈ [−0.1, 0.1] 直接进网络，所有基函数中心都落在原点两侧极窄处，输出近似常数，学不动。修复：除尺度（0.05 m/s）后进入 [−4,4] 的论域。
  • 学习速率过大：Γ = 3000 时权重在几十毫秒内冲过目标，s 与权重相互激励，出现 5–20 Hz 的"参数振荡"。修复：Γ 从 100 起调，验收标准是"权重曲线平滑进入平台"。
  • 让 NN 输出直接进力/位置安全通道：把 NN 补偿与安全限幅器并联（不串联），异常时补偿能绕过限幅。修复：限幅必须包在 NN 外面（片段 3 的包装类就是把这件事制度化）。
  • 在静止段持续学习：v ≈ 0 时输入集中在原点附近，基函数激活模式退化成单点，权重被噪声推着走。修复：使能门要求"有运动或接触"。
  • 相信"自学习"能替代模型：NN 学的是"残差里的规律"，系统的重力、几何、运动学仍要由常规模块负责；指望它从零接管整机控制，等于把安全交给一个没有证书的模块。修复：分层，常规控制保底，NN 只在补偿通道内工作（本章与第 057 章共同的安全架构）。

练习与思考

  1. 推导权重更新律：从 V = ½ms² + ½W̃ᵀΓ⁻¹W̃ 出发，代入 m·ṡ = −kds − W̃ᵀφ，证明取 Ŵ̇ = −Γφs 时 V̇ = −kds²，并说明 W̃ 的定义方向为何选择 W* − Ŵ。★★
    提示
    W̃̇ = −Ŵ̇（因为 W* 是常数）；交叉项相消的关键是"更新律的符号与 s 相乘"。定义反向会让两个交叉项相加，无法相消。
  2. 把片段 2 的 Γ 在 100/300/1000 之间扫描，记录后半程误差与权重曲线的"进入平台时间"，找出你系统里的最佳区间；再关掉泄漏项（σ=0）观察权重在静止段的漂移。★★
    提示
    Γ 大 → 学得快但抖；Γ 小 → 稳但慢。σ=0 时真机静止段的传感器噪声会让权重缓慢随机游走，这正是泄漏项存在的理由。
  3. 把输入从"速度"改成"速度 + 位置"二元（基函数中心铺成 3×3 网格），补偿对象改为"位置相关摩擦"f(v, x) = 2·sgn(v) + 3v + 0.5x。设计中心网格与宽度，并解释二维情况下"黑区"问题为什么更突出、宽度怎么选。★★
    提示
    二维时中心间距 d 处最坏覆盖 = exp(−d²/8σ²)；σ ≥ d 时相邻中心处的基函数值仍大于 0.6，境界充分。维度上升后同样点数覆盖变稀，这是"维数灾难"在控制里的具体样子。
  4. 设计一个"NN 失效场景"清单：列出至少三种会让本章方案输出错误补偿的工况（如传感器故障、负载突变、基函数覆盖区外的输入），并为每种给出检测手段与退路。★★★
    提示
    ① v̂ 长时间饱和/跳变 → 速度估计故障检测（第 048 章的物理上限保护）→ 冻结学习；② 负载突变 → 补偿残差长时间偏大 → 提高 λ 或降 Γ；③ 输入出界 → 使能门直接关闭，补偿回落到上一次的合理值（输出保持）。

小结

  • RBF 网络 = 高斯基函数 + 线性权重：适合实时控制，因为输出对权重线性，更新律可借用自适应控制的证明框架。
  • 更新律 Ŵ̇ = −Γ(φs + σŴ) 由李雅普诺夫推导：交叉项相消给出 V̇ = −kds²，泄漏项保证激励退化时权重有界。
  • 接入方式：PD/阻抗主干 + NN 补偿旁路；输出限幅、权重钳制、使能门三条红线不可省。
  • 输入归一化、组合面参数（λ、kd）与学习速率 Γ 是调试三件套，按"先稳后学"的顺序整定。
  • 与模糊的边界：模糊编码规则，NN 逼近函数形状；两者都是"参数/补偿层"的工具，不改变安全架构。
