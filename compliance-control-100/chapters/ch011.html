第一篇 · 基础、建模与稳定性

第 011 章：重力补偿下的阻抗控制

力传感器永远在"称重"：工具几公斤、质心偏几厘米，都会变成随姿态变化的伪外力。不把这几笔账扣干净，柔顺控制的所有结论都建立在错误输入上。

  • 主题：阻抗控制 / 重力与工具载荷补偿
  • 关键公式：Ftool = [m·RTg; pc×m·RTg]；gj(q) = Σ ∂U/∂q
  • 预计学时：55 分钟
  • 前置章节：第 010 章

学习目标

  • 能列出接触力估计里的三笔重力账：传感器零偏、工具/负载重力、机器人本体重力，并说明各自出现在哪条实现路径上。
  • 会推导工具重力在传感器坐标系里的等效力矩公式，理解"质心偏离原点为什么产生力矩"。
  • 掌握最小二乘辨识工具质量与质心的方法：力方程定质量、力矩方程定质心、多姿态克服病态。
  • 会写两连杆竖直臂的关节重力矩模型 g(q)，并在关节阻抗回路里正确使用前馈。
  • 理解补偿误差的放大机制：残余偏置如何经阻抗/导纳方程变成位置偏差与漂移。

背景与动机

先说一个现场数字：一台装 2 kg 打磨工具的机械臂，末端竖直向下时力传感器读到 +19.6 N；转 90° 后这 19.6 N 会"换一个方向"出现，还额外带上约 1.6 N·m 的力矩。传感器并不知道那是工具在称重，它忠实地报告"有外力"。前几章所有推导，导纳方程、稳态力公式、参数表，都建立在"F 是真实接触力"的假设上，而重力的存在让这条假设随时可能错 20 N。

重力补偿是柔顺控制的"清洁工"：把三笔账（传感器零偏、工具载荷、本体重力）从信号里扣干净，剩下的才是可以进控制律的接触力。本章按"传感器侧 → 工具侧 → 关节侧"的次序把它们逐一处理，其中工具质量与质心的最小二乘辨识是最实用的技能，它是每个力控项目的第一个标定环节。

核心原理

1. 三笔重力账：在哪儿、怎么算、不算会怎样

账目物理来源数学形式不补偿的后果
传感器零偏应变电桥零点、温漂常值 wrench 偏置恒定的位置偏移/漂移（第 002 章的死区泄漏只能兜底）
工具/负载重力末端法兰之后的全部质量随姿态 R 变化的 6 维 wrench力读数随姿势"变心"；大工具直接顶到导纳限幅
机器人本体重力各连杆质量对关节的力矩关节空间 g(q)力矩接口方案静态下垂；位置接口方案由内环扛住但影响能耗与安全

三笔账的作用位置不同：零偏与工具重力作用在传感器信号上，对位置型/导纳型实现是致命伤；本体重力作用在关节力矩上，对力矩型实现是致命伤。所以先回答一个问题：你的实现走哪条线？然后先修对应的账。两条线都要平的场景（如六维力控 + 力矩接口）就三笔全做。

2. 工具重力：从牛顿到传感器读数

设工具质量 m（kg），质心在传感器坐标系里的位置 pc（m），世界系重力加速度 g（m/s²，约 9.81，方向向下）。重力在传感器坐标系里的等效力与力矩为：

fg = m·RTg ， τg = pc × fg R：传感器相对世界系的姿态（3×3 旋转矩阵）；×为叉乘。静力学结果，工具静止或慢速时成立

两个细节决定了工程成败。第一，fg 随姿态变化：R 转一下，同一个重力在传感器系里三个分量的分配就变了，这就是"机器人一转身，力读数跟着漂"的原因，也是必须用姿态实时计算而不能只标定一个常数的原因。第二，力矩项来自质心偏移：只要 pc 不为零，重力力线就不过传感器原点，产生 τg=pc×fg。量级感：m=2 kg、|pc|=8 cm 时，最大力矩约 mgl = 19.6×0.08 ≈ 1.57 N·m，比力传感器的力矩噪声底（约 0.01 N·m）大两个数量级，质心不辨识，力矩通道的力控无从谈起。

注意符号约定的自洽：传感器读到的原始 wrench wraw = wext + wtool(R) + wbias，其中 wext 是环境/人施加的外力（也就是前几章的 Fext）。工程直觉：重力补偿的本质是做一次"姿态相关"的减法，同一个数减不对姿态，等于没减。

3. 辨识：两条线性方程，一次最小二乘

m 和 pc 通常未知（工具是拼出来的）。好消息是它们可以从静态数据里线性解出。取 N 个静态姿态（每个姿态下无接触），第 i 个姿态的姿态矩阵 Ri、读数 (fi, τi)：

力方程： fi = m·(RiTg) （3N 个方程，1 个未知数） 对 m 是最小二乘标量解：m̂ = Σ(RiTg)·fi / Σ‖RiTg‖²
力矩方程： τi = pc × fi = −[fi]×·pc （3N 个方程，3 个未知数） [f]× 为叉乘反对称矩阵；用最小二乘解 pc

两个方法组合起来就是标准工具标定：质量从力的方程来（与质心无关），质心从力矩方程来（用测量力构造系数矩阵）。三条工程要点：（1）姿态要"散"，如果所有标定姿态的 R 差不多，力的方程退化成同一个方向，m 可解但 pc 的条件数爆炸；实践里至少 3 个、最好 5–8 个在球面上分布开来的姿态。（2）标定必须在无接触状态，任何外部接触力都会被当成"工具的一部分"吸收进参数里，后患无穷。（3）力矩方程系数里用的是测量力（含噪声），属于典型"变量含误差"问题；噪声大时先用拟合出的质量与力模型过滤一遍，再解质心。辨识残差还能反推可信度：残差超过噪声 3 倍，说明有未建模项（线缆、惯性、接触）。

4. 本体重力：关节侧的一笔账

对力矩接口实现，各关节要承担连杆重力矩。以两根连杆（竖直平面、q 从水平轴量起、质心距关节 lc1、lc2）为例，用势能对角度求导可得：

g1(q) = (m1lc1 + m2L1)·g·cos q1 + m2lc2·g·cos(q1+q2) g2(q) = m2lc2·g·cos(q1+q2)；量纲 N·m，符号随构型变化

工程上有三条获取途径，按成本递增：解析模型（需要 URDF/参数）、辨识表（把 g(q) 写成基函数线性组合 g(q)=Σβkφk(q)，用静态数据解 β）、零力模式借用（若驱动器已有内部补偿，直接使用）。它的正确用法是前馈：τ = Kj(qd−q) + Dj(q̇d−q̇) + ĝ(q)。漏掉 ĝ 时，闭环稳态误差为 −Kj−1g(q)，kj=300 N·m/rad 的关节面对 11 N·m 的重力矩会下沉约 0.04 rad（2.3°），在长臂上就是好几厘米的末端偏移。注意重力补偿的目标是"让弹簧只感受外力"，所以补偿量作用在输出力矩上、不进反馈路径，不影响稳定性裕度（误差只影响稳态精度）。

5. 残余误差的放大路径

补偿不可能完美，关键是知道残差往哪儿跑。设工具补偿残差 ε（N），对导纳/位置型实现，稳态位置偏差直接是 ε/Ka，0.5 N 残差在 Ka=500 时是 1 mm；对姿态通道，残差力矩 ετ（N·m）在 Kθ=10 N·m/rad 时是 0.1 rad 级别的倾斜。对力矩接口实现，本体补偿残差 εg（N·m）造成关节偏差 εg/Kj，经 J 映射到末端。所有残差的共同特征是随姿态变化（因为重力本身随姿态变化），所以表现为"某些姿势准、某些姿势偏"，看到这种模式，先怀疑重力项，再回头查控制器参数。

实现思路与设计

一个可上机的重力补偿流水线，按开机到运行的时序组织：

  1. 上电静置标定：机器人停在远离工件的姿态，平均 0.5–1 s 得 wbias（含当时姿态下的一切静态项，作为兜底）。
  2. 工具标定（一次/换工具时）：按上一节方法采集 5–8 个姿态求 m、pc；把参数写进配置并记录标定残差。
  3. 运行期逐拍补偿：wext = wraw − wbias − [m·RTg; pc×(m·RTg)]，R 由 FK 实时给出；再过死区/滤波（第 002 章）。
  4. 本体重力前馈：力矩接口路径加 ĝ(q)；每 1–10 拍更新（它对时间不敏感，慢更新足够）。
  5. 验证：静态扫姿态测试，机器人空载走一条大范围姿态轨迹，wext 的均值应保持在噪声量级（≤0.2 N、≤0.02 N·m）；超了回查标定。
设计决策：为什么工具质心精度要用"毫米"要求，而质量只要"百分"？

由误差传播算账：质量误差主要在力通道放大（ΔF = Δm·g，1% 质量误差 = 2 kg 工具的 0.2 N）；质心误差在力矩通道放大（Δτ = m·g·Δp，0.5 mm 误差 = 2 kg 工具 0.0098 N·m）。两个通道的噪声底不同（0.1 N vs 0.01 N·m），恰好要求质量到 ~0.5%、质心到 ~0.5 mm。实践策略是"先把质量信到位、再集中精力修质心"：力方程是纯标量最小二乘，几步姿态就是良conditioned；质心方程条件数差，姿态不足时会给出离谱的 pc（几厘米），一旦 pc 偏差大，力矩补偿把误差放大到工具重力矩量级，比不补偿更糟，所以宁可不补力矩项，也不要补一个坏参数。

关键代码与解读

片段 1：工具重力 wrench 的计算与扣除

import numpy as np

G_VEC = np.array([0.0, 0.0, -9.81])       # 世界系重力加速度（取 z 向下为负）

def tool_gravity_wrench(R_s, m_t, p_com, g_vec=G_VEC):
    """工具重力在传感器系里的等效 6 维 wrench（N, N·m）。

    R_s   : 传感器相对世界系的姿态（3×3），由 FK 实时给出
    m_t   : 工具质量（kg）；p_com: 质心在传感器系的位置（m）
    物理：重力旋到传感器系 → 质心不在原点 → 追加叉乘力矩
    """
    f_g = m_t * (R_s.T @ g_vec)            # 随姿态变化的"伪外力"
    tau_g = np.cross(p_com, f_g)           # τ = p×f，叉乘顺序不能反
    return np.concatenate([f_g, tau_g])

def measure_ext(w_raw, R_s, m_t, p_com, w_bias):
    """从原始读数到真正的接触力：一手扣零偏、一手扣工具重力。"""
    return w_raw - w_bias - tool_gravity_wrench(R_s, m_t, p_com)

# 量级检查：2 kg 工具、质心偏 8 cm，姿态旋转时伪力的变化
m_t, p_com = 2.0, np.array([0.0, 0.06, 0.05])
for ang in (0.0, np.pi/2):                 # 传感器绕 x 轴转 0° / 90°
    R_s = np.array([[1, 0, 0],
                    [0, np.cos(ang), -np.sin(ang)],
                    [0, np.sin(ang),  np.cos(ang)]])
    w = tool_gravity_wrench(R_s, m_t, p_com)
    print(f"转角 {np.degrees(ang):3.0f}°: f={np.round(w[:3],2)} N, "
          f"τ={np.round(w[3:],3)} N·m")

解读：这个 10 行函数是每个力控项目的第一块积木。三个设计点：（1）R_s.T @ g_vec 的顺序，把世界系的重力方向旋到传感器系；写成 R_s @ g_vec 是常见笔误，后果是工具"朝错误方向称重"，标定时干脆解不出稳定参数。（2）np.cross(p_com, f_g) 的顺序，力矩是"质心位矢叉乘力"，反过来会得到大小相同、符号相反的结果，而符号错误会让补偿叠加在伪力上，误差翻倍。（3）演示输出：转 90° 前后 f 与 τ 的六个分量全部改头换面，直观展示"姿态相关"的强度，这也是为什么很多简陋的实现"只标零位附近能用"，因为没做姿态实时计算。真机上此函数每拍调用一次（成本几个微秒），Rs 必须与力传感器安装坐标系一致（安装偏置应在标定时并入工具坐标系，不要留在代码里补）。

片段 2：最小二乘辨识，5 个姿态解出 m 与 pc

def skew(v):
    """叉乘的矩阵形式：[v]× u = v × u。"""
    return np.array([[0.0, -v[2], v[1]],
                     [v[2], 0.0, -v[0]],
                     [-v[1], v[0], 0.0]])

def identify_tool(poses_R, poses_f, poses_tau, g_vec=G_VEC):
    """多姿态静态数据 → (m, p_com)。力方程定 m，力矩方程定质心。"""
    A_f = np.concatenate([R.T @ g_vec for R in poses_R])   # (3N,)
    b_f = np.concatenate(poses_f)                          # (3N,)
    m_hat = float(A_f @ b_f / (A_f @ A_f))                 # 标量最小二乘

    A_tau = np.vstack([-skew(f) for f in poses_f])         # 用测量力构造
    b_tau = np.concatenate(poses_tau)                      # (3N,)
    p_hat = np.linalg.lstsq(A_tau, b_tau, rcond=None)[0]   # 3 未知数
    return m_hat, p_hat

# 仿真验证：真值 m=2.0 kg、p=(0.01,-0.02,0.08)m，含传感器噪声
rng = np.random.default_rng(7)
m_true, p_true = 2.0, np.array([0.01, -0.02, 0.08])
poses_R, poses_f, poses_tau = [], [], []
for _ in range(5):                                    # 5 个随机姿态
    A = rng.normal(size=(3, 3))
    Q, _ = np.linalg.qr(A)                            # 正交化得到随机旋转
    Q = Q @ np.diag([1.0, 1.0, np.linalg.det(Q)])     # 修正为 det=+1
    f = m_true * (Q.T @ G_VEC) + 0.05*rng.normal(size=3)
    tau = np.cross(p_true, m_true * (Q.T @ G_VEC)) + 0.005*rng.normal(size=3)
    poses_R.append(Q); poses_f.append(f); poses_tau.append(tau)
m_hat, p_hat = identify_tool(poses_R, poses_f, poses_tau)
print(f"质量: 辨识 {m_hat:.4f} kg（真值 {m_true}）")
print(f"质心: 辨识 {np.round(p_hat,4)} m（真值 {p_true}）")

解读：这段代码把"标定"从玄学变成两步线性代数。力方程为什么用两步解：未知量只有标量 m，A_f @ b_f 是投影内积，直接给出闭式解，比通用 lstsq 更快也更稳。力矩方程为什么用−skew(f)：τ=p×f=−[f]×p，把每个姿态的测量力变成 3×3 系数块，5 个姿态叠出 15 个方程解 3 个未知数，超定但线性。随机的姿态生成故意用"随机正交矩阵"模拟真机标定：实际执行时让操作员用各异的姿态覆盖上半球即可，原理相同。输出中你会看到质量误差常在 0.1% 级、质心误差常在 0.1–0.5 mm，这正对应上一节"质量到 0.5%、质心到 0.5 mm"的指标。把姿态数改成 2 个再跑：质量仍准（方向少但不影响标量投影），质心开始乱跳，这就是"姿态要散、数量要够"的数值证据，也是标定报告里最该检查的一行。

片段 3：本体重力前馈，关节阻抗的"不塌"实验

# 2 连杆竖直平面臂的关节重力矩（q 从水平轴量起，g 向下）
m1, m2, lc1, lc2 = 3.0, 2.0, 0.17, 0.15
L1, gv = 0.35, 9.81

def g_joint(q):
    """势能对关节角求导：τ_g = dU/dq（dU/dq 提供的是所需补偿力矩）。"""
    q1, q2 = q
    g1 = (m1*lc1 + m2*L1)*gv*np.cos(q1) + m2*lc2*gv*np.cos(q1+q2)
    g2 = m2*lc2*gv*np.cos(q1+q2)
    return np.array([g1, g2])

k_j = np.array([300.0, 150.0])            # 关节阻抗刚度（N·m/rad）
M_jj = np.array([0.08, 0.05])
d_j = 2.0*np.sqrt(k_j*M_jj)
q_d = np.array([0.60, 0.40])
dt = 1e-3

for tag, use_comp in (("无重力补偿", False), ("有重力补偿", True)):
    q, qd = q_d.copy(), np.zeros(2)
    for i in range(3000):                 # 仿真 3 秒
        # 控制律：关节弹簧 + 阻尼 (+ 前馈判断)
        tau = k_j*(q_d - q) - d_j*qd + (g_joint(q) if use_comp else 0.0)
        qdd = (tau - g_joint(q)) / M_jj   # 本体动力学始终含 -g(q) 项
        qd += qdd*dt
        q += qd*dt
    err = q - q_d
    print(f"{tag}: 稳态关节误差 = ({err[0]:+.4f}, {err[1]:+.4f}) rad")

解读：预期结果是教科书式的对照：无补偿时关节 1 下沉约 0.038 rad（即 −g1/k1 ≈ −11.4/300），关节 2 下沉约 0.011 rad；有补偿时两个误差都掉到 10−15 量级（数值零）。把前馈加在控制律、不进反馈路径是关键设计：tau = … + g_joint(q) 使用当前实测构型计算，跟随姿态即时变化，不影响回路的稳定结构，重力补偿属于"确定性扰动抵消"，与反馈无关。真实系统里 ĝ 来自模型，永远有 3%–10% 的残差，所以验收标准要看残差与模型误差量级是否相称，零误差不可达：把 g_joint 乘以 0.95 模拟 5% 模型误差，稳态误差会缩到无补偿时的 5%，这就是"补到位"的合理标准。q_d 附近的重力矩也可以用工作区间常数近似，但跨越象限时 cos 变号，务必换回解析式或插值表。

常见坑

  • 标定时有接触：任何接触力被吸收进质量/质心参数，工具"越标越沉"。修复：标定规程里明确"远离工件、只测自重"，并对标定残差设阈值。
  • 姿态不够散：在小角度范围内摆几下，质心方程病态，解出几厘米以外的 pc。修复：至少 3 个、建议 5–8 个半球分布姿态；用条件数校验。
  • 只标质量不标质心：力通道干净了，力矩通道仍带 1–2 N·m 伪力矩，姿态调整类任务表现为"越到某些角度越顶"。修复：力矩方程一起解，或先禁用姿态力控通道。
  • 换工具不换参数：换砂纸、换吸盘后质量/质心全变，伪力重回信号。修复：把标定写入开工程序清单，工装上加条码/配置 ID 自动加载。
  • 把本体重力搬进笛卡尔补偿：力矩接口之外还画蛇添足地在任务空间加"机器人重力补偿"，把内环已经处理的项重复扣减。修复：明确分工，传感器系扣工具，关节系补本体，两者互不越界。

练习与思考

  1. 推导两连杆竖直臂的关节重力矩公式 g1、g2（用势能对角度求导），并说明当 q1=q2=0（水平位形）时哪个关节的负担最大。★
    提示
    U=m g ycom；ycom1=lc1sin q1，ycom2=L1sin q1+lc2sin(q1+q2)；水平位形时 cos=1，重力矩最大。
  2. 用片段 1 的函数计算：m=2 kg、pc=(0, 0.1, 0) m，传感器姿态从水平转到竖直绕 y 轴 90°，列出 fg、τg 六个分量的前后值，解释力矩分量的变化来源。★★
    提示
    fg 的 19.6 N 从传感器 y 轴"搬"到 z 轴（或相反）；τ=p×f 随两向量方向变化重算，可能从 0 变成 1.96 N·m。
  3. 用片段 2 的辨识代码，把姿态数改成 2、再改成 8，各跑 10 次统计 m̂ 与 p̂ 的散布。解释散布随姿态数的变化趋势，并给出"标定合格"的判定式。★★
    提示
    2 个姿态时质心解在 15 个方程中只有 6 个有效方向（秩亏风险大）；8 个姿态散布按噪声均值化缩小；判定式可用残差 RMS ≤ 3σ噪声 且 p̂ 的协方差（lstsq 可给）对角线开方 ≤ 目标精度。
  4. 推导残余补偿误差的稳态影响：工具补偿残余 ε（N）与本体补偿残余 εg（N·m），分别证明位置型实现的稳态偏差为 ε/Ka（任务侧）、力矩型实现的关节偏差为 εg/Kj（关节侧）。★★★
    提示
    两种实现的闭环稳态都是"弹簧项 = 残余外力/力矩"；把 ε 代入导纳方程/关节阻抗方程，直接读出偏差。
  5. 为"每周更换砂纸盘"的打磨单元设计自动标定流程：写出触发条件、姿态序列（≥3 个）、无接触校验、参数存储与回滚、以及上线前的三个验证测量。★★★
    提示
    触发：工具 ID 变化或残余力矩超阈值；校验：标定期 w_ext 均值与方差；存储：版本化参数 + 上一版回滚；验证：三个姿态下的残余力/力矩均值、以及一次拖动示教的手感对比。

小结

  • 三笔重力账分工明确：传感器零偏与工具重力在信号侧（影响位置型/导纳型），本体重力在关节力矩侧（影响力矩型），先按实现路线对号入座。
  • 工具重力 wrench = [m·RTg; pc×(m·RTg)]，随姿态实时变化；质心偏移是力矩项的来源，2 kg / 8 cm 的工具伪力矩可达 1.6 N·m。
  • 辨识两条线性方程：力方程定质量（标量最小二乘）、力矩方程定质心（用测量力构造系数）；姿态要散、标定要无接触、残差要核查。
  • 本体补偿写成前馈 ĝ(q)，残差表现为 Kj−1εg 的关节下沉；位置型侧残差表现为 ε/Ka 的常驻偏移。
  • 下一章处理同一层面的另一个"隐形力"：摩擦，它让微力指令死区化、让低速运动爬行，而且它的补偿比重力更依赖速度方向的判断。
