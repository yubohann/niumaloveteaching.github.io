第四篇 · 高级柔顺任务与约束

第 076 章：阻抗控制中的力限制

柔顺控制让机器人变"软"，但软不等于安全：接触力依然可能因规划失误、环境异常或参数失当而冲高。本章把"力不超过上限"做成一条有数学依据的硬约束。

  • 主题：安全约束 / 力限幅与软限幅设计
  • 关键公式：|F| ≤ Fmax ⟺ 位置偏置 |Δx| ≤ Fmax/Kd（稳态视角）
  • 预计学时：45 分钟
  • 前置章节：第 075 章（任务优先级）

学习目标

  • 理解力限制的三个层次：任务规划层（不要求过大）、控制回路层（限幅与整形）、独立安全层（硬件级），以及它们各自的责任边界。
  • 掌握三种回路内限力手段：期望力规划、导纳输出限幅、偏差预算限幅，并说清各自的生效机理。
  • 会用软限幅（smooth clamp）替代硬截断，理解硬截断为什么会在饱和边界激发抖振。
  • 掌握"稳态预算"估算：由 Fmax 反推 Kd 与位置偏置上限的容许组合。
  • 能写出一段完整的"限幅 + 抗饱和 + 滤波"安全链代码。

背景与动机

接触场景里，力超限的后果是实打实的：压裂光学镜片、把插接件怼弯、让六维力传感器进入非线性区、触发机械臂的碰撞停机。很多团队以为"用了阻抗控制就安全了"，其实阻抗控制只规定了力与运动的动态关系，如果期望位置本身规划错了 5 cm，稳态力照样是 Kd × 0.05 m。也就是说：阻抗控制管理"刚度"，力限制管理"上界"，两者正交且都必须有。

更麻烦的是接触力的"来源"具有欺骗性：它可能来自规划错误（位置偏置过大）、参数错误（Kd 过大）、环境突变（工件位置比标定差 2 mm）、甚至传感器故障（读数偏移）。本章的方法对所有这些来源统一给出一道上限闸门，并且在环路里做得连续、可微、可诊断。

核心原理

1. 稳态视角：力限制就是"偏置预算"

回到第一章的稳态关系 F = Kd·(xd − x)。要让接触力不超过 Fmax，一个必要条件是规划出来的位置偏置不超过预算：

|Δx| ≤ Fmax / Kd 例：Fmax=30 N、Kd=500 N/m ⟹ 偏置预算 60 mm；若 Kd=2000，预算只剩 15 mm

这给出两个互相牵制的旋钮：想留出大的位置容差（比如环境标定不准），就得用较小的刚度；想用大刚度保证精度，偏置预算就会很紧、规划必须更准。工程上有个不成文规则：偏置预算至少要能覆盖环境位置不确定度的 2–3 倍，否则限力形同虚设。

2. 回路层三处闸门

闸门位置手段作用注意
期望力规划端Fdes = min(Fplan, Fmax)从源头限制目标，稳态力不会超只约束稳态，不管瞬态冲击
反馈路径Fused = smooth_clamp(Fmeas)限制进入控制律的力信号幅值改变闭环动态：大误差时等效"软化"
输出端限幅速度/位置修正量限制单周期运动学动作幅度必须配抗积分饱和（见 061）

三个闸门解决的其实是不同时间尺度的问题：规划端管"哪里去"（秒级）、反馈端管"反应多大"（毫秒级）、输出端管"单步动多少"（控制周期级）。安全的做法是三道全开，因为任何单道闸门都有盲区。

3. 硬限幅 vs 软限幅：为什么要在边界"抹圆"

硬截断 clip(F, −Fmax, Fmax) 在 |F|=Fmax 处不可导：信号在阈值附近来回穿越时，输出在"线性区—饱和区"之间反复切换，等效于给回路注入一个高频方波，接触力会出现持续抖振（chatter）。软限幅用一个处处可导的平滑函数过渡：

clampsoft(F) = Fmax · tanh(F / Fmax) 小信号区：≈ F（无损）；大信号区：→ Fmax（饱和）；过渡带宽由坡度决定

也可以设计"线性区 + 三次多项式过渡 + 饱和区"的分段软限幅，让 90% 的常用区间保持完全线性（不损失力分辨率），只在接近上限的 10% 里软化。选择哪种取决于对力分辨率的要求。

4. 定量检查：限幅改变了什么

把限幅放在反馈路径上时，注意它的效应：设真实力 F 线性增大到 2Fmax，软限幅输出约 0.96Fmax，对外表现为"力越大，机器人越不抵抗"，这正是我们想要的"渐进让步"。但反馈路径限幅会让力跟踪任务在大误差时失去增益：误差 60 N 和误差 100 N 给出的反应几乎一样。所以跟踪精度要求高的任务（如打磨恒力 ±2 N）应把限幅阈值设在使用工况的 1.5 倍以上，让工作区间远离饱和区。

实现思路与设计

  1. 确定 Fmax：取三者最小值，工件许用力、传感器量程的 80%、机器人末端允许反力。为任务规划留 20% 余量（常用工况不超过 0.8Fmax）。
  2. 第一道闸门（规划）：对期望力做同一软限幅，保证任何规划错误都不能要求超限的稳态力。
  3. 第二道闸门（反馈）：f_used = soft_clamp(f_meas)，并在限幅前先做零点与滤波处理（噪声大时先低通再限幅，顺序不能反，否则尖峰先触发饱和）。
  4. 第三道闸门（输出）：对导纳积分器的速度与位置增量限幅；限幅激活时冻结积分项（抗饱和），并置一个诊断标志位供上层观察。
  5. 独立安全层：控制回路之外再做一道运行时监测（如 10 ms 窗口平均力超过 1.2Fmax 持续 100 ms → 触发停止逻辑，见 098 章）。它不参与控制律，只负责"刹车"。
设计决策：为什么限幅只作用在"动态部分"？

如果机器人做恒力曲面跟踪，执行器输出里其实包含"维持自身和工具重量"的重力补偿力矩。力限制只应该约束接触交互产生的那部分，绝不能把重力补偿也削掉，否则限幅一旦激活，机器人先"软"下去掉 10 cm，还会制造事故。实现上把 τ = τgravity + τtask 分开计算，限幅只检查 τtask（约到 079 章的力矩限制里会展开）。

关键代码与解读

片段 1：软限幅函数（可调过渡带）

import numpy as np

def soft_clamp(x, limit, band=0.2):
    """线性区 + 平滑过渡的软限幅。
    band: 过渡带占 limit 的比例。band=0 退化为硬 clip；
    band=0.2 表示在 80% 上限以内完全线性。"""
    a = limit * (1.0 - band)          # 线性区上限
    if abs(x) <= a:
        return x                      # 常用工作区：不损失任何精度
    s = np.sign(x)
    # 用三次多项式把 a 到 limit 之间平滑接起来（入口斜率 1、上限处斜率 0）
    u = min((abs(x) - a) / (limit - a), 1.0)
    smooth = u + u * u - u ** 3       # 入口与线性区斜率衔接（=1），到 cap 处斜率归零
    return s * (a + (limit - a) * smooth)

# 对比：x=1.5*limit 时两者都停在 1.0*limit；
# 差别在过渡区：软限幅连续可导，没有硬 clip 的拐点

解读：为什么不用 tanh？tanh 从原点就开始非线性（小信号也有 1% 左右偏差），对高精度力跟踪不友好；这里的"线性+三次过渡"使 80% 工作区严格线性。ease-out 曲线在过渡带尽头斜率归零，保证在 cap 处可导，这是避免抖振的关键。注意 min(..., 1.0) 是对输入的兜底保护（防止异常大数进入多项式区）。

片段 2：导纳积分器的输出限幅 + 抗饱和

class SafeAdmittance:
    """带限幅与抗饱和的导纳积分器（沿一个自由度）。"""
    def __init__(self, m=1.0, d=40.0, dt=1e-3, v_max=0.2, dx_max=0.05):
        self.m, self.d, self.dt = m, d, dt
        self.v_max, self.dx_max = v_max, dx_max   # 速度 / 位移预算
        self.v, self.dx = 0.0, 0.0

    def step(self, f_used):
        # 1) 导纳方程：M dv + D v = F（力直接驱动速度，简化的一阶形式）
        v_new = self.v + (f_used - self.d * self.v) / self.m * self.dt
        # 2) 速度限幅：激活时记录饱和标志（供上层诊断）
        saturated = abs(v_new) > self.v_max
        v_new = np.clip(v_new, -self.v_max, self.v_max)
        # 3) 位移预算限幅：到边界后把速度清零，防止"顶死"后积分
        dx_new = self.dx + v_new * self.dt
        if abs(dx_new) > self.dx_max:
            dx_new = np.clip(dx_new, -self.dx_max, self.dx_max)
            v_new = 0.0                     # 抗饱和：物理上已无路可走
        self.v, self.dx = v_new, dx_new
        return dx_new, saturated

解读：这段代码是三道闸门的"输出端"形态。两个细节最值得注意：（1）位移越过预算时把速度归零，如果只截断 dx 而不动 v，积分器会持续"顶"在边界上，一旦环境突然让开，积攒的能量会让机器人蹿出去（这就是抗饱和的本质：状态要跟着物理现实走）；（2）饱和标志位必须返回给上层，画图或日志里能清楚看到"限制在什么时候被打满"，这是调试安全约束的第一手信息。

片段 3：由预算反推参数组合（规划期检查）

def check_force_budget(k_d, f_max=30.0, pos_uncertainty=0.01, safety=2.5):
    """规划期检查：给定刚度，偏置预算能否覆盖环境位置不确定度？
    pos_uncertainty: 标定后残余的位置不确定度（m），安全系数取 2.5。"""
    budget = f_max / k_d                          # 公式 1：偏置预算
    required = safety * pos_uncertainty           # 需要的最小预算
    ok = budget >= required
    print(f"K_d={k_d:6.0f} N/m  预算={budget*1000:5.1f} mm  "
          f"需求={required*1000:5.1f} mm  {'可行' if ok else '不可行'}")
    return ok

check_force_budget(500.0)    # 预算 60 mm，需求 25 mm → 可行
check_force_budget(3000.0)   # 预算 10 mm，需求 25 mm → 不可行：先修正标定或降刚度

解读：把"参数是否合理"变成一行可执行的检查，是安全设计里性价比最高的习惯。这个检查的站位在规划期（选参数、标环境之后），不是运行期；运行期由三道闸门兜底。两者分工明确：规划期保证"正常工况根本不该超限"，运行期保证"异常工况超不了限"。

常见坑

  • 限幅阈值为"理想工况"设置：阈值贴着任务用力的 1.0 倍，导致常态化饱和、力跟踪形同虚设。工作点应落在限幅的线性区内，阈值至少是用力的 1.5 倍。
  • 先限幅后滤波：噪声尖峰在滤波前就触发了饱和标志，导致误判"频繁超限"并触发保护。正确顺序：去零点 → 低通滤波 → 限幅 → 进入控制律。
  • 忘了限幅也是非线性环节：在稳定性分析（015/016）里把回路当线性系统算出来的裕度，在持续饱和时全部失效。持续饱和本身就是一种需要避免的运行状态。
  • 把重力/工具重力补偿一起限幅：限幅激活瞬间机器人"塌"下去，比不限幅更危险。限幅只作用在交互相关通道上。
  • 只用一道闸门：规划端限幅挡不住瞬态冲击，反馈端限幅挡不住"偏置慢慢积累"的稳态超限，输出端限幅挡不住期望力本身过大，三道全开，各自补位。

练习与思考

  1. 完成计算：Fmax=40 N，标定残余不确定度 8 mm、安全系数 3。求允许的 Kd 上限。★
    提示
    预算 = Fmax/Kd ≥ 3×8 mm = 24 mm，解得 Kd ≤ 1667 N/m。选一个低于该值的刚度并在习题笔记本里核对量级。
  2. 把片段 1 的 soft_clamp 与 np.clip 在同一组输入（如从 −2Fmax 线性扫到 +2Fmax）下画成两条曲线，标出差异最大的区间，解释差异的"信息价值"。★
    提示
    两者在 cap 之外都被夹住；差别在过渡区：硬 clip 在拐点处不可导（易激发抖振），软限幅处处可导、跨过阈值时输出连续。
  3. 为什么片段 2 在位移超预算时把速度清零？若把速度限幅到一个小值，两种做法在"约束解除瞬间"的行为有何不同？★★
    提示
    行家会想到"储存弹性势能"：顶在边界上保持小速度也相当于持续加载，解除瞬间释放。清零让状态与"被墙挡住"的物理现实一致。
  4. 设计实验：让环境表面在示教后人为平移 15 mm（模拟标定误差），在 Kd 取 300 与 1500 两种情况下记录稳态力与限幅激活时长，验证"预算公式"的预测能力。★★
    提示
    Kd=300：稳态力约 4.5 N，远离限幅；Kd=1500：稳态力约 22.5 N，接近阈值，饱和时长明显增加。结论：位置不确定度大的场景别用大刚度。
  5. 把三道闸门分别单独打开与全开，构造一个"规划端要求 100 N 的力、环境在 1 s 时突然让开 20 mm"的冲击场景，记录力峰值。写出你的观察与解释。★★★
    提示
    只开输出端：冲击时速度限幅起作用，但期望偏置仍大，稳定后力可能缓慢爬升超限；只开规划端：稳态被限，但让开瞬间的速度没有约束；全开才是完整覆盖。

小结

  • 力限制与阻抗控制正交：前者管力的上界，后者管力的动态关系，两者都要有。
  • 核心预算公式 |Δx| ≤ Fmax/Kd，它把"选刚度"和"位置容差"绑定在一个检查式里。
  • 三道闸门：规划端（期望力）、反馈端（测量力软限幅）、输出端（速度/位移预算 + 抗饱和），各自覆盖不同时间尺度。
  • 软限幅（线性区 + 平滑过渡）兼顾精度与无抖振；限幅前必须先滤波。
