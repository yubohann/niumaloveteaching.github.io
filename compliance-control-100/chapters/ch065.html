第 065 章：基于导纳控制的轮廓跟踪

不追曲面、追曲线：用导纳把横向接触力积分为横向位置修正，把轮廓偏差一步步"推"回零；切向交给路径生成器，修正绝不泄漏到切向。

  • 主题：轮廓跟踪 / 焊缝寻位 / 导纳修正律
  • 关键公式：ẋc = ki(fref − flat)；v = min(vmax, √(amaxRc))
  • 预计学时：55 分钟
  • 前置章节：第 064 章

学习目标

  • 区分"曲面跟踪"与"轮廓跟踪"：前者维持法向力、后者消除沿路径横向的轮廓偏差。
  • 理解轮廓误差 ec 的定义，以及横向力为什么会随 ec 线性变化（槽型/肩型两种接触模型）。
  • 会设计横向导纳修正律 ẋc = ki(fref − flat)：一阶积分形式、环路时间常数与稳定裕度的关系。
  • 会把力按"切向/横向"分解，确保修正只作用在横向，切向由路径参数 s 的生成器负责。
  • 会由三点圆半径公式在线计算路径曲率，用于进给减速与拐角冻结。
  • 知道拐角处为什么必须冻结修正、恢复时为什么要加渐变。

背景与动机

焊缝跟踪、涂胶寻边、棱线打磨，任务对象有别于上一章的整张曲面，是一条曲线特征：坡口中心线、边缘棱线、涂胶轨迹。规划器给出的名义路径与工件的真实特征之间通常有几个毫米级的偏差（装夹误差、钣金回弹、焊缝成形变化），机器人必须一边沿名义路径前进，一边用接触信息把工具"拽"回真实特征上。

上一章的阻抗曲面跟踪以"维持法向力"为目标；轮廓跟踪的目标不同：把轮廓偏差消到零。这个"消偏差"的动作天生带记忆，偏差是慢慢攒出来的，也应该被慢慢积掉，所以主角换成导纳控制：力的横向分量不再直接对应位置偏置，改为被积分成持续的位置修正。一句话对比：曲面跟踪调的是"压得多紧"，轮廓跟踪调的是"骑在线上还是偏出去了"。

核心原理

1. 轮廓误差与横向力：两种接触模型

把工具中心到名义路径的偏差沿"路径横向"投影，得到轮廓误差 ec（单位 m，带符号）。横向力 flat 与 ec 的关系取决于接触几何，最常见的两种：

模型几何横向力修正目标
槽型（V 形坡口）两侧壁同时接触，工具偏心 e。f ≈ Kg·e，方向指向槽心flat → 0（回到中心即无侧向力）
肩型（单侧壁）探头压向单侧壁，靠 f 的大小判断贴紧程度。f 随压入量变化，方向固定flat → fref（如 5 N 贴壁）

槽型模型的线性关系 f = Kge 是本章分析的主线：Kg 叫槽侧向刚度（典型 500–2000 N/m）。注意它和曲面任务里的环境刚度扮演同一个角色，把"几何偏差"翻译成"可观测量"。肩型模型只是把目标从零改成常数，修正律写成 fref − flat 即可统一。

2. 横向导纳修正律：把力积分成位置

轮廓修正的最简形式是一阶导纳（本质是带增益的积分器）：

ẋc = ki · (fref − flat)，  修正方向沿路径横向轴 nc ki：修正增益，m/(N·s)；xc：横向位置修正量，m

把它和接触模型闭环起来看：ec 是实际偏差，xc 是工具被修正到的位置（+方向上正向偏差），flat = −Kg(ec − xc) 是"修正后剩余偏差"产生的力（力指回槽心，故取负号）。于是 ẋc = kiKg(ec − xc)，一阶收敛，时间常数：

τc = 1 / (kiKg) 例：Kg = 800 N/m，ki = 5×10−3 m/(N·s) ⟹ τc = 0.25 s

τc 的取法有硬约束：修正环路必须比内环位置控制慢 5 倍以上，否则"力→修正→位置→力"的回路会与内环动态耦合出振荡；同时它又不能太慢，否则过拐角时修正跟不上、偏差越积越大。经验区间 0.1–0.5 s，正好横跨"够快跟形状"与"够慢不打架"之间。工程直觉：轮廓跟踪靠的是"让修正量自己去积累，力越一直存在，修正就越攒越对"，并不去"用力把工具推到位"。

3. 方向分解：修正绝不能泄漏到切向

把测得的力按当前路径切向 t̂ 与横向轴 n̂c 分解：flat = F·n̂c，ftouch = F·t̂。只用 flat 驱动修正，切向分量不参与任何位置修正，如果让切向力也进修正环，力噪声会变成一节一节的"抽动"：摩擦增大瞬间工具被迫前抢，摩擦力减小又回抽，焊接速度在几赫兹上抖动。切向该由路径参数推进：s ← s + v·Δt/Rc 之类的换算交给路径生成器，轮廓环只负责横向。

横向轴 n̂c 从哪里来？两条路线：槽型的"力寻心"，直接用横向力的方向做修正方向（力指着槽心走）；肩型的"路径法向"，由名义路径的几何给出，力的大小与参考比较决定修正量。前者不需要路径先验，后者更稳、不会在多接触场景下迷路。工程上常用组合：用路径法向做主轴，用力的符号做一致性检查。

4. 拐角：几何与信号的双重不连续

拐角处两件事同时发生：路径切向几乎垂直地跳变（几何不连续），接触状态短暂改变甚至脱离（信号不连续）。此时修正环若继续工作，会把"信号缺失"当成"偏差为零"，把之前积累的正确修正又洗掉。正确策略是冻结（freeze）+ 减速 + 渐变恢复：由曲率监测触发冻结，进给降到 20–30%，过角后按 0.3–0.5 s 斜坡恢复。曲率可以直接由路径上相邻三点用外接圆半径公式在线估计：

Rc ≈ |AB|·|BC|·|CA| / (4·ΔABC面积)， v ≤ √(amax·Rc) A、B、C 为路径上间隔固定弧长的三点；amax 为允许向心加速度，m/s²

向心加速度限制 v²/Rc ≤ amax 保证法向修正不被"离心抛离"；amax 取 0.5–2 m/s² 是协作臂常见量级。

实现思路与设计

  1. 维护路径参数 s：名义路径以弧长参数化（折线+样条），每个周期按当前进给速度推进 s，并查询参考点 pd(s) 与切向 t̂(s)。
  2. 读力与滤波：测力经 10–20 Hz 低通（比修正环快、比噪声慢），再旋到基座系（若传感器在法兰，先做工具长度引起的力矩修正，第 068 章展开）。
  3. 分解：flat = F·n̂c，仅在横向进入修正律；切向分量只用于监控（超过阈值报警，说明进给遇到异常阻力）。
  4. 横向修正：ẋc = ki(fref − flat)，带速率限幅（如 ±20 mm/s）与总量限幅（如 ±3 mm，防止误把工件推飞）；拐角冻结。
  5. 合成命令：xcmd = pd(s) + n̂c·xc；接触深度方向（如 z）另有恒力或恒深处理。
  6. 曲率调度：每 10 ms 用三点估 Rc，生成进给速度上限；Rc 低于阈值时进入拐角状态（冻结+减速）。

参数起点：ki = 5×10−3 m/(N·s)（配 Kg ≈ 800 N/m 得 τc ≈ 0.25 s）；fref = 0（槽型）或 5 N（肩型）；低通 15 Hz；进给 10–30 mm/s；amax = 1 m/s²。修正量的初值应取 0 并允许快速收敛，若上电就带着上次任务的修正量，第一个拐角可能"拐错边"。

设计决策：为什么用"纯积分"？"质量-弹簧-阻尼"导纳差在哪？

轮廓修正的目标是大幅值、慢速度的累积运动（毫米级、秒级），不需要二阶动态的"手感"。加入质量会让修正对力噪声产生晃动，加入弹簧会让修正依赖"力与偏差的标定关系"（Kg 未知时不准）。纯积分只需要一个增益，而且对 Kg 的误差天然鲁棒，Kg 估错一倍，只改变收敛速度，不改变收敛性。

关键代码与解读

片段 1：把力分解到轮廓坐标系（只提取横向分量）

import numpy as np

def contour_frame(p_prev, p_cur, p_next):
    """由路径相邻三点给出切向 t 与横向 n（2D 平面内）。"""
    t = p_next - p_prev
    t = t / np.linalg.norm(t)              # 用前后点差商算切向，比单侧差分稳
    # 2D 中把切向转 90 度得到横向轴；用固定转向保证 n 的符号沿整条路径一致
    n = np.array([-t[1], t[0]])
    return t, n

def decompose_lateral(f_meas, t, n):
    """把接触力分解为切向/横向分量：只返回横向值，切向仅作监控。"""
    f_lat = float(np.dot(f_meas, n))
    f_touch = float(np.dot(f_meas, t))
    return f_lat, f_touch

解读：t 用前后两点差商，不用当前点的单侧差分，是因为拐角附近单侧差分会让切向提前"转弯"，横向轴随之歪斜，横向力的分解基准错了，修正方向也错。横向轴用"切向固定旋转 90°"生成，符号沿路径一致；如果每个点各自用最近法线方向定义，符号翻转一次就会让修正环把偏差往错误方向积累。decompose_lateral 有意只返回一个标量 flat：接口上就不给切向力进入修正环的机会，这类"用类型系统防错"的手法在安全相关代码里非常值得。

片段 2：横向修正积分器（速率限幅 + 冻结）

class LateralCorrector:
    """横向导纳修正：x_c. = k_i*(f_ref - f_lat)，带限幅与拐角冻结。"""
    def __init__(self, k_i=5e-3, dt=1e-3, rate_max=0.02, x_max=3e-3):
        self.k_i, self.dt = k_i, dt
        self.rate_max = rate_max    # 修正速度上限 20 mm/s，防误动作
        self.x_max = x_max          # 总修正量上限 3 mm，防把工件推飞
        self.x_c = 0.0              # 修正状态：横向位置增量，m
        self.frozen = False         # 拐角/无接触时冻结，保持已验证的修正量

    def step(self, f_ref, f_lat):
        if not self.frozen:
            # 一阶导纳 = 纯积分：稳态时 f_lat -> f_ref，即轮廓偏差被积掉。
            # 增益 k_i 与接触刚度 K_g 的乘积决定时间常数 tau = 1/(k_i*K_g)，
            # 这就是为什么 k_i 不能凭"响应快"随意加大
            rate = self.k_i * (f_ref - f_lat)
            rate = float(np.clip(rate, -self.rate_max, self.rate_max))
            self.x_c += rate * self.dt
            self.x_c = float(np.clip(self.x_c, -self.x_max, self.x_max))
        return self.x_c

解读：三重防护各管一层：k_i 管正常收敛速度，rate_max 管"力信号被打错时修正也不会突然暴冲"（例如碰撞瞬间 50 N 的尖峰只产生 0.25 m/s 的指令，被限到 20 mm/s），x_max 管积分总量。frozen 冻结量而不仅是冻结速率，拐角期间必须原样保持 xc，因为拐过之后工具还需要这个修正量继续骑在特征上；清零会让机器人"忘记"已经找到的偏差。若要增强安全性，可把冻结条件做成"任何时刻 |f_lat| > 30 N 都自动冻结"，让修正器在异常接触下先停下来等上层决策。

片段 3：曲率估计与进给/冻结调度

def path_curvature(a, b, c):
    """三点外接圆半径：R = abc/(4*Area)，同时给出拐角判据。"""
    ab, bc, ca = b - a, c - b, a - c
    lab, lbc, lca = map(np.linalg.norm, (ab, bc, ca))
    area2 = abs(ab[0] * bc[1] - ab[1] * bc[0])     # 叉积的绝对值 = 2*面积
    if area2 < 1e-12:                              # 三点共线：直线段
        return float("inf")
    return (lab * lbc * lca) / (2.0 * area2)        # 4*Area = 2*area2

class FeedScheduler:
    """按曲率限制进给速度，并在小半径(拐角)处触发修正冻结。"""
    def __init__(self, v_max=0.03, a_max=1.0, r_corner=0.02):
        self.v_max, self.a_max, self.r_corner = v_max, a_max, r_corner

    def update(self, R_c):
        corner = R_c < self.r_corner       # 半径小于 20 mm 视为拐角
        v_lim = np.sqrt(self.a_max * R_c) # 向心加速度约束：v^2/R <= a_max
        v = min(self.v_max, float(v_lim))
        if corner:
            v = min(v, 0.3 * self.v_max)  # 拐角额外减速到 30%
        return v, corner

解读：外接圆半径公式对"三点几乎共线"的退化情形返回 inf（视为直线），这样 FeedScheduler 里 inf < r_corner 为假、sqrt(inf) 不会把逻辑带坏，注意这里用 min(v_max, inf) 保证结果有限。触发量 corner 直接连到片段 2 的 frozen：曲率半径小于 20 mm 时冻结修正并减速 70%，过角后再由外层用 0.3–0.5 s 斜坡解除。三点间隔不要太小：间隔与噪声之比决定曲率估计的信噪比，工程上取 5–10 mm 弧长间隔。

常见坑

  • 修正方向符号不一致：横向轴 n 在路径某处翻转，修正环把已经修正好的工具又推回去，表现为"修到中途突然反向走"。修复：n 由切向统一旋转生成；单元测试沿整条路径验证 n 的连续性（相邻点 n·nprev > 0）。
  • ki 随意加大：以为"修正快等于精度高"，结果力信号里 10 Hz 的噪声被积成 10 Hz 的位置抖动，工件表面留下波浪纹。修复：按 τc = 1/(kiKg) 反算增益，并让 τc 至少是内环时间常数的 5 倍。
  • 忘记冻结导致"拐角失忆"：过角时力信号短暂消失，修正器把"无偏差"当成信息，之前积累的毫米级修正被洗掉。修复：曲率触发冻结 + 减速 + 渐变恢复三段式。
  • 切向分量混进修正：摩擦或切削阻力沿切向的波动被误当横向偏差，工具左右摇摆。修复：分解后只传横向标量；对 ftouch 设监控阈值报警。
  • 总修正量无上限：把修正量当作"越修越准"，一旦力的方向判断错了（如工具碰到夹具），修正量会线性增长直到撞界。修复：±3 mm 硬限幅 + 速率限幅 + 与路径偏差的交叉检查（修正量不应超过名义路径与 CAD 的最大可能偏差）。

练习与思考

  1. 推导横向修正环的闭环一阶方程，证明时间常数 τc = 1/(kiKg)，并解释为什么 Kg 估错只改变速度、不破坏收敛。 ★
    提示
    把 flat = −Kg(ec − xc) 代入修正律，除以 Kg 后 Kg 只出现在时间常数里；积分环对增益误差是"温和"的，符号错了才致命。
  2. 实验设计：在人工偏差 2 mm 的坡口上，分别令 ki = 1、5、20 ×10−3 m/(N·s)，记录修正收敛时间与位置抖动（用命令位置的高频标准差度量），给出你的选择与理由。 ★★
    提示
    ki 大收敛快但抖动大；重点关注"收敛时间 < 2 s 且抖动 < 50 μm"的综合最优档，并检查其 τc 是否满足内环的 5 倍准则。
  3. 推导三点圆半径公式 R = abc/(4A)，并说明三点间隔取太小与太大分别带来什么问题。 ★★
    提示
    由正弦定理 a/sin A = 2R 与面积公式 A = bc·sinA/2 联立。间隔小：曲率估计噪声大；间隔大：拐角位置被"抹平"，冻结触发晚。
  4. 任务设计：坡口两侧壁刚度不同（Kg1 = 500，Kg2 = 1500 N/m）。写出此时横向力与偏差的关系，说明"力恰好为零"还能不能作为"回到槽心"的判据；若不能，给出修正方案。 ★★★
    提示
    两侧刚度不同时，力为零的平衡点是"刚度加权中心"，跟几何中心有一段距离；需要按两侧接触力分别估计，或用路径几何先验偏置目标力。
  5. 思考题：为什么轮廓修正用"力→积分→位置"，而曲面跟踪用"力→瞬时位置偏置"？从"目标量是偏差还是力"的角度各写一句。 ★★
    提示
    曲面任务的目标是力本身（瞬时映射即可）；轮廓任务的目标是几何偏差，力只是偏差的观测，必须靠积分把它"归零"。

小结

  • 轮廓跟踪的目标是消除轮廓偏差 ec，不是维持某个力；横向力是 ec 的观测（槽型 f = Kge，肩型用参考力统一）。
  • 横向导纳修正律 ẋc = ki(fref−flat)：一阶积分，时间常数 τc = 1/(kiKg)，取 0.1–0.5 s 且至少为内环时间常数的 5 倍。
  • 力必须按切向/横向分解，修正只吃横向分量；切向由路径参数 s 的推进负责。
  • 三重防护：增益、速率限幅、总量限幅；外加异常力冻结。
  • 拐角三段式：曲率触发冻结、进给减速、渐变恢复；曲率用三点外接圆公式在线估计。
