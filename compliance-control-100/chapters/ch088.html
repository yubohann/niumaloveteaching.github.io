第五篇 · 鲁棒控制与工程实践

第 088 章：阻抗控制中的预测控制

阻抗控制是"反应式"的：撞上了才知道让。模型预测控制（MPC）选择"向前看"：用环境模型预测未来若干毫秒的接触力，在力上限与执行器约束下优化控制序列，滚动执行。它把"别超过 30 N"从愿望变成约束，代价是模型、算力与前瞻距离。

  • 主题：模型预测控制（model predictive control, MPC）
  • 关键公式：min Σ(xk−xref)²Q + Σuk²R，s.t. K̂env(xk−x̂e) ≤ Fmax
  • 预计学时：70 分钟
  • 前置章节：第 087 章

学习目标

  • 理解反应式柔顺的先天局限：接触力峰值由"接近速度 × 环境刚度"决定，等撞上再让步已经晚了。
  • 会把接触任务写成预测模型：xk+1 = xk + vkΔt，vk+1 = vk + Δt(uk − K̂env(xk−x̂e))/m，并用位置约束等效表达力上限。
  • 会写出滚动优化的标准形式：代价函数（跟踪 Q、控制 R）、约束（力上限、执行器饱和）、终端代价，理解"只执行第一个控制量"的原因。
  • 能实现一个 20 行级的投影梯度 QP 求解器，并用"热启动 + 软约束罚函数"处理实时性与约束放宽。
  • 能说清 MPC 的三笔代价：环境模型依赖（K̂env、x̂e 须先辨识/标定）、在线算力、以及"预测不等同于无源性"，接触稳定性仍要单独审查。

背景与动机

阻抗控制、导纳控制、滑模、反步，前面所有方法有一个共同点：它们都是反应式的。力传感器测到什么，控制器才响应什么；机器人不理解"前方 5 mm 处有工件"，也不会提前减速。这在慢速接触里没问题，一旦接近速度提高，灾难就来了：9 mm 刚度的例子先不看，直接算，2 kg 末端以 0.25 m/s 接近 3×104 N/m 的工件，若靠 100 N/m 的软阻抗"临时刹车"，弹性储能需要 ½mv² = 0.0625 J，刹车距离 √(2×0.0625/100) = 35 mm，接触力峰值约 60 N。问题出在控制律里没有"未来"这个变量，与控制器快慢无关。

模型预测控制（model predictive control, MPC）补的正是这块：它用环境模型预测未来几百毫秒内的接触状态，在"力不超过 Fmax、执行器不饱和"的约束下优化一段控制序列，并且只执行第一步，下一次采样再重新优化（滚动时域，receding horizon）。每次都有完整的前瞻，所以机器人可以在接触发生之前就开始制动。

它解决的问题很具体：带硬约束的柔顺接触，精密零件的力上限、薄壁件的接近速度限制、狭窄空间的位姿护栏。代价同样具体：需要一个可用的环境模型（K̂env 和表面位置，来自第 052 章的辨识或标定）、一个能实时求解的优化问题，以及"预测模型错了约束就错"的清醒认识。

核心原理

1. 预测模型：把"接触会发生什么"写成离散方程

沿任务方向，状态取 z = [x, v]ᵀ（位置、速度），控制输入 u 是机器人施加的力。接触力由环境模型给出 F = K̂env(x − x̂e)，方向与压入相反，于是连续动力学是

m·v̇ = u − K̂env·(x − x̂e) m：末端等效质量（kg）；K̂env：环境刚度估计（N/m）；x̂e：表面位置估计

用显式欧拉离散（1 ms 周期足够小），得到线性预测模型：

xk+1 = xk + vkΔt， vk+1 = vk + Δt·(uk − K̂env(xk − x̂e))/m 矩阵形式 zk+1 = Azk + Buk + c，A = [[1, Δt],[−ΔtK̂env/m, 1]]

线性化的代价是"接触开关"（未接触时 F 应为 0）被简化掉了，但工程上可以接受：MPC 关心的是接触前后的几十毫秒，且总是保留安全余量；接触开关的非线性用"约束松紧"来补偿（后文软约束会展开）。把模型递推 N 步，当前位置 zk 与未来控制序列 U = [u0, …, uN−1] 就唯一决定未来位置序列：X = Φ·zk + Γ·U。这个线性关系是整个实时求解的基础。

2. 代价函数与约束：把任务目标翻译成优化问题

每个控制周期求解：

minU Σi=1..N Q·(xi − xref)2 + Σi=0..N−1 R·ui2 + Qf(xN − xref)2 Q：跟踪权重；R：控制权重；Qf：终端代价；xref：期望位置（通常由力目标折算：xref = x̂e + Fd/K̂env）

约束有三类：执行器饱和|ui| ≤ umax（力控机器人 ±150 N 是常见量级）；力上限，通过环境模型折算成位置上限 xi ≤ xe + Fmax/K̂env（这也是"用位置管理力"思想的又一次运用）；速度上限|vi| ≤ vmax（保护人员与线缆）。三个权重各有职责：Q 决定"跟着参考走得多紧"，R 决定"为省力愿意偏离多少"，Qf 决定"最终状态有多重要"，它是 MPC 稳定性的关键，理论基础是"终端代价等于无穷时域的李雅普诺夫函数"，工程上取 Qf = 5–20 倍 Q 即可获得良好行为。

工程直觉：MPC 的代价函数是一台"优先级天平"，Q 与 R 的相对大小决定了机器人愿意用多大的力去追参考；而约束是完全没有商量余地的红线（硬约束）或高权重软墙（软约束）。前瞻之所以有效，是因为约束在整个预测窗口里同时生效：机器人发现"照着现在的速度冲下去，第 8 毫秒就会吃掉 1.5 mm 的位形、力到 45 N"，于是从第 0 毫秒就开始制动。

3. 滚动优化：为什么只执行第一步

每次采样都重新求解并只执行 u0。这样做有三个理由：（1）模型误差与环境扰动，预测不可能全对，下一拍用更新后的实测状态重新预测，等于对模型误差的自然闭环；（2）约束的时变，任务阶段、安全区、抓取状态都在变；（3）稳定性的归纳，如果每个窗口都可行、终端代价足够大，滚动执行可以保证闭环稳定（递归可行条件下的标准结论）。实现上有两个关键工程技巧：热启动（把上一周期的解平移一位作为初值，迭代次数可以少很多）与软约束（把力上限写成大权重罚函数，牺牲一点严格性换取永远有解）。

4. 代价与边界：模型、算力、稳定性话术

第一笔代价是模型依赖：K̂env 低估一半，力上限折算的位置约束就放大一倍，红线漂移，约束形同虚设；低估表面位置会把制动点放在工件内部。这两个量必须来自辨识（第 052 章）或工艺标定，且都应有保守裕量。第二笔代价是算力：N = 20–40、每毫秒求解一次，即使线性模型的小 QP 也需要几百次浮点运算量级；真正让 MPC 上机器人实时系统的做法是稀疏/热启动求解器、显式 MPC 查表或降低求解频率（外环 100 Hz 求解、内插执行）。第三笔是理论边界：MPC 优化的是预测性能，它不自动带来无源性；接触稳定性的论证仍要回到环境模型与阻抗设计本身。诚实说法是：MPC 负责"行为层"的约束与前瞻，稳定性认证仍由第 015、016 章的框架承担。

实现思路与设计

  1. 辨识环境参数：K̂env 用第 052 章的按压力—位移回归（如 3×104 N/m），x̂e 用标定或寻面程序；两者都取保守值（刚度高估 20%、表面位置外推 0.2 mm）。
  2. 选参数：Δt = 1 ms；N = 20–30（前瞻 20–30 ms，覆盖"接近速度 × 窗口"的需求）；Q = 5×105（以米为单位的代价）、R = 3×10−5、Qf = 10Q；umax = 150 N；Fmax = 30 N ⇒ xlim = Fmax/K̂env = 1.0 mm。
  3. 构建预测矩阵：Φ、Γ 由 (A, B) 递推生成（代码片段 1）；只在初始化时算一次。
  4. 求解器：投影梯度（把无约束梯度步投影到 [−umax, umax]），步长取代价函数曲率的 Lipschitz 上界的倒数；软约束的越限项以梯度形式加进来。
  5. 滚动循环：读 x、v → 求 u0 → 下发 → 热启动下一次求解。前 10 拍可多迭代几次（冷启动），稳态 20–30 次迭代足够。
  6. 安全兜底：MPC 之外并行一层"硬限幅 + 看门狗"，求解时间超时、状态越出安全区、力读数异常时切换到"保持当前柔顺参数 + 减速"的保底逻辑（第 098 章）。
设计决策：为什么力上限用"软约束 + 大权重"？纯硬约束行不行？

硬约束在理论上更漂亮，但它有两个工程软肋：（1）可行性，若当前速度太大、制动距离超过剩余行程，硬约束的 QP 无解，控制器"死机"；软约束总能给出一个"尽力而为"的解，而且越限多少在解里看得见；（2）算力，软约束把不等式变成罚函数，投影梯度可以直接求解，省掉了通用的 active-set 或内点法。工程化的折中是：软约束保底 + 越限监控 + 更远的"绝对安全区"用硬逻辑拦截（比如到位形 1.5 mm 直接切安全停止）。约束的层级化，软墙在前、硬墙在后，比任何单一方法都可靠。

关键代码与解读

片段 1：迷你 MPC（预测矩阵 + 软约束 + 投影梯度）

import numpy as np

class ContactMPC:
    """一维接触任务的迷你 MPC：预测环境反力、软约束力上限、投影梯度求解。"""
    def __init__(self, m=2.0, k_env=3e4, x_e=0.0, dt=1e-3, N=25,
                 q_pos=5e5, r_u=3e-5, rho_soft=5e8, u_max=150.0, f_max=30.0):
        self.m, self.k_env, self.x_e = m, k_env, x_e
        self.dt, self.N = dt, N
        self.q, self.r, self.rho = q_pos, r_u, rho_soft
        self.u_max = u_max
        self.x_lim = x_e + f_max / k_env      # 力上限折算位置上限：1.0 mm
        # --- 预测矩阵：X = Phi*z_k + Gamma*U（初始化时算一次，实时只做矩阵乘） ---
        A = np.array([[1.0, dt], [-dt * k_env / m, 1.0]])
        B = np.array([0.5 * dt * dt / m, dt / m])
        self.Phi = np.zeros((N, 2))
        self.Gamma = np.zeros((N, N))
        for i in range(N):
            Ai = np.linalg.matrix_power(A, i + 1)
            self.Phi[i] = Ai[0]               # 第 i+1 步位置对初始状态的灵敏度
            for j in range(i + 1):
                self.Gamma[i, j] = (np.linalg.matrix_power(A, i - j) @ B)[0]
        # 投影梯度步长：1/L，L 取代价函数曲率的上界（保证迭代单调下降）
        curv = 2.0 * (self.q + self.rho) * np.linalg.norm(self.Gamma, 2) ** 2 + 2 * self.r
        self.alpha = 1.0 / curv
        self.u_prev = np.zeros(N)             # 热启动缓存：上一步的解

    def solve(self, x, v, x_ref, iters=60):
        z = np.array([x - self.x_e, v])       # 预测坐标：相对环境表面
        Pref = np.full(self.N, x_ref - self.x_e)
        U = self.u_prev.copy()                # 热启动：少迭代也能收敛
        for _ in range(iters):
            X = self.Phi @ z + self.Gamma @ U          # 位置预测
            viol = np.maximum(0.0, X - self.x_lim)     # 软约束：越限产生惩罚梯度
            grad = 2 * self.q * self.Gamma.T @ (X - Pref) \
                 + 2 * self.rho * self.Gamma.T @ viol \
                 + 2 * self.r * U
            U = np.clip(U - self.alpha * grad, -self.u_max, self.u_max)
        self.u_prev = np.roll(U, -1)          # 平移一位作为下一拍初值
        self.u_prev[-1] = U[-1]
        return float(U[0])                    # 滚动时域：只执行第一个控制量

解读：这只 30 行的求解器包含了 MPC 的全部要素。（1）Phi/Gamma 只算一次：预测矩阵是常矩阵（线性时不变模型），实时计算量与 N² 成正比、与"重新递推"无关。（2）梯度里三项对应三件事：跟踪（q）、软约束（rho）、省力（r）；np.maximum(0.0, X - x_lim) 让越限才有惩罚，未越限时梯度为零，这是罚函数法的标准写法。（3）np.clip 投影到执行器饱和盒，保证每一步输出都物理可达。（4）热启动的平移逻辑（np.roll）利用了"两个相邻周期的解几乎相同"的时不变性，实测能把迭代次数从 200 降到 30 以内。

片段 2：纯阻抗 vs MPC 的接近对照实验

def simulate(controller, x0=-0.0, v0=0.25, n=800, dt=1e-3):
    """从"刚接触、带 0.25 m/s 接近速度"开始，比较力峰值与稳态表现。"""
    m, k_env, x_e, x_ref = 2.0, 3e4, 0.0, 0.5e-3
    x, v, peak = x0, v0, 0.0
    f_log = []
    for i in range(n):
        f_env = k_env * (x - x_e) if x > x_e else 0.0
        u = controller(x, v, f_env)
        v += (u - f_env) / m * dt            # 被控对象：控制力 - 接触反力
        x += v * dt
        peak = max(peak, f_env)
        f_log.append(f_env)
    return peak, f_env, np.mean(np.array(f_log[400:]))

mpc = ContactMPC()
# 纯阻抗基线：软弹簧阻尼（K=100 N/m、D=2sqrt(Km)≈28 N*s/m），无前馈
K_i, D_i = 100.0, 28.0
u_imp = lambda x, v, f: -K_i * (x - 0.5e-3) - D_i * v
u_mpc = lambda x, v, f: mpc.solve(x, v, x_ref=0.5e-3)

for name, ctrl in (("纯阻抗", u_imp), ("MPC  ", u_mpc)):
    pk, f_end, f_mean = simulate(ctrl)
    print(f"{name}  峰值力={pk:6.1f} N  末态力={f_end:5.1f} N  均值力={f_mean:5.1f} N")

解读：预期对照，纯阻抗从 0.25 m/s 冲进来，靠 100 N/m 的软弹簧"刹车"，峰值力 50 N 量级（远超 30 N 红线）；MPC 在预测窗口里发现"照此下去第 8 毫秒就吃穿 1 mm"，从第一拍就输出接近 −150 N 的制动，峰值压到 30 N 附近，随后平滑回落并稳定。两个实现细节：（1）起始点选在"刚接触"（x0 = 0、v0 = 0.25 m/s），把考察重点集中在制动窗口，避免自由段模型误差干扰对照；（2）f_log[400:] 只统计后半段，稳态指标不被瞬态污染。注意纯阻抗的末态力接近零，与 15 N 目标差距极大，没有力前馈的稳态偏差（第 086 章的结论）在这里同时显现。

片段 3：前瞻长度与参数敏感性一览

def horizon_study(v0_list, N_list):
    """扫描接近速度与预测长度，给出"最迟制动时刻"够不够的结论。"""
    m, k_env, f_max = 2.0, 3e4, 30.0
    x_lim = f_max / k_env                     # 力上限对应的位置余量（m）
    for v0 in v0_list:
        t_hit = x_lim / v0                    # 不制动时"吃穿红线"的时间
        for N in N_list:
            T_pred = N * 1e-3                 # 预测窗口（s）
            ok = "够" if T_pred >= t_hit else "不够"
            print(f"v0={v0:5.2f} m/s  N={N:2d}  窗口={T_pred*1000:4.0f} ms  "
                  f"吃穿时间={t_hit*1000:4.1f} ms  前瞻: {ok}")

horizon_study([0.10, 0.25, 0.50], [10, 25, 40])

解读：这张表回答选 N 时最常见的疑问，"窗口多长才够？"。基准是最坏情况时间 thit = xlim/v₀：以 0.5 m/s 接近、力限对应 1 mm 行程，仅 2 ms 就会越限；N = 10 的 10 ms 窗口看似够用，但把制动时间、采样延迟与求解时间加起来就没有裕量，N = 25 才留得下缓冲。还要注意两个隐含前提：（1）窗口必须≥制动时间 + 采样延迟 + 求解时间（真机上约 2–4 ms）；（2）当前速度 v₀ 由差分估计，本身的 5 ms 滞后也要算进预算。所以工程建议：N 取"理论需要"的 1.5–2 倍，缺少算力时优先缩短控制周期，不砍窗口。

常见坑

  • 环境刚度辨识太乐观：K̂env 低估时 xlim = Fmax/K̂env 被放大，力红线上浮。修复：取辨识值的 1.2 倍作为规划参数，并每批次复标。
  • 把预测窗口当成"越短越省算力"：窗口短于 thit 时 MPC 看不见红线，行为退化成纯阻抗。修复：用片段 3 的表算 thit，窗口取 1.5–2 倍，并给制动加速度留裕量。
  • 冷启动每拍 200 次迭代：拍间解几乎相同却不做热启动，算力浪费一个数量级，控制器在重载时"掉拍"。修复：热启动 + 20–30 次迭代；极端情况下 100 Hz 求解、内插执行。
  • 软约束权重给小了：rho/q 比例不足时，越限惩罚顶不过跟踪吸引，MPC"明知故犯"。修复：rho ≥ 10³q；同时监控越限量的时间历程，做工艺报警。
  • 忘记 MPC 不保证无源性：模型不准时预测失配，与硬环境的相互作用仍可能振铃。修复：接触段叠加"阻抗兜底"（即使 MPC 输出异常，底层仍是柔顺的弹簧阻尼），并降低 Q/R 吸引强度（追求更"听话"，放弃一味"用力"）。

练习与思考

    提示
    xlim 是"用位置表达力"的换算；K̂ 低估 30% → 位置余量放大到 1.43 倍 → 实际力可达 1.43Fmax。这就是配 20% 保守裕量的原因。
  2. 用片段 2 的代码，把 Ki 从 100 提到 500、2000 N/m，记录峰值力。解释为什么"把阻抗调硬"能降低峰值但手感变差，而 MPC 不需要变硬也能压住峰值。★★
    提示
    峰值 ∝ v₀/ω，ω = √((Ki+Kenv)/m) 基本被 Kenv 锁定，Ki 从 100→2000 只能把峰值从 40 N 级压到 30 N 级，且稳态力偏差随 Ki 上升；MPC 用"提前制动"减小碰撞能量，不改变接触刚度。
  3. 把 N 从 25 减到 8、再增到 40，记录峰值力与单拍求解时间（用 time.perf_counter 测）。给出你的"性能/算力"折中方案。★★
    提示
    N=8 的窗口 8 ms 刚够覆盖 0.25 m/s 对应的 thit = 4 ms，叠上制动与延迟后裕量不足，峰值回升；N=40 峰值不再改善但求解时间近似 N² 增长。折中点通常 N = 20–30。
  4. 设计实验：让 K̂env 保持 3×104、把真实环境刚度改为 5×104（更硬的工件），观察 MPC 的越限量与纯阻抗的峰值变化，并提出两条缓解措施。★★★
    提示
    更硬的环境 → 同样位置对应更大力量，MPC 软约束会出现可测的越限；缓解：把规划用刚度上调 20–30%，或把 xlim 在标称值上再内缩 0.2 mm。

小结

  • MPC 解决的是"带硬约束的前瞻式柔顺"：用环境模型预测未来状态，在力上限/饱和约束下滚动优化。
  • 预测模型：zk+1 = Azk + Buk（线性化接触）；代价 J = ΣQ(x−xref)² + ΣRu² + Qf(终点误差)²；约束：|u| ≤ umax、x ≤ xe+Fmax/K̂env。
  • 滚动时域只执行第一步；热启动把在线迭代压到 20–30 次；软约束保证任何状态都有解，配越限监控。
  • 三笔代价：环境模型（K̂env、x̂e 要辨识、要保守）、算力、以及"预测不保证无源性"的理论边界。
  • 下一章处理另一种不确定性哲学：不假设扰动的界已知，改为优化"最坏情况下"的放大倍数，导纳控制中的 H∞ 控制。
