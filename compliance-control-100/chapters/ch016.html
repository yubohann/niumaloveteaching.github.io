第一篇 · 基础、建模与稳定性

第 016 章：导纳控制稳定性分析

导纳回路与阻抗回路共享同一个特征方程，却活在不同的参数生态里：力滤波躲不掉、虚拟刚度偏小、直流环增益 Kenv/Ka 高得吓人。"越软越怕硬"这条反直觉规律，本章用相位裕度和时域试验把它钉实。

  • 主题：导纳控制 / 接触稳定性与漂移预算
  • 关键公式：1 + KenvA(s)e−sT = 0；Da ≥ 2KenvTeff、σx = σf√(ωn/(4ζKa²))
  • 预计学时：60 分钟
  • 前置章节：第 015 章

学习目标

  • 会从"力→位置→接触力"闭合回路推导导纳回路的特征方程 1+KenvA(s)e−sT=0，并指出它与阻抗回路数学同源、工程不同源。
  • 掌握导纳特有的四条延迟来源：力滤波、采样、总线、内环滞后，会合并成 Teff 并折算成 1/ωc 的等效延迟。
  • 理解"软导纳悖论"：直流环增益 Kenv/Ka 随 Ka 减小而增大，越软的参数越容易与硬环境失稳。
  • 会算位移抖动预算 σx = σf√(ωn/(4ζKa²))，并按允许抖动反推 Ka 下限。
  • 能给出导纳方案的三条设计规则：Da ≥ 2KenvTeff、Teff 压到毫秒级、软手感与接触稳定性的折中放在 τa 上，Ka 不再充当稳定旋钮。

背景与动机

第 015 章给阻抗回路立了"延迟不可怕、阻尼来买单"的规矩：D ≥ KenvT。导纳回路呢？很多团队照搬本体参数（Ka=200、手感柔软），一碰刚性工件就"嗡嗡"振，加大刚度反而更糟，和直觉完全相反。

本章把导纳回路完整推导一遍，回答三件事：为什么导纳的力滤波延迟是结构性的、躲不掉的？为什么"软"在导纳里反而成为高风险方向？软手感与接触稳定到底该用哪个旋钮折中？最后补上导纳的专属课题：由力噪声与偏置引起的位移游走（wander）如何量化、如何按预算反推参数。

核心原理

1. 回路闭合：从力到位、从位到力

取导纳控制器输出偏差 δ（m），通过虚拟导纳 A(s) 把感知到的接触力变成位置修正：δ = A(s)·F（F 为作用在末端的力，正方向沿推力方向；第 002 章的"让位"约定）。机器人实际位置 x = xd + δ（假设内环理想）。环境仍取单侧弹簧：F = −Kenv(x − xe)，x > xe 时有效。把 x 代入力，再考虑力信号经过总延迟 T 才被控制器使用：

F = −Kenv·[ xd + A(s)·e−sT·F − xe ] ⟹ 特征方程： 1 + Kenv·A(s)·e−sT = 0 A(s) = 1/(Mas² + Das + Ka)；回路增益在低频趋于 Kenv/Ka

展开后与第 015 章完全同形：Mas² + Das + Ka + Kenve−sT = 0。这带来一个重要认知：在"虚拟参数相同、延迟结构相同"时，导纳与阻抗的线性稳定边界是同一个；两者的真实差异藏在参数生态与延迟构成里。第 007 章的等效性讨论在稳定性维度上再次得到印证。

2. 四条延迟来源：为什么导纳的 Teff 更大

导纳回路的延迟比阻抗回路多两笔结构性开销：

  • 力滤波（不可省）：力信号直接进积分器，不滤波会发生位移游走（第 002 章）；工程上 τf 常取 3–10 ms，这一项通常就是总延迟的主体。
  • 内环滞后：位置命令由内环兑现，首接近似为 τc ≈ 1/ωc（内环带宽的倒数），3–20 ms 量级；与前几章"内环要快 5 倍"的要求一脉相承。
  • 采样保持 Ts/2 与总线/计算 0.2–1 ms：与阻抗回路相同量级。
Teff = Ts/2 + Tc + τf + 1/ωc 例：1 kHz 采样(0.5)+总线(0.3)+滤波(5)+内环(2) ≈ 7.8 ms，比同平台的阻抗回路常见值大一倍以上

把 Teff 代入第 015 章的判据，导纳的稳定边界立刻缩水：Da ≥ Kenv·Teff（安全系数 2）。第一支直觉：导纳把力"读进来再动"，全过程都在延迟账上；阻抗把力"物理感受、立即响应"，延迟主要在实现细节里。前者天生比后者多 2–5 ms 的债。

3. 软导纳悖论：Kenv/Ka 是真正的环增益

看低频段：A(s) ≈ 1/Ka，回路增益 L(0) = Kenv/Ka。这个比值说明一切：虚拟刚度 Ka 越小（手感越软），同样的接触力产生的位移指令越大，环增益越高。举个数：Kenv=104 N/m，Ka=200 时环增益是 50；Ka=2000 时只有 5，软导纳对硬环境是"高增益回路"，稳定裕度天然更小。这就是现场"越调软越振"的数学原因，与"软=安全"的生活直觉正好相反。

相位裕度的完整读法是：交叉频率 ωc 附近，回路相位 = 导纳环节的相位 + 延迟相位 −ωcT。导纳环节在 ωa=√(Ka/Ma) 以上以 −40 dB/dec 滚降，给高频"兜底"；但如果 Kenv/Ka 很大，交叉频率被推到很远、相位逼近 −180°，延迟再拿走最后一点裕度，振荡就开始了。把两条线索合并，稳健的设计形式是：用 Da 提供阻尼（不去动 Ka），即把导纳的时间常数 τa=Da/Ka 拉长；软手感由小 Ka 负责、接触稳定由大 Da 负责，两个旋钮各司其职。代价是手感的"跟手速度"变慢，τa 从 0.1 s 拉到 0.5 s，响应明显变缓，这是导纳方案绕不开的折中。

4. 位移游走预算：噪声如何变成毫米

导纳的第二类稳定性问题是"广义稳定"：不发散，但被噪声推着游走。白噪声 σf（N）经二阶导纳滤波后的输出标准差有闭式结果：

σx = σf·√( ωn/(4ζKa²) ) ， ωn=√(Ka/Ma) 推导：σx² = (σf²/2π)∫|A(jω)|²dω，用二阶低通积分 πωn/(2ζ) 化入

数值感：σf=0.1 N、Ma=2、ζ=1 时，Ka=200 → σx≈0.79 mm；Ka=500 → 0.40 mm；Ka=1000 → 0.24 mm。这就是"软导纳天生更吵"的定量形式，和第 004 章共振公式同源，但这里给出的是整个频带的积分（第 004 章给的是最坏点）。工程含义：允许的位移抖动决定 Ka 的下限；如果你的任务只能容忍 0.2 mm 抖动，Ka ≥ 1200 N/m 量级，手感立刻变硬，冲突转向"用更干净的传感器/滤波"与"泄漏/死区"组合拳。第二支直觉：导纳的稳定性有两层，发散是"快问题"，靠阻尼和延迟治；游走是"慢问题"，靠刚度下限与滤波治。两层都要预算，缺一层都会在调试后期付出代价。

5. 设计规则汇总（导纳版）

表格里最刺眼的一行是钢件上的 Da ≥ 600：它宣告了"软手感 + 钢件 + 低延迟"三者不可兼得。认清这一点，路线选择就清晰了：软交互任务配中等刚度环境 → 导纳得心应手；钢件上的精密力控 → 阻抗/混合方案更对路；非要导纳上钢件，就接受"不软"（Ka 大）或接受"不跟手"（τa 大），或者上第 019 章的自适应参数。

实现思路与设计

导纳方案上机前的稳定与游走核算清单：

  1. 填 Teff 表：把采样、总线、滤波、内环滞后逐项实测填表（发阶跃测总延迟，再用频谱确认滤波群延迟），得到设计用的总延迟。
  2. 算稳定边界：Kenv,crit ≈ Da/Teff；与任务最硬环境比较，不足 2 倍裕度就调 Da 或压延迟。
  3. 算游走预算：按 σx 公式核对允许抖动；不足就加 Ka、提传感器性能或加重滤波（会反噬延迟，两条线同时核算）。
  4. 核对环增益：Kenv/Ka 超过 10 的环境直接标注"高风险"，预先设计验证试验（推压保持 10 s，看力包络是否发散）。
  5. 参数落地：Ka 定手感、Da=max(2ζ√(KaMa), 2KenvTeff) 取大者、必要时用第 020 章的接触状态切换两套参数。
设计决策：为什么 Da 取 max(手感值, 稳定值)，不取两者折中？

两个值的作用域不同：手感值 2ζ√(KaMa) 服务于"松手不振荡、跟手不发黏"的自由空间体验；稳定值 2KenvTeff 服务于接触回路的相位裕度。任何低于 max 的取值都会在对应场景失效：取手感值会在硬环境振荡；取稳定值会在软环境显得迟钝但可用。当稳定值远大于手感值（比如 600 vs 50），说明"一套参数走天下"已经不可行，要么接受自由空间发黏（τa 从 0.1 s 拉到 0.25 s），要么上接触状态检测 + 参数切换（第 020 章），要么换实现。决策的关键是把这笔账摆给任务方："要钢件上不振荡，手推响应就得从 0.1 s 降到 0.25 s，你选哪个？"

关键代码与解读

片段 1：相位裕度计算器，环增益与延迟的合成账

import numpy as np

def phase_margin(k_env, M_a, D_a, K_a, T):
    """导纳回路 L=K_env·e^(−sT)·A(s) 的相位裕度（度）。负值=不稳定。"""
    ws = np.logspace(-1.0, 3.5, 40000)
    jw = 1j * ws
    Ls = k_env * np.exp(-jw * T) / (M_a*jw*jw + D_a*jw + K_a)
    mag = np.abs(Ls)
    # 找 |L| 穿越 1 的频率（第一个穿越点决定裕度）
    idx = np.where((mag[:-1] - 1.0) * (mag[1:] - 1.0) <= 0.0)[0]
    if len(idx) == 0:
        return 180.0                       # 环路增益始终小于 1
    w_c = ws[idx[0]]
    L_c = k_env * np.exp(-1j * w_c * T) / (K_a - M_a*w_c**2 + 1j*D_a*w_c)
    pm = 180.0 + np.degrees(np.angle(L_c))
    return pm - 360.0 if pm > 180.0 else pm

T_eff = 0.006                              # 滤波5ms+采样0.5+总线0.5：典型导纳平台
print(f"{'K_env':>9} {'软参数PM':>9} {'重阻尼PM':>9}  (软:D=20；重:D=120)")
for k_env in (1e3, 3e3, 1e4, 3e4, 1e5):
    pm_soft = phase_margin(k_env, 2.0, 20.0, 200.0, T_eff)
    pm_damp = phase_margin(k_env, 2.0, 120.0, 200.0, T_eff)
    tag = "←失稳" if pm_soft < 0.0 else ""
    print(f"{k_env:9.0f} {pm_soft:9.1f} {pm_damp:9.1f}  {tag}")

解读：这张表把"软导纳悖论"变成了两列数字。软参数列（D=20，即 τa=0.1 s 的"舒服手感"）在 Kenv 从 1e3 涨到 3e3 时相位裕度快速消耗，到 3e3 已接近临界（PM≈2°），1e4 起转为负值，与解析边界 D/T=20/0.006≈3300 完全对得上。重阻尼列（D=120）把整个表右移：1×104 时仍有约 25°、6×103 时约 42°，到 3×104（超过 120/0.006=2×104 的对应边界）转为负值。两列都在讲同一件事：导纳平台的 Teff=6 ms 决定了"每 1 份阻尼只买 1/0.006≈167 N/m 的允许环境刚度"，而软手感路线天生给不出大阻尼。最后提醒一个读表细节：相位裕度 0° 附近（比如软参数×3e3，PM≈2°）不能算作"刚好能跑"，任何轻微扰动都会激发振荡；工程上要求 ≥30° 才算可用，因此真正可用的档位要在 0° 边界基础上再保守一截。

片段 2：时域复现，从"一碰就振"到"稳住"

def run_adm(k_env, D_a, M_a=2.0, K_a=200.0, T=0.006, dt=1e-3, t_end=4.0):
    """δ 二阶导纳 + 延迟回路；返回末段/前段力波动幅度（标准差）比（>1 发散）。"""
    n_delay = max(1, int(round(T / dt)))
    buf = np.zeros(n_delay)
    d, vd, f_log = 0.0, 0.0, []
    for i in range(int(t_end / dt)):
        # 参考先用 1 秒从 49mm 推到 52mm：让接触发生得温和
        x_d = 0.049 + 0.003 * min(i*dt, 1.0)
        x = x_d + d                                # 内环理想：x = x_cmd
        f_now = -k_env*(x - 0.050)                 # 环境弹簧（保持接触的线性化模型）
        slot = i % n_delay
        f_use = buf[slot]
        buf[slot] = f_now                          # 写入当前，读取 T 秒前
        a = (f_use - D_a*vd - K_a*d) / M_a         # 导纳核（力→位移）
        vd += a*dt
        d += vd*dt
        f_log.append(f_now)
    f = np.array(f_log)
    early = f[int(0.25*len(f)):int(0.50*len(f))].std()   # 1–2 s 波动幅度
    late = f[int(0.75*len(f)):].std()                    # 3–4 s 波动幅度
    return late / max(early, 1e-12)

for tag, k_env, D_a in (("软参数×软环境", 3e3, 20.0),
                        ("软参数×硬环境", 3e4, 20.0),
                        ("重阻尼×硬环境", 3e4, 120.0)):
    g = run_adm(k_env, D_a)
    verdict = "发散" if g > 1.2 else ("收敛" if g < 0.9 else "临界")
    print(f"{tag:>14}: 幅值比={g:5.2f}  → {verdict}")

解读：三个用例对应设计表里的三种判读。软参数×软环境（3e3，低于边界 3.3e3）输出收敛（幅值比约 0.35）：说明"软"在软环境里完全没问题，别误伤。软参数×硬环境（3e4，高于边界约 9 倍）输出发散（幅值比跨越多数量级），接触力包络随时间爬升，这正是现场"嗡嗡声越来越大"的波形。重阻尼×硬环境（同样 3e4，D 提到 120 后边界上移到 2e4，越界倍数从约 9 倍缩到 1.5 倍）：输出仍为发散，但幅值比的数量级显著低于软参数行，"阻尼买边界"的方向一目了然、程度还不够；想看干净收敛，把 k_env 改到 1e4 重跑即可（远低于边界，幅值比将远小于 1）。代码结构上最值得学的是延迟的实现：环形缓冲读写顺序（先读旧值、再写新值）与缓冲长度共同决定实际延迟，差一拍判据的临界点就会系统性偏移；真机复现这个实验时，用同样的方法在力信号链里注入已知延迟，先验证你的"延迟标尺"再谈稳定性。

片段 3：位移游走预算，噪声变毫米的账

def wander(k_a, m_a=2.0, zeta=1.0, sigma_f=0.1, dt=1e-3, t_end=60.0, seed=1):
    """力噪声引起的位移抖动：解析公式 vs 60 秒仿真（含 20 秒统计窗）。"""
    d_a = 2.0 * zeta * np.sqrt(k_a * m_a)
    wn = np.sqrt(k_a / m_a)
    ana = sigma_f * np.sqrt(wn / (4.0*zeta*k_a**2)) * 1e3     # 解析值（mm）
    rng = np.random.default_rng(seed)
    xa, va, tail = 0.0, 0.0, []
    for i in range(int(t_end/dt)):
        f = sigma_f / np.sqrt(dt) * rng.standard_normal()     # 纯噪声：每步方差 σ_f²/dt，等效连续白噪声
        a = (f - d_a*va - k_a*xa) / m_a
        va += a*dt
        xa += va*dt
        if i > int((t_end - 20.0)/dt):                        # 最后 20 秒
            tail.append(xa)
    return ana, float(np.std(tail) * 1e3)

print(f"{'K_a':>6} {'解析σ(mm)':>10} {'仿真σ(mm)':>10}   （σ_f=0.1N）")
for k_a in (200.0, 500.0, 1000.0, 2000.0):
    ana, sim = wander(k_a)
    print(f"{k_a:6.0f} {ana:10.3f} {sim:10.3f}")

解读：预期两列数字大体吻合（本例差约 5%，差异来自仿真初态与有限样本；换随机种子会有数个百分点波动）。读表的结论：抖动按 Ka−3/4 规律下降（因为公式里 ωn∝√Ka、分母 Ka²，把 Ka 翻 4 倍，σ 只降到约 0.35 倍），比"线性"慢得多；想把本例的 0.79 mm 压到 0.2 mm（除以 4），刚度要从 200 加到约 1250 N/m（约 6.3 倍），这条曲线就是"软导纳抖动难治"的根源。工程上的破局组合：优先降低 σf（更好的传感器、机械隔振、姿态补偿），它是线性项，0.1 N 降到 0.03 N，抖动直接除以 3；其次才是抬 Ka。最后别忘了第 002 章的死区与泄漏：死区砍掉噪声底，泄漏把超低频分量拉回（把方差从 20 秒窗里再削一截），两者对"游走"的改善不在本公式里，却常常是现场最见效的一刀。

常见坑

  • 照搬阻抗参数直接上手导纳：同样的 K/D 在导纳平台上 Teff 大一倍以上，边界直接对折。修复：Teff 独立核算，Da 按导纳平台重算。
  • 以为"调软=更安全"：Ka 越小环增益 Kenv/Ka 越高，更接近失稳。修复：软手感靠"小 Ka + 大 Da"的组合，单减 Ka 是反向操作。
  • 加滤波治振荡：滤波时间常数本身是延迟，加在大延迟系统上是"以债还债"。修复：优先检查滤波器（噪声真的需要那么重？）、采样率与内环带宽，滤波放不大再考虑。
  • 忽略位移游走预算：发散问题都测过了，交付后用户抱怨"机器人静态时自己在毫米级晃"。修复：把 σx 公式纳入参数评审，与允许抖动比对。
  • 在临界参数下"能跑就交"：相位裕度 5°–10° 的系统能活几分钟，直到温度变化或工件换了批次。修复：目标裕度 ≥30°，并在最硬环境、最差姿态、最高温度三条件下复测。

练习与思考

  1. 推导导纳回路的特征方程：从 δ=A(s)F、x=xd+δ、F=−Kenv(x−xe) 出发，写出 1+KenvA(s)e−sT=0，并说明它与阻抗版本同形的条件。★
    提示
    把 x 代入 F 得到含 F 与 A(s)e^{−sT}F 的方程，移项即得；同形的条件是"虚拟参数与延迟结构一致"，差异在参数生态。
  2. 用片段 1 做三组扫描（Kenv=104 固定）：（a）固定 D=20、T=1 ms，把 Ka 从 200 扫到 5000；（b）固定 Ka=200、T=1 ms，把 D 从 20 扫到 400；（c）固定 Ka=200、D=120，把 Teff 从 1 ms 扫到 8 ms。三组分别回答：哪个旋钮能真正把 PM 抬过 30°、哪个几乎无效、延迟每多 1 ms 吃掉多少度？★★
    提示
    （a）PM 从 4.1° 只挪到 5.0°，几乎不动：Ka 管的是稳态环增益，交叉频率附近的相位由 Ma 与 Da 决定；（b）PM 从 4.1° 一路升到 82.6°（D=100 时 35.5°）；（c）每毫秒约 −3.4°，30° 上限在 T≈4.7 ms。结论：D 与 T 是两个有效旋钮，Ka 不是。
  3. 用片段 2（固定 D=120）把 k_env 改到 1e4、2e4、4e4，记录三种幅值比，解释边界（≈2e4）附近的敏感性，并给出你会上机的裕度线。★★
    提示
    1e4 收敛（幅值比远小于 1）、2e4 名义在边界上（本例 0.07 仍收敛，但延迟实现差半拍结论就会翻转，这正是别在边界附近工作的原因）、4e4 发散；工程上取 0.5×边界作为使用上限。
  4. 推导位移抖动公式 σx=σf√(ωn/(4ζKa²))：写出 σx² 的频域积分式，用二阶低通积分公式 πωn/(2ζ) 化简。★★★
    提示
    A(s)=(1/K)·H(s)，H 为归一化二阶低通；∫|H|²dω=πωn/(2ζ)；σx²=σf²/(2π)·(1/K²)·πωn/(2ζ)。
  5. 设计一个"导纳方案可行性评审"：输入为任务（最硬环境、允许抖动、响应时间要求）与平台（Teff、噪声、内环带宽），输出为"可做/需换方案/需自适应"三态判定。写出判定流程与两个数值例子。★★★
    提示
    流程：Da 稳定下界 → 与响应时间要求算出的 τa 冲突？→ 检查 Ka 抖动下限与 D 下界是否同时可满足；例 1：软环境+0.5mm 抖动 → 可行；例 2：钢件+0.2mm 抖动+0.1s 响应 → 三约束互斥，判"需换实现或自适应"。

小结

  • 导纳回路特征方程 1+KenvA(s)e−sT=0 与阻抗同形；差异在工程：导纳的 Teff 多出力滤波与内环滞后两笔，Da ≥ 2KenvTeff。
  • 软导纳悖论：环增益 Kenv/Ka 随 Ka 减小而升高；"更软"在硬环境上是高风险方向。软手感与接触稳定用两个旋钮分别负责：小 Ka 定手感，大 Da（长 τa）定稳定。
  • 位移游走按 σx=σf√(ωn/(4ζKa²)) 预算，Ka 按 −3/4 次幂改善；降传感器噪声是线性收益，优先动它。
  • 工程规则四条：Teff 压到毫秒级、Da 取 max(手感, 稳定)、Kenv/Ka ≤10、目标裕度 ≥30° 并在最坏工况复测。
