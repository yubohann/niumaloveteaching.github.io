第一篇 · 基础、建模与稳定性

第 017 章：与环境刚性接触的阻抗控制

钢板不会让步：0.1 mm 的越界就是 10 N。刚性接触由"接近—冲击—保持"三段组成，每段有自己的力预算与主导参数。本章给出冲击峰值、碰跳抑制与力分辨率的完整账本。

  • 主题：阻抗控制 / 刚性环境工况分析
  • 关键公式：Fpeak ≈ vc√(MdKenv)；ΔF = Kenv·Δx（位姿分辨率）
  • 预计学时：55 分钟
  • 前置章节：第 016 章

学习目标

  • 会定义"刚性环境"的工程判据，并解释为什么刚性接触把任务拆成接近—冲击—保持三段。
  • 能完成刚性接触的全套定量计算：冲击峰值、穿透深度、稳态力、位姿分辨率对力的量化影响。
  • 掌握"力引导接近"的着陆策略：不知道工件表面位置，如何靠力阈值平滑停靠而不依赖精确标定。
  • 理解碰跳（chatter）的成因与三条抑制手段：接触相阻尼、接近速度限制、参数平滑切换。
  • 会为既定力预算反推接近速度上限、位置分辨率需求与最坏冲击的应对流程。

背景与动机

第 003 章讲了"参数怎么改变接触力"，本章讲"刚性接触这件事本身怎么打"。为什么单独拎出来？因为金属件的两个数字改变了一切：Kenv≈105 N/m 时，0.1 mm 的位置误差等于 10 N 的力误差，0.01 mm 的分辨率才有 1 N 的力分辨率，位置系统里微不足道的量，在钢件上都是力的大事件。接近快一点，冲击峰值成倍涨；阻尼小一点，接触后持续碰跳；参数切换没有过渡，接触瞬间就是一次阶跃冲击。

幸运的是，阻抗控制对付刚性环境有一个漂亮的结构性质：稳态力只由虚拟刚度与位置偏置决定，与环境位置是否精确已知无关。这意味着"找表面"可以不靠标定，靠力阈值逼近；"压紧"可以不靠传感器，靠偏置。本章把这两件事都做成可复制的流程。

核心原理

1. 刚性环境的判据与三段式任务分解

工程上把满足下式的环境视为"刚性"：

Kenv ≥ 100·Kd（或用绝对量级：Kenv ≥ 105 N/m） 含义：环境刚度至少是虚拟刚度的百倍，等效刚度 Keq≈Kd，穿透量小到可忽略

此时接触过程必须分段处理，因为三段的物理主角不同：

  • 接近段（自由空间）：主角是运动规划，速度曲线决定携带的动能，也决定冲击预算；
  • 冲击段（毫秒级）：主角是惯量与阻尼，动能被弹簧吸收，峰值力由能量守恒支配；
  • 保持段（稳态接触）：主角是刚度与偏置，稳态力 F=Keq·偏置，同时延迟与阻尼决定稳定性（第 015/016 章）。

三段对应三套验收标准，千万不要用一种"手感"参数贯穿：接近要快而稳、冲击要软、保持要准，它们对 Md、Dd、Kd 的诉求本来就不同。

2. 冲击段：能量账与峰值公式

接触瞬间，机器人带着速度 vc 撞上刚度 Kenv 的环境。在峰值发生的极短时间里，虚拟弹簧（Kd≪Kenv）与阻尼做功都可不计，动能几乎全部转成环境弹簧的势能：

½Mdvc² = ½Kenvξ² ⟹ ξmax = vc√(Md/Kenv) ， Fpeak = Kenvξmax = vc√(MdKenv) ξmax：最大穿透（m）；例：vc=0.05 m/s、Md=1.5 kg、Kenv=105 → ξ≈0.19 mm、Fpeak≈19.4 N

注意三点。第一，峰值与速度成正比：v 减半，冲击减半，接近段的减速是最便宜的安全投资。第二，穿透量与 √Kenv 成反比：钢件的 0.19 mm 放在橡皮（102）上会是 6 mm 的"陷进去"（冲击力也从 19.4 N 降到 0.6 N），同一公式也解释了为什么软环境的冲击问题轻得多。第三，Md 影响 √Md：把虚拟质量减到 1/4，冲击减半；但 Md 同时影响保持段的接触阻尼比（第 003 章），别为了冲击把 Md 压太狠导致接触发振，参数得两头算。

冲击之后的"回弹"由阻尼决定：接触阻尼比 ζeff（第 003 章公式，分母含 Kd+Kenv）小于 1 时，系统在平衡点附近振荡，幅值大时会短暂离面，即碰跳。碰跳的判据可以粗看为"回弹速度 > 0 时穿透量跨过零"，抑制手段：加大 Dd、限制 vc、或在检测到接触后 10–30 ms 内把参数平滑过渡到"接触相"（第 020 章会做完整版，本章先给出最小实现）。

3. 保持段：偏置产生力，分辨率决定精度

刚性环境的"友好之处"在这里充分展现：稳态时 Fss = Keq(xd − xe)，Keq ≈ Kd（因为 Kenv≫Kd）。你不需要知道 xe 的精确值，力由"参考点相对表面的偏置"决定，误差只影响穿透深度，不影响力的大小（这个性质对未知工件位置是巨大的工程便利）。但"位置分辨率 → 力分辨率"的换算必须提前算：

ΔF = Kenv·Δx（穿透方向） 例：Kenv=105：编码器 10 µm → 1 N；1 µm → 0.1 N；0.1 µm → 0.01 N

三个数字直接对应三类任务：粗糙压紧（±1 N 即可）配 10 µm 分辨率；常规装配（±0.1 N）要 µm 级；精密压配（±0.01 N）需要亚微米级，或者放弃"位置造力"路线，改用导纳/力闭环（因为闭环可以把分辨率需求从"绝对位置精度"转成"力传感器精度"）。另外，速度通道也有对应账：接触保持时关节速度若抖动 εv，经阻尼项 Dd·εv 直接入力信号；1 mm/s 的速度噪声配 Dd=100 N·s/m 就是 0.1 N 的力纹波，刚性接触下"速度估计滤波"不是可选项。

4. 接近段：力引导着陆

既然不需要知道表面位置，接近策略就可以完全摆脱"标定依赖"：用一个"力引导速度律"边推边降速。设计目标是把接触瞬间的速度压到预算之内，形式可以取：

vcmd = clip( (Fth − F̃) / Dap, −vmax, vmax )， F̃ 为滤波后的接触力 Fth：着陆力阈值（如 5 N）；Dap：接近虚拟阻尼（N·s/m）；速度下界取负值，力超阈值时允许回退

物理读法：这相当于在接触方向挂了一个"虚拟阻尼器"，F̃ 接近阈值 Fth 时把速度"捏"下来；无接触时机器人以 min(Fth/Dap, vmax) 匀速趋近。速度下界取负值，力超过阈值时允许回退，过冲才收得回来；只许前进的实现会把第一次过冲永久留在力上。参数选择有两条约束：其一，力环时间常数 Dap/Kenv 不能远小于滤波与速度环的滞后 τlag=τf+τv，否则"力一升、速度快退"的循环会振荡（片段 1 里 Dap=60 恰好踩中这个坑）；其二，接触速度 ≈ Fth/Dap（被 vmax 封顶），冲击峰值可用 Fth + Kenv·vc·τlag 作保守估计，由冲击预算 vc,max = Fbudget/√(MdKenv) 反推 Dap 与 vmax。工程直觉：刚性接触的接近段是"边施力边试探"的过程（不只是"走位置"），力量一旦出现就立即让它做功，把动能提前在减速上花掉，避免留到撞击时结算。它的局限也要说清：力信号到达之前已经积累的速度是"刹不住的"（传感器与执行延迟期间照走），所以延迟越重、残余冲击越大，刚性接触把延迟的账从"稳定性"（第 015 章）又掸到了"冲击"上。

实现思路与设计

刚性接触的完整作业流程（以"找面并压紧 20 N"为例）：

  1. 预算先行：确定力上限（如 40 N 报警）、稳态目标（20 N）、冲击预算（如 25 N）；推算 vc,max = 25/√(MdKenv)。
  2. 接近：位置模式趋近到"粗定位余量"（如 5 mm，依赖视觉/示教粗标定），切换力引导速度律进入着陆；vmax 取 20–50 mm/s 量级，Fth 取目标力的 30%–50%。
  3. 接触确认：|F| 超过死区持续 20–50 ms 判定接触；此后把参考点按"每秒 F 增长速度 ≤ 10 N"的节奏推进到目标偏置 Δx=Ftarget/Kd（20 N、Kd=500 → 40 mm）。
  4. 接触相参数：若独立设定接触参数（推荐）：Dcontact = max(2√(Md(Kd+Kenv))·0.7, 2KenvTeff)（兼顾超调与延迟稳定）；否则至少把切换过渡时间设为 20–50 ms。
  5. 保持与撤离：保持段监控力包络（振荡与漂移），撤离按"反偏置斜坡"退到自由空间，确认力归零后再切换运动模式。
设计决策：为什么接触确认要加 20–50 ms 的"持续超过死区"条件？

单帧超阈值可能是噪声、也可能是真正的接触；两种误判代价不同：漏判接触（把真接触当噪声）会让接近速度继续，导致二次冲击；误判接触（把噪声当接触）只是提前进入保持段，多几毫秒的保守动作。持续窗口把两者的平衡点推向稳妥：20–50 ms 窗口配合 0.3 N 死区，噪声（σ≈0.1 N）连续超阈概率极低，而 50 mm/s 的接近速度在 20 ms 内只多走 1 mm，这 1 mm 由力引导律早已在减速段消化。窗口的上限受制动距离约束：窗口越长，确认前"刹不住"的距离越长，把 vmax 与窗口一起设计，别分开调。

关键代码与解读

片段 1：力引导着陆，不标定表面也能软着陆

import numpy as np

def landing_sim(d_ap=300.0, v_max=0.05, k_env=1e5, xe=0.01,
                f_th=5.0, tau_f=0.004, tau_v=0.01, dt=1e-3, t_end=8.0):
    """力引导接近：v = clip((F_th − F̃)/D_ap, −v_max, v_max)，观察接触速度与冲击。"""
    x, v, f_f = 0.0, 0.0, 0.0          # f_f：滤波后的接触力估计
    v_contact, f_peak, f_hist = None, 0.0, []
    for i in range(int(t_end/dt)):
        f = -k_env*(x - xe) if x > xe else 0.0
        # 力滤波：着陆律对噪声敏感，滤波同时带来"刹不住的余量"
        f_f += (f - f_f) * dt / (tau_f + dt)
        # 力引导速度律：力越接近阈值速度越小；可正可负，力超阈时回退
        v_cmd = float(np.clip((f_th - abs(f_f)) / d_ap, -v_max, v_max))
        v += (v_cmd - v) * dt / (tau_v + dt)     # 速度环一阶近似（τ≈10ms）
        x += v * dt
        f_peak = min(f_peak, f)
        f_hist.append(f_f)
        if v_contact is None and abs(f) > 0.5:
            v_contact = abs(v)                   # 首次有效接触时的速度
    tail = np.array(f_hist[-1000:])              # 末段 1 秒
    return v_contact, -f_peak, -tail.mean(), tail.std()

for d_ap in (60.0, 300.0, 1000.0):
    vc, fp, fm, fs = landing_sim(d_ap=d_ap)
    print(f"D_ap={d_ap:6.0f}: 接触速度={vc*1e3:5.1f}mm/s  冲击峰值={fp:6.2f}N  "
          f"末段力={fm:5.2f}±{fs:4.2f}N")

解读：这段仿真演示了"力引导着陆"的两个必要条件。接近速度由 Dap 决定：无接触时速度命令是 Fth/Dap，D_ap=60 时算出 83 mm/s（被 v_max=50 封顶）、D_ap=300 时 16.6 mm/s、D_ap=1000 时只有 5 mm/s；力环越"软"（Dap 越大），趋近越慢、冲击越小（峰值 30.2→14.7→7.9 N）。回退通道是必要条件：速度下界取 −v_max，力超过阈值时机器人往回退，三档的末段力都收敛到阈值 5 N 附近；如果把下界截在 0（只许前进），第一次过冲会永久留在力上。Dap 太小会振荡：D_ap=60 的力环时间常数 60/105=0.6 ms，远小于 τf+τv=14 ms 的总滞后，速度指令跟着力噪声来回翻，末段力呈现 ±6.9 N 的极限环；D_ap=300 起（3 ms，仍比滞后快，但配合回退已经足够）平稳收敛。把 tau_f 改成 0.02 重跑，D_ap=300 档的峰值从 14.7 N 升到 23.0 N：滤波延迟直接转化为冲击成本。真机移植时：f_th 取目标力的 30%–50%，D_ap ≥ 3·Kenv·τlag 起步再按实测下调，并把 vmax 与第 2 节的预算式核对一遍。

片段 2：冲击峰值的速度扫描，公式与仿真对账

def impact_peak(v_c, k_env=1e5, m_d=1.5, d_d=2.0*np.sqrt(500.0*1.5),
                k_d=500.0, dt=2e-5, t_end=0.1):
    """定速撞击仿真：从接触点（x=0）以速度 v_c 进入，返回力峰值。"""
    x, v, f_max = 0.0, v_c, 0.0
    for i in range(int(t_end/dt)):
        f = k_env * x if x > 0.0 else 0.0       # 单侧：墙只推不拉
        # 阻抗方程（第 001 章约定：接触力取负），从接触瞬间开始积分
        a = (-d_d*v - k_d*x - f) / m_d
        v += a * dt
        x += v * dt
        f_max = max(f_max, f)
    return f_max

print(f"{'v_c(mm/s)':>9} {'仿真峰值(N)':>11} {'公式 v√(MK)':>12}")
for v_c in (0.01, 0.02, 0.05, 0.10):
    f_sim = impact_peak(v_c)
    f_ana = v_c * np.sqrt(1.5 * 1e5)
    print(f"{v_c*1e3:9.0f} {f_sim:11.2f} {f_ana:12.2f}")

解读：注意仿真峰值系统性地低于公式值（本例约 −10%），因为公式忽略了三份"能量出口"：阻尼做功、虚拟弹簧 Kd 的压缩能、以及积分步长内已经开始的减速。在线性模型里这些修正与 vc 同阶，所以四行的相对偏差几乎恒定（10% 上下），不随速度漂动。这个偏差方向很重要：公式给出的是保守上界，拿它做安全预算不会偏乐观。步长敏感性也有量级参考：dt 从 2×10−5 加到 10−3，峰值只降约 2%（17.36→16.99 N），说明该工况下步长误差是次要项；要显著"削峰"得把步长加到接近接触时长（此处 π/√(Kenv/M)≈12 ms）的量级，而那时模型物理保真度已经不足。所以步长判据的正确表述是"远小于接触周期"，第 003 章对更硬环境的细化要求也源于此。工程用法：预算阶段用公式（快、保守），验证阶段用细步长仿真或实测（准），两者差 10% 上下即视为模型自洽。

片段 3：碰跳计数，阻尼决定"一次撞"还是"反复撞"

def chatter_count(d_d, v_c=0.03, k_env=1e5, m_d=1.5, k_d=500.0,
                  x_ref=5e-4, dt=2e-5, t_end=0.5):
    """统计碰跳：接触后再次离面（x回落到0以下）的次数与全程峰值。

    x_ref=0.5 mm：参考点压入表面半个毫米，代表"持续轻压"的工况；
    没有这份持续压入，几次回弹后能量耗尽，碰跳难以显现。
    """
    x, v, f_max = 0.0, v_c, 0.0
    in_contact = False
    bounces = 0
    for i in range(int(t_end/dt)):
        f = k_env*x if x > 0.0 else 0.0
        a = (-d_d*v - k_d*(x - x_ref) - f) / m_d
        v += a*dt
        x += v*dt
        f_max = max(f_max, f)
        if not in_contact and x > 0.0:
            in_contact = True                 # 首次接触
        elif in_contact and x <= 0.0:
            in_contact = False                # 离面 = 一次碰跳事件
            bounces += 1
    return bounces, f_max

for tag, d_d in (("轻阻尼 44.7", 44.7), ("接触相阻尼 150", 150.0),
                 ("强阻尼 300", 300.0)):
    n_b, f_m = chatter_count(d_d)
    print(f"{tag:>14}: 碰跳次数={n_b:3d}  过程峰值={f_m:6.2f} N")

解读：这张小表把第 003 章的 ζeff 与现场的"哒哒"声对应了起来。先说前提：代码里 x_ref=0.5 mm 把参考点压进表面半个毫米，机器人每次被弹开都会被虚拟弹簧重新推向墙面，碰跳才会反复；如果参考恰好停在表面，几次回弹后能量耗尽，碰跳现象会弱得多。轻阻尼行（D=44.7，ζeff≈0.06）出现 6 次离面、过程峰值 10.8 N，每次离面都意味着能量重新注入；接触相阻尼行（D=150）离面降到 2 次、峰值 9.0 N；强阻尼行（D=300）只剩 1 次离面后稳定压住，峰值 7.2 N，代价是如果这组参数常驻，自由空间会显得"泡在蜂蜜里"。看代码结构：碰跳计数逻辑极简单（接触状态机 + 离面计数），可以原样搬进真机的健康监控，运行日志里每出现一次碰跳事件就打一条标，长期统计能暴露工件错位、参数漂移、刀具磨损等慢性问题。最后一个实践提醒：碰跳检测在仿真里干净利落，在真机上有传感器噪声与摩擦粘滞，建议用"力掉回零 + 位置速度反向"的双条件确认，避免把一次噪声当成一次碰跳。

常见坑

  • 接近不减速、指望"阻抗挡得住"：阻抗只在接触后才起作用，接触前的动能必须由速度管理。修复：力引导着陆 + vmax 预算，二者缺一不可。
  • 用自由空间阻尼直接碰钢件：ζeff 被 Kenv 稀释成 0.07（第 003 章），必然碰跳。修复：接触相参数或高阻尼常驻（第 020 章参数调度）。
  • 忽略位置分辨率账：10 µm 的重复定位在钢件上就是 ±1 N 的力抖动，验收标准却写着 ±0.5 N。修复：按 ΔF=KenvΔx 反推分辨率，不够就改导纳或加力闭环。
  • 接触确认窗口与速度不联调：确认窗口 100 ms、接近 100 mm/s，确认前已走出 1 cm，直接撞击。修复：窗口 × 速度 ≤ 允许的确认行程（如 1–2 mm），两个参数一起定。
  • 保住"没标定就对不上"的执念：非要把 xe 标到 0.1 mm 才敢干活。修复：刚性环境下稳态力与 xe 精度无关，偏置给足即可；把标定精力省给力信号链。

练习与思考

  1. 从能量守恒推导冲击峰值公式 Fpeak=vc√(MdKenv)，列出被忽略的三个能量出口并说明它们让实际峰值偏高还是偏低。★
    提示
    忽略阻尼做功、Kd 压缩能、控制减速 → 公式把动能全算给环境弹簧，故为保守上界。
  2. 用片段 2 扫描 Kenv（3×104、1×105、3×105），固定 v_c=0.05。验证 Fpeak∝√Kenv，并给出"冲击峰值不超过 20 N"时的 Kenv 上限。★★
    提示
    F=0.05×√(1.5K)：20 N 对应 K≤(20/0.05)²/1.5≈1.07×105 N/m，略高于钢件，说明 5 cm/s 照撞钢件必然超 20 N。
  3. 用片段 1 把 tau_f 从 4 ms 调到 20 ms、f_th 从 5 N 调到 10 N，记录接触速度与冲击峰值的变化，解释哪个改动更危险以及为什么。★★
    提示
    τf 增大→刹得更晚→接触速度与冲击上升（延迟直接变成本）；f_th 增大→降速更晚但阈值更高，双重恶化。τf 是关键项。
  4. 推导"位置分辨率 → 力分辨率"：在 Kenv=105 下，若要求力纹波 ≤0.3 N 且力信号噪声 σ=0.1 N，写出编码器分辨率与阻尼-速度噪声两个约束的联立条件，并给出一个满足条件的参数组（分辨率、Dd、速度噪声限值）。★★★
    提示
    位置通道：Δx ≤ 0.3/1e5 = 3 µm；速度通道：Dd·σv ≤ 0.3 N，如果 Dd=100 则 σv ≤ 3 mm/s（滤波后速度估计很容易达到）。
  5. 设计"找面—压紧—撤离"的完整状态机：列出五个状态、每个状态的转移条件与超时保护，并说明力引导阶段突发过载（如工件放偏）时哪一层先响应。★★★
    提示
    状态：自由趋近→力引导着陆→接触确认→偏置爬升→保持/撤离；超时各自带（如着陆 2 s）；过载先由"力上限监控层"响应（速度清零+回退），状态机随后转移到安全态。

小结

  • 刚性环境判据 Kenv ≥ 100Kd 或 105 N/m；任务分三段：接近（速度）、冲击（能量）、保持（偏置与稳定性）。
  • 冲击峰值 Fpeak ≈ vc√(MdKenv)，与速度线性、与 √Md 成正比；减速是最便宜的冲击预算手段，公式是保守上界。
  • 保持段力与表面位置标定精度无关（F=Keq·偏置），但力分辨率受 ΔF=KenvΔx 约束：钢件上 1 N 需要 µm 级位置，或改用力闭环。
  • 力引导着陆把动能提前交还阻尼；碰跳由 ζeff 与接近速度共同决定，接触相阻尼与参数平滑切换是最小可行的抑制组合。
