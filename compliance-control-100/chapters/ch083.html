第四篇 · 高级柔顺任务与约束

第 083 章：导纳控制中的自适应增益

固定增益的导纳控制器，环境一软就有稳态力误差。本章让虚拟刚度在线"自己找位置"：用一条基于灵敏度符号的梯度自适应律把力误差压下去，并用投影、死区、速率限制与振动冻结四道护栏保证它不反咬系统一口。

  • 主题：导纳控制 / 自适应增益
  • 关键公式：Mdẍc + Ddẋc + Kd(xc−xr) = Fd − Fmeas，K̇d = −γ·ef
  • 预计学时：60 分钟
  • 前置章节：第 082 章

学习目标

  • 理解"自适应增益"与上一章"学习辅助"的本质区别：前者在单次任务内连续改变控制器参数，后者跨轮次只学前馈、不动控制器。
  • 会推导力跟踪型导纳控制的稳态力公式 F = [Fd − Kd(xe−xr)]/(1+Kd/Kenv)，并由它求出灵敏度 ∂F/∂Kd 的符号。
  • 掌握自适应律 K̇d = −γ·ef 的梯度下降来源，能用 J̇ < 0 论证"力误差单调下降"（准静态意义下）。
  • 会设计四道工程护栏：投影限幅、力死区、速率限制、振动冻结；理解变刚度为什么需要"能量视角"的安全监督。
  • 能说明为什么调 Kd 时必须让 Dd 随动（保持阻尼比），以及为什么 Md 一般不动。

背景与动机

导纳控制（admittance control）的工作方式是"测力 → 用导纳方程算出位置修正 → 交给位置内环执行"。它对位置控制型机器人特别友好，但有一个先天软肋：虚拟刚度 Kd 与环境刚度 Kenv 共同决定稳态接触力。同一组参数，在钢件上（Kenv≈105 N/m）力很准；换到橡胶垫上（Kenv≈5×103 N/m），接触力可能差百分之十几到几十；再换到海绵上，误差更大。批量生产里环境批次变化、工装换型、新旧衬垫交替，都逼着你不断手动重调增益。

第 021 章我们见过"基于力误差的阻抗参数调整"，那是启发式地按误差大小加减参数。本章要更系统：先推导力对增益的解析灵敏度，确认它的符号，再用梯度下降构造自适应律，让增益自己收敛到"把力误差消掉"的值。同时要回答一个容易被忽视的问题：增益是随时间变化的量，而变增益的弹簧会在"减刚度"时把之前储存的能量释放出来，如果释放得不合时宜，等于给系统免费充电，可能激振。所以自适应增益不能只有"更新律"，还必须配安全监督。

本章与第 093 章（负载变化适应）的区别也先讲清：本章把增益本身当作可调对象，对付的是环境与工况变化；第 093 章对付的是工具末端质量变化，走的是"辨识负载 → 补偿动力学"的路线。

核心原理

1. 力跟踪型导纳控制：没有"力"这条输出，却要跟踪力

先约定坐标：+x 方向指向环境内部，机器人静止在 x，环境表面在 xe，接触力 F = Kenv(x − xe)。导纳控制器的任务是产生一个"修正位置" xc，满足如下虚拟动力学：

Mdẍc + Ddẋc + Kd(xc − xr) = Fd − Fmeas xr：参考位置（放在名义表面处）；Fd：期望接触力；Fmeas：力传感器读数

逐项读一遍：惯性项 Mdẍc（虚拟质量，单位 kg）与阻尼项 Ddẋc（虚拟阻尼，N·s/m）刻画修正动作的快慢；弹簧项 Kd(xc−xr)（虚拟刚度，N/m）把修正位置"拽回"参考点，防止长时间漂移；右端是驱动源，力误差 ef = Fd − Fmeas 直接当作虚拟力来用。若 Fmeas 不足（ef>0），虚拟质量朝 +x（更深处）加速，机器人越压越深，直到接触力补上；若 Fmeas 过大（ef<0），修正位置退缩，力回落。工程直觉：导纳控制器是一个"力的放大器"，它把"力差"翻译成"位移"，位移又通过环境刚度翻译回力，形成闭环。

2. 稳态力的解析式：Kd 为什么会"抵住"力

接触达到稳态后（ẋc = ẍc = 0），方程退化为弹簧平衡：Kd(xc − xr) = Fd − F。此时 xc = x，与环境模型 F = Kenv(x − xe) 联立：

F = [Fd − Kd(xe − xr)] / (1 + Kd/Kenv) 把 x = xe + F/Kenv 代入弹簧平衡即可得到；分母 1 + Kd/Kenv ≥ 1

这条式子信息量很大。把参考放在名义表面处（xr = xe，推荐做法），它简化为

F = Fd / (1 + Kd/Kenv) 虚拟刚度越大、环境越软，实际接触力越低于期望值

物理图像：虚拟弹簧想把机器人"拉回"参考位置，而接触力想把机器人"推出去"，两者在稳态对峙。Kd 越大，弹簧越硬、越能顶住力的推压，机器人越站不深，力就越小。这就是软环境里导纳控制力偏小、Kenv 又不可知的根源。注意它与第 082 章 ILC 的差别：ILC 用整条误差曲线去学前馈，自适应增益则只调一个参数，让稳态点自己移动。

3. 灵敏度与自适应律：先知道"往哪调"，再决定"调多快"

把 F 对 Kd 求偏导（xr、Fd、Kenv 视为常数）：

∂F/∂Kd = (xr − xe − Fd/Kenv) / (1 + Kd/Kenv)2 参考放在表面处时 ∂F/∂Kd = −(Fd/Kenv)/(1+Kd/Kenv)² < 0

符号为负，这就是本章最关键的一步。它告诉我们：力偏大时应该把 Kd 调大（更硬的虚拟弹簧把机器人往外顶），力偏小时应该把 Kd 调小。有了方向，用最简单的性能指标 J = ½ef2 做梯度下降：

∂J/∂Kd = ef·∂ef/∂Kd = −ef·(∂F/∂Kd)，梯度下降给出 K̇d = −γ·(∂J/∂Kd)，把负的灵敏度吸收进速率后写成 K̇d = −γ·ef γ > 0：自适应速率（学习率）；ef = Fd − Fmeas

验证一遍：F 偏小 ⇒ ef > 0 ⇒ K̇d < 0 ⇒ Kd 减小 ⇒ 由 ∂F/∂Kd<0，F 回升。方向正确。再验证单调性：J̇ = ef·ėf，而 ėf = −(∂F/∂Kd)·K̇d，代入得到

J̇ = γ·(∂F/∂Kd)·ef2 < 0（∂F/∂Kd 恒为负） 只要灵敏度符号确实为负，J 的取值就单调下降

这是一个"准静态李雅普诺夫"结论：γ 足够小、自适应比力环慢得多时，每一次参数变动之间力环都已接近稳态，J 的下降才成立。工程直觉：自适应的节拍必须比它调整的对象慢一个量级以上，若快过力环，自适应就等于"和力环打架"。若 xr 被人为压入超过 Fd/Kenv，灵敏度会变号，自适应方向翻转，这是本章最隐蔽的坑，后文护栏里专门处理。

4. 为什么必须给自适应加护栏：变刚度的能量账

把虚拟弹簧的能量写出来：V = ½Kd(t)(xc−xr)2，对它求时间导数会多出一项 ½K̇d(xc−xr)2，刚度变化本身就是能量流：减刚度时这笔能量被释放回系统，如果释放速率超过接触端口当时的耗散能力，就相当于给系统"免费充电"。这就是变增益（以及第 020 章变阻抗）需要安全监督的数学根源。工程上用四道护栏把风险压住：

  • 投影：Kd 限制在 [Kmin, Kmax]（如 [50, 1500] N/m），保证灵敏度不会因 Kd 过大而畸变；
  • 死区：|ef| 小于力噪声带（约 0.5 N）时停止更新，防止噪声驱动参数漂移；
  • 速率限制：|K̇d| ≤ rmax（如 400 N·m−1·s−1），把"免费充电"的瞬时功率压小；
  • 振动冻结：检测接触力高频分量的能量，越限就冻结自适应（γ 置零），回落后再恢复。

另外两个约定：Dd 随动，每次 Kd 改变后用 Dd = 2ζ√(KdMd) 重算，否则固定的 Dd 会让阻尼比随 Kd 漂移（Kd 升则欠阻尼、降则过阻尼）；Md 不动，虚拟质量只影响高频形状，对稳态力零贡献，多调一个参数只会多一份风险。

实现思路与设计

把上述理论落成 1 ms 控制周期里的计算序列，顺序如下：

  1. 读力与位置：Fmeas 先做 20 ms 低通（第 047 章的方法），避免噪声进入自适应律。
  2. 算误差：ef = Fd − Fmeas；非接触段（Fmeas≈0 且 |ef| 很大）直接跳过自适应，没有接触就没有灵敏度可言。
  3. 振动监督：由力信号高通能量判断是否冻结；冻结只停参数更新，导纳方程照常运行，控制器保持柔顺。
  4. 更新增益：K̇d = −γef，带死区、速率限制与投影；随后重算 Dd。
  5. 积分导纳方程：解出 ẍc，半隐式欧拉更新 ẋc、xc（第 002 章的离散化，不能用显式欧拉）。
  6. 限幅输出：xc 相对参考的偏移量限幅（如 ±20 mm），与速度限幅一起交给位置内环。

参数初值建议：Md = 1.0 kg（固定）；Kd(0) 取"手动整定能稳定接触"的值，如 300–800 N/m；ζ = 1.0，Dd 由公式算；γ 与闭合环带宽挂钩，力环带宽约 √(Kd/Md)/(2π) ≈ 3 Hz，自适应时间常数取 1–2 s，对应 γ ≈ 5–20（把 ∂F/∂Kd 的量纲一并吸收后按实验微调）。

设计决策：为什么参考位置不许"预压入"？

把 xr 人为推进表面 2 mm 看起来能让接触更快建立，但它会改变灵敏度符号：灵敏度分子是 xr − xe − Fd/Kenv，当预压量超过 Fd/Kenv（对 Kenv=5000、Fd=15 只有 3 mm 的量级）时，∂F/∂Kd 由负变正，自适应律会把力误差越调越大。正确做法：xr 放在名义表面处，让导纳方程自己决定压入多少，压入量是 k 的函数，这正是自适应要利用的自由度。

关键代码与解读

片段 1：自适应增益导纳控制器

import numpy as np

class AdaptiveAdmittance:
    """力跟踪型导纳控制器：虚拟刚度 K_d 在线自适应，D_d 随动保持阻尼比。"""
    def __init__(self, m_d=1.0, k0=800.0, zeta=1.0, dt=1e-3,
                 gamma=12.0, k_min=50.0, k_max=1500.0, deadband=0.5):
        self.m_d, self.k_d, self.zeta, self.dt = m_d, k0, zeta, dt
        self.gamma = gamma                    # 自适应速率：比力环慢一个数量级
        self.k_min, self.k_max = k_min, k_max # 投影区间：灵敏度可信区 + 安全区
        self.deadband = deadband              # 力死区：噪声带内不更新参数
        self.x_c, self.v_c = 0.0, 0.0         # 虚拟修正位置及其速度（积分状态）
        self.d_d = 2.0 * zeta * np.sqrt(k0 * m_d)

    def step(self, f_meas, f_d, x_r, adapt_ok=True):
        e_f = f_d - f_meas
        # 导纳方程解加速度：M x.. = e_f - D x. - K(x - x_r)
        # 符号约定：力不足(e_f>0) → 朝 +x（更深）加速 → 接触力补上
        a_c = (e_f - self.d_d * self.v_c - self.k_d * (self.x_c - x_r)) / self.m_d
        self.v_c += a_c * self.dt             # 半隐式欧拉：先速度后位置
        self.x_c += self.v_c * self.dt
        # 自适应律 K_dot = -gamma * e_f（灵敏度为负，梯度下降的化简形式）
        if adapt_ok and abs(e_f) > self.deadband:
            dk = np.clip(-self.gamma * e_f * self.dt, -0.4, 0.4)  # 速率限制
            k_new = float(np.clip(self.k_d + dk, self.k_min, self.k_max))
            if k_new != self.k_d:
                self.k_d = k_new
                # D 随动：K 变而 D 不变会让阻尼比漂移，直接表现为接触振荡
                self.d_d = 2.0 * self.zeta * np.sqrt(self.k_d * self.m_d)
        return self.x_c

解读：注意三个"为什么"。（1）更新 Kd 用 -gamma * e_f，负号来自灵敏度为负的推导，符号写反就是发散，代码里注释把这条推导链明确写出。（2）np.clip(-self.gamma*e_f*dt, -0.4, 0.4) 把单步参数变化限制在 0.4 N/m 以内，这就是"速率限制"护栏，它同时兜住了异常大误差（如碰撞干扰）造成的狂暴更新。（3）Kd 更新后立刻重算 Dd，很多实现漏掉这一步，结果 Kd 变化时阻尼比跟着漂移：被拉低时系统变得过阻尼（响应迟钝），反向调高时才迅速欠阻尼、接触开始嗡嗡振。

片段 2：振动监督器（冻结/恢复）

class AdaptSupervisor:
    """振动监督：监视接触力高频能量，越限冻结自适应，回落恢复（带滞回）。"""
    def __init__(self, dt=1e-3, cutoff_hz=80.0, freeze_th=1.2, release_th=0.4):
        self.dt = dt
        self.freeze_th, self.release_th = freeze_th, release_th  # 单位 N
        self.lp = 0.0
        # 一阶低通的系数由截止频率直接给出，比手调一个 0.1/0.2 靠谱
        self.alpha = 1.0 - np.exp(-2.0 * np.pi * cutoff_hz * dt)
        self.hp_rms = 0.0
        self.frozen = False

    def update(self, f_meas):
        # 高通分量 = 原始 - 低通基线：要拦的正是"控制回路未建模动态被激发"
        self.lp += self.alpha * (f_meas - self.lp)
        hp = f_meas - self.lp
        self.hp_rms += 0.02 * (hp * hp - self.hp_rms)   # 慢速滑动均方
        if not self.frozen and self.hp_rms > self.freeze_th ** 2:
            self.frozen = True          # 越限：先冻结参数，让力环自己稳住
        elif self.frozen and self.hp_rms < self.release_th ** 2:
            self.frozen = False         # 恢复：滞回设计避免在阈值附近抖进抖出
        return self.frozen

解读：监督器单独成类，是为了把"安全逻辑"与"控制逻辑"解耦，冻结时只把 adapt_ok=False 传进去，导纳方程毫不停顿，机器人依旧柔顺。滞回（冻结阈值 1.2 N、恢复阈值 0.4 N）不可省：如果两者相同，系统会以振动周期的节拍反复冻结/恢复，参数在阈值附近来回蹭。截止频率 80 Hz 的选择依据是：位置内环带宽通常只有 20–40 Hz，80 Hz 以上的力信号振荡，其来源几乎必然是"控制不干净"，可排除真实接触现象。

片段 3：两种环境下的自适应收敛对比

def run_case(k_env, k0=800.0, gamma=12.0, adapt=True):
    ctrl = AdaptiveAdmittance(k0=k0, gamma=gamma)
    sup = AdaptSupervisor()
    xe, x_r = 0.0, 0.0          # 参考放在名义表面处（决定灵敏度符号的前提）
    x = 0.0
    for i in range(4000):       # 4 s
        f_env = k_env * (x - xe) if x > xe else 0.0
        x_c = ctrl.step(f_env, 15.0, x_r, adapt_ok=adapt and not sup.update(f_env))
        x += (x_c - x) * 0.25   # 位置内环一阶近似：时间常数 4 ms
    return f_env, ctrl.k_d

for k_env in (5e3, 1e5):        # 软垫 vs 钢件
    f_fix, _ = run_case(k_env, adapt=False)   # 固定增益基线
    f_ad, k_fin = run_case(k_env)             # 自适应增益
    print(f"K_env={k_env:.0e}  固定={f_fix:5.2f} N  "
          f"自适应={f_ad:5.2f} N  K_d末值={k_fin:6.1f} N/m")

解读：预期结果，软环境里固定增益力约 12.9 N（偏差 2 N 量级），自适应把 Kd 逐步压低、力向静态极限 14.9 N 逼近（4 s 窗口内到约 13.1 N）；刚性环境里固定增益本来就只有 0.15 N 的偏差，自适应几乎不动。结论：环境越软，Kd/Kenv 越大，自适应增益的收益越大、必要性越高。这行代码还示范了一个好习惯：基线（adapt=False）与改进版并行跑，让收益有对照、可量化，第 100 章的性能评估把这种对照实验体系化。

常见坑

  • 灵敏度符号想当然：以为"力小就加刚度"，于是在参考预压入的操作点上司服方向反了，力误差缓慢发散。症状是力曲线一边缓慢加大一边抖。修复：把 xr 放回名义表面处，或在线按 Fd/Kenv 与 (xr−xe) 的比较检查符号再决定更新方向。
  • 自适应速度过快：γ 大到与力环同量级，增益和力互相追着振荡，表现为低频"呼吸"式的力波动。修复：把 γ 减半再减半，直到收敛时间在秒级、曲线单调。
  • 忘了 Dd 随动：只改 Kd 不改 Dd，Kd 上升后阻尼比从 1 掉到 0.6 以下，接触瞬态出现超调。修复：Kd 每次更新后按 Dd = 2ζ√(KdMd) 重算。
  • 死区过小或无死区：稳态时力噪声（0.1–0.3 N）持续驱动参数，Kd 在末值附近来回踱步，日志里看不出但会让参数统计失去意义。修复：死区取 3–5 倍噪声 RMS。
  • 用自适应结果当环境刚度：收敛后的 Kd 只是"使力误差为零的增益"，它同时吸收了一切模型误差（摩擦、标定偏差），并不是 Kenv 的估计。要刚度真值，请走第 052 章的辨识流程。

    把 x 当作中间变量消掉；符号翻转发生在 xr − xe > Fd/Kenv 处，即"预压入超过期望力对应的名义穿刺量"。
  2. 取 Kenv = 5000 N/m、Fd = 15 N，分别用 Kd = 100/500/1500 N/m 计算稳态力，验证"Kd 越小力越准"，并说明为什么自适应收敛方向是"力小则降刚度"。★★
    提示
    F = 15/(1+Kd/5000)：三档分别为 14.7、13.6、11.5 N。K̇d = −γef 在 ef>0（力小）时让 Kd 下降，正是把系统推向力更准的方向。
  3. 把片段 1 的 γ 从 12 改为 120，观察力曲线的形态变化；再用"自适应节拍必须慢于力环"解释你看到的现象，并给出一个"单调收敛且 2 秒内完成"的 γ 取值。★★
    提示
    γ 太大时 Kd 的更新与导纳动态同频，出现振荡甚至 Kd 在边界间来回跳；先降到 30 试，再按"收敛时间≈5/γ 的粗略标尺"微调。
  4. 设计实验验证振动监督器：在力信号里叠加 100 Hz、1.5 N 的干扰（模拟内环啸叫），记录冻结/恢复的时刻与 Kd 轨迹；然后只把恢复阈值改成与冻结阈值相同，观察"反复冻结"的问题。★★★
    提示
    冻结后 Kd 保持不变、力环继续工作；滞回设计的意义在于让状态切换有"记忆"。阈值相同时切换条件互为镜像，系统会在边界附近抖动。

小结

  • 问题根源：力跟踪型导纳控制的稳态力 F = Fd/(1+Kd/Kenv)，虚拟刚度会"顶住"接触力，环境一变力就偏。
  • 自适应律：由灵敏度 ∂F/∂Kd = (xr−xe−Fd/Kenv)/(1+Kd/Kenv)² 得 K̇d = −γef；准静态下 J̇ = γ(∂F/∂Kd)ef² < 0（灵敏度为负），J 单调下降。
  • 四道护栏：投影限幅、力死区、速率限制、振动冻结；Dd 随 Kd 随动保持阻尼比，Md 保持不动。
  • 能量视角：变刚度弹簧在减刚度时释放储存能量，这是自适应必须"慢、稳、有监督"的根本原因。
  • 自适应调的是增益、对付环境与工况变化；第四篇到此收束，下一章进入第五篇，先解决"模型不确定与外部扰动有界时，怎样让柔顺行为依然有保证"：阻抗控制中的鲁棒项设计。
