第四篇 · 高级柔顺任务与约束

第 064 章：基于阻抗控制的曲面跟踪

让末端沿未知曲面滑动并保持恒定法向力：用测力估计曲面法向、构造切向-法向分离的任务坐标系，把"软法向、硬切向"写进同一个刚度矩阵。

  • 主题：曲面跟踪 / 任务坐标系 / 方向选择性阻抗
  • 关键公式：K = R·diag(kt,kb,kn)·RT；F = Keff(xd−xsurf)
  • 预计学时：55 分钟
  • 前置章节：第 063 章

学习目标

  • 理解曲面跟踪是"法向调力 + 切向进给"的双重任务，以及为什么同一套刚度无法同时胜任两个方向。
  • 会从测力数据估计曲面法向（低通 + 符号一致性检查），并知道摩擦会给估计带来多大量级的偏差。
  • 会构造任务坐标系 [t, b, n]，用相似变换 K = R·diag(·)·RT 生成方向选择性刚度与阻尼。
  • 会推导串联刚度公式 F = Keff(xd−xsurf)，理解"谁软谁说了算"的物理含义。
  • 掌握任务坐标系更新带宽（2–5 Hz）的取舍，以及 |F| 退化（过棱、脱开）时的处理策略。
  • 能写出完整的曲面跟踪控制循环，并解释每一步的顺序为什么不能交换。

背景与动机

打磨、抛光、擦拭、探伤，这些工艺的共同动作是：工具贴着曲面滑动，一边压住（法向力恒定），一边走（切向速度恒定）。用位置控制做，曲面建模误差 0.1 mm 就足以在刚性工件上产生几十牛的撞击力；用单纯的力控制做，法向力是稳了，但切向变得"没有立场"，摩擦力会把工具拖停，让进给速度形同虚设。

曲面跟踪的本质要求是两个方向、两种性格：沿法向要软（容忍曲面形状误差、把位置偏差翻译成力），沿切向要硬（跟住进给、抵抗摩擦与切削扰动）。这正是阻抗控制最擅长的形态：把刚度做成"有方向的"，一组参数走天下在这里行不通。上一章我们处理了扰动频段，这一章开始处理任务几何。

核心原理

1. 方向必须是分开的：两个任务的刚度要求相反

先看两组数字。法向：若取刚度 Kn = 300 N/m，20 N 的目标接触力只需要 67 mm 的位置偏置，位置上的"宽容"换来力的"可控"，曲面有 ±5 mm 的起伏也只在力上产生 ±1.5 N 的波动。切向：若同样取 300 N/m，前端阻力 30 N 时工具会被顶后 100 mm，加工完全无法进行；取 Kt = 3000 N/m，同样 30 N 阻力只导致 10 mm 落后，配合阻尼与进给参考就能稳住速度。可见两个方向的刚度需求差了一个数量级以上，用单一刚度必然顾此失彼。

再看力的来源。单自由度稳态公式在曲面法向上同样成立：接触力 = 法向刚度 × 法向位置偏置。你不需要"直接控制力"，只需要让期望位置沿法向"多压进去一点"，阻抗动力学自动把力建立起来。

2. 任务坐标系：把"方向选择性"写成矩阵

定义任务坐标系（task frame）三根轴：t 为进给切向，b 为副切向（曲面内的另一方向），n 为压入法向。把三根轴按列排成旋转矩阵 R = [t b n]，方向选择性刚度就是：

K = R · diag(kt, kb, kn) · RT，  D = R · diag(dt, db, dn) · RT k 单位 N/m，d 单位 N·s/m；R 的列是任务三轴在基座系中的方向

这条式子是相似变换：K 的特征向量就是任务三轴、特征值就是三个方向的刚度。为什么不能直接写 diag(kt,kb,kn)？因为那只能表达"与世界坐标轴对齐"的柔顺；曲面法向在空间中随位置连续变化，必须靠 R 实时旋转。工程直觉：柔顺是有方向的；阻抗控制的高级用法，就是让你自由指定"哪个方向软、哪个方向硬"，幅度调节只是基础功课。

3. 法向从哪来：测力反推与它的两个陷阱

没有曲面模型时，法向只能从接触力里读出来。工具压向曲面时，曲面把工具往"外"推，所以接触反力方向是外法向，压入方向（机器人需要继续移动以增大力的方向）是反力的反方向：n̂ = −F/|F|。两个陷阱必须知道：

陷阱一：摩擦让法向估计偏转。工具滑动时测得的力是法向力与切向摩擦力的合成，估计出的方向相对真实法向偏转 atan(μ) 的角度：摩擦系数 μ = 0.2 时偏约 11.3°，μ = 0.3 时偏约 16.7°。这意味着你的"软轴"歪了十几度，法向力里混入切向分量，表现为磨削纹路不均匀。可利用进给方向的先验把摩擦分量扣除（已知 t 方向，估计沿 t 的摩擦大小并从测量力中减去），把偏角压到 2–3° 以内。

陷阱二：|F| 太小时方向不可观测。过棱边、脱离接触、力信号接近零时，n̂ = −F/|F| 被噪声完全支配。正确做法是设置门限 |F| < 1 N 时保持上一拍坐标系并置 valid = False，通知上层停止进给，避免继续用噪声旋转刚度轴。

4. 稳态力与串联刚度：谁软谁说了算

把法向的阻抗稳态方程与环境的弹性模型联立：Kn(xd−x) = F（机器人侧）与 F = Kenv(x−xsurf)（环境侧，穿透量乘环境刚度），消去实际位置 x 得：

F = Keff · (xd − xsurf)，  Keff = KnKenv / (Kn + Kenv) Kenv：环境刚度，N/m；xsurf：曲面位置

这正是 ch001 推过的两弹簧串联。Kenv = 2×104 N/m、Kn = 300 N/m 时 Keff ≈ 295.6 N/m，串联刚度由软的一方决定。于是想得到 20 N，就把期望位置压入 fd/Kn = 67 mm；实际穿透只有 F/Kenv = fd/Kenv ≈ 1 mm。参考位置的生成方式：维护一个参考点 xref 沿切向匀速滑动（不需要曲面模型），期望位置 xd = xref + n̂·(fd/Kn)。

实现思路与设计

1 kHz 控制周期下的标准顺序（每一步的先后都有物理理由）：

  1. 读力并低通：测力先过 1–2 ms 模拟/数字低通，压掉传感器噪声尖峰，它会经由法向估计污染刚度方向。
  2. 估计法向：低通带宽取 2–5 Hz（低于力控制环），带 |F| 门限与符号一致性检查，输出 n̂ 与 valid 标志。
  3. 构造任务坐标系：进给方向投影到切平面得 t（去掉法向分量），b = n × t 补全右手系。
  4. 生成参考：xref ← xref + t̂·vt·Δt；xd ← xref + n̂·(fd/Kn)。
  5. 按轴解阻抗：把 (x−xd)、(v)、(Fmeas) 投影到三轴，每轴独立计算加速度，再合成：a = Σi êi·[(F·êi) − di(v·êi) − ki((x−xd)·êi)] / m。
  6. 积分、限幅、下发：半隐式欧拉积分；对命令位置、速度限幅（第 078 章展开）。

参数起点：Kn = 200–500 N/m；Kt = Kb = 2–5 kN/m；阻尼按每轴临界阻尼 di = 2ζ√(kim)，法向取 ζ = 1.0–1.2（接触震荡更保守），切向 ζ = 0.9–1.0（跟随更快）。进给速度 5–50 mm/s 按工艺定；过凸面时受限于离心效应，保持接触的条件是 v²/Rc 远小于法向加速度能力，工程上取 v ≤ √(amaxRc)。

设计决策：为什么低通带宽取 2–5 Hz？20 Hz 会怎样？

法向估计的作用是"稳定地定义刚度轴"，并不追求"快速响应"。带宽越高，力噪声在估计方向上的投影越大，K 的方向以相同频率抖动，等效于在切向注入随机扰动，磨削表面会出现周期性波纹。代价是过尖锐棱边时坐标系跟不上，但那个场景本来就该由 valid = False 的特殊逻辑处理；提高带宽只会把噪声一起放进来。

关键代码与解读

片段 1：从测力估计法向（低通 + 有效门限）

import numpy as np

class NormalEstimator:
    """从接触反力反推压入法向：n_hat = -F_lp / |F_lp|。"""
    def __init__(self, fc=3.0, dt=1e-3, f_min=1.0, n_init=(1.0, 0.0, 0.0)):
        self.a = 1.0 / (1.0 + 2.0 * np.pi * fc * dt)  # 一阶低通系数
        self.f_min = f_min          # 有效接触门限，N
        self.f_lp = np.zeros(3)
        self.n = np.array(n_init, dtype=float)
        self.n /= np.linalg.norm(self.n)

    def update(self, f_meas):
        self.f_lp = self.a * self.f_lp + (1.0 - self.a) * f_meas
        mag = np.linalg.norm(self.f_lp)
        if mag < self.f_min:
            # 力太小：方向不可观测（过棱、脱开）。保持上一拍 n，
            # 用 valid=False 通知上层停进给：绝不能拿噪声去旋转刚度轴
            return self.n.copy(), False
        n_new = -self.f_lp / mag     # 反力的反方向 = 压入方向
        # 符号一致性：法向突然反向说明发生了"另一类接触事件"，不跟
        if float(np.dot(n_new, self.n)) < 0.0:
            return self.n.copy(), False
        self.n = n_new               # 一阶低通已在 f_lp 上完成，这里无需再滤
        return self.n.copy(), True

解读：门限与符号检查是这段代码的"安全阀"：没有它们，力过零瞬间的三个条件，幅值任意、方向噪声主导、除法放大，会合成一个随机翻转的法向，阻抗的软轴会在几毫秒内乱转，比不做估计更危险。低通放在 f_lp 上，不对 n 做球面插值，是为了保持物理量语义（力乘以系数仍有单位 N），实现也简单。注意 n_init 应取任务开始时"大致压入方向"的粗估计，让第一次接触之前就有一个合理的刚度轴。

片段 2：任务坐标系与方向选择性刚度矩阵

def build_task_frame(n_est, v_feed):
    """用估计法向与进给方向构造任务坐标系 R = [t, b, n]（列向量）。"""
    n = n_est / np.linalg.norm(n_est)
    t = v_feed - np.dot(v_feed, n) * n     # 投影到切平面：切向不该有法向分量
    tn = np.linalg.norm(t)
    if tn < 1e-6:
        # 进给速度太小：切向不可定义。生产代码应沿用上一拍坐标系，
        # 这里显式报错防止调用方悄悄用上未定义方向
        raise ValueError("进给方向退化：请沿用上一拍任务坐标系")
    t = t / tn
    b = np.cross(n, t)                     # 副切向：补全右手系
    return np.column_stack([t, b, n])      # 列拼接：R.T @ x 得到三轴投影

def build_impedance_matrices(R, k_t=3000.0, k_b=3000.0, k_n=300.0,
                             m=1.0, zeta=1.0):
    """把任务方向的刚度/阻尼'旋回'基座系：K = R diag(k) R^T。"""
    k_diag = np.array([k_t, k_b, k_n])
    K = R @ np.diag(k_diag) @ R.T          # 特征向量 = 任务三轴，特征值 = 三向刚度
    d_diag = 2.0 * zeta * np.sqrt(k_diag * m)   # 每轴临界阻尼，手感各向一致
    D = R @ np.diag(d_diag) @ R.T
    return K, D

解读：column_stack 的列序与 k_diag 的位置必须严格对应，[t, b, n] 对应 [k_t, k_b, k_n]，错一位就会把"软"装到切向上，现象是进给间隙性"发飘"而法向力剧烈波动。阻尼矩阵也用同一个 R 旋转，是为了保证每根轴的阻尼比在设计值附近；如果直接给一个各向同性的 d·I，法向的实际阻尼比会随 K 的方向变化而变化。奇异情形（v_feed 与 n 平行）抛异常，不静默处理：这种输入只可能来自上层的 bug（比如进给方向没更新），尽早暴露比带着错误的轴运行安全。

片段 3：曲面跟踪主循环（2D 弧面示意，1 kHz）

# 3 秒仿真：凸圆弧面，恒定法向力 20 N + 恒定切向进给 50 mm/s
c, r, k_env = np.array([0.0, 0.40]), 0.30, 2.0e4   # 圆心/半径/环境刚度
x, v = np.array([-0.30, 0.40]), np.zeros(2)        # 初始在弧面左端点、静止
x_ref = x.copy()                                   # 参考点沿切向滑，无需曲面模型
n_est = np.array([1.0, 0.0])                       # 压入方向初值（指向圆心）
f_d, v_t = 20.0, 0.05                              # 目标力 N、进给速度 m/s
k_t, k_n, m, d_t, d_n = 3000.0, 300.0, 1.0, 110.0, 35.0
for k in range(3000):
    dvec = x - c
    dist = max(np.linalg.norm(dvec), 1e-9)
    # 环境：进入圆内即接触；反力沿外法向，大小 k_env * 穿透量
    f_ext = k_env * (r - dist) * (dvec / dist) if dist < r else np.zeros(2)
    if np.linalg.norm(f_ext) > 1.0:
        n_est = -f_ext / np.linalg.norm(f_ext)     # 反力反方向 = 压入方向
    t = np.array([-n_est[1], n_est[0]])            # 2D 法向转 90 度即切向
    # 参考生成：切向匀速滑 + 法向压入 f_d/k_n（稳态力公式反推偏置）
    x_ref = x_ref + t * (v_t * 1e-3)
    x_d = x_ref + n_est * (f_d / k_n)
    # 任务轴分解后逐轴阻抗：a = [F - D*v - K*(x-x_d)] / m
    dp, dv = x - x_d, v
    a = t * (np.dot(f_ext, t) - d_t * np.dot(dv, t) - k_t * np.dot(dp, t)) / m \
      + n_est * (np.dot(f_ext, n_est) - d_n * np.dot(dv, n_est)
                 - k_n * np.dot(dp, n_est)) / m
    v = v + a * 1e-3                               # 半隐式欧拉：先速度
    x = x + v * 1e-3                               # 再位置，能量性质更稳
    if k % 750 == 0:
        print(f"t={k*1e-3:.2f}s  F_n={-np.dot(f_ext, n_est):5.1f} N  "
              f"x={x[0]:+.3f} m")

解读：这段仿真把所有机制串了起来，法向估计、参考生成、逐轴阻抗。三个可观察现象：（1）稳定后 F_n 落在 19.5–19.6 N（平表面理论值 19.7 N），达不到精确的 20 N，差额正是串联刚度修正 (1 + Kn/Kenv) 因子，这是物理规律不是 bug；（2）切向位置平滑推进，法向刚度的"软"完全没有泄漏到切向；（3）把 k_n 改大十倍再看，法向力会围绕曲面起伏产生明显波动，原因就是第 1 节的那笔账（位置误差翻译成力的比例系数变大了 10 倍）。

常见坑

  • 法向符号搞反：n̂ = +F/|F| 时"压入方向"实际指向离开曲面的方向，参考位置越推越远，接触力恒为零或周期性撞击。修复：验证一次，压入方向应是"反力的反方向"，接触力增大时该方向的位移增量与力增量同号。
  • 忽略摩擦偏置：法向估计偏 atan(μ)（μ = 0.2 时约 11°），磨出的表面有斜纹、边缘倒角不均。修复：用进给方向先验估计并扣除摩擦分量，或对估计出的 n̂ 做"限制在与进给垂直平面附近 ±20°"的先验约束。
  • 低通太慢或太快：3 Hz 以下跟不上凸面起伏，接触力随曲率周期性欠压；10 Hz 以上力噪声把刚度轴"晃"出来，表面出现高频波纹。修复：按"曲面最小曲率半径 / 进给速度"估算坐标系转动频率，取其 5–10 倍作为低通带宽下界，再向上留 2 倍裕度。
  • 切向刚度配错轴：R 的列序与 k 对角元错位，症状是法向力波动而进给方向"发飘"。修复：单元测试 RT·t = [1,0,0]，且 K·t = kt·t。
  • 过棱不设防：|F| 骤降时继续用噪声更新法向，刚度轴在棱边附近乱转，表现为"到棱上就打摆子"。修复：门限 + valid 门控 + 过棱时减速或停进给，等力恢复再继续。

练习与思考

  1. 联立 Kn(xd−x) = F 与 F = Kenv(x−xsurf)，推导 F = Keff(xd−xsurf)，并验证 Kenv → ∞ 时结论退化为 F = Kn(xd−xsurf)。 ★
    提示
    两式相加消去 x；再令 Kenv 趋于无穷，把两弹簧串联公式取极限。
  2. 把片段 3 的 k_n 取 100 / 300 / 1000 N/m 各跑一次，记录法向力收敛时间、过凸面时的力波动幅度与切向速度波动。解释三组数据随 k_n 变化的趋势。 ★★
    提示
    k_n 越大，位置误差到力的换算系数越大：力波动上升、收敛变快；同时 f_d/k_n 的压入偏置变小，交界处的接触建立更容易出现瞬时脱开。
  3. 已知进给方向 t 的先验，设计一个"摩擦扣除"改进方案：估计沿 t 的摩擦力大小并从测量力中减去，再计算 n̂。写出公式并说明 μ = 0.3 时偏角大约能降到多少。 ★★
    提示
    测量力 ≈ Fn·(−n) + μFn·(−t)；若沿 t 的摩擦分量被完全扣掉，剩下的方向误差来自残余估计误差，通常可到 2–3°。
  4. 设计过棱策略：给出 |F| 门限、坐标系保持时长、进给减速曲线、恢复条件与恢复后的重新建立接触流程。用状态机草图表示。 ★★★
    提示
    状态：Tracking → Suspect（力低于门限）→ Hold（保持坐标系、减速到 20%）→ 若力恢复则回 Tracking，超时则停止进给上报。关键是 Hold 期间绝不更新法向。
  5. 思考题：切向为什么也要有阻尼，不能只给刚度？用"摩擦 + 相对速度方向切换"解释极限环的产生。 ★★
    提示
    摩擦方向与相对速度方向相反，速度过零时摩擦力跳变；纯弹簧系统在"粘滞-滑移"切换中不断积累能量，形成低频抖动（爬行），阻尼是唯一的耗散通道。

小结

  • 曲面跟踪 = 法向调力 + 切向进给，两方向刚度需求相差一个数量级，必须方向选择性柔顺。
  • 任务坐标系：R = [t, b, n]，K = R·diag(kt,kb,kn)·RT；特征是"特征向量方向软硬自由指定"。
  • 法向估计 n̂ = −F/|F|，必备低通（2–5 Hz）、|F| 门限、符号一致性检查；摩擦引入 atan(μ) 偏角，可用进给先验削弱。
  • 稳态力由串联刚度决定：F = Keff(xd−xsurf)，软的一方主导；想要 20 N 就压入 fd/Kn 的位置偏置。
  • 过棱/脱开用 valid 门控：保持坐标系、减速、等力恢复；绝不拿噪声旋转刚度轴。
