第二篇 · 参数调节与交互任务

第 021 章：基于力误差的阻抗参数调整

力误差是现场最诚实的信号：它过大就说明该保命（柔化），它长期偏小/偏大也可以用来"自动配平"刚度。本章把力误差变成参数调节器，并交代清楚"改刚度"与"改参考"两条路的取舍。

  • 主题：阻抗参数 / 误差驱动的在线调节
  • 关键公式：Kd=Kmin+(Knom−Kmin)e−|eF|/e0；K̇d=β·eF，Dd=2ζ√(KdMd)
  • 预计学时：55 分钟
  • 前置章节：第 020 章

学习目标

  • 理解力误差的两条修正通道：调参考点（第 019 章）与调刚度参数（本章），以及各自适用的工况。
  • 会推导"刚度通道"的力灵敏度：Kd≪Kenv 时 F≈Kd·偏置，并写出 K̇d=β·eF 的收敛速率与稳定条件。
  • 掌握阻尼联动规则 Dd=2ζ√(KdMd)：只要 K 在动，D 必须同步，否则阻尼比悄悄漂移。
  • 会设计"误差越大越软"的安全柔化调度，并说明它为什么只降 K 不升 K（只抽能不注能）。
  • 能给出刚度调节的边界盒子（Kmin/Kmax）与回退策略：压到边界仍不满足时，切换到参考自适应。

背景与动机

第 019 章用"力误差"去挪参考点，第 020 章用"任务阶段"去换挡位。还有第三种用法尚未展开：让力误差直接调节参数本身。它有两个非常实际的场景。其一，安全柔化：接触力突然冲到 30 N（工件放错、边缘刮蹭），相比"让参考点退"，更有效的保护是"把刚度降下去"，软体瞬间化解冲击，这正是协作机器人碰撞反应的标准动作。其二，自动配平：任务要求稳定的 12 N，可你不知道该把 Kd 给多少才能恰好压出这个力；让 Kd 按力误差缓慢爬升/回落，系统自己找到工作点。

本章先把两条机制的数学讲透（灵敏度、收敛、稳定、能量），再把三者（参考、挡位、参数）放在一起画清分工与回退链。它是"参数调节与安全约束"篇的开篇：从这里开始，参数不再只是"选好了挂上去"，而成为运行中可管理、有护栏、可回退的动态量。

核心原理

1. 刚度通道的灵敏度：dF/dKd 等于偏置

回到串联刚度公式（第 018 章）：稳态力 F = Keq(xr−xe)，Keq=KdKenv/(Kd+Kenv)。记固定参考与（未知）表面之间的偏置 o = xr−xe，在 Kd≪Kenv 的分区（第 018 章"控制器主导"）下 F ≈ Kd·o，于是：

∂F/∂Kd ≈ o（偏置本身）， 因此 K̇d = β·eF ⟹ Ḟ ≈ o·β·eF eF = Fd − F 为力误差；β：刚度调节增益，单位 N/(m·N·s)

误差动力学变成一阶线性：ėF = −o·β·eF，收敛速率 λK = β·o。两个结论直接影响整定：第一，收敛速度与"偏置 o"成正比，压得越深，调 K 越有效；第二，o 未知（表面位置没标定），所以增益只能从保守值起步。用延迟判据把关：这是又一条一阶自适应回路，配同样的稳定条件 λK·Ta ≤ 1（第 019 章）。取 Ta=50 ms、o 估计 10 mm，则 λK ≤ 20 /s → β ≤ λK/o = 2000 N/(m·N·s)；工程起步取 200–500，对应时间常数 0.2–0.5 s，与参考自适应同一量级的"慢"。

再给一个物理边界感：偏置 o → 0 时（刚好贴面），dF/dKd → 0，刚度通道"失去权威"，Kd 会被误差推着一直跑，直到 Kmax 或把物体压出 o>0。所以刚度调节必须带边界盒子与接触门限，且当误差在边界处仍不收敛时，把纠正职责交回参考点（第 019 章）。工程直觉：调参考是"移动工作点"，调刚度是"改变工作点对偏置的敏感度"，前者直接、后者间接；偏置很小或不可动时，前者才是正路。

2. 阻尼联动：K 一动，ζ 就漂

虚拟刚度不是孤立的参数。阻尼比 ζ = Dd/(2√(KdMd)) 里 Kd 出现在分母，K 变化时若 D 不动，ζ 反向漂移：K 翻倍 → ζ 除以 √2（1.0 变 0.71，出现可见超调）；K 砍半 → ζ 乘 √2（手感发黏）。因此任何在线调 K 的机制都必须同步：

Dd ← 2ζtarget·√(KdMd)（每拍或每 N 拍重算） ζtarget 建议 0.9–1.0；阻尼的升降本身不注入能量（第 020 章），但 D 大幅下调要经过平滑

注意联动的方向性：K 上调时 D 上调（两者都从外部"注入/耗散"看是安全的：ΔK 需过能量罐，ΔD 免检）；K 下调时 D 下调，阻尼下降不注入能量，但耗散通道变窄，若系统正有振荡，收窄耗散会延长衰减时间；所以"安全柔化"里的 K 下调建议与"振荡保护"错开：柔化时 D 不要跟着 K 一起大砍，保留一份接触阻尼。

3. 安全柔化：误差越大越软

柔化调度的标准形状是指数衰减（光滑、有界、单调）：

Kd(eF) = Kmin + (Knom − Kmin)·e−|eF|/e0 e0：软化尺度（N），如 3 N；|eF|=0 时 K=Knom，|eF|≫e0 时 K→Kmin

数字感（Knom=500、Kmin=120、e0=3）：误差 0 N → K=500；3 N → 120+380×0.368≈260；10 N → 约 134；30 N → 约 120（地板）。把"柔化"设计成只降不升是刻意的安全不对称：它只沿第 020 章能量账的"抽能"方向动作，因此可以立刻生效、不需要能量罐检查、也不会把误差放大；恢复（升刚度）则走慢速信号（误差持续小 1–2 s 后）并按速率限制回升。另一个细节：eF 要用低通后的力（τ=10–30 ms），否则单拍尖峰会触发不必要的柔化，而真正的大误差是持续量。

4. 三通道分工与回退链

把 019/020/021 三章合起来看，力控系统有三级修错手段，按"越直接越先动"排序：

层级动作带宽适用
参考点（019）xr 增减，直接改工作点0.3–1 s 时间常数偏置存在、行程有余量、环境在动
刚度通道（本章）Kd 配平工作点灵敏度；D 同步0.2–0.5 s参考受限（工作空间/kinematics）、或需要改变"较真程度"
安全柔化（本章）|eF| 大 → 降 K（只降）即时–50 ms冲击、异常接触、人机碰撞

回退链的触发条件：刚度通道顶到 Kmin 或 Kmax 而误差仍不收敛 → 交给参考通道；参考通道顶到行程限位 → 报警并请求人工/上层重新规划；安全柔化一旦触发，冻结其他两个通道的"升参数"动作（互锁）。所有通道共用一个铁律：只让"力的改善"作为收敛判据，别用"参数到了目标值"当成功，参数只是手段，力误差才是 KPI。

实现思路与设计

力误差参数调节的接线步骤（从安全到精度，逐级启用）：

  1. 第 1 级（必装）：安全柔化。K=|eF| 的指数地板函数 + 速率不对称（降即时、升限 2000 N/(m·s)）+ D 保留地板（不低于 0.5×名义）。任何力控系统先装这一级。
  2. 第 2 级（精度需求时）：刚度配平 K̇d=β·eF，β=200–500 起步，K∈[Kmin,Kmax]（例如 [150, 900]），D 按 ζ=1 联动；带接触门限与误差死区（|eF|<0.3 N 不动作）。
  3. 第 3 级（可选）：与 019 并联，用"谁有余量谁动"仲裁：行程充裕优先动参考；参考顶限才动刚度。
  4. 验收：力阶跃（Fd 从 5 N 到 15 N）的收敛时间 ≤3 s；异常接触试验（人为顶偏工件）在 100 ms 内把接触力峰值压到预算内；参数日志里 K、D、D 与 K 的 ζ 互换一致性检查。
设计决策：为什么把刚度调节的误差死区设成 0.3 N，更小不行吗？

刚度通道的输入是力误差，力传感器的噪声 σ≈0.1 N 会经 β 积分成 Kd 的随机游走：死区太小（如 0.05 N），Kd 每天做无意义的小幅震荡；死区太大（如 2 N），真实的小偏差永远不修。0.3 N（约 3σ）是"吃掉噪声、留住信号"的标准档；更精细的做法是用泄漏型积分把 Kd 缓慢拉回 Knom（时间常数 30–60 s），兼顾"配平"与"参数不漂走"。注意这与导纳的死区/泄漏（第 002 章）是同一套哲学：确定性需求走整数通道，噪声管理走死区与泄漏，力控系统的每个"在线"量都需要这对搭档。

关键代码与解读

片段 1：安全柔化与阻尼联动，十五行的保护伞

import numpy as np

def soften_k(e_f, k_nom=500.0, k_min=120.0, e0=3.0, zeta=1.0, m_d=1.0):
    """|力误差|越大→刚度越低（指数软化）；D 按 zeta 同步联动。"""
    k_d = k_min + (k_nom - k_min) * np.exp(-abs(e_f) / e0)
    d_d = 2.0 * zeta * np.sqrt(k_d * m_d)     # 联动关键：D 跟着 K 走
    return k_d, d_d

print(f"{'|e_F|(N)':>9} {'K_d':>7} {'D_d':>7}  说明")
for e_f in (0.0, 1.0, 3.0, 10.0, 30.0):
    k_d, d_d = soften_k(e_f)
    note = "名义" if e_f == 0.0 else ("地板（最强保护）" if k_d < 130 else "过渡")
    print(f"{e_f:9.1f} {k_d:7.0f} {d_d:7.1f}  {note}")

# 恢复方向的安全不对称：升 K 走慢速斜坡，且必须连续"安静"一段时间
def recover(k_now, k_nom, quiet_time, k_rate=2000.0, dt=1e-3):
    """quiet_time：|e_F|<死区 的持续时间（s）；不到 1s 不许回升。"""
    if quiet_time < 1.0:
        return k_now
    return min(k_now + k_rate * dt, k_nom)

解读：三个设计点顺次说明。形状：指数函数保证 K 关于误差光滑单调、有明确地板 Kmin（不会算到负数或零），Kmin=120 本身也有物理含义，低于它，力分辨率与抗漂移能力（第 002/004 章）就不可接受了。联动：d_d = 2ζ√(k_d m_d) 一行修掉了"软化顺带把系统变成欠阻尼"的隐患，这是很多碰撞保护实现里被忘掉的一步，症状是"保护动作后末端抖两下"。恢复的不对称：recover 要求误差持续低于死区 1 s 才允许缓慢回升，避免"误差在死区边缘闪动 → K 在软化/恢复之间反复横跳"的抖挡；速率 2000 N/(m·s) 表示从地板回升到 500 需要约 0.2 s，仍然比降速慢得多（降是唯象瞬时），这套不对称贯穿全章。

片段 2：刚度配平，让 Kd 自己找到工作点

def k_trim_sim(beta=300.0, o_true=0.012, k_env=3000.0, f_d=10.0,
               k0=300.0, k_lo=150.0, k_hi=1500.0, dt=1e-3, t_end=8.0):
    """固定参考、未知表面：用 K̇_d=β·e_F 追力（含接触门限与限幅）。"""
    k_d, f, log = k0, 0.0, []
    for i in range(int(t_end/dt)):
        # 接触回路：准静态关系 + 50ms 一阶滞后（与第 019 章同款近似）
        k_eq = k_d*k_env/(k_d+k_env)
        f_ss = k_eq*o_true
        f += (f_ss - f)*dt/(0.05 + dt)
        e_f = f_d - f
        if abs(f) > 0.5 and abs(e_f) > 0.3:          # 接触 + 死区
            k_d += beta * e_f * dt                  # 刚度积分调节
        # 边界盒子与联动阻尼（ζ=1）
        k_d = float(np.clip(k_d, k_lo, k_hi))
        d_d = 2.0*np.sqrt(k_d*1.0)
        log.append((k_d, f, d_d))
    return np.array(log)

log = k_trim_sim()
for t_i in (1000, 3000, 7000):
    k_d, f, d_d = log[t_i-1]
    print(f"t={t_i/1000:.0f}s: K_d={k_d:6.1f}  F={f:6.2f} N  D_d={d_d:6.1f}")
print(f"终态: K_d={log[-1,0]:.1f}（起点 300），F={log[-1,1]:.2f} N：刚度自己走进死区")

解读：运行曲线是一次教科书式的"参数寻优"：F 从 0 爬升、Kd 从 300 增加，两者像赛跑一样交替逼近：1 s 时 K≈1074、F≈9.42 N，3 s 时 K≈1112、F≈9.73 N，误差落入 0.3 N 死区后停止更新（终态 F≈9.7 N，死区内的收敛点）。三个实现细节：门限与死区保证调节只在"真实接触 + 误差有意义"时发生，否则自由空间的 eF=Fd>0 会把 K 一路顶到 Khi；限速体现在 β·e_F·dt 里，误差 10 N 时每拍 ΔK=3（即 3000/s），若嫌快就减 β，但别忘 λK=β·o 与延迟判据；联动阻尼每拍重算，输出里可以看到 Dd 从 34.6 涨到终值 66.7，全程 ζ=1。读者可以做一个激进实验：把 β 提到 3000，F 会冲过目标（峰值约 11.2 N）再回落到死区边缘，这就是 λKTa>1 的现场样子（过冲形式；死区与限幅会把它截住，不至于等幅振荡）。

片段 3：三策略同题对比，参考 vs 刚度 vs 固定

def run_fixed(o_true=0.012, k_d=300.0, k_env=3000.0, f_d=10.0,
              dt=1e-3, t_end=8.0):
    """策略 A：固定参考与刚度（基线）。"""
    f = 0.0
    for i in range(int(t_end/dt)):
        f_ss = (k_d*k_env/(k_d+k_env))*o_true
        f += (f_ss - f)*dt/(0.05 + dt)
    return f, k_d

def run_ref_adapt(gamma=0.02, o_true=0.012, k_d=300.0, k_env=3000.0,
                  f_d=10.0, dt=1e-3, t_end=8.0):
    """策略 B：调参考点（第 019 章），刚度保持 300 不变。"""
    f, o = 0.0, o_true
    for i in range(int(t_end/dt)):
        f_ss = (k_d*k_env/(k_d+k_env))*o
        f += (f_ss - f)*dt/(0.05 + dt)
        if abs(f) > 0.5:
            o += gamma*(f_d - f)*dt          # 参考前移 → 偏置变化
    return f, k_d

def run_k_trim(beta=300.0, o_true=0.012, k_env=3000.0, f_d=10.0,
               k0=300.0, k_lo=150.0, k_hi=1500.0, dt=1e-3, t_end=8.0):
    """策略 C：调刚度（本章），参考固定。"""
    k_d, f = k0, 0.0
    for i in range(int(t_end/dt)):
        f_ss = (k_d*k_env/(k_d+k_env))*o_true
        f += (f_ss - f)*dt/(0.05 + dt)
        if abs(f) > 0.5:
            k_d = float(np.clip(k_d + beta*(f_d - f)*dt, k_lo, k_hi))
    return f, k_d

for name, fn in (("A 固定参数", run_fixed), ("B 调参考(019)", run_ref_adapt),
                 ("C 调刚度(021)", run_k_trim)):
    f, k = fn()
    print(f"{name:>12}: 终态力={f:6.2f} N（目标 {10.0}）  K_d={k:6.1f}")

解读：三行输出构成本章最重要的结论画面。A 固定：力停在约 3.27 N（Keq=272.7，F=272.7×0.012），误差 67%，"什么都没调，就只能受着"。B 调参考：力收敛到 10 N，且 k_d 全程保持 300，手感（柔顺性格）一点没动，只是工作点搬家。C 调刚度：力同样收敛到 10 N，但 k_d 最终停在约 1154（等效刚度 Keq≈833），力准了，但手感从 300 N/m 变成了 1154 N/m。同一块力误差，两条通道给出"同一个力、两种代价"：参考通道花的是行程序量，刚度通道花的是手感特性。选哪条从来不是数学问题：装配插孔类任务常允许参考微调（行程富裕），选 B；姿态空间受限或要求恒定视觉/触觉手感的任务（如恒定压力贴合、拖动示教中保持"轻"），选 C 并把 K 的变化范围限死。代码还埋了一个可探索点：把 run_k_trim 的 o_true 改成 0.002（浅接触）重跑，K 冲到 1500 上限时力只有约 2 N，而串联等效刚度的物理上限 Kenv×o=6 N 也低于目标，这正是"刚度通道权威随偏置萎缩"的现场版，也是回退链（顶到边界换通道）的触发时机。

常见坑

  • 调 K 不调 D：ζ 随 √K 漂移，K 升则振荡、K 降则发黏。修复：D=2ζ√(KdMd) 联动，并保留阻尼地板（柔化时不小于 0.5× 名义）。
  • 自由空间里也跑刚度配平：没有接触时 F=0、eF=Fd，K 被推到上限，进接触瞬间以最大刚度撞上去。修复：接触门限（|F|>死区）+ 超出工作空间的 K 冻结。
  • 柔化恢复太快：误差一进死区就恢复刚度，K 在"保护-恢复"之间抖挡，力跟着一松一紧。修复：恢复需 1–2 s 静默 + 速率限制（片段 1 的 recover）。
  • 用单拍力尖峰触发柔化：噪声或一次采样毛刺把系统打到 Kmin，之后一直"软脚虾"。修复：用滤波力（τ=10–30 ms）计算 eF，或要求超限持续 3–5 拍。
  • 刚度通道与参考通道同时全速跑：两个慢回路叠加，力在目标附近出现分钟级摆动。修复：仲裁，默认只跑参考；调 K 只在参考受限时启用；两者若必须并存，β 和 γ 各降一半再联调。

  2. 用片段 2 把 o_true 从 0.012 改成 0.003、0.020，记录收敛时间与终态 Kd。哪一个偏置下 Kd 会顶到限幅？用 λK=βo 解释为什么。★★
    提示
    o=0.003 时按线性近似需要 K≈3333，而串联刚度上限是 Kenv=3000（对应最大力 9 N），10 N 物理上压不出；仿真里 K 顶到上限 1500、力仅约 3 N，权威不足应由参考通道接手；o=0.020 则收敛更快（λK=βo 更大）。
  3. 把片段 2 的联动阻尼一行删掉（D 固定为起始值 34.6），在每拍打印 ζ=D/(2√(KdMd))。先说明为什么在这个准静态力环仿真里 F 看不出任何变化（D 没有进入力环模型），再计算：若把这套参数直接上真机，K 升到 1154 时接触阻尼比掉到多少？把联动恢复、ζ 目标改成 0.7，D 能省多少、代价是什么？★★
    提示
    D 固定 34.6、K 从 300 升到 1154：ζ=34.6/(2√1154)≈0.51，明显欠阻尼，真机会出现超调；ζ 目标 0.7 时 D 约为 ζ=1 的 70%（省阻尼），代价是超调约 5%，接近许可下限。

小结

  • 力误差可以驱动三种修正：参考点（019）、挡位（020）、参数本身（021）；本章聚焦第三条，K 的配平与柔化。
  • 刚度通道的灵敏度 ∂F/∂Kd≈偏置 o：K̇d=βeF 的收敛速率 λK=βo，稳定条件 λKTa≤1；偏置趋于零时通道失效，需回退到参考通道。
  • 阻尼必须联动 Dd=2ζ√(KdMd)；安全柔化只降不升（只抽能、可即时），恢复走 1–2 s 静默 + 限速。
  • 三通道分工与回退链：参考直接、刚度间接、柔化应急；只认力误差收敛，不认参数到达。
