第 047 章：阻抗控制中的力传感器噪声处理

力传感器是阻抗控制的"眼睛"，但它看到的力里混着三类东西：电子噪声、工具自己的惯性力与重力、以及撞击尖峰。本章先定量算清"噪声经过阻抗模型会被放大还是缩小"，再给出中值滤波 + 低通 + 死区 + 偏置标定的完整调理链。

  • 主题：力信号调理 / 滤波与补偿
  • 关键公式：噪声到位置的传递 1/(Mds²+Dds+Kd)；有效外力 Fext = Fmeas − R·mtg − mtat
  • 预计学时：50 分钟
  • 前置章节：第 046 章（基于导纳控制的遥操作）

学习目标

  • 理解力噪声进入阻抗控制的位置增益 |1/(Mds²+Dds+Kd)|：为什么高频噪声被"过滤"、低频漂移原样通过。
  • 会区分三类"假力"：电子噪声与漂移、工具的惯性力/重力、撞击尖峰，并知道每类要用不同工具对付。
  • 掌握调理链设计：中值滤波（尖峰）→ 二阶巴特沃斯低通（噪声）→ 死区（残余微抖）→ 偏置标定（漂移）。
  • 会做相位预算：低通的群延迟要与力回路带宽、内环带宽对账。
  • 能写出惯性/重力补偿与偏置标定的代码，并解释各自的启用条件。

背景与动机

在阻抗控制里，力信号处在"反馈量的核心"位置：方程 Mdẍ + Ddẋ + Kdx = −Fext 中 Fext 的每一份噪声都会变成命令位置的扰动、每一份偏置都会变成稳态位置偏移、每一次尖峰都会给虚拟质量一个速度"脚印"。典型六维力传感器的电子噪声约 0.05–0.2 N（RMS），零点漂移约 0.1–0.5 N/小时，而工具以 3 m/s² 加速时惯性力可达 2 kg × 3 m/s² = 6 N，比信号主体还大。

本章的核心问题是：这些误差里哪些会被阻抗控制器自动"吸收"、哪些会真真切切地破坏性能？答案有点反直觉：高频白噪声反而不用担心（二阶阻抗本身是低通），真正必须动手处理的是低频漂移、偏置和尖峰。想清楚这一点，才不会把滤波器设计错方向。

核心原理

1. 从力噪声到位置：先算清楚增益

把阻抗方程看成从"外力"到"位置偏差"的传递函数（取 xd 静态），噪声的放大倍数就是这个二阶低通的幅频：

|G(jω)| = 1 / √((Kd − Mdω²)² + (Ddω)²) 单位：m/N；低频 → 1/Kd，高频 → 1/(Mdω²)

取一组真实参数 Md = 1 kg、Dd = 45 N·s/m、Kd = 500 N/m，三个频点的放大倍数是：

频率|G(jω)| (m/N)0.1 N 噪声引起的位移含义
1 Hz≈ 1.8×10−3≈ 0.18 mm低频"像真的力"，几乎全通过
10 Hz≈ 2.2×10−4≈ 22 µm开始受到阻尼/惯性压制
100 Hz≈ 2.5×10−6≈ 0.25 µm被惯性完全压死，可忽略

工程直觉：阻抗控制器自己就是一只"低频通"的超强滤波器。100 Hz 的 0.1 N 电子噪声只值 0.25 µm 位置抖动，根本不需要为它牺牲相位；而 0.5 N 的恒定偏置却值整整 1 mm 的位置误差，所以本章的滤波器针对的是"低频段"。

2. 三类假力与它们的不同对策

把"假力"分清楚是对策设计的前提：

  • 电子噪声与漂移：白噪声（高频，被阻抗低通自动压制）+ 漂移与偏置（低频，必须人工消除，偏置标定、慢速重标定）。注意 1/f 型漂移会"伪装"成缓慢变化的接触力，这是最难防的一类。
  • 工具惯性力与重力：F读数 = F真实 + R·mtg + mtat（R 为工具姿态旋转矩阵、at 为工具加速度）。它不是噪声是"结构化串扰"，滤波器只会让它多活一会儿，必须用模型补偿：Fext = Fmeas − R mtg − mtat。
  • 撞击尖峰：接触瞬间的冲击在传感器上产生几十牛的窄脉冲（1–2 ms）。它的能量集中在高频，但阻抗模型对高频的"低增益"只对稳态正弦成立，对瞬时脉冲的效应是速度突变：Δv ≈ （脉冲面积）/Md。2 kg 工具撞 30 N×1 ms，冲量 0.03 N·s，对 Md = 1 kg 就是 30 mm/s 的速度跳变。尖峰必须用中值滤波这类非线性手段直接剔除。

3. 调理链：顺序决定效果

正确的处理顺序是：先剔尖峰，再低通，后死区，最后偏置。

  1. 中值滤波（窗 3–5）对单点/双点尖峰免疫，且对阶跃边沿的失真小（它保留边界，低通会抹圆），先做它，尖峰就不会"污染"后面低通器的状态。
  2. 二阶巴特沃斯低通 fc = 40 Hz、ζ = 0.707：在力回路带宽（2 Hz）处相移只有约 4°，群延迟 √2/ωc ≈ 5.6 ms，代价可接受；换成一阶会引入更大相位（45°@fc），换更高阶则延迟更大。
  3. 死区 0.2–0.3 N 把残余的均方噪声压到"不可见"；阈值取 5–10 倍 RMS 噪声。
  4. 偏置标定：机器人在位静止时采 0.5 s 均值作为零点，在"稳定且无接触"的条件下允许慢速重标定。
设计决策：带宽为什么取 40 Hz？10 Hz 不行吗？

力回路的带宽若有 2 Hz，滤波器截止至少要 10 倍，即 20 Hz 起步；取 40 Hz 是给相位预算留余量（40 Hz 处相位滞后在回路交越频率处 < 10°）。低到 10 Hz 时，与接触力跟踪回路叠加后交越频率附近相位裕度可能不足 30°，表现为力跟踪"发飘"。

实现思路与设计

调理模块按流水线组织，每个环节职责单一（控制周期 1 ms）：

  1. 原始坐标投影：六维力/力矩 → 工具坐标系所需方向，避免把侧向分量混入。
  2. 中值滤波：窗长 3（1 ms 级别不需要更长，否则引入 1 ms 整数延迟）。
  3. 低通：biquad 直接型二型实现，fc = 40 Hz、ζ = 0.707；系数在初始化时算好。
  4. 死区：|F| < 0.25 N 输出 0（含两帧滞回防抖）。
  5. 偏置：启动时静止标定；运行中在"速度低 + 读数在死区附近"持续 0.5 s 后慢速更新（时间常数 5 s）。
  6. 惯性/重力补偿：在偏置之前做（它属于模型项不属于零点）；加速度由关节加速度估计，姿态由正运动学给出。

参数与量级小结：滤波总延迟 ≈ 0.5 ms（中值）+ 5.6 ms（低通）≈ 6 ms；力回路 2 Hz 交越处额外相移约 5°；这些要在第 043 章的时延预算里如实计入（ωnτ 判据中的 τ）。

关键代码与解读

片段 1：先算清加重与过滤的边界

import numpy as np

def force_to_position_gain(m_d=1.0, d_d=45.0, k_d=500.0):
    """计算力噪声到位置偏差的增益，回答“哪些噪声要处理”。"""
    for f in (0.5, 1.0, 10.0, 100.0):
        w = 2.0 * np.pi * f
        # 二阶系统幅频：低频趋于 1/K，高频趋于 1/(M w^2)
        den = np.sqrt((k_d - m_d * w**2)**2 + (d_d * w)**2)
        g = 1.0 / den
        # 相当一栏换算：0.1 N 与 1.0 N 的力误差各值多少位移
        print(f"f={f:6.1f} Hz  |G|={g:.2e} m/N  "
              f"0.1N->{g*0.1*1e6:8.2f} um  1.0N->{g*1e3:8.3f} mm")

force_to_position_gain()
# 输出会告诉你：100 Hz 的噪声只值零点几微米，不值得为它滤波；
# 而 1 Hz 以下、直流偏置必须靠偏置标定解决

解读：这段代码的意义是把"要不要滤波"从直觉变成数字。你会看到 100 Hz 处的增益比 1 Hz 处小三个数量级，用低通去"对付"100 Hz 噪声等于浪费相位裕度；反过来，直流偏置按 1/Kd 原样通过，低通对它毫无办法（低通本来就是让它过的）。所以后面的滤波链主要保护的对象其实是"10–100 Hz 之间那些不大不小的振动噪声"和"尖峰"，低频问题交给偏置标定与补偿模型。

片段 2：中值 + 低通 + 死区的调理链

class ForceConditioner:
    """力信号调理链：中值剔尖峰 → biquad 低通 → 死区。"""
    def __init__(self, fs=1000.0, fc=40.0, zeta=0.707, deadband=0.25):
        self.hist = [0.0, 0.0, 0.0]        # 中值窗(3 点)
        self.deadband = deadband
        # --- 双线性变换的 Butterworth 低通系数(fc 处 -3 dB, zeta=0.707) ---
        K = np.tan(np.pi * fc / fs)
        norm = 1.0 / (1.0 + np.sqrt(2.0) * K + K * K)
        self.b0, self.b1, self.b2 = K*K*norm, 2*K*K*norm, K*K*norm
        self.a1, self.a2 = 2.0*(K*K-1.0)*norm, (1.0-np.sqrt(2)*K+K*K)*norm
        self.x1 = self.x2 = self.y1 = self.y2 = 0.0

    def update(self, raw):
        # 1) 3 点中值：单点尖峰(如撞击毛刺)被直接丢弃，且不抹圆阶跃
        self.hist = [self.hist[1], self.hist[2], raw]
        med = sorted(self.hist)[1]
        # 2) 二阶低通：压制 10~100 Hz 振动噪声，群延迟约 sqrt(2)/wc
        y = (self.b0*med + self.b1*self.x1 + self.b2*self.x2
             - self.a1*self.y1 - self.a2*self.y2)
        self.x2, self.x1 = self.x1, med
        self.y2, self.y1 = self.y1, y
        # 3) 死区：残余微抖直接归零，避免阻抗积分器被“推着走”
        return 0.0 if abs(y) < self.deadband else y

解读：（1）中值窗只有 3 拍是刻意的：窗越长，阶跃边沿的"半个窗"延迟越明显，而 3 点中值只延迟 1 拍、还能完整剔除单点尖峰，对于 1–2 ms 的撞击毛刺正好够用。（2）低通用直接型二型（DF-II），每周期只要 5 次乘法，1 kHz 下毫无压力；换成 FFT 或滑动平均要么引入大延迟、要么通带形状不受控。（3）死区放在最后（不放最前）：如果死区在低通之前，低通的记忆会"补回"被死的信号，出现缓慢恢复的尾巴；放在最后则输出干净。

片段 3：惯性/重力补偿与偏置标定

def external_force(f_meas, rotation, m_tool, a_tool, g=9.81):
    """把“表观力”还原成真实外接触力：
    F_ext = F_meas - R*(0,0,m_t*g) - m_t*a_t   （工具坐标系）"""
    # 重力在工具系的投影随姿态变化：这就是“换个姿势手感变了”的根源
    f_gravity = rotation @ np.array([0.0, 0.0, m_tool * g])
    return f_meas - f_gravity - m_tool * a_tool

class BiasCalibrator:
    """偏置标定：静止且无接触时低速更新零点，时间常数 5 s。"""
    def __init__(self, dt=1e-3, still_time=0.5, tau=5.0):
        self.dt, self.still_time, self.tau = dt, still_time, tau
        self.bias = 0.0
        self.timer = 0.0

    def update(self, f, v_robot, contact):
        # 只有“机器人几乎不动”且“确认无接触”才允许动偏置：
        # 运动中或接触中更新，会把真实力当成零点“学”掉
        if (abs(v_robot) < 0.002) and (not contact):
            self.timer += self.dt
            if self.timer > self.still_time:
                self.bias += (f - self.bias) * self.dt / self.tau
        else:
            self.timer = 0.0
        return f - self.bias

解读：（1）重力补偿写成矩阵乘法，不用分姿态的查表：R 来自正运动学，任何姿态都能算，泛化性好；忘记这一项时，机器人手腕一转，等效力就变化几牛，用户看到的是"换个方向压，力就不同"。（2）惯性项需要工具加速度 at：可以从关节加速度经雅可比估计（误差稍大），也可以直接读电机电流粗估；高速打磨/装配时这一项可达几牛，必须补。（3）偏置标定的双门控（静止 + 无接触）是安全底线：无接触判断可以来自"机器人所在位置离已知工件足够远"或"力在死区内且位置未下降"。偏置让"力读数"与"真实接触力"对齐，误差 0.5 N 以下时，1 mm 级别的虚假位置偏移就消失了。

常见坑

  • 滤波器截止一味求低：为"干净"把 fc 压到 5 Hz，接触瞬间的力上升被延迟 30 ms 以上，力回路相位裕度不足，表现为接触"发飘"/超调。修复：fc ≥ 10 倍力回路带宽，40 Hz 起步。
  • 用均值滤波对付尖峰：均值把尖峰的能量平摊进后续几拍，等于人为制造了一个"假冲量"；中值直接丢弃。修复：尖峰用中值，噪声用低通，各司其职。
  • 忘做工具惯性补偿：快速移动时（at = 5 m/s²、mt = 2 kg）读数多 10 N，控制器以为撞上东西，主动"让位"10 N/Kd = 20 mm。修复：加速度估计 + 补偿项，且补偿在偏置之前。
  • 在接触中重标定偏置：有些实现"发现读数稳定就更新零点"，结果把真实的 15 N 接触力"学会"成零点，力瞬间掉到 0。修复：更新必须由"无接触"状态显式使能。
  • 死区开得太大：死区 1 N 的直接后果是 2 mm 的位置死区（Kd = 500），精密贴合任务贴不上去。修复：死区取噪声 RMS 的 5–10 倍即可（典型 0.2–0.3 N），精度要求高时改用滞回 + 偏置精标定。

  2. 推导"尖峰→速度跳变"的量化关系：设脉冲面积 I = Fpeak·Δtp，证明 Δv ≈ I/Md，并计算 5 kg 工具、40 N×2 ms 尖峰对 Md = 1 kg 阻抗系统的速度扰动。★★
    提示
    对 Mdẍ = −F 在脉冲宽度内积分：Md·Δv = −I。I = 0.08 N·s → Δv = 80 mm/s，这解释了为什么撞击瞬间不加中值滤波会"抖一大下"。

    二阶低通相位 φ = −atan2(2ζω/ωc, 1−(ω/ωc)²)；ω/ωc = 2/40 时约 −4°，2/8 时约 −20°，再叠加回路本身的相位滞后，裕度被从 60° 压到 40° 上下。
  4. 设计一个"撞击后自动重标定避让"流程：机器人碰到未知障碍导致读数尖峰后，如何在 1 s 内恢复干净的力估计而不误把接触力当偏置？写出状态机（状态名 + 转移条件）。★★★
    提示
    状态：正常 → 冲击检测（|ΔF| > 20 N/ms）→ 保持（拒绝更新偏置、用中值+滤波输出）→ 回退/撤离（位置回撤直到力回到死区持续 0.3 s）→ 重标定（静止采样 0.5 s）→ 正常。关键是"接触消失"必须用位置+力双重确认。

小结

  • 阻抗模型本身对力噪声是二阶低通：高频噪声的位移影响可忽略，真正要管的是低频漂移、偏置与脉冲尖峰。
  • 三类假力三类对策：漂移用偏置标定、惯性与重力用模型补偿、尖峰用中值滤波。
  • 调理链顺序：中值 → 低通（fc ≈ 40 Hz）→ 死区（0.25 N）→ 偏置；总延迟约 6 ms，必须计入时延预算。
  • 偏置更新的双门控（静止 + 无接触）是防止"把真实力学成零点"的安全设计。
  • 力信号调理的每一毫秒延迟都会进耦合回路的相位账本，滤波不是越狠越好。
  • 下一章处理对称问题：导纳控制中，噪声从位置传感器进入，经差分放大变成速度噪声，同样的"调理"思想，不同的数学。
