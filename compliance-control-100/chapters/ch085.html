第 085 章：导纳控制中的滑模控制

导纳控制生成"应该在哪"的参考轨迹，可内环跟得住吗？摩擦和模型误差会让内环永远差一截。本章把上一章的鲁棒项升级成完整的滑模控制器：等效控制负责"贴着参考走"，切换项负责"对抗不确定"，边界层负责"不抖"。

  • 主题：导纳控制 / 滑模控制（sliding mode control, SMC）
  • 关键公式：σ = ė + λe，τ = τ̂ref − K·sat(σ/φ)
  • 预计学时：65 分钟
  • 前置章节：第 084 章

学习目标

  • 理解导纳控制"外环给参考、内环做实现"的两层结构，以及内环跟踪误差如何污染柔顺精度（力偏、响应迟）。
  • 会在关节空间构造滑模面 σ = ė + λe，并解释到达阶段与滑动阶段各自的行为。
  • 会推导等效控制 τ̂ref = M̂q̈r + Ĉq̇r + ĝ，以及利用 Ṁ − 2C 反对称性证明滑模到达条件 V̇ ≤ −Σ(Ki − δi)|σi| < 0。
  • 会定量说明滑模控制的三笔代价：抖振（切换幅值 K 与离散频率）、模型依赖（等效控制需要动力学模型）、残差（边界层 φ 决定）。
  • 能设计"导纳外环 + 滑模内环"的双环实现，并处理力噪声、参考微分与切换项的相互作用。

背景与动机

导纳控制的结构是两层：外环把测到的力经导纳方程变成参考位置 xr(t)，内环让机器人去追这个参考。教学示例里内环常被简化成"一阶快跟随"，真机上它却是一个带摩擦、惯量变化、减速器柔性的非线性系统。内环跟不准，柔顺就失真：你的导纳模型说"现在应该比表面深 3 mm"，实际只有 2 mm，接触力就少三分之一；更糟的是低速接触时库仑摩擦造成"粘滞—滑动"交替，末端走走停停，导纳外环会以为环境在"推拉"它。

第 084 章的鲁棒项已经给出了对抗不确定性的基本武器，本章把它用满：把整个内环重写成滑模控制器（sliding mode control, SMC），不再只加一个小修正项，等效控制项负责按模型"预演"理想的加速度、速度与重力载荷，切换项负责碾压一切建模偏差。它解决的核心问题是"存在有界摩擦与建模误差时，内环的跟踪精度问题"；代价是控制信号在边界层内的高增益、对模型的依赖，以及参数没整好就出现的抖振。

时序上注意分工：导纳外环仍然在 1 kHz 下运行并输出 xr；滑模在内环同一周期内计算，跟踪的正是外环的（滤波后）参考。外环保柔顺、内环保精度，两者频率相同但职责不同。

核心原理

1. 从鲁棒项到滑模：把"护栏"变成"铁轨"

回想第 084 章的流形 s = ė + Λe：状态到达 s = 0 后，误差按 e−Λt 衰减；鲁棒项只是在流形外施加修正。滑模控制（SMC）做的是同一件事，但把设计系统化到整台机械臂：

σ = ė + λe，e = q − qr q：关节角向量（rad）；qr：导纳外环生成的关节参考；λ：对角正定矩阵（1/s）

σ = 0 是 n 维"滑动面"。控制分两段：到达阶段，从任意初始状态把 σ 压向 0，靠切换项完成；滑动阶段，状态被约束在 σ = 0 上，误差按 e(t) = e(0)e−λt 衰减，靠等效控制完成。因为滑动面上的行为是"由设计者写死的"，所以它对扰动不敏感，这正是滑模控制的招牌。工程直觉：鲁棒项是过道里的护栏，滑模控制器是搬进了整条轨道，轨道上怎么走（λ）、谁来推着走（等效控制）、有人推你出去怎么回来（切换项），三件事分得清清楚楚。

2. 等效控制的推导：先把能算的算干净

机械臂关节空间动力学（n 个关节，与第 009、013 章同一形式）：

M(q)q̈ + C(q,q̇)q̇ + g(q) + f(q̇) = τ + τext M：惯量矩阵（kg·m²）；C q̇：科氏/离心项（N·m）；g：重力力矩；f：摩擦（库仑+黏滞）；τ：关节力矩；τext = JTFext：接触力折算力矩

对 σ 求导并乘 M：Mσ̇ = M q̈ − M q̈r，其中 q̈r ≜ q̈d − λė 是把滑模面"当作期望加速度"后反推的参考加速度。把动力学代入：

Mσ̇ = τ + Δ − Mq̈r − Cq̇ − g Δ 把 τext 与摩擦等一切不确定性打包：|Δ|i ≤ δi（逐关节有界）

若模型精确且没有不确定性，令 Mσ̇ = 0 可解出"让 σ 保持为零"的力矩，这就是等效控制：

τref = Mq̈r + Cq̇r + g ⟹ 实际用估计模型：τ̂ref = M̂q̈r + Ĉq̇r + ĝ M̂、Ĉ、ĝ 为名义模型；它们的误差也进入 Δ，用切换项兜住

注意 q̈r 从哪来：由滑模面定义 q̈r = q̈d − λė，只需要参考加速度与速度误差，不需要对噪声信号做二阶差分，这正是滑模设计比"直接 PD 追 xr"更有条理的地方。

3. 到达条件：用 Ṁ − 2C 的反对称性把证明做完

取 V = ½σTMσ（物理含义：在"σ 方向"上系统还剩多少动能），求导：

V̇ = σT(Mσ̇ + ½Ṁσ) = σT(τ + Δ − τref) + σT(½Ṁ − C)σ 最后一项恒为零：机械臂有 σT(Ṁ − 2C)σ = 0 的反对称性质（第 013 章用过）

这项消去是滑模控制能"只跟模型误差打交道"的关键：惯量与科氏项内部的耦合不产生能量。选择力矩

τ = τ̂ref − K·sat(σ/φ) K = diag(Ki)：切换增益（N·m）；sat 逐分量作用；φ：边界层（rad/s）

则 V̇ = σT(Δ̃ − K·sat(σ/φ))，其中 Δ̃ = Δ + τ̂ref − τref 是"总不确定性"。在层外逐分量分析：只要 Ki > δi，每项 −(Ki−δi)|σi| 都为负，于是

V̇ ≤ −Σi(Ki − δi)|σi| < 0 （层外） 有限时间到达；层内有 miσ̇i = −(Ki/φ)σi + Δ̃i ⟹ |σi| ≤ φiδi/Ki < φi

结论与第 084 章完全同构，只是标量换成了向量、kv 换成了"切换项在层内的等效增益 Ki/φi"。工程直觉：滑模的精度由"层内等效增益 K/φ 与不确定性界 δ 的比值"决定，与"多用力"无关，δφ/K 就是你在滑动面上的速度残差刻度。例：δ = 8 N（摩擦+建模误差）、φ = 0.01 rad/s、K = 12 N·m，残差 |σ| ≤ 0.0067 rad/s，折算关节位置误差 σ/λ = 0.33 mm 量级，而同样摩擦下纯 PD 内环的稳态误差是 δ/kp = 8/400 = 20 mm，差两个数量级。

4. 代价与导纳外环的交互

第一笔代价是抖振：Ki 是切换项的幅值，也是最坏情况下的"抖振燃料"；离散实现里切换频率被采样周期锁死在 1/T（1 kHz），力矩纹波的幅值可达几个 N·m，直接反映到关节磨损与力传感器读数上。缓解：sat + 中等 φ、对 τ 再低通、或把切换项改为积分型。第二笔代价是模型依赖：等效控制要算 M̂、Ĉ、ĝ，计算量在 n 关节时是 O(n³) 量级（M̂ 求逆）；模型不准则 δ 增大，进而要么加大 K（更抖）要么放宽 φ（更糙）。第三笔代价是残差：φ 与 K 的组合固定了精度上限，不会像自适应那样随环境变好。

与导纳外环的交互有两条要盯住：（1）导纳参考 xr 由含噪力信号生成，滑模面对误差求导会放大噪声，所以 σ 里用的 ė 必须来自位置速度的滤波估计，q̈r 直接由导纳方程解析给出的加速度（见代码）。（2）滑模内环产生的高频力纹波会被力传感器拾取，进入导纳方程后又被"翻译"成位置抖动，形成内环—外环的串扰；所以 φ 不能太小，必要时在导纳输入端加 30–50 Hz 低通。

实现思路与设计

  1. 外环照旧：导纳方程（第 002/083 章）以 1 kHz 生成 q̈r、q̇r、qr。关键技巧：不要把 q̈r 用差分算，它由导纳方程右端直接给出（Md 除过去），精度高、噪声小。
  2. 滑模面参数：λ 取 15–30 s−1（对应 30–60 ms 滑动收敛时间）；λ 太大对噪声敏感、太小恢复慢。
  3. 增益自不确定性清单：Ki = (1.3–1.5)·δi。δi 估算 = 摩擦上界 + 负载惯量偏差折算 + 10% 模型误差折算。本例取 8 N·m 内、K = 12 N·m。
  4. 边界层：φ 由"允许的速度残差"反推：φ < λ·eallow。要 0.5 mm 精度、λ = 20，则 φ ≈ 0.01 rad/s（注意单位与关节半径换算）。
  5. 离散与限幅：τ 双向限幅（如 ±40 N·m），并检查 K 与 1/T 的关系，切换周期不能低于采样，否则等效于随机切换。
  6. 切换平滑：sat 已经是第一层平滑；第二层可对切换项单独做 200 Hz 一阶低通，滤掉离散纹波而不伤低频鲁棒性。
设计决策：什么时候不该用滑模内环？

滑模内环把位置跟踪做得又快又准，但两件事会劝退它：（1）机器人自带高质量关节力矩闭环（如力控型协作臂），内环已足够干净，加滑模反而引入抖振源；（2）任务本质是"顺应"，比如拖动示教，此时内环越硬，手感越差。判据：只有当"内环跟踪误差已经污染柔顺任务指标"（实测残余力偏差、迟滞）时才值得上滑模，并且始终记住它的三笔代价：抖振、模型依赖、残差。

关键代码与解读

片段 1：滑模内环控制器

import numpy as np

class SlidingModeInnerLoop:
    """导纳外环的内层：等效控制 + sat 切换项，跟踪 (q_r, dq_r, ddq_r)。"""
    def __init__(self, lam=20.0, K=12.0, phi=0.01, tau_max=40.0):
        self.lam = lam          # 滑动面斜率：滑动段的误差时间常数 1/lam = 50 ms
        self.K = K              # 切换增益（N*m）：必须大于不确定性界 delta，留 30-50% 余量
        self.phi = phi          # 边界层（rad/s）：精度与抖振的折中旋钮
        self.tau_max = tau_max

    def torque(self, q, dq, q_r, dq_r, ddq_r, m_hat=2.0, b_hat=5.0):
        # 滑模面：sigma = e_dot + lam*e，单位 rad/s（一维示范，多关节逐分量同样成立）
        e, de = q - q_r, dq - dq_r
        sigma = de + self.lam * e
        # 等效控制：按名义模型"预演"参考加速度与黏滞项，把能算的算干净
        # 摩擦、负载偏差、m_hat/b_hat 的误差都进不确定性 delta，由切换项兜底
        tau_ref = m_hat * ddq_r + b_hat * dq_r
        # 切换项：sat 保证层内线性，层外满幅；层内等效增益 = K/phi
        tau_sw = -self.K * np.clip(sigma / self.phi, -1.0, 1.0)
        tau = tau_ref + tau_sw
        return float(np.clip(tau, -self.tau_max, self.tau_max)), sigma

解读：tau_ref 用的是 参考速度 dq_r（严格形式是 C(q,q̇r)q̇r + g），实测速度只出现在滑模面里；一维示例里黏滞项 b·dqr 只是示意。三个参数与理论一一对应：K 是切换幅值（对抗不确定性），phi 是边界层（决定精度与抖振），lam 决定滑动段收敛。注意 tau_sw 层内的系数是 K/φ = 1200（等效阻尼量级），正是它把外界扰动"顶住"，所以 φ 不能随便往小取，否则这个等效增益会顶到执行器带宽的痛处。

片段 2：导纳外环 + 滑模内环的整机仿真

def run(use_smc, dt=1e-3, n=3000):
    """一维轴：导纳外环生成 q_r，滑模/PD 内环跟踪；环境提供接触力。"""
    m, b, f_c = 2.0, 5.0, 8.0      # 真实惯量、黏滞、库仑摩擦（库仑项内环不知道）
    m_d, d_d, k_d = 1.0, 30.0, 300.0   # 导纳参数（第 083 章形式）
    smc = SlidingModeInnerLoop()
    q = v = q_r = dq_r = 0.0
    tau_log = []
    for i in range(n):
        f_env = 5000.0 * (q - 0.0) if q > 0.0 else 0.0   # 环境表面在 q=0
        # 导纳外环：由力误差解出参考加速度；注意 ddq_r 是解析给出的，不做差分
        ddq_r = (15.0 - f_env - d_d * dq_r - k_d * (q_r - 0.0)) / m_d
        dq_r += ddq_r * dt
        q_r += dq_r * dt
        # 内环：滑模（含等效控制）或纯 PD（无摩擦补偿，作对照）
        if use_smc:
            tau, _ = smc.torque(q, v, q_r, dq_r, ddq_r)
        else:
            tau = m_d * ddq_r + 400.0 * (q - q_r) + 60.0 * (v - dq_r)
        # 真实被控对象：接触反力 - 库仑摩擦（tanh 平滑，模拟低速粘滞）
        tau -= b * v + f_c * np.tanh(v / 0.01)
        v += (tau - f_env) / m * dt          # 接触反力与运动方向相反：这是"接触"的物理定义
        q += v * dt
        tau_log.append(tau)
    return abs(q - q_r), abs(15.0 - f_env), np.std(tau_log[-200:])

for mode, flag in (("PD ", False), ("SMC", True)):
    e_in, e_f, jit = run(flag)
    print(f"{mode}  内环位置残差={e_in*1000:6.2f} mm  "
          f"接触力误差={e_f:5.2f} N  力矩抖动={jit:5.2f} N*m")

解读：这段仿真把"内环跟踪差 → 柔顺指标差"的因果链直接量化出来。预期 PD 对照的接触力误差是牛级（因为 8 N 库仑摩擦在 kp = 400 下产生 20 mm 跟踪缺口，导纳外环只能补偿一部分），SMC 则把它压到亚牛级。三个实现细节为什么这样写：（1）ddq_r 由导纳方程解析给出，这是双环结构里最容易被写错的地方，用差分替代会把力噪声放大成参考加速度噪声；（2）库仑摩擦用 tanh(v/0.01) 平滑，用来模拟真实的低速过渡，也避免理想符号函数在零速附近造成数值病态；（3）抖动指标取最后 200 拍的力矩标准差，它对应"切换项与离散采样"的组合效应，如果这个数接近 K，说明 φ 太小或 K 太大。

片段 3：边界层整定小工具

def tune_layer(delta, K, lam, e_allow):
    """给定不确定性界 delta、增益 K、允许误差 e_allow，反推边界层 phi。"""
    # 理论残差 |sigma| <= delta*phi/K，而位置残差 ~= |sigma|/lam
    phi_from_err = e_allow * lam * K / delta     # 由 e_allow 反推 phi 的上限
    phi_noise = 0.01                             # 速度估计噪声对应的下限（rad/s）
    phi = float(np.clip(phi_from_err, phi_noise, 0.05))
    sw_gain = K / phi                            # 层内等效增益：越大越硬、越抖
    print(f"delta={delta:5.1f} N*m  K={K:5.1f} N*m  phi={phi:.4f} rad/s  "
          f"层内等效增益={sw_gain:6.0f}  理论残差={delta*phi/K/lam*1000:5.2f} mm")
    return phi

tune_layer(8.0, 12.0, 20.0, 0.0005)   # 想要 0.5 mm 精度：phi 需多小？
tune_layer(8.0, 12.0, 20.0, 0.002)    # 放宽到 2 mm：phi 增大，等效增益回落

解读：工具函数把"要多少精度"翻译成"φ 取多少"，同时打印层内等效增益 K/φ 提醒你代价：想要 0.5 mm 需要 φ ≈ 0.015 rad/s，等效增益约 800，已经远超常见关节的等效黏滞阻尼量级，于是"理论精度"和"实际可实现的精度"分道扬镳。正确的使用方式是反向的：先看硬件的速度环能承受多大的等效增益（经验上 K/φ 不超过速度环刚度的 1/5），再算出可达精度，然后决定是否需要换用第 086–089 章的其他方法。

常见坑

  • 参考加速度用差分：对 qr 两次差分得到的 q̈r 被力噪声污染，等效控制"预演"错方向，内环看起来在抖。修复：由导纳方程解析计算 q̈r；外部轨迹参考也至少用二阶滤波光滑后再用。
  • K 小于不确定性界：σ 停在层外不收敛，力矩呈低频摆动。修复：K = 1.3–1.5δ，并检查摩擦上界的估算是否漏项（负载、线缆、气路都是常见漏项）。
  • φ 太小：切换项等效增益 K/φ 达到数千，激励关节柔性/减速器共振，听感是尖锐啸叫，力传感器上出现几十 Hz 的纹波，还会经导纳外环放大。修复：φ 从 0.02 rad/s 起调，按 K/φ ≤ 速度环刚度 1/5 的约束收敛。
  • 切换项直接接导纳输入：内环的力矩纹波→接触力纹波→导纳当成真实动力学响应，位置参考开始抖。修复：导纳输入端 30–50 Hz 低通；或把切换项的低通放在内环输出侧（二选一，避免双滤波带来过多相位滞后）。
  • 拿 SMC 去"补"轨迹规划的错误：参考本身跳变（阶跃）时，滑模面无法处理它，抖动会放大。修复：滑模跟踪的参考必须连续可微，把规划器输出先过 20–50 Hz 的平滑滤波。

练习与思考

  1. 验证 V̇ 推导中 σT(½Ṁ − C)σ = 0 的反对称性条件：写出 M、C 的定义或给出小例子（如二连杆在特定构型）说明为什么对任意 σ 成立。★★
    提示
    机械臂满足 Ṁ = C + CT，于是 ½Ṁ − C 是反对称矩阵；反对称矩阵的二次型恒为零：xTAx = −xTATx。
  2. 由 |σ| ≤ δφ/K 与 σ ≈ λe（稳态时 σ 近似常数），推导位置残差公式 ess ≈ δφ/(Kλ)，并用片段 3 的数字验证两档精度。★
    提示
    稳态时 σ = ė + λe 中 ė≈0，所以 e≈σ/λ；代入 |σ| 的上界即可。这也是"精度由 δφ/(Kλ) 四个数决定"的出处。
  3. 把片段 2 的内环换成 PD 并把 kp 从 400 加到 1600、3200，观察内环残差与接触力误差，再继续加到出现振动为止。解释"为什么纯增益提升打不过摩擦不确定性"。★★
    提示
    PD 残差随 kp 线性下降（8/kp），但 kp 高到与采样/未建模动态共振时会失稳；滑模在"低增益"下就把残差压到 δφ/K 量级，因为它用了模型前馈。
  4. 设计实验：固定 K = 12、λ = 20，把 φ 从 0.0005 扫到 0.05（十倍步进），记录接触力误差与力矩抖动，画出权衡曲线，并标出"进入稳定抖动区"的临界 φ。★★★
    提示
    小 φ 端抖动快速上升（层内增益 K/φ），大 φ 端残差按 δφ/(Kλ) 线性变大。临界点约在"抖动开始指数上升"的拐点，本例附近 0.005–0.01。

小结

  • 滑模内环解决"外环柔顺、内环失准"的矛盾；σ = ė + λe，滑动段误差按 e−λt 衰减。
  • 控制律 = 等效控制 + 切换项：τ = M̂q̈r + Ĉq̇r + ĝ − K·sat(σ/φ)；反对称性让 V̇ 只剩"不确定性"一项。
  • 到达条件 Ki > δi；层内残差 |σi| ≤ δiφi/Ki，位置残差 ≈ δφ/(Kλ)。
  • 三笔代价：抖振（K 与采样频率）、模型依赖（等效控制要模型）、残差（φ/K 决定上限）；与导纳外环的串扰要靠滤波与适中的 φ 管理。
