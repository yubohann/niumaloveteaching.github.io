第四篇 · 高级柔顺任务与约束

第 071 章：导纳控制中的虚拟工具

在软件里"装配"一个并不存在的工具：把柔顺中心、杠杆、质量与低通打包成一组以工具几何表达的参数，让机器人像握着 RCC 手腕一样自动对中。

  • 主题：虚拟工具 / 柔顺中心 / 参数打包
  • 关键公式：Kflange = Tin·Ktip·TinT，Tin = [[I,0],[S(r),I]]
  • 预计学时：55 分钟
  • 前置章节：第 070 章

学习目标

  • 理解"虚拟工具"的三层含义：工具几何（尖端、质心、杠杆）、可设计的柔顺中心、以及结构滤波与虚拟质量。
  • 会把"尖端柔度/刚度设计"搬运到法兰：Kflange = TinKtipTinT，并用校核程序验证柔顺中心落在哪。
  • 会用柔度预算（ct、cθ、dRCC）把"插入自对准"定量化：偏差 → 力 → 让位与转角。
  • 理解虚拟质量的替代逻辑：用 0.3–1 kg 的虚拟质量代表真实 2 kg 工具，同时保持重力补偿的正确性。
  • 会为虚拟工具选择低通与带宽，使工具结构振动不进入位置指令。
  • 能接受"换工具 = 换一组参数文件"的工程现实，并知道参数里最容易出错的三项。

背景与动机

真实工具都有自己的几何与柔性：砂轮盘不可能是理想质点，倒角探针的柔性集中在什么位置是机械设计决定的。可编程的机器人没有这些"先天属性"，除非你在软件里把它们建模出来，这就是虚拟工具（virtual tool）：在导纳回路中插入一个可参数化的"工具行为层"，让机器人表现得像握着真工具，而且比真工具更好调。

它最经典的应用是软件 RCC（remote center of compliance，远心柔顺）：机械 RCC 手腕曾靠一对弹簧片把"柔顺中心"放到轴尖后方 50–80 mm，装上它插轴成功率立刻提升；虚拟工具用导纳回路实现同样的几何，横向力在柔顺中心处主要产生平移、并附带让工具自对准的转角。与七、八两章的六维参数相比，虚拟工具本质上是一套把 6×6 参数翻译成"工具语言"的参数包装与验证方法，并未引入新的控制律，让每个换工具的早晨少调半天。

核心原理

1. 工具几何：尖端、质心、杠杆

虚拟工具的第一个职责是维护一条几何链：法兰坐标系 O → 工具尖端 T（沿工装方向偏移 rt，单位 m）→ 质心 COM（偏移 c，用于重力矩）。交互发生在尖端，测量发生在法兰，六维旋量的搬运沿用 ch068 的公式 mtip = mO − rt×f。链上每个点都要"标定"：rt 由工具图纸或一次接触测量得到（精度要到 1 mm 级，否则搬运误差直接变成虚假力矩）；c 与质量一起由重力标定得到。虚拟工具的第一个坑就藏在这里：换上第二把工具忘了更新 rt，前一章推好的柔顺中心全部错位，表现是"上一把工具插得好好的，这把怎么都不顺"。

2. 柔顺中心：把尖端的柔度"推到"法兰来执行

设计意图总是"我希望尖端怎么软"，执行接口却是法兰位姿。两者之间的搬运公式在刚度形式下是：

Ktip = T·Kflange·TT  ⟺  Kflange = Tin·Ktip·TinT T = [[I,0],[−S(rt),I]]（法兰→尖端）；Tin = [[I,0],[S(rt),I]]（其逆）

推导与 ch068 相同（δx 与旋量的搬运互为转置、KC = T KO TT），但使用方向反过来：六维阻抗是"在法兰设计、校核中心"；虚拟工具是"在尖端设计、搬回法兰执行"。举个数字：尖端想给 kt = 800 N/m 的横向柔度、kθ = 25 N·m/rad 的转动柔度，rt = 0.12 m；按公式搬回法兰后，法兰处会多出 800×0.12 ≈ 96 N/rad 量级的力-角耦合项，这就是"杠杆换来的自对准能力"。校验方法：重新解出 Kflange 的柔顺中心，应当落在尖端（或你指定的偏移处）。

如果还想让柔顺中心离开尖端、退到轴尖后方 dRCC（典型的 30–80 mm），只需在搬运前把 Ktip 先按"中心在 rt+dRCC"设计一次（即 B = −A·S(·) 的方法），整个链条完全复用第 068 章的两条公式。工程直觉：虚拟工具就是"参数住址"从枯燥的 6×6 矩阵搬到物理名词，尖端柔度、中心距离、工具长度、工具质量，每个数字都能在车间里被解释和校验。

3. 柔度预算：一次计算说清 RCC 为什么管用

把插入过程简化成静态柔度：孔沿横向偏差 e0，倒角接触的等效横向刚度 Kc（典型 1000–3000 N/m），则横向力 f = Kce0；尖端的横向让位由两部分组成，柔顺中心处的平移柔度 ct（m/N）与横向力乘杠杆 dRCC 引起的转角柔度 cθ（rad/(N·m)）在尖端再折算 dRCC·θ：

Δxtip = ct·f + dRCC2·cθ·f，  θ = cθ·f·dRCC θ：工具绕柔顺中心的转角；比值 dRCC2cθ/ct 决定"转动让位"占比

数值：e0 = 1 mm、Kc = 2000 N/m 时 f = 2 N；取 ct = 3×10−4 m/N、cθ = 0.05 rad/(N·m)、dRCC = 60 mm，则 Δxtip ≈ 0.6 + 0.36 = 0.96 mm，θ ≈ 0.34°。两点结论：（1）横向偏差被"让"掉了九成以上，轴才不会把孔沿撬住；（2）θ 虽小，但它是工具"顺着倒角滑入"的姿态自由度，缺了它插轴会周期性地卡在孔沿。把这两个数写进设计文档，比争论"刚度该取多少"高效得多。

4. 虚拟质量与结构滤波：把真工具的"坏脾气"留在虚拟世界里

真实工具的质量与惯量（2 kg、质心偏 80 mm）带来两个麻烦：冲击力大（Fpk ∝ √M，ch070）、结构振动（砂轮-杆件共振常在 100–300 Hz）。虚拟工具用两个手段解决：其一，导纳里的质量矩阵取"虚拟质量"0.3–1 kg，机器人按这个轻巧的质量响应外力，冲击与噪声同时受益；其二，导纳对力的响应本身就是二阶低通（转折约 √(Ka/Ma) = 5–20 Hz），而工具振动在 100 Hz 以上，两者差一个数量级，振动力矩在导纳的"积分惯性"面前被判为高频，几乎不产生位移响应。当然，重力补偿必须用真实质量与质心（虚拟质量只用于动力学，不管重力账），这个"两套质量"的分工要在参数文件里写明白。

实现思路与设计

  1. 建几何参数：rt（法兰→尖端）、c（法兰→质心）、mreal；接触测量 + 重力标定各做一次，存成工具配置文件。
  2. 定尖端指标：横/轴向刚度（或柔度）、转动柔度、期望柔顺中心距离 dRCC（插入类 30–80 mm，恰好覆盖轴长的 1/3–2/3 之间有一片"稳定插入区"）。
  3. 搬运到法兰：Kflange = TinKtipTinT；用第 068 章的中心反解代码校核 r*，应等于 rt+dRCC（沿 -工具轴方向）。
  4. 配质量与阻尼：Ma 平移 0.3–1 kg、旋转 0.02–0.05 kg·m²；D 按 2ζ√(KM)；加低通 10–20 Hz。
  5. 重力补偿分离：重力用 mreal、c；动力学用虚拟 M；两条数据流在代码里命名区分（m_real / m_virtual）。
  6. 验证：装一副"测量工装"：分别在尖端加 2 N、5 N 横向力，用外部测量（激光/刻度）核对尖端让位与转角，与第 3 节的预算表对照。

参数起点（插轴任务）：Ktip = diag(800, 800, 2000) N/m + diag(25, 25, 8) N·m/rad；dRCC = 60 mm；rt = 0.12 m；Ma = diag(0.5,0.5,0.5, 0.03,0.03,0.03)；ζ = 1.0；低通 15 Hz。

关键代码与解读

片段 1：从尖端刚度搬运到法兰（含中心校核）

import numpy as np

def skew(v):
    return np.array([[0.0, -v[2], v[1]],
                     [v[2], 0.0, -v[0]],
                     [-v[1], v[0], 0.0]])

def stiffness_tip_to_flange(K_tip, r_tip):
    """K_tip 在尖端定义，r_tip = 法兰->尖端位移；返回法兰处等效刚度。
    关系：K_tip = T K_O T^T  =>  K_O = Tin K_tip Tin^T，Tin = T^-1。"""
    Tin = np.block([[np.eye(3), np.zeros((3, 3))],
                    [skew(r_tip), np.eye(3)]])
    return Tin @ K_tip @ Tin.T

def center_of_stiffness(K):
    """反解柔顺中心（A 可逆时）：S(r) = -inv(A) B。"""
    A, B = K[:3, :3], K[:3, 3:]
    M = -np.linalg.inv(A) @ B
    r = np.array([M[2, 1], M[0, 2], M[1, 0]])
    return r, np.linalg.norm(M + M.T)      # 第二项：非对称残差，应为 0

r_tip = np.array([0.0, 0.0, 0.12])
K_tip = np.diag([800., 800., 2000., 25., 25., 8.])
K_f = stiffness_tip_to_flange(K_tip, r_tip)
r_center, asym = center_of_stiffness(K_f)
print("法兰等效刚度前 3x3 行:\n", np.round(K_f[:3, :3], 1))
print("柔顺中心 =", np.round(r_center, 4), " 非对称残差 =", f"{asym:.2e}")

解读：输出应当看到柔顺中心 = [0,0,0.12]，即"设计在尖端的柔度，校核回来还在尖端"，这一步是搬运公式的自证。移动中心（加 dRCC）的做法是先把 K_tip 按"中心在 rt+dRCC"重新生成一次再搬运，并不直接在 K_tip 里改 r：这样物理含义清晰，代码也复用同一段校核。留一个问题给你：把 K_tip 的旋转块调成 0（完全无转动柔度）再跑，center_of_stiffness 会怎样？（提示：残差仍接近零、中心公式仍给出尖端位置，但刚度矩阵出现零特征值：转动方向没有回复刚度，这正是"没有转动柔度就插不进轴"的数学表述。）

片段 2：虚拟工具导纳一步（几何搬运 + 低通 + 限幅）

class VirtualTool:
    """虚拟工具导纳：在法兰执行、以尖端交互、按虚拟质量响应。"""
    def __init__(self, K_flange, r_tip, m_virtual=(0.5, 0.5, 0.5),
                 I_virtual=(0.03, 0.03, 0.03), zeta=1.0, fc=15.0, dt=1e-3):
        M6 = np.array(list(m_virtual) + list(I_virtual))
        self.K = K_flange
        self.M, self.Minv = np.diag(M6), np.diag(1.0 / M6)
        self.D = np.diag(2.0 * zeta * np.sqrt(M6 * np.diag(K_flange)))
        self.alpha = 1.0 / (1.0 + 2.0 * np.pi * fc * dt)   # 一阶低通系数
        self.r_tip, self.dt = r_tip, dt
        self.dx, self.dv = np.zeros(6), np.zeros(6)
        self.w_lp = np.zeros(6)             # 低通后的交互旋量（法兰系）

    def step(self, w_meas_flange):
        # 低通放在导纳输入端：工具结构振动(>100 Hz)被压低，
        # 而 5-20 Hz 的任务频段几乎不衰减，这正是"虚拟工具"消振的全部秘密
        self.w_lp = self.alpha * self.w_lp + (1.0 - self.alpha) * w_meas_flange
        acc = self.Minv @ (self.w_lp - self.D @ self.dv - self.K @ self.dx)
        self.dv += acc * self.dt
        self.dx += self.dv * self.dt
        # 限幅作用在状态上：平移 25 mm、转角 0.25 rad（防 windup，见第 077 章）
        self.dx[:3] = np.clip(self.dx[:3], -0.025, 0.025)
        self.dx[3:] = np.clip(self.dx[3:], -0.25, 0.25)
        return self.dx

    def tip_offset_from(self, dx):
        """位姿修正后尖端相对法兰的位置变化：Δp_tip ≈ Δp + Δθ x r_tip。"""
        return dx[:3] + np.cross(dx[3:], self.r_tip)

解读：w_meas_flange 要求调用方已完成重力/惯性补偿与搬运，虚拟工具不替你做测量链，它只管"拿到干净的力后怎么像工具"。低通系数用 fc 与 dt 现算（不写死 0.95），保证换控制周期时截止频率不漂移。tip_offset_from 展示一个常被忽略的耦合：转角修正会让尖端位置变化，Δθ×rt 在 rt = 0.12 m、Δθ = 0.05 rad 时是 6 mm，比很多任务的允许横向误差还大。所以执行修正后必须用它更新"尖端在哪"，再交给位置回路或监控越界。

片段 3：RCC 柔度预算的数值核对

def rcc_budget(e0, K_c=2000.0, c_t=3e-4, c_th=0.05, d_rcc=0.06):
    """输入孔沿偏差与柔性参数，输出横向力、尖端让位与自对准转角。"""
    f = K_c * e0                             # 倒角接触：力与偏差近似线性
    dx_center = c_t * f                      # 柔顺中心处的平移让位
    theta = c_th * f * d_rcc                 # 横向力乘杠杆引起的转角
    dx_tip = dx_center + d_rcc * theta       # 尖端的净让位（平移 + 转动贡献）
    frac_rot = d_rcc * theta / dx_tip        # 转动让位占比：调参的关键指标
    print(f"e0={e0*1e3:4.2f} mm -> f={f:4.2f} N, 尖端让位={dx_tip*1e3:5.2f} mm, "
          f"对准角={np.degrees(theta):4.2f} deg, 转动占比={frac_rot*100:4.1f}%")
    return f, dx_tip, theta

for e0 in (0.5e-3, 1.0e-3, 2.0e-3):
    rcc_budget(e0)
# 调整 c_th 观察转动占比：0.02 -> 偏平移型；0.1 -> 偏转动型（更"软腕"）
for c_th in (0.02, 0.05, 0.1):
    print("c_th =", c_th); rcc_budget(1e-3, c_th=c_th)

解读：这段代码把"刚度取多少"的争论变成了三行可对比的输出。三个规律值得记住：让位与偏差成正比（K_c 固定时线性），转动占比由 d_rcc²·c_th/c_t 唯一决定，而增大 c_th（更软的腕）会把行为从"平移型"推向"转动型"。转动型对插轴更友好（工具能倾斜着找孔），但对轮廓跟踪类任务则是干扰，虚拟工具的参数从来不是越大越好，是"按任务选形状"。

常见坑

  • 换工具不换参数：rt、c、质量和柔度都是工具相关的，沿用上一把的参数会让柔顺中心错位。修复：工具配置文件版本化，上电自检打印"当前工具 ID + 三个几何参数"。
  • 只设计平移刚度，忘了转动：cθ = 0 时刚度矩阵出现零特征值、不再正定，柔顺中心失去意义，插轴卡孔沿时没有自对准自由度。修复：按第 3 节预算表核对转动占比，至少保留 20–40% 的转动让位。
  • 虚拟质量伪装成真质量：重力补偿误用 mvirtual（0.5 kg 替代 2 kg），工具真实重量被"少扣" 1.5 kg ≈ 14.7 N，导纳持续下坠。修复：重力账用真实参数、动力学账用虚拟参数，代码里分开命名并注释。
  • 低通开得太猛：为了彻底消振把截止频率压到 3 Hz，插入接触的力变化也被压成"慢动作"，表现为对孔反应迟钝、越插越偏。修复：截止频率 ≥ 导纳固有频率的 3 倍且 ≤ 工具共振频率的 1/5，两端一夹，可选区间其实不宽。
  • 中心距离过大：dRCC 超出轴长的 1.5 倍后，"自对准"变成"自摇摆"，工具尖端的横向让位过度、姿态晃。修复：dRCC 取轴长的 1/3–2/3；增大 D 提高姿态阻尼。

练习与思考

  1. 推导 Kflange = TinKtipTinT（由 ch068 的 KC = T KOTT 出发，说明 Tin = T−1）。 ★
    提示
    T = [[I,0],[−S(r),I]]，其逆为 [[I,0],[S(r),I]]；两边左乘右乘相应的逆即可。
  2. 计算：把 K_tip 旋转块设为零，用片段 1 的代码运行：柔顺中心还能解出来吗？非对称残差是多少？再观察法兰等效刚度 K_f 的特征值说明了什么。 ★★
    提示
    跑一遍会看到：非对称残差仍接近零（中心公式照常给出尖端位置），但 K_f 出现零特征值、不再正定：转动方向没有回复刚度，工具会自由旋转，"中心"失去工程意义，也就无法自对准。
  3. 实验：用片段 3 扫 ct = 1/3/6 ×10−4 m/N 与 cθ = 0.02/0.05/0.1，列出"转动占比"矩阵，给出你为"间隙 0.1 mm 的钢轴插入"推荐的组合与理由。 ★★
    提示
    间隙越小越倾向转动型（更软的腕更容易找孔）但姿态要稳；中等 ct + 大 cθ 是常见甜点，注意别让姿态阻尼不足。
  4. 设计：为一台 0.8 kg 的倒角探针配置虚拟工具：rt = 0.18 m、要求尖端横向 5 N 让位 1.5 mm、绕横轴 1 N·m 转角 ≤ 0.1 rad。给出 Ktip、dRCC、Kflange 的数值与校验步骤。 ★★★
    提示
    kt = 5/0.0015 ≈ 3333 N/m、kθ = 1/0.1 = 10 N·m/rad 起步；搬运后校核中心位置与特征值。
  5. 思考题：为什么虚拟工具能让"200 Hz 的结构振动"几乎不影响位移，却几乎不影响 10 Hz 的接触力响应？请从 H(s) 的高低频渐进线解释。 ★★
    提示
    高频段 |H| ~ 1/(Mω²)，200 Hz 处响应衰减约两个数量级；低频段 |H| → 1/K 保持完整。导纳 = 天然的频率选择器。

小结

  • 虚拟工具 = 工具几何（rt、c、mreal）+ 尖端柔度设计 + 柔顺中心 + 虚拟质量 + 输入低通，一套"以工具语言打包 6×6 参数"的方法。
  • 搬运关系：Kflange = TinKtipTinT，Tin = [[I,0],[S(rt),I]]；校核中心的代码与 ch068 共用。
  • RCC 预算：Δxtip = ctf + dRCC2cθf，θ = cθfdRCC；转动占比 dRCC2cθ/ct 按任务选型。
  • 虚拟质量只进动力学、真实质量管重力；低通截止频率被"导纳频率 ×3"与"结构共振 /5"两端夹住。
  • 转角修正会移动尖端（Δθ×rt 可达数毫米），必须反馈进位置/监控链路。
