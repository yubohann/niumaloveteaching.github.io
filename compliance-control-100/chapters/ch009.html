第一篇 · 基础、建模与稳定性

第 009 章：关节空间阻抗控制

把弹簧直接装在关节上：控制律最短、无奇异、不碰逆运动学；代价是末端软硬随姿态漂移、在奇异位形附近失控。本章讲清这条"最短路径"的收益与账单。

  • 主题：阻抗控制 / 关节空间实现
  • 关键公式：M(q)q̈ + Djq̇ + Kj(q−qd) = τext；Kx = J−TKjJ−1
  • 预计学时：50 分钟
  • 前置章节：第 008 章

学习目标

  • 会写出关节空间阻抗的动力学闭环：τ = Kj(qd−q) + Dj(q̇d−q̇)，并说明外力为什么以 τext = JTFext 的形式进入。
  • 理解关节空间实现的三大优势：无逆运动学、无奇异处理、对运动学标定误差不敏感。
  • 掌握映射公式 Kx = J−TKjJ−1，能解释为什么同一组关节刚度在不同构型下给出完全不同的末端手感。
  • 能用 1/det(J)² 的量级分析预测奇异位形附近等效刚度"爆炸"，并说出工程回避策略。
  • 会为关节阻抗选参数：逐关节刚度 100–2000 N·m/rad、临界阻尼、重力前馈与摩擦死区的处理顺序。

背景与动机

不是所有任务都从笛卡尔空间描述。示教回放、关节振动抑制、碰撞后柔顺卸力，这些任务的自然语言就是"每个关节多硬"；而把一切翻译成六维笛卡尔阻抗，既要算雅可比、又要处理逆解分支，控制周期还被吃掉一大截。关节空间阻抗把弹簧直接装在最底层：每个关节一根虚拟弹簧-阻尼，控制律一行就能写完，没有运动学逆解，没有奇异点，连标定误差都不敏感，因为关节角是电机编码器直接给的。

天下没有免费的手感：你在关节上装的弹簧，到了末端会变成"随姿态变化、各向异性、奇异点附近失控"的软硬分布。本章先把闭环推导干净，再算清这场"位置/姿态换算"的账，它是理解第 010 章（两种空间的互相转换）的必经之路。

核心原理

1. 关节空间闭环：把弹簧装在"最底层"

机器人关节动力学（保留惯量矩阵与重力，忽略科氏项作教学简化）：M(q)q̈ + g(q) = τ + JTFext，其中 M(q) 为 n×n 关节惯量矩阵（kg·m²），q（rad）为关节角，g(q)（N·m）为重力矩，τ（N·m）为关节力矩。控制器输出关节阻抗力矩：

τ = Kj(qd − q) + Dj(q̇d − q̇) + ĝ(q) Kj：关节刚度矩阵（N·m/rad）；Dj：关节阻尼（N·m·s/rad）；ĝ：重力前馈

代入动力学并假定重力补偿到位（ĝ ≈ g），得到闭环：

M(q)q̈ + Djq̇ + Kj(q − qd) = τext， τext = JTFext τext：末端外力在关节空间的等效力矩（N·m），由 JT 映射而来（第 006 章虚功原理）

稳态关系一步可得：q − qd = Kj−1τext，外力在关节上一格一格地"压出"偏差。这和第 001 章的一维结论完全同构，只是每个关节独立一支弹簧。因此外力不需要测量、不需要进入控制律：它通过物理方程和 JT 自然加载，与第 006 章力接口的思想一脉相承。若装有各关节力矩传感器，可以实测 τext 做碰撞判断；没有传感器时，τext 就是"机体自己感觉到的力"，做观测器估计即可（第 049 章）。

2. 三大优势：为什么工业界大量使用它

  • 无逆运动学：控制律在关节坐标里闭合，不需要每拍做 IK、不需要检查分支连续性、不受肘/腕构型跳变影响。对 1 kHz 级的硬实时循环，这一步省下的机时很可观。
  • 无奇异问题：关节空间里没有"雅可比不可逆"这回事，控制律在任何位形都有定义，精确伸直的姿态照样能柔顺（代价见第 4 节：末端手感此时不可用）。
  • 对运动学误差钝感：反馈量是编码器关节角，不依赖 DH 参数标定精度与 FK 的累积误差。对示教型、协作型应用，这直接转化为"所见即所得"的稳定手感。

代价同样明确：任务指标（力的方向、末端软硬）表达在笛卡尔空间，而参数装表达在关节空间，两者之间隔着一个随构型变化的雅可比。下一节把这个"隔阂"写成公式。

3. 映射公式：关节刚度怎么变成末端刚度

用虚功/小位移推导。设关节处弹性力矩 τ = Kjδq（δq 为关节偏离平衡的向量），对应末端广义力 F = J−Tτ（力用转置的逆把关节力矩搬回任务空间）；末端位移与关节位移由运动学相连：δx = Jδq，即 δq = J−1δx。串起来：

F = J−TKjδq = J−TKjJ−1δx ⟹ Kx = J−TKjJ−1 J 在平衡位形处取值；Kx：末端等效刚度（平移/姿态按任务维度自动混合）

这个公式有三个直接推论：第一，配置依赖，J 随构型变化，所以同一组 Kj 在伸直、弯曲、侧伸姿态下给出不同的 Kx，"手感"随动作漂移；第二，量级放大，J 的量纲是 m/rad，J−1 是 rad/m，平方之后刚度被打上"每米多少弧度"的换算：对 0.3 m 有效力臂，Kj=300 N·m/rad 大致对应 Kx ≈ 300/0.3² ≈ 3300 N/m，关节上几百牛米每弧度的"软"，到了末端常常已经是每米几千牛的"硬"；第三，各向异性自动出现，即使 Kj 对角，J 的方向性也会让 Kx 的椭球长短轴随位形旋转。

工程直觉：关节柔顺像给每个电机单独装减震器，电机舒服了，但传到手的振动大小取决于杠杆怎么放；笛卡尔柔顺像给手掌统一装一套减震，手感均匀，但你要先算清手臂的姿势。哪个更好，取决于任务的语言在关节里还是在手上。

4. 奇异位形附近：刚度的"黑洞"

Kx = J−TKjJ−1 里含有 J−1 的平方，而 J 的行列式在某些位形趋于零（2 连杆手臂完全伸直或完全折叠）。看数量级：det(J) → 0 时 J−1 的元 ∝ 1/det，Kx 的特征值 ∝ 1/det²。以第 005 章的 2 连杆参数（L1=0.35、L2=0.30）为例，Kj=diag(300,200)：正常位形下 Kx 的特征值在 5×102–4×104 N/m 之间游走；当第二关节角降到 0.05 rad（接近伸直）时，一个特征值冲到 4×106 N/m 量级，末端某个方向"硬得碰不得"，一点位置误差就是巨大的力；与此同时，与奇异方向对应的外力几乎不产生关节力矩，控制器"感觉不到"它，保护逻辑可能失灵。

工程上的应对首推回避工作区：任务规划时让机器人工作在 det(J) 尽可能大的区域（2 连杆的"肘部弯曲 90° 附近"是经典甜区）；无法回避时降低 Kj 或切换笛卡尔实现；再加上一条监控：在线计算 det(J)（或最小奇异值 σmin），低于阈值时报警并降刚度。注意奇异附近的"硬"与"钝"是同一枚硬币：一端是刚度爆炸，另一端是力→关节力矩的投影趋零。两者都说明：关节空间的参数在奇异点附近失去了对末端行为的解释力。

5. 参数怎么选

逐关节独立整定，量级参考：

用途关节刚度 Kj (N·m/rad)阻尼初值备注
拖动示教 / 零力示教30–1002√(KjMjj)配合重力与摩擦补偿才顺滑
碰撞吸能（软防护）50–200ζ=1–1.5越大关节越"绵"
常规柔顺装配200–600ζ=0.9–1.0末端等效刚度自动放大（见映射公式）
精密定位（近刚体）800–2000ζ=0.8–1.0接近位置控制行为，柔顺余量小

Mjj 取对应关节的惯量对角元（可从厂商模型或经验估），这个量在各关节间差异很大，底座关节可能比腕关节大两个数量级，所以 Dj 必须逐关节算，不能"一个阻尼值走天下"。重力前馈与摩擦补偿的次序：先补 g(q)（否则弹簧平衡点随姿态漂移，静态测试直接失败），再评估摩擦死区（第 012 章展开），先做后者会把重力造成的偏差误诊为摩擦。

实现思路与设计

关节阻抗的实现链路（力接口）比笛卡尔版短得多：

  1. 读关节状态：q 来自编码器（直接可信）；q̇ 用滤波微分或驱动器给定。
  2. 算力矩：τ = Kj(qd−q) + Dj(q̇d−q̇) + ĝ(q)；不需要 FK、不需要 J、不需要触力传感器。
  3. 限幅与安全：逐关节力矩饱和（第 006 章的顺序：先限幅关节力矩本体，因为这里没有任务空间目标）；速度超限时叠加/切换阻尼模式。
  4. 多模式切换：笛卡尔任务用第 008 章的 6 维实现；关节任务与奇异性兜底切到本节实现；切换时保证两边的"命令状态"连续（位置命令从当前实测出发、力矩命令从当前实测力矩出发）。
设计决策：什么信号能用来判断"该不该切回笛卡尔实现"？

三个可在线计算的标量可以组成判据：最小奇异值 σmin(J)（低于阈值说明接近奇异）、任务空间误差与关节误差的换算比、以及力矩饱和计数。实践中常见策略是"默认笛卡尔、奇异区切关节、用 σmin 的滞环做切换"，滞环宽度取 20%–30%，避免在阈值附近来回抖切。切换本身对控制器是一次"参数阶跃"，务必让两边的虚拟状态（关节目标、笛卡尔命令）在切换瞬间对齐到实测值，否则用户手感里会出现一次"顿挫"。核对方法：切换瞬间打印两边命令之差，应小于 1 mm / 0.5°。

还要给"关节柔顺"一个诚实的期望管理：由于 J−1 平方放大，同样的关节刚度在不同臂长下差异巨大，多轴联动的任务（如轨迹跟踪打磨）里末端刚度还会随轨迹缓慢变化。如果你的任务对末端力的重复性要求高（如 ±1 N），关节空间参数的"漂移"会吃掉精度预算，这类任务应规划为笛卡尔实现（第 010 章给出完整转换方案）。

关键代码与解读

片段 1：关节空间阻抗主循环，四个公式都不需要

import numpy as np

L1, L2 = 0.35, 0.30                       # 与第 005 章相同的 2 连杆

def fk(q):
    return np.array([L1*np.cos(q[0]) + L2*np.cos(q[0]+q[1]),
                     L1*np.sin(q[0]) + L2*np.sin(q[0]+q[1])])

def jac(q):
    return np.array([[-L1*np.sin(q[0]) - L2*np.sin(q[0]+q[1]), -L2*np.sin(q[0]+q[1])],
                     [ L1*np.cos(q[0]) + L2*np.cos(q[0]+q[1]),  L2*np.cos(q[0]+q[1])]])

q, qd = np.array([0.40, 0.50]), np.zeros(2)
M_jj = np.array([0.08, 0.05])             # 关节惯量对角元（kg·m²）
k_j = np.array([300.0, 200.0])            # 关节刚度（N·m/rad），别与末端刚度混淆
d_j = 2.0 * np.sqrt(k_j * M_jj)           # 逐关节临界阻尼（不是一个常数！）
q_d = q + np.array([0.06, -0.004])        # 期望关节位形：让末端压向墙面
xe, k_env, dt = 0.52, 1e5, 1e-3

for i in range(2000):
    q1, q2 = q
    x = fk(q)
    # 环境力只用于仿真动力学；控制律里没有任何外力项（同第 006 章）
    f_env = -k_env*(x[0] - xe) if x[0] > xe else 0.0
    tau_ext = jac(q).T @ np.array([f_env, 0.0])     # 外力→关节等效力矩
    # 控制律只有一行：关节弹簧 + 关节阻尼（重力项水平面运动为零）
    tau = k_j*(q_d - q) + d_j*(0.0 - qd)
    qdd = (tau + tau_ext) / M_jj            # 关节惯量（对角简化）
    qd += qdd * dt
    q += qd * dt
    if i % 400 == 0:
        print(f"t={i*dt:3.1f}s x=({x[0]:.3f},{x[1]:.3f}) F={f_env:6.2f}N "
              f"dq=({(q-q_d)[0]:+.4f},{(q-q_d)[1]:+.4f})rad")

解读：把这段与第 005 章的主循环并排比较，差异一目了然：没有 IK、没有期待位置、没有笛卡尔误差，控制律是关节坐标里的一行减法乘增益。三个容易踩的点：k_j 的单位是 N·m/rad，若误填成 N/m 的量级（如 500），末端会硬得面目全非（记得映射公式的平方放大）；d_j 必须逐关节算（本例两关节惯量差 1.6 倍，同一个阻尼值会让一个关节过阻尼、另一个欠阻尼）；q_d 的选择本身就是"任务设计"，它决定末端压向哪里、压多深，而不像笛卡尔实现那样有直接的"期望力"概念。运行后观察 dq：接触稳态时它稳定在 Kj−1τext，位置偏差的物理含义就是“关节弹簧被外力压出的形变”，与一维章节完全同构。

片段 2：映射公式的数值验证，同一参数，三种姿态三种手感

def cartesian_stiffness(q, k_joint):
    """由关节刚度反推末端等效刚度：K_x = J^{-T} K_j J^{-1}（伪逆防奇异）。"""
    J = jac(q)
    J_inv = np.linalg.pinv(J)             # 教学用伪逆；近奇异时数值发散是"信号"
    return J_inv.T @ np.diag(k_joint) @ J_inv

print("同一组 K_j = diag(300, 200) N·m/rad，不同姿态下的末端刚度：")
for tag, q in (("弯曲（甜区）", np.array([0.40, 0.50])),
               ("半伸",       np.array([0.40, 0.20])),
               ("侧摆",       np.array([1.20, 0.60]))):
    Kx = cartesian_stiffness(q, [300.0, 200.0])
    ev = np.linalg.eigvalsh(Kx)           # 特征值=椭球的主刚度（N/m）
    ratio = ev[1] / max(ev[0], 1e-9)      # 各向异性比
    print(f"{tag}: K_x 主刚度=({ev[0]:>9.0f}, {ev[1]:>9.0f}) N/m  各向异性比={ratio:6.1f}")

解读：预期输出告诉你三件事。量级：几百 N·m/rad 的关节刚度对应的是 102–105 N/m 量级的末端刚度（本例三姿态从 543 到 2.5×105），远超第 008 章推荐的 200–2000 N/m 柔顺区间，所以"关节柔顺"用于接触任务时必须把 Kj 压得很低（几十到一百 N·m/rad），否则末端根本"软"不下来。各向异性：三个姿态的主刚度比在 50–500 之间，说明末端手感是一只随姿态变化的椭球，无法用"一个数"概括。伪逆的边界：教学里用 pinv 让程序不崩，但看到特征值异常巨大或极小的输出时，应把它当作"该姿态接近奇异"的诊断信号；拿它当有效刚度使用会失准。注意"各向异性比只由 J 决定"这句话只在 Kj 各向同性（k·I）时成立：把 Kj 从 diag(300,200) 改成 diag(100,100) 重跑，弯曲姿态的比值会从约 72 变到约 92，因为 Kj 自身的方向性与 J 叠加了；只有按 k·I 等比缩放时，比值才保持不变、量级按 k 线性缩放。

片段 3：奇异位形扫描，刚度的暴涨与投影的熄灭

print("第二关节角扫描（q1 固定 0.3，逐渐伸直手臂）：")
for q2 in (1.00, 0.50, 0.20, 0.05):
    q = np.array([0.30, q2])
    J = jac(q)
    Kx = cartesian_stiffness(q, [300.0, 200.0])
    ev = np.linalg.eigvalsh(Kx)
    # 奇异方向上的力能否产生关节力矩？用法向量与奇异方向的夹角衡量：
    # 先取 J 的最小奇异向量 u（末端最"难动"的方向），算 ||J^T u||
    U, S, Vt = np.linalg.svd(J)
    u_min = U[:, -1]                      # 对应最小奇异值 σmin 的输出方向
    transmit = np.linalg.norm(J.T @ u_min)   # >0 才有力传进关节
    print(f"q2={q2:4.2f} det(J)={np.linalg.det(J):8.5f} σmin={S[-1]:6.3f} "
          f"K_x主刚度=({ev[0]:>9.0f},{ev[1]:>9.0f}) 力传导‖Jᵀu‖={transmit:.3f}")

解读：这张扫描表把奇异位形的两种病理同时摊开。刚度暴涨：σmin 从 0.14 降到 0.007 时，Kx 的最大特征值从约 1.1×104 冲到 4×106，控制器里写着"Kj=300"的温和数字，末端却硬如铁砧。力传导熄灭：σmin 对应方向上，‖JTu‖ 同步趋零，沿该方向推末端，几乎不产生关节力矩，虚拟弹簧"感觉不到"，阻尼器也"收不到信号"。这解释了一个现场困惑："为什么机器人伸到最直时，有时僵得像钢筋，有时软得像棉花，而且换个方向就换一种？"，同一位形、同一参数，两个病理方向可以同时存在。实操方案到此完全清晰：在线监控 σmin（用 SVD，1 kHz 对 2–6 维矩阵完全可行），设阈值与滞环，进警戒区就降刚度或切笛卡尔实现。把本片段的 q2=0.05 一行接进上一节的切换策略，就是一套完整的奇异防护雏形。

常见坑

  • 把关节刚度当末端刚度填：按"末端想 500 N/m"的思路给 Kj=500 N·m/rad，实际末端整体硬了十几倍。修复：先用片段 2 在几个典型姿态估算 Kx，按目标末端软硬反推 Kj。
  • 阻尼用一个常数：腕关节惯量比底座小两个数量级，同一 Dj 要么腕部欠阻尼抖动、要么底座过阻尼迟滞。修复：Dj = 2ζ√(KjMjj) 逐关节算，Mjj 不明就用标定或经验表。
  • 忘了重力前馈：关节弹簧的平衡点被重力矩平移，示教手感"下沉"，或者静态下机器人在低位'停不住'。修复：先做 ĝ(q)（模型或辨识表），再做摩擦评估。
  • 在奇异区里调试参数：在位形接近伸直时调好的参数，一到弯曲姿态就变味，调参者怀疑人生。修复：调参固定在有代表性的中位区（σmin 较大）；奇异区只单独验证安全性，手感指标在那里没有意义。
  • 多模式切换不对齐状态：笛卡尔模式与关节模式互切时命令跳变，表现为"顿一下"或瞬时冲击力。修复：切换时把两边的命令状态对齐到实测值，并在切换前后各锁一拍做平滑过渡。

练习与思考

  1. 写出关节空间阻抗的闭环方程并推导稳态关系 q−qd = Kj−1JTFext，说明外力如何在关节上"分配"。★
    提示
    稳态所有导数项为零；JTF 是外力对每个关节的等效力矩（虚功原理，第 006 章）。
  2. 用片段 2 计算 Kj=diag(300,200) 与 diag(100,100) 两组参数在"弯曲"与"半伸"两姿态下的 Kx 主刚度，观察各向异性比其实随 Kj 改变；再改用 diag(300,300) 与 diag(100,100)（k·I 形式）重算，验证此时各向异性比只由 J 决定、量级按 k 线性缩放。为什么两种情形的结论不同？★★
    提示
    Kx = J−TKjJ−1 对 Kj 是线性的，但方向信息也来自 Kj：只有 Kj = k·I 时 Kx = k·J−TJ−1，偏心度才纯由 J 决定；对角元不相等时 Kj 的方向性与 J 叠加，比值随参数变。
  3. 用片段 3 扫描 q2 ∈ [0.02, 1.0]，找到"最大主刚度首次超过 5×105 N/m"的临界角，并说明这个阈值对应的安全策略（降刚度还是切模式）。★★
    提示
    Kx ∝ 1/det²，det ≈ L1L2sin q2；5×105 大致在 q2 ≈ 0.1–0.2 rad 区间触发，策略取决于任务是否允许该姿态存在。
  4. 推导 Kx = J−TKjJ−1，再反向设计：给定目标 Kx*（笛卡尔），写出应设定的 Kj = JTKx*J，并解释为什么这个设计"只能在一个位形上精确成立"。★★★
    提示
    J 随 q 变化，Kj 固定而 Kx 变化；要全空间恒定 Kx，必须在线更新 Kj = JT(q)Kx*J(q)，这正是第 010 章要算的账。
  5. 设计一个"关节柔顺 + 碰撞保护"的完整方案：正常工作用笛卡尔 6 维参数（K=800 N/m 级），碰撞或奇异警戒时切关节模式（Kj=80 N·m/rad）。写出切换判据（至少两个信号）、切换时的状态对齐步骤、以及三个验收测试。★★★
    提示
    判据可用 σmin < 阈值、观测外力突增、力矩饱和计数；对齐：关节目标与笛卡尔命令都从实测生成；验收：切换冲击力 <5 N、切换后手推手感连续、奇异区末端力不超安全值。

小结

  • 关节空间阻抗的闭环：M(q)q̈ + Djq̇ + Kj(q−qd) = τext；外力经 τext=JTFext 自然进入，控制律不需要力传感器与逆运动学。
  • 三大优势：无 IK、无奇异定义问题、对运动学误差钝感；代价：末端刚度 = 关节参数经 J−T(·)J−1 的配置依赖映射。
  • Kx = J−TKjJ−1：随姿态漂移、量级被 1/det² 放大、各向异性自动生成；几百 N·m/rad 常常对应 102–105 N/m 量级的末端刚度。
  • 奇异位形是双向病理：刚度暴涨与力传导熄灭并存；工程对策是在线监控 σmin、降刚度或切笛卡尔模式，切换时对齐命令状态。
