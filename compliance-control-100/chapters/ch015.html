第一篇 · 基础、建模与稳定性

第 015 章：阻抗控制稳定性分析

理想的弹簧-阻尼环境耦合无条件是稳定的；真正决定生死的是延迟。本章把"力测量晚一拍"写进特征方程，解出临界环境刚度，并给出 D ≥ 2KenvTeff 这条可背下来的设计规则。

  • 主题：阻抗控制 / 延迟稳定性判据
  • 关键公式：Ms² + Ds + K + Kenve−sT = 0；Dcrit ≈ Kenv·T
  • 预计学时：60 分钟
  • 前置章节：第 014 章

学习目标

  • 会写出"理想阻抗 + 弹簧环境"的闭环特征方程，并说明为什么系数全为正时无条件稳定。
  • 会在反馈路径里引入纯延迟，把特征方程变成超越方程，并用实部/虚部联立解出临界环境刚度。
  • 能背出并推导小延迟近似：Dcrit ≈ Kenv·T，以及等价形式"接触阻尼比需达到 ζeff ≳ ωT/2"。
  • 会把采样、计算、滤波、通信延迟折算成一个等效延迟 Teff，并用 D ≥ 2KenvTeff 做设计核算。
  • 会用数值工具验证：临界增益求解 + 时域仿真的幅值增长比，双重确认边界。

背景与动机

前几章反复出现同一类现场故障："参数在仿真里对、在真机上振"。第 003 章把它归因于接触阻尼比被环境刚度稀释，第 014 章用"延迟账"给出了无模型方案的粗判据。本章把这件事做成完整的分析：理想阻抗控制为什么天然稳定？加入一个"力晚到 1 ms"的延迟后，稳定边界在哪里？答案会以一条极其简洁的规则出现：允许的环境刚度约为"阻尼 ÷ 延迟"。

这条规则的分量在于它把设计自由度重新排了座次：想稳刚性环境，放大刚度 K 没用，关键是加大阻尼 D 和压缩延迟 T；而阻尼与延迟都有物理与带宽的代价。理清这笔账，你就能在评审会上回答"为什么这台样机能压钢件、那台一碰就振"。

核心原理

1. 理想情况：为什么从不失稳

设阻抗已被精确实现（第 013 章的成果）：Mdẍ + Ddẋ + Kd(x−xd) = −F，环境为单侧弹簧 F = Kenv(x−xe)（F 为接触力幅值，与运动反向，符号沿用第 001 章）。把环境代入，闭环特征方程是：

Mds² + Dds + (Kd + Kenv) = 0 二阶多项式，三系数 Md、Dd、Kd+Kenv 全部为正

二阶系统稳定判据（劳斯判据的退化形式）：所有系数同号即稳定。三个参数都是物理正数，环境刚度只让"弹簧项"变大，理想阻抗回路对任意环境刚度无条件稳定，这就是阻抗控制比力/位混合控制更"皮实"的理论根源。注意此时接触阻尼比 ζeff = Dd/(2√(Md(Kd+Kenv))) 会随 Kenv 增大而下降（第 003 章）：响应变振荡，但极点实部始终为负，振荡 ≠ 失稳，理想回路里的振荡总会衰减。真正让极点越过分界线的，是延迟。

2. 引入延迟：超越方程与临界条件

现实回路里，控制器拿到的力（或机器人兑现位置）永远晚一步：采样保持、计算、通信、滤波。把总延迟记为 T（s），并假设它作用于力反馈路径，控制器实际使用的是 T 秒前的接触力。闭环变为

Mdẍ + Ddẋ + Kd(x−xd) = −Kenv(x(t−T) − xe) 特征方程：Mds² + Dds + Kd + Kenve−sT = 0 ， 含 e−sT，是超越方程

稳定边界出现在一对纯虚根 s = jω（系统从衰减振荡走向等幅/发散振荡的瞬间）。代入并分离实部、虚部：

实部： Kd + Kenvcos(ωT) − Mdω² = 0 ； 虚部： Ddω − Kenvsin(ωT) = 0 两个方程、三个未知量 (ω, Kenv, 给定参数)，给定机器人参数即可解出边界上的 (ω, Kenv,crit)

从虚部解出 Kenv = Ddω/sin(ωT) 代入实部，得到只含 ω 的方程：

Mdω² − Ddω·cot(ωT) − Kd = 0 ⟹ Kenv,crit = Ddω/sin(ωT) 先解出交叉频率 ω，再由它算出临界环境刚度；下一个代码片段把它实现为数值求解器

对小延迟（ωT ≪ 1）做展开：cot(ωT) ≈ 1/(ωT) − ωT/3，sin(ωT) ≈ ωT，于是第二式立刻给出 Kenv,crit ≈ Dd/T，第一式给出 ω² ≈ (Kd + Dd/T)/Md ， 注意它和接触自然频率 ωn=√((Kd+Kenv)/Md) 在数量级上一致，互为自洽。整理成设计形式：

稳定性规则：Dd ≥ Kenv·T（设计取 2–3 倍安全系数） 等价写法：允许的环境刚度 Kenv,max ≈ Dd/T；与刚度 Kd 基本无关

再把它翻译成阻尼比语言：边界处 ζeff·ωn = Dd/(2Md)，而 Kenv≈Dd/T ⟹ ζeff ≈ ωnT/2。工程直觉：延迟 T 相当于把"稳定所需的阻尼比"抬高到 ωT/2 附近，采样周期 1 ms、接触频率 317 rad/s 时，这个门槛是 0.16；自由空间里精心调到 1.0 的阻尼比，在接触回路里实际只有 0.07，越界了。这也再次解释了第 003 章"自由空间临界阻尼一接触就振"的现象，理论闭环在无延迟时稳，但现实的延迟把它推过了边界。

3. 把数字代进去：三个场景

取 Md=1 kg、Kd=500 N/m，扫描阻尼与延迟，用精确求解器（代码片段 1）算得的临界环境刚度：

阻尼 Dd (N·s/m)T = 1 msT = 2 msT = 5 ms
44.7（自由空间临界）≈ 4.5×104≈ 2.2×104≈ 0.9×104
100≈ 1.0×105≈ 5.0×104≈ 2.0×104
200≈ 2.0×105≈ 1.0×105≈ 4.0×104

三条结论直接写进设计准则：（1）量级律，Kenv,crit ≈ D/T 在整张表里成立（44.7/0.001≈4.5×104，100/0.005=2×104…），精确解与近似式偏差在 15% 以内（最大一格约 14%，延迟越大偏差越大）；（2）延迟是最贵的资源，T 从 1 ms 涨到 5 ms，允许的环境刚度缩水 5 倍，赶得上把阻尼加大 5 倍的效果；（3）把这句话背下来：钢件（105）配 1 ms 延迟需要 D≥105×0.001×(2~3 安全系数)=200–300 N·s/m，比自由空间临界值高约 5–7 倍。这就是现场"刚性接触要重阻尼"的定量依据。

4. 延迟预算：Teff 怎么算

实际回路里延迟有四个来源，逐个计入：

来源典型值说明
采样保持Ts/2（1 kHz → 0.5 ms）零阶保持的等效平均延迟
计算与通信0.1–1 ms总线周期、协议栈；EtherCAT 类总线典型 0.1–0.5 ms
力滤波τf（3–10 ms）一阶低通的群延迟≈τf；这是最大头，也最容易被忽视
速度估计滤波τv（1–5 ms）影响阻尼通道；计入或通过观测器消除

Teff = Ts/2 + Tc + τf 是设计公式里该用的数。1 kHz 循环 + 5 ms 滤波 + 0.5 ms 通信 → Teff ≈ 6 ms，允许环境刚度就只有 D/(2×0.006) 了，比"1 ms 直觉"又缩水六倍。优化的顺序由此明确：先砍滤波延迟（提高信噪比换更小 τf，或改用相位补偿滤波），再提采样率，最后才是加阻尼。滤波延时的代价必须和它的收益放在同一张账上算：把力噪声从 0.3 N 压到 0.1 N 可能只需要 5 ms 的滤波，但这 5 ms 在钢件上等价于强制你多配 500 N·s/m 的阻尼，很多平台给不出这笔阻尼，于是"安静"直接换来"振荡"。

5. 边界之外：还该知道的三件事

  • 单侧接触的碰跳：上面分析假设接触保持。实际冲击后机器人可能"弹离"再落回，每次落回的冲击都会注入能量；稳定性判据保证的是"若保持接触则收敛"，防碰跳要靠限制接近速度与增大阻尼（第 017 章）。
  • 位置接口的实现：内环滞后不直接等于 T，它作用在"位置兑现"路径上，闭环结构不同，但同一套推导可以照搬（把内环一阶滞后乘进 Zr），结论趋势一致：有效延迟变大、临界刚度下降。
  • 非线性项：摩擦力补偿过头的负斜率、力矩饱和、间隙，都会在特定幅值处"局部改变参数"，线性判据退化为参考值，实践里给安全系数 2–3 倍就是在买这份非线性余量。

实现思路与设计

把本章判据嵌进标准设计流程：

  1. 测量环境刚度：按第 003 章方法粗估（钢板 105、塑料 103–104、橡皮 102）。任务跨多种材料时以最硬的为准。
  2. 统计延迟预算：按 Teff 表格逐项填数；用实测确认（发一个力阶跃，量从阶跃到输出反应的纯延迟，再加上滤波群延迟）。
  3. 计算所需阻尼：Dneed = (2~3)·Kenv·Teff；与自由空间用的 Dd 比较，取大者或引入变阻尼（第 020 章）。
  4. 校核阻尼预算：Dneed 过大（比如 > 500 N·s/m 且平台反应迟钝）时，回到延迟预算砍 τf，或承认该类硬环境需要换实现（导纳侧或专用力控）。
  5. 复测：在真实硬环境上做"推压-保持-撤离"循环，记录接触力包络是否随时间增长；配合幅度 20% 的扰动力做衰减率检查。
设计决策：为什么"加大刚度 Kd"救不了稳定性？

从判据看，Kenv,crit ≈ D/T 里没有 Kd 的位置（它的影响在 ω 的修正项里，占比很小）。直觉版：失稳的本质是"延迟造成的相位滞后"与"阻尼耗散"之间的赛跑，弹簧不管延迟，它只是把振荡频率抬高了一点；阻尼才是消耗振荡能量的通道，延迟才是把能量回灌的通道。加大 Kd 甚至略微有害：接触自然频率 ωn 升高使 ωT 变大，小角度近似变差、临界值小幅下降。正确顺序永远是：压延迟 → 加阻尼 → 最后才动刚度。

关键代码与解读

片段 1：临界环境刚度求解器，超越方程的数值解

import numpy as np

def critical_k_env(m_d, d_d, k_d, T):
    """求延迟 T 下闭环 Ms²+Ds+K+K_env·e^(−sT)=0 的临界环境刚度。

    边界条件（s=jω 代入后的实/虚部）：
        Mω² − Dω·cot(ωT) − K = 0     … 解出交叉频率 ω
        K_env = Dω / sin(ωT)          … 由 ω 得临界值
    """
    w_hi = 0.99 * np.pi / (2.0 * T)      # 限制 ωT < π/2，避开 cot 的零点与负值区
    ws = np.linspace(1e-3, w_hi, 40000)
    f = m_d * ws**2 - d_d * ws / np.tan(ws * T) - k_d
    idx = np.where(np.diff(np.sign(f)) > 0.0)[0]
    if len(idx) == 0:
        return float("inf")              # 无交叉 → 给定参数下无条件稳定
    w0 = ws[idx[0]]
    return d_d * w0 / np.sin(w0 * T)

print(f"{'T(ms)':>6} {'D(N·s/m)':>9} {'K_env,crit':>12} {'近似 D/T':>10}")
for T in (0.001, 0.002, 0.005):
    for d_d in (44.7, 100.0, 200.0):
        kc = critical_k_env(1.0, d_d, 500.0, T)
        print(f"{T*1e3:6.0f} {d_d:9.1f} {kc:12.0f} {d_d/T:10.0f}")

解读：求解器把"稳定性"变成了一个可查的表格。扫描区间的选择有讲究：把 ω 限制在 ωT < π/2 内，一是保证 cot 为正值（f(ω) 从负出发、单调上升一次），二是第一个过零点就是最危险的交叉频率，更高频的交叉在工程参数下发生在小幅值处（更保守），拿第一个已足够。返回 inf 的分支表示扫描区间内 f 始终为负，即不存在临界交叉，也可理解为"参数太保守、裕度用不完"（常见于极小 Kenv 或极小 T）。为什么同时打印 D/T 一列：它是近似公式的即时对照，两列接近（10% 内）说明小延迟近似在此参数域成立；如果精确值比 D/T 高出 30% 以上（大 T、大 D 情形），说明小延迟近似已经不可靠，应改用精确解；近似式总体上落在偏保守的一侧。与第 003 章的呼应：表中 D=44.7、T=1 ms 一格给出 ≈4.5×104，恰好落在"软环境安全、钢件越界"的分界上，第 003 章算出的 ζeff=0.07 与本章"需要 0.16"的结论完全一致。

片段 2：时域验证，幅值增长比说话

def simulate(k_env, T, m_d=1.0, d_d=44.7, k_d=500.0, dt=1e-4, t_end=2.0):
    """控制器使用 T 秒前的接触力，检验系统是收敛还是发散。"""
    n_delay = max(1, int(round(T / dt)))
    buf = np.zeros(n_delay)
    x, v, amp = 1e-3, 0.0, []                    # 1 mm 初始扰动，激发振荡
    for i in range(int(t_end / dt)):
        f_now = k_env * x                         # 环境弹簧（保持接触的线性化模型）
        slot = i % n_delay
        f_use = buf[slot]                        # 控制器看到 T 秒前的力
        buf[slot] = f_now
        a = (-d_d * v - k_d * x - f_use) / m_d   # 阻抗律（参考点在 x=0）
        v += a * dt
        x += v * dt
        amp.append(abs(x))                       # 对称振荡，|x| 即幅度
    a_arr = np.array(amp)
    early = a_arr[int(0.25*len(a_arr)):int(0.5*len(a_arr))].mean()
    late = a_arr[int(0.75*len(a_arr)):].mean()
    return late / max(early, 1e-15)              # >1 发散，<1 收敛

kc = critical_k_env(1.0, 44.7, 500.0, 0.001)     # 先用解析工具拿边界
for ratio in (0.8, 1.2):
    g = simulate(ratio * kc, 0.001)
    print(f"K_env={ratio:>3.1f}×K_crit={ratio*kc:9.0f} N/m → "
          f"末段/前段幅值比 = {g:6.2f}  ({'发散' if g > 1.05 else '收敛'})")

解读：这个 20 行的时域实验是解析结果的第一道保险。离散延迟用环形缓冲实现：buf 长度 n_delay，先读旧值再写新值，保证控制器用的是整整 T 秒前的力；用 T/dt 取整时要留意 1 ms/0.1 ms = 10 拍，四舍五入后的实际延迟与设定值差半拍以内，对结论无影响。幅值比的统计窗口取 25%–50% 与 75%–100% 两段：早期包含初始瞬态不用，用"中期 vs 晚期"判断增长/衰减，避开启动阶段的一次性冲击。预期结果：0.8×临界时幅值比明显小于 1（本例约 0.013，衰减率由阻尼与裕度决定）；1.2×临界时大于 1（超出边界越多增长越快：1.2× 时 2 秒窗口内幅值增长约 75 倍，趋势不逆转）。若两者都不符合预期，优先查延迟实现（缓冲长度是否正确）与仿真的等效离散延迟：控制周期的半拍 ZOH 延迟没有建模，实际会比设定略保守，解析边界有 5%–10% 的系统性偏差，这是正常误差带。

片段 3：阻尼预算表，设计助手

def required_damping(k_env, T_eff, safety=2.0):
    """设计助手：D ≥ safety·K_env·T_eff（小延迟近似 + 安全系数）。"""
    return safety * k_env * T_eff

print("所需阻尼 D(N·s/m)，安全系数 2；行=环境，列=等效延迟")
T_effs = (0.001, 0.003, 0.006, 0.010)
print(f"{'K_env(N/m)':>11} " + "".join(f"{t*1e3:>9.0f}ms" for t in T_effs))
for k_env in (1e3, 1e4, 3e4, 1e5):
    row = "".join(f"{required_damping(k_env, t):>11.0f}" for t in T_effs)
    print(f"{k_env:>11.0f} {row}")

print("\n对照：自由空间临界阻尼 2√(K_d·M_d) = 44.7（K_d=500, M_d=1）")
print("→ 橡皮(1e3)与塑料(1e4)轻易达标；钢件(1e5)需要 10ms 级延迟下 2000 的阻尼，")
print("  现实做法：压延迟到 2ms 并接受 400，或改用导纳方案（第 016 章判据更宽松）")

解读：这张表把"环境-延迟-阻尼"三角浓缩成一张可现场查的图。读法示范：任务要碰钢件（105）、你的滤波与总线加起来的 Teff 是 6 ms，表里对应 1200 N·s/m，远超多数平移通道的合理阻尼范围（20–200），结论是要么改设计（压 Teff 到 1–2 ms），要么换方案；任务在塑料件（104）上做，6 ms 延迟只需 120，落在可用区间，位置型阻抗方案可以放心上。最后三行注释是本章的"处方"：现实里压延迟的收益往往大于堆阻尼（前者不牺牲手感，后者让自由空间发黏），所以优化顺序永远是先砍 τf。把这个函数放进项目的参数评审模板：每次改动滤波或通信周期，重跑一次表格，让稳定性账目始终可见。

常见坑

  • 用"仿真稳了"替代延迟核算：连续域仿真没有采样与滤波延迟，天然稳定；一切结论到真机作废。修复：仿真里显式建模 ZOH 与滤波，并用本章判据交叉核对。
  • 把滤波延迟漏出预算：只记采样与总线，忘了 5–10 ms 的力滤波，Teff 少算 5 倍，设计完全走样。修复：把滤波群延迟写进 Teff 表格，作为固定条款。
  • 靠加刚度治振荡：Kd 在判据里几乎不出现，加大只会小幅恶化。修复：按"压延迟→加阻尼→后动刚度"的顺序排查。
  • 在单侧接触里套用双线性判据：碰跳不在线性分析范围内，判据通过仍可能有周期冲击。修复：限制接近速度、增大接触阻尼，必要时做碰跳专项试验（第 017 章）。
  • 忽略平台相关的非线性：摩擦补偿过头的负斜率区、饱和、间隙在特定幅值下让"局部阻尼"变号。修复：给 2–3 倍安全系数，并在实际幅值范围做衰减率测试（不同幅度各测一次）。

练习与思考

  1. 写出理想阻抗与弹簧环境耦合的特征方程，用劳斯判据论证无条件稳定；再说明"振荡但稳定"与"发散"的区别在极点位置上的表现。★
    提示
    系数全正 → 左半平面；ζeff 变小让极点靠向虚轴但实部仍负；发散对应实部为正（延迟注入所致）。
  2. 用片段 1 计算：M=1、K=500、T=1 ms，把 D 从 20 扫到 300（步长 20），画 Kenv,crit–D 曲线，验证线性关系与 10% 偏差带。★★
    提示
    曲线近似直线 K≈D/T；小 D 端受 K 修正项影响偏差略大，大 T/D 组合时偏差更明显，对照代码里同时打印的两列。
  3. 用片段 2 复现边界：在 0.8×、1.0×、1.2× 三个点跑仿真，记录 2 s 内的幅值比。1.0× 附近的结果为什么最"耐看"也最不确定？★★
    提示
    临界点上幅值比≈1（等幅振荡），但对离散延迟的半拍误差最敏感，结果在 0.9–1.1 间摆动，这正是"别在边界上工作"的现场理由。
  4. 推导等价形式 ζeff ≥ ωnT/2：从 D=KenvT 与 ζeff=D/(2√(M(K+Kenv))) 出发，用 ωn≈√((K+Kenv)/M) 化简。★★★
    提示
    ζeff = KenvT/(2√(M(K+Kenv))) = (T/2)·Kenv/√(M(K+Kenv))；Kenv≫K 时 Kenv/√(M(K+Kenv))≈√(Kenv/M)≈ωn，得 ζeff≈ωnT/2。
  5. 某打磨单元：环境 3×104 N/m，力滤波 8 ms、总线 0.4 ms、1 kHz 采样。请给出 Teff、D 的推荐值，并写一份"若硬件不变、还想压到 1 ms 级 Teff"的三条改造方案（每条含代价）。★★★
    提示
    Teff≈0.5+0.4+8=8.9 ms → D≥2×3e4×0.0089≈534；改造：换低噪声传感器以减小 τf（成本）、提高采样率减 Ts/2（带宽/算力）、用相位补偿滤波替代部分纯延迟（设计复杂度）。

小结

  • 理想阻抗 + 弹簧环境的闭环系数全正，无条件稳定；振荡由阻尼比稀释引起，但不发散。
  • 延迟让特征方程含 e−sT：临界点由实部/虚部联立确定，Mdω²−Ddωcot(ωT)−Kd=0 解 ω，Kenv,crit=Ddω/sin(ωT)。
  • 小延迟近似给出可背的规则：Dd ≥ Kenv·T，设计取 2–3 倍；等价直觉是"稳定需要接触阻尼比 ≳ ωT/2"。
  • 延迟预算 Teff=Ts/2+Tc+τf(+τv)；优化顺序：压延迟 → 加阻尼 → 最后动刚度。
  • 下一章做对偶分析：同样的延迟放进"导纳"回路，代价函数换成 Kenv 与控制刚度 Ka 的比值，为什么导纳怕硬环境、却对软环境与漂移问题更友好。
