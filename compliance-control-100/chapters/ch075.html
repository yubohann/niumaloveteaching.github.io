第四篇 · 高级柔顺任务与约束

第 075 章：导纳控制中的任务优先级

当"维持接触力"和"精确跟踪轨迹"同时对你提要求、而且互相冲突时，加权折中不够用了，本章用零空间投影给出"谁优先、谁让位"的严格答案。

  • 主题：冗余机器人 / 分层任务（task-priority）框架
  • 关键公式：q̇ = J₁⁺v₁ + (J₂N₁)⁺(v₂ − J₂J₁⁺v₁)，N₁ = I − J₁⁺J₁
  • 预计学时：50 分钟
  • 前置章节：第 074 章（奇异值分解）

学习目标

  • 理解多任务冲突的根源：自由度有限而任务约束叠加后会"超编"，加权和只能折中，无法保证关键任务不被牺牲。
  • 掌握零空间投影（null-space projection）的几何意义：低优先级任务只能在"不影响高优先级任务"的子空间里活动。
  • 会写出两层与多层任务优先级的分配公式，并会用阻尼伪逆处理奇异附近的速度爆炸。
  • 能设计一个面向接触任务的四层任务栈：安全限制 → 接触力 → 切向跟踪 → 姿态优化。
  • 理解严格优先级与软加权各自的适用边界，知道什么时候必须用前者。

背景与动机

七自由度机械臂在曲面上做恒力打磨时，同时背着至少四个目标：别撞关节限位（安全）、法向力保持在 20 N（工艺）、切向以 50 mm/s 沿曲面移动（效率）、姿态别扭曲（可维护性）。这四件事会互相抢自由度：维持 20 N 需要沿法向"压进去"一点，而精确跟踪任务希望位置分毫不差，同一个自由度不可能同时满足两个主人。

加权折中（把任务误差乘以权重求和）是最容易想到的办法，但它有一个致命缺陷：关键时刻保证不了关键任务。当安全任务和工艺任务冲突时，权重再大也只是"更倾向"，不是"必须"。工程上我们需要的是一套严格的字典序：先全力满足第一优先，在不破坏它的前提下尽量满足第二优先，以此类推。这就是任务优先级（task priority）框架，也叫分层控制（hierarchical control）。本章把它的数学、几何与代码实现一次讲透。

核心原理

1. 任务、雅可比与自由度账本

一个"任务"请你给出它的期望速度 v（m/s 或 rad/s），任务与关节速度 q̇（n 维）之间的映射由雅可比矩阵 J（m×n）给出：

v = J·q̇ n：关节数；m：该任务的输出维数。J 的每一列是"该关节对该任务速度的贡献"

记自由度账本：n=7 的机械臂，末端位姿任务 m=6，还剩 1 维"零空间"（null space），能改变关节构型却不改变末端位姿的运动方向集合。任务超编（m₁+m₂ > n）时无精确解，这正是冲突的来源。

2. 零空间投影：第二个任务的"合法活动区"

设第一优先级任务是 v₁ = J₁q̇。定义投影矩阵 N₁，它把任意关节速度投影到"不产生第一任务速度"的子空间：

N₁ = I − J₁⁺J₁ ，性质：J₁·N₁ = 0；N₁² = N₁ J₁⁺ 是伪逆；N₁ 对称、幂等（投影两次与一次相同）

于是两层严格优先级的分配为：

q̇ = J₁⁺v₁ + (J₂N₁)⁺ (v₂ − J₂J₁⁺v₁) 第一项满足 v₁；第二项只在 N₁ 的零空间内动作，天生不破坏第一任务

几何直觉：把第二任务的"剩余误差"先投影到 N₁ 允许的方向上（J₂N₁ 是"第二任务在零空间里的雅可比"），再求解。低层任务永远没有能力伤害高层任务，这是它和加权和的本质区别。

3. 阻尼伪逆：奇异附近的安全阀

当 J 接近奇异（上章 074 讨论过），普通伪逆给出的关节速度会冲向无穷大。阻尼伪逆（damped least squares）用一个小正数 λ² 压制：

J⁺ ≈ Jᵀ(JJᵀ + λ²I)⁻¹ λ 大 → 稳健但任务增益下降；λ 小 → 精确但奇异附近危险。常用 λ 随最小奇异值自适应

分层框架里每一层的伪逆都应默认用阻尼版本，这也是 074 章内容在这里的直接落地。

4. 把导纳控制的输出接到分层框架上

导纳控制器按 F = Mdv̇ + Ddv + KdΔx 生成的是某个任务级的速度 v。分层框架负责把这些任务级速度翻译成关节速度指令。以本章的四层任务栈为例：

层级任务输出 v 的物理量为什么在这层
L1（最高）关节限位与奇异回避关节速度（rad/s）安全不可妥协；失败不可恢复
L2法向接触力调节（导纳律）末端法向速度（m/s）工艺核心，直接决定打磨质量
L3切向轨迹跟踪末端切向速度（m/s）效率指标，可被适度牺牲
L4（最低）姿态优化（舒适位形）关节速度（rad/s）纯品质项，有空间就优化

工程直觉：优先级是"硬约束"，加权是"软约束"；当任务的安全等级不同时，只有硬约束才配得上"保证"二字。分层框架的另一个隐藏优势是不同任务可以用各自的物理单位（N 驱动的速度、m/s 的速度），因为它们在投影后才混合，不需要人为统一量纲，这避免了加权法中最令人头疼的量纲折算。

实现思路与设计

  1. 定义任务与雅可比：为每层写好"当前雅可比 + 期望速度"的取数函数；法向/切向任务需要对曲面法向 n̂ 做投影：Jn = n̂ᵀJ，Jt = (I − n̂n̂ᵀ)J。
  2. 从高到低逐层计算：把上一层的结果作为基座，逐层叠加零空间里的分量。实现上维护一个"累积投影矩阵"比每层重算嵌套更快。
  3. 每层内部先限幅：对每层的 v 以及分配后该层的关节贡献做限幅（饱和放进零空间，SNS 技巧），防止某一层瞬时需求过大破坏数值稳定性。
  4. 最后统一限速：对合成 q̇ 做速度缩放（整向量等比缩放，保方向），这一步放在最外层。
  5. 日志与诊断：记录每层"请求速度 vs 实际达成速度"的比例，如果 L3 长期只能达成 30%，说明它在频繁被上层挤占，该调整任务规划，硬调权重解决不了。
设计决策：为什么安全层不直接"禁止"某些关节运动？

直接禁关节会造成速度指令的不连续（下一毫秒又允许了），在导纳回路里表现为抽动。正确做法是安全层输出一个"远离限位的速度场"：越接近上限，向外推的速度越大（比如限位前 10° 开始线性加大），由 L1 占据最高优先级，其他任务自动绕开。这样指令连续、行为可预测，也不需要任何"如果……则……"的硬开关。

关键代码与解读

片段 1：阻尼伪逆与零空间投影器

import numpy as np

def damped_pinv(J, lam=0.05):
    """阻尼伪逆 J^T (J J^T + lam^2 I)^-1。lambda 越大越稳健，
    但任务增益越低；0.05 是中小型机械臂常用的保守起点。"""
    JJT = J @ J.T
    return J.T @ np.linalg.solve(JJT + (lam ** 2) * np.eye(JJT.shape[0]), np.eye(JJT.shape[0]))

def null_projector(J, lam=0.05):
    """零空间投影矩阵 N = I - J^+ J。
    性质 J @ N == 0：投影后的任何关节速度都不会改变该任务的速度。
    用阻尼伪逆构造，N 不再是严格幂等，但数值上更安全。"""
    return np.eye(J.shape[1]) - damped_pinv(J, lam) @ J

解读：注意用 np.linalg.solve 求数值稳定的解，不要直接求逆；对 m×m 的小矩阵（m≤6）解线性方程组既快又稳。阻尼系数 λ 选 0.05 意味着"当任务增益接近 20 倍噪声时开始刹车"，这是经验与数值实验的折中；奇异姿态多或噪声大时自适应加大（如 λ = max(0.02, 1 − σ_min/σ₀)×0.1，σ 为奇异值）。

片段 2：四层任务栈的分配（核心循环）

def layered_resolve(tasks, q_do = None, lam=0.05):
    """tasks: [(J, v_desired), ...] 按优先级从高到低。
    返回合成关节速度 q_dot。"""
    n = tasks[0][0].shape[1]
    q_dot = np.zeros(n)
    N = np.eye(n)              # 累积零空间投影器，初始为全空间

    for J, v_des in tasks:
        J_bar = J @ N          # 把该任务映射到"还没被上层占用"的方向上
        # 只追 J_bar 能表达的残差：v_des 与现有 q_dot 已产生部分的差
        v_res = v_des - J @ q_dot
        dq = damped_pinv(J_bar, lam) @ v_res
        q_dot = q_dot + N @ dq
        # 把本层任务也纳入"不可破坏"集合：更新累积投影器
        # （工程实现常用递推式 N <- N (I - J_bar^+ J) ，此处直接重算更直观）
        N = N @ null_projector(J_bar, lam)
    return q_dot

解读：三个关键行各自对应一个原理。J_bar = J @ N 就是"该任务在未被占用自由度里的雅可比"；v_res 用的是残差；若直接拿原始期望速度来算，上层已经贡献的部分会被重复计算一遍；最后更新投影器，让之后所有层都不敢碰本层用过的方向。真实工程中投影器递推更新（每层一次矩阵乘法）比连续调用 null_projector 更快，这里为了可读性写成直算。

片段 3：把法向力导纳接到 L2

def force_task_jacobian(J_pos, normal):
    """法向力任务只关心沿法向的速度分量：v_n = n^T J_pos q_dot。
    返回一维雅可比与一维期望速度的封装。"""
    J_n = (normal.reshape(1, -1) @ J_pos)   # 1 x n 的行雅可比
    return J_n

def admittance_normal_velocity(f_meas, f_des, v_prev, K_a=2e-4, dt=1e-3):
    """法向小导纳律：力误差 -> 速度修正。K_a 是'每 1 N 误差给多少速度'，
    2e-4 m/(s·N) 表示力误差 50 N 时速度约 10 mm/s，足够温和。"""
    dv = K_a * (f_meas - f_des)     # 力大了就往外退，力小了就往里进
    return v_prev + dv              # 速度积分，提供给 L2 使用

解读：把接触力任务表达成"沿法向的一维速度任务"，分层框架并不关心这个速度是来自位置规划还是导纳律，这就是模块化解耦的好处。参数 Ka=2e-4 m/(s·N) 的量级值得记住：它让 10 N 的力误差在 1 秒内只产生 2 mm 的位移修正，配合上层 50–100 Hz 的控制周期非常温和；调大 10 倍会明显出现力振荡。

常见坑

  • 低层任务"无声失效"：当高层任务把自由度吃掉后，低层只能部分达成。不记录"达成率"就会误以为是参数问题。给每层加达成率日志，数据会直接告诉你该调整任务设计。
  • 用普通伪逆构造投影器：奇异附近 N 的元素爆大，低层任务输出剧烈抖动。分层框架里所有伪逆统一用阻尼版本，投影器也要用同一个 λ。
  • 把"零空间"理解成"空闲关节"：零空间是关节速度空间里的一个子空间，不是某几个关节。用位形变量（如"只用第 5 关节做优化"）去近似会引入难以排查的耦合。
  • 在每层里不做限幅：某一层瞬时发出大速度需求（如力任务遇到冲击），在投影链里被放大传递，整个 q̇ 疯掉。每层内部先做饱和（SNS），再做投影。
  • 混淆"严格优先级"与"安全"：优先级框架本身不保证安全，它只保证顺序。如果 L1 的任务设计错了（比如安全速度场方向反了），框架会忠实执行错误。安全层的逻辑必须单独验证。

练习与思考

  1. 数一数自由度账本：6 轴机械臂，任务是"末端位姿(6 维) + 法向力(1 维)"，能不能同时精确满足？如果换成 7 轴呢？★
    提示
    6 轴时任务总维数 7 > 自由度 6，必然冲突，需要优先级裁决；7 轴时恰好"满编"，仍然没有姿态优化等余量，这就是冗余机器人存在的意义。
  2. 验证投影矩阵性质：对随机 J 构造 N₁ = I − J⁺J，数值检查 (a) J·N₁ ≈ 0，(b) N₁² ≈ N₁。解释性质 (b) 为什么意味着"投影一次就够了"。★★
    提示
    幂等性来自投影算子的定义：投影到子空间后再投影不会离开该子空间。代码三行就能验证，注意阻尼伪逆下是近似性质。
  3. 把 L4 姿态任务从"严格优先级"改成"加权最小二乘"（q̇ = J₁⁺v₁ + w·N₁J₂⁺v₂），在 w=0/0.5/1 三个值下比较：什么时候会破坏 L1？为什么严格优先级永远不会？★★
    提示
    加权版中 w·N₁J₂⁺v₂ 仍在零空间内，所以严格来说不破坏 L1，破坏发生在你为了"要效果"而把任务写进非投影路径时。借此体会投影的边界。
  4. 为 L1 安全层设计"远离限位的速度场"：关节角距上限还剩 δ（rad），希望以 0.5 rad/s 的速度往回走。写出 v_safe(δ) 的表达式（提示：分段或 smoothstep），并说明为什么在 δ 接近 0 时不能让速度无限大。★★★
    提示
    速度场只需"够用"：δ 大时可以是 0（不干预），δ 小于阈值后线性或三次平滑上升到 0.5 rad/s 并封顶。速度无限大不物理，也会把其他任务全部挤出。
  5. 设计一个实验：给 L3 加一个 5 s 的阶梯形扰动（模拟曲面上的小凸起），观察各层的达成率日志，说明"谁让位、让了多少"。★★★
    提示
    凸起会先激活 L2（力超目标→后退），L3 的切向速度在投影链里被迫减小。达成率日志里 L2 应保持在 90% 以上、L3 明显下降，这正是优先级设计的预期行为。

小结

  • 多任务冲突的本质是自由度超编；加权和只能折中，分级（task priority）才能保证关键任务。
  • 核心公式：q̇ = J₁⁺v₁ + (J₂N₁)⁺(v₂ − J₂J₁⁺v₁)，N₁ = I − J₁⁺J₁；所有伪逆用阻尼版本保证奇异附近安全。
  • 接触场景的任务栈设计：安全 → 力 → 切向跟踪 → 姿态优化；安全层用连续速度场，不用硬开关。
  • 实践要点：每层残差求解、每层内部限幅、达成率日志诊断。
  • 下一章从"框架"回到"约束"：最常用、最关乎安全的单项约束，力限制，它在导纳与阻抗回路里各有自己的实现坑。
