第二篇 · 参数调节与交互任务

第 040 章：基于导纳控制的插拔操作

只用位置接口和一支力传感器完成插入与拔出。插入靠各向异性导纳实现"横向让、纵向压"；拔出的难点是静摩擦突跳，本章给出力斜率监测、跳出检测与微振动辅助的完整方案。

  • 主题：插拔操作 / 导纳框架 / 静摩擦突跳
  • 关键公式：Md,iẍi+Dd,iẋi+Kd,iΔxi=Fi，跳出判据 dF/dt < −100 N/s
  • 预计学时：55 分钟
  • 前置章节：第 039 章、第 022 章

学习目标

  • 会把第 039 章的装配策略完整移植到"位置接口 + 力传感器"的导纳框架：横向柔顺、轴向力跟踪、搜索螺旋都用同一套六维导纳参数表达。
  • 理解拔出（pull-out）与插入的本质差异：静摩擦系数大于动摩擦系数，拔出过程必然出现"力爬到峰值后骤降"的突跳。
  • 会设计跳出检测器：用 10 ms 窗口的力斜率（dF/dt < −100 N/s）把"拔出瞬间"从噪声里可靠地分辨出来，并解释窗口与噪声的换算。
  • 掌握拔出策略曲线：预载释放、缓升拔力（≤10 N/s）、跳出后切换到低速回撤、卡滞时微振动（dither）辅助。
  • 会给插拔全过程写力/速度/深度三重安全限幅，并说明每个限值的来源。

背景与动机

装配线的大多数设备没有开放力矩接口，一台协作臂加一支腕部力/力矩传感器就是全部"感官"。好消息是：第 022 章的导纳力跟踪已经证明"位置接口也能做力控"，第 039 章的装配几何（倒角引导、卡死判据）与执行框架无关。这一章做两件事：（1）把装配策略参数化成导纳版本，横向用被动柔顺、轴向用参考自适应、搜索用位置螺旋；（2）补上第 039 章没讲的反向操作，拔出。

拔出为什么单独讲？因为它的力学机制完全不同：插入面对的是动摩擦（部件在滑动），拔出面对的是静摩擦的"挣脱"过程。静摩擦系数比动摩擦大 20–50%，拔力必须先爬到峰值 Fbreak 才能让部件动起来；一动起来，摩擦立刻跌回动摩擦，接触力骤降，机器人如果还在"按原计划用力"，就会突然蹿出去。没有跳出检测和回撤策略的拔出动作，在小零件上最轻是"弹飞"，重则撞坏夹具。这一章把它治住。

核心原理

1. 插入：六维各向异性导纳的完整参数化

把第 022 章的导纳方程逐轴展开成任务空间六维形式：

Md,iẍi + Dd,iẋi + Kd,i(xi−xr,i) = Fi，i = 1…6 横向 i=1,2：K 取 250–500 N/m（对中）；轴向 i=3：K 取 800–1000 + 参考自适应（力跟踪）；姿态 i=4,5：5–20 N·m/rad；绕轴 i=6：约 50（近似锁定）

插入阶段的轴向不用"弹簧压"而用"参考自适应"（第 022 章的 ẋr = λ(Fd−F)）：这样插入力有明确的指令值（如 25 N），深度由环境决定，不会因为孔底位置不确定而失控。横向保持被动柔顺：倒角力把轴推向孔心，对中过程不需要任何显式方向判断，这正是装配"手感"的本质：几何负责指路，柔顺负责让路。

搜索螺旋（第 039 章）在导纳框架下的差异只有一个：螺旋位移直接作为 xr 的横向分量输入，横向导纳会在碰到孔壁时"叠加"让位，两种运动自然合成，不需要模式切换。

2. 拔出：静摩擦突跳与"能量的突然释放"

拔出过程的力学链条：轴向拔力缓慢上升 → 部件不动（静摩擦锁住）→ 当拔力达到 Fbreak ≈ μs·N（N 为配合面的法向压紧力）时突然滑动 → 摩擦跌到 μk·N，平衡被打破：原本用来"对抗静摩擦"的那部分力全部变成加速力。用数字感受：μs=0.15、μk=0.10、N=300 N（常见的过盈/卡扣配合量级），则 Fbreak=45 N；跳出瞬间多余的 15 N 作用在"轴 + 末端执行器 + 力环等效质量"上（等效 1 kg 级），瞬时加速度 15 m/s²，不处理就是一次明显的蹿动。

处理链条分四步：

  1. 预载释放：若配合带横向压紧（卡扣、涨套），先卸横向力再拔，把 Fbreak 从源头降下来。
  2. 力缓升：拔力参考以 ≤10 N/s 爬升（比数值更准确的说法：爬升时间尺度 ≥1 s），让跳出判据有足够的信号积攒时间。
  3. 跳出检测：监测轴向力斜率 dF/dt。跳出时力在 5–20 ms 内骤降几十牛，斜率远小于 −100 N/s；而正常噪声（0.1 N、10 ms 窗口）的斜率水平只有 ~±30 N/s，阈值 100 N/s 相当于 3 倍以上信噪裕度。
  4. 跳出后切换回撤：检测到跳出立即切到"低速回撤"（速度控制，20 mm/s、导纳增益降低），不再追力参考；回撤到位后升速脱离。

如果拔到力上限（1.2×Fbreak 估计）还没跳出，说明卡滞（胶粘、变形咬合）：切换"微振动辅助"，叠加 ±0.15 mm、3–10 Hz 的横向 dither，等效降低 μ（振动让接触面周期性部分卸载），再试一次；两次失败即报警交给人工，绝不无限期硬拔。

实现思路与设计

任务参数表（10 mm 轴、摩擦 μs≈0.15、预估 Fbreak≈45 N）：

  1. 插入段：横向 K=300 N/m；轴向力参考 25 N、λ=0.005；搜索螺旋幅度 1.5 mm；轴向力上限 40 N、横向上限 10 N；深度到位 + 力抬升判坐底。
  2. 保压段：力升 30 N 保持 0.3 s（可忽略，直接进入拔出）。
  3. 拔出段：力参考 0 → 55 N、速率 8 N/s（约 7 s 到上限）；跳出判据 dF/dt < −100 N/s（10 ms 滑窗）；跳出后回撤速度 20 mm/s。
  4. 安全：轴向力硬限 70 N、回撤速度上限 50 mm/s、深度监视（回撤 8 mm 未完成即报警）；所有限值同时写入参数表与实时监控。
设计决策：跳出检测为什么盯"斜率"？"力的绝对值"会漏掉什么？

绝对阈值（如"力掉到 20 N 以下"）在不同配合（20 N 还是 80 N 的过盈量）下完全不可用；斜率反映的是"事件"本身，无论 Fbreak 是 20 还是 80，跳出都伴随几十牛/几十毫秒的骤降。凡是"事件检测"，优先找与绝对量无关的特征（斜率、相对变化率），这是第 096 章接触状态检测的核心方法论。

关键代码与解读

片段 1：各向异性导纳核心（插入用）

import numpy as np

class InsertionAdmittance:
    """位置接口机器人的插入控制：横向被动柔顺 + 轴向力跟踪。"""
    def __init__(self, lam=0.005, k_xy=300.0, k_z=800.0,
                 m_d=1.0, zeta_xy=1.0, zeta_z=0.8, dt=1e-3):
        self.lam, self.dt = lam, dt
        self.k = np.array([k_xy, k_xy, k_z])          # 平移三维
        self.m = np.array([m_d, m_d, m_d])
        self.d = 2.0*np.array([zeta_xy, zeta_xy, zeta_z])*np.sqrt(self.k*self.m)
        self.x = np.zeros(3)          # 命令位置（相对孔口坐标系）
        self.v = np.zeros(3)          # 导纳内部速度
        self.zr = 0.0                 # 轴向参考位置（力环积分状态）
    def step(self, f_meas, f_d_z, x_r_xy):
        # 轴向：参考自适应推动 zr，直到测得力等于指令力
        self.zr += np.clip(self.lam*(f_d_z - f_meas[2]), -0.02, 0.02)*self.dt
        x_r = np.array([x_r_xy[0], x_r_xy[1], self.zr])
        # 三维导纳：外力越大，命令位置越退让
        a = (f_meas - self.d*self.v - self.k*(self.x - x_r)) / self.m
        self.v += a*self.dt
        self.x += self.v*self.dt
        return self.x.copy()

解读：类里同时住了两种"柔顺哲学"：横向（x、y）是纯被动弹簧 K(x−xr)，外力推它就横向让位；轴向是参考自适应，zr 被力误差推动，把插入力严格控制在指令值上。这样分工的依据来自第 039 章：横向的任务是"对齐"（位移型），轴向的任务是"压到指定力"（力型）。f_meas 必须是工具重力补偿后的值（第 029 章），否则"指令 25 N"会被工具自重污染；zr 增量做了 ±0.02 m/s 限幅，防止力传感器故障时参考位置疯跑。

片段 2：拔出状态机，缓升、跳出检测、回撤

class PullOutFSM:
    """拔出控制：力缓升 -> 跳出 -> 低速回撤 -> 完成。"""
    def __init__(self, f_break=45.0, rate=8.0, drop=-100.0,
                 v_retract=0.02, win=0.01, dt=1e-3):
        self.state, self.t = "ramp", 0.0
        self.f_ref, self.rate, self.drop = 1.2 * f_break, rate, drop   # 上限=1.2×估计值，留 breakout 余量
        self.v_retract, self.dt = v_retract, dt
        self.win = int(win/self.dt)       # 斜率窗口 10ms
        self.f_hist = []                  # 力历史（取负号=拔力）
    def step(self, f_axial_meas, depth):
        # 约定：拔力 = -f_axial（压入为正）
        pull = -f_axial_meas
        self.f_hist.append(pull)
        if len(self.f_hist) > self.win:
            self.f_hist.pop(0)
        if self.state == "ramp":
            self.t += self.dt
            f_ref = min(self.f_ref, self.rate*self.t)
            # 跳出判据：10ms 窗口内斜率小于阈值
            if len(self.f_hist) == self.win:
                slope = (self.f_hist[-1] - self.f_hist[0]) / (self.win*self.dt)
                if slope < self.drop:
                    self.state, self.t = "retract", 0.0
            if f_ref >= self.f_ref and self.t > self.f_ref/self.rate + 0.5:
                self.state = "stuck"      # 到上限没跳出：卡滞
            return f_ref
        if self.state == "retract":
            return None                   # 切换速度控制回撤（v_retract）
        return None

解读：状态机只有三个状态却覆盖了完整的工业逻辑。f_hist 是定长滑窗（10 ms），slope = (最新−最早)/窗口时长：这里刻意用"整段首尾差"，不用单拍差分：首尾差对白噪声的标准差只有单拍差分的 1/N（本窗口 1/10），是更稳的斜率估计器。跳出阈值 drop=-100 N/s 的选择过程：噪声 0.1 N、窗口 10 ms 时斜率噪声 σ≈14 N/s，100 N/s 相当于 7σ，几乎不会误报；而真实跳出（−40 N/10 ms）是 −4000 N/s，检测裕度 40 倍。"信号尺度/噪声尺度"两头都留裕度，是事件检测器设计的通用模板。到力上限仍未跳出则转"卡滞"分支（片段 3 处理）。

片段 3：卡滞微振动（dither）与安全串联

def dither_wave(t, amp=0.15e-3, freq=5.0):
    """卡滞辅助：横向微振动，等效降低静摩擦。"""
    return amp*np.sin(2*np.pi*freq*t)

def pull_safety(f_pull, v_retract, depth_gone, dt_state):
    """拔出安全串：三重限幅 + 一次重试。返回动作指令。"""
    if f_pull > 70.0:
        return "abort"                    # 硬限：保护零件
    if abs(v_retract) > 0.05:
        return "abort"                    # 速度异常（跳出后蹿动）
    if depth_gone < 0.5e-3 and dt_state > 2.0:
        return "dither"                   # 拔不动：上微振动重试
    if dt_state > 8.0:
        return "abort"                    # 超时兜底
    return "continue"

# 使用节奏：ramp 阶段每拍调用 pull_safety；
# 返回 "dither" 时把 dither_wave(t) 叠加到横向参考，
# 并把拔力参考再抬 5 N 后重试一次；"abort" 则停机报警。

解读：dither 的幅度与频率都经过"用得上又不惹事"的核算：±0.15 mm 在 10 mm 轴的配合间隙（单边 0.05 mm）之外，会不会刮伤？它只作用在横向、且是"部分卸载"，不构成大面积滑动，配合 5 Hz（周期 200 ms，远慢于任何结构共振）实现可控的微动；幅度上限的原则是"不超过配合间隙的量级"，间隙越小的精密件越要减幅甚至禁用。pull_safety 把四个 abort 条件写成独立的短路判断：力硬限（零件安全）→ 速度异常（跳出蹿动）→ 卡滞重试（一次机会）→ 超时兜底。每个 abort 都可以绑定不同的报警文案，让现场维护一眼知道"是哪条规则救的场"。

常见坑

  • 拔力用阶跃指令：Fref 直接跳到 60 N，系统用 0.1 s 就完成"爬升"，一样是冲击；而且没有足够时间让跳出检测"看到"力平台。修复：力参考用 8–10 N/s 的斜坡发生器（第 032 章的工具直接复用）。
  • 跳出检测不做低通/滑窗：逐拍差分在 1 kHz 下噪声斜率可达上千 N/s，全是误报。修复：10 ms 滑窗首尾差（片段 2），阈值 −100 N/s，两边都留裕度。
  • 跳出后继续追力参考：部件已经松脱，力环却还在"补力"，会把部件甩出去。修复：跳出即弃力控、切速度回撤（模式切换要在 1–2 拍内完成）。
  • 横向导纳参数照抄插入段：拔出时横向若仍保持 300 N/m 的软刚度，轴在自由后会晃；而如果横向锁死，又会加剧卡滞。修复：拔出段横向刚度适度上调（500–800 N/m）并保留 dither 通道。
  • 忽略工具重力补偿：拔出力是"负方向"的小力，工具自重 20–50 N 没补掉的话，力通道完全不可用。修复：第 029 章的标定流程对拔出同样强制。

练习与思考

  1. 计算：力噪声 0.1 N、检测窗口 10 ms 时，斜率估计的噪声标准差约多少？若阈值取 −100 N/s，相当于几倍标准差？若改用 2 ms 窗口呢？★
    提示
    σ≈0.1×√2/0.01 ≈ 14 N/s → 7σ；2 ms 窗口 σ≈70 N/s，−100 N/s 只剩 1.4σ，会大量误报。窗口不能太短。
  2. 推导拔出动力学的一维模型：m ẋ = Fpull − μN，说明"跳出瞬间多余的力 = (μs−μk)N"如何变成加速度，并计算 m=1 kg、N=250 N、μs−μk=0.05 时的瞬时加速度。★★
    提示
    多余的力 12.5 N → a≈12.5 m/s²，20 ms 内速度增量 0.25 m/s，足够让 0.1 kg 的零件弹飞。
  3. 把片段 2 的跳出阈值改成 −300 N/s，用一条模拟的力曲线（缓升 + 突降 + 噪声）测试检测延迟与误报；解释阈值与检测延迟的取舍。★★
    提示
    阈值越靠近噪声，越容易在爬升段的抖动上误报；−300 会把检测滞后到下降得更深的位置，但抗噪更好。取"跳变幅度的 20–30%"通常是好起点。
  4. 实验：给 dither 幅度取 0.05/0.15/0.4 mm，在"卡滞"场景下比较解脱时间与横向力峰值，说明为什么幅度上限和配合间隙同量级。★★
    提示
    0.05 太弱（几秒无效果），0.15 有效且横向力可控，0.4 会在孔壁产生明显撞击/刮擦，间隙 0.1 mm（单边 0.05）的件，0.4 mm 已超 8 倍间隙。
  5. 设计题：为"塑料卡扣（Fbreak≈12 N、怕侧向刮伤）"写一份拔出策略：缓升速率、跳出阈值、回撤速度、dither 是否启用、以及全部安全限值，并解释塑料件与金属件策略的差异。★★★
    提示
    塑料：更慢（4–5 N/s）、力上限更保守（1.3×Fbreak）、禁用大 dither 或幅度 ≤0.05 mm；差异的核心是"摩擦系数大 + 更怕刮伤 + 跳出能量小"。

小结

  • 导纳框架把装配拆成"横向被动柔顺（对中）+ 轴向参考自适应（力跟踪）+ 位置螺旋（搜索）"，全部用一套六维对角参数表达。
  • 拔出面对静摩擦突跳：Fbreak≈μsN，跳出瞬间多余力 (μs−μk)N 变成加速冲击。
  • 跳出检测用 10 ms 滑窗力斜率（阈值 −100 N/s，两端都有 7× 以上裕度）；跳出后立即弃力控、切低速回撤；卡滞走微振动重试一次、超时报警。
  • 插拔全过程三重限幅（力 70 N、速度 50 mm/s、深度/时间监视），每条限值都写进参数表并说明来源。
