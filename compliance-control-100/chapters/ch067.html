第四篇 · 高级柔顺任务与约束

第 067 章：导纳控制中的姿态调整

当机器人只有"力矩→姿态修正"这一条通路时：用四元数维护一个姿态修正状态，把测到的力矩积分成转角；死区、泄漏与时间尺度分离决定它是稳如磐石还是抖如筛糠。

  • 主题：姿态导纳 / 四元数积分 / 修正状态管理
  • 关键公式：Iaω̇ = τmeas − Daω − Kaφc；qc = qnom⊗exp(φc)
  • 预计学时：55 分钟
  • 前置章节：第 066 章

学习目标

  • 理解姿态导纳与姿态阻抗的本质区别：前者维护一个"姿态修正状态"，后者只做瞬时映射。
  • 会设计姿态导纳的三环结构：期望姿态 → 修正向量 φc → 实际命令姿态 qc = qnom⊗exp(φc)。
  • 掌握力矩信号的条件：死区（约 0.2 N·m）、低通（10–20 Hz）与它们对残余对准偏差的定量影响。
  • 会推导为什么 Ka = 0 时必须加泄漏项，以及泄漏率 λ 与漂移时间常数的关系。
  • 理解姿态修正与位置修正的耦合：修正姿态会移动工具尖端，两个环必须时间尺度分离（姿态环慢 2–3 倍）。
  • 会用四元数做积分并解释每步归一化的必要性，能写出 q⊗dq 的更新与回滚检查。

背景与动机

上一章的姿态阻抗把力矩瞬时映射成"想让机器人服从的角度偏置"，前提是内环能把这层偏置当作姿态指令精确执行；实现上它输出的是姿态目标，机器人"看"不到一个持续的姿态误差状态。姿态导纳（orientation admittance）走另一条路：把力矩当作输入，让姿态修正量自己积累，力矩一直存在，转角就一直增加，直到力矩消失。这在两类任务里是唯一自然的选择：

其一，被动力矩贴合：工具被工件扶正，扶正过程中力矩会变化，导纳的积分状态天然记录"已经转了多少"，不会因为一次接触瞬断而丢失进度；其二，搜索类装配：接触力矩指示"孔在哪边"，机器人要朝那个方向一点点转着找，转角必须被记住。代价是：导纳的任何状态都会漂，必须给死区、泄漏与时间尺度分离三件套，这正是本章的核心。

核心原理

1. 姿态导纳方程：转角是一个状态

用修正向量 φc ∈ R3（轴角向量，rad）表示"当前命令姿态相对名义姿态 qnom 的额外旋转"，姿态导纳写作：

Ia ω̇ = τmeas − Da ω − Ka φc，  φ̇c = ω Ia：虚拟转动惯量；Da：阻尼；Ka：虚拟回位刚度（可为零）

与 ch066 的旋转阻抗对比：那里的 Kθδθ 是"当前实际姿态与期望姿态之差"的瞬时函数，没有记忆；这里的 Kaφc 作用在累积转角上，它表示"希望纠正量最终回到零"的弱约束。三者行为差异一目了然：外加恒力矩 τ，Ka = 0 时导纳以 ωss = τ/Da 匀速转动（积分直到任务结束都有效），Ka > 0 时收敛到 φc,ss = τ/Ka。工程直觉：Ka 是"记忆的回位弹簧"，有它，姿态会慢慢忘记被推过的角度；没它，你必须用泄漏或外部重置来防止永远漂下去。

单位与量级：Ia 取 0.05–0.2 kg·m²，Da 取 2–8 N·m·s/rad，Ka 取 2–10 N·m/rad。注意 Ia 不能取太小：0.01 的惯量配 0.1 N·m 的力矩噪声，加速度达到 10 rad/s²，滤波再不到位就是"抖腕"。

2. 修正向量的应用：为什么要相对名义姿态

命令姿态由名义姿态与修正合成：

qc = qnom ⊗ expq(φc) ⊗：四元数乘法；expq：把轴角向量转成单位四元数

这个结构的优点是修正永远相对"任务本来的姿态目标"表达：轨迹规划器更新 qnom 时，修正向量不受影响；停止接触、任务切换时把 φc 清零即可复位，不需要反解绝对姿态。如果用"绝对姿态积分"（每次在命令姿态上右乘增量），一旦名义轨迹变化，累积修正的含义就乱了，而"回位"更是无从谈起。这正是本设计选择"相对名义"的理由。

3. 力矩信号的条件：死区、低通与残留偏差

姿态力矩的真实信号比力信号更"细"：手腕力矩传感器噪声约 0.05–0.1 N·m，而未补偿的工具重力矩残差常在 0.1–0.3 N·m 量级。假设死区 Dz = 0.2 N·m，小于它的力矩一律不响应，能换来的好处是：静止时修正不漂、工具不"微颤"。代价必须用数字记住：死区内的真实对准力矩同样被忽略，最终残留对准误差 φres ≈ Dz/Kcontact。设接触的角刚度 Kcontact ≈ 5 N·m/rad（插轴常见量级），则 φres ≈ 0.04 rad ≈ 2.3°，这就是使用 0.2 N·m 死区后"精度天花板"的量级。想要更准，只能把死区压到噪声允许的最小值，或把低通与死区做成"低通快、死区窄"的组合：低通 20 Hz 负责抑制高频抖，死区 0.1 N·m 负责斩掉残余常值偏置。

低通的位置也有讲究：要放在导纳之前，不能放在之后。放在之后（对 φc 滤波）会引入额外相位滞后，与位置环耦合后更容易振荡；放在之前只是让输入力矩变"钝"，导纳的动态仍然干净。

4. 泄漏：Ka = 0 时的安全绳

许多任务希望"力矩消失后保留修正"（插轴对中后不想弹回去），于是设 Ka = 0。此时任何常值力矩偏置（哪怕只有 0.05 N·m）都会让 φc 线性增长，几分钟后工具可能转了上百圈或撞到机械限位。补一条泄漏项：

φ̇c = ω − λ φc，  漂移时间常数 ≈ 1/λ λ = 0.02–0.1 s−1 ⟹ 记忆 10–50 s

泄漏对"真实修正"的影响可以忽略：真实的接触力矩通常几十倍于偏置，泄漏率 0.05 s−1 只对超过 20 s 尺度的持续量起作用。它真正拦住的是"偏置长期累积"这一失效模式，这是把 ch063 的低频思想原封不动搬到了旋转维度：积分器必须有记忆时间，不管积分的是力还是力矩。

5. 时间尺度分离：姿态环为什么要比位置环慢

姿态修正一旦转动，工具尖端的位置就变了（ptip = pflange + R·rtool），位置环测到的偏差随之变化；位置环修正后，接触点的位置又变，力矩又变。两个环通过"杠杆 + 接触"互相耦合，各自都是稳定的二阶系统时，耦合回路的稳定性取决于它们的带宽比。沿用第 062 章奇异摄动的结论：姿态环带宽取位置环的 1/2–1/3，两个环便近似解耦，中间那个"互相喂"的通道被时间尺度差过滤掉。具体到数字：位置环等效带宽 20 rad/s 时，姿态环的自然频率取 7–10 rad/s（由 √(Ka/Ia) 或 Da/Ia 决定）。反过来，姿态环做得比位置环快，最容易出现的症状是 2–4 Hz 的"摇头"，两个环互相追赶形成的极限环。

实现思路与设计

  1. 补偿先行：工具重力矩、传感器零偏处理到残差 < 0.1 N·m；静止读数残差大于死区一半就要重新标定。
  2. 信号条件：力矩低通 20 Hz；死区 0.1–0.2 N·m，带滞环（进 0.2 启动、回 0.1 停止）。
  3. 导纳步：ω ← ω + [τlp − Daω − Kaφc]/Ia·Δt；φc ← (φc + ωΔt)·(1 − λΔt)；φc 每轴限幅（如 ±0.5 rad）。
  4. 姿态合成：qc = qnom ⊗ expq(φc)，送入内环姿态控制；同时把 φc 限幅与关节限位联合检查。
  5. 一致性更新：姿态更新后用工具变换重算尖端位置，交给位置环；位置环的修正不回头改 φc（单向解耦 + 时间尺度分离）。
  6. 复位策略：任务切换、离开接触、急停恢复时把 φc 以 0.5–1 s 斜坡清零；瞬时清零等于制造一次姿态阶跃。

参数起点：Ia = 0.1 kg·m²、Da = 3 N·m·s/rad、Ka = 0（对准任务）或 4（贴合任务）、λ = 0.05 s−1、死区 0.15 N·m。对准速度上限：ω 限幅 0.5 rad/s，手腕转太快时工具端的线速度 L·ω 会撞进位置环的安全限制里。

关键代码与解读

片段 1：四元数工具函数（乘法、指数、归一化）

import numpy as np

def q_mul(a, b):
    """四元数乘法 a ⊗ b，约定 q = [w, x, y, z]。"""
    w1, x1, y1, z1 = a
    w2, x2, y2, z2 = b
    return np.array([
        w1*w2 - x1*x2 - y1*y2 - z1*z2,
        w1*x2 + x1*w2 + y1*z2 - z1*y2,
        w1*y2 - x1*z2 + y1*w2 + z1*x2,
        w1*z2 + x1*y2 - y1*x2 + z1*w2])

def q_exp(rotvec):
    """轴角向量 -> 单位四元数（半角公式）。"""
    th = np.linalg.norm(rotvec)
    if th < 1e-9:
        return np.array([1.0, 0.5*rotvec[0], 0.5*rotvec[1], 0.5*rotvec[2]])
    u = rotvec / th
    h = 0.5 * th
    return np.concatenate([[np.cos(h)], u * np.sin(h)])

解读：q_exp 的小角度分支用的是 sin(h) ≈ h 的一阶近似，它保证"零误差时输出严格是单位四元数 [1,0,0,0]"，避免 0/0；误差量级 O(th²) 在 th < 1e-9 时远低于浮点精度。q_mul 按行展开书写，不用矩阵形式，是为了让索引错误一眼可见，四元数乘法是最容易抄错一行的地方，配合"随机 104 组与旋转矩阵互换验证"的单元测试才保险。注意 [w,x,y,z] 的约定要与姿态内环接口严格一致，很多"姿态莫名绕错轴"的 bug 就是接口两端一端的顺序是 [x,y,z,w]。

片段 2：姿态导纳一步（死区 + 泄漏 + 限幅）

class OrientationAdmittance:
    """姿态导纳：力矩 -> 修正向量 phi_c；命令姿态 = q_nom ⊗ exp(phi_c)。"""
    def __init__(self, I_a=0.1, D_a=3.0, K_a=0.0, lam=0.05, dt=1e-3,
                 deadband=0.15, phi_max=0.5, w_max=0.5):
        self.I_a, self.D_a, self.K_a, self.lam = I_a, D_a, K_a, lam
        self.dt, self.deadband = dt, deadband
        self.phi_max, self.w_max = phi_max, w_max
        self.w = np.zeros(3)        # 角速度状态，rad/s
        self.phi = np.zeros(3)      # 修正向量状态，rad

    def step(self, tau_meas):
        # 死区（带滞环思想的简化）：小力矩不响应，滤掉噪声与残余重力矩
        tau = tau_meas.copy()
        tau[np.abs(tau) < self.deadband] = 0.0
        # 导纳动力学：注意除了弹簧-阻尼，还多了一项泄漏 -lam*phi，
        # 它保证 K_a=0 时修正量不会因常值偏置无限累积（记忆时间 1/lam）
        w_dot = (tau - self.D_a * self.w - self.K_a * self.phi) / self.I_a
        self.w = np.clip(self.w + w_dot * self.dt, -self.w_max, self.w_max)
        self.phi = self.phi + self.w * self.dt - self.lam * self.phi * self.dt
        self.phi = np.clip(self.phi, -self.phi_max, self.phi_max)
        return self.phi

    def command_quat(self, q_nom):
        # 修正是"相对名义姿态"表达的：轨迹更新时 phi 不受影响
        return q_mul(q_nom, q_exp(self.phi))

解读：三个保护环环相扣，死区斩掉小力矩（噪声与残差），泄漏拦住长期累积，硬限幅兜底异常工况。注意限幅的先后：角速度先限幅再进修正积分，否则 w_max 就只是显示值，积分仍会以未限幅的速度狂奔。泄漏项 -lam*phi*dt 的离散形式与连续形式 ẋ = ω − λx 略有差别，但在 λΔt = 5e-5 下差异可忽略，书写更直观。command_quat 里的乘法顺序是 qnom ⊗ exp：修正发生在名义姿态的局部坐标系里；如果换成 exp ⊗ qnom，修正轴就变成世界系固定轴，插轴任务里会表现为"轴转着转着修正方向乱了"。

片段 3：修正姿态后的尖端一致性更新

def update_tip(p_flange, q_cur, t_tool):
    """姿态变了以后重算工具尖端位置：p_tip = p_flange + R(q)*t_tool。
    位置环要用这个点做偏差判断，否则姿态修正带来的尖端移动会'不被看见'。"""
    R = quat_to_R(q_cur)
    p_tip = p_flange + R @ t_tool
    return p_tip, R

def quat_to_R(q):
    """单位四元数 -> 旋转矩阵（假设已归一化）。"""
    w, x, y, z = q / np.linalg.norm(q)   # 每步归一化：防止数值漂移破坏正交性
    return np.array([
        [1-2*(y*y+z*z),   2*(x*y-w*z),   2*(x*z+w*y)],
        [2*(x*y+w*z),   1-2*(x*x+z*z),   2*(y*z-w*x)],
        [2*(x*z-w*y),     2*(y*z+w*x), 1-2*(x*x+y*y)]])

解读：quat_to_R 里"先归一化再建矩阵"是最便宜的正交性保险：四元数的模长漂移会以整体缩放的形式进入旋转矩阵，虽然每次乘法后误差极小，但连续几十秒的姿态导纳会积攒成可观的量，归一化只花 4 次乘法一次开方，代价可以忽略。一致性更新的意义在于闭环：若不重算尖端，位置环会以为工具还停在旧位姿对应的端点上，接触力会产生一个无法解释的偏差；重算后两个环通过"共享同一位姿"耦合，这正是时间尺度分离要处理的通道。

常见坑

  • 四元数不归一化：连续积分后模长漂移，旋转矩阵整体缩放，姿态误差计算失真，表现为"看着没转但力矩越来越大"。修复：每次乘法/积分后归一化；单元测试 |q| − 1 < 1e-9。
  • 坐标系混用：τmeas 在世界系、ω 在工具体系，直接相减会算出毫无意义的方向。修复：在代码顶部固定约定并在接口注释中写明；进入导纳前把力矩旋到与 ω 相同的坐标系。
  • 死区给太大：为了"让机器人安静"把死区拉到 0.5 N·m，结果对准残留 0.1 rad（5.7°），插轴成功率暴跌。修复：死区 ≤ 0.2 N·m，并把重力补偿残差压到 0.1 N·m 以内，用"干净的信号"换稳定，别靠"大死区"。
  • 姿态环比位置环还快：两个环互相追赶的极限环（2–4 Hz 摇头），加大哪个环的阻尼都不见效。修复：把姿态环带宽降到位置环的 1/2–1/3（即慢 2–3 倍），让时间尺度差自动解耦。
  • 相位滞后被低估：力矩低通放在 φc 之后、或低通带宽低于姿态环带宽，导纳的相位裕度被吃掉，接触瞬间出现持续振荡。修复：低通放导纳输入侧，带宽至少 3 倍于姿态环自然频率。

练习与思考

  1. 证明姿态导纳在常值力矩下的稳态：Ka > 0 时 φss = τ/Ka；Ka = 0 时 φ̇ss = τ/Da（忽略泄漏）。说明两种模式分别适合什么任务。 ★
    提示
    令 ω̇ = 0 与 ω = 0（或 ω 为常数）分类讨论；回位模式适合贴合保持，积分模式适合搜索对中。
  2. 推导死区 Dz 造成的残留对准角 φres ≈ Dz/Kcontact，并计算 Dz = 0.1 / 0.2 / 0.5 N·m、Kcontact = 5 N·m/rad 时的三组残留角。 ★★
    提示
    忽略死区时 φres → 0；死区把"最后一个能被感知的力矩"截断在 Dz，剩余误差由接触刚度决定。
  3. 实验设计：固定位置环带宽 20 rad/s，把姿态环带宽（由 Da/Ia 决定）从 5 / 10 / 20 / 40 rad/s 扫一遍，记录接触过渡阶段的力矩振荡幅度，验证"慢 2–3 倍"的经验准则。 ★★
    提示
    带宽接近与超过位置环时振荡明显增大；注意用同一组位置环参数做对照，才能把耦合效应单独暴露出来。
  4. 设计：插轴搜索任务中，接触力矩约 0.5–2 N·m、要求搜索角速度 0.2 rad/s。给出 Ia、Da、Ka、λ、死区与限幅的整套参数，并说明每一项的依据。 ★★★
    提示
    由 τ/Da ≈ 0.2 rad/s 反推 Da；Ia 由"带宽慢于位置环 2–3 倍"确定；Ka = 0 配 λ = 0.05；死区取噪声上限 0.15–0.2。
  5. 思考题：为什么修正向量要相对名义姿态表达？直接对绝对姿态积分会出什么问题？从"轨迹更新"与"任务复位"两个场景各写一句。 ★★
    提示
    名义姿态随轨迹变化时，相对表达能让修正量保持语义、复位时直接清零；绝对积分则会把"修正"与"轨迹"混成一团无法分离。

小结

  • 姿态导纳 = 力矩驱动的姿态修正状态：Iaω̇ = τ − Daω − Kaφc，φc 是转角向量状态，与姿态阻抗的"瞬时映射"形成对照。
  • 命令姿态 qc = qnom⊗exp(φc)：修正在名义姿态的局部系中表达，轨迹更新与任务复位都干净。
  • 信号条件：力矩低通 10–20 Hz（放导纳输入侧）+ 死区 0.1–0.2 N·m；死区造成 φres ≈ Dz/Kcontact 的精度天花板。
