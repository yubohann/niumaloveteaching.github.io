第四篇 · 高级柔顺任务与约束

第 082 章：阻抗控制中的学习辅助

阻抗控制给了你一个稳定、安全的柔顺"底座"，但固定参数无法把重复任务的接触力误差压到很小。本章用迭代学习控制（ILC）给这个底座配一本"错题本"：把每一轮的力误差学成前馈修正，逐轮逼近目标力，而不去动增益。

  • 主题：学习辅助（迭代学习控制）+ 阻抗控制
  • 关键公式：uk+1(t) = Q[uk(t) + L·ek(t)]，收敛条件 0 < L < 2/g
  • 预计学时：55 分钟
  • 前置章节：第 081 章

学习目标

  • 理解"阻抗控制器 + 学习"的分工：阻抗负责每一轮的稳定与安全，学习负责跨轮次的误差消减。
  • 会推导迭代学习控制（iterative learning control, ILC）的误差递推与收敛条件，理解学习增益 L 的物理含义。
  • 理解准静态灵敏度系数 g = Kenv/(Kd+Kenv) 为什么总在 0 与 1 之间，以及它怎样决定收敛速度。
  • 会用"力前馈 → 位置偏置"的换算 Δx = u/Kd 把学习量接入阻抗控制器。
  • 能说清学习辅助的三条边界：任务可重复、轮间可复位、非重复扰动学不到。

背景与动机

前几章你已经把阻抗控制调得很稳：打磨、抛光这类往复接触任务里，力不再振荡，机器人也不会"撞墙"。但仔细看数据会发现一个尴尬的稳态误差：想让砂轮压 15 N，实际只有 12 N；换一批工件、位置差 1 mm，力又变成 13.5 N。原因出在任务本身：接触力的稳态值由 F = Kd·(xd−x) 决定，x 又由环境刚度"吃"掉一部分，环境位置一变，标称轨迹就不准了。

两条技术路线可以消除这个误差：一条是自适应，在线改增益、改参数，让控制器自己"变强"，这是下一章的主题；另一条是学习，不改控制器，只在每一轮结束后回顾"这一轮误差长什么样"，把误差反算成下一轮的前馈修正。学习路线有两个前提：任务重复（每轮的期望力曲线相同）、轮间可复位（每轮从同样的状态出发）。工业现场恰好大量满足：批量抛光、同款零件装配、按固定程序往复的焊缝打磨。

本章要回答的问题就是：误差怎样变成修正、修正为什么不会越学越乱、学习增益怎么选。这是一条"用重复性换精度"的路线，它的代价，也正是它的边界。

核心原理

1. 学习辅助的结构：内层保稳定，外层管精度

最稳妥的架构是两层：内层是已经调好的阻抗控制器（第 001 章的方程），它保证任何时刻与环境交互都是稳定的、力是平滑的；外层是学习器，它不直接产生控制量，只在每轮结束后更新一个前馈量 uk(t)，让下一轮的"期望位置"变成

xd,k(t) = xnom(t) + uk(t)/Kd xnom：名义轨迹；uk：第 k 轮学到的力前馈（单位 N）；uk/Kd：换算成位置偏置（单位 m）

把 u 定义成"力"（单位 N），是工程上很实用的一个选择：它让学习增益 L 变成无量纲的比值，也让限幅的物理含义一目了然（umax 就是"最多额外施加多少牛顿的前馈"）。工程直觉：学习器做的是"贴膏药"，哪里力小了，就在轨迹上把那一段往环境里多推一点；膏药不改变病人（控制器）的体质，只补上缺口。

2. 从力误差到误差递推：一条链式推导

先看一轮之内发生了什么。接触进入稳态后，力的平衡由两个"弹簧"串联决定：控制器的虚拟弹簧 Kd 和环境弹簧 Kenv。联立

F = Kd·(xd − x)，F = Kenv·(x − xe) ⟹ F = (KdKenv/(Kd+Kenv))·(xd − xe) xe：环境表面位置；串联刚度 = KdKenv/(Kd+Kenv)

把 xd = xnom + u/Kd 代入并对 u 求偏导，得到学习系统里最重要的一个数，准静态灵敏度：

g ≜ ∂F/∂u = Kenv/(Kd + Kenv) ∈ (0, 1) u 每加 1 N，接触力最后多出 g 牛：环境越硬，g 越接近 1

g 的直觉解释很漂亮：环境越硬（Kenv ≫ Kd），前馈力几乎全部转化成接触力，g → 1；环境越软，前馈力被"柔顺的机器人自己"吸收掉一部分，g 变小。注意 g 永远小于 1，这意味着用位置偏置加力永远存在"泄漏"，但也永远不会有 1/g 以外的放大风险，这是学习能稳定工作的物理基础。

3. ILC 更新律与收敛条件

学习器记录第 k 轮的力误差 ek(t) = Fd(t) − Fk(t)（Fd 为期望力曲线），然后做最简单的线性更新：

uk+1(t) = Q[ uk(t) + L·ek(t) ] L：学习增益；Q[·]：滤波/截断算子（下段解释为什么不"裸更新"）

若暂时忽略滤波 Q，把灵敏度 g 代入误差定义：

ek+1 = (1 − gL)·ek ⟹ 收敛条件 |1 − gL| < 1 ⟺ 0 < L < 2/g 每轮误差按系数 |1−gL| 衰减；L 取 1/g 时"一轮清零"（理论上）

这是本章的核心结论。三个推论你都应该记住：第一，L 不能为负，负学习增益会把误差越放越大；第二，L 也不能太大，超过 2/g 后误差交替变号并放大，表现为"这一轮推太深、下一轮又太浅"的轮间振荡；第三，最优点在 L = 1/g 附近（一轮收敛），但实际工程里永远不去踩这个点：真实系统的动态、延迟和噪声会让"理论最优"变成"实践振荡"，通常取 L ≈ (0.3–0.7)/g，用可控的收敛速度换取鲁棒性。

4. Q 滤波器：为什么更新必须"滤一下"

上面的收敛分析是准静态的，只对低频有效。高频段里，从 u 到 F 的传递函数不再是 g，变成带相位滞后的动态 G(jω)，相位滞后过 180° 时，任何正增益都等于正反馈。Q 滤波（常用零相位滑动平均或低通）的作用就是：在动态可信的低频段保持增益≈1，让学习发挥作用；在相位不可信的高频段把增益压到接近 0，禁止学习。加入 Q 后收敛条件升级为频域形式 ‖Q(jω)(1 − G(jω)L)‖∞ < 1，这个式子你不需要手算，但要知道它的意思：学习只在"模型可信的频率段"发生。这就是学习辅助的全部理论骨架，比它听起来简单，也比它听起来更好用。

实现思路与设计

把 ILC 接进阻抗控制，需要按下面的步骤设计，每一步都有工程理由：

  1. 固定时间轴：每轮从同一初始状态出发、采样周期一致、任务时长一致。ILC 的记忆按样本序号寻址（u[i] 对应第 i 个采样点），相位一旦漂移，学习的对象就变成了噪声。真机上用一个"轮次开始"信号同时复位机器人、清空误差缓存的对齐标记。
  2. 只学接触段：接触前的自由运动阶段，力误差没有物理意义（还没接触，F=0 不代表错误）。用"接触标志"分段，只更新接触段内的样本。
  3. 死区：|e| 小于噪声带（力传感器噪声约 0.1 N，取死区 0.3 N）的样本不更新，避免把噪声"学成"一个固定的抖动前馈。
  4. Q 滤波与限幅：每轮更新后对 u(t) 做 3–5 点滑动平均；同时把 u 限制在 ±umax（如 ±40 N），防止局部异常样本把前馈推到危险区。
  5. 学习增益：先用 g 的保守估计算 L = 0.5/g 起步。环境刚度可以先用第 052 章的辨识方法粗估；辨识不确定时，宁可取小。
  6. 终止与监控：连续 3 轮 RMS 误差不再下降，或低于阈值（如 0.5 N）就停止更新，把 u 冻结；同时监控峰值力，超限立即丢弃本轮更新并报警。
设计决策：为什么学习作用在前馈上？直接改期望力行不行？

有人会问：既然每轮误差可测，为什么不下一轮直接把期望力调成 Fd 加修正？答案是：阻抗控制器的"力"不是输入，你不能直接命令力，只能命令位置。要改变力，唯一的杠杆就是位置偏置。把学习量定义成力前馈 u，再统一换算成偏置，好处是既保留"力"的直观量纲（好整定、好限幅），又落到了控制器真正能接收的信号上。这个"学什么"与"给什么"的分离，是柔顺任务里做学习的通用技巧。

关键代码与解读

片段 1：带死区与 Q 滤波的学习器

import numpy as np

class ILCForceCorrector:
    """阻抗控制外层的迭代学习器：维护一条逐样本的"力前馈"记忆 u(t)。

    学习量为什么定义成"力前馈"？因为它与误差同量纲（N），
    学习增益 L 就成了无量纲的比例旋钮，整定最直观；输出时再除以 K_d。
    """
    def __init__(self, n_steps, k_d, gain=0.6, deadband=0.3, u_max=40.0):
        self.k_d = k_d                    # 内层阻抗刚度，用于把力前馈换算成位置偏置
        self.gain = gain                  # 学习增益 L：本轮修正误差的比例
        self.deadband = deadband          # 死区：|e| 低于传感器噪声带就不学
        self.u_max = u_max                # 前馈限幅：等效最大额外偏置 = u_max/k_d
        self.buffer = np.zeros(n_steps)   # u(t) 的逐样本记忆，这就是"学习的载体"

    def update(self, err_track):
        # 死区逻辑：噪声区间内保持不变，否则每轮都在把噪声"学"成固定偏置
        e = np.clip(err_track, -self.u_max, self.u_max)   # 先限幅，防单样本污染
        mask = np.abs(e) > self.deadband
        self.buffer[mask] += self.gain * e[mask]
        # Q 滤波：3 点滑动平均压掉更新中的高频成分。高频段相位不可信，
        # 不滤的话学习会在轮间放大振动（等价于把控制带宽往稳定边界上推）
        kern = np.ones(3) / 3.0
        self.buffer = np.convolve(self.buffer, kern, mode="same")
        self.buffer = np.clip(self.buffer, -self.u_max, self.u_max)
        return self.buffer

    def offset(self, i):
        # 力前馈折算为位置偏置：Δx = u/K_d（第 1 章的"用偏置换力"在这里成了外环）
        return self.buffer[i] / self.k_d

解读：这个类只有三个动作，限幅、死区更新、Q 滤波，但每个动作都对应一条理论：限幅防单点污染、死区保干净学习、Q 滤波保高频稳定。注意 update() 修改的是整条时间轴上的记忆，这与普通积分控制"只维护一个标量总量"构成最本质的区别：普通积分器只记"总量"，ILC 记"哪一刻误差多大"，因此可以补偿随相位变化的误差（比如接触力曲线上某个位置总是偏低）。

片段 2：六轮重复任务的闭环仿真

# 一维环境与阻抗参数（与第 1 章一致，保证读者能对上）
k_env, xe, dt, n = 1e5, 0.05, 1e-3, 1500
k_d, m_d = 500.0, 1.0
d_d = 2.0 * np.sqrt(k_d * m_d)          # 临界阻尼初值
ilc = ILCForceCorrector(n, k_d, gain=0.6)

for trial in range(6):                   # 重复 6 轮同样的任务
    x, v = 0.0, 0.0                      # 轮间复位：这是 ILC 成立的前提
    err = np.zeros(n)
    for i in range(n):
        t = i * dt
        x_d = 0.055 + ilc.offset(i)      # 名义轨迹 + 学习到的偏置
        f_env = k_env * (x - xe) if x > xe else 0.0
        # 阻抗方程解出加速度，半隐式欧拉积分（外环只改 x_d，不动控制器）
        a_cmd = -(d_d * v + k_d * (x - x_d) + f_env) / m_d
        v += a_cmd * dt
        x += v * dt
        # 只学接触段：前 0.5 s 还没稳定接触，误差没有学习意义
        err[i] = (15.0 - f_env) if t > 0.5 else 0.0
    rms = np.sqrt(np.mean(err[n // 3:] ** 2))
    print(f"第 {trial} 轮  接触段力误差 RMS = {rms:5.2f} N")
    ilc.update(err)                      # 用本轮误差更新下一轮的前馈记忆

解读：预期输出是一条干净的下降曲线，第 0 轮 RMS 约 12 N（固定参数只有 2.5 N 左右的实际力），随后按 |1−gL| ≈ 0.4 的比例逐轮衰减，第 4–5 轮后进入 0.2 N 量级的噪声地板。三个细节值得注意：（1） 外环只改了 x_d 一行，控制器本身完全没动，这正是"学习辅助"的含义；（2） 误差只在接触段累积，如果拿自由段的误差去学习，会把偏置推到一个荒谬的值；（3） 第 0 轮的误差几乎完全由稳态模型偏差决定，这验证了"重复任务 + 固定控制器 = 稳定可复现误差"这一 ILC 前提。

片段 3：用灵敏度公式预判收敛

def ilc_convergence(k_d, k_env, gain):
    """用准静态灵敏度 g 预测每轮误差的衰减因子 rho = |1 - g*L|。"""
    g = k_env / (k_d + k_env)            # u 到 F 的稳态增益，恒在 0 与 1 之间
    rho = abs(1.0 - gain * g)            # rho < 1 收敛；rho 越小学得越快
    print(f"K_d={k_d:5.0f} N/m  K_env={k_env:7.0f} N/m  L={gain:.2f}  "
          f"g={g:.3f}  衰减={rho:.3f}")
    return rho

ilc_convergence(500.0, 1e5, 0.6)     # 刚性环境：g≈0.995，衰减≈0.40，良
ilc_convergence(500.0, 2000.0, 0.6)  # 软环境：g≈0.80，衰减≈0.52，稍慢
ilc_convergence(500.0, 2000.0, 2.6)  # L>2/g≈2.5：衰减>1，发散，禁止

解读：这三行调用把"整定 L"变成了"查表"：先用 052 章的思路粗估 Kenv，算出 g，再取 L = 0.5/g。最后一行的警告情形在实践中很常见，工程师看到收敛慢就加大 L，一旦越过 2/g，误差符号每轮翻转、幅度递增，观察到的现象是"打磨压力像打拍子一样一轮大一轮小"。记住这个判读特征：交替振荡即超限，立即把 L 减半。

常见坑

  • 轮间复位不彻底：起始位置、速度、力前馈缓存没有同步清零，学习的"相位"就错位了。症状是误差曲线每轮"横移"一点，RMS 卡在某个值下不去。修复：用同一个轮次触发信号复位所有状态，并对齐误差数组的长度。
  • 把非重复扰动当可学对象：工件个体差异、刀具磨损属于轮间变化的干扰，ILC 学不到，硬学会在记忆里"平均掉"它们，甚至把某几批的偏差固化。修复：学习前做异常检测（如接触力峰值超限则丢弃该轮更新），或改用自适应方法处理慢变干扰。
  • 学习增益过高：L > 2/g 时理论与实测都发散；接近 2/g 时即使不发散也会激发高频振动。修复：从 L = (0.3–0.5)/g 起步，逐步加，观察 RMS 是单调下降还是出现轮间振荡。
  • 没有 Q 滤波：理论推导里 g 是常数，真机里它是带相位滞后的频率响应；不滤波的学习等价于在高频段盲目加正反馈。修复：至少 3 点滑动平均，高频噪声大的系统用 5–10 点的零相位滤波。
  • 把学习量忘记限幅：某个样本异常（如碰撞干扰）会让 u(t) 局部飙高，换算成位置偏置后可能推着机器人压向工件。修复：双重限幅（更新时限幅 + 输出时再限幅），并把 umax 与执行器的力安全边界挂钩。

练习与思考

  1. 由误差递推 ek+1 = (1 − gL)ek 出发，证明收敛区间是 0 < L < 2/g，并解释为什么 L = 2/g 处出现的是"等幅振荡"，既不发散也不收敛。★
    提示
    |1 − gL| = 1 意味着每轮误差的绝对值不变、符号交替；这正是"边缘稳定"，任何建模误差都会把它推向发散。
  2. 用片段 2 的仿真，把学习增益改为 0.3、1.0、2.2 三档，记录每轮 RMS 误差，画出误差随轮数变化的曲线，并对照 g 值验证理论衰减因子。★★
    提示
    g ≈ 1e5/(1e5+500) ≈ 0.995，理论衰减因子分别为 |1−0.3g|≈0.70、|1−1.0g|≈0.005、|1−2.2g|≈1.19；第三档应该看到轮间振荡并放大。
  3. 环境刚度从 1e5 N/m 降到 2000 N/m 后重跑仿真。解释为什么在同样的 L 下收敛变慢，并给出把收敛速度恢复到接近刚性环境的 L 值。★★
    提示
    g 从 0.995 降到 0.8，衰减因子从 0.4 升到 0.52；按 L = 0.5/g 反推，L 应增大到约 0.63。注意环境软时接触瞬态更缓，学习也更安全。
  4. 设计一个实验：任务前 1 s 目标力 10 N、后 1 s 目标力 25 N（阶跃变化），验证 ILC 能学出带"台阶"的前馈记忆。写出期望力数组的构造方式，并说明为什么要对 25 N 段单独检查峰值力安全。★★★
    提示
    F_d 用 np.where(t > 1.0, 25.0, 10.0) 构造；ILC 逐样本地学，所以能学会"前段 10 N、后段 25 N"的整条形态。阶跃处的高频成分会被 Q 滤波部分削弱，观察台阶边缘的残余误差。

小结

  • 学习辅助的定位：阻抗控制器负责"每轮稳定"，ILC 外层负责"跨轮精度"；任务可重复、轮间可复位是它成立的前提。
  • 核心机制：把力误差学成前馈记忆 u(t)，再经 Δx = u/Kd 接入阻抗控制器，不改增益、不改控制器结构。
  • 核心公式：误差递推 ek+1 = (1 − gL)ek，灵敏度 g = Kenv/(Kd+Kenv) ∈ (0,1)，收敛条件 0 < L < 2/g，工程取 L ≈ 0.5/g。
  • 三条工程护栏：只学接触段、死区防噪声、Q 滤波保高频稳定；再加一条限幅防异常样本。
  • 学习管"可重复的误差"，下一章的自适应增益管"随环境/工况慢变的参数"，两者互补，是第四篇"学习与自适应"专题的收束，也是第五篇"鲁棒控制与工程实践"的入口。
