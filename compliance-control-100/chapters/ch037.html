第二篇 · 参数调节与交互任务

第 037 章：阻抗控制中的阻尼比调节

阻尼比 ζ 是阻抗控制里性价比最高的旋钮：超调从 52.7% 到 0 只由它决定，代价是上升时间与速度噪声。本章给出 ζ-超调的精确对照表、噪声增益公式，以及按任务阶段调度 ζ 的实现。

  • 主题：参数整定 / 二阶系统 / 噪声权衡
  • 关键公式：ζ = Dd/(2√(KdMd))，Mp = e−πζ/√(1−ζ²)，σF = Dd·σẋ
  • 预计学时：50 分钟
  • 前置章节：第 034 章、第 036 章

学习目标

  • 理解 ζ = D/(2√(KM)) 才是决定响应"形状"的参数，D 的数值单独没有意义，同一 D 在不同 K、M 下 ζ 完全不同。
  • 会使用三张定量关系：超调 Mp(ζ)、上升/调节时间随 ζ 的变化、以及"速度噪声→力噪声"放大公式 σF = D·σẋ。
  • 掌握不同任务的 ζ 推荐区间：接触任务 0.7–1.0、纯自由运动可到 0.5、任何任务都不低于 0.3；并理解接触场景要按 Kd+Kenv 折算 ζeff。
  • 会实现"按阶段调度阻尼"：接近段高阻尼保安全、过渡段维持临界、稳态段可略降以保持响应，且切换平滑无冲击。
  • 能做"超调-速度-噪声"三方权衡表，并用它回答"这个任务 ζ 该取多少"。

背景与动机

前面几章反复出现同一个身影：第 031 章的超调、第 034 章的 76% 力尖峰、第 035 章平滑前的 15.5 N、第 036 章的两张阻尼口径表，全指向同一个参数：阻尼比 ζ。它是二阶系统"形状"的唯一决定者：给定位移或力参考，超调多少、振几次、多久停下来，都写在 ζ 里。

但很多工程师调参时直接拖 D 的数值，忽略 K 和 M：把 K 从 800 改到 3200（第 035 章的"追快"操作）后，原来的 D 会让 ζ 减半，超调从 5% 跳到 30%，却没人意识到是自己"顺手改了 K"的账。这一章先把 ζ 的语言立起来，再给出完整的取舍账本：ζ 越接近 1 越平顺但越慢；D 越大噪声增益越高。最后用"阶段化阻尼"把这张账本用到工程上，接近、接触、稳态三个阶段本来就不该用同一个 ζ。

核心原理

1. ζ 的定义与三公式

对二阶阻抗 Mdẍ + Ddẋ + Kdx = F（自由或接触统一形式）：

ωn = √(Kd/Md)，　ζ = Dd/(2√(KdMd))，　Dd = 2ζ√(KdMd) ζ 无量纲；ωn 单位 rad/s。ζ < 1 欠阻尼（会振）、= 1 临界、> 1 过阻尼（迟钝）

阶跃响应的三个特征量全部由 ζ 与 ωn 组合给出：

Mp = e−πζ/√(1−ζ²)（ζ<1），　tp = π/(ωn√(1−ζ²))，　ts,2% ≈ 4/(ζωn)

把 Kd=800 N/m、Md=1 kg（ωn=28.3 rad/s）代入，得到本章的核心对照表（仿真实测与公式完全一致）：

ζDd (N·s/m)上升时间(10–90%)超调调节时间(2%)
0.211.343 ms52.7%693 ms
0.317.047 ms37.2%397 ms
0.528.358 ms16.3%285 ms
0.739.675 ms4.6%211 ms
1.056.6119 ms0%206 ms

读表三条结论：（1）超调只认 ζ，想压超调，唯一的办法是加 D（或降 K、加 M），"微调参考"帮不上忙；（2）ζ 越低上升越快、但尾振越久，ζ=0.2 的上升时间最短（43 ms）却在 0.7 s 后才真正停下，"看着快、其实没完"；（3）高阻尼的代价是上升时间，ζ=1 比 ζ=0.7 慢了 44 ms（58%），换来的只是把 4.6% 超调清零。这条"持平线"解释了为什么 0.7 是工程默认值：超调已经很小，速度损失还不心疼。

2. 能量视角：ζ 是唯一的耗散通道

把阻抗系统看成能量账本：动能 ½Mdẋ²、弹簧势能 ½Kdx²，两者之间的来回转换不损失能量；只有阻尼项 Ddẋ 在做负功、把能量耗散成热。阻尼耗散的功率为 P = Ddẋ²。ζ 小意味着耗散弱：阶跃注入的能量只能在弹簧里"倒腾"，形成多次过冲。工程直觉：ζ 就是"能量泄洪闸"的开口大小；关小闸门（ζ→0.2），洪水（动能）漫过堤坝的第一次高度（超调）就大。这也解释了接触场景为什么更严苛：第 034 章的有效刚度 Kd+Kenv 让"水库"变大（储能上限提高），同样的闸门（D）对应的 ζeff 就小得多，所以接触任务的 ζ 要按总刚度核算。

3. ζ 的另一个代价：噪声放大

D 不是凭空产生的，它乘的是速度估计 ẋ。速度估计来自差分+滤波，必然带噪声 σẋ，于是阻尼项贡献的"噪声力"为：

σF = Dd·σẋ = 2ζ√(KdMd)·σẋ 例：σẋ=0.01 m/s 时，ζ=0.7 对应 σF≈0.40 N，ζ=1.5 则 0.85 N，滤波不足时就是"沙沙"的手感

所以 ζ 的"免费区间"其实有限：往上加阻尼压超调，同时把速度噪声线性买进力通道。ζ 的上界由噪声与响应速度决定（阻尼增加对稳定裕度是好事，λmax ∝ Dd，稳定性不构成上界）；工程做法是"ζ 到 0.7–1.0 就停手"，剩下的抗噪工夫花在速度滤波（第 047 章）与传感器质量上。

实现思路与设计

实验设置（1 kHz，自由空间位置阶跃 10 mm 与接触力阶跃两套数据）：

  1. ζ 扫描：Kd=800、Md=1 固定，ζ ∈ {0.2, 0.3, 0.5, 0.7, 1.0}；测超调并与公式对照。
  2. 噪声测量：给速度估计叠加 σẋ=0.01 m/s 的白噪声，统计 D·ẋ 输出（阻尼力通道）的标准差，验证 σF=Dσẋ。
  3. 阶段化阻尼：接近段 ζ=1.0、接触过渡 0.2 s 内降回 0.7、稳态保持 0.7；切换用时间常数 50 ms 的一阶平滑。
  4. 任务推荐表：接触/装配 ζ=0.8–1.0；自由点到点 0.6–0.8；示教拖动（第 028 章）Bv 另算；任何接触任务 ζeff 不低于 0.4。
设计决策：为什么改 K 或 M 后必须重算 D？

ζ ∝ D/√(KM)：K 翻 4 倍，ζ 减半（0.7→0.35，超调 5%→30%）；M 翻 4 倍同理。因此"调参记录"里不该只写 D=40 N·s/m，而要写"ζ=0.7（K=800、M=1）"。真机脚本里把 D 和 ζ 的换算写成一行函数，任何时候改 K/M 都自动重算，这是最便宜的防呆设计。

关键代码与解读

片段 1：ζ 到 D 的换算与超调对照实验

import numpy as np

def d_from_zeta(zeta, k_d=800.0, m_d=1.0):
    """按目标阻尼比反算阻尼系数：改 K/M 后永远先过这个函数。"""
    return 2.0*zeta*np.sqrt(k_d*m_d)

def zeta_experiment(zeta, k_d=800.0, m_d=1.0, x_d=0.01,
                    dt=1e-4, T=3.0):
    """自由空间位置阶跃：测超调与上升时间，与公式对照。"""
    d_d = d_from_zeta(zeta, k_d, m_d)
    x, v, log = 0.0, 0.0, []
    for i in range(int(T/dt)):
        t = i*dt
        xd = x_d if t >= 0.1 else 0.0
        a = (k_d*(xd - x) - d_d*v) / m_d
        v += a*dt; x += v*dt
        log.append((t-0.1, x))
    return np.array(log)

for z in (0.2, 0.3, 0.5, 0.7, 1.0):
    L = zeta_experiment(z)
    t, x = L[:, 0], L[:, 1]
    m = t >= 0.0
    over = (x[m].max() - 0.01)/0.01*100
    th = np.exp(-np.pi*z/np.sqrt(1-z*z))*100 if z < 1 else 0.0
    print(f"zeta={z:3.1f}  D={d_from_zeta(z):5.1f} N*s/m  "
          f"超调实测 {over:5.1f}%  理论 {th:5.1f}%")

解读：五组数据全部落在公式线上（52.7/37.2/16.3/4.6/0.0），说明这个系统在本例范围内就是一个标准二阶环节，"公式即真理"。d_from_zeta 单独成函数不是小题大做：真机项目里 Kd 会跟着任务变（抛光 500、装配 2000），每次改动都调用它重新算 D；手动填 D 会漏改。一个函数消灭一整类"改了 K 忘了 D"的事故。实验的前 1 秒让系统稳定在 0，阶跃后再统计，避免把启动瞬态混进超调。

片段 2：阻尼力的噪声增益，ζ 的另一面

def noise_gain_experiment(zeta, k_d=800.0, m_d=1.0,
                          sig_v=0.01, n=20000, seed=0):
    """验证 sigma_F = D * sigma_v：统计阻尼通道输出的噪声。"""
    rng = np.random.default_rng(seed)
    d_d = d_from_zeta(zeta, k_d, m_d)
    v_noisy = rng.normal(0.0, sig_v, n)      # 速度估计：零均值白噪声
    f_damp = -d_d*v_noisy                    # 阻尼力通道
    return f_damp.std(), d_d*sig_v            # 实测 vs 理论

print(" zeta   D      sigma_F实测  sigma_F理论  (sig_v=0.01 m/s)")
for z in (0.3, 0.7, 1.0, 1.5):
    meas, th = noise_gain_experiment(z)
    print(f" {z:4.1f}  {d_from_zeta(z):5.1f}  {meas:10.3f}"
          f"  {th:10.3f}")

解读：实测与理论逐行吻合（0.17/0.40/0.57/0.85 N），演示了那条常被低估的经验：滤波留宿的 0.01 m/s 速度噪声，在 ζ=1.5 的"重阻尼"设置下会变成 0.85 N 的力噪声，占 15 N 工作力的 5.7%，手感上就是明显的高频颤动。相反 ζ=0.3 时只有 0.17 N（1.1%），所以"手感轻快"和"力噪声小"经常是同一件事（都来自小 D）。这条实验和片段 1 并排看，取舍图景就完整了：ζ 取 0.7 时你要付 0.4 N 噪声，取 1.0 付 0.57 N、换 4.6% 超调清零；哪笔交易值，由工件的力预算决定。

片段 3：阶段化阻尼，接近、接触、稳态用不同的 ζ

class ZetaScheduler:
    """按任务阶段调度阻尼比：切换用一阶平滑，绝不跳变。"""
    def __init__(self, k_d=800.0, m_d=1.0, tau=0.05, dt=1e-3):
        self.k_d, self.m_d, self.tau, self.dt = k_d, m_d, tau, dt
        self.zeta = 1.0                    # 初始：最保守的临界阻尼
    def update(self, phase):
        # 阶段目标：approach 1.0（防撞）、contact 0.7（默认手感）、
        # steady 0.7 保持；若任务要求更灵敏可调 0.6（但别低于 0.5）
        target = {"approach": 1.0, "contact": 0.7, "steady": 0.7}[phase]
        alpha = min(1.0, self.dt/self.tau)  # 50ms 时间常数平滑
        self.zeta += (target - self.zeta)*alpha
        # 每次输出都重新换算 D：K/M 变了也不会出错
        return 2.0*self.zeta*np.sqrt(self.k_d*self.m_d), self.zeta

解读：调度器的价值在于"每个阶段用最合适的账本"：接近段用 ζ=1.0，任何意外接触都不会有过冲力（这段本来就最危险）；接触过渡降回 0.7，让力建立过程既快又稳；稳态段保持 0.7，若为"更跟手"降到 0.6 也可以，但要用接触力纹波验收。切换用 50 ms 一阶平滑（alpha），因为 ζ 跳变意味着 D 跳变，直接切会让阻尼力出现台阶、激励高频；update 每次返回"当拍应该用的 D"，调用方不必自己缓存 ζ，从根上避免"K 改了、D 没改"。

常见坑

  • 把 D 当绝对参数记忆："上次这个工件用 D=40 挺好"，换到 K=3200 的配置后 ζ 从 0.7 掉到 0.35，超调翻几倍。修复：调参记录、配置文件、代码里统一存 ζ。
  • 接触任务按 Kd 折算 ζ：有效刚度是 Kd+Kenv，ζeff 只有名义值的 √(Kd/(Kd+Kenv)) 倍（钢件下 0.09 倍）。修复：接触设计与验收都用 ζeff。
  • ζ 加到 1.5+ 所以"肯定稳"：超调确实没了，但上升时间与噪声全面变差，还有人误把噪声当"干扰"去调滤波器补，越补越慢。修复：ζ 停在 0.7–1.0，噪声问题回到速度滤波与传感器上解决。
  • 阶段切换时 ζ 硬跳变：D 突变 → 阻尼力台阶 → "咯噔"一下。修复：50 ms 时长的平滑（片段 3），或直接按任务时间预算一次性定死 ζ、不切换。
  • 只做力通道验收、不做自由段验收：ζ 是两套动力学共用的参数，力通道达标了、自由段趋近可能慢得影响节拍。修复：验收表同时含自由段（第 035 章）与接触段（第 034/036 章）指标。

练习与思考

  1. Kd=500、Md=2，要 ζ=0.7 需要 D 多少？若错用 Kd=2000 工况下算的 D=88.5，实际 ζ 是多少、超调多少？★
    提示
    D = 2×0.7×√1000 = 44.3；88.5 用在 K=500、M=2 下 ζ = 1.4（过阻尼，上升变慢但无超调）；反之若把 44.3 用去 K=2000：ζ = 44.3/(2√4000) = 0.35，超调 31%。
  2. 推导：从 M ẍ + D ẋ + Kx = 0 推导特征方程与 ζ 表达式，并证明阻尼耗散功率 P = D ẋ² 恒非负。第二问用能量法解释"ζ 小则超调大"。★★★
    提示
    特征方程 Ms² + Ds + K = 0；P = F阻尼·ẋ = −Dẋ·ẋ = −Dẋ²（负功即耗散）。每次过冲对应一次"动能→势能"转化，耗散少则振荡久、峰值高。
  3. 实验：把片段 1 的 Kd 改为 1600（D 仍按 ζ=0.7 重算），预测超调与上升时间怎么变，再跑验证（提示：ζ 不变则超调不变，ωn 变大则时间变小）。★★
    提示
    超调仍 4.6%；上升时间从 75 ms 缩到 ~53 ms（∝1/√K）。这组实验最能说明"ζ 管形状、K 管快慢"。
  4. 把片段 2 的 σv 从 0.01 改到 0.03，重跑四档 ζ，画"σF-ζ"直线并读出 ζ=1.0 时的力噪声。若工件力预算允许纹波 ≤0.5 N，滤波后 σv 至少要压到多少？★★
    提示
    σF = D·σv，ζ=1 时 D=56.6；要求 0.5 N 则 σv ≤ 0.5/56.6 ≈ 0.0088 m/s，比 0.03 小 3.4 倍，滤波时间常数大约要乘 3–4。
  5. 设计题：为"接近速度 20 mm/s、接触后 15 N 恒力、环境刚度 5×104–2×105"的任务写出 ζ 调度方案（各阶段 ζ、D 的换算、切换时间常数），并给出两段验收指标。★★
    提示
    接近 1.0；接触段按最硬 K：ζeff = 0.7 ⇒ D = 2×0.7×√(M(Kd+2e5))；验收：接触超调 ≤10%、20 ms 内无振荡。

小结

  • ζ = D/(2√(KM)) 是响应形状的唯一决定者；超调 Mp = e−πζ/√(1−ζ²) 与 ωn 无关，改 K/M 后必须重算 D。
  • ζ-对照表：0.2→52.7% 超调/693 ms 调节，0.5→16.3%，0.7→4.6%（默认甜点），1.0→0% 但上升时间比 0.7 慢 58%。
  • 阻尼是唯一的能量耗散通道；接触任务按 Kd+Kenv 折算 ζeff，钢件上仅为名义值的 0.09 倍。
  • ζ 的另一面：力噪声 σF = D·σẋ 随 ζ 线性增长，ζ 的上界由噪声与速度要求决定（稳定性在常见取值下不构成约束）。
  • 阶段化调度（接近 1.0 / 接触 0.7 / 平滑切换）把三个阶段的账各算各的；下一章把镜头对准它的孪生参数：导纳控制中的虚拟质量 Md。
