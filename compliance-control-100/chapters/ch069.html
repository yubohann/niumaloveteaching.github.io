第四篇 · 高级柔顺任务与约束

第 069 章：六维力/力矩导纳控制

同一条六维数据流，换一条实现路线：力矩测量 → 位姿修正 → 位置环执行。本章把测量链（重力/惯性/搬运）、修正状态与 PSD 检查三件事一次讲透。

  • 主题：六维导纳 / 测量链补偿 / 位姿修正状态
  • 关键公式：Maδẍ + Daδẋ + Kaδx = Wint；Wint = Wmeas − Wgrav(R) − Winertia
  • 预计学时：60 分钟
  • 前置章节：第 068 章

学习目标

  • 理解六维导纳的实现结构：测量旋量 → 导纳动力学 → 位姿修正量 → 位置内环，与阻抗路线的分工差异。
  • 会写出完整的测量链：扣除工具重力旋量（随姿态变化！）、扣除工具惯性旋量、再搬运到作用点。
  • 会维护六维修正状态 δx：平移分量直接叠加、旋转分量相对名义姿态合成，并知道限幅的位置与理由。
  • 掌握 PSD 检查：Ma、Da、Ka 必须半正定/正定，负特征值方向的物理含义与症状。
  • 会算导纳的固有频率 √(Ka/Ma) 并确保位置内环至少快 5–10 倍。
  • 能识别导纳特有的失效模式：修正量 windup、"无接触漂移"与位置环滞后引起的振荡。

背景与动机

第 068 章的六维阻抗把柔顺关系"写进控制律"，对力矩/电流接口的机器人最自然。但工业现场绝大多数机器人只开放位置接口（或速度接口），柔顺只能这样实现：测出力与力矩，算出机器人"应该让到哪儿"，再让位置环把你送过去，这就是六维导纳。它多出的工作全在"测量链"三个字上：传感器读到的数里混着工具重量、工具惯性和安装偏置，不扣干净，导纳就在响应一堆并不存在的力。

导纳还有一个常被忽视的优点是结构上的被动性：只要 Ma、Da、Ka 是半正定的，导纳回路对任意未知环境都不会"自己制造能量"，实现起来比阻抗省心。代价是延迟：测量、滤波、计算、位置环全部串在回路里，导纳的带宽天花板由这条链最慢的一环决定。

核心原理

1. 方程与结构：修正是"状态"，命令 = 名义 + 修正

六维导纳的方程与阻抗同形，但输入输出语义不同：

Maδẍ + Daδẋ + Kaδx = Wint，  xcmd = xnom ⊕ δx δx = [δp; δθ]：位姿修正量（状态）；Wint：交互旋量（已去除重力/惯性）

xcmd = xnom ⊕ δx 中的 ⊕ 表示位姿合成：平移是向量加法 pcmd = pnom + δp；旋转用相对旋转 qcmd = qnom⊗exp(δθc/2)（ch067 的结构）。把 δx 当状态的三个好处：名义轨迹更新时修正量不受影响；任务复位时清零即可；限幅作用于"相对量"比作用于绝对位姿更直观。注意 δx 是导纳的内部状态，不是简单地把 W 乘一个增益，Ka = 0、只留阻尼时，常值力对应的稳态是"匀速修正"（δẋss = W/Da），这与阻抗的"静力对应静态偏移"完全不同。选 Ka = 0 还是 > 0，就是选择"边推边走到推不动为止"还是"让位后停在那里"。

2. 测量链：先扣干净，再谈控制

传感器读数是三个旋量的叠加，必须逐一剥离：

Wint = Wmeas − Wgrav(R) − Winertia， Winertia = [mtat; Itαt + ωt×(Itωt)] mt、at：工具质量与质心加速度；It、ωt、αt：工具惯量与角速度/角加速度

其中 Wgrav 随姿态变化：工具重力在传感器坐标系里的表达是 RT·[0, 0, −mtg]，再乘质心偏置得到力矩。2 kg 的工具单重力旋量就有 19.6 N，姿态补偿向量错 4%，残留力误差约 0.8 N、力矩误差在 0.05–0.2 N·m 量级，恰好是导纳能否安静工作的分界线。这里有一个隐蔽的环：姿态修正 δθ 会改变 R，从而改变重力补偿；补偿又参与决定 δθ。工程上把补偿里的 R 用"修正后的命令姿态"计算，这个环就是良性的（补偿跟着实际走）；若用名义姿态，则会在工具大幅倾斜时出现"补偿错位—修正偏移—补偿更错"的慢漂移。

剥离之后再按 ch068 的搬运公式把旋量移到作用点，或就近在法兰建立导纳（两者等价，但设计参数的含义不同，写清楚你的约定）。

3. PSD 检查：负特征值 = 会自己跑的方向

导纳参数矩阵必须满足 Ma ≻ 0（正定）、Da ⪰ 0、Ka ⪰ 0（半正定）。理由是能量：导纳产生的运动只应"耗散或储存"交互能量。若某个方向 Ka 出现负特征值，导纳在该方向上的弹性势能是负的，位移越大"推力"越大，修正量指数增长，机器人朝机械限位冲过去。数值上这个检查只需一行特征分解，务必在上电时执行；尤其是手工拼装的耦合矩阵（如从柔顺中心设计推出的 Ka），很容易因为非对角项过大而破坏正定性。与 ch068 的差别：阻抗的 K 几乎总是"你亲手选的对角阵"，而导纳的 Ka 常来自"任务刚度/柔度矩阵的厨房配方"，更值得查。

4. 带宽与延迟：导纳的固有频率必须远低于位置环

导纳的"被控对象"就是位置内环。若取 Ka、Ma，导纳对力的响应带宽约 ωa = √(Ka/Ma)（Ka > 0 时；Ka = 0 时看待成"一阶" ωa ≈ Ka/Da 或 D/M 的形式）。典型数字：Ma = 2 kg、Ka = 200 N/m，ωa = 10 rad/s（约 1.6 Hz）；内环位置环应做到 50–100 rad/s（8–16 Hz）以上，即至少快 5–10 倍，这样导纳"看到"的位置环近似为 1:1 跟随，前面推导的所有结论才成立。测量链上的低通（如 20 Hz）与通信延迟会各贡献相位滞后，当它们累加到导纳回路 180° 附近时，系统开始振荡；工程直觉：导纳控制器的带宽是"位置环带宽减去测量链滞后"的剩余量，无法自行决定。想更柔顺（Ka 小）通常容易稳定；想更"硬气"（Ka 大）则先要检查内环与延迟。

5. 与阻抗路线的对照表

维度六维阻抗（068）六维导纳（本章）
接口力矩/电流环直接执行柔顺律位置环执行位姿修正
力测量补偿后进入方程必须：任何偏置都会被积成位移
参数约束K 正定（倒弹簧立刻失稳）M、D、K 半正定即结构被动
典型失效K 耦合项错、搬运错补偿残差漂移、修正 windup、延迟振荡

实现思路与设计

  1. 统一坐标系约定：本章约定导纳在工具作用点（TCP）建立，W 与 δx 都在基座系表达，旋转修正用 TCP 的 rotvec。
  2. 测量链：读取原始旋量 → 工具重力补偿（用修正后姿态）→ 惯性补偿（用 TCP 加速度，可由关节状态经雅可比微分估计）→ 搬运到 TCP。
  3. 信号条件：低通 10–20 Hz，死区按传感器噪声 1–2 倍（如 0.15 N / 0.02 N·m）。
  4. 导纳步：δẍ = Ma−1(Wint − Daδẋ − Kaδx)，半隐式积分；参数从 Ka 由"允许让位距离"反推、Ma 取 1–3 kg、Da 用 2ζ√(KaMa)。
  5. 限幅：δp 每轴 ±30 mm、δθ ±0.3 rad、δẋ 各分量按安全速度；还要对"持续不收敛的修正"加泄漏（判断持续单向增大时回泄）。
  6. 合成下发：pcmd = pnom + δp，qcmd = qnom⊗exp(δθ/2)，联合关节限位检查后送内环。

参数起点：Ma = diag(2,2,2, 0.05,0.05,0.05)；Ka = diag(200,200,400, 8,8,4)（平移 N/m、旋转 N·m/rad）；Da = 2√(KaMa) 逐轴；ζ = 1.0。上电自检：特征值 > 0、静止时 Wint 的均值 < 0.2 N / 0.02 N·m。

关键代码与解读

片段 1：测量链，重力（随姿态）、惯性与搬运

import numpy as np

def wrench_intrinsic(w_meas, R_cmd, a_tcp, alpha_tcp, omega_tcp,
                     m_t=2.0, c_com=(0.0, 0.0, 0.08), I_t=(0.01, 0.01, 0.005),
                     g=9.81):
    """从原始测量中剥离工具重力与惯性，返回交互旋量（传感器系）。"""
    # 1) 重力补偿：重力方向是基座系的常量，姿态变了它在传感器系的投影就变，
    #    因此必须用"修正后的命令姿态" R_cmd，不可用名义姿态或上电时冻结的值
    f_g = R_cmd.T @ np.array([0.0, 0.0, -m_t * g])          # 传感器系下的重力
    tau_g = np.cross(np.array(c_com), f_g)                  # 质心偏置产生力矩
    w_grav = np.concatenate([f_g, tau_g])

    # 2) 惯性补偿：工具不是质点，线加速度 + 角加速度 + 陀螺项都要扣
    I_vec = np.array(I_t)
    f_i = m_t * a_tcp
    tau_i = I_vec * alpha_tcp + np.cross(omega_tcp, I_vec * omega_tcp)
    w_inertia = np.concatenate([f_i, tau_i])

    # 3) 剥离顺序无所谓（都是相加项），但搬运必须在补偿之后做，
    #    否则 r x f 的杠杆会把重力也放大成虚假力矩
    return w_meas - w_grav - w_inertia

解读：三个注释各对应一类现场事故。第一类：重力补偿用固定姿态，机器人一转，补偿就错，导纳把它积成"自己慢慢往下沉"；第二类：只扣 F = ma 不扣陀螺项 ω×Iω，工具快速旋转时多出一份随时间变化的虚假力矩，表现为"转速一转快就抖"；第三类：先搬运后补偿，质心偏置产生的重力矩和 r×f 杠杆混在一起，误差量级从 0.1 N·m 涨到 3 N·m。R_cmd 用修正后姿态是与导纳回路一致的选择：重力补偿依赖姿态、姿态又依赖修正，用修正值把这个环闭合在"物理正确"的一侧。

片段 2：六维导纳一步与位姿合成

class Admittance6D:
    """六维导纳：W_int -> δx（位姿修正量状态），命令 = 名义 ⊕ 修正。"""
    def __init__(self, M_diag, K_diag, M_diag_rot=None, dt=1e-3, zeta=1.0):
        M6 = np.array(M_diag, dtype=float)
        K6 = np.array(K_diag, dtype=float)
        # PSD 自检：负刚度分量 = "越偏越推"的倒弹簧，必须在启动时拦下
        assert (M6 > 0).all(), "质量必须正定"
        assert (K6 >= 0).all(), "刚度出现负分量：检查参数拼装"
        self.M, self.K = np.diag(M6), np.diag(K6)
        self.D = np.diag(2.0 * zeta * np.sqrt(M6 * K6))
        self.dt = dt
        self.dx = np.zeros(6)           # [dp, dtheta] 位姿修正状态
        self.dv = np.zeros(6)

    def step(self, w_int):
        acc = np.linalg.solve(self.M, w_int - self.D @ self.dv - self.K @ self.dx)
        self.dv += acc * self.dt
        self.dx += self.dv * self.dt
        # 修正量限幅：平移 30 mm、转角 0.3 rad。限幅放在"状态"上，
        # 不放在输出上：状态才是积分器，只限输出会让内部继续 windup
        self.dx[:3] = np.clip(self.dx[:3], -0.03, 0.03)
        self.dx[3:] = np.clip(self.dx[3:], -0.3, 0.3)
        return self.dx

def compose_command(p_nom, q_nom, dx, q_exp):
    """命令 = 名义 + 修正：平移加法，旋转左乘相对旋转（相对名义的局部系）。"""
    p_cmd = p_nom + dx[:3]
    q_cmd = q_mul(q_nom, q_exp(dx[3:]))     # q_mul/q_exp 来自第 067 章
    return p_cmd, q_cmd

解读：np.linalg.solve 比先算逆再乘更快也更稳（数值上不动点更少）；对对角 M 差值不大，但养成习惯，等以后 M 带耦合时不用改代码。限幅写在状态上是这段代码的关键细节：很多实现把限幅加在"输出给位置环的 pcmd"上，内部 δx 继续增长，等外力方向一变，机器人要"穿越"一大段虚假修正量才能回来，这就是导纳的 windup，症状是"松开后机器人卡在半路上"。旋转修正的合成顺序 q_nom ⊗ exp(dx[3:]) 与 ch067 一致：修正在名义姿态的局部系里解释，让"绕工具轴转一点"这类意图在任何名义姿态下都成立。

片段 3：上电自检与固有频率报告

def admittance_selftest(K_diag, M_diag, inner_bw_rad_s=60.0):
    """输出每个自由度的固有频率与内环带宽比，给调参提供硬约束。"""
    K = np.array(K_diag, dtype=float)
    M = np.array(M_diag, dtype=float)
    lam = np.linalg.eigvalsh(np.diag(K / M))     # 对角参数：逐轴频率
    wn = np.sqrt(np.clip(lam, 1e-9, None))       # K=0 的轴：wn -> 0（纯阻尼）
    for i, (w, k, m) in enumerate(zip(wn, K, M)):
        name = ["px", "py", "pz", "rx", "ry", "rz"][i]
        ratio = inner_bw_rad_s / w if w > 1e-3 else float("inf")
        print(f"{name}: K={k:6.1f} M={m:5.3f} f_n={w/(2*np.pi):5.2f} Hz  "
              f"内环/导纳带宽比={ratio:6.1f}")
    # 经验判据：带宽比 < 5 的轴必须降 K 或提高内环带宽，否则延迟会把它振起来
    bad = [i for i, w in enumerate(wn) if w > 1e-3 and inner_bw_rad_s / w < 5.0]
    if bad:
        print("警告：以下自由度带宽比不足 5：", bad)
    return wn

admittance_selftest([200, 200, 400, 8, 8, 4], [2, 2, 2, 0.05, 0.05, 0.05])

解读：这段小工具把"感觉调参"变成"看数字"：它报告每个自由度的自然频率和内环带宽比，后者小于 5 的轴会被直接点名。留意 K = 0 的轴（比如故意做成"纯阻尼让位"的轴）：wn → 0，代码用 clip 与条件分支避免除零，并把带宽比显示为无穷，这属于"该轴没有弹性回位，只靠阻尼"的正常表达。调参顺序建议照它来：先保证所有轴的带宽比达标，再逐轴修剪到任务想要的刚度；先设刚度、后补稳定的顺序会反复返工。

常见坑

  • 重力补偿不随姿态更新：工具一转补偿就错，导纳把误差积成缓慢下沉或上抬。修复：用修正后姿态计算 RTg；上电慢转几圈，检查 Wint 的均值随姿态的变化小于 0.2 N。
  • 惯性补偿漏陀螺项：只扣 m·a，旋转快时虚假力矩随转速周期性波动，症状是"甩腕就抖"。修复：加上 ω×Iω；对惯性项做 20–50 ms 的均值/低通（它本来就慢）。
  • 修正量 windup：限幅只加在输出、位置环被夹具挡住时 δx 无限增长，松开后机器人"跳"回一大段。修复：限幅落在 δx 状态上 + 持续单向增长时触发泄漏（0.5–1 s 时间常数）。
  • Ka 参数出现负分量：任务刚度表手工拼装时符号写错，出现倒弹簧方向，修正量指数发散直到撞限位。修复：特征分解断言 + 参数表统一由"柔度矩阵取逆"生成，避免手拼。
  • 带宽比不足：Ka 调大后又用了慢内环，回路在 3–8 Hz 振荡，加大阻尼压制会导致响应迟钝。修复：用片段 3 的带宽比报告做硬约束，先提高内环或降低 Ka，不要用阻尼掩盖相位问题。

练习与思考

  1. 推导：Ka = 0、只有阻尼时，常值交互旋量 W 下 δx 的稳态行为；再说明 Ka > 0 时稳态偏移是多少。 ★
    提示
    Ka = 0 时平衡在 δẋ = W/D（匀速走）；Ka > 0 时平衡在 δx = W/K（静止偏移）。
  2. 实验：给一个 2 kg 工具的补偿向量人为加 5% 误差，记录 60 s 内导纳修正量的漂移量与方向；再对比"用名义姿态"与"用修正姿态"两种补偿方式。 ★★
    提示
    5% × 19.6 N ≈ 1 N 的残余，在 Ka = 200 N/m 下对应 5 mm 静态偏移或（Ka=0 时）持续漂移；用名义姿态在大倾角时表现更差。
  3. 算例：Ma = 3 kg、Ka = 100/300/900 N/m，计算三个固有频率，并分别判断需要多快的位置内环（按 5 倍与 10 倍准则）。 ★★
    提示
    ω = √(K/M)：约 5.8 / 10 / 17.3 rad/s，对应内环 29 / 50 / 87 rad/s（5 倍）以上。
  4. 设计：贴合任务要求"横向 10 N 力最多让位 20 mm、绕接触轴的 0.5 N·m 最多转 3°"。给出 Ka 的平移/旋转取值、Ma、Da 与带宽比校验，并指出哪一轴最接近不稳定边界。 ★★★
    提示
    平移 K = 10/0.02 = 500 N/m，旋转 K = 0.5/0.052 ≈ 9.6 N·m/rad 起；旋转轴的 M 小、频率可能最高，重点校验它。
  5. 思考题：为什么说导纳"半正定即结构被动"？请从"修正量只由测得的能量驱动"的角度解释，并指出这个性质在传感器噪声下会被什么样的实现破坏。 ★★
    提示
    半正定的 M/D/K 使导纳是欠驱动耗散系统，输出位移不能增加系统能量；但把噪声放大（如过小 M）、或让状态无限 windup 都会在实现层面破坏它。

小结

  • 六维导纳 = 测量旋量 → Ma、Da、Ka 动力学 → 位姿修正状态 δx → 位置内环执行；命令 = 名义 ⊕ 修正。
  • 测量链三件事：重力补偿（随姿态、用修正后姿态）、惯性补偿（含陀螺项）、搬运到作用点；残差目标 0.2 N / 0.02 N·m。
  • 参数必须 M ≻ 0、D ⪰ 0、K ⪰ 0；负特征值方向是"倒弹簧"，启动时用特征分解拦截。
  • 带宽比是硬约束：内环至少快 5–10 倍；导纳的可用带宽 = 内环带宽中扣除测量链滞后后的剩余。
  • 导纳特有失效：补偿残差漂移、修正 windup（限幅必须落在状态上）、延迟引起的低频振荡。
  • 下一章回到单支路上的参数设计：惯性整形，把 M 从"固定常数"变成"设计变量"，用它同时管理冲击力、响应速度与噪声。
