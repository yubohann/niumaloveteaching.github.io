第一篇 · 基础、建模与稳定性

第 001 章：单自由度阻抗控制基础

从一个"撞墙就会炸"的位置控制器出发，理解阻抗控制的核心思想：控制目标从位置本身转向机器人对外表现出的"质量-弹簧-阻尼"关系。

  • 主题：阻抗控制入门 / 单自由度模型
  • 关键公式：M(ẍ−ẍd) + D(ẋ−ẋd) + K(x−xd) = −Fext
  • 预计学时：45 分钟
  • 前置章节：无（本课程从这里开始）

学习目标

  • 理解为什么"纯位置控制"在接触任务中本质上不可行，接触力由环境决定，而控制器对它一无所知。
  • 建立阻抗控制的物理图景：把机器人末端"虚拟地"改造成一个质量-弹簧-阻尼（mass-spring-damper）系统。
  • 会写出并解释一维阻抗方程，理解 M、D、K 三个参数各自控制什么物理行为。
  • 掌握两个关键定量关系：稳态接触力 F = K·Δx（刚度乘位置偏置），阻尼初值 D = 2√(KM)（临界阻尼）。
  • 能写出一个离散化的单自由度阻抗控制循环，并知道每一步为什么这样写。

背景与动机

绝大多数工业机器人出厂时只会两件事：走到指定位置（位置控制）、按指定速度运动（速度控制）。在自由空间里这套能力非常精确，重复定位精度可以到 0.05 mm。但一旦任务涉及接触：擦洗、打磨、装配、插拔，位置控制立刻暴露出结构性缺陷。

看一个数字：典型金属零件的接触刚度约 Kenv ≈ 105 N/m。位置控制器若带着 0.1 mm 的跟踪误差撞上工件，接触力就是 F = 105 × 10−4 = 10 N，听起来不大，但如果控制器为了消除误差继续"用劲"，误差 1 mm 时就是 100 N，足以压坏零件或触发机器人保护停机。问题的本质是：位置控制器把末端当成"刚性位置源"，而接触任务要求末端是"可控的柔顺接口"。

阻抗控制（impedance control）的答案很优雅：既然交互中"位姿"和"力"不可能同时自由指定，那就转而指定它们之间的动态关系，让机器人像弹簧、像阻尼器、像质量块那样对外界作用力做出反应。本章先用最简单的一维场景把这件事讲透，它是后面 99 章的全部基础。

核心原理

1. 接触力从哪来：环境是一个弹簧

与环境接触时，最简单的模型是把环境看成一个刚度 Kenv 的弹簧。机器人末端比环境表面"多走"的距离 xr − xe（穿透量）乘以刚度，就是接触力：

Fext = Kenv · (xr − xe) xr：机器人末端位置；xe：环境表面位置；Kenv 单位 N/m

这条式子说明两件事：第一，接触力由"机器人位置 × 环境刚度"共同决定，机器人单方面决定不了它，位置控制器想精确控制位置，却对力没有任何话语权；第二，若能把"机器人的位置偏差"控制成与力的确定关系，就能间接控制力。这正是阻抗控制的出发点。

2. 期望阻抗模型：给末端装一套虚拟的质量-弹簧-阻尼

阻抗控制规定：机器人与环境之间应当遵守如下二阶动态关系（单自由度形式）：

Md(ẍ − ẍd) + Dd(ẋ − ẋd) + Kd(x − xd) = −Fext xd：期望轨迹；Md、Dd、Kd：期望质量、阻尼、刚度

三个参数的物理含义可以这样读：

参数物理类比调大它的效果典型量级（平移）
Md惯性质量对外力反应变慢、更"沉着"，但响应迟滞0.5–5 kg
Dd阻尼器（摩擦/黏滞）振荡衰减快、超调小，但过大显得"黏"20–200 N·s/m
Kd弹簧偏差时"顶回去"的劲大，即表现得越"硬"100–2000 N/m

工程直觉：阻抗控制并不直接改写运动轨迹，它调的是机器人"手感"的软硬轻重。自由空间中 Fext = 0，方程退化为 Mdẍ + Ddẋ + Kdx = Mdẍd + Ddẋd + Kdxd，稳态下 x → xd，也就是完美跟踪期望轨迹；一旦受外力，允许产生与力成比例的偏差，"位置让一点、力扛一点"。

3. 稳态接触力：最重要的一个数字

把它和环境模型联立，可以推出阻抗控制中最有用的一条工程结论。接触达到平衡时加速度、速度都为零，令机器人静止在 x，则方程只剩弹簧项：

Kd(x − xd) = −Fext ⟹ Fss = Kd · (xd − x) 稳态接触力 = 期望刚度 × 位置偏置

这意味着：在阻抗控制下，你想让机器人压出 20 N 的力，只需要把期望位置 xd 往工件内推 F/Kd 的距离。例如 Kd = 500 N/m、想得到 20 N，就把 xd 推入 40 mm 的方向上多给 4 cm 的偏置，位置偏差在此转化为产生力的手段，不再计为"误差"。环境位置未知也没关系，控制器会自动通过偏差找到平衡点，这就是柔顺控制对"位置不确定性免疫"的来源。

4. 参数怎么选：两个公式定初值

先定刚度 Kd：它有明确的任务含义。Kd 大 → 机器人硬 → 力分辨率高但抗冲击差；Kd 小 → 柔顺安全但定位差。经验上以"环境刚度的一个小比例"起步：对 Kenv ≈ 105 N/m 的刚性工件，取 Kd = 500–2000 N/m，即刚度比约 1/50–1/200，能保证闭环稳定且手感合适。

再定阻尼 Dd：二阶系统的阻尼比公式给出初值：

ζ = Dd / (2√(KdMd)) ，取 ζ = 1（临界阻尼）⟹ Dd = 2√(KdMd)

例如 Md = 1 kg、Kd = 500 N/m，则 Dd = 2√500 ≈ 44.7 N·s/m。临界阻尼保证接触瞬间不来回振荡；若后续实测超调大，可以再增大 20–50%。质量 Md 一般固定为合适的小常数（太小会被噪声放大、太大响应迟钝），不参与主要调参。

实现思路与设计

我们考虑最常见也最实用的场景：机器人只提供位置接口（工业机械臂的普遍情况），外接一个力传感器。此时把上面的阻抗方程离散化、解出每一步要下发的命令位置。流程如下：

  1. 读取状态：x（编码器/关节角换算）、ẋ（差分滤波）、F（力传感器，注意一维投影方向）。
  2. 解算期望加速度：由阻抗方程 = −Fext，得到 ẍcmd = ẍd − [Dd(ẋ−ẋd) + Kd(x−xd) + Fext]/Md。
  3. 数值积分：速度 ẋ ← ẋ + ẍcmd·Δt，位置 xcmd ← x + ẋ·Δt（半隐式欧拉，稳定性好于显式）。
  4. 限幅与安全：对 xcmd、速度以及（间接）力做限幅，画外音：安全限制在第三章会系统展开。
  5. 下发并记录：把 xcmd 发给内环位置控制器，记录 x、F 用于分析。

为什么走"加速度积分成位置"这条路？直接算 xcmd = xd − F/Kd 只是一个稳态近似，它丢掉了惯性和阻尼，动态接触时（比如撞上的瞬间）会产生尖锐的力峰值。本章的完整积分形式保留了二阶动态，接触过渡更平滑。

设计决策：为什么控制周期取 1 ms？

阻抗控制器的等效刚度和阻尼都是在时间轴上的运算（差分与积分），采样太慢会让离散系统相位滞后，把"弹簧"算成"弹簧+迟滞"，稳定性急剧下降。经验规则：控制周期应小于虚拟系统自然周期（2π√(Md/Kd)）的 1/20。Md=1、Kd=500 时自然周期约 0.28 s，1 ms 采样绰绰有余；即便是更硬的 Kd=5000（周期 0.089 s），1 ms 也满足要求。

关键代码与解读

片段 1：阻抗控制器的核心类

import numpy as np

class ImpedanceController:
    """单自由度阻抗控制器：由阻抗方程解出该下发的命令位置。"""
    def __init__(self, m_d=1.0, k_d=500.0, d_d=None, dt=1e-3):
        self.m_d, self.k_d = m_d, k_d
        # 若未指定阻尼，用临界阻尼公式给初值：D = 2*sqrt(K*M)
        # 理由：临界阻尼是"无超调且最快"的客观标准，先保证接触不振荡
        self.d_d = d_d if d_d is not None else 2.0 * np.sqrt(k_d * m_d)
        self.dt = dt
        self.x_cmd = 0.0   # 内部积分状态：命令位置（机械接口的真实输出）
        self.v_cmd = 0.0   # 命令速度，供下一拍积分使用

    def step(self, x, v, x_d, v_d, a_d, f_ext):
        # 由阻抗方程 M(x..-x_d..) + D(v_d-v) + K(x_d-x) = -F 解出期望加速度
        # 每一项的物理含义：惯性项追求期望加速度，阻尼项耗散速度差，
        # 刚度项对准位置差；外力 F 通过"M 除以"的方式变成加速度偏置
        a_cmd = a_d - (self.d_d * (v - v_d) + self.k_d * (x - x_d) + f_ext) / self.m_d
        # 半隐式欧拉：先更新速度再积分位置，比显式欧拉稳定（能量不增）
        self.v_cmd += a_cmd * self.dt
        self.x_cmd += self.v_cmd * self.dt
        return self.x_cmd

解读：注意 f_ext 前面的符号与 m_d 的除法关系，它决定了"外力推机器人，机器人就顺着让位"。如果符号写反（很常见的错误），外力会被放大、无法被吸收，系统正反馈发散。另外把 x_cmd、v_cmd 放进控制器内部当状态，每拍由上一拍状态递推，是为了让控制器的输出保持连续；若每次由公式重算，输出会跳变，位置接口的机械臂最怕命令位置跳变。

片段 2：1 ms 控制循环与一维环境仿真

# 环境：一堵固定在 xe 的"墙"，刚度 k_env。机器人越界即产生接触力
k_env, xe = 1e5, 0.05        # 1e5 N/m 的刚性环境，表面在 x=5cm 处
ctrl = ImpedanceController(k_d=500.0)
x, v = 0.0, 0.0              # 机器人初始状态（真机里由编码器提供）

for t_i in range(3000):      # 仿真 3 秒（1 ms 周期）
    t = t_i * 1e-3
    # 期望轨迹：前 1 秒推着机器人向墙里走，之后停住观察稳态力
    x_d = 0.06 * min(t, 1.0)     # 目标越过墙面 1 cm → 必然接触
    v_d, a_d = (0.06 if t < 1 else 0.0), 0.0

    # 环境接触力：只有越界才有（单向接触，墙不会"拉住"机器人）
    f_env = k_env * (x - xe) if x > xe else 0.0

    x_cmd = ctrl.step(x, v, x_d, v_d, a_d, f_env)

    # 一阶动力学近似：位置指令被内环"快速跟随"（时间常数 5 ms）
    # 真机上这里换成实际机械臂；教学仿真里用一阶滞后足够反映耦合本质
    x += (x_cmd - x) * 0.2
    v = (x_cmd - x) / 5e-3 * 0.2  # 粗略速度估计，仅用于更新内环状态

    if t_i % 250 == 0:
        print(f"t={t:4.2f}s  x={x*1000:6.1f}mm  F={f_env:6.2f}N")

解读：这段仿真的价值在于观察三样东西：（1）接触瞬间，力从 0 平滑上升，没有阶跃尖峰，这是阻尼项在工作；（2）稳态，最终 F ≈ Kd(xd−x)：xd 停在 60 mm、墙在 50 mm，按公式稳态力约 500 N/m × 偏差。偏差去哪了？一部分被环境"吃掉"（穿入墙面），剩下的由控制器平衡，两者联立可解出精确稳态点；（3）振荡，如果去掉阻尼，接触后会出现持续振荡，这正是下一节"常见坑"讨论的内容。

片段 3：参数整定小工具

def tune_impedance(k_d, m_d=1.0, damping_ratio=1.0, dt=1e-3):
    """输出一组可用的阻抗参数，并给出稳定性经验的检查结果。"""
    d_d = 2.0 * damping_ratio * np.sqrt(k_d * m_d)  # ζ=1 时为临界阻尼
    T_n = 2 * np.pi * np.sqrt(m_d / k_d)            # 虚拟系统的自然周期
    # 经验规则：采样周期应远小于自然周期，否则离散化会引入相位滞后
    ok = dt < T_n / 20.0
    print(f"K_d={k_d:6.0f} N/m  D_d={d_d:6.1f} Ns/m  "
          f"自然周期={T_n*1000:5.1f} ms  采样裕度检查: {'通过' if ok else '不通过'}")
    return k_d, d_d

tune_impedance(500.0)    # 通过
tune_impedance(5000.0)   # 更硬：D 变大、周期变短，仍然通过
tune_impedance(50000.0)  # 极硬：周期 28 ms，1kHz 采样开始逼近极限

解读：把"参数选择"变成一行命令，是控制工程里非常值得养成的习惯。这里输出三个量：阻尼初值、自然周期、采样裕度。最后一行用 50000 N/m 演示极限，虽然数值上"通过"，但真实系统还有传感器延迟、内环带宽等未建模动态，工程实践不建议刚度比超过环境刚度的 1/20。

常见坑

  • 外力符号写反：+f_ext 与 −f_ext 一字之差，系统从"柔顺让位"变成"用力对抗"，接触瞬间直接发散。符号约定写在注释里，跟着阻抗方程的推导走。
  • 刚度挑得太大：Kd 接近或超过环境刚度 Kenv 时，接触闭环刚度约为 Kd+Kenv，一点位置扰动就产生大力量波动，表现为"接触后嗡嗡振荡"。先从小刚度分 3 档试起（如 200/500/1000 N/m）。
  • 速度用裸差分：ẋ = (x−xprev)/Δt 在 1 ms 周期下噪声被放大 1000 倍，必须加一阶低通滤波（时间常数 5–20 ms），否则噪声经由阻尼项进入控制律，听起来像"沙沙"的高频抖动。
  • 忽略稳态力公式就调参：有人发现 20 N 的力怎么调都差一点，就是因为不知道 F = Kd·偏置：力不够时应先调偏置（期望位置），这是直接的力手段；盲目加大 Kd 会同时改变接触刚度与稳定裕度。
  • 没有限幅：阻抗控制器输出的是位置指令，接触异常（如工件错位）时可能算出很远的目标位置。速度、位置都必须限幅，这是安全底线（第二篇展开）。

练习与思考

  1. 把阻抗方程中 Fext = 0 代入，写出自由空间的闭环方程，并说明为什么稳态下 x → xd（即使 M、D、K 取值不理想）。★
    提示
    稳态意味着所有导数项为零；方程退化成 Kd(x−xd) = 0。想想为什么"弹簧最终总要把东西拉回原长"。
  2. 分别取 Kd = 50 / 500 / 5000 N/m 运行片段 2 的仿真，记录稳态接触力与到达稳态的时间。哪一组"力分辨率"最高？哪一组最安全？★★
    提示
    稳态力由 F=Kd·(xd−x) 与环境方程联立决定；刚性越大，同样的位置偏差产生越强的力响应，同时接触瞬态也更激烈。
  3. 把阻尼 Dd 减小到临界阻尼的 20%，观察接触后的力曲线。用"能量耗散"解释你看到的现象。★★
    提示
    阻尼项 D(ẋ−ẋd) 是系统唯一的耗散通道；ζ 远小于 1 时，接触瞬间的动能只能在"弹簧"里来回倒腾，表现为振荡。
  4. 推导接触稳态的精确解：环境 F = Kenv(x−xe)，控制器平衡 F = Kd(xd−x)，联立解出 x 与 F，并验证当 Kenv → ∞ 时 F → Kd(xd−xe)。★★★
    提示
    把两式相加消去 x，得到 F×(1/Kd + 1/Kenv) = xd − xe，两个"弹簧"串联决定力。无穷刚度极限下力完全由控制器决定。
  5. 设计一个实验：让机器人在 2 秒内把接触力从 5 N 平滑升到 25 N（用位置偏置来规划）。写出 xd(t) 的表达式与参数，并说明为什么"力规划"比"力阶跃"更适合真实机械臂。★★★
    提示
    由 F=k·Δx 反解偏置：Δx(t) 用平滑插值（如余弦或三次多项式）从 5/k 过渡到 25/k；阶跃会激发机械臂未建模高频动态。

小结

  • 接触任务中位置控制失效的根源：接触力由"位置×环境刚度"决定，控制器对力没有直接发言权。
  • 阻抗控制的定义：用 Md、Dd、Kd 三个参数规定机器人对外力的动态响应关系；自由空间仍精确跟踪轨迹，受外力时按设计让位。
  • 两个定量支柱：稳态力 F = Kd·位置偏置；阻尼初值 Dd = 2√(KdMd)。
  • 实现上：离散积分（半隐式欧拉）+ 速度滤波 + 位置/速度限幅，控制周期至少为虚拟系统自然周期的 1/20。
  • 下一章转入它的"镜像"：导纳控制，当机器人只有力接口、或者任务更适合"测力→修正位置"时，同一套物理思想如何换一种实现方式，以及两者在什么条件下等价。
