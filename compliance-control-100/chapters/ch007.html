第一篇 · 基础、建模与稳定性

第 007 章：导纳控制与阻抗控制的等效性验证

"位置口实现的阻抗"和"力矩口实现的导纳"看起来是两家，其实共用同一根端口方程。本章把等效条件推导清楚，再用两组仿真逐条验证它在哪里成立、在哪里失效。

  • 主题：阻抗/导纳对偶性 / 等效性验证
  • 关键公式：Mdδ̈ + Ddδ̇ + Kdδ = Fext；位置口精确实现任何 (Md,Dd,Kd)，力矩口 Level-0 仅当 mx = Md 时等效
  • 预计学时：55 分钟
  • 前置章节：第 006 章

学习目标

  • 能写出两种实现共用的端口模板方程，并说明"阻抗"与"导纳"只是同一关系在因果方向上的两种读法。
  • 会证明：内环理想时，位置接口实现能精确复现任意虚拟参数；力矩接口 Level-0 只在"物理等效惯量 = 虚拟质量"时精确等效。
  • 掌握等效性的三条边界条件（内环、信号路径、参考前馈），并能在实验数据里识别它们被破坏的特征。
  • 会写一份双分支数值验证脚本，用同一工况对比两种实现的轨迹与最大偏差。
  • 能根据任务与硬件条件选型：什么时候必须在位置口做导纳、什么时候力矩口的物理阻抗更有优势。

背景与动机

现场常出现一种争论："你这个方案到底是阻抗控制还是导纳控制？"翻看代码，位置接口版本里明明写着"M ẍ + D ẋ + K x = F"的积分，力矩接口版本输出的却是纯弹簧-阻尼力矩。同一台机器人、同一组虚拟参数，两种实现的结果有时几乎一样，有时天差地别，差异从哪来？

本章把这张"等效性地图"画出来：在什么条件下两者数学上完全等价，在什么条件下只是近似，在什么条件下必须分开对待。这份地图有直接的工程价值：它决定你能否用一台设备的调参结果直接迁移到另一台设备，决定仿真原型能否预言真机行为，也决定了调试时该怀疑哪一层。

核心原理

1. 共同的端口模板：δ 的动力学

无论哪种实现，目标行为都可以写成同一个模板。记任务空间偏差 δ = x − xd（m），外力 Fext（N，正方向为推末端的方向）：

Mdδ̈ + Ddδ̇ + Kdδ = Fext ⟺ δ(s)/Fext(s) = 1/(Mds² + Dds + Kd) Md(kg)、Dd(N·s/m)、Kd(N/m)；这条式子既是导纳（F→δ），其倒数就是阻抗（δ→F）

"等效"的严格定义是：从外力的角度观察，两种实现给出的端口映射 δ/F 相同。两种实现并不要求内部结构相同，等同之处在于对外部世界的作用-反作用关系。下面分别推导两条实现路径的端口映射。

2. 位置接口实现：软件积分，精确复现

位置接口方案（第 002/005 章）在后台积分虚拟方程，输出命令位置 xcmd = xd + δ̂，其中 δ̂ 由模板方程数值积分得到。若内环理想（x = xcmd，即 ωc → ∞），则实际偏差就是 δ̂，端口映射精确等于模板，与机器人自身的惯量、摩擦、构型都无关。这是位置接口方案"任意虚拟参数随便设"的底气所在：Md 可以设成 0.5 kg，也可以设成 50 kg，软件里积分什么就是什么。

3. 力矩接口实现（Level-0）：物理积分，条件等效

力矩接口方案（第 006 章）输出 τ = JT(Kde + Ddė)，一维情况下等价于 τ = Kd(xd−x) + Dd(ẋd−ẋ)。把它代入一维机器人动力学 mxẍ = τ + Fext：

mxδ̈ + Ddδ̇ + Kdδ = Fext − mxẍd mx：机器人末端在该方向的物理等效惯量（kg），多自由度时为 Mx(q) 的相应元素

对照模板可见两个差异：第一，惯性项是物理惯量 mx，你设定的 Md 无法直接参与，只有 mx = Md 时方程才逐项相同；第二，多出一个 −mxẍd 项：参考轨迹自身的加速度需要额外的惯性力矩支撑，Level-0 不给这项，于是 ẍd 动的瞬间会产生额外偏差（相当于参考点"甩出去"了一截）。

工程直觉：位置口的等效全靠软件，软件里写什么质量就是什么质量；力矩口的等效受物理记账约束，机器里有多少质量就流多少质量，想让它们对上，要么把物理惯量改造成虚拟质量（Level-2），要么接受瞬态上的差异。注意稳态不受此影响：两边稳态都由 Kdδ = Fext 决定（质量不参与稳态），所以"慢速接触行为等价、快速动态行为不一定等价"是从这条推导里直接读出来的结论。

4. 等效性的三条边界

把上面的推导边界整理成一张检验清单。破坏任何一条，实测轨迹就会出现相应的偏差特征：

边界条件被破坏时的表现定量判据
内环理想（位置口）外力变化时响应变慢、幅值偏软；阶跃力下有额外振荡ωc ≥ 5ωn，ωn=√(Kd/Md)（第 005 章）
惯量匹配 mx = Md（力矩口）瞬态超调/滞后不同，松手回弹节奏不同；稳态一致比较阶跃力的峰值时间与超调量，稳态值应相同
参考前馈完整参考加速时出现与 ẍd 成正比的滞后或超前用正弦参考扫描：偏差幅值 ∝ ω²

还有一条不属于"边界"但必须单独记账的：信号路径。位置口方案的力信号直接进入积分器，噪声经二重积分成为位置随机游走；力矩口 Level-0 的控制律根本不读力信号（外力经物理方程进入），对测量噪声完全免疫。同理，力信号的相位延迟对位置口是"控制回路延迟"，对 Level-0 只是"观测延迟"，两者对稳定性的影响不可同日而语。第 015/016 章会分别展开。

实现思路与设计

把等效性验证做成标准实验流程，四步走：

  1. 参数对齐：两条实现的 Kd、Dd 取同一组值；力矩口的等效质量用实测（推动试验估 mx），位置口的 Md 设成与 mx 一致，先创造"等效条件"，再验证等效结论。
  2. 工况对齐：同一接触场景（静态推压 + 阶跃释放 + 参考阶跃），同一初始状态。仿真步长 0.1 ms（第 003 章的采样要求），真机用位置/力记录同步时间戳。
  3. 三项指标对比：稳态偏差（应完全一致）、阶跃超调与峰值时间（惯量匹配时才一致）、松手回中时间（ζωn 决定）。
  4. 偏差归因：不一致时按上一节的三条边界逐项排查，先查内环（位置口）、再查惯量折算（力矩口）、最后查参考前馈。
设计决策：为什么"稳态一致"要作为等效性的第一证据？

稳态方程 Kdδ = Fext 里没有 M、没有内环带宽、没有信号路径，它是两条实现路线的"公约数"。工程调试时按"先稳态、后瞬态"的顺序验证，可以快速定位问题层：稳态都不一致，说明参数或几何换算有错（如 Kd 单位、J 的维度）；稳态一致、瞬态不一致，才进入惯量/延迟/滤波这些动态因素的排查。这也解释了为什么很多现场"看起来等效"：他们的任务以准静态接触为主，恰好落在公约数内。

选型建议可以浓缩成一条决策线：任务以准静态接触为主、硬件只有位置口 → 位置口导纳（软件灵活、鲁棒、无需动力学模型）；任务要求动态接触或统一手感、硬件开放力矩口 → 力矩口（物理直出、无噪声积分、需重力/模型支持）。两者都可用时，优先考虑"调试工具链更成熟"的那条，因为等效性保证了你可以在另一边复现结果。

关键代码与解读

片段 1：双分支仿真器，同一工况跑两种实现

import numpy as np

def simulate(mech, m_d=1.0, k_d=500.0, d_d=None, m_robot=1.0,
             w_c=1e9, k_env=1e5, x_d=0.005, dt=1e-4, n=20000):
    """mech='adm'：位置口导纳（软件积分，内环一阶滞后）
       mech='imp'：力矩口 Level-0（物理惯量 m_robot）
       返回位置与接触力轨迹。x_d 为参考点，墙面在原点。"""
    d_d = d_d if d_d is not None else 2.0*np.sqrt(k_d*m_d)
    x, v, xh, vh = 0.0, 0.0, -x_d, 0.0   # 两分支共享初值：δ(0) = −x_d（x_cmd(0)=0）
    xs, fs = [], []
    for i in range(n):
        # 环境：墙面在 x=0，越界才有反力（单向弹簧，与第 002 章一致）
        f = -k_env*x if x > 0.0 else 0.0
        if mech == 'adm':
            # 软件积分模板：M δ̈ = F − D δ̇ − K·δ（δ=xh 相对参考的偏差）
            a = (f - d_d*vh - k_d*xh)/m_d
            vh += a*dt
            xh += vh*dt
            x_cmd = x_d + xh
            # 内环：一阶滞后，步长内比例 = min(1, w_c*dt)
            x += (x_cmd - x)*min(1.0, w_c*dt)
        else:
            # 力矩口：弹簧-阻尼力矩；外力只经物理方程进入（控制律不测力）
            tau = k_d*(x_d - x) - d_d*v          # 参考静止 → 阻尼项 = −D·ẋ
            v += (tau + f)/m_robot*dt            # 与导纳分支同一欧拉积分格式
            x = x + v*dt
        xs.append(x); fs.append(f)
    return np.array(xs), np.array(fs)

解读：这段代码的写法刻意为"可对照"服务：两条分支共享同一环境模型、同一初值、同一时间步，唯一差异是动力学实现。有两个工程化细节值得注意。第一，内环滞后用 min(1.0, w_c*dt) 实现，w_c 极大时该比例饱和为 1，等价于"瞬时到位"的理想内环；w_c 取有限值时它就是每拍固定的跟踪比例，对应时间常数 1/w_c 的一阶环节。这个写法在 0.1 ms 步长下可稳定复现从理想内环到慢内环的全谱。第二，两分支采用同一套欧拉积分与速度状态（力矩口的速度是积分状态，不是差分估计），对比不受积分格式差异干扰；真机上力矩口的速度仍需带滤波的估计（第 002 章），避免差分噪声直接进入阻尼项。运行后应看到：m_robot = m_d = 1 kg 时两条轨迹逐点重合（同一 ODE、同一积分格式、同一初值），这就是"惯量匹配时精确等效"的数值证据；把 m_robot 改成 3 kg 重跑，稳态仍一致而瞬态出现差异（本例钢性接触下幅度不大，环境越软差异越明显）。

片段 2：内环带宽扫描，等效性在哪里开始破裂

# 以力矩口（惯量已匹配，m=1）为基准，扫描位置口的内环带宽
x_ref, _ = simulate('imp', m_robot=1.0)          # 理想等效基准
print(f"{'w_c (rad/s)':>12} {'最大偏差':>10} {'稳态偏差差':>10}")
for w_c in (1e9, 3000.0, 1600.0, 800.0, 400.0, 200.0):
    x_adm, _ = simulate('adm', w_c=w_c)          # 位置口，同一组虚拟参数
    dev = np.abs(x_adm - x_ref)
    ss = abs(x_adm[-2000:].mean() - x_ref[-2000:].mean())
    print(f"{w_c:12.0f} {dev.max()*1e3:9.3f}mm {ss*1e3:9.4f}mm")

解读：预期结果是阶梯式曲线：w_c = 109（理想）时最大偏差为数值零（两条轨迹逐点重合）；w_c = 3000 时在 0.01 mm 以内；1600（≈5 倍线）仍小于 0.05 mm；800 以下开始可见（0.2 mm 级），400 接近毫米级，200 时超过 2 mm 并伴随不衰减的持续振荡。对照第 005 章要修正一个直觉：接触回路的自然频率由接触刚度主导，√((Kd+Kenv)/Md) ≈ 317 rad/s，"内环快 5 倍"的对象是它（≈1600 rad/s）；虚拟自由频率 √(Kd/Md) ≈ 22.4 rad/s 在这里没有指导意义。"稳态偏差差"一列在仍收敛的档位几乎恒为零，再次验证稳态与内环无关的结论；进入持续振荡的档位后稳态本身被破坏、该列数值抬升，这正是"瞬态问题恶化到吞噬稳态"的边界标志。若你的真机实测显示稳态也不一致，直接去查参数换算（Kd 的定义、力的符号、δ 的基准），先别怪带宽。

片段 3：噪声路径对比，同一粒噪声的两条命运

# 自由空间（真力=0），传感器噪声 σ=0.1 N，观察它能否进入位置
rng = np.random.default_rng(0)
dt, n = 1e-4, 20000
m_d, k_d = 1.0, 500.0
d_d = 2.0*np.sqrt(k_d*m_d)
xh, vh, log = 0.0, 0.0, []
for i in range(n):
    f_meas = 0.1*rng.standard_normal()   # 控制器"看到"的噪声力
    # 位置口：噪声直接进虚拟体，经二次积分变成位置随机游走
    a = (f_meas - d_d*vh - k_d*xh)/m_d
    vh += a*dt
    xh += vh*dt
    log.append(xh)
tail = np.array(log[-10000:])            # 最后 1 秒
print(f"位置口：1s 后位移漂移 均值={tail.mean()*1e3:.3f}mm  "
      f"标准差={tail.std()*1e3:.3f}mm")
print("力矩口 Level-0：控制律不含力信号，同一噪声对位置零影响")

解读：预期输出里均值为零附近、标准差约 0.004 mm（2 秒仿真、最后 1 秒窗口），长时间运行也不增长；量级可以这样粗估：白噪声经虚拟导纳滤波后的位移方差 ∝ σ²/(DdKd)。真正需要治理的是非零均值分量：偏置与温漂会变成常驻偏移并缓慢变化，只能靠第 002 章的死区、标定与泄漏兜住。这段实验的教学点是"等效性必须连同信号路径一起声明"：两条实现的端口映射在无噪声时相同，但有噪声时一个把噪声搬进位置、另一个对噪声免疫。做仿真对比时如果只比理想曲线，你会在真机上遭遇"参数一样、表现不同"的困惑；把噪声、延迟、滤波都放进对比，等效性地图才完整。真机实践建议：位置口方案配好死区/泄漏/滤波（第 002 章），并在对比实验里显式记录滤波时间常数，迁移参数时连同它一起迁移。

常见坑

  • 把"稳态一致"当"完全等效"：静推试验很漂亮，一切到动态接触（插拔冲击、振动工况）就露馅。修复：验收清单必须包含阶跃/冲击工况，并核对惯量项。
  • 迁移参数时忽略内环与滤波：从位置口设备搬到力矩口设备直接照抄 Kd、Dd，手感从"干脆"变"发飘"。修复：理解各自的动态附加项（内环滞后 vs 物理惯量），迁移时按目标设备重估有效参数。
  • 参考前馈项实现不一致：同一句"M ẍ + D ẋ + K x = F"，有人写成相对模板（含 ẍd、ẋd 前馈），有人写成绝对形式。参考一动就对不上。修复：在代码注释里明确声明模板形式，测试里加入正弦参考扫描。
  • 用力矩口 Level-0 对标位置口的高动态指标：位置口软件里能"造"出 50 kg 虚拟质量，力矩口物理上就是几公斤，动态轨迹必然不同。修复：需要一致动态时上 Level-2 惯量整形，或把指标按物理惯量重新设计。
  • 忽略 J 的维度/构型效应：一维验证通过就推广到六维，结果不同方向等效程度不同（Mx(q) 随时变）。修复：多方向、多构型分别验证，关注最差构型。

练习与思考

  1. 对模板方程做拉普拉斯变换，写出 δ(s)/F(s) 与 F(s)/δ(s)，并解释"导纳与阻抗互为倒数"在频域的具体含义。★
    提示
    δ/F = 1/(Ms²+Ds+K)；F/δ = Ms²+Ds+K。同一组参数、两个方向的因果读法。
  2. 运行片段 1，把 m_robot 依次设为 0.5、1.0、3.0（保持虚拟参数不变），记录稳态偏差与超调量。哪些指标不变？哪些变了？用推导式解释。★★
    提示
    稳态 K δ = F 不变；瞬态惯性项 mx 由物理惯量提供，超调与峰值时间随 m_robot 变（本例钢性接触下差异较小，把 k_env 调软后更明显）。m_robot=0.5 与 3.0 分别对应"过轻发飘"与"过重发钝"。
  3. 运行片段 2（可加密扫描），找出"最大偏差超过 0.5 mm"的临界 w_c（500–600 rad/s 量级），并解释为什么它远高于自由空间直觉的 5√(Kd/Md) ≈ 112 rad/s：5 倍线应对接触自然频率 √((Kd+Kenv)/Md) ≈ 317 rad/s 取；按虚拟自由频率估算会得到偏低的错误答案。★★
    提示
    0.5 mm 相对本例的接触偏差量级（约数毫米）约 10%；临界点落在 500–600 rad/s，约为接触自然频率 317 rad/s 的 1.5–2 倍，说明"5 倍线"是通用判据，具体任务的相对阈值可以更宽松，但不能按虚拟自由频率 22.4 rad/s 的倍数来估。
  4. 为"参考前馈"缺失设计一个可量化的检测实验：参考取 xd(t) = A sin(ωt)，测偏差的基频分量幅值与相位，说明为什么它可以区分"缺 −m ẍd 前馈"与"内环滞后"两种病因。★★★
    提示
    缺前馈的误差幅值 ∝ Aω²（与加速度成比例），滞后误差 ∝ Aω（与速度成比例）；扫频后看对数斜率即可区分：2×斜率=前馈问题，1×斜率=滞后问题。
  5. 写一份等效性验收方案（不超过 10 条检查项），覆盖稳态、阶跃、正弦、噪声、多构型五个维度，并给每条写出"通过判据 + 不过时的排查方向"。★★★
    提示
    示例条目：静推斜率=Kd（不过→查参数与坐标）；力阶跃超调差<5%（不过→查惯量与内环）；正弦扫频斜率 1 或 2（区分滞后/前馈）；空载噪声位移 drift<0.1 mm/s（不过→查死区泄漏）；伸直/弯曲构型手感差<20%（不过→查 Mx 构型依赖）。

小结

  • 等效性的定义在端口：两条实现只要给出相同的 δ/F 映射，对外部世界就不可区分；模板方程 Mdδ̈ + Ddδ̇ + Kdδ = Fext 是共同目标。
  • 位置口实现靠软件积分，内环理想时精确复现任意虚拟参数；力矩口 Level-0 靠物理，只有 mx = Md 且参考加速度项被妥善处理时才逐项等效。
  • 三条边界条件：内环带宽（位置口）、惯量匹配（力矩口）、参考前馈完整性；稳态一致性是它们的"公约数"，验收从稳态做起。
  • 噪声与延迟不在等价类里：位置口把力噪声搬进位置、力矩口 Level-0 天然免疫；参数迁移必须连同滤波与延迟一起迁移。
