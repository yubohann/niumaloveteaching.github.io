第 061 章：导纳控制中的抗积分饱和

上一章看到事故现场：限速服务器"空转"期间，力误差积分悄悄攒了 5 mm 的虚假偏置，接触瞬间兑成 85.8 N 的力尖峰。本章给出三种防护，条件积分、按 K̂e 钳制、回算，的公式、实现与实测对照，并讲清各自适用边界。

  • 主题：抗积分饱和（anti-windup）/ 导纳力跟踪
  • 关键公式：ẋoff = kief（条件积分/钳制/回算三种修正）；xoff,max = (Fref+margin)/K̂e
  • 预计学时：55 分钟
  • 前置章节：第 060 章（阻抗控制中的饱和处理）

学习目标

  • 认清导纳控制里的三处积分器（力误差偏置、导纳状态、内环位置环）与饱和发生时各自的症状。
  • 理解卷绕的量化机理：偏置空转速率 ki·ef × 空转时长 = 虚假偏置 = 接触瞬间的力尖峰。
  • 会实现条件积分（冻结式）与积分钳制（按 K̂e 定界）两种方案，并说明 KP 条件与滞回为什么必要。
  • 看懂回算（back-calculation）公式的适用前提，能从本章的反例说清"回算增益为什么不能乱设"。
  • 能为力跟踪回路写一份抗饱和验收单：峰值、恢复时间、稳态偏置与"bumpless"切换检查。

背景与动机

导纳控制的力跟踪靠一路积分：把力误差积成位置偏置，高压过去、低压回来。这路积分在"执行器没有尽力"的时候是天使，在"执行器已经尽力"的时候是魔鬼，它不管执行器能不能做到，只管误差还在不在。饱和期间误差必然存在（否则就不是饱和），积分于是持续累积一个"未来才会被兑现"的偏置，等到约束解除（接触发生、限速通过、障碍移开），这笔积攒的偏置一次性变现，就是超调、冲击甚至危险。

第 060 章的实测里，2.5 秒空转攒出 5 mm 偏置、接触峰值 85.8 N；现实中更险的场景是"顶着工件等人靠近"，只要空转不断、积分不停，数字可以大得多。抗积分饱和（anti-windup）是带积分器力控的必备安全件：它的目标是让"执行器受限"这件事对积分器可见，并不改变正常工况（那时积分行为应当原样保留）。

核心原理

1. 导纳回路里的三处积分器

  • 力误差偏置积分：ẋoff = ki(Fref − F)，输出期望位置偏置。本章主角，症状=接触冲击/超调。
  • 导纳状态积分：v 与 xa 由 Mdẍ + Ddẋ = F 两重积分而来。当速度/位置被限幅（第 025、027 章）时，内部状态可能"跑"在受限输出之外；恢复时状态先于输出"缓过来"。症状=解除限幅后的延迟与过冲。
  • 内环位置环积分：伺服内部，一般封闭在驱动器里。它的饱和由驱动器厂商处理，但你要保证"送入内环的指令不长期驻留在不可达区域"。

三者的共同护卫策略一句话：限制"给积分的输入"，而不只限制"积分的输出"，对输出来说已经晚了，偏差早就存进状态里了。

2. 卷绕的量化：给算盘配一张账

饱和期间偏置以恒定速率累积：

Δxwound = ki · ef · tsat 例：ki = 10−4 m/(N·s)、ef = 20 N、tsat = 2.5 s ⟹ 累积 5 mm 偏置

兑现时的力尖峰上界是 Fpeak ≈ Ke·Δxwound（再加撞击动能项）。2×104 N/m × 5 mm = 100 N 级，与第 060 章实测的 85.8 N 吻合。两条反卷绕原则由此得出：要么让 tsat 里的积分速率降为零（条件积分），要么让 Δxwound 有硬上限（钳制）。调小 ki 是第三条路，但它牺牲的是正常工况的响应速度，以此换安全并不划算，不应作为第一选择。

3. 三种方案：公式与边界

方案 A：条件积分（conditional integration），饱和且误差仍在要求"更多同向输出"时冻结积分：

if (饱和) and (ef·∂u/∂xoff > 0)：ẋoff = 0，否则 ẋoff = kief 判据的物理含义：执行器已尽力，且误差方向正是"再挤一点"的方向 → 再积就是卷绕

优点：不需要任何模型，天然正确；缺点：释放瞬间积分从零速率重启，力建立略慢（实测恢复 3.55 s），且判据在噪声下需要加滞回（饱和标志保持 20–50 ms）。

方案 B：积分钳制（clamping with environment knowledge），用环境刚度辨识（第 052 章）给偏置一个物理上限：

|xoff| ≤ xoff,max = (Fref + margin)/K̂e 例：Fref = 20 N、margin 5%、K̂e = 2×104 N/m ⟹ 钳到 1.05 mm

优点：实现最简单（一行 clip），正常工作零影响；实测性能最好（超调 4.3%、2.58 s 收敛，因为它允许偏置平稳积累到"刚好够用"而不冻结）。缺点：依赖 K̂e 的质量与保守性，K̂ 偏小会把钳位收紧（性能损失），偏大则防不住（用最坏环境刚度取值）。

方案 C：回算（back-calculation），标准形式是把执行器"截掉的那部分"反馈回积分器：

ẋoff = kief + (usat − uraw)/Tt u：本环路的某个可饱和量；Tt：回算时间常数（通常 0.05–0.2 s）；(usat−uraw) 为负时把积分拉回

它在"积分器输出即执行器输入"的经典结构里表现很好，但本章要送一个实测反例：把 u 取成伺服速度需求、Tt = 0.15 s 时，回算项在接近段把偏置一路压到负值，机器人根本到不了接触面（峰值力 0 N）。原因：饱和的"截掉的量"（1.2 m/s）大部分来自位置伺服正常的前进需求，与积分卷绕无关；回算把这份正常的差额也当成卷绕去还款，等于给接近动作踩了刹车。结论：回算增益必须与"积分器在环路中的角色"匹配，要么调大 Tt 弱化、要么改用 A/B 方案。

4. 验收与"bumpless"

抗饱和的验收不止"峰值不大"：还要检查无扰切换（bumpless transfer），限幅解除、使能切换、故障复位时，积分状态不得跳变，否则表现为"一顿"。检查清单：峰值力 ≤ 1.2Fref、恢复时间 ≤ 3.5 s、稳态偏置与理论值一致、模式切换点的力斜率无尖峰。

实现思路与设计

把抗饱和接进力跟踪回路（控制周期 1 ms）：

  1. 定义饱和标志：由速度限幅（|vcmd| ≥ 0.99vmax）、位置软限位、力矩利用率任一触发；加 30 ms 保持时间防抖。
  2. 主方案选型：有 K̂e（第 052 章辨识器在线供给）→ 钳制；没有 → 条件积分。两者可叠加：先钳制，再条件积分，双保险（钳制管"上限"，冻结管"空转"）。
  3. 参数：ki = 10−4 m/(N·s)（力回路带宽约 2 rad/s ≈ 0.3 Hz）；margin 演示取 1.05（钳到 1.05 mm），真机保守取值 1.2–1.3 对付 K̂ 的估计误差；条件积分判据用 ef 的滤波版本。
  4. 状态维护：模式切换时偏置只允许"连续演化"，禁用任何以"清零/重置"为手段的快捷修复（它们造成的都是高阶不连续）。
  5. 日志：xoff、饱和标志、ef 三联记录；验收脚本（见片段 3）读日志输出四项指标。

上机顺序：先在仿真里把三种方案的对照表打出来，再在真机上先只开"钳制"跑一周任务，最后按场景需要切到组合方案。

关键代码与解读

片段 1：带三种防护的偏置积分器

import numpy as np

class ForceOffsetIntegrator:
    """力跟踪偏置积分：Anti-windup 三选一（none / cond / clamp / back）。
    输出 x_off 叠加到期望位置上；饱和标志由调用方传入。"""
    def __init__(self, ki=1e-4, dt=1e-3, mode='cond',
                 k_env_hat=2e4, f_ref=20.0, margin=1.05, t_back=0.15,
                 off_hard=8e-3):
        self.ki, self.dt, self.mode = ki, dt, mode
        self.k_env_hat, self.f_ref = k_env_hat, f_ref
        self.t_back, self.off_hard = t_back, off_hard
        self.off = 0.0                      # 偏置状态（唯一的积分器）
        self.clamp = (f_ref * margin) / k_env_hat   # K̂ 钳位界限≈1.05 mm

    def step(self, e_f, sat, u_raw=0.0, u_sat=0.0):
        # 基础积分率：一切防护都在“改这一行的输入”，不在事后砍输出
        rate = self.ki * e_f
        if self.mode == 'cond':
            # 条件积分：饱和 & 误差还要求同向加码 → 冻结
            if sat and e_f > 0.0 and self.off >= 0.0:
                rate = 0.0
            if sat and e_f < 0.0 and self.off <= 0.0:
                rate = 0.0
        elif self.mode == 'back':
            # 回算：把“截掉的量”按 1/T_t 拉回（注意本章反例的教训）
            rate += (u_sat - u_raw) / self.t_back
        self.off += rate * self.dt
        # 对外钳制：钳制模式用 K̂ 界限；其他模式也保留一个硬安全界
        lim = self.clamp if self.mode == 'clamp' else self.off_hard
        self.off = float(np.clip(self.off, -lim, lim))
        return self.off

解读：（1）三种模式共享同一个"积分率"入口，抗饱和的正确姿势是改积分率的输入（冻结或注入负回馈），积分完再砍输出则无效：砍输出相当于把积累抹掉在状态里（下一拍又会算回来），而冻结/回馈让状态本身保持在合理值。（2）条件积分的判据用了"误差方向 + 偏置符号"的双条件：只在"误差想让偏置继续朝同个方向长"时冻结；误差反向时照常积分（那是在正常卸载）。（3）钳制模式仍保留硬安全界 8 mm，K̂ 万一被辨识得离谱，安全界兜底；这是纵深防御，不是冗余啰嗦。（4）回算模式的实现故意保留完整公式：它在本章场景里会被证伪，但换成速度环/电流环级别的抗饱和时它又是标准解法，工具没有对错，场景有。

片段 2：三种方案的同场对照

def tracking_experiment(mode, k_env=2e4, x_e=0.05, f_ref=20.0,
                        v_max=0.02, k_s=25.0, dt=1e-3, t_end=6.0):
    """限速 20 mm/s 的力跟踪：自由段 2.5 s → 接触。返回(峰值, 超调, 恢复时间)。
    这组参数下无防护的基准是：峰值 85.8 N、超调 329%。"""
    integ = ForceOffsetIntegrator(mode=mode, k_env_hat=k_env, f_ref=f_ref)
    x, f_hist = 0.0, []
    for k in range(int(t_end / dt)):
        u_raw = k_s * (x_e + integ.off - x)          # 伺服速度需求
        u_sat = float(np.clip(u_raw, -v_max, v_max)) # 伺服限速(饱和源)
        x += u_sat * dt
        f_env = k_env * (x - x_e) if x > x_e else 0.0
        e_f = f_ref - f_env
        sat = abs(u_sat) >= 0.999 * v_max
        integ.step(e_f, sat, u_raw, u_sat)
        f_hist.append(f_env)
    f = np.array(f_hist)
    idx = int(np.argmax(f > 0.5))
    recover = float('nan')
    for i in range(idx, len(f)):
        if all(abs(v - f_ref) < 2.0 for v in f[i:i + 500]):
            recover = i * dt
            break
    return max(f), 100.0 * (max(f) - f_ref) / f_ref, recover

for mode in ('none', 'cond', 'clamp'):
    peak, overshoot, rec = tracking_experiment(mode)
    print(f"mode={mode:5s}  峰值力={peak:6.2f} N  超调={overshoot:6.1f}%  "
          f"恢复时间={rec:.2f} s")

解读：三行输出构成本章的核心对照表（实测量级）：无防护：峰值 85.8 N、超调 329%、恢复 4.39 s；条件积分：峰值 20.0 N、超调 ≈ 0%、恢复 3.55 s；K̂ 钳制：峰值 20.9 N、超调 4.3%、恢复 2.58 s。（1）两种防护都把峰值压回目标附近，但性格不同：条件积分"宁慢勿错"（冻结导致力建立略慢），K̂ 钳制"该积累就积累、只设上限"，恢复速度最快，代价是那 4.3% 的超调正来自"钳制线本身在目标附近"的设计裕度。（2）如果 K̂e 估计偏大 2 倍（k_env_hat 写成 4×104），钳制线会收紧到 0.53 mm：力被钳在约 10.5 N、根本压不到目标值；反过来把 k_env_hat 改小 2 倍（1×104）则钳位放宽到 2.1 mm，超调回潮到 94%。你可以亲自改参数验证这条单调性。（3）把两种防护叠加（先钳制再冻结）得到的是"两者较保守的行为"，不是两者的优点相加，组合要考虑相位/时序，别指望"都上就更好"。

片段 3：验收脚本，从日志里读四项指标

def acceptance(f_hist, off_hist, sat_hist, f_ref=20.0, dt=1e-3):
    """抗饱和验收：峰值 / 恢复时间 / 稳态偏置 / 切换平滑度。"""
    f = np.array(f_hist); off = np.array(off_hist)
    sat = np.array(sat_hist, dtype=bool)
    idx = int(np.argmax(f > 0.5)) if np.any(f > 0.5) else 0
    recover = float('nan')
    for i in range(idx, len(f)):
        if all(abs(v - f_ref) < 2.0 for v in f[i:i + 500]):
            recover = i * dt
            break
    # 稳态偏置：取最后 0.5 s 的均值，应为 f_ref / K̂ 量级
    off_ss = float(np.mean(off[-500:])) * 1000.0
    # 切换平滑度：饱和标志跳变的邻域内，偏置的“加速度”不应有尖峰
    edges = np.where(np.diff(sat.astype(int)) != 0)[0]
    jerk = float(np.max(np.abs(np.diff(off, 2)))) if len(off) > 2 else 0.0
    print(f"峰值力 {np.max(f):6.2f} N | 恢复 {recover:.2f} s | "
          f"稳态偏置 {off_ss:5.2f} mm | 偏置二阶差分峰值 {jerk:.2e} m | "
          f"饱和切换 {len(edges)} 次")
    ok = (np.max(f) <= 1.2 * f_ref) and (recover < 3.5) and (len(edges) <= 4)
    print("结论:", "通过" if ok else "不通过(按指标逐项排查)")

# 用法：仿真或真机把三联日志攒齐后调用
# acceptance(f_log, off_log, sat_log)

解读：（1）"稳态偏置"这一项容易被忽略却最有诊断价值：理论值 = Fref/K̂e = 1 mm；若实测末值明显偏离（如 5 mm），说明钳制/冻结没有真正作用于稳态，或者 K̂e 与实际差太多，两种病因都一览无余。（2）"偏置二阶差分峰值"检查的是 bumpless：我们允许偏置连续变化（一阶差分），但不允许它的变化率突然拐弯（二阶差分尖峰），那是模式切换在状态里留下的疤痕。（3）"饱和切换次数 ≤ 4"约束的是滞回质量：次数爆炸说明饱和标志在阈值附近抖动，抗饱和自身变成了振荡源。三项判据都以"数字能对账"为准，这也回应了本章的立场：抗饱和是审计工作，不是调参玄学。

常见坑

  • 只限输出、不限输入：把 xoff 事后 clip 到 ±8 mm 却让它自由积累，等于只设"账户上限"、不做"止付"，饱和一解除，全额兑付。修复：改积分率的输入（冻结/回馈/钳制线）。
  • 饱和判据太敏感：用瞬时 |v| ≥ vmax 直接触发，噪声让标志高频翻转、积分断续，表现为"力忽快忽慢"。修复：饱和标志加 30 ms 保持与回差判据。
  • K̂e 失配不设兜底：钳制线完全信任辨识值，辨识器在"无接触段"漂移把 K̂ 带偏，钳位随之发散。修复：硬安全界（±8 mm 或 ±Flimit/K̂min）+ 辨识器的激励门（第 052 章）。
  • 回算增益照抄教科书：Tt 按"好看"的 0.1–0.2 s 直接抄，在本章的架构里压死了接近动作（实测峰值 0 N，压根没碰到工件）。修复：回算前先做一次"谁饱和、积分器贡献多少"的归因实验，归因不清：用条件积分。
  • 用"清零重置"修卷绕：发生撞击后把偏置直接置零，看似回到干净状态，实则制造了位置命令的阶跃，第 053 章的注能分析照样适用。修复：只允许连续状态演化，重置必须配参考的平滑过渡。

练习与思考

  1. 推导卷绕公式 Δxwound = kieftsat，并用它估计：ki = 2×10−4、ef = 15 N、空转 4 s 时的虚假偏置与接触瞬间的力尖峰上界（Ke = 3×104 N/m）。★
    提示
    Δx = 2e−4×15×4 = 12 mm；尖峰 3e4×12e−3 = 360 N。看到这个数字就该明白：任何"顶着障碍等人来"的场景都必须开抗饱和。
  2. 把片段 1 的条件积分判据去掉"偏置符号"那一半（只保留 sat 和 ef > 0），构造一个会让正常卸载过程被误冻结的场景（提示：从高力向低力过渡时偏置应为负、误差也为负……画出符号组合表找出反例），说明双条件设计的必要性。★★
    提示
    列出 (sat, sign e_f, sign x_off) 的八种组合，标出哪些是"加码"、哪些是"卸载"；单条件版会在某些卸载组合上冻结，导致力迟迟降不下来。
  3. 用片段 2 的实验，把 k_env_hat 分别设成 1×104、2×104、4×104、1×105（真实值 2×104），记录钳制模式的峰值与恢复时间，画出"K̂ 估计误差 → 性能"的曲线，并给出你对 margin 取值的建议。★★
    提示
    K̂ 偏小 → 钳位放宽 → 超调回潮、恢复拖长（1×104 档实测 94%、3.7 s）；K̂ 偏大 → 钳位收紧 → 力可能压不到目标（4×104 档只到约 10.5 N）。margin 1.2–1.3 用于覆盖 K̂ 的估计误差，选值要同时验收"能压到目标"与"超调不超标"两个方向。
  4. 设计"抗饱和 + 第 059 章 PC"的组合架构：力跟踪偏置的防护（本章）与端口能量的防护（059）各管什么、会不会互相干扰？给出你判断"两套防护冲突"的两条实验判据，并说明为什么它们实际上作用在不同变量上（偏置 vs 速度）。★★★
    提示
    偏置防护管"命令跑到能力之外"（慢变量、结构性），PC 管"端口能量被泵入"（快变量、瞬时性）；冲突判据：①两套都触发时偏置与速度的符号是否一致；②关闭一套后另一套的触发率是否暴涨。若互不相关，职责隔离成立。

小结

  • 导纳回路有三处积分器；饱和期间"误差仍在、能力已尽"，力误差偏置会空转积累 Δx = kieftsat，解除约束时一次性兑成力尖峰。
  • 方案 A 条件积分：饱和且误差要求加码时冻结积分，无模型、安全，恢复略慢；判据要双符号条件 + 滞回。
  • 方案 B 钳制：|xoff| ≤ (Fref+margin)/K̂e，性能最好（实测 4.3% 超调、2.58 s 恢复），依赖 K̂e 质量并需硬安全界兜底。
  • 方案 C 回算：教科书公式在本章架构下会把接近动作"压死"（实测峰值 0 N），增益与角色不匹配时禁用，归因不清就选 A/B。
  • 抗饱和的正确作用点是"积分率输入"，事后砍输出、清零重置都只是把问题挪到下一拍或下一个信号。
  • 验收四件：峰值、恢复、稳态偏置对账、bumpless（二阶差分无尖峰）。至此饱和处理专题收官；下一站进入高级柔顺任务：曲面跟踪、姿态柔顺与六维力控。
