第二篇 · 参数调节与交互任务

第 041 章：阻抗控制在抛光中的应用

抛光追求的目标是"每一寸表面都吃到同样的压强"。本章把任务坐标系分解、Preston 去除律、表面波纹的频率抑制与边缘力调度合成一套完整的工艺闭环。

  • 主题：抛光 / 任务坐标系分解 / 工艺参数
  • 关键公式：h = k·P·v·t（Preston），ripple ≈ (Kenv·A)·f/fc
  • 预计学时：55 分钟
  • 前置章节：第 031 章、第 033 章

学习目标

  • 会把抛光任务在任务坐标系里三段分解：法向恒力（阻抗力环）、切向进给（位置/速度）、姿态法向对准，并说清每段的控制量与参数。
  • 理解 Preston 方程 h = k·P·v·t 的两个推论：单位行程的去除量只取决于压强（与速度无关），以及停留（v→0）不会过磨。
  • 会用法向力环的"扰动抑制"公式估算表面波纹引起的力纹波，并按波纹频率与进给速度核算环路带宽是否够用。
  • 掌握边缘力调度：抛光垫越界时有效接触面积下降 20–40%，按接触比例降低法向力可避免边缘过磨。
  • 能列出抛光的全参数表（力/刚度/阻尼/进给/转速/滤波）与常见工艺缺陷（过磨、漏磨、边缘塌陷）的参数级原因。

背景与动机

抛光机器人是柔顺控制最大的工业市场之一：汽车外饰、卫浴五金、3C 外壳、模具曲面，共同点是曲面 + 高速扫描 + 要求去除均匀。位置控制在抛光上有一个致命悖论：为了让某个区域"磨到位"，你需要知道曲面的精确形状（否则压力忽大忽小）；而曲面每件都有公差，模具还有回弹，你永远不会精确知道它在哪里。阻抗控制的答案与前面章节一脉相承：不再追问"工件面在哪里"，转而追问"法向力是多少"，面在哪里由柔顺接口自然适应，力的大小由力环严格保持。

但抛光又比单纯的"按压"多一层工艺逻辑：去除量 h 不只取决于压力，还取决于工具与工件的相对速度（Preston 经验关系）。进给速度在转角处会降低、抛光垫会磨损、边缘会"越界"，每一个都会改变实际的去除分布。这一章把控制层（力环、阻抗参数）与工艺层（Preston、边缘调度）的账算到一起，让"均匀抛光"从一个愿望变成一个可验收的指标体系。

核心原理

1. 任务坐标系分解：一软、一稳、一对准

把抛光工具接触点定义任务坐标系：法向 z、切向 x-y、绕轴 r。三个方向的任务完全不同：

法向：ẋr,z = λ(Fd − Fz)（力环，Kd,z = 300–500 N/m 的柔顺底子）
切向：xcmd,xy(t) = 轨迹发生器输出（位置控，进给 20–50 mm/s）
姿态：把工具轴对准曲面法向（误差 ≤2°），绕工具轴不控（主轴自转）

法向力取 15–30 N（对 Ø30 mm 抛光盘，接触压强 P = F/A = 20/7.1×10−4 ≈ 28 kPa）。为什么法向刚度取小值（300–500 N/m）？取大会带来什么后果？因为法向面对的是"波动的地形"：工件表面起伏 + 定位误差 ±0.5 mm 量级，刚度 500 N/m 时这些起伏只需力环"对抗" 0.25 N 的偏置（500×0.0005）；如果刚度取 5000 N/m，同样的起伏就是 2.5 N 的扰动幅度，虽不至于不稳定，却会让力纹波预算变得紧张。工程直觉：软法向让"地形误差"尽量少地转成"力误差"，力环再把剩下的磨掉。

切向为什么不用力控？因为切向的目标是"覆盖行程"（第 039 章搜索的同一逻辑）：位置/速度控制保证轨迹密度均匀；切向力只用来监测（异常增大 = 撞到什么）。这就是第 023 章混合控制选择矩阵在抛光里的标准用法，法向给力、切向给位、姿态给对准。

2. Preston 去除律：为什么"单位行程去除量只认压强"

抛光去除的经验关系（Preston 方程）为 dh/dt = k·P·v，其中 h 为去除深度（m）、P 为接触压强（Pa）、v 为工具相对工件的线速度（m/s）、k 为材料-工艺系数（m³/(N·m)，由试验确定）。把时间与行程的关系 dl = v·dt 代入：

dh/dl = k·P　（单位行程去除深度，与 v 无关！） 推论一：恒压 + 行程覆盖均匀 ⟹ 去除均匀，转角减速不影响均匀性；
推论二：v→0 停留时 h 不再增长（纯 Preston 意义下），不必担心"停顿处磨坑"

这两个推论看起来反直觉，却是抛光策略的基石：进给速度描的是"覆盖地图"，压强描的是"去除刻度"。你把角速度降下来只是为了轨迹精度和热管理，不需要为此补偿压力；真正的均匀性敌人是压强不均，而压强不均有两个来源：（1）法向力波动（力环没压住波纹或边缘越界）；（2）接触面积变化（边缘悬空、曲面曲率大的位置）。第一条靠控制解决，第二条靠"力调度"解决（见下）。

3. 波纹抑制：把表面起伏翻译成频率

表面波纹（waviness）幅度 A、空间波长 λs，工具以进给速度 v 扫过时，它变成频率 f = v/λs 的"力扰动"：未补偿的扰动幅度约 Kenv·A（Kenv 为垫子与工件的接触刚度，5×103–2×104 N/m）。力环以 ωc ≈ λfKenv 的带宽把它们压下去，低频段残余纹波近似：

ripple ≈ (Kenv·A) · f / fc，fc = ωc/(2π) 例：A=0.2 mm、Kenv=1×104 → 扰动 2 N；f=3 Hz、λf=0.02 → fc=32 Hz → 残余 ≈ 0.19 N

这个公式直接把工艺指标（纹波 ≤0.5 N）翻译成控制指标（fc ≥ 12 Hz，即 λf ≥ 2π×12/1e4 ≈ 0.0075 m/(N·s)）。反过来，若工件波纹更细（λs=3 mm、v=50 mm/s → f=17 Hz），fc=32 Hz 时残余已达扰动的一半，此时要么提高增益（受 λmax 限制）、要么换更软的垫（降 Kenv）、要么上压电/主动端执行器（超出本课范围）。工艺级结论：力环带宽不是随便调的，它由"最细的波纹 × 最高的进给速度"共同决定。

4. 边缘调度与工具磨损

抛光盘扫到工件边缘时，有效接触面积 Aeff 从满值降到 50–70%；若法向力保持 20 N 不变，边缘处压强会飙升 1.4–2 倍，这正是"边缘塌陷/过磨"的经典成因。对策是按接触比例缩放力：

Fedge = Fnom · (Aeff/A)，Aeff 由盘心相对边缘的越界距离几何估算 工程常用简化：越界 < 1/3 盘半径时按 0.6–0.8 线性缩放；转速与进给在该区段同时降 20%（热与轨迹双保险）

工具磨损则改变 k 与 A：抛光垫 8–20 小时寿命，磨损后需要（1）重新对刀（补偿高度 0.2–1 mm）；（2）每班次做一次"标准试块"标定（固定 P、v、t 测去除量），把 k 的漂移纳入过程记录，这是工艺员与机器人工程师交接的窗口。抛光项目的成败往往不在控制算法，而在这张"参数-磨损-标定"台账有没有人认真维护。

实现思路与设计

参数总表（Ø30 mm 盘、面积 7.1×10−4 m²、目标 20 N / 28 kPa）：

  1. 法向力环：λf=0.02（fc≈32 Hz）、Kd,z=400 N/m、Md=1 kg、Dd 按 ζeff=0.7 对 (Kd+Kenv) 设计（第 034/037 章规则）；力信号 50 Hz 低通（纹波估计用原始信号）。
  2. 切向轨迹：进给 30 mm/s；曲率半径 < 20 mm 的转角降到 15–20 mm/s（第 025 章分层）；转弯处不补偿压力（Preston 推论一）。
  3. 边缘区：越界距离 0–10 mm 区间按 0.8→0.6 缩放法向力；同时记录该区段的实际力用于离线复核。
  4. 主轴：3000 rpm（50 Hz）旋转；检查 50 Hz 与力环带宽（32 Hz）、结构模态（通常 60–120 Hz）不重合；盘选用偏心/软边设计削弱旋转频率成分。
  5. 磨损台账：每班标定 k；垫高磨损 >0.3 mm 重新对刀；力纹波连续 3 件 >0.8 N 触发垫子更换检查。
设计决策：为什么纹波用"原始信号"评估、而力环用"50 Hz 滤波"信号？

与第 034 章的双通道纪律相同：控制回路吃的是滤波后的低噪声信号（避免把传感器噪声放大成力指令）；而工艺验收要看真实的力波动（包括被滤波器保留的低频纹波和不能保留但真实存在的高频成分）。同一条数据链、两种使用口径，报告里写清"评估用原始、控制用滤波"，评审就不会被数字打架困扰。

关键代码与解读

片段 1：任务坐标系三段合成

import numpy as np

class PolishingTask:
    """抛光任务：法向力环 + 切向轨迹 + 边缘力调度。"""
    def __init__(self, f_nom=20.0, lam=0.02, k_env=1e4,
                 v_feed=0.03, pad_r=0.015):
        self.f_nom, self.lam, self.k_env = f_nom, lam, k_env
        self.v_feed, self.pad_r = v_feed, pad_r
        self.zr = 0.0                  # 法向参考位置（力环积分状态）
    def force_schedule(self, edge_overhang):
        """边缘越界(米) -> 法向力目标：按有效接触比例缩放。"""
        if edge_overhang <= 0.0:
            return self.f_nom
        ratio = max(0.55, 1.0 - edge_overhang/self.pad_r)
        return self.f_nom * ratio
    def step(self, dt, f_z_meas, edge_overhang, tangent_cmd, v_now):
        f_d = self.force_schedule(edge_overhang)
        # 法向：力误差 -> 参考速度（第 031 章结构）；越靠近边缘略降速
        v_scale = 0.8 if edge_overhang > 0.0 else 1.0
        self.zr += np.clip(self.lam*(f_d - f_z_meas), -0.02, 0.02)*dt
        cmd = np.array([tangent_cmd[0], tangent_cmd[1], self.zr])
        return cmd, f_d
    def feed_rate(self, curvature_radius):
        """转角降速：半径 < 20mm 时按比例降到 15-20 mm/s。"""
        if curvature_radius >= 0.02:
            return self.v_feed
        return max(0.015, self.v_feed * curvature_radius/0.02)

解读：类把三段任务的"接缝"写清楚：法向只有一条力环积分状态 zr；切向命令 tangent_cmd 由外部轨迹发生器给出；边缘调度 force_schedule 用最简单的线性接触模型（越界超过盘半径时保底 0.55，再低会从"过磨"翻到"漏磨"）。feed_rate 的转角降速只影响轨迹与热，不影响去除（Preston 推论一），这种"把每个调整都归属到明确目标"的写法，是工艺团队与控制团队对话的语言。真机里 edge_overhang 来自路径几何与工件模型的在线计算（或激光轮廓仪），本片段保持接口纯净。

片段 2：波纹抑制核算，从工艺指标反推控制指标

def ripple_check(lam=0.02, k_env=1e4, amp=0.2e-3,
                 v_feed=0.03, wav_len=0.01, k=1.0):
    """给定波纹与进给，估算力纹波；k 为安全系数(取1.5留裕度)。"""
    f_c = lam*k_env/(2*np.pi)              # 力环带宽(Hz)
    f_d = v_feed/wav_len                   # 波纹的扰动频率(Hz)
    disturb = k_env*amp                    # 未补偿的扰动幅度(N)
    ripple = disturb * f_d/f_c * k         # 低频近似 + 安全系数
    print(f"lambda={lam:5.3f}: 带宽 {f_c:5.1f} Hz, 扰动 {f_d:5.1f} Hz, "
          f"纹波估计 {ripple:5.2f} N")
    return ripple

print("找满足'纹波 <= 0.5 N'的最小 lambda:")
for lam in (0.005, 0.01, 0.02, 0.04):
    ripple_check(lam=lam)

解读：四行输出显示 λ=0.005 → 带宽 8 Hz、纹波约 0.75 N；λ=0.01 → 16 Hz、0.38 N（达标）；λ=0.02 → 32 Hz、0.19 N；λ=0.04 → 64 Hz、0.09 N（再降但逼近 λmax 风险区，需查第 022 章上界）。这就是"工艺指标 → 控制指标"的完整翻译：0.5 N 的验收线自动变成"λ ≥ 0.0075 左右、且必须验证最细波纹与最高进给的最坏组合"。安全系数 k=1.5 是工程习惯，解析近似没有涵盖相位滞后、采样延迟与垫子非线性的全部影响，留一点余量给仿真与首件实测。

片段 3：Preston 均匀性数值实验，恒压 vs "按速度补偿"

def removal_profile(policy="const_p"):
    """沿路径积分去除：直段 30mm/s、慢段 10mm/s、再回 30mm/s。"""
    k_p, P_nom, dt = 1e-9, 28e3, 1e-3      # k_p 为示意系数
    x, h = 0.0, 0.0
    h_at = {}                              # 位置(保留 4 位) -> 累计去除
    while x < 0.1:                         # 共 100mm 行程
        v = 0.03 if (x < 0.07 or x >= 0.09) else 0.01
        # 两种工艺策略：恒压 / 恒定'单位时间去除'(需 P ∝ 1/v)
        P = P_nom if policy == "const_p" else P_nom*(0.03/v)
        h += k_p*P*v*dt                     # dh = k*P*v*dt
        x += v*dt
        h_at[round(x, 4)] = h
    def h_near(xq):
        return min(h_at.items(), key=lambda kv: abs(kv[0]-xq))[1]
    d_fast = (h_near(0.06) - h_near(0.02))/40.0    # 直段 40mm 行程
    d_slow = (h_near(0.085) - h_near(0.075))/10.0  # 慢段 10mm 行程
    print(f"策略 {policy:9s}: 每 mm 去除 直段 {d_fast*1e6:6.3f} um,"
          f"  慢段 {d_slow*1e6:6.3f} um")

removal_profile("const_p")     # 恒压：每 mm 去除只与压强有关
removal_profile("compensate")  # 速度补偿：慢段被过度去除

解读：这段数值实验想让你亲眼看到"恒压 = 均匀"的推论。两行输出的"每 mm 去除"对比中，恒压策略直段与慢段都是 28.0 µm/mm（完全一致，Preston 推论一），而"按 1/v 补偿"的策略在慢段把去除推高到 84.0 µm/mm，3 倍，如果目标只是"每单位行程去除一致"，这个补偿纯属画蛇添足。真正的细节在于：把时间轴换成行程轴看问题，很多工艺直觉会被改写。抛光程序里凡是与"停留"有关的疑虑（转角、减速带、进给暂停）都可以用这条推论排掉；要盯住的是压强本身的两个来源，力波动与接触面积。

常见坑

  • 用刚度大得多的法向参数"求稳"：Kd,z=3000 N/m 让地形误差放大成力纹波（0.5 mm × 3000 = 1.5 N），工艺验收过不了。修复：法向刚度 300–500 N/m，稳定靠力环增益与阻尼；硬弹簧只会把地形误差放大。
  • 转角减速后加压力补偿：按"恒定单位时间去除"思路把慢段压力升上去，慢段过磨 3 倍（片段 3）。修复：按 Preston 推论一，恒压到底。
  • 边缘不做力调度：边线处接触面积下降 30%，压强超 40%，典型的"边缘塌陷"。修复：按越界比例缩放力（0.8→0.6），并降速 20% 控制热输入。
  • 主轴频率与环路撞车：3000 rpm = 50 Hz 落在力环带宽（32 Hz）之外的近处，若垫不平衡量较大，50 Hz 及其倍频会激励结构与力环的耦合振荡。修复：偏心垫/软边设计、力通道带阻滤波、或把转速移开共振区。
  • 不标定磨损：垫子磨薄 0.5 mm 后"同样的力"下压强分布全变，去除率漂移 10–20%，而力曲线看起来"一切正常"。修复：班次标定 + 垫高阈值（0.3 mm）更换提醒。

练习与思考

  1. 计算：Ø30 mm 盘、法向力 20 N 时的平均压强；若目标压强提到 35 kPa，力应改为多少？★
    提示
    A=π×0.015²=7.07×10−4 m²；P=20/7.07e-4≈28 kPa；目标 35 kPa → F=35e3×7.07e-4≈24.7 N。
  2. 推导 Preston 推论：h = k·P·v·t 与 dl = v·dt 联立，证明 dh/dl 只含 P；再说明"机器人停下 1 s"对去除量的影响（主轴仍在转的情况要单独讨论）。★★
    提示
    dh/dl = k·P；完全静止（相对速度=0）时 Preston 意义下去除停止，但主轴自转时的相对速度 ≠ 0，这时"停留处磨坑"是真实的，取决于工具运动学（偏心/公转盘可免）。
  3. 用片段 2 的公式计算：波纹 0.3 mm、波长 8 mm、进给 40 mm/s、Kenv=1.5×104 N/m 时，λ=0.02 的残余纹波；若验收线 0.6 N，λ 至少要多少（查 λmax 复核）？★★
    提示
    f=5 Hz、fc=47.7 Hz、扰动 4.5 N → 纹波≈0.47 N（k=1）；要 <0.6 已经满足；若波纹再细一倍（f=10 Hz）则 0.94 N，需 λ≈0.032 并复核稳定性。
  4. 实验：把片段 3 的慢段速度改为 5 mm/s（更极端），分别运行两种策略，画"单位行程去除，位置"曲线，指出"补偿策略"的最大偏差出现在哪里，并解释为什么实际车间里仍有人坚持补偿（提示：他们优化的是"单位时间产能"，不是"单位面积质量"）。★★
    提示
    慢段去除 6 倍；偏差最大在慢段中部。补偿思路适用于"节拍约束下的总面积去除"，与"表面均匀性"是两个目标，别混用。
  5. 设计题：为"曲率半径最小 15 mm、波纹幅度 0.15 mm、波长 5 mm、进给 25–40 mm/s、验收纹波 ≤0.5 N"写一份参数表（λ、Kd,z、Dd、滤波、边缘调度、标定周期），并列出三项风险与对应的监控信号。★★★
    提示
    最坏 f=40/5=8 Hz，扰动约 1.5–3 N（Kenv 取 1–2e4）→ λ≈0.02–0.03；监控：纹波趋势、垫高、法向力方差；风险：边缘塌陷、50 Hz 主轴耦合、磨损漂移。

小结

  • 抛光的三段分解：法向恒力（λ 力环 + 软底子 300–500 N/m）、切向轨迹（位置控、转角降速）、姿态对准；与第 023 章混合控制的选择矩阵一一对应。
  • Preston 方程的两条工程推论：单位行程去除只认压强（恒压即均匀，减速不补偿）；纯滚动接触下停留不过磨，均匀性的真正敌人是力波动与接触面积变化。
  • 波纹抑制公式 ripple ≈ KenvA·f/fc：把"最细波纹 × 最高进给"翻译成力环带宽与 λ 的下限。
  • 边缘力调度（0.8→0.6）与磨损台账（班次标定、垫高阈值 0.3 mm）是工艺质量的最后两道闸。
