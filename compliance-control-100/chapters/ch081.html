第四篇 · 高级柔顺任务与约束

第 081 章：基于导纳控制的路径修正

导纳让位是"当下"的事，外力一走，机器人就回到原轨迹。本章把反复出现的让位偏差"记账"，再回写进轨迹，让同样的接触不再发生第二次。

  • 主题：轨迹层自适应 / 偏差吸收与固化
  • 关键公式：c ← c + γ(Δx − c)（慢环偏差吸收）
  • 预计学时：45 分钟
  • 前置章节：第 080 章（动态避障）

学习目标

  • 理解"瞬态让位"与"系统性偏差"的区别，学会用时间统计把两者分开。
  • 掌握慢环偏差吸收律 c ← c + γ(Δx − c)，以及时间尺度分离原则对 γ 上界的约束。
  • 会设计一致性检验（稳定性窗口）：偏差稳定多久才允许被写进轨迹。
  • 掌握修正的限幅、方向掩码与持久化管理（任务切换时的清理策略）。
  • 能区分本章的"轨迹层固化"与 065 章"实时轮廓跟踪"、028/029 章"示教修正"的各自定位。

背景与动机

用导纳控制在同一个工装上磨十个工件，你会观察到一件事：每次接触时机器人都会让出几乎相同的 3–5 mm 偏差，工件位置公差、夹具公差、工件自身公差叠加出的系统性偏移。让位本身没问题（柔顺控制的职责），但每次都让、让完就忘，等于放弃了系统里最廉价的那种学习：这些偏差在第九个工件上还会一模一样地再来一遍。

工业现场的传统解法是人工标定：把工件挪正 3 mm，或者手动修一下程序点。本章给出自动化的版本：把短期让位记录成长期修正。它和"学习"的边界也很清楚，只吸收"稳定、重复、方向明确"的偏差，任何一次性的、随机的、瞬态的扰动都不许写进轨迹。这条纪律是本章所有设计细节的来源。

核心原理

1. 偏差的时间结构：三分量分解

导纳输出的偏差 Δx(t) 可以看成三个分量叠加：

Δx(t) = c*（系统分量） + w(t)（随机噪声/振动） + s(t)（瞬态冲击） c* 是环境/工件造成的稳定偏移；w 是零均值波动；s 是偶发大偏差（碰撞、零件卡滞）

路径修正的目标就是估计 c*、忽略 w、拒绝 s。三个分量无法"分离"出解析形式，但它们的统计特征不同：c* 近乎常数、w 零均值、s 大而短暂，用"时间平均 + 一致性检验"就能各就各位。

2. 慢环吸收律：一个新回路，慢一百倍的回路

用一阶（指数平均）跟踪器持续估计偏差的稳定部分：

c ← c + γ·(Δx − c) γ 是吸收速率（1/s 量级）；γ·dt 每周期移动的"吸收比例"

关键参数是 γ 的时间尺度。控制周期 1 ms、接触回路带宽 ~50 Hz 是"快环"；让修正以秒级速度生长（γ≈0.5/s，时间常数 2 s）就是"慢环"。时间尺度分离（十倍以上）保证了两个回路几乎不相互作用：慢环看到的是快环数百个周期的平均效果，天然滤掉了 w 和大多数 s。γ 的上限由此而来：慢环带宽（≈γ/2π）应小于快环带宽的 1/10，想吸收更快，先问快环是否愿意。

3. 一致性检验：把"不许写进轨迹"的东西挡住

单靠 γ 平均还不够：如果工件在某个周期被撞歪了 20 mm，这个瞬态会以指数方式"渗"进 c。加一道检验：只有满足"偏差稳定"条件的时段才允许吸收：

吸收条件：|Δx − c| < ε 且 Var(Δx) 窗口 < v₀ ，持续 Thold 以上 典型：ε = 2 mm、v₀ 对应标准差 0.5 mm、Thold = 0.5 s

不满足条件时冻结 c（不更新），同时把该时段标注为"瞬态事件"记入日志，这个日志后面会很有用：如果同一位置频繁出现瞬态事件，那是机械干涉的信号，不是"公差"。工程直觉：慢环只对"重复出现的历史"负责，不对"当下发生的事故"负责。

4. 修正的合法化：限幅、方向掩码与持久化

把吸收到的 c 加回名义轨迹之前，还要过三道闸门：

闸门规则理由
单次步长|c 的变化率| ≤ 1 mm/s加回轨迹的动作本身要平滑，不能制造新的指令阶跃
累计上限|c| ≤ 5 cm（按任务设定）修正不是万能的；超过上限说明环境变化超出设计假设，应停机检查
方向掩码只吸收法向（接触方向）偏差切向偏差属于"轨迹规划问题"，可能与任务意图冲突，默认不碰

持久化：修正值存进"工件/夹具档案"，下次任务直接加载，跳过学习阶段；任务或工装更换时清空（或切换档案）。这一步让"修正"真正产生工程收益，第一次任务学习，后续任务白赚。

5. 与相邻章节的界线

065 章的"轮廓跟踪"是实时协同：外力决定当下轨迹，任务结束偏差就消失，它服务"这一次"；本章是轨迹层固化：偏差跨任务保留，它服务"下一次"。028/029 章的拖动示教是人工生成修正；本章是自动积累。三者不冲突，可以在同一条产线共存。

实现思路与设计

  1. 数据流定位：在路径生成器与导纳控制器之间插入一层：xref = xnominal + c；导纳层照旧处理 Δx 并输出运动。
  2. 吸收器状态：c（3 维或 6 维）、一致性窗口计时器、方差估计（用滑动窗口或指数方差）。任务开始时空窗启动，前 0.5 s 只统计不吸收。
  3. 每周期三件事：更新统计；若满足一致性条件 → 按 γ 吸收（再乘方向掩码）；把 c 限幅后输出给路径层。任何一步的拒绝都要有日志原因。
  4. 加回轨迹的平滑：c 更新速率被限制（≤1 mm/s），意味着吸收一个 5 mm 的偏置需要 5 s，比"直接跳"慢，但避免了对导纳环的扰动。也可以对 c 再做一次低通，双保险。
  5. 任务边界：任务结束保存 c 到档案；新任务加载前做"合理性检查"（与该档案上次数值偏差超过 5 mm 时警告，可能工件或工装换错了）。
设计决策：为什么吸收的对象是"偏差"？直接吸收"接触力误差"为什么不行？

有人会想：既然目标是让力匹配，何不直接吸收力误差积分？不行。力误差里有 r环境刚度的未知系数，同一力差在刚性/柔性工件上对应完全不同位置修正；而直接吸收位置偏差，就绕过了刚度识别问题（它已经在导纳动力学里被"用"过一次了）。这也是第 019 章自适应方法与本章自动消解的原因：能靠时间平均解决的，不要引入在线辨识的复杂度。

关键代码与解读

片段 1：带一致性检验的偏差吸收器

import numpy as np

class BiasAbsorber:
    """慢环偏差吸收：只有稳定且一致的偏差才被写进修正 c。"""
    def __init__(self, gamma=0.5, hold_s=0.5, eps=0.002,
                 std_lim=0.0005, dt=1e-3):
        self.c = np.zeros(3)          # 已吸收的修正
        self.gamma, self.dt = gamma, dt
        self.eps, self.std_lim = eps, std_lim
        self.hold_needed = int(hold_s / dt)
        self.hold_cnt = 0
        self.win = []                 # 近期偏差样本（用于方差）

    def update(self, dx, mask=(0.0, 0.0, 1.0)):
        """dx: 本周期导纳偏差(3,)  mask: 允许吸收的方向（示例只吸收 z 向）。"""
        mask = np.asarray(mask)
        self.win.append(np.asarray(dx).copy())
        if len(self.win) > 200:       # 200 ms 滑动窗
            self.win.pop(0)

        stable = np.abs(dx - self.c) < self.eps
        var_ok = True
        if len(self.win) > 50:
            var_ok = float(np.mean(np.var(self.win, axis=0))) < self.std_lim ** 2

        if bool(np.all(stable)) and var_ok:
            self.hold_cnt += 1
        else:
            self.hold_cnt = 0             # 任一条件破坏：计时清零（严格不吸收）

        if self.hold_cnt >= self.hold_needed:
            # 通过检验：朝偏差方向缓慢移动 c；mask 外的分量恒为零
            self.c = self.c + mask * self.gamma * self.dt * (dx - self.c)
        return self.c.copy()

解读：三个挑剔的实现细节：（1）hold_cnt 在条件破坏时清零（不逐次减一），瞬态必须让整个稳定窗口从头计时，这是"宁可晚，不可错"；（2）方差窗口 200 ms、需要至少 50 个样本才开始判稳，避免启动阶段就误吸收；（3）mask 默认只开 z 向（接触方向），x/y 即使有系统偏差也不动，防止横向漂移污染任务轨迹。这几个常数都值得按你的任务实测调整，但结构不要改。

片段 2：接进路径层（位置加回 + 平滑保护）

def corrected_reference(x_nom, c, c_prev, max_rate=1e-3, dt=1e-3):
    """把修正 c 加到名义轨迹上；并限制 c 一秒钟最多走 1 mm。"""
    step = c - c_prev
    step_norm = np.linalg.norm(step)
    if step_norm > max_rate * dt:               # 超速：本周期只走允许的部分
        step = step * (max_rate * dt / step_norm)
        c_slow = c_prev + step
    else:
        c_slow = c
    return x_nom + c_slow, c_slow               # 返回修正后参考与"实际生效的 c"

解读：这个函数让"修正生效"本身也变成一个受控的动态过程，max_rate=1 mm/s 意味着 5 mm 的修正用 5 秒缓慢到位。为什么要这么慢？因为修正改变了参考轨迹，等效于给导纳回路一个持续的小激励；只要激励的频率远低于接触带宽，回路就当它是"准静态"的偏置，不会激起振荡。返回 c_slow 是让吸收器同步这个"实际生效值"，避免两边账本不一致。

片段 3：修正档案的存取与合理性检查

import json

def save_bias(path, fixture_id, c):
    """把修正写进夹具档案（示例用 JSON；工程里可入库/PLC）。"""
    with open(path, "w", encoding="utf-8") as f:
        json.dump({"fixture": fixture_id, "c": [round(v, 6) for v in c]}, f)

def load_bias(path, fixture_id, tol=0.005):
    """读取并把关：与档案差异过大时提出警告。"""
    try:
        with open(path, encoding="utf-8") as f:
            d = json.load(f)
        c = np.array(d["c"], dtype=float)
        if d.get("fixture") != fixture_id:
            raise ValueError(f"夹具不符：档案={d.get('fixture')} 当前={fixture_id}")
        if np.linalg.norm(c) > 0.05:
            print("警告：历史修正超过 5 cm，建议先检查工装")
        return c
    except FileNotFoundError:
        return np.zeros(3)      # 首次任务：从零开始学习

解读：档案化是让本章成果"生效于产线"的最后一步。fixture_id 校验防止"A 工件的修正套到 B 工件上"这种灾难，它比数值检查更早发现人为失误。5 cm 的合理性闸门与设计部分的累计上限呼应：修正越长，越可能是环境出了问题而学习方向错了，停机检查比继续"学习"便宜得多。

常见坑

  • γ 太大：慢环带宽逼近接触带宽时，两个回路开始互激，表现为"修正越学越抖"。守住 γ/2π ≤ 快环带宽/10 的底线。
  • 没有一致性检验：一次撞件产生的 20 mm 瞬态被逐步平均进 c，随后任务轨迹永远歪着走。检验条件宁可严，吸收速度宁可慢。
  • 忘记方向掩码：x/y 向的偏差被一并吸收，横向轨迹被"学歪"，操作员百思不得其解。默认只吸收接触法向。
  • 只加不减的漂移：某些工况（温度、磨损）偏差本身在缓慢变化，c 会长期"跟着跑"，这没错，但要监控 c 的变化率：持续单向变化说明系统在退化，该维护了。
  • 任务/工件切换不清档案：上一批薄件的修正（比如 +3 mm）加载到这批厚件上，第一颗就撞，加载时的"合理性检查"必须上线。

练习与思考

  1. 数量级判断：控制周期 1 ms、快环带宽 50 Hz。慢环 γ 取 0.5、5、50 三个值时，验证"≤1/10 快环带宽"的约束是哪个被违反。★
    提示
    慢环带宽 ≈ γ/2π：γ=0.5 → 0.08 Hz（安全）；5 → 0.8 Hz（安全边缘）；50 → 8 Hz（违反）。结论：γ 的量级上限就在 5 附近，具体由实测裕度决定。
  2. 用一阶推理模拟：若吸收速率是 1 mm/s，一个 5 mm 的初始偏差多久吸收完毕（达到 95%）？如果把限速放到 10 mm/s，除速度之外还会有什么变化？★
    提示
    5 s 走完（线性）。10 mm/s 时 0.5 s 完成，但它开始接近"准静态激励"假设的频率上限，可能激起导纳回路的小振荡。慢有慢的道理。
  3. 设计一个区分"系统性偏移"与"工件歪斜"的检验：工件歪斜表现为法向偏差与横向偏差成比例。写出你的特征量与判据思路。★★
    提示
    看 "Δx_xy / Δx_normal" 的比值稳定性：系统性平移时该比值稳定且符号一致；歪斜时比值随位置变化。可对多个接触点绘图观察。
  4. 把一致性检验删掉，用一段"第 3 秒发生一次 30 ms、20 mm 瞬态冲击"的仿真数据跑吸收器，观察 c 轨迹被污染的样子；再加回检验对比。★★★
    提示
    污染会以指数尾巴形式出现（约 γ × 面积 的量级进入 c）。检验版在冲击时 hold_cnt 清零，c 纹丝不动，这就是防护的价值。
  5. 设计完整的"学习-固化-复用"生命周期：三个工件批次（位置公差 ±2 mm）的期望学习曲线什么样的？第几批开始加载档案？档案更新条件与版本管理怎么写？★★★
    提示
    第 1 批在线学习（≤5 s）；第 2 批加载档案后只剩残余偏差 ±0.5 mm 的学习；第 3 批直接稳态。更新策略：只在"新偏差稳定超过 1 mm"时更新档案并记录版本与时间戳。

小结

  • 偏差三分量：系统分量要吸收、随机分量要滤掉、瞬态分量要拒绝，时间统计是分离它们的工具。
  • 慢环吸收律 c ← c + γ(Δx − c)；γ 有硬上限（慢环带宽 ≤ 快环的 1/10），慢属于刻意的设计取舍。
  • 一致性检验（稳定窗口 + 方差门限 + 清零机制）是"不把事故写进轨迹"的关键防线。
  • 修正生效要限速、限幅、带方向掩码；修正资产要进档案、带校验、可复用。
  • 第 076–081 章的"约束与适应"一组至此收尾：四类限制 + 避障 + 路径修正构成了柔顺控制的约束工具箱。下一章进入学习辅助：当规则方法触到天花板时，学习成分从哪里、以什么形式进入控制回路。
