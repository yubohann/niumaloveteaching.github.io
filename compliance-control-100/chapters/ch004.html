第一篇 · 基础、建模与稳定性

第 004 章：导纳控制参数对位置跟踪的影响

导纳控制的"位置跟踪"有自己的时间尺度：Ma 决定多快、Ka 决定让多少、Da 决定晃不晃。本章把这三者与响应速度、噪声灵敏度和恒定偏差的定量关系解出来。

  • 主题：导纳控制 / 参数对位置行为的影响
  • 关键公式：ωn = √(Ka/Ma)，ess = F/Ka，|X/F|共振 ≈ 1/(2ζKa)
  • 预计学时：50 分钟
  • 前置章节：第 003 章

学习目标

  • 区分导纳控制里"位置跟踪"的两层含义：内环伺服跟踪与导纳滤波器自身的偏差演化，不再把两者混为一谈。
  • 会推导导纳滤波器的自由响应与力阶跃响应，掌握时间尺度 t90 = κ/ωn（κ 随 ζ 在 1.7–3.9 之间变化）与超调量 Mp = exp(−πζ/√(1−ζ²)) 两条指标。
  • 理解三个参数的角色分工：Ka 管稳态偏差与噪声灵敏度，Ma 管惯性/滞后，Da 管振荡收敛。
  • 掌握 ωn 处的噪声换算 |X/F| = 1/(2ζKa)，会用"允许位移噪声"反推刚度下限。
  • 能解释恒定偏置力为什么会变成恒定的跟踪偏差，以及标定、泄漏、模型补偿三种对策各自适用什么场景。

背景与动机

拖动示教时有人抱怨"机器人跟手太慢"；装配插针时有人抱怨"机器人一碰就缩、根本对不上孔"；打磨时又有人抱怨"空转时末端自己在抖"。这三类抱怨指向的是同一组参数 Ma、Da、Ka 的不同侧面：响应速度、让位幅度、噪声传播。

需要澄清一个概念：导纳控制里的"位置跟踪"不是传统伺服的意义。机器人内环的位置跟踪误差由伺服带宽决定，跟 Ma、Da、Ka 基本无关；参数真正塑造的是导纳滤波器输出 xa 的时间行为，受力后偏移多快建立、撤力后多快归零、以及它叠加到参考轨迹上会不会留下常驻偏差。把这层关系量化，才能回答上面三类抱怨。

核心原理

1. 导纳滤波器的自由响应：撤力之后怎么归零

导纳滤波器就是方程 Maẍa + Daẋa + Kaxa = Fext。先看最简单的情形：人手把末端推开 xa0 后突然松手（Fext 归零），偏移如何消失？方程为齐次形式，对照标准二阶系统：

ωn = √(Ka/Ma)， ζ = Da/(2√(KaMa))， e(t) = e0·e−ζωnt·[cos ωdt + (ζ/√(1−ζ²))·sin ωdt] ωd = ωn√(1−ζ²) 为阻尼振荡频率（rad/s）；e0 为松手瞬间的偏移（m）

两个指数包络之间藏着全部手感：归零速度由 ζωn 决定，约 4/(ζωn) 秒后偏移衰减到 2%。代入 Ka=500 N/m、Ma=2 kg、ζ=1：ωn=15.8 rad/s（约 2.5 Hz），归零时间约 0.25 s。如果你想要"松手即停、干脆利落"，就得把 ωn 往上提，但 Ma 不能无限小（噪声），Ka 不能无限大（接触稳定性与手感），第 5 节给权衡表。ζ<1 时松手还会"来回探头"：第一次反向过冲量与阶跃超调同式 Mp=exp(−πζ/√(1−ζ²))，ζ=0.3 时过冲 37%，肉眼非常明显。

2. 力阶跃响应：偏差建立的节奏

再看受力的过程：t=0 时刻施加恒力 F0（例如人开始推、或接触开始）。响应为

xa(t) = (F0/Ka)·[1 − e−ζωnt(cos ωdt + (ζ/√(1−ζ²))sin ωdt)] ⟹ xa(∞) = F0/Ka 稳态偏差 = 力 ÷ 虚拟刚度；上升过程由 ζ 与 ωn 共同决定

实用近似：达到 90% 稳态偏差的时间由 ωn 主导，写成 t90 = κ/ωn，修正系数 κ 随 ζ 在 1.7（ζ=0.2）到 3.9（ζ=1）之间变化（ζ=0.7 时 κ≈2.6）。阻尼越小，振荡越早把响应推过 90% 线；接近临界阻尼时最后一段收敛变慢，κ 反而最大。数字感：10 N 的力、Ka=500 N/m，最终偏移 20 mm；若 Ma=2、ζ=1，ωn=15.8 rad/s，t90≈0.25 s，这就是"跟手"的节奏。工程直觉：Ka 是"让位的大小"，Ka/Ma 是"让位的快慢"，Da 是"让位的过程顺不顺"。三者中任何两个变化都会同时改变三件事，所以调参时建议先锁 ζ（按手感），再调 ωn（按快慢），最后微调 Ka（按力度）。

还要注意：t90 是导纳滤波器自身的时间尺度。整个机器人从受力到"看起来动了"还要经过力滤波（延迟约 1–10 ms，可忽略）、内环位置响应（几乎瞬间）与机械传动柔顺（10–100 ms）。当你把 ωn 提到 10 Hz 以上（t90 降到 60 ms 量级）时，传动柔顺开始主导，继续加参数只会把力噪声放大成真实振动。

3. 噪声灵敏度：共振点是最危险的地方

导纳滤波器的频域增益是 |X/F|(ω) = 1/√((Ka−Maω²)² + (Daω)²)。ζ<0.7 时分母在 ωr = ωn√(1−2ζ²) 附近取极小，出现共振峰；ζ≥0.7 后峰消失，增益从零频的 1/Ka 起单调滚降。无论哪种情况，ω=ωn 处的增益都严格等于 1/(Daωn) = 1/(2ζKa)，工程上把它当作带宽内的噪声换算基准：

|X/F|(ωn) = 1/(2ζKa) ⟹ xnoise ≈ Fnoise/(2ζKa) Fnoise 为力传感器噪声幅值（N），xnoise 为对应位移噪声（m）；严格等式，欠阻尼共振峰比它高 1/√(1−ζ²) 倍

用噪声底 0.1 N 测：Ka=200、ζ=0.9 时位移噪声约 0.28 mm；Ka=2000、ζ=1 时约 0.025 mm。这解释了为什么"软"的导纳（小 Ka）天生更吵，滤波器并无故障，"位移 = 力 ÷ 刚度"这条物理定律在噪声上同样成立。想安静：提高 Ka、提高 ζ，或把力先滤得更干净（但要小心相位滞后，见第 016 章）。Ma 的作用则体现在高频段（增益 ∝ 1/(Maω²)）：Ma 越大，高频噪声越被"机械低通"掉，但慢启动的问题随之而来，这就是 Ma 的取舍。

4. 恒定偏差：力上的"零头"直接搬进位置

上面的公式还说明一个容易被忽略的后果：只要力信号里存在恒定的非零分量（比如工具重力补偿残差 1.5 N、线缆拖拽、双脚标定误差），稳态偏差就是 xa = Fbias/Ka 的常驻平移，机器人干活时整体偏着 1.5/500 = 3 mm。它不会自己消失（除非加泄漏，但那对真实慢力同样削弱），也不同于随机噪声（可以平均），必须从源头修掉。三类对策：

  • 标定：上电空载平均，修掉固定偏置与大部分工具重力项（第 002 章）。姿态变化大的任务不够用。
  • 泄漏：时间常数 2–5 s 的位置泄漏能吃掉分钟级的慢漂移，但会让"持续缓慢施力"的任务（缓慢加载）失真。
  • 模型补偿：按当前姿态精确扣除工具重力/惯性项，是唯一能同时保住慢力响应的方案（第 011 章展开）。

顺带一个"系统性"偏差来源：机器人加速运动时，工具惯性会经力传感器表现为伪外力 F = m·a（质心偏移时还有杠杆项），它随加速度变化、均值可能不为零。振动剧烈的搬运轨迹几乎一定会污染导纳输出，重载工具必须做惯性补偿。

实现思路与设计

把选参过程做成四步，每步一个可验证的数字：

  1. 定 Ka：由"期望的最大让位"与"预期接触力"相除。手推 10 N 想走 40 mm → Ka ≈ 250 N/m；装配 8 N 只想让 10 mm → Ka ≈ 800 N/m。再用噪声公式校核：0.1 N 噪声 ÷ (2Ka) 是否低于任务允许的抖动（打磨一般 ≤ 0.05 mm）。
  2. 定 ωn 与 Ma：由允许的响应时间反推 ωn：ζ 取 1 时 t90 ≈ 3.9/ωn，即 ωn ≈ 3.9/t90；ζ 取 0.7 时系数可降到 2.6。再由 Ma = Ka/ωn² 得质量。例如 Ka=500、要求 t90≈0.25 s：ωn≈15.6 rad/s、Ma≈2.1 kg。
  3. 定 Da：Da = 2ζ√(KaMa)。ζ=1 起步；拖动示教想让"松手回弹"更柔和，可到 0.8；冲压类怕过冲，可到 1.2。
  4. 噪声与偏置复核：查共振噪声是否可接受；检查工具重力/惯性补偿残差，估算常驻偏差；必要时细化轨迹规划或补偿；滤波只负责清洁噪声，不负责消除常驻偏差。
设计决策：为什么先用 ζ 锁手感，再调 ωn，最后回 Ka？

三个参数在公式里互相纠缠：改 Ma 会同时改 ωn、ζ 和噪声增益。工程上有效的做法是"归一化调参"，先固定 ζ（它对松手回弹、超调这类主观手感负责），把二阶系统简化为自然的单参数族；再用 ωn 对齐响应速度；Ka 作为最后的绝对尺寸旋钮，因为它同时决定稳态偏差和噪声的量级，改动它会破坏前两步的标定。每改一次 Ka，Da 必须按 ζ 公式同步更新（这就是代码片段 1 把 z 作为入口参数、不直接收 D 的原因）。

关键代码与解读

片段 1：三组参数的阶跃响应对比

import numpy as np

def admittance_step(k_a, m_a, z, f0=10.0, dt=1e-3, t_end=1.5):
    """导纳滤波器对阶跃力 f0 的响应：返回稳态偏差、超调、t90 与轨迹。"""
    d_a = 2.0 * z * np.sqrt(k_a * m_a)     # 用归一化阻尼比入口，避免手算 D
    x, v, hist = 0.0, 0.0, []
    for _ in range(int(t_end / dt)):
        a = (f0 - d_a * v - k_a * x) / m_a  # 力→加速度：导纳方程逐项对应
        v += a * dt                         # 半隐式欧拉（与第 002 章一致）
        x += v * dt
        hist.append(x)
    e = np.array(hist)
    e_ss = f0 / k_a                         # 稳态偏差：力 ÷ 刚度
    t90 = np.argmax(e >= 0.9 * e_ss) * dt  # 首次达到 90% 的时间
    return e_ss, e.max() / e_ss - 1.0, t90, e

# (K_a, M_a, zeta)：从"很软"到"很硬"三档，ζ 都固定在接近临界
for k_a, m_a, z in ((200.0, 3.0, 0.9), (500.0, 2.0, 1.0), (2000.0, 1.0, 1.0)):
    e_ss, over, t90, _ = admittance_step(k_a, m_a, z)
    wn = np.sqrt(k_a / m_a)
    print(f"K={k_a:5.0f} M={m_a:3.1f} ζ={z:.1f}  wn={wn:5.1f}rad/s  "
          f"e_ss={e_ss*1e3:5.1f}mm  超调={over*100:3.0f}%  t90={t90*1e3:6.1f}ms")

解读：三行输出把第 1、2 节的全部公式一次性验证：Ka 与 ess 成反比，刚度越大偏差越小（三档分别为 50 mm、20 mm、5 mm）；ωn 从 8.2 到 44.7 rad/s，t90 从约 0.42 s 缩到约 0.09 s；ζ≈1 的两档超调接近 0，ζ=0.9 的软档过冲也只有 0.1% 量级。注意函数入口用"k_a、m_a、z"，不直接给 D，这正是上一节"归一化调参"的代码化：D 永远从 ζ 派生，杜绝了"改了 K 忘了 D"的经典错误。最后请留意 e_ss 与 t90 的乘积：软档 50 mm×0.42 s≈21 mm·s、硬档 5 mm×0.09 s≈0.44 mm·s，相差约 48 倍（ess·t90 ∝ κ√(Ma)/Ka1.5，κ 随 ζ 缓变）。工程上最常见的问题恰恰是在软档里既想要小偏差又想要快响应，那需要换接口或换策略；拧参数只会把代价挪到内环带宽或噪声上。

片段 2：噪声灵敏度扫描，共振公式的实测

def noise_gain(k_a, m_a, z, w):
    """频率 w 处的位移/力增益 |X/F|，用于评估力噪声传到位置的放大。"""
    d_a = 2.0 * z * np.sqrt(k_a * m_a)
    return 1.0 / np.hypot(k_a - m_a * w * w, d_a * w)

f_noise = 0.1                                  # 传感器噪声底（N）
for k_a, m_a in ((200.0, 3.0), (500.0, 2.0), (2000.0, 1.0)):
    wn = np.sqrt(k_a / m_a)                    # 最坏增益大约在 ωn 附近
    g_res = noise_gain(k_a, m_a, 1.0, wn)
    print(f"K={k_a:5.0f}  wn={wn:5.1f}rad/s  "
          f"共振增益={g_res*1e6:6.1f}µm/N  "
          f"位移噪声≈{f_noise*g_res*1e3:5.3f}mm  "
          f"解析1/(2K)={f_noise/(2*k_a)*1e3:5.3f}mm")

解读：这段代码同时给出"数值计算"与"解析计算"两列，你应该看到两列逐行严格相等，这可以直接代数验证：|X/F|(ωn) = 1/(Daωn) = 1/(2ζKa)。三档位移噪声 0.25→0.10→0.025 mm 的变化说明：软导纳的"抖动"来自物理账本的必然，调试无法消除。如果你的任务对 0.05 mm 级抖动敏感，Ka 必须 ≥ 1000 N/m 左右（0.1 N ÷ 2Ka ≤ 0.05 mm），同时保证力滤波在共振频率（2.5–45 Hz）之前不要"帮倒忙"，滤太狠会把这个频率附近的相位拖到危险区。

片段 3：恒定偏置的常驻偏差，看得见的跟踪平移

# 实验：力信号里带 1.5 N 常值偏置（工具重力残差/标定误差），无真实接触
bias, k_a, m_a, z, dt = 1.5, 500.0, 2.0, 1.0, 1e-3
d_a = 2.0 * z * np.sqrt(k_a * m_a)
x_a, v_a = 0.0, 0.0
for i in range(3000):                 # 3 秒，观察是否"自己稳定下来"
    a = (bias - d_a * v_a - k_a * x_a) / m_a
    v_a += a * dt
    x_a += v_a * dt
    if (i + 1) % 1000 == 0:
        # 打印实测偏差与解析预测 bias/K，两者应一致
        print(f"t={(i+1)/1000:.0f}s  x_a={x_a*1e3:6.2f}mm  "
              f"预测={bias/k_a*1e3:4.2f}mm")
# 结论：偏置不会衰减，轨迹被整体平移 bias/K；若要求 <0.5mm，
# 要么把偏置压到 0.25N 以内，要么加大 K_a，要么做模型补偿

解读：运行结果会显示 xa 在约 0.3 s 内稳定到 3.00 mm 并永久保持，滤波器没有故障，它严格按 F/K 行事。这正是导纳控制最容易被误诊的故障：机器人"总是偏一点"，大家怀疑机械或标定，其实是力信号里那点常值在作祟。把这段实验反过来用就是排查方法：记录空载运动时的 xa 均值，若与某方向上的常值偏移一致，直接去查对应方向的力偏置。最后一行注释给出了量化判断：1.5 N／500 N/m=3 mm，能把偏差压进 0.5 mm 的要么是 0.25 N 以下的残余偏置，要么是 3000 N/m 的刚度，后者会毁掉手感，所以正确解是前者（补偿），代码里改一行系数就能验证这个论断。

常见坑

  • 把 Ka 当"伺服增益"调：以为加大 Ka 会提升"跟踪精度"，实际上它同时缩小让位同时也放大对撞硬度；而真正的内环跟踪误差与它无关。修复：分清两个回路，伺服带宽归内环、手感与让位归导纳。
  • 改了 Ka 不同步改 Da：ζ 随 √Ka 变化，跳过 D 的更新会让系统突然欠阻尼。症状：参数一调就出现松手回弹振荡。修复：Da = 2ζ√(KaMa) 每次同步算。
  • 用低通滤波抢救软导纳的噪声：滤波把响应延迟加了进去，t90 名义值与真实值脱节，手感"说快不快、说慢还抖"。修复：先按噪声公式抬 Ka，滤波只做 30–80 Hz 的"清洁"，不做"整形"。
  • 用泄漏掩盖偏置又抱怨慢力失真：泄漏时间常数的倒数就是"被吃掉的频率下限"，2 s 泄漏会削弱持续 10 s 的慢速加载。修复：需要慢力保真就做模型补偿，泄漏只当兜底。
  • 忽略工具惯性产生的伪力：加速运动时 m·a 项（质心偏移时还有 m·r×α）混进力信号，振动轨迹下均值非零，产生随工况漂移的偏差。修复：重载工具做惯性补偿，或限制加速度并加宽死区。

    Ma 增大 → ωn 降低 → 变慢；共振频率降低但 1/(2ζKa) 与 M 无关，噪声"幅度"不变、频带下移。最优值取决于任务：要快要小 M，要静要大 M，中间取 1–3 kg 的常用折中。
  3. 用片段 1 测量三档参数的 t90，计算 κ = t90·ωn。κ 随 ζ 怎么变？为什么临界阻尼时反而最慢？★★
    提示
    ζ=1 时响应为 (1+ωnt)e−ωnt，尾部拖着长尾，κ≈3.9；ζ=0.7 时振荡提前把响应推过 90% 线，κ≈2.6；ζ=0.2 时 κ≈1.7。慢在"最后一段接近"，不在初始上升。
  4. 拖动示教场景：希望 5 N 手推力让机器人走 25 mm、松手 0.2 s 内基本归零、手部感受不到明显振动。给出 Ka、Ma、ζ 的完整数值，并核算 0.1 N 噪声下的位移噪声。★★★
    提示
    K=5/0.025=200 N/m；0.2 s 归零要求 ζωn≈4/0.2=20，ζ=0.9 时 ωn≈22 rad/s、M=K/ωn²≈0.4 kg，比预想小，检查噪声 0.1/(2×200)≈0.25 mm 是否可接受，不可接受就放宽归零时间。
  5. 推导 ωn 处的位移/力增益 |X/F|(ωn) = 1/(2ζKa)（提示：代入 Ka=Maωn² 化简），再推导 ζ<0.707 时的共振峰频率 ωr=ωn√(1−2ζ²) 与峰值 1/(2ζ√(1−ζ²)Ka)，说明工程上仍常用 1/(2ζKa) 估算的原因及误差方向。★★★
    提示
    在 ωn 处分母 = Daωn，而 Daωn = 2ζ√(KaMa)·√(Ka/Ma) = 2ζKa，严格成立；真实峰值是它的 1/√(1−ζ²) 倍，ζ=0.5 时约 15%、ζ=0.3 时约 5%，公式给出偏乐观的下界。

小结

  • 导纳控制的位置行为由滤波器方程决定：ωn=√(Ka/Ma)、ζ=Da/(2√(KaMa))；松手归零与受力让位都遵守同一组二阶公式。
  • 三条定量尺度：稳态偏差 F/Ka；响应时间 t90 = κ/ωn（κ≈1.7–3.9，随 ζ 缓变）；共振噪声灵敏度 |X/F|≈1/(2ζKa)。
  • 参数分工：Ka 定"让多少"和噪声，Ma 定快慢与高频滚降，Da 定过程平稳度；推荐按 ζ→ωn→Ka 的顺序整定并保持 Da 同步更新。
  • 恒定偏置力产生恒定位置平移且不会自愈；泄漏只治慢漂移，根治要靠标定与模型补偿。
