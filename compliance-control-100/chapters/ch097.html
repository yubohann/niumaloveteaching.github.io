第五篇 · 鲁棒控制与工程实践

第 097 章：导纳控制中的碰撞检测

腕部力传感器看不见"胳膊肘撞了桌子"，但动量观测残差全都看得见。本章把第 090 章的观测器变成全天候的碰撞探测器：自适应阈值带让高速运动不误报，驻留确认让电磁毛刺不进门，残差上升的时间常数给出检测延迟的解析式。

  • 主题：碰撞检测 / 动量残差与自适应阈值
  • 关键公式：r(t) = Δ(1−e−Kot)，t检测 = (1/Ko)·ln(Δ/(Δ−th))
  • 预计学时：65 分钟
  • 前置章节：第 096 章

学习目标

  • 理解碰撞检测与接触检测的本质差异与分工：接触检测回答"是不是在计划部位轻触"，碰撞检测回答"有没有计划外的力量突然出现"。
  • 理解动量残差为什么是"全身碰撞"的探测器：它能看见任何位置的外部作用，而不局限于腕部传感器。
  • 会推导检测延迟公式 t = (1/Ko)·ln(Δ/(Δ−th))，并解释"观测器带宽 Ko 决定检测速度、阈值 th 决定灵敏度"的分工。
  • 会设计自适应阈值带 th(t) = τ0 + kτ|τ| + kv|q̇|，理解每一项对应的模型误差来源（摩擦、科氏项、噪声）。
  • 能说清从"检测到"到"响应"的接口：检测只负责产生事件与等级（第 098、099 章负责停止/回退），并给出漏报/虚报的权衡方法。

背景与动机

上一章把"计划内的接触"变成了可检测的状态，但事故往往发生在计划之外：工作台被移动了 10 cm、人手伸进了作业区、夹具没夹紧工件飞出来、另一台机器人撞上了你的大臂。这些事件的共同点是突发、不可预期、且有些根本不在腕部传感器能看到的方向上，腕力传感器测的是末端法兰的受力，胳膊肘撞上立柱对它来说是"没有信号"。于是需要一个"全身的痛觉"：任何位置的碰撞都会在电机力矩与关节运动之间制造矛盾，而这份矛盾可以被观测器抓住。

第 090 章已经建好了动量观测器：r 收敛到"外部力 + 摩擦"的合力估计。本章把它改造成碰撞探测器：正常情况下，r 只反映摩擦与模型误差（平滑、与速度相关）；碰撞发生时，r 会在几毫秒内跳变。要做的就是在"平滑的日常"与"跳变的意外"之间画一条会动的分界线。

为什么导纳控制尤其需要它？因为导纳的自然反应是"顺从外力"：意外的持续推力会被当成任务力，机器人一边"礼貌"地让开一边继续执行任务，对人是危险的，对设备是破坏性的。导纳让机器人变得温柔，而碰撞检测保证这份温柔不会用在错的场合。检测之后做什么（停止、回退）是接下来两章的主题，本章先把"看得见"做到又快又准。

核心原理

1. 残差检测为何能"全身感知"

回到动量观测器（第 090 章的构造）：

p = M(q)q̇，ṗ̂ = τ + CTq̇ − g − f̂ − r，r = Ko(p̂ − p) r：总外部力矩估计（含未建模摩擦残差）；Ko：观测器带宽（s−1），典型 40–100

与第 090 章相同，可以证明 r 以时间常数 1/Ko 跟踪真实外部力矩 d：ṙ = Ko(d − r)。关键差别在于"d 的来源"：d 是全关节空间的广义外力，无论撞击发生在末端、小臂、大臂还是底座的线缆上，只要它产生了关节力矩，就一定会出现在 d 里。这正是残差法相对"腕力阈值"的本质优势：腕传感器有"视野"，观测器没有盲区（代价是它同时看见了摩擦，所以界定阈值时要为模型误差让出预算）。

2. 检测延迟的解析式：一阶响应穿越阈值

碰撞常被建模成阶跃式的外部力矩 Δ（比观测器带宽慢的碰撞都适用）。r 的响应是一阶低通：r(t) = Δ·(1 − e−Kot)。它穿越阈值 th 的时刻（忽略模型误差与噪声）就是检测延迟：

t检测 = (1/Ko)·ln( Δ/(Δ−th) )，前提 Δ > th（否则漏报） 例：Ko = 80、Δ = 25 N、th = 4 N ⟹ t ≈ 2.2 ms；Δ = 5 N 时约 20.1 ms

这条公式说明两个工程事实：（1）"大碰撞自然快、小碰撞天然慢"，这属于物理规律，算法无法改变：观测器需要时间让 r 爬升到阈值，碰撞越小爬到得越晚（Δ 逼近 th 时延迟趋于无穷，即漏报）；（2）想更快，要么提高 Ko（代价：噪声与模型误差放大，见第 090 章的估计噪声公式），要么降低 th（代价：虚警增多）。实数例：巡线擦碰（5 N 级）在 Ko = 80、th = 4 N 下检测约 20 ms；同一阈值下 25 N 的撞击约 2.2 ms，一个"轻扫"总是比"重击"更难被发现，安全标准里因此常要求额外的人体接触力限值（第 098 章）。

3. 自适应阈值带：给模型误差留一条"随速浮动"的走廊

阈值 th 必须大于"正常情况下的 r 波动"，否则高速运动时摩擦与模型误差就会触发虚警。工程上标准的自适应带形式：

th(t) = τ0 + kτ·|τ| + kv·|q̇| τ0：噪声与静态模型误差底（约 5–10 N·m 视角关节）；kτ、kv：力矩与速度的比例系数

每一项都有明确的误差来源对应：τ0 覆盖力/力矩传感噪声、重力模型误差与静摩擦的不确定性；kτ|τ| 覆盖"与负载成正比"的摩擦与传动误差（负载越大，摩擦误差越大）；kv|q̇| 覆盖与速度相关的摩擦、科氏项建模误差与观测器噪底（Ko·噪声）。工程直觉：这条带就是"正常世界的轮廓线"，机器人跑得越快、出力越大，正常波动就越宽，阈值就随之外扩；一个慢速工作、受力很小的机器人应该使用紧贴底线的阈值，从而获得最高灵敏度。

4. 检测判定与响应接口

逐关节比较 |ri| 与 thi 之后，还需两项工程处理：（1）归一化聚合，不同关节阈值量级不同，把 |ri|/thi 作为统一灵敏度指标，各关节任意一个超过 1 即候选（也可用最大值）；（2）驻留确认，连续超过阈值 N 拍（2–5 ms）才算事件，滤掉电磁脉冲与单点异常。响应分级建议：轻度（1.2–2×阈值）→ 减速+吸附保持（第 098 章安全停止）；中重度（> 2×）→ 立即停止+反向回退（第 099 章）；同时记录 r 的峰值与方向用于事故复盘。

最后必须说清漏报与虚报的边界条件：漏报发生在"Δ 太小（低于带）、碰撞太慢（低频、被观测器视为慢变外力）、方向恰好在弱可观测方向"；虚报发生在"阈值带没有覆盖某个模型误差通道"，最典型的是未知负载（第 093 章若未做负载辨识，负载起飞时 r 跳变会被判碰撞）。所以碰撞检测的调试流程是：先在各种正常工况（空载/满载/各种速度）下记录 r 的包络、让阈值带完整覆盖之，再故意施加已知小撞击验证灵敏度。先学会"假装没看见"，才能真的看见。

实现思路与设计

  1. 观测器参数：Ko = 40–100；先按噪声预算确定上限（Ko·m·σv 与模型误差一起决定 r 的平稳波动）。
  2. 模型账：完成 M̂、重力、摩擦与负载补偿（第 091–093 章）；未补偿的负载每 1 kg 就会在 r 里留约 10 N 的"可疑跳变"。
  3. 阈值带标定：在各工况下记录 max|r|，取 1.3–1.5 倍作为 τ0、kτ、kv 的拟合初值；逐关节独立标定。
  4. 检测逻辑：|ri|/thi 取最大值；连续 3 采样超限确认；输出事件等级（轻度/重度）与 r 的方向向量。
  5. 与接触状态（第 096 章）联调：armed 窗口内、且碰撞判据未触发，才允许进入 CONTACT；窗口外的高 r 只走碰撞链路，两条链路共享观测器数据但判定互斥。
  6. 验证：正常工况 30 分钟无虚报；对 5/10/25 N 的标定撞击测量检测时间，与公式 t = (1/Ko)ln(Δ/(Δ−th)) 对照，偏差超过 50% 时检查摩擦模型与阈值带。
设计决策：为什么不能用"力传感器 + 阈值"替代动量残差？

如果只看腕部传感器：（1）盲区，小臂与大臂的碰撞不在测量方向上，永远看不见；（2）覆盖成本，要做到全身覆盖，每段都要装力传感或皮肤，成本与维护难度陡增；（3）静默失效，传感器一旦偏置或损坏，检测能力无声消失，而残差法用的是驱动与编码器这两套"事故后也必须工作"的信号。残差法与腕传感是互补关系：腕传感负责接触力的精确计量（任务用），残差负责突发事件的快速告警（安全用）。两者独立，任一路失效都不会让系统完全"失去痛觉"。

关键代码与解读

片段 1：残差碰撞监视器（自适应阈值带）

import numpy as np

class CollisionMonitor:
    """动量残差碰撞检测：自适应阈值带 + 驻留确认，输出事件与等级。"""
    def __init__(self, m=2.0, k_o=80.0, dt=1e-3,
                 tau0=1.0, k_tau=0.06, k_v=0.30, dwell=3):
        self.m, self.k_o, self.dt = m, k_o, dt
        self.tau0, self.k_tau, self.k_v = tau0, k_tau, k_v
        self.dwell = dwell
        self.p_hat = 0.0            # 观测器积分状态
        self.r = 0.0                # 残差：外部力 + 摩擦残差的估计
        self.count = 0

    def update(self, v, u, f_fric_hat=0.0):
        p = self.m * v                              # 实测动量（速度来自编码器）
        self.p_hat += (u - f_fric_hat - self.r) * self.dt
        self.r = self.k_o * (self.p_hat - p)        # 与第 090 章同一观测器
        # 自适应阈值带：静态底 + 负载相关项 + 速度相关项
        th = self.tau0 + self.k_tau * abs(u) + self.k_v * abs(v)
        ratio = abs(self.r) / th                    # 归一化灵敏度（多关节时取 max）
        if ratio > 1.0:
            self.count += 1
        else:
            self.count = 0
        event = self.count >= self.dwell           # 连续超限才升级为事件
        level = "重度" if ratio > 2.0 else ("轻度" if event else "无")
        return event, level, float(ratio), float(th)

解读：（1）观测器部分与第 090 章逐行一致，同一个观测器同时服务"力估计"与"碰撞检测"，是这套方法最经济的用法；（2）自适应带只有三个参数，但它们由"正常工况包络"标定，不能拍脑袋决定（设计第 3 步）；（3）ratio = |r|/th 是关键抽象：它把不同量级的关节统一成"超限倍数"，既方便多关节聚合，也让分级（1.2–2 轻度、> 2 重度）与阈值参数解耦；（4）驻留计数与第 096 章的写法相同，检测类逻辑的通用模式。

片段 2：往复运动 + 突加碰撞的对照实验

def run(adaptive=True, const_th=1.0, n=2500, dt=1e-3, seed=9):
    """0.7 Hz 往复运动激励模型误差；1.0 s 处施加 25 N 突加碰撞。"""
    rng = np.random.default_rng(seed)
    m, b_f, fc_nom = 2.0, 2.0, 3.0
    mon = CollisionMonitor()
    x, v, u_prev = 0.0, 0.0, 0.0
    false_cnt, t_det, first_r = 0, None, None
    for i in range(n):
        t = i * dt
        w, amp = 2 * np.pi * 0.7, 0.25
        v_ref = amp * np.sin(w * t)                  # 往复参考速度
        a_ref = amp * w * np.cos(w * t)
        # 简单跟踪律：惯量前馈 + 速度反馈（真实系统会更复杂，这里够用）
        u = m * a_ref + 20.0 * (v_ref - v)
        fc_true = fc_nom + 1.5 * np.sin(4 * np.pi * x)   # 位置相关摩擦（模型错）
        f_fric = b_f * v + fc_true * np.tanh(v / 0.01)
        f_coll = 25.0 if t >= 1.0 else 0.0            # 1.0 s 处碰撞（持续）
        v += (u - f_fric - f_coll) / m * dt
        x += v * dt
        f_hat = b_f * v + fc_nom * np.tanh(v / 0.01)      # 名义摩擦模型
        event, level, ratio, th = mon.update(v, u_prev, f_hat)
        if not adaptive:                                   # 对照：固定阈值
            event = abs(mon.r) > const_th
            level = "触发" if event else "无"
        u_prev = u
        if t < 1.0 and event:
            false_cnt += 1
        if t >= 1.0 and event and t_det is None:
            t_det = t - 1.0
        if first_r is None and t >= 1.0 and abs(mon.r) > 0.5:
            first_r = mon.r
    return false_cnt, t_det, mon.r

for name, kw in [("固定阈值1N", dict(adaptive=False, const_th=1.0)),
                 ("自适应带 ", dict(adaptive=True))]:
    fc, td, r_end = run(**kw)
    td_s = f"{td*1000:5.1f} ms" if td is not None else "未检出"
    print(f"{name}: 虚报次数={fc:4d}  检测延迟={td_s}  末态残差={r_end:5.1f} N")

解读：预期结果，固定阈值 1.0 N 对模型误差的余量最小：0.7 Hz 往复运动把"位置相关摩擦的残差"推高到逼近阈值，工况稍有恶化就会反复虚报；自适应带 在运动段把阈值外扩到 1.5–2.2 N，虚报为 0，而 1.0 s 的 25 N 碰撞照样在几毫秒内被抓住（末态残差接近 25 N + 剩余摩擦误差）。三个实现细节：（1）速度参考是正弦，加速度前馈让 u 里包含"正常的大力矩"，用来验证阈值带的 k_tau*|u| 项确实在起作用；（2）摩擦误差被刻意造成"位置相关 + 高速时更大"（与速度项同相），这正是实际中最常见的虚警源；（3）对照实验里把 event 覆写为固定阈值判断，保证两条路径共享同一个观测器与同一段数据，对照才干净。

片段 3：检测延迟与碰撞幅度的预算表

import numpy as np

def latency_table(k_o=80.0, th_list=(2.0, 5.0, 10.0), f_list=(3.0, 5.0, 10.0, 25.0)):
    """按 t=(1/K_o)ln(f/(f-th)) 列出不同碰撞幅度与阈值下的检测延迟。"""
    print(f"K_o={k_o:.0f} 1/s   (单位: ms，'-' 表示漏报)")
    print("碰撞幅度\\阈值 " + "  ".join(f"{th:5.1f}N" for th in th_list))
    for f in f_list:
        row = []
        for th in th_list:
            if f <= th:
                row.append("    - ")
            else:
                t_ms = 1000.0 * np.log(f / (f - th)) / k_o
                row.append(f"{t_ms:5.1f} ")
        print(f"   {f:5.1f} N     " + "  ".join(row))

解读：这张表是"安全需求 ↔ 检测能力"的对账单。读法示例：阈值 5 N、Ko = 80 时，25 N 撞击 2.8 ms 检出、10 N 碰撞 8.7 ms、5 N 碰撞永远不会触发（恰好等于阈值），"能检测到的最小碰撞"就等于阈值本身，而阈值又被模型误差的包络顶高，这构成了残差法的灵敏度地板。工程上调这张表的顺序是：先给"必须检测到的最小碰撞"（如安全标准关心的 10 N 接触力）划一条线，反推允许的最大阈值，再检查正常工况的 r 包络是否低于该阈值，两者冲突时，唯一的出路是改善模型（更准的摩擦/负载补偿）或提高 Ko（改善信号链），不能拍一个"既要又要"的阈值。

常见坑

  • 负载未补偿就上碰撞检测：抓取 4 kg 工件的瞬间，r 跳变约 40 N，直接触发"重度碰撞"。修复：先完成第 092/093 章的重力与负载补偿，并把"抓放事件"通知检测器进入短暂屏蔽窗。
  • 固定阈值：为了不误报被迫把阈值抬高，结果灵敏度全面下降；为灵敏调低则高速运动天天虚警。修复：自适应带 + 逐关节标定；本章片段 2 就是这套对照的证据。
  • 摩擦模型老化不更新：温度、磨损让摩擦残差缓慢增大，r 的包络随之变宽，某天开始间歇虚警。修复：把"正常工况 r 的包络"做成长期监控指标（第 100 章的评估体系），漂移超 30% 触发模型复标。
  • 用一个 Ko 走天下：大关节用小 Ko、小关节用大 Ko 才合理；统一值会让某些关节噪声大、另一些关节迟钝。修复：逐关节按"噪声底 + 惯性"单独整定，4–8 个关节分别标定阈值带。
  • 检测与响应混在一起写：检测器里直接调用急停，调试期一虚警就整线停机，没人敢开。修复：检测与响应解耦，检测输出"事件 + 等级 + 方向"给状态机（第 098/099 章），响应策略单独整定与测试；调试期先只记录不动作。

练习与思考

  1. 推导 t检测 = (1/Ko)ln(Δ/(Δ−th))：从 ṙ = Ko(d − r)、d 为阶跃 Δ 出发求解 r(t)，再令 r(t) = th。★
    提示
    r(t) = Δ(1−e−Kot)；解 e−Kot = 1 − th/Δ，两边取对数即得。
  2. 取 Ko = 40、60、100，计算 10 N 碰撞在阈值 3 N 下的检测时间；再计算"检测时间内机器人以 0.3 m/s 运动时会多走多远"，讨论为什么安全设计要同时限制速度与检测时间。★★
    提示
    t = (1/Ko)ln(10/7)：Ko = 40 时约 9 ms、100 时约 3.6 ms；0.3 m/s 下分别多走 2.7 mm 与 1.1 mm。停止距离还要叠加制动过程（第 098 章），所以"限速 + 快检"必须成对使用。
  3. 把片段 2 的碰撞幅度从 25 N 逐渐降到 5 N，测量检测延迟并与片段 3 的表格对照；再故意把摩擦模型误差放大一倍（1.5 改成 3.0），说明阈值带必须如何调整、灵敏度损失多少。★★
    提示
    5 N 碰撞在自适应带（约 1.8 N 动态阈值）下仍可检出但延迟到 15 ms 量级；误差加倍后阈值带要上浮约 1.5 N，最小可检碰撞随之抬高，用表格量化"模型质量买来的灵敏度"。
  4. 设计一套完整的碰撞检测验证方案：正常工况清单（3 种负载 × 3 种速度）、虚警判据（连续 30 分钟 0 虚报）、灵敏度验证（5/10/25 N 标定撞击各 10 次、延迟统计）、以及失效降级策略（观测器异常时用腕传感阈值兜底）。★★★
    提示
    验证方案要让"模型误差的所有已知通道"都被覆盖：抓放瞬间、温度变化前后、线缆拖拽姿态；降级策略的关键是"两条独立通道互为备份"，写出切换条件与日志字段。

小结

  • 碰撞与接触的分工：接触（096 章）靠"计划上下文 + 力阈值"识别预期交互；碰撞靠动量残差识别任何位置的突发外力。
  • 残差法全身无盲区：d = 广义外力，任何碰撞都进 r；代价是摩擦与模型误差也进 r，必须用阈值带隔离。
  • 检测延迟 t = (1/Ko)ln(Δ/(Δ−th))：Ko 定速度、th 定灵敏度，小碰撞天然慢，最小可检幅度就是阈值本身。
  • 自适应带 th = τ0 + kτ|τ| + kv|q̇| 是在"灵敏度"与"不虚报"之间的可持续平衡，参数由正常工况包络标定。
  • 检测与响应解耦：本章只产出"事件 + 等级 + 方向"；下一章消费它，安全停止：怎样在几毫秒内既停得住又不"硬撞停"。
