第二篇 · 参数调节与交互任务

第 022 章：基于位置的导纳控制用于力跟踪

工业机器人多半只开放位置接口。本章用"导纳内环 + 参考位置自适应外环"两层结构，在只下发位置的前提下把接触力稳定跟踪到期望值，并给出增益上界的推导。

  • 主题：导纳控制 / 力跟踪
  • 关键公式：Mdδ̈ + Ddδ̇ + Kdδ = Fext − Fd，ẋr = λf(Fd − Fext)
  • 预计学时：50 分钟
  • 前置章节：第 002 章、第 021 章

学习目标

  • 理解"基于位置"的力跟踪结构：为什么在位置接口机器人上，力跟踪必须写成"导纳内环 + 缓慢移动的参考位置"两层回路。
  • 会推导纯比例导纳的稳态力公式，说明静差为什么正比于未知的面位置误差，从而理解积分（参考自适应）项的必要性。
  • 会推导两层回路的闭环特征方程 s³ + (Dd/Md)s² + ((Kd+Kenv)/Md)s + λfKdKenv/Md = 0，并用劳斯判据求出 λf 的稳定上界。
  • 会按"先内环后外环"的顺序整定参数：Kd 定接触手感、Dd 定瞬态、λf 定力收敛速度。
  • 能写出 1 ms 周期的离散实现，理解每一步的符号约定、限幅与滤波为什么这样设计。

背景与动机

工业现场大量机器人只提供位置命令接口：你下发一个笛卡尔位姿或关节角，内环伺服自己把它走到。这类机器人上做接触任务（抛光、装配、力控打磨）时，最自然的柔顺方案就是导纳控制：力传感器测到接触力，控制器把力"折算"成一段位置修正，加到命令上。第 002、007 章已经建立了这个基本回路。

但那两章解决的只是"受外力时机器人让位"的被动柔顺问题，力是被吸收的对象，不是被跟踪的目标。真实任务往往要求更高：不管工件面在哪、不管环境多硬，接触力都要稳定在 15 N。这就是力跟踪（force tracking）问题。本章要回答：在只有位置接口、环境位置 xe 与环境刚度 Kenv 都未知的前提下，怎样让稳态力恰好等于期望值，以及为什么必须引入一层积分（缓慢移动的参考位置）。

核心原理

1. 问题定义：三个未知量挡住力跟踪

考虑一维按压场景，规定坐标正方向为"压入工件"。接触力由环境弹簧模型给出：

Fext = Kenv · (x − xe)，仅当 x > xe 时有接触 x：末端实际位置（m）；xe：工件表面位置（m）；Kenv：环境刚度（N/m）

目标是 Fext → Fd（期望力，N）。难点在于：xe 不知道、Kenv 不知道、工件还可能被装偏。如果只做位置控制，控制回路里根本没有"力"这个量，永远无法保证力的大小；如果做纯柔顺（导纳让位），机器人只会"按你规划的位置去压"，压力大小还是由未知的环境参数决定。

2. 纯比例导纳的静差：为什么必须"再慢一层"

先看最朴素的做法，把力误差直接喂给导纳内环。定义退让量 δ：机器人从参考位置 xr 后退 δ 下发命令，即 xcmd = xr − δ，δ 满足二阶导纳：

Mdδ̈ + Ddδ̇ + Kdδ = Fext − Fd Md：虚拟质量（kg）；Dd：虚拟阻尼（N·s/m）；Kd：虚拟刚度（N/m）

静态时导数项为零，δ = (Fext − Fd)/Kd。再与 x = xcmd = xr − δ、Fext = Kenv(x − xe) 联立消去 x 和 δ：

Fss = Kenv⁄(Kd+Kenv) · Fd + Kseries · (xr − xe)， Kseries = KdKenv⁄(Kd+Kenv) Kseries 是两个"弹簧"串联的等效刚度（参见第 001 章练习）

取典型值 Kd = 800 N/m、Kenv = 1×105 N/m、Fd = 15 N：若装配偏差让 xr 比实际面多出 2 mm，静差就是 Kseries×2 mm ≈ 793×0.002 ≈ 1.6 N，对要求 ±0.5 N 的抛光任务已经超标。而且这个偏差等于多少，你事先根本不知道。结论：纯比例导纳的力跟踪精度由未知的面位置偏差决定，必须引入积分作用把它吃掉。

3. 两层结构：快内环塑形，慢外环清零

解决方案是把参考位置 xr 也变成一个动态量，用力误差的积分推动它：

ẋr = λf · (Fd − Fext) λf：参考自适应增益，单位 m/(N·s)，含义是"每牛顿力误差让参考位置走多快"

于是系统分成两个时间尺度：内环导纳（响应快，主导毫秒到百毫秒级的接触瞬态，决定"手感"）；外环积分（响应慢，一秒量级，缓慢推动 xr 直到力对上）。稳态时 ẋr = 0，立刻得到 Fext = Fd，静差严格为零，与 Kenv、xe 完全无关。此时内环退让量 δ = (Fext − Fd)/Kd 回到零（无接触的找面阶段它承担 −Fd/Kd ≈ −19 mm 的预载行程），它不再影响力的数值。

工程直觉：内环导纳决定"摸上去的感觉"，外环积分决定"力跟踪得多准、多快"，两者分频设计，互不打架。另外注意，如果机器人还没接触（Fext = 0），外环会以 λfFd 的速度把 xr 往工件方向推，力跟踪回路本身自带"自动找面"能力，但这也意味着必须限制 xr 的行程与速度，否则工件缺失时机器人会一直压下去（见"常见坑"）。

4. 闭环稳定性：劳斯判据给出的增益上界

两层回路耦合起来后，系统变成三阶。把环境方程代入导纳方程，忽略内环位置伺服的动态（假设它足够快），并令 ef = Fd − Fext，可得线性化状态方程（状态取 x−x̄、ẋ、xr−x̄r）：

s³ + Dd⁄Md s² + (Kd+Kenv)⁄Md s + λfKdKenv⁄Md = 0

对 s³ + a₂s² + a₁s + a₀ 用劳斯判据，稳定条件是 a₂a₁ > a₀，即：

λf < λmax = Dd(Kd+Kenv)⁄MdKdKenv = Dd⁄MdKd · (1 + Kd⁄Kenv) 环境越硬（Kenv 越大），上界越小 → 外层必须越慢

代入 Dd = 56.6、Kd = 800、Md = 1、Kenv = 1×105：λmax ≈ 0.071 m/(N·s)。我们实际取 λf = 2×10−3，安全裕度约 35 倍。物理解读：积分器与二阶系统串起来后，闭环特征根是"一对接触极点 + 一个被积分器越推越远的实根"；λf 越大，接触极点对的实部越靠右，超过上界后这对极点穿越虚轴，表现为接触力持续振荡。这也解释了为什么"环境越硬上界越低"：硬环境里参考位置每挪一点，力就涨得猛，积分必须更谨慎。

实现思路与设计

控制周期取 1 ms（内环导纳自然频率 ωn = √(Kd/Md) ≈ 28 rad/s ≈ 4.5 Hz，1 kHz 绰绰有余）。整定顺序与依据：

  1. Kd = 800 N/m：与环境刚度（典型 1×105 N/m）之比约 1/125，保证接触稳定；同时找面阶段的预载行程 Fd/Kd ≈ 19 mm，幅度适中、不会让内环伺服跑出大动作。
  2. Md = 1 kg，Dd = 2√(KdMd) ≈ 56.6 N·s/m：临界阻尼起步，接触过渡不振荡。若你偏好更硬的"手感"可提到 ζ = 0.9，但不要低于 0.7，外层积分会进一步压低相位裕度。
  3. λf = 2×10−3 m/(N·s)：等价于力环时间常数 τf = 1/(λfKseries) ≈ 1/(2×10−3×793) ≈ 0.63 s。抛光类任务要求力收敛在 1 s 内，这个速度合适；希望更快就按 λmax 的比例上抬，但保留 5 倍以上裕度。
  4. 安全限制：外环参考速度 |ẋr| ≤ 50 mm/s（防止"找面"时冲撞）、参考位置相对起始点的行程 ≤ 100 mm、退让量 δ 限幅（相当于最大虚拟压缩 32 N）；力信号加 30 Hz 一阶低通，滤掉高频噪声再进积分器，否则噪声被积分成参考位置抖动。
设计决策：为什么滤波器不能任意加？

力滤波器在回路里引入相位滞后。经验规则：滤波截止频率至少是力环带宽的 5–10 倍。本例力环带宽约 1/(2π×0.63) ≈ 0.25 Hz，30 Hz 滤波器的滞后对稳定性几乎无影响；但如果你为了"让力显示好看"把滤波降到 2 Hz，滞后角在 0.25 Hz 已有约 7°，再加上传感器与通信延迟，裕度会被悄悄吃掉。

关键代码与解读

片段 1：两层力跟踪导纳控制器的核心类

import numpy as np

class ForceTrackingAdmittance:
    """位置接口机器人上的力跟踪：导纳内环 + 参考位置自适应外环。"""
    def __init__(self, k_d=800.0, m_d=1.0, d_d=None,
                 lam=2e-3, dt=1e-3, v_r_max=0.05):
        self.k_d, self.m_d = k_d, m_d
        # 未指定阻尼就按临界阻尼起步：先保证接触过渡不振荡
        self.d_d = d_d if d_d is not None else 2.0 * np.sqrt(k_d * m_d)
        self.lam, self.dt, self.v_r_max = lam, dt, v_r_max
        self.delta, self.d_dot = 0.0, 0.0   # 内环状态：退让量与退让速度
        self.x_r = 0.0                       # 外环状态：参考位置（慢变量）

    def step(self, f_ext, f_d):
        # ---- 外环：力误差 -> 参考速度。积分作用保证稳态力 = f_d ----
        # 符号约定：外力超出期望（f_ext > f_d）时参考位置后退；
        # 没接触时（f_ext=0）参考位置自动向前找面，这是该结构的副产品
        v_r = np.clip(self.lam * (f_d - f_ext), -self.v_r_max, self.v_r_max)
        self.x_r += v_r * self.dt
        # ---- 内环：二阶导纳。力大了，退让量 delta 变大，命令位置后退 ----
        a = (f_ext - f_d - self.d_d * self.d_dot
             - self.k_d * self.delta) / self.m_d
        self.d_dot += a * self.dt           # 半隐式欧拉：先速度后位置
        self.delta += self.d_dot * self.dt
        return self.x_r - self.delta         # 命令位置 = 参考位置 - 退让量

解读：类里有两个状态对，delta/d_dot（快）与 x_r（慢）。delta 的方程符号是"力大则后退"，如果写成 +(f_ext - f_d)，机器人在力偏大时反而前进，正反馈直冲发散。外环只积分力误差、不乘刚度：这正是"不需要知道 Kenv"的关键，它直接以速度形式推动参考位置，Kenv 只影响收敛速度，不影响稳态。限幅放在 v_r 上，参考位置由有界速度积分而来，位置连续、速率受限；若改成对 x_r 硬限位，速度会在边界处突变。

片段 2：4 秒按压仿真，从自由空间自动接触并稳定到 15 N

# 环境与控制器的"未知量"：墙面位置、环境刚度只存在于仿真环境里
k_env, x_e, f_d = 1.0e5, 0.050, 15.0
ctrl = ForceTrackingAdmittance()
x, f_log = 0.048, []                    # 从面外 2 mm 起步

for i in range(4000):                   # 4 s，1 ms 周期
    f_env = k_env * (x - x_e) if x > x_e else 0.0
    x_cmd = ctrl.step(f_env, f_d)
    x += (x_cmd - x) * 0.3              # 内环位置伺服的一阶近似
    f_log.append((i * 1e-3, f_env))

t = np.array([s[0] for s in f_log]); f = np.array([s[1] for s in f_log])
i90 = int(np.argmax(f >= 0.9 * f_d))
print(f"进入接触时刻 ≈ {t[np.argmax(f > 0.01)]*1000:.0f} ms")
print(f"90% 上升时间 = {t[i90]*1000:.0f} ms   峰值 = {f.max():.2f} N")
print(f"末 0.5 s 均值 = {f[-500:].mean():.3f} N   期望 {f_d} N")

解读：这段仿真的重点是观察两个时间尺度的分工。前 ~100 ms：外环以 λfFd = 30 mm/s 把参考位置推向墙面（"自动找面"），接触瞬间内环 δ 快速反应、力平滑上升；随后 ~0.6 s：外环积分把静差磨掉，力收敛到 15 N；末段均值输出 15.00 N 说明静差为零。(x_cmd - x) * 0.3 把内环伺服近似成增益 0.3/拍的一阶环节，真机里这里换成实际轴控，但仿真里这样写足以体现"快内环 + 慢外环"的层次。若把 λf 改成 0.2（超过劳斯上界 0.071），你会看到力开始持续振荡而永远收敛不了。

片段 3：用特征方程验证 λf 的稳定上界

def force_loop_eigs(lam, k=800.0, d=56.6, m=1.0, k_env=1e5):
    """两层回路的线性化特征根：判断给定 lambda 是否稳定。"""
    # s^3 + (D/M)s^2 + ((K+Kenv)/M)s + lam*K*Kenv/M = 0
    return np.roots([1.0, d / m, (k + k_env) / m, lam * k * k_env / m])

lam_max = 56.6 * (800 + 1e5) / (1.0 * 800 * 1e5)   # 劳斯判据上界
print(f"劳斯上界 lambda_max = {lam_max:.4f} m/(N*s)")
for lam in (2e-3, 0.02, 0.08, 0.2):
    r = force_loop_eigs(lam)
    tag = "稳定" if r.real.max() < 0 else "不稳定"
    print(f"lambda={lam:5.3f}  最大实部={r.real.max():+8.3f}  {tag}")

解读：把判据变成可执行代码是控制工程的好习惯。四个增益里 2×10−3 和 0.02 稳定（后者振荡趋势已经明显，振荡模态的阻尼在下降），0.08 与 0.2 越过上界、最大实部为正。注意最大实部为正≠立刻发散得飞快：线性化预测指数增长（0.08 一档约 e+3.3t），而真机与本章仿真里的限幅、饱和会把增长截住，几秒内表现为持续的等幅振荡，在真机上很容易被误判成"环境扰动"。真机调试时建议从 λmax 的 1/20 起步，逐步上抬并观察力的振荡趋势。

常见坑

  • 外环符号反了：lam * (f_d - f_ext) 写成 (f_ext - f_d) 后，力偏大时参考位置继续往里压，力误差被"积分放大"，几秒内撞到限幅。先把手按在传感器上验证：人手施力越大，命令位置应撤得越快。
  • λf 取大求快：超过 λmax = Dd(Kd+Kenv)/(MdKdKenv) 后力会持续振荡，典型周期约 2π/√((Kd+Kenv)/Md)（本例 ≈20 ms）。症状是"力表针来回扫、工件被磨出波浪"；修复是减 λf 或增大 Dd（上界与 Dd 成正比）。
  • 没接触就长时间外环推进：工件缺失时外环每秒能推 λfFd ≈ 30 mm，若没有行程限幅，几秒后就是一次高速撞机。加 |ẋr| 限幅 + 行程限幅 + 接触超时报警三件套。
  • 力信号偏置未标定：传感器零点偏 1 N，稳态力就会整体偏 1 N，因为外环诚实地把"测得值"当真实值。上电先空载测 2 s 均值做零偏补偿（第 091 章展开）。
  • 忽略内环伺服带宽：位置环如果只有 10 Hz，快导纳（4.5 Hz）已经"追不上"，等效于给回路加了大延迟，劳斯推导的前提被破坏，稳定裕度大幅缩水。要求内环带宽 ≥ 5 倍内环导纳频率。

练习与思考

  1. 取 Kd = 500 N/m、Kenv = 5×104 N/m、xr − xe = 1 mm，用稳态公式计算纯比例方案的力静差；若要求静差小于 0.2 N，装配偏差需控制在多少以内？★
    提示
    Kseries = 500×5e4/(500+5e4) ≈ 495 N/m，静差 ≈ 495×0.001 ≈ 0.5 N；把 0.2 = 495×Δx 反解 Δx。
  2. 把片段 2 的 λf 分别改成 1×10−3、5×10−3、2×10−2，记录 90% 上升时间与峰值力。画出"上升时间-增益"关系，解释为什么继续增大到 0.08 会出现振荡。★★
    提示
    上升时间应随 λf 近似反比缩短（一阶环节 τ=1/(λKseries)）；0.08 超过劳斯上界 0.071，低频特征根实部转正。
  3. 推导劳斯上界公式：写出闭环特征方程，用 a₂a₁ > a₀ 展开，验证 Kenv→∞ 时 λmax→Dd/(MdKd)，并解释这个极限值的物理意义。★★★
    提示
    ∞ 刚度意味着参考位置挪动、"力增长"无上限；Dd/(MdKd) 恰好是"阻尼时间常数 Md/Dd"与刚度 Kd 的组合，1/(λmaxKd) = Md/Dd。
  4. 把 Kd 从 800 改为 200 N/m（其他不变）。先写出你对三件事的预测，δ 稳态值、λmax、力环时间常数，再跑仿真验证。★★
    提示
    δ 稳态回到 0，但无接触时的找面预载为 −Fd/Kd = −15/200 = −75 mm，量级大，需检查 δ 限幅；λmax = 56.6×(200+1e5)/(1×200×1e5) ≈ 0.284（更大）；τ = 1/(λ×Kseries)，Kseries≈196 → τ ≈ 2.55 s（更慢）。软刚度换来更大增益裕度但更慢的力收敛。
  5. 设计安全逻辑：当机器人以"自动找面"模式运行 2 s 仍未检测到接触（Fext > 0.5 N），应触发什么动作？写出判据与处理流程，并说明为什么不能只靠行程限幅兜底。★★
    提示
    接触超时 → 暂停外环推进（冻结 xr）并报警；只靠行程限幅时，撞上侧壁或夹具同样会触发，原因难以区分。

小结

  • 位置接口机器人做力跟踪的标准结构：快内环（二阶导纳 δ）+ 慢外环（参考位置积分 ẋr=λfef）。
  • 纯比例导纳的静差 Fss−Fd = Kseries(xr−xe) 由未知面位置决定，这就是必须用积分清零的根本原因。
  • 两层耦合后系统三阶，劳斯判据给出 λmax = Dd(Kd+Kenv)/(MdKdKenv)；环境越硬，外层必须越慢。
  • 参数整定顺序：Kd → Dd = 2√(KdMd) → λf（留 5 倍以上裕度），并用行程/速度限幅与接触超时保护"自动找面"过程。
