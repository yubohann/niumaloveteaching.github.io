第 025 章：导纳控制中的速度限制

导纳控制的输出是速度/位置：外力一大，速度就大。本章讲清速度限制为什么是导纳控制的第一安全阀、方向保持式限速怎么做，以及限速如何"温和地"改变机器人手感而不注入能量。

  • 主题：导纳控制 / 速度安全约束
  • 关键公式：Mdẍ + Ddẋ + KdΔx = Fext，vss ≈ F/Dd，vcmd = v·min(1, vmax/‖v‖)
  • 预计学时：45 分钟
  • 前置章节：第 011 章、第 024 章

学习目标

  • 理解导纳控制中速度为什么"天生"危险：准静态下 v ≈ F/Dd，外力尖峰线性转化成速度尖峰。
  • 掌握方向保持式限速（范数缩放）与逐轴截断的区别，知道为什么前者是默认选择、后者的误差如何随外力方向变化。
  • 能证明"限速不注入能量"：速度被截断只会削减功率流，因此限速属于"安全方向"的非线性：它牺牲响应速度，但不会威胁稳定性。
  • 会做"限速-阻尼"联合设计：先按最坏外力定 Dd 下限，再用限速处理尖峰，用饱和率监视触发自适应阻尼。
  • 能写出状态一致性自动满足的离散积分（积分"截断后的速度"），并解释它为什么天然没有积分卷绕问题。

背景与动机

导纳控制把力"翻译"成运动：外力越大、运动越快。回看准静态关系，阻尼主导时 v ≈ F/Dd。你按"人手轻推 10 N、机器人走 100 mm/s"的良好手感把 Dd 定成 100 N·s/m，那么一次 80 N 的碰撞（工件卡住、机械限位）就会命令机器人以 0.8 m/s 的速度冲出去，这已经接近很多协作臂的额定速度上限，而在精细设备旁边这就是事故。

问题出在"线性"：物理世界的外力分布是有长尾的（正常 10 N，异常 100 N），而导纳映射是线性的，异常会被原封不动地放大成速度异常。速度限制（velocity limiting）就是在这个长尾上装一道闸门，它不改正常手感（小力时根本不触发），只在异常时把速度锁在安全上限，同时用"位置积分被限速后的速度"保证命令永远连续、状态永远自洽。与第 024 章的力矩限制对照：那一章防的是"执行器累垮"，这一章防的是"机器人跑飞"。

核心原理

1. 速度从哪来：v ≈ F/Dd，以及 Dd 的两难

一维阻尼为主的导纳方程（Kd = 0，拖动/自由接触的典型设置）是：

Md·ẍ + Dd·ẋ = Fext − Fd ⟹ 稳态速度 vss ≈ F/Dd F：作用于机器人的外力（N）；Dd：虚拟阻尼（N·s/m）；vss 单位 m/s

取"手感良好"的 Dd = 100 N·s/m：人力 10 N → 100 mm/s（合适），人力/碰撞 100 N → 1 m/s（危险）。如果你为了压住最坏情况而把 Dd 干脆提到 1000 N·s/m，则 10 N 时只有 10 mm/s，机器人像陷在蜂蜜里，教学拖动完全不能用。线性阻尼无法同时满足"轻推要动、猛推不能飞"，这正是需要非线性限速的根本原因。

再看力传感器噪声 0.1 N 的量级：噪声速度 = 0.1/100 = 1 mm/s，可忽略；但若为了让轻推更灵敏把 Dd 降到 10 N·s/m，噪声速度变成 10 mm/s，机器人会"自己慢慢漂"。这是 Dd 的第二个下界（噪声），设计时要一起考虑。

2. 方向保持式限速：整体缩放，方向不变

三维速度命令 v = (vx, vy, vz) 超限时，两种做法：

逐轴截断：v′i = clip(vi, ±vmax,i)　　方向可能旋转
范数缩放：v′ = v · min(1, vmax/‖v‖)　　方向不变，只缩大小

逐轴截断的危险与第 024 章点头限定一样：当 vy 先超限而 vx 未超时，合成运动偏离外力方向，人往斜上拖、机器人却水平滑出去，接触任务里相当于磨偏。"范数缩放"保持只有一个标量缩放因子作用于整个向量，是默认选择。工程上常把"统一缩放"与"单轴软上限"结合：先按每轴上限求统一缩放系数 s = mini(vmax,i/|vi|)，再让 s 在接近 1 的一段区间内平滑过渡（见片段 3）。

3. 限速为什么是"安全的非线性"

把速度钳在 vmax 改变了系统的动力学，但它改变的方向是良性的：机器人从"力源"中获取的机械功率是 P = F·v；限速只可能让 |v| 变小，所以任何时刻外部注入系统的能量只减不增。换句话，限速不会像"错误的力偏置"那样制造正反馈。它带来的是三样可预期的副作用：

  1. 等效阻尼变大：饱和期间系统表现为 Deff = F/vmax（例如 80 N / 0.15 m/s ≈ 533 N·s/m），手感变"黏"，这是降级，不是故障。
  2. 速度波形出现"平台"：力继续增大，速度不再增大，位置按 vmax·t 匀速推进。只要撤力后回到线性区，系统重新按设计阻尼收敛。
  3. 退出饱和时的加速度跳变：速度从 vmax 立刻下跳会带来较大反向加速度；在接触任务里表现为"顿一下"。用 5–20 ms 一阶平滑整流可消除（对总行程影响仅毫米级）。

工程直觉：限速像汽车的下坡缓降，它不改变发动机特性，只是在超过设定车速时接管刹车；一旦坡缓了，发动机特性原样回归。

4. 与积分状态的关系：为什么这里天然无卷绕

位置命令是速度的积分：xcmd ← xcmd + v′·Δt。只要积分的和状态使用的都是限速后的 v′，位置输出就永远与真实运动一致，不存在"内部账本与现实脱节"的问题，这是导纳限速比力矩限幅省心的地方（第 024 章需要专门的状态一致化，这里由结构自动保证）。反例：先积分未限速的 v、再对 xcmd 做限幅，那么"位置被截断"会丢行程、状态与实际不符；更糟的是若同时有参考弹簧回拉，会制造非物理的"记忆位置"。原则：限幅作用在积分之前的速度上，积分之后的位置不再做限幅。

实现思路与设计

  1. 定 vmax 与场景分层：自由拖动 150–300 mm/s；抛光/擦拭行走 50–100 mm/s；精细装配 10–20 mm/s。在任务状态机里切换 vmax 向量（如接近段 z 轴限 20 mm/s，自由段 150 mm/s）。
  2. 定 Dd 下限：按"常用外力不应触发限速"取 Dd ≥ F常用/vmax。例：F常用=15 N、vmax=150 mm/s → Dd ≥ 100 N·s/m。再用尖峰测试确认（例 80 N 时若无机会触发限速，说明 Dd 还能小一点，手感更轻）。
  3. 选 Md：0.5–2 kg；Md 决定从静止到 vmax 的加速时间常数 Md/Dd = 10–20 ms，也决定"起步跟手"程度。
  4. 限速器：先范数缩放、再逐轴兜底；缩放系数做 5 ms 平滑；开启饱和计时，连续饱和 > 0.2 s 时按表增大 Dd（每次 +20%）来主动减少饱和度，撤力后 1 s 内缓慢恢复。
  5. 安全链：vmax 之下还有驱动器级速度保护与机械限位；三层独立，不互相替代。
设计决策：为什么自适应阻尼要"慢慢恢复"？

饱和解除瞬间如果 Dd 立刻跳回原值，速度命令会因阻尼突变而出现跳变，人体感为"咯噔"。用 1 s 时间常数把 Dd 拉回，等于把饱和事件的"余震"摊平；对控制安全而言，稍大的阻尼永远比稍小的安全。

关键代码与解读

片段 1：方向保持式限速器

import numpy as np

def limit_velocity(v, v_max, v_max_axis=None):
    """方向保持限速：统一缩放 + 逐轴软上限。
    v: 3 维速度命令; v_max: 范数上限; v_max_axis: 各轴独立上限(可选)。"""
    n = np.linalg.norm(v)
    s = 1.0 if n <= v_max else v_max / n      # 缩放系数只作用于整个向量
    if v_max_axis is not None:
        # 每轴上限也通过统一缩放满足：取所有轴里最紧的那个约束
        ratios = np.where(np.abs(v) > 1e-12,
                          v_max_axis / np.maximum(np.abs(v), 1e-12),
                          np.inf)
        s = min(s, float(np.min(ratios)))
    return v * s

解读：s 始终是一个标量，保证输出方向与输入方向严格一致，这是与"逐轴 clip"的本质区别。ratios 的写法把"各轴独立上限"也翻译成统一缩放：例如 z 轴限 20 mm/s，工具以 45° 斜向运动时，整条速度向量会被缩到 z 分量恰好 20 mm/s；把 z 分量单独砍掉则会改变方向，45° 斜线被压成 26.6° 的斜线。注意 np.maximum(..., 1e-12) 防止除零：静止时 ratios 置 inf，不产生假约束。函数保持无状态、纯函数式，方便在状态机里按不同阶段传入不同的 vmax。

片段 2：限速导纳一步，状态一致性由积分结构天然保证

class LimitedAdmittance:
    """导纳控制 + 限速：先限速、后积分，位置状态永远与现实同拍。"""
    def __init__(self, m_d=1.0, d_d=100.0, dt=1e-3, v_max=0.15):
        self.m_d, self.d_d, self.dt = m_d, d_d, dt
        self.v = np.zeros(3)         # 虚拟速度：有限状态
        self.x = np.zeros(3)         # 命令位置：v 的积分
        self.v_max = v_max
        self.sat_time = 0.0

    def step(self, f_ext):
        # 阻尼主导的导纳：加速度 = (外力 - D*v)/M，外力大则 v 涨得快
        a = (f_ext - self.d_d * self.v) / self.m_d
        v_free = self.v + a * self.dt          # 未限速的新速度
        n = np.linalg.norm(v_free)
        if n > self.v_max:
            v_free = v_free * (self.v_max / n)  # 方向保持缩放
            self.sat_time += self.dt            # 记录饱和时长用于自适应
        else:
            self.sat_time = max(0.0, self.sat_time - self.dt)
        self.v = v_free
        self.x += self.v * self.dt             # 关键：积分的是限速后的速度
        return self.x.copy()

解读：整个类只有两个状态（v、x），且 self.x += self.v * self.dt 里的 v 一定是限速后的值，位置输出与虚拟速度严格一致，撤力后不会"放账"。把 a 写成 (f−Dv)/M，与物理方程逐项对应，是为了让代码"一看就是物理"：M 定加速快慢、D 定稳态速度 F/D、限速器只做最后一个非线性环节。严格说，饱和期间 self.v 停在 vmax，方程对应的梯度流结构被破坏，但由第 3 节的分析，能量注入只减不增，行为可控。工程上再把 vfree 之后加一个 5 ms 一阶滤波即可消除退出饱和的加速度跳变（下一片段）。

片段 3：尖峰对比实验 + 饱和率监视

def run_spike(v_max=None, d_d=100.0, m_d=1.0, dt=1e-3, T=1.0):
    """1 秒内前 0.1 s 经历 80 N 尖峰，其余时间力为 0。"""
    ctrl = LimitedAdmittance(m_d, d_d, dt, v_max if v_max else 1e9)
    x_peak, v_peak, sat_frames = 0.0, 0.0, 0
    for i in range(int(T / dt)):
        f = np.array([80.0, 0.0, 0.0]) if i * dt < 0.1 else np.zeros(3)
        x = ctrl.step(f)
        v_peak = max(v_peak, np.linalg.norm(ctrl.v))
        x_peak = max(x_peak, np.linalg.norm(x))
        sat_frames += 1 if ctrl.sat_time > 0 else 0
    return v_peak, x_peak, sat_frames / int(T / dt)

for vm in (None, 0.15):
    vp, xp, sat = run_spike(v_max=vm)
    tag = "无限速" if vm is None else f"限速 {vm*1000:.0f} mm/s"
    print(f"{tag}: 峰值速度 {vp*1000:6.0f} mm/s  最大行程 {xp*1000:5.1f} mm")

解读：跑出来会看到，无限速时峰值速度 (80−0)/100 冲到 ~0.8 m/s、最大行程约 80 mm；限速 150 mm/s 后峰值被锁在 150 mm/s、行程约 16 mm，尖峰结束后系统按 D 恢复线性收敛。sat_frames 就是"饱和率"，工程上做两件事：（1）阈值告警，单次任务饱和率 >10% 说明工艺外力异常，交人检查；（2）自适应阻尼，连续饱和时把 Dd 乘 1.2（上限 3 倍），让机器人主动"变黏"，尽快退出饱和，避免长期顶着限速跑。

常见坑

  • 逐轴 clip 代替范数缩放：外力斜向时运动方向漂移，表现为"拖它往上、它却往侧滑"。症状在斜向操作时最容易暴露；修复：统一缩放系数。
  • 限速加在积分之后：对 xcmd 限幅会丢行程、破坏状态一致；还可能产生"位置记忆"把机器人缓缓拉回。修复：限速作用在速度上、积分在限速之后。
  • vmax 定得太低：正常操作也在饱和区里跑，人感觉"推不动、一顿一顿"，与人的力闭环还可能形成低频振荡（人加力→机器微动→人再加力）。修复：让正常工况只占上限的 50–70%。
  • 只在自由空间限速、忽略接触过渡：向工件接近时仍用 150 mm/s，接触瞬间以该速度"撞"上去。修复：状态机里接触前自动切低速档（10–20 mm/s），或按力大小连续降限速。
  • 饱和状态不做限速历史记录：事后无法区分"任务真快"与"异常外力"。修复：记录饱和率与最大未限速速度 vfree，两者差得越多说明安全阀工作得越频繁。

练习与思考

  1. 常用外力 15 N、期望手感速度 120 mm/s，求 Dd 下限；再算 70 N 碰撞下的"无限速"稳态速度。★
    提示
    D ≥ 15/0.12 = 125 N·s/m；70 N 时 v = 70/125 = 0.56 m/s，这就是必须限速的原因。
  2. 用片段 1 的函数，令 v = (0.1, 0.2, 0.05) m/s、统一上限 0.15、z 轴独立上限 0.03 m/s，手算缩放后的向量，并验证方向严格不变。★★
    提示
    先范数缩放：‖v‖≈0.229 → s₁=0.15/0.229≈0.655；再看 z 轴比 0.03/0.05=0.6 更紧，最终 s=0.6，输出 (0.06, 0.12, 0.03)，与 v 平行。
  3. 推导：饱和期间等效阻尼 Deff = F/vmax。用它解释"为什么 80 N 尖峰里机器人手感'像黏住'却依然可控"。★★
    提示
    速度不再随力增长，力全部由"虚拟大阻尼"平衡；力与速度仍单调对应，只是斜率变了，是可控的降级。
  4. 改参数实验：把片段 3 的 vmax 依次取 50 / 150 / 500 mm/s，记录峰值速度与最大行程，画图并解释行程对 vmax 的关系。★★
    提示
    尖峰期间行程 ≈ vmax×0.1 s（加上恢复段），与 vmax 近似线性；到 500 mm/s 后与无限速结果接近，说明限速已接近失效边界。
  5. 设计题：为"接近-接触-拖动"三阶段任务设计 vmax 状态机（自由段、接近段、接触段），写出每段的数值与切换判据，并说明为什么采用平滑过渡、直接跳变会带来什么后果。★★★
    提示
    例如 150 / 20 / 50 mm/s；切换用 0.2 s 线性插值，跳变限速会让速度命令出现台阶、机械冲击和体感顿挫。

小结

  • 导纳控制的软肋是线性映射：v ≈ F/D，长尾外力会线性放大成速度尖峰；Dd 又要兼顾手感与噪声，无法靠单一阻尼解决。
  • 限速是导纳侧的第一安全阀：方向保持（范数缩放）、限速在积分之前、逐轴上限用统一缩放表达。
  • 限速只削减功率注入，是安全方向的非线性；代价是等效阻尼变大、波形出平台、退出饱和有加速度跳变（用 5–20 ms 平滑处理）。
  • 位置状态积分"限速后的速度"，天然状态一致、无卷绕；饱和率可用于告警与自适应阻尼。
  • 下一章回到阻抗侧处理几何安全：奇异点规避，为什么近奇异区是导纳的"速度爆炸区"，阻尼最小二乘与可操作度梯度怎样把机器人推离险区。
