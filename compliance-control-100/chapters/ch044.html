第二篇 · 参数调节与交互任务

第 044 章：导纳控制在人机交互中的应用

上一章从"控制力矩"的角度实现了协作阻抗；本章换一条路线：机器人只有位置接口时，如何用一路力传感器把"被人推着走"的感觉算出来，手感轻重由虚拟质量 Md 和虚拟阻尼 Dd 两个数字决定。

  • 主题：导纳控制 / 手引导（hand guiding）与物理交互
  • 关键公式：Mdẍ + Ddẋ = Fh，稳态速度 vss = Fh/Dd
  • 预计学时：50 分钟
  • 前置章节：第 043 章（阻抗控制在人机协作中的应用）

学习目标

  • 理解导纳控制用于人机交互的适用条件：机器人是位置接口 + 外力由力传感器测量。
  • 掌握"手感"参数的定量映射：Md 决定反应快慢（时间常数 Md/Dd），Dd 决定稳态漂移速度（vss = F/D）。
  • 会设计三件套：死区与滞回（防抖动）、偏置自动更新（防漂移）、速度与位移限幅（保安全）。
  • 能分析力传感器噪声与偏置如何经导纳积分进入位置，理解为什么"轻快的设置"必然更敏感。
  • 能写出完整的导纳手引导循环，并解释每行为什么这样写。

背景与动机

大量协作机器人（cobot）出厂时只开放位置/速度接口：你只能告诉它"每毫秒走到哪里"，而不能直接指定力矩。人机交互最典型的功能，人手抓着机械臂拖动示教（hand guiding），在纯位置接口下怎么实现？答案是导纳控制（admittance control）：用力传感器测量人施加的力，把它代入一个虚拟的"质量-阻尼"模型，算出机器人应该移动的速度，再把位置指令下发给位置环。

这条路线的魅力在于参数有直观的物理类比：你可以把机器人调成"推一辆装了阻尼的 8 kg 小车"的手感，轻轻推走得慢，用力推得快，松手就停。它的麻烦也同样明确：手感越轻快，传感器噪声和偏置被放大得越厉害，机器人会"自己发抖""自己漂移"。本章就是围绕这个核心矛盾展开设计与防护。

核心原理

1. 导纳模型：从力到运动的映射

导纳控制的本质是规定"机器人末端对外力的运动响应"：

Mdẍ + Ddẋ = Fh，拉氏域导纳 Y(s) = 1/(Mds + Dd) Md：虚拟质量（kg）；Dd：虚拟阻尼（N·s/m）；Fh：人施加的交互力（N）

它和一阶惯性环节 v(s) = F/(Mds + Dd) 完全同形，所以"手感"可以读出两个数：稳态速度 vss = F/Dd（推多快），时间常数 τ = Md/Dd（推起来要多久、松手多久停）。取 Md = 8 kg、Dd = 400 N·s/m：10 N 的推力对应 25 mm/s 的稳态速度，τ = 20 ms，手感接近"推一辆润滑良好的小车"。工程直觉：导纳控制调的是"机器人对外力的反应快慢与漂移速度"，就像给机械臂装不同的轮子和刹车。

2. 为什么 Md 和 Dd 要对调着看

两个参数的效应可以分开看：

  • Dd 主要定"速度尺度"：vss = F/Dd。Dd = 200 时 10 N 推 50 mm/s（轻快），Dd = 800 时只有 12.5 mm/s（沉稳）。
  • Md 主要定"起步的惰性"：Md 越大，加速到稳态越慢、松手后滑行越长；Md = 20 kg 时推起来有明显的"惯性感"，急停时还会前冲几毫米。
  • 噪声敏感度由 Dd 主导：力噪声 σF 引起的速度噪声约 σF/Dd。σF = 0.2 N、Dd = 200 时速度噪声 1 mm/s 左右，肉眼可见的微抖；Dd = 400 就基本安静。

所以调参顺序是：先按"推多快"定 Dd，再按"希望多灵敏/多稳"微调；最后按时间常数 τ 反推 Md = τ·Dd。推荐起步组合：Md ∈ [5, 15] kg、Dd ∈ [300, 600] N·s/m。

3. 三个必装的安全阀

纯净的导纳模型在真实交互里必然出问题，需要三个保护：

  1. 死区与滞回：人手静止搭在把手上时，传感器噪声（约 ±0.2 N）会被积分成持续微动。装 ±1.5 N 死区：|F| 小于阈值不产生速度。再配 0.5 N 滞回（进入死区 1.5 N、退出 2.0 N），防止力在阈值附近时速度断续"咔哒"。
  2. 偏置自动更新（bias 更新）：传感器零点漂移或工具重力补偿残差 1 N，在 Dd = 400 下就是 2.5 mm/s 的持续漂移，15 cm/min，几分钟就撞限位。策略：当机器人速度很低且力读数在死区内持续 0.5 s，把当前读数缓慢归零（时间常数 5–10 s）。
  3. 速度与位移限幅：v ≤ 0.25 m/s（协作安全速度），并且对每个控制周期积分出来的位置增量限幅；再叠加第 043 章的距离/力双通道缩放。

4. 与阻抗路线（第 043 章）的分工

同一个协作任务，两条路线的差异是结构性的：

维度阻抗路线（第 043 章）导纳路线（本章）
机器人接口关节力矩接口（力矩控制）位置接口（内环位置控制）
传感需求关节力矩/电流即可必须有力传感器
接触刚度上限高（直接力矩闭环）受内环带宽与时延限制
手感调节调 Kd、Dd（软硬）调 Md、Dd（轻快/沉稳）
典型用途有力控接口的新一代协作臂位置接口 cobot 的拖动示教

选择原则一句话：有力矩接口就用阻抗，只有位置接口就用导纳；若两者都有，看任务，接触刚度高（如精密装配）用阻抗更稳，以移动/示教为主（如拖动示教）用导纳更顺。

实现思路与设计

一个可用的手引导循环按如下顺序组织（控制周期 1 ms）：

  1. 读六维力并投影：按工具坐标系把力/力矩分解为需要的交互轴（默认 X-Y 平移 + Z 旋转）。
  2. 死区+滞回：对每个轴独立判断（平移 ±1.5 N，旋转 ±0.4 N·m）。
  3. bias 更新：静止+死区内持续 0.5 s 开始慢速归零（时间常数 8 s），运动则立即冻结更新。
  4. 导纳积分：把 Mdẍ + Ddẋ = F 离散化（半隐式欧拉）成速度→位置增量。
  5. 限幅：速度 0.25 m/s、单周期位移 ≤ 0.25 mm（等价于 0.25 m/s）、工作空间软限位收敛。
  6. 下发位置指令：注意导纳控制器输出的应是"相对当前位置的增量"，输出绝对位置会与内环位置环打架。
设计决策：为什么导纳输出用"增量"？"绝对位置"会出什么问题？

机器人位置内环本身就在跟踪指令；如果导纳算出的是绝对位置，而内环存在十几毫秒的跟随滞后和稳态误差，两个积分器会互相"较劲"，表现为松手后缓慢蠕动。输出增量并以"上一次实际位置"为基准则天然自洽：人在推，增量推动内环；人不推，增量为零。这也是第 029 章拖动示教的做法。

关键代码与解读

片段 1：单轴导纳通道，死区、偏置、限幅三件套

import numpy as np

class AdmittanceAxis:
    """单自由度手引导导纳通道（如工具 X 轴）。"""
    def __init__(self, m_d=8.0, d_d=400.0, deadband=1.5, dt=1e-3):
        self.m_d, self.d_d, self.dt = m_d, d_d, dt
        self.deadband = deadband
        self.bias = 0.0            # 力零点偏置估计（慢速更新）
        self.v = 0.0               # 导纳积分状态：交互速度
        self.v_max = 0.25          # 协作安全速度上限
        self.still_time = 0.0      # “静止在死区内”的持续计时

    def step(self, f_meas):
        f = f_meas - self.bias
        # 死区内的力不产生运动：噪声约 ±0.2 N，1.5 N 死区有 7 倍裕度
        if abs(f) < self.deadband:
            f = 0.0
            self.still_time += self.dt
        else:
            self.still_time = 0.0
        # bias 更新：仅当持续静止时慢速归零(时间常数 8 s)，
        # 运动中更新会把人的真实推力“学”掉，手感凭空变重
        if self.still_time > 0.5:
            self.bias += (f_meas - self.bias) * self.dt / 8.0
        # 导纳方程离散：M dv + D v = F 的半隐式欧拉
        a = (f - self.d_d * self.v) / self.m_d
        self.v += a * self.dt
        self.v = float(np.clip(self.v, -self.v_max, self.v_max))
        return self.v * self.dt        # 返回本周期位移增量，交给位置内环

解读：（1）死区把 f 直接置零，"减去死区"的方案被有意弃用：把 1.5 N 当作硬阈值会让 1.4 N 的持续手推力完全不产生运动，操作者觉得"推不动"；若改成减死区，又要额外处理符号。工程上更常用的是"死区+滞回"（见片段 3），这里先用最简单版本建立结构。（2）bias 更新的门控条件是关键：只在静止时更新，且用 8 s 慢速平均。快速更新会把弯道里的持续手推力当成偏置抹掉，机器人会突然"加速逃跑"。（3）返回值是"速度×周期"的增量：下游位置内环只需要做 x_cmd += delta，导纳与内环的职责边界清晰，不存在双积分器打架。

片段 2：同推力下两种手感的对比实验

def feel_test(m_d, d_d, f_push=10.0, t_end=1.0, dt=1e-3):
    """恒力推 1 秒：记录稳态速度与 90% 上升时间，量化“手感”。"""
    ax = AdmittanceAxis(m_d=m_d, d_d=d_d, deadband=0.0, dt=dt)
    v_hist, t = [], 0.0
    for k in range(int(t_end / dt)):
        ax.step(f_push)                 # 恒力 10 N
        v_hist.append(ax.v)
    v_ss = v_hist[-1]
    t90 = next(t for t, v in zip(np.arange(len(v_hist)) * dt, v_hist)
               if v > 0.9 * v_ss) if v_ss > 0 else float('nan')
    print(f"M_d={m_d:5.1f} kg  D_d={d_d:5.0f} Ns/m  "
          f"v_ss={v_ss*1000:6.1f} mm/s  t90={t90*1000:5.1f} ms  "
          f"tau=M/D={m_d/d_d*1000:4.1f} ms")

feel_test(8.0, 400.0)     # 基准手感：25 mm/s, tau=20 ms
feel_test(3.0, 150.0)     # 轻快型：67 mm/s — 快，但噪声也放大 2.7 倍
feel_test(20.0, 800.0)    # 沉稳型：12.5 mm/s — 稳，但推起来“拖泥带水”
feel_test(20.0, 150.0)    # 危险组合：D 小起步快，松手后还会前冲（M 大）

解读：四组参数演示了"手感设计"的两种误区。轻快型（M 小 D 小）推着爽，但速度噪声 σF/D 比基准大 2.7 倍，传感器的 0.2 N 噪声会变成约 1.3 mm/s 的可感抖动。沉稳型安静，但 τ = M/D = 25 ms 之外还有"松手滑行"：M = 20 kg 意味着撤力后动量还要把它推出去一段。危险组合最值得警惕：M 大 D 小意味着"起步快、停不下"，松手后前冲距离约 M v/D，代入 v = 67 mm/s 得 8.9 mm，在精密对位场景里这是事故级别的偏差。所以本章建议把 τ = M/D 控制在 15–30 ms，D 不低于 300。

片段 3：带滞回的死区判决

class HysteresisGate:
    """死区+滞回：进入阈值 1.5 N，退出阈值 2.0 N。
    避免“力在阈值附近时速度断续”造成的咔哒感与机械冲击。"""
    def __init__(self, enter=1.5, exit_=2.0):
        self.enter, self.exit_ = enter, exit_
        self.active = False            # 当前是否已“过阈值”

    def filter(self, f):
        a = abs(f)
        if not self.active:
            if a >= self.exit_:
                # 退出死区：力升过退出阈值(2.0 N)才激活；输出扣掉死区宽度以减小跳变
                self.active = True
                return f - np.sign(f) * self.enter
            return 0.0
        else:
            if a <= self.enter:
                # 进入死区：力回落到 1.5 N 以内才释放，防止反复通断
                self.active = False
                return 0.0
            # 已激活状态：始终扣除死区宽度，输出沿 0 连续
            return f - np.sign(f) * self.enter

解读：滞回的核心作用是让"通/断"两个状态各有独立的边界：力要升过 2.0 N 才激活，激活后要回落到 1.5 N 才断开，1.5–2.0 N 区间里保持当前状态。这样一来，人手在阈值附近抖动时输出不会反复跳变。另一个细节是"扣除死区宽度"的处理：激活瞬间输出从 0 变成 2.0−1.5 = 0.5 N 的小台阶，之后再随手劲线性增长，跳变已经被压得很轻。如果直接"过阈值就输出原始力"，激活的瞬间速度会从 0 跳到 F/D = 5 mm/s，手上会有明显的"咯噔"。这段代码与导纳积分之间是纯记忆环节，不引入相位滞后，可以放心放在 1 ms 回路里。

常见坑

  • 没有 bias 更新导致持续漂移：残余偏置 1 N、Dd = 400 时漂移 2.5 mm/s，三分钟就是 45 cm。症状是"没人碰它，机器人慢慢往一个方向走"。修复：静止+死区内慢速归零，运动中冻结。
  • 死区过小：把死区设成 0.3 N 追求"灵敏"，结果静态时机器人以 0.5 mm/s 的微速持续蠕动（噪声整流效应）。修复：死区取噪声峰值的 5–10 倍，本期推荐 1.5 N。
  • 忘记重力补偿：工具重力在力传感器上的分量约 20–40 N，方向随姿态变化。若不做重力旋转补偿，机器人抬手时手感"突然变沉"。修复：先做工具参数辨识再启用导纳（第 092 章）。
  • 导纳输出绝对位置：与位置内环形成双积分器，松手后蠕动、指令与实测差距收敛慢。修复：输出增量、以实测位置为基准。
  • 速度限幅只做在最后：限幅放在积分之后，内部状态 v 其实已经超限，松手瞬间会"按内部超速"继续走。修复：对状态本身限幅（片段 1 已示范）。

练习与思考

  1. 推导恒力 F 下的稳态速度与时间常数：从 Mdẍ + Ddẋ = F 出发，令加速度为零得 vss = F/Dd，再验证一阶环节时间常数是 Md/Dd。★
    提示
    把方程写成 τ ẋ + x = ... 的标准一阶形式，或直接解微分方程 v(t) = vss(1−e−t/τ)，与 τ = M/D 对照。
  2. 设计实验：用片段 2 的 feel_test 扫描 Md ∈ {4, 8, 16}、Dd ∈ {200, 400, 800}，找出手感"既不抖(速度噪声小于 0.3 mm/s)又够快(vss 大于 20 mm/s)"的可行组合，并解释为什么这张表只有一条窄带可行。★★
    提示
    速度噪声 σF/D 只取决于 D，快慢只取决于 F/D，两者都被 D 锁死，所以"安静"和"轻快"在导纳路线里是对立的；只能在死区、滤波和 M 上找平衡。
  3. 偏置 0.8 N 未被更新，Dd = 300 N·s/m，机器人从工作空间中心出发。计算 30 s 后的漂移距离；若 bias 更新的时间常数为 8 s，估算漂移能被压到什么量级。★★
    提示
    漂移速度 2.7 mm/s，30 s 约 8 cm。bias 更新是慢速一阶系统，稳态残余偏置趋近零，但更新期间仍会漂移约 τbias·v ≈ 8 s×2.7 mm/s ≈ 2 cm；所以初始标定比事后更新更重要。
  4. 把死区升级为"力-速度曲线塑形"：小力段用较小等效阻尼（轻快），大力段用较大等效阻尼（稳）。设计 D(|F|) 的分段解析式（保证连续），并说明它为什么不是变参数振荡源。★★★
    提示
    例如 D(|F|) = D0 + α|F|，输出 v = F/D(|F|) 是 F 的单调连续函数；D 只依赖于已滤波的力幅值，变化率有界，不构成参数自激。注意 D 分段处导数连续，避免"手感台阶"。
  5. 同一个"扶着机器人把零件放进卡槽"的任务，分别用第 043 章的阻抗路线和本章导纳路线实现，各写一段 5 行伪代码，指出哪种在"卡槽刚性接触瞬间"更不容易抖，并给出理由。★★
    提示
    刚性接触瞬间等效刚度骤升，导纳路线依赖力滤波+位置内环，时延更长、更易抖；力矩级阻抗享受更高的接触刚度上限。这是"接口决定上限"的典型例子。

小结

  • 导纳控制面向"位置接口 + 力传感器"的机器人：外力经虚拟质量-阻尼模型 Mdẍ + Ddẋ = Fh 变成运动指令，是拖动示教与手引导的标准实现。
  • 手感由两个数决定：vss = F/Dd（推多快）、τ = Md/Dd（多灵敏）；噪声敏感度 σF/Dd 与轻快感直接冲突，需要死区与滤波调解。
  • 三件套必装：死区+滞回、静止门控的 bias 更新、状态级速度限幅。
  • 输出增量、以实测位置为基准，避免与位置内环形成双积分器对打的蠕动。
  • 与阻抗路线的选择原则：有可靠的力控接口用阻抗（接触刚度上限高），只有位置接口用导纳（实现简洁、手感直观）。
  • 下一章把交互从"人-机器人"扩展到"人-主手-从手"：遥操作场景中，通信时延会成为稳定性的头号敌人，我们先用基于阻抗控制的第一种方案建立对时延与无源性的直觉。
