第一篇 · 基础、建模与稳定性

第 010 章：任务空间与关节空间阻抗转换

同一只刚度椭球，站在关节侧看和站在任务侧看是两组数。本章把两侧的换算写成正规的共轭变换，讲清"锁定哪一侧、在线更新哪一侧"的取舍，以及奇异与零空间在换算里的角色。

  • 主题：阻抗控制 / 空间换算与雅可比对偶
  • 关键公式：Kq = JTKxJ，Kx = J−TKqJ−1
  • 预计学时：55 分钟
  • 前置章节：第 009 章

学习目标

  • 掌握雅可比对偶关系：速度侧 ẋ = Jq̇、力侧 τ = JTF，以及它们共同的虚功来源。
  • 会推导并双向使用刚度换算 Kq = JTKxJ 与 Kx = J−TKqJ−1，并验证往返精确一致。
  • 理解共轭变换保持对称与正定、但不保持特征值，这是"关节侧设计"与"任务侧设计"差异的数学根源。
  • 能说清"在线换算 = 笛卡尔实现"的等价性：τ = JT(Kxe + Dxė) 就是每拍做一次 Kq(t) 的转换。
  • 会用零空间与奇异分析读懂：为什么拉回映射可能奇异、为什么"末端不动的关节运动"是冗余机器人的宝贵资源。

背景与动机

第 008 章在任务空间设计椭球，第 009 章在关节空间装弹簧。真实项目几乎总在两边的夹缝里做取舍：任务书用笛卡尔语言写（"法向 15 N、横向让位"），驱动器只接受关节量；参数在关节侧固定下来后，末端手感随姿态漂移，用户会投诉；参数在任务侧在线换算，又多出一堆实现问题。

本章把转换写成一套干净的工具：先证明双向公式是精确可逆的共轭变换（想换就换、来回一致），再指出其中的陷阱（特征值不守恒、速度项还有 J̇ 修正、奇异位形下单侧无定义）；最后给出工程决策表，什么时候锁定关节侧参数、什么时候每拍在线换算、什么时候两边都要。这是基础篇的收官章：坐标空间的所有换算工具到此集齐，下一站转入建模、补偿与稳定性。

核心原理

1. 对偶关系：速度用 J，力用 JT

任务空间与关节空间之间只有一条运动学纽带：ẋ = J(q)q̇，其中 ẋ（m/s）为末端广义速度，q̇（rad/s）为关节速度，J（m/rad）为雅可比。力的方向反过来：

ẋ = Jq̇（速度正映射） ， τ = JTF（力逆映射） F：任务空间广义力（N / N·m）；τ：关节力矩（N·m）

第二条由虚功原理一以贯之：τTδq = FTδx，代入 δx = Jδq 对任意 δq 成立即得。两条关系的"互补"结构贯穿全章：运动用 J 搬，力用 JT 搬，刚度（力的位移导数）会同时沾上两个因子，这就是下一节换算公式里出现两个 J 的原因。

2. 刚度换算：一对共轭变换

设任务侧刚度为 Kx：F = Kxδx；关节侧刚度为 Kq：τ = Kqδq。把两边用对偶关系串起来：δx = Jδq → τ = JTF = JTKxδx = JTKxJ·δq，立即读出

任务 → 关节： Kq = JT·Kx·J dim: (m/rad)T × (N/m) × (m/rad) = N·m/rad，量纲自动对上

反方向把 J 换成 J−1：δq = J−1δx → F = J−Tτ = J−TKqJ−1δx，得到

关节 → 任务： Kx = J−T·Kq·J−1（要求 J 可逆） 阻尼、惯量的换算公式形状相同（Dq=JTDxJ，Mq=JTMxJ）

这类变换（STA S）在数学上叫共轭变换（congruence）。两条性质每天都要用到：对称性与正定性保持（若 Kx 正定、J 满列秩，则 Kq 正定；反之亦然），以及特征值不保持，特征值是"方向+数值"的属性，换空间后椭球的主轴与长短都要重新算。第 008 章的 R⊕R 旋转共轭是个例外（旋转保持特征值），因为旋转不改变"哪些方向多硬"，只改方向标签；而 J 的共轭同时改变标签和度量，同一只椭球在关节坐标里可能变得又长又歪。这也解释了第 009 章的现象：关节侧的对角弹簧到了任务侧必然各向异性。

往返一致是严格的：Kq → Kx → Kq 与 Kx → Kq → Kx 在 J 可逆时都是恒等映射（把两个公式互相代入即可验证）。工程直觉：换算的本质是关于同一件事的两本账，并不丢失信息；麻烦不在数学，在于 J 本身随姿态变，账本一旦开始变，就要决定"锁定哪个数字、让谁跟着变"。

3. 锁定哪一侧：三种工程策略

策略做法效果适用
锁定关节侧Kq 常数（第 009 章）末端手感随姿态漂移关节任务、奇异兜底、算力极紧
锁定任务侧（在线换算）每拍 Kq(t)=JTKxJ，或直接 τ=JT(Kxe+Dxė)末端手感恒定；需要 FK 与 J接触任务、多姿态作业（第 008 章）
混合任务刚度在线换算 + 零空间姿态刚度两者兼得冗余机器人（第 073 章展开）

这里有一个漂亮的统一结论：第 008 章的笛卡尔实现，本质就是"每拍在线做一次共轭换算"。把 τ = JT(Kxe + Dxė) 改写成关节误差形式：e ≈ Jδq（小误差），则 τ = (JTKxJ)δq + (JTDxJ)δq̇，方括号就是每一拍的 Kq(t)、Dq(t)。所以"任务空间控制"与"关节空间控制在每一拍重新换算参数"是同一件事的两种记账方式；差别只在误差的定义点（任务误差还是关节误差）与 J 的更新频率。

更新频率的判据来自 J 的变化速度 J̇q̇：快任务（杆件角速度大）里 J 在 1 ms 内的变化不可忽略，换算必须每拍做；慢任务里每 10–50 拍更新一次也够。还有一个容易被忽略的修正项：把任务阻抗方程完整投影到关节空间会出现一个形如 JTMxJ̇q̇ 的"速度修正项"（运动学科氏项）。低速接触任务通常忽略它；高速运动补偿它，或者干脆留在任务空间做控制，这条是"什么时候别换算"的答案。

4. 奇异与零空间：换算的两处边界

拉回映射 Kq = JTKxJ 永远有定义（J 转置无需求逆），但 J 不满列秩时 Kq 会奇异：存在非零关节方向 v 使 Jv ≈ 0，机器人"自娱自乐"地动关节，末端几乎不动。任务侧刚度对该方向"看不见"（Kqv ≈ 0），这就是运动学零空间。奇异位形附近（第 009 章扫描过），零空间方向与"极度敏感方向"同时出现：前者 Jv≈0，后者 Jv 爆炸式大（微小关节动作造成大末端位移），Kq 的特征值谱被拉到两端。

推回映射 Kx = J−TKqJ−1 在奇异处无定义（J−1 不存在），这正是"关节参数在奇异位形无法解释末端行为"的数学表述。工程上两个出口：其一，奇异区改用任务空间控制（τ=JT(Kxe+…)，只需 JT），其代价是某些方向"力不加载关节"；其二，利用零空间做正事，给零空间单独加姿态刚度：Kq = JTKxJ + α(I − J+J)（J+ 为伪逆），第二项只作用在末端不动的方向上：机器人可以"自己捋顺胳膊"（保持一个舒适姿态）而不影响末端受力。冗余机器人的姿态管理、奇异回避都建立在这条公式上，第 073 章会专门展开。

实现思路与设计

把换算接进控制器的三种典型架构，按任务特性选择：

  1. 架构 A（锁定关节侧）：像第 009 章那样直接输出 τ=Kq(qd−q)−Dqq̇；参数用一次离线换算得到（Kq=JTKxJ 在标称构型处算一次）。实现最省，手感随姿态漂移。
  2. 架构 B（锁定任务侧，在线换算）：主循环每拍求 FK→J，然后两选一，直接把任务误差经 JTKx 变成力矩（第 008 章写法），或显式算出 Kq(t) 再乘关节误差。两者在中小误差下一致；不要混用两种误差定义（下一页详述）。
  3. 架构 C（混合）：在 B 的基础上叠加零空间项 α(I−J+J)q̇ 或姿态弹簧，用于冗余手臂的关节姿态保持与奇异回避。
设计决策：为什么"误差定义"必须全链统一？

任务误差 e = pd−p 与关节误差 δq = qd−q 只在一阶意义上互换（e ≈ Jδq）；二阶残差来自两边的"直线差 vs 弧线差"。如果你的控制器一半用 JTKxe、一半用 Kqδq，误差大的时候两条路径给出的力矩不同（5 cm 级偏差下可差 20% 以上，见片段 2），表现为"位置修正越到后段越拧巴"。工程原则：要么全程任务侧（e 由 FK 算、力由 JT 回）要么全程关节侧（δq 由关节角算、力矩由 Kq 出）；混用时只在误差小于 1 mm / 0.5° 的区间近似成立。代码片段 2 用一个 5 cm 的大误差演示这个差异。

数值成本可以放心：对一个 6 轴机器人，JTKxJ 的乘法是 6×6×6 的两步矩阵乘积，1 kHz 下占用微秒级时间，现代控制柜完全可以承受。"算力不够才锁关节侧"在 2020 年代已经很少成立，真正的理由通常是FK/J 的精度与标定，速度早已不是瓶颈。

关键代码与解读

片段 1：双向换算器与往返验证

import numpy as np

def k_task_to_joint(J, K_x):
    """任务空间刚度 → 关节空间：K_q = Jᵀ K_x J（随时可算，无需求逆）。"""
    return J.T @ K_x @ J

def k_joint_to_task(J, K_q):
    """关节空间刚度 → 任务空间：K_x = J⁻ᵀ K_q J⁻¹（要求 J 可逆）。"""
    J_inv = np.linalg.inv(J)
    return J_inv.T @ K_q @ J_inv

# 第 005 章的 2 连杆构型：任务侧要"x 软 y 硬"的椭圆刚度
L1, L2 = 0.35, 0.30
q1, q2 = 0.40, 0.50
J = np.array([[-L1*np.sin(q1) - L2*np.sin(q1+q2), -L2*np.sin(q1+q2)],
              [ L1*np.cos(q1) + L2*np.cos(q1+q2),  L2*np.cos(q1+q2)]])
K_x = np.diag([400.0, 1200.0])          # N/m：一条软轴、一条硬轴
K_q = k_task_to_joint(J, K_x)           # 换算到关节侧（N·m/rad）
K_x_back = k_joint_to_task(J, K_q)      # 往返验证
np.set_printoptions(precision=2, suppress=True)
print("K_q =\n", K_q)
print("往返误差 max =", np.abs(K_x_back - K_x).max(), "（应为数值零）")
print("K_q 特征值 =", np.linalg.eigvalsh(K_q),
      "← 与 K_x 的 400/1200 不同，共轭变换不保特征值")

解读：运行输出里两个数字最关键。往返误差是 10−12 量级，证明换算严格可逆，参数迁移（关节侧调好的值换到任务侧分析、或反之）不会丢信息，这给工程上"在一侧调试、在另一侧解释"提供了合法依据。K_q 的特征值不再是 400/1200：本例输出约 2.8 与 427，比任务侧更分散，这提醒你共轭变换与旋转共轭的本质区别。注意 K_q 的非对角元通常非零（输出矩阵里能看到）：关节弹簧互相"串"起来了，物理含义是"为了在末端实现各向异性，两个关节必须协调出力"。另外，k_joint_to_task 里用 inv 是教学写法，生产代码建议 np.linalg.solve 两次解方程（J A = K_q 再解），并且先检查 cond(J)。

片段 2：两种控制写法的等价边界，小误差一致、大误差分道

# 写法 A（任务侧）：τ = Jᵀ·K_x·e，e = p_d − p 由 FK 直接给出
# 写法 B（关节侧）：τ = K_q·δq，δq = q_d − q，q_d 经 IK 解出（真实非线性路径）
def torque_A(J, K_x, e):
    return J.T @ (K_x @ e)

def torque_B(J, K_x, q_d, q):
    return (J.T @ K_x @ J) @ (q_d - q)

def ik(x, seed):                        # 解析 IK，与第 005 章同款
    px, py = x
    c2 = (px*px + py*py - L1*L1 - L2*L2) / (2.0*L1*L2)
    q2 = np.arccos(np.clip(c2, -1.0, 1.0))
    if seed[1] < 0.0:
        q2 = -q2
    q1 = np.arctan2(py, px) - np.arctan2(L2*np.sin(q2), L1 + L2*np.cos(q2))
    return np.array([q1, q2])

q = np.array([q1, q2])
p = np.array([L1*np.cos(q1) + L2*np.cos(q1+q2),
              L1*np.sin(q1) + L2*np.sin(q1+q2)])
for tag, e in (("小误差 4mm", np.array([0.004, -0.002])),
               ("大误差 5cm", np.array([0.050, -0.030]))):
    q_d = ik(p + e, q)                  # 期望位姿经 IK 变成关节目标
    tA, tB = torque_A(J, K_x, e), torque_B(J, K_x, q_d, q)
    diff = np.abs(tA - tB).max()
    print(f"{tag}: A={np.round(tA,3)}  B={np.round(tB,3)}  "
          f"最大差={diff:.4f} N·m  相对={diff/max(np.abs(tA).max(),1e-9)*100:.2f}%")

解读：小误差 4 mm 行两种写法的差异约 0.03 N·m（1.4%），5 cm 的大误差行拉大到约 5.6 N·m（22%），正是上一节"误差定义必须统一"的数值证据。为什么会分道：写法 B 的 δq 是期望位姿经 IK 解出的真实关节路径差，写法 A 的 e 是末端直线差，二者只在一阶意义上互换，二阶残差随误差增大而放大；误差越大、构型越远离线性化点，偏差越显著。工程结论：选择一种写法写到底；若必须混用（例如任务侧给期望、关节侧给限幅），把混用区间限制在毫米级。参数传播的意义：片段同时演示了"在线换算"的最简实现，torque_B 里每次调用都重算 Kq，没有任何状态；如果你把 K_q 提出来缓存并每 50 拍更新一次，就得到"准静态换算"，误差由 J 的变化率决定，快任务请回到每拍重算。

片段 3：奇异位形处的零空间方向，末端不动的关节运动

# 完全伸直位形（精确奇异，det J = 0），拉回映射会出现零特征方向
q_s = np.array([0.30, 0.0])
q1, q2 = q_s
J_s = np.array([[-L1*np.sin(q1) - L2*np.sin(q1+q2), -L2*np.sin(q1+q2)],
                [ L1*np.cos(q1) + L2*np.cos(q1+q2),  L2*np.cos(q1+q2)]])
K_q_s = k_task_to_joint(J_s, K_x)       # 拉回：永远有定义
ev, V = np.linalg.eigh(K_q_s)           # 对称矩阵用 eigh（升序特征值）
v_null = V[:, 0]                        # 最小特征值对应的关节方向
print("K_q 特征值 =", np.round(ev, 3), " ← 最小者为数值零")
print("沿该方向末端速度 ‖J·v‖ =", np.linalg.norm(J_s @ v_null))
print("该方向关节位移范数 ‖v‖ =", np.linalg.norm(v_null))
# 伪逆方案：给零空间补一个姿态刚度 alpha（冗余/奇异机器人常用）
alpha = 2.0
P_null = np.eye(2) - np.linalg.pinv(J_s) @ J_s   # 零空间投影算子
K_q_aug = K_q_s + alpha * P_null
print("补姿态刚度后特征值 =", np.round(np.linalg.eigvalsh(K_q_aug), 3))

解读：输出验证了三件事的闭环。第一，Kq 的最小特征值为数值零（精确奇异位形），对应的特征向量 vnull 满足 ‖J·v‖≈0，关节在动、末端不动，这就是零空间方向的物理内容。第二，P_null = I − J⁺J 是"投影到零空间"的算子（对满秩方阵 J 它是零矩阵，此时姿态刚度自动消失；本例在精确奇异处它退化为秩 1 投影）；把 α=2.0 的姿态刚度加进 Kq 后，零空间特征值从 0 抬到 2.0，其余特征值 579.2 不变，末端受力特性不受影响，机器人只是更"愿意"保持某个关节姿态。注意方阵的零空间只在精确奇异位形存在，真实的冗余机器人（关节数多于任务维数）在整个工作空间都保有这个方向，这就是零空间姿态管理的前提。第三，整个实验里我们只用了 pinv，没有对 J−1 硬求逆，这就是"能在奇异区工作"的实现姿势：拉回映射 + 伪逆零空间管理，永远绕开封死的推回映射。真机上把 α 的项替换成对 (q−q_nominal) 的弹簧，就得到"自动归位到舒适姿态"的协作机器人行为。

常见坑

  • 以为换算保持特征值：拿关节侧算出的 Kq 特征值与任务侧目标 Kx 直接比较，得出"换算把柔软度弄丢了"的错误结论。修复：共轭变换只保证对称与正定；软硬要回到同一空间再比。
  • 误差定义混用：半程任务误差、半程关节误差，或 J 用了与 FK 不一致的姿态。症状：收敛尾段力矩"拧巴"、误差随大偏差非线性放大。修复：全链统一，或用片段 2 在最大工作误差处做一次残差体检。
  • 快任务里用准静态换算：J 每 50 拍更新一次，高速摆臂时任务刚度实际在"飘"。修复：按 ‖J̇q̇‖ 与任务刚度容差定更新率，拿不准就每拍换算（成本很低）。
  • 奇异点附近对 J 硬求逆：inv(J) 抛异常或给出数值垃圾，Kx 凭空出现 107 级刚度。修复：推回映射前查条件数或 σmin，越界即切策略（阻尼最小二乘、任务侧控制或降刚度）。
  • 忘记零空间的管理成本：叠了姿态刚度却没限幅，冗余自运动在关节限位处"顶死"。修复：零空间项自身要限幅、要在关节限位附近软化，并验证不侵入任务方向（用 P_null 投影检查）。

练习与思考

  1. 用虚功原理推导 τ=JTF，然后延着 δx=Jδq 把 F=Kxδx 与 τ=Kqδq 串起来，得到 Kq=JTKxJ。★
    提示
    τ = JTF = JTKxδx = JTKxJδq，对任意 δq 成立即得。
  2. 用片段 1 的 J 计算往返：先把 Kx=diag(400,1200) 转成 Kq，再转回任务侧，验证往返误差为零；然后把 Kx 换成有耦合项 [[400,100],[100,1200]] 重做，说明对称正定是否保持。★★
    提示
    共轭变换对任何对称 A 保对称；J 可逆时正定性等价（vTJTAJv=(Jv)TA(Jv)>0，v≠0）。耦合项在两侧都会"转译"成相应耦合，不会消失。
  3. 修改片段 2：把任务误差固定为 1 mm，遍历构型 q2 ∈ [0.1, 1.4]，记录 A、B 两种写法的相对差随构型的曲线。哪种构型差异最大？与 J 的条件数关联起来。★★
    提示
    一阶近似残差 ∝ ‖e‖²·(J 的二阶导数)/(刚度尺度)，条件数差的构型（接近伸直）差异更大；把 cond(J) 与相对差画在同一张图上能看到正相关。
  4. 推导：把任务阻抗方程 Mxẍ+Dxẋ+Kxe=F 完整投影到关节空间，证明除 JTMxJ、JTDxJ、JTKxJ 三块外，还多出 JTMxJ̇q̇ 一项；给出忽略它的频率条件（用 J̇ 与系统带宽的关系表达）。★★★
    提示
    ẍ = Jq̈ + J̇q̇；投影后 Mqq̈ + (Dq)q̇ + Kqe + JTMxJ̇q̇ = JTF。当 J̇ 的特征尺度 × 关节速度远小于 J×加速度尺度（低速任务）时该修正占比重极小。
  5. 设计冗余 3 自由度平面臂（可自行加一根连杆）的"任务刚度 + 姿态刚度"组合：写出 Kq=JTKxJ+αPnull 中 α 的单位与量级选择，并说明如何验证"末端刚度不变"。★★★
    提示
    α 的单位是 N·m/rad（关节弹簧单位）；验证方法：随机给零空间方向扰动，计算末端位移 ‖Jδq‖ 应≈0；再算 J⁻ᵀKqJ⁻¹（非奇异处）应与 Kx 一致。

小结

  • 雅可比对偶：运动 ẋ=Jq̇、力 τ=JTF，共同来源是虚功；阻抗换算因此带上两个 J。
  • 双向公式：Kq=JTKxJ 与 Kx=J−TKqJ−1，严格可逆；共轭变换保对称与正定、不保特征值。阻尼、惯量同形换算。
  • 三种策略：锁定关节侧（省、飘）、锁定任务侧（准、需 FK/J）、混合（加零空间姿态项）；在线换算与笛卡尔实现是同一件事的两种记账。
  • 两处边界：拉回映射遇奇异出零空间（末端不动的关节运动，可用作姿态管理）；推回映射在奇异处无定义。误差定义必须全链统一。
  • 基础篇到此收官：坐标、接口、对偶、换算的工具箱已经齐备。第 011 章从"重力补偿下的阻抗控制"开始，把之前所有推导里被当作"已处理"的 g(q) 与工具重力摊开算清楚。
