第三篇 · 感知、辨识与智能调参

第 049 章：基于观测器的外力估计

没有力传感器也能"摸到"外力：利用机器人自己的动力学模型与电机力矩读数，把外力矩从残差里"挤"出来。本章推导动量观测器，只需要位置和速度、完全避开加速度测量，残差就是外力的带限估计。

  • 主题：外力估计 / 动量观测器（momentum observer）
  • 关键公式：p = M(q)q̇，p̂′ = τ + Cᵀq̇ − g + r，r = Ko(p − p̂)，则 ṙ = Ko(τext − r)
  • 预计学时：55 分钟
  • 前置章节：第 048 章（导纳控制中的位置传感器噪声处理）

学习目标

  • 理解无传感器外力估计的工程动机：碰撞检测、零力示教、传感器故障冗余都依赖它。
  • 会推导动量观测器：从机器人动力学出发，说明为什么选择"广义动量"作为中间变量可以完全避开 q̈。
  • 掌握残差方程 ṙ = Ko(τext − r) 的含义：r 是一阶低通的 τext，带宽就是增益 Ko。
  • 会选 Ko（与噪声/延迟的权衡），并把关节外力矩映射成笛卡尔外力、加阈值判接触。
  • 清楚模型误差（摩擦、负载、重力）如何变成"假外力"，以及它与第 050 章扰动观测器的分工。

背景与动机

很多在役机械臂没有腕部力传感器：要么出厂就没有，要么传感器装在别处、要么为了成本被省掉。但没有力感知，就无法做碰撞检测、拖动示教、柔顺装配，整个柔顺控制的大厦似乎缺了地基。好消息是：机器人自己就是一台"力传感器"。电机电流乘以力矩常数能得到关节力矩读数，编码器提供位置与速度，只要再补上动力学模型（惯性矩阵、科氏项、重力项），就能从"执行器给出的力"与"关节实际运动"之间的不一致中反推出外力。

关键难点是数值噪声：朴素做法是解 Mq̈ = τ + JᵀF − Cq̇ − g，需要 q̈，而第 048 章刚讲过，两次差分会把噪声放大百倍。动量观测器的漂亮之处在于：它把方程改写成弹性变量"广义动量"的形式，使 q̈ 严格不出现在任何计算里。本章推导它、整定它，并看清它什么时候会骗你。

核心原理

1. 动力学回顾与"外力"的位置

刚性机械臂的标准动力学（关节空间）：

M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + τext M：惯性矩阵；C q̇：科氏/离心项；g：重力矩；τ：关节驱动力矩（可读）；τext = Jᵀ(q)Fext：外力等效关节力矩（待估）

目标是在未知 τext 的情况下估计它，且只用可测量 q、q̇、τ 和已知模型。注意两个现实约束：（1）τ 可由电流估计，但摩擦、电机惯量等未建模效应就天然混在"应当的力矩"里；（2）既然不能可靠地测 q̈，就要给方程找一个不含 q̈ 的等价形式。

2. 广义动量与观测器推导

定义广义动量 p = M(q)q̇，对时间求导并用动力学方程替换 Mq̈：

ṗ = Ṁq̇ + Mq̈ = Ṁq̇ + (τ + τext − Cq̇ − g) = τ + τext − g + (Ṁ − C)q̇

这里用到一个机器人动力学的基本性质（Ṁ − 2C 反对称性的直接推论）：(Ṁ − C)q̇ = Cᵀq̇。于是得到不含加速度的动量方程：

ṗ = τ + Cᵀ(q,q̇)q̇ − g(q) + τext 所有项都可计算或可测：右边前四项全部已知，只有 τext 未知

构造观测器：让 p̂ 跟踪 p，但把"估计的未知量" r 反馈进去；再用真实动量与估计动量之差定义 r：

p̂′ = τ + Cᵀq̇ − g + r， r = Ko(p − p̂) Ko：观测器增益（rad/s），取对角矩阵；p 用测量 q̇ 与模型 M 直接算，无需积分

两式相减可推出残差的自洽方程：

ṙ = Ko(τext − r) ⟹ r(s) = [Ko/(s + Ko)]·τext(s) r 是 τext 经过一阶低通的估计；Ko 就是那台低通的带宽

推导的每一步都值得回味：把 ṗ 的未知项"塞进"反馈 r，误差动力学自动变成一阶线性方程，r 会以带宽 Ko 逼近 τext，且全程不用 q̈。取 Ko = 30 rad/s：检测延迟约 1/Ko = 33 ms，对碰撞检测（要求 ≤ 100 ms 报警）足够，对高保真力控则偏慢。

3. 从关节力矩到笛卡尔外力

残差 r 是关节空间的等效外力矩。要用在笛卡尔柔顺任务中，需要经雅可比映射：

τext = Jᵀ(q) Fext ⟹ F̂ext = (Jᵀ)⁺ τext 方阵（6 自由度）时直接解线性方程；冗余时用最小二乘 (JJᵀ)⁻¹J τ；奇异位形放大会出问题

三个实践要点：（1）奇异位形保护，J 的最小奇异值过小时拒绝输出并报警；（2）阈值设成统计量，用 3σ（σ 为静止段残差的标准差）作阈值，不用拍脑袋的常数；（3）方向验证，碰撞检测只需要"有外力"，而柔顺控制需要方向，方向错了会把机器推向危险处，第一次上机必须用已知方向的手推验证。

4. 与第 050 章的分工（预告）

本章的 r 只把"外力"当作唯一的未知量，其余不匹配（摩擦、负载偏差、模型误差）会原样出现在残差里，看上去也像外力。第 050 章的扰动观测器（DOB）则把这些统称为"扰动"一起估计并前馈补偿掉，让内环表现得像理想模型，两者的差别是"要报告真相"还是"要修好系统"。典型组合拳：DOB 负责让残差干净，动量观测器负责把干净残差解释成外力。

实现思路与设计

上机顺序与要点（控制周期 1 ms）：

  1. 模型准备：M(q)、Cᵀq̇、g(q) 按连杆参数与负载在线计算；负载惯量若变化（换工具），先用第 051 章的 RLS 更新。
  2. 状态输入：q 用编码器；q̇ 用第 048 章的 α-β 观测器输出（观测器增益 Ko 要大于速度观测带宽，否则速度滞后会表现为"外力缓慢出现"）。
  3. 离散化：p̂(k+1) = p̂(k) + Δt(τ + Cᵀq̇ − g + r)，r = Ko(M(q)q̇ − p̂)。半隐式顺序（先更新 p̂ 再算 r）与第 001 章一致。
  4. 初值：p̂(0) = M(q₀)q̇₀，避免启动瞬间有一个大残差尖峰。
  5. 增益整定：Ko 从 20 rad/s 起试，观察静止残差 RMS，它应随 Ko 上升而上升（噪声放大），到 50 rad/s 时若提示"噪声过大"就退回。
  6. 标定与验证：静止时记录残差带（3σ），已知推力的方向试验验证符号与量级（误差应小于 10%）。
设计决策：为什么 Ko 就是低通带宽？

从 ṙ = Ko(τext−r) 直接看：输入 τext 的传递函数是 Ko/(s+Ko)。Ko = 30 表示 30 rad/s 以下的"外力变化"能跟上，30 rad/s（约 4.8 Hz）以上被压制。这个数同时是"检测速度"和"噪声带宽"的旋钮，不存在免费的午餐。

关键代码与解读

片段 1：动量观测器

import numpy as np

class MomentumObserver:
    """动量观测器：仅用 q、dq、tau 与模型项估计关节外力矩 tau_ext，
    全程不使用 q 的二次差分(这是它相对“直接解 Mq''=...”的核心优势)。"""
    def __init__(self, k_o=30.0, dt=1e-3):
        self.k_o, self.dt = k_o, dt     # k_o 单位 rad/s，即估计的带宽
        self.p_hat = None
        self.r = None

    def update(self, q, dq, M, cqqd, g, tau):
        # 广义动量：只需要惯性矩阵 M 和速度 dq，不涉及加速度
        p = M @ dq
        if self.p_hat is None:          # 初值对齐：启动不产生假残差
            self.p_hat = p.copy()
            self.r = np.zeros_like(p)
        # 半隐式欧拉：先积分观测器状态，再算残差(顺序与前几章一致)
        self.p_hat = self.p_hat + self.dt * (tau + cqqd - g + self.r)
        # r = Ko(p - p_hat)：Ko 越大跟踪越快、噪声越大；
        # 数学上 r 是 tau_ext 经过 1/(s/Ko+1) 的低通估计
        self.r = self.k_o * (p - self.p_hat)
        return self.r

解读：（1）输入清单里没有 q̈ 也没有加速度估计，这是设计目标本身，不要"顺手"把加速度项加回来。（2）cqqd 传入的是已经算好的 Cᵀq̇ 向量（矩阵 C 本身不传入），因为方程里只需要这个乘积，函数签名防止用错转置。（3）初值对齐（p̂(0) = p(0)）看起来是小事，但真机上若从零开始，起步瞬间 r 会出现 Ko·|p| 的大尖峰（可能数十 N·m），会误触发碰撞检测，这是实测中很常见的一类"幽灵警报"。

片段 2：单关节验证仿真（已知外力矩脉冲）

# 单关节：m q'' + b q' = tau + tau_ext（1.2 等效惯量，0.8 阻尼）
# 0.3~0.5 s 施加 5 N.m 外力矩脉冲，看观测器多久、多准地把它“捞”出来
m, b, dt = 1.2, 0.8, 1e-3
obs = MomentumObserver(k_o=30.0, dt=dt)
q = dq = 0.0
r_hist = []
for k in range(1000):
    t = k * dt
    tau = 2.0 * np.sin(2.0 * np.pi * 0.5 * t)      # 已知关节驱动力矩
    tau_ext = 5.0 if 0.3 <= t < 0.5 else 0.0       # 待估计的真实外力矩
    ddq = (tau + tau_ext - b * dq) / m             # 环境是被动的“弹簧手”
    dq += ddq * dt
    q += dq * dt
    # 观测器只拿得到 q、dq、tau；一辈子看不到 tau_ext
    r = obs.update(np.array([q]), np.array([dq]),
                   np.array([[m]]), np.array([-b * dq]),   # 黏性阻尼是已知模型项
                   np.array([0.0]), np.array([tau]))
    r_hist.append(float(r[0]))
print(f"脉冲中段(0.4s)估计: {r_hist[400]: .2f} N.m  真值 5.00")
print(f"无外力时(0.10s)估计: {r_hist[100]: .2f} N.m  真值 0.00")
print(f"脉冲结束后 0.2s 残差: {r_hist[700]: .2f} N.m  真值 0.00")

解读：运行结果会看到三件事。（1）跟踪形状：r 呈指数上升，0.4 s 时约 4.7 N·m，滞后约 1/Ko ≈ 33 ms，与 ṙ = Ko(τext−r) 的解析解吻合；要提高检测速度就把 Ko 调大（试 60），代价是噪声带立刻变宽。（2）无外力时残差接近零：因为这颗"单关节卫星"没有摩擦、没有负载偏差，真机上这行数字往往不为零，差值就是模型误差的活证据。（3）脉冲结束后 r 衰减回零：说明估计器没有积分漂移，这是无源性带来的好处（观测器本身耗散）。把 k_o 改成 5 再看脉冲：幅度只剩约 3.2 N·m、拖尾很长，检测慢、恢复更慢。

片段 3：映射到笛卡尔外力 + 奇异保护 + 阈值判定

def external_force_estimate(jac, tau_ext, sigma_still=0.3, k_sig=3.0,
                            sing_min=0.02):
    """由关节残差反解笛卡尔外力，并给出碰撞指示位。
    奇异保护：J 的最小奇异值过小时放大噪声，直接拒答。"""
    u, s, vt = np.linalg.svd(jac)
    if s[-1] < sing_min:
        return None, False                 # 奇异：返回空，交给上层报警
    n = jac.shape[0]
    if jac.shape[1] == n:
        f_hat = np.linalg.solve(jac.T, tau_ext)          # 方阵直解
    else:
        f_hat = np.linalg.lstsq(jac.T, tau_ext, rcond=None)[0]  # 冗余最小二乘
    # 3σ 阈值：sigma_still 由“静止段残差”实测得到，不要拍脑袋写死
    contact = bool(np.linalg.norm(f_hat) > k_sig * sigma_still)
    return f_hat, contact

# 用法示意：每周期拿残差 r，先映射、再判接触、再做柔顺反应
# f_est, is_contact = external_force_estimate(J, r)
# if f_est is None:      # 奇异位形：只降速，不采信方向
#     ...

解读：（1）先查奇异值再做逆：单边奇异位形（如臂伸直）下 Jᵀ 近似奇异，解出的外力方向会剧烈摆动，宁可"拒答"也不要把噪声当力方向输出。（2）冗余机器人的最小二乘解 (Jᵀ)⁺ 只是"最小范数"意义下的最优，实际外力在零空间的分量不可观测，这不是算法缺陷，是物理事实：观测不到的方向上，任何估计器都只能沉默。（3）阈值判定留了接口：工程实践里更稳妥的是"阈值 + 持续 3 帧 + 方向一致性"三条件，本章从简但把 σ 的来源讲清楚，σ 必须从你自己机器的静止残差测出来（含摩擦与噪声），一般在 0.2–0.5 N·m 量级。

常见坑

  • 模型误差冒充外力：摩擦未建模 2 N·m 时，残差长期存在 2 N·m 的"假力"，正推有、反推没有。修复：先做第 051 章的参数辨识补摩擦；或把残差均值当作偏置扣除（惰性做法，运动方向反转时会露馅）。
  • Ko 越大越好：Ko = 100 rad/s 时残差噪声按比例放大，静止时也频繁越阈值、碰撞检测"狼来了"。修复：以静止残差 3σ 不超过 1 N·m 为准反推 Ko 上限。
  • 用未滤波速度：第 048 章的差分噪声经 M(q) 进入 p，r 抖动剧烈。修复：观测器上游挂 α-β 速度估计，且速度观测带宽要大于 Ko。
  • 重力和力矩常数标定错误：g(q) 偏 1 N·m 会在大臂水平位置产生固定假力，且随姿态变化。修复：先用"静止悬挂、外力已知"的标定实验校核 g 与 τ 的尺度。
  • 把 r 当精确力用：Ko = 30 意味着只对 5 Hz 以下的外力变化敏感，快速敲击的峰值会被削平，用于碰撞检测的"峰值报警"必须另设瞬时阈值通道。

练习与思考

  1. 推导 (Ṁ − C)q̇ = Cᵀq̇：利用机器人动力学中 Ṁ − 2C 反对称的性质，说明式中每一项的物理意义（哪项与惯性变化相关、哪项与科氏力相关）。★
    提示
    反对称性给出 (Ṁ−2C)ᵀ = −(Ṁ−2C)；展开 (Ṁ−C) 与其转置，或用能量守恒（动能对时间导数等于 q̇ᵀ(τ−g) 等）反推。物理上：惯量的变化率与科氏项耦合，组合后恰好等于 Cᵀq̇。
  2. 从 p̂′ = τ + Cᵀq̇ − g + r 与 r = Ko(p − p̂) 出发，推导 ṙ = Ko(τext − r)，并写出 Ko = 30 rad/s、外力矩为 5 N·m 阶跃时 r(t) 的显式表达式与 33 ms、100 ms 时刻的取值。★★
    提示
    r(t) = 5(1 − e^{−30t})；t = 0.033 s 时约 3.2 N·m，t = 0.1 s 时约 4.75 N·m。
  3. 把仿真里 k_o 从 10 扫到 80，画出（或列表）"静止残差 RMS"与"检测延迟"两条曲线，给出你对碰撞检测（要求 ≤ 50 ms）与柔顺控制（要求低噪声）分别推荐的 Ko，并说明为什么两者取值不同。★★
    提示
    检测延迟 ≈ 1/Ko，噪声 RMS ∝ Ko·噪声带宽；碰撞检测可以牺牲噪声余量求快（50–80），柔顺控制的力估计要求干净（20–30），无法兼顾就分两路各设增益。
  4. 设计一个"摩擦偏差自检"实验：在无接触、多方向匀速运动下采集残差，如何区分"某方向恒定的摩擦偏差"与"真实外力"？给出判据（至少两条）与需要的记录量。★★★
    提示
    摩擦残差符号随运动方向翻转且与速度相关、无接触时也存在；真实外力与运动方向无固定关系。记录残差 vs 速度的散点（迟滞环）并检查"正反行程对称性"；判据：正反行程残差符号相反且幅值相近 → 判摩擦。

小结

  • 没有力传感器时，外力可被动力学残差"观测"出来：关键工具是广义动量 p = M(q)q̇ 与性质 (Ṁ−C)q̇ = Cᵀq̇。
  • 动量观测器：p̂ 积分 + 残差反馈 r = Ko(p−p̂)，可证 ṙ = Ko(τext−r)，r 是一阶低通的外力矩估计，带宽 Ko（典型 20–50 rad/s）。
  • 全程不用 q̈，这是它相对"直接解牛顿方程"的核心优势；代价是模型误差（摩擦、负载、重力）会原样进入残差。
  • 笛卡尔映射要配奇异值保护；碰撞阈值用静止残差的 3σ 实测（不用固定数）。
  • 检测速度与噪声是同一条旋钮，工程上常分双路增益：快检测 + 慢滤波。
  • 下一章换角色：把"模型误差 + 外力"统称为扰动、估计后前馈补偿，扰动观测器让阻抗控制的内环"像理想模型一样干净"。
