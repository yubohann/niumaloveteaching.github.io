第二篇 · 参数调节与交互任务

第 042 章：阻抗控制在打磨中的应用

打磨工人靠"手感"把砂轮压在工件上：压力太大烧工件、太小磨不动。本章把这份手感翻译成控制器，法向用阻抗控制稳住接触力，切向用位置控制稳住进给，再用一路慢速积分自动补偿工件的表面起伏与装夹偏差。

  • 主题：力跟踪 / 打磨接触任务的分向控制
  • 关键公式：Fn = Kn·Δx（法向稳态力）与 Preston 去除律 ḣ = kp·(Fn/A)·vt
  • 预计学时：50 分钟
  • 前置章节：第 041 章（阻抗控制在抛光中的应用）

学习目标

  • 理解打磨工艺为什么对法向力敏感：从 Preston 去除律出发，说清"力波动"如何直接变成"去除量波动"。
  • 会推导法向-切向分向控制结构，并能说明切向为什么更适合位置/速度控制（阻抗控制在切向的局限）。
  • 掌握力误差积分偏置的作用原理：它如何在环境位置未知、装夹有偏差时仍把稳态力"磨"到设定值。
  • 能算出两个关键量级：串联等效刚度 Keq = KnKenv/(Kn+Kenv) 与力回路带宽 ωc ≈ kiKeq。
  • 会写分向阻抗控制器代码，并能解释每处限幅、滤波和名义插入量为什么这样取。

背景与动机

打磨（grinding）与上一章的抛光相似：都是让磨具以一定压力压向工件表面并沿表面进给。但打磨的工艺要求更"硬核"：材料去除量几乎完全由法向力决定，力波动 10% 就意味着打磨深度波动 10%，工件表面会出现肉眼可见的波浪纹，甚至局部过磨烧蚀。而工件的实际表面高度总在变，铸造件的余量公差常达 ±0.3 mm，装夹还会带来 ±0.5 mm 的整体偏置。如果按固定轨迹走位置控制，这些偏差乘以接触刚度就是几十牛到上百牛的力波动。

本章要建立的工程习惯是：打磨任务不宜"一个方向包打天下"，应当按方向分工，法向（压向表面的方向）交给阻抗控制以稳定接触力，切向（沿表面的进给方向）交给位置/速度控制以保证进给率稳定，两者再通过力误差积分耦合起来。这套结构在后面的曲面跟踪（第 064 章）里还会再见。

核心原理

1. 打磨的力学画像：去除率由力决定

先用一条经验公式把"力"和"磨掉多少"对上。Preston 去除律认为，单位时间的去除深度 ḣ（m/s）正比于接触压强 p 与相对滑移速度 vt：

ḣ = kp · p · vt = kp · (Fn / A) · vt ḣ：去除深度速率（m/s）；kp：Preston 系数（m²/N）；Fn：法向接触力（N）；A：接触面积（m²）；vt：切向滑移速度（m/s）

这条式子告诉我们两件事。第一，法向力 Fn 是去除量的"主控量"：想磨得均匀，Fn 必须稳；第二，切向速度 vt 同样线性地调制去除率，所以进给速度也必须稳，这就是为什么切向方向也要闭环；"随手推着走"满足不了均匀性要求。

2. 环境模型与稳态力：两个弹簧串联

把磨具-工件接触近似成一个刚度 Kenv 的弹簧（打磨金属时接触等效刚度约 2×104 N/m，比刚性装配的 105 N/m 软，因为砂带和磨屑层都有弹性）。与第 001 章的推导完全一样，阻抗控制器的稳态力由"控制器弹簧"和"环境弹簧"串联决定：

Fss = Keq · (xd − xs)， 1/Keq = 1/Kn + 1/Kenv xd：命令位置；xs：工件表面位置；Keq：等效刚度（N/m）

取 Kn = 800 N/m、Kenv = 2×104 N/m，则 Keq ≈ 769 N/m，几乎就是控制器刚度。也就是说只要 Kn 远小于 Kenv，稳态力基本由控制器决定，工件刚度波动对力影响很小。这就是柔顺控制对"工件批次差异"不敏感的原因。

3. 分向控制：法向阻抗 + 切向位置

为什么切向不能也做成阻抗？因为两个方向的任务目标不同：法向要"维稳力"（力是控制目标），切向要"稳进给"（速度是控制目标）。如果切向也设成软阻抗，遇到砂轮侧向摩擦力变化，末端会忽快忽慢地"躲"，进给速度不稳，直接调制去除率。所以正确结构是：

  • 法向 n：阻抗控制方程 Mnẍn + Dnẋn + Kn(xn−xd,n) = −Fn，输出命令位置；
  • 切向 t：速度/位置控制，vt 恒定（本章取 20 mm/s），保证 Preston 公式的第二个因子稳定。

工程直觉：法向方向是"力的方向"，所以用阻抗；切向方向是"运动的方向"，所以用位置。两个方向各管各的指标，比在一个耦合控制器里"既要又要"更容易调、更容易诊断。

4. 力误差积分偏置：把稳态误差"磨"掉

名义命令 xd,nom 是"估计表面位置 + 反解插入量 Fref/Kn"，但表面位置总估不准。解决办法是加一路慢速积分：把力误差折算成沿法向的偏置位移，

ẋoff = ki · (Fref − Fn)， xd = xd,nom + xoff ki：积分增益（m/(N·s)）；偏置就写在名义轨迹上，相当于"自动改写期望位置"

闭环线性化后，力误差 ef 的收敛时间常数由 ki·Keq 决定，即力回路带宽 ωc ≈ kiKeq。取 ki = 0.015 m/(N·s)、Keq ≈ 769 N/m，则 ωc ≈ 11.5 rad/s ≈ 1.8 Hz。为什么积分必须这么慢？因为力回路外面还套着位置内环（带宽约 20–40 Hz）和接触动力学，积分通道一旦逼近内环带宽，相位滞后会把负反馈变成正反馈，出现 1–3 Hz 的"呼吸式"力振荡。经验规则：kiKeq ≤ ω内环/10。

5. 主轴扰动：这里为什么用陷波？低通为什么不行

打磨用主轴转速 8000 rpm，约 133 Hz。主轴不平衡、砂轮偏心会产生同频的周期性力扰动，直接叠在力传感器读数上。如果用低通硬压到几十赫兹以下，力回路带宽也被压死了，表面起伏就跟踪不了。更好的做法是二阶陷波器（notch filter）：只挖掉 133 Hz 附近一条窄带，相位代价集中在窄带内，其余频段几乎不动。这就是"对症"和"通杀"的区别。

实现思路与设计

控制周期 1 ms。每个周期按下面的顺序执行，顺序本身也带着设计理由：

  1. 读状态：法向位置 xn、速度 vn（滤波差分）、力 Fn（传感器投影到工具 z 轴）。力必须在位置之后读，保证同一时刻的采样尽量对齐。
  2. 力信号调理：陷波（133 Hz）→ 低通（约 40 Hz）→ 去偏置。先挖周期性扰动再低通，避免陷波器在低通之后被"重新激发"。
  3. 积分偏置：按 ẋoff = ki(Fref−Fn) 更新，限幅 ±6 mm（饱和保护，第 061 章会系统讲）。
  4. 法向阻抗：由阻抗方程解出命令加速度 → 半隐式欧拉积分成命令位置，速度限 50 mm/s。
  5. 切向进给：由弧长参数推进名义轨迹（20 mm/s），不做力反馈。
  6. 合成与下发：工具坐标系下合成六维命令位姿，发给内环；记录 Fn 用于事后统计力波动。

参数取值理由：Mn = 2 kg（主轴+工具在法向的等效质量，偏大一点更"沉"、抗冲击）；Kn = 800 N/m（环境等效刚度的约 1/25，兼顾力分辨率与稳定性）；Dn = 2√(KnMn) = 80 N·s/m（临界阻尼，接触过渡不振荡）；ki = 0.015 m/(N·s)（力回路带宽约 1.8 Hz，远低于内环）。

设计决策：名义插入量为什么取 Fref/Kn？

如果名义插入量取 0，接触要全靠积分慢慢"爬"过去，建立力要好几秒；取 Fref/Kn 是让前馈先把力做到"七七八八"，积分只负责修掉剩下的偏差。前馈粗调、反馈细修，这是力控回路的基本分工。

关键代码与解读

片段 1：法向轴控制器，阻抗积分 + 力误差积分

import numpy as np

class GrindingAxis:
    """打磨法向轴：阻抗控制 + 力误差积分偏置。"""
    def __init__(self, k_n=800.0, m_n=2.0, ki=0.015, dt=1e-3):
        # K_n 取 800 N/m：约为砂带-金属接触等效刚度(2e4 N/m)的 1/25，
        # 太小则力分辨率差、磨不动；太大则接触瞬间冲击力尖峰扛不住
        self.k_n, self.m_n, self.dt, self.ki = k_n, m_n, dt, ki
        self.d_n = 2.0 * np.sqrt(k_n * m_n)   # 临界阻尼，接触过渡不振荡
        self.x_off = 0.0     # 积分偏置：环境位置未知时产生稳态力的手段
        self.v_cmd = 0.0     # 法向命令速度（阻抗积分状态）
        self.x_cmd = 0.0     # 法向命令位置（对外的真实输出）

    def step(self, x_n, v_n, x_d_nom, f_meas, f_ref):
        # 1) 力误差积分：只有积分项能消掉装夹偏差引起的稳态力误差
        e_f = f_ref - f_meas
        #    限幅 ±6 mm 属于"预抗饱和"：饱和期间偏置不能无限累积(第 61 章)
        self.x_off = float(np.clip(self.x_off + self.ki * e_f * self.dt,
                                   -0.006, 0.006))
        # 2) 阻抗方程解加速度：期望位置 = 名义路径 + 偏置，外力按 -F/M 让位
        a_cmd = -(self.d_n * v_n + self.k_n * (x_n - x_d_nom - self.x_off)
                  + f_meas) / self.m_n
        # 3) 半隐式欧拉：先限速再积分，防止积分状态飞掉
        self.v_cmd = float(np.clip(self.v_cmd + a_cmd * self.dt, -0.05, 0.05))
        self.x_cmd += self.v_cmd * self.dt
        return self.x_cmd

解读：三个设计点值得注意。（1）积分偏置写在外层（第 1 段），阻抗解算用"名义路径 + 偏置"当期望位置（第 2 段），这样阻抗控制器的"刚度手感"完全不受积分影响，积分只改变工作点。（2）速度限 50 mm/s 是安全底线：表面位置估计错 50 mm 时，偏置限幅先兜住；若偏置被撞上大障碍，速度限还能把冲击能量再压一层。（3）为什么不用解析式 xcmd = xd − F/Kn 直接算位置？那是稳态近似，丢掉惯性后接触瞬间会产生冲击尖峰；积分形式保留二阶动态，过渡更平滑，这与第 001 章的选择完全一致。

片段 2：只挖主轴转频的陷波器

class NotchFilter:
    """二阶陷波器：专挖主轴转频的周期性力扰动，不动其他频段。"""
    def __init__(self, f0, fs, q=3.0):
        # f0=133 Hz 对应 8000 rpm 主轴的转频；Q=3 决定陷波带宽约 f0/Q
        w0 = 2.0 * np.pi * f0 / fs
        alpha = np.sin(w0) / (2.0 * q)
        # 标准 biquad 陷波：零点在单位圆上(w0 处)拉低增益，
        # 极点稍稍偏内保证数值稳定，两者频率相同、宽度由 alpha 控制
        self.b0, self.b1, self.b2 = 1.0, -2.0 * np.cos(w0), 1.0
        self.a0, self.a1, self.a2 = 1.0 + alpha, -2.0 * np.cos(w0), 1.0 - alpha
        self.x1 = self.x2 = self.y1 = self.y2 = 0.0

    def update(self, u):
        # 直接型二型实现：三阶差分方程，1 kHz 下每周期只做几次乘加
        y = (self.b0 * u + self.b1 * self.x1 + self.b2 * self.x2
             - self.a1 * self.y1 - self.a2 * self.y2) / self.a0
        self.x2, self.x1 = self.x1, u          # 滑动输入历史
        self.y2, self.y1 = self.y1, y          # 滑动输出历史
        return y

解读：为什么不用简单低通？若低通截止取 30 Hz 来压 133 Hz 扰动，力回路本身只剩 30 Hz 可用，而表面起伏（几赫兹）的相位裕度也被吃掉；陷波器只牺牲 133 Hz 附近 ±20–40 Hz 的窄带，其余频段相位几乎不动。Q 怎么选？Q 太小（如 1）陷波太宽，会碰近力回路的高频动态；Q 太大（如 10）对主轴转速漂移太敏感，主轴转速 8000±100 rpm 就让 133 Hz 跑到 131.7–135 Hz，所以 Q = 3 是常用折中。工程上更稳妥的做法是跟踪主轴实际转速动态更新 f0，本章从简。

片段 3：起伏表面上的恒力打磨仿真

# 工件表面以 2 Hz 起伏 ±0.15 mm（相当于 0.3 mm 平面度误差）
k_env, dt, f_ref = 2e4, 1e-3, 20.0
ctrl, x, v = GrindingAxis(), 0.0, 0.0
forces = []
for k in range(4000):                    # 仿真 4 秒
    t = k * dt
    x_surf = 0.050 + 0.15e-3 * np.sin(2.0 * np.pi * 2.0 * t)
    # 名义路径 = 表面估计 + 前馈插入量 F/K_n：前馈粗调，积分细修
    x_d_nom = x_surf + f_ref / ctrl.k_n
    f_env = k_env * (x - x_surf) if x > x_surf else 0.0   # 单向接触
    x_cmd = ctrl.step(x, v, x_d_nom, f_env, f_ref)
    x += (x_cmd - x) * 0.2               # 内环位置环快速跟随(一阶近似)
    v = (x_cmd - x) / 5e-3 * 0.2
    forces.append(f_env)
    if k % 1000 == 0:
        print(f"t={t:4.1f}s 表面={x_surf*1000:7.3f}mm 力={f_env:6.2f}N")
print(f"后半程力峰峰值: {np.ptp(forces[2000:]):.2f} N")  # 目标 < 2 N

解读：这个仿真要观察三个层次。（1）前馈：名义路径跟随表面起伏，力大部分已被前馈"稳住"；（2）积分：把固定偏差（例如表面均值估偏、力信号偏置）慢慢磨掉，看后半程均值是否回到 20 N；（3）动态：表面起伏 2 Hz、力回路带宽 1.8 Hz，回路对 2 Hz 扰动的抑制有限，力峰峰值会略大于零，把积分增益翻倍到 0.03 会让峰峰值先降后升，因为回路开始接近临界振荡。实验里建议画出 F(t) 曲线亲自验证这个非单调现象。

常见坑

  • 工具坐标系标定不准，法向/切向串扰：标定角误差 θ = 2° 时，读数 Fmeas ≈ Fncosθ + Ftsinθ，切向摩擦 Ft = μFn 会以约 sinθ ≈ 3.5% 的比重（θ = 2°）串进法向读数。症状是"换打磨方向后稳态力变了一个值"。修复：用测头或试打磨标定工具 z 轴与表面法向，定期复核。
  • 积分增益贪大：ki 从 0.015 加到 0.05，力回路带宽升到约 6 Hz，若内环只有 20 Hz，会看到稳态附近 1–3 Hz 的持续力振荡（极限环）。修复：按 ki ≤ ω内环/(10Keq) 反推上限，宁小勿大。
  • 用低通硬压主轴振动：把力信号低通到 20 Hz 后，力回路响应变慢，表面起伏处出现明显的欠磨带。修复：改用 133 Hz 陷波 + 40 Hz 低通的组合。
  • 忘记力传感器的工具重力/惯性分量：工具重力 30 N 的恒定分量混在读数里，等效于一个"假外力"，位置被永久顶偏。修复：按工具姿态做重力旋转补偿，并扣除主轴加速度引起的惯性力（第 092 章展开）。
  • 切向进给不做闭环：直接给速度指令就撒手，摩擦变化让实际 vt 起伏 ±30%，Preston 去除率跟着起伏。修复：切向做速度闭环，摩擦大时自动补力矩。

练习与思考

  1. 用 Preston 公式推导：若法向力波动 ±10%、切向速度波动 ±5%，去除深度速率的最坏波动是多少？并解释为什么打磨工艺要求力控优于速度控。★
    提示
    去除率是两因子的乘积，波动近似相加：10% + 5% = 15%。但摩擦驱动的速度波动通常比力波动更不可控，所以工程上把"稳"的重点放在法向力上。
  2. 把 Kn 从 800 改成 200 与 3000 N/m，各跑一遍片段 3 的仿真，记录后半程力峰峰值与第一次接触的力尖峰。解释两组数字随 Kn 的单调性差异。★★
    提示
    Kn 大 → 对表面起伏的力响应大（峰峰值升），但同样插入量下建立力更快（接触尖峰也大）；Kn 小 → 力平稳但需要更大插入量，且分辨率变差。
  3. 推导串联等效刚度：由 F = Kn(xd−x) 与 F = Kenv(x−xs) 消去 x，证明 1/Keq = 1/Kn+1/Kenv，并计算 Kenv = 2×104、Kn = 800 N/m 时，若名义插入量偏小 1 mm，实际稳态力是多少（不用积分）。★★
    提示
    先相加两式消去 x，得到 F 与 (xd−xs) 的关系。插入量偏小时 F = 769×0.001 ≈ 0.77 N，远小于目标 20 N，这正是"没有积分就补不回来"的量化说明。
  4. 设计一个变进给策略：表面起伏幅值 0.3 mm、频率 4 Hz 时，若要求力波动小于 2 N，给出 Kn 与进给速度 vt 的组合方案，并说明为什么在"起伏剧烈的局部"主动降速是安全的（提示：结合力回路带宽与扰动频率的关系）。★★★
    提示
    回路对扰动的抑制随频率上升而下降；4 Hz 接近 1.8 Hz 带宽的 2 倍以上，抑制不足。降速不改变扰动频率但减小单次扰动暴露的材料去除时间，同时给力回路更多"恢复窗口"；也可以在此局部暂时增大 Kn（更"顶"）但要同步检查稳定性裕度。
  5. 分析标定角误差：设真实法向力 20 N、摩擦系数 0.3，工具坐标系偏 1° 与 5°，分别估算法向力读数误差。为什么"打磨方向改变"会暴露标定问题？★★
    提示
    Ft = 0.3×20 = 6 N；读数误差 ≈ Ft·sinθ。1° 约 0.1 N，5° 约 0.5 N。换方向后 Ft 符号/大小变化，误差项随之变化，所以不同方向打磨的稳态力不同。

小结

  • 打磨的去除率由 Preston 律 ḣ = kp(Fn/A)vt 决定：法向力与切向速度都必须稳，前者用阻抗、后者用位置/速度。
  • 分向控制结构：法向阻抗维稳力、切向速度闭环稳进给，通过工具坐标系分解实现。
  • 稳态力由串联等效刚度决定，Keq = KnKenv/(Kn+Kenv)；Kn ≪ Kenv 时力几乎只由控制器说了算。
  • 力误差积分偏置负责消除装夹/表面估计偏差，带宽 ωc ≈ kiKeq 必须远低于内环带宽，限幅是安全底线。
  • 主轴转频扰动用陷波器"对症"处理，避免低通把力回路带宽一起压死。
