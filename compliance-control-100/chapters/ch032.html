第二篇 · 参数调节与交互任务

第 032 章：斜坡接触力跟踪

力参考以恒定速率上升时，速度型力环会"慢半拍"。本章推导滞后量 ess = Ṙ/(λKenv)，给出加积分（类型 2）与前馈两条修正路线，并用实验量化三者的差别。

  • 主题：力跟踪 / 斜坡参考 / 类型系统
  • 关键公式：ess = Ṙ/(λKenv)，vr = λpe + λi∫e dt
  • 预计学时：50 分钟
  • 前置章节：第 031 章

学习目标

  • 理解为什么"斜坡参考"比"阶跃参考"难：类型 1 系统对阶跃零静差、对斜坡却有与速率成正比的滞后。
  • 会推导 ess = Ṙ/(λKenv)，并从"压入速率需求 vs 环路提供的速率"角度给出物理直觉。
  • 掌握加积分（类型 2）设计：vr = λpe + λi∫e dt 的参数含义、零点位置与稳定性代价。
  • 了解前馈路线 ẋff = Ṙ/K̂env 的作用与陷阱：K̂env 必须估计真实环境刚度，用 Kd 当代替会过冲。
  • 会执行"斜坡 + 指标"标准实验：斜坡段最大滞后、斜坡结束时刻滞后、结束后的稳态误差，并读得懂 λi 扫描表。

背景与动机

很多工艺的力需要"缓慢加上去"：压装开始时要让力从接触到目标在几秒内线性升高，避免冲击；恒压排气贴合要求压力按设定斜率上升以防止气泡；材料试验机更是标准的斜坡加载。这类任务的参考信号是斜坡：Fd(t) = F0 + Ṙ·t，Ṙ 单位 N/s。

第 031 章的恒力实验已经证明：速度形式的力环对常值参考零静差。但把参考换成斜坡，性质立刻变化，控制器必须"一边追着不断增大的目标、一边保持速度"，而环路建立速度的能力是有限的：每牛顿力误差只能买来 λ 米/秒的压入速度。于是形成了一个不可能三角：想跟得快，要么加大 λ（吃稳定裕度），要么知道"每秒钟需要压进多少毫米"（前馈），要么再加一层积分（类型 2）。本章把三条路线讲清、量清。

核心原理

1. 斜坡滞后的推导与物理直觉

沿用第 031 章的外环 vr = λ(Fd − F)，并注意被控对象的关键关系：接触力由压入量决定，环境刚度 Kenv 是"位置到力"的增益：F ≈ Kenv(x − xe)，因此力的变化率来自压入速率：Ḟ = Kenv·ẋ。跟踪斜坡时，要让力以 Ṙ 上升，就必须以 ẋ = Ṙ/Kenv 的速度压入；而环路能提供的压入速度正比于误差：ẋ = λe。两者相等即得：

λ·ess = Ṙ / Kenv ⟹ ess = Ṙ / (λ·Kenv) ess：斜坡段的稳态滞后（N）；Ṙ：力斜率（N/s）；λ 单位 m/(N·s)；Kenv 单位 N/m

这就是控制系统教科书里的"类型 1 系统速度误差常数"：Kv = λKenv，斜坡误差 = Ṙ/Kv。公式的工程读法：硬环境（Kenv 大）几乎不滞后，同样的力斜率需要的压入速率更小；软环境（垫、橡胶、薄壁件）滞后显著，想涨 2 N/s，在 Kenv=1000 N/m 的垫上要每秒压 2 mm，环路得为此付出 2 mm/s 的"误差预算"。数字：λ=0.01、Ṙ=2 N/s，Kenv=1000 → ess = 2/(0.01×1000) = 0.2 N；换成 Kenv=1×104 则只有 0.02 N。软接触是本章的主战场。

2. 修正一：把 λ 加大，有上限的方案

ess ∝ 1/λ，把 λ 从 0.005 提到 0.02，滞后从 0.4 N 降到 0.1 N（本章实验将验证）。但 λ 受第 022 章劳斯上界 λmax = Dd(Kd+Kenv)/(MdKdKenv) 约束，且增大 λ 同时放大阶跃响应超调（第 031 章的表）。当环境很软、λmax 反而变大（Kenv 小），可以适度用大增益；但"用增益换斜坡精度"的边际收益随 λ 线性递减、代价（超调、噪声灵敏度）却是持续的，所以要引入结构性的修正。

3. 修正二：加积分（类型 2），让滞后归零

按内模原理：常值参考要一个积分器（第 031 章已有的位置状态），斜坡参考要两个积分器。把外环升级为速度形式的 PI：

vr = λp·e + λi·∫e dt λp 单位 m/(N·s)；λi 单位 m/(N·s²)；比值 λi/λp (rad/s) 决定积分通道的"切入频率"

加入第二个积分后，系统对斜坡的稳态误差为零：积分通道会持续"补充"追赶斜坡所需的固定速度，直到误差完全消失。代价是相位：积分器在低频贡献 −90°，若切入频率太靠近穿越频率会使相位裕度变差。设计经验：让零点频率 ωz = λi/λp 取 0.5–2 rad/s（即低频加成、环路穿越频率的 1/10 以下），λp 保持第 031 章的工作点。本章实验里 λp=0.01、λi=0.01（ωz=1 rad/s）能把 0.2 N 的滞后压到 0.06 N 以内，λi=0.03 则接近归零。

注意：积分器要防卷绕

斜坡实验里积分通道总量 = ∫e dt，量级多少？e 初始 0.2 N 持续 5 s，积分量约 1 N·s，必须限幅（本例 ±1 N·s）。同时"找不到工件"时积分会一路爬升，配套行程限幅与接触超时（第 022 章三件套）照旧。

4. 修正三：前馈，需要正确的 K̂env

如果知道环境刚度，可以直接给出"斜坡需要的压入速度"：ẋff = Ṙ/K̂env，误差归零且不占相位裕度。问题在于 K̂env 的来源：用理想模型的 Kd（虚拟刚度）当代替是错误的，两者差了 Kenv/Kseries 倍（软接触下可达 10 倍），前馈会产生过冲（本章实验将演示约 −0.05 N 的"负滞后"）。正确做法：（1）用第 052 章的在线环境刚度辨识；（2）用"安全比例"前馈 Ṙ/(q·K̂) 的缩放系数 q 从 0.5 起调，宁可欠一点；（3）仅在高重复性工装上启用。

实现思路与设计

实验设置（1 维按压，1 kHz，12 s 时长）：

  1. 被控对象：软接触环境 Kenv = 1000 N/m（弹性垫/薄壁件量级），初始力 5 N（压入 5 mm）。
  2. 参考：t=1 s 起 Fd 以 Ṙ = 2 N/s 从 5 N 升至 15 N（5 s 斜坡），之后保持 15 N。
  3. 对比组：A 组纯比例 λp∈{0.005, 0.01, 0.02}；B 组 PI（λp=0.01，λi∈{0.01, 0.03}）；C 组前馈（错误 K̂ = Kd = 800，演示陷阱）。
  4. 指标：斜坡段最大滞后 max(Fd−F)、斜坡结束时刻滞后、结束后 5 s 的稳态误差。
  5. 验收：软接触下斜坡滞后 < 0.05 N（配 PI），结束后稳态误差 < 0.02 N。

积分通道的切换逻辑建议：只在"接触确认且 |e| 小于某阈值（如 3 N）"时启用，防止从自由空间切入时积分器已经被"大误差 × 长时间"灌满。

关键代码与解读

片段 1：带速率限制的斜坡参考发生器

import numpy as np

class RampForceRef:
    """力参考发生器：支持'从 F0 以 R N/s 升到 F1 后保持'。
    输出 (Fd, Rd)：参考值与参考斜率，供 PI 与前馈共用。"""
    def __init__(self, F0=5.0, F1=15.0, rate=2.0, t_start=1.0):
        self.F0, self.F1, self.rate, self.t_start = F0, F1, rate, t_start
        self.dur = (F1 - F0) / rate          # 斜坡时长：5 s
    def step(self, t):
        if t < self.t_start:
            return self.F0, 0.0
        if t < self.t_start + self.dur:
            return self.F0 + self.rate*(t - self.t_start), self.rate
        return self.F1, 0.0                  # 斜坡结束后斜率归零

解读：参考发生器必须同时输出值和斜率，因为 PI 的积分项与前馈项分别用两者。斜率在斜坡两端"跳变"（0→2→0 N/s），这是斜坡信号固有的角点；如果工艺对力加速度敏感（如 M=m/s³ 级 smoothness 要求），可把 rate 也做成斜坡（S 型曲线），代价是发生器多一个状态，本章保持线性以聚焦主题。真机上 Fd、Rd 应该来自工艺文件（力-时间曲线），发生器只负责插值与限速。

片段 2：PI 力环 + 前馈的三种配置实验

def ramp_experiment(lam_p=0.01, lam_i=0.0, ff_gain=0.0,
                    k_env=1000.0, k=800.0, m_d=1.0, dt=1e-3, T=12.0):
    """斜坡 5->15N(2 N/s)。ff_gain: 前馈系数 1/K_hat（0=关闭）。"""
    d_d = 2*np.sqrt(k*m_d)
    gen = RampForceRef()
    x_e, x = 0.08, 0.085         # 初始压入 5mm -> 5N
    x_r = x; delta, delta_dot, integ = 0.0, 0.0, 0.0
    log = []
    for i in range(int(T/dt)):
        t = i*dt
        f_d, r_dot = gen.step(t)
        f_ext = k_env*(x - x_e) if x > x_e else 0.0
        e = f_d - f_ext
        integ = float(np.clip(integ + e*dt, -1.0, 1.0))    # 抗卷绕
        v = np.clip(lam_p*e + lam_i*integ + r_dot*ff_gain,
                    -0.1, 0.1)                              # 参考速度
        x_r += v*dt
        a = (f_ext - f_d - d_d*delta_dot - k*delta) / m_d
        delta_dot += a*dt; delta += delta_dot*dt
        x += (x_r - delta - x)*0.3
        log.append((t, f_d, f_ext))
    return np.array(log)

def report(name, **kw):
    L = ramp_experiment(**kw); t, fd, f = L[:,0], L[:,1], L[:,2]
    m = (t >= 2.5) & (t <= 6.0)
    print(f"{name:26s} 斜坡最大滞后 {np.max(fd[m]-f[m]):.3f} N"
          f"  结束时刻滞后 {fd[m][-1]-f[m][-1]:.3f} N")

report("比例 lam_p=0.005", lam_p=0.005)
report("比例 lam_p=0.01",  lam_p=0.01)
report("比例 lam_p=0.02",  lam_p=0.02)
report("PI lam_i=0.01",    lam_p=0.01, lam_i=0.01)
report("PI lam_i=0.03",    lam_p=0.01, lam_i=0.03)
report("前馈误用 K_hat=800", lam_p=0.01, ff_gain=1/800.0)

解读：六行输出就是本章结论的完整证据链。比例组：滞后 0.40 / 0.20 / 0.10 N，与 ess=Ṙ/(λKenv) 的预测完全一致，这条直线验证了类型 1 的模型。PI 组：0.06 N 与 0.001 N，斜坡滞后几乎清零，代价是相位裕度与"结束时刻的近零误差"（积分把历史误差补回来）。前馈误用组：K̂ 错取了虚拟刚度 800（真实环境刚度是 1000），前馈速度偏大 25%，出现约 −0.05 N 的"负滞后"（过冲），误差符号都变了，说明前馈的准确性要求比稳定性更苛刻：宁可少喂，不可多喂。

片段 3：理论与实测对照，三行验证脚本

def verify_theory(rate=2.0, k_env=1000.0):
    """对照 e_ss = R/(lam*K_env) 与仿真实测的最大滞后。"""
    print("  lam   e_ss 理论(N)   实测(N)   比值")
    for lam in (0.005, 0.01, 0.02, 0.04):
        L = ramp_experiment(lam_p=lam)
        t, fd, f = L[:,0], L[:,1], L[:,2]
        m = (t >= 2.5) & (t <= 6.0)
        meas = float(np.max(fd[m] - f[m]))
        theory = rate / (lam * k_env)
        print(f"{lam:6.3f}   {theory:10.4f}   {meas:8.4f}   {meas/theory:5.2f}")

verify_theory()

解读：这个"小验证脚本"是控制工程里最值得养成的习惯，理论公式不能写完就算，要让它与仿真/实验的柱子并排站。本例四个增益下"比值"都接近 1.0（越软的接触、越低的增益，吻合越好；λ 很大时导纳内环与采样延迟开始贡献一点偏差）。当理论比值明显偏离 1（比如 0.5 或 3），说明你的模型漏掉了某个动态环节，先查内环伺服时间常数与滤波延迟，再怀疑公式。把这段脚本挂进 CI，每次改控制器都自动回归。

常见坑

  • 前馈增益取 Kd 或"想当然的刚度"：Kd 是虚拟刚度、Kenv 是物理刚度，软接触下差 10 倍，前馈过冲、力超调。修复：K̂ 用辨识值（第 052 章）或保守系数（从 0.5 倍起试）。
  • PI 的积分从自由空间就开始累积：接触前的力误差是"全量 15–25 N"，积分器一卷就是几 N·s，接触瞬间以猛烈速度冲击。修复：接触确认后再启用积分（阈值门控），并保持 ±1 N·s 限幅。
  • 把 λi 加得太大：积分零点频率逼近穿越频率，斜坡段是变好了（0.001 N），但阶跃段出现"先冲后回"的低频摆动。修复：ωz=λi/λp ≤ 穿越频率的 1/5–1/10；改完重跑第 031 章的阶跃实验。
  • 用"斜坡段平均值"当滞后指标：斜坡起步阶段（前 0.5 s）滞后天然更大（积分还没吃饱），平均值会掩盖峰值。修复：报告"斜坡段最大值 + 结束时刻值"两个数，别偷懒。
  • 忽略环境刚度随位置变化：曲面工件的等效 Kenv 沿轨迹变化，标定值只在标定段有效。修复：分段标定或在线更新 K̂；对变化剧烈的工况退回到"小斜率 + PI"的稳健组合。

练习与思考

  1. 用 ess = Ṙ/(λKenv) 计算：Ṙ=5 N/s、λ=0.01 时，Kenv=500 与 5000 N/m 的滞后各是多少？如果工艺要求滞后 < 0.1 N，两种环境各需要多大的 λ（并检查第 022 章上界）？★
    提示
    1.0 与 0.1 N；软环境需要 λ≥0.1，超出典型 λmax，说明软环境必须用 PI 或前馈；硬加增益会先撞上稳定上界。
  2. 推导：类型 2（vr=λpe+λi∫e）在"位置→力"增益为 Kenv 的简化模型下，误差方程是什么？验证斜坡稳态误差为零，并给出自然频率与阻尼比的表达式。★★★
    提示
    ë + λpKenvė + λiKenve = F̈d；斜坡时 F̈d=0（除角点），特征多项式两根均左半平面 → e→0；ωn=√(λiKenv)，ζ=λpKenv/(2ωn)。
  3. 实验：把片段 2 的斜坡结束时刻从 6 s 改为 3 s（斜率翻倍到 4 N/s），三组（λ 加大、PI、前馈误用）的相对优劣会怎样变化？先预测再运行。★★
    提示
    滞后∝Ṙ，比例组从 0.2 变 0.4 N；PI 仍近零；前馈误差同步翻倍，结论：斜率越大，结构修正（PI/前馈）越值钱。
  4. 改参数实验：固定 λp=0.02，让 λi 从 0.005 扫到 0.1，记录斜坡滞后与"斜坡结束后 2 s 内的最大过冲"，画出两条曲线，解释拐点。★★
    提示
    滞后随 λi 单调下降；过冲在 ωz 接近穿越频率后开始上升。拐点即推荐工作区（ωz 约为穿越频率 1/5–1/10）。
  5. 设计题：给一条"力按 1 N/s 从 0 升到 30 N、保持 10 s、再以 −2 N/s 卸到 0"的工艺曲线，设计完整的参考发生器 + 控制器（含所有限幅与启用条件），并写出验收指标。★★★
    提示
    发生器支持正/负斜率与角点；卸载段注意别让"δ 退让 + 参考回撤"叠加过冲；验收：三段各自的滞后/静差 + 全曲线无超调。

小结

  • 速度型力环是类型 1 系统：阶跃零静差，但斜坡有滞后 ess = Ṙ/(λKenv)，硬环境滞后小、软环境滞后大。
  • 三条修正路线：加大 λ（受 λmax 与超调限制）、加积分成类型 2（滞后归零，注意零点频率与抗卷绕）、前馈 ẋff=Ṙ/K̂env（需真实环境刚度，误用 Kd 会过冲）。
  • 推荐组合：λp 按第 031 章工作点、λi 使 ωz=λi/λp≈0.5–2 rad/s、积分门控+限幅；前馈仅在 K̂env 可信时使用。
  • 实验指标三件套：斜坡段最大滞后、结束时刻滞后、结束后稳态误差；理论公式与实测对照（比值≈1）是回归测试的标配。
