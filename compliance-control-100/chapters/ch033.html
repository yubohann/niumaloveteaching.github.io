第二篇 · 参数调节与交互任务

第 033 章：正弦接触力跟踪

让接触力按正弦规律起伏。本章用频域视角给出误差公式 |e|/A = ω/√(ω²+ωc²) 与相位滞后 arctan(ω/ωc)，解释"带宽决定一切"，并把导数前馈做成"波形已知时"的终极方案。

  • 主题：力跟踪 / 频域设计 / 前馈
  • 关键公式：e(s)/Fd(s) = s/(s+ωc)，ωc = λKenv
  • 预计学时：50 分钟
  • 前置章节：第 032 章

学习目标

  • 把力跟踪回路看成"参考到误差的高通滤波器"：误差传递函数 e/Fd = s/(s+ωc)，理解幅度与相位的完整公式。
  • 会计算给定力信号频率下的跟踪误差与相位滞后，并反推"要跟踪到 fmax 需要多宽的环路带宽"。
  • 理解相位滞后的工程含义（力波形与位置/运动波形的同步问题），知道什么任务必须在乎相位、什么任务可以只看幅值。
  • 掌握导数前馈 ẋff = Ḟd/K̂env 的用法与精度要求，理解为什么它比加积分更适合"已知周期的力波形"。
  • 会设计并执行扫频实验：0.1–2 Hz 正弦力参考，测量幅值误差与相位，画出实测频响并对照理论曲线。

背景与动机

正弦力参考在工程里比看起来常见得多：按摩/理疗机器人要求按正弦节奏按压；去毛刺和拉丝要求压力随行程周期性调制；装配压装前常用小幅"振动压入"（dither）降低摩擦影响；测试台上更是用正弦力做执行器与力传感器的动态标定。第 031、032 章分别处理了"常值"与"斜坡"参考，这一章处理周期信号，它的特殊性在于：参考持续变化、不给你任何收敛到零误差的平稳窗口，稳态误差就是一个恒定存在的量。

因此正弦跟踪的评价方式也从"上升时间、恢复时间"换成频域指标：给定频率 f 的力信号，跟踪误差的幅值是多少、相位滞后多少度。这两个数字直接由回路的带宽决定，而带宽又由 λ 与接触环境 Kenv 共同决定。搞清楚这条链，你就知道"这台机器能跟踪多快的力波形"这个参数的来龙去脉，从此不必靠反复试错。

核心原理

1. 频域核心公式：误差是高通滤波

把第 032 章的闭环方程复用到正弦场景：速度型力环 + "位置→力"增益 Kenv 构成一阶闭环，带宽 ωc = λKenv（rad/s）。闭合力跟踪传递函数与误差传递函数为：

F(s)/Fd(s) = ωc/(s + ωc)，　e(s)/Fd(s) = s/(s + ωc) e = Fd − F；低频误差小（积分型特性），高频误差趋于 100%（高通）

代入正弦参考 Fd(t) = F0 + A·sin(ωt)，稳态误差也是同频正弦，其峰值与相位滞后为：

|e|峰值 = A · ω/√(ω² + ωc²)，　φ滞后 = arctan(ω/ωc) ω = 2πf；ω ≪ ωc 时误差 ≈ A·ω/ωc（线性增长），ω ≫ ωc 时误差 → A（完全跟不上）

工程直觉：力环对"慢变化"几乎不损，对"快变化"逐渐失明；带宽就是这条"失明曲线"的拐点。三个数字感受量级（λ=0.02、Kenv=1000 N/m → ωc=20 rad/s ≈ 3.2 Hz）：

信号频率误差峰值（A=4 N，理论）相位滞后（理论）
0.25 Hz0.31 N（7.8%）4.5°
0.5 Hz0.62 N（15.6%）8.9°
1.0 Hz1.20 N（30%）17.4°
3.2 Hz（=带宽）2.83 N（70.7%）45°

由此得到设计不等式：要保证误差幅度小于 A 的 20%，需 ω ≥ ωc/5，即信号频率不超过带宽的 1/5；要 10% 则不超过 1/10。反过来，"这台机器人能跟踪多快的力波形"= ωc/(2π×5)。注意 ωc 里坐着 Kenv：同样的 λ，硬工装响应更快、软垫更慢，这与第 032 章斜坡滞后的结论完全同源（斜坡看的是 1/Kv = 1/(λKenv)，正弦看的是 ω/(λKenv) 的缩放）。

2. 相位滞后为什么有时比幅值更要命

幅值误差让"力的大小"不准；相位滞后让"力的时机"不准。对周期性工艺（抛光压力与轨迹同步、振动压入的相位对齐），滞后 20° 意味着压力波峰比位置波峰迟到 1/18 个周期，在 0.5 Hz 下就是 111 ms，足以让"下压点"错过目标区域。所以给周期性任务写验收指标时，幅值误差与相位滞后要分开列：幅值决定"力准不准"，相位决定"力来得是不是时候"。一阶回路的相位滞后随频率单调增大、最大趋近 90°，这是物理下限；想在保持幅值的同时消掉相位，只有前馈能办到。

3. 三条改进路线与它们的适用场景

  • 加大 λ：ωc 线性增大，误差与相位同步改善；代价是稳定裕度（第 022 章 λmax）与阶跃超调。适合"带宽差一点点、环境不太软"的场合。
  • 加积分（类型 2）：对常值/斜坡有效，但对正弦的改善受限于积分零点位置：误差公式变为 |e|/A = ω²/√((λiKenv−ω²)²+(λpKenvω)²)。要让积分在信号频率处真正出力，需要 λi ≳ λpω，这会把零点推到穿越频率附近、吃掉相位裕度，因此积分不是正弦跟踪的主力工具，实验部分会看到它在 ωz=λi/λp 只有 1–3 rad/s 时几乎不改善幅值。
  • 导数前馈：参考波形已知时，直接补上"波形需要的压入速度" ẋff = Ḟd/K̂env。理想情况下误差与相位双双归零，不占稳定裕度；唯一要求是 K̂env 别太离谱（本章将量化 ±30% 误差的代价）。

实现思路与设计

实验设置（1 维按压，1 kHz，13 s 时长）：

  1. 被控对象：Kenv = 1000 N/m，均值压入 10 mm（对应均值力 10 N，保证全程接触）。
  2. 参考：t = 1 s 后 Fd(t) = 10 + 4·sin(2πf t)，扫频 f ∈ {0.25, 0.5, 1.0} Hz。
  3. 控制器：λ = 0.02、参考速度限幅 ±0.2 m/s（第 025 章理念）；后 6 s 窗口做稳态测量。
  4. 指标：稳态峰值误差 max|Fd−F|、相位滞后（用整周期 FFT 或相关法估计）、以及对照理论值。
  5. 前馈组：ẋff = Ḟd/K̂env，K̂ ∈ {700, 1000, 1300} 三档，展示精度敏感性。
设计决策：为什么实验中要固定"均值+振幅"，不直接给纯正弦？

力必须保持在接触区间内：Fd 一旦小于 0 就"离面"，系统回到自由空间、模型立刻不同，实验会出现"半个周期在跟踪、半个周期在追面"的伪现象。取均值 10 N、幅值 4 N（10±4 N 全域为正），既保持接触又留出足够动态范围。同理，真机上还要检查振幅×1/Kenv 是否超过工具的行程与安全权限。

关键代码与解读

片段 1：正弦参考发生器（值 + 导数）

import numpy as np

class SineForceRef:
    """正弦力参考：F0 + A*sin(2*pi*f*t)，同时输出导数供前馈使用。"""
    def __init__(self, F0=10.0, A=4.0, freq=0.5, t_start=1.0):
        self.F0, self.A, self.freq, self.t_start = F0, A, freq, t_start
        self.w = 2.0 * np.pi * freq
    def step(self, t):
        if t < self.t_start:
            return self.F0, 0.0          # 起始段先稳住均值，避免角点冲击
        s = np.sin(self.w * (t - self.t_start))
        c = np.cos(self.w * (t - self.t_start))
        return self.F0 + self.A * s, self.A * self.w * c

解读：与第 032 章的斜坡发生器同构，参考发生器永远输出"值 + 导数"两个通道，因为导数前馈需要 Ḟd，而控制器自己数值微分会引入噪声与滞后。t_start 之前输出常值 F0，让系统先进入接触稳态再开始振荡，避免开机角点把实验污染。真机上如果工艺给出的是"位置-力"联合波形（例如压力随弧长调制），把相位也纳入发生器输出即可（多一个相位补偿量）。

片段 2：扫频实验与相位测量

def sine_experiment(freq=0.5, lam=0.02, k_env=1000.0, k=800.0,
                    m_d=1.0, dt=1e-3, T=13.0, ff_gain=0.0):
    """正弦跟踪实验：ff_gain = 1/K_hat（0 表示关闭前馈）。"""
    d_d = 2*np.sqrt(k*m_d)
    gen = SineForceRef(freq=freq)
    x_e, x = 0.08, 0.09            # 压入 10mm -> 10N
    x_r, delta, delta_dot = x, 0.0, 0.0
    log = []
    for i in range(int(T/dt)):
        t = i*dt
        f_d, r_dot = gen.step(t)
        f_ext = k_env*(x - x_e) if x > x_e else 0.0
        v = np.clip(lam*(f_d - f_ext) + r_dot*ff_gain, -0.2, 0.2)
        x_r += v*dt
        a = (f_ext - f_d - d_d*delta_dot - k*delta) / m_d
        delta_dot += a*dt; delta += delta_dot*dt
        x += (x_r - delta - x)*0.3
        log.append((t, f_d, f_ext, r_dot))
    return np.array(log)

def sine_metrics(freq, ff_gain=0.0):
    L = sine_experiment(freq=freq, ff_gain=ff_gain)
    t, fd, f = L[:, 0], L[:, 1], L[:, 2]
    m = (t >= 7.0) & (t <= 13.0)              # 整周期窗口：3 个周期
    w = 2*np.pi*freq; tt = t[m]
    # 用整周期窗口做相关/FFT 提取一阶谐波：比峰值检测抗噪
    pr = np.trapezoid((fd[m]-fd[m].mean())*np.exp(-1j*w*tt), tt)
    pm = np.trapezoid((f[m]-f[m].mean())*np.exp(-1j*w*tt), tt)
    peak_err = float(np.max(np.abs(fd[m]-f[m])))
    lag_deg = -float(np.degrees(np.angle(pm/pr)))
    return peak_err, lag_deg

for fr in (0.25, 0.5, 1.0):
    e_peak, lag = sine_metrics(fr)
    wc = 0.02 * 1000.0
    th_e = 4.0 * (2*np.pi*fr) / np.sqrt((2*np.pi*fr)**2 + wc**2)
    th_p = np.degrees(np.arctan(2*np.pi*fr / wc))
    print(f"f={fr:4.2f} Hz  峰值误差 {e_peak:.2f} N (理论 {th_e:.2f})"
          f"   相位滞后 {lag:5.1f}deg (理论 {th_p:.1f})")

解读：实测输出为，0.25 Hz：0.31 N / 相位 4.8°（理论 0.31 N / 4.5°）；0.5 Hz：0.57 N / 8.1°（理论 0.62 N / 8.9°）；1.0 Hz：0.95 N / 13.2°（理论 1.20 N / 17.4°）。低频段理论与实测几乎重合；1 Hz 处实测误差小于理论，是导纳内环（ωn≈4.5 Hz 的二阶环节）带来的额外滤波把高频误差"帮忙压住"了，理论一阶模型没含它。相位用整周期积分（FFT 思路）估计：找峰值时刻在采样噪声下抖动好几度，整周期基波提取最稳。lag_deg 取负角度，输出正值表示"测量滞后参考"。

片段 3：前馈精度敏感性，±30% 刚度误差的代价

print("前馈对刚度估计的敏感性（f=0.5 Hz）:")
for k_hat in (1000.0, 700.0, 1300.0):
    e_peak, lag = sine_metrics(0.5, ff_gain=1.0/k_hat)
    print(f"  K_hat={k_hat:6.0f} N/m -> 峰值误差 {e_peak:.3f} N, "
          f"相位滞后 {lag:5.2f}deg")
# 参考对照：无前馈
e0, lag0 = sine_metrics(0.5)
print(f"  无前馈          -> 峰值误差 {e0:.3f} N, 相位滞后 {lag0:5.2f}deg")

解读：四行输出把前馈的脾气说透，K̂=1000（正确）：误差 0.005 N、相位 0.1°，几乎完美；K̂=700（低估 30%）：误差 0.246 N（回到无前馈的 43%）；K̂=1300（高估 30%）：误差 0.132 N（23%）。规律是：误差 ∝ K̂ 的相对偏差 ×（无前馈误差），高估比低估危害略小、但仍然远不如"猜对"。

这里再补一句工程判断：如果你完全不知道 Kenv，宁可不做前馈（误差 0.57 N）也别乱喂前馈（可能过冲或振荡）；只有在工装重复性好、K̂ 经辨识确认（第 052 章）或用"保守 0.5×"试出来的场合，前馈才是稳赚的。周期性工艺是第一类值得投入辨识的场景：波形每周期重复，误差也每周期重复，一次辨识收益无限次。

常见坑

  • 忘了均值、把正弦做成"负力"：Fd = 4·sin(...) 在负半周脱离接触，测量到的"跟踪误差"其实是自由空间轨迹误差，数据不可用。修复：均值必须大于振幅，接触裕度 = F0/A ≥ 2 起步。
  • 用峰值差当"误差标准"并忽略相位：幅值对了但滞后 30° 的波形，峰值差可能"看起来"不大，工艺上却完全错位。修复：幅值、相位分开测（片段 2），周期性同步任务加相位验收线。
  • 信号频率贴着内环导纳带宽：0.5 Hz 信号配 ωn=1 Hz 的软虚拟参数时，内环自身衰减十几分贝，实测误差远大于一阶理论。修复：先检查 ωn ≥ 10×信号频率；不满足就减小 Md 或增大 Kd（在安全范围内）。
  • 用"加大 λ 强行提带宽"，忽略了 λmax 随 Kenv 变化：硬工装上标定好的 λ 换到软工装仍然安全（λmax 变大），反过来则可能振荡。修复：按最硬工装设 λ，按最软工装设前馈。
  • 前馈用"上一拍的 Ḟd"：离散延迟让前馈波形掉队 1 ms，高频段引入相位误差。修复：发生器直接输出解析导数（片段 1），不要对采样序列做数值微分。

练习与思考

  1. 取 λ=0.01、Kenv=500 N/m，计算带宽 ωc，并求 0.2 Hz 正弦（A=5 N）的峰值误差与相位滞后。★
    提示
    ωc=5 rad/s；ω=1.257 rad/s：误差 = 5×1.257/√(1.257²+25)=1.23 N；相位 ≈ arctan(0.251)=14.1°。
  2. 推导误差公式：从 e/Fd = s/(s+ωc) 出发，令 s=jω 求模与相角，验证表格里的四个数字（0.25/0.5/1.0/3.2 Hz）。★★
    提示
    |e/Fd| = ω/√(ω²+ωc²)；幅值乘 A=4 即可；相位 = arctan(ωc/ω) 的余角，即 arctan(ω/ωc)。
  3. 实验：把片段 2 的 λ 从 0.02 改为 0.005，重跑三个频率，验证"误差近似 ∝ 1/λ"的缩放律在哪个频率区间成立、哪个区间失效，并解释失效原因。★★
    提示
    低频率遵循缩放；频率接近导纳带宽后，额外动态使实际误差比一阶理论小（内环在帮忙滤波），缩放律偏保守。
  4. 把片段 2 加入 λi=0.03 的积分通道，对比 0.5 Hz 的峰值误差；用误差公式 |e|/A = ω²/√((λiKenv−ω²)²+(λpKenvω)²) 解释"积分对正弦帮助有限"。★★★
    提示
    ω²=9.87、λiK=30、λpKω=62.8：分母由最后一项主导 → 误差几乎只由 λp 决定；积分要"出力"需 λi≳λpω，代价是相位裕度。
  5. 设计题：为"压力随轨迹以 2 Hz 正弦调制、振幅 3 N、均值 12 N"的打磨工艺选择方案：环境 K̂ 已辨识为 1500 N/m。给出 λ、前馈增益、限幅与验收指标（幅值误差与相位各一条）。★★★
    提示
    ωc=λ×1500 ≥ 5×2π×2=62.8 → λ≥0.042，用前馈后可放宽 λ 到 0.02；ff=1/1500；限幅考虑振幅×1/K̂ 的行程（2 mm）；验收：幅值误差 ≤15%、相位 ≤15°。

小结

  • 正弦力跟踪的一阶频域模型：误差是高通、闭合理想时一阶低通，|e|/A = ω/√(ω²+ωc²)，相位滞后 arctan(ω/ωc)，ωc=λKenv。
  • 设计不等式：误差 <20% ⇔ f信号 ≤ 带宽/5；"能跟踪多快的力波形"就是 ωc/(2π×5)。
  • 相位滞后关系到"力来得是不是时候"，周期性同步任务必须单独验收相位；一阶回路滞后单调增大、极限 90°。
  • 三条改进：加大 λ（限稳定裕度）、加积分（对正弦作用有限）、导数前馈（波形已知时误差与相位双归零，要求 K̂ 准确，误差 ∝ 相对偏差）。
  • 下一章换个视角：把参考信号做成阶跃，系统性地测量接触力阶跃响应的时间指标与超调，并与前两章形成"四波形方法论"的闭环。
