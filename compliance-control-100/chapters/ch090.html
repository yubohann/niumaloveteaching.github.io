第 090 章：阻抗控制中的无传感器力控制

不装六维力传感器，也能"感觉到"外力：接触力会在电机力矩里留下痕迹。本章讲动量观测器怎样不用加速度信号就把这份痕迹积出来，估计带宽如何反过来限制柔顺性能，以及摩擦为什么是这条路线永远的盲区。

  • 主题：无传感器力估计 / 动量观测器
  • 关键公式：ṙ = Ko(d − r)，r̂ → 外部力 + 摩擦；u = −Ddẋ − Kd(x−xr) + F̂
  • 预计学时：65 分钟
  • 前置章节：第 089 章

学习目标

  • 理解"力信息藏在电机力矩里"的物理机制：接触力对关节产生反力矩，但要从 力矩读数 反推出它，必须先把惯性、重力、摩擦项算清楚。
  • 会推导动量观测器：p = M(q)q̇、ṗ̂ = τ + CTq̇ − g − r、r = Ko(p̂ − p) ⟹ ṙ = Ko(d − r)，并解释为什么它不需要加速度信号。
  • 掌握估计器带宽 Ko 的双向作用：Ko 越大延迟越小，但噪声与模型误差泄漏越大；力闭环外环增益必须满足 γad ≲ Ko/10。
  • 理解无传感器力估计的两个盲区：摩擦与外力在同一通道不可区分（需要摩擦模型剥离）、静摩擦低速盲区。
  • 能实现"动量观测器 + 阻抗律 + 估计力前馈"的完整无传感器力控制回路，并说出它与第 049 章观测器方法的侧重差异。

背景与动机

不是所有机器人都装得起六维力传感器：协作臂腕部的传感器价格数千到数万元、怕过载怕磕碰、还会占掉宝贵的腕部空间；而一旦传感器损坏，整台设备的柔顺功能全部停摆。工业现场更常见的硬件是：电机电流环 + 高分辨率编码器，或是近年普及的关节力矩传感器。无传感器（sensorless）力控制的目标就是：从这些已有信号里"算出"外力，让柔顺控制不依赖额外的腕部传感器。

第 049 章已经介绍过基于观测器的外力估计：那份内容偏重"估计出外力可以用来做什么"；本章把镜头拉到闭环内部，用估计力去闭合一个力控制回路时，会发生什么。你会看到一个很本质的结论：估计器不是透明的水管，它有带宽、有延迟、有噪声，柔顺回路的"手感"和"力精度"最终被估计器的三样品质锁死。同时你会认识摩擦这个永远的盲区：它与接触力进入完全相同的数学通道，唯一的出路是先用模型把它剥离。

本章的工程价值在于"把性能上限说清楚"：装不了传感器时，你能期待的最好结果是什么；哪些指标注定要打折；怎么在电机电流、编码器和一点模型知识的组合里把这份打折感降到最低。

核心原理

1. 力信息藏在哪里：反力矩通道

关节空间动力学（第 013 章的方程）在"接触"发生时多了一项 JTFext：

M(q)q̈ + C(q,q̇)q̇ + g(q) + f(q̇) = τ + JT(q)·Fext Fext：末端接触力（N）；J：雅可比矩阵；JTFext：接触力折算到关节的反力矩（N·m）

理论上"解出 Fext"只需要把其他项都移到右边，但 M(q)q̈ 这一项要求关节加速度，意味着对编码器做二阶差分，噪声放大到不可用。这就是"无传感器"路线的第一个分水岭：谁能绕开 q̈，谁就赢。动量观测器（momentum observer）正是绕开它的经典构造。

2. 动量观测器：不碰加速度的"外力计"

定义广义动量 p = M(q)q̇。对时间求导并代入动力学，利用 Ṁ − 2C 的反对称性质整理为：

ṗ = τ + CTq̇ − g + JTFext （摩擦并入待估计的"总阻力" d） d ≜ JTFext + 摩擦等一切"模型外"力矩

构造观测器，其中 r 是估计量、Ko 是增益矩阵（正定对角，单位 s−1）：

p̂ 由 ṗ̂ = τ + CTq̇ − g − r 积分； r = Ko(p̂ − p) p 由实测 q̇ 计算，p̂ 由力矩指令积分，两边都不含加速度

对 r 求导，把两个动态代进去，噪声项 p 的导数与 p̂ 的导数相减后大部分抵消：

ṙ = Ko(ṗ̂ − ṗ) = Ko(d − r) ⟹ 误差 e = d − r 满足 ė = −Koe + ḋ 常值外力下 r → d 以时间常数 1/Ko 收敛；这就是一个"一阶低通估计器"

工程直觉：动量观测器像一台只靠"力矩流水账"工作的外力计，它不测加速度，专门把"电机给了多少、动量应该涨多少"与"动量实际涨了多少"对账；对不上的差额就是外力（和摩擦）。对账的灵敏度由 Ko 决定：Ko 大，一眼就能看出差额，但也把账本上的噪声看得清清楚楚。观测误差的收敛速度与抗噪是一对老冤家：Ko = 40–80 s−1（时间常数 12–25 ms）是无腕部传感器机器人上的常用起点。

估计出 r 后（摩擦模型已在观测器方程里扣除），直接得到外部力估计：F̂ = (JT)+·r，其中 (JT)+ 是伪逆。这一步的精度几乎完全由摩擦模型的精度决定，下一节解释为什么。

3. 可观测性的直觉与两个盲区

为什么说"摩擦与外力同通道不可区分"？看观测器方程 ṙ = Ko(d − r)：d 是接触反力矩与摩擦力矩的和。观测器只能看到这个和，单凭力矩信号，一个 5 N 的接触力与 5 N 的静摩擦产生完全相同的读数。区分它们只能靠"额外的先验"：摩擦与速度相关（库仑项与 sign(q̇) 同号、黏滞项与 q̇ 成比例），接触力则与位置/环境相关；于是可以先把速度相关的那部分建模剥离，剩下的记为接触力。盲区由此而来：（1）速度接近零时库仑摩擦方向不定（静摩擦区），模型剥离误差最大，而这本书里的接触任务恰好在低速段工作；（2）摩擦本身随温度、磨损、润滑变化，模型误差会变成"幻影外力"，第 097 章会看到它如何触发误碰撞报警。

第二个盲区是带宽：估计器是一阶低通，接触力突然建立时，F̂ 滞后约 1/Ko。这个滞后会进入整个力环：外环（用 F̂ 调参考）的增益被限制在 γad ≲ Ko/10 以内，否则"外环比估计器还快"，系统会振荡。可实现的力环带宽 ≈ Ko/10 量级，以 Ko = 80 为例，力环带宽约 1.3 Hz，做恒力打磨够用，做快速装配插拔就吃力。这就是无传感器力控制的性能定价：用估计器带宽换取硬件成本。

4. 与直接测量的对比、与第 49 章的差异

腕部六维力传感器的带宽通常 500 Hz–2 kHz，噪声 ~0.1 N，且有专门的温度补偿；关节力矩传感器次之（几百赫兹，且位于减速器输出侧、摩擦污染小）；电流估计最粗（受 kt 标定、齿槽、温度漂移影响，误差 5–15%）。换算成控制能力：直接测量可以支撑几十赫兹的力环，而无传感器路线通常只能支撑 1–5 Hz。结论并不悲观：恒力打磨、表面跟踪、拖动示教（低频交互）都够用；高频力反馈任务（精密插装、碰撞前馈）还是需要真传感器，或者"传感器 + 估计"融合。第 049 章讲的是估计方法本身的来龙去脉；本章强调的是"把估计器放进闭环后的系统账本"：延迟、噪声、摩擦剥离误差三笔账，每一笔都直接写在力控精度与稳定性上。

实现思路与设计

  1. 先做模型账：辨识 M̂(q)、重力项 ĝ(q)（第 011 章）、摩擦模型 f̂(q̇)（第 012 章）；观测器精度直接由这三项的误差决定，其中摩擦最要紧。
  2. 定观测器带宽：Ko = 40–80 s−1 起步；对速度信号做 10–20 ms 低通（Ko 越大，速度噪声被放大得越多）。
  3. 摩擦剥离：用速度相关模型（库仑 sign/tanh + 黏滞 + 可选 Stribeck）；静摩擦区用"速度阈值 + 保持上次摩擦估计"的细节处理。
  4. 构建力环：内层阻抗 u = −Ddẋ − Kd(x−xr) + F̂；外层力误差积分调参考 γad ≲ Ko/10。目标力 12 N、Kenv = 104 N/m 时，γad = 3×10−4 m/(N·s) 给出约 0.3 s 的力收敛时间常数。
  5. 安全与冗余：F̂ 用于力控制的同时，也喂给碰撞检测（第 097 章）与安全停止（第 098 章）；注意用"摩擦剥离后"的信号，否则运动中的摩擦会产生幻影碰撞。
  6. 初始化与重连：观测器状态 r 从 0 启动、p̂ 从实测动量初始化；每次使能前做 0.5 s 静止对账（此时 d 应≈重力残差），防止"开机即幻影力"。
设计决策：为什么观测器中还要放摩擦模型 f̂？

观测器的 r 估计的是"总阻力" d = 外力 + 摩擦。若把 r 直接当外力用，机器人一旦运动，摩擦就被当成外力：拖着示教时会"自己觉得被人拉着"，力控时会朝着摩擦方向漂移。把 f̂ 放进观测器方程（ṗ̂ = τ − f̂ − r），等价于让 r 只对"摩擦之外"的部分负责，估计误差从"摩擦全体"降到"摩擦模型误差"。代价是引入模型偏差：f̂ 过小则残余摩擦变成幻影力，f̂ 过大则真实外力被吃掉一块。工程折中是识别准确 + 保守系数 0.9（宁可少剥一点，不制造负力）。

关键代码与解读

片段 1：动量观测器（无加速度版外力估计）

import numpy as np

class MomentumObserver:
    """动量观测器：从电机力矩与编码器速度估计"总阻力"，不需要加速度。"""
    def __init__(self, m=2.0, k_o=80.0, dt=1e-3):
        self.m, self.k_o, self.dt = m, k_o, dt
        self.p_hat = 0.0     # 观测动量的积分状态
        self.r = 0.0         # 总阻力估计（外力 + 摩擦剥离后的残差）

    def update(self, v, u, f_fric_hat=0.0):
        p = self.m * v                          # 实测动量：只用速度，不用加速度
        # 观测器积分：账本左端 = 力指令 - 摩擦模型 - 当前估计的残余阻力
        self.p_hat += (u - f_fric_hat - self.r) * self.dt
        # 对账：积分动量与实测动量的差，乘上带宽就是阻力估计
        self.r = self.k_o * (self.p_hat - p)
        return self.r

解读：核心只有三行，却包含了全部思想。（1）观测器方程用 u - f_fric_hat - self.r 积分动量，摩擦模型被提前"扣除"，r 只负责剩下的未知量；这一步把摩擦从"幻影外力"里剥离出去。（2）self.k_o * (self.p_hat - p) 是"对账灵敏度"：Ko 越大响应越快，但速度噪声（经 p = m·v 直接进入）也被同倍放大。（3）离散实现在 1 ms 周期下稳定，但 Ko 不应超过 1/(3Δt) ≈ 330 s−1，否则观测器本身先于物理系统发散。

片段 2：无传感器力控制回路（观测器 + 阻抗 + 力外环）

def run_sensorless(k_o=80.0, gamma_adm=3e-4, fc_hat=3.0, noise=0.0,
                   dt=1e-3, n=6000, seed=1):
    """无传感器恒力控制：估计力前馈 + 参考位置积分，目标 12 N。"""
    rng = np.random.default_rng(seed)
    m, b_fric, fc, k_env, x_e = 2.0, 1.5, 4.0, 1e4, 0.002
    d_d, k_d, f_d = 30.0, 400.0, 12.0
    obs, x, v, x_r, u_prev = MomentumObserver(m=m, k_o=k_o), 0.0, 0.0, 0.0, 0.0
    f_true_log = []
    for i in range(n):
        f_ext = k_env * (x - x_e) if x > x_e else 0.0
        f_fric = b_fric * v + fc * np.tanh(v / 0.01)
        v_meas = v + (rng.normal(0.0, noise) if noise > 0 else 0.0)
        f_hat_fric = 1.5 * v_meas + fc_hat * np.tanh(v_meas / 0.01)
        r_hat = obs.update(v_meas, u_prev, f_hat_fric)     # 残余阻力估计（已扣除摩擦模型）
        f_hat = max(0.0, r_hat)                            # 取正部得到外部力估计
        # 外环：力误差积分调参考位置（增益受观测器带宽约束 gamma <= k_o/10）
        x_r += gamma_adm * (f_d - f_hat) * dt
        # 内层阻抗 + 估计力前馈：F_hat 越准，参考就越"干净"
        u = -d_d * v - k_d * (x - x_r) + f_hat
        v += (u - f_ext - f_fric) / m * dt
        x += v * dt
        u_prev = u
        f_true_log.append(f_ext)
    tail = np.array(f_true_log[4000:])
    return float(np.mean(tail)), float(np.std(tail))

解读：注意控制回路的层次，观测器在里、阻抗在中、力外环在外，每一层都用上一层的输出。（1）摩擦模型剥离发生在观测器内部：f_hat_fric 从动量账本里提前扣除，输出的 r 只对"摩擦之外"的残差负责（与设计决策同一套分工）。（2）max(0.0, ...) 的单向截断对应"接触只能推不能拉"的物理：真实环境不会"吸住"机器人，负估计多半来自摩擦误差，直接截断。（3）速度测量带可选噪声，用来演示 Ko 的噪声代价；tail 统计后 2 秒的均值与波动，对应"力精度"与"力纹波"两个验收指标。

片段 3：带宽与增益的实验矩阵

def experiment_matrix():
    """三组对照：观测器带宽与力外环增益的匹配/失配。"""
    cases = [
        ("匹配     ", dict(k_o=120.0, gamma_adm=3e-4)),
        ("慢观测器 ", dict(k_o=40.0,  gamma_adm=3e-4)),
        ("外环过快 ", dict(k_o=40.0,  gamma_adm=3e-3)),
    ]
    for name, kw in cases:
        mean_f, rip = run_sensorless(noise=0.005, **kw)
        print(f"{name}  K_o={kw['k_o']:5.1f}  gamma={kw['gamma_adm']:.0e}  "
              f"末态力={mean_f:5.2f} N  纹波={rip:5.2f} N")

解读：预期现象，"匹配"组在 1 s 内收敛到 12 N 附近；"慢观测器"组收敛明显变慢（估计滞后把力环拖住），但依然稳定；"外环过快"组 γad = 3×10−3 让外环时间常数（约 33 ms）逼近观测器时间常数（25 ms），出现持续振荡甚至发散。这张表就是"γad ≲ Ko/10"这条经验规则的实验证据：估计器决定了闭环性能的上限，任何试图绕过它的整定都会被振荡打回来。另外从纹波列可以看出速度噪声的传递：Ko 越大纹波越大，如果现场只能用低分辨率编码器，就必须在"快"与"稳"之间主动选边。

常见坑

  • 用差分加速度喂观测器：以为"观测器里反正有 M(q)q̈"，直接二阶差分，噪声瞬间淹没估计。修复：坚持用动量形式（本片段 1 的结构），任何需要 q̈ 的写法都要改。
  • 忘记摩擦剥离，拿 r 直接当外力：拖动示教时机器人"感到"持续的幻影力，碰撞检测频频误报。修复：观测器方程中显式减去 f̂(q̇)，并定期复标摩擦参数（温度与磨损都会漂）。
  • Ko 一味求大：看文献里 Ko = 300 就照搬，结果力信号上一片噪声，还把关节抖得吱吱响。修复：Ko 与速度噪声挂钩，Ko·m·σv 就是估计力的噪声底，先把这个数压到 0.5 N 以内再谈响应速度。
  • 力外环与观测器"抢速度"：γad 按"越快速越好"调，结果 2–3 Hz 的持续振荡。修复：按 γad ≲ Ko/10 起调，实测收敛时间常数应为 1/(Kenvγad)，两侧联立即可定 γ 的合理量级。
  • 装机不复核 kt：电流到力矩的系数 kt 随温度漂 5–14%，直接导致力估计系统偏差。修复：用重力负载或标准砝码定期标 kt，或让重力项辨识在每个上电周期重新执行一次。

练习与思考

  1. 推导观测误差方程 ė = −Koe + ḋ（e = d − r），并解释"常值外力下 e 按时间常数 1/Ko 衰减"与"缓变外力下存在稳态滞后"两种情况的差别。★
    提示
    常值时 ḋ = 0，e(t) = e(0)e−Kot；ḋ ≠ 0 时稳态 ess ≈ ḋ/Ko，即"外力变化越快，估计越落后"。
  2. 取 Ko = 40/80/160，用片段 2 加 0.005 m/s 的速度噪声跑三遍，记录纹波与稳态力。给出你手上硬件条件下的推荐 Ko，并说明理由。★★
    提示
    纹波近似 Ko·m·σv（m=2 时每档分别约 0.4/0.8/1.6 N），稳态力差别不大；推荐"纹波 ≤ 0.5 N 前提下能取的最大 Ko"。
  3. 把 f̂fric 的库仑系数从 3.0 改成 6.0（高估摩擦），观察稳态力与瞬态；再改成 0（不剥离），观察拖动/运动中 F̂ 的虚假分量。解释"高估吃外力、低估造幻影"的对称性。★★
    提示
    f̂ 高估 → f̂ = r − f̂_fric 偏小 → 外环把参考推得更深，末态力偏大；不剥离 → 运动期 r 含摩擦，F̂ 虚高、末态偏移方向相反。可用"静止段误差最小化"来标定最优剥离系数。
  4. 设计一个融合方案：腕部传感器（低频漂移小、噪声低）与观测器（高频受限）用互补滤波融合。写出融合公式，并给出分频点选择的依据。★★★
    提示
    类似传感器互补滤波：F̂ = α(s)/(α(s)+s)·F̂sensor + s/(α(s)+s)·F̂obs；分频点取在"传感器可信带宽"与"观测器带宽"之间（如 3–10 Hz），兼顾低频精度与高频相位。

小结

  • 无传感器力控制的信号源：电机力矩（或关节力矩）里的反力矩通道；动量观测器 ṗ̂ = τ + CTq̇ − g − f̂ − r、r = Ko(p̂ − p) 完全绕开加速度。
  • 估计误差动态 ė = −Koe + ḋ：常值外力收敛时间 1/Ko，缓变外力存在 ḋ/Ko 的滞后。
  • 摩擦与外力的同通道不可区分是根本盲区：必须用摩擦模型剥离；静摩擦低速段与摩擦时变是误差主源。
  • 性能定价：力环带宽 ≈ Ko/10；估计噪声 ≈ Ko·m·σv；把 Ko 定在"纹波可接受"的最大值，不必追"文献最大"。
  • 第 084–090 章的"鲁棒与估计"一组到此收官：从鲁棒项、滑模、反步、DSC、MPC、H∞ 到无传感器估计，你手上已有一套"面对不确定性"的方法库。后半程转入工程实践：先做力传感器校准与重力补偿这类"地基工作"。
