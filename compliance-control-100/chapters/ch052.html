第 052 章：导纳控制中的环境刚度辨识

导纳控制靠"力误差除以刚度"来折算位置偏置，可环境刚度不知道，按错了，力就压不准。本章用双参数递推最小二乘把环境刚度 Ke 与表面位置 xe 一起从"力-位移"数据里估出来，并讲清激励不足时它会怎么骗你。

  • 主题：接触环境辨识 / 在线最小二乘
  • 关键公式：F = Ke(x − xe) 线性化为 F = θ1x + θ2，θ1 = Ke，θ2 = −Kexe
  • 预计学时：55 分钟
  • 前置章节：第 051 章（阻抗控制中的参数辨识）

学习目标

  • 理解环境刚度辨识在导纳控制中的三项用途：力跟踪偏置换算、稳定性裕度检查、接触状态判定。
  • 掌握双参数线性化技巧：表面位置 xe 未知时如何把方程变成两项回归。
  • 会实现带遗忘因子的双参数 RLS，并知道数值条件差时如何用位移尺度归一化。
  • 能设计"探针激励"：抖动幅度与频率的选取如何在信噪比与工艺质量间折衷。
  • 会写三重门控（接触门、激励门、范围门），理解每个门防的是什么事故。

背景与动机

第 022 章给过导纳力跟踪的核心公式：要让接触力达到 Fd，把期望位置压到表面内 Fd/Ke 的深度。这里有两个未知量，表面在哪（xe）和表面多硬（Ke）。表面位置可以靠"接触时把当前位置记下来"粗略估计，但环境刚度就没这么客气了：不同材质差三个数量级（橡胶 103 N/m、塑料 104、金属零件 105–106）。刚度按错 10 倍，力就偏 10 倍，或者控制器在刚性表面上突然"过冲"。

好消息是：机器人在执行任务时本来就会在接触面上"动来动去"（对位、找正、力调节），这些自然的位移变化恰好提供了辨识所需的激励。我们要做的是把这些数据（x 与 F）喂给一个在线估计器，让 Ke 跟着任务走。困难也来自同一处：接触数据永远只有"压入"的片段、且往往位移范围很小，"足够激励"是稀缺资源，估计器的门控设计比算法本身更决定成败。

核心原理

1. 环境模型与双参数线性化

把接触（在一个方向、一次近似的意义上）写成线性弹簧模型：

F = Ke · (x − xe) F：接触力（N）；x：机器人末端沿接触法向的位置（m）；xe：环境表面位置（m）；Ke：环境刚度（N/m）

直接看这个方程，Ke 与 xe 以乘积形式纠缠在一起，不是一个标准回归问题。展开重写：

F = Ke·x − Kexe = θ1x + θ2 θ1 = Ke；θ2 = −Kexe；回归向量 φ = [x, 1]，一个"斜率加截距"的直线拟合

物理读法：其实就是在 (x, F) 平面上拟合一条直线，斜率是刚度、截距与斜率之比给出表面位置。这个视角非常实用：数据点在 (x, F) 图上的"横向铺开程度"就是辨识的全部信息量；点挤在一处（位移没变化），直线形状就定不下来，Ke 与 xe 只能组成无穷多组解，这就是下一节要量化的激励条件。

2. 递推最小二乘回顾与数值条件

θ = [θ1, θ2] 用第 051 章同款 RLS 逐样本更新（λ 取 0.998，记忆约 0.5–1 s 量级，用于跟踪材质变化）。有一个细节必须先处理：两列的物理量纲不同，第一列是位置（约 0.05 m），第二列是常数 1，直接算会让 φ⊤Pφ 由位置项主导，截距方向学得极慢。做法是把位置除以尺度 x0（如 0.05 m）再进回归：

F = θ′1·(x/x0) + θ′2， θ′1 = Ke·x0， K̂e = θ′1/x0， x̂e = −θ′2/θ′1·x0 归一化后两列量级相当（约 1），增益分布均匀，收敛速度和数值稳定性都会变好

3. 激励条件：从几何上看"能不能解"

回归协方差 Φ = Σφφ⊤ 的条件数决定估计的可解性。直观版本：设接触段内位移跨度 Δx = xmax − xmin，力跨度 ΔF = Ke·Δx。要让拟合出的斜率可靠，ΔF 必须显著高于力噪声（0.2 N 级）：

Δx ≥ (3–10) · σF / Ke 例：σF = 0.2 N、Ke = 104 N/m 时，Δx 至少 0.06–0.2 mm；刚性表面（105）同样信噪比只需 6–20 µm

这解释了一件反直觉的事：越软的环境越难辨识（需要更大的位移才能积累出可信的力差），而软环境恰恰是机器人最"敢"用力的地方。工程上的对策就是主动"探针"：在力跟踪的名义位置上加一个微小抖动（比如 0.1–0.3 mm、2–5 Hz），用有计划的变化换取信息，代价是力也开始周期性波动，幅度必须小到工艺能容忍。

4. 三顶帽子：接触门、激励门、范围门

在线辨识最危险的失败模式全是"不该学的时候学了"：

  • 接触门：F < 0.5 N 时不更新模型。无接触时方程 F = K(x−xe) 不成立，硬学会让 Ke 趋于零、xe 漂向机器人当前位置，整段估计作废。
  • 激励门：本接触段内的位移跨度不足阈值（如 0.2 mm）时冻结更新。两个未知数、一条"短线段"数据，方程欠定，强行更新只会让估计随噪声乱走。
  • 范围门：把 K̂e 钳在 [102, 106] N/m、x̂e 钳在合理行程内。野数据（如一瞬间的 50 N 尖峰）能带飞估计，钳制是最后防线。

实现思路与设计

把估计器接进导纳力跟踪环路的顺序如下（控制周期 1 ms）：

  1. 进入接触：位置逐步逼近，F 越过 0.5 N 后开启估计；初次接触的前 0.3 s 只收集数据不采信。
  2. 探针激励：F 稳定到目标附近后，在期望位置叠加 Δxprobe = 0.15 mm × sin(2π·3t) 的小抖动；若工艺不允许（如表面质量敏感），把幅度降到 0.05 mm 并接受更慢的收敛。
  3. 在线更新：三重门控通过时执行 RLS 更新；估计值再经一层输出滤波（时间常数 0.1 s）吐出，抑制逐样本波动。
  4. 力跟踪换算：期望位置 = x̂e + Fd/K̂e；同时用 K̂e 复核接触回路增益，超限就降低导纳刚度（第 016 章稳定性分析的在线版）。
  5. 材质切换检测：把 K̂e 的持续性变化（超 3 倍）作为"换了工件/换面"信号，复位激励段计数并加快 λ（临时降到 0.995）。

参数量级：x0 = 0.05 m；λ = 0.998；K̂e 初值 2×104 N/m（对金属-塑料混合工位的折衷）；P0 = 0.5·I（中等不确定度，收敛 0.5–2 s）。

关键代码与解读

片段 1：双参数环境刚度 RLS

import numpy as np

class EnvStiffnessRLS:
    """环境刚度辨识：F = K_e*(x - x_e) 线性化为两项回归。
    归一化尺度 x0 让两列量级相当，改善数值条件。"""
    def __init__(self, x0=0.05, lam=0.998, k_init=2e4, xe_init=0.05):
        self.x0, self.lam = x0, lam
        # theta = [K_e*x0, -K_e*x_e]（第二项带 x0 尺度）
        self.theta = np.array([k_init * x0, -k_init * xe_init])
        self.P = np.eye(2) * 0.5        # 中等先验不确定度

    def update(self, x, f):
        phi = np.array([x / self.x0, 1.0])         # 两列量级都接近 1
        e = f - phi @ self.theta                   # 新息(力残差)
        K = self.P @ phi / (self.lam + phi @ self.P @ phi)
        self.theta = self.theta + K * e
        self.P = (self.P - np.outer(K, phi) @ self.P) / self.lam
        k_hat = float(np.clip(self.theta[0] / self.x0, 1e2, 1e6))
        xe_hat = float(-self.theta[1] / self.theta[0] * self.x0)
        return k_hat, xe_hat

    def p_trace(self):
        return float(np.trace(self.P))    # 不确定度：不降=激励不足

解读：（1）把 θ 定义成"带尺度"的形式，换算回 K̂e、x̂e 时各除一次 x0，量纲对账是这类技巧最容易出错的地方，写代码时把单位写在注释里能省很多调试。（2）P 初值 0.5 是折衷：太大（104）时前几步被第一对数据"带飞"，太小收敛要几秒；真机整定时可以先用 0.1 φ 扫一遍看收敛曲线。（3）p_trace() 暴露给门控逻辑：如果某个接触段里 tr(P) 几乎不降，说明这段数据"没学到东西"，估计值应被冻结在上一段的有效结果；任其随数据漂移只会越估越偏。

片段 2：变刚度墙面的在线辨识仿真

# 仿真：墙面刚度 3e4 → 1e5（2 秒时换材质）；机器人带 3 Hz 探针激励
k_wall, x_wall, dt = 3e4, 0.05, 1e-3
est = EnvStiffnessRLS()
k_hat, xe_hat = 2e4, x_wall          # 估计值缓存(供轨迹使用)
x, f_ref = x_wall - 1e-3, 10.0
for k in range(5000):
    t = k * dt
    k_wall = 1e5 if t > 2.0 else 3e4
    # 期望位置 = 表面估计 + 力换算偏置 + 探针激励(0.15 mm 是信噪比与工艺的折衷)
    x_d = xe_hat + f_ref / max(k_hat, 1e2) + 0.15e-3 * np.sin(2.0*np.pi*3.0*t)
    x += (x_d - x) * 0.1                       # 内环一阶快速跟随
    f = k_wall * (x - x_wall) if x > x_wall else 0.0
    if f > 0.5:                                # 接触门：无接触不更新
        k_hat, xe_hat = est.update(x, f)
    if k % 1000 == 0:
        print(f"t={t:3.1f}s F={f:5.2f}N K_hat={k_hat:9.0f} N/m "
              f"(真值 {k_wall:8.0f}) x_e_hat={xe_hat*1000:6.2f} mm")

解读：（1）打印序列里你会看到 K̂ 从 2×104 出发，先在软墙面段缓慢上爬（换料前约 2.0×104）；2.0 s 换硬材质后，力先跳升（同样的插入深度碰上更硬的墙），随后 K̂ 用约 5–6 s 爬升到 105 量级（λ 长记忆跟踪本就偏慢，把 λ 压小可加快，见练习 3），同时 x̂e 有小幅修正，这就是"在线辨识"的全过程。（2）把探针幅度从 0.15 mm 降到 0.02 mm 再跑：软墙面段的 K̂ 会开始"爬不上去"或随噪声乱走，直观看到激励条件的红线。（3）把 f_ref 固定 10 N 时刚性面上的力波动是 0.15 mm×105 = 15 N，探针不是免费的，工艺敏感时务必评估这个数字。

片段 3：三重门控与力跟踪换算

class EstimationGuard:
    """三顶帽子：接触门 / 激励门 / 范围门，防止“不该学的时候学”。"""
    def __init__(self, f_min=0.5, x_span_min=2e-4, k_lo=1e2, k_hi=1e6):
        self.f_min, self.x_span, self.k_lo, self.k_hi = f_min, x_span_min, k_lo, k_hi
        self.x_lo = self.x_hi = None

    def gate(self, x, f):
        # ① 接触门：力太小则方程不成立，同时清空本段位移包络
        if f < self.f_min:
            self.x_lo = self.x_hi = None
            return False
        # ② 激励门：本接触段位移跨度不足则冻结（欠定问题不能硬解）
        if self.x_lo is None:
            self.x_lo = self.x_hi = x
        self.x_lo, self.x_hi = min(self.x_lo, x), max(self.x_hi, x)
        if (self.x_hi - self.x_lo) < self.x_span:
            return False
        return True

    def clamp_k(self, k_hat):
        # ③ 范围门：钳进物理可能区间，防止野数据“带飞”
        return float(np.clip(k_hat, self.k_lo, self.k_hi))

def force_tracking_offset(f_des, k_hat, xe_hat):
    """辨识结果的用途：期望位置 = 表面估计 + F_des / K_hat。
    k_hat 越小(越软) → 需要越大的插入量，这正是“压软材料要更深”的数学。"""
    return xe_hat + f_des / max(k_hat, 1e2)

解读：（1）接触门在力不足时连包络一起清空，若只清标志位不清包络，上一段接触的旧跨度会被计入新段，激励门形同虚设。（2）激励门用"本段累计位移跨度"，不用瞬时速度：抖动速度再大，如果原地往复（往左多了往右也多），净信息量依然有限，严格的判据其实是回归协方差 Φ 的条件数，工程上用跨度近似已经能防住大部分事故。（3）范围门的上下限（102–106）覆盖了从海绵到钢件的全部常见环境；如果估计值贴住上界不动，应怀疑是"接触瞬间的力尖峰被当成刚度"，把力信号先过第 047 章的中值+低通再进辨识器，这类野点会少一半。

常见坑

  • 无接触时也更新：自由段的 F 只是噪声，辨识器把"噪声 vs 位置"当关系学，K̂ 塌向零、x̂ 追着末端跑。修复：接触门（f > 0.5 N）+ 新接触段前 0.3 s 只采集不采信。
  • 不归一化直接拟合：量纲差导致截距方向几乎不更新，表现为"K̂ 收敛了但 x̂e 总差几毫米"。修复：位移除以尺度 x0，或对每列做标准化。
  • 忘记完全松开后 P 复位：离开接触很久后再接触，如果沿用旧 P（已收缩得很小），估计不能适应新工件。修复：接触中断超过 1 s 就把 P 部分复位（如置 0.1·I）。
  • 探针幅度越界：为了辨识快把探针加到 1 mm，刚性面上力波动 100 N，直接违反力限。修复：探针幅度的预算 = 允许的力波动/K̂e,worst，先按最硬环境算上限。
  • 把辨识值当真值用：K̂e 有滞后与偏差，力跟踪偏置应留 20–30% 的闭环修正余量（靠第 061 章的积分回路收尾），不要指望开环偏置一次到位。

练习与思考

  1. 把 F = Ke(x−xe) 线性化为两项回归，推导 K̂e、x̂e 从 θ 恢复的公式，并说明为什么"接触段位移为零时两者不可分离"。★
    提示
    若 x 恒定，所有数据点在同一条竖直线上，任意 (Ke, xe) 组合都能拟合同一 F，直线的斜率无从确定。
  2. 推导激励条件下的最小位移跨度：给定 σF = 0.2 N、Ke = 5×103 N/m，要让斜率估计的误差小于 10%，需要多大跨度？（提示：斜率误差约 σF/(Δx/√12)，取一维简化。）★★
    提示
    σK̂ = σF√12/Δx（12 来自均匀分布的最小二乘方差）；要求 σK̂ < 0.1Ke → Δx > 0.2·√12/0.1×10³ m ≈ 0.7 mm，软环境确实"难教"。
  3. 用片段 2 仿真：把 λ 从 0.998 改为 0.99 与 0.9999，记录材质切换时的跟随时间与稳态期 K̂ 的波动幅度，解释"跟踪速度-噪声"折衷在环境辨识里的具体表现。★★
    提示
    λ 小 → 记忆短 → 切换跟随快（0.2–0.3 s）但稳态波动大；λ 大 → 波动小但切换后要好几秒才追上。按"材质切换频率"选 λ。
  4. 设计一个"无探针"版本的辨识方案：利用任务本身的对位/找正运动来激励，给出你能想到的两类自然激励场景，并说明为什么它们比探针更难保证条件数。★★★
    提示
    自然激励如插入装配的倒角滑入（位移-力曲线非线性段）、力调节的阶跃超调。难点：位移范围由任务决定不可控、可能与摩擦耦合；验收要看回归矩阵条件数，不能拍脑袋。

小结

  • 环境刚度 Ke 与表面位置 xe 可通过双参数线性化 F = θ1x + θ2 一起在线辨识；本质是 (x, F) 平面上的两点定直线。
  • 数值条件是隐形杀手：位移尺度归一化让两列量级相当，收敛与稳定都变好。
  • 激励条件是物理铁律：软环境需要更大的位移跨度；条件不满足时宁可冻结，不要硬解。
  • 主动探针（0.05–0.3 mm、2–5 Hz）用可控的力波动换取信息；幅度预算由最硬环境与力限共同决定。
  • 三重门控（接触/激励/范围）分别防"乱学、欠定、野点"三类事故。
  • 下一章开始参数"服役"：先看阻抗控制中的时变刚度，怎么在任务阶段之间安全地切换刚度，为什么"悄悄地快切"会向系统注入能量。
