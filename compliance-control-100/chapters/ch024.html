第二篇 · 参数调节与交互任务

第 024 章：阻抗控制中的力矩限制

阻抗控制算出的是力旋量，落到电机上却是关节力矩，执行器有物理上限。本章讲清限幅放在哪一层、为什么逐关节截断会扭曲力的方向，以及近奇异点时"限了力矩也未必限得住力"的放大效应。

  • 主题：阻抗控制 / 执行器安全约束
  • 关键公式：τ = JT(q)·F，‖F‖ ≤ ‖τ‖ / σmin(J)
  • 预计学时：45 分钟
  • 前置章节：第 008 章、第 023 章

学习目标

  • 理解阻抗 wrench（力旋量）到关节力矩的映射 τ = JTF，能用"杠杆臂"直觉解释每个关节分到多少力矩。
  • 会区分两种限幅，任务力旋量层面等比缩放与关节空间逐轴截断，并解释为什么逐轴截断会旋转实际施加力的方向。
  • 会推导并解释奇异点处的力放大关系 ‖F‖ ≤ ‖τ‖/σmin(J)：为什么"限力矩"不等于"限接触力"。
  • 掌握"用实际施加的力回灌状态"的一致化方法：让阻抗内部状态与真实执行器同拍，天然避免积分卷绕。
  • 能写出一段带力矩预算、饱和监测与硬兜底的阻抗输出级代码，并说出每行的理由。

背景与动机

阻抗控制设计在"任务空间"里：你规定的是末端对外表现出的刚度、阻尼和期望力。但伺服驱动只认识关节力矩 τ（单位 N·m），两者之间隔着雅可比转置：τ = JT(q)F。每台机器人的每个关节都有明确的力矩上限，中型六轴臂常见 40–150 N·m，协作臂更小。一旦某个关节吃饱了，控制器想要的力旋量就无法完整施加：机器人表现得不再是你设计的那个阻抗。

更隐蔽的是第二个问题：限力矩并不等于限接触力。当机器人接近奇异构型（手臂快伸直、手腕对接）时，很小的关节力矩会被几何放大成很大的末端力，5 N·m 的肘部力矩在近奇异姿态能顶出上千牛的"柱力"。如果你只用关节力矩限幅当安全网，这张网在奇异点附近会漏。本章把这两件事讲透，并给出正确的限幅层次与代码。

核心原理

1. 力的落点：τ = JTF 的杠杆臂解释

设末端受到（或要施加）一个任务空间力旋量 F ∈ R6（前三维力 N，后三维力矩 N·m）。在准静态下，关节力矩与它满足：

τ = JT(q) · F，分量形式 τi = Σj Jji(q) · Fj Jji：第 j 个任务方向对第 i 个关节的"几何传递系数"，量纲 m 或无量纲（旋转轴）

把 J 的这一列读成力矩臂：末端力作用点离第 i 个关节轴越远、力的方向越垂直于"轴到作用点"的连线，τi 就越大。这也解释了量级：末端施加 30 N，腕部关节到作用点的距离 0.1–0.3 m，腕关节力矩约 3–9 N·m；肩部杠杆 0.5 m 量级，力矩约 15 N·m，都在上限之内，正常姿态下力矩不是瓶颈，瓶颈出现在"误差大、刚度大、姿态险"的时刻。阻抗控制算出的力正比于位置误差（Kd·e）与速度项（Dd·v），所以限幅设计必须考虑"位姿偏差多大时开始饱和"。

2. 两种限幅：任务层等比缩放 vs 关节层逐轴截断

当 ‖τ‖ 超限时，直觉告诉你"砍掉多余的部分"，但砍法有两种，结果完全不同：

  • 任务层缩放：先算 τ = JTF，再按标量 s = min(1, τmax/‖τ‖∞) 把 F 整体缩为 s·F。力旋量的方向不变、大小按比例缩小，机器人还是沿着你设计的方向推，只是"推不动那么狠"。
  • 关节层逐轴截断：对每个 τi 单独做 clip(τi, ±τmax)。饱和的轴停在上限、没饱和的轴照旧，合成后的 τ′ 对应一个旋转了方向的等效力，你本来往法向压 20 N，实现出来却偏了 30°，切向磨出划痕。

所以正确做法是先做任务层缩放，再做关节层硬限幅兜底。兜底限幅几乎不应触发（任务层已经保证不超限），它的唯一职责是防御数值异常、J 读错等"不该发生"的情况。

3. 近奇异点的力放大：为什么力矩限不住力

把 J 做奇异值分解 J = UΣVT，则从关节力矩反推末端力的关系里出现 1/σi 因子，最坏情况给出：

‖F‖ ≤ ‖τ‖ / σmin(J) σmin：J 的最小奇异值（单位 m 或无量纲）。σmin→0 时，任意微小的力矩都能"表达"成巨大的末端力

物理图景：近距离伸直的机械臂像一根柱子，肘部一点点力矩，经过几乎共线的杆系几何，就变成末端沿柱轴方向的巨大推力。数值演示：连杆长 0.4 m 的平面两杆臂，肘部角 q₂ = 0.01 rad（几乎伸直）时 σmin ≈ 2×10−3 m，5 N·m 的力矩预算"对应"的峰值力达 ∼2800 N；而 q₂ = 0.5 rad 的正常姿态下 σmin ≈ 0.09 m，同样的力矩只能顶出约 57 N。结论：力矩限制是"执行器保护"，不是"接触力保护"；接触力的安全要靠力旋量限幅 + 力传感器监控 + 奇异规避（第 026 章）共同承担。

顺带记住对偶关系：近奇异点时运动能力塌缩（σmin→0，动不了）、力传递能力暴涨（1/σmin→∞）。所以同一个奇异区，对导纳控制是"速度爆炸"风险（第 026 章讲 DLS），对阻抗控制是"力爆炸"风险。

4. 限幅后的状态一致性：反对卷绕的一种自然解法

限幅后真正的陷阱是内部状态与现实脱节：阻抗内部还在按"我要施加 40 N"积分速度，而执行器实际只给了 25 N，误差被状态记在账上、越积越多，接触解除时突然"放账"，机器人猛冲。传统解法是附加抗饱和补偿，但更优雅的做法是：把"实际施加的力"（缩放后的 s·F）回灌进阻抗动力学，让内部状态只基于现实演化。这样限幅对系统而言只是"阻抗参数临时变了"（等效质量变大、反应变慢），不会让控制器"失忆"，稳定性和无源性都更容易论证。

实现思路与设计

把限幅环节嵌入阻抗输出级的流程（1 ms 周期）：

  1. 读状态：q、ẋ、J(q)、力传感器 Fext。J 必须与当前 q 同拍，用上一拍的 J 是常见的隐性延迟源。
  2. 算理想力旋量：Fdes = −[Mdacmd + Dd(v−vd) + Kd(x−xd)] 中的"接触反力部分"，连同前馈重力项分开记账。
  3. 力矩预算：τavail = τmax − |τgravity| − |τfriction|。重力/摩擦补偿先欠账后花钱，相同姿态下静态悬停就要吃掉 20–40% 预算。
  4. 任务层缩放：s = min(1, τavail/‖JTFdes‖∞)，应用 s·Fdes，记录 s 的时间序列用于诊断与告警（s 长期 < 0.5 说明参数或轨迹有问题）。
  5. 硬兜底：对最终 τ 逐轴 clip。正常情况它不应触发；触发即是"异常事件"，记日志。
  6. 状态一致化：用 s·Fdes 更新阻抗内部速度/位置状态，再做数值积分。
设计决策：τmax 取多少？

取执行器连续工作力矩的 70–80% 作为软限幅门限，铭牌峰值只作硬上限参考。原因：峰值力矩只能维持几百毫秒，而接触任务常常持续几分钟；留出的余量还给重力、摩擦、温度降额和控制抖动。例如关节连续力矩 25 N·m、峰值 60 N·m，则软门限取 20 N·m。

关键代码与解读

片段 1：任务层缩放的限幅器

import numpy as np

def limit_by_torque(J, f_des, tau_max):
    """任务力旋量 -> 关节力矩 -> 等比缩放限幅。
    返回 (实际施加的力旋量, 缩放系数 s, 实际力矩)。"""
    tau = J.T @ f_des
    tau_peak = np.max(np.abs(tau))          # 用无穷范数衡量"最吃紧的关节"
    s = min(1.0, tau_max / max(tau_peak, 1e-9))
    f_app = s * f_des                        # 在力旋量层面等比缩放：方向不变
    tau = J.T @ f_app                        # 缩放后的力矩（理论上已不超限）
    tau = np.clip(tau, -tau_max, tau_max)    # 兜底硬限幅：防数值异常，正常不触发
    return f_app, s, tau

解读：核心是 f_app = s * f_des 这一行，缩放发生在力旋量层面，所以无论哪几个关节超限，最终输出力的方向不旋转，这保住了阻抗控制的语义（方向是设计的一部分，大小可以被预算削减）。如果反过来做 np.clip(tau, ...) 再反推 F，力方向就会被"哪个轴先撞上限"随机扭曲。tau_peak 取无穷范数，理由在安全约束本身：要求"每个轴都不能超"，无穷范数对应的正是最吃紧的那个轴，2-范数会把单轴尖峰平均掉。最后的 np.clip 保留着当保险丝，工程上昂贵的保护层永远留一道冗余。

片段 2：把"实际施加的力"回灌状态

class LimitedImpedance:
    """阻抗输出级：限幅后状态一致化，避免积分卷绕。"""
    def __init__(self, k_d=800.0, m_d=1.0, d_d=None,
                 tau_max=20.0, dt=1e-3):
        self.k_d, self.m_d = k_d, m_d
        self.d_d = d_d if d_d is not None else 2.0 * np.sqrt(k_d * m_d)
        self.tau_max, self.dt = tau_max, dt
        self.x_cmd, self.v_cmd = 0.0, 0.0     # 阻抗内部状态（命令侧）
        self.s_log = []                        # 饱和系数历史，用于诊断

    def step(self, x, v, x_d, f_ext, J):
        # 理想阻抗加速度：外力越大，命令位置越要"让位"
        a_des = -(self.d_d * (v - 0.0) + self.k_d * (x - x_d)
                  + f_ext) / self.m_d
        # 由加速度反推"本拍希望施加的力旋量"（1 维切面示意，六维同理）
        f_des = np.array([self.m_d * a_des + self.d_d * (v - 0.0)
                          + self.k_d * (x - x_d)])
        f_app, s, tau = limit_by_torque(J, f_des, self.tau_max)
        # 关键：状态更新以实际施加的 f_app 为准。
        # 力矩不够时系统等效为"更重更慢的阻抗"，不会记账后突然释放
        a_app = (f_app[0] - self.d_d * (v - 0.0)
                 - self.k_d * (x - x_d)) / self.m_d
        self.v_cmd += a_app * self.dt
        self.x_cmd += self.v_cmd * self.dt
        self.s_log.append(s)
        return self.x_cmd, tau

解读：本片段一维简化展示机制，真实系统里 fdes 是六维、aapp 用 (J.T @ f_app) 再映射回关节/操作空间。两处 f_des 与 f_app 的区别就是本章的灵魂：a_app 的计算里用的是实际力，于是当 s=0.5 时，内部速度更新也慢了一半，状态与现实同拍，无需任何显式的抗饱和补偿。代价是"理想阻抗"在饱和期间被改变了等效参数，但你换来的是可预测、可论证的降级行为。对于极端安全场景，还可以在 s 长期小于门限时主动降低 Kd（软化任务），这是 020 变阻抗与本章的组合技。

片段 3：近奇异姿态的力放大实测

l1 = l2 = 0.4                              # 平面两杆臂，连杆 0.4 m

def two_link_J(q1, q2):
    return np.array([
        [-l1*np.sin(q1) - l2*np.sin(q1+q2), -l2*np.sin(q1+q2)],
        [ l1*np.cos(q1) + l2*np.cos(q1+q2),  l2*np.cos(q1+q2)]])

tau_budget = 5.0                           # 假设某关节只有 5 N·m 可用
print(" q2(rad)  sigma_min(m)  同力矩可产生的峰值力(N)")
for q2 in (0.5, 0.1, 0.05, 0.01):
    sv = np.linalg.svd(two_link_J(0.6, q2), compute_uv=False)
    # 力放大：F_max ~ tau / sigma_min。奇异值越小，同样的力矩顶出力越大
    print(f"  {q2:6.3f}   {sv[-1]:10.5f}   {tau_budget / sv[-1]:12.1f}")

解读：输出会显示 σmin 从 0.5 rad 时的 ≈0.09 m 一路跌到 0.01 rad 时的 ≈1.8×10−3 m，而"同力矩峰值力"从约 57 N 涨到约 2800 N，近 50 倍的放大。这段代码想告诉你的工程结论很直接：（1）关节力矩传感器看到"还很宽裕"时，末端力可能已经失控，所以力安全必须有独立的、来自力传感器与任务层的判据；（2）任务层的力旋量限幅（设 Fmax=50 N）在奇异区同样重要，它不依赖 σmin 的估计；（3）姿态规划时让 q₂ 离 0（或 π）保持 0.3 rad 以上，能从源头消掉大部分风险（第 026 章系统展开）。

常见坑

  • 逐关节 clip 当限幅：力方向被扭曲，表现为"本该压法向却沿切向划出"或装配时力旋量偏转导致卡死。修复：先在力旋量层等比缩放，clip 只做兜底。
  • 忘了重力也在预算内：静态悬停时重力矩可能占掉一半额度，运动到"伸得远"的姿态时接触力突然变软。修复：把 |τg| 从 τmax 里先扣除，并按姿态监视余量。
  • 只看峰值力矩不看持续力矩：软门限若贴在峰值铭牌上，电机很快过热降额，行为随时间漂移。修复：软门限取连续工作力矩的 70–80%。
  • 饱和期间不记录 s：调试时只看到"有时候不太听话"，无从下手。修复：把 s 的时间序列记录下来，长期 <0.5 就是参数或轨迹问题（刚度太大、限速太松、姿态太险）。
  • 用限幅后的 τ 反解力再喂给力显示：若反解时没考虑 J 的秩亏，显示的力与真实差异巨大。修复：显示直接用 s·Fdes（任务层缩放已知），或经阻尼最小二乘反解。

练习与思考

  1. 在一个已知姿态下，J 的某一列全为 0.2 m 量级，末端要施加 25 N 的法向力。估算最大的单关节力矩是多少，并判断 20 N·m 的预算是否够用。★
    提示
    τi ≈ 0.2×25 = 5 N·m；加两个量级的余量也远小于 20 N·m，此姿态下力矩不是瓶颈，注意别被"上千米诺米"吓到。
  2. 把片段 1 的缩放从力旋量层改到关节层（直接 clip τ 再反解 F），构造一个 J 矩阵例子，让"力方向"在两种做法下相差 20° 以上，并解释差值来源。★★
    提示
    构造 J 的某一行特别大（长杠杆），该关节先饱和被 clip，其他关节不变，合成方向偏转。用 J=[[1,0],[0,0.1]]、F=(30,30) 之类的小例子手算最快。
  3. 推导 ‖F‖ ≤ ‖τ‖/σmin：从 τ = JTF 出发，用奇异值分解写出 F 的解并取范数上界。★★★
    提示
    J = UΣVT 时 JT = VΣUT；F = UΣ−1VTτ（方阵满秩时），‖F‖ ≤ ‖τ‖/σmin 由 Σ−1 的最大元素为 1/σmin 得到。
  4. 实验：让片段 2 的限幅器经历一次"力尖峰"（外力从 5 N 跳到 40 N 再回落），分别记录（a）用 fapp 回灌、（b）用 fdes 积分 两种做法的 xcmd 轨迹，解释 b 的回冲现象。★★
    提示
    (b) 中状态在饱和期间继续按理想力积分，撤力时"欠账"一次性释放，xcmd 出现快速回弹；这正是抗卷绕要解决的问题。
  5. 设计题：给定 τmax=80 N·m、重力补偿已占 30 N·m，写出一条"任务层软缩放 + 力旋量上限 60 N"的组合限幅规则，并说明两层限幅的先后顺序为什么不能颠倒。★★
    提示
    先对 Fdes 取范数上限 60 N（任务语义），再用 50 N·m 预算缩放（执行器语义）；若先按预算缩放到很小、再被 60 N 上限截断，就浪费了方向信息。

小结

  • 阻抗力旋量经 τ = JTF 落到关节；限幅的正确层次是先任务层等比缩放、后关节层硬兜底，逐轴截断会扭曲力的方向。
  • 力矩预算要扣除重力/摩擦补偿的"固定开销"，软门限取连续工作力矩的 70–80%。
  • 近奇异点存在力放大 ‖F‖ ≤ ‖τ‖/σmin：关节力矩限幅保护不了接触力，必须叠加力旋量上限与传感器监控。
  • 状态一致化（用实际施加的 s·F 回灌阻抗动力学）是简单可靠的抗饱和方案，饱和期行为等效为"更重更慢"的降级阻抗。
  • 下一章把镜头切到导纳侧：当速度成为输出量，速度限制为什么比位置截断更安全、限速又如何破坏理想动力学并需要平滑处理。
