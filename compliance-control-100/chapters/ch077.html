第 077 章：导纳控制中的位置限制

导纳控制天生"听得进外力的话"，但如果外力把机器人推向工作空间之外呢？本章给柔顺行为划出可行域，并让边界表现得像一堵"有弹性的墙"。

  • 主题：安全约束 / 虚拟墙与可行域投影
  • 关键公式：Fwall = Kw·max(0, d₀ − d)，单侧激活
  • 预计学时：45 分钟
  • 前置章节：第 076 章（力限制）

学习目标

  • 理解为什么柔顺控制更需要位置限制：环境力可以把末端推到任何方向，包括工作空间外与禁入区。
  • 掌握虚拟墙（virtual wall）的力模型与参数选择：墙刚度、缓冲带宽度、临界阻尼匹配。
  • 掌握速度层投影法：在边界处把速度投影到可行切平面，让机器人贴边滑行。
  • 会比较"输出端硬截断"与"把墙当作虚拟环境接入导纳律"两种方案在平稳性上的差异，并解释原因。
  • 能实现一段"墙角卡死自动脱离"的判断逻辑，理解可行域角落的几何特殊性。

背景与动机

位置控制在自由空间里根本不需要"位置限制"，控制器本来就一丝不苟地待在规划轨迹上。柔顺控制则相反：它的设计目的就是让外部力改变末端位置（"让位"）。这本是美德，但让位的方向没有任何保证，操作者手一歪、环境件卡住、力传感器漂移，都可能把机器人推向工作空间边界、工件禁区、甚至人的活动区。

简单做法是在输出端加一个硬截断："位置不许超过 xb"。但你会发现两个问题：其一，机器人顶在边界上时"黏住"，外力撤走后不能自然弹回；其二，接触瞬间位置指令的导数是断的，速度指令跳变，机械臂听起来"咯噔"一下。本章的两个方法，把边界建模成虚拟墙、在速度层做可行投影，分别解决这两个问题，而且都与前 76 章建立的框架自然兼容。

核心原理

1. 虚拟墙：把边界变成"一个弹性环境"

与其在输出端截断，不如换一个思路：边界不过是一种特殊的接触环境。定义距边界的"剩余距离" d（进入缓冲带后从 d₀ 递减到 0），虚拟墙产生单侧力：

Fwall = Kw · max(0, d₀ − d) d：到边界表面的距离；d₀：缓冲带宽度；只有进入缓冲带（d < d₀）才激活

把这个力与真实的外力一起送入导纳律（第一章的 M/D/K 框架原封不动），机器人就会以一种平滑、可预测的方式"软"停在边界附近：越接近边界，反推力越大；稳态穿透深度 Δ = F/Kw（外力越大，压得越深一点，但绝对撞不穿）。它天然解决"黏住"问题，外力撤走，墙的弹力把机器人推回自由区。

参数选择的经验规则：墙刚度取任务刚度的 5–10 倍（保证边界比任务约束"硬得多"），缓冲带宽度 d₀ 取 5–20 mm（太窄响应陡，太宽干扰正常任务），并给墙配一个单独的阻尼 Dw = 2√(KwMd)，别用任务的 Dd，否则硬墙配软阻尼会振荡。

2. 速度层投影：在边界处"贴着走"

很多任务的运动方式是"沿着边界走"，比如用尺子靠着工件边缘滑。这时在位置层限制会带来剪力，更优雅的是速度层投影：把期望速度分解为可行切向与禁入法向，切除法向分量：

vallowed = v − (v·n̂)·n̂ （当 d < d₀ 且 v·n̂ > 0，即正在往外推时） n̂：边界外法向；投影保留贴着边界的滑动，只拦"想出去"的分量

这个操作有两个刻意设计的细节：只在"逼近"时拦截（远离边界时投影是空操作，行为与自由空间完全一致）；保留切向分量（沿边界滑动不受影响，也就是允许"墙边滑行"）。从能量角度看，投影只做减法，不向系统注入能量，是天然安全的操作。

3. 两法组合与"角落"问题

工程上通常两层都用：速度投影做常规的防越界与贴边运动；虚拟墙作为兜底，处理"来不及投影"的高动态冲击。两者叠加时要注意顺序：先投影、再让墙的力进入导纳律，最后再做输出截断（第三道保险）。

可行域如果是多面体的角落（两个边界同时激活），会有一个经典陷阱：两个法向投影叠加后切向空间缩成一条线，机器人在角落里"进退两难"。处理办法是：检测到两界同时激活且速度几乎衰减为零时，给一个指向可行域内部的脱离速度（沿两法向之和的反方向），并持续到任一界解除，这就是"墙角逃逸"逻辑。

实现思路与设计

  1. 边界表示：每个限制单元存 (位置 b、外法向 n̂、缓冲带 d₀)。凸多面体只需逐面枚举；关节限位通过 J 映射到任务空间也可以表达成一组"动态边界"。
  2. 计算距离与激活：d = (x − b)·n̂；d < d₀ 时该墙进入"活动集合"。
  3. 速度投影：对活动集合中的每面依次投影（超过两个面同时激活时，按"最违反"顺序投影或改用 QP，见 075 章框架）。
  4. 墙力注入：Fwall 与真实力一起送入导纳律，注意符号：墙力永远指向可行域内部。
  5. 兜底截断与诊断：输出位置最后再夹一层硬上下限（正常不该被触发），并把"投影余量 d、激活面数量、逃逸标志"记入日志。
设计决策：为什么墙力不直接"加在输出位置"上？

如果直接把位置修正量加在输出端（xcmd += Δxwall），等于绕过了导纳动力学，墙的响应会立刻出现（无惯性），在接触瞬间产生速度跳变。把墙力送入导纳律则让墙和真实环境共享同一套惯性/阻尼，边界处的行为与撞上一面真墙完全一致：这是"物理一致性"设计，也是能被操作员直觉理解的行为。

关键代码与解读

片段 1：虚拟墙力（单侧、平滑激活）

import numpy as np

def wall_force(x, b, n, d0=0.01, k_w=5000.0):
    """单面虚拟墙：返回该面产生的力（指向可行域内部）。
    x: 当前末端位置(3,)  b: 面上一点  n: 外法向(单位向量)"""
    d = float(np.dot(x - b, n))        # 到头边界的带符号距离
    if d >= d0:
        return np.zeros(3)             # 未进入缓冲带：完全不干预
    penetration = d0 - d
    # 用 max(0,·) 实现单侧激活；k_w=5000 N/m 是任务刚度(500)的 10 倍
    f = k_w * max(penetration, 0.0)
    return -f * n                      # 负号：力指向可行域内部（与 n 相反）

解读：注意这个函数天然处理了三个边界情形：远离（d≥d₀）返回零、刚好在缓冲带边缘（穿透量≈0）力连续地从零开始长出来、深穿透时线性增长。d0=10 mm 与 k_w=5000 的组合意味着：被外力压着时最多"陷进缓冲带"约 F/5000，20 N 的力只压进 4 mm，视觉上像撞在一面软垫上。真实实现里还会加墙阻尼（按临界阻尼公式算）避免冲击反弹。

片段 2：速度层投影（防越界 + 允许贴边滑动）

def project_velocity(v, x, walls):
    """对活动墙集合做速度投影。
    walls: [(b, n, d0), ...]；只拦"正在往外推"的法向分量。"""
    v_out = v.copy()
    for b, n, d0 in walls:
        d = float(np.dot(x - b, n))
        if d >= d0:
            continue                          # 未接近：该面不参与
        vn = float(np.dot(v_out, n))
        if vn > 0:
            # 法向分量指向界外 → 切除；切向分量原样保留（贴边滑行）
            v_out = v_out - vn * n
    return v_out

def corner_escape(v, x, walls, v_esc=0.02):
    """多面同时激活时给一个朝可行域内部的脱离速度。"""
    active = [n for b, n, d0 in walls if np.dot(x - b, n) < d0]
    if len(active) >= 2 and np.linalg.norm(v) < 1e-3:
        e = -np.sum(active, axis=0)           # 两法向之和的反方向
        return v_esc * e / (np.linalg.norm(e) + 1e-9)
    return v

解读：投影函数有意不做"减速"，它只砍掉越界分量，哪都不去的自由度留给任务本身。vn > 0 的判据保证从边界往回走时完全不干预（方向性）。角落逃逸的速度取 20 mm/s：足够让系统离开"死点"，又不至于看起来像抽搐。注意逃逸只在"速度已经接近零"时激活（很小时才启用），避免正常贴边滑行被误打断。

片段 3：把两者接入同一导纳循环

def compliant_step(x, v, f_ext, walls, adm, dt=1e-3):
    """一个完整周期：墙力 → 导纳动力学 → 速度投影 → 积分 → 兜底截断。"""
    # 1) 汇总外力：真实传感器力 + 所有活动墙的弹力
    f_total = f_ext.copy()
    for b, n, d0 in walls:
        f_total += wall_force(x, b, n, d0=d0)

    # 2) 导纳动力学（M dv = F - D v），墙力与外力走同一条通道
    v_new = v + (f_total - adm.d * v) / adm.m * dt

    # 3) 速度投影：防止下一周期的位置越过边界
    v_new = project_velocity(v_new, x, walls)
    v_new = corner_escape(v_new, x, walls)

    # 4) 积分 + 硬兜底（只有投影/墙都失效时才可能触发，属诊断事件）
    x_new = np.clip(x + v_new * dt, -adm.x_limit, adm.x_limit)
    return x_new, v_new

解读：这段代码的顺序就是设计意图本身，墙力在最前（进入动力学），投影在动力学之后（作用于"将要发生"的速度），硬截断在最后（兜底）。真实系统里还要对 x_new 做一次关节限位检查（任务空间可行 ≠ 关节可行），二者冲突时以关节限位为准，这将在 085 章展开。

常见坑

  • 硬截断不清速度：只夹住位置而速度照旧，机器人"顶"在边界上积累动能，约束解除瞬间弹射出去。要么投影速度，要么把墙建模成力。
  • 墙刚度选择极端：Kw 太小（与任务刚度同量级）会被穿透"陷进墙里"；太大（10⁶ 级）会让接触瞬间力冲击陡峭，与导纳惯性不匹配而振荡。5–10 倍任务刚度是稳妥区间。
  • 缓冲带方向搞反：n̂ 定义为外法向时，d 减小表示接近边界；符号弄反会变成"越界才报警"。建议对每个墙写一个 3 行的单元测试验证激活方向。
  • 多面同时激活只做一次投影：一次投影只保证第一个面不越界，对第二个面仍是"向外推"。必须迭代或按 075 章的分层框架处理；角落卡死就用逃逸逻辑。
  • 虚拟墙与真实力传感器耦合：如果操作员的手把机器人往墙里推，力传感器读数和墙力符号相反，调试时看"总力+墙力"的合力日志，不要把墙力误当传感器故障。

练习与思考

  1. 计算稳态穿透：操作员持续施加 15 N 把机器人往墙里压，Kw=5000 N/m。机器人在缓冲带内会"陷"多少毫米？如果希望不大于 2 mm，Kw 至少要多少？★
    提示
    Δ = F/Kw = 3 mm；要 ≤2 mm 则 Kw ≥ 7500 N/m。同时检查这仍是任务刚度的 5 倍以上。
  2. 推导对比：输出端硬截断 vs 虚拟墙，在"外力从 5 N 阶跃到 20 N"时的位置轨迹有什么本质差别？谁的加速度连续？★★
    提示
    硬截断：位置指令立刻停在边界，加速度是冲激（不物理）；虚拟墙：位置按二阶动力学平滑加深，加速度连续。用第一章的稳态与瞬态分析方法各自验证。
  3. 速度投影只砍 vn > 0 的分量。如果机器人已经在外界（因传感器跳变误入），这个判据会怎么表现？设计一个"回收模式"：允许反向（往回走）的速度通过。★★
    提示
    已经在界外时，往回走意味着 vn < 0，现有判据已经放行。真正要处理的是"界外还要往外走"的病态输入，加一个位置哨兵把投影无条件打开即可。
  4. 画一个二维可行域的角落（两面墙 90° 相交），任意给几个速度向量，手算两次投影后的结果，验证"角落死区"的存在，并说明逃逸逻辑中"两法向之和的反方向"为什么指向角落内部。 ★★★
    提示
    二维里数值实验最快：取 n₁=(1,0)、n₂=(0,1)（禁入区在右上方），任取几组 v 看投影后的切向空间。两法向之和 (-1,-1) 指向左下，可行域深处。
  5. 把虚拟墙的"阻尼"补上（现在片段里只有弹簧）：写出含阻尼的墙力并说明 Dw = 2√(KwMd) 从哪里来；再思考：如果墙的阻尼忘记加了，你会在实验里看到什么现象？★★★
    提示
    D_w 用与任务阻尼相同的临界阻尼公式（第一章）。缺阻尼 → 撞墙反弹振荡，力曲线像振铃；对照第 001 章练习 3 的结论。

小结

  • 柔顺行为必须配可行域约束；核心手段是"把边界当环境"（虚拟墙力）与"速度层投影"。
  • 虚拟墙公式 Fwall = Kw·max(0, d₀−d)，单侧激活、连续可导；参数取 5–10 倍任务刚度 + 临界阻尼。
  • 速度投影只拦"向外"分量，保留贴边滑行；多面同激活要迭代投影或分层处理，角落用逃逸速度脱离。
  • 实现顺序：墙力 → 导纳动力学 → 速度投影 → 兜底截断；异常数据全部进日志。
  • 下一章：位置限制的对偶问题，速度限制，它在导纳与阻抗里作用机理完全不同，而且"缩放速度"里藏着无源性的红线。
