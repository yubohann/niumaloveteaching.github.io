第四篇 · 高级柔顺任务与约束

第 070 章：阻抗控制中的惯性整形

把虚拟质量 M 从"固定常数"变成"设计变量"：用传递函数看清它控制什么频段，用能量守恒算出冲击力峰值，再学会定向惯性与时变整形的两条实操路径。

  • 主题：惯性整形 / 冲击力管理 / 时变参数
  • 关键公式：H(s) = 1/(Ms²+Ds+K)；Fpk ≈ v0√(M·Keff)
  • 预计学时：55 分钟
  • 前置章节：第 069 章

学习目标

  • 理解 Md 在频域里的作用：低频决定"弹簧感"、高频决定"惯性感"，转折频率 ωn = √(K/M)。
  • 会从能量守恒推导冲击力峰值公式 Fpk ≈ v0√(M·Keff)，并能据此由"允许峰值力"反推 M 的上限。
  • 理解小惯性带来的噪声代价：加速度噪声 ∝ Fnoise/M，并知道 M 有"不能低于实际笛卡尔惯量一定比例"的下界。
  • 会设计定向惯性：M = R·diag(mt,mb,mn)·RT，按任务方向分配"轻/重"。
  • 会做时变惯性整形：平滑混合、变化速率限制，以及用 ½Ṁẋ² 估计"改质量"引入的能量。
  • 能根据任务状态（自由/接触）自动切换惯性，并说明切换逻辑为什么必须渐变。

背景与动机

从 ch001 开始，Md 一直被当作"选个 1 kg 就行"的配角。但它其实握着三个关键指标：冲击力峰值（越小越安全）、响应速度（越小越灵敏）、力噪声放大（越小越抖）。这三个指标方向冲突，而 M 是能在同一套 K、D 框架内调节它们的旋钮，这就是"惯性整形"（inertia shaping）：不与刚度、阻尼抢活，专门管理"质量"这一维。

它的典型应用都很实际：机械臂从 30 cm/s 接近工件，希望接触瞬间峰值力不超过 15 N，由公式反推 M 的上限；在自由空间希望动作轻快、在接触阶段希望沉稳，按状态切换惯性；打磨时希望沿法向"轻"（少冲击）、沿进给方向"重"（抗扰动），定向惯性。本章把这些用法收敛成两条主线：传递函数看频段，能量守恒管冲击。

核心原理

1. 传递函数：M 管的是高频段

把阻抗看作外力到位移的传递函数：

H(s) = 1 / (M s2 + D s + K)， ωn = √(K/M)，ζ = D/(2√(KM)) 低频 |H| → 1/K（弹簧区）；高频 |H| → 1/(Mω²)（惯性区）

两个频段的物理读法：在远低于 ωn 的频率上，外力对应静态偏移 x = F/K，M 几乎不出现；在远高于 ωn 的频率上，系统来不及响应刚度，只有质量在起作用，加速度 a = F/M。M 的整形就是移动两个频段之间的转折点：M 减小使 ωn 增大，惯性区"变小"、弹簧区"变宽"，机器人对中频外力开始表现为弹簧特性，惯性墙般的阻挡感随之消退。冲击本质上是一个"高频事件"（接触瞬间的力上升沿相当于宽频谱激励），所以冲击行为主要由 M 决定，这是下一节的定量化。

另外注意 M 与 D 的耦合：若只调 M 不动 D，ζ = D/(2√(KM)) 会随之变化，M 减半，阻尼比上升 √2 倍，手感变"黏"。所以惯性与阻尼应联动：改 M 时同步把 D 按 2ζ√(KM) 重算，让 ζ 保持设计值，才是"只改质量、不改性格"的整形。

2. 冲击力峰值：能量守恒给出的一行公式

接触瞬间动能全部转成弹性势能（阻尼耗散的一小部分先忽略，得到保守估计）。撞向环境时，串联刚度 Keff = KKenv/(K+Kenv) 在起作用：

½Mv02 = ½Keffxpk2  ⟹  Fpk = Keffxpk = v0√(M·Keff) v0：接触瞬间速度 m/s；Kenv ≫ K 时 Keff ≈ K

数字感受：v0 = 0.1 m/s、K = 500 N/m、M = 1 kg 时 Fpk ≈ 0.1×√500 ≈ 2.2 N；M 加到 5 kg，峰值涨到约 5 N。反过来用：允许峰值 15 N、v0 = 0.3 m/s 时，M ≤ (15/0.3)²/500 = 5 kg。这条公式把"安全接触"变成选型问题，不再依赖碰运气。工程直觉：冲击力随 M 的平方根增长，把 M 减到 1/4，峰值减半；想让峰值减到 1/3，M 要降到 1/9。

3. 噪声与内环：M 的下界来自哪里

测力噪声 fn（0.1 N 量级）经阻抗变成加速度 a = fn/M：M = 0.2 kg 时是 0.5 m/s²，M = 1 kg 时降到 0.1 m/s²。小 M 的诱惑（敏捷、低冲击）必须在噪声预算内兑现，否则位置指令高频抖动、关节听着"沙沙"响。除了噪声，还有一条更硬的下界：内环不是无限带宽的理想位置源，它自己的等效笛卡尔惯量 Mreal = (J Mq−1JT)−1 与虚拟的 M 必须"量级相容"。经验规则：Md ≥ 0.1·Mreal。虚拟质量比真实惯性小一个数量级以上时，阻抗模型要求内环产生的加速度超过它的能力，实际运动跟不上数学，等效于引入严重滞后，现象和"M 太小"的噪声抖动叠加在一起，很难拆开，所以先把下界守住。

4. 定向惯性：把"轻重"分配到你想要的方向

与刚度一样，惯性也可以有方向：M = R·diag(mt,mb,mn)·RT，把 M 的特征椭球按任务坐标系对齐。两条典型策略：
法向轻、切向重（打磨/擦洗）：法向 mn = 0.5 kg 让接触更柔和、冲击更小；切向 mt = 3 kg 让摩擦扰动推不动工具，速度更稳。
进给方向轻、约束方向重（装配）：沿进给轴 m = 0.5 kg 便于快进快退，横向重（1.5–3 kg）抗侧向噪声。
实现方式与 ch064 的刚度矩阵完全同构（相似变换），只需保证特征值均为正、并让阻尼也按同一 R 旋转。代价是标定与调试维度变多，建议每次只改一个方向，用"推一推、看响应"的小试验验证直觉。

5. 时变惯性：可以切换，但必须平滑

按状态切换 M（自由空间 3 kg 顺滑、接触阶段 0.5 kg 柔和）很实用，但直接跳变会在指令位置或速度上产生冲击。更本质的问题是能量：质量变化对系统功的贡献是 dE = ½Ṁẋ²dt，瞬时改变质量相当于向系统注入/抽取能量。用 Ṁ 的连续性控制它：M 以 ≤ 0.5 kg/s 变化、ẋ = 0.05 m/s 时功率仅 ½×0.5×0.0025 ≈ 0.6 mW，比执行器能力小三个数量级，可以忽略；而"10 ms 内从 0.5 跳到 3 kg"等效于毫秒级注入几十毫焦，足以激起明显的振动。实现上用一阶混合 m(t) = m1 + (m2−m1)(1−e−t/T)，T 取 0.2–0.5 s；同时把 D 同步整形（上一节），运动方程中再加一项 ½Ṁ·ẋ 做被动性修正的话，就与"多体系统变质量"的严格形式一致了，教学实现里参数变化够慢时，这一项可略。

实现思路与设计

  1. 先定任务约束：由接触速度与允许冲击力算出 Mmax；由噪声预算与内环惯量算出 Mmin；把区间交给下一步。例：v0 = 0.2 m/s、Fpk ≤ 10 N、K = 500 N/m → Mmax = (10/0.2)²/500 = 5 kg；Mreal = 2 kg → Mmin = 0.2 kg。
  2. 在区间内选起点：一般取 0.5–2 kg；需要更快响应取小值、需要抗扰动取大值。
  3. 联动阻尼：D = 2ζ√(KM)，ζ = 0.8–1.0；每改 M 一次重算 D，否则"改质量顺手改了手感"。
  4. 必要时定向：建任务坐标系 R，M = R·diag(mt,mb,mn)·RT，D 同构；三向特征值都校验正。
  5. 状态切换：接触检测（力超阈值 > 1 N 持续 20 ms）触发"接触惯性"，离开接触 0.5 s 后恢复"自由惯性"；切换用时间常数 0.3 s 的一阶混合。
  6. 验证：用示波器式记录接触瞬间力峰值（应以 20% 精度复现公式）、噪声引起的加速度幅值、切换前后 1 s 的力曲线是否平滑。
一条实用的"惯性预算"口诀

冲压看峰值 → 定上限；听声看噪声 → 定下限；手感看 ζ → 联动阻尼；方向看任务 → 定向整形；切换看平滑 → 限速率。五个问题问完，M 的取值基本唯一。

关键代码与解读

片段 1：由冲击指标反推惯性上限

import numpy as np

def inertia_budget(v0, F_peak_max, K, M_real=None, margin=0.1):
    """由接触速度、允许峰值力与刚度，反推虚拟质量的可用区间。"""
    M_max = (F_peak_max / v0) ** 2 / K      # 由 F_pk = v0*sqrt(M*K) 反解
    M_min = margin * M_real if M_real else 0.2
    if M_min >= M_max:
        print("警告：噪声/内环下界已超过冲击上限，必须先降 v0 或降 K")
    print(f"接触速度 {v0:.2f} m/s，允许峰值 {F_peak_max:.0f} N，K={K:.0f} N/m")
    print(f"M 可用区间: [{M_min:.2f}, {M_max:.2f}] kg")
    for M in (M_min, (M_min + M_max) / 2, M_max):
        D = 2.0 * np.sqrt(K * M)             # 临界阻尼：与 M 联动
        print(f"  M={M:4.2f} kg -> D={D:6.1f} N.s/m, "
              f"f_n={np.sqrt(K/M)/(2*np.pi):4.2f} Hz, 预计峰值={v0*np.sqrt(M*K):5.1f} N")
    return M_min, M_max

inertia_budget(v0=0.2, F_peak_max=10.0, K=500.0, M_real=2.0)

解读：函数把两个下界与一个上界放在同一张表里输出，最后一列"预计峰值"让你当场验证公式与直觉。注意 M_min >= M_max 的警告分支不是防御性编程的摆设，它对应一类真实的立项问题："要求 30 cm/s 接触且峰值不超过 5 N，但臂本身的反射惯量就有 2 kg"，这时无论怎么调软件都做不到，必须在任务速度或机构上让步。把这类冲突在参数表阶段就显式暴露，是惯性整形的第一价值。

片段 2：冲击仿真的数值验证（扫 M）

k_env, v0, dt = 1.0e5, 0.10, 1e-4       # 刚性墙面、0.1 m/s 接触、0.1 ms 步长

def impact_peak(M, K=500.0, T=0.4):
    """从接触瞬间开始积分：初始速度 v0、穿透为零，记录峰值力。"""
    D = 2.0 * np.sqrt(K * M)            # 阻尼联动：只改 M 不改手感
    x, v, peak = 0.0, v0, 0.0
    for _ in range(int(T / dt)):
        f_env = k_env * x if x > 0.0 else 0.0    # 单向接触：只有压入才有力
        # 阻抗方程（外力为环境反力，指向 -x）：M a = -f_env - D v - K x
        a = (-f_env - D * v - K * x) / M
        v += a * dt
        x += v * dt
        peak = max(peak, f_env)
    return peak

K = 500.0
for M in (0.5, 1.0, 2.0, 5.0):
    pk = impact_peak(M)
    theory = v0 * np.sqrt(M * (K + k_env))
    print(f"M={M:4.1f} kg  仿真峰值={pk:5.2f} N  理论={theory:5.2f} N")

解读：仿真与理论列的对照是本段的核心，两列偏差在 10% 上下，说明"忽略阻尼耗散的保守估计"足够准；若你的仿真里峰值比理论大很多，检查 dt 是否过大（接触刚度 k_env = 105 N/m 时，1e-4 步长的显式积分才稳）。f_env = k_env*x if x > 0 的单向写法还原了"墙不会拉住你"这一物理事实，若写成双向弹簧，机器人会被"粘"在墙上振荡，峰值统计失真。把 M 从 0.5 拉到 5，峰值只涨 √10 ≈ 3.2 倍，远低于质量 10 倍的涨幅：这是平方根规律的直接观察。

片段 3：状态切换的惯性整形（平滑 + 能量检查）

class InertiaShaper:
    """按任务状态平滑整形虚拟质量：自由空间沉稳、接触阶段轻快。"""
    def __init__(self, m_free=3.0, m_contact=0.6, K=500.0, zeta=1.0,
                 T_blend=0.3, dt=1e-3):
        self.m_free, self.m_contact = m_free, m_contact
        self.K, self.zeta, self.T_blend, self.dt = K, zeta, T_blend, dt
        self.m = m_free                 # 当前虚拟质量（连续变化）
        self.in_contact = False

    def update(self, f_meas, v_est):
        # 接触检测带滞环：>1 N 进入、<0.3 N 退出，避免阈值附近抖动
        if not self.in_contact and abs(f_meas) > 1.0:
            self.in_contact = True
        elif self.in_contact and abs(f_meas) < 0.3:
            self.in_contact = False
        m_target = self.m_contact if self.in_contact else self.m_free
        # 一阶混合：m_dot 被 T_blend 限制，避免时变质量注入能量/冲击
        m_dot = (m_target - self.m) / self.T_blend
        self.m += m_dot * self.dt
        # 能量注入估计：dE/dt = 0.5*m_dot*v^2，监控它别超过功率预算
        p_inject = 0.5 * abs(m_dot) * v_est ** 2
        D = 2.0 * self.zeta * np.sqrt(self.K * self.m)   # 阻尼随 M 联动
        return self.m, D, p_inject

解读：p_inject 是这段代码最别致的输出，它把"改质量是否安全"变成一个可监控的物理量，把定性经验换成数字。典型数值：m 从 3 到 0.6 kg、T = 0.3 s 时 |ṁ| = 8 kg/s，v = 0.05 m/s 时注入功率 10 mW 量级，远低于执行器功率；若把 T 缩到 0.01 s，功率瞬间放大 30 倍，且离散积分也开始失真。滞环阈值（1.0 / 0.3 N）不能省：没有滞环时力在阈值附近的噪声会让 m_target 每毫秒翻转，混合器被持续激励，输出质量在 3 与 0.6 之间来回荡，等效于给系统加了一个持续扰动。

常见坑

  • 只改 M 不改 D：以为"整形惯性"只动一个数，结果阻尼比随 M 变化（M 减半、ζ 涨 √2），手感变黏或变颤。修复：D 与 M 联动，按 2ζ√(KM) 同步更新。
  • M 调到远小于实际惯量：数学上任意小都"稳定"，实现上内环跟不上，等效大滞后 + 噪声放大，接触时先抖后振。修复：Md ≥ 0.1·Mreal，并把内环带宽一起核对。
  • 时变 M 无速率限制：状态切换时瞬时改质量，看似响应快，实为毫秒级能量注入，接触瞬间力曲线出现尖峰。修复：一阶混合 0.2–0.5 s；监控 ½Ṁẋ²。
  • 定向惯性的特征值校验缺失：R 拼接错误或特征值给了负数，出现方向性的"倒质量"（该方向加速度反号），立刻发散。修复：构造后 eigvalsh(M).min() > 0 断言，R 做正交性检查。
  • 用冲击公式时拿错 K：把任务 K 直接代入，忘了环境刚度串联后 Keff 略小；在软环境（Kenv ≈ K）下峰值被高估最多 √2 倍。修复：用 Keff = KKenv/(K+Kenv)，或对峰值给 20% 的保守余量。

练习与思考

  1. 从能量守恒推导 Fpk = v0√(M·Keff)，并说明为什么峰值力只随 M 的平方根增长。 ★
    提示
    动能 ½Mv² 全部转为弹性能 ½Keffx²，峰值为 Keffx；由 x ∝ √(M/Keff) 即得。
  2. 实验：固定 K = 800 N/m、v0 = 0.15 m/s，扫 M = 0.3/1/3/8 kg，用片段 2 记录峰值与到达峰值的时间，回答"更小的 M 是让冲击更快还是更慢"。 ★★
    提示
    M 小则峰值低但到达更快（√(M/K) 的时间尺度）；"轻"获得的是低幅、短促的接触过渡。
  3. 计算题：给定 M = 0.5 kg、测力噪声 0.1 N（有效值）、噪声带宽 100 Hz，估算噪声引起的加速度有效值与位置抖动幅值（按 a/ω² 近似）。 ★★
    提示
    a = 0.1/0.5 = 0.2 m/s²；在 100 Hz 处位移 ≈ a/ω² = 0.2/(628²) ≈ 0.5 μm，量级很小，但经内环微分链路放大后不可忽略，提示你要看的是指令抖动，理想位移本身可忽略。
  4. 设计：打磨任务要求法向峰值 ≤ 6 N（v0 = 0.2 m/s、Kn = 400 N/m），同时切向抗扰动要"重"到 2.5 kg。写出 M 的方向矩阵（含特征值与 R 的形式）、D 的三轴取值，并说明为什么两个要求能同时满足。 ★★★
    提示
    法向 Mmax = (6/0.2)²/400 = 2.25 kg，取 0.6；切向直接取 2.5；M = R·diag(2.5, 2.5, 0.6)·RT，方向解耦让两种需求互不干扰。
  5. 思考题：为什么说"惯性是同一套框架内最便宜的手感旋钮"？从"K 受环境与稳定性约束、D 由 ζ 决定、M 相对自由"三个角度各写一句。 ★★
    提示
    K 有明确的力/安全含义、改它牵一发动全身；D 通常被 ζ 绑住；M 可以大范围移动转折频率且主要影响高频与冲击，副作用集中、可测。

小结

  • Md 在传递函数 H(s) = 1/(Ms²+Ds+K) 中掌管高频段与转折频率 ωn = √(K/M)：它是"惯性感"与"冲击行为"的旋钮。
  • 冲击峰值 Fpk ≈ v0√(M·Keff)：与 M 的平方根成正比，是"反推 M 上限"的依据。
  • M 的下界来自噪声放大（a = fnoise/M）与内环惯量比（M ≥ 0.1·Mreal）。
  • 定向惯性 M = R·diag(·)·RT：法向轻、切向重是打磨类任务的常用配方。
  • 时变惯性必须平滑（一阶混合 0.2–0.5 s）并联动阻尼；用 ½Ṁẋ² 监控能量注入。
