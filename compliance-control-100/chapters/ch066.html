第四篇 · 高级柔顺任务与约束

第 066 章：阻抗控制中的姿态柔顺

让工具不仅会"平移让位"，还会"转角让位"：用旋转矩阵与对数映射表达姿态误差，把旋转阻抗写成 Kθ·δθ 的形式，并说清量级、各向异性与积分表示这三件事。

  • 主题：姿态柔顺 / SO(3) 姿态误差 / 旋转阻抗
  • 关键公式：Idω̇ + Dθω + Kθδθ = τext，δθ = log(RdTR)
  • 预计学时：60 分钟
  • 前置章节：第 065 章

学习目标

  • 理解姿态柔顺的必要性：姿态偏差与环境旋转刚度相乘会产生远超手腕能力的大扭矩。
  • 会用旋转矩阵误差 RdTR 与对数映射 δθ = log(RdTR) 表达姿态误差，并知道小角度与近 180° 的数值处理。
  • 会写出旋转阻抗方程，理解转动惯量 Id（kg·m²）、旋转阻尼（N·m·s/rad）、旋转刚度（N·m/rad）的单位与典型量级。
  • 会做工具坐标系下的各向异性刚度设计：拧紧轴要硬、对准轴要软，并用相似变换换到世界系。
  • 会用 SO(3) 指数映射积分姿态、定期重正交化，避免姿态矩阵"漂成"剪切变形。
  • 会算清重力力矩与工具长度对手腕载荷的贡献，知道什么时候必须先做力矩补偿。

背景与动机

先算一笔账。轴孔装配中常见的姿态偏差是 1°（0.0175 rad）。如果姿态环保持刚性，环境的旋转刚度按 Kθ,env ≈ 5000 N·m/rad 估计，侧向接触产生的力矩是 5000×0.0175 ≈ 87 N·m，这已经超过多数协作臂腕部关节的额定力矩，机器人要么报警停机，要么用全身去"顶"这个力矩，把零件压坏。若姿态是柔顺的，同样的偏差只产生 Kθδθ = 30×0.0175 ≈ 0.5 N·m 的恢复力矩，工具自己就能被工件"扶正"。

位置柔顺解决"推得动"，姿态柔顺解决"转得动"。打磨时工具要自动贴合曲面切平面，插轴时轴要自动对准孔轴，装配薄壁件时接触力产生的力矩要能被吸收、不被放大，这些都要求机器人对外来力矩表现出可控的旋转顺从。本章把 ch001 的质量-弹簧-阻尼方程"复制"到旋转上去，但姿态有它自己的数学：旋转矩阵、对数映射与积分方式，一个都不能含糊。

核心原理

1. 旋转阻抗方程：把二阶动态搬到 SO(3) 上

平移阻抗有三要素：期望轨迹、误差、增益。旋转的情形平行地写为：

Id ω̇ + Dθ ω + Kθ δθ = τext ω：角速度 rad/s；δθ：姿态误差向量 rad；τext：外力矩 N·m

参数的量纲读法：Id 是虚拟转动惯量（kg·m²，典型 0.02–0.2，手腕尺度下取大值会迟钝、小值会被噪声驱动）；Dθ 是旋转阻尼（N·m·s/rad，用临界阻尼 Dθ = 2√(KθId) 起步）；Kθ 是旋转刚度（N·m/rad，典型 5–100）。旋转刚度的物理含义：偏差 1 rad 时"顶回来"的力矩大小；工程上先问"允许多大的稳态偏转角 δθallow"，再按 Kθ = τ/δθallow 反推刚度。例如接触力矩 3 N·m、允许工具下垂 0.1 rad（约 5.7°），则 Kθ ≥ 30 N·m/rad。

2. 姿态误差怎么算：RdTR 与对数映射

姿态不能像位置那样做减法。设当前姿态 R、期望姿态 Rd（都是 3×3 旋转矩阵），最常用的误差定义是

Re = RdT R，  δθ = log(Re) = θ·u θ ∈ [0,π]：需要的转角；u：转轴单位向量；δθ 是三维向量

它的意义：把 Re 表示为"绕轴 u 转 θ"就能从期望姿态到达当前姿态，δθ 就是这个旋转的轴角向量。数值上 log 有闭式：对 θ ≠ 0,π，δθ = θ/(2sinθ)·vee(Re − ReT)；对小角度，因子 θ/(2sinθ) → 1/2，直接用 0.5·vee(Re−ReT) 即可，避免 0/0。两个必须处理的坑：一是 θ 接近 π 时分母 sinθ → 0，需要用 (Re+I)/2 的列向量去找转轴；二是要区分 RdTR 与 RdRT，前者给"在期望坐标系里表达"的误差，后者反号，用它算出的力矩方向相反，表现为工具朝错误方向倒。

四元数表示也常用：误差四元数 qe = qd−1⊗q，转轴向量近似 2·vec(qe)·sign(qe.w)；注意那个符号修正，当 qe 的标量部分为负时说明走的是"长弧"，不修正会让工具在接近 180° 时突然翻转。为了少一类坑，本章统一用矩阵 + log，四元数在姿态导纳一章对比。

3. 力矩从哪里来：工具长度就是杠杆

姿态柔顺读的是力矩，而力矩有两个来源要分清：接触力矩与重力力矩。接触力矩常常是"力乘杠杆"：工具尖侧向受力 f，工具长 L，则施加在法兰上的力矩约 L·f。L = 0.15 m、f = 20 N 时就是 3 N·m，已经接近前述 30 N·m/rad 刚度下的允许量级。重力力矩更隐蔽：质量 2 kg、质心偏置 0.15 m，静态重力矩 9.81×2×0.15 ≈ 2.9 N·m，和典型接触力矩同量级。若不做补偿，姿态柔顺环会把"重力想让工具低头"当成"工件要我低头"，稳态时工具带着一个恒定倾角工作。

还有裁剪问题：旋转阻抗解出的力矩只是"内部控制目标"，真正下发到手腕的关节力矩是 τ = JrotT·τcmd，必须在关节侧检查限幅与耦合（第 079 章展开）。Kθ 的选择因此有三重约束：稳态下垂角、手腕力矩上限、以及旋转内环的稳定性。

4. 各向异性与坐标系：哪些轴该软，哪些轴该硬

姿态柔顺几乎总是各向异性的，而且通常在工具坐标系里描述：插轴的例子，两根垂直于轴线的方向要软（让轴自动对准孔），绕轴线的旋转要硬（保持插入方向、传递拧紧力矩）；打磨的例子，绕工具两轴的倾斜要软（贴合曲面），绕工具轴的自转要硬（转速或角度受控）。记工具系下的对角刚度 Kθ,tool = diag(kx, ky, kz)，则世界系中的力矩目标为：

τcmd = R · Kθ,tool · (RT δθ) 先把误差旋到工具系"按轴分配刚度"，再把结果力矩旋回世界系

注意 RTδθ 这一步：把世界系的姿态误差投影到工具三轴上，各轴乘上各自的刚度，再合成回世界系。等价写法 τ = (R Kθ,tool RT)·δθ，括号里就是世界系里的、带方向的旋转刚度矩阵。数值例：Kθ,tool = diag(4, 4, 20) N·m/rad，工具系 z 轴沿插入轴，横向两轴 4 N·m/rad 意味着 1 N·m 横向接触力矩产生 0.25 rad 的倾斜容纳量，插入轴 20 N·m/rad 保证拧紧时不打滑。

5. 姿态怎么积分：用指数映射，别做加法

算出力矩，得到角加速度，积出角速度 ω，最后要把 ω 累积进姿态。正确做法是 SO(3) 指数映射：Rk+1 = Rk·exp([ωb]Δt)（ωb 为工具体系角速度，[·] 为反对称矩阵）。为什么不能写 R + [ω]Δt·R？因为旋转矩阵的约束是 RTR = I 且 det R = 1，加法更新不满足约束，几步之后矩阵就"长出"缩放和剪切分量：算出的姿态误差、进而力矩全是错的，症状是工具缓慢自旋、姿态越来越歪却找不到增益问题。指数映射在数学上严格保持在 SO(3) 上（数值误差只是缓慢漂移），同时每 1–2 秒做一次重正交（SVD 或 Gram-Schmidt）把浮点漂移清零，是实践中的标准组合拳。

实现思路与设计

  1. 约定坐标系：明确 ω 在哪个系、τ 在哪个系表达，本章统一：力矩与误差在世界系表达（由工具系刚度旋转而来），角速度取工具体系，积分用 exp 右乘。
  2. 读力矩：法兰力矩传感器读数先扣除工具重力矩、并把力矩参考点从法兰平移到工具作用点（力矩搬运公式 mtip = mflange − r×f，第 068 章细讲）。
  3. 算误差：Re = RdTR，log 映射（含小角度分支与近 π 保护）得到 δθ。
  4. 解阻抗：τcmd = Kθ,world·δθ + Dθω + Idω̇ 的积分形式；参数初值 Id = 0.05 kg·m²、Kθ 按"允许下垂角"反推、Dθ = 2√(KθId)。
  5. 限幅：τcmd 每轴限幅（如 ±10 N·m），再做 JrotT 映射到关节力矩并检查关节上限。
  6. 积分姿态：ω ← ω + Id−1(τext − Dθω − Kθδθ)Δt；R ← R·exp([ω]Δt)；每 1–2 s 重正交化。
参数速查：从任务反推 Kθ

插轴对准：Kθ 横向 3–8、轴向 15–30 N·m/rad；曲面贴合：两轴 5–15；装配拧紧：轴向 50–100。统一原则：用稳态下垂角 δθss = τmax/Kθ 校验，下垂角必须小于任务允许的失配角，否则工具"软到对不上"。

关键代码与解读

片段 1：姿态误差的对数映射（含小角度与近 180° 保护）

import numpy as np

def vee(M):
    """反对称矩阵取逆映射：返回三维向量。"""
    return np.array([M[2, 1] - M[1, 2], M[0, 2] - M[2, 0], M[1, 0] - M[0, 1]]) * 0.5

def rot_error_log(R, R_d):
    """姿态误差向量 dtheta = log(R_d^T R)，单位 rad。"""
    Re = R_d.T @ R                       # 误差：把 R_d 带到 R 的旋转
    c = 0.5 * (np.trace(Re) - 1.0)
    c = min(1.0, max(-1.0, c))           # trace 的数值误差可能超出 [-1,1]
    theta = np.arccos(c)
    if theta < 1e-6:
        # 小角度：theta/(2sin) -> 1/2，直接用反对称部分，避免 0/0
        return 0.5 * vee(Re - Re.T)
    if theta > np.pi - 1e-3:
        # 近 180 度：sin(theta) -> 0，换用 (Re+I)/2 的列找转轴
        A = (Re + np.eye(3)) * 0.5
        u = A[:, int(np.argmax(np.diag(A)))]
        u = u / np.linalg.norm(u)
        return u * theta if vee(Re - Re.T) @ u >= 0 else -u * theta
    return theta / (2.0 * np.sin(theta)) * vee(Re - Re.T)

解读：三个分支各对应一类数值溃点：小角度时 θ/(2sinθ) 是 0/0；近 180° 时 sinθ → 0 使因子爆炸；trace 的浮点误差可能让 arccos 的输入越出 [−1,1]。习惯上把这段函数称为"姿态代码的三道保险"，它是整个姿态柔顺里最值得写单元测试的地方，随机生成 104 组姿态对，验证 log 与 exp 的往返误差小于 1e-9，再人为构造 0.001° 与 179.99° 两组边界姿态确认分支正确。注意 vee 里乘了 0.5：反对称矩阵 (R−RT) 的元素是 2sinθ·u，取半才能得到 sinθ·u 再乘因子，漏掉它会得到双倍的误差向量。

片段 2：旋转阻抗一步（解力矩 + 积分角速度与姿态）

def exp_so3(w, dt):
    """Rodrigues 公式：指数映射 exp([w*dt])，保持 SO(3) 结构。"""
    phi = w * dt
    th = np.linalg.norm(phi)
    if th < 1e-9:
        K = np.array([[0, -phi[2], phi[1]],
                      [phi[2], 0, -phi[0]],
                      [-phi[1], phi[0], 0]])
        return np.eye(3) + K            # 一阶近似，误差 O(th^2)
    K = np.array([[0, -phi[2], phi[1]],
                  [phi[2], 0, -phi[0]],
                  [-phi[1], phi[0], 0]]) / th
    return np.eye(3) + np.sin(th) * K + (1 - np.cos(th)) * (K @ K)

class RotationalImpedance:
    """旋转阻抗：I*w. + D*w + K*delta = tau_ext，姿态用 exp 右乘积分。"""
    def __init__(self, K_theta=(4.0, 4.0, 20.0), I_d=0.05, zeta=1.0, dt=1e-3):
        self.K_tool = np.diag(K_theta)          # 工具系各向异性刚度
        self.I_d = I_d
        # 阻尼按工具系每轴临界阻尼起步：D = 2*zeta*sqrt(K*I)
        self.D_tool = np.diag(2.0 * zeta * np.sqrt(np.array(K_theta) * I_d))
        self.dt = dt
        self.w = np.zeros(3)                    # 工具体系角速度
        self.R = np.eye(3)                      # 当前姿态（命令姿态）
        self._since_reorth = 0.0

    def step(self, R_d, R_meas, tau_ext):
        # 误差在世界系：先把测量姿态与期望姿态做误差，再旋到工具系分配刚度
        dtheta_w = rot_error_log(R_meas, R_d)
        tau_cmd = self.R @ self.K_tool @ (self.R.T @ dtheta_w) \
                  + self.R @ self.D_tool @ (self.R.T @ self.w)
        # 期望角加速度 = (外来力矩 - 阻尼项 - 刚度项)/惯量，再积分出角速度
        tau_net = tau_ext - (self.R @ self.D_tool @ (self.R.T @ self.w)) \
                  - (self.R @ self.K_tool @ (self.R.T @ dtheta_w))
        self.w = self.w + tau_net / self.I_d * self.dt
        self.R = self.R @ exp_so3(self.w, self.dt)   # 右乘：绕工具体系轴转
        self._since_reorth += self.dt
        if self._since_reorth > 1.0:                 # 每秒重正交一次
            U, _, Vt = np.linalg.svd(self.R)
            self.R = U @ Vt                          # 把浮点漂移清零
            self._since_reorth = 0.0
        return tau_cmd, self.R

解读：注意 tau_cmd 只用于监控/限幅，闭环真正用的是 tau_net，"命令力矩"与"净力矩"在阻抗框架里是两笔账：前者是弹簧-阻尼器对外发出的力矩，后者是虚拟质量块看到的合力。两者若混用，惯量项会被重复计入，等效于凭空加了一倍阻尼。重正交化每 1 秒一次，不必每步：SVD 不便宜，而指数映射的漂移率在 1 kHz 下约 1e-9/步，1 秒积攒的偏差仍在 1e-6 量级，对力控无影响。工具系调参的好处在这段代码里体现得很直接：把 K_theta 改成 (8, 8, 5) 再跑，插轴阶段"绕轴更自由、绕横向更硬"'的行为变化与直觉一致。

片段 3：从任务指标反推刚度，一个小标定脚本

def design_theta_gains(tau_max=(3.0, 3.0, 5.0), droop_max_deg=(10.0, 10.0, 3.0),
                       I_d=0.05):
    """输入：各轴最大接触力矩与允许下垂角；输出：K_theta 与阻尼初值。"""
    droop = np.radians(droop_max_deg)
    K_min = np.array(tau_max) / droop          # 由 delta = tau/K 反推下界
    K = np.ceil(K_min * 1.2)                   # 留 20% 裕度再圆整
    D = 2.0 * np.sqrt(K * I_d)                 # 临界阻尼
    for i, ax in enumerate("xyz"):
        print(f"{ax} 轴: K={K[i]:6.1f} N.m/rad  D={D[i]:5.2f} N.m.s/rad  "
              f"tau_max={tau_max[i]:.1f} N.m 下垂={droop_max_deg[i]:.0f} deg")
    return K, D

design_theta_gains()
# 输出示例：x/y 轴 K=21.0（3 N.m 下垂 10 度）；z 轴 K=115.0（5 N.m 下垂 3 度）

解读：这段脚本把"调参"变成"填指标"，你只需要回答两个工程问题：这个轴最大会遇到多大力矩（由外力与力臂、腕部限幅与工艺决定）、允许它偏多少度。得到的 K 再回填片段 2。注意 z 轴（插入轴）的刚度比横向大近 5.5 倍：这正是"轴向硬、横向软"的量化表达，参数不需要凭感觉试。若算出的 K 超过了旋转内环能稳定跟踪的范围（经验上 Kθ ≤ 0.1×内环旋转刚度），说明任务允许的下垂角太小、或内环带宽不足，必须回到机构与带宽层面解决；继续加大控制器刚度只会把问题推向失稳。

常见坑

  • 用加法更新姿态矩阵：R ← R + [ω]Δt·R 几步后矩阵不再正交，姿态误差与力矩计算全错，工具缓慢自旋。修复：一律用指数映射，定期 SVD 重正交；单元测试 R.T@R ≈ I。
  • 误差方向用反：RdRT 与 RdTR 混淆，力矩方向相反，工具往偏差更大的方向倒。修复：拿两个简单姿态（绕 z 转 10°）手工验证 log 的符号。
  • 四元数走长弧：直接用 2·vec(qe) 而没做 sign(qe,w) 修正，接近 180° 时工具突然翻半圈。修复：符号修正，或如本章统一改用矩阵 log。
  • 忘了重力力矩：2 kg 工具在 0.15 m 处产生约 2.9 N·m 常值力矩，全部被当成接触力矩进入柔顺环，工具恒定低头。修复：重力补偿先行；上电时工具静止的力矩读数应趋近零。
  • Kθ 只看稳定性、不看下垂：Kθ 太小（如 1 N·m/rad）时稳定无忧，但 3 N·m 接触力矩带来 172° 的"下垂"，工具根本对不上目标。修复：用 δθss = τ/Kθ 做任务级校验，先满足下垂要求再谈稳定。

练习与思考

  1. 证明：当 θ 很小时，log(Re) ≈ 0.5·vee(Re − ReT)，并给出下一阶修正项（提示：θ/(2sinθ) 的泰勒展开）。 ★
    提示
    vee(R−RT) = 2sinθ·u；乘 θ/(2sinθ) 得 θu；展开 sinθ 的泰勒级数得到系数 1/2·(1+θ²/6+…)。
  2. 设计实验：在一个虚拟插轴任务中（孔深 20 mm、间隙 0.2 mm），令横向 Kθ = 2 / 8 / 30 N·m/rad，记录插入成功率与插入时间，解释非单调趋势。 ★★
    提示
    太软：横向力无法把轴扶正（对中力矩不足）；太硬：接触力矩大、轴被"顶死"在孔沿；中间存在针对间隙与摩擦的最优区间。
  3. 推导：工具长 L、尖端侧向力 f 时，施加在法兰的力矩为 L·f（含方向说明）。若手腕允许力矩 τmax = 8 N·m、L = 0.12 m，允许的侧向力上限是多少？与 Kθ 的选择如何联动？ ★★
    提示
    f ≤ τmax/L ≈ 66 N；同时稳态下垂角 δθ = L·f/Kθ，两个约束联立给出 Kθ 的可行区间。
  4. 任务设计：打磨任务要求"贴合曲面倾斜 ±15°、绕工具轴角度受控到 ±2°"，接触力矩横向可达 4 N·m、绕轴可达 2 N·m。给出 Kθ,tool 三轴取值、阻尼初值与三轴的稳态下垂角。 ★★★
    提示
    横向 K ≥ 4/0.262 ≈ 15.3，取 20；绕轴 K ≥ 2/0.035 ≈ 57，取 70；D 用 2√(KI)，I 取 0.05。
  5. 思考题：为什么姿态积分必须用指数映射而不能用"欧拉角增量叠加"？从万向锁与矩阵约束两个角度各写一句。 ★★
    提示
    欧拉角在特定姿态附近奇异、增量与角速度的关系含三角函数耦合；矩阵加法破坏正交约束，二者分别死在表示与数值上。

小结

  • 姿态柔顺的必要性由数字决定：刚姿态环把 1° 偏差乘以环境旋转刚度变成近百牛·米的力矩，柔顺环把它压到零点几牛·米。
  • 旋转阻抗 Idω̇ + Dθω + Kθδθ = τext；单位分别是 kg·m²、N·m·s/rad、N·m/rad，Dθ 用 2√(KθId) 起步。
  • 姿态误差用 Re = RdTR 与 log 映射；小角度与近 π 两个分支必须显式处理。
  • 各向异性在工具系设计、用 R·Kθ,tool·RT 旋转到世界系；插轴"横向软、轴向硬"，打磨"倾斜软、自转硬"。
  • 姿态积分用 exp([ω]Δt) 右乘，定期重正交；否则矩阵漂移会毁掉全部力矩计算。
  • 下一章换实现路径：当机器人只有"力/力矩→姿态修正"这一条通路时，姿态调整由导纳完成，多出的是状态、死区与泄漏。
