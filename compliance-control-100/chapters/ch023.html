第二篇 · 参数调节与交互任务

第 023 章：力/位混合控制与阻抗控制比较

把"哪些自由度管位置、哪些自由度管力"显式拆开的力/位混合控制，与把所有自由度统一成动态关系的阻抗控制，是接触控制的两种世界观。本章推导选择矩阵，并把两者放在同一个谱系上比较。

  • 主题：力/位混合控制 / 控制框架对比
  • 关键公式：τ = JT[ S·ff + (I−S)·fp ]，S = diag(si)，si ∈ {0,1}
  • 预计学时：50 分钟
  • 前置章节：第 001 章、第 022 章

学习目标

  • 理解力/位混合控制（hybrid force/position control）的核心思想：在任务坐标系里按自由度（DOF）显式分配"管位置"或"管力"。
  • 会构造选择矩阵 S 并解释它的两个数学性质，幂等（S² = S）与互补（S + (I−S) = I），以及它们对应的物理含义。
  • 会把混合控制写成 JT 形式的关节力矩命令，并理解为什么力、位置两种控制量能在同一量纲（力矩）下相加。
  • 能把混合控制看作阻抗控制的极限情形（力方向 K→0 + 积分、位置方向 K→∞），从而说清两者"何时等价、何时不同"。
  • 面对一个具体任务（擦拭、倒角、砂带打磨），能根据接触几何、环境先验和任务精度要求选择合适的框架，并说出理由。

背景与动机

考虑擦桌子的机器人：抹布必须始终以 20 N 压住桌面（法向），同时在桌面平面内以 100 mm/s 走轨迹（切向）。这个任务天然是分工的，法向管力、切向管位姿，工程师脑海里已经把它拆开了。力/位混合控制就是把这种直觉直接写进控制律：每个自由度单独指定"这一维我控制力"或"这一维我控制位置"，用选择矩阵把它们装配起来。

而阻抗控制（第 001 章）走的是另一条路：对任何自由度都不"下死命令"，改为统一规定"机器人对外表现为质量-弹簧-阻尼"。两条路线在 20 世纪 80 年代同期成熟，至今仍是接触控制的两个基本框架。本章要说清楚：它们的差别不在"谁更先进"，而在信息结构，你愿意为任务提供多少先验（任务坐标系、接触方向），以及你希望系统在多大程度上依赖未知环境。理解了这层关系，你就知道什么时候该用哪一个。

核心原理

1. 选择矩阵：把 6 个自由度分给两种控制器

在一个任务坐标系（task frame，例如"桌面法向为 z、切向为 x-y"）里，定义 6×6 对角选择矩阵 S：

S = diag(s1, …, s6)，si ∈ {0, 1} si = 1：第 i 维实施力控制；si = 0：第 i 维实施位置控制

混合控制律把两种控制量在任务空间中相加，再经雅可比转置映射为关节力矩：

τ = JT(q) · [ S · ff + (I − S) · fp ] ff：力控制维的力命令（N/N·m）；fp：位置控制维等效的"力"命令 Kpep+Kdėp（N/N·m）

注意量纲：位置误差 ep（m）乘刚度 Kp（N/m）后就是力，所以两种控制量天然可以在同一向量里相加，其根源正是 JT 的物理意义：任务空间的力（矩）与关节力矩之间只差一个转置雅可比。这也是混合控制如此简洁的原因。

2. S 为什么必须幂等：一个自由度不能既管位又管力

S 的两条性质直接来自几何：S² = S（幂等）与 S + (I−S) = I（互补投影）。幂等的意义是"投影两次等于投影一次"，如果某个自由度既带位置增益又带力增益，写出来的命令就变成 S·ff + S·fp 的混叠，两个回路在同一个物理自由度上互相打架。为什么会打架？自由度计数：刚性接触每建立一条约束就"吃掉"一个自由度。压住桌面的方向已经被环境"锁住"，沿这个方向，位置由环境决定（你说不上算），力才是你能控制的对象；反过来，离面方向没有约束，力恒为零，你只能控制位置。想在同一个方向同时精确指定力和位置，等于要求环境既是刚性的又是可让位的，物理上自相矛盾。

3. 力方向的回路：IR 与积分

力控制维用经典的 PI 规律（以"参考位置调节"的等价形式写出，便于位置接口实现）：

ff = Kf,p(Fd − Fext) + Kf,i ∫(Fd − Fext) dt，或等价地 ẋf = kf(Fd − Fext) kf 单位 m/(N·s)，与第 022 章的 λf 是同一个量

积分项的作用与第 022 章完全一样：面位置未知，纯比例力控必有静差 Kseries·Δx；积分把静差磨到零。稳定性也继承第 022 章的结论：力回路增益上界 λmax = Dd(Kd+Kenv)/(MdKdKenv)，环境越硬，力环越不能快。这说明混合控制并没有"绕开"柔顺回路的稳定性问题，只是把位置维从柔顺回路里拿了出去。

4. 阻抗控制是"每个方向都柔顺"，混合控制是"要么无穷硬、要么零刚度"

把阻抗方程逐维展开：Md,iẍi + Dd,iẋi + Kd,i(xi−xd,i) = −Fi。现在看两个极限：

  • 位置控维：Kd,i → ∞，任何位置偏差都被极大的刚度"顶回"，等效于刚性位置伺服。这正是混合控制位置维的 PD 大增益。
  • 力控维：Kd,i → 0 且加积分，机器人对该方向偏差"毫不抵抗"，力的数值由参考位置（被积分推动）决定，等效于混合控制的力环。

所以：混合控制是阻抗控制取"每维极限刚度"后的特例；反过来说，阻抗控制是"软化"所有方向的混合控制。这也解释了工程现象：混合控制在已知接触几何（你能准确说出哪个方向是法向）时表现最好，因为 S 依赖任务先验；一旦接触方向变化（曲面、斜面、多面接触），S 失效，需要不断重构任务坐标系，而此时阻抗控制的"不需分解、全局柔顺"优势就出来了。曲面跟踪（第 064 章）就是典型例子：法向在走，S 是时变的，而"法向柔顺 + 切向跟踪"的自然写法就是阻抗/导纳。

维度力/位混合控制阻抗控制
控制对象每个自由度显式分配力或位置全方向统一的动态刚度关系
需要的先验准确的任务坐标系与接触方向粗略的期望刚度/阻尼量级
位置精度位置维高刚度，精度高有限刚度，受外力即偏移
力精度力维 PI，静差可为零需积分/参考自适应，否则有静差
稳定性焦点力维对硬环境敏感（增益受限）刚度比与阻尼设计决定裕度
几何变化需重构 S 或平滑过渡天然适应，无需切换
典型任务擦桌、倒角、砂带磨（法向力+切向位）装配、示教、人机协作、曲面抛光

实现思路与设计

实现顺序（假设力矩接口，若只有位置接口，把力维换成第 022 章的导纳形式即可）：

  1. 定义任务坐标系并写死接触方向：例如擦拭任务取"工件法向 z、切向 x-y"，则 S = diag(0,0,1,0,0,0)（只把 z 一维交给力控），或加上绕 x/y 的力矩维去适应曲面（s=1）。
  2. 建选择矩阵：用字符串描述（如 "PPPFPP"）生成 S 与 I−S，避免手工写 6×6 矩阵出错。
  3. 力维参数：kf = 5×10−3 m/(N·s)，相当于力环时间常数 1/(kfKseries) ≈ 0.25 s；先给 0.5×并留 5 倍以上稳定裕度。力信号 30 Hz 低通。积分限幅 ±20 mm（防"找不到面"时积分卷死）。
  4. 位置维参数：Kp = 5000 N/m、Kd = 100 N·s/m（比力维刚度大一个量级，体现"位置维尽量硬、力维尽量软"的分工）。
  5. 过渡混合：从自由空间接近到接触，硬切换 S 会让位置伺服带着接近速度"撞"进力环，产生力尖峰。把 si 在一段过渡时间 Tblend = 0.3 s 内从 0 平滑升到 1，位置指令速度同步降到接触速度（20 mm/s），力峰值可降一半以上。
设计决策：混合控制要不要"知道" Kenv？

力环的闭环增益里含 Kenv（力误差经过位置→环境变成力），因此整定力环时心里必须有一个 Kenv 的保守上界：按最硬工件（如 5×105 N/m 的钢件）算增益上界，再回到软工件上工作。这与阻抗控制把 Kenv 的影响"藏进刚度比"里是两种不同的工程处理方式，前者显式、后者隐式。

关键代码与解读

片段 1：选择矩阵与混合控制律

import numpy as np

def build_selection(axes):
    """axes 为 6 位字符串：'F'=力控制，'P'=位置控制，顺序 x,y,z,rx,ry,rz。"""
    s = np.array([1.0 if a == 'F' else 0.0 for a in axes])
    return np.diag(s), np.diag(1.0 - s)        # 返回 S 与 I-S 两个互补投影

def hybrid_wrench(x, v, f_meas, x_d, v_d, f_d, S, S_pos,
                  kp=5000.0, kd=100.0, kf=2.0):
    # 位置维命令：PD 展开为"等效力"（单位 N）；刚度大 => 位置维尽量硬
    f_pos = kp * (x_d - x) + kd * (v_d - v)
    # 力维命令：力误差直接反馈，kf 无量纲（力环 P 增益）
    # 注意：这一纯 P 形式有回弹静差，且增益不能大；位置接口版本
    # 请换成片段 2 的"参考位置积分"形式，才能对未知面位置免疫
    f_force = kf * (f_d - f_meas)
    return S @ f_force + S_pos @ f_pos         # 同一量纲(力)下相加，再送出

解读：build_selection 把易错的 6×6 矩阵交给一行代码生成，S @ f_force + S_pos @ f_pos 是整个混合思想的浓缩，两个互补投影把"力维"和"位置维"的贡献拼成一个完整力旋量。量纲一致性是本片段的关键：位置误差乘刚度后是力（N），力维的 P 反馈输出也是力（N），两者才能相加后经 JT 变成关节力矩；如果把力维写成"力误差乘 m/(N·s) 的速度量"，就会和位置维的量纲对不上，这也是很多新手实现混合控制时数值"能跑但不对"的根源。位置维的等效刚度（5000 N/m 量级）比力维的等效柔顺（Kseries≈800 N/m）大近一个量级，体现了"该硬的方向硬、该软的方向软"。

片段 2：力维的正确实现，限幅积分 + 抗饱和

class ForceAxis:
    """混合控制力维：PI 参考位置调节，含抗积分饱和。"""
    def __init__(self, kf=5e-3, dt=1e-3, x_span=0.04):
        self.kf, self.dt, self.x_span = kf, dt, x_span
        self.x_ref = 0.0          # 力维参考位置：积分状态
        self.sat_time = 0.0       # 连续饱和计时：用于诊断与保护

    def step(self, f_d, f_meas):
        e = f_d - f_meas
        v_ref = self.kf * e
        x_new = self.x_ref + v_ref * self.dt
        # 位置状态限幅 + 条件积分：只在未饱和(或误差方向回撤)时才继续积分
        if abs(x_new - self.x_ref) > 1e-9 and abs(x_new) >= self.x_span:
            if e * v_ref > 0:                 # 还在往饱和方向推：冻结积分
                self.sat_time += self.dt
            x_new = np.clip(x_new, -self.x_span, self.x_span)
        else:
            self.sat_time = 0.0
        self.x_ref = x_new
        return self.x_ref          # 输出：力维的参考位置（送到下位位置环）

解读：这就是第 022 章外环在"混合控制语境"下的重新命名，力维的核心状态落在被积分推着走的参考位置 x_ref 上。x_span = 40 mm 是安全行程：找不到面、或力传感器故障时，积分器最多把参考位置推到 40 mm 就停住，不会无限前进。条件积分（只在"还在增大力误差"的饱和方向冻结）是抗卷绕的标准做法：提前 3 行写对，比事后在真机上抓振荡便宜得多。

片段 3：同一条式子里的两种世界观，静差与增益上界的数值对照

def compare_schemes(k=800.0, m=1.0, d=56.6, k_env=1e5):
    """对比：阻抗(无积分) / 阻抗(带积分) / 混合(力维PI) 的静差与增益上界。"""
    k_series = k * k_env / (k + k_env)          # 串联刚度，决定力响应
    lam_max = d * (k + k_env) / (m * k * k_env) # 劳斯上界：三种方案的力环共用
    print(f"K_series={k_series:7.1f} N/m   lambda_max={lam_max:.4f} m/(N*s)")
    for dx in (0.001, 0.002, 0.005):            # 面位置偏差 1/2/5 mm
        e_imp = k_series * dx                   # 阻抗无积分：静差 = 串弹刚度 x 偏差
        print(f"面偏差 {dx*1000:.0f} mm -> 阻抗静差 {e_imp:5.2f} N"
              f"   阻抗+积分 0.00 N   混合力维 0.00 N")

compare_schemes()
# 只改环境：换成软垫 K_env=1e4，观察上界与应用范围的移动
compare_schemes(k_env=1e4)

解读：这段代码输出把本章结论钉成数字：（1）静差，阻抗无积分方案被迫用 Kseries×Δx 支付面位置误差，混合力维与带积分阻抗都能清零；（2）稳定边界，λmax 与方案无关，只取决于柔顺内环与环境，说明混合控制的力维并不比阻抗"更稳"，只是把力环暴露得更直白；（3）环境切换，把 Kenv 从 1×105 降到 1×104，λmax 从 0.071 升到 0.076（略增），但 Kseries 从 793 降到 741，两种方案都更"好说话"。真机选型时，把这段函数扩成参数扫描表，就是一份选型报告。

常见坑

  • S 与任务坐标系对不上：把 S 定义在工作坐标系却在另一个坐标系里解释力方向，力控维实际控的是斜方向，力误差沿正确法向残留。校验方法：让机器人只用 P 维走 +x，观察力传感器输出是否只出现预期的分量。
  • 力维 PI 的积分没有限幅：没接触时误差恒为 Fd，积分把参考位置一路推到底，接触瞬间以极大的"等效速度"撞上去。给积分状态加行程限幅（本例 ±40 mm）与接触超时保护。
  • 硬切换 S：从位置模式切入力模式的瞬间，位置伺服带着固定接近速度，力峰值可达稳态的 2–3 倍。用 0.2–0.3 s 的平滑过渡，并把接近速度降到 10–20 mm/s。
  • 把"位置维"也调软：有人为了"安全"把位置维刚度设得跟力维一样小，结果切向位置精度不够、轨迹走歪。记住分工：位置维要硬（5000 N/m 量级），力维要软（自然刚度由 kf 决定）。
  • 混淆力/力矩的 S 位：旋转自由度用 "F" 还是 "P" 取决于接触物理，拧螺丝时绕轴力矩必须控制，砂带磨削时绕切向的力矩要柔顺释掉。S 写错一位，任务就"看起来能跑、其实不对"。

练习与思考

  1. 为"擦拭平面玻璃"任务写出任务坐标系与 S 字符串，并说明每一维为什么这样选（提示：玻璃是光滑刚面，工具是海绵垫）。★
    提示
    法向（z）力控 20 N；x、y 位置控；绕 x/y 可以力控（让工具贴平）也可以位置控（刚性连接时）。一个合理答案是 "PPPFPP"。
  2. 推导：如果 S 不小心写成每维都是 0.5（不是 0/1），力维和位置维在每维各占一半，闭环会发生什么？用 S² ≠ S 说明。★★
    提示
    S = 0.5I 时 S² = 0.25I ≠ S；两个回路的输出在每维叠加，等效为一个低增益的位置环加一个低增益力环，谁都压不住谁，表现为力跟不上、位置又软又飘。
  3. 把片段 3 的 k 从 800 扫到 200、2000，记录 λmax 和 Kseries 的变化，画出"虚拟刚度-力环增益上界"曲线，并解释曲线形状。★★
    提示
    λmax = D(K+Kenv)/(MKKenv)，K 越大上界越小（D 若按临界阻尼随 √K 变化，要代进公式再算）；Kseries 随 K 增、趋于 K。结论：更硬的"手感"换来更受限的力环增益。
  4. 设计过渡混合实验：接近速度 20 mm/s、接触检测阈值 0.5 N，对比（a）硬切换、（b）0.3 s 线性混合 两种方案的力峰值。预测哪一个大，为什么？★★
    提示
    硬切换时位置伺服仍按 20 mm/s 的参考速率推进，等效于给接触面一次速度冲击，力峰值 ≈ 环境刚度 × 进入深度增量；线性混合把速度平滑降到 0，峰值明显更小。
  5. 论证题：为什么在"接触方向随时间变化"的曲面上跟踪，混合控制需要不断重构 S，而阻抗控制不需要？从"自由度计数"和"刚度比"两个角度各写一句话。★★★
    提示
    自由度计数角：S 是任务坐标系下的硬分配，坐标系变了 S 必须跟着变；刚度比角：阻抗只依赖"法向柔顺/切向较硬"的比例关系，方向变化时比例关系自动随笛卡尔方向生效。

小结

  • 混合控制 = 选择矩阵 S 显式分配自由度：τ = JT[S ff + (I−S) fp]；S 必须幂等且与 I−S 互补，同一自由度不能同时管位又管力。
  • 它的信息前提是准确的任务坐标系与接触方向；力维同样需要积分清零静差，同样受 λmax 型增益上界约束。
  • 阻抗控制是混合控制的"软化版"：位置维 K→∞、力维 K→0 时两者等价；阻抗不需要几何先验，代价是所有方向都"软"。
  • 选型口诀：几何已知、方向固定、要位置精度 → 混合；几何多变、接触丰富、要鲁棒 → 阻抗/导纳。过渡处用平滑混合；硬切换会在接触瞬间留下明显力尖峰。
  • 下一章开始给这套回路补上"安全阀"：先讲力矩限制，当阻抗控制算出的关节力矩超过执行器能力时，什么该限、怎么限才不破坏稳定。
