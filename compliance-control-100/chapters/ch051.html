第三篇 · 感知、辨识与智能调参

第 051 章：阻抗控制中的参数辨识

重力补偿、摩擦补偿、扰动观测器、外力观测器，全书一半的模块都写着"假设模型参数已知"。本章把这句话补上：用递推最小二乘（RLS）从力矩与运动数据里在线辨识惯量、摩擦与重力系数，并教你为什么"激励信号"比算法本身更重要。

  • 主题：动力学参数辨识 / 递推最小二乘（RLS）
  • 关键公式：τ = Y(q,q̇,q̈)·β；β̂⁺ = β̂ + K·(τ − Y β̂)，K = P Yᵀ/(λ + Y P Yᵀ)
  • 预计学时：60 分钟
  • 前置章节：第 050 章（基于扰动观测器的阻抗控制）

学习目标

  • 理解机器人动力学的"参数线性"结构：为什么 τ 总能写成 Y(q,q̇,q̈)·β 的形式，哪些量属于 β。
  • 掌握递推最小二乘（RLS）的三行核心递推：增益、参数、协方差各在做什么，遗忘因子 λ 的物理意义。
  • 理解"持续激励"（persistent excitation）条件：为什么单方向、单频率的运动永远辨识不准。
  • 会设计一次辨识实验：激励轨迹、数据滤波、初值、验收指标（力矩预测残差）。
  • 能把辨识结果接入重力补偿与 DOB 名义模型，并知道辨识偏差在控制里如何显形。

背景与动机

回顾一下前面的"模型依赖清单"：第 011 章的重力补偿需要连杆质量与质心参数；第 012 章的摩擦补偿需要黏性/库仑摩擦系数；第 049 章的动量观测器与第 050 章的 DOB 需要惯性矩阵；负载一变（换工具、换工件），这些参数全部漂移。厂商数据手册给的常是 CAD 值，而真实系统的摩擦与负载惯量往往和手册差 10–30%。

把参数"学"出来有两条路：离线辨识（托盘里跑一段标准轨迹、统一算参数）和在线辨识（边干活边更新，适应负载变化）。两者共享同一套数学，最小二乘及其递推形式 RLS。本章的目标是让"模型供给"这件事从黑盒变成一个可解释、可验收的流程：你不仅要会跑辨识，还要会看残差、会判断"数据不够想"。

核心原理

1. 参数线性：机器人动力学的礼物

对 n 关节机械臂（含摩擦模型），动力学方程可以严格整理成"回归矩阵 × 参数向量"：

τ = Y(q, q̇, q̈) · β Y：n×(10n 或含摩擦参数) 的回归矩阵，完全由运动状态决定；β：常数参数向量（惯量、质心矩、摩擦系数等）

摩擦常用的两级模型（黏性 + 库仑）在状态里的写法是：

τf,i = bi·q̇i + ci·sgn(q̇i) bi：黏性摩擦（N·m·s/rad，约 0.5–2）；ci：库仑摩擦（N·m，约 0.5–3）

参数线性意味着：给定一段含有丰富运动的数据 (q, q̇, q̈, τ)，辨识就是把 τ 表达成状态特征的线性组合，可以用成熟的线性回归工具，不必做非线性搜索。以一维单关节为例，完整的线性形式是：

τ = I·q̈ + b·q̇ + c·sgn(q̇) + (mgℓ)·sin q 待辨识 β = [I, b, c, mgℓ]⊤；I 转动惯量、b 黏性摩擦、c 库仑摩擦、mgℓ 重力矩系数

2. 最小二乘与递推形式

收集 N 组数据，把它们按行拼成矩阵：τN×1 = YN×p·β。批量解是经典的正规方程：

β̂ = (Y⊤Y)−1Y⊤τ 要求 YᵀY 可逆（激励足够丰富）；数据量大时不必重算矩阵求逆，改递推

RLS 把每来一批数据就整体重算，改为"上一份估计 + 本次新息修正"：

e = y − φ⊤β̂， K = Pφ/(λ + φ⊤Pφ)， β̂ ← β̂ + K·e， P ← (P − Kφ⊤P)/λ φ：本次回归向量（Y 的一行）；P：参数协方差矩阵；λ：遗忘因子（0.98–0.999）

三行的角色要分清：e 是"模型错得有多大"，K 是"这次修正该走多远"（φ 方向的不确定度越大、修正越激进），P 记录"每个方向还有多少没学会"，λ < 1 让老数据按 λⁿ 淡化，从而能跟踪缓慢漂移的参数。λ 的物理意义是记忆长度：有效记忆约 1/(1−λ) 组数据，λ = 0.998、周期 1 ms、按 100 Hz 抽数据时约 5 s 记忆，足够跟上负载变化，又不至于被噪声牵着走。

3. 持续激励：数据必须"问对问题"

为什么单方向匀速运动辨识不出摩擦和重力？因为在那种运动里，回归向量方向几乎不变：sgn(q̇) 与 sin q 的值成固定比例地一起出现，算法无法区分"是重力还是摩擦"。严格条件是：回归序列的协方差矩阵一致正定（所有方向都被激励）。工程上最简单的满足方式是多正弦叠加轨迹（3–5 个互不成整数倍的频率），让每个参数对应特征在时间上"解耦"。在线辨识时还要监测 P 的迹：某个方向的方差降不下来，就是没被激励到。

4. 辨识结果在控制里如何显形

辨识出的 β 直接喂给三个消费者：重力补偿 τg = Ygβ、摩擦前馈 τf = Yfβ、DOB/观测器名义模型。其中摩擦系数的偏差最"疼"：库仑摩擦偏差 0.5 N·m，会让阻抗控制的稳态力出现 0.5 N·m 级别的死区偏差；惯量偏差 20% 则基本被 DOB 的 (1−Q) 吸收，影响小得多。所以辨识验收的优先级是：摩擦 → 重力 → 惯量。

实现思路与设计

一次规范的辨识流程（以单关节为例，同样适用于整臂的逐关节或整体辨识）：

  1. 实验设计：多正弦激励 θd(t) = ΣAksin(ωkt + φk)，3–5 个频率覆盖 0.2–3 Hz，幅度取关节行程的 30–60%；持续 20–40 s。
  2. 数据采集：位置（编码器）、速度（α-β 观测）、力矩（电流×力矩常数）；控制用高增益 PD 跟踪，让激励轨迹真实发生。
  3. 预处理：对回归向量与力矩做同一组低通滤波（相同滤波器防止相位失配引入偏差）；加速度用观测器差分（裸差分噪声太大）。
  4. RLS 配置：λ = 0.998–0.9995；P0 = 104·I（"一开始谁也不信"）；β̂0 = CAD 值（从合理点出发）。
  5. 验收：在一段没参与辨识的验证轨迹上计算力矩预测残差 RMS（目标：小于力矩噪声的 2–3 倍）；检查 β̂ 的物理合理性（转动惯量不能为负）。
  6. 上线：把 β̂ 写入补偿模块；对负载变化场景再开在线小增益更新（λ 提高、P 复位为小值防止参数漂移）。

关键代码与解读

片段 1：RLS 类

import numpy as np

class RLS:
    """递推最小二乘：在线辨识 tau = phi @ beta 的 beta。
    P 为参数协方差(不确定度矩阵)，lambda 为遗忘因子。"""
    def __init__(self, n_params, lam=0.998, p0=1e4):
        self.lam = lam
        self.beta = np.zeros(n_params)
        self.P = np.eye(n_params) * p0     # 大初值 = 对旧参数“毫不留恋”

    def update(self, y, phi):
        e = y - phi @ self.beta            # 新息：模型预测错了多少
        denom = self.lam + phi @ self.P @ phi
        K = self.P @ phi / denom           # 卡尔曼式增益(标量分母，零求逆)
        self.beta = self.beta + K * e      # 参数按不确定度加权修正
        # 协方差收缩 + 遗忘：旧数据按 lambda^n 衰减，才能跟踪缓变参数
        self.P = (self.P - np.outer(K, phi) @ self.P) / self.lam
        return self.beta

    def excitation_trace(self):
        # P 的迹=“还有多少没学会”；长期不降说明激励不足
        return float(np.trace(self.P))

解读：（1）递推式的核心是"标量分母"，全式没有任何矩阵求逆，这是递推相对批量算法在嵌入式上受欢迎的直接原因。（2）P 的初值大小是"先验不信任度"：初值大则前几步修正激进、收敛快但会抖；用 CAD 值当 β̂₀、P₀ 取 103–104 是常用配方。（3）忘记因子里有一个陷阱：λ 越小、记忆越短，跟踪快但噪声放大，噪声进入 K 的路径是 Pφ/(λ+φᵀPφ)，φ 本身含噪声时参数估计会持续波动。稳定工况下可以把 λ 提到 0.999 甚至关闭遗忘（λ = 1），只在换负载时开"快学模式"。

片段 2：单关节四点辨识仿真

# 真值：I=0.35 kg.m^2, b=0.90, c=1.20 N.m, mgl=8.00 N.m
# 模型：tau = I*q'' + b*q' + c*sgn(q') + mgl*sin(q)  →  phi = [q'', q', sgn, sin]
rng = np.random.default_rng(3)
I, b, c, mgl = 0.35, 0.90, 1.20, 8.00
dt, rls = 1e-3, RLS(4, lam=0.999)
th = dth = 0.0
for k in range(30000):
    t = k * dt
    # 多正弦激励：3 个非整数倍频率，让四个参数“各问各的问题”
    th_d = (0.20*np.sin(2*np.pi*0.30*t)
            + 0.10*np.sin(2*np.pi*1.10*t + 0.7)
            + 0.05*np.sin(2*np.pi*2.70*t + 2.1))
    dth_d = (0.20*2*np.pi*0.30*np.cos(2*np.pi*0.30*t)
             + 0.10*2*np.pi*1.10*np.cos(2*np.pi*1.10*t + 0.7)
             + 0.05*2*np.pi*2.70*np.cos(2*np.pi*2.70*t + 2.1))
    tau = 40.0*(th_d - th) + 3.0*(dth_d - dth)      # 跟踪控制力矩(已知)
    ddth = (tau - b*dth - c*np.sign(dth) - mgl*np.sin(th)) / I
    dth += ddth * dt
    th += dth * dt
    phi = np.array([ddth, dth, np.sign(dth), np.sin(th)])
    rls.update(tau + rng.normal(0.0, 0.5), phi)     # 0.5 N.m 力矩测量噪声
print("真值: I=0.35  b=0.90  c=1.20  mgl=8.00")
print("估计:", np.round(rls.beta, 3), " tr(P)=%.1e" % rls.excitation_trace())

解读：（1）注意 phi 里的 q̈ 在真机上必须来自观测器差分或"滤波回归"，这里直接用模型值是为了聚焦算法本身，正文的"预处理"一节讲了替代方案。（2）跑完你会看到四个参数收敛到真值附近，通常惯量 I 与摩擦 c 的收敛误差稍大（它们对噪声最敏感），mgℓ 收敛最稳（激励幅度大）。（3）打印 tr(P)：从 4×104 一路降到 0.1 以下（本例约 0.07），说明四个方向都被学到了；如果把激励改成一个单频正弦，tr(P) 会在某个量级"卡住"不降，激励不足的数字化报警。（4）可把 0.5 N·m 噪声改到 2 N·m 看估计抖动：λ 不变时估计误差大约按噪声比例上升。

片段 3：验收，用未参与辨识的轨迹做力矩预测

def predict_torque(beta, th, dth, ddth):
    """给定状态与参数，预测所需力矩：辨识的最终用途就是这个预测。"""
    phi = np.array([ddth, dth, np.sign(dth), np.sin(th)])
    return float(phi @ beta)

def validate(beta_hat):
    """在另一组频率的验证轨迹上计算预测残差 RMS(与真值参数对照)。"""
    err_id, err_true = [], []
    true_beta = np.array([I, b, c, mgl])
    th = dth = 0.0
    for k in range(8000):
        t = k * dt
        th_d = 0.15*np.sin(2*np.pi*0.45*t) + 0.08*np.sin(2*np.pi*1.7*t + 1.0)
        dth_d = (0.15*2*np.pi*0.45*np.cos(2*np.pi*0.45*t)
                 + 0.08*2*np.pi*1.7*np.cos(2*np.pi*1.7*t + 1.0))
        tau = 40.0*(th_d - th) + 3.0*(dth_d - dth)
        ddth = (tau - b*dth - c*np.sign(dth) - mgl*np.sin(th)) / I
        dth += ddth*dt; th += dth*dt
        err_id.append(tau - predict_torque(beta_hat, th, dth, ddth))
        err_true.append(tau - predict_torque(true_beta, th, dth, ddth))
    print(f"辨识参数预测残差 RMS: {np.sqrt(np.mean(np.square(err_id))):.3f} N.m")
    print(f"真值参数预测残差 RMS: {np.sqrt(np.mean(np.square(err_true))):.3f} N.m")

解读：验证的关键在"另一组频率"，如果在参与辨识的同一条轨迹上验收，残差当然小，这不叫验证叫复读。工程上期望看到：辨识参数的残差与真值参数残差处于同一量级（比如都是 0.3–0.8 N·m 的噪声地板），说明模型把可解释的部分都学到了；若辨识版残差明显更大，说明某些参数（通常是 c 与 mgl 的耦合方向）没被激励够。这段代码还有个隐藏好处：把 beta_hat 换成"零向量"再跑，你会看到残差变成几 N·m 量级，这就是"不做补偿"的代价，也是辨识收益的直接度量。

常见坑

  • 激励不足：只让关节小幅度慢速摆动，mgℓ 与 c 无法分离，估计出的摩擦大到离谱。修复：多正弦、多幅度、覆盖正反行程；看 tr(P) 不降就补激励。
  • 加速度裸差分：0.7 m/s² 的噪声直接进入 Y，β̂ 被拖偏。修复：观测器差分或滤波回归（把滤波器和数据一起"洗"）。
  • 回归与力矩滤波不一致：对 τ 滤波却用未滤波的 Y（或反之），相位失配产生系统性偏差，表现为"辨识结果总是偏大 20%"。修复：所有通道同一组滤波器。
  • 遗忘因子过小：λ = 0.95 在 1 kHz 下记忆不足 20 拍，参数随噪声乱跳，接入补偿后系统"神经质"抖动。修复：稳定工况 λ 0.998–0.9995，或关闭遗忘转"慢学"。
  • 不查物理合理性：转动惯量估计为负、摩擦系数比重力矩还大，这些在数学上都"最优"，在物理上荒谬。修复：给参数加下界投影（I > 0、b,c ≥ 0），并把越界当作报警。

练习与思考

  1. 写出单摆关节的回归形式：τ = I q̈ + b q̇ + c·sgn(q̇) + mgℓ sin q，验证它满足"参数线性"，并说明如果只做缓慢小角度摆动（sin q ≈ q），为什么 c 与 b 难以区分。★
    提示
    小角度慢速时 q̇ 与 q 近似同相、sgn(q̇) 与 q̇ 近似成比例，回归向量方向坍缩，典型的激励不足。
  2. 推导 RLS 的协方差更新式：从"最小化带遗忘的加权平方误差"出发，说明 P ← (P − KφᵀP)/λ 中每一项的来源，以及 φ 方向不确定度如何被"吃进去"。★★
    提示
    写成加权代价 J = Σλ^{n−k}(yk−φkᵀβ)²，对 β 求导；或用矩阵求逆引理从批量的 (YᵀWY)⁻¹ 递推，KφᵀP/λ 就是把本次方向上的方差从 P 中消掉。
  3. 实验：把片段 2 的激励改成单频正弦（幅值翻倍），记录 tr(P) 与参数误差变化；再改成两组频率，观察改善。用"回归向量方向覆盖率"解释你看到的现象。★★
    提示
    单频时 φ 沿一条闭合轨迹运行，某些方向的方差永远降不下去；加第二频率后轨迹在状态空间"铺开"，tr(P) 才会继续下降。
  4. 设计一套"换工具自适应"流程：新工具装上后，如何在不打断产线的前提下更新负载惯量与重力矩？写出你的流程（何时重置 P、λ 怎么调、用哪些动作做激励、验收指标），并说明为什么"换工具后先做几次慢速正反摆动"是高效的。★★★
    提示
    把 P 沿负载相关方向复位成中等值、λ 临时取 0.99 快学；慢速正反摆动天然激励"sgn(q̇) 与 sin q"，能快速分离重力矩与摩擦；验收看力矩残差的均值与偏斜是否消失。

小结

  • 机器人动力学对参数是线性的：τ = Y(q,q̇,q̈)β，惯量、摩擦、重力矩系数都是常数向量的分量。
  • RLS 三行递推：新息 e、增益 K = Pφ/(λ+φᵀPφ)、协方差收缩与遗忘；λ 决定记忆长度 1/(1−λ)。
  • 持续激励是辨识的天条：多正弦轨迹覆盖尽可能多的状态方向，监测 tr(P) 判断"学没学会"。
  • 预处理三件事：统一的滤波、观测器速度/加速度、物理边界投影。
  • 验收用"未参与辨识轨迹"上的力矩预测残差；拟合残差偏乐观，不能作验收。
  • 下一章把辨识对象从"机器人自己"换成"环境"：导纳控制要知道墙面有多硬，才能把力跟踪的偏置算准，环境刚度辨识。
