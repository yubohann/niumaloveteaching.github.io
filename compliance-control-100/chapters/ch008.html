第一篇 · 基础、建模与稳定性

第 008 章：笛卡尔空间阻抗控制

从一根轴的弹簧扩展到六根轴的弹簧-阻尼-惯量：平移与姿态各三个自由度，各自一个椭球。难点不在方程，而在方向的表达、姿态误差的度量，以及"椭球随任务转"的坐标系换算。

  • 主题：阻抗控制 / 六维笛卡尔空间
  • 关键公式：Mdδ̈ + Ddδ̇ + Kdδ = Fext（δ、F 为 6 维）；Kw = (R⊕R)Kl(R⊕R)T
  • 预计学时：60 分钟
  • 前置章节：第 007 章

学习目标

  • 会把一维阻抗方程推广为六维形式，正确写出平移/姿态各分量的单位与量级。
  • 理解"各向异性刚度"的工程意义：为什么打磨要法向软、切向硬，插孔要横向软、轴向挺。
  • 掌握刚度椭球随坐标系旋转的换算公式 Kw = (R⊕R)Kl(R⊕R)T，会用特征值验证"旋转不改变软硬比例"。
  • 会用旋转矩阵对数映射计算姿态误差向量 eo = log(RdRT)∨，并解释为什么不能直接"两个矩阵相减"。
  • 能写出六维阻抗控制器的完整数据流：6 维状态积分、姿态命令用指数映射更新、逐轴限幅。

背景与动机

真实的接触任务几乎都是六维的：擦洗时末端要沿表面滑动（切向自由）、法向压紧（法向受控）、姿态略微顺从（跟随表面倾斜）；插孔时横向要柔（纠正对中误差）、轴向要挺（压入力可控）、三个转动方向要柔而不过软（避免卡死）。用一组笛卡尔各向同性参数（K 在所有方向相同）去干这些活，要么稳不住，要么干不快。

从一维到六维，方程的形式没有大变：弹簧还是弹簧。真正的新增工程内容是三件事：方向的表达（刚度矩阵在哪个坐标系里定义、怎么随工具旋转）、姿态的度量（旋转没有"相减"这种操作）、姿态命令的生成（怎样把解出来的角偏差平滑地积进一条合法姿态轨迹）。本章把这三件事讲透，代码里给出可直接复用的旋转工具函数。

核心原理

1. 六维模板：平移与姿态各三条"轴"

把笛卡尔的位姿偏差写成 6 维向量：δ = [δp; δθ]，其中 δp = (δx, δy, δz)（m）为平移偏差，δθ = (δθx, δθy, δθz)（rad）为姿态偏差（轴角向量）。外力写成 6 维广义力 Fext = [f; τ]，f（N）为力，τ（N·m）为力矩。阻抗方程逐维平行地推广为：

Mdδ̈ + Ddδ̇ + Kdδ = Fext Md、Dd、Kd 均为 6×6 矩阵；对角块分解为"平移 3 维 + 姿态 3 维"

三类矩阵的物理量纲需要点清，这是六维实现里最常见的错误源头：

维度刚度 Kd阻尼 Dd惯量 Md典型量级
平移（3）N/mN·s/mkgK=200–2000；D=20–200；M=0.5–5
姿态（3）N·m/radN·m·s/radkg·m²K=5–50；D=0.5–5；M=0.02–0.5

注意姿态刚度的数值天然比平移小两个量级，这源于单位不同：把末端绕一个轴拧 0.1 rad（约 5.7°）所需的力矩，与平移 10 cm 所需的力，在物理上处于同一难度档。数值上别把 Kθ=10 N·m/rad 与 Kp=500 N/m 直接比较"谁硬"。

2. 各向异性与刚度椭球：软硬是有方向的

取对角形式 Kd = diag(Kx, Ky, Kz, Kα, Kβ, Kγ) 时，六个方向各自独立：位移方向 d 上的等效刚度是 dTKdd。三个平移刚度的不同组合构成一只刚度椭球：椭球的长轴方向软、短轴方向硬。工程上就是靠这只椭球干活：

  • 表面任务（打磨/擦洗）：法向 Kn=200–500（随形起伏、力可控），切向 Kt=1000–2000（跟轨迹准、不被摩擦力拖走），姿态偏软 Kθ=5–10（贴合曲面）。
  • 插孔装配：横向 Kx、Ky=150–400（吸收对中误差），轴向 Kz=400–800（压入力可控），绕横向轴 K=5–15（允许微量倾斜纠偏）。
  • 旋转工件任务（拧螺丝）：绕工具轴 Kγ=20–50（力矩分辨率优先），其余轴保持中等柔性防别劲。

工程直觉：笛卡尔阻抗为每个方向各配一个软硬，再用一只可以旋转的椭球把它们装起来，整体单一软硬只是它的退化情形。调试时的第一步永远是问：任务的"受控方向"和"让位方向"分别是谁？把它们对应到坐标系轴线上，各向异性设计才有依据。

3. 椭球随任务转：坐标系换算

刚度通常定义在"任务坐标系"里（比如工件表面法向为 z，沿边方向为 x），但控制器的姿态测量在世界系（或基座系）里。把任务系的 6×6 刚度转到世界系需要旋转矩阵 R（任务系相对世界系的姿态）：

Kw = (R ⊕ R)·Kl·(R ⊕ R)T，其中 R ⊕ R = blkdiag(R, R) Kl：任务系刚度；Kw：世界系刚度。推导用 Fw=R⊕R·Fl、δw=R⊕R·δl 代入 F=Kδ

这个公式的三个不变性值得牢记：特征值不变（旋转只改方向不改成色，软硬比例原样保留）；对称性不变（Kw 仍对称）；正定性不变（所有特征值仍 > 0，物理可实现性保持）。如果换算后出现负特征值，一定是 R 抄错了或 Kl 本身不是正定。姿态块同理由 R 直接共轭。工具随动场景要特别注意：R 应取"任务坐标系相对世界系的实时姿态"，任务开始前和结束前各校核一次。

4. 姿态误差：旋转矩阵的对数映射

姿态部分没有"xd − x"这种操作，旋转矩阵不能相减。常用的合法误差度量是旋转矩阵的对数映射（轴角误差）：

Re = RdRT， eo = log(Re)∨ = θ·k， cosθ = (tr(Re) − 1)/2 Rd：期望姿态；R：实际姿态；eo：轴角向量（rad），方向为转轴 k，模长 θ 为转角

它的物理意义清晰：eo 就是"把实际姿态拧到期望姿态所需的最小旋转矢量"。小角度时 eo ≈ 0.5·vec(RdRT − RRdT)（反对称部分），这也是数值实现时的安全路径，θ 接近 0 时用反对称部分避免除零；θ 接近 π 时正弦项退化，需要单独的极限分支（代码片段 1 都做了处理）。为什么不用欧拉角做误差？因为欧拉角有万向节锁死与 ±π 跳变，误差向量会在奇异姿态附近突然翻转，控制器把它当成"瞬间 300° 的姿态偏差"输出巨大纠正力矩。

姿态命令的生成与平移对称：把 6 维速度/位移命令积分成 6 维向量后，平移直接加到位置参考上，姿态部分经过指数映射变成旋转矩阵再作用到期望姿态上：Rc = Exp(δθc)·Rd。指数映射（罗德里格公式）保证结果仍是合法旋转矩阵，反过来，若直接给 Rd 的元素加增量，几秒后矩阵就不再正交，姿态会"发散"成切变，这是姿态实现的第一号事故。

5. 阻尼与惯量的逐轴设计

对角近似下每个轴独立成二阶系统，阻尼按各轴参数单独算：Di = 2ζi√(KiMi)。实用建议：软轴（让位大的方向）取 ζ≈1 防振荡；硬轴取 ζ=0.7–0.9 保响应速度；姿态轴取 ζ≥0.9，因为腕部对力矩噪声远比平移敏感（力矩噪声 0.01 N·m 经臂长 0.2 m 折合 0.05 N，但在姿态轴上可能直接激起腕部振动）。惯量 Md 的初值取物理等效惯量的同量级：平移 1 kg、姿态 0.05–0.2 kg·m²；太小则高频噪声直通，太大则接触反应迟钝。矩阵耦合项（K 的非对角元素、Md 的耦合）在低速接触任务里通常置零；高速任务需要用李雅普诺夫方程配阻尼（Dd 使 Mds²+Dds+Kd 稳定），那是第 070 章"惯性整形"的话题。

实现思路与设计

六维位置型阻抗的落地步骤（沿用第 001/005 章的积分骨架）：

  1. 选任务坐标系与椭球：确定受控方向（硬）与让位方向（软），给出 Kl 的六个对角值；姿态轴不知道就先用 10 N·m/rad 起步。
  2. 换算到世界系：每拍或每次任务开始，用 R⊕R 共轭得到 Kw；位置环里求误差也用世界系。
  3. 计算 6 维误差：δp = p − pd；eo = log(RdRT)∨。速度项：平移直接测，姿态用角速度 ω（陀螺或微分滤波）。
  4. 解算 6 维加速度：a = Md−1(Fext − Ddν − Kdδ)，ν 为 6 维速度偏差；用 np.linalg.solve 直接解方程（不求逆，数值更稳健）。
  5. 积分与限幅：6 维半隐式欧拉；平移限幅 ±50 mm 量级、姿态 ±0.3–0.5 rad；限幅处清零对应速度（第 002 章的教训）。
  6. 生成姿态命令：Rc = Exp(δθc)Rd；位置命令 pc = pd + δpc，一并交给内环/IK。
设计决策：姿态轴为什么从 10 N·m/rad 起步，不按平移等比缩放？

姿态刚度受两个约束夹击：太大时，几毫牛的力矩噪声（传感器底噪 0.01 N·m 量级）就产生 10−3 rad 级抖动，通过腕部放大成可见的毫米级末端跳动；太小时，工具重力矩（2 kg 工具、0.1 m 偏心 ≈ 2 N·m）会造成 0.2 rad 的静态倾角，连姿态都保持不住。10 N·m/rad 恰好把两者挡在可接受范围：噪声抖动约 0.001 rad、重工具静差约 0.2 rad（配合重力补偿后归零）。如果你的工具更重或臂更长，先补工具重力模型，再根据残余噪声回调这个数，顺序反了会把噪声问题误诊成刚度问题。

关键代码与解读

片段 1：姿态误差与姿态积分，SO(3) 两个基本工具

import numpy as np

def rot_error(R_d, R):
    """姿态误差 e_o = log(R_d·R^T) 的轴角向量（rad），带两种极限处理。"""
    R_e = R_d @ R.T
    cos_t = np.clip((np.trace(R_e) - 1.0) / 2.0, -1.0, 1.0)  # 防 arccos 域外
    theta = np.arccos(cos_t)
    if theta < 1e-9:
        # 小角度极限：R_e ≈ I + [w]×，反对称部分直接给出误差向量
        return 0.5 * np.array([R_e[2,1]-R_e[1,2],
                               R_e[0,2]-R_e[2,0],
                               R_e[1,0]-R_e[0,1]])
    if theta > np.pi - 1e-6:
        # 接近 180°：sinθ→0 公式退化，用 R_e = 2aa^T − I 重建旋转轴
        a = np.sqrt(np.maximum((np.diag(R_e) + 1.0) / 2.0, 0.0))
        k = int(np.argmax(a))
        for j in range(3):                      # 用 R_e[k,j] 的符号恢复其余分量
            if j != k and R_e[k, j] < 0.0:
                a[j] = -a[j]
        return theta * a
    return (theta / (2.0 * np.sin(theta))) * np.array([R_e[2,1]-R_e[1,2],
                                                       R_e[0,2]-R_e[2,0],
                                                       R_e[1,0]-R_e[0,1]])

def exp_so3(w):
    """轴角向量（rad）→ 旋转矩阵（罗德里格公式）：用于积分姿态命令。"""
    th = np.linalg.norm(w)
    K = np.array([[0.0, -w[2], w[1]], [w[2], 0.0, -w[0]], [-w[1], w[0], 0.0]])
    if th < 1e-9:
        return np.eye(3) + K                   # 一阶近似，足够小步长使用
    K = K / th
    return np.eye(3) + np.sin(th)*K + (1.0-np.cos(th))*(K @ K)

解读：这两个函数是六维实现里唯一"必须小心写"的地方，其余都是数字搬运。三重极限处理各有理由：θ→0 时 1/sinθ 会放大数值噪声，用反对称部分（本质是一阶近似）既稳定又足够精确；θ→π 时旋转轴不唯一但方向会影响收敛，用对角元素重建轴并借 R_e[k,j] 定符号能给出确定的分支；中间的通用分支是教科书公式。指数映射的写法与之对偶：先构造反对称矩阵 K 再统一乘 sinθ、把高阶项留在 K@K 里，避免手写九个元素时抄错符号。注意这两个函数只处理"相对误差"与"相对增量"，不要用它们去修绝对旋转矩阵的元素，那是两码事。真机上若使用四元数表示（很多机器人 API 走这条路），误差可改为四元数向量部分的 2 倍，思路与极限处理完全一样。

片段 2：六维阻抗控制器，平移与姿态共用一条积分链

class CartesianImpedance6D:
    """6 维笛卡尔阻抗：前 3 维平移（m, N），后 3 维姿态（rad, N·m）。"""
    def __init__(self, k=None, m=None, zeta=None, dt=1e-3):
        k = k if k is not None else [500, 500, 300, 10, 10, 10]
        m = m if m is not None else [1, 1, 1, 0.05, 0.05, 0.05]
        zeta = zeta if zeta is not None else [1.0]*6
        self.M = np.diag(m)
        # 逐轴临界阻尼：姿态轴单位是 N·m·s/rad，公式形式与平移完全一致
        self.D = np.diag(2.0*np.asarray(zeta)*np.sqrt(np.asarray(k)*np.asarray(m)))
        self.K = np.diag(k)
        self.dt = dt
        self.v_cmd = np.zeros(6)               # 6 维命令速度（平移+姿态向量）
        self.d_cmd = np.zeros(6)               # 6 维命令偏差（姿态用轴角向量）

    def step(self, p, R, dp, w, f_ext, p_d, R_d):
        """输入：实测位姿/速度、6 维外力、期望位姿；输出：命令位姿。"""
        e_p = p - p_d                          # 平移误差（m）
        e_o = rot_error(R_d, R)                # 姿态误差向量（rad）
        nu = np.concatenate([dp, w])           # 6 维速度（平移+角速度）
        # 6 维阻抗方程解加速度：实测状态进弹簧/阻尼项（第 001 章结构）
        a = np.linalg.solve(self.M, f_ext - self.D @ nu - self.K @ np.concatenate([e_p, e_o]))
        self.v_cmd += a * self.dt              # 半隐式欧拉
        self.d_cmd += self.v_cmd * self.dt
        # 逐轴限幅：平移 ±50mm、姿态 ±0.4rad；触边清速度防"憋劲"
        self.d_cmd[:3] = np.clip(self.d_cmd[:3], -0.05, 0.05)
        self.d_cmd[3:] = np.clip(self.d_cmd[3:], -0.4, 0.4)
        if np.any(np.abs(self.d_cmd[3:]) >= 0.4):
            self.v_cmd[3:] = 0.0
        p_cmd = p_d + self.d_cmd[:3]
        R_cmd = exp_so3(self.d_cmd[3:]) @ R_d  # 姿态命令：指数映射保正交
        return p_cmd, R_cmd

解读：这段代码把六维和三维的差异压缩到两个细节上。第一，用 np.linalg.solve(M, ·) 解方程：对角矩阵时它与 M⁻¹@· 数值上都行，但你迟早会换成非对角的 Md（惯性整形），solve 的写法提前把接口留对。第二，姿态命令用 exp_so3 合成（对元素直接加增量会破坏正交性）：d_cmd[3:] 始终是"相对 R_d 的轴角增量"，与 rot_error 的输出语义对齐，这样"测量的误差"和"命令的偏差"是同一套坐标，反馈闭环才有意义。第三个例子中已悄悄埋了限幅与清速度逻辑（第 002 章的教训推广到 6 维），真机上还应加上 6 维 d_cmd 的速率限幅，防止外力突变时命令跳变。为什么不用四元数存 d_cmd[3:]：轴角向量在 ±0.4 rad 限幅内没有奇异与双覆盖问题，代码最简单；若轨迹需要连续大角度回转（> π），再改为"四元数状态 + 轴角增量"的混合表示。

片段 3：任务系刚度换算与椭球验证

def frame_stiffness(k_axis, R):
    """任务系逐轴刚度 → 世界系：K_w = (R⊕R)·K_l·(R⊕R)^T。"""
    R6 = np.zeros((6, 6))
    R6[:3, :3] = R
    R6[3:, 3:] = R
    K_l = np.diag(k_axis)                 # 前 3 平移 N/m，后 3 姿态 N·m/rad
    return R6 @ K_l @ R6.T

# 打磨任务：任务系 z 为表面法向（软 200），x/y 沿表面（硬 1500/800），
# 任务坐标系相对世界系绕 z 轴旋转 30°：检查世界系下的耦合项与特征值
th = np.pi / 6.0
R = np.array([[np.cos(th), -np.sin(th), 0.0],
              [np.sin(th),  np.cos(th), 0.0],
              [0.0, 0.0, 1.0]])
K_w = frame_stiffness([1500.0, 800.0, 200.0, 8.0, 8.0, 8.0], R)
np.set_printoptions(precision=1, suppress=True)
print("世界系平移块 K_w[:3,:3]:\n", K_w[:3, :3])   # 出现非对角耦合项
print("特征值（应保持 1500/800/200）:", np.linalg.eigvalsh(K_w[:3, :3]))

解读：运行输出会看到世界系平移块里出现了约 +303 的 xy 耦合项（(1500−800)/2·sin60°），而特征值原封不动地保持 1500/800/200，这正是"旋转只改变方向"的数值验证。这个输出的工程含义：在任务系里你设计的是"三条独立的弹簧"，换到世界系看就带有耦合，控制器若在世界系直接按对角近似去理解这些数，会以为"xy 方向互相拉扯"；正确的做法是把耦合项原样塞进 Kd 矩阵参与运算（CartesianImpedance6D 用 np.diag 只是教学简化，生产代码应接受完整矩阵并做正定检查）。最后给一个实用检查清单：每次换任务系后用 eigvalsh 扫一遍，特征值全正、且与设计值一致，说明 R 与 Kl 都对；不一致就回头查 R 的转置方向和任务系定义，这两处是全工程最常抄错的地方。

常见坑

  • 姿态误差写成 Rd−R：直接相减得到的矩阵既不反对称也不表示旋转，误差向量指向毫无几何意义的方向，表现为"姿态纠偏时越纠越歪"。修复：用 log 映射或四元数向量部分。
  • 姿态命令元素级累加：往 Rd 元素上加增量，几十毫秒后矩阵失去正交性，姿态发散成切变。修复：增量必须经指数映射合成，永远保持"旋转×旋转"。
  • 任务系刚度忘了随工具旋转：倾斜打磨时"法向软"的方向没有跟着工具转，实际变成"某世界轴软"，接触力方向与预期相反。修复：Kw = (R⊕R)Kl(R⊕R)T 每拍更新。
  • 把平移与姿态的数值直接对比：误以为 Kθ=10 比 Kp=500"软 50 倍"，据此调参失衡。修复：各自在单位体系内评估（姿态看"拧动 0.1 rad 需要多少 N·m"）。
  • 刚度矩阵非正定：手工拼 Kw 时符号写错或耦合系数过大，出现负特征值，系统沿某方向"越偏越用力"，局部发散。修复：使用前做 eigvalsh 断言，任何负特征值立即拒绝进入控制回路。

练习与思考

  1. 写出六维阻抗方程并给每个矩阵标注量纲；说明为什么姿态刚度典型值只有平移的百分之一量级。★
    提示
    方程与一维同形；差异全在单位：N·m/rad 与 N/m 不可比。0.1 rad 的角偏差已经是"可见"的倾斜，而 0.1 m 的平移偏差通常不可接受，两者的"工程尺度"不同。
  2. 取 Kl=diag(1200, 400, 200, 8, 8, 8)，任务系绕世界 z 轴旋转 45°，手算 Kw 的 (1,1)、(1,2)、(2,2) 三个元素，再用片段 3 验证。★★
    提示
    二维旋转共轭：K11=1200cos²+400sin²，K22=1200sin²+400cos²，K12=(1200−400)sin·cos。45° 时 K11=K22=800，K12=400。
  3. 用片段 2 的类做一个数值实验：让末端压向 z 向墙面（Kz 软轴）同时施加绕 x 的 0.5 N·m 力矩，观察平移与姿态通道是否解耦；再把 K 的非对角项手动置入（如 Kxz=100），观察耦合行为。★★
    提示
    对角 K 下 z 向力只产生 z 向位移、绕 x 力矩只产生绕 x 转角；加入 Kxz 后 z 向力会额外产生绕 x 倾斜（反之亦然），这就是"耦合柔顺"的雏形。
  4. 推导小角度极限：证明 eo ≈ 0.5·vec(RdRT − RRdT) + O(θ³)，并说明代码里 θ<10−9 分支为何足够。★★★
    提示
    R_e=Exp(θk) 展开到一阶；R_e−R_eT=2sinθ[k]×≈2θ[k]×；vec 后除以 2 得 θk。θ 很小时高阶项可忽略，且该分支只在数值极限触发。
  5. 设计一段"倾斜打磨"的完整参数：工具相对世界系俯仰 25°，要求法向力 15 N±2、切向刚度足以抵抗 8 N 摩擦扰动、姿态跟随曲面起伏 ±3°。给出 Kl、旋转 R、Kw 的计算流程与三个验收指标。★★★
    提示
    Kl：法向 z 取 400（15 N 对应约 4 cm 偏置，可按偏置需求反推）、切向取 1500、姿态 6–8；R 由俯仰角与绕工具轴角合成；验收：法向力稳态误差、切向受扰位移 <2 mm、姿态跟随滞后 <0.5°。

小结

  • 六维阻抗 = 平移三轴 + 姿态三轴各一套质量-弹簧-阻尼；核心新增工作是指明方向、度量姿态、生成合法姿态命令。
  • 各向异性是工程主线：刚度椭球的长短轴对应任务的让位方向与受控方向，调参前先画任务坐标系。
  • 坐标系换算 Kw = (R⊕R)Kl(R⊕R)T：特征值、对称性、正定性三重不变；负特征值是拼装错误的红灯。
  • 姿态误差用 log 映射 eo=log(RdRT)∨，姿态命令用 Exp 合成；两端极限各写一个分支，避免除零与方向跳变。
  • 下一章沿自由度类型切换视角：把柔顺直接做在关节轴上，讨论何时更简单、何时更危险，以及两种空间的等价换算钥匙。
