第 031 章：恒定接触力控制

把接触力稳在 15 N。本章把"恒定力"当作扰动抑制问题：力阶跃给指标、表面凸起给干扰、λ 增益给取舍，用上升时间、超调、稳态误差三件套建立一个可复现的力控实验范式。

  • 主题：力调节 / 扰动抑制 / 实验方法论
  • 关键公式：vr = λ(Fd−F)，ΔFbump ≈ Kenv·Δz
  • 预计学时：50 分钟
  • 前置章节：第 022 章

学习目标

  • 理解"恒定力"是一个调节（regulation）问题：参考是常数、扰动来自表面位置与运动耦合，控制目标是"偏差有界且回零"。
  • 会用"速度形式的 P 律 + 位置积分状态"实现零静差的力环，并解释它与第 022 章外环的等价性。
  • 掌握三个标准实验指标：阶跃上升时间（10–90%）、超调峰值、扰动恢复时间与稳态误差；能独立设计并执行这套实验。
  • 会推导表面凸起造成的力跳变 ΔF ≈ Kenv·Δz 与恢复时间 ≈ 1/(λKseries)，并解释两者为什么由不同物理量决定。
  • 能通过 λ 扫描实验量化"响应速度 ↔ 超调 ↔ 稳定性裕度"的取舍，并给出验收级的参数选择。

背景与动机

擦洗、抛光、贴合、恒压压装，这些工艺对控制器的要求出奇地一致：把接触力保持在一个常数附近。为什么不是"大概差不多"？因为材料去除率、贴合质量、甚至零件的密封性都随力线性或敏感变化：抛光力从 15 N 漂到 18 N，去除率就偏高 20%，表面出现"过磨"；压装力波动过大，则零件会被压伤。恒力的工程指标通常写成"±5%"或"±0.5 N"，这要求控制器对两类扰动都要有明确的抑制能力：

第一类扰动是"工件面不在你以为的地方"：装配偏差、曲面起伏、工件热变形，等效为环境位置 xe 的移动；第二类扰动是"机器人的运动本身"：工具沿表面滑动时，姿态变化、机构误差都会耦合进法向压入量。本章用第 022 章的导纳 + 参考自适应结构来同时处理这两类问题，并把它做成一套可复现的实验：同一批指标、同一批参数、同样的结论结构，第 032–036 章都会沿用这套方法论。

核心原理

1. 恒力控制的闭环结构：速度形式的 P 律

沿用第 022 章的两层结构：导纳内环（Md、Dd、Kd）负责接触瞬态的手感，外环把力误差变成参考位置的运动。对恒力任务，外环取最简单的速度形式：

vr = λ·(Fd − Fext)，xr ← xr + vr·Δt，xcmd = xr − δ Fd：期望恒力（N）；λ：力环增益（m/(N·s)）；δ：导纳退让量（第 022 章）

两个视角理解"为什么静差为零"：（1）速度视角，vr 是力误差的纯比例函数，稳态时 xr 不再移动意味着 vr = 0 即 Fext = Fd，误差被"运动必须停止"这一事实逼零；（2）积分视角，以位置为输出看，xr 是力误差的积分，常量扰动（面位置偏移）被积分器"记住"并补偿，参照内模原理：常值扰动需要积分器才能完全抑制。两种说法等价，调试时用第一句（速度不清零不行），写论文用第二句。

2. 扰动定量的两条公式：跳变看刚度，恢复看增益

实验将施加两种激励，先给预测公式。第一，力参考阶跃 Fd: 5 → 15 N。初始响应速度由增益决定：vr = λ·ΔF = 0.01×10 = 0.1 m/s 量级，在 1×104 N/m 的接触环境里，每 1 mm 压入对应 10 N，10 N 的力缺口折算成约 1 mm 的行程，按 0.1 m/s 走完约 10 ms；叠加导纳内环的平滑，实测上升时间为 10 ms 量级。这给出一条设计公式：

trise ≈ ΔF / (λ · ΔF · Kenv) = 1 / (λ·Kenv) 量级 Kenv 越大（越硬的接触），同样的 λ 下响应越快，因为需要的行程更短

第二，表面凸起：工具滑过 0.5 mm 高的凸包，环境表面瞬间向机器人"挤"0.5 mm。压入量瞬增，接触力立即跳变：

ΔFbump ≈ Kenv · Δz = 1×104 × 0.5 mm = 5 N 量级 注意：跳变由环境刚度决定，与 λ 无关；λ 决定跳变后"多快拉回去"

恢复过程同样是积分器工作：力偏高 → vr 为负 → 参考位置后退，需要后退的行程是 ΔF/Kenv，速度是 λ·ΔF，于是恢复时间常数 τrec ≈ 1/(λKenv)，实测在 10 ms 量级。工程直觉：表面凸起"砸"出来的力跳变由环境刚度决定（躲不开），你能控制的是它停留多久（λ 决定），所以恒力精度的核心是"快速回零"。

3. 增益的三方取舍与稳定边界

λ 越大，恢复越快、稳态保持越硬，但（1）超调增大（实测峰值从 λ=0.002 的 15.4 N 涨到 λ=0.05 的 17.2 N）；（2）逼近第 022 章推导的稳定上界 λmax = Dd(Kd+Kenv)/(MdKdKenv)。本例参数 Dd=150、Kd=1000、Md=1、Kenv=1×104 给出 λmax ≈ 0.165，取 λ=0.01 时裕度 16 倍，取 0.05 时裕度 3.3 倍，后者虽然还稳定，但对内环延迟、力滤波滞后变得敏感。推荐工作点：λ ∈ [0.005, 0.02]，即"10 倍以上裕度"区间；超过 0.05 请先做延迟鲁棒性复核。

顺带回答一个常见疑问：为什么不能把 λ 一路加大到"瞬间到位"？因为力环的驱动信号是"参考位置的速度"，位置每挪一点力就变一次，闭环里存在导纳动态与内环伺服延迟；λ 超过边界后，系统在"力道过冲—回拉过冲"之间来回，表现为持续振荡（第 022 章特征根穿越虚轴的现象）。

实现思路与设计

实验设置（1 维按压，1 kHz 控制周期，5 s 时长）：

  1. 被控对象：接触环境刚度 Kenv = 1×104 N/m（带弹性垫的工装量级），初始力 5 N；工具已压入 0.5 mm。
  2. 激励一（阶跃跟踪）：t = 1 s 时 Fd 从 5 N 跳到 15 N，测上升时间（10–90%）、峰值超调、稳态误差。
  3. 激励二（表面扰动）：t = 3 s 时环境表面向机器人方向平移 0.5 mm（模拟凸包），测力跳变幅度、峰值、恢复时间（回到 ±0.3 N 带内）与残余误差。
  4. 控制器参数：Kd = 1000 N/m、Md = 1 kg、Dd = 150 N·s/m（对 Kenv=1×104 约 ζ≈0.7）、λ = 0.01 m/(N·s)、参考速度限幅 ±0.2 m/s。
  5. 验收判据：上升时间 < 50 ms；超调 < 20%；扰动恢复 < 100 ms；稳态误差 < 0.2 N。
设计决策：为什么实验里要"先阶跃、后扰动"？

阶跃测的是"跟踪能力"，扰动测的是"抑制能力"，两者对增益的敏感方向一致但物理不同。先跑阶跃可以快速确认环路健康（无持续振荡、无明显辨识错误），再跑扰动才有意义；如果先跑扰动就发现振荡，你无法区分是增益问题还是接触模型问题。这也是"一次只变一个量"的实验纪律。

关键代码与解读

片段 1：恒力环（含限幅）

import numpy as np

class ConstantForceLoop:
    """恒定接触力控制：速度形式 P 律 + 参考位置积分状态。"""
    def __init__(self, lam=0.01, dt=1e-3, v_r_max=0.2, x_span=0.05):
        self.lam, self.dt = lam, dt
        self.v_r_max, self.x_span = v_r_max, x_span
        self.x_r = None              # 参考位置：第一次调用时对齐当前状态
        self.v_r = 0.0
    def step(self, f_ext, f_d, x_nom):
        if self.x_r is None:
            self.x_r = x_nom         # 初始化：以当前接触状态为参考，避免起始冲击
        e = f_d - f_ext
        # 速度形式的 P 律：力偏小就往里推、偏大就后退，方向一目了然
        self.v_r = float(np.clip(self.lam * e, -self.v_r_max, self.v_r_max))
        x_r_new = self.x_r + self.v_r * self.dt
        # 参考位置行程限幅：防止"找不到工件"时无限推进（第 022 章安全线）
        self.x_r = float(np.clip(x_r_new, x_nom - self.x_span,
                                 x_nom + self.x_span))
        return self.x_r

解读：类的状态只有"参考位置"一个积分状态，刷新公式是"e 乘 λ 再乘 dt"，没有加速度补偿、没有环境模型，这就是恒力控制可以做到十行代码的原因。x_span 限幅是关键安全线：没有它，拆掉工件后控制器会把参考位置推向无限远；有它，最坏情况也只是顶在 ±50 mm 的边界上等待超时保护。x_r 的初始化取当前名义位置；从零起步会带来"开机瞬间以 15 N 缺口全速冲压"的启动冲击，真机上这个对齐动作放在接触检测之后。

片段 2：阶跃 + 扰动实验与指标提取

def force_experiment(lam=0.01, dt=1e-3, T=5.0):
    """阶跃(5->15N @1s) + 表面凸起(0.5mm @3s) 一维仿真。"""
    k_env, x_e, k, m_d, d_d = 1e4, 0.08, 1000.0, 1.0, 150.0
    loop = ConstantForceLoop(lam, dt)
    x = x_e + 0.0005            # 初始压入 0.5mm -> 5N
    delta, delta_dot = 0.0, 0.0
    log, bumped = [], False
    for i in range(int(T/dt)):
        t = i*dt
        f_d = 5.0 if t < 1.0 else 15.0
        if (not bumped) and t >= 3.0:
            x_e -= 0.0005; bumped = True    # 凸包把表面推入 0.5mm
        f_ext = k_env*(x - x_e) if x > x_e else 0.0
        x_r = loop.step(f_ext, f_d, 0.0805)
        # 导纳内环：力大则 delta 增大、命令位置后退
        a = (f_ext - f_d - d_d*delta_dot - k*delta) / m_d
        delta_dot += a*dt; delta += delta_dot*dt
        x += (x_r - delta - x) * 0.3        # 内环伺服一阶近似
        log.append((t, f_ext))
    return np.array(log)

L = force_experiment()
t, f = L[:, 0], L[:, 1]
i1, ib = int(1.0/dt), int(3.0/dt)
r10 = t[i1+np.argmax(f[i1:] >= 6.0)] - 1.0
r90 = t[i1+np.argmax(f[i1:] >= 14.0)] - 1.0
print(f"上升时间 {1000*(r90-r10):.0f} ms, 峰值 {f[i1:ib].max():.2f} N")
print(f"凸起跳变 +{f[ib+2]-15:.1f} N, 峰值 {f[ib:ib+1500].max():.2f} N")
rec = next((t[j]-3.0 for j in range(ib, len(f)) if abs(f[j]-15) < 0.3), None)
print(f"恢复时间 {1000*rec:.0f} ms, 稳态误差 {abs(f[-1]-15):.3f} N")

解读：这段实验真机会对应一套动作，先空载对刀建立接触，再让 Fd 跳变，最后用校准过的位移台顶一下工件（或换一段带台阶的试件滑过去）。数字指标全部从日志里算，argmax 找首次到达 10%/90% 的采样点是最可靠的上升时间算法（比目测曲线强）。判断"恢复"用"首次进入并保持 ±0.3 N"更严谨，这里为简洁只取首次进入；真机报告里建议加 50 ms 保持窗。

片段 3：λ 扫描，把取舍做成表

def lambda_sweep(lams=(0.002, 0.01, 0.02, 0.05)):
    print(" lambda   上升(ms)   峰值(N)   恢复(ms)")
    for lam in lams:
        L = force_experiment(lam=lam)
        t, f = L[:, 0], L[:, 1]
        i1, ib = int(1.0/1e-3), int(3.0/1e-3)
        r10 = t[i1+np.argmax(f[i1:] >= 6.0)] - 1.0
        r90 = t[i1+np.argmax(f[i1:] >= 14.0)] - 1.0
        rec = next((t[j]-3.0 for j in range(ib, len(f))
                    if abs(f[j]-15) < 0.3), np.nan)
        print(f"{lam:6.3f}   {1000*(r90-r10):6.0f}   {f[i1:ib].max():7.2f}"
              f"   {1000*rec:6.0f}")

lambda_sweep()

解读：输出（本课环境实测）会是，λ=0.002: 17 ms / 15.35 N / 24 ms；λ=0.01: 9 ms / 16.06 N / 13 ms；λ=0.02: 6 ms / 16.53 N / 9 ms；λ=0.05: 5 ms / 17.18 N / 5 ms。三列数据讲出完整故事：速度与超调同向增长，恢复时间随增益下降；从 0.01 到 0.05 只换来 4 ms 的上升时间，却让峰值离验收线更近，边际收益递减，就是选择 λ≈0.01–0.015 的量化理由。真机做这张表时建议每档重复 3 次取中位数，先跑低增益建立基准，避免一开始就撞上振荡。

常见坑

  • 把恒力控制调成"力弹簧"：直接用 Fcmd = Fd 的力控模式、丢掉"误差推动参考位置"的积分结构，一旦环境刚度未知，稳态误差随 Kseries/Kd 漂移。修复：坚持"误差→运动→偏差被环境吃掉"的积分结构。
  • 参考位置无行程限制：拆件后控制器持续推进参考位置，下一次接触变成高速度撞击。修复：xspan 限幅 + 接触超时（第 022 章三件套）。
  • 把超调当"噪声"忽略：λ=0.05 时峰值 17.2 N 对 15 N 目标已过 15%，对压装类任务可直接压伤零件。修复：按任务设超调验收线（如 ≤10%），从低增益选起。
  • 扰动测试用"移动机器人"代替"移动工件"：两者的等效扰动不同，移动机器人引入了内环动态误差。修复：标准实验用位移台顶工件，机器人保持静止。
  • 只在一种环境刚度下验收：Kenv 从 1×104 换到 1×105，恢复时间缩短而超调与稳定裕度变化。修复：至少在"软垫/刚性"两种接触上各跑一遍 λ 扫描。

练习与思考

  1. 用 trise ≈ 1/(λKenv) 与 λ=0.01 估算 Kenv=5×103 与 1×105 两种环境下的上升时间，并用片段 2 的仿真验证（改 k_env），解释为什么"软环境响应反而慢"。★
    提示
    软环境需要更大行程才能建起同样的力，而位移速度由 λΔF 决定，所以慢；这也是"软接触要用大 λ 或位置前馈"的原因。
  2. 推导零静差结论：若把外环改成 vr = λ(Fd−F) + c（常数偏置），稳态力会偏多少？说明"任何不经过积分状态的常数项都会留下静差"。★★
    提示
    稳态 vr=0 给出 Fss = Fd + c/λ；只有把偏置放进被积分的状态（xr）里，才能让稳态与 c 无关。
  3. 实验：把 λ 固定为 0.05，把导纳阻尼 Dd 从 150 降到 60（ζ 从 0.7 降到 0.28），重跑阶跃实验，记录峰值与是否振荡；用劳斯上界公式解释。★★
    提示
    λmax ∝ Dd，D 降低后上界降到 0.066，λ=0.05 的裕度只剩 1.3 倍，肉眼可见的振荡趋势出现。
  4. 设计并执行：给出一个"两个 Fd（10 N 与 25 N）+ 两个扰动幅度（0.2/0.5 mm）"的实验矩阵，预测每个格子的跳变与恢复时间，然后仿真验证。哪个格子的指标最差？为什么？★★★
    提示
    跳变只随扰动幅度变化（KenvΔz），恢复时间与跳变无关而与 λKenv 有关；最差格子是"大扰动 + 小 λ"。
  5. 把片段 2 的恢复判据改成"进入 ±0.3 N 并保持 50 ms"，重新跑 λ 扫描，比较两种判据下的恢复时间差，说明为什么"保持窗"判据更接近生产验收。★★
    提示
    首次进入可能只是穿过误差带（还在振荡），保持窗确保真正收敛；两者差值就是"穿越型恢复"的代价，通常 5–30 ms。

小结

  • 恒力控制 = 速度形式 P 律（vr=λe）+ 参考位置积分状态；静差为零的两种等价解释：运动停止迫使误差为零 / 积分器补偿常值扰动。
  • 两条定量关系：扰动跳变 ΔF ≈ KenvΔz（环境刚度决定、躲不开）；恢复时间 ≈ 1/(λKenv)（增益决定、能优化）。
  • λ 的取舍由实验表量化：本课基准 λ=0.01 → 上升 9 ms、峰值 16.1 N、恢复 13 ms；λ 超过 0.05 后稳定裕度逼近 3 倍，进入谨慎区。
  • 实验范式固定为"阶跃 + 位移台扰动 + 指标提取"，并做多环境刚度验证；验收线写进参数表（上升/超调/恢复/静差）。
