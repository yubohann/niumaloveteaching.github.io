第五篇 · 鲁棒控制与工程实践

第 084 章：阻抗控制中的鲁棒项设计

摩擦、负载、未建模动态让"想要的柔顺"和"实际的柔顺"总差一截。本章给阻抗回路加一个只负责"把状态拽回设计流形"的鲁棒项：先用 sgn 把数学讲透，再用 sat 把抖振关进边界层，最后用一条统一公式量化鲁棒性的收益与代价。

  • 主题：鲁棒控制 / 滑模思想入门
  • 关键公式：τrob = −ρ·sat(s/ε)，|s|∞ ≤ ρ/(kv + ρ/ε)
  • 预计学时：60 分钟
  • 前置章节：第 083 章

学习目标

  • 理解阻抗控制回路里"不确定性从哪里来"：摩擦力、负载、关节柔性与未建模动态，为什么它们不能靠加大反馈增益解决。
  • 会定义误差流形 s = ė + Λe，并解释"流形上保持阻抗、流形外由鲁棒项收敛"的分工。
  • 会写李雅普诺夫函数 V = ½ms²，推导 sgn 鲁棒项在 |δ| ≤ ρ 下的收敛性，以及 sat 鲁棒项的最终有界性。
  • 会用公式 |s|∞ ≤ ρ/(kv + ρ/ε) 定量分析边界层 ε 的取舍：越小的 ε 越精确，但等效增益 ρ/ε 越大、越危险。
  • 能说出鲁棒项的三笔代价：残差、保守性、抖振风险，并知道各自的缓解手段。

背景与动机

到目前为止，我们的柔顺控制都默认一件事：控制器算出来的"虚拟动力学"能被机器人真实执行。真实系统里这个假设漏洞百出：关节摩擦吃掉 5–15% 的力矩、负载让惯量随姿态变化、谐波减速器的柔性只在低频近似刚性、线缆拖拽与气动管路又塞进一堆未知外力。结果就是你设计的是 Mdẍ + Ddẋ + Kde = −F 的柔顺，实际表现却带着一个"抹不掉的偏差"，比如恒定摩擦让末端总是落后期望位置一点，接触力也随偏。

加大反馈增益是工程师的第一反应，但它撞上两条硬墙：增益受采样与未建模动态限制，过了某个值就振荡；而且高增益会把"柔顺"变硬，阻抗控制的目的恰恰是管理刚度，误差只需落在设计范围内。鲁棒控制的思路完全不同：承认不确定性存在，用一个额外的力矩项去"支配"它，避开正面对抗。这个项不参与塑造理想动力学，只在系统偏离理想动态时工作。

本章先把这件事在一维上完整做一遍：定义误差流形、构造鲁棒项、证明最终有界性、量化取舍；同时，它会成为下一章"导纳控制中的滑模控制"的数学底座，那里的滑模面，就是这里的流形 s = 0。

核心原理

1. 不确定性长什么样：把问题写成"标称 + 未知有界项"

沿任务方向把机械臂的动力学做等价投影（关节空间 → 任务空间，惯量用操作空间惯量 Λ = J−TMJ−1），只研究一维形式：

m·ẍ = u + fext + δ(t)，|δ(t)| ≤ ρ u：任务空间等效力指令（N）；fext：接触力；δ：摩擦+负载偏差+未建模动态的"总账"，设保守界 ρ

为什么不把 δ 建模得更细？因为它的价值恰恰在于"不需要精确知道"。鲁棒项的设计只需要两个信息：界 ρ（最多有多大）与它进入系统的通道（这里是与控制量同一通道，称为匹配不确定性 matched uncertainty）。有界匹配不确定性是可以被"硬扛"的，这就是鲁棒项存在的全部理由。

2. 误差流形：把"好状态"定义成一个集合

理想的阻抗行为是 Md(ẍ−ẍd) + Dd(ẋ−ẋd) + Kd(x−xd) = −fext。为了设计鲁棒项，我们把它"折叠"成一个一阶条件，跟踪误差 e = x − xd 满足

s ≜ ė + Λe = 0，Λ > 0 s：误差流形坐标（单位 m/s）；Λ：流形斜率（单位 1/s），决定回到流形后的收敛快慢

s = 0 是一张"曲面"（实际上是相平面里过原点、斜率为 −Λ 的一条线延伸出的超面）：只要状态在 s = 0 上，位置误差就按 e(t) = e(0)·e−Λt 指数衰减，这就是我们愿意待的"理想流形"。控制设计从此分成两件事：

  • 流形外：用鲁棒项把 s 拽向 0，越快越强；
  • 流形上：行为由阻抗设计（Md、Dd、Kd）决定，鲁棒项不再改变它。

工程直觉：鲁棒项像过道两边的护栏，它不决定你去哪（轨迹由阻抗模型决定），只保证你不偏出走廊（s 有界且趋于零附近）。这一步抽象非常关键：它让"保证鲁棒性"与"设计柔顺性"解耦，两件事可以分别审查。

3. 李雅普诺夫推导：sgn 精确但抖振，sat 平滑但留残差

取 V = ½ms2（物理含义：偏离流形的"动能代价"），求导：

V̇ = m·s·ṡ = s( u − m·ẍr + δ )，其中 ẋr ≜ ẋ − s 是流形上的期望速度

选 u = unom + τrob，其中标称部分 unom = m̂ẍr − kvs 负责常规跟踪（kv > 0 是速度反馈增益，N·s/m），鲁棒项 τrob 专门对付 δ。先看理想形式（sgn）：

τrob = −ρ·sgn(s) ⟹ V̇ ≤ −kvs2 + |s|(ρ−ρ) = −kvs2 < 0 只要 ρ ≥ 未知项的真实上界，s 就在有限时间内到达 0，且之后不再离开（理想滑模）

数学上完美，工程上灾难：sgn 是理想开关，实际执行器带宽有限、采样离散，s 在 0 附近无法"无限快"地换向，表现为抖振（chattering），力矩指令高频跳变，听感是"咔咔"响，关节和减速器加速磨损。解决方案是给开关加一个线性过渡带（边界层 boundary layer），把 sgn 换成饱和函数：

τrob = −ρ·sat(s/ε)，sat(z) = z（|z|≤1），sat(z) = sgn(z)（|z|>1） ε > 0：边界层厚度，单位 m/s；|s| ≤ ε 时鲁棒项退化为高增益线性反馈 −(ρ/ε)s

把 sat 代回 V̇：在层外（|s| > ε）仍有 V̇ < 0，状态必然进入层内；在层内（|s| ≤ ε）有

V̇ ≤ −(kv + ρ/ε)s2 + ρ|s| ⟹ |s|∞ ≤ ρ/(kv + ρ/ε) 最终有界（UUB）：s 不会到零，但被压进一个可用公式算出来的小球里

这条统一公式请记牢，它把三种情形一网打尽：ε → 0 时右端 → 0（理想滑模，代价是抖振）；ε → ∞ 时右端 → ρ/kv（纯标称控制，残差最大）；中间的 ε 每减小一半，等效增益 ρ/ε 翻倍。工程直觉：鲁棒性不是免费的，你买到的"更小的残差"，是用"更大的层内等效刚度"换来的，而那个刚度正对着未建模动态的枪口。代入一组手感数字：ρ = 10 N、kv = 60 N·s/m、ε = 0.01 m/s，得 |s|∞ ≤ 10/(60+1000) ≈ 9.4 mm/s；再除 Λ = 20 s−1，位置残差不超过 0.47 mm，而纯标称下是 ρ/kv/Λ = 8.3 mm，鲁棒项把偏差压小了将近 20 倍。

4. 界 ρ 怎么来、代价怎么算

ρ 的选取是工程判断：先给各项不确定性"记账"，摩擦库仑力（如 6 N）、负载偏差（如 2 N）、未建模动态折算（如 3 N），再加 20–30% 的余量，得到 ρ ≈ 12–15 N。保守的 ρ 保证正确性但浪费能量（层内等效增益 ρ/ε 更大）；也可以让 ρ 自适应：ρ̂̇ = γ(|s| − σρ̂)，第一项在需要时增大，第二项（泄漏项，σ 小正数）防止 ρ̂ 无限增长。鲁棒项的三笔代价：残差（由公式定量）、保守性（ρ 按最坏情况定）、抖振风险（ε 越小越严重）。三者的缓解手段分别是：调 ε、自适应 ρ、加低通/高阶滑模，本章只做最基础的两招。

实现思路与设计

把鲁棒项嵌进阻抗控制器的步骤：

  1. 确定流形：由期望阻抗反解跟踪参考 xr（阻抗模型输出的"应该在哪"），或直接用 e = x − xr 构流形 s = ė + Λe。Λ 按"回到流形后的收敛时间"取：Λ = 20 s−1 对应 50 ms 时间常数，比力环慢、比自适应快。
  2. 算标称项：unom = m̂·ẍr − kvs；m̂ 用辨识的名义惯量，误差进入 δ。kv 取 40–80 N·s/m，保证标称回路本身接近临界阻尼。
  3. 算鲁棒项：τrob = −ρ·sat(s/ε)。ε 取 0.005–0.02 m/s（对应速度噪声的 3–10 倍），ρ 先按最坏情况 12–15 N。
  4. 限幅与滤波：τrob 单独限幅（如 ±15 N），并用 100–200 Hz 一阶低通做最后一道防抖，注意低通会引入相位滞后，因此 ε 不能贴到噪声下限。
  5. 映射到关节：任务空间合力 Fc = unom + τrob，关节力矩 τ = JTFc（单位 N·m）；这一步复用第 008 章的笛卡尔阻抗框架，鲁棒项只是多出来的一个求和项。
设计决策：为什么鲁棒项不"顺便解决"接触力误差？

有人希望鲁棒项把稳态接触力偏差也压掉。可以，但要想清楚代价：那相当于让鲁棒项与阻抗弹簧"抢活"，接触瞬时冲击会被硬扛，柔顺手感被破坏。正确分工是：鲁棒项只负责把状态压回流形（动力学残差、摩擦），稳态力精度留给第 082 章的学习辅助与第 083 章的自适应增益（它们动的是前馈与增益，不硬扛冲击）。每章方法只解一类问题，是本课程反复强调的原则。

关键代码与解读

片段 1：鲁棒项本体与流形构造

import numpy as np

class RobustTerm:
    """阻抗回路的鲁棒项：把状态拽回流形 s = e_dot + Lambda*e。"""
    def __init__(self, lam=20.0, rho=12.0, eps=0.01, tau_max=15.0):
        self.lam = lam          # 流形斜率：回到流形后的误差收敛时间 = 1/lam = 50 ms
        self.rho = rho          # 不确定性上界（N）：摩擦 + 负载偏差 + 未建模动态
        self.eps = eps          # 边界层厚度（m/s）：在"残差"与"抖振"之间折中的旋钮
        self.tau_max = tau_max  # 鲁棒项单独限幅：它不允许主导整个控制力矩

    def manifold(self, e, de):
        # s 的量纲是速度：数值上等于"沿流形方向还差多远"
        return de + self.lam * e

    def torque(self, e, de):
        s = self.manifold(e, de)
        # sat: |s|<eps 时成为高增益线性反馈 -(rho/eps)s，等效刚度 rho/eps
        z = np.clip(s / self.eps, -1.0, 1.0)
        tau = -self.rho * z
        return float(np.clip(tau, -self.tau_max, self.tau_max)), s

解读：类里三个参数与理论的对应关系一目了然，lam 对应 Λ，rho 对应界 ρ，eps 对应边界层 ε。为什么把 np.clip(s/eps, -1, 1) 作为 sat？因为 sat 的数学定义就是"裁剪"，一行实现且向量化安全。为什么给鲁棒项单独限幅？当传感器瞬间跳变或状态估计出错时，s 可能冲到很远，sgn/sat 结构会输出满值力矩；独立限幅保证最坏情况下鲁棒项也只贡献 ±15 N（约等于 2 kg 负载的重力），不会把机器人"甩"出去。注意返回值里同时给出 s，便于日志里观察"状态离流形多远"。

片段 2：带鲁棒项的阻抗回路一维仿真

def run_case(mode, rho=12.0, eps=0.01, m=2.0, k_v=60.0, lam=20.0):
    """mode: 'none' 无鲁棒项 / 'sat' 饱和 / 'sgn' 理想开关。"""
    dt, n, dv = 1e-3, 1500, -8.0        # dv：恒定摩擦等效扰动 8 N（保守取 ρ 的 2/3）
    x, v, x_r = 0.0, 0.0, 0.0
    u_log = []
    for i in range(n):
        x_r += 0.1 * dt                  # 参考沿 +x 以 0.1 m/s 平移
        e, de = x - x_r, v - 0.1
        s = de + lam * e                 # 误差流形坐标
        u = -k_v * s                     # 标称项：恒定速度参考不需要加速度前馈
        if mode == "sat":
            u += -rho * np.clip(s / eps, -1.0, 1.0)
        elif mode == "sgn":
            u += -rho * np.sign(s)       # 无边界层：理想滑模，实际会抖振
        v += (u + dv) / m * dt           # 一维动力学：m v. = u + 干扰
        x += v * dt
        u_log.append(u)
    return x - x_r, np.std(u_log[-200:])  # 末态位置误差、末端力矩指令的抖动强度

for mode in ("none", "sat", "sgn"):
    e_ss, jitter = run_case(mode)
    print(f"{mode:4s}  位置残差={e_ss*1000:6.2f} mm  力矩抖动={jitter:6.2f} N")

解读：这段仿真把三种情形放在同一扰动（8 N 摩擦）下对照。预期：none 残差 ≈ −6.7 mm（理论值 dv/(k_v·Λ) = 8/60/20）；sat 残差 ≈ −0.4 mm（理论 |s|/Λ = 9.4 mm/s / 20）；sgn 的残差也不大，但 jitter 高达数牛，这就是抖振的量化特征：位置看起来还行，力矩指令却在每毫秒翻转。为什么这个对照实验设计得好？因为它同时考察了"精度"与"平滑"两个指标，避免只盯残差就误选 sgn。真机上 sgn 的抖动还会激励未建模动态，把"看起来还行"的位置也毁掉。

片段 3：ρ 自适应（泄漏版），降低保守性

class AdaptiveRho:
    """ρ̂ 自适应：不预先给最坏界，让 |s| 自己把 ρ̂ 抬到需要的水平。"""
    def __init__(self, rho0=2.0, gamma=50.0, leak=0.05, rho_max=25.0):
        self.rho_hat = rho0
        self.gamma = gamma    # 增益：ρ̂ 上升得快慢（1/s 量级）
        self.leak = leak      # 泄漏项 σ：没有持续需求时让 ρ̂ 缓慢回落
        self.rho_max = rho_max

    def update(self, s, dt):
        # 需求项 gamma*|s|：只要还在层外，就说明"现在的 ρ̂ 不够用"
        # 泄漏项 -leak*rho_hat：防止一次碰撞把 ρ̂ 永久钉在最大值（那等于退化回保守）
        self.rho_hat += (self.gamma * abs(s) - self.leak * self.rho_hat) * dt
        self.rho_hat = float(np.clip(self.rho_hat, 0.5, self.rho_max))
        return self.rho_hat

解读：两行更新律对应两个设计意图：需求项让 ρ̂ 跟踪不可预见扰动的强度；泄漏项提供"记忆衰减"，让 ρ̂ 在扰动结束后回落，没有泄漏，系统会把历史上最恶劣的一次事件永远记住，鲁棒项从此一直用力，等效于把 ρ 永久设成最坏值，白付保守性的代价。把 leak 设得太大则 ρ̂ 总是低估，s 长期在层外徘徊；一般取 0.02–0.1 s−1，配合 gamma=30–80。

常见坑

  • 用 sgn 上真机：仿真里"收敛完美"，实机上力矩高频翻转、噪音刺耳、减速器快速磨损。修复：一律用 sat（或再叠加 100–200 Hz 低通），把 ε 从 0.02 m/s 起调小。
  • ε 贴到速度噪声量级：ε 取 0.001 m/s（与差分速度噪声相当）后，s 的噪声让 sat 一直在正负 1 间切换，抖振从"开关"变成了"宽带噪声"。修复：ε ≥ 3–10 倍速度估计噪声（当前 1 ms 差分 + 滤波下通常 0.005 m/s 起）。
  • ρ 给小了还宣称"已验证"：ρ 小于真实不确定性时，|s| 停在 ρ 达不到的边界外，公式给出的球体不成立，抖动和残差同时出现。修复：ρ 按不确定性清单加 30% 余量，或用自适应 ρ̂ 并保留 ρmax 兜底。
  • 把鲁棒项算进"期望刚度"里：层内等效增益 ρ/ε（例：1000 N·s/m 量级）远大于 Dd（几十 N·s/m），有人据此认为"系统变硬了"。其实这只作用于 s 方向（快到流形的动态），接触稳态行为仍由阻抗参数决定，但前提是流形设计正确、ε 不畸小。
  • 不做限幅：鲁棒项在未接触→突接触的瞬间可能整段满出力，若 ρ 偏大甚至与阻抗弹簧"互顶"。修复：鲁棒项与总力矩双重限幅，并给接触过渡段 5–10 ms 的软切换。

练习与思考

  1. 取 V = ½ms2，推导带 sat 鲁棒项的 V̇，并求出最终界 |s|∞ ≤ ρ/(kv+ρ/ε)；验证它总小于 ε 的原因。★
    提示
    ρ/(kv+ρ/ε) < ε ⟺ ρ < kvε + ρ，恒成立。这意味着 s 最终总会停在边界层内部，层外只是"路过"。
  2. 用片段 2 的代码，把 ε 设为 0.05 / 0.01 / 0.002 m/s 三档，跑 sat，记录位置残差与力矩抖动，作出两者的"权衡曲线"，并选出一个你推荐的 ε。★★
    提示
    残差按 ρ/(Λ(kv+ρ/ε)) 随 ε 减小而减小；抖动随 ε 减小而上升。推荐点应在"抖动尚未明显上升、残差已进入毫米以下"的膝部，约 0.005–0.01。
  3. 推导"无鲁棒项"的稳态残差：由 mṡ = −kvs + δ 求 sss = δ/kv，再乘 1/Λ 得位置残差；与带鲁棒项的公式对比，解释两种残差的结构差异。★★
    提示
    无鲁棒：（kv）−1；有鲁棒：（kv + ρ/ε）−1。后者相当于把有效增益放大了 (1 + ρ/(kvε)) 倍，边界层越薄放大越多。
  4. 设计实验：让摩擦扰动在仿真中途从 8 N 突增到 20 N（超过 ρ=12），观察 s 的越界与 ρ̂ 未被自适应时的残差；再打开片段 3 的自适应 ρ̂，记录 ρ̂ 的上升时间与回落的泄漏速度。★★★
    提示
    ρ 不足时，s 停在 −(20−12)/kv ≈ −0.13 m/s 处不再收敛；自适应后 ρ̂ 按 γ|s| 的速率爬升到约 20，随后由泄漏项缓慢回落。观察"上升快、回落慢"的不对称是设计特征还是缺陷。

小结

  • 鲁棒项要解决的问题：匹配不确定性（摩擦、负载偏差、未建模动态）让理想阻抗无法逐字实现；它只依赖界的假设 |δ| ≤ ρ，不依赖模型细节。
  • 设计分工：流形 s = ė + Λe 上保持阻抗行为，流形外由鲁棒项 τrob = −ρ·sat(s/ε) 收敛；V = ½ms² 给出证明。
  • 核心公式：最终界 |s|∞ ≤ ρ/(kv+ρ/ε)，ε→0 退化为理想滑模（抖振），ε→∞ 退化为纯标称控制（残差 ρ/kv）。
  • 三笔代价与对策：残差（调 ε）、保守性（自适应 ρ̂ 带泄漏）、抖振（sat + 限幅 + 低通）。
  • 下一章把这套思想搬到导纳一侧：导纳方程生成参考轨迹，滑模面负责让位置内环"贴着"参考滑动，你会看到同样的 sat、同样的边界层，只是"被控对象"换成了位置环。
