第 053 章：阻抗控制中的时变刚度

接近时软、接触时硬、精调时更硬，任务阶段要求刚度会变。但刚度不是一个"随手可调"的旋钮：它代表储存在虚拟弹簧里的能量，悄悄调大相当于往系统里注能。本章推导能量注入速率 ½K̇e²，并给出"平滑调度 + 阻尼同步 + 能量监督"的安全切换方案。

  • 主题：变阻抗 / 增益调度与能量分析
  • 关键公式：V = ½Mv² + ½K(t)e²，V̇ = −Dv² + ½K̇e² + v·Fext
  • 预计学时：55 分钟
  • 前置章节：第 052 章（导纳控制中的环境刚度辨识）

学习目标

  • 理解刚度调度的任务动机：为什么单一刚度无法同时满足安全性、过渡平稳与任务精度。
  • 会推导时变刚度下的能量方程，认出 ½K̇e² 这一"注能项"，并能估算一次刚度跳变的动能后果。
  • 掌握三条安全规则：平滑调度（smoothstep）、阻尼同步重算、静止/近平衡门控。
  • 会写能量监督器：用李雅普诺夫函数 V 的增量做在线审计，超限即冻结刚度上升。
  • 知道时变刚度如何与第 058 章的能量储藏槽（energy tank）衔接。

背景与动机

任务会"换挡"，刚度就得跟着换：机器人空载接近工件时要软（撞上也不疼）；压上表面进入磨削/装配时要硬一些（位置确定性好、力分辨率高）；做精细贴合时又要变软（跟随型面）。第 043 章的人机协作场景里也是同一套逻辑：空闲段软、任务段硬。于是"时变刚度"看起来只是"按阶段把 Kd 从 300 调到 1200 再调回来"这么简单。

但物理学不允许免费换挡。虚拟弹簧里存着能量 ½Kde²，把 Kd 调大而不动 e，储能会凭空增加，这份能量不是从电机来的，就是"凭空"，而"凭空造能量"的控制器在闭环里意味着失稳风险。见一个数字：e = 10 mm、K 从 400 跳到 2000 N/m，储能从 0.02 J 变成 0.1 J，多出 0.08 J；对一个 1 kg 的等效质量，如果全转成动能就是 0.4 m/s 的速度跳变，"换挡"瞬间机器人会弹一下。本章就是给换挡装上"变速箱与刹车"。

核心原理

1. 时变系统的能量账本

对时变阻抗模型 Mdẍ + Ddẋ + Kd(t)(x − xd) = Fext（Fext 取环境作用于系统的带符号力），取李雅普诺夫函数（虚拟系统的总能量）：

V(t) = ½Mdv² + ½Kd(t)e²， e = x − xd 第一项：动能；第二项：虚拟弹簧的势能；V 是"系统自能量"的度量

对时间求导并代入动力学方程（取 Fext 为外部注入功率项）：

V̇ = v·Mdv̇ + Kde·ė + ½K̇d·e² = −Ddv² + ½K̇de² + v·Fext 阻尼项 −Ddv² 永远耗散；½K̇de² 与 Kd 的变化率有关；最后一项是环境交换的功率

这是全章的核心公式。三个项的读法：（1）阻尼耗散是熟悉的"刹车"；（2）½K̇de² 是"隐性油泵"，只要在 e ≠ 0 时调大刚度（K̇d > 0），系统就在注入能量；（3）外力项可以正可以负（环境可以吸能也可以放能，但被动环境保证其长期平均不放能）。要让系统对任意被动环境都稳定（无源），最基本的一条是：K̇d > 0 时注入的能量必须被记账、被限制，最好直接以阻尼或储藏槽兜住。

2. 失败模式定量：一个"跳变"到底多危险

设切换时 v ≈ 0（很多实现就发生在"停稳后换挡"），阻尼耗散项为零，误差 e = 10 mm：

ΔV = ½(K2 − K1)e²， K1 = 400 → K2 = 2000 N/m ⟹ ΔV = ½×1600×10−4 = 0.08 J

这 0.08 J 若进入"虚拟质量动力学"，最终会以动能与耗散的形式重新分配；在最坏假设下全部转成速度：Δv = √(2ΔV/Md) = √0.16 ≈ 0.4 m/s（Md = 1 kg）。即使这个估计偏保守（实际上阻尼会吃掉一部分），0.1–0.2 m/s 的"换挡弹跳"也足以在装配时撞出划痕。工程直觉：时变刚度的风险不在稳态，而在切换的那 200–500 ms；设计目标是让这段时间里 K̇de² 的功率低于阻尼的耗散能力。

3. 三条安全规则

  1. 平滑调度：用 smoothstep 曲线 s(u) = 3u² − 2u³（u ∈ [0,1]）在切换时长 T 内插值。它在两端的一阶导数都为零，位置和"力"都无跳变，这是"柔性换挡"的标准做法。切换时长 T 的规则：T ≥ 3×max(自然周期 2π√(Md/Kd))，使过程"准静态"。
  2. 阻尼同步：每一步按 Dd = 2ζ√(KdMd)（ζ 取 1–1.2）重算阻尼。若只升 K 不升 D，阻尼比 ζ 掉到 0.3 以下，切换期间必然振荡；反之升 D 额外花钱（电机力矩），所以一般升档先升 D 再升 K，降档先降 K 再降 D。
  3. 平衡门控：K̇d > 0 的"注能方向"切换（即 K 增大）尽量安排在 |e| 小或 |v| 小的时刻；最保守的规则是"K 只在接近平衡（|v| < 5 mm/s）时允许增大"。

补充一条实用的第四条：能量监督器。对 V(t) 做在线积分/增量审计，若发现 V 在无外力条件下增长超过阈值（比如 20 mJ/0.1 s），立即把 K̇d 置零并短暂加大 Dd，这是继"规则"之后的最后防线。

实现思路与设计

调度器的输入是"目标刚度档位"，输出是每一拍实际使用的 (Kd, Dd)。流程：

  1. 档位管理：任务状态机给出目标值 Ktarget（如接近 300、磨削 1200、精调 800），切换时记录起点 K0 与时刻 t0。
  2. 平滑插值：Kd(t) = K0 + (Ktarget − K0)·s((t−t0)/T)；T 按自然周期规则取 0.4–1.0 s。
  3. 阻尼伴随：Dd = 2ζ√(KdMd)，ζ = 1.0；同时给 Dd 加一个"切换加成"（例如 ×1.2），用额外的黏性吸收注能。
  4. 能量监督：每周期计算 V[k]，维护滑动窗口内的 ΔV；超过阈值（如 20 mJ/100 ms）→ 冻结 Kd、临时升 Dd，并在日志里报警。
  5. 角度/位置量程检查：e 超过工作范围时不准升 K（e 大时 ½K̇e² 的注能最猛）。

与第 058 章衔接：能量监督器在这里是"报警+冻结"，在 058 章演进为"储藏槽记账+配额发放"，同一套能量思想的两个成熟度等级。

关键代码与解读

片段 1：平滑刚度调度器（含阻尼同步）

import numpy as np

class StiffnessScheduler:
    """刚度档位之间的平滑调度：smoothstep 插值 + 阻尼同步。
    规则：T 不小于 3 倍自然周期；zeta 恒为 1；只允许慢慢“换挡”。"""
    def __init__(self, m_d=1.0, zeta=1.0, T=0.6, dt=1e-3):
        self.m_d, self.zeta, self.T, self.dt = m_d, zeta, T, dt
        self.k = 300.0                  # 当前刚度
        self.k0 = 300.0                 # 切换起点
        self.k_target = 300.0
        self.tau = T                    # 当前切换已进行的时间
        self.moving = False

    def set_target(self, k_target):
        if abs(k_target - self.k_target) > 1e-9:
            self.k0, self.k_target = self.k, k_target   # 记录起点
            self.tau, self.moving = 0.0, True

    def step(self):
        if self.moving:
            self.tau = min(self.tau + self.dt, self.T)
            u = self.tau / self.T
            # smoothstep：两端斜率为零 → 力与位置都不出现跳变
            s = 3.0 * u * u - 2.0 * u * u * u
            self.k = self.k0 + (self.k_target - self.k0) * s
            if self.tau >= self.T:
                self.moving = False
        # 阻尼同步：切换期间额外加 20% 黏性，用耗散兜住注能项
        z = self.zeta * (1.2 if self.moving else 1.0)
        self.d = 2.0 * z * np.sqrt(self.k * self.m_d)
        return self.k, self.d

解读：（1）smoothstep 的"两端斜率为零"是针对"力 = K·e"和"阻抗方程的加速度项"都能连续而选择的：线性插值在两端有斜率突变，实测中会在切换起点/终点听到轻微的"嗒"声。（2）阻尼同步写成函数（不写常量），是为了保证任何时刻 ζ 都不掉队；切换期间的 ×1.2 加成是经验的"刹车片"。（3）切换时长 T = 0.6 s 的由来：最硬档 K = 1200 N/m、M = 1 kg 的自然周期约 0.18 s，T ≈ 3.3 倍，满足"准静态"规则；如果档位差更大（300→3000），把 T 拉到 1 s 更稳。（4）同一目标重复下发时不重启插值（if abs(...) > 1e-9），否则调度器永远"刚到一点又起步"，K 卡在中间状态，这是个很容易写出的 bug。

片段 2：能量监督器

class EnergySupervisor:
    """用虚拟系统能量 V = M v^2/2 + K e^2/2 做在线审计：
    无外力时 V 只应下降；窗口内增长超阈值 → 冻结刚度上升。"""
    def __init__(self, m_d=1.0, window=0.1, dv_max=0.02, dt=1e-3):
        self.m_d, self.dt = m_d, dt
        self.window, self.dv_max = window, dv_max   # 20 mJ/100 ms
        self.hist = []                              # (t, V) 滑动窗口
        self.fault = False

    def update(self, k, e, v, f_ext):
        V = 0.5 * self.m_d * v * v + 0.5 * k * e * e
        self.hist.append(V)
        n_win = max(2, int(self.window / self.dt))
        if len(self.hist) > n_win:
            self.hist.pop(0)
        dv = self.hist[-1] - self.hist[0]
        # 外力在消耗/注入能量时会混淆审计：|f_ext| 小才严格判据
        if abs(f_ext) < 1.0 and dv > self.dv_max:
            self.fault = True       # 无外力却“凭空”长能量：冻结升级
        if dv < 0.0:
            self.fault = False      # 能量回落（阻尼在耗散）→ 解除
        return V, self.fault

解读：（1）审计窗口选 100 ms、阈值 20 mJ：对 M = 1 kg、K = 1200 的系统，20 mJ 对应约 0.2 m/s 或 e ≈ 6 mm 的能量尺度，低于"机器人弹一下"的感知阈值，能提前拦住恶性切换。（2）判据里排除外力大的时段：环境中的人推、摩擦突变都会改变 V，把它们算进"凭空造能"会误报。精细版本应把外力功率也纳入账本（第 058 章的完整形式）。（3）fault 解除条件不看"窗口是否增长"，只看"V 是否回落"：系统必须有真实的耗散发生才解禁，防止在能量平台上"解禁→再注入→再冻结"的锯齿。（4）监督器不修改控制律本身（不越权），只输出 fault 标志；是否冻结由调度器决定，职责分离让调试时的因果关系清晰。

片段 3：跳变 vs 平滑的对比实验

def switch_test(smooth, k1=400.0, k2=2000.0, T=0.4, dt=1e-3):
    """在 e=10 mm、v=0 的初始条件下切换刚度，记录速度峰值。
    smooth=False 为“示波器上看着也平滑”的 10 ms 线性插值，依然危险。"""
    m_d, zeta = 1.0, 1.0
    x, v, e0 = 0.010, 0.0, 0.010
    k, d = k1, 2.0 * np.sqrt(k1 * m_d)
    v_peak, t_peak = 0.0, 0.0
    nT = max(int(T / dt), 1)
    for i in range(int(1.5 / dt)):
        if i < nT:                        # 切换阶段：s 的导数形状决定注能功率
            u = i / nT
            s = (3*u*u - 2*u*u*u) if smooth else u
            k = k1 + (k2 - k1) * s
            d = 2.0 * zeta * np.sqrt(k * m_d)
        # 系统动力学：M v' = -Dv - K e，e 从 x - 0 计
        a = (-d * v - k * x) / m_d
        v += a * dt
        x += v * dt
        if abs(v) > abs(v_peak):
            v_peak, t_peak = v, i * dt
    return v_peak, t_peak

for smooth in (False, True):
    vp, tp = switch_test(smooth)
    print(f"smooth={smooth}  速度峰值={vp*1000:7.2f} mm/s  t_peak={tp*1000:6.1f} ms")

解读：这个实验甩掉了执行器与外部环境，只看"虚拟系统自己"的能量。运行结果（量级）：线性快速切换（即使看起来"只用了 0.4 s"）速度峰值数十到一百 mm/s；smoothstep 版本峰值明显更低，因为注能功率 ½K̇e² 在两端被平滑到零，能量来得及被阻尼耗散。把 T 从 0.4 提到 1.0 再对比，两条曲线都会下移，这正是 T ≥ 3×自然周期规则的来历。再试把切换起点放在 |e| 更小的状态（把 x 初值改成 2 mm），峰值按 e² 比例骤降，直观验证"平衡门控"的价值。也可以把代码里 d 固定成 k1 的阻尼（不随 K 更新）看振荡：ζ 崩到 0.45 附近时速度峰值会明显上翘。

常见坑

  • 把"快点切"当优化：认为切换越快越不容易被察觉，结果是切换瞬间弹跳更猛（注能功率与 K̇ 成正比）。修复：T ≥ 3×自然周期，宁可慢半秒。
  • 只调 K 忘了 D：切换期间 ζ 掉到 0.3–0.5，出现"换挡抖"。修复：D 随 K 同步重算，切换期间再给 20% 加成。
  • 在大力接触时升刚度：e 大、K̇ 大，注能按 e² 放大，最坏情况触发过流保护。修复：平衡门控（|v| 小、|e| 小、无外力冲击）才允许升 K。
  • 能量监督阈值拍脑袋：阈值设成 1 J，等于没有；设成 1 mJ，正常切换天天报警、系统被冻结在中间刚度。修复：以"允许的速度跳变"反算阈值：ΔV = ½MΔv²，Δv 取 0.05–0.1 m/s。
  • 和饱和打架：高刚度瞬时要求大加速度，电机力矩饱和后虚拟动力学失效，切换过程出现"贴墙不动+积分堆积"。修复：切换期间同时检查力矩余量（第 060 章展开）。

练习与思考

  1. 推导 V̇ = −Ddv² + ½K̇de² + vFext：从 V = ½Mdv² + ½Kde² 出发，注意 Kd 是时间的函数、e 的导数不依赖 ḱd，逐项写出。★
    提示
    d(½Kde²)/dt = ½K̇de² + Kdeė；把 Mdv̇ 用阻抗方程替换后 Kde 项与加速度项相消，剩下 −Ddv²。
  2. 对 Md = 2 kg、e = 5 mm，分别计算 K 从 500→1500 以 (a) 0.1 s 线性、(b) 0.5 s smoothstep 切换的注能功率峰值，并求最坏情况下的速度跳变。★★
    提示
    (a) K̇ = 104 N/(m·s)，功率峰值 ½×104×2.5×10−5 = 0.125 W，持续 0.1 s → 12.5 mJ → Δv = √(2E/M) ≈ 0.11 m/s；(b) 平滑后注能功率峰值约为 (a) 的 1.5ΔK/(T·K̇) ≈ 0.3 倍，速度跳变随之更低。
  3. 用片段 3 的 switch_test 扫描 T ∈ {0.1, 0.2, 0.4, 1.0}，画（或打印）速度峰值 vs T，验证"T 增大到 3×自然周期后收益递减"，并解释 T 太大会有什么新代价（提示：任务节拍与真实误差干扰）。★★
    提示
    注能总量与 T 无关、功率峰值 ∝ 1/T；但 T 越长，任务在"低刚度档"滞留越久，精度与节拍受损，而且长过程的准静态假设可能被外力扰动打破。
  4. 给 EnergySupervisor 加一个"升级配额"：不仅审计 V 的增量，还记录"历史耗散余量"（阻尼累计耗散 − ∫Dv²dt），只有当耗散余量大于待注入能量时才允许 K 上升。写出改造后的判据，并说明它与第 058 章能量储藏槽的关系。★★★
    提示
    定义 Etank += max(0, −V̇_window)（耗散收益存入），升级需 Etank ≥ ½ΔK e²；这就是能量槽的"先存后花"思想，058 章会把它形式化为 Ṫ = −Pc 的记账式。

小结

  • 时变刚度是任务刚需，但 K̇de²/2 是"隐性油泵"：在 e ≠ 0 时升刚度等于向系统注入能量。
  • 能量账本：V̇ = −Ddv² + ½K̇de² + vFext；阻尼永远耗散，刚度变化率必须被管住。
  • 三条安全规则：smoothstep 平滑调度（T ≥ 3×自然周期）、阻尼同步重算（ζ ≥ 1）、平衡门控（近平衡才允许升 K）。
  • 能量监督器用 V 的窗口增量做审计，无外力时的增长超过阈值即冻结，阈值按允许速度跳变反算。
  • 速度跳变估算 Δv = √(ΔK·e²/Md) 是评估任何调参方案的第一把标尺。
  • 下一章转向它的镜像问题：时变阻尼。阻尼在能量上是"只耗散、不储能"的，所以切换更安全，但切换会怎样影响手感与噪声？
