第一篇 · 基础、建模与稳定性

第 013 章：基于动力学模型的阻抗控制

把机器人全套动力学（惯量、科氏、重力）一次算净，让实际加速度等于外环开出的期望值，虚拟阻抗从此连"质量"都能刻进系统。代价是模型误差从此进入回路。

  • 主题：阻抗控制 / 计算力矩与惯性整形
  • 关键公式：τ = M̂q̈des + Ĉq̇ + ĝ − JTF̂ext，q̈des = J−1(ẍcmd − J̇q̇)
  • 预计学时：60 分钟
  • 前置章节：第 012 章

学习目标

  • 会写出完整机器人动力学 M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + JTFext，并解释每一项在阻抗控制里的角色。
  • 掌握计算力矩（computed torque）结构：外环解期望加速度、内环用模型"抵消"真实动力学，实现惯量整形。
  • 理解 −JTF̂ext 项的必要性：不多不少注入一次外力，才能让 Fext 精确出现在期望阻抗方程里。
  • 会推导理想模型下闭环与期望阻抗的严格相等，并说出其中每一步用到的假设（J 可逆、模型精确、无未建模动态）。
  • 能定量评估模型误差的影响：质量 +30%、重力偏置等失配下，稳态力与瞬态超调各变化多少。

背景与动机

第 006 章展示了 Level-0 力接口的物理阻抗：简单、稳，但虚拟质量被物理惯量"锁死"，手臂伸直和弯曲时手感不一样，快速碰撞的动能也不受控。要让柔顺控制走出"慢速接触"的舒适区，就必须动真格：把机器人的惯量、科氏、重力全部显式计算出来、在控制律里逐项抵消，再按设计值重新注入。

这套方法叫计算力矩控制（computed torque）或反馈线性化，是机器人控制的经典骨架；在阻抗控制里它负责回答一个尖锐的问题：怎么让真实的六轴机器人表现得像一台"质量、阻尼、刚度都随你定"的理想机器？答案是把动力学当作一笔可计算的"债务"，一次还清。本章先在 2 连杆上把推导与代码走通，再讨论模型误差这条现实的尾巴。

核心原理

1. 完整动力学：三笔"债务"

机器人关节空间的完整动力学：

M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + JTFext M(q)：关节惯量矩阵（kg·m²）；C(q,q̇)q̇：科氏与离心力矩（N·m）；g(q)：重力矩（N·m）

第 006 章的 Level-0 只处理了"右边"（输出弹簧-阻尼力矩），M、C、g 三笔债务原样留在方程左边，于是表观惯量只能是物理惯量。计算力矩的思路是反过来：先由外环算出"希望的关节加速度" q̈des，然后输出一笔力矩，把左边的债务按模型全部还掉、再把 q̈des 顶进去。

2. 外环：把期望阻抗解成期望加速度

任务空间的期望阻抗沿用第 007 章的模板（δ = x − xd 为偏差，Fext 为作用在末端的广义力）：

Mdδ̈ + Ddδ̇ + Kdδ = Fext ⟹ ẍcmd = ẍd + Md−1[Fext − Dd(ẋ − ẋd) − Kd(x − xd)] 这里是"先解方程再实现"：加速度是外环的输出，Md 真正参与动态（惯量整形）

再把任务空间加速度换算成关节空间（对 ẋ = Jq̇ 求导得 ẍ = Jq̈ + J̇q̇）：

q̈des = J−1(ẍcmd − J̇q̇) J̇q̇ 称为"运动学科氏项"：构型变化带来的加速度修正；必须补，否则高速时姿态回不到期望

3. 内环：计算力矩，把 q̈des 顶进系统

输出力矩取为：

τ = M̂(q)·q̈des + Ĉ(q,q̇)q̇ + ĝ(q) − JTF̂ext 带帽的量表示模型估计值；−JTF̂ 用于把外力从回路中"取出来"

把它代回动力学。假设模型精确（M̂=M 等）、力的估计精确（F̂ext=Fext）：

Mq̈ + Cq̇ + g = [Mq̈des + Cq̇ + g − JTFext] + JTFext ⟹ q̈ = q̈des

再经 q̈des 的定义逆推：Jq̈ + J̇q̇ = ẍcmd，即 ẍ = ẍcmd。最后把 ẍ = ẍcmd 代入外环表达式，得到严格的期望阻抗 Mdδ̈ + Ddδ̇ + Kdδ = Fext。三个"债务项"（M、C、g）被逐项抵消，虚拟质量 Md 第一次真正参与系统动态，这就是惯性整形的实现，也是 Level-2 与 Level-0 的分水岭。

几个必须想清的设计点：为什么 τ 里要减 JTF̂，动力学里外力已经以 +JTF 的形式存在一次；如果控制律不把它取出来，闭环会多出一份 "M−1JTF"，等于外力被"免费放大"，期望阻抗失效。减去一次之后，Fext 只通过外环的 Md−1Fext 进入，系数正好是设计值。为什么 J̇q̇ 不能省，它的量级在高速时可达几十 m/s²，直接体现为"圆周运动时姿态总是差一截"的系统性误差。为什么 q̈des 走 solve 解方程这条路，数值稳健，且 J 近奇异时可以用阻尼最小二乘/伪逆自然扩展（伪逆情形下 q̈des 只保留可控方向）。

工程直觉：计算力矩像给机器人换了一副"理想骨骼"，不管它原来多重、多别扭，控制器都按你画的骨架去动；外环阻抗则是在这副理想骨骼上安装质量-弹簧-阻尼。骨骼仿真度（模型精度）决定这套动作"像不像"。

4. 模型误差：理想闭环的裂缝

现实中 M̂ ≠ M、Ĉ ≠ C、ĝ ≠ g，还有摩擦与传动柔性没建模。把失配写成 ΔM = M̂ − M 等，闭环变为：

q̈ = q̈des + M−1[ΔM·q̈des + ΔC·q̇ + Δg + ΔJTFext] 误差项与期望加速度、速度、载荷成正比；静止或慢速接触时只剩 Δg 与 ΔJTF 的常值影响

误差的工程化读法有三条：（1）慢接触看重力误差，ĝ 偏 10 N·m 相当于给某些关节加了恒力偏置，稳态力偏移由阻抗刚度折算，重载工具必须把负载项并入 g；（2）快动作看惯量误差，ΔM 使有效质量偏离 Md，瞬态的超调与峰值时间随失配漂移；质量辨识误差 20% 通常造成 10%–20% 的瞬态偏差，但系统仍稳定（失真不丢稳）；（3）失配可以"吸收"进设计指标，把 Md 取成"物理惯量估计值的加权平均"，让 Δ 的双向偏差对称，这比追求参数级精确更实用。

实现思路与设计

把计算力矩阻抗接进控制器，按以下顺序落地并验收：

  1. 模型来源：URDF/参数辨识 → 逆动力学（RNE）函数，给出 M(q)、C(q,q̇)q̇、g(q)。每拍调用一次，1 kHz 下 6 轴 RNE 的耗时在几十微秒量级，完全可承受。
  2. 负载并入模型：工具的质量/质心（第 011 章标定结果）合进最后一级连杆，让 M̂、ĝ 涵盖工具，这一步省掉，惯量误差立刻放大。
  3. 外环整定：Md、Dd、Kd 按任务选（平移 200–2000 N/m、ζ=1 起步）；Md 建议取 0.5–2 倍物理惯量的对角估计，太小则外环对力噪声敏感，太大则响应迟钝。
  4. 数值细节：J̇q̇ 用差分近似（Δt 取一拍）或用解析导数；J 近奇异时对 q̈des 用阻尼伪逆；对 τ 做逐关节限幅（第 006 章），记录饱和。
  5. 验收：先自由空间验证"闭环≈期望阻抗"（阶跃响应的超调、时间常数与解析值比），再做接触稳态与冲击试验；最后做模型失配压力测试（负载 ±30%）。
设计决策：为什么不是所有场景都上计算力矩？

三个现实约束：其一，模型成本，RNE + 参数辨识 + 负载标定是一套工程体系，而 Level-0/1 只需要运动学；其二，鲁棒性结构，反馈线性化把模型误差"搬到"了前馈路径上，失配大时性能退化比 Level-0 更敏感（后者至少闭环结构里没有模型）；其三，传动柔性，模型通常假设刚性关节，谐波减速器的柔性在快速任务里不可忽略，抵消不掉的"残余动力学"可能比不做补偿更麻烦。实战取舍：慢速接触、要求统一手感或大惯量工具 → 上计算力矩；快速多变、模型粗糙、或只想"安全交互" → 留在 Level-0/1，把工程预算花在环境交互层。

关键代码与解读

片段 1：平面 2 连杆动力学，M、C、g 的显式实现

import numpy as np

L1, L2 = 0.35, 0.30
m1, m2 = 2.5, 1.5                # 点质量简化：质量集中于连杆远端

def dynamics(q, qd):
    """返回 M(q)、C(q,q̇)q̇、g(q)。水平面运动：g(q)=0。

    显式公式仅用于教学；真机请用 RNE（递归牛顿-欧拉）按 URDF 计算。
    """
    q2 = q[1]
    M11 = (m1+m2)*L1**2 + m2*L2**2 + 2.0*m2*L1*L2*np.cos(q2)
    M12 = m2*L2**2 + m2*L1*L2*np.cos(q2)
    M22 = m2*L2**2
    M = np.array([[M11, M12], [M12, M22]])       # 对称正定，随 q2 变化
    h = -m2*L1*L2*np.sin(q2)                     # 科氏/离心项的统一系数
    c = np.array([h*(2.0*qd[0]*qd[1] + qd[1]**2),
                  -h*qd[0]**2])                  # 符号由拉格朗日推导确定
    g = np.zeros(2)                              # 竖直臂时改为重力矩公式
    return M, c, g

# 快速体检：M 的两个极端构型与科氏项量级
for q2 in (np.pi/2, 0.0):
    M, c, _ = dynamics(np.array([0.4, q2]), np.array([1.0, 1.0]))
    print(f"q2={q2:.2f}: M11={M[0,0]:.3f}  ‖C(q,q̇)q̇‖={np.linalg.norm(c):.3f} N·m")

解读：把显式公式放进代码的价值是"看见结构"：M 随构型变化（q2=π/2 与 0 时 M11 差异约 2m2L1L2，即 0.32 kg·m² 量级），C 项在 1 rad/s 关节速度下就有零点几牛米的量级，速度加倍时按平方增长。这就是计算力矩要处理的"债务"的真实尺寸。两个工程注意点：其一，教学用点质量模型，真机参数（连杆质心、转动惯量）必须以辨识结果为准，否则模型形式再对也白搭；其二，h 的符号与惯例强相关（有人定义 h 时把 sin 写成 −sin），代码里必须用一个能量或数值实验校验正负，最简单的检验：从静止给 q2 一个正初速度，离心效应下 M 的演化方向是否符合物理直觉（半径缩小转速加快）。别在这种符号细节上省时间，它会让所有瞬态结果"看着不对又说不出哪不对"。

片段 2：计算力矩阻抗主循环，把期望阻抗刻进系统

def fk(q):
    q1, q2 = q
    return np.array([L1*np.cos(q1) + L2*np.cos(q1+q2),
                     L1*np.sin(q1) + L2*np.sin(q1+q2)])

def jac(q):
    q1, q2 = q
    return np.array([[-L1*np.sin(q1) - L2*np.sin(q1+q2), -L2*np.sin(q1+q2)],
                     [ L1*np.cos(q1) + L2*np.cos(q1+q2),  L2*np.cos(q1+q2)]])

q, qd = np.array([0.40, 0.50]), np.zeros(2)
M_d = np.diag([1.0, 1.0]); K_d = np.diag([500.0, 500.0])
D_d = 2.0*np.sqrt(K_d @ M_d)              # 2√(K_d·M_d)，对角阵逐元开方
x_d = fk(q) + np.array([0.03, 0.0])       # 参考：x 方向偏出 3 cm（会接触）
xe, k_env, dt = 0.52, 1e5, 1e-3
for i in range(2000):
    x, J = fk(q), jac(q)
    f_ext = -k_env*(x[0]-xe) if x[0] > xe else 0.0
    F_ext = np.array([f_ext, 0.0])
    # 外环：期望加速度（外力在这里注入一次，系数为 M_d⁻¹）
    ddx_cmd = np.linalg.solve(M_d, F_ext - D_d@(J@qd) - K_d@(x - x_d))
    # 运动学科氏项：J̇q̇ ≈ (J(q+qd·ε) − J(q))·qd / ε（一拍差分）
    eps = 1e-6
    Jdot_qd = ((jac(q + qd*eps) - J) @ qd) / eps
    qdd_des = np.linalg.solve(J, ddx_cmd - Jdot_qd)
    # 计算力矩：还清 M/C/g 债务，并减去外力（外力已在上面注入过一次）
    M, c, g = dynamics(q, qd)
    tau = M @ qdd_des + c + g - J.T @ F_ext
    # 真实杆件：只认自己收到的力矩与环境力
    qdd = np.linalg.solve(M, tau + J.T@F_ext - c - g)
    qd += qdd*dt
    q += qd*dt
    if i % 400 == 0:
        print(f"t={i*dt:3.1f}s x=({x[0]:.4f},{x[1]:.4f}) F={f_ext:6.2f}N")

解读：这是全书"最重"的一条控制律，逐行都有讲究。第一行外环：注意 F_ext 的系数通过 solve(M_d, ·) 变成 1/Md，这正是期望阻抗里"外力驱动"的通道；D_d@(J@qd) 用的是实测速度，参考静止（ẋd=0）时无第二项。J̇q̇ 的差分：用当拍 q、qd 沿运动方向前探 ε 求 J 的变化率，误差 O(ε)+O(Δt²) 完全够用；高速真机可以改为解析式。τ 的计算：M @ qdd_des + c + g 是"债务全还"，- J.T@F_ext 是"外力只进一次"；把这三者与第 006 章的 J.T @ (k_d*e + d_d*de) 对比，能直观看到 Level-2 多了哪些信息。运行结果：稳态接触力与第 003 章的串联公式一致，但瞬态由 Md 支配。把 M_d 改成 diag(3,3) 再跑（D_d 随公式同步更新），接触建立明显变慢（ωn=√((Kd+Kenv)/Md) 按 √3 倍下降）、峰值力几乎不变；改成 diag(0.3,0.3) 则响应加快、峰值同样几乎不变。要让峰值变化，动的是 D_d 与接近速度：把 D_d 写死成 44.7 再去调大 M_d，阻尼比被稀释，峰值力增大到约 −109 N。这就是"惯性整形"第一次在你眼前生效：物理连杆没变，系统的表观质量跟着参数走了，时间尺度与阻尼配比都由你定价。

片段 3：模型失配压力测试，质量 +30%、重力偏置 8 N·m

def run_case(m_scale=1.0, g_err=np.zeros(2)):
    """模型失配跑同一工况，返回（稳态力, 峰值力, 最大跟踪偏差mm）。"""
    q, qd = np.array([0.40, 0.50]), np.zeros(2)
    f_hist, e_hist = [], []
    for i in range(2000):
        x, J = fk(q), jac(q)
        f_ext = -k_env*(x[0]-xe) if x[0] > xe else 0.0
        F_ext = np.array([f_ext, 0.0])
        ddx_cmd = np.linalg.solve(M_d, F_ext - D_d@(J@qd) - K_d@(x - x_d))
        eps = 1e-6
        Jdot_qd = ((jac(q + qd*eps) - J) @ qd) / eps
        qdd_des = np.linalg.solve(J, ddx_cmd - Jdot_qd)
        M, c, g = dynamics(q, qd)
        # 失真源：M̂=scale·M，ĝ=g+err（C 项低速下影响小，暂不动）
        tau = (m_scale*M) @ qdd_des + c + (g + g_err) - J.T @ F_ext
        qdd = np.linalg.solve(M, tau + J.T@F_ext - c - g)
        qd += qdd*dt
        q += qd*dt
        f_hist.append(f_ext); e_hist.append(x[0]-x_d[0])
    f_hist = np.array(f_hist)
    return f_hist[-1], f_hist.min(), np.abs(np.array(e_hist)).max()*1e3

for tag, ms, ge in (("理想模型", 1.0, np.zeros(2)),
                    ("质量 +30%", 1.3, np.zeros(2)),
                    ("重力偏置 8N·m", 1.0, np.array([0.0, 8.0]))):
    f_ss, f_pk, e_max = run_case(ms, ge)
    print(f"{tag:>14}: F_ss={f_ss:6.2f}N  F_peak={f_pk:6.2f}N  最大偏差={e_max:5.2f}mm")

解读：三种情况给出三类特征模式。理想模型行是基准：稳态力与解析值一致（−9.38 N，与第 003 章串联公式吻合）、瞬态与 Md、Kd、Dd 的设计响应吻合。质量 +30%：稳态力不变（稳态与质量无关，第 003 章的结论再次生效），闭环真实加速度变成 1.3·q̈des，瞬态随之改变：峰值力从 −76 N 变为 −69 N（约 10%），说明惯量参数直接决定动态特征；慢接触下它无感，快动作冲击下立现。重力偏置：本例平面臂本无重力，人为注入的 8 N·m 相当于某个关节的补偿项偏了 8 N·m，经闭环换算成恒定的任务空间偏移（本例末端被推离参考 37.9 mm，接触也因此丢失、稳态力归零）；真机上这就是"负载没标定"的后果，偏移随姿态变化，接触状态也跟着变。测试脚本的设计意图：把模型误差按"未知参数"的方式注入（标称的 M̂、ĝ 与真实的 M、g 分离），这正是现场面对的情形。建议把这张表加进你的上机验收清单，并且每换一次工具就重跑一次；如果某行出现"力整段偏、偏差不随扰动恢复"，优先检查该行对应的补偿项。

常见坑

  • 忘记 −JTF̂ 项：外力在回路里被注入两次，实际阻抗"偏硬"且与设计不符。症状：同一组参数在接触下比自由空间"脾气大"。修复：按推导逐一核对四项，力的符号用静止压墙实验验证。
  • J̇q̇ 省掉：中高速轨迹出现系统性跟踪滞后，速度越快越大。修复：差分近似成本极低，直接补上；验算时看"圆周运动时姿态偏差"。
  • 负载没并进模型：ĝ、M̂ 只含本体，工具一动就露馅。修复：把工具的 m、pc（第 011 章）折算到末连杆，或直接在 RNE 里加一个末端质量。
  • 在传动柔性大的关节上激进整定：模型假设刚性关节，谐振频率内未建模动态被前馈放大，表现为特定速度区间"嗡嗡"共振。修复：识别传动谐振，限制外环带宽或加陷波滤波，不要在模型误差大的频段硬碰。
  • 把计算力矩当"万能增益"：期望阻抗的瞬态完全由 Md 决定，但 Md 设得远小于物理惯量时，需要的力矩峰值可能触碰限幅，闭环退化成"限幅下的另一套系统"。修复：按力矩预算反推 Md 下限（峰值力矩 ≈ Md·最大期望加速度 + 抵消项），并监控饱和。

练习与思考

  1. 写出完整的替换推导：把 τ=M̂q̈des+Ĉq̇+ĝ−JTF̂ 代入动力学，证明理想模型下 q̈=q̈des，再证明 ẍ=ẍcmd 与期望阻抗成立。★
    提示
    替换后同项相消只剩 Mq̈=Mq̈des；再对 ẋ=Jq̇ 求导得到 ẍ 与 Jq̈+J̇q̇ 的关系。
  2. 在片段 2 中把 Md 依次改成 diag(0.3,0.3)、diag(3,3)，记录接触峰值力、稳态力、建立时间。哪些量说明"Md 参与动态"？★★
    提示
    稳态力几乎不变（稳态与质量无关）；峰值与建立时间随 Md 正相关，这两项才是惯量整形的可见效果。
  3. 把片段 3 的质量失配扫描成 −30%、−15%、0、+15%、+30%，画"峰值力 vs 失配"曲线，解释为什么它近似线性。★★
    提示
    峰值力主要由 1.3·q̈des 的缩放决定，一阶近似下线性；非线性来自接触刚度对加速度的反馈，在峰值点附近较弱。
  4. 推导外力项"注入一次"的条件：若控制律写成 τ=M̂q̈des+Ĉq̇+ĝ（不减 JTF̂），求闭环 ẍ 与期望阻抗之差，并说明接触工况下这个差如何改变稳态力。★★★
    提示
    闭环会多出 M_x−1F 项，等效于外力系数由 M_d−1 变为 M_d−1+M_x−1；接触稳态时 K_d(x_d−x)=F 的关系被打破，静差与刚度比有关。
  5. 设计一个"模型失配体检"流程：只允许 30 分钟机上时间，列出四个测试（自由空间阶跃、接触稳态、冲击、负载突变）各自要记录的数据与判定阈值，并说明如何定位到具体失配项。★★★
    提示
    自由空间阶跃→查 M̂；接触稳态→查 ĝ 与力的符号；冲击→查 M̂ 高频行为与延迟；负载突变→查 M̂、ĝ 是否正确包含工具参数。阈值可用"与理想模型预测差 20%"作统一线。

小结

  • 完整动力学三笔债务 M、C、g；计算力矩逐项抵消并在外环重新注入期望加速度，实现含惯量整形的精确阻抗。
  • 外环解 ẍcmd = ẍd+Md−1(F−DdΔẋ−KdΔx)，经 q̈des=J−1(ẍcmd−J̇q̇) 进入内环；−JTF̂ 保证外力只注入一次。
  • 理想模型下闭环与期望阻抗严格相等；现实中误差特征分明：慢接触看 Δg、快动作看 ΔM，失配失真但通常不丢稳。
  • 工程要点：负载并入模型、J̇q̇ 用差分低成本补偿、近奇异用阻尼伪逆、力矩预算反推 Md 下限。
  • 下一章的反方向问题：没有可信模型、也不允许做辨识时，如何仅凭"结构最少的反馈"获得可用的柔顺？无模型方法的边界与技巧在那里登场。
