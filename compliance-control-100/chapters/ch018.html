第一篇 · 基础、建模与稳定性

第 018 章：与环境柔性接触的导纳控制

柔性的环境会"跟着动"：橡胶、弹性支撑、软组织把力与位置的关系搅在一起。稳定性压力最小、力精度却最难，本章把"串联柔量 + 环境运动"的双重账算清。

  • 主题：导纳控制 / 柔性环境与运动跟踪
  • 关键公式：Keq = KaKenv/(Ka+Kenv)；位移扰动传递 |G| = Kenv/|1+KenvA(jω)|
  • 预计学时：55 分钟
  • 前置章节：第 017 章

学习目标

  • 会判断"柔性环境"的工程区间（Kenv=102–103 N/m），并说明它与刚性接触在难点上的镜像关系。
  • 掌握串联柔量公式 Keq，能分段讨论"控制器主导"与"环境主导"两种参数体制各自的力精度特性。
  • 会用扰动传递 |G(jω)| 分析"环境在动"的场景：低频衰减、高频透传与交界频率 √(Kenv/Ma) 的意义。
  • 会设计"运动环境"下的导纳参数：Ma 定透传起点、Ka 定低频衰减比、Da 保稳定。
  • 掌握"用接触力当环境位置传感器"的估计式 x̂e=x−F/Kenv 及其噪声与滞后特性，为第 019 章铺路。

背景与动机

上一章的钢件是"一步不让"的对手；本章的环境相反：橡胶垫、弹簧座、传动带、人手前臂、皮肤，它们自己会变形、会移动、刚度还不稳定。典型任务：在弹性支撑件上压装、在运动带上抛光、在人体上做辅助按摩或康复夹持。这些场景有两个共同特征：（1）接触力对"相对位移"敏感而对"绝对位置"不敏感；（2）环境位置 xe 随时间变化，而且往往是不可能精确建模的变化。

导纳控制在这里的处境和刚性环境恰好镜像：稳定性几乎不用操心（Da ≥ 2KenvTeff 中 Kenv 很小），但"用位置差造力"的精度很难保证，想要 5 N，你需要知道 Kenv 和 xe。本章把这两笔账算清，并把"环境在动"这件事从干扰变成可以主动跟踪的信号。

核心原理

1. 柔性环境与串联柔量：谁主导？

环境仍建模为弹簧，但刚度量级换到 Kenv ≈ 102–103 N/m（压下去 1 cm 才有几牛），且表面位置 xe 可能缓慢变化。导纳控制器输出 δ = A(s)F，机器人位置 x = xd + δ；接触力满足 F = −Kenv(x − xe)。稳态联立（第 003/016 章同款推导）得到：

Fss = −Keq(xd − xe) ， Keq = KaKenv/(Ka+Kenv) Keq：串联等效刚度；两种"串联弹簧"的合成，谁小谁主导

分段读这个公式，两种体质泾渭分明：

  • Ka ≪ Kenv（控制器主导）：Keq≈Ka，力 ≈ Ka×偏置，与环境刚度几乎无关，对 Kenv 的不确定性免疫。代价：同样的力需要极大的让位（5 N、Ka=20 → 25 cm），行程与观感都难以接受。
  • Ka ≳ Kenv（环境主导）：Keq≈Kenv，力 ≈ Kenv×偏置，Kenv 估错 30%，力就错 30%；xe 估错 2 mm，在 Kenv=300 上就偏 0.6 N。行程合理，但精度依赖环境知识。

对比第 017 章的刚性接触：那里 Kenv≫Ka 自动落在"控制器主导"体制，力由 Ka×偏置决定、与 xe 精度无关，开环力设定在刚性环境里反而更可靠。工程直觉：柔性环境把力精度的问题从"位置精度"变成了"环境知识"，要么接受大的行程换免疫力（软导纳），要么承认你是在靠估计压东西，并把力反馈闭环补上（第 019 章）。

2. 环境在动：扰动传递与透传带宽

设环境表面自己做小位移 xe(t)（弹性支撑的颤振、人的呼吸、皮带跳动）。取小信号，把 xd 固定，推导从 xe 到接触力 F 的传递：F = −Kenv(xd + A(s)F − xe) 整理得

G(s) = F(s)/xe(s) = −Kenv / [1 + Kenv·A(s)] 低频：G→−Keq（软）；高频：G→−Kenv（环境位移原样变成力）

用二阶导纳 A(s)=1/(Mas²+Das+Ka) 代入，可以得到两个特征频率：低频处 |G| ≈ Keq（衰减到"串联"水平），高频处 |G| → Kenv（1:1 透传）。两者之间的交界频率近似 ωc ≈ √(Kenv/Ma)，当 Maω² 量级追上 Kenv，导纳回路"来不及反应"，环境运动便全部转成力波动。

数字感：Kenv=200、Ma=2 → ωc≈10 rad/s（1.6 Hz）：1 Hz 以下的表面运动还能被导纳吸收一部分，2 Hz 以上的振动直接透传成力纹波。想跟踪更快的表面运动（比如 5 Hz 的皮带跳动），必须把 Ma 压到 0.2 kg 量级（ωc≈31 rad/s），这就是"柔性环境里 Ma 是第一设计参数"的含义：它不决定手感，它决定你能'看见'多快的环境运动。Da 的角色与前面各章相同：给 Ma、Ka 配阻尼比，同时提供第 016 章意义下的稳定性裕度（这里 Kenv 小，Da=2ζ√(KaMa) 通常就够）。

3. 把力信号当"环境位置传感器"

柔性环境有一个宝贵特性：同样的噪声水平下，力信号能换算出更可靠的环境位置。由 F = Kenv(x − xe)（符号取幅值讨论）反解：

x̂e = x − F/Kenv Kenv 越小，同样的力对应越大的位移，估计的"信噪比"越好

噪声传播：σx̂e = σF/Kenv；Kenv=200、σF=0.1 N 时，环境位置估计噪声只有 0.5 mm，比多数视觉与建模手段都便宜。滞后特性则来自力滤波 τf：估计的是"τf 之前"的位置，环境运动快时需要相位补偿（对估计值做微分前馈，即 x̂e + τf·ẋ̂e）。这个估计式是下一章自适应力控制的入口：有了 x̂e 和 K̂env，参考点就可以被"重新瞄准"到让力恰好等于目标值的位置，不必靠猜。

4. 稳定性视角：本章的"容易模式"

第 016 章的接触稳定判据 Da ≥ 2KenvTeff 在这里几乎白送：Kenv=300、Teff=6 ms 时只要 Da ≥ 3.6 N·s/m，远低于手感要求。真正需要警惕的则是"软过头"带来的两个次生问题：（1）行程与速度，Ka 太小时让位巨大，慢速运动都对应大位移，关节速度余量被吃掉；（2）位置内环的非线性区，大让位跨越较多的传动柔性与摩擦区，内环的等效带宽下降，导纳失真（第 005 章）；建议给 δ 设软限位（比如 ±10 cm）并在接近时线性收窄增益。结论：柔性环境里导纳参数由"跟踪需求 + 行程约束"决定，而几乎不受稳定性约束，这与刚性环境正好互换。

实现思路与设计

柔性环境导纳的参数设计流程：

  1. 估环境三件套：Kenv（压一压量斜率）、xe 的大致范围、xe 的运动频带（静置的弹性件？1 Hz 的支撑颤振？手部的 0.5–2 Hz？）。
  2. 定 Ma：由交界频率要求反推 Ma ≤ Kenv/ωc²。例：想吸收到 3 Hz（19 rad/s）、Kenv=200 → Ma ≤ 0.55 kg。
  3. 定 Ka：先看"力精度 vs 行程"：若接受环境依赖（Kenv 估得准），Ka 取 100–500 保行程；若要强免疫力，Ka 取 10–50 并准备大让位与软限位。
  4. 定 Da：Da=max(2ζ√(KaMa), 2KenvTeff)，ζ 取 0.9–1.1。
  5. 加估计器：运行 x̂e = x − F/Kenv 的滑动平均/低通，供监控与后续自适应使用；先在低速工况验证估计精度（与示教位置对照）。
设计决策：什么时候该把 Ka 压到"控制器主导"区？

三条同时成立才值得：（a）环境刚度不可信（如人体组织、未知弹性件，标称 300 实际 150–800 游走）；（b）允许大让位（工作空间与节拍允许大幅压缩，如按摩头贴体、贴合式打磨）；（c）力的大小适中（F/Ka 在行程预算内：5 N 配 Ka=30 是 16.7 cm，超预算，配 Ka=100 是 5 cm，可行）。任一条不满足，就回到"环境主导 + 力反馈闭环"的路线：让位置差粗定位，力误差积分/自适应精修（第 019 章）。现场经验：康复与外骨骼类任务大量使用"控制器主导"的极软参数（安全优先）；工业弹性件压装则几乎都走力闭环路线（精度优先）。

关键代码与解读

片段 1：串联柔量计算器，两种体质的分区表

import numpy as np

def equilibrium(k_a, k_env, x_off=0.02):
    """稳态：F = K_eq·offset，返回(等效刚度, 力, 让位δ)。"""
    k_eq = k_a * k_env / (k_a + k_env)     # 串联合成：小者主导
    f_ss = k_eq * x_off                    # 幅值（方向取压入为正）
    delta = f_ss / k_a                     # 导纳让位：δ = F/K_a
    return k_eq, f_ss, delta

print(f"{'K_a':>6} {'K_env':>7} {'K_eq':>7} {'F(N)':>7} {'δ(cm)':>7}  体制")
for k_a, k_env in ((20.0, 200.0), (100.0, 200.0), (500.0, 200.0),
                   (500.0, 3000.0)):
    k_eq, f_ss, d = equilibrium(k_a, k_env)
    regime = "控制器主导" if k_a < 0.5*k_env else (
        "环境主导" if k_a > 2.0*k_env else "过渡区")
    print(f"{k_a:6.0f} {k_env:7.0f} {k_eq:7.1f} {f_ss:7.2f} {d*100:7.2f}  {regime}")

解读：四行数据把整章的核心权衡摆上台面。第一行（Ka=20 ≪ Kenv=200）等效刚度≈18.2 N/m，力≈0.36 N，与"Ka×偏置=0.4 N"同量级：环境刚度怎么变，力都不动；代价是让位 δ≈1.8 cm 几乎吃掉了整个偏置（真正穿入环境只有 1.8 mm），行程预算要留够。第二三行在过渡区到环境主导：Ka=500 时 Keq=500×200/700≈143 N/m，F≈2.86 N、δ=0.57 cm；此时若要 5 N，需要 offset≈3.5 cm，而 Kenv 波动 ±20% 会让力在 4.2–5.7 N 之间游走。第四行展示刚性环境的对照（Ka=500、Kenv=3000）：Keq≈429，F≈8.6 N，偏置造力更有效率（接近 Ka×offset），且 Kenv 波动 ±20% 只带来约 3% 的力变化（灵敏度被压缩到 Ka/Kenv 量级）。结论可视化：越硬的环境，"偏置造力"越可靠；越软的环境，偏置路线越需要"更软或更巧"。把这张表当参数初筛：先填任务的两个 K，再读体制列，就能决定走哪条路线。

片段 2：运动环境扰动，透传滤波的实测与理论

def moving_env_ripple(f_env_hz, k_env=200.0, m_a=2.0, k_a=100.0,
                      zeta=1.0, amp=0.002, dt=1e-3, t_end=6.0):
    """环境表面做正弦运动 amp·sin(2πωt)，返回稳态力纹波幅值（N）。"""
    d_a = 2.0*zeta*np.sqrt(k_a*m_a)
    w = 2.0*np.pi*f_env_hz
    delta, vd, tail = 0.0, 0.0, []
    x_d = 0.01                                  # 参考点在环境名义表面内 1cm
    for i in range(int(t_end/dt)):
        t = i*dt
        x_e = amp*np.sin(w*t)                   # 环境在动
        x = x_d + delta                         # 内环理想
        f = -k_env*(x - x_e) if x > x_e else 0.0
        a = (f - d_a*vd - k_a*delta)/m_a
        vd += a*dt; delta += vd*dt
        if t > t_end - 2.0:                     # 稳态窗口 2 秒
            tail.append(f)
    return np.std(tail)*np.sqrt(2.0)            # 正弦幅值 ≈ √2·σ
print(f"{'f(Hz)':>6} {'仿真纹波(N)':>11} {'K_e·A(N)':>9}  说明")
k_env, amp = 200.0, 0.002
for f_hz in (0.2, 0.5, 1.0, 3.0, 8.0):
    rip = moving_env_ripple(f_hz)
    full = k_env*amp
    print(f"{f_hz:6.1f} {rip:11.3f} {full:9.3f}  " +
          ("受抑制" if rip < 0.5*full else "接近透传"))

解读：预期曲线形状：0.2–0.5 Hz 纹波 0.12–0.16 N，明显小于"全透传"值 Kenv·A=0.4 N（导纳回路跟得上，部分吸收）；1 Hz 升到 0.25 N；3 Hz 因越过共振区出现约 1.2× 的动态放大（0.48 N）；8 Hz 回落到 0.42 N，接近全额透传。交界点与理论 √(Kenv/Ma)/2π = √(200/2)/6.28 ≈ 1.6 Hz 一致，这就是"透传起点"的可视化；"透传"不是一条硬边界，交界附近的动态放大（峰值略超 Kenv）是二阶系统共振的正常行为。第二列与第三列的比值就是衰减因子 |G|/Kenv，低频端由 Kenv/Ka=2 决定衰减上限（本例只能压到约 1/3：|G|≈Keq=66.7 N/m，对应纹波 0.13 N）。想让 3 Hz 也有衰减？把 Ma 改 0.2、Ka 改 50 重跑，交界推到 5 Hz，低频端衰减也因 Ka 变小而更深，这正是设计流程第 2/3 步的数字依据：Ma 管带宽、Ka 管深度。真机验证时用同样的扫频结构：让工件分别以不同频率微动（或让机器人参考做微幅正弦、把力响应当扰动实验），记录纹波曲线，直到与设计目标吻合。

片段 3：环境位置估计器，把力信号变成"毫米级视觉"

def env_estimator(k_env=200.0, sigma_f=0.1, tau_est=0.02,
                  amp=0.002, f_env=0.5, dt=1e-3, t_end=4.0):
    """仿真：环境正弦运动下，用 x_e = x − F/K_env 估计表面位置。"""
    w = 2.0*np.pi*f_env
    delta, vd = 0.0, 0.0
    xh, err_max = 0.0, 0.0
    rng = np.random.default_rng(5)
    d_a, m_a, k_a, x_d = 2.0*np.sqrt(100.0*2.0), 2.0, 100.0, 0.01
    for i in range(int(t_end/dt)):
        t = i*dt
        x_e_true = amp*np.sin(w*t)
        x = x_d + delta
        f = -k_env*(x - x_e_true) if x > x_e_true else 0.0
        f_meas = f + sigma_f*rng.standard_normal()
        # 估计式：环境位置 = 机器人位置 − 力/环境刚度
        x_e_hat_raw = x + f_meas/k_env          # 注意符号：f 为负向力
        xh += (x_e_hat_raw - xh) * dt / (tau_est + dt)   # 一阶低通
        a = (f_meas - d_a*vd - k_a*delta)/m_a
        vd += a*dt; delta += vd*dt
        if t > t_end - 1.0:
            err_max = max(err_max, abs(xh - x_e_true))
    return xh, err_max

xh, e = env_estimator()
print(f"估计误差上界（含低通与噪声）≈ {e*1e3:.2f} mm")
print("对照：原始噪声 σ_F/K_env = 0.50 mm；低通把它压低，但引入约 0.1 mm 的滞后")

解读：这段代码演示"力当环境位置传感器"的完整信号链与误差账。估计式的符号是最容易写错的地方：采用有符号力约定时 x̂e = x − F/Kenv（F 为压向环境方向的力）；代码里用无符号幅值时对应 x + f/k_env（f 为负、把机器人位置"往回折"）。注释里把两种约定都点明了，抄代码时先确认自己的符号。误差账：未滤波的原始估计噪声是 σF/Kenv=0.5 mm，一阶低通（τ=20 ms）把它压到约 0.08 mm，但引入约 0.13 mm 的相位滞后误差；两项抵消后实测上界 0.28 mm。滤波更重则噪声更小、滞后更大，τest 要按环境运动频带取舍，这正是"估计器要连回路一起设计"的教训。实践升级路线：加微分前馈补偿滞后（x̂ + τ·ẋ̂）、用 K̂env 在线辨识（第 052 章）替换常值 Kenv、把估计误差当"观测噪声"进入第 019 章的自适应律设计。别小看这个 x̂e：它把"未知环境位置"变成了"可观测信号"，几乎所有实用的力跟踪方案都建立在这一步之上。

常见坑

  • 拿柔性环境当刚性处理：沿用 105 的直觉算偏置，结果压穿工件也没到目标力。修复：先测 Kenv（斜率法），按第 1 节分区表重算。
  • 只调 Ka 不管 Ma：环境一动就透传成力纹波，还以为是传感器问题。修复：按 ωc=√(Kenv/Ma) 反推 Ma，环境运动频带多高就压多小。
  • 让位不设限：Ka 压太软，一个大偏置就让它位跑到几百毫米，撞上机构限位。修复：δ 软限位 + 接近限位时增益收窄（渐进式约束）；硬裁切会在触边时造成冲击。
  • 估计式符号或刚度用错：x̂e 往错误方向跑，后续自适应把参考点越推越歪。修复：静止状态用"手推位移 vs 估计值"做一次符号验证，Kenv 用实测值。
  • 忘了 y/z 向的柔性：只在接触方向建模，横向的柔量让"接触点"漂移，长期出现边缘磨损或力偏离。修复：至少对主要接触方向分别估计；姿态通道的柔性单独评估。

    提示
    Ka ≤ 100（≤Kenv/2）进入控制器主导：力≈Ka×偏置趋稳；代价是 δ=F/Ka 线性膨胀，5 N 时 5–50 cm。
  3. 用片段 2 把 Ma 从 2 改成 0.2、0.5，记录 1 Hz 与 3 Hz 的纹波变化，验证"交界频率 ∝1/√Ma"，并给出 3 Hz 环境下允许 Ma 的上限。★★
    提示
    交界 3 Hz=19 rad/s → Ma ≤ Kenv/19²=0.55 kg；Ma 越小高频越"跟得上"，纹波越小。
  4. 推导扰动传递在低频与高频的极限：证明 |G(0)|=Keq、|G(∞)|=Kenv，并解释为什么"高频一定全额透传"。★★★
    提示
    低频 A(0)=1/Ka 代入；高频 A→0 分母→1。高频时导纳回路指令来不及生成位移，环境运动与机器人之间的相对位移完全由 xe 承担。
  5. 设计"手部按摩辅助"任务：目标接触力 8 N±1、人体等效 Kenv≈150、表面有 1.5 Hz 的自主运动 ±3 mm。给出 Ka、Ma、Da、δ 限值与安全策略，并预估纯导纳下的力纹波，说明是否需要第 019 章的自适应。 ★★★
    提示
    力 vs 行程权衡：Ka=80 时 δ=10 cm；Ma≤Kenv/(1.5×2π)²≈1.7 kg；纹波估计需比较 ω_c=√(150/1.7)≈9.4 rad/s 与 1.5 Hz=9.4 rad/s，正好交界，需要自适应或加大回路增益。

小结

  • 柔性环境判据 Kenv=102–103 N/m；与刚性环境镜像：稳定容易，力精度依赖对环境知识的掌握。
  • 串联柔量 Keq=KaKenv/(Ka+Kenv)：Ka≪Kenv 时力≈Ka×偏置（免疫力强、行程大）；Ka≳Kenv 时力≈Kenv×偏置（行程合理、精度靠估计）。
  • 环境在动时看扰动传递：低频衰减到 Keq、高频全额透传，交界 ωc≈√(Kenv/Ma)；Ma 管带宽、Ka 管衰减深度、Da 管稳定。
  • 估计式 x̂e=x±F/Kenv 把"看不见的表面"变成可观测信号；噪声 σF/Kenv 与滤波滞后是主要误差源。
  • 下一章把未知 Kenv 与 xe 正式纳入控制：先辨识、再改写参考点，让稳态力精确落在目标值上，自适应阻抗控制。
