第一篇 · 基础、建模与稳定性

第 005 章：基于位置控制的阻抗控制实现

机器人只会"走到哪里"，阻抗方程却在说"受多大力让多少位"。外环算位置、内环追位置，两条环的带宽差，决定了你对环境展示的"手感"到底有多真。

  • 主题：阻抗控制 / 位置接口实现（级联结构）
  • 关键公式：xcmd = xd − 阻抗解算；内环 H(s) = 1/(1+s/ωc)，要求 ωc ≥ 5√(Kd/Md)
  • 预计学时：55 分钟
  • 前置章节：第 004 章

学习目标

  • 掌握位置型阻抗控制（position-based impedance control）的级联结构：外环把力翻译成位置修正，内环把位置修正追出来。
  • 会推导内环滞后如何"污染"虚拟阻抗：把内环近似为一阶环节，算出在阻抗自然频率处的幅值误差与相位滞后。
  • 记住带宽分离经验规则 ωc ≥ 5ωn,imp，并会用它为机器人选参数或反过来为任务挑机器人。
  • 会在笛卡尔闭环里正确使用正运动学、雅可比与逆运动学：为什么逆解每拍都要做、为什么会"翻腕"、如何避免。
  • 能写出一条完整的位置型阻抗主循环，并解释启动初始化、参考斜坡、限幅三个工程细节的作用。

背景与动机

翻开工业机械臂的手册：控制柜对外基本只开放一种接口，"到达某个关节位姿"或"到达某个末端位姿"。没有力矩接口、没有力环，甚至连关节力矩都不可见。想在这种机器上做柔顺控制，你没有选择：把阻抗方程解出来的"应该在哪"，直接喂给位置控制器。这就是位置型阻抗控制，工业界 90% 的"力控"功能都构建在这条路上。

它的优雅之处在于对机器人本体动力学"零要求"：不需要知道质量矩阵、科氏力、重力模型，那些都由位置内环自己扛了。代价也很明确：外环想要的运动必须经过内环"翻译"，内环的带宽、滞后与跟踪误差都会混进最终的手感。本章要回答的就是：这个"翻译过程"给虚拟阻抗加了多少失真，什么时候可以忽略，什么时候会闯祸。

核心原理

1. 级联结构：外环是"大脑"，内环是"肌肉"

位置型阻抗控制把控制器分成两层。外环（本章主角）以 1 ms 级周期运行：读末端状态 x、ẋ 与接触力 F，解阻抗方程

Mdẍcmd + Ddẋcmd + Kd(xcmd − xd) = −F ⟹ 输出 xcmd Md(kg)、Dd(N·s/m)、Kd(N/m)；xcmd 是"期望机器人到达的位置"（m）

内环（机器人自带的位置控制器）接收 xcmd 并驱动关节去追它。两层之间的关系可以画成：力 →（外环阻抗）→ 位置命令 →（内环）→ 实际位置 → 环境 → 力。闭环中唯一由你设计的部分是外环；内环是买来的、不可改的，只能用它的性能说话。

工程直觉：位置型阻抗把"软硬"全写在外环的数学里，内环只负责"听话"；对外表现的手感 = 虚拟阻抗 − 内环拖的后腿。外环刚度可以设 200 N/m 让人推着走，也可以设 2000 N/m 压着工件干；机器人本体是钢是铝、重是轻，外环都不用知道，反正内环会把命令追到位。这是"模型无关"的第一层含义（第 014 章还会用速度环讲第二层）。

2. 内环滞后混进阻抗：一阶模型的定量分析

把内环近似成一阶跟踪环节：x 的实际位置相对命令的传递函数 H(s) = ωc/(s+ωc)，其带宽 ωc（rad/s）就是"内环能多快跟上命令"。对频率为 ω 的正弦命令，幅值衰减与相位滞后为：

|H(jω)| = 1/√(1+(ω/ωc)²) ， ∠H(jω) = −arctan(ω/ωc) ωc 越大，外环命令被"歪曲"得越少

关键问题：该拿什么频率去评估？答案是外环虚拟系统的自然频率 ωn,imp = √(Kd/Md)，外环命令里能量最集中的频率。把 ω = ωn,imp 代入：Kd=500、Md=1 时 ωn,imp≈22.4 rad/s。

ωc/ωn,imp幅值误差相位滞后实际效果
1×（22 rad/s）−29%−45°手感明显变软、发"糊"，接触响应迟钝
2×（45 rad/s）−10%−26°勉强可用，力波动幅度与相位都偏大
5×（112 rad/s）−2%−11°工程推荐线：阻抗失真 ≤ 3%、稳定裕度充足
10×（224 rad/s）−0.5%−6°几乎理想，多数内环的真实带宽上限附近

为什么"5 倍"就够？幅值失真 2% 肉眼不可辨，相位 11° 在奈奎斯特图上只吃掉一点点稳定裕度；低于 3 倍时，外环设计的 ζ 会被相位滞后吃掉一大半，你以为给了临界阻尼，实际输出像欠阻尼。相反，把 ωc 提到 10 倍以上通常没有收益：真实内环受机械共振、编码器量化、传动柔性限制，标称带宽之外还有 1–2 个未建模极点，外环跑得越快越容易撞上它们。

还要记住一条结构性结论：相位滞后等效于"额外的阻尼/弹簧组合"，且随频率变化，低频处滞后的主要效果是给外环添了等效阻尼，高频处则直接吞稳定裕度。所以"内环慢一点就当加了阻尼用"这种说法只在很窄的频带成立，不能作为设计依据。

3. 笛卡尔闭环里的三个映射

外环工作在笛卡尔空间，但机器人吃关节命令，因此每拍都要做三个映射：

  • 正运动学（FK）：由关节角 q 算末端位姿 x，为外环提供状态反馈。外环的 x、ẋ 都只从这里拿；另立一套估计会让坐标系不一致。
  • 逆运动学（IK）：由 xcmd 算关节目标 qcmd。IK 是每拍都做的数值/解析求解，须保证解沿"上一拍的分支"连续演化，否则肘部/腕部会在几何奇异附近瞬间翻转，等效于给内环一次阶跃冲击。
  • 雅可比（J）：两个用处。其一是速度前馈：ẋcmd 经 q̇cmd = J−1(q)ẋcmd 传给内环，显著减小跟踪误差；其二是理解外力—关节力矩映射 τ = JTF（第 009/010 章展开）。

用 2 连杆平面臂把这件事走通，代码片段 1–2 就是完整例子。真实六轴机器人做法相同，只是 IK 换成数值求解（阻尼最小二乘等）并检查分支连续性。

实现思路与设计

一条可上机的位置型阻抗主循环，按以下顺序组织：

  1. 初始化：把虚拟阻抗的内部状态（xcmd、ẋcmd）初始化到当前实际位置，避免从抽象原点起步；否则开机第一拍就会产生一个巨大的位置命令跳变。
  2. 参考生成：xd(t) 从当前点平滑出发（斜坡或 S 曲线），控制周期 1 ms。接触段的目标点由"稳态力公式"决定偏置，例如想要 5 N、Kd=500 就规划到墙内 1 cm。
  3. 外环解算：解阻抗方程得到 xcmd（加速度→速度→位置半步积分），对所有状态限幅。
  4. 速度前馈：把 ẋcmd 经 J−1 变成关节速度前馈，与位置命令一起下发；这一步能把内环的"必须落后一点才能出力"的稳态误差压掉大半。
  5. IK 与下发：IK 从上一拍解出发迭代，保证分支连续；命令变化率（|xcmd−xcmd,prev|/Δt）设上限，防止异常时冲击内环。
设计决策：内环带宽怎么测、怎么兜底？

不要照抄手册的"位置环带宽"。自己测：向内环发一个 1 mm 的位置阶跃，用编码器数据画响应曲线，取到达 63%（一阶近似时间常数）的时间 τ，则 ωc ≈ 1/τ；更严谨的做法是扫频测幅频特性。常见工业臂内环等效 ωc 在 30–150 rad/s：若你的任务需要 ωn,imp > ωc/5（例如需要又软又快的触觉示教），位置型方案会失真，此时要么降低外环刚度让 ωn,imp 下来，要么换力矩接口实现（第 006 章）。兜底策略：外环参数整定完成后，用力阶跃做一次实测，对比第 003 章的解析预测，偏差若超过 30% 就把缺口算在内环账上。

关键代码与解读

片段 1：2 连杆平面臂的运动学三件套

import numpy as np

L1, L2 = 0.35, 0.30                      # 连杆长度（m）

def fk(q):
    """正运动学：关节角 q=(q1,q2) → 末端位置 (px,py)，单位 m。"""
    q1, q2 = q
    return np.array([L1*np.cos(q1) + L2*np.cos(q1+q2),
                     L1*np.sin(q1) + L2*np.sin(q1+q2)])

def jac(q):
    """雅可比 2×2：ẋ = J·q̇；转置 J.T 用于力→关节力矩映射。"""
    q1, q2 = q
    return np.array([[-L1*np.sin(q1) - L2*np.sin(q1+q2), -L2*np.sin(q1+q2)],
                     [ L1*np.cos(q1) + L2*np.cos(q1+q2),  L2*np.cos(q1+q2)]])

def ik(x, q_seed):
    """解析逆解（肘下分支），以 q_seed 所在分支为准：连续性是第一需求。"""
    px, py = x
    # 余弦定理求第二关节角；np.clip 处理工作空间边界外的不可达点
    c2 = (px*px + py*py - L1*L1 - L2*L2) / (2.0*L1*L2)
    q2 = np.arccos(np.clip(c2, -1.0, 1.0))
    if q_seed[1] < 0.0:                  # 保持与上一拍相同的肘部朝向
        q2 = -q2
    q1 = np.arctan2(py, px) - np.arctan2(L2*np.sin(q2), L1 + L2*np.cos(q2))
    return np.array([q1, q2])

解读：三个函数都是"每拍要跑"的实时件，写法上的每个决定都服务于确定性：解析 IK：2 连杆可以闭式解，没有初值敏感性；q_seed 只用来选分支（肘上/肘下），保证机器人不会在运动中途突然"翻肘"；np.clip 不是可选优化，没有它，一旦外环命令把目标点推出工作空间，arccos 立刻返回 NaN，整条控制链当场失控。真机上的 6 轴用阻尼最小二乘 IK 时也遵循同一原则：用上一拍解做种子、检查关节跳变、拒绝不连续解。另外注意 FK 输出的位置就是外环状态 x 的唯一来源，闭环里不允许并存第二套"软件位置"，那是坐标系事故的温床。

片段 2：完整级联主循环，沿 x 推墙 5 N

# 外环状态：沿 x 的虚拟质量（y 保持不动）
m_d, k_d = 1.0, 500.0
d_d = 2.0 * np.sqrt(k_d * m_d)           # 自由空间临界阻尼
q = np.array([0.40, 0.50])
qd = np.zeros(2)
xh = fk(q)[0]                            # 关键：虚拟状态初始化到当前位置
vh, y_d = 0.0, fk(q)[1]                  # y 参考=当前 y，不制造横向移动
xe, k_env = 0.52, 1e5                    # 墙面位置与刚度（N/m）
kp, kd_pd = 400.0, 20.0                  # 内环关节 PD（等效 ωc≈70 rad/s）
dt = 1e-3
for i in range(3000):
    x_now = fk(q)
    # 接触力（沿 x）：越界只有反力，符号与第 001 章约定一致
    f_ext = -k_env * (x_now[0] - xe) if x_now[0] > xe else 0.0
    # 外环：阻抗方程解算命令位置（半隐式欧拉，和前几章同一套）
    # f_ext 压入时为负，取 +f_ext 与第 002 章"外力让位"的符号约定一致
    a = (-d_d*vh - k_d*(xh - 0.53) + f_ext) / m_d
    vh += a * dt
    xh = min(xh + vh * dt, 0.53)         # 参考上限 0.53：越过墙面 1 cm
    x_cmd = np.array([xh, y_d])
    # 内环：IK + 关节 PD（真机上就是控制柜里那层）
    q_cmd = ik(x_cmd, q)
    tau = kp * (q_cmd - q) - kd_pd * qd
    # 关节动力学（简化对角惯量）+ 环境经雅可比转成关节力矩
    f_vec = np.array([f_ext, 0.0])
    qdd = (tau + jac(q).T @ f_vec) / np.array([0.08, 0.05])
    qd += qdd * dt
    q += qd * dt
    if i % 500 == 0:
        print(f"t={i*dt:4.1f}s  x={x_now[0]:.4f}m  F={f_ext:6.2f}N  "
              f"|q_cmd-q|={np.linalg.norm(q_cmd-q):.4f}rad")

解读：这条循环里有四处"最容易被写坏"的地方，请逐一核对。第一，虚拟状态初始化在 fk(q) 上，如果像有些演示代码那样从 0 起步，开机第一拍就会命令机器人狂奔 40 cm。第二，参考上限用 min(..., 0.53) 做软收口，让稳态力按 F≈Kd(0.53−x) 收敛到约 5 N；真实的限幅应该作用在速度与加速度上，这里为可读性简化成位置夹紧。第三，雅可比转置 jac(q).T @ f_vec 把环境力正确地灌进关节：平移空间的力要经雅可比转置变成关节力矩，这是后面第 010 章的伏笔。第四，最后一行监控 |q_cmd−q| 是内环跟踪误差的直接指示：稳态时它应该很小（毫弧度级）；如果它持续偏大，说明 ωc 跟不上外环，你看到的"力"就掺了内环滞后的水。运行后稳态力落在约 4 N（理想内环下为解析值 5 N，内环刚度有限会带来少量下垂），与解析公式对得上；把 kp 降到 50 重跑，你会看到同一参考下力波动明显加大，那就是片段 3 要量化的东西。

片段 3：带宽分离验收工具

def inner_loop_check(k_d, m_d, w_c):
    """评估内环一阶模型 H=1/(1+s/w_c) 在阻抗自然频率处的失真。"""
    w_n = np.sqrt(k_d / m_d)             # 外环虚拟自然频率 rad/s
    h = 1.0 / (1.0 + 1j * w_n / w_c)    # 复频响应 H(j·w_n)
    mag_err = abs(h) - 1.0               # 幅值误差（负=偏软）
    phase = np.degrees(np.angle(h))      # 相位滞后（度）
    verdict = "通过" if w_c >= 5.0 * w_n else "偏慢"
    print(f"w_n={w_n:5.1f}  w_c={w_c:6.1f}  w_c/w_n={w_c/w_n:4.1f}  "
          f"幅值误差={mag_err*100:6.2f}%  相位={phase:6.1f}°  {verdict}")
    return mag_err, phase

for w_c in (22.4, 45.0, 112.0, 224.0):   # 内环带宽从"同速"到"10 倍"
    inner_loop_check(500.0, 1.0, w_c)

解读：这个 12 行的小工具值得放进你的标准调试脚本。参数为什么这样传：k_d、m_d 来自外环配置，w_c 来自你实测的内环带宽，三个数一填，立即知道当前配置是不是"5 倍线"以上。为什么用复频响应 1/(1+1j*w)：这样一行同时得到幅值和相位，比分别手算两个 arctan/hypot 更不容易写错（符号、单位都跟着复数走）。判据为什么落在"偏软"一侧：幅值误差为负意味着实际让位比设定多，手感偏软；如果你的任务允许"软一点"，2 倍线也可以接受，规则是给判断提供依据，不是死线。最后一个工程细节：w_c 的实测值应取你所用频率段的等效值，若内环在 50 rad/s 处有机械共振，等效带宽要按共振峰值折算，不能只看 −3 dB 点。

常见坑

  • 虚拟状态未初始化到当前位置：开机或模式切换瞬间产生大位置跳变，内环猛追，触发保护或撞机。修复：进入柔顺模式的第一拍先 xh = fk(q)，并冻结一个控制周期再开始。
  • IK 分支跳变：越过某个几何位置后肘部瞬间翻转，关节命令出现大跳变，表现为"咔"的一下冲击。修复：用上一拍解做种子、检查关节增量、必要时拒绝并沿原分支迭代。
  • 忘记速度前馈：纯位置命令下内环必须"落后一点"才产生运动，外环看到的 x 永远滞后于 xcmd，等效于给虚拟阻抗串了额外滞后。修复：下发 J−1ẋcmd 作为速度前馈，或接受 5 倍带宽规则。
  • 把力噪声直接做成位置噪声再喂内环：外环输出的抖动量全被内环忠实执行，机械上表现为嗡嗡声与磨损。修复：外环输出加低通（10–50 Hz）与变化率限幅，滤波器带宽要高于 ωn,imp 乘以裕度。
  • 在设计时用"标称内环带宽"：手册值往往是理想负载下的空载带宽，带载、低速、大范围姿态下会明显下降。修复：在真实任务姿态与负载下实测，取最差工况校核 ωc ≥ 5ωn,imp。

    F = KeqΔx，K_eq≈Kd=500、Δx=0.03 → 约 15 N；位置型方案稳态只依赖外环方程与几何，内环只要"追得上"，稳态不受带宽影响。

  5. 某六轴机器人实测内环等效 ωc≈35 rad/s，任务要求 Kd=800 N/m、Md=0.8 kg。请判断位置型方案能否满足 5 倍线；若不能，给出两种不改硬件的出路并各写一句代价。★★★
    提示

小结

  • 位置型阻抗控制 = 外环阻抗解算 + 内环位置跟踪的级联；对外表现的手感由虚拟阻抗与内环滞后共同决定。
  • 内环一阶近似 H=1/(1+s/ωc)：在 ωn,imp=√(Kd/Md) 处幅值误差约 −(ωn/ωc)²/2、相位约 −ωn/ωc（弧度）；5 倍带宽线给出约 2% 幅值误差与 11° 滞后。
  • 笛卡尔闭环的三件套各司其职：FK 提供状态、IK 保证分支连续、J 用于速度前馈与力—力矩映射。
  • 工程细节决定成败：虚拟状态初始化到当前位置、参考平滑限幅、速度前馈、IK 连续性检查。
  • 下一章把内环换成"力矩接口"：同样的虚拟阻抗，不走位置命令而直接输出力/力矩，解除带宽分离的束缚，但把动力学模型的责任还给控制器。
