第 093 章：导纳控制中的负载变化适应

抓取发生的一瞬间，机器人末端多了 4 kg，重力补偿账本作废，交互带宽被负载拖低。本章用递推最小二乘在"举升窗口"里把总质量辨识出来，再按带宽预算把导纳的虚拟质量与阻尼同步缩放，让机器人"知道自己变重了"。

  • 主题：负载辨识 / 增益调度（gain scheduling）
  • 关键公式：f = m总·(gs+as) + b；Md ∝ m总，Dd ∝ √Md
  • 预计学时：60 分钟
  • 前置章节：第 092 章

学习目标

  • 理解负载变化同时破坏两件事：重力补偿的"账本"（幻影力 4 kg 就是 39 N）与位置内环的动态品质（等效惯量变大、带宽下降）。
  • 会写出"工具+负载"总质量的回归模型 f = m·(gs+as) + b，并解释质量与零点为什么必须靠激励（加速度变化或姿态变化）才能分开。
  • 会实现带遗忘因子的递推最小二乘（RLS），并在抓取/释放事件触发时重置协方差实现快速重收敛。
  • 掌握从辨识质量到导纳增益的映射：Md ∝ m总、Dd ∝ √Md（保持阻尼比、按 √ 规律降低带宽），并会设计限幅与速率限制。
  • 能说清本章与第 083 章的边界：083 调增益对付"环境/工况变化"，本章调增益的驱动源是"负载辨识结果"。

背景与动机

抓放（pick-and-place）、码垛、上下料，这些任务里机器人的末端质量会在一瞬间改变：抓取前 1.5 kg（工具），抓取后 5.5 kg（工具 + 工件）。对柔顺控制来说这是双重打击。第一重是补偿账本作废：第 092 章辨识的工具质量是 1.5 kg，抓取后真实值变成 5.5 kg，多出来的 4 kg 在传感器上表现为约 39 N 的幻影力，比接触目标（10–30 N）还大，导纳控制器立刻被这份"假力"推着跑。第二重更隐蔽：位置内环的等效惯量变大，跟踪带宽按 1/√m 下降，而导纳外环的虚拟参数还按轻载整定的节奏工作，两边节拍失配，接触响应出现超调甚至振荡。

直觉上"抓取时用手册里的工件质量更新补偿"就行，但工件质量往往未知（散装物料、注塑件差异），或者夹具本身在抓取前后状态都会变。所以工程解法是在线辨识：利用每次抓取后的一个"举升/转腕"动作，把总质量从传感器读数里估出来，自动更新重力补偿与增益调度。本章解决的就是"机器人怎么知道自己变重了、变重了多少、变重后参数怎么改"。

与第 083 章的关系先讲清：那一章的自适应增益由"力误差"驱动，是反馈式补救；本章的增益变化由"负载辨识"驱动，是前馈式预防，辨识先于振荡发生，机器人不必等到被幻影力推着跑才反应。

核心原理

1. 单轴回归模型：把"变重"变成可辨识问题

沿重力方向取传感器的一个轴（工程上取"举升动作中与重力最对齐的轴"，比如手腕坐标系的 z 轴），在不接触环境的时间窗口里，读数满足：

f(t) = m总·(g + az(t)) + b + n(t) g = 9.81 m/s²；az：该轴方向的加速度；b：该轴的零点+姿态残差；n：噪声

把 (g + az) 当作回归量 φ1、常数 1 当作 φ2，就是标准的"两参数线性回归"，未知量 θ = [m总, b]。这里有一个必须理解的可辨识性细节：如果机器人在窗口里匀速运动（az ≈ 0 恒定），回归量 φ1 恒等于 g，"质量的贡献"与"零点"完全同比例，两个未知量不可分辨，估计器只能学到两者之和。可辨识性的来源有两条：让 az 在窗口里变化（加速—匀速—减速的举升曲线），或者让姿态变化使 g 的投影变化（第 092 章的多姿态思路）。前者更快（一次举升 0.5 s 内即可完成），工程上首选。

2. RLS：为什么不用"攒够数据再批处理"

批处理最小二乘当然可以，但负载是"事件式"变化的：抓取发生在某一拍，之后你需要尽快（几百毫秒内）更新补偿，否则幻影力就会推着导纳控制器走。递推最小二乘（recursive least squares, RLS）把估计做成逐拍更新：

k = Pφ/(λ + φTPφ)，θ ← θ + k(f − φTθ)，P ← (P − kφTP)/λ P：参数不确定性（协方差矩阵，2×2）；λ：遗忘因子（0.99–0.999）

三行更新的物理读法：k 是"增益"，P 大（我对现在的参数很没把握）就多听新数据，P 小（参数已经收敛）就少听噪声；残差 f − φTθ 是"意外量"，突然抓取时残差骤增，估计被推动；遗忘因子 λ 让信息变旧，有效窗口约 1/(1−λ) 拍，λ = 0.995 在 1 kHz 下约 0.2 s，既能跟踪变化又足够平滑。抓取事件还可以显式加速：事件时刻把 P 重置为大值（"我全忘了，重新学"），估计在 0.2–0.3 s 内重收敛，然后用较小的 P 保持稳定。工程直觉：P 就是估计器的"好奇程度"，常态下调低它，别被传感器噪声牵着走；事件时刻抬高它，全速学习新负载。

3. 从质量到增益：带宽预算的 √ 规律

质量估计出来后要做两件事：更新重力补偿（把 m总 代进第 092 章的公式，这一步是"零阶"的，直接消除幻影力），以及重新安排导纳增益。为什么增益要动？因为位置内环的带宽受等效惯量制约：位置环增益 kp 不变时，闭环带宽 ωil ≈ √(kp/m) 随 √m 下降。稳定性经验要求导纳虚拟系统带宽 ωd = √(Kd/Md) 保持在内环带宽的 1/5 以内。若 Kd 不变（手感刚度保持），则要求

Md ∝ m总，Dd = 2ζ√(KdMd) ∝ √m总 质量翻到 3.67 倍（1.5→5.5）时：Md 放大 3.67 倍、Dd 放大 1.92 倍、ωd 降到 52%

这条映射的逻辑很干净：用"降带宽"换取"扛得住更重负载"的稳定性余量；用 Dd 的 √ 缩放保持阻尼比不变，避免变重后接触超调。Kd 不动是刻意的，接触手感（稳态力/位移关系）保持用户设定值，机器人"变稳"不"变硬"。当然，负载变轻（放下工件）时映射也反向生效，机器人"恢复灵敏"。这就是增益调度（gain scheduling）：一条按测量量查表的映射，不靠在线自适应，简单、可审计、不会自激。

4. 边界与代价

第一，估计窗口必须"无接触"：接触力会污染回归量，所以辨识只在自由运动段启用（通常就是抓取后的举升动作）；接触中靠"最后估计值"冻结。第二，估计的是"传感器以下的总质量投影"，工件从夹具中取走、部分工件留在台面等边界情况会让估计偏小，验收上宁可设计一个"±20% 误差仍安全"的参数余量。第三，增益调度是开环映射，质量估计错误会一路传到增益上，所以要给调度因子设限幅（如 [0.7, 3.0]）与速率限制（每秒变化不超过 0.5 倍），防止"一次错误估计把参数打飞"。最后，容忍度设计：即使完全不做增益调度（只更新重力补偿），多数中低速任务的稳定性也够用；调度收益主要体现在重载下的接触品质，先上辨识、再上调度，是风险可控的实施顺序。

实现思路与设计

  1. 触发时机：从夹具状态机拿到"已抓取/已释放"事件；事件后规划一段标准"举升-转腕"动作（如沿重力方向抬 8 cm、转腕 ±20°，历时 0.6 s），作为辨识激励。
  2. 数据门控：只在自由段（无接触标志）、夹具状态确定的窗口内喂数据；速度与力波动门控沿用第 091 章的思路。
  3. RLS 参数：λ = 0.995（0.2 s 有效窗口）、初始 P = 1（质量轴）与 0.01（零点轴）；事件时刻 P 重置为 [50, 50] 加速收敛，0.3 s 后回落到常规值。
  4. 质量更新：把 m̂总 送进第 092 章的重力补偿器（替换工具质量项）；零点 b 同时刷新（注意与第 091 章运行时跟踪的分工，避免两个模块同时抢着改零点）。
  5. 增益调度：s = m̂总/m0 限幅到 [0.7, 3.0]，Md = Md0·s、Dd = Dd0·√s；变化速率 ≤ 0.5/s，调度后重新做一次稳定性自检（ωd 是否仍在预算内）。
  6. 监控：记录每次事件前后的 m̂、收敛时间、残差；连续两次事件估计差异 > 30% 触发告警（可能混入接触或夹具异常）。
设计决策：为什么质量只调 Md、Dd，不调 Kd？

Kd 决定"接触手感"，稳态力与位移的比例（第 001 章：F = Kd·偏置）。如果负载一变就把 Kd 调小，任务层规划的力-位关系全部失效，操作员的直觉也被破坏。而 Md、Dd 控制的是"多快"与"多稳"，这正是负载会影响的部分。把"手感"与"快慢"分给不同参数，同一条任务参数表就能在空载/满载下通用，这是工程上最受欢迎的设计分界。

关键代码与解读

片段 1：带遗忘因子的负载 RLS（含事件重置）

import numpy as np

class PayloadRLS:
    """在线辨识"工具+负载"总质量与零点：沿重力方向的单轴回归。"""
    def __init__(self, m0=1.5, b0=0.0, lam=0.995, p_mass=1.0, p_bias=0.01):
        self.theta = np.array([m0, b0])       # [总质量, 零点]
        self.P = np.diag([p_mass, p_bias])    # 协方差：质量比零点更该被相信数据
        self.lam = lam

    def update(self, g_plus_a, f_axis):
        phi = np.array([g_plus_a, 1.0])       # 回归量：等效重力与常数
        Pphi = self.P @ phi
        k = Pphi / (self.lam + phi @ Pphi)    # RLS 增益：由不确定性加权
        r = f_axis - phi @ self.theta         # 预测残差（意外量）
        self.theta += k * r
        self.P = (self.P - np.outer(k, phi) @ self.P) / self.lam
        return self.theta.copy()

    def on_load_event(self, m_init):
        """抓取/释放事件：抬高协方差，快速重学习（0.2-0.3 s 收敛）。"""
        self.theta[0] = m_init
        self.P = np.diag([50.0, 0.5])         # 大 P = 好奇心最大，全速吸收数据

解读：（1）初始协方差 p_mass=1.0 与 p_bias=0.01 的不对称是刻意的：质量在任务中会变化，零点基本稳定，先验就告诉估计器"多怀疑质量、少怀疑零点"。（2）on_load_event 里把质量初值设成"抓取前 + 一个先验的工件质量"，同时抬高两轴 P，这对应"我知道大概变重了多少，但不确定，让它自己学"。（3）注意 update 里没有任何除法保护的省略：分母 lam + phi@Pphi 理论上恒正（P 半正定 + λ > 0），可以直接用。工程上仍建议加一个 max(..., 1e-9) 兜底，防止浮点极端情况。

片段 2：从辨识质量到导纳参数（带宽预算映射）

class AdmittanceScheduler:
    """按辨识出的总质量缩放导纳虚拟参数：M_d ~ m，D_d ~ sqrt(M_d)。"""
    def __init__(self, m_ref=1.5, m_d0=1.0, zeta=1.0, k_d=500.0,
                 s_min=0.7, s_max=3.0, rate_max=0.5):
        self.m_ref, self.zeta, self.k_d = m_ref, zeta, k_d
        self.m_d0 = m_d0
        self.s = 1.0                  # 缩放因子（平滑后的）
        self.s_min, self.s_max, self.rate_max = s_min, s_max, rate_max
        self.update_gains()

    def update_gains(self):
        self.m_d = self.m_d0 * self.s
        self.d_d = 2.0 * self.zeta * np.sqrt(self.k_d * self.m_d)   # 保阻尼比
        self.omega_d = np.sqrt(self.k_d / self.m_d)                 # 供自检用

    def step(self, m_total, dt):
        s_target = float(np.clip(m_total / self.m_ref, self.s_min, self.s_max))
        # 速率限制：一次错误估计最多把参数挪 0.5/s，防止"打飞"
        ds = np.clip(s_target - self.s, -self.rate_max * dt, self.rate_max * dt)
        self.s += ds
        self.update_gains()
        return self.m_d, self.d_d, self.omega_d

解读：s_target = m_total / m_ref 就是理论的 Md 比例；sqrt 出现在 Dd 上，源自 Dd = 2ζ√(KdMd) 的临界阻尼公式。为什么限制 s ∈ [0.7, 3.0]？下限防止负载估计过小把虚拟质量压太小（噪声更容易驱动它）；上限防止异常估计（例如辨识瞬间混入接触力）把带宽压得过低、机器人"变傻"。速率限制让参数变化是连续可微的，导纳方程是二阶动态，参数跳变会激发瞬态，平滑是免费的稳定性。返回 omega_d 是为了在与内环带宽的比值越界时报警或临时冻结调度。

片段 3：辨识收敛与调度的联合验证

def simulate_pick(m_load=4.0, lam=0.995, reset=True, n=3000, dt=1e-3):
    """模拟一次抓取：0.8 s 处负载从 0 跳到 m_load 的举升窗口。"""
    rng = np.random.default_rng(11)
    m_tool, g = 1.5, 9.81
    est = PayloadRLS(m0=m_tool, lam=lam)
    sched = AdmittanceScheduler(m_ref=m_tool)
    m_true, log_m, log_md = m_tool, [], []
    for i in range(n):
        t = i * dt
        if 0.8 <= t < 1.4:              # 举升段：0.6 s 的加速-匀速-减速
            a_z = 2.0 * np.sin(2 * np.pi * (t - 0.8) / 0.6)
        else:
            a_z = 0.0
        if t >= 0.8 and m_true < m_tool + m_load:
            m_true = m_tool + m_load    # 负载突变
            if reset:
                est.on_load_event(m_tool + 0.5 * m_load)   # 事件触发：先给半程先验
        f_axis = m_true * (g + a_z) + 0.3 + rng.normal(0, 0.08)  # 含 0.3 零点
        est.update(g + a_z, f_axis)
        if 0.8 <= t < 1.4:              # 只在自由运动（举升）窗口喂数据
            m_hat = est.theta[0]
        sched.step(m_hat, dt)
        log_m.append(m_hat); log_md.append(sched.m_d)
    print(f"抓取后 0.4 s 估计={log_m[1200]:.2f} kg，结束估计={log_m[-1]:.2f} kg "
          f"（真值 {m_tool+m_load:.2f}）")
    print(f"M_d 从 {log_md[700]:.2f} 调度到 {log_md[-1]:.2f} kg")

解读：这段仿真把事件触发的价值量化出来：reset=True 时估计器在 0.2–0.4 s 内从 3.5 kg 附近爬到 5.5 kg，而"纯遗忘不重置"要慢得多（可把 reset=False 对比）。三个设计细节：（1）举升段的正弦加速度幅值 2 m/s²，既要足够大让 φ 变化（可辨识性），又不能大到把工具甩起来（工程约束）；（2）数据只在 0.8 ≤ t < 1.4 窗口进入估计器，其余时间估计冻结（对应"只在自由运动段学习"的门控）；（3）输出同时打印 m 与 Md 的演化，便于确认"质量先收敛、参数后到位"的时序正确性。

常见坑

  • 匀速窗口里想辨识质量：没有加速度激励，m 与 b 不可分，估计在两者之间来回分配。修复：设计带加减速的举升动作，或复用多姿态数据；至少保证窗口里 az 变化几个 m/s²。
  • 接触中继续学习：接触力进入回归量，质量估计被"抬高"，随后重力补偿过量、机器人"感觉变轻"继续压入。修复：接触标志硬门控（同第 091 章），接触段冻结估计。
  • 遗忘因子过小：λ = 0.95 时有效窗口仅 20 ms，1 kHz 噪声让估计疯狂抖动。修复：λ 取 0.99–0.999，用"事件重置"来获得快速性，避免"永久健忘"。
  • 调度因子不设限：一次错误估计（如抓取瞬间碰撞）把 s 推到 10，机器人交互带宽被压到地板，任务停滞。修复：s 限幅 + 速率限制 + 估计一致性检查（连续两窗口偏差 > 30% 拒绝更新）。
  • 两处零点同时更新打架：第 091 章的运行时零漂跟踪与本章 RLS 的 b 项互相"学习"对方的更新，零点慢慢漂移。修复：明确主从，正常运行时零漂跟踪负责 b，负载事件后短暂冻结零漂跟踪、由 RLS 接管，事件结束后把结果交还。

练习与思考

  1. 证明"匀速窗口里 m 与 b 不可分辨"：写出 φ = [g, 1] 下两个不同 (m, b) 组合给出相同预测的构造，并说明 RLS 的 P 矩阵会在哪个方向发散。★
    提示
    取 m' = m+Δ、b' = b−Δg，则预测完全相同；P 在 [1, g] 方向上持续增大，说明该方向不可观测，这就是需要激励的代数表述。
  2. 用片段 3 的代码，把 reset 设为 False、lam 设为 0.999，测量估计收敛时间；再改 λ = 0.99，观察稳态方差。给出你自己的 λ 与重置策略组合。★★
    提示
    收敛时间 ∝ 1/(1−λ)（样本数）；λ 过大则慢，λ 过小则稳态抖动大。事件重置可以在保持 λ 大（平滑）的同时获得快收敛，是双赢策略。
  3. 把负载从 4 kg 改为 8 kg，重复仿真。验证 s 被限幅在 3.0、Md 与 Dd 的最终值符合映射公式；说明"限幅之后质量估计还有用吗"。★★
    提示
    s 限幅后增益不再跟随（这是安全边界）；但重力补偿仍用真实 m̂（多出的 8 kg 负载就是约 78 N 的幻影力，必须消除）。请说明"补偿"与"调度"这两件事各自对限幅的敏感度完全不同。
  4. 设计一个"负载辨识质量自检"流程：用已知的 2 kg 标准砝码做半自动验证，写清动作序列、门控条件、验收判据（估计误差与收敛时间）。★★★
    提示
    动作：空载举升 → 装 2 kg 砝码 → 举升；验收：估计值 2.00±0.15 kg、0.4 s 内收敛、残差 < 0.2 N。这套流程可以放进产线点检表。

小结

  • 负载突变双重打击：重力补偿账本作废（4 kg = 39 N 幻影力）＋内环带宽随 1/√m 下降。
  • 回归模型 f = m总(g+az) + b；可辨识性需要加速度或姿态激励，匀速窗口里 m 与 b 不可分。
  • RLS 三行更新 + 遗忘因子 0.99–0.999 + 事件触发协方差重置；只在自由运动窗口学习，接触中冻结。
  • 增益调度：Md ∝ m总、Dd ∝ √m总（保阻尼比、降带宽），Kd 保持不动以保住手感；限幅 [0.7, 3.0] 与速率限制是安全底线。
