第二篇 · 参数调节与交互任务

第 035 章：阻抗控制下的位置阶跃响应

位置参考跳 10 mm，机器人怎么跟？自由空间看二阶跟踪指标，接触状态看"力扰动番外篇"：同样的位置步长，在钢件上会砸出 76% 的力超调，把阶跃磨成 30 ms 斜坡就能降到 4%。

  • 主题：位置阶跃 / 跟踪指标 / 接触耦合
  • 关键公式：X/Xd = Kd/(Mds²+Dds+Kd)，Fss = Kseries·Δxd
  • 预计学时：50 分钟
  • 前置章节：第 001 章、第 034 章

学习目标

  • 会写出阻抗控制在自由空间的闭环传递函数 X/Xd = Kd/(Mds²+Dds+Kd)，并说明"直流增益为 1"意味着最终必到目标。
  • 会用 ωn=√(Kd/Md) 与 ζ=Dd/(2√(KdMd)) 预测位置阶跃的上升时间与调节时间，并理解 tr ∝ 1/√Kd 的刚度缩放律。
  • 理解接触状态下位置步长与力扰动的关系 Fss = Kseries·Δxd，以及"位置稳态偏移 = Fext/Kd"这条柔顺方程的工程读法。
  • 能解释接触中位置阶跃的力超调为何由 ζeff = Dd/(2√(Md(Kd+Kenv))) 决定，并用"阶跃平滑化"把超调从 76% 降到 4%。
  • 会做安全步长预算：给定允许峰值力 Flimit，反解最大位置步长与所需平滑时间，写进任务参数表。

背景与动机

前四章都在"力"这一侧做文章（恒定、斜坡、正弦、阶跃），这一章把参考换成位置：任务要求末端位置跳变 10 mm，阻抗控制器控制下的实际位置怎么走？这道题有两种典型场景，答案很不一样：

自由空间：目标位姿阶跃是家常便饭（从一个点到另一个点）。纯位置控制会让你"瞬时到位"，阻抗控制则给了一个设计好的二阶过渡，到位虽慢一点，但换来了接触时的柔顺。你要知道这个"慢"到底是多少、能不能接受、以及和刚度参数的关系。

接触状态：位置参考每一步都会被柔顺方程"打折"，稳态下末端要停在 Fext/Kd 的偏移处，而位置差又通过环境刚度变成力增量。更麻烦的是瞬态：同样的 10 mm 步长，钢件的力超调可达 76%，相当于"没碰之前好好的，一挪位置就压坏东西"。这一章把自由空间与接触两种位置阶跃讲透，并给出两条保命技巧：按总刚度加阻尼（第 034 章的规则）和把位置参考"磨圆"。

核心原理

1. 自由空间：直流增益为 1 的二阶跟踪

阻抗方程在无外力时退化为 Mdẍ + Ddẋ + Kd(x − xd) = 0。对位置参考做拉普拉斯变换：

X(s)/Xd(s) = Kd / (Mds² + Dds + Kd) s=0 处取值 1：无论 Md、Dd 取多少，稳态 x → xd，这是阻抗控制"自由空间仍精确跟踪"的数学依据

这是一条归一化二阶低通：ωn = √(Kd/Md)、ζ = Dd/(2√(KdMd))。ζ=1（临界阻尼）时无超调，上升时间（10–90%）近似 tr ≈ 3.36/ωn；ζ=0.7 时超调 4.6%、tr ≈ 1.8/ωn。数值感受（Md=1 kg、Dd = 2√Kd 即临界阻尼）：

Kd (N/m)ωn (rad/s)上升时间 tr调节时间 ts(±2%)
40020.0169 ms293 ms
80028.3119 ms208 ms
120034.698 ms170 ms

规律：tr ∝ 1/√Kd，刚度翻倍只把到位时间缩短 30%。这是"位置逼近速度"与"接触柔顺性"之间的性价比拐点：把 Kd 从 800 加到 3200（4 倍）才换来一半的过渡时间，而接触刚度会变得像石头一样硬。所以对大多数任务，"位置阶跃慢一点"通常可以接受，尤其在±5 mm 级的装配微调里。

2. 接触状态：稳态打折，瞬态"炸毛"

接触时多了一个环境弹簧。稳态分析（第 001、031 章已经用过）给出两条读法：

Fss = Kseries · Δxd（力随位置步长线性增），　位置偏移 = Fext/Kd（柔顺方程的反解） Kseries = KdKenv/(Kd+Kenv)，钢件下 ≈ Kd。例：Kd=800、Δxd=10 mm → ΔF ≈ 7.9 N

瞬态则完全是另一回事：接触时系统的有效刚度是 Kd+Kenv，有效阻尼比塌缩为 ζeff = Dd/(2√(Md(Kd+Kenv)))。用"按 Kd 设计的阻尼"（Dd=56.6）在钢件上做事：ζeff≈0.09，10 mm 步长把力从 1.6 N 推到 9.5 N（ΔF=7.9 N），但峰值冲到 15.5 N，超调 76%。力超调是随位置步长等比例放大的：步长腰斩、力峰值也腰斩；但 ζ 不动，比例就不动。

两条解药，按性价比排序：（1）把阶跃"磨圆"，用 30 ms 的五次/三次多项式平滑代替理想阶跃，实测把 76% 直接压到 4%，比调任何参数都有效。原因在频谱：10 mm 理想阶跃的能量铺满整个频带，其中 50 Hz（ωn 的共振区）成分激励了 (Kd+Kenv) 模态；30 ms 平滑的频谱在 30 Hz 以上已大幅衰减。（2）按总刚度加大阻尼（第 034 章规则 Dd=2ζ√(Md(Kd+Kenv,max))）：Dd 从 56.6 提到 220，超调 76% → 31%；但这同时让自由空间响应变"肉"（220 按接触段 ζeff≈0.35 选取；放到自由空间那段动力学里，ζ 被推到约 3.9、明显过度阻尼）。两招可以叠加：先磨圆，再适度加阻，最后用步长预算兜底。

实现思路与设计

实验设置（1 kHz 等效，自由与接触两组）：

  1. 自由空间组：xd 阶跃 0 → 10 mm；Kd ∈ {400, 800, 1200}，Dd = 2√(KdMd)（临界）；测 tr、ts、超调。
  2. 接触组：Kenv = 1×105 N/m；初始平衡对应 xd0 = 2 mm（F≈1.6 N），t=50 ms 跳到 xd1 = 12 mm；对比 Dd∈{56.6, 220} 与平滑时间 ∈{0, 30, 60 ms}；测力峰值与超调。
  3. 安全步长预算：给定 Flimit（如 15 N，超调后），反解最大 Δxd 与需要的平滑时间。
  4. 验收：自由空间 tr ≤ 150 ms（K=800 档）；接触力超调 ≤ 10%（默认配 30 ms 平滑 + D=220）。
设计决策：为什么"磨圆"比"加阻尼"优先级更高？

阻尼是全局参数：为了压住最坏接触瞬态把 Dd 加大，会让所有自由动作变慢、手感变重；平滑是针对单次参考跳变的局部整形，只影响那一段轨迹（多花 30 ms），不改变回路的任何固有特性，也不吃稳定裕度。控制工程的一条通用原则：能用参考整形解决的问题，不要用反馈增益解决。

关键代码与解读

片段 1：自由空间位置阶跃 + 三档刚度

import numpy as np

def free_step(k_d=800.0, m_d=1.0, d_d=None, x_d=0.01,
              dt=1e-3, T=2.0):
    """自由空间位置阶跃：M x.. + D x. + K(x - xd) = 0。"""
    d_d = d_d if d_d else 2.0*np.sqrt(k_d*m_d)   # 临界阻尼起步
    x, v, log = 0.0, 0.0, []
    for i in range(int(T/dt)):
        t = i*dt
        xd = x_d if t >= 0.1 else 0.0
        a = (k_d*(xd - x) - d_d*v) / m_d
        v += a*dt
        x += v*dt
        log.append((t - 0.1, x))
    return np.array(log)

def free_metrics(L, x_d=0.01):
    t, x = L[:, 0], L[:, 1]
    m = t >= 0.0
    tr10 = t[m][np.argmax(x[m] >= 0.1*x_d)]
    tr90 = t[m][np.argmax(x[m] >= 0.9*x_d)]
    over = (x[m].max() - x_d) / x_d * 100.0
    band = np.where(np.abs(x[m] - x_d) > 0.02*x_d)[0]
    ts = t[m][band[-1] + 1] if len(band) else 0.0
    return tr90 - tr10, over, ts

for k_d in (400.0, 800.0, 1200.0):
    tr, over, ts = free_metrics(free_step(k_d=k_d))
    print(f"K_d={k_d:6.0f}  上升 {1000*tr:4.0f} ms  "
          f"超调 {over:4.1f}%  调节 {1000*ts:4.0f} ms")

解读：输出即上表，169/119/98 ms（上升时间随 Kd 按 1/√ 缩短），超调全为 0（临界阻尼）。np.argmax(x[m] >= 0.1*x_d) 的写法同时完成"找首次到达"和容错：即便数值上永远取不到恰好 0.9xd，argmax 也会在到达时给出第一帧。注意仿真从 t−0.1 记时，让"阶跃时刻"对齐到 0；真实机器人里阶跃起点是上一段轨迹的终点，往往还带速度前馈，行为更平滑。

片段 2：接触阶跃，阻尼与平滑两个旋钮

def contact_step(d_d=56.6, smooth=0.0, k_d=800.0, m_d=1.0,
                 k_env=1e5, z0=0.002, z1=0.012, dt=1e-4, T=0.6):
    """接触中位置阶跃：z 为 x_d 相对面的偏置；smooth 为平滑时间。"""
    x_e = 0.05
    x = x_e + k_d/(k_d + k_env)*z0        # 初始平衡位置（先算对！）
    v, log = 0.0, []
    for i in range(int(T/dt)):
        t = i*dt
        if t < 0.05:
            z = z0
        elif smooth > 0 and t < 0.05 + smooth:
            u = (t - 0.05)/smooth
            z = z0 + (z1 - z0)*(u*u*(3 - 2*u))   # 三次平滑（smoothstep）
        else:
            z = z1
        f = k_env*(x - x_e)
        a = (k_d*(x_e + z - x) - d_d*v - f) / m_d
        v += a*dt; x += v*dt
        log.append((t - 0.05, x, f))
    return np.array(log)

def contact_metrics(d_d=56.6, smooth=0.0, z0=0.002, z1=0.012):
    L = contact_step(d_d=d_d, smooth=smooth)
    t, f = L[:, 0], L[:, 2]
    m = t >= 0
    f0, fss, peak = f[m][0], f[-1], f[m].max()
    return f0, fss, peak, (peak - fss)/(fss - f0)*100.0

for d_d, sm in ((56.6, 0.0), (220.0, 0.0), (56.6, 0.03), (56.6, 0.06)):
    f0, fss, peak, over = contact_metrics(d_d, sm)
    print(f"D_d={d_d:6.1f} 平滑={sm*1000:3.0f}ms -> 峰值 {peak:5.2f} N"
          f"  超调 {over:4.0f}%")

解读：四行实验输出，(56.6, 0 ms): 15.51 N / 76%；(220, 0 ms): 11.99 N / 31%；(56.6, 30 ms): 9.84 N / 4%；(56.6, 60 ms): 9.67 N / 2%。这四行就是本章最有价值的一张表：平滑 30 ms 用"多花 30 毫秒"的代价，换掉了 72 个百分点的超调；而加阻尼 4 倍只换来 45 个百分点、还拖累全局手感。代码里两个细节：初始位置必须用平衡解（写成 xe+z0 就是 2 mm 直接等于 200 N 的假初始力，这是复现接触实验最常见的错误）；平滑用三次 smoothstep，两端导数为零，接得上前后段轨迹。

片段 3：安全步长预算计算器

def step_budget(f_limit=15.0, k_d=800.0, k_env=1e5,
                over_head=0.05, smooth=0.03):
    """给定峰值力预算，反解允许的最大位置步长。
    over_head: 平滑后预留的超调余量(相对增量)；smooth 用于文档。"""
    k_series = k_d*k_env/(k_d + k_env)       # 稳态力增益
    dz = (f_limit / (1.0 + over_head)) / k_series
    print(f"K_series={k_series:.0f} N/m; 允许步长 {dz*1000:.2f} mm"
          f" (含 {over_head*100:.0f}% 超调余量, 建议平滑 {smooth*1000:.0f} ms)")
    return dz

# 压装任务：峰值不超过 15 N
step_budget(f_limit=15.0)
# 抛光任务：峰值不超过 8 N（更保护）
step_budget(f_limit=8.0)
# 若没有平滑：余量要按最坏 76% 计
step_budget(f_limit=15.0, over_head=0.76, smooth=0.0)

解读：三行输出讲清"预算思维"，压装（15 N 预算、30 ms 平滑）允许 18.0 mm 的单步；抛光（8 N 预算）允许 9.6 mm；如果偷懒不做平滑，15 N 预算下只允许 10.7 mm 步长（按 76% 超调折算）。把"平滑时间"与"步长上限"一起写进任务参数表，换产线、换工件时按同一张表复核。函数第三个参数 over_head 故意做成可配置：有平滑时留 5%，无平滑时必须按实测超调（钢件 76%）留，这两档差近 1.7 倍的步长权限，值得在项目评审时强调。

常见坑

  • 接触实验初始位置没放平衡点：x = xe+z0 直接给一个远超稳态的力（钢件 2 mm = 200 N），实验从"爆炸"开始。修复：先用 F=Kseriesz 标定，或让系统先自由收敛到平衡再触发阶跃。
  • 用 Kd 的名义响应预测接触行为：自由空间的 tr 是"按 Md、Kd"算的，接触里 ωn 变成 √((Kd+Kenv)/Md)，快了一个量级、也脆了一个量级（ζeff 塌缩）。修复：自由与接触两套指标分开设计。
  • 位置阶跃换成"大 K"追平：把 Kd 加到 4000 能让自由空间 tr 减半，但接触时 ΔF = KseriesΔx 扩大 5 倍、ζeff 更小。修复：先接受"慢一点"，用平滑与步长预算提速；硬加刚度会把 ΔF 与 ζeff 的账一起推坏。
  • 平滑函数两端不 C¹ 连续：用线性斜坡做"平滑"，端点处速度从 0 跳到 v，等于给系统一个小阶跃激励；用三次 smoothstep 或五次多项式（两端一、二阶导为零）。
  • 把"位置稳态偏移 = F/Kd"当误差去消：有人给位置环再加一个积分去"消除偏移"，结果接触力被顶飞。修复：这个偏移是柔顺方程的一部分（力就是靠它产生的），不许消。

练习与思考

  1. 用 tr ≈ 1.8/ωn 与 ωn=√(Kd/Md) 验证表中 K=400/800/1200（ζ=1 时换 3.36/ωn）的三行上升时间，并解释"K 翻 3 倍、tr 只降 42%"的数学来源。★
    提示
    tr ∝ K−1/2：√3 ≈ 1.73，169/1.73 ≈ 98 ms；平方根来自二阶系统的特征频率结构。
  2. 推导稳态关系：接触中从 xd0 跳到 xd1，证明 ΔFss = Kseries(xd1−xd0)，并写出实际位置相对命令的偏移 Fss/Kd。★★
    提示
    联立 Kd(xd−x)=F 与 F=Kenv(x−xe)，消去 x；偏移就是 F/Kd。
  3. 实验：把片段 2 的平滑时间从 0 扫到 100 ms（步长 10 ms），画"超调-平滑时间"曲线，找出把超调压到 10% 以内的最短平滑时间。★★
    提示
    曲线在 20–40 ms 区间下降最陡（跨越共振周期 20 ms 的尺度），之后趋于平台；用 50 Hz 共振周期对平滑时间做归一化感受更深。
  4. 把接触组的 Kd 从 800 改为 400，重算 Fss、峰值与超调（Dd 仍取 2√(Kd)），解释"软阻抗让力扰动变小、但位置偏移变大"的双面性。★★
    提示
    Kseries≈397：ΔF 减半；但偏移 F/Kd 变为两倍（9.5/400=23.8 mm）；超调比例基本不变（ζeff 仍很小）。
  5. 设计题：一个贴合任务要"每 200 ms 作一次 5 mm 的位置微跳"，允许力峰值 12 N、环境刚度 5×104 N/m。给出 Kd、Dd、平滑时间与校验计算（提示：周期 200 ms 意味着平滑时间不能超过周期的 1/4，否则轨迹被"磨平"叠加失真）。★★★
    提示
    Kseries≈Kd（取 800）→ ΔF≈4 N，余量充足；平滑 30–40 ms；Dd 按总刚度 ζ=0.7 设计；再用片段 3 复核。

小结

  • 自由空间：X/Xd = Kd/(Mds²+Dds+Kd)，直流增益 1；tr ∝ 1/√Kd，K 从 400 到 1200 只把上升从 169 ms 压到 98 ms。
  • 接触状态：稳态 ΔF = KseriesΔxd、位置偏移 = F/Kd；瞬态有效刚度 Kd+Kenv，ζeff 塌缩，10 mm 步长在钢件上超调 76%。
  • 两条解药：参考平滑（30 ms 把 76% 压到 4%，首选）与按总刚度加阻尼（56.6→220，压到 31%，次选）；步长按峰值力预算反解并写进参数表。
  • 实验纪律：初始位置用平衡解、平滑函数 C¹ 连续、自由/接触两套指标分开验收。
  • 下一章进入"导纳控制下的力阶跃响应"：把力参考的阶跃交给导纳与积分外环，看看第一阶响应形态与本章的二阶形态有何不同、指标如何测。
