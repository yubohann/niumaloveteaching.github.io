第 055 章：基于模糊逻辑的阻抗参数调整

"力误差大就使劲调，误差快收敛了就收着点"，老工程师的调参口诀其实是一张规则表。本章把这张表变成模糊控制器：三角形隶属度、5×5 规则、加权解模糊，让阻抗参数在未知工况下自适应，同时保持"每周期几十次乘加"的实时性。

  • 主题：模糊逻辑 / 参数增益调度
  • 关键公式：g = Σiwi·gi / Σiwi（高度法解模糊），wi = μe,i·μde,i
  • 预计学时：55 分钟
  • 前置章节：第 054 章（导纳控制中的时变阻尼）

学习目标

  • 理解模糊控制器在阻抗控制中的定位：它是一种把经验规则表变成平滑非线性增益的工具，并不追求"更聪明的算法"。
  • 会设计 5×5 规则表：行是力误差、列是误差变化率，能说清每个"激进/刹车"格子背后的意图。
  • 掌握三角形隶属度（50% 重叠）与高度法解模糊的公式和计算量，理解为什么它能跑在 1 kHz 回路里。
  • 会做稳定性边界检查：模糊输出的增益上界 × 基础回路增益必须仍在相位裕度之内。
  • 能写出完整的模糊增益调度代码，并用对称性/有界性/收敛段三项自检查自己的规则表。

背景与动机

第 021 章用"力误差"调参数、第 049–052 章用观测器估计状态，这些都是"有模型"的方法：你需要写下一个函数或一个估计器。但在接触任务里，经验丰富的调试工程师往往使用一套语言化规则："误差大、还在扩大，就加劲；误差小、正在快速收敛，就收着点，别冲过头。"这类规则不依赖精确模型，却在各种工况下都好用。

模糊逻辑（fuzzy logic）的价值就在于此：它把"大/小/快/慢"这些语言量转化为连续可计算的隶属度，让规则表自动插值，得到平滑的增益调度。它和另外两种"智能"方法（第 056 章神经网络、第 057 章强化学习）的区别要一开始就树立：模糊不学习、不拟合数据，它把人的先验知识结构化；计算量恒定且极小；行为可解释（每条规则可以讲给同事听），这在安全相关的力控回路里是巨大优势。它的短板同样明确：规则表靠人手写、维数膨胀快、没有"发现新策略"的能力。

核心原理

1. 模糊控制器四步流水线

以"力误差 e = Fd − F 及其变化率 ė"为输入、输出"积分速率倍率 g ∈ [0, 1.5]"为例（g 乘在位置偏置的更新速率上）：

  1. 模糊化：把 e 归一化到论域 [−2, 2]（除以尺度 escale，如 2 N），用 5 个三角形隶属函数 NB/NS/ZE/PS/PB 求隶属度。三角形底宽 2、中心间隔 1，相邻三角形 50% 重叠，使得任意输入至多被两个集合"部分覆盖"，拼起来恒为 1，输出连续且无盲区。
  2. 规则激活：5×5 规则表给出每条规则的输出常量 gi；激活强度用乘积推理 wi = μe,i·μde,i（也可以用 min，乘积更平滑）。
  3. 解模糊：直接算加权平均 g = Σwigi/Σwi。这叫高度法（height defuzzification），因为输出是"单点集"，不需要算面积积分。
  4. 后处理：乘回尺度，加输出限幅（[0, 1.5]），作为基础积分的增益倍率。

2. 规则表的设计逻辑

规则表是"知识"，写的时候照下面三条原则，比逐格拍脑袋可靠得多：

  • 对称性：把误差和变化率同时取反，结论应不变（g(e, ė) = g(−e, −ė)），因为"力太大、正在变大"与"力太小、正在变小"是同构的。对称规则表还省掉一半调试工作。
  • 同号激进、异号刹车：e 与 ė 同号（误差在扩大）→ 加大倍率（1.2–1.5）；异号且 e 小（正在收敛）→ 压到 0.2–0.7，实现对超调的"预先刹车"。
  • 零误差列平缓：e ≈ 0 时输出接近 0（避免小误差也被猛调）；但 |ė| 大时给 0.2–0.6 的"预动作"，提前抵消趋势。

下表就是按这三条写出的经典 5×5 表（行 = e，列 = ė，数值为倍率 g）：

e \ ėNBNSZEPSPB
NB1.51.21.00.80.5
NS1.20.90.70.50.3
ZE0.60.20.00.20.6
PS0.30.50.70.91.2
PB0.50.81.01.21.5

读几个格子："e = PB、ė = NB"（力严重不足但正在快速回升）给 0.5，刹车，防止冲过目标；"e = NB、ė = NB"（力严重过大且还在变大）给 1.5，最紧急的工况，全力回调。

3. 为什么它稳定：把模糊当作"有界的非线性增益"

模糊控制器不含动态、不含记忆（本章版本），因此稳定性分析可以退化成"增益上界"检查：输出倍率最大 1.5，所以最坏情况的等效回路增益是基础增益的 1.5 倍。设计规则是：

ki · Kenv,max · 1.5 ≤ ω内环/3 基础积分增益 × 最硬环境刚度 × 模糊增益上界，仍要低于内环带宽的三分之一，先按最坏点设计，再让模糊在好工况下"锦上添花"

注意这句话的含义：模糊控制器不是用来自救一个不稳定的基础回路的；它的职责是在稳定性预算内把"快"与"稳"的矛盾摊到不同工况上。若指望靠规则表把 ki 从"其实太大"救回来，规则表写得再漂亮也会在某个中间工况露馅。

实现思路与设计

把模糊模块接到力跟踪回路上（控制周期 1 ms）：

  1. 输入准备：e 用滤波后的力误差；ė 用 20 ms 窗的一阶差分（第 047 章的滤波链输出后再差分，避免噪声经模糊"放大"）。
  2. 归一化尺度：escale = 2 N（覆盖典型力控范围 ±4 N 进入饱和区）；descale = 20 N/s。
  3. 规则表实现：5×5 常量表 + 隶属度外积，全向量化，单周期约 60 次乘加，1 kHz 下 CPU 占用可忽略。
  4. 输出用途：g 乘在偏置积分速率上（本章方案）；也可以设计成同时调 Kd（Kd 乘 (0.8 + 0.4g)），但对变刚度的能量问题要回到第 053 章的规则。
  5. 下限保护：g ≥ 0，避免残余振荡被"反向增益"放大；上限 1.5 与稳定性预算对应。

验收：与固定增益跑同一组"软/硬环境"实验，比较超调、稳定时间与力波动；模糊版本应在硬环境下明显减小超调，在软环境下不明显变慢。

关键代码与解读

片段 1：模糊增益调度器

import numpy as np

class FuzzyGain:
    """模糊增益：输入(力误差 e, 误差变化率 de)，输出倍率 g ∈ [0, 1.5]。
    三角形隶属度(50% 重叠) + 高度法解模糊，计算量恒定、行为可解释。"""
    CENTERS = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])    # NB NS ZE PS PB
    RULE = np.array([
        [1.5, 1.2, 1.0, 0.8, 0.5],   # e=NB：力过大
        [1.2, 0.9, 0.7, 0.5, 0.3],   # e=NS
        [0.6, 0.2, 0.0, 0.2, 0.6],   # e=ZE
        [0.3, 0.5, 0.7, 0.9, 1.2],   # e=PS
        [0.5, 0.8, 1.0, 1.2, 1.5],   # e=PB：力严重不足
    ])

    def __init__(self, e_scale=2.0, de_scale=20.0):
        self.e_scale, self.de_scale = e_scale, de_scale

    @classmethod
    def _memberships(cls, x):
        # 三角形：中心处 1，离开 1 个间距归零；相邻两个三角形重叠 50%
        m = 1.0 - np.abs(cls.CENTERS - x)
        return np.clip(m, 0.0, 1.0)

    def eval(self, e, de):
        # 归一化 + 饱和：野值(传感器尖峰)不破坏规则区间
        x = float(np.clip(e / self.e_scale, -2.0, 2.0))
        y = float(np.clip(de / self.de_scale, -2.0, 2.0))
        w = np.outer(self._memberships(x), self._memberships(y))  # 乘积推理
        wsum = w.sum()
        if wsum < 1e-9:
            return 0.0
        # 高度法解模糊：规则输出的加权平均（输出是单点集，无需面积积分）
        return float((w * self.RULE).sum() / wsum)

解读：（1）隶属度函数用"1−|中心−x|"的向量式一行写完，比逐个 if 分支出错概率低；clip 保证重叠区外为零。（2）乘积推理 + 加权平均，两个求和就是全部代价，这就是它能进 1 kHz 回路的底气；对比之下，如果用重心法（centroid）解模糊，要对聚合后的面积做数值积分，代价高出一个数量级且收益有限。（3）输入饱和（clip 到 ±2 论域）看似细节，其实防的是"传感器尖峰把控制器推到规则表外的外推区"，模糊系统在论域外没有定义，必须由饱和兜底。（4）输出 g ∈ [0,1.5] 恒非负，保证"模糊只会调整快慢，不会反转控制方向"，方向永远由 e 的符号决定。

片段 2：模糊增益调制力跟踪积分（对比固定增益）

def tracking_sim(fuzzy_on, k_env=3e4, f_ref=20.0, dt=1e-3):
    """力跟踪：偏置积分速率被模糊倍率调制。k_i 按标称软环境整定，
    碰上 3 倍硬的表面时固定增益就会超调，看模糊怎么救。"""
    k_i, x_e = 0.004, 0.02          # 基础积分增益；实际表面在 20 mm
    x, off, f_prev, f_hist = 0.0, 0.0, 0.0, []
    fg = FuzzyGain(e_scale=2.0, de_scale=20.0)
    for k in range(2500):
        f = k_env * (x - x_e) if x > x_e else 0.0
        e = f_ref - f
        de = -(f - f_prev) / dt      # 误差变化率 = 力的下降速率
        g = fg.eval(e, de) if fuzzy_on else 1.0
        # 积分速率 = 基础增益 × 模糊倍率：收敛段被“刹车”，扩大段被加劲
        off += k_i * g * e * dt
        x += (x_e + off - x) * 0.15  # 内环一阶跟随(约 7 ms 时间常数)
        f_prev = f
        f_hist.append(f)
    over = (max(f_hist) - f_ref) / f_ref        # 全程峰值超调(含接触瞬间)
    return over, f_hist

for flag in (False, True):
    over, fh = tracking_sim(flag)
    print(f"fuzzy={flag}  超调={over*100:5.1f}%  末值={fh[-1]:5.2f} N")

解读：（1）固定增益版本（fuzzy=False）在 ki·Kenv = 0.004×3×104 = 120 rad/s 的等效带宽下，与内环（约 150 rad/s）只差一档，全程峰值超调达到两位数百分比（本例 84.8%）；模糊版本在"误差正在快速收敛"的格子输出 0.3–0.7，等效地说"快到了就松油门"，超调随之下降（本例 72.5%）。（2）把 k_env 改成 1×104（软表面）再跑：两个版本都稳，模糊版因为在大误差段给 1.2–1.5 的倍率，稳定时间还略快，这就是"不牺牲正常工作点"的含义。（3）这段代码里 de 用"力的下降速率"，不对 e 求导再滤波：力信号已在第 047 章清理过，差分噪声小；若直接差分，噪声会先进模糊再放大。（4）进阶实验：把规则表所有值乘 0.5（"保守表"）和乘 1.3（"激进表"），观察超调与稳定时间的变化，验证"规则表强度整体缩放"等效于基础增益缩放，这能帮你在真实项目里快速标定。

片段 3：规则表设计自检

def audit_fuzzy(fg):
    """三项自检：① 中心对称 ② 输出有界 ③ 收敛段倍率小于发散段。"""
    ok_sym = all(abs(fg.eval(e, de) - fg.eval(-e, -de)) < 1e-9
                 for e in np.linspace(-3.0, 3.0, 31)
                 for de in np.linspace(-40.0, 40.0, 31))
    g_all = [fg.eval(e, de) for e in np.linspace(-3.0, 3.0, 31)
             for de in np.linspace(-40.0, 40.0, 31)]
    ok_bound = (min(g_all) >= 0.0) and (max(g_all) <= 1.5 + 1e-9)
    g_conv = fg.eval(1.2, 12.0)     # e 与 de 同号：误差在扩大 → 应该更大
    g_brake = fg.eval(1.2, -12.0)   # e 与 de 异号：正在收敛 → 应该更小(刹车)
    print(f"① 对称性: {'通过' if ok_sym else '不通过'}")
    print(f"② 有界性: {min(g_all):.2f} ~ {max(g_all):.2f} "
          f"{'通过' if ok_bound else '不通过'}")
    print(f"③ 刹车检查: 扩大段 {g_conv:.2f} vs 收敛段 {g_brake:.2f} "
          f"{'通过' if g_brake < g_conv else '不通过'}")

audit_fuzzy(FuzzyGain())

解读：（1）把"设计原则"写成自动检查有三个好处：改表之后立刻知道有没有手滑写错符号；评审时同事能跑一遍看结论；未来若换成 7×7 表，检查逻辑照搬。（2）第②项特别重要：有界性给出稳定性分析所需的增益上界，如果 check 失败（比如误写 15.0 当 1.5），最坏增益分析全部作废。（3）第③项检查的是"意图"层面的趋势，g(e, ė) 这样的函数可能有局部反常格子（例如对称轴附近的 0.2 vs 0.3 之争），但关键工况（大误差同号、小误差异号）必须满足直觉。最后提醒：自检通过 ≠ 回路稳定，它只保证"模糊模块本身不制造危险"，稳定性仍要靠基础增益按最坏点设计。

常见坑

  • 用模糊"硬扛"过大的基础增益：以为规则表能驯服任意 ki，结果在规则表覆盖不到的中间工况振荡。修复：先按最坏点（最硬环境×1.5 上界）整定基础增益，模糊只做工况适配。
  • 输入不带滤波/饱和：力尖峰直接进模糊化，输出瞬间跳到极值，控制量"抽一下"。修复：输入先过第 047 章调理链，再加 ±2 论域饱和。
  • 规则表不对称：手写表漏改一个格子，导致"力压过头"和"力不够"两种工况的动态完全不同，现场表现为"只有某一个方向会振"。修复：跑片段 3 的对称性自检。
  • 把 ė 的尺度定错一个数量级：de_scale = 200 N/s 时 ė 永远落在 ZE 列，规则表退化成"只看误差的一维表"，刹车功能全失效。修复：用实际系统的力变化速率分布（典型 5–50 N/s）定尺度。
  • 盲目上高维：为了"更智能"搞成 7×7×7（再加个速度输入），规则数从 25 涨到 343，调试量爆炸而性能提升有限。修复：先用 5×5，确有需要再逐维扩展，每扩一维都要有数据证明收益。

练习与思考

  1. 解释三角形隶属度 50% 重叠的两个好处（覆盖率与连续性），并验证：当输入恰好落在两个中心中点时（如 x = 0.5），两个隶属度之和为 1。★
    提示
    x=0.5 时 μZE = 0.5、μPS = 0.5；在 [−2,2] 内任意点，至多两个三角形非零且和恰为 1，这保证了解模糊输出的连续无跳变。
  2. 把片段 2 的 k_env 在 1×104、3×104、1×105 之间扫描，分别记录两种控制器的超调与稳定时间，画出"环境刚度-性能"对比，并解释固定增益为何在刚度变大时急剧恶化（提示：回路带宽 ∝ K）。★★
    提示
    kiKenv 随刚度线性上升，逼近内环带宽后相位裕度崩溃；模糊在收敛段压低倍率，等于把有效带宽"收缩"，故恶化更缓。
  3. 为规则表增加一列"刹车增强"：把"异号且 |e| 中等"的格子（NS/PB、PS/NB）从 0.3 降到 0.15，其余不变。用片段 3 的自检确认对称性仍通过，再用片段 2 观察超调变化；解释为什么这个改动不影响软环境下的速度。★★
    提示
    软环境下误差收敛慢，落入"异号大 ė"格子的时间少，因此主要影响硬环境的超调；改表要用数据（超调 vs 稳定时间）评估，不要凭感觉。
  4. 设计一个双输出模糊控制器：同时输出"积分倍率 g1"与"刚度倍率 g2"（维度同 5×5），说明 g2 的规则表应该与 g1 有何不同（提示：刚度的变化受第 053 章能量约束，应该更迟钝、更保守），并给出你会怎样限制 g2 的变化率。★★★
    提示
    g2 表整体幅度更小（如 [0.9, 1.1]）、且应带"接触稳定后才允许升 K"的使能条件；变化率限制沿用 053 章的 K̇ ≤ 2Dv²/e² 的粗略上界，或直接沿用调度器的速率常数。

小结

  • 模糊控制器把语言规则变成连续增益：模糊化（三角形 50% 重叠）→ 乘积推理 → 高度法解模糊，全程几十次乘加。
  • 规则表三原则：中心对称、同号激进、异号刹车；零误差列平缓但保留预动作。
  • 稳定性用"最坏增益"记账：ki·Kenv,max·gmax ≤ ω内环/3；模糊不做"雪中送炭"，只做"锦上添花"。
  • 工程细节：输入滤波+饱和、尺度校准（escale、descale）、输出非负、规则表自动自检。
  • 模糊 ≠ 学习：它编码先验知识、可解释、可验证，这是它在安全相关力控中不可替代的原因。
