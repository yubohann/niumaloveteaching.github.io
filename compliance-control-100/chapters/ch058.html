第 058 章：阻抗控制中的能量整形

阻抗控制说了半天"让机器人像弹簧阻尼器"，但弹簧阻尼器的本质是一张有界的能量账本。本章把控制问题改写成"给闭环选一个能量函数"，从端口哈密顿形式出发做能量整形与阻尼注入，并给变参数配一个"先存后花"的能量储藏槽。

  • 主题：端口哈密顿系统（pH）/ 能量整形与无源控制
  • 关键公式：ẋ = (J − R)∇H，V = ½Mdv² + ½Kde²，V̇ = −Ddv² + v·Fext
  • 预计学时：60 分钟
  • 前置章节：第 057 章（基于强化学习的阻抗参数优化）

学习目标

  • 理解端口哈密顿（port-Hamiltonian, pH）形式 ẋ = (J−R)∇H 的两个矩阵各代表什么：J 只管"路由"、R 只管"耗散"。
  • 理解阻抗控制是一类能量整形问题：先选定期望的闭环能量 Hd，再让控制器去实现它。
  • 会推导一维阻抗闭环的能量恒等式 V̇ = −Ddv² + v·Fext，并解释"为什么它天然对任意被动环境稳定"。
  • 会实现能量储藏槽（energy tank）：T ≥ 0、阻尼收入存入、参数升级支取，理解配额约束 ½ΔK·e² ≤ T。
  • 能写出 pH 结构自检与带槽位的变刚度实验代码，并读懂能量日志。

背景与动机

前几章处理参数与安全时，本质上都在用"局部线性化 + 经验规则"：看极点、看相位裕度、限速率、设阈值。这些方法有效，但都有一个共同前提，你得知道环境参数（刚度、阻尼）才能验算。能量方法提供了另一条路：不依赖环境参数，只要机器人和环境都是"不会凭空造能量"的系统，互联后的稳定性就由能量账本自动保证。这就是无源控制（passivity-based control）的思想，而它的实现工具，就是本章的"能量整形 + 阻尼注入"。

换个说法：位置控制是给机器人写"剧本"（轨迹），阻抗控制是给机器人装"弹簧阻尼器"，而能量整形则是直接设计"这个弹簧阻尼器系统的总能量长什么样"。它带来的红利在第 053 章已经露过头：正是因为没有把变刚度的能量注入讲清楚，你才会在切换时"抖一下"。本章把那个直觉升级成定理的可计算版本。

核心原理

1. 端口哈密顿形式：把"能量"摆到台面上

机器人和物理系统里常见的一类动力系统可以写成：

ẋ = (J(x) − R(x)) ∇H(x) + B(x)·u H：总能量（储能函数）；J：反对称矩阵（Jᵀ = −J）；R：半正定矩阵（R ≥ 0）；u：端口输入

对能量的导数做一次内积：∇HᵀJ∇H = 0（反对称矩阵的二次型恒为零），于是

Ḣ = −∇Hᵀ R ∇H + yᵀu， y = Bᵀ∇H 两项的物理含义一清二楚：−∇HᵀR∇H 是内部耗散（永远 ≤ 0），yᵀu 是与外界交换的功率

以一维质量-弹簧-阻尼为例（状态 [q, p]，p = Mẋ 为动量，目标位置 qd）：

H = p²/(2M) + ½K(q−qd)²， J = [[0, 1], [−1, 0]]（反对称）， R = diag(0, D)（只作用在动量通道）

展开 (J−R)∇H 得到的就是熟悉的 ẋ = p/M、ṗ = −K(q−qd) − D·p/M。工程直觉：J 只负责"能量在动能与势能之间来回倒腾"，一个焦耳都不产生；R 只负责"把能量变成热"。这就是为什么无源系统的稳定性证明从来不依赖参数的具体数值，能量账本就长这样。

2. 阻抗控制 = 能量整形 + 阻尼注入

能量整形的观点把控制器设计变得直观：你不需要"凭空发明"控制律，只需先写下期望闭环的能量函数：

Hd = ½Mdv² + ½Kd(x − xd)²， 闭环目标： V̇d ≤ v·Fext 第一项塑形"惯性"，第二项塑形"弹簧"；最后的不等式表示：除了对外交换的功，闭环只会耗散

对一维对象 Mẍ = τ + Fext，取控制律 τ = −Kd(x−xd) − Ddẋ 并令 V = ½Mv² + ½Kd(x−xd)²（注意质量项仍是物理质量）：

V̇ = v(M v̇ + Kd(x−xd)) = v(−Ddv + Fext) = −Ddv² + v·Fext

这个恒等式是本章的心脏：闭环自己的能量永远不会涨，只会耗散；外力与机器人之间可以双向交换能量，但只要环境是被动的（对环境的净输入非负），整个互联系统就稳定。注意"整形"一词的准确性：控制律并没有改变物理质量，它改变的是"势能井"的形状（把无控制的自由系统变成围绕 xd 的弹簧井），并在动量通道注入阻尼。重力补偿是最简单的能量整形案例，把势能 Vg = mgh 从能量函数里"减去"，让原点在任意姿态都成为能量极小点。

3. 能量储藏槽：把"变参数"纳入能量账本

第 053 章讲过：刚度增大时注入 ½K̇e² 的功率。从能量整形的角度，这笔注资必须"有来源、有账目"。能量储藏槽（energy tank）就是为此设计的第三条账本：

T ≥ 0， Ṫ = σ·Dd·v² − Pc T：槽位余额（J）；σ ∈ (0,1]：阻尼耗散中存入槽位的份额；Pc：参数升级/参考修改索取的功率（如 ½K̇de²）

规则只有一条：任何"向系统注能"的操作只能从槽里支出，且不许透支。变刚度请求 ½K̇de² 的功率时，先问账："T 够不够付这一拍？"不够就冻结升级（等耗散慢慢回充）。槽位还要设上限 Tmax：否则长时间运行会把所有耗散都存起来，一旦某次参数操作把槽放空，系统会突然失去阻尼感。σ 通常取 0.2–0.5：把大部分耗散留给物理阻尼，小部分留给"创新预算"。

它和第 046/059 章的 PO/PC 是同一思想家族：先审计、再动作。区别是槽位允许"先存后花"（有预算的借贷），而 PC 是"即收即烧"的保守版。

实现思路与设计

用能量方法设计一个阻抗控制器的落地顺序（1 ms 控制周期）：

  1. 写期望能量：Hd = ½Mdv² + ½Kd(x−xd)²；标出它需要的整形项（弹簧井、重力补偿）与阻尼项。
  2. 推导控制律：一维情形直接写出 τ = −Kde − Ddv（加已知模型前馈）；多关节用能量整形 + 阻尼注入的标准形式（IDA-PBC 提供系统化构造，本章用其一维退化形式）。
  3. 验算能量恒等式：仿真里逐拍计算 V 与 ΔV + Ddv²Δt，二者应只差外力做功项，这是最实在的自检。
  4. 接入槽位：T 初始化 2–5 mJ；σ = 0.5；Tmax = 20–50 mJ；所有参数升级（变 K、变 xd 大跳变）必须过支出检查。
  5. 日志与告警：记录 T(t)、拒绝次数、V(t)；若拒绝次数长期高企，说明任务需要的注资超过系统耗散能力，应放慢调度或减小 ΔK。

参数示例：m = 1 kg、Kd 从 300 升到 1800 N/m、k̇d = 3000 N/(m·s)、e = 8 mm、Dd = 40 N·s/m；槽位 T0 = 2 mJ、σ = 0.05、Tmax = 20 mJ。注意 σ 取 0.05 是刻意"抠门"的演示值：让槽位经常成为瓶颈，你才能看清它的作用。

关键代码与解读

片段 1：pH 结构自检（J 反对称、R 半正定、能量只会降）

import numpy as np

def ph_1dof(m=1.0, k=500.0, d=45.0, q_d=0.0, dt=1e-3, t_end=1.0):
    """一维质量-弹簧-阻尼的端口哈密顿形式自检：
    x_dot = (J - R) @ grad_H；J 反对称只管路由，R 半正定只管耗散。"""
    q, p = 0.02, 0.0                       # 初始位移 2 cm、动量 0
    J = np.array([[0.0, 1.0], [-1.0, 0.0]])   # 交错矩阵：动能<->势能路由
    R = np.array([[0.0, 0.0], [0.0, d]])      # 耗散矩阵：只作用在动量通道
    E_hist = []
    for _ in range(int(t_end / dt)):
        grad = np.array([k * (q - q_d), p / m])   # ∇H
        dq_dp = (J - R) @ grad                    # 状态导数
        q += dq_dp[0] * dt
        p += dq_dp[1] * dt
        E_hist.append(0.5 * p * p / m + 0.5 * k * (q - q_d) ** 2)
    E = np.array(E_hist)
    print(f"总能量从 {E[0]*1000:.2f} mJ 耗散到 {E[-1]*1000:.4f} mJ")
    print(f"逐拍能量增量最小值: {np.min(np.diff(E)):.3e} J（应接近 0 且非正）")

ph_1dof()

解读：（1）这段代码的价值不在"仿真一个弹簧"，而在把结构性质"跑出来"：J 的反对称性如果用矩阵乘法检查（J + Jᵀ = 0），R 的半正定性用特征值检查，这两条是任何能量整形设计的"出生证"，应该在仿真初始化时就断言。（2）能量单调不增只在 R ≥ 0 且离散化足够细时成立；显式欧拉在 dt 偏大时会有微小能量波动（数值"造能"），这也是真机上"为什么需要 PC/槽位兜底"的数值侧原因，模型再漂亮，采样精度有限。（3）把 q_d 换成时变的 qd(t) 再跑，你会看到能量曲线出现"平台或台阶"，那正是参考轨迹在向系统注入（或抽取）能量，这个现象将引出片段 3 的槽位。

片段 2：能量储藏槽与"先存后花"的变刚度

class EnergyTank:
    """能量储藏槽：阻尼耗散按份额存入，参数升级按预算支取。
    支出检查拒绝时返回 False：调用方必须真正放弃本拍的升级。"""
    def __init__(self, d_diss=40.0, sigma=0.05, t_max=0.02, t_init=0.002):
        self.d_diss, self.sigma = d_diss, sigma
        self.t_max, self.t = t_max, t_init

    def charge(self, v, dt):
        # 阻尼收入：sigma 份额存槽（其余留给物理阻尼），并封顶
        self.t = min(self.t + self.sigma * self.d_diss * v * v * dt, self.t_max)

    def spend(self, p_out, dt):
        # 支出：功率 p_out 持续 dt；不够付则拒绝，槽位不动(不许透支)
        if p_out * dt > self.t:
            return False
        self.t -= p_out * dt
        return True

def ramp_sim(use_tank, dt=1e-3, t_end=2.0, k_target=1800.0, k_dot=3000.0):
    """被压紧的弹簧(k: 300->1800)遇上“先存后花”：对比升级速度与速度峰值。"""
    m, d, q, v, k = 1.0, 40.0, 0.008, 0.0, 300.0
    tank = EnergyTank(d_diss=d)
    t_reach, v_peak = None, 0.0
    for i in range(int(t_end / dt)):
        e = q                                   # 固定偏差演示：e 近似不变
        kd = k_dot if k < k_target else 0.0
        if kd > 0.0 and use_tank:
            if not tank.spend(0.5 * kd * e * e, dt):   # ½ k̇ e²：升级的注资功率
                kd = 0.0                        # 预算不足：本拍冻结升级
        k = min(k + kd * dt, k_target)
        if t_reach is None and k >= k_target - 1e-9:
            t_reach = i * dt
        tank.charge(abs(v), dt)
        a = (-k * e - d * v) / m
        v += a * dt
        q += v * dt
        v_peak = max(v_peak, abs(v))
    return v_peak * 1000.0, t_reach

for flag in (False, True):
    vpk, tr = ramp_sim(flag)
    print(f"use_tank={flag}  速度峰值={vpk:6.2f} mm/s  刚度到位时间={tr:.3f} s")

解读：运行结果（本章参数）会打印两行：无槽位版速度峰值约 62.9 mm/s、0.50 s 内完成升级；带槽位版峰值约 54.8 mm/s、升级被拉到约 0.65 s。这就是"先存后花"的定价：用 30% 的升级时间去换 13% 的速度峰值削减。（1）为什么峰值会降？因为升级被冻结的那些拍里，弹簧刚度没涨，系统有更多时间让阻尼把动能吃掉。（2）为什么只削 13%？因为槽位只是"限流器"，不承担"刹车"的角色，真正的安全裕度仍来自 σ 与 κ̇ 的联合设计。把 σ 从 0.05 提到 0.5（更慷慨的入账）会几乎看不出差别，这正是"演示参数要捶到疼处"的道理。（3）注意 spend 被拒绝时调用方必须真的把 kd 置零，很多实现"问是问了、升级照做"，账就白记了。

片段 3：把重力补偿理解为势能整形

# 单摆：I*q'' = tau - mgl*sin(q)。控制器做两件事：
# ① 势能整形：+mgl*sin(q) 把重力势能“抹平”（这就是重力补偿）
# ② 阻尼注入：-d*q' 给系统装上耗散通道
# 闭环能量 V = ½I q'^2 + ½k(q-q_d)^2 应满足 V_dot = -d q'^2
def pendulum_shaping(I=0.1, mgl=8.0, k=20.0, d=2.0, q_d=0.1, dt=1e-4):
    q, dq = 0.30, 0.0                      # 初始 0.3 rad，离目标 0.2 rad
    V_hist = []
    for i in range(int(1.5 / dt)):
        tau = -k * (q - q_d) - d * dq + mgl * np.sin(q)   # 整形+注入
        ddq = (tau - mgl * np.sin(q)) / I                  # 真实对象
        dq += ddq * dt
        q += dq * dt
        V_hist.append(0.5 * I * dq * dq + 0.5 * k * (q - q_d) ** 2)
    V = np.array(V_hist)
    print(f"V(0)={V[0]*1000:7.2f} mJ  V(1.5s)={V[-1]*1000:7.4f} mJ")
    print(f"逐拍增量最大值: {np.max(np.diff(V)):.3e} J（应 ≈ 0，投影误差量级）")

pendulum_shaping()

解读：（1）把控制律写成"−k e − d q̇（整形 + 阻尼）+ mgl·sin q（势能整形项）"，与把重力补偿当成"抵消干扰"是两种完全不同的视角：前者说明为什么重力补偿后系统对任意姿态都稳定（能量函数处处正定），后者只能解释"某个位置能不能站住"。（2）打印的 V 从 400 mJ 单调降到零附近，逐拍增量最大值约 −10−18 J，在浮点意义上就是零，说明"能量单调不增"在离散实现里也保持住了（这正是无源方法对数值友好的体现）。（3）顺带说清一个常见混淆：摆的"势能井"是重力提供的；整形项把它抹平后，新的势能井由控制器弹簧提供。两个井的曲率之和才是闭环刚度，这也是为什么重力补偿误差会以"弹簧偏移"的形式表现出来。

常见坑

  • 只做势能整形、忘了阻尼注入：能量函数正定只保证"不会发散"，不保证收敛到目标，观测量会在等能面上永久游荡。修复：任何整形设计都配一对阻尼注入，ζ ≥ 0.7。
  • 把 J 写成对称矩阵：反对称性一旦破坏，"路由"就变成了"油泵"（∇HᵀJ∇H ≠ 0），稳定性证明作废。修复：构造后立即断言 J + Jᵀ ≈ 0。
  • 槽位没有上限：长期运行后 T 顶到 Tmax 之外任意增长，某次参数调度一次放空，手感突变。修复：Tmax = 3–10 倍典型升级成本，超出部分"漏掉"（视为耗散）。
  • 支出检查形同虚设：spend 返回 False 后仍执行升级，账目与动作脱节；或把 ½K̇e² 的 e 用了错的量（用了速度）。修复：升级功率的推导写进注释，单测覆盖"拒绝路径"。
  • 把能量方法与"低增益"混为一谈：无源性保证的是"不造能"，不是"性能好"；用极小的 K、极大的 D 换来的稳定毫无工程价值。修复：能量账本管安全，性能仍按第 001–021 章的带宽/刚度准则设计。

练习与思考

  1. 验证反对称矩阵的二次型恒为零：任取 2×2 反对称矩阵 J 与非零向量 x，计算 xᵀJx；再解释为什么 R 只需半正定就能保证 Ḣ 的耗散项非正。★
    提示
    xᵀJx = (xᵀJx)ᵀ = xᵀJᵀx = −xᵀJx → 只能是 0。R 的意义：∇HᵀR∇H ≥ 0 对一切梯度成立 ⇔ R ≥ 0。
  2. 推导片段 1 的逐拍能量恒等式：证明 V̇ = −Ddv² + v·Fext，并说明若环境是刚度 Ke 的弹簧（Fext = −Ke(x−xe)），闭环总能量 ½Mv² + ½Kde² + ½Ke(x−xe)² 的导数是什么、为什么非正。★★
    提示
    把环境弹簧的势能也纳入总能量：其导数为 Ke(x−xe)ẋ = −Fext·v，与 v·Fext 恰好相消，剩下 −Ddv² ≤ 0，两个"储能元件"互换了能量的账，阻尼一方净耗散。
  3. 把片段 2 的 σ 取 0.02/0.2/0.8，记录升级时间与速度峰值；解释"入账越慷慨，槽位越不成为瓶颈"这一趋势，并给出你为某打磨任务（允许升级时间充裕、峰值力敏感）推荐的 σ 与 Tmax。★★
    提示
    σ 大 → 冻结少 → 曲线趋近无槽位版；峰值敏感的工艺应选小 σ（让限流更狠）+ 中等 Tmax（避免一次大额支出），并用日志验证拒绝次数。
  4. 设计"参考轨迹的能量预算"：把 xd 的阶跃改造成 smoothstep 时，推导它以功率 ½Kd·2e·ẋd 向系统注能（提示：对 ½Kd(e)² 求导时 e 的导数含 −ẋd）；给出"轨迹修改也要过槽位检查"的判据，并说明它与第 053 章"平衡门控"的关系。★★★
    提示
    d(½K e²)/dt = K e ė = K e(ẋ − ẋd)，其中 −K e ẋd 是参考移动注入的功率项；把该项送入 spend 检查，就得到"轨迹级"的先存后花；平衡门控（|v| 小时才动参数）是它的特例。

小结

  • 端口哈密顿形式把系统写成 ẋ = (J−R)∇H：J 反对称负责能量路由、R 半正定负责耗散，能量账本 Ḣ = −∇HᵀR∇H + yᵀu。
  • 阻抗控制 = 能量整形 + 阻尼注入：先选闭环能量 Hd，再让控制律实现它；一维闭环满足 V̇ = −Ddv² + v·Fext。
  • 无源性保证与参数无关的全局稳定：只要环境被动，互联系统的能量有界（把环境势能一并纳入能量函数即可看出）。
  • 能量储藏槽为"变参数/变参考"提供预算制：T ≥ 0、耗散按 σ 入账、升级按 ½K̇e² 支取、不许透支，付不起就冻结。
  • 能量方法管安全不管性能；刚度、阻尼的取值仍由任务带宽与手感决定，账本只保证不越安全红线。
  • 下一章把这套账本搬到导纳控制：采样与延迟会直接破坏连续系统的无源性，我们来看审计器（PO）与耗散器（PC）如何把损失补回来。
