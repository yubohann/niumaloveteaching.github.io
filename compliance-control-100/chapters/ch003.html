第一篇 · 基础、建模与稳定性

第 003 章：阻抗参数对接触力的影响

把接触过程写成封闭的二阶系统，用稳态值、阻尼比与冲击峰值三条公式，量化 Md、Dd、Kd 各自对接触力做了什么。

  • 主题：阻抗控制 / 接触力动力学分析
  • 关键公式：ωn = √((Kd+Kenv)/Md)，ζ = Dd/(2√(Md(Kd+Kenv)))，Fpeak ≈ vc√(MdKenv)
  • 预计学时：50 分钟
  • 前置章节：第 002 章

学习目标

  • 会把"机器人虚拟阻抗 + 环境弹簧"联立成封闭二阶系统，并写出特征方程。
  • 掌握三条定量公式：稳态接触力 Fss = KeqΔx、接触阻尼比 ζeff 与超调量 Mp、速度冲击峰值 Fpeak ≈ vc√(MdKenv)。
  • 理解为什么"按自由空间临界阻尼整定的机器人在刚性环境里会剧烈超调"，ζeff 的分母里多了 Kenv。
  • 会分辨两种截然不同的接触激励：参考位置阶跃（超调有界）与带速度冲击（能量决定峰值），以及各自的对策。
  • 能说出三个参数各自的"管辖范围"：Kd 管稳态力，Dd 管超调，Md 管冲击峰值。

背景与动机

调参现场最常见的疑问是："我把 Kd 从 500 改到 2000，接触力为什么没变大多少？""为什么慢速靠近很平稳，一快就'啪'地一声撞出 20 N 的尖峰？""阻尼明明按临界值给的，一碰上去还是嗡嗡振？"这些问题全都指向同一件事：接触力由机器人虚拟阻抗与环境刚度联立解出，无法单靠调参直接设定。

本章把接触过程写成解析式，用三条公式回答上面三个问题。学完你就能在动手之前预测：改变哪个参数、改变多少、接触力曲线的稳态、超调与峰值分别怎么动，这是把"试错调参"升级为"计算调参"的关键一步。

核心原理

1. 联立：接触闭环是一个二阶系统

沿用第 001 章的符号约定：机器人末端被期望服从虚拟阻抗关系 Md(ẍ−ẍd) + Dd(ẋ−ẋd) + Kd(x−xd) = −F，其中 F 是接触力幅值（N），因接触力总与运动方向相反而带负号。环境用单向弹簧建模：F = Kenv(x−xe)，Kenv 为环境刚度（N/m），xe 为环境表面位置（m）；只有 x > xe 成立时才成立（墙不会"拉住"机器人）。

把环境方程代入阻抗方程，并令参考点静止（ẋd = ẍd = 0，这是接触阶段最常见的情形）：

Mdẍ + Ddẋ + (Kd + Kenv)x = Kdxd + Kenvxe 左端：(Kd+Kenv) 是"虚拟弹簧与环境弹簧并联"的总刚度，单位 N/m

这就是本章的出发点：接触阶段的机器人相当于一个质量 Md、刚度 Kd+Kenv、阻尼 Dd 的经典二阶系统。对照标准形式 M s² + 2ζωnM s + Mωn² （质量-弹簧-阻尼），立刻读出两条特征参数：

ωn = √((Kd + Kenv) / Md) ， ζeff = Dd / (2√(Md(Kd + Kenv))) ωn：接触自然频率（rad/s）；ζeff：接触有效阻尼比（无量纲）

工程直觉：环境刚度直接"加进"了你的虚拟弹簧。你在自由空间里精心设计的 Kd = 500 N/m，一碰 105 N/m 的钢件，总刚度瞬间变成约 100500 N/m，刚度几乎全部由环境决定，而阻尼 Dd 没有跟着变大，于是阻尼比被"稀释"了 14 倍。这就是"自由空间调好的参数一接触就振"的数学原因。

2. 稳态接触力：串联弹簧的下标要对

接触稳定后所有导数项为零，从上面的式子解出平衡位置，再代回环境方程：

Fss = Keq·(xd − xe)， Keq = KdKenv/(Kd + Kenv) xd−xe：参考点越过环境表面的"偏置量"（m）；Keq：串联等效刚度

这条式子包含两个反差极大的事实。第一，稳态力只由偏置量和两个刚度决定，与 Dd、Md 无关，加阻尼不能让机器人压得更紧，只能让过程更平稳。第二，当 Kenv ≫ Kd 时 Keq ≈ Kd：刚性环境下力几乎由虚拟刚度说了算；但 Kenv 小（软环境）时 Keq ≈ Kenv：力主要由环境决定，虚拟刚度再大也压不出大力量。同一段偏置，在钢板上得到 500·Δx，在橡皮上也许只有 200·Δx，想压软物体必须加大偏置；软环境里加大 Kd 压不出更大的力。

3. 参考阶跃下的超调：ζeff 说了算

假设接触已经建立，参考点 xd 突然被推入 δ（比如上层轨迹模块做了一次插补跳变），初值 x(0)=xe、ẋ(0)=0。这是标准二阶系统的阶跃响应，力的波形与位移波形成比例（F = Kenv(x−xe)）。两条现成公式：

Mp = exp(−πζeff/√(1−ζeff²)) ， tp = π/(ωn√(1−ζeff²)) Mp：最大超调比例；tp：到达首个峰值的时间（s）。2% 稳定时间可估 ts ≈ 4/(ζeffωn)

代入一组真实数字：Md=1 kg、Kd=500 N/m、Dd=2√(KdMd)=44.7 N·s/m（自由空间临界阻尼），Kenv=105 N/m。则 ωn=317 rad/s≈50 Hz，ζeff=44.7/(2√(1·100500))≈0.07，Mp≈80%，tp≈9.9 ms。参考一旦阶跃，力会先冲到稳态值的 1.8 倍，再以约 50 Hz 的频率来回摆动，这正是现场听到的"碰上去嗡嗡响"。治疗方式有两种：要么按接触场景把 Dd 按 ζeff=0.7 反推（本例 Dd≈440 N·s/m），要么让参考轨迹永远不阶跃（做平滑插补）。前者会让自由空间运动变得粘滞迟钝，这是"一组参数走天下"的固有矛盾，第 020 章用变阻抗解决。

4. 速度冲击：能量决定峰值

另一类完全不同的激励是"带着速度撞上去"：接触瞬间 x=xe、ẋ=vc（接近速度，m/s）。此时驱动峰值力的是机器人的动能。在力峰值的极短时间内，忽略阻尼与虚拟弹簧做功（接触环境刚度占绝对优势），能量守恒给出：

½ Md vc² = ½ Fpeak²/Kenv ⟹ Fpeak ≈ vc·√(MdKenv) vc：接触瞬间速度（m/s）。例：vc=0.06 m/s、Md=1 kg、Kenv=105 N/m → Fpeak≈19 N

注意 19 N 这个数，稳态力才 5 N，冲击峰值却是它的近 4 倍，而峰值与接近速度成正比：速度减半，冲击减半。这解释了工业实践里"接近段减速"的铁律，也给出一条设计式：若允许最大冲击 Fmax，则接近速度应满足 vc ≤ Fmax/√(MdKenv)。例如要求冲击不超过 5 N、Kenv=105、Md=1，则 vc ≤ 0.016 m/s。

5. 三个参数的管辖范围

参数稳态力 Fss超调 Mp / 频率 ωn冲击峰值 Fpeak
Kd ↑增大（趋向 Keq→Kenv 上限时饱和）ωn 略增、ζeff 略降几乎不变（Kenv 主导）
Dd ↑不变超调显著下降、摆幅收敛快几乎不变
Md ↑不变ωn 降低、更"迟钝"线性增大 √Md
接近速度 vc ↓不变不适用线性减小

用一句话总结：要调"压多紧"改偏置（必要时配 Kd）；要调"稳不稳"改 Dd；要调"撞多疼"改接近速度与 Md。把这张表贴在调试台前，可以省掉大量盲调时间。

实现思路与设计

把上面的公式变成一条可执行的参数设计流程：

  1. 先估计环境刚度：用"推一段已知位移读力"的现场实验粗估 Kenv = ΔF/Δx。钢板 105、铝件 105、塑料件 103–104、橡皮 102 量级。这个数决定后面所有公式的走向。
  2. 由力需求定 Kd 与偏置：目标力 15–25 N 的打磨场景，取 Kd=500 N/m、偏置 3–5 cm 左右；同时检查 Kd ≤ Kenv/20 的稳定裕度经验。
  3. 由超调需求定 Dd：若你要对参考阶跃的 ζeff ≥ 0.7（超调 ≤ 5%），按 Dd = 2ζeff√(Md(Kd+Kenv)) 反推。注意这是"接触值"；如果自由空间也需要活跃的手感，干脆采用平滑轨迹规划，把 Dd 留在自由空间临界值附近。
  4. 由冲击需求定接近速度：vc ≤ Fmax/√(MdKenv)，在轨迹规划器里用"剩余距离开方"的减速律实现（代码片段 3）。
  5. 仿真验证再上机：用 10−4 s 步长仿真接触瞬态，比对 Fpeak、Mp、ts 与公式预测，偏差超过 30% 说明模型缺项（摩擦、延迟、内环滞后）。
设计决策：仿真步长为什么要比控制周期小 10 倍？

接触自然频率 ωn 由环境刚度决定，可达 300 rad/s（50 Hz）以上，其中还包含大量高频振铃。控制周期 1 ms 足以"控制"，但不足以"观测"瞬态：要准确捕捉峰值和振荡周期，仿真步长需要至少 30 个采样/周期，即 Δt ≤ 2π/(30ωn) ≈ 0.6 ms；对更硬的环境取 0.1 ms 更稳妥。代码片段 1 用 10−4 s 就是这个考虑。这也是为什么真机上 1 kHz 控制器看到的"冲击峰值"往往比仿真低，采样把尖峰平均掉了，别用控制器日志去标定冲击模型。

关键代码与解读

片段 1：接触阶跃仿真，观察 Kd 与超调的关系

import numpy as np

def contact_step(k_d, d_d, m_d=1.0, k_env=1e5, dx=0.005,
                 dt=1e-4, t_end=0.4):
    """参考位置瞬间推入墙内 dx 米，返回(稳态力预测, 仿真峰值, 力轨迹)。"""
    x, v, f_hist = 0.0, 0.0, []      # 从接触点静止起步：纯阶跃激励
    for _ in range(int(t_end / dt)):
        # 单侧弹簧环境：越界才有力，墙面不会拉住机器人
        f = k_env * (x - 0.0) if x > 0.0 else 0.0
        # 阻抗方程解加速度（第 001 章符号约定：接触力项取负）
        a = (-d_d * v - k_d * (x - dx) - f) / m_d
        v += a * dt                   # 半隐式欧拉：对高频振荡更稳
        x += v * dt
        f_hist.append(f)
    f_hist = np.array(f_hist)
    f_ss = k_d * k_env / (k_d + k_env) * dx   # 串联刚度 × 偏置
    return f_ss, f_hist.max(), f_hist

for k_d in (200.0, 500.0, 2000.0):
    d_d = 2.0 * np.sqrt(k_d * 1.0)            # 自由空间的临界阻尼值
    f_ss, f_pk, _ = contact_step(k_d, d_d)
    print(f"K_d={k_d:5.0f}  F_ss={f_ss:5.2f}N  F_peak={f_pk:5.2f}N  "
          f"超调={(f_pk/f_ss-1)*100:4.0f}%")

解读：三种 Kd 各自配"自己尺度上"的临界阻尼，结果却全都大幅超调（64%–87%，Kd 越小越重），因为阻尼比的分母里还有 Kenv，自由空间临界阻尼在接触场景下全部退化成欠阻尼。这段代码的另一个价值是验证"仿真峰值不超过 2×Fss"（欠阻尼下从零位移起步的振荡上限），提示你：参考阶跃造成的超调有上限（≤100%），真正危险的是带速度的冲击（片段 2 的公式）。若把 d_d 改成 2√(k_d+k_env)（按接触阻尼要求设计），超调会掉到 5% 以内，你可以自己改一行验证。

片段 2：解析指标计算器，三条公式对号入座

def contact_metrics(k_d, d_d, m_d=1.0, k_env=1e5):
    """按解析公式给出接触二阶系统的完整指标，用于调参前预测。"""
    k_par = k_d + k_env                       # 关键：并联总刚度
    wn = np.sqrt(k_par / m_d)                 # 接触自然频率 rad/s
    z = d_d / (2.0 * np.sqrt(m_d * k_par))    # 有效阻尼比（分母用 k_par）
    s = np.sqrt(max(1.0 - z * z, 1e-12))      # 防 z≥1 时开方为负
    mp = np.exp(-np.pi * z / s)               # 超调量（0~1）
    tp = np.pi / (wn * s)                     # 峰值时间 s
    ts = 4.0 / (z * wn)                       # 2% 稳定时间 s
    return wn, z, mp, tp, ts

for k_d in (200.0, 500.0, 2000.0):
    d_d = 2.0 * np.sqrt(k_d)                  # 自由空间临界阻尼
    wn, z, mp, tp, ts = contact_metrics(k_d, d_d)
    print(f"K_d={k_d:5.0f}  wn={wn:6.1f}rad/s  zeta={z:.3f}  "
          f"超调={mp*100:4.0f}%  t_p={tp*1e3:5.2f}ms  t_s={ts*1e3:6.1f}ms")

# 反推：若要求接触超调≤5%（zeta=0.7），阻尼该给多少？
k_d, m_d, k_env = 500.0, 1.0, 1e5
d_need = 2 * 0.7 * np.sqrt(m_d * (k_d + k_env))
print(f"接触 zeta=0.7 所需阻尼 = {d_need:.1f} N·s/m "
      f"(自由空间临界值仅 {2*np.sqrt(k_d*m_d):.1f})")

解读：这个工具的意义在于把"调参"变成"查表"。输出里两个数最扎眼：ζeff=0.07 与反推出的 440 N·s/m。后者告诉你要在钢件上保持 5% 超调，阻尼得加大约 10 倍，而这么做的代价是自由空间里机器人"像泡在蜂蜜里"。所以代码最后两行实际上是在演示一个负结论：单一参数的方案要么自由空间迟钝、要么接触振荡，两者不可兼得。tp 与 ts 的差（约 10 ms vs 180 ms）也提醒你：视觉上"很快就稳了"的判断可能只是峰值过去，尾部的小幅振荡仍在影响打磨质量。

片段 3：接近速度的减速规划，把冲击控制在预算内

def approach_velocity(dist, v_max=0.05, a_brake=0.05, margin=0.001):
    """按剩余距离给出接近速度：平方根减速律 v = sqrt(2*a*d)。"""
    d = max(dist - margin, 0.0)          # 留 1 mm 安全裕量，不压线接触
    return min(np.sqrt(2.0 * a_brake * d), v_max)

# 冲击预算：F_peak ≈ v_c*sqrt(M_d*K_env)，反推允许的最大接近速度
m_d, k_env = 1.0, 1e5
for f_max in (5.0, 10.0, 20.0):
    print(f"冲击预算 {f_max:4.0f}N → v_c ≤ {f_max/np.sqrt(m_d*k_env):.4f} m/s")

print("剩余距离 vs 减速指令速度：")
for dist in (0.05, 0.02, 0.005, 0.001):
    print(f"  d={dist*1e3:5.1f}mm → v={approach_velocity(dist):.4f} m/s")

解读：平方根减速律来自经典"恒减速停车"关系 v² = 2ad，剩余距离 d 越大允许的速度越高，逼近时自然收敛到零，比"分段定速"平滑得多。与冲击公式联用后，第一段输出把"力预算"翻译成"速度预算"：想把 105 N/m 钢件上的冲击压到 5 N 以内，接近速度必须 ≤ 0.016 m/s，比多数人凭感觉用的 5–10 cm/s 慢得多。第二段输出展示了减速律的形状：50 mm 时全速 50 mm/s，20 mm 降到 44 mm/s，5 mm 时只剩 20 mm/s，最后 1 mm 内随时可停。注意最后一行输出 v=0，裕量内的速度由下游接触控制器接管，这正是导纳/阻抗控制该上场的区间。

常见坑

  • 用自由空间阻尼去解释接触行为：ζ = Dd/(2√(KdMd)) 只在自由空间成立；接触时刚度变成 Kd+Kenv，阻尼比随之缩水。症状："阻尼我都给到临界了还振"。修复：改用 ζeff 公式核算，或接受轨迹平滑方案。
  • Keq 与 Kd 混用：软环境下（Kenv≈500）用 F=KdΔx 预测稳态力，会高估接近 2 倍，力其实由串联刚度 Keq≈250 决定。修复：先估 Kenv，再决定用哪条公式。
  • 忽视接近速度：稳态力完全正常，一接触却触发保护停机，原因全在冲击峰值。症状：力记录里一个孤立尖峰，随后平稳。修复：加平方根减速，或减小 Md（虚拟质量对冲击影响是 √ 关系），或预置接触前减速窗口。
  • 拿控制器 1 kHz 日志量冲击峰值：采样把 50 Hz 振荡中的真实尖峰"抹匀"，日志峰值系统性偏低。修复：冲击标定用外部示波器/更高速采集，或只用日志做相对比较。
  • 为压软物体盲目加大 Kd：软环境里 Fss≈KenvΔx，Kd 加到天上也没用，反而恶化稳定性。修复：正确的手段是加大偏置 Δx 或改用导纳型力闭环（第 019 章）。

  3. 用能量守恒推导冲击峰值公式 Fpeak ≈ vc√(MdKenv)，说明忽略了哪些因素（阻尼做功、虚拟弹簧压缩、环境阻尼），并估计这些忽略带来的误差方向。★★

    接触时间极短（毫秒级），阻尼耗能 ∝ ∫Fẋdt 相对动能是小量；虚拟弹簧也分担一部分压缩能，会略微高估峰值。忽略双方阻尼 → 公式偏保守（高估）。
  4. 设计一个"既不牺牲自由空间手感、又把接触超调压到 5%"的方案：允许 Kd、Dd 在接触前后取不同值。写出切换判据（用哪些测量量）与切换瞬间如何避免力跳变。★★★
    提示
    用 |F| 超阈值判接触；关键是不要直接跳变 D（阻尼跳变会造成加速度跳变），用 10–50 ms 的连续过渡把参数插值过去，之后在第 020 章展开。
  5. 某铝件打磨任务：Kenv=8×104 N/m、Md=1.5 kg、稳态力要求 15 N±1、冲击预算 8 N。请给出 Kd、Δx、接近速度上限 vc，并核算接触 ζeff。若 ζeff<0.3，给出两种把超调压下来的手段。★★★
    提示
    Kd=500 时 Keq≈497，Δx≈30 mm；vc≤8/√(1.5×8e4)≈0.023 m/s；ζeff 若不足，手段一：加大 Dd（按接触 ζ 反推），手段二：轨迹平滑 + 接触前减速，把阶跃激励从源头去掉。

小结

  • 接触闭环 = 机器人虚拟阻抗 + 环境弹簧联立：总刚度是 Kd+Kenv（并联），稳态力由串联刚度 Keq 决定。
  • 三条定量公式：Fss = KeqΔx；ζeff = Dd/(2√(Md(Kd+Kenv)))、Mp = exp(−πζ/√(1−ζ²))；Fpeak ≈ vc√(MdKenv)。
  • 自由空间临界阻尼在刚性环境下会被"稀释"十倍以上；超调的对策是接触专用阻尼或平滑轨迹，二者在单参数方案里不可兼得。
  • 冲击峰值与接近速度成正比：先减速度，再减虚拟质量，最后才动刚度；参数各有管辖范围（Kd 管力、Dd 管振、Md 与 vc 管冲击）。
  • 下一章换到导纳侧：同样三个参数，在"力进位置出"的回路里呈现出的却是位置跟踪的时间特性，响应速度、滞后与漂移如何被 Ma、Da、Ka 决定。
