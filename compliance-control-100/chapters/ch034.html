第二篇 · 参数调节与交互任务

第 034 章：阶跃接触力响应

当力通过"位置偏置 + 导纳弹簧"实现时，接触力阶跃响应的超调由阻尼比 ζ 完全决定。本章推导有效刚度 Kd+Kenv、给出超调公式与阻尼设计规则，并用 26 N 的教训说明"按 Kd 设计的阻尼"为什么会在钢件上失控。

  • 主题：接触瞬态 / 二阶响应 / 超调控制
  • 关键公式：Mdδ̈ + Ddδ̇ + (Kd+Kenv)δ = Kenv(xr−xe) − Fd，Mp = e−πζ/√(1−ζ²)
  • 预计学时：50 分钟
  • 前置章节：第 031 章、第 017 章

学习目标

  • 会把"力参考阶跃"经过导纳弹簧实现时的接触瞬态写成标准二阶系统，指出有效刚度是 Kd+Kenv（含环境刚度在内）。
  • 会推导并使用二阶响应三公式：超调 Mp = e−πζ/√(1−ζ²)、峰值时间 tp = π/ωd、调节时间 ts ≈ 4/(ζωn)。
  • 理解超调的能量解释：接触动能一头撞进"Kd+Kenv"的等效弹簧，只有阻尼在耗散；ζ 小则动能往复倒腾成力尖峰。
  • 会用"按总刚度设计阻尼"的规则 Dd = 2ζ√(Md(Kd+Kenv,max))，并解释为什么这个规则让 Dd 明显大于临界阻尼初值。
  • 能设计并执行阶跃实验：测峰值力、超调百分比、峰值时间、调节时间与稳态力，写进验收表。

背景与动机

接触任务里最危险的时刻永远是"力加上去的那一下"：装配的起始压入、抛光的下刀、压装的贴面，力参考从 0 跳到目标值，系统要在一瞬间从自由状态切换到承力状态。第 031 章的恒力实验已经测过一次阶跃（上升 9 ms、超调约 10%），但那是在"速度型力环"下的温和响应；本章要处理的是另一种常见实现，通过导纳弹簧的位置偏置来施加力（δ = (F−Fd)/Kd 那一支，第 022 章的"纯比例导纳"路线）。这种实现保留了完整的二阶动力学，代价是超调对阻尼比极其敏感，而阻尼比又取决于你并不知道的环境刚度。

不夸张地说：很多"力冲击压坏零件"的事故，根源不在控制器失稳，而在工程师用 Kd=800 N/m 的名义刚度算出"临界阻尼 D=57"，然后把它用在 Kenv=105 N/m 的钢件上，有效阻尼比掉到 0.09，力峰值 26 N。本章把这笔账算清楚。

核心原理

1. 从"力阶跃"到"二阶系统"：有效刚度 Kd+Kenv

回到第 022 章的导纳实现：退让量 δ 满足 Mdδ̈ + Ddδ̇ + Kdδ = Fext − Fd，命令位置 xcmd = xr − δ；环境给出 Fext = Kenv(x − xe)。先取参考与面相齐（xr = xe，纯跟踪情形）并把内环近似为理想跟随（x = xcmd），代入消元：

Mdδ̈ + Ddδ̇ + (Kd + Kenv)·δ = −Fd δ 的"弹簧"由虚拟刚度与环境刚度并联组成：物理上，机器人往前的每一毫米都同时被自己的虚拟弹簧和工件弹簧抵抗

于是阶跃响应完全是标准的二阶：自然频率与阻尼比为

ωn = √((Kd+Kenv)/Md)，　ζ = Dd / (2√(Md(Kd+Kenv))) 接触力 F = −Kenv·δ（xr=xe 时），所以力的超调百分比与 δ 的超调百分比相同

稳态：δss = −Fd/(Kd+Kenv)，对应稳态力 Fss = Fd·Kenv/(Kd+Kenv)。钢件上这个比例是 0.992，误差 0.8% 可以忽略；软环境（Kenv 与 Kd 同量级）就有明显偏差，这是纯比例方案的固有静差，需要第 022 章的积分外环来清零，但本章先聚焦瞬态。

2. 三个公式把瞬态说全

阶跃响应的峰值、时机、收敛速度由 ζ、ωn 支配：

Mp = e−πζ/√(1−ζ²)（超调百分比），　tp = π/ωd，ωd = ωn√(1−ζ²)
ts,2% ≈ 4/(ζωn)

代入钢件工况（Kenv=1×105 N/m、Kd=800、Md=1 kg）：ωn = √(100800) ≈ 317 rad/s（50 Hz）。现在看两种阻尼选的命运：

Dd 的选择ζ超调 Mp15 N 阶跃峰值调节时间
56.6（按 Kd 临界阻尼）0.0975.5%约 26 N≈140 ms
222（折中）0.3531.0%约 19.5 N≈36 ms
444（按总量 ζ=0.7）0.704.6%约 15.6 N≈18 ms
634（按总量临界）1.000%≈15 N≈13 ms

工程直觉：接触超调是"动能没地方去"的结果。力从 0 涨到 15 N，机器人末端获得的等效动能必须被阻尼吃掉；ζ=0.09 意味着 99% 的动能只能在两个弹簧（虚拟 + 环境）之间来回倒腾，第一次倒干净时，压缩量比稳态多 75%，力就冲到 26 N。这也解释了为什么"力阶跃"比"位置阶跃"更险：位置任务超调最多让轨迹过头，力任务超调直接等于"多压 75% 的力"，压装零件当场受伤。

3. 设计规则：按"最硬的总刚度"设计阻尼

从 ζ 公式反解，并取工程目标 ζdesign = 0.7–1.0：

Dd = 2ζdesign·√(Md·(Kd + Kenv,max)) Kenv,max：任务中可能遇到的最硬环境；本例 1×105 N/m → Dd ≈ 620（ζ=1）或 440（ζ=0.7），比"按 Kd"的 57 大一个数量级

这条规则会让机器人在软环境里"阻尼偏大"（显得沉稳），在硬环境里刚好；反过来做（按软环境设计）等于给硬环境准备了一次冲击。工程上还可叠加两条辅助手段：（1）力参考不要真阶跃，用 20–50 ms 的小斜坡代替理想阶跃（等价于给系统加了个低通，峰值立降）；（2）接近速度管理，自由运动撞上工件时的附加冲击力约为 Fimp ≈ v√(MdKenv)，50 mm/s 撞钢件就是约 16 N 的额外脉冲，把接近速度降到 10 mm/s 就能压到 3 N 量级（第 025 章的速度分层在这里兑现第二份收益）。

实现思路与设计

实验设置（1 维接触，20 μs 仿真步长以解析 50 Hz 瞬态，1 kHz 实机等价）：

  1. 被控对象：Kenv = 1×105 N/m（刚性金属接触），xr 与 xe 对齐，初始无力。
  2. 激励：t = 50 ms 时 Fd: 0 → 15 N 理想阶跃（同时做一个 30 ms 斜坡版对照）。
  3. 控制器：Kd=800、Md=1、Dd 四档 {56.6, 222, 444, 634}。
  4. 指标：峰值力、超调百分比（对比稳态 Fss）、峰值时间、调节时间（±2%）、稳态力误差。
  5. 验收：超调 ≤10%、无持续振荡；超调超标时优先检查阻尼规则（先降 Kd 的收益很小）。
测量陷阱：滤波器会把峰值"抹掉"

50 Hz 的力瞬态要求力通道带宽至少 500 Hz；如果你习惯性地把力信号 30 Hz 低通，26 N 的尖峰会被削成 20 N 以下，超调"看起来达标"，实际上零件已经吃过一次冲击。规则：做瞬态指标测量时，滤波带宽 ≥ 10× 瞬态频率（本例 ≥500 Hz）；做控制回路时再降回 30 Hz。同一路信号，两套使用方式。

关键代码与解读

片段 1：二阶接触阶跃的核心动力学

import numpy as np

def step_response(d_d, k_d=800.0, m_d=1.0, k_env=1e5,
                  f_d=15.0, dt=2e-5, T=0.4):
    """x_r=x_e 对齐下的力阶跃响应（理想内环，纯比例导纳）。
    状态只有 delta/delta_dot，力由 F=-k_env*delta 读出。"""
    delta, delta_dot, log = 0.0, 0.0, []
    for i in range(int(T/dt)):
        t = i*dt
        fd_now = f_d if t >= 0.05 else 0.0       # 50ms 时刻阶跃
        # 关键方程：有效刚度 = k_d + k_env（两个弹簧并着推）
        a = (-fd_now - d_d*delta_dot - (k_d + k_env)*delta) / m_d
        delta_dot += a*dt
        delta += delta_dot*dt
        log.append((t, -k_env*delta))            # F = -k_env * delta
    return np.array(log)

解读：整个瞬态由一行加速度方程决定，(k_d + k_env) 这一项就是本章的主角，写代码时如果照抄单自由度阻抗公式而忘了加 Kenv，你会低估 ωn、更严重的是高估 ζ（分母少了一块），算出的"临界阻尼"其实远远不够。-k_env*delta 的负号来自坐标约定（δ 为退让量，退让越多、压入越少、力越小）；仿真步长取 20 μs 是因为 ωn=317 rad/s 对应周期约 20 ms，每周期约 1000 步，保证瞬态形状不失真；改用 1 ms 步长会明显失真。

片段 2：四档阻尼 + 指标提取

def metrics(d_d, k_env=1e5, f_d=15.0):
    L = step_response(d_d, k_env=k_env)
    t, F = L[:, 0], L[:, 1]
    m = t >= 0.05
    f_ss = f_d * k_env / (800.0 + k_env)      # 稳态解析值
    peak = F[m].max()
    over = (peak - f_ss) / f_ss * 100.0
    # 峰值时间、调节时间（末次进入 +-2% 的时刻）
    tp = t[m][np.argmax(F[m])] - 0.05
    band = 0.02 * f_ss
    outside = np.where(np.abs(F[m] - f_ss) > band)[0]
    ts = t[m][outside[-1]+1] - 0.05 if len(outside) else 0.0
    return peak, over, tp, ts, f_ss

print("  D_d    zeta    峰值(N)  超调(%)  峰值(ms)  调节(ms)  稳态(N)")
wn = np.sqrt((800 + 1e5) / 1.0)
for d_d in (56.6, 222.0, 444.0, 634.0):
    peak, over, tp, ts, f_ss = metrics(d_d)
    print(f"{d_d:6.1f}  {d_d/(2*wn):5.2f}   {peak:7.2f}  {over:7.1f}"
          f"  {1000*tp:8.1f}  {1000*ts:8.1f}  {f_ss:6.2f}")

解读：输出与第 2 节的表大体一致，D=56.6 那一行会是"峰值 26.1 N、超调约 75%、峰值时间约 10 ms、调节时间约 130 ms"；D=634 一行是"平凡"的：峰值 14.88 N、超调 ≈0%（单调逼近稳态 14.88 N）。两组数字之间差了整整一个数量级的阻尼，却只是为了保住同一个 15 N。指标提取全部用解析稳态值 f_ss 做基准，避免用被滤波器污染的末拍采样值；"末次离开 ±2% 带"是调节时间的稳健算法，比"首次进入"严谨（防止穿越型假收敛）。

片段 3：用理论公式预测实测，三公式的验证脚本

def verify_formulas():
    wn = np.sqrt((800.0 + 1e5) / 1.0)
    print("  zeta   超调理论(%)  超调实测(%)   峰值时间理论(ms)")
    for d_d in (56.6, 222.0, 444.0):
        z = d_d / (2*wn)
        mp_th = np.exp(-np.pi*z/np.sqrt(1 - z*z)) * 100.0
        tp_th = np.pi / (wn*np.sqrt(1 - z*z))
        _, over, tp, _, _ = metrics(d_d)
        print(f"  {z:5.2f}  {mp_th:10.1f}  {over:10.1f}"
              f"  {1000*tp_th:12.1f}")
    # 附加：斜坡化的"阶跃"能把峰值压多少？
    print("提示：把 0->15N 的理想阶跃换成 30ms 线性斜坡再跑一遍")

verify_formulas()

解读：跑出来理论/实测两列并排：ζ=0.09 → 75.5% / 75.5%；ζ=0.35 → 31.0% / 30.9%；ζ=0.70 → 4.6% / 4.6%。两列的微小差异来自采样与峰值检测（不超过 0.1 个百分点），足以证明"公式可信、可直接用于设计"。这类验证脚本的价值：把"超调公式"从考卷搬进你的验收工具链，设计新工具时，先算 Mp，再决定 Dd 和试件保护力。最后一行提示的"斜坡化阶跃"是生产中的常用技巧：同样的 Dd，把参考阶跃改 30 ms 斜坡，峰值通常再降 30–50%，等于免费的可靠性。

常见坑

  • 用 Kd 算阻尼（忘记 Kenv）：这是本章第一号错误，ζ 被高估 √((Kd+Kenv)/Kd) ≈ 11 倍，实际超调 74%。修复：永远按 Kenv,max 的总刚度设计 Dd。
  • 用低带宽滤波器测峰值：30 Hz 低通把 50 Hz 的尖峰削掉，超调验收"看起来通过"。修复：瞬态测量通道 ≥500 Hz，与控制通道分开。
  • 只在软试件上做验收：软接触 ζ 大、超调小，指标全绿；一上钢件就出事。修复：验收矩阵必须含"最硬工件"一档。
  • 自由空间高速接近后直接力控：附加冲击 Fimp ≈ v√(MdKenv) 没算进峰值预算。修复：接近速度 ≤10 mm/s + 接触检测后 20 ms 再切入力阶跃。
  • 超调超标先降 Kd：降 Kd 对 ζ 的影响很小（Kenv 主导时几乎无效），却让位置偏置变大、稳态力更难保证。修复：先改 Dd 或把参考斜坡化。

练习与思考

  1. 推导本章的有效刚度方程：从 Mdδ̈+Ddδ̇+Kdδ = Fext−Fd 与环境方程出发，消去 x 得到 δ 的二阶方程，说明 Kd+Kenv 的"并联"来源。★
    提示
    x = xr−δ 代入 Fext=Kenv(x−xe)，把 −Kenvδ 移到左边，与 Kdδ 合并。
  2. 取 Kd=500、Md=0.8、Kenv=2×104，分别按"仅 Kd"与"Kd+Kenv"设计 ζ=0.8 的 Dd，算出两个 D 的比值；再算错用后者时实际 ζ 与超调。★★
    提示
    Dd = 2×0.8×√(0.8×20500) ≈ 204；按 Kd 只给 32；错用 32 时 ζ = 32/(2√(0.8×20500)) ≈ 0.125，超调 ~67%。
  3. 推导近似冲击公式 Fimp ≈ v√(MdKenv)（提示：动能 ½Mv² 全部转成弹簧势能 ½Kx² 的瞬时估计），并计算 Md=1、Kenv=1×105、v=0.05 m/s 的值。★★★
    提示
    从 ½Mdv² = ½Kenvx² 得 x = v√(Md/Kenv)，乘 Kenv 即得；数值 ≈ 0.05×√(1e-5)×1e5 = 15.8 N。
  4. 实验：把片段 1 的理想阶跃改成 30 ms 线性斜坡（Fd 从 0 线性升到 15 N），用 ζ=0.09 与 ζ=0.7 两种阻尼各跑一遍，记录峰值。解释"斜坡化"对两种阻尼的帮助为何不同。★★
    提示
    小阻尼时斜坡把动能的注入时间拉长，阻尼来得及耗散，峰值大幅下降；大阻尼时本来就不超调，改善有限。
  5. 设计题：为"钢件压装、目标力 25 N、峰值不得超过 30 N"设计参数组合（Kd、Md、Dd、参考斜坡时间），用本章公式给出理由，并列出你的验收表。★★★
    提示
    超调预算 20% → ζ ≥ 0.45（查公式或表）；Dd = 2ζ√(M(Kd+1e5))；再配 30–50 ms 斜坡与 10 mm/s 接近速度双保险。

小结

  • 经导纳弹簧施加的力阶跃是标准二阶系统，有效刚度 Kd+Kenv，ωn=√((Kd+Kenv)/Md)，ζ=Dd/(2√(Md(Kd+Kenv)))。
  • 三公式给全瞬态：Mp=e−πζ/√(1−ζ²)、tp=π/ωd、ts,2%≈4/(ζωn)；钢件上"按 Kd 设计阻尼"会把 ζ 高估约 11 倍，15 N 阶跃冲成 26 N。
  • 设计规则：Dd = 2ζ√(Md(Kd+Kenv,max))，ζ 取 0.7–1.0；辅以参考斜坡化与低速接近（冲击力 ≈ v√(MdKenv)）。
  • 测量纪律：瞬态通道带宽 ≥500 Hz，稳态基准用解析值；验收矩阵必须覆盖最硬工件。
  • 下一章换到"位置"这一侧：阻抗控制下的位置阶跃响应，自由空间的跟踪精度、接触后的稳态偏移，以及安全位置步长的设计。
