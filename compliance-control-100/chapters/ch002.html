第一篇 · 基础、建模与稳定性

第 002 章：导纳控制基础

如果机器人只有位置接口、却装着力传感器，"测到的力"如何变成"该走的位置"？答案是把力灌进一个虚拟的质量-弹簧-阻尼系统，这就是导纳控制。

  • 主题：导纳控制入门 / 力到位的位置修正
  • 关键公式：Maẍa + Daẋa + Kaxa = Fext，xcmd = xd + xa
  • 预计学时：45 分钟
  • 前置章节：第 001 章

学习目标

  • 理解阻抗与导纳是一对互为倒数的端口描述：一个"由运动算力"，一个"由力算运动"。
  • 会从牛顿第二定律完整推导导纳方程 Maẍa + Daẋa + Kaxa = Fext，并解释每个符号的含义与单位。
  • 掌握位置接口下的关系式换算：虚拟位移 xa 如何叠加到期望轨迹上变成命令位置 xcmd。
  • 理解导纳控制"双击分"的结构为什么会让力传感器偏置变成位置漂移，以及死区、泄漏、标定三项工程对策。
  • 能写出带力滤波、死区、限幅的离散导纳控制循环，并说清每一步为什么这样写。

背景与动机

第 001 章的阻抗控制在软件里解一个方程，然后把结果当成位置命令下发，它默认"运动可以随便造"。但反过来想：如果机器人只有位置接口，你怎么让它"感觉到力"？工业现场 80% 以上的机械臂正是这种情况：控制器只收位置指令，只回编码器数据，外加一只装在腕部的六维力传感器（six-axis force/torque sensor）。

导纳控制（admittance control）就是为这种硬件组合量身定做的：读传感器测到的力，通过一个虚拟的质量-弹簧-阻尼模型算出"应该让位多少"，再把让位量叠加到期望轨迹上发给位置控制器。打磨、装配、拖动示教这些任务里，操作者的关注点从"机器人多准"转向"机器人多软"，这正是导纳控制的舞台。理解它与阻抗控制的方向性区别（谁当输入、谁当输出），是后面所有力控功能的基础。

核心原理

1. 一个交互端口，两种描述：阻抗与导纳

把机器人末端与环境接触的那一点看成一个"单端口"：在这一点上可以观测两个量，速度 v（m/s）和力 F（N），它们是一对功率共轭变量，乘积就是功率交换（W）。描述该端口的动力学特性有两条对称路线：

Z(s) = F(s)/V(s) ：运动输入 → 力输出；A(s) = V(s)/F(s) = 1/Z(s)：力输入 → 运动输出 Z 为阻抗（impedance），A 为导纳（admittance），互为倒数

工程直觉：阻抗控制像一堵"弹簧做的墙"，你先动它，它才出力；导纳控制像一个"听得见力的伺服系统"，你先推它，它测到力再退。方向正好相反：两者的数学关系互为倒数，因此描述"同一种物理柔顺"的信息量相同；区别在于实现时谁当因、谁当果。

为什么这个区别对工程如此关键？因为实现载体不同：阻抗控制常驻在力矩接口上，需要机器人能直接输出关节力矩；导纳控制常驻在位置接口上，需要的是位姿测量、力测量和一条稳定的位置内环。你手上有什么接口，就往哪条路走。

2. 导纳方程的由来：虚拟物体上的力平衡

设立一个想象中的"虚拟物体"：它有质量 Ma（kg），被一根刚度为 Ka（N/m）的弹簧拴在参考点 xd 上，还泡在黏性液体里，阻尼系数 Da（N·s/m）。它的位移相对参考点是 xa = x − xd（m）。现在有外力 Fext（N）作用在它上面，逐项写出受力：

  • 外力：Fext，方向定义为"正号时把末端往坐标正方向推"；
  • 黏性阻力：−Da·ẋa，与速度反向、大小正比于速度，单位换算 N = (N·s/m)·(m/s)；
  • 弹簧回复力：−Ka·xa，与位移反向、大小正比于位移；
  • 惯性：Ma·ẍa，牛顿第二定律。

牛顿第二定律：Maẍa = Fext − Daẋa − Kaxa。移项即得导纳方程：

Maẍa + Daẋa + Kaxa = Fext Ma：虚拟质量（kg）；Da：虚拟阻尼（N·s/m）；Ka：虚拟刚度（N/m）；xa：相对参考的虚拟位移（m）

它的频域形式更说明问题：Xa(s)/Fext(s) = 1/(Mas2 + Das + Ka)。注意分母是二次、分子是常数，计算结构上力先化成加速度、再积分成速度、再积分成位置：常量偏置会形成常驻的位置偏差（Fbias/Ka，Ka 越小越明显），而在 Ka = 0 的纯阻尼结构里，偏置与零均值噪声都会沿这条双重积分链积成漂移（第 029 章）。第 3 节给出的死区与泄漏，就是为此设置的。

3. 稳态关系与参数初值

让方程里所有导数项归零，得到最重要的稳态关系：

Kaxa = Fext ⟹ xa = Fext/Ka 例：Ka = 500 N/m 时，20 N 的推力对应 40 mm 让位

换句话说，导纳控制器里"刚度"决定手感：Ka 越小，同样的力让出越多位置，机器人越软。注意这和第 001 章阻抗控制的稳态公式 F = Kd(xd−x) 是同一回事，只是现在把 F 当输入、x 当输出。

参数初值沿用同一套直觉：刚度量级取平移 200–1000 N/m（对 Kenv ≈ 105 N/m 的刚性工件约 1/100–1/500，足够安全）；阻尼用临界阻尼公式 Da = 2√(KaMa) 起步，再按实测微调；质量取 1–5 kg，太小会把力噪声放大成抖动，太大反应迟钝。阻尼比 ζ = Da/(2√(KaMa)) 建议 0.8–1.0：低于 0.5 时松手后会来回晃。

4. 从虚拟位移到命令位置：位置接口的关系式换算

导纳方程解出来的 xa 是"虚拟物体该偏移多少"，而位置接口能接受的只有一条任务轨迹。两者的换算关系是本章的核心等式：

xcmd(t) = xd(t) + xa(t)，其中 Maẍa + Daẋa + Kaxa = Fext

只要内环位置控制器跟踪 xcmd 足够快（带宽至少是导纳自然频率 ωa = √(Ka/Ma) 的 5 倍以上），实际末端位置 x ≈ xcmd，虚拟导纳就被真实复现了。离散化时把方程解出加速度再积分：

ak = [ Fk − Davk − Kaxa,k ] / Ma；vk+1 = vk + akΔt；xa,k+1 = xa,k + vk+1Δt 半隐式欧拉（速度先用新值再积分位置），比显式欧拉更稳定

为什么先更新速度再更新位置？显式欧拉相当于用旧速度外推，虚拟系统的"能量"会随步数缓慢增长，遇到硬接触时容易发散；半隐式（也叫辛欧拉）对弹簧-阻尼系统是能量有界的，1 ms 周期下绰绰有余。推导中的符号约定尤其要先想清楚：本章约定 Fext 为"作用在机器人上的外力"，正方向沿着它推动末端的方向；接触挤压时，墙的反力与插入方向相反，故测到的 Fext 为负、xa 为负（机器人往后退）。第 001 章写成 −Fext，是因为那里把 Fext 定义成了环境反力的幅值；两种写法只差一个符号定义，代码里写反就是正反馈发散。

实现思路与设计

按信号流把控制器拆成四步，每一步都对应一个必须回答的工程问题：

  1. 力获取与预处理：六维力传感器读数先减去静态偏置（上电空载平均 0.5–1 s），投影到控制轴得到标量 F，再过一阶低通（截止 30–80 Hz）。不去偏置，常值力会在二次积分下把位置推偏；不滤波，0.1 N 级噪声会被 Ma 放大成高频抖动。
  2. 解导纳方程：按上面公式算 ak、vk+1、xa,k+1。控制周期取 1 ms，力环的等效带宽只有几赫兹，1 kHz 采样留出上百倍裕度，为滤波和计算延迟兜底。
  3. 漂移防护三件套：力死区（|F| < 0.3 N 视为 0，盖住噪声底）、位置泄漏（每拍把 xa 往零拉一点，时间常数 2–5 s，抵消残余偏置）、xa 限幅（如 ±50 mm，异常力时不产生大位移）。
  4. 叠加与下发：xcmd = xd + xa，再做速度与位置安全检查后交给内环位置控制器。
设计决策：为什么力死区取 0.3 N，泄漏时间常数取 2 s？

典型六维力传感器的噪声底约 0.1 N（标准差），死区取 3 倍标准差能挡住 99% 以上的噪声，同时保留 1 N 以上真实接触力的分辨率，装配任务需要的力通常 ≥ 5 N，0.3 N 门限不会造成可感知的力偏差。泄漏时间常数则要在"抵消偏置"和"不干扰慢速操作"之间折中：2 s 意味着 2 s 内的持续小力仍会被完整响应，而分钟级的偏置漂移会被慢慢抹掉。若任务需要长时间维持 1 N 以下的微力（如触觉探索），应改为在线偏置跟踪，简单加大泄漏会把真实微力一起抹掉。

内环跟踪带宽是隐形的质量瓶颈：导纳自然频率 ωa = √(Ka/Ma)，Ka=500、Ma=2 时约 15.8 rad/s ≈ 2.5 Hz，内环带宽有 20 Hz 以上就够了；但如果你把 Ka 提到 5000 N/m 追求更清晰的力感，ωa ≈ 50 rad/s ≈ 8 Hz，内环、力滤波、通信延迟任何一环跟不上，虚拟导纳都会"失真"，严重的会振荡。

关键代码与解读

片段 1：力预处理，偏置标定、投影与滤波

import numpy as np

class ForcePreprocessor:
    """把六维力传感器读数变成干净的标量接触力（沿控制轴，单位 N）。"""
    def __init__(self, axis, tau_f=0.005, n_calib=500, dt=1e-3):
        self.axis = np.asarray(axis, float)   # 控制轴（工具坐标系单位向量）
        self.alpha = dt / (tau_f + dt)        # 一阶低通系数：tau_f 越大越平滑
        self.n, self.n_calib = 0, n_calib     # 标定计数：前 n_calib 拍算偏置
        self.bias = np.zeros(6)               # 六维静态偏置（含工具重力残余）
        self.f_f = 0.0                        # 滤波后的力，跨拍保持

    def update(self, f_raw):
        # 上电后前段假设"空载静止"，用增量平均求偏置：比单次采样抗噪
        if self.n < self.n_calib:
            self.n += 1
            self.bias += (f_raw - self.bias) / self.n
            return 0.0                        # 标定期间不输出力，防止误动作
        f = float(np.dot(f_raw - self.bias, self.axis))   # 投影成标量
        # 这里选一阶低通的理由：低通相位滞后可算（atan(w*tau)），
        # 便于在稳定性分析里折算成延迟；均值滤波的群延迟不直观
        self.f_f += self.alpha * (f - self.f_f)
        return self.f_f

解读：这段代码的关键决策有三个。增量平均求偏置（bias += (f_raw - bias)/n）只需 O(1) 内存，且天然给早期样本和近期样本相同权重，标定期只有 0.5 s，不需要遗忘因子。标定期间返回 0 很重要：否则上电瞬间的偏置会被导纳控制当成真力，产生一次无意义的让位。投影用点积（取固定 z 分量会失效）：工具姿态改变时控制轴在世界系中的方向会变，必须用当前姿态把偏差旋转后再投影，这一步在真机上由外层的坐标变换完成，此处只留接口。

片段 2：导纳控制器，死区、泄漏、限幅

class AdmittanceController:
    """单自由度导纳控制器：力 → 虚拟位移 x_a → 命令位置 x_d + x_a。"""
    def __init__(self, m_a=2.0, k_a=500.0, d_a=None, dt=1e-3,
                 f_dead=0.3, leak_tau=2.0, x_lim=0.05):
        self.m_a, self.k_a = m_a, k_a
        # 未指定阻尼则取临界阻尼：先保证松手后不振荡，再按手感微调
        self.d_a = d_a if d_a is not None else 2.0 * np.sqrt(k_a * m_a)
        self.dt, self.f_dead = dt, f_dead
        self.leak = dt / leak_tau        # 每拍泄漏比例：1/2000 很轻微但持续
        self.x_lim = x_lim
        self.x_a, self.v_a = 0.0, 0.0    # 虚拟位移与虚拟速度，跨拍积分状态

    def step(self, f_ext, x_d):
        # 死区：|F| 小于噪声底就当作零，否则 0.1N 级噪声经二次积分会漂移
        f = f_ext if abs(f_ext) > self.f_dead else 0.0
        # 导纳方程解出加速度：这就是"M ẍ = F - D ẋ - K x"的逐项计算
        a = (f - self.d_a * self.v_a - self.k_a * self.x_a) / self.m_a
        self.v_a += a * self.dt                    # 半隐式欧拉：先更新速度
        # 泄漏项把 x_a 缓慢拉回零：对抗偏置残余与温漂，不改变快变响应
        self.x_a += self.v_a * self.dt - self.leak * self.x_a
        self.x_a = float(np.clip(self.x_a, -self.x_lim, self.x_lim))
        if abs(self.x_a) >= self.x_lim:
            self.v_a = 0.0      # 限幅处清零速度，避免"顶着限幅攒劲"后突然弹开
        return x_d + self.x_a                      # 位置接口的真正命令

解读：死区放在最前面（放在积分之后过滤的写法，噪声照样进积分器）。泄漏项− leak·x_a 在数学上等价于在弹簧上并联一个"刚度 tiny 的额外弹簧"：它把纯积分变成有界，这是工程上处理传感器偏置最廉价的手段；代价是对超低频外力响应被削弱（时间常数内的慢力仍响应，分钟级漂移被吃掉）。限幅处清速度是本片段里最容易被忽略的细节：若不清零，x_a 被夹在边界时加速度仍在积累速度，一旦外力反向，机器人会先"冲"出限幅区再反向，表现为突然的窜动。np.clip 后接 float() 是习惯动作，保证状态是标量（避免 0 维数组），方便后续类型检查。

片段 3：1 kHz 主循环，压住 5 N 接触力的完整例子

k_env, xe = 1e5, 0.05        # 环境刚度 1e5 N/m，表面在 x=50 mm 处
pre = ForcePreprocessor(axis=[0, 0, 1])   # 沿 z 轴控制（单位向量）
adm = AdmittanceController(k_a=500.0)
x = 0.0                      # 末端真实位置（真机上来自编码器/正运动学）

for i in range(2500):        # 2.5 s 循环，1 ms 周期
    f_raw = np.zeros(6)      # 教学简化：只有沿 z 的接触力，其余分量为零
    # 环境模型：越界才有反力，且反力方向与插入方向相反（牛顿第三定律）
    f_raw[2] = -k_env * (x - xe) if x > xe else 0.0
    f = pre.update(f_raw)
    # 前 1 s 让传感器完成标定、机器人停在原地；之后把参考推入墙内 10 mm
    x_d = 0.0 if i < 1000 else 0.06
    x_cmd = adm.step(f, x_d)
    # 内环位置环的粗略模型：每拍向命令位置追赶 30%（等效时间常数 ~3 ms）
    x += (x_cmd - x) * 0.3
    if i % 250 == 0:
        print(f"t={i*1e-3:4.1f}s x={x*1e3:6.2f}mm "
              f"x_a={adm.x_a*1e3:6.2f}mm F={f:6.2f}N")
# 稳态预测：F = K_a·x_a 与接触方程联立 → F ≈ -K_a(x_d-xe)/(1+K_a/k_env)
#              ≈ -500×0.01/(1+0.005) ≈ -4.98 N（负号=压向墙面）

解读：这段仿真把三个机制放在一起检验。标定期（前 1 s）x_d 保持 0，机器人不动、力为零、偏置被平均为零，真机上也应该这样设计开机流程：先静置标定，再进入力控。推入墙内后，测到的 F 为负（墙面反力与插入方向相反），导纳方程把它翻译成负的 x_a：虚拟位移向后让，x_cmd 停在墙前某处，被内环追上后达到平衡。稳态值约 −4.98 N，由 Ka、x_d 与 Kenv 联立决定，注意它几乎只由虚拟刚度与参考偏置决定（因 k_env 远大于 Ka），这与你第 001 章算出的 5 N 完全一致。x_a 的波形补充了一个直觉：它的响应会先冲过头，再被阻尼慢慢拉回，与理想阶跃的形态不同，欠阻尼明显的参数会看到 x_a 来回振荡，这正是参数 ζ 的可见效果。

常见坑

  • 力传感器偏置与温漂：症状是空载时 xa 以毫米级慢慢漂移，任务中途机器人自己"让位"。修复：上电静置标定 + 泄漏 + 死区三件套；高精度场景改为每隔几分钟在"确认无接触"窗口内重新标定一次。
  • 力滤波过度：把截止频率压到 5 Hz 以下图安静，结果接触瞬间的相位滞后足以让刚度环自激，出现 10–30 Hz 的持续嗡嗡声。经验：滤波时间常数不超过控制周期的 10 倍（1 ms 周期对应 ≤ 10 ms）。
  • 符号与坐标系写错：传感器坐标系随腕部姿态旋转，如果不做姿态旋转直接取原始分量，工具一转"受力方向"就变了。症状是某些姿态正常、某些姿态发散。修复：始终把力旋到控制坐标系再投影。
  • 忘记工具重力：5 kg 打磨工具的重力约 49 N，若不扣除，机器人会带着约 49/Ka 的固定让位工作（Ka=500 时近 10 cm），直接顶到限幅。修复：按当前姿态精确扣除工具重力，或把重力项并入标定偏置（仅当姿态变化小时可行）。
  • 把 xa 直接当绝对位置：xa 是相对参考的修正量，参考 xd 还要随时间规划。把两者弄混会让轨迹跟踪被"力修正"整段吃掉，表现为一旦接触就再也不会执行前进指令。修复：代码里分开两个变量，永远只在下发前一刻相加。

    三项都应是力的单位 N：kg·(m/s²)、(N·s/m)·(m/s)、 (N/m)·m。弹簧项与阻尼项的符号来自"回复/耗散"的物理含义。
  2. 把片段 3 中 Ka 分别改成 100、500、2000 N/m，先预测稳态接触力与 xa，再跑仿真验证。哪个设置下机器人最"敏感"？★★
    提示
    稳态力近似 F ≈ −Ka(xd−xe)/(1+Ka/kenv)，刚度越大压得越"较真"；Ka 大时 xa 也大，检查是否触发限幅。
  3. 去掉代码中的死区与泄漏，在力信号上叠加 std=0.1 N 的零均值噪声，观察 10 s 内 xa 的变化；再把 Ka 调成 0 对比。解释为什么 Ka>0 时噪声只造成有界抖动，而 Ka=0 时零均值噪声会积成无界漂移。★★
    提示
    噪声先被 M 除成加速度再积分。Ka>0 时弹簧把结果约束成有界抖动（方差 ∝ σ²/(DaKa)，不随时间增长）；Ka=0 时位置是速度的积分，白噪声经这条积分链成为随机游走（维纳过程），位移方差随时间线性增长、无界。
  4. 推导接触稳态的精确解：环境 Fext = −Kenv(x − xe)，控制器平衡 Kaxa = Fext，x = xd + xa，联立证明 Fext = −Keq(xd − xe)，其中等效刚度 Keq = KaKenv/(Ka+Kenv)，并解释为什么 Kenv → ∞ 时力趋于 −Ka(xd − xe)。★★★
    提示
    消去 x：xd − xe = xa − (x − xe)，而 xa=F/Ka、x−xe = −F/Kenv，得到串联弹簧公式 F(1/Ka + 1/Kenv) = −(xd−xe)。
  5. 设计一个小实验区分"力死区造成的稳态力偏差"和"传感器偏置造成的漂移"：只给机器人看 10 s 的力-位移记录，你如何判断问题出在哪一环？写出你的判据。★★★
    提示
    死区表现为"施加 0.2 N 的力没有位移，0.5 N 才有"，是静态输入输出关系；偏置漂移表现为"无输入、位置仍缓慢移动"，是时间轴上的趋势。分别用阶跃力实验和空载静置实验隔离。

小结

  • 阻抗与导纳是交互端口的两种因果描述，互为倒数：阻抗"运动进、力出"，导纳"力进、运动出"。
  • 导纳方程 Maẍa + Daẋa + Kaxa = Fext 来自虚拟物体的牛顿第二定律；传递函数含两个积分，因此对力偏置与噪声天生敏感。
  • 位置接口下的换算关系是 xcmd = xd + xa；内环带宽至少为导纳自然频率的 5 倍，虚拟导纳才不失真。
  • 工程三件套：死区（0.3 N 量级）、泄漏（时间常数 2–5 s）、限幅（±50 mm 量级）；参数初值 Ka 200–1000 N/m、Da = 2√(KaMa)、Ma 1–5 kg。
  • 下一章把镜头对准参数本身：Ka、Da、Ma 各自会把接触力曲线改造成什么样，以及冲击峰值、稳态值、稳定性的定量关系。
