第一篇 · 基础、建模与稳定性

第 020 章：变阻抗控制

接近要硬、接触要软、撤离要快回中，单一参数组满足不了多阶段任务。变阻抗让 M、D、K 随状态调度，但"变"本身是一笔能量账：快降慢升、按罐支取，是本章的两条铁律。

  • 主题：阻抗控制 / 参数调度与能量安全
  • 关键公式：dE/dt = δ̇F − Dδ̇² + ½Ṁδ̇² + ½K̇δ²；能量罐守卫
  • 预计学时：60 分钟
  • 前置章节：第 019 章

学习目标

  • 理解变阻抗的动机：从第 003/005/016 章的分歧中归纳出"多阶段任务需要多组参数"这一结构性事实。
  • 会推导时变参数下的能量演化方程 dE/dt，解释增加刚度/质量注入能量、减小则释放能量。
  • 掌握两条安全律："快降慢升"与"能量罐支取"；会给变化速率与每步能量预算设数。
  • 会设计三态调度表（接近/接触/撤离）并用平滑过渡 + 状态机实现，避免切换冲击。
  • 能辨析变阻抗、自适应（第 019 章）与参数自整定（第 021 章）的分工与边界。

背景与动机

回顾前几章埋下的冲突：自由空间的跟手活性希望阻尼小（第 004 章），刚性接触的稳定需要阻尼是自由空间值的 3–7 倍（第 015 章）；接近段的精度希望刚度大（快、准），接触段的超调与安全希望刚度小、阻尼重（第 003 章）。三组诉求指向三个方向，任何一组固定参数都只能偏袒一边。

变阻抗控制（variable impedance control）的答案是：让参数成为时间的函数，由任务阶段、接触状态与安全条件调度。它并未引入新的控制器，只是给同一个阻抗/导纳外壳换上"会换挡的变速箱"。代价是调度必须付一笔能量账：参数变化本身会注入或吸收虚拟能量，处理不好，一套原本稳定的参数会因"变"而失稳。本章先算清这笔账，再给出可落地的调度架构。

核心原理

1. 时变参数的能量账：dE/dt 的推导

取虚拟系统（一维，δ 为相对参考的偏差）的"储能" E = ½Mδ̇² + ½Kδ²（动能 + 弹性势能），让 M=M(t)、K=K(t) 随时间变化。对 E 求导：

dE/dt = Mδ̇δ̈ + ½Ṁδ̇² + Kδδ̇ + ½K̇δ² 前两项来自动能，后两项来自势能；Ṁ、K̇ 为参数变化率

代入阻抗方程 Mδ̈ = F − Dδ̇ − Kδ（F 为外力，D 也可时变，其对能量的贡献始终是 −Dδ̇²），整理得：

dE/dt = δ̇·F（外部输入的功率） − Dδ̇²（阻尼耗散） + ½Ṁδ̇² + ½K̇δ²（参数变化注入/吸收） 单位全部是 W（瓦）；关键在最后两项的符号完全取决于 Ṁ、K̇

这张账本给出全部设计规则：（1）减小参数（Ṁ<0、K̇<0）只会从储能里"抽走"能量，永远安全，可以快；（2）增大参数按 ½K̇δ² 的速率注入能量，δ≠0 时的刚度阶跃相当于给系统打了一枪，能量 ½ΔKδ² 瞬间入账；（3）阻尼只出现在耗散项，增大阻尼永远安全，减小阻尼只是变弱了耗散通道，不会直接注入能量。最危险的操作因此被精确定位：在偏差较大的时刻快速增大刚度或质量。数字感：δ=6 mm 时把 K 从 300 阶跃到 1500（ΔK=1200），注入能量 ½×1200×36×10−6≈0.022 J，对一个 M=1 kg 的虚拟质量，等价于 0.21 m/s 的速度跳变；这一跳变正是接触瞬间"弹一下"的物理来源。

2. 两条安全律：快降慢升与能量罐

律一：快降慢升。减小刚度/阻尼的过渡可以快（它只抽能），增大必须限速。工程上给两个数：参数变化率上界（如 K̇ ≤ 2000 N/(m·s)、Ḋ ≤ 300 N/(m·s)）与每步能量预算（如每拍 ½ΔKδ² ≤ 1 mJ）。前者保证过渡时间（1200 的刚度变化至少 0.6 s），后者保证"位移大时自动变慢"，同一套速率限制，在 δ=1 mm 和 δ=20 mm 时给出的安全节奏不同，能量预算把这件事自动对齐。

律二：能量罐支取。把"阻尼耗散掉的能量"存进一个虚拟罐子（上限如 0.05 J），任何参数增大的能量需求都从罐里扣；罐空则冻结增大（保持当前值，等待耗散攒能量）。这是无源性（passivity）思想的工程化最小实现：只花"自己挣来的"能量，系统就不会被参数调度推向发散。完整定理与扩展（能量整形、罐的连续形式）在第 058 章展开，本章先用它做刚度上调的守门人。

工程直觉：变阻抗像给机器人换挡，降挡（变软/变轻）随时可以，升挡（变硬/变重）必须先踩离合等转速匹配；能量罐就是那只离合器，转速匹配的指标就是"这次上调要花多少能量、罐里还剩多少"。

3. 调度信号：用什么决定"挡位"

  • 任务阶段（时间/流程）：接近段、接触段、作业段、撤离段，最常用也最可靠，由上层任务状态机给出。典型三态表见下。
  • 接触状态（力/速度）：|F| 超阈值判接触；碰跳检测（第 017 章）触发"接触相阻尼"。这是第 015 章稳定性的自动补救。
  • 力误差与安全事件：力误差超限立即大幅降刚度（"快降"）保证安全，这就是第 021 章的前奏，但注意本章只做"调度"，不涉及增益自整定。
  • 人机距离/人机力：检测到人的接触力时切到极软参数（人机协作场景，第 043/044 章展开）。

三态参数表的例子（Md=1 kg 固定）：

实现思路与设计

变阻抗的最小可信实现（状态机 + 速率限制 + 能量罐，三件套）：

  1. 状态机：定义 3–4 个阶段（approach / contact / work / retreat），转移条件用"力阈值 + 速度 + 超时"组合；转移只改变"目标参数"，不改控制器结构。
  2. 目标到生效：每拍把当前参数向目标值靠拢，速率受限；刚度/质量上调再过能量罐检查（阻尼上调免检）。
  3. 能量记账：每拍计算耗散 Ed=Dδ̇²Δt 存入罐（上限封顶），刚度/质量上调按 ½ΔKδ² 支取；维护一个"最近 10 s 注入/耗散比"的诊断量。
  4. 验参：阶跃式调度 vs 速率受限调度的对比试验（看速度/力曲线的"台阶"）；刚性环境上的调度试验（确认接触相参数按预期生效）。
设计决策：为什么"撤离相"的刚度取中间值，不直接回到接近相的 1500？

撤离瞬间通常还残留小的接触力与形变，直接跳到 1500 属于"δ 未归零时大幅升 K"，正是能量账里最危险的组合。中间值 500 让"离开-回中"这段绝大多数时间有充足裕度，同时避免了大刚度顶着一层薄接触去"挣开"工件（这会造成卸载冲击）。若你的任务要求撤离定位精度，正确做法是先以中间刚度退到自由空间、确认力归零，再升到高刚度去走后续轨迹，把"升挡"安排在 δ≈0 的时刻，能量代价自然趋零，这是整套规则里最划算的一个习惯。

关键代码与解读

片段 1：带速率限制与能量记账的调度器

import numpy as np

class VariableImpedance:
    """三态变阻抗：目标参数由阶段给出，生效参数受速率与能量双约束。"""
    def __init__(self, m=1.0, dt=1e-3, k_rate=2000.0, d_rate=300.0):
        self.m, self.dt = m, dt
        self.k_rate, self.d_rate = k_rate, d_rate     # 参数变化率上界
        self.k, self.d = 500.0, 2.0 * np.sqrt(500.0 * m)
        self.e_inject = 0.0                           # 累计注入能量（J）
        self.e_diss = 0.0                             # 累计耗散（J）：罐的进项

    def target(self, phase):
        if phase == "approach":                       # 接近：硬且准
            return 1500.0, 2.0*np.sqrt(1500.0*self.m)
        if phase == "contact":                        # 接触：软且重阻尼
            # 阻尼按接触回路 ζ_eff≈2.4 反推（中等刚度环境 K_env≈1 kN/m）
            return 300.0, 2.0*2.4*np.sqrt((300.0 + 950.0)*self.m)
        return 500.0, 2.0*np.sqrt(500.0*self.m)       # 撤离：中间值

    def step(self, phase, delta, ddot):
        k_t, d_t = self.target(phase)
        dk = float(np.clip(k_t - self.k, -self.k_rate*self.dt, self.k_rate*self.dt))
        dd = float(np.clip(d_t - self.d, -self.d_rate*self.dt, self.d_rate*self.dt))
        ek = 0.5 * dk * delta * delta                 # 刚度增量携带的能量
        if ek > 0.0 and ek > self.e_diss - self.e_inject:
            # 能量罐不足：按余量截断本次刚度增量（罐空则原地不动）
            room = max(self.e_diss - self.e_inject, 0.0)
            dk = float(np.clip(room / max(0.5*delta*delta, 1e-12),
                               -self.k_rate*self.dt, self.k_rate*self.dt))
            ek = 0.5 * dk * delta * delta
        self.e_inject += max(ek, 0.0)
        self.e_diss += self.d * ddot*ddot * self.dt   # 当前阻尼的耗散入账
        self.k += dk
        self.d += dd
        return self.k, self.d

# 演示：接近相（自由空间，δ=1mm）升到 1500 挡；
# 0.8 s 后切换接触相（形变 δ=6mm），从 1500 降挡到 300，观察过渡节奏
sched = VariableImpedance()
for i in range(1600):
    contact = i >= 800
    k, d = sched.step("contact" if contact else "approach",
                      0.006 if contact else 0.001, 0.01)
    if i == 800:
        k1 = k                                    # 切换瞬间刚度（供打印）
print(f"切换时 K={k1:6.1f} → 结束 K={k:6.1f}（降挡 0.6 s 到位，目标 300）")
print(f"注入能量合计={sched.e_inject*1e3:.3f} mJ，耗散={sched.e_diss*1e3:.2f} mJ")

解读：调度器的骨架只有二十来行，但每行都对应一条设计规则。速率 clip 的方向不对称：这里为简洁用了对称限速，工程实现里应把负向限速放宽 3–5 倍（降 K 只抽能量，越快越安全）。能量罐的两行：e_diss 每拍以 Dδ̇²Δt 充能、e_inject 按 ½ΔKδ² 支取，罐余量不足时先截断本拍增量再入账，顺序很重要，先支取后入账会算错稳态。演示里接近相在 δ=1 mm 的小偏差下用约 0.5 s 升到 1500（注入仅 0.5 mJ），0.8 s 后切接触相、把 K 从 1498 降到 300 是"降挡"，降挡段注入为零、0.6 s 到位；真正危险的升挡示范在片段 2。最后看诊断输出：整个 1.6 s 演示里累计耗散约 18 mJ，而注入总共只有 0.5 mJ，这就是能量罐的现实尺度：进项薄，所以大幅升刚度必须趁 δ 小时做、或分几步走边耗散边升。

片段 2：阶跃切换 vs 速率受限，能量注入的可见后果

def sim_switch(mode, dt=1e-3, t_end=1.6):
    """δ 从 6mm 平衡态开始（外载恒为 1.8N），0.8s 时把 K 从 300 提到 1500。"""
    m_d = 1.0
    k, d = 300.0, 2.0*np.sqrt(300.0*m_d)
    f_ext = 300.0 * 0.006                    # 1.8 N 常力：δ=6mm 处恰为平衡
    delta, ddot, log = 0.006, 0.0, []       # 初始偏差 6mm（模拟接触形变）
    for i in range(int(t_end/dt)):
        if mode == "step" and i == 800:
            k = 1500.0                       # 阶跃：危险动作（对照用）
        elif mode == "ramp" and i >= 800:
            k = min(k + 2000.0*dt, 1500.0)   # 限速升挡：0.6s 到位
        a = (f_ext - d*ddot - k*delta) / m_d # 常载 + 参数变化：唯一激励源
        ddot += a*dt
        delta += ddot*dt
        log.append((delta, ddot))
    log = np.array(log)
    peak_v = np.abs(log[800:1200, 1]).max()  # 切换后 0.4 s 内的速度峰值
    return peak_v

for mode in ("step", "ramp"):
    v = sim_switch(mode)
    print(f"{'阶跃' if mode=='step' else '限速'}: 切换后速度峰值 = {v*1000:6.1f} mm/s")

解读：这个对照实验把能量账"翻译"成可以看见的运动。场景是"压着 1.8 N 接触力、K=300 处于 6 mm 形变的平衡态"，切换前后的稳态都合法（新平衡落在 δ=1.2 mm），差异全在过渡路径：阶跃模式在切换拍注入 ½×1200×36×10−6≈0.0216 J，折成纯动能的等价速度跳变是 √(2×0.0216/1)≈0.21 m/s；仿真里阻尼与随后的势能再分配吃掉一部分，切换后速度峰值仍有约 107 mm/s。限速模式用 0.6 s 把刚度平摊上去，能量边注入边被跟踪运动消化，速度峰值只有约 21 mm/s，平顺得像"手动拧上去的"。五倍左右的差距，就是"快降慢升"最直观的证据。把这段实验放进调试习惯里：任何"换挡"逻辑上线前先跑这个 1.6 秒的仿真，把峰值速度与预算对照（比如不超过工作速度的 20%）。另外注意代码里的仿真只留下"常力 + 参数变化"两个激励源，任何运动都只能归因于切换与平衡点迁移，诊断的纯度最高。真机上复现时用同样的思路：把工件置空、让机器人在接触位置模拟形变，观察换挡瞬间的末端速度尖峰。

片段 3：能量罐守卫，罐空时自动"挂起"升挡

def guarded_k_raise(k_old, k_cmd, delta, tank, cap=0.05):
    """能量罐守卫：升 K 的能量需求超过罐余量时，按余量截断。
    tank 由调用方维护：耗散时增加（封顶 cap），支取时减少。"""
    need = 0.5 * max(k_cmd - k_old, 0.0) * delta * delta
    if need <= tank:
        return k_cmd, tank - need             # 罐够：照单放行并扣款
    room = tank / max(0.5*delta*delta, 1e-12)  # 罐里只够这么多刚度增量
    k_allowed = k_old + min(max(k_cmd - k_old, 0.0), room)
    return k_allowed, 0.0                     # 罐清零：等耗散重新攒

# 演示：初始罐 0.01 J，想在 δ=6mm 处把 K 升 1200 N/m
k_new, tank_left = guarded_k_raise(300.0, 1500.0, 0.006, 0.01)
print(f"请求 K=1500 → 实际放行 K={k_new:.0f}（受罐余量限制），罐余={tank_left:.4f} J")
# 若 δ 只有 1mm（升挡时机好），同样的罐可放行多少？
k_new2, _ = guarded_k_raise(300.0, 1500.0, 0.001, 0.01)
print(f"若 δ=1mm：放行 K={k_new2:.0f}")

解读：两个演示结果是本章最值得带回项目的一句话。δ=6 mm 时，0.01 J 的罐余只放行约 300+555≈855 的刚度（公式：0.01/(0.5×36e−6)≈555），距离 1500 还差得远，守卫自动把"一次大胆升挡"拆成"等耗散、分几步升"的节奏；δ=1 mm 时同样的罐余可以一口气放行全部 1200 的增量（需求仅 0.0006 J），同样的能量预算，在偏差小时是"富余"、偏差大时是"贫困"，这正是"把升挡安排在 δ≈0 时刻"从口号变成数学的原因。调用侧的责任是把耗散入账做对：tank = min(tank + D*ddot**2*dt, cap)，D 用当前生效阻尼。诊断建议：记录"债率"= 过去 10 s 的注入/耗散比，健康系统应远小于 1；若长期接近 1，说明你的调度过于激进或耗散通道（阻尼）太小，先把接触相阻尼设计好，再谈调度速度。

常见坑

  • 在 δ≠0 时阶跃升刚度：最经典的"变阻抗事故"，表现为换挡瞬间的"弹跳"与力尖峰。修复：速率限制 + 能量罐双保险，并把升挡安排在偏差归零时刻。
  • 把降挡也限速得很慢：降挡（软化/变轻）只抽能量，越快越安全；采集中限速让安全响应（急停、柔化）变迟钝。修复：负向速率放宽 3–5 倍，安全事件触发时甚至可以瞬时降。
  • 忘记给 Φ 值检查的"挡位定义"：调度表里两个阶段目标相近却来回切换（抖挡），参数在目标附近反复横跳。修复：状态机加滞环与最小驻留时间（如 200 ms）。
  • 能量罐封顶太小/太大：太小则升挡永远被卡（性能退化）；太大则失去守卫意义。修复：按"允许的最大单次升挡能量"设 cap，例如想让 5 mm 偏差下允许一次 800 N/m 的升幅，cap=½×800×25e-6=0.01 J。
  • 调度回路与自适应回路带宽同阶：019/020/021 三个回路互相激励，出现分钟级振荡。修复：时间尺度分离（快慢至少差 3–5 倍），联调时逐个投用。

练习与思考

  1. 推导 dE/dt 的能量方程，指出哪一项对应"参数输入功率"，并说明为什么"减小刚度"永远不注入能量。★
    提示
    dE/dt = δ̇F − Dδ̇² + ½Ṁδ̇² + ½K̇δ²；K̇<0 时最后一项为负（抽能），Ṁ<0 同理。
  2. 用片段 2 把限速从 2000 改到 500、8000 N/(m·s)，记录速度峰值，找出"峰值 ≤ 50 mm/s"对应的限速上限，并与能量式预测对照。★★
    提示
    限速越大、单位时间注入越多，峰值越高：本例 2000 档约 21 mm/s、4000 档约 33 mm/s；"峰值 ≤ 50 mm/s"对应限速约 7000–8000 N/(m·s)，再快就进入"换挡弹跳"区间。
  3. 为"抛光→抬起→换区→再压下"的循环设计四态调度表（给 K、D 数值与时序），标明每个转换的升/降方向，并解释哪一个转换最需要能量罐保护。★★
    提示
    最危险的是"抬起后刚脱离接触再回到软参数"，看似在降挡，但如果定义反了（把工作相设为低 K、接近相设为高 K），从工作相切换到接近相时可能带残余 δ 升 K；检查每个转换的 ΔK 符号与当时的 δ。
  4. 证明：若调度保证"任意时刻注入功率 ≤ 耗散功率"（dE_inject/dt ≤ Dδ̇²），则虚拟系统总能量不会因参数变化而增加。说明这个条件比"快降慢升"更严格还是更宽松。★★★
    提示
    在含外力的一般情形，只要参数项非正，E 的演化与"参数冻结"的系统相同或更耗散；逐点比较两个条件：功率条件允许刚度上升，只是必须小于阻尼耗散，比一律降速更宽松、也更难实现（需要实时判断）。
  5. 设计一体化案例：变阻抗（本章）负责"接近硬、接触软"，自适应（019）负责"未知环境力跟踪"，自整定（021）负责"接触相刚度的微调"。画出三者信号流（谁改谁），写出各自带宽，并指出两个必须加的互锁条件。★★★
    提示
    信号流：021 改 K̂ 挡位内取值 → 020 再把挡位与限速作用到控制器；019 只动参考点。互锁一：自适应冻结时（脱离接触）020 不得升刚度；互锁二：能量罐告急时 021 的升刚度请示一律挂起。

小结

  • 多阶段任务的参数诉求互相冲突，变阻抗通过"换挡"让同一控制器分饰多角；变的是参数，不是结构。
  • 核心账本 dE/dt = δ̇F − Dδ̇² + ½Ṁδ̇² + ½K̇δ²：降参数只抽能（可快），升参数注入能量（限速 + 能量罐）。
  • 两条安全律：快降慢升（负向速率放宽 3–5 倍）、能量罐支取（升 K 需求 ½ΔKδ² 与罐余量比较，不够则截断等待）。
  • 三态调度（接近 1500/77、接触 300/170、撤离 500/45）+ 滞环状态机 + 平滑过渡，是可直接复用的最小可信方案。
  • 下一章把"调度"换成"调节"：参数不再由阶段命令给出，改为让力误差本身成为 K、D 的调节依据，基于力误差的阻抗参数调整。
