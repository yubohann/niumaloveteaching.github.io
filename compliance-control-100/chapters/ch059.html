第 059 章：导纳控制中的无源性设计

连续世界里的导纳 Mdẍ + Ddẋ = F 永远无源；但采样、计算延迟和内环滞后会在某些频段把它变成"负阻尼"，0.1 m/s 的小撞击能长成打满限幅的极限环。本章用能量审计器（PO）盯住账本，用修正器（PC）把透支精确补回。

  • 主题：无源监视与控制（PO/PC）/ 采样延迟补偿
  • 关键公式：Eobs(k) = Eobs(k−1) + Δt·F·v；触发时 v修正 = v − αF，α = Eobs/(Δt·F²)
  • 预计学时：60 分钟
  • 前置章节：第 058 章（阻抗控制中的能量整形）

学习目标

  • 会用存储函数证明连续导纳的无源性：E = ½Mdv²，Ė = F·v − Ddv²。
  • 理解采样、计算延迟与内环滞后如何破坏无源性：能量账本出现"先支出、后入账"的错位。
  • 掌握 PO/PC 的递推式与修正公式，会推导"修正后账本恰好归零"的代数，并说清符号约定的由来。
  • 会给 PC 设安全参数：α 上限、|F| 门限、速度限幅顺序，理解保守版方案对透明性的代价。
  • 能设计一张验收清单：峰值不放大、账本不长期为正、末段残差收敛，并会在日志里读这三件事。

背景与动机

导纳控制在纸面上是最"乖"的控制律：Mdẍ + Ddẋ = F，配两个正参数，数学上它是严格无源的，只要输入力有界，运动就有界。但真实系统里这个方程从来不"裸奔"，它被三层非理想包着：力传感器的滤波延迟、控制周期的采样保持（ZOH）、位置内环的跟随滞后。三者叠加形成一个"相位欠账"，在高刚度接触时把某一频段的等效阻尼变成负数，于是小扰动被逐步放大：本章开篇场景里，0.1 m/s 的轻碰在 3 秒内长成打满限幅的极限环。

第 058 章给了"能量账本"这套语言，本章把它工程化为两个可运行的模块：无源监视器（passivity observer, PO）实时记账，无源控制器（passivity controller, PC）在账本被透支时精确地补一笔耗散。它们不修改导纳参数、不改变正常工况下的行为，只在"能量赤字"出现的瞬间工作，这是"按需阻尼"的思想。

核心原理

1. 连续导纳的无源性：一页纸的证明

取储存函数 E = ½Mdv²（动能，也是这个虚拟元件的全部储能），对时间求导并代入导纳方程 Mdv̇ = F − Ddv：

Ė = Mdv·v̇ = v·F − Ddv² 第一项是与外界的功率交换，第二项是内部耗散（Dd > 0 时永远为负）

两边积分：E(t) = E(0) + ∫F·v dτ − ∫Ddv²dτ ≤ E(0) + ∫F·v dτ。物理读法：导纳元件可以给外界做净功，但做的总量不能超过"已经存下来的 + 之前从外界收进来的"。两个条件 Md > 0、Dd > 0 是全部要求，这就是"连续系统永远无源"的含义。

2. 采样与延迟如何"偷走"无源性

离散实现里，力与速度的配对不再同时成立：本拍读到的 F 是 τ 秒前环境的反应，而本拍输出的 v 早已把它当作"当下"使用。从能量看，这相当于在特定频段把 F 与 v 的相位关系扭转了，原本该"力顶逆着速度"（耗散）的区间里，出现了"力顺着速度"（注能）。3 ms 的滤波、1 ms 的 ZOH、5–10 ms 的内环跟随，加起来就是 10–15 ms 的相位欠账。数字直觉来自本章实验：导纳 Md = 1 kg、Dd = 1 N·s/m 的元件以 0.1 m/s 撞上 5×105 N/m 的墙，只有 10 ms 的力延迟，若无审计修正，系统保持在限幅 ±0.3 m/s 的极限环里不收敛。

3. 审计器（PO）与修正器（PC）

把导纳元件当作一个一端口：输入是环境力 F（作用于元件），输出是元件速度 v。按第 058 章的语言，定义"外界对元件的做功"账本：

Eobs(k) = Eobs(k−1) + Δt · F(k) · v(k) Eobs：累计注入能量（J）；Eobs > 0 表示环境侧（含延迟）在这段时间里净向元件"泵"能量

本章采用保守版判据（与第 046 章的遥操作端口同族）：只要 Eobs > 0，就认为环境侧存在净注能，立即把它烧掉，不对"历史吸收"做借贷。修正量取沿 F 的反向加一个黏性阻尼：

v修正 = v − α·F， α = Eobs / (Δt · F²) α 量纲为 (m/s)/N，即导纳；修正只减不增，因为触发时 F·v > 0，而 (v−αF)·v = v² − αF·v < v²

为什么这个公式"精确"？把修正代回账本：Eobs′ = Eobs + Δt·F·(−αF) = Eobs − Δt·α·F²。取 α = Eobs/(ΔtF²) 得 Eobs′ = 0，修正注入的耗散不多不少，恰好把这一笔注能烧平；其余时段（Eobs ≤ 0）零干预。工程上 α 要设上限（如 0.5 (m/s)/N）：一是防 F ≈ 0 时公式发散（配 |F| > 0.5 N 门限），二是限制单拍修正幅度以免冲击执行器。

保守的代价要说清楚：它把环境侧的一切净注能都当成可疑，包括接触回弹时弹簧"还回来的能量"，那本来是合法的回收。因此 PC 常开的系统手感会偏"实"、透明性打折；更精细的方案是第 058 章的槽位（给一个储能预算，先存后花），但实现复杂度与调参量都上一个台阶。选择建议：安全优先、参数多变、要快速落地的场合用本章的即收即烧；追求透明性的研究平台再上槽位版。

4. 符号约定是第一生产力

PO/PC 的公式在不同教材里符号各异，比对之前先建一张"关系表"：

端口输入（可测）输出账本触发条件修正方向
遥操作主手（第 046 章）Fapp = −kfFrv∫Fapp·vEr > 0逆着 Fapp 加阻尼
导纳元件（本章）F（环境力）v∫F·vEobs > 0逆着 F 加阻尼

两个端口形式一致："环境侧正在把能量泵进元件" ⇒ 沿泵的方向反向加阻尼、并把账本销平。如果你手上的文献用的是"E < 0 触发"，多半是它把账本定义成了"元件对外的做功"（差一个全局负号），换算一次即可，切不可两套约定混用。

实现思路与设计

PC 的接入位置与控制环路只有一行距离，但顺序很关键（控制周期 1 ms）：

  1. 导纳积分：v ← v + (F − Ddv)/Md·Δt（用滤波后的 F）。
  2. 速度状态限幅：v 先裁到 ±vmax（如 0.3 m/s），PC 的账本必须记录"真实输出"的速度。
  3. PO 记账：Eobs += Δt·F·v。
  4. PC 修正：Eobs > 0 且 |F| > 0.5 N 时，α = min(Eobs/(ΔtF²), αmax)，v ← v − αF，再限一次幅；账本按实际修正销账。
  5. 下发：v 积分成位置增量交给内环；记录 Eobs、v、α 供验收。

调参起点：αmax = 0.5 (m/s)/N、|F| 门限 0.5 N、vmax 按任务（手引导 0.25、装配 0.1）。验收三件事：撞击峰值不超过初速度的 1.2 倍（"不放大"）；Eobs 不长期为正（"不缺账"）；末段 0.5 s 速度 RMS 收敛（"不振荡"）。调试顺序永远是：先只跑 PO 看账本长什么样 → 再开 PC → 最后接工艺负载。

关键代码与解读

片段 1：PO/PC 修正器

import numpy as np

class PassivityController:
    """导纳端口的时域无源控制（保守版）：
    PO 记录环境侧净注能；PC 在 E>0 时逆着注能方向加阻尼并销账。
    pc_on=False 时只记账不修正：便于对照实验里对照“无防护”的账本。"""
    def __init__(self, dt=1e-3, alpha_max=0.5, f_min=0.5, pc_on=True):
        self.dt, self.alpha_max, self.f_min = dt, alpha_max, f_min
        self.pc_on = pc_on
        self.e_obs = 0.0          # 账本：环境对元件的累计做功(J)
        self.alpha_last = 0.0     # 上拍修正强度，用于日志/诊断

    def step(self, f, v):
        # ① PO：用“即将输出”的速度记账（与输出保持一致）
        self.e_obs += self.dt * f * v
        # ② PC：只在账本为正、且力有真实幅值时触发
        self.alpha_last = 0.0
        if self.pc_on and self.e_obs > 0.0 and abs(f) > self.f_min:
            alpha = min(self.e_obs / (self.dt * f * f), self.alpha_max)
            dv = -alpha * f                 # 逆着被泵方向加阻尼：只减不增
            v = v + dv
            self.e_obs += self.dt * f * dv  # 用实际修正量销账
            self.e_obs = max(0.0, self.e_obs)   # 数值残差归零
            self.alpha_last = alpha
        return v

解读：（1）记账用"即将输出的速度"、销账用"实际施加的修正量"：如果记账与输出用的速度不是同一个（常见错误：记的是修正前、输出的是修正后），账本会系统性偏差，PC 要么过敏要么迟钝。（2）dv = -alpha * f 的符号（与第 046 章同款）：触发时 F·v > 0（力与速度同向），逆着 F 的修正一定让速度幅值变小，它天然是"只减不增"的耗散动作，不可能把系统推向发散。（3）α 用 min 封顶并配 |F| 门限：F → 0 时 α 的原式发散，门限把噪声触发挡在门外；α 封顶则限制单拍冲击。（4）代码只做"外挂修正"，不碰导纳参数与积分状态，这种"旁路性"让它能与任何导纳实现组合，也是它能进安全链路的原因。

片段 2：轻阻尼撞墙实验，极限环 vs 收敛

from collections import deque

def admittance_wall(pc_on, k_wall=5e5, tau=0.010, m_d=1.0, d_d=1.0,
                    v0=0.1, v_max=0.3, dt=1e-3, t_end=3.0):
    """导纳元件以 10 cm/s 撞 5e5 N/m 的墙；力测量延迟 10 ms、
    内环 10 ms 一阶滞后，速度限幅 0.3 m/s（真机安全限幅的替身）。"""
    nd = max(1, int(tau / dt))
    f_buf = deque([0.0] * nd, maxlen=nd)
    pc = PassivityController(dt=dt, pc_on=pc_on)   # 关 PC 时仍记账
    v, x, x_cmd = v0, 0.0, 0.0
    v_hist, e_max = [], 0.0
    for k in range(int(t_end / dt)):
        f = f_buf[0]                             # 延迟的力测量
        v_new = v + (f - d_d * v) / m_d * dt
        v_new = float(np.clip(v_new, -v_max, v_max))
        v_new = float(np.clip(pc.step(f, v_new), -v_max, v_max))
        v = v_new
        x_cmd += v * dt
        x += (x_cmd - x) / 0.010 * dt            # 内环位置环滞后
        f_true = -k_wall * max(x, 0.0)           # 墙面反作用力
        f_buf.append(f_true)
        v_hist.append(v)
        e_max = max(e_max, pc.e_obs)
    tail = np.array(v_hist[-1000:])
    return np.sqrt(np.mean(tail**2)) * 1000, np.max(np.abs(v_hist)) * 1000, e_max

for flag in (False, True):
    rms, vmax, e_max = admittance_wall(flag)
    print(f"pc_on={flag}  末段速度RMS={rms:7.2f} mm/s  "
          f"全程最大速度={vmax:7.2f} mm/s  账本峰值={e_max:.3f} J")

解读：两行输出是本章的招牌对照（实测量级）：关掉 PC 时，末段速度 RMS ≈ 27.6 mm/s、峰值打满限幅 300 mm/s、账本峰值飙到 1.35 J，能量被环境侧的延迟效应持续泵进来，系统在限幅之间来回撞；打开 PC 后，末段 RMS ≈ 0.00、峰值只有 99.9 mm/s（等于初速，几乎没有放大）、账本峰值钉在 0.000。三个数字对应验收清单的三条：不振荡、不放大、不缺账。（1）为什么峰值"恰好等于初速"？因为 PC 把每一次环境注能都当场烧掉，撞击后的动能只按物理阻尼衰减，不再有"越弹越高"。（2）把 d_d 从 1 提到 20 再跑："关 PC"的那行会自然收敛（阻尼够用），但 PC 版峰值仍略低（初始撞击也不放大），说明 PC 与"加大阻尼"不矛盾，它是参数之外的第二道防线。（3）把 tau 提到 20 ms、v_max 压到 0.1 m/s，PC 版依然收敛；把 α_max 缩到 0.05，你会看到收敛变慢但仍有界，α_max 只是"预算上限"，收紧它只会让收敛变慢；系统的有界性不依赖它。

片段 3：验收报告器

def acceptance_report(rms, vmax, v0=0.1, e_max=0.0):
    """把验收清单写成可打印的报告：三条判据 + 结论。
    判据阈值应随任务标定，这里给的是“安全优先”的保守值。"""
    ok_peak = vmax <= 1.2 * v0 * 1000      # 峰值不放大(不超过初速 1.2 倍)
    ok_rms = rms <= 1.0                    # 末段 RMS 收敛到 1 mm/s 内
    ok_budget = e_max <= 0.05              # 账本不长期为正(≤ 50 mJ)
    verdict = "通过" if (ok_peak and ok_rms and ok_budget) else "不通过"
    print(f"峰值 {vmax:7.2f} mm/s [{'OK' if ok_peak else 'NG'}]  "
          f"末段RMS {rms:6.2f} mm/s [{'OK' if ok_rms else 'NG'}]  "
          f"账本峰值 {e_max:.3f} J [{'OK' if ok_budget else 'NG'}]  => {verdict}")

# 用法：先跑片段 2 的仿真，再把统计量送进来
rms0, vmax0, e0 = admittance_wall(False)
rms1, vmax1, e1 = admittance_wall(True)
print("无 PC:"); acceptance_report(rms0, vmax0, e_max=e0)
print("有 PC:"); acceptance_report(rms1, vmax1, e_max=e1)

解读：（1）把"验收"从脑子里的感觉变成三行代码，是能量方法给工程的最大礼物：每个指标都有明确的物理对应（末段 RMS ↔ 是否振荡；峰值 ↔ 是否放大；账本峰值 ↔ 是否在持续注能）。（2）阈值（1.2 倍初速、1 mm/s、50 mJ）是"安全优先"的示例值：真正上线时要按你的任务把"工艺能接受的残余振动"翻译成 RMS 阈值，把"峰值力预算"翻译成速度阈值。（3）报告器故意接收统计量，不自己跑仿真：在真机上它应当接的是日志流（Eobs、v、F 的环形缓冲），同一个函数既能验收仿真、也能每天巡检真机，工具复用是最低成本的工程纪律。

常见坑

  • 符号约定混用：把"E < 0 触发"的文献公式和本章的"E > 0 触发"混着抄，修正方向随之反向，PC 变成"加油器"，系统比不加还抖。修复：先画第三节的关系表，再写代码；先只跑 PO 确认"注能时为正是负"。
  • 账本与输出不一致：记账用了修正前的速度、输出用了修正后的（或反之），账本系统性偏差。修复：记账、销账、输出三点用同一串变量，写完单元测试断言"触发一拍后 Eobs ≈ 0"。
  • α 不封顶、也不设力门限：F 接近零时修正量爆炸，机器人"接触前发涩、一碰就顿"。修复：|F| > 0.5 N 门限 + αmax 封顶，双保险。
  • PC 修正后又忘记重新限幅：修正把速度推出 vmax，下一拍账本记录的"真实输出"对不上。修复：修正后立即二次限幅（片段 2 的写法）。
  • 拿"保守版"去追透明性：PC 常开会把接触回弹的合法能量回收也烧掉，手感偏"实"。若任务对透明性敏感，务必上第 058 章的槽位版（先存后花）或给 PC 加"能量预算"的借贷机制。修复顺序：先问任务要安全还是要手感，再选方案。

练习与思考

  1. 推导连续导纳的无源不等式：从 Ė = vF − Ddv² 出发，积分并证明 ∫Fv dτ ≥ −½Mdv(0)²。（提示：E(t) = ½Mdv(t)² ≥ 0。）★
    提示
    ∫Fv dτ = E(t) − E(0) + ∫Dv²dτ ≥ −E(0)。注意这个下界由"初始动能的有限性"给出，说明无源的本质是"放能总额有限"，并不等于"从不放能"。
  2. 验证修正公式的精确销账：设触发时账本 Eobs，取 α = Eobs/(ΔtF²)、v修正 = v − αF，用修正后的速度重算本拍账本增量，证明结果为零；再说明为什么 F·v > 0 保证了 |v修正| ≤ |v|（分 F、v 同向/反向两种情形讨论）。★★
    提示
    触发条件下 F 与 v 同号：若同正，Δv = −αF < 0；若同负，Δv > 0，两种情形都让速度幅值减小，这正是"只减不增"的耗散本质。
  3. 用片段 2 扫描参数：d_d ∈ {0.5, 1, 2, 5, 20}、tau ∈ {2, 5, 10, 20} ms，填一张 5×4 表（每格两个数字：无 PC 的末段 RMS、有 PC 后的峰值），标出"PC 真正救场"的格子并总结它们的共同特征。★★
    提示
    救场区通常满足"轻阻尼 + 较大延迟"（相位欠账明显）。阻尼很足时无 PC 也能收敛，PC 的价值退化为"降低初始撞击峰值"（仍值得一提）。
  4. 设计"借贷版" PC：允许 Eobs 在 [−Ebudget, +∞) 之间浮动（历史吸收可以给未来注能"担保"），支出超过预算才触发。写出判据与修正公式，讨论 Ebudget 取 0（本章）、取较大值（接近透明）、取 ½Mdvmax²（物理上限）三种极限的行为差异。它是第 058 章槽位思路的曾孙版本。★★★
    提示
    Eobs < −Ebudget 时触发，把余额拉回 −Ebudget+ε；budget=0 即本章保守版；budget→∞ 完全不干预；budget = ½Mvmax² 对应"最多允许动用全部动能额度"的物理保守线。

小结

  • 连续导纳的无源性一页纸可证：E = ½Mdv²，Ė = Fv − Ddv²，条件只有 Md > 0、Dd > 0。
  • 采样、滤波与内环滞后合计 10–15 ms 的相位欠账，轻阻尼、高刚度接触时把导纳变成"负阻尼"，小撞击长出极限环。
  • PO 账本 Eobs += Δt·F·v；PC 在 Eobs > 0 时 v ← v − αF、α = Eobs/(ΔtF²)，修正的耗散恰好销平注能，其余时段零干预。
  • 实现三纪律：账本/输出/销账用同一串速度；α 封顶 + 力门限；修正后二次限幅。
  • 保守版把一切净注能当可疑，手感变"实"；要透明性就升级到槽位（先存后花）版本，安全与手感之间有明确的价格标签。
