第四篇 · 高级柔顺任务与约束

第 073 章：基于导纳控制的冗余机器人

7 个关节管 6 个自由度：多出来的那一维是包袱还是资源，取决于零空间投影怎么用。本章把导纳的位姿修正落到关节侧，并让"不干活的自由度"去干姿势维护。

  • 主题：冗余机器人 / 零空间投影 / 姿态柔顺
  • 关键公式：q̇ = J⁺ẋ + (I − J⁺J)·q̇0；J⁺ = JT(JJT+λ2I)−1
  • 预计学时：60 分钟
  • 前置章节：第 072 章

学习目标

  • 理解冗余的数学定义与几何含义：零空间的维度 n−m，以及"零空间运动不影响末端"的条件。
  • 会写出阻尼最小二乘（DLS）伪逆 JT(JJT+λ2I)−1，理解 λ 在奇异附近的保护作用与它带来的近似误差。
  • 会构造零空间投影算子 N = I − J⁺J，并会数值验证"投影后的关节速度不改变末端速度"。
  • 会设计零空间的三个常用目标：关节限位回避、偏好姿态、以及基于导纳的"肘部柔顺"。
  • 理解任务空间导纳与零空间运动的带宽关系：为什么零空间可以（也应该）慢一些。
  • 会处理关节速度限幅与姿态切换时的平滑问题。

背景与动机

七轴协作臂比六轴多一个关节，这多出来的一维就是"零空间"（null space）：调整肘部姿态，末端位姿可以纹丝不动。护着它不用，机器人姿态容易在连续工作里慢慢"拧"到关节限位附近，触碰限位后突然停摆；用好了，它同时是三种能力的来源：躲限位（把关节从极限位置拉回来）、保姿态（保持适合下一步任务的构型）、让人推（肘部可以被人工引导，像导纳手柄一样柔顺）。

当机器人执行导纳任务时，问题更精细：导纳算出的是末端该往哪偏，可关节怎么分配、多余自由度怎么动，都需要一套"分层"的运动学。本章的写法刻意和 ch075（任务优先级）区分：这里处理的是一个任务 + 一个零空间的经典结构，重点在投影算子的构造、阻尼伪逆的数值细节，以及零空间自己也可以是一条轻柔的导纳通道。

核心原理

1. 零空间：多出来的自由度在哪里安家

关节数 n = 7、任务维数 m = 6 时，对任意期望的末端速度 ẋ，满足 J q̇ = ẋ 的关节速度有无穷多组，它们相差任意零空间分量。零空间由投影算子定义：

N = I − J⁺J，  J·N·z = 0（对任意 z） J：m×n 雅可比；J⁺：n×m 伪逆；N：n×n 投影矩阵，rank = n−m = 1

理解 N 的两个性质就够用：（1）投影性，N 把关节速度里"不会改变末端"的成分留下、把其余成分滤掉；（2）每用一次就掉一圈秩，rank(N) = n−m = 1，"七轴比六轴多一条可用通道"这句行话的精确含义就是它。注意 N 依赖于位形 q（因为 J 依赖 q），所以每一次控制周期都要重新计算投影，别把它当成常数矩阵缓存。

2. 阻尼伪逆：奇异附近的呼吸阀

数学伪逆 J⁺ = JT(JJT)−1 在奇异位形附近会爆炸：JJT 的某个特征值趋零时，逆里出现 1/0，关节速度瞬间冲到几千度/秒。工程上换成阻尼最小二乘：

J⁺λ = JT(JJT + λ2I)−1， q̇ = J⁺λẋ + Nλq̇0，Nλ = I − J⁺λJ λ：阻尼因子，m/s 量级；奇异方向的有效增益变为 σ/(σ²+λ²)

λ 的代价是显式的：沿奇异方向的速度跟踪误差约 λ²/(σ²+λ²)。λ 取 0.05、σ = 0.5（正常位形）时误差只有 1%；σ = 0.05（接近奇异）时误差 50%，这正是"宁可跟不准，也不能冲出去"的取舍。工程实现里 λ 常按最小奇异值调度：λ = λ0·(1 − σmin/σth) 之类的软切换（第 074 章展开），平时 λ ≈ 0，近了才"呼吸"起来。还要注意一个二手效应：用了阻尼伪逆，零空间投影的"零"也变成近似，JNλ = λ²(JJT+λ²I)−1J 不再严格为零。量级上它随 λ² 缩小，λ = 0.05 时对 σ = 0.5 的通道约 1%，足够好；但如果你用 λ = 0.5 的"重阻尼"还指望零空间绝对干净，就会在末端看到毫米级的漂。

3. 零空间里放什么：三类目标的设计

（1）关节限位回避。给每个关节一个势垒：V(q) = Σ wi/(qi − qi,min)2（接近下限）与对称项（上限），一旦某个关节进入"警戒区"，−∂V/∂q 就是把它推回来的梯度，投影后不影响末端。势垒宽度取关节行程的 10–15%，权重让"最危险的关节"梯度最大。

（2）偏好姿态。对七轴臂，一个自然参数是"臂角"（arm angle）φ：同一末端位姿下肘部的不同摆放对应 φ 的连续取值。设偏好值 φd，零空间速度取 q̇0 = −kφ(φ − φd)∂φ/∂q，把构型温柔地拉回舒适区。

（3）肘部导纳（人机协作场景）。人推肘部时，测得的外部关节力矩（观测器或关节力矩传感器）经过一个关节空间导纳：q̇0 = Dj−1τext。投影之后，人推肘只动肘、不动手，这正是"导纳控制 + 冗余"的组合价值：让出身体的一部分而不破坏作业。工程直觉：任务空间的导纳管"手"，零空间的导纳管"肘"，两个导纳叠起来，机器人在两个层次上同时柔顺。

4. 时间尺度：零空间应该慢一点

任务空间的导纳带宽由接触力回路决定（顺服、快速）；零空间的运动没有接触回路，可以也应该慢，典型 0.5–2 rad/s 的关节速度上限、姿态回中带宽 0.1–0.5 Hz。快有两个害处：一是零空间运动在数值上会通过 Nλ 的近似性"漏"到末端（尤其带阻尼时），慢速把它压到不可见；二是它会引入关节速度的额外占用，挤压任务空间的可用速度（关节速度上限是个总量）。把零空间当"背景动作"来调，这正是它稳而好用的关键；按第二个任务来追，上面两个害处都会应验。

实现思路与设计

  1. 任务侧：导纳把外力积成末端位姿修正 Δx（ch069 的做法），差分/规划成 ẋtask（限幅如 0.1 m/s、0.3 rad/s）。
  2. 雅可比与阻尼：用当前关节角算 J；由 σmin 调度 λ（0.01–0.1）；JJ^T + λ²I 用 Cholesky 解，别显式求逆。
  3. 零空间速度：q̇0 = 限位梯度 + 姿态回中 + 肘部导纳，合成后整体限幅（各关节 0.3 rad/s 起步）。
  4. 合成与下发：q̇ = J⁺λẋtask + Nλq̇0；再按关节速度上限做整体缩放（保持方向）；积分关节角（或用速度接口直发）。
  5. 兜底：任何关节进入硬限位前 3° 时，任务速度整体缩放至 0 并报警；自碰撞距离图（若有）同层检查。
  6. 验证：给静态末端一个 ẋ 与一段 q̇0，实测末端残差 < 1 mm / 0.2°；人为把肘部推离偏好姿态，观察回中规律且末端不动。

数字起点：λ = 0.03（σmin > 0.1 时）；限位势垒宽度 15°；姿态回中增益 0.5 s−1；肘部导纳 Dj = 5 N·m·s/rad；q̇0 合成上限 0.3 rad/s。

关键代码与解读

片段 1：阻尼伪逆与零空间投影（含不变性数值验证）

import numpy as np

def dls_pinv(J, lam=0.03):
    """阻尼最小二乘伪逆：J^T (J J^T + lam^2 I)^{-1}。
    用 Cholesky 解线性方程组，避免显式求逆的数值损耗。"""
    m = J.shape[0]
    A = J @ J.T + (lam ** 2) * np.eye(m)
    L = np.linalg.cholesky(A)          # A 对称正定：Cholesky 最快且稳定
    Jinv = np.linalg.solve(A, J).T     # 解 A X = J 得 X = A^{-1} J，再转置
    del L                              # 显式删掉未使用的中间量，防止误用
    return Jinv

def null_projector(J, lam=0.03):
    Jinv = dls_pinv(J, lam)
    return np.eye(J.shape[1]) - Jinv @ J

# 验证：投影后的速度对末端速度的影响应当极小
rng = np.random.default_rng(0)
J = rng.normal(size=(6, 7))            # 用满秩随机雅可比代替真实机器人
N = null_projector(J, lam=0.03)
z = rng.normal(size=7)
print("||J N z|| =", np.linalg.norm(J @ N @ z))     # 期望 < 1e-2
print("rank(N) 应约等于 1：奇异值 =", np.round(np.linalg.svd(N)[1], 3))

解读：这段代码的两个输出就是零空间实现的"验收标准"：||J N z|| 要落在 1e-2 以下（本例约 1.5e-3，残余部分来自 λ 的近似性，属于正常现象），N 的奇异值应当是"一个 1、六个接近 0"（精确伪逆时是 1 与 0）。若你的 rank(N) 显示两个大奇异值，说明雅可比其实只有 5 个有效自由度（某方向奇异），此时零空间变成二维，它不该被当成"意外"，而应触发 λ 调度与任务速度缩放。del L 那行有意保留：教学代码里显式写出"这个量不该再用"，比静默留一个未使用变量更少误导。

片段 2：零空间姿态与限位控制器

class NullSpacePosture:
    """零空间里的三件事：限位回避、偏好姿态、肘部导纳。"""
    def __init__(self, q_min, q_max, q_pref, w_limit=2.0, k_posture=0.5,
                 D_elbow=5.0, v_max=0.3):
        # 限位势垒宽度取行程的 15%：太窄来不及刹车，太宽平时瞎忙
        self.q_min, self.q_max = np.asarray(q_min), np.asarray(q_max)
        self.band = 0.15 * (self.q_max - self.q_min)
        self.q_pref, self.w_limit = np.asarray(q_pref), w_limit
        self.k_posture, self.D_elbow, self.v_max = k_posture, D_elbow, v_max

    def limit_gradient(self, q):
        """势垒 V = w/(q - q_lim)^2 的负梯度：逼近限位时给回推力。"""
        g = np.zeros_like(q)
        d_lo = q - self.q_min
        d_hi = self.q_max - q
        mask_lo = d_lo < self.band
        mask_hi = d_hi < self.band
        # dV/dq = -2w/d^3：越靠近，梯度越陡（但被 band 截断，不会真到无穷）
        g[mask_lo] += 2.0 * self.w_limit / np.maximum(d_lo[mask_lo], 1e-6) ** 3
        g[mask_hi] -= 2.0 * self.w_limit / np.maximum(d_hi[mask_hi], 1e-6) ** 3
        return g

    def compute(self, q, tau_ext_joint):
        # 1) 限位回避梯度（推离限位）；2) 姿态回中（温柔拉向偏好构型）
        qd = self.limit_gradient(q) - self.k_posture * (q - self.q_pref)
        # 3) 肘部导纳：人被推的关节力矩直接映射成关节速度（哪被推哪动）
        qd += np.linalg.solve(np.diag([self.D_elbow] * len(q)), tau_ext_joint)
        # 整体限幅：零空间是"背景动作"，速度必须远小于任务通道
        nrm = np.linalg.norm(qd)
        if nrm > self.v_max:
            qd *= self.v_max / nrm
        return qd

解读：三路输入的单位与量级刻意统一在"关节速度（rad/s）"上，限位梯度实际上是"势垒力除以单位阻尼"，姿态回中是无阻尼弹簧，肘部导纳是"力除以 D"。这样合成时不需要再配权重矩阵，v_max 一个总闸就管住全体。注意 np.maximum(d_lo, 1e-6) 的护栏：势垒公式在 d → 0 时发散，运行时若真的贴上限位，去掉护栏会得到 inf·0 = nan，把整条控制链污染成 NaN，这类"数值护栏"在安全相关代码里宁可冗余也不能少。

片段 3：分层合成与关节速度整体缩放

def redundant_step(J, xdot_task, q, ns, tau_ext, lam=0.03, qd_max=1.5):
    """导纳任务 + 零空间：合成关节速度并做安全缩放。"""
    Jinv = dls_pinv(J, lam)
    N = np.eye(J.shape[1]) - Jinv @ J
    qd_task = Jinv @ xdot_task              # 任务通道：负责末端位姿
    qd_null = N @ ns.compute(q, tau_ext)    # 零空间通道：负责姿态与肘部柔顺
    qd = qd_task + qd_null
    # 关节速度整体缩放（等比，不改变各关节的运动方向）：
    # 单关节超限就全体减速，避免"一个关节尽力、姿态被拧变形"
    s = min(1.0, qd_max / max(np.max(np.abs(qd)), 1e-9))
    qd *= s
    # 任务通道被缩放的比例要回报给导纳，防止其内部状态继续积累（windup）
    return qd, s

解读：缩放系数 s 选择"整体等比"，避开"逐关节独立截断"，理由与 ch079 的力矩缩放完全同构：逐关节截断会扭曲运动方向，末端轨迹在超限瞬间拐弯，接触力也随之跳变；等比缩放保持方向，只是"整体变慢"，让上层导纳有机会通过降低任务速度自然化解。s 被返回给调用方是这段代码的隐含接口约定：导纳若不知道"本拍只实现了 60% 的期望速度"，它的积分状态会按 100% 继续积累，几拍之后内部修正量远超实际，一旦障碍解除，机器人会"突然快进"，这是冗余机器人上最典型的一类 windup，处理方式与 ch063 的冻结思路同源。

常见坑

  • 用 λ 很大的伪逆还指望零空间干净：JNλ ≈ λ² 量级的漏泄让末端微微漂移，久跑成毫米级。修复：λ 按 σmin 调度，平时小；零空间速度降下来。
  • 零空间和任务通道"抢速度"：零空间峰值速度 1 rad/s 起，任务加速时总速度超限，机器人行为时快时慢。修复：零空间独立限幅 0.2–0.3 rad/s；缩放系数回报给两个通道。
  • 势垒权重不随负荷变化：关节在重力负荷大的构型里被"推回"得慢，越靠越近最终触发硬限位。修复：势垒权重乘一个与关节外部力矩相关的放大因子（或让 λ 调度接管）。
  • 偏好姿态切换不连续：任务切换时 q_pref 直接跳变，零空间速度瞬间饱和。修复：q_pref 用 0.5–1 s 的斜坡过渡；切换期间冻结肘部导纳通道。
  • 忘了验证末端不变性：实现完就上真机，末端在"背景动作"期间缓慢漂移，还以为是标定问题。修复：离线跑片段 1 的不变性测试（||JN z|| 与 rank(N)），并在现场用激光跟踪仪做一次静态验证。

练习与思考

  1. 说明 N = I − J⁺J 的秩为 n−m（提示：J⁺J 是投影到 J 的行空间，其秩为 m）；对 7 轴臂验证 rank(N) = 1。 ★
    提示
    J⁺J 是秩 m 的正交投影，N 投影到其正交补，维数 n−m。数值验证用 svd(N) 看大奇异值个数。
  2. 推导 JNλ = λ²(JJT+λ²I)−1J，并按 σ 通道计算 λ = 0.05、σ = 0.5 / 0.1 / 0.02 时的漏泄量级。 ★★
    提示
    逐通道化为 σ 的标量式：相对漏泄 λ²/(σ²+λ²)，λ = 0.05 时 σ = 0.5/0.1/0.02 对应约 1%/20%/86%；σ 越小、零空间被侵蚀得越厉害，这是"重阻尼侵蚀零空间"的定量解释。
  3. 实验设计：固定任务通道不动，只让限位梯度在 0 与全额之间切换，观察末端位置的漂移与关节速度峰值，给出"零空间速度上限"的推荐值。 ★★
    提示
    用 ||J N v|| 与关节速度峰值双指标：找到"漂移可忽略（< 0.2 mm）且不挤占任务速度"的档位。
  4. 设计：人机协作打磨任务，要求肘部被推 20 N 时以约 0.2 rad/s 让位、同时末端打磨压力波动不超过 10%。给出肘部导纳 Dj、零空间合成上限、λ 与验证步骤。 ★★★
    提示
    Dj 使"τ_ext/Dj ≈ 0.2 rad/s"；末端波动由零空间漏泄与导纳带宽共同决定，回头用 ||JN|| 校核。
  5. 思考题：为什么把"肘部柔顺"放在零空间实现，比放在任务空间安全得多？从"改造对象"和"失效后果"两个角度各写一句。 ★★
    提示
    零空间只改姿态、不动末端任务；失效后果被限制在构型层面（可回中），不会波及接触状态（可能撞坏工件）。

小结

  • 冗余给出一条零空间通道（rank = n−m）：投影算子 N = I − J⁺J 把"不影响末端"的关节速度留下。
  • 工程上必须用阻尼伪逆 J⁺λ = JT(JJT+λ2I)−1：代价是 λ² 量级的速度误差与零空间漏泄，收益是奇异附近不暴走。
  • 零空间三大用途：限位回避（势垒梯度）、偏好姿态（软回中）、肘部导纳（把外力矩变成关节让位）。
  • 零空间是"背景动作"：限速 0.2–0.3 rad/s、独立限幅，并把整体缩放系数回报给任务导纳，防 windup。
  • 验证三件套：||JN z|| 小、rank(N) 正确、现场静态末端不变性实测。
  • 下一章把雅可比拆到它的"骨架"上：用奇异值分解同时管理奇异位形、刚度方向与伤害极限。
