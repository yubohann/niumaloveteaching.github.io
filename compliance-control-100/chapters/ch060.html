第 060 章：阻抗控制中的饱和处理

阻抗方程默认"要多少力矩就有多少力矩"，可电机的力矩上限就摆在那里。一旦命令被截断，那个精心设计的虚拟弹簧阻尼器当场"离线"，机器人退化成一台恒力机器，本章算清这次降级的影响范围，并给出力预算、参考调速与卷绕防护三件套。

  • 主题：执行器饱和 / 虚拟模型失真与缓解
  • 关键公式：τapp = sat(τcmd, ±τmax)；失真项 Δτ = τapp − τcmd；可用力 Fmax = τavail/r
  • 预计学时：55 分钟
  • 前置章节：第 059 章（导纳控制中的无源性设计）

学习目标

  • 理解饱和使阻抗控制"降级"的确切含义：饱和期间虚拟模型失效，机器人退化为恒力源，但系统仍然无源。
  • 会做力预算：由关节力矩上限、重力占用与力臂长度算出各方向的可用末端力，并反推允许的刚度上限。
  • 掌握"饱和感知"控制结构：扭矩命令的平滑缩放、期望轨迹的参考调速（reference governor）、以及两者的触发条件。
  • 能识别饱和引发的卷绕（windup）现象：位置型力跟踪中偏置积分累积，接触瞬间力峰值数倍于目标。
  • 会写力预算检查器与饱和感知阻抗步，并读懂峰值力/恢复时间两类验收指标。

背景与动机

第 001 章就把阻抗控制写成"解出加速度再积分"的形式，默认每一步算出的 τ 都能被电机如实输出。工程现实里有三道闸门：电机峰值力矩（几毫秒级）、连续力矩（热约束）、以及电流环的能力。以一台 6 轴臂为例，腕部关节峰值力矩常只有 20–60 N·m；在伸展位形下，这对应末端 30–80 N 的平移力，看上去够用，但阻抗控制瞬态里"想要"的力往往远超稳态：σ = 5 mm 的位置误差乘 Kd = 2000 N/m 就是 10 N 的即时需求，再叠加惯性与重力余量，饱和是日常状态，很难当成例外处理。

饱和的坏消息在于控制律与被控对象之间的契约被单方面撕毁：虚拟刚度、虚拟阻尼、无源性证书的前提都是"τ 被如实执行"；饱和期间这一切暂时失效，还常常伴随积分卷绕与冲击超调。本章的目标是让饱和"可见、可控、可预期"，先算得清、再管得住。

核心原理

1. 饱和发生在哪：三种闸门与它们的数学

最直接的是力矩饱和：

τapp = τmax · tanh(τcmd/τmax) 或更常见地 τapp = clip(τcmd, −τmax, +τmax) tanh 是"软饱和"（处处可导），clip 是"硬饱和"（法律上更常见，工程上更疼）

把失真写成一个误差项：Δτ = τapp − τcmd。把它代入阻抗方程，理想的 Mdẍ + Ddẋ + Kde = −Fext 变成：

Mdẍ + Ddẋ + Kde = −Fext + Δτ Δτ 是一股"凭空出现"的推力：物理上来自电机（它是真实存在的力），但控制律从未下达过它

两种解读都有用：（1）行为解读：饱和方向上虚拟弹簧和阻尼"离线"，机器人变成一台上限为 τmax 的恒力源，你精心设计的刚度值、阻尼比统统不可信；（2）稳定性解读：饱和是单调的扇区非线性（输入输出同号且增益 ≤ 1），它是无源的，不会凭空造能，所以"潜在的失稳"来自它和积分器/延迟的组合，饱和本身是无源环节，不制造能量。

2. 力预算：把"能出多少力"变成设计约束

先算通常量：某方向上可用的末端力由关节力矩减去重力与摩擦占用后、再除以该方向的力臂：

Favail(q) = ( τmax − |τg(q)| − τfric ) / r(q) q：当前构型；τmax：最小可用关节力矩（沿该方向的等效值）；r(q)：末端到该关节的有效力臂（m）

例：τmax = 40 N·m、重力占用 10 N·m、摩擦占用 2 N·m、r = 0.8 m，则 Favail = 28/0.8 = 35 N。再把它翻译成刚度约束：若任务瞬态误差最大 0.05 m、留 20% 余量，则 Kd ≤ 0.8×35/0.05 = 560 N/m。工程直觉：刚度不是"想调多大就调多大"，它被可用力除以工作误差反向上限锁死；先用这条不等式定预算，再谈手感。需要更高刚度只有三条路：缩短力臂、增大关节力矩、或减小工作行程/瞬态误差。

3. 三件套：让饱和"可见、可控、可预期"

  1. 力矩预缩放（saturation-aware scaling）：在解算阶段就把 τcmd 过一个软缩放，等于告诉虚拟模型"预算有限"，比事后 clip 更平滑，且天然避免"截断后 Δτ 跳变"对加速度的冲击。实现上常与第 024 章的力矩限制合并。
  2. 参考调速（reference governor）：把期望轨迹 xd 朝"可行域"拉：当需求的稳态力 超预算时，按 τ 余量把 xd 的位置分量缩回来，用时间常数 0.1–0.3 s 缓慢逼近可行边界。它的效果是"用时间换力"，任务慢一点、力永远不越界。
  3. 卷绕防护（anti-windup）：力跟踪的偏置积分必须知道"执行器已经尽力了"，饱和期间冻结或限幅（下一章全面展开）。没有这一条，参考调速也救不了接触瞬间的数倍力峰值。

饱和的"可见性"靠监控：记录每拍的 τutil = |τcmd|/τmax 与饱和占空比（saturation duty）。指标经验值：稳态占空比 < 1%、瞬态峰值占空比 < 20% 且持续 < 50 ms；若稳态就贴着上限，说明参数预算从头就是错的。

实现思路与设计

把预算与防护写进设计流程（控制周期 1 ms）：

  1. 第一条设计公式：从 Favail 与最大允许瞬态误差 etask 反推 Kd,max = 0.8·Favail/etask（预留 20% 余量给阻尼与摩擦）；Dd 再按 ζ 计算。
  2. 离线校验：在典型构型网格上扫描 Favail(q)，本方向的最小值就是"最坏构型"的预算，用它的 60–80% 定 Kd。
  3. 在线监控：τutil、饱和占空比、Δτ 的均方值；后者直接反映"虚拟模型失真"的程度。
  4. 参考调速：当 etask 超限（需求力 > 0.8 Favail）时，把 xd 的偏置分量按 0.2 s 时间常数收缩到可行值；释放时同样按 0.2 s 恢复（不突变）。
  5. 卷绕防护：偏置积分按第 061 章的三方案之一处理；本章实验先看"不加防护"的代价。

打分表：峰值力 ≤ 1.2·目标（不超调）、恢复时间 ≤ 3 s、饱和占空比峰值 ≤ 20%。三行都能标定，才算"饱和已被管理"。

关键代码与解读

片段 1：力预算检查器

import numpy as np

def force_budget(tau_max=40.0, tau_gravity=10.0, tau_fric=2.0,
                 r=0.8, e_task=0.05, k_d_desired=1200.0):
    """把关节力矩上限翻译成末端力预算与刚度上限，逐项打印依据。"""
    # 可用关节力矩：从峰值里扣掉重力与摩擦的“最低消费”
    tau_avail = tau_max - abs(tau_gravity) - tau_fric
    f_avail = tau_avail / r                    # 可用末端力(N)
    # 一条工作误差 e_task 内的最大刚度(留 20% 余量给阻尼与摩擦)
    k_max = 0.8 * f_avail / e_task
    # 期望刚度是否可行？不可行给出建议
    ok = k_d_desired <= k_max
    print(f"可用力 {f_avail:5.1f} N | 刚度上限 {k_max:6.0f} N/m | "
          f"期望 {k_d_desired:5.0f} N/m -> {'可行' if ok else '不可行'}")
    if not ok:
        # 三条出路分别给出“需要多少”: 更小的误差、更大的力、更长的行程
        print(f"  把瞬态误差压到 {0.8*f_avail/k_d_desired*1000:.1f} mm，"
              f"或把可用力提到 {k_d_desired*e_task/0.8:.1f} N")

force_budget()                          # 默认参数：期望 1200 > 上限 → 不可行
force_budget(k_d_desired=500.0)         # 降刚度到 500 → 可行

解读：（1）这个检查器只做算术，却能在项目早期拦住最贵的错误，把 Kd 按"手感"定成 1200 N/m，再指望示教器上拧出 60 N 的接触力，结果全程贴限幅。第一行算出的 560 N/m 上限才是这台机器在该方向上的"物理天花板"。（2）注意公式里 etask 的选择权在任务：对擦拭类任务 50 mm 的瞬态很宽松，对贴合类 5 mm 才是真实需求，误差预算越紧，允许的刚度越低，这是"贴合难做"的能量本质。（3）"三条出路"的打印不是装饰：它把失败模式翻译成可执行决策（压误差 / 加力矩 / 加行程），评审时直接读这一行就能定方向。

片段 2：饱和感知的阻抗步 + 参考调速

class SaturationAwareImpedance:
    """位置型阻抗的饱和感知版本：
    ① 加速度需求先按可用力软缩；② 期望位移朝可行域被“调速器”牵引。"""
    def __init__(self, k_d=500.0, d_d=80.0, m_d=2.0, f_avail=35.0, dt=1e-3):
        self.k_d, self.d_d, self.m_d = k_d, d_d, m_d
        self.f_avail, self.dt = f_avail, dt
        self.x_off = 0.0                # 偏置状态（供力跟踪使用）
        self.in_sat = False             # 饱和标志：供日志与抗饱和使用

    def step(self, x, v, x_d, f_ext):
        # ① 参考调速器：稳态需求的弹簧力超预算时，把 x_d 往回收
        e = x - x_d
        f_needed = abs(self.k_d * e + self.d_d * v)
        if f_needed > 0.8 * self.f_avail:
            # 用 0.2 s 时间常数把 e“拉回”到 0.8F/k 对应的幅度
            e_max = 0.8 * self.f_avail / self.k_d
            pull = (np.sign(e) * e_max - e) * self.dt / 0.2
            x_d = x_d - pull            # 移动参考点，不硬砍输出
            self.in_sat = True
        else:
            self.in_sat = False
        # ② 饱和感知缩放：用 tanh 软限量加速度，避免 clip 后的 Δτ 跳变
        a_raw = -(self.d_d * v + self.k_d * (x - x_d) + f_ext) / self.m_d
        a_scale = self.f_avail / self.m_d
        a_cmd = a_scale * np.tanh(a_raw / max(a_scale, 1e-9))
        return a_cmd, x_d

解读：（1）参考调速器动的是"参考"，不直接砍"输出"：把 xd 沿误差方向拉回可行幅度 emax = 0.8Favail/Kd，虚拟动力学在可行域内仍然完整成立，这是它比"输出 clip"高明的地方。（2）拉回速率用 0.2 s 时间常数，避免一步到位：阶跃式改参考会注入能量（第 053 章的账本照样适用），缓慢牵引则平滑。（3）tanh 软缩放让加速度需求在大幅超标时渐近逼近 ascale，处处可导，切到硬 clip 时，加速度的拐角会在接触瞬间产生 jerk 尖峰；但注意 tanh 在 |a_raw| 较小时几乎线性，参数预算（片段 1）仍然是第一道防线，软缩放只是"体面的降级"。

片段 3：饱和卷绕的现场，限速下力跟踪的两种命运

def windup_demo(anti_windup, k_env=2e4, x_e=0.05, f_ref=20.0, ki=1e-4,
                v_max=0.02, k_s=25.0, off_lim=8e-3, dt=1e-3, t_end=6.0):
    """位置型力跟踪：伺服限速 20 mm/s。偏置积分在自由段“空转”
    2.5 秒后撞墙：抗饱和做的事就是拦住这段空转。"""
    x, x_off = 0.0, 0.0
    f_hist = []
    for k in range(int(t_end / dt)):
        v_s = float(np.clip(k_s * (x_e + x_off - x), -v_max, v_max))
        x += v_s * dt
        f_env = k_env * (x - x_e) if x > x_e else 0.0
        e_f = f_ref - f_env
        sat = abs(v_s) >= 0.999 * v_max
        if anti_windup and sat and e_f > 0.0:
            pass                        # 条件积分：饱和且要求更多输出 → 冻结
        else:
            x_off = float(np.clip(x_off + ki * e_f * dt, -off_lim, off_lim))
        f_hist.append(f_env)
    f = np.array(f_hist)
    print(f"anti_windup={anti_windup}  峰值力={max(f):6.2f} N  "
          f"超调={100*(max(f)-f_ref)/f_ref:6.1f}%  末值={f[-1]:5.2f} N")

windup_demo(False)
windup_demo(True)

解读：实测量级一目了然，不加防护时接触峰值 85.8 N、超调 329%；冻结积分后峰值 20.0 N、超调归零。机理：自由段的 2.5 s 里，力误差恒为 20 N，偏置以 ki·ef = 2 mm/s 静默累积约 5 mm；接触瞬间这 5 mm 全部兑现成 2×104×5 mm ≈ 100 N 级的命令力（仿真里 85.8 N 是实际截断后的结果）。（1）把 v_max 提到 0.05 m/s（更快接近）会缓解但不会消除：空转时间缩短到 1 s，卷绕仍有 2 mm，峰值约 38 N，"提速"是治标。（2）把 ki 改小 10 倍：卷绕慢 10 倍，但这同时也让正常工作段的力跟踪慢 10 倍，这就是必须用"抗饱和"、不能靠"调小增益"的原因。（3）本章演示的是位置型阻抗最常见的饱和点（限速伺服），同一机理在扭矩限幅、关节限位处一模一样；下一章把三种抗饱和方案一次讲透。

常见坑

  • 按"手感"定刚度、从不看力预算：Kd = 2000 N/m 配 5 mm 瞬态就是 10 N 的即时需求，叠加重力余量直接贴限幅，虚拟模型长期离线。修复：先跑片段 1 的检查器，用最坏构型的 60–80% 定参数。
  • 事后 clip 当"用了就行"：torque clip 是必须的，但只做事后截断、没有参考调速与卷绕防护，等于"知道要撞墙却不减速"。修复：三件套一起上，截断是底线不是方案。
  • 饱和期间的性能数据照单全收：用饱和段的误差去评估"刚度是否合适"，得到的结论全是假的（那段刚度根本没生效）。修复：日志里给每拍打饱和标志，评估只用未饱和段。
  • 忘记重力占用的动态性：伸展位形重力矩最大，力预算在该构型最差；按折叠位形调的参数到了伸展位就饱和。修复：预算按构型扫描，取最坏值。
  • 认定饱和会"造能"：饱和是无源的（扇区 [0,1] 的单调映射），失稳的锅要么属于积分卷绕、要么属于延迟与采样，找对嫌疑人再开药方。

练习与思考

  1. 证明硬饱和 clip 是无源的：把 τapp = clip(u) 与 u 的乘积展开，说明 |τapp| ≤ |u| 且 τapp·u ≥ 0，因此对任意输入序列 Σu·τapp 不会为负地失控。（提示：按 |u| 是否超限分两段。）★
    提示
    未饱和时 τapp = u，乘积 u² ≥ 0；饱和时 τapp·u = τmax|u| ≥ 0，永不为负，这就是"扇区非线性"的耗散含义。
  2. 对 τmax = 30 N·m、重力占用随构型在 5–18 N·m 间变化、r 在 0.4–0.9 m 间变化的六轴臂，计算 Favail 的"最坏组合"，并给出 Kd 上限（etask = 10 mm、留 20% 余量）。★★
    提示
    最坏：τg = 18、r = 0.9 → Favail = (30−18−2)/0.9 ≈ 11.1 N → Kmax = 0.8×11.1/0.01 ≈ 890 N/m。注意这是"最坏方向"的答案，其他方向可以更高。
  3. 用片段 3 的场景扫描 v_max ∈ {5, 10, 20, 50} mm/s，记录无防护时的峰值力，验证"接近越快、卷绕时间越短、峰值越小"的趋势；再解释为什么把 v_max 调到 50 mm/s 仍不是"解决方案"。★★
    提示
    卷绕量 ≈ k_i·e_f·t_free ∝ 1/v_max；50 mm/s 时峰值降到约 38 N，仍在超调区间，且更快的接近在刚性环境上引入更高的撞击动能，两头不讨好。
  4. 设计"参考调速器"的完整状态机：给出进入条件（需求力 > 0.8Favail 持续 20 ms）、牵引速率（0.2 s）、退出条件（需求力 < 0.5Favail 持续 100 ms）与滞回理由，并讨论它与第 025 章速度限制、第 053 章平衡门控的接口关系。★★★
    提示
    20 ms 进入延时防误触发，100 ms 退出延时防边界抖动；调速器改参考、限速器改速度上限、平衡门控改刚度，三者都是"用时间/状态换可行性"，接口处要统一用"需求力预算"这一个公共量做判据，避免各自为政。

小结

  • 饱和 = 虚拟模型的临时失效：失真项 Δτ = τapp − τcmd 让阻抗方程不再成立，机器人退化为上限为 τmax 的恒力源，但系统仍然无源。
  • 力预算 Favail = (τmax − 重力 − 摩擦)/r 是参数设计的第一约束：Kd ≤ 0.8Favail/etask，按最坏构型取数。
  • 三件套：软缩放（体面降级）、参考调速器（用时间换力）、卷绕防护（下一章），截断只是底线。
  • 监控指标：扭矩利用率、饱和占空比、Δτ 均方值；评估性能只看未饱和段。
  • 本章实测的卷绕事故：限速伺服下 2.5 s 空转积累 5 mm 偏置，接触峰值 85.8 N；冻结积分后 20.0 N 超调归零。
