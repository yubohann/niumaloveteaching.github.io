第 050 章：基于扰动观测器的阻抗控制

摩擦、负载变化、模型误差都在偷偷改写阻抗控制的"出厂设定"。扰动观测器（DOB）把它们统一估成一个扰动项前馈抵消，让内环表现得像理想的名义模型，而阻抗参数只需在那个理想模型上设计。

  • 主题：扰动观测器（DOB）/ 内环模型对齐
  • 关键公式：d̂ = Q(s)·(Mnẍ − τ)，τ = τcmd − d̂ ⟹ Mnẍ = τcmd + (1−Q)d
  • 预计学时：55 分钟
  • 前置章节：第 049 章（基于观测器的外力估计）

学习目标

  • 理解扰动观测器与外力观测器的角色差异：一个"修系统"，一个"报真相"。
  • 会推导 DOB 的闭环作用：为什么名义模型误差与摩擦被乘上 (1−Q) 后从系统里"消失"。
  • 掌握 Q 滤波器设计：带宽、阶数与鲁棒性条件 |Δ(1−Q)| < 1 的相互关系。
  • 理解"加速度从哪来"这一实现难题，以及工程上如何用速度观测器绕开二次差分。
  • 能写出 DOB 前馈补偿的代码并与无补偿版本对比稳态精度。

背景与动机

第 013 章讲过基于动力学模型的阻抗控制：如果你能准确算出 M(q)、C、g，就能把它们整体前馈抵消，让机器人的"物理身体"变成你设计的虚拟质量-弹簧-阻尼。但真机上总有算不准的东西：库仑摩擦随温度变化、负载换了个抓手就变、减速器的弹性与齿隙无法建模。这些误差会让名义阻抗和实际手感出现偏差，装配时"说好的 20 N 压不上去"，示教时"松手它自己慢慢滑"。

扰动观测器（disturbance observer, DOB）的思路是把所有"不该有却有"的力矩统称为一个扰动 d，用名义模型的输入输出去反推它，然后把 −d̂ 叠加到控制量上。它像一位贴身管家：不管谁在系统里捣乱，他都实时记账、实时抵消，让上层控制器看到的永远是一个干净的、参数已知的"理想机器人"。与第 049 章的区别一句话说清：第 049 章要"真相"（外力是多少），本章要"秩序"（系统是否听话）。

核心原理

1. 名义模型与扰动定义

先写"真实系统"与"你手里的模型"。以一维平移轴为例（旋转关节同理，把量换成力矩与惯量）：

Mnẍ = τ + d，其中 d = (Mn − M)ẍ − 摩擦力 − 重力残差 + 外接触力 + … Mn：设计者手里的名义惯量；d：所有未建模效应的总称（N）；τ：控制力矩（可测/可算）

理想情况下 d = 0，系统就是名义模型。DOB 要做的，是在线估计 d 并抵消它。注意这里把外力也算进了 d，这埋着一个设计上的哲学问题：如果你的目的是"对外力柔顺"，就别把外力一起抵掉（后文设计一节专门处理）。

2. DOB 的结构与闭环结论

加速度可获取时，扰动的直接估计式是 d̂ = Mnẍ − τ（把定义式改写成"已知量减已知量"）。直接用太吵，串一个低通 Q(s) 再输出，并把估计值前馈抵消：

d̂ = Q(s)·(Mnẍ − τ)， τ = τcmd − d̂

把两式联立，消去 d̂：

Mnẍ = τcmd + (1 − Q(s))·d 扰动从 d 变成 (1−Q)d：低于 Q 带宽的扰动被"清零"，高于带宽的原样保留

这是全章最核心的一条式子。它的物理读法是：Q(s) 像一只"低频放大器的手"，低频扰动被估计得很准、抵消得很干净；高频扰动估计噪声太大，干脆放行。因此 Q 的带宽决定了系统的"干净程度"：fc = 50 Hz 的 Q 能把 50 Hz 以下的摩擦、负载偏差压掉一到两个数量级（|1−Q| 在 1 Hz 处约 3×10−2）。

3. 鲁棒性：Q 带宽不能无限宽

把"扰动"再细分，会看到其中包含模型误差的部分 Δ(jω)（|Δ| 表示相对误差的幅值上界）。闭环稳定性对模型误差的要求（小增益条件）是：

|Δ(jω)| · |1 − Q(jω)| < 1，对所有 ω 若名义模型在高频有 30% 的相对误差（|Δ| = 0.3），则 (1−Q) 必须小于约 3.3，这通常容易满足；真正苛刻的是相位滞后叠加的情形

工程上更常用的经验是"Q 的截止频率不超过最大建模误差频带起点"：例如柔性关节的第一阶谐振在 80 Hz，那么 Q 的带宽就取 30–50 Hz，绝不要骑到谐振上。带宽选定后，Q 的阶数决定过渡带的陡度：一阶简单但抑制带窄，二阶（巴特沃斯）是工程甜点，本章实现取二阶、fc = 50 Hz。

4. 加速度从哪来：实现层的真正难点

d̂ = Q(Mnẍ − τ) 里的 ẍ 是魔鬼。第 048 章已经算出：二次差分的噪声可达 0.7 m/s²（编码器 1 µm、1 kHz），乘 Mn 后完全是噪声。三条可行路线：

  • 速度差分 + α-β 观测量：用第 048 章的 v̂[k]−v̂[k−1] 作加速度估计，噪声约 0.05–0.1 m/s²，经 Q 滤波后可用；这是最常用的工程折衷。
  • 加速度计：装在腕部/关节上，直接测惯性加速度，信噪比好但要处理重力投影与安装误差。
  • 高增益观测器：用位置测量扩展出加速度状态，本质是把"差分"换成"动态估计"。
设计决策：为什么 DOB 要做在关节/驱动层？笛卡尔层的问题在哪里？

名义惯量 Mn 在关节层最容易写准（电机+减速器+连杆的等效惯量随姿态变化小）；笛卡尔层的 Mn 要经过雅可比变换，奇异位形附近会放大。所以标准做法：关节层 DOB 负责把"电气-机械"通道擦干净，笛卡尔阻抗律在外环设计，第 013 章"内环模型化、外环柔顺化"的又一次落地。

实现思路与设计

控制周期 1 ms；每个关节独立跑一个 DOB：

  1. 名义参数：Mn 由 CAD 或第 051 章的辨识给出；误差 20% 以内都能接受（误差会被 (1−Q) 残留，不破坏稳定）。
  2. 加速度估计：α-β 观测器速度 + 一阶差分，α = 0.4；差分结果再过 50 Hz 低通（可并入 Q 一起算）。
  3. Q 滤波器：二阶巴特沃斯，fc = 50 Hz；输入是 (Mnâ − τ)，输出 d̂。
  4. 前馈叠加：τ = τimp − d̂；对 τ 做限幅（电机能力），d̂ 做限幅（防估计飞车，通常取额定力矩的 2 倍）。
  5. 外力与柔顺的关系：DOB 的扰动里包含外力；若阻抗律已按 −Fext 让位，再让 DOB 抵消外力会"掐死"柔顺。工程做法：在外力较大时冻结或部分衰减 DOB 对低频外力的抵消通道（利用外力的"持续、低频、有方向"特征与摩擦区分，第 096 章展开）。
  6. 使能开关：困在奇异点/急停恢复后，先让 Q 滤波状态清零再使能，避免 d̂ 里的历史值导致"抽搐"。

验收方法：固定姿态下给关节一个小的方波力矩指令，无 DOB 时因摩擦会有"死区+黏滑"，有 DOB 后响应接近一阶惯性特征；用位置环带宽的提升定量验收。

关键代码与解读

片段 1：一维扰动观测器

import numpy as np

class DisturbanceObserver:
    """一维 DOB：把摩擦、负载、模型误差统一估成 d 并前馈抵消。
    d_hat = Q(s) * (m_n * a_meas - tau)，Q 取二阶巴特沃斯。"""
    def __init__(self, m_n=1.0, fc=50.0, fs=1000.0, d_lim=50.0):
        self.m_n = m_n
        self.d_lim = d_lim            # 扰动估计限幅：防止估计“飞车”
        Kc = np.tan(np.pi * fc / fs)
        norm = 1.0 / (1.0 + np.sqrt(2.0) * Kc + Kc * Kc)
        self.b0, self.b1, self.b2 = Kc*Kc*norm, 2*Kc*Kc*norm, Kc*Kc*norm
        self.a1 = 2.0 * (Kc*Kc - 1.0) * norm
        self.a2 = (1.0 - np.sqrt(2.0)*Kc + Kc*Kc) * norm
        self.x1 = self.x2 = self.y1 = self.y2 = 0.0
        self.d_hat = 0.0

    def _qfilter(self, u):
        y = (self.b0*u + self.b1*self.x1 + self.b2*self.x2
             - self.a1*self.y1 - self.a2*self.y2)
        self.x2, self.x1 = self.x1, u
        self.y2, self.y1 = self.y1, y
        return y

    def update(self, tau, a_meas):
        raw = self.m_n * a_meas - tau          # 名义模型下的“异常力矩”
        self.d_hat = float(np.clip(self._qfilter(raw), -self.d_lim, self.d_lim))
        return self.d_hat

    def compensation(self, tau_cmd):
        # 前馈抵消：等价于把真实对象“拉回”名义模型 m_n
        return tau_cmd - self.d_hat

解读：（1）raw = mnâ − τ 一行有两个"信源"：â 来自观测器、τ 来自指令（或电机反馈）。为了让两者时间对齐，加速度估计不能引入额外延迟，否则 d̂ 会带错相位、抵消效果打折甚至注入振荡。（2）d̂ 限幅不是保守主义，是必须的安全件：一旦速度估计出错误跳变，无限制的 d̂ 会瞬间把电机推向最大力矩。（3）Q 的实现与第 047/048 的 biquad 同构，看到"滤波 + 反馈"字样时就该想起这五行的标准结构。注意 Q 的相位也参与了鲁棒性账本，所以 fc 不要骑在柔性谐振上。

片段 2：有/无 DOB 的阻抗控制对比仿真

# 真实对象：m_true 质量 + 3 N 库仑摩擦；名义模型故意写小 10% 考验鲁棒性
m_true, fric, dt = 1.0, 3.0, 1e-3
k_d, d_d, x_ref = 300.0, 50.0, 0.005
result = {}
for use_dob in (False, True):
    dob = DisturbanceObserver(m_n=0.9, fc=50.0)
    x = v = -0.02       # 从目标左侧 20 mm 出发，弹簧先攒出足以顶开静摩擦的力
    for k in range(3000):
        tau_imp = -k_d * (x - x_ref) - d_d * v      # 简化阻抗律(软目标)
        tau = dob.compensation(tau_imp) if use_dob else tau_imp
        # 库仑摩擦：静止时提供静摩擦“顶住”小力，运动时方向相反
        if abs(v) < 1e-6 and abs(tau_imp) < fric:
            fr = tau_imp                            # 被静摩擦完全顶住
        else:
            fr = fric if tau_imp > 0 else -fric
        a = (tau - fr) / m_true
        v += a * dt
        x += v * dt
        dob.update(tau, a)      # 教学简写：真机里 a 用 α-β 观测器差分估计
    result[use_dob] = x
print(f"无 DOB 稳态位置: {result[False]*1000:7.2f} mm (目标 5 mm)")
print(f"有 DOB 稳态位置: {result[True]*1000:7.2f} mm (目标 5 mm)")

解读：跑出来的对比非常典型：无 DOB 时，摩擦力 3 N 需要弹簧提供同等力才能"顶住"，稳态停在距目标 kd 偏差约 3 N/300 N/m = 10 mm 的位置（打印值会是 −5 mm 附近：被摩擦锁在目标之前、弹簧力不足以顶开）；有 DOB 时，d̂ 把摩擦估出来并前馈补掉，稳态误差回到毫米以内，甚至名义模型写小 10% 也不影响，误差被 (1−Q) 压掉。把 use_dob=True 的 fc 改成 10 Hz 再跑一次，你会看到低频摩擦依然被补掉（残余略增）；反过来把 fc 提到 300 Hz，稳态精度更好，但若把加速度换成含噪声的估计（给 a 加 0.05 m/s² 白噪声），d̂ 就会开始"沙沙"抖动，这就是带宽换噪声的现场演示。

片段 3：Q 带宽的权衡清单

def dob_tradeoff(fc_list):
    """对每个候选带宽列出两个数：
    1 Hz 处扰动残余 |1-Q|（越小越好）；100 Hz 处噪声通过率 |Q|（越小越好）。"""
    for fc in fc_list:
        wc = 2.0 * np.pi * fc
        def q_mag(w):                     # 二阶巴特沃斯幅频
            return 1.0 / np.sqrt(1.0 + (w / wc) ** 4)
        def q_val(w):                     # 二阶巴特沃斯复频响(用于 |1-Q|)
            s = 1j * w
            return wc*wc / (s*s + np.sqrt(2.0)*wc*s + wc*wc)
        resid = abs(1.0 - q_val(2.0 * np.pi * 1.0))     # 低频扰动残留比例
        noise = q_mag(2.0 * np.pi * 100.0)         # 高频噪声被放行的比例
        print(f"fc={fc:5.0f} Hz  扰动残余@1Hz={resid:7.4f}  "
              f"噪声通过@100Hz={noise:6.3f}")

dob_tradeoff([10.0, 30.0, 50.0, 100.0, 300.0])
# 结论：fc 越高低频残余越小，但 100 Hz 噪声放行越多：
# 且 fc 逼近结构谐振(常见 80~150 Hz)时鲁棒性急剧恶化，故 30~80 Hz 最常用

解读：这张小表是整章设计哲学的数字版：不存在"既不牺牲精度又不吃噪声"的带宽，只有与你的结构特性匹配的带宽。选择流程建议三步：① 测出结构第一阶谐振频率（敲击试验或频响扫频）；② 取谐振频率的 1/2–1/3 作为 fc 上限；③ 在这个上限以下选"中频扰动（执行器摩擦的起伏、负载摆动）抑制足够"的最小值。还有一个容易忽略的细节：Q 的群延迟约为 1/(2πfc) 量级（fc = 50 Hz 时 3–5 ms），它会进入 DOB 环路自身的相位账本，这也是 fc 不能无限升高的另一个原因。

常见坑

  • Q 带宽骑上结构谐振：fc 取到 150 Hz 而关节柔性谐振在 80 Hz，表现为金属感的"嗡嗡"声。修复：fc ≤ 谐振频率的 1/3，并在 Q 设计时把该频段衰减算进验算。
  • 用裸二次差分算加速度：噪声量级 0.7 m/s²，d̂ 输出成噪声发生器。修复：α-β 观测器速度差分，或加速度计，或高增益观测器。
  • 把外力一路抵消掉：DOB 把接触力也当成扰动补掉，人推不动、装配按不下去，柔顺完全失效。修复：外力的"持续、定向、低频"特征识别后冻结抵消通道，或做在关节层只补偿摩擦（第 096 章）。
  • d̂ 不限幅：估计异常时电机会被推满力矩，是安全隐患。修复：按额定力矩的 1.5–2 倍限幅，并加变化率限制。
  • 名义模型符号/单位错：Mn 用错正负号，d̂ 会变成"正反馈放大器"，系统直接振荡。修复：上电后用"手动推关节、看 d̂ 是否与推力反号"做第一项检查（摆好急停按钮）。

练习与思考

  1. 推导 Mnẍ = τcmd + (1−Q)d：从 d 的定义出发，代入 τ = τcmd − Q(Mnẍ − τ)，整理得闭环方程，并说明 Q = 1（理想）与 Q = 0（失效）两个极限的物理含义。★
    提示
    Q=1 时扰动完全消失（理想 DOB）；Q=0 时 d̂ = 0，退化为无补偿。现实是 Q 在低频接近 1、高频接近 0。
  2. 用片段 2 的仿真，把名义模型从 0.9 改到 0.5（相差 50%），记录稳态位置误差与振荡情况，并结合小增益条件解释"名义模型可以错，但不能错到破坏鲁棒性"。★★
    提示
    Δ 变大后 (1−Q)Δ 在高频接近 Δ，相位裕度下降；先出现轻微超调，再走向振荡。名义模型的"安全误差"通常 20–30% 以内。
  3. 把片段 2 的 dob.update(tau, a) 换成带噪声版本（a 加 0.05 m/s² 白噪声、τ 加 0.2 N 噪声），分别在 fc = 20/50/200 Hz 下记录位置误差的噪声 RMS，验证"带宽换噪声"的定量关系。★★
    提示
    d̂ 噪声 ≈ Q 带宽内通过的 (mnσa, στ) 组合，位置噪声再乘 1/kd；预期误差 RMS 随 fc 近似线性增大，直到 fc 逼近谐振。
  4. 设计"外力部分冻结"策略：给出一个可编程的门（如 |d̂| > 5 N 且持续 0.3 s 且方向稳定 → 判为外力，冻结这部分抵消），写出状态机与阈值理由，并讨论它和第 096 章接触检测的关系。★★★
    提示
    摩擦扰动与运动方向强相关、符号随速度翻转；外力方向与运动无关。判据：把 d̂ 分解为"与速度相关"与"与速度无关"两部分，后者的持续分量归为外力；阈值/持续时间用于滤掉瞬态。

小结

  • DOB 把摩擦、负载与模型误差统一为一个扰动 d，用 d̂ = Q(Mnâ − τ) 估计并前馈抵消。
  • 闭环结论：扰动被乘上 (1−Q)，低频被清除、高频保留；Q 的带宽是"干净程度"的旋钮。
  • Q 带宽受鲁棒性约束（|Δ(1−Q)| < 1、远离结构谐振），工程常用 30–80 Hz 二阶巴特沃斯。
  • 加速度估计是实现难点：用 α-β 速度差分或加速度计，绝不做裸二次差分。
  • 小心把外力一起抵消：柔顺任务需要"选择性补偿"，这是 DOB 与阻抗外环的接口设计问题。
  • 下一章转向参数本身：当惯性、摩擦、重力系数未知时，用递推最小二乘让机器人"边干边学"，为 DOB、观测器与重力补偿提供模型供给。
