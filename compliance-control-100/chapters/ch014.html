第一篇 · 基础、建模与稳定性

第 014 章：无模型阻抗控制

没有可信的动力学模型、也不许停机辨识，只剩"速度指令 + 力传感器"两样东西。把导纳从二阶降到一阶、把惯性从方程里拿掉，这是工业控制器上最常见的柔顺实现。

  • 主题：阻抗控制 / 无模型实现（速度级导纳）
  • 关键公式：Daδ̇ + Kaδ = Fext，δ = x − xd；时间常数 τa = Da/Ka
  • 预计学时：55 分钟
  • 前置章节：第 013 章

学习目标

  • 理解"无模型"的准确定义：不建立 M(q)、C(q,q̇)、g(q)，把动力学交给内环速度环去扛。
  • 会推导速度级一阶导纳 Daδ̇ + Kaδ = Fext，并解释它为什么天然抗漂移。
  • 掌握三条递进方案：纯阻尼注入、一阶导纳、软件二阶导纳，各自能实现什么、代价是什么。
  • 会用频率分离原则判断可行性：导纳带宽 Ka/Da 必须远低于速度环带宽，并给出量化规则。
  • 能识别无模型方案的典型故障：接触振荡（速度环延迟）、恒力漂移（缺弹簧项/重力未补）、速度映射用错 J 与 JT。

背景与动机

上一章的代价很直白：一套可信的动力学模型。可现实里大量机器人不给这个条件，控制器只开放"速度指令"，关节力矩不可见；或者可以读力矩但参数辨识排不进项目预算；又或者传动柔性让刚体模型在关心的频段根本不准。这时做柔顺，只剩最硬的两样资源：一条响应不错的速度环，和一只力传感器。

无模型方法的策略是选择一种对模型不敏感的柔顺形式：把虚拟阻抗从二阶降到一阶（去掉惯性项），让"力 → 速度"的直接映射承担柔顺，超出的动态全部甩给速度环。本章给出这套方法的推导、实现与边界，国内外的工业力控功能（拖动示教、柔顺装配的"力控速度模式"）大多就是它的变体。

核心原理

1. "无模型"到底无了什么、留了什么

先划清边界：无模型方案不建立也不使用机器人动力学 M(q)q̈ + C(q,q̇)q̇ + g(q)；运动学仍然是必须的（要把任务方向的力/速度换算到关节），工具重力的静态补偿也仍然需要（第 011 章），"无模型"指的是无动力学模型。方案的立足点是内环速度环：一个带宽几十到几百 rad/s 的反馈环，把"电机转多快"这件事做得相当可靠。记速度环带宽 ωv，只要外环导纳的工作带宽远低于 ωv，机器人在外环眼里就是一台"速度源"：命令多大的速度，它就走出多大的速度，中间的质量、摩擦、重力都被包裹在速度环内部消化。

2. 一阶导纳的推导：从模板中拿掉惯性

回顾第 007 章的端口模板 Mdδ̈ + Ddδ̇ + Kdδ = Fext。速度接口能可靠执行的是速度，不是加速度；而惯性项 Mdδ̈ 恰恰是"加速度级"的条目。把它拿掉，得到一阶形式：

Daδ̇ + Kaδ = Fext ， δ = x − xd Da：虚拟阻尼（N·s/m）；Ka：虚拟刚度（N/m）；两边除以 Da 得速度命令：δ̇ = (Fext − Kaδ)/Da

传递函数与两条关键指标一步可得：δ(s)/F(s) = 1/(Das + Ka)，所以

稳态柔量 = 1/Ka（同样的"让多少"含义）， 时间常数 τa = Da/Ka（响应多快） 例：Ka=500 N/m、τa=0.1 s → Da=50 N·s/m

三个性质值得逐条品味。第一，抗漂移是结构性的：只要回路的输入 F 有界，稳态偏差被 Kaδ=F 钉住，不会像第 002 章的纯阻尼结构（Ka=0）那样被力偏置推着"无界漫游"（这里只有一个极点、无需二次积分）；这也是现场"一阶导纳调得动、纯阻尼总漂"的原因。第二，没有惯性就没有振荡：一阶系统的时间响应是单调指数，不存在超调，代价是失去"质量手感"，快速推拉时像在搅蜂蜜，没有重物该有的惯性。第三，参数二换二：Ka 决定让位多少、Da 由目标时间常数反推 Da=Kaτa，两分钟就能整定完，对比二阶方案里 M/D/K 的三角权衡，这就是它流行的工程原因。

工程直觉：一阶导纳像给机器人装了一个"黏滞手柄"，推多快它跟多快、推住它停在约定位置；你不去感受它的重量，也感受不到它的脾气。

3. 三档方案：阻尼、一阶、软件二阶

方案方程能力病灶
纯阻尼注入δ̇ = Fext/Da最简单：力越大退越快；拖动示教的"轻推"手感没有静态平衡点，常力下持续漂移；只适合"人手一直扶着"的交互
一阶导纳（推荐）Daδ̇ + Kaδ = Fext有静态柔量、无超调、抗漂移；速度接口原生适配无惯性手感；高频段柔量以 −20 dB/dec 衰减，力控制带宽有限
软件二阶导纳Maδ̈ + Daδ̇ + Kaδ = Fext，积分得速度命令可塑造"质量"与物性手感；与第 002 章一致要求速度环能瞬时兑现加速度（加速度越大越吃力）；力偏置在二次积分下重新带来漂移风险

三档的共同上限由同一条频率分离原则决定：导纳的等效带宽必须让位给速度环。一阶导纳的带宽就是 ωa = Ka/Da = 1/τa；工程规则取 ωv ≥ 5ωa，即速度环带宽至少要 5 倍于导纳带宽。例子：τa=0.1 s（ωa=10 rad/s）要求 ωv ≥ 50 rad/s，多数工业速度环在 30–150 rad/s，前者勉强、后者从容。τa 取 0.02 s（"跟手极快"）时要求 250 rad/s，很多平台已经做不到，硬调会出现接触振荡（第 5 节量化）。

4. 运动学与静态补偿：仍然逃不掉的功课

无模型方案里两种映射必须分清：速度用 J−1（或伪逆），力用 JT。任务方向导纳算出的速度命令 vtask（m/s）要变成关节速度 q̇cmd = J−1vtask；而力传感器测到的法兰 wrench 要在任务方向进行投影时，用 JT 把关节/法兰量联起来（或在法兰系直接投影）。把两者搞混是"越推越歪"的经典事故。静态补偿方面：工具重力的姿态相关项（第 011 章公式）同流水线照做；本体重力则依赖速度环的内建补偿（大多数驱动器的速度环自带力矩前馈/重力处理），无模型不是"无工程量"，只是工程量的落点从控制器挪到了驱动器与标定。

5. 稳定性预算：延迟在哪儿、代价是多少

无模型方案的稳定裕度几乎全部由"延迟账"构成：力传感滤波延迟、通信与采样延迟、速度环等效滞后。把速度环近似成一阶滞后 τv（等效 ωv=1/τv），接触刚度 Kenv 从环境折回回路，稳定条件可以粗估为

Kaτa ≥ Kenv·(τv + τf)·κ ，κ 为 0.5–1 的工程系数 τf：力滤波时间常数；本质是"阻尼要能吃掉延迟带来的相位滞后"

用数字感受：Ka=500、τa=0.1 时左边是 50 N·s/m；环境 105 N/m 的刚性工件、速度环滞后 5 ms、力滤波 5 ms，右边是 105×0.010×0.5=500，左边差一个数量级，说明这套参数碰刚性环境必振：要么加大 Da（τa 拉长）把左边抬上去，要么加滤波/降速度环带宽的等效延迟（把右边压下来），要么承认它只适合软环境（Kenv ≤ 104 量级）。第 016 章会给导纳控制完整的稳定判据，本章先记住这张"延迟账"的直觉：无模型方案的鲁棒性不是免费的，它用"可实现的导纳带宽"换来的。

实现思路与设计

速度接口下的一阶导纳实现清单：

  1. 信号链：力传感器 → 零偏与工具重力扣除（第 011 章）→ 投影到任务方向 F → 死区（0.3 N 量级）→ 低通（τf=3–10 ms）。
  2. 导纳核：δ̇ = (F − Kaδ)/Da；用前向欧拉即可（一阶系统对步长不敏感），δ 做位置限幅（±50 mm）。
  3. 速度合成：vcmd = ẋd + δ̇；任务速度限幅（如 ±0.25 m/s）后经 J−1 变关节速度下发。
  4. 参数整定：Ka 由"可接受让位"反推；τa 由"跟手速度"取 0.05–0.3 s；Da=Kaτa；最后用 ωv ≥ 5/τa 校核平台。
  5. 验收：恒力台阶测试（看稳态柔量 1/Ka 与时间常数）、手推测试（手感一致性）、刚性环境推压（看是否振荡、用第 5 节不等式定位问题）。
设计决策：为什么商业产品常用速度级一阶导纳，二阶方案少见？

三个工程原因：其一，参数少、整定快，Ka、τa 两个旋钮，现场工程师半小时能教会；其二，行为可预测，一阶系统无超调、无漂移，出错模式少，售后成本低；其三，延迟容忍度高，一阶导纳只有一个参数决定带宽，厂商可以把 τa 卡在"平台一定能达到"的范围（通常 0.05–0.2 s），不去赌用户的二阶参数。你在项目中想用二阶（比如需要惯量手感）时，先把这三笔账对齐：平台速度环带宽、延迟预算、以及现场愿不愿意理解 M/D/K 三角。多数交付场景下，"稳、够用、可解释"比"手感最像"值钱。

关键代码与解读

片段 1：一阶导纳控制器，20 行、两个参数

import numpy as np

class FirstOrderAdmittance:
    """速度级一阶导纳：D·δ̇ + K·δ = F，输出速度命令（无动力学模型）。"""
    def __init__(self, k_a=500.0, tau_a=0.1, d_a=None, dt=1e-3,
                 f_dead=0.3, d_lim=0.05):
        self.k_a = k_a
        # 阻尼默认由目标时间常数反推：D = K·τ；纯阻尼场景可直接给 d_a
        self.d_a = d_a if d_a is not None else k_a * tau_a
        self.dt = dt
        self.f_dead = f_dead            # 力死区：噪声底约 0.1 N
        self.d_lim = d_lim              # 偏差限幅：异常力时不产生大位移
        self.delta = 0.0                # 偏差状态：唯一的状态，一阶的优势

    def step(self, f_ext, v_d=0.0):
        f = f_ext if abs(f_ext) > self.f_dead else 0.0
        # 一阶核心：速度 = (力 − 弹簧项)/阻尼；无加速度、无二次积分
        d_dot = (f - self.k_a * self.delta) / self.d_a
        self.delta += d_dot * self.dt   # 前向欧拉足够：一阶系统无振荡模式
        self.delta = float(np.clip(self.delta, -self.d_lim, self.d_lim))
        return v_d + d_dot              # 叠加到轨迹速度上 → 交给速度环

# 对照第 002 章二阶导纳：状态从 (x, v) 减到 (δ)；
# 传动/摩擦/重力全在速度环内消化，控制器只活在外环的低频世界里

解读：这是全课程最短的控制器，但每一行都可以与二阶版本对照着读。状态只有一个 δ：没有速度积分器，意味着"常力 → 速度积分 → 漂移"的路径被物理切断，这就是抗漂移的结构性来源；力矩偏置最多把 δ 推到 F/Ka 停住，不会无限跑。d_dot 直接输出为速度命令：在速度接口上不需要任何"积分成位置"的步骤（那是位置接口的事，第 002 章），从而少一次积分、少一层状态、少一分漂移风险。前向欧拉够用：一阶线性系统的显式欧拉稳定域很宽（dt < 2τ_a 即可），不必像二阶那样讲究半隐式；但 d_a 很小时（τa 很小、D 很小）仍需检查 dt·k_a/d_a 的离散化误差，一个经验线是 dt < τ_a/10（0.1 s 对应 1 ms，绰绰有余）。时间常数的物理感：τa=0.1 s 意味着"推上去大约 0.23 s 达到 90% 让位"，快过绝大多数装配操作的需求，又慢于速度环的时间尺度，这就是它在工业上"刚好合适"的原因。

片段 2：速度接口机器人上的对照实验，从纯阻尼到一阶导纳

# 机器人模型：内环速度环 ≈ 一阶滞后（τ_v=5ms），环境为墙面
k_env, xe = 1e4, 0.05          # 软一点的墙（1e4 N/m），无模型方案的主场
tau_v, dt = 5e-3, 1e-3

def run(k_a, tau_a, d_a=None, t_end=3.0):
    ctrl = FirstOrderAdmittance(k_a, tau_a, d_a=d_a, dt=dt)
    x, v = 0.0, 0.0
    log = []
    for i in range(int(t_end/dt)):
        t = i*dt
        xd = 0.06*min(1.0, t)      # 参考斜坡：1 s 匀速推到墙内 1 cm
        f = -k_env*(x - xe) if x > xe else 0.0    # 接触力（推挡方向为负）
        v_cmd = ctrl.step(f, v_d=0.06 if t < 1.0 else 0.0)
        # 速度环：一阶趋向 v_cmd，建模"速度源"特性的最小模型
        v += (v_cmd - v) * (dt / (tau_v + dt))
        x += v * dt
        log.append((x, f))
    return np.array(log)

for tag, k_a, tau_a, d_a in (("纯阻尼 K=0", 0.0, 0.1, 50.0),
                             ("一阶导纳 K=500", 500.0, 0.1, None),
                             ("一阶导纳 更软 K=250", 250.0, 0.1, None)):
    log = run(k_a, tau_a, d_a)
    x_end, f_end = log[-1]
    print(f"{tag:>18}: 末端 x={x_end*1e3:5.2f}mm  稳态力={f_end:6.2f}N")

解读：三种配置的对照回答了两个关键问题。纯阻尼（K=0，D=50）在参考斜坡结束后被接触力推回墙面边缘，最终 F=0、末位置退回 49.90 mm：力在这里"无处驻扎"；这在示教场景没问题（力的存在本身在驱动运动），但在需要"稳住某个力"的场景里没有归宿。一阶导纳（K=500）则找到平衡：接触力与偏差相互平衡，末端停在墙内 50.48 mm 处，稳态力 −4.76 N 由 Ka、xd、Kenv 联立决定（对比第 002 章稳态公式，注意这里没有 M，平衡点与质量无关；与第 003 章串联公式一致：KeqΔx≈476×0.01≈4.76 N）。Ka 减半到 250 时稳态力近似减半到 −2.44 N（Kenv≫Ka 区间里 F≈KaΔ），验证 Ka 的"软硬旋钮"语义与二阶方案一致。代码里速度环的"一阶趋近"是最小可信建模：真实速度环还有电流环、摩擦、量化等，但对外环而言它们都折叠进 τv，下一片段专门研究 τv 的影响。两个实现细节：参考用了 1 s 斜坡、且把参考速度 0.06 m/s 经 v_d 前馈给控制器，否则机器人不会被带向墙面；纯阻尼行显式给 d_a=50，因为 ka=0 时"由 K·τ 反推 D"这条路走不通。真机移植时的顺序建议：先在仿真里把这三种配置跑通（确认手势正确），再到软环境上实测纯阻尼，最后接入一阶导纳并做 τa 扫描。

片段 3：延迟预算扫描，速度环带宽决定导纳能"多快"

# 固定导纳参数（K=500, τ_a=0.1s），只扫速度环滞后 τ_v 与力滤波 τ_f
import numpy as np

def run_tau(tau_v, tau_f):
    k_a, tau_a, dt, t_end = 500.0, 0.1, 1e-3, 3.0
    d_a = k_a * tau_a
    delta, f_f, x, v = 0.0, 0.0, 0.0, 0.0
    f_hist = []
    for i in range(int(t_end/dt)):
        f = -k_env*(x - xe) if x > xe else 0.0
        f_f += (f - f_f) * dt / (tau_f + dt)         # 一阶力滤波
        d_dot = (f_f - k_a*delta) / d_a
        delta = np.clip(delta + d_dot*dt, -0.05, 0.05)
        v_d = 0.06 if i*dt < 1.0 else 0.0            # 与片段 2 相同的接近斜坡
        v += (d_dot + v_d - v) * dt / (tau_v + dt)   # 速度环一阶滞后
        x += v*dt
        f_hist.append(f)
    f_hist = np.array(f_hist[-1500:])                # 末段 1.5 秒
    return f_hist.std(), f_hist.mean()

print(f"{'tau_v(ms)':>9} {'tau_f(ms)':>9} {'力波动σ(N)':>10} {'均值(N)':>8}")
for tau_v in (0.002, 0.005, 0.02):
    for tau_f in (0.002, 0.010, 0.030):
        sd, mean = run_tau(tau_v, tau_f)
        print(f"{tau_v*1e3:9.0f} {tau_f*1e3:9.0f} {sd:10.3f} {mean:8.2f}")

解读：这张 3×3 表是无模型方案的"稳定性地图"。预期趋势：τv 增大（速度环变慢）与 τf 增大（滤波变重）都会让力波动 σ 上升，当总延迟逼近 τa 的量级（10 ms 级别对 100 ms）时波动加速恶化；某些组合会出现持续振荡（σ 达数牛以上），那就是上一节不等式的破线点。反之，2 ms + 2 ms 的"低延迟组合"应给出接近数值零的 σ（纯仿真无传感器噪声，真机的下限由噪声底决定，约 0.1–0.3 N 量级），说明参数还有富余。读表的方法：先看均值（是否稳住目标力），再看 σ（抖动预算）；均值一致而 σ 随延迟涨，说明结构没问题、稳定裕度在流失，此时应加大 τa（拉长导纳时间常数、把带宽让出来）；猛加力滤波只是把问题推迟。工程建议：把这张表作为项目初期的"平台体检"固定流程，用 2–3 组典型τ组合跑一遍，你就知道这台机器上"无模型柔顺"的天花板在哪里。

常见坑

  • 速度映射掉了 J−1/用了 JT：任务速度到关节速度必须过运动学逆映射，力才用转置。症状：某些方向"推着走"、某些方向"越推越乱"。修复：两条映射各写一个函数，注释里写明"速度 J−1、力 JT"。
  • 忘了速度限幅：大偏差或异常力时导纳输出速度无界，速度环全速冲出去。修复：导纳输出端与任务速度都限幅（如 0.25 m/s），并且限幅后清理积分/偏差状态的累积方向。
  • 一阶方案却要求"惯性手感"：用一阶导纳去做需要质量感的拟真交互（如模拟重物拖拽），怎么调都"不对味"。修复：接受它的边界，或改软件二阶并接受速度环可行性检查。
  • 硬环境上直接推高阶参数：在 Kenv=105 的钢件上沿用软环境的参数，接触后持续振荡。修复：先跑片段 3 的延迟预算表，按不等式回推 τa 下限，或降低 Ka 与任务速度。
  • 把重力完全"自动化"处理：假设速度环一定补偿了工具重力，换了重工具后不重新标定，恒力漂移如约而至。修复：工具标定与验证照第 011 章执行，任何"无模型"都不豁免这一步。

练习与思考

  1. 对一阶导纳 Dδ̇+Kδ=F 求阶跃响应 δ(t)，写出稳态值与时间常数，并证明响应无超调。★
    提示
    δ(t) = (F/K)(1 − e−Kt/D)；一个极点 −K/D，响应单调，超调为零。
  2. 用片段 2 把 Ka 分别设为 250、500、1000（τa 固定 0.1 s），先解析预测稳态力（联立 F=Kaδ 与 F=Kenv(x−xe)），再仿真核对。哪组"软硬"变化更明显？★★
    提示
    Keq=KaKenv/(Ka+Kenv)；Kenv=1e4 时 Ka 在 250–1000 间变化都会显著改变 Fss，而二阶方案里还要多操心 M，一阶的"即调即得"正是它的卖点。
  3. 改片段 2 的环境刚度：Kenv 从 104 提到 105，保持参数不变。先用第 5 节不等式判断是否会振荡，再仿真验证，最后给出让它在硬环境下稳定的两套参数改动（各写一句代价）。★★
    提示
    50 vs 500 的左边右边立刻破线；改动一：τa 从 0.1 s 加到 1 s（代价：响应迟钝）；改动二：力滤波加重到 20 ms 并降低 ωv（代价：响应迟滞、带宽下降）。
  4. 推导"纯阻尼无静态平衡"：在常力 F0 下 δ̇=F0/Da，说明 δ 随时间线性增长；若加入泄漏项 −δ/τL，稳态去哪了？给泄漏项的工程利弊各一条。★★★
    提示
    纯阻尼稳态速度不变→无界；泄漏后稳态 δ=F0τL/Da（有限）。利：防漂移；弊：持续慢力被误当成"泄漏"吃掉，手推手感变钝。
  5. 把片段 3 扩展成"平台体检报告"：设计三组测试（延迟扫描、刚度扫描、速度扫描），定义通过/否决判据，并写出报告里必须包含的三个数字。为什么说"力波动 σ"比"均值误差"更能反映平台能力？★★★
    提示
    σ 反映稳定裕度与延迟预算；均值可以靠加大 Ka 与推入深度修正，但 σ 超标意味着已经贴稳性边界。报告三数字：稳态力误差、波动 σ、以及"振荡临界时的最小 τa"。

小结

  • 无模型 = 不建动力学 M/C/g，把机体交给速度环，控制器只保留任务级导纳与运动学；工具重力等静态补偿仍然必做。
  • 一阶导纳 Dδ̇+Kδ=F：稳态柔量 1/Ka、时间常数 τa=Da/Ka；单极点、无超调、结构抗漂移，是速度接口上的工作马。
  • 三档方案递进：纯阻尼（无静态平衡）、一阶导纳（推荐）、软件二阶（有惯性手感但要求速度环兑现加速度）。
  • 可行性由延迟账决定：ωv ≥ 5/τa，稳定裕度 ∝ Kaτa 对 Kenv(τv+τf)；硬环境是这套方案的天敌。
  • 下一章把稳定性从"经验不等式"升级为"分析工具"：对阻抗控制回路做完整的建模与判据推导，看延迟、刚度、阻尼如何在复平面上决定生死。
