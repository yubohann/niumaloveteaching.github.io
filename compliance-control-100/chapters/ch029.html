第二篇 · 参数调节与交互任务

第 029 章：基于导纳控制的拖动示教

只有位置接口的机器人怎么被"拖"？用腕部力传感器测人手施力，经虚拟导纳变成位置命令，"零力引导"的手感全由 Md、Dd 两个数字决定，且必须先过工具重力补偿这道关。

  • 主题：拖动示教 / 导纳控制 / 力传感补偿
  • 关键公式：Mdẍ + Ddẋ = Fhuman，vss = Fhuman/Dd
  • 预计学时：50 分钟
  • 前置章节：第 028 章、第 025 章

学习目标

  • 理解导纳式拖动示教与第 028 章力矩式的本质差别：控制量从关节力矩变成位置命令，力的来源从关节力矩传感变成腕部力传感器。
  • 会围绕"零力引导"目标设计 Md、Dd：用 vss = F/D 反推"引导 100 mm/s 需要多少牛"，并解释虚拟质量决定起步手感。
  • 掌握工具重力补偿的最小二乘标定法：多姿态静止采样，解出传感器坐标系下的工具重力向量。
  • 理解为什么传感器零偏未标定会变成"恒定漂移速度"（vdrift = Fbias/Dd），以及上电自动偏置估计的写法。
  • 能列出这种方案的安全清单，把速度/加速度/工作空间限幅与使能逻辑接到导纳输出链上。

背景与动机

第 028 章的力矩级拖动示教效果最好，但它要求机器人开放关节力矩接口与关节力矩传感，而且依赖机械臂自己的重力/摩擦模型，换工具、加载荷都要重新标定。大量现有设备不具备这些条件：它们只有位置命令接口（甚至封闭的内环），能加的是一支腕部六维力/力矩传感器。于是就有了第二条路线：测力 → 虚拟导纳 → 修正位置命令。

这条路线把"拖动机器人"翻译成"力驱动机器人运动"：人手施加 5 N，机器人就按设计好的虚拟阻尼以对应速度移动；松手（力为零）就停。调得好时人手几乎感觉不到阻力，就是所谓的"零力引导"，从重度到轻触只需要很小的力就能引着机器走。但它有自己的一票工程问题：传感器测到的是人手力 + 工具自身重力的合成，工具重力不抵消，人手就得先"托着"工具；传感器零偏不校准，机器人会以恒定速度自己漂走。本章把这些讲全，并在最后与第 028 章做系统对比。

核心原理

1. 导纳式拖动的核心方程与"零力"含义

在任务空间（笛卡尔），把人手施加的外力 Fh ∈ R6 送进虚拟导纳：

Mdẍcmd + Ddẋcmd + Kd(xcmd − xr) = Fh Md：虚拟质量（kg）；Dd：虚拟阻尼（N·s/m）；Kd：虚拟刚度，示教时取 0；Fh 为六维力旋量

为什么 Kd = 0？与第 028 章同理：任何非零的虚拟弹簧都会把机器人拉向某个"期望位置"，人手必须持续用力与之对抗；零弹簧时"拖到哪停到哪"。Kd = 0 后剩下惯性 + 阻尼，稳态速度为：

vss = Fh / Dd "零力引导"的量化定义：让常用引导速度对应的手力尽量小，例如 100 mm/s 只需 3–5 N

代入数字感受设计：希望"轻触 3 N 就能以 100 mm/s 引导"，则 Dd = 3/0.1 = 30 N·s/m；希望"推 10 N 快走 250 mm/s"，则 Dd = 40。Dd 越小手感越"轻飘"但越难控制（松手后滑行远、噪声引起漂移），Dd 越大越"稳"但引导费力，这就是"零力引导"与"可控性"的取舍旋钮。Md 管起步：m 越大起步越"沉"，但它同时是抗噪声的"滤波器"（加速度噪声 ∝ 1/Md，第 038 章展开），示教场景一般取 2–5 kg。

2. 传感器读数的组成：公式化你的标定任务

腕部力传感器在静止姿态下的读数由三部分组成：

Fmeas = Fbias + Ftool(R) + Fh Fbias：零偏（常数）；Ftool = RT·wtool：工具重力在传感器坐标系的投影；Fh：人手外载荷

wtool 是世界系下的工具重力向量（0, 0, −mtg）。它是一个三维常向量（对力部分而言），机器人摆不同姿态时 R 不同，Ftool 随之变化，所以"空载在若干姿态下静止采集"就能解出 wtool：对每姿态 k 有 Fmeas,k ≈ Fbias + RkTwtool，把 RkT 纵向堆叠、Fmeas,k 纵向堆叠，做一次最小二乘即可同时得到 Fbias 与 wtool（6 个未知数）。标定完成后，控制器每个周期用当前实测 R 前馈补偿：

Fh ≈ Fmeas − Fbias − R(q)Twtool 这一步做在控制器最前端；不补偿工具重力，"零力"就无从谈起

数量级：一支 1.5 kg 的打磨/夹持工具，"残留"如果只补偿 80%，剩下 0.3 kg ≈ 3 N 的重力欠补，人手就得额外扛着 3 N 到处拖，手感直接"重了三倍"（相对 3–5 N 的引导力而言）。工具重力补偿的精度是导纳式拖动示教的第一质量指标。

3. 零偏就是"漂移速度"：为什么必须自动估计

力传感器零偏 Fbias（含温漂）若不补偿，等效于一个常力输入，导纳把它变成恒定速度：

vdrift = Fbias / Dd 例：Dd = 30 N·s/m、残余零偏 0.6 N → 20 mm/s 的"自己走"

20 mm/s 不快，但无人干预时两分钟就是 2.4 m，必须清零。工程做法：上电后在"无人触碰"状态下采集 1–2 s 读数求均值得到 Fbias（同时把上电姿态作为拖动的参考姿态）；运行中若检测到"人手已松开且速度持续非零"，缓慢回拉偏置估计（时间常数 10 s 量级），不要让偏置估计追着正常操作跑。

4. 稳定性：内环带宽与"人-机耦合"双约束

导纳输出的是位置命令，实际位置由内环伺服跟踪。闭环是"导纳 + 内环延迟 + 人手（弹簧-阻尼型的阻抗）"的耦合系统。两条约束：（1）虚拟导纳的带宽 ωa = √(Kd/Md)（K 很小，实际主要看 1/τ，τ = Md/Dd）必须远小于内环带宽（经验 ≥5 倍差距，内环 30 Hz 时导纳时间常数取 30–100 ms）；（2）人手也是一条反馈通道（人看位置、调力），人手刚度紧张、反应延迟 100–200 ms，导纳增益（1/Dd）太大时会形成 5–8 Hz 的低频振荡，现象是"机器人抖着手"，此时该做的是增大 Dd（手感变稳），不要急着责怪伺服。

与第 028 章并排看，两条路线的结构差异一目了然：

维度028 力矩级（阻抗式，"顺重力拖"）029 位置级（导纳式，"零力引导"）
控制量关节力矩笛卡尔位置命令
力信息关节力矩传感/电流 + 模型腕部六维力传感器
重力摩擦由谁处理控制器显式补偿（模型依赖强）机器人内环自扛；仅需工具重力补偿
手感决定量摩擦力补偿精度、BvDd（速度手感）、Md（起步手感）
典型风险补偿误差导致自走/拖不动零偏漂移、工具重力欠补、低频抖动
适用条件开放力矩接口的机器人任意位置接口 + 安装力传感器

实现思路与设计

  1. 开机流程：上电读姿态 → 2 s 静止采样估零偏（假设无人触碰）→ 记录参考姿态 xr（导纳的零点）→ 进入待使能状态。工具箱重力参数来自离线标定文件。
  2. 力信号处理：减去零偏与工具重力 → 20 Hz 低通 → 死区（±0.5 N，滤手中微动）→ 送入导纳。死区不是必需的，但能明显减少"机器人随噪声微动"的观感。
  3. 导纳参数：Md = 3 kg、Dd = 30–40 N·s/m、Kd = 0；τ = Md/Dd = 75–100 ms，比 1 kHz 控制周期大两个数量级，离散化毫无压力。
  4. 输出链：导纳角速度 → 积分位置命令 → 速度限幅（0.3 m/s）→ 加速度限幅（5 m/s²）→ 工作空间软墙（越界回弹 50 N/m）→ 下发内环。限幅原理与第 025、027 章同构。
  5. 示教记录：位置级方案天然记录笛卡尔位姿 + 时间戳；抽稀判据"平动 0.5 mm 或姿态 0.1° 或时间 50 ms"。回放仍走位置控制。
  6. 安全：使能按钮（最基础的底线）、拖动速度上限、超速即退出、传感器断线检测（读数冻结 > 20 ms 报警）。
设计决策：阻尼为什么推荐 30–40、取更小的 10 会怎样？

Dd = 10 时 3 N 就能跑 300 mm/s，听起来很"零力"，但三个问题随之而来：（1）零偏 0.5 N 就有 50 mm/s 漂移；（2）噪声 0.2 N 对应 20 mm/s 抖动；（3）人手微动放大成明显运动，定位精度差。30–40 是"轻"与"稳"的工程甜点区；追求极轻盈的手感请配合更好的传感器与更低噪声，单纯减阻尼只会把漂移与抖动一并放大。

关键代码与解读

片段 1：导纳拖动核心（含零偏估计与输出限幅）

import numpy as np

class AdmittanceDrag:
    """位置接口机器人的拖动示教：力 -> 虚拟导纳 -> 位置命令。"""
    def __init__(self, m_d=3.0, d_d=35.0, dt=1e-3, v_max=0.3):
        self.m_d, self.d_d, self.dt, self.v_max = m_d, d_d, dt, v_max
        self.v = np.zeros(3)          # 虚拟速度（平移 3 维示意）
        self.x = np.zeros(3)          # 命令位置
        self.bias = np.zeros(3)       # 零偏估计
        self.bias_buf = []            # 开机采集缓冲
    def start_calibration(self):
        self.bias_buf = []
    def calibrate(self, f_raw):
        """上电静止 1-2 s 采均值：假设无人触碰。"""
        if len(self.bias_buf) < 1500:
            self.bias_buf.append(f_raw.copy())
            return False
        self.bias = np.mean(self.bias_buf, axis=0)
        return True
    def step(self, f_raw, f_tool):
        # 人手力 = 实测 - 零偏 - 工具重力（工具项由姿态实时前馈）
        f_h = f_raw - self.bias - f_tool
        # 零弹簧导纳：拖到哪停到哪；阻尼决定引导速度手感
        a = (f_h - self.d_d * self.v) / self.m_d
        self.v += a * self.dt
        n = np.linalg.norm(self.v)
        if n > self.v_max:                       # 方向保持式限速
            self.v *= self.v_max / n
        self.x += self.v * self.dt
        return self.x.copy(), f_h

解读：整个拖动逻辑只有十行：去偏、去工具重力、二阶导纳、限速、积分。bias 用上电均值实时估计：零偏随温度变化（开机与运行 1 小时后差 0.2–0.5 N 很常见），写死常数很快失配。f_tool 由调用方用当前姿态算出（见片段 2），这里保持类"只关心动力学"的单一职责。f_h 同时返回给上层做"是否有人触碰"的判断（例如判断松手以触发偏置慢更新）。注意我们只演示平移三维，真实的六维版本把 Md、Dd 换成 6×6 对角矩阵，姿态维度用 N·m·s/rad 的阻尼。

片段 2：工具重力向量的最小二乘标定

def calibrate_tool_gravity(R_list, f_list):
    """空载多姿态静止采样，解出 (F_bias, w_tool)。
    R_list: 各姿态传感器->世界旋转矩阵; f_list: 对应力读数(3 维)。"""
    # 模型: f_k = F_bias + R_k^T @ w_tool, 其中 w_tool=(0,0,-m*g)
    # 未知量 6 个: [F_bias(3), w_tool(3)]。构造 A x = b 的最小二乘
    A, b = [], []
    for R, f in zip(R_list, f_list):
        A.append(np.hstack([np.eye(3), R.T]))    # 未知量排列: [bias; w]
        b.append(f)
    A = np.vstack(A); b = np.concatenate(b)
    sol, *_ = np.linalg.lstsq(A, b, rcond=None)
    f_bias, w_tool = sol[:3], sol[3:]
    m_tool = np.linalg.norm(w_tool) / 9.81
    return f_bias, w_tool, m_tool

# 用法示例：把机器人摆 5 个姿态，每处静止采 1 s 均值
# f_bias, w, m = calibrate_tool_gravity(R_list, f_mean_list)
# 打印: f"工具质量 {m:.2f} kg, 零偏 {np.round(f_bias,2)} N"

解读：标定的关键在于"模型线性、数据多姿态"，只要姿态旋转足够分散（R 的列张成三维），最小二乘就能把常数零偏与姿态相关的重力项分离开，这正是单姿态标定做不到的。代码里用 np.hstack([I, R.T]) 把未知量拼成 6 维向量一次解出；姿态数 ≥3（且不共面）即可解，实践中建议 5–9 个姿态覆盖关节范围。得到的 wtool 范数除以 g 就是工具质量 mtool；工具质心位置对应力矩部分的标定（把 f 换成六维力旋量、RT 换成 6×6 的力旋量映射即可推广）。标定质量自检：残差 RMS 应小于传感器噪声的 2 倍（如 0.3 N 量级）。

片段 3：零偏漂移实验，为什么"自己不走的机器人"是设计出来的

def drift_demo(d_d=35.0, dt=1e-3, T=4.0):
    """无操作时，不同零偏残余下的漂移速度与 4 s 累计位移。"""
    for residual in (0.0, 0.2, 0.6, 1.0):
        ctrl = AdmittanceDrag(m_d=3.0, d_d=d_d, dt=dt)
        # 人为给一个未补偿的偏置：模拟零偏标定残差
        for i in range(int(T/dt)):
            f_raw = np.array([residual, 0.0, 0.0])
            ctrl.step(f_raw, np.zeros(3))       # 无工具重力项干扰
        v = ctrl.v[0]; x = ctrl.x[0]
        print(f"残余零偏 {residual:3.1f} N -> 漂移速度 {v*1000:5.1f} mm/s,"
              f" 4 s 位移 {x*1000:6.1f} mm")

drift_demo()

解读：输出会显示"残余零偏 × 1/Dd = 漂移速度"的线性关系：0.2 N → 5.7 mm/s，0.6 N → 17 mm/s，1.0 N → 28.6 mm/s，4 s 累计位移到厘米级，机器人在没人碰的情况下自己往一边爬。这段实验的结论有三层：（1）零偏标定残差直接决定"静止漂移"指标，验收标准建议定为"无人触碰 10 s 位移 < 5 mm"（对应残余偏置 < 0.018 N）；（2）要达到这个精度，上电均值采样的时间要够（1–2 s）、期间必须没人碰桌子；（3）运行中的慢速偏置跟踪（时间常数 10 s 级）是第二道保险，但它不能替你把启动质量做对。

常见坑

  • 忘补/欠补工具重力：某些姿态"拖得动"、某些姿态"沉得推不动"，工具越重越明显。修复：多姿态最小二乘标定 + 运行中姿态前馈，残差 RMS < 0.3 N。
  • 零偏偏置未重新估计：开机时刚好有人扶过机器人，把"手的力"采进偏置，之后一直漂。修复：上电静止条件检查（力波动 < 0.1 N 才采）+ 运行中慢更新。
  • Dd 太小求"轻"：漂移、噪声、人手微动全被放大，定位精度崩溃。修复：30–40 N·s/m 起步，配合死区；确实要更轻就换更高带宽传感器，硬减阻尼会同时放大漂移与噪声。
  • 导纳增益相对内环带宽过大：出现 5–8 Hz 抖动（"抖手"），有时被误判为伺服故障。修复：τ = Md/Dd ≥ 5/内环带宽对应的时间常数，或增大 Dd。
  • 只保存位置增量（Δx）当作状态：每拍直接 x += F/k 看似简单，但没有惯性项、松手后立即停（手感"顿"），也无法限加速度。修复：保留完整的二阶导纳状态（v、x），按第 025/027 章的链式限幅。

练习与思考

  1. 取 Dd = 40 N·s/m，计算引导力 2、5、10 N 对应的稳态速度；若希望"10 N 对应 200 mm/s"，Dd 应为多少？★
    提示
    50、125、250 mm/s；Dd = 10/0.2 = 50 N·s/m。
  2. 推导零偏-漂移公式 vdrift = Fbias/Dd，再算出"无人 10 s 位移 < 5 mm"允许的最大残余零偏（Dd=35 N·s/m），并讨论这个数字是否现实。★★

    v < 0.5 mm/s，反推 Fbias < 35×0.0005 = 0.0175 N，远低于传感器噪声，说明严苛的短时漂移指标基本不可达；工程上用"更长观察窗 + 运行中慢速偏置更新"共同解决，这正是设计取舍。
  3. 用片段 2 的模型，说明为什么单姿态标定无法分离零偏与工具重力，而两个姿态就能"张成"必要条件？需要几个姿态才能保证数值稳定？★★★
    提示
    单姿态下 bias 与 RTw 的合成只能给出一个方程；不同姿态让 RT 变化，才能从数据里区分"常数项"与"随姿态变化项"；5 个以上分散姿态保证条件数良好。
  4. 实验：在片段 3 里把 Dd 从 35 改为 12，重复四组残余零偏，记录漂移速度与"手感"数字（v/F 灵敏度）。总结 Dd 对两项指标的反向作用。★★
    提示
    灵敏度 ∝ 1/Dd（越轻越灵敏），漂移同样 ∝ 1/Dd（越轻越漂），同一根旋钮控制两个相反指标，只能折中。
  5. 设计题：把本章的导纳拖动与第 028 章的力矩拖动并列，写一段 8 行以内的"选型决策"伪代码（输入：机器人是否有力矩接口、是否已装力传感器、工具是否常换），并说明每个分支的理由。★★
    提示
    有开放力矩接口且工具固定 → 028；只有位置接口或工具频繁更换（传感器随工具走）→ 029；两者都有 → 用 028 做手感基准、029 做兼容方案。

小结

  • 导纳式拖动示教 = 力传感 + 零弹簧虚拟导纳（Mdẍ+Ddẋ = Fh）+ 位置命令，兼容任何位置接口机器人。
  • "零力引导"的量化指标：引导力 F 对应稳态速度 F/Dd；Dd 管轻/稳取舍，Md 管起步手感与抗噪，推荐 30–40 N·s/m 与 2–5 kg 起步。
  • 工具重力（随姿态变化）与传感器零偏（常数）必须分离标定：多姿态最小二乘一次解出；静态漂移验收给出可执行的数字标准。
  • 安全链与第 025/027 章一致：方向保持限速、加速度/jerk 塑形、工作空间软墙、使能开关与传感器健康监测。
