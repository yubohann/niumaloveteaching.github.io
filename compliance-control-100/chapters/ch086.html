第五篇 · 鲁棒控制与工程实践

第 086 章：阻抗控制中的反步法

反步法（backstepping）把"位置→速度→力矩"当作一层层楼梯：每层设计一个虚拟控制，用同一个李雅普诺夫函数把上一层钉牢，再走到下一层。它不切换、不抖振，是满配平滑版的鲁棒设计，代价是模型依赖与"虚拟控制求导"。

  • 主题：反步法（backstepping）非线性控制
  • 关键公式：α1 = ẋd − c1e1，u = m̂α̇1 − e1 − c2e2 + Fmeas
  • 预计学时：65 分钟
  • 前置章节：第 085 章

学习目标

  • 理解反步法的核心思想：把二阶（或更高阶）系统拆成串联的"低阶子系统"，逐层构造虚拟控制并用同一个李雅普诺夫函数贯穿。
  • 会推导两层反步控制律：从 e1 = x − xd 到 α1 = ẋd − c1e1，再到 u = m̂α̇1 − e1 − c2e2 + Fmeas。
  • 能写出 V2 = ½e12 + ½me22 并证明 V̇2 ≤ −c1e12 − c2e22 + e2δ̃，理解扰动残差 e2 = δ̃/(c2+1/c1) 的来源。
  • 理解为什么"力控型"阻抗实现必须前馈测得的接触力 Fmeas（与第 006 章一脉相承），以及忽略它会造成多大的静态偏差。
  • 能说清反步法的两笔代价：模型依赖与"虚拟控制求导"（微分爆炸的起点），为下一章动态面控制做铺垫。

背景与动机

滑模给出了漂亮的不敏感性，但切换项是"抖振的种子"。很多工程师不喜欢在执行器指令里放任何开关，宁愿多算一点模型。反步法（backstepping）正是这条路线：它把控制律"递归地"构造出来，每一步都保证李雅普诺夫函数下降，最终得到的力矩是连续、可微的，没有 sat、没有 sgn，也就没有抖振。

为什么把它和阻抗控制放在一起？因为阻抗控制的本质是一个"二阶目标行为"：Md(ẍd−ẍr) + Dd(ẋd−ẋr) + Kd(xd−xr) = −Fext。这个方程本身可以被当作"参考发生器"：它实时给出应该跟踪的 xd(t)。于是问题变成标准的跟踪控制，而反步法恰好是处理"非线性+串级结构"的标准武器：末端位置是一层、末端速度是一层、关节力矩是执行层，甚至电机电流和柔性关节都能继续往下加层。

本章的目标很明确：让物理机器人精确复现阻抗模型的输出，同时不引入切换项。你将看到反步法怎样"自动地"给出一个鲁棒项位置，在最后一层，跨层耦合项 e1 与速度反馈 c2e2 之外，剩下的扰动缺口可以被第 084 章的 sat 项无缝接上。同时你会看到力控型机器人实现阻抗时的一个硬性前提：接触力前馈不可省。

核心原理

1. 系统分层：把二阶问题拆成两个一阶问题

先约定方向：+x 指向环境内部，机器人位置 x，环境表面在 xe；接触反力作用于机器人的大小 F = Kenv(x − xe)（x > xe 时存在），方向与压入相反。沿任务方向的一维等价模型（惯量 m 未知但有名义值 m̂）：

m·ẍ = u − F + δ(t)，|δ| ≤ ρ u：任务空间力指令（N）；F：实测接触力；δ：摩擦、负载偏置、模型误差的代数和

目标：让 x 跟踪阻抗模型生成的参考 xd（ẋd、ẍd 都可知，后者由阻抗方程解析给出：Mdẍd = −Fmeas − Ddẋd − Kd(xd−xr)）。层次结构是：x 由 ẋ 驱动，ẋ 由 u 驱动。反步法从最外面一层开始：

e1 = x − xd 第一层误差（m）；先不管 u，先假设"ẋ 是我能指挥的"

取 V1 = ½e12，则 V̇1 = e1(ẋ − ẋd)。我们希望 ẋ 取某个值让 V̇1 < 0：把 ẋ 当作"虚拟输入"，取

α1 = ẋd − c1e1 （c1 > 0） 若 ẋ = α1，则 V̇1 = −c1e12，第一层稳定

但 ẋ 不是我们能直接下命令的量（真正能下的是 u），实际 ẋ 与 α1 之间总差一个 e2 ≜ ẋ − α1。这个差额进入 V̇1：

V̇1 = −c1e12 + e1e2 多出来的 e1e2 就是下一步要负责消灭的对象

工程直觉：反步法像"逐层结算债务"。第一层欠下的 e1e2，由第二层的控制律偿还：第二层里加一个 −e1 项，把跨层耦合精确抵消。它的来源是李雅普诺夫函数的交叉项结构，有推导依据，这正是反步法比"手动拼控制律"严谨的原因。

2. 第二层：用真实输入 u 让 e2 收敛

取增广李雅普诺夫函数 V2 = V1 + ½m·e22（第二项是"速度失配的动能"）。求导：

V̇2 = −c1e12 + e1e2 + e2( m·ẍ − m·α̇1 ) m·ẍ = u − F + δ；α̇1 = ẍd − c1ė1 是虚拟控制的时间导数

这里有一个力控型机器人特有的步骤：把测到的接触力 Fmeas 直接前馈进控制律，否则机器人为了"顶住"环境反力，必须靠位置误差换取力，静态偏差会非常大（第 006 章讲过同一个道理）。选择

u = m̂·α̇1 − e1 − c2e2 + Fmeas ⟹ m·ė2 = −e1 − c2e2 + δ̃ δ̃ = δ + (m̂ − m)α̇1 + (Fmeas − F)：力传感器误差也进 δ̃，理想情况下只剩摩擦与偏置

于是：

V̇2 = −c1e12 − c2e22 + e2δ̃ −e1 项抵消跨层耦合，−c2e2 是本层阻尼；前馈项把接触力从事务里"摘出去"

没有扰动时（δ̃ = 0），V̇2 ≤ −c1e12 − c2e22 严格负定，系统全局渐近稳定到原点。有常值扰动时，把稳态条件 ė1 = ė2 = 0 代入：由 ė1 = −c1e1 + e2 = 0 得 e1 = e2/c1；由 ė2 = 0 得 e2(c2 + 1/c1) = δ̃，于是

e2,ss = δ̃ / (c2 + 1/c1)，e1,ss = e2,ss/c1 反步法的典型残差结构：两层增益共同决定稳态误差

代入 m = 2 kg、常值偏置 b = 5 N（线缆拖拽、气路张力这一类"不会自己消失"的干扰）、c1 = 25 s−1、c2 = 40 s−1：e2,ss ≈ 0.125 m/s、e1,ss ≈ 5 mm。这个残差不小，因为反步法本身没有积分也没有切换项，它对"不一定衰减的扰动"只负责到"有界"为止。想压掉它，有两条路：把 c2 加大（增益越大残差越小，但没用模型信息），或在最后一层加第 084 章的鲁棒项。作为对照：同样带力前馈的纯 PD 跟踪，5 N 偏置在 kp = 400 N/m 下产生的偏差是 12.5 mm，反步法用 (1+c1c2) ≈ 1001 的等效刚度把偏差压到 5 mm；再叠加鲁棒项（K = 10 N、ε = 0.01 m/s）可到 0.2 mm 级。

3. 与滑模、反馈线性化的关系

把反步法的两层展开，控制律形如 u = m̂ẍd − (m̂c1+c2)ė1 − (1+c1c2)e1… 展开后你会发现它与"反馈线性化 + PD"有相似的外观：都在用模型前馈抵消非线性。差别在于设计方法论：反馈线性化要求全状态精确模型并显式抵消非线性；反步法只逐层抵消"阻碍李雅普诺夫下降的那部分"，不刻意抵消有用非线性，并且能自然向上延伸，如果电机或柔性关节引入更多状态，只需继续加层，每层仍然贡献一个正的李雅普诺夫项。这就是它被称为"递归设计方法"的原因。

与滑模的关系更像"一枚硬币的两面"：滑模的到达条件对应反步法最后一层的 V̇ < 0 要求；滑模的切换项可以在反步法最后一层原位替换掉"c2e2"的位置，变成 u = m̂α̇1 − e1 − K·sat(e2/ε) + Fmeas。工程直觉：反步法负责把系统的骨架搭整齐，鲁棒项负责给骨架穿上一层防弹衣，两者配合，才是完整的"连续律 + 抗扰"设计。加上鲁棒项后，残差变为 e2 ≈ δ̃/(c2+1/c1+K/ε)，用 K = 10 N、ε = 0.01 m/s 算：5/(1040) ≈ 0.005 m/s，位置残差回到亚毫米。

4. 代价：模型依赖与微分爆炸

反步法的两笔代价必须认识清楚。第一笔是模型依赖：u = m̂α̇1 − e1 − c2e2 + Fmeas 中的 α̇1 = ẍd − c1ė1 需要 ẍd，好在阻抗模型的输出 ẍd 是解析给出的（把阻抗方程除以 Md 即得），不用差分；它还包含 ė1，用速度测量替代位置差分。反过来，力前馈 Fmeas 把"必须知道接触力"变成了硬前提，没有力传感器时只能走向第 090 章的无传感器估计，估计误差直接进入 δ̃。第二笔是"微分爆炸"（derivative explosion）：对二阶系统，第二层的 α̇1 只用一阶信息；但如果被控对象是三阶（例如含电机电气动态或柔性关节），第三层就会需要 α̇2，其中包含 ė2 的导数乃至 ẍd 的导数，阶数每加一层，就要对越来越多含噪信号做微分。这正是下一章动态面控制（DSC）要解决的问题：用一个一阶低通滤波器代替"解析求导"，把爆炸掐灭在源头。

实现思路与设计

  1. 阻抗参考发生器：以 1 kHz 运行阻抗方程 Mdẍd = −Fmeas − Ddẋd − Kd(xd−xr)，输出 xd、ẋd、ẍd；三个量都是解析积分结果，可以直接喂给反步控制律。
  2. 第一层误差：e1 = x − xd；虚拟控制 α1 = ẋd − c1e1。c1 取 15–30 s−1：太快会把力噪声放大进速度指令，太慢则阻抗跟踪迟钝。
  3. 第二层误差与控制：e2 = ẋ − α1；u = m̂α̇1 − e1 − c2e2 + Fmeas（可再加 sat 鲁棒项）。c2 取 30–60 N·s/m 量级：它与 c1 共同决定残差 δ̃/(c2+1/c1)。
  4. 力前馈不能省：力控型机器人必须把 Fmeas 加进控制律，否则接触反力全靠位置误差换取（在 21.9 N 接触力下静态偏差可达厘米级）。正确性检查：把系统置于静态，u 应当恒等于 Fmeas 的量级。
  5. 导数来源审计：逐项检查每个导数项是否"有解析来源"，ẍd 来自阻抗方程、ė1 来自速度测量；凡是需要差分的项都要改设计或用 DSC 滤波。
  6. 鲁棒项（可选）：u += −ρ·sat(e2/ε)，ε 取速度噪声的 3–10 倍，ρ 按不确定性清单给（参考第 084 章）。
设计决策：为什么不直接把"阻抗方程 + PD"当成反步法？

把阻抗方程和 PD 拼起来确实能工作，但两者的"证明"完全不同：拼装方案只能在小误差下局部论证，且不知道每个增益对应哪一层误差；反步法的每一层都对应 V2 里的一个负定项，增益的物理意义是"这层误差的收敛速率"，残差公式 e2 = δ̃/(c2+1/c1) 让你能反推需要的增益量级，整定有据可依。当任务要求"可解释的调试过程"（医疗、协作场景的认证需求）时，这个区别是实质性的。

关键代码与解读

片段 1：两层反步控制器（含力前馈）

import numpy as np

class BacksteppingAxis:
    """一维任务轴的反步控制器：把误差链 (e1, e2) 逐层压零。"""
    def __init__(self, c1=25.0, c2=40.0, m_hat=2.0, rho=0.0, eps=0.01):
        self.c1, self.c2 = c1, c2   # 两层增益：位置层与速度层的收敛速率
        self.m_hat = m_hat          # 名义惯量：与真实惯量的差进入扰动 delta
        self.rho, self.eps = rho, eps  # 可选鲁棒项（rho=0 时关闭）

    def control(self, x, v, x_d, dx_d, ddx_d, f_meas):
        e1 = x - x_d
        # 第一层虚拟控制：如果 v 能达到 alpha，V1_dot = -c1*e1^2
        alpha = dx_d - self.c1 * e1
        # alpha_dot：关键在"不差分"：e1_dot = v - dx_d 用速度测量，
        # ddx_d 由阻抗方程解析给出，因此这里没有任何数值微分
        alpha_dot = ddx_d - self.c1 * (v - dx_d)
        e2 = v - alpha
        # 第二层：模型前馈 + 跨层耦合 -e1 + 本层阻尼 -c2*e2 + 接触力前馈
        # 力前馈是所有力控型阻抗实现的硬性要求：没有它，机器人要靠位置
        # 误差"顶住"环境反力，静态偏差会是厘米级
        u = self.m_hat * alpha_dot - e1 - self.c2 * e2 + f_meas
        if self.rho > 0.0:
            # 可选：最后一层接入第 084 章的 sat 鲁棒项，补齐扰动残差
            u -= self.rho * np.clip(e2 / self.eps, -1.0, 1.0)
        return float(u), e1, e2

解读：控制律每一行都能对应到推导：alpha 是第一层的虚拟控制，-e1 是"跨层耦合的偿还项"，-c2*e2 是本层阻尼，+f_meas 是接触力前馈。最值得学的是 alpha_dot 的写法：能解析算就解析算，用速度测量替代差分，用阻抗模型的 ẍd 替代外部轨迹的差分。同时注意 f_meas 的位置：它加在最后、系数为 1，如果以后把力传感器噪声问题带进来（第 047 章），这一项也是 δ̃ 的一部分，可以用低通后的力信号替代。

片段 2：三种内环的对照仿真

def run_case(mode, dt=1e-3, n=3000):
    """mode: 'pd' 纯PD+力前馈 / 'bs' 反步 / 'bs_rob' 反步+鲁棒项。"""
    m, bias = 2.0, 5.0                 # 真实惯量、常值扰动（线缆拖拽等）
    m_d, d_d, k_d = 1.0, 60.0, 1500.0  # 阻抗参考模型（临界阻尼）
    ctrl = BacksteppingAxis(rho=10.0 if mode == "bs_rob" else 0.0)
    x = v = x_d = dx_d = 0.0
    rms = 0.0
    for i in range(n):
        f_env = 5000.0 * (x - 0.001) if x > 0.001 else 0.0   # 表面在 1 mm 处
        # 参考发生器：由阻抗方程解析给出 x_d 的加速度（反步第 2 层要用）
        ddx_d = (-f_env - d_d * dx_d - k_d * (x_d - 0.02)) / m_d
        dx_d += ddx_d * dt
        x_d += dx_d * dt
        if mode == "pd":
            # 公平对照：PD 也带力前馈，差别只在增益结构
            u = m * ddx_d + 400.0 * (x - x_d) + 60.0 * (v - dx_d) + f_env
        else:
            u, e1, e2 = ctrl.control(x, v, x_d, dx_d, ddx_d, f_env)
        # 真实被控对象：控制力 - 接触反力 - 常值扰动
        v += (u - f_env - bias) / m * dt
        x += v * dt
        err = x - x_d
        rms += (err * err - rms) / (i + 1)   # 在线 RMS：全程跟踪质量
    return rms, x - x_d                      # 跟踪 RMS、末态位置偏差

解读：这段对照实验想让你看到三件事：（1）PD 带力前馈后不再是"撞墙"级别，但 5 N 常值偏置在 kp = 400 下留下 12.5 mm 稳态偏差；（2）反步法用 (1+c1c2) 的等效刚度把静态偏差压到约 −5 mm，且在接触瞬态的跟踪 RMS 更小，因为 −e1 跨层耦合项让两层误差同步收敛；（3）加上鲁棒项后偏差进一步压到亚毫米级。实现细节：bias 是刻意的"不会自己消失"的干扰（摩擦只在运动时出现，静态偏差要靠常值扰动才能暴露）；rms 采用在线递推写法，可以直接放进实时控制器当健康指标。把 bias 调大再跑一次，你就能看出"反步的残差地板"和"鲁棒项地板"的区别。

片段 3：残差与增益的标尺

def residual_table(delta, pairs, eps=None, K=None):
    """打印不同 (c1, c2) 组合下的稳态残差，把整定从试错变成查表。"""
    for c1, c2 in pairs:
        e2 = delta / (c2 + 1.0 / c1)          # 无鲁棒项的残差公式
        e1 = e2 / c1
        tag = "纯反步"
        if eps and K:
            e2r = delta / (c2 + 1.0 / c1 + K / eps)   # 加 sat 鲁棒项后
            tag = f"加鲁棒 {e2r:.4f} m/s"
        print(f"c1={c1:4.0f} c2={c2:4.0f}  e2={e2:.3f} m/s  "
              f"e1={e1*1000:6.2f} mm  ({tag})")

residual_table(5.0, [(15, 30), (25, 40), (40, 80)])
residual_table(5.0, [(25, 40)], eps=0.01, K=10.0)   # 鲁棒项把残差压到约 1/26

解读：这张"残差表"把 c1、c2 的选择直接换算成稳态误差：δ̃ = 5 N 时三档分别为 11.1/5.0/1.6 mm；加鲁棒项后，(25,40) 同组参数给出 0.19 mm。这就是"用模型信息换增益"的经济学：一个 sat 项提供的等效增益（K/ε = 1000）远超把 c2 提高几倍的收益。调试顺序建议：先按带宽约束选 c1（决定阻抗跟踪的快慢），再按可接受的残差选 c2，最后才决定要不要上鲁棒项。

常见坑

  • 力前馈漏掉或符号反：力控型机器人上表现为"接触后静态偏差厘米级"或直接发散。修复：静态自检，让机器人停在接触状态，检查 u 是否与 Fmeas 量级一致、方向相反（控制力顶住反力）。
  • 对含噪信号做"假解析"求导：把 ė1 写成 (e1−e1,prev)/dt 却自认为"没有用差分"。修复：优先用速度测量 v 构造 ė1；无法获得的速度量用 5–20 ms 低通估计，不要用 1 ms 裸差分。
  • 忽略跨层耦合项 −e1：去掉它后两层李雅普诺夫函数不再拼合，表现为 e2 收得快而 e1 迟缓。修复：它必须与 α̇1 的系数同一次推导得到，符号别丢。
  • c1、c2 拉开数量级：若 c1 ≫ c2，残差公式 e2 ≈ δ̃/c2 使位置层"独木难支"；若 c2 ≫ c1，速度层过头把噪声放大进力矩。修复：让 c2 ≥ 2c1（数值上）并用残差表核对。
  • 把反步当成"包含积分环节"：反步法本身不消除常值扰动残差，想零稳态误差要么加积分（注意抗饱和），要么加鲁棒项。修复：优先加鲁棒项（不引入积分饱和风险），位置精度要求更高时再引入带抗饱和的积分层。

练习与思考

  1. 推导 V2 = ½e12 + ½me22 的导数，验证 u = m̂α̇1 − e1 − c2e2 + Fmeas 使 V̇2 = −c1e12 − c2e22 + e2δ̃，并说明 −e1 项的必要性。★
    提示
    e1e2 与 e2(−e1) 精确抵消；没有它，交叉项符号不定，V̇ 不能保证负定。
  2. 由稳态条件求 e2,ss = δ̃/(c2+1/c1)、e1,ss = e2,ss/c1；代入 δ̃ = 5 N 计算 (c1, c2) = (25, 40) 与 (25, 200) 的位置残差，比较"加增益"与"加鲁棒项"的效率。★★
    提示
    (25,40)：e1 ≈ 5 mm；(25,200)：e1 ≈ 1 mm；而 (25,40)+鲁棒项（K=10、ε=0.01）可到 0.19 mm。增益提升 5 倍的代价是噪声与带宽，鲁棒项的代价是 ε 的残差与抖振风险。
  3. 把片段 2 中真实被控对象的惯量改为 2.3 kg（控制器名义值仍为 2.0，模拟负载加重 15%），跑三种模式，观察反步法对惯量偏差的敏感性与鲁棒项的补偿作用。★★
    提示
    α̇1 被 m̂ 低估 13%，等效于扰动 δ̃ 增大；反步残差随之增大、鲁棒项继续兜住。若把 m̂ 改成 2.3 再跑，反步残差应明显回落，这正是第 093 章在线负载估计要自动化的事情。
  4. 设计三阶扩展：给系统串联一层"电机一阶动态"（u̇ = (ucmd − u)/τm），写出第三层的虚拟控制与所需导数项，指出哪一项会引入数值微分，并说明下一章 DSC 会替换掉什么。★★★
    提示
    第三层需要 α̇2，其中包含 α̇1 的组合乃至 α̈1，也就是对速度信号的高阶导数；DSC 用低通滤波后的 α2f 替代 α2，把"求导"换成"滤波"。

小结

  • 反步法把"末端位置—速度—力矩"拆成串联层，每层设计虚拟控制并用同一个李雅普诺夫函数贯穿；控制律连续光滑、无切换抖振。
  • 两层结构：α1 = ẋd − c1e1；u = m̂α̇1 − e1 − c2e2 + Fmeas；V̇2 ≤ −c1e12 − c2e22 + e2δ̃。
  • 力前馈 Fmeas 是力控型阻抗实现的硬性前提；漏掉它，静态偏差由位置误差承担，厘米级。
  • 常值扰动残差 e1,ss = δ̃/(c1(c2+1/c1))；用第 084 章的 sat 鲁棒项可在不抬高 c2 的前提下把残差再压缩一个数量级以上。
  • 两笔代价：模型依赖（m̂、α̇1、力传感）与微分爆炸（层数一多就要对含噪信号求高阶导）。下一章动手拆掉第二笔代价：动态面控制用一个一阶滤波器替代虚拟控制的解析求导。
