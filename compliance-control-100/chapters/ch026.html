第二篇 · 参数调节与交互任务

第 026 章：阻抗控制中的奇异点规避

机械臂伸直、腕部共线时，雅可比降秩：运动能力塌缩、力传递放大、力的控制权限消失。本章用可操作度与最小奇异值量化"离奇异有多近"，用阻尼最小二乘和零空间梯度给出规避方法。

  • 主题：阻抗控制 / 运动学奇异性 / 数值鲁棒
  • 关键公式：q̇ = JT(JJT+λ²I)−1ẋ，w(q) = √det(JJT)
  • 预计学时：50 分钟
  • 前置章节：第 024 章、第 025 章

学习目标

  • 理解运动学奇异性（singularity）的几何本质：雅可比 J 降秩、σmin(J)→0，以及它在阻抗/导纳两种实现中的不同表现形式。
  • 会用可操作度 w(q) = √det(JJT) 与条件数 σmax/σmin 度量"离奇异有多近"，会为 2R 平面臂写出 w = l₁l₂|sin q₂| 并解读。
  • 会推导阻尼最小二乘（DLS）解 q̇ = JT(JJT+λ²I)−1ẋ，并解释 λ 的调度公式与"精度换安全"的定量代价。
  • 理解冗余机械臂的零空间可操作度梯度 ∇w，能写出"任务运动 + 远离奇异姿态"的复合指令。
  • 掌握阻抗侧的两个守卫动作：奇异邻域软化任务刚度（降低力放大风险）与 DLS 化运动指令（压住关节速度）。

背景与动机

每一台串联机械臂都有若干"神奇姿态"：臂完全伸直去够远端物体、腕部三个轴共线拧螺钉、肩腕奇异对齐。在这些姿态附近，机器人的运动学雅可比 J（把关节速度映射成末端速度的矩阵）会失去满秩，某些末端运动方向在数学上"没有对应的关节速度组合"，或者对等量关节速度的反应比例失衡到成千上万倍。

第 024、025 章已经分别看到它在两侧的破坏力：对阻抗（力矩）侧，σmin→0 时 ‖F‖ ≤ ‖τ‖/σmin 意味着几牛米的力矩就能顶出千牛级末端力，而且力的控制权限在丢失的方向上彻底消失，你无法调节那个方向的力，机器人像一根刚性柱子；对导纳（速度）侧，l⁻¹ 型放大让 5 cm/s 的任务速度指令变成 25 rad/s 的关节速度（本章会有具体数字）。接触任务又特别容易把人推向这些姿态：装配要伸进去、打磨要够到边角。奇异点规避因此是柔顺控制安全链上不可绕过的一环。

核心原理

1. 奇异性的几何：J 降秩与两个数量级的变化

任务空间速度 ẋ = J(q)q̇。J 是 m×n 矩阵（m 个任务维、n 个关节维）。当 rank(J) < min(m,n) 时该姿态称为运动学奇异。做奇异值分解 J = UΣVT，奇异值 σ₁ ≥ … ≥ σmin ≥ 0，则奇异时 σmin = 0。它造成一对对偶现象：

  • 速度方向：沿小奇异值方向的运动需要巨大的关节速度（q̇ 含 1/σmin 因子），导纳输出如果直接求 J−1，就是"速度爆炸"。
  • 力方向：沿同一方向，几何的"杠杆"变得极长，末端力 F 与关节力矩 τ 之间出现 1/σmin 放大（第 024 章公式）。力权限在另一个投影方向上消失。

2R 平面臂是最好的教具：连杆 l₁、l₂，肘角 q₂。它的可操作度（manipulability）为

w(q) = √det(JJT) = l₁l₂|sin q₂|，σmin ≈ w/σmax w 的几何含义：末端速度椭球的面积。q₂→0 或 π 时 w→0：臂伸直，速度椭球退化成一条线

取 l₁ = l₂ = 0.4 m：q₂ = 90° 时 w = 0.16 m²，σmin ≈ 0.25 m；q₂ = 5.7°（0.1 rad）时 w = 0.016 m²，σmin ≈ 0.018 m；q₂ = 0.57°（0.01 rad）时 w = 0.0016 m²，σmin ≈ 0.0018 m。肘角缩小一个数量级，σmin 就缩小一个数量级，放大效应是"渐进"的，没有"安全的臂伸直"这种说法。

2. 阻尼最小二乘：把"爆炸"换成"有界近似"

求关节速度本质上是解 Jq̇ = ẋ。最小二乘解 q̇ = J+ẋ 在 σmin→0 时范数发散。阻尼最小二乘（damped least squares, DLS）改为求解带罚项的优化问题：

minq̇ ‖Jq̇ − ẋ‖² + λ²‖q̇‖² ⟹ q̇ = (JTJ + λ²I)−1JTẋ = JT(JJT + λ²I)−1ẋ λ ≥ 0：阻尼因子（单位与 σ 相同）；由矩阵求逆引理可得第二个等式，计算上更常用（求 m×m 逆）

行为解读：σmin ≫ λ 时，(JJT+λ²I)−1 ≈ (JJT)−1，解几乎不变（精度不受损）；σmin ≪ λ 时，该方向被 λ² 主导，q̇ 幅值上限约为 ‖JTẋ‖/λ²，是有界的梯度式运动，不会发散。代价也随之出现：沿小 σ 方向的任务速度无法实现，任务空间出现偏差，精度换安全，交换比由 λ 精确控制。用一句话概括：DLS 不阻止你"靠近"奇异，只是保证靠近时关节速度不失控；真正的规避还要靠姿态规划与零空间梯度。

λ 的经典调度（Levenberg–Marquardt 风格）为：

λ² = λ²max · max(0, 1 − (σmin/ε)²) ε：奇异阈值（σmin 低于 ε 才开启阻尼）；λmax：最大阻尼。σmin ≥ ε 时 λ = 0，完全恢复无阻尼精度

3. 冗余自由度与零空间：把姿态"推"离奇异

n > m 的冗余机械臂（如 7 轴臂、平面 3R 对 2D 任务）额外拥有零空间：不改变末端运动就能改变关节姿态的自由度集合，投影矩阵 N = I − J+J 把任意关节速度投影进零空间。于是可以叠加一项"爬坡"修正：

q̇ = J+DLSẋ + NDLS · k₀∇w(q) ∇w(q)：可操作度对关节角的梯度；k₀：爬升增益（1/s 量级）；NDLS = I − JT(JJT+λ²I)−1J

物理直觉：末端该走的路一步不差，但"肘、肩、腕这些内部姿态"被持续推向可操作度更高、σmin 更大的构型，如同人在窄门里侧身摆臂，让身体始终远离"卡住"的姿态。梯度 ∇w 在实践中用解析式或数值差分都行（w 对 q 光滑右导）。对阻抗控制而言这一步在哪个环节执行？任务力由 τ = JTF 给出、不受零空间影响（N 与 JT 正交），所以零空间修正可以安全地叠加在参考轨迹生成（或外部导纳层）里，而不干扰主任务的阻抗行为，这是冗余臂"任务柔顺"与"姿态安全"可以解耦的根源。

4. 阻抗侧的两个守卫：软化刚度与选择阻尼

对纯阻抗（力矩）实现，没有 J−1 爆炸问题，但有力放大与权限丢失。守卫动作有两个：（1）刚度软化，按 σmin/ε 比例下调任务刚度 Kd（例如最低到 30%），因为 Kd 越大、位置误差转化为力的增益越大，在放大区更危险；（2）指令投影，把期望力旋量投影到 JT 的值域空间，丢弃物理上无法实现的分量，避免控制器"对着空气使劲"造成内部积分器堆积。这两条与 DLS 配合，构成"运动有 DLS、力有软化与投影"的完整奇异处置。

实现思路与设计

  1. 监控量：σmin、σmax 与条件数 κ = σmax/σmin。6 维 J 混合平移（m）与旋转（无量纲）单位，先归一化：旋转行乘以特征长度 Lc = 0.1 m 再算 SVD，否则 κ 没有可比性。
  2. 阈值初值：ε = 0.05×σmax（或绝对量 0.05 m 量级，取两者较小）；进入保护的比率下限 0.15、退出上限 0.25，形成滞环，防止 λ 在边界抖动。
  3. DLS 参数：λmax = 0.05 m 量级起步；λ² 由调度公式给出；1 kHz 控制周期下 SVD 每 2–5 拍算一次足够（J 随 q 缓慢变化），省算力。
  4. 零空间增益：k₀ = 5–10；梯度可用有限差分（每轴 ±10⁻⁶ rad）；把零空间速度限制在 0.5 rad/s 以内，并叠加关节限位保护（接近限位时梯度项截断）。
  5. 刚度守卫：scale = clip(σmin/ε, 0.3, 1)，Kd(t) = scale·Kd0；只在保护激活时生效，退出后以 1 s 时间常数恢复，避免刚度突变。
设计决策：为什么防止 λ 抖动很重要？

λ 在阈值附近来回跳，会使关节速度指令出现"开关式"跳变，机械上表现为奇异邻域的"咯噔"抖动，接触任务中直接转化为力波动。滞环 + 平滑调度（把 λ² 限制在连续函数里）两个措施并用，效果最稳。这与第 025 章速度饱和的平滑出饱和是同一类思想：安全约束的开启/退出都必须是连续过程。

关键代码与解读

片段 1：2R 臂上的"速度爆炸"与 DLS 对比

import numpy as np
l1 = l2 = 0.4

def two_link_J(q1, q2):
    return np.array([
        [-l1*np.sin(q1) - l2*np.sin(q1+q2), -l2*np.sin(q1+q2)],
        [ l1*np.cos(q1) + l2*np.cos(q1+q2),  l2*np.cos(q1+q2)]])

x_dot = np.array([0.05, 0.0])          # 沿 x 走 50 mm/s 的任务速度
for q2 in (0.5, 0.1, 0.01):            # 肘角逐步逼近"臂伸直"
    J = two_link_J(0.0, q2)
    qd_exact = np.linalg.solve(J, x_dot)                    # 未阻尼：直接解
    lam2 = 0.0025                                          # λ = 0.05 m 的平方
    qd_dls = J.T @ np.linalg.solve(J @ J.T + lam2*np.eye(2), x_dot)
    err = np.linalg.norm(J @ qd_dls - x_dot)               # 被牺牲的任务速度
    print(f"q2={q2:5.2f}  qd_exact=[{qd_exact[0]:7.2f},{qd_exact[1]:7.2f}] rad/s"
          f"  qd_dls=[{qd_dls[0]:6.2f},{qd_dls[1]:6.2f}]  任务误差 {err:.3f} m/s")

解读：输出会非常直观，q₂ = 0.5 rad 时两种解都在 0.2–0.5 rad/s 的温和区间；q₂ = 0.01 rad 时未阻尼解骤增到 ±12.5/±25 rad/s（约 240 rpm 量级，真实机器人根本做不到，驱动器会直接报跟随误差），而 DLS 解只有 0.02–0.03 rad/s，另外用 0.05 m/s 的"任务误差"支付代价，那个方向的速度被放弃了。这就是 DLS 的精确语义：用可量化的任务误差换取有界的关节速度。工程上还要把误差回传给上层（例如路径执行器知道"这里走得比预定慢"），避免默默吞掉。

片段 2：冗余臂的零空间可操作度爬升

def J3(q):
    """平面 3R 臂（2 维任务、3 个关节 => 有 1 维零空间）的雅可比。"""
    L = 0.3
    s, c = np.sin, np.cos
    a, b, g = q[0], q[0]+q[1], q[0]+q[1]+q[2]
    return np.array([[-L*s(a)-L*s(b)-L*s(g), -L*s(b)-L*s(g), -L*s(g)],
                     [ L*c(a)+L*c(b)+L*c(g),  L*c(b)+L*c(g),  L*c(g)]])

def manipulability(q):
    J = J3(q)
    return np.sqrt(max(np.linalg.det(J @ J.T), 0.0))       # w = sqrt(det(JJ^T))

def grad_w(q, h=1e-6):
    g = np.zeros(3)
    for i in range(3):                                      # 数值差分最省事
        qp, qm = q.copy(), q.copy()
        qp[i] += h; qm[i] -= h
        g[i] = (manipulability(qp) - manipulability(qm)) / (2*h)
    return g

q = np.array([0.3, -0.02, 0.02])          # 接近伸直：sigma_min = 0.0028
lam2, k0, dt = 1e-4, 8.0, 0.01
for i in range(400):                       # 4 秒"只动零空间"的爬升
    J = J3(q)
    Jinv = J.T @ np.linalg.solve(J @ J.T + lam2*np.eye(2), J)
    q = q + dt * (np.eye(3) - Jinv) @ (k0 * grad_w(q))     # 纯零空间修正
    if i % 100 == 0:
        smin = np.linalg.svd(J3(q), compute_uv=False)[-1]
        print(f"t={i*dt:3.1f}s  q={np.round(q,3)}  sigma_min={smin:.4f}")

解读：起点 q₂+q₃ ≈ 0 是接近"全伸直"的奇异邻域（σmin ≈ 0.003），四秒纯零空间爬升后 σmin 提升到 0.07 量级，而末端位置几乎不动（零空间的定义使然），这就是"任务不动、姿态变安全"。(np.eye(3) - Jinv) 里的 Jinv 用了带阻尼的伪逆，保证奇异邻域投影本身不发散；k0=8 是爬升速度，太大（例如 30）会让关节运动显得"自己晃"，太小则爬离太慢。真机上还要加关节限位投影与速度上限，否则梯度可能把某个关节推向限位、爬升停滞。

片段 3：λ 调度与刚度守卫（带滞环）

class SingularityGuard:
    """奇异保护：DLS 阻尼因子 + 任务刚度软化，均带滞环与平滑。"""
    def __init__(self, sig_eps=0.05, lam_max=0.05,
                 ratio_lo=0.15, ratio_hi=0.25, k_min=0.3):
        self.sig_eps, self.lam_max = sig_eps, lam_max
        self.ratio_lo, self.ratio_hi, self.k_min = ratio_lo, ratio_hi, k_min
        self.active = False
        self.scale = 1.0                      # 刚度缩放状态（平滑变量）
    def update(self, J, dt):
        sv = np.linalg.svd(J, compute_uv=False)
        smin, smax = sv[-1], sv[0]
        ratio = smin / max(smax, 1e-9)
        # 滞环：低于 lo 进入保护，高于 hi 才退出，防止阈值抖动
        if not self.active and ratio < self.ratio_lo:
            self.active = True
        elif self.active and ratio > self.ratio_hi:
            self.active = False
        lam2 = 0.0
        if smin < self.sig_eps:
            lam2 = self.lam_max**2 * (1.0 - (smin / self.sig_eps)**2)
        target = max(self.k_min, min(1.0, smin / self.sig_eps))
        tau = 0.1                              # 200 ms 平滑：刚度别突变
        self.scale += (target - self.scale) * min(1.0, dt / tau)
        return lam2, self.scale, (self.active, smin, ratio)

解读：这个类把本章的工程手段装进一个小盒子：lam2 交给 DLS 使用（σmin 正常时为 0，完全恢复精度）；scale 乘到任务刚度 Kd 上，奇异邻域弱到 30%（力放大与运动压力的联合降档）；active 与三者一起输出，供状态机把"正在经过奇异区"上报给上层，例如抛光任务可在此刻降速进给。滞环的 ratio_lo/ratio_hi 采用条件数之比，对臂长不同的机器人可移植。时间上的 200 ms 平滑（tau=0.1）保证即使保护开关切换，刚度也是连续的。

常见坑

  • 直接求 J−1 或伪逆：奇异邻域关节速度爆表，轻则跟随误差报警、重则过速保护急停。修复：所有逆解统一走 DLS；代码审查时搜 inv(J)、pinv(J) 是否出现在运动指令路径上。
  • 6 维 J 混单位做 SVD：旋转行无量纲、平移行是米，κ 与 σmin 阈值失去意义，保护变得要么从不触发要么一直触发。修复：旋转行乘 Lc ≈ 0.1 m 归一化后再算。
  • λ 全局常量、永远开启：正常区也带着阻尼跑，位置跟踪始终偏一点、力环变"肉"。修复：用调度公式让 σmin ≥ ε 时 λ = 0。
  • 零空间梯度顶到关节限位：爬升方向持续推某个关节，而该关节已到限位，速度指令被下层截断，等效于"爬升停摆 + 内部积分堆积"。修复：在 N 之后再乘一层限位投影，或靠近限位时减半梯度增益。
  • 忽略"力权限丢失"方向：在奇异方向继续给阻抗控制器喂力命令，力旋量实现不了、内部状态却按理想值积分。修复：把期望力旋量投影到 JT 值域（或随 σmin 缩放刚度），并监控"期望力-实际力"的残差告警。

练习与思考

  1. 写出 2R 臂雅可比并证明 w = √det(JJT) = l₁l₂|sin q₂|；计算 q₂ = 90°、10°、1° 三档的 w 与 σmin 近似值。★
    提示
    det(J) = l₁l₂ sin q₂；(JJT) 的特征值乘积 = det(J)²。σmin ≈ w/σmax，σmax 在伸直附近约为 l₁+l₂。
  2. 把片段 1 的 lam2 依次取 0、0.0001、0.0025，记录 q₂ = 0.1 rad 时的关节速度与任务误差，画出"安全-精度"权衡曲线，并指出你会在哪种任务下选哪档。★★
    提示
    λ 越大关节速度越小、任务误差越大。自由运动选小 λ；接触/装配（误差会转化为力）选大 λ，并配合降速。
  3. 推导 DLS 解：从 min‖Jq̇−ẋ‖²+λ²‖q̇‖² 出发，对 q̇ 求导置零，得到 (JTJ+λ²I)q̇ = JTẋ，再用矩阵求逆引理化为 JT(JJT+λ²I)−1ẋ。★★★
    提示
    目标函数梯度为 2JT(Jq̇−ẋ)+2λ²q̇；求逆引理：(JTJ+λ²I)−1JT = JT(JJT+λ²I)−1。
  4. 把片段 2 的 k₀ 改为 0、2、8、30，记录 4 秒后的 σmin 与关节角的"自发运动量"。解释 k₀ 过大为什么不好（提示：关节在"没事找事"）。★★
    提示
    k₀ 越大爬升越快也越"活跃"；过大时零空间运动本身消耗关节速度预算、看起来像机器人自己抖，还会挤占接触任务的带宽。
  5. 设计题：为 7 轴协作臂设计一份"奇异区任务降档表"：保护激活时进给速度、刚度缩放、力上限各怎么变？说明每一项与奇异几何的对应关系。★★
    提示
    速度降档对应速度放大、刚度缩放对应力放大、力上限对应权限丢失与放大残余；三者都随 σmin/ε 连续调度，退出时按时间常数恢复。

小结

  • 奇异 = J 降秩、σmin→0；它在导纳侧放大速度（1/σmin）、在阻抗侧放大力（≤1/σmin）并丢失控制权限。
  • 度量工具：可操作度 w = √det(JJT)（2R 臂为 l₁l₂|sin q₂|）、σmin 与条件数；6 维 J 必须先归一化旋转行。
  • DLS 用 q̇ = JT(JJT+λ²I)−1ẋ 把发散换成有界，λ² = λ²maxmax(0,1−(σmin/ε)²) 保证正常区零代价。
  • 冗余臂用零空间梯度 q̇ += (I−J+J)k₀∇w 主动爬离奇异，任务不动、姿态变安全；滞环与平滑贯穿所有保护开关。
