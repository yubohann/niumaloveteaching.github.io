第四篇 · 高级柔顺任务与约束

第 072 章：基于阻抗控制的软轴驱动

当柔顺来自一根真实的柔性轴：串联刚度的账要算清、尖端位置要靠力反推、旋转带来的周期性扰动力要用梳状滤波治理。

  • 主题：柔性轴传动 / 串联刚度 / 周期性扰动力
  • 关键公式：Kshaft = 3EI/L3；1/Ktip = 1/Kbase + 1/Kshaft
  • 预计学时：55 分钟
  • 前置章节：第 071 章

学习目标

  • 会用欧拉-伯努利悬臂梁公式估算软轴的横向刚度 K = 3EI/L3 与扭转刚度 GJ/L，并知道典型量级。
  • 理解串联刚度在两个方向上的不同后果：横向"轴的柔性说了算"，轴向"机器人说了算"。
  • 会用力信号反推尖端位置（虚拟尖端），把"看不见的尖端"变成可监控量。
  • 会设计"利用轴自身柔顺"的策略：让控制器保持刚性，把柔顺交给物理弹簧，并说明它为什么天然稳定。
  • 会处理旋转引起的周期性扰动力：梳状滤波器的构造、相位与延迟代价。
  • 知道软轴回滞（迟滞）对力控制的影响量级以及应对方式。

背景与动机

许多工具天生带着一根"软轴"：底座电机通过柔性传动轴驱动远端打磨头、抛光轮或钻头；轴本身就是一段可弯曲的细长弹性体，机器人夹住的是轴的外壳或中段，交互发生在轴的另一端。于是控制问题变了形状：机器人能精确知道你夹持的这一点在哪，却不知道真正接触工件的那个点在哪，两点之间隔着一段有刚度的弹性体。

软轴的存在同时带来三件礼物和三笔账：礼物是"物理级柔顺"（接触冲击天然被轴吸收）、"远程驱动"（电机可以放在不碍事的位置）、"过弯能力"（工具可以伸进机器人本体到不了的角落）；账本是"串联刚度让末端比你设计的更软"、"旋转不平衡力周期性干扰"、"传动回滞让开环定位失准"。本章把这三笔账逐一算清，阻抗控制在这里的角色是读懂并管理这根轴。

核心原理

1. 软轴的刚度：两个方向、两组公式

把软轴近似成一根悬臂梁（一端被机器人夹持固定、一端装工具头）。横向刚度与扭转刚度都有闭式估计：

K横 = 3EI / L3， K扭 = GJ / L E：弹性模量（钢 2×1011 Pa）；I = πd4/64：截面惯性矩；G：剪切模量（钢约 8×1010 Pa）；J = πd4/32

取一根直径 d = 6 mm、长 L = 0.3 m 的钢轴：I = 63.6 mm4，K横 = 3×2×1011×6.36×10−11/0.027 ≈ 1400 N/m；K扭 = 8×1010×1.27×10−10/0.3 ≈ 34 N·m/rad。两个数字定下本章的基本盘：横向刚度和典型阻抗刚度（500–2000 N/m）同量级，轴的柔顺不可忽略；扭转刚度 34 N·m/rad 足以传 5 N·m 的拧紧力矩而只扭 0.15 rad，但工具的真实转角必须从扭转角反推，不能拿电机编码器当真值。轴向无需细算，EA/L ≈ 2×107 N/m，硬得像墙：轴向定位完全由机器人决定。

2. 串联刚度：末端刚度由软的一方说了算

横向看，机器人阻抗 Kbase 与轴刚度 Kshaft 串联：

1/Ktip = 1/Kbase + 1/Kshaft  ⟹  Ktip = KbaseKshaft/(Kbase+Kshaft) 串联只会"越串越软"：Ktip 永远小于两者中较小的那个

推论很有意思：想让尖端极软，根本不需要把控制器调软，用一根软轴（比如 Kshaft = 300 N/m 的尼龙管轴），把机器人 PID 调得刚性十足，尖端自然只有 ~300 N/m 的柔顺。而且这个柔顺是物理弹簧：它不耗采样率、不引入相位滞后、永远被动稳定。控制器在这里只需留出两点配合：其一，阻抗的参考位移要理解成"机器人侧位移"，尖端位移要加上轴的挠度；其二，轴的横向一阶共振不能与阻抗带宽打架：工具头质量 mt = 0.5 kg 时共振频率 √(Kshaft/mt) ≈ 24 rad/s（约 4 Hz），阻抗带宽压到它的 1/2 以下（≤ 2 Hz）或给尖端加阻尼头。这条约束比任何增益公式都硬：带宽撞上柔性共振，任何调参都是拆东墙补西墙。

3. 虚拟尖端：用力信号把看不见的点算出来

轴挠度与横向力近似线性（小挠度）：δ = F/Kshaft，方向沿力。于是可以不装尖端传感器，用"夹持点位置 + 力反推挠度"重建尖端：

xtip ≈ xbase + F横/Kshaft δ：轴端横向挠度，m；F横 取垂直于轴线的分量

它有 5–10% 的模型误差（轴的实际约束不是理想悬臂、挠度大时非线性），但用来做监控、限位、进给规划完全够用。工程直觉：软轴控制的"眼睛"一半是编码器、一半是力，缺掉任何一半，你要么不知道尖端在哪，要么不知道尖端受多大力。对打磨类任务还有一条隐含要求：进给方向必须垂直于力方向取切向分量（ch064 的任务坐标系），轴挠度方向判断错了，会使"实际切向"与"计划切向"差 5–10°，长期影响表面质量。

4. 旋转的软轴：周期性扰动与梳状滤波

轴一转，残留不平衡就产生旋转频率 fs 的横向力，高次谐波还会以 2fs、3fs 出现。典型数字：3000 r/min → fs = 50 Hz，不平衡力可达 1–5 N，远大于多数力控任务的稳态力误差预算（±1 N）。如果阻抗去"响应"它，最终只会把 50 Hz 的抖动穿到位置指令上，再通过传动链激励出嗡嗡声。对策是梳状滤波（comb filter）：把力信号对"恰好一个旋转周期"的样本做滑动平均；加大阻尼收效有限（对 50 Hz 抑制不足，还拖慢任务频段）：

Ns = fs/fspin（每转采样数），F̄(k) = (1/Ns)·Σ F(k−i) 对周期为 Ns 的整数倍频率（fs 及其谐波）增益为零；代价：群延迟 Tspin/2

这个滤波器的美妙之处在于：通带（0–10 Hz 任务频段）几乎不被衰减，陷波点却精确落在旋转谐波上（由物理转速决定，不需要"猜"），代价是一半旋转周期的延迟（50 Hz 时 10 ms），对力控环来说可以接受。转速变化时按当前转速重算 Ns（可用变频器转速或电流纹波估计），转速信号本身要平滑，否则滤波器长度抖动会引入低频寄生。

5. 回滞：软轴不怕弯，怕"记性"

多层缠绕的柔性轴（尤其带护套的传动轴）在正反向传动时有 3–10% 的回程误差：同样给 10 N 再回到"零力位置"，实际位置比出发时多偏 0.3–1 mm。这属于机械迟滞，控制器无法消除，只能"绕过"：（1）永远从同一侧逼近目标力（例如始终保持略大于目标的下压量）；（2）用"力闭环 + 位置初值"的组合：位置负责快速接近，力环负责最终精度，避免让开环位置承担它承担不了的回程误差；（3）换向时把积分类状态清零（ch063 的思想），防止迟滞被积分器"记住"变成慢漂移。

实现思路与设计

  1. 测轴的参数：用一次静态加载测 K横（挂 1–2 kg 砝码看挠度），比查表准，实际约束、护套刚度都影响结果；K扭 用扭矩标定。
  2. 算共振与带宽预算：f轴 = (1/2π)√(Kshaft/mtip)；阻抗带宽取 ≤ f轴/2；若任务要求更宽的带宽，换更粗的轴或加尖端阻尼。
  3. 分配刚度：由目标尖端刚度反推机器人侧：Kbase = KshaftKtip/(Kshaft−Ktip)，注意目标值必须小于轴刚度，否则无解（只能换轴）。
  4. 建虚拟尖端：xtip = xbase + F横/Kshaft，用于监控、限位与切向规划；挠度大于轴长 5% 时降级为告警。
  5. 抗旋转扰动力：梳状滤波（Ns = fs/fspin）加在力通道；转速平滑（时间常数 0.5 s）；转速低于 5 Hz 时不启用以避免超长窗口。
  6. 迟滞策略：单向逼近；力环里积分项在换向时清零；位置与力的分工写进状态机注释。

数字起点（0.3 m、6 mm 钢轴）：Kshaft ≈ 1400 N/m（实测可能 1000–1600）；工具头 0.5 kg → f轴 ≈ 8.4 Hz；阻抗带宽 ≤ 4 Hz；转速 3000 r/min → Ns = 20（1 kHz 采样）。

关键代码与解读

片段 1：软轴刚度与串联预算

import numpy as np

def shaft_stiffness(d, L, E=2.0e11, G=8.0e10):
    """悬臂软轴的横向/扭转刚度估计。d、L 单位 m。"""
    I = np.pi * d**4 / 64.0                # 圆截面惯性矩
    J = np.pi * d**4 / 32.0                # 极惯性矩
    k_bend = 3.0 * E * I / L**3            # 横向：3EI/L^3
    k_tors = G * J / L                     # 扭转：GJ/L
    return k_bend, k_tors

def series_target(k_shaft, k_tip_want):
    """由目标尖端刚度反推机器人侧需要的刚度（解 1/k_tip = 1/k_base + 1/k_shaft）。"""
    if k_tip_want >= k_shaft:
        # 串联只会更软：想要比轴还硬是不可能的，必须换轴/改机构
        raise ValueError(f"目标 {k_tip_want:.0f} N/m 已超过轴本身 {k_shaft:.0f} N/m")
    return 1.0 / (1.0 / k_tip_want - 1.0 / k_shaft)

k_b, k_t = shaft_stiffness(d=0.006, L=0.30)
print(f"横向 {k_b:7.0f} N/m   扭转 {k_t:5.1f} N.m/rad")
for want in (300.0, 600.0, 1000.0):
    print(f"目标尖端 {want:5.0f} N/m -> 机器人侧需 {series_target(k_b, want):7.0f} N/m")

解读：series_target 的异常分支是本段的知识点：串联刚度的上界就是最软环节本身，"想要末端比轴更硬"在物理上无解，这一句能省下大量现场调参时间（很多"末端怎么调都不够硬"的抱怨，根因是要么换了更软的轴、要么轴的固定端松了等效 L 变大）。三个目标值依次得到机器人侧 382 / 1050 / 3500 N/m：注意规律，目标越接近轴刚度，需要的机器人侧刚度爆炸式增长；工程上让 Ktip ≤ 0.6Kshaft，机器人侧负担才现实。

片段 2：虚拟尖端与"刚机器人 + 软轴"的配合

class ShaftAwareBase:
    """机器人侧保持刚性；用轴模型与力信号重建尖端，供监控与规划使用。"""
    def __init__(self, k_shaft=1400.0, axis_dir=(0, 0, 1), f_band=4.0, dt=1e-3):
        self.k_shaft = k_shaft
        self.axis = np.array(axis_dir, dtype=float) / np.linalg.norm(axis_dir)
        # 阻抗带宽：不超过轴-工具共振的 1/2，否则会与柔性共振互相激励
        self.f_band, self.dt = f_band, dt
        self.K_d = 3.0 * k_shaft            # 取 3 倍轴刚度：控制器保持刚性，尖端仍由物理轴主导
        self.D_d = 2.0 * 0.9 * np.sqrt(self.K_d * 0.5)
        self.x_cmd, self.v_cmd = 0.0, 0.0   # 机器人侧一维命令（横向）

    def lateral_tip(self, x_base, f_meas):
        """虚拟尖端：夹持点位置 + 力反推挠度。用于监控/限位，不做闭环。"""
        f_lat = float(np.dot(f_meas, self.axis))     # 垂直轴线方向的分量
        deflection = f_lat / self.k_shaft            # 线性小挠度模型
        if abs(deflection) > 0.05 * 0.30:            # 挠度超过轴长 5%：模型失效
            print("警告：软轴挠度过大，虚拟尖端不可信")
        return x_base + deflection

    def step(self, x, v, x_d, v_d, f_lat):
        # 刚性机器人侧：K 远大于轴刚度，尖端柔顺几乎全部由物理轴提供，
        # 控制器不需要"演柔顺"，也就不会把滞后与噪声带进接触过程
        a = -(self.D_d * (v - v_d) + self.K_d * (x - x_d) + f_lat) / 0.5
        self.v_cmd += a * self.dt
        self.x_cmd += self.v_cmd * self.dt
        return self.x_cmd

解读：这段代码的主旨和常见直觉相反：机器人侧刚度 K_d 取到轴刚度的 3 倍（约 4200 N/m），比"越软越好"的直觉高得多，因为
柔顺已经由物理轴提供；控制器越硬，接触回路的相位滞后越小、抗扰能力越强。真正需要"软"的数字只有两个：尖端等效刚度（由串联公式保证）与挠度告警线（5% 轴长）。若你确实需要比轴更软的尖端，请换轴；继续压低 K_d 换不来尖端柔顺，还会让控制回路更脆，控制器柔顺与物理柔顺的稳定性代价完全不同，这是本章最重要的一句工程直觉。

片段 3：旋转梳状滤波（对付不平衡扰动力）

class SpinCombFilter:
    """梳状滤波：窗口 = 恰好一个旋转周期，陷波落在 f_spin 及其谐波上。"""
    def __init__(self, fs=1000.0, f_spin=50.0, spin_smooth=0.5):
        self.fs = fs
        self.n = max(2, int(round(fs / f_spin)))   # 每转采样数
        self.buf = np.zeros(self.n)
        self.idx = 0
        self.sum = 0.0
        self.f_spin_lp = f_spin
        self.a_s = spin_smooth                     # 转速平滑系数（秒）
        self.dt = 1.0 / fs

    def update(self, f_meas, f_spin_meas):
        # 转速先平滑：滤波器长度 N 抖动会引入寄生低频，比原扰动更难治
        self.f_spin_lp += (f_spin_meas - self.f_spin_lp) * self.dt / self.a_s
        n_new = max(2, int(round(self.fs / max(self.f_spin_lp, 5.0))))
        if n_new != self.n:                        # 长度变化时整体重建（保持均值）
            self.buf = np.full(n_new, self.sum / max(self.n, 1))
            self.n, self.idx = n_new, 0
        # 滑动平均：先减旧值再加新值，O(1) 更新
        self.sum += f_meas - self.buf[self.idx]
        self.buf[self.idx] = f_meas
        self.idx = (self.idx + 1) % self.n
        return self.sum / self.n                   # 群延迟 T_spin/2，通带几乎无衰减

解读：梳状滤波的三处工程细节都在注释里，转速平滑防"窗口抖动"、长度变化时用均值重建缓冲（避免瞬时跳变）、滑动求和保持 O(1)。需要留意它的两个边界：转速低于 5 Hz 时窗口长于 0.2 s，群延迟开始影响力控相位，此时应关闭滤波（低速时不平衡力也小）；转速快速扫过时 f_spin_lp 的平滑时间常数决定滤波器"重新对频"的速度，0.5 s 是"够稳"与"够跟"的折中。若你只有编码器转速而无独立转速信号，用电机电流的基频估计也可以，转子不平衡与电流纹波基本同频。

常见坑

  • 无脑照抄梁公式：实际固定端有柔性、护套约束改变了边界条件，实测刚度可能与 3EI/L3 差 30% 以上。修复：静态加载实测；把实测值写进配置文件。
  • 想调出比轴更硬的尖端：串联公式无解的情况下不断加大控制器增益，接触环开始振荡却毫无收益。修复：接受 Ktip ≤ 0.6Kshaft 的现实；需要更硬就换轴。
  • 把电机编码器当工具转角：扭转角 0.15 rad 起步（5 N·m 时），工具实际相位比命令滞后 8° 以上，拧紧/对位任务直接出错。修复：用扭转刚度换算真实转角，或加装输出端编码器。
  • 阻抗去追不平衡力：50 Hz 的横向力被"当真"，指令里全是高频分量、电机嗡嗡响。修复：梳状滤波 + 转速平滑；滤波窗口绝不能随转速估计抖动。
  • 忽略回滞：开环位置控制下，正反向 10 N 循环后零点漂 0.5 mm，表现为"重复精度忽好忽坏"。修复：单向逼近 + 换向清积分 + 关键工序给位置环加回差补偿表。

  4. 设计：一根软轴的实测横向刚度 900 N/m，工具头 0.8 kg，要求打磨接触力的带宽 3 Hz。推导共振频率、判定带宽是否可行；若不可行，给出两种工程解法并比较代价。 ★★★
    提示
    f = √(900/0.8)/2π ≈ 5.3 Hz；3 Hz 已接近 5.3/2，边界；解法：换粗轴（提刚度提共振）或加尖端阻尼（降共振峰），前者改硬件，后者可能引入摩擦。
  5. 思考题：为什么"物理弹簧的柔顺"比"控制器算出来的柔顺"更稳？从采样率、相位、能量三个角度各写一句。 ★★
    提示
    物理弹簧不经过采样与延时、没有额外相位滞后、结构上永远被动不注入能量；控制器柔顺的"稳定性预算"要分一部分给这些非理想因素。

小结

  • 软轴的横/扭刚度可估：K横 = 3EI/L3、K扭 = GJ/L；6 mm×0.3 m 钢轴约 1400 N/m、34 N·m/rad。
  • 横向串联刚度决定尖端软硬（只会越串越软）；轴向由机器人主导；设计目标取 Ktip ≤ 0.6Kshaft。
  • 利用物理柔顺：控制器保持刚性，让轴提供软件无法安全实现的大柔度；配合虚拟尖端（力反推挠度）完成监控与规划。
  • 旋转不平衡力用梳状滤波治理：窗口 = 一个旋转周期，陷波精确、通带保真，代价是半个周期的群延迟。
  • 回滞属于机械"记性"：单向逼近 + 换向清积分 + 力环兜底，别指望位置开环。
  • 下一章换场景：柔顺的对象从"被动柔性"变成"主动冗余"，导入控制下冗余机器人的零空间怎么保持姿态不添乱。
