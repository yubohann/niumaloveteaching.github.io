第五篇 · 鲁棒控制与工程实践

第 096 章：阻抗控制中的接触状态检测

机器人必须先知道自己"在不在接触"、接触得稳不稳，才能切换参数、启用门控、判断好坏。本章把这件事做成一个带迟滞与驻留的状态机，并划清工程上最难说清的一条线：什么是"接触"，什么是"碰撞"。

  • 主题：接触状态检测 / 状态机与阈值设计
  • 关键公式：t检测 ≈ fth/(K̂env·v)；进入门限 5σ、退出门限 3σ
  • 预计学时：60 分钟
  • 前置章节：第 095 章

学习目标

  • 理解接触状态是"控制模式、参数门控与安全逻辑"的共同输入：没有状态量，一切自适应、学习、补偿都无从谈起。
  • 能清楚区分"接触"与"碰撞"：预期与计划外、渐进与突发、力幅值与动量突变，两者的检测通道与响应路径完全不同。
  • 会设计三件套检测器：噪声统计定阈值（5σ/3σ）、迟滞（Schmitt）防抖、驻留时间（dwell）过滤瞬态。
  • 会推导检测延迟公式 t ≈ fth/(K̂env·v)，并用它做"阈值—延迟—虚警"的三方权衡。
  • 会实现"armed 窗口"（只在计划接触的位置/阶段允许判接触），把计划内的轻触与计划外的撞击分流到不同处理链路。

背景与动机

翻回前面几章，你会发现接触状态几乎无处不在：第 082 章的迭代学习"只学接触段"；第 083 章的自适应增益"非接触段必须冻结"；第 091 章的零点漂移跟踪"只在不接触时更新"；第 093 章的负载辨识"只能在自由运动窗口进行"。所有这些"门控"都依赖同一个判断：机器人现在到底在不在接触？状态错了，学习会把自由段误差学成偏置，零漂跟踪会把接触力当零点，负载辨识会把工件力当自重，每一条都是以事故结尾。

但"接触"远不止有无两个值。工程上更有价值的是分辨：空载（FREE）、稳定接触（CONTACT）、接触失稳/打滑（SLIP）、意外碰撞（COLLISION）。前两个是日常工作，后两个是安全与工艺问题。本章先解决最基本的"是否接触 + 接触是否稳定"，并把接触与碰撞的边界作为核心概念讲透，因为这条线划不清楚，第 097 章的碰撞检测就会把日常接触全部误判成事故。

检测本身的难度不在算法，在权衡：阈值低一点，检测更灵敏但噪声会引发虚警；滤波厚一点，信号更干净但检测延迟增加，机器人已经多压进去了几毫米。本章把这份权衡量化成一条可计算的公式。

核心原理

1. "接触"与"碰撞"：同一物理、两种事件

物理上，两者都是"机器人与物体发生了相互作用"。工程上的分界不看现象，看上下文与预期：

维度接触（contact）碰撞（collision）
预期性计划内：任务要求的工作面、装配对象计划外：人、夹具、障碍、错位工件
建立过程渐进：接近速度低（约 1–50 mm/s），力渐进上升突发：相对速度高，力/动量突变，毫秒级
主导检测通道力幅值 + 计划阶段（armed 窗口）动量观测残差（第 097 章）
响应策略保持柔顺、切换参数、记录停止/回退/报警（第 098、099 章）

工程直觉：接触是"预约过的见面"，碰撞是"没预约的撞见"。检测上最实用的分工是：用计划信息（当前点是不是应该接近工件、离预期表面还有多远）给检测器"上膛"（armed）；上膛窗口内、渐进上升的力 = 接触；窗口外、突然出现的力 = 碰撞（送第 097 章处理）。没有这份上下文，任何单一阈值都同时会误报和漏报。

2. 基元检测器：阈值 + 迟滞 + 驻留

最基础的接触判据是"力幅值超阈值"，但裸阈值注定抖动：信号在阈值附近上下浮动时，状态会以采样频率来回切换，下游的门控就会"抽搐"。工业界标准的三件套是：

进入条件：|F| > fon 且持续 ton（驻留）；退出条件：|F| < foff 且持续 toff，且 foff < fon（迟滞） fon 取 5σ–10σ、foff 取 3σ–5σ；示例 1.0/0.5 N（σ = 0.1 N）；ton = 5 ms、toff = 20 ms

三件套各自解决一个问题：阈值把"噪声"和"信号"分开（5σ 的高斯尾部概率约 3×10−7/样本，即使高频采样也极难误触发）；迟滞让进入/退出用两条不同的线，防止在单条线附近振荡；驻留进一步过滤瞬态（电气尖峰、电磁干扰、传感器自检脉冲），代价是引入了几毫秒的固定延迟。退出驻留（20 ms）比进入驻留（5 ms）更长是有意的："接触中"误判成"脱离"会触发错误的状态重置（比如零点跟踪突然开始学习），而"脱离"多等 20 ms 基本无害，不对称的门限应该按"哪种错误更贵"来设。

3. 检测延迟与阈值预算：一条公式拍板

接触建立的物理过程很直观：工具以速度 v 压向刚度为 K̂env 的表面，接触力近似按 Ḟ ≈ K̂env·v 上升。要触发阈值为 fth 的检测器，需要的时间就是

t检测 ≈ fth / (K̂env·v) 例：fth = 1 N、K̂env = 104 N/m、v = 20 mm/s ⟹ 5 ms，期间多压入 0.1 mm

这条公式是阈值选择的核心：框架静度 K̂env 越大、接近速度越高，同样的阈值对应的延迟越小、越"划算"；反过来，软环境（海绵 103 N/m）低速接近（5 mm/s）时，1 N 阈值意味着 200 ms 延迟、1 mm 的额外压入，这就是软接触总被"迟到发现"的原因。工程做法：把这条公式写进参数表，按最坏工况（最软环境 + 最低速度）核算延迟，如果延迟不可接受就两条路，降阈值（要付虚警的代价）或主动规划"探测动作"（先小步试探建立接触，再进入任务，见第 099 章的 guarded move）。

顺带说清"接触稳定/失稳"与"打滑"：稳定接触的特征是力围绕均值小幅波动（波动 RMS ≈ 传感器噪声）；失稳（如未建模的柔性、间隙）会表现为周期性的力振荡，可用滑窗方差检测；打滑则要看摩擦力锥：当切向力比 |Ft|/Fn 逼近摩擦系数 μ 时进入滑移风险区，

滑移判据：|Ft| > μ̂·Fn - margin ⟹ SLIP（应加大夹紧力或降低切向加速度） μ̂：摩擦系数估计（典型钢-橡胶 0.4–0.8；油污面可低至 0.1）

4. 与估计力、滤波的关系（跨章一致性）

两个"阈值重标定"的提醒：（1）如果力信号来自第 090 章的观测器估计，σ 属于"估计噪声"（含摩擦残差、模型误差），不再等同于传感器噪声，阈值必须按估计通道重新统计，否则会把摩擦残差判成接触；（2）第 047 章的滤波会同时压低噪声和平滑力的上升沿，延迟公式里的 Ḟ 比理论值小，检测时间比公式更长。工程校核方法：在做完整信号链（滤波、补偿、载入）后，用"慢速压向标定块"的实测记录反推 σ 与 Ḟ，把公式里的参数替换成实测值，数据手册值只能作对照。所有门限类参数都必须来自"当前信号链"的统计，不能沿用历史项目的复制粘贴，这是本章最重要的一条工程习惯。

实现思路与设计

  1. 统计 σ：自由空间、静止、完整信号链下采 2 s，按第 091 章的稳健方法得到每轴 σ（典型 0.06–0.1 N）。
  2. 定阈值：进入取 5σ–10σ（先试 5σ，按延迟与虚警上浮）、退出取 3σ–5σ；同时按最坏工况用公式核算延迟。
  3. 驻留：进入 5 ms（别错过真接触）、退出 20–50 ms（别被振动打扰）；驻留计时用"连续满足"，一旦中断清零。
  4. armed 窗口：由"计划信息"给出，离预期表面 < 2 mm、或以低速接近、或任务状态是"探查/装配"。窗口外不判"接触"，只做"碰撞候选上报"。
  5. 附加判断（可选）：用 F/(x−x̂e) 估计接触刚度以识别基底类型（工件 vs 夹具），用滑窗方差判失稳，用 |Ft|/Fn 判打滑。
  6. 状态输出与接口：FREE/CONTACT/SLIP 每个状态发送给学习、自适应、零漂跟踪、负载辨识、安全模块；所有下游只认这一个"唯一真值源"，禁止各自再写一份阈值判断（重复判据是现场事故的经典来源）。
设计决策：为什么退出测量要用"更慢的阈值 + 更长驻留"？

退出（接触→自由）意味着"收工"信号：零点跟踪要开始学习、负载辨识可能触发、学习器可能收集样本。如果退出判早了（把瞬时力下探当脱离），这些模块会在接触状态下拿到错误数据；而且接触中的微振动本身常出现短暂的力低谷，20 ms 驻留足以滤掉它们，而人类和任务的时间尺度完全来得及。反过来的进入（自由→接触）判晚一点只是在参数切换上晚几毫秒，代价小。不对称设计的统一原则：把"更贵的错误"拖得更不容易发生。

关键代码与解读

片段 1：迟滞 + 驻留的接触状态机

import numpy as np

class ContactDetector:
    """接触状态检测：幅值门限 + 迟滞 + 驻留时间；armed 窗口区分接触/碰撞。"""
    def __init__(self, f_on=1.0, f_off=0.5, t_on=5e-3, t_off=2e-2, dt=1e-3):
        self.f_on, self.f_off = f_on, f_off       # 进入/退出门限（迟滞）
        self.t_on, self.t_off = t_on, t_off       # 进入/退出驻留时间
        self.dt = dt
        self.state = "FREE"
        self.timer = 0.0

    def update(self, f_mag, armed=True):
        # armed=False：不在计划接触窗口内。此刻出现的力属于"意外"，
        # 不判为接触；它将被送往碰撞检测链路（第 097 章）
        if not armed:
            if self.state == "CONTACT":
                self.state, self.timer = "FREE", 0.0
            return self.state
        if self.state == "FREE":
            self.timer = self.timer + self.dt if f_mag > self.f_on else 0.0
            if self.timer >= self.t_on:           # 连续超过进入门限才确认
                self.state, self.timer = "CONTACT", 0.0
        else:
            self.timer = self.timer + self.dt if f_mag < self.f_off else 0.0
            if self.timer >= self.t_off:          # 退出更保守：驻留 4 倍
                self.state, self.timer = "FREE", 0.0
        return self.state

解读：状态机只有两个状态、两条转移，但每一行都有设计依据。（1）armed 放在最前面：未上膛时不进入 CONTACT，这就是"接触/碰撞分流"的实现；注意它还顺手把 CONTACT 状态强制清零，避免"计划窗口结束后状态残留"。（2）计时器用连续满足逻辑（不满足即清零），这保证"闪烁式"的噪声无法拼凑出驻留时间。（3）门限与驻留作为构造参数暴露，便于现场按第 3 节的公式与实测 σ 重标定；把状态机的参数与"下游用途"写进同一份配置，杜绝各模块私下改门限。

片段 2：接近—接触—脱离的全程仿真

def run_contact(det, n=4000, dt=1e-3, noise=0.1, seed=5):
    """一维轴探测：约 2.5 s 处慢速触壁（20 mm/s），3.5 s 处退出。"""
    rng = np.random.default_rng(seed)
    k_env, x_wall = 1e4, 0.0
    x, v, log, triggers = 0.0, 0.0, [], []
    prev = det.state
    for i in range(n):
        t = i * dt
        # 期望速度：1-2.52 s 接近（20 mm/s）；2.52-3.5 s 保持；之后回退
        if 1.0 <= t < 2.52: v_ref = 0.02
        elif 2.52 <= t < 3.5: v_ref = 0.0
        else: v_ref = -0.03
        v += (v_ref - v) * dt / 0.02            # 近似速度伺服（时间常数 20 ms）
        x += v * dt
        f_true = k_env * (x - x_wall) if x > x_wall else 0.0
        f_meas = f_true + rng.normal(0.0, noise)     # 0.1 N 噪声
        armed = x > -0.002                      # 离预期表面 2 mm 内才上膛
        st = det.update(abs(f_meas), armed=armed)
        if st != prev:
            triggers.append((round(t, 3), st))
            prev = st
        log.append(st)
    return triggers, log

det = ContactDetector(f_on=1.0, f_off=0.5)
tr, _ = run_contact(det)
print("状态切换序列:", tr)

解读：预期输出是两次干净的切换：FREE → CONTACT（约 2.53 s，接触后 1 N 阈值按公式 5 ms 达成）、CONTACT → FREE（回退段约 3.55 s，等力降到 0.5 N 再驻留 20 ms）。三个实现细节值得品味：（1）armed 用位置门控实现（2 mm 内上膛），现实系统里更常用"任务状态 + 位置"联合判断；（2）速度伺服用一阶近似（时间常数 20 ms），避免引入完整控制器扰乱教学重点；（3）记录每次切换的时间戳，这份序列就是验收材料，把实测切换时刻与公式预测（t ≈ 2.5 s + fth/(Kenvv)）对照，误差应在 1–2 ms 内。

片段 3：阈值—延迟—虚警的预算表

from math import erfc, sqrt

def threshold_budget(sigma=0.1, k_env=1e4, v=0.02, fs=1000.0):
    """对候选阈值列出：虚警概率（每样本/每秒）与检测延迟。"""
    print(f"sigma={sigma:.2f} N  K_env={k_env:.0e} N/m  v={v*1000:.0f} mm/s")
    for n in (3.0, 4.0, 5.0, 6.0):
        f_th = n * sigma
        p = 0.5 * erfc(n / sqrt(2.0))          # 单样本误触发概率（高斯尾）
        per_s = p * fs                          # 每秒钟期望的虚警次数
        t_det = f_th / (k_env * v)              # 检测延迟（秒）
        print(f"  {n:.0f}sigma: f_th={f_th:4.2f} N  虚警={per_s:7.2e}/s  "
              f"延迟={t_det*1000:5.1f} ms")

threshold_budget()

解读：这张表把"阈值该取几 σ"从玄学变成算术：3σ 的虚警率约 1.3×10−3/样本 ， 1 kHz 下平均每秒 1.3 次，直接不可用；5σ 降到每千秒 0.3 次，配合 5 ms 驻留几乎不可能误报；6σ 更安全但延迟按比例上升（本例 6 ms）。结论：在 1 kHz 采样下，"5σ + 驻留"是性价比最高的组合；如果力信号采样率低（100 Hz），同样的 5σ 每秒虚警下降 10 倍，阈值可以适当放宽。注意 erfc 来自 Python 标准库 math，不引入额外依赖。表里还隐含一个设计动作：把延迟与"多压入多少毫米"（延迟 × v）一起写进工艺允许量，做一次校核。

常见坑

  • 裸阈值无迟滞：信号在门限附近时状态每毫秒跳一次，下游门控"抽搐"（学习器反复启动停止）。修复：进入/退出双门限 + 连续驻留，切换次数在日志里可审计。
  • 阈值取自数据手册：手册的噪声是在实验室屏蔽环境测的；产线上的 σ 可能是 2–3 倍。修复：每次装机后在完整信号链上实测 σ，重标定门限（第 091 章的流程直接复用）。
  • armed 窗口过宽或过窄：过宽会把"计划外但离得近"的碰撞漏给接触分支（危险）；过窄会在稍偏的工件上"永远不接触"（任务卡死）。修复：窗口按几何标定的不确定性给（如 ±1.5 mm），并在任务开始前用寻面动作校准。
  • 把滤波延迟当零：47 章的 20 ms 低通让力的上升沿变缓，检测延迟可能比公式大一倍。修复：用实测上升沿斜率（不是理论 K·v）代入延迟公式。
  • 多个模块各自判接触：学习器、零漂跟踪各写一份阈值判断，出现"学习器认为接触了、跟踪器认为没有"的冲突。修复：全系统唯一状态源，下游只订阅不重判。

  3. 把噪声 σ 从 0.1 增到 0.3 N（模拟未滤波的估计力，第 090 章），用片段 3 的表格重新选择阈值，并说明"阈值、延迟、虚警"三者的新平衡点在哪里。★★
    提示
    σ 增大 3 倍后，5σ = 1.5 N，延迟从 5 ms 增到 7.5 ms；若想恢复延迟必须降 σ（加滤波或改善估计），说明"信号质量"是不能靠参数技巧绕过的地板。
  4. 设计一个完整的接触状态机（含 SLIP）：画出状态图（FREE/CONTACT/SLIP），写出各转移的条件（含滞回与驻留）与响应动作；再用一维仿真制造一次打滑（切向比为独立假想量）验证转移序列。★★★
    提示
    SLIP 进入条件 |Ft| > μ̂Fn − margin 且持续 10 ms；退出条件 |Ft| < 0.8μ̂Fn 且持续 50 ms；响应：夹紧力 +20%、切向加速度减半、记录事件。状态图请把三个状态画成三角形并标双向转移。

小结

  • 接触状态是全部门控与参数切换的唯一真值源：学习、自适应、零漂跟踪、负载辨识、安全模块都订阅它，禁止各自重判。
  • 接触 vs 碰撞的本质分界是"预期性"：armed 窗口内、渐进上升的力是接触；窗口外、突发的力是碰撞（下一章用动量残差检测）。
  • 检测三件套：5σ/3σ 双阈值 + 迟滞 + 不对称驻留（进入 5 ms、退出 20 ms）；阈值来自完整信号链的实测统计。
  • 核心预算公式 t检测 ≈ fth/(K̂env·v)：软环境 + 低速 + 高阈值是延迟的三大来源，必要时用"探测动作"主动建接触。
  • 下一章处理"窗口外的力"：碰撞检测，用动量观测残差看见突发外力，并设计自适应阈值，让检测既不漏报也不被高速运动误触发。
