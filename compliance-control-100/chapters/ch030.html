第 030 章：零力控制实现

让机器人在任意方向上"零阻力"：重力、摩擦、模型偏差统统抵消，人用极小力就能推任意方向。本章给出模型前馈 + 广义动量观测器 + 静置自标定的完整实现，并解释"无差别补偿会自激"的原因。

  • 主题：零力控制 / 观测器 / 重力摩擦补偿
  • 关键公式：τcmd = ĝ(q) + τ̂f(q̇) − Bvq̇ + τ̂off，r = Ko(p − ∫(τcmd + CTq̇ − ĝ + r)dt)
  • 预计学时：55 分钟
  • 前置章节：第 028 章、第 029 章

学习目标

  • 说清"零力控制"的物理定义：把机器人自身的重力、摩擦、模型偏差抵消到"人几乎感觉不到"，只留下可调的虚拟阻尼（外力并不会因此变成零）。
  • 会推导并实现广义动量观测器：不用加速度计、不做数值微分，从动量积分残差里估计外部力矩。
  • 掌握"静置自标定"：利用观测器残差在无人触碰时的读数估计重力/摩擦的模型偏差，解释它为什么比在线连续补偿安全。
  • 理解"无差别扰动补偿会自激"的机理：把阻尼和手力一起当扰动抵消，导致松开手后系统自己加速。
  • 掌握补偿量的权限限制与验收指标（推力阈值、停止时间、静置漂移），把零力控制器按工程标准交付。

背景与动机

第 028、029 章的两个拖动方案，背后都站着一个共同的"使能技术"：零力控制，让机器人对任意外力近乎"零阻抗"地响应。它不止服务于拖动示教：换工具时人工摆位、协作场景中"顺手推一把让开"、手动引导机器人进出狭小空间，都需要这个能力。第 028 章的力矩式方案要求好的重力/摩擦模型，第 029 章的导纳式方案要求腕部力传感器；而在既没有六维力传感器、也没有关节力矩传感器、模型还不准的机器人上，怎么做到"零力"？答案是把广义动量观测器（generalized momentum observer）请进来，它只用编码器与电流/力矩命令，就能估计"总外部力矩"，让控制器知道"机器人现在被多重的力拖着"。

但"零力"三个字有一层容易踩空的坑：观测器测到的"外部力矩"里，混着力、摩擦、模型误差、乃至你自己施加的阻尼，如果不加区分地全部抵消，就等于把阻尼和人的手也一起拉开，系统会自激。本章的关键内容就是把这层区分讲清楚，并给出一套安全、可验收的实现路线。

核心原理

1. 零力条件：把动力学方程里"不属于人的项"全部消掉

关节空间刚体动力学（再次列出，因为一切从这里出发）：

M(q)q̈ + C(q,q̇)q̇ + g(q) + τf(q̇) = τcmd + τext τext：外部力矩（人手、接触力在关节上的等效）；其他符号同第 028 章

若控制器取：

τcmd = ĝ(q) + τ̂f(q̇) − Bvq̇ + τ̂off 前三项 = 重力 + 摩擦 + 虚拟阻尼；τ̂off = 对模型偏差（补偿残差）的估计，见第 3 小节

并且把 M̂、Ĉ 的整形项留给"进阶实验"，则残余动力学为 M(q)q̈ + Bvq̇ ≈ τext + Δτ（Δτ 为模型偏差）。零力条件 = Δτ 尽量小：人手不需要托重力、不需要克服摩擦，只需提供"想让系统怎么动"的那部分力矩。反过来说，零力控制的质量就是"Δτ 的大小"：典型指标是，轻推 1–2 N 的力能让末端开始运动（对应关节上 0.2–0.5 N·m 的静摩擦残差）。

和拖动示教（028）的关系：零力控制是"底层能力"，028 是"上层工作流"（记录与回放）；和导纳式（029）的关系：零力控制不要求力传感器，代价是残差水平受模型与观测器精度限制，一般比传感器方案大一个量级。

2. 广义动量观测器：不借加速度传感器估计外力

观测器要解决的核心困难：外力 τext 只出现在动力学的高阶项里，而 q̈ 难以直接测。广义动量观测器绕开 q̈ 的办法很妙：对整个动力学做动量积分。定义广义动量 p = M(q)q̇，并利用 Ṁ − 2C 反对称的性质，可以推出：

ṗ = τcmd + CT(q,q̇)q̇ − g(q) − τf + τext 对 ṗ 做积分不需要 q̈，只需要 q、q̇ 与各项力矩，全部可测/可算

于是构造残差 r（观测器状态）：

r = Ko [ p(t) − ∫0t( τcmd + CTq̇ − ĝ + r ) dτ ] Ko：观测器增益（1/s 量级，20–100）；r 的稳态值趋近于"未被模型解释的外部力矩"，含摩擦与碰撞

直觉理解：右边括号里是"用模型预测的动量"与"真实动量 p"的差。真实动量比预测多，说明有外力在推（r 变正）；少则说明有阻力（r 变负）。r 以 Ko 的带宽逼近 τext 的第一时间常数滤波版本。工程参数：Ko 越大跟踪越快、但对噪声越敏感；典型取 30–60，配合 10–20 Hz 低通使用。注意符号约定：本章的 r 估计的是"模型之外的一切"，也包括摩擦，它既能当"外力表"用（拖动意图检测），也会在补偿设计里引发第 3 小节的陷阱。

3. 补偿什么、放过什么：三条纪律

把 r 直接反向加进命令（τcmd ← τcmd − r）看起来"什么都能补"，但等于把整个机器人变成"无扰动系统"，包括把你自己的阻尼 Bvq̇ 和人的手力也当成扰动抵消：人一推，r 变正，控制器反向补掉推力，手感到"黏"；更糟的是阻尼被抵消后系统失去耗散，松手瞬间储能释放，机器人自激加速。前面章节的验证实验再次提示了这个现象：无差别补偿的 1-DOF 系统在松手后仍以数 rad/s 自走。

正确的纪律是三条：

  1. 结构化补偿：摩擦按"速度的函数"补（τ̂f = τctanh(q̇/vs) + bq̇），不按"测到的扰动"补，只有与速度方向强相关的慢变部分进入补偿，人的快变动作自然通过。
  2. 静置自标定：模型偏差（如 ĝ 少算了工具 0.3 kg）是常值/慢变量，利用"无人触碰且静止"的时间窗口估计：此时 q̇≈0、τext≈0，r 的读数就是模型的静态偏差 τ̂off。闲时学习、忙时服从，与第 029 章的零偏策略同构。
  3. 权限与带宽限制：无论 τ̂off 还是任何在线补偿，都做幅值限幅（如 ≤ 15% 额定力矩）与速率限制；补偿估计的更新带宽 ≤ 1 Hz。这样即使估计错了，最坏影响有界。

实现思路与设计

  1. 准备：需要关节位置（高分辨率）、关节速度（滤波后）、力矩命令与刚体参数；工具负载参数可由第 029 章同样的多姿态方法标定（无传感器时用观测器 r 代替力读数，原理一致）。
  2. 观测器参数：Ko = 40 起步；r 后接 15 Hz 低通；Ko 与滤波共同决定 r 的时间常数（本章重点看稳态值，快速性要求不高）。
  3. 静置标定流程：上电 → 只启用重力补偿 → 静置 3 s（判据 |q̇| < 0.02 rad/s 持续 2 s）→ 记录 r 均值作为 τ̂off → 进入零力模式。运行中每 5 分钟无操作窗口微更新一次（步长 ≤ 0.05 N·m）。
  4. 阻尼与限幅：Bv = 0.5–1.5 N·m·s/rad（按轴惯量）；关节速度限 0.5 rad/s、力矩输出的变化率限 50 N·m/s；任一关节接近限位时该轴阻尼 ×3。
  5. 验收指标：推动启动阈值（各方向 < 2 N 末端力）、松手停止时间（< 1 s 或最大 5° 滑行）、静置漂移（60 s < 10 mm）、自激测试（快速推-松-推不应越推越快）。
设计决策：摩擦模型为什么用 tanh？最基础的 sign 差在哪？

这是零力手感的"最后一厘米"。sign 模型在零速附近不连续，补偿力矩来回跳，机器人静止时能听到/摸到高频抖动（典型的"嗡嗡"感）。tanh 的平滑过渡（速度尺度 vs = 0.02–0.1 rad/s）让穿越零点时机力矩连续；配合滤波良好的速度估计，手推的"起步感"会显著变轻。这与第 028 章是同一个技术，说明它属于零力控制的通用工具集。

关键代码与解读

片段 1：广义动量观测器

import numpy as np

class MomentumObserver:
    """广义动量观测器：从动量积分残差估计外部力矩。
    r 的稳态趋近于"模型未解释的外力矩"（含摩擦、碰撞、人手）。"""
    def __init__(self, n, k_o=40.0):
        self.n, self.k_o = n, k_o
        self.p_int = np.zeros(n)     # 积分状态：模型预测的动量
        self.r = np.zeros(n)         # 残差（外部力矩估计）
    def step(self, qd, M_q, C_T_qd, g_hat, tau_cmd, dt):
        # 广义动量 p = M(q) * qd：无需加速度，只用可测的 q、qd
        p = M_q @ qd
        # 对 (tau_cmd + C^T*qd - g_hat + r) 做积分（用 r 补偿自身，收敛更快）
        self.p_int += dt * (tau_cmd + C_T_qd - g_hat + self.r)
        self.r = self.k_o * (p - self.p_int)
        return self.r.copy()

解读：三行数学，一行代码。p - self.p_int 是"真实动量与预测动量之差"：被外力推着，真实动量增长更快，差为正，r 给出正的外力矩估计。积分项里包含 self.r 自身，是标准的观测器收敛结构（相当于预估校正环），使 r 以一阶时间常数 1/Ko ≈ 25 ms 跟踪外部力矩。C_T_qd 与 g_hat 由模型给出（第 013 章的做法）；模型越准，r 的"底盘"越干净。注意：输入里没有加速度、没有力传感器，这正是它取代"微分 q̇ 求 q̈"或昂贵传感器的价值。低通滤波（15 Hz）在调用处做，别塞进这个类，保持职责单一。

片段 2：零力控制器，结构补偿 + 静置标定 + 权限限制

class ZeroForceController:
    """零力控制：重力/摩擦前馈 + 静置偏差标定 + 虚拟阻尼。
    不做"无差别扰动抵消"，人力和阻尼必须能通过。"""
    def __init__(self, n, b_v=1.0, off_max=15.0, dt=1e-3):
        self.n, self.dt = n, dt
        self.b_v = b_v                      # 虚拟阻尼（可逐轴）
        self.off_max = off_max              # 静态偏差补偿的幅值权限(N*m)
        self.tau_off = np.zeros(n)          # 静置标定得到的模型偏差
        self.idle_time = 0.0
    def update_offset(self, qd, r_filt):
        """只在'无人触碰且静止'时学习偏差：闲时学习，忙时服从。"""
        if np.linalg.norm(qd) < 0.02:
            self.idle_time += self.dt
        else:
            self.idle_time = 0.0
        if self.idle_time >= 2.0:           # 静止 2 s 才开始采样
            # 小步长慢更新（速率限制），并做幅值权限限制
            step = 0.02 * self.dt * 50.0 * r_filt   # 等效带宽 ~0.02*50=1 Hz
            self.tau_off = np.clip(self.tau_off + step,
                                   -self.off_max, self.off_max)
    def command(self, q, qd, g_hat, tau_f_hat, r_filt):
        self.update_offset(qd, r_filt)
        # 结构化补偿：重力 + 摩擦模型 + 静置偏差 - 虚拟阻尼
        tau = g_hat + tau_f_hat + self.tau_off - self.b_v * qd
        return tau

解读：这段代码表面朴素，但每一行都对应第 3 小节的一条纪律。update_offset 里的双重条件（静止 + 2 s 确认）保证学习窗口里没有人的力：此时 r 读数中的"外力"只剩模型偏差，学习方向正确；一旦有人推动，idle_time 清零、学习冻结，缺陷在于它学得慢，但慢正是安全属性。step 里 0.02*dt*50 这种写法把"学习带宽约 1 Hz"翻译成每拍增量，工程上比直接调参更可解释。command 中摩擦来自结构化模型 tau_f_hat（例如 τctanh + bq̇），与"无差别补偿"的 −r_filt 划清了界限。阻尼项 -b_v*qd 原样保留，让松手后系统有确定的减速通道。

片段 3：一维验证，有/无零力补偿的推力实验

def zero_force_demo(zero_force=True, tau_h=3.0, dt=1e-3, T=9.0):
    """一维轴：真实重力 5 N·m、库仑摩擦 2 N·m；模型略偏（ĝ=4.8）。
    3-6 s 人手推 3 N·m，其余时间松手。"""
    J, qd, off, log = 1.0, 0.0, 0.2, []   # off=0.2 为静置标定学到的偏差
    for i in range(int(T/dt)):
        t = i * dt
        th = tau_h if 3.0 <= t < 6.0 else 0.0
        if zero_force:
            tau_cmd = 4.8 + 1.7*np.tanh(qd/0.05) + off - 1.0*qd
        else:
            tau_cmd = 0.0                  # 完全不做补偿：纯伺服断使能
        qd += dt*(tau_cmd + th - 5.0 - 2.0*np.tanh(qd/0.05))/J
        log.append(qd)
    return np.array(log)

for zf in (True, False):
    L = zero_force_demo(zf)
    tag = "零力补偿" if zf else "无补偿  "
    print(f"{tag}: 推动段速度 {L[4500]:5.2f} rad/s,"
          f" 松手 3 s 后 {L[-1]:5.3f} rad/s")

解读：这组数字是整章的落点。无补偿时：重力 5 + 摩擦 2 的阻力远超人手的 3 N·m，轴倒退（被自重拖走，速度可达 −9 rad/s 量级，重力根本没被托住）。零力补偿后：残余阻力只有模型偏差 (5−4.8) + (2−1.7)tanh ≈ 0.3 N·m 量级，人手 3 N·m 让轴平稳加速到 2.5 rad/s 量级，松手后靠阻尼衰减、3 s 内完全停下（打印 0.000 级）。注意 off=0.2 正是静置标定学到的 0.2 N·m 偏差，它就是"从业余到能用"的关键 20%。真机上把这三个数字做成验收表：推动启动阈值、推动稳态速度、松手停止时间，每次换工具后复测。

常见坑

  • 无差别扰动补偿：把 −r 全部加进命令，连阻尼与手力一起抵消。症状：松手后机器人自走、快速推拉后越推越快。修复：结构化补偿 + 静置学习，如片段 2 的设计。
  • 观测器带宽设置过高：Ko = 200 以上时，r 里全是编码器量化噪声与电流纹波，补偿力矩把噪声注入关节。修复：Ko = 20–60 + 15 Hz 低通；不要用未滤波的 r 做任何高带宽用途。
  • 速度估计未滤波直接进 tanh：摩擦补偿的 tanh 输入抖动，零速附近产生高频力矩颠簸。修复：20 Hz 速度低通 + tanh 速度尺度取 0.05 rad/s 量级。
  • 静置标定当天与次日结果不一致：温度变化让零偏/摩擦漂移，被算进 τoff。修复：限制 τoff 权限（≤15% 额定）、运行中慢更新，并在验收表里记录标定时间与温度。
  • 用零力模式当"安全模式"：零力模式下机器人几乎无阻抗，一旦发生意外接触也没有抵抗力可依赖。修复：零力模式必须与使能按钮、速度/位置限幅绑定（第 025、027 章），它不是急停的替代品。

练习与思考

  1. 写出广义动量 p = M(q)q̇ 的时间导数，并说明 Ṁ − 2C 的反对称性如何被用来消掉 q̈ 项（提示：代入拉格朗日方程）。★★★
    提示
    ṗ = Ṁq̇ + Mq̈；用 Mq̈ = τ + τ_ext − Cq̇ − g − τ_f 代入，Ṁ − 2C 反对称给出 Ṁq̇ − Cq̇ = CTq̇。
  2. 取 Ko = 40，计算观测器残差 r 对真实外力的跟踪时间常数；若 Ko 提高到 100，跟踪快多少、噪声放大多少倍（按幅频近似）？★★
    提示
    τ ≈ 1/Ko = 25 ms → 10 ms；带宽提高 2.5 倍，对白噪声的增益近似按带宽比放大。
  3. 设计一个"自激检测"：在零力模式下记录"推-松-推"序列的速度包络，给出判定"越推越快"的数值判据与处理动作。★★
    提示
    比较连续两次"松手段"的最大速度：第二次显著大于第一次（如 >120%）即触发；处理动作=退出零力模式、报警并冻结 τoff 学习。
  4. 实验：把片段 3 的摩擦模型增益 1.7 改为 2.2（过度补偿），观察松手后的残余速度；再解释为什么"过补"与"欠补"的松手行为完全不同。★★
    提示
    过补后残余力与速度同向，系统自走（类似第 028 章 feel_check 的 err=−1 情形）；欠补只是更费力、松手更快停。
  5. 设计题：为"零力模式 + 示教记录"写一份验收表：至少 4 项指标、每项的测法与合格线，并说明测法为什么要在"换工具后"复测。★★★
    提示
    推动阈值（在各方向用测力计推）、松手停止时间（秒表/日志）、静置漂移（60 s 位移）、自激测试；工具改变质量与质心，重力/摩擦参数全部偏移。

小结

  • 零力控制 = 把重力、摩擦、模型偏差抵消到"人只感觉阻尼"；量化的零力条件就是残余模型偏差 Δτ 足够小，它并不追求把外力变成零。
  • 广义动量观测器用动量积分绕开 q̈，不需要加速度计或力传感器即可估计外部力矩；Ko = 20–60、配 15 Hz 低通。
  • 三条纪律：结构化摩擦补偿、静置自标定、补偿量与学习速率权限限制；无差别扰动补偿会把手力与阻尼一起抵消并自激。
  • 摩擦用 tanh 平滑、速度滤波、权限限幅，是"手感最后一厘米"的工程细节。
