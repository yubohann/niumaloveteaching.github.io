第 028 章：基于阻抗控制的拖动示教

让人手"顺重力"地领着机器人走一遍任务并记录、回放。本章讲清力矩级拖动示教的动力学条件：重力补偿让轴"失重"、虚拟阻尼让它"稳而顺"、零虚拟弹簧让它"不回弹"。

  • 主题：拖动示教 / 关节力矩级阻抗
  • 关键公式：τcmd = ĝ(q) + τ̂fric(q̇) − Bvq̇，M(q)q̈ + Bvq̇ = τhuman
  • 预计学时：50 分钟
  • 前置章节：第 011 章、第 012 章

学习目标

  • 理解拖动示教（kinesthetic teaching）的物理目标：让人只感觉到"轻阻尼"，感觉不到重力、摩擦和弹簧回拉力。
  • 会写出力矩级拖动示教的动力学条件 τcmd = ĝ(q) + τ̂fric − Bvq̇，并解释为什么"重力补偿 + 虚拟阻尼 + 无虚拟弹簧"三件套缺一不可。
  • 会实现带 Sigmoid 平滑的库仑摩擦补偿，解释它为什么能消除零速附近的"顿挫"。
  • 会设计轨迹记录器：带时间戳采样、按位移/时间双重判据抽稀、回放插值与速度缩放。
  • 知道拖动示教的安全清单：速度限幅、关节限位、使能开关、松手检测与记录数据的回放验证。

背景与动机

产线换活的时间常常比干活还贵：一件新品要示教几十个点位、几段轨迹。传统示教器按键编程慢、抽象；如果能直接攥着机器人末端"拖"着走一遍，轨迹自然、上手极快，这就是拖动示教。它要求机器人变成一台"透明"的机器：你推它，它跟着走；你松手，它停在原地；你不碰它，它不会因为自重滑下来，也不会像弹簧一样弹回原位。

实现这件事有两条路线：力矩级（阻抗式）与位置级（导纳式）。本章讲前者，直接在每个关节注入补偿力矩，是"根目录"级的实现，也是"顺重力拖"最自然的形态：重力被模型精确抵消后，大臂、重工具都轻若无物，人手只需克服虚拟阻尼与残余摩擦；即使拖得慢、停得久，也绝不会有积分漂移。第 029 章再讲导纳式（零力引导）的差别。

核心原理

1. 让人"只感到阻尼"：从机器人动力学反推控制力矩

n 轴机械臂的刚体动力学（忽略挠性与未建模高频）：

M(q)q̈ + C(q,q̇)q̇ + g(q) + τfric(q̇) = τcmd + τhuman M(q)：惯量矩阵（kg·m²）；C：科氏/离心项；g(q)：重力矩（N·m）；τ 各项均 N·m

现在设计命令力矩为"模型补偿 + 虚拟阻尼"：

τcmd = ĝ(q) + τ̂fric(q̇) − Bvq̇（符号：Bvq̇ 产生阻尼力，正方向与运动相反时可写成 −Bvq̇） Bv：关节虚拟阻尼矩阵，典型 0.5–2 N·m·s/rad（对角正定）

代回动力学，若模型补偿准确（ĝ≈g、τ̂fric≈τfric），得到"理想拖动方程"：

M(q)q̈ + Bvq̇ ≈ τhuman 人手力矩驱动，机器人只呈现"固有惯性 + 你设的阻尼"，这就是"顺"的来源

逐项解释三件套的分工：重力补偿 ĝ 让每根轴"失重"，松开手也不会因为自重下滑（"顺重力"：你想让它慢速下落时，只需要很小的反向力就能控制下降速度，无需托着它的全部重量）；虚拟阻尼 Bvq̇ 提供运动阻力，防止轻推就飞、松手后晃；没有虚拟弹簧（Kv = 0，也不做"回到某位置"），拖到哪里就是哪里，绝不回弹，这是示教场景与一般阻抗任务最重要的差别。如果你错误地保留一个"期望位置 xd"和弹簧项，机器人会立即弹回 xd，人根本拖不动。

剩余不理想项是真实惯量 M(q)：它在不同姿态下各轴不同（手臂伸开时惯量大），人手会感到"有时轻有时沉"。工程上可以加"惯量整形"项 M̂(q)q̈d 抵消一部分，但需要估计加速度、对噪声敏感；示教场景先用"只补偿重力+摩擦+阻尼"的轻量方案，接受惯量差异。

2. 为什么摩擦补偿决定"手感"，以及为什么必须平滑

关节里真正的阻力大头常常是摩擦：谐波减速器的库仑摩擦能到 5–15 N·m，比人手想施加的力矩还大。不补偿摩擦，人拖起来会"一格一格"的：黏滞（stiction）让轴不动，积累到足够力后猛地滑动，循环往复，这就是 stick-slip（粘滑）颤抖。摩擦模型用库仑项 + 黏滞项：

τ̂fric = τc·tanh(q̇/q̇s) + b·q̇ τc：库仑摩擦幅值；q̇s：平滑速度尺度（0.02–0.1 rad/s）；b：黏滞系数

核心在 tanh：sign(q̇) 在零速附近来回跳变，补偿力矩跟着跳，制造高频抖动；tanh 让补偿在零速附近平滑过零，轴"跨过零点"时力矩连续。q̇s 的选择是取舍：太小（如 0.001）仍会抖，太大（如 0.5）会让低速段欠补偿、手感发涩。经验值 0.02–0.1 rad/s，配合速度估计的滤波带宽（第 047 章）。

3. 记录什么、怎么回想：轨迹数据的三层结构

拖动过程中的状态是连续流，回放时只需要"路径 + 时间法"。记录三层信息：

  1. 采样层：200 Hz 记录 (t, q, q̇)，原始不抽稀；
  2. 抽稀层：按"角度变化 > 0.001 rad 或时间间隔 > 50 ms"保留关键点（直线段省数据、拐角保细节）；
  3. 回放层：对保留点做时间轴插值（三次样条或带速度限制的线性插值），支持 0.5×–2× 速度缩放。

回放验证有两个必查项：误差（回放实际 q 与记录 q 的偏差 < 1°）与限位穿越（插值曲线不得越过关节限位）。速度缩放到 2× 时，加速度×4，注意复核力矩与速度约束。

实现思路与设计

  1. 前置能力：关节力矩接口（电流环/力矩模式）+ 关节位置；有连杆参数与质量属性（gravity 模型）。没有力矩接口的机器人请走第 029 章导纳路线。
  2. 重力补偿校验：上电后先只给 ĝ(q)，把手臂摆到几个典型姿态，观察 2 s 内漂移；漂移明显说明模型参数（质量/质心）误差大，先标定再继续（第 092 章）。
  3. 虚拟阻尼初值：Bv = 1.0 N·m·s/rad 起步（大臂可 2.0、小臂 0.5）；判据：10 N 手力在大臂上应能推动（10 N × 0.5 m / Bv ≈ 5 rad/s 上限）但要"有阻力感"；太滑（Bv < 0.3）松手后余摆明显。
  4. 摩擦补偿参数：τc 用低速恒速试验估（在不同速度下测所需力矩，反推）；q̇s = 0.05 rad/s 起步；b 取 0.2–0.5。
  5. 安全：拖动模式速度上限 0.5 rad/s（关节）+ 任务空间 0.3 m/s；使能按钮（松手即退出拖动）；关节限位前 5° 预留缓冲并加"软墙"，限位邻域把 Bv 增大 3 倍。
  6. 记录与回放：记录通道与拖动模式解耦（模式退出后数据仍可回放）；回放走正常位置控制 + 速度前馈，不依赖拖动控制器。
设计决策：为什么拖动时不加位置回中，回放时才用位置控制？

拖动是"人在写轨迹"，控制器必须完全服从人；回放是"机器执行轨迹"，需要位置精度和重复性。两者目标正交，混在一起就两头不讨好，这也是本章与导纳式（第 029 章）共有的结构原则：示教模式 = 透传人的意图；回放模式 = 高刚度重放。

关键代码与解读

片段 1：浮动模式力矩命令（重力 + 摩擦 + 阻尼）

import numpy as np

def gravity_torque_2r(q, m1, m2, lc1, lc2, l1, g=9.81):
    """平面两杆臂重力矩解析式（真机上换成通用刚体模型调用）。"""
    q1, q2 = q
    g1 = (m1*lc1 + m2*l1)*g*np.cos(q1) + m2*lc2*g*np.cos(q1+q2)
    g2 = m2*lc2*g*np.cos(q1+q2)
    return np.array([g1, g2])

def float_torque(q, qd, params, b_v=1.0):
    """拖动示教的命令力矩：补偿重力与摩擦，只留下虚拟阻尼。"""
    tau_g = gravity_torque_2r(q, params['m1'], params['m2'],
                              params['lc1'], params['lc2'], params['l1'])
    # 摩擦补偿：tanh 平滑库仑项 + 黏滞项，避免零速附近 sign 抖动
    tau_c, qd_s, b = params['tau_c'], 0.05, 0.3
    tau_f = tau_c*np.tanh(np.asarray(qd)/qd_s) + b*np.asarray(qd)
    # 无虚拟弹簧（K_v=0）：拖到哪停到哪，绝不回弹
    tau_v = -b_v*np.asarray(qd)
    return tau_g + tau_f + tau_v

解读：float_torque 就是拖动模式的全部"控制律"，三个补偿项相加，没有任何位置反馈。注意 qd 必须来自滤波后的关节速度估计（如 20 Hz 低通），否则 tanh(qd/qd_s) 在噪声驱动下来回翻转，人手感到"电机在打哆嗦"。tau_v = -b_v*qd 的阻尼是唯一让人"感到机器人存在"的项，调它就是在调手感。np.asarray 只是防御 qd 是列表的情况；真机实现里还要在每个关节输出前做力矩限幅与变化率限制（第 024 章的理念同样适用）。

片段 2：轨迹记录器，采样、抽稀与统计

class TeachRecorder:
    """拖动示教记录：200 Hz 原始采样 + 位移/时间双判据抽稀。"""
    def __init__(self, dq_keep=1e-3, dt_keep=0.05):
        self.dq_keep, self.dt_keep = dq_keep, dt_keep
        self.t0, self.raw = None, []           # 原始采样
        self.pts = []                          # 抽稀后的关键点 (t, q)
        self.q_last = None
    def push(self, t, q):
        if self.t0 is None:
            self.t0 = t
        self.raw.append((t - self.t0, q.copy()))
        keep = False
        if not self.pts:
            keep = True                        # 首个点必留
        elif (t - self.pts[-1][0]) >= self.dt_keep:
            keep = True                        # 时间间隔超限必留（慢速段）
        elif self.q_last is not None and \
             float(np.linalg.norm(q - self.q_last)) >= self.dq_keep:
            keep = True                        # 位移超限必留（快速段）
        if keep:
            self.pts.append((t - self.t0, q.copy()))
            self.q_last = q.copy()
    def summary(self):
        n_raw, n_keep = len(self.raw), len(self.pts)
        dur = self.raw[-1][0] if self.raw else 0.0
        print(f"记录 {dur:.1f} s: 原始 {n_raw} 帧 -> 关键点 {n_keep} 个"
              f" (压缩比 {n_raw/max(n_keep,1):.1f})")
        return np.array([p[1] for p in self.pts]), \
               np.array([p[0] for p in self.pts])

解读：抽稀判据用"或"关系，快速拖动段靠位移判据保形状，慢速拖动段靠时间判据保停留（示教里"停下看看再继续"的动作必须保留）。q_last 只在保留点处更新，这样判据衡量的是"与上一个关键点"的距离，不会因连续小步移动而"漏掉"整个行程。压缩比会在报告中显示：典型操作压缩 10–50 倍，回放时按时间戳插值即可。真机上 push 写在控制循环里但只做浅拷贝，别做重运算；统计与落盘放到模式退出后。

片段 3：手感自检，阻尼、漂移与"顺重力"验证

def feel_check(b_v=1.0, tau_c_err=0.0, dt=1e-3):
    """一维手感检查：前 1.5 s 施加 4 N·m 手力矩，后 1 s 松手。
    tau_c_err：摩擦补偿偏差，正=欠补偿，负=过补偿。"""
    tau_c, tau_c_hat = 5.0, 5.0 - tau_c_err
    m, b = 0.8, 0.5                            # 真实转动惯量与黏滞
    qd, log = 0.0, []
    for i in range(2500):                      # 2.5 s
        tau_in = 4.0 if i*dt < 1.5 else 0.0    # 手力矩：1.5 s 后"松手"
        tau_cmd = tau_c_hat*np.tanh(qd/0.05) + 0.2*qd - b_v*qd
        qd += dt*(tau_in + tau_cmd
                  - tau_c*np.tanh(qd/0.05) - b*qd) / m
        log.append(qd)
    print(f"补偿偏差 {tau_c_err:+.1f} N·m: 拖动稳态 {log[int(1.5/dt)-1]:.2f} rad/s,"
          f"  松手 1 s 后 {log[-1]:.3f} rad/s")

for err in (0.0, 1.0, -1.0):
    feel_check(tau_c_err=err)

解读：这个自检把"手感"翻译成两个数字：拖动稳态速度与松手后的残余速度。补偿偏差为 0 时拖速约 2.8 rad/s，松手后只靠阻尼衰减、1 s 内已降到 0.55 并继续趋零；欠补偿 1 N·m 时拖速掉到 2.1、"更费力"，但松手会被残余摩擦迅速刹停；过补偿 −1 N·m 最危险，拖动更快（3.5 rad/s），松手后补偿力矩超过真实摩擦，轴以约 1.3 rad/s"自己走"。现场症状就是"放开后机器缓缓滑走"，只能靠速度限幅与使能按钮兜底。真机调试把这段判断搬去现场：先摩擦辨识拿 τc，再用"拖-松-停"三步检查残余速度方向。拖动示教的质量 = 补偿精度 × 阻尼整定，两者都能用数字衡量，不必诉诸"手感玄学"。

常见坑

  • 重力模型不标定直接上：工具没算进去、质心参数抄手册，结果某些姿态"自己往上爬"或"往下坠"。症状：松手后 2 s 漂移 > 0.5°。修复：先做重力辨识与工具负载标定（第 092 章）。
  • 摩擦补偿用 sign(q̇)：零速附近抖动、拖起来"咔咔"响。修复：tanh 平滑（本章公式），且速度估计先滤波。
  • 虚拟阻尼取太小：松手后手臂余摆、撞限位更狠。修复：Bv 从 1.0 起调，宁可"稳"一点；大惯量轴单独加大。
  • 记录无时间戳（只存点序列）：回放时不知道每点该停多久，速度被"平均掉"，快慢变化丢失。修复：时间轴必须记录，回放按时间插值。
  • 回放不做验证直接上生产：插值曲线可能穿过关节限位或与夹具干涉。修复：回放前做离线限位/自碰撞检查，低速空跑一遍再提速。

练习与思考

  1. 写出 2R 臂的两条重力矩公式并解释每项来源（提示：把第二杆的重力分解到两关节）。若把末端负载 2 kg 加到 l₂ 末端，公式怎么改？★
    提示
    g₁ 的 m₂ 项用 (l₁, lc₂) 计；末端负载等效为增大 lc₂ 质量项或直接加 mLl₂g cos(q₁+q₂) 到 g₁、mLl₂g cos(q₁+q₂) 到 g₂ 的力矩。
  2. 推导：若误留虚拟弹簧项 Kv(q−qd)，拖动方程变成什么？用 M q̈ + Bvq̇ + Kv(q−qd) = τh 说明"回弹"与"拖不动"两种症状出现的条件。★★
    提示
    稳态时 Kv(q−qd) = τh，人必须一直"顶着"才能停在偏离处；松手弹回 xd，示教场景必须 Kv=0。
  3. 实验：把片段 3 的 bv 取 0.3、1、3，记录稳态拖速与松手后 0.5 s 的速度，画出"阻尼-手感"曲线，并给出你为演示场景选的阻尼与理由。★★
    提示
    稳态速度 ≈ (手力−摩擦残差)/(bv+b)；阻尼越大越稳但越"黏"，示范操作通常选 0.8–1.5。
  4. 把片段 2 的两个判据分开测试：只用位移判据（慢速拖动 3 s 不动）与只用时间判据（快速划弧 1 s），观察关键点数量与形状丢失情况，解释双判据的必要性。★★
    提示
    单一位移判据会丢掉"停留"信息；单一时间判据在快速段点数过多、还漏形状特征。二者取"或"才兼顾。
  5. 设计题：写出"拖动-记录-回放"的完整状态机（含使能开关、超速退出、记录完成、回放前验证、回放中偏差过大急停），并说明每个转移的判据为什么放在控制器里、不放在上位机。★★★
    提示
    安全转移（超速、偏差、限位）必须在实时控制器内以 1 kHz 处理；上位机只做记录管理与离线验证。

小结

  • 力矩级拖动示教的控制律 = 重力补偿 + 摩擦补偿 + 虚拟阻尼，没有虚拟弹簧；补偿准、无弹簧，才有"拖到哪停到哪"的手感。
  • 摩擦补偿用 tanh 平滑库仑项可消除 stick-slip 抖动；速度估计滤波是手感稳定的前提。
  • 记录 = 200 Hz 原始流 + "位移或时间"双判据抽稀 + 时间戳插值回放；回放模式与示教模式相互独立。
  • 安全 = 使能开关 + 关节/速度限位 + 限位软墙 + 回放前验证；示教本质是"人写机器读"，两个阶段职责分离。
  • 下一章是它的"位置级"镜像：基于导纳控制的拖动示教，同样的拖动体验，控制量却变成了位置命令，比较两者在结构、手感与精度上的差别。
