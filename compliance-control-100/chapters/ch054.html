第三篇 · 感知、辨识与智能调参

第 054 章：导纳控制中的时变阻尼

上一章说"刚度会储能，切换要小心"；阻尼不一样，它只耗散、不储能，切换在能量上天然安全。本章讲清这个不对称性，给出接触增强、速度相关、力变化率三套阻尼调度，并解决它真正的问题：切换瞬间手感和力的"台阶"。

  • 主题：变阻尼 / 无源性优势与手感调度
  • 关键公式：E = ½Mdv²，Ė = v·F − D(t)·v²（Ḋ 不出现）
  • 预计学时：50 分钟
  • 前置章节：第 053 章（阻抗控制中的时变刚度）

学习目标

  • 理解时变阻尼与刚度在无源性上的本质差异：为什么 D(t) 在正数之间任意切换都不注入能量。
  • 定量分析阻尼切换的真实代价：速度连续但加速度跳变，耦合端瞬时阻力 ΔD·v 的台阶有多大。
  • 掌握三类实用调度：接触增强（0.2–0.3 s 冲击吸收）、速度相关（高速更黏）、力变化率触发（撞击前预加阻尼）。
  • 会用速率限制与滞回让阻尼切换"无感"，并把噪声抑制收益 σv = σF/D 纳入设计。
  • 能写出带调度的导纳积分代码，并用能量账本验证其无源性。

背景与动机

导纳控制里，阻尼 Dd 是比质量 Md 更常用的"手感与安全旋钮"：它直接决定稳态漂移速度（vss = F/D）、决定噪声敏感度（σv = σF/D）、决定耦合回路的耗散度。真实任务里对它的需求是分时段的：自由接近时希望"轻快"（D 小）；接触瞬间希望"稳"（D 大）；高速拖动时希望"不甩"（D 大）；精细对位时又希望"跟手"（D 小）。

与刚度调度相比，阻尼调度有一个巨大的理论优势：阻尼是纯耗散元件，"调大调小"不会改变系统任何一处储存的能量，它没有对应 ½Ke² 那样的能量库。这让设计者可以把精力从"防注入"转向另一个更实际的问题：切换瞬间的"抗阻台阶"。人的手对力的突变极为敏感，ΔD·v 达到几牛就足以被感知为"咯噔"。本章给出一个"能量安全、手感平滑、噪声可控"的阻尼调度方案。

核心原理

1. 为什么时变阻尼不注入能量

取一维导纳模型 Mdv̇ = F − D(t)·v，动能作为存储函数：

E(t) = ½Mdv²， Ė = Mdv·v̇ = v·F − D(t)·v² 对比第 053 章的 V̇ = −Dv² + ½K̇e² + vFext：那里多出的 ½K̇e² 项在这里完全没有，D 不出现在任何储能项里

这就是那个关键的不对称性：K 出现在储能项 ½Ke² 里，所以 ḱ 会直接改变储能；D 只以 D·v² 的耗散形式出现，D(t) 只要始终为正，耗散率就始终为正。因此，无论 D(t) 怎么在 [Dmin, Dmax] 之间跳变，系统对任何被动外力都保持无源，这是阻尼调度的"理论通行证"。它立刻给出两条设计约束：（1）任何调度都必须保证 D(t) > 0（绝不能出现"负阻尼增强响应"的写法）；（2）离散实现的截断误差仍可能引入微小负耗散，主要影响在极小 D 附近，所以 Dmin 不要压到接近零。

2. 切换的真实代价：不是能量，是"台阶"

能量安全不等于手感安全。考察 D 从 D1 跳到 D2 的瞬间：速度 v 是状态量、连续；加速度 a = (F − D·v)/Md 发生跳变。对交互端而言，阻尼器反作用在手上的力是 FD = D·v，它同样发生跳变：

ΔF手 = |D2 − D1| · |v| 例：D 从 200 跳到 500 N·s/m，v = 0.1 m/s 时手上出现 30 N 的阻力台阶，这是"咯噔"的来源

结论：阻尼切换的能量账本永远平衡，但力的账本会在瞬间结算。工程约束因此变成"手感预算"：单次切换的 ΔD·v典型 不超过几牛。两个手段：分散（把切换摊到 0.1–0.3 s，力台阶变缓坡）与择时（在速度小的时刻切换，v → 0 时台阶自动消失）。

3. 三套常用调度

  • 接触增强：检测到接触（力越过阈值或力变化率超限）后，把 D 提升至 1.5–2 倍，维持 0.2–0.3 s 再回落。它用一段额外的黏性吸收接触冲击能量；注意回落要慢（时间常数 0.3–0.5 s），因为"突然变轻"比"变重"更容易让操作者失手。
  • 速度相关：Dd(v) = D0·(1 + α|v|/vref)，典型 α = 0.5–1、vref = 0.2 m/s。高速时更黏，直观解释：速度大时同样的 ΔD·v 台阶更大，反过来说,这正是快速运动最需要稳定的区间；固定比例的增强还有一个好处：它不改变低速手感。
  • 力变化率触发（预阻尼）：|Ḟ| 超过阈值（比如 50 N/s）时立即把 D 抬到上限并保持 0.1 s。这是"撞击预判"：等到力已经很大再增强就晚了，变化率是更早的信号。预阻尼的理想收益是把接触冲击的峰值削减 20–40%。

三个调度可以叠加（取最大值或加权），但每一路都要配滞回与速率限制，否则会在阈值附近高频切换，变成"抖动发生器"。速率限制建议：ΔD/Δt ≤ 1500 N·s/(m·s)（即 300 的跨度至少 0.2 s 走完），这样在 v = 0.15 m/s 时的力台阶速率只有约 225 N/s，人的感知接近"渐强"，不会形成"撞击"感。

4. 顺带的收益：噪声模式

把 D 调大还有一个与手感无关、与信号质量有关的收益：力噪声引起的速度噪声是 σv = σF/D。接触段把 D 从 300 提到 600，速度抖动直接减半，对导纳控制来说，接触段恰恰是最怕微抖的时段（微抖会在接触面上激发力振荡）。所以"接触增强"是双赢设计：既有冲击吸收，又有噪声压制。代价是巡航速度变小、到位用时变长（时间常数 τ = Md/Dd 同时变小，起步反而更快），必须在任务允许的"跟手性"预算之内。

实现思路与设计

一个完整的阻尼调度器包含四件事：状态判定 → 目标值合成 → 平滑过渡 → 输出限幅。参数起步：

  1. 基础档：自由段 D0 = 250 N·s/m；任务段 D1 = 400；Md 固定 8 kg（变化交给 D，保持"惯性感"一致）。
  2. 接触增强：接触门（|F| > 2 N 或 |Ḟ| > 30 N/s）触发，D 目标 ×1.5，保持 0.25 s 后按 0.4 s 时间常数回落。
  3. 速度相关：D 加成 +40%·clip(|v̂|/0.2, 0, 1)；v̂ 用第 048 章的 α-β 观测器，不用裸差分。
  4. 合成：Dtarget = Dbase·max(增强倍率, 1 + 速度加成)；再经速率限制（1500 N·s/(m·s)）得到本周期 Dd。
  5. 安全：Dd ∈ [150, 800] N·s/m；低于 150 时噪声与低阻尼振荡风险都上升；高于 800 手感"像搅水泥"，也无必要。

验收用两个指标：（1）切换时耦合端力台阶的时间导数（应小于 300 N/s 量级，可接受为"渐进"）；（2）接触段速度噪声 RMS（应比自由段不升反降）。

关键代码与解读

片段 1：阻尼调度器（接触增强 + 速度相关 + 速率限制）

import numpy as np

class DampingScheduler:
    """三合一阻尼调度：接触增强 / 速度相关 / 速率限制。
    理论依据：D(t)>0 恒耗散，切换不注入能量；要防的只是力台阶。"""
    def __init__(self, d_base=250.0, d_lo=150.0, d_hi=800.0, rate=1500.0, dt=1e-3):
        self.d_base, self.d_lo, self.d_hi = d_base, d_lo, d_hi
        self.rate, self.dt = rate, dt
        self.d = d_base
        self.contact_hold = 0.0        # 接触增强保持计时
        self.boost = 1.0               # 当前增强倍率(带缓释)

    def step(self, f, df_rate, v_hat):
        # ① 接触门：力超 2 N 或力变化率超 30 N/s → 触发 0.25 s 增强
        # 用“或”不用“与”：撞击的第一证据是变化率，不能等力足够大
        if abs(f) > 2.0 or abs(df_rate) > 30.0:
            self.contact_hold = 0.25
        self.contact_hold = max(0.0, self.contact_hold - self.dt)
        # ② 增强缓释：抬得快(时间常数 0.05 s)、落得慢(0.4 s)，防“突然变轻”
        boost_target = 1.5 if self.contact_hold > 0 else 1.0
        tau = 0.05 if boost_target > self.boost else 0.4
        self.boost += (boost_target - self.boost) * self.dt / tau
        # ③ 速度相关：高速更黏(噪声与冲击都随速度变大)
        v_add = 1.0 + 0.4 * float(np.clip(abs(v_hat) / 0.2, 0.0, 1.0))
        d_target = self.d_base * max(self.boost, v_add)
        # ④ 速率限制：让 ΔD·v 的力台阶变成“渐强”，不形成撞击
        d_target = float(np.clip(d_target, self.d_lo, self.d_hi))
        d_new = self.d + float(np.clip(d_target - self.d,
                                       -self.rate*self.dt, self.rate*self.dt))
        self.d = d_new
        return self.d

解读：（1）接触门用"力大 或 变化率大"，不用"与"：撞击的第一证据是变化率（力还没大起来之前 Ḟ 已经超限），等力足够大再增强就晚了一个控制周期量级。（2）"抬得快、落得慢"的不对称时间常数（0.05 s / 0.4 s）是手感设计的核心：接触瞬间要马上"接住"，恢复轻快则要让人有准备。（3）速度相关项用 clip 把加成限制在 1.4 倍以内，避免高速时 D 冲进 800+ 让操作者"推不动"。（4）速率限制作用在最终值上，保证不管是哪个分支触发，输出的时间导数都有界，这条对"叠加多个调度源"尤为重要：没有它，两个分支同时切换会让 D 一步跳完。

片段 2：导纳积分 + 能量账本（验证 D(t) 的无源性）

class AdmittanceWithD:
    """带时变阻尼的导纳积分：M dv = (F - D(t) v) dt，附能量审计。"""
    def __init__(self, m_d=8.0, dt=1e-3):
        self.m_d, self.dt = m_d, dt
        self.v = 0.0
        self.e_diss = 0.0          # 累计耗散∫D v^2 dt（应单调不减）
        self.e_in = 0.0            # 外力累计做功∫F v dt

    def step(self, f, d_now):
        a = (f - d_now * self.v) / self.m_d
        v_new = self.v + a * self.dt
        # 记账恒等式：ΔE = ΔW_in - ΔW_diss（离散用梯形平均速度，误差更小）
        v_mid = 0.5 * (self.v + v_new)
        self.e_in += f * v_mid * self.dt
        self.e_diss += d_now * v_mid * v_mid * self.dt
        e_kin = 0.5 * self.m_d * v_new * v_new
        # 断言式自检：动能不能超过“外部投入-已耗散”（留 1 mJ 离散容差）
        assert e_kin <= self.e_in - self.e_diss + 1e-3, "能量账本被破坏"
        self.v = v_new
        return self.v

解读：（1）这个类的用途是把无源性证明"翻译成可运行的自检"，并不执行控制任务：每拍断言动能不超过"外部投入 − 已耗散"。只要 D(t) > 0，任何调度序列都不会触发断言，这正是本章理论的实验版。（2）把 assert 保留在调试版本里，上生产线换成计数器 + 日志（断言失败会停机，量产代码里通常不允许直接断死）。（3）如果你想亲手制造一次"能量破坏"，把某一步的 d_now 临时传成负值，断言会立刻在 1–2 ms 内触发，用它来向同事演示"负阻尼不是鲁棒性工具"很有说服力。

片段 3：切换台阶 vs 噪声抑制的定量对照

def d_switch_metrics(d1, d2, v, dt_switch):
    """阻尼切换的两个指标：力台阶 ΔD*v 与台阶斜率 ΔD*v/dt_switch。"""
    force_step = abs(d2 - d1) * abs(v)
    slope = force_step / max(dt_switch, 1e-6)
    print(f"D {d1:4.0f}->{d2:4.0f} Ns/m  @v={v*1000:5.1f} mm/s: "
          f"力台阶={force_step:5.2f} N  斜率={slope:7.1f} N/s")

# 三组对照：同一 ΔD，不同速度与过渡时长
d_switch_metrics(250.0, 500.0, 0.15, 1e-3)   # 冷切换：一步到位 → 37.5 N 台阶!
d_switch_metrics(250.0, 500.0, 0.15, 0.2)    # 速率限制 0.2 s → 187 N/s 渐强
d_switch_metrics(250.0, 500.0, 0.02, 1e-3)   # 低速时刻切换 → 台阶仅 5 N
print("噪声抑制: sigma_v = sigma_F / D, D 翻倍 → 速度噪声减半")

解读：三行输出的对比是本章最实用的设计口诀：同一个 ΔD = 250 N·s/m，"冷切换"（一拍跳完）在手速 150 mm/s 时是 37.5 N 的力冲击；摊到 0.2 s 变成 187 N/s 的渐变；而如果等速度降到 20 mm/s 再切，台阶只有 5 N。所以调度器的"择时"（在速度过零点附近做主要切换）与"分散"（速率限制）是两个互补手段：前者治标又治本，后者兜底。最后一行把噪声收益写出来：D 从 250 到 500，速度噪声从 σF/250 变成 σF/500，接触段的微抖直接减半，与"接触增强"的目标完全兼容。

常见坑

  • 误以为"阻尼随便调"：能量上确实安全，但手感上不是，能量账本没记的力台阶会让人投诉"机器人突然变重"。修复：速率限制 + 择时（低速切换）。
  • 负阻尼思维：为了"更跟手"把 D 暂时调成负数来抵消摩擦，这是把无源性保证当儿戏，会直接振荡。修复：要补偿摩擦用摩擦前馈（第 012 章），不要动 D 的符号。
  • D 上限设太小：Dhi = 300 时高速拖动的晃动压不住（σv 大），接触冲击也吸不掉。修复：按"接触段速度噪声目标 ≤ 0.5 mm/s、冲击吸收需求"反推 Dhi，通常 500–800。
  • D 下限设太小：Dlo = 30 时离散误差与延迟会放大成低阻尼振荡；且 σv = σF/30 ≈ 7 mm/s，抖动肉眼可见。修复：Dlo ≥ 150。
  • 切换阈值附近来回跳：没有滞回的多路调度在阈值附近每几拍切换一次，产生"吱吱"的手感。修复：每路调度独立滞回（比值 2:1）+ 保持时间（0.1–0.3 s）。

练习与思考

  1. 推导 Ė = vF − D(t)v²：取 E = ½Mdv²，代入导纳方程，说明为什么 Ḋ 不出现，并解释"D(t) 为正即可保证任意切换无源"。★
    提示
    E 里没有 D，全式只剩 D·v² 的耗散结构；被动外力（v·F 长期平均非正）无法让 E 无限增长。
  2. 对比第 053 章：把 ½K̇e² 类比成"水泵"、把 D v² 类比成"水轮机"。用一个句子说清两章的差异，并举一个任务场景说明为什么两个旋钮要分工使用。★★
    提示
    K 切换挑剔（要记账、限速、择时），D 切换省心（正数即可），所以"需要快速改变手感"的场合优先动 D，"需要改变稳态力-位移关系"才动 K (装配插孔 vs 手引导)。
  3. 用片段 3 的公式设计一个"速度过零切换"策略：规定槽口 |v̂| < 10 mm/s 且持续 50 ms 才执行 D 档位变更，否则推迟。分析在连续移动的任务里该策略的最坏推迟时间，并给出兜底规则（推迟超过 2 s 时如何处理）。★★
    提示
    最坏推迟可能无限；兜底是"超时后以最大允许速率沿途切换"，把不可控的推迟换成可控的斜坡。这也是实际工程的常规写法。
  4. 设计一个"手感标定"小实验：让 3 名同事在 D = 200/400/800 N·s/m 下推动机器人并给"轻/重"打分，然后画出 D-评分曲线，选出让任务段"不拖、不甩"的 D 区间。说明为什么主观评分也要写进工程验收。★★★
    提示
    手感存在个体差异，评分分布的中位数与标准差决定了可用区间；把人机交互的主观量纳入验收是协作机器人开发的常规做法（这也是"工程直觉"的一类量化）。

小结

  • 时变阻尼在无源性上天然安全：D 只以耗散项 D(t)v² 出现，Ḋ 不出现在能量方程里，只要 D(t) > 0。
  • 切换的真实代价是力台阶 ΔD·|v| 与由此产生的"咯噔"感，需要速率限制（分散）与择时（低速切换）。
  • 三套调度：接触增强（冲击吸收+噪声抑制）、速度相关（高速更黏）、力变化率预阻尼（提前接住）；全部配滞回与保持时间。
  • D 的上下界（150–800 N·s/m）同时覆盖稳定性、噪声与手感三个约束。
  • 噪声收益 σv = σF/D 与冲击吸收收益方向一致，接触段"变黏"几乎总是双赢。
