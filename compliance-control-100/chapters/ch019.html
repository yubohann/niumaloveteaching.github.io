第一篇 · 基础、建模与稳定性

第 019 章：未知环境刚度下的自适应阻抗控制

不知道对面有多硬、表面在哪，却要把力稳稳压在目标值上：要么让参考点"自己找"，要么先学会环境再瞄准。本章给积分自适应与在线辨识两条路线，并合成为完整方案。

  • 主题：阻抗控制 / 力跟踪自适应
  • 关键公式：ẋr = γ(Fd−F)；F = Kenv(x−xe) 的递推最小二乘
  • 预计学时：60 分钟
  • 前置章节：第 018 章

学习目标

  • 理解"未知环境"给力跟踪带来的两个缺口：环境刚度 Kenv 与表面位置 xe 同时未知时，开环偏置无法精确控制力。
  • 会推导积分型参考自适应 ẋr=γ(Fd−F)，写出力误差的指数收敛律与收敛速率 γKeq。
  • 掌握自适应回路与阻抗回路的"时间尺度分离"原则及其延迟稳定条件 γKeqTa ≤ 1。
  • 会写出 F = Kenv(x−xe) 的线性回归形式，用递推最小二乘在线辨识 Kenv 与 xe，并说明"激励不足则不可辨识"。
  • 能装配完整方案：估计驱动的参考瞄准 + 小积分微调 + 限幅/暂停等安全护栏。

背景与动机

前两章把环境的两种极端都算过账：刚性环境里"偏置造力"对 xe 不敏感（第 017 章），柔性环境里力精度依赖你对 Kenv 和 xe 的了解（第 018 章）。现实任务恰好落在最难的组合上：环境刚度未知且会变（不同批次的弹性件、不同部位的软组织）、表面位置也未知（零件摆放、人体姿态）。此时一个固定偏置只能"压个大概"，误差 20%–50% 是常态。

自适应阻抗控制处理这类问题：允许参考点 xr 在运行中缓慢调整，直到实测力落到目标值。它有两条实现路径，不进模型的积分自适应（像力环的 I 项，简单皮实）和进模型的在线辨识（先估环境参数，再一步瞄准，收敛更快更精确）。本章把两条都讲完，并回答工程上的关键问题：自适应要多快、会不会和接触回路打架、什么时候必须停下来。

核心原理

1. 问题的结构：两个未知、一个目标

把环境写成 F = Kenv(x − xe)（F 为压入方向的力幅值，x、xe 单位 m），接触回路稳态满足 F = Keq(xr − xe)，其中 xr 是控制器实际使用的参考点、Keq 为串联刚度（第 018 章）。力跟踪任务要求 F → Fd。理想情况下参考点应取

xr* = xe + Fd/Keq 两个未知量的直接组合：xe 决定"从哪开始算"，Keq 决定"每牛要压多深"

注意这里有一个比第 018 章更完整的视角：控制目标是让 xr 到达 xr*，而 xr 是我们唯一的可写旋钮。两条路线的分歧就在"如何找到 xr*"：积分法不问因果，靠力的误差一步步挪；辨识法先解开两个未知数，再算出来。前者不需要激励与模型，后者更快更准但要有"可观测性"，下一节分别展开。

2. 积分自适应：不问因果的"力误差积分"

最朴素的方案：力大了就往后退、力小了就往里压，速率正比于力误差：

ẋr = γ·(Fd − F) γ：自适应增益，单位 m/(N·s)；这就是"参考点上的积分力环"

在没有接触时这个式子会把机器人一直往前推（F=0、误差恒正），所以它必须与接触状态机配合：只在"保持接触"状态启用，脱离接触立即冻结 xr 并交给接近逻辑（第 017 章）。在接触状态下，把 F = Keq(xr−xe) 对时间求导：Ḟ = Keqẋr = γKeq(Fd−F)，于是力误差按指数收敛：

F(t) − Fd = [F(0) − Fd]·e−γKeqt ， 收敛速率 λ = γKeq（1/s） 想 1 s 大致收敛（3 倍时间常数）→ λ≈3 → γ = 3/Keq；Keq≈300 时 γ≈0.01 m/(N·s)

但这是"准静态"推导：它假设接触回路对参考移动的响应永远跟得上。真实回路有延迟 Ta（力滤波、采样、接触动力学），把延迟加进来，特征方程变为 s + γKeqe−sTa = 0，纯延迟一阶回路的临界点是 γKeqTa = π/2。取安全值：

稳定性规则：γ·Keq·Ta ≤ 1 Ta=20 ms 时 γKeq ≤ 50 /s；典型取值 1–5 /s，慢于接触回路一个数量级以上

工程直觉：自适应不是"越快越好"，它和接触回路是两班倒的时间尺度，接触回路在秒级以下的频段里工作，自适应只能在更慢的频段上搬运参考点。把它调快，看起来是"反应灵敏"，实际是给延迟回路喂振荡。τc=1/λ 取 0.3–1 s 是甜区：几分钟的任务里两三次时间常数足够收敛，而手感上用户几乎察觉不到参考点在动。

3. 在线辨识：先学环境，再一步瞄准

积分法的缺点是"试探着挪"，对 Kenv 未知的量级完全不利用。辨识法把环境模型线性化：F = Kenv·x − Kenv·xe，写成回归形式：

F = φTθ ， φ = [x, −1]T， θ = [Kenv, Kenvxe]T 两个参数的线性模型：斜率=环境刚度，截距=Kenvxe；估出 θ 即得 K̂env、x̂e

用递推最小二乘（RLS）在线更新：每拍获得一对 (x, F) 就迭代一次，带遗忘因子 λf∈(0.95, 0.999] 以适应缓慢变化的环境。三条实践要点：（1）激励是辨识的燃料，如果 x 一动不动（完美静压），回归矩阵退化，只有"Kenvxe"这个乘积可辨识；实践中用接触力自身的波动（推压起伏、任务固有的微运动）或注入 0.5–2 Hz、0.5–2 mm 的微型激励。（2）先粗后精，RLS 的初值用物理粗估（K̂env,0=500、x̂e,0=首次接触位置），协方差 P 给足够大让数据说话。（3）把估计当传感器读，别当真相，给 K̂、x̂ 设合理范围（如 50–5000 N/m、±20 cm），超界冻结并报警；估计与真值的偏差最终由积分微调兜底。

有估计之后，参考点的"瞄准式"更新为：

xr ← (1−w)·xr + w·[ x̂e + Fd/K̂eq ]， w 为低通系数（每拍 0.001–0.01） K̂eq 由 K̂env 与控制器刚度算得；低通保证参考点移动慢于接触回路（时间尺度分离）

为什么还要低通？因为 RLS 的估计会有噪声与跳变，直接灌进参考点等于把辨识噪声变成位移抖动；低通把"瞄准"平滑成分钟级的缓慢修正，同时天然满足 γKeqTa≤1 的稳定约束。两条路线合起来的完整方案是：RLS 提供快速近似（第一次接触就能把误差从 30% 收到 5%–10%），低通参考搬运 + 小增益积分微调负责最后的 1–2 N；任何时刻估计异常，积分项独立保证系统仍收敛。

4. 安全护栏：自适应的边界条件

  • 脱离接触冻结：|F| 低于死区（如 0.5 N）表示接触丢失，冻结 xr 与 RLS，回到接近逻辑，否则积分会把参考点推到"穿墙"的方向。
  • 误差门限：|F−Fd| 超过阈值（如 10 N）说明工况异常（工件缺失、卡死），暂停自适应、报警，等人工确认。
  • 目标斜坡：Fd 的变化用 0.5–2 s 的斜坡给入，避免把阶跃强加给慢自适应回路。
  • 参考限幅：xr 限定在工作空间与安全区内，与第 002 章的 δ 限幅同源。
  • 监控：把 xr、K̂env、F 误差记录进日志，它们是最廉价的工艺传感器（工件批次变化会先体现在 K̂env 上）。

实现思路与设计

完整自适应力跟踪的接线顺序（从简单到复杂逐级启用）：

  1. 第 0 级：固定参考 + 稳态校准（试压一次记下 F/K 偏置），能应付环境稳定的小批量；
  2. 第 1 级：加积分自适应 γ=1/(K̂eq·τc)，τc=0.3–1 s，配脱离冻结与误差门限，覆盖大部分未知环境的工程需求；
  3. 第 2 级：加 RLS 辨识（λf=0.99，P0=104I），参考按瞄准式+低通更新；积分保留小增益（τc=2–5 s）做残差兜底；
  4. 第 3 级：把辨识结果前馈给接近策略（用 K̂env 重算接近速度与着陆力）与安全监控（刚度突变触发重标定）。
设计决策：为什么积分兜底不能省？

RLS 的估计精度依赖三件事：模型正确（环境真是线性弹簧）、激励充分（x 有足够波动）、噪声可控。任何一条不满足，K̂env 就会有系统偏差，比如环境带阻尼或摩擦时估计出的"等效刚度"偏高，用 K̂ 计算的偏置会偏小，力永远差一截。小增益积分（λ≈0.2–0.5 /s）独立于这些假设，只利用"力错了就往对的方向挪"这一条事实，是整套自适应最后的正确性保障。代价是慢（几分钟收敛）与抗噪声差，所以它只适合当兜底，主路仍是辨识加瞄准。工程判断：如果任务不允许误差超过 5%，而 RLS 单独做不到 3%，就把积分时间常数缩到 1 s 观察稳定性；两者都做不到，说明该换硬件（测力、视觉标定）；继续调算法的收益已经见底。

关键代码与解读

片段 1：积分自适应，三步收敛到目标力

import numpy as np

def integral_adapt(gamma, k_env=300.0, k_eq_known=None,
                   f_d=10.0, x_e_true=0.05, dt=1e-3, t_end=6.0):
    """未知环境上用积分自适应跟踪 10 N：观察参考点与力的收敛。"""
    # 机器人侧：参考点 x_r 被缓慢搬运；稳态力按 F=K_eq(x_r-x_e) 近似
    k_eq = k_eq_known if k_eq_known is not None else 150.0   # 粗估的串联刚度
    x_r = 0.055                    # 初始参考：比真实表面深 5 mm（力偏大）
    f_log = []
    for i in range(int(t_end/dt)):
        # 接触回路被当作"快到看不见"：准静态关系 + 一阶滞后
        f_target_static = k_env * (x_r - x_e_true)
        # 用一阶滞后模拟接触回路对参考变化的响应（τ=50ms）
        f = f_log[-1] if f_log else f_target_static
        f += (f_target_static - f) * dt / (0.05 + dt)
        # 积分自适应：只在接触保持时启用（|F|>0.5N）
        if abs(f) > 0.5:
            x_r += gamma * (f_d - f) * dt      # 力小则加深，力大则后撤
        f_log.append(f)
    return np.array(f_log)

for tag, g in (("γ=0.01 (τ≈0.7s)", 0.01), ("γ=0.05 (τ≈0.13s)", 0.05),
               ("γ=0.20（过快）", 0.20)):
    f = integral_adapt(g)
    print(f"{tag:>18}: F(0.5s)={f[500]:5.2f}  F(2s)={f[2000]:5.2f}  "
          f"F(6s)={f[-1]:5.2f} N")

解读：预期三行的终值都趋向 10 N（积分律对任意正 γ 都收敛，这是它"皮实"的来源），差别在过程：γ=0.01 的时间常数 τ=1/(γKeq)≈0.67 s，2 s 时已接近目标；γ=0.2 的时间常数只有 33 ms，但它已经和"接触回路 50 ms 的滞后"同量级，仿真里会看到超调与振铃（这就是 γKeqTa 判据的可见化）。代码里两个仿真细节值得学：其一，接触回路用一阶滞后代表（τ=50 ms），这正是 Ta 的物理内容；其二，自适应带接触门限（abs(f) > 0.5），脱离接触就冻结，否则参考点会在自由空间一路狂飙。真机上的门限要用滤波后的力并加一点滞环，避免在"擦边接触"时反复启停。把 Keq 换成你现场的粗估（不必准确，量级对即可），γ 按 1/(K̂eq·τc) 给，τc 取 0.3–1 s，这套代码可以原样上机做第一版验证。

片段 2：RLS 在线辨识，从 (x, F) 数据里解出环境

def rls_identify():
    """仿真：机器人端 0.5 Hz、±2 mm 推压微动提供激励，RLS 辨识 K_env 与 x_e。"""
    rng = np.random.default_rng(11)
    k_true, x_e_mean = 400.0, 0.05          # 真值（控制器不知道）
    theta = np.array([300.0, 300.0*0.048])  # 初值：粗估 K=300、xe≈48mm
    P = 1e4 * np.eye(2)                     # 大初始协方差：先让数据说话
    lam = 0.995                             # 遗忘因子（缓慢时变环境）
    dt = 1e-3
    log = []
    for i in range(6000):                   # 6 秒
        t = i*dt
        # 激励来自机器人：在 8 mm 名义压深上叠加 0.5 Hz、±2 mm 的推压微动
        x = x_e_mean + 0.008 + 0.002*np.sin(2*np.pi*0.5*t)
        f = k_true*(x - x_e_mean) + 0.1*rng.standard_normal()  # 含噪声的力测量
        phi = np.array([x, -1.0])
        # RLS 三步：增益、参数、协方差更新
        K_gain = P @ phi / (lam + phi @ P @ phi)
        theta = theta + K_gain * (f - phi @ theta)
        P = (P - np.outer(K_gain, phi @ P)) / lam
        log.append(theta.copy())
    k_hat, xe_hat = theta[0], theta[1]/theta[0]
    return k_hat, xe_hat, k_true, x_e_mean, np.array(log)

k_hat, xe_hat, k_true, xe_true, hist = rls_identify()
print(f"K_env: 估计 {k_hat:6.1f}  真值 {k_true}")
print(f"x_e  : 估计 {xe_hat*1e3:6.2f} mm  真值 {xe_true*1e3:.2f} mm")
print(f"第 1 / 2 / 6 秒的 K 估计: {hist[999,0]:.0f} / {hist[1999,0]:.0f} / {hist[-1,0]:.0f}")

解读：RLS 三个更新式各司其职：K_gain 根据当前不确定性 P 与回归向量决定"这一步信多少"，theta 按预测误差修正，P 收缩表示"学到了"。几个数值决策的理由：P0=104 很大，让前几十拍基本"听数据的"；遗忘因子 0.995 的记忆窗口约 200 拍（1 kHz 下 0.2 s），对分钟级漂移偏短，真机建议 0.999 或自适应遗忘，代码里用 0.995 是为了在 6 秒的仿真窗口内演示收敛；激励 0.5 Hz、±2 mm 来自机器人端的推压微动，这样即使环境静止，(x, F) 数据也带足信息，辨识完成后把这段微动从任务轨迹里扣掉即可。验证点：K 的估计序列应在 1–2 s 内从 300 收敛到 400 附近（本例 1 s 时约 403、6 s 末约 393），x̂e 的误差在 0.1–0.3 mm（本例 0.13 mm；噪声 0.1 N ÷ K=400 的单点极限 0.25 mm 是量级基准）。如果收敛很慢或发散：检查 x 的波动幅度是否够大（激励不足）、遗忘因子是否过小（噪声放大）、以及回归向量的量纲差距是否过大（x~0.05 与常数 1 在本例可接受，更悬殊的数据仍建议对 x 做归一化）。

片段 3：合体，辨识瞄准 + 积分微调的全流程

class AdaptiveForceTracker:
    """估计驱动参考瞄准 + 小增益积分兜底。k_hat/xe_hat 来自外部 RLS。"""
    def __init__(self, k_eq, f_d, w_aim=0.004, gamma_trim=0.002, dt=1e-3):
        self.k_eq, self.f_d = k_eq, f_d
        self.w_aim = w_aim            # 瞄准低通：每拍搬运 0.4% 目标距离
        self.gamma_trim = gamma_trim  # 积分微调增益（τ≈数秒）
        self.x_r = None               # 参考点：第一次由进入接触位置初始化
        self.dt = dt

    def step(self, x_contact, f, k_hat, xe_hat):
        if self.x_r is None:
            # 初始参考：直接取"接触位置往回 F_d/K_eq"的保守估计
            self.x_r = x_contact + self.f_d / self.k_eq
        if abs(f) < 0.5:              # 接触丢失：冻结一切，等下一状态
            return self.x_r
        # 瞄准项：用估计参数算"力应该在哪"，低通搬运防抖
        x_aim = xe_hat + self.f_d / self.k_eq
        self.x_r += self.w_aim * (x_aim - self.x_r)
        # 微调项：独立于模型的力误差积分（兜底正确性）
        self.x_r += self.gamma_trim * (self.f_d - f) * self.dt
        self.x_r = float(np.clip(self.x_r, x_contact - 0.05, x_contact + 0.20))
        return self.x_r

# 下发给阻抗/导纳层的"参考点"从固定的 x_d 换成这个 x_r

解读：这个类把两条路线合成一个"参考点生成器"，接口干净：进去的是机器人当前位置、滤波力、以及辨识器输出的两个参数。三行核心逻辑的语气各不相同：初始化行x_r = x_contact + f_d/k_eq是"没有任何信息时的最好猜测"；瞄准行以上估计为根据，每拍只走 0.4%（w=0.004），10 s 后走完大半，比积分快、比 RLS 的原始估计稳；微调行以 0.002 的低增益补充"估计错了也能到"的正确性。限幅把参考点困在"当前接触位置向后 5 cm、向前 20 cm"的窗内，双向都防呆：前者防脱离后狂退，后者防压穿工件。参数搭配的检查方法：分开跑三组，只开瞄准、只开微调、两个都开，比较 6 s 内的力误差曲线；理想的合体应比任一单项都更快（瞄准的功劳）且终值更准（微调的功劳）。如果合体反而更差，多半是两个回路的增益相乘后接近了稳定边界，把 w_aim 减半再试，时间尺度分离是永远不会错的方向盘。

常见坑

  • 脱离接触不冻结：力为零时积分照跑，参考点"向前狂奔"，再接触时是一记高速撞击。修复：接触状态机 + 冻结 + 限幅三重保护（片段 1、3 都演示了）。
  • 自适应增益按"响应快"来调：τc 调到几十毫秒，与接触回路同频，结果力在目标值附近低频振荡。修复：τc≥0.3 s，并用 γKeqTa≤1 核对。
  • 静态接触上做辨识：没有位移激励，RLS 的两参数不可辨识，K̂ 乱飘。修复：正常推压动作即可提供激励；确实全静态的任务，给参考加微幅正弦（并把它从"任务精度"里扣掉）。
  • 把 K̂ 直接用于刚度切换：估计值有偏差时拿去改 Kd，等于把辨识误差放大进手感。修复：K̂ 只用于"参考瞄准"这类一阶量；参数整定第 021 章另走保守规则。
  • 两套自适应都开满：RLS 瞄准 + 大增益积分同时作用，两个慢回路互相驱动。修复：主从分工，瞄准快（10 s 级）、积分慢（分钟级）且增益小一个量级。

  1. 从 F=Keq(xr−xe) 出发，推导积分自适应下力误差的指数收敛律，并解释 γ 单位与收敛速率的关系。★
    提示
    Ḟ=Keqẋr=γKeq(Fd−F)；一阶线性 ODE，时间常数 1/(γKeq)。γ 单位 m/(N·s) 使 γ·Keq 量纲为 1/s。
  2. 用片段 1 把 γ 从 0.01 提到 0.3（保持其他参数），记录振荡出现的位置，并与判据 γKeqTa≤1 对照（Ta≈0.05 s）。★★

  3. 用片段 2 把激励幅度从 2 mm 降到 0.2 mm，再把噪声从 0.1 N 提到 0.3 N，各跑一次。解释哪一个变化对 K̂ 的收敛更致命，并为"低激励、高噪声"的场景给出两条改进。★★

小结

  • 未知环境力跟踪的目标参考 xr*=xe+Fd/Keq 含两个未知量；积分法与辨识法是找到它的两条路径。
  • 积分自适应 ẋr=γ(Fd−F) 使力误差指数收敛，速率 γKeq；稳定条件 γKeqTa≤1，τc=0.3–1 s 为甜区。
  • RLS 用回归 F=φTθ（φ=[x,−1]）在线辨识 Kenv 与 xe；激励不足不可辨识，估计要带范围检查。
  • 合体方案：估计驱动参考瞄准（低通）+ 小增益积分兜底 + 冻结/限幅/门限护栏；时间尺度分离（瞄准秒级、积分分钟级）是稳定的前提。
  • 下一章把"参数"本身变成变量：在冲击、接触、撤离各阶段动态调度 M、D、K，兼得安全与手感，变阻抗控制。
