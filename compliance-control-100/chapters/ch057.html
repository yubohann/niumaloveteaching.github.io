第三篇 · 感知、辨识与智能调参

第 057 章：基于强化学习的阻抗参数优化

模糊靠人写规则、NN 学函数形状，如果连"规则长什么样"都说不上来呢？强化学习让控制器在"试错 + 回报"中自己找到好的阻抗参数。本章把接触任务写成一个 MDP，用最小可跑的策略梯度循环演示参数优化，并把安全投影（shield）立成不可绕过的关卡。

  • 主题：强化学习（RL）/ 阻抗参数策略优化
  • 关键公式：J(θ) = E[Σγtrt]，∇J = E[∇logπθ(a|s)·(R − b)]
  • 预计学时：60 分钟
  • 前置章节：第 056 章（基于神经网络的阻抗控制）

学习目标

  • 会把接触任务写成 MDP：状态（力误差、误差率、速度、接触标志）、动作（阻抗参数）、回报（精度/超调/动作代价）。
  • 理解策略梯度定理的工程版本：用"回报加权"的方向更新策略参数，基线 b 削减方差。
  • 会做回报塑形（reward shaping）：为什么罚太狠会养出"不敢接触"的机器人，罚太松会养出"砸桌子"的机器人。
  • 掌握安全投影（shield）：把动作投到可行域（刚度/阻尼范围 + 阻尼比带），并对动作变化率限幅。
  • 明确 RL 的定位：优化"十几个参数"，不直接输出力矩；学习在离线/仿真完成，在线只做策略推断。

背景与动机

模糊（第 055 章）需要你的同事能把经验说成规则；神经网络（第 056 章）需要一个可微的误差信号。如果一个任务的"好参数"依赖大量相互纠缠的因素，工件表面从软到硬、进给速度、工具磨损、操作者习惯，你可能既写不出规则，也构造不出干净的监督信号。这类问题正好落在强化学习（reinforcement learning, RL）的射程内：定义一个回报（reward），让策略在反复尝试中把"什么状态该用什么参数"优化出来。

但 RL 用在力控上必须先立规矩：探索（exploration）在真实设备上意味着"故意做出可能危险的尝试"。所以工业上可行的形态是分层：底层是永远在线的经典控制器（保证稳定与安全），RL 只调它的少数参数；学习和验证在仿真里做，真机上以"带盾"的方式小步部署。本章的代码刻意保持最小：一个一维接触环境、一个高斯策略、一个策略梯度循环，重点是把"怎么让它不闯祸"讲清楚。

核心原理

1. 把任务写成 MDP

接触任务的 MDP 设计有一套实用惯例：

  • 状态 s：选"低维且物理意义明确"的量，力误差 ef、其变化率、末端速度 v、接触标志位。刻意不喂原始力/位置历史：状态越高维，样本需求越恐怖。
  • 动作 a：让策略输出"阻抗参数"（本章取 Kd 与阻尼比 ζ，再由 ζ 换算 Dd）：参数的动作空间天然有界、可解释，且安全投影容易做；力矩或位置增量作为动作则难有这些保证。
  • 回报 r：工程上写成四项之和：精度项 −0.02ef²、超调惩罚 −2·max(0, Fmax/(1.2Fd) − 1)2、动作代价 −0.0013·Kd（每步，"硬=贵"）、以及完成奖励 +2（偏差进入 ±5% 容差带）。
  • 回合（episode）：一次"加载→稳定"的力响应为一个回合（本章演示 0.2 s，8 个决策步 × 25 ms）；参数在每个决策步重采一次（决策频率远低于控制频率）。

2. 策略梯度：最小但正确的数学

策略 πθ(a|s) 用高斯分布（均值 = 参数目标，标准差 = 探索强度）。优化的目标是期望回报：

J(θ) = Eτ~πθ[ Σt γt rt ]

策略梯度定理给出一个惊人简洁的估计式：

∇J(θ) ≈ E[ ∇θlog πθ(a|s) · (R − b) ] R：该回合(或该步)的回报；b：基线（常用回报的滑动平均），减方差不偏置

对高斯策略，∇log π = (a − θ)/σ²，于是更新就是"让高回报时的动作更靠近被采样的值、低回报时更远离"。三个工程细节决定它能不能用：（1）回报归一化（减基线、除标准差），否则梯度尺度横跨几个数量级；（2）探索方差 σ 随训练退火（从大范围找方向到精细搜索）；（3）每次只动一点点（学习率小），参数化系统对突变敏感。

3. 回报塑形：小心你考核什么，就得到什么

回报设计里的两个经典陷阱，在力控里尤其致命：

  • 罚力过重 → 胆小鬼策略：超调惩罚系数大，策略学会"永远保持轻接触"，任务做不完却回报最高。修补：用"完成奖励 + 适度惩罚"，并检查最终参数是否落在物理合理区。
  • 只看最终误差 → 砸桌子策略：奖励对瞬态无感，策略学会用大刚度猛冲（力尖峰高但很快到位）。修补：显式惩罚力峰值（取 max 统计，不用平均），把瞬态纳入考核。

一句经验：回报的每一项都要能在日志里画出曲线、并对上物理直觉；画不出来的回报项，通常在教你错误的策略。

4. 安全投影（shield）：动作在进入控制器之前必须过闸

RL 的动作永远不直接作用于机器人，先经过一个确定性投影：

asafe = Π[a]， Π：Kd ∈ [200, 1500] N/m， ζ ∈ [0.8, 1.2]， |aₖ − aₖ₋₁| ≤ Δamax 投影是"多对一"的确定性映射：策略再离谱，控制器收到的参数始终在验证过的范围内

投影有代价：策略的"梯度信号"在投影边界上会失真（动作被削平，策略不知道自己错在哪），工程上通过"边界惩罚"补偿，把越界量作为额外负回报反馈给学习。工程直觉：shield 不保证策略最优，但保证"学习过程中的每一步都在安全集合内"，对真实硬件来说，这是把 RL 从论文带进车间的必要条件。

实现思路与设计

一个轻量的教学循环（在普通笔记本电脑上即可运行）：

  1. 环境：力环模型，力参考 20 N；每个决策步让参数作用 25 ms（25 个 1 ms 子步），共 8 步、0.2 s，观察力误差与峰值力。
  2. 策略：在归一化坐标 u 上的二维高斯，映射 Kd = 500+500u₁、ζ = 1+0.2u₂；均值初始 u = 0（即 [500, 1.0]），探索 σ 从 0.25 缓慢退火到 0.08。
  3. 回报：r = −0.02ef² − 2·max(0, Fmax/(1.2Fd) − 1)² − 0.0013Kd，回合末进入 ±1 N 容差带再 +2。
  4. 更新：逐回合 REINFORCE + 回报归一化（adv = (R−b)/std）+ 梯度截断 ±1，学习率 0.03，共 500 回合。
  5. 安全：物理映射 to_phys 内完成边界裁剪（含变化率限制的完整 shield 见片段 3）；记录动作被裁剪的比例，长期大于 20% 说明探索 σ 该收。
  6. 部署：训练结束后把策略退化为"查表 + 线性插值"或小 MLP 推理；在线只做前向计算，学习关闭。

预期结果（教学量级）：初始参数 [500, 1.0] 的回合回报约 −26；训练 500 回合后策略收敛到 Kd ≈ 800–850 N/m、ζ 贴在可行域下沿 0.8 附近，末期回报约 −19.9（与格点扫描的全局最优 −19.9 相当），它自己走到了"手调要摸半天"的那片参数区。ζ 贴边很有信息量：回报的超调阈值设在 1.2 倍，1.5% 的小超调不疼不痒，策略就把阻尼压到安全域边缘换响应速度；想让策略更保守，把超调阈值降到 1.05 再训一遍即可。

关键代码与解读

片段 1：最小接触环境与回报

import numpy as np

class ContactEnv:
    """一维接触任务的“力环”模型：策略给 (K_d, zeta)，它们决定闭环
    力响应的自然频率与阻尼，K 大到位快、zeta 小会超调。教学从简。"""
    def __init__(self, f_ref=20.0, m=2.0, dt=1e-3, substeps=25, t_steps=8):
        self.f_ref, self.m, self.dt = f_ref, m, dt
        self.substeps, self.t_steps = substeps, t_steps  # 每决策 25 ms，共 0.2 s

    def reset(self):
        self.f, self.fd, self.t = 0.0, 0.0, 0            # 力 / 力变化率 / 步计数
        return self._obs()

    def _obs(self):
        # 状态：归一化力误差 + 归一化力变化率（低维、物理可读）
        return np.array([(self.f_ref - self.f) / self.f_ref,
                         self.fd / self.f_ref])

    def step(self, k_d, zeta):
        omega = np.sqrt(max(k_d, 1.0) / self.m)          # 硬=快、软=慢
        f_max = 0.0
        for _ in range(self.substeps):
            fddot = omega**2 * (self.f_ref - self.f) - 2.0*zeta*omega*self.fd
            self.fd += fddot * self.dt
            self.f += self.fd * self.dt
            f_max = max(f_max, self.f)
        e = self.f_ref - self.f
        r = -0.02 * e * e                                # ① 精度
        r -= 2.0 * max(0.0, f_max / (1.2*self.f_ref) - 1.0) ** 2  # ② 超调
        r -= 0.0013 * k_d                                # ③ 动作代价：硬=贵
        self.t += 1
        if self.t >= self.t_steps:
            r += 2.0 if abs(e) < 0.05 * self.f_ref else 0.0   # ④ 完成奖励
        return r, self._obs()

解读：（1）环境本身是"玩具"，重点是 MDP 接口的形状：参数进、回报与观测出；真机上这个类由仿真器或数字孪生实现。（2）回报里的峰值惩罚用 f_max（由子步记录），不用步末力：这正是"砸桌子策略"的疫苗，只看稳态的策略会选激进参数，只看峰值又过度保守，两者相加才平衡。（3）完成奖励用 1 N 的容差带，简单但有效：它告诉策略"任务是什么"，否则优化会退化成"参数越软越好"。（4）注意 step 里没有任何"安全逻辑"，安全由外面的 shield 管（片段 3），职责分离让环境代码保持纯粹。

片段 2：REINFORCE 循环（策略梯度最小实现）

def to_phys(u):
    """归一化策略坐标 → 物理参数，顺便过安全边界（完整版见片段 3）：
    K = 500+500*u1 截到 [200,1500] N/m；zeta = 1+0.2*u2 截到 [0.8,1.2]。"""
    k = float(np.clip(500.0 + 500.0 * u[0], 200.0, 1500.0))
    z = float(np.clip(1.0 + 0.2 * u[1], 0.8, 1.2))
    return k, z

def episode_once(env, k_d, zeta):
    """按固定参数跑完一个回合(0.2 s)，返回累计回报。"""
    env.reset()
    R = 0.0
    for _ in range(env.t_steps):
        r, _ = env.step(k_d, zeta)
        R += r
    return R

def train(episodes=500, lr=0.03, seed=0):
    """最小策略梯度：归一化高斯策略 + 回报归一化 + 梯度截断 + 安全边界。"""
    env = ContactEnv()
    theta_u = np.array([0.0, 0.0])          # 0 → (K_d=500 N/m, zeta=1.0)
    sigma_u = np.array([0.25, 0.25])        # 探索强度(归一化坐标)，缓慢退火
    baseline, var = -26.0, 4.0
    rng = np.random.default_rng(seed)
    history = []
    for ep in range(episodes):
        a_u = theta_u + sigma_u * rng.standard_normal(2)  # 采样动作
        k, z = to_phys(a_u)                 # 映射物理参数并过安全边界
        R = episode_once(env, k, z)
        var = 0.9 * var + 0.1 * (R - baseline) ** 2
        adv = (R - baseline) / (np.sqrt(var) + 1e-6)      # 回报归一化
        # 高斯策略的 ∇logπ = (a-θ)/σ²；截断防单次极端回报把参数带飞
        g = ((a_u - theta_u) / sigma_u ** 2) * adv
        theta_u = theta_u + lr * np.clip(g, -1.0, 1.0)
        baseline = 0.9 * baseline + 0.1 * R
        sigma_u = np.maximum(sigma_u * 0.997, np.array([0.08, 0.08]))
        history.append(R)
    return theta_u, history

theta_star, hist = train()
k_star, z_star = to_phys(theta_star)
print("训练初始回报:", round(hist[0], 2))
print("训练末期回报:", round(np.mean(hist[-20:]), 2))
print("学到的参数: K_d=%.0f N/m, zeta=%.2f" % (k_star, z_star))

解读：（1）策略在"归一化坐标 u"里学习，物理映射与裁剪放在 to_phys，这是让更新步长在两个维度上都合适的关键：直接对 [Kd, ζ] 做高斯更新时，K 的尺度（几百）与 ζ 的尺度（零点几）差三个数量级，σ² 归一化会让某一个维度的有效步长大得失控。（2）回报归一化再配滑动基线：adv = (R−b)/std，它不改变期望梯度方向（E[∇logπ·b] = 0），只把步长压到 O(1) 量级，不加基线与标准化的版本在接触任务里方差大到几乎学不动，这是读者最容易踩的坑。（3）梯度截断 ±1 是"参数化系统的安全带"：单次幸运或倒霉回合的 (R−b) 可达几个标准差，不截断时一次就能把参数推出去很远；截断牺牲一点理论优雅，换训练过程和参数轨迹都平滑可控。（4）实测输出（默认种子）：首回合回报 −25.7、末期 ≈ −19.9；5 次不同随机种子的训练都收敛到 Kd ≈ 810–850 N/m、ζ = 0.80，末期回报 ≈ −19.9，与格点扫描最优 (850, 0.8) 的 −19.9 一致，说明这套最小实现确实收敛到了全局最优附近；ζ = 0.80 正是可行域下沿，其含义见"实现思路"一节的解读。（5）500 回合 × 8 步的规模在笔记本电脑上几秒钟跑完；换成整臂接触任务，样本量要乘 103–104，所以真实项目几乎都从"仿真预训练 + 真机微调"开始。

片段 3：安全投影（shield）

class Shield:
    """安全投影：把策略动作投到已验证的可行域，并限制参数变化率。
    投影不可绕过：RL 输出的任何数值都必须先过这里。"""
    def __init__(self, m_d=2.0, k_lo=200.0, k_hi=1500.0,
                 z_lo=0.8, z_hi=1.2, dk_max=100.0, dz_max=0.05):
        self.m_d = m_d
        self.k_lo, self.k_hi = k_lo, k_hi      # 刚度可行域(N/m)
        self.z_lo, self.z_hi = z_lo, z_hi      # 阻尼比可行域
        self.dk_max, self.dz_max = dk_max, dz_max
        self.k_last, self.z_last = 500.0, 1.0

    def __call__(self, a_raw):
        k = float(np.clip(a_raw[0], self.k_lo, self.k_hi))
        z = float(np.clip(a_raw[1], self.z_lo, self.z_hi))
        # 变化率限制：防止“参数阶跃”把第 053 章的能量问题引进来
        k = float(np.clip(k, self.k_last - self.dk_max, self.k_last + self.dk_max))
        z = float(np.clip(z, self.z_last - self.dz_max, self.z_last + self.dz_max))
        self.k_last, self.z_last = k, z
        d = 2.0 * z * np.sqrt(k * self.m_d)    # 由 (K, zeta) 算出 D
        return np.array([k, d])

def shield(a_raw):
    return _GLOBAL_SHIELD(a_raw)

_GLOBAL_SHIELD = Shield()   # 全局单例：训练与部署共用同一套边界

解读：（1）可行域 [200, 1500] N/m、ζ ∈ [0.8, 1.2] 不是拍脑袋：它们来自前面章节的稳定性分析（刚度上限由内环带宽与时延预算决定，ζ ≥ 0.8 保证不振荡），shield 的参数应该从正式的控制分析里来，不能从 RL 的奖励里反推。（2）动作空间用 (K, ζ)，不用 (K, D)：ζ 的可行带比 D 的可行带更稳定（不受 K 变化导致的 √ 换算），也更容易向同事解释。（3）变化率限制（dk_max = 100 N/m 每决策步）把第 053 章的"参数突变注能"问题挡在学习阶段之外。（4）单例写法故意让"训练时"和"部署时"共用同一个投影器：避免出现"离线验证过的边界"和"上线后实际的边界"不一致这种经典事故。

常见坑

  • 把 RL 直接接在力矩上：动作空间变成不安全的高维连续量，探索等于随机破坏。修复：RL 只调参数（本章），力矩永远由经典控制器计算。
  • 没有基线：梯度方差巨大，训练曲线看起来"在学"，实际是随机漫步。修复：滑动平均基线（一行代码），必要时再用回报归一化。
  • 回报只看终值：策略学会"猛冲到位"，力峰值被忽略，真机上触发保护。修复：加峰值惩罚（max 项），并把 Fmax 打进日志。
  • 在真实机器人上从零探索：未经训练的随机策略必然撞出危险力。修复：仿真（域随机化：Kenv、噪声、延迟各扫一个范围）训练 → 真机上以"冻结策略 + 小 σ"部署，且全程有 shield。
  • 边界惩罚缺失：超过 50% 的动作被投影削平时，策略收不到"你越界了"的信号，卡在边界附近废话。修复：把越界量计入回报；或把动作空间直接参数化为 sigmoid 压缩的形式。

练习与思考

  1. 证明滑动基线不引入梯度偏差：说明 E[∇logπ(a|s)·b(s)] = 0（对任意只依赖状态的 b），因此减去它可以减方差而不改期望方向。★★
    提示
    Ea~π[∇logπ·b] = b·∇∫π da = b·∇1 = 0。
  2. 用片段 2 训练，把回报里的峰值惩罚从 2.0 改到 0.2 与 8.0，各跑一遍，记录学到的 (Kd, ζ) 与末段力峰值的对应关系，解释"你考核什么就得到什么"。★★
    提示
    惩罚轻 → K 偏大、峰值高；惩罚重 → K 偏小、到位慢。没有"正确"的系数，只有"与验收指标一致"的系数，先定验收，再定回报。
  3. 把探索方差 σ 固定不衰减（验收训练曲线），解释为什么末段回报的方差明显变大、以及"训练在平台上震荡"与"探索不足卡在局部"两种现象如何用 σ 曲线与回报曲线联合诊断。★★
    提示
    σ 不衰减 → 每回合采样的动作噪声不收敛 → 回报波动大；σ 太小 → 早期就卡死。典型配方：σ 随回报平台期到达而衰减（自适应退火）。
  4. 为"多环境"训练设计域随机化方案：列出你会随机化的三类参数（环境刚度范围、传感噪声量级、通信/滤波延迟范围），给出各自的分布假设与采样范围，并解释为什么域随机化是"仿真训练-真机部署"之间最重要的一道桥。★★★
    提示
    Kenv：对数均匀 103–106；力噪声：0.05–0.5 N；延迟：1–20 ms。策略在"很多种世界"里都得分高，意味着它对真实世界（也在集合内）更可能健壮；代价是峰值性能下降、训练变慢。

小结

  • 接触任务的 MDP：低维状态、参数化动作（Kd、ζ）、四项回报（精度/峰值/动作/完成）。
  • 策略梯度：∇J ≈ E[∇logπ·(R−b)]；高斯策略下就是"高回报方向靠拢"；基线减方差是可用性的分水岭。
  • 回报塑形决定策略性格：罚太狠出胆小鬼、看终值出砸桌子；每一项都要画得出来、对得上物理。
  • shield 是硬边界：可行域来自控制分析、变化率受限、训练与部署共用；越界量反馈进回报。
  • 分层安全架构：经典控制器保底，RL 只调参数；仿真（域随机化）训练、真机小步部署。
