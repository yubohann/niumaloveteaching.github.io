第 063 章：导纳控制中的低频扰动抑制

导纳控制把"测到的力"变成"位置修正"，于是力的慢偏置会直接酿成位置的慢漂移。本章讲清直流偏置、缓变漂移与慢变任务力三者的频段边界，并给出冲刷滤波、泄漏积分、偏置估计与冻结三套机制的使用边界。

  • 主题：导纳控制 / 低频扰动与漂移抑制
  • 关键公式：冲刷滤波 H(s) = s/(s+ωc)；泄漏积分 ẋi = ki(Fref−F) − λxi
  • 预计学时：50 分钟
  • 前置章节：第 062 章

学习目标

  • 理解导纳控制中低频扰动的三条进入通道：力测量的直流偏置、真实但缓慢变化的外力、以及参考位置的缓漂。
  • 会写出冲刷滤波（washout）的传递函数与差分实现，定量说明它对直流增益为零、对慢变任务力会造成多大的衰减。
  • 会设计带泄漏的积分修正，并推导泄漏系数 λ 与稳态残余力误差之间的定量关系。
  • 理解偏置估计器的"冻结"机制：为什么任务力和传感器偏置在信号上不可区分，只能靠上下文切换。
  • 掌握低频段的分工表：DC 偏置、0.01–0.5 Hz 漂移、0.5–5 Hz 任务力分别交给谁。
  • 会用"水床效应"解释为什么低频抑制带宽不应无限加宽。

背景与动机

上一章处理的是中频扰动：用更快的内环把 0.5–50 Hz 的动态压掉。但工程现场最频繁的抱怨其实是另一个频段：力传感器零点温漂 1–3 N、工具线缆拖拽、重力补偿残差、工件缓慢热变形，它们都在 0.5 Hz 以下，属"看着像真力、其实不是"的信号。

对阻抗控制来说，慢偏置只造成一个静态位置偏差（Kd 越大偏差越小）；但对导纳控制，力是输入、位置是输出，输入端的偏置会被积分成一个持续的位置漂移：2 N 的偏置在 K = 200 N/m 的导纳模型下就是 10 mm 的目标偏移；若 K 取 0，机器人会以 F/D 的速度一直走，直到撞上限位。本章的任务，就是把"哪些低频信号该被忽略、哪些是任务本身"这条边界画清楚。

核心原理

1. 低频扰动为什么在导纳里格外麻烦

先看导纳方程的稳态解。对 Mvẍ + Dvẋ + Kv(x−xr) = Fmeas，当外力恒定、加速度与速度为零时：

xss = xr + Fmeas / Kv Kv：导纳的虚拟刚度，N/m；Fmeas 含"真力+偏置"

若把 Fmeas 写成真力 Fext 加偏置 b，位置就多出一项 b/Kv。Kv 越小（越柔顺），同样的偏置造成的偏移越大：Kv = 200 N/m、b = 2 N 时是 10 mm；若为做拖动示教把 Kv 设成 0、只留阻尼 Dv = 50 N·s/m，则速度稳态为 b/Dv = 40 mm/s，机器人以肉眼可见的速度自己"飘走"。这就是低频扰动的第一条特性：它不会被阻尼吃掉，只会被刚度或积分机制处理。

第二条特性来自信号本身：偏置与"用户想让你跟踪的慢力"在频谱上完全重叠。工件热膨胀让接触力缓慢爬升（是真实任务力），传感器温漂也让读数缓慢爬升（是假的），单看力信号无法区分，只能靠"上下文"（当前是否有任务、是否处于接触）把两者分开。这是本章全部机制设计背后的约束。

2. 三条通道、三个频段的分配表

信号频段机制代价
传感器偏置、工具重力残差DC（< 0.01 Hz）标定 + 重力补偿 + 偏置估计需要"无接触"学习窗口
温漂、线缆拖拽、参考缓漂0.01–0.5 Hz冲刷滤波 / 泄漏积分慢变任务力被一并削弱
真正的任务力（接触、按压）0.5–5 Hz保留通带，交给导纳动态无（这是要保护的部分）
接触冲击、噪声> 5 Hz导纳的虚拟质量 + 低通（062 的 ε 层）响应变慢

工程直觉：低频抑制的本质是"在正确的频段上做高通"，滤掉想忽略的，保住不想忽略的。参数选择归结为一句话：找到任务力最慢的变化速率，把抑制机制的截止频率压到它之下。

3. 冲刷滤波：把直流"洗掉"的一阶高通

冲刷滤波（washout filter）的连续传递函数是：

H(s) = s / (s + ωc)  ⟹  直流增益 0，ω ≫ ωc 时增益 → 1 ωc = 2πfc，rad/s；fc 典型 0.5–2 Hz

它对恒定力完全"看不见"，缓慢漂移会在约 1/fc 秒内被洗成零，机器人于是不会随偏置漂移。副作用要用数字记住：对斜率 r = 0.2 N/s 的斜坡力（工件热膨胀），输出不跟随增长，稳态趋近常值 rτ = 0.2 × 1/ωc ≈ 0.03 N：缓慢增长的任务力被削成一个小偏置。ωc 既是"洗掉多快"的标尺，也是"忽略多慢以下信号"的标尺。若任务要求长时间保持恒定接触力，请不要用冲刷滤波：恒定力正是它要洗掉的东西，表现为压上去 2 秒后力自己滑回零、工件被松开。

4. 泄漏积分：给积分器装上"记忆时间"

对"保持型"任务（顶住工件维持接触力），正确工具是对力误差积分，但纯积分的记忆是无限的：一旦偏置方向或符号判错，它会一直朝错误方向推。泄漏积分（leaky integrator）给积分状态加一个与自身成比例的泄放项：

ẋi = ki(Fref − Fmeas) − λ xi，xi 直接叠加到导纳输出位置 ki：积分增益，m/(N·s)；λ：泄漏率，s−1，记忆时间约 1/λ

稳态分析可以给出残余误差的完整表达式。设修正量 xi 通过环境等效刚度 Keff 作用于接触力（每深入 1 m 力增 Keff N），静平衡时：

ess = Fref − Fss = λ(Fref − F0) / (λ + kiKeff) F0：未加修正时的接触力水平，N

纯积分（λ = 0）残余误差为零；λ > 0 时留下一个比例式残差，例如 λ = 0.05 s−1、ki = 0.02 m/(N·s)、Keff = 104 N/m，则残差只有初偏的 0.025%。这里的精度代价几乎可以忽略，泄漏真正兜住的是参数被改错、符号判错这类极端场景，用看不见的精度损失换"永远不会跑飞"的有界性，通常值得。

5. 偏置估计与冻结：靠上下文区分真假力

偏置估计器把力信号的低频部分慢速学习成一个估计值 b̂ 并从前馈中扣掉，它是处理 DC 通道最干净的手段，前提是"学习窗口"选对：只在准静态、且明确处于自由段（未接触、任务未开始）时学习。判据通常两条同时成立：力的变化率小（|dF/dt| < 5 N/s）、读数与当前估计的偏离小（|F − b̂| < 0.8 N）。一旦接触发生或操作者开始按，立即"冻结"学习，否则估计器会把任务力当偏置学掉，机器人随后就不再出力，这是现场最典型的"越学越软"故障。

设计决策：为什么用"泄漏"？"更小的积分增益"不行吗？

把 ki 调小确实能减慢漂移，但同时也等比例延长了收敛时间，稳态精度却不受影响，它管的是响应快慢，对"漂移"本身没有作用。泄漏项 λ 专门作用于"长时间积攒的修正量"，只削减超慢分量，对 1–5 Hz 内的力跟踪几乎无影响。两者单位不同、频段不同，是不能互相替代的两把刀。

最后记住一条频域约束：任何稳定闭环的灵敏度函数满足 ∫ln|S|dω = 0（水床效应），低频压下去的抑制量必然在别处抬起来。因此低频抑制带宽只需要覆盖真实的漂移频段（0.01–0.5 Hz），把 fc 或 λ 往 0.001 Hz 推不但没有收益，还会把相位余量耗在中频。

实现思路与设计

把你的任务先分成"保持型"（维持某个接触力水平，如打磨、按压）与"跟踪型"（力要按规划变化，如力跟踪、装配插入），机制选择完全不同：

  1. 标定与补偿先行：空载标定传感器零点，按工具重力模型扣除重量与重心力矩残差；这步没做，后面所有机制都在和数倍于漂移的残差搏斗。
  2. 保持型任务：导纳方程 + 泄漏积分（λ 对应 10–30 s 记忆）+ 0.2–0.5 N 死区；不用冲刷滤波，因为任务力本身就是"慢"的。
  3. 跟踪型任务：保留直通力通道，另加 0.05–0.2 Hz 的偏置估计器，用接触检测触发冻结；力参考的变化速率不要低于 0.05 Hz 等效斜率，否则会落进估计器窗口。
  4. 参数起点：fc = 1 Hz（τ ≈ 0.16 s）；λ = 0.05 s−1；ki = 0.02 m/(N·s)；xi 限幅 ±20 mm。
  5. 限幅与安全：xi 与冲刷输出都限幅；冻结解除后用 0.5–1 s 渐变恢复学习，避免突变。
  6. 验证：顶住等效刚度约 104 N/m 的弹性工件，在力读数上叠加 2 N 阶跃偏置，记录位置漂移（应有限、有界）与稳态残余力（应小于 0.5 N）。
数字感受一下

b = 2 N 的偏置在无机制时造成 10 mm 漂移（Kv = 200 N/m）；加 λ = 0.05 的泄漏积分后被压到毫米级、20 s 量级自动回中，代价是 0.3–0.5 N 稳态残差。先问能接受多少残差，再反选 λ，顺序反过来很容易调一整天。

关键代码与解读

片段 1：冲刷滤波，一行差分实现一阶高通

import numpy as np

class WashoutFilter:
    """一阶冲刷滤波：H(s) = s / (s + wc)。
    用途：在保持型任务里把恒定/超慢的力偏置'洗掉'，不让它进导纳。"""
    def __init__(self, fc=1.0, dt=1e-3):
        self.dt = dt
        self.tau = 1.0 / (2.0 * np.pi * fc)     # 时间常数，1 Hz 对应约 0.16 s
        self.a = self.tau / (self.tau + dt)     # 离散极点，越接近 1 泄放越慢
        self.f_prev = 0.0                       # 上一拍输入，做差分用
        self.y = 0.0                            # 滤波输出（去偏置后的力）

    def update(self, f_meas):
        # 差分 (f - f_prev) 保证直流增益严格为零：恒定输入最终输出恒为 0；
        # 极点 a 决定'洗掉'要多快。注意 a 由 tau 与 dt 共同决定，
        # 若直接写 a = 0.99 而不看 dt，实际截止频率会随控制周期漂移
        self.y = self.a * self.y + self.a * (f_meas - self.f_prev)
        self.f_prev = f_meas
        return self.y

解读：差分方程 y[k] = a·y[k−1] + a·(f[k] − f[k−1]) 对应的离散传递函数 H(z) = a(1 − z−1)/(1 − a·z−1)，代入 z = 1（直流）得零增益，代入 z = −1（奈奎斯特）得 2a/(1+a) ≈ 1：正是我们想要的形状。a 由 tau 和 dt 推出，不写死常数，是因为控制周期可能随平台变化，写死会让截止频率悄悄跑偏。把 f_prev 与 y 当内部状态，意味着此实现只允许单实例、顺序调用。

片段 2：泄漏积分，给修正量设定"记忆时间"

class LeakyForceIntegrator:
    """带泄漏的力误差积分：输出 x_i 直接叠加到导纳位置指令上。
    纯积分记忆无限长，一次符号错误就可能推动机器人跑飞；泄漏项给出有界性。"""
    def __init__(self, k_i=0.02, leak=0.05, dt=1e-3, x_max=0.02):
        self.k_i, self.leak, self.dt = k_i, leak, dt
        self.x_max = x_max          # 修正量上限 20 mm，防意外工况
        self.x_i = 0.0              # 积分状态：位置修正量，单位 m
        self.freeze = False         # 冻结标志：接触过渡、力阶跃期间置 True

    def step(self, f_ref, f_meas):
        if not self.freeze:
            # -leak*x_i 是泄放项：记忆时间约 1/leak 秒。
            # 它保证哪怕 f_ref - f_meas 长期有偏差（比如参考被人改错），
            # 修正量也不会无限增大，在 k_i*e/leak 附近停下
            self.x_i += self.dt * (self.k_i * (f_ref - f_meas)
                                   - self.leak * self.x_i)
            # 硬限幅永远保留：泄漏的'理论有界'依赖参数没被改错
            self.x_i = float(np.clip(self.x_i, -self.x_max, self.x_max))
        return self.x_i

解读：freeze 放在方法内部判断，不交给外部决定，是为了让"何时积累修正"与"修正怎么算"绑定在一起、不会被调用方忘记。泄漏项系数用乘 dt 的形式（不直接写 x_i *= 0.999）保证连续时间语义：换控制周期时记忆时间不变。限幅用 np.clip 是最后一道安全线，注意它不做 anti-windup 回写，因为泄漏项本身已经在"泄压"；若你的任务对 20 mm 上限很敏感，应改用带回写（back-calculation）的限幅，这是 061 章内容的低频版复用。

片段 3：偏置估计器，用"变化率 + 偏离量"触发冻结

class BiasEstimator:
    """慢偏置估计 b_hat：学习力的直流分量，在疑似事件出现时冻结学习。"""
    def __init__(self, fc=0.1, dt=1e-3, freeze_rate=5.0, freeze_band=0.8):
        self.tau = 1.0 / (2.0 * np.pi * fc)     # 0.1 Hz：约 1.6 s 时间常数，只跟温漂
        self.a = self.tau / (self.tau + dt)
        self.b_hat = 0.0
        self.freeze_rate = freeze_rate          # 变化率阈值，N/s
        self.freeze_band = freeze_band          # 偏离阈值，N
        self.f_prev = 0.0

    def update(self, f_meas, dt):
        rate = abs(f_meas - self.f_prev) / dt
        # 双条件：变化太快说明有事件；偏离已学偏置太远说明任务力已出现。
        # 只有两个条件都不触发时才允许学习：把'上下文'显式编码进代码
        learn = (rate < self.freeze_rate) and (abs(f_meas - self.b_hat) < self.freeze_band)
        if learn:
            self.b_hat = self.a * self.b_hat + (1.0 - self.a) * f_meas
        self.f_prev = f_meas
        return self.b_hat, learn

解读：估计器增益 (1 − a) ≈ dt/τ ≈ 6×10−4，单次更新只挪动万分之六左右，任何单拍噪声都带不偏它，"慢"本身就是鲁棒性来源。两个冻结条件分工不同：rate 抓突发事件（碰撞、抓取），freeze_band 抓缓变任务力。返回 learn 标志供调试界面显示：如果打磨过程中 flag 还在闪 True，说明阈值偏松，正在把任务力学掉。

常见坑

  • 用冲刷滤波做力保持：现象是"压上去 2 秒后力自己回零、工件被放开"，恒定接触力恰恰是它要洗掉的直流。修复：保持型任务换成泄漏积分；只有"防漂移但不要求维持特定力水平"的任务才用冲刷。
  • 纯积分 + 偏置符号错误：修正方向与偏置同号时互相喂养，位置以指数速度跑飞，撞上软件限位才停。修复：泄漏项 + 限幅 + 上电小位移试探验证符号（力增大时修正应使机器人退让）。
  • 偏置估计吃掉了任务力：现象是"刚接触时力正常，两三秒后越来越软"。原因：冻结阈值过松或学习窗口太长，把接触力学成了偏置。修复：收紧 freeze_band，让接触检测同时抑制学习。
  • 死区造成极限环：死区吃掉静差后，机器人在"该动"与"不动"间反复切换，表现为 1–3 Hz 的轻微抖动。修复：死区加滞环（进 0.5 N 启动、回 0.2 N 停止），或对修正量做速率限制。
  • 把 λ 推得极小"追求精度"：λ = 0.001 s−1（记忆 1000 s）效果上等于纯积分，有界性退回原点。修复：先量化可接受残差，再由残差公式反解 λ。

练习与思考

  1. 推导冲刷滤波 H(s) = s/(s+ωc) 对斜坡输入 r·t 的稳态响应，验证文中"稳态输出趋近 rτ"的结论。 ★
    提示
    用终值定理：Y(s) = H(s)·r/s² = r/(s(s+ωc))，稳态值 y(∞) = lims→0 s·Y(s) = r/ωc = rτ。
  2. 实验设计：让机器人顶着弹性工件，给力读数叠加 2 N 阶跃偏置，分别用 (a) 无机制、(b) 冲刷滤波 fc = 1 Hz、(c) 泄漏积分 λ = 0.05 三种配置跑 30 s，记录位置漂移峰值与末态残余力，列表比较。 ★★
    提示
    (a) 会出现 10 mm 量级漂移；(b) 漂移几分钟值后被洗回但任务力也被削；(c) 漂移有界、残余力约 0.3–0.5 N。注意三种配置要使用同一套导纳参数。
  3. 推导泄漏积分的稳态残余误差公式 ess = λ(Fref−F0)/(λ + kiKeff)，并说明当 Keff → ∞（刚硬工件）时残差如何变化。 ★★
    提示
    令 ẋi = 0，结合 Fss = F0 + Keffxi 联立消元。刚性工件使 kiKeff 远大于 λ，残差趋于零，峰值力控制变容易，但稳定性裕度变差，两个效应方向相反。
  4. 任务对比练习：任务 A 是"以 20 N 顶住工件保持 60 s"；任务 B 是"接触力在 10 s 内从 5 N 线性升到 25 N"。为两者分别选择机制组合（冲刷/泄漏积分/偏置估计）与参数，并写出理由。 ★★★
    提示
    A 是保持型：泄漏积分 + 死区，禁用冲刷。B 的力以 2 N/s 上升，偏置估计器必须把 freeze 阈值压到 0.5 N/s 以下，否则会吃掉斜坡。
  5. 思考题：为什么低频抑制的截止频率不需要低于 0.001 Hz？请用灵敏度函数的水床效应回答。 ★★
    提示
    ∫ln|S|dω = 0：低频压得越深越宽，中频必然抬得越多；而 0.001 Hz 以下没有真实扰动源，投入买不到收益，只消耗相位余量。

小结

  • 导纳控制中，力的慢偏置会被放大成位置的慢漂移：Kv 越小放大越厉害，Kv = 0 时退化为匀速漂移。
  • 频段分工：DC 偏置交给标定+估计+冻结；0.01–0.5 Hz 漂移交给冲刷滤波或泄漏积分；0.5–5 Hz 任务力必须保住通带。
  • 冲刷滤波 H(s) = s/(s+ωc)：对直流零增益、对慢变力有 rτ 的经验偏差；只适合"不允许漂移、不要求保持恒定力"的任务。
  • 泄漏积分用残差 ess ∝ λ 换有界性；λ 的选择按"可接受残差"反解，别凭手上感觉。
  • 偏置估计必须冻结：任务力与偏置同频同量纲，唯一的区分手段是上下文（自由段、低变化率）。
