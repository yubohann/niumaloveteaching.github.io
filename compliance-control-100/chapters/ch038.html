第二篇 · 参数调节与交互任务

第 038 章：导纳控制中的虚拟质量调节

Md 是导纳参数里最"隐形"的一个：它不改变稳态、却决定起步手感、加速度噪声与内环带宽冲突。本章给出 M 的选用流程：先按内环带宽定下限、再按噪声定上限、最后用阻尼把形状收尾。

  • 主题：参数整定 / 虚拟惯量 / 噪声与带宽
  • 关键公式：τ起步 = Md/Dd，σa = σF/Md，Mmin ≈ Kd/(ω内环/5)²
  • 预计学时：50 分钟
  • 前置章节：第 036 章、第 037 章

学习目标

  • 理解 Md 在导纳控制中的三个身份：起步时间常数 Md/Dd 的来源、加速度噪声的分母（σa=σF/Md）、以及内环带宽的"不速之客"（ωn=√(Kd/Md)）。
  • 会做三件事的量化：用小 Md 换起步灵敏度的收益、噪声放大的代价、以及与内环伺服带宽的最小间距要求。
  • 掌握虚拟质量的底线公式 Mmin ≈ Kd/(ω内环/5)²，并知道为什么它决定了"不能再小了"。
  • 会使用"固定形状换质量"的缩放律：ωn、ζ 不变的前提下，M→a·M 需同时 K→a·K、D→a·D。
  • 能按"先定 M 下限、再配 D、最后验噪声与手感"的流程独立完成一组导纳参数设计。

背景与动机

调导纳参数时，工程师的注意力几乎都在 Kd（刚度、手感软硬）和 Dd（阻尼、超调）上，Md 常年被"设个 1 kg 算了"。但 Md 绝不是旁观者：它决定你推第一下时机器人"多久才动起来"（Md/Dd），决定力传感器噪声被放大成多大的加速度（σa=σF/Md），还决定导纳动态带宽 √(Kd/Md) 会不会撞上内环伺服的带宽。

第 036 章已经见过一个戏剧性的场景：同样的 λ 和阻尼口径，Md 从 0.5 加到 8 kg，超调从 21% 降到 2.6%，但那是阻尼没配好时的"意外收获"。本章要把 Md 的正经作用讲清：什么时候小是对的（示教拖动的轻快起步）、什么时候小是危险的（噪声与带宽），以及怎样在不改变 K、D 语义的前提下调整 M。

核心原理

1. Md 管什么：起步、噪声、带宽

导纳方程 Mdẍ + Ddẋ + Kd(x−xr) = Fh（外力驱动）中，Md 的系数出现在加速度项。对自由拖动（Kd=0、常力 F），速度的响应是：

v(t) = (F/Dd)·(1 − e−t/τ)，τ = Md/Dd 稳态 v=F/Dd 与 Md 无关；Md 只买"起步多快"，τ 就是这次起动的缓释时间

取 Dd=100 N·s/m、F=10 N：稳态都是 100 mm/s，但 Md=0.5 kg 的起步时间常数只有 5 ms，Md=5 kg 要 50 ms，"轻推一下何时开始动"的区别就是它。工程直觉（示教场景）：Md 是手感里的"重量"；同样的力气、同样的最终速度，Md 大就像推购物车、小就像推空箱子。

代价有两个。第一，噪声：力噪声 σF（典型 0.1 N）经 Md 变成加速度噪声：

σa = σF / Md，　σẋ（ω≪1/τ 时）≈ σF/Dd Md=0.2 kg 时 0.1 N 噪声对应 0.5 m/s² 的加速度抖动，被积分两次后成为位置噪声，小质量必须配滤波

第二，带宽冲突：Kd>0 时导纳自然频率 ωn=√(Kd/Md)。导纳的输出要由内环位置伺服执行，而内环是"带延迟的执行器"；经验要求：

ωn ≤ ω内环 / 5　⟹　Md ≥ Kd / (ω内环/5)² 内环 30 Hz（≈188 rad/s）、Kd=800 时 Md ≥ 800/(37.7)² ≈ 0.56 kg

这就是 Md 的"不能更小线"：再小，导纳动态就把内环的延迟"看出来"了，表现为高频低幅振荡（有时被误认成力传感器故障）。综合三个身份，Md 的推荐区间是 0.5–2 kg（工具级任务），示教拖动可以到 0.3 kg 但必须加带宽复核。

2. 缩放律：换 M 而不换"形状"

如果想把 Md 调整到 a 倍、同时保持自然频率与阻尼比不变（即同样的响应形状）：

M → a·M，　K → a·K，　D → a·D　⟹　ωn、ζ 均不变 推导：ωn²=K/M、ζ=D/(2√(KM))，三参数同乘 a 时两个比值都不变

这条缩放律有两类用法：（1）仿真缩放，把真机参数整体缩放到仿真里调（比如全部 ×0.1），只要是按比例缩放，响应形状不变，调好后再缩回去；（2）刻意打破形状，只想"起步更轻"又不想动 K 的，就单独减 M 并加大滤波；只想"更沉稳"的，单独加 M 而保持 D、K 不变（ζ 会变大、ωn 变小，响应更慢更平顺，第 036 章的超调下降正是这条）。两种用法要分清，别在缩放律生效时误以为"只动了 M"。

实现思路与设计

实验设置（1 kHz；两组对照）：

  1. 实验 A（起步手感，Kd=0 自由拖动）：Dd=100 N·s/m、F=10 N 阶跃，Md ∈ {0.5, 1, 2, 5} kg；测达到 90% 稳态速度的时间（≈2.3τ）与稳态速度。
  2. 实验 B（接触力阶跃，λ=0.01，Kd=1000，Kenv=1×104）：Md ∈ {0.5, 2, 8} kg，Dd 按总刚度 ζ=0.7 设计；测上升时间、超调、调节时间。
  3. 噪声核算：σF=0.1 N 下逐档算 σa=σF/Md；给出滤波时间常数建议。
  4. 内环带宽复核：按 Mmin ≈ Kd/(ω内环/5)² 检查所选 M 是否越过"不能更小线"。
  5. 验收：起步 90% 时间 ≤ 100 ms（拖动场景）、接触超调 ≤ 10%、无高频抖动。
设计决策：为什么先定 M 再配 D？反过来会怎样？

因为 M 有两个硬约束（内环带宽下限、噪声/滤波上限），而 D 是"形状旋钮"没有硬约束，先让 M 落在安全区间，再用 D 把 ζ 调到 0.7–1.0，就是可行设计。反过来先配 D 的话，一旦 M 因为带宽被改大，ζ 会跟着漂（ζ=D/(2√(KM))），全部白配。这和第 037 章"改 K、M 必重算 D"是同一条纪律的另一面。

关键代码与解读

片段 1：起步手感，M 只改变"多久到速度"

import numpy as np

def velocity_startup(m_d, d_d=100.0, f_h=10.0, dt=1e-4, T=0.5):
    """自由拖动（K_d=0）：v(t) = (F/D)(1 - exp(-t/(M/D)))。"""
    v, log = 0.0, []
    for i in range(int(T/dt)):
        t = i*dt
        f = f_h if t >= 0.05 else 0.0
        a = (f - d_d*v) / m_d            # 导纳：M a = F - D v
        v += a*dt
        log.append((t-0.05, v))
    return np.array(log)

print("  M(kg)  tau=M/D(ms)  90%速度时间(ms)  稳态速度(mm/s)")
for m_d in (0.5, 1.0, 2.0, 5.0):
    L = velocity_startup(m_d)
    t, v = L[:, 0], L[:, 1]
    m = t >= 0
    t90 = t[m][np.argmax(v[m] >= 0.09)] * 1000     # 90% * 0.1 m/s
    print(f"  {m_d:4.1f}   {1000*m_d/100:10.0f}   {t90:13.0f}"
          f"   {v[-1]*1000:12.1f}")

解读：四行的稳态速度全是 100.0 mm/s（Dd 决定的），而 90% 时间按 Md/Dd 变化：约 12/23/46/115 ms（理论 2.3τ = 11.5/23/46/115 ms）。这张表把 Md 的职责界定清楚了：它不影响"拖动最终多快"，只影响"手感里那一下的重量"。把这个性质用在工作任务里就是：想让机器人"起步跟手"，减 M；想让它"起步稳"，加 M，都不必动 D。t90 里 0.09 m/s 的阈值写法建议改成由稳态值计算（如 0.9*v_ss），这里为了表格直观用了硬编码。

片段 2：接触力阶跃下的 M 扫描（阻尼按总刚度配）

def contact_step_m(m_d, lam=0.01, k_d=1000.0, k_env=1e4,
                   zeta=0.7, dt=1e-3, T=3.0):
    """λ 固定的导纳力环力阶跃；D 按 (K_d+K_env) 配 ζ。"""
    d_d = 2.0*zeta*np.sqrt((k_d + k_env)*m_d)
    x_e = 0.08
    x = x_e + 5.0/k_env
    x_r, delta, delta_dot, log = x, 0.0, 0.0, []
    for i in range(int(T/dt)):
        t = i*dt
        f_d = 5.0 if t < 1.0 else 15.0
        f = k_env*(x - x_e) if x > x_e else 0.0
        x_r += np.clip(lam*(f_d - f), -0.2, 0.2)*dt
        a = (f - f_d - d_d*delta_dot - k_d*delta) / m_d
        delta_dot += a*dt; delta += delta_dot*dt
        x += (x_r - delta - x) * 0.3
        log.append((t, f))
    return np.array(log)

print("  M(kg)  D_d    上升(ms)  超调(%)  调节(ms)")
for m_d in (0.5, 2.0, 8.0):
    L = contact_step_m(m_d)
    t, f = L[:, 0], L[:, 1]
    i1 = 1000
    r90 = t[i1+np.argmax(f[i1:] >= 14.0)] - 1.0
    over = (f[i1:].max() - 15.0)/15.0*100
    out = np.where(np.abs(f[i1:] - 15.0) > 0.3)[0]
    ts = t[i1+out[-1]+1] - 1.0 if len(out) else 0.0
    d_d = 2.0*0.7*np.sqrt(11000*m_d)
    print(f"  {m_d:4.1f}  {d_d:6.1f}  {1000*r90:7.0f}  {over:7.1f}"
          f"  {1000*ts:8.0f}")

解读：输出为，M=0.5：D=103.8，上升 9 ms、超调 9.1%、调节 42 ms；M=2：D=207.6，11 ms、5.4%、35 ms；M=8：D=415.2，14 ms、2.6%、39 ms。读取方式：（1）上升时间随 M 增大缓慢变差（9→14 ms，因为力环的 ωc 不变、内环变慢）；（2）超调与调节时间在中档 M=2 最优（5.4%、35 ms），M 太小内环振铃多、M 太大调节尾巴长，"0.5–2 kg 区间"的推荐在这里得到实证；（3）稳态终值都是 15.00 N，M 不影响稳态。注意本片段每次循环里 D 都随 M 重算（2ζ√((k_d+k_env)m_d)），这正是第 036 章"小 M 必须配大阻尼"的正确写法：M 从 0.5 到 8，D 跟着从 104 到 415。

片段 3：M 的上下界检查器，把两条硬约束写成一页

def check_m(k_d=800.0, w_inner_hz=30.0, sigma_f=0.1,
            m_d=1.0, d_d=100.0):
    """一页检查：内环带宽下限、噪声加速度、起步手感。"""
    w_inner = 2*np.pi*w_inner_hz
    m_min = k_d / (w_inner/5.0)**2          # 内环带宽约束
    sigma_a = sigma_f / m_d                 # 加速度噪声
    tau = m_d / d_d                         # 起步时间常数
    sigma_v = sigma_f / d_d                 # 低频速度噪声：只与 D 有关
    print(f"K_d={k_d:.0f}, 内环 {w_inner_hz:.0f} Hz:")
    print(f"  M 下限(带宽)    : {m_min:6.2f} kg")
    print(f"  M={m_d:.1f} kg -> sigma_a={sigma_a:5.2f} m/s^2, "
          f"sigma_v(低频)={sigma_v*1000:4.1f} mm/s, 起步 tau={tau*1000:4.1f} ms")

check_m(m_d=0.5, d_d=100.0)     # 小质量：起步快、加速度噪声大
check_m(m_d=2.0, d_d=100.0)     # 中大质量：稳健

解读：两行输出对照，M=0.5：σa=0.20 m/s²、σv=1.0 mm/s、τ=5 ms（且 0.5 kg 已低于带宽下限 0.56 kg，提示必须复核内环）；M=2：σa=0.05 m/s²、σv 不变、τ=20 ms。三个数字各司其职：σa 随 M 反比缩小（它决定速度指令每拍抖多少、进而影响内环激励与 jerk），σv 由 D 决定（干 M 的事），τ 决定起步手感。注意不要用"σx≈σaτ²"这类粗估下结论，位移噪声最终由整个闭环（含滤波与内环）决定，正确做法是加噪仿真或静态漂移实测（第 048 章的噪声专题）。把"下限、噪声、手感"三个数字打印在一页上，参数评审时任何一个候选 M 顶到了哪条约束都一目了然。

常见坑

  • M 取太小追"轻快"，撞上内环带宽：表现为高频低幅振荡，常被误诊为传感器故障或机械共振。修复：按 Mmin ≈ Kd/(ω内环/5)² 复核，K 大时 M 必须跟着大。
  • 换 M 不换 D，然后抱怨超调变了：ζ=D/(2√(KM))，M 翻 4 倍 ζ 减半。修复：任何 M 改动后按目标 ζ 重算 D（第 037 章纪律）。
  • 用"缩放律"时只改一个参数：想"整体缩放"必须 M、K、D 同乘以 a；只改 M 等于换了一个响应形状，别混淆。
  • 把 M 当"稳态旋钮"：稳态速度 F/D、稳态位置误差 F/K 都与 M 无关，想调稳态别动 M（去调 D、K 或前馈）。
  • 小 M 场景不做噪声预算：σa=σF/M 在小 M 下爆炸，经两次积分变成可见的位置抖动，最终"轻快"变成"毛糙"。修复：M≤0.5 kg 时把速度/力滤波时间常数一并加大，或回到 M≥1 kg。

练习与思考

  1. 计算：Dd=120 N·s/m，Md=1.5 kg 时拖动起步时间常数 τ 是多少？要达到"90% 速度 ≤ 30 ms"，Md 最大取多少（D 不变）？★
    提示
    τ=12.5 ms；2.3τ ≤ 30 ms → τ ≤ 13 ms → M ≤ 1.56 kg。两者很接近，说明 30 ms 指标下 M 余量不大。
  2. 推导缩放律：若 M→aM、K→aK、D→aD，证明 ωn 与 ζ 不变、且对任意力输入的响应时间轴不变（幅度如何缩放？）。★★
    提示
    方程两边同乘 a 即得同解（时间轴）；位移幅度不变、加速度与力成反比 1/a 的对应关系可用 a=F/M 验证。
  3. 实验：固定 Kd=2000、内环 25 Hz，用 Mmin 公式计算最小 M，再取 M=0.5×Mmin 跑接触力阶跃，观察高频振荡的出现与消失（把内环一阶时间常数调大代表更慢的伺服）。★★
    提示
    Mmin=2000/(2π×25/5)²≈2.03 kg；取 1.0 kg 且内环变慢后，输出会出现与内环延迟同频段的振荡，这是"带宽不匹配"的教科书图像。
  4. 把片段 2 的 ζ 改为 0.5，重跑三档 M，观察"中档最优"现象是否还成立，并解释超调-调节时间两条曲线的形态。★★
    提示
    ζ 降低后超调整体抬高，但"M 太小振铃多、M 太大尾巴长"的结构不变，两条曲线的最小/最大点位置由内环与力环的相对带宽决定。
  5. 设计题：人机协作拖动机器人搬运 3 kg 工具，要求"起步轻、无抖动、无漂移"。给出 Md、Dd、滤波时间常数与验收指标；说明 3 kg 工具在模型里为什么主要改动 D（提示：工具质量属于"被控对象"，跟虚拟参数 Md 是两笔账）。★★★
    提示
    虚拟参数负责"手感"、工具质量进入真实动力学；建议 M=1、D=80–120、20 Hz 滤波；验收：τ≈10 ms、静置漂移 < 5 mm、无 5–8 Hz 自激（第 029 章）。

小结

  • Md 三个身份：起步时间常数 τ=Md/Dd（只买起步、不买稳态）、加速度噪声 σa=σF/Md、内环带宽约束 ωn=√(Kd/Md)。
  • M 下限公式 Mmin ≈ Kd/(ω内环/5)²；工具级任务推荐 0.5–2 kg；示教拖动可到 0.3 kg 但需滤波与带宽复核。
  • 实验 A：稳态速度与 M 无关（F/D），90% 时间 ∝ M/D；实验 B：接触力阶跃在 M=2 kg 附近综合最优（超调 5.4%、调节 35 ms）。
  • 缩放律：形状不变需 M、K、D 同乘；只改 M 会同时改变 ωn 与 ζ，必须重配 D。
