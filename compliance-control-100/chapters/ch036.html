第二篇 · 参数调节与交互任务

第 036 章：导纳控制下的力阶跃响应

力参考从 5 N 跳到 15 N，导纳控制器的响应由两个频道合成：外环 λ 决定"多快到"，内环阻尼决定"冲多高"。本章用两张实验表把这两个频道分开，并给出"小虚拟质量必须配大阻尼"的量化证据。

  • 主题：力阶跃 / 双时间尺度 / 超调分解
  • 关键公式：ωc≈λKenv，ζeff = Dd/(2√(Md(Kd+Kenv)))
  • 预计学时：50 分钟
  • 前置章节：第 031 章、第 034 章

学习目标

  • 理解导纳力环阶跃响应的"双时间尺度"结构：外环 λ 决定上升时间的量级，内环导纳的动态决定超调的形状。
  • 会区分并分别测量三个指标：上升时间（10–90%）、超调（相对稳态的百分比）、调节时间（±2% 或 ±0.3 N 带内）。
  • 会用两张实验表定量回答"改 λ"与"改 Md/Dd"各改善什么：λ 主要买速度，阻尼主要压超调。
  • 理解有效阻尼比 ζeff = Dd/(2√(Md(Kd+Kenv))) 在"力阶跃"里的角色，并解释为什么小虚拟质量必须配大阻尼。
  • 会把本章的导纳式阶跃响应与第 034 章的弹簧式阶跃响应放在一起对比，说清两种实现超调机制的不同。

背景与动机

第 034 章讲过一种力阶跃的"坏脾气"：当力通过导纳弹簧 δ=(F−Fd)/Kd 施加时，接触系统的有效刚度是 Kd+Kenv，阻尼比崩塌，10 mm 位置步能砸出 76% 的力超调。现实中更常用的却是另一种结构：第 031 章那种"力误差 → 参考速度"的导纳力环，力参考的阶跃不再直接冲击弹簧，转化为"参考位置慢慢逼近"的过程。它的响应长什么样？峰值由谁决定？这一章把它测清楚。

这个问题的工程意义在于：压装、贴合、抛光下刀这些工艺都从"力阶跃"开始，峰值力决定了工件会不会受伤，上升时间决定了节拍。两个指标要能分开调，工程师必须知道"哪个旋钮管哪个指标"，本章的实验设置就是为此设计的：第一张表只扫 λ（看速度频道），第二张表只扫 Md 与阻尼（看形状频道），稳态误差则用于确认外环的零静差特性没有被破坏。

核心原理

1. 双时间尺度：外环管"快"，内环管"形"

回顾结构：外环 vr = λ(Fd−F) 把力误差变成参考位置的运动（等效一阶带宽 ωc ≈ λKenv）；内环是二阶导纳 Mdδ̈+Ddδ̇+Kdδ = F−Fd（第 022 章）。从 Fd 阶跃到 F 的响应，可以近似看成"一阶外环的低通"×"二阶内环的振铃"：

trise ~ 1/ωc = 1/(λKenv)（外环时间尺度）
超调形状 ← ζeff = Dd/(2√(Md(Kd+Kenv)))（内环在接触刚度下的阻尼比）

先说外环。λ 越大，参考位置推进越快，上升时间近似按 trise ∝ 1/λ 缩小；这部分的"迹"是单调的，不产生超调。再说内环：力误差进入 δ 动力学时，δ 的弹簧是 Kd，但它最终要"让位"给环境弹簧 Kenv，两者的并联将 δ 模态的自然频率抬到 √((Kd+Kenv)/Md)，如果 Dd 是按 Kd 定的（第 034 章的老错误），ζeff 会塌缩到 √(Kd/(Kd+Kenv)) 倍，本例 0.30 倍，于是产生"台阶状"超调。导纳力环的峰值因此是"内环振铃的残余"，好消息是它比第 034 章的弹簧式小得多（前者 10–20%，后者 76%），因为力误差先被"速度通道"缓冲了一层。

2. 三个指标的操作定义

  • 上升时间：从阶跃时刻起，力首次到达"初值 + 90% 增量"的时间（10–90% 类似）。对 5→15 N 的阶跃、90% 即 14 N。
  • 超调：(峰值 − 稳态)/稳态 × 100%。注意基准取稳态值；若取"增量"作基准只差一个比例系数，报告里要写明（本章统一用稳态）。
  • 调节时间：力最后一次离开 ±2% 带（15 N 对应 ±0.3 N）之后一直停留在带内。取"最后离开"时刻可以排除穿越型假收敛；用"首次进入"会把穿越型的假收敛也算进来。

还有一个容易被忽略的前提：测量上升时间必须让时间起点对齐"阶跃注入时刻"，而且传感器/滤波延迟要单独记账。1 kHz 控制加 30 Hz 滤波，单是滤波群延迟就 ≈5 ms，占典型上升时间（10 ms 量级）的一半，报告里写"≥ 8 ms"比写"8.0 ms"更诚实。

3. 两种实现，两种超调机制

把第 034 章与本章并排看：

机制弹簧式（第 034 章）速度式（本章）
力的生成位置偏置 δ=(F−Fd)/Kd 直接压弹簧力误差 → 参考速度 → 缓慢逼近
接触瞬态刚度Kd+Kenv（共振暴力）被速度通道缓冲
典型超调ζ 塌缩时 30–76%10–20%，阻尼合规后 <10%
零静差需要外加积分外环天然成立（运动停止 ⇔ 误差为零）

两者之间是取舍，无关对错：弹簧式响应最直接，适合环境已知、阻尼可设计的场景；速度式更温和、鲁棒，是产线接触任务的主力结构。混用时（很多控制器两种都有）要确认当前激活的是哪一支，别用弹簧式的脑子调速度式的参数。

实现思路与设计

实验设置（1 kHz，3 s 时长，Kenv=1×104 N/m，初始力 5 N）：

  1. 激励：t = 1 s 时 Fd: 5 → 15 N 理想阶跃（控制器侧不做参考平滑，保持"最坏情况"口径）。
  2. 实验 A（λ 频道）：Md=1、Kd=1000、Dd=150 固定，λ ∈ {0.002, 0.01, 0.02, 0.05}。
  3. 实验 B（形状频道）：λ=0.01 固定，Md ∈ {0.5, 2, 8}；每个 Md 各跑"按 Kd 临界阻尼"与"按 Kd+Kenv 设计 ζ=0.7"两种阻尼。
  4. 指标：上升时间、超调（相对稳态）、调节时间（±0.3 N）、终值误差。
  5. 验收：上升 ≤ 20 ms、超调 ≤ 10%、终值误差 ≤ 0.05 N。
设计决策：实验 B 为什么同时给出"两种阻尼口径"？直接给一个"最优阻尼"会掩盖什么？

因为工程里"按 Kd 定阻尼"太常见了（很多教材只给 ζ=D/(2√(KM)) 这一条），必须用同一批数据把两种口径的差距摆出来：M=0.5 时超调 21.4% → 9.1%、调节时间 81 → 42 ms，只改阻尼公式，没有牺牲任何别的指标。把这条对照做进验收表，比写十页注意事项都管用。

关键代码与解读

片段 1：导纳力阶跃核心与指标提取

import numpy as np

def admittance_step(lam=0.01, k_d=1000.0, m_d=1.0, d_d=150.0,
                    k_env=1e4, f0=5.0, f1=15.0, dt=1e-3, T=3.0):
    """导纳力环的力阶跃响应：速度式外环 + 二阶导纳内环。"""
    x_e = 0.08
    x = x_e + f0/k_env            # 初始平衡：压入量对应 5N
    x_r, delta, delta_dot = x, 0.0, 0.0
    log = []
    for i in range(int(T/dt)):
        t = i*dt
        f_d = f0 if t < 1.0 else f1
        f = k_env*(x - x_e) if x > x_e else 0.0
        v_r = np.clip(lam*(f_d - f), -0.2, 0.2)   # 外环：速度式 P 律
        x_r += v_r*dt
        a = (f - f_d - d_d*delta_dot - k_d*delta) / m_d
        delta_dot += a*dt; delta += delta_dot*dt
        x += (x_r - delta - x) * 0.3              # 内环伺服近似
        log.append((t, f))
    return np.array(log)

def step_metrics(L, f1=15.0, band=0.3):
    t, f = L[:, 0], L[:, 1]
    i1 = int(1.0/1e-3)                            # 阶跃发生在 1 s
    r10 = t[i1+np.argmax(f[i1:] >= 5 + 0.1*(f1-5))] - 1.0
    r90 = t[i1+np.argmax(f[i1:] >= 5 + 0.9*(f1-5))] - 1.0
    peak = f[i1:].max()
    outside = np.where(np.abs(f[i1:] - f1) > band)[0]
    ts = t[i1+outside[-1]+1] - 1.0 if len(outside) else 0.0
    return (r90-r10)*1000, (peak-f1)/f1*100, ts*1000, f[-1]

解读：结构与第 031 章的恒力环相同，但指标提取独立成函数，这是"一次写函数、四处复用的"实验脚手架。r10/r90 用增量百分比定义（阶跃从 5 N 起跳，90% 增量点是 14 N），比"绝对值的 90%"更符合广义定义；band=0.3 就是 ±2% 的绝对带。注意仿真里内环伺服用一阶近似 (x_r-delta-x)*0.3，真机换成轴控后上升时间会慢 2–5 ms；对比不同控制器时保持同一套仿真假设即可。

片段 2：实验 A，λ 只买速度

print("  lam    上升(ms)  超调(%)  调节(ms)  终值(N)")
for lam in (0.002, 0.01, 0.02, 0.05):
    tr, over, ts, fend = step_metrics(admittance_step(lam=lam))
    print(f"{lam:6.3f}   {tr:7.0f}  {over:7.1f}  {ts:8.0f}  {fend:6.3f}")

解读：输出四行，λ=0.002: 17 ms / 2.3% / 451 ms；0.01: 9 ms / 7.1% / 30 ms；0.02: 6 ms / 10.2% / 22 ms；0.05: 5 ms / 14.5% / 21 ms；终值全部 15.00 N 附近（零静差）。读表的关键有三层：（1）λ 增大时上升时间持续改善（速度频道生效）；（2）超调同步增大，更快的参考推进把内环"拽"出了更多振铃；（3）λ=0.002 那一行的调节时间 451 ms 格外扎眼，超调只有 2.3%，但"慢外环"的收敛尾巴很长，力在 ±0.3 N 带外磨了近半秒。所以增益不能一味保守也不能一味激进：0.01→0.05 只省 4 ms 上升时间，却把超调放大两倍；若工艺对峰值敏感，应停在 0.01–0.02 档，用参考斜坡化（第 035 章）取代增益。

片段 3：实验 B，阻尼口径决定超调

def shape_experiment(m_d, design="total", k_d=1000.0, k_env=1e4, zeta=0.7):
    """两种阻尼口径: 'kd' 按 K_d 临界; 'total' 按 K_d+K_env 设计 ζ。"""
    if design == "kd":
        d_d = 2.0*np.sqrt(k_d*m_d)                    # 只认虚拟刚度
    else:
        d_d = 2.0*zeta*np.sqrt((k_d + k_env)*m_d)     # 认总刚度（第 034 章规则）
    tr, over, ts, fend = step_metrics(
        admittance_step(m_d=m_d, d_d=d_d))
    return d_d, tr, over, ts

print("  M_d   阻尼口径      D_d    上升(ms)  超调(%)  调节(ms)")
for m_d in (0.5, 2.0, 8.0):
    for design in ("kd", "total"):
        d_d, tr, over, ts = shape_experiment(m_d, design)
        tag = "按K_d" if design == "kd" else "按总刚度"
        print(f"{m_d:5.1f}   {tag:6s}  {d_d:7.1f}  {tr:7.0f}"
              f"  {over:7.1f}  {ts:7.0f}")

解读：六行输出（本课环境实测）：M=0.5 按 Kd → 21.4% 超调 / 81 ms 调节；同 Md 按总刚度 → 9.1% / 42 ms。M=2：10.8%/70 ms → 5.4%/35 ms。M=8 按总刚度 → 2.6%/39 ms。规律非常干净：（1）阻尼口径一换，超调直接腰斩、调节时间也大幅缩短（大阻尼让内环振铃更快耗尽）；（2）Md 增大让超调继续下降（0.5→8 kg 时 21.4%→4.3% 按旧口径、9.1%→2.6% 按新口径），代价是上升时间从 8–9 ms 变慢到 14 ms。所以"小 Md 灵敏、大 Md 稳重"的记忆升级为：小 Md 可以被大阻尼救回来，但不能被 Kd 口径的阻尼救回，这正是第 038 章"虚拟质量调节"要展开的主题。

常见坑

  • 超调基准混用：有人用"相对阶跃增量（10 N）"、有人用"相对稳态（15 N）"，同一份数据差 1.5 倍。修复：报告里写清口径，本章统一"相对稳态"。
  • 测到的是滤波后的峰：30 Hz 低通把 8–15 ms 的峰形削平，超调被低估三分之一以上。修复：瞬态分析用 ≥500 Hz 的原始力；控制回路再单独滤波。
  • 按 Kd 给阻尼还承诺"<10% 超调"：小 Md 下物理不可能（21% 起步）。修复：阻尼口径切到总刚度，再把 Md 往 1–2 kg 以上放。
  • 只测一次、不复核终值：某些参数组合（大 λ + 小 D）在 3 s 内看着收敛，但 ±0.3 N 带外还有慢漂移。修复：调节时间用"最后离开"判据，并核对 10 s 后的终值误差。
  • 拿弹簧式的参数直觉套速度式：弹簧式的 76% 超调经验让人把 Dd 加得过大，速度式反而变得迟钝、上升时间翻倍。修复：先确认实现结构，再套对应的超调机制表。

练习与思考

  1. 计算题：λ=0.01、Kenv=1×104 时，外环时间常数 1/(λKenv) 是多少？与实验 A 测得的 9 ms 上升时间对比，解释"If 内环够快，上升时间 ≈ 该时间常数"的近似。★
    提示
    1/(0.01×1e4) = 10 ms；实测 9 ms 基本吻合，差异来自内环不是理想快速。
  2. 用 ζeff = Dd/(2√(Md(Kd+Kenv))) 分别算 M=0.5 两种阻尼口径的 ζeff（D=44.7 与 103.8），并解释为什么超调从 21.4% 落到 9.1%。★★
    提示
    ζeff：44.7/(2√5500)=0.30；103.8/(2√5500)=0.70。查超调公式 37% vs 4.6%（实测受外环耦合影响，与纯二阶公式有出入）。
  3. 实验：λ=0.02 固定，把 Dd 从 150 加到 300，预测上升时间、超调、调节时间各自怎么变，再跑片段跑验证（提示：外环时间尺度不变）。★★
    提示
    上升时间基本不变（由 λ 主导）；超调下降、调节时间缩短（内环振铃快速耗散）；终值不变。
  4. 把片段 2 的 Fd 阶跃从 5→15 改为 5→25（增量加倍），记录三个指标，验证"超调百分比不变、绝对峰值随增量线性放大"的一致缩放律。★★
    提示
    线性系统在理想内环下一切按比例缩放；若实测百分比漂移，说明碰到了非线性环节（限幅、滤波、伺服饱和）。
  5. 设计题：给"力阶跃 0→20 N、峰值 ≤22 N、上升 ≤15 ms、Kenv 未知（1e3–1e5）"设计参数：λ 给一个、Md/Dd 给一组，并用最坏 Kenv 核算 ζeff。说明为什么 λ 要按软环境取值、阻尼要按硬环境取值。★★★
    提示
    λ 按软环境（ωc 最小）保上升时间；D 按硬环境（ζeff 最小）保超调；两侧分别卡口径是本章"双频道"设计的直接应用。

小结

  • 导纳力环的力阶跃响应是双时间尺度合成：外环 λ 决定上升/调节时间的量级，内环阻尼决定超调形状；稳态零静差由外环结构保证。
  • 实验 A：λ 0.002→0.05，上升 17→5 ms，但超调 2.3→14.5% 同步增长，λ 主要买速度，不能买"平顺"。
  • 实验 B：阻尼口径从"按 Kd"切到"按 Kd+Kenv"，超调 21.4→9.1%（M=0.5）、10.8→5.4%（M=2）；小 Md 必须配大阻尼。
  • 与第 034 章对比：弹簧式超调可达 30–76%（直接冲击 Kd+Kenv 弹簧），速度式仅 10–20% 且可压到 10% 以下，结构决定了超调的"上限"。指标口径（上升/超调/调节）要写清定义再比较。
  • 下一章聚焦一个参数：阻抗控制中的阻尼比调节，把 ζ 从 0.2 扫到 1.0，用公式与实验同时看清"超调-速度-噪声"的三方账。
