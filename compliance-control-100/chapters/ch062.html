第 062 章：阻抗控制中的奇异扰动抑制

把阻抗控制系统显式拆成"慢"的阻抗外环与"快"的扰动内环：用奇异摄动（singular perturbation）理解时间尺度分离为什么让扰动抑制变得可设计、闭环误差为什么是 O(ε)。

  • 主题：奇异摄动 / 双时间尺度扰动抑制
  • 关键公式：ẋ = f(x, z)，εż = g(x, z)，ε→0 得准稳态 z = h(x)
  • 预计学时：55 分钟
  • 前置章节：第 061 章

学习目标

  • 理解"奇异摄动"这个名词的确切含义：ε 乘在最高阶导数上时，"令 ε = 0"会让系统降阶，这种突变才是"奇异"的来历。
  • 会把"阻抗外环 + 快内环/扰动观测器"写成标准奇异摄动形式，并区分慢变量与快变量各是谁。
  • 理解 Tikhonov 定理给出的两条结论，准稳态解 + 边界层修正，以及 O(ε) 误差界的物理含义。
  • 掌握扰动抑制的频段分工：低频偏置、中频摩擦、高频噪声分别该由什么机制负责，为什么高增益不能无限提高。
  • 会实现一阶快子系统（扰动估计器），并记住离散稳定性硬约束 dt 与 2ε 的关系。
  • 会通过扫描 ε 定量权衡"扰动抑制带宽"与"噪声放大"。

背景与动机

前 61 章我们把阻抗方程写得很漂亮，但真机上性能的瓶颈通常不在外环公式，而在扰动：关节摩擦、负载变化、电机纹波、传动柔性、接触冲击。这些量要么难建模，要么时变，逐项辨识补偿的工程成本极高。

本章换一个思路：与其"精确认识扰动"，不如"用更快的回路在扰动影响外环之前把它压掉"。奇异摄动（singular perturbation）理论恰好为这条直觉提供了严格框架，只要内环比外环快得多（时间尺度分离，ε 足够小），整个闭环的行为就以 O(ε) 逼近你设计的阻抗行为，残余误差有界且可预测。它提供的是一套"扰动抑制放在哪个频段、由谁负责"的顶层设计语言，其价值远超又一项调参技巧，下一章的低频抑制正是它的另一半拼图。

核心原理

1. "奇异"两个字从哪来

常规的"正则摄动"是参数微扰：方程阶数不变，解随小参数连续变化。奇异摄动不同，小参数 ε 乘在最高阶导数上：

ẋ = f(x, z, ε)，  ε ż = g(x, z, ε) x ∈ Rn：慢状态；z ∈ Rm：快状态；ε：时间尺度之比，秒

当 ε → 0 时，第二个微分方程退化成代数方程 0 = g(x, z, 0)，它的解 z = h(x) 叫准稳态（quasi-steady state）。系统的动态阶数从 n+m 掉到 n，阶数会"跳变"，所以是奇异的。物理图像：极快的子系统"来不及被外环看见"，外环看到的只是它的平衡值；而快子系统在初始瞬间的过渡过程，则被甩到伸缩时间 τ = t/ε 上单独描述，称为边界层（boundary layer）。

2. 阻抗控制系统怎么写成这个形式

在阻抗控制里，时间尺度天然有两层：外环阻抗的自然频率由 ωn = √(Kd/Md) 决定（典型 10–50 rad/s），内环（力矩环、速度环、扰动观测器）工作在 100–1000 rad/s。取 ε = ωslow/ωfast，整个系统就是双时间尺度的。一个最简洁的写法是一个一阶扰动估计器作为快子系统：

慢：Mdẍ + Ddẋ + Kd(x−xd) = −(Fext − ŵ)
快：ε ŵ̇ = −ŵ + (Fext − Fmodel) ŵ：扰动估计（N）；Fmodel：模型能预测的那部分力；ε 单位秒

先看快子系统自己的解。对一个常数扰动 w，εŵ̇ = −ŵ + w 的解是 ŵ(t) = w + (ŵ(0)−w)e−t/ε：它以时间常数 ε 指数逼近真值。ε 越小，估计越快，这就是"快"的量化含义：ε 就是快子系统的带宽倒数，抑制带宽约等于 1/(2πε)。再看慢方程：把 ŵ ≈ w 代进去，扰动被 −ŵ 前馈抵消，外环回到纯阻抗 Mdẍ + Ddẋ + Kd(x−xd) = −(Fext − w) ，扰动对消，这就是复合控制（composite control）的全部思想。

3. Tikhonov 定理：两条结论、一个误差界

非线性情形下这个"先抵消再审"的推理由 Tikhonov 定理保证，工程上记住三句话即可：

  1. 准稳态：z 会迅速贴到 h(x)，慢系统近似按 ẋ = f(x, h(x), 0) 演化；
  2. 边界层修正：z(t) = h(x(t)) + z̃(t/ε)，修正在 τ = t/ε 刻度上指数衰减，初始冲击靠它描述；
  3. 误差界：当两个子系统各自稳定、耦合项有界时，存在 ε0，使 ε 小于 ε0 后闭环状态与简化系统的差始终 ≤ c·ε（c 是常数）。

工程直觉：O(ε) 意味着"要更快"没有免费的午餐，精度线性地买在带宽上。把 ε 减半，抑制带宽翻倍，但下面会看到噪声增益也在涨。

4. 频段分工表：谁负责哪一段扰动

扰动是个宽频概念，不同频段该用完全不同的手段，这正是本章与下一章（063，低频）成对出现的原因：

扰动频段典型来源抑制机制设计要点
< 0.5 Hz负载变化、重力补偿残差、传感器偏置参数自适应 / 积分（063 展开）带宽越低越安全，防 windup
0.5–50 Hz关节摩擦、未建模动力学、接触过渡快内环（本章 ε 层）ε 取外环时间常数的 1/5–1/10
> 200 Hz电机纹波、测力噪声、结构共振物理滤波、机械阻尼，控制器不碰硬刚等于把噪声注入执行器

为什么高频不归控制器管？两条硬约束：采样定理给出可观测上限约 fs/5（1 kHz 采样约 200 Hz），再往上控制器只会把混叠噪声和相位滞后引入外环；而且高增益估计器对白噪声的传递增益趋近 1/ε，ε 减小一倍，执行器上的噪声抖动翻一倍。所以扰动的"最后一段"必须交给物理世界解决，控制器的任务是把中频段兜住。

实现思路与设计

落地流程一共六步，每步都有明确的数字依据（以 Kd = 500 N/m、Md = 1 kg、dt = 1 ms 为例）：

  1. 定外环：Kd = 500 N/m、Md = 1 kg、Dd = 2√(KdMd) ≈ 44.7 N·s/m，外环自然频率 ωn = √500 ≈ 22.4 rad/s，外环时间常数约 45 ms。
  2. 选 ε：先记一条经验规则，快子系统至少要快 5–10 倍，即 ε ≤ 45/5 = 9 ms，取 ε = 2 ms（对应抑制带宽约 80 Hz）。
  3. 检查离散化：一阶显式欧拉的递推是 ŵ ← ŵ + (dt/ε)(w − ŵ)，收敛条件是 |1 − dt/ε| 落在单位圆内，即 dt 必须小于 2ε；工程上把递推系数 dt/ε 限在 0.5 以内，取 dt ≤ ε/2（相对硬边界留 4 倍裕度）。这意味着采样周期决定了 ε 的下界：1 kHz 采样时 ε 最小约 2 ms，这是硬件给扰动抑制划的天花板。
  4. 接传感器：Fmeas 先做 1–2 ms 的模拟低通（硬件或软件），再进估计器；否则 ε 一减小，测力噪声直接放大成命令抖动。
  5. 复合前馈：外环方程里用减法引入 ŵ（写成加法方向就反了）；上电把 ŵ 初始化为 0（宁可从零慢慢学到真值，也不要一开始就带着错误初值冲击接触）。
  6. 扫描验证：ε ∈ {1, 2, 5, 10} ms 各跑一次阶跃接触，记录抑制时间、稳态误差、命令抖动，再定最终值。
设计决策：为什么内环用"观测器"？"逆动力学前馈"差在哪？

逆动力学前馈要求模型精确，而模型误差恰恰就是我们要抑制的扰动，逻辑上循环。观测器只要求"快"：它不关心扰动是什么，只把测量力与模型预测力的残差低通成估计值。快，永远能做到；准，不一定。能用时间尺度换精度的场合，永远优先换。

关键代码与解读

片段 1：一阶快子系统（扰动估计器）与离散稳定条件

import numpy as np

class FastDisturbanceObserver:
    """快子系统：varepsilon * d(w_hat)/dt = -w_hat + w_meas。
    epsilon 同时决定两件事：估计带宽 1/(2*pi*eps) 与离散稳定边界。"""
    def __init__(self, eps=2e-3, dt=1e-3):
        self.eps, self.dt = eps, dt
        self.w_hat = 0.0      # 快状态：扰动估计值，单位 N
        # 显式欧拉递推 w_hat += (dt/eps)*(-w_hat + w) 的收敛条件是 dt < 2*eps，
        # 这是数学上的硬约束：违背它，估计器自己变成振荡源，越"快"越炸
        assert dt < 2.0 * self.eps, "dt 过大：快子系统离散化将发散"

    def update(self, w_meas):
        # 之所以写成"往测量值方向挪一小步"（-w_hat + w_meas），不直接赋值：
        # 直接赋值等价于 eps=0：没有滞后看似完美，却把测力噪声原样注入外环微分项
        self.w_hat += (self.dt / self.eps) * (-self.w_hat + w_meas)
        return self.w_hat

解读：类里只有一行真正的算法，但三处设计都有"为什么"。第一，assert 把 dt < 2*eps 变成启动即检查的契约，这条约束会被外环的"我想再快一点"反复挑战，写在代码里比写在文档里可靠。第二，递推写成"增量式"，不用闭式解 exp 形式，是为了保持与控制周期同步、便于在线改 ε。第三，返回的是估计值本身，不返回补偿后的力：补偿放在调用方（片段 2），因为"扰动"在不同任务里的定义不同（有时要包含工具重力，有时不包含）。

片段 2：复合控制，慢外环 + 快估计前馈

class CompositeImpedance:
    """慢外环：标准阻抗动力学；快子系统给的前馈项抵消扰动。"""
    def __init__(self, m_d=1.0, k_d=500.0, eps=2e-3, dt=1e-3):
        self.m_d, self.k_d = m_d, k_d
        self.d_d = 2.0 * np.sqrt(k_d * m_d)     # 临界阻尼初值，先保证不振荡
        self.obs = FastDisturbanceObserver(eps, dt)
        self.v_cmd, self.x_cmd = 0.0, 0.0

    def step(self, x, v, x_d, v_d, a_d, f_meas, f_model):
        # 快子系统：残差 = 测量力 - 模型预测力，把残差当扰动去估计
        w_hat = self.obs.update(f_meas - f_model)
        # 慢外环：注意 f_meas - w_hat 是"扣掉估计扰动后的净外力"，
        # 它进入阻抗方程的方式与真外力相同，符号写反会变成正反馈发散
        a_cmd = a_d - (self.d_d * (v - v_d) + self.k_d * (x - x_d)
                       + f_meas - w_hat) / self.m_d
        # 半隐式欧拉：先积速度再积位置，与 001 章一致，能量性质更好
        self.v_cmd += a_cmd * self.dt
        self.x_cmd += self.v_cmd * self.dt
        return self.x_cmd, w_hat

解读：step 的输入分成"外环该看到的量"（x、v、x_d）与"快子系统该处理的量"（f_meas、f_model）。这种划分本身就是时间尺度分离在接口上的体现：外环永远不知道 ε 存在，它只看到被净化过的外力。若把 f_meas - w_hat 误写成 f_meas + w_hat，理论上闭环变成"扰动被放大一倍"，实际表现是接触后力缓慢爬升、越压越紧。注意 w_hat 同时被返回，方便在示波器上观察估计器有没有学歪，调试阶段这个信号比位置曲线更能说明问题。

片段 3：扫 ε，抑制速度与噪声放大的定量权衡

rng = np.random.default_rng(0)
dt = 1e-3

def sim(eps, sec=2.0):
    obs = FastDisturbanceObserver(eps=eps, dt=dt)
    n = int(sec / dt)
    w = np.zeros(n); w[n // 4:] = 3.0           # 0.5 s 时突加 3 N 负载
    noise = rng.normal(0.0, 0.1, n)             # 0.1 N 有效值的测力噪声
    est = np.zeros(n)
    for k in range(n):
        est[k] = obs.update(w[k] + noise[k])
    # 抑制误差：瞬态后估计值离真值 3 N 的差距；抖动：稳态段的波动标准差
    err = abs(np.mean(est[-n // 10:]) - 3.0)
    jitter = np.std(est[-n // 10:])
    return err, jitter

for eps in [1e-3, 2e-3, 5e-3, 10e-3]:
    err, jitter = sim(eps)
    print(f"eps={eps*1e3:4.0f} ms  稳态误差={err:5.2f} N  噪声抖动={jitter:5.3f} N")

解读：这段仿真把本章的核心权衡变成四个数字。ε = 1 ms 时估计器几乎瞬时跟上，噪声抖动也最大（约 0.1 N 量级、与测力噪声同阶，因为增益 dt/ε = 1 已经逼近"直通"）；ε = 10 ms 时抖动小到 0.03 N 以下，但阶跃后要等约 30 ms 才收敛。选 ε 的原则是取"抑制时间短于外环时间常数（约 45 ms）、同时抖动低于力控制分辨率（如 0.5 N）"的最省采样值，本例中 2–5 ms 都合格，取 2 ms。你会注意到 ε = 10 ms 时抖动里仍有一部分来自 3 N 阶跃后尚未收敛的瞬态，这正是"扫描要看两行数字、不能只看一行"的原因。

常见坑

  • dt 与 ε 比例失守：为了"更快"把 ε 压到 dt/2 以下，估计器递推系数 dt/ε > 2，数值上直接振荡发散，现象是接触后 100–500 Hz 的刺耳嗡鸣。修复：把递推系数压回 dt/ε ≤ 0.5（即 dt ≤ ε/2），硬件频率不够就先换硬件、再谈 ε。
  • 高增益放大测力噪声：ε 减小一倍，执行器上的噪声抖动约翻一倍。0.1 N 的传感器噪声经 ε = 1 ms 的估计器进入外环微分项，等效到加速度上是 m/s² 级抖动。修复：进估计器前先做模拟低通或滑动平均，代价是牺牲一点相位。
  • 时间尺度分离不足：ε 只有外环时间常数的 1–2 倍时，Tikhonov 的前提不存在，快慢模态互相激励，表现为 5–20 Hz 的"拍振"，幅度时大时小，很像机械共振。修复：先把带宽比拉到 5 倍以上，再逐格微调。
  • 积分器与估计器叠满：低频积分（063）与中频观测器同时以最大增益工作，低频段相位滞后叠加超过 180°，稳态很准、动态一碰就振。修复：明确分工，同一频段只保留一种机制。
  • 估计器初值不当：接触瞬间以真实冲击力初始化 ŵ，前馈项会在第一个控制周期把冲击"预先抵消"得过头。修复：ŵ 从 0 起步，宁可让学习过程吃掉前 5 ms。

练习与思考

  1. 对一阶快子系统 εż = −z + w（w 为常数），写出它的解析解，并区分"准稳态项"与"边界层项"。说明为什么说快子系统的全部信息都是 O(ε) 量级的。 ★
    提示
    解是 z(t) = w + (z0−w)e−t/ε；前一项与 ε 无关，后一项在 τ = t/ε 刻度上衰减，只在初始瞬间量级不为零。
  2. 运行片段 3，把噪声从 0.1 N 提到 0.5 N，重新扫 ε。你平台的"最佳 ε"向哪边移动？用一句话解释为什么。 ★★
    提示
    抖动随 ε 减小而增大，噪声变大后，能满足"抖动指标"的 ε 下界被抬高，最佳值变大（更慢但更稳）。
  3. 推导显式欧拉递推的稳定条件 dt < 2ε。如果把快子系统改成隐式欧拉（用 k+1 时刻的 ŵ），稳定条件变成什么？工程上为什么仍然不主张用极小的 ε？ ★★
    提示
    隐式欧拉无条件稳定，但会引入额外相位滞后；且 ε 的物理下界由采样周期与噪声决定，数值稳定性只是必要条件。
  4. 实验设计：外环刚度从 500 提到 5000 N/m，ωn 变成约 70.7 rad/s。为保持同样的时间尺度分离比，ε 应取多少？此时如果控制周期还是 1 ms，离散裕度是否还够？给出数字并讨论后果。 ★★★
    提示
    分离比不变要求 ε 同比例缩小，旧值 2 ms 对应新值约 0.6 ms，将低于 dt = 1 ms 的可行域，结论是"外环更硬时，必须提高采样率，或接受分离比下降"。
  5. 思考题：为什么 200 Hz 以上的扰动"交给物理"更划算？用采样定理、噪声增益、执行器带宽三个角度各写一句。 ★★
    提示
    采样定理限制可观测与重建；高增益把噪声搬进执行器；执行器本身也带不动那么快的动作，三者都指向"控制器不该承担这一段"。

小结

  • 奇异摄动的标准形式 ẋ = f(x,z)、εż = g(x,z)：ε 出现在最高阶导数上，ε→0 时系统降阶，故名"奇异"。
  • 两条支柱：准稳态 z = h(x)（外环只看到快系统的平衡值）与边界层修正（初始瞬间在 τ = t/ε 上展开）；闭环误差 O(ε)。
  • 阻抗控制的双时间尺度：外环阻抗（10–50 rad/s）与内环观测器（100–1000 rad/s），ε 就是两者之比，抑制带宽约 1/(2πε)。
  • 频段分工：<0.5 Hz 归自适应/积分，0.5–50 Hz 归本章的 ε 层，>200 Hz 归物理滤波；高增益的代价是噪声与离散步长。
