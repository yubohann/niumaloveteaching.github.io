第二篇 · 参数调节与交互任务

第 027 章：导纳控制中的加速度限制

速度限住了"走多快"，加速度决定"多久进入这个速度"。力尖峰除以小虚拟质量会得到惊人的加速度，本章讲清限加速度如何改变等效惯量、为什么还要限制加加速度（jerk），以及三层限幅的正确顺序。

  • 主题：导纳控制 / 动态平滑与安全
  • 关键公式：a = F/Md，acmd = clip(a, ±amax)，Meff = F/amax
  • 预计学时：45 分钟
  • 前置章节：第 025 章、第 026 章

学习目标

  • 理解加速度在导纳控制里的地位：它是虚拟惯性方程的输出，也是激发机械共振、冲击与噪声的"激励源"。
  • 会计算力尖峰下的裸加速度 a = F/Md，并解释为什么"小虚拟质量 + 大力尖峰"会让加速度轻松超过 10 m/s²。
  • 掌握限加速度的物理含义：饱和期间等效惯量 Meff = F/amax 变大，机器人"表现得像更重"，这是可控的降级。
  • 理解 jerk（加加速度）限制的作用：消除加速度台阶、压低高频激励；会写速率限制 + 一阶平滑两层结构。
  • 能按"加速度限幅 → 数值积分 → 速度限幅"的正确顺序组织代码，并让所有限幅状态自洽。

背景与动机

导纳控制解出的加速度是"虚拟惯性"上的牛顿第二定律：a = F/Md。把 Md 调小会得到灵敏、跟手的手感（拖动示教很喜欢），但代价是加速度对力异常极其敏感：Md = 0.5 kg 时，一次 40 N 的碰撞对应 80 m/s²，8 个重力加速度，等效于让一个 0.5 kg 的实心铁块以 8g 加速；这远超大多数协作机器人的关节加速度能力，也远超任何机械结构愿意承受的冲击。

更微妙的是，加速度的突变（jerk，加加速度）比加速度本身更"吵"：从 0 跳到 5 m/s² 的台阶，在 1 kHz 采样下相当于给系统注入宽带高频能量，会激励挠性关节、谐波减速器的扭转振荡、乃至工具安装的微振，接触任务里，这些振动会直接调制接触力。第 025 章限了速度，但限速管不住"0 到 vmax 之间怎么过渡"；这一章补上加速度与 jerk 两层，让导纳输出的整条轨迹（位置、速度、加速度）都落在机械可承受的包线内。

核心原理

1. 裸加速度从哪来、能有多大

一维虚拟惯性方程（阻尼与刚度项先忽略，看最坏情况）给出：

a = (Fext − Fd) / Md F：外力（N）；Md：虚拟质量（kg）；a 单位 m/s²。1 g = 9.8 m/s² 可作量级参照

Md = 0.5 kg、常见人工力 10 N 时 a = 20 m/s²（已 2g）；力传感尖峰或瞬时碰撞 40 N 时 a = 80 m/s²。工业协作臂的典型笛卡尔加速度能力约 5–15 m/s²，也就是说小虚拟质量下，正常操作都能触到硬件加速度能力的边缘。反过来，取 Md = 5 kg，40 N 也只有 8 m/s²，安全，但 10 N 常用力时加速度 2 m/s²、起步变慢，"手感变重"。Md 的两难与第 025 章 Dd 的两难同构：线性映射无法同时满足"灵敏"和"抗尖峰"，限加速度就是那个非线性闸门。

2. 限加速度改变了什么：等效惯量的概念

设 amax 为上限。饱和期间加速度被钳住，力与加速度的比值看起来像一个更大的质量：

Meff = F / amax（饱和期间的有效惯量） 例：F = 40 N、amax = 5 m/s² → Meff = 8 kg，即使设计值 Md = 0.5 kg

这解释了限幅期间的行为图景：机器人并未"失灵"，只是临时变成一个更重的物体，起步钝、惯性大、冲击小。与第 024、025 章相同的审查逻辑：限幅只削减能量注入速率（加速度被钳住 ⇒ 动能增长速率受限），不会制造正反馈；真正的副作用是波形出现"弯折"（加速度平台）与退出饱和时的过冲（速度已经不小、加速度还蓄着势）。纪律性结论：限加速度让系统从"设计的惯量"平滑过渡到"防护的惯量"，参数设计时心里要有 Meff 这个量。

3. jerk 限制：把台阶磨成斜坡

加速度限幅本身是一个硬钳位：进入和退出饱和时，a 从一个值跳到另一个值。加速度台阶的频谱是宽带的一一你可以把它理解成"敲一下"：能量在所有频率上都有分布，而机械的挠性模态（谐波减速器 20–60 Hz、臂杆弯曲 几十赫兹）会把某些频率"收下"并振荡起来。jerk（da/dt，单位 m/s³）限制把这些台阶变成斜率有限的斜坡：

|acmd(t) − acmd(t−Δt)| ≤ jmax · Δt jmax：加加速度上限，m/s³。人手交互场景取 100–500；工业节拍场景 500–2000

数量级感受：若 jmax = 500 m/s³，达到 a = 5 m/s² 需要 10 ms，这个斜坡时间恰好把激励能量从"宽带敲击"集中到 25 Hz 以下，避开了大部分结构模态的"敏感带"。jerk 限制还有一个离散化上的好处：它把每拍的加速度增量限制在 jmaxΔt（动采样 1 ms、j=500 时每拍只变 0.5 m/s²），速度与位置指令逐拍变化都是小幅的，下游插补器、滤波器不会因为大台阶产生振铃。

4. 三层限幅的顺序与状态自洽

完整的导纳输出链：

araw = (F − Ddv − KdΔx)/Md → [jerk 限速] → [a 限幅] → v ← v + a·Δt → [v 限幅] → x ← x + v·Δt

为什么是这个顺序？（1）a 是动力学产生量、jerk/a 限制是"塑形"，都在积分之前；（2）速度限幅放在积分之后、位置积分之前，继续沿用第 025 章"限速先于积分"的原则，积分用的永远是实际能走的速度；（3）三层都只修改"即将用于积分的那一拍值"，没有独立的外部状态，所以整体天然自洽：任何时刻 x 的导数就是链里最终通过的速度，v 的导数（在可导意义上）就是链里最终通过的加速度。反例警告：如果先对 x 限幅（例如"步长不超 1 mm"），饱和时会丢行程，且与 v 的记录不一致，退出时速度对不上、产生跳动。

实现思路与设计

  1. 按场景定 amax：人机协作/示教 2–5 m/s²（人体舒适与碰撞安全）；工业接触任务 5–10 m/s²；高速搬运不属于本课程范畴。取执行器能力（如 10 m/s²）的 50–70% 作为软限，留余量给重力方向的不对称。
  2. 按场景定 jmax：人手交互 100–500 m/s³；自动装配 300–800；一般来说 jmax ≥ amax/(0.01–0.03 s)，即"ramp 时间 10–30 ms"。
  3. Md 与限幅联合定：先按手感选 Md（拖动 0.5–1 kg），再按下式反查最坏加速度是否会打满：aworst = Fworst/Md；若 aworst ≫ amax，接受"尖峰被限速保护"的设计，但要在监视里记录饱和率（持续饱和说明 Md 太小或外力异常）。
  4. 抗噪设计：加速度层对力噪声最敏感（a 噪声 = σF/Md）。0.1 N 噪声、Md=0.5 kg 时 a 噪声 0.2 m/s²，影响不大；但若 Md 再小一个数量级，就要给力信号加 20–50 Hz 低通后再进入本层（详见第 038 章"虚拟质量调节"）。
  5. 监视指标：加速度饱和率、最大 jerk（用 (a[k]−a[k−1])/Δt 的滑窗最大值估计）、amax 利用率。三者任一持续饱和，就回头调 Md/限幅/滤波。
设计决策：为什么 jerk 限制通常只上界、不"超前规划"？

工业里的 S 型轨迹发生器会超前规划 jerk，因为整条轨迹已知。导纳控制的轨迹是"力驱动"的、实时生成的，无法预知下一步会撞到什么，所以只能做"逐拍钳位"。逐拍钳位已经消掉了大部分高频能量；如果实测仍有振铃，再加一层一阶低通滤波（10–30 Hz）兜底即可，不必上复杂的在线规划器。

关键代码与解读

片段 1：三层限幅导纳核心（jerk → a → v）

import numpy as np

class AccelLimitedAdmittance:
    """导纳控制输出级：jerk/a/v 三层塑形，状态自洽。"""
    def __init__(self, m_d=0.5, d_d=80.0, dt=1e-3,
                 a_max=5.0, j_max=500.0, v_max=0.15):
        self.m_d, self.d_d, self.dt = m_d, d_d, dt
        self.a_max, self.j_max, self.v_max = a_max, j_max, v_max
        self.v = np.zeros(3)          # 速度状态
        self.x = np.zeros(3)          # 位置状态
        self.a_prev = np.zeros(3)     # 上一拍加速度：jerk 限制需要
        self.sat_a = 0.0              # 加速度饱和计时（诊断用）

    def step(self, f_ext):
        # 1) 原始加速度：惯性主导的导纳方程
        a_raw = (f_ext - self.d_d * self.v) / self.m_d
        # 2) jerk 限制：每拍的加速度增量不超过 j_max*dt（把台阶磨成斜坡）
        da = np.clip(a_raw - self.a_prev, -self.j_max*self.dt,
                     self.j_max*self.dt)
        a = self.a_prev + da
        # 3) 加速度限幅：方向保持的范数缩放（三维一致处理）
        na = np.linalg.norm(a)
        if na > self.a_max:
            a = a * (self.a_max / na)
            self.sat_a += self.dt
        else:
            self.sat_a = max(0.0, self.sat_a - self.dt)
        self.a_prev = a
        # 4) 积分速度，再做速度限幅（沿用第 025 章：先限速、后积分位置）
        v = self.v + a * self.dt
        nv = np.linalg.norm(v)
        if nv > self.v_max:
            v = v * (self.v_max / nv)
        self.v = v
        self.x += self.v * self.dt
        return self.x.copy()

解读：一维写法展开成三维，核心仍是四步链。a_prev 是 jerk 限制必需的记忆量，没有它就只能做硬钳位。da 的 clip 是逐轴的，在逐拍层面这样做没问题吗？注意：jerk 逐轴钳位与"方向保持"的加速度范数缩放是两个不同层面的约束：jerk 是塑形（不改变最终稳态方向）、amax 是安全（必须方向保持），分工明确。第 3 步的范数缩放只在超限时改变幅值不改变方向；第 4 步继续积分限速后的 v，保证位置与实际一致。整个类没有隐藏积分器，任何时刻从 (a, v, x) 都能复现下一拍。

片段 2：力尖峰对比，无限幅 vs 限幅的完整波形指标

def spike_experiment(a_max, j_max, m_d=0.5, d_d=80.0, dt=1e-3):
    """80 N 尖峰 0.05 s：记录加速度、速度、位置与最大 jerk。"""
    ctrl = AccelLimitedAdmittance(m_d, d_d, dt, a_max, j_max)
    a_peak, v_peak, x_peak, jerk_peak = 0.0, 0.0, 0.0, 0.0
    a_last = 0.0
    for i in range(1000):
        f = np.array([80.0, 0.0, 0.0]) if i*dt < 0.05 else np.zeros(3)
        x = ctrl.step(f)
        jerk_peak = max(jerk_peak, np.linalg.norm(ctrl.a_prev - a_last)/dt)
        a_last = ctrl.a_prev.copy()
        a_peak = max(a_peak, np.linalg.norm(ctrl.a_prev))
        v_peak = max(v_peak, np.linalg.norm(ctrl.v))
        x_peak = max(x_peak, np.linalg.norm(x))
    return a_peak, v_peak, x_peak, jerk_peak

for am, jm in ((1e3, 1e6), (5.0, 500.0)):
    ap, vp, xp, jp = spike_experiment(am, jm)
    print(f"a_max={am:7.1f}  a_peak={ap:7.1f} m/s^2  v_peak={vp*1000:6.1f} mm/s"
          f"  行程={xp*1000:5.1f} mm  maxJerk={jp:8.0f} m/s^3")

解读：第一行（限幅放到 1000，等效无限）会打印出 apeak ≈ 160 m/s² 量级（80 N/0.5 kg 再被阻尼项修正）、maxJerk 高达约 1.6×105 m/s³ 量级，这个 jerk 就是"敲击"，真机上会听到清晰的"咔"。第二行（amax=5、jmax=500）把加速度锁在 5、jerk 锁在 500：两组的速度峰值与最大行程差异不大（都被 vmax = 150 mm/s 拦住、行程都在 10 mm 量级），波形则从"一拍冲顶"变成"爬坡-平台-缓降"。注意两个实验的 vpeak 差异没有加速度与 jerk 的差异那么夸张，这正说明三层限幅各司其职：加速度管"起步冲击"，速度管"最终跑多快"，jerk 管"过渡有多硬"。

片段 3：参数自检小工具，等效惯量与 ramp 时间的量级检查

def admittance_check(m_d=0.5, a_max=5.0, j_max=500.0,
                     f_worst=40.0, v_max=0.15):
    """打印关键量级：裸加速度、饱和等效惯量、ramp 时间、达到 v_max 时间。"""
    a_bare = f_worst / m_d
    m_eff = f_worst / a_max
    t_ramp = a_max / j_max                       # jerk 限制下 a 爬坡时间
    t_vmax = t_ramp + v_max / a_max              # 斜坡+匀速到 v_max 的总时间
    print(f"最坏外力 {f_worst:.0f} N: 裸加速度 {a_bare:6.1f} m/s^2"
          f" -> 饱和后等效惯量 {m_eff:4.1f} kg")
    print(f"a 爬坡 {t_ramp*1000:5.1f} ms;  v 达到上限需 {t_vmax*1000:5.1f} ms"
          f"  (相对 1 kHz 控制周期 = {t_vmax/1e-3:.0f} 拍)")
    # 经验规则：t_vmax 最好不超过任务最小时间常数的一半，否则"来不及响应"
    print("提示: 若 ramp 时间超过力环时间常数的 1/2，请提高 a_max 或降低 j_max 约束")

admittance_check()

解读：这个小工具把设计取值变成三行数字，方便你在"手感（Md）—安全（amax）—平滑（jmax）"三者间做量化取舍。本例输出：裸加速度 80 m/s²、饱和等效惯量 8 kg，两者之间的差距（16 倍）就是限幅器的工作空间；ramp 时间 10 ms、达到 vmax 需 40 ms。把这个时间与你的力环时间常数（例如抛光力环 0.3 s）比较：40 ms 只占 1/7，说明限幅不会拖慢主任务的力跟踪；如果某个参数组合给出 tvmax > 100 ms，就要提高 amax，否则"力到位了、速度还没起来"，跟踪波形会被明显削顶。

常见坑

  • 用"位置增量限幅"代替加速度限幅：对每拍位移设上限等价于限速，管不了起步冲击；而且丢行程、坏状态。修复：加速度/速度/位置各管一层，别互串。
  • 只限加速度、不限 jerk：加速度台阶依旧"敲击"结构，工具细长时表现为高频微振、力曲线毛刺。修复：jmax = amax/(10–30 ms) 起步。
  • jerk 限制过紧：a 爬坡比力变化还慢，力跟踪出现大滞后、方波响应变三角波。自检：ramp 时间应远小于任务最快力变化的时间常数（见片段 3）。
  • Md 太小 + 噪声大：加速度噪声 = σF/Md，被限幅器"削"住后表现为小幅高频颤动或反复进出饱和。修复：力信号先滤波（20–50 Hz），或适度增大 Md（第 038 章展开）。
  • 三层限幅各自为政：每层用独立状态（比如速度限幅器自己记忆 v），层间数字不一致，退出饱和时状态对不上、位置跳变。修复：本章的"单链状态"结构，只保留一组 (aprev, v, x)，每层只是对即将写入的下一个值的修改。

小结

  • 加速度是虚拟惯性方程的输出，也是机械冲击与共振的激励源；小虚拟质量让正常外力都能逼近硬件加速度极限。
  • 限加速度的物理含义是饱和期等效惯量 Meff = F/amax 变大，从"灵敏"平滑降级到"沉重"，不注入能量。
  • jerk 限制把加速度台阶磨成 10–30 ms 斜坡，把激励能量压到低频，避开结构模态敏感带。
  • 完整输出链顺序：jerk 限速 → 加速度限幅 → 积分速度 → 速度限幅 → 积分位置；单链状态保证限幅间自洽。
