第三篇 · 感知、辨识与智能调参

第 048 章：导纳控制中的位置传感器噪声处理

上一章的噪声从力传感器来、被阻抗模型"顺带过滤"；这一章的噪声从编码器来，一旦被差分求速度就直接放大几百倍。本章推导放大倍数、解释低速"台阶效应"，并给出 α-β 观测器这条既降噪又不添太多滞后的正解。

  • 主题：位置信号调理 / 速度观测器（α-β 滤波）
  • 关键公式：σv = √2·σx/Δt（裸差分放大律）；α-β：x̂k = xpred + α(z−xpred)，v̂ += (β/Δt)(z−xpred)
  • 预计学时：50 分钟
  • 前置章节：第 047 章（阻抗控制中的力传感器噪声处理）

学习目标

  • 理解"差分放大"的数学：为什么 1 µm 的编码器量化误差经 1 ms 差分会变成 0.4 mm/s 的速度噪声。
  • 掌握 α-β 观测器的预测-校正结构与参数配比 β = α²/(2−α)，理解它为什么比"低通后差分"更好。
  • 能分析低速运动下的"台阶效应"：速度低于 q/Δt 时编码器整拍跳变导致的蠕动与顿挫。
  • 会设计速度门（滞回门）供偏置更新、功率审计等模块使用，避免噪声触发误动作。
  • 知道导纳回路里哪些地方需要速度估计、哪些地方绝不能做二次差分。

背景与动机

导纳控制把力变成运动，因此它对"运动"的度量质量极其敏感。多数机器人只提供位置（编码器计数）而不提供速度，控制器若需要速度，阻尼项、拖动示教的偏置门控、遥操作的能量审计、接触时刻判定，就必须自己"从位置里挤出速度"。最朴素的写法是差商 v = (xk − xk−1)/Δt：在 1 kHz 控制周期下，这相当于把位置噪声乘以 1000 倍再放进控制器。

数字本身就很吓人：编码器分辨率 1 µm 时，量化误差的标准差约 0.29 µm，差分后的速度噪声约 0.4 mm/s，已经和手引导的典型速度（20–30 mm/s）同量级，占比超过 1%。若再对速度差分求加速度，噪声被进一步放大（σa = √6·σx/Δt² ≈ 0.7 m/s²），直接淹没任何真实的加速度信号。本章的核心结论是：导纳控制里任何"两次差分"的冲动都必须被压制，速度要用观测器估计，加速度要用模型算或用观测器扩展得到。

核心原理

1. 差分放大律：一个必须背下来的公式

设编码器位置噪声为白噪声，标准差 σx，采样周期 Δt。差商是两次相邻采样之差除以 Δt，白噪声做差后方差翻倍：

σv = √2 · σx / Δt σx：位置噪声标准差（量化时 ≈ q/√12，q 为分辨率）；Δt：控制周期

代入 q = 1 µm（σx ≈ 0.29 µm）、Δt = 1 ms：σv ≈ 0.41 mm/s。若加速度也这么求，σa = √6·σx/Δt² ≈ 0.7 m/s²，比机器人真实加速度（接触任务里通常小于 1 m/s²）不相上下。工程直觉：差分是噪声的放大器，采样周期越短、放大越狠；"算法更细腻"只是把"更准确的位置"变成"更嘈杂的速度"。

2. 低速台阶效应：比噪声更隐蔽的问题

量化系统还有一个结构性缺陷：当真实速度低于一个"每拍分辨率"时（v < q/Δt，即 1 mm/s），编码器的输出呈现"若干拍不动、某一拍跳 1 个计数"的台阶状。对导纳控制而言：速度估计在 0 与 1 mm/s 之间跳变（跳变拍的差商等于 q/Δt，与真实速度脱钩），机器人表现为低幅度的顿挫式蠕动，频率由真实速度决定。这属于确定性失真，滤波只能压它的幅度，不能消除它的节律。对策有三：选用更细分辨率的编码器/插补；用观测器在"台阶间"外推插值（α-β 的预测步正是干这个的）；在贴近的精细任务中干脆改用速度前馈，绕开对估计值的依赖。

3. α-β 观测器：预测-校正结构

α-β 观测器是运动学层面的稳态卡尔曼滤波器，状态取 [位置, 速度]，每个周期两步：

预测： xpred = x̂ + v̂·Δt
校正： r = z − xpred； x̂ = xpred + α·r； v̂ ← v̂ + (β/Δt)·r z：本周期编码器测量；r：新息（测量与模型预测之差）；α、β：位置/速度校正增益

它的思想是"用运动模型外推、用测量纠正"：预测步利用已知的匀速运动先验把噪声"平均"掉，校正步只按增益吸收残差。标准配比 β = α²/(2−α) 让二阶误差动态临界阻尼（α 取 0.2–0.5 之间）。与"先低通再差分"的对比：低通滤波在降噪的同时把相位滞后全堆在速度上（一阶低通 20 ms 时间常数就是 20 ms 滞后），而 α-β 的等效滞后只有约 Δt/α（α = 0.4 时 2.5 ms），降噪与滞后同时改善，这就是它值得记入工具箱的原因。

4. 速度估计用在哪里：三个入口的对账

  • 导纳积分状态：导纳方程里的 v 本身是内部状态（由 F 驱动），不需要差分测量，这是很多实现"没遇到噪声问题"的原因，也说明先把状态量分清再谈滤波。
  • 物理阻尼/摩擦前馈：若内环用"力矩 = Dphys·v"来构造物理阻尼，必须用干净的 v̂，否则阻尼项变成噪声放大器（D·0.4 mm/s，D = 50 时 20 mN 级别抖动，尚可，但 D = 300 就明显了）。
  • 状态判定与门控：偏置更新、静止检测、功率审计都需要"是否在动"的判断，应使用带滞回的 v̂（见片段 3）；瞬时差分在低速段不可靠。

绝不允许的地方：用位置二次差分得加速度去做前馈，真实加速度被噪声淹没；需要加速度时应从动力学模型反解（τ、F 都已知）。

实现思路与设计

速度观测模块的设计要点（控制周期 1 ms）：

  1. 入口：每个周期取编码器原始计数（未插补或仅驱动器插补后），转成米制；做坐标变换（关节到任务空间）放在观测器之后，观测器装在哪个信号上由接口决定：能在关节层拿到高频位置，就在关节层观测再经雅可比映射。
  2. 增益选取：α = 0.4 起步（等效滞后 Δt/α ≈ 2.5 ms，噪声抑制约 6–10 倍）；精细贴合任务可降到 0.3 换取更平滑；示教类可升到 0.5 换取更灵敏。
  3. 初始化：首帧位置取测量值、速度置零；重新使能（如急停复位）时同样处理，避免旧状态产生"瞬移"估计。
  4. 速度门：把 v̂ 送入滞回判定（进门限 1 mm/s、出门限 2 mm/s、驻留 0.2 s），供偏置与状态机使用。
  5. 异常保护：当 |v̂| 超过物理速度上限（如 1 m/s）时冻结更新并报警，多半是编码器跳数或通信丢帧。
设计决策：为什么不用简单低通滤波位置？

对位置做一阶低通再差分，噪声确实小了，但低通的相位滞后直接计入速度估计，再进入耦合回路就是稳定性账本里的额外 τ。α-β 用"预测"替代"滞后平滑"：它宁可相信运动连续性，也不把新测量一棍子打成低权，这正是卡尔曼滤波"按不确定度加权"的朴素版本。

关键代码与解读

片段 1：裸差分 vs α-β 的噪声实测

import numpy as np

rng = np.random.default_rng(7)
dt, q_lsb = 1e-3, 1e-6          # 1 ms 周期，编码器 1 um 量化台阶
N, v_true = 2000, 0.005         # 真实以 5 mm/s 匀速运动
x_true = np.cumsum(np.full(N, v_true * dt))
x_meas = np.round(x_true / q_lsb) * q_lsb       # 量化：产生最小时 1 um 台阶
x_meas = x_meas + rng.normal(0.0, 0.2 * q_lsb, N)  # 叠加少量电气噪声

# --- 方案 A：裸差分 ---
v_raw = np.diff(x_meas) / dt
# --- 方案 B：alpha-beta 观测器 ---
alpha = 0.4
beta = alpha * alpha / (2.0 - alpha)     # 临界阻尼配比
xh, vh, v_ab = x_meas[0], 0.0, np.zeros(N)
for k in range(N):
    x_pred = xh + vh * dt                # 运动模型预测
    r = x_meas[k] - x_pred               # 新息
    xh = x_pred + alpha * r              # 位置校正
    vh = vh + beta / dt * r              # 速度校正
    v_ab[k] = vh
print(f"真实速度 5.0e-3 m/s")
print(f"裸差分噪声 RMS   : {np.std(v_raw - v_true):.2e} m/s")
print(f"alpha-beta 噪声  : {np.std(v_ab[200:] - v_true):.2e} m/s")

解读：跑出来你会看到裸差分噪声 RMS 在 4×10−4 m/s（0.4 mm/s）附近，与公式 √2σx/Δt 完全对上；α-β 输出则降一个数量级左右。但注意 v_ab 的均值仍会带上低速台阶的节律（5 mm/s 时每 5 拍跳一个计数），这就是"滤波器降幅不降频"的具体表现。你可以把 v_true 改到 0.5 mm/s 再跑，会更直观地看到裸差分在 0 与 1 mm/s 之间"蹦台阶"。

片段 2：α-β 观测器类

class AlphaBetaObserver:
    """位置/速度观测器：把量化编码器信号变成平滑的 (x, v)。
    预测步用运动模型外推；校正步按增益吸收新息。
    参数配比 beta = alpha^2/(2-alpha) 保证误差动态临界阻尼。"""
    def __init__(self, alpha=0.4, dt=1e-3):
        self.alpha = alpha
        self.beta = alpha * alpha / (2.0 - alpha)
        self.dt = dt
        self.x = None
        self.v = 0.0

    def update(self, z):
        if self.x is None:               # 首帧/复位：位置迎面吸收，速度置零
            self.x, self.v = float(z), 0.0
            return self.x, 0.0
        x_pred = self.x + self.v * self.dt      # 预测
        r = float(z) - x_pred                   # 新息
        self.x = x_pred + self.alpha * r        # 位置：按 alpha 吸收
        self.v = self.v + self.beta / self.dt * r   # 速度：按 beta/dt 吸收
        # 物理上限保护：速度突跳超出机器人能力范围必是测量异常
        if abs(self.v) > 1.0:
            self.v = float(np.clip(self.v, -1.0, 1.0))
        return self.x, self.v

    def reset(self):
        # 急停复位或重新使能时必须清状态，否则旧速度会“带球跑”
        self.x, self.v = None, 0.0

解读：（1）预测-校正是这个类的灵魂：新息 r 里既有噪声也有真实运动变化，α、β 决定"信测量多少、信模型多少"。α 大 = 更信测量（灵敏但噪声大），α 小 = 更信模型（平滑但滞后）。（2）β/Δt 的量纲是 1/s，把米制新息变成速度修正；β 与 α 的固定配比省去了独立整定。若任务特别在意低速平滑，可单独把 β 调小 10–20%，代价是速度估计略微滞后。（3）物理上限保护不是装饰：编码器跳数、EtherCAT 丢帧都会出现 1 m 级的位置跳变，无保护时 v̂ 会瞬间到达几百 m/s 并污染积分状态。

片段 3：静止判定滞回门（供偏置/状态机使用）

class StillGate:
    """静止判定：进门限 1 mm/s、出门限 2 mm/s、驻留 0.2 s。
    用于 bias 更新、能量审计等“只在静止时做事”的模块。"""
    def __init__(self, v_in=1e-3, v_out=2e-3, t_hold=0.2, dt=1e-3):
        self.v_in, self.v_out, self.t_hold, self.dt = v_in, v_out, t_hold, dt
        self.still = True          # 初始视为静止（上电后通常确实静止）
        self.timer = 0.0

    def update(self, v_hat):
        a = abs(v_hat)
        if self.still:
            if a > self.v_out:               # 明确超过出门限 → 判运动
                self.still = False
                self.timer = 0.0
        else:
            if a < self.v_in:                # 回落到进门限内 → 开始计时
                self.timer += self.dt
                if self.timer >= self.t_hold:
                    self.still = True
                    self.timer = 0.0
            else:
                self.timer = 0.0
        return self.still

解读：为什么必须带滞回？假设只用一个门限 1.5 mm/s：噪声让 v̂ 在 1.4–1.6 mm/s 之间抖动，静止状态每一两拍就翻转一次，偏置更新刚刚启动又被冻结，功能性失效。进门限（1 mm/s）与出门限（2 mm/s）把两个方向分开，再叠加"驻留 0.2 s"确认，让状态切换变成低频事件。这个门同样用在第 046 章的能量审计上：只有"真静止"时才允许重置账本或做灵敏度自检，否则噪声功率会污染审计。参数选择与延迟的权衡：v_in 越小（越接近零），越难判静止、恢复越慢；建议 v_in 取 v̂ 噪声均值的 2–3 倍（0.4 mm/s 噪声 → 1 mm/s 门限）。

常见坑

  • 直接对位置差分：导纳回路里任何 v = (x[k]-x[k-1])/dt 都应先怀疑。症状是机器人在静止时"沙沙"微抖、示教时手把上有高频颗粒感。修复：α-β 观测器或驱动器原生速度。
  • 补一刀低通再差分：滤波器相位滞后叠加到速度估计上，耦合回路稳定性变差；且阶跃响应变钝。修复：改用预测-校正结构，或在观测器内部调增益。
  • 用二次差分做加速度前馈：σa 百倍于真实加速度。修复：加速度由动力学模型（τ、F、已知惯量）反解，或把 α-β 扩为 α-β-γ 并谨慎使用。
  • 观测器在使能切换时不清状态：急停恢复后残余速度估计让机器人瞬间"飘"一段。修复：reset()，并把首帧位置设为测量值。
  • 忽略低速台阶：以为"慢速更安全"，结果 0.5 mm/s 的对位动作变成一顿一顿。修复：细分辨率编码器 + 观测器外推；对位阶段用速度前馈替代速度反馈。

练习与思考

  1. 推导 σv = √2σx/Δt：设相邻两次量化误差独立同分布、标准差 σx，写出差商的方差并计算 q = 0.1 µm（高分辨率编码器）、Δt = 1 ms 时 σv。★
    提示
    Var(xk−xk−1) = 2σx²；除以 Δt² 再开方。q = 0.1 µm → σx ≈ 0.029 µm → σv ≈ 41 µm/s。
  2. 用片段 1 的框架，把 α 从 0.2 扫到 0.8，记录速度噪声 RMS 与对速度阶跃（0 → 10 mm/s）的 90% 响应时间，画出或列出"噪声-滞后"权衡表，并给出你对"示教任务"与"精密贴合任务"各推荐哪个 α。★★
    提示
    α 小：噪声低、滞后大（约 Δt/α）；示教求灵敏 → α ≈ 0.5；贴合求平滑且能容忍几十 ms 滞后 → α ≈ 0.3，并注意贴合时主要靠力反馈，速度环只作辅助。
  3. 低速台阶实验：设 v = 0.3 mm/s、q = 1 µm、Δt = 1 ms，写出编码器输出序列的规律（每隔几拍跳一次），计算裸差分输出的取值集合，并解释 α-β 输出为什么是"带节律的平滑值"。★★
    提示
    q/(vΔt) = 1e-6/(0.3e-3×1e-3) ≈ 3.3 拍跳一次 → 裸差分在 0 与 1 mm/s 之间跳；α-β 的校正增益把节律低通成一个 0.3 mm/s 附近的周期性波动。
  4. 把 StillGate 的进门限设成 0.3 mm/s（低于噪声 RMS），仿真说明"静止判定为何变成每几拍翻转一次"，并给出你根据 v̂ 噪声实测值设计门限的一般配方（写成三步流程）。★★★
    提示
    阈值低于噪声带 → 状态随机游走。配方：① 实测静止时 v̂ 的 RMS；② 门限取 2–3 倍 RMS；③ 加滞回比 2:1 与 0.2 s 驻留，最后用"静止/运动"误判率验收。

小结

  • 位置噪声经差分被放大 √2/Δt 倍：1 µm、1 kHz 下就是 0.4 mm/s，与手引导速度同量级，速度估计必须用观测器；裸差分会被噪声淹没。
  • α-β 观测器 = 预测-校正：预测用运动模型、校正按增益吸收新息；β = α²/(2−α) 保证误差动态临界阻尼，等效滞后仅 Δt/α。
  • 低速台阶是确定性失真，滤波只降幅不降频；对策是细分辨率、观测器外推、关键阶段用速度前馈。
  • 速度估计服务于阻尼前馈、状态判定与能量审计；加速度绝不二次差分，应由动力学模型反解。
  • 滞回速度门把"是否在动"从噪声敏感量变成低频状态量，是所有门控模块的地基。
  • 下一章升级问题：当机器人连力传感器都没有时，力从哪来？用动量观测器从动力学模型中"算"出外力，这是力觉感知的软件方案。
