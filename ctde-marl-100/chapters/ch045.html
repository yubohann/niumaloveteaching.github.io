第三篇 · 环境与任务实践

第 045 章：多智能体导航

多智能体导航是带目标与碰撞约束的共享空间移动问题；本章对照多智能体路径规划（Multi-Agent Path Finding, MAPF）的冲突定义，推导保持最优策略不变的势能塑形，并说明局部避障与全局规划的平衡方式。

  • 主题：路径冲突消解 / 奖励塑形
  • 关键公式：r′ = r + γ Φ(s′) − Φ(s)，Φ(s) = − Σi ‖pi − gi‖
  • 预计学时：60 分钟
  • 前置章节：第 044 章 多智能体追捕问题

学习目标

读完本章，应当能够把导航任务写成带目标与安全约束的协同移动问题，并选择正确的奖励塑形方式。

  • 理解导航任务与协作导航任务的差别：专属目标、长程规划、以及冲突消解的必要性。
  • 掌握 MAPF 的三种冲突定义（顶点冲突、边冲突、跟随冲突）与冲突计数的实现方式。
  • 掌握势能型奖励塑形（potential-based reward shaping, PBRS）的形式与最优策略不变性条件，能解释普通距离塑形为何会改变最优解。
  • 理解速度障碍（velocity obstacle）与互惠避让的几何含义，能说明局部避障与全局规划的分工。
  • 会设计导航任务的评价指标体系：成功率、路径长度比、碰撞率与通过时间，并识别只看成功率的评估偏差。

背景与动机

导航任务的难点在于长程目标与短程安全之间的协调，冲突消解必须在线完成。

多智能体导航在仓储搬运、机场摆渡、密集人群通行等场景中出现，其抽象形式是 MAPF：N 个智能体各有一个起点与目标点，需要在共享空间中找到无碰撞的移动方案。经典方法分为两类。耦合式方法（例如基于冲突的搜索，conflict-based search, CBS）把冲突作为约束逐步加入规划树，能得到最优或无界次优解，代价是计算量随智能体数量组合增长。解耦式方法（例如优先级规划与速度障碍法）把问题拆成逐智能体的局部反应，计算轻量，但可能陷入死锁。

强化学习的定位是在线决策层：在动力学受限、观测局部、通信不稳定的真实条件下给出以安全为约束的移动策略，不把静态最优路径作为目标。与上一章追捕任务的区别在于目标的非对抗性：所有智能体都希望尽快通过，冲突来自空间共享，各方利益一致，因此存在“全体协作即可改善”的机会，例如对称互换与主动让行。与协作导航任务的区别在于长程性与安全性权重：协作导航的目标是分布覆盖，本任务要求逐个到达指定终点，中途任何碰撞都会终止或大幅惩罚。

核心原理

导航任务的理论分两块：冲突的离散定义与连续避让的几何条件，二者分别对应规划层与反应层。

1. 任务形式化与冲突定义

每个智能体 i 拥有起点 si 与目标 gi，位置与速度组成状态，碰撞按几何距离判定。

φvertex(i, j) = 1[ pi,t+1 = pj,t+1 ] ， φedge(i, j) = 1[ pi,t+1 = pj,t 且 pj,t+1 = pi,t ] 顶点冲突指两步后占用同一位置；边冲突指两智能体交换位置；两者都对应离散规划中的必检项

离散模型中出现第三类冲突：跟随冲突，即 i 在 t + 1 步进入 j 在 t 步离开的位置，两个连续时间层的位置被相邻占用。连续物理空间中这三种冲突对应不同的几何事件（正面相撞、擦肩而过、追尾），在实现中统一用距离阈值判定，但是保留离散分类有助于设计奖励与诊断：擦肩碰撞提示相对速度观测缺失，追尾碰撞提示制动距离估计不足，正面相撞提示对向意图预测缺失。

若把位置与时间离散化，MAPF 的目标通常是最小化总到达时间（sum of costs）或最大到达时间（makespan）。以总到达时间为目标的无冲突求解是组合优化，难度随智能体数量迅速上升。强化学习绕开显式搜索，用策略在连续状态上直接输出速度，但必须付出样本复杂度作为代价。

2. 势能型奖励塑形

导航天然是稀疏奖励任务：只有在到达目标时才有正回报，随机探索几乎无法命中。

r′t = rt + γ Φ(st+1) − Φ(st) ， Φ(s) = − Σi ‖ pi − gi ‖1 Φ 为势能函数，取负的曼哈顿距离和；γ 为折扣因子；该变换不改变最优策略集合（Ng 等的定理）

势能型塑形的关键性质是：塑形项写成“下一状态势能减当前状态势能”的折扣差分形式时，任何策略的回报都被加上一个与策略无关的望远镜项，最优策略不变。若直接用 −Σ‖pi − gi‖ 作为奖励（省略差分），训练目标会额外混入与“累计折扣距离”相关的分量：折算出的附加项为 Φ(s) + (1 − γ)Φ(s′)，其最优解依赖折扣因子与回合设定，跨配置不再可比；在一般的势能函数上，这类目标偏移可能诱发驻留、绕行等退化行为。差分形式把这些附加项精确消去，塑形项只贡献一个与策略无关的常数，这是最优策略不变性的来源。该结论对所有任务通用，本章把它用在长程稀疏任务上是典型用例。

势能函数的形式可以选择：曼哈顿距离在网格运动下与真实步数一致，欧氏距离在连续动力学下更自然，两者可用凸组合调和。塑形项的量级通过 γ 与进入奖励的总量控制，实践上让塑形项的步进量级与安全惩罚同阶即可，无需精调。

3. 速度障碍与互惠避让

连续避让的经典工具是速度障碍：给定邻居当前相对位置与速度，存在一个速度集合会导致未来某个时刻距离小于安全距离。

VOij = { v : ∃ t > 0, ‖ (pj − pi) + (vj − v) t ‖ < rs } v 为候选速度；vj 为邻居速度（假设保持）；rs 为安全距离；该集合在相对速度空间中是一个锥形区域

速度障碍把“未来是否碰撞”转化为“当前速度是否落在锥内”，几何直观明确。若所有智能体都假设对方保持当前速度而独自避让，避让行为会过度保守且彼此冲突；互惠避让规则（例如 ORCA，optimal reciprocal collision avoidance）假设双方各承担一半责任，把锥形区域外推成半平面，每个智能体的可行速度集合是若干半平面的交集，从中选最接近期望速度的解。期望速度由全局目标方向给出，避让在速度层面完成，规划与反应因此解耦。

强化学习策略学习的是同一层次的映射：观测给出邻居相对位置与速度，输出经过安全约束过滤的速度。把互惠避让的可行集作为动作过滤层是有效做法：策略在可行集内选择动作，安全由几何保证，策略只需优化通行效率。该“策略加安全层”的结构把难学的安全行为交给解析规则，把难描述的偏好留给学习，是安全约束型任务的通用模式，第 080 章会系统讨论。

4. 观测设计与方向信息

相邻智能体的相对速度是区分“迎面而来”与“同向同行”的唯一依据，观测中必须包含它。

oi = [ vi, gi − pi, { pj − pi, vj }j∈N(i), mi, 历史编码 ] gi − pi 为到目标的相对向量；vj 为邻居速度；历史编码由循环或注意力模块生成

只给邻居位置而不给速度时，策略无法区分静止障碍与迎面而来的智能体，训练出的行为不是过度保守就是频繁碰撞，且这种缺陷无法通过更多样本弥补。目标相对向量提供长程方向，历史编码在观测视野有限时补足被遮挡的邻居信息。归一化方面，位置以视野半径为单位，速度以速度上限为单位，两类量的数量级因此对齐，价值网络的条件数得到改善。

5. 死锁、让行与对称性破坏

对向走廊与十字交叉是两类典型死锁场景，双方对称地互相等待或互相抢行。

死锁的根源是策略对称：两个能力相同、观测镜像的智能体学到相同的让行规则就会僵持。破解手段有随机化与优先级两类。随机化在动作采样中加入噪声或随时间变化的偏置，使对称被概率性打破，代价是通行行为不完全确定。优先级给智能体分配不同的让行顺序（例如按编号、按剩余距离、按进入顺序），互让规则不对称化，死锁在结构上被排除。训练时可以在观测中加入优先级特征，策略据此执行一致的通行规则。分布式执行中优先级信息需要邻居交换获得，通信成本为每个邻居一个整数，负担很轻。

实现思路与设计

训练方案围绕“从简单到复杂”的课程组织，先建立基本通行能力，再逐步加入冲突密度与规模。

1. 课程学习的三级划分

第一级：无邻居或极少邻居，智能体从随机起点到达随机目标，主要建立势能塑形下的直达行为。第二级：加入对向与交叉流量，激活避让与让行行为。第三级：加入瓶颈地形（窄通道、单门房间），激活排队与优先级行为。每级晋升以成功率为判据，未达标时在当前级继续采样。

3. 网络结构与执行流程

策略网络在邻居聚合编码器之上叠加一层门控循环单元（gated recurrent unit, GRU），把最近若干步的观测编码为隐状态，用于推断被遮挡邻居的意图。执行流程为：观测构造、策略推理、可行速度过滤（速度障碍半平面求交）、动作输出、环境推进与冲突统计。训练使用集中式评论家读取全部智能体位置速度，配合允许多步自举的折扣设置。

4. 与第 044 章的差异点

追捕任务的对手主动制造对抗，价值函数的非平稳主要来自对手学习；导航任务的非平稳来自邻居策略的同步更新，冲突是空间性的，各方利益一致。奖励结构上，追捕任务靠稠密几何项加捕获稀疏项，导航任务靠势能塑形加到达稀疏项；安全约束的实现上，追捕任务用惩罚，导航任务推荐惩罚与动作过滤并用。这些区别决定了本章的重点落在安全层与评估指标上。

关键代码与解读

三段代码分别实现冲突检测、势能塑形奖励与互惠避让的可行速度过滤。

片段 1：三类冲突的检测

import numpy as np

def count_conflicts(prev, curr, order, radius=0.15):
    """按离散 MAPF 口径统计冲突：prev 与 curr 为前后两步位置。"""
    n = len(curr)
    v_conf = e_conf = f_conf = 0
    for a in range(n):
        for b in range(a + 1, n):
            # 顶点冲突：两步后在相近位置，连续模型里等价于同格相撞
            if np.linalg.norm(curr[a] - curr[b]) < radius:
                v_conf += 1
            # 边冲突：交换位置（对向擦肩），离散模型中必然相撞
            if (np.linalg.norm(curr[a] - prev[b]) < radius
                    and np.linalg.norm(curr[b] - prev[a]) < radius):
                e_conf += 1
            # 跟随冲突：b 进入 a 腾出的位置；按优先级 order 决定谁让行
            if np.linalg.norm(curr[b] - prev[a]) < radius and order[b] > order[a]:
                f_conf += 1
    return {"vertex": v_conf, "edge": e_conf, "follow": f_conf}

解读：三类冲突共用一对循环与距离阈值，保持统计口径一致。跟随冲突使用优先级 order 判定责任方：优先级高的智能体无责，低的负责避让，这与后文让行规则训练一致。连续实现中阈值半径取安全距离，三类冲突在数值上可能同时触发同一对智能体，因此诊断时按类别分别计数、不合并求总数，避免因果混淆。该函数只在诊断与安全层使用，训练奖励由塑形项与到达项承担。

片段 2：势能型奖励塑形

class PotentialShaping:
    """势能塑形：r' = r + gamma * Phi(s') - Phi(s)，最优策略不变。"""
    def __init__(self, goal_weight=1.0, gamma=0.99):
        self.w, self.gamma = goal_weight, gamma
        self.prev_phi = None

    def potential(self, pos, goals):
        # 曼哈顿距离之负：与网格步数一致，且对坐标轴方向的变化敏感
        return -self.w * float(np.abs(pos - goals).sum())

    def reset(self, pos, goals):
        self.prev_phi = self.potential(pos, goals)   # 回合开始先记录初始势能

    def __call__(self, reward, pos, goals):
        phi = self.potential(pos, goals)
        delta = self.gamma * phi - self.prev_phi   # 塑形增量：为正表示距离在缩小
        self.prev_phi = phi                        # 状态更新必须在增量计算之后
        # 返回塑形增量便于诊断：它与距离变化方向相反
        return reward + delta, {"shaping_delta": delta}

解读：势能函数取距离之负，塑形增量为正表示距离在缩小。把 γ 乘在下一状态势能上是定理要求的形式，若省略 γ，最优策略不变性在折扣任务中不再严格成立。reset 预置初始势能，避免第一步出现“凭空”的塑形奖励。信息字典中的塑形增量用于区分两种奖励来源：若塑形项占回报比例长期过高（例如超过 70%），说明到达奖励的引导作用被淹没，需要调整权重。实现注意顺序：更新 prev_phi 必须在计算增量之后。

片段 3：互惠避让的可行速度过滤

def orca_half_planes(pos, vel, goals, v_max=1.0, tau=1.0, safety=0.15):
    """为每个智能体生成半平面约束，返回可行速度集的近似求交结果。"""
    n = len(pos)
    v_pref = goals - pos
    # 期望速度：朝目标、按上限裁剪；速度障碍的锥顶由它确定
    norm = np.linalg.norm(v_pref, axis=1, keepdims=True)
    v_pref = v_pref / (norm + 1e-9) * np.minimum(norm, v_max)
    out = []
    for i in range(n):
        lines = []                                 # 每个邻居贡献一个半平面
        for j in range(n):
            if i == j:
                continue
            rel_p = pos[j] - pos[i]
            rel_v = vel[i] - vel[j]                # 相对速度决定锥的形状
            dist = np.linalg.norm(rel_p)
            # 时间视野 tau 内不会接近到安全距离以内，则无需约束
            if dist > safety and np.dot(rel_p, rel_v) >= 0:
                if np.linalg.norm(rel_v - np.dot(rel_v, rel_p) / dist**2 * rel_p) * tau > dist - safety:
                    continue
            u = rel_v - rel_p / tau                # 教学简化：接近分量超过时间视野允许值的部分
            lines.append((u, safety / tau))
        # 简化求解：从期望速度出发沿半平面法向逐步投影（实现取近似）
        v_new = v_pref[i].copy()
        for u, b in lines:
            un = u / (np.linalg.norm(u) + 1e-9)
            v_new = v_new + max(0.0, b - np.dot(un, v_new)) * un
        out.append(np.clip(v_new, -v_max, v_max))
    return np.array(out)

解读：互惠避让的核心是 u 向量，它是“相对速度在锥内时，为脱离锥所需的修正”，幅度上限为安全距离与时间视野之比。连续时间视野 tau 取 1.0 与速度上限 1.0 一致，表示一秒的预判窗口。实现中半平面交的求解采用顺序投影近似（精确求解需要线性规划求解器，如 Gurobi 一类实现），精度低于精确求解但在实时控制中足够，且计算量与邻居数线性相关。该层可作为动作过滤：策略输出经此过滤后，碰撞概率大幅下降，策略学习的重点转向通行效率。

常见坑

  • 把势能直接当奖励：奖励直接写成距离的负值（省略差分），目标混入累计折扣距离分量，最优解依赖折扣设定，可能产生驻留类退化行为。症状是回合长度增加而成功率不升。修复：严格按 γΦ(s′) − Φ(s) 的差分形式实现，并用塑形增量做诊断。
  • 观测缺少邻居速度：无法区分迎面与同向，碰撞率居高不下且无法通过训练量弥补。症状是碰撞事件集中在相对速度接近零的擦肩情形。修复：观测加入邻居速度分量并按速度上限归一化。
  • 安全层参数与动力学不匹配：时间视野过短会来不及制动，过长会使可行集过小导致智能体停滞。症状分别是追尾碰撞与通道口拥堵。修复：按速度上限与单步位移估算制动距离，令时间视野覆盖制动时间。
  • 对称死锁无处理：相同策略在窄通道面对面僵持，回合超时。症状是对向通道场景成功率显著低于交叉场景。修复：引入优先级特征或随机化让行，评估集应包含对向走廊场景。
  • 只报告成功率：低碰撞率可能来自大量停滞，高成功率可能来自绕极长的路径。修复：指标同时报告路径长度比（实际路径与最短路径之比）与通过时间，三者联合判读。

练习与思考

  1. 计算题：8 个智能体两步之间需要检查多少对智能体？每对需要做几次距离比较？据此说明冲突检测的复杂度。★
    提示
    无序对为 8×7/2 = 28 对；每对做顶点、边、跟随三次距离比较。复杂度为 O(N²)，与邻居截断结合可降为 O(N·K)。
  2. 推导题：证明势能型塑形不改变最优策略，并说明若省略 γ 折扣会引入何种偏差。★★
    提示
    把塑形回报按时间累加，除首尾项外全部抵消，得到与策略无关的常数项；省略 γ 后望远镜项不成立，回报多出与折扣势函数累加成正比的附加分量（系数为 1/γ − 1），目标发生偏移，策略行为对折扣设定额外敏感。
  3. 改参数并预测：把安全距离从 0.15 提高到 0.3，预测碰撞率、通过时间与死锁比例的变化方向，并判断哪个指标最先恶化。★★
    提示
    安全距离增大后可行空间缩小，碰撞率下降但通过时间上升，窄通道场景最先出现拥堵与死锁。指标上死锁比例通常先于碰撞率变化被观察到。
  4. 设计题：为十字交叉口设计让行规则并写入观测，说明规则如何打破对称，以及通信量与鲁棒性代价。★★★
    提示
    常用规则是“先到先行”或“右侧优先”，以离散特征进入观测。需要邻居广播进入顺序或相对方位，通信量为每邻居一个标量；鲁棒性代价是个别智能体信息过时时规则被误用。
  5. 实验设计：构造“策略输出经安全层过滤”与“策略端到端输出”两组对照，设计指标区分解耦策略的安全水平与效率损失。★★★
    提示
    指标至少包含碰撞率、路径长度比与动作被过滤的比例。过滤比例高说明策略本身不安全，依赖安全层兜底；过滤比例低且碰撞率低说明策略内化了安全约束，这是更理想的结果。

小结

  • 多智能体导航是带专属目标与安全约束的共享空间移动问题，离散层面用顶点、边、跟随三类冲突刻画碰撞。
  • 稀疏奖励下使用势能型奖励塑形，差分形式保证最优策略不变；直接使用距离负值会改变最优解。
  • 速度障碍给出避让的几何条件，互惠避让把责任对半分配得到半平面约束，可用作动作过滤层，把安全交给解析规则、把效率交给学习。
  • 观测必须包含邻居速度；死锁通过随机化或优先级打破，评估需要成功率、路径长度比与通过时间联合判读。
