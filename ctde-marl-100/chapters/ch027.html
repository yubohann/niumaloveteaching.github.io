第二篇 · 训练工程与稳定性

第 027 章：梯度裁剪与优化器选择

本章讲多智能体训练的反向传播工程：全局范数裁剪与分组裁剪、同策略算法的价值损失裁剪、Adam 与 RMSProp 的选择与参数标定，以及参数共享结构下的梯度干扰诊断。

  • 主题：优化器配置 / 梯度控制
  • 关键公式：g ← g · min(1, c / ‖g‖2)
  • 预计学时：50 分钟
  • 前置章节：第 026 章 多智能体环境下的归一化技术

学习目标

  • 理解多智能体中梯度异常的四个来源：长时序信用链、稀疏大额奖励、价值目标突变、多损失项合成。
  • 掌握全局范数裁剪的数学形式与几何含义，能解释裁剪阈值对更新步长的约束关系。
  • 掌握同策略算法价值损失裁剪的动机与形式，理解它与全局范数裁剪的分工。
  • 掌握 Adam 与 RMSProp 在多智能体算法中的常见配置及迁移注意事项。
  • 能用梯度余弦相似度诊断共享参数结构下的梯度干扰，并给出缓解方案。

背景与动机

第 026 章处理前向传播的数值尺度，本章处理反向传播的梯度尺度。多智能体训练的梯度异常有四个典型来源：其一，循环网络沿回合时间展开时梯度连乘，长回合末端的信用链长度可达上百步；其二，稀疏任务的大额奖励在首次获得时产生巨大的时序差分误差；其三，目标网络刷新或课程切换使价值目标突变，损失曲面局部陡峭；其四，策略损失、价值损失、熵正则与辅助损失合成的总损失中各分项量级不同，梯度叠加后方向可能被单项主导。

异常的梯度通过三个渠道破坏训练：单步参数移动过大引起策略崩溃、共享参数结构下不同智能体的梯度相互干扰、优化器自适应状态被离群梯度污染后长期偏移。梯度裁剪与优化器配置是控制这三类后果的基本手段，也是实验复现中改动最频繁的一层配置。

核心原理

1. 全局范数裁剪

全局范数裁剪限制所有参数梯度拼成的大向量之长度，只缩放方向、不改变方向：

g ← g · min(1, c / ‖g‖2) g 为全部参数梯度的拼接向量，‖g‖2 为其欧几里得范数，c 为裁剪阈值

几何含义：裁剪把梯度向量投影到半径为 c 的球内，范数小于 c 时保持原样，超过 c 时等比缩小到球面。对使用梯度下降的更新而言，单步参数移动的范数以学习率为尺度被间接限制在 lr·c 以内；对 Adam 一类自适应优化器，参数移动由归一化后的矩估计决定，裁剪的作用主要体现在限制自适应状态（二阶矩）被离群梯度抬高的程度上。

阈值选择依赖算法族与损失构成：同策略算法（PPO 类）常用 0.5，因为策略更新的信任域本身要求小步长；离策略值分解算法常用 5 到 10，梯度量级更大且更新频率更高；若损失包含循环网络的长展开，阈值可以保持不变而把裁剪对象限定到循环模块。阈值标定的经验规则是观察未裁剪时的梯度范数分布：把阈值设在分布第 90 到 95 百分位附近，让多数批次不受裁剪影响，仅拦截尾部异常批次。

2. 分组裁剪与逐模块控制

全局裁剪的一个副作用是耦合：某个模块（例如价值头）的梯度尖峰会缩放整个网络的更新，拖累其他模块的有效步长。多智能体算法通常包含多个子模块（个体网络、混合网络、策略头、价值头、辅助头），自然的分组粒度按子模块或按"共享主干与个体分支"划分，逐组独立裁剪。分组裁剪的判据与全局相同，只是范数在每个组内计算。

价值损失裁剪是同策略算法的专用手段：重要性采样比率把价值误差放大时，直接裁剪价值估计相对旧价值的偏离：

LVF = max( (V − R)2, (clip(V, V旧 − ε, V旧 + ε) − R)2 ) 取两式最大值，只有让损失变小的方向被裁剪封住，极端偏移的梯度被移除

两类裁剪分工明确：范数裁剪是全局兜底，任何模块任何时刻的梯度都被限幅；价值裁剪是局部契约，约束价值更新相对旧价值不越界。同策略算法同时使用两者是常规配置，离策略算法没有旧价值参考，只使用范数裁剪。

3. 优化器选择与参数标定

深度强化学习的事实标准是自适应优化器。Adam 维护一阶矩与二阶矩的指数滑动平均并做偏差校正：

m ← β1m + (1 − β1)g；v ← β2v + (1 − β2)g²；θ ← θ − lr · m̂ / (√v̂ + ε) m̂、v̂ 为偏差校正后的矩估计；默认 β1 = 0.9，β2 = 0.999，ε = 1e-5

多智能体文献中的配置分两派：值分解与离策略算法沿用 PyMARL 惯例的 RMSProp（学习率 5e-4，平滑系数 0.99，ε = 1e-5）；策略梯度类算法多用 Adam（学习率 5e-4 至 1e-3）。学习率与批大小配对标定：批大小扩大一倍时，学习率可近似同步扩大，但策略更新的信任域约束（裁剪比率）应保持不变。共享参数结构中，个体网络与集中式模块可以配置不同学习率，典型组合是共享主干用较小学习率（5e-4 量级）而个体策略头用标准值；注意学习率的比例在优化器构造时确定，运行中调整需要重建优化器状态。

优化器状态（矩估计）的保存与恢复是复现性的一部分：暂停后恢复训练时若只加载模型参数而丢弃优化器状态，重启瞬间的自适应尺度归零，训练曲线出现可观测的拐点。配置对象中把优化器状态纳入检查点清单是惯例。

4. 共享参数下的梯度干扰

参数共享（第 004 章）把全部智能体的梯度叠加到同一组参数上。当智能体处于任务的冲突相位（一个在向目标推进，另一个在避障绕行）时，两者的梯度方向部分或完全相反，叠加后互相抵消，表现为共享主干的学习速度远低于个体分支。

诊断量是梯度方向的一致性：对两个智能体在同一批次上的梯度向量计算余弦相似度，

cos(g1, g2) = g1·g2 / (‖g1‖·‖g2‖) 接近 1 表示方向一致，接近 0 表示近似正交，负值表示冲突

余弦相似度长期为负意味着该共享层承受系统性冲突，缓解手段按代价从低到高排列：抬高该层的专用度（拆分为角色分支）、对个体优势做标准化再回传、对冲突梯度做投影组合（在梯度更新前把与主方向冲突的分量剔除）。多数任务上第一种手段已足够，后两种属于诊断确认冲突严重后的进阶处理。

5. 数值算例：范数裁剪的三种情形

取梯度向量 g = (3, 4)，其欧氏范数为 5。对三个阈值分别计算（数值经程序核对）：

阈值 c缩放系数 min(1, c/5)裁剪后梯度裁剪后范数
10.20(0.6, 0.8)1.00
20.40(1.2, 1.6)2.00
51.00(3.0, 4.0)，不变5.00

读表：裁剪只乘一个标量系数，方向（3 比 4）三行完全相同；范数低于阈值时系数为 1，"不裁剪"由公式自然给出，无需单独逻辑。配合梯度下降更新，学习率 0.001 时单步参数移动的范数不超过 0.001 × c：c = 1 时上界 0.001，c = 5 时上界 0.005。该上界在 Adam 下不直接成立，因为更新量被二阶矩归一化，裁剪通过抑制离群梯度对二阶矩的瞬时污染间接起作用，这是同策略算法把阈值设到 0.5 量级仍要同时监控触发率的原因。

6. 数值算例：Adam 的尺度不变性与首步行为

固定梯度 g = 7 连续三步，β1 = 0.9、β2 = 0.999、lr = 0.001：偏差校正后 m̂ = 7.0000、v̂ = 49.0000 从第一步起就精确等于真值，参数移动恒为 0.001000；把梯度换成 0.07（缩小一百倍）重算，参数移动同样为 0.001000（数值经程序核对）。读数两则：其一，Adam 的单步移动量与梯度绝对尺度无关，恒在学习率量级（m̂ / √v̂ = 1），这是它跨任务迁移省心的原因；其二，尺度不变性的代价是"梯度整体缩小一百倍"这类退化不会被察觉，移动仍为 lr 乘符号，训练可能在无信息方向上缓慢漂移，监控梯度范数与参数移动量的比值是发现该类退化的手段。

7. 数值算例：梯度余弦相似度的判读

三组梯度对的余弦值（数值经程序核对）与对应处理：

梯度对余弦值含义与处理
(1, 2) 与 (−1, −2)−1.00完全冲突，叠加后互相抵消为零；拆分角色分支的最强信号
(1, 0) 与 (0, 1)0.00正交，无协同也无冲突；共享层不因这组样本受损

判读纪律：单批次余弦值波动很大，只有滑动窗口均值长期为负才构成"系统性冲突"的证据。余弦值为零不等于无影响：正交梯度各自作用于参数更新，对同一个参数产生不同修改，冲突度量看方向余弦，幅值大小不进入判据。

实现思路与设计

梯度处理按"裁剪后步进"的固定次序实现：前向计算损失、反向传播、裁剪、优化器步进、目标网络更新（第 024 章）、梯度监控记录。十条训练规则里次序错误是最常见的实现缺陷，因此裁剪与步进封装在同一函数内，调用方无法颠倒次序。

关键代码与解读

片段 1：分组裁剪与步进封装

import torch

def clip_and_step(optimizer, groups, clip_map, ready):
    """先分组裁剪再统一步进的固定次序；ready 标志由反向阶段置位。"""
    assert ready, "裁剪必须在反向之后、步进之前执行"
    norms = {}
    for name, params in groups.items():
        # 组内范数是欧氏范数：把该组全部参数梯度视作一个向量求模长
        total = torch.sqrt(sum((p.grad.detach() ** 2).sum() for p in params if p.grad is not None))
        norms[name] = float(total)
        c = clip_map[name]
        # 只缩放不改变方向：系数 min(1, c / norm) 保证不放大任何梯度
        if total > c:
            scale = c / (total + 1e-6)
            for p in params:
                if p.grad is not None:
                    p.grad.detach().mul_(scale)
    optimizer.step()
    optimizer.zero_grad(set_to_none=True)   # set_to_none 省内存且避免残留脏梯度
    return norms

解读：函数把"反向之后、步进之前"的次序约束写成断言，把易错点变成显式契约。分组范数在组内计算，某组的尖峰不会污染其他组的缩放系数，这正对应子模块量级差异大的多智能体网络（个体网络、混合网络、辅助头）。返回的范数字典直接进入监控管线，用于标定阈值与触发率。set_to_none=True 让梯度张量即时释放，内存收益在批次较大时明显。

片段 2：同策略算法的价值损失裁剪

def clipped_value_loss(values, values_old, returns, clip_eps=0.2):
    """PPO 价值裁剪：极端偏移的更新方向被移除，保留正常修正方向。"""
    # 未裁剪的平方误差：所有方向都允许
    err_raw = (values - returns) ** 2
    # 旧价值参考带内的估计不裁剪，带外估计回拉后再算误差
    values_clipped = values_old + (values - values_old).clamp(-clip_eps, clip_eps)
    err_clipped = (values_clipped - returns) ** 2
    # 取最大值：只有已经比裁剪版更差的方向被限制，改善方向保持原样
    loss = torch.max(err_raw, err_clipped)
    return loss.mean()

解读：max 的取舍方向是这段代码的关键：当估计值已经朝缩小误差的方向移动时，裁剪版误差更大，取最大值保留原梯度；当估计值越过参考带继续外推时，裁剪版误差更小，取最大值切换到裁剪版，梯度被回拉。该设计保证价值更新不会在单批次上被重要性采样比率放大到越界区间，与全局范数裁剪形成局部与全局的互补。参数 clip_eps 与策略比率裁剪共用 0.2 量级，当回报尺度整体变化时两者应同步重标定。

片段 3：共享主干的梯度干扰诊断

def grad_conflict(shared_module, per_agent_losses):
    """计算各智能体经共享模块回传梯度的成对余弦相似度。"""
    grads = []
    for loss in per_agent_losses:
        # 每次都清空后单独反传，得到每个智能体对共享参数的独立梯度
        shared_module.zero_grad(set_to_none=True)
        loss.backward(retain_graph=True)
        flat = torch.cat([p.grad.detach().flatten() for p in shared_module.parameters()
                          if p.grad is not None])
        grads.append(flat)
    sims = {}
    for i in range(len(grads)):
        for j in range(i + 1, len(grads)):
            cos = torch.nn.functional.cosine_similarity(grads[i], grads[j], dim=0)
            sims[(i, j)] = float(cos)
    # 负值持续出现说明共享层承受系统性冲突，考虑拆分角色分支
    return sims

解读：逐个智能体单独反传是诊断必要代价，只在监控周期执行，不影响训练主路径。retain_graph=True 允许多次反传复用同一前向图；生产训练中该函数通常以 1% 的采样率触发。cosine_similarity 对尺度不敏感，正适合比较量级不同的梯度。诊断结论的使用方式见前文三条缓解手段，注意相似度为负的智能体对如果固定成群（例如总是任务中的两个冲突角色），拆分分支最有效；随机波动型的负值则以调整优势标准化处理。

常见坑

  • 裁剪与步进的次序颠倒。先 optimizer.step() 再裁剪，梯度已被消费，裁剪只修改了下一轮的残留值。症状是裁剪配置完全无效。修复：封装函数内固定次序并加断言。
  • 对多损失项只裁剪总梯度。熵正则或辅助损失的量级远小于主损失时，其梯度被主损失方向淹没，症状是熵系数调整毫无效果。修复：对分项损失分别反传与分组裁剪（分项反传需要保留计算图，注意内存成本）。
  • 裁剪阈值从不标定。直接抄用 0.5 或 10，触发率长期高于 10% 或接近 0%。修复：记录未裁剪范数分布，把阈值设在 90 到 95 百分位。
  • 循环网络展开段未纳入监控。梯度尖峰只出现在长回合的末端时间步，全局范数偶尔超标却难以定位。修复：按时间步分桶记录范数，同时按模块分组裁剪循环模块。
  • 训练恢复与配置迁移的疏漏。恢复训练丢弃优化器状态，自适应矩估计归零后曲线出现拐点；批大小扩大后学习率未同步调整，等效步长变小。修复：检查点包含优化器 state_dict 并核对参数组数量；学习率与批大小按配对规则同步调整并记录配置表。

    更新量等于 lr 乘裁剪后梯度，范数上界由裁剪直接给出；Adam 把梯度除以自身二阶矩的平方根，参数移动量级与原始范数解耦，裁剪只通过二阶矩间接作用。
  2. 改参数预测：把分组裁剪阈值从 0.5 降低到 0.05，预测梯度触发率、回报上升速度与策略熵三个量的变化，并说明何时这种设置反而有益。★
    提示
    触发率接近 100%，有效步长被压缩，回报上升变慢、熵下降变慢；当早期出现频繁的策略崩溃且无法通过学习率调低解决时，强裁剪可作为稳定化手段。
  3. 设计：为一个包含个体网络、混合网络、循环编码器与辅助预测头的值分解算法设计裁剪分组与阈值，给出每组的标定依据与监控指标。★★
    提示
    循环编码器和混合网络量级中等取 5；个体网络与辅助头分别成组；监控每组触发率作为阈值复标的输入。
  4. 实验设计：在参数共享算法上对比默认配置、拆分支、优势标准化、梯度投影四种配置，用共享层梯度余弦相似度、达到固定回报的环境步数两个指标评估，说明如何用单一变量原则隔离各手段的贡献。★★★
    提示
    四种配置保持网络容量、学习率与种子集合一致；拆分支会改变参数量，报告时同时给出参数量以澄清对比口径。

小结

  • 梯度异常来自长信用链、稀疏大额奖励、目标突变与多损失合成；裁剪与优化器配置控制其后果。
  • 全局范数裁剪把梯度投影到半径 c 的球内，只缩方向不改变方向；阈值按未裁剪范数的 90 到 95 百分位标定。
  • 分组裁剪隔离子模块尖峰；价值损失裁剪在同策略算法中约束价值更新相对旧价值的越界，与范数裁剪互补。
  • Adam 与 RMSProp 是主流配置，学习率与批大小配对标定；优化器状态必须进入检查点。
  • 共享参数的梯度干扰用余弦相似度诊断，缓解手段从拆分角色分支到梯度投影逐级加重。
