第三篇 · 环境与任务实践

第 051 章：多智能体能源管理

能源管理把发电、储能与可调负荷放进同一个功率平衡约束；本章推导等微增率调度的最优性条件，说明储能的跨时段耦合为何要求策略具备长视野，并给出不平衡惩罚的设计方式。

  • 主题：功率平衡 / 储能调度
  • 关键公式：SOCt+1 = SOCt + ηc Pc Δt − Pd Δt / ηd
  • 预计学时：65 分钟
  • 前置章节：第 050 章 多智能体交通信号控制

学习目标

读完本章，应当能够把能源系统运行写成带功率平衡与储能动态的序贯优化问题，并把学习组件放在不确定性的应对位置上。

  • 掌握经济调度问题的形式：二次成本、出力上下限与功率平衡约束，理解等微增率原则与拉格朗日乘子作为边际电价的含义。
  • 掌握储能状态方程与充放电效率模型，理解荷电状态（state of charge, SOC）的跨时段耦合如何排除逐步贪心的最优性。
  • 理解可再生能源预测误差的处理方式：场景采样、备用容量与鲁棒约束，以及它们对奖励设计的影响。
  • 会设计需求响应的效用表达，说明价格信号如何将可调负荷纳入平衡。
  • 能设计包含运行成本、功率不平衡与 SOC 越界的组合奖励，并识别几类典型退化策略。

背景与动机

能源管理的核心矛盾是实时功率必须平衡与可再生能源出力不可控之间的冲突。

在包含分布式发电、储能与可调负荷的能源系统里，运行目标是在满足功率平衡的前提下最小化运行成本。传统经济调度把问题写成凸优化，用等微增率原则求解，几分钟到一小时的调度周期内表现良好。当可再生能源占比上升后，两个变化打破了经典方案的前提：净负荷的波动幅度与时间尺度同时增加，预测误差使“先优化后执行”的开环结构失去精度；分布式主体的数量增加，集中求解的信息成本与隐私约束上升。

多智能体强化学习的引入方式分两种。其一是替代调度器：每个发电单元或区域作为智能体，观测本地状态与价格信号，直接输出出力与充放电功率。其二是替代价格形成机制：学习主体对价格变动的响应，由环境侧负责平衡校验。两种方式的共同技术难点是时间耦合：储能今天少充的电会让明天多花成本，策略必须把跨时段约束纳入价值估计。与交通信号任务的差别在于状态是连续电量、耦合由物理功率平衡强制，而不平衡的代价在现实中远高于经济性波动，奖励中必须优先保证可行性。

核心原理

本章原理分四层：静态经济调度的最优性、储能的动态耦合、不确定性下的应对、以及分解到多个决策主体的方式。

1. 经济调度与等微增率原则

给定一期内的负荷需求，调度问题最小化总发电成本并满足功率平衡。

minP Σg Cg( Pg ) s.t. Σg Pg = D + Ploss， Pgmin ≤ Pg ≤ Pgmax Cg 为机组 g 的成本函数，通常取 ag Pg2 + bg Pg + cg；D 为总负荷；Ploss 为网损；上下限为机组物理约束

构造拉格朗日函数并对每个 Pg 求导，得到最优性条件：对于未达限的机组，边际成本 C′g(Pg) 全部相等，且等于功率平衡约束的乘子 λ。λ 的物理含义是增加一单位负荷所需的边际成本，即现货电价的定价基础。等微增率原则提供了两个直接用途：作为强化学习的基线调度器，以及作为诊断工具，检查策略的出力分配是否偏离最优结构。约束起作用的机组（顶到上下限）脱离等差数列，处理方式是先把受限机组出力固定，再对剩余机组应用原则。

多主体的分解正是从这里开始：若每个机组按“本地边际成本等于全网价格 λ”决策，网络通过迭代调整 λ 达到全局最优。强化学习可以替代该迭代：策略以当前价格与本地状态为观测，输出出力，价格由环境侧的平衡缺口反馈调整。学习策略的优势在于成本函数未知或随时间变化时无需重新建模，缺点是收敛质量的保证弱于凸优化。

2. 储能动态与跨时段耦合

储能把电能的时间价值显性化，其状态方程引入了跨时段约束。

SOCt+1 = SOCt + ηc Pc,t Δt − ( Pd,t / ηd ) Δt ， SOCmin ≤ SOCt ≤ SOCmax Pc,t、Pd,t ≥ 0 为充电与放电功率（互斥）；ηc、ηd ∈ (0, 1] 为充放电效率；SOC 单位为能量，容量归一化后取值常见区间为 0.1 至 0.9

两个细节塑造了策略的行为空间。第一，充放电互斥：同一时刻同一电池只能处于一种模式，若策略输出两个非零功率，需要投影到互斥集，投影后等效效率会下降，实现中必须显式处理。第二，效率不对称：充电时乘 ηc、放电时除 ηd，往返一次的能量损失为 1 − ηc ηd，通常在 5% 至 15% 之间，这将阻止策略进行无意义的反复充放，但若价差足够大，套利行为仍是最优的。

跨时段耦合意味着逐步贪心不再最优：在净负荷低谷时充电会暂时降低“低买高卖”的即时收益，其价值在数小时后体现。策略需要长视野价值估计，折扣因子的选择和回合长度在这里比前面的任务更关键。回合长度推向一天（数百步）时，可引入时间特征（时段编号的正余弦编码）帮助策略区分电池价值较高的时段。

3. 不确定性与备用容量

负荷与可再生能源的预测误差在实时阶段表现为功率缺口。

Pimb,t = Σg Pg,t + Pre,t − Dt − Pc,t + Pd,t ， 备用： Σg min( Pgmax − Pg,t, rg ) ≥ Rt Pimb 为功率不平衡量，正值表示供大于求；Pre 为实际可再生出力；rg 为机组可提供的旋转备用；Rt 为系统所需备用容量

不平衡量的绝对值进入奖励作为可行性惩罚，权重需要高于任何经济项，使策略优先学会功率平衡。备用约束处理预测误差：当可再生出力高于预期时，机组需要有能力下调；低于预期时上调。学习者处理不确定性有两条路线。场景采样把预测误差建模为分布，训练时每回合采样不同实现，策略学到跨场景稳健的行为。鲁棒约束把最坏情形纳入优化，训练更保守但在极端事件下可靠。两条路线的代价都体现为运行成本上升，评估时需要同时报告期望成本与最坏场景成本。

4. 需求响应与价格弹性

可调负荷把消纳能力变成决策变量，需求响应因此与储能互补。

Uj( dj , tj ) = uj( dj ) − πt · dj ， dj ∈ [ djmin, djmax ] dj 为负荷 j 在当前时段的用电量；uj 为其用电效用（凹函数，常用对数或二次形式）；πt 为电价

用电效用取凹函数保证边际价值递减：用电越多，最后一单位的价值越低。负荷在低电价时段增加用电（例如提前制冰、推迟充电），在高电价时段削减，削峰填谷因此由效用与价格的比较产生。学习型需求响应把“效用减价格”写进个体奖励，策略自行学习在不同价格下的用电安排；与储能配合时可以分工：储能处理秒级至分钟级的快速平衡，可调负荷处理数十分钟级的能量转移。

5. 多主体分解与价格机制

把调度权分给多个主体时，价格成为协调的公共信号。

分解方案的基本结构是双层迭代：下层各主体在给定价格下优化自身目标，上层根据总不平衡调整价格。对偶分解的收敛条件依赖问题的凸性；当主体行为由神经网络表示时，上层的价格更新可以退化为简单的比例控制：不平衡为正（供大于求）降价，为负加价。策略在训练中面对的是随其他主体行为变化的价格，属于非平稳环境，训练技巧与第 047 章的对战类似：冻结部分主体的策略、轮流更新，或为价格加入噪声以提高鲁棒性。评估时应报告两个层面的指标：系统的功率不平衡与运行成本，主体的个体成本分布。

实现思路与设计

实现采用一天 288 步（5 分钟粒度）的轻量微网仿真：光伏、两台可调机组、一个储能单元与一组可调负荷。

1. 环境循环

每一步：采样负荷与光伏的实现值；策略输出机组出力、储能充放电与负荷调整；环境计算不平衡并更新价格；按成本函数结算奖励；更新储能 SOC；记录成本与不平衡时间序列。回合结束时统计总成本、不平衡量平方和、SOC 越界次数与峰值负荷。

3. 网络结构与训练要点

策略输入包含本地出力能力、储能 SOC、当前价格、时段编码与需求预测信息。设备类型不同的主体按类型分组共享参数；同类型机组可参数共享以减少样本需求。集中式评论家读取全部主体状态与全网不平衡量，训练时对不平衡的信用分配较直接。探索噪声施加在出力上，经过上下限裁剪与充放电互斥投影后执行，保证样本可行。价格由环境按比例控制更新，策略对价格变化的响应在训练中自然涌现。

4. 与第 050 章的差异点

交通信号的状态是离散队列，能量管理的状态是连续电量与功率，后者带跨时段耦合且约束是等式（功率平衡）；表 050 的奖励以排队代理延误的量级衡量，本章的奖励以成本与不平衡平方衡量，可行性惩罚的重要性高得多。协同结构也不同：交通的协同来自车流移动的物理耦合，能源的协同来自共同满足一个等式约束，后者对价格信号的依赖更强。

关键代码与解读

三段代码分别实现储能动力学、等微增率基线调度、以及含不平衡惩罚的奖励。

片段 1：储能状态更新与互斥投影

import numpy as np

class Battery:
    """储能单元：状态方程、效率与互斥投影。"""
    def __init__(self, capacity=20.0, soc=0.5, eta_c=0.95, eta_d=0.95,
                 dt=300.0, p_max=4.0, soc_min=0.1, soc_max=0.9):
        self.cap, self.soc = capacity, soc
        self.eta_c, self.eta_d = eta_c, eta_d
        self.dt, self.p_max = dt, p_max
        self.min, self.max = soc_min, soc_max

    def project(self, p_c, p_d):
        """把策略输出投影到互斥可行集：同时充放时保留净方向。"""
        p_c, p_d = max(0.0, float(p_c)), max(0.0, float(p_d))
        net = p_c - p_d                      # 净功率决定最终方向
        p_c, p_d = max(0.0, net), max(0.0, -net)
        return (min(p_c, self.p_max), min(p_d, self.p_max))

    def step(self, p_c, p_d):
        p_c, p_d = self.project(p_c, p_d)    # 投影在前，保证状态更新可行
        # 充电乘效率、放电除效率：往返效率为 eta_c * eta_d
        energy = (self.eta_c * p_c - p_d / self.eta_d) * self.dt
        raw = self.soc * self.cap + energy
        clipped = float(np.clip(raw, self.min * self.cap, self.max * self.cap))
        violation = abs(raw - clipped) / self.cap   # 越界量用于惩罚，静默截断会丢失诊断信息
        self.soc = clipped / self.cap
        return violation

解读：互斥投影把策略输出映射到物理可行集，同时充放时按净功率处理，避免同一时刻两种模式并存带来的双重效率损失。越界量以比例形式返回，使奖励可以区分“轻微越界”与“严重越界”，也便于诊断策略是否在学会边界躲避；静默截断会丢失这一信息。SOC 以比例存储、以能量计算，两个单位的使用位置明确，减少换算错误。dt 取 300 秒与 5 分钟粒度一致，功率乘时间得到能量。

片段 2：等微增率基线调度

def economic_dispatch(demand, caps, costs, tol=1e-6, iters=60):
    """等微增率原则：二分搜索价格 lambda，使总出力匹配需求。"""
    a = np.array([c[0] for c in costs])
    b = np.array([c[1] for c in costs])
    lo, hi = 0.0, 10.0
    for _ in range(iters):
        lam = 0.5 * (lo + hi)
        # 每家机组的边际成本等于价格时取最优出力：P = (lam - b) / (2a)
        p = np.clip((lam - b) / (2 * a), 0.0, caps)
        total = p.sum()
        if abs(total - demand) < tol:
            break
        if total < demand:                 # 出力不足说明价格偏低
            lo = lam
        else:
            hi = lam
    return p, lam

解读：二分法的单调性由边际成本递增保证：价格越高总出力越大。出力裁剪到上下限后，被裁剪的机组不再是边际机组，其边际成本低于或高于价格，等价于把约束起作用的机组固定在边界上，与理论处理一致。返回的价格 λ 可作为策略的观测特征与基线对比量。迭代次数的上限与容差共同控制精度，单元测试时可用解析解对照。该基线只处理单时段，把它扩展到多时段时需要为储能引入跨期价格，属于经典方法的困难点，也是学习方法的切入空间。

片段 3：奖励与价格更新

def energy_reward(gen, renew, demand, bat, viol, cost_coeff,
                 w_imb=10.0, w_soc=5.0, w_cost=1.0):
    """奖励：运行成本 + 不平衡惩罚 + SOC 越界惩罚。"""
    # 机组运行成本按二次形式结算，与基线调度同一口径
    cost = float(sum(c[0] * p ** 2 + c[1] * p + c[2]
                     for p, c in zip(gen, cost_coeff)))
    imbalance = float(gen.sum() + renew - demand - bat["p_c"] + bat["p_d"])
    r = -w_cost * cost - w_imb * imbalance ** 2 - w_soc * viol
    info = {"cost": cost, "imbalance": imbalance, "soc": bat["soc"]}
    return r, info

def price_update(price, imbalance, step=0.05, lo=0.0, hi=1.0):
    """比例价格更新：供大于求降价，供不应求加价，限幅保证平稳。"""
    new_price = price - step * imbalance          # 不平衡为正（过剩）压价
    return float(np.clip(new_price, lo, hi))

解读：平方形式的不平衡惩罚对大幅缺口给出快速上升的代价，权重 10.0 使单位缺口的代价高于机组的边际成本量级，可行性优先级由权重结构保证。SOC 越界惩罚独立成项；两类违规的成因不同，分开惩罚便于策略区分。价格按比例更新，负号方向使过剩降价、短缺加价，与经济学直觉一致；限幅避免价格在极端缺口时剧烈波动，训练中价格的分布也更稳定。信息字典中的三项构成标准诊断面板：成本、不平衡与电量水平。

常见坑

  • 充放电同时发生：策略输出两个正功率时未做互斥投影，效率被双重损失或能量凭空消失。症状是储能利用率异常高而系统成本不降。修复：状态更新前执行净功率投影，并把投影前后的差异计入诊断。
  • 不平衡惩罚权重过低：策略以牺牲平衡换取低成本，训练指标好看而物理不可行。症状是奖励上升且不平衡量长期非零。修复：不平衡权重设为成本量级的数倍，并将不平衡时间占比纳入评估。
  • SOC 不进入观测：策略无法判断储能剩余能量，末端时段频繁越界或闲置。修复：SOC 与时段编码同时作为观测，保证策略能感知跨时段价值。
  • 训练用预测值评估用实现值：训练阶段以预测当真值，评估阶段误差暴露导致行为失效。修复：训练时按分布采样误差并混入训练集，评估固定随机种子集合覆盖多种误差实现。
  • 折扣因子过小：储能的跨时段收益被折扣抹平，策略退化为逐步贪心，峰谷套利消失。修复：折扣因子接近 1，或采用整回合平均回报的评估口径。

    提示
    先假设两台都未达限，边际成本相等给出 P1 与 P2 的线性关系，与总和为 12 联立求解；若某机组越界则固定到上限后重解，最后核对 Kuhn-Tucker 条件。
  2. 推导题：推导储能往返效率对套利收益的影响，给出在峰谷价差为 Δπ 时交易有利可图的条件式。★★
    提示
    低谷充电买入 πlow、高峰放电卖出 πhigh，每单位循环的能量损失使实际可卖电量为 ηcηd，获利条件为 ηcηdπhigh > πlow。价差不足时最优策略是不动作，这能解释训练后期储能闲置的现象。
  3. 改参数并预测：把不平衡惩罚从 10 提高到 100，预测总成本、不平衡时间占比与储能循环次数三条指标的变化方向。★★
    提示
    不平衡下降、成本上升、储能循环次数增加（被用于频繁修补缺口）。权重过高时策略会牺牲经济性换取绝对平衡，评估需同时报告两个维度。
  4. 设计题：为一天期的调度任务设计时段特征与回合终止条件，说明如何避免策略在回合末端把电量消耗殆尽。★★★
    提示
    时段特征可用正余弦编码表达日周期，终止条件覆盖完整 24 小时。末端电量可通过设置终值约束（终止时 SOC 不低于起点附近水平）或末端时段的额外惩罚项实现，前者更接近实际调度惯例。
  5. 实验设计：比较“固定价格”与“比例响应价格”两种环境设置下的学习曲线，说明价格信号对多主体协调的作用与潜在不稳定性。★★★
    提示
    固定价格下主体之间缺少协调信号，总不平衡更大；比例价格下协调改善但价格与出力可能形成振荡。评估需要同时看成本、不平衡方差与价格波动幅度。

小结

  • 经济调度的最优性条件是等微增率原则，功率平衡约束的乘子即边际电价；约束起作用的机组固定在边界后对其余机组应用原则。
  • 储能状态方程引入跨时段耦合，充放电互斥需要投影处理，往返效率限制套利条件，策略必须具备长视野价值估计。
  • 不确定性用场景采样与备用容量应对，不平衡惩罚权重需高于经济项，保证可行性优先。
  • 需求响应以凹效用与价格比较产生削峰填谷，与储能形成快慢互补；多主体分解用价格做协调信号，训练需处理价格引起的非平稳。
