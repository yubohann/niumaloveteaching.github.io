第一篇 · CTDE 基础与核心算法

第 014 章：多智能体软演员批评家MASAC

把最大熵强化学习引入 CTDE：目标回报中加入策略熵奖励，评论家学习软价值，温度系数自适应调节。MASAC（Multi-Agent Soft Actor-Critic）继承了 MATD3 的双评论家骨架，又用随机策略取代外加探索噪声，本章给出软贝尔曼方程、三条损失的设计与工程要点。

  • 主题：最大熵 RL / 连续控制
  • 关键公式：V(s) = 𝔼a∼π[ Q(s, a) − α log π(a | o) ]
  • 预计学时：55 分钟
  • 前置章节：第 013 章

学习目标

  • 理解最大熵目标中温度系数 α 的作用：控制探索强度，并让价值函数对动作噪声更鲁棒。
  • 掌握软贝尔曼方程与软策略改进的 KL 形式，理解其与标准演员批评家的差异点。
  • 掌握 MASAC 的三条损失：双软评论家回归、按智能体的随机策略改进、温度自适应损失。
  • 会实现高斯策略的重参数化采样与 tanh 变换的对数概率修正，避免熵估计错误。
  • 能对比 MASAC 与 MATD3、MAPPO 的探索机制与样本效率，设计温度调节敏感性实验。

背景与动机

第 011 章的 MATD3 用取最小抑制高估，但探索仍依赖外加的高斯噪声，策略本身是确定性的。最大熵强化学习换了一个角度：把"策略的随机性"写进优化目标，让策略在最大化回报的同时保持尽可能大的熵。这个看似简单的改动带来三方面收益：探索由目标内生驱动，噪声尺度不再需要人工设计；价值函数在动作邻域内被平滑，对评论家的逼近误差更鲁棒；策略可以保持多模态，在存在多个等价协作模式的任务中避免过早坍缩到单一模式。

MASAC（Multi-Agent Soft Actor-Critic）是这套目标在 CTDE 框架下的实现：每个智能体持有随机策略与集中式软评论家对，评论家输入全体动作，温度系数 α 按目标熵自动调节。执行期每个智能体从策略分布采样动作，跨智能体仍无通信。本章与第 011 章的代码呈镜像关系，双评论家与软更新直接复用，替换的是策略类型与目标构造中的熵项，逐项对照即可看清最大熵的增量。

核心原理

本节给出最大熵目标、软贝尔曼方程、策略改进的 KL 形式、温度自适应机制，以及与 MATD3 的对照。

1. 最大熵目标与温度系数

最大熵目标在每步回报上追加策略熵奖励：

J(π) = 𝔼τ∼π [ Σt γt ( R(st, at) + α · H( πi(· | oi,t) ) ) ] H 为策略熵; α > 0 为温度系数, 度量"一单位熵值多少回报"。α 越大探索越强。多智能体版本中各智能体的熵项独立进入各自的目标

熵项的梯度作用可以这样理解：策略分布越集中，熵越小，熵项为策略提供"铺开概率质量"的梯度；当铺开的边际回报损失超过 α 时，策略自然回缩。探索强度因此由 α 与回报尺度共同决定，外接噪声的衰减计划获得了解析替代。

2. 软贝尔曼方程与策略评估

在最大熵目标下，价值与动作价值的定义中加入熵项，形成软贝尔曼方程：

Q(s, a) = R(s, a) + γ 𝔼s′[ V(s′) ]， V(s) = 𝔼a∼π[ Q(s, a) − α log π(a | o) ] 等价地 Q(s, a) = R + γ 𝔼[ Q(s′, a′) − α log π(a′ | o′) ]，a′ 为目标策略的采样动作。评论家目标比 MATD3 多一项 −α log π，少一项目标平滑噪声（随机采样天然覆盖邻域）

多智能体版本中，评论家输入是全体动作的拼接，熵项按"被评估智能体自己的 log 概率"计算；即智能体 i 的评论家目标为 R + γ ( minj Q′i,j(s′, ã′) − αi log π′i(ã′i | o′i) )。取最小与熵项的组合意味着双重悲观化：价值下界再减去自身随机性的惩罚，评论家目标整体偏低，这与第 011 章的高估抑制一脉相承。

3. 软策略改进与温度自适应

策略改进步骤在 KL 投影形式下可解：

πnew = argminπ′ KL( π′(· | o) ‖ exp( Q(s, ·) / α ) / Z(s) ) Z(s) 为归一化常数。对高斯策略族, 该目标等价于重参数化的最小化损失: 𝔼[ α log π(a|o) − Q(s, a) ]，a 由重参数化采样。实现中把 Q 的最小评论家估计代入

温度的自动调节把 α 从超参变为可学习量，其目标是最小化"当前策略熵与目标熵 H̄ 的偏差"：

L(α) = 𝔼o[ −α · ( log π(a | o) + H̄ ) ]， H̄ 取动作维度负值（H̄ = −dim(Ai) × κ，κ 常取 0.5 至 1） 策略熵低于目标熵时括号项为正, L 对 α 的梯度推动 α 增大(探索增强); 高于目标时反向。α 由此自动跟随训练阶段的速度

5. 数值算例：软价值与温度档位

取两动作、Q = (2, 0)，温度取三档，按软策略 π(a) ∝ exp(Q(a)/α) 与软价值 V = Σ π (Q − α log π) 计算（数值经程序核对，并与闭式 V = α log Σ exp(Q/α) 完全一致）：

α软策略 π软价值 V与最优动作价值的差距
0.5(0.9820, 0.0180)2.00910.0091
1.0(0.8808, 0.1192)2.12690.1269
2.0(0.7311, 0.2689)2.62650.6265

表读法：α 越大动作分布越平、软价值越高。超出的部分属于熵奖励的折算，不来自更好的动作：V 超过 max Q 的差额等于 α log(1 + exp(−ΔQ/α))，α = 0.5 且 ΔQ = 2 时只有 0.0091，α = 2 时膨胀到 0.6265。选择 α 时要把这部分账面增值与真实探索收益分开看待，策略评估统一使用环境回报口径。

6. 数值算例：软贝尔曼不动点的闭式核对

取单状态两动作、奖励 R = (1, 0)、γ = 0.9、α = 1。软贝尔曼方程的自洽条件为 V = γ V + α log(e1/α + e0/α)（动作价值由 R + γV 直接给出），不动点为 V = α log(e + 1) / (1 − γ)。迭代计算收敛到 V = 13.1326，闭式代入 1 × 1.3133 / 0.1 = 13.1326，两者一致；忽略熵项的常规最优价值为 1 / 0.1 = 10.0000。差额 3.1326 是熵奖励按 (1 − γ)−1 放大的年金额度：每步的固定熵收益在折扣下积累为常数倍。该对照解释了最大熵方法的价值尺度膨胀，同一任务下软价值天然高于常规价值，跨方法比较时统一用环境回报口径。

7. 熵的尺度感与探索失效边界

高斯策略的微分熵 H = ½ log(2πe σ²)，数值经程序核对：σ = 0.2 时 H = −0.19（窄分布的微分熵可以是负值），σ = 0.5 时 H = 0.73，σ = 1.0 时 H = 1.42。两个边界由这组数字刻画：其一，α = 0.05 时一维单位方差策略的熵奖励折算仅约 0.07 回报，远小于典型单步回报，探索压力主要来自温度自适应机制；其二，回报尺度很大（单步 10 量级）时，同一 α 下策略趋于坍缩到低方差，温度损失承担主要调节职责，观察 α 轨迹与策略熵曲线是第一诊断手段。

失效模式集中三处：回报量级被外部修改（例如奖励缩放调整）时 α 需要重新适应，适应期内行为可能骤变；评估采用分布均值时，部署行为与训练期采样存在口径差异，对动作敏感的任务应同时报告两种口径的回报；目标熵常数与动作维度脱钩（换任务时未同步）会让策略长期处于过探索或欠探索状态，表现为回报平台或曲线高噪。此外，多智能体版本中若把团队层面的平均熵代入目标熵检查，会把"某些智能体高熵、另一些低熵"的异质分布平均掉，掩盖单智能体的坍缩，检查应按智能体分组进行，分组统计更能暴露坍缩个体。

实现思路与设计

本节给出 MASAC 的组件与配置。数据层与第 010、011 章完全共用；网络层替换策略分布并增加温度参数。

与第 011 章的差异点集中在三处：策略接口从确定性映射变为分布对象；评论家目标加入 −α log π 项；新增温度参数的损失与优化器。目标平滑噪声被删除，因为目标动作本身来自随机采样，已包含邻域覆盖；两套噪声同时保留会导致目标方差过大。

设计决策：目标熵与动作维度挂钩的理由

目标熵的绝对数值需要与动作维度匹配：维度越高，均匀分布的熵越大。以 −dim(Ai) 为基线，使"每维平均保留约 e 级别的分辨粒度"成为可比较的常数；缩放因子 κ 提供单一旋钮，探索不足时下调（允许更集中），欠稳定时上调。该设计与温度学习率共同构成探索强度的一组调节杆，实验时先动 κ 再动学习率，避免两个旋钮互相掩盖。

温度与回报尺度的耦合

软目标中回报与熵奖励的相对权重由 α 与回报尺度的比值决定：把回报整体乘上常数 c，等价于把探索压力 α 除以 c。因此换用回报量级更大的任务时，α 的平衡位置随回报尺度等比例上移，若不重设 α0，适应期内的有效探索压力会低一个档位。核对方法：记录 α 与单步平均回报的比值曲线，跨任务对照时该比值比 α 的绝对值更有可比性。这条耦合也是软价值与真实回报口径分离的深层原因：α 变化会同时改变账面价值与策略行为，读实验结论时两者要分开陈述。

α 初值与预热期的配合

α0 = 0.05 在回报量级为单位的任务上对应很弱的熵奖励（按第 7 小节的折算约 0.07 回报），预热期内动作方差主要由策略网络初始 log_std 提供；基线的限幅上界取 0，对应初始标准差 1，预热样本天然覆盖动作范围。若把限幅上界调低（例如 −1），预热数据集中到动作空间中心区域，评论家在边缘区域缺少监督，温度抬升后新探索区域的价值估计质量差，表现为"探索增强与回报下降同时出现"的矛盾现象。限幅与 α0 的配合关系应在实验记录中一并声明。

温度参数的组织方式有每智能体独立与全局共享两种。独立温度允许不同角色采用不同探索强度（侦察型智能体高熵、执行型智能体低熵），代价是温度参数随 N 线性增长，且不同智能体的熵曲线会掩盖策略本身的分化；共享温度参数量不随 N 变化，但在异构角色任务中把探索预算平均化。基线按每智能体独立设置，与第 013 章异构兼容的取向一致，共享版本留作消融。

关键代码与解读

片段 1：tanh 压缩的高斯策略

import torch
import torch.nn as nn

class GaussianActor(nn.Module):
    """随机策略: 对角高斯采样, tanh 压缩到有界区间。"""
    def __init__(self, obs_dim, act_dim, act_limit=1.0, hidden=64):
        super().__init__()
        self.act_limit = act_limit
        self.trunk = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
        )
        self.mu = nn.Linear(hidden, act_dim)          # 均值头
        self.log_std = nn.Linear(hidden, act_dim)     # 对数标准差头

    def forward(self, obs):
        h = self.trunk(obs)
        # 限幅: 标准差过小会熵塌缩, 过大会退化为无信息噪声
        std = self.log_std(h).clamp(-4.0, 0.0).exp()
        return torch.distributions.Normal(self.mu(h), std)

    def sample(self, obs):
        dist = self.forward(obs)
        u = dist.rsample()                            # 重参数化: 梯度可穿透采样
        a = torch.tanh(u) * self.act_limit            # 压缩到 [-limit, limit]
        # tanh 变换的 log 概率修正: 密度变换的雅可比行列式项
        logp = dist.log_prob(u) - torch.log(1.0 - torch.tanh(u) ** 2 + 1e-6)
        logp = logp.sum(dim=-1)                       # 各动作维独立, 求和
        return a, logp

解读：三处实现细节决定熵项是否正确。（1）rsample 使用重参数化采样，梯度可穿过随机采样点回流到均值与方差头；若误用 sample，策略损失对分布参数的梯度信号消失。（2）tanh 压缩改变概率密度，log_prob(u) 需要减去变换的雅可比项 log(1 − tanh²(u))；漏掉该项会让熵估计与真实策略熵偏差随动作靠近边界而放大。（3）log_std 限幅是稳定性措施：无限制时训练中期容易塌缩到极小的方差，探索突然消失，回报曲线出现"阶梯式"停滞。上述实现以相应开源框架的 SAC 接口习惯为参照。

片段 2：软评论家目标

def soft_target(q1_t, q2_t, target_actors, ns, nobs_next, done, rew,
                alpha, agent_idx, gamma=0.95):
    """软目标: r + gamma * (min 双 Q 减自身熵项)。"""
    with torch.no_grad():
        next_acts, next_logp = [], []
        for i, ta in enumerate(target_actors):
            a_i, lp_i = ta.sample(nobs_next[:, i])    # 目标动作来自目标策略
            next_acts.append(a_i)
            next_logp.append(lp_i)                    # 保留自身 log 概率
        a_next = torch.cat(next_acts, dim=-1)
        q_min = torch.minimum(q1_t(ns, a_next), q2_t(ns, a_next))
        # 熵项只扣被评估智能体自己的对数概率, 队友的采样随机性不进入该项
        entropy = alpha[agent_idx] * next_logp[agent_idx]
        y = rew[:, 0] + gamma * (1.0 - done[:, 0]) * (q_min - entropy)
    return y

解读：目标构造与第 011 章 twin_critic_target 逐行对照，差异只有两处。（1）目标动作从"目标演员确定性输出加截断噪声"变为"目标策略分布采样"，采样天然覆盖动作邻域，平滑噪声因此删除。（2）取最小之后减去 α log π 项：符号为负，软价值在"随机性大的动作"上被扣分，等价于要求高熵资格门槛。该函数以智能体 i 为视角书写，实际调用时按评论家归属替换 i；队友的 next_logp 不进入智能体 i 的熵项，保持"熵按智能体归属"的分配原则。

片段 3：演员损失与温度损失

def actor_and_alpha_loss(actor_i, q1, q2, alpha_log, target_entropy, batch, act_scale):
    """策略损失: 重参数化 + 最小评论家; 温度损失: 熵偏差回归。"""
    s, obs_i, others_acts = batch
    a_i, logp = actor_i.sample(obs_i)
    all_acts = torch.cat([others_acts.detach(), a_i / act_scale], dim=-1)
    q_min = torch.minimum(q1(s, all_acts), q2(s, all_acts))
    # 最小化 alpha*logpi - Q: KL 投影目标的等价形式
    loss_pi = (alpha_log.exp().detach() * logp - q_min).mean()
    # 温度: 熵高于目标时压低 alpha, 低于时抬高; alpha_log 保证恒正
    loss_alpha = -(alpha_log.exp() * (logp.detach() + target_entropy)).mean()
    return loss_pi, loss_alpha

解读：两条损失的形式来自各自的推导。（1）loss_pi 中 α 被 detach：温度由独立损失调节，策略损失只把 α 当权重，两个优化过程互不渗透；若让梯度穿过，策略可以通过"压低 α"粉饰熵项，温度的学习目标被破坏。（2）loss_alpha 用 logp.detach() 把策略熵视为观测量；α 以对数参数化（alpha_log.exp()）保证恒正，这也是数值稳定性的常见做法。（3）动作归一化与评论家入口约定保持一致，与第 010 章的拼接纪律相同。

常见坑

  • 漏掉 tanh 的 log 概率修正。症状：熵项数值与真实分布不符，温度快速贴到上界或下界。原因：密度变换项缺失。修复：单元测试对纯高斯输出（绕过 tanh）比较 logp 与解析值，再打开 tanh 检查修正项符号。
  • 用 sample 代替 rsample。症状：策略损失不下降或梯度恒为零。原因：采样点与参数间的梯度路径断裂。修复：检查分布 API 的重参数化版本，并断言策略梯度范数非零。
  • 熵项归错智能体。症状：温度参数发散，策略方差失衡。原因：把队友的对数概率混入自身熵项。修复：熵项一律使用被评估智能体自己的 log π，测试中构造两智能体方差差异显著的样本做对拍。
  • 目标熵配置失当。症状：策略陷入高熵无目的游走，或方差塌缩失去探索。原因：H̄ 与动作维度、回报尺度不匹配。修复：先按 −dim(A) 基线运行，观察策略熵曲线长期位置，再以 0.5 步长调整缩放因子 κ。
  • 评估期采样引入高方差。症状：评估曲线毛刺明显，误判训练不稳。原因：评估用随机采样动作。修复：评估固定为分布均值，并在记录中声明口径；如需评估"随机策略期望回报"，增加评估回合数。

练习与思考

  1. 两动作情形，Q(s, a1) = 2、Q(s, a2) = 0，策略概率 π = (0.5, 0.5)，α = 0.2。计算软价值 V(s) 与不加熵项时的期望价值，比较差异。★
    提示
    加熵：V = 0.5×2 + 0.5×0 − 0.2×log 2 ≈ 1 − 0.139 = 0.861；不加熵为 1。熵项在均匀分布上扣分，鼓励策略向高价值动作倾斜的同时保底探索。
  2. 把目标熵从 −dim(A) 改为 −0.5·dim(A)，预测训练早期策略熵、动作方差与回报曲线的变化。★
    提示
    目标降低后 α 会被调节到较小值，策略更快集中到高价值动作：早期熵下降更快、动作方差更小；若任务需要长探索，回报曲线可能更早停滞。该实验校准 κ 的直觉。
  3. 推导 tanh 压缩后的 log 概率修正：由 u ∼ 𝒩(μ, σ²) 与 a = tanh(u)，写出 p(a) 与 p(u) 的关系及修正项表达式。★★
    提示
    密度变换法则 p(a) = p(u) / |da/du|，da/du = 1 − tanh²(u)，取对数即 log p(a) = log p(u) − log(1 − tanh²(u))。动作接近边界时修正项趋向负无穷，截断保护不可省略。
  4. 设计实验比较探索机制：MASAC 与 MATD3 在同一任务上，记录训练期动作分布熵（对动作做直方图估计）、回报曲线与不同探索噪声档位下 MATD3 的敏感性。给出预期结论。★★
    提示
    预期 MATD3 表现对噪声尺度敏感，过低探索不足、过高回报受损；MASAC 的熵曲线自动适应，对噪声超参免设。结论表述应附带动作熵的度量方案以支撑"内生探索"的说法。
  5. 设计题：给出温度学习率与目标熵缩放 κ 的二维网格实验方案（各取三档，共九组），说明每组记录什么量、如何判定"温度调节处于健康区间"，以及极端配置的预期症状。★★★
    提示
    记录 α 轨迹、策略熵、回报与动作方差；健康区间表现为 α 有界波动、熵贴近目标附近。极端症状：学习率大加 κ 小导致 α 爆炸、熵失控；学习率小加 κ 大导致 α 长期不动、方差塌缩。

小结

  • 最大熵目标在回报上追加 α 加权的策略熵，探索由目标内生驱动；温度自适应把 α 从超参变为可学习量。
  • 软贝尔曼方程在评论家目标中引入 −α log π 项；多智能体版本对该项按被评估智能体的归属计算。
  • MASAC 复用 MATD3 的双评论家与软更新骨架，替换策略分布与目标构造；目标平滑噪声被随机采样替代。
  • 实现关键：重参数化采样、tanh 密度修正、熵项归属、温度 detach，四处错误都会破坏训练稳定性。
