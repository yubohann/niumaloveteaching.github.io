第四篇 · 高级机制与研究专题

第 065 章：多智能体协同建图

多台机器人分头探索并维护共同占据栅格地图：用对数几率做贝叶斯更新、用因子图优化位姿、用一致性规则融合地图，并用集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）协调探索分工。

  • 主题：占据栅格与位姿图 / 分布式地图融合
  • 关键公式：lt = lt−1 + log(p(m|z)/(1−p(m|z))) − l0
  • 预计学时：65 分钟
  • 前置章节：第 064 章

学习目标

  • 掌握占据栅格（occupancy grid）的对数几率更新规则，理解逆传感器模型（inverse sensor model）的设计与数值截断的作用。
  • 理解重复计入同一观测导致的过度自信（overconfidence）问题，掌握多次观测计数上限与独立融合两类修复手段。
  • 掌握位姿图（pose graph）优化的最小二乘形式，理解分布式高斯赛德尔（Gauss-Seidel）迭代逼近全局解的原理。
  • 能实现一致性加权的双机地图融合，说明协方差交叉（covariance intersection）为何能避免重复计数。
  • 能设计探索奖励与对比实验，比较独立前沿探索与 CTDE 分工的覆盖速度与地图一致性。

背景与动机

单机建图是成熟问题：机器人一边估计自身轨迹一边用激光雷达更新占据栅格。多机场景新增三层困难。第一层是地图一致性：各机器人从不同起点出发，里程计漂移使各自地图坐标系错位，融合前必须对齐。第二层是观测重复计入：把两份包含相同环境证据的地图直接相乘，相当于同一观测被使用两次，贝叶斯更新会高估置信度，栅格概率被推向 0 或 1 的饱和区，后续观测无法再修正。第三层是探索分工：多台机器人应覆盖不同区域，若都涌向同一前沿（frontier），建图效率不升反降。

本章与第 064 章的差别：状态从高斯过程换为全网格栅格，信息增益对象从场值换成栅格熵，核心工程问题变为对数几率一致性与位姿对齐。CTDE 训练期用全局地图评估分工收益，执行期各机器人只维护本地地图。

核心原理

本节依次建立栅格更新、一致性修复、位姿图优化与 CTDE 映射四条线索。

1. 占据栅格的对数几率更新

把地图划分为网格，每一格维护被占据的概率。为便于增量更新，用对数几率 l(m) = log(p(m)/(1−p(m))) 表示。每一次观测 z 按贝叶斯规则更新：先验几率乘似然比。当观测噪声较小时，逆传感器模型近似为分段常数：光束扫过的格子向空闲方向更新，命中点附近的格子向占据方向更新，其余格子不更新。

lt(m) = lt−1(m) + log(p(m|zt)/(1−p(m|zt))) − l0，截断于 [lmin, lmax] l0 为先验对数几率；每次更新是加法，这正是选择对数几率表示的原因

加法形式使更新成为常数时间操作。截断区间的选择决定地图的可修正性：lmin、lmax 限制单格置信度的上界，防止长时间未观测的格子锁定错误状态。

2. 过度自信与一致性修复

若两台机器人从同一区域走过并各自更新过格子，融合时把两份对数几率相加，等价于把相关证据当作独立证据。修复手段有三类：计数限制（更新次数封顶）、占用衰减（旧证据按因子指数衰减）与独立融合。独立融合用协方差交叉按权重合并两份估计，权重由各方不确定性决定，无需交叉协方差，适合分布式场景。

Σfused−1 = ωΣ1−1 + (1−ω)Σ2−1，ω ∈ (0, 1) ω 通常取使融合后行列式最小的值；相关证据被按比例折扣，避免置信度无限增长

3. 位姿图与分布式优化

把每个机器人位姿作为节点，里程计与回环约束作为边，位姿图优化求解使约束残差加权平方和最小的位姿配置：min Σ(i,j) eijTΩijeij。集中式求解需要全部边，分布式场景下每台机器人只持有自身轨迹的边与少量跨机回环。分布式高斯赛德尔迭代让每台机器人用本地边与接收到的邻居位姿更新自己的子轨迹，交替进行直至收敛，不动点与集中式解满足相同的一阶条件，收敛速度受通信拓扑约束。

4. CTDE 映射

观测含本地地图的局部窗口、自身位姿估计的不确定性、最近前沿点列表与队友通信的占据摘要；动作是朝向或前沿目标选择；奖励为团队新覆盖栅格数减去重叠覆盖惩罚与移动代价。集中式评论家输入全局地图统计与全部机器人位姿，评价分工质量。执行期机器人不需要全局地图，只需本地地图与轻量邻居摘要。评估时覆盖率与跨机一致性分开统计：重叠区域的占据分类不一致格数反映位姿对齐质量，覆盖不足与覆盖重叠则是探索分工的两类退化，需要分别归因。

5. 数值算例：截断饱和与协方差交叉融合

截断算例：某格先验对数几率 l0=0，连续命中观测每次 +0.85。第 4 次后数值为 3.4，第 5 次的理论值 4.25 被截断到 3.5，对应占据概率 1/(1+e−3.5)≈0.971。此后无论再命中多少次，数值都停在上界，格子置信度无法超过约 0.97，后续观测仍保留把错误格子翻转回来的空间。

融合算例：两台机器人对同一区域给出方差均为 1 的标量估计。若按独立证据直接相加信息（精度相加），融合精度为 1/1+1/1=2，方差降到 0.5，置信度虚增一倍；改用协方差交叉并取 ω=0.5，融合精度为 0.5×1+0.5×1=1，方差保持 1，与单份估计持平。

解读：两个算例分别对应过度自信的两种形态：截断饱和限制单格置信度上限，协方差交叉限制多源融合的置信度增量。融合方差每虚降一半，等价于把同一观测使用了两次，后续需要多一倍的证据才能纠正被锁定的错误格子。复现实验时应监控"融合后方差下降速率对重叠比例的依赖"，斜率显著小于 1 说明折扣生效。

实现思路与设计

系统分为三层：栅格层做对数几率更新与截断，图优化层维护位姿约束，策略层做前沿选择。三层以固定节奏交替运行。

设计决策：为什么奖励用新覆盖格数替代地图熵

地图熵能从信息论角度精确刻画剩余不确定性，但全网格熵的计算需要遍历每一个格子，复杂度与地图面积成正比，训练中每步执行不可承受。新覆盖格数是一次观测中新进入确定状态（越过置信阈值）的格子计数，与熵下降高度相关且计算是常数时间。代价是阈值附近的格子反复越界造成计数抖动，可用双侧滞回阈值平滑。

与第 064 章的差异：状态估计从稀疏高斯过程后验换为稠密栅格；奖励从解析可预测的信息增益换成需要真实更新的覆盖计数；新增位姿图优化与地图一致性两个工程模块。

对比分析：四种一致性修复手段

手段作用对象计算代价过度自信控制适用条件
直接独立更新无最低无单机或几乎无重叠覆盖
计数上限单格更新次数低强（硬封顶）静态环境、长时间重复观测
证据衰减全图旧证据低（按周期乘因子）中等动态环境、障碍会移动
协方差交叉融合融合时刻的双方估计中（权重搜索）强（有数学保证）分布式多机融合、通信可用

选择依据是重叠的来源：同一台机器人反复观测同一区域时计数上限最直接；队友之间证据相关时协方差交叉更合适。两类手段可以叠加，叠加时先做单机计数管理再进入跨机融合，顺序颠倒会把融合后的折扣证据重新计满，抵消折扣效果。

实现顺序的提醒：截断、计数上限与融合三者的作用点不同，调试时逐项开启并记录对数几率分布的直方图，确认每一步修正都落在预期范围内。若融合后方差仍快速下降，先检查协方差交叉的权重搜索范围是否被硬编码限制在一侧，再检查两份估计是否共享了同一批感知数据；两处都正常时再怀疑逆传感器模型的命中集合生成有偏。

关键代码与解读

片段 1：对数几率栅格更新

import numpy as np

def update_grid(log_odds, hit_cells, free_cells, count, l_hit=0.85,
                l_free=-0.4, l_min=-2.0, l_max=3.5, max_hits=8):
    """按一次扫描更新占据栅格的对数几率。
    log_odds: 全图数组；hit/free_cells: 本次观测的命中与扫过格子索引。
    """
    np.add.at(log_odds, free_cells, l_free)     # 扫过但未命中：空闲证据
    # 命中格单独计数，超过上限后不再累加，抑制相关性证据叠加
    fresh = count[hit_cells] < max_hits
    np.add.at(log_odds, hit_cells[fresh], l_hit)
    np.add.at(count, hit_cells[fresh], 1)
    np.clip(log_odds, l_min, l_max, out=log_odds)   # 置信度截断
    return log_odds, count

解读：np.add.at 处理同一格被重复索引的场景（一次扫描中多个光束命中同格），普通花式索引赋值会遗漏重复项。计数上限在加法之前检查，等价于对相关证据做折扣。空闲更新不设计数上限，原因是空闲证据的更新量本身较小，且走廊等常见区域需要持续确认。

片段 2：协方差交叉地图融合

import numpy as np

def covariance_intersection(mu1, p1, mu2, p2, steps=21):
    """按最小行列式准则融合两份相关估计。
    mu*: 估计值；p*: 方差（标量场景）。
    """
    best = None
    for omega in np.linspace(0.05, 0.95, steps):
        # 精度加权：方差小的一方获得更大权重
        prec = omega / p1 + (1.0 - omega) / p2
        var = 1.0 / prec
        mu = var * (omega * mu1 / p1 + (1.0 - omega) * mu2 / p2)
        if best is None or var < best[0]:
            best = (var, mu)
    return best[1], best[0]

解读：协方差交叉保证融合方差不超过输入方差的调和型上界，即使两份估计包含共同证据也不会过度自信。权重扫描按融合方差最小准则选点，对相关性程度不敏感。批量融合多份估计需要在单纯形上优化，规模增大时改用封闭形式近似。

片段 3：分布式位姿迭代片段

import numpy as np

def distributed_gauss_seidel(poses, edges, local_ids, iters=20):
    """分布式高斯赛德尔：仅用本地边与邻居位姿更新自身节点。
    poses: {节点: 位姿向量}；edges: (i, j, offset, weight) 约束；
    local_ids: 本机负责的节点集合。
    """
    for _ in range(iters):
        for i in local_ids:
            num = np.zeros_like(poses[i])
            den = 0.0
            for (a, b, offset, w) in edges:
                if a == i or b == i:               # 只使用与本节点相连的边
                    other = poses[b] if a == i else poses[a]
                    # offset 是观测到的相对位置，换算为对 i 的目标位姿
                    target = other + offset if a == i else other - offset
                    num += w * target
                    den += w
            if den > 0:
                poses[i] = num / den               # 加权平均即一步更新
    return poses

解读：迭代的核心是"每个节点向邻居约束的加权折中位置移动"，权重来自边的信息矩阵。只遍历本地节点与相关边，通信量随回环数量增长、与地图规模无关，这是可扩展性的来源。实际系统设置迭代上限，不设收敛阈值，避免阻塞实时控制；跨机回环稀疏时，单次迭代传播范围有限，需要多轮交替才能对齐。

常见坑

  • 地图直接相加导致饱和：两台机器人覆盖同一走廊后，栅格对数几率超过截断上界，后续观测无法翻转错误格子。修复：启用计数上限或协方差交叉融合。
  • 位姿对齐前融合地图：里程计漂移使两份地图整体错位，融合后出现"双墙"现象而不可恢复。修复：先求解位姿图，确认对齐残差低于一个栅格分辨率，再做栅格融合。
  • 错误回环未加鲁棒核：外观相似但位置不同的区域被误判为回环，位姿图把整段轨迹拉偏，地图出现难以定位的整体扭曲。症状是回环加入后残差普遍上升而局部单步误差正常。修复：对回环残差使用鲁棒核（Huber 或 Cauchy）或开关变量，并用里程计预测量做几何一致性校验后再接受回环。
  • 逆传感器模型方向错误：把光束扇形外区域误标为占据，导致地图膨胀。修复：用扇形裁剪精确生成命中与扫过格集合，并在角分辨率低时保守增大空闲区域。
  • 前沿目标振荡：两台机器人交替选择同一前沿，路径反复折返。修复：奖励中重叠惩罚与目标保留机制并用，或引入目标预约的轻量协商。
  • 并行更新产生竞态：多线程写同一栅格造成丢失更新。修复：按机器人聚合后单线程合并，或对栅格分区加锁。

练习与思考

  1. 某格先验对数几率 0，连续 6 次命中观测（每次 +0.85），计算对数几率与对应概率，再说明截断上界 3.5 何时生效。★
    提示
    6×0.85=5.1 超过 3.5，被截断；3.5 对应概率约 0.97，第 5 次起即达上界。
  2. 把更新计数上限从 8 调到 3，预测走廊区域的对数几率分布与地图可修正性的变化。★★
    提示
    上限过低使置信度普遍下降，噪声格子更易翻转；可修正性上升但地图稳定性下降，需看动态障碍场景的权衡。
  3. 推导：证明协方差交叉的融合方差落在两份输入方差之间，并说明 ω=0.5、p1=p2 时的结果。★★★
    提示
    融合精度 ω/p1+(1−ω)/p2 是两个精度的加权平均，故融合方差必在 p1 与 p2 之间。对称情形 ω=0.5、p1=p2=p 时精度为 1/p，方差为 p，与单份估计持平；这正是“同一观测不被重复计入”的含意，可对照正文融合算例。
  4. 设计实验：三台机器人从不同起点探索同一层平面，比较"独立前沿探索"与"CTDE 分工"在 3000 步内的覆盖率和地图一致性（跨机重叠区域的占据分类不一致格数）。★★★
    提示
    一致性用重叠区域分类众数偏差度量；预期分工策略覆盖率更高，一致性差异主要来自位姿对齐精度。
  5. 两台机器人对同一格的估计方差分别为 p1=1、p2=4，分别计算 ω=0.5 与 ω=0.8 时的融合方差，说明 ω 应向哪一侧移动以及最小行列式准则为何会自动实现这一偏向。★★
    提示
    ω=0.5 时精度为 0.5×1+0.5×0.25=0.625，方差 1.6；ω=0.8 时精度为 0.8+0.05=0.85，方差约 1.18。方差小的一方应获得更大权重，权重扫描以最小融合方差为准则会自动选到这一侧。

小结

  • 对数几率表示让贝叶斯栅格更新成为加法操作，截断区间决定地图可修正性。
  • 相关证据重复计入会破坏一致性，计数上限、证据衰减与协方差交叉是三把修复工具。
  • 位姿图把建图写成最小二乘优化，分布式高斯赛德尔以本地边迭代逼近集中式解，收敛速度受图直径约束。
  • 探索奖励用新覆盖格数近似信息增益，重叠惩罚抑制前沿振荡；执行期依赖本地地图与邻居摘要。
  • 数值算例把两种过度自信的形态量化：截断让单格置信度止于约 0.97，协方差交叉让相关证据的置信度增量回到单份水平。
