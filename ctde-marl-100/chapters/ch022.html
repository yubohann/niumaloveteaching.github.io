第一篇 · CTDE 基础与核心算法

第 022 章：课程学习在CTDE中的应用

本章讲课程学习（Curriculum Learning）如何组织多智能体训练的任务难度序列：从智能体数量、地图规模、对手强度到协同深度，逐维提升难度，并用成功率窗口与学习进度准则控制推进节奏。

  • 主题：训练任务编排 / 课程学习
  • 关键公式：推进条件 success_rate(窗口 W) > θ
  • 预计学时：50 分钟
  • 前置章节：第 021 章 基于奖励重塑的CTDE

学习目标

  • 理解课程学习的形式化描述：任务分布上的调度序列如何从简单分布逐步转移到目标分布。
  • 掌握多智能体课程的四类难度维度（智能体数量、观测受限程度、对手强度、协同深度）及其提升顺序。
  • 掌握基于成功率窗口与学习进度（Learning Progress）的两类推进准则，理解窗口长度对推进稳定性的影响。
  • 理解课程推进与灾难性遗忘（Catastrophic Forgetting）的关系，掌握数据保留与教师学生蒸馏两种缓解手段。
  • 能设计一个包含推进、回退、评估三条通路的课程训练流程，并说明每条通路的触发条件。

背景与动机

多智能体任务的难点常常来自协调收敛：单个智能体学会"到达目标"所需的探索量有限，但若要求两个以上智能体在同一时期具备互补技能，随机探索命中协作序列的概率随智能体数量与回合长度指数下降。直接在大规模任务上训练时，稀疏的协作成功样本不足以支撑值函数学习，训练曲线长期停留在零回报附近的平坦区间。

课程学习把任务本身当作可以顺序供给的资源：先用小规模、短回合、弱对手的版本把基础技能训练出来，再逐步提升难度，让每一阶段的新增挑战建立在已成形的技能之上。第 021 章的奖励重塑作用于单步信号层，本章的课程学习作用于任务分布层，两者可以叠加使用。CTDE 框架下还有一项特殊收益：集中式训练阶段可以先用全局状态帮助个体学习简单技能，随难度提升逐步增加观测受限程度，为分布式执行做平滑过渡。

核心原理

1. 课程学习的形式化

常规训练在固定的任务分布 p(τ) 上优化期望回报。课程学习把单一分布扩展为一族按难度参数 λ 索引的分布 pλ(τ)，训练过程沿 λ 从简单到困难推进。难度参数可以离散（阶段编号）或连续（混合比例）。两种调度方式：

离散阶段：ptrain(τ) = pλk(τ)，λk+1 = λk + Δλ 在满足推进条件时执行 阶段之间硬切换，实现简单，但性能在切换点会短暂下探
软化调度：ptrain(τ) = (1 − ρ)·pλ目标(τ) + ρ·pλ简单(τ) ρ 为保留旧难度的混合比例，随训练进程衰减，硬切换被替换为连续过渡

软化调度在直觉上更接近"复习"机制：训练样本始终包含一部分旧难度任务，策略在地形移动时仍能看到过去学到的解法，减少灾难性遗忘。多智能体环境里这一点尤其重要，因为协调技能（例如包抄站位）的退化需要重新探索才能恢复。

数值算例：协作命中的指数壁垒与窗口噪声

先量化"直接在大任务上训练"的代价。设每个智能体有 5 个动作，任务要求两个智能体连续 3 步执行指定的同步动作序列。随机策略下每步命中指定联合动作的概率是 (1/5)2 = 1/25，连续 3 步全中的概率是 (1/25)3 ≈ 6.4×10−5，首次命中所需回合数的期望值约为 1.56×104。若课程先把任务退化为单智能体版本（只需一个智能体完成 3 步序列），命中概率升到 (1/5)3 = 1/125，期望探索代价降到 125 步，约为原任务的百分之一。这组数字解释了两件事：为何多智能体任务直接训练经常停留在零回报平台，以及课程的收益随协作深度与智能体数量共同放大。

再看推进准则的窗口参数。用滑动窗口估计成功率，估计标准差约为 √(p(1 − p)/W)。设真实成功率 p = 0.8，窗口 W = 20 时标准差 0.089，估计在正负两个标准差范围内的波动幅度约 0.18，远超典型滞回区间 0.1：窗口内一次运气波动就可能把估计推过升阶阈值。把 W 提高到 150，标准差降到 0.033，两个标准差的波动约 0.066，落在滞回区间以内，误触发概率显著下降。这就是取值依据"窗口覆盖至少两个策略更新周期"的数值形态：窗口长度按判定所需的统计分辨力反推，再与更新周期核对。

2. 多智能体的四类难度维度

与单智能体课程相比，多智能体的难度空间多出两个特有维度，共四类：

维度典型参数提升顺序训练难点
规模智能体数量 N、地图大小先小后大联合动作空间按 |A|N 扩张，信用分配难度随 N 上升
观测局部观测半径、遮挡比例先大后小观测受限后个体无法直接看到协作对象，依赖记忆与通信
对手对手策略强度、反应速度先弱后强对手策略随训练更新，构成非平稳来源
协同深度完成任务的编排步数、同步约束先浅后深深度越深，随机基线命中协作序列的概率越低

提升顺序遵循同一原则：先解除对探索要求最高的约束，再解除对表征能力要求最高的约束。规模与协同深度直接压低探索命中率，因此放在课程前段；观测受限考验的是表征与记忆，放在中段；对手强度考验鲁棒性与适应能力，放在后段，与第 032 章的非平稳话题衔接。

把四个维度各自量化，课程顺序的依据会更清楚。规模维度上，|A| = 5、N = 6 的联合动作数为 56 = 15625，N = 10 时增至 510 ≈ 9.77×106，单靠随机交互采样覆盖率的下降是指数级的；观测维度上，视野半径 r 内的期望邻居数与 r2 成正比，半径减半后可见的协作伙伴平均只剩四分之一；对手维度的难点在分布随时间移动，属于第 032 章的处理对象；协同深度维度按命中概率的幂次恶化，前面算过的三步同步序列已经给出量级。三条可量化线索共同支持同一个编排原则：先压缩联合空间的规模维度与深度维度，再收缩信息通道，最后抬高对手压力。

3. 推进准则：成功率窗口与学习进度

最简单的推进准则是成功率阈值：在最近 W 个回合的滑动窗口上统计成功率，超过阈值 θ 时提升难度。窗口长度是关键的抗噪参数：

推进条件：mean(1[任务完成])最近 W 回合 > θ 且 回合数 ≥ Wmin W 过短时单次幸运回合就触发推进；W 过长时课程停滞，训练早期长时间停留在简单任务

更自适应的准则是学习进度：比较相邻两个窗口的性能提升幅度，选择提升最大的难度继续训练。当某难度上的性能已饱和（提升趋零），切换到更难的任务；当更难任务的提升为负，则回退。学习进度准则的几何直觉是让训练始终停留在"能力边界"附近，既不浪费算力在已掌握的任务上，也不陷入当前能力之外的挣扎区间。工程上常用两窗口成功率之差作为进度的廉价代理量，避免维护完整的性能曲线。

准则推进信号抗噪手段主要风险适用场景
成功率阈值最近 W 回合成功率与 θ 比较窗口长度与滞回区间阈值错设导致课程停滞或虚进难度可解释、阶段边界清晰的课程表
学习进度相邻窗口的成功率提升幅度两窗口差值取平滑进度估计噪声导致频繁切换难度维度连续、可自动加码的任务族

两者共享同一套数据，差别在判定量上：阈值看绝对水平，进度看一阶差分。实践中常见的组合是先按阈值粗调课程表，确认维度顺序有效之后再切换到进度准则做自动加码，切换点在日志里表现为升阶时刻从周期性变为不规则，这是正常现象。

4. 遗忘问题与教师学生蒸馏

进入新阶段后，策略参数分布向新任务移动，旧任务上的行为可能显著退化。两种缓解手段：其一，数据混合，按比例 ρ 采样旧阶段的任务数据一同更新，代价是单批数据中目标难度的有效占比下降；其二，教师学生蒸馏（Teacher-Student Distillation），为每个已完成阶段保存一个教师策略，让学生策略在训练时接受教师的动作分布监督：

L = LRL(θ) + λKD · Es[ KL( πteacher(·|s) ‖ πθ(·|s) ) ] λKD 随阶段推进衰减，蒸馏项只约束行为不替代回报目标

在多智能体场景中教师与学生均为联合策略，蒸馏可以按智能体拆分到局部观测上执行，从而与分布式执行的接口保持一致。选型建议：旧阶段任务仍可获得时优先数据混合，任务难以重回（例如对手版本无法冻结）时使用参数层蒸馏。两项措施的量级都可以量化：混合比 ρ = 0.2 时每个 32 回合的批次中约 6 个来自旧阶段，等价于给旧难度保留两成的更新流量；蒸馏项按梯度范数不超过主损失十分之一的经验比例配置，由在线监控回传的梯度范数之比调到该区间。两者都只改变数据或损失的配比，不改动算法主结构，可以叠加使用，并以旧阶段技能保留率与目标难度成功率作为联合验收指标。

实现思路与设计

课程系统的数据流由三条通路组成：推进通路（评测触发升阶）、回退通路（性能崩溃时降阶）、评估通路（在固定目标难度上周期性测性能）。三条通路共用同一份环境参数注入接口，难度状态作为配置对象随回合传递。

难度配置与超参数

参数默认值作用取值依据

窗口长度 W100 至 200 回合成功率统计范围覆盖至少两个完整的策略更新周期，抑制噪声触发
升阶步长 Δλ0.1 至 0.2单次推进的难度增幅过大会在切换点造成性能断层

关键代码与解读

片段 1：成功率窗口课程调度器

from collections import deque
import numpy as np

class CurriculumScheduler:
    """基于滑动窗口成功率的阶段调度：升阶、回退、保持三态。"""
    def __init__(self, n_stages=5, theta=0.8, window=150, min_episodes=150):
        self.n_stages = n_stages
        self.theta = theta                    # 升阶阈值：成功率需持续超过它
        self.window = deque(maxlen=window)    # 滑动窗口：旧结果自动挤出
        self.min_episodes = min_episodes      # 样本不足时不判定，防早期噪声
        self.stage = 0

    def report(self, success):
        # 每个回合结束调用一次，只记录 0/1 结果，统计口径轻量
        self.window.append(1.0 if success else 0.0)
        if len(self.window) < self.min_episodes:
            return self.stage
        rate = np.mean(self.window)
        # 滞回区间：升阶阈值与回退阈值不同，避免在边界反复切换
        if rate >= self.theta and self.stage < self.n_stages - 1:
            self.stage += 1
            self.window.clear()               # 升阶后清空窗口，重新统计新难度
        elif rate <= self.theta - 0.3 and self.stage > 0:
            self.stage -= 1
            self.window.clear()               # 回退同样清空窗口，防止旧数据再次触发
        return self.stage

解读：三处细节决定了调度器在噪声环境下的稳定性。滑动窗口用双端队列实现，统计代价为 O(1)；升阶与回退阈值之间留出 0.3 的滞回区间（Hysteresis），防止成功率在单一阈值附近抖动时课程反复升降；每次切换后清空窗口，避免旧难度的回合结果继续影响新难度的判定。参数选择上，窗口覆盖至少两个策略更新周期，min_episodes 与窗口长度相同，保证首次判定前已经有足够样本。

片段 2：难度参数注入与课程标记写入回放池

def curriculum_env_config(stage, base):
    """把阶段编号映射为环境参数：规模、观测、对手、协同深度逐维提升。"""
    cfg = dict(base)
    cfg["n_agents"] = min(base["n_agents"] + stage, base["n_agents_max"])
    # 观测半径逐级收缩，训练表征对部分可观测性的适应
    cfg["obs_radius"] = max(base["obs_radius"] - 0.1 * stage, base["obs_radius_min"])
    # 对手强度按阶段线性提升，与自博弈强度参数共用同一接口
    cfg["opponent_level"] = stage
    return cfg

def push_with_stage(buffer, transition, stage):
    """写入回放池时附带课程阶段标记，供采样端做混合与统计。"""
    transition["stage"] = stage
    buffer.push(transition)

解读：把阶段编号标记写入过渡数据，是课程系统与训练系统解耦的关键。采样端据此可以按阶段分组做混合采样、诊断各难度的学习状况，或在阶段回收时过滤过期数据。参数映射函数保持纯函数形态，同一阶段编号在任何随机种子下得到相同的环境配置，保证实验可复现。对手强度与后续章节的自博弈强度共用接口，避免为课程单独维护一套环境参数体系。

片段 3：旧任务混合采样与教师蒸馏损失

import torch

def mixed_batch(buffer, stage, batch_size, rho, device):
    """按比例 rho 从旧阶段、1-rho 从当前阶段组成批次。"""
    n_old = int(batch_size * rho)
    old = buffer.sample_filtered(lambda t: t["stage"] < stage, n_old)
    new = buffer.sample_filtered(lambda t: t["stage"] == stage, batch_size - n_old)
    # 同一字段按样本维拼接后再转张量：避免两次采样的字段顺序不一致
    merged = {k: torch.as_tensor(np.concatenate([new[k], old[k]]), device=device) for k in new}
    return merged

def distillation_loss(student_logits, teacher_logits, lam_kd):
    """教师学生蒸馏：用教师动作分布约束学生，缓解阶段切换后的能力退化。"""
    # 温度系数 1.0：教师与学生同源，无需软化分布带来的额外平滑
    teacher_prob = torch.softmax(teacher_logits, dim=-1)
    # KL 项只做行为约束，权重随阶段推进衰减，不改变回报目标的优先级
    return lam_kd * -(teacher_prob * torch.log_softmax(student_logits, dim=-1)).sum(dim=-1).mean()

解读：混合采样把"复习"写进了数据管线：旧阶段样本占比 ρ 从 0.2 线性衰减，训练后期完全由目标难度数据主导。蒸馏损失用教师分布对学生分布的一阶约束，作用范围限定在学生可见的观测上，因此集中式教师的知识以行为监督的形式传给个体策略，执行接口不变。选择 lam_kd 时遵循一个经验比例：蒸馏梯度范数不超过主损失梯度范数的十分之一，否则学习方向被教师复制主导，新难度的学习受阻。

常见坑

  • 窗口过短导致反复升降。W 采用 20 回合时，连续几次幸运成功即可升阶，随后成功率骤降又回退，课程状态持续振荡。症状是阶段编号在日志里高频跳动。修复：窗口覆盖至少两个策略更新周期，并设置滞回区间。
  • 只在训练难度上评估。把课程中间阶段的成功率当作最终性能，报告出的数值远高于目标难度上的真实表现。修复：评估通路固定在目标难度上周期性运行，与训练难度完全解耦。
  • 升阶步长过大。单次 Δλ 使智能体数量或对手强度跨越多个档位，训练曲线出现断层且难以恢复。修复：单维单步提升，观察 5 万环境步的恢复情况后再继续。
  • 遗忘旧协作技能。进入高难阶段后，早期学会的包抄、分布站位等行为退化，表现为成功率在新阶段初期不降反升之后又快速下滑。修复：提高旧任务混合比，或在阶段切换点引入教师蒸馏。
  • 课程推进与探索衰减脱节。探索率按全局环境步数衰减，难度提升后有效探索量反而不足。修复：探索参数按阶段重置或按阶段内步数重新调度。

    对成功率曲线求导，令其保持为正且较大；固定阈值本质上是把"进度尚可"的先验编码成绝对水平门限。
  2. 改参数预测：把升阶步长 Δλ 从 0.1 调到 0.5，预测课程阶段曲线与目标难度成功率两条曲线的形状变化，并给出至少一条日志证据。★
    提示
    阶段曲线会呈现"跳跃后长期回退"的锯齿；目标难度成功率上升更慢甚至出现中部塌陷，因为高难阶段的有效学习时间被回退压缩。
  3. 设计：为一个 4 智能体协同围捕任务设计四维课程表（规模、观测、对手、协同深度），给出每维的起点、终点、提升顺序与每一阶的推进条件。★★
    提示
    先固定小规模把围捕基础行为练出，再扩数量；观测半径收缩放在对手增强之前，避免两个约束同时生效。
  4. 实验设计：比较固定课程、学习进度准则、无课程三种设置在相同总环境步数下的目标难度成功率，说明如何控制总算力一致以保证公平对比。★★★
    提示
    三种设置使用同一评测协议与种子集合；总环境步数相同，但有效训练数据分布不同，报告中给出达到 50% 成功率所需的环境步数作为样本效率指标。

小结

  • 课程学习把任务分布按难度参数索引，训练沿参数从简单到困难推进；离散阶段实现简单，软化调度通过旧任务混合减少遗忘。
  • 多智能体课程包含四个维度：规模、观测受限、对手强度、协同深度；提升顺序先解除探索约束，后解除表征与鲁棒性约束。
  • 推进准则以成功率窗口为基线，加入滞回区间抗抖动；学习进度准则让课程停留在能力边界附近，调度更自适应。
  • 遗忘的两种缓解：旧任务数据混合与教师学生蒸馏；前者依赖任务可重现，后者把教师分布作为行为约束传递。
  • 下一页进入经验回放：当课程与塑形改变了数据分布，回放池如何按优先级取用数据、如何修正由此引入的偏差。
