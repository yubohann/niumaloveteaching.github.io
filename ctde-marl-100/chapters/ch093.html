第 093 章：论文复现方法：策略梯度系列

策略梯度系列的复现难点集中在优势估计与训练数据的组织：本章以 COMA、MADDPG、MAPPO、HAPPO 为脉络，给出 GAE 的截断处理、优势标准化、值归一化与批量组成的复现检查清单。

  • 主题：论文复现方法论 / 策略梯度算法族
  • 关键公式：GAE 递推 At = δt + γλAt+1、PPO 截断目标 min(rA, clip(r, 1±ε)A)、值裁剪 max((V−R)², (Vclip−R)²)
  • 预计学时：65 分钟
  • 前置章节：第 092 章

学习目标

  • 理解策略梯度系列的方法脉络：反事实基线、集中式 critic、信任区域与截断目标的关系。
  • 掌握多智能体 GAE 的计算与终止、截断两类边界的自举处理。
  • 理解 MAPPO 风格的复现细节：优势标准化、观测与值归一化、回合完整批量、动作掩码。
  • 能识别 on-policy 复现的特有偏差：自举缺失、归一化统计泄漏、批量组成不一致。
  • 能写出可复现的 PPO 风格更新代码与配置清单，并设计验收对照实验。

背景与动机

第 092 章的值分解系列全部基于时间差分学习，复现偏差主要来自目标构造与网络结构。策略梯度系列的偏差结构不同：训练数据由当前策略实时生成，优势估计与数据组织方式直接决定梯度质量。同一个 PPO 目标函数，优势估计少一次截断自举、归一化统计多更新一步，学习曲线就能从"稳定上升"变成"高位振荡"。

本章覆盖四条代表路线：MADDPG 的集中式 critic 加个体 actor 属于 off-policy；COMA 的反事实基线解决多智能体信用分配；MAPPO 把 PPO 扩展到 CTDE 并成为社区强基线；HAPPO 用顺序更新替代信任区域约束。复现时优先选择 MAPPO 作为主基线，其余方法围绕它做增量对照，原因是 MAPPO 的超参数少且社区复现记录最丰富。本章的检查清单同样适用于第 094 章的通信系列中基于 PPO 的变体。

核心原理

1. 方法脉络与信任区域

策略梯度系列的方法在"梯度信号从哪里来"上分道：MADDPG 用集中式 critic 给每个个体 actor 提供确定性策略梯度；COMA 在集中式 critic 上减去反事实基线，得到比全局基线方差更低的优势估计：

Ai(s, a) = Q(s, a) − Σa′i πi(a′i | oi) · Q( s, (a−i, a′i) ) 反事实基线只边缘化第 i 个智能体的动作，其余动作保持现状；相比全局基线 Σπ(a′)Q(s, a′) 方差更低

信任区域方法把"更新幅度"直接约束：TRPO 用 KL 约束求步长，PPO 用截断比率替代约束成为工程默认。HAPPO 则利用多智能体结构的特殊性：按顺序逐个更新智能体，每个智能体的更新只改变自身策略，其优势的单调改进条件更容易满足，从而省去信任区域。复现的优先顺序建议为 MAPPO、IPPO（去中心化 critic）、HAPPO，每一步只改变一处组件。

2. 多智能体 GAE 与边界自举

团队奖励设定下所有智能体共享同一奖励，时序差分残差为 δt = rt + γV(st+1) − V(st)，优势按 GAE 逆序累加 At = δt + γλAt+1。边界处理是复现偏差的头号来源：

  • 终止：任务终点，下一状态价值为零，不自举；
  • 截断：时间上限到达，价值函数仍有残余，必须用 V(sT) 自举；
  • 个体死亡：该智能体后续不再决策，其优势链在此断开，同时掩码把它的损失贡献置零。

三类边界的语义不同，代码上用两个布尔数组（term 与 trunc）分别表达，任何合并都会引入系统性价值偏差。截断自举缺失会把长回合的价值估计整体压低，表现为策略趋于提前结束或消极避险。衰减量级可以手算：γ = 0.99、λ = 0.95 时，距末端 L 步的残差权重为 (γλ)L = 0.9405L，L 取 20、50、100 时分别约 0.29、0.047、0.002（数值经程序核对）；靠近截断边界的优势受影响最重，越早的时间步偏差衰减越快。

4. on-policy 偏差清单

  • 自举缺失：截断回合未自举，价值估计系统性偏低；
  • 统计量泄漏：归一化统计用包含评估数据的样本更新，评估与训练相互污染；
  • 批量不一致：采样批量与更新批量不同（回合完整与否），梯度估计方差不可比；
  • 掩码缺位：死亡智能体的优势与损失未屏蔽，策略被无效样本拖动；
  • 学习率与截断失配：学习率过高时截断频繁触发，策略更新被反复裁剪，名义学习率与实际步长脱节。

5. 验收与对照设计

策略梯度系列的验收侧重样本效率：固定环境步预算下比较到达目标胜率所需的步数，以及最终胜率与置信区间。建议设置三组对照：MAPPO（集中式 critic）、IPPO（个体 critic）、MAPPO 去优势标准化。第一组验证集中化的收益，第二组验证去中心化的代价，第三组验证归一化开关的必要性；三组共享同一采样与评估协议，构成最小可信复现包。

实现思路与设计

MAPPO 风格训练循环分五步：

  1. 采样：并行副本收集若干完整回合，记录观测、全局状态、动作、旧对数概率、价值估计、终止与截断标志。
  2. 优势计算：按逆序 GAE 计算优势与回报目标，边界按终止与截断分别处理。
  3. 标准化：优势按整批标准化一次；观测归一化用冻结的滚动统计量。
  4. 更新：PPO 轮次遍历批量，截断目标加值裁剪加熵奖励。
  5. 评估：按第 092 章的贪心协议评估，统计量与训练完全隔离。

与第 092 章的差异点：值分解系列是 off-policy，回放缓冲与目标网络是复现关键；本章是 on-policy，采样批量与优势估计是复现关键，两者共享三层对齐框架但检查项不同。

设计决策：为什么 on-policy 批量必须保持回合完整？

GAE 的逆序累加依赖时间上的连续性；随机切分窗口会让窗口边界处的优势估计失去后续轨迹信息，产生系统性偏差。RNN 的隐藏状态同理，窗口截断处需要重新预热。保持回合完整虽然牺牲 batch 内的样本多样性，但换来了优势估计与序列状态的一致性。这一取舍与 off-policy 按转移条随机抽样的惯例恰好相反，是两类算法复现工具不可直接复用的原因。

关键代码与解读

片段 1：多智能体 GAE（含终止与截断处理）

import numpy as np

def compute_gae(rew, value, last_value, term, trunc, gamma=0.99, lam=0.95):
    """GAE：终止处不自举，截断处用下一状态价值自举；形状 (T, N)。"""
    T = rew.shape[0]
    adv = np.zeros_like(rew)
    gae = np.zeros_like(rew[0])
    for t in reversed(range(T)):
        if t == T - 1:
            # 批量末端：截断用末状态价值自举，终止直接置零
            v_next = np.where(term[t], 0.0, last_value)
        else:
            v_next = np.where(term[t], 0.0, value[t + 1])
        delta = rew[t] + gamma * v_next - value[t]
        # 终止处优势链断开；其余位置按 gamma * lambda 加权累积
        gae = delta + gamma * lam * np.where(term[t], 0.0, gae)
        adv[t] = gae
    return adv, adv + value          # 优势与回报目标（用于值函数拟合）

解读：（1）函数把终止（term）与截断（trunc）分成两个参数，批量末端的 v_next 只对未终止样本启用自举；若把截断也置零，价值目标被系统性压低，策略趋向拖延回合末端。（2）np.where 对全体智能体向量化：团队奖励下所有智能体共享同一个 δ，只有掩码（在损失端使用）区分个体。（3）返回优势与"优势加价值"两类量：后者是 critic 的回归目标，优势是 actor 的加权系数，两者分离便于 critic 使用不同的归一化。（4）lambda 取 0.95 时远期残差权重快速衰减，偏差换方差；复现时若发现优势的批次方差过大，先检查奖励尺度再考虑调整 λ。

片段 2：PPO 更新主体（截断、值裁剪与熵）

import torch

def ppo_update(actor, critic, optimizer, batch, clip=0.2, epochs=10):
    """PPO 更新：截断策略目标、值裁剪与熵奖励的组合损失。"""
    obs, state, act, old_logp, old_v, adv, ret = batch
    # 优势标准化：只在本批内计算统计量，避免引入跨批的统计依赖
    adv = (adv - adv.mean()) / (adv.std() + 1e-8)
    losses = []
    for _ in range(epochs):
        logp, ent = actor.evaluate(obs, act)
        ratio = torch.exp(logp - old_logp)
        # 截断目标：比率超出 1±clip 的部分不再贡献梯度
        pg_loss = -torch.min(ratio * adv,
                             torch.clamp(ratio, 1 - clip, 1 + clip) * adv).mean()
        v = critic(state)
        # 值裁剪：更新前后的估计都与回报目标比较，取更大的误差回传
        v_clipped = old_v + torch.clamp(v - old_v, -10.0, 10.0)
        v_loss = 0.5 * torch.max((v - ret) ** 2, (v_clipped - ret) ** 2).mean()
        loss = pg_loss + v_loss - 0.01 * ent
        optimizer.zero_grad()
        loss.backward()
        # 梯度裁剪与截断目标互补：一个限梯度范数，一个限策略比率
        torch.nn.utils.clip_grad_norm_(
            list(actor.parameters()) + list(critic.parameters()), 5.0)
        optimizer.step()
        losses.append(float(loss.detach()))
    return losses

解读：（1）优势标准化在每批开始时做一次，PPO 轮次内的多次更新共用同一标准化优势；若每轮都重算，等价于每轮改变目标，优化会震荡。（2）值裁剪需要旧值 old_v：标准实现比较"新值误差"与"裁剪后新值误差"取大者，双方都依赖同一回报目标；省略 old_v 直接用回报裁剪是常见简化，效果相近但复现声明时应注明采用哪种。（3）熵奖励以负号进入损失：最大化熵即最小化负熵，系数 0.01 让探索压力在训练后期被回报项自然覆盖。（4）梯度裁剪阈值 5.0 与截断系数 0.2 是两个独立旋钮：前者保护参数更新的范数，后者限制策略分布的变化幅度，不应当用其中一个替代另一个。

常见坑

  • 截断不自举：价值目标在时间上限处按零计算，长回合价值被低估。修复：term 与 trunc 分开传入 GAE，批量末端对未终止样本自举。
  • 评估时归一化统计量继续更新：评估结果随被访问次数漂移，重复评估的数值不一致。修复：评估阶段冻结统计量并记录其版本。
  • 优势按智能体分别标准化：团队协作中相对贡献被抹平，信用分配退化。修复：按整批全局标准化，个体差异交给掩码处理。
  • 随机窗口切分序列：GAE 尾部与 RNN 状态被切断，产生系统偏差。修复：保持回合完整批量，必要时按回合长度分桶以减少填充。
  • PPO 轮次与学习率同时调大：样本内过拟合叠加过大步长，比率越界频繁、策略抖动。修复：轮次 10 附近，学习率 5e-4 附近，两者不同时加倍。

练习与思考

  1. 在一个长度 50 的回合上手工计算：若批量末端为截断且未自举，优势估计的偏差来自哪些时间步？给出前 5 步的优势差值表达式。★
    提示
    偏差来自缺失的 γλ 幂次项 γ^L λ^L V(s_T)，所有早于末端的时间步都受影响，越靠前衰减越重。写出 A_0 的完整展开后再对比截断自举版本。
  2. 把优势标准化从整批改为按智能体，预测协作任务中信用分配与胜率的变化方向。★★
    提示
    团队奖励下各智能体优势完全相同，按智能体标准化会放大优势小的智能体、压缩优势大的，个体激励差异被破坏；预期胜率下降、方差上升。
  3. 推导：PPO 截断目标在 A 大于零且比率大于 1 + ε 时的梯度为零，说明该样本为何不再贡献更新，以及它在 A 小于零时的对应区间。★★
    提示
    A > 0 时目标为 min(r, 1+ε)A，r > 1+ε 后 min 取常数，梯度为零；A < 0 时目标为 max(r, 1−ε)A，r < 1−ε 后梯度为零。截断只阻止"已经变好"方向的继续更新。
  4. 设计对照实验：MAPPO、IPPO、MAPPO 去优势标准化三组，在相同预算与种子上报告胜率曲线与到达 0.8 胜率所需环境步数。★★★
    提示
    到达阈值步数用第 095 章的插值方法计算；预期 MAPPO 优于 IPPO（集中信息），去标准化组方差显著增大。种子数不少于 10，按 IQM 管道聚合。
  5. 写一份复现偏差审计表：对本章六项偏差逐条给出检查方法（代码位置或诊断图）与修正动作，并设计一个能暴露"统计量泄漏"的最小实验。★★★
    提示
    统计量泄漏实验：同一模型连续评估三次，比较三次评估胜率是否漂移；若无泄漏，三次结果应完全一致（贪心加固定评估种子）。

小结

  • 策略梯度系列复现的关键在数据组织与优势估计：COMA 反事实基线、MADDPG 集中 critic、MAPPO 截断目标加值裁剪、HAPPO 顺序更新。
  • GAE 的终止与截断必须分开处理：终止不自举、截断自举，掩码在损失端屏蔽死亡个体。
  • 优势按整批标准化一次；观测归一化评估时冻结；批量保持回合完整。
  • on-policy 偏差清单五项：自举缺失、统计泄漏、批量不一致、掩码缺位、学习率与截断失配。
  • 最小可信复现包为三组对照：MAPPO、IPPO、去优势标准化，共享采样与评估协议。
