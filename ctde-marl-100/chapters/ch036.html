第二篇 · 训练工程与稳定性

第 036 章：超参数敏感性分析

本章讲超参数实验的方法论：随机搜索与分阶段筛选协议、共同随机数下的配对比较、敏感度与交互效应的度量，以及避免选择偏差的预算分配与报告规范。

  • 主题：实验方法论 / 参数响应曲线
  • 关键公式：配对差值 ds = yA(s) − yB(s)
  • 预计学时：55 分钟
  • 前置章节：第 035 章 训练曲线诊断方法

学习目标

  • 理解多智能体算法对超参数敏感的结构性原因，以及敏感性信息在复现与迁移中的价值。
  • 掌握随机搜索优于网格搜索的论证，能按对数格点与有效维度设计搜索空间。
  • 掌握共同随机数配对比较的原理，能用种子配对差值代替独立均值比较降低方差。
  • 掌握敏感度度量（对数斜率、等级相关）与交互效应的识别方法。
  • 能设计粗筛加精调的两阶段协议，并识别选择偏差、验证集泄漏两类报告错误。

背景与动机

深度强化学习的性能对超参数高度敏感，多智能体训练把敏感度进一步放大：智能体数量的变化会改变有效批大小与信用信噪比；非平稳性让学习率与更新间隔的最优组合随训练阶段移动；课程与对手池引入训练过程中变化的参数。这些性质意味着从单智能体任务照搬的参数配置很难直接可用，敏感性分析成为每个多智能体项目必须承担的步骤。

与性能调优不同，敏感性分析的目的不止于找到一组更好的数值，还在于回答"结论对参数选择有多稳健"：论文复现失败常源于评测协议与超参数细节未对齐，与算法实现错误关系不大。第 035 章解决了单次训练的观察规范，本章解决多配置实验的组织规范：用受控比较代替直觉调整，用分阶段预算代替全组合穷举。

核心原理

1. 搜索空间的设计

超参数的取值范围按几何尺度展开：学习率、裁剪阈值、熵系数、探索衰减时长等正量在十进制数量级上变化，采用对数均匀格点；批大小、邻居数、目标网络间隔等取离散格点。一次性改变一个参数的实验设计（One-Factor-At-A-Time, OFAT）在参数交互存在时误导性强：学习率与批大小、探索率与熵系数都是成对起作用的组合。

随机搜索的论证：高维空间中只有少数维度影响性能，随机采样让每个有效维度获得更密集的覆盖。设搜索空间有 d 个维度、预算 N 次试验，随机搜索在任一维度上的采样密度相当于网格搜索的数倍量级（当有效维度远小于 d 时），而网格搜索的代价随维度指数增长。实践推论：先按领域经验锁定参数区间，再随机采样，结束条件按预算与边际收益设定，不追求覆盖全部组合。

参数的先验区间来自三个来源：相邻任务的既有配置、本任务小规模预跑、量纲分析（例如学习率与批大小共同决定每样本的参数移动量）。区间外扩一档用于确认边界行为，确认后收回，避免搜索预算被明显无效区域占用。给每个参数标注预期交互伙伴，采样时对交互对做联合分层，比完全独立采样更快找到联合最优区。

2. 配对比较与共同随机数

比较两个配置时，最大的方差来源是种子间差异。共同随机数（Common Random Numbers）让两个配置使用同一组训练种子与评测种子，把比较转为逐种子的差值：

配对差值：ds = yA(s) − yB(s)，s 为种子编号 估计量取 ds 的均值；配对方差通常远小于两组独立样本的方差

配对有效的条件是种子效应在配置间共享：初始化、采样的随机序列、评测局面完全相同，差异只来自被比较的参数。配对失败的常见原因是实现中引入了配置相关的随机性（例如不同配置下评测回合数不同），此时差值的方差优势消失，需要改用独立比较并增加种子数。报告配对结果时给出差值的均值与置信区间，两组各自的均值信息量有限：差异及其不确定性才是读者关心的对象。

配对有效性可以做数据侧自检：设两组性能的方差同为 σ2、种子效应相关性为 ρ，配对差值方差为 2σ2(1 − ρ)，相对独立比较的缩减因子即 (1 − ρ)。观测到的差值样本方差接近 2σ2 时说明相关消减没有发生，ρ 接近零，配对设计失效。典型原因是两侧配置的评测随机化档位不同或训练中断点不一致。发现失效后先修复实现，再决定是否退回独立比较并增加种子数。

方差分解的试验预算与因子数成指数关系：三因子两档的全因子设计需要 8 格乘以每格种子数，两两交互项的估计还要求每格有重复。预算不足时的降级方案是只对预期交互对做全因子，其余参数固定在名义值，这一策略在实践中能覆盖大部分关键交互。

3. 敏感度与交互效应

敏感度度量分两类。局部敏感度用对数斜率描述参数微小变化对性能的相对影响：

Si ≈ Δy / y ÷ Δθi / θi 在名义配置附近取多个邻近点拟合斜率；|S| 越大表示性能对该参数越敏感

全局视角用等级相关（Spearman）或方差分解：把各配置的性能排序与参数取值排序做相关，识别单调响应；方差分解把性能方差归到主效应与两两交互项，交互项显著意味着两个参数必须联合调整。以第 027 章得到的经验为例：学习率与批大小是典型的交互对，单独扫一个参数得到的结论在另一个参数变化后失效。工程上的折中做法是固定已知强交互对中的较稳参数（例如批大小按并行环境数与内存定死），只扫描学习率，并把交互检查放在精调阶段。

交互效应的识别最小方案是条件扫描：选择两个最可能交互的参数（例如学习率与目标网络 τ），各自取两档组成四格，每格用同一组配对种子跑短预算，比较两因素主效应在两档之间的方向。同一参数在两档中的最优方向不一致时即确认交互存在，正式扫描必须采用联合格点或在精调阶段成对调整。四格设计的算力开销是单因子扫描的两倍，作为筛查手段可以接受；确认存在交互后，单因子结论在文档中标注"仅在固定另一参数时成立"的使用条件。

4. 预算分配与两阶段协议

把总预算分成粗筛与精调两阶段。粗筛阶段每配置用 3 个种子、较短训练预算（目标步数的 30% 到 50%），按中位数性能淘汰；精调阶段对入选的 3 到 5 个配置用 8 个以上种子跑完整预算，报告配对差异与置信区间。两阶段的省算力逻辑在于：粗筛筛掉的是明显弱势区域，短预算下的排序与全预算排序的相关性足以支撑粗筛决策，这在响应面较为平滑时成立。

粗筛协议的失效边界需要明确：响应面在短预算下与全预算下的排序不一致时，粗筛会系统性淘汰慢热配置，把预算浪费在早期快、后期平的参数区。防护措施有两条：淘汰只做一轮，边缘配置保留进入精调观察名单；相似任务的历史粗筛一致性检验结果可以复用，用于预先设定粗筛与精调的预算比例。两阶段之间的配置替换全部记录，实验结束后可完整归因。若精调后的排名相对粗筛发生翻转，说明预算比例或种子数不足，记录该事件并提高下一轮粗筛的种子数。

选择偏差是必须管理的风险：从 30 个配置中挑出最好的一组并报告其性能，会把种子噪声当作配置优势。规范做法是把粗筛与精调使用独立的种子集合，精调阶段的报告基于全部种子（不挑最好的种子）；若资源允许，用验证集选定配置、在新种子集合上做最终评测。

5. 数值算例：配对差值的方差优势与等级相关读法

用五个种子的合成数据核对配对方差优势。设种子效应为 (−1, −0.5, 0, 0.5, 1)，配置 B 的性能为 10 加种子效应，配置 A 为 11 加同一效应，得到 A = (10, 10.5, 11, 11.5, 12)、B = (9, 9.5, 10, 10.5, 11)。逐种子差值是恒定的 1，配对估计的标准误为 0；若忽略配对属性、按两组独立样本比较，各组标准差约 0.79，差值标准误约 0.5。同一份数据，配对流程给出零不确定度的差值结论，独立流程给出宽一倍的区间，达到同等精度所需种子数相差数倍。真实实验中种子效应不会完全相消，但配对通常能消掉其中的主要部分。

搜索预算的覆盖差异可以手算：六个参数中有效维度约为二，网格每维取 3 档需要 36 = 729 次试验，才能在二维切片上保证每格至少一个采样点；随机搜索在 64 次试验时，二维切片上落有 64 个采样点，位置密度约为网格 9 个格点的 7 倍。有效维度为二时，随机搜索用不足十分之一的预算覆盖了更密的切片：预算约束下的可行做法是随机采样加事后切片分析，对全维度继续加密网格在预算上不可行。

等级相关的读法用一个六点例子说明：学习率取值 (1, 2, 3, 4, 5, 6) 对应性能 (1, 3, 2, 5, 4, 7) 时秩相关约 0.89，说明响应总体单调上升；对应性能 (6, 4, 5, 2, 3, 1) 时秩相关约 −0.89，说明方向相反。|ρ| 低于 0.3 的参数列为弱敏感并从后续扫描降级，把预算让给强敏感参数与交互对；落在 0.3 到 0.7 的参数保留在精调名单中，用配对流程复测。

三组数字合起来给出一次扫描的完整判定链：秩相关定参数优先级，条件扫描定交互对，配对差值定最终胜负。链条中任何一环缺失，结论都会停留在排序看起来如此的表层，无法支撑配置选择。

实现思路与设计

实验管线围绕配置字典展开：采样器生成配置，执行器按配对协议运行种子，分析器汇总差值。所有配置与种子编号落盘，任何一条曲线可以追溯到唯一的（配置，种子）组合。

参数名义值扫描范围优先级
学习率5e-4对数 [1e-4, 2.5e-3]高（与批大小交互）
批大小（回合数）32离散 {16, 32, 64}中（随并行环境数固定）
裁剪阈值10（值分解）离散 {0.5, 5, 10, 无}高（第 027 章）
目标网络 τ0.01对数 [0.001, 0.05]中（第 024 章）
探索衰减时长总步数的 60%{0.3, 0.6, 1.0} 倍总步数中（第 025 章）
熵系数0.01对数 [0.001, 0.1]高（策略梯度类）

与第 035 章的衔接点：敏感性实验的每个配置都执行第 035 章的质量过滤，EV 异常或裁剪触发率失控的运行标记为无效，不进入性能比较，防止把配置缺陷与训练故障混为一谈。

关键代码与解读

片段 1：随机搜索配置采样器

import numpy as np

def sample_configs(n_trials, seed=0):
    """按参数类型采样：正量用对数均匀，离散量用格点均匀。"""
    rng = np.random.RandomState(seed)
    configs = []
    for _ in range(n_trials):
        cfg = {
            # 学习率跨数量级变化：对数均匀让每个十倍区间采样密度相近
            "lr": float(10 ** rng.uniform(np.log10(1e-4), np.log10(2.5e-3))),
            # 批大小取离散格点：内存与并行度约束决定候选集合
            "batch_episodes": int(rng.choice([16, 32, 64])),
            "clip_norm": float(rng.choice([0.5, 5.0, 10.0])),
            "tau": float(10 ** rng.uniform(np.log10(1e-3), np.log10(5e-2))),
            # 熵系数同样按数量级扫描，与探索衰减时长经常同时调整
            "ent_coef": float(10 ** rng.uniform(-3, -1)),
            "anneal_frac": float(rng.choice([0.3, 0.6, 1.0])),
        }
        configs.append(cfg)
    return configs

解读：采样器的核心约定是"参数类型决定分布形状"：对数均匀保证跨数量级的公平覆盖，格点均匀保证离散约束不被破坏。固定采样种子让搜索空间本身可复现，任何人用同一 seed 得到同一批配置；这与训练种子是两回事，后者的配对管理在片段 2。真实管线会把候选字典与领域经验区间写入配置文件，采样器只负责形状，不混入取值判断。

片段 2：配对差值分析与置信区间

import numpy as np

def paired_compare(scores_a, scores_b, n_boot=10_000, seed=0):
    """输入两组按种子对齐的性能分数，返回配对差值的统计量。"""
    a, b = np.asarray(scores_a), np.asarray(scores_b)
    assert a.shape == b.shape, "配对比较要求种子一一对应"
    d = a - b                                     # 逐种子差值：抵消种子效应
    rng = np.random.RandomState(seed)
    boot = np.empty(n_boot)
    for i in range(n_boot):
        idx = rng.randint(0, len(d), len(d))      # 有放回重采样：构造差值均值分布
        boot[i] = d[idx].mean()
    lo, hi = np.percentile(boot, [2.5, 97.5])
    # 报告差值的均值与 95% 区间：区间跨零表示方向不确定
    return {"mean_diff": float(d.mean()), "ci95": (float(lo), float(hi)),
            "win_rate": float((d > 0).mean())}

def cross_compare(scores_a, scores_b, n_boot=10_000, seed=0):
    """非配对后备方案：两组独立运行、无共享种子时使用。"""
    a, b = np.asarray(scores_a), np.asarray(scores_b)
    rng = np.random.RandomState(seed)
    boot = np.empty(n_boot)
    for i in range(n_boot):
        ia = rng.randint(0, len(a), len(a))       # 两组各自独立重采样
        ib = rng.randint(0, len(b), len(b))
        boot[i] = a[ia].mean() - b[ib].mean()
    return float(a.mean() - b.mean()), tuple(np.percentile(boot, [2.5, 97.5]))

解读：配对差值把"两组均值差"的方差降到"差值的方差"，在多智能体这类种子方差大的场景中是首要手段。自助法重采样不假设差值分布形态，小样本下比标准 t 区间更稳健。返回的胜率给出第三个视角：差值均值受个别大正差拉动时，胜率揭示一致性。后备方案用于无法配对的场景（例如对比外部复现结果），其置信区间宽得多，需要更多种子才能支撑同等强度的结论。

片段 3：敏感度与交互汇总

import numpy as np

def _rank(x):
    """平均秩无关的简化排名：先排序再回填序号。"""
    ranks = np.empty(len(x), dtype=np.float64)
    ranks[np.argsort(x)] = np.arange(len(x))
    return ranks

def sensitivity_table(configs, scores, param_names):
    """汇总每个参数的等级相关与首要交互对。"""
    rows = []
    for p in param_names:
        vals = np.array([c[p] for c in configs], dtype=np.float64)
        # Spearman 相关 = 排名的 Pearson 相关：对量纲与单调变换不敏感
        rho = float(np.corrcoef(_rank(vals), _rank(scores))[0, 1])
        rows.append({"param": p, "spearman": rho})
    # 交互检查：对每个参数对，比较"双高组"与"单高组"的中位数差
    best = max(param_names, key=lambda p: max(abs(r["spearman"])
               for r in rows if r["param"] == p))
    inter = {}
    for p in param_names:
        if p == best:
            continue
        hi = [s for c, s in zip(configs, scores)
              if c[best] > np.median([cc[best] for cc in configs])]
        inter[p] = float(np.median(hi) - np.median(scores)) if hi else 0.0
    return {"main": rows, "interactions_with_best": inter}

解读：等级相关回答"该参数单调影响性能吗"，交互项的粗筛回答"哪些参数必须与主敏感参数联合调整"。该实现刻意保持轻量：完整的方差分解（多因子设计）需要正交实验结构，扫描预算通常不允许，用分层的条件中位数差作为交互的近似信号已足够指导下一轮实验。小样本下不追求显著性判定，结论以效应量（相关系数、中位数差）为主。输出表格直接进入实验档案，与第 037 章的方差报告合并呈现。

常见坑

  • 用不同种子比较两组配置。种子效应混入配置效应，结论不可靠。修复：共同随机数配对；无法配对时增加种子数并报告区间。
  • 选择偏差。只报告优胜配置把噪声当选型；用评测种子调参使性能估计偏乐观。修复：粗筛与精调使用独立种子集，最终报告使用未参与调参的种子集合；复测时记录轮次编号，同一配置在多次复测中的得分波动是选择偏差的直接度量。
  • 扫描范围与量纲错配。学习率用线性格点导致低量级区间欠采样，或裁剪阈值跨越无意义区域浪费预算。修复：按量纲选择分布形状，先用粗网格定位后再局部加密。
  • 忽略交互效应。单独扫学习率得到的"最优值"在批大小换档后失效。修复：对已知交互对做条件扫描或联合格点。
  • 短预算粗筛结论直接引用。短训练下表现好的配置未必在全预算下领先。修复：粗筛只用于淘汰，入选配置必须完成全预算精调才进入结论。

    网格取每维 m 档需 md 次试验，随机搜索在任一单维上的投影密度约为 N/r 档；当 r 远小于 d 时后者在有效维度上更密。
  2. 改参数预测：把粗筛阶段的种子数从 3 降到 1，预测入选配置与真实前几名的一致率变化，并说明哪些参数区的淘汰错误最可能发生。★
    提示
    单种子下噪声主导排序，一致率显著下降；响应面平坦的参数区（例如裁剪阈值 5 与 10 之间）最容易误淘汰。
  3. 设计：为值分解算法设计一个三因子扫描（学习率、目标网络 τ、裁剪阈值），给出各因子的格点、预期交互对与两阶段预算的分配比例，并说明如何用条件扫描验证交互。★★
    提示
    学习率与 τ 共同决定价值目标的移动速度，是预期交互对；条件扫描固定一个因子的两档、扫描另一个，比较两组响应曲线形状。
  4. 实验设计：对同一算法运行两轮独立随机搜索（不同搜索种子），比较两轮得到的前三名配置集合的重叠率与性能排序相关性，据此判断搜索预算是否充分。★★★
    提示
    预算充分时两轮应选出相近的稳健区域，前三名完全相同反而可疑；重叠率过低说明种子噪声主导，需要扩大配对或精调预算。

小结

  • 多智能体的高敏感度决定了敏感性分析是必需步骤；搜索空间按量纲选择分布，正量用对数均匀。
  • 随机搜索在高维且有效维度低的场景优于网格搜索；参数交互对要求条件扫描，单因子扫描会得出误导结论。
  • 共同随机数配对比较把种子方差从估计中大部分消除，自助区间与胜率提供差值的完整性描述。
  • 两阶段协议：粗筛短预算淘汰，精调全预算报告；粗筛与精调使用独立种子集合避免选择偏差。
