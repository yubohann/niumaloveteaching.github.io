第 006 章：基于值分解的VDN实现

值分解（value decomposition）家族的第一代方法：把联合动作价值写成个体价值之和 Qtot = Σ Qi，训练只用团队回报监督总价值，执行期各智能体对自己的 Qi 贪心即可。学完本章，你能证明加性分解满足个体全局最大条件，并完整实现 VDN 的训练与执行。

  • 主题：值分解算法 / 加性分解
  • 关键公式：Qtot(τ, u) = Σi Qi(τi, ui)；个体全局最大条件
  • 预计学时：50 分钟
  • 前置章节：第 005 章

学习目标

  • 理解值分解的动机：集中式评论家解决了训练目标问题，执行分散化仍需要把联合决策拆回个体决策。
  • 掌握个体全局最大（Individual-Global-Max, IGM）条件的定义，以及加性分解满足该条件的证明。
  • 掌握 VDN（Value Decomposition Networks）的训练损失与目标值分解计算，理解其无需枚举联合动作的原因。
  • 会实现个体 Q 网络、求和混合器、目标网络与分散贪心执行，并用穷举测试验证 IGM 一致性。
  • 能说明加性分解的表达力边界，为第 007 章 QMIX 的单调混合网络建立改进动机。

背景与动机

第 003 至 005 章给出了集中式训练的标准形态：评论家 Q(s, a) 以全局信息估计价值，训练目标稳定。但执行端留下一个未解的问题：Q(s, a) 是联合动作的函数，执行期每个智能体无法获得 s，也无法枚举 4N 量级的联合动作做 argmax。策略梯度家族用显式演员绕开了这一点（πi 直接给出动作），值方法则必须回答：如何让联合价值与个体决策建立结构约束，使联合最优可以分散地达到。

VDN（Value Decomposition Networks）给出的回答最小化到极致：联合价值等于个体价值之和。这一假设带来三项收益：执行期每个智能体对自己 Qi 贪心即可得到联合最优的分解；目标值中的联合最大化可以在个体层面分别进行，避免枚举；团队回报的梯度自动流向每个个体价值，形成一种隐式信用分配。代价是表达力：加性结构无法表示"只有联合行动才产生超额价值"的任务，这一缺陷由第 007 章的单调混合网络部分修补。VDN 是值分解路线的坐标原点，后续两章的改进都以它为参照物。

核心原理

本节给出值分解的形式化目标（IGM 条件）、VDN 的实现选择、训练目标的分解计算，以及表达力边界。

1. 个体全局最大条件

值分解的关键要求：存在个体价值函数 {Qi} 与联合价值 Qtot，使得联合最优动作恰好由个体最优动作拼装：

argmaxu Qtot(τ, u) = ( argmaxu1 Q1(τ1, u1), …, argmaxuN QN(τN, uN) ) 称该条件为个体全局最大（Individual-Global-Max, IGM）。满足 IGM 时, 执行期每个智能体独立 argmax 得到的联合动作即 Qtot 的贪心动作, 不需要任何中心协调

加性分解 Qtot = Σi Qi 自动满足 IGM：对任意联合动作 u 有 Qtot(u) = Σ Qi(ui) ≤ Σ maxui Qi，右侧上界在"每个个体取各自最大动作"时达到，故联合最大点与个体最大点的组合重合。证明只用到每个 Qi 只依赖自己的动作分量这一结构，与网络具体形式无关。

把证明拆成两个方向更清楚。方向一（上界）：对任意联合动作 u，每一项 Qi(ui) 都不超过自己的最大值 maxui Qi，求和即得左边不超过右边。方向二（可达）：取 u* 为各智能体独立 argmax 的拼接，代入左边，每一项都取到最大值，左边等于右边。更深一层的结论：若 Σ Qi(ui) = Σ max Qi，则每一项都必须取到自身最大值，因此联合 argmax 集合恰好是各智能体 argmax 集合的笛卡尔积，平局结构在两层级之间完好传递。

2. 训练目标与分解计算

VDN 用团队回报监督总价值，损失为标准时序差分误差：

L(θ) = 𝔼(τ, u, r, τ′)∼D [ ( r + γ (1 − done) · maxu′ Qtottarget(τ′, u′) − Qtot(τ, u) )² ] θ 为全部个体网络参数之和；Qtottarget 使用目标网络参数。注意目标中的联合最大化同样享受分解：maxu′ Σ Qitarget(τ′i, u′i) = Σi maxu′i Qitarget(τ′i, u′i)

分解 max 这一步是 VDN 计算可行的全部秘密：目标值计算只需对每个智能体在 n_actions 个动作上取最大，复杂度从 O(|A|N) 降为 O(N·|A|)。把差额数出来：N = 6、动作数 3 时，枚举联合动作求 max 每条样本需要评估 729 个组合，逐智能体 max 只需 18 次前向，相差 40.5 倍；N = 10 时 59049 对 30，相差约 1968 倍，差距随 N 指数扩大。训练时用行为策略采集的联合动作 u 取 Qtot(τ, u) = Σ Qi(τi, ui)（仅取执行动作对应分量），梯度经求和算子均匀回流到每个 Qi，即每个个体价值都收到同一份时序差分误差信号。这种"误差均分"是最粗糙的隐式信用分配，第 009、020 章将给出更精细的分配方案。

分解 max 与梯度均分来自同一个结构事实：∂Qtot/∂Qi = 1。对每个个体价值求偏导，损失梯度为 2(Qtot − y)/B，与智能体下标 i 无关。所有个体网络收到完全相同的标量误差，差异只出现在各自输入与执行动作的路径上；"误差均分"意味着信用分配的分辨率完全由个体网络的输入区分能力决定，网络看不到队友动作，就无法把"我的贡献"与"队友的贡献"从团队信号中分离出来。

3. 表达力边界

加性函数类是联合函数空间的真子集。考虑需要协同增益的任务：两个智能体各有两个动作，联合价值含交互项 Qtot = Q1(u1) + Q2(u2) + 3·1[u1 = u2 = 1]，最后一项表示"同时按下开关才启动发电"的超额收益。设个体项在动作 0 上略高，加性分解的最优会是双方都选 0，联合最优（都选 1 获得交互项 3）不可达。

把边界算成数字。二动作任务的联合价值矩阵 V(u1, u2) 可精确分解为加性形式的充要条件是交叉差分为零：

V(0, 0) + V(1, 1) − V(0, 1) − V(1, 0) = 0 证明思路：加性函数对 u2 的两个取值，两行之差相同；交叉差分正是"行差与列取值无关"这一性质的度量，非零值即交互结构的强度

取加性基座（双方选 0 各得 1、选 1 各得 0）叠加"同时选 1 额外得 5"的交互项，价值矩阵为 V(0,0) = 2、V(0,1) = 1、V(1,0) = 1、V(1,1) = 5。交叉差分 = 2 + 5 − 1 − 1 = 5，恰等于交互项大小。方差分析意义下的最佳加性拟合把交互残差均分到四个格子：拟合值为 0.75、2.25、2.25、3.75，残差矩阵为 +1.25、−1.25、−1.25、+1.25（1.25 = 5 / 4），与真值的平方误差和为 6.25。该例中最佳拟合的贪心动作碰巧仍是 (1, 1)，但拟合并不能保证这一点：把矩阵换成 V(0,0) = 6、V(0,1) = 6、V(1,0) = 0、V(1,1) = 10，真值最优仍是 (1, 1) 得 10，而最佳加性拟合的四个值为 3.5、8.5、2.5、7.5，贪心动作变成 (0, 1)。原因机械而清楚：交叉差分不为零时，最差的错配格子（这里是 V(1,0) = 0）把智能体 1 的行均值从 6 拉到 5，单方面最优与联合最优脱钩，这就是"低估联合专属动作组合"的算术形态。

三句话概括 VDN 的边界：能表示的可加性问题表现优良；协同增益占比高的任务存在系统性偏差；偏差的方向是低估联合专属的高价值动作组合。第 007 章的 QMIX 引入状态相关的单调混合函数 fs：∂fs/∂Qi ≥ 0，在保持 IGM 的同时表达任意单调组合，覆盖了交互项非负的任务谱系。

4. 与集中式评论家的对比

第 003 章的 Q(s, a) 是自由函数，表达力最强，但执行无法分散；VDN 用加性结构换取可执行性。两者训练数据的接口一致（同样是联合转移），差异在网络参数化与执行方式：VDN 的"评论家"同时是执行策略的载体，训练与执行共享同一组个体价值，不需要独立的演员网络。这一特性也解释了 VDN 类方法在离散动作任务上的广泛适用性，连续动作版本需要为个体价值挂接演员网络（第 010 章路线）。

实现思路与设计

本节给出 VDN 的结构与训练配置。核心组件为：N 个个体 Q 网络（支持第 004 章的共享开关）、无参数的求和混合器、目标网络组、ε-greedy 执行。

设计项取值（基线）作用与依据
个体 Q 网络MLP 64×64，输出 n_actions输入仅为该智能体的观测；共享可选但默认独立，控制变量
混合器纯求和，无参数VDN 的定义；状态偏置项在保持 IGM 下可加，但基线保持最小形式
目标网络硬拷贝，每 200 环境步与第 002 章节奏一致，便于横向对照
学习率5e-4（Adam）求和使每个个体网络收到的标量误差与单网络同量级（∂Qtot/∂Qi = 1），学习率无需放大；观察不稳时降为 2.5e-4
批大小32 条联合转移VDN 每次更新只产生一个标量损失，批过大会稀释个体差异信号
ε 调度1.0 线性降至 0.05，2×104 步与第 002 章一致
回放容量5×104 条联合转移值分解对旧数据同样敏感，容量取小

与第 005 章的衔接：数据层与检验工具完全复用；网络层把 CentralCritic 替换为"个体 Q 网络组 + 求和"。执行端从第 003 章的显式演员改为对 Qi 贪心，ε-greedy 探索保持在个体动作层面。配置实验中优先切换的变量是"混合器是否带状态偏置"与"个体网络是否共享"，两者都保持 IGM，可作为消融起点。混合器加状态偏置 b(s) 是一个保持 IGM 的扩展：该项不随动作变化，不改变任何 argmax，只吸收"与动作无关、随状态变化"的回报基线，减轻个体网络的拟合负担。基线保持纯求和，把"是否加 b(s)"作为第一个消融开关，这一开关在第 007 章的混合网络里以状态条件参数的形式自然延续。

设计决策：目标值计算采用逐智能体 max 的理由

枚举 36 = 729 条联合动作在训练每步都执行会吞掉大量算力，智能体数增加后不可行。加性结构让 max 与求和可交换：Σi maxui Qitarget 与联合 max 严格相等，逐个体计算的最大值与之和即精确的联合贪心目标，无任何近似。"最大化算子穿过分解结构"是全部值分解方法共享的计算红利，第 007、008 章在各自约束下维持这一性质。

关键代码与解读

片段 1：个体价值与求和混合

import torch
import torch.nn as nn

class AgentQ(nn.Module):
    """个体价值网络: 输入只含本智能体的观测, 输出每个动作的 Q 值。"""
    def __init__(self, obs_dim, n_actions, hidden=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, n_actions),
        )

    def forward(self, obs_i):
        return self.net(obs_i)                 # (B, n_actions)

class VDNMixer(nn.Module):
    """求和混合器: 无参数, 直接提供 IGM 保证。"""
    def forward(self, q_agents, actions):
        # q_agents: (B, N, n_actions); actions: (B, N) 执行动作索引
        chosen = q_agents.gather(2, actions.unsqueeze(-1)).squeeze(-1)
        return chosen.sum(dim=1)               # (B,) 联合价值 = 个体价值之和

解读：AgentQ 的输入约束与第 005 章纪律一致，个体价值不得消费其他智能体的信息。VDNMixer 的两个设计点值得展开：（1）gather 先取"执行动作"分量再求和，对应损失式中的 Qtot(τ, u)；若把全部动作分量求和会得到与动作无关的量，训练立刻失效。（2）混合器无参数这一事实意味着目标网络只需复刻个体网络组，混合过程无需目标版本，第 002 章的目标网络机制原样适用。

片段 2：训练目标与损失

def vdn_loss(agent_qs, target_agent_qs, batch, gamma=0.95):
    """一次 VDN 更新: 目标值中的联合 max 分解为逐智能体 max。"""
    obs, act, rew, nobs, done = batch         # (B, N, ·) 形状
    B, N = act.shape
    q_all = torch.stack([net(obs[:, i]) for i, net in enumerate(agent_qs)], dim=1)
    mixer = VDNMixer()
    q_tot = mixer(q_all, act)                 # 训练侧: 用执行过的联合动作
    with torch.no_grad():
        # 目标侧: 每个智能体独立取 max, 再求和, 与联合 max 严格相等
        q_next_all = torch.stack(
            [tn(nobs[:, i]).max(dim=1).values for i, tn in enumerate(target_agent_qs)],
            dim=1)                            # (B, N)
        q_tot_next = q_next_all.sum(dim=1)    # (B,)
        y = rew[:, 0] + gamma * (1.0 - done[:, 0]) * q_tot_next
    return ((q_tot - y) ** 2).mean()          # 单一标量损失, 梯度均分到个体网络

解读：目标侧构造是本章的技术核心。（1）.max(dim=1).values 对每个智能体只在其自身动作维取最大，得到 (B, N) 的个体最大值，求和即精确联合贪心价值；这一行就是"max 与 sum 交换"的代码形态。（2）目标侧用 no_grad 包裹，防止目标价值的梯度回流；这是时序差分自举的通用纪律，遗漏会导致训练目标随参数漂移。（3）损失是单一标量对全部个体网络反向传播，梯度按求和结构的偏导均匀分配，验证梯度量级时可用 autograd 对每个 AgentQ 参数分别打印范数。

片段 3：分散执行与 IGM 一致性验证

def decentralized_greedy(agent_qs, obs_i_list):
    """执行期: 每个智能体对自己的 Q_i 贪心, 无任何跨智能体计算。"""
    with torch.no_grad():
        return [int(net(o.unsqueeze(0)).argmax(dim=-1)) for net, o in zip(agent_qs, obs_i_list)]

def verify_igm(agent_qs, obs, n_actions, atol=1e-6):
    """小规模穷举测试: 联合 argmax 与个体 argmax 组合必须一致。"""
    from itertools import product
    with torch.no_grad():
        qs = [net(obs[:, i]) for i, net in enumerate(agent_qs)]   # 各 (B, n_actions)
        joint_ids = list(product(range(n_actions), repeat=len(agent_qs)))
        for b in range(qs[0].shape[0]):
            total = [sum(float(qs[i][b, a]) for i, a in enumerate(js)) for js in joint_ids]
            best_joint = joint_ids[int(torch.tensor(total).argmax())]
            best_indi = tuple(int(qs[i][b].argmax()) for i in range(len(qs)))
            # 若不一致, 说明分解实现有误(随机参数下平局概率可忽略)
            assert best_joint == best_indi, f"IGM 验证失败: {best_joint} vs {best_indi}"
    return True

解读：decentralized_greedy 是执行通路的全部内容，每个智能体只用自己的网络与观测，结构上排除协调通信。verify_igm 是值分解家族的单元测试模板：在随机初始化的网络上穷举联合动作，验证"联合 argmax 等于个体 argmax 组合"。（1）测试用小规模动作空间（32 = 9 条联合动作）即可完成，覆盖实现层面的索引错误。（2）断言消息区分"实现错误"与"平局"：严格相等在存在平局时可能误报，随机参数下平局概率可忽略，工程上可接受；正式实验中对平局需要定义稳定的破平局规则。该测试在第 007、008 章的混合网络改造后仍然适用，是值分解三章共享的质量闸门。

常见坑

  • 目标值忘记逐智能体 max。症状：TD 损失下降但策略不改进，Q 值整体膨胀。原因：目标用了执行过的动作价值，未取贪心价值，退化为行为值评估。修复：核对目标侧每个 q_next 都走了 max，并打印若干批次的 y 与 q_tot 比值。
  • 求和方法用错维度。症状：维度为 (B,) 的损失变成 (B, N) 或标量异常放大 N 倍。原因：sum(dim=1) 误写为默认全维求和。修复：在混合器内断言输出形状为 (B,)，并保持批维为第 0 维的全局约定。
  • 个体 Q 网络输入了全局状态。症状：训练指标正常，执行端性能崩塌。原因：个体网络被当作评论家使用，输入维度悄悄升级。修复：个体网络与集中式组件分属不同类，输入维度断言挂在构造函数上。
  • 目标网络遗漏个体网络之一。症状：更新若干步后出现系统性的正偏差。原因：新增个体网络时忘记同步目标副本，拷贝循环长度与网络列表长度不一致。修复：用列表推导成对构造在线与目标网络，并在初始化时逐个断言参数一致性。
  • ε 衰减过快加纯贪心执行。症状：训练早期探索不足，落入"全体停留"的零收益稳定点。原因：VDN 的个体贪心对平局动作破平规则固定，联合层面探索多样性不足。修复：探索率衰减期拉长或采用联合层面的探索扰动，同时检查平局规则是否为固定索引。

练习与思考

  1. 给定两个智能体、两个动作的个体价值表：Q1 = [2.0, 3.0]，Q2 = [1.0, 2.5]。写出 VDN 的联合价值矩阵（4 个条目），求联合 argmax 并验证它等于个体 argmax 的组合。★
    提示
    联合价值矩阵为 [[3.0, 4.5], [4.0, 5.5]]，联合最大奖 5.5 在 (1, 1)；两个个体 argmax 分别为 1 与 1，组合一致，IGM 成立。若把 Q2 改为 [3.0, 2.5]，联合最大变为 (1, 0) 仍等于组合，因为求和结构自动保证该性质。
  2. 把学习率从 5e-4 提高到 2e-3，预测训练曲线在前 104 步内的变化形态，并解释求和结构如何影响有效步长。★
    提示
    预期损失抖动加剧、Q 值过冲后回落，策略改进放缓。求和使总损失的梯度均分至 N 个网络，单网络有效步长与学习率成正比；学习率放大后个体差异信号被淹没，表现为过早同质化。
  3. 证明：若把混合器改为 Qtot = Σ Qi + b(s)（b 只依赖状态、与动作无关），IGM 条件仍成立；再证明若 b 依赖任一智能体动作，IGM 一般不再成立。★★
    提示
    不含动作项的 b(s) 在 argmax 中为常数，不影响最优集合。含动作的偏置等价于给联合价值添加与分解结构无关的项，可能把最优动作拖离个体最优组合，构造二维反例即可。
  4. 设计实验：在协作位移任务上对比 VDN 与第 003 章集中式评论家 + 显式演员的回报曲线；再构造"需同时到达才触发加成"的配对奖励任务，预测 VDN 的相对劣势并解释。★★
    提示
    协作位移任务的可加性较强，预计两者接近；配对奖励任务引入非负交互项，VDN 的加性结构欠表达，预期在触发协同的回合比例上落后，直接引出第 007 章。
  5. 设计题：构造一个超模交互任务（联合价值含 3·1[u1 = u2 = 1] 项，个体项偏向动作 0），推导 VDN 收敛的联合策略与联合最优策略的差距，并给出 QMIX 单调混合可修复该差距的直觉论证。★★★
    提示
    加性最优在动作 0；联合最优在 (1, 1)，差距 3 减去个体项损失。单调混合 ∂f/∂Qi ≥ 0 且依赖状态，可将"开关状态"编码进混合参数，使同一 Qi 值在不同状态下贡献不同，从而抬高 (1, 1) 的总价值。

小结

  • 值分解的目标是 IGM 条件：联合 argmax 可由个体 argmax 拼装；加性分解通过 Qtot = Σ Qi 自动满足该条件。
  • 训练用团队回报监督总价值，目标中的联合 max 在加性结构下严格等于逐智能体 max 之和，计算复杂度降为 O(N·|A|)。
  • 梯度经求和结构均分到每个个体价值，构成最粗糙的隐式信用分配；更精细的分配在信用分配专题展开。
  • 表达力边界在交互项非负的任务谱系，代价是低估需要联合才能触发的超额价值；第 007 章的单调混合网络对此修补。
  • 下一章：QMIX 单调性约束实现，用状态相关的非负权重混合网络把加性分解推广到单调族。
