第一篇 · CTDE 基础与核心算法

第 024 章：目标网络在CTDE中的使用

本章讲目标网络（Target Network）在 CTDE 中的构造与调度：柔性更新（Polyak Averaging）与硬更新的选择、值分解结构中目标值的逐层计算、双评论家与目标动作平滑，以及队友策略漂移带来的额外不稳定性。

  • 主题：目标值构造 / 自举稳定性
  • 关键公式：y = r + γ·maxa′ Q(s′, a′; θ−)；θ− ← τθ + (1−τ)θ−
  • 预计学时：50 分钟
  • 前置章节：第 023 章 经验回放在CTDE中的改进

学习目标

  • 理解自举（Bootstrapping）目标随参数更新移动所形成的反馈回路，以及"致命三要素"组合导致发散的机制。
  • 掌握硬更新与柔性更新的数学形式，能解释平滑系数 τ 对应的有效时间常数。
  • 掌握值分解算法中目标网络的逐层计算：个体目标网络与混合网络目标必须同时维护。
  • 理解多智能体特有困难：目标网络只能冻结自身参数，队友策略漂移的稳定作用来自更新节奏与共享数据。
  • 能实现统一的目标网络管理器，并为离策略与同策略算法分别给出是否需要目标网络的判断依据。

背景与动机

时序差分学习用网络自身的输出构造学习目标：目标值 y = r + γ·max Q(s′, ·; θ) 中的参数 θ 与正在被优化的参数完全相同，每次梯度更新都会移动目标本身。当函数逼近、自举与离策略采样三者同时出现时，这种"追逐自身输出"的结构可能形成正反馈，价值估计逐步发散或剧烈振荡，这一组合被称为致命三要素（Deadly Triad）。

目标网络用一个滞后于主网络的参数副本 θ− 计算目标值，把连续移动的目标转化为分段静止的参考点，切断反馈回路中的即时耦合。在 CTDE 中，目标网络还要覆盖值分解结构：混合网络与个体网络各有一套目标参数，目标值先在个体层计算、再经目标混合网络合成；此外，队友策略的持续更新让目标的"另一半"（联合动作分布）同样漂移，目标网络与更新节奏管理需要配合使用。

核心原理

1. 自举反馈回路与目标网络的作用

考虑查表更新的情形，时序差分目标 r + γV(s′) 使用真实回报，误差传播有界。引入函数逼近后，V(s′) 由参数化网络输出，更新 V(s) 会顺带改变 V(s′) 的估计，目标值随参数更新而移动。在离策略数据分布下，这条反馈回路可能使价值估计的误差被反复放大：网络抬高 V(s) 的输出，目标随之抬高，下一次更新又把输出推向更高的目标，形成单调漂移。

目标网络把目标中的参数替换为副本：

yt = rt + γ · maxa′ Q(st+1, a′; θ−) 目标使用滞后参数 θ−，主网络参数 θ 的更新在两次目标刷新之间不影响目标值

反馈回路的耦合被周期性地切断：在一个刷新周期内，目标是关于 θ 的固定函数，最小化均方误差的问题退化为普通回归，收敛行为更容易分析。目标网络的本质是把非平稳回归问题分段替换为静态回归问题，刷新周期越短，静态假设的持续时间越短。

2. 硬更新与柔性更新

两种刷新调度：

硬更新（每 C 步执行一次）：θ− ← θ C 典型取 200 到 5000 步；两次刷新之间目标完全静止
柔性更新（每一步执行）：θ− ← τθ + (1 − τ)θ− τ 典型取 0.005 到 0.01，目标参数每一步向主网络滑动一小段

柔性更新的累积效果是参数的历史指数平均：序列贡献权重按 (1 − τ)k 衰减，参数变化的有效时间常数约为 1/τ 步（把 (1 − τ)k 近似为 e−kτ 后的指数衰减长度），更精确的平均滞后为 (1 − τ)/τ 步：τ = 0.01 对应约 100 步的平滑窗口与 99 步的平均滞后。与硬更新相比，柔性更新不产生刷新瞬间的目标跳变，各时刻接收到的样本被平滑地混合进目标，训练曲线更平顺；代价是目标与主网络始终保持一定滞后，缺少"完全静止"的短暂窗口。多智能体环境下常选柔性更新，因为联合动作空间大、刷新跳变的瞬时冲击更明显。

数值算例：柔性更新的权重分解与两档调度的对照

把递推展开成权重序列：目标参数在第 t 步的取值近似等于历史主参数的加权平均，k 步之前的参数获得权重 τ(1 − τ)k。τ = 0.01 时权重总和 Σ τ(1 − τ)k = 1，参数的平均滞后 Σ k·τ(1 − τ)k = (1 − τ)/τ = 99 步；年龄不小于 100 步的参数合计权重为 (1 − τ)100 = 0.366，超过三分之一的目标信息来自百步以前。τ 换成 0.005 与 0.05 时平均滞后分别为 199 步与 19 步，与 1/τ 同阶。这组数字把取值依据具体化：批间间隔若为 100 步，τ = 0.01 的目标窗口与批次节奏同量级，目标值在相邻两个采样批次之间保持连贯。

对照硬更新。C = 500 步、批间间隔 100 步时，目标在刷新周期内经历 5 个批次保持完全静止，第 500 步一次性吸收主参数五个批次的累积移动；学习率越大，这段累积移动越大，缩短 C 可以让单次跳变幅度回落。工程上用一对日志曲线监控两种调度的差异：目标参数与主参数的距离序列在柔性更新下平滑，在硬更新下呈周期性锯齿，锯齿峰值与学习率、C 的乘积相关。这对曲线比损失曲线更早暴露目标震荡。

调度方式目标静止性跳变形态关键参数多智能体适用性
硬更新刷新周期内完全静止每 C 步一次整段跳变C 与学习率联动标定大联合动作空间下跳变冲击更明显

3. 值分解结构中的逐层目标计算

以 QMIX 为代表的值分解算法把联合动作价值写作个体价值经单调混合函数的输出：Qtot = fmix(Q1, …, QN; φ)。对应的目标值需要三层计算：

  1. 个体目标网络计算 Qi(o′i, a′i; θ−i)，其中 a′i 由个体目标网络的贪婪动作给出；
  2. 目标混合网络 fmix(·; φ−) 用同一组个体目标价值合成 Q−tot；
  3. 目标值 y = r + γ·Q−tot，梯度只回传主网络的 θ 与 φ。

混合网络的目标参数 φ− 与个体目标参数 θ− 必须同步维护，只复制个体网络而遗漏混合网络是实现的常见缺陷。目标混合网络仍然满足单调性约束，目标值的合成结构与在线网络一致，单调性蕴含的个体最优动作一致性在目标侧同样成立。

用一组小数字走一遍三层计算。取 N = 2、|A| = 3，下一观测处在线个体网络的输出为 Q1(o′) = (−1, 2, 0.5) 与 Q2(o′) = (0.3, −0.2, 1.1)，掩码全合法，于是 a′1 = 1（价值 2）、a′2 = 2（价值 1.1）。个体目标网络对这两个动作的评估为 Q−1 = 1.8、Q−2 = 0.9，目标混合器在下一状态下给出非负权重 0.6 与 0.7，则 Q−tot = 0.6×1.8 + 0.7×0.9 = 1.71，取 r = 0.1、γ = 0.99 得到目标值 0.1 + 0.99×1.71 = 1.7929。所有数字都来自目标侧，主网络的 θ 与 φ 不出现在这组计算里。

遗漏目标混合器的后果可以在这组数字上量出来。若混合器不做目标副本，仅有个体目标网络，则 Q−tot 用在线混合器权重计算；设在线权重已从 0.6 滑到 0.65，目标变为 0.65×1.8 + 0.7×0.9 = 1.80，对应的学习目标从 1.7929 升到 1.8820，单步目标抬升 0.0891。目标值随混合器参数更新而移动，这正是目标网络要切断的反馈回路。逐层清单因此需要包含：个体目标网络、目标混合器，以及边缘情况（终止步与无合法动作步）的目标截断处理。

4. 队友策略漂移与更新节奏

目标网络稳定的是逐智能体的价值参数，目标值中的联合动作分布由全部智能体的当前策略决定。分布式执行时智能体 A 的价值目标依赖于其他智能体的行为，队友策略的更新无法被 A 的目标网络冻结。三项工程手段用于缓解：

  • 更新节奏同步。所有智能体在同一次更新轮次内完成参数更新，避免部分智能体多步领先；参数共享结构下天然满足。
  • 目标刷新与数据采样对齐。柔性更新的 τ 与批次采样频率配合，使目标滞后时间与环境回合长度同量级以内。
  • 双评论家与目标动作平滑。连续动作场景（第 011 章 MATD3）用两个评论家取最小值抑制高估，并在目标动作上叠加小幅平滑噪声，降低目标对特定队友动作组合的过拟合。

与之相对，同策略算法（MAPPO、HATRPO 一类）的目标值由广义优势估计（GAE）在当前策略的数据上直接计算，数据天然与参数版本对应，无需目标网络；给同策略算法添加目标网络会引入没有必要的滞后，属于参数配置错误。

滞后窗口与队友更新节奏之间存在一个可计算的比值，用来判断目标参数的谱系是否合理。τ = 0.01 的 99 步平均滞后相对队友每 2×104 步一次的策略快照只是 0.5% 的尺度，价值目标对队友变化的跟随几乎即时，被平滑的对象主要是自身参数的更新噪声；把 τ 取到 0.2（平均滞后约 4 步）时静态回归窗口消失，目标与主网络同步移动，等同于没有目标网络。合理区间由两侧时间尺度夹定：明显小于数据分布漂移的时间尺度，又明显大于单个批次的噪声时间尺度。这个比值可以作为配置检查项写入实验档案，落在千分之一到十分之一之间属于常规区间，越界时触发一次目标参数复核。

实现思路与设计

目标网络管理器统一持有全部目标副本，接口包含构造、柔性更新、硬更新与批量同步四类操作。设计要点：目标网络与主网络结构相同、参数独立存储；前向在 no_grad 下执行；更新调用挂在优化器步进之后的位置。

参数默认值作用取值依据
更新方式柔性更新决定目标刷新形态值分解类算法默认柔性；单智能体重放类可硬更新
τ0.005 至 0.01柔性更新平滑系数对应约 100 到 200 步平滑窗口，不小于一个批次构建间隔
硬更新间隔 C200 至 5000 步硬更新跳变周期C 与学习率配合：学习率越大，C 取小让目标跟上
目标累加范围个体网络 + 混合网络保证目标合成完整值分解结构必须全量覆盖，遗漏任一层都会造成目标断裂
目标动作平滑 σ0.1 至 0.2连续动作去过拟合动作幅值归一化后取幅值的百分之十量级

与第 023 章的衔接点：优先级回写计算误差时使用与训练相同的目标值口径，避免"优先级来自旧目标、梯度来自新目标"的口径分裂。实现上把目标计算封装为学习器（Learner）上的单一函数，优先级回写与损失计算共用它。

关键代码与解读

片段 1：目标网络管理器

import torch
import copy

class TargetManager:
    """统一维护所有目标网络：个体网络与混合网络逐层覆盖。"""
    def __init__(self, nets, tau=0.01):
        # 深拷贝参数，目标网络与主网络共享结构但参数完全独立
        self.tau = tau
        self.targets = [copy.deepcopy(n) for n in nets]
        for t in self.targets:
            t.eval()                       # 关闭训练期行为（如 Dropout）
            for p in t.parameters():
                p.requires_grad_(False)    # 目标前向不建图，杜绝梯度回流

    def soft_update(self, nets):
        # 在优化器 step 之后调用：目标沿主参数方向滑动一小步
        with torch.no_grad():
            for t, n in zip(self.targets, nets):
                for pt, pn in zip(t.parameters(), n.parameters()):
                    pt.mul_(1.0 - self.tau).add_(pn, alpha=self.tau)

    def hard_update(self, nets):
        # 硬更新整段复制；与软更新二选一，不要混用同一组参数
        with torch.no_grad():
            for t, n in zip(self.targets, nets):
                t.load_state_dict(n.state_dict())

解读：单独一层的目标管理器让"哪些网络需要目标副本"成为配置项。构造时对参数做 requires_grad_(False) 与 eval()，即使前向忘记加 no_grad 也不会建立梯度图，这是防御性设计。柔性更新用原地运算 mul_ 与 add_，避免中间张量分配；更新调用点固定在优化器步进之后，保证一个优化步内主网络与目标网络的相对次序确定。hard_update 与 soft_update 互斥使用，默认配置选择其一写入实验配置。

片段 2：值分解目标值的逐层计算

def compute_target(batch, target_agent_nets, target_mixer, gamma):
    """QMIX 风格目标计算：个体目标 + 目标混合，全流程 no_grad。"""
    with torch.no_grad():
        n_agents, batch_size, obs_dim = batch["obs_next"].shape
        # 1) 从下一观测出发取贪婪动作：动作选择用目标网络，保持目标自洽
        q_next = torch.stack([net(batch["obs_next"][i]) for i, net in enumerate(target_agent_nets)], dim=1)
        q_next[batch["avail_next"] == 0] = -1e9      # 掩码不可行动作，防 argmax 选中非法动作
        actions_next = q_next.argmax(dim=-1, keepdim=True)
        chosen_next = q_next.gather(-1, actions_next).squeeze(-1)
        # 2) 经目标混合网络合成联合价值；单调性由目标网络的结构天然保持
        q_tot_next = target_mixer(chosen_next, batch["state_next"])
        # 3) 回合终止时只保留即时奖励，截断自举
        target = batch["reward"] + gamma * q_tot_next * (1 - batch["done"])
    return target

解读：该函数把目标计算集中在单一位置，优先级回写（第 023 章片段 3）复用同一口径。动作选择与动作评估都使用目标网络，保证目标值内部的一致性；若用在线网络选动作、目标网络评估，两个参数版本错位会引入额外噪声。终止标志的乘法截断让回合边界处的目标退化为即时奖励，这一步与目标网络平滑无关，但同样防止跨回合的错误自举。掩码在 softmax 与 argmax 之前生效，避免不可行动作参与贪婪选择。

片段 3：MATD3 风格的双评论家目标与动作平滑

def td3_target(actor_targets, critics_target, batch, gamma, noise_std=0.2, clip=0.5):
    """连续动作双评论家目标：动作平滑后取两个评论家的较小值。"""
    with torch.no_grad():
        n_agents = len(actor_targets)
        a_next = torch.stack([actor_targets[i](batch["obs_next"][i]) for i in range(n_agents)], dim=1)
        # 目标动作平滑：噪声降低目标对特定联合动作的过拟合，截断限制扰动幅度
        noise = (torch.randn_like(a_next) * noise_std).clamp(-clip, clip)
        a_next = (a_next + noise).clamp(-1.0, 1.0)     # 动作范围与环境接口一致
        # 两个目标评论家分别评估，取最小值抑制复合高估
        q1 = critics_target[0](batch["obs_next"], a_next, batch["state_next"])
        q2 = critics_target[1](batch["obs_next"], a_next, batch["state_next"])
        q_next = torch.min(q1, q2)
        target = batch["reward"] + gamma * q_next * (1 - batch["done"])
    return target

解读：目标动作平滑解决连续动作空间中"目标值对特定动作组合过拟合"的风险：策略更新后目标动作的小幅漂移不应引发目标值的剧烈变化，噪声注入让评论家对动作邻域内的扰动保持稳健。取最小值来自双重估计的偏差抑制原理，与多智能体无关但同样适用于联合评论家。clamp 双重约束（噪声幅度与最终动作范围）对应两个不同目的：前者限制平滑强度，后者维持与执行接口的动作边界契约。

常见坑

  • 只复制个体网络、遗漏混合网络。值分解的目标值与在线合成结构脱节，训练出现持续的高估漂移。症状是团队时序差分损失在初期下降后缓慢回升。修复：目标管理器按网络列表全量覆盖，单元测试比对目标参数与主参数的一致性。
  • 目标前向忘记关闭梯度。目标计算参与了反向传播，主网络被"目标中的自己"牵引，等价于删除了目标网络。修复：目标管理器构造时冻结参数，目标计算统一包裹 no_grad。
  • 更新调度配置混乱。硬更新间隔与学习率不匹配（学习率 1e-3 配 C = 50 步时目标几乎与主网络同步移动），或软硬更新混用使滞后程度不可控。修复：按 τ 的等效窗口设置柔性更新，硬更新将 C 设为百步量级以上；配置层限定二选一，并记录目标与主网络的参数距离。
  • 给同策略算法加目标网络。MAPPO 一类算法数据与参数版本对应，目标网络引入多余滞后，优势估计与实际策略错位。修复：按算法族分类：离策略自举类需要目标网络，同策略类使用裁剪代替。
  • 目标动作平滑噪声过大。σ 取 0.5 以上时目标值被随机扰动主导，评论家学到的动作邻域过宽。修复：从动作幅值的百分之十量级起调，并监控目标值与在线评估值的差距。

    提示
    把递推展开成几何级数，注意 (1−τ)k ≈ e−kτ（τ 很小时），指数衰减到 1/e 的步数约为 1/τ。
  2. 改参数预测：在值分解算法上把 τ 从 0.01 改为 0.3，预测目标网络滞后程度、训练曲线噪声水平与最终回报三个方面的变化。★
    提示
    滞后窗口从百步量级缩短到数步，目标几乎跟随主网络移动，曲线高频振荡加大；最终回报可能无显著下降，但达到同一水平所需的种子数增加。
  3. 设计：为一个单调混合的值分解算法设计目标更新流程，画出在线参数、目标参数、混合网络三者在一次优化步内的调用顺序，并标出每个环节是否需要 no_grad。★★
    提示
    目标计算与优先级回写全程 no_grad；优化器 step 之后执行目标柔性更新；注意混合网络的目标副本与个体目标副本的更新次序不影响结果，但必须同一次调用内完成。
  4. 实验设计：比较无目标网络、硬更新 C = 500、柔性更新 τ = 0.01 三种设置在相同种子集合上的时序差分损失曲线与回报曲线，说明各自适合报告的指标。★★★
    提示
    无目标网络组关注发散比例；两种更新方式对比曲线平滑度与中期回报；报告使用相同评估间隔，避免刷新时刻与评测时刻的共振偏置。

小结

  • 自举目标随参数移动形成反馈回路，与函数逼近、离策略采样构成致命三要素；目标网络把连续移动的目标替换为分段静止参考。
  • 硬更新按固定间隔整段复制参数，柔性更新按 τ 每步滑动；τ 对应约 1/τ 步的历史平滑窗口（平均滞后 (1−τ)/τ）。
  • 值分解结构中目标值需逐层计算：个体目标网络选出下一动作，目标混合网络合成联合价值，两层参数目标必须全覆盖。
  • 目标网络无法冻结队友策略漂移，需要更新节奏同步、滞后与回合长度匹配、双评论家与目标动作平滑配合。
