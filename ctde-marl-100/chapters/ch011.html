第一篇 · CTDE 基础与核心算法

第 011 章：MATD3双Critic实现

连续控制路线的稳定性修补：双评论家取最小压制高估、延迟策略更新先校正评论家、目标策略平滑压低误差尖峰。MATD3（Multi-Agent Twin Delayed Deep Deterministic Policy Gradient）在 MADDPG 骨架上增加三件套，本章逐项推导机理、实现并给出消融协议。

  • 主题：连续控制 / 高估抑制
  • 关键公式：y = r + γ (1 − done) · minj∈{1,2} Q′j(s′, a′ + clip(ε, −c, c))
  • 预计学时：50 分钟
  • 前置章节：第 010 章

学习目标

  • 理解连续控制评论家高估的成因：逼近误差被确定性目标与自举反复利用并放大。
  • 掌握双评论家取最小、延迟策略更新、目标策略平滑三项机制各自抑制的环节。
  • 会实现 MATD3 的评论家目标、更新时序与联合动作平滑噪声，并保持与第 010 章的接口一致性。
  • 会设计高估测量实验（蒙特卡洛对照）与三件套逐一消融协议。
  • 能说明取最小带来的悲观偏差与延迟更新的样本效率代价，理解两者与任务容错度的匹配关系。

背景与动机

第 010 章的 MADDPG 在连续控制问题上结构清晰，但训练中普遍出现一类故障：评论家的价值估计系统性高于真实回报，策略梯度沿着虚高的方向改进，最终陷入"评估漂亮、执行平庸"的状态。单智能体文献把这类现象称为高估偏置（overestimation bias），其放大机制有两步：函数逼近误差使某些动作的价值被高估；自举目标反复采用"下一时刻的贪心动作价值"，贪心选择优先落在正误差上，误差经时序差分回流并累积。

多智能体设定放大了这两个环节：评论家输入是高维联合动作，逼近误差更大；目标侧动作由确定性目标演员生成，没有随机策略的动作分布来平均掉误差。MATD3（Multi-Agent Twin Delayed Deep Deterministic Policy Gradient）把单智能体 TD3 的三项修补搬到多智能体：双评论家取最小直接惩罚正误差的传播路径，延迟策略更新降低"策略利用误差"的频率，目标策略平滑把目标动作置于一个小邻域的平均位置以避开误差尖峰。三项机制各有代价，本章的消融协议用于逐项量化收益与代价。

核心原理

本节先交代高估的自举放大机制，再拆解三件套各自的数学作用与代价，最后给出多智能体适配细节。

1. 高估的自举放大

记评论家 Qj(s, a; φ) = Qπ(s, a) + εφ(s, a)，其中 εφ 为逼近误差，可正可负。时序差分目标取下一动作的价值后回归：

y = r + γ Qφ(s′, μ′(o′))， 更新后 Q 在 (s, a) 处趋向 y 当误差函数 εφ 在 argmax 附近为正时，目标值被抬高；更新让 Q(s, a) 追随被抬高的目标，下一轮误差又在新的贪心点附近被采样，正误差沿轨迹逐步累积。若误差零均值且各点独立，期望意义下仍出现系统性偏高，因为"取所估计的贪心动作的价值"优先利用了正误差

多智能体版本中每个评论家面对 (s, a1, …, aN) 的高维输入，误差上界随维度上升；确定性目标动作没有分布平均效应。高估的后果在协作任务中表现为"策略相信某些联合配合一定能获得高回报"，而真实环境中该配合的收益低于估计，探索会被系统性误导。

2. 三件套的作用机理

（1）双评论家取最小。评论家 j ∈ {1, 2} 独立初始化、独立更新，目标取二者较小值：

y = r + γ (1 − done) · minj∈{1,2} Q′j( s′, a′1, …, a′N ) 两个独立误差同时为正的概率低于单一误差为正；取最小近似"悲观下包络"，正误差峰被惩罚。代价：误差同号向下时转变为低估，策略趋于保守

（2）延迟策略更新。评论家每环境步更新，演员每 d = 2 步更新一次，目标网络随演员更新一起软更新：

每步更新评论家； 每 d 步更新演员，随后一次 Polyak 软更新全部目标参数 机理：策略改进依赖评论家梯度，评论家误差要先被数据校正；延迟把"用未校正的评论家改策略"的频次减半。代价：策略改进速度下降，达到同等回报所需环境步数上升

（3）目标策略平滑。目标动作叠加截断噪声，相当于对目标策略做局部期望：

ã′i = μ′i(o′i) + clip( εi, −c, c )， εi ~ 𝒩(0, σ²)， 每个智能体独立采样 机理：若某动作点恰好是误差尖峰，邻域平均把目标值拉回平缓区域；独立噪声保证联合动作邻域被各方向覆盖。代价：目标值方差上升，平滑过强会让价值面失去细节

3. 多智能体适配细节

三件套在拓扑上的落点与单智能体不同：每个智能体持有自己的评论家对（Qi,1, Qi,2），目标值取该智能体自己两个评论家的最小；平滑噪声施加在"全体智能体的目标动作"拼接向量上，每个分量独立采样；演员损失仍只对自身动作求导。更新次序固定为评论家、演员（条件触发）、目标更新（紧随演员）三段。次序是算法定义的组成部分：若把目标更新提前到演员更新之前，目标动作与目标价值来自不同版本的策略，平滑与取最小的联合效果会被稀释，消融实验将显示稳定性差异。

5. 数值算例：取最小的悲观幅度与平滑的削峰比例

先量化取最小的偏差方向与幅度。设两个独立评论家在同一个函数点上各带一个等概率取值 {−1, +1} 的误差（单位误差、对称分布、均值为零），四种误差组合等概率出现，聚合方式的期望偏差为：取平均 0（无偏），取最大 +0.5（乐观），取最小 −0.5（悲观），数值经程序核对。结论有两层：其一，取最小与"双估计器取最大"的偏差幅度相同、符号相反，MATD3 用悲观替换乐观，把高估故障换成经过标定的低估；其二，偏差幅度与误差分布宽度成正比，误差尺度为 δ 时期望偏差约为 0.5δ，任务回报尺度远大于 δ 时该偏差可忽略，回报尺度与 δ 同阶时必须把悲观偏差计入策略评估结论。

再量化目标平滑的削峰力度。设某动作维上误差呈窄峰，峰宽 w = 0.05（按高斯形状衡量），峰值幅度 1；平滑噪声标准差 σ = 0.2、截断 c = 0.5。叠加噪声后目标值的期望为峰形与噪声分布的卷积，峰值贡献从 1 衰减为 w / √(w² + σ²) = 0.05 / √(0.0025 + 0.04) = 0.2425，约 76% 被削掉；把峰宽放大到 w = 0.1 后衰减系数升到 0.4472，削峰减弱到约 55%。读数方法：平滑对"窄尖峰"压制强、对"宽缓起伏"几乎不动（峰宽远大于 σ 时系数趋近 1）。误差尖峰通常来自单点过拟合、尺度较窄，真实价值面上的宽结构需要被保留；σ 的选择因此等价于声明"多宽的起伏按噪声处理"，σ = 0.2 在动作幅度为 1 的设定下抑制尺度约为 0.2 以下的起伏。

延迟系数还可以精确换算：演员更新次数约为环境步数的 1/d。在固定环境步预算下要恢复 MADDPG 同量的演员更新，需要把环境步数乘以 d，或把批大小与演员学习率提到等效带宽；前者增加采样成本，后者改变优化动力学，两条路径都说明延迟的收益以样本效率为代价。工程折中：先按 d = 2 跑基线，若回报曲线的快速改进段明显偏后（前期平台期拉长），再把 d 降到 1 做对照，或将演员学习率提高一档观察。若任务允许在更长的交互预算内收敛，延迟几乎没有副作用；交互预算紧张时它是最先被削减的组件。

实现思路与设计

本节给出 MATD3 的组件与配置，沿用第 010 章的环境与数据接口，增量集中在评论家数量、目标构造与更新时序。

实现层面需维护一个更新计数器 step_t，三种事件挂在计数器 mod d 的余数上。第 010 章的评论家类继续复用，加一层"评论家对"包装。数据接口唯一的增量是目标平滑的噪声配置字段：噪声尺度与截断为全局常量，不随状态变化，保证目标构造确定可复现（固定种子情况下）。

设计决策：取最小作用于评论家对的理由

更精细的方案是显式估计并减去误差（例如双评论家的差作为方差代理），实现复杂度高且引入新的超参。取最小的优点是零额外超参、计算开销为一个前向的价值读取，且与"独立误差同时为正概率低"的直觉直接对应。c 与 σ 是本章仅有的两个新增连续超参，窄搜索即可：σ 取动作幅度的一半量级，c 取 2σ 附近，先固定后各自微调。

关键代码与解读

片段 1：评论家对与目标取最小

def twin_critic_target(q1_t, q2_t, target_actors, ns, nobs_next, done, rew,
                       gamma=0.95, sigma=0.2, c=0.5):
    """目标值 = r + gamma * min(Q1', Q2'), 目标动作加截断平滑噪声。"""
    with torch.no_grad():
        # 联合目标动作: 每个智能体独立采样噪声, 保证邻域各方向被覆盖
        a_next = []
        for i, ta in enumerate(target_actors):
            a_hat = ta(nobs_next[:, i])
            eps = torch.randn_like(a_hat) * sigma
            a_next.append(a_hat + eps.clamp(-c, c))    # 截断限制单步偏移
        a_next = torch.cat(a_next, dim=-1)
        q1 = q1_t(ns, a_next)
        q2 = q2_t(ns, a_next)
        y = rew[:, 0] + gamma * (1.0 - done[:, 0]) * torch.minimum(q1, q2)
    return y

解读：这段函数是本章理论的核心实现。（1）噪声在每个智能体的动作上独立采样，torch.randn_like 的形状与动作一致；若全部智能体共享同一噪声向量，联合目标的偏移方向单一，平滑退化为沿对角线的移动。（2）clamp(-c, c) 把采样值截断在对称区间，截断位置的梯度为零（在 no_grad 内无影响，语义上表示"极端偏移不被允许"）。（3）torch.minimum(q1, q2) 逐元素取小，与逐智能体的评论家对一一对应；两个评论家在同一批次、同一目标动作上求值，保证比较的是同一函数点的两个估计。

片段 2：更新时序

def matd3_step(agents, batch, step_t, d=2, tau=0.01):
    """一次完整更新: 评论家每步, 演员与目标按延迟系数 d 触发。"""
    s, acts, rew, ns, nobs, done = batch
    for ag in agents:
        # 评论家对: 两个网络分别对同一个 min 目标回归
        y = twin_critic_target(ag.q1_t, ag.q2_t, [a.target_actor for a in agents],
                               ns, nobs, done, rew)
        for q, opt in ((ag.q1, ag.opt_q1), (ag.q2, ag.opt_q2)):
            loss_q = ((q(s, acts) - y) ** 2).mean()   # 双网络共享目标, 独立参数
            opt.zero_grad(); loss_q.backward(); opt.step()
    # 延迟触发: 演员与目标只在 step_t % d == 0 时更新
    if step_t % d == 0:
        for ag in agents:
            # 演员损失: 只用 Q_i 对自己动作的梯度, 其他动作为常数
            a_i = ag.actor(ag.obs_i(batch))
            others = ag.others_acts(batch).detach()
            q_val = ag.q1(s, torch.cat([others, a_i / ag.act_scale], dim=-1))
            loss_a = -q_val.mean()
            ag.opt_a.zero_grad(); loss_a.backward(); ag.opt_a.step()
        for ag in agents:
            # 目标参数一次 Polyak 滑动: 演员与双评论家成对更新
            for online, target in ag.online_target_pairs():
                for p_o, p_t in zip(online.parameters(), target.parameters()):
                    p_t.mul_(1.0 - tau).add_(p_o, alpha=tau)
    return step_t + 1

解读：时序函数把"频率"落实为显式分支。（1）评论家更新在每个环境步都发生，演员与目标更新挂在 step_t % d 条件内；三者共享同一批次，评论家与演员看到的数据快照一致。（2）演员损失复用第 010 章的写法：只对自身动作求导、其他动作 detach；延迟策略下同一批次被评论家多学一轮，策略改进更干净。（3）目标滑动紧随演员更新，保证"目标策略版本"与"目标价值版本"在同一节奏上前进；online_target_pairs() 把需要成对维护的网络集中声明，避免遗漏评论家对中的某一个。

片段 3：高估测量

def overestimation_report(agents, eval_states, env, n_episodes=20):
    """在同一评估状态集上比较 Q 估计与蒙特卡洛回报的平均差距。"""
    import numpy as np
    est = []
    for s in eval_states:
        # 估计侧: 双评论家取小后的价值作为"经过悲观化的估计"
        with torch.no_grad():
            q_min = float(torch.minimum(agents[0].q1(s), agents[0].q2(s)).mean())
        est.append(q_min)
    mc = []
    for _ in range(n_episodes):
        obs, _ = env.reset()
        done, ret, t = False, 0.0, 0
        while not done:                            # 评估策略滚动: 不加探索噪声
            acts = [ag.actor.act_greedy(obs[i]) for i, ag in enumerate(agents)]
            obs, _, r, done = env.step(acts)
            ret = ret + (0.95 ** t) * r              # 折扣回报, 与 gamma 对齐
            t += 1
        mc.append(ret)
    # 差距显著为正提示高估残留; 由正转负提示取最小带来低估
    return float(np.mean(est) - np.mean(mc))

解读：测量函数把"高估"从定性描述变为可随着训练周期记录的数值。（1）估计侧使用双评论家取小的结果，测量的是"经过悲观化后"的价值估计；这个量接近蒙特卡洛回报说明三件套工作正常，显著为正说明高估残留，显著为负说明保守过度。（2）蒙特卡洛回报用与训练一致的折扣因子累加，评估策略不带探索噪声，回报分布才与 Q 的定义对齐。（3）函数只读参数、不触发更新，可以作为训练回调按固定步数间隔调用；把该曲线与回报曲线并列观察，能在回报下降时第一时间区分"高估被纠正"与"策略退化"两种不同原因。

常见坑

  • 双评论家初始化相关。症状：取最小与单评论家效果几乎无差别，高估曲线与 MADDPG 重合。原因：两个评论家从相同种子或相同数据顺序起步，误差高度相关。修复：独立初始化并验证两个评论家在早期批次上的输出相关系数明显低于 1。
  • 把平滑噪声加到行为探索上。症状：探索不足且目标值噪声增大。原因：平滑噪声与行为噪声共用同一配置。修复：两者拆成独立参数，平滑噪声只出现在目标构造内部、位于 no_grad 段。
  • 目标更新与演员更新不同步。症状：训练出现周期性抖动，价值曲线与目标值差距反复张开。原因：目标网络每步更新但演员延迟，目标动作与目标价值版本错位。修复：把目标更新放进延迟分支，并与演员更新顺序相邻。
  • 延迟系数与学习率联调失误。症状：策略改进极慢或出现停滞。原因：d 过大同时又降低学习率，改策略的"带宽"过低。修复：先固定 d = 2 与第 010 章学习率，确认改进速度后再单独调整 d。
  • 用单评论家输出做评估。症状：测量脚本显示低估而实际执行偏保守。原因：评估时只读 q1，未包含 min。修复：所有面向外部的价值报告统一经过 min 聚合函数，避免"训练用 min、报告用单个"的口径不一致。

练习与思考

  1. 给定同一状态动作点上两个评论家估计 Q1 = 5、Q2 = 2，真实回报为 3。分别计算"取最小"与"取平均"作为目标时，下一轮回归对价值估计的推动方向，并说明哪种更抑制正误差。★
    提示
    取最小目标值 2，向下拉动估计，惩罚 5 的正误差；取平均目标 3.5，仍高于真实回报，偏乐观的估计被保留。取最小对正误差的惩罚更直接。
  2. 把延迟系数从 2 改为 1（退化为每步更新演员），预测高估曲线与回报曲线的变化，并说明此时算法与第 010 章的差异还剩哪些。★
    提示
    d = 1 后平滑与取最小仍在，但策略更新频率恢复；预期高估略升、收敛更快，与第 010 章的差异退化为"双评论家 + 平滑"两项，正好作为消融对照组。
  3. 论证：两个零均值独立误差中"同时取正"的概率低于单个误差取正的概率，并说明该论据对"低估风险"的对称含义。★★
    提示
    独立同分布下 P(两者皆正) = P(正)²，小于 P(正)；同理两者皆负的概率同为 P(负)²，取最小在负侧同样激进，低估风险与高估抑制同一机制的两种表现。
  4. 设计消融：三件套（双评论家、延迟更新、目标平滑）各去掉一项，共四个配置。给出每组的高估测量曲线、回报曲线与所需环境步数，说明如何从结果判定某项对该任务是否必要。★★
    提示
    判定标准：去掉某组件后高估测量显著恶化且回报下降，说明必要；若高估测量不变且回报相当，说明该任务结构中该项贡献小。四组共享随机种子与超参，唯一变量为组件开关。
  5. 设计题：目标平滑的噪声幅度若改为状态相关的（例如依动作范围或价值坡度自适应），给出一种可实现的方案设想、可能收益与引入的新风险。★★★
    提示
    方案例：σ(s) 正比于该状态下两评论家估计差值（不确定度代理），差大处多平滑。收益是平滑强度对齐不确定区域；风险是噪声尺度随估计反馈形成闭环，估值噪声被自我放大，需要限幅与滑动平均。

小结

  • 高估偏置由逼近误差与自举放大两个环节构成；多智能体的高维联合动作输入与确定性目标放大这两个环节。
  • 双评论家取最小压制正误差传播；延迟策略更新降低"策略利用误差"的频率；目标平滑把目标动作置于邻域平均位置。
  • 多智能体适配：逐智能体评论家对、独立平滑噪声、目标更新随演员触发；次序是算法定义的一部分。
  • 代价是悲观偏差与样本效率下降；高估测量（估计对蒙特卡洛）与三件套消融是必要的实验环节。
