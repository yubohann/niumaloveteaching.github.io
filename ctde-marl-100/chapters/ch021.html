第一篇 · CTDE 基础与核心算法

第 021 章：基于奖励重塑的CTDE

本章讲奖励重塑（Reward Shaping）与势能式奖励重塑（Potential-Based Reward Shaping, PBRS）：在稀疏奖励下为集中式训练补充密集反馈信号，同时用势能差分保证最优策略集合不发生改变。

  • 主题：训练信号设计 / 奖励重塑
  • 关键公式：F(s, s′) = γΦ(s′) − Φ(s)
  • 预计学时：50 分钟
  • 前置章节：第 020 章 多智能体信用分配

学习目标

  • 理解奖励重塑（Reward Shaping）的一般形式，以及任意塑形项会改变最优策略的风险来源。
  • 掌握势能式奖励重塑的最优策略不变性定理，能独立完成望远镜求和（Telescoping Sum）推导。
  • 理解多智能体条件下势能可分解性的含义，以及集中式训练与分布式执行（Centralized Training with Decentralized Execution, CTDE）之间的张力。
  • 掌握势能函数在训练流水线中的两种部署位置，以及缩放系数、折扣一致性的选择依据。
  • 能用数值实验验证策略排序不变性，并诊断塑形权重过大造成的策略偏置。

背景与动机

多智能体任务的联合奖励通常稀疏：整支队伍只有在占据目标点或完成协同动作时才收到一次信号，单步动作与最终成败之间的关联被长时间跨度掩盖，信用分配（Credit Assignment）无从谈起。奖励重塑在原始奖励上叠加一个塑形项 F，把"离目标更近、更少碰撞、更好覆盖"这类先验知识注入训练信号，缓解稀疏性与延迟性。

代价是任意塑形项会改写回报地形，可能诱导出与任务目标相悖的最优策略：智能体可能学会绕圈累积塑形奖励而永远不完成任务。势能式奖励重塑给出了充分条件：只要塑形项写成势能的折扣差分，策略优劣排序保持不变。在 CTDE 中还多一层约束，训练阶段可以访问全局状态，执行阶段只有局部观测，塑形项的信息依赖必须与这条边界相容。

核心原理

1. 一般形式的奖励重塑及其风险

奖励重塑把环境奖励修改为：塑形项的设计质量直接决定训练结果是加快收敛还是引入策略偏置。

R̃(s, a, s′) = R(s, a, s′) + F(s, a, s′) R 为环境原始奖励，F 为塑形项，R̃ 为训练使用的修改奖励

对 F 不加约束时，最优策略可能被彻底改写。经典反例是"绕圈问题"：若塑形项奖励"接近目标"，智能体可以在目标附近反复进出获得持续塑形收益，而完成任务本身只带来一次性原始奖励；当折扣因子较大时，绕圈的累计回报超过直接完成任务，最优策略从"完成任务"漂移为"原地绕圈"。这一风险在多智能体场景中被放大，重写联合回报地形会同时改变大量个体策略的协调结构。

2. 势能式重塑与回报平移定理

势能式奖励重塑限制塑形项的形状：引入势能函数 Φ（Potential Function），定义在状态空间上，塑形项取相邻两状态势能的折扣差分：

F(s, s′) = γΦ(s′) − Φ(s) γ 为折扣因子，Φ(s) 为状态 s 的势能值，s′ 为转移后的下一状态

此时沿任意轨迹的塑形项累计出现逐项抵消，即望远镜求和：

Σt=0T γtF(st, st+1) = γT+1Φ(sT+1) − Φ(s0) → −Φ(s0) T → ∞ 或终态势能取 0 时，累计塑形只留下与初始状态有关的常数项

推导过程：把 F 展开为 Σ γt+1Φ(st+1) 与 Σ γtΦ(st) 之差，前者作指标平移 t → t+1 后与后者逐项相消，只剩首尾两项。于是任意策略 π 的塑形折扣回报满足：

Ṽπ(s0) = Vπ(s0) − Φ(s0) 所有策略被同一个常数 Φ(s₀) 平移，策略之间的优劣排序不变，最优策略集合不变

这就是势能式重塑的全部合法性来源：塑形项不改变任何策略的排序，只改变回报的数值尺度。直觉上可以把 Φ 理解为"重排了回报的记账方式"：练习时每次进步都提前发一部分"预支分"，但当整段轨迹结算完，预支与偿还恰好抵消，只有起点势能作为常数留在了账上。

数值算例：一条三步轨迹的抵消过程与折扣错配的残差

给定势能序列 Φ(s0) = 3.7、Φ(s1) = 5.2、Φ(s2) = 4.1、Φ(s3) = 0（终态势能为零），折扣因子 γ = 0.9，轨迹包含三个转移。逐步塑形项为 F0 = 0.9×5.2 − 3.7 = 0.98，F1 = 0.9×4.1 − 5.2 = −1.51，F2 = 0.9×0 − 4.1 = −4.1。按折扣加权求和：0.98 + 0.9×(−1.51) + 0.81×(−4.1) = 0.98 − 1.359 − 3.321 = −3.7，恰好等于 −Φ(s0)。注意中间两站一升一降、幅度各异，总和却只由首尾势能决定，抵消结构对轨迹形状不敏感。

折扣错配的危害可以用同一轨迹量化，这是"塑形折扣必须与环境折扣严格相等"这条取值依据的算术根据。取 γshape = 1.0 而环境折扣仍为 0.9，塑形项变为 F0 = 5.2 − 3.7 = 1.5，F1 = 4.1 − 5.2 = −1.1，F2 = 0 − 4.1 = −4.1，按环境折扣加权和为 1.5 − 0.99 − 3.321 = −2.811，与 −3.7 相差 0.889。这个差值一般地等于 (γshape − γ)·Σt γtΦ(st+1)，与轨迹上的势能取值相关：不同策略受到的平移量不再相同，策略排序因此被系统性扰动，且残差随回合计入的势能总量与回合长度增长。

γshape ≠ γ 时的加权和 = γT+1Φ(sT+1) − Φ(s0) + (γshape − γ)·Σt γtΦ(st+1) 残差项与轨迹相关；γshape = γ 时残差归零，望远镜求和结构恢复

代入验证：0.1×(5.2 + 0.9×4.1) = 0.889，与逐项算出的差值一致。工程含义有两条：其一，折扣错配的残差在势能量级与回合长度上双重增长，长回合任务的策略偏置最明显；其二，残差符号随 γshape − γ 的符号翻转，取大塑形折扣时塑形回报整体偏正（乐观偏置），取小时偏负（悲观偏置），监控塑形回报与原始回报的差值曲线可以直接看到残差的漂移。

3. 多智能体条件下的可分解性

在 CTDE 中，势能函数定义在全局状态 s 上时，训练阶段可由集中式模块计算。关键问题出现在两个层面：

  • 优化层面。若所有智能体共同优化同一个联合回报，用全局势能 Φ(s) 塑形团队奖励，联合最优策略不变，个体策略的协调结构也不变，这是最安全的使用方式。
  • 分解层面。若每个智能体维护独立的个体回报（例如各类独立学习基线），塑形项必须写成可分解形式 F = Σi[γΦi(o′i) − Φi(oi)]，即全局势能是各局部势能之和 Φ(s) = ΣiΦi(oi)。此时每个智能体的塑形项只依赖本地观测轨迹，分布式执行阶段无需额外信息。

如果对个体回报分别使用互不相容的势能（例如各自奖励"靠近自己偏好的目标"），博弈的效用结构被改写，均衡点可能发生迁移，即使每个单独的塑形都满足势能形式。结论：势能式重塑的合法性针对单一决策者的联合回报成立，多智能体中使用时必须明确塑形作用于哪个回报层。

4. 常用势能函数与近似形式

工程上常见的三类势能设计：距离型 Φ(oi) = −β·d(oi, g)，以到目标的距离取负，引导智能体缩短行程；覆盖型，以已覆盖区域比例或信息熵构造；进度型，用某过程量的推进幅度（如占据点数、协作链完成度）构造。三类函数共享同一判据：势能的差分必须能被解释为"向任务完成的净推进"，否则抵消结构只在数学上成立、在直觉上具有误导性。与差分奖励（Difference Reward）的关系是：差分奖励把"本个体相对默认行为的边际贡献"作为个体信号，属于信用分配层；势能重塑把先验知识注入奖励层，两者可以叠加，塑形项仍须满足势能形式以保持团队最优。

5. 适用边界与失效模式清单

势能式重塑的定理有几条隐含的适用条件，工程实现时对应具体的失效模式。条件是势能函数有界、折扣因子一致、终态势能取零；集中式训练中势能可基于全局状态定义，执行期不参与计算，这两条路线都不受影响。把条件破坏后的行为按行整理：

失效模式触发条件症状修复
残差漂移塑形折扣与环境折扣不相等策略排序被系统性偏置，偏差随回合长度增长配置层断言两者相等，残差公式见上一节
终态残留势能在终止状态不取零回合末端出现固定量级的附加回报，行为在末端异常令 Φ(终止) = 0，或把终态势能并入折扣裁剪
残差不收敛势能随状态无界增长长回合训练回报持续偏移，价值目标漂移选用有界势能：距离、覆盖比例、进度百分比都在界内
效用改写个体回报使用互斥的局部势能联合策略收敛到局部协调结构，全局长程收益受损塑形统一作用于团队回报，或验证局部势能之和等于全局势能

终态残留的量级可以估算：γ = 0.99、回合长度 200 步、终态势能 Φ = 5 时，残留项 γT+1Φ = 0.99201×5 ≈ 0.67，与常规步级奖励同量级，足以在回合末尾几十步内改变动作偏好。这解释了实现规范里"reset 时重新初始化势能缓存"与"终态势能取零"两条约定的地位：它们属于定理成立的技术条件，与编码风格无关。超出这些边界时，塑形与原始任务之间的回报差不再是常数，策略排序的保序承诺失效。

把边界条件按使用场景再排一遍，便于实现时逐项自检。单智能体任务里最容易违反的是折扣一致性，因为塑形模块与算法模块常由不同代码路径提供折扣参数；多智能体任务里最容易违反的是效用改写，因为每个智能体的局部势能看起来都合法；课程或对抗这类奖励分布不断变化的任务里最容易违反的是有界性，势能若按任务进程冗余编码（例如把回合编号当作势能），长训练下残差会随分幕长度累积。

实现思路与设计

奖励重塑在训练流水线中有三个可插入的位置，选择位置等于选择"数据可逆性"与"调试灵活性"的权衡。

部署位置作用时机优点代价
环境包装器环境步进返回奖励时立即修改训练循环无感知；与现有算法解耦最彻底数据不可逆，事后无法恢复原始奖励做消融
回放缓冲区写入前过渡数据（Transition）入池前修改可按对手/阶段选择性塑形需修改采样代码路径，跨实现移植成本高
损失计算层计算目标值时组合 r + F权重可在线调整，便于消融实验需在每个算法的目标式计算处维护一份塑形逻辑

超参数与取值依据

参数默认值作用取值依据
塑形折扣 γshape与环境 γ 相同参与势能差分必须严格相等，否则望远镜求和无法完成抵消
缩放系数 β0.1 至 0.5控制势能幅值塑形项量级不超过原始奖励单步量级的一个百分比区间
势能归零方式终态 Φ = 0保证求和收敛否则残留项 γT+1Φ(sT+1) 破坏平移结构
退火策略固定或后段线性衰减减弱先验偏差任务后期原始奖励逐渐密集时，可降低塑形权重

与第 020 章的差异点：信用分配处理的是"已有的联合回报如何归因"，本章处理的是"在归因之前先把信号本身设计得更密集"。两者的衔接顺序是奖励塑形在前、信用分配在后，COMA 一类的反事实基线仍然作用于塑形后的奖励结构。

关键代码与解读

片段 1：势能式塑形包装器（单智能体视角，接口习惯参照 PyMARL 的奖励预处理层）

import numpy as np

class PotentialShaping:
    """势能式奖励重塑：保存上一步势能，逐步计算 F = gamma*phi(s') - phi(s)。"""
    def __init__(self, gamma, beta=0.2, goal=np.array([0.0, 0.0])):
        # gamma 必须与环境折扣因子完全一致，否则望远镜求和无法抵消
        self.gamma = gamma
        self.beta = beta          # beta 控制塑形强度，过大时策略由塑形项主导
        self.goal = goal
        self.phi_prev = None      # 缓存上一步势能，避免重算与错位

    def phi(self, obs):
        # 距离型势能：取负距离，使“靠近目标”对应势能上升
        return -self.beta * np.linalg.norm(obs[:2] - self.goal)

    def reset(self, obs):
        # 回合开始时初始化势能；跨回合沿用旧值会让首步塑形项携带上一回合残留
        self.phi_prev = self.phi(obs)

    def shape(self, reward, obs_next):
        # 用 gamma*phi(s') - phi(s) 改写奖励，再把缓存前移一步
        phi_next = self.phi(obs_next)
        shaped = reward + self.gamma * phi_next - self.phi_prev
        self.phi_prev = phi_next
        return shaped

解读：这个类的三个设计点都服务于同一个定理。其一，phi_prev 缓存上一步势能，避免每步重算轨迹上的全部势能，因为 F 只依赖相邻两状态，缓存把计算代价降为 O(1)；其二，reset 时必须重新初始化势能，否则新回合第一步的差分把两个回合拼接，抵消结构断裂；其三，shape 的返回值直接作为训练奖励使用，调用方无需知道塑形逻辑的存在。工程实现中该包装器通常挂在环境步进的出口，对应上表的第一种部署位置。

片段 2：多智能体局部势能的团队合成

def team_shaping(obs, obs_next, gamma, potentials):
    """把各智能体的局部势能合成为团队塑形项，写入回放池之前调用。

    obs / obs_next: 形状为 (n_agents, obs_dim) 的批量观测
    potentials:     每个智能体的势能函数列表 phi_i(obs_i)
    """
    total = 0.0
    for i, phi in enumerate(potentials):
        # 每项都是 gamma*phi_i(o') - phi_i(o)，对应全局势能的分解形式
        total += gamma * phi(obs_next[i]) - phi(obs[i])
    # 团队奖励叠加同一个合成塑形项：联合回报只被常数平移，最优联合策略不变
    return total

解读：合成方式决定了定理是否成立。把每个局部势能的差分先求和、再一次性叠加到团队奖励上，等价于使用全局势能 Φ(s) = ΣiΦi(oi)，望远镜求和仍然适用。如果换成"每个智能体把自己的塑形项加进自己的个体奖励"，则公式表面相同、语义已变，效用结构被改写。这个函数在多智能体缓冲区（Buffer）写入前被调用一次，天然保持了所有智能体看到同一塑形项的一致性。

片段 3：数值验证回报排序不变性

def discounted_return(rewards, gamma):
    """按 gamma 折扣累计一条轨迹的回报。"""
    out, power = 0.0, 1.0
    for r in rewards:
        out += power * r
        power *= gamma
    return out

def check_invariance(path_a, path_b, gamma, phi0=3.7):
    """验证塑形后两策略回报差不变：理论上两者同减常数 Phi(s0)。"""
    base_a = discounted_return(path_a, gamma)
    base_b = discounted_return(path_b, gamma)
    shaped_a = base_a - phi0      # 塑形回报 = 原始回报 - Phi(s0)
    shaped_b = base_b - phi0
    gap_before = base_a - base_b
    gap_after = shaped_a - shaped_b
    # 差值应当严格相等，浮点误差量级控制在 1e-9 以内
    assert abs(gap_before - gap_after) < 1e-9
    print(f"策略差 塑形前 {gap_before:.6f} / 塑形后 {gap_after:.6f}")

解读：这段脚本的作用是把定理变成可执行的断言。phi0 取任意常数都不影响断言成立，这本身就是定理的内容：平移量与环境、策略无关，只与初始势能有关。做消融实验时，可以先用该函数确认实现没有破坏抵消结构，再进入完整训练，避免把实现错误误判为"塑形无效"。需要注意的是，该断言只验证数学性质，塑形对收敛速度的影响仍需通过环境步数到目标回报的对比曲线衡量。

常见坑

  • 塑形折扣与环境折扣不一致。塑形项用 γ=1.0 而环境用 0.95 时，Σ 中的抵消不再逐项成立。症状是策略排序被塑形项系统性偏置，且偏差随回合长度增长。修复：塑形类显式接收环境折扣因子，并在配置层做一次断言。
  • 势能跨回合残留。回合终止后没有重置势能缓存，首步差分把上一回合末态与当前初态拼接。症状是回合边界处出现异常大的奖励尖峰。修复：在环境的 reset 回调中同步重置塑形器。
  • 对个体回报使用互斥势能。每个智能体被各自的目标势能牵引，联合策略在有限训练步数内收敛到局部协调结构。修复：塑形项统一作用于团队回报，或确证局部势能之和等于全局势能。
  • 塑形权重过大。β 使塑形项量级超过原始奖励后，回报地形由塑形项塑造，智能体停在势能高点附近不再推进任务。修复：从 0.1 量级起调，同时监控塑性回报与原始回报的比值曲线。
  • 与奖励裁剪（Reward Clipping）混用。先塑形后裁剪会在量级超限处截断，破坏望远镜求和的线性结构。修复：裁剪只作用于原始奖励，塑形在裁剪之后叠加。

练习与思考

  1. 推导：设终态势能为零，写出 Σt=0TγtF(st, st+1) 的完整展开式，证明其等于 −Φ(s0) + γT+1Φ(sT+1)。★
    提示
    把求和拆成两项后对第一项做指标平移 t → t+1，观察中间项逐一相消，只剩首尾。
  2. 改参数预测：把 β 从 0.2 提高 50 倍到 10，预测 "到达目标" 与 "在目标附近绕圈" 两种行为在训练 10 万环境步后的回报对比，并说明与势能定理是否矛盾。★
    提示
    定理保证最优策略排序不变，但有限步训练加上函数逼近误差，极大塑形项使塑形分项主导梯度信号，收敛到的是塑形回报意义下的最优，与原始回报的最优存在偏差。
  3. 设计：在一个 3 智能体协同搬运任务中，设计一组局部势能 Φi 使 ΣiΦi 单调对应协作进度，并说明每一项的可计算范围（哪个智能体在什么阶段能算到它）。★★
    提示
    可把进度分解为各自到搬运点的距离之和加上负载离合状态；局部项只用本地观测，团队项由集中式模块在训练阶段计算。
  4. 实验设计：在同一稀疏奖励任务上对比无塑形、势能式塑形、任意形式塑形（例如直接奖励接近目标）三种设置，画出台数到目标回报的曲线并解释任意形式塑形的失败模式。★★★
    提示
    三条曲线使用同一随机种子集合；关注任意形式塑形在中后期是否出现回报回落或策略振荡，那正是回报地形被重写的信号。

小结

  • 奖励重塑用塑形项 F 为稀疏奖励补充密集信号，任意 F 会改写最优策略，势能式差分是保持策略排序不变的充分条件。
  • 回报平移定理：F(s, s′) = γΦ(s′) − Φ(s) 时，塑形回报等于原始回报减去常数 Φ(s0)，推导依赖望远镜求和。
  • CTDE 中使用塑形必须明确作用层：团队回报配全局势能最安全；个体分解需满足 Φ(s) = ΣiΦi(oi) 且共享同一塑形项。
  • 部署位置三选一：环境包装器、缓冲区写入前、损失计算层，分别对应操作简便、选择性塑形、消融灵活。
