第一篇 · CTDE 基础与核心算法

第 018 章：部分可观测马尔可夫决策过程建模

回到第 001 章的元组深水区：状态不可见时，最优决策依赖观测历史；信念状态给出理论上的充分统计量，循环记忆给出可训练的近似。本章讲清信念更新与记忆架构的对应关系，实现序列化训练流程，并给出感知别名的诊断与修复流程。

  • 主题：部分可观测建模 / 信念与记忆
  • 关键公式：b′(s′) ∝ O( o′ | s′, a ) Σs P( s′ | s, a ) b(s)
  • 预计学时：55 分钟
  • 前置章节：第 017 章

学习目标

  • 掌握部分可观测马尔可夫决策过程（Partially Observable Markov Decision Process, POMDP）的信念状态定义与递推更新，理解"策略依赖信念"的含义。
  • 理解 Dec-POMDP 中个体历史作为决策依据的地位，以及信念近似与记忆架构的对应关系。
  • 会实现循环策略：序列批次、隐藏状态管理、回合边界重置与截断时间反向传播的取舍。
  • 掌握感知别名的诊断流程：构造别名样本、验证记忆必要性、对照帧叠与循环记忆的修复效果。
  • 能在"补观测特征（环境侧）"与"加记忆（算法侧）"两类修复之间做出选择，并说明各自的代价。

背景与动机

第 001 章把协作任务写成 Dec-POMDP，并用局部观测历史 τi 定义策略；后续章节的实现大多使用单帧观测的多层感知机，这在小规模基准上工作良好，却绕开了一个核心问题：当同一观测在不同状态下对应不同最优动作时（第 005 章的感知别名），无记忆策略在函数类上就无法表示最优解，任何调参都不能修复。部分可观测是协作任务的常态：通讯受限、传感器视野有限、对手隐藏，都会让当前观测丧失区分性。

本章回到建模层补齐这块理论：POMDP 用信念状态（belief state）给出"历史信息的充分统计量"的精确形式，信念空间连续且随状态维度指数增长，直接学习不可行；实用路线用循环网络把历史压缩成隐向量，隐向量即信念的可训练近似。第 016 章的通信隐藏状态、第 012 章的序列批次都是这条路线的一部分，本章把它们的正确用法系统化。序列化训练同时带来一组新的工程纪律：隐藏状态的管理、回合边界的重置、截断长度与任务依赖长度的匹配，这些是本章的实现主线。

核心原理

本节给出信念更新的推导与直觉、Dec-POMDP 中历史依赖的结构、记忆架构的近似逻辑，以及诊断与修复的两条路径。

1. 信念状态与递推更新

信念 b(s) = P(s | τ) 是"给定历史后对当前状态的概率分布"，其中 τ 为观测与动作的历史。执行动作 a 并收到新观测 o′ 后，贝叶斯更新为：

b′(s′) = O( o′ | s′, a ) · Σs P( s′ | s, a ) b(s) / Z， Z 为归一化常数 分子依次乘三项：上一时刻的信念 b(s)、转移概率 P(s′|s,a)、观测似然 O(o′|s′,a)。Z = Σs′ 分子对全部 s′ 求和，保证概率归一

信念更新的结构决定了 POMDP 的最优策略形式：Bellman 最优方程作用在信念空间上，策略 π(a | b) 以信念为输入，历史与信念在信息上等价，任何历史函数都可改写为信念函数。信念空间的维度等于状态数（单纯形），状态空间大时无法显式表示；即使状态小，连续单纯形上的规划仍需函数逼近。这两条现实约束导向"用可训练的隐向量代替信念"的近似路线。

2. Dec-POMDP 中的个体历史与联合信息

多智能体设定把信念拆分到每个智能体：智能体 i 只能依据自己的历史 τi 更新个体信念 bi(s) = P(s | τi)，不同智能体的信念无需一致（他们看到的信息不同）。联合的最优行为依赖各智能体信念的组合，这正是 Dec-POMDP 困难的结构来源：训练期集中式组件可以看到全局状态，执行期每个智能体只能携带自己的隐状态；CTDE 各算法通过训练期信息注入与执行期记忆两条通道来补偿这一鸿沟。通信（第 016、017 章）是另一条减少信念差异的通道，记忆与通信在功能上互补：记忆解决"自己历史里有但当前帧没有"的信息，通信解决"别人历史里有而自己没有"的信息。

3. 用循环记忆近似信念

循环策略把历史压缩为隐藏状态序列：

ht = fθ( ht−1, ot, at−1 )， πi(ai,t | ht) 且 h0 = 0 fθ 取门控循环单元; 输入包含上一步动作, 因为动作影响后续转移与观测, 历史应当包含它。容量充分时隐向量可逼近任意历史函数, 即信念的任意充分统计量的函数

三点实践含义：（1）上一步动作进入记忆输入是常被忽略的细节，缺失它会让记忆对"自己刚做过什么"失忆，在依赖动作历史的任务上表达力不足；（2）隐向量并不对应可解释的信念数值，它只承担"区分不同历史"的表示功能，环境隐变量的显式估计留给基于模型的路线；（3）无参数替代是帧叠（stack 最近 k 帧），它只覆盖固定短窗，长程依赖任务上必须用循环记忆，两者作为对照档出现在消融清单里。

4. 诊断与修复

别名诊断流程分三步。第一步构造别名样本：寻找两个观测相同但最优动作不同的历史片段，可以直接用环境状态池筛选（固定观测码、筛不同最优动作的状态对）。第二步验证记忆必要性：用无记忆策略在这些样本上评估，若精确最优动作的达成率显著低于有记忆版本，别名为真。第三步选择修复路径：环境侧补充特征（加入走廊标识等区分性观测）成本最低且不改变算法，适用于环境可控的场景；算法侧加循环记忆适用于观测接口冻结的场景，代价是序列化训练的复杂度与更长的样本需求。两条路径可以叠加，诊断记录中应分别报告各行修复的达成率增量。

5. 数值算例：一次完整的信念更新

两状态、两观测的最小实例。先验信念 b = (0.5, 0.5)；执行动作 a 后的转移概率为 P(s′ | s1, a) = (0.8, 0.2)、P(s′ | s2, a) = (0.4, 0.6)（分量按 s′ 排列）；观测似然 O(o = 1 | s′) = (0.9, 0.2)。逐步计算，数值经程序核对：

步骤计算式结果
预测下一状态分布0.5×(0.8, 0.2) + 0.5×(0.4, 0.6)(0.60, 0.40)
乘观测似然（未归一）(0.60×0.9, 0.40×0.2)(0.54, 0.08)
归一化常数 Z0.54 + 0.080.62
后验信念(0.54 / 0.62, 0.08 / 0.62)(0.871, 0.129)

读表要点：三段计算的顺序与公式逐项对应，任何一步顺序错误都会在中间行显形。观测 o = 1 在 s1 下更常见（0.9 对 0.2），后验把概率从 0.60 提到 0.871；若收到的是 o = 2（似然 (0.1, 0.8)），未归一项变为 (0.06, 0.32)，Z = 0.38，后验 (0.158, 0.842)，方向完全翻转。这正是观测修正信念的数值演示：转移预测负责漂移，似然负责矫正；长期收不到观测时，信念退化为转移矩阵反复作用下的先验演化。

6. 数值算例：别名的达成率上界

设观测空间中 30% 的观测属于别名观测，且在这些观测下两类历史的最优动作各占一半。无记忆策略对同一观测只能输出一个动作，在别名观测上的最高达成率为 50%，整体上界为 0.7×100% + 0.3×50% = 85%；带记忆策略可区分两类历史，上界回到 100%。这个 15 个百分点的差距就是记忆的理论上限红利，实际差值通常更小（记忆不完美、历史区分不充分）。诊断时把实测达成率与两个上界对照：无记忆版接近 85% 且记忆版显著更高，说明别名真实且修复有效；两版都接近 100%，说明别名构造失败或任务本身无别名。

7. 三档记忆容量的对照

维度单帧 MLP4 帧堆叠GRU 循环记忆

实现思路与设计

本节给出循环策略的训练配置：回合级序列批次、隐藏状态管理、截断时间反向传播；数据接口在联合转移基础上增加时间维度与隐藏状态字段。

设计项取值（基线）作用与依据
记忆类型GRU，隐藏 64与第 016 章通信隐藏状态同构；门控缓解梯度消失
对照档单帧 MLP / 4 帧堆叠 / GRU三档覆盖无记忆、短窗、长程三类容量
序列组织按回合切片，时间主序 (T, B, ·)与第 001 章数据布局兼容；序列内时间顺序不可打乱
截断长度整回合（60 步）任务依赖长度短于回合上限时无需截断；长任务截断到 30 步
隐藏状态初始化每回合零向量重置防止跨回合信息泄漏；并行环境逐副本维护
学习率5e-4与全篇一致
批大小8 回合序列训练显存占用随长度线性增长，批不宜过大
诊断钩子别名样本集评估（每固定步数）把记忆必要性检验常态化

与环境侧修复的接口：观测函数若增加特征，观测维度变化只影响编码器输入，序列组织不变。实验记录必须注明当前档位（环境侧补充 / 算法侧记忆 / 两者叠加）与别名样本集上的达成率，单看总回报无法区分"记忆起效"与"任务别名不严重"。

设计决策：隐藏状态由数据层显式管理的理由

把隐藏状态存成模型属性（自持状态）会让采样、评估与梯度计算共享同一份可变状态，任意一次前向都改变它，测试与训练互相污染，并行环境也无法区分副本。本课程统一采用"状态作为显式张量在数据层传递"的模式：前向函数接受 h 并返回 h′，重置由回合边界掩码驱动。第 016 章的图通信隐藏状态遵循同一约定，两处记忆在同一条数据流水线上可以并存。

关键代码与解读

片段 1：循环策略的序列前向

import torch
import torch.nn as nn

class RecurrentPolicy(nn.Module):
    """循环策略: 逐时间步更新隐藏状态, 输出动作分布。"""
    def __init__(self, obs_dim, n_actions, hidden=64):
        super().__init__()
        self.encoder = nn.Linear(obs_dim + n_actions, hidden)  # 观测 + 上一步动作
        self.rnn = nn.GRUCell(hidden, hidden)                  # 记忆核心
        self.head = nn.Linear(hidden, n_actions)

    def forward(self, obs_seq, act_prev_seq, h0):
        # obs_seq: (T, B, obs_dim); act_prev_seq: (T, B, n_actions)
        T, B, _ = obs_seq.shape
        h = h0                                                  # (B, hidden)
        logits = []
        for t in range(T):
            x = torch.tanh(self.encoder(
                torch.cat([obs_seq[t], act_prev_seq[t]], dim=-1)))
            h = self.rnn(x, h)                                  # 状态随步推演
            logits.append(self.head(h))
        return torch.stack(logits), h                           # (T, B, nA), 终态

解读：序列前向的三个设计点。（1）输入拼接上一步动作的 one-hot：动作影响后续观测，缺省它会让隐状态无法区分"因我动作导致的观测变化"与"环境自发变化"，在依赖自身历史的任务上表达力受损。（2）循环体只维护一个 h 张量并逐步推演，梯度沿时间链回传；GRUCell 与序列级 RNN 模块在语义上等价，前者便于与掩码重置、逐环境副本等控制流结合。（3）返回终态 h 供数据层续写：训练批次结束时若回合未终止，隐藏状态需传给下一采集段；终止则丢弃。该返回值是"状态显式管理"约定的实现落点。

片段 2：回合边界重置与掩码

def masked_forward(policy, obs_seq, act_prev_seq, done_seq, h0, truncate_len=30):
    """按回合边界重置隐藏状态; 按片段长度截断 BPTT。"""
    T, B, _ = obs_seq.shape
    h = h0
    logits = []
    for t in range(T):
        x = torch.cat([obs_seq[t], act_prev_seq[t]], dim=-1)
        h_candidate = policy.rnn(torch.tanh(policy.encoder(x)), h)
        # done=1 的样本: 该步之后记忆链重置为零, 防止跨回合信息串扰
        keep = (1.0 - done_seq[t]).unsqueeze(-1)         # (B, 1)
        h = h_candidate * keep
        if (t + 1) % truncate_len == 0:                  # 截断 BPTT 梯度链
            h = h.detach()
        logits.append(policy.head(h))
    return torch.stack(logits)

解读：掩码函数承担两件事，必须分开理解。（1）keep 乘法实现回合重置：终止步的隐藏状态被清零，下一回合从干净状态开始；漏掉该掩码的后果是跨回合信息串扰，统计上表现为同一智能体在相邻回合间的行为相关性异常高。（2）truncate_len 控制截断时间反向传播：每当推算到片段边界，隐藏状态 detach，梯度只在一个片段内回传。截断长度与任务依赖长度的关系是超参要点：依赖长度 20 步的任务用 30 步截断足够；截断过短会让长程依赖的信号无法回传，此前章节的 GAE 与这里共享同一"依赖长度"直觉。（3）两个机制互不替代：重置管信息边界，截断管梯度边界，前者是任务语义，后者是计算预算。

片段 3：感知别名的诊断

def alias_diagnostic(env, policy_fn, alias_pairs, max_steps=40):
    """在别名样本对上比较无记忆与带记忆策略的达成率。"""
    scores = {"memoryless": 0.0, "recurrent": 0.0}
    for obs_seq, target_actions in alias_pairs:

                a = policy_fn(o, h, mode)                   # 由策略给出动作
                if mode == "recurrent":
                    h = rec_step(h, o, a)                   # 记忆随历史推进
                if a == target_actions[t]:

            scores[mode] += ok / len(target_actions)

解读：诊断函数把"要不要上记忆"从经验判断变成数据结论。（1）样本对由环境状态池筛选：固定最后观测码、筛出最优动作不同的状态，再回溯各自的历史片段；构造脚本与第 005 章的充分性检验共用同一状态池。（2）两种模式共享同一动作读出函数，唯一差异是隐藏状态是否携带，对照干净；无记忆档以"零历史"执行，记忆档以完整历史推进。（3）达成率差距达到显著水平后再启动记忆版训练与消融，避免把"别名不严重"的任务错误升级为序列化管线，付出不必要的训练复杂度。

常见坑

  • 隐藏状态跨回合残留。症状：回合起始行为受上一回合末尾影响，方差随回合数累积。原因：重置掩码缺失或被优化器状态掩盖。修复：在数据层用 done 驱动重置，单元测试断言"终止步之后的状态等于零"。
  • 序列时间步被打乱。症状：记忆版本与无记忆版本表现几乎相同。原因：批处理管线对时间维做了 shuffle。修复：随机化只作用于回合维，时间维顺序固定；数据加载器加断言。
  • 截断长度与依赖长度失配。症状：长程任务上记忆版本学不到关键历史。原因：BPTT 截断过短，远距离信号梯度不可达。修复：以任务依赖长度的 1.5 倍设置截断，或在该长度上做敏感性扫描。
  • 上一步动作未进入输入。症状：动作历史敏感的任务表达力不足。原因：输入只有观测序列。修复：拼接动作 one-hot；用只保留动作历史的探针任务验证记忆容量。
  • 记忆必要性未验证就升级管线。症状：训练成本上升而无收益。原因：任务别名不严重。修复：先跑别名诊断，达成率差距显著再切换序列化训练。

    先验若为均匀，后验比例 0.7:0.3，归一后 b′(s1) = 0.7。加入转移概率后按公式再乘 P(s′|s,a) 项，步骤不变。
  2. 把帧叠从 4 帧改为 1 帧，在别名诊断任务上预测达成率变化，并说明帧叠窗口长度与依赖长度的关系。★
    提示
    窗口短于别名区分所需的历史长度时达成率回落；帧叠只覆盖固定短窗，长程依赖必须用循环记忆，二者的适用边界由任务依赖长度决定。
  3. 推导信念更新的完整公式：从 b(s) = P(s|τ) 出发，用贝叶斯法则展开 P(s′|τ, a, o′)，说明分母 Z 的构成。★★
    提示
    P(s′|τ,a,o′) ∝ P(o′|s′,τ,a) P(s′|τ,a)；第一项由观测函数给出，第二项对 s 求和并乘转移概率与先验信念。Z 为对 s′ 求和的全概率。
  4. 设计别名诊断实验：给出状态池筛选脚本的判定条件、样本对数量要求（说明统计功效的直觉）与预期对照结果。★★
    提示
    筛选条件：相同观测码、最优动作不同；样本量以每类至少数百对起步，保证达成率差异的置信区间可分。预期：无记忆档在不冲突的历史对上可以达标，在冲突对上必有一侧犯错，整体达成率明显低于记忆档。
  5. 设计题：构造"信念特征 + MLP"的近似方案：用环境模型在训练期计算显式信念或采样估计，将其作为策略输入；与 GRU 隐式记忆对照，给出计算代价、对模型精度的依赖与适用条件分析。★★★
    提示
    显式信念的特征工程依赖转移与观测模型的可得性；粒子滤波近似精度随粒子数上升，代价进入训练回路。适用条件：模型已知或可低成本学习、状态空间中小规模；否则 GRU 隐式路线更通用。

小结

  • 信念状态是部分可观测下的充分统计量，服从"转移预测 + 观测似然 + 归一化"的递推；策略以信念为输入。
  • Dec-POMDP 中信念按智能体拆分，记忆解决"自己历史"的信息，通信解决"他人历史"的信息，两者互补。
  • 循环策略用隐状态近似信念：输入含上一步动作、状态显式传递由数据层管理、回合边界重置与片段截断各管信息与梯度边界。
  • 别名诊断三步：构造冲突样本、验证记忆必要性、在环境侧补特征与算法侧加记忆之间选择。
  • 下一章处理执行期的近似问题：去中心化执行中的策略融合，讨论把联合策略化为分散策略时的信息陷阱与修复路线。
