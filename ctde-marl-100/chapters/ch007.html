第 007 章：QMIX单调性约束实现

把加性分解推广为单调混合：Qtot = fs(Q1, …, QN)，只要混合函数对每个个体价值单调不减，IGM 条件依然成立，而表达力扩展到整个非线性单调族。本章实现超网络生成的混合权重，并给出单调性充分性证明与梯度敏感性分析。

  • 主题：值分解算法 / 单调性约束
  • 关键公式：∂Qtot/∂Qi ≥ 0 ⟹ IGM；Qtot = fθ(s, Q1, …, QN)
  • 预计学时：55 分钟
  • 前置章节：第 006 章

学习目标

  • 理解 QMIX（Monotonic Value Function Factorisation for Deep Multi-Agent Reinforcement Learning）用单调性替代加性的设计逻辑：IGM 只需混合函数对个体价值单调。
  • 掌握单调性充分性的证明思路：逐坐标替换加单调链，联合最优可由个体最优拼装。
  • 掌握超网络（hypernetwork）生成非负混合权重的结构，及 abs、ELU、状态条件化三个部件各自的作用。
  • 会实现 QMixer、目标混合器同步、梯度敏感性监控，并能与第 006 章 VDN 做受控对照。
  • 能说明单调族的表达力边界与失效任务形态，为第 008 章 QTRAN 直接约束 IGM 的路线建立动机。

背景与动机

第 006 章的 VDN 用最简单的方式获得 IGM 保证，代价是加性结构无法表达交互项。第 007 章的观察是：IGM 对分解结构的要求其实很弱，只要混合函数对每个 Qi 单调递增，联合 argmax 就仍可由个体 argmax 拼装。单调函数族包含全部加性函数，还允许状态相关的非线性组合，"同时按下才加分"这类非负交互项可以被混合网络表达。

QMIX（Monotonic Value Function Factorisation for Deep Multi-Agent Reinforcement Learning）由此得名。它的实现核心是混合网络：权重由以全局状态为条件的超网络生成，并强制非负；个体价值输入后经两层非线性混合输出 Qtot。训练沿用第 006 章的时序差分框架，执行仍然是每个智能体对 Qi 贪心。

QMIX 在星形协作基准（如星际争霸多智能体挑战 StarCraft Multi-Agent Challenge, SMAC）上确立了值分解路线的强势地位，是后续研究的通用基线。本章与第 006 章的差异全部集中在混合器，逐行对照即可看清"加性到单调"的增量。

核心原理

本节给出单调分解的定义、充分性证明、混合网络的参数化、梯度敏感性解释与表达力边界。

1. 单调性约束与 IGM 充分性

称 Qtot 可单调分解，若存在个体价值 {Qi} 与混合函数 f 使得：

Qtot(τ, u) = f( Q1(τ1, u1), …, QN(τN, uN) )， 且 ∂f / ∂Qi ≥ 0 对一切 i 成立 f 可为任意单调函数，不再限于求和；单调性是对个体价值的偏序约束。第 006 章的加性分解是 ∂f/∂Qi ≡ 1 的特例

充分性证明思路。记 u★ 为个体最优的组合，即 u★i ∈ argmaxui Qi。对任意联合动作 u，构造坐标替换链：把 u 的第 1 个坐标换成 u★1，其余保持不变，由 Q1(u★1) ≥ Q1(u1) 与对第 1 个坐标的单调性得 f 的值不降；继续依次替换第 2 至第 N 个坐标，每步值不降，最终得 f(u★) ≥ f(u)。由于 u 任意，u★ 是联合价值的一个最大值点，argmax 的分解关系成立。证明只使用逐坐标单调性，与 f 的具体形式无关；这一条性质是整个 QMIX 类方法合法性的全部依据。

2. 混合网络的参数化

f 用一个两层网络实现，权重全部由状态条件的超网络生成：

h = ELU( W1(s) · Qagents + b1(s) )， Qtot = W2(s) · h + b2(s)
W1(s) = | MLP1(s) |， W2(s) = | MLP2(s) |， b1(s) = MLP3(s)， b2(s) = MLP4(s) |·| 为逐元素绝对值，是权重非负化的实现；偏置不受单调性约束，保持无约束。s 为全局状态，只在训练期被混合器读取

逐部件解释：（1）非负权重。链式法则下 ∂Qtot/∂Qi 是两层非负权重与 ELU 非负导数（ELU 的导数恒为正）的乘积和，恒 ≥ 0。展开到第 e 个隐藏单元：∂Qtot/∂Qi = Σe W2[e] × ELU′(pree) × W1[e, i]，三个因子全部非负，求和后敏感度恒 ≥ 0。该展开同时说明非负化必须覆盖两层权重：任一层出现负值，乘积就可能为负，逐坐标替换证明的每一步失效，IGM 失去保证；绝对值把权重映射到非负半轴，是最常用的实现。（2）状态条件。W(s) 让"同样的个体价值在不同局面下贡献不同的协调权重"，这是交互项可表达的来源；若删除状态输入，f 退化为全局共享的单调函数，表达力类似 VDN 的平滑推广。（3）ELU。作为中间激活，ELU 在原点光滑且负半轴有下界，梯度流比 ReLU 平稳；ReLU 的零导数区域会截断部分个体价值的梯度，监控中表现为某些智能体的敏感性恒为零。

3. 梯度敏感性与信用分配的加权

训练对个体价值的梯度经过混合器加权：

∂L / ∂Qi = ( ∂L / ∂Qtot ) · ( ∂Qtot / ∂Qi ) VDN 中 ∂Qtot/∂Qi ≡ 1，误差均分；QMIX 中该系数随状态与个体价值水平变化，学到的敏感度即"该智能体对全局结果的影响力估计"

该系数可作为诊断指标：若训练中发现某智能体的平均敏感度长期趋近零，说明混合网络把它判定为对团队无影响，其个体价值学习信号被切断，常见于该智能体长期处于非关键位置的局面。监控每智能体的平均 ∂Qtot/∂Qi 是排查"部分智能体不学习"故障的第一把工具。

敏感度随个体价值水平变化，可以算一个例子。取混合函数 f(Q1, Q2) = Q1 + Q2 + 0.5 × max(0, Q1 + Q2 − 3)，全部系数非负，对两个坐标都单调。在 (Q1, Q2) = (1, 1) 处，二元和 2 低于阈值 3，两个偏导都是 1；在 (2, 2) 处二元和 4 越过阈值，偏导一起升到 1.5；在 (2, 3) 处偏导同为 1.5。同一智能体的敏感度随个体价值水平从 1 变到 1.5，这是 VDN 的均分（恒等于 1）表达不了的形态；若监控曲线上所有智能体的敏感度长期锁定在同一个常数附近，应检查混合器是否退化成了线性结构。

4. 表达力边界与失效形态

单调族严格包含加性族，但仍小于一般联合函数。需要非单调交互的任务会失效，典型形态是"对称破缺"或"掩护式合作"：个体最优组合与联合最优不一致，且最优联合动作要求某智能体采取局部次优动作（例如一方主动吸引注意力，牺牲自身局部收益换取团队整体收益上界）。单调性要求"个体价值越高，联合价值越高"，无法回卷这类牺牲结构。

单调可表示性有一个精确判据，比"交互项非负"更严格。由偏导非负直接得到一条引理：若混合函数对 Q1 单调且 Q1(a) > Q1(b)，则对任意队友动作 u2 有 V(a, u2) = f(Q1(a), Q2(u2)) ≥ f(Q1(b), Q2(u2)) = V(b, u2)。因此容量充分时，QMIX 能精确表示的价值函数必须满足：为每个智能体的动作选定一个排序后，V 沿每个坐标轴单调不减；反之，满足该排序单调性的函数可以构造 Qi 与单调 f 精确表示。判断一个函数超出单调族，只需找到排序上的矛盾。

用第 006 章的交互矩阵做检验：V(0,0) = 2、V(0,1) = 1、V(1,0) = 1、V(1,1) = 5。固定队友动作为 0 的列是 (2, 1)，固定队友动作为 1 的列是 (1, 5)，矩阵对称使行的结构与列完全一致。第一列要求 V(0,0) ≥ V(1,0) 严格成立（2 > 1）：若 Q1(0) ≤ Q1(1)，单调性将迫使 2 ≤ 1，矛盾，故必须有 Q1(0) > Q1(1)。第二列要求 V(1,1) ≥ V(0,1) 严格成立（5 > 1）：同理必须有 Q1(0) < Q1(1)。两列对同一对个体价值提出相反的大小要求，矛盾。结论：该矩阵超出单调可表示族，交互项为正并不保证单调可表示；"同时选 1 得超额收益"能被单调混合表达的前提，是个体价值排序与团队收益排序不冲突。这一"排序冲突"形态是 QMIX 在部分协调任务上收敛次优的又一类机理，也是第 008 章直接约束 IGM 的另一条动因。

单调性的实现级抽查与 IGM 穷举测试互补：对随机批次逐坐标施加正向扰动 Qi → Qi + ε（ε 取 1e-3），断言混合输出不下降，容差 1e-6；该测试查局部偏导，IGM 测试查全局最优结构，两者合起来把"非负化是否落实"与"argmax 是否可分解"分开定位。

三个值分解方法的约束强度与失效形态并排对照如下：

方法分解约束可表示族目标侧结构典型失效
VDN求和，∂f/∂Qi ≡ 1加性函数族逐智能体 max 后求和协同增益任务系统性低估
QMIX逐坐标单调，∂f/∂Qi ≥ 0存在轴排序使 V 单调的函数族目标混合器作用于个体 max排序冲突与局部牺牲任务
QTRAN（下一章）直接约束 IGM满足 IGM 的更大函数族变换加松弛惩罚项松弛权重敏感，训练更复杂

工程判据：任务的最优联合行为若可由"每人贪心地最大化自己的贡献"达成，QMIX 类方法适合；若最优行为持续要求局部牺牲，单调约束成为结构性上界，应转向第 008 章 QTRAN 的直接 IGM 约束或策略梯度路线。

实现思路与设计

本节给出 QMIX 的组件配置。相对第 006 章的增量只有三处：混合器带参数、超网络消耗状态、目标侧增加目标混合器。

设计项取值（基线）作用与依据
个体 Q 网络MLP 64×64，输出 n_actions与第 006 章完全一致，保证消融对照只反映混合器差异
混合嵌入维度32第一层隐藏宽度，决定 W1 的秩；过小限制表达力，过大增加过拟合风险
超网络两层 MLP，隐藏 64，ReLU超网络本身无需单调约束，激活可自由选择
非负化绝对值 abs标准实现；softplus、exp 为等价替代，见练习
折扣因子 γ0.95（长时域任务可升至 0.99）全篇基线一致；交互项在远期的任务提高 γ 有助于信用信号回传
学习率5e-4（Adam）混合器引入额外参数，过高时权重饱和，观察饱和指标后下调
目标网络个体网络与混合器成对拷贝，每 200 步混合器带参数后必须纳入目标侧，这是与 VDN 的实现分水岭

混合器的参数量核算（状态 4 维、智能体 2 个、嵌入 32）：超网络 W1 支路 4480 个参数，W2 支路 2400 个，两个偏置支路 160 与 385 个，合计 7425 个，约为单个个体 Q 网络（4547 个参数）的 1.63 倍。小规模任务里混合器是第二大网络，把它从目标网络拷贝中遗漏的代价与遗漏个体网络同级；这是"目标混合器同步"被列为实现分水岭的量化理由。

与第 006 章的差异点可以压缩为一句话：凡是携带参数的组件，目标侧必须有一份滞后拷贝。混合器加入了参数，训练目标的构造从"个体网络组的目标拷贝求和"升级为"目标混合器作用于目标个体网络"。

设计决策：非负化采用绝对值的理由

非负化候选有 abs、softplus、平方、指数四种。abs 的梯度在零点两侧分别为 +1 与 −1，允许超网络自由调整权重大小且无上界；softplus 输出恒正但近零区梯度小，深层权重初期活跃度低；平方与指数在增大方向把参数推向极端，训练中权重饱和更频繁。开源实现（PyMARL、EPyMARL 接口习惯）普遍采用 abs，本课程保持一致，并在练习中给出替换实验的预测框架。

关键代码与解读

片段 1：单调混合网络

import torch
import torch.nn as nn
import torch.nn.functional as F

class QMixer(nn.Module):
    """单调混合器: 超网络由状态生成权重, 权重经 abs 保证非负。"""
    def __init__(self, state_dim, n_agents, embed_dim=32):
        super().__init__()
        self.n_agents, self.embed_dim = n_agents, embed_dim
        # 超网络输出 W1 的全部元素; 输出维度 = embed_dim * n_agents
        self.hyper_w1 = nn.Sequential(
            nn.Linear(state_dim, 64), nn.ReLU(),
            nn.Linear(64, embed_dim * n_agents))
        # 第二层权重: embed_dim -> 1, 输出 embed_dim 个元素
        self.hyper_w2 = nn.Sequential(
            nn.Linear(state_dim, 64), nn.ReLU(),
            nn.Linear(64, embed_dim))
        # 偏置不参与单调性条件, 无需非负约束
        self.hyper_b1 = nn.Linear(state_dim, embed_dim)
        self.hyper_b2 = nn.Sequential(
            nn.Linear(state_dim, 64), nn.ReLU(), nn.Linear(64, 1))

    def forward(self, q_agents, state):
        # q_agents: (B, N) 每个智能体对各自执行动作的 Q 值
        B = q_agents.shape[0]
        q = q_agents.unsqueeze(1)                       # (B, 1, N)
        w1 = torch.abs(self.hyper_w1(state))            # (B, embed*N)
        w1 = w1.view(B, self.embed_dim, self.n_agents)  # (B, E, N)
        b1 = self.hyper_b1(state).view(B, 1, self.embed_dim)
        hidden = F.elu(torch.bmm(q, w1.transpose(1, 2)) + b1)  # (B, 1, E)
        w2 = torch.abs(self.hyper_w2(state)).view(B, self.embed_dim, 1)
        b2 = self.hyper_b2(state).view(B, 1, 1)
        q_tot = torch.bmm(hidden, w2) + b2              # (B, 1, 1)
        return q_tot.view(B)

解读：形状操作是这段代码的全部难点，按数据流核对：q 是 (B, 1, N) 的行向量；w1 重排为 (B, E, N)，与 q 做批量矩阵乘法得到 (B, 1, E)。（1）第一层输出维度 E 是混合嵌入宽度，它决定中间表示容量，也是消融实验的第一变量。（2）两处 torch.abs 位置必须覆盖所有权重张量，偏置保持原样；任何一处漏掉绝对值，∂Qtot/∂Qi ≥ 0 的保证即被破坏，IGM 验证测试会捕获这一错误。（3）ELU 的应用位置在求和之后，保证负值有界且处处可导，避免 ReLU 零点梯度断流。

片段 2：训练目标与目标混合器

def qmix_loss(agent_qs, target_agent_qs, mixer, target_mixer, batch, gamma=0.95):
    """QMIX 时序差分损失: 目标侧使用目标个体网络与目标混合器。"""
    obs, act, rew, nobs, done, state, nstate = batch
    B, N = act.shape
    q_all = torch.stack([net(obs[:, i]) for i, net in enumerate(agent_qs)], dim=1)
    q_chosen = q_all.gather(2, act.unsqueeze(-1)).squeeze(-1)     # (B, N)
    q_tot = mixer(q_chosen, state)                                # 训练侧混合
    with torch.no_grad():
        q_next_all = torch.stack(
            [tn(nobs[:, i]).max(dim=1).values for i, tn in enumerate(target_agent_qs)],
            dim=1)                                                # (B, N) 逐智能体 max
        # 关键: 目标混合器作用于"个体最大价值", 与单调性一起保持 IGM 一致
        q_tot_next = target_mixer(q_next_all, nstate)
        y = rew[:, 0] + gamma * (1.0 - done[:, 0]) * q_tot_next
    return ((q_tot - y) ** 2).mean()

解读：与第 006 章 vdn_loss 的差异集中在两行：训练侧 mixer(q_chosen, state) 替换求和，目标侧 target_mixer(q_next_all, nstate) 替换逐智能体 max 直接求和。（1）目标侧先做逐智能体 max 再做目标混合，与"先混合再对联合动作 max"在单调性下保持相同的最优动作集合，但计算量小得多；这一顺序不能交换错。（2）target_mixer 的存在是混合器带参数后的强制要求，遗漏它会让目标值随当前混合器漂移，训练表现为回报上升后坍缩。（3）伪状态拼接（第 005 章的 concat_obs 档）可直接替换 state 字段，本章不重复展开。

片段 3：梯度敏感性监控

def sensitivity_monitor(agent_qs, mixer, obs, act, state):
    """监控 ∂Q_tot/∂Q_i 的均值: 判定混合器给每个智能体的权重。"""
    B, N = act.shape
    q_all = torch.stack([net(obs[:, i]) for i, net in enumerate(agent_qs)], dim=1)
    q_chosen = q_all.gather(2, act.unsqueeze(-1)).squeeze(-1)
    q_chosen.requires_grad_(True)                 # 以个体价值为变量求偏导
    q_tot = mixer(q_chosen, state)
    grads = []
    for i in range(N):
        g = torch.autograd.grad(q_tot.sum(), q_chosen, retain_graph=(i < N - 1),
                                create_graph=False)[0]
        grads.append(g[:, i].mean().item())       # 该智能体的平均敏感度
    # 均值长期趋近 0 表示该智能体被判为"对团队无影响", 其学习信号被切断
    return grads

解读：监控函数把理论中的偏导系数变成可打印的数值序列。（1）以 q_chosen 为求导变量、对 q_tot.sum() 求梯度，得到每个样本每个智能体的敏感度；求和只为了让输出成为标量以便一次性求导。（2）retain_graph 的用法与第 004 章梯度冲突监测一致，多次求导共享同一计算图。（3）该指标的解释需要结合任务：处于关键位置的智能体敏感度随训练上升，这是混合网络"学到协调结构"的可观测证据；若全智能体敏感度同步冻结在相近数值，提示超网络权重饱和，应降低学习率或增大嵌入维度。

常见坑

  • 漏掉目标混合器。症状：训练回报先升后降，Q 值整体漂移。原因：目标 Qtot 用了在线混合器，目标随参数同步移动，自举失去滞后锚点。修复：初始化时成对构造在线与目标混合器，并在更新循环中断言目标混合器没有进入优化器参数组。
  • abs 只加在第二层权重。症状：IGM 验证间歇失败，敏感度出现负值。原因：第一层权重未非负化，链式乘积仍可能为负。修复：核对两层权重均经 abs；把 sensitivity_monitor 的最小值纳入训练日志，负值即报警。
  • 超网络输入未归一化。症状：权重饱和（绝对值普遍偏大且变化缓慢），Q 值尺度失控。原因：状态尺度大导致超网络提前进入饱和区。修复：沿用第 005 章固定边界归一化；对状态数值范围变化的任务，把归一化挪到 StateBuilder 内部统一处理。
  • ReLU 替换 ELU 后部分智能体停止学习。症状：某些智能体敏感度恒为零且不再恢复。原因：ReLU 的零梯度区截断了个体价值通道。修复：换回 ELU（或 LeakyReLU），并检查第一层偏置是否长期把预激活压到负区。
  • 把 QMIX 当万能解处理牺牲型任务。症状：在对称破缺任务上收敛到对称但次优的联合行为，增加训练步数无效。原因：单调性约束的结构性上界。修复：先做"单调性上限诊断"（对照穷举联合最优的差距），确认后转向 QTRAN 或策略梯度方法，避免无效调参。

练习与思考

  1. 给定单调混合 f(Q1, Q2) = Q1 + Q2 + 0.5·min(Q1, Q2)，验证其满足 ∂f/∂Qi ≥ 0，并计算 Q1 = 2、Q2 = 3 时的两个偏导值。★
    提示
    ∂f/∂Q1 在 Q1 ≤ Q2 时为 1.5，否则为 1；代入得 1.5 与 1。两个偏导均正，混合对双方单调，IGM 成立。
  2. 把非负化从 abs 改为 softplus，在相同任务上预测前期训练速度与后期表达力的变化，并给出监控指标。★
    提示
    softplus 在零点附近梯度为 0.5 且输出恒正，前期权重增长偏慢、训练略滞后；后期表达力相近。监控超网络输出权重的均值与敏感度曲线即可验证该预测。
  3. 完整写出单调性充分性证明（逐坐标替换链），并指出证明在哪个环节使用了"∂f/∂Qi ≥ 0"这一条件。★★
    提示
    替换链的每一步只改变一个坐标且该坐标的个体价值不降，单调性保证 f 值不降；若该条件失效，替换后值可能下降，链式论证断裂，联合最优与个体最优不再重合。
  4. 设计一个两智能体非单调任务：个体价值的最优组合必须包含一方动作的"牺牲"，写出奖励结构，预测 QMIX 与 QTRAN 的表现差异，并给出验证实验。★★
    提示
    例如"掩护"任务：智能体 A 吸引注意（局部收益为负）才能让 B 完成目标，团队收益为正。QMIX 受单调约束预计卡在双方都保守的联合行为；QTRAN 通过直接约束 IGM 有机会到达联合最优。实验用穷举联合最优作为上界对照。
  5. 设计消融实验：在同一个含非负交互项的任务上比较 VDN、QMIX-无状态条件（混合权重不依赖 s）、完整 QMIX 三者。要求给出预测排序、监控指标（回报、敏感度、混合权重的状态方差）与结论判定标准。★★★
    提示
    预测：完整 QMIX 优于无状态条件版本，后者与 VDN 接近或略好；混合权重的状态方差可量化"状态条件化是否被使用"。若状态方差趋零且性能退化为 VDN 水平，说明超网络未利用状态信息，检查归一化与状态维度接线。

小结

  • QMIX 用单调性替代加性：只要混合函数对每个个体价值偏导非负，IGM 成立；证明核心是逐坐标替换链。
  • 混合器由状态条件化的超网络生成非负权重、无约束偏置，abs 与 ELU 分别保证单调性与梯度流。
  • 训练梯度按 ∂Qtot/∂Qi 加权，该系数是可监控的信用敏感性指标；目标侧必须同步混合器。
  • 表达力覆盖非线性单调协调，失效形态是要求局部牺牲的对称破缺任务，引出下一章直接约束 IGM 的路线。
