第二篇 · 训练工程与稳定性

第 040 章：经验共享与样本效率

本章讲经验共享（Experience Sharing）的三个维度（跨智能体、跨任务、跨时间）与样本效率（Sample Efficiency）的度量规范：相关数据的有效样本量修正、达到阈值的步数与曲线下面积，以及共享增益与负迁移的判别。

  • 主题：数据复用 / 样本效率度量
  • 关键公式：Neff ≈ N · (1 − ρ̄) / (1 + ρ̄)
  • 预计学时：55 分钟
  • 前置章节：第 039 章 异步更新与同步更新对比

学习目标

  • 理解经验共享的三个维度及各自的收益机制，能对给定系统判断哪些共享应当启用。
  • 掌握相关数据下有效样本量的修正公式，理解共享池中数据相关性对统计有效性的影响。
  • 掌握样本效率的两个标准度量：达到性能阈值所需环境步数与曲线下面积，及其报告规范。
  • 理解共享的负迁移条件，能结合异构性与任务差异判断共享边界。
  • 能实现按智能体视图的共享池、样本效率度量函数与自相关检查，并设计共享对照实验。

背景与动机

样本效率衡量"交多少环境步的学费能学到多少"，是多智能体算法最受关注的指标之一：环境交互常是训练成本的大头，而多智能体任务的交互成本随智能体数量线性增长。样本效率的提升有两条路线：改变算法（更高效的信用分配、更好的探索）与改变数据的使用方式（让每条数据被更多位置复用）。本章聚焦第二条路线，它不需要改动算法结构，收益直接来自系统的数据组织。

经验共享的三个维度在多智能体系统中天然存在：同构智能体的经验互为增广（跨智能体），并行环境与课程阶段的数据可以交叉使用（跨任务），回放池让历史数据反复参与更新（跨时间）。共享有明确的代价：数据分布被混合后偏离目标分布，轨迹内部的样本高度相关使"数据量"与"信息量"脱钩。本章同时处理两个问题：怎样共享，以及怎样诚实地度量共享的收益。作为第二篇的收束章，本章的度量口径与第三篇的任务实践共用同一套报告规范。

核心原理

1. 经验共享的三个维度

维度机制收益来源主要风险
跨智能体参数共享 + 共享回放；同一联合过渡为每个智能体提供训练样本样本量乘以有效智能体数异构智能体间的负迁移（第 030 章）
跨任务并行环境、课程阶段、任务变体共用一个池分布覆盖更广，稀有事件样本增加行为策略分布混合，偏差上升（第 022 章）
跨时间回放复用与回放比控制同一样本多次利用陈旧数据与非平稳（第 023、032 章）

三个维度可以叠加，叠加顺序有讲究：先确认跨智能体共享的收益为正（同构性或分组正确），再加入跨任务共享，最后用回放比调节跨时间复用强度；顺序颠倒会让负迁移与陈旧数据的问题相互掩盖。

顺序背后的机制是失败模式的可观测性递进：跨智能体共享的失败（异构负迁移）最容易通过分组监控发现，跨任务共享的失败（分布混合偏差）需要更长观察窗口才能分辨，跨时间共享的失败（陈旧数据）随训练阶段缓慢累积、最晚显形。按此顺序引入，每一层的问题都在前一层稳定之后暴露，诊断的因果链最短。

2. 相关数据与有效样本量

共享池里的数据来自轨迹，相邻样本高度相关；把 10 万个相关样本当作 10 万个独立样本会高估统计效力。一阶自相关近似下，有效样本量为：

Neff ≈ N · (1 − ρ̄) / (1 + ρ̄) ρ̄ 为相邻样本的平均相关系数；ρ̄ = 0.9 时有效样本量约为名义量的百分之五

推导思路：独立样本的均值方差为 σ²/N，相关系数为 ρ 的样本序列均值方差扩展为 σ²/N · (1 + 2Σρk)，令扩展后的方差等于 σ²/Neff 反解得到有效样本量。工程含义有两层：其一，评估样本效率时以环境步为口径，天然规避该问题；其二，设计数据管线时用去相关手段（打乱采样、跨环境混合）提升单位数据的实际信息量。共享池天然带有批内去相关效果：混合后的批次不再整段截取自同一条轨迹，这是它除样本量之外的第二重收益。

去相关的工程手段按成本排序：交错入池最便宜，只需改变写入顺序；采样时按大窗口随机索引次之；对轨迹段整体打散会破坏回合结构，只在回合内奖励可加的任务中使用。验收标准可以量化：记录入池序列的自相关，交错后滞后一期的相关应显著低于单环境序列；没有下降时检查写入缓冲是否把同一环境的连续轨迹整段提交。同时核对偶数滞后项：交错会把相关峰移到滞后 2k 处（约为原相关的 k 次幂），相关总量不因重排而消失，验收不能只看滞后一期。

3. 样本效率的度量规范

两个标准度量：

达到阈值步数：Tθ = min{ t : 平滑曲线首次超过阈值 θ 且保持至训练末 } 阈值 θ 在实验开始前固定（例如基线最终回报的 80% 分位），禁止事后调整
曲线下面积：AUC = ∫ y(t) dt / (tmax − t0)（对回报曲线在环境步轴上取平均） AUC 同时刻画速度与最终水平；报告时换算为回报量纲便于解释

报告规范沿用第 037 章：多种子聚合用 IQM，曲线呈现中位数与分位带，AUC 与阈值步数使用分层自助区间。阈值的事前固定是度量有效性的前提：从曲线中挑选一个对某算法有利的阈值水平再比较，结论失去意义。墙钟时间作为附加指标单独报告，避免把实现效率混入样本效率。

报告 AUC 时注明积分区间与评测间隔：积分区间不同时 AUC 不可比，评测间隔过粗会把早期快速上升段的面积算错；评测间隔从 1 万步改为 2 万步会同时改变 AUC 的分辨率与达标步数的定位精度。三件套数字应来自同一条评测曲线的同一批种子，任何一个数字更换口径都整组重算。

4. 共享的边界：负迁移

跨任务共享数据在多任务学习中称为经验复用的双刃剑：任务之间共享特征加速学习（正迁移），任务之间梯度冲突时互相拖累（负迁移）。第 027 章的梯度余弦相似度诊断可以直接用于判定：共享池的数据来自两个任务分布时，对共享参数分别反传，观察梯度方向；持续为负说明两个任务的最优方向冲突，应拆分参数或降低共享比例。

跨智能体共享的边界由异构性决定（第 030 章）：同构智能体共享几乎无损，异构智能体共享需要在分组内进行。跨时间共享的边界由非平稳性决定（第 032 章）：队友漂移快时旧数据价值衰减，用版本标记与新旧比例控制（第 038 章）。三个边界的共同判据是"共享后的有效梯度是否仍指向共同的最优方向"，诊断工具统一使用梯度方向分析加性能对照实验。

共享维度的引入顺序有配套的准入检查：每加入一个共享维度前，先在该维度上做小规模对照并记录梯度余弦与绩效差；梯度余弦持续为负且绩效下降时回滚该维度。回滚记录保留在实验档案中，避免后续轮次重复尝试同一组合。多维共享同时开启时诊断信号会相互掩盖，准入检查一次只放行一个维度。

三个维度的收益可以在一次实验中逐个度量：固定算法与预算，逐维度开启，观察达标步数的下降幅度；降幅随维度数量递减是常见形态，第三个维度的边际收益最小，资源有限时优先保证前两个维度。

5. 数值算例：有效样本量、AUC 与阈值步数

用一阶自回归模型核对有效样本量公式。名义样本量 10 万、相邻相关 0.9 时，Neff ≈ 100000 × (1 − 0.9) / (1 + 0.9) ≈ 5263，只有名义量的百分之五；相邻相关降到 0.5 时 Neff 升到约 33333。把两条独立环境序列交错入池会改变相关结构的分布：相邻样本来自不同环境，滞后一期的相关降到接近 0，相关峰移到偶数滞后，滞后 2k 处约为 ρk。有效样本量按全部滞后求和决定，重排不改变信息总量：交错后 10 万样本的 Neff 仍约为 5263。这里的工程价值有二：其一，只统计滞后一期的简化公式会在交错池上把 Neff 高估约 19 倍，验收脚本必须按全部滞后累加；其二，按连续窗口抽样时，交错池的批次混合多条轨迹段，覆盖的场景更广、批内样本的重复度更低，这才是共享池跨环境混合的可量化收益形态。

样本效率的三件套用两条构造曲线对照。曲线 A 快速上升后走平：yA(t) = 85(1 − e−t/15000)；曲线 B 慢速上升但最终更高：yB(t) = 120(1 − e−t/60000)，评测间隔 1 万步、训练预算 10 万步。计算结果：A 的 AUC 约 71.8、达标步数（阈值 60）2 万步、终值 84.9；B 的 AUC 约 61.5、达标步数 5 万步、终值 97.3。A 在前两项占优、B 在终值占优，三件套把"谁更快"与"谁更高"分开陈述；只报终值会选中 B，只报达标步数会选中 A，任何单指标都会剪掉一半结论。

回放比的收益边界同样可以量化：回放比从 1 提到 4 等价于同一批样本被消费 4 次，早期等效样本量增加，达标步数下降；同一数据被反复拟合到残差饱和后，价值估计对该批分布的过拟合开始显现，末期回报方差随回放比上升。扫描回放比时同时记录达标步数与末期方差两条曲线，反噬点取两条曲线改善与恶化交叉的位置；这个位置随任务非平稳性前移或后移，没有跨任务的通用取值。

实现思路与设计

共享池按"全局存储、多维视图"组织：过渡数据按时间入池并附带智能体编号、任务标签与策略版本；采样时按视图过滤。样本效率度量模块把评测曲线转为阈值步数与 AUC，与第 037 章的聚合器衔接。

与第 039 章的衔接点：回放比与更新数据比是同一量的两种表达，跨架构比较时两者取同一数值；本章的样本效率实验若对比不同回放比，需固定其他全部配置并使用配对种子。

视图切片在存储层的实现决定内存开销：底层联合过渡只存一份，各视图以索引区间描述字段范围，采样时按索引组装批次；若实现为视图各自复制数组，N 个智能体的共享池内存开销放大 N 倍，与共享的初衷相反。验收测试比较联合池容量与进程内存占用，两者比例应接近常数，比例随智能体数增长说明发生了复制；该检查脚本纳入数据管线的常规测试集，随数据管线版本一起更新维护。

关键代码与解读

片段 1：按智能体视图采样的共享池

import numpy as np

class SharedBuffer:
    """联合过渡唯一存储，智能体视图按索引采样，避免数据重复。"""
    def __init__(self, capacity):
        self.capacity = capacity
        self.joint = []                    # 每项为一个完整联合过渡（含全部智能体字段）

    def push_joint(self, transition):
        # 只入池一次：同一过渡的多个智能体视图共享底层存储
        self.joint.append(transition)
        if len(self.joint) > self.capacity:
            self.joint.pop(0)

    def sample_views(self, batch_size, agent_view, rng):
        """agent_view: (start, end) 的智能体索引区间，用于分组共享。"""
        idx = rng.randint(0, len(self.joint), batch_size)
        batch = []
        for i in idx:
            t = self.joint[i]
            # 视图只切出该组智能体的字段：底层仍是同一条联合过渡
            batch.append({"obs": t["obs"][agent_view[0]:agent_view[1]],
                          "obs_next": t["obs_next"][agent_view[0]:agent_view[1]],
                          "actions": t["actions"][agent_view[0]:agent_view[1]],
                          "state": t["state"], "reward": t["reward"]})
        return batch

解读："唯一存储、视图切片"的组织方式同时解决两个问题：内存上不重复存储联合数据，语义上保留跨智能体共享的样本增广收益。分组视图（agent_view 区间）与第 030 章的角色分组对齐：角色内的智能体共享该视图的数据，角色间互不借用。采样用均匀分布起步，按第 023 章的优先级机制升级时，优先级存储在联合过渡层，各视图读取同一优先级，避免同一数据在不同视图下优先级分裂。

片段 2：样本效率度量

import numpy as np

def steps_to_threshold(curve, threshold, eval_interval):
    """首次超过阈值且保持到训练末的环境步数；未达标返回 None。"""
    above = curve >= threshold
    # 从后向前找最后一次低于阈值的位置：其后全部达标才算保持
    last_below = np.where(~above)[0]
    if len(last_below) == 0:
        start = 0                                  # 全程达标：从第一个评测点算起
    else:
        start = last_below[-1] + 1
        if start >= len(curve):
            return None                            # 从未稳定达标
    return int(start * eval_interval)

def area_under_curve(curve, eval_interval):
    """曲线下面积：梯形法对评测点积分后按步数平均。"""
    steps = np.arange(len(curve)) * eval_interval
    auc = np.trapz(curve, steps) / (steps[-1] - steps[0])
    return float(auc)                              # 量纲为回报，便于跨实验解释

解读：阈值步数的"保持"语义是关键细节：首次越过阈值可能是短暂尖峰，用"最后低于阈值的评测点之后"定义消除了单点波动的影响。两个函数都以环境步为口径，不使用样本条数，规避了相关数据造成的名义量虚高（见有效样本量一节的讨论）。AUC 按步数归一化后量纲为回报，与终值回报直接可比。多种子调用这两个函数后进入第 037 章的 IQM 与分层自助区间，报告层不需要额外约定。

片段 3：自相关检查与有效样本量估计

def effective_sample_size(x, max_lag=20):
    """按自相关和估计有效样本量：共享池去相关效果的量化检查。"""
    x = np.asarray(x, dtype=np.float64)
    x = x - x.mean()
    denom = np.dot(x, x) + 1e-12
    acf = []
    for lag in range(1, max_lag + 1):
        # 滞后自相关：相邻样本的相关系数结构
        acf.append(float(np.dot(x[:-lag], x[lag:]) / denom))
    # 截断负相关段并累加：得到方差膨胀因子
    inflate = 1.0 + 2.0 * sum(a for a in acf if a > 0)
    return len(x) / inflate

def check_design(obs_sequence):
    """验收检查：共享池数据去相关后有效样本量应达到名义量的可观比例。"""
    eff = effective_sample_size(obs_sequence)
    ratio = eff / len(obs_sequence)
    # 经验阈值：混入多环境数据后该比例应有明显提升，否则检查打乱逻辑
    return {"eff": eff, "ratio": ratio}

解读：该检查把"共享池是否真正起到去相关作用"变成可测数字：跨环境混合后的数据序列，有效样本量占比应显著高于单一环境的连续序列。实现按正自相关段求和（负相关段截断）构造方差膨胀因子，是相关分析里的标准简化。多环境数据先打乱再入池，或按环境交错写入，都能提升该指标；若比例长期偏低，依次检查入池顺序、采样是否按时间相邻抽取、缓冲期是否过短。这项检查属于数据管线验收测试，不进入训练主循环。

常见坑

  • 把样本条数当独立样本报告。相关数据下名义样本量远高于有效量，效率结论虚高。修复：统一用环境步口径；需要条数时附自相关修正。
  • 跨任务共享无负迁移检测。任务梯度冲突时共享池互相拖累。修复：梯度余弦诊断加共享比例对照实验，冲突持续即下调比例。
  • 同一过渡重复入池。各智能体视图分别写入造成重复计数与优先级虚高。修复：联合过渡唯一入池，视图按索引切片。
  • 度量口径缺陷。阈值事后挑选使结论失去意义；只报最终回报掩盖到达速度；AUC 积分区间不注明时不同实验的数字无法比较。修复：阈值随基线冻结并写入实验档案；三件套报告阈值步数、AUC、终值，并附积分区间与评测间隔。
  • 共享池跨训练-评估混用。评估数据回流放池，评测集被污染。修复：评估过程不写入共享池，池的入口只接受采集数据。

练习与思考

  1. 推导：设样本序列的相邻相关系数为常数 ρ（一阶自回归），写出均值方差的小样本表达式，并据此导出 Neff ≈ N(1 − ρ)/(1 + ρ)。★
    提示
    方差膨胀因子为 1 + 2Σρk = (1 + ρ)/(1 − ρ)，取倒数得上式。
  2. 改参数预测：把回放比从 1 提高到 4（其余配置不变），预测达到阈值步数、AUC 与训练末期回报方差三个量的变化方向，并说明何时回放比提高会反噬。★
    提示
    适度提高改善阈值步数与 AUC；过高时数据被过度拟合，末期方差上升、泛化变差，反噬点与任务非平稳强度相关。
  3. 设计：为一个含两种角色、三种地图变体的任务设计经验共享方案：共享维度、按视图的数据划分、负迁移检测流程与回滚条件。★★
    提示
    角色内共享智能体视图；地图变体按 0.3 比例混合并监控任务间梯度余弦；持续为负时先降低混合比例再考虑拆分参数。
  4. 实验设计：在相同环境步预算下比较无共享、跨智能体共享、全维度共享三种方案，报告阈值步数、AUC 与终值三指标，并说明如何把实现开销从样本效率中分离。★★★
    提示
    三种方案用同一算法与种子；实现开销以每环境步的墙钟时间单独报告，不折算进样本效率曲线。

小结

  • 经验共享分跨智能体、跨任务、跨时间三个维度，按"先智能体、再任务、后回放比"的顺序引入并用对照实验验证收益。
  • 相关数据的有效样本量按自相关修正；共享池的跨环境混合兼具样本增广与去相关双重作用。
  • 样本效率以环境步口径度量：事前冻结阈值下的达标步数、AUC 与终值回报三件套，聚合规范沿用第 037 章。
  • 共享边界由梯度方向诊断判定：负迁移、异构冲突、陈旧数据三类风险分别对应分组、比例与版本管理。
  • 第二篇到此收束，训练工程工具箱完整；下一页进入第三篇的开篇：多智能体粒子环境，把前述全部机制落到一个可实验的最小任务上。
