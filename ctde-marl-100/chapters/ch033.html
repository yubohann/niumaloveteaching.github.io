第二篇 · 训练工程与稳定性

第 033 章：对抗环境下的CTDE

本章讲对抗环境（Adversarial Environments）中的 CTDE 改造：零和博弈的极小极大目标、训练期对手动作条件化、自博弈的循环问题与联盟训练（League Training）、以及可被利用度（Exploitability）的度量协议。

  • 主题：对抗学习 / 均衡与利用
  • 关键公式：Q(s, a, b) ← r + γ · maxa′ minb′ Q(s′, a′, b′)
  • 预计学时：55 分钟
  • 前置章节：第 032 章 非平稳环境下的CTDE

学习目标

  • 理解零和对抗任务的目标结构：联合回报为零使学习问题从最大化退化为极小极大，均衡概念取代单点最优。
  • 掌握对抗场景下集中式评论家的改造：训练期条件化对手动作、执行期以对手建模近似，以及梯度不穿透对手的纪律。
  • 理解自博弈（Self-Play）的收敛条件与循环失效模式，能解释石头剪刀布型博弈的动态。
  • 掌握联盟训练（League Training）的对手池构成、采样权重与版本管理，以及可被利用度的标准评测协议。
  • 能实现极小极大目标计算与对手池采样，并诊断评估口径错误造成的虚高胜率。

背景与动机

第 032 章讨论的队友共适应仍有合作底色：全体智能体共享一个优化方向。对抗环境去掉这个前提：对手的目标与自身相反，联合回报之和在零和设定下恒为零，一方的收益严格等于另一方的损失。最大化自身期望回报的朴素目标在对抗任务中失效，正确目标是极小极大：在对手最坏响应下最大化自身表现。

对抗训练同时带来两类特有风险。第一类是过拟合当前对手：只与最新版本自博弈时，策略可能找到针对当前对手的剥削性漏洞，对手一旦更新，漏洞失效甚至反噬。第二类是循环动力学：石头剪刀布型博弈中，任何确定性策略都有被克制者，学习动力学可能进入无休止的循环而不收敛到稳定策略。CTDE 的集中式结构在对抗中有一项天然优势：训练期评论家可以访问对手动作，把博弈的价值评估变成条件化预测；执行期只依赖自身观测与对手建模。本章围绕这三件事组织：目标改造、对手分布管理、均衡度量。

核心原理

1. 零和博弈与极小极大目标

两人零和博弈的收益结构满足 r夺取 = −r防守，学习目标是寻找纳什均衡策略对 (π*, σ*)：

maxπ minσ E[ Σt γt rt | π, σ ] π 为自身的策略，σ 为对手策略；均衡处双方均无单方面偏离的动机

与单智能体最优的差别在于：均衡策略的最优性以"对手最优应对时也不吃亏"为标准，对某一批固定对手的胜率无法刻画这一性质。在零和情形，极小极大定理保证混合策略意义下均衡存在且双方均衡值互为相反数，这为交替更新的算法提供了理论锚点：交替执行"对当前对手求最佳响应"在表格型零和博弈中收敛到均衡，其表格版本称为虚构博弈（Fictitious Play）的一种实现。

值函数的极小极大回溯对应：

Q(s, a, b) ← r(s, a, b) + γ · maxa′ minb′ Q(s′, a′, b′) a、b 分别为自身与对手动作；min 一侧体现对手的最坏响应

实现上 min 一侧常以"对手使用确定性策略时的朴素 Q 更新"近似，或对离散动作做极小极大枚举。注意该更新在循环博弈上可能振荡，需要平均化或交替冻结一侧。

2. 集中式结构的对抗改造

CTDE 的对抗版本保留"训练集中、执行分布"的分工，改动集中在一处：训练期的评论家输入拼接对手动作（对手可观测时直接拼接，不可观测时用对手建模头预测分布），执行期的策略只依赖自身观测。逐项拆解：

  • 自身网络。策略与价值输出与协作场景相同，输入限定在自身观测与历史。
  • 集中式评论家。输入为全局状态加对手动作，输出对联合行为的价值估计；对手动作条件化让价值网络区分"对手配合"与"对手反制"两种情形。
  • 梯度纪律。对手动作张量必须从计算图中分离（detach）或用独占的输入通道；任何让梯度穿透对手的行为都会把双方优化耦合在一起，更新方向不再对应极小极大结构。
  • 执行期近似。分布式执行拿不到真实对手动作，用对手建模头（第 032 章）的预测分布替代，或用无对手条件的价值头加保守惩罚。这一处近似是"训练优势转换为执行优势"的损耗来源，评测时需要单独度量。

梯度分离只是必要条件：分离保证了更新方向属于极小极大结构，但对手策略本身仍随训练演化，条件化输入的分辨率决定学习器能否跟上。两类残余困难的处置方式不同：对手动作可观测时不稳定来自分布漂移，用更新节奏与对手池管理（本章第 3 节）处理；对手动作不可观测时不稳定来自条件化误差，用预测置信度做输入门控，置信度低时退化为保守价值估计。

3. 自博弈的循环与联盟训练

自博弈让智能体与自己的历史版本或当前版本对练，是获取对手数据的最直接方式。两个失效模式：其一，对手池只保留最新版本时，策略对旧对手风格退化；其二，博弈包含非传递克制关系（石头剪刀布型）时，自博弈的学习动力学可能陷入循环：当前策略 A 占优、更新后 B 克制 A、再更新 A′ 克制 B，循环往复且周期可能增长。

联盟训练（League Training）用对手分布管理替代单点对手：维护一个跨版本、跨风格的对手集合，训练时按权重采样对手。典型组成：

对手条目作用采样权重（经验量级）
最新快照逼近当前水平0.4
历史快照池防止遗忘旧风格0.3
剥削者（针对当前策略训练）暴露漏洞、提升鲁棒性0.2
基础对手（规则或随机策略）稳态基线、下限保障0.1

快照的保存粒度是工程要点：一个对手要能被正确复现，除策略参数外还需要其配套的观测归一化统计、动作空间约定与随机种子状态，漏存任何一项都会让复现出的对手与当时版本行为不一致。

4. 可被利用度与评测协议

对抗策略的质量不能只看与当前对手的胜率，需要度量可被利用度（Exploitability）：针对待评估策略训练一个最佳响应对手，用该对手的收益超出均衡收益的部分衡量漏洞大小。完整计算均衡收益不可行时，使用代理协议：

代理可被利用度：在固定对手集 {σ1, …, σM} 上统计胜率下界与波动幅度 对手集包含历史快照、脚本策略与专用剥削者；报告最差胜率与方差，平均胜率只作参考

评测协议的纪律有三条：对手集冻结并随实验版本固定；评测期双方都使用确定性或固定温度的混合策略；胜率与收益同时报告，因为零和任务中收益差会放大胜率的微小差异。单看对最新对手的胜率是虚高的主要来源，因为它忽略了策略对旧版本与非常规风格的退化。

5. 数值算例：循环博弈的混合策略与对手池采样权重

石头剪刀布是检验对抗机制的最小模型，收益矩阵对角为 0、胜为 +1、负为 −1。三个确定性策略两两循环克制：任意纯策略遇到其克制者时每回合损失 1；均匀混合策略对任意纯对手的期望收益为 (0 + 1 − 1)/3 = 0，对均匀对手的期望同样为 0。这组数字是"均衡不可被利用"的具体形态：胜负各三分之一，任何方向上的偏离都被对称补偿。学习动力学在纯策略之间循环时，回报以周期平均近似为零，单点策略的瞬时优势不能作为训练进度的证据。评测改用最差胜率后，均匀策略在三类确定性对手上的最差胜率为 1/2（三局中一胜一负一平，平局按半分计入得分率），而任何纯策略的最差胜率为 0，两者的差距即混合策略的价值所在。

对手池的采样权重需要精确落地，否则配置与实际占比脱节。设池内条目为：最新快照 1 个、历史快照 18 个、剥削者 1 个、脚本对手 2 个，共 22 个条目。若按条目扁平采样，历史快照的合计占比为 18/22 ≈ 82%，最新快照只占 4.5%，与 0.4/0.3/0.2/0.1 的设计权重完全背离；改为先按类别权重抽桶、再在桶内均匀抽取后，历史类合计恰为 30%、桶内每条目约 1.7%，脚本类合计 10%、每条目 5%。桶内条目越多，单条目权重被摊薄，这正是类别权重能把"风格覆盖"与"条目数量"解耦的原因。容量与快照间隔的乘积决定历史窗口：容量 20、间隔 2 万步时，池覆盖最近约 40 万环境步的风格演化，间隔拉大到 5 万步则窗口扩到 100 万步，覆盖变宽而中间风格的粒度变粗。

最小验证流程可以完全离线完成：取一张两人零和收益表，分别运行虚拟对局与"池化自博弈"两种流程各数百轮，比较经验频率与解析均衡的 L1 距离，以及收益序列的滑动均值。均衡附近的收益均值应逼近博弈值，频率的收敛速度通常在百轮量级；若收益均值持续高于博弈值，优先检查评测是否只统计了有利对手子集，这一现象与训练期的虚高胜率同源。

实现思路与设计

对抗训练系统由三个组件构成：极小极大学习器、对手池管理器、评测器。三者的数据接口分离，对手池向学习器提供采样的对手参数与配套状态，评测器只读取检查点。

参数默认值作用取值依据
对手池容量10 至 30 个快照风格覆盖任务非传递性越强，容量越大
快照间隔每 2 万至 5 万环境步版本抽样粒度过密冗余、过疏丢失中间风格
采样权重最新 0.4 / 历史 0.3 / 剥削者 0.2 / 基础 0.1对手分布构成按任务的可被利用风险调整
剥削者训练预算主训练预算的 10%漏洞探测强度过高拖慢主策略进展，过低探测不足
可被利用度评测频率每 20 万环境步质量监控评测成本与训练长度的折中
梯度穿透防线对手输入 detach结构纪律不设例外，检查点中对手参数全程冻结

与第 032 章的衔接点：漂移监控在对抗场景中升级为对手分布监控，除策略散度外记录对手池的版本活跃度（哪些快照长期未被采样），活跃度失衡说明采样权重需要调整。

评测预算需要单独核算，因为可被利用度探针本身消耗训练同款的环境接口。以每次评测使用 6 个对手、每对手 200 回合、每回合约 200 步计，单次评测约 24 万环境步；每 20 万训练步评测一次时，评测开销与训练开销的比例约为百分之百量级，必须在预算中显式列支，或把剥削者的训练并入主训练预算内摊销。若评测频率保持而单次规模减半（对手 200 回合降到 100），胜率的标准误约上升为原来的根号二倍，报告的最差胜率波动随之放大，预算压缩的正确位置是降低评测频率，单对手回合数保持不变。这一点与第 037 章的种子方差规范一致：观测精度不足时，宁可少测几次，也要保证每次足够支承结论。

关键代码与解读

片段 1：极小极大目标计算

import torch

def minimax_target(q_joint, reward, done, gamma=0.99):
    """两人零和目标：自身取 max、对手取 min 的嵌套最优。"""
    with torch.no_grad():
        # q_joint: (batch, n_act_self, n_act_opp) 的联合价值网格
        inner = q_joint.min(dim=-1).values          # 先在对手维取 min：对手最坏响应
        best = inner.max(dim=-1).values             # 再在自身维取 max：自身最优应对
        # 终止步截断自举，与协作场景的约定一致
        return reward + gamma * best * (1.0 - done)

def detach_opponent_input(opp_actions):
    """对手动作进入评论家前必须分离梯度，防止双方优化耦合。"""
    return opp_actions.detach()                     # 对手参数不接收来自主损失的任何梯度

解读：min 与 max 的次序是极小极大结构的全部内容：先站在对手角度选择最不利于自身的动作，再从自身角度选择最优应对。离散联合网格在双方动作数乘积可达的规模上直接枚举；规模过大时改用对手建模分布下的期望替代 min（对分布的期望取 min 上界）：Eb~σ[Q(s, a, b)] 的近似。第二段函数的 detach 是纪律性封装，避免任何实现路径意外建立梯度连接；在批处理代码中把它放在数据加载器出口是最可靠的位置。

片段 2：对手池采样与版本管理

import numpy as np

class OpponentPool:
    """快照池：保存参数与配套状态，按权重采样对手。"""
    def __init__(self, capacity=20, weights=(0.4, 0.3, 0.2, 0.1)):
        self.capacity = capacity
        self.weights = weights                       # 最新/历史/剥削者/基础
        self.latest, self.history = [], []           # 两类快照分开管理
        self.exploiter, self.scripts = [], []

    def snapshot(self, policy_state, norm_state, seed):
        # 配套状态随参数一起保存：缺失任一项都会让复现的对手行为漂移
        entry = {"params": policy_state, "norm": norm_state, "seed": seed}
        self.latest = [entry]
        self.history.append(entry)
        if len(self.history) > self.capacity:
            self.history.pop(0)                      # 先进先出，保持时间跨度覆盖

    def sample(self, rng):
        pool = [self.latest, self.history, self.exploiter, self.scripts]
        # 先按类别权重选桶，再在桶内均匀取一个，避免大桶被过度采样
        bucket = rng.choice(len(pool), p=self.weights)
        members = pool[bucket]
        return members[rng.integers(len(members))]

解读：两层采样（先类别后桶内）让各类对手的实际采样占比与配置权重精确对应，直接按条目扁平采样会让历史池越大占比越高。快照条目包含归一化统计与种子状态，这两个字段是小规模实现最常遗漏的部分。剥削者条目在训练循环中周期性重建，脚本对手保持不变；桶为空时上层的采样函数应回退到基础对手，保持接口在任何训练阶段都可调用。

片段 3：可被利用度评测

def exploitability_probe(policy, opponent_set, env, n_episodes=200):
    """固定对手集上的胜率下界：报告最差对手与分布波动。"""
    wins = {}
    for name, opponent in opponent_set.items():
        w = 0
        for ep in range(n_episodes):
            env.seed(10_000 + ep)                # 每对手共享同一组环境种子
            obs = env.reset()
            done = False
            while not done:
                # 评测双方均用确定性动作：消除采样噪声对胜率的干扰
                a_self = policy.deterministic(obs["self"])
                a_opp = opponent.deterministic(obs["opp"])
                obs, r, done = env.step(a_self, a_opp)
            w += int(r["self"] > 0)
        wins[name] = w / n_episodes
    # 报告最差胜率与标准差：平均胜率会掩盖单点漏洞
    worst = min(wins.values())
    print(f"最差胜率 {worst:.3f} | 各对手 {wins}")
    return worst, wins

解读："最差胜率"是比平均胜率更接近可被利用度的代理指标：平均化会稀释来自单一克制风格的低分，而均衡策略的性质恰恰要求对所有风格不落下风。同一组环境种子用于全部对手，构成配对比较，显著降低方差；确定性动作消除采样噪声，代价是忽略混合策略的收益，属于评测口径的显式取舍。实际协议中对手集还应包含一个在线训练的剥削者，其训练轮数固定（例如主预算的百分之十），保证评测强度跨实验可比。

常见坑

  • 梯度穿透对手网络。对手动作未分离梯度，双方参数被同一条损失拉动，学习方向偏离极小极大。症状是对手行为异常配合。修复：数据出口处 detach，检查图中断言无跨侧梯度。
  • 对手池管理缺陷。只与最新版本自博弈使策略对历史风格退化；快照缺少配套状态（归一化、种子）使复现的对手行为漂移。修复：维护历史快照池并纳入采样；快照按完整状态打包，加载时做一致性断言。
  • 用训练中的对手评测。对手仍在学习，胜率反映的是双方相对速度，与策略质量脱钩。修复：评测使用冻结对手集，训练与评测环境实例分离。
  • 非零和任务误用极小极大。一般和结构中对手的最坏响应未必是合理假设，min 嵌套导致过度保守。修复：先确认收益结构是否零和；混合动机任务改用第 034 章的框架。
  • 循环博弈中强行要求收敛。石头剪刀布型动态下策略持续循环，误判为训练失败。 修复：接受周期行为，评测改看可被利用度，不盯单点策略的回报。

练习与思考

  1. 推导：在石头剪刀布的对称收益矩阵上，证明任意确定性策略都有被克制者；写出均匀混合策略的收益值，并说明"最佳响应对均匀策略"与"均匀策略对均匀策略"的收益差为什么是零。★
    提示
    三个确定性策略两两循环克制；均匀混合对任意对手期望为零，对均匀策略也是零，故均匀策略不可被利用。
  2. 改参数预测：把历史快照池容量从 20 降到 2（其余配置不变），预测"对最新对手胜率"与"最差胜率"两条评测曲线的分化方向，并给出训练中可观察的迹象。★
    提示
    对最新对手胜率大致保持，最差胜率明显下降；训练中可观察历史风格相关的回合失败率上升。
  3. 设计：为一个非传递性明显的对抗任务（例如环形克制的关系）设计联盟组成与采样权重，说明剥削者的训练目标、更新周期与退役条件。★★
    提示
    剥削者以最大化对主策略的收益为目标短程训练；更新周期与主策略快照同期；当其对主策略胜率低于阈值即退役，防止长期占用采样权重。
  4. 实验设计：比较纯自博弈、历史池自博弈、完整联盟三种设置，评测使用固定对手集上的最差胜率与收益方差，说明如何控制三类设置的训练预算一致。★★★
    提示
    联盟的剥削者训练计入总预算；三种设置的主策略更新步数相同；报告曲线取相同评测间隔的多点对比。

小结

  • 零和对抗的目标是极小极大：在对手最坏响应下最大化收益，均衡策略取代单点最优成为成功标准。
  • CTDE 的对抗改造集中在评论家：训练期条件化对手动作，执行期用对手建模近似；对手输入必须分离梯度。
  • 自博弈可能陷入循环动力学；联盟训练以对手池管理替换单点对手，快照需打包策略与配套状态。
  • 可被利用度用固定对手集上的最差胜率代理评估；平均胜率与单点胜率都会掩盖漏洞。
