第 095 章：实验设计与评价指标

从"跑几条曲线"到可检验的研究设计：本章给出假设与变量控制、种子数与统计功效、配对比较与检验选择、样本效率指标（到达阈值步数与曲线面积）以及一份可直接使用的实验协议模板。

  • 主题：实验方法论 / 统计评价
  • 关键公式：到达阈值步数 t(τ) 的线性插值、曲线面积 AUC = ∫ f(t) dt / T、配对差值的自助置信区间
  • 预计学时：60 分钟
  • 前置章节：第 094 章

学习目标

  • 掌握实验设计五要素：假设、自变量、因变量、控制变量与配对结构，能为研究问题写出完整设计。
  • 理解种子数与统计功效的关系，能根据曲线方差给出种子数建议。
  • 掌握三类评价指标：最终性能、样本效率（到达阈值步数）与曲线面积（AUC），理解各自适配的问题。
  • 学会配对比较与检验选择：配对差值的自助区间、Wilcoxon 符号秩检验与多重比较校正。
  • 能写出预注册风格的实验协议：指标定义、评估协议、检验方法与报告格式一次锁定。

背景与动机

第 082 章解决了"数据怎么聚合"，第 092 至 094 章解决了"别人怎么复现"，本章解决中间环节：实验怎么设计才能在统计上站得住脚。多智能体实验的方差来源比单智能体更多：种子的初始化差异、探索噪声路径、评估对手策略、并行副本的调度顺序，任何一项失控都会让"算法 A 优于 B"的结论在重复实验后翻转。实验设计的目标是把结论的可靠性从"作者相信"提升到"数据支持"。

本章按实验的生命周期组织：设计阶段确定假设与变量，执行阶段固定评估协议，分析阶段选择指标与检验，报告阶段统一格式。四个阶段共享同一份协议文档，预注册的意义在于防止看到结果之后再挑指标。与第 096 章的分工：本章解决"主实验如何比较"，096 章解决"机制归因如何做消融"。

核心原理

1. 设计五要素

要素定义多智能体示例
假设 H1方向性预期，例如"全局状态输入的 critic 提升样本效率"MAPPO 到达 80% 胜率所需环境步少于 IPPO
自变量被操纵的因素算法、critic 输入结构、通信开关
因变量被测量的量胜率、回合回报、到达阈值步数、比特数
控制变量保持不变的因素环境版本、地图、评估协议、训练预算
配对结构共享随机性的分组方式同一环境下同一种子运行全部算法

配对结构的价值是方差消除：同种子的初始状态与探索路径相同，算法间差异不再被种子差异掩盖，所需种子数显著下降，这是多智能体对比实验的标准做法。

2. 种子数与统计功效

统计功效是"真实差异存在时检验能检出的概率"。功效取决于效应量与噪声之比：效应量固定时，种子数越大、噪声越低，功效越高。工程上的经验规则：先跑五个种子估计曲线的标准差 σ，再按目标效应量 Δ 估算所需种子数，量级上种子数与 (σ/Δ)² 成正比。多智能体基准上的常见结论差距在 5 到 10 个百分点量级，对应 10 个以上种子；三个种子的"显著"结论多数是噪声。评估回合数（例如 32）降低的是评估噪声，与种子数降低的初始化噪声是两类独立的方差来源，不能互相替代。

3. 评价指标：最终性能、样本效率与曲线面积

三个指标回答三个不同问题，实验中应按问题选择：

  • 最终性能：训练预算末端的表现，取最后 10% 评估点窗口的均值。回答"最终能达到多好"，对样本效率不敏感。
  • 样本效率：到达固定阈值 τ（例如 0.8 倍参考胜率）所需的环境步数，曲线首次穿过阈值处线性插值。回答"多快能到可用水平"，未达标种子按右删失计入并单独统计比例。
  • 曲线面积（AUC）：曲线对环境步的积分除以总预算，回答"全程平均水平"。AUC 对早期差异敏感，适合比较收敛速度量级不同的算法。
t(τ) = t0 + (τ − v0) / (v1 − v0) · (t1 − t0)，AUC = (1/T) ∫0T f(t) dt t(τ) 为首次穿过阈值附近的线性插值；AUC 用梯形法数值积分，量纲与平均胜率一致

三个指标必须同时预定义：只看最终性能会低估快速收敛的算法，只看样本效率会漏掉渐近水平的差异。阈值 τ 的选择尤其要预防"事后挑选"：先按参考方法确定，再对所有算法使用同一数值。

4. 检验选择与多重比较

配对比较的最小充分做法是"同种子差值的自助置信区间"：对每个种子计算算法 A 与 B 的指标差，重采样种子得到的区间若不跨零，则差异显著。区间不跨零与配对检验的方向一致，Wilcoxon 符号秩检验在分布未知时更稳健，配对 t 检验在差值近似正态时功效更高。报告规范为：效应量（差值点估计）加 95% 区间加检验名称，只报 p 值不报效应量会隐藏差异的实际大小。当一次实验包含多组对比（例如四组算法两两六次比较）时，必须做多重比较校正，Holm 方法按 p 值升序，依次与递增的显著性水平 α/m、α/(m−1)、… 比较，控制族错误率。

5. 评估协议与预注册

协议在实验开始前锁定：评估频率、评估回合数、评估种子集、贪心与否、截断计胜规则、指标定义、检验方法与种子数。锁定的意义是把"分析自由度"提前消耗掉：允许在看到曲线后修改阈值或种子集，等于给结论留了自我实现的空间。预注册协议并不排斥探索性分析，但探索性结果必须与验证性结果分开标注，前者只用于提出新假设。

实现思路与设计

实验流程分五步：

  1. 预实验：五种子估算噪声水平与效应量，确定主实验的种子数。
  2. 协议固化：指标定义、阈值、评估协议、检验方法写成协议文档并标注版本。
  3. 主实验：按配对矩阵运行算法与种子，训练预算固定。
  4. 分析：按第 082 章管道聚合，计算三指标、配对区间与校正后的检验结果。
  5. 报告：统一表格格式，效应量与区间并列，探索性发现单独小节。

与第 094 章的差异点：094 章保证复现保真，本章保证结论可检验；复现产出的记录文件正是本章分析管道的输入，两章通过第 082 章的 JSONL 格式对接。

设计决策：为什么配对结构能显著减少种子数需求？

非配对比较中，种子间的性能差异（初始化质量、探索运气）与算法差异叠加，方差是两者之和；配对结构中算法差异用同种子差值度量，种子间差异被逐种对消，只剩差值本身的方差。实验数据显示配对设计常把所需种子数降低到一半以下。代价是实验调度必须"按种子成组运行"，无法按算法分批运行。

关键代码与解读

片段 1：配对差值的自助置信区间

import numpy as np

def paired_difference_ci(curve_a, curve_b, n_boot=20000, alpha=0.05, rng=None):
    """配对比较：同种子逐点求差，自助区间回答差异是否偏离零。"""
    rng = rng or np.random.default_rng(7)
    diff = np.asarray(curve_a) - np.asarray(curve_b)   # 形状 (K, T)
    k, t = diff.shape
    boots = np.empty(n_boot, dtype=np.float64)
    for b in range(n_boot):
        si = rng.integers(0, k, size=k)      # 重采样种子：方差的主要来源
        ti = rng.integers(0, t, size=t)      # 重采样评估点：次级噪声来源
        boots[b] = diff[si][:, ti].mean()
    lo, hi = np.quantile(boots, [alpha / 2, 1 - alpha / 2])
    # 双向判据：区间不跨零即显著，同时给出效应量（差值均值）
    return float(diff.mean()), float(lo), float(hi), bool(lo > 0 or hi < 0)

# 用法：A 比 B 平均高 0.04，区间 [0.01, 0.07]：显著且效应量可读
mean, lo, hi, sig = paired_difference_ci(curve_a, curve_b)

解读：（1）函数先做逐点配对差再聚合，避免先聚合各自曲线再相减的方差失真：配对差保留了同种子的相关性信息。（2）两层重采样与第 082 章的分层自助一致；种子是第一层，因为它是方差主源。（3）返回值四元组把效应量、区间与显著性判断一次性给出，报告模板直接引用，避免各处重复实现导致口径不一。（4）注释中的示例数值展示"读法"：显著不等于大，效应量 0.04 的胜率差与 0.04 的回报差意义不同，量纲由指标决定。

片段 2：到达阈值步数与曲线面积

import numpy as np

def steps_to_threshold(steps, curve, tau):
    """到达阈值 tau 的最小环境步：曲线首次穿过阈值处线性插值。"""
    for i in range(1, len(curve)):
        if curve[i] >= tau:
            t0, t1 = steps[i - 1], steps[i]
            v0, v1 = curve[i - 1], curve[i]
            # 线性插值避免评估间隔粗导致的高估
            frac = (tau - v0) / (v1 - v0 + 1e-8)
            return float(t0 + frac * (t1 - t0))
    return float("nan")            # 预算内未达标：按右删失处理，不丢弃种子

def curve_auc(steps, curve, total_steps):
    """曲线面积：梯形积分除以总预算，量纲与平均胜率一致。"""
    return float(np.trapezoid(curve, steps) / total_steps)

# 报告全部种子的 t(tau)：达标种子给数值，未达标给 NaN 并单独统计比例
steps = np.arange(0, 500001, 25000)
taus = [steps_to_threshold(steps, c, 0.8) for c in per_seed_curves]
print(np.nanmean(taus), np.mean(np.isnan(taus)))   # 均值与删失比例

解读：（1）穿越阈值用插值："取首个达标点"在 25000 步的评估间隔下会系统性高估达到时间，插值把偏差降到间隔的分数级。（2）未达标返回 NaN 并保留删失记录：丢弃相当于假装算法从未运行过，会系统性高估快算法系列；NaN 加删失比例报告是诚实做法。（3）np.trapezoid 是 numpy 2 的积分函数（旧版为 np.trapz）；AUC 除以总预算后与平均胜率同量纲，不同总预算的实验可以直接比较。（4）两函数都按单条曲线计算，批量统计（均值、区间）交给调用方按种子循环，职责边界清晰。

常见坑

  • 事后挑选阈值：看到曲线后再定 τ，让结论更"好看"。修复：协议预注册，τ 由参考方法确定并全局统一。
  • 只报 p 值不报效应量：大样本下微小差异也显著。修复：效应量、区间与检验名三者并列报告。
  • 把评估回合数当种子数用：增加评估回合只降低评估噪声，无法替代种子覆盖的初始化差异。修复：两类噪声分别规划，主实验种子不少于 10。
  • 多组两两比较不做校正：六次比较的族错误率逼近 0.26。修复：Holm 或 Bonferroni 校正，报告校正前后两套 p 值。
  • 未达标种子被静默丢弃：样本效率均值被系统性高估。修复：NaN 加删失比例，或改用生存分析报告。

练习与思考

  1. 给定两条曲线的配对差值均值 0.03、区间 [−0.005, 0.065]，判断显著性并说明需要增加种子还是接受"无结论"。★
    提示
    区间跨零，无显著差异；区间宽度按 1/√K 收缩，种子数增到四倍可把宽度减半，届时再判断。
  2. 把阈值 τ 从 0.8 提高到 0.9，预测达标步数、未达标比例与算法排序的变化，并解释为何 τ 的选择要在协议中锁定。★★
    提示
    阈值提高后所有算法达标更晚，接近渐近水平的弱算法大量删失，排序可能反转。多档 τ 的敏感性分析可作为附录，主结论以预注册阈值为准。
  3. 推导：若单种子指标的方差为 σ²，K 个种子的均值方差为 σ²/K；配对差值在设计效应量 Δ 时，比较两组均值的功效所需种子数与 (σ/Δ)² 的量级关系。★★
    提示
    配对后差值方差为 σd²（通常小于 2σ²），检验统计量均值/标准误约为 Δ/(σd/√K)，要达到阈值 2 需 K ≈ 4σd²/Δ²，与 (σd/Δ)² 同阶。
  4. 设计实验协议：在复现的 MAPPO 与 IPPO 对比中填入五要素、三指标定义、种子数与检验方法，并说明协议锁定后允许与不允许的修改。★★★
    提示
    允许的修改：实现缺陷修复（需记录版本与影响）；不允许：阈值、种子集、评估协议的存在性修改。两者区别写入协议文档的"变更记录"节。
  5. 用模拟数据构造两种情形：真实差异 0.05 但噪声大、真实差异 0.01 但噪声小，分别算配对区间并讨论为什么效应量比 p 值更有信息量。★★★
    提示
    两种情形都可能显著，但前者结论稳健性差（换种子集可能翻盘），后者结论稳定。区间宽度与效应量的比值是稳健性的直接读数。

小结

  • 实验设计五要素：假设、自变量、因变量、控制变量与配对结构；配对设计用同种子差值消除初始化方差。
  • 种子数按效应量与噪声比规划，10 个是常见下限；评估回合数降低的是另一种噪声，两者不可互换。
  • 三指标各司其职：最终性能、到达阈值步数（含删失处理）与曲线面积；阈值必须预注册。
  • 检验用配对差值自助区间，Wilcoxon 与 t 检验按分布选择；多组比较用 Holm 校正，效应量与区间必须并列报告。
  • 实验协议在开始前锁定，探索性分析与验证性结论分开标注。
  • 下一章细化机制归因：消融实验设计，讨论组件移除、因子设计与交互效应的量化方法。
