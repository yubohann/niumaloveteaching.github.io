第二篇 · 训练工程与稳定性

第 028 章：多智能体离散动作空间处理

本章讲离散动作空间（Discrete Action Space）在多智能体中的工程设计：动作掩码（Action Masking）在采样、目标计算与损失三个环节的一致性约束，因子化动作空间（Factorized Action Space）的组合爆炸与分层决策，以及异构动作维度的统一接口。

  • 主题：动作空间工程 / 掩码一致性
  • 关键公式：a* = arg maxa: mask(a) = 1 Q(o, a)
  • 预计学时：50 分钟
  • 前置章节：第 027 章 梯度裁剪与优化器选择

学习目标

  • 理解离散动作的多智能体表示：动作索引、独热编码与动作嵌入的取舍。
  • 掌握动作掩码在行为策略、目标值计算、损失计算三个环节的作用方式，能说明"三处一致"失败的具体后果。
  • 掌握掩码的数值实现：负大值填充与掩码 softmax 的等价性，以及 NaN 防护。
  • 理解因子化动作空间的结构：子动作联合枚举、分层解码与联合合法性检查。
  • 能实现掩码化的探索采样与目标计算，并诊断掩码错位、维度错配两类故障。

背景与动机

多智能体任务的动作常带约束：目标位置已被占据时不能移动过去、弹药耗尽后攻击动作无效、通信带宽用尽后广播不可用。这类合法性约束随状态动态变化，若交给智能体自行试错，无效动作的负反馈与合法动作的学习信号混杂在同一价值函数上，训练效率显著下降。

动作掩码把工程上的先验知识直接注入动作选择：环境每个时间步返回可用动作集合，策略只在合法子集上比较与采样。多智能体把这项工程的复杂度抬高一个层次：合法集合按智能体、按时间步各不相同，掩码必须随数据一并存入回放池，并在目标值计算与损失两个训练环节复现。与此同时，技能类任务的动作空间常按维度因子化：移动方向与技能类别分开选择，联合动作数按乘积增长，掩码检查需要覆盖组合合法性。本章处理这些问题，为第 029 章的连续动作与第 030 章的异构智能体打下接口基础。

核心原理

1. 离散动作的表示与选择

每个智能体的离散动作空间大小记为 |Ai|，输出端从价值或策略头得到长度 |Ai| 的向量。同构智能体共享同一动作空间与网络输出维度；异构智能体（第 030 章）的 |Ai| 可以不同，接口层用动作嵌入把不同维度映射到统一隐空间，再各自解码。动作的执行形式可以是索引，也可以是独热向量或嵌入向量：索引最省内存，与交叉熵损失天然匹配；独热或嵌入在需要把动作作为输入（例如对手建模网络）时更方便。回放池存索引，训练时按需转换是主流做法。

2. 动作掩码的三处一致性

设掩码 mi(oi) ∈ {0, 1}|Ai| 由环境或接口层给出，1 表示动作合法。掩码在训练系统中出现在三个位置，缺一不可：

  • 行为策略处：采样与探索只在合法集合内进行。贪婪时取合法集合上的最大值，随机探索时从合法集合中均匀抽取或按掩码化分布采样。
  • 目标值处：下一状态的最优动作在下一时刻的合法集合上取，a′i = arg maxm′i = 1 Q(o′i, ·)。若此处的掩码被遗漏，时序差分目标会把不可行动作的价值当作可达到的上界，价值估计被系统性抬高。
  • 损失处：策略梯度类的对数概率在掩码化分布上计算，价值类算法的目标选择使用掩码化动作。
掩码化贪婪：a*i = arg maxa: mi(a) = 1 Qi(oi, a) 等价写法：Q̃i(a) = Qi(a) + log mi(a)，将非法动作记为对数值 −∞

三个位置共享同一份掩码数据，且时间对齐：行为策略用的是 t 时刻掩码，目标计算用 t+1 时刻掩码，两者在回放池中必须分别存储。工程上把掩码作为过渡数据的标准字段（第 023 章的缓冲区结构已将 avail 纳入），从数据结构层面保证复现。

3. 掩码的数值实现

非法动作的填充值影响数值稳定性。用严格 −∞ 会在 softmax 与除法中出现 0/0 或 NaN；常用负大值 −109 替代，指数运算结果下溢到 0，同时避免 NaN。掩码与玻尔兹曼温度联用时温度不宜过小，否则合法集合内低价值动作的概率同样下溢，探索失效。

π(a | o) = m(a) · exp( Q(o, a) / τ ) / Σa′ m(a′) · exp( Q(o, a′) / τ ) 实现上先做"减合法集合最大值"的平移，再做指数，双保险防止溢出与下溢

走探索路径的均匀采样也必须限定在合法集合：先对掩码求和得到合法数量 k，再在 0 到 k−1 的均匀整数中取一个，映射回第几个合法动作。直接在全动作空间均匀采样再重试的实现会引入隐式偏置与额外计算。

4. 因子化动作空间

技能类任务的离散动作常天然分层：移动方向有 5 到 9 个选项，技能类别有攻击、治疗、传送等若干选项，完整动作是两者的组合。联合枚举的规模是乘积 |Amove| × |Askill|，对 Q 头不构成困难（几十到上百维），关键是合法性检查：某些技能只允许在特定移动后使用，掩码定义在联合格点上，需要环境逐组合给出或由接口层按规则合成。

当乘积过大或结构更强时改用分层解码：先选择子动作 A，条件于 A 再选子动作 B，策略的对数概率分解为两项之和：

log π(a1, a2 | o) = log π1(a1 | o) + log π2(a2 | o, a1) 两项分别做掩码化归一；联合掩码按条件分解 m(a₁, a₂) = m₁(a₁)·m₂(a₂ | a₁)

分层解码把联合空间的选择代价从乘积降为求和，代价是两层之间的条件依赖必须真实存在且被数据覆盖。值分解算法处理因子化动作时，个体 Q 头在联合格点上输出后取掩码化 argmax，保持与混合网络单调性条件（IGM）兼容；把 Q 拆成两个独立头再相加会破坏联合最优与个体最优的对应关系，属于结构错误。

5. 数值算例：掩码填充值与非法采样概率

取三个动作其价值为 (2.0, 1.0, 0.5)，第三个非法，温度 τ = 1。分别用按填充处理的玻尔兹曼采样核对非法动作的残留概率（数值经程序核对）：

非法位填充值非法动作概率说明
−1（与价值同量级）0.0351约 3.5% 的采样犯错，数据被污染
−1090（下溢）指数运算下溢为零，行为与精确屏蔽一致

读数：填充值必须远离合法价值的量级，−1 这样的"轻罚"会让非法动作以可观概率进入回放池与目标计算；同时另一个边界也要记住，若合法集合在 softmax 平移后被整体压下（温度过低），合法动作之间的概率差同样会下溢为 one-hot，探索失效。τ = 0.1 时上例合法两动作的概率为 (0.999955, 0.000045)，策略已接近永不探索，温度本身构成一道探索下限的约束。

6. 数值算例：目标计算漏掩码的抬价幅度

设下一状态动作价值估计为：合法动作 1.0，非法动作 50.0（网络在别处学到的峰值外推）。漏掩码时目标取 max = 50，正确掩码时取 1.0；取 γ = 0.99，目标值被抬高的幅度为 0.99 × 49 = 48.51（数值经程序核对）。这个数字说明"目标计算处漏掩码"是三类掩码缺口中最致命的一类：单步目标的错误量级与价值尺度同阶，误差经自举回流后系统性放大价值估计，训练表现为价值曲线整体上浮、策略沿虚高方向退化。检查手段是构造"目标掩码关闭"的对照运行，观察价值估计与真实回报的偏差是否同步扩大。

7. 三种动作头结构的代价与表达力

以移动 9 档、技能 6 档、特征维度 64 为例（数值经程序核对）：

结构输出层参数量表达力适用边界
联合全连接头64 × 54 = 3456完整，可表达任意组合偏好联合格点几十到上百维
因子化外和头64 × 15 = 960加性结构，移动与技能无交互项两维子动作近似独立
分层解码两段输出，参数量介于两者之间可表达单向条件依赖层级依赖真实存在且数据覆盖充分

选择判据有两层：其一，参数量差距 3.6 倍说明因子化在格点规模大时省的是输出层乘法，规模越大差距越显著（外和头的参数量随 |A1| + |A2| 增长，全连接随乘积增长）；其二，外和头只能表达 S(m, s) = u(m) + v(s) 的加性结构，无法表达"传送只在静止时值得"这类交互，交互强时需在全连接头或分层解码之间选择。先训练外和头版本，用联合格点残差（各组合的实测价值与加性分解的偏差）判断交互强度，再决定是否升级结构。

8. 掩码工程的边界清单

除前述三类位置外，三个边界情形需要专门用例覆盖：（1）全非法动作状态（单位被消灭、技能冷却齐发），掩码和为零时均匀采样与 argmax 都失去定义，必须在接口层转成截断标记；（2）掩码随时间的对齐，t 与 t+1 掩码分别随过渡数据存储，回段边界处尤其容易串位，单元测试用"掩码全常开"与"全常闭"两种极端任务各跑一条短训练即可暴露；（3）评估路径的掩码一致性，评测不经过训练接口时容易直接对原始输出取 argmax，非法动作被执行导致评测进入异常状态，修复方式是评测与训练强制共用一个动作选择入口，并把非法执行计数纳入评估指标（正常应恒为零）。

实现思路与设计

动作接口层统一管理三件事：掩码的获取与存储、采样与目标计算对掩码的消费、异构动作维度的对齐。掩码字段随过渡数据入池，训练端通过同一读取接口取用，避免两处手工传递造成错位。

参数默认值作用取值依据
非法动作填充值−109屏蔽非法动作足够小使指数下溢为 0，同时远离浮点溢出边界
动作头结构联合格点输出因子化动作选择乘积规模在百维以内时直接输出；更大时改分层解码
掩码存储t 与 t+1 两份目标计算需要下一掩码每智能体一个布尔向量，占用可忽略
探索时的合法采样合法集合内均匀探索不产生非法动作先求掩码和再映射，避免重试偏置
动作维度的异构处理按智能体分组维度不同时对齐第 030 章展开分组与嵌入方案

与第 027 章的衔接点：掩码使部分动作的输出梯度恒为零，掩码严格的智能体其动作头得到的有效梯度样本更少；学习率与裁剪标定应考虑有效梯度收入的差异，动作头学习率可略高于共享主干。

关键代码与解读

片段 1：掩码化贪婪与合法探索采样

import numpy as np

def masked_greedy(q_values, avail):
    """在合法集合内取最大：非法动作以负大值屏蔽，避免泄入选择。"""
    q = q_values.copy()
    q[avail == 0] = -1e9          # 与训练端填充值一致，保持两处口径统一
    return int(np.argmax(q))

def masked_epsilon_greedy(q_values, avail, eps, rng):
    """探索采样限定在合法集合内：先计数再映射，避免拒绝重试的偏置。"""
    if rng.rand() >= eps:
        return masked_greedy(q_values, avail)
    legal = np.flatnonzero(avail)                 # 合法动作的下标列表
    return int(rng.choice(legal))                 # 合法集合内均匀抽取

解读：两次实现都把合法集合的界定集中在一个函数内，采样路径与贪婪路径共用同一判定。负大值取值在采样端与训练端保持完全相同是刻意的纪律：两处填充值不同会让"训练时屏蔽的动作"与"执行时屏蔽的动作"出现细微差异，这种缺陷在小规模测试中不可见，只在长训练里表现为价值估计的缓慢漂移。flatnonzero 加 choice 的两步法与"随机重试直到合法"相比没有偏置且最坏代价有界。

片段 2：掩码化 Q 目标计算

import torch

def masked_q_target(q_next, avail_next, reward, done, gamma=0.99):
    """目标值计算：下一状态的最优动作必须在下一时刻合法集合内选取。"""
    q = q_next.clone()
    # 掩码在 argmax 之前生效：进入最优选择的只有合法动作
    q[avail_next == 0] = -1e9
    q_max = q.max(dim=-1).values                  # 每个智能体的最优合法价值
    # 若某状态无任何合法动作（终态常见），该智能体贡献置零并视为终止
    no_legal = (avail_next.sum(dim=-1) == 0)
    q_max = torch.where(no_legal, torch.zeros_like(q_max), q_max)
    done_eff = done | no_legal.float()            # 无合法动作等价于回合截断
    return reward + gamma * q_max * (1 - done_eff)

解读：掩码在这里承担双重职责：屏蔽不可行动作的价值，以及界定无动作可用状态的处理。无合法动作的边界情形（例如单位已被消灭）若无专门处理，argmax 会在全负大值向量上返回任意索引，其对应的价值接近 −109，目标值被灾难性拉低。done_eff 的合成把该情形转化为截断，与第 024 章终止处理共用同一条通路。该函数对所有智能体同时计算，联合目标的合成由值分解混合器完成。

片段 3：因子化动作头的联合掩码

import torch.nn as nn

class FactoredActionHead(nn.Module):
    """移动与技能两个子头，联合掩码在格点上检查组合合法性。"""
    def __init__(self, feat_dim, n_move=9, n_skill=6):
        super().__init__()
        self.n_move, self.n_skill = n_move, n_skill
        self.head_move = nn.Linear(feat_dim, n_move)     # 子头 A：移动方向
        self.head_skill = nn.Linear(feat_dim, n_skill)   # 子头 B：技能选择
        self.register_buffer("joint_mask", torch.ones(n_move, n_skill, dtype=torch.bool))

    def forward(self, feat, joint_mask=None):
        # 两子头输出外和形成联合格点分数：结构与联合枚举等价但参数更省
        scores = self.head_move(feat).unsqueeze(-1) + self.head_skill(feat).unsqueeze(-2)
        mask = self.joint_mask if joint_mask is None else joint_mask
        # 非法组合屏蔽后展平：后续 argmax 或采样在合法组合上进行
        return scores.masked_fill(~mask, -1e9).flatten(-2)

    def decode(self, joint_index):
        # 联合索引解码为 (移动, 技能) 二元组，供环境执行
        return divmod(int(joint_index), self.n_skill)

解读：forward 用外和把两个子头的分数拼成联合格点，参数量为两个线性层之和，联合格点规模只影响输出维度，不会带来乘积级的参数增长，这正是因子化结构的收益。masked_fill 在展平之前施加，保证联合掩码以二维格点形式表达，与环境的组合合法性规则一一对应。decode 用整除与取余还原二元组，注意联合索引的排列约定（先行后列）必须与环境侧一致，这是跨模块接口中最容易错位的一处，通常用单元测试固定。当联合格点规模超过数百维时，把这个类替换为第 029 章的分层解码形式，接口保持不变。

常见坑

  • 目标计算与数值约定的掩码缺陷。目标值在全动作空间取 max 使不可行动作抬高时序差分目标；填充值用严格 −∞ 时指数运算产生 NaN 并扩散到全部参数。修复：缓冲区存储 t 与 t+1 两份掩码供目标函数读取；统一使用 −109 并加 nan 检测熔断。
  • 探索采样在全局动作空间均匀抽取后重试。合法集合大小随状态变化时，重试次数与合法数量逆相关，采样分布出现状态依赖的偏置。修复：先求合法集合再均匀抽取。
  • 异构动作维度共享动作头。不同 |Ai| 的智能体共用输出层，维度小的智能体被迫学习永不可用的输出位。修复：按动作空间分组共享，或分组加嵌入。
  • 因子化联合掩码未检查组合合法性。只按子动作各自合法合成联合掩码，忽略了组合约束（技能与移动的搭配限制）。修复：环境给出联合格点掩码，或在接口层用规则函数合成并单测覆盖。
  • 评估路径绕过掩码。评测时直接对原始输出取 argmax，非法动作被执行导致评测异常终止。修复：评测与训练共用同一动作选择接口。

    联合规模 40；掩码规则例如"传送技能仅允许在静止移动下使用"需要在格点上显式表达；测试覆盖边界状态与全非法情形。
  4. 实验设计：在含动态约束的任务上比较无掩码、仅行为策略掩码、全链路掩码三种设置，指标使用非法动作执行率、达到固定回报的环境步数与价值估计偏差（与回合真实回报对照）。★★★
    提示
    预期仅行为策略掩码的设置价值偏差最大，可作为"目标计算必须掩码"的直接证据；三种设置保持网络与种子一致。

小结

  • 动作掩码把合法性先验注入动作选择，在多智能体系统中要在行为策略、目标计算、损失三个环节保持一致，t 与 t+1 掩码分别存储。
  • 掩码的数值实现用负大值填充与平移指数，避免 −∞ 引发的 NaN；探索采样限定在合法集合内并用两步映射避免偏置。
  • 因子化动作空间用外和构造联合格点分数，参数代价从乘积降为求和；联合掩码表达组合合法性，解码约定需单元测试固定。
  • 无合法动作的边界状态需特殊处理为截断，防止目标值被负大值污染。
