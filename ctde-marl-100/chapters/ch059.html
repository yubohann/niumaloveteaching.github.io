第三篇 · 环境与任务实践

第 059 章：多智能体供应链管理

供应链把库存与订货决策串成多级链条；本章推导报童模型的临界分位数，解释牛鞭效应的四个成因，并说明信息共享与契约协调如何把分散决策拉回系统最优附近。

  • 主题：多级库存协同 / 机制协调
  • 关键公式：P( D ≤ Q* ) = cu / ( cu + co )
  • 预计学时：65 分钟
  • 前置章节：第 058 章 多智能体金融交易

学习目标

读完本章，应当能够把多级库存系统写成链式动态决策，并解释协同失灵与契约协调的机制。

  • 掌握多级库存的递推动力学与提前期管道的作用，能正确实现“在途货物”的状态跟踪。
  • 掌握报童模型的临界分位数求解与（s, S）策略的形状，理解服务水平与库存成本的权衡。
  • 理解牛鞭效应的定义、度量方式与四个成因，能说明信息共享对放大系数的抑制作用。
  • 理解双重边际化与契约协调（回购、收益共享）的机制，能判断契约参数的可协调区间。
  • 会为链条中的每个节点设计观测与奖励，并识别只优化本地成本导致的系统次优。

背景与动机

供应链的核心矛盾是分散决策与系统最优之间的偏差。

多级供应链由供应商、制造商、分销商与零售商组成，每一级根据下游订单向上游订货，货物按提前期逐级传递。若每一级只优化自身成本，两个后果随之出现。第一，需求信号在逐级传递中被反复平滑与放大，零售商的小幅需求波动传导到上游成为大幅的生产波动，这一现象称为牛鞭效应（bullwhip effect）。第二，各级的加价造成双重边际化（double marginalization），链条总利润低于集中决策的水平。经典研究表明，牛鞭效应的四个成因分别是需求信号处理（每级用本地订单估计需求）、批量订货、价格波动与短缺博弈。

强化学习在此有两条切入路线。路线一是把每个节点建模为一个智能体，共享需求信息或向集中式评论家开放全局观测，让策略在训练中学会近似协调；路线二是学习契约参数或补偿机制，让分散主体的自利行为自动导向系统目标，这与第 048 章的价格机制同源。两条路线互补：前者输出操作策略，后者输出协调规则。评估必须同时报告各节点成本与系统总成本，否则“把成本转移给上下游”会被误判为改进。

核心原理

本章原理分四层：库存动力学、报童与（s, S）策略、牛鞭效应、以及契约协调。

1. 库存动力学与提前期管道

库存随订货到货与需求消耗变化，提前期使订货与到货之间存在延迟。

Ii,t+1 = Ii,t + Qi,t−Li − min( Di,t , Ii,t + Qi,t−Li ) ， on-orderi,t = Σk=1Li Qi,t−k I 为库存；Q 为订货量；D 为需求；Li 为节点 i 的提前期；on-order 为在途订货总量；到货即时计入可用库存，min 表示发货量不超过手持库存与当期到货之和

在途量是关键状态：决策者必须知道“已订未到”的总量，否则会重复订货或误判缺货风险。库存位置（inventory position）定义为现有库存加在途量减缺货积压，它是订货决策的充分统计量。需求未被满足的部分有两种处理：丢失销售（lost sales）或延期交货（backorder），前者使需求不可恢复，后者形成负库存。两种处理对策略的影响不同，实现必须在环境接口中明确声明，训练与评估保持一致。多级链条中下游的订货即上游的需求，耦合由此逐级传递。

2. 报童模型与（s, S）策略

单期最优订货量由缺货成本与持货成本的比值决定。

P( D ≤ Q* ) = cu / ( cu + co ) ， 服务水平 = 临界分位数 D 为随机需求；Q* 为最优订货量；cu 为单位缺货成本（利润损失加信誉损失）；co 为单位持货成本；临界分位数即目标服务水平

该式的含义是：订货量应使需求不超过它的概率等于缺货成本的相对占比。缺货成本相对持货成本越高，服务水平越高。报童模型是最优 (s, S) 策略的单期退化，多期情形下订货策略的形状为：库存位置降至再订货点 s 以下时订货至目标水平 S，订货量等于 S 减去当前库存位置；若需求分布与提前期稳定，s 由服务水平反解得到。学习策略只需在 (s, S) 的邻域内做微调，就能接近最优，因此把 (s, S) 作为对照基线与动作先验都可以显著加速训练。

3. 牛鞭效应的度量与成因

牛鞭效应用订货方差与需求方差的比值度量。

bullwhip = Var( Q ) / Var( D ) ， 若各级独立预测且提前期为正，则 bullwhip > 1 且随级数放大 Var(Q) 为某级订货序列的方差；Var(D) 为其面对的需求序列方差；比值大于一表示订货波动被放大

四个成因的机理各不相同。需求信号处理：每级用自己收到的订单估计需求，订单已含有上游的平滑与放大，二次估计使偏差累积。批量订货：固定订货批量的策略把连续需求聚集成脉冲，方差被放大。价格波动：折扣促销引发提前购买，需求潮汐化。短缺博弈：供应紧张时各级超订，紧缺缓解后订单骤减。对策与成因一一对应：共享终端需求数据（消除信号失真）、减小批量或采用高频订货（平滑脉冲）、稳定价格（消除提前购买）、按历史比例分配配额（消除超订动机）。

信息共享的收益可以用方差比与成本双指标度量：共享需求数据后，上游节点的预测误差下降，订货方差比随级数增长的速度显著放缓。实现上把终端需求作为观测的一部分下发给所有节点，或由集中式评论家在训练中向各级提供学习信号。需要注意信息共享不改变库存的成本结构，它减少的是不确定性带来的安全库存，收益随需求波动率上升而放大。

4. 契约协调

分散决策的无效性来自外部性，契约通过重新分配收益消除它。

回购契约：零售商利润 = 售价 · 销售 − 批发价 · 订货 + 回购价 · 退货 ， 可协调条件：回购价 = 单位缺货损失对应的机会成本 回购价指未售出商品的退回价格；收益共享契约的等价参数为零售商向供应商的转移支付比例

契约协调的目标是让分散主体的订货量等于集中最优量。回购契约给零售商提供下行保护，使其临界分位数上升至系统水平；收益共享契约把零售收入按比例转移给上游，直接消除双重边际化。契约参数存在一个可协调区间，区间内的分配比例由谈判决定，这与第 056 章议价结构衔接。学习型方法可以搜索契约参数，奖励为系统总利润，约束为主体参与约束（各节点利润不低于分散基准），构成一个带约束的优化问题，处理方式与第 057 章的拉格朗日法一致。

5. 多智能体建模与评估

每个节点是一个智能体，观测与奖励需要覆盖链条上下游信息。

oi = [ Ii , on-orderi , 最近订单 , { Dterminal（共享） } , 上游到货计划 , t ] 终端需求共享项为可选信息；上游到货计划使节点了解供应能力，抑制短缺博弈

奖励设计的主体是利润：收入减采购、持货、缺货与固定订货成本。只给本地利润时，训练会重新制造牛鞭效应，需要额外处理：或在奖励中加入价格与分配的协调项，或把终端需求放入观测并让集中式评论家承担协调学习的压力。评估指标包含系统总成本、各节点利润、服务水平（满足率）与牛鞭比四项，四者联合判读：服务水平与总成本同向改善才是真正的改进。

实现思路与设计

实现采用四级链（供应商、制造商、分销商、零售商）的轻量模型，需求为带季节性的随机过程，提前期固定。

1. 环境循环

每步：终端需求到达零售商；各级按策略订单并沿链上传（下游订单即上游需求）；到货按提前期管道结算；更新库存与成本；返回观测。回合长度为 200 步，覆盖数个季节周期。信息共享开关控制终端需求是否下发给全部节点，作为对照实验。

3. 网络结构与训练要点

各级智能体共享参数（同质化单位）或按级分组共享，观测维度随级数统一设计。训练使用集中式评论家读取全链状态，执行期各节点只看本地下游信息与可选共享数据。动作空间为离散订货量档位（例如 0 至 60 按 5 递增），与批量订货的现实对应，也便于与 (s, S) 基线对比。评估报告四项指标并按信息共享开关分组；训练曲线中牛鞭比与总成本的分离程度是协调质量的核心证据。

4. 与第 058 章的差异点

金融交易处理连续报价与资产价格，风险来自市场波动与对手适应；供应链处理离散订货与实物库存，风险来自需求不确定与链条协调。金融市场的耦合是瞬时的（成交即影响价格），供应链的耦合带长延迟（提前期），延迟使信用分配跨越更多时间步。两章共享的评估纪律是分层与对照：金融按制度窗口分层，供应链按信息共享开关分组；两者都要求总指标与分项指标同时呈现。

关键代码与解读

三段代码分别实现提前期管道与库存更新、报童临界分位数与（s, S）基线、以及牛鞭比度量。

片段 1：提前期管道与库存更新

import numpy as np

class Echelon:
    """单级库存：现有库存、在途管道与缺货积压。"""
    def __init__(self, lead_time=2, init_inv=40.0):
        self.L = lead_time
        self.inv = init_inv
        self.pipeline = [0.0] * lead_time      # 按提前期分槽的在途量
        self.backlog = 0.0                     # 延期交货累积

    def step(self, demand, order):
        # 到货：管道头部进入库存，新订单进入尾部
        arrived = self.pipeline.pop(0)
        self.inv += arrived
        self.pipeline.append(order)
        # 先满足积压，再满足当期需求；不足部分形成新增积压
        need = self.backlog + demand
        served = min(self.inv, need)
        self.inv -= served
        self.backlog = need - served
        # 库存位置是订够判据：现货加在途减积压
        return self.inv, sum(self.pipeline) - self.backlog

解读：管道用定长列表模拟提前期，头部出队即到货，尾部入队即新订，长度恒等于 L 保证延迟正确。积压先于新需求被满足，符合延期交货的语义；若改为丢失销售，只需把 backlog 置零并统计未满足量，两种语义在奖励中的成本口径不同。库存位置返回给上层决策，它是订货决策的充分统计量，观测中必须包含。实现注意列表操作的顺序：先到货再加入新订单，若颠倒会出现提前期为 L 减一的系统性错误，这类偏差在长时间训练中会稳定存在且难以通过调参掩盖。

片段 2：报童临界分位数与（s, S）策略

def critical_fractile(c_u, c_o):
    """报童临界分位数：目标服务水平。"""
    return c_u / (c_u + c_o)

def newsvendor_qty(demand_samples, c_u, c_o):
    """按经验分布求最优订货量：取对应分位数的需求值。"""
    q = critical_fractile(c_u, c_o)
    return float(np.quantile(np.asarray(demand_samples), q))

def sS_policy(inv_pos, s, S):
    """（s, S）策略：库存位置低于 s 时订货至 S，否则不订。"""
    if inv_pos <= s:
        return max(0.0, S - inv_pos)          # 订货量补足至目标水平
    return 0.0

def s_from_service(demand_samples, lead_time, service):
    """由服务水平与提前期需求分布反解再订货点。"""
    # 提前期需求约为单期需求的 lead_time 倍，方差按独立同分布叠加
    lead = np.asarray(demand_samples) * lead_time
    return float(np.quantile(lead, service))

解读：临界分位数由缺货与持货成本的比值决定，两个成本参数的相对大小直接改变服务水平，是奖励设计中最敏感的参数之一。经验分位数代替理论分布假设，训练数据不足时估计偏差大，样本量应与服务水平的分辨率匹配。再订货点由提前期需求分布的分位数给出，独立同分布假设下均值与方差按提前期缩放；若需求存在自相关，该近似偏乐观，再订货点需要上调。三条函数构成完整的启发式基线，用于对照学习策略的输出并诊断偏差来源。

片段 3：牛鞭比与服务水平度量

def bullwhip_ratio(orders, demands, eps=1e-9):
    """牛鞭比：订货方差与需求方差的比值，按序列整体统计。"""
    o = np.asarray(orders, dtype=float)
    d = np.asarray(demands, dtype=float)
    # 使用无偏方差；需求方差接近零时用 eps 兜底
    return float(o.var() / (d.var() + eps))

def fill_rate(served_series, demand_series):
    """满足率：累计已满足需求与累计需求的比值。"""
    s = np.asarray(served_series, dtype=float).sum()
    d = np.asarray(demand_series, dtype=float).sum()
    return float(s / (d + 1e-9))

def diagnostic_panel(log):
    """按级汇总诊断：各级牛鞭比、满足率与平均库存。"""
    rows = []
    for lvl in log["levels"]:
        rows.append({
            "level": lvl["id"],
            "bullwhip": bullwhip_ratio(lvl["orders"], lvl["demand"]),
            "fill": fill_rate(lvl["served"], lvl["demand"]),
            "avg_inv": float(np.mean(lvl["inv"])),
        })
    return rows

解读：牛鞭比按整段序列计算，短窗口统计会因方差估计噪声而失真，评估窗口需要覆盖多个需求周期。满足率对缺货量敏感，与平均库存一起构成“成本与服务的两条曲线”：两者同时改善才是真改进，平均库存下降而满足率下降只是把成本转移给了客户。诊断面板按级输出，可以直接定位放大发生在哪一级：前段级的比值通常接近一，越靠近上游越高，这一形状是牛鞭效应的直接证据。三个函数都不依赖训练框架，可以接入任意策略的评估流程。

常见坑

  • 在途量丢失或重复计数：管道实现顺序错误，订单或货物被重复计入，库存长期偏高或偏低。症状是训练不收敛且成本曲线与理论严重偏离。修复：对管道的入队与出队写单元测试，核对任意时刻的订货总量守恒。
  • 只优化本地成本：奖励仅含本地持货与缺货成本，各级把库存与风险推给上下游，牛鞭比随级数放大。修复：共享终端需求、加入协调项或使用全链集中式评论家，评估报告各级指标。
  • 需求过程与评估不匹配：训练使用平稳需求，评估加入季节性后策略失效。修复：训练分布覆盖季节性与波动率变化，评估按需求制度分组。
  • 缺货语义不一致：训练按延期交货、评估按丢失销售，未满足需求的处理不同导致成本口径混乱。修复：接口显式声明语义，训练与评估使用同一实现。
  • 服务水平指标被均值掩盖：平均满足率可观但尾部缺货严重。修复：同时报告满足率的分布（分位数）与最大缺货时长，避免平均值掩盖极端事件。

    两级各自加价使零售商的边际成本高于系统的边际成本，最优订货量偏低。回购价相当于降低零售商的过剩成本，把其临界分位数提升到系统水平，参数区间由双方利润不低于分散基准确定。
  3. 改参数并预测：把固定订货成本从 2 提高到 10，预测订货频率、牛鞭比与平均库存的变化方向。★★
    提示
    订货成本上升后订货频率下降、批量增大，牛鞭比上升、平均库存上升。该实验可用于验证“批量订货是牛鞭效应成因之一”的论断。
  4. 设计题：为短缺博弈设计配额规则，说明规则如何抑制超订动机，并给出评估该规则效果的指标。★★★
    提示
    按历史采购比例分配配额，使超订不带来额外份额，直接消除博弈收益。评估指标包括订货虚高程度（订单与真实需求的比值）与紧缺期的分配偏差。
  5. 实验设计：对比“无信息共享”“共享终端需求”“共享需求并通过集中评论家训练”三种配置，设计控制变量与指标，说明信息共享收益的来源。★★★
    提示
    固定需求过程、提前期与成本参数，报告各级牛鞭比、总成本与平均库存。收益来源是预测误差下降与安全库存减少，可通过各级需求预测误差的变化分量佐证。

小结

  • 多级库存的递推包含提前期管道，在途量与积压共同构成库存位置，是订货决策的充分统计量。
  • 报童模型的临界分位数等于缺货成本占比，给出服务水平与订货量的权衡；（s, S）策略是该结构在多期的自然延伸。
  • 牛鞭效应用方差比度量，四个成因分别是需求信号处理、批量订货、价格波动与短缺博弈，对策与成因一一对应。
  • 分散决策造成双重边际化，回购与收益共享契约通过调整收益分配把订货量拉回系统最优，参数区间受参与约束限制。
