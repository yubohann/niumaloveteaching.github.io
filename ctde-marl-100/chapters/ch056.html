第三篇 · 环境与任务实践

第 056 章：多智能体对话系统

对话系统把语言当作动作：智能体在信息不对称下用离散消息协调行动；本章推导离散通信的梯度估计方法，说明协议崩塌与冗余编码的成因，并给出谈判类对话的议价结构。

  • 主题：通信学习 / 语言动作空间
  • 关键公式：∇θ J ≈ E [ Σt ∇θ log πθ( mt | · ) · ( Gt − bt ) ]
  • 预计学时：65 分钟
  • 前置章节：第 055 章 多智能体推荐系统

学习目标

读完本章，应当能够把对话建模为带私有信息的通信决策问题，并为离散消息设计可训练的梯度通路。

  • 理解信息不对称下的协作对话结构：说话者与听者的私有观测、消息信道与联合任务回报。
  • 掌握离散消息的梯度估计方法：策略梯度、Gumbel 软化与直通估计（straight-through estimator）的取舍。
  • 理解协议崩塌与熵塌缩的成因，会用语料熵与互信息度量通信信道的信息量。
  • 掌握谈判类对话的议价结构：效用函数、让步策略与截止时间如何决定均衡。
  • 会设计通信代价与任务奖励的组合，并评估协议的可解释性与对新搭档的泛化。

背景与动机

语言在多智能体系统中是一种动作，它有成本、有延迟、也可以失效。

许多协作任务的信息分布天然不均匀：一方看到目标，另一方看到候选；一方知道库存，另一方知道需求。若没有通信，掌握信息的一方只能通过物理动作隐式传递信息，效率低且难以泛化。图灵完备意义上的语言学习属于开放问题，工程上可行的是受限协议学习：给定固定词表、固定长度的消息，让智能体在任务回报的驱动下学会一套自用的编码。这类协议在指代游戏（referential game）等基准上能稳定涌现，词汇表会收敛到一致的映射关系。

对话系统在课程中的位置介于通信机制与语言生成之间。第 016 章的图神经网络通信、第 017 章的信道受限通信学习的是连续向量的传递；本章处理离散符号的选择，梯度无法直接穿透采样操作，需要专门的估计技术。谈判类对话进一步引入利益结构：双方目标部分冲突，让步节奏与威胁可信度决定收益分配。这些技术在第 085 至 090 章的通信学习与协商机制中会以更抽象的形式复现。

核心原理

本章原理分四层：信息不对称的建模、离散梯度估计、协议的形成与度量、以及谈判对话的议价结构。

1. 信息不对称与通信动作

协作对话可以写成一个带消息通道的联合决策问题。

ai,t = ( mi,t, ui,t ) ， mi,t ∈ V = { 1, …, K } ， ui,t ∈ U ai,t 为智能体 i 在 t 步的动作；m 为消息（取值于词表 V，大小 K）；u 为物理动作；私有观测 oi 不同，接收到的消息向量为各邻居消息的拼接

消息与物理动作共享同一个策略网络，网络需要学习“何时说、说什么、做什么”。与纯动作任务相比，信用分配多了一层：一句话的价值取决于听者后续的动作，回报延迟跨多个时间步，而且消息的因果效应依赖搭档的解读方式。训练上通常把消息通道纳入观测的一部分，记录发送日志（谁在何时说了什么），以便对消息的影响做归因分析。若任务允许广播，消息对所有邻居可见；点对点通道则需要指定接收者，动作空间包含地址选择，学习难度上升。

2. 离散消息的梯度估计

词表上的采样操作不可微，梯度需要经由估计器传递。

策略梯度：∇θ J ≈ ( 1 / N ) Σn Σt ∇θ log πθ( mt | · ) · ( Gt − bt ) ， Gumbel 软化：m̃ = softmax( ( log π + g ) / τ ) Gt 为 t 步后的折扣回报；bt 为基线（常用共享价值网络）；g 为 Gumbel 噪声；τ 为温度，趋近零时软化分布收敛到离散采样

策略梯度对离散动作无偏，但方差随消息长度与词表增大而上升，基线的作用是降低方差。Gumbel 软化用带噪声的软采样近似离散选择，梯度可以经由 softmax 回传，温度从高到低退火，使训练早期平滑、后期接近离散。直通估计在前向传播时用离散值、反向传播时用软值近似梯度，实现简单且在实践中常用；其梯度是有偏的，偏置程度与软化的锐度相关，训练日志中应观察词表分布的收敛情况加以验证。若消息既要写入连续控制回路（例如坐标值），可用“离散量化加软化”的组合，把连续信息编码为词表上的分布。

3. 协议的形成、崩塌与度量

通信协议是训练中涌现的共享编码，其质量用信息量度量。

H( M ) = − Σk P( m = k ) log P( m = k ) ， I( M ; O ) = H( M ) − H( M | O ) H(M) 为消息的边缘熵，度量词表使用的分散程度；H(M | O) 为给定私有观测后的条件熵；互信息 I 度量消息携带的信息量

协议崩塌指所有输入映射到同一条消息：此时 H(M) ≈ 0，互信息为零，消息不携带任何信息。崩塌的常见诱因有三：任务太容易（无需通信即可完成）、词表过小（分辨率不足）、熵正则权重为负或通信成本过高（说话代价大于收益）。度量协议质量需要同时报告 H(M) 与互信息：熵高但互信息低说明消息随机，熵低但互信息高说明编码高效。指代游戏中的组成性（compositionality）是进一步目标：属性组合对应消息结构，模型需要在新组合上泛化，评估集必须包含训练中未出现的组合。

噪声信道下的冗余编码会自发涌现：给定一定概率的消息翻转，能完成任务的协议往往对单个符号错误不敏感，这属于语言系统内生鲁棒性的体现。实现上把信道噪声建模为按概率替换符号，训练与评估使用不同噪声率可以检验鲁棒程度。

4. 谈判对话与议价结构

谈判任务的双方利益部分冲突，让步节奏决定分配结果。

Ui( x , t ) = ( 1 − δit ) · ui( x ) ， 交替出价均衡：x* 使双方在最后一轮出价下互为最优反应 x 为协议点（例如价格与数量的组合）；t 为轮次；δi ∈ (0, 1) 为贴现因子，度量等待成本；ui 为协议点对 i 的效用

交替出价模型的均衡表明：贴现因子越大（越有耐心）的一方分得越多；截止时间临近时出价快速向对方的接受边界靠拢。学习型谈判智能体通过自博弈逼近均衡，训练中观察到的行为与理论一致：耐心方坚持、急躁方让步。对话层与议价层的耦合是技术难点：语言既承担信息交换（“我的成本是……”），也承担承诺与威胁（“低于该价格我不出售”），承诺的可信度由后续行为检验。可解释性要求高的场景（例如交易合规审查）需要把议价动作从自由文本中分离出来，用结构化出价加模板化措辞的组合，本章的实现采用结构化出价。

5. 搭档泛化与人群训练

协议只在训练过的搭档之间有效，泛化需要人群化训练与评估。

自博弈训练出的协议会过拟合到自身策略，具体表现为：对训练搭档的协调率高，换新搭档后骤降。缓解手段有通道共享（双方共享词表定义） 与人群训练（维护若干历史检查点作为搭档），评估协议泛化能力的方法是对每个检查点测协调率。零样本协调（zero-shot coordination）是更严格的设定：评估搭档是本智能体从未见过的新策略，要求协议具有人类或独立训练者可理解的性质。该目标催生了“临时共识”类方法，思路是在训练中弱化搭档特异性表征，让策略依赖更一般的约定（例如排序约定：按距离或按编号），本章不展开算法细节，但评估集必须包含未见过搭档这一要求是通用的。

实现思路与设计

实现包含两个任务：指代游戏用于协议学习，结构化议价用于谈判对话；两者共享消息编码器与训练循环。

1. 环境循环

每回合开始采样场景（目标物体与候选集合），智能体各获得私有观测。每个时间步双方同时发送消息并接收；回合末进行指认或出价，环境结算任务奖励与通信代价并终止。消息长度固定为 2 个符号，词表大小 8，噪声率按课程从零缓升。议价任务中双方交替出价，时限 8 轮，超时按当前最优方案或未达成结算。

3. 网络结构与训练要点

消息编码器为小词表嵌入加线性输出，物理动作头与消息头共享主干。训练使用策略梯度加共享基线（价值网络输入为全局状态，与 CTDE 结构一致），消息与动作的梯度都经由同一回报，熵正则加在消息分布上。为缓解协议过拟合，训练时从历史检查点池采样搭档，池更新频率与评估挂钩。评估报告协调率、语料熵、互信息与噪声鲁棒曲线四项，任一项异常都需要先修复再继续训练。

4. 与第 055 章的差异点

推荐系统的动作是选择物品，反馈来自用户行为，偏差来自数据生成过程；对话系统的动作包含符号生成，反馈来自任务完成，难点在梯度通路与协议形成。推荐系统的探索针对物品的未知偏好，对话系统的探索针对编码约定，两者都需要人群或多样化机制防止过拟合。两者共享的评估原则是分层报告：推荐按物品年龄分组，对话按搭档类型分组。

关键代码与解读

三段代码分别实现离散消息采样、指代游戏结算与协议度量。

片段 1：离散消息的直通采样

import torch
import torch.nn.functional as F

def sample_message(logits, tau=1.0, hard=True):
    """Gumbel 软化采样：前向离散、反向软梯度（直通估计）。"""
    # 加 Gumbel 噪声后 softmax，等价于对离散分布采样
    g = -torch.log(-torch.log(torch.rand_like(logits) + 1e-9) + 1e-9)
    soft = F.softmax((logits + g) / tau, dim=-1)
    if not hard:
        return soft, logits
    # 直通：前向取 one-hot，反向用软分布的梯度
    idx = soft.argmax(dim=-1, keepdim=True)
    hard_onehot = torch.zeros_like(soft).scatter_(-1, idx, 1.0)
    straight = hard_onehot - soft.detach() + soft
    return straight, logits

def message_entropy(logits):
    """词表分布的平均熵：监控协议是否发生崩塌。"""
    p = F.softmax(logits, dim=-1)
    return float((-(p * torch.log(p + 1e-9)).sum(dim=-1)).mean())

解读：Gumbel 噪声通过双重对数变换从均匀分布构造，与 softmax 结合后等价于从类别分布采样，这一性质是软化方法的基础。直通技巧中 `hard_onehot - soft.detach() + soft` 的写法保证前向值等于离散结果（`soft` 项被抵消），反向梯度等于软分布的梯度（`detach()` 阻断离散项的梯度）。温度 τ 在训练中退火，早期软梯度平滑、后期接近真实离散选择。熵监控函数接入训练日志，熵曲线贴近零时需要检查通信代价与熵正则权重。

片段 2：指代游戏与奖励结算

def referential_episode(scene, messages, guess_idx, comm_penalty=0.05):
    """指代游戏：说话者看到目标，听者在候选中指认。"""
    target, candidates = scene["target"], scene["candidates"]
    # 听者的选择命中目标即协调成功，奖励为 1，否则 0
    success = float(guess_idx == target)
    # 通信代价按消息符号数计费：抑制无信息的长消息
    cost = comm_penalty * sum(len(m) for m in messages)
    reward = success - cost
    info = {"success": success, "n_symbols": sum(len(m) for m in messages)}
    return reward, info

def channel_mutual_information(msg_log, obs_log, k=8):
    """近似互信息：边缘熵减条件熵，用于度量信道信息量。"""
    m = np.asarray(msg_log)
    o = np.asarray(obs_log)
    def ent(x):
        p = np.bincount(x, minlength=k) / len(x)
        p = p[p > 0]
        return float(-(p * np.log(p)).sum())
    # 条件熵按观测分组求熵再加权平均
    cond = 0.0
    for val in np.unique(o):
        idx = o == val
        cond += ent(m[idx]) * idx.mean()
    return ent(m) - cond

解读：奖励把协调成功与通信代价合并，两个分项在信息字典中保留，便于判断策略是否用冗余消息换取稳定收益。互信息计算先求消息的边缘熵，再按观测分组求条件熵的加权平均，差值即互信息。实现中需要保证观测的取值离散化（连续观测会退化为经验估计），日志长度不足时估计偏差大，评估时应固定样本量。该项指标与协调率联合解读：协调率高但互信息接近零说明任务无需通信，协议并未真正形成。

片段 3：议价对话的出价与让步

def bargaining_step(t, t_max, own_value, other_cost_hint, delta=0.95,
                   concession_rate=0.5):
    """结构化议价：按剩余时间让步，出价从己方最优点向折中点靠拢。"""
    # 己方最优点为最高可接受价格，折中点为双方边界的中间
    best = own_value
    mid = 0.5 * (own_value + other_cost_hint)
    # 剩余时间越少让步越大：由幂函数控制的让步曲线
    progress = (t / t_max) ** (1.0 / max(1e-6, concession_rate))
    offer = best - (best - mid) * progress
    # 等待成本贴现：评估当前成交相对立即成交的效用
    u_offer = (1 - delta ** t) * (own_value - offer)
    # 接受判据：对方出价不差于己方下一轮的心理价位
    info = {"offer": offer, "discounted_utility": u_offer, "t": t}
    return float(offer), info

解读：让步曲线由时间的幂函数控制，参数 concession_rate 决定让步是前快后慢还是前慢后快，贴现因子则决定等待的代价。该结构把议价动作从自由文本中分离，策略网络只需在给定让步曲线族上选择参数或调整出价，训练目标明确且可解释。对方成本提示 other_cost_hint 来自对话中对方声称的信息，可信度由后续行为验证，这一“声称与行为不一致”的情形是谈判学习的难点，实践中可以用贝叶斯更新维护对方类型的估计。信息字典保留折扣后效用，便于分析成交时机相对耐心参数的关系。

常见坑

  • 协议崩塌：训练中期所有消息收敛到同一符号，协调率短暂上升后停滞。症状是语料熵趋近零且互信息为零。修复：提高熵正则权重、降低通信代价、或加难任务迫使通信必需。
  • 梯度方差过大：消息长度与词表增大后策略梯度噪声淹没信号，训练缓慢。修复：加强共享基线、减小词表或消息长度、采用软化梯度并退火温度。
  • 只评估训练搭档：协调率虚高，换搭档后失效。修复：维护历史检查点池并按搭档分层评估，报告最差搭档的协调率。
  • 信道噪声训练与评估不一致：训练无噪声、评估有噪声时符号错误被放大。修复：课程式引入噪声，评估固定多个噪声率绘制鲁棒曲线。
  • 把说话当作无成本动作：通信代价为零时策略发送冗余消息，信道拥塞且协议可解释性差。修复：施加按符号计费的代价，并在评估中报告平均消息长度。

    策略梯度无偏但方差大，直通估计方差小但有偏；温度高时软化接近真实分布的平滑版本，偏置小但梯度消失风险高，温度低时接近离散但方差回升，退火用于在两者间过渡。
  3. 改参数并预测：把通信代价从 0.05 提高到 0.5，预测协调率、平均消息长度与语料熵的变化方向，并判断是否可能触发崩塌。★★
    提示
    代价提高后消息变短、协调率下降，语料熵可能因使用单一符号而降低，存在崩塌风险。若任务必须依赖通信，崩塌会直接反映为协调率的大幅下降，可作为诊断依据。
  4. 设计题：为零样本协调设计评估方案，说明如何构造评估搭档以及判定协议泛化的指标。★★★
    提示
    评估搭档应包含独立训练的多个智能体与随机初始化的未训练策略；指标使用协调率的下界统计（最差搭档）与平均搭档数，避免平均掩盖失败模式。
  5. 实验设计：在议价任务中改变双方贴现因子，验证“更耐心一方分得更多”的结论，并给出与理论值的对照方法。★★★
    提示
    固定其他参数，扫描 δ 的组合并统计成交价格；理论值来自交替出价均衡解，比较时注意回合长度与出价精度的离散化误差，报告置信区间；单点估计会掩盖离散化误差带来的波动。

小结

  • 对话系统在信息不对称下用离散消息协调行动，消息与物理动作共享策略，信用分配跨越多步且依赖搭档解读。
  • 离散消息用策略梯度或软采样直通估计训练，熵正则防止协议崩塌，词表熵与互信息是协议质量的直接度量。
  • 协议只在训练过的搭档之间可靠，人群训练与零样本协调评估用于衡量泛化；噪声信道会催生冗余编码。
  • 谈判对话的让步节奏由贴现因子与截止时间决定，结构化出价提高可解释性，对方声称信息的可信度需要验证。
