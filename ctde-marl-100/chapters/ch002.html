第一篇 · CTDE 基础与核心算法

第 002 章：独立Q学习基线

让每个智能体各自跑一份 Q 学习，把其他智能体并入环境动态。这是成本最低的起点，也是暴露多智能体全部困难的一面镜子：非平稳目标、旧策略数据、相对过度泛化。学完本章，你能解释独立 Q 学习（Independent Q-Learning, IQL）何时够用、何时失效，并把它作为后续所有算法的对照下界。

  • 主题：独立学习基线 / 非平稳性分析
  • 关键公式：yi = r + γ (1 − done) · maxa′ Qtargeti(o′i, a′)
  • 预计学时：45 分钟
  • 前置章节：第 001 章

学习目标

  • 理解 IQL 的核心假设：把 (状态, 其他智能体动作) 的联合效应折叠进"环境动态"，每个智能体只优化自己的动作价值。
  • 掌握表格型与深度网络（Deep Q-Network, DQN）两种形式的 IQL 更新公式及其等价性。
  • 能说明非平稳性如何进入自举目标，以及经验回放缓冲区（replay buffer）中两类分布偏移的来源。
  • 能构造"相对过度泛化"（relative overgeneralization）的支付矩阵小例，解释紧耦合任务中 IQL 收敛到次优稳定点的机制。
  • 能实现一个可运行的 IQL 训练循环，并把它作为后续章节算法的性能对照。

背景与动机

第 001 章把协作任务写成了 Dec-POMDP。求解路线上最省力的想法是把 N 个智能体当成 N 个互不相干的学习者：每个智能体维护自己的 Q 表或 Q 网络，用标准单智能体 Q 学习更新，只是环境里恰好还有其他学习者。这就是独立 Q 学习（Independent Q-Learning, IQL），训练与执行完全分散，不需要任何全局信息通道。

IQL 的地位由两个事实共同决定。第一，它在若干基准任务上表现强得超出预期，例如某些需要与随机队友配合的顺序决策任务，独立学习者反而比使用全局信息的算法更稳健，这使 IQL 至今仍是论文中的必备基线。第二，它从原理上就是有缺陷的：每个智能体面对的环境包含其他正在变化的策略，平稳性假设不成立，收敛性没有保证。缺陷会在紧耦合协作任务中集中爆发，症状是收敛到"安全但平庸"的联合行为。因此本章的任务是讲清缺陷的机理，让后续每章算法的改进点都有明确的靶子。

核心原理

本节给出 IQL 的更新公式、非平稳性的进入方式、两类分布偏移，以及相对过度泛化这一典型失效模式。

1. 更新公式与"折叠假设"

把其他智能体的策略 π−i 视为环境的一部分后，智能体 i 面对的有效转移与有效奖励写为：

Pi(s′ | s, ai) = Σa−i π−i(a−i | s) · P(s′ | s, ai, a−i)， Ri(s, ai) = Σa−i π−i(a−i | s) · R(s, ai, a−i) 若 π−i 固定，上式就是标准 MDP，单智能体 Q 学习收敛；问题在于 π−i 随队友的更新持续漂移

表格型更新（在线一步）与深度网络版的经验回放目标分别为：

Qi(s, ai) ← Qi(s, ai) + α [ r + γ maxa′ Qi(s′, a′) − Qi(s, ai) ]
L(θi) = 𝔼(oi, ai, r, o′i, d) ∼ D [ ( r + γ (1 − d) maxa′ Qθ−i(o′i, a′) − Qθi(oi, ai) )² ] α 为学习率；θ− 为目标网络参数；d 为终止标志。注意目标值里的 max 只对本智能体的动作取，队友动作的影响被吞进 r 与 o′ 的随机性中

这个"吞进随机性"的动作是 IQL 全部优点的来源：执行期不需要任何队友信息，可扩展性最好。它也是全部缺点的来源：目标值 r + γ max Qi(o′i, ·) 的期望随队友策略变化，Qi 追踪的是一个持续漂移的目标。

2. 非平稳性与两类分布偏移

设队友策略在第 k 次更新前后为 πk−i 与 πk+1−i，则智能体 i 的有效转移分布变化幅度上界与策略变化幅度成正比：

‖Pik+1 − Pik‖1 ≤ maxs ‖πk+1−i(· | s) − πk−i(· | s)‖1 队友策略每变一点，有效环境就变一点；同频更新时两个漂移源互相放大。第 032 章将给出更细的漂移分解

第二个问题在经验回放中：缓冲区 D 里同时存放多个训练时期的数据，分布偏移有两个来源。其一是行为策略自身的 ε-greedy 探索率衰减，这属于单智能体也有的偏移；其二是队友策略的变化，同一（oi, ai）在训练早期和后期对应完全不同的回报分布。当队友从随机策略收敛到熟练策略时，早期数据对 Qi 目标的估计已经与现状无关，却仍被均匀采样。常见缓解手段是缩短缓冲区容量、优先采样近期数据，或对旧数据做重要性修正，第二篇第 023 章系统展开。

给漂移一个具体量级。协作位移任务处于状态 (4, 4)、智能体 1 选右移时，一步奖励由队友动作决定：队友也右移则双方到达获得 +1，队友停留或左移则获得 −0.01。队友策略从均匀随机（右移概率 1/3）收敛为确定右移（概率 1）的过程中，该状态动作对的一步期望奖励从 1/3 × 1 + 2/3 × (−0.01) ≈ 0.327 升到 1.000。同一个状态动作对，监督信号变了两倍以上，这是"目标持续漂移"在单个数据点上的直接体现。有效转移分布同样漂移：队友动作分布从均匀切换到确定性右移时，两个分布的 L1 距离为 |1/3 − 0| + |1/3 − 0| + |1/3 − 1| = 4/3，有效转移的漂移不超过该上界。

3. 相对过度泛化：紧耦合任务里的次优稳定点

孤立地看非平稳性，容易误以为"漂移但不影响最终解"。考虑一个两动作支付矩阵（智能体 1 选行，智能体 2 选列，条目为双方共享收益）：

收益矩阵队友选 A队友选 B
我选 A5−10
我选 B−100

联合最优是 (A, A)，收益 5，需要双方同时冒险配合。独立学习者更新时，若队友暂时以较高概率选 B，则 Qi(A) 被 −10 拉低而 Qi(B) 稳定在 0 附近，贪心策略切换为 B；双方同时切换后 (B, B) 收益 0 成为自我强化的稳定点。这个现象称为相对过度泛化（relative overgeneralization）：独立最大化把队友的非最优行为当作环境的固有属性，策略因此偏好"对任何队友都不差"的安全动作，放弃需要配合的高收益动作。第 006 至 009 章的值分解与反事实方法，正是为了在保留分散执行的同时避免个体视角下的过度悲观。

4. 数值算例：双稳定点的完整计算与缓解手段

用第 3 小节的支付矩阵做完整计算。设队友在近期数据中选 A 的经验频率为 p，我的两个动作的期望收益为：

E[Qi(A)] = 5p − 10(1 − p) = 15p − 10，E[Qi(B)] = −10p + 0 × (1 − p) = −10p 两式相等给出切换边界：15p − 10 = −10p，解得 p* = 10 / 25 = 0.4

在边界两侧各取一档核对：p = 0.5 时 E(A) = −2.5、E(B) = −5.0，选 A；p = 0.4 时两者同为 −4.0，位于边界；p = 0.3 时 E(A) = −5.5 低于 E(B) = −3.0，改选 B。队友选 A 的经验频率一旦跌破 0.4，双方的最优反应同时翻转为 B；翻转后队友选 A 的频率继续下滑，(B, B) 以收益 0 自我印证，锁定为稳定点。对称地 p 升过 0.4 后系统向 (A, A) 收敛，最终停在哪个点由训练路径决定，这种路径依赖是非平稳自举的宏观后果。两个稳定点的收益差给出直接代价：最优协调 (A, A) 每步 5，次优稳定点 (B, B) 每步 0，错配组合每步 −10。避开错配相对 (B, B) 增收 10，追求协调相对 (B, B) 只增收 5，独立最大化的风险规避取向在数值上完全理性，却使团队停在次优稳定点。作为对照，双方各以 1/2 概率随机选择时，四种组合的联合期望收益为 (5 − 10 − 10 + 0) / 4 = −3.75，低于两个稳定点的任意一个，说明探索行为本身在训练早期持续压低观测到的收益，这正是学习过程中 p 反复穿越 0.4 边界的外部条件。

针对这类失配，IQL 之上有三类常见修补，作用机理与局限各不相同：

手段机制代价与局限
宽松更新（lenient Q-learning）对负的时间差分误差按时间折扣弱化，淡忘队友早期的不佳表现环境本身的真实惩罚同时被弱化，收敛后可能高估危险动作
滞迟更新（hysteretic Q-learning）正误差用较大学习率、负误差用较小学习率，注入乐观偏置乐观偏置在惩罚密集任务中放大高估，Q 值可长期高于真实回报
交替训练（alternating training）轮流冻结一方策略若干步再交换，使另一方在窗口内面对平稳目标单向样本效率减半，冻结期工况与双方同频更新的最终工况仍有分布差

三者都只缓解症状，不改变"独立最大化把队友行为当作环境常数"的根本假设，因此后续章节转向训练期引入全局信息的路线。

5. IQL 在 CTDE 体系中的位置

按训练期与执行期的信息使用方式划分，IQL 属于"分散训练、分散执行"（Decentralized Training with Decentralized Execution, DTDE）：训练期不用全局状态、不用队友动作，成本最低。CTDE 体系在其上逐级增加训练期信息：第 003 章引入集中式评论家，第 006 至 008 章引入联合价值分解。IQL 的工程价值在于它提供了每条改进路线的对照下界，任何新算法若在 IQL 已能解决的任务上表现更差，说明实现或假设存在问题。

实现思路与设计

本节给出 IQL 的最小实现结构：每智能体一套 Q 网络与目标网络，共享一份联合转移回放缓冲区，独立更新。

设计项取值（基线）作用与依据
Q 网络结构2 层 MLP，隐藏层 64，ReLU观测维度 2 的低维任务，深层网络收益为零
学习率5e-4（Adam）多智能体同步更新误差叠加，取单智能体常用值偏小一侧
折扣因子 γ0.95与第 001 章环境一致
回放缓冲区5×104 条联合转移容量刻意取小：队友策略漂移使旧数据迅速失效
批大小64小批量下梯度噪声可作为隐式正则
ε 衰减1.0 线性降至 0.05，2×104 环境步内完成多智能体任务里探索不足会被锁定在次优协调，衰减不宜过慢
目标网络更新每 200 步硬拷贝漂移环境下目标网络缓冲带作用有限，更新周期取常见值

与第 001 章的衔接：环境接口完全不变；新增的是"训练循环"这一层。三个关键决策依次是：回放缓冲区按联合转移存储（每个智能体读取自己那一列切片）、每个智能体独立取最大值构造目标、更新顺序上不做任何协调。整个流程没有任何一行代码需要访问其他智能体的网络输出，这正是"独立"一词在实现层面的含义，也是后面对照实验的起点。

关键代码与解读

片段 1：每智能体一套 Q 网络

import torch
import torch.nn as nn

class QNet(nn.Module):
    """单智能体 Q 网络: 输入本地观测, 输出每个离散动作的 Q 值。"""
    def __init__(self, obs_dim, n_actions, hidden=64):
        super().__init__()
        # 低维观测下两层 MLP 足够; 网络深度不参与本章对照, 保持最小实现
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, n_actions),   # 每个动作对应一个标量输出
        )

    def forward(self, obs):
        # obs 形状 (B, obs_dim) -> 输出 (B, n_actions)
        return self.net(obs)

n_agents = 2
# "独立"的第一层含义: 每个智能体有自己的在线网络与目标网络
qs = [QNet(obs_dim=2, n_actions=3) for _ in range(n_agents)]
q_targets = [QNet(obs_dim=2, n_actions=3) for _ in range(n_agents)]
for i, qt in enumerate(q_targets):      # 目标网络初始参数逐智能体对齐其在线网络
    qt.load_state_dict(qs[i].state_dict())

解读：这里刻意让每个智能体持有独立参数。第 004 章会讨论参数共享，但本章保留不共享的原始形态，因为"独立"要义在于每个智能体的目标值与梯度互不干扰。目标网络的初始化必须逐智能体对齐其在线网络，若统一从 qs[0] 拷贝到所有目标网络看似无害，却会让两个智能体的初始目标值分布在偶发情况下产生不一致的初始偏置，破坏对照实验的中立法。

片段 2：一次独立更新

def iql_update(qs, q_targets, optimizers, batch, gamma=0.95):
    """从联合转移批次中为每个智能体做一次独立 Q 学习更新。"""
    obs, act, rew, nobs, done = batch      # 形状 (B, N, ·), 奖励为团队标量
    n_agents = obs.shape[1]
    for i in range(n_agents):
        with torch.no_grad():
            # 独立最大化: 只对本智能体的下一动作取 max, 队友动作不出现在计算里
            q_next = q_targets[i](nobs[:, i]).max(dim=1).values
            # 终止步必须截断自举, 否则终止后的"折扣尾巴"污染目标值
            y = rew[:, 0] + gamma * (1.0 - done[:, 0]) * q_next
        # gather 取出实际执行动作对应的 Q 值, 其余动作不参与本次损失
        q_pred = qs[i](obs[:, i]).gather(1, act[:, i:i + 1]).squeeze(1)
        loss = ((q_pred - y) ** 2).mean()  # 团队奖励直接充当每个智能体的监督信号
        optimizers[i].zero_grad()
        loss.backward()
        optimizers[i].step()               # 更新只触及智能体 i 的参数

解读：三处写法各有原因。（1）用团队标量奖励 rew[:, 0] 直接构造每个智能体的目标，这是 IQL 对信用分配问题的默认回答：每个智能体都学"在队友当前行为分布下的动作价值"，Qi 隐含了队友贡献而不显式拆分。（2）gather 只取执行动作的 Q 值，因为离策略更新只对"执行过的动作"有监督信号，其余动作靠同一网络在后续推理中被间接校正。（3）循环内每个智能体各自反向传播，梯度互不混杂；若把两个 Q 网络拼成一个批处理前向，务必确认每列输出只对其对应损失产生梯度，这是拼批实现中最容易出错的细节。

片段 3：独立探索与联合回放

import numpy as np

def eps_greedy_actions(qs, obs, eps, n_actions=3):
    """行为策略: 每个智能体独立执行 eps-greedy, 彼此不交换任何信息。"""
    actions = []
    for i, q in enumerate(qs):
        if np.random.rand() < eps:
            actions.append(int(np.random.randint(n_actions)))
        else:
            with torch.no_grad():
                qv = q(torch.as_tensor(obs[i], dtype=torch.float32).unsqueeze(0))
                actions.append(int(qv.argmax(dim=-1).item()))
    return actions

    # 存 (联合观测, 全局状态, 联合动作, 团队奖励, 终止标志):
    # 智能体 i 训练时取 [:, i] 切片, 集中式方法(后续章节)直接读全局字段

解读：eps_greedy_actions 展示执行期信息约束：每个智能体的决策函数只引用自己的 Q 网络与自己的观测，没有任何跨智能体数据流，这保证本章算法可以在完全无通信条件下部署。push 采用"单条联合转移、多方切片"的回放结构，是为后续章节做铺垫的设计：第 003 章的集中式评论家需要读取整条记录里的联合动作与全局状态，若此刻按智能体拆分存储，后面每引入一个集中式组件都要改动数据层。数据层一次设计到位，算法层才能逐章替换。

常见坑

  • 把收敛中的震荡当作调参失败。症状：曲线在若干水平间反复跳变后突然崩塌，改学习率只改变崩塌时刻。原因：队友策略漂移使旧数据失效，缓冲区跨时期混采。修复：先用"训练后期仅用近 104 步数据"的消融确认漂移贡献，再考虑缩小缓冲区或改用第 023 章的近期优先采样。
  • 目标网络与慢漂移叠加。症状：Q 值整体缓慢膨胀后崩溃。原因：目标网络更新周期过长，在线网络追逐过时目标，高估逐步累积。修复：缩短硬更新周期到数百步，或改用软更新（Polyak 平均），并检查日志中平均 Q 值与真实折扣回报的偏差。
  • done 掩码方向写反。症状：回合长度 60 步时性能轻微受损，长回合任务中严重高估。原因：y = r + γ·done·Q 与正确写法相反，终止后仍自举、非终止处被截断。修复：单元测试断言终止步目标值恰为 r。
  • 共享观测切片错列。症状：换智能体数量后性能骤降，或两个智能体表现高度不对称。原因：回放数据 (B, N, ·) 中列索引与网络实例的对应关系在重采样或打乱后错位。修复：固定"列 i 恒指智能体 i"，并在训练启动时用随机策略的数据做一次一致性检查。
  • 误判相对过度泛化。症状：IQL 稳定收敛到低回报的对称行为，加大探索率也无法脱离。原因：任务收益结构中协调动作伴随风险，独立最大化天然规避。修复：对照"集中式联合 Q 表格解"确认联合最优可达，再更换第 007 至 009 章的算法，避免在 IQL 上无效调参。

练习与思考

  1. 给定支付矩阵：我选 A / 队友选 A 得 5，我 A / 队友 B 得 −10，我 B / 队友 A 得 −10，我 B / 队友 B 得 0。设队友以概率 p 选 A，写出我选 A 与选 B 的期望收益，求 p 的临界值；若双方都按对方临界点切换，联合行为收敛到哪里？★
    提示
    期望收益：A 为 15p − 10，B 为 −10p。临界点 p* = 0.4。p < 0.4 时 B 占优，双方同时切换后 p 下降，(B, B) 自我强化成为稳定点，即相对过度泛化的落点。
  2. 把 ε 从"2×104 步线性降至 0.05"改为"恒定 0.3"，在协作位移任务上预测成功率与收敛速度的变化方向并解释。★
    提示
    恒定高探索使行为策略保持较高熵，回放数据的分布更接近均匀随机，收敛速度下降；同时探索维持了脱离次优协调的机会。预测：后期回报更低、方差更大，但触发相对过度泛化的概率略降。
  3. 设计一个实验测量非平稳性的强度：训练过程中每 500 步冻结所有网络，用固定批次数据评估每个 Q 网络的目标值 y 的均值与方差，绘制时间曲线。解释曲线在队友策略收敛前后形态的差异。★★
    提示
    目标值方差在队友策略快速变化期显著偏高，队友收敛后方差回落。该曲线是"漂移强度"的直接代理指标，可与第 032 章的漂移度量对照。
  4. 推导：假设队友策略 π−i 固定，证明 IQL 的更新收敛到在该固定队友策略下的最优 Q 函数（引用单智能体 Q 学习收敛条件即可）。再说明"固定队友策略"这一前提在多智能体同时训练时被破坏的环节。★★
    提示
    固定 π−i 时有效过程是标准 MDP，满足 Robbins-Monro 条件的学习率与有界奖励下 Q 学习收敛。破坏环节：每次队友更新后 Pi 变化，学习率对"环境漂移"没有衰减作用，收敛定理的前提失效。
  5. 设计对照实验：在协作位移任务（N = 2）上比较三种方案，随机联合策略、IQL、以及联合 Q 表格法（对 32 = 9 个联合动作做表格更新）。报告成功率与平均折扣回报，并给出 IQL 与联合 Q 表格解之间差距随 N 从 2 增至 4 的变化趋势预测。★★★
    提示
    联合 Q 表格法在小状态空间可枚举最优联合策略，作为上界参照。预期差距随 N 增大而扩大：联合动作数按 3N 增长，协调需求提高，独立视角的过度悲观加剧；同时联合 Q 表格法本身在 N = 4 时仍可运行（81 条动作），N = 5 后开始吃力。

小结

  • IQL 把队友策略折叠进环境动态，每个智能体做标准 Q 学习更新；执行期零通信，是成本最低的 DTDE 方案。
  • 非平稳性直接进入自举目标；回放缓冲区同时承受探索衰减与队友漂移两类分布偏移，旧数据价值快速衰减。
  • 相对过度泛化使紧耦合任务收敛到"安全但平庸"的稳定点，这是个体视角过度悲观的直接后果。
  • 数据层采用"单条联合转移、多方切片"结构，为第 003 章起的集中式组件预留接口。
  • 下一章进入 CTDE 的第一个完整框架：集中式训练分布式执行基础框架，用训练期的全局信息为漂移的目标值提供校准。
