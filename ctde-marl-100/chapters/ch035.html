第二篇 · 训练工程与稳定性

第 035 章：训练曲线诊断方法

本章讲训练曲线的系统化诊断：回报曲线与辅助指标（价值损失、解释方差、时序差分误差分位数、熵、梯度范数）的联读方法，常见故障的症状与成因对照，以及避免平滑掩盖、单种子误判等观测偏差。

  • 主题：实验观察 / 故障归因
  • 关键公式：解释方差 EV = 1 − Var(R − V) / Var(R)
  • 预计学时：50 分钟
  • 前置章节：第 034 章 混合合作竞争环境

学习目标

  • 理解回报曲线的观测偏差来源：平滑窗口、种子选择、横轴口径、评测协议，能规范地呈现曲线。
  • 掌握辅助指标组的分工：价值侧解释方差与时序差分误差、策略侧熵与裁剪比例、梯度侧范数与触发率、数据侧回合长度与覆盖。
  • 掌握"症状到成因"的对照分析与排查顺序，能对平台、发散、崩溃、振荡四类形态给出定位路径。
  • 能用规则化检查器把常见诊断逻辑固化为监控代码，并设计单变量消融验证诊断结论。
  • 能识别评估口径失真：训练奖励与原始回报换算、评测与训练分布不一致、曲线平均掩盖崩溃。

背景与动机

训练曲线是强化学习实验最直接的信息来源，也是最容易被误读的对象。多智能体训练叠加了三类干扰：曲线本身的种子方差较大，任何单条曲线都可能误导；训练中期的指标变化（价值损失下降、熵下降）不总意味着进步；课程、塑形、归一化等模块改变了奖励口径后，不同实验的回报数值不再直接可比。

诊断的任务是把"曲线形态"翻译成"系统状态"，再定位到具体模块。第 021 到 034 章建立的每个模块都留在训练日志里的痕迹：目标网络的滞后反映在价值损失平滑度上，探索调度反映在熵与动作分布上，归一化反映在奖励与价值尺度上。本章把这些痕迹组织成一套读图方法，为第 036 章的超参数敏感性分析与第 037 章的方差报告建立观测基础。

核心原理

1. 回报曲线的正确呈现

回报曲线的呈现遵循三条规范：保留种子级原始曲线，平滑只用于叠加展示；横轴采用环境步数并注明评测间隔；评测曲线与训练曲线分开绘制。平滑的常用形式是移动平均或指数平均：

指数平均：st = α·rt + (1 − α)·st−1，等效窗口约 1/α α = 0.05 时窗口约为 20 个评测点；窗口过长会把骤降抹平为缓降

平滑的用途是压制观测噪声，代价是引入相位延迟并压缩尖峰：一次持续数千步的性能崩塌在窗口 20 的平滑曲线上可能只表现为"轻微下探"。因此呈现规则是原始散点或细线加平滑粗线叠加，异常检测基于未平滑数据。多智能体实验的评测间隔通常取 1 万到 5 万环境步，评测曲线本身已经过回合平均，再叠加大窗口平滑属于双重压缩。

评测协议的固定项包括：评测环境实例与训练实例分离，评测难度与随机化档位在实验开始前冻结，评测回合数对全部配置一致。协议冻结后，两批实验的曲线差异才能全部归因到被比较的变量；第 036 章的配对设计在本章协议之上执行，两章合起来构成观测规范与实验规范的完整流程。

2. 辅助指标组

回报之外的指标按回答的问题分组，每组取一个代表量：

组别指标回答的问题
价值侧解释方差、时序差分误差中位数与 95 分位价值网络是否拟合当前回报分布；误差尾部是否失控
策略侧策略熵、新旧策略动作分布散度探索程度与策略更新幅度是否合理
梯度侧全局梯度范数、裁剪触发率优化步长是否受控（第 027 章）
数据侧回合长度、状态覆盖、受限动作占比任务进展是否真实；掩码与边界约束是否正常
环境侧课程阶段、漂移度量、对手池活跃度难度与对手分布是否按预期演进（第 022、032、033 章）

价值侧的核心诊断量是解释方差（Explained Variance）：

EV = 1 − Var(R − V) / Var(R) R 为折扣回报估计，V 为价值预测；EV 接近 1 表示拟合良好，接近 0 表示不如常数预测，负值表示系统性偏差

EV 提供两重信息：EV 高而回报不升说明价值拟合正常、瓶颈在策略侧；EV 低而回报上升说明价值网络滞后于策略改进，属于暂时性现象还是容量不足需要观察其趋势。时序差分误差只看均值会被大误差样本拉偏，报告 95 分位才能暴露尾部爆炸；多智能体场景中按智能体分组报告误差分位数，可以定位到具体角色。

指标的采样频率需要与训练节奏匹配：价值侧指标每个训练批次都可统计，策略侧与数据侧按评测间隔统计，环境侧按阶段统计。把高频指标降采样到评测频率再画图会损失批次级抖动，定位崩溃时又需要回看高频记录，因此记录器按指标分组保存不同粒度，展示层再统一重采样。

3. 四类形态与成因对照

把回报形态与辅助指标联读，形成对照表：

形态伴随特征常见成因定位手段
平台熵缓慢下降、EV 稳定偏高探索不足、表征不足、信用分配过平均提高探索或更换信用结构做消融
发散价值损失上升、误差分位数爆炸目标不稳定、学习率过高、裁剪失效检查目标网络与裁剪配置，降学习率复测
崩溃熵骤降、回报骤降后部分恢复策略更新步过大、目标追错（数据口径分裂）检查新旧策略散度与数据新鲜度
振荡回报周期性波动、漂移指标同步起伏非平稳过强、更新节奏失配检查队友漂移曲线与更新间隔（第 032 章）

排查顺序遵循"从外到内"：先确认评测协议与奖励口径没有变化，再确认数据管线（掩码、归一化、新鲜度）正常，最后才怀疑网络结构与优化配置。顺序颠倒会导致把口径问题误诊为算法问题，浪费大量复现成本。

以平台形态为例说明量化判断：回报在 50 附近波动、最近 5 个评测点的极差为 0.8，相对量级约 1.6%，低于 2% 的平台判据，同时 EV 稳定在 0.6 以上，检查器输出探索与信用结构的线索；若极差扩大到 3.0（6%）而 EV 仍处高位，形态更接近收敛但还有余量的状态，优先观察若干个评测点再决定是否做消融。判据的数值需要按任务回报量级重新标定，绝对阈值跨任务无效。

4. 常见观测偏差

  • 单种子误判。多智能体训练的种子间方差常与设定间的差异同量级，单曲线比较的结论不可靠；至少 5 个种子起步，配合第 037 章的聚合统计。
  • 横轴错配。按墙钟时间对齐会引入实现效率差异，按环境步对齐才反映样本效率；两者都要时分开绘图。两种实现效率相差一倍时，按墙钟对齐会把实现差异读成算法差异，样本效率的比较全部失真。
  • 口径混合。不同实验的奖励塑形、归一化、课程配置不同，回报数值不可直接比较；报告原始奖励换算值或统一评测口径。
  • 平滑掩盖。大窗口平滑把崩溃与恢复整段抹平，最终点看起来平滑收敛。

以上四类偏差的共同点是都可在训练启动前规避：把呈现规范、聚合规范与协议冻结写入实验清单，逐条确认后再开始正式运行。清单化的原因在于偏差一旦发生就无法从曲线反推，只能重跑实验；第 036 章的配对比较与第 037 章的方差报告都建立在这类事前纪律之上。

5. 数值算例：解释方差的分解与联读

用四个批次的回报与价值做一次完整计算。回报 R = (1, 2, 3, 4)，价值 V = (1.1, 1.9, 3.2, 3.8)。残差为 (−0.1, 0.1, −0.2, 0.2)，残差方差 (0.01 + 0.01 + 0.04 + 0.04)/4 = 0.025；回报方差 1.25；解释方差 EV = 1 − 0.025/1.25 = 0.98。这组数据中价值与回报的相关系数约 0.991，两项同时偏高属于健康拟合：残差没有系统性的符号分布，意味着价值既学到了排序，也校准了水平。

把 EV 改写成分解形式便于归因：EV = 2·(σV/σR)·ρ − (σV/σR)2，其中 ρ 为价值与回报的相关系数，σ 比值为幅度比。代入上例：幅度比约 0.949，ρ 约 0.991，EV ≈ 1.880 − 0.900 = 0.98，与直接计算一致。两个失效通道由此分离：幅度比偏离 1 说明价值尺度错位，ρ 偏低说明价值没有提取状态信息。推广一步：价值恰为回报的 a 倍时 EV = 2a − a2，a = 0.5 对应 0.75，a = 0.9 对应 0.99，常数预测（a = 0）对应 0。上报 EV 时附上幅度比与相关系数两个分量，曲线异常的归因从单点数字变成两维定位。

平滑的窗口换算同样可以核对：指数平滑系数 α = 0.05 的等效窗口约 1/α = 20 个评测点，窗口之外的数据仍保留 0.9520 ≈ 0.36 的权重，滞后量级约 (1 − α)/α ≈ 19 个点。评测间隔 2 万步时，19 个点对应 38 万环境步的相位延迟：崩溃发生与平滑曲线可辨认之间存在几十万步的滞后，事故定位必须回看未平滑的逐点数据。

联读顺序在数字上也有依据：先看 EV 与误差分位，再看熵与裁剪，最后看梯度范数。EV 与误差分位来自同一批评估数据、不依赖训练内部状态，最容易核查；熵与裁剪受超参数直接影响，需要先用价值侧排除数据口径问题再解读；梯度范数对批构成敏感，放在最后用于确认优化配置。这套顺序与第 036 章的敏感性实验衔接：筛查阶段用价值侧指标过滤无效运行，再对入选配置做参数扫描。

实现思路与设计

诊断系统的骨架是一个指标记录器加一个规则检查器。记录器在每个评测点收集指标并落盘为结构化记录，检查器按阈值规则输出提示，人工复核后进入消融。工具只提示不阻断训练，避免误报中断长实验。

参数默认值作用取值依据
评测间隔每 2 万环境步曲线采样密度覆盖策略更新周期的同时控制评测开销
评测回合数20 至 50降低评测噪声回合方差大时取上限
平滑窗口5 到 10 个评测点压制观测噪声小于崩溃恢复的特征时长，防止掩盖事故
EV 告警阈值连续 5 个点低于 0.3价值拟合异常提示结合任务回报方差标定
误差分位中位数 + 95 分位尾部监控尾部连续抬升早于均值恶化 1 到 2 个评测点
裁剪触发率告警超过 10%优化配置提示与第 027 章阈值标定共用同一口径

与第 034 章的衔接点：混合动机任务的指标记录增加逐智能体优势统计字段；检查器对个体回报分布的告警独立于团队回报曲线，两套告警交叉出现时优先排查奖励分层配置。

阈值的标定路径在实现上固定为两步：先在无故障的基线运行上统计各指标的均值与波动范围，把告警线放在基线波动之外；再人为注入两类故障（例如把学习率乘十、把熵系数置零），观察先行指标的出现顺序，据此给多指标告警排序。阈值随任务重新标定，跨任务沿用同一组数字会把总回报量级差异误读为故障。标定记录与曲线快照一并归档，后续误报复核时先对照这份记录。

关键代码与解读

片段 1：价值侧诊断指标计算

import torch

@torch.no_grad()
def value_diagnostics(values, returns):
    """计算解释方差与误差分位数：价值拟合质量的两类视角。"""
    values, returns = values.flatten(), returns.flatten()
    # EV 用总体方差口径：分子为残差方差，分母为回报方差
    err = returns - values
    ev = 1.0 - err.var(unbiased=False) / (returns.var(unbiased=False) + 1e-8)
    # 分位数比均值更能暴露尾部：少数批次的巨大误差被均值稀释
    q50 = err.abs().quantile(0.50).item()
    q95 = err.abs().quantile(0.95).item()
    # 回报与价值的相关系数作为补充：EV 为正但相关系数低说明仅在均值上对齐
    corr = torch.corrcoef(torch.stack([values, returns]))[0, 1].item()
    return {"explained_variance": ev.item(), "td_err_q50": q50, "td_err_q95": q95, "value_return_corr": corr}

解读：四个量各回答一个独立问题：EV 回答"比常数预测好多少"，分位数回答"误差尾部多危险"，相关系数回答"是否学到了状态相关性"。EV 与相关系数的组合能区分两类失败：EV 低且相关低（价值网络没有提取信息），EV 低但相关高（价值有信息但系统性偏移，常见于奖励口径分裂，对照第 023 章的下一观测存储问题）。该函数在评测批次上调用，开销极小。

片段 2：跨种子曲线的聚合与平滑

import numpy as np

def aggregate_curves(seed_curves, smooth_alpha=0.1):
    """输入 (n_seeds, n_points) 的评测矩阵，返回聚合统计。"""
    arr = np.asarray(seed_curves, dtype=np.float64)
    # 先做种子聚合再平滑：先平滑后平均会放大起始段的平均值偏置
    median = np.median(arr, axis=0)
    q25 = np.percentile(arr, 25, axis=0)
    q75 = np.percentile(arr, 75, axis=0)
    smooth = median.copy()
    for t in range(1, len(smooth)):
        # 指数平滑：窗口约 1/alpha，只用于展示，异常检测用原始曲线
        smooth[t] = smooth_alpha * median[t] + (1 - smooth_alpha) * smooth[t - 1]
    return {"raw_seeds": arr, "median": median, "q25": q25, "q75": q75, "smooth": smooth}

解读："先聚合后平滑"的选择避免了平滑的相位延迟在种子平均中被放大，返回字典保留原始种子矩阵，供后续方差分析与异常检测使用。中位数与四分位距替代均值与标准差：多智能体训练的成功/崩溃双峰分布下，中位数反映典型表现，四分位距反映稳定性，均值会被崩溃种子拖低。若任务需要报告均值，同时报告中位数并在两者差距大时注明分布形态。

片段 3：规则化症状检查器

def diagnose(history, window=5):
    """按规则做初步归因；输入为最近若干评测点的指标记录列表。"""
    recent = history[-window:]
    ret = [h["eval_return"] for h in recent]
    ev = [h["explained_variance"] for h in recent]
    ent = [h["entropy"] for h in recent]
    clip = [h["clip_fraction"] for h in recent]
    hints = []
    # 规则 1：回报平台 + EV 高位 → 价值无碍，优先怀疑探索与信用结构
    if max(ret) - min(ret) < 0.02 * abs(np.mean(ret)) and np.mean(ev) > 0.5:
        hints.append("回报平台且价值拟合良好：检查探索调度与信用分配")
    # 规则 2：熵骤降伴随回报下降 → 策略过早收敛
    if ent[-1] < 0.5 * ent[0] and ret[-1] < 0.9 * max(ret):
        hints.append("熵骤降且回报回落：探索塌缩，检查熵系数与温度")
    # 规则 3：裁剪触发率高 → 优化步长失控或阈值配置不当
    if np.mean(clip) > 0.1:
        hints.append("裁剪触发率偏高：复标裁剪阈值或下调学习率")
    return hints

解读：检查器把教科式的诊断逻辑固化为可复查的代码，输出的是"线索"，结论留给人工复核，每条提示都指向后续的消融方向。规则的阈值全部走配置，不同任务族分别标定；把检查结果与被检查的训练配置一同落盘，便于回溯误报。真实系统中该模块挂载在评测回调上，与曲线渲染共用数据，避免两处口径分裂。需要注意的是规则的组合关系：多条提示同时出现时优先排查数据管线与优化配置，再回到算法结构。

常见坑

  • 平滑的不当使用。大窗口平滑把崩溃与恢复整段抹平；基于平滑数据统计方差会低估波动。修复：平滑只用于展示层，异常检测与统计一律基于原始逐点评测。
  • 用训练奖励对比不同配置。塑形、归一化、课程改变奖励口径后数值不可比。修复：统一评测协议（固定难度、固定原始奖励口径）后再对比。
  • 单种子判定优劣。种子方差与配置差异同量级时结论随机。修复：多种子聚合，按第 037 章的报告规范执行。
  • 把 EV 暂时偏低当作故障。策略改进速度快于价值跟随时 EV 会短期走低，属于正常滞后。修复：观察趋势，避免以单点下结论，结合回报曲线判断。
  • 评测与训练分布不一致未标注。训练难度上评测的数值远高于目标难度。修复：评测协议在图表注释中显式声明（第 022 章）。

练习与思考

  1. 推导：当价值预测为常数 c 时，解释方差 EV 的取值；说明 EV = 0 与 EV < 0 分别对应什么拟合状态。★
    提示
    常数预测取回报均值时残差方差等于回报方差，EV = 0；预测系统性偏离（例如始终偏高）时残差方差更大，EV < 0。
  2. 改参数预测：把曲线展示的平滑窗口从 5 个评测点增大到 50 个，预测一次持续 3 万步的性能崩溃在展示曲线上的可见程度，并说明这对事故定位的影响。★
    提示
    3 万步若对应 2 到 3 个评测点，大窗口会把下探摊薄到近乎不可见；定位事故必须回看原始评测点。
  3. 设计：为值分解算法的常规训练设计一页诊断看板，列出六条曲线（回报、EV、TD 误差分位、熵、梯度范数、裁剪触发率）及其联读规则，说明每条告警触发的消融动作。★★
    提示
    联读规则示例：EV 高 + 回报平台触发探索与信用消融；EV 低 + 误差尾部抬升触发目标网络与学习率检查。
  4. 实验设计：人为构造两类故障（学习率过高、探索系数归零），验证你的检查器能否在崩溃出现前 1 到 2 个评测点给出提示，并记录误报率。★★★
    提示
    高学习率故障的先行信号通常是误差分位数抬升与裁剪触发率上升；探索归零的先行信号是熵曲线斜率变化。

小结

  • 回报曲线呈现三规范：保留种子原始曲线、横轴用环境步、评测与训练分布分开；平滑只用于展示，异常检测用原始数据。
  • 辅助指标五组：价值侧 EV 与误差分位、策略侧熵与散度、梯度侧范数与触发率、数据侧回合长度与覆盖、环境侧课程与漂移。
  • 四类形态各有伴随特征与定位路径；排查顺序从评测口径到数据管线，最后到网络与优化配置。
  • 规则化检查器把诊断逻辑固化为代码，输出线索并触发消融，不阻断训练。
  • 下一页进入超参数敏感性：用固定种子与配对设计，把单次训练曲线升级为可信的参数响应曲线。
