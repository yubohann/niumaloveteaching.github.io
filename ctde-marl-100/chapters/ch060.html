第三篇 · 环境与任务实践

第 060 章：多智能体电力系统控制

电力系统控制处理频率与电压的实时平衡；本章推导摇摆方程与下垂特性，说明分布式二次控制如何用一致性协议恢复额定值，并给出兼顾稳定与设备寿命的奖励设计。

  • 主题：动态系统协同 / 一致性与稳定性
  • 关键公式：M df/dt = Pm − Pe − D Δf ， f = fn − kp ( P − Pref )
  • 预计学时：65 分钟
  • 前置章节：第 059 章 多智能体供应链管理

学习目标

读完本章，应当能够把频率与电压控制写成多机协同的动态问题，并区分一次调节与二次调节的目标。

  • 掌握摇摆方程的构成：惯量、阻尼、机械功率与电磁功率之差，理解频率偏差与功率缺口的对应关系。
  • 掌握下垂控制的线性特性与功率分配规则，能说明下垂系数与机组容量比例的匹配要求。
  • 掌握分布式二次控制的一致性结构，理解通信拓扑的连通性对频率恢复的影响。
  • 理解通信延迟与采样周期对闭环稳定性的作用，能解释为何学习策略需要在稳定约束下训练。
  • 会设计包含频率偏差、电压偏差与功率变化率的组合奖励，并识别只压偏差导致执行器磨损的退化。

背景与动机

电力系统的频率与电压是必须实时维持的系统级变量，控制必须在毫秒到秒的时间尺度上闭环。

传统电力系统的频率控制分三层：一次调节由发电机调速器按下垂特性自动响应，响应快但存在稳态偏差；二次调节由调度中心下发自动发电控制（automatic generation control, AGC）指令恢复频率并维持联络线功率；三次调节处理经济调度。随着分布式电源与逆变器接口设备占比上升，系统惯量下降，扰动后的频率变化率更高，集中式二次调节的通信与计算延迟成为瓶颈。分布式二次控制因此受到重视：每个单元与邻居交换频率与功率偏差信息，用一致性协议协同恢复额定频率，无需中心节点。

强化学习在此的定位有两类。其一是参数整定：把下垂系数、二次控制增益或滤波器时间常数作为决策变量，用学习替代人工整定，奖励包含偏差与振荡程度。其二是直接控制：策略以本地频率、功率与邻居信息为观测，直接输出功率指令。前者的动作空间小、可解释性强，适合作为起点；后者的表达能力更强，但必须处理稳定性与物理约束。与第 051 章的能源管理相比，本章的时间尺度更短、动力学更明确，控制目标从经济性转向动态品质与稳定性。

核心原理

本章原理分四层：频率动力学、下垂与分配、分布式二次控制、以及延迟与稳定性。

1. 摇摆方程与频率响应

频率是发电与用电功率平衡的积分表现，任何缺口都转化为频率变化。

M · df/dt = Pm − Pe − D · Δf ， Δf = f − fn M 为等效惯量（秒为单位）；f 为系统频率；Pm 为机械功率；Pe 为电磁功率（负荷）；D 为阻尼系数；Δf 为频率偏差；fn 为额定频率

方程的物理含义是功率缺口的能量去向：机械功率不足以覆盖电磁功率时，缺口由转子动能补偿，转速随之下降，频率降低。惯量 M 越大，同样缺口下频率变化越慢，最低点（nadir）越浅；阻尼 D 提供与偏差成正比的恢复力。新能源占比上升使等效惯量下降，这是频率质量恶化与快速储能需求上升的根本原因。控制设计的三项指标由该方程直接导出：最大频率偏差、恢复时间与稳态误差。仿真实现用半隐式积分推进，步长与惯量的乘积决定了数值稳定性边界。

2. 下垂控制与功率分配

下垂特性用频率偏差换取功率支撑，是并联单元自动分担负荷的基础。

Pi = Pref,i + ( fn − f ) / kp,i ， 稳态：Δf = − ( Σ ΔPi ) / Σ ( 1 / kp,i ) kp,i 为第 i 台机组的下垂系数（频率下降与功率增量的比值）；ΔPi 为其承担的功率增量；并行运行的单元频率相同，功率按下垂系数倒数分配

分配公式说明两件事。第一，下垂系数小的单元承担更大份额，因此系数的设置应与其额定容量成反比，容量大者承担更多，避免小机组过载。第二，下垂控制必然存在稳态频率偏差：偏差等于总负荷增量除以总下垂增益。要消除稳态偏差需要二次控制。电压控制与之对偶：无功与电压幅值之间存在下垂关系，逆变器的 Q-V 下垂系数决定无功分配。频率与电压两个通道在逆变器上耦合，实现时分别设系数并检查耦合引起的交互。

3. 分布式二次控制

二次控制的目标是恢复额定值，分布式实现让每个单元与邻居交换偏差信息。

ui( t ) = − c · Σj∈N(i) [ ( Δfi − Δfj ) + kp,i ( Pi − Pj ) ] ， 再叠加本地频率回馈： − c0 Δfi N(i) 为通信邻居；c 为一致性增益；c0 为本地回馈增益；ui 为附加功率指令；两项分别对齐邻居状态与本地恢复

一致性项让相邻单元的状态趋于一致，本地回馈项把共同值拉向零偏差，两项合起来实现“频率恢复加功率按比例分配”的双目标。通信拓扑的连通性决定可行性：图连通且增益正定时，偏差指数收敛；图不连通时各连通分量收敛到各自的平衡，无法全局一致。与第 042 章的拉普拉斯矩阵结构完全同源，只是状态变量从位置换成频率与功率。学习策略可以替代固定增益：观测包含邻居偏差，输出每个单元的补偿量，训练中奖励收敛速度与超调，学到的策略在拓扑变化时具备自适应能力。

4. 通信延迟、采样与稳定性

分布式控制的性能受通信延迟约束，延迟过大时闭环振荡甚至失稳。

延迟系统近似：ui( t ) ≈ ui( t − τ ) ， 稳定裕度随 τ · c 增大而下降 τ 为通信与计算的总延迟；c 为一致性增益；乘积刻画控制回路在延迟期间累积的相位滞后

延迟的破坏机理是相位滞后：控制器依据过时状态行动，修正方向在延迟期间可能已过时，形成正反馈分量。工程上的对策包括降低增益、增加滤波器或事件触发通信（状态变化超过阈值才发送）。学习策略面对相同的约束：若训练忽略了延迟，学到的策略在含延迟的评估中会表现出更强的振荡。训练环境的延迟参数应按实际链路设定并随机化，评估报告不同延迟下的最大频率偏差与振荡幅度，形成类似第 052 章的鲁棒曲线。稳定性的底线通常由解析控制器兜底：学习输出经过限幅与速率约束后注入，或与固定增益并行，再由安全层保证闭环稳定。

5. 多智能体建模与奖励

每个发电单元或逆变器是一个智能体，观测包含本地电气量与可获得的邻居信息。

rt = − wf Σ | Δf | − wv Σ | ΔV | − wr Σ max( 0 , | ΔPi,t − ΔPi,t−1 | − Ri ) − wt Σ 超限次数 Δf 为频率偏差；ΔV 为电压偏差；Ri 为爬坡阈值；第三项对功率变化率施行单边惩罚，只有超过 Ri 的部分才计入（设备磨损与储能循环）；第四项统计越限（频率或电压超出允许带）次数

四项奖励各有对应目标：频率项与电压项维持品质，变化率项保护设备寿命，越限项保证硬约束。变化率惩罚与频率恢复存在冲突：恢复越快，功率变化越剧烈。权重比例决定策略风格，过高的变化率惩罚会得到缓慢恢复的保守策略，评估需要同时报告恢复时间。与第 051 章的奖励相比，本章不含经济成本，因为控制层的时间尺度内经济性影响可忽略，两者在分层结构中各司其职：上层调度给出参考功率，下层控制跟踪并维持品质。

实现思路与设计

实现采用微电网级模型：四台逆变器接口的可控单元、一个负荷节点与稀疏通信图，纯 NumPy 积分。

1. 环境循环

每步：负荷扰动按场景生成（阶跃、斜坡或随机脉冲）；各单元按策略输出功率指令；摇摆方程更新频率，电压按无功功率偏差的代数关系更新；通信按拓扑与延迟参数交换邻居状态；结算奖励并记录指标。回合以频率回归允许带并保持若干步为结束条件，或以时间上限截断。

3. 网络结构与训练要点

策略网络输入为本地频率偏差、功率偏差、电压偏差与邻居广播的对应量（含延迟），输出为功率补偿指令。训练使用集中式评论家读取全员状态，执行期各单元只看本地与邻居数据。奖励中的变化率项在动作端用速率限制器实现，训练与执行一致。评估覆盖三类扰动：负荷阶跃、机组脱网（单元失效）与负荷随机波动；报告最大频率偏差、恢复时间与频率在允许带内的时间占比。

4. 与第 051 章、第 042 章的差异点

第 051 章处理经济调度，时间尺度为分钟级，目标是成本与平衡约束；本章处理动态品质，时间尺度为百毫秒级，目标是频率与电压的暂态表现，两者的优化对象分别为能量流与动态响应。第 042 章的编队控制同样是分布式一致性结构，状态为位置，约束来自几何；本章的状态是电气量，约束来自物理动力学与稳定性。三章共享图论工具与一致性思想，差异在状态变量、时间尺度与约束来源。

关键代码与解读

三段代码分别实现频率动力学积分、一致性二次控制与含变化率惩罚的奖励。

片段 1：摇摆方程积分

import numpy as np

def swing_step(f, p_m, p_e, M=2.0, D=0.5, dt=0.01, f_n=50.0):
    """一步频率推进：机械功率与电磁功率之差驱动频率偏差。"""
    # 频率偏差按 (P_m - P_e - D*df) / M 积分，半隐式格式
    df = f - f_n
    ddf = (p_m - p_e - D * df) / M
    f_new = f + ddf * dt
    # 频率硬件限幅：模拟保护动作前的物理边界，避免数值发散
    f_new = float(np.clip(f_new, f_n - 2.0, f_n + 2.0))
    return f_new, {"df": f_new - f_n, "rocof": ddf}

解读：功率量采用标幺值（基值为机组总额定功率），因此惯量 M 的单位为秒，物理含义是“满功率下动能可持续的时间”。返回的变化率（rocof）是频率质量的关键指标，评估中用它衡量扰动初期的严重程度。限幅设置为额定偏差的较大范围，仅用于防止数值发散，正常运行不会触及。积分步长 0.01 秒与百毫秒级现象匹配，若惯量进一步降低需要同时减小步长以维持数值稳定。

片段 2：一致性二次控制

def consensus_secondary(df_vec, p_vec, adj, kp_vec, delay_buffer,
                      c=0.5, c0=1.0, dt=0.01):
    """分布式二次控制：邻居一致项 + 本地恢复项，含延迟状态。"""
    # 用延迟缓冲中的旧状态计算一致性项，模拟通信延迟
    df_old, p_old = delay_buffer
    u = np.zeros_like(df_vec)
    for i in range(len(df_vec)):
        for j in np.nonzero(adj[i])[0]:
            # 相邻状态之差：频率偏差差与功率标幺值差分别对齐
            u[i] -= c * ((df_old[i] - df_old[j]) + kp_vec[i] * (p_old[i] - p_old[j]))
    u -= c0 * df_vec                 # 本地回馈把共同值拉向零偏差
    # 速率限制：与设备爬坡约束一致，学习策略输出同样受此约束
    return np.clip(u * dt, -0.2, 0.2)

解读：一致性项只使用从缓冲取出的旧状态，本地回馈项使用当前状态，这一分离是延迟建模的关键，两类信息在真实系统中的时效不同。功率项按下垂系数加权，使一致的目标与分配的物理意义对齐。输出乘以步长并做速率限制，返回的是本步允许的功率增量，绝对功率由上层累加维护，与设备爬坡能力对应。增益 c 与 c0 的关系决定行为：本地回馈强时恢复快但耦合弱，一致性增益强时协同好但对延迟敏感，两者的比例需要在延迟随机化的条件下调试。

片段 3：动态品质奖励

def power_control_reward(df_vec, dv_vec, p_cmd, p_prev, ramp=0.2,
                       w_f=1.0, w_v=0.5, w_r=0.3, w_lim=2.0):
    """奖励：频率偏差 + 电压偏差 + 功率变化率 + 越限惩罚。"""
    freq_term = -w_f * float(np.abs(df_vec).sum())
    volt_term = -w_v * float(np.abs(dv_vec).sum())
    # 变化率项：只惩罚超过设备能力的变化，正常调节不受影响
    delta_p = np.abs(p_cmd - p_prev)
    ramp_term = -w_r * float(np.maximum(0.0, delta_p - ramp).sum())
    # 越限为硬约束：频率或电压任何一项超出允许带都计入
    over = int((np.abs(df_vec) > 0.05).sum() + (np.abs(dv_vec) > 0.05).sum())
    r = freq_term + volt_term + ramp_term - w_lim * over
    info = {"df_max": float(np.abs(df_vec).max()), "over": over,
            "ramp_excess": float(np.maximum(0.0, delta_p - ramp).sum())}
    return r, info

解读：频率与电压项按绝对值求和，对偏差大小线性计价，与小偏差的物理含义一致（线性阻尼系统）。变化率用单边惩罚：超过爬坡能力才扣分，避免惩罚正常调节动作，这一设计与第 053 章的近失惩罚同属“只在风险区给信号”的模式。越限惩罚独立于连续项，保证硬约束的优先级，权重按恢复过程单步收益的数十倍量级设定。信息字典输出的最大偏差与越限数是评估面板的核心量，训练日志中两者与奖励曲线联合观察可以区分“奖励上升来自偏差下降还是来自变化率下降”。

常见坑

  • 只惩罚频率偏差：策略用过大的功率变化换取快速恢复，执行器磨损与储能循环加剧。症状是恢复时间短而设备动作量异常大。修复：加入变化率单边惩罚与爬坡限制，评估报告动作总量。
  • 通信延迟未建模：训练使用同步通信，含延迟的评估出现振荡与超调。症状是恢复时间的评估方差随延迟增大。修复：延迟进入环境状态并随机化，评估绘制延迟与最大偏差的鲁棒曲线。
  • 下垂系数与容量不匹配：系数设置使小容量机组承担大份额，出现超载与环流。症状是单元功率长期偏离额定比例。修复：按容量成反比设置系数，并在奖励中加入分配比例偏差项。
  • 采样步长与惯量失配：步长过大时积分振荡放大，被误判为控制策略问题。修复：按惯量与阻尼的组合估计稳定步长，必要时减小步长或改用隐式格式。
  • 评估只用单一扰动场景：策略过拟合到阶跃扰动，遇到连续随机波动时品质下降。修复：评估覆盖阶跃、斜坡、随机波动与单元失效四类场景，逐类报告。

    提示
    稳态偏差为增量除以总下垂增益，0.2/25 = 0.008。要求不超过 0.005 时需要增益不低于 0.2/0.005 = 40，高于当前的 25，需要增加并联机组或调小下垂系数。
  2. 推导题：由摇摆方程推导扰动后的频率最低点与惯量、扰动量的近似关系，说明低惯量系统的风险。★★
    提示
    忽略阻尼与一次调频的初始阶段，频率变化率为扰动量除以惯量，最低点与扰动量的平方除以惯量近似成正比。惯量减半使最低点偏差显著加深，这是频率安全的核心指标。
  3. 改参数并预测：把一致性增益 c 从 0.5 提高到 2.0，预测恢复时间、超调幅度与延迟容限的变化方向。★★
    提示
    增益提高后恢复加快、超调增大、延迟容限下降，含延迟评估中可能触发振荡。该权衡与第 042 章图增益的作用一致，需在延迟随机化条件下选取折中值。
  4. 设计题：设计一个在通信中断时保持基本功能的降级方案，说明观测与动作如何切换，以及如何评估降级状态下的品质。★★★
    提示
    通信中断时退化为纯本地下垂控制，恢复额定值的能力丢失但稳定性可保。切换依据为邻居信息年龄，评估报告中断时长与频率稳态偏差的关系，并设置恢复通信后的平稳接管逻辑。
  5. 实验设计：比较“固定增益二次控制”“学习补偿量”“学习下垂系数”三种方案在四类扰动下的表现，说明评估指标与结论的适用范围。★★★
    提示
    指标包含最大频率偏差、恢复时间、动作总量与越限次数。学习补偿量在场景适应上更灵活，学习系数实现简单但能力有限，固定增益基线稳定可预期；结论需要说明各方案适用的扰动类型与延迟范围。

小结

  • 频率由摇摆方程描述，功率缺口通过惯量转化为频率变化，最大偏差与恢复时间由惯量、阻尼和控制共同决定。
  • 下垂控制实现自动功率分配，系数按容量成反比设置，稳态偏差不可避免，需要二次控制恢复额定值。
  • 分布式二次控制用一致性项加本地回馈实现频率恢复与比例分配，通信拓扑连通性与增益共同决定收敛。
  • 通信延迟压缩稳定裕度，训练需将延迟随机化；奖励需同时包含频率、电压、功率变化率与越限四项，评估覆盖多类扰动。
  • 本篇到此结束，从粒子环境到电力系统共二十个任务环境已经覆盖空间协同、物理约束、机制设计与动态控制；下一篇高级机制与研究专题从多智能体无线网络资源管理开始，把分配与约束工具应用到通信资源与更复杂的机制场景。
