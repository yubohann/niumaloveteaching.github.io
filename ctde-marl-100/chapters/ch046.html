第三篇 · 环境与任务实践

第 046 章：多智能体协同搬运

协同搬运是带接触与力约束的协作任务；本章推导载荷的合力与力矩平衡条件，说明力分配的解空间为何包含零空间内力，并把力均衡写进奖励以抑制挤压。

  • 主题：接触约束协同 / 力分配
  • 关键公式：m a = Σ fi，I α = Σ ri × fi
  • 预计学时：65 分钟
  • 前置章节：第 045 章 多智能体导航

学习目标

读完本章，应当能够把“多个机器人抬一个物体走”翻译成一组合力与力矩约束，并为它设计可训练、可诊断的奖励。

  • 掌握平面刚体载荷的动力学方程，理解合力控制质心运动、力矩控制姿态的分工。
  • 理解力分配方程的解空间结构：最小范数解与零空间内力，以及内力对运动无影响、对接触安全有影响的双重性质。
  • 掌握接触的摩擦锥约束与接触模型（刚性抓取与软接触）的表达方式，理解它们对动作空间的影响。
  • 能为搬运任务设计包含轨迹跟踪、姿态保持、力均衡与接触安全的组合奖励，并识别只优化载荷位姿导致接触力发散的失败模式。
  • 会按角色条件化策略参数或观测，处理能力不同的异构搬运队员。

背景与动机

搬运任务的特殊性在于动作通过接触力传递，接触既是执行手段也是风险来源。

单个机器人可以抓取物体，但大型、柔性或形状特殊的负载需要多个接触点共同支撑。多机器人搬运在装配、物流分拣与灾害救援中具有实际意义，其核心困难有三。第一，力与运动之间存在不可逆的映射损失：每个机器人只能控制自己接触点的力，载荷的运动是所有力的合成结果，单个机器人的控制权被稀释。第二，约束是多重的：机器人之间需要避免碰撞，机器人、负载与环境之间需要保持接触，接触力还要落在摩擦锥以内。第三，任务对同步性敏感：任何一方的延迟都会通过载荷传递给全队。

强化学习的介入方式通常是把力分配问题分解为两层：上层策略学习载荷的期望运动（或直接学习各接触点的期望力），下层由解析的力控制器保证接触安全。本章同时讨论端到端方案与分层方案，重点在理解力分配的数学结构，因为它是判断策略优劣与设计奖励的依据。后续的机器人协作（第 054 章）与机器人装配任务会复用本章的接触模型。

核心原理

搬运任务的原理可以概括为三件事：载荷如何被合力驱动、接触力如何被分配、以及分配解中的自由度如何处理。

1. 载荷动力学：合力与力矩的分工

把载荷看作平面刚体，其质心运动由接触力之和决定，姿态旋转由力矩决定。

m · a = Σi fi + fext ， I · α = Σi ri × fi + τext m 为载荷质量；a 为质心加速度；fi 为第 i 个接触点的作用力；ri 为接触点相对质心的位置向量；I 为转动惯量；α 为角加速度；下标 ext 表示环境外力

两个方程合起来说明：希望载荷沿某方向加速，需要所有接触力的向量和指向该方向；希望载荷不旋转，需要接触力对质心的力矩和为零。后者给出了姿态保持的解析条件，也是布置抓取点的依据：对称分布时，等大力的力矩自然抵消，姿态稳定所需的控制量最小。载荷姿态漂移是搬运失败的主要形式，多数任务把姿态误差作为独立奖励项处理，不依赖位置误差隐含表达。

若载荷与环境存在支撑面，问题可以退化为“推动”形式：无需平衡重力，只需克服摩擦并提供平面运动的合力。若为悬吊或空中搬运，重力补偿成为每一项接触力的固定分量，动力学方程的形式不变，但力的分布需要显式包含垂直分量。工程实现上两种形式共用同一套力分配逻辑。

2. 力分配的解空间与零空间内力

把期望的合力与力矩合写成一个三维目标向量，力分配方程通常是欠定的。

A f = wdes ， A = [ I2 I2 … I2 ; r1⊥ r2⊥ … rN⊥ ] ∈ ℝ3 × 2N f = (f1, …, fN) 为全部接触力拼接向量；wdes = (Fx, Fy, τ) 为期望的合力与力矩；ri⊥ 为力臂向量的正交方向

当 N ≥ 2 时方程个数为 3，未知数为 2N，解空间是 2N − 3 维的仿射空间。最小范数解 f = AT (A AT)−1 wdes 给出“总力最小”的分配，它均匀分摊负载，通常作为默认选择。解空间的零空间分量称为内力：一组大小相等、方向沿接触连线成对出现的力，它们的合力与力矩都为零，不改变载荷运动，却改变接触点之间的挤压程度。

内力的实际意义有两面。恰当的预紧内力保证接触不松脱，例如双臂夹持需要在接触法向维持一定压力。过大的内力造成能量浪费、关节负载升高，甚至在柔性载荷上造成变形。因此内力不进入运动目标，却必须进入安全与能耗约束。策略学习的任务因此可以分解为：学习期望运动 wdes（或直接学习 f），由奖励约束内力与接触力上界。

3. 接触模型与摩擦锥

接触力能否被物理实现，取决于法向分量与切向分量的比例。

摩擦锥： ‖ ft ‖ ≤ μ · fn ， fn ≥ 0 ft 为切向力分量；fn 为法向压力；μ 为摩擦系数；fn ≥ 0 表示接触只能推不能拉

摩擦锥约束是凸的，多个接触点的约束交集仍是凸集，这意味着给定期望运动时存在多项式时间的可行力分配求解方法（例如二次规划）。强化学习的动作若解释为接触力，必须经过摩擦锥投影；若解释为机器人末端位移，则接触力由软接触模型隐式给出。软接触模型把接触力写成穿透深度的弹簧阻尼函数：f = k · δ + c · δ̇，参数 k、c 决定接触刚度与能量耗散，取值过软时接触力延迟明显，过硬时数值不稳定，训练中的步长需要与刚度匹配。

刚性抓取（接触点与载荷的相对位姿固定）简化了接触建模，代价是失去重抓取能力；点接触允许相对滑动，表达更强但需要策略显式处理滑移。初步实现通常选择刚性抓取加软接触，既避开滑移判定，又保留接触力的连续表达。

4. 奖励设计：轨迹、姿态、力均衡与接触安全

搬运奖励由四项组成，各自对应一类失败模式。

rt = − wp ‖ pL − pref ‖2 − wθ θ2 − wf Vari ( fi ) − wv Σi max(0, ‖fi‖ − fmax) + wg · 1[到达] pL 为载荷质心；pref 为参考轨迹点；θ 为载荷姿态角偏差；Var 项度量各接触力的离散程度；fmax 为安全力上限

轨迹项驱动载荷移动，姿态项防止载荷旋转，两项共同定义“搬得稳”。力均衡项抑制内力：接触力方差大说明部分机器人出力远高于平均，通常伴随内力增加。接触安全项对超限力施加单边惩罚，形式上是铰链损失（hinge loss），只惩罚越界不奖励“力很小”，避免策略学会完全不出力。稀疏到达奖励用于给出收敛目标，强度按稠密项量级设定。

力均衡权重过大会逼近均匀分配，削弱载荷机动能力（机动需要不对称的力分布）；过小则内力失管。调试时同时观察三条曲线：载荷跟踪误差、接触力方差、超限次数，三者分别对应上文权重。

5. 角色分工与异构队员

搬运队员在能力上常常不同：臂长、负载上限、传感器配置各异。

处理异构的通用做法是角色条件化：给每个智能体附加一个能力向量（负载上限、抓取点相对位置、最大速度），与观测拼接后送入共享策略网络。若能力差异过大，共享参数会互相干扰，此时按角色分组共享参数。另一条路线是显式的领导者与跟随者结构：一个智能体跟踪载荷参考轨迹，其余智能体跟踪自身在载荷坐标系下的期望抓取点。该结构把任务分解成主从两段，训练信号更清晰，代价是领导者失效时缺乏冗余。端到端策略有能力学出动态的角色分配，但需要更长的训练预算与更细的奖励设计。

实现思路与设计

实现选择“策略输出期望力、环境用软接触积分载荷动力学”的路线，接触安全由力投影与惩罚共同保证。

1. 数据流与执行流程

每个控制周期内：策略读取观测（载荷位姿与速度、自身相对抓取点位置、上一步接触力），输出期望接触力；环境将力裁剪到摩擦锥与幅值上限；接触力经载荷动力学积分更新载荷状态；机器人位置通过刚性抓取约束跟随载荷。环境返回载荷位姿误差、接触力统计与碰撞事件。

3. 网络结构与训练要点

策略网络输入包含全局可共享的载荷状态与个体观测（自身抓取点偏差与上一步接触力）。邻居聚合不用于本例的力分配，因为载荷状态提供了足够的公共协调信号；参数共享适用于同构队员，异构场景按能力向量条件化。训练使用集中式评论家读取载荷状态与全部接触力，价值网络的输入维度随队员数线性增长。探索噪声施加在力上，经过摩擦锥投影后生效，保证样本始终可行。

4. 与第 045 章的差异点

导航任务的约束主要来自智能体之间的几何关系，动作直接作用于自身；搬运任务的动作通过载荷耦合，个体动作的收益取决于队友动作，物理约束的耦合强度更高。奖励上，导航任务使用势能塑形保证长程引导，搬运任务使用载荷位姿误差与力统计，短程密集信号占主导。安全约束的实现上，导航用半平面过滤，搬运用摩擦锥投影，两者都是把不可行动作映射回可行集，这一模式在后续章节反复出现。

关键代码与解读

三段代码分别实现载荷动力学积分、力分配的最小范数解、以及搬运奖励。

片段 1：载荷动力学积分

import numpy as np

class Payload:
    """平面刚体载荷：质量、惯量、状态与动力学积分。"""
    def __init__(self, mass=4.0, inertia=1.0):
        self.m, self.I = mass, inertia
        self.pos = np.zeros(2)             # 质心位置
        self.vel = np.zeros(2)
        self.theta, self.omega = 0.0, 0.0  # 姿态角与角速度

    def step(self, forces, grasp_pts, dt=0.02):
        F = np.sum(forces, axis=0)                       # 合力驱动质心
        # 力臂取相对质心的向量；叉积 z 分量给出力矩标量
        torques = [r[0] * f[1] - r[1] * f[0]
                   for r, f in zip(grasp_pts, forces)]
        tau = float(np.sum(torques))
        self.vel += (F / self.m) * dt                    # 半隐式：先速度
        self.pos += self.vel * dt                        # 再位置
        self.omega += (tau / self.I) * dt
        self.theta += self.omega * dt
        self.theta = (self.theta + np.pi) % (2 * np.pi) - np.pi  # 角规范化
        return {"force_sum": F, "torque": tau}

解读：动力学实现与粒子环境同构（半隐式欧拉），区别在自由度包含姿态角。力矩用二维叉积的标量形式计算，避免构造三维向量。角规范化把姿态保持在 (−π, π]，否则姿态误差在跨越 ±π 时会跳变，奖励出现不连续。返回的合力与力矩用于诊断：合力接近零而载荷仍在移动说明外力干扰，力矩长期非零说明姿态控制不足。

片段 2：力分配的最小范数解与内力

def allocate_forces(desired, grasp_pts):
    """求 A f = desired 的最小范数解，并给出零空间维数。"""
    n = len(grasp_pts)
    # 每列对应一个接触点的贡献：单位力与单位力的力矩
    A = np.zeros((3, 2 * n))
    for i, r in enumerate(grasp_pts):
        A[0, 2 * i] = 1.0                      # x 方向合力
        A[1, 2 * i + 1] = 1.0                  # y 方向合力
        A[2, 2 * i] = -r[1]                    # x 力对质心的力矩
        A[2, 2 * i + 1] = r[0]                 # y 力对质心的力矩
    # 最小范数解：均匀分摊负载，等价于求解带正则的最小二乘
    # 正则项处理退化构型：多个抓取点重合时 AA^T 奇异
    f = A.T @ np.linalg.solve(A @ A.T + 1e-8 * np.eye(3), desired)
    # 零空间维数 = 未知数 - 方程秩，即内力自由度
    nullity = 2 * n - np.linalg.matrix_rank(A)
    return f.reshape(n, 2), nullity

解读：矩阵 A 的构造直接对应动力学方程，每两列描述一个接触点在 x、y 方向的力及其力矩。最小范数解通过 AT(AAT)−1 计算，正则项 1e-8 处理退化构型（例如多个抓取点重合使 AAT 奇异）的情形。零空间维数用于理解解的灵活性：两点抓取时零空间为一维，恰好对应一对挤压内力，可用一个标量参数控制预紧力大小；四点抓取时零空间升到五维，六对两两挤压方向存在一个线性关系，预紧控制需要先在零空间中选定方向组合。该函数作为基线与诊断工具，策略的出力分布与最小范数解的偏离程度反映其是否学会利用不对称分配。

片段 3：搬运奖励与力诊断

def transport_reward(load, ref_pos, forces, grasp_pts,
                     w_p=1.0, w_theta=0.5, w_f=0.1, f_max=1.5):
    # 轨迹项与姿态项：二次型，远离参考时信号强，接近时平滑
    e_p = float(np.sum((load.pos - ref_pos) ** 2))
    e_theta = float(load.theta ** 2)
    # 力均衡项：各接触力模长的方差，方差大意味着部分队员过度出力
    mags = np.linalg.norm(forces, axis=1)
    var_f = float(mags.var())
    # 单边惩罚：只对超过安全上限的力收费，避免鼓励“不出力”
    over = float(np.sum(np.maximum(0.0, mags - f_max)))
    r = -w_p * e_p - w_theta * e_theta - w_f * var_f - 2.0 * over
    info = {"pos_err": e_p, "theta_err": e_theta,
            "force_var": var_f, "over_limit": over,
            "force_sum": forces.sum(axis=0).tolist()}
    return r, info

解读：四项奖励的量纲通过权重对齐：位置误差为平方量，姿态为弧度平方，两者数值尺度相差一个量级，因此姿态权重取位置权重的一半。力方差项对内力施加软约束，其值同时也用于诊断。单边惩罚的权重 2.0 使一次超限的代价约等于位置误差下降一个数量级的收益，避免策略频繁试探上限。信息字典中的 force_sum 与最小范数解对照可判断分配是否合理：合力偏离期望而位置误差同步增大时，问题定位在力分配环节。

常见坑

  • 只奖励载荷位姿，放任接触力：载荷轨迹跟踪良好但接触力发散，出现内力互相挤压。症状是载荷被“抬”到目的地的同时关节力矩超限。修复：加入力方差项与安全上限的单边惩罚，并把接触力统计纳入诊断。
  • 摩擦锥投影遗漏：策略输出经幅值裁剪但未按摩擦锥投影，切向力超出摩擦极限时物理上不可实现，仿真中的实际接触力与策略输出不符。症状是训练与评估行为不一致。修复：在动作输出端统一做摩擦锥投影，保持策略输出与环境实际力的对应关系。
  • 接触刚度与仿真步长失配：刚度加大而步长未减小，接触力出现数值振荡。症状是接触力曲线高频抖动且随步长翻倍而变化。修复：按 k·dt² 与等效质量的关系约束刚度，或降低步长、改用隐式积分。
  • 抓取点坐标换算错误：力臂向量在错误坐标系下计算，力矩方向相反，载荷持续旋转。症状是载荷姿态单向漂移且力矩符号与期望相反。修复：统一以载荷质心坐标系表达力臂，并用最小范数解做单元验证。
  • 异构队员共用一套参数不加条件：负载能力不同的队员被同一策略驱动，弱队员长期超限出力。症状是超限次数集中在固定成员。修复：把能力向量拼入观测，或按能力分组共享参数。

练习与思考

  1. 推导题：对 N = 4 的平面载荷，写出 A 的维度并计算力分配解空间的维数，说明其中哪些自由度对应内力。★
    提示
    A 为 3×8，秩至多 3，解空间维数为 8 − 3 = 5，其中零空间维数亦为 5（对满秩情形）。内力是其中不改变合力与力矩的分量组合。
  2. 计算题：正方形抓取点上两组对称内力 f 与 −f 叠加，验证合力与力矩均为零，说明其在摩擦锥内的约束条件。★★
    提示
    对称内力成对出现且方向沿接触连线时合矢量为零；摩擦锥要求每个接触点的切向分量不超过 μ 倍法向分量，这给出内力的幅度上限。
  3. 改参数并预测：把力均衡权重 wf 从 0.1 提高到 1.0，预测载荷跟踪误差、力方差与能耗三项指标的变化方向，并判断在需要急转弯的任务里会出现什么退化。★★
    提示
    方差下降但跟踪误差上升，能耗可能先降后升（规避不对称分配导致机动不足，延长了搬运时间）。急转弯时需要不对称出力提供力矩，权重过大时载荷姿态误差首先恶化。
  4. 设计题：为两臂夹持场景设计预紧内力控制方案，给出内力标量的调节规则与安全边界，并说明它如何嵌入强化学习框架。★★★
    提示
    预紧力可取常数或按载荷估计动态调整，安全边界由摩擦锥与材料强度共同决定。嵌入方式是把预紧力作为力分配零空间分量叠加到策略输出上，或直接在观测中提供接触状态由策略隐式控制。
  5. 实验设计：对比“动作即接触力”与“动作即末端位移（软接触隐式出力）”两种动作空间，设计指标区分两者的样本效率与控制精度差异。★★★
    提示
    直接力动作的控制精度高但样本需求大，位移动作受接触动力学隐式约束、早期更易学习。指标可用达到相同跟踪误差所需回合数、接触力超限频次与稳态抖动幅度。

小结

  • 载荷动力学分两条通道：合力控制质心运动，力矩控制姿态；对称布置接触点可以让姿态保持所需的控制量最小。
  • 力分配方程欠定，解空间含零空间内力；内力不影响运动，但受摩擦锥约束并影响接触安全与能耗。
  • 摩擦锥约束把可行力集合限制为凸集，动作端做投影即可保证可行性；软接触模型的刚度与步长需要匹配。
  • 奖励需同时覆盖轨迹、姿态、力均衡与接触安全四项，单边惩罚优于对称惩罚，避免策略学会不出力。
