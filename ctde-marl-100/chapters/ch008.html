第 008 章：QTRAN算法实现

值分解第三代：放弃单调性假设，用变换与不等式约束逼近 IGM 条件本身。QTRAN（Learning to Factorize with Transformation）把"联合最优等于个体最优拼装"拆成一组逐动作可检验的充分条件，本章实现时序差分、最优点等式、非最优点松弛三段损失，并说明实现中两处近似的必要性。

  • 主题：值分解算法 / 直接 IGM 约束
  • 关键公式：Σi Qi(u) − Qjt(u) + V(s) ≥ 0 恒成立且在个体最优动作组合处取等
  • 预计学时：55 分钟
  • 前置章节：第 007 章

学习目标

  • 理解 QTRAN 的设计目标：在保持分散执行的同时逼近完整的 IGM 函数类，突破单调性上界。
  • 掌握变换形式充分条件（通用上界不等式加个体最优组合处取等）及其完整的充分性证明。
  • 掌握三段式损失的分工：Ltd 训练联合价值与状态价值，Lopt 约束个体最优组合处取等，Lnopt 松弛非最优点的单边不等式。
  • 会实现带 detach 控制的 QTRAN 损失，理解最优点替身与邻域扰动采样两处近似的必要性。
  • 能比较 VDN、QMIX、QTRAN 三代的约束强度与适用任务谱系，并设计受控对照实验。

背景与动机

第 007 章把分解约束从加性放宽到单调，覆盖非负交互项，但"个体价值越高则联合价值越高"这一全局单调性仍排除一类任务：最优联合行为需要某个智能体主动采取局部次优动作（掩护、破缺、牺牲结构）。单调约束与任务结构直接冲突时，算法会系统性地收敛到保守联合行为。

QTRAN 的问法是：能否绕开对混合函数形状的假设，直接逼近 IGM 条件本身？IGM 是关于 argmax 的条件，逐动作枚举验证的代价为指数级，无法直接写进损失。QTRAN 的回答由两部分组成：其一是变换视角，用状态价值 V(s) 把联合价值平移出可逐动作比较的形式，得到一组充分条件；其二是松弛策略，充分条件中昂贵的一侧（全联合动作上的不等式）改为对邻域动作的惩罚项，最优点一侧用近似 argmax 的动作施加等式约束。本章沿这条思路把三段式损失落成代码，逐块解释每处 detach 与近似的位置及后果，并给出与 QMIX 的受控对照清单。

核心原理

本节先给出变换形式的充分条件与证明思路，再拆解三段式损失，最后讨论两处近似与三代方法的对照。

1. 变换形式的充分条件

设联合价值网络 Qjt(s, u)、个体价值 {Qi(τi, ui)} 与状态价值 V(s)。记 ūi = argmaxui Qi 为各智能体的个体最优动作，ū = (ū1, …, ūN) 为个体最优动作的组合（简称个体最优组合）。平移量 V 按下面的定义式计算：

V(s) := maxu Qjt(s, u) − Σi Qi(τi, ūi) V 记录"联合最优值与个体最优组合之和之间的落差"，只依赖状态、与动作无关；部分可观测与联合结构造成的全部差异都吸收在这一个标量里

QTRAN 的充分条件为：

（C1）对一切联合动作 u： Σi Qi(τi, ui) − Qjt(s, u) + V(s) ≥ 0
（C2）在个体最优组合 ū 处： Σi Qi(τi, ūi) − Qjt(s, ū) + V(s) = 0 按 V 的定义，(C2) 在形式上自动成立；条件的主体是 (C1)：要求 Σ Qi 成为 Qjt 减去平移量之后的逐动作上界，且该上界在个体最优组合处被取到。ū 由各智能体独立 argmax 拼装，无需枚举联合空间，这是条件可检验的关键

充分性证明（不跳步）。把 V 的定义式代入 (C1)，对一切 u 得到一条夹逼链：

Qjt(u) − maxu′ Qjt(u′) ≤ Σi Qi(τi, ui) − Σi Qi(τi, ūi) ≤ 0 右端不等式用结构事实：和式 Σ Qi(ui) 在且仅在每个坐标取个体最大时达到最大值。左端不等式即重写后的 (C1)

第一步：在 u = ū 处应用夹逼链，左端变成 Qjt(ū) − maxu′ Qjt(u′)，右端为 0，于是 Qjt(ū) = maxu Qjt，个体最优组合确实是一个联合最优。第二步：链式不等式说明 Qjt 相对最优值的下降幅度，被 Σ 相对其最大值的下降幅度所支配，这一支配关系对所有 u 成立。第三步：若 u* 使 Qjt(u*) = max Qjt，代入链式得 0 ≤ Σ(u*) − Σ(ū) ≤ 0，故 Σ(u*) 达到最大值，u* 的每个坐标都取到个体最大。三步合起来给出两个 argmax 集合的相等关系，IGM 成立；证明只用到"Σ 的最大值在个体最优组合处取到"，与 Qjt 由什么网络产生无关，这是 QTRAN 不依赖分解形状的根源。另有两条使用前必须知道的性质：IGM 对个体价值的正比例缩放不变（缩放不改变任何 argmax），而 (C1) 不是缩放不变的，这一自由度在讨论 QMIX 族与 QTRAN 族的关系时会用到（见练习 3）。

2. 数值算例：条件逐项核对与单调族的失效对照

取两智能体两动作的团队收益矩阵（条目为一步回报）：V(0,0) = 6、V(0,1) = −4、V(1,0) = −4、V(1,1) = 2，联合最优在 (0,0)。候选个体价值 Q1 = [2, 1]、Q2 = [4, 1]：个体最优动作分别是 0 与 0，个体最优组合 ū = (0, 0)，平移量为 V(s) = maxu V(u) − (2 + 4) = 6 − 6 = 0。逐项核对：

联合动作 u团队收益 V(u)Σ Qi(u)Σ Qi(u) − V(u) + V(s)判定
(0, 0)660取等，(C2) 成立
(0, 1)−437严格大于 0，(C1) 成立
(1, 0)−459严格大于 0，(C1) 成立
(1, 1)220取等（第三处等号不违反条件）

Σ Qi 的矩阵为 [[6, 3], [5, 2]]，argmax 在 (0, 0)，与团队收益的 argmax 一致，IGM 由此三元组见证成立。再看同一矩阵能否被单调混合表达：交叉差分 = 6 + 2 − (−4) − (−4) = 16 不为零，矩阵不是加性函数。按第 007 章的排序判据逐轴检查：固定队友动作得到的两条切片是 (6, −4) 与 (−4, 2)，第一条要求"动作 0 的个体价值更高"，第二条要求"动作 1 的个体价值更高"，同一坐标轴上两种要求互斥，四种轴向组合全部失败，该矩阵超出单调可表示族。对照关系清晰：交叉差分为零时 VDN 可解；矩阵沿某个轴排序单调时 QMIX 可解；本例两个条件都不满足，而 QTRAN 通过平移量 V 与个体价值的配合仍然给出合法的分解，这是"可行集逐代扩大"的最小反例。读表方法可以总结为一句话：把"Σ Qi 相对自身最大值的降幅"与"团队收益相对最优值的降幅"逐动作对照，前者处处不小于后者，(C1) 即成立。

3. 三段式损失

充分条件中 (C1) 需对全部 |A|N 个联合动作成立，(C2) 需解析 argmax，两者都不能直接计算。三段式损失把条件拆开松弛：

Ltd = 𝔼[ ( r + γ (1 − done) maxu′ Qjttarget(s′, u′) − Qjt(s, u) )² ]， Ltd2 = 𝔼[ ( r + γ (1 − done) Vtarget(s′) − V(s) )² ]
Lopt = 𝔼[ ( Qjt(s, ū) − V(s) − Σi Qi(τi, ūi) )² ]， Lnopt = 𝔼[ max( 0, Σi Qi(τi, ûi) − Qjt(s, û) + V(s) )² ] Ltd 与 Ltd2 用团队回报训练 Qjt 与 V；Lopt 在近似最优点拉平；Lnopt 只惩罚违例的邻域动作（铰链形式），对应 (C1) 的松弛

三段的梯度分工是本章最易讲错的部分，逐项拆解：（1）Ltd 只训练 Qjt，使其成为合格的联合动作价值估计；V 由 Ltd2 训练为状态价值估计。两者构成平移的两端。（2）Lopt 把 Qjt(ū) − V(s) 作为监督目标拉近 Σ Qi(ū)；实现中对 Qjt 与 V 一侧做 detach，梯度只流向个体网络，避免目标随个体网络一起移动。（3）Lnopt 只惩罚 Σ Qi 超出 Q′jt 的违例动作；铰链形式让满足 (C1) 的动作贡献零梯度，梯度只在边界活跃。三段损失的合并方式与权重决定收敛行为，实验时以等权为基线。

4. 两处近似及后果

实现层面有两处不可避免的近似。（1）最优点替身。(C2) 的 ū 是 Qjt 的全局 argmax，枚举代价指数级；实现取行为策略在探索时执行的联合动作作为替身，依据是 ε-greedy 行为在训练中后期以较高频率接近贪心动作。替身偏离真实 argmax 时，等式约束被施加在次优点上，个体价值被往错误方向拉动，这是 QTRAN 对超参数与探索调度敏感的主要原因。（2）邻域动作采样。(C1) 要求全空间成立，Lnopt 只在邻居联合动作上施罚，属于单边松弛；覆盖不足时违例动作可能残留，"IGM 验证测试"因此成为必要工序，用穷举在小任务上定期核查。

QTRAN-alt 针对第一处近似做了改进：用反事实形式的差值构造约束，把"改变单个智能体动作"的动作集合纳入惩罚，约束不再依赖联合 argmax 的准确定位。第 009 章 COMA 的反事实基线与第 020 章的信用分配会从另一方向遇到同类构造，本章先埋下伏笔。

6. 约束覆盖率与采样预算（边界分析）

(C1) 要求不等式在全部 |A|N 条联合动作上成立，而 Lnopt 的单步扰动每次只覆盖每个智能体的单坐标邻域，覆盖条数为 N(|A| − 1)，未覆盖部分依赖个体网络在未采样点上的泛化。两者之比随智能体数与动作数指数衰减，下表的数字已用程序枚举核对：

表读法：N 不超过 3、动作数不超过 4 时，单步扰动可覆盖邻域空间的七分之一到一半，配合训练中反复采样，违例动作被反复发现的概率较高；N 达到 5 及以上时，单步邻域占比跌破百分之一，未采样到的违例点只能依靠个体网络的泛化被间接压制，这种压制没有形式化保证。工程含义是采样预算应随规模增长：把每批次的扰动次数从每智能体 1 次提高到每智能体 k 次，或与随机联合动作采样混合使用；验证阶段用穷举（小任务）或大样本抽样（大任务）统计 c1 违例率，并跟踪随机联合动作样本上的最小余量 Σ Qi(u) − Qjt(u) + V(s)，余量最小值跌破零即说明约束在外推点失效。

另一条边界来自多体偏离：单步扰动只改变一个坐标，两个及以上智能体同时偏离最优组合的动作点既不在邻域集合内，也不共享单坐标边际的解释。训练数据如果由接近贪心的策略生成，这类远点只会以极低频率出现，模型对其取值完全由网络平滑性决定。对含大量远点违例的任务（例如奖励结构存在多个局部高峰），应把随机联合动作采样纳入 Lnopt，或接受"约束仅在采样分布支撑集上近似成立"这一事实，并在实验报告中如实标注验证范围。

实现思路与设计

本节给出 QTRAN 的组件与配置。相对第 007 章的增量：联合价值网络独立化、新增 V 网络、新增两段约束损失、训练循环改为一轮四分量合并损失。

优化Adam，lr 5e-4，梯度裁剪上限 10四分量梯度尺度差异大，裁剪作保险

与第 007 章的差异点：混合器消失，IGM 保证从"结构内建"改为"损失约束"；训练从单一 TD 损失变为四分量联合优化。由于约束是软性的，每固定步数运行一次穷举版 IGM 验证，是本章工程流程的强制项。

设计决策：四分量共用同一批次与同一优化步

四个损失分量共享同一条联合转移批次：Ltd 与 Ltd2 需要 (s, u, r, s′)，Lopt 与 Lnopt 需要同点状态与动作。同批次保证各约束在同一数据点上相互一致，避免不同步损失之间的目标错位。合并反传也控制计算成本：独立反传四次会让 Qjt 与个体网络交替漂移，收敛更慢。合并的代价是各损失梯度尺度的耦合，这正是权重与梯度裁剪存在的原因。

关键代码与解读

片段 1：联合价值网络与状态价值网络

import torch
import torch.nn as nn

class JointQ(nn.Module):
    """联合价值网络: 输入全局状态与联合动作 one-hot, 输出标量 Q_jt。"""
    def __init__(self, state_dim, n_agents, n_actions, hidden=128):
        super().__init__()
        # 联合动作显式进入输入: 满足 (C1)(C2) 检验所需的"任意动作可求值"接口
        self.net = nn.Sequential(
            nn.Linear(state_dim + n_agents * n_actions, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, 1),
        )

    def forward(self, state, joint_oh):
        return self.net(torch.cat([state, joint_oh], dim=-1)).squeeze(-1)

class StateValue(nn.Module):
    """状态价值网络: 仅受状态价值损失监督, 为变换提供平移量。"""
    def __init__(self, state_dim, hidden=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, 1),
        )

    def forward(self, state):
        return self.net(state).squeeze(-1)

解读：两个网络的接口差异对应两类用途：JointQ 接收状态与联合动作的 one-hot 拼接，因此可以对"任意候选联合动作"求值，这是 (C1) 在邻域动作上施罚的前提；若沿用第 007 章"状态条件混合器"的接口，邻域动作的联合价值将无法单独查询。（1）分离的 StateValue 不接收动作，结构上保证 V 只依赖状态，满足充分条件中平移量的定义。（2）两个网络与个体网络三组参数彼此独立，训练时各受不同类型损失监督，参数隔离让梯度来源可追溯。

片段 2：四分量合并损失

def joint_onehot(acts, n_actions):
    # (B, N) 索引 -> (B, N*n_actions) 拼接 one-hot, 段序固定对应智能体编号
    return torch.cat([torch.nn.functional.one_hot(acts[:, i], n_actions)
                      for i in range(acts.shape[1])], dim=-1).float()

def sum_chosen(agent_qs, obs, acts):
    # 取各智能体在给定动作上的 Q 值并求和: Σ_i Q_i(τ_i, u_i)
    vals = [net(obs[:, i]).gather(1, acts[:, i:i + 1])
            for i, net in enumerate(agent_qs)]
    return torch.cat(vals, dim=1).sum(dim=1)

def qtran_losses(agent_qs, q_jt, v_net, targets, batch, n_actions, gamma=0.95):
    """四分量合并损失: 各分量共享同批次, 一次反传。"""
    obs, act, rew, nobs, done, s, ns = batch
    B, N = act.shape
    with torch.no_grad():                       # 分量 1: Q_jt 的时序差分
        g_next = torch.stack([tn(nobs[:, i]).argmax(dim=1)
                              for tn in targets["agent_qs"]], dim=1)
        q_n = targets["q_jt"](ns, joint_onehot(g_next, n_actions))
        y_jt = rew[:, 0] + gamma * (1.0 - done[:, 0]) * q_n
    l_td = ((q_jt(s, joint_onehot(act, n_actions)) - y_jt) ** 2).mean()
    with torch.no_grad():                       # 分量 2: V 的时序差分
        y_v = rew[:, 0] + gamma * (1.0 - done[:, 0]) * targets["v"](ns)
    l_td2 = ((v_net(s) - y_v) ** 2).mean()
    with torch.no_grad():                       # 分量 3: 最优点等式
        opt_t = q_jt(s, joint_onehot(act, n_actions)) - v_net(s)
    l_opt = ((sum_chosen(agent_qs, obs, act) - opt_t) ** 2).mean()
    pert = act.clone()                          # 分量 4: 逐智能体扰动
    for i in range(N):
        pert[:, i] = (act[:, i] + 1 + torch.randint(
            0, n_actions - 1, (B,), device=act.device)) % n_actions
    with torch.no_grad():
        margin = q_jt(s, joint_onehot(pert, n_actions)) - v_net(s)
    l_nopt = (torch.clamp(sum_chosen(agent_qs, obs, pert) - margin, min=0.0) ** 2).mean()
    return l_td + l_td2 + l_opt + l_nopt

解读：逐行核对 detach 与梯度路径。（1）分量 1、2 的目标侧整体在 no_grad 内构造，只更新 Qjt 与 V；这正是时序差分自举的纪律要求。（2）分量 3 的 opt_t 由 no_grad 包裹，梯度只经 sum_chosen 流向个体网络；若漏掉包裹，个体价值会被"拉向一个自己参与定义的目标"，等式约束退化为自动满足的恒等式。（3）分量 4 用 % n_actions 的偏移构造每个智能体的邻域动作，+1 保证扰动后的动作与原动作不同，避免采样到自身导致违例恒为零；clamp(..., min=0) 使满足不等式的样本贡献零梯度。（4）返回四个分量的和，权重暂取 1；如需分权重，把 λ 作为函数参数相乘即可，梯度裁剪挂在外层优化步。

片段 3：IGM 穷举验证

def verify_qtran(agent_qs, q_jt, v_net, obs, s, n_actions, atol=1e-4):
    """小规模穷举核查: (C1) 不等式, (C2) 最优点取等, argmax 一致性。"""
    from itertools import product
    N = len(agent_qs)
    with torch.no_grad():
        qs = [net(obs[:, i]) for i, net in enumerate(agent_qs)]      # 各 (1, nA)
        sums, joints = [], []
        for js in product(range(n_actions), repeat=N):               # 全部联合动作
            sums.append(sum(float(qs[i][0, a]) for i, a in enumerate(js)))
            oh = joint_onehot(torch.tensor(js).unsqueeze(0), n_actions)
            joints.append(float(q_jt(s[:1], oh)))                    # 逐动作联合价值
        v0 = float(v_net(s[:1]))
        c1 = all(x - q + v0 >= -atol for x, q in zip(sums, joints))
        best_s = int(torch.tensor(sums).argmax())
        best_j = int(torch.tensor(joints).argmax())
        c2 = abs(sums[best_j] - joints[best_j] + v0) <= atol
    # C1 与 C2 成立时两个 argmax 应重合; 训练早期允许违例, 作为进度指标
    return {"c1": c1, "c2": c2, "argmax_match": best_s == best_j}

解读：验证函数把充分条件逐条落到可执行的断言上。（1）穷举全部 |A|N 条联合动作，小任务（33 = 27 条以内）瞬时完成；测试对象只取单个状态样本，避免代价累积。（2）argmax_match 是最有信息量的指标：训练早期三段损失尚未平衡时它通常为假，收敛后应翻转为真；把它按时序记录，可以观察"约束逐步成立"的动力学，比单看总损失更直观。（3）该测试与第 006、007 章的验证共享同一套 joint_onehot 编码约定，三代方法使用同一工具，横向对比的代价极低。

常见坑

  • 分量 3 漏掉 detach。症状：Lopt 迅速降到接近零但回报无改善。原因：等式两侧相互追随形成恒等式，约束没有把个体价值拉向任何目标。修复：核对目标侧是否全部在 no_grad 或 .detach() 保护内，并观察 Lopt 与 IGM 验证指标是否同步改善。
  • 邻域扰动采到自身动作。症状：Lnopt 恒为零，约束形同虚设。原因：扰动公式没有排除原动作（例如直接取模后仍等于原动作）。修复：扰动步长取 1 至 n_actions−1 之间的随机值再取模，并从分布上断言扰动动作与原动作不等。
  • λ 权重失衡。症状一：λnopt 过大时个体价值被压到极低（到处违例的错觉消失但表达力丧失）；症状二：λopt 过大时整条 IGM 约束松弛失效。原因：约束项与建议项尺度的竞争。修复：以等权起步，用 IGM 验证指标的翻转时刻作为调权依据，调整幅度按 2 的幂次逐档进行。
  • V 网络退化为常数。症状：Qjt − V 与 Qjt 形状一致，约束等价于"Σ Qi 在最优处等于平移后的联合价值"，平移量失效。原因：Ltd2 权重过低或 V 的梯度被裁剪吞噬。修复：单独打印 V 的输出方差与更新前后差值，确认其随状态变化。
  • 把行为动作当 ū 后不复查。症状：训练中期回报停滞，IGM 验证中 c1 频繁违例。原因：探索率较高时替身质量差，等式约束长期施加在次优点上。修复：让替身随探索率衰减一起提纯；或改用 QTRAN-alt 的反事实构造，把对 argmax 定位的依赖替换为对单智能体动作替换的鲁棒约束。

练习与思考

  1. 给定两个智能体各两个动作，个体价值 Q1 = [1, 2]，Q2 = [0, 3]，联合价值 Qjt = [[0, 1], [2, 5]]，V = 0。逐条核查 (C1) 与 (C2)，指出 argmax 是否一致。★
    提示
    Σ Qi 矩阵为 [[1, 4], [2, 5]]；逐项差值为 [[1, 3], [0, 0]]，全部非负且在最优点 (1, 1) 处取等，C1、C2 成立，两个 argmax 一致为 (1, 1)。
  2. 把 λnopt 从 1 提高到 10，在含局部牺牲的任务上预测 IGM 验证指标的翻转时刻与最终回报的变化。★
    提示
    惩罚加强使 C1 更快成立、翻转提前，但个体价值被过度压制，联合最优所在的动作组合可能被一起压平，最终回报可能下降。该实验用于校准"约束达成"与"表达保留"的平衡点。
  3. 证明：任何满足单调分解的 {Qi} 与 Qjt = fs(Qi) 都可以通过选择适当的 V 满足 (C1)(C2)，从而说明 QTRAN 的可行集包含 QMIX 族。★★
    提示
    取 ū 为联合最优，令 V 使 (C2) 在 ū 处取等；由单调性，任意 u 处 f 的值不低于单坐标替换链起点对应值，可推出 (C1)。逐坐标替换论证与第 007 章充分性证明同构。
  4. 设计实验：在"掩护牺牲"任务上比较 VDN、QMIX、QTRAN-base、QTRAN-alt 四种方法。给出穷举联合最优作为上界对照、报告的指标（回报、IGM 验证通过率、约束满足时刻）与预期排序。★★
    提示
    预期回报排序：QTRAN 系列高于 QMIX 高于 VDN，其中 QTRAN-alt 验证通过率更高（不依赖 argmax 替身）；QMIX 受单调上界限制在牺牲回合比例上显著落后。指标缺失时用随机策略回报作下界锚点。
  5. 设计题：把邻域扰动从"全体智能体各扰动一次"改为 QTRAN-alt 式的反事实构造（固定其他智能体动作、只替换单个智能体），写出新的 Lnopt 计算方案并论证它为何降低对 ū 定位的依赖。★★★
    提示
    对每个智能体 i 构造 (ū−i, u′i) 型动作集合，第 i 个个体价值单边变化，约束只需"联合最优的坐标不动"这一局部性质，不需要全局 argmax 的精确位置；代价是每组替代动作的前向次数随 N 线性增长。

小结

  • QTRAN 直接用变换不等式 (C1)(C2) 刻画 IGM，占优性与最优点取等两条合起来保证 argmax 分解，不再假设混合函数的单调性。
  • 四分量损失各司其职：两项时序差分训练 Qjt 与 V，Lopt 拉平最优点，Lnopt 铰链惩罚邻域违例；detach 位置决定每条梯度的来源。
  • 两处近似（最优点替身、邻域采样）是算法对超参敏感的来源；穷举验证是软约束方法的强制工程环节。
  • 三代对照：VDN 加性、QMIX 单调、QTRAN 变换不等式，可行集逐代扩大，实现与调参成本同步上升。
  • 下一章转向策略梯度路线：COMA 反事实基线实现，用集中式评论家与逐动作边际化消除信用分配中的偏差。
