第 086 章：信息瓶颈与注意力通信

从信息论视角审视通信信道：信息瓶颈目标 min I(X;Z) − βI(Z;Y) 给出压缩与保真的权衡，变分近似把它变成可训练损失；注意力机制则是"选择性收发"的具体实现，注意力熵与温度控制选择的稀疏程度。

  • 主题：信息论通信 / 注意力消息聚合
  • 关键公式：信息瓶颈目标 min I(X;Z) − βI(Z;Y)、变分界 E[KL(q(z|x)‖p(z))] − βE[log q(y|z)]、注意力 α = softmax(QKT/√d)
  • 预计学时：60 分钟
  • 前置章节：第 085 章

学习目标

  • 理解互信息（Mutual Information）的定义与信息瓶颈（Information Bottleneck, IB）目标的推导直觉。
  • 掌握变分信息瓶颈（Variational Information Bottleneck, VIB）的可训练损失形式，能解释 KL 项与预测项各自的作用。
  • 理解多头注意力（Multi-Head Attention）的消息聚合机制，掌握查询、键、值三路投影的含义。
  • 学会用注意力温度与熵正则调节消息选择的稀疏程度，并监控选择退化的病态。
  • 能设计实验区分"信息压缩"与"注意力选择"两类机制各自的贡献。

背景与动机

第 085 章用代价项约束通信量，但代价函数只回答"发了多少"，回答不了"发的内容里有多少与任务相关"。信息论提供了第二个视角：把消息看作观测的压缩表示，压缩率与任务保真度构成一对矛盾。信息瓶颈目标把这对矛盾写成单一目标函数，变分近似再把它化为可反向传播的损失，这条路径使得"每条消息该带多少信息"成为可以计算的设计量。

注意力机制从另一侧解决同一问题：接收端不再等权聚合所有邻居消息，改为按相关性加权，相关性由查询与键的内积即时计算。注意力在 CTDE 系统中的位置很灵活，既可用在 critic 的观测编码（第 015 章的路线），也可用在执行期的消息聚合。本章把两条路线放进同一框架：注意力权重解释为消息的带宽分配，信息瓶颈解释为分配总量的预算。

核心原理

1. 互信息与瓶颈目标

互信息度量两个随机变量共享的信息量，等价于联合分布与边缘分布乘积之间的 KL 散度：

I(X; Z) = Σx,z p(x, z) log [ p(x, z) / (p(x) p(z)) ] = DKL( p(x, z) ‖ p(x) p(z) ) I(X;Z) ≥ 0，等于零当且仅当 X 与 Z 独立；Z 为 X 的确定性函数时 I(X;Z) = H(Z) ≤ H(X)，等号当且仅当该函数可逆

信息瓶颈把编码 z 视为信息的"瓶颈"：希望 z 尽量少携带输入 x 的细节（压缩），又尽量多保留与目标 y 有关的信息（保真）。目标函数写作：

minq(z|x) LIB = I(X; Z) − β · I(Z; Y) β 是压缩与保真的交换率：β 越大越保真，越小越压缩；与率失真理论（Rate-Distortion Theory）中的拉格朗日乘子同源

把 X 取为邻居的观测、Y 取为自身的动作或任务回报，IB 目标就变成通信设计原则：消息只保留与决策相关的摘要，其余细节全部丢弃。

2. 变分信息瓶颈的可训练形式

IB 目标中的两项都依赖未知分布，无法直接计算。变分方法给出可训练的两个界：I(X; Z) 被后验与先验的 KL 散度上界，I(Z; Y) 被对数似然期望下界，合并后得到负证据下界（Evidence Lower Bound, ELBO）形式的损失：

LVIB = Ex[ DKL( q(z|x) ‖ p(z) ) ] − β · E(x,y)[ log qθ(y | z) ] q(z|x) 取对角高斯，p(z) 取标准正态；log qθ(y|z) 用一个小解码器（或策略头）估计

对角高斯情形下 KL 项有闭式解，逐维计算即可（见代码片段）。采样用重参数化（Reparameterization）：z = μ + σ ⊙ ε，ε 为标准正态噪声，使采样操作可反向传播。两个系数的行为值得记住：KL 项过强会引发后验坍缩（Posterior Collapse），编码器停止使用潜在变量 z，消息退化为先验采样，接收端无法获得信息；预测项过强则压缩消失，信道量级回落到第 085 章的普通连续消息。

数值算例（KL 项的量级感）。取二维潜在消息，q(z|x) 为对角高斯，第一维 (μ, σ²) = (0.5, 0.25)、第二维 (−0.2, 4)。闭式解 0.5·Σ(μ² + σ² − ln σ² − 1) 逐维给出 0.443 与 0.827，合计约 1.27 nat（数值经程序核对）。两个方向都在抬高 KL：均值偏离零由 μ² 项惩罚，方差偏离一由 σ² − ln σ² − 1 项惩罚，该项在 σ² = 1 处取零。把某维标准差压到 0.01，该维贡献升到约 4.1 nat；编码器为压低 KL 会把 σ 拉回接近 1、μ 拉回接近 0，压缩与保真的张力直接体现在这两个数字上。

3. 注意力机制：消息选择的实现

注意力把接收端的聚合权重从固定（等权均值）变为数据驱动。查询向量 Q 来自自身特征，键 K 与值 V 来自各邻居消息，缩放点积注意力为：

αij = softmaxj( qiT kj / √d )，输出i = Σj ≠ i αij vj d 是键维度，缩放 √d 使内积方差不随维度增长；多头并行计算再拼接，捕捉多种相关模式

与 IB 的联系：注意力权重 αij 是对邻居消息的信息预算分配，熵 H(αi·) = −Σj αij log αij 度量分配的分散程度。熵接近 log(N − 1) 时退化为等权均值，与不用注意力等价；熵接近零时聚焦单一邻居，一旦该邻居提供的信息有偏，决策随之出错。典型做法是给熵加一个小的下界奖励或正则项，让选择保持可解释的稀疏度。

4. 两类机制的评估与消融

压缩与选择是两种不同的归纳偏置，消融要分别验证：

消融设置验证目标预期差异
VIB 编码器对普通编码器压缩带来的泛化收益VIB 在观测噪声上更强，干净环境下差异小
注意力对均值聚合选择带来的性能收益邻居数量多或信息异质时差距显著
熵正则系数扫描稀疏度的最优工作点回报随系数先升后降，最优点附近熵介于两极端之间
潜在维度扫描瓶颈容量的影响容量过小欠拟合，过大压缩收益消失

互信息本身难以精确估计，评估时用两类代理指标：消息与动作的条件熵差 H(a) − H(a | m)，以及消息在各维度的经验方差。绝对数值不必精确，趋势与消融差值提供可用结论。

实现思路与设计

把 VIB 编码器与注意力聚合器组合在通信模块中，数据流为：观测与隐藏状态进入 VIB 编码器，得到潜在消息 z 及其分布参数；消息广播后，接收端多头注意力聚合，输出与观测拼接进入策略与价值网络。训练循环同时优化任务损失与 VIB 损失：

  1. 前向：编码器输出（z, μ, log σ²），消息 z 广播并聚合。
  2. 损失：L = LRL + λKL · KL(q(z|x) ‖ p(z)) − λH · H(α)。
  3. 监控：KL 逐维分解、消息经验方差、注意力熵、每步比特数。
  4. 调参：先固定注意力（等权）调 KL 系数，再放开注意力调熵系数，两个旋钮分开扫描。

与第 085 章的差异点：085 章的价格 β 约束消息的"数量"，本章的 KL 与熵正则约束消息的"信息含量与分配形状"；两者的损失项可以直接叠加，形成"数量加质量"的双重约束。

信息瓶颈参数起点

参数默认值作用取值依据
潜在消息维度8瓶颈容量低于观测维度一个量级，强制压缩
KL 系数 λKL0.05压缩强度量级 0.01–0.1，先低后高逐步增加以防坍缩
注意力头数4相关模式数邻居数 4–8 时 4 头覆盖主要模式
键维度 d16相似度分辨率与消息维度匹配，缩放因子 √16 = 4
注意力温度1.0选择尖锐度温度小于 1 更聚焦，训练后期可退火
熵正则系数 λH0.01保持选择分散只在出现单点聚焦病态时启用
设计决策：为什么 KL 系数要从低位逐步升高？

训练初期编码器尚未提取到有效信息，此时强 KL 项会让它直接放弃使用潜在变量（后验坍缩），且坍缩后梯度微弱、难以恢复。从 0.01 量级起步随训练步数线性升到目标值，给编码器先建立信息通路、后收紧瓶颈的机会。这种"先松后紧"的调度是变分训练对抗坍缩的标准手段。

关键代码与解读

片段 1：变分信息瓶颈编码器

import torch
import torch.nn as nn

class VIBMessageEncoder(nn.Module):
    """变分信息瓶颈编码器：把观测与隐藏状态压成低维消息。"""
    def __init__(self, obs_dim=32, hidden_dim=64, msg_dim=8):
        super().__init__()
        self.shared = nn.Sequential(nn.Linear(obs_dim + hidden_dim, hidden_dim),
                                    nn.ReLU())
        self.mu = nn.Linear(hidden_dim, msg_dim)        # 后验均值
        self.logvar = nn.Linear(hidden_dim, msg_dim)    # 后验对数方差

    def forward(self, obs, hidden):
        h = self.shared(torch.cat([obs, hidden], dim=-1))
        mu, logvar = self.mu(h), self.logvar(h)
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)                     # 重参数化：采样可反传
        z = mu + std * eps
        return z, mu, logvar

def vib_loss(rl_loss, mu, logvar, log_q_y, kl_coef=0.05):
    """负 ELBO 组合损失：KL 项压缩消息，预测项保留任务信息。"""
    # 对角高斯对标准正态的 KL 有闭式解：逐维累计后取批次平均
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp(), dim=-1).mean()
    # 预测项用 z 预测动作的对数似然，替代不可直接计算的 I(Z;Y)
    nll = -log_q_y.mean()
    return rl_loss + kl_coef * kl + nll, kl

解读：（1）重参数化把随机性转移到与参数无关的 ε 上，采样节点因此可以求导；若用 torch.distributions 的 sample，需要 rsample 才有同等效果。（2）KL 闭式解来自两个对角高斯之间散度的逐维求和，代码里三个项分别对应 logvar、mu² 与 exp(logvar)，与公式逐项对应。（3）函数返回 kl 标量供监控：当 kl 在训练早期迅速趋近零时即为后验坍缩信号，调用方可以自动降低 kl_coef。（4）预测项用策略头对 z 的对数似然，与任务损失共享解码器，避免单独训练一个可能与策略目标脱节的解码器。

片段 2：多头注意力消息聚合

import torch
import torch.nn as nn
import torch.nn.functional as F

class AttnAggregator(nn.Module):
    """多头注意力聚合：查询来自自身特征，键与值来自其余智能体的消息。"""
    def __init__(self, feat_dim=64, msg_dim=16, heads=4):
        super().__init__()
        self.heads = heads
        self.q = nn.Linear(feat_dim, msg_dim * heads)   # 查询投影
        self.k = nn.Linear(msg_dim, msg_dim * heads)    # 键投影
        self.v = nn.Linear(msg_dim, msg_dim * heads)    # 值投影

    def forward(self, feat, msgs, temperature=1.0):
        b, n, _ = msgs.shape
        q = self.q(feat).view(b, n, self.heads, -1)     # 拆头：每个头独立打分
        k = self.k(msgs).view(b, n, self.heads, -1)
        v = self.v(msgs).view(b, n, self.heads, -1)
        logits = torch.einsum("bnhd,bmhd->bhnm", q, k) / temperature
        # 屏蔽自身消息：对角线置为负无穷再 softmax，避免自评高分
        eye = torch.eye(n, dtype=torch.bool, device=msgs.device)
        logits = logits.masked_fill(eye.view(1, 1, n, n), float("-inf"))
        alpha = F.softmax(logits, dim=-1)
        # 注意力熵：接近均匀说明选择失效，接近零说明过度聚焦
        ent = -(alpha * torch.log(alpha + 1e-8)).sum(dim=-1).mean()
        out = torch.einsum("bhnm,bmhd->bnhd", alpha, v)
        return out.reshape(b, n, -1), ent

解读：（1）查询来自自身特征、键值来自邻居消息，这一非对称设计让"我需要什么"驱动"我关注谁"；若查询也来自消息，接收端就失去表达需求的能力。（2）温度参数在训练后期可从 1.0 退火到 0.5，让选择逐渐尖锐；温度趋近零会让 softmax 饱和、梯度消失，不建议低于 0.2。（3）返回熵供损失函数使用：加入 −λH·H(α) 的奖励项即可把熵推离零，抑制单点聚焦；熵贴近上限时该项梯度小，无需额外干预。（4）掩码对角线用 view(1, 1, n, n) 对齐 (b, h, n, m) 四个维度，这是多头实现中最常见的形状错误来源。

常见坑

  • KL 系数过大导致后验坍缩：消息方差趋近先验、均值信息微弱，接收端表现与零通信无异。症状：KL 项快速趋零且任务回报停滞。修复：系数从低位起步逐步升高，监控逐维 KL 分布。
  • β 的量纲混淆：VIB 的 β 依赖对数似然与 KL 的量纲，换任务时数值需重标定，直接套用文献数值常失效。修复：先测两项的初始量级比，再设定系数。
  • 注意力矩阵显存爆炸：全连接注意力张量形状 (B, H, N, N) 随智能体数平方增长，N 上百时显存不可承受。修复：邻域内注意力或稀疏注意力，把复杂度降回 O(N·k)。
  • 温度设置过小：softmax 饱和后注意力近似 one-hot，梯度消失，选择无法随训练调整。修复：温度下限 0.2，配合熵监控。
  • 用小样本互信息估计下结论：基于分箱或 MINE 的估计在高维小样本下偏差大，掩盖真实趋势。修复：以消融差值与条件熵代理为主，互信息估计只作定性参考。

练习与思考

  1. 证明：当 Z 是 X 的确定性函数时 I(X; Z) = H(Z)（可逆时等于 H(X)）；当 Z 与 X 独立时 I(X; Z) = 0。说明这两个极端在通信设计中的对应物。★
    提示
    可逆的确定性函数对应"无压缩直传"（不可逆时互信息降为 H(Z)，属于有损压缩），独立对应"信道断开"。IB 目标在这些极端之间寻找工作点。
  2. 把变分损失中的 kl_coef 从 0.05 提高到 0.5，预测 KL 值、消息方差、任务回报与注意力熵的变化轨迹。★★
    提示
    KL 被强行压低，消息方差趋近先验（后验坍缩），回报下降；注意力熵可能上升（消息无差异可分辨）。验证：同一组种子对照两档系数。
  3. 推导：对角高斯 q(z|x) = N(μ, σ²I) 与标准正态先验之间的 KL 散度闭式解，并说明每一项的符号含义。★★
    提示
    DKL = 1/2 Σ (μ² + σ² − log σ² − 1)。μ² 惩罚均值偏离零，σ² 与 −log σ² 之和惩罚方差偏离 1，恰在 σ = 1 处取最小值 0。
  4. 设计消融实验：在 8 智能体协作任务上比较（VIB + 注意力）、（普通编码器 + 注意力）、（VIB + 均值聚合）、（普通编码器 + 均值聚合）四组，报告两因子的主效应与交互效应。★★★
    提示
    这是 2×2 因子设计，主效应为压缩与选择的独立贡献，交互效应说明两者是否互补。评估用第 082 章的 IQM 管道，种子数不少于 10。
  5. 实现注意力熵的实时监控，并设计一个自动调节方案：当熵低于下限时临时增大 λH，高于上限时置零。★★★
    提示
    类似第 085 章预算控制器的对偶思路：λH 按熵偏差方向更新，带上下界与平滑。验证时记录 λH 轨迹与熵轨迹的相位关系。

小结

  • 信息瓶颈用单一目标统一压缩与保真：min I(X;Z) − βI(Z;Y)，β 是两者的交换率。
  • 变分近似把 IB 化为可训练损失：KL 上界加负对数似然，重参数化保证采样可反传；KL 系数调度是防坍缩的关键。
  • 注意力是消息选择机制：查询来自自身、键值来自邻居，温度与熵正则控制选择的稀疏度。
  • 注意力熵贴近上限等同等权均值，贴近零导致过度聚焦；两类病态都要监控。
  • 压缩与选择是两种归纳偏置，用 2×2 因子消融分别验证其主效应与交互效应。
  • 下一章把通信结构显式化：图通信与对手建模，讨论以图为先验的稀疏消息通路与对手行为预测。
