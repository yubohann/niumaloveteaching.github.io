第四篇 · 高级机制与研究专题

第 078 章：内在奖励与好奇心驱动

稀疏奖励下让探索有方向：本章讲清基于计数的奖励、内在好奇心模块（Intrinsic Curiosity Module, ICM）与随机网络蒸馏（Random Network Distillation, RND）三种内在奖励的构造，再讲多智能体共享新奇信号时的分配与归一化，以及与集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）的衔接。

  • 主题：探索机制 / 预测误差与新奇度
  • 关键公式：ri(s) = ‖f(s) − f̄(s)‖2，r总 = re + βri
  • 预计学时：60 分钟
  • 前置章节：第 077 章

学习目标

  • 理解内在奖励的作用机制：把探索收益从稀疏的外在奖励中解耦，用可即时计算的代理信号引导行为。
  • 掌握基于计数、ICM 与 RND 三类方法的奖励构造与适用条件，说明"预测误差"与"访问频次"两种新颖度度量的关系。
  • 理解随机动态下的噪声吸引问题，掌握特征分离与去随机化两类修复思路。
  • 能实现共享新奇模块与团队奖励归一化两个片段，解释多智能体共享信号时的重复计数问题。
  • 能设计实验：无内在奖励、计数奖励、RND 三组对照，加共享与个体模块、β 扫描的消融。

背景与动机

协作任务的奖励常常稀疏：只有完成整套配合才获得回报，中间过程没有信号。随机探索在状态空间较大时命中稀疏奖励的概率极低，训练实际上无法启动。内在奖励提供即时的探索信号：访问得越少的状态，奖励越高，智能体于是被"好奇心"牵引着覆盖新的区域。这类奖励不改变任务定义，只改变探索路径，任务完成后外在奖励仍占主导。

多智能体场景让新奇信号具有公共品性质：一台机器人探索过的区域对其他机器人不再新奇，各自独立计算新奇度会重复访问同一区域。共享新奇模块让团队的新奇度按联合访问量衰减，等效于隐式的分工探索；代价是信号分配与归一化更复杂。这与第 064 章的信息增益奖励同源不同层：那里奖励来自任务本身的不确定性下降，这里奖励来自状态空间覆盖。

核心原理

本节先讲三类内在奖励的构造，再讲多智能体分配与与 CTDE 的衔接。

1. 基于计数的奖励

访问计数 N(s) 给新颖状态更高奖励，常用形式 ri(s) = 1/√N(s)。平方根的衰减速率是从"计数探索"的理论分析中得到的，保证对每个状态的总投入次线性增长而覆盖持续扩展。连续状态空间无法精确计数，用密度模型或分桶离散化近似伪计数。

ri(s) = β / √N(s) N(s) 为状态访问次数；伪计数方法用密度估计替代精确计数

2. ICM：预测误差奖励

训练前向模型预测下一状态的特征表示，预测误差即新奇度。直接用原始状态做预测会被不可预测的噪声主导（噪声吸引问题），因此先用逆向模型学习特征：从 (s, s′) 预测动作 a，使特征保留可控信息、丢弃与动作无关的随机细节。内在奖励 = 前向模型在特征空间的预测误差。

ri = (η/2)·‖φ(s′) − f(φ(s), a)‖2，Linv = −log q(a | φ(s), φ(s′)) φ 为特征编码器；前向误差给奖励，逆向误差训练 φ；两项联合优化

3. RND：随机网络蒸馏

固定一个随机初始化的目标网络 f̄，训练预测网络 f 拟合其输出，两者在状态上的差异即新颖度。目标网络输出是确定函数，与状态是否随机无关，天然规避噪声吸引；预测误差随访问次数增加而下降，行为与伪计数一致。实现只需两个前馈网络，是当前稀疏奖励任务中最常用的基线。

ri(s) = ‖fθ(s) − f̄(s)‖2，Lrnd = ri(s)（对 θ 优化，f̄ 冻结） 奖励即损失：预测得越准，该状态越不新奇；目标网络输出做归一化稳定尺度

4. 多智能体分配与 CTDE 衔接

共享新奇模块时，团队奖励取联合状态下模块输出的单一数值，一台智能体的探索立刻降低全体后续的新奇奖励，形成"先到先得"的分工激励。缺点是无法反映个体贡献，需要反事实基线或按贡献比例分配。与 CTDE 的衔接有两种模式：评论家在共享奖励上评估联合动作的长期价值；技能或子目标的探索信号由集中式模块统一生成，低层执行只消费局部观测。执行期除策略网络外不保留好奇心模块。

5. 数值算例：计数衰减、归一化与退火

计数奖励 1/√N：同一点的第 1、4、100 次访问分别获得 1、0.5、0.1。对同一状态的前 N 次访问累计奖励约 2√N，N=100 时约 20，N=400 时约 40，累计投入随访问次数的平方根增长，覆盖的边际成本递减但始终为正。

归一化算例。RND 原始误差 0.8、运行均值 0.5、运行标准差 0.2 时，归一化奖励为 (0.8−0.5)/0.2=1.5；取 β=0.01 后对总奖励的贡献约 0.015，与量级 1 的外在奖励相比约 1.5%。模块训练使原始误差随时间下降，运行均值同步下滑，归一化后的探索权重保持稳定，这是归一化存在的意义。

退火算例。β 从 0.01 起每 1e5 步减半：2e5 步后为 0.0025，4e5 步后为 6.25e-4。若任务奖励在约 3e5 步后稳定获取，退火节奏与之匹配；保留不退火时，后期残留奖励继续牵引策略离开高回报区域，表现为成功率平台偏低而覆盖熵偏高。

解读：三组数字分别给出覆盖成本、尺度稳定与探索退出的定量感觉。复现时训练前期以首次获得外在奖励的步数与覆盖熵为关注指标，中后期切换为任务回报与退火曲线，用单组指标贯穿全程会把探索期与利用期的结论混在一起。

实现思路与设计

训练流水线在标准 CTDE 之上插入好奇心模块：状态先经模块产生内在奖励，与环境奖励合成后再进入回报计算。

实验设计

  1. 对比基线：无内在奖励、计数式伪计数奖励、RND；随机网络初始化噪声作为控制组。
  2. 消融设置：共享模块与个体模块、β ∈ {0.001, 0.01, 0.1}、ICM 逆向模型开/关、归一化开/关。
  3. 评价指标：首次获得外在奖励的步数、状态覆盖熵、达到目标成功率的步数、后期回报（探索是否干扰收敛）。
  4. 统计方式：探索指标方差大，至少 10 个种子并报告分位数。
设计决策：为什么内在奖励要按运行标准差归一化

RND 奖励随模块训练迅速衰减，早期数值可能是后期的百倍；不归一化等价于 β 在时间上不断变化，探索强度失控。运行标准差归一化把奖励折算为"相对近期"的尺度，使 β 的语义在训练全程稳定。跨智能体共享归一化统计量保证团队内权重一致，个体统计会导致个别智能体探索强度失衡。

与第 077 章的差异：技能发现的内在奖励指向状态与技能的互信息，本章的内在奖励指向纯粹的新奇度；前者服务于复用，后者服务于覆盖。

对比分析：四类探索信号的适用边界

信号新奇度来源随机环境鲁棒性实现代价适用条件
无内在奖励无不适用最低奖励较密集
计数式伪计数访问频次中等低到中（需要密度模型）状态可离散化
ICM特征空间预测误差高（逆向特征）中动作对状态影响显著
RND随机网络输出差异高（确定目标）低高维观测、含噪环境

选择依据是环境噪声水平与实现预算：状态空间可离散且噪声低时计数式直观可控；高维连续观测下 RND 以较低实现代价获得稳定表现；动作对状态的影响弱时 ICM 的逆向特征收益下降，可与 RND 并联形成两组参照，单一信号无法区分退化来源。

多机共享信号的对齐细节：共享模块要求所有智能体的观测编码器保持一致，否则同一状态在不同智能体处的误差量级不同，归一化统计量失去意义。工程上把观测编码器并入共享策略主干，好奇心头单独挂在主干的输出之上，两处参数各自更新互不覆盖。

监控面板把原始误差、运行均值与归一化奖励三条曲线并列，任何一条单调趋零都说明探索信号即将耗尽，应触发 β 的检查。模块重置或预训练权重替换时，归一化统计量必须同步清零，否则旧统计量会把新模块的误差错误地压缩。

关键代码与解读

片段 1：RND 奖励与损失

import torch
import torch.nn as nn

class RND(nn.Module):
    """随机网络蒸馏：冻结目标网络与可训练预测网络。"""
    def __init__(self, obs_dim, out_dim=128):
        super().__init__()
        self.target = nn.Sequential(nn.Linear(obs_dim, out_dim), nn.ReLU(),
                                    nn.Linear(out_dim, out_dim))
        self.pred = nn.Sequential(nn.Linear(obs_dim, out_dim), nn.ReLU(),
                                  nn.Linear(out_dim, out_dim))
        for p in self.target.parameters():
            p.requires_grad_(False)          # 目标网络全程冻结

    def forward(self, obs):
        with torch.no_grad():
            feat_t = self.target(obs)
        feat_p = self.pred(obs)
        error = (feat_p - feat_t).detach().pow(2).mean(dim=-1)
        # 预测损失与奖励同源：拟合越准，后续该状态奖励越低
        loss = (feat_p - feat_t).pow(2).mean()
        return error, loss

解读：奖励取误差的停止梯度版本，奖励用于驱动策略，损失单独用于驱动预测网络，两者共用一次前向但梯度路径分开。目标网络必须保持固定：周期性更新会使新奇度基准漂移，模块与策略的目标同时移动。误差在特征维度上取均值以消除维度依赖。

片段 2：ICM 的前向与逆向损失

import torch
import torch.nn as nn
import torch.nn.functional as F

class ICM(nn.Module):
    """内在好奇心模块：特征编码、前向模型的误差给奖励。"""
    def __init__(self, obs_dim, act_dim, feat_dim=64):
        super().__init__()
        self.enc = nn.Sequential(nn.Linear(obs_dim, feat_dim), nn.ReLU())
        self.fwd = nn.Sequential(nn.Linear(feat_dim + act_dim, feat_dim),
                                 nn.ReLU(), nn.Linear(feat_dim, feat_dim))
        self.inv = nn.Sequential(nn.Linear(2 * feat_dim, 64), nn.ReLU(),
                                 nn.Linear(64, act_dim))

    def forward(self, s, s_next, a_onehot):
        f1, f2 = self.enc(s), self.enc(s_next)
        pred_f2 = self.fwd(torch.cat([f1, a_onehot], dim=-1))
        # 前向误差（停止梯度）作为内在奖励
        r_int = 0.5 * (pred_f2 - f2).detach().pow(2).sum(dim=-1)
        # 逆向模型训练特征：让特征保留可预测动作的信息
        logits = self.inv(torch.cat([f1, f2], dim=-1))
        loss_inv = F.cross_entropy(logits, a_onehot.argmax(dim=-1))
        loss_fwd = 0.5 * (pred_f2 - f2.detach()).pow(2).sum(dim=-1).mean()
        return r_int, loss_fwd + 0.2 * loss_inv

解读：前向损失的预测目标是 f2.detach()，避免特征编码器被前向误差拉向"让所有状态难预测"的方向，编码器只由逆向损失训练。逆向权重 0.2 平衡两项量级。特征空间预测误差天然忽略随机噪声，因为噪声不影响动作的可预测性，这是 ICM 应对噪声吸引的核心机制。

片段 3：共享新奇与团队归一化

import torch

class TeamNoveltyNorm:
    """跨智能体共享的奖励归一化统计量。"""
    def __init__(self, momentum=0.99, eps=1e-8):
        self.mean = 0.0
        self.var = 1.0
        self.m = momentum
        self.eps = eps

    def __call__(self, bonus):
        x = float(bonus)                       # 团队合并后的单一新奇度
        delta = x - self.mean
        self.mean = self.mean + (1 - self.m) * delta
        self.var = self.m * self.var + (1 - self.m) * delta ** 2
        return (x - self.mean) / (self.var ** 0.5 + self.eps)

解读：共享统计量意味着归一化后的奖励反映"相对团队近期体验的新奇程度"，个体之间尺度可比，避免个别智能体探索强度失衡。衰减率 0.99 对应约百步的有效窗口，窗口过短会让奖励快速漂移，过长则适应不了模块训练导致的误差衰减。奖金加在团队奖励上再由评论家分配，或按各智能体对联合状态的责任度加权分摊。

常见坑

  • 噪声吸引：环境含随机噪声时预测误差长期偏高，智能体守在噪声源附近。修复：用 ICM 特征分离或改用 RND 的确定目标网络。
  • β 过大压过任务奖励：策略沉迷探索，任务成功率长期为零。修复：按"任务奖励出现的步数区间"扫描 β 并设置退火。
  • 好奇心模块更新过快：预测网络迅速拟合，探索信号过早消失。修复：降低模块学习率或降低更新频率。
  • 个体模块重复探索：每个智能体维护独立模块，团队反复访问同一区域。修复：共享模块或共享访问统计，配合职责分工。
  • 归一化统计混入评测：评测阶段继续更新统计量，指标被训练分布污染。修复：评测时冻结归一化参数或关闭内在奖励。

练习与思考

  1. 状态被访问 1、4、100 次时，按 1/√N 计算内在奖励，说明序列的衰减特征与总和的有界性。★
    提示
    奖励为 1、0.5、0.1；对同一状态重复访问的累计奖励按 √N 增长，单状态总投入的边际递减。
  2. 把 β 退火去掉（全程 0.01），预测训练后期任务回报与覆盖熵的变化。★★
    提示
    后期模块误差已小，残留奖励仍牵引策略离开任务高回报区域，表现为成功率平台偏低、覆盖熵偏高。
  3. 推导：证明 RND 的期望奖励关于访问频次单调递减，并说明它与伪计数 1/√N 的近似关系。★★★
    提示
    预测网络对频繁访问样本的拟合误差随有效样本数下降；线性拟合下误差与 N−1 相关，给出与 1/√N 类比的量级讨论。
  4. 设计实验：共享 RND 与个体 RND 两组，统计 1e6 步内的区域覆盖次数分布与首达成功步数，解释分歧来源。★★★
    提示
    共享组覆盖面更广、单区域重复访问少；个体组可能在同一区域重复刷奖励，首达步数更长。
  5. 某状态被访问 100 次与 400 次，用前 N 次累计奖励约 2√N 的近似计算两种情况的总奖励；再说明若不做平方根衰减（改用常数奖励），单状态的总投入为何无界。★★
    提示
    累计奖励约 20 与 40；常数奖励下每次访问收益不变，策略可以无限次刷同一状态，总收益随步数线性增长而不收敛，平方根衰减是覆盖行为收敛的关键。

小结

  • 内在奖励把探索收益解耦为即时信号，计数式、ICM 与 RND 分别以访问频次与预测误差度量新奇度。
  • ICM 用逆向模型学习可控特征以避免噪声吸引，RND 用冻结随机目标网络获得确定的新奇基准。
  • 多智能体共享新奇模块使探索具有公共品性质，一台智能体的访问降低全体的新奇奖励，形成隐式分工。
  • 奖励归一化按运行统计量进行，β 的语义因此在训练全程稳定；好奇心模块不进入部署链路。
  • 数值算例给出探索尺度的参照：平方根衰减使单状态累计投入约 2√N，归一化把衰减中的原始误差折算为稳定权重，退火曲线与任务奖励出现的时间匹配。
