第 089 章：协商机制

当协作意味着"分蛋糕"时，联合决策需要协商：本章给出 Nash 议价解的公理刻画、Rubinstein 交替出价模型中"耐心即议价力"的结论、单调让步协议与 Zeuthen 规则，并把协商循环嵌入多智能体策略训练。

  • 主题：议价理论（Bargaining Theory）/ 协议设计
  • 关键公式：Nash 议价解 argmax (u1 − d1)(u2 − d2)、Rubinstein 均衡份额 (1 − δ2)/(1 − δ1δ2)
  • 预计学时：60 分钟
  • 前置章节：第 088 章

学习目标

  • 理解议价问题（Bargaining Problem）的要素：前景集、破裂点与可行分配。
  • 掌握 Nash 议价解及其四条公理的表述，能解释乘积最大化形式的来源。
  • 理解 Rubinstein 交替出价模型的子博弈精炼均衡与贴现因子的作用，掌握"耐心即议价力"的直觉。
  • 学会单调让步协议与 Zeuthen 让步规则，能实现两智能体协商循环。
  • 能设计嵌入 MARL 的协商协议：提议与回应消息、轮数上限、承诺与训练课程。

背景与动机

第 088 章的联盟形成决定了"谁与谁合作"，但没有处理合作剩余如何分配、联合行动如何确定。当两个智能体都想占用同一条通道、同一块资源时，联合动作的选择需要双方通过消息交换逐步收敛，这类过程称为协商（Negotiation）。协商的价值在于把冲突从"执行期碰撞"前移到"决策期议价"：轮流提出方案、逐步让步，用可控的通信代价换取动作层面的协调。

与前三章的通信机制相比，协商的消息有明确的语义结构：提议（携带具体分配方案）、回应（接受或拒绝）、终止（成交或破裂）。这种结构化语义让博弈论工具可以直接套用：议价解给出理性成交点的理论基准，交替出价模型刻画耐心如何转化为议价力，让步协议提供有限轮数下的实用算法。本章任务是把这些工具与强化学习策略对接：协商参与者的策略也是学出来的，任务回报经协商结果传导回双方的策略梯度。

核心原理

1. 议价问题的公理刻画

议价问题由三要素描述：可行效用对集合 U（前景集）、破裂点 d = (d1, d2)（谈崩时双方得到的效用）、以及分配机制。Nash 议价解选择最大化效用增益乘积的可行点：

(u1∗, u2∗) = argmax(u1, u2) ∈ U (u1 − d1) · (u2 − d2)，要求 ui ≥ di 该解是唯一满足帕累托效率、对称性、仿射不变性与无关备选独立性的方案

乘积形式的经济学直觉：对数效用之和 max Σ ln(ui − di)，乘积最大化等价于让双方的"增益比例"趋于平衡。破裂点 d 是关键参数：d 越高，对方需要让出的效用越多，议价结果向 d 较高一方倾斜。否则一方在协商中虚报高破裂点就能获得优势，这引出可信承诺问题。

2. Rubinstein 交替出价与贴现

Rubinstein 模型描述无限轮交替出价：轮到我出价时，我提出一个分配；对方可以接受（成交）或拒绝（轮换出价方并消耗一轮时间）。若双方每轮对效用的贴现因子为 δ1、δ2，模型存在唯一的子博弈精炼均衡：先出价方获得份额

s1∗ = (1 − δ2) / (1 − δ1δ2) δ 越接近 1 表示越有耐心；δ1 = δ2 = δ 且 δ → 1（贴现消失）时份额趋于 1/2，先出价者优势随之减弱

"先出价者优势"体现在份额偏向先出价的一方；"耐心即议价力"体现为 δ 较大者的份额更高。MARL 语境下的对应关系：折扣因子 γ 与训练步数决定智能体对延迟收益的耐心，耐心不足的智能体在协商中会更早接受不利条件，这提示协商奖励需要与折扣因子联合调参，否则协商结果会系统性地偏向耐心一方。

3. 单调让步协议与 Zeuthen 规则

有限轮数下的实用协议是单调让步（Monotone Concession）：每轮报价朝对方偏好方向移动，让步幅度递减，双方越谈越接近。每个参与者的让步序列形如 pt+1 = pt − Δ/(t + 1)，既保证移动方向单调，又让接近成交时步长足够小。哪一方该让步由 Zeuthen 规则决定：计算双方"坚持不退让导致破裂"的风险比率，风险较高（效用损失比更大）的一方让步。该规则使让步顺序由效用结构决定，排除了固定轮流让步的机械低效。

4. 协商协议的工程结构

嵌入 MARL 的协商协议包含三个要素：

  • 消息语义：提议消息携带分配参数（例如资源比例，量化 8 比特）；回应消息为二值接受/拒绝；协议在有限轮后强制终止并回落到默认动作。
  • 策略输入：协商策略的观测是提议历史与自身效用函数的组合，用 RNN 编码历史；输出为提议或回应的分布。
  • 奖励结构：任务回报按协商结果分配给双方，再扣减协商代价（每轮通信的比特数与延迟步数）。协商失败时双方获得破裂点收益。

训练难点是终止信号的稀疏性：只有协商结束才有明确奖励。缓解手段包括课程学习（先训练近似合作的任务，再引入冲突）、对基线协议（例如 Zeuthen 规则的固定让步）做模仿预热、以及 self-play 让协商对手持续演化。

5. 收敛性与终止保证

单调让步协议在有限轮内终止：让步幅度递减且报价有界，要么在轮数上限前成交，要么按协议回落到破裂点。学习型协商策略没有先验的单调性保证，需要两层约束：一是硬性轮数上限，二是对超时行为施加固定回退动作。评估协商机制的指标包括成交率、成交轮数、双方效用与 Nash 议价解的理论之差，四个指标联合报告才能刻画协商质量。

实现思路与设计

协商循环嵌入训练循环的流程：

  1. 触发：当联合动作空间出现资源冲突（同一资源被多方申请）时进入协商模式。
  2. 提议轮：出价方策略生成提议，经信道发送；接收方策略输出接受或反提议。
  3. 终止：成交则双方执行协议动作；超时则各自执行默认动作并计入破裂惩罚。
  4. 训练：按协商结果分配奖励，协商消息进入回放缓冲区作为序列样本。

与第 088 章的差异点：联盟形成输出静态结构（一段时期内固定分组），协商处理一次交互的联合决策；联盟内用值分解解决协作，联盟间的资源冲突用协商解决，两套机制可以叠加使用。

设计决策：为什么协商必须有硬性轮数上限？

学习型出价策略可能学会"拖延"来提升自身议价地位，无上限的协商会把任务时间预算耗尽。硬性上限加固定回退把拖延的代价变成确定性的：超过上限即按破裂点结算，拖延不再有利可图。上限同时限界了通信量：每轮固定比特数乘以上限即协商的通信预算上界。

关键代码与解读

片段 1：单调让步协商循环

import numpy as np

def monotone_concession(u_a, u_b, thr_a, thr_b, rounds=8, step0=0.15):
    """单调让步协商：报价朝对方偏好方向逐轮让步，直到对方接受。"""
    offer = 0.5                                  # 资源分配比例，越大对 A 越有利
    history = [offer]
    for t in range(rounds):
        # 让步幅度随轮数递减：先大步逼近，后小步精调
        step = step0 / (t + 1)
        if t % 2 == 0:                           # A 出价：朝 B 的偏好方向让
            offer = float(np.clip(offer - step, 0.0, 1.0))
        else:                                    # B 回价：朝 A 的偏好方向让
            offer = float(np.clip(offer + step, 0.0, 1.0))
        history.append(offer)
        # 双方效用都达到保留阈值即成交，否则继续让步
        if u_a(offer) >= thr_a and u_b(1.0 - offer) >= thr_b:
            return offer, history                # 达成协议
    return None, history                         # 轮数用尽，协议破裂

# 效用函数示例：A 偏好比例大，B 偏好比例小
print(monotone_concession(lambda x: x, lambda y: y, 0.4, 0.4))

解读：（1）固定轮换让步是协议的最简形态，Zeuthen 规则只是把"轮流"换成"按风险比率选择让步方"，循环骨架不变。（2）让步步长 step0/(t+1) 保证单调性与收敛性：总让步量有界（约 step0·ln rounds），报价不会越界；clip 处理边界，防止量化误差导致比例越界。（3）成交条件用双方效用的保留阈值表达，阈值可以来自学习策略的输出，也可以来自固定规则；示例中 A 的效用是比例本身、B 是剩余比例，阈值 0.4 对应双方都可接受的区间 [0.4, 0.6]。（4）返回 None 表示破裂，调用方按第 4 节的设计执行默认动作并计入破裂惩罚。

片段 2：Nash 议价解的数值求解

import numpy as np

def nash_bargaining(u_a, u_b, d_a=0.0, d_b=0.0, grid=2001):
    """在报价网格上最大化 (u_a - d_a)(u_b - d_b)，逼近 Nash 议价解。"""
    ratios = np.linspace(0.0, 1.0, grid)         # 分配比例的一维网格
    gains = (u_a(ratios) - d_a) * (u_b(1.0 - ratios) - d_b)
    gains = np.maximum(gains, 0.0)               # 增益为负说明劣于破裂点，截断
    best = int(np.argmax(gains))
    return float(ratios[best]), float(gains[best])

# 双方效用都是线性偏好的情形：解为 0.5，并给出理论基准值
ratio, gain = nash_bargaining(lambda x: x, lambda y: y)
print(ratio, gain)                               # 0.5 0.25

解读：（1）Nash 议价解一般要解一个约束优化，网格搜索是一维分配问题的最简可靠实现：2001 个网格点上的乘积比较只需毫秒级，作为评估基准完全够用。（2）gains 截断到非负后取 argmax，等价于"破裂点以上最大化乘积"，避免所有网格点都劣于破裂点时选出错误的负增益点。（3）返回（比例, 增益）两值：增益是协议质量的上界，与学习策略的实际成交效用之差就是"议价效率损失"，这是第 095 章评估指标的直接素材。（4）若效用函数非凸，网格分辨率不足会漏掉尖锐峰值，把 grid 提高一倍或改用对数刻度网格即可验证。

常见坑

  • 无轮数上限的协商：学习策略学会拖延以获得议价优势，任务时间预算被耗尽。修复：硬性上限加固定回退动作，把拖延代价确定化。
  • 破裂点设置失真：把 d 设得过低会高估合作收益，协商达成的协议无法执行（一方宁可违约）。修复：破裂点按"协商失败后实际执行的默认策略回报"设定。
  • 协商奖励与折扣因子脱节：δ 小的智能体耐心不足，协商结果系统性偏向对方，长期训练出现单边协议。修复：联合调整 γ 与协商收益的时间尺度，或对坚持行为给予明确奖励。
  • 提议量化过粗：8 位量化在分配维度多时分辨率不足，双方在相邻档位之间反复微调。修复：按维度降低量化粒度或改用相对报价（百分比）。
  • 只在自博弈中评估协商质量：对手分布单一，策略对顽固对手失效。修复：评估集加入固定 Zeuthen 协议对手与随机让步对手。

练习与思考

  1. 在单调让步示例中把 thr_a 设为 0.6、thr_b 设为 0.4，判断协商能否成交并解释原因。★
    提示
    A 要求比例不低于 0.6，B 要求剩余不低于 0.4 即比例不高于 0.6，边界点 0.6 理论上可行；由于让步序列离散，检查历史中是否恰好触及 0.6，否则破裂。这说明保留阈值的组合决定可行区间宽度。
  2. 把协商代价系数从 0.05 提高到 0.2，预测成交率、平均成交轮数与任务回报的变化。★★
    提示
    代价升高促使策略尽早成交或直接放弃协商，成交率与轮数同时下降；任务回报取决于放弃协商后的默认动作质量，可能升也可能降。用四指标联合报告验证。
  3. 推导：在 Rubinstein 模型中证明 δ1 = δ2 = δ 时先出价方份额为 1/(1 + δ)。★★
    提示
    设先出价方均衡份额为 s，对方拒绝后自己成为先出价方的份额为 s，接受条件给出 1 − s = δ·s，解得 s = 1/(1 + δ)；δ → 1 时趋于 1/2。
  4. 设计实验：两智能体资源分配任务中比较（固定均分）、（单调让步协议）、（学习协商策略）三种模式的成交效用、轮数与总回报，并计算相对 Nash 议价解的效率损失。★★★
    提示
    均分是 Nash 解在线性效用下的特例，效率损失为零但不适应非线性效用；学习策略应在线性任务上接近均分、在非线性任务上超过固定协议。种子数不少于 10，按第 082 章管道聚合。
  5. 把 Zeuthen 规则接入片段 1：每轮计算双方"坚持导致破裂"的风险比率，由风险高者让步，比较与固定轮换版本的成交轮数分布。★★★
    提示
    风险比率可用 (成交效用 − 破裂效用)/破裂效用 的比值近似；Zeuthen 版本在效用不对称时让步集中在一方，理论收敛更快。验证：统计 1000 次随机效用组合下的平均成交轮数。

小结

  • Nash 议价解由四条公理唯一确定，乘积最大化等价于增益对数之和最大；破裂点是分配倾斜的决定参数。
  • Rubinstein 交替出价模型揭示"先出价者优势"与"耐心即议价力"：贴现因子决定均衡份额。
  • 单调让步协议以递减步长保证有限轮收敛，Zeuthen 规则按风险比率决定让步顺序。
  • MARL 协商协议的结构是提议、回应、强制终止三段；奖励包含协商代价，稀疏终止信号用课程与模仿预热缓解。
  • 评估协商质量的四指标：成交率、成交轮数、双方效用与 Nash 基准的效率损失。
