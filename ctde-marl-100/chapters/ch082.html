第 082 章：训练可视化与实验分析方法

把几十条种子曲线变成可比较的结论需要一套统计管道：本章讲学习曲线的稳健聚合（IQM 与分层自助置信区间）、平滑与坐标轴的规范、诊断面板的信号选择，以及从原始记录到图表的可复现流程。

  • 主题：实验数据聚合 / 训练诊断可视化
  • 关键公式：指数滑动平均（EMA）、四分位均值（IQM）、分层自助置信区间（Stratified Bootstrap CI）
  • 预计学时：50 分钟
  • 前置章节：第 081 章

学习目标

  • 理解均值加标准差聚合的失效条件，掌握四分位均值（Interquartile Mean, IQM）、中位数与均值三者的选择依据。
  • 学会用分层自助（Stratified Bootstrap）为聚合指标构造置信区间，并解释置信区间的统计含义。
  • 掌握指数滑动平均（Exponential Moving Average, EMA）与窗口平均的区别，能规定"平滑用于展示、统计用原始数据"的边界。
  • 能搭起训练诊断面板：从 TD 损失、梯度范数、策略熵、Q 值量级等信号判断训练所处阶段。
  • 能设计从记录文件到图表的可复现分析管道，保证图表与统计同源。

背景与动机

一次完整的多智能体对比研究通常是 3 个算法 × 5 到 10 个种子 × 数百万环境步。过程中产生的不只是"最终胜率"一个数字，还包括每个评估点、每个诊断量的时间序列。如果这些序列的记录与聚合方式不规范，实验结论会在两个层面同时失真：展示层面被噪声淹没，统计层面得出不可靠的显著性。

第 035 至 037 章讨论过训练曲线诊断、超参数敏感性与种子方差，本章把这些线索升级为完整分析管道。与第 095 章互为前后：本章解决"拿到数据后怎么处理"，第 095 章解决"跑实验前怎么设计"。在 CTDE 体系中，可视化还有特殊用途：角色坍缩、通信退化、信用分配失衡等失败模式往往先出现在诊断信号上，很久之后才反映到总回报曲线。

核心原理

1. 聚合统计：均值、中位数与 IQM

给定 K 个种子在某个评估点的得分 x1, …, xK，聚合方式决定结论的稳健性。均值对离群值敏感，一个偶然高分的种子就能抬高整体；中位数完全忽略尾部信息，小样本下效率低。四分位均值（IQM）折中：去掉最低与最高各约 25% 的种子，对剩余中间段取均值：

IQM = (1 / |Q2|) · Σk ∈ Q2 x(k) x(k) 为升序排列后的分数，Q2 为去掉两端各 ⌊K/4⌋ 个后的序号集合；K = 8 时取中间 4 个，K = 10 时取中间 6 个

IQM 对离群值稳健，也比中位数利用了更多样本、方差更小。种子数在 5 到 10 的常见规模下，IQM 加分层自助置信区间是当前研究推荐的默认聚合方案。若研究问题关心尾部（例如安全底线），应直接报告中位数与最差分位数。

2. 分层自助置信区间

置信区间回答：重新抽一批种子，聚合指标的波动范围有多大。分层自助在小样本下比正态近似更可靠，流程分三层：从 K 个种子的记录中有放回抽取 K 条轨迹；对每条轨迹在其评估点序列内再抽样；在每个自助样本上计算 IQM，重复 B 次后取分位数。

CI95 = [ Q0.025({IQMb}b=1..B)，Q0.975({IQMb}b=1..B) ] “分层”指按种子分层重采样，保证自助样本的种子构成与原始实验一致

第一步重采样刻画种子间差异，第二步刻画评估点噪声，两者分离是“分层”的含义。报告格式统一为 IQM 加区间上下界，并注明种子数与评估点数。

3. 平滑与坐标轴规范

EMA 用递推式 yt = (1 − α) yt−1 + α xt 抑制高频抖动，α 取 0.05–0.1 比较平衡。窗口平均对窗口内等权且在转折处引入固定滞后，EMA 对新数据加权更高、滞后更小，但需要约 1/α 个点的预热期。两条纪律必须写进分析规范：

  • 平滑只用于展示，显著性检验、阈值判定与区间估计一律用原始评估点；
  • x 轴统一用环境步（Environment Steps），不同并行度与机器上的墙钟时间不可比较；评估点不等间隔时先对齐到公共网格。

4. 诊断面板：看哪些信号

总回报是滞后指标，诊断信号是先行指标。一个够用的面板包含六类量：

信号健康形态异常形态与含义
TD 损失（Critic）快速下降后平稳波动持续上升：目标值发散或学习率过大
梯度范数（裁剪前）平稳波动，与学习率同量级尖峰频发：优势估计方差过大
策略熵缓慢下降后稳定骤降到零：探索坍缩，评估曲线平台期提前
Q 值量级有界，与回报同阶无界增长：目标网络或奖励尺度问题
回合长度或活跃智能体数随任务进度合理变化突然跌落：死亡掩码使用错误
消息熵（通信模块）先降后稳保持最大熵：消息无信息；归零：消息坍缩

算法结构一致时横向比较信号形态，无需逐点比对数值。例如 QMIX 与 VDN 的 TD 损失绝对值不可比，但"是否出现持续上升段"这一形态特征可迁移。

5. 可视化类型与分析管道

四类图形对多智能体分析最有价值：值函数或优势函数在状态空间上的热力图，检查策略是否与任务结构一致；策略箭头场与轨迹叠加图，检查协同行为与碰撞；注意力矩阵或通信拓扑图，检查信息路由是否退化成均匀分布；逐智能体回报的箱线图，对应第 081 章的公平性视角。

数据流保持单向：训练进程只写入原始记录（每评估点一行，含种子、环境步、指标、数值），分析脚本从原始记录重新计算平滑与聚合。训练进程不做可视化端加工，保证同一份记录可被不同口径反复利用，图表与统计检验共享数据源。

实现思路与设计

分析管道分三层，与训练进程解耦：

  1. 记录层：每次评估向 JSONL 追加一行，字段为 run_id、seed、env_step、metric、value；诊断量按固定间隔采样，避免文件膨胀。
  2. 聚合层：读取多 run 记录，按环境步对齐到公共网格，计算逐点 IQM、置信区间与平滑曲线。
  3. 展示层：图表只消费聚合层输出；单种子原始曲线以浅色叠加，用于暴露异常轨迹。

与第 081 章的差异点：081 章在训练目标内部加入公平约束并实时反馈；本章处理训练外部的事后分析，两者共享标签字段但不共享计算时机，081 章的评估脚本按本章规范输出 JSONL 即可进入同一管道。

设计决策：为什么图表统计必须与显著性检验同源？

常见错误是图表用平滑均值、检验用原始数据，两个口径结论方向不一致时无法自洽解释。把聚合逻辑收敛到同一个分析函数，图表与检验共享输入，才能保证"图上看的"与"检验算的"一致。工程上这会牺牲一点灵活性，换来结论可追溯。

关键代码与解读

片段 1：EMA 平滑与 IQM 聚合

import numpy as np

def ema_smooth(values, alpha=0.05):
    """指数滑动平均：只用于绘图展示，alpha 越小曲线越平滑、滞后越大。"""
    out = np.empty_like(values, dtype=np.float64)
    acc = values[0]
    for t, v in enumerate(values):
        acc = (1.0 - alpha) * acc + alpha * v   # 新数据权重 alpha，历史权重指数衰减
        out[t] = acc
    return out

def iqm(scores):
    """四分位均值：去掉最高与最低各 25%，对中间 50% 取平均。"""
    s = np.sort(np.asarray(scores, dtype=np.float64))
    k = len(s)
    lo = k // 4                    # 两端各去掉的下取整数量
    hi = k - lo                    # 中间段的右边界
    mid = s[lo:hi]                 # K 为 4 的倍数时恰为中间 50%
    return float(mid.mean())

def aggregate_at_step(per_seed, step):
    """per_seed: {seed: [(env_step, score), ...]}，取最接近 step 的评估点做 IQM。"""
    scores = []
    for trace in per_seed.values():
        arr = np.asarray(trace, dtype=np.float64)
        j = np.argmin(np.abs(arr[:, 0] - step))   # 最近邻对齐，避免插值造数
        scores.append(arr[j, 1])
    return iqm(scores)

解读：（1）iqm 先按下取整去掉两端各 25% 的取值，再对中间段取均值；K 不是 4 的倍数时中间段占比略高于 50%，这种离散近似与对称数据下的直觉一致。（2）aggregate_at_step 用最近邻对齐评估点：不同 run 的评估步数因回合截断略有差异，线性插值会制造原始数据中不存在的分数。（3）ema_smooth 把“只用于展示”写进注释与接口，避免下游误用。

片段 2：分层自助置信区间

import numpy as np

def stratified_bootstrap_ci(per_seed, n_boot=50000, alpha=0.05, rng=None):
    """对 IQM 做分层自助置信区间：先重采样种子，再在种子内部重采样评估点。"""
    rng = rng or np.random.default_rng(0)
    traces = [np.asarray(t, dtype=np.float64)[:, 1] for t in per_seed.values()]
    k = len(traces)
    boots = np.empty(n_boot, dtype=np.float64)
    for b in range(n_boot):
        picks = rng.integers(0, k, size=k)          # 第一层：有放回抽 K 条种子轨迹
        sample = [traces[i][rng.integers(0, len(traces[i]),
                                         size=len(traces[i]))]  # 第二层：轨迹内重采样
                  for i in picks]
        boots[b] = iqm(np.concatenate(sample))      # 每个自助样本算一个 IQM
    lo, hi = np.quantile(boots, [alpha / 2, 1 - alpha / 2])
    return float(lo), float(hi)

解读：（1）两层重采样对应两类不确定性：种子间差异（算法在不同初始化下的稳定性）与评估点噪声（同一策略在 32 个回合上的抽样波动）；只做第一层会低估总不确定性。（2）固定 rng 种子让图表可复现：同一份记录任何时候重算都得到相同区间。（3）B 等于五万次在纯 Python 下也是秒级，因为每次只操作数十个数字。该区间与第 095 章的配对检验互补：区间回答绝对水平的不确定性，配对检验回答差异是否显著。

常见坑

  • 用平滑后的曲线做显著性判断：EMA 把方差人为压低，两条平滑曲线的交叉可能只是相位差。修复：检验回到原始评估点。
  • 种子数不足仍报告置信区间：3 个种子构造的 95% 区间名义覆盖率严重失真。修复：提升到 5 个以上并注明种子数。
  • 在环境步轴上比较不同 frame skip 的实验：一个环境步对应的决策数不同，曲线差异可能来自动作重复次数。修复：统一换算到决策步。
  • 评估点插值造出不存在的数据：不同 run 的评估步数因回合截断偏移。修复：按最近邻对齐到公共网格。
  • 只盯总回报忽略诊断信号：信用分配失衡与通信退化在诊断面板上早已可见。修复：把六类诊断信号固定进评测脚本，与回报同源记录。

练习与思考

  1. 给定 8 个种子的最终胜率 [0.55, 0.60, 0.62, 0.64, 0.66, 0.70, 0.72, 0.95]，分别计算均值、中位数与 IQM，说明哪个统计量最能代表“典型表现”。★
    提示
    均值约 0.68，中位数 0.65，IQM 为中间四个值的均值 0.655。离群种子把均值抬高了约 0.03，中位数与 IQM 稳健。
  2. 把 EMA 系数 α 从 0.05 提高到 0.3，预测图形的抖动幅度与峰值滞后变化，并设计验证实验。★★
    提示
    曲线更抖、滞后更小。验证：同一条轨迹上叠加三档 α 的平滑曲线与原始点，标注跃升位置的滞后点数。
  3. 推导：若单项评估胜负是伯努利变量，32 个评估回合的胜率标准误是多少？评估回合数增加到 128 时间隔宽度如何变化？★★
    提示
    标准误为 √(p(1−p)/n)，p = 0.5 时约 0.088；n 增大四倍时间隔按 1/√n 缩小一半。评估回合数与种子数是两种独立的降噪手段。
  4. 设计实验：同一算法用“均值 + 标准差”与“IQM + 分层自助区间”两种口径作图，构造一个含离群种子的场景，报告两种口径对“是否优于基线”的结论差异。★★★
    提示
    均值口径的区间可能跨越零差异线而 IQM 口径不跨越；讨论两种口径各自适配的研究问题。
  5. 实现诊断面板脚本：从 JSONL 抽取 TD 损失、梯度范数与策略熵画出三联图，并给出“Q 值发散”与“探索坍缩”两类异常的自动识别规则。★★★
    提示
    用滚动窗口均值与斜率：Q 值用“连续 5 点单调上升且超初始值 20 倍”，熵用“连续 5 点低于初始值的 5%”。规则写成函数便于复用。

小结

  • 学习曲线聚合首选 IQM 加分层自助置信区间：对离群种子稳健、小样本可靠；报告注明种子数与评估点数。
  • 平滑只服务展示，统计推断用原始评估点；x 轴统一用环境步，评估点按最近邻对齐。
  • 诊断面板的六类信号是先行指标，应固定进评测脚本。
  • 记录层、聚合层、展示层三层解耦，保证任何分析口径都能从原始记录复算。
