第 074 章：元学习与CTDE结合

把训练对象从单个任务扩展到任务分布，学习"快速适应新任务"的能力：本章讲清模型无关元学习（Model-Agnostic Meta-Learning, MAML）的双层优化与一阶近似，再把任务分布定义为队友策略与动力学变体，给出与集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）结合的适配点与实验设计。

  • 主题：快速适应 / 双层优化与任务分布
  • 关键公式：θ′ = θ − α∇Ltr(θ)，θ ← θ − β∇ET[Lval(θ′)]
  • 预计学时：65 分钟
  • 前置章节：第 073 章

学习目标

  • 掌握元学习的问题设定：任务分布、支持集与查询集，能写出双层优化目标并解释内层与外层各自的角色。
  • 理解二阶导数的来源与代价，掌握一阶近似（FOMAML）与 Reptile 的替代逻辑。
  • 能定义多智能体场景的任务分布（队友策略、规模、动力学变体），分析哪些变体适合元学习、哪些适合直接微调。
  • 能实现内层适配循环与外层元更新两个片段，并说明共享头与适配头的参数划分依据。
  • 能设计实验：元学习、预训练后微调、联合训练三类基线，加内层步数与任务分布宽度的消融。

背景与动机

上一章的迁移面向单个目标任务，如果目标以任务族的形式持续出现（对手风格轮换、载重参数采样、编队队形变化），逐个微调的代价随任务数线性增长。元学习把"适应过程"本身作为优化对象：训练一组初始化参数，使其在新任务上只需少量交互与梯度步即可达到可用性能。元学习与迁移的区别在于外层目标：迁移优化的是目标任务性能，元学习优化的是"适应后的性能"，梯度要穿过适应过程回传。

多智能体的任务定义包含其他智能体：队友策略的变化使同一条环境规则下的最优行为完全不同，把队友策略纳入任务分布是元学习在此场景的核心用法，训练出的策略能快速适配陌生队友。与 CTDE 的分工一致：适应过程发生在执行期，只允许使用本地观测与少量交互数据。

核心原理

本节先讲 MAML 的目标函数与求解，再讲一阶近似、任务分布设计与 CTDE 的落点。

1. 问题设定与双层目标

给定任务分布 p(T)，元参数 θ 在每个任务上用支持集 Dtr 做若干步内层梯度更新得到任务参数 θ′，外层在查询集 Dval 上评估 θ′ 的性能并更新 θ。目标为适应后的期望损失最小。

minθ ET~p[ LT(θ′) ]，θ′ = θ − α∇θLTtr(θ) α 为内层学习率；外层梯度需对 θ′ 中的 θ 求导，产生二阶项

内层与外层的样本必须分离：支持集与查询集重合时元目标退化为普通训练，学到的初始化没有泛化能力。任务分布的宽度同样是设计量：过窄时所有任务近似相同，元学习退化为预训练；过宽时任务间最优行为冲突，元参数无法快速适应。

2. 二阶项与一阶近似

外层梯度按链式法则展开包含 Hessian 项，计算与存储代价随网络规模增长（海森矩阵在参数维度的规模）。两类近似被广泛使用：一阶近似忽略二阶项，用停止梯度的任务参数做外层更新，实践效果与二阶版本接近，代价降一个数量级；Reptile 完全绕开元梯度，把任务参数的更新方向直接作为元参数的更新方向，实现最简但并不优化显式元目标。

FOMAML：θ ← θ − β∇θ′LTval(θ′)，Reptile：θ ← θ + ε(θ′k − θ) FOMAML 在 θ′ 处求导但不再展开二阶；Reptile 只需内外层学习率

3. 多智能体任务分布设计

可进入任务分布的变化维度：对手或队友脚本策略族、智能体数量、动力学参数（质量、延迟）、奖励权重。任务内首先生成队友配置，再以该配置跑支持集交互，查询集用不同随机种子评估。队友策略变化与动力学变化对参数的要求不同：前者改变最优反应，适合放在内层快速修正；后者改变状态演化规律，适合在外层学习鲁棒表征。两类变体混入同一分布会稀释适应信号，建议分两组实验。

4. CTDE 的适配方案

参数划分为共享编码器与适配头：编码器由元学习学到跨任务通用表征，适配头（策略最后一层与价值最后一层）在内层用支持集数据快速更新。集中式评论家只在训练期参与外层更新，执行期的内层适配不得依赖全局信息。

5. 数值算例：一维任务族的手算元学习

任务族损失 L(θ)=½(θ−a)2，任务参数 a 在 {0, 2} 上等概率取值，内层学习率 α=0.5。一步适应为 θ′=θ−0.5(θ−a)=0.5θ+0.5a。

起点对比。元参数 θ=0 时：a=0 的任务适应到 0、损失 0；a=2 的任务适应到 1、损失 0.5；平均损失 0.25。元参数 θ=1 时：两个任务分别适应到 0.5 与 1.5，损失各 0.125，平均损失 0.125，仅为起点的二分之一。元参数停在任务间中间位置，让一步适应把每项任务拉向各自最优。

外层梯度验证。外层损失对 θ 的梯度均值为 E[(θ′−a)·dθ′/dθ]，代入 dθ′/dθ=0.5 展开得 0.25(θ−1)，驻点为 θ=1，与手算折中点一致。梯度系数 0.25 同时说明任务批越小时方差越大，任务批大小的选择直接决定外层方向的可信度。

退化解的提醒。若内层学习率取 α=1，一步适应直接得到 θ′=a，外层损失恒为零，元参数不再有信息。内层步数与学习率必须限制在使适应后仍留有误差的区间，否则元目标失去区分度。

解读：算例给出三件事的直觉。其一，元参数的语义是提供好的起点，好策略要靠适应过程取得；其二，外层目标的方差来自任务采样，任务批过小时方向噪声主导；其三，支持集与查询集共享样本时 θ=1 处的损失被粉饰，测试时的适应表现会明显退化。

实现思路与设计

训练外层按任务批量采样，内层对每任务做 k 步适配，适配用支持集、评估用查询集，全部批次并行计算。

实验设计

  1. 对比基线：联合训练单策略（不适应）、预训练后微调、MAML 二阶版本。
  2. 消融设置：内层步数 k ∈ {1, 3, 8}、任务分布宽度两档（队友脚本数 2 与 6）、适配头范围（仅策略头与策略加价值头）。
  3. 评价指标：held-out 任务上的适应步数（达到门槛所需交互）、适应后回报、任务间回报标准差（适应一致性）。
  4. 统计方式：任务维度与种子维度双重采样，报告任务分位表现，均值不足以反映分布尾部。
设计决策：为什么适配头只放在输出层

把适配范围限制在输出层使内层更新的参数规模最小，少量支持集样本即可产生有效梯度，且不破坏共享表征的跨任务一致性。扩大适配范围（如整个策略网络）在任务差异极大时表达力更强，但内层数据量与步数需求同步上升，存在过拟合查询集的风险。中间方案是为每个任务增加嵌入调制向量，表达力介于两者之间。

与第 073 章的差异：迁移复用一套参数，元学习复用"适应流程"；本训练的目标函数包含适应过程本身，计算图需要穿过内层梯度。

对比分析：四类快速适应路线的代价

路线外层目标二阶计算执行期数据适应速度
预训练加微调源任务损失无梯度步与数据中，依赖任务相似度
FOMAML适应后损失（一阶近似）无支持集快
完整 MAML适应后损失（精确）有支持集快，计算最贵
Reptile任务参数外推无支持集快，目标不同

选择依据是计算预算与任务分布形状：任务间最优参数接近时四者差别小；分歧大时完整二阶与一阶近似的差距扩大，选择仍应以内部基准实验为准，文献结论仅作参考。执行期支持集越小，越需要把适配范围限制在输出层，参数量与样本量的匹配是适应成败的第一约束。

适配范围的三档对照：仅输出层、输出层加价值头、整个策略网络。第一档内层参数最少、最稳；第三档表达力最强但支持集需求成倍上升。中间的折中是任务嵌入调制，把任务条件注入中间层而不更新权重，在参数效率与表达力之间取平衡。分档实验以 held-out 任务的适应后回报为主指标，支持集规模作为协变量随结果一并报告。

关键代码与解读

片段 1：内层适配循环

import torch

def inner_adapt(policy, support_batches, lr_inner=0.1, steps=3):
    """用支持集执行若干步内层梯度更新，返回适配后的参数副本。
    support_batches: 支持集的 (obs, act, adv) 批次列表。
    """
    fast = {k: v.clone() for k, v in policy.state_dict().items()}
    for _ in range(steps):
        loss = torch.zeros(())
        for obs, act, adv in support_batches:
            logp = policy.log_prob(obs, act, params=fast)
            loss = loss - (logp * adv).mean()   # 策略梯度式内层目标
        names = [k for k, v in fast.items() if v.requires_grad]
        grads = torch.autograd.grad(loss, [fast[k] for k in names])
        updated = dict(fast)
        for name, g in zip(names, grads):
            updated[name] = fast[name] - lr_inner * g
        fast = updated                          # 保留计算图供外层使用
    return fast

解读：内层目标用优势加权对数概率，优势由集中式评论家在训练期估计，属于外层提供的信息。把参数复制为字典并用 autograd.grad 手动更新，是 MAML 系列实现的标准形态；直接对网络参数原地更新会破坏外层计算图。梯度只对可训练参数计算，冻结项显式跳过。

片段 2：外层元更新（一阶近似）

import torch

def meta_update(policy, fast_params, query_loss, lr_outer=1e-3,
                optimizer=None):
    """一阶元更新：在适配参数处求查询损失梯度，回写元参数。"""
    # query_loss 已用 fast_params 前向计算：f(theta')
    grads = torch.autograd.grad(query_loss, list(policy.parameters()),
                                allow_unused=True)
    # 一阶近似：忽略 d theta'/d theta 中的二阶项，直接当作参数更新
    for p, g in zip(policy.parameters(), grads):
        if g is not None:
            p.grad = g
    optimizer.step()
    optimizer.zero_grad()
    return policy

解读：严格 MAML 需要在适配参数处对元参数求导并穿回内层更新链，一阶近似把 fast_params 视作独立变量直接求梯度，省去二阶项。实现上必须把 fast 参数的更新表达式改写成可微形式才能得到真正二阶版本；本片段给出的一阶路径在多数基准上损失极小。优化器状态不跨任务共享。

片段 3：执行期快速适配

import torch

def adapt_on_deploy(policy, local_rollouts, lr_inner=0.1, steps=3):
    """部署时的无监督适配：只用本地轨迹，不依赖评论家与全局信息。"""
    fast = {k: v.clone() for k, v in policy.state_dict().items()}
    for _ in range(steps):
        # 执行期没有优势估计：用熵正则与动作平滑作为替代目标
        loss = torch.zeros(())
        for obs in local_rollouts:
            logits = policy.forward(obs, params=fast)
            prob = torch.softmax(logits, dim=-1)
            loss = loss + 0.01 * (prob * torch.log(prob + 1e-8)).sum(-1).mean()
        names = [k for k, v in fast.items() if v.requires_grad]
        grads = torch.autograd.grad(loss, [fast[k] for k in names])
        updated = dict(fast)
        for name, g in zip(names, grads):
            updated[name] = fast[name] - lr_inner * g
        fast = updated
    return fast

解读：部署期没有奖励标签，适配目标改用无监督代理（熵正则）维持策略的决策边界，这也是元学习从仿真走向实际场景的必要让步。带标签的方案需要在线回报估计，延迟较高时以代理目标起步。适配步数与内层学习率与训练期保持一致，否则元参数的适应敏感度错配。

常见坑

  • 支持集与查询集泄漏：同一批回合先适配后评估，元目标无泛化压力，测试时适应失效。修复：任务内按回合严格划分两组样本。
  • 二阶实现显存溢出：完整二阶方案在批量较大时显存需求高一个量级。修复：改用一阶近似或对任务批分块。
  • 任务分布过宽：队友脚本与动力学同时大幅变化，元初始化在任务间折中后处处平庸。修复：分维度实验或分层元学习，先对子分布训练再组合。
  • 内层过拟合：k 较大且支持集较小时，适配参数在支持集上过拟合，查询集性能下降。修复：减小 k、增加支持集，或在适配目标中加入正则。
  • 执行期适配破坏安全约束：适配后的策略可能越过训练分布中的安全边界。修复：适配只作用于输出层并设置参数裁剪范围，保留安全回退层。

练习与思考

  1. 单参数损失 L(θ)=((θ−a)2)/2、任务 a 从分布 {0, 2} 等概率采样，手算一步内层、外层更新后的元参数趋势。★
    提示
    内层把 θ 拉向各自任务的 a，外层评估在 a 方向上的下降；元参数收敛到分布中心 1 附近。
  2. 把内层步数从 1 增到 8，预测适应后回报与查询集方差的变化方向。★★
    提示
    步数增多支持集拟合更好，但过拟合使查询集方差先降后升；画出两曲线的交点位置。
  3. 推导：对上述一维任务族证明 FOMAML 与完整二阶 MAML 的一阶最优性条件相同，而 Reptile 的更新方向为任务梯度的加权和。★★★
    提示
    在元参数处展开内外层梯度；Reptile 的差 θ′−θ 近似等于该任务损失在 θ 处的梯度乘以步长。
  4. 设计实验：队友脚本数从 2 增到 6，比较元学习与预训练微调在 held-out 队友上的适应步数分布。★★★
    提示
    预测元学习组的适应步数中位数增长较缓、上分位明显占优；预训练组对陌生队友需要更多步或无法达到门槛。
  5. 在内层学习率 α=1、一步适应的简化下，适应后 θ′=a 且外层损失恒为零。说明元学习为何退化为无意义，并解释内层学习率与步数组合需要受限的原因。★★
    提示
    一步适应精确到位使外层目标对元参数的梯度消失，元初始化不再被约束；把内层学习率限制在小于 1，或限制步数使适应留有残差，外层目标才保留可优化的信号。

小结

  • 元学习在任务分布上优化适应后的性能，双层目标的内外样本必须分离，否则退化为普通训练。
  • 二阶项由链式法则穿过内层更新产生，一阶近似与 Reptile 以不同方式绕开其代价，实践效果接近。
  • 多智能体的任务分布可定义为队友策略与动力学变体，两类变体对适配范围的要求不同，建议分开实验。
  • CTDE 下适配头限于输出层，优势信号训练期由集中式评论家提供，部署期改用无监督代理目标并保留安全回退。
  • 一维算例量化了元学习的收益来源：折中初始化让一步适应的平均损失减半，支持集与查询集分离是元梯度有效的前提。
