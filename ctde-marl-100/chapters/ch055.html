第三篇 · 环境与任务实践

第 055 章：多智能体推荐系统

推荐系统把内容分发写成用户与平台的长期交互；本章说明点击率捷径为何损害长期留存，推导逆概率加权的偏差修正，并给出多方目标下的奖励分解方式。

  • 主题：信息分发协同 / 偏差修正
  • 关键公式：RIPS = ( 1 / n ) Σ ok rk / pk
  • 预计学时：60 分钟
  • 前置章节：第 054 章 多智能体机器人协作

学习目标

读完本章，应当能够把推荐问题写成带反馈偏差的序贯决策，并用工具修正训练数据中的偏差。

  • 理解推荐系统的序贯决策视角：状态为用户历史与上下文，动作为物品或列表，奖励包含即时反馈与长期价值。
  • 掌握协同过滤的嵌入表示与双塔评分结构，理解冷启动为何要求显式探索机制。
  • 掌握位置偏差与曝光偏差的来源，理解逆概率加权（inverse propensity scoring, IPS）的无偏性条件与方差代价。
  • 掌握列表级多样化的最大边际相关（maximal marginal relevance, MMR）重排，理解多目标奖励的标量化与帕累托取舍。
  • 会设计离线评估与在线指标的组合，识别“离线提升、在线下降”的常见原因。

背景与动机

推荐系统的学习目标与观测数据之间存在系统性偏差，偏差修正和探索是绕不开的技术环节。

推荐系统的传统方案以点击率预测为核心：训练一个模型估计用户对物品的点击概率，按分数排序展示。该结构在短期指标上表现良好，但存在两类系统性问题。第一，点击率不是最终目标：用户点击高但事后不满意会造成留存下降，平台收益、用户体验与内容生态（作者曝光）三者构成多目标优化问题。第二，训练数据由旧策略生成，被展示过的物品才有反馈，未被展示的物品没有数据，模型会不断强化已有的偏好结构，新生内容与长尾内容获得曝光的机会持续下降。

强化学习把推荐建模为序贯交互：状态随用户行为更新，动作是推荐列表，奖励是终局用户价值。多智能体视角在此有两层含义：多个推荐渠道（首页、推送、搜索补全）共享物品池与用户注意力，彼此的决策互相影响；用户与创作者也可以建模为有自身利益的智能体，平台在多目标之间做协调。与上一章机器人协作相比，本章的“资源”是用户注意力，约束是反馈数据的选择偏差，技术重点从物理安全转向统计正确性。

核心原理

本章原理分四层：序贯建模与嵌入表示、探索机制、反馈偏差修正、以及多目标与多样化。

1. 序贯建模与嵌入表示

推荐决策按会话推进，状态是用户历史与上下文，动作是候选物品集合上的选择。

P( s′ | s, a ), R(s, a) = 即时反馈 + γ · 长期价值预测 ， 评分： score( u, v ) = ⟨ eu, ev ⟩ u 为用户；v 为物品；eu、ev 为嵌入向量；内积表示偏好强度；长期价值常以留存、会话长度或复访率衡量

嵌入表示把用户与物品映射到同一空间，相似度用内积或余弦计算，双塔结构把两侧编码器分开以便线上检索。序贯建模的关键区别于单次排序：一次推荐改变用户的下一次状态，连续推荐同类内容会缩短会话、降低留存，因此价值函数需要把长期影响纳入。工程实现通常用“即时反馈加长期价值预测”的组合奖励：即时部分提供密集信号，长期部分由价值网络估计，两者的加权比例是核心调参对象。直接优化即时点击率的策略会收敛到极端内容，价值估计是对抗这一倾向的主要手段。

2. 探索与冷启动

新物品没有反馈数据，必须通过显式探索获得展示机会。

UCB：at = arg maxv [ μv + c √( ln t / nv ) ] ， ε-greedy：以概率 ε 随机，以 1 − ε 选择当前最优 μv 为物品 v 的平均反馈；nv 为其被展示次数；c 控制探索强度；UCB 为置信区间上界（upper confidence bound）

置信上界方法把“不确定性”直接写入评分：展示次数少的物品获得加分，随次数增加而衰减，探索自动收敛。ε-greedy 实现简单但探索效率低，且在流量大的系统中随机探索会浪费展示位；实用变体是分层探索：只在部分流量位、部分场景下开放探索。探索的度量应当报告“探索点击率”与“探索获得的新偏好数据量”：只有两者联合看才能判断探索是否有效。冷启动的物品在训练分布之外，评估时需要构造冷启动场景组，否则整体指标会掩盖问题。

3. 反馈偏差与逆概率加权

日志数据由旧策略生成，直接用其训练会把“旧策略的偏好”当成“用户的偏好”。

pk = P( 物品被旧策略展示 | 上下文 ) ， RIPS(π) = ( 1 / n ) Σk = 1n 1[ ak = π( xk ) ] · rk / pk xk 为上下文；ak 为旧策略展示的物品；rk 为观测反馈；π 为待评估策略；pk 为倾向分（propensity）

逆概率加权的基本思想是按“被展示的概率”倒数加权：展示概率低的样本在数据中出现得少，但每次出现代表更多未观测人群，加权后估计量在新策略下无偏。代价是方差：倾向分很小时加权系数很大，估计量波动剧烈。常用的缓解手段是裁剪（把权重截断到上限）或自归一化加权，两者都会引入少量偏差换方差下降。位置偏差的处理类似：同一列表内位置靠前的物品天然点击率高，把位置作为条件计算倾向分，或用位置固定分组评估。

在强化学习框架里，偏差修正与策略优化结合：重要性采样可以校正行为策略与目标策略的分布差，但跨多步连乘会使方差指数增长，实践上裁剪、逐决策加权或采用价值估计方法替代。评估阶段的正确性依赖倾向分的可得性，工程系统需要记录每次展示的策略版本与概率，这一要求属于数据管道的组成部分。

4. 多目标、多样化与公平

列表推荐不仅选什么，还要决定如何组合与排序。

MMR：vnext = arg maxv ∉ S [ λ · sim1( u, v ) − ( 1 − λ ) · maxv′ ∈ S sim2( v, v′ ) ] S 为已选集合；sim1 为用户与物品的相关度；sim2 为物品间相似度；λ 控制相关性与多样性的权衡

MMR 在每次选择时对“与已选内容过于相似”的候选做扣分，用一次贪心即可得到多样化列表。多目标奖励的标量化形式为 r = w1 r用户 + w2 r平台 + w3 r生态，权重需要按业务优先级设定；把权重当自由调参量会让指标优化偏离业务方向。曝光公平关注内容供给侧的分布：度量各内容分组的曝光占比与物品基数的匹配程度，常用的指标是分组曝光占比与基尼系数。公平约束可以作为奖励项，也可以作为排序阶段的配额约束，两者对策略训练的影响不同：奖励项是软的、可能被效率收益抵消；配额约束是硬的、保证下限但损失最优性。评估需要按内容分组与用户分组分解指标，整体指标会掩盖局部分配的偏差。

5. 多推荐渠道的协同

首页、推送与搜索补全等多个渠道争抢同一用户的注意力，渠道之间需要协调。

渠道协调的机制有两种。集中式在全局层面对所有渠道的候选做统一排序，实现简单但灵活性差。分布式给每个渠道独立策略，用代价信号协调：当某一渠道刚触达用户时，代价上升，其他渠道的推荐倾向下降，该结构与第 048 章的价格机制同源。训练上可以按渠道分别学习，并用共享的用户状态表示保证一致性；评估时统计跨渠道的重复曝光率与用户疲劳指标，重复触达是协调失败的直接症状。

实现思路与设计

实现采用模拟用户环境加离线日志重放的双轨结构：前者用于训练与消融，后者用于偏差修正方法的验证。

1. 模拟环境

模拟用户具有隐偏好向量与疲劳系数，点击概率由偏好与当前疲劳决定，连续同类推荐使疲劳上升、留存概率下降。环境记录每次展示的策略概率，用于倾向分计算。回合长度为一周（以若干会话近似），终止时以留存与总满意度结算长期奖励。

3. 网络结构与训练要点

用户塔编码用户历史与上下文，物品塔编码物品属性与内容特征，双塔输出内积评分；策略头在评分上加入探索加成与约束项。训练数据混入 IPS 加权的离线样本与在线交互样本，两部分的权重按数据量比配置。评估分三组：普通用户、冷启动物品曝光、内容分组公平，并同时报告即时指标与留存指标。离线评估指标使用 IPS 估计与真实模拟值的对照，检验偏差修正的实现是否正确。

4. 与第 054 章的差异点

机器人协作的耦合通过物理接触与共享工具传递，约束是硬性的；推荐系统的耦合通过用户注意力传递，约束是统计性的（数据偏差）与多目标的。协作章的奖励是事件型，信号稀疏但明确；推荐章的奖励由反馈事件加价值估计构成，反馈本身带有选择偏差，训练流程需要额外的样本加权环节。两章的共同点是都采用“策略加约束层”的结构：协作章用柔顺与安全层，推荐章用约束与重排层。

关键代码与解读

三段代码分别实现双塔评分、IPS 加权估计与 MMR 重排。

片段 1：双塔评分与嵌入

import numpy as np

def user_embedding(history, item_emb, recency=0.8):
    """用户表示：历史物品嵌入的近期加权平均。"""
    if not history:
        return np.zeros(item_emb.shape[1])
    weights = recency ** np.arange(len(history))[::-1]   # 越近的行为权重越高
    emb = item_emb[history]
    return (emb * weights[:, None]).sum(axis=0) / (weights.sum() + 1e-9)

def two_tower_score(u_emb, item_emb, item_bias):
    """双塔评分：内积加物品偏置，偏置吸收全局流行度。"""
    # 内积衡量个性化匹配，偏置项承担物品本身的通用吸引力
    return item_emb @ u_emb + item_bias

def ucb_scores(base, counts, total, c=0.5):
    """在评分上叠加置信上界：次数少的物品获得探索加成。"""
    bonus = c * np.sqrt(np.log(total + 1.0) / (counts + 1.0))
    return base + bonus

解读：用户表示用近期加权的历史平均构造，权重的指数衰减系数控制记忆长度，取值小则偏好短期兴趣。物品偏置项承担流行度效应：没有它时，全网热门的物品只能通过嵌入与每个用户匹配，评分会低估其真实吸引力。UCB 加成中分母用展示次数加一，避免新物品的除零；分子取对数总次数，探索强度随系统运行缓慢增长，保证探索不会永久压制利用。评分与探索加成分离实现，便于替换探索算法而不改动表示层。

片段 2：逆概率加权的策略评估

def ips_estimate(log, target_scores, eps=0.01):
    """对日志样本做逆概率加权，估计目标策略的期望回报。"""
    total, weight_sum = 0.0, 0.0
    for rec in log:
        ctx_items, probs = rec["items"], rec["probs"]
        target = target_scores(rec["context"])[:len(ctx_items)]
        # 目标策略在日志展示集合上的归一化概率（softmax 形式）
        t_probs = np.exp(target - target.max())
        t_probs = t_probs / t_probs.sum()
        for k, (item, p_old) in enumerate(zip(ctx_items, probs)):
            w = t_probs[k] / max(p_old, eps)     # 倾向分下限裁剪，控制方差
            total += w * rec["rewards"][k]
            weight_sum += w
    # 自归一化：权重和替代样本数，降低权重尺度带来的偏置
    return total / max(weight_sum, eps)

def effective_sample_size(weights):
    """有效样本量：权重集中度过高说明估计不可靠。"""
    w = np.asarray(weights, dtype=float)
    return float(w.sum() ** 2 / (np.sum(w ** 2) + 1e-12))

解读：估计量按对数逐条累加加权回报，权重为目标概率与行为概率之比。裁剪下限 eps 防止极端权重，其代价是引入少量偏差，实践中通过有效样本量监控偏差与方差的平衡。自归一化形式在数据量小时比原始 IPS 稳定，是工程上的默认选择。有效样本量指标用于判断估计可信度：它远小于样本总数时说明权重分布高度集中，需要提高行为策略的探索均匀性。该函数只依赖日志中的倾向分与回报，对被评估策略无额外要求，评估流程因此可以面向任意候选策略离线重放。

片段 3：MMR 重排与多目标奖励

def mmr_rerank(scores, item_emb, k=5, lam=0.7):
    """最大边际相关重排：逐位选择兼顾相关度与新颖度的物品。"""
    selected = []
    cand = list(range(len(scores)))
    while len(selected) < k and cand:
        best, best_val = None, -np.inf
        for v in cand:
            if selected:
                # 与已选集合的最大相似度：惩罚同质化内容
                sim = max(float(item_emb[v] @ item_emb[s]) for s in selected)
            else:
                sim = 0.0
            val = lam * scores[v] - (1 - lam) * sim
            if val > best_val:
                best, best_val = v, val
        selected.append(best)
        cand.remove(best)
    return selected

def multi_objective_reward(user_r, plat_r, eco_r, w=(1.0, 0.5, 0.3)):
    """多目标标量化：用户价值、平台收益与内容生态各占一项。"""
    # 三项都需要事先归一化到可比量纲，否则权重失去含义
    r = w[0] * user_r + w[1] * plat_r + w[2] * eco_r
    return r, {"user": user_r, "platform": plat_r, "eco": eco_r}

解读：MMR 的贪心复杂度为 O(k · n)，在候选集合规模数百时开销可接受，选择过程是确定性的（给定相同输入结果一致），便于离线复现。相似度取已选集合的最大值，语义是“与列表中任何一项都不太像”；取平均会被低相似项稀释，低估同质化程度，最大值更贴合多样性的直觉。多目标奖励函数把三项分量的原始值一并返回：标量奖励用于训练，分量用于诊断，避免权重设定掩盖某一目标的退化。三个权重之和可在训练中按课程调整（早期偏向用户价值，后期引入生态项），调整时机需要与指标监控联动。

常见坑

  • 忽视位置偏差：把点击直接当作偏好强度训练，模型学到“展示位越高点击越多”并不断强化既有排序。症状是离线点击率提升但换位置后效果下降。修复：位置作为条件特征或按位置分层评估，倾向分包含位置概率。
  • IPS 权重不裁剪：倾向分很小的样本获得巨大权重，估计量方差失控。症状是离线和在线指标差异巨大。修复：裁剪下限结合有效样本量检查，必要时提高行为策略的探索均匀性。
  • 探索不足：策略过快收敛到高分的成熟物品，新物品无展示机会。症状是冷启动分组的曝光占比长期趋近于零。修复：置信上界或分层探索，评估按物品年龄分组。
  • 只优化即时反馈：点击率上升但会话长度与留存下降，用户疲劳累积。修复：奖励加入长期价值项，长期目标用独立价值网络估计，评估同时报告即时与长期指标。
  • 多目标权重任意设定：目标权重未按业务优先级确定，某一目标退化被其他目标的提升掩盖。修复：分项目标独立监控，权重调整需要记录并复跑历史评估。

练习与思考

  1. 推导题：证明在倾向分正确且为正、样本充足的条件下，逆概率加权估计量对目标策略回报无偏，并给出方差表达式。★
    提示
    对展示事件求期望时，行为概率与倾向分相消，剩余项恰为目标策略的回报期望。方差与权重的平方期望成正比，权重越大方差越大，这是裁剪必要性的来源。
  2. 计算题：某物品历史展示概率 0.2，目标策略在其上的概率 0.5，回报为 1；另一物品历史概率 0.5，目标概率 0.1，回报为 0。计算两条样本的权重与加权贡献。★★
    提示
    权重分别为 2.5 与 0.2，加权贡献分别为 2.5 与 0。可见目标策略概率高于行为策略的样本被放大，这也是新策略评估时方差上升的直接原因。
  3. 改参数并预测：把 MMR 的 λ 从 0.7 降到 0.3，预测点击率、列表内物品相似度与会话长度三项指标的变化方向。★★
    提示
    λ 降低后多样性上升、相似度下降、瞬时点击率下降，会话长度可能上升（用户疲劳缓解）。长期指标与即时指标的分离正是多样性的价值所在。
  4. 设计题：为多推荐渠道设计协作机制，给出代价信号的定义与更新规则，并说明如何避免同一用户被重复触达。★★★
    提示
    代价信号可按“最近触达时间”构造：刚触达过的用户在其它渠道的推荐代价上升，呈指数衰减。需要跨渠道共享触达记录，评估重复曝光率与用户疲劳指标。
  5. 实验设计：构造“存在位置偏差”的日志，比较“未校正训练”与“IPS 加权训练”在模拟环境上的表现，给出判断偏差修正生效的流程。★★★
    提示
    用模拟器作为真值，先验证估计量对目标策略回报的估计误差，再训练策略比较真实回报。若 IPS 估计与真值偏差小于未加权估计，且训练后真实回报更高，则修正生效。

小结

  • 推荐是序贯决策问题，状态由用户历史构成，奖励需要兼顾即时反馈与长期价值，纯点击率优化会导致留存退化。
  • 探索机制（置信上界或分层随机）是冷启动与长尾内容获得数据的唯一途径，评估需要按物品年龄分组。
  • 日志数据带位置偏差与曝光偏差，逆概率加权在倾向分正确时无偏，代价是方差，需要裁剪与有效样本量监控。
  • 列表推荐用最大边际相关做多样化重排，多目标奖励标量化后需分项监控，公平约束可以软化为奖励或硬化为配额。
