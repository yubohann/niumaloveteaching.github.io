第二篇 · 训练工程与稳定性

第 029 章：多智能体连续动作空间处理

本章讲连续动作空间（Continuous Action Space）在 CTDE 中的工程实现：对角高斯策略的参数化、tanh 压缩与对数概率修正、动作边界重缩放、联合对数概率的合成，以及目标动作平滑噪声与行为探索噪声的分工。

  • 主题：连续控制接口 / 概率密度修正
  • 关键公式：log π(a|o) = log N(u; μ, σ) − Σd log|dad/dud|
  • 预计学时：55 分钟
  • 前置章节：第 028 章 多智能体离散动作空间处理

学习目标

  • 理解连续动作策略的两种参数化：高斯分布标准差直接参数化与网络预测对数标准差，以及各自的稳定性约束。
  • 掌握 tanh 压缩与线性重缩放的数学形式，能推导有界动作下对数概率的雅可比修正项。
  • 掌握多智能体联合对数概率的合成方式，以及策略梯度中动作项与价值的对应关系。
  • 理解行为探索噪声与目标动作平滑噪声的不同职责，能正确标定两类噪声的幅度。
  • 能实现带密度修正的有界高斯策略，并诊断动作边界偏置、标准差坍缩两类故障。

背景与动机

连续控制任务（机器人关节、速度指令、力反馈）的动作是实值向量，每个维度对应一个物理控制量。多智能体连续控制把维度进一步抬升：N 个智能体的联合动作维度是各智能体维度之和，集中式评论家需要在这个联合向量上评估价值，而每个智能体的执行策略只输出自己的部分。

连续动作的实现难点集中在概率密度的正确性上：策略梯度与最大熵算法对动作的对数密度求梯度，密度计算只要漏掉变量变换带来的雅可比项，优化目标就偏离预设，表现为熵估计失真与探索行为异常；多智能体的联合密度是各智能体密度的乘积，求和的数值精度与维度增长都需要显式处理。第 028 章的离散掩码解决合法性，本章解决连续动作的分布参数化与边界契约，两者共同构成动作接口层的完整设计。

核心原理

1. 高斯策略的参数化

连续动作策略的标准形式是对角高斯分布：网络对每个动作维度输出均值 μd(o) 与标准差 σd(o)，采样 u = μ + σ ⊙ ξ，ξ 为标准正态噪声。两个实现细节决定训练稳定性：

  • 标准差的正参数化。网络输出对数标准差 log σ，经 softplus 或直接指数得到 σ，并施加范围约束 log σ ∈ [−5, 2]。下限防止标准差坍缩到零后策略退化为确定性输出、梯度消失；上限防止早期标准差过大淹没均值信号。
  • 均值与标准差的输出分离。共享主干之后接两个头，标准差头通常用独立初始化（使初始 σ 接近 1 的邻域）与较小的学习率。

参数化选择的核心判据是梯度路径：均值头的梯度直接来自回报，标准差头同时受回报与熵项调节；两者共用输出层时相互干扰，分离输出头是默认做法。

2. 有界动作：压缩变换与密度修正

物理动作有界，采样得到的无界高斯样本需要映射到 [lo, hi]。设缩放系数 s = (hi − lo)/2、平移 m = (hi + lo)/2，压缩操作为：

a = m + s · tanh(u)，u ~ N(μ, σ²) tanh 把样本压入 (−1, 1)，再经线性变换落到物理区间

概率密度在变量变换下必须携带雅可比修正。密度变换公式给出：

log π(a | o) = log N(u; μ, σ) − Σd log( sd · (1 − tanh²(ud)) ) 求和遍历动作维度；sd 为第 d 维的缩放系数，雅可比项按维度分解

推导要点：一维变换 a = f(u) 的密度关系为 p(a) = p(u)·|du/da|，取对数后减去 log|da/du|；tanh 的导数为 1 − tanh²，再乘线性缩放 s。减去修正项的效果是：靠近动作边界处 tanh 导数趋零，修正项趋于正无穷，密度被压向零，策略不会在边界堆积概率质量。漏掉修正项时策略梯度与熵估计在边界区域系统性偏置，症状是动作贴边，关节持续饱和。多智能体下各智能体的动作维度互不重叠，联合密度修正为各智能体修正项之和。

3. 联合对数概率与策略梯度

各智能体的策略条件于自身观测独立采样，联合对数概率分解为求和：

log π(a | o) = Σi log πi(ai | oi) o 为全部观测的集合；分布式执行时每个智能体只需计算自己的一项

集中式评论家评估的联合动作 a 由各智能体的执行动作拼接而成，策略梯度对每个智能体大参数只涉及自己的一项，求和结构使梯度天然按智能体分解。把各智能体对数概率求和再送进联合损失，与逐智能体损失相加等价；工程量差别在于批量组织，前者需要把所有智能体的观测拼成批，后者可复用现有采样管线。

连续动作下的探索不依赖 ε 随机替换（随机动作在全空间均匀分布无意义），改用分布自身的宽度与显式噪声：行为采集期在高斯样本上叠加或放大标准差，目标值计算期对目标动作做小幅平滑（第 024 章片段 3）。两者职责不同，幅度标定也不同，混用同一参数是配置错误。

4. 动作维度增长与混合空间

联合动作维度随智能体数量线性增长，评论家输入端的拼接向量同步增长，对集中式评论家的容量与泛化提出要求（第 031 章展开缩放手段）。当任务同时含离散与连续通道（例如方向选择加力控制）时，采用混合空间设计：离散头与连续头并列，联合对数概率为离散对数概率与连续对数概率之和，目标动作平滑只作用于连续通道。

另一种常见替代是离散化：每个自由度离散为 k 档，动作空间规模 kd 随维度指数增长，只适用于自由度不超过三个的任务。选择判据：自由度少且精度要求低时离散化实现简单；自由度多或精度要求连续时使用参数化高斯，本课程的连续控制任务统一采用后者。

8. log σ 上下限的数值依据

范围约束 [−5, 2] 两端的实际含义（数值经程序核对）：下限对应 σ ≈ 0.0067，单维采样集中在均值 ±0.02（约 3σ）宽度内，行为近似确定性；上限对应 σ ≈ 7.389，tanh 之前的样本约有 68.5% 落在 |u| > 3 的深度饱和区，压缩后几乎全部贴边。日常作用区间的对照数字：σ = 1 时约 6.7% 的样本越过半宽的 95% 线，σ = 2 时升到 36.0%，σ = 0.1 时样本集中在半宽的 ±30% 内。取值建议：初始 log σ 设成使 σ 落在 0.5 至 1（对应 log σ ∈ [−0.7, 0]），奖励尺度大、学习率高的任务偏小，反之偏大；上下限的职责是拦截训练漂移，日常作用点落在区间内部，诊断时观察 σ 是否长期顶住边界比看单步数值更有意义。

密度正确性的验收建议用数值积分：对一维策略在物理区间上取 1000 个均匀网格点，累加 π(a) 乘以步长，断言总和落在 1 附近（误差量级 10−3）；漏掉修正项时积分会系统性偏离 1，单元测试能在训练开始前拦截这一类缺陷。该测试与第 028 章的掩码和断言清单合并，组成动作接口层的完整验收集。

实现思路与设计

策略模块封装三个接口：sample（采集期采样，带对数概率）、deterministic（评估期用均值压缩后的动作）、log_prob（对已有动作求修正后的对数概率，供损失与集束搜索使用）。三个接口共享同一份参数化与压缩实现，杜绝路径分叉。

关键代码与解读

片段 1：带密度修正的有界高斯策略

import torch
import torch.nn as nn

class BoundedGaussianPolicy(nn.Module):
    """对角高斯策略 + tanh 压缩；log_prob 携带雅可比修正。"""
    def __init__(self, obs_dim, act_dim, log_std_min=-5.0, log_std_max=2.0):
        super().__init__()
        self.trunk = nn.Sequential(nn.Linear(obs_dim, 128), nn.ReLU(), nn.Linear(128, 128), nn.ReLU())
        self.mu_head = nn.Linear(128, act_dim)         # 均值头：承载回报信号
        self.log_std_head = nn.Linear(128, act_dim)    # 标准差头：独立输出，避免与均值梯度耦合
        self.log_std_min, self.log_std_max = log_std_min, log_std_max
        self.act_scale = nn.Parameter(torch.ones(act_dim), requires_grad=False)  # 半宽 s

    def forward(self, obs):
        feat = self.trunk(obs)
        mu = self.mu_head(feat)
        # clamp 对齐接口上限：σ 过大时采样噪声淹没均值
        log_std = self.log_std_head(feat).clamp(self.log_std_min, self.log_std_max)
        return mu, log_std

    def sample(self, obs):
        mu, log_std = self(obs)
        std = log_std.exp()
        dist = torch.distributions.Normal(mu, std)
        u = dist.rsample()                             # rsample 保留重参数化梯度
        action = torch.tanh(u)
        # 密度修正：减去 log(scale) + log(1 - tanh^2(u))，逐维求和
        log_prob = dist.log_prob(u) - torch.log(self.act_scale * (1 - action.pow(2)) + 1e-6)
        return action * self.act_scale, log_prob.sum(dim=-1, keepdim=True)

    def deterministic(self, obs):
        mu, _ = self(obs)
        return torch.tanh(mu) * self.act_scale          # 评估走均值路径，不注入采样噪声

解读：四行数学变换对应理论部分的全部公式。rsample 的重参数化让噪声路径可导，这是策略梯度的要求；对数概率同时减去缩放项与 tanh 导数项，1e-6 下限防止边界处对数发散；deterministic 只是把采样换成均值，压缩与缩放共用同一代码路径。act_scale 注册为不可训练参数，便于从环境元数据自动注入并随模型保存，避免部署时缩放系数与训练不一致这一常见故障。

片段 2：MADDPG 风格的目标动作平滑

def target_joint_action(actor_targets, next_obs, noise_std=0.2, noise_clip=0.5):
    """集中式评论家的目标动作：各目标策略输出加截断噪声，再压回边界。"""
    acts = []
    for i, actor in enumerate(actor_targets):
        # 目标动作使用确定性输出：噪声之外不引入策略自身随机性
        a = actor.deterministic(next_obs[i])
        noise = (torch.randn_like(a) * noise_std).clamp(-noise_clip, noise_clip)
        acts.append((a + noise).clamp(-actor.act_scale, actor.act_scale))
    # 拼接为联合动作：行内块按智能体排列，与评论家输入的约定一致
    return torch.cat(acts, dim=-1)

解读：目标动作平滑的作用对象是评论家的目标值，不进入行为数据。噪声截断避免个别批次的目标动作被推到远离策略支撑集的位置，边界 clamp 维持物理契约。与片段 1 的采样噪声的区别在于：此处的目标动作取确定性输出，噪声是唯一的随机源；行为探索则允许分布自身抽样与附加噪声并存。torch.cat 的排列顺序必须与评论家输入端的拼接约定一致，多智能体代码中该约定通常在一个常量文件中声明并被测试覆盖。

片段 3：联合对数概率与逐智能体损失

def joint_log_prob(policies, obs_list, act_list):
    """按智能体逐项累加对数概率，返回形状 (batch, 1) 的联合密度。"""
    total = None
    for policy, obs, act in zip(policies, obs_list, act_list):
        # 每个智能体的动作先反缩放回 tanh 空间再求密度：与策略内部约定一致
        u = torch.atanh((act / policy.act_scale).clamp(-0.999, 0.999))
        mu, log_std = policy(obs)
        std = log_std.exp()
        # 修正项：log(scale) + log(1 - tanh(u)^2)，还原到物理动作空间的密度
        base = torch.distributions.Normal(mu, std).log_prob(u)
        corr = torch.log(policy.act_scale * (1 - torch.tanh(u).pow(2)) + 1e-6)
        lp = (base - corr).sum(dim=-1, keepdim=True)
        total = lp if total is None else total + lp       # 逐项累加即联合对数概率
    return total

解读：该函数演示了"从回放数据中的物理动作反推对数概率"的完整路径，这是离策略策略梯度算法复用旧数据的入口。atanh 反变换前先做 0.999 截断，避免物理动作恰好落在边界时反变换发散；修正项与片段 1 中的求和项完全对应，两处实现若不一致，会出现在线采样与重算损失之间的密度口径分裂，表现为策略梯度更新方向与采样密度不匹配。逐项累加，避免先拼接大张量，在智能体数量增长时节省显存；批量维度的形状保持在 (batch, 1)，与优势函数逐元素相乘时无需广播处理。

常见坑

  • 漏掉雅可比修正项。对数概率在边界附近严重偏置，策略把概率质量堆到动作区间端点。症状是动作直方图两端堆积、关节长期饱和。修复：在采样与重算两条路径使用完全相同的修正公式，并用数值积分对密度归一化做单元测试。
  • 数值范围防护缺失。log σ 不设范围时标准差坍缩或爆炸；边界处未截断的 atanh 反变换得到无穷大。修复：网络输出端 clamp 到 [−5, 2]；反变换前截断到 ±0.999。
  • 评估用采样动作。评估期调用 sample，测评结果被策略自身噪声抹低且不可复现。修复：评估走 deterministic，并在评测入口断言无随机分支。
  • 行为噪声与目标平滑噪声共用一个参数。调整探索强度时连带改变目标值平滑程度，两个效应耦合，实验归因困难。修复：两个参数独立命名、独立记录。
  • 动作缩放系数未随模型保存。部署端使用默认单位缩放，物理动作量纲错误。修复：缩放与平移量注册为模型缓冲区或参数并进入检查点。

练习与思考

  1. 推导：对一维变换 a = s·tanh(u) + m，从密度变换关系 p(a) = p(u)|du/da| 出发推导对数概率的修正项，并说明修正项在 u → ±∞ 时的极限行为及其对边界概率的影响。★
    提示
    du/da = 1/(s(1 − tanh²u))，取对数得 −log s − log(1 − tanh²u)；u 趋大时 1 − tanh²u 指数趋零，修正项线性增长，密度被压向零。
  2. 改参数预测：把 log σ 下限从 −5 放宽到 −10，保持其他配置不变，预测策略熵曲线、动作标准差分布与最终回报三方面的变化。★
    提示
    部分维度标准差可坍缩到极小，采样噪声消失，熵贴底；早期回报上升可能更快（贪心化），但探索不足使部分任务陷入局部协调模式，最终回报方差增大。
  3. 设计：为一个 4 智能体、每个智能体 3 自由度机械臂的任务设计动作接口，说明缩放量如何从关节限位生成、确定性评估路径如何定义、以及目标平滑噪声的量级选择依据。★★
    提示
    半宽 s 取 (上限−下限)/2，平移取中点；目标平滑噪声按半边宽度的百分之十量级；评估用关节角度均值并检查限位余量。
  4. 实验设计：在连续控制任务上比较无修正、含修正、含修正但评估用采样三种配置，指标使用动作边界占用率、熵估计校准误差与最终回报，说明如何验证密度修正的正确性。★★★
    提示
    校准误差可用同一批状态下经验采样频率与理论密度的对比估计；边界占用率直接观察动作直方图；第三种配置用回报方差暴露评估噪声。

小结

  • 连续动作策略采用对角高斯参数化，均值与标准差分离输出，log σ 需范围约束防止坍缩与爆炸。
  • 有界动作通过 tanh 压缩加线性缩放实现，对数概率必须携带雅可比修正，边界处密度被正确压低。
  • 多智能体联合对数概率为各智能体对数概率之和，策略梯度按智能体自然分解，集中式评论家评估拼接的联合动作。
  • 行为探索噪声与目标动作平滑噪声职责不同，幅度独立标定；评估路径固定使用均值输出。
