第四篇 · 高级机制与研究专题

第 061 章：多智能体无线网络资源管理

把功率控制、信道分配与用户关联建模为相互耦合的多智能体决策问题，用集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）在训练期利用全局信道状态，在执行期仅凭本地观测完成资源调度。

  • 主题：无线资源管理 / 分布式功率控制与信道分配
  • 关键公式：γi = pigii / (Σj≠i pjgji + σ2)
  • 预计学时：60 分钟
  • 前置章节：第 060 章

学习目标

  • 理解干扰耦合的物理来源，写出信干噪比（Signal-to-Interference-plus-Noise Ratio, SINR）与香农速率（Shannon rate）表达式并解释各符号含义。
  • 掌握功率控制的博弈建模：势博弈（potential game）、纳什均衡（Nash equilibrium）与无政府代价（price of anarchy）的关系。
  • 掌握信道分配的组合拍卖（combinatorial auction）与 VCG（Vickrey-Clarke-Groves）机制建模，理解影子价格（shadow price）的定价角色。
  • 能设计干扰感知的集中式评论家（critic），把信道增益矩阵编码进价值估计，说清训练与执行的信息边界。
  • 能设计对比实验，验证 CTDE 相对分布式基线与中心式上界的总速率、公平性与收敛速度差异。

背景与动机

无线网络中每条链路都在同一物理介质上竞争，任何链路的发射功率都会抬高其他链路的干扰，各链路的最优决策因此彼此依赖。这一耦合使资源分配成为非凸的全局优化问题：中心式求解需要全局瞬时信道状态，开销随链路数快速增长；实际系统中链路常分属不同设备，无法共享原始测量数据。问题结构要求分布式执行，而自私决策又因干扰外部性偏离全局最优。

CTDE 匹配这一结构：训练阶段用全局信道增益矩阵评估联合动作的长期收益，执行阶段每个发射机只依据本地观测选择功率与信道。与第 048、第 060 章相比，本章决策变量含连续功率与离散信道索引，奖励由物理层信干噪比给出，便于设置解析基线与上界。

核心原理

本节依次建立速率表达式、非凸优化结构、博弈均衡与拍卖定价四条线索，再映射到 CTDE 的观测、动作、奖励。

1. 系统模型：SINR 与速率

考虑 N 条发射机与接收机对（链路）：发射机 j 以功率 pj 发送信号，接收机 i 的期望信号功率为 pigii，干扰功率为 Σj≠i pjgji，gji 为发射机 j 到接收机 i 的信道增益，σ2 为热噪声功率。

γi = pigii / (Σj≠i pjgji + σ2)，Ri = B·log2(1 + γi) B 为带宽；Ri 即香农容量，单位 bit/s；γi 无量纲

目标是在功率上限约束下最大化加权总速率：max Σi wiRi，约束为 0 ≤ pi ≤ Pmax。该目标在功率对数域中是两个凸函数之差，一般非凸，不存在通用的多项式时间精确解。解析求解困难时，改用学习算法搜索策略空间，用集中式评论家逼近全局收益。

2. 功率控制的博弈视角

把每条链路视为博弈参与者，策略空间为功率区间 [0, Pmax]，效用取自身速率 Ri。若存在全局函数 Φ(p) 使任一参与者单方面改变功率时效用变化量与 Φ 相同，则该博弈为精确势博弈：有限势博弈一定存在纯策略纳什均衡，逐次最优响应（best response）迭代必然收敛到该均衡。

纳什均衡通常偏离全局最优：自私参与者把干扰代价推给他人，均衡总速率低于中心式最优，两者比值刻画为无政府代价。训练期全局信息的作用正是把策略推向协作均衡，因此评论家必须接收全局信道增益矩阵。

势博弈的收敛保证有边界：它依赖效用函数的特定结构（势函数存在），信道分配这类离散组合决策的博弈一般不具备精确势函数，最优响应迭代可能进入循环。工程上的替代是惩罚重塑：把干扰外部性的一部分折入个体效用（例如对自身造成的总干扰加线性罚项），博弈向势结构靠近，收敛性改善的代价是均衡点发生偏移。重塑强度作为超参数扫描，判据取训练振荡幅度与最终总速率的联合表现。

3. 信道分配的竞价与拍卖建模

信道分配处理离散资源配置：M 个正交信道分配给 N 条链路，每条链路至多占用一个信道。链路 i 对信道 c 的估值 vi,c 取该信道下的预测速率增量。VCG 机制的核心性质是激励兼容：如实报告估值是每个参与者的占优策略，参与者 i 恰好承担自己施加给其他人的外部性。

paymenti = max Σj≠i vj,c(j) 在无 i 约束下 − Σj≠i vj,c*(j) 在含 i 的配置下 max 项为排除 i 的最优福利，后项为当前配置下他人福利，差额即外部性

组合拍卖求解属于 NP 难（NP-hard）问题，实际系统采用贪心近似或对偶分解；对偶变量即影子价格，表示资源增加一个单位带来的边际社会收益。把影子价格作为评论家输入，相当于向价值估计注入机制设计先验，在网络规模扩大时改善样本效率。

4. CTDE 映射：观测、动作与奖励

转写为多智能体马尔可夫决策过程（Markov Decision Process, MDP）：观测 oi 含本链路信道增益、近期速率与干扰统计、信道占用标志；动作 ai 为（功率，信道索引）二元组；奖励 ri 取对数域速率或团队平均速率。评论家输入全局观测与增益矩阵，执行期各链路仅凭 oi 选动作。

L(φ) = E[(Σt βtrt − Qφ(o, a, G))2]，πi(ai|oi) 仅依赖本地观测 G 为全局增益矩阵，仅训练期可用；β 为折扣因子，与 SINR 符号 γ 区分

5. 数值算例：两链路功率博弈的均衡与协作点

设两条链路：g11=0.1（弱直连）、g22=1（强直连）、g12=g21=1（强交叉干扰）、σ2=0.1，功率上限 1 W，速率以 bit/s/Hz 计。

步骤一，求纳什均衡。链路 1 的 SINR 为 γ1=0.1p1/(p2+0.1)，对 p1 单调递增，故给定对手功率时满功率是自身最优；链路 2 同理，双方满功率 (1, 1) 构成纳什均衡。代入得 γ1≈0.091、γ2≈0.909，两链路速率分别为 log2(1.091)≈0.126 与 log2(1.909)≈0.933，总速率约 1.058 bit/s/Hz。

步骤二，搜索协作点。把功率组合改成 (0.1, 1)：γ1=0.01/1.1≈0.009，γ2=1/(0.1+0.1)=5，速率约为 0.013 与 log2(6)≈2.585，总速率约 2.598 bit/s/Hz，达到均衡点总速率的约 2.46 倍。

步骤三，解读。链路 1 的直连增益弱、对链路 2 的干扰强，个体理性驱使它满功率发射；而全局最优要求它大幅收缩甚至静默。无政府代价 2.598/1.058≈2.46 量化了协调机制的回报空间。该算例也解释了评论家为何必须接收全局增益矩阵：只有看清交叉增益的结构，价值估计才能识别强弱链路之间的角色差异，把策略推向协作点。

6. 数值核对：公平性权衡与信道拍卖定价

继续用两条链路的算例核对目标函数的选择。最大化和速率的解是链路 1 静默、链路 2 满功率，总速率等于 log2(1 + 1/0.1) ≈ 3.459 bit/s/Hz，为纳什均衡点的约 3.27 倍，但链路 1 的速率归零。把目标换成比例公平（对数和效用 Σ log Ri）后，对数项对零速率的惩罚趋于无穷，最优解为 (p1, p2) ≈ (1.0, 0.62)：双方都保持发射，弱链路速率约 0.19、高于均衡点的 0.13，强链路速率降到约 0.64，总速率约 0.83，低于均衡点的 1.06，公平性由此付出总速率代价。三种目标给出三种操作点：和速率推向单方静默，比例公平提升弱链路并压低强链路，纳什均衡停在双方满功率的无协调点；复现实验必须显式声明目标函数，否则“接近协作解”的结论没有确定所指。

信道拍卖的定价用一个小例核算：3 条链路对 2 个正交信道的速率增量为 [[5, 3], [4, 4.5], [2.5, 2]]。贪心按各链路的最高估值降序处理：链路 1 取信道 0（估值 5），链路 2 的偏好是信道 1（4.5 高于 4），链路 3 的两个方向均已被占用，进入未分配集合。影子价格取未获分配者对同一信道的最高估值：信道 0 的占用者计入 2.5，信道 1 的占用者计入 2.0，链路 3 的记账为零。价格与挤出者机会损失在数字层面一一对应：竞争更激烈的信道（被挤出者估值 2.5）给占用者更高记账，没有竞争者的信道为零。该价格可以直接作为奖励塑形项，引导策略向低拥挤信道迁移。

量纲换算的自检放在环境封装入口：信道增益 0.1 与 1 对应约 −10 dB 与 0 dB，直接与线性域的功率混算会得到数量级错误的 SINR，进而在对数域产生无效值使训练在首个批次中断。封装的验收测试对每个字段断言量纲标签，与第 062 章的动作屏蔽同属环境接口层的必要防线。

实现思路与设计

整体采用共享参数策略网络、干扰图注意力评论家与物理量归一化结构，训练流程与前面章节的策略梯度框架一致。

网络结构与数据流

  1. 策略网络：两层多层感知机（Multilayer Perceptron, MLP）产生两组输出，功率头输出均值 μ 与标准差 σ，经截断高斯采样映射到 [0, Pmax]；信道头输出 M 维 logits 做分类采样。

  3. 优势估计：广义优势估计（Generalized Advantage Estimation, GAE）按团队奖励计算，不做逐智能体分解。

设计决策：为什么奖励取对数域速率

香农速率跨越多个数量级，直接使用 bit/s 会使优势函数被高增益链路的绝对数值主导，弱链路的学习信号被淹没。取 log2(1+γi) 后奖励分布集中。若任务目标是保底速率公平性，应改用比例公平（proportional fairness）形式的对数效用 Σ log Ri。

与第 048 章的差异：动作含连续功率维度，奖励由物理公式精确计算；评论家引入增益矩阵先验，链路数扩大时保持参数效率。

从复现角度补充一个操作细则：干扰感知评论家的注意力偏置应使用对数域归一化后的增益再乘入权重，直接在 dB 域做 softmax 会让衰减严重的负增益链路失去可辨识的强弱顺序；归一化后的偏置在不同增益量级的数据集之间可以复用同一组超参数，这也是跨场景复现稳定性的一部分。

关键代码与解读

片段 1：SINR 与香农速率计算

import numpy as np

def sinr_rate(p, G, noise, bw=1e7):
    """按链路计算 SINR 与香农速率。
    p: 发射功率向量 (mW)；G[i, j]: 发射机 j 到接收机 i 的信道增益。
    """
    signal = np.diag(G) * p                  # 对角项 g_ii 为期望信道
    total = G @ p + noise                    # 到达各接收机的总功率加噪声
    interference = total - signal            # 扣除期望信号即干扰加噪声
    # 零功率链路速率定义为 0；下限 1e-12 防止除零与 log2 发散
    sinr = np.where(p > 0, signal / np.maximum(interference, 1e-12), 0.0)
    rate = bw * np.log2(1.0 + sinr)          # 香农容量，单位 bit/s
    return sinr, rate

解读：矩阵乘法 G @ p 一次算出所有接收机的聚合功率，再按"对角项即期望信号"扣除得到干扰，避免双重循环，便于批量并行计算。零功率分支不参与速率统计；信道增益入参需提前从 dB 转回线性域，混用 dB 与 mW 会让 SINR 变成负数。

片段 2：干扰感知的集中式评论家

import torch
import torch.nn as nn

class InterferenceCritic(nn.Module):
    """集中式评论家：训练期输入全局观测、动作与增益矩阵。"""
    def __init__(self, obs_dim, act_dim, emb=64):
        super().__init__()
        self.embed = nn.Sequential(nn.Linear(obs_dim + act_dim, emb), nn.ReLU())
        self.q = nn.Linear(emb, emb)         # 查询投影：当前链路关注什么
        self.k = nn.Linear(emb, emb)         # 键投影：邻居提供什么
        self.value = nn.Linear(emb, 1)

    def forward(self, obs, act, gain):
        # obs/act 形状为 [批, N, 维度]；gain 形状为 [批, N, N]
        e = self.embed(torch.cat([obs, act], dim=-1))
        att = torch.softmax(self.q(e) @ self.k(e).transpose(1, 2), dim=-1)
        # 用物理干扰强度再乘一次注意力：数值小的弱耦合链接被压低
        ath = torch.softmax(gain, dim=-1)
        pooled = (att * ath) @ e
        return self.value(torch.relu(pooled)).squeeze(-1)

解读：注意力先在嵌入空间计算语义相关性，再乘以增益矩阵的按行 softmax，让价值聚合同时受表示相似度与物理干扰强度调制。按行归一化是因为每条链路只关心邻居干扰的相对强弱。替代方案是展平增益矩阵拼接进 MLP，参数量随 N2 增长且无法适应变长邻居集合。

片段 3：贪心信道分配与影子价格

def greedy_assign_and_price(rates, n_channel):
    """按边际速率增益分配正交信道，并估计外部性定价。
    rates[i, c] 为链路 i 使用信道 c 的预测速率增量。
    """
    n = rates.shape[0]
    assign = [-1] * n                        # -1 表示尚未分配到信道
    occupied = [False] * n_channel
    order = sorted(range(n), key=lambda i: rates[i].max(), reverse=True)
    for i in order:                          # 先安排潜在收益最高的链路
        best = int(np.argmax(rates[i]))
        if not occupied[best]:
            assign[i] = best
            occupied[best] = True
    prices = np.zeros(n)
    for j in range(n):                       # 影子价格：替代者失去的机会
        if assign[j] >= 0:
            rivals = [rates[k, assign[j]] for k in range(n) if assign[k] < 0]
            prices[j] = max(rivals) if rivals else 0.0
    return assign, prices

解读：贪心按各链路最大边际速率降序处理，把竞争最激烈的信道优先留给收益最高的链路，属于组合拍卖的经典近似。影子价格取未获分配链路对同一信道的最高估值，即被挤出者的机会损失，可作为拥塞惩罚项引导策略向低冲突信道迁移。严格 VCG 支付需求两次最优配置，N 较大时以一次贪心近似替代。

常见坑

  • dB 与线性域混用：增益以 dB、功率以 mW 存储时直接代入 SINR 公式会得到负值，训练初期奖励出现 NaN。修复：环境封装层统一持有线性域量纲。
  • 评论家只看到本地信息：删去增益矩阵后评论家退化为局部评价，总速率停留在纳什均衡水平。判定：对比中心式上界曲线并检查评论家输入维度。
  • 团队奖励掩盖链路差异：低增益链路梯度信号微弱，收敛后长期静默。修复：加入公平性正则项，或对各链路优势标准化后聚合。
  • 信道索引作为纯类别处理：无结构离散变量丢失正交约束，同一信道可被多条链路占用。修复：增加冲突惩罚，或让网络输出占用向量。
  • 重放缓冲区跨越信道统计变化：信道分布漂移后旧经验与评论家目标不匹配。修复：限制缓冲区容量或按时间加权采样。

  1. 两条链路、g11=g22=1、g12=g21=0.3、σ2=0.1、Pmax=1，判断双方同时满功率发射是否构成纳什均衡，计算该点的总速率与"一方降为 0.5 功率"后的总速率。★
    提示
    满功率下干扰加噪声为 0.3+0.1=0.4，γ=1/0.4=2.5，单条速率 log23.5≈1.81，总速率约 3.61；任一方降功率只会降低自身速率，故 (1,1) 是纳什均衡。把一方降到 0.5 后总速率约 3.49，低于满功率点，说明该参数下均衡不存在效率损失；交叉增益增大后均衡与协作解的差距才显现（对照正文交叉增益为 1.0 的算例）。
  2. 推导：在只有两条链路、忽略噪声的对称信道下，写出势函数并验证单边功率变化的效用差与势函数差相等。★★★
    提示
    Φ 不能简单取两速率之和，需含干扰交叉项；先写出参与者 1 的对数速率对 p1 的差分，再对称拼出 Φ。
  3. 设计消融实验：分别去掉增益矩阵注意力、去掉影子价格奖励项、将集中式评论家换成独立评论家，给出对照与预期结论。★★★

小结

  • 无线资源管理的本质是干扰外部性下的耦合决策，目标函数非凸，解析求解不可扩展。
  • 功率控制可建模为势博弈，分布式最优响应收敛，但均衡与全局最优存在系统性差距，这便是学习协调的空间。
  • 信道分配对应组合拍卖，VCG 支付度量外部性，影子价格可作奖励塑形与评论家输入先验；CTDE 实现要点是评论家用增益矩阵构造干扰感知注意力，执行期仅依赖本地观测。
  • 数值算例给出量化参照：强交叉干扰下均衡与协作点的总速率可相差一倍以上，协调机制的回报空间随耦合强度上升。
