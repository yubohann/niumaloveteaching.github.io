第三篇 · 环境与任务实践

第 048 章：多智能体资源分配

资源分配把“谁用多少”写成带容量约束的效用最大化问题；本章推导影子价格的经济含义，讨论拥挤导致的边际效用递减，以及策略如何通过价格信号完成分布式匹配。

  • 主题：供需匹配 / 分配机制
  • 关键公式：max Σi,j uij(xij) s.t. Σi xij ≤ cj
  • 预计学时：60 分钟
  • 前置章节：第 047 章 多智能体游戏对战

学习目标

读完本章，应当能够把资源竞争问题写成带容量约束的规划问题，并用对偶变量解释分配结果的合理性。

  • 掌握资源分配问题的标准形式：效用、容量约束与决策变量，理解线性分配与可分凹分配的差别。
  • 掌握对偶变量的影子价格含义与互补松弛条件的直觉，能用手算验证小规模分配的定价逻辑。
  • 理解拥挤与边际效用递减的数学形式，能解释次模效用为何让顺序分配机制失效。
  • 会设计价格信号型观测与个体效用型奖励，说明个体理性与团队最优的冲突来源与协调方式。
  • 能够区分效率目标与公平目标，并在奖励函数中表达加权组合。

背景与动机

资源分配的难点在于：个体最优与全局最优通常不一致，机制设计决定了二者能否协调。

资源分配问题随处可见：计算任务争抢算力、车辆争抢充电桩、配送机器人争抢货梯，形式上是若干个容量有限的资源与若干个有偏好的使用者之间的匹配。经典求解思路是集中优化：给定效用矩阵与容量约束，用线性规划或匈牙利算法（Hungarian algorithm）求得全局最优分配。集中优化在一切信息可得时有效，到了分散环境中面临三个障碍：偏好是私有的，使用者不会如实上报效用；决策有实时性要求，集中求解的延迟不可接受；系统规模扩大后，通信与计算成本上升。

机制设计提供了分布式协调的工具：价格。若给每个资源设定一个价格，使用者按其“效用减价格”的净收益做选择，在适当条件下全体自利选择的汇总结果恰好等于最优分配，价格与约束的松紧程度一一对应。强化学习在此的角色是替代显式的效用申报与价格求解：策略直接从观测中学会接近均衡的选择行为，价格信号作为观测的一部分提供协调信息。本章的分配思想在第四篇的联盟、协商、拍卖章节会被进一步展开。

核心原理

本章原理分四步展开：写出规划问题，读出对偶价格，引入拥挤与次模性，最后把三者落到奖励与观测上。

1. 带容量约束的分配问题

使用者对资源有偏好，每个资源能容纳的使用者数量有限。

maxx Σi Σj uij xij ， s.t. Σi xij ≤ cj， Σj xij ≤ 1， xij ∈ {0, 1} xij = 1 表示使用者 i 被分配到资源 j；uij 为其效用；cj 为资源 j 的容量；两个约束分别限制资源不超载与使用者不重复占用

当 cj = 1 且下标数量相等时，问题退化为标准指派问题，存在多项式时间的最优解。容量大于 1 或数量不等时，问题仍可用线性规划松弛加取整处理，规模更大时用贪心加交换的启发式。若效用随分配人数变化，uij 需要改写为 uj(k)（资源 j 上的第 k 个使用者带来的边际效用），问题从线性变为可分凹，定价逻辑仍然成立。

2. 影子价格与互补松弛

对容量约束引入拉格朗日乘子，乘子的经济解释是资源的边际价值。

L(x, λ) = Σi,j uij xij − Σj λj ( Σi xij − cj ) ， λj ≥ 0 λj 为资源 j 的影子价格；互补松弛条件为 λj ( Σi xij − cj ) = 0

互补松弛条件说明：资源未满载时（约束不紧），价格为 0，因为增加一个单位的容量不带来任何增益；资源满载时价格为正，大小等于“再增加一个单位容量能给总效用带来的提升”。因此价格同时是稀缺程度的度量与扩容决策的依据。个体最优条件变为：使用者 i 选择资源 j 当且仅当 uij − λj 在其所有选项中最大，净收益为零的边际使用者决定价格水平。这就是价格机制分散化的原理：每个使用者只需知道价格与自身效用，无需了解他人偏好。

在强化学习中，价格不必由集中求解器在线给出，可以采样为每回合随机扰动的参数或由环境随负载动态计算。策略以价格为观测，学会的是“在给定价格下的最优选择”，评估时价格由环境的负载自适应给出，这类结构对负载变化的泛化能力显著优于把负载隐式编码进观测的做法。

3. 拥挤与边际效用递减

当资源的使用价值随人数增加而下降时，效用函数具备次模结构。

uj(k) = uj(0) · ρk−1 ，或 uj(k) = uj(0) / (1 + β (k − 1)) k 为资源 j 上的使用者序数；ρ ∈ (0, 1] 为衰减因子；β 为拥挤强度；两者都表达“第 k 个使用者带来的边际效用小于第 k − 1 个”

次模性放大了一个在线性分配中已经存在的现象：顺序分配机制本身不保证最优。线性分配中，按任意顺序逐个让使用者选择剩余效用最高的资源，结果虽然具有帕累托效率（交换论证成立），总效用仍随顺序变化；次模分配中先到者对后到者造成负外部性，顺序效应与抢跑激励叠加，因此需要价格、拍卖或预分配等机制来协调。拥挤惩罚项在奖励中的角色就是把这份负外部性定价：使用者的收益中扣除因自身加入而降低的他人边际效用，理想情况下扣除量恰为负外部性，机制从个体最优导向团队最优，这正是 VCG（Vickrey-Clarke-Groves）类机制的直觉所在。

4. 效率、公平与奖励设计

分配目标可以设为总效用最大，也可以设为最差个体最优，两者通常不可同时达到。

rt = we · Δ Σi vi − wf · Gt − wo · overflowt vi 为使用者 i 的净收益；Gt 为收益分布的基尼系数（Gini coefficient），度量不公平程度；overflow 为超出容量的分配量

效率项取总效用的增量，公平项取收益分布的不均衡度量。基尼系数取值在零至一之间，与效用尺度无关，适合作为跨情形的公平指标。容量违反项对超载施加惩罚，权重需要显著高于效率项，使策略在早期就学会回避不可行分配。奖励结构对策略行为的影响是定性的：效率权重主导时出现“赢者通吃”，公平权重主导时出现平均主义与效用损失，权重比例应当由任务的价值判断决定，训练调参无法替代这一判断。

个体效用型奖励与团队效用型奖励的取舍也在这里。个体效用对应每个使用者的自利回报，训练出的策略在评估时更稳健（不会依赖队友的牺牲），代价是收敛到非合作均衡的风险；团队效用收敛更快但容易学习到“搭便车”与依赖某一成员超额付出的方案。折中做法是奖励 = wself · 个体效用 + wteam · 团队效用，两项权重之和归一，训练后期逐步提高团队项占比。

5. 观测设计：把机制信息放进输入

分散策略要做出接近最优的选择，观测必须包含价格或等价信号。

oi = [ 自身偏好 ui1, …, uiM, λ1, …, λM, 空闲容量 c1, …, cM, 时间 t / T ] λj 为资源价格信号，可由环境按负载计算或由采样器按扰动分布给出；时间项用于区分回合同阶段

价格信号与空闲容量同时提供时，策略可以在价格与容量冲突的情形（例如价格低但已接近满载）下学习取舍。若价格不可得，替代方案是把空闲容量与历史分配信息编码到观测，让策略自行推断稀缺程度，样本效率会下降。回合时间项处理动态到达：使用者在不同时刻进入系统，剩余回合长度影响等待是否划算，时间信息因此必要。

实现思路与设计

实现路径为“环境计算价格、策略输出选择、奖励含拥挤定价”的三段结构，保证机制与学习解耦。

1. 环境循环与价格计算

每一步里，环境先根据当前负载更新每个资源的价格（负载越高价格越高），构造观测下发给各策略，收集动作后执行分配并结算效用。价格更新规则采用滞回形式：价格变动幅度小于负载变动幅度，避免策略面对剧烈跳动无法学习；同时设置价格上限，防止满载时的理论价格无穷大。

3. 网络结构与训练要点

策略输入为偏好向量与价格向量的拼接，输出为资源选择的离散分布，选择结果用掩码限制在有空闲容量的资源上。集中式评论家读取全体偏好与当前分配状态，评估联合动作价值。训练中每回合随机化偏好矩阵与初始容量，避免策略过拟合到固定市场。价格信号的分布需要在训练集中覆盖不同的稀缺程度（从无约束到重度稀缺），否则策略在评估时面对未见过的价格会失效。

4. 与第 047 章的差异点

对战任务的对手是显式敌对体，目标零和；资源分配中没有敌对方，竞争源于稀缺性，个体收益之和是团队收益，目标非零和且可协调。对战任务的信用分配通过价值分解完成，资源分配的信用更接近个体责任：选择哪个资源主要由自身偏好决定，评估时对每个使用者的分配满意度单独统计即可获得清晰的诊断信号。两类任务的共同点是都需要处理离散选择与约束，掩码机制在两端通用。

关键代码与解读

三段代码分别实现最优分配求解、次模效用与边际增益、以及含拥挤定价的奖励。

片段 1：小规模最优分配与对偶检验

import numpy as np
from itertools import permutations

def optimal_assignment(u):
    """穷举法求小规模指派最优解，作为策略评估的参照实现。"""
    n = u.shape[0]
    best, best_perm = -np.inf, None
    for perm in permutations(range(u.shape[1]), n):
        # perm[i] 是使用者 i 被分配到的资源编号
        val = sum(u[i, perm[i]] for i in range(n))
        if val > best:
            best, best_perm = val, perm
    return best, best_perm

def shadow_prices(u, cap=1, price_max=10.0, iters=200):
    """用简化拍卖迭代估计影子价格：超需求的资源逐步加价。"""
    n, m = u.shape
    price = np.zeros(m)
    for _ in range(iters):
        # 在价格下求每个使用者的最优资源（净收益最大）
        gain = u - price[None, :]
        choice = gain.argmax(axis=1)
        load = np.bincount(choice, minlength=m)
        # 超载资源加价，空闲资源降价；步长固定保证过程平稳
        price = np.clip(price + 0.1 * (load - cap), 0.0, price_max)
    return price

解读：穷举法只用于单元测试与仿真评估的行数级验证，实际规模下要用匈牙利算法或线性规划。拍卖迭代的核心循环是“给定价格选净收益最大、按超载情况调价”，本质是价格调整的次梯度法。价格裁剪到非负且不超过上限：非负来自资源不能“倒贴”，上限防止迭代在满载附近发散。收敛后超载资源的 load 接近 cap，价格水平表达稀缺程度，可与理论影子价格对照，差值反映步长与迭代次数的有限精度误差。

片段 2：次模效用与边际增益

def marginal_gain(base_utility, load, rho=0.7):
    """第 k 个使用者加入资源时的边际效用：随负载指数衰减。"""
    # load 为加入前的现有使用者数；第 k = load+1 个使用者的增益
    return base_utility * (rho ** load)

def submodular_allocation(u_base, cap, rho=0.7):
    """贪心分配：返回分配结果与最终负载，供奖励定价使用。"""
    n, m = u_base.shape
    load = np.zeros(m, dtype=int)
    assign = -np.ones(n, dtype=int)
    # 按最大可能增益排序，贪心在次模情形下可保证 1 - 1/e 近似
    order = np.argsort(-u_base.max(axis=1))
    for i in order:
        gains = np.where(load < cap, u_base[i] * rho ** load, -np.inf)
        j = int(gains.argmax())
        assign[i] = j
        load[j] += 1
    return assign, load

def externality(u_base, load, j, rho=0.7):
    """拥挤负外部性：新加入者使后续边际效用降低的总量（简化估计）。"""
    # 仅统计后续一位使用者的效用损失，作为惩罚尺度的近似
    return u_base * (rho ** load) * (1 - rho)

解读：边际增益按指数衰减，负载越高增益越低，这个形式保证次模性成立（任意两个使用者加入同一资源的联合增益不大于分别加入的增益之和）。无约束的次模最大化中贪心的经典近似比为 1 − 1/e；本问题还带分配约束与异质偏好，贪心不再享有该保证，只作为训练策略的质量下界参照。外部性函数只估计一位后继使用者的损失，是完整负外部性的下界；奖励中惩罚系数取该值的倍数即可在不精确的情形下产生正确的方向性引导。三个函数共用 rho 参数，保证效用、分配与定价使用同一套拥挤模型。

片段 3：含拥挤定价的团队奖励

def allocation_reward(assign, u_base, load_after, cap,
                      w_e=1.0, w_f=0.3, w_o=5.0):
    """团队奖励：效率项 + 公平项 + 超载惩罚。"""
    n, m = u_base.shape
    vals = np.zeros(n)
    for i, j in enumerate(assign):
        if j < 0:
            continue                                # 未分配者收益为零，但不惩罚
        k = load_after[j] - 1                       # 自身是该资源的第几个使用者
        vals[i] = u_base[i, j] * (0.7 ** k)         # 与增益函数同源的效用口径
    eff = float(vals.sum())
    # 基尼系数：与尺度无关的不公平度量，适合作为公平奖励项
    cum = np.sort(vals)
    gini = float((np.arange(1, n + 1) - (n + 1) / 2).dot(cum))
    gini = gini / (n * (cum.sum() + 1e-9)) * 2
    over = float(sum(max(0, int(load_after[j]) - cap) for j in range(m)))
    r = w_e * eff - w_f * max(0.0, gini) - w_o * over
    return r, {"efficiency": eff, "gini": gini, "overflow": over}

解读：效用口径与分配器的边际增益保持一致，奖励与策略面对的选择逻辑因此自洽。基尼系数用排序后加权求和计算，公式中的系数为常数，无需昂贵的成对比较。超载惩罚权重最高，保证可行先行：策略在没学会不超载之前，效率项的收益无法抵消惩罚。公平项使用 max(0, ·) 截断，避免极端情形下的负基尼数值干扰梯度。信息字典中的三项分别对应诊断三问：总效用是否上升、收益分布是否收敛、是否存在超载。

常见坑

  • 个体效用奖励无协调机制：只给个体效用时全体选择效用最高的资源，超载惩罚由所有人共同承担，出现公地退化。症状是效率项后期下降。修复：加入拥挤惩罚（负外部性定价），或把价格信号放入观测，让高负载资源自动失去吸引力。
  • 效用尺度不归一化：不同使用者效用数量级差异大，效用大者主导奖励，小者被忽略。症状是部分使用者长期未分配且公平项异常。修复：按最大值归一化效用，或使用排序型效用保持尺度一致。
  • 价格信号训练覆盖不足：训练时价格总是温和，评估遇到重度稀缺时策略失效。修复：训练时随机化容量与需求强度，覆盖从空闲到超载的全范围，评估集按稀缺程度分层。
  • 容量约束用软惩罚代替掩码：策略学会偶尔超载以获取短期效用，评估时产生不可行分配。修复：加入动作掩码屏蔽满载资源，惩罚只作为兜底。
  • 公平指标选择不当：使用与尺度相关的方差，在不同规模下需要反复调参。修复：使用基尼系数或最差个体收益等尺度无关指标。

  2. 推导题：对指数衰减的拥挤效用，证明其满足次模性，并给出两个使用者联合增益与分别增益之差的表达式。★★

    联合增益为 u(1 + ρ)，分别加入的增益和为 2u，差值为 u(1 − ρ) ≥ 0，满足次模不等式。ρ 越接近 1，拥挤越弱，问题越接近线性分配。
  3. 改参数并预测：把公平权重 wf 从 0.3 提高到 1.0，预测总效用、基尼系数与超载次数三条曲线的走向，并说明何时会出现“平均主义”退化。★★
    提示
    公平权重提高后基尼下降、总效用下降；当权重足够大时，策略会把高偏好者引导到低效用资源以求平均，效率损失超过公平收益，这即为平均主义退化，可从总效用曲线的持续下滑识别。
  4. 设计题：为动态到达的使用者设计观测与机制，说明等待决策如何纳入动作空间，以及时间项在奖励中如何体现。★★★
    提示
    动作空间扩充为“选择资源或不选并等待”，观测加入回合剩余时间与当前价格趋势。奖励可把等待的机会成本写成折扣损失，需注意等待获利的策略与环境负载的耦合，评估时按到达时机分组统计。
  5. 实验设计：比较“观测含价格”“观测含空闲容量”“两者都含”三种设置的学习曲线与评估表现，说明价格信号相对原始容量信息的增益来源。★★★
    提示
    价格是容量的压缩表示，含价格通常收敛更快；两者都含在稀缺程度剧烈变化时最稳健。增益来源可解释为价格把全局负载映射为个体可用的标量信号，降低了策略需要从原始容量推断冲突的负担。

小结

  • 资源分配的标准形式是带容量约束的效用最大化，小规模可用匈牙利法，大规模用线性规划松弛与启发式。
  • 影子价格表达资源边际价值，互补松弛给出“满载才有价格、未满价格为零”的判据，价格机制让分散决策趋近全局最优。
  • 拥挤使效用具备次模性，顺序分配的最优性进一步退化，负外部性惩罚与拍卖类机制是纠正手段；贪心分配常用作质量下界参照。
  • 奖励需同时表达效率与公平，公平度量选择尺度无关的指标如基尼系数；观测应包含价格与容量信息，训练需覆盖不同稀缺程度。
