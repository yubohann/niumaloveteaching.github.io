第四篇 · 高级机制与研究专题

第 077 章：选项学习与技能学习结合

让智能体自己发现可复用的技能：本章讲清选项（option）三元组与技能发现中的互信息目标，给出 DIAYN 风格的内在奖励构造，再讲技能库与集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）结合的协调方式与实验设计。

  • 主题：技能发现 / 互信息与选项框架
  • 关键公式：I(z; s) = H(z) − H(z|s)，奖励 rz = log qφ(z|s) − log p(z)
  • 预计学时：65 分钟
  • 前置章节：第 076 章

学习目标

  • 掌握选项三元组（起始集合、内部策略、终止条件）的定义，理解它相对原始动作的扩展维度。
  • 掌握互信息目标的分解与变分下界，能写出 DIAYN 型内在奖励并解释每一项的含义。
  • 理解技能坍缩与奖励钻空子两类失败模式，能设计多样性度量与审计方法。
  • 能实现技能条件策略、判别器奖励与终止头三个片段，说明技能标识在 CTDE 中的传递方式。
  • 能设计实验：随机技能对照、单技能对照、技能数消融与下游迁移评估。

背景与动机

上一章的分层结构由人工指定子目标空间，技能学习把这一层也自动化：不给目标，让智能体通过内在激励自行发现若干行为模式。发现出的技能可以组合成复杂行为，也可以在任务变化时作为可复用的初始化。技能发现的目标函数来自信息论：希望技能与轨迹（状态访问分布）之间的互信息最大，即不同技能引导策略访问不同的状态区域。

多智能体场景让技能具有新的用途：把技能视为角色，智能体选择技能组合形成分工模式（运输者、侦察者、协调者）。与第 075 章的多任务相比，技能由学习自动产生，与人工定义路线形成对照；与第 076 章相比，技能为无目标的短时行为，层级结构可叠加在技能之上。CTDE 的作用在于为技能组合提供集中式评价：个别技能的效用依赖队友技能，只有全局视角能评估组合质量。

核心原理

本节建立选项定义、互信息目标、变分求解与 CTDE 组合四条线索。

1. 选项框架

选项 o = (I, πo, β) 中 I 为起始状态集合，πo 为内部策略，β(s) 为终止概率。选项在任意时刻启动后按内部策略执行，直到按 β 终止再交由上层选择。技能学习中常用的简化是把选项的起始集合设为全体状态（任何状态可调用），终止条件由学习得到，技能因此成为"带条件的短时策略"，条件 z 即技能的标识。

2. 互信息目标

记技能变量为 z、状态为 s。希望从状态能推断出技能（可区分），且技能被均匀利用（不塌缩）。互信息分解为两项：

I(z; s) = H(z) − H(z|s) H(z) 在技能均匀采样时取最大；最大化互信息等价于最小化给定状态的技能条件熵，即让状态可区分技能

直接计算 H(z|s) 需要对技能的先验与后验均已知，变分下界用判别器 qφ(z|s) 近似后验，得到可执行的内在奖励 rz(s) = log qφ(z|s) − log p(z)。平方采样时 p(z) 为常数，奖励近似为"判别器认为当前状态与技能 z 的匹配程度"。

3. 变分求解与稳定性

交替训练：策略以 rz 加环境奖励为回报最大化回报，判别器以监督学习方式预测技能。两个失败模式需要预防：技能坍缩（不同技能学习相同行为，判别器无从区分）与状态钻空子（策略只访问容易区分但无用的状态，例如四角）。前者靠判别器容量与熵正则缓解，后者靠限制内在奖励权重并加入状态覆盖正则缓解。

Ldisc = −E[ log qφ(z|s) ]，rint = α(log qφ(z|s) − log p(z)) α 为内在奖励权重；判别器仅用于产生奖励，不进入部署链路

4. 与 CTDE 的结合

技能条件策略 π(a|o, z) 保持分散执行：每个智能体只接收自己的技能标识与本地观测。集中式评论家接收全局状态与全体技能，评估技能组合的长期价值，使"侦察者加运输者"这类组合模式通过价值反馈被保留，摆脱了对人工配对的依赖。高层技能选择器可以周期性重选技能组合，频率低于低层动作，形成技能级的时间抽象。

5. 数值算例：互信息与内在奖励

技能数 Z=2、均匀先验时 H(z)=ln2≈0.693 nat（即 1 比特）。若判别器对某状态的技能后验为 0.8/0.2，条件熵 H(z|s)=−(0.8ln0.8+0.2ln0.2)≈0.500，互信息约 0.193 nat；后验达到 0.99/0.01 时条件熵约 0.056，互信息升到约 0.637 nat；完全可区分时互信息达到上界 0.693。

奖励算例。DIAYN 型奖励 r=log q(z|s)−log p(z)，先验 0.5 时 log p(z)=−0.693。正确技能概率 0.8 时 r≈ln0.8+0.693≈0.470；概率 0.2 时 r≈ln0.2+0.693≈−0.916。同一状态下错误技能的惩罚约为正确技能奖励的两倍，判别器越自信，两方向的差距越大。

解读：互信息的数值区间与技能数挂钩，Z=2 时上界 0.693 nat，Z=8 时上界 ln8≈2.08 nat，奖励权重 α 的标定应与该上界同量级考虑。技能柱状图与互信息曲线应随训练共同记录：互信息停滞而任务回报上升，通常说明判别器被绕过或技能被策略忽略，需要检查奖励权重与判别器更新节奏。

估计器的选择说明。互信息可用判别器交叉熵的下界估计，也可用状态聚类的直方图估计。前者随训练可微、适合在线监控，后者近似无偏但样本需求大、适合离线审计。两类估计在训练日志里并列记录，差距长期扩大说明判别器过拟合了训练状态，这通常先于坍缩指标出现。

实现思路与设计

结构为技能条件低层策略、技能判别器与集中式技能评论家；训练按"策略与判别器交替、评论家全程更新"的节奏进行。

实验设计

  1. 对比基线：平铺式 CTDE 无技能、随机技能标识（不对策略产生条件作用）、单技能（退化无发现）。
  2. 消融设置：α ∈ {0, 0.05, 0.2}、技能数 Z ∈ {4, 8}、判别器输入用全局状态与本地观测两档。
  3. 评价指标：互信息估计值、状态覆盖熵、轨迹可视化中的技能分布分离度、下游任务微调的首达步数。
  4. 统计方式：技能与种子双维采样，报告每种技能的状态分布；总平均会掩盖技能间的差异。
设计决策：为什么判别器只看本地观测也能工作

局部观测下的 q(z|o) 是真实后验的有偏近似，但内在奖励只要求"不同技能访问不同状态"的相对区分，不要求概率值精确。局部判别器带来两个好处：判别器规模小、训练稳定；技能条件策略与判别器共享同一信息尺度，避免执行期需要全局信息。当任务要求技能体现协作模式时，判别器改用全局状态可显著提升技能的角色分化程度，代价是判别器只在训练期可用。

与第 076 章的差异：上一章的子目标由高层指定，技能由互信息自动发现；本章新增判别器支路与多样性审计，两章可以叠加为"技能作为低层选项、子目标作为高层意图"的三层结构。

对比分析：四类技能来源的对照

来源技能定义自动发现可复用性主要风险
无技能平铺策略无不适用不适用长时程探索困难
随机技能标识外部随机否低标识与行为无关
DIAYN 型技能互信息目标是高坍缩与状态钻空子
人工定义选项领域知识否中覆盖受先验限制

选择依据是领域知识密度与复用需求：知识与复用都强时先手工定义少量选项作为基线，再用技能发现补充空白区域；缺乏可靠先验时直接从互信息目标起步，并把多样性与覆盖指标纳入常规监控。四类来源的技能条数都要报告单技能使用频率分布，平均使用率掩盖下的个别技能闲置是坍缩的早期信号。

多样性审计的量化口径：状态覆盖熵、技能两两动作分布的距离矩阵、判别器混淆矩阵。三项中任一项长期无变化都说明探索停滞；审计频率建议与技能切换周期同步，避免只在训练结束时做一次定性检查。

审计频率与技能切换周期同步还有一个原因：切换周期内的状态样本属于同一技能的行为快照，跨周期混合采样会把不同阶段的分布混在一起，使分离度指标虚低，进而误判技能质量。

若必须跨周期比较，可先在每个周期内部做标准化再合并，或按周期分别计算分离度后取中位数。技能数较多时单技能样本被摊薄，审计阈值应随技能数放宽，否则正常的长尾技能会被误报为坍缩。

关键代码与解读

片段 1：DIAYN 型内在奖励

import torch

def intrinsic_reward(skill_logits, skill_id, prior_prob, alpha=0.05):
    """由判别器输出构造技能内在奖励。
    skill_logits: 判别器对状态的技能 logits [批, Z]；
    skill_id: 实际执行的技能索引 [批]；prior_prob: 技能先验概率。
    """
    log_q = torch.log_softmax(skill_logits, dim=-1)
    # 取实际技能的对数概率：越大表示状态越"像"该技能的领地
    log_qz = log_q.gather(1, skill_id.view(-1, 1)).squeeze(1)
    reward = alpha * (log_qz - torch.log(torch.tensor(prior_prob)))
    return reward.detach()               # 奖励不回传判别器：避免梯度自环

解读：detach 是关键，内在奖励参与策略优化但不得把梯度传回判别器，否则判别器会朝"让奖励变大"的方向漂移，拟合后验的目标被破坏。先验取均匀分布时第二项为常数。奖励值本身随技能数变化，α 的标定需要在具体 Z 下进行。

片段 2：技能条件策略

import torch
import torch.nn as nn

class SkillActor(nn.Module):
    """技能条件策略：π(a | o, z)，技能用嵌入向量拼接观测。"""
    def __init__(self, obs_dim, n_skills, act_dim, emb=64):
        super().__init__()
        self.skill_emb = nn.Embedding(n_skills, emb)   # 技能嵌入表
        self.trunk = nn.Sequential(nn.Linear(obs_dim + emb, 128),
                                   nn.ReLU(), nn.Linear(128, act_dim))

    def forward(self, obs, skill_id):
        z = self.skill_emb(skill_id)               # 索引转嵌入
        return self.trunk(torch.cat([obs, z], dim=-1))

解读：技能嵌入把离散技能投射到与观测同层的语义空间，技能间相似性由嵌入距离表达，策略可以泛化到训练中少见的技能组合。拼接保留了两路信息的独立性（加法会把两路混入同一分量），便于诊断策略对技能标识的敏感度。技能切换时观测不变而嵌入突变，输出分布随之切换，这属于预期行为；需要平滑切换时对嵌入做低通滤波。

片段 3：终止头与终止梯度

import torch
import torch.nn as nn

class TerminationHead(nn.Module):
    """选项终止概率 β(s)：输出 0 到 1 之间的标量。"""
    def __init__(self, obs_dim, emb=64):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(obs_dim, emb), nn.ReLU(),
                                 nn.Linear(emb, 1))

    def forward(self, obs):
        return torch.sigmoid(self.net(obs)).squeeze(-1)

def termination_gradient_loss(beta_prob, advantage, entropy_bonus=0.01):
    """选项批判（option-critic）风格的终止梯度。
    终止概率的更新方向随优势符号翻转：优势为负时倾向继续执行。
    """
    loss = -(beta_prob * advantage.detach()).mean()
    # 熵奖励抑制终止概率过早饱和到 0 或 1
    ent = -(beta_prob * torch.log(beta_prob + 1e-8) +
            (1 - beta_prob) * torch.log(1 - beta_prob + 1e-8))
    return loss - entropy_bonus * ent.mean()

解读：终止头的梯度乘上优势的停止梯度副本，让"该状态继续执行还是交还上层"由后续回报好坏决定，属于最小化的选项批判实现。熵奖励防止终止概率迅速饱和导致的终止坍缩。与第 076 章的固定间隔 c 相比，学习式终止让技能时长自适应任务节奏，代价是训练更不稳定。

常见坑

  • 技能坍缩：多个技能学成同一种行为，互信息估计趋零。修复：提高判别器更新频率、增大技能嵌入维度并检查技能间动作分布的距离。
  • 状态钻空子：策略蜷缩在易区分的角点刷内在奖励。修复：降低 α、加入状态覆盖或访问频次正则，并审计状态分布。
  • 内在奖励梯度回传判别器：未做停止梯度处理，判别器目标被污染。修复：奖励张量 detach，判别器损失独立计算。
  • 技能标识泄漏到执行期依赖：部署时无法获得技能调度信号，策略等待外部输入。修复：技能切换逻辑内置到策略侧，或训练技能无关的兜底策略。
  • 只做定性可视化：用轨迹图判定技能质量，缺乏量化指标。修复：报告互信息估计、状态覆盖熵与技能使用频率分布三类数值。

练习与思考

  1. 技能数 Z=2、状态分布完全可区分时，互信息的上界是多少？说明它与均匀技能先验的关系。★
    提示
    上界为 H(z)=log2 比特（自然对数下为 ln2）；均匀先验使 H(z) 取最大。
  2. 把 α 从 0.05 提高到 0.5，预测互信息估计与环境回报的变化方向。★★
    提示
    互信息上升而环境回报下降，策略优先服务判别器；两曲线交叉区即合适权重。
  3. 推导：对两技能、离散状态的情形，写出互信息的直接表达式并验证 DIAYN 奖励的期望等于互信息减去常数。★★★
    提示
    展开 I(z;s)=Σ p(z,s)log(p(z|s)/p(z))；在判别器精确拟合后验时，奖励期望等于互信息项加技能熵常数。
  4. 设计实验：判别器分别用本地观测与全局状态训练，比较技能的角色分化程度与下游微调步数。★★★
    提示
    全局判别器预期产出更显著的角色分工（技能状态分布分离度更高），但部署期判定依赖训练期设施，需在结论中注明适用边界。
  5. 技能数 Z=2、均匀先验，判别器对某状态的技能后验为 0.9/0.1。计算条件熵与互信息，并说明后验继续提高到 0.99/0.01 时互信息的上升幅度为何变小。★★
    提示
    0.9/0.1 时条件熵约 0.325，互信息约 0.368 nat；0.99/0.01 时互信息约 0.637。条件熵以对数形式接近零，互信息的边际提升随后验接近确定而递减。

小结

  • 选项框架用起始集合、内部策略与终止条件扩展动作空间，技能是带条件标识的短时策略。
  • 技能发现的优化对象是技能与状态的互信息，变分下界给出可执行的内在奖励，判别器只用于训练期。
  • 技能坍缩与状态钻空子是两类典型失败模式，分别用判别器容量管理与奖励权重控制应对。
  • CTDE 让技能组合通过集中式评论家获得评价，执行期策略仅依赖本地观测与技能标识。
  • 数值算例给出互信息与奖励的量级参照：Z=2 时互信息上界约 0.693 nat，错误技能的单步惩罚约为正确技能奖励的两倍，权重标定应参照该区间。
