第三篇 · 环境与任务实践

第 053 章：多智能体自动驾驶协同

自动驾驶协同处理的是混合动机博弈：车辆既想快速通过又必须避免碰撞；本章推导安全距离边界与安全过滤器，说明让行与抢行的均衡结构，并给出对手人群训练的组织方式。

  • 主题：交互决策 / 安全约束下的博弈
  • 关键公式：TTC = d / ( vego − vlead )，dsafe = vego τ + vego2/(2b) − vlead2/(2b)
  • 预计学时：65 分钟
  • 前置章节：第 052 章 多智能体无人机集群控制

学习目标

读完本章，应当能够在道路场景中写出安全约束、设计混合动机奖励，并组织对手多样化的训练流程。

  • 理解交互式驾驶的博弈结构：让行与抢行的收益矩阵，以及不对称策略成为均衡的原因。
  • 掌握碰撞时间（time-to-collision, TTC）与纵向安全距离的计算，能判断给定状态是否处于安全集内。
  • 掌握安全过滤器（safety filter）的作用方式：把策略输出投影到安全集，保证执行行为满足约束。
  • 理解社会价值取向（social value orientation, SVO）参数化与合作程度的表达，能说明混合动机奖励的构造。
  • 会设计对手人群采样与评估场景集，识别单一对手训练导致的策略僵化。

背景与动机

道路场景的协同难点在于：安全是硬约束，效率是软目标，而协调对象是意图不可见的其他车辆。

交叉口通行、匝道汇入与车道变更都属于交互式驾驶场景：两车或多车需要在短时间内决定谁先通过。这类场景的收益结构是混合动机的：双方都让行造成通行效率损失，双方都抢行导致碰撞，社会最优是其中一方让行，但“谁让”没有天然的分配规则。纯规则控制器（例如固定优先级）在结构化场景可靠，遇到模糊情形时缺乏适应能力；纯学习方法能适应多样交互，但需要明确的安全兜底。

强化学习在此采用“学习决策加安全过滤”的结构：策略输出期望加速度或轨迹，安全过滤器检查并投影到安全集，安全集由纵向安全距离与横向包络定义。训练的核心挑战是对手多样性与安全信号的稀疏性：碰撞是稀有事件，奖励需要在近失（near-miss）阶段就给出区分信号；对手策略需要覆盖从礼让到激进的行为谱，否则策略学会的协调方式只在特定对手下有效。第五篇的公平性与可解释性章节会回到道路场景中的责任与规范问题。

核心原理

本章原理分四层：交互博弈结构、安全距离与风险度量、安全过滤、以及对手人群训练。

1. 交互式驾驶的博弈结构

两车在无信号交叉口相遇时，收益矩阵可以写成一个协调博弈。

己方 / 对方对方让行对方抢行
己方让行双方等待，效率损失（−2, −2）对方通过，己方等待（−1, +3）
己方抢行己方通过（+3, −1）碰撞（−10, −10）

该矩阵有两个纯策略均衡：（让行, 抢行）与（抢行, 让行）。均衡选择依赖不对称信息与动态过程：先到路口的一方、速度更高的一方、或表现出明确意图的一方更容易被默认为先行者。学习策略在此需要两类能力：识别他车已经决定的意图并避免同时抢行；以及在对方犹豫时果断通过，避免双方都让行造成的时间损失。当己方观察到对方减速时，最优反应是加速通过；对方同样推理，双方都加速则危险。稳定协调依赖先动信号与速度承诺，模型预测控制中的“先到先行”启发式正是这一逻辑的简化。

2. 安全距离与碰撞时间

纵向安全由距离与相对速度共同决定，工程上常用碰撞时间与最小安全距离两个量。

TTC = d / max( ε , vego − vlead ) ， dsafe = vego τreact + vego2 / (2 bmax) − vlead2 / (2 bmax) d 为两车距离；v 为速度；τreact 为反应时间；bmax 为最大制动减速度；第二式为考虑制动过程的安全距离简化形式

安全性判据需要同时考虑两车的减速度能力与反应延迟。碰撞时间低于阈值（例如 2 秒）提示风险，实际间距低于安全距离则说明即使前车全力制动、己车按反应时间延迟后制动也会追尾。实现上安全参数可以按保守值设定，并用分区惩罚（风险越高惩罚越大）代替二值碰撞惩罚，让策略在接近风险区时获得连续的梯度。近失事件（例如小于 1 秒的碰撞时间且未碰撞）应单独统计为指标，它是安全裕度收紧的早期信号。

安全距离的三段分解可以手算核对：己车 10 米每秒、前车 6 米每秒、反应时间 1 秒、最大制动 6 米每二次方秒时，反应期行驶 10 米，己车制动距离 102/(2×6) ≈ 8.33 米，前车制动距离 62/(2×6) = 3 米，安全距离约 15.33 米。若实际间距恰为 15 米，差额 0.33 米说明当前速度下制动能力已被用满：速度提高 2 米每秒会把己车制动距离从 8.33 米拉到 12 米，仅制动项就多出约 3.7 米，安全距离缺口随之扩大，安全裕度对速度的敏感程度由此可以看出。反应时间项随速度线性增长，制动项随速度平方增长，高速端的约束加速收紧；只报告碰撞时间会掩盖这一结构，因为 3.75 秒的碰撞时间看起来尚可时，制动距离可能已经超限。

3. 安全过滤与控制屏障

安全过滤把策略输出投影到安全集，保证闭环系统的安全集不变性。

asafe = arg mina ∈ Asafe ‖ a − apolicy ‖ ， Asafe = { a : d(t) + Δv · τ + ½ ( alead − a ) τ2 ≥ dmin } apolicy 为策略输出的期望加速度；alead 为前车加速度估计；τ 为规划视界；dmin 为最小安全距离

该投影是一个二次规划：目标为距离策略输出最近，约束为安全条件。安全集的定义基于简化运动学，预测视界内的位置变化，保证在视界末端两车距离不小于 dmin。安全过滤的定位与前面的半平面过滤、摩擦锥投影相同：把不可行的动作修正为可行，让学习专注于效率与交互。控制屏障函数（control barrier function, CBF）提供更一般的理论工具：构造一个对距离的标量函数，令其在控制作用下的时间导数在边界附近满足约束，可证明安全集前向不变。工程实现中视界与 dmin 的保守程度决定效率与安全的权衡，过于保守的过滤器会在密集车流中频繁触发减速，形成人为拥堵。

4. 混合动机与礼貌度

把利他程度参数化，让一组策略覆盖从礼让到激进的行为谱。

ri = ( 1 − σi ) rself + σi · ( 1 / ( N − 1 ) ) Σj ≠ i rj ， σi ∈ [0, 1] σi 为社会价值取向参数，取值 0 完全自利、取值 1 完全利他；rj 为其他车辆的效率奖励

社会价值取向把合作程度变成一个可采样的标量：训练时按分布采样 σ，学习到一族的策略，评估时可以挑选合适的礼貌水平，也可以把 σ 作为观测的一部分由上层指定。观察的经验规律是：适度利他的策略在混合交通中的平均通行效率高于完全自利策略，因为利他行为减少了僵持与急刹的概率。礼貌度存在上限：完全利他会在让行中无限等待，通行效率崩解。混合动机的平衡点与交通密度相关，评估需要按密度分层。

5. 观测、通信与意图

交互决策的观测必须包含他车的运动趋势，车路协同场景还可以借助广播的意图信息。

oi = [ 自身状态 , { 邻车相对位置、相对速度、加速度、航向 } , 道路拓扑 , { V2V 意图标志 } , 历史编码 ] V2V 指车车通信（vehicle-to-vehicle）；意图标志为可选信息，例如转向灯状态或轨迹规划器输出的预期动作

无通信时的意图推断依赖历史：连续减速序列提示让行意图，横向漂移提示变道意图。观测中加入邻车加速度比只给速度更能区分“匀速接近”与“正在减速”。V2V 广播意图显著降低推断难度，但需要考虑信息可信度：训练时可以按概率翻转或延时意图标志，模拟通信错误与信号不一致的情形，评估时报告意图信息缺失场景下的性能退化幅度。道路拓扑以车道连接关系与限速编码，帮助策略理解可行驶方向。

实现思路与设计

实现选择纵向加速度控制与简化横向车道保持的组合，场景覆盖交叉口冲突与匝道汇入。

1. 环境循环

每步：更新邻车状态与意图估计；策略输出期望加速度；安全过滤器投影；执行动作并积分运动学；检查碰撞与越界；结算奖励。回合以所有车辆通过冲突区或超时结束。评估场景集包含无信号交叉口对向直行、匝道汇入、以静态障碍表示的横穿情景与密集跟车。

3. 网络结构与训练要点

策略网络以邻车为槽位做共享编码，槽位顺序按距离排序；道路拓扑以车道连接矩阵的嵌入表示。训练采用人群式自博弈：维护一组不同 σ 与不同训练阶段的对手，训练时按权重采样，同时保留一个反应式规则对手（跟驰模型）作为稳定基线。评估对每种对手分别报告，避免平均指标掩盖交互退化。安全过滤器在训练与执行阶段都开启，保证样本中不含碰撞轨迹；碰撞惩罚因此主要作为安全裕度不足的预警信号，事后纠正由过滤器实时承担。

4. 与第 052 章、第 045 章的差异点

第 045 章的导航任务中智能体互相协作且没有交通规则，避让目标是最小化冲突；本章的车辆之间存在混合动机，存在合法的优先权与规则约束，协调问题包含博弈维度。第 052 章的安全约束来自三维几何与欠驱动动力学；本章的安全约束来自纵向运动学与时间余量，约束形式是安全距离不等式，更接近一维问题。三章共用的结构是“策略输出加安全层”，差异在安全层的维度与信息结构。

关键代码与解读

三段代码分别实现风险度量、安全过滤与混合动机奖励。

片段 1：碰撞时间与安全距离

import numpy as np

def ttc_1d(d, v_ego, v_lead, eps=1e-3):
    """纵向碰撞时间：仅在接近（己车更快）时有定义。"""
    closing = v_ego - v_lead
    if closing <= eps:
        return np.inf                 # 未接近则风险为零
    return d / closing

def safe_distance(v_ego, v_lead, tau=1.0, b_max=6.0, d_min=2.0):
    """考虑反应时间与制动的安全距离（简化形式，用于过滤约束）。"""
    react = v_ego * tau                       # 反应期内的行驶距离
    brake_ego = v_ego ** 2 / (2 * b_max)      # 己车制动距离
    brake_lead = v_lead ** 2 / (2 * b_max)    # 前车制动后仍会前进的距离
    # 前车制动能力按己车参数保守估计，得到偏保守的下界
    return max(d_min, react + brake_ego - brake_lead)

解读：碰撞时间在非接近情形返回无穷，避免除零与无意义的负值，下游的风险判据因此可以统一写成“TTC 低于阈值”。安全距离公式由三段构成：反应期行驶、己车制动距离、前车制动距离的扣除项。第三项按己车制动能力保守估计，得到的值略小于真实需求，但实现简单且在参数一致时自洽。返回前用 d_min 兜底，防止低速时安全距离趋近于零导致过滤失效。该函数是过滤器的核心输入，参数修改会同时改变训练与评估的安全水平，需成组调整。

片段 2：安全过滤器

def safety_filter(a_policy, d, v_ego, v_lead, a_lead=0.0,
                  tau=2.0, d_min=2.0, a_lo=-6.0, a_hi=3.0):
    """把期望加速度投影到安全集：线性约束下的最近点投影。"""
    # 视界末端的间距要求：d + dv * tau + 0.5 * (a_lead - a) * tau^2 >= d_min
    dv = v_lead - v_ego
    # 解出对 a 的约束：a <= a_lead + 2 * (d + dv * tau - d_min) / tau^2
    a_cap = a_lead + 2.0 * (d + dv * tau - d_min) / (tau ** 2)
    a_safe = min(a_policy, a_cap)         # 约束为单边上限，直接截断即可
    return float(np.clip(a_safe, a_lo, a_hi)), {"a_cap": a_cap}

def min_ttc_among(ego_state, neighbors):
    """对全部邻车取最小碰撞时间，用于风险诊断与近失统计。"""
    worst = np.inf
    for nb in neighbors:
        d = nb["rel_pos"][0]              # 纵向相对距离（前方为正）
        if d <= 0:
            continue                      # 后方车辆不影响追尾风险
        worst = min(worst, ttc_1d(d, ego_state[0], nb["v"]))
    return worst

解读：单边约束下的投影退化为简单的上限截断，计算量为常数，适合高频调用。约束来自二次运动学的代数变形，其中 a_lead 的估计误差直接影响安全裕度，实现上可对 a_lead 施加保守偏置（估计减速幅度取大值）。返回的 a_cap 用于诊断：当 a_cap 长期低于 0 时说明约束正在主动制动，过滤器参与度过高，策略本身的安全意识可能不足。最小碰撞时间函数只考虑前方车辆，因为追尾风险具有方向性，后方车辆的风险由对方的两车距离判断，分布式架构下各自负责自己的前向安全。

片段 3：混合动机奖励

def driving_reward(ego, neighbors, svb, collision, lane_ok, jerk,
                  w_speed=1.0, w_col=20.0, w_near=1.0, w_jerk=0.1, w_lane=2.0):
    """混合动机奖励：自身效率与他车效率按社会价值取向加权。"""
    r_self = w_speed * ego["v"] / 12.0            # 速度项按上限归一化
    # 他车效率用邻车速度的均值近似，σ 越大越关心他人的通行效率
    r_others = float(np.mean([nb["v"] / 12.0 for nb in neighbors])) if neighbors else 0.0
    r = (1 - svb) * r_self + svb * r_others
    if collision:
        r -= w_col                                 # 碰撞作为终止事件重罚
    ttc = min_ttc_among((ego["v"],), neighbors)
    if ttc < 2.0:
        r -= w_near * (2.0 - ttc) / 2.0            # 近失惩罚：风险越高扣分越多
    r -= w_jerk * jerk ** 2                        # 舒适性：惩罚加加速度
    if not lane_ok:
        r -= w_lane                                # 越界与违规行驶
    info = {"r_self": r_self, "r_others": r_others, "ttc": ttc}
    return r, info

解读：自身与他车效率项都按速度上限归一化，σ 加权后量级一致，礼让的代价与收益因此可比。碰撞惩罚取 20 的量级，使一次碰撞抵消数十步的效率收益，同时避免过大导致策略过度保守。近失项用碰撞时间的连续函数，风险越接近零值惩罚越大，在碰撞前的整个区间提供梯度。加加速度（jerk）惩罚抑制急加速急减速，与乘坐舒适性对应。信息字典中保留自身效率与他人效率的分项，可以验证 σ 是否真的改变了策略行为：σ 增大时 r_others 应上升而 r_self 略降。

常见坑

  • 对手单一导致策略僵化：只与战术固定的对手训练，策略学到针对性的抢行或让行习惯。症状是换对手后碰撞率骤升或通行时间翻倍。修复：人群式对手池加规则基线对手，评估按对手类型分别报告。
  • 安全过滤过于保守：视界与安全距离取值偏大，密集车流中过滤器持续主动制动。症状是平均速度异常低且跟车距离远大于必要值。修复：按场景标定参数，或在过滤器中区分场景类型，把保守度与车速关联。
  • 只惩罚碰撞不惩罚近失：碰撞稀有导致梯度信号缺失，策略长期停留在高风险边缘。修复：加入碰撞时间的连续惩罚项，并把近失率列为评估指标。
  • 礼貌度未参与观测：σ 在训练时采样但不告知策略，同一观测对应不同目标，价值学习混叠。修复：把 σ 作为观测特征输入，或按 σ 分桶共享部分网络参数。
  • 意图信息训练时完美、评估时缺失：依赖 V2V 完美广播的策略在信息缺失时性能崩解。修复：训练时按概率遮蔽或延时意图标志，评估设置无意图信息对照。

练习与思考

  1. 计算题：己车 10 m/s、前车 6 m/s、间距 15 米，求碰撞时间；若反应时间 1 秒、最大制动 6 m/s²，判断当前间距是否满足安全距离。★
    提示
    碰撞时间为 15/4 = 3.75 秒；安全距离约为 10 + 8.33 − 3 = 15.3 米，略大于 15 米，处于临界状态。该结果说明“碰撞时间尚可”与“制动距离不足”可以同时成立。
  2. 推导题：对协调博弈写出混合策略纳什均衡，并说明为何纯策略均衡的协调需要先动信号。★★
    提示
    混合均衡中双方以一定概率让行使对方无差异；纯策略均衡存在两个但选择依赖不对称信息。先动信号（先减速或先加速）把博弈转为序贯形式，使协调有确定结果。
  3. 改参数并预测：把规划视界 τ 从 2 秒提高到 4 秒，预测通行时间、近失率与过滤触发频率的变化方向。★★
    提示
    视界变长后约束更严，近失率下降、通行时间上升、过滤触发频率上升。收益递减很快，因为视界外的不确定性使约束的保守度失真。
  4. 设计题：为汇入场景设计让行规则，说明如何用观测表达“对方是否已经在让行”，并给出双方同时犹豫时的处置方案。★★★
    提示
    用对方的加速度与相对间距变化率刻画让行意图；同时犹豫时可用时间戳或编号引入确定性优先级，避免两个策略互相等待。需要评估该规则对通行效率的代价。
  5. 实验设计：比较 σ 取 0、0.3、0.8 三种礼貌度的策略在密集与稀疏交通下的表现，说明混合动机的平衡点如何随密度变化。★★★
    提示
    稀疏交通下自利策略效率最高，密集交通下中等礼貌度最优，完全利他在任何密度下都出现僵持损失。报告指标应包含平均通行时间与冲突事件次数，并按密度分层。

小结

  • 交互式驾驶是混合动机博弈，让行与抢行构成两个纯策略均衡，协调依赖先动信号与意图表达。
  • 纵向安全由碰撞时间与安全距离共同刻画，安全距离包含反应期行驶与双方制动距离，近失率是重要的早期指标。
  • 安全过滤器把策略输出投影到安全集，保证执行安全；过滤器过度保守会造成人为拥堵，参数需按场景标定。
  • 社会价值取向参数化礼貌度，训练时采样 σ 得到策略族；对手人群与规则基线共同保证交互泛化。
