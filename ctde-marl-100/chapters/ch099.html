第 099 章：大规模扩展：从十个到上百个智能体

智能体数量上探时，联合动作空间指数增长、通信量平方增长、信用信号逐个体稀释：本章给出参数共享与局部化、平均场近似、分组分层、课程扩展四条技术路线，以及可扩展性的评估方法。

  • 主题：可扩展性（Scalability）/ 平均场近似（Mean Field）
  • 关键公式：联合空间 |A|N、平均场近似 Qi(s, a) ≈ (1/|N(i)|) Σj∈N(i) Qi(s, ai, aj)、局部通信复杂度 O(N·k)
  • 预计学时：60 分钟
  • 前置章节：第 098 章

学习目标

  • 理解规模化的三类瓶颈：联合空间指数增长、通信量平方增长与信用信号稀释。
  • 掌握参数共享与局部化设计的原理，理解置换不变性与感受野对规模的约束作用。
  • 理解平均场近似（Mean Field Approximation）的数学形式与误差随规模下降的直觉。
  • 学会组合使用分组分层与课程式规模扩展，设计从十个到上百个智能体的迁移路径。
  • 能设计可扩展性评估：性能-规模曲线、单步开销核算与瓶颈定位方法。

背景与动机

课程前面的任务大多在 2 到 10 个智能体的规模上验证；实际系统常要求 50 到 500 台设备的协同。规模改变的不只是数量：联合动作空间按 |A|N 指数增长，全连接通信按 N² 增长，团队奖励对单个智能体决策的敏感度按 1/N 稀释。小规模上有效的算法直接放大到大规模，通常同时遇到搜索困难、带宽耗尽与学习信号消失三类问题。

本章的技术路线围绕"把与 N 相关的复杂度拉回线性或常数"组织：参数共享让参数量与 N 解耦；局部化让每个智能体的计算与邻居数 k 相关，与 N 解耦；平均场近似把成对交互压缩成与分布均值的交互；分组分层把大规模系统拆成小规模子问题；课程扩展让策略在不同规模间迁移。五条路线可以叠加，组合方式取决于任务的交互结构与部署约束。

核心原理

1. 三类规模瓶颈

瓶颈增长律症状对应路线
联合动作空间|A|N集中式搜索与枚举失效值分解、平均场
通信与计算全连接 O(N²)，局部 O(N·k)链路饱和、单步耗时上升局部化、图通信、分组
信用信号单智能体影响力约 1/N梯度方差大、学习停滞局部信用、奖励分组

三类瓶颈的耦合使"单独解决一个"收效有限：只做通信局部化而信用仍全局稀释，学习曲线依旧停滞；只做信用分组而联合空间仍指数，执行期的动作协调依旧不可行。规模化的工程判断是先把瓶颈按预算逐项核算（内存、带宽、梯度方差），再选择影响最大的两条路线叠加。

2. 参数共享与局部化

参数共享让全部智能体复用同一网络权重，参数量与 N 解耦；局部观测让每个网络的输入维度与 N 解耦；置换不变聚合（均值、求和、最大）让网络对智能体编号不敏感。三者组合的结果是置换等变策略：交换智能体编号只交换输出。数学上可以对任意 N 定义同一个函数，训练时 5 个智能体的网络直接作用于 50 个智能体：

π( oi, { oj : j ∈ N(i) } ) 与 N 无关，交互复杂度 O(N·k) 条件：观测与聚合都与编号无关；k 为邻域大小，与 N 无关时总复杂度线性

参数共享付出的代价是表达能力受限：同构假设不成立时（异构能力、不同角色）需要引入类型嵌入或分组策略。工程上默认先共享、再按消融确定哪些部分需要个体化，与第 030 章异构协作的处理一脉相承。

3. 平均场近似

成对交互的 Q 分解仍需要枚举邻域联合动作；平均场近似的想法是用"邻居动作的经验分布均值"替代对每个邻居的显式建模：

Qi(s, a) ≈ (1 / |N(i)|) Σj ∈ N(i) Qi( s, ai, aj ) ≈ Qi( s, ai, āi )，其中 āi = (1 / |N(i)|) Σj aj 邻居动作先按当前策略的分布求期望（对离散动作用动作分布加权），再作为"平均队友"输入 Q 网络；查询次数从 |A|k 降为 |Ai|

误差分析直觉：邻居动作偏离均值时产生近似误差，而经验分布的方差按 1/|N(i)| 收缩，规模越大近似越准，这一点与第 088 章 Shapley 采样的中心极限直觉同源。平均场在数十到数百智能体的聚合任务上稳定可用；在强互异性任务（每个邻居角色不同）上误差不可忽略，需要退回分组或图结构建模。

4. 分组分层与课程扩展

分组把 N 个智能体切成 m 个规模为 g 的子群，子群内用第 006 至 008 章的值分解或第 088 章的联盟方法处理，子群间用稀疏协调（共享少量全局量或轮询通信）。选择 g 的原则是让子群规模落在已验证的舒适区（通常 4 到 8），从而把"大规模新问题"转化为"已知规模的老问题加组间协调"。分层则把时间轴也拆分：上层策略给出子群级指令（目标区域、队形参数），下层策略执行局部控制，两层的动作频率相差一个量级。课程扩展把规模本身当作课程维度：先在 5 个智能体上训练基础行为，再冻结部分参数微调 10 与 20 个智能体的版本，观测维度的变化用集合式编码吸收。

5. 可扩展性评估

评估包含三条曲线与两项核算：性能-规模曲线（回报或胜率对 N 的曲线，观察拐点位置）、收敛成本曲线（到达阈值所需环境步对 N 的曲线）、单步开销曲线（前向耗时与通信比特数对 N 的曲线）；核算内存（缓冲区随 N 的线性项）与梯度方差（同批量下优势估计的标准差）。可扩展性的合格线是：单步开销线性、收敛成本近似线性、性能在目标规模内不出现断崖。

实现思路与设计

规模迁移分四步：

  1. 瓶颈核算：按目标 N 计算联合空间、带宽与内存，确定主瓶颈。
  2. 结构改造：参数共享加局部观测加置换不变聚合；邻居数 k 由任务交互半径确定。
  3. 近似引入：邻域规模超过 8 个对手时用平均场或分组压缩。
  4. 课程迁移：按 5、10、20 的序列逐级扩展，逐级评估性能与开销曲线。

与第 098 章的差异点：098 章选择代码基座，本章改造算法结构；框架的并行能力支撑采样吞吐，算法结构决定参数量、通信量与梯度质量的增长律，两者共同决定可达规模。

设计决策：为什么参数共享是规模化的前提条件？

不共享参数时，模型参数量随 N 线性增长，样本复杂度同步上升：每个智能体的数据要独立支撑自己的网络。共享把有效样本量放大约 N 倍（数据跨智能体复用），参数量与 N 解耦，并带来置换等变的结构先验。没有共享，后面的局部化与平均场都失去意义，因为参数量瓶颈先于计算瓶颈出现。

关键代码与解读

片段 1：平均场动作选择

import numpy as np

def mean_field_action(q_net, obs_i, neighbor_obs, n_action=5):
    """平均场 Q：邻居动作分布取均值，再枚举自身动作求最优。"""
    # 邻居策略输出动作分布，堆叠为 (K, A)；K 为邻域大小
    probs = q_net.policy_probs(np.stack(neighbor_obs))
    mean_action = probs.mean(axis=0)          # 邻居动作的经验分布 (A,)
    # 自身动作枚举只有 |A_i| 次查询，联合空间 |A|^K 被折叠
    q_values = q_net.q_mean(obs_i, mean_action, n_action)
    best = int(np.argmax(q_values))
    return best, float(q_values[best])

# 对比复杂度：K = 16 时显式联合枚举 5^16 约 1.5e11，平均场仅 5 次查询

解读：（1）平均动作由邻居策略分布直接求期望，不需要邻居实际执行动作：这一步把平均场从"事后平均"变成"事前期望"，避免采样噪声进入 Q 估计。（2）q_mean 的输入取平均动作分布：网络对分布做特征提取（例如对动作 embedding 加权求和），信息量高于硬平均。（3）返回（最优动作, 估值）二元组，估值可进入集中式 critic 或经验回放；调用方以固定频率重算邻居分布，频率过低会让平均场滞后。（4）示例注释给出量级对比：K = 16 时显式枚举超过一千亿，平均场只需五次查询，这是规模化的直接收益。

片段 2：参数共享的局部策略网络

import torch
import torch.nn as nn

class LocalPolicy(nn.Module):
    """参数共享的局部策略：自身观测加邻居集合编码，输出动作分布。"""
    def __init__(self, obs_dim=16, n_actions=5, hidden=64, k_neighbors=4):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(obs_dim, hidden), nn.ReLU())
        self.neighbor = nn.Sequential(nn.Linear(obs_dim, hidden), nn.ReLU())
        self.head = nn.Linear(2 * hidden, n_actions)

    def forward(self, obs, neighbor_obs):
        # obs: (B, obs_dim)；neighbor_obs: (B, k, obs_dim)
        h = self.encoder(obs)
        # 邻居编码后沿邻居维取均值：置换不变，k 变化不改变输出维度
        m = self.neighbor(neighbor_obs).mean(dim=1)
        logits = self.head(torch.cat([h, m], dim=-1))
        return logits

解读：（1）邻居编码器与自身编码器分离：邻居信息需要"抽象成环境上下文"，与自身状态的处理目标不同，分离参数比共享编码器表达力强。（2）均值池化后输出维度与 k 无关，网络可直接作用于不同邻居数的场景；若改用拼接，输入维度随 k 变化，迁移即失败。（3）该网络对全部智能体共享权重，实例化一份即可服务 N 个智能体；训练时把批维度 B 与智能体维度 N 合并成 B·N，样本复用倍数随之提升。（4）邻居输入要求固定 k：不足时用零向量加掩码补齐，掩码在池化前乘入，保证缺失邻居不贡献特征。

常见坑

  • 共享网络输入仍含 N 相关项：观测里拼接全体智能体位置，输入维度随 N 变化，迁移失败。修复：改用局部观测加置换不变聚合。
  • 平均场与显式交互混用不当：小邻域上平均场引入不必要误差，大邻域上显式交互计算爆炸。修复：按邻域阈值切换，并消融验证阈值位置。
  • 课程扩展时直接继承优化器状态：规模变化后梯度尺度与批量都变，旧优化器动量引起失稳。修复：扩展时重建优化器，只继承网络权重。
  • 只测最终性能不测开销：性能持平但单步耗时涨了三倍，实际部署不可行。修复：单步耗时与通信比特数进入评估曲线，与性能并列。
  • 分组后组间协调缺位：子群各自最优导致组间资源冲突。修复：加一层稀疏协调（共享全局量或轮询），用第 089 至 091 章的机制之一承接。

练习与思考

  1. 计算 |A| = 5、N 从 4 增加到 16 时联合动作空间的增长倍数，并对比平均场方案查询次数的变化。★
    提示
    4 到 16 时联合空间从 625 涨到约 1.5×1011（约 2.4 亿倍）；平均场始终是 5 次查询，规模只影响邻居分布的计算量。
  2. 把邻域大小 k 从 4 增到 16 并保持其他不变，预测回报、单步耗时与通信比特数的变化方向，说明在哪个 k 上性能出现饱和。★★
    提示
    回报先升后平（交互半径之外的邻居贡献为零），耗时线性上升，比特数按 k 线性上升。饱和点即任务交互半径，按消融曲线定位。
  3. 推导：说明平均场近似误差为何随邻域规模下降（从邻居动作经验分布的方差按 1/K 收缩入手）。★★
    提示
    Q 对邻居动作光滑时，偏差可展开为二阶项乘以动作方差；方差约 σ²/K，K 增大误差按 1/K 衰减，光滑性差时二阶项权重上升，误差更大。
  4. 设计规模实验：同一算法在 N ∈ {5, 10, 20, 50} 上训练，报告性能-规模曲线、到达阈值步数与单步算子数量，并定位第一个明显拐点。★★★
    提示
    单步算子数量可用浮点运算次数或前向调用次数代理；拐点若出现在 N > 20，检查是否单步开销先于学习质量恶化，两项分开陈述。
  5. 设计分层方案：上层 1 个策略输出 4 个子群的目标区域，下层子群内 4 个智能体用值分解；写出两层的动作频率比与总通信量估算。★★★
    提示
    上层频率取下层的 1/10（例如 2 Hz 与 20 Hz）；通信量 = 上层广播 O(m) 加子群内 O(g²)，总计约 4 + 4×16 = 68 条消息每上层周期，远低于 16² 的全连接。

小结

  • 规模化三瓶颈：联合空间 |A|N、通信 O(N²) 与信用信号 1/N 稀释，先核算再叠路线。
  • 参数共享加局部观测加置换不变聚合，把参数量与交互复杂度分别拉回与 N 无关和线性。
  • 平均场用邻居动作分布均值折叠联合查询，误差随邻域规模下降，强互异任务需退回分组。
  • 分组分层把大规模拆成小规模子问题；课程扩展按 5、10、20、50 逐级迁移，扩展时重建优化器。
  • 可扩展性评估三条曲线：性能-规模、收敛成本、单步开销；单步开销线性是合格线。
