第四篇 · 高级机制与研究专题

第 062 章：多智能体云计算资源调度

把集群中的作业分派与资源分配建模为多个本地调度器的协同决策，用集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）在训练期评估全局队列与负载，在执行期让每个调度域独立决策。

  • 主题：集群调度 / 队列网络与异构资源分派
  • 关键公式：Qt+1 = max(0, Qt + at − ct)
  • 预计学时：60 分钟
  • 前置章节：第 061 章

学习目标

  • 掌握队列网络的离散时间模型，能写出队列更新方程并说明服务能力、到达率与积压之间的守恒关系。
  • 理解短视贪心调度失效的原因：未来到达的不确定性、资源碎片化与作业依赖图（Directed Acyclic Graph, DAG）约束。
  • 掌握按调度域划分智能体的建模方式，说明观测、动作与奖励的设计依据。
  • 能实现异构节点嵌入策略与反事实信用分配，并解释两者对训练稳定性的作用。
  • 能设计基线与消融实验，比较 CTDE 与贪心、最短队列优先（Least Loaded First, LLF）及集中式方法在平均等待上的差异。

背景与动机

经典调度按固定规则分派作业：轮询、最短队列优先或按权重分配。这些规则在负载平稳时够用，在突发与异构负载下退化，原因是只使用当前快照，无法预判后续到达。任务分派与装箱问题（bin packing）同源，属于 NP 难问题，精确求解代价随节点数增长。逐时隙的调度决策交给学习算法直接优化长期平均等待，可以绕开规则设计与精确求解的两难。

本章与前两章的差别：集群调度的耦合来自共享队列与服务能力，决策时间尺度更长（秒级到分钟级），节点容量异构。异构性由节点嵌入与动作屏蔽处理，长时程由较高折扣因子与时间抽象处理。

核心原理

本节从队列动力学出发，说明贪心为何次优，再给出多调度域建模与信用分配两条主线。

1. 队列网络模型

设集群有 K 个节点，节点 k 在时隙 t 的积压为 Qt,k，分派矩阵 Pt 的列为各节点到达量 at,k，节点每步最多服务 ck 个单位。按利特尔法则（Little's law），平均队列长度与等待时间成正比：L = λW。控制平均队长等价于控制平均响应时间，这为逐时隙奖励提供了依据。

Qt+1,k = max(0, Qt,k + at,k − ck)，目标 min limT→∞ (1/T)ΣtΣk Qt,k max 保证队列非负；服务不足时积压延续到下一时隙，构成延迟的累积

2. 贪心调度为何次优

最短队列优先每步选取当前积压最小的节点，属于短视策略。三种代价使其偏离最优：到达随机时，当前最短队列可能立刻被新作业填满；资源需求异构时，大作业塞进小容量节点造成碎片；DAG 依赖下，前置未完成的任务占用资源而无产出。价值函数对未来若干步的队列演化建模，正好覆盖这三类盲区。

容量盲区可以用一个两节点例核算：节点 A、B 的服务能力分别为每步 3 与 1，两队列均空，一个时隙内到达 4 个作业。按最短队列逐作业分派（忽略容量）时四个作业各得两个：服务后 A 清零，B 服务 1 个、余 1 个；按能力比例分派（A 三个、B 一个）时服务后两队列都清零。同样四个作业，最短队列留下 1 个单位的积压，差异来自分派规则是否使用容量信息；容量相差数倍的异构集群中，这一盲区直接放大为持续积压。

3. 多调度域智能体建模

把集群划分为 M 个调度域（例如按服务类型或机架划分），每个域由本地调度器负责把该域到达的作业分派到 K 个节点。智能体数量为 M，动作是 K 维分派分布，跨域耦合来自共享节点容量：某域占用的服务能力会挤压其他域的可用容量。每个智能体只能观测本地到达与队列估计，全局耦合通过集中式评论家在训练期建模。与单智能体全集群调度相比，这一分解把联合动作空间从 K 的指数级组合降到线性规模，执行期通信需求也随之消失。

规模的差距可以直接数出来：4 个调度域、8 个节点时，联合动作的组合数由 84 = 4096 降到每域 8 个方向的独立决策；域数升到 8 时组合数再乘 84，而分解后的每域决策规模不变。评论家仍需评估联合行为的价值，但策略采样与执行不再面对组合爆炸，这是分解式建模在规模上的核心收益。

4. 奖励与反事实信用分配

奖励采用团队信号：负载均衡项取各节点利用率的方差负数，积压项取队列总长负数，再加服务级别协议（Service Level Agreement, SLA）违背惩罚。团队奖励的缺陷是无法区分哪个调度域造成了积压，因此训练期引入反事实优势：把第 i 个域的动作替换为默认动作（例如按剩余容量比例分派），比较联合价值之差，差值即该域动作的边际贡献。

Ai = Qφ(s, a) − Qφ(s, (a−i, airef)) airef 为默认动作；Ai 衡量第 i 个域相对默认策略的增量价值，用于局部策略梯度

默认动作的选择影响反事实优势的尺度与解释：默认动作为按剩余容量比例分派时，差值度量的是相对容量均衡基线的增量；默认动作为均匀分布时，差值度量相对无信息基线的增量。两种基线下 Ai 的数值不同，但用于策略梯度时的排序作用接近，报告必须注明默认动作的定义；跨实验比较 Ai 的绝对值没有意义，同一基线下的符号分布与量级才可解读。

5. 数值算例：单节点队列的负载敏感性

设单节点每步服务能力 c=3 个单位，到达量服从均值 λ=2.5 的泊松分布，利用率 ρ=λ/c≈0.833。按 M/D/1 排队近似估计等待队长与等待时间：

Lq ≈ ρ2/(2(1−ρ))，Wq ≈ ρ/(2c(1−ρ)) ρ 为利用率；两式在 ρ 接近 1 时揭示队列长度的快速上升

代入 λ=2.5：Lq≈0.694/0.333≈2.08 个单位，Wq≈0.83 步。把到达率提高到 λ=2.9：ρ≈0.967，Lq≈0.935/0.067≈14.0，Wq≈4.8 步。

解读：利用率从 0.83 提到 0.97，平均队长扩大约 6.7 倍。非线性来自分母 1−ρ，说明调度策略的价值集中在高负载区间：低负载下最短队列优先已接近最优，学习策略的收益有限；高负载下分派差异被非线性放大，这正是复现实验必须覆盖高负载档位的原因。

补充说明非平稳到达。泊松假设只是基础情形，真实作业到达带有突发性：突发窗口内的瞬时到达率可能超过服务能力数倍，此时队列增长由突发幅度主导，平均利用率不足以描述这一形态。价值函数的观测应包含近期到达统计（滑窗均值与峰值），以区分平稳高负载与突发高负载两种形态。二者的最优分派不同：平稳形态适合预分散，突发形态适合先积累缓冲再集中清空，把两类形态混在同一条曲线上比较会掩盖策略差异。

把负载链补完整：λ = 1.5 时 ρ = 0.5，Lq ≈ 0.25 个单位、Wq ≈ 0.17 步；λ 为 2.5 与 2.9 时的队长分别约 2.08 与 14.0。从 ρ = 0.5 到 0.83 队长扩大约 8 倍，从 0.83 到 0.97 再扩大约 6.7 倍，高负载段的每一次收紧都被分母 1 − ρ 放大：低负载段各策略的差异被压到一个数量级以内，高负载段被逐级放大，评估档位的选择直接决定实验能否分辨方法优劣。

突发到达的代价用两步对照核算：服务能力 3、两个时隙总到达 6 的条件下，均匀到达 [3, 3] 使队列全程为零；突发到达 [6, 0] 在第一步积起 3 个单位，第二步才清空，产生 3 个单位的队列时间。同样的总到达量，只因时序不同就制造出可观的等待成本，这是价值函数必须观察到达统计的直接原因：只看平均到达率，两类形态在状态上无法区分。

实现思路与设计

策略网络按"作业编码 + 节点编码 + 点积打分"设计，评论家接收全局观测与联合动作，训练循环沿用策略梯度骨架。

数据流与网络结构

  1. 观测编码：作业特征含资源需求向量、预估执行步数、DAG 入度；节点特征含容量向量、当前利用率、队列长度。两类特征分别经线性层编码到 48 维。
  2. 动作生成：作业编码广播并与各节点编码相加，经打分头得到 K 维 logits，容量不足的节点在 softmax 前屏蔽为负大值。
  3. 信用分配：评论家输出联合价值，同时用默认动作的边际价值近似（边际均值）计算反事实优势，二者共用同一价值网络，避免额外参数。

设计决策：为什么用节点嵌入替代 one-hot 编号

one-hot 编号把每个节点学成独立参数，节点数变化即失效。节点嵌入让打分函数对容量相近的节点给出相近 logits，同一套参数可直接用于不同规模与配置的集群，契合拓扑频繁变化的场景。代价是表达能力略弱，需要以特征工程补偿。

与第 061 章的差异：动作为节点分派分布，奖励为队列与均衡指标，评论家不再需要物理结构先验，新增动作屏蔽与反事实信用分配。

对照的结论是分工结构决定信息需求：规则基线无需通信但缺乏预判，单智能体全局调度有预判却要求执行期全量观测，只有 CTDE 同时具备训练期全局视野与执行期零通信两个性质。选择基线时应先按目标负载区间做一轮标定，确认所选基线在该区间具有竞争力，避免用弱基线衬托方法效果。

基线标定的顺序固定为：先在目标负载区间上跑三条规则基线（轮询、最短队列、按剩余容量比例），确认哪条基线在该区间最强；再把学习策略与最强基线配对比较。负载区间按平均利用率划分，覆盖 0.5 到 0.95 的若干档位；用弱基线衬托效果属于比较设计错误，评审与复现阶段都容易被识别。

另一处易被忽略的对照维度是奖励尺度：均衡项与积压项的量级随集群规模变化，固定系数在不同规模下会改变权衡点。迁移到更大集群前，先用少量步数标定两项的均值与方差，再按比值缩放系数，这一步与第 073 章的迁移流程直接衔接；跳过标定会让迁移后的策略在均衡与吞吐之间滑向错误一侧。

关键代码与解读

片段 1：队列演化与奖励计算

import numpy as np

def step_cluster(queues, arrivals, capacity, dispatch):
    """单步集群演化：分派、服务、队列更新与奖励。
    queues/capacity: 各节点积压与服务能力；dispatch: 分派矩阵。
    """
    incoming = dispatch @ arrivals                # 逐节点聚合到达量
    served = np.minimum(queues + incoming, capacity)
    queues_next = queues + incoming - served      # 守恒：入队减服务
    # 利用率方差取负：越均衡奖励越高，等价于负载均衡正则
    util = served / np.maximum(capacity, 1e-9)
    balance = -float(np.var(util))
    # 积压惩罚系数 0.1，保证均衡项与队列项量级相当
    reward = balance - 0.1 * float(np.sum(queues_next))
    return queues_next, reward

解读：np.minimum 保证服务量不超过节点实际持有的作业，守恒式写法使队列更新天然满足非负约束，无需额外的 max 截断。奖励把均衡与积压两个目标打包为标量，均衡项用方差；改用最大值会让单节点过载主导梯度。系数取值需要随作业到达率调整，到达率升高时应加大积压项权重。

片段 2：异构节点嵌入策略

import torch
import torch.nn as nn

class NodePolicy(nn.Module):
    """作业到节点的分派策略：容量差异经嵌入表达，不使用节点编号。"""
    def __init__(self, job_dim, node_dim, emb=48):
        super().__init__()
        self.job = nn.Linear(job_dim, emb)
        self.node = nn.Linear(node_dim, emb)
        self.score = nn.Linear(emb, 1)

    def forward(self, job_feat, node_feat, invalid):
        g = torch.tanh(self.job(job_feat)).unsqueeze(1)   # 广播给所有节点
        n = torch.tanh(self.node(node_feat))
        logits = self.score(torch.relu(g + n)).squeeze(-1)
        # 容量不足的节点屏蔽为负大值，softmax 后概率趋近 0
        logits = logits.masked_fill(invalid, -1e9)
        return torch.softmax(logits, dim=-1)

解读：加法交互 g + n 假设作业与节点的匹配可分，参数量不随 K 增长，这是变长节点集合下最简洁的可行打分形式。匹配存在强交互时可改用双线性形式 gTWn，参数量随嵌入维度平方增长。屏蔽值取 -1e9；取 0 时 softmax 仍保留概率，会让非法动作长期获得梯度。

片段 3：反事实优势近似

import torch

def counterfactual_advantage(q_joint, q_marginal):
    """反事实信用分配：联合价值与"该智能体取默认动作"的价值之差。
    q_joint: [批]；q_marginal: [批, M]，每列是把第 i 个域换成默认
    动作后的价值估计（此处由边际均值近似）。
    """
    adv = q_joint.unsqueeze(-1) - q_marginal
    # 逐智能体减去均值：消除不同域的价值基线偏移
    adv = adv - adv.mean(dim=-1, keepdim=True)
    # 不反向传播差分本身：它只用于塑形各域的策略梯度权重
    return adv.detach()

解读：真正的反事实需要 M 次前向评估（每次替换一个域的动作），批量实现时把 M 个查询打包进一次前向即可。差值正表示该域的动作优于默认动作，负值则相反。detach 的目的是把信用信号当作权重使用，价值网络无需拟合这一差值，评论家目标因此不会被二次塑形。替代方案是蒙特卡洛采样反事实队友，偏差更小但需要环境交互，批量反向传播在轨迹数据上更高效。

常见坑

  • 决策频率与到达频率不匹配：环境步与调度周期取相同值时动作决策过密，价值估计被单步噪声主导。修复：显式引入时间抽象，每若干环境步决策一次。
  • 容量维度归一化混用：容量以核心数与内存兆字节混合输入，量纲差异使嵌入被大数值维度主导。修复：各维度分别按历史分位数缩放。
  • 忽略 DAG 依赖导致无效分派：前置任务未就绪的作业被分派后只占资源不产出。修复：观测中加入入度与就绪标志，或在动作生成前过滤未就绪作业。
  • 团队奖励长期掩盖慢速域：负载轻的调度域贡献固定，梯度长期接近零，策略退化。修复：启用反事实优势或按域奖励标准化。
  • 拓扑变化后复用旧经验：节点下线或扩容后，旧轨迹中的节点索引失效。修复：经验按节点特征存储，节点索引只作临时引用，拓扑变化时清空缓冲区。

    提示
    λ=2.5 小于 c=3，队列稳定；平均积压可由 M/D/1 型近似估计，随 λ 接近 c 而快速上升。
  2. 把均衡项系数从 0.1 调到 1.0，预测平均等待与最大节点利用率的变化方向，并设计验证实验。★★
    提示
    均衡项过强会拒绝把作业分给空闲大节点，等待上升但利用率方差下降；用两档系数对照曲线验证。
  3. 推导：证明分派矩阵列为概率分布时，系统总到达量守恒，即 Σkat,k 等于总新到作业量。★★
    提示
    利用每行和为 1 与矩阵乘法的定义展开求和，逐行交换求和次序即可。
  4. 设计消融实验：分别关掉反事实优势、动作屏蔽与节点嵌入，给出三组对照的预期结论与评价指标。★★★
    提示
    指标取平均等待、SLA 违背率与负载方差；屏蔽消融预期非法动作比例上升，嵌入消融预期扩容泛化变差。
  5. 单节点 c=3、到达率从 2.5 升到 2.9，用近似公式计算平均队长与等待时间的变化倍数，并解释高负载区间为何放大调度策略之间的差异。★★
    提示
    队长从约 2.08 升到约 14.0（约 6.7 倍），等待时间从约 0.83 步升到约 4.8 步；放大效应来自 1/(1−ρ) 项，选择差异的代价随拥塞同步上升。

小结

  • 集群调度等价于队列网络控制，逐时隙奖励与平均等待通过利特尔法则建立联系，长期目标可分解为可优化的单步代价。
  • 贪心的三类盲区是随机到达、资源碎片与 DAG 依赖，价值函数通过多步展望覆盖。
  • 按调度域划分智能体使联合动作空间线性化；节点嵌入与动作屏蔽是异构集群下的两项必要工程。
  • 团队奖励配合反事实优势恢复信用分配能力，差分信号以权重形式使用，不进入评论家回归目标。
  • 排队近似给出量化直觉：利用率从 0.83 升到 0.97 时平均队长扩大数倍，策略间的差距主要在高负载区间显形。
  • 突发到达与非平稳负载要求观测包含近期到达统计，策略需要区分平稳与突发两种高负载形态，两类形态下的最优分派方向相反。
