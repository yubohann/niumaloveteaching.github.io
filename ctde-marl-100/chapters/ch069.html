第四篇 · 高级机制与研究专题

第 069 章：多智能体协同决策

联合动作空间随智能体数量指数增长，本章用协调图把联合价值分解为成对效用，用最大和（max-sum）消息传递在分布式条件下求解近优联合动作，并给出与集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）衔接的训练设计。

  • 主题：协调图 / 分布式约束优化与消息传递
  • 关键公式：a* = argmaxaΣ(i,j)∈Efij(ai, aj)
  • 预计学时：65 分钟
  • 前置章节：第 068 章

学习目标

  • 理解联合动作空间指数爆炸的来源，掌握用条件独立性把联合价值分解为成对项的建模方式。
  • 掌握分布式约束优化（Distributed Constraint Optimization Problem, DCOP）的标准形式，能写出最大和消息更新并说明其在树结构上的最优性。
  • 理解环路图中消息传递的振荡现象与阻尼（damping）修复，能分析收敛性与近似质量的关系。
  • 能实现边效用网络与消息传递执行器，说明训练期集中、执行期分布式的信息边界。
  • 能设计实验比较协调图策略、独立决策与全连接价值分解在协作任务上的成功率与通信量。

背景与动机

N 个智能体、每人 m 个动作时，联合动作空间规模为 mN。小规模任务可以用贪心分解，但贪心忽略动作间交互，在需要配合的任务上损失显著；穷举联合动作在 N 增大后不可行。关键在于交互稀疏：智能体的效用大多只依赖少数几个邻居的动作，把交互结构写成图后，求解规模由图中相邻对的组合决定。

协调图方法来自分布式约束优化领域，本章把它与策略学习衔接：值网络学习边效用，执行期用消息传递选动作。与第 007 章的值分解相比，那里的分解针对全局价值单调性约束，本章的分解作用于动作选择本身，且消息传递可以在仅有邻居通信的条件下运行。这与 CTDE 的执行期信息边界天然一致：训练期用全局数据拟合边效用，执行期只需邻居间的有限轮消息交换。

核心原理

本节给出联合价值分解、最大和算法、环路处理与学习集成四条线索。

1. 联合价值分解与协调图

假设联合动作价值可以写成成对效用之和：Q(s, a) = Σ(i,j)∈Efij(s, ai, aj)，E 为交互边集合，fij 由局部观测与动作决定。最优联合动作即最大化该和式。图结构描述交互范围：链状图适合车队，环形图适合编队，全连接对应稠密交互的最坏情形。

a* = argmaxa Σ(i,j)∈E fij(ai, aj)，|a| = Πimi 视为枚举总量 图的两端是分解精度与求解代价：边越多拟合越准，求解越贵

2. 最大和消息传递

在因子图上交替传递变量到因子、因子到变量的消息，每条消息是关于某变量取值向量的函数。变量 i 发给邻居 j 的消息聚合其余邻居的贡献：

mi→j(aj) = maxai [ fij(ai, aj) + Σk∈N(i)∖j mk→i(ai) ] 消息维度等于接收方动作数；树结构图上两遍传递即收敛到最优联合动作

树结构上的最优性来自动态规划：根节点回传一遍、前向一遍即可确定全部取值。一般图的近似质量与图的树宽相关，紧环路会放大近似误差。消息维度与动作空间同阶，动作连续时需要参数化消息分布，工程上常先离散化动作或改用值采样。

3. 环路图与阻尼

环路图中消息可能振荡：两条互相缠绕的路径反复放大同一方向误差。阻尼更新对旧消息与新消息做凸组合：m ← (1−β)m旧 + βm新，β 取 0.3 至 0.7。阻尼降低振荡幅度并放缓有效收敛速度，需要更多迭代轮数。停止准则可用消息变化的无穷范数低于阈值，或固定迭代上限以匹配控制周期。

4. 训练与执行的分工

训练期用集中式数据拟合边效用网络 fij(τi, ai, τj, aj; θ)，损失为时序差分误差对联合动作最小化。执行期各智能体只持有与邻居的边效用副本，运行有限轮消息传递得到动作分布，按分布采样执行。这构成 CTDE 的完整闭环：价值拟合需要全局数据，动作选择只需局部通信。

5. 数值算例：链式图上的消息传递

三个智能体构成链 1−2−3，每员两个动作。边效用取 f12=[[1, 3], [2, 0]]（行是 a1，列是 a2），f23=[[0, 2], [4, 1]]（行是 a2，列是 a3）。

穷举参照。a2=1 时，左侧最优 f12(·, 1) 取 2，右侧最优 f23(1, ·) 取 2，合计 4；a2=2 时，左侧最优取 3，右侧最优取 4，合计 7。全局最优为 (a1, a2, a3)=(1, 2, 1)，总分 7。

消息传递复算。叶到中心：m1→2(a2)=(2, 3)，m3→2(a2)=(2, 4)。中心聚合得 (2+2, 3+4)=(4, 7)，argmax 取 a2=2。中心到叶：m2→1(a1)=maxa2[f12+m3→2]=(7, 4)，取 a1=1；m2→3(a3)=maxa2[f23+m1→2]=(7, 4)，取 a3=1。最终 (1, 2, 1) 与穷举一致，两条消息同时携带了各自子树的最优选择。

解读：两遍传递后每个变量的入边消息之和等于全树最优分解，第三遍不产生新信息，这是树结构上动态规划的本质。若在 1 与 3 之间加一条边形成环，同一组更新进入循环依赖，需要阻尼与迭代上限，且最优性不再有保证，只能收敛到近似解。

推导补充：消息维度为何等于接收方的动作数。因子到变量的消息需要为接收方每一个动作取值各给一个数，表示接收方选该动作时因子分支能达到的最大贡献。把消息压缩成标量会丢失动作条件，回传阶段无法恢复最优选择，所以维度代价是每边 O(|A|)，与动作数线性相关。动作空间连续时需要以函数形式传递消息，工程上常用离散化或分量近似，两类近似都会在回传阶段引入偏差，需要以联合价值的下界做校验。

实现思路与设计

网络分两层：局部编码器把观测映射到嵌入，边效用头对邻居嵌入与动作对打分。执行器的消息传递独立实现，与训练网络共享边效用参数。

设计决策：为什么把图结构与图神经网络解耦

把交互结构直接编进网络参数（例如全连接价值网络）无法在智能体数量变化时复用；把图结构作为输入（邻接表与边特征）则使同一套参数适配不同规模的协作。训练时随机切换拓扑（链条、环、随机稀疏图）可以提升执行期的结构泛化，代价是每种拓扑的边缘效用都要覆盖足够的样本，训练步数需求上升。工程上建议固定目标任务族内的两种典型拓扑交替采样。

与第 068 章的差异：动作从连续速度换成离散选择，决策对象从瞬时安全换成长期协作收益；执行器需要消息传递模块，通信量以边数与迭代轮数的乘积计。

对比分析：四类联合决策路线

路线决策质量求解计算量执行期通信结构泛化
独立决策忽略交互，协作任务损失大最低无好
协调图加消息传递树图最优、环图近似边数乘动作对数邻居间有限轮好（图作输入）
全连接值分解表达力强，结构约束需谨慎随动作组合增长训练集中、执行无差（规模绑定）
穷举联合动作精确指数增长训练集中不适用

路线取舍的核心是交互密度：交互稀疏时协调图以线性规模的计算逼近精确解；交互稠密时图趋于全连接，消息维度与迭代轮数的通信代价可能超过集中式求解。选择前先估计任务中的有效交互度，即每条边对联合价值的贡献幅度，再决定图结构与迭代预算，避免把"图看起来稀疏"当成"交互确实稀疏"。

补充阻尼参数的数值经验：阻尼系数取 0.5 时，环形图上消息变化范数通常在前 6 到 10 轮进入平台；取 0.3 时收敛更稳但轮数约翻倍；取 0.8 时前期振荡幅度明显。复现实验可以固定轮数上限并检查范数曲线是否进入平台，未进入平台的配置应提高轮数或减小阻尼；把近似误差直接归因于网络容量会掩盖真正的收敛问题。

再补充消息压缩的衔接点：消息维度与轮数的乘积决定每步通信量，训练期可学习低维投影（编码器在发送侧共享），邻居侧完成解码。投影维度过低会破坏接收方的条件分辨力，退化体现在动作质量上，通信量本身仍按压缩比下降；做压缩消融时以"动作分布与未压缩版本的散度"作为质量指标，比全局回报更快暴露退化。

关键代码与解读

片段 1：边效用网络

import torch
import torch.nn as nn

class EdgeUtility(nn.Module):
    """对相邻动作对打分：f_ij(a_i, a_j) = 嵌入点积加动作偏置。"""
    def __init__(self, obs_dim, act_dim, emb=64):
        super().__init__()
        self.obs_enc = nn.Sequential(nn.Linear(obs_dim, emb), nn.ReLU())
        self.act_emb = nn.Embedding(act_dim, emb)   # 动作嵌入表
        self.bias = nn.Embedding(act_dim, 1)        # 个体动作偏置

    def forward(self, obs_i, obs_j, a_i, a_j):
        # 双方观测各自编码后相加，实现参数共享
        e_i = self.obs_enc(obs_i) + self.act_emb(a_i)
        e_j = self.obs_enc(obs_j) + self.act_emb(a_j)
        pair = (e_i * e_j).sum(-1)                  # 点积交互项
        return pair + self.bias(a_i).squeeze(-1) + self.bias(a_j).squeeze(-1)

解读：点积交互项参数量固定，动作对评分不需要为每对 (ai, aj) 单独存储参数，动作数增大时表规模线性增长。个体偏置承担与邻居无关的收益分量。需要表达更强交互时可以改用双线性形式或小型多层感知机，代价是计算量随边数增长。观测编码器在所有邻居间共享，这是参数效率的来源。

片段 2：最大和消息传递

import numpy as np

def max_sum(edge_utils, n_agents, act_dim, iters=10, beta=0.5):
    """离散动作空间的最大和消息传递。
    edge_utils[(i, j)]: 形状 [act_dim, act_dim] 的效用矩阵。
    返回每个智能体的动作边缘分布。
    """
    neighbors = {}
    for (i, j) in edge_utils:
        neighbors.setdefault(i, []).append(j)
        neighbors.setdefault(j, []).append(i)
    msg = {e: np.zeros(act_dim) for e in edge_utils}   # 变量到因子
    for _ in range(iters):
        new = dict(msg)
        for i, nbrs in neighbors.items():
            for j in nbrs:
                # 收集其余邻居发来的消息并求和
                incoming = np.zeros(act_dim)
                for k in nbrs:
                    if k != j:
                        incoming += msg.get((k, i), np.zeros(act_dim))
                # 对自身动作取最大：得到发给 j 的消息
                table = edge_utils[(min(i, j), max(i, j))]
                table = table.T if (min(i, j), max(i, j)) != (i, j) else table
                new[(i, j)] = (table + incoming).max(axis=0)
                # 阻尼：新旧消息凸组合，抑制环路上的振荡
                new[(i, j)] = (1 - beta) * msg[(i, j)] + beta * new[(i, j)]
        msg = new
    return msg

解读：消息用字典按有向边存储，无向边的效用矩阵按索引顺序决定转置方向，转置处理是这类实现最容易出错的细节。阻尼在每轮更新后施加，与不动点迭代结合可稳定环路。收敛后的动作由入边消息之和的 argmax 恢复，返回边缘分布则可与采样执行衔接。

片段 3：训练目标

import torch

def coordination_td_loss(q_edges, target, actions, gamma_discount=0.98):
    """边效用之和逼近时序差分目标。
    q_edges: [批, 边数] 各边当前效用；target: [批] 自举目标。
    """
    q_joint = q_edges.sum(dim=-1)            # 联合价值 = 边效用之和
    td = target - q_joint
    # Huber 损失：对离群目标更稳健，避免个别边爆炸拉偏全图
    loss = torch.where(td.abs() < 1.0, 0.5 * td ** 2, td.abs() - 0.5)
    return loss.mean()

解读：边效用之和作为联合价值，与值分解系列的结构一致，区别在于本结构的优化目标不施加单调性约束，允许边效用为负，适合存在取舍的协作任务。Huber 损失抑制重放缓冲区中离群目标的影响，与因子图中单个边错误传播的放大效应相对应。目标值的计算使用目标网络与最大和选出的动作，截断梯度避免目标漂移。

常见坑

  • 环路消息不收敛：无阻尼迭代在环形拓扑上进入极限环，动作选择抖动。修复：启用阻尼并按消息变化范数设定停止准则。
  • 消息未中心化：消息数值随迭代持续增长，数值溢出。修复：每轮减去消息均值，动作选择不受影响。
  • 边集过密：把全连接当作协调图，求解代价退化为穷举。修复：按感知半径或互信息剪枝，保留交互强度前若干条边。
  • 执行期通信超预算：迭代轮数与边数乘积超过链路能力。修复：减少轮数并接受近似误差，或先在训练中把消息压缩到低维。
  • 边效用过拟合单拓扑：固定拓扑训练后换环境性能骤降。修复：训练期交替多种拓扑，并对边集剪枝做随机化。

  3. 推导：树结构上证明两遍消息传递后，每个节点的最优动作可由入边消息和给出，并说明为何无需第三遍。★★★
    提示
    树无环，任选根做后序传递得到子树上值函数，前序传播其余部分；入边消息和即全体贡献，根节点动作取 argmax 后其余节点已在消息中携带最优选择。

    提示
    通信量按边数×轮数×消息维度统计；预期协调图在成功率接近全连接的同时把通信量降一个量级，独立基线在需要配合的奖励项上显著落后。
  5. N=12 智能体、平均度 3、每员 5 个动作：分别估算穷举联合动作总数与消息传递单轮运算量（按边数乘动作对数乘方向计），给出两者数量级之比并解释稀疏结构的价值。★★

    穷举规模 512≈2.44×108；边数约 18，单轮运算约 18×2×25≈900，两者相差约 2.7×105 倍。稀疏交互把指数复杂度降为线性结构复杂度，这是协调图可行的前提。

小结

  • 协调图把联合价值分解为成对效用，求解规模由图结构与单边动作组合决定，稀疏交互是可行的前提。
  • 最大和在树结构上两遍传递即得最优联合动作，环路图转入近似领域，阻尼与停止准则是必要工程。
  • 执行期的消息传递只依赖邻居通信，与 CTDE 的执行边界一致；训练期用全局数据拟合边效用。
  • 边效用的点积交互形式控制参数量，随机切换训练拓扑提升结构泛化，边集剪枝需权衡精度与代价。
  • 链式图算例展示两遍传递即达最优：消息携带子树的最优值，中心聚合后回传确定全体动作，环图则转入需要阻尼的近似领域。
