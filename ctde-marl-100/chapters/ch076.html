第四篇 · 高级机制与研究专题

第 076 章：分层强化学习与CTDE结合

用时间抽象拆解长时程协作任务：本章从半马尔可夫决策过程（Semi-Markov Decision Process, SMDP）的性质讲起，给出高层协调者与低层执行者的两时间尺度结构，再讲分层信用分配与与集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）的衔接。

  • 主题：时间抽象 / 半马尔可夫决策与分层信用
  • 关键公式：Q(s,o) = E[r + γkmaxo′Q(s′,o′)]，k 为选项持续步数
  • 预计学时：65 分钟
  • 前置章节：第 075 章

学习目标

  • 掌握半马尔可夫决策过程的定义与折扣形式，理解可变持续时间动作对回报计算的影响。
  • 理解两层结构的非平稳来源：高层策略变化使低层面对的目标分布漂移，反之亦然。
  • 掌握分层信用分配的两个手段：内在奖励塑形与目标重标注（relabeling）。
  • 能实现变时长回报计算与目标重标注两个片段，并解释持续时间在折扣中的处理方式。
  • 能设计实验：平铺式 CTDE 基线、固定动作重复对照、子目标频率与重标注的消融。

背景与动机

长时程协作任务的原始动作序列长达数百步，稀疏奖励下的信用分配需要把奖励信号传播回溯很远。分层结构让高层每隔若干步做一次粗粒度决策（目标点、队形、区域分配），低层在短时间内完成具体动作序列，有效决策视界被缩短为原来的若干分之一，探索的尺度也随之分层：高层决定去哪里，低层探索怎么去。

多智能体与分层结合有两个直接收益：协调通信只在高层时间尺度发生，带宽需求大幅下降；高层可以用集中式信息做全局意图分配，与 CTDE 的训练期信息边界吻合。本章与第 077 章的区别：本章聚焦时间尺度分解与半马尔可夫性质，下一章聚焦技能本身的结构与自动发现。

核心原理

本节建立 SMDP 形式、两层结构与分层信用分配三条线索。

1. 半马尔可夫性质与折扣形式

选项 o 由三元组定义：起始集合、内部策略与终止条件。选项在状态 s 启动后持续 k 步，累积回报按每步折扣叠加，总折扣因子为 γk。选项价值满足自洽方程：

Q(s, o) = E[ Σi=0k−1γirt+i + γk maxo′ Q(st+k, o′) | st=s, ot=o ] 求和项为选项执行期间的即时回报，尾项为选项终止后的续值；k 随机时取期望

持续时间随机使折扣因子本身成为随机变量，用 γk 的期望近似替代逐项展开，是大多数分层实现采用的时间折算方式。当高层决策周期固定为 c 步时，高层折扣可直接取 γc，实现上只需把高层回报按 c 步聚合成一次更新。

2. 两层结构与协同分工

高层协调者每隔 c 步输出联合子目标 g = (g1, …, gN)，低层各智能体以 (观测, 子目标) 为输入输出原始动作。低层的奖励为环境奖励加上子目标逼近奖励（距离变化量），高层的奖励为环境奖励在 c 步上的累积。高层可以在训练期使用全局状态选择子目标，低层只依赖局部观测与子目标执行，形成清晰的两级 CTDE 边界。层间通信频率降低为原来的 1/c，这是工程上最直接的收益。

3. 分层信用分配

低层策略由高层子目标引导，但子目标可能不可达或与最优协作冲突。两种手段互补：内在奖励塑形给低层提供子目标追踪的即时反馈，使低层在稀疏环境奖励下仍可学习；目标重标注在回放时为失败轨迹改写子目标为实际到达的状态，让低层训练数据与可达性重对齐。重标注本质是把"未能到达的目标"替换为"实际达成的目标"，使正样本比例大幅提高，长时程任务的样本效率因此改善。

4. 非平稳与训练节奏

两层交替更新时互为非平稳环境：高层改进使低层的目标分布漂移，低层改进使高层的价值估计失效。稳定手段有三：冻结一方更新另一方若干轮、按比例放缓高层更新频率、对另方策略加入滞后副本（类似目标网络）。工程上推荐"低层先热身、高频更新，高层低频且用滞后低层评估"的节奏。

5. 数值算例：段内折扣、时域压缩与重标注

取 γ=0.98、高层间隔 c=15：高层折扣 γc=0.9815≈0.739。若选项执行期间每步获得 1 单位奖励，段内折扣和 Σi=014γi≈(1−0.739)/0.02≈13.07，尾折扣 0.739 乘续值估算，两段相加即高层目标的构成。

时域对照。c=5 时 γc≈0.904，高层有效视界 1/(1−0.904)≈10.4 个高层步，折算约 52 个环境步；c=40 时 γc≈0.446，有效视界约 1.8 个高层步，折算约 72 个环境步。平铺结构的有效视界为 1/(1−0.98)=50 个环境步。三者的折算视界同量级，说明 γc 的作用是保持两层在真实时间轴上的折扣尺度一致，c 调整时该参数必须联动。

重标注算例。某段轨迹的原子目标距实际到达位置 3 米，按原子目标计算的内在奖励全程为负；重标注把目标改为实际到达位置，按新目标的距离缩短量重算后，多数转移获得非负奖励，正样本比例从约两成提升到八成量级，低层的到达技能因此可以持续学习。

解读：三组数字分别回答高层折扣取多少、c 变化时视界如何移动、重标注得到什么。c 的选取与子任务完成步数的中位数挂钩：过小则高层退化为平铺，过大则尾折扣过小、远期信号被压扁，两种偏差都会削弱分层的意义。

工程上把 c 与高层折扣写进同一处配置对象派生，c 修改时折扣自动重算，可以避免手工同步的遗漏；检查方式是打印首段轨迹的高层回报与手算值对照，两者偏差超过截断误差量级即说明折扣联动未生效。

实现思路与设计

训练循环分内外两层：低层在每个环境步更新，高层每 c 步聚合一次轨迹片段更新；共享回放缓冲区按管理层级分区。

实验设计

  1. 对比基线：平铺式 CTDE（无时间抽象）、固定动作重复（框架动作重复 c 步）。
  2. 消融设置：去掉重标注、去掉内在奖励、c ∈ {5, 15, 40}、高层子目标全局共享与个体独立两档。
  3. 评价指标：任务成功率、达到门槛的交互步数、子目标到达率、高层通信次数。
  4. 统计方式：多随机种子，报告成功率的置信区间与子目标到达率分布。
设计决策：为什么高层折扣取 γ 的 c 次幂

把高层更新视为在"压缩时间轴"上的决策，每隔 c 步记一个高层转移。若按原始 γ 计算高层回报，高层的有效规划视界会被放大 c 倍，价值估计被远期噪声主导。用 γc 折算后两层在真实时间上的价值尺度一致，高层对远期回报的折扣速度与低层相符。c 变化时需要同步调整高层折扣，这是复现实验最容易遗漏的参数联动。

与第 075 章的差异：多任务学习并行学习多个目标，本章纵向拆解单一长时程目标；新增层间信用分配与两套时间折扣的协调问题。

对比分析：三类时间结构的取舍

结构决策频率信用分配跨度层间通信失效模式
平铺式 CTDE每环境步原始步数尺度每步长时程稀疏奖励下难收敛
固定动作重复每 c 步，无子目标缩短 c 倍每 c 步缺少中间表示，探索仍受限
分层（本章）低层每步、高层每 c 步两层分解每 c 步层间非平稳、重标注偏差

取舍的核心是子任务是否可定义：任务能自然拆成去哪里与怎么去时分层收益最大；子目标难以表达或层间冲突剧烈时，固定动作重复以更低的复杂度获得部分收益，适合作为低成本基线先行验证，再决定是否引入完整分层。

两套折扣的联动检查清单：修改 c 时同步修改高层折扣与段内折扣报告口径；重标注比例、内在奖励系数与到达率三项指标联测；低层热身步数以到达率曲线的拐点为准，取固定常数容易错配。把这三项写进配置表，复现时最常被遗漏的参数联动就都有迹可循。

关键代码与解读

片段 1：变时长回报计算

import numpy as np

def smdp_return(rewards, gamma=0.98, c=15):
    """把 c 步低层回报聚合为一次高层回报。
    rewards: 长度为 c 的低层即时奖励序列。
    """
    discounts = gamma ** np.arange(len(rewards))
    total = float((discounts * rewards).sum())
    # 尾值为选项结束后的续值折扣：与高层折扣 gamma^c 对齐
    tail = gamma ** len(rewards)
    return total, tail

解读：高层目标即"最大化 ⟨聚合回报 + 尾折扣乘续值估算⟩"。聚合回报内部的折扣（γi）与高层折扣（γc）解释的是同一时间轴，二者必须一致，工程上用同一个 gamma 常数派生。实际实现常忽略段内折扣（取 1），段长 c 越小误差越小。

片段 2：子目标重标注（HIRO 风格）

import numpy as np
import random

def relabel_subgoal(rollout, sampled_proportion=0.8):
    """把未达成的高层子目标改写为轨迹实际到达的状态。
    rollout: 含 (state, subgoal, reward, next_state) 的片段列表。
    """
    out = []
    for (s, g, r, ns, done) in rollout:
        if random.random() < sampled_proportion:
            g_new = np.asarray(ns[:2])      # 新目标取本次转移到达的位置
            # 内在奖励按"到新目标的距离缩短量"重算，恒为非负
            d_before = np.linalg.norm(np.asarray(s[:2]) - g_new)
            d_after = np.linalg.norm(np.asarray(ns[:2]) - g_new)
            r_new = float(d_before - d_after)
        else:
            g_new, r_new = g, r
        out.append((s, g_new, r_new, ns, done))
    return out

解读：重标注把"失败样本"改写为"达成另一个目标"的成功样本，高层给出的远端子目标不可达时，低层仍获得有指导意义的训练信号。采样比例控制改写强度，全部改写会引入估计偏差。新目标的选取通常用未来若干步内的状态采样，位置分量是常用选择，与子目标空间的维度一致。

片段 3：低层目标条件策略的编码

import torch
import torch.nn as nn

class GoalConditionedActor(nn.Module):
    """低层策略：输入观测与子目标，输出原始动作分布参数。"""
    def __init__(self, obs_dim, goal_dim, act_dim, emb=64):
        super().__init__()
        self.obs_enc = nn.Linear(obs_dim, emb)
        self.goal_enc = nn.Linear(goal_dim, emb)
        self.trunk = nn.Sequential(nn.Linear(emb, emb), nn.ReLU())
        self.head = nn.Linear(emb, act_dim)

    def forward(self, obs, goal):
        # 子目标编码与观测编码相加：目标作为状态的一部分参与决策
        h = torch.relu(self.obs_enc(obs) + self.goal_enc(goal))
        return self.head(self.trunk(h))

解读：把子目标编码为可加项让策略同时保留"当前处境"与"期望达成"两路信息，子目标在重标注后频繁变化，策略对目标输入的敏感性因此被强化。目标空间的尺度需要与观测归一化同步，否则相对距离的量纲差异使目标编码的主导性失衡。动作头沿用各规范的高斯或分类输出。

常见坑

  • 高层折扣未随 c 折算：沿用 γ 导致高层价值被远期噪声主导，训练发散或停滞。修复：高层折扣取 γc，c 调整时同步修改。
  • 终止条件坍缩：终止头退化为每步终止，分层退化为平铺结构。修复：惩罚过早终止或对终止事件加入最小持续步数约束。
  • 层间非平稳无缓冲：两层同步高频更新互相追逐。修复：低层热身、高层用滞后副本评估、按比例放缓高层更新。
  • 重标注与内在奖励口径不一致：重标注后回报未按新目标重算，低层学到矛盾信号。修复：重标注与奖励重算必须成对执行，作为原子操作。
  • 子目标超出可达范围：高层输出远端子目标，低层长期无法到达，内在奖励恒负。修复：对子目标做可达性裁剪或加入到达可行性过滤。

练习与思考

  1. c=15、γ=0.98，手算高层折扣值；再取 c=5 与 40 比较，说明 c 与规划视界的关系。★
    提示
    0.9815≈0.74；c 越大高层单步跨越更长时间，γc 越小，高层视界被压缩为约 1/(1−γc) 个高层步。
  2. 把内在奖励系数从 0.1 调到 1.0，预测子目标到达率与环境成功率的变化。★★
    提示
    系数过大时低层只顾追目标、不顾环境奖励，到达率上升但成功率下降；两指标交叉点即合适量级。
  3. 推导：在选项持续步数恒为 c、段内折扣忽略的简化下，说明高层贝尔曼方程退化为普通 MDP 形式且折扣为 γc。★★★
    提示
    把每 c 步定义为一个高层时间步，回报求和与尾项合并即得标准形式。
  4. 设计实验：对照"高层全局子目标"与"个体独立子目标"在搬运协作任务上的成功率与通信次数。★★★
    提示
    全局子目标隐含协调但限制个体自由度；统计成功率、子目标到达率与高层消息字节数三组指标。
  5. 取 γ=0.98，计算 c=15 时的高层折扣与段内折扣和；把 c 改为 5 与 40 后比较折算的环境步视界，说明 c 应以什么量为选取依据。★★
    提示
    0.9815≈0.739，段内折扣和约 13.07；c=5 时折算约 52 步，c=40 时约 72 步。c 应与子任务完成步数的中位数匹配，过大或过小都会削弱分层结构。

小结

  • 分层结构把长时程任务拆成两套时间尺度，SMDP 用可变持续时间动作描述选项价值，高层折扣需按 γc 折算。
  • 高层协调者用全局信息分配子目标，低层以目标条件策略执行，层间通信频率降为 1/c。
  • 分层信用分配由内在奖励塑形与目标重标注共同完成，两者必须口径一致；重标注显著提升长时程样本效率。
  • 两层互为非平稳环境，靠热身、更新比例与滞后副本稳定训练节奏。
  • 数值算例把两套折扣的联动量化：c=15 时高层折扣约 0.739，c 在 5 到 40 之间移动时折算视界在 50 到 72 个环境步内变化，与平铺结构的 50 步同量级。
  • 重标注把不可达目标的失败样本改写为达成新目标的成功样本，正样本比例从两成量级升到八成量级，是长时程任务样本效率改善的主要来源。
