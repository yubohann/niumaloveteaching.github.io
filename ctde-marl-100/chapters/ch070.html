第四篇 · 高级机制与研究专题

第 070 章：多智能体协同学习

把训练本身分散到多个学习节点：本章讲清分布式随机梯度下降（Decentralized Stochastic Gradient Descent, D-PSGD）的混合步、共识误差与拓扑谱隙的关系，以及通信压缩与误差反馈的配合方式，并把它落到集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）的参数同步上。

  • 主题：去中心化训练 / 共识、压缩与同步策略
  • 关键公式：θi(t+1) = ΣjWijθj(t) − ηgi(t)
  • 预计学时：65 分钟
  • 前置章节：第 069 章

学习目标

  • 理解分布式训练的目标函数形式，区分参数服务器与去中心化两种数据流。
  • 掌握混合矩阵（mixing matrix）驱动的共识步骤，能说明谱隙与收敛速度的关系。
  • 掌握误差反馈（error feedback）压缩机制，解释它为何能抵消量化带来的系统偏置。
  • 能实现联邦平均、D-PSGD 混合步与压缩传输三个片段，并说明在 CTDE 中哪些参数适合同步、哪些适合本地保留。
  • 能设计实验比较同步平均、异步更新与压缩通信在样本效率与通信量上的帕累托表现。

背景与动机

多智能体系统的训练往往天然分布：每个智能体或每组智能体在本地采集轨迹，本地计算梯度，若把全部轨迹集中到单机再训练，带宽与存储成本随规模线性增长。分布式的替代方案有两种：参数服务器汇总梯度（星形结构，中心带宽瓶颈），或节点间直接交换参数（去中心化结构，每节点只与邻居通信）。去中心化结构的收敛速度由通信拓扑决定，这正是需要理解混合矩阵的原因。

与第 039 章异步更新、第 040 章经验共享相比，本章的对象是训练系统本身：梯度如何混合、参数如何压缩、节点间漂移如何控制。落在 CTDE 上，策略与评论家参数的同步时机直接影响训练稳定性：评论家需要与策略同步演化，而各节点的经验分布随策略变化而漂移。本章的方法解决"分布式训练能否达到单机训练的质量"这一核心问题。

核心原理

本节从目标函数与两种数据流出发，推导共识步骤、压缩机制与 CTDE 的衔接设计。

1. 目标函数与两种数据流

K 个节点各自持有本地目标 fk（由本地轨迹的时序差分损失构成），全局目标为平均：minθ F(θ) = (1/K)Σkfk(θ)。参数服务器每轮收集全部梯度求平均，通信量与 K 成正比且中心节点承载全部流量。去中心化结构让每个节点维护本地参数 θi，与邻居交换后执行混合与梯度步。

θi(t+1) = Σj∈N(i)∪{i} Wijθj(t) − ηgi(t) W 为双随机矩阵（行和列和均为 1）；gi 为本地梯度；η 为学习率

2. 共识误差与谱隙

把参数堆叠为矩阵 Θ，混合步等价于 Θ ← WΘ。W 的特征值 1 对应共识方向，第二大特征值 λ2 的模决定误差衰减速度：共识误差按 |λ2|t 衰减，1/(1−|λ2|) 称为混合时间。环状拓扑的 |λ2| 接近 1，混合慢；完全图与星形结构混合快。网络越稀疏，每一轮的通信量越低，但需要更多轮才能达到同等共识。

3. 压缩与误差反馈

带宽受限时对交换的梯度或参数做压缩：量化到低位宽、稀疏化（只传输幅值最大的分量）或随机投影。直接压缩引入偏置，尤其量化误差会随迭代累积。误差反馈把未传输的残差记入下一次发送的补偿量：ei(t) = gi(t) + ei(t−1) − C(gi(t) + ei(t−1))，发送 C 的输出，保留残差。该机制保证压缩误差在时间上平均为零，收敛性质与未压缩情形一致（学习率量级相同的情况下）。

mi(t) = C(gi(t) + ei(t−1))，ei(t) = gi(t) + ei(t−1) − mi(t) C 为压缩算子；e 为误差记忆，逐节点独立维护

4. 与 CTDE 的衔接

训练系统通常包含共享的策略网络与集中式评论家。适合全局同步的是评论家参数与共享特征层：各节点用本地轨迹计算评论家梯度再混合，等价于在全体数据上训练。各节点本地保留的是采样分布与探索噪声，用于制造轨迹多样性。同步周期 τ 是精度与通信的折中：τ 过大时各节点的策略分叉，评论家对别人策略的评估失效；τ 过小则通信开销占比过高。

5. 数值算例：混合矩阵的谱与压缩残差

完全图算例。四节点完全图取等权混合：非对角元 1/3、对角元 0。混合矩阵的特征值为 1（共识方向）与 −1/3（三重）。初始参数偏差每混合一次按 1/3 衰减，三轮后约为初始的 3.7%，五轮后约 0.4%。

环形图算例。四节点环取 Metropolis 权重 0.5，特征值为 1、0、−1、0。−1 特征值对应二部图上的周期振荡，参数在两组节点间来回摆动，纯线性混合不收敛到共识。加自环的惰性化处理把非主特征值折半到 0.5，偏差每轮乘 0.5，七轮后约为初始的 0.8%。

压缩算例。梯度 1000 维、稀疏度 10%，每轮发送 100 个分量。关闭误差反馈时未被选中的 900 个分量永久丢失；开启后残差累积，按幅值排序的发送在有限轮内覆盖全部维度，压缩只改变发送的时间分布，不改变总量。

解读：三组数字对应三个设计点。其一，拓扑的谱隙决定混合速度，完全图快而环图慢，稀疏拓扑需要更多轮或更小学习率；其二，二部图的 −1 特征值说明拓扑分析必须检查全部特征值，只看 λ2 会漏掉振荡风险；其三，误差反馈把压缩的长期误差压回零，是带宽受限训练的必要组件。

推导补充：双随机性为何对共识至关重要。行和为 1 保证每轮混合是凸组合，参数不会被系统性放大，共识方向（全 1 向量）在混合后保持不变；列和为 1 保证参数均值恒定。仅行和为 1 的矩阵可能把参数均值系统性推高或压低，均值漂移与梯度步叠加后，有效学习率会偏离标定值。Metropolis 构造只需邻居度数即可本地计算，是在拓扑动态变化下维持双随机性的常用手段。

学习率与谱隙的联动在环形与完全图之间有数值对应：若完全图用 5e-4 收敛良好，4 节点惰性化环图的等效噪声方差约为完全图的 4/3 倍，学习率应降到约 3.75e-4 起步再微调（环的节点数增大后折算系数继续下降，大环按完全图的三分之一到二分之一取）。跳过这一缩放，环图配置常在训练中期出现节点间参数差持续上升的现象。

设计决策：为什么学习率要随拓扑调整

共识误差进入梯度方向后等效为额外的噪声项，噪声方差与 (1−|λ2|) 的倒数成比例。稀疏拓扑下必须减小学习率，否则参数的节点间差异被放大为训练振荡。经验规则是学习率随混合时间反向缩放：环状拓扑取完全图情形的三分之一到二分之一。判断依据是观察节点间参数差的范数轨迹，若持续上升即需要降学习率或加密通信。

对比分析：四类分布式训练结构

结构每轮通信量收敛速度节点失效影响实现复杂度
参数服务器（星形）随节点数线性，中心汇聚全部流量快（单轮全局聚合）中心失效则全体停摆低
去中心化环形每节点两条链路慢（谱隙小）单点失效只延迟局部传播中
去中心化完全图每节点 N−1 条链路最快鲁棒中
异步参数服务器与同步相近快但引入陈旧梯度容错好高（需要版本控制）

结构选择的判据是带宽预算与故障模型：星形适合带宽充足且中心可靠的部署；去中心化适合链路受限或中心不可靠的场景。介于两者之间的折中是分层结构，先组内星形聚合再在代表节点间环形混合，谱隙接近星形而单点风险被限制在组内，代价是两套同步逻辑与更多的超参数。

补充同步周期的数值感受：τ=50 时，节点间参数差的范数通常稳定在单步梯度尺度的数倍以内；τ 提到 500 后节点策略分叉，评论家对非本地策略的评估误差随分叉累积，曲线在中段先表现为平台停顿，发散随后逐步显现。诊断方法是每个混合周期记录节点间参数差的范数与均值，两者中任一显著偏离历史区间即说明 τ 需要回退，或学习率需要同步下调。

关键代码与解读

片段 1：联邦平均与权重

import numpy as np

def federated_average(states, weights=None):
    """按权重平均各节点参数（或梯度）。
    states: 列表，每项为参数字典；weights: 节点权重，默认均匀。
    """
    n = len(states)
    if weights is None:
        weights = np.full(n, 1.0 / n)
    # 按数据量加权优于均匀平均：样本多的节点噪声更小
    avg = {}
    for key in states[0]:
        stacked = np.stack([s[key] for s in states], axis=0)
        avg[key] = np.tensordot(weights, stacked, axes=1)
    return avg

解读：权重默认均匀，按本地轨迹数量加权可以降低方差较大的节点的影响。平均的对象必须是同一时刻的参数快照，混入不同训练步的参数会引入系统性偏差，实现上常用版本号或双缓冲保证一致性。参数字典的遍历顺序由第一项决定，要求各节点网络结构一致。

片段 2：D-PSGD 混合步

import numpy as np

def metropolis_weights(adj):
    """由邻接矩阵构造 Metropolis 双随机混合矩阵。
    adj[i, j] = 1 表示 i、j 互为邻居。
    """
    n = adj.shape[0]
    W = np.zeros((n, n))
    degree = adj.sum(axis=1)
    for i in range(n):
        for j in range(n):
            if i == j:
                W[i, j] = 1.0 - sum(
                    min(1.0 / max(degree[i], 1), 1.0 / max(degree[k], 1))
                    for k in np.nonzero(adj[i])[0])
            elif adj[i, j]:
                W[i, j] = min(1.0 / max(degree[i], 1), 1.0 / max(degree[j], 1))
    return W

解读：Metropolis 权重只需邻居的度信息即可本地计算，构造出的 W 同时满足行和与列和为 1，保证共识方向的稳定性。对角元补足剩余权重使节点保留部分自身信息。谱隙由拓扑决定，环形拓扑的 |λ2| 随节点数增大而趋近 1，这是大环训练慢的数学根源。

片段 3：误差反馈压缩

import numpy as np

def compressed_send(grad, memory, keep_ratio=0.1):
    """稀疏化压缩加误差反馈。
    grad: 本次梯度；memory: 上次未发送的残差（原地更新）。
    返回将要发送的稀疏增量。
    """
    buf = grad + memory
    k = max(1, int(buf.size * keep_ratio))
    # 保留幅值最大的 k 个分量：其余置零后不发送
    idx = np.argpartition(np.abs(buf), -k)[-k:]
    mask = np.zeros_like(buf, dtype=bool)
    mask[idx] = True
    send = np.where(mask, buf, 0.0)
    memory = buf - send            # 残差留存到下次一起发送
    return send, memory

解读：argpartition 以 O(n) 代价选出阈值附近的索引，无需完整排序。残差记忆使被截断的分量不会永久丢失，长期看每个分量最终都会被发送，压缩只改变发送的时间分布而不改变总量。keep_ratio 越小单轮通信越省，残差累积越慢，训练周期内需要更多轮次完成等量信息传输。

常见坑

  • 快照不同步：某节点用他人两步前的参数混合，等价于引入陈旧梯度，训练后期参数无法收敛到共识点。修复：同步屏障或带版本校验的交换。
  • 忽略共识误差调学习率：稀疏拓扑下沿用完全图的学习率，节点参数发散。修复：监视节点间参数差范数，按混合时间缩放学习率。
  • 压缩无误差反馈：量化误差系统性偏向小幅值方向，价值函数出现常量偏移。修复：开启误差反馈，或改用无偏的随机量化器。
  • 目标网络本地独立更新：各节点目标网络相位不同，自举目标不一致。修复：目标网络参数纳入同步集合，与在线网络一起混合。
  • 评估只在单节点进行：用本地策略评估全局性能，结论被采样偏差扭曲。修复：评估时聚合各节点固定种子下的回放结果。

练习与思考

  1. 四节点环状拓扑，写出邻接矩阵并计算 Metropolis 权重矩阵，说明双随机性如何验证。★
    提示
    每节点度数为 2，非对角元为 0.5，对角元为 0；验证行和列和均为 1。
  2. 把同步周期 τ 从 50 调到 500，预测节点间参数差范数与最终协作性能的变化。★★
    提示
    τ 增大后节点策略分叉，评论家对非本地策略的评估失准，性能先小幅波动后明显下降；差范数曲线是直接证据。
  3. 推导：对两节点环，混合矩阵 W=[[0.5,0.5],[0.5,0.5]]，证明一次混合后参数差归零，并推广给出 |λ2|t 的衰减结论。★★★
    提示
    差向量被 W 作用后归零；特征分解给出一般情形的衰减因子。
  4. 设计实验：4 节点环形拓扑、稀疏度两档（10% 与 30%），对照开启与关闭误差反馈，比较训练曲线终值与累计通信字节数。★★★
    提示
    关闭反馈组在后期出现系统性偏差且无法通过延长训练消除；10% 稀疏度节省通信但更依赖反馈机制。
  5. 四节点环采用 Metropolis 权重时特征值含 −1。解释偏差序列在两组节点间振荡的机制，并估算惰性化后偏差衰减到 1% 以内所需轮数。★★
    提示
    二部图上两个分区的均值互换形成周期 2 的振荡；惰性化把非主特征值折半为 0.5，解 0.5t≤0.01 得约 7 轮，与谱隙 1−0.5 给出的混合时间一致。

小结

  • 分布式训练把梯度或参数在节点间混合，目标函数为各节点本地目标的平均，收敛质量取决于共识精度。
  • 混合矩阵的双随机性保障共识方向，谱隙决定混合时间，稀疏拓扑需要更多轮次或更小学习率。
  • 误差反馈把压缩残差记入下一次发送，使量化与稀疏化不再引入系统偏置，是带宽受限训练的关键组件。
  • CTDE 中评论家与共享层适合跨节点同步，探索噪声与采样分布本地保留；目标网络必须纳入同步集合。
  • 数值算例把谱隙、二部图振荡与压缩残差三个概念量化：完全图偏差每轮乘 1/3，环图需惰性化后每轮乘 0.5，误差反馈使压缩不损失长期信息。
