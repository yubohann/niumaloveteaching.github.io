第一篇 · CTDE 基础与核心算法

第 015 章：基于注意力机制的Critic

评论家面对"数量可变、顺序无关"的队友集合，拼接加多层感知机的结构既不置换等变也不利于关系建模。注意力机制用查询与键的相似度数据驱动地决定"关注谁"，把评论家升级为集合函数。本章实现多头注意力评论家、掩码聚合与置换一致性检验。

  • 主题：评论家结构 / 集合函数与注意力
  • 关键公式：αij = softmaxj( qi⊤ kj / √d )， vi = Σj αij vj
  • 预计学时：55 分钟
  • 前置章节：第 014 章

学习目标

  • 理解多智能体评论家的置换等变要求，以及拼接结构在顺序敏感与变长兼容两方面的不足。
  • 掌握缩放点积注意力与多头扩展的计算形式，理解缩放因子的方差依据。
  • 掌握注意力评论家的完整数据流：观测编码、自注意力层、动作条件化、按智能体输出价值。
  • 会实现掩码 softmax 处理不存在实体，并用置换一致性检验验证结构约束。
  • 能设计注意力权重诊断与"拼接对照"消融实验，说明收益来源与计算代价。

背景与动机

第 003 章起，集中式评论家的输入一直是"状态加联合动作的拼接向量"。这个结构有两个隐含缺陷。其一是顺序敏感：拼接的列序把智能体身份与输入位置绑死，重新编号智能体会改变评论家输出，而任务的物理过程对编号无感知。其二是变长不友好：智能体数量变化（智能体退出、队伍规模调整）会让输入维度变化，网络结构被迫重做。更深一层，协作任务的价值往往取决于"谁与谁相关"：搬运任务里价值取决于成对距离，覆盖任务里取决于邻域分布，拼接结构把这些关系交给隐层去隐式拟合，样本效率低。

注意力机制（attention）把评论家改写为集合函数：每个智能体先编码为自己的向量，用查询与键的相似度决定对各智能体信息的加权聚合，权重由数据学习。置换等变结构内建在计算图里，数量变化只影响参与聚合的集合大小，关系权重可直接观察。本章的注意力评论家可以插入第 010 至 014 章任意一条连续控制管线，替换原有的拼接式评论家，数据接口不变。更大规模场景需要稀疏聚合时，第 016 章的图神经网络通信提供延伸。

核心原理

本节形式化置换性质、推导缩放点积注意力、给出评论家的分层结构与掩码处理，最后讨论可解释性与代价。

1. 置换等变与拼接结构的缺陷

设输入集合 X = {x1, …, xN}（各智能体的编码向量），置换 π 重排集合元素。评论家的输出 f(X) = (f1(X), …, fN(X)) 满足以下性质时称为置换等变：

f( π(X) ) = π( f(X) )， 即重排输入只重排输出, 价值函数本身不变 拼接结构 f(X) = MLP( x1 ⊕ … ⊕ xN ) 不满足该性质：列序变化给出不同输出, 且网络无从表达"xi 与 xj 的关系"这类成对特征

置换等变有直接的工程价值：它决定了模型对智能体编号的泛化能力。训练中若任务包含大量对称状态，等变结构自动共享统计强度；固定列序的结构则需要在数据中重复遇到每种编号模式才能学到等价行为。

置换等变的例外情形也要交代：需要区分身份的场合（角色异构、编号本身携带语义），系统必须主动打破等变。正确做法是把身份作为显式输入送入，例如在编码器输入拼接角色向量、或在条件段加入角色嵌入，让网络在不依赖输入顺序的前提下获得身份信息；把身份藏在位置编码（第 i 个槽位的 one-hot）里的做法同时破坏等变性与跨规模迁移能力，属于应避免的模式。判据一句话：身份可以进"值"的通道，不可以进"位置"的通道。

2. 缩放点积注意力

每个智能体的编码向量经三个线性投影得到查询、键、值：

qi = WQ xi， kj = WK xj， vj = WV xj； αij = softmaxj( qi⊤ kj / √d )； vi = Σj αij vj d 为键向量维度。除以 √d 的原因：点积的方差随维度线性增长, 不缩放时 softmax 在初期就进入饱和区, 梯度信号被压平

计算层面的三点解读：（1）αij 是"智能体 i 关注智能体 j 的权重"，行方向做 softmax，每行权重和为 1；权重由 (i, j) 对的表示相似度决定，不再依赖集合顺序。（2）多头结构把 d 维分成 h 组并行计算，各组独立学习不同的关系模式（例如一组关注距离、一组关注动作历史），再拼接投影；头数是容量旋钮。（3）若把值投影替换为"动作编码"，注意力就能生成"对其他智能体动作的加权摘要"，这是与值分解混合网络、反事实评论家结合时的常见用法。

3. 评论家的分层结构

注意力评论家的数据流分为四段：

  1. 编码段。每个智能体的观测（或观测历史摘要）经共享编码器得到 ei；角色敏感任务可在编码前拼接标识嵌入。
  2. 聚合段。L 层自注意力块，每块为"多头注意力加残差与层归一化"；深层块逐步把局部信息扩散为全局关系表示。
  3. 条件段。把该智能体自己的动作（或 one-hot）与聚合后的表示拼接。
  4. 输出段。共享价值头映射为 Qi(s, a)；训练时对全部智能体前向，取需要更新的分量。

聚合段只作用于观测编码，动作进入条件段之后再参与输出，这个次序保证"注意力权重不随执行动作改变"，权重可视化才有稳定的解释。若把动作提前并入注意力输入，权重会随探索噪声抖动，诊断价值大打折扣。

4. 掩码、可解释性与代价

变长队伍用掩码处理：对不存在的智能体位置，把其键值置为负无穷使 softmax 权重归零；掩码方向写反（屏蔽有效位置）会让权重集中在被填充的无效槽位上，训练早期即可通过权重和检验发现。注意力权重提供两种诊断：一是权重矩阵的行分布（是否集中在少数队友），二是权重与物理量（距离、相对速度）的相关性，后者用于验证"学到的关注是否与任务结构一致"。代价方面：注意力计算是 O(N² d)，智能体数量增长时昂贵，超过数十个智能体后需要稀疏化或局部邻域限制，第 016、031 章分别从图结构与扩展性角度处理。

5. 数值算例：缩放因子的方差依据

取查询与键的各维独立同分布（均值 0、方差 1），点积是 dk 个独立乘积之和，方差应等于 dk。蒙特卡洛模拟（每个规模 2×105 组样本）给出下列数字：

1615.883.9850.996
6464.118.0071.001

读表结论：不缩放时 logit 的标准差随 √dk 增长，dk = 64 时已达 8，softmax 输入跨度十几个单位，权重接近 one-hot、梯度趋于消失；除以 √dk 后 logit 标准差稳定在 1 附近，softmax 处于梯度有效区间。这就是缩放因子必须与投影维度同步核对的定量原因：头数拆分后 dk 变小，缩放量随之变化，基线配置"每头 16 维"对应缩放因子 4。

6. 数值算例：一组注意力的完整前向

两智能体单头、dk = 2：q1 = (1, 0)，k1 = (1, 0)，k2 = (0, 2)。点积为 1 与 0，除以 √2 后 logit 为 0.7071 与 0，softmax 权重 α11 = 0.6698、α12 = 0.3302（数值经程序核对）。智能体 1 的聚合输出为 0.6698 v1 + 0.3302 v2。三个观察：其一，权重和为 1，聚合是凸组合；其二，权重之比 0.6698 / 0.3302 = 2.028 恰好等于 exp(0.7071)，相似度高的键获得略多关注但不极端，未缩放时该比值会变成 2.718 : 1，缩放确实压平了分布；其三，把 k1 改为 (4, 0)（与 q1 平行且更强）后 logit 差扩大到 2.8284，权重变为 0.9442 : 0.0558，注意力择取能力随相似度差快速上升，这就是 softmax 的非线性放大特性。

7. 关系数量的代价账

注意力权重矩阵每头每层有 N² 个条目，基线配置（4 头、2 层）合计 8N² 条：N = 5 时 200 条，N = 20 时 3200 条，N = 50 时 20000 条，N = 100 时 80000 条；前向计算量按同一量级增长。是否需要稀疏化的判据在"关系是否物理稀疏"：搬运与覆盖类任务的有效交互集中在邻域，全连接注意力把 O(N²) 的容量花在大量无关对上；智能体超过数十个且交互有局部性时，切换到第 016 章的图结构或邻域注意力，把每条边只保留给物理相关的对，关系代价从 O(N²) 降到 O(N·k)（k 为平均邻居数）。交互本身全局相关的任务（例如全局投票）仍需全连接注意力，代价是必要成本。有一项隐含前提：稀疏化的收益以"图的稀疏度在训练期间稳定"为前提，若各决策步动态改图，邻接重算的 O(N²) 成本会叠加到每一轮，实际节省要按"重算成本加消息成本"合并核算。

实现思路与设计

本节给出注意力评论家的组件与配置。数据接口沿用第 010 章，替换的只有评论家内部结构，可用同一份回放批次直接对照。

设计决策：置换等变作为验收标准的理由

注意力结构天然近似满足置换等变，但实现细节会破坏它：编码器中混入位置特征（如"第 i 个智能体"的 one-hot）、输出头按列索引取不同权重、掩码应用顺序错误，都会让等变性失效。把"随机置换输入后输出是否相应重排"写进训练前检查，等价于给结构性质上一道锁；后续任何重构都必须通过该检查，避免等变优点在演进中静默丢失。

关键代码与解读

片段 1：带掩码的多头注意力块

import torch
import torch.nn as nn

class AttentionBlock(nn.Module):
    """多头自注意力 + 残差 + LayerNorm, 支持掩码。"""
    def __init__(self, dim=64, heads=4):
        super().__init__()
        self.heads = heads
        self.dk = dim // heads
        self.qkv = nn.Linear(dim, dim * 3)            # 一次投影出 Q/K/V
        self.out = nn.Linear(dim, dim)
        self.norm = nn.LayerNorm(dim)

    def forward(self, x, mask=None):
        # x: (B, N, dim); mask: (B, N) 中 1 表示有效智能体
        B, N, _ = x.shape
        qkv = self.qkv(x).view(B, N, 3, self.heads, self.dk)
        q, k, v = qkv.unbind(dim=2)                   # 各 (B, N, heads, dk)
        # 缩放点积: 除以 sqrt(dk) 防止 softmax 在训练初期饱和
        att = (q.permute(0, 2, 1, 3) @ k.permute(0, 2, 3, 1)) / (self.dk ** 0.5)
        if mask is not None:
            # 无效位置置 -1e9: softmax 后权重归零, 方向写反会屏蔽有效位
            att = att.masked_fill(~mask[:, None, None, :].bool(), -1e9)
        w = torch.softmax(att, dim=-1)                # 行方向归一化
        out = w @ v.permute(0, 2, 1, 3)               # (B, heads, N, dk)
        out = out.permute(0, 2, 1, 3).reshape(B, N, -1)
        return self.norm(x + self.out(out))           # 残差连接稳定深层训练

解读：形状变换是这段代码的全部难点，逐段核对。（1）masked_fill 的布尔条件用 ~mask，把无效位置打成负无穷；掩码张量在头维与行维上广播，每行只看键集合的有效性。（2）softmax 在最后一个维度（键方向）进行，输出权重矩阵行和为 1；用随机掩码做单元测试时断言无效列权重为零。（3）残差加 LayerNorm 放在输出投影之后，是保持深层网络信号尺度的标准做法；Norm 放在注意力之前的变体同样常见，对照实验时可作为超参处理，但两者不宜混用。

片段 2：注意力评论家前向

class AttentionCritic(nn.Module):
    """注意力评论家: 观测编码 -> 自注意力聚合 -> 条件化动作 -> 逐智能体 Q。"""
    def __init__(self, obs_dim, n_actions, n_agents, dim=64, heads=4, layers=2):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(obs_dim, dim), nn.ReLU())
        self.blocks = nn.ModuleList([AttentionBlock(dim, heads) for _ in range(layers)])
        # 条件段: 聚合表示与自身动作 one-hot 拼接后进价值头
        self.head = nn.Sequential(
            nn.Linear(dim + n_actions, dim), nn.ReLU(), nn.Linear(dim, 1))

    def forward(self, obs, act_oh, mask=None):
        # obs: (B, N, obs_dim); act_oh: (B, N, n_actions) 各智能体自身动作
        e = self.encoder(obs)
        for blk in self.blocks:
            e = blk(e, mask=mask)                     # 聚合只依赖观测编码
        x = torch.cat([e, act_oh], dim=-1)            # 动作在条件段才进入
        return self.head(x).squeeze(-1)               # (B, N) 逐智能体 Q

解读：把理论中的四段数据流压缩成三行。（1）编码器按智能体共享，输出的向量在集合内无身份标签；角色敏感任务需要在 obs 中拼接标识特征，这是数据层职责，网络结构保持对身份无感知。（2）输出是 (B, N) 的逐智能体价值矩阵，与第 010 章"每智能体一个标量评论家"在语义上等价：第 i 列即 Qi；双评论家版本把本模块实例化两份。（3）动作条件化放在注意力之后，权重不随执行动作变化，诊断输出稳定；该次序与设计决策中"权重可视化解释性"的约定一致。

片段 3：置换一致性检验

def permutation_check(critic, obs, act_oh, n_agents, seed=0):
    """置换输入后输出应相应重排: f(pi(X)) = pi(f(X))。"""
    g = torch.Generator().manual_seed(seed)
    perm = torch.randperm(n_agents, generator=g)
    with torch.no_grad():
        y_src = critic(obs, act_oh)                       # (B, N)
        # 按置换重排智能体维度的输入
        obs_p = obs[:, perm, :]
        act_p = act_oh[:, perm, :]
        y_perm = critic(obs_p, act_p)
    # 期望: y_perm 的第 k 列等于 y_src 的第 perm[k] 列
    ok = torch.allclose(y_perm, y_src[:, perm], atol=1e-5)
    return ok

解读：置换检验把结构性质变成可执行断言。（1）perm 用固定种子生成，失败案例可复现；y_src[:, perm] 是"输出按同一置换重排"的期望形态，比较对象是 (B, N) 矩阵整体。（2）容差取 1e-5 与浮点累积误差匹配；若检验偶发失败而损失仍下降，优先怀疑掩码分支或身份特征的偶然引入，浮点误差的贡献可以忽略。（3）该检验与前两章的 IGM 验证、分解引理验证组成同一套结构验收清单：算法假设每增加一条，就配一条穷举或置换级的测试，把错误拦截在训练开始之前。

常见坑

  • 掩码方向写反。症状：变长任务训练完全失效，权重集中在填充位置。原因：masked_fill 的布尔条件漏了取反。修复：用含空槽位的样本断言"无效列权重为零、有效列权重和为一"。
  • 编码器中混入位置特征。症状：置换检验失败，编号变化导致价值跳变。原因：编码时拼接了智能体序号或 one-hot。修复：身份特征只允许作为显式的角色输入进入"条件段"，聚合段保持无身份。
  • 缩放因子缺失或写错。症状：注意力权重在训练初期就接近 one-hot，梯度平缓。原因：softmax 饱和。修复：核对除以 √dk 的维度与投影维度一致，观察初始权重矩阵的熵是否在合理区间。
  • 动作并入注意力输入。症状：权重矩阵随探索噪声剧烈抖动，诊断失去意义。原因：条件段与聚合段次序颠倒。修复：动作只在注意力之后拼接；把该次序写进结构测试。
  • 深层注意力未加残差或 Norm。症状：两层以上训练不收敛，梯度范数持续衰减。原因：深层堆叠信号尺度失稳。修复：每块保持"注意力输出加残差、LayerNorm 收尾"的最小结构，再按需加宽网络，暂不加深堆叠。

  2. 把头数从 4 改为 1，预测训练速度、最终回报与注意力权重可视化信息量的变化。★
    提示
    头数减少，关系模式共享一组投影，容量下降；简单任务回报接近，复杂关系的任务上落后。可视化上单头只有一张权重图，多头可对比不同关系模式，诊断信息量随头数增加。
  3. 证明：若注意力层不含位置信息，则整体输出满足置换等变；再指出实现中哪些细节可能破坏该性质（至少列出两处）。★★
    提示
    注意力对键集合的加权求和与集合顺序无关，重排输入只重排每行对应的查询与聚合结果，输出随输入置换而置换。破坏点例：位置特征编码、按索引取不同输出头、掩码错位。
  4. 设计消融：同一连续控制管线分别使用 (a) 拼接 MLP 评论家、(b) 注意力评论家、(c) 注意力评论家去掉全部掩码。报告回报、置换检验通过与注意力权重与距离的相关性，预测三者排序。★★

  5. 设计题：为注意力评论家设计"按角色分组掩码"的方案：让不同类型智能体只能被同组或指定组关注，给出掩码矩阵构造、与置换等变的兼容性分析（等变性将退化为分组内等变）与实验协议。★★★
    提示

小结

  • 评论家面对集合输入，置换等变决定编号泛化与关系建模能力；拼接结构两项都不满足。
  • 缩放点积注意力用查询键相似度生成权重，缩放因子防止 softmax 饱和；多头并行学习多种关系模式。
  • 评论家分四段：编码、聚合、条件化、输出；动作在注意力之后进入，保证权重诊断的稳定性。
  • 掩码处理变长队伍，置换检验与掩码断言把结构性质固化为训练前验收。
