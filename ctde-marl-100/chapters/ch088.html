第 088 章：联盟形成

当智能体数量超过任务所需时，分组协作比全体协作更高效：本章给出联盟形成的合作博弈基础（特征函数、夏普利值、联盟结构稳定性），并设计"划分选择、联盟内协同、贡献分配"三段式的训练方案。

  • 主题：合作博弈 / 联盟结构（Coalition Structure）
  • 关键公式：特征函数 v(S) 与夏普利值（Shapley Value）、联盟结构价值 max Σk v(Ck)、贝尔数（Bell Number）复杂度
  • 预计学时：60 分钟
  • 前置章节：第 087 章

学习目标

  • 理解合作博弈（Cooperative Game）与特征函数（Characteristic Function）的定义，能写出联盟形成问题的优化形式。
  • 掌握夏普利值的四条公理与平均边际贡献的直觉，能对小规模联盟精确计算。
  • 理解核心（Core）与享乐博弈（Hedonic Game）稳定性概念，区分 Nash 稳定与个体稳定。
  • 学会在 MARL 中用值函数估计联盟价值，把联盟选择建成上层策略。
  • 能实现贪心合并划分与贡献分配，并用稳定性检查评估划分质量。

背景与动机

第 087 章的图通信刻画了"谁与谁交互"，但没有回答"谁应该与谁组成协作单元"。任务中经常出现超出需求数量的智能体：8 台机器人搬运 3 块货物，或 12 个传感器监测 4 个区域。全体协作的方案会引入大量冗余通信与信用分配噪声，分组协作则把问题拆成若干小规模协作，每组独立优化，通信与样本需求都随之下降。

联盟形成（Coalition Formation）把"如何分组"形式化为合作博弈问题：给定任意联盟的价值，寻找使总价值最大的联盟结构。本章先建立博弈论基础（特征函数、夏普利值、稳定性），再给出与强化学习结合的工程结构：联盟价值由值函数学习，划分由上层策略选择，联盟内沿用第 006 至 008 章的值分解方法，贡献分配用夏普利近似保证公平。本序列（088 至 091）依次处理联盟、协商、投票、市场四种机制，本章从结构性分组开始。

核心原理

1. 合作博弈与特征函数

合作博弈用二元组 (N, v) 描述：N 是智能体集合，特征函数 v: 2N → R 给出任意联盟 S ⊆ N 通过协作能获得的价值，约定空联盟价值为零。特征函数假定可转移效用（Transferable Utility），即联盟获得的价值可以在成员之间任意分配。联盟结构 CS = {C1, …, Cm} 是 N 的一个划分，联盟形成问题写作：

maxCS W(CS) = Σk = 1..m v( Ck )，满足 Ck ∩ Cl = ∅（k ≠ l）且 ∪k Ck = N 划分总数由贝尔数 BN 给出：B5 = 52，B10 = 115975，精确枚举随 N 迅速不可行

超可加性（Super-additivity）v(S ∪ T) ≥ v(S) + v(T) 成立时划分全体成员最优；任务中常见的却是非超可加情形（资源拥挤、通信冲突），此时分组优于合并，联盟形成才有意义。

2. 夏普利值：唯一合理的贡献分配

联盟价值如何在成员间分配，夏普利值给出唯一满足四条公理的方案：效率（分配之和等于联盟总价值）、对称（贡献相同者获得相同）、哑元（零贡献者获得零）、可加性（两个博弈叠加时分配可加）。公式为成员在所有加入顺序上的平均边际贡献：

φi(v) = ΣS ⊆ N∖{i} [ |S|! (N − |S| − 1)! / N! ] · [ v(S ∪ {i}) − v(S) ] 权重恰好是"随机排列中 i 之前的成员集合恰为 S"的概率；精确计算需枚举 2N 个联盟

与夏普利值对照的班茨哈夫指数（Banzhaf Index）统计"在多少个联盟中 i 是关键票"，不满足效率公理，分配之和一般大于总价值，适合度量影响力；分配收益应改用满足效率公理的夏普利值。MARL 中使用夏普利值的场景有两个：训练后按贡献重新分配共享奖励，评估时解释各智能体对联盟价值的贡献排序。

3. 稳定性：核心与享乐博弈

分配方案 (φi)i∈N 在核心（Core）中，当且仅当没有任何联盟能通过脱离整体而获得更多：对任意 S，Σi∈S φi ≥ v(S)。核心可能为空：此时无论怎样分配，总有子联盟希望脱离，整体联盟不可持续。留存在核心中的判据把"分配公平"与"结构稳定"联系起来。

享乐博弈（Hedonic Game）放弃可转移效用，让每个智能体直接对"与谁同组"有偏好。稳定性概念按强度分级：Nash 稳定（无人愿单独更换联盟）、个体稳定（无人愿单独退出）、合同稳定（无群体共同偏离）。Nash 稳定划分在一般偏好下并不保证存在，对称偏好等受限情形才有存在性结论；局部换组动态可能陷入循环，算法需要显式终止规则，或改用存在性有保证的更弱稳定性概念。

4. MARL 中的三段式设计

把联盟形成嵌入强化学习需要三个组件：

  1. 联盟价值估计：v̂(S) 用集中式值函数近似，输入联盟观测与联合动作，输出估计价值；联盟外的智能体动作边缘化（对随机策略取期望）或固定为基线策略。
  2. 划分选择：上层策略输出联盟结构。划分空间随 N 指数增长，策略参数化需要特殊设计：为每对智能体输出"同队倾向"分数，再由聚类或贪心合并导出划分。
  3. 联盟内协同：每个联盟内部使用第 006 至 008 章的值分解方法训练联合策略，联盟间的价值估计共享参数（若有结构相似性）或独立参数。

训练信号来自任务总回报，划分策略与联盟内策略交替更新，避免同时更新导致两者互相追逐。

5. 近似与复杂度

夏普利值的精确枚举在 N 超过 12 时不再可行，标准近似是用 M 个随机排列采样边际贡献，估计标准误随 1/√M 下降，M 取 512 到 2048 可满足评估需要。划分搜索用贪心合并：从单元素联盟出发，反复执行增益最大的合并，复杂度 O(N²) 每轮，总复杂度约 O(N³)，总价值通常接近最优的 90% 以上。评估报告应同时给出划分总价值与稳定性检查结果，只有价值高而无稳定性的划分在动态环境中不可维持。

实现思路与设计

工程实现分四步：

  1. 价值函数预热：先在全协作模式下训练基础值函数，作为 v̂ 的初始近似。
  2. 划分策略训练：为每对智能体输出同队分数，softmax 或阈值化后聚类得到划分。
  3. 联盟内训练：各联盟独立执行值分解算法，共享特征编码器、独立混合网络。
  4. 交替更新与稳定性检查：划分策略与联盟内策略交替更新；定期检查分配是否满足核心条件或 Nash 稳定。

与第 087 章的差异点：087 章的边由观测几何决定，属于自然结构；本章的划分由策略决定，属于选择结构。图确定"消息沿哪些边传"，联盟确定"价值如何分组聚合"。

设计决策：为什么用贪心合并代替枚举最优划分？

贝尔数增长使枚举在 N 大于 8 后不可行；贪心合并每轮只需 O(N²) 次价值查询，且天然产生"合并增益为正才合并"的早停条件。代价是可能陷入局部最优，缓解方式是从多个随机初始划分重启并对结果取最大值。联盟价值估计本身带有噪声，追求划分的精确最优意义有限，稳健的次优解更符合学习系统的实际。

关键代码与解读

片段 1：夏普利值精确计算

from itertools import combinations
import math

def shapley_values(value_fn, agents):
    """精确计算夏普利值：value_fn(联盟集合) 返回联盟价值。"""
    n = len(agents)
    phi = {a: 0.0 for a in agents}
    for a in agents:
        others = [x for x in agents if x != a]
        for size in range(n):                # 枚举除 a 外联盟的大小
            for S in combinations(others, size):
                # 权重 = 随机排列中 a 之前的成员集合恰为 S 的概率
                w = math.factorial(size) * math.factorial(n - size - 1) / math.factorial(n)
                # 边际贡献：把 a 加入联盟 S 的价值增量
                phi[a] += w * (value_fn(set(S) | {a}) - value_fn(set(S)))
    return phi

# 验证：三人分蛋糕博弈 v(S) = |S|^2，夏普利值应为各人相同
print(shapley_values(lambda S: float(len(S)) ** 2, ["a", "b", "c"]))

解读：（1）三层循环对应公式的三个要素：被分配的成员 a、联盟大小 size、具体联盟 S；组合数与权重的乘积正是"平均"的显式展开。（2）value_fn 以集合为输入，接口上不依赖智能体顺序，从源头保证对称公理；若实现成列表下标会引入顺序偏差。（3）每个成员的枚举量是 Σk C(n−1, k) = 2n−1，全部分配合计 n·2n−1；n 等于 12 时约 2.5 万次枚举（每次枚举两次价值查询），可作评估工具；n 更大时必须换成排列采样。示例中 v(S) = |S|² 的边际贡献对每个成员对称，结果均分 v(N)/3 = 3。

片段 2：贪心合并求联盟划分

def greedy_partition(value_fn, agents, target_size=3):
    """贪心合并形成联盟划分：每次合并增益最大的两个联盟。"""
    coalitions = [{a} for a in agents]           # 初始每个智能体单独成盟
    floor = max(1, len(agents) // target_size)
    while len(coalitions) > floor:
        best, best_gain = None, 0.0
        for i in range(len(coalitions)):
            for j in range(i + 1, len(coalitions)):
                merged = coalitions[i] | coalitions[j]
                # 合并增益：联盟价值增量，正增益才值得合并
                gain = (value_fn(merged) - value_fn(coalitions[i])
                        - value_fn(coalitions[j]))
                if gain > best_gain:
                    best, best_gain = (i, j), gain
        if best is None:
            break                                # 无正增益合并，提前终止
        i, j = best
        coalitions[i] = coalitions[i] | coalitions[j]
        coalitions.pop(j)
    return coalitions

解读：（1）循环条件同时受目标规模与正增益约束：规模下限防止过度碎片化，正增益约束防止强行合并没有协同收益的联盟；两个条件都满足时划分近似最优。（2）每轮扫描所有联盟对，复杂度 O(N²) 次价值查询；N 等于 20 时单轮约 190 次查询，在集中式价值网络上可接受。（3）best_gain 初始为零意味着"零增益合并不做"，保持划分最小化；若任务要求恰好 target_size 成员的联盟，可把条件改为允许零增益合并。（4）返回联盟划分，分配交给片段 1 的夏普利值对每个联盟单独计算，两段职责分离，便于分别替换近似方案。

常见坑

  • 假设超可加性无条件成立：强行追求全体大联盟，忽略资源拥挤导致的负协同，总价值反而下降。修复：先用价值函数扫描若干划分，验证非超可加现象是否存在。
  • 夏普利值用于训练中的实时分配：2N 枚举每个回合执行一次会拖垮训练。修复：训练用简单分配（按估计价值比例），夏普利值用于事后评估与最终分配。
  • 划分策略与联盟内策略同时大跨步更新：两者互相追逐，划分在两种结构之间振荡。修复：交替更新并错开学习率，参考第 085 章的双时间尺度思路。
  • 价值函数噪声导致划分抖动：v̂ 的估计误差使合并增益符号不稳定。修复：对 v̂ 做 EMA 平滑，或对增益设置最小阈值（例如幅值超过估计标准误的两倍才视为正增益）。
  • 稳定性检查只在单步状态评估：瞬时稳定的划分在长时程中可能瓦解。修复：按完整情节评估 v(S)，检查多个不同初始状态下的稳定性。

练习与思考

  1. 对特征函数 v(S) = |S| 与 v(S) = |S|² 分别计算 3 人博弈的夏普利值，比较两种分配的差异并解释边际贡献的直觉。★
    提示
    v(S) = |S| 时每人获得 1/3；v(S) = |S|² 时同样均分，因为价值只依赖联盟人数，属于对称博弈，夏普利值必然均匀。要看非均匀分配须引入不对称的 v：例如 v(A,B) = 6、v(A,C) = 6、v(B,C) = 2、v(A,B,C) = 7，则三人份额依次为 11/3、5/3、5/3，A 因为对两个二人联盟都关键而获得更多（结果经程序核对）。
  2. 把贪心合并中的 target_size 从 3 改为 2，预测划分结果、总价值与联盟间通信量的变化。★★
    提示
    划分为更多小联盟，若任务协作人数需求为 3，则 v 值下降；通信量可能下降。验证：固定价值函数扫描 target_size ∈ {2, 3, 4} 的划分总价值。
  3. 推导：证明夏普利值满足效率公理，即 Σi φi(v) = v(N) − v(∅)。★★
    提示
    把 Σφi 展开为所有"加入事件"的边际贡献之和；沿任一排列累加得 v(N) − v(∅)，权重求和为 1，故对任意排列一致成立。
  4. 设计实验：在 6 智能体两区域监测任务中比较（固定全协作）、（固定两两分组）、（学习划分）三种设置，报告回报、每步通信比特数与划分抖动率。★★★
    提示
    划分抖动率 = 每 K 个评估点之间划分变化的比例。学习划分应同时优于两种固定方案或在某一维度显著更优，否则说明划分学习未被任务信号驱动。
  5. 设计核心条件检查器：给定 v̂ 与分配向量，验证所有 2N 个联盟的偏离条件，输出违反程度最大的联盟；在 N = 10 时评估计算量。★★★
    提示
    1024 个联盟 × 每个联盟的价值查询，与一次夏普利精确计算同量级；超过 N = 15 时改为抽样检查随机子联盟。输出"最大偏离量"作为稳定性指标。

小结

  • 联盟形成把分组协作写成合作博弈：特征函数给出任意联盟价值，目标是最大化联盟结构总价值。
  • 夏普利值满足效率、对称、哑元、可加性四公理，是唯一的平均边际贡献分配；精确计算为 2N 量级，大 N 用排列采样。
  • 核心描述不被偏离的分配集合，享乐博弈的 Nash 稳定划分在弱偏好下总存在。
  • MARL 实现采用三段式：值函数估计联盟价值、划分策略选择结构、联盟内值分解训练策略。
  • 划分搜索用贪心合并，复杂度 O(N²) 每次迭代；价值估计噪声需要用平滑与增益阈值抑制。
