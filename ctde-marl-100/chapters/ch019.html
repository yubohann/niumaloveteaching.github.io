第一篇 · CTDE 基础与核心算法

第 019 章：去中心化执行中的策略融合

从联合视角的计划落回分散执行时，隐藏着一类结构性乐观偏差：策略融合（strategy fusion）。本章说明它的产生机制、给出偏差的量化检测，并实现三条修复路线：分散策略空间的直接优化、通信补信息、执行口径蒸馏。

  • 主题：训练与执行一致性 / Dec-POMDP 执行语义
  • 关键公式：融合偏差 = 𝔼s[ maxa Q(s, a) ] − V(π1, π2, …)（分散执行口径）
  • 预计学时：50 分钟
  • 前置章节：第 018 章

学习目标

  • 理解策略融合现象：把依赖联合信息的计划切分为分散策略时，执行价值系统性地低于集中视角的估计。
  • 掌握偏差的形式化刻画：集中贪心值与分散执行值之差，以及信息集交叉的结构来源。
  • 掌握三条修复路线：分散策略空间直接优化（交替最佳响应）、通信补关键信息、执行口径蒸馏，以及各自的适用条件。
  • 会实现融合偏差检测器与执行口径蒸馏，把"部署评估只给本地信息"的纪律固化为代码。
  • 能在实验设计层面区分融合偏差与探索不足、信息泄漏两类相近症状。

背景与动机

CTDE 的框架承诺执行期只依赖本地信息，第 005 章的泄漏检验保护了这条纪律。然而纪律之外还有一层结构问题：即便执行路径没有明文引入全局变量，把"集中视角学到的行为"转化为"分散策略"的过程本身也会引入乐观偏差。设想一个需要两个智能体配合的小任务：路线选择的关键变量由智能体 1 观测，速度档位的关键变量由智能体 2 观测，联合最优计划要求两人的选择相互匹配。若训练阶段依赖集中式价值评估"最优联合动作"，每个智能体都会以为对方掌握了自己没有的信息；执行时两人按各自的信息集分别最大化，得到的联合动作与任何真实可达的最优行为都不一致。这一现象在 Dec-POMDP 文献中称为策略融合（strategy fusion）。

它与信息泄漏的区别在于：泄漏是代码把不该给的输入给了执行策略，可被 patch test 拦截；融合偏差没有可拦截的违规代码，它藏在"训练目标与执行口径的错位"里。本章的价值是把这个错位诊断出来并修复：通过执行口径的评估器量化偏差，通过分散策略空间的直接优化或执行口径蒸馏消除偏差，并通过通信为关键信息缺口补课。本章也是第一篇的收官章，为信用分配专题（第 020 章）提供"什么是真实可达的联合行为"这一基准。

核心原理

本节形式化融合偏差、拆解信息集交叉的机理、给出三条修复路线的对照与选择判据。

1. 融合偏差的形式化

记集中式价值 Q(s, a)，分散策略集合 {πi(ai | τi)}，真实执行价值为 V(π1, …, πN)。用一个集中视角的贪心估计衡量"计划层面以为能达到的价值"：

融合偏差 ≜ 𝔼s[ maxa Q(s, a) ] − V(π1, …, πN)， 其中 V 用部署口径评估（仅本地历史） maxa 表示"若所有变量都可即时获得"的计划值; 右侧是真实可达的分散执行值。偏差恒非负（max 不小于任何固定策略的取值）, 显著为正时说明执行能力与训练目标脱节

偏差的第二来源是支持集错配：训练时联合动作 u 的监督信号（例如联合价值或教师分布）覆盖整个动作空间，而分散执行的实际分布是每个智能体信息集上的条件分布，二者的支撑集不同。把联合空间的"最优点"作为学习目标，等于向智能体索取它信息集中不可辨认的量。

2. 信息集交叉的机理

用一个两状态例子说明。任务要求选择路线 L 或 R：智能体 1 观测到关键变量 x ∈ {0, 1}（黄色提示），智能体 2 观测到关键变量 y ∈ {0, 1}（绿色提示），奖励仅在"x = 1 且两人都选 R"或"x = 0 且两人都选 L"时发放；y 只影响智能体 2 对 x 的推断（例如 y = 1 时 x 以 0.9 概率为 1）。分散执行中两人分别依据 x 与 y 决策：智能体 1 直接知道 x，智能体 2 只能猜。集中视角的 maxa Q 同时使用 x 与 y 的信息，高估了"两人同时选对"的概率；真实执行中只要智能体 2 的推断出错，奖励就落空。这就是融合偏差的典型形态：每个局部决策都"正确"，拼起来与任何可行联合计划的一致执行都不相同。

数值算例：推断精度如何换算成偏差

把上面的两状态例子写成可计算的版本。任务在两人同时选对路线时给出奖励 10，其余情形为 0。集中视角同时掌握 x 与 y，计划层贪心值为 10；分散执行时智能体 1 直接按 x 行动，命中率 1，智能体 2 依据 y 推断 x，在对称先验与对称信道的简化假设下，贝叶斯最优的选择与 y 的指向一致，两人同时选对的概率等于信道一致率 p，部署口径价值为 10p。融合偏差因此可以写成不含状态枚举的乘积形式：

融合偏差 = Qplan · (1 − p)， p = P( 智能体 2 推断正确 ) Qplan 为计划层贪心值；Qplan = 10、p = 0.7 时执行价值 7、偏差 3，占计划值的 30%

代入 p = 0.7 得到执行价值 7 与偏差 3。若信道噪声减小使 p 升到 0.9，偏差降到 1，仅为原值的三分之一；若通过通信把 x 广播给智能体 2，p 达到 1，偏差归零。这组数字给出两条可操作的判据：检测器读出的差值应与"不可观测变量对联合最优的贡献占比"同阶，量级明显偏离时先检查信息缺口是否正确建模；修复路线的收益上界可以预先估算，广播 x 的收益上限就是当前的偏差读数，超过这个上界的提升必然来自其他因素。

3. 三条修复路线

  • （a）分散策略空间直接优化。联合均衡搜索（Joint Equilibrium Search for Policies, JESP）式交替最佳响应：固定其余智能体的策略，在当前智能体的信息集上评估并改进自身策略，轮流若干轮。优化目标与执行口径一致，融合偏差从定义上消失；代价是收敛到局部均衡，需要在多个随机起点上运行并报告分布。
  • （b）通信补信息。让关键变量在智能体之间流通：智能体 1 把 x 编入消息（第 016 章的图通信或第 017 章的受限消息），智能体 2 的信念被补齐，信息集交叉被消解。适用条件：通信预算允许该信息的流通量；受限信道的代价项会自动权衡"补信息"与"省带宽"。
  • （c）执行口径蒸馏。用集中式教师提供动作标签，学生策略只接收本地历史；训练损失必须按部署口径构造（输入仅本地历史），并加入"教师侧变量扰动"增强：保持本地历史不变、随机替换教师看到的其他变量，迫使学生对不可见信息形成稳定的边际行为。

选择判据：通信可用且关键信息稀疏，优先路线 (b)；通信冻结且联合策略搜索的评估器可承受，优先 (a)；已有高质量教师且需要规模迁移，用 (c) 并把偏差检测器作为验收。三条路线可以叠加，例如先补一部分信息，再对剩余缺口做执行口径蒸馏。

修复路线偏差消除机制主要代价失效形态
分散策略空间直接优化评估与改进都在执行口径上进行，偏差从定义上不存在多起点重复搜索的计算量收敛到劣质局部均衡且难以察觉
通信补信息把不可观测变量的取值编入消息，信息集交叉被消解带宽占用与信息代价项关键变量不可压缩时消息容量不足，偏差只被部分收窄
执行口径蒸馏学生只接收本地历史，扰动增强压制依赖不可见信息的行为教师质量上限与蒸馏表示误差教师动作本身依赖不可见信息时，标签噪声被学生继承

4. 与相邻症状的区分

汇报融合偏差前必须排除两类相近症状：探索不足表现为多种子间方差大、增加探索可缓解；信息泄漏表现为 patch test 失败、训练指标与部署指标差距随训练扩大。融合偏差的特征标识是：patch test 通过、探索充分、训练目标（集中贪心值或教师拟合度）持续改善，而部署口径评估停滞在低于训练目标的上限处，且差距在信息交叉更强的任务上更大。

实现思路与设计

本节给出偏差检测与两条实现路线的组件配置：检测器复用集中式价值函数与部署评估器，修复路线以执行口径蒸馏为主、JESP 交替改进为辅。

设计项取值（基线）作用与依据
集中式价值函数Q(s, a) 或 V(s)，与主算法共享检测器的估计侧；不进入执行路径
部署评估器仅本地历史驱动，多回合平均报告 V(π1, …, πN) 的唯一口径
检测频率每固定训练步数运行一次偏差曲线与回报曲线并列观察
学生策略本地历史编码（GRU 64），第 018 章结构执行口径的表示能力要与任务依赖长度匹配
蒸馏损失教师动作的交叉熵，教师 logits 可加温度平滑温度高于 1 时保留类别间相对信息，利于学生泛化
扰动增强保持本地历史、替换教师侧变量，替换比例 0.5迫使学生行为不依赖不可见信息
JESP 评估集固定状态集上估计，交替改进 5 轮 × 3 随机起点应对局部均衡：多起点报告分布
学习率5e-4与全篇一致

与第 018 章的衔接：学生在序列化管线上训练，隐藏状态管理约定不变；新增的两块是检测器与扰动增强器。验收标准写死：部署评估回报不得低于教师价值的常态估计减去可接受阈值，否则即使训练损失下降也判定为融合偏差未解。

设计决策：蒸馏标签采用教师动作的理由

动作标签提供的是"在教师视角下值得模仿的行为"，学生用自己的历史复盘该行为是否可从本地信息重现；价值标签则把教师对状态的估计直接搬运给学生，而该估计本身可能依赖学生不可见的信息，偏差被藏在标签里不可分辨。动作标签配合扰动增强，让"学生能复现的动作"与"依赖不可见信息的动作"在数据上分开：后者在不一致的历史-动作配对下产生高损失，训练会自然降低对它们的依赖。实践中两者可以组合：以动作标签为主，价值标签以小权重作为正则，并要求价值标头也只看本地历史。

关键代码与解读

片段 1：融合偏差检测器

import torch

def fusion_gap_detector(q_net, student_policy, eval_states, env, n_rounds=20):
    """检测: 集中贪心值与部署口径回报的差距。"""
    # 估计侧: 评估状态集上对联合动作取最大 (计划层价值)
    plan_vals = []
    with torch.no_grad():
        for s in eval_states:
            a_grid = all_joint_actions(env.n_agents, env.n_actions)  # 小规模枚举
            qs = [float(q_net(s, a_oh)) for a_oh in a_grid]
            plan_vals.append(max(qs))
    plan_est = sum(plan_vals) / len(plan_vals)
    # 执行侧: 学生策略只吃本地历史, 多回合滚动估计真实回报
    rets = []
    for _ in range(n_rounds):
        obs, _ = env.reset()
        h = student_h0(env.n_agents)
        done, ret = False, 0.0
        while not done:
            acts = student_policy.act_decentralized(obs, h)      # 仅本地历史
            h = student_policy.step_hidden(h, obs, acts)         # 记忆推进
            obs, _, r, done = env.step(acts)
            ret = ret * 0.95 + r
        rets.append(ret)
    exec_est = sum(rets) / len(rets)
    # gap 显著为正且随信息交叉强度增大, 是融合偏差的特征标识
    return plan_est - exec_est

解读：检测器是本章的度量核心。（1）估计侧对联合动作做小规模枚举取最大，代表"计划层以为可达的上界"；状态集固定并公开，保证跨实验口径一致。（2）执行侧只用 act_decentralized(obs, h)，隐藏状态随步推进，任何全局变量都不得进入该调用；这里复用了第 005 章的信息纪律，检测对象则升级到"数值差距"这一层面。（3）返回的是原始差值，不做归一化；汇报时与价值尺度一起给出，差值显著为正且随任务的信息交叉强度单调上升，是判定融合偏差的关键证据，可与探索不足的症状区分。

片段 2：执行口径蒸馏与扰动增强

def distill_execution_contract(student, teacher, batch, temp=2.0):
    """蒸馏: 输入仅本地历史, 标签为教师动作; 教师侧变量做扰动增强。"""
    obs_seq, act_prev, done_seq, teacher_logits = batch.fields
    # 学生前向: 全程部署口径, 隐藏状态按第 018 章约定推进
    student_logits, _ = student(obs_seq, act_prev, h0=None)
    # 扰动增强: 保持学生输入不变, 只在标签侧混入"教师可见但学生不可见"的替换
    mix = batch.teacher_variable_mask                 # 0/1 指示该步变量是否可替换
    logits_mix = teacher_logits * mix + batch.shuffled_logits * (1.0 - mix)
    # 软标签损失: 温度平滑保留教师分布的类别关系
    loss = -(torch.softmax(logits_mix / temp, dim=-1)
             * torch.log_softmax(student_logits / temp, dim=-1)).sum(dim=-1).mean()
    # 与部署口径回报联动验收: 损失下降但回报不升, 判定为偏差继承
    return loss * (temp ** 2)

解读：蒸馏损失包含三层防偏差设计。（1）学生输入只含 obs_seq、act_prev 与显式传递的隐藏状态，教师侧变量不进入前向路径；"输入仅本地历史"由函数签名保证，注释纪律升级为参数纪律。（2）teacher_variable_mask 标记哪些时间步存在"教师可见、学生不可见"的关键变量，这些步的标签被随机替换为打乱值：学生无法通过拟合不可见信息降低损失，只能学习在这些步保持对本地历史稳定的边际行为。（3）温度的平方还原因子使不同温度下的梯度尺度可比；验收标准强调损失与部署回报的联动，损失曲线单独下降不构成蒸馏成功的证据。

片段 3：JESP 式交替最佳响应

def jesp_improve(student_team, env, eval_states, rounds=5, seeds=(0, 1, 2)):
    """分散策略空间交替改进: 固定他人策略, 在自身信息集上做评估与改进。"""
    logs = []
    for seed in seeds:                                 # 多起点应对局部均衡
        student_team.reset(seed)
        for r in range(rounds):
            for i, agent in enumerate(student_team.agents):
                # 评估集在部署口径下生成: 其余智能体用当前策略行动
                rollouts = deploy_evaluate(env, student_team, eval_states,
                                           only_replay_other_agents=True)
                # 在该智能体的信息集上做一步策略改进(策略梯度或策略迭代)
                agent.improve_on_infosets(rollouts[i])
            # 每轮记录分散执行回报, 观察是否稳定上升
            logs.append({"seed": seed, "round": r,
                         "return": deploy_evaluate(env, student_team, eval_states)})
    # 报告各起点的收敛值分布, 单起点结果不构成方法结论
    return logs

解读：交替改进的循环结构直接对应"在分散策略空间优化"这一修复路线。（1）改进每个智能体时，其余智能体保持当前策略参与环境交互，产生的数据天然是执行口径：某个智能体看到的转移由其真实可达行为生成，融合偏差在评估环节被结构性地排除。（2）每个智能体只在自身信息集上做策略改进，"信息集"在本实现中即本地历史类，改进前后不跨信息集共享参数。（3）多起点与逐轮记录让收敛的局部性可见：不同随机起点收敛到不同均衡是 JESP 类方法的常态，报告结果应给出分布，单点值不足以反映该方法性质。

常见坑

  • 蒸馏损失用教师价值作为输入特征。症状：训练损失很低，部署回报停滞。原因：学生以价值为输入，而价值估计含不可见信息。修复：标签与输入分离，价值至多做独立监督头且只读本地历史。
  • 评估口径混入全局量。症状：检测器的执行侧数值虚高，融合偏差被低估。原因：部署评估路径复用了训练期接口。修复：评估入口做输入白名单断言，只允许本地历史字段通过。
  • 把融合偏差当探索不足处理。症状：加大探索率、增加种子均无法收窄检测器差值。原因：偏差源于信息结构。修复：按第 4 节的特征标识判定，转向三条修复路线，停止在探索维度调参。
  • JESP 单起点结论。症状：汇报的收敛值与另一随机起点差异大。原因：分散策略空间的局部均衡。修复：固定三个以上起点与公开评估集，报告分布与中位数。
  • 扰动增强比例设置极端。症状：比例过低不见效，比例过高学生退化到无信息行为。原因：替换比例与关键变量占比失配。修复：以关键变量占比为基准，在 0.3 至 0.7 区间扫描，用部署回报与检测器差值双指标选点。

练习与思考

  1. 两智能体、两动作、x 与 y 各以 0.7 概率一致。计算"集中贪心计划"认为的成功概率与两人独立按各自信息推断时执行的成功概率，给出两者的差（融合偏差的实例数值）。★
    提示
    集中视角成功率 1（两人都知道 x）；执行视角智能体 2 依据 y 推断 x，成功率约 0.7 × 1 + 0.3 × 0 = 0.7（简化模型下），差值约 0.3 即融合偏差的量级示例。
  2. 把通信预算从 0 提高到"仅允许广播 x"，预测检测器差值与部署回报的变化，并说明通信代价系数 β（第 017 章）如何影响该决策。★
    提示
    补入 x 后信息集交叉消解，偏差收窄、回报上升；β 小则广播成为最优策略，β 大时策略权衡"少发消息导致个别回合失败"与"省下的带宽"，权衡点由扫描曲线给出。
  3. 证明：融合偏差恒非负，即 𝔼s[maxa Q(s, a)] ≥ V(π1, …, πN)，并指出等号成立的充分条件（提示：考虑"策略恰好实现集中贪心"需要什么信息）。★★
    提示
    max 不小于任一策略的实际取值，取期望后不等式保持。等号成立需要每个状态下分散策略实现的联合动作恰好是贪心动作，通常要求信息集足以还原贪心动作分量。
  4. 设计实验：在信息交叉强度可调的任务上（用关键变量耦合概率作为旋钮），测量检测器差值与部署回报随耦合强度的曲线，验证偏差随交叉增强而扩大的假设。★★
    提示
    耦合强度从 0.5 增至 0.9，预期检测器差值单调扩大、部署回报先平后降；控制探索与种子方差后用同一评估集比较。
  5. 设计题：把 JESP 与执行口径蒸馏组成两阶段方案（先交替改进探明局部均衡，再蒸馏到单一学生网络），给出阶段划分标准、中间产物的表示形式与预期的收益／风险。★★★
    提示
    阶段一以检测器差值收窄为完成标准，产出均衡策略的执行轨迹与动作分布；阶段二把轨迹重标注为学生输入形态，蒸馏压缩为单网络。风险：蒸馏重新引入表示误差，需要以检测器差值复验。

小结

  • 策略融合是联合视角计划与分散执行语义之间的结构性偏差，检测量是集中贪心估计与部署口径回报之差。
  • 偏差来源有两层：信息集交叉使每个局部决策"正确"而拼装不一致；支持集错配让训练目标超出执行分布的可辨认范围。
  • 修复三路线：分散空间直接优化（JESP 交替改进）、通信补关键信息、执行口径蒸馏加扰动增强；判据由通信预算与教师可得性决定。
  • 部署评估入口做输入白名单断言，检测器差值与部署回报联动验收，是本章新增的工程纪律。
