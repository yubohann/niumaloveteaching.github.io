第四篇 · 高级机制与研究专题

第 063 章：多智能体智能家居控制

把多个房间的温控器建模为协同智能体，在热传导耦合与总功率上限约束下平衡舒适度与能耗，用集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）让每个房间仅凭本地传感完成控制。

  • 主题：连续控制 / 热动力学与舒适度权衡
  • 关键公式：Ti,t+1 = Ti,t + αi(Tout−Ti,t) + Σjκij(Tj,t−Ti,t) − βiqi,t
  • 预计学时：55 分钟
  • 前置章节：第 062 章

学习目标

  • 掌握集总热阻热容（Resistance-Capacitance, RC）模型，能写出多房间热耦合的离散演化方程并解释每一项的物理含义。
  • 理解舒适度与能耗的多目标结构，能设计带死区的舒适度惩罚，避免奖励在目标区间内全为零而失去学习信号。
  • 掌握共享功率上限的处理方式：动作投影、拉格朗日惩罚与安全回退三种手段的适用条件。
  • 能实现带动作平滑约束的策略网络，抑制温控设备的频繁启停。
  • 能设计对比实验，比较 CTDE 与独立温控、规则温控在舒适度达标率与总能耗上的差异。

背景与动机

单房间温控是经典控制问题，比例积分微分（Proportional-Integral-Derivative, PID）控制器即可胜任。多房间场景改变了问题结构：房间之间通过墙体与门洞热传导，任一房间的制冷功率会影响邻室温度；全部设备共享一个总功率上限，高峰时段同时启动会触发过载；室外温度与电价随时间变化，控制需要预判未来数小时的演化。这些耦合使逐房间独立控制陷入局部最优：邻室协同降温比各自满功率更省电，但独立控制器无法协商。

与第 062 章相比，本章的动作是连续功率，动力学是缓慢的热惯量系统，奖励是舒适度与能耗的加权折中；三处结构分别与上一章的离散分派、队列积累和单一等待时间目标形成对照。热惯性意味着单步奖励与长期后果的关联更弱，价值估计需要更长的信用分配跨度。

核心原理

本节建立热动力学、舒适度度量与共享约束三条线索，并给出 CTDE 的映射。

1. 多房间 RC 热模型

把每个房间视为一个集总热容节点：外界热量通过墙体以温差驱动的方式流入，邻室之间以热传导系数 κij 交换热量，空调以效率 βi 抽走热量。αi 为房间与室外的换热系数，随保温性能变化。

Ti,t+1 = Ti,t + αi(Tout,t − Ti,t) + Σj∈N(i) κij(Tj,t − Ti,t) − βiqi,t T 为温度（摄氏度），q 为制冷功率，κij 为邻室热传导系数，N(i) 为与 i 相邻的房间集合

该模型是线性的：给定动作序列，温度轨迹可解析预测。线性结构有两个用途：其一，作为基于模型预测控制（Model Predictive Control, MPC）的基线；其二，说明热传导项使多房间状态矩阵非对角，舒适度目标无法按房间可加分解，这正是需要协同决策的数学根源。

三个系数的辨识用最小二乘即可：把温度变化量对 (Tout − Ti)、(Tj − Ti) 与 qi 做线性回归，逐房间估计 αi、κij 与 βi；辨识数据覆盖不同室外温度与功率档位，避免系数只在单一工况下拟合。残差的标准差给出过程噪声量级，它与感知噪声一起决定死区宽度的下限。

2. 舒适度与能耗的度量

舒适度用设定温度附近的死区刻画：温度落在 [Tset−δ, Tset+δ] 内视为舒适，超出部分按二次方惩罚。能耗取功率的线性累计，峰时段电价 ρt 提高时能耗代价自动放大。

rt = −wcΣimax(0, |Ti,t − Tset,i| − δ)2 − weρtΣiqi,t wc、we 为权重；δ 为死区半宽；ρt 为分时电价系数

死区设计既反映真实舒适感（人对 ±0.5 摄氏度内的偏差不敏感），也影响学习信号：死区内惩罚为零，策略在死区内仍能通过能耗项获得梯度，若把舒适度权重设得过大，能耗项的梯度会被完全淹没，策略退化为满功率降温。

权重的标定沿用扫描流程：在 3 到 5 档能耗权重上各跑短预算，记录舒适度达标率与总能耗两个指标，画出散点后选择未被规则基线支配且达标率满足要求的档位。达标率的定义需要事前冻结（例如各决策点温度落在死区内的比例），事后更换定义会让折中曲线失去可比性。

3. 共享功率约束的三种处理

设总功率上限为 Ppeak，约束为 Σiqi,t ≤ Ppeak。处理手段有三类：动作投影在网络输出后按比例缩放，保证每步可行但可能扭曲策略分布；拉格朗日惩罚把违规量乘系数加进奖励，实现简单但系数需要调节；安全回退在投影不满足时按优先级裁剪，适合硬约束场合。三者可以叠加，工程上常用惩罚训练加投影执行。

4. CTDE 映射与部分可观测

每个房间是一个智能体：观测含本室温度、设定值、室外温度预报、当前电价与上一动作；动作是本室制冷功率；奖励即上式。耦合结构对智能体不可见，训练期由集中式评论家接收全部房间温度与联合动作，执行期每个温控器只依赖本地传感，无需房间间通信链路。热惯性带来的长记忆效应通过循环网络或堆叠历史帧缓解。历史帧的堆叠数量按热时间常数决定：决策间隔 10 分钟、时间常数 10 步时，堆叠 3 到 5 帧即可覆盖一个时间常数的演化，更多帧只增加输入维度并重复信息。

5. 数值算例：单室热平衡与共享功率缺口

设单房间换热系数 α=0.1、制冷效率 β=0.5 摄氏度每千瓦每决策步，室外温度 Tout=35，设定温度 Tset=26，死区半宽 0.5 摄氏度。室内当前温度 28 摄氏度，先施加 q=1 kW：

Tnext = 28 + 0.1×(35−28) − 0.5×1 = 28 + 0.7 − 0.5 = 28.2 摄氏度。单步制冷量小于室外热流入，温度仍在上升，说明维持设定值需要更大的平衡功率。

平衡功率推导：令室外热流入等于制冷量，0.1×(35−26) = 0.5q，解得 q = 0.9/0.5 = 1.8 kW。若四个房间同时按平衡功率运行，总功率需求为 7.2 kW。

共享约束收紧：峰值上限按 0.7×4=2.8 kW 设置时，投影层把每台功率压缩到 0.7 kW，仅为平衡值的约 39%。若各房间维持 0.7 kW，温度将持续上漂，直到偏差越过死区后舒适度惩罚接管梯度。

解读：算例给出两层信息。其一，热平衡功率可以手算校验散热项与制冷项的量级，是调试环境实现的基准；其二，共享约束造成的功率缺口无法靠单室独立控制消除，只能通过峰谷电价下的时间迁移与房间间热传导的协同来弥补，这正是评论家需要全局温度场的原因。

补充口径说明。算例中的 β 把功率折算为温度变化，实际设备的制冷量还受能效比与环境湿度影响，线性 β 只在工作区间内近似成立。数字仿真中若发现大功率段的温降与线性预测偏离明显，应先在标定数据上校正 β 的工作区间，再检查学习曲线；跳过校正会让策略把模型偏差学成行为偏好，例如长期回避高功率动作。

调试顺序建议先核对单室温升曲线与手算值，再接入多室传导，最后接入共享约束。三者一次性接入时，任何一环的量纲偏差都会表现为整体的奖励尺度异常，定位成本成倍上升。

热传导项的衰减速度可以手算：两房间耦合系数 κ = 0.05、其余条件相同，温差每步按因子 1 − 2κ = 0.9 收缩，初温差 2 摄氏度降到 0.5 摄氏度需要 14 步（0.913 ≈ 0.254 对应的温差 0.508 仍高于 0.5，0.914 ≈ 0.229 满足），初温差 4 摄氏度则需要 20 步。传导的时间常数 1/(2κ) = 10 步与单房换热的时间常数 1/α = 10 步同阶，邻室协同与室外散热的速率相当，两个通道都不能忽略。省略传导项建模会把邻室间的影响全部归给室外通道，学到的策略在隔墙耦合强的房型上失效。

投影的比例保持性质用不等需求的问题核对：四房间原始需求为 [1.8, 3.6, 3.6, 3.6] 千瓦、峰值上限 2.8 千瓦时，缩放因子为 2.8/12.6 ≈ 0.222，投影后为 [0.4, 0.8, 0.8, 0.8]，相对份额保持不变。比例投影不做分配仲裁，需求高的房间仍获得更多功率；若任务要求有人在的房间优先，比例投影不足，需要换用带优先级的裁剪投影，并把优先级信号放入观测让策略提前适应。

共享约束持续贴轨时有结构性失效风险：峰值上限低于全部房间维持设定值的总需求时，温度偏差是系统容量不足的结果，策略层面已无改善空间，价值函数在让谁偏离之间反复摆动。诊断方法是检查约束活跃比例与各房间偏差分布：偏差长期集中在固定房间说明策略已形成稳定的优先级；偏差在房间之间轮换说明分配规则尚未形成，需要检查观测中是否包含在场或优先级信号。

关键代码与解读

片段 1：多房间热演化

import numpy as np

def thermal_step(t_in, t_out, q, alpha, kappa, beta):
    """一步热演化：室外换热 + 邻室传导 + 空调制冷。
    t_in/t_out: 室温与室外温度；kappa[i, j]: 房间 i、j 间传导系数。
    """
    outdoor = alpha * (t_out - t_in)          # 室外热流入
    neighbor = kappa @ t_in - kappa.sum(1) * t_in  # 邻室净传导
    cooled = beta * q                          # 制冷量
    return t_in + outdoor + neighbor - cooled

解读：kappa @ t_in 是流入总量，kappa.sum(1) * t_in 是流出总量，用矩阵形式一次完成全部邻室的净交换计算，系数矩阵对称保证热量守恒。室温与室外温度使用同一单位（摄氏度），而制冷量按功率乘效率折算为温度变化，量纲在设计阶段就要统一，混用瓦特与摄氏度是常见错误。

片段 2：带死区的舒适度奖励

import numpy as np

def comfort_reward(t_in, t_set, deadband=0.5, w_c=1.0, w_e=0.2,
                   price=1.0, q=None):
    """舒适度与能耗的加权奖励。
    deadband: 舒适死区半宽；price: 当前电价系数。
    """
    deviation = np.abs(t_in - t_set) - deadband
    # 死区内偏差为负，clip 后归零：只在越界时产生惩罚
    violation = np.maximum(0.0, deviation)
    comfort = -w_c * float(np.sum(violation ** 2))
    energy = -w_e * price * float(np.sum(q))
    return comfort + energy

解读：np.maximum 的截断位置决定惩罚的连续性与可导性，二次方处罚使大偏差的边际代价递增，符合"温度越不舒适越难以容忍"的实际感知。电价系数乘在能耗项上，使同一份电量在峰时段的代价更高，策略因此学会把制冷负荷向低价时段迁移，这属于需求响应（demand response）的奖励实现方式。

片段 3：峰值功率投影层

import torch
import torch.nn as nn

class PeakProjection(nn.Module):
    """把各房间功率按比例缩放，使其总和不超过共享上限。"""
    def __init__(self, peak):
        super().__init__()
        self.peak = peak

    def forward(self, q_raw):
        # q_raw 形状 [批, 房间数]，先经 softplus 保证非负
        q = torch.nn.functional.softplus(q_raw)
        total = q.sum(dim=-1, keepdim=True)
        # 缩放因子上限为 1：总量未超限时不改变动作
        scale = torch.clamp(self.peak / total.clamp_min(1e-6), max=1.0)
        return q * scale

解读：clamp(max=1.0) 保证投影只在超限时生效，总量正常时动作原样通过，避免了对策略输出的系统性压缩。按比例缩放保留了策略给出的相对分配，属于最小干预的投影方式。替代方案是按优先级裁剪（先保障有人的房间），代价是需要额外判断逻辑且投影后的梯度不连续。

常见坑

  • 舒适度奖励全零：死区过宽或权重过大时，初始策略长期获得恒定奖励，优势估计方差为零而无法学习。修复：初期收窄死区或加入与偏差线性相关的小项。
  • 投影层后忘记梯度修正：投影改变了动作分布，但策略梯度仍按未投影动作计算，导致更新方向与执行行为不一致。修复：把投影写进计算图内，或采用投影后重参数化采样。
  • 时间尺度错配：按分钟级决策而温度响应时间常数为小时级，价值估计被相邻步的高相关观测主导，泛化变差。修复：决策间隔取时间常数的一到两个数量级以下，并核查相邻帧自相关。
  • 室外预报直接当真实值：训练使用完美预报、部署使用带误差预报，性能骤降。修复：训练时对预报加噪声，模拟预报误差分布。
  • 共享约束只写进奖励：拉格朗日惩罚下策略仍可能短时违规，触发硬件保护停机。修复：奖励惩罚用于训练，执行端保留投影或回退层兜底。

    把缩放因子代入求和式，利用 softplus 输出的非负性讨论总量与上限的大小关系。
  4. 设计实验：训练期给室外预报叠加高斯噪声（方差两档），比较部署时的舒适度达标率，验证鲁棒性训练的效果。★★★
    提示
    对照组用无噪声训练；评价用带误差的部署预报；指标取达标率与能耗的联合表现。
  5. 峰时电价系数 2.0、谷时 0.5，死区允许温度在 25.5 到 26.5 摄氏度之间浮动。设计一个预冷策略：在峰时前把温度拉向死区下界，写出成本对比式并说明预冷的边界条件。★★
    提示
    预冷多消耗的电量按谷价计，峰时少用的电量按峰价计，两者价差构成节省上界；边界条件是预冷期间温度不得越过死区下界，且过度预冷会抬高能耗项，需要价值函数在时间维度上权衡。

小结

  • 多房间热耦合用 RC 模型刻画，非对角传导项使舒适度目标不可按房间分解，协同决策因此必要。
  • 舒适度用死区二次惩罚、能耗按分时电价加权，两项权重决定帕累托工作点；死区设计不当会使奖励失去梯度。
  • 共享功率上限推荐"惩罚训练加投影执行"的组合，投影按比例缩放且仅在超限时生效。
  • CTDE 让执行期只依赖本地传感；上一动作入观测并配合切换惩罚，可抑制设备频繁启停。
  • 数值算例给出热量尺度的校验基准：平衡功率由散热项与制冷项的手算比例确定，共享上限收紧后的缺口必须靠时间迁移与邻室协同弥补。
