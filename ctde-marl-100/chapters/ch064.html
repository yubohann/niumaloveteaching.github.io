第四篇 · 高级机制与研究专题

第 064 章：多智能体环境监测

把多台移动传感器部署到空间场中采样，用高斯过程（Gaussian Process, GP）刻画场的后验不确定性，让信息增益成为奖励，并用集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）协调采样路径、抑制重复采样。

  • 主题：信息驱动的采样 / 高斯过程与信息增益
  • 关键公式：I(q) = H(Σt) − H(Σt+1)，H(Σ) = ½log((2πe)ddetΣ)
  • 预计学时：60 分钟
  • 前置章节：第 063 章

学习目标

  • 掌握高斯过程回归（Gaussian Process Regression, GPR）的后验均值与方差公式，理解核函数（kernel）在空间相关建模中的作用。
  • 理解信息增益与熵的关系，能推导高斯分布下熵的表达式并说明为什么信息增益恒为非负。
  • 掌握多机采样中的信息冗余问题，理解路径重叠为何破坏单机贪心的近似保证。
  • 能实现局域不确定性地图编码策略，并解释观测裁剪（crop）与归一化的必要性。
  • 能设计实验比较 CTDE、独立信息贪心与随机游走三种策略在均方预测误差与采样效率上的差异。

背景与动机

环境监测的目标是用尽可能少的采样还原空间场的分布：水质监测、气体泄漏溯源、温度场重建都属此类。场在空间上连续且相关，相邻位置的观测可以互相推断，因此采样点之间存在信息替代关系。传统做法是用高斯过程建模场并对候选点做信息贪心，单机场景下有接近最优的近似保证。多台传感器同时采样时，贪心规则失效：两台机器人可能同时奔向同一信息热点，第二台获得的实际增益远低于预估。

本章与第 063 章相比，奖励来源从物理量的即时收益换为对世界的认知改进，属于内在奖励（intrinsic reward）的来源之一；动作从连续功率换成平面运动指令，耦合来源从共享功率换成采样位置的相互影响。用集中式评论家评估联合采样轨迹的信息增益，恰好弥补执行期智能体看不到队友计划的信息缺口。

核心原理

本节从高斯过程后验出发，导出信息增益奖励，再讨论多机冗余与 CTDE 映射。

1. 空间场的高斯过程建模

设场值 f(x) 服从高斯过程：任意有限点集上的取值服从联合高斯分布，协方差由核函数 k(x, x′) 给出。常用径向基（Radial Basis Function, RBF）核 k(x, x′) = σf2exp(−‖x−x′‖2/(2ℓ2))，ℓ 为长度尺度，刻画相关范围。给定带噪观测 (X, y)，后验预测为：

μ(x*) = k*T(K + σn2I)−1y，σ2(x*) = k** − k*T(K + σn2I)−1k* k* 为待测点与样本的协方差向量，K 为样本间协方差矩阵，σn2 为观测噪声方差

后验方差只依赖采样位置，与观测值无关，这一性质使信息增益可以在规划阶段精确预测，无需真实观测。方差在远离样本处趋近先验值 σf2，在样本附近被显著压低，形状由长度尺度决定。

核参数的估计方法按数据量选择：样本少于数百条时用边缘似然最大化；数据量大时用留一交叉验证的均方误差或半变异函数拟合。长度尺度的估计误差对后验形状影响最直接：估小一倍会让方差在样本之间保持高位，策略被虚假的不确定性反复吸引到同一区域，表现为采样点局部聚团。

2. 信息增益：熵的下降

不确定性用微分熵度量。d 维高斯分布的熵为 H(Σ) = ½log((2πe)ddetΣ)。一次采样使协方差从 Σt 变为 Σt+1，信息增益定义为熵差。对单点目标位置，熵差为 ½log(σt2/σt+12)，即方差比的对数半值。

I = H(Σt) − H(Σt+1) = ½log(σt2/σt+12) ≥ 0 观测只会降低方差，增益恒非负；增益随重复采样同一位置而趋近 0

信息增益函数在采样点集合上接近次模（submodular），单机序贯贪心可获得至少 (1−1/e) 倍最优的近似。多机场景下，两台机器人同一时隙的联合增益小于各自预估增益之和，次模性恰好量化了这种 1+1<2 的冗余。

增益对观测噪声的敏感度可以核算：噪声方差从 0.05 降到 0.025 时，单点后验方差从 0.048 降到 0.024，增益从 1.52 nat 升到 1.86 nat，变化不足四分之一。增益与噪声是对数关系，量级稳定；相比之下核参数错配会让后验方差整片形状失真，核查的优先级应放在长度尺度上。

3. 多机冗余与协同机制

冗余有两种来源：空间重叠（采样半径覆盖同一区域）与时间重叠（同一智能体连续采样同一区域）。缓解手段有三：奖励中扣除重复增益（用已计入的联合增益替代逐机增益求和）、观测中广播队友近期采样位置（轻量共享）、策略内在分工（不同智能体学习不同方向的偏好）。第一类手段通过评论家实现，训练期就能看到联合效果；后两类需要执行期的动作或观测协调，复杂度更高。

冗余的代价可以用上一节的核参数直接量化：两台机器人在同一点采样的联合增益约为 1.52 + 0.33 = 1.86 nat；分头到相隔 2ℓ 的两个位置，总增益约 3.03 nat，比同点采样高约 63%。差距不是小幅优化空间，分工与不分工的信息量差出一个量级内的显著比例，这解释了为什么多机监测的绩效对分工机制特别敏感。

4. CTDE 映射

观测 oi 含智能体位置、局部感知范围内的均值与方差网格、最近采样值；动作 ai 为平面速度向量；奖励为团队信息增益减去移动代价与重复惩罚。集中式评论家输入全部智能体位置与局部地图拼接，价值对应未来若干步的累计信息增益，执行期各智能体仅凭局部地图选动作。

5. 数值算例：后验方差与重复采样冗余

取 RBF 核、先验方差 1、观测噪声方差 0.05。单样本条件下，各位置的后验方差可由公式直接计算：采样点处为 1−1/(1.05)≈0.048；距样本一个长度尺度 ℓ 处核值 exp(−0.5)≈0.607，后验方差约 1−0.6072/1.05≈0.649；距样本 2ℓ 处核值约 0.135，后验方差约 0.983，几乎回到先验水平。

重复采样算例：两台机器人都采样同一位置。第一份样本把该点方差从 1 压到 0.048，信息增益约 ½ln(1/0.048)≈1.52 nat；第二份样本只把方差再压到 0.024，增益约 ½ln(0.048/0.024)≈0.34 nat，仅为首份的约 22%。若第二台机器人改去距首样本 2ℓ 的新位置，该点增益约 ½ln(0.983/0.048)≈1.51 nat，与首份相当。

解读：核值随距离平方指数衰减，后验方差在 2ℓ 外回到先验，解释了网格分辨率取约 ℓ/3 的依据：更粗无法分辨方差梯度，更细只增加计算量。重复采样的增益折减与"新位置的全额增益"对照，说明多机协同的收益几乎全部来自空间分工；奖励因此采用联合增益求和，逐机增益相加会重复计入同一区域的收益。

补充计算复杂度。后验求解需要对核矩阵做一次分解与两次三角求解，复杂度随样本数三次方增长；批量评估多台机器人的联合增益时，每次候选位置评估都要重复这一过程，规划视界与候选点数量的乘积决定单步规划预算。滑动窗口上限取 200 点正是在这一预算约束下的折中，规模更大时应切换诱导点稀疏近似，同时重新标定长度尺度。

复现提示：把一次后验更新的耗时与单步规划耗时分别记录，两者比值超过约三成时说明规划预算已被推断占满，应减小候选点数量或窗口长度；继续加大规划视界只会让预算更紧张。

第二次采样的矩阵计算可以完整写出：两个观测的核矩阵为 K = [[1.05, ρ], [ρ, 1.05]]，ρ 为两点的先验相关，后验方差为 1 − kTK−1k，k = [1, ρ]T。同点（ρ = 1）时 kTK−1k = 0.1/0.1025 ≈ 0.976，后验方差约 0.0244，第二份样本的增益约 0.33 nat，仅为首份的约两成。换成一般距离可以得到一张单调的对照表：

第二份样本的边际增益随距离单调上升，在 2ℓ 外几乎等于首份的全额增益（1.52 nat）；协同的全部价值集中在把第二台机器人推向新位置这一段距离上，奖励设计让去新位置优于留在原地，正是对这条曲线的利用。表格也解释了为什么冗余抑制不能只靠惩罚：距离 1ℓ 处增益已恢复到 1.32，仅靠“去新位置”的自然激励就够了，惩罚项主要用于阻止同点重复。

复杂度随样本数三次方增长：窗口从 200 点扩到 1000 点时核矩阵分解的运算量放大约 125 倍；诱导点稀疏近似把复杂度降到与 n·m2 成正比，诱导点取 50 个时，200 样本的运算量约 5 × 105 次，比稠密分解低一个数量级以上。窗口长度与诱导点数是两套预算旋钮，选择依据是后验地图在智能体活动范围上的分辨率是否仍能分辨方差梯度，分辨率不足时先加窗口，足够时优先稀疏化。

实现思路与设计

核心数据流是"采样更新后验、后验生成本地地图、地图进策略、策略输出速度"。高斯过程更新按固定样本容量滑动窗口执行。

设计决策：为什么用滑动窗口而不保留全部样本

高斯过程推断的复杂度为 O(n3)，样本越多代价增长越快。监测场在时间上缓慢漂移，远期样本对当前后验的贡献有限，滑动窗口以轻微的建模损失换取可控代价。窗口大小需要与长度尺度匹配：窗口内样本的空间跨度应覆盖相关范围，否则后验方差被系统高估。更大规模时改用诱导点稀疏近似，把复杂度降到 O(nm2)。

与第 063 章的差异：奖励来源从物理收益换为认知收益，信息增益可由协方差解析预测，奖励计算不需要环境反馈；评论家输入从温度向量换成空间地图，需要卷积或网格编码结构。

关键代码与解读

片段 1：高斯过程后验

import numpy as np

def gp_posterior(X, y, X_star, ls=3.0, var=1.0, noise=0.05):
    """RBF 核的高斯过程后验均值与方差。
    X: 采样位置 [n, d]；y: 观测 [n]；X_star: 预测位置 [m, d]。
    """
    def rbf(A, B):
        d2 = ((A[:, None, :] - B[None, :, :]) ** 2).sum(-1)
        return var * np.exp(-0.5 * d2 / ls ** 2)

    K = rbf(X, X) + noise * np.eye(len(X))
    Ks = rbf(X, X_star)
    # Cholesky 分解替代显式求逆：数值稳定，复杂度同为 O(n^3)
    L = np.linalg.cholesky(K)
    alpha = np.linalg.solve(L.T, np.linalg.solve(L, y))
    mu = Ks.T @ alpha
    v = np.linalg.solve(L, Ks)
    var_post = var - (v ** 2).sum(0)          # 观测削减后的剩余方差
    return mu, np.maximum(var_post, 1e-9)

解读：两次三角求解复用同一个 Cholesky 因子，比逐一求解线性方程组节省一半以上的运算量，这是把复杂度控制在可接受范围的关键写法。后验方差用"先验减削减量"表达，残差恒非负由正定性保证，最后的截断只用于吸收浮点误差。批量预测时把 X_star 一次性传入，避免逐点循环。

片段 2：信息增益奖励

import numpy as np

def info_gain(var_before, var_after):
    """单点采样的信息增益：高斯熵的下降量。
    var_before/var_after 形状相同，单位是场值的方差。
    """
    eps = 1e-9
    # 高斯微分熵 H = 0.5 * log(2*pi*e*var)，对数底为自然对数
    h_before = 0.5 * np.log(2 * np.pi * np.e * np.maximum(var_before, eps))
    h_after = 0.5 * np.log(2 * np.pi * np.e * np.maximum(var_after, eps))
    gain = np.sum(h_before - h_after)
    # 数值截断：浮点误差可能产生极小负值
    return float(max(gain, 0.0))

解读：增益只在方差下降幅度大时显著，策略因此天然偏好"高不确定性且远离已采样点"的位置。对重复采样位置，var_after 几乎等于 var_before，增益趋近 0，机制自带冗余抑制。替代方案是直接用方差下降量（非对数）作奖励，量纲更直观但在高方差区域梯度偏大，容易吸引全部智能体挤向个别热点。

片段 3：局部地图编码策略

import torch
import torch.nn as nn

class SamplingPolicy(nn.Module):
    """局部不确定性地图与近期采样值联合编码，输出平面速度。"""
    def __init__(self, map_dim=64, sample_dim=8, emb=64):
        super().__init__()
        self.map_enc = nn.Sequential(nn.Linear(map_dim, emb), nn.ReLU())
        self.samp_enc = nn.Sequential(nn.Linear(sample_dim, emb), nn.ReLU())
        self.head = nn.Linear(emb, 2)

    def forward(self, local_map, last_samples):
        # 地图按全局统计归一化，否则不同场强下输入尺度漂移
        z = self.map_enc(local_map) + self.samp_enc(last_samples)
        vel = torch.tanh(self.head(torch.relu(z))) * 2.0   # 限速 2 米每秒
        return vel

解读：两路编码相加允许策略在"看哪里"与"刚采到什么"之间自由组合权重。tanh 乘限速常数的写法保证动作有界且梯度平滑，比裁剪出界动作更利于策略梯度估计。局部地图截取以智能体为中心的固定边长窗口，窗口边长应覆盖两到三倍长度尺度，过小则看不到可采样的不确定性梯度，过大则输入维度浪费。

常见坑

  • 核参数与场不匹配：长度尺度设得远小于真实相关范围，后验方差在样本之间仍很高，策略被虚假的不确定性吸引。修复：先用最大似然拟合核参数，或按观测半变异函数估计。
  • 信息增益逐机求和：每台机器人独立计算增益并相加，重复区域的增益被高估约 N 倍。修复：用联合后验计算一次总增益，再作为团队奖励分配。
  • 地图归一化使用全局常数：不同场强下输入尺度漂移，策略泛化差。修复：按当前后验的最大方差归一化，或使用分位数裁剪。
  • 移动代价缺失：策略学会原地反复采样高噪声位置刷取微小增益。修复：加入与位移成正比的代价项，并核查平均轨迹长度。
  • 滑动窗口覆盖不足：窗口内样本空间跨度小于相关范围，远处旧样本被丢弃后后验方差被高估。修复：窗口按空间分布管理，各方向保留代表样本。

    系数增大使智能体主动分离，覆盖率上升；过大会压制对高价值热点的集中采样，均方误差先降后升。
  3. 推导：证明高斯分布下微分熵 H = ½log((2πe)ddetΣ)，并由此给出两点目标下信息增益用行列式表达的公式。★★★
    提示
    从微分熵定义出发代入高斯密度，积分得到含期望二次型的项，利用 E[xTAx]=tr(AΣ) 化简；两点情形直接把行列式比取对数。
  4. 设计实验：固定采样预算为每智能体 200 步，比较信息贪心、CTDE 与随机游走的均方误差曲线，并统计三者的重叠采样比例。★★★
    提示
    重叠比例用"与他机采样点距离小于 ℓ/2 的次数占比"度量；预期贪心重叠最高，CTDE 在信息增益总量上接近贪心但重叠显著更低。
  5. 取先验方差 1、噪声方差 0.05，计算距单一样本 0.5ℓ、ℓ、1.5ℓ 三处的后验方差与首次采样增益，说明增益随距离下降的形状为何与核函数不同。★★
    提示
    核值分别为 exp(−0.125)≈0.882、exp(−0.5)≈0.607、exp(−1.125)≈0.325；后验方差约为 0.258、0.649、0.899，增益约为 0.68、0.22、0.05 nat。增益含对数变换，衰减比核值更快也更有结构。

小结

  • 空间场用高斯过程建模，后验方差只依赖采样位置，使信息增益可在规划阶段解析预测。
  • 信息增益是熵的下降，恒为非负，在采样点集合上接近次模，重复采样同一位置的边际增益趋近零。
  • 多机冗余来自空间与时间重叠，用联合后验计算团队增益是抑制冗余的核心机制。
  • CTDE 的价值在于训练期看到队友位置与计划；执行期策略仅依赖局部地图，需要窗口裁剪与归一化配套。
  • 数值算例量化了冗余：重复采样同一位置的增益衰减到首份的两成左右，分工到新位置的采样接近全额增益，这是多机协同的主要收益来源。
  • 后验方差只依赖采样位置，重复采样的增益折减与核衰减形状共同决定探索奖励的尺度，奖励设计应让"去新位置"始终优于"留在原地"。
