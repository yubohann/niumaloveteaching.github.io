第二篇 · 训练工程与稳定性

第 031 章：大规模智能体扩展性

本章讲智能体数量扩展的三类瓶颈（联合动作空间、输入维度、信用信噪比）与三类结构对策：均值场（Mean-Field）近似、局部邻域交互、置换不变的网络组织，以及规模迁移的评测方法。

  • 主题：规模化结构 / 交互复杂度控制
  • 关键公式：Qi(o, ai, āN(i))，ā 为邻居平均动作
  • 预计学时：55 分钟
  • 前置章节：第 030 章 异构智能体协作

学习目标

  • 理解规模扩展的三个瓶颈：联合动作空间的指数增长、集中式输入维度的线性增长、信用分配信噪比的衰减。
  • 掌握均值场近似的思想与形式：用邻居平均动作替代逐个建模，把交互复杂度降为常数。
  • 掌握局部邻域与注意力机制的信息组织，理解 O(N·k) 与 O(N²) 复杂度差异的适用边界。
  • 理解置换不变性与动态数量的处理：聚合函数的选择、死亡智能体的掩码与均值的无偏修正。
  • 能按规模档位给出网络结构决策表，并设计参数量、计算量、收敛步数随 N 变化的评测实验。

背景与动机

第 030 章处理智能体"种类"的差异，本章处理"数量"的增长。从 5 个智能体扩展到 50 个，训练系统的三个层面同时承压：联合动作空间按 |A|N 增长，例如 |A| = 5、N = 10 时组合数接近千万，任何显式枚举的算法结构直接失效；集中式模块的输入维度按 N 线性增长，全连接层的参数与计算量同步膨胀；团队奖励的信用信噪比随 N 下降，单个智能体的贡献被平均化，梯度信号越来越稀薄。

这三类瓶颈决定了大规模训练的可行结构。参数共享（第 004 章）先解决参数量问题；本章的结构手段进一步解决输入维度与交互复杂度问题，让每步计算量随 N 近似线性增长，远离平方或指数增长。现实任务（无人机集群、交通网络、粒子环境）的规模从数十到数百智能体，能否扩展到这些规模取决于网络组织决策是否在训练开始前就设计正确。

核心原理

1. 三个瓶颈的数学刻画

规模 N 增长时，训练系统的代价结构为：

联合动作空间规模：|A|N；集中式输入维度：O(N·do)；团队信用的个体信噪比：O(1/N) 量级 |A| 为单智能体动作数，do 为单智能体观测维度；第三项为经验量级

三项瓶颈对应三类损失：显式枚举算法（依赖联合动作 max 或精确分解）在大 N 下不可用；全连接的集中式评论家参数量与计算量膨胀；共用一套团队奖励时个体贡献的方差被邻居的动作噪声淹没。结构对策的共同思想是把"全体对全体"的交互降为"局部对局部"或"个体对统计量"的交互，让每步计算复杂度与 N 解耦或线性相关。

2. 均值场近似

均值场（Mean-Field）方法用一个统计量替代对全部邻居的逐个建模：智能体 i 的价值不再依赖每个邻居的具体动作，只依赖邻居动作的平均值：

Qi(s, a) ≈ Qi(oi, ai, āN(i))，其中 āN(i) = (1/|N(i)|) Σj∈N(i) aj N(i) 为智能体 i 的邻居集合；平均动作 ā 概括邻居群体行为

近似的误差来源是高阶交互项：当智能体的收益依赖邻居动作的分布形状（例如需要"一半左、一半右"的编队），平均值不足以概括时，均值场丢失信息。均值场更新的迭代形式（用邻居价值的玻尔兹曼平均值重构最优响应）在理论上有不动点保证，工程上通常直接以网络实现：把邻居的编码特征做置换不变的均值池化，再与个体信息拼接送入价值网络。动作语义在异构智能体间不一致时，均值必须在同类型智能体内部进行，跨类型统计转交给角色分组结构（第 030 章）。

3. 局部邻域与注意力

另一条路线保留逐邻居建模，但把邻居数量限制为常数 k：每个智能体只观测与交互最近邻的 k 个智能体。复杂度从全局注意力的 O(N²) 降为 O(N·k)：

注意力聚合：hi = Σj∈N(i) αij vj，αij = softmaxj( qiTkj / √d ) q、k、v 为查询、键、值投影；局部约束把求和范围从全体压到 k 个邻居

邻域的定义可以是空间距离最近、通信链路可达或预定义的编队结构。k 的选择是信息与代价的权衡：k 过小丢失协调所需信息，k 过大退化为全局注意力。经验取值在 4 到 8 之间，按任务中"一次协调动作涉及的有效伙伴数"标定。局部结构还有一项迁移收益：邻域大小固定后，同一套参数可以在不同 N 下运行，模型从 10 智能体训练后直接服务 50 智能体的推理，无需重新设计输入层。

4. 置换不变性与动态数量

智能体之间无固定顺序，网络对邻居的聚合结果必须与输入排列无关：求和、均值、最大池化天然置换不变，逐个拼接与逐元素加权相乘则依赖顺序。训练中的顺序稳定性由数据管线保证（固定索引约定），而跨规模迁移要求结构层面使用置换不变的聚合。

动态数量（智能体在回合中被消灭或中途加入）引入两个工程问题：其一，死亡智能体的观测与动作需要掩码，聚合统计量在有效智能体集合上计算；若简单置零参与平均，平均值被系统性稀释。修正方式是把均值改为有效集合上的均值，并在批次中维护有效计数。其二，价值分解框架中死亡智能体的个体价值是否进入混合器需要与训练一致：常见约定是死亡智能体掩码后不参与混合（等价于其价值视为 0 且占据无贡献位），与第 028 章无合法动作的处理共享同一通路。

读表：联合动作空间在 N = 10 时就到 107 量级，N = 50 时约 1034.95，任何显式枚举结构直接失效；输入维度与信噪比只是线性变化，前者可以压成常数、后者用信用分配机制补偿。规模扩展的优先级因此是"先拆掉指数项，再治理线性项"：局部邻域或均值场重塑交互结构，参数共享控制参数量，信用分配方案应对信噪比衰减。

6. 数值算例：均值场的不可区分性

构造一个两邻居例子（邻居动作集 {−1, 0, 1}），说明平均动作的信息损失（机制示意例）：

邻居动作组合动作均值 ā真实回报
(1, −1)01.00
(0, 0)00.20

两组组合的统计量完全相同（均值 0），回报相差 0.80。均值场评论家对这两组输入只能给出同一个估计，最优回归解是两值的平均 0.60，单组误差 0.40、均方误差 0.16，这一误差不随网络容量增大而消失，属于近似的结构误差。失效边界由此明确：收益依赖邻居动作分布形状（对向夹击、一半掩护一半突进）时，平均值不足以概括，应改用局部注意力保留逐个邻居动作，或把均值升级为分布统计量（改用各动作的频率向量）。

7. 数值算例：掩码均值的稀释效应

5 个智能体中有若干死亡，存活者的动作均为 1.0（死者动作记为 0）。若不掩码直接把全体求平均，统计量随死亡数下降（数值经程序核对）：

死亡数未掩码均值有效集合均值
01.001.00
10.801.00
20.601.00

读数：未掩码均值按存活比例线性稀释，死亡两人时统计量失真 40%；网络会把这种稀释当成"邻居行为变弱"来拟合，等价于在价值函数中混入一个与任务无关的存活数变量。掩码版本在有效集合上求均值，统计量恒定；有效计数本身可以显式作为特征提供给网络，让"人数减少"成为可区分输入，消除隐含的统计失真。

8. 三类交互结构的信息与代价对照

结构每步复杂度信息保留失效模式
全局拼接或全局注意力输入 O(N·d)；注意力 O(N²)完整N 大时输入层与计算量一起失控
局部邻域注意力O(N·k)保留邻域内逐个动作k 小于协调半径时丢失协同信息
均值场O(N)只保留一阶统计量收益依赖动作分布形状时产生结构误差

代价数字（数值经程序核对）：N = 100、k = 6 时局部注意力的邻居交互次数为 600，全局为 10000，比值 16.7；k = 8 时比值为 12.5。选择判据链：先问协调是否需要逐个队友的信息，不需要则用均值场；需要则用局部注意力，k 取协调半径对应的邻居数；只有任务本身全局耦合（例如全局投票）且 N 不大时，全局结构在经济上才成立。

9. 规模课程与结构不变性的配合

规模课程从 4 智能体逐档升到目标规模，训练中每个档位的 N 都不同。结构选型有两条纪律：其一，聚合与编码器在所有档位共用同一套参数与同一套输入接口，N 只体现在集合大小上，这要求输入层维度与 N 完全脱钩，升档时只改变环境侧的智能体数量；其二，档位切换时重置的是难度相关量（探索率档位、课程进度），不重置网络参数，避免每次升档都重新学习基本技能。经验档位取 4、8、16、32，每档以协作成功率连续若干回合超过阈值作为升档条件；评测应同时报告目标规模下的性能与从最小档到目标档的总环境步数，后者衡量课程摊销后的真实成本，只报前者会掩盖课程设计失败的情形。档位数超过四档后收益边际递减，相邻档的规模差距建议控制在两倍以内，差距过大等价于每档重新开始。规模课程的调度器复用第 022 章的通用接口，本节的增量只在结构与 N 脱钩这一条。

实现思路与设计

结构选择按规模档位决策，再按交互结构参数化网络。整条管线中，参数量由参数共享控制、输入维度由局部编码控制、计算量由邻居数控制，三个旋钮各管一段。

关键代码与解读

片段 1：均值场评论家

import torch
import torch.nn as nn

class MeanFieldCritic(nn.Module):
    """个体价值依赖邻居平均动作：交互复杂度与邻居数解耦。"""
    def __init__(self, obs_dim, act_dim, hidden=128):
        super().__init__()
        self.own = nn.Sequential(nn.Linear(obs_dim, hidden), nn.ReLU())
        # 邻居编码器把 (平均动作, 平均观测) 压成统计向量
        self.neighbor = nn.Sequential(nn.Linear(act_dim + obs_dim, hidden), nn.ReLU())
        self.head = nn.Sequential(nn.Linear(hidden * 2, hidden), nn.ReLU(), nn.Linear(hidden, 1))

    def forward(self, obs, actions, alive):
        """obs/actions: (batch, N, ·)；alive: (batch, N) 有效掩码。"""
        mask = alive.unsqueeze(-1).float()
        # 有效集合上的均值：乘法掩码后除以有效计数，避免死亡个体稀释统计
        count = mask.sum(dim=1).clamp(min=1.0)
        mean_act = (actions * mask).sum(dim=1) / count
        mean_obs = (obs * mask).sum(dim=1) / count
        own = self.own(obs)                                   # 个体项保留全部局部信息
        stat = self.neighbor(torch.cat([mean_act, mean_obs], dim=-1))
        # 广播统计项到每个个体：同一批邻居下每个智能体一个价值输出
        return self.head(torch.cat([own, stat.unsqueeze(1).expand_as(own)], dim=-1))

解读：掩码除法是这段代码的核心工程点：均值的无偏修正让统计量直接可比，死亡个体的动作不会把邻居平均拉向零。个体项保留完整局部观测，统计项只承担"群体态势"的概括，两者在输出头拼接。计算复杂度对每步是 O(N·d)，与邻居数的显式规模无关；把此结构用于策略梯度类算法时，统计项输入改为邻居演员网络输出的平均或注意力加权和，模块替换而掩码逻辑不变。

片段 2：局部邻域注意力聚合

class LocalAttention(nn.Module):
    """每个智能体只对 k 近邻做注意力：复杂度 O(N·k)。"""
    def __init__(self, latent=64, heads=2):
        super().__init__()
        self.h = heads
        self.qkv = nn.Linear(latent, latent * 3)   # 查询、键、值一次投影，减少小矩阵开销
        self.out = nn.Linear(latent, latent)

    def forward(self, feats, neighbor_idx):
        """feats: (batch, N, latent)；neighbor_idx: (batch, N, k) 邻居索引。"""
        b, n, d = feats.shape
        k = neighbor_idx.shape[-1]
        q, kk, v = self.qkv(feats).chunk(3, dim=-1)          # 各自 (b, n, d)
        q = q.view(b, n, self.h, d // self.h)                # 拆多头：与后面聚合的排列一致
        kk = kk.view(b, n, self.h, d // self.h)
        v = v.view(b, n, self.h, d // self.h)
        idx = neighbor_idx.view(b, n, k, 1, 1).expand(b, n, k, self.h, d // self.h)
        # 先把节点维展开成可收集的形状，再按邻居索引 gather：只取 k 个邻居
        k_nb = torch.gather(kk.unsqueeze(1).expand(b, n, n, self.h, d // self.h), 2, idx)
        v_nb = torch.gather(v.unsqueeze(1).expand(b, n, n, self.h, d // self.h), 2, idx)
        # 点积注意力在 k 维归一化：概率质量严格限定在邻居集合内
        att = (q.unsqueeze(2) * k_nb).sum(dim=-1) / (d // self.h) ** 0.5
        att = torch.softmax(att, dim=2)
        agg = (att.unsqueeze(-1) * v_nb).sum(dim=2)          # (b, n, h, d/h)
        return self.out(agg.reshape(b, n, d))

解读：这段实现展示"按索引取邻居"与"多头注意力"的组合：其一，gather 按预先计算的邻居索引取键值，邻居数量 k 为常数，整体计算量与 N 线性相关；其二，softmax 在邻居维上归一化，注意力范围被结构性地限定在局部集合内，与全局注意力形成对照。邻居索引由环境几何或通信图离线生成，支持按状态动态更新；当 k 等于 N 时该实现退化为全局注意力，可作为对照实验的基线。真实工程中这段收集逻辑会封装为工具函数（PyMARL 风格按索引聚合的写法），此处展开以便看清张量维度的对齐关系。

片段 3：置换不变性与规模迁移检查

def check_permutation_invariance(model, obs, alive):
    """打乱智能体顺序后，逐智能体输出应随索引一起重排，聚合统计严格不变。"""
    import torch
    perm = torch.randperm(obs.shape[1])
    out = model(obs, alive)
    out_perm = model(obs[:, perm], alive[:, perm])
    # argsort(perm) 把置换后的输出次序还原，逐项比对
    err = (out - out_perm[:, torch.argsort(perm)]).abs().max().item()
    assert err < 1e-5, f"聚合破坏置换不变性，误差 {err}"
    # 规模迁移检查：同一模型接受 N=8 与 N=32 的输入，输出形状一致
    big = obs.repeat(1, 4, 1)
    big_alive = alive.repeat(1, 4)
    assert model(big, big_alive).shape[1] == big.shape[1]
    print("置换不变性与规模迁移检查通过")

解读：该检查把两个结构性质变成可执行的断言，接入单元测试后能在改动网络时立即捕获退化。第二个断言验证的是结构设计目标：输出形状随输入智能体数量伸缩，模型不因 N 变化而失效。注意它只验证形状与可运行性，跨规模的性能迁移仍需环境步数到回报的实测曲线；把测试与实验分开，避免把结构性质误读为性能保证。

常见坑

  • 全局拼接输入随 N 变化。集中式评论家输入维度与训练时的 N 绑定，扩展时整层失效。症状是 N 改变后模型无法加载。修复：局部聚合加固定隐空间，输入维度与 N 脱钩。
  • 死亡智能体未掩码参与统计。均值被置零个体稀释，邻居行为估计系统性偏低。症状是存活智能体的价值随死亡数量整体下移。修复：有效集合上计算均值，批次维护有效计数。
  • 均值场用于语义不一致的动作。异构动作取平均没有意义。症状是策略在大 N 下无法形成有效协同。修复：同类型内部均值，跨类型交给角色条件。
  • 邻域与注意力的配置缺陷。k 过小丢失协同信息、过大失去复杂度优势；softmax 在全智能体维执行使概率质量泄漏到非邻居位置。修复：按协调伙伴数标定 k 并观察 4 到 8 的回报曲线；归一化严格限定在邻居维。
  • 规模课程与网络结构不匹配。结构对小 N 优化（例如固定维度输入）却在课程中直接跳到大 N，训练崩溃。修复：结构先满足最大目标规模的输入约束，课程只调节难度。

练习与思考

  1. 推导：设单智能体观测维度 d、邻居数 k、注意力隐维度 m，写出局部注意力评论家每步计算量关于 N、k、m 的表达式，并与全局注意力对比，给出复杂度相等的临界 k 值。★
    提示
    局部为 O(N·k·m)，全局为 O(N²·m)；临界条件 k = N，即邻居数覆盖全部智能体时两者重合。
  2. 改参数预测：把邻居数 k 从 6 降到 2，预测训练前 20 万环境步的协作成功率曲线与价值损失曲线的变化，并说明哪种任务最先受损。★
    提示
    需要三个以上伙伴同步的任务最先受损；协作成功率上升更慢，价值损失因目标不可达而保持高位波动。
  3. 设计：为一个 40 智能体的聚集任务设计网络结构（聚合方式、邻居定义、有效集合处理），并给出死亡智能体比例从 0 升到 30% 时各项统计量的预期行为。★★
    提示
    空间最近邻 k = 6 加均值聚合；有效集合均值随死亡比例上升保持无偏；若发现价值整体下移，检查掩码是否进入均值除法。
  4. 实验设计：在同一个均值场算法上评测 N 取 10、30、60 三档的参数量、每步计算量、达到固定回报的环境步数，绘制三组曲线并解释曲线形状与理论复杂度的对应关系。★★★
    提示
    参数量应近似不变（参数共享），计算量近似线性增长，收敛步数可能随 N 上升而增加，这是信用信噪比下降的直接体现。

小结

  • 规模扩展的三个瓶颈：联合动作空间指数增长、集中式输入维度线性增长、个体信用信噪比随 N 衰减。
  • 均值场用邻居平均动作替代逐个建模，交互复杂度与邻居数解耦；平均值必须限定在同类智能体与有效集合内。
  • 局部邻域注意力把 O(N²) 降为 O(N·k)，k 按协调伙伴数标定；固定邻域使模型可跨规模迁移。
  • 置换不变聚合（均值、求和、最大值）是跨规模与跨顺序稳定的结构基础；死亡智能体掩码与有效计数修正保证统计无偏。
