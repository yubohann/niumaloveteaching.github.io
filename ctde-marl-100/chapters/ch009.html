第一篇 · CTDE 基础与核心算法

第 009 章：COMA反事实基线实现

策略梯度路线的信用分配方案：用一个集中式评论家回答"如果只有我换动作，团队价值会怎样"，用对该问题在自身动作分布下的期望作为基线。COMA（Counterfactual Multi-Agent Policy Gradients）的这段反事实基线是对单智能体演员批评家的自然推广，本章给出推导、评论家接口设计与完整实现。

  • 主题：反事实基线 / 演员批评家
  • 关键公式：Ai(s, a) = Q(s, a) − Σa′i πi(a′i | τi) Q( s, (a−i, a′i) )
  • 预计学时：55 分钟
  • 前置章节：第 008 章

学习目标

  • 理解团队奖励下策略梯度的方差来源，以及反事实基线相对于团队价值基线的差别。
  • 掌握反事实基线的构造：固定其他智能体动作、对自身动作边际化，并证明其对自身动作的期望为零。
  • 掌握适合边际化计算的评论家接口：自身动作槽位置零、按智能体分组输出动作价值。
  • 会实现反事实优势计算与演员更新，理解基线项 detach 处理的原因。
  • 能对比 COMA 与值分解三代方法的适用条件与计算代价，为第 010 章的连续动作方法建立对照。

背景与动机

第 003 章的多智能体策略梯度 ∇θi J = 𝔼[∇ log πi(ai|τi)·Qπ(s, a)] 在理论上成立，实践中团队奖励带来两个问题：回报的随机性高，梯度方差随智能体数放大；用团队价值做基线只能整体平移权重，无法回答"这个动作对团队价值的增量是多少"这一信用分配问题。

COMA（Counterfactual Multi-Agent Policy Gradients）的洞察是：基线可以从"团队平均"下沉到"个体反事实平均"。对智能体 i 而言，队友的动作已经发生，反事实问题只涉及它自己的动作：假如我换成别的动作、队友保持不变，价值如何变化？把这一差值在自身动作分布下取期望，得到与动作无关的基线，正好正交于策略梯度。用一个输出按智能体分组的集中式评论家，一次前向即可获得全部反事实值，N 个基线的计算摊薄到 O(N·|Ai|)。COMA 是离散动作空间上信用分配最直接的实现，也是理解第 020 章多种分配机制的枢纽。

核心原理

本节给出基线的一般条件、反事实基线的推导与性质、评论家接口的数学形式，以及与差值奖励的关系。

1. 基线的合法性条件与团队基线的不足

策略梯度允许减去任意只依赖历史 τ 的基线 b(τ)，因为：

𝔼ai∼πi [ ∇θi log πi(ai | τi) · b(τi) ] = b(τi) · ∇θi Σai πi(ai | τi) = 0 关键：b 不依赖 ai，求和可移出。团队价值 V(s) 满足该条件，但其中不含"仅因我而变化"的成分，信用分配无从谈起

进一步放宽：只要基线 b(τi, a−i) 不依赖 ai，同一推导逐点成立。反事实基线正是这一族的成员，它比历史函数携带更多信息（队友动作已知），因此在条件方差意义上更接近最优基线。

2. 反事实基线的构造与性质

Ai(s, a) = Q(s, a) − Σa′i πi(a′i | τi) · Q( s, (a−i, a′i) ) 第二项把智能体 i 的动作在自身策略下边际化，得到"队友如现状时，平均而言的个体价值"；差值即当前动作相对自身平均水平的超额，即反事实优势

性质一（零均值）。𝔼ai∼πi[Ai] = Σai πi(ai|τi) Q(s, a) − Σa′i πi(a′i|τi) Q(s, (a−i, a′i)) = 0。基线项与策略梯度正交，估计无偏。性质二（信息利用）。基线条件于 (τi, a−i)，比 V(s) 携带更多关于回报结构的信息，剩余方差更小。性质三（信用定位）。差值只随 ai 变化：队友造成的高回报被基线同样吸收，不会错误地强化智能体 i 的动作，这正是团队基线做不到的。

3. 与差值奖励的联系

差值奖励（difference reward）Di(z) = R(z) − R(z−i) 用"移除智能体 i 的贡献"定义个体功劳，需要构造 z−i（常用默认动作替换）。反事实基线与它同源：把默认动作替换的确定性差值，换成在自身策略下的期望差值：

Σa′i πi(a′i|τi) [ Q(s, a) − Q(s, (a−i, a′i)) ] 展开即 Ai。也就是说反事实基线等于"期望差值奖励"，同时解决了默认动作选择问题与稀疏回报下的估计问题；第 020 章将从分配机制角度回到这一族

4. 评论家接口：为边际化而设计

反事实基线的计算需要 Q(s, (a−i, a′i)) 对全部 a′i 取值。若为每个 (i, a′i) 单独前向，代价为 N·|Ai| 次；COMA 的评论家把这一组查询折叠进一次前向：

Qθ(s, a−i) ∈ ℝ|Ai|，输入为 s 与"自身动作槽置零"的联合动作 one-hot，并附加智能体标识 idi 输出向量的第 a′ 个分量即 Q(s, (a−i, a′i = a′))。训练该评论家时把完整联合动作填入后取对应分量；计算基线时对输出向量与 πi 做内积

置零自身动作槽是接口设计的核心：它强制评论家看不到"实际执行的动作"，只能基于队友动作给出评估，输出的每个分量天然对应一个反事实选项。评论家用团队回报做时序差分训练，与第 003 章的集中式评论家同源，仅输出结构不同。

5. 与值分解和集中式 Q 的对照

三族方法对同一个信用分配问题的回答各不相同：值分解把总价值拆成个体分量，用结构约束保证可执行性，适合离散动作、离策略大批量训练；集中式 Q 加显式演员（第 003 章）用自由评论家，但基线停留在团队层面；COMA 保留自由评论家，用反事实边际化把信用分配写进优势项，代价是每次更新需要 N 次向量化边际化与按智能体的输出结构。COMA 是策略梯度方法（因此天然支持随机策略与探索），其离散动作边际化在内积中完成；连续动作的对应替代见第 010、014 章。

方法族动作空间信用分配机制每次更新的关键代价
VDN / QMIX 值分解离散结构化总价值对个体分量的导数一次混合器前向，无按动作枚举
COMA离散反事实优势（对自身动作边际化）每智能体一次评论家前向，读取 |Ai| 维向量
MADDPG（第 010 章）连续评论家对自身动作的链路梯度每智能体一次评论家前向加一次反传

三行对照给出选择顺序：动作离散且价值结构可加或单调时用值分解；动作离散且需要精细信用信号、任务含明显分工时用 COMA；动作连续时转向确定性策略梯度。离散与连续混合动作的设定在第 029 章处理。

6. 数值算例：两种基线的权重方差对照

取一个固定状态，两智能体各两动作，联合价值矩阵 Q(s, ·) = [[8, 4], [3, 1]]（行对应智能体 1 的动作，列对应智能体 2 的动作），两智能体策略均为均匀分布 (0.5, 0.5)。分别计算团队基线与反事实基线的权重项，全部数字经程序核对：

联合动作 (a1, a2)Q(s, a)团队基线权重 Q − V反事实权重 A1
(0, 0)84.02.5
(0, 1)40.01.5
(1, 0)3−1.0−2.5
(1, 1)1−3.0−1.5

团队基线 V 取均匀策略下的联合期望，V = (8 + 4 + 3 + 1) / 4 = 4；反事实基线按队友动作分组计算：a2 = 0 时 0.5×8 + 0.5×3 = 5.5，a2 = 1 时 0.5×4 + 0.5×1 = 2.5。两组权重在均匀采样下的均值都为零（对应前面两条零均值性质），权重方差分别为 6.5 与 4.25，反事实基线把权重方差降到原有的 65.4%，约 35% 的降幅。机制解释：团队基线把"队友导致的差异"（动作 1 列的行均值从 6 降到 2，落差 4.0 的一半计入权重）也写进权重，这部分与智能体 1 的动作无关，只贡献噪声；反事实基线按队友动作分组后再取组内差值，组间共同平移被吸收，权重只剩"当前动作相对组内均值"的成分。当队友动作与回报强相关、组间落差大时，这种吸收幅度更大；当任务接近可加、组间差异接近零时，两种基线的方差差距缩小，COMA 的收益相应有限，这是选择该路线前的第一层判断。

代价一侧同样可以量化：分组输出评论家在每个状态上需要 N 次前向（每个智能体一次，取各自的价值向量），标量评论家只要 1 次；换来的是对 |Ai| 个反事实选项的并行读取，替代了朴素替换采样的 N·|Ai| 次前向。动作空间增大时该折中依然占优，但输出层参数与维度随动作数线性增长，|Ai| 超过数百的场景应先做动作分支降维再接入本接口，否则最后一层的参数量会成为新的瓶颈。

实现思路与设计

本节给出 COMA 的组件与配置：分散演员输出离散分布，集中式评论家按智能体分组输出动作价值，训练按回合批次进行。

演员结构MLP 64×64，输出 logits；参数共享可选与第 004 章共享开关兼容；默认不共享，控制变量

与第 003、008 章的差异点：评论家输出从标量变为分组向量，信用分配从"误差均分"（VDN）与"拉伸个体价值"（QTRAN 的 Lopt）变为"优势项的逐动作比较"。数据接口增加"每个时刻的演员分布快照"字段：反事实基线要在旧分布上计算，训练批次必须携带当时的 πi(· | τi) 或由策略一致性保证可重算。

设计决策：评论家按智能体分组输出的理由

标量评论家 Q(s, a) 用"替换后重新前向"也能得到反事实值，但每次替换都要一遍网络，N 个智能体各 |Ai| 次查询让更新代价乘上 N·|Ai|。分组输出把这个循环变成一次前向的向量读取：同一 (s, a−i) 下全部候选动作的价值在同一输出层并行给出。代价是网络输出维度随 N 与动作数线性增长，以及"自身动作信息被系统屏蔽"的接口约束必须由实现保证。

零均值检查的容差设置

检查的容差不能取固定值，要按样本标准误设定。以第 6 小节的权重方差 4.25 为例，反事实优势的样本标准差约 2.06；按每批 8 回合 × 60 步 = 480 个样本计，均值的标准误约为 2.06 / √480 ≈ 0.094。此时固定容差 0.05 会让正确实现有约 59.5% 的概率误报（数值经程序核对），检查失去判别力。实用做法：容差取 max(0.05, 3 × σ̂ / √B)，其中 σ̂ 为该批优势的样本标准差、B 为样本数；等价地监控标准化均值 √B × 均值 / σ̂，阈值取 3。系数 3 对应正态近似下约 99.7% 的覆盖，样本数很少时该近似不可靠，应改用滑动多批平均后再判定。同一纪律适用于第 003 章集中式评论家带来的任何零均值检验。

关键代码与解读

片段 1：分组输出评论家

import torch
import torch.nn as nn

class COMACritic(nn.Module):
    """集中式评论家: 自身动作槽置零, 输出该智能体的全部候选动作价值。"""
    def __init__(self, state_dim, n_agents, n_actions, hidden=128, emb_dim=8):
        super().__init__()
        self.logit = nn.Sequential(
            nn.Linear(state_dim + n_agents * n_actions + emb_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, n_actions),        # 输出向量维 = 自身动作空间大小
        )
        self.id_emb = nn.Embedding(n_agents, emb_dim)

    def forward(self, state, joint_oh, agent_idx):
        # joint_oh 中第 agent_idx 段的 one-hot 必须已被置零, 屏蔽自身动作
        e = self.id_emb(agent_idx)               # (B, emb_dim)
        x = torch.cat([state, joint_oh, e], dim=-1)
        return self.logit(x)                     # (B, n_actions) 反事实价值向量

解读：接口设计与理论部分的映射是逐项的。（1）输出维度取 n_actions，对应 Q(s, (a−i, a′i)) 的候选集合；调用方用 agent_idx 决定置零哪一段输入。（2）置零动作在调用侧完成，网络内部不处理这一步：网络无从知道"哪个动作被执行过"，实现层把这一约定放在数据流入口，配合断言检查置零段是否全为零。（3）id 嵌入让同一权重服务全部智能体，参数量与 N 无关地增长，这是评论家直接复用第 004 章共享思想的实例。

片段 2：反事实优势

def counterfactual_advantage(critic, actor_i, batch, agent_idx, n_actions):
    """计算智能体 i 的反事实优势: A_i = Q(s,a) - E_{a'_i~pi_i}[Q(s,(a_-i,a'_i))]。"""
    state, joint_oh, act, _ = batch
    B = state.shape[0]
    # 构造自身槽置零的输入: 其余智能体动作保持实际执行值
    masked = joint_oh.clone()
    seg = slice(agent_idx * n_actions, (agent_idx + 1) * n_actions)
    masked[:, seg] = 0.0
    idx = torch.full((B,), agent_idx, dtype=torch.long)
    with torch.no_grad():
        q_vec = critic(state, masked, idx)               # (B, nA) 全部反事实价值
        probs = actor_i(batch.obs_i).probs               # 采集时刻的策略分布
        baseline = (q_vec * probs).sum(dim=1)            # 对自身动作边际化
        q_actual = q_vec.gather(1, act[:, agent_idx:agent_idx + 1]).squeeze(1)
    # 优势按常数处理: 梯度只经 score function 项流入演员参数
    return (q_actual - baseline).detach()

解读：这段代码承载反事实基线的全部数学。（1）masked[:, seg] = 0.0 屏蔽自身动作段，保证评论家看不到实际执行动作；队友动作段保持原值，回答"队友如现状"的条件问题。（2）(q_vec * probs).sum(dim=1) 是内积形式的边际化，与公式第二项逐字对应；probs 取自采集时刻的策略（批次字段或可重算的一致性检查），训练中途策略已前移，用错分布会让基线与梯度估计不匹配。（3）返回值整体 detach：反事实优势作为权重使用，REINFORCE 型估计器忽略通过基线的二阶项，这是与第 003 章 advantages.detach() 一致的处理纪律。

片段 3：演员更新与零均值自检

def coma_actor_loss(actor_i, batch, advantage):
    """策略梯度: 优势权重冻结, 梯度只经对数概率项。"""
    logp = actor_i(batch.obs_i).log_prob(batch.act_i)
    return -(logp * advantage).mean()

def check_zero_mean(advantage_samples, tol=0.05):
    """经验自检: 大样本上反事实优势的均值应接近零。"""
    m = float(advantage_samples.mean())
    # 均值显著偏离零提示置零段泄漏或概率分布错配, 属于实现级故障
    return abs(m) <= tol, m

解读：coma_actor_loss 的形状与第 003 章完全一致，替换的只有优势项的来源：团队优势换成反事实优势。这种"接口不变、信用信号升级"的重构是第 003 章数据层预留字段的直接回报。check_zero_mean 把性质一变成训练期的监控指标：零均值性质在正确实现下是精确成立的期望等式，经验均值长期偏离零只有两类原因，置零段泄漏了自身动作，或边际化用的 π 分布与实际执行分布错配；两种都属于实现故障，调参无法修复。把该检查挂在每个训练周期末尾，可以在早期拦截绝大多数接口错误。

常见坑

  • 忘记屏蔽自身动作槽。症状：反事实优势的零均值检查持续偏移，且优势与自身动作强相关。原因：评论家看到了实际执行动作，输出向量不再是反事实值组。修复：在数据入口加入断言，置零段的范数必须为零。
  • 边际化用错策略分布。症状：训练发散或策略提前收敛到低熵。原因：用更新后的策略分布计算旧批次的基线，权重向新分布倾斜。修复：批次携带采集时刻的 logits 或概率字段，边际化一律读取保存值。
  • 优势未 detach 导致二阶项污染。症状：优势项自身参与梯度后出现难以解释的漂移，梯度范数与优势尺度不正相关。原因：反事实基线内部的 π 与 Q 参与了反向传播。修复：优势整体 detach，仅保留 score function 项；用梯度范数日志确认修好后量级恢复正常。
  • 评论家输出索引错位。症状：零均值检查通过但策略不改进。原因：gather 读取的列与智能体动作的编码顺序不一致（例如动作索引与输出列存在偏移）。修复：用"单动作数据集"做对拍：固定执行动作 a，断言 q_actual 恒等于 q_vec 的第 a 列。
  • 评论家容量不足。症状：Ai 的尺度长期偏小，策略改进缓慢。原因：分组输出使每个样本只监督一个分量，其余分量靠泛化，容量过小无法学到反事实结构。修复：增大隐藏层宽度并观察零均值检查与回报曲线是否同步改善。

练习与思考

  1. 两动作情形：πi = (0.3, 0.7)，反事实价值向量 Q(s, (a−i, a′i)) = (4, 2)。计算两个动作的反事实优势，并验证其在 πi 下的期望为零。★
    提示
    基线 = 0.3×4 + 0.7×2 = 2.6；优势为 (1.4, −0.6)，期望 0.3×1.4 + 0.7×(−0.6) = 0。
  2. 把边际化中的策略分布从"采集时刻"改为"当前策略"，在非平稳策略更新下预测零均值检查与回报曲线的变化方向。★
    提示
    基线与实际动作分布错配后，优势均值不再为零（加权中心偏移），零均值检查首先报警；回报曲线随后出现策略熵异常下降。监控指标是发现该类错误的第一信号。
  3. 推导：证明反事实基线等于"在自身策略分布下对差值奖励的期望"，其中差值奖励取默认动作为"分布下的任意固定动作"。写出推导的关键交换步骤。★★
    提示
    由 Q(s,a) − Σπ(a′)Q(s,(a−i,a′)) = Σπ(a′)[Q(s,a) − Q(s,(a−i,a′))]，把 Q 差额解释为以 a′ 为对照的差值奖励；交换步骤利用了 Σπ(a′)=1。
  4. 设计实验测量信用分配收益：在同一任务上比较 (a) 团队价值基线 A = r + γV(s′) − V(s)；(b) 反事实基线。报告策略梯度范数的方差、收敛所需环境步数与最终回报，并解释预期的方差差异。★★
    提示
    预期 (b) 的梯度方差显著更低，收敛步数更少；差异在需要精细分工的任务上最大。方差计算可在固定批次上重复采样动作估计，作为可复现的度量。
  5. 设计题：连续动作空间下反事实基线需要 Σ 替换为期望采样。给出两种方案（单样本蒙特卡洛、高斯闭式近似）的估计式、方差性质与实现代价，并说明第 010 章 MADDPG 为何完全放弃这一路线。★★★
    提示
    单样本蒙特卡洛无偏但方差高；闭式近似要求评论家对动作二次型等结构假设。MADDPG 用确定性策略绕过"对自身动作边际化"的需求，把信用分配交给集中式评论家的梯度路径。

小结

  • 反事实基线 Ai = Q(s, a) − Σa′i πi(a′i|τi) Q(s, (a−i, a′i)) 条件于队友动作，对自身动作期望为零，估计无偏且方差更低。
  • 它与差值奖励同源，把默认动作替换的确定性差值推广为策略分布下的期望差值。
  • 分组输出评论家把 N·|Ai| 次反事实查询折叠为一次前向；自身动作槽置零是接口正确性的核心约束。
  • 零均值检查把理论性质变成实现级自检，可拦截屏蔽失效与分布错配两类高频故障。
  • 下一章进入连续动作：MADDPG 多智能体连续控制，用确定性策略梯度与集中式评论家处理连续动作的协调。
