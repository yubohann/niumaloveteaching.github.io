第 073 章：迁移学习与CTDE结合

把已训练好的协作策略迁移到新的规模、动力学或观测配置：本章先讲清迁移学习的目标与三类求解方式，再讲参数迁移、特征对齐与价值校准在 CTDE 中的落点，并给出负迁移检测与实验设计。

  • 主题：跨任务复用 / 微调、对齐与校准
  • 关键公式：Ltar(θ) + λ‖θ − θsrc‖2
  • 预计学时：60 分钟
  • 前置章节：第 072 章

学习目标

  • 掌握迁移学习的三种目标设定（参数迁移、特征对齐、样本复用），能写出各自的损失形式。
  • 理解负迁移（negative transfer）的产生条件，能设计检测流程区分迁移收益与随机波动。
  • 掌握 CTDE 各组件的迁移性差异：编码器、策略头、评论家、混合器的迁移难度依次排列及原因。
  • 能实现带源参数正则的微调、最大均值差异（Maximum Mean Discrepancy, MMD）特征对齐与价值校准三个片段。
  • 能设计实验：从完全重训、全量微调到冻结编码器三档基线，加正则强度扫描与规模扩展组的消融。

背景与动机

协作策略的训练代价高，而实际需求通常以"变体"形式出现：机器人数量从 4 台增到 8 台，载重与摩擦参数改变，传感器从 10 维升到 14 维。从零训练每个变体在环境交互预算上不可接受，迁移的目标是让源任务的经验把目标任务的首达门槛步数压缩一个量级。迁移并不总有效：源任务与目标任务的差异会使源特征产生系统性偏置，此时性能低于从零训练。

与第 030 章异构协作、第 022 章课程学习相比，本章关注任务分布之间的跳变；单任务内的难度递增属于课程学习的议题。CTDE 的分工结构恰好提供迁移切口：与规模相关的只有智能体编码与聚合方式，与任务相关的只有观测编码与奖励尺度，两类参数可以分开处理。

核心原理

本节先讲迁移学习的定义与三类目标函数，再讲 CTDE 各组件迁移能力的差异与校准方法。

1. 迁移学习：定义与目标

源任务 Msrc 上训练获得参数 θsrc，目标任务 Mtar 的分布与之不同（动力学参数、智能体数量或观测空间任一维度的差异）。迁移学习的直接做法是两阶段：初始化 θ ← θsrc 后在目标任务上继续训练。带正则的联合目标在一阶段内完成：

minθ Ltar(θ) + λΩ(θ, θsrc)，常用 Ω = ‖θ − θsrc‖2 λ=0 退化为普通微调，λ→∞ 退化为冻结源参数；L2-SP 正则在二者间连续插值

正则的作用是限制参数偏离源解的距离，在目标数据稀少的早期阶段，正则项等价于以源任务为均值的高斯先验。数据积累后减小 λ 允许参数自由修正源偏置。

2. 特征对齐

观测空间变化时无法直接复用输入层，可在特征层做分布对齐：把源特征与目标特征映射到同一空间，最小化两者分布的距离。最大均值差异用核函数度量分布距离，可作为可微正则项加入损失。

MMD2 = ‖(1/m)Σiφ(zsi) − (1/n)Σjφ(ztj)‖2，对齐目标为 Ltar + λ·MMD2 z 为特征层输出，φ 为核特征映射；实践用核技巧展开避免显式映射

3. CTDE 各组件的迁移性

按迁移难度排序：局部编码器最容易迁移（感知与技能跨任务相似）；策略头次之（动作语义通常保持，动作空间变化时需替换输出层）；集中式评论家较难（价值尺度随奖励与规模变化，需要校准）；混合网络最难（其单调性约束下的权重与智能体数量的对应关系直接绑定，规模变化时参数结构失配）。工程策略是冻结编码器、微调策略头、重置或校准价值尺度、重建混合网络。

4. 价值校准与负迁移检测

目标任务的回报量级与源任务不同时，直接沿用评论家会产生自举偏差。校准方式有两种：在线性输出层加可学习缩放与偏移（Q′ = αQ + β），或在目标数据上重估价值函数的前几千步。负迁移的检测用三组对照：源参数初始化组、随机初始化组、随机初始化但相同训练预算组，只有当源初始化组在多种子统计下显著更快达到门槛时才判定迁移有效。

5. 数值算例：正则量级、价值校准与 MMD

正则算例。某共享层单参数从源值 0.30 漂移到 0.35，平方惩罚为 0.0025；该层有 1e4 个参数、平均偏离 0.05 时惩罚合计约 25。取 λ=1e-3 时该项贡献 0.025，与量级 0.5 的时序差分损失相比约占 5%。标定目标即让早期惩罚占损失比重维持在几个百分点：过小不起约束作用，过大把参数冻结在源解上。

校准算例。源任务价值输出范围约 1 到 10，目标任务为 100 到 1000。直接沿用评论家时自举目标与预测值相差两个数量级，时序差分残差被放大上百倍，损失曲线初期出现尖峰。仿射校准 Q′=αQ+β 以 α=50、β=0 初始化，残差回落到可训练区间，两个参数在前几千步内微调到实际比例。

MMD 算例。取线性核时 MMD2 退化为两批特征均值差的平方。源特征均值 (1, 2)、目标均值 (1.5, 1.5) 时为 0.25+0.25=0.5；均值接近时该值趋零，但线性核只检测一阶差异，方差层面的偏移需要改用高斯核才能暴露。

解读：三个数字分别对应参数层、输出层与特征层的对齐手段。开启顺序建议先校准价值量级保证自举稳定，再解冻感知层并施加参数正则，最后按对齐损失曲线决定是否加入 MMD 项；顺序颠倒会让早期高方差的对齐梯度污染价值估计，之后的迁移收益难以归因。

负迁移检测的配对设计。同一评估种子下比较源初始化与随机初始化两条曲线，逐种子求首达步数差值再统计。配对把环境随机性从差值中消去，所需种子数少于独立两组比较；差值置信区间跨零判定迁移无收益，负迁移发生率按差值显著为正的种子占比报告。

报告模板建议四行并列：从零训练、全量微调、正则微调、冻结编码器的首达步数均值与配对差值区间。四行同表呈现使选择依据一目了然，也便于第三方按同一模板复算与横向核对。

实现思路与设计

迁移流程分三步：结构适配（对齐观测与动作维度）→ 参数装载（按组件选择性加载）→ 训练（正则微调加价值校准）。

实验设计

  1. 对比基线：目标域从零训练、全参数微调、冻结编码器三类。
  2. 消融设置：λ ∈ {0, 1e-3, 1e-2}、价值校准开/关、MMD 对齐开/关、规模组 4→6 与 4→8。
  3. 评价指标：目标域首达门槛步数、最终回报、迁移增益比（相对从零训练的步数比值）、负迁移发生率。
  4. 统计方式：多种子配对的差值统计，配对设计降低方差。
设计决策：为什么冻结编码器往往优于全量微调

全量微调令全部参数自由更新，目标数据不足时源特征在早期被噪声覆盖，相当于用少量目标样本重新学习感知，迁移收益消失。冻结编码器把学习集中在决策层，感知层保留源任务的通用表征。代价是目标观测分布与源差异较大时，冻结层成为表示瓶颈；判断依据是对齐损失曲线，持续上升即需要解冻并降低学习率。

与第 072 章的差异：上一章恢复奖励，本章复用整套参数；关注点从"学什么"转为"哪些参数值得保留、哪些必须重置"。

对比分析：四类复用策略的取舍

策略加载参数目标域数据需求主要风险适用条件
从零训练无最大样本浪费任务差异极大
全量微调全部中源特征被早期噪声覆盖数据量充足
L2-SP 正则微调全部加约束中λ 标定敏感数据量中等
冻结编码器编码器冻结、头部训练小表示瓶颈观测分布接近

选择的准则按目标域数据量与观测分布差异二维定位：数据少且分布接近时冻结编码器收益最稳；数据中等时用 L2-SP 正则留出修正空间；数据充足且分布差异大时全量微调不再吃亏。四档的边界应由配对多种子的首达步数实验决定，直觉判断在小样本下经常给出错误结论。

规模扩展组的特别说明：智能体数量变化时受影响的组件集中在聚合与混合环节，编码器与策略头通常仍可装载。把 4 到 8 的扩展组与 4 到 6 的组并列报告，可以区分装载策略失效与规模泛化困难两类原因；只报一组时两种原因混在同一条曲线上，无法归因。

关键代码与解读

片段 1：带源参数正则的微调

import torch

def l2_sp_penalty(model, source_state, exclude=("head",)):
    """L2-SP 正则：约束参数偏离源解，输出层除外。
    source_state: 源任务参数快照；exclude: 名称包含该子串的参数跳过。
    """
    pen = 0.0
    for name, p in model.named_parameters():
        if any(key in name for key in exclude):
            continue                      # 输出头绑定新动作空间，不做约束
        pen = pen + ((p - source_state[name]) ** 2).sum()
    return pen

解读：排除输出头的理由是新任务的输出层语义已变化，把源输出层拉回旧空间会直接阻碍任务适配。惩罚在参数层面计算，与损失量级无关，λ 需要按参数量级缩放。快照应保存训练完成时的参数，它比最优验证参数更平滑。

片段 2：MMD 特征对齐

import torch

def mmd2(z_src, z_tar, bandwidth=None):
    """最大均值差异平方的有偏估计（高斯核）。"""
    if bandwidth is None:
        # 中值启发式：用两域混合样本对距离的中位数定核宽
        z = torch.cat([z_src, z_tar], dim=0)
        d = torch.cdist(z, z)
        bandwidth = d.median().clamp_min(1e-6)
    def k(a, b):
        dist2 = torch.cdist(a, b) ** 2
        return torch.exp(-dist2 / (2 * bandwidth ** 2))
    kss = k(z_src, z_src).mean()
    ktt = k(z_tar, z_tar).mean()
    kst = k(z_src, z_tar).mean()
    return kss + ktt - 2 * kst

解读：MMD 展开为三项核均值，对角项包含自相关，小批量下有偏但方差可控，属于常用折中。核宽取混合样本距离中位数保证尺度自适应，避免手工调参。对齐项建议只作用于中间特征层，作用于输出会干扰策略的决策边界。

片段 3：评论家价值校准

import torch
import torch.nn as nn

class ValueCalibrator(nn.Module):
    """对迁移评论家的输出做仿射校准：Q' = alpha * Q + beta。"""
    def __init__(self):
        super().__init__()
        self.alpha = nn.Parameter(torch.ones(1))
        self.beta = nn.Parameter(torch.zeros(1))

    def forward(self, q):
        # 前向时钳制 alpha 下界，防止校准层把价值整体翻转
        alpha = torch.clamp(self.alpha, min=1e-3)
        return alpha * q + self.beta

解读：仿射校准只有两个参数，用目标域少量数据即可收敛，属于最小的可学习适配面。钳制 α 下界避免训练早期把价值符号反向。校准层挂载在评论家输出之后，目标网络同步持有校准副本，否则自举目标与预测值处于不同尺度。

常见坑

  • 负迁移无检测流程：只看曲线感觉更好，缺少随机初始化对照。修复：配对多种子实验，报告首达步数差值的置信区间。
  • 观测归一化统计未迁移：沿用源域均值方差，目标域输入分布偏移。修复：用目标域数据重估统计量，或改用在线自适应归一化。
  • 价值尺度失配：目标奖励量级变化后沿用评论家输出，自举目标震荡。修复：仿射校准或重置价值输出层。
  • 混合网络直接装载：智能体数量变化后混合器权重结构失配，强行加载导致形状错误或语义错乱。修复：混合网络重建，仅保留单调性结构超参数。
  • 目标域早期冻结过度：观测空间差异大时冻结编码器形成表示瓶颈，训练长期停滞。修复：监控对齐损失，超阈值后按低学习率解冻。

练习与思考

  1. 源任务奖励量级为 1 到 10，目标任务为 100 到 1000，说明不做校准时自举目标的误差量级与修复方案。★
    提示
    误差与价值量级成正比，未校准的评论家输出被放大后时序差分残差溢出；仿射校准或重置输出层即可对齐。
  2. 把 λ 从 0 调到 1e-2，预测首达门槛步数与最终回报的变化，解释曲线交叉点。★★
    提示
    λ 偏大时早期受源约束、后期难以突破，终值低于自由微调；交叉点出现在源偏置尚未成为瓶颈之前。
  3. 推导：说明 MMD 平方作为核均值差在特征映射为恒等时退化为两批样本均值差的欧氏距离平方。★★★
    提示
    取线性核 k(a,b)=a·b，展开三项核均值即得 ‖mean_s − mean_t‖²。
  4. 设计实验：4 智能体源策略迁移到 8 智能体目标，对比冻结编码器、全量微调与从零训练的首达步数，并给出负迁移的判定标准。★★★
    提示
    配对 5 种子，计算冻结组相对从零组的步数差；差值置信区间跨零即判定无迁移收益。
  5. 某共享层有 1e4 个参数，平均偏离源解 0.05。计算平方惩罚的总量，写出使该惩罚占时序差分损失（量级 0.5）不超过 5% 的 λ 上界。★★
    提示
    惩罚合计 1e4×0.0025=25；要求 λ×25≤0.05×0.5=0.025，得 λ≤1e-3，与推荐初值一致。训练后期再按曲线下调 λ 释放自由度。

小结

  • 迁移学习把源任务参数作为先验，L2-SP 正则在"完全微调"与"完全冻结"之间连续插值。
  • 特征对齐处理观测空间变化，MMD 提供可微的分布距离，核宽用中值启发式自适应。
  • CTDE 的迁移难度按编码器、策略头、评论家、混合网络递增，规模相关的组件建议重建，直接装载会失配。
  • 价值校准与负迁移检测是两项必要保障：前者对齐量级，后者用配对多种子实验划清收益与波动。
  • 数值算例给出三层对齐尺度：参数正则占损失比重控制在几个百分点，价值仿射校准把两个数量级的自举残差压回可训练区间，MMD 负责检测特征均值偏移。
  • 配对多种子的检测设计把环境随机性从差值中消去，迁移收益以差值置信区间为判定单位，负迁移发生率按差值显著为正的种子占比报告。
