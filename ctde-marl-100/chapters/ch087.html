第 087 章：图通信与对手建模

把通信拓扑显式结构化为图：节点是智能体、边由距离或可见性定义，消息沿边稀疏传播，参数量与智能体数量解耦；对手建模部分讨论如何用轨迹预测与类型推断应对非平稳的其他学习主体。

  • 主题：图神经网络通信 / 对手建模（Opponent Modeling）
  • 关键公式：消息传递 h′i = U(hi, ⊕j∈N(i) M(hi, hj, eij))、对手动作预测交叉熵
  • 预计学时：60 分钟
  • 前置章节：第 086 章

学习目标

  • 理解图通信的建模方式：节点、边、邻接矩阵的定义与三种邻接构造策略。
  • 掌握图神经网络（Graph Neural Network, GNN）消息传递公式与置换等变性的意义。
  • 理解对手建模两类方法：行为预测与类型推断，掌握它们作为辅助任务的训练方式。
  • 理解心智理论（Theory of Mind）层级与递归推理的直觉及其计算代价。
  • 能实现带边特征的图消息传递层与对手预测辅助头，并设计联合训练与评估方案。

背景与动机

第 085 与 086 章讨论发什么消息、发多少信息，通信对象一直是全体智能体。全连接通信有两个现实困难：一是通信量随智能体数平方增长；二是远处的智能体通常与当前决策无关，给它们发消息纯粹消耗带宽。把交互结构显式建模为图，让消息只沿与任务相关的边传播，是同时解决两个困难的直接手段。图结构还带来一个额外收益：参数量与智能体数量解耦，训练时 5 个智能体的模型可以直接作用于 20 个智能体的场景。

对手建模处理另一类难题：其他主体的策略在训练中不断变化，从任一智能体视角看环境是非平稳的。如果能把"别人会怎么做"作为可学习的预测问题显式建模，智能体就能对策略变化做出更快的适应。图通信与对手建模共享同一条方法论：把隐式的交互结构变成显式的建模对象。两者的结合点在于，图定义"跟谁交互"，对手模型定义"如何理解交互对象"。

核心原理

1. 图结构的定义与邻接构造

图 G = (V, E) 中，顶点集 V 是智能体集合，边集 E 刻画交互关系。邻接矩阵 A ∈ RN×N 的三种常见构造：

  • 距离阈值：Aij = 1 当且仅当智能体 i 与 j 的距离小于 r。邻接随位置动态变化，适合编队、自动驾驶等几何交互任务。
  • k 近邻：每个节点连接最近的 k 个邻居。度数固定，保证通信量上界 O(N·k)，适合密度不均匀的部署。
  • 可见性：Aij = 1 当且仅当 j 落在 i 的感知范围内。最贴近执行期现实，但可能产生单向边，需要处理非对称消息流。

无论哪种构造，边权都可以从二值升级为连续权重（例如距离的反比），为消息传递提供几何信息。三者的共同点是局部性假设：与远处智能体的交互通过多跳传播间接完成，直接全连接被有意省略。

2. 图神经网络消息传递

GNN 的基本操作是消息传递：每个节点沿入边收集邻居消息，聚合后更新自身状态：

mij = M(hi, hj, eij)，h′i = U( hi, ⊕j ∈ N(i) mij ) M 为消息函数，U 为更新函数（常用 GRU），⊕ 为置换不变的聚合（求和、均值、最大值）

两层堆叠后，节点 2 跳范围内邻居的信息都能到达；层数与感受野成正比，层数过多会出现过平滑（Over-smoothing）：所有节点表示趋同，区分度消失。聚合函数使用求和或均值保证置换等变性：交换任意两个智能体的编号，输出只是对应交换，网络学到的交互规律不依赖编号，这正是参数共享能跨数量泛化的数学依据。

数值算例（通信量）。N = 20 的编队任务：全连接每步有向消息 20×19 = 380 条，k 近邻（k = 4）只需 20×4 = 80 条，约为前者的 21%；N 增到 100 时两个数字变为 9900 与 400，倍数从 4.75 扩到 24.75（数值经程序核对）。压缩的是每步消息数；信息覆盖方面，两层 GNN 的感受野约为 2 跳，k = 4 时 2 跳内可达邻居的上界为 4 + 4×3 = 16 个，当协作依赖更远的队友时需要增加层数（并承担过平滑风险）或引入全局状态通道。

3. 对手建模：行为预测与类型推断

对手建模把其他主体的行为当作预测目标。两类主流形式：

  • 行为预测：给定对手的历史轨迹 τj = (oj1, …, ojt)，预测下一步动作分布 p(ajt+1 | τj)。用交叉熵或对数似然训练，输出直接供自身策略或 critic 使用。
  • 类型推断：假设对手属于有限风格类型（激进、保守等），用潜变量 zj 表示类型，通过变分推断从轨迹估计后验 p(zj | τj)。相比动作预测，类型推断更能捕捉长期一致的风格。

对手模型在训练中作为辅助任务与主任务联合优化：L = LRL + λopp · Lopp。辅助损失权重 λopp 过大会让共享编码器偏向可预测性而牺牲决策质量，常见取值范围 0.05 到 0.2。

4. 心智理论层级与递归推理

心智理论（Theory of Mind）把"我对你的建模"分级：0 级假设对手策略固定，1 级对 0 级对手求最优响应，2 级假设对手在对自己做 1 级推理，如此递归。每增加一级，计算与样本代价显著上升，而收益随级别增加快速衰减，实践中 1 到 2 级已覆盖多数交互。互相建模还引入梯度耦合问题：双方同时沿着"欺骗对方的梯度"更新，可能共同发散。对抗训练中的振荡与梯度交互项正是这一现象的表现，稳健做法是交错更新或对交互项做截断。

5. 联合训练与评估

图通信与对手模型可以组合进同一策略网络：图消息传递提供聚合后的邻居信息，对手模型提供行为预测，两者拼接进入决策头。评估时需要分离两类收益：通信消融（断开图消息）验证图结构的贡献，预测准确率与回报的联合曲线验证对手模型的贡献。只报告回报无法区分"图通信提升了协作"与"对手模型教会了策略保守避让"。

实现思路与设计

组合模块的数据流分四步：

  1. 构图：从当前观测计算距离矩阵，按 k 近邻构造邻接矩阵与边特征（相对位置、距离）。
  2. 消息传递：两层 GNN 沿边传播状态，得到每个智能体的邻域聚合表示。
  3. 对手预测：历史轨迹进入对手模型，输出其余智能体的动作分布，与图表示拼接。
  4. 联合损失：L = LRL + λopp · Lopp；监控图度数分布、过平滑程度与预测准确率。

与第 086 章的差异点：086 章的注意力在全体消息上做软选择，本章的图结构提供硬连接的先验骨架；两者可叠加，用图限制候选项、用注意力在图内加权。

设计决策：为什么图通信比全连接更值得默认启用？

全连接通信的参数量与通信量都随 N 平方增长，而大多任务的交互强度随距离快速衰减。图结构把"谁与谁相关"从网络内部学习的隐式知识变成结构化的显式输入，训练样本需求下降、可解释性上升。代价是需要先验定义边，边定义错误（例如 k 过小）会切断必要的信息通路，因此 k 的选择应通过消融确定。

关键代码与解读

片段 1：带边特征的图消息传递层

import torch
import torch.nn as nn

class GraphCommLayer(nn.Module):
    """单层图消息传递：邻接与边特征由外部构图流程提供。"""
    def __init__(self, node_dim=64, edge_dim=8, out_dim=64):
        super().__init__()
        self.msg = nn.Sequential(nn.Linear(2 * node_dim + edge_dim, out_dim), nn.ReLU())
        self.upd = nn.GRUCell(out_dim, out_dim)          # 聚合后更新节点状态

    def forward(self, h, adj, edge_feat):
        # h: (B, N, D)；adj: (B, N, N)；edge_feat: (B, N, N, E)
        b, n, d = h.shape
        hi = h.unsqueeze(2).expand(b, n, n, d)           # 接收者视角
        hj = h.unsqueeze(1).expand(b, n, n, d)           # 发送者视角
        m = self.msg(torch.cat([hi, hj, edge_feat], dim=-1)) * adj.unsqueeze(-1)
        # 按入度归一化：邻居多的节点不至于消息量级失控
        deg = adj.sum(dim=-1, keepdim=True).clamp(min=1.0)
        agg = m.sum(dim=2) / deg
        return self.upd(agg.reshape(b * n, -1), h.reshape(b * n, -1)).view(b, n, -1)

解读：（1）消息函数同时读入接收者状态、发送者状态与边特征，三者缺一不可：只有两者状态无法区分不同方向的同一条边，只有边特征则丢失身份信息。（2）乘以 adj 把非边位置的消息清零，这一步让同一份代码在稠密图上退化为全连接通信，便于消融对照。（3）按入度归一化避免高低度数节点的消息量级失衡；若要保留度数信息（度数本身可能是有意义的特征），可改用求和聚合并把度数拼入节点特征。（4）GRUCell 逐节点更新，位置无关，保证置换等变性。

片段 2：对手模型与辅助损失

import torch
import torch.nn as nn
import torch.nn.functional as F

class OpponentModel(nn.Module):
    """对手模型：编码其余智能体的观测轨迹，预测其下一步动作分布。"""
    def __init__(self, obs_dim=32, hidden_dim=64, n_actions=5):
        super().__init__()
        self.encoder = nn.LSTM(obs_dim, hidden_dim, batch_first=True)
        self.head = nn.Linear(hidden_dim, n_actions)

    def forward(self, traj):
        # traj: (B*N, T, obs_dim)，末时刻隐状态概括近期行为模式
        out, _ = self.encoder(traj)
        return self.head(out[:, -1])

def opponent_aux_loss(logits, labels, weight=0.1):
    """行为预测交叉熵作为辅助损失：与主任务共享编码器。"""
    # 权重过大时编码器优先服务"可预测"，牺牲"利于决策"的表达
    ce = F.cross_entropy(logits, labels, reduction="mean")
    return weight * ce, ce

解读：（1）预测只取末时刻隐状态，参数量与序列长度解耦；若对手模式变化快，可缩短预测时间窗提高灵敏度。（2）交叉熵的标签是实际动作，训练数据来自回放缓冲区中其他智能体的轨迹，不额外要求交互式查询。（3）函数返回（加权损失, 原始交叉熵）两项：原始值送入监控管道（第 082 章），加权值进入总损失；训练中若预测准确率停滞在随机水平，说明对手行为接近随机或轨迹特征不足。（4）共享编码器使图表示同时服务决策与预测，两任务的梯度在编码器处叠加，λopp 控制叠加比例。

常见坑

  • k 过小切断信息通路：协作必需的远距离队友被排除在邻域外，回报显著低于全连接。修复：扫描 k ∈ {2, 4, 6, 8} 找性能拐点，或改用距离阈值自适应。
  • GNN 层数过多过平滑：节点表示趋同，网络失去区分度。症状：层数增加但回报不升，节点表示的两两余弦相似度接近 1。修复：层数控制在 2 到 3 层。
  • 邻接矩阵未按批对齐：不同样本的邻接形状或顺序不一致，传播结果错位。修复：统一定义"节点序号即智能体序号"的约定并断言。
  • 对手模型辅助损失权重过大：编码器学到利于预测对手、不利于最优决策的表示，回报下降。修复：λopp 从 0.05 起步，按预测准确率平台位置调整。
  • 对手预测标签穿越情节边界：跨情节取"下一个动作"会引入 reset 后的无关样本。修复：标签构造时按情节切分，末时刻样本丢弃。

练习与思考

  1. 解释置换等变性：为什么节点更新函数不能使用节点编号作为输入特征？若强行加入编号嵌入，会破坏什么性质？★
    提示
    编号嵌入使输出依赖编号排列，模型无法从 5 智能体迁移到 20 智能体，且同一几何构型因编号不同得到不同决策。
  2. 将 k 从 4 增加到 N（全连接），预测通信量、回报与训练耗时的变化方向，并说明如何验证"冗余连接"假设。★★
    提示
    通信量升到 O(N²)，回报可能持平或下降，耗时上升。验证：统计注意力权重或边消息范数，若大多数边的消息范数接近零，说明连接冗余。
  3. 推导：两层 GNN 在环状拓扑（每个节点只连左右邻居）上的感受野是多少？要覆盖全体 N 个节点需要几层？★★
    提示
    每层扩展一跳，两层覆盖左右各两跳共 4 个邻居；覆盖 N 节点需约 N/2 层，忽略了过平滑约束后仍不现实，这正是引入长程机制（如全局状态）的原因。
  4. 设计对手建模实验：在混合合作竞争任务中比较（无对手模型）、（动作预测辅助）、（类型推断辅助）三种设置，报告回报与预测准确率的联合曲线。★★★
    提示
    类型推断用潜变量后验的分类准确率代理。注意区分收益来源：对手模型可能提升回报（更好响应）或仅提升可解释性（预测准但回报持平）。
  5. 把图通信与第 086 章的注意力叠加：图限制候选集、注意力在候选内加权；设计消融验证"先验拓扑"与"数据驱动选择"的互补性。★★★
    提示
    四组对照：全连接均值、全连接注意力、图均值、图注意力。观察 k = 2 时图加注意力的表现是否超过 k = 8 的全连接注意力，若超过则印证先验拓扑减少了搜索空间。

小结

  • 图通信把交互结构显式化：距离阈值、k 近邻、可见性三种邻接构造各有适配场景，通信量上界 O(N·k)。
  • GNN 消息传递由消息函数、置换不变聚合与更新函数组成；置换等变性保证参数可跨智能体数量泛化，层数受过平滑限制。
  • 对手建模分行为预测与类型推断两类，以辅助损失联合训练，权重需在预测质量与决策质量之间平衡。
  • 心智理论层级提供递归推理框架，级别越高代价越大，一至两级已足够覆盖常见交互。
  • 评估要分离图通信与对手模型的贡献，避免把两类收益混在一条回报曲线里。
  • 下一章进入机制设计序列：联盟形成，讨论合作博弈的特征函数、夏普利值与联盟稳定性。
