第 072 章：逆强化学习与CTDE结合

当奖励函数难以手工设计而专家行为可得时，用逆强化学习（Inverse Reinforcement Learning, IRL）从示范中恢复奖励：本章先讲最大熵 IRL 与对抗式方法的目标函数，再讲集中式判别器与信用分配的结合点与实验设计。

  • 主题：奖励恢复 / 最大熵与对抗训练
  • 关键公式：minπmaxD Eπ[log(1−D)] + EE[log D]
  • 预计学时：65 分钟
  • 前置章节：第 071 章

学习目标

  • 理解逆强化学习的问题设定与病态性来源，说明"多种奖励解释同一示范"的含义。
  • 掌握最大熵 IRL 的约束优化形式与特征匹配条件，能写出指数族分布形式的轨迹概率。
  • 掌握生成对抗式模仿学习（Generative Adversarial Imitation Learning, GAIL）的极小极大目标，理解判别器输出如何转换为奖励。
  • 能设计集中式判别器与团队奖励恢复流程，用势函数塑形把恢复奖励分配到集中式价值估计中。
  • 能设计结合实验：判别器的信息边界消融、奖励共享与个体奖励的对照、与手工奖励基线的比较。

背景与动机

强化学习依赖奖励函数，而协作任务的奖励设计常需反复试错：全局奖励容易忽视局部贡献，局部奖励容易诱使智能体钻空子。逆强化学习走反方向：假设示范来自某个最优策略，从行为反推最能解释该行为的奖励。问题天生欠定：任何与示范轨迹序一致的奖励函数都能解释同一份示范，需要引入正则（最大熵）来挑选唯一解。

多智能体场景带来两个新问题：示范是联合行为的产物，单机 IRL 无法区分"某智能体贡献好"与"队友配合好"；交互非平稳使传统 IRL 的马尔可夫假设在个体视角下不成立。CTDE 恰好提供解法：训练期用全局状态训练判别器区分联合轨迹，恢复出的团队奖励由评论家统一评估，执行期策略仍只依赖本地观测。

核心原理

本节先讲 IRL 的目标与两种求解路线，再讲与 CTDE 的三个结合点。

1. 问题设定与病态性

给定专家轨迹 E 与特征映射 φ(τ)（轨迹的统计特征，例如访问频次、终态位置），IRL 寻找奖励 r 使得专家策略在 r 下最优。若奖励只用线性特征 r(τ) = wTφ(τ)，则可定义特征期望匹配条件。约束太弱时解不唯一：所有 w 正比例的奖励给出相同的策略排序，全部常量奖励也满足"专家最优"。最大熵正则是标准解法：在满足特征匹配的策略集合中取熵最大者。

maxπ H(π) s.t. Eπ[φ(τ)] = EE[φ(τ)] 对偶形式给出 p(τ) ∝ exp(wTφ(τ))：奖励越高轨迹概率越大，熵正则防止退化解

2. 对抗式求解：GAIL

最大熵 IRL 的配分函数需要对全部轨迹求和，深层网络下不可行。对抗式方法用判别器替代似然：判别器区分策略轨迹与专家轨迹，策略则最大化被判为专家的概率。

minθ maxψ E(s,a)~πθ[log(1 − Dψ(s,a))] + E(s,a)~E[log Dψ(s,a)] Dψ 高表示样本像专家；其对数比值形式与最大熵奖励的关系可由最优判别器代回目标推出

训练中把判别器输出转换为奖励信号 r(s, a) = −log(1 − D(s, a))（D 越高代表样本越像专家），环境不再提供手工奖励，策略在"像专家"的引导下优化。判别器过强时梯度饱和，策略学习停滞，需要限制其更新频率或对输入加入噪声。

3. 与 CTDE 的结合点

第一，判别器输入取全局状态与联合动作 (s, a1:N)，训练期集中判别，判别信号携带协作结构。第二，恢复奖励作为团队奖励进入 CTDE 的回报计算，评论家照常做信用分解（可用反事实基线辅助）。第三，样本级奖励塑形用势函数变换 r′(s, a) = r(s, a) + γΦ(s′) − Φ(s)，势函数塑形保持最优策略集合不变，可把集中式判别的密集奖励安全地转换为局部形式，供分散执行的价值更新使用。

4. 求解方式与数据要求

判别器与策略交替更新，每轮策略采样若干轨迹、判别器做若干梯度步。示范数据规模按特征覆盖度衡量，回合数不是主要指标：需要覆盖协作行为的主要模态（不同的配合方式），否则恢复奖励偏向示范中高频出现的单一模式。

5. 数值算例：特征匹配与判别奖励尺度

设一个两状态任务，特征取"访问状态 B 的频率"。专家轨迹的 B 访问频率为 0.8，初始策略为 0.5，特征差为 0.3。线性对偶解的权重方向为正，含义是专家在状态 B 的访问显著多于策略，奖励应给状态 B 正向增量。随着策略对 B 的访问概率上升，特征差缩小，权重更新幅度受正则项约束自动减小，避免特征差接近零时的数值爆炸。

判别奖励尺度算例。判别器输出 D=0.5 时样本奖励 −log(0.5)=0.693；D=0.9 时 2.303；D=0.99 时 4.605。样本被判"像专家"时 D 趋近 1，奖励快速上升并在截断处封顶约 13.8；被判"不像"时 D 趋近 0，奖励趋近 0。截断 1e-6 后单样本奖励上限约 13.8，这是对数变换的自然量程。

配分函数的困难。最大熵分布 p(τ)∝exp(wTφ(τ)) 的归一化需要对全部轨迹求和，轨迹数随回合长度指数增长，直接计算不可行。对抗式方法用判别器绕开配分函数，代价是训练动态从凸优化变为博弈，收敛性依赖两方更新的平衡条件。

势函数不变性推导要点。任一策略下的塑形回报差 γΦ(s′)−Φ(s) 沿轨迹做望远镜求和，期望等于 γ 倍边界项与初始势之差，与策略的中间行为无关，因此最优策略集合保持不变；把 Φ 取为停止梯度的价值估计即可安全使用。

解读：上述数值共同刻画出恢复奖励的工程形态：线性特征给出可解释的权重方向，判别器把方向搜索交给网络，对数变换把置信度映射为量程可控的奖励。复现时可把特征层面的快速原型与判别器的深层版本串成流水线，先用前者确认特征设计可分辨，再用后者扩大表达力。

实现思路与设计

结构为"集中式判别器加分布式策略加团队评论家"三件套：判别器训练期可用全局信息，策略与评论家网络与常规 CTDE 一致。

实验设计

  1. 对比基线：手工奖励的 CTDE、行为克隆、单机 GAIL（每个智能体独立判别）。
  2. 消融设置：判别器输入去掉全局状态、去掉势函数塑形、判别器更新比取 1 与 8、示范模态减半。
  3. 评价指标：与专家轨迹的占用度量距离（状态访问分布的发散度）、隐藏真实奖励下的回报、协作条款达成率（如同时到位）。
  4. 统计方式：判别器随机初始化影响较大，每配置至少 5 种子并报告分位数。
设计决策：为什么要把判别奖励经势函数塑形后再使用

判别奖励是密集的样本级信号但方差较高，直接回传到分散执行的价值网络会让评价抖动。势函数塑形把奖励分解为"即时项加状态势差"，状态势由集中式评论家统一估计，样本级噪声被平均进价值函数，同时保持策略不变性。塑形势取评论家的价值输出是最常见的实现，需要停止梯度以保证势函数不参与策略目标的二次优化。

与第 071 章的差异：上一章直接监督动作分布，本章恢复奖励并通过强化学习间接优化；示范利用率从"逐样本监督"变为"分布级判别"。

对比分析：四类奖励来源的对照

来源信号密度任务一致性钻空子风险数据要求
手工奖励视设计高（设计正确时）中（塑形偏差）无

选择依据是可用数据形态与对奖励可解释性的要求：只有轨迹没有状态动作对时从 IRL 起步；需要可检查的奖励表达式时用特征线性形式；追求策略质量且接受训练不稳定性时用对抗式。三类可以组合：先用线性 IRL 得到特征方向，再用判别器细调局部行为，最后用势函数塑形把密集信号压稳。

对抗训练平衡的量化参照：判别准确率稳定在 0.6 到 0.8 之间时策略获得的梯度最有效；超过 0.9 后奖励饱和，回报曲线走平。监控判别准确率并在超阈值时降低判别器学习率或更新频率，是把对抗训练维持在工作区间的常规操作。

关键代码与解读

片段 1：线性特征匹配的奖励求解

import numpy as np

def maxent_feature_matching(feat_expert, feat_policy, reg=1e-3):
    """最大熵 IRL 的线性对偶：求解特征匹配的奖励权重。
    feat_expert/feat_policy: 专家与策略的特征期望向量。
    """
    # 对偶问题是凸的：最小化熵正则下的特征差
    diff = feat_expert - feat_policy
    # 岭回归式闭式解：正则项保证权重有界
    w = diff / (np.linalg.norm(diff) * np.linalg.norm(diff) + reg)
    cost = -float(feat_expert @ w)          # 专家成本：越小越接近最优
    return w, cost

解读：线性 IRL 的闭式解出现在特征匹配梯度为零处，正则项防止特征差接近零时的数值爆炸。权重方向即"专家做得多而策略做得少"的特征方向，判别器的深层版本把这个方向搜索交给网络表达。该片段适合作为教学与快速原型，表达能力受特征设计限制。

片段 2：判别器更新与奖励转换

import torch
import torch.nn as nn

def gan_reward(d_out):
    """把判别器输出转换为奖励：r = -log(1 - D)。
    d_out: 判别器对样本的标量输出（已过 sigmoid）。
    """
    # 截断避免 log(0)：判别器过早确信时仍保留有限梯度
    d = torch.clamp(d_out, 1e-6, 1 - 1e-6)
    return -torch.log(1.0 - d)

def discriminator_loss(d_expert, d_policy, gp=None):
    """对抗损失：专家判真、策略判假，可选梯度惩罚。"""
    loss = -torch.log(d_expert.clamp(1e-6, 1 - 1e-6)).mean()
    loss = loss - torch.log(1.0 - d_policy.clamp(1e-6, 1 - 1e-6)).mean()
    if gp is not None:                    # WGAN 风格 Lipschitz 正则
        loss = loss + 10.0 * gp
    return loss

解读：奖励转换取"样本像专家"的程度，判别器越确信样本来自专家，奖励越大；策略样本的奖励趋近零，两者之差形成朝专家分布靠拢的梯度。截断让判别器饱和后仍保留少量信号。梯度惩罚约束判别器的变化率，是多智能体高维状态空间下稳定对抗训练的关键；没有它时判别器容易在数十次更新内输出接近 0 或 1 的硬判决。

片段 3：势函数塑形与数值稳定

import torch

def potential_shaping(reward, v_s, v_next, gamma=0.98, scale=0.3):
    """势函数塑形：r' = r + gamma*Phi(s') - Phi(s)，Phi 取价值估计。
    v_s/v_next: 当前与下一状态的集中式价值（保持常数即可）。
    """
    with torch.no_grad():                 # 势函数不参与梯度回传
        shaped = reward + gamma * v_next - v_s
    # 按尺度混合：塑形项压缩方差，保留原始判别信号的方向
    return (1.0 - scale) * reward + scale * shaped

解读：no_grad 保证势函数只做奖励变换，避免价值网络被"自己制造的奖励"反复驱动。混合系数 scale 控制方差压缩强度：值越大，奖励越平滑但越依赖价值估计的准确性。价值未收敛时塑形项可能引入系统偏差，工程上在前若干万步取较小 scale，待价值稳定后提高。

常见坑

  • 判别器过强：两个策略步内判别准确率接近 1，策略奖励饱和无梯度。修复：降判别学习率、加梯度惩罚或谱归一化。
  • 示范模态单一：判别器把示范中偶然细节当特征，策略只学会复刻单一模式。修复：扩充示范覆盖、对判别器输入做时间抖动增强。
  • 奖励漂移：判别器持续更新使奖励函数非平稳，评论家追逐移动目标。修复：周期性冻结判别器再训练策略，交替节奏写在配置中。
  • 忽略执行期信息边界：判别器奖励使用了执行期不可得的全局量，部署后性能崩塌。修复：判别器与策略观测对齐审计，或仅用它塑造训练期信号。
  • 势函数带梯度：未停止梯度的塑形把价值估计卷入策略目标，出现反馈放大。修复：对势函数项显式停止梯度。

练习与思考

  1. 给出一个"三种奖励解释同一示范"的小例子（两状态两动作即可），说明最大熵正则如何打破不唯一性。★
    提示
    任何正比例缩放的奖励、加上常量偏移的奖励都保持动作排序；最大熵在匹配约束下取熵最大策略对应唯一权重方向。
  2. 把判别器输入从全局状态改为局部观测，预测恢复奖励的结构变化与协作指标的变化。★★
    提示
    局部判别无法感知队友贡献，恢复奖励偏向个体行为特征，同时到位的协作条款达成率下降。
  3. 推导：由最优判别器 D*(s,a) = pE/(pE+pπ)，论证 r = −log(1−D*) 与最大熵奖励在轨迹分布意义下等价。★★★
    提示
    把 D* 代入判别目标，极小极大值退化为两分布 JS 散度的负值；奖励差等于对数密度比。
  4. 设计实验：判别器更新比取 1 与 8 两档，观察判别准确率、策略回报与协作条款达成率三组曲线，解释差别的机制。★★★
    提示
    更新比 8 时判别器收敛过快、奖励饱和，回报曲线早停；更新比 1 时判别信号弱、学习慢但稳定，需在两者间找折中。
  5. 判别器输出取 0.5、0.9、0.99 三个值，计算 r=−log(1−D) 的数值，说明奖励量程为何可控，以及 D 接近 1 时梯度为何需要截断。★★
    提示
    三个值对应 0.693、2.303、4.605；对数变换把 D 向 1 的指数级接近映射为线性增长的奖励。D 达到 1−1e-6 时奖励约 13.8，若不截断，浮点精度会使对数溢出或产生极端梯度。

小结

  • 逆强化学习从示范反推奖励，问题欠定，最大熵正则在特征匹配集合中挑出唯一解。
  • GAIL 用判别器替代似然计算，判别器输出经对数变换得到密集奖励，对抗平衡是训练成败的关键。
  • CTDE 的结合方式是集中式判别、团队奖励与势函数塑形：判别捕捉协作结构，塑形压方差并保持策略不变性。
  • 实验设计需覆盖判别器信息边界与更新节奏两类消融，指标兼顾分布距离与真实回报。
  • 数值算例给出奖励量程与对抗平衡区间的参照：对数变换下单样本奖励介于 0 到约 13.8，判别准确率维持在 0.6 到 0.8 时训练最稳。
