第一篇 · CTDE 基础与核心算法

第 023 章：经验回放在CTDE中的改进

本章讲多智能体经验回放（Experience Replay）的组织与改进：联合过渡数据的存储结构、优先经验回放（Prioritized Experience Replay, PER）的优先级设计、重要性采样（Importance Sampling, IS）修正，以及策略非平稳性带来的数据新鲜度管理。

  • 主题：数据管线 / 优先回放与偏差修正
  • 关键公式：P(i) ∝ (|δi| + ε)α；wi = (N·P(i))−β
  • 预计学时：55 分钟
  • 前置章节：第 022 章 课程学习在CTDE中的应用

学习目标

  • 理解多智能体回放池与单智能体回放池的结构差异：联合过渡的组织粒度、状态与观测的双通道存储。
  • 掌握优先经验回放的采样分布与重要性采样修正的数学形式，能推导无偏性修正因子的来源。
  • 理解多智能体环境下优先级来源的选择：团队时序差分误差与个体误差聚合的权衡。
  • 理解策略非平稳性对回放数据的影响，掌握缓冲期、数据新鲜度衰减两类管理手段。
  • 能实现回合式缓冲区与优先采样，并诊断优先级偏移、隐状态断裂两类典型故障。

背景与动机

回放机制把历史过渡数据重复利用，显著提高样本效率，是离策略（Off-Policy）多智能体算法的基础组件。多智能体场景给回放带来两个单智能体不存在的问题。

第一是数据结构问题：一条联合过渡包含多个智能体的观测、动作与个体奖励，集中式评论家（Critic）还需要全局状态与可行动作掩码等字段，字段的组织粒度直接决定采样代码的复杂度。第二是分布问题：队友策略持续更新使回放池中的数据由"当时策略"与"当前策略"混合产生，过时程度不同的数据在更新中携带不同的偏差；训练早期数据过少时过早启动训练又会放大这种偏差。本章讨论这两类问题的工程与原理改进，为后续值分解、策略梯度系列算法提供统一的数据层。

核心原理

1. 联合过渡的组织粒度

多智能体回放的存储单元由"单步单智能体"升级为"单步联合过渡"。一条联合过渡至少需要以下字段：各智能体的当前观测 oi,t、下一观测 oi,t+1、动作 ai,t、个体奖励 ri,t 与团队奖励 rt，集中式模块所需的全局状态 st、st+1，以及可行动作掩码（第 028 章展开）和回合结束标志。

存储粒度有两种方案：按智能体存储为每个智能体维护一条记录，共享同一时间戳，采样时按时间索引拼装；按时间步存储把一条联合过渡作为一个单元整体存放。前者便于按智能体过滤与重加权，后者保证所有智能体看到的时序切片严格一致。工程实践倾向后者加一层智能体维度的切分接口，兼顾一致性与灵活性。

部分可观测场景还有一条容易遗漏的规则：目标值计算使用的是下一时刻的观测历史，所以当前观测与下一观测都必须完整保存；只保留最新观测的做法让时序差分目标退化为错误的值估计。使用循环网络（Recurrent Network）时，回放通常以完整回放回合为单位存储与采样，保证隐状态（Hidden State）从回合起点顺序展开的条件成立。

内存账本同样值得先算清楚。一条联合过渡的浮点字段量为 2N·do + 2ds + N + 1 + N（观测、下一观测、状态、下一状态、动作、团队奖励与个体奖励），掩码按布尔量存储。代入 N = 6、观测维度 32、状态维度 64：单步约 525 个浮点数，按 float32 计约 2.1 KB，池容量 105 步时占用约 210 MB。容量翻倍会让内存与全量优先级刷新成本同步翻倍，同时按 3.2% 的单批覆盖比把新鲜数据占比压低，扩容量这个动作在两个方向上都有账要记。按回合整体入池还有一项实现成本：变长回合让批次张量的形状依赖采样结果，需要用掩码或按长度分桶处理，否则批次的有效利用率随回合长度方差下降。

2. 优先经验回放与重要性采样修正

均匀采样对所有数据一视同仁，稀疏奖励下真正具备学习价值的过渡（携带非零时序差分误差）被采到的概率极低。优先经验回放把采样概率与误差信号挂钩：

P(i) = piα / Σk pkα，其中 pi = |δi| + ε δi 为过渡 i 的时序差分误差，ε 保证零误差数据仍可被采到，α 控制优先级强度

α = 0 退化为均匀采样，α = 1 完全按误差比例采样。非均匀采样改变了参数更新的期望：以概率 P(i) 取样的样本在损失中的名义边际贡献被放大 1/(N·P(i)) 倍，因此需要重要性采样权重抵消：

wi = (N · P(i))−β / maxj wj β 从 0.4 线性退火到 1.0；β = 1 时加权更新在期望意义上无偏，归一化因子只缩小整体学习率

推导要点：期望 Ei~U[fi] = Σ (1/N) fi 在优先采样下变为 Σ P(i) fi，乘上 wi = 1/(N·P(i)) 后每个样本的贡献回到 1/N，求和恢复原始期望。β < 1 的折中在训练早期引入受控偏差以降低方差，是工程上更稳的选择。

数值算例：优先级指数与重要性采样权重的尺度

先看 α 对采样分布的控制。取三条误差为 |δ| = (0.1, 1, 10)（ε 取 10−5 可忽略），α = 0.6 时归一化采样概率为 (0.048, 0.191, 0.761)，α = 1.0 时变为 (0.009, 0.090, 0.901)。误差最大项的概率份额从 76% 抬到 90%，中等误差项从 19% 压到 9%：α 越大，抽样越集中到少数高误差过渡上，这就是"α = 1 过度聚焦易过拟合"的算术形态。α = 0.6 保留了对中等误差项的采样，梯度覆盖更均衡。

再看 β 对权重的压缩。设回放池 N = 4，采样概率 P = (0.5, 0.3, 0.15, 0.05)，计算 wi = (N·Pi)−β。β = 1 时权重为 (0.5, 0.833, 1.667, 5.0)，最大值与最小值之比为 10；β = 0.4 时权重为 (0.758, 0.930, 1.227, 1.904)，比值降到 2.51。归一化（除以最大权重）后，β = 0.4 的权重落在 (0.398, 1.0]，β = 1 的权重落在 (0.1, 1.0]，最低权重相差约 4 倍。期望核对：Σ Pi·wi = Σ (1/N) = 1，β = 1 时加权更新恢复无偏。两个读数可以进入日志：当前采样分布的最大概率项（监控 α 的集中度）与当前权重最大最小比（监控 β 退火的进程），比只记录参数值更接近梯度的实际形态。退火进入末期时权重比值应收敛到 2 以内，若仍高于 5 说明 α 过大或退火步数设置不足，需要回到配置层修正。

3. 多智能体优先级来源的取舍

优先回放需要一个标量误差信号，多智能体环境里它有三个可选来源：

  • 团队时序差分误差。用混合后的团队值与团队回报计算。整个联合过渡获得同一个优先级，实现最简单，且与共享回报的结构相容。
  • 个体误差聚合。各智能体分别计算 δi，取最大值或均值作为过渡优先级。最大值会优先采样分歧较大的个别智能体，均值让整体分歧主导。
  • 混合来源。团队误差定基础优先级，个体误差的方差作为修正项，兼顾整体价值修正与个体行为修正。

选择依据在于算法结构：共享团队评论家的算法（VDN、QMIX 一类）天然给出团队误差；带有独立个体评论家的算法（COMA、MAPPO 一类）可先聚合个体误差再回写。需要注意，优先级只影响采样顺序与修正权重，不参与梯度本身的构造，因此不会破坏值分解的单调性等结构性约束，这是它可以在各类算法间通用移植的原因。

4. 非平稳性与数据新鲜度

队友策略更新使同一个联合过渡的时序差分误差随时间漂移，旧策略产生的数据在更新中的价值持续衰减。三类管理手段：

  • 容量限制。回放池容量按环境步数设置，旧数据被自动挤出，天然形成时间窗口。典型容量 5×104 到 106 步。
  • 缓冲期。开局先收集若干回合数据再启动优化器，避免用少量高度相关的数据反复更新。典型缓冲期为池容量的 5% 到 10%。
  • 优先级重算。周期性对池中数据重新计算 δ 并刷新优先级，让"曾经重要但现已学会"的数据降权。刷新间隔与环境步数的比例通常取 1 比 1000 量级。

三者共同刻画一个概念：回放池的有效信息量由数据数量与数据新鲜度的乘积决定，单纯增大容量会稀释新鲜数据的采样占比。

数值算例：容量、缓冲期与刷新开销的账本

把设计表的默认值代进具体任务核对一遍。设池容量 105 环境步、回合长度 100 步，池满时约存 1000 个回合；缓冲期取容量的 5% 至 10%，即 5000 到 10000 步、50 到 100 个回合，训练启动时首批样本可跨几十个回合，相关性已经很低。批次按 32 个回合对齐时，单批覆盖 3200 步，约占池容量的 3.2%，新鲜数据的占比与这个比例同阶。优先级刷新有两种粒度：全量刷新一次要对 105 步数据做约 105/32 ≈ 3125 个批次的前向计算，是单批采样的 3125 倍开销；只刷新本次采样的批次则开销可以忽略，代价是池中其余数据的优先级停留在写入时刻。默认配置取折中：每 1000 环境步做一次采样批次级的回写，每若干个刷新周期穿插一次全量重算。

优先级来源信号语义实现成本典型失效模式
团队时序差分误差整体价值修正的紧迫程度低，与共享评论家天然兼容个别智能体的大分歧被平均，局部行为修正被拖延
个体误差聚合（均值）全体个体误差的平均修正需求中，需要逐智能体目标分歧集中时优先级被稀释
个体误差聚合（最大值）最需要复习的个体中个别异常样本长期占用采样头部
混合来源整体修正为主、个体分歧为辅较高，需要两套误差两项量纲不匹配时修正项失去作用

实现思路与设计

缓冲区按"回合式存储，联合粒度采样，优先级回写"三条原则设计，接口与 PyMARL 的内存缓冲区习惯保持一致：以回合为单位积累，池满后开始训练，采样时抽取完整回合再切出训练窗口。

参数默认值作用取值依据
池容量5×104 至 2×105 步控制数据时间窗口任务回合长度越长、非平稳越强，容量取小让数据更新鲜

关键代码与解读

片段 1：回合式联合过渡缓冲区

import numpy as np

class EpisodeBuffer:
    """按回合积累、按回合采样的联合过渡缓冲区（接口参照 PyMARL 习惯）。"""
    def __init__(self, capacity_steps, n_agents, obs_dim, state_dim):
        self.capacity = capacity_steps
        self.episodes = []                 # 已完成回合列表，元素为字段字典
        self.current = {"obs": [], "obs_next": [], "actions": [],
                        "reward": [], "state": [], "state_next": [], "done": []}

    def push_step(self, obs, obs_next, actions, reward, state, state_next, done):
        # 存入本步全部字段；obs_next 必须显式保存，目标值计算要用它
        self.current["obs"].append(np.asarray(obs, dtype=np.float32))
        self.current["obs_next"].append(np.asarray(obs_next, dtype=np.float32))
        self.current["actions"].append(np.asarray(actions, dtype=np.int64))
        self.current["reward"].append(float(reward))
        self.current["state"].append(np.asarray(state, dtype=np.float32))
        self.current["state_next"].append(np.asarray(state_next, dtype=np.float32))
        self.current["done"].append(bool(done))
        if done:
            self._close_episode()

    def _close_episode(self):
        # 回合终止才整段入池：循环网络回放需要按时间顺序展开隐状态
        self.episodes.append(self.current)
        self.current = {k: [] for k in self.current}
        while sum(len(e["reward"]) for e in self.episodes) > self.capacity:
            self.episodes.pop(0)           # 超容后从最旧回合开始淘汰

解读：回合式积累解决了循环网络回放与部分可观测采样的一致性，代价是采样代码需要处理变长序列。字段命名与 PyMARL 的 episode 字典保持同构，便于与既有算法实现对接。obs_next 单独存放，保证采样窗口的最后一步也有正确的目标观测，若靠相邻步推导，窗口截断处会丢失目标信息。超容淘汰从最旧回合开始，与数据新鲜度的时间窗口语义一致。capacity_steps 以环境步计量，容量行为与任务回合长度解耦。

片段 2：优先采样与重要性采样权重

class PrioritizedSampler:
    """按 |delta|^alpha 采样，返回重要性采样权重用于损失加权。"""
    def __init__(self, alpha=0.6, beta_start=0.4, beta_end=1.0, anneal_steps=2_000_000):
        self.alpha, self.beta_start, self.beta_end = alpha, beta_start, beta_end
        self.anneal_steps = anneal_steps

    def probabilities(self, deltas):
        # p = |delta| + 1e-5：零误差数据保底概率，避免永远无法被复习
        p = (np.abs(deltas) + 1e-5) ** self.alpha
        return p / p.sum()

    def sample(self, deltas, batch_size, step):
        prob = self.probabilities(deltas)
        idx = np.random.choice(len(prob), batch_size, p=prob)
        # beta 线性退火：早期降方差，后期恢复无偏更新
        beta = min(self.beta_end, self.beta_start +
                   (self.beta_end - self.beta_start) * step / self.anneal_steps)
        weights = (len(prob) * prob[idx]) ** (-beta)
        weights /= weights.max()           # 归一化只缩放等效学习率
        return idx, weights.astype(np.float32)

解读：采样与权重计算分离，使得优先级回写可以独立于采样实现。线性退火用环境步数与预设总步数之比推进，目标步数从任务规模估计（典型 2×106 步量级）。权重除以最大值进行归一化，避免权重进入损失后把有效学习率整体抬高；这一步在实现中经常被省略，导致调参结果难以迁移。概率数组按全池误差构建，池容量在 105 步量级时单次构建的代价仍可接受。

片段 3：时序差分误差回写与优先级刷新

import torch

def update_priorities(buffer, sampler, batch_idx, batch, learner, gamma=0.99):
    """用当前网络重算批次误差并回写优先级；周期调用保持全池优先级可信。"""
    with torch.no_grad():                  # 优先级回写属于数据侧操作，不进入计算图
        q_taken = learner.q_values(batch)                      # 当前值估计
        q_next = learner.target_max(batch["obs_next"])         # 目标值估计
        target = batch["reward"].unsqueeze(-1) + gamma * q_next * (1 - batch["done"].unsqueeze(-1))
        deltas = (target - q_taken).abs().mean(dim=-1)         # 按智能体维聚合
    for k, d in zip(batch_idx, deltas.cpu().numpy()):
        # 回写绝对误差，作为下一次优先采样依据；epsilon 已在采样端保底
        buffer.priority[k] = float(d)

解读：no_grad 上下文保证回写不污染梯度计算图，这在将回写逻辑嵌入训练循环时极易被忽略。个体误差沿智能体维取均值聚合为联合过渡的优先级，与共享团队评论家的结构相容；若算法使用独立评论家，把 mean 换成 max 更符合"优先复习分歧最大的个体"的意图。刷新频率按表所示每 1000 环境步触发一次，在池规模较大时也可以只刷新本次采样的批次，两种粒度分别对应全量精确与抽样近似的取舍。

常见坑

  • 只存储当前观测。部分可观测下用当前观测近似下一观测，时序差分目标系统性错误，表现为价值估计持续偏高。症状是评论家损失下降而回报不上升。修复：把 ot+1 作为独立字段存储。
  • 按过渡采样但用循环网络。时间窗口从回合中间随机截断，隐状态展开条件不成立。症状是训练损失剧烈波动且随回合长度加剧。修复：以完整回合为采样单元，训练窗口在回合内部顺序切分。
  • β 固定在 0.4。训练末期持续使用有偏更新，收敛到与均匀版本不同的解。修复：按环境步数线性退火到 1.0，并在日志中记录当前 β 值。
  • 优先级与课程阶段脱节。阶段切换后旧任务的高误差数据长期占据采样头部，新任务的学习被拖慢。修复：切换时对旧阶段数据整体降权或分区管理。
  • 容量盲目调大。池容量是新鲜数据占比的反向参数，过大时多数批次由陈旧策略数据构成，非平稳性偏差上升。修复：先按回合长度与任务切换频率选容量，再根据训练曲线微调。

练习与思考

  1. 推导：证明当 β = 1 且权重按 wi = 1/(N·P(i)) 计算时，加权损失的期望与均匀采样下的期望相等，并说明归一化因子 maxj wj 的作用。★
    提示
    把期望写成关于 P 的求和，代入 wi·P(i) = 1/N，逐项回收到均匀期望；归一化把所有权重压入 (0,1] 区间，等效于缩放学习率。
  2. 改参数预测：把 α 从 0.6 调到 1.0 且 β 保持 0.4，预测训练前 10 万环境步内优先级分布的集中程度与回报曲线变化。★
    提示
    优先级将集中在少数高误差过渡上，采样分布的熵下降；回报曲线早期上升更快但中期更易出现过拟合式的平台。
  3. 设计：为一个 3 智能体、回合长度 100 步的任务选择池容量与缓冲期，写出推算过程，并说明若对手策略每 2 万步更新一次，容量应如何调整。★★
    提示
    容量至少覆盖一个课程阶段内的多个完整回合；对手更新快意味着数据半衰期短，容量取小并提高优先级刷新频率。
  4. 实验设计：在值分解算法上比较均匀回放、优先回放无修正、优先回放加重要性采样修正三种设置，指标使用达到固定回报所需环境步数与种子间方差。★★★
    提示
    无修正版本用同一批种子对比；预期其均值提升但方差显著增大，重要性采样修正的主要收益体现在方差控制上，均值提升幅度有限。

小结

  • 多智能体回放的存储单元是联合过渡，需同时保存当前与下一观测、全局状态、掩码与完成标志；循环网络场景按完整回合采样。
  • 优先回放按 |δ|α 采样，重要性采样权重 (N·P(i))−β 恢复期望；β 从 0.4 退火到 1.0 平衡偏差与方差。
  • 优先级来源有三类：团队误差、个体误差聚合、混合来源；选择与算法是共享评论家还是独立评论家对应。
  • 非平稳性通过容量窗口、缓冲期、优先级周期刷新三件套管理，容量是数据新鲜度的反向参数。
  • 下一页转向目标网络：回放数据与自举结合会放大估计偏差，目标网络如何构造稳定的目标值。
