第 012 章：MAPPO近端策略优化

同策略路线的核心配方：近端策略优化（Proximal Policy Optimization, PPO）的裁剪代理目标配上集中式价值函数，执行期每个智能体只用自己的观测历史。MAPPO（Multi-Agent PPO）是这套组合在实践中广泛复现的名字，本章讲清裁剪机制的信任域含义、泛化优势估计的计算，以及多智能体工程配方。

  • 主题：同策略算法 / 裁剪代理目标
  • 关键公式：LCLIP(θ) = 𝔼[ min( rt(θ) Ât, clip( rt(θ), 1−ε, 1+ε ) Ât ) ]
  • 预计学时：55 分钟
  • 前置章节：第 011 章

学习目标

  • 理解 PPO 裁剪代理目标的动机：用比率截断近似信任域，控制单次策略更新幅度。
  • 掌握集中式价值函数与泛化优势估计（Generalized Advantage Estimation, GAE）在多智能体数据上的计算，包括终止截断的正确处理。
  • 掌握 MAPPO 的关键工程配方：共享演员与标识、输入归一化、旧策略占比固定、多轮小批更新与熵系数。
  • 会实现回合批次的采集缓冲、GAE 计算与非策略比率更新，接口与第 003 章骨架保持一致。
  • 能对比同策略与离策略两条路线的样本效率、稳定性与适用任务，设计 MAPPO 的调参敏感性实验。

背景与动机

第 009 至 011 章都是离策略路线：反事实基线、确定性演员加集中式评论家、双评论家修正高估。离策略方法样本效率高，但对超参与目标网络的同步节奏敏感。另一条路线回到同策略的基本盘：每批数据采集后立刻更新、用后即弃，稳定性由算法结构与更新纪律提供。近端策略优化（Proximal Policy Optimization, PPO）是这条路线上的标准工具，它以裁剪代理目标近似"策略更新不能离旧策略太远"的信任域约束，实现简单、超参稳健。

MAPPO 的构成是"PPO 加集中式价值函数"：训练期价值函数读取全局状态，执行期每个智能体只依赖自己的观测历史；优势函数用泛化优势估计计算，优势权重把集中信息带入每个智能体的比例项。多智能体实践还沉淀了一组工程配方：演员参数共享加标识嵌入、观测与状态的分别归一化、旧比率一次性锁定、回合批次多轮小批更新。这些配方与第 004、005 章的知识直接衔接，是本章的实现重心。

核心原理

本节给出裁剪代理目标的推导直觉、GAE 的递归计算、多智能体适配与两条路线的对照。

1. 裁剪代理目标与信任域

同策略策略梯度要求"梯度以当前策略的数据估计"，重复使用旧数据会引入偏差。重要性比率纠正偏差，但比率过大会放大方差与步长。PPO 的代理目标把比率截断在 [1−ε, 1+ε]：

rt(θ) = πθ(at | τt) / πθold(at | τt)， LCLIP = 𝔼t[ min( rt Ât, clip( rt, 1−ε, 1+ε ) Ât ) ] ε 取 0.1 至 0.2。直觉：Â 为正时爬升被 1+ε 封顶，Â 为负时下压被 1−ε 封底；更新的收益上限被锁在旧策略附近的一个邻域内，这正是信任域思想的可微近似

多智能体版本按智能体分别计算比率：每个智能体有自己的 πi 与 rt(i)，优势 Ât 来自集中式价值函数（同一批数据同一优势，作用于全部智能体）。比例项保证各智能体沿各自方向改进，优势项保证改进方向与团队回报对齐，两者分工与第 003 章的推导一致。

2. 泛化优势估计

优势的偏差方差权衡由泛化优势估计（Generalized Advantage Estimation, GAE）参数 λ 调节：

δt = rt + γ V(st+1) (1 − donet) − V(st)， Ât = δt + γλ Ât+1 λ = 0 退化为单步时序差分（低方差高偏差），λ = 1 退化为蒙特卡洛（高方差无偏）。λ 取 0.95 是常见折中；递归从回段末端向前累乘，done 处截断递归链

递归实现从时序末端反向遍历，天然与回合数据的存储布局（时间主序）契合。价值函数用同一批数据进行若干轮回归，目标取回报的分段估计 Ât + V(st) 或 λ 回报。价值目标与优势共享中间量，两处拼接必须一致，否则优势与价值互相矛盾，训练表现为价值损失异常上升而策略无改进。

3. 多智能体工程配方

以下四点在离散与连续任务上反复被复现，逐条给出依据：

  • 共享演员加标识。同构智能体共享参数放大有效样本量（第 004 章的梯度之和论证）；标识嵌入保留角色差异。
  • 观测与状态分别归一化。执行侧只能使用训练侧冻结的统计量或固定边界；集中侧统计可来自更大范围，两者混用即泄漏（第 005、026 章）。
  • 旧策略占比一次性锁定。批次采集完成后立刻保存 log πold，多轮更新期间不再刷新；中途刷新会让比率失去参照，裁剪失去意义。
  • 多轮小批更新。整批数据被切成小批多轮使用，提升同策略数据的利用率；轮数过多会让策略离旧策略过远，比率超出裁剪区间后梯度信号退化，回报曲线先升后降。

与第 011 章的差异点：回放池被回合批次缓冲替代，更新目标从时序差分单步变为裁剪代理目标，策略从确定性变为分类分布（离散）或高斯（连续）。数据接口保持"单条联合转移、多方切片"不动，新增字段为 log πold、优势与回报目标，这三者由采集缓冲一次算好。

设计决策：优势归一化在全局批次进行的理由

优势归一化（减均值除标准差）让裁剪阈值与优势尺度解耦。归一化统计若在每轮小批内计算，不同小批之间的优势尺度不一致，等价于对同批数据施加了随机的重加权，训练出现"小批间振荡"。在回合批次进入更新循环前做一次全局归一化，此后各轮各小批读取同一组统计量，尺度一致且可复现。该处理与执行侧归一化的纪律相似：统计量的作用域必须显式声明，避免跨域混用。

采集批次与优势估计质量

批次大小直接影响 GAE 的质量。优势经价值函数自举，价值误差沿时间维相关，批次内回段越多、起点越分散，累计起点的误差被平均得越充分。基线取 8 回合 × 60 步，每批约 480 条转移。把批次换小到 2 回合（120 条）时，单批优势均值的标准误按 √4 = 2 倍放大，裁剪阈值面对的优势尺度随批次漂移，等效于每批的更新力度不受控。取值依据可归纳为：批次大小按"优势估计的标准误降到优势标准差的固定分数以下"来定，基线 480 条对应的比值约为 1/22；回报尺度明显更大的任务在此基础上加倍，长回段任务则优先增加回合数，把回段起点的多样性作为加批方向；增加步数只拉长单段长度，起点个数不变。批次加倍会线性增加每轮迭代的采集时间与显存占用，两倍批次对新任务的调参风险最低、收益边际递减，通常无需超过两倍基线。

关键代码与解读

片段 1：批次采集与 GAE 计算

import torch

def compute_gae(rewards, values, dones, gamma=0.95, lam=0.95):
    """从时间主序批次反向计算 GAE: 递归在 done 处截断。"""
    T = rewards.shape[0]
    adv = torch.zeros_like(rewards)              # (T,)
    last = torch.zeros_like(rewards[0])
    for t in reversed(range(T)):
        # done=1 时下一状态价值不参与, 递归链也随之切断
        next_v = values[t + 1] if t + 1 < T else 0.0
        delta = rewards[t] + gamma * next_v * (1.0 - dones[t]) - values[t]
        last = delta + gamma * lam * (1.0 - dones[t]) * last
        adv[t] = last
    returns = adv + values                       # 价值回归目标: 优势加基线
    # 归一化作用域为整批: 后续全部轮次共享同一组统计量
    adv = (adv - adv.mean()) / (adv.std() + 1e-8)
    return returns, adv

解读：递归段落实现理论公式的最后一行。（1）reversed(range(T)) 从末端向前累计，last 承载 γλ 衰减的后续优势之和；done 一旦为 1，递归链与自举项同时被切断，两个位置各乘一次 (1.0 - dones[t])，漏掉任一处都会把跨回合的回报混入优势。（2）价值目标取 adv + values，与优势共享同一条递归路径；两者若在不同函数里各算各的，接口漂移几乎不可避免。（3）归一化放在整批尾部统一执行，统计量作用域与设计决策一致。

片段 2：裁剪代理更新

def ppo_update(actor, critic, batch, opts, eps=0.2, ent_coef=0.01, vf_coef=1.0):
    """一轮 PPO 更新: 比率裁剪 + 价值回归 + 熵奖励。"""
    obs, idx, acts, old_logp, adv, ret, s = batch.split()
    dist = actor(obs, idx)                       # 共享演员: (B*N, nA)
    logp = dist.log_prob(acts)
    ratio = torch.exp(logp - old_logp)           # old_logp 采集时锁定, 此处只读
    surr1 = ratio * adv
    surr2 = ratio.clamp(1.0 - eps, 1.0 + eps) * adv
    loss_pi = -torch.min(surr1, surr2).mean()    # 裁剪目标: 比率越界后梯度归零
    v_pred = critic(s)
    loss_v = ((v_pred - ret) ** 2).mean()        # 价值回归到 GAE 回报目标
    loss = loss_pi + vf_coef * loss_v - ent_coef * dist.entropy().mean()
    for opt in opts:                             # 演员与价值函数各自反传
        opt.zero_grad()
    loss.backward()                              # 一次反传覆盖两个网络
    torch.nn.utils.clip_grad_norm_(                        # 全局范数裁剪
        list(actor.parameters()) + list(critic.parameters()), 10.0)
    for opt in opts:
        opt.step()
    return dict(loss_pi=float(loss_pi), loss_v=float(loss_v))

解读：四行损失各对应理论公式的一项。（1）torch.min(surr1, surr2) 在 Â 为正时分两种情况：比率未越界走 surr1（正常爬升），越界走被截断的 surr2（上界封顶）；Â 为负时同理封底。（2）old_logp 来自采集批次、更新期间保持不变；比率由 exp(logp - old_logp) 计算，数值上比直接相除稳定。（3）演员与价值函数共享一次反传并按各自优化器分步，梯度裁剪作用于合并参数列表，防止某一侧异常梯度污染另一侧。（4）熵项以负号进入损失，鼓励维持策略熵；系数由 0.01 起步，任务早期可上调。

片段 3：整批—多轮—小批循环

def train_epochs(actor, critic, buffer_batch, opts, epochs=5, minibatch=256, seed=0):
    """回合批次进入多轮小批更新; 大小批边界固定, 便于复现。"""
    g = torch.Generator().manual_seed(seed)
    logs = []
    norm_adv = buffer_batch.adv                  # 全局归一化已完成, 各轮共享
    for ep in range(epochs):
        perm = torch.randperm(buffer_batch.size(), generator=g)
        for start in range(0, buffer_batch.size(), minibatch):
            idx = perm[start:start + minibatch]
            mb = buffer_batch.gather(idx, adv_override=norm_adv)
            logs.append(ppo_update(actor, critic, mb, opts))
        # 轮数过多时策略偏离旧策略, 比率失配会先在日志中显现
    return logs

解读：外层循环把"同一批数据用几轮"这一超参落到代码上。（1）洗牌使用固定种子的生成器，同一实验可复现；gather 只做索引抽取，不改动原批次的存储顺序，方便的对照实验可以复用同一份采集数据。（2）优势一律读取预先归一化的 norm_adv，小批内不再做任何统计变换。（3）每轮结束后可记录比率的越界比例（ratio 落在 [1−ε, 1+ε] 之外的比例），它是"策略离旧策略多远"的直接度量；越界比例随时间急剧上升时，收益通常已经到顶，继续加轮数无益。该指标是 MAPPO 调参的第一观测点。

常见坑

  • old_logp 被刷新。症状：裁剪失效，更新后回报剧烈震荡。原因：多轮更新中重算了旧比率。修复：采集缓冲写入时一次性固化 log πold，更新路径只读不写。
  • GAE 的 done 掩码漏乘。症状：跨回合优势污染，价值目标系统性偏高。原因：递归链与自举项只切断了一处。修复：在单元测试里构造"回合末奖励突增"的序列，断言下一回合影子的优势不受影响。
  • 优势在小批内归一化。症状：小批间表现互相抵消，总损失下降而回报停滞。原因：每小批统计量不同，等价随机重加权。修复：归一化移出循环，作用域与批次划分解耦。
  • 轮数过多。症状：回报曲线先升后降，比率越界比例冲高。原因：同批数据被过度消费，策略偏离旧分布。修复：以比率越界比例与验证回报双指标调低轮数；基线从 5 轮开始。
  • 执行侧归一化使用运行统计。症状：评估掉点，随训练时长扩大。原因：执行特征统计随训练更新。修复：执行侧固定边界或冻结统计，集中侧统计与执行侧分离（第 005 章纪律）。

小结

  • PPO 的裁剪比率把信任域约束写成可微的代理目标；多智能体版本按智能体计算比率，优势来自集中式价值函数。
  • GAE 用 (γ, λ) 调节偏差方差，递归在 done 处同时切断自举与链式累计，价值目标与优势共享同一中间量。
  • 工程配方四点：共享演员加标识、归一化作用域分离、旧比率锁定、整批多轮小批；比率越界比例是第一调参观测点。
  • 与离策略家族对照：样本效率换稳定性，路线选择由数据获取成本与调参预算决定。
