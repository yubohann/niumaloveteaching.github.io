第一篇 · CTDE 基础与核心算法

第 004 章：参数共享与不共享对比

同构智能体是否共用一套网络参数，直接决定参数量、样本效率与策略表达力三者之间的取舍。本章给出参数共享（parameter sharing）的梯度解释、智能体标识（agent ID）注入方法、部分共享结构，以及共享与不共享的完整对照实验设计。

  • 主题：参数共享 / 同构智能体建模
  • 关键公式：J(θ) = 𝔼[ Σi ∇θ log πθ(ai | τi, idi) · Ai ]
  • 预计学时：50 分钟
  • 前置章节：第 003 章

学习目标

  • 理解参数共享、不共享、部分共享三种粒度的定义与适用条件，掌握各自参数量与表达力的权衡。
  • 掌握参数共享的梯度解释：总梯度为各智能体梯度之和，样本效率来自多任务式的信号复用，风险来自梯度冲突。
  • 理解智能体标识（agent ID）注入的作用：用少量参数打破对称性，让共享网络表达角色差异化的策略。
  • 会实现带标识嵌入的共享策略、按 (B·N) 展平的损失聚合，以及梯度冲突监测。
  • 能设计共享与不共享的对照实验，在智能体异构程度变化时预测两种配置的相对表现。

背景与动机

第 003 章的框架给每个智能体一份独立的演员与评论家。当任务里的智能体同构（例如同一型号的多台移动机器人、同一兵种的多架无人机）时，N 份网络参数意味着 N 倍的参数量与 N 个独立的优化过程，每条联合转移只能更新每个网络一次。工程直觉上这是浪费：N 个同构智能体面对相似的状态分布，学到的策略高度相似，参数量本可以压缩。

参数共享（parameter sharing）让全部智能体共用一套策略与评论家参数，通过输入中的智能体标识区分身份。它的收益是三重的：参数量降为约 1/N；每条联合转移为共享网络提供 N 份梯度信号，样本效率上升；观测分布汇总后更平稳，训练方差下降。代价同样明确：共享把 N 个策略学习问题耦合为多任务学习问题，策略函数类被收紧，梯度方向可能相互冲突，异构场景下退化明显。

本章回答三个问题：共享为什么在样本效率上占优；标识注入如何恢复部分表达力；什么条件下共享从收益转为负迁移。掌握这些判据后，后续每章的算法实现都能在这两档配置间切换。

核心原理

本节先形式化三种参数化方式，再推导共享梯度，最后分析标识注入的表达力与共享的边界条件。

1. 三种参数化方式

设每个智能体的策略网络参数为 θi，状态维度上的参数化选择有三种：

独立：πθi(ai | τi)，参数量 N·|θ|；
完全共享：πθ(ai | τi, idi)，参数量 |θ| + |Emb(idi)|；
部分共享：πθenc, φi(ai | τi, idi)，编码器共享、输出头 φi 独立 idi 为智能体标识输入（one-hot 或可学习嵌入）；部分共享在异构与同构之间的中间地带使用，第 030 章展开

从函数类的角度看：完全独立策略的参数空间是各智能体参数空间的乘积，完全共享是其对角子空间的扩展。共享加上标识输入后，网络理论上可逼近"每个标识一条子策略"的行为，但初始化相同、梯度耦合，实际会产生相互促进或被干扰的学习动力学，这正是对照实验要测量的对象。

把参数量账算清楚（观测 2 维、隐藏层 64、动作 3 个的 MLP）：单体参数为 2 × 64 + 64 + 64 × 64 + 64 + 64 × 3 + 3 = 4547。独立档 N = 4 时总量 18188。共享加 ID 档：嵌入 N × 8 = 32，主干第一层输入从 2 维升到 10 维（10 × 64 + 64 = 704），加 4160 与 195，合计 5091，相对独立档的比值为 0.28；N = 10 时共享档 5139、独立档 45470，比值降到 0.11。ID 注入的总开销是 544 个参数（嵌入 32 加第一层新增输入列 512），约为单体网络的 12%，换来的是角色差异化的表达能力。三种配置的取舍列成对照表：

配置参数量（N = 4 实算）角色表达力异构鲁棒性样本效率适用条件
独立18188最强，各智能体自由分化最高，异构无需额外机制最低，每条数据只服务一个网络强异构、小规模、参数量不敏感
共享 + ID5091中等，受共享主干约束低，观测或能力异构引发梯度冲突最高，单条联合转移贡献 N 份梯度同构或弱异构、参数预算紧张
部分共享介于两者，取决于拆分位置较高，输出头可独立分化中高，编码器隔离异构观测较高观测异构而动作同构

2. 共享梯度的分解：多任务视角

训练目标对共享参数的梯度等于各智能体梯度之和：

∇θ J(θ) = 𝔼轨迹∼πθ [ Σi=1N ∇θ log πθ(ai | τi, idi) · Ai(s, a) ] Ai 为各智能体的优势权重（第 003 章训练通路产生）。注意期望符号下所有 log 项共享同一 θ，推导与单智能体策略梯度相同，只是求和号内多了智能体下标

该式解释了两个现象。（1）样本效率。一条联合转移同时出现在 N 个求和项中，每个智能体为同一组参数贡献一份梯度。若智能体同构、优势权重相近，等效于把每条数据放大 N 倍使用，达到相同回报所需环境步数下降。（2）梯度冲突。不同智能体的优势权重朝相反方向时，求和后的梯度是两个方向的折中，可能对任何单个智能体都不构成有效的改进方向。多任务学习研究表明，冲突强度与任务间梯度夹角相关：夹角余弦接近 −1 时冲突最严重。智能体越异构，夹角分布越宽，共享的边际收益越差。由此得到判据：共享的收益来自同构性，异构程度决定收益的衰减速率。

冲突的几何可以量化为三个档位。设两智能体梯度的夹角余弦为 cos φ，模长相等时求和梯度在各自方向上的投影正比于 1 + cos φ：φ = 0° 时投影放大为 2 倍，信号最强叠加；φ = 90° 时投影为 1 倍，互不干扰但也没有共享增益；φ = 180° 时投影为 0，完全抵消，共享参数原地不动。模长不平衡时抵消的后果更严重：智能体 1 的梯度模长 1、指向 0°，智能体 2 的梯度模长 10、指向 180°，求和梯度为 (−9, 0)，在智能体 1 方向上的投影是 −9。此时共享更新对智能体 1 构成负向推进，小梯度智能体被大梯度智能体拖着重写策略，这是异构任务中共享档后期表现崩坏的直接机理。

3. 标识注入与对称性打破

不带标识的共享网络对输入置换是等变的：所有智能体在观察相同观测时输出相同分布。当任务存在角色不对称（一个智能体在队伍左侧、另一个在右侧，目标要求两人角色互换）时，无标识共享无法表达两种角色的差异策略，学习会停滞在对称的折中行为。

标识注入的基本做法是把 idi 的嵌入向量与观测编码向量相加或拼接后送入后续层。嵌入维度通常取 4 至 16，参数量为 N × demb，相比独立网络的 N × |θ| 可以忽略。需要强调：标识打破的是函数输入的对称性，不自动保证各智能体学到差异；当任务本身对称且最优策略对称时，嵌入也会收敛到近似相等的向量，这种"学到了但用不上"的形态说明共享设定与任务供给匹配。作为对照，若评估中发现去掉标识后性能不变，说明该任务不提供需要角色区分的信号。

4. 共享的边界条件

三类信号会削弱共享的收益。第一类是观测异构：智能体观测维度或语义不同（一个读激光雷达、一个读图像），共享编码器被迫兼容两种分布，负迁移出现，此时应使用部分共享：观测编码器分开，动作头或评论家共享。第二类是动作异构：动作空间不同则输出层无法共享，最低限度保留独立输出头。第三类是能力异构：第 030 章讨论的异构协作中，不同智能体的最优策略结构可差很远，共享退化为强正则，需要按类型分组共享（group sharing）。工程上把共享做成可配置开关，并在实验中把它作为第一个消融变量，是成本最低的稳健策略。

实现思路与设计

本节给出三种配置的统一实现结构与对照实验协议。核心设计是：数据经 (B, N, ·) 展平为 (B·N, ·) 批量前向共享网络，标识以嵌入形式注入，损失按智能体聚合。

设计项取值（基线）作用与依据
配置档独立 / 共享 / 共享+ID 三档切换共享做成布尔配置项，避免两份代码分叉
ID 嵌入维度8N ≤ 10 时足够区分身份；加大到 32 收益有限且增加过拟合风险
网络结构64×64 MLP，共享档三层共用与第 002、003 章同构，控制变量
优化器共享档单一 Adam（lr 5e-4）共享参数必须单优化器，独立档每智能体一个
归一化层LayerNorm（替代 BatchNorm）BatchNorm 的批统计跨智能体混合，等于引入训练期才有的全局信息，评估时不复现
实验协议N = 4，同构任务与"观测尺度异构"任务各跑 5 个种子用同构/异构两档任务测收益衰减，种子方差计入结论

与第 003 章的差异点集中在演员与评论家的参数化方式，训练循环、数据接口、超参学习率保持不变。唯一新增的超参是 ID 嵌入维度，它必须进入消融清单：嵌入维度为零即退化为无标识共享。

设计决策：共享档采用 (B·N) 展平批量的理由

展平后一次前向即可处理所有智能体样本，显存与耗时接近单智能体训练；拆分后需要在时间维-智能体维间反复转置，且每条样本的前向无法并行。展平的代价是损失聚合时必须携带智能体索引，用于取各自的优势权重与掩码。该结构对后续所有"共享网络"场景通用，包括第 012 章的 MAPPO 与第 015 章的注意力评论家。

关键代码与解读

片段 1：带标识嵌入的共享策略网络

import torch
import torch.nn as nn

class SharedActor(nn.Module):
    """共享策略: 全部智能体共用同一套参数, 身份由 ID 嵌入注入。"""
    def __init__(self, obs_dim, n_actions, n_agents, emb_dim=8, hidden=64):
        super().__init__()
        # ID 嵌入参数量仅 N*emb_dim, 相对主干网络可忽略
        self.id_emb = nn.Embedding(n_agents, emb_dim)
        self.encoder = nn.Sequential(
            nn.Linear(obs_dim + emb_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
        )
        self.head = nn.Linear(hidden, n_actions)   # 输出 logits

    def forward(self, obs, agent_idx):
        # obs: (B, obs_dim); agent_idx: (B,) 长整型智能体编号
        e = self.id_emb(agent_idx)                 # (B, emb_dim)
        # 嵌入与观测拼接后进入共享主干: 标识只改变输入, 不改动参数
        h = self.encoder(torch.cat([obs, e], dim=-1))
        return torch.distributions.Categorical(logits=self.head(h))

    def n_params(self):
        # 用于对照实验报告: 共享档参数量与 N 倍独立档的比值
        return sum(p.numel() for p in self.parameters())

解读：结构上有三个定点。（1）嵌入层是共享档唯一的身份相关参数，它将"每个身份的行为差异"压缩在一个低维向量中；与观测拼接后进入共享主干，主干面对的是"带身份标签的观测"统一分布。（2）输出层共享要求各智能体动作空间同构；动作异构任务需要把 head 换成 ModuleList 实现部分共享。（3）n_params() 是为对照实验服务的：参数量降幅是共享的第一项可报告收益，把它固化进类接口，实验代码不用重复统计。

片段 2：展平批量与损失聚合

def shared_actor_loss(actor, obs, agent_idx, actions, advantages):
    """共享档损失: 展平 (B, N) 后一次前向, 再按智能体聚合梯度信号。"""
    B, N = actions.shape
    obs_f = obs.reshape(B * N, -1)                 # (B*N, obs_dim)
    idx_f = agent_idx.reshape(B * N)               # 展平的智能体编号
    act_f = actions.reshape(B * N)
    adv_f = advantages.reshape(B * N)              # 优势权重按样本对齐
    dist = actor(obs_f, idx_f)                     # 单次前向覆盖全部智能体样本
    logp = dist.log_prob(act_f)
    # 归一化优势: 防止优势尺度的智能体差异把共享梯度带偏
    adv_f = (adv_f - adv_f.mean()) / (adv_f.std() + 1e-8)
    loss = -(logp * adv_f.detach()).mean()
    return loss, dist.entropy().mean()             # 熵随损失一并返回供日志观察

解读：展平操作把"多智能体"折叠进批量维，配合嵌入层实现单次前向多身份输出，这是共享档效率优势的实现来源。优势归一化处的注释对应理论部分：共享梯度是不同智能体优势权重的加权和，若各智能体优势尺度差异大，尺度大的智能体主导梯度，等效于对它单独训练。归一化使各智能体梯度贡献量级对齐。注意归一化用批次统计（mean/std）时必须限定在同一批样本内并对执行期无依赖，它与 BatchNorm 的风险不同：前者只作用于损失权重，后者改变特征表示。熵项只观测不进入损失，探索强度的控制留给第 025 章统一处理。

片段 3：梯度冲突监测

def gradient_conflict(qs_or_actor, loss_fn, batch, n_agents):
    """测量共享参数上各智能体梯度的两两余弦相似度, 诊断负迁移。"""
    grads = []
    for i in range(n_agents):
        loss_i = loss_fn(batch, agent_index=i)     # 仅第 i 个智能体的损失分量
        g = torch.autograd.grad(loss_i, qs_or_actor.parameters(),
                                retain_graph=(i < n_agents - 1))
        grads.append(torch.cat([x.flatten() for x in g]))
    cos = torch.nn.functional.cosine_similarity
    sims = [float(cos(grads[i], grads[j], dim=0))
            for i in range(n_agents) for j in range(i + 1, n_agents)]
    # 接近 -1 表示两智能体拖拽共享参数的方向相反, 共享收益将转为负担
    return sims

解读：这段监测代码把理论部分的"梯度夹角"变成可打印的数字，是共享与不共享对照实验的中间变量。（1）retain_graph 在最后一个智能体之外必须为真，否则前几次 autograd.grad 调用后计算图被释放；这个细节错了会报运行时错误，属于实现层面高频错误。（2）只测量不干预：把它作为日志指标，观察相似度从训练早期的近零随机值向何值演化。若稳定在明显负值区间而共享性能不达标，改用部分共享或分组共享，这是数据驱动的结构选择路径。

常见坑

  • 共享档为每个智能体各建一个优化器。症状：优化器状态与会话对象数量随 N 增长，更新次数与预期不符。原因：从独立档代码直接改造时保留了列表式优化器。修复：共享档断言优化器数量为 1，并检查每条数据只产生一次 step。
  • 忘记注入 ID 就断言"共享更好/更差"。症状：对称性任务上结论成立，角色不对称任务上共享档完全学不动。原因：无标识共享的函数类无法表达角色差异。修复：把 ID 维度加入消融清单，默认配置带 ID，报告结论时注明标识开关状态。
  • BatchNorm 混入跨智能体统计。症状：训练曲线正常，离线评估掉点（评估批量小时尤其明显）。原因：批统计把同批中其他智能体的样本信息带入特征归一化。修复：全部归一化层替换为 LayerNorm，或采用第 026 章的隔离统计方案。
  • 展平后身份索引错位。症状：策略输出与观测不匹配，表现为"看了别人观测却用自己的身份"。原因：reshape 与转置顺序不一致导致 idx 与实际样本错列。修复：在展平函数内加入断言（每行 idx 与动作张量同序），并用恒等输入做一次对拍。
  • 异构任务盲目共享。症状：共享档后期回报低于独立档且方差更大。原因：观测或能力异构造成梯度冲突，负迁移压过样本效率收益。修复：先看梯度冲突指标，再切换部分共享；必要时按智能体类型分组共享。

练习与思考

  1. 设每个智能体网络参数量为 8000，ID 嵌入维度 8、主干输入增加 8 维带来的额外参数约 64。计算 N = 4 与 N = 10 时共享档相对独立档的参数量比值。★
    提示
    N = 4 时约 (8000 + 32 + 64)/32000 ≈ 0.25；N = 10 时约 (8000 + 80 + 80)/80000 ≈ 0.10。参数量降幅随 N 近似线性扩大，这是共享在大规模智能体下更受青睐的直接原因。
  2. 把 ID 嵌入维度从 8 改为 0（无效注入）和 32，在对称协作任务与角色不对称任务上分别预测性能排序，并解释差异。★
    提示
    对称任务：0 维与 8 维接近，32 维略慢（多余参数稀释梯度）；不对称任务：0 维无法表达角色差异，明显劣于 8 维；32 维与 8 维接近。结论：嵌入维度存在"够用即止"的平台区。
  3. 推导共享目标 J(θ) 对 θ 的梯度为各智能体梯度之和，并说明当两个智能体的优势权重分布独立零均值时，共享梯度的方差与独立训练两者梯度方差之和的关系。★★
    提示
    由期望线性性与 log 项可分性逐项求导即得。方差方面：独立权重下和的方差等于方差之和，信号强度随 N 增长，等同批数据量放大；若权重间正相关（同构且同奖励），有效样本量增幅低于 N，这是"同构收益"的量化边界。
  4. 设计实验：构造观测尺度异构任务（智能体 1 的观测乘 0.1，智能体 2 保持原尺度），比较独立、共享+ID、部分共享（观测编码器独立、动作头共享）三种配置的收敛步数与后期回报，并给出梯度冲突指标与性能的相关性预测。★★
    提示
    预测：共享+ID 因单一编码器兼容两种尺度而受损，冲突指标明显为负；部分共享恢复大部分性能且参数量仍低于独立档。若冲突指标与回报损失正相关，说明监测变量有效。
  5. 设计题：给出"按智能体类型分组共享"的数据结构与训练循环改造方案：如何定义类型、如何在展平批量中携带类型索引、优化器与分组参数的对应关系。说明该方案在 N = 20、类型数 = 3 时的参数量与调度开销。★★★
    提示
    类型→参数组映射；展平时携带 (agent_idx, type_idx) 双索引，按类型桶拆分批次分别前向并聚合梯度；参数量约 3 份主干加全部 ID 嵌入；调度开销来自分桶次数，随类型数线性增长，可接受。

小结

  • 参数化三档：独立、共享+ID、部分共享；参数量、表达力、样本效率形成三角权衡，异构程度决定共享收益的衰减速率。
  • 共享梯度等于各智能体梯度之和；样本效率来自信号复用，风险来自梯度冲突，两智能体梯度余弦相似度是可监测的中间变量。
  • ID 注入用极少量参数打破输入对称性，使共享网络表达角色差异策略；ID 维度必须进入消融清单。
  • 实现上采用 (B·N) 展平批量、单一优化器、LayerNorm 替代 BatchNorm，三点共同保证共享档的评估一致性。
  • 下一章回到框架内部的信息设计：全局状态与局部观测分离，讨论状态表示与观测编码如何做到既信息充分又不泄漏。
