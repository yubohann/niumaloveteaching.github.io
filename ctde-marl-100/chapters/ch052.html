第三篇 · 环境与任务实践

第 052 章：多智能体无人机集群控制

无人机集群把空间协同搬进三维并叠加欠驱动、风扰与断连三类现实约束；本章推导分层控制接口，说明高度分层如何把三维避碰降为二维问题，并给出鲁棒训练的方法。

  • 主题：三维集群 / 欠驱动系统与鲁棒性
  • 关键公式：m dv/dt = R(θ, φ) · T · ez − m g ez + fwind
  • 预计学时：65 分钟
  • 前置章节：第 051 章 多智能体能源管理

学习目标

读完本章，应当能够为三维集群任务选择正确的控制接口，并把风扰与断连纳入训练与评估。

  • 理解四旋翼欠驱动特性：推力沿机体轴产生，位置控制必须经由姿态实现，策略输出需要选择合适的抽象层级。
  • 掌握分层控制结构：外环位置控制与内环姿态控制的接口划分，以及学习策略应放置的位置。
  • 掌握高度分层避碰的规则与适用条件，理解垂直分离如何将三维冲突降维处理。
  • 理解风扰与观测噪声的建模方式，掌握域随机化（domain randomization）在鲁棒训练中的作用与代价。
  • 会设计含通信中断模拟与能量约束的训练配置，识别评估阶段性能骤降的原因。

背景与动机

无人机集群把空间协同的难度从二维提升到三维，同时引入欠驱动与扰动两类控制约束。

四旋翼的动力学是欠驱动的：四个执行器控制三维位置与偏航，位置与姿态之间通过推力方向耦合，任何横向机动都必须先倾斜机身。集群任务又要求多个无人机在共享空域中协同，避碰在三维空间中比二维更难：冲突事件的几何条件更复杂，垂直方向没有天然的分层结构。真实环境中还有两类扰动：风场作用于每一台无人机，观测噪声使相对位置估计存在误差；通信链路断续，邻居信息陈旧。

强化学习在此的常见做法是接管外环位置控制，把姿态跟踪交给解析内环控制器。该接口划分让策略的动作维度保持在三维加速度或速度量级，避免学习高频姿态动力学；把风力估计与相对位置估计作为独立模块，观测中注入带噪估计值。本章的鲁棒训练方法（域随机化、断连模拟）与前几章的安全约束技术互补，它处理的是训练分布与真实分布之间的偏差，这一主题在第五篇的真机集成章节会继续展开。

核心原理

本章原理分四层：欠驱动动力学与接口、三维避碰的分层化简、风扰与噪声的建模、以及断连下的去中心化执行。

1. 欠驱动动力学与控制接口

四旋翼的合力仅沿机体轴的推力方向产生，姿态决定了加速度方向。

m · dv/dt = R(θ, φ) · T · ez − m g ez + fwind m 为质量；v 为速度；R 为由俯仰角 θ 与横滚角 φ 决定的旋转矩阵；T 为总推力；ez 为竖直单位向量；g 为重力加速度；fwind 为风力

该方程说明两个控制事实。第一，水平加速度只能通过倾斜机体间接获得，倾斜角与水平加速度近似成正比，机动性受最大倾角限制。第二，垂直与水平通道通过同一个推力耦合：加大推力同时提升高度与水平加速度分量。若让学习策略直接输出四个电机转速，它需要同时学习姿态动力学与位置控制，样本效率低且在风扰下难稳定；标准做法是分层：内环姿态控制器跟踪期望姿态，外环输出期望姿态或期望加速度，学习策略在外环工作。

策略输出常见三种抽象层级：期望速度（最稳，适合编队巡航）、期望加速度（机动性强，适合避障）、期望姿态加推力（自由度最高，样本效率最低）。选择依据是任务的机动需求与训练预算；本章的参考实现采用期望加速度，通过限制加速度幅值间接限制倾角。

2. 高度分层与三维避碰

给集群分配不同的高度层，可以把大部分冲突从三维降为二维处理。

layeri = i mod L ， zides = z0 + layeri · Δz ， Δz > 2 rz + hmargin L 为层数；Δz 为层间距；rz 为垂直方向安全半厚；hmargin 为余量；同一层内的无人机主要需要水平避让

分层规则的有效条件是层间距大于垂直安全距离的两倍加余量，此时不同层的无人机在垂直方向上有确定分离，控制器的冲突检查只需要考虑同层邻居，问题复杂度从三维的近邻检查降为二维。分层也带来代价：任务要求的高度分布可能被层结构拉扯，且越层机动（上升穿越其他层）必须安排时间窗口并与相关层的无人机协调。层数与集群规模的关系近似为“同层无人机数 = N / L”，层数越多冲突越少，但高度利用率与任务灵活性下降。

同层内的水平避让沿用第 045 章的速度障碍思想，把冲突判定投影到水平面。三维完整版的速度障碍同样是锥形区域，计算量增加一个维度，实现复杂度上升；分层加二维避让的组合是效率与完整性的折中方案。

3. 风扰与观测噪声

风在动力学中表现为力，在观测中表现为估计误差，两者都需要建模。

fwind = cd · ( vair − v ) · ‖ vair − v ‖ ， vair = vconst + vgust(t) cd 为阻力系数；vair 为气流速度；vconst 为常值风；vgust 为阵风扰动，通常建模为零均值随机过程叠加偶发脉冲

阻力型风力模型给出两个性质：风速与机体速度接近时风力趋近零（顺风飞行阻力小），逆风飞行需要额外推力维持速度。阵风的时间尺度决定控制器的带宽需求，脉冲型阵风考验策略的瞬时鲁棒性。观测噪声方面，相对位置估计误差常用高斯模型，误差幅度随距离增加；若观测中包含速度估计，则速度噪声与位置噪声相关，独立同分布的假设需要检验。

域随机化在训练时对风场参数、噪声幅度与质量参数按分布采样，每回合内参数固定、回合间变化。它让策略见到扰动范围的全貌，评估时在分布内与分布外的风况下都表现稳定，代价是收敛速度变慢（策略需要兼顾多种条件）以及无风情形下的性能略低于专用策略。随机化范围的设定以真实系统的置信区间为准，过宽的分布会牺牲性能，过窄的分布无法覆盖边缘工况。

4. 断连与陈旧信息

通信链路的断续使邻居状态在策略手中过时，去中心化执行必须对信息新鲜度建模。

断连处理的通用结构是每条邻居记录附带时间戳，观测中给出“信息年龄”。策略对年龄大的邻居降低信任：可以降低其权重，或按最后已知位置加不确定性半径的方式使用。训练时按概率随机丢弃邻居数据、并给出被遮蔽的掩码，模拟真实链路的统计特性。若训练时链路完全可靠，评估遇到丢包会出现两种退化：碰撞率上升（邻居突然消失）或保守停滞（策略把“无信息”当成“无邻居”）。为老化信息设计不确定半径是很自然的补救：观测中给出邻居位置及其时间戳，策略学到按年龄扩张安全半径。

5. 能量与续航约束

无人机的功率消耗与推力相关，任务策略必须把剩余能量纳入决策。

Pe( T ) ≈ c0 + c1 T1.5 ， Et+1 = Et − Pe( Tt ) Δt T 为推力；c0、c1 为悬停与诱导功率系数；E 为电池能量；增长速度高于线性使高推力机动代价昂贵

能耗模型说明机动幅度与续航直接相关：急加速与频繁变速会显著缩短任务时间。策略观测中包含剩余能量与到基地距离，奖励中加入低电量返航约束（低于阈值时强制向基地方向移动的惩罚或动作约束），可以避免常见的“任务末期电量耗尽”现象。评估时统计任务完成率与平均剩余电量，两者同时改善才说明能量管理合理。

实现思路与设计

实现采用三层时间尺度：内环姿态用解析控制器按毫秒级运行；策略以 20 Hz 输出期望加速度；规划与分层以秒级更新。环境为纯 NumPy 的简化三维动力学。

1. 环境循环

每步：采样风场实现；按策略输出计算期望加速度并限幅；积分速度与位置；更新能量；检查碰撞与禁飞区；构造带噪观测（含信息年龄）；结算奖励。回合结束统计任务指标与安全指标。

3. 网络结构与训练要点

策略网络输入包含自身状态、带时间戳的邻居相对位置、风场估计与任务目标。邻居编码器沿用置换不变结构，时间戳作为附加特征参与编码。训练采用集中式评论家，输入全集群状态与风场实现（特权信息），执行仅依赖带噪观测。域随机化在每回合开始时采样风场参数与噪声水平，随机化范围按真实系统的估计区间设定。评估分为四组：无风、常值风、阵风、高丢包，报告每组的安全率与任务完成率。

4. 与第 042 章、第 051 章的差异点

第 042 章的编队约束在二维且动力学抽象为速度积分，策略可以专注几何；本章的动力学是欠驱动三维系统，几何目标必须通过受限的加速度实现，且叠加风扰与断连。第 051 章的约束是等式功率平衡，耦合来自共享资源；本章的耦合来自共享空域，约束是不等式（安全距离）与任务目标的组合。三章共享的工具是相对位姿观测、安全投影与参数共享结构，差异集中在动力学自由度、扰动来源与约束类型。

关键代码与解读

三段代码分别实现含风扰的动力学积分、分层避碰的安全投影、以及域随机化采样。

片段 1：三维动力学与风力

import numpy as np

def wind_force(vel, wind_const, gust, cd=0.25):
    """阻力型风扰：风与机体相对速度决定力的大小与方向。"""
    rel = wind_const + gust - vel                  # 相对气流速度
    speed = np.linalg.norm(rel)
    # 二次阻力：相对速度越大，扰动越强；方向沿相对气流
    return cd * rel * speed

def uav_step(pos, vel, acc_cmd, wind_const, gust, dt=0.05,
             a_max=3.0, v_max=6.0, mass=1.0):
    """外环积分：策略输出期望加速度，限幅后推进。"""
    a = np.clip(acc_cmd, -a_max, a_max)
    f_wind = wind_force(vel, wind_const, gust)
    a_total = a + f_wind / mass                    # 风以力的形式进入动力学
    vel = vel + a_total * dt
    # 速度限幅：限制水平与垂直分量，防止风把机体加速到失控
    sp = np.linalg.norm(vel)
    if sp > v_max:
        vel = vel / sp * v_max
    pos = pos + vel * dt
    return pos, vel, f_wind

解读：风力按相对气流速度计算，顺风时阻力为负（推动），逆风时为正（阻滞），这一形式在不增加参数的情况下复现了两个真实效应。限幅分两级：加速度限幅对应倾角限制，速度限幅对应气动与电机的综合极限。返回的风力向量用于诊断与信息字典，策略看不到真实风力，只能通过观测中的估计值感知。dt 取 0.05 秒与 20 Hz 决策频率一致，若内环姿态带宽低于该频率，模型需要在积分中补充一阶滞后环节近似执行延迟。

片段 2：分层避碰与安全投影

def layered_assign(n, layers=2, z0=1.0, dz=2.0):
    """按编号分配高度层，返回期望高度与层编号。"""
    idx = np.arange(n)
    layer = idx % layers
    return z0 + layer * dz, layer

def repel_acc(pos, vel, others, others_layer, own_layer,
              r_h=0.8, r_z=0.6, k_rep=2.0):
    """排斥加速度：同层按水平距离推开，异层按垂直距离调整高度。"""
    acc = np.zeros(3)
    for p_j, l_j in zip(others, others_layer):
        d = pos - p_j
        if l_j == own_layer:
            d_h = d.copy()
            d_h[2] = 0.0                             # 同层只看水平分量
            dist = np.linalg.norm(d_h)
            if 1e-6 < dist < r_h:
                acc += k_rep * (r_h - dist) / r_h * d_h / dist
        else:
            # 异层检查垂直间距，防止越层机动时上下撞
            if abs(d[2]) < r_z:
                acc[2] += np.sign(d[2]) * k_rep * (r_z - abs(d[2])) / r_z
    return acc

解读：分层把邻居分成两类，同层用水平距离、异层用垂直距离，判定逻辑因此简单且可解释。排斥加速度采用线性衰减形式（距离越近推力越大），幅值由 k_rep 控制，与最大加速度的比值决定避让的优先级。垂直分量的符号函数保证异层单位朝远离方向调整高度而不互相压向同一侧。该排斥项的定位是兜底层：策略输出与此项叠加后再限幅执行，即使策略失效，几何安全仍由解析规则保障，与第 045 章的半平面过滤属同一设计模式。

片段 3：域随机化采样

def sample_domain(rng, wind_scale=(0.5, 3.0), gust_prob=0.3,
                  noise_scale=(0.02, 0.1), drop_range=(0.0, 0.2)):
    """每回合采样一次环境参数：风、噪声与丢包率。"""
    mag = rng.uniform(*wind_scale)
    theta = rng.uniform(0, 2 * np.pi)
    wind = mag * np.array([np.cos(theta), np.sin(theta), 0.0])
    cfg = {
        "wind_const": wind,
        "gust_prob": gust_prob,
        "noise_std": rng.uniform(*noise_scale),
        "drop_rate": rng.uniform(*drop_range),
    }
    return cfg

def apply_gust(rng, cfg, dt=0.05, duration=1.0):
    """按概率触发阵风：脉冲触发后按时间常数衰减到零。"""
    if "gust" not in cfg:                          # 首次调用初始化扰动状态
        cfg["gust"] = np.zeros(3)
    if rng.random() < cfg["gust_prob"] * dt:       # 每步触发概率随步长缩放
        cfg["gust"] = rng.normal(0, 1.0, 3)
    else:
        cfg["gust"] = cfg["gust"] * max(0.0, 1.0 - dt / duration)
    return cfg["gust"]

解读：域随机化在回合级别采样，回合内部保持参数恒定，避免策略面对同一回合内参数跳变而混淆因果。风速方向均匀采样、幅度按区间采样，保证训练覆盖各个来风方向，评估时不必担心方向外推。阵风用惰性衰减的随机脉冲模拟，触发概率按步长缩放保证不同频率下的物理一致性。丢包率同样在回合间采样，把“链路质量”作为泛化维度；固定参数会使策略只适应单一链路质量，评估时按丢包率分层报告。

常见坑

  • 训练无风、部署有风：策略在无扰条件下学到的控制增益过小，实际风况下位置偏差大。症状是评估误差随风速单调上升。修复：训练即引入风场并随机化幅度方向，评估按风况分层。
  • 分层间距不足：层间距小于垂直安全距离两倍，越层机动时上下冲突。症状是垂直方向的接近事件在高机动任务中集中出现。修复：层间距按安全半厚与机动余量重新计算，或增加越层的时间窗协调。
  • 忽略执行延迟：策略以 20 Hz 输出而内环跟踪延迟未建模，仿真与实机行为不一致。修复：在动力学中串联一阶滞后环节近似内环，或降低策略频率到内环带宽的十分之一以下。
  • 观测用真值训练：训练时相对位置与速度取真值，忽略了估计误差。症状是仿真指标优秀而实机碰撞率上升。修复：观测注入按距离相关的高斯噪声，训练分布与估计器实际误差一致。
  • 能量项权重过小：任务奖励远高于能耗惩罚，策略耗尽电量后无法返航。症状是任务后期电量归零且返航失败率上升。修复：加入低电量返航约束，把剩余电量与返航距离写入观测。

练习与思考

  1. 推导题：由合力方程推导水平加速度与倾角的关系 ah ≈ g · tan(θ)，并说明最大加速度如何限制机动半径。★
    提示
    将推力分解为竖直与水平分量，竖直分量平衡重力、水平分量提供加速度，取小角度近似或保留正切形式均可。机动半径与速度平方除以最大加速度成正比。
  2. 计算题：两层布置、层间距 2.0 米、垂直安全半厚 0.6 米；若在同样的高度跨度内改为三层，新层间距是多少，是否仍满足分离条件？★★
    提示
    按 z = z₀ + layer·Δz 的层位公式，高度跨度为 (L−1)Δz：两层跨度 2.0 米，三层时 Δz 压缩到 1.0 米，低于两倍安全半厚 1.2 米，分离条件不再满足。恢复条件是抬高总高度或降低安全半厚（后者要求更精确的位置估计）。
  3. 改参数并预测：把域随机化的风速上限从 3 m/s 提高到 6 m/s，预测无风场景的性能、强风场景的性能与收敛所需步数的变化方向。★★
    提示
    强风性能改善、无风性能略降、收敛步数增加。随机化范围扩大相当于求解更难的分布鲁棒问题，代价是无扰情形的专用性下降。
  4. 设计题：为断连场景设计观测编码，说明如何表达邻居信息的时间年龄，以及策略可采取的两类应对行为。★★★
    提示
    为每个邻居槽位附加时间戳或年龄特征，并给出掩码。应对行为包括按年龄扩张安全半径（保守）与按最后已知速度外推位置（主动），两者可以随年龄大小切换。
  5. 实验设计：比较“带随机化训练”与“固定中等风训练”两组策略在四种评估风况下的表现，说明鲁棒性的代价如何量化。★★★
    提示
    四组评估为无风、常值风、阵风、高丢包。鲁棒性的代价量化为无风场景的性能差，收益量化为最坏场景的性能差，两者权衡可用帕累托前沿表达，需要多组随机种子支持结论。

小结

  • 四旋翼是欠驱动系统，位置控制经由姿态实现；学习策略适合放在外环，输出期望加速度或速度，内环姿态由解析控制器承担。
  • 高度分层把三维避碰降为同层二维问题，层间距需大于两倍垂直安全距离加余量，越层机动需要额外的时间窗协调。
  • 风扰以阻力形式进入动力学，观测噪声与信息年龄进入观测；域随机化提升鲁棒性，代价是无扰性能略降与收敛变慢。
  • 断连下的去中心化执行需要表达信息新鲜度，能量约束需要进入观测与奖励，评估按风况与链路质量分层报告。
