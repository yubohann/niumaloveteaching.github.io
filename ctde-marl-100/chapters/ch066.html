第四篇 · 高级机制与研究专题

第 066 章：多智能体协同定位

当卫星信号不可用时，机器人依靠相互测距与少量锚点确定各自位姿：本章用克拉美罗下界量化几何精度，用一致性卡尔曼滤波做分布式估计，并用集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）学习测距对象的选择。

  • 主题：协同定位 / 测距约束与精度下界
  • 关键公式：Cov(θ) ≥ F−1，F = Σij JijTΣz−1Jij
  • 预计学时：60 分钟
  • 前置章节：第 065 章

学习目标

  • 掌握双边测距模型与对数距离路径损耗模型，理解测距噪声随距离增长的来源。
  • 掌握费舍尔信息矩阵（Fisher Information Matrix, FIM）与克拉美罗下界（Cramér-Rao Lower Bound, CRLB），能用单位向量雅可比推导双机测距的信息贡献。
  • 理解分布式卡尔曼一致性滤波（Kalman Consensus Filter, KCF）的更新结构，说明共享测量导致的估计相关性问题。
  • 能实现基于邻居注意力的测距调度策略，并解释能量预算约束下的动作屏蔽。
  • 能设计实验比较 CTDE 调度、轮询测距与贪婪方差下降在定位误差与能耗上的差异。

背景与动机

室内、地下与遮挡环境的机器人无法依赖卫星定位。协同定位利用机器人之间的测距（超宽带或无线电强度）与少量已知道路的锚点，通过几何约束互相校准位姿。精度取决于测量几何：两台机器人相距过远时，距离测量对相对方位的约束退化；锚点共线时，垂直方向的误差无从消除。决定精度的首要因素是测量集合的几何结构，估计器只能在这一几何允许的范围内逼近下界，这正是克拉美罗下界的意义。

与第 065 章相比，那里在已知相对位姿下融合地图，本章反过来估计位姿本身；两章共享因子图式的约束思维，但本章的观测函数非线性，线性化误差与估计相关性成为主要工程问题。CTDE 的作用对象是测距调度：谁与谁在何时测距，属于离散选择问题，训练期用全局误差协方差评估选择的长期价值。

核心原理

本节建立测距模型、精度下界、分布式融合与调度映射四条线索。

1. 测距模型

超宽带测距输出两机距离 zij = ‖pi − pj‖ + ε，噪声方差近似常数。无线电强度测距按对数距离路径损耗模型：RSSI 随距离对数线性衰减，指数 n 在自由空间取 2、室内常见 2 至 4。强度模型的噪声方差随距离指数增长，远距离测量对定位的贡献迅速贬值，因此调度策略偏好中近距离的邻居。

2. 精度下界与几何

把全部待估位姿记为 θ，测距观测的对数似然在真值处的曲率构成费舍尔信息矩阵。CRLB 给出任何无偏估计的协方差下界。

F = Σ(i,j) JijTΣz−1Jij，Cov(θ̂) ⪰ F−1，Jij = ∂zij/∂θ 对两台机器人的测距，雅可比由各自指向对方的单位向量组成；锚点贡献类似但位置已知

单条测距 J 的行向量形如 (uT, −uT)，u 为两机连线单位向量。多条测距的信息叠加表现为方向约束的叠加：当所有测量方向接近共线时，F 接近奇异，下界发散，这对应"排成一条直线的机器人无法确定整排的法向位置"。几何精度因子（Geometric Dilution of Precision, GDOP）即 √tr(F−1)，可作为调度策略的状态特征。

3. 分布式一致性滤波与相关性

每台机器人用扩展卡尔曼滤波（Extended Kalman Filter, EKF）维护自身位姿与协方差：预测步由运动模型推进，更新步使用与邻居的测距。分布式版本在更新后追加一致性步，把邻居的位姿估计按权重平均进自己的状态。共享测量引发相关性：两台机器人若使用同一条测距更新，其误差不再独立，后续融合再按独立假设处理会低估方差，产生过度自信。缓解手段是拆分信息（split information）或协方差交叉式的折扣融合。

4. CTDE 与测距调度

能量与带宽限制使机器人无法与所有邻居同时测距。观测含自身协方差特征（特征值、GDOP）、邻居方向与相对距离、剩余能量；动作是从邻居集合中选择一个子集；奖励为定位误差的下降（用迹或行列式度量）减去测距能耗。集中式评论家输入全部机器人的协方差与测量图，评价调度的团队效果。

测距子集选择是带基数约束的集合函数优化：以对数行列式为度量时信息增益单调且次模，预算约束下的贪心选择具有 (1−1/e) 近似保证，可作为调度基线；以协方差迹为度量时次模性没有通用保证，需按几何实例校验贪心比后再决定基线资格。学习策略的增量价值在于把几何时变与未来回报纳入选择，覆盖单步贪心看不到的长时收益。

5. 数值算例：锚点几何与精度下界

设测距噪声标准差 σz=0.1 m，待定位机器人位于原点，仅估计自身二维位置。首先考虑两台锚点位于 (10, 0) 与 (20, 0)，三者共线于 x 轴。

共线情形。每条测距对机器人位置的雅可比方向均为沿 x 轴的单位向量，信息矩阵只有 x 方向分量：Fxx=2/σz2=200，Fyy=0。x 方向标准差下界为 1/√200≈0.071 m，已优于单条测距；y 方向下界发散，法向位置不可观测。

非共线情形。把第二台锚点挪到 (10, 10)，两条测距方向分别为 (1, 0) 与 (1/√2, 1/√2)。信息矩阵变为 F=100×[[1.5, 0.5], [0.5, 0.5]]，求逆后对角元为 0.01 与 0.03，两方向标准差下界约为 0.10 m 与 0.17 m。法向变得可观测，代价是 x 方向下界从 0.071 m 回升到 0.10 m。

解读：几何结构决定精度下界的方向分布，估计器只能逼近而不能突破。调度策略的任务由此明确：优先测量能把信息补充到当前最弱方向上的邻居，策略输入里的协方差特征向量恰好指示了弱方向。GDOP 把这一几何质量压缩为标量，适合作为状态特征，但它掩盖方向信息，需要与特征值配对使用。

推导补充：测量信息为何可以直接叠加。不同时刻的测距噪声在条件独立假设下互不相关，各次测量的信息矩阵按元素相加。这一性质使贪心调度只需比较"新增一条测距给 F 增加的秩一贡献"，不必重解整个估计问题。实践中的多径与时钟漂移会引入相关性，此时信息叠加会高估收益，调度策略需要按测距类型对来自不同设备的测量做折扣，并在审计中对比实际误差下降与预测下降的比值。

设计决策：为什么奖励用协方差迹替代瞬时误差

瞬时定位误差受单次噪声实现影响，方差极大，作为奖励会让策略拟合噪声。协方差迹是估计器自报的不确定性，与真实误差的长期均值高度相关，且不依赖真值，可直接从估计器读出，无需额外真值通道。注意协方差的自报特性也可能被策略利用（选择让滤波器低估方差的测量），审计时应并列监控真实误差。

与第 065 章的差异：状态换成位姿与协方差；动作换成测距对象选择；新增雅可比线性化与一致性折扣两个数值细节。

对比分析：四类定位方案的误差与能耗

方案几何信息利用测距能耗误差行为适用条件

本章 CTDE 调度按信息缺口选择受预算约束收敛更快、方向均衡能量受限、几何时变

信息缺口选择指优先测量能把信息补充到最弱方向的邻居：策略输入含协方差特征向量方向，输出对每个候选邻居打分。复现实验要注意轮询基线的公平性：几何均匀时轮询已接近最优，只有协方差各向异性明显且预算紧张时，调度收益才会显现，仿真初始构型应覆盖这两种情形，并报告最差方向的误差；仅报均方根会掩盖方向失衡。

再补充一个数值注意点：一致性权重 kappa 增大时估计收敛更快，但方差放大项 (1+kappa) 同步抬高协方差的自评水平，融合权重随之变得保守；kappa 过小时自评方差被低估，后续融合过度自信。推荐的标定方法是用已知真值的仿真轨迹扫描 kappa，选择"自评方差与真实误差比值"最接近 1 的取值，该比值在部署中同样可以作为在线监控指标。

关键代码与解读

片段 1：测距雅可比与信息贡献

import numpy as np

def range_jacobian(pi, pj):
    """距离观测对两机位置的雅可比，形状 [2, 4]。
    pi/pj: 两机位置估计，长度 2。
    """
    d = pj - pi
    r = np.linalg.norm(d)
    u = d / max(r, 1e-9)            # 单位指向向量
    J = np.zeros((1, 4))
    # 距离对 pi 的导数沿远离 pj 的方向，对 pj 的导数方向相反
    J[0, :2] = -u
    J[0, 2:] = u
    return J, r

解读：雅可比是 CRLB 计算与 EKF 更新共用的基础量，两机距离对各自位置的梯度只依赖连线方向，与距离本身无关，但信息矩阵中的权重随噪声方差变化。近零距离除零保护是数值必需项：两机重合时方向不可定义，实际系统还需排除过近的无效测量。

片段 2：卡尔曼一致性更新

import numpy as np

def kcf_update(x, P, z, xj, Pj, R, kappa=0.5):
    """一步分布式测距更新加一致性步（标量测距）。
    x/P: 自身状态与协方差；xj/Pj: 邻居估计；R: 测距噪声方差。
    """
    H = range_jacobian(x[:2], xj[:2])[0]
    S = H @ P @ H.T + R                  # 新息协方差
    K = P @ H.T / S                      # 卡尔曼增益
    resid = z - np.linalg.norm(xj[:2] - x[:2])
    x_pred = x + (K * resid).ravel()
    P_pred = (np.eye(len(x)) - K @ H) @ P
    # 一致性步：向邻居估计靠拢，权重 kappa 控制聚合强度
    x_next = x_pred + kappa * (xj - x_pred)
    P_next = P_pred * (1.0 + kappa)      # 方差略放大，抑制过度自信
    return x_next, P_next

解读：新息 resid 用邻居的当前位置估计计算，避免了邻居位姿作为待估变量的联合更新复杂性。一致性步的方差放大 (1+kappa) 是对相关性的保守补偿：共享测量使两机误差相关，按独立假设更新会压小方差，放大项抵消这一偏差。kappa 取值需要与测量图的连接度匹配，连接度高时相关性更强，需要更大的放大系数。

片段 3：邻居注意力调度策略

import torch
import torch.nn as nn

class SchedulePolicy(nn.Module):
    """为每个候选邻居打分，选出测距子集。"""
    def __init__(self, self_dim=6, nb_dim=4, emb=48):
        super().__init__()
        self.self_enc = nn.Linear(self_dim, emb)
        self.nb_enc = nn.Linear(nb_dim, emb)
        self.score = nn.Sequential(nn.Linear(2 * emb, emb), nn.ReLU(),
                                   nn.Linear(emb, 1))

    def forward(self, self_feat, nb_feat, budget_mask):
        s = self.self_enc(self_feat).unsqueeze(1)     # 本机协方差特征
        n = self.nb_enc(nb_feat)                      # 各邻居特征
        pair = torch.cat([s.expand_as(n), n], dim=-1) # 逐邻居拼接对特征
        logits = self.score(pair).squeeze(-1)
        # 候选预算不足或能量低的邻居屏蔽，softmax 后按概率采样子集
        logits = logits.masked_fill(budget_mask, -1e9)
        return torch.softmax(logits, dim=-1)

解读：逐对拼接让打分函数看到"本机当前不确定性"与"该邻居方向"的交互，同样的邻居在不同协方差形态下的价值不同，这种交互无法用固定打分表表达。采样保留了探索性；测距选择具有多臂赌博机的结构，取最大值会让策略固守对某一邻居的偏好。屏蔽同时承担能量约束与链路不可用的处理。

常见坑

  • 线性化点距离估计过远：EKF 在估计误差大时用当前估计线性化，雅可比方向偏差造成更新发散。修复：迭代更新（多次重线性化）或改用无迹变换。
  • 共享测量重复使用：两台机器人用同一条测距互相更新后，再各自与他机融合，误差相关性被忽略。修复：一致性方差放大或拆分信息滤波。
  • 锚点少于三个：全局平移不可观测，协方差迹缓慢增长而误差无界。修复：固定足够锚点，或引入相对坐标系并定期对齐。
  • 调度奖励只看单步方差下降：策略反复测量同一对机器人，边际收益趋零后仍不切换。修复：按边际信息增益（方差下降量）设计奖励，并加入重复测量惩罚。
  • 时间同步误差混入测距：到达时间类测距的时钟偏差被当作距离偏置，定位出现系统性偏移。修复：双向测距协议或把时钟偏差作为状态一并估计。

练习与思考

  1. 三台机器人与两个锚点共线排列于 x 轴，写出测距集合的 F 矩阵并说明哪个方向不可观测。★
    提示
    所有雅可比行向量的 y 分量为零，F 的 y 子块为零矩阵，法向平移不可观测。
  2. 把一致性权重 kappa 从 0.5 调到 0，预测估计误差与协方差自评的变化，说明风险在哪里。★★
    提示
    协方差被低估、估计仍然可信，但自评方差下降过快，后续融合权重失衡，误差可能突然放大。
  3. 推导：对单条测距证明信息矩阵贡献为 (1/σz2)·(uT, −uT)的秩一矩阵，并说明它约束的是相对位移的哪个分量。★★★
    提示
    JTJ/σ² 的外积形式；零空间包含"两机沿垂直方向同向平移"的位移组合，即相对法向分量不可约束。
  4. 设计实验：5 台机器人、2 锚点，预算为每周期 2 次测距，比较轮询、贪婪方差下降与 CTDE 调度在 200 个周期内的位置均方根误差与总测距次数的关系。★★★
    提示
    画误差对能耗的帕累托图；预期贪婪在前 50 周期接近 CTDE，后期因局部最优落后，CTDE 的优势呈现在长时累积误差上。
  5. 机器人位于原点，两个锚点位于 (10, 0) 与 (0, 10)，测距噪声 0.1 m。写出累计信息矩阵 F 并计算两个坐标方向的标准差下界，说明它与共线布点的本质差别。★★
    提示
    两条测距方向分别为 (1,0) 与 (0,1)，F=100×diag(1,1)，两方向标准差下界均为 0.1 m；共线布点使垂直方向的 F 分量缺失，下界发散；可观测性由几何决定，算法无法弥补。

小结

  • 协同定位精度由测量几何决定，CRLB 与 GDOP 提供了不依赖算法的精度标尺。
  • 测距雅可比由连线单位向量构成，共线布置导致信息矩阵奇异，法向不可观测。
  • 分布式一致性滤波用邻居估计更新自身状态，共享测量导致相关性，需方差放大或信息拆分补偿。
  • 测距调度是带预算的离散选择问题，逐对特征打分加采样兼顾表达力与探索；奖励用协方差迹需审计自评偏差。
  • 数值算例说明几何决定下界的方向分布：共线锚点使法向不可观测，非共线锚点把两方向下界拉回 0.1 m 量级，调度策略据此优先补最弱方向。
