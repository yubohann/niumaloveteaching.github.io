第四篇 · 高级机制与研究专题

第 068 章：多智能体协同避障

多台机器人在共享空间中互不碰撞地到达各自目标：本章从碰撞锥与速度障碍（Velocity Obstacle, VO）的几何讲起，经互惠避让半平面到控制屏障函数（Control Barrier Function, CBF），再给出学习策略与安全层的组合设计。

  • 主题：安全导航 / 几何避让与安全约束
  • 关键公式：‖pi(t)−pj(t)‖ ≥ 2r，∀t；ḣ + αh ≥ 0
  • 预计学时：60 分钟
  • 前置章节：第 067 章

学习目标

  • 掌握碰撞锥与速度障碍的几何定义，能从相对速度与连线夹角推出碰撞条件。
  • 理解互惠避让中"各担一半责任"的构造，能写出最优互惠避障（Optimal Reciprocal Collision Avoidance, ORCA）半平面约束并求解最小修正速度。
  • 掌握控制屏障函数的约束形式，说明它相对速度障碍在连续时间安全性上的优势。
  • 能设计"学习策略输出意图速度、安全层做最小修正"的组合结构，并解释安全层的可行性保障条件。
  • 能设计实验比较纯规则避障、纯学习策略与组合结构在到达率、碰撞率与停滞率上的差异。

背景与动机

路径规划分两层：全局层给出路径，局部层负责动态避让。局部避让的困难在于对称僵局：两台机器人正面相遇时，任何单方面的避让决策都可能与对方的同样决策叠加，产生震荡或对峙（deadlock）。几何方法用确定性规则消解这一困难，速度障碍刻画碰撞速度集合，互惠规则把避让责任对半分配，使双方在共享约定下打破对称。

纯几何规则的局限是只保证避碰，不优化任务效率：绕行方向固定、窄通道中的通行顺序僵化、对运动学约束的考虑有限。学习策略能优化长期通行效率，但训练期探索会撞、部署期存在分布外状态。把学习策略负责意图、安全层负责兜底的分工结构作为答案，也是第 080 章约束强化学习的先行机制。

核心原理

本节依次给出碰撞锥几何、互惠半平面、屏障函数约束与学习集成四条线索。

1. 碰撞锥与速度障碍

把机器人简化为半径 r 的圆盘。对机器人 i 与 j，连心距 d = ‖pj − pi‖，膨胀半径 R = ri + rj。若相对速度 vi − vj 的方向落在以连心线为轴、半角 α = arcsin(R/d) 的锥体内，则未来某一时刻两盘必然接触。

VOi|j = { v | ∃t>0：pi + t(v − vj) ∈ D(pj, R) } D 为以 pj 为心、R 为半径的圆盘；VO 是速度空间中需要回避的集合

当 d ≤ R 时膨胀圆盘覆盖原点，任何相对速度都碰撞，对应"已经侵入安全距离"的紧急状态，需要更强的逃逸策略。速度障碍把时间维度的碰撞问题折叠为速度平面上的集合判定，这是它适合实时计算的关键。

2. 互惠避让与半平面约束

ORCA 的构造：对每个邻居取碰撞锥边界上最接近相对速度的点，形成一条速度平面上的半平面约束，要求修正后的相对速度落在半平面内。两个互相可见的机器人各自承担一半修正量，等价于每人把相对速度推离碰撞锥边界至共享的中间位置。

(vnew − vpref)·n ≥ 0，n 为半平面法向；取 ‖vnew − vpref‖ 最小的解 多条约束时求解二次规划；无可行解时按违反度放松约束或启用逃逸模式

互惠性是打破对称僵局的机制：两台机器人同向偏移，总修正量等于单方完全避让的修正量，避免了"双方都退让一半再各退一半"的震荡。半平面集合为空时说明当前密度下无可行速度，需要引入减速或优先级规则。

3. 控制屏障函数

把避碰写成连续时间不变性：定义屏障 hij(p) = ‖pi−pj‖2 − R2，要求 h ≥ 0 恒成立。控制输入需满足 ḣ + αh ≥ 0，即 h 向边界的衰减速度不超过指数率 α，保证状态不穿越边界。CBF 约束与控制目标合成二次规划：

minu ‖u − udes‖2 s.t. 2(pi−pj)T(ui−uj) + αhij ≥ 0，∀j u 为速度级输入，邻居速度按最近观测代入；约束在每个控制周期求解一次，紧邻边界时只有远离方向可行

速度障碍与 CBF 的差别在于约束性质：前者按视界 τ 检查当前速度是否指向未来碰撞，后者要求 ḣ + αh ≥ 0 在连续时间上成立，把接近速度限制为随余量衰减的形式。两种形式都作用在速度层，实际机器人受加速度上限约束，部署时还需检查修正后的速度指令可被跟踪，并确认约束在每个控制周期存在可行解（控制可达性）。

4. 学习策略与安全层的组合

策略网络输出期望速度 vdes，安全层把 vdes 投影到满足全部邻避约束的可行域，投影结果既执行策略意图又保证安全。训练期奖励为到达进度减去碰撞与停滞惩罚，集中式评论家观测全部机器人的位置速度。执行期安全层只依赖本机观测到的邻居状态，是天然的分布式结构。

5. 数值算例：CBF 约束的最小修正

取膨胀半径 R=0.72 m（由 0.6 m 的半径和乘 1.2 膨胀系数得到），CBF 衰减率 α=2.0，把邻居 j 视为静止参照。屏障函数 h=‖pi−pj‖2−R2，当前距离 d=1.0 m 时 h=1−0.518=0.482。

约束 2(pi−pj)T(ui−uj)+αh≥0 在朝向对方接近时化为 2d·v≤αh，其中 v 为接近速度，允许的最大值为 vmax=αh/(2d)=2×0.482/2=0.482 m/s。期望速度取 1.0 m/s 指向对方时，安全层把它压到 0.482 m/s，修正量约为一半。

距离缩到 0.8 m 时 h=0.64−0.518=0.122，vmax=2×0.122/1.6≈0.153 m/s，不足期望值的六分之一。允许速度上限随距离近似线性收紧，安全层据此按距离由近到远排序处理邻居。

解读：膨胀系数需要覆盖感知与执行延迟：延迟越大，约束实际生效时距离越小、允许速度越低，预留裕度必须相应加大。ORCA 的 τ 参数与 CBF 的 α 表达同一件事，τ 越小或 α 越大越保守，两者可通过接近速度上限的等效量级互相换算。

另一个数值事实值得记录：修正量随屏障余量线性变化，把膨胀半径从 0.72 m 提到 0.9 m 后，同样的间距下允许接近速度从 0.482 m/s 降到 0.19 m/s，不足原来的四成，等价于提前约一个身位开始减速。复现实验在对比不同膨胀系数时，应同时报告到达时间中位数的变化，避免只展示安全性改善而掩盖效率代价。

实现思路与设计

三层结构：策略层输出意图速度，安全层求解投影与逃逸，底层执行速度指令。训练在仿真中进行，部署时保留安全层。

设计决策：为什么安全层只在策略之后修正而不接管

安全层接管全部动作会退化为纯规则系统，丢失学习策略的效率优化；完全依赖策略则在罕见状态下无安全保障。最小修正投影保留策略在可行域内的全部意图，只在违反约束的方向上做最小改动，学习信号因此仍能覆盖大部分状态空间。工程上需要监控修正比例：比例长期高说明策略与约束系统性错位，应把安全层状态纳入观测重新训练。

与第 067 章的差异：状态从外部目标换成邻居与本机位姿，动作是速度向量，奖励含强安全惩罚；新增安全层的投影求解与逃逸逻辑。

对比分析：四类避障方案的保证与效率

纯几何规则（ORCA）单步无碰撞（假设互惠）中等，绕行保守内建互惠分解低

选择依据是安全保证的形式与实现成本：投影式速度约束实现简单、按步执行，适合差速底盘；CBF 形式给出连续时间不变性并随余量自动收紧，但要求每个控制周期存在可行解且执行器能跟踪修正后的速度。复现实验应记录安全层修正比例这一诊断量：修正比例长期超过约三成说明策略与约束系统性错位，应把安全层状态纳入观测重新训练；继续加大碰撞惩罚只会掩盖错位。

补充逃逸模式的设计：约束集合为空时，安全层按最大减速加转向生成回退动作，并按邻居碰撞时间由近到远分配减速量。回退动作应记录触发次数与持续时长，长期高频触发说明训练分布缺少高密度场景的样本，应往课程中补充对应密度档位；继续放大惩罚系数并不增加高密度场景的样本。回退动作会改变后续状态分布，训练阶段应允许策略观测到回退后的状态，保持训练与部署的状态一致性。

关键代码与解读

片段 1：碰撞锥判定

import numpy as np

def in_collision_cone(pi, vi, pj, vj, radius_sum):
    """判断相对速度是否落入碰撞锥。
    返回布尔值与最近碰撞时间（无碰撞时为无穷大）。
    """
    dp = pj - pi
    dv = vi - vj
    d = np.linalg.norm(dp)
    if d <= radius_sum:                     # 已侵入安全圆：紧急状态
        return True, 0.0
    # 投影到相对速度方向：p(t)=dp-t*dv 与圆盘的最小距离时刻
    t_star = float(np.dot(dp, dv)) / max(float(dv @ dv), 1e-9)
    if t_star <= 0:
        return False, np.inf               # 正在远离，不会碰撞
    closest = dp - t_star * dv
    hit = np.linalg.norm(closest) < radius_sum
    return hit, t_star if hit else np.inf

解读：判定用"最近接近点"，与碰撞锥等价但数值上更稳定，避免了 arcsin 在临界角附近的病态放大。返回碰撞时间供安全层按紧迫度排序处理邻居。距离已小于膨胀半径时直接返回紧急状态，这条分支在离散仿真中保护穿模场景。

片段 2：ORCA 半平面与最小修正

import numpy as np

def orca_velocity(v_pref, p_self, p_other, v_other, radius_sum,
                  tau=2.0):
    """单邻居的 ORCA 半平面：返回允许速度集合的线性约束 (n, b)。
    约束形式为 n @ v >= b，双方各承担一半修正。
    """
    rel_p = p_other - p_self
    rel_v = v_pref - v_other
    d = np.linalg.norm(rel_p)
    u = rel_p / max(d, 1e-9)
    # 沿连心线的逃逸速度分量：把相对速度推出膨胀圆
    a = rel_v @ u
    b = np.sqrt(max(rel_v @ rel_v - a * a, 0.0))
    factor = np.sqrt(max(d * d - radius_sum * radius_sum, 0.0)) / d
    n = u                                    # 约束法向取连心方向
    allowed = a + (radius_sum / tau - b * factor) * 0.5
    return n, allowed

解读：这一步是 ORCA 的几何核心，系数 0.5 实现"各担一半"的互惠分解：把沿连心线的相对速度推到共享边界。tau 为规划视界，越小越保守。实现中省略了切向分量与圆锥边界的严格投影，用于教学演示；完整实现需要处理投影点在锥角两侧的两种情形。多条邻居约束在 v 平面上求交，空集时按违反度量大小逐条放松。

片段 3：策略意图与安全投影的组合

import numpy as np

def safe_action(v_des, p_self, neighbor_states, radius_sum, v_max=1.5):
    """把策略期望速度投影到可行集合：沿违例方向做最小修正。
    p_self: 本机位置；neighbor_states: 每项为 (p, v) 邻居状态。
    """
    v = np.clip(v_des, -v_max, v_max)
    for (p, vn) in neighbor_states:
        n, b = orca_velocity(v, p_self, p, vn, radius_sum)
        slack = n @ v - b                    # 当前速度的约束违反量
        if slack < 0:
            # 沿法向修正最小距离：v += (-slack) * n
            v = v + (-slack) * n
    # 修正后重新限速：修正量不得放大速度
    return np.clip(v, -v_max, v_max)

解读：逐邻居串行修正是一次投影的近似，复杂度线性于邻居数，满足高频控制周期。修正后重新限速保证物理可行性。串行顺序会引入偏差，与邻居的处理顺序相关；消除顺序影响需要联立所有约束求解二次规划，工程上按碰撞时间从近到远排序已能控制偏差量级。

常见坑

  • 互惠假设被破坏：一方用互惠规则、另一方用单边规则，修正量叠加导致过冲与震荡。修复：统一避让约定，或对未知行为者按非互惠（全责）规则处理。
  • 离散步长过大导致穿透：速度较高时单步位移超过安全圆厚度，连续时间的安全保证失效。修复：步长满足 vmax·dt 小于最小安全裕度，或增加扫掠碰撞检测。
  • 对称僵局的死锁：多机在窄通道口互相等待，停滞惩罚过小时策略选择原地不动。修复：引入通行优先级或随机扰动打破对称，并监控停滞率。
  • 安全层约束全集为空：高密度下所有方向都违反约束，求解器无解。修复：保留"最大减速"回退模式，并降低居住密度或在空间上分层通行。
  • 训练奖励鼓励贴边飞行：贴边节省时间且未碰撞时不受罚，部署中小扰动即引发碰撞。修复：加入与安全裕度相关的连续风险惩罚，而不仅在碰撞时给惩罚。

小结

  • 碰撞锥把时域碰撞判定化为速度平面上的集合问题，最近接近点的数值形式比角度阈值稳定。
  • 互惠避让通过五五分账的修正约定打破对称僵局，半平面约束的公共交集为空时需要减速或优先级回退。
  • 控制屏障函数在速度层保证连续时间安全性，其可行性依赖控制可达性与膨胀半径的合理设置。
  • 组合结构分工明确：意图来自学习、兜底来自几何，修正比例监控两者是否错位。
  • CBF 算例给出修正量级的手算方式：允许接近速度上限约为 αh/(2d)，随距离线性收紧，膨胀系数与衰减率共同决定保守程度。
