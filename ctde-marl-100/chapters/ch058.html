第三篇 · 环境与任务实践

第 058 章：多智能体金融交易

金融交易环境里策略互相影响：报价改变成交概率，成交改变存货，存货改变下一次报价；本章用订单簿模型与存货风险推导做市报价，说明风险约束与非平稳适应的训练方案。

  • 主题：市场环境 / 做市与风险约束
  • 关键公式：r = mid − q · γ · σ2 · ( T − t ) ， 报价 = r ± ( c + k )
  • 预计学时：65 分钟
  • 前置章节：第 057 章 多智能体网络安全防御

学习目标

读完本章，应当能够把做市与交易策略写成存货与风险约束下的序贯决策，并设计抗过拟合的评估流程。

  • 理解订单簿的基本结构：限价单、市价单、价差与成交优先级，能说明做市商的收益来源与风险。
  • 掌握存货风险对报价的影响，能推导保留价格随存货偏移的关系式。
  • 理解市场影响与拥挤交易：策略之间的相互冲击使单智能体假设失效，训练需要多智能体市场模型。
  • 掌握风险约束型奖励的构造：对数收益、回撤惩罚与风险调整指标，理解约束优化在资金管理中的位置。
  • 会设计防止前视偏差与过拟合的评估流程，识别“回测优秀、实盘失效”的常见原因。

背景与动机

交易策略的效果取决于市场中其他参与者的行为，这是金融环境作为多智能体问题的根本原因。

订单驱动市场的运作方式决定了策略之间的耦合：做市商挂出买卖双边报价赚取价差，但成交意味着持仓变化，持仓在价格波动中产生风险；交易者拆分大单以减少冲击，但拆分节奏会被其他参与者识别并抢先；动量策略的群体化会放大趋势并在反转时集中亏损。单智能体视角把价格序列当作外生变量，忽略了策略自身对价格与成交概率的影响，在容量受限的策略上可以近似成立，在涉及报价与主动成交的场景中偏差显著。

多智能体建模把市场写成多个异质参与者的组合：做市商、动量交易者、套利者与噪声交易者各自遵循不同的目标与约束，价格由他们的订单共同决定。强化学习的研究重点是做市与执行：在给定对手行为分布的假设下优化报价与下单节奏，约束是存货与回撤。与上一章的攻防博弈相比，金融市场的收益结构既非纯零和也非协作，交易成本的存在使“零和减去成本”成为多数场景的真实结构；与推荐系统的偏差问题相比，金融数据的非平稳性更强，训练与评估的分布差异更值得警惕。

核心原理

本章原理分四层：订单簿与报价、存货风险下的最优报价、市场影响与拥挤、以及风险约束与评估纪律。

1. 订单簿与做市收益

限价单提供流动性并承担被逆向选择的成本，市价单消耗流动性并支付价差。

spread = bestask − bestbid ， 做市单笔期望收益 = spread/2 − 逆向选择成本 − 交易费用 bestask 为最优卖价；bestbid 为最优买价；逆向选择成本指成交后价格向不利方向运动的平均损失

报价的每一侧都有成交概率与信息成本：买方报价被成交通常发生在市场下行时（对手掌握更差的消息），卖方报价被成交发生在上行时，两侧的系统性损失即逆向选择成本。做市的净利润来自价差覆盖逆向选择与费用后的余量，因此报价宽度必须适应波动率与信息流强度：波动率高时逆向选择成本上升，报价必须放宽。订单簿状态的观测特征包括盘口价量、深度分布与近期成交强度，它们是策略调整报价的基础。

2. 存货风险与保留价格

成交量累积成存货，存货在价格波动中产生方差，最优报价需要补偿该风险。

r( q , t ) = midt − q · γ · σ2 · ( T − t ) ， bid = r( q , t ) − δ ， ask = r( q , t ) + δ q 为存货（正为多头）；γ 为风险厌恶系数；σ 为波动率；T − t 为剩余时间；r 为保留价格（做市商心目中的公平价）；δ 为报价半宽

保留价格公式的含义是：持仓为正时把公平价估计下调，使卖方报价更有竞争力而买方报价更保守，从而推动存货回归；持仓为负时相反。时间项使风险敞口按剩余时间缩放，临近收盘时存货偏移自然收窄。δ 由逆向选择与手续费决定，市场波动大时加宽。强化学习的学习目标可以表述为：在给定对手流量与自身存货的分布下，学习 r 的偏移与 δ 的调整，学到的策略在效果上逼近该解析规则，并在流量预测更精细时超过它。

存货偏移的量级可以代入核对：存货 5 个单位、风险厌恶系数 0.1、每步波动率 0.02、剩余 10 步时，相对偏移为 −0.1 × 5 × 0.022 × 10 = −0.002；价格量纲为 100 时换算成约 −0.2 个价格单位。偏移方向随存货符号反转，大小与风险厌恶、波动率平方、剩余时间三个因子成正比，任何一项增大都让做市商更急切地削减存货。数值与单步逆选择损失比较后可以判断偏移是否过大：偏移接近价差半宽时报价单侧失去竞争力，成交概率归零，这一边界在参数标定中作为上限约束。

3. 市场影响与拥挤交易

大额订单会推动价格，策略的预期收益必须扣除自身冲击。

impact ≈ Y · σ · √( Q / V ) ， 执行成本 = Σk [ impactk + spreadk/2 ] · qk Q 为订单规模；V 为日均成交量；Y 为比例常数；平方根形式为经验规律；执行成本按子单累加

平方根律说明冲击随规模增长但递减：规模翻四倍，冲击约翻一倍。执行算法把大单拆成子单，在冲击成本与时间风险（价格漂移）之间取平衡。拥挤交易是市场层面的反馈：多个策略使用相似信号时，它们同时建仓推高价格、同时减仓放大跌幅，个体回测中的收益包含了对其他同行的“抽取”，在容量扩大后消失。多智能体仿真可以显式构造这种拥挤：让若干策略共享部分信号，观察策略收益随同类数量增加而衰减的曲线，这与策略容量评估的直觉一致。

平方根律的量级可以手算：订单规模为日均成交量的十分之一时，√0.1 ≈ 0.32，冲击约为波动率的 32%；规模降到百分之一时，√0.01 = 0.1，冲击比例降到 10%，为原来的约三分之一。总冲击与子单数量的平方根成反比，把一笔大单拆成 10 笔时总冲击约降到三分之一；时间风险则随拆分数线性上升，两者的平衡点随波动率与紧迫度移动。执行算法的拆分表由这两个量共同标定；固定单一拆分数量会让冲击成本与时间风险在制度变化时失衡。

4. 非平稳、制度切换与适应

波动率与相关性随时间变化，训练分布与评估分布的一致性只能近似保证。

波动率聚集意味着大波动之后仍是大波动，制度切换（例如从低波动到高波动）使最优参数发生跳变。应对方式有三层：观测中加入波动率估计与制度标签，让策略条件化；奖励与仓位按波动率缩放（波动率目标化），使风险敞口稳定；训练数据跨越多种制度并评估各制度的子样本表现。在线自适应则通过短期窗口的再估计或元学习实现，代价是引入额外的估计误差与换手率。评估的纪律性在金融任务中格外重要：训练、验证与测试按时间切分且不可重叠，任何用到未来信息的特征工程都会造成前视偏差，任何在同一段数据上反复调参的行为都会造成过拟合。

5. 风险约束与奖励设计

收益最大化必须与风险约束同时进行，单看收益的策略在极端行情下会放大损失。

奖励：rt = log( Wt+1 / Wt ) − λdd · max( 0 , DDt − DDmax ) − c · | Δposition | ， 指标：Sharpe = E[ r ] / σ( r ) · √N W 为账户净值；DD 为回撤；Δposition 为仓位变化（换手）；Sharpe 为风险调整收益年化形式；λdd 为回撤惩罚权重

对数收益具有可加性且与财富规模无关，是单期效用最大化的自然形式（凯利准则的近似）。回撤惩罚只在超过容忍阈值时生效，属于单边惩罚，避免对正常波动施加压力。换手惩罚抑制高频调整，与真实交易成本对应。评估使用夏普比率等风险调整指标，并同时报告最大回撤与换手率；只看收益率会选中高杠杆高波动的策略，这项教训在所有风险敏感任务中通用。

实现思路与设计

实现采用轻量订单簿仿真：限价单撮合、市价单消耗深度、价格由成交与外部噪声共同驱动，多个异质对手参与。

1. 环境循环

每步：外部噪声给出一个冲击价格；各智能体提交限价单与市价单；订单簿撮合与部分成交；价格按净成交压力调整；结算持仓与费用；返回观测与奖励。对手集合包含噪声交易者、动量交易者与一个规则做市商，训练时可切换构成比例。

3. 网络结构与训练要点

做市策略网络的输入为订单簿特征（多档盘口、深度、近期成交）、自身存货、未成交挂单与波动率估计；输出为买卖报价偏移与数量的连续参数（正态分布的均值与标准差），动作空间取报价偏移量，直接输出绝对价格会失去可解释性。训练使用历史数据生成对手行为的分布，对手池包含不同激进度与信息质量的交易者。评估按时间顺序切分：训练段、验证段、测试段互不重叠，并在测试段的多个制度窗口上分别报告指标。

4. 与第 057 章的差异点

防御博弈的收益近似零和，策略目标是降低最坏损失；金融环境中交易成本与风险约束是主要结构，收益目标以风险调整后的增长衡量。防御任务的动作空间是离散的巡检与隔离，金融任务的动作是连续报价与数量参数。两章共享的纪律是评估分层与对手多样：防御按对手风格分层，金融按制度窗口分层；两者都强调最坏情形与平均值同时报告。

关键代码与解读

三段代码分别实现订单撮合、存货调整报价与风险约束奖励。

片段 1：限价单撮合

import numpy as np

def match_orders(bids, asks, market_bid, market_ask):
    """简化撮合：价格优先、时间优先，返回成交明细。"""
    fills = []
    # 卖单价不高于对手买价即可成交，按价格从低到高处理
    for price, size, owner, t in sorted(asks, key=lambda x: (x[0], x[3])):
        for i, (bp, bs, bo, bt) in enumerate(sorted(bids, key=lambda x: (-x[0], x[3]))):
            if price > bp or bs <= 0 or size <= 0:
                continue                     # 价格不满足或数量耗尽则跳过
            qty = min(size, bs)
            fills.append({"price": price, "qty": qty, "buyer": bo, "seller": owner})
            size -= qty
            bids[i] = (bp, bs - qty, bo, bt)  # 更新剩余数量，时间戳保留
    return fills

解读：撮合按价格优先、时间优先的交易所惯例实现，排序键的第一个元素是价格、第二个是提交时间。内层循环遍历更新后的买盘列表，未成交部分保留在簿中等待后续撮合。成交价取卖方报价（价格优先规则下被动方受益），这一细节影响做市的现金流，测试用例应覆盖“买卖价交叉”与“部分成交”两类边界。函数只返回成交明细，账户修改由独立的结算模块承担，便于审计与单元测试。

片段 2：存货调整的报价

def quote_with_inventory(mid, inventory, sigma, horizon_left,
                        gamma=0.1, half=0.02, max_skew=0.05):
    """保留价格加价差：存货越多，卖价更积极、买价更保守。"""
    # 保留价格：存货按风险厌恶与剩余时间偏移公平价
    skew = np.clip(-gamma * inventory * sigma ** 2 * horizon_left * 100.0,
                   -max_skew, max_skew)
    reservation = mid + skew
    # 报价围绕保留价格对称展开，随后按最小报价单位取整
    bid = round(reservation - half, 4)
    ask = round(reservation + half, 4)
    # 买卖价必须保持合理间距，避免自成交
    if ask - bid < half:
        ask = bid + half
    return bid, ask, reservation

解读：skew 的计算包含风险厌恶、存货与剩余时间三个因子，比例系数 100.0 用于把典型参数缩放到可视范围内，该系数属于实现细节，与理论常数无关。偏移量被裁剪到 max_skew，防止极端存货下的报价远离市场造成不成交。报价围绕保留价格对称展开，保持买卖价差不随存货变化，符合存货管理的直觉（调整的是报价中心，价差宽度不变）。自成交保护（最小间距）在仿真撮合中必须显式检查，真实交易所同样有此规则。返回的保留价格用于诊断：策略学到的偏移应与解析公式近似一致。

片段 3：风险约束奖励

class RiskAdjustedReward:
    """对数收益 + 回撤单边惩罚 + 换手惩罚。"""
    def __init__(self, w_dd=0.5, w_turn=0.001, dd_limit=0.1):
        self.w_dd, self.w_turn, self.dd_limit = w_dd, w_turn, dd_limit
        self.peak = 1.0

    def __call__(self, wealth_prev, wealth_now, position_delta):
        # 对数收益：对财富规模中性，避免大额收益获得不成比例的奖励
        r = float(np.log(max(wealth_now, 1e-9) / max(wealth_prev, 1e-9)))
        self.peak = max(self.peak, wealth_now)
        drawdown = 1.0 - wealth_now / self.peak      # 相对历史高点的回撤
        # 单边惩罚：只有超过容忍阈值的部分才扣分
        r -= self.w_dd * max(0.0, drawdown - self.dd_limit)
        r -= self.w_turn * abs(position_delta)       # 换手成本
        return r, {"drawdown": drawdown, "log_ret": r + self.w_dd * max(0.0, drawdown - self.dd_limit) + self.w_turn * abs(position_delta)}

解读：对数收益保证不同财富水平下的可比性，也保证连续多期的可加性。峰值财富在类中维护，回撤按相对当前峰值计算，跨回合需要重置，否则上一段的峰值会压低下一段的度量。单边惩罚保留正常波动空间，惩罚只在超过 dd_limit 时生效。信息字典同时返回原始对数收益（加回换手项），便于把风险项与收益项分离归因。该奖励在多个任务中通用：任何带资金与回撤概念的任务（能源调度、库存管理）都能复用其结构。

常见坑

  • 忽略交易成本与滑点：回测中使用中间价成交，真实执行的价差与费用被忽略。症状是换手率极高的策略显示为正收益。修复：撮合按对手价成交并计入费用，奖励加入换手惩罚。
  • 前视偏差：特征使用了未来信息（例如当步收盘价预测当步），回测表现异常好。修复：严格按时间对齐，特征只由决策时刻之前的数据构造，评估采用滚动窗口。
  • 奖励用原始收益：仓位规模直接影响回报，策略倾向放大杠杆。症状是收益与回撤同步放大。修复：使用对数收益与风险调整指标；仓位由风险预算决定，奖励负责收益侧信号。
  • 单智能体市场假设：忽略自身订单对价格与成交的影响，策略容量被高估。修复：在多智能体仿真中让所有参与者提交订单并共同定价，评估拥挤敏感性。
  • 训练与评估同段数据：反复在同段数据上调参，测试集失去意义。修复：数据按时间三段切分，验证段用于选择，测试段只评估一次并记录。

    比例与规模的平方根成正比，规模从 0.1 降到 0.01 时冲击比例约降为原来的三分之一。这一递减规律是拆单执行的基本依据。
  3. 改参数并预测：把回撤惩罚权重从 0.5 提高到 2.0，预测平均收益、最大回撤与换手率的变化方向，并说明何时会出现过度保守。★★
    提示
    回撤权重提高后最大回撤下降、平均收益下降、换手率下降。当权重足够大时策略收缩仓位并不再承担必要的风险，夏普比率同步下降，这即为过度保守的表现。
  4. 设计题：构造一个含拥挤效应的多智能体市场模型，说明如何度量策略收益随同类数量增加的衰减，并给出评估容量的方法。★★★
    提示
    让多个策略共享部分信号并各自独立下单，价格由净压力驱动。扫描同类策略数量并统计单位容量收益，收益衰减到零对应的规模即为容量估计，需要固定随机种子与对手构成。
  5. 实验设计：设计一套防前视与防过拟合的评估流程，说明数据切分、调参协议与报告方式。★★★
    提示

小结

  • 订单驱动市场中做市收益等于价差减逆向选择成本与费用，报价宽度随波动率与信息流强度调整。
  • 存货风险让保留价格随持仓偏移，偏移量与风险厌恶、方差、剩余时间成正比，该解析式为学习策略提供了结构化先验。
  • 市场冲击按平方根律增长，拥挤交易使个体收益随同类策略数量衰减，评估需要多智能体市场模型与容量分析。
  • 奖励使用对数收益并叠加回撤与换手的单边惩罚，评估用风险调整指标，数据切分与调参协议保证结论可信。
