第 071 章：模仿学习与CTDE结合

先用示范数据把策略带到专家水平附近，再用环境交互精调：本章先讲清行为克隆（Behavior Cloning, BC）与数据集聚合（Dataset Aggregation, DAgger）的目标函数与分布偏移问题，再给出与集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）结合的训练配方与实验设计。

  • 主题：示范驱动的初始化 / 分布偏移与联合训练
  • 关键公式：LBC = −E(o,a)~D[log πθ(a|o)]
  • 预计学时：60 分钟
  • 前置章节：第 070 章

学习目标

  • 掌握行为克隆的目标函数与求解方式，能说明它作为监督学习问题的适用条件与失效条件。
  • 理解分布偏移（distribution shift）导致的复合误差，掌握误差随回合长度平方增长的直观推导。
  • 掌握 DAgger 的数据集聚合流程，说明在线专家标注在何时值得其成本。
  • 能设计"示范损失加时序差分损失"的联合目标，解释权重退火与评论家初始化对训练的作用。
  • 能独立设计结合实验：基线选择、消融设置与评价指标，覆盖样本效率与策略质量两个维度。

背景与动机

多智能体任务常具备可用的先验：人工撰写的规则策略、历史系统日志、仿真中调试好的脚本都能提供示范轨迹。从零开始的强化学习在稀疏奖励下需要大量交互，用示范数据初始化可以显著缩短冷启动阶段。模仿学习的核心风险是分布偏移：策略在训练分布外的状态上误差增大，误差又改变后续状态分布，形成自我强化的偏离。

多智能体场景加剧这一问题：策略的下一状态由所有智能体的联合动作决定，任一队友偏离示范行为，其余智能体面对的输入分布即发生变化，训练分布与实际分布的分歧以联合方式放大。与单独使用 BC 或单独使用强化学习相比，结合方案让评论家在训练期提供环境真实回报信号，把示范的质量与环境的真实目标统一到一个目标函数里。

核心原理

本节先讲模仿学习的定义、目标函数与求解方式，再给出与 CTDE 的四个结合点。

1. 模仿学习：定义与目标

模仿学习研究"从示范中恢复策略"：给定专家数据集 D = {(ot, at)}，寻找参数 θ 使策略在示范动作上的似然最大。行为克隆把它化为监督分类，目标函数为负对数似然。DAgger 在此基础上迭代：用当前策略采集状态，请专家在这些状态上标注动作，扩充数据集后重训，使训练分布逐步逼近策略自身的状态分布。

LBC(θ) = −E(o,a)~D[ log πθ(a|o) ] 离散动作为交叉熵，连续动作为高斯负对数似然；DAgger 把 D 替换为沿线策略状态分布的聚合集

2. 分布偏移的量化

设单步误差概率为 ε，回合长度 T。若每次偏离后无法回到示范分布，回合内期望错误数按 O(εT2) 增长；若策略具备纠偏能力（误差指数衰减），界收紧为 O(εT)。把这一结论放到多智能体系统，队友行为引入额外的分布扰动，T 的有效值被联合决策链拉长，平方界更接近实际情况。这解释了为何纯 BC 在多机任务上的退化通常快于单机任务。

3. 与 CTDE 的结合点

第一，用集中式评论家为示范提供价值基线：BC 只模仿动作，价值网络同时评估该动作的长期收益，两者互补。第二，联合损失 L = LTD + λtLBC，λt 随训练退火，训练早期依赖示范稳定探索，后期允许超越示范质量。第三，示范数据参与评论家预热：在环境交互开始前用示范轨迹预训练价值网络，缓解冷启动的自举偏差。第四，针对多智能体的信用问题，可用集中式评论家对示范动作做优势过滤，只保留正优势样本参与模仿，剔除队友失误造成的坏演示。

L(θ, φ) = LTD(φ) + λtLBC(θ)，λt = λ0·max(0, 1 − t/Tdecay) TD 损失训练评论家并驱动策略改进；λ 退火到零后训练等效于常规 CTDE 算法

4. 求解方式与数据要求

BC 阶段是标准监督学习，规模由示范样本数决定；DAgger 阶段需要专家访问（人或规则）与策略交互交替进行，迭代轮数与每轮采集状态数为两个关键参数。工程上先用离线示范完成预训练，再进入环境交互微调，可避免在线专家不可得时的阻塞。

5. 数值算例：误差界、联合一致率与退火表

取单步错误概率 ε=0.05、回合长度 T=50。策略具备纠偏能力时，回合内期望错误数按 O(εT) 估计约 2.5 次；错误使状态偏离示范分布且无法回归时，最坏界按 O(εT2) 估计约 125 次。两界的比值约 T=50，说明纠偏能力带来的差异属于数量级层面，按百分比调参无法跨越两界的差距。

推导思路。把偏离视为吸收事件：偏离后状态分布与示范分布的距离按固定速率放大，第 t 步仍处于偏离的概率以 εt 为上界，回合内累计期望错误数为离散和，最坏量级为 εT2。推导假设了最坏情形；实际策略若能在若干步内重新对齐示范分布，误差回落为线性界。两界的差距全部来自"偏离后能否回归"这一条性质。

多机放大算例。两条策略各自单步一致率 0.95 时，联合一致率为 0.952=0.9025，联合错误概率约 0.0975，接近单机错误概率 0.05 的两倍。队友增至 4 个时联合一致率约 0.815，联合错误概率升到约 0.185。联合偏离的频率随队友数上升，这解释了多机示范数据的覆盖要求比单机更严。

退火表。λt=max(0, 1−t/3e5)：训练到 1e5 步时 λ=0.667，2e5 步时 0.333，2.5e5 步时 0.167，3e5 步归零。退火以环境步数计量；若在平台期提前归零，策略在探索能力成型前失去引导，回报曲线表现为先升后降再缓慢恢复。

把两个界与联合放大合起来看，多机模仿的性能衰减有三个独立来源：单步误差水平、纠偏能力与队友数量。示范数据与评论家预热的投入应优先改善后两项，单纯提高示范动作一致率的边际收益递减最快。

实现思路与设计

训练分三段：示范预热（BC 单独训练）→ 联合训练（TD 加退火 BC）→ 纯 RL 微调。三段共享网络结构，仅损失权重变化。

超参数默认值作用取值依据
示范回合数100 至 300预热数据量以覆盖状态分布的密度为准，与轨迹长度无关
预热轮数2000 梯度步BC 收敛以验证集动作一致率不再上升为界
BC 权重 λ01.0早期模仿强度与 TD 损失量级对齐后统一缩放

学习率1e-3（预热期）监督学习步长联合训练后降到 5e-4
评论家预热500 梯度步降低自举偏差用示范轨迹的回报拟合

实验设计

  1. 对比基线：独立 BC（每智能体单独监督，无联合训练）、从零 RL、BC 加固定权重（不退火）。
  2. 消融设置：去掉评论家预热、去掉优势过滤、λ 退火改为常数、示范数据减半，共四组。
  3. 评价指标：达到目标回报所需的交互步数（样本效率）、最终回报、示范状态集的平均动作一致率、分布外状态的回报衰减幅度。
  4. 统计方式：每配置至少 5 个随机种子，报告均值的置信区间；单次运行曲线不足以支撑结论。
设计决策：为什么 λ 必须退火而不能固定

固定权重使策略被示范分布持续牵引，最优示范与最优策略存在差距时，最终性能被示范封顶。退火让示范的约束随时间释放，策略可以聚焦在环境真实回报更高的行为模式上。退火过快的风险是策略在尚未学会自主探索时失去引导，表现为回报先升后骤降；退火跨度按回报曲线的稳定段长度校准。

与第 070 章的差异：上一章优化训练系统的分布式结构，本章改变信息来源：从环境交互扩展到示范数据，训练目标新增监督分量。

对比分析：四类训练起点的取舍

方案数据需求分布偏移风险性能上限适用条件
纯行为克隆固定示范集高（本讲主议题）受示范封顶示范质量高、任务时程短
DAgger示范加在线专家标注低（分布被拉回）接近示范专家可在线访问
联合损失（BC 加 TD）示范加环境交互中（退火控制）可超过示范环境可仿真
纯强化学习仅交互不适用理论最优奖励密集或探索可行

选择依据是两类资源的可得性：专家标注便宜而交互昂贵时选 DAgger；交互便宜而专家只存在于离线数据时选联合损失并退火。复现实验应对四类方案使用同一评估门槛，报告达到门槛的交互步数与终值两类指标，单一指标会把起步快与上限高混为一谈。

示范规模的选择以状态覆盖密度为依据：按观测空间聚类划分区域，要求策略可能到达的每个区域都有一定数量样本。覆盖不足的区域在联合训练早期表现为高方差与动作摆动，此时补充示范比调大 λ 更有效。优势过滤的参考数值：四条示范样本优势为 [2.5, 0.8, −0.4, 1.2] 时，阈值取 0 保留三条丢弃一条；阈值随训练推进逐步收紧，过滤强度与样本量下降之间的权衡由验证集动作一致率监控。

关键代码与解读

片段 1：共享编码的行为克隆损失

import torch
import torch.nn as nn

def bc_loss(policy, obs, act, agent_ids):
    """行为克隆损失：按智能体索引取对应策略头。
    obs: [批, 观测维]；act: [批]；agent_ids: [批] 智能体编号。
    """
    logits_all = policy(obs)          # 每个样本对全部智能体头的输出
    # 按编号收集：同一条示范只训练做出该动作的智能体头
    logits = logits_all[torch.arange(len(obs)), agent_ids]
    return nn.functional.cross_entropy(logits, act)

解读：共享编码器提取通用特征，各智能体保留独立输出头，按样本索引收集对应头是参数共享下最容易写错的一步。若把全部头的损失都计入，未做动作的智能体也会被训练，示范信号被稀释。连续动作场景替换为高斯负对数似然，均值与标准差两个头都要接入损失。

片段 2：DAgger 聚合循环骨架

def dagger_round(policy, env, expert, dataset, steps=1000):
    """一轮 DAgger：用当前策略跑，专家为访问到的状态标注动作。"""
    obs = env.reset()
    new_samples = []
    for _ in range(steps):
        # 策略动作带探索噪声：需要覆盖策略偏离示范后的状态
        act = policy.act_with_noise(obs, eps=0.1)
        label = expert.act(obs)        # 专家在同一状态给出标注
        new_samples.append((obs, label))
        obs, _, done = env.step(act, demo_mode=True)
        if done:
            obs = env.reset()
    # 聚合：旧数据不丢弃，防止策略回退时数据分布空洞
    dataset.extend(new_samples)
    policy.fit(dataset)                 # 重新训练到验证一致率平台
    return policy

解读：demo_mode=True 表示演示环境中其余智能体按固定规则执行，把多智能体非平稳性隔离在数据采集之外，否则标注状态分布被队友的随机行为污染。旧数据保留是 DAgger 的收敛保证来源。工程上把专家标注批量异步生成，训练与采集重叠执行可减少等待。

片段 3：联合损失与权重退火

import torch

def joint_loss(td_loss, policy, obs, act, agent_ids, lam):
    """时序差分损失与行为克隆损失的加权组合。"""
    l_bc = bc_loss(policy, obs, act, agent_ids)
    # 退火到零时只剩 TD 分量，训练回到标准 CTDE 流程
    total = td_loss + lam * l_bc
    # 两分量比值用于诊断失衡：偏离 1 个数量级即需要重标权重
    ratio = float((lam * l_bc.detach()).abs() / (td_loss.abs() + 1e-8))
    return total, {"td": float(td_loss), "bc": float(l_bc.detach()),
                   "ratio": ratio}

解读：返回分项损失供监控，两分量量级失衡是结合训练最常见的故障，必须在标量化的同一尺度上核对。lam 由外部调度器按环境步数线性退火，调度器与优化器解耦便于复现实验。BC 分量在 lam 归零后从计算图中移除可节省一次前向，规模较大时值得实现条件分支。

常见坑

  • 示范状态分布过窄：专家轨迹只覆盖理想情形，策略进入干扰状态后一致率骤降。修复：采集含扰动与失败恢复的示范，或直接使用 DAgger。
  • BC 与 TD 损失量级失衡：交叉熵量级远大于时序差分误差，退火前策略被监督项主导。修复：标准化两分量，或按目标量级设置 λ0。
  • 队友行为未建模：把多机示范当作独立单机数据，策略无法处理队友偏离。修复：观测中保留队友特征，用集中式评论家做优势过滤。
  • 专家标注泄漏未来信息：标注函数使用了策略不可见的全局状态，学习者无法复现示范。修复：标注接口与执行观测对齐，审计一致率上限。
  • 只报告训练回报：结合方案的收益常体现在样本效率，终值差异较小，单一指标看不出优势。修复：报告达到给定回报门槛的步数与终值两类指标。

练习与思考

  1. 单步误差 ε=0.02、回合长度 50，分别按 O(εT) 与 O(εT²) 估算回合内期望错误数，说明两界的适用差异。★
    提示
    线性界约 1 次，平方界约 50 次；纠偏能力的差别来自"偏离后能否回到示范分布"。
  2. 把 λ 退火跨度从 3e5 步缩到 5e4 步，预测回报曲线的形状变化与可能出现的故障。★★
    提示
    退火过快时策略在探索能力成型前失去引导，回报先升后降再缓慢恢复；对照曲线可定位拐点。
  3. 设计一组消融实验，验证"评论家预热"对早期回报稳定性的贡献，写出对照、指标与预期结论。★★★
    提示
    对照组取消预热；指标取前 1e5 步的回报方差与首达门槛步数；预期预热组方差显著更低。
  4. 分析：若示范来自旧版本系统的脚本策略、且队友行为与当前版本不同，BC 预训练为何仍有价值？给出两个可检验的假设。★★★
    提示
    假设一：个体技能（如避障、对准）跨版本可迁移；假设二：评论家预热只需回报量级信息；两者分别用冻结编码器迁移实验与评论家误差曲线检验。
  5. 两条策略单步一致率各 0.95，计算联合一致率与联合错误概率；队友数升到 4 时重复计算，并说明示范数据覆盖要求的变化。★★

小结

  • 行为克隆把策略学习化为监督分类，分布偏移使误差在回合内按长度平方级累积，多智能体队友行为加剧这一效应。
  • DAgger 用策略访问的状态扩充数据集，把训练分布拉回策略自身分布，代价是专家访问成本。
  • 与 CTDE 的结合点是联合损失、评论家预热与示范的优势过滤；权重退火让策略最终超越示范水平。
  • 实验设计要覆盖样本效率与终值两类指标，并以多种子统计区分真实差异与随机波动。
  • 误差界的数值对比揭示纠偏能力是数量级因素：线性界与平方界相差约 T 倍，多机联合一致率随队友数指数下降，示范覆盖与评论家预热优先改善这两项。
