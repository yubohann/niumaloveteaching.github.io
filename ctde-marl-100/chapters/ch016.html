第一篇 · CTDE 基础与核心算法

第 016 章：图神经网络通信

把通信结构写成图：智能体是节点，可通信或邻近关系是边，消息沿边传递、节点用门控循环单元更新。图神经网络（Graph Neural Network, GNN）给消息传递装上结构先验，把全连接的注意力聚合稀疏化为受邻接约束的局部聚合。本章实现动态图构造、消息函数与多轮传递，并对照注意力路线。

  • 主题：消息传递 / 动态通信图
  • 关键公式：mi = Σj∈N(i) fe( hi, hj, eij )， hi′ = GRU( hi, mi )
  • 预计学时：55 分钟
  • 前置章节：第 015 章

学习目标

  • 理解图结构先验对通信与协调的作用：稀疏化计算、支持局部交互归纳偏置、与注意力结构的家族关系。
  • 掌握消息传递框架的三个部件：消息函数、置换不变的聚合、带时序记忆的节点更新。
  • 掌握动态图构造（距离阈值、可学习边）与边特征设计，理解训练与执行的一致性原则。
  • 会实现一步消息传递模块、邻接矩阵构造与掩码，并与第 015 章的注意力评论家做受控对照。
  • 理解通信轮数与感受野的关系、消息维度与计算代价的取舍，为第 017 章的带宽受限设定建立接口。

背景与动机

第 015 章的注意力评论家可以看作一张完全图上的加权消息传递：每个智能体对全部队友分配注意力权重。完全图没有错，但它缺了两个现实世界的结构：交互常常是局部的（协同搬运、编队、覆盖都依赖空间邻域），通信成本随连接数增长。把"谁与谁可以交流"写成图，既省计算，也把"局部交互"这一归纳偏置注入模型。

图神经网络（Graph Neural Network, GNN）提供消息传递的一般框架：节点携带隐藏状态，边传递由两端状态与边特征生成的消息，节点聚合消息后更新状态。三个部件各有讲究：消息函数决定"传什么"，聚合函数决定"怎么合并"（必须置换不变），节点更新决定"如何记住"（门控循环单元让智能体跨决策步保持信息，这与第 018 章的部分可观测记忆是同一条技术路线）。图结构可以是环境给定的（距离阈值、感知范围），也可以是学习出来的（边门控），动态图让连边随状态演化。本章在仿真环境内实现全部内容，通信被允许发生在每一次决策步内，带宽约束留到第 017 章处理。

核心原理

本节给出从注意力到图的形式对照、消息传递框架的数学形式、动态图与边特征，以及与执行期的接口约定。

1. 从注意力权重到邻接矩阵

注意力权重矩阵与图邻接矩阵的关系可以由一个稀疏化操作连接：

Aij = 1[ j ∈ N(i) ]， 硬邻接由距离阈值或学习门控给出； αij = Aij · softmaxj( 相似度 ) / Σj′ Aij′·… 注意力是"加权完全图", 硬邻接是"0/1 稀疏图"; 两者可以叠加成"邻域内再做注意力"。计算复杂度从 O(N²) 降为 O(E), E 为边数

邻域定义的三种来源，按先验强度排序：环境给定（例如感知范围 r 内的智能体可见）、先验规则（同队、同类型才连通）、完全学习（门控网络输出边存在概率）。选择哪一档取决于任务：局部交互任务用距离阈值即可获得强先验；关系不依赖空间的任务把边交给学习，但需要额外的稀疏化正则或采样维持 O(E) 的规模。

2. 消息传递框架

一层消息传递对每个节点 i 执行三步：

消息： mij = fe( hi, hj, eij )，j ∈ N(i)； 聚合： mi = ⊕j∈N(i) mij； 更新： hi′ = fu( hi, mi ) ⊕ 取求和、均值或最大, 三者都满足置换不变；fe 为共享的消息网络; fu 取门控循环单元 用于承载历史。孤立节点（无邻居）的消息定义为零向量

三点解读：（1）共享消息函数意味着"处理关系的方式"与节点身份无关，参数量与 N 无关，泛化到新队伍规模；（2）聚合的置换不变性保证输出与邻居顺序无关，论证与第 015 章注意力相同；（3）多轮传递 K 轮后，节点感受野扩展为 K 跳邻域，信息传播距离随轮数线性增长。每轮传递对应一个"通信周期"，轮数与通信量成正比，是第一个要权衡的旋钮。

3. 动态图与边特征

图随状态变化是协作任务的常态：编队队形变化改变邻接、障碍物改变可见性。动态图的实现有两种主流方式：

  • 确定性重算。每步用环境给出的相对位置与阈值重新计算邻接，代价 O(N²) 但可无梯度地高效向量化；图的变化轨迹可解释、可测试。
  • 学习式门控。边存在概率由两端状态经小型网络输出，训练时用松弛（Gumbel 采样或软门控）保持可导，推理时取阈值；代价是训练不稳定需要正则，第 017 章的信道门控沿用同一技术。

边特征 eij 承载关系本身的先验：相对位移与距离（空间任务）、可见性标志、通信质量。把距离显式放进消息函数，相当于告诉网络"多远"这一物理量，省去网络从坐标差值中重新拟合的负担。边特征缺省的对照实验常用于验证"显式关系量是否值得进入模型"。

4. 训练与执行的一致性

图通信模块在两条通路中的位置需要明确定义。若执行期允许通信（本课程此阶段的默认设定），策略网络本身可以包含消息传递：执行时每个智能体按同一图协议收发消息，隐藏状态逐决策步更新。若执行期禁止通信，图模块只能出现在训练期评论家中，用于生成更准确的全局信息表示；两种口径下的输入信息集合不同，必须在实验记录中声明，否则对照失去意义。图的计算必须只使用执行期可获得的信息：距离若来自环境的全局坐标广播，则需要确认该广播在部署协议中存在，或改用相对估计。

5. 数值算例：一维链上的感受野与消息量

取 10 个智能体排成一条链（相邻位置距离在阈值内），无向边 9 条，有向边 18 条。每步消息条数等于有向边数乘以轮数 K，感受野为 2K + 1 个节点（含自身），数值经程序核对：

传递轮数 K感受野（链上节点数）每步消息条数（18×K）是否覆盖全链
1318否，链径为 9
2536否
4972否，端点尚差一跳
919（受链长限制为 10）162是，K 等于图的直径

读表要点：感受野按每轮一跳扩展，达到全连通所需轮数等于图的直径（链上为 N − 1 = 9）；消息量随 K 线性增长。任务只需两跳协调时，K = 2 的 36 条消息与 K = 9 的 162 条之间存在 4.5 倍通信差，而多余的高跳信息对决策通常没有增量。轮数上限的估法：用环境交互半径除以典型间距得到所需跳数，取该值加一作为 K 的搜索上界。

6. 数值算例：一次邻接构造的完整核对

取五个一维位置 0、1、2.5、4、6，阈值 r = 1.5。逐对核对：|0−1| = 1 连通，|0−2.5| = 2.5 断开，|1−2.5| = 1.5 连通（恰好等于阈值，按小于等于保留），|2.5−4| = 1.5 连通，|4−6| = 2 断开。连通对为 (0,1)、(1,2.5)、(2.5,4)，有向边 6 条，加 5 个自环共 11 条，数字经程序枚举核对。

三个核对点：其一，位置 6 没有任何邻居，属于孤立节点，消息聚合对它返回零向量，节点靠自身编码与自环维持更新；若实现里把零消息当作缺失值跳过更新，该节点隐藏状态停在上一步，行为上表现为持续掉队。其二，距离恰好等于阈值的对依赖"小于等于"与"小于"的写法差异，阈值判定建议保留容差并写进单元测试。其三，连通分量可以断裂：图的直径只在连通分量内有定义，"K 轮覆盖全图"的表述必须限定在同一分量内，否则 K 的取值论证不成立。

设计决策：GRU 更新与决策步节奏对齐

把节点更新做成带记忆的门控单元，使"通信"与"时序"两件事在同一条隐藏状态上展开：第 t 个决策步的消息作用于 ht−1 得到 ht，跨步信息通过隐藏状态沉淀。若改用无记忆的残差 MLP，每步的表示独立，消息只能传递当前观测，历史协作模式（例如"队友上一轮在做什么"）需要数据扩容才能学到。代价是隐藏状态必须在回合边界正确重置，且并行采样时逐环境维护状态副本，这与第 018 章的记忆接口完全同构。

关键代码与解读

片段 1：距离阈值动态图构造

import torch

def build_adjacency(positions, radius=2.0, include_self=True):
    """按距离阈值构造邻接: positions (N, 2) -> 邻接 (N, N) 与边索引。"""
    # 成对距离: (N, N), 对角为 0
    diff = positions[:, None, :] - positions[None, :, :]
    dist = torch.norm(diff, dim=-1)
    adj = (dist <= radius).float()                   # 阈值内连通
    if include_self:
        adj = adj + torch.eye(positions.shape[0], device=adj.device)
    adj = (adj > 0).float()                          # 去重并转回 0/1
    # 边索引 (2, E): 后续按索引收集消息, 复杂度 O(E) 与 N^2 解耦
    src, dst = torch.nonzero(adj, as_tuple=True)
    return adj, torch.stack([src, dst])              # 注意方向: src 发, dst 收

解读：图构造是模块的计算入口，方向约定必须一次定死。（1）距离矩阵用广播差值一次性算出，阈值比较得到 0/1 矩阵；自环由 include_self 控制，含自环时节点保留自身信息，避免更新只依赖邻居导致状态漂移。（2）torch.nonzero 返回的边索引固定约定为"src 发、dst 收"，后续消息收集一律按 dst 聚合；方向写反会把"我关注谁"换成"谁关注我"，在非对称任务上表现为学习停滞。（3）返回邻接矩阵与边索引两份表示：邻接矩阵供小规模调试与可视化，边索引供 O(E) 消息收集；两者在单元测试中互相对照。

片段 2：一步消息传递模块

import torch.nn as nn

class MessageBlock(nn.Module):
    """一步消息传递: 边消息 -> 按收端求和 -> GRU 更新节点状态。"""
    def __init__(self, hidden=64, msg_dim=32, edge_dim=3):
        super().__init__()
        self.msg = nn.Sequential(                          # 共享消息函数 f_e
            nn.Linear(hidden * 2 + edge_dim, msg_dim), nn.ReLU(),
            nn.Linear(msg_dim, msg_dim))
        self.update = nn.GRUCell(msg_dim, hidden)          # 节点更新 f_u

    def forward(self, h, edge_index, edge_feat):
        # h: (N, hidden); edge_index: (2, E); edge_feat: (E, edge_dim)
        src, dst = edge_index[0], edge_index[1]
        pair = torch.cat([h[src], h[dst], edge_feat], dim=-1)  # 无向消息
        m = self.msg(pair)                                 # (E, msg_dim)
        # 按收端聚合: 先做 scatter 求和, 无邻居节点得到零消息
        agg = torch.zeros(h.shape[0], m.shape[1], device=h.device)
        agg.index_add_(0, dst, m)
        return self.update(agg, h)                         # 新隐藏状态

解读：三步对应公式的三个部件。（1）消息函数输入拼接 h[src] 与 h[dst]，表示消息与收发双方状态都相关；边特征作为第三分量携带距离等物理量。（2）index_add_ 按收端散列求和实现置换不变聚合，复杂度 O(E)；无邻居节点 agg 为零向量，模块退化为"只更新自身状态"。（3）GRUCell 以聚合消息为输入、旧状态为隐藏态，一步完成记忆更新；隐藏状态在批次与回合间的维护方式与第 018 章统一约定。

片段 3：多轮传递与评论家集成

class GraphCritic(nn.Module):
    """图通信评论家: K 轮消息传递后, 与自身动作拼接输出逐智能体价值。"""
    def __init__(self, obs_dim, n_actions, hidden=64, rounds=2):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(obs_dim, hidden), nn.ReLU())
        self.blocks = nn.ModuleList([MessageBlock(hidden) for _ in range(rounds)])
        self.head = nn.Sequential(
            nn.Linear(hidden + n_actions, hidden), nn.ReLU(), nn.Linear(hidden, 1))

    def forward(self, obs, act_oh, edge_index, edge_feat, h0=None):
        h = self.encoder(obs)                              # (N, hidden)
        if h0 is not None:
            h = h + h0                                     # 跨决策步记忆入口
        for blk in self.blocks:                            # K 轮 = K 跳感受野
            h = blk(h, edge_index, edge_feat)
        x = torch.cat([h, act_oh], dim=-1)                 # 动作在聚合后进入
        return self.head(x).squeeze(-1)                    # (N,) 逐智能体 Q

解读：集成方式与第 015 章的评论家对位，替换的只有聚合段。（1）编码器、动作条件化与输出头的结构原样保留，说明两种结构共享同一接口，可由配置切换，这正是受控对照实验得以成立的原因。（2）GRU 的隐藏状态入口 h0 在此处以加和形式示意跨步记忆；正式实现按回合维护状态张量并在 done 处重置，重置遗漏会把上一回合的旧消息带入新回合，表现为回合启动阶段行为异常。（3）K 轮循环之外没有额外参数，感受野仅由轮数控制；把 K 与邻域阈值同时加大是提高信息覆盖的两条独立途径，实验时分开调节以便归因。

常见坑

  • 边方向写反。症状：非对称协作任务学习停滞，权重可视化显示的是"被关注"方向，与预期的"关注"方向相反。原因：src 与 dst 的约定在构造与聚合两处不一致。修复：在构造函数与模块各加一处形状与语义断言，用小规模样例人工核对两遍。
  • 回合边界未重置隐藏状态。症状：新回合开头行为与上回合结尾相关，统计上出现"结转"效应。原因：GRU 状态跨回合存留。修复：数据层的 done 标志驱动状态重置，并写一条"连续两回合状态独立"的单元测试。
  • 距离来自执行期不可得的信息。症状：仿真内表现良好，部署评估回退。原因：邻接使用了全局坐标而部署协议不提供。修复：把邻接构造所需量列入执行期信息清单（第 005 章纪律），不可得时改用相对估计并把估计噪声纳入实验。
  • 聚合用多头拼接但不做置换不变包装。症状：置换检验失败，邻居顺序影响输出。原因：把邻居消息按序号外积成固定维度。修复：消息收集只用置换不变算子，置换检验纳入回归测试。
  • 轮数与阈值联调失控。症状：通信量或计算时间骤增而回报无增益。原因：感受野扩大超过任务实际交互半径。修复：先用环境物理量估算交互半径，取其对应的一至两跳作为 K 的上限，再做单变量扫描。

练习与思考

  1. 五个智能体位置为 0、1、2.5、4、6（一维），阈值 r = 1.5。写出邻接矩阵（含自环）与边索引数量，说明孤立情形是否出现。★
    提示
    连通对为 (0,1)、(1,2.5)、(2.5,4)，双向共 6 条有向边，加 5 个自环共 11 条；位置 6 没有任何邻居，属于孤立节点，正是零消息约定与自环兜底要覆盖的情形。
  2. 把传递轮数 K 从 2 改为 4，预测一维链式队伍中末端节点的信息覆盖范围与通信量的变化。★
    提示
    每轮传播一跳，K = 4 覆盖四跳；消息条数随边数与轮数乘积线性增长。回报增益只在"实际交互半径超过两跳"的任务中出现，否则纯增成本。
  3. 证明求和、均值、最大三种聚合均满足置换不变性；再给出一个"先按邻居序号拼接再线性层"的聚合例子并说明其在什么条件下破坏置换不变。★★
    提示
    三种算子对输入顺序的对称性直接可验。拼接加线性层对邻居顺序敏感，除非权重矩阵对交错维度做成共享（此时退化为加权和加常数项），一般情形不满足。
  4. 设计消融：无通信、距离图（本模块）、全连接注意力（第 015 章）三档在同一任务上的回报、通信量与置换检验结果，预期排序与各自的适用条件。★★
    提示
    局部交互任务预计距离图以最低通信量接近注意力表现；全局耦合任务注意力反超且通信量最高；无通信档作为下界。置换检验三档均应通过，缺失说明实现破坏了结构。
  5. 设计题：给出一套可学习边门控方案：门控网络输入 (hi, hj, eij)，输出边存在概率，训练用 Gumbel 松弛采样、推理取阈值；分析其与第 017 章带宽受限设定的接口，以及需要正则化的原因与形式。★★★
    提示
    门控概率乘以消息即"按需通信"的雏形；引入熵正则与稀疏惩罚控制边密度，否则训练早期即退化到完全图。第 017 章在同一位置加入发送代价项，门控与代价共享消息布局。

小结

  • 图结构给通信装上先验：硬邻接把注意力完全图稀疏化为 O(E)，边特征把距离等物理量显式送入消息函数。
  • 消息传递三部件：共享消息函数、置换不变聚合、GRU 节点更新；K 轮传递对应 K 跳感受野与 K 倍通信量。
  • 动态图有确定性重算与学习式门控两条实现路线；训练与执行的信息口径必须显式声明。
  • 实现纪律：边方向固定、回合重置、置换检验与执行期信息清单，与前几章的结构验收清单合并使用。
