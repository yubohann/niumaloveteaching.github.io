第三篇 · 环境与任务实践

第 043 章：多智能体覆盖问题

覆盖问题的数学本质是把一个区域划分给多个智能体，使任意位置到最近智能体的加权距离最小；本章推导 Voronoi 分区与质心最优性，并说明强化学习如何在未知密度分布与局部观测下逼近这一划分。

  • 主题：空间划分 / 覆盖质量泛函
  • 关键公式：H = ∫ φ(x) · mini ‖x − pi‖2 dx
  • 预计学时：60 分钟
  • 前置章节：第 042 章 多智能体编队控制

学习目标

读完本章，应当能够把一个覆盖任务写成密度加权的划分问题，并能判断策略输出是否接近该问题的最优划分。

  • 理解覆盖质量泛函的构造方式：密度函数、最近智能体距离与二次型代价各自的含义与选择依据。
  • 掌握 Voronoi 分区（Voronoi partition）的定义与质心最优性，理解 Lloyd 算法为何收敛到质心 Voronoi 划分（centroidal Voronoi tessellation, CVT）。
  • 掌握网格离散化近似覆盖积分的做法，理解网格分辨率对奖励精度与计算量的权衡。
  • 能为局部观测下的覆盖任务设计奖励与诊断指标，识别“几何均衡但局部空洞”的退化现象。
  • 会区分覆盖任务与编队任务的约束结构差异：前者是无冲突的空间划分，后者是成对的等式约束。

背景与动机

覆盖问题描述的是“空间分工”，它在几何约束型任务里约束最弱，但全局结构最强。

区域覆盖、环境监测、清扫与巡检任务共享同一数学内核：多个智能体分布在一个区域中，希望区域内任意位置都能在期望距离内被某个智能体到达，同时不同智能体的负责区域不重叠。经典解是 Voronoi 划分：给定智能体位置，离哪个智能体最近，哪个智能体就负责该位置。该划分把连续空间的覆盖问题转化为有限个几何区域的管理问题，并给出明确的最优性条件：智能体位于各自区域的质心时，覆盖代价达到局部最优。

强化学习的价值出现在经典解失效的场合：密度分布未知或随时间变化、智能体只有局部观测、存在障碍与能耗约束。此时策略需要在线估计密度并调整站位；固定的 Lloyd 迭代在这些条件下不再适用。本章的 Voronoi 工具同时是理解后两章的基础：追捕任务中的合围区域可以看作动态 Voronoi 单元，协同建图中的采样分布也依赖覆盖代价的估计。

核心原理

覆盖问题的全部理论围绕一个积分型代价展开：对区域内每一点，度量它到最近智能体的距离，并按密度加权求和。

1. 覆盖质量泛函

把区域记作 Ω，密度函数记作 φ(x)，覆盖质量的度量方式如下。

H(p1, …, pN) = ∫Ω φ(x) · mini ‖ x − pi ‖2 dx Ω 为待覆盖区域；φ(x) ≥ 0 为密度权重，表示位置 x 的重要程度；pi 为第 i 个智能体位置；min 表示每个点由最近的智能体负责

密度函数决定任务语义：均匀密度对应“处处同等重要”的巡检，凸起密度对应事故点附近的重点监视。二次型距离惩罚远距离遗漏的程度高于一次型，取值越大越强制智能体靠近高密度区中心。若干可选变体：min 换成对智能体求和（代价变得可分解但失去分工语义），二次型换成四次型（对大距离更敏感，等价于施加更强的均匀化压力）。

该泛函有一个直接性质：全部智能体同时平移不改变 H，整体旋转也不改变 H，覆盖问题同样存在规范自由度，评估指标只看几何分布而不看绝对坐标。

2. Voronoi 分区与质心最优性

对给定的智能体位置，把区域划分给最近的智能体，得到的划分即 Voronoi 分区。

Vi = { x ∈ Ω : ‖ x − pi ‖ ≤ ‖ x − pj ‖ , ∀ j ≠ i } Vi 为第 i 个智能体的负责区域；边界上的点归属任一最近智能体都不改变 H 的取值

把分区代入泛函，H 分解为逐区域的积分：H = Σi ∫Vi φ(x) ‖x − pi‖2 dx。对单个 pi 求梯度，得到 ∂H/∂pi = 2 Mi ( pi − ci )，其中 Mi = ∫Vi φ(x) dx 为区域质量，ci = (1/Mi) ∫Vi x φ(x) dx 为区域的密度质心。该梯度在 pi = ci 时为零，因此最优位置条件是每个智能体位于其分区的密度质心，此时的划分称为质心 Voronoi 划分。

Lloyd 算法把该条件写成迭代：计算分区、把每个智能体移到分区质心、重复。它是覆盖代价的坐标下降法，H 单调不增，收敛到局部最优。局部最优不唯一：对称配置（例如四个智能体位于正方形四角）是典型的鞍点式停滞点，实务中通过随机初始化与对称破缺来缓解。

3. 网格离散化

连续积分的解析形式只在矩形区域与简单密度下有闭式解，实现上统一采用网格离散。

H ≈ ( |Ω| / K ) · Σk=1K φ(xk) · mini ‖ xk − pi ‖2 K 为网格点数，|Ω| / K 为单格面积；xk 为格子中心坐标

离散化引入的误差量级是 O(1/K)，除分辨率之外还受两点影响：密度函数在格子内变化剧烈时需要用格子内平均值代替中心点取值，否则系统性地高估或低估某些区域；智能体位于两个格子边界附近时 min 的归属在相邻步之间切换，造成奖励的微小抖动，这一抖动在高分辨率下更明显。工程上常取 32×32 到 64×64 的网格，并在奖励计算时复用同一份距离矩阵。

4. 覆盖奖励的设计

训练用的奖励是覆盖代价的增量形式加上均衡性修正。

rt = − wh ( Ht − Ht−1 ) − wb · Vari ( Mi ) − wc ncollision Ht 为当前覆盖代价；Vari(Mi) 为各分区质量（面积）的方差，度量均衡性

增量形式的奖励把绝对代价转成进展信号：策略移动导致 H 下降即获得正回报，停滞获得零回报。相比直接使用 −H，增量形式对尺度变化更鲁棒，缺点是倾向于“先易后难”，容易在容易改进的区域收敛后忽视高密度角落。均衡性修正项补偿这一倾向：分区面积方差大意味着某些智能体负责的区域过大，通常伴随局部空洞，该项给出额外的改进压力。

另一种常见形式是逐智能体的局部覆盖奖励：智能体只统计自身分区内的覆盖代价。该形式让奖励在智能体之间可分解，配合值分解方法更自然，代价是分区边界附近的归属切换会造成个体奖励跳变，需要在实现上用平滑权重或延迟归并处理。

5. 局部观测下的覆盖

全局密度分布通常不可得，观测需要给出足够引导策略移动的局部信息。

oi = [ pi, vi, { pj − pi }j∈N(i), patch( φ , pi, Rs ) ] patch 为以智能体为中心的局部密度采样窗口，半径 Rs；窗口内的密度以固定分辨率栅格化后展平

局部密度窗口把连续场压缩成定长向量，策略可以直接感知“哪个方向更密集”。窗口半径需要覆盖智能体的单步可达范围：半径过小则信息不足以规划移动方向，半径过大则分辨率被摊薄。窗口与邻居相对位置的组合让策略同时掌握“谁在附近”和“哪里更需要人”。部分可观测程度越高（窗口越小、通信越弱），策略越依赖历史信息，此时使用循环网络编码观测序列成为必要手段，把它降级为可选技巧会带来明显性能损失。

6. 数值核对：解析值、偏移代价与网格误差

取矩形区域 [0, 2] × [0, 1]、密度恒为 1，覆盖代价可以手算。单个智能体位于几何中心 (1, 0.5) 时，H 等于两个方向的中心二阶矩积分之和：x 方向为 1 × ∫02(x − 1)2 dx = 2/3（区域在 y 方向长 1），y 方向为 2 × ∫01(y − 0.5)2 dy = 1/6（区域在 x 方向长 2），合计 H = 5/6 ≈ 0.8333。把智能体沿 x 方向平移 δ 后，交叉项积分为零，H = 5/6 + 2δ2：偏移代价随位移平方增长，δ = 0.1 相当于中心到边界距离 1.0 的十分之一，代价只上升 2.4%（0.02 / 0.8333），这是覆盖任务梯度在质心附近较小的数量级来源。

两台智能体的对照给出协同收益的解析基准：把区域从中线分成两个单位正方形，智能体各居其中心，每个区域的代价为 1/12 + 1/12 = 1/6，合计 H = 1/3 ≈ 0.3333。相对单机的 5/6，第二台智能体把代价压到四成，这是“增加一台设备”的收益上限参照；实际策略的分区质量与 Lloyd 解的差距可以用这个尺度的相对误差衡量。两台及以上时 H 无简单闭式，但对称布局按区域拆分的分解计算仍然可用。

网格误差的收敛行为可以实测核对：对两机布局在分辨率 12、24、48、96（两个方向各 r 格）上分别计算，与解析值 1/3 的偏差依次约为 5.8 × 10−3、1.4 × 10−3、3.6 × 10−4、9.0 × 10−5，分辨率每翻倍误差约降为四分之一。误差量级与网格点总数 K 成反比（O(1/K)），48×48 时相对误差约 0.1%，继续加密按同样的反比律收敛，收益有限。收敛阶与光滑函数的中点求积一致；Voronoi 边界处的折角不改变阶数，只影响误差常数，分辨率的选择因此落在误差常数与任务尺度的匹配上，无需一味加密网格。

把上面的数字与实现配置对照：48×48 的网格下，距离矩阵形状为智能体数乘 2304，四机时共 9216 个元素，单步代价可忽略；奖励的数值波动中，由网格归属切换贡献的部分约在 10−4 量级，低于奖励主体量级一个数量级以上，属于可接受噪声。

实现思路与设计

实现覆盖任务的关键决策集中在三处：网格的实现方式、奖励的形式、以及如何把 CVT 解作为诊断基准。

1. 环境与基线

环境内部维护一张网格与一份密度权重表。每一步执行后计算新的覆盖代价与均衡度，连同奖励返回。诊断输出包含三项：覆盖代价曲线、分区面积方差、以及策略与 Lloyd 迭代结果之间的距离（把 Lloyd 收敛解作为上界参照，衡量策略离最优划分的差距）。

3. 网络结构与训练循环

策略网络包含两个编码支路：邻居支路与第 042 章相同（共享多层感知机加掩码聚合），密度窗口支路用两层卷积网络（convolutional neural network, CNN）把栅格化的局部密度编码成定长向量。两个支路的输出与自身状态拼接后送入策略头。训练采用集中式评论家，输入为全局网格与所有智能体状态，输出团队价值估计；执行期只用两个编码支路与策略头。

4. 与第 042 章的差异点

编队任务里智能体之间是等式约束，误差项成对出现；覆盖任务里智能体之间是划分关系，一个位置的归属由最近性决定，分区边界会随位置变化连续移动，误差曲面是分段二次的。分段性质给优化带来两处影响：梯度在边界跨越处不连续，策略更新需要更小的学习率或用梯度裁剪；局部最优结构更明显，对称配置附近的梯度接近零，探索机制的作用比在编队任务中更重要。

关键代码与解读

三段代码分别实现网格化的覆盖代价、Lloyd 基线迭代与包含均衡项的奖励函数。

片段 1：网格覆盖代价

import numpy as np

def make_grid(size=2.0, res=48):
    """生成网格中心坐标与面积元，一次构造全程复用。"""
    axis = np.linspace(-size / 2 + size / res / 2, size / 2 - size / res / 2, res)
    gx, gy = np.meshgrid(axis, axis)
    pts = np.stack([gx.ravel(), gy.ravel()], axis=1)   # (K, 2) 格子中心
    cell_area = (size / res) ** 2                      # 单格面积，积分权重
    return pts, cell_area

def coverage_cost(pos, grid_pts, phi, cell_area):
    """H = 面积元 * sum( 密度 * 到最近智能体的距离平方 )。"""
    # 距离矩阵 (N, K)：一次性算完，避免对每个智能体重复循环
    d2 = ((grid_pts[None, :, :] - pos[:, None, :]) ** 2).sum(axis=-1)
    nearest = d2.min(axis=0)               # 每个格子归属最近的智能体
    H = cell_area * float((phi * nearest).sum())
    # 分区质量近似：用于均衡性诊断，按最近归属统计密度和
    owner = d2.argmin(axis=0)
    masses = np.array([phi[owner == i].sum() * cell_area for i in range(len(pos))])
    return H, masses

解读：网格一次构造、全程复用，避免每步重建坐标网格带来的固定开销。距离矩阵形状为 (N, K)，N 为智能体数、K 为格子数，全部向量化计算；在 48×48 网格与 4 个智能体的规模下，矩阵仅 9216 列，单步开销可忽略。分区质量通过归属数组统计，同一份距离矩阵支撑代价与均衡度两个输出，保持诊断口径一致。

片段 2：Lloyd 基线迭代

def lloyd_step(pos, grid_pts, phi, lr=0.8):
    """一次 Lloyd 更新：移到各自分区的密度质心（带步长平滑）。"""
    d2 = ((grid_pts[None, :, :] - pos[:, None, :]) ** 2).sum(axis=-1)
    owner = d2.argmin(axis=0)              # 归属由最近性唯一决定
    new_pos = pos.copy()
    for i in range(len(pos)):
        m = owner == i
        if not m.any():                    # 空分区：理论上不会出现，防御性兜底
            continue
        w = phi[m]                         # 密度权重决定质心的偏向
        c = (grid_pts[m] * w[:, None]).sum(axis=0) / (w.sum() + 1e-12)
        # 用 lr 做平滑：质心可能一次移动很远的距离，直接跳变会引起振荡
        new_pos[i] = pos[i] + lr * (c - pos[i])
    return new_pos

def lloyd_solve(pos, grid_pts, phi, iters=30):
    """迭代到近似收敛，作为策略的诊断上界。"""
    for _ in range(iters):
        pos = lloyd_step(pos, grid_pts, phi)
    return pos

解读：Lloyd 迭代的关键一步是质心计算，密度加权求和决定了智能体向高密度区偏移的程度。步长 lr 的平滑处理有两个理由：直接跳变会导致相邻分区之间来回振荡（尤其当智能体接近边界时），以及相位对齐问题（多个智能体同时跳向对方区域）；平滑后代价单调下降的性质仍然保持。防御性兜底处理空分区，在网格极稀疏或智能体极多时可能出现，忽略该分支会让质心计算产生除零。

片段 3：覆盖奖励与诊断量

class CoverageReward:
    """增量覆盖奖励 + 均衡修正，同时维护可诊断的统计量。"""
    def __init__(self, grid_pts, phi, cell_area, w_h=1.0, w_b=0.1):
        self.grid_pts, self.phi, self.cell_area = grid_pts, phi, cell_area
        self.w_h, self.w_b = w_h, w_b
        self.prev_H = None

    def reset(self):
        self.prev_H = None                 # 回合重置：增量基准必须清空

    def __call__(self, pos):
        H, masses = coverage_cost(pos, self.grid_pts, self.phi, self.cell_area)
        if self.prev_H is None:
            self.prev_H = H                # 首步无增量可算，返回零进展
            return 0.0, {"H": H, "var_mass": float(masses.var())}
        delta = H - self.prev_H            # 负增量表示覆盖改善
        self.prev_H = H
        r = -self.w_h * delta - self.w_b * float(masses.var())
        return r, {"H": H, "var_mass": float(masses.var()),
                   "improved": float(-delta)}

解读：增量基准 prev_H 必须按回合重置，否则跨回合的差值是两次独立初始化的代价之差，奖励信号完全失去意义，这是覆盖类任务最常见的实现错误之一。信息字典同时输出覆盖代价与分区质量方差：两者同降说明策略在兼顾效率与均衡，代价下降而方差上升说明策略在牺牲均衡换取局部改善，诊断价值高于单独观察奖励曲线。改进量单独输出便于绘制“每步进展”曲线，它比累计代价更早暴露策略停滞。

常见坑

  • 增量奖励的基准未按回合重置：跨回合计算代价差值，首步奖励异常大或异常小，训练早期波动剧烈。症状是每一回合第一步奖励出现规律性尖峰。修复：在环境重置时同步清空上一代价缓存。
  • 网格分辨率与智能体数不匹配：格子数远小于智能体数时平均每格归属频次过低，分区质量统计噪声大；格子数过大会放大边界抖动。修复：保证平均每格至少覆盖一个智能体活动范围，48×48 配合 4 至 8 个智能体是稳健起点。
  • 密度函数在格子内取值不平滑：直接取格子中心值导致密度峰落在格子交界时被系统性低估。修复：网格分辨率与密度带宽匹配，或构造时对密度做一次低通滤波。
  • 对称初始化的停滞：四个智能体从正方形四角出发时梯度接近零，策略长时间无改进。症状是覆盖代价曲线停在初值附近且无方差变化。修复：随机化初始化，或在探索噪声中加入足够幅度的扰动。
  • 局部窗口半径过小：策略看不到密度峰方向，奖励与观测脱节，学习退化为随机游走。症状是覆盖代价缓慢下降且均衡度无改善。修复：窗口半径覆盖单步可达范围的一定倍数，或提高历史编码能力。

练习与思考

  1. 推导题：证明均匀密度、单个智能体情形下覆盖代价的梯度为零当且仅当智能体位于区域质心，并说明矩形区域的解。★
    提示
    单个智能体的分区为整个区域，代价为二次泛函，梯度条件直接给出质心。矩形区域在均匀密度下质心为几何中心，边界效应不影响结论。
  2. 改参数并预测：把均衡修正权重 wb 从 0.1 提高到 1.0，预测分区面积方差曲线与覆盖代价曲线的走向，并判断在双峰密度下会牺牲什么。★★
    提示
    方差权重提高后策略倾向等面积划分，高密度峰附近的覆盖投入被摊薄，覆盖代价上升。这正是效率与均衡的取舍，权重取值应以任务对遗漏的容忍度为准。
  3. 设计题：为 6 个智能体设计局部密度窗口的栅格化方案，给出窗口半径、栅格分辨率与展平后的观测长度的计算，并说明窗口重叠时不同智能体的观测差异。★★
    提示
    窗口半径 0.5、栅格 8×8 时，观测长度为 64 加自身与邻居特征。窗口重叠区域被多个智能体同时观测，冗余信息对协同有利，但需要控制观测维度膨胀。
  4. 实验设计：把 Lloyd 解与训练策略的分区面积方差对比，设计一组实验判断策略的差距来自观测不足还是奖励设计，并给出区分依据。★★★
    提示
    若给策略接入全局密度信息后方差显著下降，差距主要来自观测；若接入全局信息后方差仍大，则奖励设计中的均衡项权重或增量形式应被怀疑。对比实验需固定随机种子与回合预算。
  5. 分析题：说明为什么覆盖任务的奖励曲面是分段二次的，并给出分段边界与智能体位置的对应关系。★★★
    提示
    分区归属在 Voronoi 边界处切换，代价函数在每个分区内部是二次型，跨边界的整体函数是分段二次的连续函数。边界由相邻智能体的垂直平分线给出，与网格相交的位置决定分段点的分布。

小结

  • 覆盖质量以密度加权的最近距离平方积分定义，最优位置条件是智能体位于各自分区的密度质心，对应质心 Voronoi 划分。
  • Lloyd 迭代是坐标下降法，代价单调不增，收敛到局部最优；对称配置存在停滞点，需要随机初始化与探索缓解。
  • 实现上统一使用网格离散化，代价、分区质量与诊断指标共用同一份距离矩阵；增量奖励的基准必须按回合重置。
  • 奖励设计需要覆盖进展与均衡性两项，局部观测下策略依赖局部密度窗口与历史编码，窗口半径与可达范围匹配。
