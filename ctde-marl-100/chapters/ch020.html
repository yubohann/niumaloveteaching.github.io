第一篇 · CTDE 基础与核心算法

第 020 章：多智能体信用分配

第一篇的收束章：把团队回报拆解为个体贡献，是贯穿全篇的核心问题。本章建立统一框架：以合理性公理定义"好的分配"，以差值奖励和夏普利值（Shapley value）给出两种可计算机制，以蒙特卡洛估计落地，并给出评估分配质量的三条实验路径。

  • 主题：信用分配机制 / 合作博弈值
  • 关键公式：Di(z) = R(z) − R(z−i)； φi = ΣS⊆N∖{i} |S|! (N−|S|−1)! / N! · [ v(S ∪ {i}) − v(S) ]
  • 预计学时：55 分钟
  • 前置章节：第 019 章

学习目标

  • 理解信用分配问题的欠定结构与四条合理性公理，掌握夏普利值作为唯一满足公理的分配方案的含义。
  • 掌握差值奖励的构造、默认动作敏感性及其与反事实基线（第 009 章）的期望化联系。
  • 会实现蒙特卡洛排列采样的夏普利估计与策略化默认动作的差值奖励，并分析两者的偏差方差特性。
  • 能绘制信用分配机制的分类图谱：隐式分配、反事实梯度、博弈值类、注意力与关系分配、时序分配。
  • 会设计三条评估路径：合成任务对齐度、下游训练收益、分配稳定性，并说明各自的适用与局限。

背景与动机

协作环境只返回团队标量回报 R。第 006 章的值分解把梯度均分或加权分给个体价值，第 009 章的反事实基线用自身动作的期望差值做优势，两条路线各回答了信用分配的一个侧面。本章把它们放进同一框架：信用分配是一个从团队回报到个体贡献赋值的映射，其设计空间由"分配应满足什么性质"这一问题定义，与具体算法的实现细节无关。

合作博弈论给出的答案是夏普利值：满足效率（贡献之和等于总收益）、对称（等价角色获得相同分配）、虚拟支付者（无贡献者不参与分配）、可加性四条公理的分配方案唯一存在。它的代价是精确计算需要遍历全部子集，规模指数级；蒙特卡洛排列采样把代价压到可承受范围，代价是估计方差。差值奖励是它的近亲：用"删除该智能体后的收益变化"做单点估计，计算便宜但存在默认动作偏差。本章的计算、对比与评估全部落在小规模精确可核对的任务上，方法本身经接口封装后可直接用于第 021 章起的奖励重塑与诊断工具链。

核心原理

本节给出公理体系、两种分配机制的形式化与对照、蒙特卡洛估计，以及跨章节的机制分类图谱。

1. 合理性公理与夏普利值

把联合动作（或轨迹片段）z 的价值记为 v(S)（子集 S 的智能体参与时的团队收益），完整集合 N 的价值记 v(N) = R(z)。夏普利值定义为全部加入顺序上边际贡献的平均：

φi = ΣS ⊆ N∖{i} [ |S|! · (N − |S| − 1)! / N! ] · [ v(S ∪ {i}) − v(S) ] 权重是"在随机加入顺序中, i 恰好面对子集 S 作为先行者"的概率; φ 与 v 相关, Σi φi = v(N) − v(∅)（效率公理）。四条公理共同刻画下解唯一

公理的直觉逐条对应实验要求：效率要求分配不虚增不遗漏；对称要求同贡献同待遇，防止编号偏袒；虚拟支付者要求零贡献者获得零分配，防止搭便车激励；可加性要求把两个独立任务合并时不改变分配结构。当研究者提出的分配机制不满足其中某条时，应当在论文或实验记录中明确说明取舍，不能默认其合理性。

数值算例：三人合作博弈的精确夏普利值

用一组小规模价值表把定义式完整算一遍。设三人博弈的子集价值为：v(∅) = 0，v({1}) = 2，v({2}) = 1，v({3}) = 0，v({1,2}) = 4，v({1,3}) = 3，v({2,3}) = 2，v({1,2,3}) = 6。以智能体 1 为例，按定义式对 S ⊆ {2,3} 的四种子集逐一计算，系数 |S|!(N−|S|−1)!/N! 依次为 1/3、1/6、1/6、1/3：

φ1 = (1/3)·[v({1}) − v(∅)] + (1/6)·[v({1,2}) − v({2})] + (1/6)·[v({1,3}) − v({3})] + (1/3)·[v(N) − v({2,3})] 四个括号依次为 2、3、3、4；加权求和得 (2/3) + (1/2) + (1/2) + (4/3) = 3

代入数值：第一项 (1/3)×2 ≈ 0.667，第二项 (1/6)×3 = 0.5，第三项 (1/6)×3 = 0.5，第四项 (1/3)×4 ≈ 1.333，合计 φ1 = 3。同法算出 φ2 = 2、φ3 = 1，三人之和 6 恰好等于 v(N) − v(∅)，效率公理通过核对。数值与直觉一致：智能体 1 加入任何子集都带来至少 +2 的边际（2、3、3、4），份额最大；智能体 3 的边际在 0 到 2 之间，份额最小。注意这组数据里角色互不等价，对称公理与虚拟支付者公理没有可检验的差异，因此精确夏普利作为基准的价值在于给出可核对的数值，排序层面的直觉需要另设例子检验。

2. 差值奖励与反事实基线

差值奖励只用两个对照点估计边际贡献：

Di(z) = R(z) − R( z−i, ci )， ci 为默认动作 z−i 保留其余智能体行为, 仅把 i 的动作替换为默认值。第 009 章的反事实基线是其期望化版本: 把固定默认替换为在 πi 下的期望替换, Ai = 𝔼ci∼πi[ Di ]

差值奖励的性质与风险都由默认动作决定：默认动作取"环境自然态"（如不动或停机）时语义清晰，取"策略平均动作"时与反事实基线等价；选错默认动作会让某些智能体的贡献被系统性高估或低估。它在计算上只要求一次反事实评估，适合嵌入训练循环（第 021 章的奖励重塑），代价是单点估计的偏差；夏普利值在原理上消除默认动作问题，代价是计算量。

用上面的价值表核对差值奖励的尺度：取默认动作为"该智能体退出协作"，则 D1 = 6 − v({2,3}) = 4，D2 = 6 − v({1,3}) = 3，D3 = 6 − v({1,2}) = 2，三项之和为 9，比总价值 6 高出 50%，效率公理被破坏。差值奖励给出的排序 (4, 3, 2) 与夏普利 (3, 2, 1) 一致，数值整体上偏，这解释了工程做法：用它做个体信号的相对强弱，用团队回报或归一化对齐总量，两类信号各司其职。

3. 蒙特卡洛夏普利估计

随机采样加入顺序，逐步计算边际贡献并平均：

采一个随机排列 σ， 沿 σ 让智能体逐个加入，第 k 位的边际为 v(Sk ∪ {σk}) − v(Sk)；对 m 个排列求均值即 φ 的无偏估计 每个排列贡献 N 个边际样本（每个智能体一个）。排列间的相关性是方差的来源, 用共同排列集评估多种方法时可实现方差共享

估计精度随采样数 m 下降速率为 1/√m，与常规蒙特卡洛一致；实践中 m 取 32 至 128 时小规模任务的分配排序已经稳定。价值函数 v(S) 的来源需要明确声明：离线分析可用环境真值（合成任务）或训练好的评论家近似；用评论家近似时，分配质量的上限被评论家误差锁定，评估实验应把两者分开报告。

实现思路与设计

本节给出信用分配工具层的组件与配置：统一价值接口、两种估计器、三条评估路径。工具层不改变主训练管线，可独立调用。

设计项取值（基线）作用与依据
价值接口 v(S)接收子集掩码与联合动作，返回标量合成任务用解析公式，训练管线用集中式评论家

MC 夏普利m = 64 个排列，固定采样种子方差的起点；跨方法对比时共享同一排列集

合成评估任务R(z) = Σ ri(zi) + w·耦合项，真值已知对齐度评估：分配值与真值贡献的 MAE 与排名相关
下游评估Di 重塑奖励后训练 5 个种子分配质量的最终检验标准
稳定性指标跨种子分配向量的一致性（余弦相似度）区分结构性差异与随机噪声

与第 019 章的衔接：融合偏差检测提供了"真实可达行为"的基准，信用分配在部署口径的轨迹上计算，两者共同保证分析不建立在不可执行的联合行为上。工具层内置的接口纪律：v(S) 的每次调用记录使用的信息范围，训练期评论家不得把未来信息混入时序分配的分析口径。

设计决策：评估优先于训练，对齐度优先于回报

信用分配的价值主张是"信号更准"，直接拿下游回报做唯一评估会被探索噪声与超参噪声淹没。合成任务提供已知真值，把分配误差分解为"机制固有偏差"（例如差值奖励的默认动作方向性）与"估计噪声"（采样数不足），两类问题对应不同修复手段。只有对齐度通过后，下游训练收益的差异才归因给分配机制本身。回报提升而对齐度差的机制仍可能有效，那属于奖励重塑的功劳（第 021 章），归因应分开陈述。

关键代码与解读

片段 1：蒙特卡洛夏普利估计

import numpy as np

def mc_shapley(value_fn, n_agents, m=64, seed=0):
    """排列采样估计夏普利值: value_fn(S_mask) 返回子集 S 的团队价值。"""
    rng = np.random.default_rng(seed)
    phi = np.zeros(n_agents)
    for _ in range(m):
        order = rng.permutation(n_agents)          # 一次随机加入顺序
        mask = np.zeros(n_agents, dtype=bool)      # 当前已加入集合 S
        prev = value_fn(mask)                      # v(∅)
        for i in order:
            mask[i] = True
            cur = value_fn(mask)                   # v(S ∪ {i})
            phi[i] += cur - prev                   # 边际贡献累加
            prev = cur
    phi /= m                                       # 对排列求平均: 无偏估计
    # 效率自检: 分配和应等于 v(N) - v(∅), 误差只来自采样
    return phi

解读：估计器结构直接对应夏普利值的定义式。（1）每次采样一个排列，沿排列把智能体逐个加入，cur - prev 即"在先行者集合 S 下加入第 i 个的边际"；对全部排列平均，恰好是定义式中按权重加权的边际贡献。（2）value_fn 接受子集掩码作为输入，把"子集价值如何取"隔离在接口之外：合成任务里是解析公式，训练环境里可由交互回放或评论家近似实现。（3）效率自检是免费的验收项：分配和与 v(N) − v(∅) 的偏差给出蒙特卡洛误差的直接读数，跨实现替换价值接口时先跑该断言。

片段 2：策略化默认动作的差值奖励

def difference_reward(env, joint_actions, agent_idx, policy_probs, n_samples=8, seed=0):
    """差值奖励: 用策略采样替换个体动作, 平均得到期望化边际。"""
    rng = np.random.default_rng(seed)
    base_r = env.evaluate_joint(joint_actions)              # R(z): 当前联合动作
    margins = []
    for _ in range(n_samples):
        counterfactual = list(joint_actions)
        # 从该智能体策略分布采样替换动作: 期望化消除单一默认的偏差
        counterfactual[agent_idx] = rng.choice(
            len(policy_probs), p=policy_probs / policy_probs.sum())
        margins.append(base_r - env.evaluate_joint(counterfactual))
    # 采样平均即反事实优势的单一轨迹版本(第 009 章为分布内积版本)
    return float(np.mean(margins))

解读：这段函数是第 009 章反事实思想的"奖励重塑形态"。（1）替换动作从策略分布采样，未使用固定默认值，期望化抹平了默认选择的系统性偏差；采样数 8 是偏差与成本的折中，方差随采样数下降。（2）env.evaluate_joint 允许在不推进环境的前提下重算奖励（环境需提供无副作用评估接口），这是把分配计算从交互循环中解耦的关键工程条件。（3）返回值可直接作为个体奖励整形项使用（第 021 章展开），取代或叠加团队回报；此时必须重新审视最优策略是否保持，报酬整形的保序条件在该章的练习中给出推导。

片段 3：对齐度评估

def credit_alignment(phi_est, phi_true):
    """对齐度: MAE 衡量数值逼近, 秩相关衡量排序正确性。"""
    import numpy as np
    mae = float(np.abs(phi_est - phi_true).mean())
    # 秩相关用排序位置的一致性, 对尺度不敏感, 适合跨机制对比
    rank_est = np.argsort(np.argsort(phi_est))
    rank_true = np.argsort(np.argsort(phi_true))
    n = len(phi_true)
    d2 = ((rank_est - rank_true) ** 2).sum()
    spearman = 1.0 - 6.0 * d2 / (n * (n ** 2 - 1))
    # MAE 看"分多少", 秩相关看"分给谁", 两条指标都汇报
    return {"mae": mae, "spearman": spearman}

解读：评估函数把"分配质量"拆成两个正交维度。（1）MAE 度量数值逼近，受真值尺度影响；合成任务中真值由奖励结构解析给出，尺度可控。（2）斯皮尔曼秩相关只关心排序，对机制的尺度差异免疫：差值奖励与夏普利估计的绝对数值可能不同，但"谁贡献更大"的排序应当一致，秩相关是跨机制比较的主指标。（3）两条指标的组合能定位故障类型：MAE 差而秩相关好，说明机制方向正确但估计尺度有偏（检查估值来源）；两者都差，说明机制与任务的价值结构不匹配（更换分配机制）。

常见坑

  • 价值函数口径混用。症状：对齐度评估结果与训练表现矛盾。原因：离线分析用环境真值，训练用评论家近似，两者误差未被区分。修复：在报告中分两行给出"真值口径 + 评论家口径"的指标，把评论家误差作为独立量报告。
  • 差值奖励默认动作选择随意。症状：个别智能体的分配值系统性偏离真值。原因：默认动作语义与任务不匹配。修复：默认动作改为策略期望化的采样版本，或对任务选择有明确语义的停机动作并记录选择理由。
  • 排列采样数不足且不共享随机性。症状：机制间比较被采样噪声主导，结论随种子翻转。修复：跨机制对比共用同一排列集实现方差共享，采样数按效率自检的误差读数确定。
  • 把注意力权重直接当真值。症状：论证"注意力机制实现了正确信用分配"时缺少可证伪依据。原因：注意力是代理信号。修复：在合成任务上与真值对照后再下结论，权重仅作为诊断的辅助证据。
  • 时序与空间分配混淆。症状：长时域任务上分配结果对关键决策步不敏感。原因：只在单步奖励上做空间分配，未沿时间维度回传。修复：与 GAE 类时序回溯组合（第 012 章），两个维度的分配分别报告。

    按 2 人先行的排列枚举计算边际平均：φ1 约为 (2+2+3+4+3+4)/6 等组合的均值，三人之和应等于 6。逐项算完对照即可。
  2. 把 MC 夏普利的采样数 m 从 64 改为 8，预测效率自检误差与秩相关的波动幅度，并说明需要用多少种子才能得到稳定结论。★
    提示
    误差按 1/√m 放大约 2.8 倍；秩相关在小样本下波动明显，建议至少 10 个种子报告中位数与四分位距。
  3. 推导：差值奖励 Di = R(z) − R(z−i, ci) 是夏普利定义中边际贡献的一个单点样本，说明它对应"加入顺序把 i 排在最后、且先行者恰为全部其他人"的情形；再说明期望化差值奖励与反事实基线的等价性。★★
    提示
    沿排列最后加入的边际为 v(N) − v(N∖{i})，默认动作版本把"其余人保持当前行为"具体化为 z−i。对 ci 取策略期望即 Ai = Σ π(c) [R(z) − R(z−i, c)]（第 009 章内积形式）。
  4. 设计合成任务评估协议：奖励含可加项与耦合项，真值分解已知；给出数据生成方式、指标计算流程与"耦合项权重增大时秩相关变化"的预测。★★
    提示
    真值 = 可加项各分量；耦合项权重增大时边际贡献之间的交互增强，差值奖励围绕单一对照点的偏差扩大，预期秩相关下降而夏普利估计保持稳定，该对比直接展示两种机制的适用边界。
  5. 设计题：把期望化差值奖励接入训练循环（奖励重塑），给出保序条件的推导直觉（报酬差是否满足势函数结构）、需要重做的评估项（最优策略与最优回报是否保持）与对照实验方案。★★★
    提示
    若 Di 可写成势函数差 Φ(s′) − Φ(s)，策略最优集不变；一般差值奖励不严格满足该形式，需要以合成任务核对最优策略。实验对照：原奖励训练 / 重塑奖励训练 / 两者线性组合，报告最优策略与回报。

小结

  • 信用分配是团队回报到个体贡献的映射；四条合理性公理刻画下夏普利值唯一，是分配机制的基准参考。
  • 差值奖励以单点反事实估计边际贡献，计算便宜但默认动作敏感；期望化后与第 009 章的反事实基线等价。
  • 蒙特卡洛排列采样把夏普利计算压到可承受成本，效率自检与秩相关是估计质量的直接读数。
  • 机制图谱覆盖隐式分配、反事实梯度、博弈值、关系与注意力、时序五类，按训练内循环与离线分析分档选用。
