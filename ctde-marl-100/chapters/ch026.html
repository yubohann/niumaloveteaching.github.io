第二篇 · 训练工程与稳定性

第 026 章：多智能体环境下的归一化技术

本章讲多智能体训练中的三种归一化：观测归一化、奖励缩放与价值归一化（PopArt），重点分析运行统计的跨回合累积、训练与评估的统计隔离，以及归一化在分布式执行接口下的约束。

  • 主题：数值尺度治理 / 统计量管理
  • 关键公式：ô = clip((o − μ) / √(σ² + ε))
  • 预计学时：55 分钟
  • 前置章节：第 025 章 探索策略在CTDE中的设计

学习目标

  • 理解多智能体环境中数值尺度失控的三个来源：异构观测分量、奖励量级漂移、价值累积尺度。
  • 掌握运行均值方差的增量更新形式（Welford 递推），以及统计量跨回合累积与训练评估隔离的原则。
  • 理解观测归一化在分布式执行中的约束：统计量必须可由局部信息估计并随策略一并冻结、保存。
  • 掌握奖励缩放与价值归一化（PopArt）的原理，包括输出层的重缩放变换。
  • 能实现带冻结开关的统计模块，并诊断统计泄漏、除零放大两类典型故障。

背景与动机

多智能体环境的观测向量通常由不同来源的物理量拼接而成：位置以米计、速度以米每秒计、能量以比例计，各分量自然量级相差若干数量级。全局状态还叠加了更多维度的任务信息。直接把这样的向量送入网络，梯度方向被大量级分量主导，小量级分量对应的特征长期得不到有效学习。

奖励侧存在同类问题：稀疏任务的一次性大额奖励与常规步级惩罚并存，回报在不同任务阶段漂移数个数量级，价值函数需要适配持续变化的回归目标。这些尺度问题在单智能体训练中已经存在，多智能体环境把严重程度放大：智能体数量越多，拼接观测的维度越高；课程与对抗训练让奖励分布随训练阶段系统性地漂移。第 025 章的探索调度了动作分布的广度，本章的归一化处理输入与目标的数值尺度，两者共同构成训练工程的基础设施。

核心原理

1. 观测归一化与运行统计

观测归一化把每个分量变换到近似零均值、单位方差的尺度，等价于给网络前端加一层在线估计的白化模块。标准形式为减去均值、除以标准差，并对结果做幅度截断：

ô = clip( (o − μ) / √(σ² + ε), −c, c ) μ、σ² 为运行统计量，ε 防止除零，c 为截断幅值（常用 5 到 10）

运行统计不能由单批次或单回合计算。批次统计把同批样本的信息泄漏给彼此，回合统计让归一化依赖回合内未来数据，二者都破坏因果性并引入训练与部署的不一致。正确做法是跨回合增量更新全局统计，用 Welford 递推同时维护计数、均值与二阶矩：

n ← n + 1；μ ← μ + (x − μ) / n；M2 ← M2 + (x − μ)旧 · (x − μ)新； 方差 σ² = M2 / n 递推形式无需保存历史样本，内存恒定；等价写法用并行合并公式支持批量喂入

统计量的作用域有两条常用策略：全体智能体共享一套统计，保持同构输入在参数共享结构下的一致性；每个智能体独立统计，适配观测分布差异明显的智能体。选择依据是参数是否共享与观测是否同构：共享参数且观测同构时用共享统计，异构智能体（第 030 章）用独立统计或按角色分组统计。混合策略（共享统计加每个智能体的仿射校准）在工程上也很常见。

2. 训练与评估的统计隔离

统计模块的行为规则可以概括为三条：训练期更新统计并应用归一化；评估期只应用训练时冻结的统计快照，不更新统计；部署时把快照随策略参数一起保存与加载。评估期更新统计量会让评测数据污染归一化参数，评估结果依赖于评估顺序与批次划分，实验不可复现；部署时不保存快照则同一策略在不同环境上产生不同的输入变换，行为漂移。

异步采样与多环境并行（第 038 章）还会引入统计竞争：多个采集进程同时写统计量，更新次序失去确定性。解决办法是统计只在学习器侧更新，采集侧使用学习器周期性广播的快照；快照间隔对应统计量的滞后时间，与目标网络的滞后管理同类处理。

3. 奖励缩放

奖励缩放的目标是稳定价值回归的数值条件。常用形式是除以回报的运行标准差：

r̃t = rt / (σR + ε) σR 为近期回合回报的标准差估计；尺度随任务进展自动调整

其原理是把价值目标的量级锁定在单位尺度附近，使学习率与梯度裁剪阈值（第 027 章）跨任务迁移。注意两点：其一，缩放系数一旦进入回报，最优策略不变（正数缩放保持策略排序），但塑形项（第 021 章）与原始奖励必须使用同一个缩放系数，否则势能抵消结构在数值上失真；其二，缩放系数本身是运行统计，同样适用训练评估隔离原则，评估回报应换算回原始尺度后再报告。

4. 价值归一化与 PopArt

价值归一化在输出层处理尺度问题：网络输出被解释为归一化价值 V̂ = (V − μV) / σV，回归目标也被同尺度变换。PopArt 的关键在于每次统计更新后重新缩放输出层，使网络直接输出未归一化的价值不受影响：

统计更新后：W ← W · σ旧 / σ新，b ← (b · σ旧 + μ旧 − μ新) / σ新 W、b 为价值输出层的权重与偏置；变换保持网络输出的物理含义连续

这一变换的意义在于兼顾两方面：内部回归目标保持在单位尺度，稳定优化；对外输出的价值估计始终是原始尺度，策略改进与优势计算无需换算。多智能体场景中，值分解算法对团队价值头维护一组 PopArt 统计，个体价值通常量级相近，可以共享同一组统计；策略梯度类算法对优势做标准化（减均值除标准差）即可获得类似效果，需要分发全局统计以保持各进程口径一致。

5. 数值算例：异构分量的尺度失衡与修复

取两个分量：位置 p ~ 均匀分布 U(0, 10)（单位米），能量 e ~ U(0, 1)（比例）。两者标准差分别为 10 / √12 = 2.887 与 1 / √12 = 0.289，比值恰好 10，数值经程序核对。对线性层而言，输入分量的尺度决定对应权重收到的梯度量级：在相同的误差信号下，小尺度分量对应的权重每次更新幅度只有大尺度分量的十分之一，能量特征需要约十倍的数据量才能达到同等学习程度。归一化把两者同时压到单位方差，权重更新的竞争回到特征结构本身而不再由量纲决定；拼接观测的异构来源越多，这一矫正的累计收益越大。

6. 数值算例：Welford 递推逐步核对

取样本序列 [4, 8, 6]，从零初始化逐步执行递推（数值经程序核对）：

最终均值 6.000，方差 m2 / n = 8 / 3 = 2.6667，与直接两遍计算逐位一致。核对要点：m2 的增量使用"更新后的均值"，第 2 步中 4 × (8 − 6) 的减数是新均值 6；用错旧均值会得到 m2 = 16，方差恰好翻倍。该样本刻意让第三个值等于当前均值，使第 3 步增量为零，便于看清递推的停止条件与数值路径。

7. 数值算例：PopArt 重缩放的恒等核验

取输出层 w = 3、b = 0.5，统计从 (μ, σ) = (2, 1) 更新到 (4, 2)。重缩放公式给出 w′ = 3 × 1 / 2 = 1.5，b′ = (0.5 × 1 + 2 − 4) / 2 = −0.75。核验原始尺度输出的连续性：更新前 raw(x) = 2 + (3x + 0.5)，更新后 raw(x) = 4 + 2 × (1.5x − 0.75)，在 x = 0、1、2.5 处两式分别给出 2.5、5.5、10.0，逐点一致，数值经程序核对。读数：重缩放不改变任何 x 处的原始尺度估计；改变的是内部归一化输出，x = 1 处从 3.5 变为 0.75，因为新统计把同一原始值解释为"低于新均值"的位置。价值损失回归的是归一化输出，重缩放后网络沿新尺度目标继续优化；策略改进读取的原始尺度价值保持连续，这就是"内部稳定、对外连续"的完整含义。

边界条件要写清楚：奖励缩放保持最优策略的前提是目标为无熵（或熵权重同步缩放）的折扣回报；同时使用最大熵目标（第 014 章）时，回报整体缩放 c 倍等价于温度除以 c，α 需要联动标定。价值统计若每个优化步都更新，回归目标随统计漂移，价值的移动靶效应会让损失曲线长期高位震荡；按固定间隔（例如每若干千步）更新可以兼顾适应速度与稳定。该纪律与观测统计的快照节奏同源，运行统计的时间常数与管理规则需要写入配置对象并跨实验沿用。

实现思路与设计

归一化模块按包装器链组织：环境出口处依次经过观测归一化与奖励缩放，价值归一化放在学习器的输出头。统计模块对外暴露 update、normalize、freeze、state_dict 四个接口，评估与部署路径只允许调用后两个。

关键代码与解读

片段 1：带冻结开关的运行统计模块

import numpy as np

class RunningStats:
    """Welford 递推统计：训练期更新，评估与部署期冻结。"""
    def __init__(self, shape, eps=1e-5, clip=10.0):
        self.mean = np.zeros(shape, dtype=np.float64)   # 用 float64 累积统计
        self.m2 = np.ones(shape, dtype=np.float64)      # 二阶矩累计量
        self.count = 1e-4                                # 平滑初值，避免首步除零
        self.eps, self.clip = eps, clip
        self.frozen = False

    def update(self, x):
        # 评估路径不更新统计：冻结后 update 直接跳过，防止评测数据污染
        if self.frozen:
            return
        x = np.asarray(x, dtype=np.float64)
        self.count += 1.0
        delta = x - self.mean
        self.mean += delta / self.count            # 均值递推
        self.m2 += delta * (x - self.mean)         # 与更新后均值配对，数值更稳

    def normalize(self, x, update=True):
        if update and not self.frozen:
            self.update(x)
        # 方差下限 1e-6：低方差分量除以接近零的标准差会放大噪声
        std = np.sqrt(np.maximum(self.m2 / self.count, 1e-6))
        return np.clip((x - self.mean) / std, -self.clip, self.clip)

    def freeze(self):
        # 训练结束或进入评估前调用：此后统计量固定，行为可复现
        self.frozen = True

解读：四个设计点对应前文三条规则加一条数值纪律。统计量以 float64 累积，与网络的 float32 分离，长训练下避免均值漂移；m2 增量使用更新后的均值，这是 Welford 稳定性的来源；freeze 提供不可逆的状态切换，评估代码只需检查一个布尔量；方差下限独立于 eps，防止常量分量的乘性噪声。若需要批量喂入，用并行合并公式把 count/mean/m2 三元组合并，代价 O(1)。

片段 2：多智能体观测归一化包装器

class MultiAgentNorm:
    """按智能体维护统计：支持共享、独立两种作用域。"""
    def __init__(self, n_agents, obs_dim, scope="per_agent", clip=10.0):
        self.scope = scope
        if scope == "shared":
            stats = RunningStats((obs_dim,), clip=clip)
            self.stats = [stats] * n_agents        # 同一对象引用，天然同步
        else:
            self.stats = [RunningStats((obs_dim,), clip=clip) for _ in range(n_agents)]

    def transform(self, obs, update=True):
        # obs 形状 (n_agents, obs_dim)；逐个智能体应用自己的统计
        return np.stack([self.stats[i].normalize(obs[i], update=update)
                         for i in range(len(self.stats))], axis=0)

    def state_dict(self):
        # 快照随策略一起保存：部署端没有训练数据，必须复用训练统计
        return {"scope": self.scope,
                "stats": [{"mean": s.mean.tolist(), "m2": s.m2.tolist(),
                           "count": s.count} for s in self.stats]}

解读：共享作用域通过对象引用复用同一统计，从数据结构层面杜绝了两套共享统计不同步的实现缺陷。独立作用域下每个智能体的统计量在长训练中可能漂移到不同的尺度，这对异构智能体是期望行为，对同构智能体则需要检查漂移幅度作为诊断指标。state_dict 快照是部署契约的一部分：推理端加载快照后调用 freeze 并只做变换，保证仿真训练与真实推理的输入变换完全一致。

片段 3：奖励缩放与 PopArt 价值头

import torch

class RewardScaler:
    """按回报标准差缩放奖励；评估回报需换算回原始尺度再报告。"""
    def __init__(self, eps=1e-8):
        self.return_mean, self.return_std, self.count = 0.0, 1.0, 0
        self.eps = eps

    def scale(self, reward, episode_return=None):
        if episode_return is not None:
            # 每个回合结束用回报更新统计，奖励序列未结束时沿用旧系数
            self.count += 1
            delta = episode_return - self.return_mean
            self.return_mean += delta / self.count
            self.return_std = max(0.1, 0.99 * self.return_std + 0.01 * abs(delta))
        return reward / (self.return_std + self.eps)

class PopArt(torch.nn.Module):
    """价值归一化输出层：内部回归用归一化尺度，对外提供原始尺度估计。"""
    def __init__(self, in_dim):
        super().__init__()
        self.linear = torch.nn.Linear(in_dim, 1)
        self.mu, self.sigma = 0.0, 1.0

    def forward(self, x):
        return self.linear(x)                  # 归一化尺度输出，用于价值回归损失

    @torch.no_grad()
    def value(self, x):
        # 原始尺度估计 = mu + sigma * f(x)，供策略改进与优势计算使用
        return self.mu + self.sigma * self.linear(x)

    @torch.no_grad()
    def update_stats(self, targets):
        mu_new = targets.mean().item()
        sigma_new = targets.std().item() + 1e-5
        # 重缩放后 mu_new + sigma_new * f_new(x) 与旧输出的原始尺度估值一致
        self.linear.weight.data *= self.sigma / sigma_new
        self.linear.bias.data = (self.linear.bias.data * self.sigma + self.mu - mu_new) / sigma_new
        self.mu, self.sigma = mu_new, sigma_new

解读：RewardScaler 的标准差用指数滑动平均估计，回报分布随任务阶段漂移时窗口自动跟随；下限 0.1 防止缩放系数趋近于零时把奖励放大到失真。PopArt 用同一线性层提供两种读出：forward 的归一化输出供价值损失使用，value 的原始尺度估计供策略改进使用。update_stats 先算新统计、再变换输出层参数，变换保证同一输入在统计更新前后的原始尺度估值连续，这是该方法的全部数学内容。两处统计更新都在 no_grad 或纯 Python 侧完成，不进入计算图；调用频率通常为每若干个优化步一次，避免统计量高频抖动。

常见坑

  • 评估期继续更新统计。评测数据进入运行统计，归一化参数随评估批次漂移，结果依赖评估顺序。症状是同一策略两次评测结果不一致。修复：评测入口调用 freeze，评测结束按需恢复。
  • 用当前回合或当前批次统计做归一化。归一化依赖同批未来数据，因果性破坏，训练与部署行为不一致。症状是策略在训练时表现良好、部署后骤降。修复：统计只在跨回合运行量上更新，批次内使用已有运行统计。
  • 统计快照管理缺失。部署端未随策略加载统计快照，观测尺度与训练错位；并行采集进程各自更新统计造成分叉。修复：快照纳入模型产物清单并在加载时断言；统计只在学习器侧更新，采集侧使用广播快照（第 038、039 章展开）。
  • ε 过小放大低方差分量噪声。接近常量或极低方差的分量在除以近零标准差后获得夸张的增益。症状是输入出现大幅尖峰、梯度范数异常。修复：设置方差下限，配合截断幅值双重约束。
  • 奖励缩放与塑形项尺度脱钩。塑形项在缩放前叠加而缩放系数按原始奖励统计，塑形项占比随训练漂移。修复：塑形与原始奖励合并后再统一缩放，或分别监控两者的比值。

练习与思考

  1. 推导：从均值与二阶矩的定义出发，推导 Welford 均值递推 μn = μn−1 + (xn − μn−1)/n，并说明它与"求和后相减"的朴素算法在数值精度上的差别来源。★
    提示
    把 μn 写成 (n−1)/n·μn−1 + xn/n 后再合并同类项；朴素算法在大量级相近样本上做减法相消，递推形式避免了这种相消。
  2. 改参数预测：把观测归一化的截断幅值 c 从 10 降到 2，预测含少量大幅异常观测的训练在熵曲线与回报曲线上的变化，并说明对低方差目标定位的影响。★
    提示
    强截断压缩目标相关分量的动态范围，位置信息分辨率下降；回报上升更慢，熵曲线更早确定化（信息不足下策略更快退化到粗粒度行为）。
  3. 设计：构造一个异构智能体任务（一个快速小智能体、一个慢速大智能体），给出归一化作用域方案（共享、独立、分组、共享加仿射校准四选一），并用观测分布假设计算各组件的归一化后尺度，说明选择理由。★★
    提示
    两类智能体速度量级不同时独立统计更合理；若两者观测同构且数量少，共享统计加每个体的仿射校准可以兼顾样本利用率与差异适配。
  4. 实验设计：在同一任务上比较无归一化、观测归一化、观测归一化加 PopArt 三种设置，指标使用价值损失的绝对值曲线与达到固定回报的环境步数，并说明为何价值损失曲线必须与回报曲线联读。★★★
    提示
    归一化后价值损失口径变化，绝对值之间不直接可比；联读回报曲线判断"损失下降是否对应真实性能"，避免把尺度变化误读为学习进展。

小结

  • 多智能体训练的尺度问题来自异构观测分量、奖励量级漂移与价值累积三个层面，分别对应观测归一化、奖励缩放与价值归一化。
  • 运行统计用 Welford 递推跨回合累积；训练更新、评估冻结、部署保存快照是统计模块的三条行为规则。
  • 归一化作用域按参数共享与观测同构性选择：共享保持一致性，独立适配异构，分组与仿射校准是折中方案。
  • PopArt 通过输出层重缩放兼顾内部单位尺度回归与外部原始尺度输出；奖励缩放必须与塑形项共用系数。
