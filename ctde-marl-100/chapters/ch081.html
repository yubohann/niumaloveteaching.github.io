第 081 章：公平性与可解释性

全局回报最大化并不保证每个智能体都获得合理收益：本章把公平性写成可优化的约束（基尼系数、Jain 指数、拉格朗日对偶），并用 Shapley 值与反事实动作替换给出策略解释的两条技术路线。

  • 主题：公平性度量与可解释性分析
  • 关键公式：基尼系数（Gini Coefficient）、Jain 公平指数（Jain's Fairness Index）、Shapley 值（Shapley Value）
  • 预计学时：55 分钟
  • 前置章节：第 080 章

学习目标

  • 理解功利主义（Utilitarian）与平均主义（Egalitarian）两类社会目标的形式差别，能写出三种社会福利函数（Social Welfare Function）。
  • 掌握基尼系数与 Jain 公平指数的定义、取值域与失效条件，能在评估脚本中独立实现。
  • 学会把公平需求写成约束式优化，用拉格朗日乘子（Lagrange Multiplier）与对偶上升（Dual Ascent）在线调节惩罚权重。
  • 理解 Shapley 值的四条公理与计算复杂度，能对不超过十个智能体的联盟精确计算贡献分配。
  • 能实现注意力权重与反事实替换两类解释方法，并说明各自的解释边界。

背景与动机

前八十章的训练目标几乎都写成全局回报总和的最大化：J(θ) = E[Σt γt Σi rit]。这一目标隐含功利主义价值观，单位回报无论归属哪个智能体都被视为等价。在多智能体部署中，这一假设经常不成立：若个别智能体长期承担高风险子任务而回报偏低，策略会出现责任分布失衡，个体失效时系统缺乏冗余。

与第 020 章信用分配的关系需要先澄清：信用分配解决"谁的贡献应当获得奖励信号"，属于训练机制；公平性解决"最终收益分布是否可接受"，属于目标函数层面的约束。可解释性把两者的计算过程暴露给分析者，回答"决策依据是什么"。三者共享同一套工具：合作博弈（Cooperative Game Theory）的贡献分解。

核心原理

1. 从全局回报到社会福利函数

把回合回报向量 r = (r1, …, rN) 聚合成标量的方式，就是社会福利函数。三种常见形式各有不同的价值取向：

Wutil(r) = Σi ri，Wmm(r) = mini ri，Wnash(r) = Σi ln ri 功利目标追求总量；最大最小目标保护最差个体；纳什福利介于两者之间

最大最小（max-min）目标直接优化时梯度只来自最差智能体，其余个体梯度为零，训练信号稀疏。实践中用软最小（soft-min）近似：−τs ln Σi exp(−ri/τs)，温度 τs 趋于零时收敛到 min；τs 增大时各项权重趋于均匀，优化方向退化为均值方向（函数值相差只与 N 有关的常数项，梯度不受影响）。纳什福利对低回报个体的边际效用更大，优化压力自动导向弱势个体。

2. 公平性度量：基尼系数与 Jain 指数

度量需要满足三个基本要求：与回报尺度无关、取值有界、对个体数量不敏感。基尼系数源自收入分布分析，是成对差绝对值的平均：

G = Σi Σj |ri − rj| / (2 N2 r̄) r̄ 为回报均值；G ∈ [0, 1]，0 表示完全均等；要求回报非负且 r̄ 显著大于零

Jain 公平指数来自网络资源分配领域，度量"平方和相对均分的集中程度"：

J(r) = (Σi ri)2 / (N Σi ri2) J ∈ [1/N, 1]，1 表示完全均等；对回报整体缩放不敏感

两者互补：Jain 指数下界确定，便于设定阈值；基尼系数对分布尾部更敏感，便于诊断"少数个体极低"的失衡形态。评估协议应同时报告总量与公平指标。

3. 公平约束与拉格朗日对偶

把公平要求写成约束式优化问题，是兼顾效率与均衡的标准做法：

maxθ J(θ)  s.t.  F(θ) ≥ τ，对应拉格朗日函数 L(θ, λ) = J(θ) + λ (F(θ) − τ)，λ ≥ 0 F 取 Jain 指数或 1 − G；τ 是公平下限；λ 是对偶变量，表示约束的边际代价

对偶上升按约束违反方向更新 λ：λ ← [λ − α (F̂ − τ)]+，F̂ 是当前策略的经验估计，α 是对偶步长。直觉：公平水平低于阈值时增大 λ，让公平项占更大权重；达标时 λ 衰减，把优化重心还给总回报。由于 F 由整回合的回报分布定义，对偶更新粒度是回合级，比动作级约束更易振荡，实践中要对 F̂ 做指数滑动平均（Exponential Moving Average, EMA）。

4. 可解释性：贡献分解与反事实替换

贡献分解把协作收益按合作博弈论分摊到个体。给定特征函数 v(S)（联盟 S 的联合价值，可用集中式 critic 的估值近似），Shapley 值是个体在所有加入顺序上的平均边际贡献：

φi = ΣS ⊆ N∖{i} |S|! (N − |S| − 1)! / N! · [v(S ∪ {i}) − v(S)] 满足效率（Σφi = v(N)）、对称、哑元、可加性四条公理；精确计算需枚举 2N 个联盟

反事实替换是另一条路线：保持其他智能体动作不变，只替换第 i 个智能体的动作，观察回报或 Q 值的变化幅度，变化越大说明该动作越关键。这一思路与第 009 章 COMA 的反事实基线同源，区别在于 COMA 用它构造训练基线，解释分析用它排序动作重要性。

注意力权重最容易获得，但必须说明边界：注意力度量信息路由的相关性，不等于因果贡献，观测冗余时两者会出现显著偏差。严谨的解释报告应给出两条路线的交叉验证。

5. 公平与效率的权衡曲线

扫描阈值 τ 并重复训练，得到一系列（总回报, 基尼系数）点对，连成帕累托前沿（Pareto Front）。前沿形状回答关键研究问题：把 Jain 指数从 0.6 提升到 0.8 需要多少总量代价；继续提升到 0.95 时代价是否陡增。陡增段的起点，通常就是约束开始扭曲个体激励的阈值区间。

实现思路与设计

把公平约束嵌入 CTDE 训练循环，标准流程分五步：

  1. 回报统计：每个回合收集各智能体累计回报 ri，计算 Jain 指数与基尼系数。
  2. 对偶更新：按 EMA 平滑后的 F̂ 更新 λ，并截断到 [0, λmax]。
  3. 奖励重塑（Reward Reshaping）：按 r′i = (1 − λ) ri + λ r̄ 把回报向量拉向均值。
  4. 策略更新：用重塑后的回报训练原有算法（QMIX、MAPPO 均可），算法本体不做修改。
  5. 双指标评估：每 T 个环境步评估一次，同时记录总回报、Jain 指数、基尼系数与 λ 轨迹。

与第 080 章的差异点：安全约束作用于状态动作对（每次决策的可行性），公平约束作用于回合回报向量的分布形状；安全约束的更新粒度为动作级，公平约束为回合级，后者的对偶变量需要更强的平滑。

超参数起点

参数默认值作用取值依据
τ（Jain 阈值）0.85公平约束下限未约束基线落在 0.6–0.75，0.85 表示明确的改善目标
α（对偶步长）0.02λ 的更新速度回合回报标准差越大，步长应越小
λmax0.5公平项权重上界超过 0.5 后个体激励排序反转
EMA 系数0.9平滑 F̂回合长度抖动越大取值越高
τs（软最小温度）0.5min 的光滑近似回报量级 0–10 时取十分之一量级
Shapley 排列采样数512贡献分解精度标准误随 1/√M 下降，N 较大时改用采样
设计决策：回报重塑相比直接修改损失函数有哪些优势？

直接给损失加公平正则项，需要把统计量反传到回合内所有时间步，梯度路径长且方差大。回报重塑在回合结束后做一次线性变换，任何算法都能直接消化。代价是引入延迟反馈：λ 的变化要经过一整个回合生效，这正是需要对偶步长与小截断上界的原因。

关键代码与解读

片段 1：公平性指标计算

import numpy as np

def fairness_metrics(returns):
    """输入 N 个智能体的回合回报，返回 (基尼系数, Jain 指数)。"""
    r = np.asarray(returns, dtype=np.float64)
    n = r.size
    # 基尼系数基于非负量定义：均值过小时先做正向平移，否则分母无意义
    if r.mean() <= 1e-8:
        r = r - r.min() + 1e-6
    # 排序后可用加权秩公式，把 O(n^2) 的成对差求和降为 O(n log n)
    rs = np.sort(r)
    idx = np.arange(1, n + 1)                # 秩从 1 开始，与公式索引对齐
    gini = 2.0 * (idx * rs).sum() / (n * rs.sum()) - (n + 1.0) / n
    # Jain 指数对回报整体缩放不敏感，直接度量平方和相对均分的集中度
    jain = (r.sum() ** 2) / (n * (r ** 2).sum())
    return float(gini), float(jain)

# 四个智能体的回合回报：总量 24，但个体差距明显
print(fairness_metrics([8.0, 7.0, 7.0, 2.0]))   # 基尼约 0.19，Jain 约 0.87

解读：（1）基尼系数的教科书定义是成对差求和，直接实现是 O(n²)；排序后按秩加权求和是等价变形，复杂度降为 O(n log n)，每回合调用也不构成瓶颈。（2）非负性是基尼系数的前提，回报含负值时必须先平移；Jain 指数对平移敏感、对缩放不敏感，这正是两者互补的原因。（3）返回值做 float 转换，避免 numpy 标量进入记录文件导致序列化不稳定。

片段 2：对偶更新与公平奖励重塑

import numpy as np

class FairnessDual:
    """把公平性下限写成约束，用对偶上升在线调节惩罚权重 lambda。"""
    def __init__(self, tau=0.85, lr_dual=0.02, lam_max=0.5):
        self.tau = tau            # Jain 指数下限：约束 g(theta) = tau - F 不超过 0
        self.lr_dual = lr_dual    # 对偶步长：与回合回报方差成反比设置
        self.lam_max = lam_max    # 权重上界，防止个体激励排序反转
        self.lam = 0.0
        self.f_ema = None

    def update_dual(self, jain_hat):
        # 用 EMA 平滑单回合统计量：回合长度与终局运气带来大幅抖动
        if self.f_ema is None:
            self.f_ema = jain_hat
        else:
            self.f_ema = 0.9 * self.f_ema + 0.1 * jain_hat
        # 低于阈值就增大 lambda，达标则逐步衰减，形成自动配平
        self.lam = float(np.clip(self.lam + self.lr_dual * (self.tau - self.f_ema),
                                 0.0, self.lam_max))
        return self.lam

    def reshape(self, r):
        """把回报向量拉向均值：低回报个体相对增益，高回报个体被压缩。"""
        r = np.asarray(r, dtype=np.float64)
        return (1.0 - self.lam) * r + self.lam * r.mean()

解读：（1）update_dual 的符号约定需要固定：约束写成 τ − F ≤ 0，违反时（F 低于 τ）λ 增大，与对偶上升的通用形式一致；固定约定可避免 λ 沿错误方向发散。（2）EMA 平滑是必需的：单回合 Jain 指数受终局随机性影响可达 ±0.1，未平滑的 F̂ 会让 λ 来回摆动。（3）reshape 采用凸组合，λ ≤ 0.5 时系数 (1 − λ) 保持为正，所有个体仍"回报越高越受鼓励"，公平项只改变相对倾斜。替代方案是直接把公平项加入损失，但梯度路径长、方差大。

常见坑

  • 对 min 目标直接求梯度：损失只由最差个体贡献，其余智能体梯度恒为零。修复：改用软最小或纳什福利。
  • Gini 在负回报或零均值下计算：分母趋近零时数值失真。修复：先平移到非负区间，或改用 Jain 指数作约束量。
  • 对偶步长过大：λ 与策略互相追逐，双指标双双不收敛，λ 轨迹呈锯齿状。修复：降低 α 到 0.01–0.02 并提高 EMA 系数。
  • 把注意力权重当因果解释：观测冗余时注意力分布与贡献排序不一致。修复：用反事实替换交叉验证，报告排序的秩相关。
  • Shapley 值在大 N 下精确枚举：N 等于 25 时联盟数超过三千万。修复：改用排列采样估计并报告标准误。

练习与思考

  1. 计算 4 个智能体回报 [6, 6, 6, 2] 的基尼系数与 Jain 指数，与正文例子 [8, 7, 7, 2] 对比：总量减少了，公平指标如何变化？★
    提示
    Jain 指数约 0.89，高于正文例子的 0.87；基尼系数 0.15，低于 0.19。总量从 24 降到 20，但分布更均匀：公平指标度量分布形状，与总量无关，两类指标要并列报告。
  2. 把对偶步长 α 从 0.02 提高到 0.2，其他参数不变。预测 λ 轨迹与双指标曲线的变化，并说明验证方法。★★
    提示
    λ 更快达到上界并在回合间大幅摆动；总回报下滑，Jain 指数在阈值附近震荡。验证：相同种子集跑三条曲线，观察 λ 方差与区间宽度。
  3. 推导 N 等于 2 时 Shapley 值公式的具体形式，验证 φ1 + φ2 = v({1, 2})，说明效率公理在推导中的来源。★★
    提示
    φ1 = 1/2 [v({1}) − v(∅)] + 1/2 [v({1,2}) − v({2})]，φ2 对称；两式相加中间项消去，取 v(∅) = 0 即得效率公理。
  4. 设计实验：在 4 智能体协作搬运任务上扫描 τ ∈ {0.70, 0.80, 0.85, 0.90}，每个设置 10 个种子，画出（总回报, 基尼系数）散点并标注帕累托前沿。★★★
    提示
    陡增段对应约束开始覆盖"任务分工导致的合理差距"：承担探索子任务的个体回报天然偏低，强行拉平会削弱其激励。可加"角色固定"对照验证。
  5. 实现反事实解释器：对一次联合动作逐个体替换为次优动作，记录总回报变化并输出重要性排序；与注意力权重排序计算斯皮尔曼（Spearman）秩相关。★★★
    提示
    替换动作在集中式 critic 上评估最方便；秩相关低于 0.5 时要在报告中写明注意力解释不可靠，并给出观测冗余导致两者背离的例子。

小结

  • 全局回报最大化隐含功利主义价值观；社会福利函数把聚合方式显式化，三种目标的梯度特性决定优化稳定性。
  • 基尼系数对分布尾部敏感但要求非负回报；Jain 指数取值有下界、尺度不变，适合作为约束量。
  • 公平约束用回合级对偶上升求解：λ ← [λ − α(F̂ − τ)]+，F̂ 需 EMA 平滑，λ 需截断。
  • 可解释性有贡献分解与反事实替换两条路线；Shapley 值满足四公理但精确计算是 2N 量级。
