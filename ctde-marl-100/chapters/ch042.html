第三篇 · 环境与任务实践

第 042 章：多智能体编队控制

编队控制的数学本质是一组成对的相对位姿等式约束；本章用图论把队形写清楚，推导误差度量与规范自由度，并说明强化学习如何在保持队形的同时完成转场机动。

  • 主题：空间协同 / 图论约束建模
  • 关键公式：eij = (pj − pi) − gij，L = D − A
  • 预计学时：60 分钟
  • 前置章节：第 041 章 多智能体粒子环境

学习目标

读完本章，应当能够把任意队形翻译成一张带约束的图，并把保持队形写成一个可优化的误差函数。

  • 掌握队形的图论表示：顶点为智能体，边为相对位姿约束，理解刚性（rigidity）条件与约束独立数的关系。
  • 理解编队误差的定义与规范自由度（gauge freedom）：为什么平移与旋转不能进入奖励，以及虚拟领航者（virtual leader）如何固定自由度。
  • 掌握拉普拉斯矩阵（Laplacian matrix）与一致性协议（consensus protocol）的推导，理解代数连通度决定队形误差的收敛速度。
  • 会区分两类任务阶段：静态队形保持与转场机动，并能分别为其设计奖励与终止条件。
  • 能为队形任务设计置换不变的观测与奖励，并正确识别不连通队形图带来的子群漂移问题。

背景与动机

编队控制把“多个智能体保持规定几何关系”这件事写成约束，是空间协同任务中约束最强的一类。

在经典控制文献里，编队问题有明确的代数结构：期望队形是一组相对位置约束，控制目标是最小化约束违背量。传统方法按领导者跟随者（leader-follower）、虚拟结构（virtual structure）、基于行为（behavior-based）三条路线展开，各自解决了队形定义与稳定性问题，但对未知动力学、避障与通信受限的适应能力有限。强化学习的介入点是把避障、能耗与队形保持放进同一个回报函数中求近似最优策略。

本章在第三篇中承担两个角色。其一是提供一组标准的图论工具（邻接矩阵、拉普拉斯矩阵、刚性条件），这些工具在后续的覆盖、追捕、协同建图章节反复出现。其二是展示约束型任务的奖励设计范式：约束违背量进入奖励时要处理规范自由度，否则策略会学到把整队平移或旋转当作“作弊”解的退化行为。理解这一点，是后续所有空间协同任务的基础。

核心原理

编队控制的原理可以概括为：用图记录期望的相对位姿约束，用误差泛函度量违背程度，用分布式协议把误差驱动到零。

1. 队形作为带约束的图

把 N 个智能体看作图的顶点，把需要保持的相对位姿看作边上的约束，队形问题就转化为约束满足与优化问题。

G = (V, E)，对每条边 (i, j) ∈ E 给定期望相对位置 gij = pj* − pi* V 为智能体集合；E 为约束边集合；gij 由期望队形一次性确定，例如三角形队形取 g12 = (1, 0)、g13 = (0.5, 0.87)

约束总数与自由度之比决定队形是否唯一确定。二维平面中 N 个智能体共有 2N 个坐标自由度，整体平移与旋转占用 3 个自由度（平移 2 个、旋转 1 个），距离型约束下确定队形形状至少需要 2N − 3 条独立约束。独立约束更少时队形可变（欠约束）；更多时出现冗余，形状已经确定但误差项之间不再独立。恰好相等且雅可比满秩时称队形刚性（rigid），这是队形能被唯一保持的数学条件。相对位姿约束同时固定边长与朝向，强于距离约束：任一连通生成树的 N − 1 条边即可把队形确定到只剩整体平移，本章任务因此采用相对位姿约束。

约束类型有三种常见形式：距离约束只规定边长，队形可绕边旋转（距离刚性）；方位约束（bearing）规定相邻连线方向，配合少量距离约束可确定形状；相对位姿约束同时规定方向与长度，信息最强但要求邻居间可直接测量或通信获得相对位姿。强化学习任务一般选择相对位姿约束，因为观测可以直接提供该量，不需要额外的测距推理。

2. 编队误差与规范自由度

误差是约束违背量，衡量当前相对位姿与期望值的偏离。

eij = ( pj − pi ) − gij ， E = Σ(i,j)∈E ‖eij‖2 eij 为边 (i, j) 上的相对位姿偏差向量；E 为队形误差能量，是全部边偏差平方和

该误差对整体平移与整体旋转不敏感：把全部 pi 同时加上同一个向量，所有 eij 不变；整体旋转会改变 eij 的取值，但若把期望相对位置同步旋转，误差同样归零。这组等价变换称为规范自由度（gauge freedom）。它带来两个设计影响：其一，奖励中不要出现绝对坐标项，除非任务确实要求固定位置；其二，闭环系统的平衡位置构成一整个等价类，评估指标应取“队形形状误差”；按“智能体绝对位置误差”评估会把等价类内的合法差异误计为误差。

转场任务需要固定规范自由度，常用手段是引入虚拟领航者：一个不参与动作的参考点 rt 按预定轨迹移动，奖励中加入智能体到参考点的位置项，要求编号与队形中位置的对应关系确定。领航者信息作为观测的一部分下发，通信拓扑退化为“卫星式”结构，工程上便于验证与调试。

3. 拉普拉斯矩阵与一致性协议

图的代数表示把分布式控制写成了矩阵运算，这是分析收敛速度的工具。

L = D − A ， ẋi = − Σj∈N(i) wij ( xi − xj ) = − ( L ⊗ I ) x A 为邻接矩阵（连边为 1）；D 为度对角矩阵；L 为拉普拉斯矩阵；wij 为边权；⊗ 为克罗内克积，表示对每个坐标分量施加同一协议

一致性协议是最简单的分布式协同律：每个智能体朝邻居的平均位置移动。它的平衡态是所有智能体位置一致，收敛速度由 L 的第二小特征值 λ2（代数连通度，Fiedler 值）决定：λ2 越大，图越“连通”，收敛越快；λ2 = 0 意味着图不连通，智能体分裂成互不交换信息的子群，各自收敛到不同位置，队形整体漂移。把一致性协议中的 x 换成相对误差 eij，就得到编队保持的基线控制器：ai = − kp Σj∈N(i) eij − kd vi。强化学习策略应当在这条基线之上额外获得避障与机动能力；增益本身由基线给定，策略无需从零学习。

4. 奖励设计：队形误差、控制代价与碰撞

队形任务的奖励由三项构成：误差能量的负值、控制量惩罚与碰撞惩罚。

rt = − wf Et − wu Σi ‖ai,t‖2 − wc ncollision + wg · 1[ Et < ε ] Et 为当前队形误差能量；ai,t 为控制量；最后一项是误差进入阈值 ε 后给予的保持奖励

误差平方项是稠密的：任何偏离都产生梯度信号，训练早期即可使用。保持奖励是稀疏的：只有误差足够小才有正回报，用于推动策略收敛到精确队形并将队形维持到回合结束。控制量惩罚抑制抖动，防止智能体用高频小幅动作反复“修正”误差而消耗能量。碰撞惩罚处理几何安全，在世界尺度较小或队形较紧密时权重需要提高。

转场阶段在奖励中加入参考点项：− wr Σi ‖ (pi − rt) − di ‖2，其中 di 是编队中第 i 个位置的期望偏移。该项把队形整体钉在参考轨迹附近，消除规范自由度，转场与保持因此可以用同一个奖励框架描述，只是参考点是否移动不同。

5. 观测设计与通信拓扑

编队任务的观测要求给出足以消除误差的信息：自身速度、到邻居的相对位姿、以及（转场时）到参考点的相对位置。

oi = [ vi, pr − pi, { pj − pi − gij }j∈N(i), mi ] pr 为参考点位置；相对位姿误差直接进入观测可显著降低学习难度；mi 为邻居掩码

若把误差 eij 直接作为观测项，策略无需自行计算期望值之差，相当于把任务的结构先验注入输入。该做法在约束型任务中普遍有效，代价是需要保证训练与执行时的 gij 一致。通信拓扑可以固定，也可以随距离时变；时变拓扑下观测槽位数量变化，上一章的固定槽位加掩码方案继续适用，但要注意通信半径与碰撞半径的比例：通信半径过小会让队形在机动时频繁断开，等价于降低 λ2。

实现思路与设计

队形任务的训练分为两个阶段进行，先固定队形保持，再叠加参考轨迹完成转场，避免两个目标同时出现时早期信号互相抵消。

1. 两阶段课程

第一阶段把参考点固定在原点附近，回合内目标仅为最小化队形误差能量，终止条件为误差持续低于阈值若干步。第二阶段让参考点沿预定轨迹（例如直线加圆弧）移动，智能体需要保持队形同时跟踪，终止条件为参考点到达终点。课程切换的判据使用阶段一的成功率，避免过早进入转场导致样本被浪费。

3. 网络结构

策略网络采用邻居聚合结构：对每个邻居槽位用共享的多层感知机（multilayer perceptron, MLP）编码，再按掩码求和或取最大完成聚合，最后与自身特征拼接送入策略头。该结构对邻居槽位顺序不变，与上一章的观测格式自然衔接。若使用图神经网络（graph neural network, GNN）消息传递，编码器可以叠加两层以获得两跳邻域信息，代价是通信量增加一倍，在队形任务中收益有限，因为约束边通常只覆盖一跳邻域。

4. 与第 041 章的差异点

第 041 章的观测是“邻居在哪里”，本章的观测是“邻居相对位姿偏离期望多少”。前者是几何量，后者是约束误差量。奖励同样如此：协作导航奖励最小化距离，不规定智能体之间的相互关系；队形奖励规定全部成对关系，任一智能体偏离都会影响多个误差项。这使得队形任务的奖励曲面耦合更强，单个智能体的动作会立刻改变邻接边的误差，信用分配问题比协作导航更尖锐，值分解或集中式评论家的作用因此更明显。

关键代码与解读

三段代码依次给出队形误差计算、拉普拉斯矩阵与一致性基线、以及邻居聚合编码。接口风格参照 PyMARL 与 MARLlib 的通用约定。

片段 1：队形误差能量与奖励

import numpy as np

def formation_error(pos, edges, offsets):
    """计算队形误差能量：edges 为约束边列表，offsets 为每条边的期望相对位置。"""
    E = 0.0
    for (i, j), g in zip(edges, offsets):
        # 期望相对位置 g 由队形设计者给定，与当前坐标无关
        e = (pos[j] - pos[i]) - g
        E += float(e @ e)          # 二次型保证误差处处可导，便于梯度传播
    return E

def formation_reward(pos, vel, acts, edges, offsets,
                     w_f=1.0, w_u=0.01, w_c=1.0, eps=0.05, collide=0.12):
    E = formation_error(pos, edges, offsets)
    # 控制惩罚用平方和：对大幅动作的抑制强于小幅动作，避免浪费机动余量
    r_u = sum(float(a @ a) for a in acts)
    n_coll = sum(1 for i in range(len(pos)) for j in range(i + 1, len(pos))
                 if np.linalg.norm(pos[i] - pos[j]) < collide)
    r = -w_f * E - w_u * r_u - w_c * n_coll
    if E < eps:                    # 稀疏保持奖励：只在精确队形附近给正反馈
        r += 1.0
    return r, {"formation_err": E, "collisions": n_coll}

解读：误差用二次型，原因是范数在零点不可导，会削弱近距离修正的梯度质量。保持奖励的阈值 ε 与误差能量同量级，取小了策略几乎拿不到奖励，取大了策略会满足于粗糙队形；实际调试时先让误差能量进入 ε 以下再观察奖励曲线的跳变。碰撞半径取 0.12，略大于智能体几何半径，给控制留出安全余量。

片段 2：拉普拉斯矩阵与一致性基线控制器

def laplacian(n, edges, weights=None):
    """构造拉普拉斯矩阵 L = D - A，供收敛性分析与基线控制器使用。"""
    A = np.zeros((n, n))
    for k, (i, j) in enumerate(edges):
        w = 1.0 if weights is None else weights[k]
        A[i, j] = A[j, i] = w          # 无向图：邻接矩阵对称
    D = np.diag(A.sum(axis=1))         # 度矩阵 = 每行权重和
    return D - A

def consensus_control(pos, vel, L, kp=1.0, kd=0.5):
    """一致性基线：朝邻居平均位置移动，用于对比学习策略的机动能力。"""
    # L @ pos 的第 i 行恰为 sum_j (p_i - p_j)，与推导的协议一致
    a = -kp * (L @ pos) - kd * vel
    return np.clip(a, -1.0, 1.0)       # 与动作空间保持一致，保证可比性

def fiedler_value(L):
    """代数连通度：第二小特征值，决定一致性协议的收敛速度。"""
    eig = np.linalg.eigvalsh(L)
    return float(eig[1])               # eig[0] 理论为 0，对应全 1 向量

解读：一致性基线控制器有三个用途：作为强化学习策略的下界参照，作为奖励塑形的先验（早期用基线动作混合采样），以及作为诊断工具（策略学到的不应差于基线）。拉普拉斯矩阵的特征值排序后第二个即代数连通度，它同时是“队形图是否连通”的判据与“误差收敛速度”的指标：λ2 接近零时，误差能量下降极慢，训练回合内看不到队形成形，常被误判为算法失效。构造时保持矩阵对称，避免有向化处理引入额外的收敛条件讨论。

片段 3：邻居聚合的置换不变编码

import torch
import torch.nn as nn

class NeighborEncoder(nn.Module):
    """把变长邻居集编码成定长特征：共享 MLP + 掩码聚合。"""
    def __init__(self, in_dim=4, hidden=64, out_dim=64):
        super().__init__()
        self.phi = nn.Sequential(nn.Linear(in_dim, hidden), nn.ReLU(),
                                 nn.Linear(hidden, out_dim))
        self.psi = nn.Sequential(nn.Linear(out_dim * 2, hidden), nn.ReLU(),
                                 nn.Linear(hidden, out_dim))

    def forward(self, self_feat, nb_feat, nb_mask):
        # self_feat: (B, F)；nb_feat: (B, K, in_dim)；nb_mask: (B, K)
        h = self.phi(nb_feat)                    # 每个邻居独立编码，参数共享
        h = h * nb_mask.unsqueeze(-1)            # 无效槽位置零，避免补零参与统计
        # 求和聚合：与邻居排列无关，槽位顺序变化不改变输出
        agg = h.sum(dim=1) / nb_mask.sum(dim=1, keepdim=True).clamp(min=1.0)
        return self.psi(torch.cat([self_feat, agg], dim=-1))

解读：共享 MLP 对每个邻居使用同一组参数，参数量不随邻居数增长，策略可以泛化到规模不同的队形。聚合前乘以掩码，保证补零槽位不进入求和；除以有效邻居数完成平均，避免邻居多时特征幅值膨胀。若任务需要区分“某个关键邻居”，可以把求和换成注意力加权，让网络自行决定关注谁，这一机制在第 047 章的异构单位场景中会再次出现。编码器输出的定长特征与自身特征拼接后送入策略头，形成完整的分布式执行网络。

常见坑

  • 奖励含绝对位置导致退化解：为了“把队形放到指定位置”，奖励里直接使用绝对坐标误差，结果策略学会整队平移的捷径而放松内部几何约束。症状是队形形状误差长期不降但总奖励上升。修复：形状项只用相对误差，位置约束交给参考点项独立加权。
  • 队形图不连通：通信半径小于期望边长，图分裂为两个子群。症状是两群智能体各自成形但相对位置任意漂移。修复：核对通信半径与期望边长的比例，补齐约束边，并把代数连通度纳入环境诊断输出。
  • 误差量纲与奖励尺度失配：误差能量随边数增长，N 增大后同一权重下学习率需要重调。症状是扩大队形规模后训练停滞。修复：把误差能量按边数归一化，或随边数同步调整权重。
  • 把编号匹配交给策略自行学习：未标记队形下同一目标有 N 种等价实现，策略需要多倍样本才能收敛。症状是训练曲线方差极大。修复：在观测中给出身份信息，或采用带分配机制的目标（例如对目标集合做最小代价匹配后再算误差）。
  • 拓扑时变时掩码失效：邻居进出通信半径时旧槽位未及时清空，观测中残留过期的相对位姿。症状是机动阶段动作突变。修复：每步重建邻居集合与掩码，过期条目立即置零。

练习与思考

  1. 推导题：三个智能体组成等边三角形：写出三条边长约束，验证 2N − 3 = 3 的计数，并说明去掉任意一条后形状的可变自由度；再说明改用相对位姿约束时，几条边即可确定形状。★
    提示
    N = 3 时 2N − 3 = 3。去掉一条边长后剩下两条距离约束，第三个顶点相对第一个顶点的夹角自由，形状一维可变（还剩整体平移与旋转 3 个自由度）。相对位姿约束同时固定边长与朝向，两条边组成的连通生成树即可确定形状，只剩整体平移。
  2. 计算题：三节点路径队形图有两条边，权重相等均为 w。写出拉普拉斯矩阵并求代数连通度；若把其中一条边权重提高到 3w，预测 λ2 与误差收敛速度的变化方向。★★
    提示
    等权时 L 的特征值为 (0, w, 3w)，λ2 = w。一条边加权到 3w 后 λ2 升到约 1.35w，收敛更快；权重分布不均时误差沿弱边方向的修正较慢，调参需要与避障项联合考虑。
  3. 改参数并预测：把控制惩罚权重 wu 从 0.01 提高到 0.5，预测队形误差曲线与动作范数曲线的走向，并判断是否会出现在误差阈值附近“躺平”的策略。★★
    提示
    控制惩罚过大时，修正误差的收益被动作代价抵消，策略倾向输出接近零的动作，误差停留在初值附近。若保持奖励权重不变，这种退化平衡会被进一步强化，需要通过奖励诊断曲线识别。
  4. 设计题：把三角形队形扩展为六机两行队形，给出约束边集与期望偏移表，说明如何保证队形图连通且约束独立。★★★
    提示
    两行各三个点，行内取相邻边与隔点边，行间取对应点边，共 9 条，达到 2N − 3 的计数。逐条检查独立性的方法是在一般位置（不共线的随机位形）对约束雅可比做秩分析，本例秩为 9，无冗余；也可以按参考位置构造图后计算 λ2 验证连通性。
  5. 实验设计：比较“观测含相对位姿误差”与“观测只含邻居相对位置”两种设置的收敛步数，说明结构先验注入观测的作用与适用边界。★★★
    提示
    含误差的观测等价于给策略预计算了约束残差，通常收敛更快。边界在于期望队形变化时观测定义随之变化，若训练与评估使用不同队形，预计算误差的先验优势会消失，需要重新训练或改用可配置的期望偏移。

小结

  • 队形用带约束的图表示：顶点为智能体，边为期望相对位姿，二维平面中 2N − 3 条独立约束确定队形形状，刚性是唯一可保持的条件。
  • 编队误差是约束违背量的平方和，对平移不敏感、对内旋转有等价类，规范自由度需要用虚拟领航者或参考点项固定。
  • 拉普拉斯矩阵与代数连通度刻画队形图的连通性与误差收敛速度，一致性协议是策略的基线与诊断工具。
  • 奖励由误差能量、控制惩罚、碰撞惩罚与阈值的稀疏保持奖励构成；观测中直接给出相对位姿误差可显著降低学习难度。
