第四篇 · 高级机制与研究专题

第 079 章：预测模型与模型预测控制结合

先学一个可用的环境动力学模型，再用滚动时域控制在线求解动作序列：本章讲清模型学习的目标与复合误差、模型预测控制（Model Predictive Control, MPC）与交叉熵方法（Cross-Entropy Method, CEM）的求解流程，再讲集中式模型与分布式规划在 CTDE 中的衔接。

  • 主题：基于模型的规划 / 滚动时域与采样优化
  • 关键公式：min Σt=0H−1cost(st, at)，st+1 = fθ(st, at)
  • 预计学时：65 分钟
  • 前置章节：第 078 章

学习目标

  • 掌握动力学模型的学习目标与增量预测形式，理解复合误差随预测步数增长的原因。
  • 掌握 MPC 的滚动时域结构：有限时域优化、执行首动作、重新规划，说明终止代价的作用。
  • 掌握 CEM 的采样与精英集更新流程，能分析采样数、精英比例与求解质量的取舍。
  • 能实现集成动力学模型、CEM 规划器与价值引导终止代价三个片段，说明它们在 CTDE 中的分工。
  • 能设计实验：模型无关基线、无模型 MPC、模型集成规模与规划时域的消融。

背景与动机

模型无关方法需要与环境交互数万回合才能获得策略，样本效率受限于每次交互只贡献一条轨迹的信息。学习一个动力学模型后，智能体可以在模型内部推演任意多条虚拟轨迹，把一次真实交互的价值放大若干倍。模型预测控制则把模型用于在线规划：不训练策略网络，每个控制周期求解一个有限时域优化问题，直接得到动作。

多智能体场景的规划遇到新的耦合：每个智能体的最优动作依赖队友的动作序列，独立规划会把队友行为当作固定背景，产生策略振荡。解决路径有三条：联合状态空间的集中式规划、预测轨迹共享后的迭代最优响应、以及用集中式价值函数作为终止代价的单机规划。本章的三条主线最后都汇入 CTDE 的价值引导结构。

核心原理

本节先讲模型学习与复合误差，再讲 MPC 与 CEM 的求解，最后讲多智能体规划的三条路径。

1. 动力学模型的学习

模型学习是监督回归：从真实轨迹采样 (s, a, s′)，最小化预测与真实下一状态的误差。常用增量形式 fθ(s, a) ≈ s′ − s，增量预测消除状态的绝对量级影响，使同一网络适合不同位置的局部动态。单模型在数据稀疏区域误差大，集成（ensemble）用多个网络头提供均值与分歧度，分歧度可以作为规划时的惩罚项。

Ldyn(θ) = E[ ‖(s′ − s) − fθ(s, a)‖2 ]，预测 st+1 = st + fθ(st, at) H 步开环预测的误差按步数累积，模型每步的微小偏差在末端被放大

复合误差是模型使用方式的核心约束：规划时域 H 越大，模型误差越可能把规划引向虚假的高回报区域。短时域加值函数终止代价是标准的折中方案。

2. MPC 与 CEM 求解

MPC 在每个控制周期优化动作序列 a0:H−1 使累计代价最小，只执行第一个动作，下一周期带着新状态重新规划。动作空间连续且代价非凸时，梯度求解易陷局部最优，采样式求解是常用替代：CEM 从高斯分布采样若干动作序列，按总代价选出精英集，用精英集拟合新的分布，迭代若干轮后取分布均值，随着迭代进行采样集中在低代价区域，兼顾全局搜索与局部精化。

分布更新：μ ← mean(精英动作)，σ ← std(精英动作) + εreg εreg 防止方差坍缩过早；每轮采样数 N 与精英比例 ρ 是主要超参数

3. 多智能体规划的三条路径

集中式联合规划把全部智能体的动作序列一起优化，维度为 N×H×|A|，小规模可行但计算量随 N 增长。预测轨迹共享加迭代最优响应适合模块化系统：每台机器人广播未来 H 步的预测轨迹，各机以固定队友轨迹求解自身 MPC，交替若干轮。价值引导规划让单机 MPC 的终端代价取集中式价值函数 V(s′)，把队友行为的长期影响压缩进价值估计，规划时域可以显著缩短。

4. 与 CTDE 的衔接

训练期用全局数据训练动力学模型与集中式价值函数，模型与价值都只在训练与规划服务器可见；执行期各智能体本地运行 MPC，输入本地观测与接收的邻居预测轨迹，输出动作。价值函数的训练复用前面章节的评论家体系，模型的不确定性惩罚用集成分歧度量，二者共同控制规划的外推风险。

5. 数值算例：复合误差、终端价值与 CEM 收敛

复合误差算例。单步模型相对误差 1%，最坏情形按线性累加估计：H=10 步开环误差上界约 10%，H=30 步约 30%。规划搜索会把模型误差当作真实收益，误差接近任务尺度时规划结果已不可信，H 的取值应截断在这一水平之前。

终端价值算例。步代价每步 1、时域 H=10、γ=0.99：段内折扣和约 9.56，终端价值 V(sH)=5 时折现为 0.9910×5≈4.52，总代价约 14.08。终端项占比约三成，说明短时域规划中远期结构的权重并不低，价值网络的偏差按同一比例进入决策，价值训练质量与模型误差同等重要。

CEM 收敛算例。初始标准差 0.75（限速 1.5 的一半），精英比例 0.1。若每轮精英分布的标准差约为原分布的 0.45 倍，五轮后收缩到约 0.75×0.455≈0.014，采样集中在低代价区域；方差下限 0.05 防止坍缩后失去搜索能力，下限与精度需求共同决定迭代轮数的上限。

解读：三个数字分别约束规划的三个参数：时域由复合误差决定，终端权重由折扣口径决定，迭代轮数由方差收缩速度决定。复现时先固定时域与终端项验证开环误差曲线，再调采样数与精英比例，两组参数分开调试可以避免把模型误差与搜索不足混为一谈。

系统分三层：数据层采集真实轨迹并训练集成模型；规划层运行 CEM；执行层下发首动作并按周期重规划。

实验设计

  1. 对比基线：模型无关 CTDE、无模型 MPC（用真实环境推演的对照上界）、随机射击规划。
  2. 消融设置：H ∈ {5, 10, 20}、集成规模 1 与 5、终端价值开/关、CEM 轮数 1 与 5。
  3. 评价指标：达到目标回报的交互步数（样本效率的核心优势）、开环预测误差随步数曲线、单步规划计算量、任务成功率。
  4. 统计方式：与模型无关基线配对多种子比较步数，报告模型误差的分位数。
设计决策：为什么用价值引导而不单纯加大规划时域

加大 H 会减小规划截断误差，同时把复合误差按步数放大，两类误差的平衡点即最优 H。价值函数把 H 之外的长期回报压缩成可学习的终端项，规划器只需对可信的短时域负责，长期结构由价值估计承担。终端价值的偏差会成为系统偏差，价值网络的训练质量与模型误差同等重要。

与第 078 章的差异：好奇心用模型误差做探索奖励，本章用模型做控制规划；前者消费误差，后者必须压低误差。

对比分析：四类规划与控制路线

路线样本效率单步计算量误差来源适用条件
模型无关 CTDE低一次前向无模型误差交互便宜、任务单一
无模型 MPC（真实环境推演）不适用多轨迹真实交互无模型误差，交互代价高低速安全场景
学习模型加 MPC高采样批量前向复合误差动力学复杂且可仿真

选择依据是交互成本与模型可信区间：交互昂贵且动力学复杂时以学习模型加短时域规划为主；模型误差在可接受区间内时优先加长时域；价值网络质量不足时缩短时域并接受截断误差，待价值训练稳定后再逐步放开。

误差审计的操作建议：把开环预测误差按步数画成曲线并随训练记录，曲线斜率决定时域上限；集成分歧度与真实误差的比值定期对照，比值长期偏离 1 说明分歧度失去校准意义，需要调整集成训练的分批方式。

关键代码与解读

片段 1：集成动力学模型

import torch
import torch.nn as nn

class EnsembleDynamics(nn.Module):
    """集成动力学：多投共享数据，输出增量与分歧度。"""
    def __init__(self, state_dim, act_dim, n_heads=5, hidden=128):
        super().__init__()
        self.heads = nn.ModuleList([
            nn.Sequential(nn.Linear(state_dim + act_dim, hidden),
                          nn.ReLU(), nn.Linear(hidden, state_dim))
            for _ in range(n_heads)])

    def forward(self, s, a):
        x = torch.cat([s, a], dim=-1)
        deltas = torch.stack([h(x) for h in self.heads], dim=0)
        mean = deltas.mean(dim=0)
        # 头间方差即认知不确定性：数据稀疏区域分歧大
        disagreement = deltas.var(dim=0).sum(dim=-1)
        return mean, disagreement

解读：各头独立初始化并在数据分批上训练即可获得多样性，头间分歧在数据稀疏处自然增大，无需额外的不确定性建模。返回的离散度用于规划惩罚，抑制利用模型盲区的"对抗性"动作序列。头数增加提升估计质量但线性放大前向计算，规划循环中需要控制调用次数。

片段 2：CEM 规划器

import torch

def cem_plan(model, s0, horizon=10, n_samples=256, elite_frac=0.1,
             iters=5, act_dim=2, act_limit=1.5):
    """采样式滚动时域规划，返回首动作。"""
    mu = torch.zeros(horizon, act_dim)
    sigma = torch.ones(horizon, act_dim) * act_limit * 0.5
    for _ in range(iters):
        noise = torch.randn(n_samples, horizon, act_dim)
        acts = (mu + sigma * noise).clamp(-act_limit, act_limit)
        total, _ = rollout_cost(model, s0, acts)   # 批量推演代价
        n_elite = max(1, int(n_samples * elite_frac))
        idx = torch.topk(total, n_elite, largest=False).indices
        elite = acts[idx]
        mu, sigma = elite.mean(dim=0), elite.std(dim=0) + 0.05
        sigma = sigma.clamp(max=act_limit)          # 方差上限防溢出
    return mu[0].detach()                           # 只执行首动作

解读：批量采样让 rollout 并行执行，规划的主要计算量集中在批量前向上，向量化写法直接决定实时性。方差下限 0.05 防止坍缩后失去搜索能力，上限防止数值溢出。规划只消费首动作是滚动时域的本质：下一周期用新观测重新求解，用闭环反馈抵消开环误差。

片段 3：队友预测轨迹与价值终端

import torch

def rollout_cost(model, s0, other_plan, acts, value_fn=None, gamma=0.99):
    """推演自身动作序列，给定队友预测规划与可选终端价值。"""
    s = s0.unsqueeze(0).repeat(acts.shape[0], 1)
    total = torch.zeros(acts.shape[0])
    for t in range(acts.shape[1]):
        a_joint = torch.cat([acts[:, t], other_plan[t].expand_as(acts[:, t])],
                            dim=-1)
        delta, disagreement = model(s, a_joint)
        s = s + delta
        # 队友轨迹按固定序列展开：本机规划对队友行为取条件
        step_cost = task_cost(s) + 1.0 * disagreement
        total = total + (gamma ** t) * step_cost
    if value_fn is not None:
        # 终端价值承担时域之外的长期回报，权重与折扣口径对齐
        total = total + (gamma ** acts.shape[1]) * value_fn(s)
    return total, s

解读：队友规划按条件输入处理，联合模型的各自输入维度在拼接处对齐，队友轨迹精度直接影响自身规划的准确度。终端价值的权重取 γH，与逐步折扣的口径一致，避免时域边界处的价值跳变。分歧惩罚与任务代价相加时需核对量级，过大时规划退化为保守爬行。

常见坑

  • 模型被规划利用：优化器找到模型误差大而虚构高回报的动作序列，真机执行失败。修复：集成分歧惩罚、动作幅度限幅与模型验证集监控。
  • 时域过长：复合误差使规划轨迹与真实轨迹分叉。修复：缩短 H 并用价值终端补偿，以开环误差曲线确定截断点。
  • 独立规划互相追逐：每台机器人把队友动作当固定背景，双方策略循环振荡。修复：迭代最优响应或共享预测轨迹，必要时退回联合采样。
  • 终端价值口径不一致：价值函数训练用的折扣与规划权重不匹配，边界回报被系统性放大。修复：统一折扣口径并以单步测试验证边界连续性。
  • 重规划频率过低：执行期间世界变化未被吸收，闭环失效。修复：按扰动时间尺度设定重规划周期，并监控预测误差回放。

练习与思考

  1. 单步模型误差 1%，说明 10 步与 30 步开环预测的相对误差量级差异。★
    提示
    误差按步数放大且方向可能一致，最坏情形按线性累加估计，30 步约为 10 步的三倍，同时受动力学非线性放大。
  2. 把 CEM 采样数从 256 降到 32，预测单步计算量与求解质量的变化，给出评估方案。★★
    提示
    计算量按比例下降、解质量方差上升；用同一状态下的规划代价与首动作差异度量质量损失。
  3. 推导：说明终端价值项 γHV(sH) 与完整无限时域回报在价值函数准确时的等价性条件。★★★
    提示
    把 H 步后的回报按 V(sH) 的定义展开，折扣对齐后两条式子逐项相等。
  4. 设计实验：H ∈ {5, 10, 20} 与终端价值开关的 2×3 对照，用模型误差曲线解释最优组合随训练阶段的变化。★★★
    提示
    训练早期模型误差大，短时域加终端价值占优；后期误差下降后长时域规划开始领先。
  5. 单步模型误差 0.5%，分别估算 H=20 与 H=40 的最坏线性累加误差；再说明终端价值占规划总代价的比例如何随 H 变化。★★
    提示
    两档误差上界约 10% 与 20%；H 增大时终端项折现因子 γH 变小，其在总代价中的占比下降，但价值偏差的影响未必同步下降，需结合误差曲线判断。

小结

  • 动力学模型用增量回归学习，集成分歧度量认知不确定性，复合误差随时域放大是规划的先验约束。
  • MPC 以"优化、执行首动作、重规划"的循环对抗开环误差，CEM 以采样与精英拟合应对非凸代价。
  • 多智能体规划的三条路径是联合规划、迭代最优响应与价值引导，后者把长期耦合压缩进集中式价值终端。
  • CTDE 下模型与价值在训练与规划层可见，执行层只运行本地 MPC；分歧惩罚与终端口径是两项关键实现细节。
  • 数值算例约束了规划的三个参数：时域由复合误差决定，终端权重由折扣口径决定，CEM 迭代轮数由方差收缩速度决定，三者分开调试避免误差来源混淆。
