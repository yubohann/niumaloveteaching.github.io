第三篇 · 环境与任务实践

第 057 章：多智能体网络安全防御

网络防御是多阶段不完全信息对抗：告警带噪声、资源有限、对手策略会适应；本章推导贝叶斯后验更新与虚拟对局求解，说明如何用约束优化处理误报预算。

  • 主题：攻防博弈 / 不完全信息决策
  • 关键公式：P( 被攻陷 | 告警 ) = P( 告警 | 被攻陷 ) P( 被攻陷 ) / P( 告警 )
  • 预计学时：65 分钟
  • 前置章节：第 056 章 多智能体对话系统

学习目标

读完本章，应当能够把防御任务写成带噪声观测的博弈，并同时处理对抗适应与运营约束两类问题。

  • 理解攻防博弈的形式化：攻击者的目标选择与手段、防御者的检测与响应资源、双方收益的零和与非零和结构。
  • 掌握告警的贝叶斯后验更新，理解假阳性与假阴性如何共同决定检测策略的价值。
  • 掌握虚拟对局（fictitious play）与极小极大求解的基本流程，能解释混合策略在防御中优于确定性策略的原因。
  • 理解约束型马尔可夫决策过程（constrained Markov decision process, CMDP）与拉格朗日乘子法，能用它处理误报预算。
  • 会设计攻防双方的人群训练与鲁棒评估，识别固定对手训练造成的乐观偏差。

背景与动机

防御决策的价值取决于攻击者如何反应，而攻击者的反应不可直接观测。

现代网络防御的主要困难有三：告警数量远超人工处理能力，误报消耗了大部分响应资源；攻击者会观察防御部署并调整手段，静态规则被绕过只是时间问题；防御资源（巡检带宽、隔离动作、审计配额）有限，需要把有限能力分配到最可能的威胁路径上。多智能体视角把防御组织为一组协同单元：检测单元负责筛选与关联告警，响应单元负责隔离与恢复，欺骗单元负责布置诱饵获取情报，三者的目标一致但动作与观测不同。

强化学习适合处理检测阈值与响应时机的联合优化：检测过松导致漏检损失，过紧导致误报泛滥。对抗维度使问题成为博弈：单方最优策略会被针对性攻击瓦解，因此训练必须包含对手适应。与追捕章节的空间合围不同，本章的博弈发生在信息空间，策略质量用损失与误报率共同衡量；与对话章节的谈判相比，通信不是主要手段，观测的噪声与欺骗是核心特征。第 080 章的安全约束与鲁棒性会把本章的约束优化方法推广到一般任务。

核心原理

本章原理分四层：攻防博弈结构、告警的后验推断、混合策略与极小极大、以及带运营约束的优化。

1. 攻防博弈的结构

攻击者选择目标与路径，防御者选择检测与响应动作，双方的收益取决于彼此的联合选择。

UA( a , d ) = 攻击收益 − 攻击成本 ， UD( a , d ) = − 资产损失 − 响应成本 − 误报成本 a 为攻击者动作；d 为防御者动作；资产损失按被攻陷资产的价值计算；两类成本刻画防御动作的代价与其副作用

收益结构随场景变化：纯破坏性攻击近似零和，以窃取信息为目标的攻击则可能非零和（攻击者获得情报而防御者未必立即损失）。非零和结构下防御者需要建模攻击者的收益；只最大化自身最坏情形会忽略攻击者的动机差异。多阶段结构是另一特征：攻击者通常先侦察、再立足、后横向移动，防御者若只在最后阶段响应，处置代价最高；早期检测的收益来自把攻击阻断在低价值阶段，这要求价值函数覆盖长时程回报。

2. 告警的贝叶斯推断

检测器输出的是带噪声的证据，防御者需要把证据与先验结合成后验威胁概率。

P( C | e ) = P( e | C ) · P( C ) / [ P( e | C ) P( C ) + P( e | ¬C ) P( ¬C ) ] ， odds 后验 = 似然比 × 先验 odds C 表示主机已被攻陷；e 为告警事件；P(e | C) 为检测率（真阳性率）；P(e | ¬C) 为假阳性率；先验 P(C) 由历史频率或上级情报给出

后验形式把检测的两个错误率分离开，便于定量比较检测器的价值：在相同假阳性率下，检测率高的检测器需要更少的响应资源；在低先验环境下（绝大部分主机正常），即使很小的假阳性率也会产生大量误报，这是告警洪泛的数学根源。防御策略的观测应当包含后验概率或其充分统计量（告警计数与似然比之和），直接使用原始告警会迫使策略从长历史中推断先验，学习效率显著下降。多源告警的关联方式是把各源的似然比相乘（条件独立假设下），得到更强的后验更新，这与证据累积的直觉一致。

基础率效应可以完整算一遍：1000 台主机、先验攻陷率 0.02，检测率 0.8、假阳性率 0.05 时，期望真阳性为 20 × 0.8 = 16 条，期望假阳性为 980 × 0.05 = 49 条，告警池中约四分之三来自误报，单条告警的后验概率约 0.246，连续两条独立告警后升到约 0.84。数字说明两件事：低先验下告警多不等于威胁多，运营压力由主机数乘假阳性率决定；证据累积是应对低先验的正确方式，后验在第二条告警后越过常用的响应阈值。假阳性率降低一半（到 0.025）时误报期望降到约 24.5 条，告警精度改善接近一倍；检测率从 0.8 提到 0.9 只把真阳性从 16 条提到 18 条。低先验环境下，压低误报的杠杆大于提高检出。

3. 混合策略与虚拟对局

存在对手适应时，确定性策略容易被针对，混合策略是博弈的稳健解。

vt( d ) = ( 1 / t ) Στ ≤ t 1[ dτ = d ] ， 攻击者最优反应：a*( t ) = arg maxa Σd vt( d ) UA( a , d ) vt 为防御者在前 t 轮的经验频率，即当前的混合策略估计；攻击者按该估计选择最优反制

虚拟对局是求解两人零和博弈的经典迭代：双方轮流对经验频率做最优反应，经验频率在循环中收敛到纳什均衡，均衡价值可用迭代下界与上界的差监控。在多智能体强化学习中，该流程对应对手建模的训练循环：防御方维护对手动作的统计，按统计求稳健响应；对手也按同样方式更新，双方策略在训练中互相适应。工程上的简化是种群训练：维护一组历史对手，按能力加权采样，效果接近显式求解但实现更直接。混合策略的代价是行动的可预测性下降，运营层面需要说明随机化的动机（降低攻击者的确定性收益），这属于部署沟通问题，训练报告应包含策略分布的熵作为随机化程度的度量。

4. 误报预算与约束优化

运营约束把误报率限制在人力可处理的范围内，问题从无约束回报最大化变为约束优化。

maxθ E [ Σt γt rt ] s.t. E [ Σt γt ct ] ≤ B ， L( θ , λ ) = E[ 回报 ] − λ ( E[ 成本 ] − B ) ct 为每步的误报与响应成本；B 为预算上限；λ ≥ 0 为拉格朗日乘子，其经济含义是预算的影子价格

拉格朗日法把约束吸收进目标：当约束满足时 λ 趋近于零，约束收紧时 λ 上升，策略在“回报与成本的边际交换”处最优。实现上通常用双变量更新：每轮用当前 λ 调整奖励并做一步策略改进，然后按约束违反程度调整 λ（违反则增大、满足则减小）。该结构与第 048 章的价格机制同源：λ 是防御资源的价格，只不过这里的“资源”是误报预算。约束优化要求训练日志同时跟踪回报与成本两条曲线，只看回报会掩盖约束违反。

5. 欺骗与信息战

欺骗手段（蜜罐、诱饵文件、虚假拓扑）通过改变攻击者的信息结构获得优势。

蜜罐的价值在于把无差别扫描转化为可观测的活动：攻击者一旦触达诱饵，防御者获得高置信度的告警。代价是资源配置与可能的反向利用（攻击者识破诱饵后制造假线索）。学习型部署把诱饵位置作为动作，奖励包含“诱饵被触达次数”与“高风险资产未受掩护的暴露时间”，两者联合优化。评估欺骗效果时需要对照组：相同配置下不部署诱饵的损失曲线，差异才是欺骗的净收益。

实现思路与设计

实现采用轻量网络模型：若干主机节点、攻防双方的离散动作与带噪声检测器，回合以攻击完成或时间耗尽结束。

1. 环境循环

每步：攻击者选择一个动作（侦察、利用、横向移动、放弃）；防御者选择巡检主机、调整检测阈值或实施隔离；环境按检测率与假阳性率生成告警；双方观测更新；结算损失与成本。攻防双方策略交替更新，对手池保存历史检查点。评估统计平均损失、误报率、检测延迟与阻断阶段分布。

3. 网络结构与训练要点

防御策略的观测包含各主机的后验威胁概率、资源占用、历史告警计数与攻击阶段估计。策略网络可以按角色拆分为检测头与响应头，共享主干。训练循环为“防御更新若干回合、攻击更新若干回合”的交替节奏，对手池按与当前策略的胜负比加权采样。约束处理使用拉格朗日乘子，λ 作为环境状态的一部分进入观测，使策略能感知当前的预算压力。评估含三组对手：随机攻击、规则攻击与训练检查点，报告最差组的表现。

4. 与第 056 章的差异点

对话系统的核心是通信协议学习与离散梯度，双方在协作框架下对齐编码；防御系统的核心是不完全信息对抗，观测本身被对手影响（欺骗与隐蔽），且约束来自运营预算。对话系统的评估关注协调率与新搭档泛化，防御系统的评估关注最坏情形损失与误报预算满足率。两章共享的技术是人群训练与对手建模，差异在优化目标的性质：协作任务可分解，博弈任务需要混合策略。

关键代码与解读

三段代码分别实现贝叶斯告警更新、虚拟对局求解与约束型奖励。

片段 1：告警后验更新

import numpy as np

def posterior_compromised(prior, alerts, tpr=0.8, fpr=0.05):
    """多源告警的贝叶斯更新：按似然比连乘得到后验。"""
    odds = prior / (1.0 - prior + 1e-12)     # 先验几率
    for e in alerts:
        # 每条告警贡献一个似然比：真阳性概率比假阳性概率
        lr = tpr / fpr if e == 1 else (1 - tpr) / (1 - fpr)
        odds *= lr                            # 条件独立假设下似然比相乘
    return odds / (1.0 + odds)                # 几率转概率

def alert_priority(post, asset_value, response_cost):
    """优先级：后验威胁与资产价值成正比，与响应成本成反比。"""
    # 该分数用于排队与巡检顺序，不直接作为奖励
    return post * asset_value / (response_cost + 1e-9)

解读：几率形式把概率乘法转换成比率乘法，数值上更稳定（避免连续相乘下溢），先验概率为零或一时用微小量兜底。似然比的构造对未告警事件同样适用：没有告警并不意味着威胁为零，比率小于一，后验随时间衰减。优先级分数把资产价值与响应成本纳入排序，与贝叶斯后验解耦，便于分别调整与验证。实现注意告警输入的编码约定（1 表示告警，0 表示无告警），若原始告警是多级强度，可按等级拆分多个似然比。

片段 2：虚拟对局求均衡

def fictitious_play(payoff, iters=200):
    """两人博弈的虚拟对局：双方对经验频率做最优反应。"""
    n_a, n_d = payoff.shape
    counts_a = np.ones(n_a)                  # 经验计数从 1 开始，避免零概率
    counts_d = np.ones(n_d)
    values = []
    for _ in range(iters):
        d_mix = counts_d / counts_d.sum()
        a_mix = counts_a / counts_a.sum()
        # 攻击者对防御频率取最优反应（收益最大），反之亦然
        a_best = int(np.argmax(payoff @ d_mix))
        d_best = int(np.argmin(a_mix @ payoff))
        counts_a[a_best] += 1
        counts_d[d_best] += 1
        # 均衡价值可用双方混合策略的期望值监控收敛
        values.append(float(a_mix @ payoff @ d_mix))
    return counts_a / counts_a.sum(), counts_d / counts_d.sum(), values

解读：payoff 矩阵以攻击者为行、防御者为列，攻击者最大化、防御者最小化（零和约定）。经验计数从 1 开始相当于拉普拉斯平滑，保证早期不出现零概率导致的确定性策略。价值序列的振荡幅度收敛到零说明接近均衡，监控该序列比单看策略频率更可靠。迭代次数取数百已足够小规模博弈，实际矩阵维度大时可用遗憾最小化（regret matching）替代，两者的收敛性质不同但工程实现相近。求出的混合策略可以作为防御策略的初始化或对照基线。

片段 3：约束型奖励与乘子更新

class LagrangianBudget:
    """把误报预算约束吸收进奖励：r' = r - lambda * 成本。"""
    def __init__(self, budget=5.0, lr_lambda=0.05, lam=0.0):
        self.budget, self.lr_lambda, self.lam = budget, lr_lambda, lam
        self.cost_sum = 0.0

    def reset(self):
        self.cost_sum = 0.0                  # 每回合重置成本累积

    def shape(self, reward, cost):
        self.cost_sum += cost
        # 拉格朗日形式：成本按当前乘子定价后从回报中扣除
        shaped = reward - self.lam * cost
        return shaped, {"cost_sum": self.cost_sum, "lambda": self.lam}

    def update_lambda(self):
        """回合结束后按约束违反程度调整乘子：违反增大，富余减小。"""
        violation = self.cost_sum - self.budget
        self.lam = float(np.clip(self.lam + self.lr_lambda * violation, 0.0, 5.0))
        return self.lam

解读：乘子作为可学习参数在回合间更新，更新方向由约束违反量决定，这是原始对偶方法的标准形式。乘子上限截断防止训练早期权重爆炸；下限为零对应约束不活跃时惩罚消失。成本累加与乘子更新分函数实现，回合边界清晰，避免成本跨回合泄漏。诊断时把 λ 曲线与成本曲线联合观察：λ 持续贴在零附近说明预算从未收紧，可能需要把预算调低以验证约束机制；λ 贴在上限说明约束在技术上不可满足，需要增加防御资源或放宽预算。

常见坑

  • 忽略假阳性成本：奖励只计损失，策略把检测阈值调到最灵敏，误报压垮响应能力。症状是损失下降而误报率飙升。修复：成本项进入约束或惩罚，报告误报预算满足率。
  • 对手池单一：只与固定攻击者训练，评估损失乐观，换攻击风格后失效。修复：对手池覆盖多种风格并按能力加权采样，评估报告最差组。
  • 观测缺少告警历史：策略仅依赖瞬时告警无法累积证据，需要自行从零推断先验。修复：观测中加入后验概率或告警计数统计量，降低推断负担。
  • 先验估计缺失：把全网先验设为常数，忽略了不同主机的暴露差异，后验失真。修复：按主机角色维护差异化先验，或把暴露度作为观测特征参与策略推断。
  • 确定性策略评估：只在确定性策略下评估，混合策略的稳健性无法体现，还会低估对手的最优反应收益。修复：评估时对方使用最优反应，报告随机化程度的熵指标。

练习与思考

  1. 计算题：先验 0.02、检测率 0.8、假阳性率 0.05，计算单条告警后的后验威胁概率；再算连续两条告警后的概率。★
    提示
    先用几率乘法：先验几率约 0.0204，乘以似然比 16 得到约 0.327，转概率约 0.246；第二条再乘 16 得约 5.23，概率约 0.84。两条告警即把低先验提升到高置信度。
  2. 推导题：说明为何在低先验环境下，相同假阳性率的检测器产生的误报数量随主机数增加而急剧上升，并给出误报期望的表达式。★★
    提示
    误报期望等于未攻陷主机数乘假阳性率，主机数增加时该乘积线性上升，而与真阳性相关的收益只随真实攻击数量增长，二者比例失衡导致信噪比恶化。
  3. 改参数并预测：把误报预算从 5 次降到 2 次，预测平均损失、误报率与拉格朗日乘子曲线的变化方向。★★
    提示
    预算收紧后误报率下降、损失上升，乘子抬升到新的平衡水平。乘子曲线先上升后稳定，上升的幅度与损失增量对成本的交换率对应。
  4. 设计题：为蜜罐部署设计动作空间与奖励项，说明如何度量欺骗的净收益，并给出防止策略过度依赖诱饵的约束。★★★
    提示
    动作可为诱饵位置与数量；奖励包含诱饵触达次数与高风险资产暴露时间。净收益需用同配置无诱饵的对照组计算。约束可以是“高价值资产必须有不低于基线的巡检频率”。
  5. 实验设计：比较“交替更新”与“同时更新”两种攻防训练节奏的均衡价值与稳定性，说明判定收敛的指标。★★★
    提示
    用双方策略的经验频率与均衡距离（例如与虚拟对局解的距离）作为收敛指标，并报告损失曲线的滑动方差。同时更新通常震荡更大，交替更新收敛慢但稳定。

小结

  • 网络防御是多阶段不完全信息博弈，收益结构在零和与非零和之间变化，防御决策需要考虑攻击者的最优反应。
  • 告警的贝叶斯后验由先验与似然比决定，低先验环境下假阳性主导误报量，后验或充分统计量应进入观测。
  • 混合策略是博弈的稳健解，虚拟对局通过交替最优反应逼近均衡，经验频率的收敛可用价值序列监控。
  • 误报预算用约束型目标建模，拉格朗日乘子作为预算的影子价格在回合间更新，训练需同时跟踪回报与成本。
