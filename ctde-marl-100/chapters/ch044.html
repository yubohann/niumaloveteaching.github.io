第三篇 · 环境与任务实践

第 044 章：多智能体追捕问题

追捕任务的成败取决于合围几何：追捕者需要在逃逸者的角度空间上形成完整封锁；本章把合围写成角度覆盖问题，推导最大间隙指标，并说明对抗训练为何必须管理对手策略。

  • 主题：对抗协同 / 合围几何
  • 关键公式：gap = maxk ( θk+1 − θk ) ，包围完备当且仅当 gap ≤ 2 arcsin( rc / d )
  • 预计学时：65 分钟
  • 前置章节：第 043 章 多智能体覆盖问题

学习目标

读完本章，应当能够把合围判定写成角度空间的覆盖条件，并为对抗训练设计可诊断的奖励与对手策略管理流程。

  • 理解追捕问题的不完全信息对抗结构，能写出双方的观测、动作、奖励与捕获条件。
  • 掌握合围几何的量化方式：相邻追捕者的角度间隙、逃逸锥与封锁条件，理解捕获半径与包络距离的代价关系。
  • 掌握角色分配的两个视角：扇区分配视角与阻挡逼近分工视角，并能说明两者与第 043 章分区思想的联系。
  • 理解追捕奖励中径向项与切向项的分工，能解释单侧挤压（herding）退化解的成因与修复方式。
  • 掌握对抗训练的对手策略管理：自博弈（self-play）、策略池采样与过拟合识别。

背景与动机

追捕问题是第三篇中第一个双方目标直接对立的场景，它同时检验协同能力与对抗适应能力。

追捕逃逸（predator-prey）是粒子环境最早的任务之一：多个追捕者围住一个移动目标，目标持续逃跑，追捕者需要分工封锁。直接朝目标移动的策略会失败，原因在于目标可以从追捕者之间的空隙穿过，这在几何上等价于视角覆盖存在缺口。传统求解思路有两条：基于势场的合围控制，把追捕者安排在目标周围的均匀角度位置；基于围捕-驱赶（herding）的分工策略，一部分追捕者压缩目标的活动空间，另一部分预判目标移动方向封堵。强化学习把两条思路统一在奖励函数里，让策略自行发现分工。

对抗结构带来额外困难。逃逸者也在学习，追捕者面对的转移分布持续变化，训练目标非平稳。若逃逸者固定不变，追捕者会过拟合到特定逃跑路线；若双方同时更新且更新速度不匹配，追捕方会退化为追着目标跑的简单策略并停止改进。第三篇后续章节中的自动驾驶协同、网络安全防御、金融交易都面临同类问题，本章的对手策略管理方法是通用的。

核心原理

追捕任务的理论核心是合围条件：追捕者的位置分布在目标的角度空间上是否形成完整封锁。

1. 问题形式化与捕获条件

追捕方有 N 个智能体，逃逸方有 M 个（通常 M = 1 起步），双方动作空间相同，速度能力有明确比例。

捕获成立 ⟺ maxi ‖ pi − q ‖ ≤ dc 且 ∀ i, j 相邻夹角 θj − θi ≤ θmax q 为逃逸者位置；dc 为捕获半径；θi 为追捕者 i 相对逃逸者的方位角，按升序排列

捕获条件包含距离与角度两部分。距离条件保证追捕者足够近，角度条件保证封锁完整。若速度比不利（逃逸者最大速度显著高于追捕者），角度封锁在物理上不可达，任务退化为追不上；实践中的速度比通常取 1.0 至 1.3 之间，保证合围可行且策略有改进空间。角度条件依赖捕获半径：半径越大，允许的角度间隙越大，因为逃逸者穿过间隙时经过的弧长更长，追捕者有时间响应。

2. 合围几何：角度间隙与逃逸锥

把追捕者相对逃逸者的位置投影到角度环上，得到一组方位角，合围完整程度由相邻角之间的最大间隙度量。

gap = maxk ( θ(k+1 mod N) − θ(k) ) ，封锁条件 gap < 2 · arcsin( rblock / di ) θ(k) 为排序后的方位角；rblock 为单个追捕者可封锁的弧长半径参数；di 为该方向上的追捕距离

该条件的几何含义是：间隙对应的弧长不超过追捕者的封锁范围。最小化最大间隙属于极小极大问题，与覆盖一章的连续划分问题结构同源：两者都把几何布置写成对区域（角度环）的覆盖，差别在目标泛函，覆盖一章最小化平均代价，本章最小化最坏间隙。角度环长度有限且没有边界，合围求解不会出现角落遗漏，但存在相位问题：全部追捕者需要均匀分布在环上，任何集中都会在其他位置留下缺口。

目标选择逃跑方向时，评估每个方向上的封锁程度，选择间隙最大的方向逃逸。因此追捕方的有效策略同时包含两项：压缩最大间隙（均匀占位）与缩短包络半径（逼近）。两项存在代价冲突：逼近过程中追捕者之间的角间距会因为各自的位置调整而抖动，若逼近过早，目标从抖动间隙中穿出；若只顾均匀分布而保持距离，目标在中心长期存活，回合以失败告终。

3. 角色分配：扇区与阻挡逼近分工

锁定式的角色分配把角度环切成 N 个等长扇区，每个追捕者负责一个扇区的封堵。

sectori = [ 2π (i − 1) / N , 2π i / N ) ，目标角 φi = 2π ( i − 0.5 ) / N sectori 为第 i 个追捕者的责任扇区；φi 为其扇区中心角，追捕者朝该方向上距离 dtarget 的包围点移动

扇区分配的优点是结构清晰，每个追捕者有明确的包围点，策略学习等价于从任意位置移动到以目标为原点、角度为 φi、半径 dtarget 的移动参照点。缺点是需要目标位置作为分配基准，目标移动时扇区随之旋转，追捕者需要持续跟踪；以及锁定扇区在部分追捕者落后时不愿跨区支援，形成死板分工。

动态分工视角来自围捕-驱赶策略：追捕者按当前方位角与速度分为两组，驱赶组位于目标运动方向的同侧并施加压力，阻挡组预置在目标可能转向的前方。两类角色在回合中动态切换，切换依据是目标的朝向与双方速度向量夹角。文献中常见的行为分解（包围、逼近、阻挡）可以作为奖励塑形的先验：三项行为分别对应角度均匀项、径向距离项与目标前向封堵项，策略在组合奖励下自行调度。

4. 奖励设计：径向、切向与稀疏捕获

追捕奖励的常见形式把几何目标分解为三个可微分量。

rt = − wr Σi ‖ pi − q ‖ − wg · gapt + wf Σi max( 0, d̂i · êt ) + wcap · 1[捕获] 第一项压缩包围半径；第二项压缩最大角度间隙；第三项奖励位于目标逃逸方向前侧的追捕者，d̂i 为追捕者相对目标的方向单位向量，êt 为目标速度方向单位向量，取正部分只统计前侧封堵者；最后一项为捕获的稀疏奖励

径向项单独使用时会产生单侧挤压：追捕者聚集在目标一侧，把目标推向墙角（若有边界）或者沿直线追赶，角度间隙不降反升。切向项（角度间隙项）修正这一倾向，力度不足时策略仍然偏向挤压，力度过大时追捕者排斥彼此、包围圈越来越大，给目标留出机动空间。惩罚项与稀疏捕获奖励的权重比决定收敛行为：稀疏奖励过小时策略停在“围而不攻”的平衡，过大时策略放弃合围直接冲刺，因为冲刺存在低概率捕获的期望收益。

团队共享奖励与个体奖励的混合方式也影响结果：共享项推动合围，个体项（例如个体到目标的距离）提升样本效率但引入搭便车行为（部分智能体离得远，依赖队友完成捕获而自己获得团队奖励）。常见折中是共享项为主、个体项为辅，并按个体到目标的距离加权个体项，让完成封堵关键动作的智能体获得更高回报。

5. 对抗训练与对手策略管理

逃逸者的策略也由学习得到，追捕方面对的是非平稳的转移分布。

自博弈是最直接的方案：双方各自更新，环境对双方对称。问题在于胜负信号的零和性质会导致训练震荡，一方暂时领先会压制另一方的学习信号。策略池是常用的稳定手段：保存历史对手检查点，每次训练回合从池中采样对手，追捕方因此同时面对多种逃跑风格。池的成分需要两层平衡：多数是近期对手（保持难度匹配），少数是历史困难对手（防止遗忘）。对手能力评估用胜率或平均捕获步数，采样概率与其能力挂钩。

若无法承担双方同时训练的开销，固定逃逸者策略需要谨慎处理：固定策略越强，追捕方训练越有效，但固定策略的表达能力是上限，追捕方学到的是针对该策略的最优回应，无法获得一般能力。折中做法是让逃逸者仅在特定路线族内随机化，既保留一定多样性，又使追捕方的训练分布稳定。

实现思路与设计

实现分为环境层、奖励层与对抗训练层，三层可以独立替换。

1. 环境与评估流程

环境包含 N 个追捕者与 M 个逃逸者，位置随机初始化，逃逸者初始位置与任何追捕者的距离不小于捕获半径的两倍。每步双方同时输出动作，环境按同一套动力学推进。评估时固定一组逃逸者策略（含随机策略与若干检查点），统计三项指标：捕获率、平均捕获步数、平均最大角度间隙。第三项在失败回合中尤为重要，它衡量追捕方离成功有多远。

2. 关键参数与取值依据

3. 网络结构与训练循环

追捕方共享一套策略网络，观测包含自身状态、逃逸者相对位置与速度、邻居追捕者相对位置。逃逸方使用独立网络与独立观测（不含追捕方历史）。集中式评论家读取双方全量状态，可以对追捕方内部共享，但不要跨阵营共享，否则价值估计混合了双方视角。更新节奏采用交替更新：追捕方更新 K 个回合后切换逃逸方更新，避免双方策略同时剧烈变化导致震荡；K 在 5 至 20 之间取值，过小震荡过大，过大使对手过时。

4. 与第 043 章的差异点

覆盖任务的分区基准是静态区域，本任务的分区基准随目标移动；覆盖任务的均衡对象是面积，本任务的均衡对象是角度；覆盖任务的反馈完全来自代价函数，本任务还要应对对手的主动扰动。三处差异中，对抗性是根本性的：目标可以针对追捕者的策略调整逃跑方向，追捕者的最优策略随对手能力变化，落到双方耦合的均衡策略上，不再单调收敛到某个几何配置。这也是奖励设计需要在径向与切向之间精细权衡的原因。

关键代码与解读

三段代码分别实现合围指标、捕获判定与奖励、以及对抗训练的对手采样。

片段 1：合围角度指标

import numpy as np

def encircle_metrics(pos, q):
    """计算合围指标：方位角、最大间隙与逃逸方向估计。"""
    rel = pos - q                                  # 追捕者相对目标的向量
    ang = np.arctan2(rel[:, 1], rel[:, 0])         # 方位角取值 (-pi, pi]
    ang = np.sort(np.mod(ang, 2 * np.pi))          # 归一到 [0, 2pi) 后排序
    if len(ang) < 2:
        return ang, 2 * np.pi, rel
    # 相邻角之差构成环上的间隙；最后一个间隙跨越 2pi 边界，需要单独补上
    gaps = np.diff(np.concatenate([ang, ang[:1] + 2 * np.pi]))
    max_gap = float(gaps.max())
    return ang, max_gap, rel

def gap_penalty(pos, q, w_g=1.0):
    """把最大间隙转成惩罚项：间隙越小越好，均匀合围时间隙为 2pi/N。"""
    _, max_gap, _ = encircle_metrics(pos, q)
    return -w_g * max_gap

解读：角度排序后用差分计算间隙，这是环上间隔的标准做法。跨 2π 边界的间隙通过把第一个角加 2π 拼接得到，若遗漏这一步，最大间隙会被系统性低估（环被当成直线段）。指标返回排序后的角度，供诊断绘图使用：均匀合围时角度序列接近等差数列，偏斜分布一眼可辨。单个逃逸者的均匀基准间隙为 2π/N，可以据此判断策略的合围程度距离理想值还差多少。

片段 2：捕获判定与奖励合成

def pursuit_reward(pos, q, prev_gap, w_r=0.1, w_g=1.0, w_cap=10.0,
                   d_c=0.12, theta_max=1.2):
    """追捕方奖励：径向压缩 + 间隙压缩 + 捕获稀疏奖励。"""
    d = np.linalg.norm(pos - q, axis=1)            # 各追捕者到目标距离
    r_radial = -w_r * float(d.sum())               # 逼近项：缩短包络半径
    _, max_gap, _ = encircle_metrics(pos, q)
    r_gap = -w_g * max_gap                         # 合围项：压缩最大缺口
    # 捕获判定：距离全部门限内且最大间隙小于允许值，两者同时满足
    captured = bool((d <= d_c).all() and max_gap <= theta_max)
    r = r_radial + r_gap + (w_cap if captured else 0.0)
    info = {"max_gap": max_gap, "min_dist": float(d.min()), "captured": captured}
    return r, captured, info

解读：捕获判定要求距离与角度同时满足，只检查距离会奖励“一群追捕者挤在同一侧把目标围住”的假捕获。prev_gap 参数保留在接口中用于后续扩展（例如对间隙的下降给额外进展奖励），当前实现直接用绝对间隙惩罚。奖励中不含目标前向封堵项，因为该项需要目标速度方向，属于可选增强；在初步实验中先跑通基础版本，再按诊断结果决定是否加入。

片段 3：对手策略池采样

import random

class OpponentPool:
    """维护历史对手检查点，按能力加权采样，抑制自博弈震荡。"""
    def __init__(self, recent_ratio=0.7, min_pool=4):
        self.pool = []                             # 元素为 (策略对象, 能力分)
        self.recent_ratio = recent_ratio
        self.min_pool = min_pool

    def add(self, policy, score):
        # 能力分由最近若干回合的胜率或生存步数估计
        self.pool.append((policy, float(score)))

    def sample(self, rng):
        if len(self.pool) < self.min_pool:
            return None                            # 池未满时回退到当前策略
        recent = self.pool[-self.min_pool:]        # 近期对手：难度与当前接近
        old = self.pool[:-self.min_pool] or recent # 历史对手：防止遗忘
        # 按最近比例采样，池越新越难，训练分布随之逐步加难
        src = recent if rng.random() < self.recent_ratio else old
        weights = np.array([s for _, s in src]) + 1e-6
        probs = weights / weights.sum()            # 能力强弱决定被采概率
        idx = int(rng.choice(len(src), p=probs))
        return src[idx][0]

解读：池未满时回退到当前策略，保证训练早期不会因为对手缺席而空转。近期与历史的分组采样让训练难度自动校准：追捕方变强后，近期对手的采样概率上升，历史弱对手占比下降。能力分参与采样权重，优势对手被更频繁地复现，防止策略在简单对手上刷胜率。权重加小常数的目的是避免所有能力分为零时采样分布未定义。该结构同样适用于逃逸方训练，只需交换传入的策略来源。

常见坑

  • 单侧挤压退化解：只保留径向距离项时追捕者聚集在目标一侧，角度间隙不降。症状是捕获率长期为零但奖励曲线持续上升。修复：提高间隙项权重，并在诊断中把最大间隙与距离曲线分开绘制。
  • 捕获判定的角度条件遗漏：只按距离判定，追捕者只需围在目标一侧即可获得稀疏奖励。症状是评估捕获率虚高。修复：距离与角度双条件判定，或采用“目标各方向逃逸锥均被封锁”的更严格判定。
  • 速度比设置失衡：逃逸者远快于追捕者时任务不可解，训练表现为策略退化为追赶直线。症状是所有评估回合都在步数上限失败。修复：把速度比控制在 1.0 至 1.3，或通过缩短逃逸者的初始距离补偿。
  • 与固定对手过拟合：逃逸者策略单一，追捕方学到针对特定路线的反应。症状是训练评估优秀而换对手后捕获率骤降。修复：引入对手策略池，评估集至少包含随机策略与两个历史检查点。
  • 稀疏奖励权重失衡：捕获奖励过小时策略停在“围而不攻”，过大时策略放弃合围直接冲刺。症状分别是对称地表现为捕获步数上限与最大间隙居高不下。修复：按稠密项单步量级标定捕获奖励，并观察两种失败模式的诊断曲线。

练习与思考

  1. 计算题：N = 4 时均匀合围的理想最大间隙是多少？若捕获半径 dc = 0.12、包围距离 d = 0.5，按弧长近似估算每个追捕者能封锁的最大角度，判断理想间隙是否满足封锁条件。★
    提示
    理想间隙为 2π/4 = π/2 ≈ 1.571。单侧封锁角约 2·arcsin(0.12/0.5) ≈ 0.484，四者合计 1.94 小于 2π，说明仅靠几何封锁不够，需要策略压缩包围距离增大封锁角。
  2. 改参数并预测：把速度比从追捕 1.0 / 逃逸 1.2 改为 1.0 / 0.8，预测捕获率与平均捕获步数的变化，并判断是否会出现新的退化策略。★★
    提示
    逃逸者变慢后捕获率上升，策略可能退化为直接追击而不再维持合围，因为追赶本身就足够。要同时观察合围指标；只看成功率会误判策略质量。
  3. 设计题：为两个逃逸者的场景设计合围判定，说明如何把单目标的“最大间隙”推广为可计算的指标。★★
    提示
    可对每个逃逸者分别计算其附近追捕者的最大间隙后取平均，或定义“距离最近逃逸者的追捕者数”作为封堵约束。需要明确追捕者同时应对两个目标时的分配关系，这回到扇区分配思想。
  4. 实验设计：比较“双方同时更新”与“交替更新 K = 10”两种节奏的捕获率曲线，给出判定训练震荡程度的指标与工作流程。★★★
    提示
    可用捕获率的滑动标准差与对手策略池内胜率差作为震荡指标。同时更新的曲线波动更大、双方胜率长期在 0.5 附近来回；交替更新曲线更平滑但总样本效率低，需要权衡。
  5. 推导题：在追捕者速度略低于逃逸者时，证明单靠径向逼近无法缩小包围圈，并给出需要切向分量出现的最小速度差条件。★★★
    提示
    逃逸者总能沿径向分量相反的方向加速远离，径向距离的下界由速度差与反应延迟决定。切向分量的作用是把逃逸者逼向其他追捕者，使逃逸方向上的封锁角增益大于速度劣势，可从逃逸锥被压缩的速率出发推导。

小结

  • 追捕任务的捕获条件是距离与角度的联合判据，角度条件可用最大间隙刻画，均匀合围的理想间隙为 2π/N。
  • 合围在数学上是角度环上的极小极大覆盖问题，与覆盖章节的分区思想同源，度量空间从平面区域换成角度环。
  • 奖励需要径向压缩与角度压缩两项配合，单侧挤压是权失衡的典型退化解；捕获稀疏奖励按稠密项量级标定。
  • 对抗训练的稳定性依赖对手策略管理：策略池按能力与新鲜度采样，交替更新避免双方同时剧烈变化。
