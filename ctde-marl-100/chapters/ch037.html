第二篇 · 训练工程与稳定性

第 037 章：训练稳定性与种子方差

本章讲训练结果的方差来源与报告规范：初始化、采样与协调分叉如何造成种子间差异，四分位均值（Interquartile Mean, IQM）与分层自助置信区间的构造，概率改进与崩溃率的报告，以及方差缩减的受控手段。

  • 主题：统计报告 / 稳定性度量
  • 关键公式：IQM = 截去上下四分位后的均值
  • 预计学时：55 分钟
  • 前置章节：第 036 章 超参数敏感性分析

学习目标

  • 理解多智能体训练种子方差的来源，能区分可缩减的技术方差与源于多均衡分叉的结构方差。
  • 掌握均值、中位数、四分位均值（IQM）三种聚合统计的适用条件与失效场景。
  • 掌握分层自助置信区间的构造：先对种子重采样再对评测点聚合，理解两层结构的必要性。
  • 掌握概率改进与崩溃率两个稳定性相关指标的定义与报告方式。
  • 能设计满足可复现规范的报告方案，并识别挑种子、平滑后统计两类报告错误。

背景与动机

多智能体训练的种子间差异常与算法改进的效应同量级：同一算法在 10 个随机种子上的最终回报可能横跨两个数量级，个别种子完全失败。这种分布形态使"均值加减标准差"的传统报告方式失效：方差大时均值被离群种子拉动，标准差在非正态分布下失去解释力，读者无法判断性能波动是常态还是事故。

第 036 章解决如何选择配置的受控比较，本章解决如何报告结论：给定一批种子上的训练结果，用什么统计量概括中心趋势，用什么区间表达不确定性，用哪些辅助指标刻画稳定性。报告规范的目标是让读者能够独立判断"算法 A 优于算法 B"这一主张在多大范围内成立；孤立的最优数值无法承担这一功能。

核心原理

1. 种子方差的来源

按可干预程度分类：

来源机制性质
初始化网络参数随机起点不同，早期行为差异被策略改进放大技术方差，可被更多种子平均
采样噪声动作与探索的随机序列不同技术方差，共同随机数可部分消除
环境随机局面生成、对手扰动不同技术方差，评测协议固定后可控
协调分叉对称任务存在多个等价协调模式（左绕与右绕），不同种子收敛到不同模式结构方差，来自任务本身的多均衡性
训练路径非平稳耦合使微小差异沿训练放大混合方差，与任务和算法相关

协调分叉需要单独识别：性能直方图呈双峰时，方差反映的是"收敛到哪个模式"的不确定性，增加种子数只能让两个峰更清晰，无法消掉峰间距离。这类方差的诊断方式是聚类分析或按终态协调模式分组统计，报告应分别给出各模式的性能；混淆技术与结构方差会导致对算法稳定性的错误判断。第 034 章联盟内多均衡的讨论提供了同一现象的机制解释。

来源识别有一个可操作的最小流程：对全部种子的终值做直方图或单变量聚类检查，聚成两类且类间距离远大于类内散布时，给每个种子标注模式（例如绕行方向），模式内与模式间分开统计。模式内方差不下降说明分叉判断有误，回到单峰解释；模式间均值显著不同时，报告模式到达率与各模式内的性能两组数字。

两类方差的处置方向相反：技术方差靠增加种子与配对缩小，结构方差靠改变任务结构或接受多模式共存。把结构方差当作技术方差处理，会在双峰任务上持续加种子而不见收敛；把技术方差误判为结构方差，会在单峰任务上过早放弃统计细化。两类判断的初始成本都很低（直方图加简单聚类），在任何正式报告前先做这一步。

2. 聚合统计的选择

三种常用统计量的性质对比：

  • 均值与标准差。在近似对称分布上信息完整；分布右偏或含崩溃样本时均值被拉动、标准差夸大。
  • 中位数与四分位距。对离群值稳健，反映典型表现；缺点是完全忽略分布尾部，无法区分"无崩溃"与"25% 崩溃"两种情形。
  • 四分位均值（IQM）。截去最小的 25% 与最大的 25% 样本后取均值，兼顾稳健性与尾部敏感性：
IQM = mean( { ys : Q0.25 ≤ ys ≤ Q0.75 } ) ys 为种子 s 的汇总性能；截尾比例取 25% 属于领域惯例

IQM 的取舍是显式的：它不掩盖中位数附近的分布细节，同时不被极端种子支配；作为代价，它忽略的恰好是尾部信息，因此尾部分析必须与崩溃率配套呈现。报告建议三件套：IQM（中心趋势）、中位数与四分位距（稳健描述）、均值与标准差（与旧文献可比）。

三件套的分工在数值上互补：均值对分布的对称性敏感，中位数只依赖排序、完全不反映尾部，IQM 保留中间百分之五十的分布信息。报告的默认顺序是 IQM 作为主数字，中位数与四分位距作为稳健性描述，均值与标准差仅在需要与既有文献对齐时给出并注明口径。

3. 分层自助置信区间

性能数据有两个嵌套层级：种子层与评测点层。忽略层级的重采样（把所有点一锅重采样）会低估不确定性，因为同一种子的相邻评测点高度相关。正确做法是分层自助：

对种子做有放回重采样 → 在重采样集合上计算聚合统计 → 重复 B 次得到区间 聚合统计可为 IQM、中位数或终值；B 取 1000 到 10000

该构造对应"如果重新做一批种子实验，聚合值会怎么波动"，比正态近似区间更贴合重尾分布。两个纪律随区间一起执行：所有比较使用同一批重采样索引（配对），区间基于未平滑的逐点评测计算（平滑会低估方差）。

配对的自助实现要求两个算法共享重采样索引：对同一次有放回抽样同时取出 A、B 的同一批种子，区间基于配对差值构造；各自独立重采样时区间宽度回到独立比较的水平，配对设计在统计阶段被抹掉的收益无法追回。自助次数取 5000 时区间端点的蒙特卡洛波动已小于图表可视精度，继续提高次数只增加计算量。

4. 概率改进与崩溃率

比较两个算法时，除差值区间外报告概率改进：

P(A > B) ≈ (1/|S|) Σs∈S 1[ yA(s) > yB(s) ] 在共享种子集合上的经验估计 共享种子时估计规则简单；无共享种子时需借自助重采样估计

概率改进把"A 在多数种子下优于 B"与"A 的均值更高但胜率接近一半"区分开来。崩溃率定义需要任务相关阈值：以基线算法的中位数为下限，统计低于该阈值的种子比例，或统计训练中回报跌破阈值后未恢复的比例。崩溃率是 IQM 的互补指标：IQM 上升而崩溃率不变说明整体提升，IQM 上升但崩溃率也上升说明改进集中在少数种子、整体稳定性反而恶化。

崩溃阈值的一个标定例子：基线终值中位数 10，阈值取其一半 5；某算法 10 个种子中 2 个终值低于 5，崩溃率为 0.2。若该算法的 IQM 高于基线百分之十五且崩溃率同为 0.2，结论是整体提升；若 IQM 同样高出百分之十五而崩溃率升到 0.4，改进集中在少数强种子，稳健性实际下降，结论应表述为性能上限提高，不能表述为整体更优。阈值随基线一同冻结，中途更换阈值会让历史结论不可比。胜率在 0.5 附近时估计最不稳，报告时应给出区间；胜率高于 0.8 时点值已能支撑方向性结论。

5. 数值算例：三种统计量的对照与区间收窄速度

取 10 个种子的终值 (0.2, 0.5, 0.6, 0.62, 0.65, 0.7, 0.72, 0.75, 0.8, 2.0)：均值为 0.754，中位数为 0.675，IQM 截去两端各 2 个样本后对中间 6 个取均值，得 0.673。一个离群种子（2.0）把均值拉到 0.754，高出 IQM 约 0.08；中位数与 IQM 几乎不受该种子影响：分布带有崩溃侧离群值时，均值报告会系统性高估典型表现；中位数与 IQM 相互印证说明中心趋势稳健，两者的差距本身是分布偏态的指示。

截尾比例与种子数的配合可以核对：10 个种子截百分之二十五，恰好去掉两端各两个；5 个种子时 floor(5 × 0.25) = 1，实际去掉两端各一个（相当于百分之二十），中间三个样本的均值比名义定义的保护范围略宽。截尾比例不变而种子数下降时，IQM 的执行层面保护范围在漂移，报告需要注明实际截取的样本数。

区间收窄速度按样本量的平方根倒数：标准误从 5 个种子到 20 个种子收窄为一半（√(5/20) = 0.5），从 20 到 80 再收窄一半。5 增到 20 的区间改善幅度与 20 增到 80 相当，边际收益并未随种子数快速增长；预算允许时先补种子，再考虑增加配置数。

双峰分布的对照：让 5 个种子终值为 10、另 5 个为 20，均值、中位数与 IQM 同为 15，三个统计量都无法提示分叉。这一构造说明聚合并不能替代分布检查：终值直方图与双峰检测是必须与聚合量同时呈现的图件，单看任何一个数字都会把模式分化读成中等表现。复现实验交付时把种子矩阵、模式标签与聚合脚本一并归档，报告中的每个数字都能追溯到原始曲线。

实现思路与设计

报告管线以种子矩阵为中心：每个（配置，种子）产出一条评测曲线，终值由曲线末段窗口的均值给出；聚合器提供 IQM、分位数与分层自助区间；报告模板固定输出表格与两类图（分位带曲线、终值分布）。

参数默认值作用取值依据
种子数至少 5，建议 10估计方差方差越大所需种子越多；资源受限时优先保证对照配对
终值窗口末 10% 训练步的最后 3 个评测点均值定义汇总性能避开单点噪声，捕捉收敛平台
截尾比例25%IQM 构造领域惯例；种子数少于 8 时不建议截尾超过 20%
自助次数 B5000区间精度区间端点波动小于可视精度即可
崩溃阈值基线中位数的 50%崩溃率定义任务相关，随基线一同冻结
曲线呈现中位数 + 25/75 分位带稳定性可视化原始种子细线可叠加透明显示

与第 036 章的衔接点：敏感性实验的入选配置在本章规范下报告最终结论；配对比较的种子集合与这里的报告种子集合一致，避免两处统计口径分裂。

种子矩阵的存储方式影响分析效率：以（配置，种子，评测点）三维张量落盘，聚合器按任意维度切片；终值窗口、截尾比例等口径参数随矩阵一起保存，任何历史图件都能按当时口径重建。评测点维度保留未平滑数据，展示层的平滑在读取时应用，不写回存储；终值窗口、截尾比例与自助次数作为元数据随矩阵冻结，跨阶段统计不再重设。

关键代码与解读

片段 1：IQM 与分层自助区间

import numpy as np

def iqm(scores, trim=0.25):
    """四分位均值：截去两端各 trim 比例的样本后取均值。"""
    x = np.sort(np.asarray(scores, dtype=np.float64))
    lo = int(np.floor(len(x) * trim))              # 下截断位置
    hi = len(x) - lo                               # 上截断位置
    return float(x[lo:hi].mean())

def iqm_ci(seed_curves, n_boot=5000, seed=0):
    """分层自助：先重采样种子，再聚合，重复 B 次得到区间。"""
    arr = np.asarray(seed_curves, dtype=np.float64)  # (n_seeds, n_points)
    n = arr.shape[0]
    rng = np.random.RandomState(seed)
    finals = arr[:, -5:].mean(axis=1)              # 每种子终值：末 5 个评测点均值
    stats = np.empty(n_boot)
    for i in range(n_boot):
        idx = rng.randint(0, n, n)                 # 单位是种子：保持点层相关性
        stats[i] = iqm(finals[idx])
    return {"iqm": iqm(finals),
            "ci95": (float(np.percentile(stats, 2.5)), float(np.percentile(stats, 97.5)))}

解读：重采样单位选种子是分层自助的全部要点：评测点在种子内部高度相关，把它们视为独立样本会把区间压窄一半以上。终值取末段多个评测点的均值，吸收单点评测噪声；截断比例与样本量挂钩，5 个种子时截 25% 会丢掉两端各一个多，区间估计变得跳跃，故实践中配合更多种子：种子数不足时退化为中位数报告。seed 参数固定后区间可复现，多算法比较时必须传入同一实测集合与同一自助种子。

片段 2：配对概率改进

def prob_of_improvement(scores_a, scores_b, seed=0):
    """共享种子下估计 P(A 优于 B)：对种子集合做配对比较。"""
    a, b = np.asarray(scores_a), np.asarray(scores_b)
    assert a.shape == b.shape, "成对估计需要共享种子"
    wins = (a > b).astype(np.float64)              # 逐种子胜负：抵消种子效应
    # 自助重采样给出胜率的区间：0.5 附近的估计需要区间才能下结论
    rng = np.random.RandomState(seed)
    boot = [wins[rng.randint(0, len(wins), len(wins))].mean() for _ in range(2000)]
    lo, hi = np.percentile(boot, [2.5, 97.5])
    return {"p_improve": float(wins.mean()), "ci95": (float(lo), float(hi)),
            "n_seeds": len(a)}

解读：概率改进与差值均值提供互补视角：差值均值回答"提升多少"，胜率回答"提升有多普遍"。两者背离时的解释是性能分布的分叉：A 在多数种子上略优、在少数种子上远落后，报告需要结合终值分布图说明。接口接受未配对的输入会直接断言失败，这是刻意的：无共享种子时应先走第 036 章的独立比较流程，在报告层掩盖配对缺失属于错误做法。

片段 3：崩溃率与分位带汇总

def stability_report(seed_curves, baseline_median, collapse_ratio=0.5):
    """汇总：崩溃率、终值分布与跨种子分位带。"""
    arr = np.asarray(seed_curves, dtype=np.float64)
    finals = arr[:, -5:].mean(axis=1)
    threshold = baseline_median * collapse_ratio
    # 崩溃率：终值低于阈值的种子比例；同时给出从未达到基线的比例
    collapse_rate = float((finals < threshold).mean())
    never_above = float((arr.max(axis=1) < baseline_median).mean())
    bands = {"median": np.median(arr, axis=0),
             "q25": np.percentile(arr, 25, axis=0),   # 分位带不做平滑
             "q75": np.percentile(arr, 75, axis=0)}
    # 双峰检测：终值列表出现明显双峰时提示按协调模式分组再统计
    hist, _ = np.histogram(finals, bins=max(3, len(finals) // 3))
    bimodal = bool((hist > 0).sum() >= 2 and hist.min() == 0)
    return {"collapse_rate": collapse_rate, "never_above_baseline": never_above,
            "bands": bands, "check_bimodal": bimodal}

解读：三个输出对应三类问题：collapse_rate 回答稳定性，never_above 回答是否存在整段失败的种子，check_bimodal 提示分布是否需要按模式拆分后再统计。分位带直接使用未平滑数据，保证视觉呈现与统计口径一致；双峰检测用直方图空隙的简易判据，命中时把样本按终态行为聚类（例如协调模式标签）分别报告，这一步把结构方差从技术方差中剥离。

常见坑

  • 3 个种子下报结论。小样本下均值与标准差自身波动巨大，区间极宽或偶然极窄；3 个种子的聚合量标准误约为 10 个种子的一点八倍（√(10/3) ≈ 1.83）。修复：至少 5 个种子，关键结论用 10 个以上；资源不足时应减少配置数并保留种子数。
  • 用标准差比较不同量级的任务。回报尺度不同使标准差不可直接比较，甚至同一任务上崩溃种子会主导标准差。修复：报告 IQM 与崩溃率；需要方差时用变异系数或按尺度归一。
  • 报告选择偏差。挑最平滑的种子作图掩盖真实波动；只报终值使中期崩溃不可见。修复：叠加全部种子与分位带，曲线图与终值表同时呈现，曲线不做重平滑。
  • 平滑后统计方差。平滑显著低估评测点间波动与崩溃幅度。修复：统计量一律基于原始逐点评测，平滑只用于展示层。
  • 双峰分布按均值报告。两个协调模式被均值折叠成中间值，读者无法察觉分叉。修复：双峰检测命中后按模式分组报告。

    点估计逐渐稳定到真实值附近，区间宽度按样本量的平方根倒数收窄；收益递减意味着从 5 到 20 的改善可观，从 20 到 50 的改善有限。
  3. 设计：为一个存在左右两个等价协调模式的任务设计报告方案，说明如何标注模式、如何在两种模式下分别汇总，以及合并报告时使用什么指标。★★
    提示
    按终态行为聚类标注模式（例如绕行方向），分模式报告 IQM 与崩溃率，合并层报告模式到达率的稳定性。
  4. 实验设计：对两个算法在 10 个共享种子上做配对比较，同时报告差值区间、概率改进与崩溃率三个指标，构造一个三者结论不完全一致的例子并解释数据的分布形态。★★★
    提示
    A 多数种子小幅领先但两个种子崩溃、B 无崩溃时：差值均值可能接近零、胜率 0.8、崩溃率 A 高；结论取决于任务对崩溃的容忍度。

小结

  • 种子方差分技术方差（初始化、采样、环境）与结构方差（协调分叉）；后者要用聚类分组统计处理。
  • IQM 截去两端 25% 后取均值，兼顾稳健与尾部敏感；与中位数、均值三件套联报。
  • 分层自助按种子重采样再聚合，区间解释为"重做一批种子实验的波动"；比较时共享重采样索引。
  • 概率改进回答提升的普遍性，崩溃率与双峰检测回答分布的尾部与形状；三者与 IQM 互补。
