第一篇 · CTDE 基础与核心算法

第 010 章：MADDPG多智能体连续控制

连续动作空间的第一条主线：每个智能体一副确定性演员加一个集中式评论家，评论家对全体动作可微，演员直接沿价值函数的梯度方向改进。MADDPG（Multi-Agent Deep Deterministic Policy Gradient）把离策略的深度确定性策略梯度搬到多智能体设定，本章给出推导、实现与探索噪声设计。

  • 主题：连续控制 / 确定性策略梯度
  • 关键公式：∇θi J = 𝔼[ ∇θi μi(oi) · ∇ai Qi(s, a) | ai = μi(oi) ]
  • 预计学时：55 分钟
  • 前置章节：第 009 章

学习目标

  • 理解连续动作空间为何排除值分解与反事实边际化的直接套用，确定性策略梯度如何绕开动作上的最大化与求和。
  • 掌握多智能体确定性策略梯度的形式：只需评论家对自身动作可导，队友动作作为条件输入。
  • 掌握实现结构：每智能体一套演员与集中式评论家、经验回放、软更新目标网络、行为噪声探索。
  • 会实现连续动作的协作位移任务版演员与评论家接口，并解释动作缩放与边界饱和的成因。
  • 能说明单评论家的高估问题，为第 011 章 MATD3 的双评论家机制建立动机。

背景与动机

第 006 至 009 章的方法都依赖离散动作空间：值分解要对个体动作取最大，反事实基线要对自身动作求和。连续动作下这两个操作都会变成优化问题或积分，无法在每次更新中精确完成。连续控制需要另一条路线：既然动作不可枚举，就让评论家对动作可微，用梯度代替搜索。

MADDPG（Multi-Agent Deep Deterministic Policy Gradient）的组织方式是：每个智能体维护确定性演员 μi(oi) 与一个集中式评论家 Qi(s, a1, …, aN)，评论家训练期可读取全部动作，演员沿 ∂Qi/∂ai 的链式方向更新。每个智能体配一个评论家，让"我的动作对团队价值的贡献"由专属评论家度量；评论家输入全体动作，把队友策略的影响显式条件化。训练采用离策略回放与软更新目标网络，执行期演员只用本地观测。原始论文面向合作、竞争与混合动机场景，本课程聚焦合作设定，混合动机变体在第二篇讨论。MADDPG 的结构问题（单评论家高估）由第 011 章的 MATD3 修补。

核心原理

本节给出确定性策略梯度的推导直觉、多智能体版本的形式、评论家目标与训练循环，以及评论家数量选择的讨论。

1. 确定性策略梯度

随机策略用 ∇log π(a|o) 估计梯度，需要动作采样与方差控制；确定性策略 μ(o) 把动作视为可导映射，梯度可以直接穿过评论家。单智能体的深度确定性策略梯度（Deep Deterministic Policy Gradient, DDPG）给出：

∇θ J = 𝔼o∼ρμ [ ∇θ μ(o) · ∇a Q(s, a) |a = μ(o) ] 推导直觉：J(θ) = 𝔼[Q(s, μ(o))]，对 θ 求全导数即链式乘积；无需对动作分布求导，也无需 log 技巧。前提是 Q 对动作可微

多智能体版本逐智能体写出：智能体 i 的参数只影响 μi，价值度量用其专属评论家 Qi：

∇θi J = 𝔼(s, a)∼D [ ∇θi μi(oi) · ∇ai Qi(s, a1, …, aN) |ai = μi(oi) ] 关键细节：求导路径只经过 ai 这一个动作变量；其他智能体的动作作为评论家输入的常数项参与前向。更新 μi 时其他演员的参数保持不变，多智能体策略改进以"轮流改进"的形式交替进行

2. 评论家目标与信用分配

评论家 i 用时序差分学习，目标动作来自目标演员：

yi = r + γ (1 − done) · Qitarget( s′, μ1target(o′1), …, μNtarget(o′N) )； L(φi) = 𝔼[ ( yi − Qi(s, a) )² ] 合作任务中团队回报 r 对所有评论家相同；"谁的贡献"由每个评论家对自身动作的敏感性 ∂Qi/∂ai 承载。目标侧用目标演员生成下一动作，抑制自举目标的漂移

评论家数量是一个设计变量。每智能体一个评论家（Qi）让每个评论家专注评估"在前述策略组合下，智能体 i 的动作价值"；全部智能体共享一个评论家（Q(s, a)）参数量更省，但对不同智能体的动作差异缺少区分结构，消融实验中常见的退化是共享评论家对弱势智能体的梯度信号偏弱。MADDPG 默认逐智能体评论家，共享版本作为第 004 章参数共享思想的延伸实验。

3. 训练循环：离策略回放与软更新

MADDPG 的数据效率来自离策略回放：联合转移 (s, a, r, s′) 入池，任意时刻可重复采样。目标网络采用 Polyak 软更新：

θ′i ← τ θi + (1 − τ) θ′i， φ′i ← τ φi + (1 − τ) φ′i， τ 取 0.01 软更新让目标缓慢跟随，兼顾稳定与新鲜度；硬拷贝周期更新是等价选择，本课程统一用软更新以配套第 011 章的延迟更新设计

探索在第 002 章 ε-greedy 的连续对应物：动作 = μ(o) + 噪声。噪声尺度从较大值随环境步衰减，保证早期覆盖动作空间、后期精调。回放池中存储的是"加噪后的执行动作"，评论家对所有执行过的动作都有监督信号；若误存去噪动作，评论家会低估高探索区域的覆盖，学习曲线出现"评估好看、探索无效"的割裂。

4. 与前三章的衔接

接口层面：第 003 章的集中式评论家接口（状态加联合动作）原样复用；第 009 章的反事实边际化被链路求导替代；第 006 至 008 章的值分解不出现。执行层面：演员是确定性的，部署时无采样噪声，这对控制类任务是一致性优势。MADDPG 的已知短板集中在评论家：单评论家的逼近误差在确定性目标下被反复放大，形成系统性高估；第 011 章沿 TD3 路线引入双评论家与延迟更新。

5. 数值算例：链式梯度的一步更新

把链路求导逐步算一遍。取一维观测 o = 1，演员为单神经元加 tanh：μ(o) = tanh(w·o + b)，w = 0.5，b = 0；评论家取 Q(a) = 3 − (a − 0.8)²，真最优动作在 0.8。各因子与一步更新如下（数值经程序核对）：

评论家敏感度∂Q/∂a = −2(a − 0.8)0.6758

参数梯度0.6758 × 0.7864 × 10.5315

继续第二步得到 w = 0.5975、Q = 2.9299，单步增益从 0.0259 收缩到 0.0182。因子拆解说明两点：其一，梯度是"评论家敏感度 × 网络导数 × 输入"的连乘，任一因子为零参数即停滞；动作逼近目标后 ∂Q/∂a 自动趋零，形成内置的自适应步长。其二，tanh 导数在预激活离零较远时快速衰减，预激活的初始化方差与观测尺度会经该因子长期放大或压制学习速度，这是动作输出层不加大初始化幅度的直接原因。数值上还可核对边界：把 w 推到 3.0 后预激活进入饱和区，1 − tanh²(3.0) = 0.0099，梯度几乎消失，此时学习停滞来自输出层的结构性平区，与优化器状态无关。

6. 确定性策略梯度与随机策略梯度的对照

维度确定性策略梯度（DDPG / MADDPG）随机策略梯度（COMA 的连续推广）
策略输出单一动作动作分布（含均值与方差）
梯度方差低，无动作采样噪声高，依赖基线质量与采样量
探索来源外部注入动作噪声分布自带熵，策略可学噪声水平
离策略复用天然支持，回放池直接复用需要重要性修正或用近策略约束
典型失效确定性目标高估、噪声相关盲区策略塌缩到低熵、方差爆炸
适合场景连续控制、数据效率优先多模态最优动作、探索敏感任务

对照结论：连续控制任务中确定性路线的数据效率优势明显，代价是探索完全交给外部噪声，噪声设计失误没有策略内部机制可以补救；方差型路线把探索写进策略本体，却失去回放池的复用效率。第 012、013 章将展示另一条折中：用随机策略加近策略约束保留稳定性，用集中式评论家保留信用信号。

实现思路与设计

本节给出 MADDPG 的组件与配置。连续动作设定沿用协作位移任务的连续版本：动作是每个智能体的速度增量 vi ∈ [−1, 1]，位置按速度积分并裁剪在区间内。

评论家结构输入 (s, a1, …, aN) 拼接，隐藏 128动作进入输入前按幅度归一化，避免尺度失衡

预热步数104 环境步随机动作填池评论家初始拟合需要覆盖数据，预热结束后再启动学习

与第 009 章的差异点：数据采集从回合内批改为持久回放；策略从随机改为确定性；信用信号从反事实基线改为评论家对个体动作的梯度。数据集接口保持不变（联合转移加全局状态），新增字段为"执行动作的幅度归一化"与"动作范围元数据"，供两种评论家共享。

设计决策：动作归一化放在评论家入口的理由

不同任务的动作幅度差异大（速度增量与力矩的尺度可差两个数量级），评论家输入若混用原始尺度，对动作的敏感度会被幅度差异主导，梯度方向偏袒大尺度动作。归一化有两种放法：演员输出层直接缩放，或评论家入口统一除以范围。选择后者的理由是复用性：评论家被多套演员共享时（消融实验），入口归一化对全部来源一致生效；缩放后的原始动作仍按任务语义存入回放池，评估与日志沿用物理单位。该处理与第 026 章的状态归一化遵循同一原则：语义单位与学习单位分离。

探索噪声的两个实现细节

其一，各智能体的噪声随机流必须独立。若全部智能体共用同一随机种子或同一噪声向量，噪声在智能体间完全相关，联合探索退化为沿单一方向移动，协作策略中的相对位形几乎不被扰动。其二，独立噪声的联合幅度随智能体数增长：N 个标准差 0.3 的独立高斯分量，噪声向量模的期望约为 0.3×√N（N = 4 时实测约 0.564，N = 10 时约 0.925，数值经程序核对）。团队动作若以向量形式整体驱动任务状态，建议把每维噪声幅度按 √N 归一，或为每个智能体设定独立的噪声预算，避免规模扩大后整体抖动失控。噪声衰减表与环境步数挂钩并保留小幅常值底线（如 0.05），完全退火到零会让策略丧失偏离当前轨迹的能力，持续学习场景中尤为不利。

关键代码与解读

片段 1：确定性演员与逐智能体评论家

import torch
import torch.nn as nn

class Actor(nn.Module):
    """确定性演员: 输出连续动作, tanh 保证有界后按任务范围缩放。"""
    def __init__(self, obs_dim, act_dim, act_limit=1.0, hidden=64):
        super().__init__()
        self.act_limit = act_limit
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, act_dim), nn.Tanh(),
        )

    def forward(self, obs):
        return self.act_limit * self.net(obs)     # 动作范围写入网络接口

class Critic_i(nn.Module):
    """智能体 i 的集中式评论家: 输入状态与全部动作的拼接。"""
    def __init__(self, state_dim, n_agents, act_dim, hidden=128):
        super().__init__()
        in_dim = state_dim + n_agents * act_dim
        self.net = nn.Sequential(
            nn.Linear(in_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, 1),
        )

    def forward(self, state, all_acts):
        # all_acts: (B, N*act_dim) 已按动作范围归一化的拼接向量
        return self.net(torch.cat([state, all_acts], dim=-1)).squeeze(-1)

解读：两个网络各自的接口约定都直接编码了理论假设。（1）演员的 act_limit 是构造参数，输出层用 tanh 保证数值有界，缩放发生在网络出口，参数梯度自然会考虑边界（饱和区梯度趋零，这既是约束也是"软限位"）。（2）评论家输入不含智能体标识，它的"身份"由实例化决定，每个智能体持有自己的评论家实例，这与设计决策中"逐智能体评论家"一一对应；若改为共享评论家，需要在输入加入 id 嵌入，接口变更点在此处。

片段 2：评论家更新

def critic_update(critic, target_critic, target_actors, batch, gamma=0.95):
    """评论家一步: 目标动作由目标演员生成, 不参与梯度。"""
    s, acts, rew, ns, obs_next, done = batch
    with torch.no_grad():
        # 目标动作: 全部智能体的目标演员在下一观测上输出
        next_acts = torch.cat(
            [ta(obs_next[:, i]) for i, ta in enumerate(target_actors)], dim=-1)
        q_next = target_critic(ns, next_acts)
        y = rew[:, 0] + gamma * (1.0 - done[:, 0]) * q_next
    q_pred = critic(s, acts)
    # 均方误差: 该评论家只学过"数据集中出现过的联合动作"的价值
    return ((q_pred - y) ** 2).mean()

解读：目标动作链是这段代码的语义核心：评论家 i 的目标值使用全部目标演员（不只是 i 的目标演员），因为 Qi 的输入需要完整的动作向量。（1）torch.no_grad 包裹目标侧，防止梯度经目标演员回流到在线参数，这是离策略自举的通用纪律。（2）每个智能体调用本函数更新自己的评论家时，目标侧涉及其他智能体的目标演员；多智能体交替更新的顺序不影响正确性，因为目标演员全部处于冻结求值状态。（3）损失对评论家 i 单独反传，其他评论家不被触碰，逐智能体结构在优化层面的体现即"每个评论家只负责一个视角的价值函数"。

片段 3：演员更新与软更新

def actor_update(actor_i, critic_i, batch, others_acts, act_scale):
    """演员 i 一步: 只用 Q_i 对 a_i 的梯度, 其他动作作为常数输入。"""
    s, obs_i = batch
    a_i = actor_i(obs_i)                           # 当前确定性动作 (B, act_dim)
    # 拼接评论家输入: 其他智能体的动作用数据集执行值, 且 detach 为常数
    all_acts = torch.cat([others_acts.detach(),
                          a_i / act_scale], dim=-1)  # 归一化与评论家入口一致
    q = critic_i(s, all_acts)
    # 最大化 Q_i: 损失取负, 梯度经 a_i 回传到演员参数
    return -q.mean()

def soft_update(online, target, tau=0.01):
    # Polyak 软更新: 目标参数按 tau 比例向在线参数滑动
    with torch.no_grad():
        for p_o, p_t in zip(online.parameters(), target.parameters()):
            p_t.mul_(1.0 - tau).add_(p_o, alpha=tau)

解读：演员损失只有一行，但包含三个正确性前提。（1）others_acts.detach() 保证梯度不泄漏给其他智能体的动作：理论上更新 θi 时其他动作是常数，若省略 detach，反传会把梯度推到 others_acts 张量上，虽然它通常不接其他演员的参数而暂时无害，但一旦数据流被重构（例如 others_acts 来自某演员的前向），就会造成跨智能体参数污染。（2）a_i / act_scale 与评论家入口的归一化约定一致，量纲错误会让梯度被范围差异放大或缩小。（3）负号与均值构成"最大化 Qi"的目标；软更新函数对在线与目标参数成对遍历，遍历顺序必须与构造顺序一致，错位会让参数被错误组合。

常见坑

  • 回放池存了去噪动作。症状：评论家对高价值区域的估计偏差，探索后期性能停滞。原因：执行动作与存储动作不一致。修复：入库前断言存储张量等于实际发给环境的动作向量。
  • 演员更新漏掉 detach 或错拼动作。症状：训练初期正常，重构代码后出现难以定位的参数污染或突然发散。原因：其他智能体动作带了梯度路径，或拼接顺序与评论家输入约定不一致。修复：为评论家入口写维度与顺序断言，并在演员损失外部对 others_acts 强制 detach。
  • tanh 饱和区过大。症状：动作输出长期贴近边界、梯度趋零，策略不再改进。原因：动作目标范围远大于 tanh 的敏感区间，或初始化偏置把预激活推入饱和。修复：核对动作范围缩放系数，观察预激活分布，必要时缩小最终层初始化方差。
  • 软更新系数与学习率失配。症状：目标值噪声大且波动周期明显，或价值估计长期滞后于回报。原因：τ 过大使目标网络追随在线噪声，τ 过小使目标过时。修复：固定 τ = 0.01 为基线，用 q 值曲线与回报曲线的滞后量作调参依据。
  • 预热不足就启动学习。症状：评论家早期拟合自身的随机动作，策略被拖向噪声大的区域。原因：回放池覆盖不足。修复：保证不少于 104 环境步的随机预热；预热期间演员与评论家参数冻结。

练习与思考

  1. 从 J(θ) = 𝔼[Q(s, μ(o))] 出发，写出对 θ 求全导数的链式展开，指出确定性策略梯度省去 log 项的条件。★
    提示
    ∇θ J = 𝔼[∇aQ·∇θμ]，全过程无需动作分布的可导形式，省去 log 项的条件是"动作由 θ 确定生成且 Q 对动作可微"。若动作含额外噪声源，需补充噪声路径或改回随机策略估计。
  2. 把软更新 τ 从 0.01 改为 0.1，预测评论家损失曲线、目标值方差与最终回报的变化。★
    提示
    目标跟随变快，目标值方差上升，评论家损失抖动加剧；短期收敛更快，长期回报可能劣化。该实验用于建立 τ 与噪声容忍度的对应感。
  3. 解释：为什么评论家 i 的梯度不需要对队友动作 aj 求导？说明若有人实现里对全部动作求导会发生什么（提示：该目标函数已偏离 MADDPG 的定义）。★★
    提示
    梯度估计目标是对 θi 的策略改进，只涉及 μi；对 aj 求导相当于把 θj 也纳入相干更新，改变了"轮流改进"的假设，目标函数变为联合参数化版本，可能引发同步震荡。
  4. 设计消融：逐智能体评论家与共享评论家（加 id 嵌入）在同构任务上的对比。给出参数量差距、预期回报排序与"弱势智能体梯度信号"的度量方案。★★
    提示
    度量可设计为各智能体优势或 q 值对各自动作梯度的模长分布；共享评论家预计模长更分散，个别智能体明显偏小。参数量：逐智能体版为共享版保障与 N 倍的关系，实验报告一并给出。
  5. 设计实验测量高估：在固定评估状态下记录 maxa Q(s, a) 沿训练的变化，与蒙特卡洛回报核对。预测单评论家 MADDPG 的曲线与双评论家版本的差异，并说明测量所需的数据与步数。★★★
    提示
    连续动作下 max 无法枚举，改在评估状态上对局部网格或多次采样取上包络；预期 MADDPG 的 Q 上包络持续高于 MC 回报，MATD3 的差值显著缩小。数据只需固定评估状态集与策略滚动回报。

小结

  • 连续动作排除动作上的精确最大化与求和，确定性策略梯度用链路求导替代，前提是评论家对动作可微。
  • MADDPG 逐智能体配集中式评论家，只对自身动作求导；队友动作作为条件输入，训练期可读、执行期不读。
  • 离策略回放加软更新目标网络构成训练骨架；探索靠动作噪声，回放池存储执行动作。
  • 动作范围归一化与 tanh 边界共同约束输出空间，饱和与量纲是高频故障点。
