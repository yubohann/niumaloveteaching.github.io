第 080 章：安全约束与鲁棒性结合

把"性能之外的要求"写进优化目标：本章讲清约束马尔可夫决策过程（Constrained Markov Decision Process, CMDP）、拉格朗日对偶与信任域方法的求解，再讲不确定动力学下的鲁棒优化，最后给出与集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）结合的训练与评测设计。

  • 主题：约束优化 / 安全边界与最坏情形
  • 关键公式：maxπJr(π) s.t. Jc(π) ≤ d，对偶 minλ≥0maxπJr−λ(Jc−d)
  • 预计学时：65 分钟
  • 前置章节：第 079 章

学习目标

  • 掌握 CMDP 的形式化定义，能写出带约束的回报目标并解释代价折扣与预算阈值的含义。
  • 理解拉格朗日对偶的鞍点结构，描述策略与乘子的交替更新流程及震荡风险。
  • 掌握信任域类方法（如约束策略优化 Constrained Policy Optimization, CPO）的核心思想：在保证约束满足的单步内最大化回报改进。
  • 理解鲁棒马尔可夫决策过程的不确定集合与最坏情形目标，掌握对抗训练与稳健评测的构造方式。
  • 能设计实验：无约束基线、固定惩罚、拉格朗日与安全层组合四类对照，评测覆盖平均与尾部风险两类指标。

背景与动机

协作任务的目标常包含硬性要求：机器人不得碰撞、能耗不得超过预算、区域访问不得越界。把这些要求折进奖励塑形会带来两个问题：权重标定困难，权重过小时约束被短时收益压倒；权重过大时任务性能被压制。约束优化把要求写成独立的代价通道与预算阈值，优化目标与约束分离，训练过程自动调节两者的权衡。

鲁棒性是安全的另一半：训练环境与部署环境的动力学、传感器噪声、队友行为都存在差异，平均性能好不代表最坏情形可用。鲁棒优化显式定义不确定集合，针对集合内最坏情形训练；与 CTDE 结合时，集中式代价评论家评估团队约束，分散执行配安全层兜底，本章把这个最完整的防线下沉到分层的评测体系里。

核心原理

本节先讲 CMDP 与两类求解，再讲鲁棒优化与统一评测。

1. 约束马尔可夫决策过程

CMDP 在标准 MDP 上增加代价函数 c(s, a) 与预算 d：优化回报的同时要求累计折扣代价不超过预算。约束可以是多条（碰撞代价、能耗代价、越界代价），每条独立累计。

maxπ Jr(π) = E[Σtγtrt] s.t. Jci(π) = E[Σtγtci,t] ≤ di，i=1…m 预算 d 的量纲与代价通道对应；m 条约束对应 m 个乘子

2. 拉格朗日对偶

把约束以乘子 λi ≥ 0 折入目标得到拉格朗日函数 L(π, λ) = Jr(π) − Σiλi(Jci(π) − di)。问题转化为求鞍点：策略最大化 L，乘子最小化 L。乘子的语义是"约束的影子价格"：越界时 λ 增大压制违规动作，满足约束且有裕量时 λ 减小释放性能。

minλ≥0 maxπ L(π, λ)，λi ← [λi + η(Jci − di)]+ 投影梯度上升/下降交替进行；η 过大引起乘子与策略的同步震荡

朴素的交替更新存在循环震荡：乘子增大把策略推离约束边界，代价下降后乘子回落，策略又漂回去。抑制手段包括减小平滑系数（乘子取滑动平均）、代价评论家与回报评论家分享特征、以及在每次更新后用实测代价校准。

3. 信任域求解与安全层分工

CPO 把单步更新限制在信任域内，先求回报改进最大的方向，再在回报与代价两个目标上做回溯线搜索：接受更新须同时满足策略改进与约束不显著恶化，两步验证使约束满足具有单步保证。训练期用 CMDP 做约束优化，执行期保留几何安全层（第 068 章）兜底，两者互补：前者塑造"倾向于安全"的策略分布，后者在状态越界时提供最小修正。

4. 鲁棒优化与评测

鲁棒 MDP 定义不确定集合 U（动力学参数区间、传感器噪声方差、队友策略族），目标为 maxπminP∈UJ(π, P)。求解用对抗训练：固定集合内采样若干环境配置，逐一评估取最差者回传梯度。评测层面加入条件风险价值（Conditional Value at Risk, CVaR）：把回放按回报排序取最差 5% 的均值，平均值与尾部指标同时报告，才能暴露"均值达标、极端失效"的隐患。

5. 数值算例：乘子更新、CVaR 与信任域

乘子算例。单约束、预算 d=0.05、当前窗口代价 0.08，违例 0.03。λ=2、η=0.05 时一次对偶更新为 λ←max(0, 2+0.05×0.03)=2.0015，乘子微增；若连续多批违例累积，λ 按比例持续上升，把策略推回约束内。约束满足且留有裕量时，λ 每轮以同等步长衰减，最终把权重还给回报项。

CVaR 算例。100 个回合回报排序后取最差 5 个：−10、−8、−6、−5、−4，CVaR5%=−6.6；若全体均值为正 2，尾部与均值的差距 8.6 就是均值掩盖的风险量。报告时应同时给出均值、CVaR 与最差配置回报三项，缺任何一项都可能误判鲁棒性。

信任域算例。KL 半径 δ=0.01 时单步策略分布的平均变化受严格限制，动作分布的对数比变化约在几个百分点；半径放大到 0.1 则单步更新幅度显著增大，约束容易被突破。两档对照用于标定"单步不恶化"保证的边界位置。

解读：三组数字分别约束对偶步长、尾部报告与更新幅度。乘子步长过小则约束响应慢，过大则与策略同步震荡；CVaR 的估计需要覆盖尾部事件，评估回合数应达到稀有事件发生概率的倒数量级以上，否则尾部均值的方差不可接受。

实现思路与设计

训练采用"双评论家加乘子调度"结构：回报评论家与代价评论家共享特征，乘子按滑窗约束违例更新；执行端保留安全层与扰动鲁棒策略。

实验设计

  1. 对比基线：无约束 CTDE、固定惩罚系数（两档）、拉格朗日方法、拉格朗日加安全层。
  2. 消融设置：乘子平滑开/关、代价评论家共享特征与独立两档、信任域半径两档、对抗训练开/关。
  3. 评价指标：平均回报、约束违例率（逐通道）、CVaR5% 回报、最坏配置下的成功率、恢复步数（从扰动中回到约束内的步数）。
  4. 统计方式：约束指标的方差较小但尾部事件稀有，评测回合数需覆盖稀有事件，报告违例次数的置信区间。
设计决策：为什么 CMDP 约束与几何安全层必须同时保留

CMDP 是"软约束"：它在期望意义下限制违例密度，单条轨迹仍可能出现瞬时越界；几何安全层是"硬约束"：它在每步执行时做最小修正，单步越界概率受控。仅用 CMDP 时训练后期仍有偶发碰撞；仅用安全层时策略不规避高风险区域，修正比例长期偏高、任务效率受限。两者叠加时 CMDP 把策略推向低风险行为，安全层处理残余的分布外状态。

与第 079 章的差异：模型预测规划处理的是已知模型的约束满足，本章在未知或不确定模型下学习约束策略；与第 068 章相比，安全层从唯一手段降级为兜底组件，成为完整防线的一环。

对比分析：四类约束处理路线

路线约束满足形式调参负担失效特征适用条件
固定惩罚期望型，无保证权重反复标定权重失衡，性能或违例其一恶化约束较软
拉格朗日方法期望型，乘子自适应对偶步长与平滑乘子震荡、响应滞后约束通道可测量
信任域方法（CPO）单步不恶化的近似保证半径与回溯线搜索可行域过小时更新停滞需要较强约束保证
拉格朗日加安全层期望型加执行端硬修正两套参数修正比例长期偏高安全关键任务

选择依据是约束性质：硬性物理约束需要执行端兜底，期望型预算适合用对偶方法处理。两者叠加是安全关键任务的常规组合，代价是接口与监控点增多；修正比例、乘子轨迹与逐通道违例率都应进入常规看板，任一指标漂移都先于回报变化出现。

评测协议的补充约定：训练扰动集与评测扰动集必须独立采样，前者用于对抗训练，后者用于验收；评测回合数按尾部事件频率设定，并对每个配置单独报告违例次数，聚合后取平均会掩盖最坏情形，逐配置报告才能在表格中直接看到风险。

关键代码与解读

片段 1：拉格朗日乘子更新

import numpy as np

class MultiplierSchedule:
    """按滑窗代价更新约束乘子，抑制对偶震荡。"""
    def __init__(self, n_constraints, lr=0.05, smooth=0.9):
        self.lam = np.zeros(n_constraints)
        self.lr = lr
        self.smooth = smooth
        self.window = np.zeros(n_constraints)

    def update(self, cost, budget):
        # 滑窗均值降低单批代价的采样噪声
        self.window = self.smooth * self.window + (1 - self.smooth) * cost
        violation = self.window - budget
        # 投影到非负域：约束满足且有裕量时乘子衰减到 0
        self.lam = np.maximum(0.0, self.lam + self.lr * violation)
        return self.lam.copy()

解读：乘子作用在拉格朗日目标上 L = J_r − λ(J_c − d)，违例为正时 λ 上升、策略被压制，裕量时 λ 向 0 衰减并把权重还给回报。滑窗替代单批代价是稳定性的关键，窗口长度与回合长度需匹配。乘子本身不参与梯度计算，只通过奖励校正项影响策略更新。

片段 2：代价奖励修正与策略损失

import torch

def constrained_actor_loss(logp, adv_r, adv_c, lam):
    """拉格朗日策略损失：回报优势减去乘子加权的代价优势。"""
    surr_r = (logp * adv_r.detach()).mean()
    surr_c = (logp * adv_c.detach()).mean()
    # lam 为标量或多通道向量；多通道时逐项加权求和
    loss = -(surr_r - float(lam.sum()) * surr_c)
    return loss

def cost_critic_loss(v_c, target_c):
    """代价评论家：与回报评论家同构，单独回归折扣代价。"""
    return 0.5 * ((v_c - target_c.detach()) ** 2).mean()

解读：代价优势 adv_c 用广义优势估计在代价通道上计算，正值表示该动作增加违例风险，在乘子加权后从回报优势中扣除。多通道时乘子逐项相乘再求和，各通道量纲不同时先做归一化。代价评论家与回报评论家结构相同但参数独立，共享底层特征会引入两目标的梯度干扰，是否共享作为消融项。

片段 3：最坏情形与 CVaR 评测

import numpy as np

def robust_evaluation(returns, cfg_returns, alpha=0.05):
    """稳健评测：跨配置最坏值与回报尾部风险。
    returns: 单配置回合回报；cfg_returns: 各配置的平均回报列表。
    """
    arr = np.sort(np.asarray(returns))
    k = max(1, int(len(arr) * alpha))
    cvar = float(arr[:k].mean())          # 最差 alpha 比例的均值
    worst_cfg = float(np.min(cfg_returns))  # 跨配置最坏平均回报
    return {"cvar": cvar, "worst_cfg": worst_cfg,
            "mean": float(np.mean(arr))}

解读：CVaR 关注回报分布的左尾，平均回报掩盖的"少数回合彻底失败"在 CVaR 中显现。跨配置最坏值与 CVaR 从两个维度度量鲁棒性：前者检验对动力学偏移的适应，后者检验回合内的运气波动。报告三类数值避免单一指标误导。评测配置集合应与训练时的不确定集合分离，防止鲁棒性过拟合。

常见坑

  • 乘子震荡：对偶步长过大或未平滑，策略与乘子同步摆动。修复：滑动平均、减小 η、固定乘子若干轮再释放。
  • 代价评论家低估风险：代价信号稀疏且延迟，价值低估导致约束名义满足而实测违例。修复：代价通道单独归一化、提高代价样本回放权重。
  • 约束按团队聚合掩盖个体：团队平均达标但个别智能体持续越界。修复：逐智能体代价通道，并报最坏个体违例率。
  • 鲁棒训练过拟合配置集：只在训练用扰动上最坏优化，换一组扰动即退化。修复：评测用独立扰动集，训练扰动范围留裕量。
  • 只报告平均指标：尾部失效在均值中被稀释。修复：默认并列报告 CVaR 与最坏配置指标，作为验收门槛。

练习与思考

  1. 单约束、当前代价 0.08、预算 0.05、λ=2、η=0.05，计算一次对偶更新后的乘子值，并说明它对策略损失的影响方向。★
    提示
    违例 0.03，λ 更新为 2.0015；代价优势的惩罚权重略增，策略进一步规避高代价动作。
  2. 把乘子平滑系数从 0.9 降到 0.5，预测约束违例率与回报曲线的变化。★★
    提示
    响应更快但噪声更大，违例率波动扩大、回报被过度压制；用两档系数对照违例与回报的联合曲线。
  3. 推导：在单一约束、策略类足够丰富的简化下，说明鞍点处"约束恰好激活"（Jc=d 且 λ>0）与"约束不激活"（λ=0）两种情形的互补条件。★★★
    提示
    由 KKT 条件出发：λ≥0、Jc−d≤0、互补松弛 λ(Jc−d)=0，讨论两类情形的最优策略。
  4. 设计实验：对抗训练开/关两组，评测覆盖训练扰动集与独立扰动集两套配置，用最坏配置回报与 CVaR 两项指标检验鲁棒性的真实性与迁移边界。★★★
    提示
    预期对抗组在训练集上最坏回报显著更高，独立集优势缩小；缩小幅度反映不确定集合设定的松紧。
  5. 某策略的 100 个回合回报排序后最差 4 个为 −12、−7、−5、−3。计算 CVaR5%（按最差 5 个计，缺口补一个次差值），并说明它与均值为 1.5 的差距反映了什么风险。★★
    提示
    最差 5 个取 −12、−7、−5、−3 与次差值（假定为 0），CVaR 约 −5.4；与均值的差距约 6.9，反映少数回合彻底失败的风险，均值报告无法暴露这一层信息。

小结

  • CMDP 把安全要求写成独立代价通道与预算阈值，目标与约束分离，避免惩罚系数的反复标定。
  • 拉格朗日对偶以乘子调节权衡，乘子是约束的影子价格；平滑与步长控制决定对偶稳定性。
  • 信任域方法为单步更新提供约束不恶化的保证；执行期安全层兜底，软硬约束分层各司其职。
  • 鲁棒优化针对不确定集合内的最坏情形训练，评测并列报告 CVaR 与最坏配置指标，防止均值掩盖尾部失效。
  • 数值算例给出三处定量约束：乘子按违例量成比例更新，CVaR 揭示均值掩盖的尾部风险，信任域半径决定单步更新的幅度上限。
