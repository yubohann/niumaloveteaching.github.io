第二篇 · 训练工程与稳定性

第 032 章：非平稳环境下的CTDE

本章讲非平稳性（Non-Stationarity）的数学刻画与缓解：队友与对手策略更新如何使个体诱导转移核持续漂移、漂移速率的度量方法、策略特征标识与对手建模两类适应机制，以及更新节奏与数据新鲜度的配合。

  • 主题：学习动力学 / 漂移缓解
  • 关键公式：Pi(s′ | s, ai) = Σa−i π−i(a−i | s) · P(s′ | s, a)
  • 预计学时：55 分钟
  • 前置章节：第 031 章 大规模智能体扩展性

学习目标

  • 理解多智能体学习中非平稳性的来源分类，能区分共适应漂移、对手漂移与任务分布漂移。
  • 掌握个体诱导转移核的形式化：从单个智能体视角把其他智能体策略边缘化，观察转移核随训练时间的漂移。
  • 掌握漂移的度量方法：动作分布散度、参数距离、队友预测误差，以及监控频率与成本的取舍。
  • 掌握策略特征标识与对手建模两类适应机制的实现方式与适用条件。
  • 能组合更新节奏、数据新鲜度与适应模块给出缓解方案，并诊断冻结队友评测造成的评估失真。

背景与动机

单智能体强化学习的马尔可夫决策过程假设转移分布固定：环境动力学不因策略更新而改变。多智能体环境放弃了这个假设：其他智能体的策略在训练中持续更新，从任何单个智能体的视角看，环境对他动作的响应方式一直在变。第 023 章从数据角度讨论过"旧策略数据"，本章从学习动力学角度讨论"目标本身在移动"这一更根本的问题。

非平稳性在 CTDE 中的表现具有特殊性：集中式评论家访问全局状态，缓解了个体视角下的部分可观测问题，但评论家拟合的目标值中包含其他智能体的策略，这些策略每周更新一次，评论家每周被移动一次靶位。训练曲线因此呈现特有的形态：价值损失长期不降或周期性抬升、策略回报在收敛带附近振荡。理解并度量漂移是选择缓解手段的前提，也为第 033 章的对抗训练与第 034 章的混合动机环境建立分析框架。

核心原理

1. 非平稳性的来源分类

按漂移的驱动因素分为四类，缓解手段各不相同：

来源漂移对象典型场景主要缓解
队友共适应队友策略的联合分布合作任务中全体持续学习更新节奏同步、策略特征标识
对手适应对手策略的响应方式竞技与对抗任务对手建模、种群训练（第 033 章）
任务分布漂移奖励与难度分布课程学习、奖励重塑阶段化配置、数据分区（第 022、023 章）
表征漂移共享网络的特征分布参数共享、异构扩展归一化、目标网络、低学习率

四类来源可以同时存在，诊断时先用漂移度量确认哪一类的贡献最大，再投放对应手段；在来源未定位时叠加全部缓解手段会让因果分析失效。

2. 诱导转移核的漂移

从智能体 i 的视角，其他智能体的策略 π−i 被边缘化进转移核：

Pi(s′ | s, ai) = Σa−i π−i(a−i | s) · P(s′ | s, ai, a−i) a−i 遍历其他智能体的联合动作；边缘化后 i 面对的是一个等效单智能体 MDP

当 π−i 随训练更新时，等效转移核 Pi 随时间变化，i 的学习问题从固定 MDP 变为漂移 MDP 序列。漂移速率可以用相邻时间窗上策略分布的散度度量：

dt = Es[ DKL( π−i(t)(· | s) ‖ π−i(t−Δ)(· | s) ) ] Δ 为比较间隔；dt 高出阈值时说明该时间窗内学习目标移动过快

漂移对价值的后果是时序差分目标的有偏性：目标值 y 用旧策略行为下的回报估计来指导新策略的价值学习，偏差随漂移幅度增长。目标网络（第 024 章）平滑了自身参数的移动，对队友策略的漂移没有直接约束，这是它在本章问题上的作用边界。

度量实现上还有一步常被忽略：用采样估计的散度存在正偏差，偏差量级与动作数成正比、与样本量成反比。用每轮数百条轨迹估计 KL 时，两个完全相同的策略也会给出小的正值，告警阈值应把这一估计基线一并考虑，或改为观察散度序列的斜率，单点绝对值不作为判据。

3. 策略特征标识与对手建模

适应机制的共同思路是把"其他智能体的当前行为"显式编码为网络输入，让价值或策略对伙伴行为条件化：

  • 策略特征标识（Policy Fingerprint）。用低维统计量概括队友的策略状态，例如最近若干回合中队友各动作的执行频率、最近更新的时间步编号。价值函数输入拼接特征标识后，同一观测在不同队友风格下获得不同的价值估计，避免把两种风格的平均当作真值学习。
  • 对手建模（Opponent Modeling）。训练辅助预测头，用队友观测与历史预测其下一步动作，预测分布的编码作为适应信号输入价值网络。辅助头的损失是监督式交叉熵或回归，与主任务损失分开加权。

两类机制在实现上共享接口：特征标识是压缩后的统计，建模头是学习到的表征，后者的适应能力更强、代价是训练信号与主任务竞争。关键的工程纪律是数据口径一致：用在线新数据训练的特征标识不能在旧回放数据上直接使用，否则价值网络把两个口径的特征标识当作同一输入，产生系统性偏差。常见修正是在回放数据上重建特征标识（用行动序列重算统计量），或对特征标识做时间衰减加权。

两类机制的适用边界由可预测性判定：对手行为预测误差低于随机基线的交叉熵时，建模头提供的条件信号才含信息；把预测头的每次输出都当真值拼接进价值输入，在对手接近随机时等价于注入噪声。诊断方法是记录辅助头在验证集上的交叉熵，与均匀策略的交叉熵 ln|A| 比较：两者接近说明该对手不可预测，此时的适应预算应转向特征标识统计与鲁棒性训练，或把对手的历史检查点加入训练分布，而不应继续加大建模头容量。

4. 更新节奏与学习率

漂移速率直接由全体智能体的更新频率决定。三项控制手段：

  • 减缓更新。降低学习率、增大目标网络平滑系数、延长批量累积窗口。代价是收敛速度下降，收益是漂移幅度与训练稳定性改善。
  • 同步节奏。让所有智能体在同一次更新轮次内完成参数更新，避免部分智能体领先数个版本；参数共享结构与批次式更新天然接近该性质。
  • 经验混合比例。控制回放池中新旧数据的采样比例，让价值网络适度回顾旧对手行为，提升鲁棒性；比例过高则会拖慢对新行为的适应。

还有一类主动适应手段来自元学习：在训练中周期性加入策略快速适应阶段，让网络学习"如何在少量交互内调整到当前伙伴风格"，与特征标识机制配合使用。工程上多数任务用"特征标识加节奏控制"已经可以稳定训练，元学习适合伙伴风格变化剧烈的场景。

5. 数值算例：目标偏差与漂移度量的量级

用一个两动作队友的例子把偏差公式具体化。设自身某动作下，队友取两个动作时对应的联合 Q 值分别为 2.0 与 −1.0，队友策略从 π1 = (0.8, 0.2) 切换到 π2 = (0.2, 0.8)，其余条件不变。切换前的引导目标按 π1 边缘化，切换后按 π2 边缘化，两者之差为 Σ(π1 − π2)(a) · Q(a) = 0.6 × 2.0 + (−0.6) × (−1.0) = 1.8：同一状态与同一自身动作下，学习目标在队友切换后瞬间移动 1.8，折扣回报的其余系数按 γ 逐项缩放。偏差为零的两种情形由此可以看出：两策略动作分布相同（差值向量为零），或 Q 对队友动作不敏感（差值向量与之正交）。

漂移度量的数值感受同样可以手算。在二动作分布上，把动作概率从 0.5 移动 10 个百分点（到 0.60）对应 KL 约 0.020，移动 22 个百分点（到 0.72）对应 KL 约 0.108：设计文档里"KL 0.1 量级"的告警阈值换算成动作分布语言，约等于关键动作概率在一个比较窗口内移动两成；窗口越短，同样的概率移动折算出的 KL 越大，阈值必须与窗口长度成对标定。把窗口从 2 万步缩短到 5 千步而沿用原阈值，会把正常的学习进度误报为漂移告警。

策略特征标识的衰减系数与告警响应存在配合关系：decay = 0.99 时权重的半衰期为 ln(1/2)/ln(0.99) ≈ 69 步，100 步以前的统计仍保留 0.99100 ≈ 0.366 的权重。若漂移告警的响应动作是重建特征标识，重建周期应短于半衰期，否则特征标识在两次重建之间已把旧风格权重降到不足三成，新风格统计尚未积累充分，价值输入在切换期进入双重失配。

边界提示：上述偏差量级是单步静态度量，训练中的实际后果还取决于切换频率与价值学习率。切换周期短于价值网络的有效平滑窗口时，网络学到的是两代策略的平均，与任何一代的真实价值都不吻合，此时应优先同步全体更新节奏，追加特征标识只能缓解输入侧，无法消除目标侧的平均化。

实现思路与设计

漂移治理参数与适应模块分开配置：漂移度量进入监控管线，按阈值触发节奏调整；适应模块（特征标识、建模头）作为价值网络的输入扩展，不影响算法主结构。

与第 031 章的衔接点：大规模任务中漂移度量的计算限定在采样子集上进行（全量代价过高），采样规模取每轮数百条轨迹；监控指标的日志格式与第 035 章的诊断体系共用字段。

监控管线的字段设计沿用第 035 章的诊断体系：漂移度量（策略散度、参数距离）、特征标识统计（各动作频率与更新龄）、辅助头误差（预测交叉熵与其基线之差）三组指标按同一评测间隔落盘，任一告警触发时保留前后各一个窗口的原始数据切片，供事后归因。把三组指标与学习率、更新间隔画在同一时间轴上，漂移曲线对学习率调整的响应通常在一个窗口内可见：下调学习率后漂移散度回落，说明告警来源是更新过猛；散度不随学习率调整而持续上行，说明来源是探索或任务分布改变，需要改用分布侧的处置手段。

关键代码与解读

片段 1：队友动作预测头（对手建模）

import torch
import torch.nn as nn
import torch.nn.functional as F

class TeammateModel(nn.Module):
    """辅助头：用队友观测预测其动作分布，供价值网络条件化。"""
    def __init__(self, obs_dim, act_dim, hidden=64):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(obs_dim, hidden), nn.ReLU(), nn.Linear(hidden, act_dim))

    def loss(self, obs, actions):
        # 交叉熵监督：预测分布与真实动作的偏差，与主任务损失独立加权
        logits = self.net(obs)
        return F.cross_entropy(logits.view(-1, logits.shape[-1]), actions.view(-1))

    @torch.no_grad()
    def fingerprint(self, obs):
        # 推理时输出预测分布：作为伙伴行为的特征标识，不参与梯度回传
        return torch.softmax(self.net(obs), dim=-1)

解读：三段式接口把"训练、适配、推理"分开：训练用交叉熵，推理用 no_grad 输出的分布作为特征标识。预测头通常只对需要的队友计算（对手数量多时按角色分组），特征标识维度等于动作数，与第 030 章的角色嵌入拼接顺序保持一致。一个容易忽略的细节是预测头的输入必须取队友的观测，用自身观测会退化为动作复制，训练数据中队友动作与自身动作的相关性会让该头在训练集上"虚高"而在评估中失效。

片段 2：策略特征标识的构建与衰减

import numpy as np

class PolicyFingerprint:
    """维护队友动作频率与更新龄的低维特征标识，供价值输入拼接。"""
    def __init__(self, n_agents, n_actions, decay=0.99, age_scale=1e-4):
        self.freq = np.zeros((n_agents, n_actions), dtype=np.float32)
        self.age = np.zeros(n_agents, dtype=np.float32)
        self.decay, self.age_scale = decay, age_scale

    def observe(self, actions):
        # 指数衰减统计：近期行为权重高，旧风格自动淡出
        self.freq *= self.decay
        for i, a in enumerate(actions):
            self.freq[i, a] += 1.0
        # 归一化前对行做平滑，避免从未出现的动作把特征标识压向奇异分布
        row = self.freq + 1e-3
        return row / row.sum(axis=1, keepdims=True)

    def mark_update(self, agent_idx):
        # 队友最近一次参数更新的龄：0 表示刚更新，越大越陈旧
        self.age[agent_idx] = 0.0

    def tick(self):
        # 每环境步调用：龄按固定尺度累积并压缩到 (0,1) 区间
        self.age = np.tanh(self.age * self.decay + self.age_scale)

解读：指数衰减让特征标识自动跟踪策略漂移：队友风格变化后，旧行为统计在约 1/(1−decay) 步内淡出，与本课程的目标网络时间常数口径一致。更新龄提供第二条信息通道：即使动作频率尚未明显变化，年龄信号也提示"队友可能即将变化"，价值网络可以主动应用保守估计。特征标识拼接进价值输入时通常乘一个小系数缩放，防止其量级与观测特征失衡；回放旧数据时用行动序列重算特征标识，保持与在线口径一致。

片段 3：策略漂移监控

def policy_drift(policy_old, policy_new, obs_batch):
    """在采样状态上计算两个策略版本的平均 KL 散度。"""
    with torch.no_grad():
        logits_old = policy_old(obs_batch)                  # 旧版本分布
        logits_new = policy_new(obs_batch)                  # 当前版本分布
        p_old = torch.softmax(logits_old, dim=-1)
        log_p_new = torch.log_softmax(logits_new, dim=-1)
        # KL(p_old || p_new) 按状态平均：度量策略平均意义上的移动幅度
        kl = (p_old * (torch.log_softmax(logits_old, dim=-1) - log_p_new)).sum(-1)
    return float(kl.mean())

解读：该函数在固定的采样状态子集上比较新旧策略版本，度量的是"策略在常见状态上的行为位移"，与参数距离相比更贴近实际影响。监控要点是趋势，绝对值只作参照：KL 曲线的持续上行说明漂移加速，配合学习率与更新间隔的图表可以做因果归因。保留旧版本策略的副本需要少量显存与参数拷贝开销，通常在监控间隔到达时执行一次版本快照，快照之间策略不再更新副本，计算对比后即释放。

常见坑

  • 用冻结队友做训练期评测。队友固定时个体策略表现良好，恢复全体训练后性能骤降。症状是"评测领先训练"。修复：评测分为冻结伙伴与共适应伙伴两套协议，同时报告。
  • 对手建模头反传污染主网络。辅助损失梯度与主任务梯度在共享主干中相互干扰。症状是主损失波动增大。修复：建模头使用独立编码器，或在共享主干处对辅助梯度做 detached 处理。
  • 特征标识口径在线与回放不一致。在线特征标识来自实时统计，回放数据使用旧特征标识，价值网络学到混合口径。修复：回放时重算特征标识，或对特征标识样本做时间权重。
  • 学习率与漂移速率失配。高学习率下队友策略快速变化，价值目标持续错位。症状是价值损失在收敛带上方周期性抬升。修复：降低学习率或延长更新间隔，观察漂移曲线的响应。
  • 回放池混存不同年代的对手数据而不加标记。旧对手行为与新对手行为混合训练，策略对当前对手的针对性下降。修复：按策略版本或年代标记数据，控制新旧采样比例。

    偏差正比于 Σa−i(π1−π2)(a−i)Q(s, ai, a−i)；当两策略动作分布相同或 Q 对队友动作不敏感时偏差为零。
  2. 改参数预测：把目标网络 τ 从 0.005 调到 0.05（其余配置不变），预测价值损失曲线的平滑度与训练回报方差两个指标的变化方向，并说明在队友漂移加剧的场景下为何不建议这样做。★
    提示
    τ 增大削弱目标平滑，价值目标对策略变化更敏感，损失曲线抖动加剧、回报方差上升；队友漂移与自身目标移动叠加后抖动被放大，两道平滑来源只应保留一道。
  3. 设计：为一个队友风格在训练中存在明显阶段切换的任务设计特征标识方案（统计量、维度、衰减系数、触发重建的条件），并给出验证特征标识有效性的对照实验。★★
    提示
    对照实验：启用与禁用特征标识，在风格切换点附近的适应速度用"切换后恢复成功率的步数"衡量。
  4. 实验设计：比较全体同步更新、两个训练组交替更新、冻结伙伴三种设置下的漂移曲线与联合回报曲线，说明三种设置在"个体最优"与"团队最优"之间的取舍。★★★
    提示
    冻结伙伴给出个体最优的上界参考；交替更新的漂移幅度介于两者之间；全体同步在联合回报上更优但个体曲线波动更大。

小结

  • 非平稳性来源分四类：队友共适应、对手适应、任务分布漂移、表征漂移；先用度量定位来源再投放手段。
  • 个体诱导转移核把队友策略边缘化进环境，策略更新使该核持续漂移，时序差分目标因此带有与漂移幅度相关的偏差。
  • 策略特征标识与对手建模把伙伴行为显式编码为网络输入；数据口径一致性是两者可用性的前提。
  • 减缓更新、同步节奏、控制新旧数据比例是通用缓解组合；元学习适应适合伙伴风格剧变场景。
